## 工程机制与反证实验

### 任务定义先于指标

没有明确输入、环境和成功状态，单个分数无法解释。

动手验证：把“回答得好”改写为可验证任务与结果。

### 结果与轨迹都要评分

最终正确但调用越权、成本异常或走了脆弱路径仍应失败。

动手验证：加入工具次数、权限和首错 grader。

### 模型 grader 需要校准

主观维度可用模型评审，但要与人工标签对齐并监控漂移。

动手验证：计算 grader 与双人标注的一致率。

### 生产反馈回流离线集

线上新失败簇应脱敏后进入回归集，避免只优化旧样本。

动手验证：从告警中抽样、分类并新增最小复现用例。

## 最小可运行切片

```ts
const run = await harness.execute(evalCase);
const scores = await Promise.all([
  taskResultGrader(run.environment),
  toolPolicyGrader(run.trace),
  latencyCostGrader(run.metrics),
  calibratedModelGrader(run.messages),
]);
storeEval({ evalCase, run, scores, versions });
assertNoRegression(scores, baseline);
```

切片只表达“用 trace、span、环境状态、确定性 grader 与校准后的模型 grader 建立回归和生产监控”的核心合同。生产实现还要补齐持久化、超时、密钥隔离、结构化日志、幂等和批量评测；如果不能重新取得eval case、模型版本、完整 messages、tool events、环境快照、grader、分数、延迟与成本，代码跑通也不能证明机制正确。

<Callout type="trap" title="本章首要反例">
  只评价最终回答是否顺眼，忽略越权工具调用、绕路、成本和错误恢复。它会破坏“每个评分都能回到输入、完整轨迹、环境结果、grader
  版本和可复跑样本”；应从eval case、模型版本、完整 messages、tool
  events、环境快照、grader、分数、延迟与成本定位首个分叉，而不是追加提示词掩盖运行时缺陷。
</Callout>

<Callout type="trap" title="结果正确也可能轨迹错误">
  “评估与可观测性”必须同时验收环境结果和完整轨迹。偶然得到正确文本，但发生越权调用、证据缺失、成本失控或错误停止，仍然是失败运行。
</Callout>

<Callout type="trap" title="升级后重新校准">
  模型、提示、工具、向量、协议或运行时变化都可能改变“用
  trace、span、环境状态、确定性 grader 与校准后的模型 grader
  建立回归和生产监控”的行为分布。升级后应在冻结任务集上重跑eval
  case、模型版本、完整 messages、tool
  events、环境快照、grader、分数、延迟与成本。

## 练习与答案

<Exercises>

**问题 1：最小证明。** 怎样用正常、边界和单故障三类样本证明“每个评分都能回到输入、完整轨迹、环境结果、grader 版本和可复跑样本”？

<Answer>
  冻结模型、任务、工具、权限和预算，手工写出三类预期，再保存eval
  case、模型版本、完整 messages、tool
  events、环境快照、grader、分数、延迟与成本。任何未解释的首个分叉、未配对事件或失败副作用都应阻断通过。
</Answer>

**问题 2：节点覆盖。** 评估与可观测性、小特上岗了，可你看不见它在干什么、为什么 Agent 上线后必须能「看见」和「量得出」、trace 与 span：把一次运行的每一步都记下来、三种评估方法：怎么判断 Agent 答得好不好（对比取舍）、回归与监控：改完一版，怎么确认没把别的地方改坏、动手玩：当一回裁判，再当一回回归探长、动手一：答得准，就一定得高分吗如何从目录词变成工程证据？

<Answer>
  把八个坐标分别映射到架构决策、状态轨迹和故障重放。每个坐标至少对应一个可观察状态、一个确定性判断或一个反例；只出现在列表里不算掌握。
</Answer>

**问题 3：恢复验收。** 怎样证明“只评价最终回答是否顺眼，忽略越权工具调用、绕路、成本和错误恢复”已经修复？

<Answer>
  保存正常基线，注入故障并在eval case、模型版本、完整 messages、tool
  events、环境快照、grader、分数、延迟与成本中标出首个差异；撤销后复位全部状态，用相同输入、版本、预算和权限重放。结果、轨迹与停止状态都回到基线才可交接。
</Answer>

</Exercises>
