## 直觉引入

想象你要比较两辆车的速度。你不能只看快不快，要看多远跑多快（距离=输入规模，时间=运行时间）。大O表示法就是算法的速度表——它告诉你当输入规模翻倍时运行时间怎么变化。O(n) 翻倍，O(n^2) 变四倍，O(log n) 只加一步。这就是算法分析的核心直觉。

## 概念讲解

### 大O表示法

<Al4FundamentalsDiagram />

<Term def="大O表示法描述算法运行时间随输入规模增长的上界，忽略常数因子和低阶项">
大O表示法
</Term>

O(f(n)) 表示运行时间不超过 c*f(n)。常见复杂度排序：O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)。大O 给出最坏情况上界，实际性能还受常数因子和输入分布影响。

### Union-Find

并查集解决动态连通性问题。关键优化：路径压缩（查找时把路径上节点直接连到根）和按秩合并（小树合并到大树），使每次操作接近 O(1)（均摊 O(alpha(n))）。

## 代码对照

```java
// Union-Find（加权 + 路径压缩）
public class WeightedQuickUnionUF {
    private int[] id, sz;

    public WeightedQuickUnionUF(int n) {
        id = new int[n]; sz = new int[n];
        for (int i = 0; i < n; i++) { id[i] = i; sz[i] = 1; }
    }

    public int find(int p) {
        int root = p;
        while (root != id[root]) root = id[root];
        while (p != root) { int next = id[p]; id[p] = root; p = next; }
        return root;
    }

    public void union(int p, int q) {
        int rp = find(p), rq = find(q);
        if (rp == rq) return;
        if (sz[rp] < sz[rq]) { id[rp] = rq; sz[rq] += sz[rp]; }
        else { id[rq] = rp; sz[rp] += sz[rq]; }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：认为 O(n log n) 一定比 O(n) 慢。**
大O忽略常数因子。小 n 时 O(n log n) 可能因为常数小而比 O(n) 快。大O只在 n 足够大时有意义。
</Callout>

<Callout type="trap">
**误区：Union-Find 只需路径压缩。**
两者解决不同问题：路径压缩优化查找，按秩合并防止树退化。两者结合才保证均摊 O(alpha(n))。
</Callout>

<Exercises>
**问题 1**：分析双层循环的复杂度：外层 i*=2，内层 j 从 0 到 n。

<Answer>
外层 log n 次，内层 n 次。总 O(n log n)。
</Answer>

**问题 2**：Union-Find 路径压缩后 find 的复杂度？

<Answer>
均摊 O(alpha(n))，反阿克曼函数，实际 n 下 <= 5，可视为 O(1)。
</Answer>
</Exercises>
