## 直觉引入

想象你要建一座大楼。基础（地基）决定了楼能盖多高，排序和查找（框架）是日常使用的核心功能，字符串与图（装修）是解决复杂问题的高级工具。算法第4版用 Java 为载体，从最基础的排序一路讲到字符串处理和图算法，核心思想：好的算法不只是正确，更是高效且可验证的。

### 学习路径

先掌握大 O 表示法和基础数据结构（栈、队列、背包），再学排序（选择、插入、归并、快排），然后是查找（二叉树、红黑树、散列表），最后是图和字符串算法。

## 代码对照

```java
// 同一问题：查找有序数组中的元素
// 方案A：顺序查找 O(n)
int bruteSearch(int[] a, int key) {
    for (int i = 0; i < a.length; i++)
        if (a[i] == key) return i;
    return -1;
}

// 方案B：二分查找 O(log n)
int binarySearch(int[] a, int key) {
    int lo = 0, hi = a.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (key < a[mid]) hi = mid - 1;
        else if (key > a[mid]) lo = mid + 1;
        else return mid;
    }
    return -1;
}
// 100万数据：顺序查找平均50万次，二分查找最多20次
```

## 常见误区

<Callout type="trap">
**误区：背了复杂度公式但不理解常数因子的影响。**
大 O 忽略常数因子，但实际性能中常数因子很重要。快排和归并都是 O(n log n)，但快排常数更小所以实际更快。
</Callout>

<Callout type="trap">
**误区：认为学算法就是为了刷题面试。**
算法是解决工程问题的思维工具。排序帮你理解数据库索引，图算法帮你理解网络路由。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？它们之间是什么关系？

<Answer>
基础、排序、查找、字符串与图。呈递进关系：基础提供分析工具，排序是经典算法入门，查找是数据结构应用，字符串与图是高级算法实战。
</Answer>

**问题 2**：为什么 Sedgewick 强调性能实验？

<Answer>
理论给出上界，但实际性能受常数因子、缓存、输入分布影响。实验揭示理论隐藏的因素。
</Answer>
</Exercises>
