## 从“代码能运行，不等于模型已说清”开始

基础编程模型（<Term def="Algorithms第4版用于表达程序、数据、控制流、methods、APIs与I/O的最小Java语言和library约定。">基础编程模型</Term>，basic programming model）不是Java语法速查表。它给后续全书建立共同实验语言：algorithm要写成完整program，input要能重放，output要能比较，数据结构要通过API隔离，性能判断要建立在明确operations之上。

先预测 `7 / 2` 与 `7 / 2.0` 是否都得到 `3.5`。不会：前者两个operands都是 `int`，执行integer division得到 `3`；后者提升为 `double` 才得到 `3.5`。如果连expression type都未确认，binary search里的index arithmetic、random simulation里的probability和analysis里的measurements都会从第一步偏离。

官方1.1依次覆盖 **Primitive data types and expressions、Statements、Arrays、Static methods、APIs、Strings、Input and output、Binary search**，并给出标准输入输出、drawing、audio与image processing libraries。这里不把这些主题压成“会写Java”一句话，而是把每一层的contract接到可验证程序上。

## 1.1.1 原始数据类型、表达式与语句

原始数据类型与表达式（<Term def="由primitive values、variables、literals与operators构成，并按静态类型规则产生value的计算片段。">原始数据类型与表达式</Term>，primitive data types and expressions）从四类常用types开始：`int` 表示整数，`double` 表示浮点数，`boolean` 表示逻辑值，`char` 表示单个字符。Expression不是只看符号；operand types决定operator的含义、promotion与result type。

<Algs4ExpressionTypeLab />

```java
int quotient = 7 / 2;          // 3
double ratio = 7 / 2.0;       // 3.5
boolean safe = n > 0 && total / n > limit;
char first = name.charAt(0);
```

`&&` 与 `||` 是short-circuit operators。上例在 `n <= 0` 时不会计算右侧，因此避免division by zero；若改成bitwise `&`，两个operands都会求值。Cast也不是精度恢复工具：`(double) (7 / 2)` 先完成integer division，再把 `3` 转成 `3.0`；必须在除法前转换operand。

Statement把expressions组织成state transitions。Assignment改变variable绑定或object content，conditional在branches间选择，loop重复执行block，method call转移控制并返回。可靠阅读方式是为每个block写出进入前state、guard和退出后state，而不是只追某次sample output。

## 1.1.2 数组：连续索引与reference语义

数组与静态方法（arrays and static methods）是本节把数据和algorithm连接起来的核心。Java array是固定长度、同一element type、由0开始索引的object；`a.length` 是field，不是method。有效区间是 `0` 到 `a.length - 1`，empty array的最后index是 `-1`，因此基于length写loop比硬编码边界可靠。

数组别名（<Term def="两个array variables保存同一个array object reference，任一方修改element都会被另一方观察到。">数组别名</Term>）来自assignment只复制reference：

```java
int[] a = { 2, 4, 6, 8 };
int[] b = a;
b[1] = 99;              // a[1] is also 99

int[] c = a.clone();
c[1] = -1;              // a is unchanged
```

<Algs4ArrayAliasLab />

二维数组在Java中是array of arrays，各rows可以有不同length。算法若假设rectangular matrix，必须验证每一行；只检查 `a.length` 不能证明 `a[i][j]` 有效。复制也分层：outer array的 `clone` 只复制row references，真正deep copy要逐row复制。

<Callout type="trap" title="用<=遍历array length">
Loop `for (int i = 0; i <= a.length; i++)` 最后一轮会访问 `a[a.length]`，必定越界。正确guard通常是 `i < a.length`；二分查找使用 `lo <= hi` 是因为 `hi` 本身是最后有效index，两者的边界语义不同。
</Callout>

## 1.1.3 静态方法：把算法变成带契约的operation

静态方法（<Term def="绑定到class而非instance、通过typed parameters接收values并由return type声明结果的Java operation。">静态方法</Term>）让algorithm拥有可复用name、parameters与return value。Java永远pass by value：primitive parameter得到value copy，array parameter得到reference value的copy。Method可以改动所指array elements，却不能通过重新赋值parameter改变caller variable指向。

```java
public static int gcd(int p, int q) {
    if (q == 0) return p;
    return gcd(q, p % q);
}
```

<Algs4StaticMethodCallLab />

Euclid method的termination argument不是“看起来会停”：当 `q` 为正时，`p % q` 落在0到 `q - 1`，第二parameter严格下降，最终到0。每次recursive call拥有独立parameter values；return时按相反顺序回到caller。对于可能为负的inputs还要先规定normalization，否则 `%` 的sign semantics会让契约含糊。

Method overloading根据compile-time argument types选择signature，不能只靠return type区分。Side effects也应进入API说明：pure method只由arguments决定result，更容易测试；mutating method必须说明修改哪个object、是否保留ordering以及异常时state是否完整。

## 1.1.4 API与字符串：client只依赖公开契约

API与字符串（APIs and strings）把program拆成client与implementation。API（<Term def="client可使用的public constructors、methods、arguments、returns与行为约束集合。">API</Term>）不仅是method列表，还包括preconditions、postconditions、side effects和failure behavior。后续章节每个data type都先给API，再比较多种implementation。

`String` 是immutable object。Concatenation产生新string；`length()`、`charAt()`、`substring()`提供query。内容相等要用 `equals`，因为 `==` 比较两个variables是否持有同一object reference：

```java
String a = new String("key");
String b = new String("key");

boolean sameReference = (a == b);  // false
boolean sameContent = a.equals(b); // true
```

Immutable value使string可以安全作为symbol-table key，但大量loop内concatenation可能反复创建objects；性能敏感构建应使用appropriate buffer。String indexing以UTF-16 code units为基础，不等于所有Unicode user-perceived characters；本书ASCII-oriented examples成立时，也要明确alphabet assumption。

<Callout type="trap" title="用==比较字符串内容">
Interning可能让某些literals的 `==` 偶然为true，造成测试假通过；从file或input构造的同内容strings常是不同objects。内容契约必须使用 `equals`，ordering使用 `compareTo`，不要让object identity混入algorithm semantics。
</Callout>

## 1.1.5 输入输出：让实验可组合、可重放

输入与输出（<Term def="program从command-line arguments、files或standard input读取data，并向standard output或media libraries产生可观察结果。">输入与输出</Term>，input and output）决定algorithm能否被可靠实验。Command-line arguments配置run，`In` 读取指定file，`StdIn` 读取standard input，`StdOut` 写standard output。Shell redirection与pipes让同一client无需修改source就能切换datasets和后处理。

官方 `BinarySearch` allowlist client的data path是：

```java
In in = new In(args[0]);
int[] allowlist = in.readAllInts();
Arrays.sort(allowlist);

while (!StdIn.isEmpty()) {
    int key = StdIn.readInt();
    if (BinarySearch.indexOf(allowlist, key) == -1)
        StdOut.println(key);
}
```

<Algs4StdIoPipelineDiagram />

这里file提供allowlist，standard input提供query stream，standard output只打印missing keys。可以用 `java BinarySearch tinyAllowlist.txt < tinyText.txt` 重放；输出可直接diff。Standard drawing、audio与image libraries把同样原则扩展到visual/media experiments，但visual output也应保留deterministic parameters或reference data，不能只凭“看起来对”验收。

## 1.1.6 二分查找：模型第一次成为完整算法

二分查找（<Term def="在ascending sorted array的闭区间中比较middle element并安全排除一半candidate range的logarithmic search。">二分查找</Term>，binary search）是1.1的综合实例。它同时使用array、static method、loop、comparison、API contract与I/O client。官方当前实现名为 `indexOf(int[] a, int key)`，要求 `a` ascending sorted；找到返回一个matching index，找不到返回 `-1`。

```java
public static int indexOf(int[] a, int key) {
    int lo = 0;
    int hi = a.length - 1;
    while (lo <= hi) {
        // If key is present, it is in a[lo..hi].
        int mid = lo + (hi - lo) / 2;
        if      (key < a[mid]) hi = mid - 1;
        else if (key > a[mid]) lo = mid + 1;
        else return mid;
    }
    return -1;
}
```

<Algs4BinarySearchTraceLab />

关键不是背诵template，而是证明loop invariant：每轮开始时，若key存在，它必在closed interval `a[lo..hi]`。当key小于middle value，sortedness证明 `mid` 及其右侧都不可能；更新为 `hi = mid - 1`。另一侧同理。每次未返回都会严格缩短interval，最终 `lo > hi`，empty candidate set证明key不存在。

`mid = lo + (hi - lo) / 2` 比 `(lo + hi) / 2` 更稳健，避免两个large nonnegative indices相加overflow。Duplicates不破坏“返回某个matching index”，但不能把结果误称为rank或first occurrence；若API要求lower bound，找到equal后还需继续向左收缩。

## 本章回顾

1. Basic programming model把primitive expressions、statements、arrays、methods、APIs与I/O统一成后续算法实验语言。
2. Expression semantics由types决定；integer division、promotion与short-circuit都必须先于数值直觉。
3. Array是reference object，assignment会alias，valid indices永远止于 `length - 1`。
4. Static method接收value copies；algorithm contract还必须说明termination与side effects。
5. API隔离client与implementation，String内容比较使用 `equals`。
6. Standard input/output让dataset可重放、output可比较，media libraries也应保留deterministic evidence。
7. Binary search依赖sorted precondition与closed-interval invariant，返回某个match不等于rank。

<Exercises>

**问题 1：`double x = (double) (5 / 2);` 与 `double y = 5 / 2.0;` 分别是多少？**

<Answer>`x` 是2.0，因为parentheses内先做integer division得到2，再cast；`y` 是2.5，因为一个operand是double，division前完成numeric promotion。</Answer>

**问题 2：method收到 `int[] data` 后执行 `data = new int[10]`，caller variable会改变吗？**

<Answer>不会。Parameter得到caller reference value的copy，重新赋值只改变local parameter。若method执行 `data[0] = 10`，则会修改双方共同指向的array object。</Answer>

**问题 3：为什么binary search进入loop时使用 `lo <= hi`，普通array遍历却使用 `i < length`？**

<Answer>Binary search维护inclusive closed interval，`lo == hi` 时仍有一个candidate必须检查；普通遍历的valid indices是0到length-1，因此guard必须在i等于length前停止。</Answer>

**问题 4：allowlist file未排序时，为什么程序即使不崩溃也不可信？**

<Answer>Binary search排除半区的证明依赖ascending order。未排序array可能碰巧找到部分keys，也可能错误返回-1；client必须先排序或把sortedness作为已验证precondition，并用linear oracle做交叉测试。</Answer>

</Exercises>
