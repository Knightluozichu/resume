## 直觉引入

想象你在整理一手扑克牌。一种方法是每次找最小的放最前面（选择排序），另一种是每拿到一张牌就插到正确位置（插入排序）。两种方法都很直觉，但效率不同——选择排序交换次数最少，插入排序对近乎有序的数据极快。希尔排序则是插入排序的加速版，用递减增量让元素跨越式移动。

## 概念讲解

### 选择排序与插入排序

<Al4SortingElementaryDiagram />

<Term def="选择排序每轮找最小值与当前位置交换，插入排序将当前元素插入已排序部分的正确位置">
初级排序
</Term>

选择排序：n 轮，每轮找最小值交换。比较固定 n^2/2，交换 n 次（最少）。插入排序：逐个插入已排序部分，比较次数取决于逆序对数量，最好 O(n)，平均 O(n^2)。

### 希尔排序

用递减增量序列（如 n/2, n/4, ..., 1），先做 h-排序，逐步缩小 h。大间隔让元素跨越式移动到接近最终位置，小间隔微调。实际性能远优于 O(n^2)。

<Step title="希尔排序">递减增量 h-排序。大间隔快速移动，小间隔微调。性能 ~O(n^1.3)。</Step>

## 代码对照

```java
// 1. 选择排序
void selectionSort(int[] a) {
    for (int i = 0; i < a.length; i++) {
        int min = i;
        for (int j = i+1; j < a.length; j++)
            if (a[j] < a[min]) min = j;
        exch(a, i, min);
    }
}

// 2. 插入排序
void insertionSort(int[] a) {
    for (int i = 1; i < a.length; i++)
        for (int j = i; j > 0 && a[j] < a[j-1]; j--)
            exch(a, j, j-1);
}

// 3. 希尔排序
void shellSort(int[] a) {
    int h = 1;
    while (h < a.length/3) h = 3*h + 1;
    while (h >= 1) {
        for (int i = h; i < a.length; i++)
            for (int j = i; j >= h && a[j] < a[j-h]; j -= h)
                exch(a, j, j-h);
        h /= 3;
    }
}
```

## 常见误区

<Callout type="trap">
**误区：认为 O(n^2) 排序没用。**
小数据（n&lt;20）或近乎有序数据，插入排序比快排还快。很多高级排序递归到小数组时切换到插入排序。
</Callout>

<Callout type="trap">
**误区：希尔排序的增量序列随便选。**
增量序列决定性能。原始2-幂序列最坏 O(n^2)，Sedgewick序列可达 O(n^(4/3))。
</Callout>

<Exercises>
**问题 1**：为什么插入排序对近乎有序数据效率高？

<Answer>
比较次数=逆序对数+n。近乎有序数据逆序对很少，接近 O(n)。
</Answer>

**问题 2**：选择排序和插入排序各适合什么场景？

<Answer>
选择排序适合写内存开销大的场景（交换最少）。插入排序适合小数据或近乎有序数据。
</Answer>
</Exercises>
