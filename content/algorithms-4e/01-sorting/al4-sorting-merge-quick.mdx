## 直觉引入

想象整理一万份文件。选择排序是每次找最薄的放前面——太慢。归并排序是先分成两堆分别整理再合并——分而治之。快速排序是随便拿一份当基准，比它薄的放左边厚的放右边再分别整理。两种方法都把 O(n^2) 降到 O(n log n)，但各有优劣。

## 概念讲解

### 归并排序

<Al4SortingMergeQuickDiagram />

<Term def="归并排序用分治策略：递归将数组对半分割，排序后合并，保证 O(n log n) 且稳定">
归并排序
</Term>

归并排序：分成两半→递归排序→合并。合并是线性扫描两个已排序数组取较小值。时间固定 O(n log n)，空间 O(n)。稳定排序。适合需要稳定排序或最坏情况保证的场景。

### 快速排序

快排：选 pivot→partition→递归排序左右两部分。平均 O(n log n)，最坏 O(n^2)（随机化可避免）。原地排序，不稳定。实际中最快（常数小、缓存友好）。

## 代码对照

```java
// 1. 归并排序
void mergeSort(int[] a, int[] aux, int lo, int hi) {
    if (hi <= lo) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, aux, lo, mid);
    mergeSort(a, aux, mid+1, hi);
    merge(a, aux, lo, mid, hi);
}

void merge(int[] a, int[] aux, int lo, int mid, int hi) {
    for (int k = lo; k <= hi; k++) aux[k] = a[k];
    int i = lo, j = mid + 1;
    for (int k = lo; k <= hi; k++) {
        if (i > mid) a[k] = aux[j++];
        else if (j > hi) a[k] = aux[i++];
        else if (aux[j] < aux[i]) a[k] = aux[j++];
        else a[k] = aux[i++];
    }
}

// 2. 快速排序
void quickSort(int[] a, int lo, int hi) {
    if (hi <= lo) return;
    int j = partition(a, lo, hi);
    quickSort(a, lo, j-1);
    quickSort(a, j+1, hi);
}

int partition(int[] a, int lo, int hi) {
    int pivot = a[lo];
    int i = lo, j = hi + 1;
    while (true) {
        while (a[++i] < pivot) if (i == hi) break;
        while (pivot < a[--j]);
        if (i >= j) break;
        exch(a, i, j);
    }
    exch(a, lo, j);
    return j;
}
```

## 常见误区

<Callout type="trap">
**误区：快排最坏 O(n^2) 所以不能用。**
随机化 pivot 使最坏概率极低。实际中快排最快。Java/C++ 标准库都用快排变体。
</Callout>

<Callout type="trap">
**误区：归并排序浪费空间所以不如快排。**
归排的空间 O(n) 是劣势，但稳定性和最坏保证是快排没有的。对象排序必须用归并。
</Callout>

<Exercises>
**问题 1**：归并和快排的分治策略有什么不同？

<Answer>
归并「先分后合」——分简单对半切，合是线性合并。快排「先分后递归」——分是 partition，递归后不需合。
</Answer>

**问题 2**：什么时候用堆排序？

<Answer>
需 O(n log n) 最坏保证且原地排序时。如实时系统。或只需 top-K 时用优先队列。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="归并排序">分治排序：对半分割→递归排序→线性合并。O(n log n) 保证，稳定，空间 O(n)。</GlossaryItem>
<GlossaryItem term="快速排序">分治排序：选pivot→partition→递归。平均 O(n log n)，原地，不稳定。实际最快。</GlossaryItem>
<GlossaryItem term="堆排序">基于二叉堆：建堆→反复取堆顶。O(n log n) 保证，原地。</GlossaryItem>
<GlossaryItem term="partition">快排核心：选 pivot，小于的移左，大于的移右。O(n)。</GlossaryItem>
</Glossary>
