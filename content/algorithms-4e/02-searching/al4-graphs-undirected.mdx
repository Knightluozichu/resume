## 直觉引入

想象你要探索一座迷宫。一种策略是走到死路再回头换方向（DFS），另一种是先探索所有距离入口1步的再探索2步的（BFS）。图就是迷宫的数学抽象——节点是路口，边是通道。DFS 适合找连通性和环，BFS 适合找最短路径。

## 概念讲解

### 图的数据结构

<Al4GraphsUndirectedDiagram />

<Term def="图由顶点集V和边集E组成，邻接表用每个顶点的链表存储邻居，适合稀疏图">
图
</Term>

图有两种表示：邻接表（每个顶点存邻居链表，空间 O(V+E)，适合稀疏图）和邻接矩阵（V*V矩阵，空间 O(V^2)，适合稠密图）。Sedgewick 推荐邻接表，因为大多数实际图是稀疏的。

### DFS 与 BFS

DFS 用递归/栈，深入走到死路再回溯。应用：连通分量、环检测。BFS 用队列，逐层扩展。应用：无权图最短路径。两者都是 O(V+E)。

## 交互Demo

<Stepper>
<Step title="DFS 深度优先">递归遍历：访问→标记→递归访问未标记邻居。应用：连通分量、环检测。O(V+E)。</Step>
<Step title="BFS 广度优先">队列遍历：出队→访问→未访问邻居入队。逐层扩展。应用：最短路径。O(V+E)。</Step>
<Step title="图算法应用">连通分量（DFS计数）、环检测（DFS遇已访问非父节点）、二分图（BFS染色）。</Step>
</Stepper>

## 代码对照

```java
public class Graph {
    private final int V;
    private Bag<Integer>[] adj;

    public void addEdge(int v, int w) {
        adj[v].add(w); adj[w].add(v);  // 无向图双向
    }
}

// DFS
public class DepthFirstSearch {
    private boolean[] marked;
    private void dfs(Graph G, int v) {
        marked[v] = true;
        for (int w : G.adj(v))
            if (!marked[w]) dfs(G, w);
    }
}

// BFS（最短路径）
public class BreadthFirstPaths {
    private boolean[] marked;
    private int[] edgeTo;

    private void bfs(Graph G, int s) {
        Queue<Integer> q = new Queue<>();
        marked[s] = true; q.enqueue(s);
        while (!q.isEmpty()) {
            int v = q.dequeue();
            for (int w : G.adj(v)) {
                if (!marked[w]) {
                    edgeTo[w] = v;
                    marked[w] = true;
                    q.enqueue(w);
                }
            }
        }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：BFS 和 DFS 可以互相替代。**
解决不同问题。BFS 找最短路径，DFS 找连通分量和环更自然。拓扑排序只能用 DFS。
</Callout>

<Callout type="trap">
**误区：邻接矩阵一定比邻接表快。**
矩阵判断边存在 O(1) 但空间 O(V^2)。稀疏图用邻接表省空间且遍历更快。
</Callout>

<Exercises>
**问题 1**：为什么 BFS 能找到无权图最短路径？

<Answer>
BFS 逐层扩展按距离递增访问，第一次到达目标即最短。DFS 可能绕远路。
</Answer>

**问题 2**：如何用 DFS 检测无向图中的环？

<Answer>
遇到已访问的邻居且不是父节点则存在环。
</Answer>
</Exercises>
