## 直觉引入

想象一本字典。如果词条无序排列，找一个词要从头翻到尾（O(n)）。如果按字母排序，可以二分查找（O(log n)）。二叉搜索树就是可动态更新的有序字典——左子树小于根，右子树大于根。但如果不平衡，树可能退化成链表，又回到 O(n)。

## 概念讲解

### 二叉搜索树

<Al4SearchingStDiagram />

<Term def="二叉搜索树（BST）是每个节点左子树值都小于它、右子树值都大于它的二叉树，支持 O(h) 操作">
二叉搜索树
</Term>

BST 核心性质：中序遍历得到有序序列。查找：从根开始比大小走左右。插入：查找位置挂新节点。删除：用后继节点（右子树最小值）替换。操作 O(h)，平衡时 h=log n，退化时 h=n。

### 符号表 API

符号表是键值对抽象：put/get/delete/contains。有序版支持 min/max/floor/ceiling/rank/select。BST 天然支持有序操作（中序遍历）。

## 代码对照

```java
public class BST<Key extends Comparable<Key>, Val> {
    private Node root;
    private class Node {
        Key key; Val val; Node left, right; int size;
    }

    public Val get(Key key) { return get(root, key); }
    private Val get(Node x, Key key) {
        if (x == null) return null;
        int cmp = key.compareTo(x.key);
        if (cmp < 0) return get(x.left, key);
        else if (cmp > 0) return get(x.right, key);
        else return x.val;
    }

    public void put(Key key, Val val) { root = put(root, key, val); }
    private Node put(Node x, Key key, Val val) {
        if (x == null) return new Node(key, val, 1);
        int cmp = key.compareTo(x.key);
        if (cmp < 0) x.left = put(x.left, key, val);
        else if (cmp > 0) x.right = put(x.right, key, val);
        else x.val = val;
        x.size = 1 + size(x.left) + size(x.right);
        return x;
    }

    // 删除双子节点用后继替换
    public void delete(Key key) { root = delete(root, key); }
    private Node delete(Node x, Key key) {
        if (x == null) return null;
        int cmp = key.compareTo(x.key);
        if (cmp < 0) x.left = delete(x.left, key);
        else if (cmp > 0) x.right = delete(x.right, key);
        else {
            if (x.right == null) return x.left;
            if (x.left == null) return x.right;
            Node t = x;
            x = min(t.right);
            x.right = deleteMin(t.right);
            x.left = t.left;
        }
        x.size = 1 + size(x.left) + size(x.right);
        return x;
    }
}
```

## 常见误区

<Callout type="trap">
**误区：BST 的查找是 O(log n)。**
BST 查找是 O(h)。平衡时 h=log n，但顺序插入会退化成链表 h=n。这就是需要平衡树的原因。
</Callout>

<Callout type="trap">
**误区：BST 删除只需删节点。**
双子节点删除需用后继替换，保证 BST 性质不被破坏。最复杂的情况。
</Callout>

<Exercises>
**问题 1**：为什么 BST 按顺序插入会退化为链表？

<Answer>
顺序插入每个新键都大于之前，总是插入右子树最右端，树变成链表。
</Answer>

**问题 2**：BST 中序遍历有什么特殊性质？

<Answer>
中序遍历（左→根→右）得到键的升序序列，使 min/max/floor/rank 等有序操作可高效实现。
</Answer>
</Exercises>
