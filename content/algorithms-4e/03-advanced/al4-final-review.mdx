## 直觉引入

想象你在学武功。基础是内功心法（大O分析、数据结构），排序是招式套路（分治、随机化），查找是兵器选择（树、散列），字符串与图是实战应用（模式匹配、网络分析）。总复习就是把内功、招式、兵器、实战融会贯通，从会一招变成成体系。

## 概念讲解

### 知识体系

知识体系

全书四板块形成分析工具→经典算法→查找结构→高级算法的闭环。核心问题：基础——怎么分析？排序——怎么排序？查找——怎么查找？字符串与图——怎么处理复杂结构？

### 算法选择决策

选择算法的决策框架：1）分析问题类型（查找/排序/搜索/优化）；2）确定数据特征（有序/无序/稠密/稀疏）；3）选择数据结构（数组/树/散列/图）；4）选择算法范式（分治/贪心/动态规划）；5）验证复杂度和正确性。

## 代码对照

```java
// 全书知识综合：一个完整的问题解决流程
// 问题：找出一组数据中最常见的K个元素

// 方案1：排序+计数 O(n log n)
Map<Integer,Integer> count = new HashMap<>();
for (int x : data) count.merge(x, 1, Integer::sum);
List<Integer> sorted = count.entrySet().stream()
    .sorted((a,b) -> b.getValue() - a.getValue())
    .limit(k).map(Map.Entry::getKey).toList();

// 方案2：最小堆 O(n log k)
PriorityQueue<Map.Entry<Integer,Integer>> pq =
    new PriorityQueue<>(Comparator.comparingInt(Map.Entry::getValue));
for (var e : count.entrySet()) {
    pq.offer(e);
    if (pq.size() > k) pq.poll();  // 维持k大小
}

// 方案3：快速选择 O(n) 平均
// 用 partition 思想找第K大的频率

// 决策：
// n小→方案1（简单）
// n大k小→方案2（堆，O(n log k)）
// n极大→方案3（快速选择，O(n)）
// 需要有序输出→方案1（排序）
```

## 常见误区

<Callout type="trap">
**误区：复习时只背复杂度不写代码。**
算法是实践技能。每个算法至少手写一遍实现，理解边界条件。建议：用 Java 重写全书核心算法。
</Callout>

<Callout type="trap">
**误区：认为高级算法一定比基础算法好。**
实际中 O(n^2) 的插入排序在小数据上比 O(n log n) 的快排快。选算法要考虑数据规模、常数因子、缓存友好性，而非只看大O。
</Callout>

<Exercises>
**问题 1**：全书四板块的核心问题分别是什么？如何形成闭环？

<Answer>
基础——怎么分析（大O/数据结构）；排序——怎么排序（分治/随机化）；查找——怎么查找（树/散列）；字符串与图——怎么处理复杂结构（模式匹配/网络）。闭环：分析工具→经典算法→查找结构→高级算法。
</Answer>

**问题 2**：面对一个新问题，如何用全书知识系统分析？

<Answer>
1）定义问题（输入/输出/约束）；2）分析数据特征（有序/稠密/稀疏）；3）选数据结构（数组/树/散列/图）；4）选算法范式（分治/贪心/DP）；5）分析复杂度；6）写代码验证；7）性能实验优化。
</Answer>
