## 直觉引入

想象做饭的流程：洗菜→切菜→炒菜→装盘。有严格的先后顺序（有向边），不能先炒再洗。这就是有向无环图（DAG）——拓扑排序告诉你合理的执行顺序。如果步骤间有循环依赖就死锁了——这就是环检测的价值。

## 概念讲解

### 有向图与拓扑排序

<Al4GraphsDirectedDiagram />

<Term def="有向图的边有方向，拓扑排序将DAG顶点排成线性序使得所有边从前指向后">
拓扑排序
</Term>

有向图边有方向。拓扑排序只对DAG有意义：DFS后序的逆序就是拓扑序。应用：任务调度、编译依赖。如果有环则拓扑排序不可能。

### 强连通分量

强连通分量（SCC）是任意两顶点互相可达的最大子图。Kosaraju算法：1）对G做DFS记后序；2）对反向图G^R按后序逆序DFS，每棵DFS树是一个SCC。O(V+E)。

## 代码对照

```java
class Digraph {
    public void addEdge(int v, int w) { adj[v].add(w); }  // 只加出边
    public Digraph reverse() {  // 反向图
        Digraph r = new Digraph(V);
        for (int v = 0; v < V; v++)
            for (int w : adj(v)) r.addEdge(w, v);
        return r;
    }
}

// 拓扑排序（DFS后序逆序）
class Topological {
    private Iterable<Integer> order;
    public Topological(Digraph G) {
        if (!new DirectedCycle(G).hasCycle())
            order = new DepthFirstOrder(G).reversePost();
    }
}

// Kosaraju强连通分量
class KosarajuSCC {
    private boolean[] marked; private int[] id; private int count;

    public KosarajuSCC(Digraph G) {
        marked = new boolean[G.V()];
        DepthFirstOrder order = new DepthFirstOrder(G.reverse());
        for (int s : order.reversePost())
            if (!marked[s]) { dfs(G, s); count++; }
    }
    private void dfs(Digraph G, int v) {
        marked[v] = true; id[v] = count;
        for (int w : G.adj(v)) if (!marked[w]) dfs(G, w);
    }
}
```

## 常见误区

<Callout type="trap">
**误区：有环图也能拓扑排序。**
拓扑排序只对DAG有意义。有环则不存在满足所有边从前到后的线性序。
</Callout>

<Callout type="trap">
**误区：Kosaraju不如Tarjan因为要遍历两遍。**
两者都是O(V+E)。Kosaraju更直觉，Tarjan一遍DFS但更难理解。性能差异可忽略。
</Callout>

<Exercises>
**问题 1**：拓扑排序和DFS后序有什么关系？

<Answer>
DAG拓扑排序=DFS后序逆序。后序是节点所有后代访问完后输出，逆序后父在子前。
</Answer>

**问题 2**：如何判断有向图是否有环？

<Answer>
DFS遇到递归栈中的节点（正在访问中）说明有环。或Kahn算法最后有顶点剩余则有环。
</Answer>
</Exercises>
