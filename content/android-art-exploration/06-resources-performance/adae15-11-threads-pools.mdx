## 最小可执行切片

在《第11章 Android的线程和线程池》中，下面的Java片段只抓住本章核心合同。先预测线程、状态和失败，再在匹配Android 5.0语境的样例工程中运行；代码所依赖的上下文和导入应在工程中显式声明。

```java
BlockingQueue<Runnable> queue = new ArrayBlockingQueue<>(32);
ThreadPoolExecutor pool = new ThreadPoolExecutor(
    2, 4, 30L, TimeUnit.SECONDS, queue,
    new ThreadPoolExecutor.AbortPolicy());
Future<?> work = pool.submit(new DecodeTask(input));
// Owner cancellation calls work.cancel(true) and later pool.shutdown().
```
