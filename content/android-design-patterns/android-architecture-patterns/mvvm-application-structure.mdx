## 名词解释

<Glossary>
  <GlossaryItem term="MVVM">
    Model-View-ViewModel。View 观察状态，ViewModel
    暴露状态并处理意图，不直接调用 View。
  </GlossaryItem>
  <GlossaryItem term="ViewModel">
    跨配置变化保留界面状态的对象。它应该依赖抽象的数据能力，而不是持有 Fragment
    或 View。
  </GlossaryItem>
  <GlossaryItem term="Observable State">
    可被 UI 观察的一份状态，例如 LiveData 或 StateFlow。UI
    根据它重绘，而不是被逐个命令驱动。
  </GlossaryItem>
  <GlossaryItem term="DataBinding">
    把 View 和可观察状态绑定起来的机制。好处是减少胶水代码，风险是隐藏过多逻辑。
  </GlossaryItem>
  <GlossaryItem term="责任边界">
    代码中可以被讨论、测试、review
    和文档共同保护的分界线。它决定“谁该改、谁不该改”。
  </GlossaryItem>
</Glossary>
