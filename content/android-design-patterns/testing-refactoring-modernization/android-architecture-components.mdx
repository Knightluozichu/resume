## 名词解释

<Glossary>
  <GlossaryItem term="LifecycleOwner">
    能暴露生命周期状态的对象，例如 Activity 或
    Fragment。观察者可以按生命周期自动启停。
  </GlossaryItem>
  <GlossaryItem term="ViewModelStore">
    保存 ViewModel 的容器，使配置变化后新 View 仍能拿回旧状态。
  </GlossaryItem>
  <GlossaryItem term="Observer">
    观察状态变化并触发 UI 更新的订阅者。它应该跟随生命周期注册和解绑。
  </GlossaryItem>
  <GlossaryItem term="SavedState">
    进程被杀后仍需要恢复的轻量状态。它不是缓存所有业务数据的地方。
  </GlossaryItem>
  <GlossaryItem term="责任边界">
    代码中可以被讨论、测试、review
    和文档共同保护的分界线。它决定“谁该改、谁不该改”。
  </GlossaryItem>
</Glossary>
