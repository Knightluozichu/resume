## 章节理解报告

现代汽车不只是机械结构，也是一张电子网络。传感器采集环境和车辆状态，控制器判断要不要提示、制动、转向、点亮、制冷或展开气囊，执行器把电子决策变成真实动作。

小白常见卡点：

- 以为电子系统只是屏幕和音响，看不见 ABS、ESP、AEB、气囊和空调背后的控制链。
- 分不清主动安全和被动安全。
- 把传感器当成“能直接控制汽车”的东西，不知道中间还有控制器判断。

适合做图的是汽车电子系统分层、传感器/控制器/执行器关系、ADAS 感知范围和空调循环；适合做动画的是信号流、AEB/ABS 介入和气囊触发；适合做交互的是点击传感器、切换安全类型和模拟紧急制动。

## 逐项机制说明

### 9.1 灯光照明

近光、远光、位置灯、转向灯和制动灯分别承担照路与通信功能，控制器还可能执行自动调平和自适应配光；亮度提升必须服从眩光与法规边界。

### 9.2 仪表

仪表把车速、能量、故障和驾驶辅助状态转成驾驶者能及时理解的信息；数据来源可能跨多个控制器，显示设计必须区分正常提示、警告和立即处置。

### 9.3 空调

压缩机、冷凝器、膨胀装置和蒸发器搬运热量，风门与鼓风机分配空气；燃油车可利用发动机余热，电动车制热则会直接影响续航。

### 9.4 驾驶辅助系统

摄像头、雷达和超声波等传感器感知环境，控制器估计目标并给出提示或有限控制；系统有天气、遮挡和工作域边界，驾驶者仍需理解接管责任。

### 9.5 主动安全系统

ABS、牵引力控制和车身稳定控制通过轮速、转角与横摆等信号识别失稳趋势，再调节制动或动力；它们利用现有附着，不能创造超出轮胎极限的抓地。

### 9.6 被动安全系统

安全带、气囊、吸能结构和乘员舱在碰撞发生后管理人体减速度与侵入；各装置按碰撞方向和乘员状态协同，单看气囊数量不能代表整体安全。

## 本章复习

### 学习地图回顾

电气电子系统像汽车的神经系统：

- 感知层：摄像头、雷达、轮速、温度、碰撞传感器。
- 控制层：车身控制器、制动控制器、气囊 ECU、空调控制器、域控制器。
- 执行层：灯光、仪表、空调风门、制动执行器、转向执行器、安全气囊。

### 核心概念卡片

- <Term def="把外界或车辆状态转换为电信号的部件">传感器</Term>
  ：负责看见、听见或感知状态。
- <Term def="根据输入信号做判断并输出控制命令的电子单元">控制器</Term>
  ：电子系统的大脑。
- <Term def="根据控制命令执行动作的部件">执行器</Term>
  ：例如电机、阀体、灯光、气囊和制动执行机构。
- <Term def="事故发生前预防风险或主动干预的安全系统">主动安全</Term>：例如
  ABS、ESP、AEB、车道保持。
- <Term def="事故发生时保护乘员的安全系统">被动安全</Term>
  ：例如安全带预紧、气囊和车身吸能结构。
- <Term def="高级驾驶辅助系统，通过感知、判断和执行帮助驾驶者">ADAS</Term>
  ：不是自动驾驶本身，而是辅助驾驶者。

### 系统对比

| 系统     | 输入                     | 判断                 | 输出                 |
| -------- | ------------------------ | -------------------- | -------------------- |
| 灯光照明 | 光照、开关、车速、转角   | 是否需要照明或提示   | 大灯、转向灯、刹车灯 |
| 仪表     | 车速、转速、电量、故障码 | 需要显示什么状态     | 仪表和告警           |
| 空调     | 温度、湿度、阳光、设定值 | 制冷、制热、除雾策略 | 压缩机、风门、鼓风机 |
| ADAS     | 摄像头、雷达、轮速       | 是否有碰撞或偏离风险 | 提示、制动、转向辅助 |
| 气囊     | 碰撞加速度和方向         | 是否达到展开阈值     | 安全带预紧和气囊展开 |

### 易错点对比

| 错误认知                     | 更准确的看法                                     |
| ---------------------------- | ------------------------------------------------ |
| 摄像头看到障碍物就能直接刹车 | 传感器只给信号，控制器判断后才命令执行器         |
| 主动安全和被动安全差不多     | 主动安全在事故前干预，被动安全在事故中保护       |
| ABS 只是刹车更强             | ABS 的核心是防抱死，保留转向能力                 |
| 空调只是压缩机工作           | 空调还涉及传感器、控制器、风门、鼓风机和制冷循环 |

### 拆车观察题

看一辆车的配置表时，试着判断：

1. 它有哪些传感器？摄像头、毫米波雷达、超声波分别在哪里？
2. 哪些配置属于主动安全？哪些属于被动安全？
3. AEB、ACC、LKA 分别可能需要哪些传感器和执行器？
4. 空调自动模式需要哪些输入信号？

## 练习与诊断

<Exercises>

**问题 1**：摄像头被遮挡时驾驶辅助系统应怎样处理？

<Answer>
  识别感知质量下降，限制或退出相关功能并明确提示驾驶者接管，不能继续输出看似正常的控制。
</Answer>

**问题 2**：主动安全系统为什么不能突破轮胎极限？

<Answer>它只能重新分配制动力或动力，所有车辆力仍通过轮胎接触区产生。</Answer>

**问题 3**：被动安全为何必须把安全带、气囊和车身结构一起看？

<Answer>
  三者共同管理乘员运动、约束时序与碰撞减速度，单个装置无法覆盖全部碰撞方向和状态。
</Answer>

## 名词解释

<Glossary>
  <GlossaryItem term="传感器">
    把环境、车辆或乘员状态转换为电信号的部件。
  </GlossaryItem>
  <GlossaryItem term="控制器">
    接收信号、做判断并输出控制命令的电子单元。
  </GlossaryItem>
  <GlossaryItem term="执行器">根据控制命令产生动作的部件。</GlossaryItem>
  <GlossaryItem term="主动安全">
    在事故发生前提示、预警或干预的安全系统。
  </GlossaryItem>
  <GlossaryItem term="被动安全">事故发生时保护乘员的安全系统。</GlossaryItem>
  <GlossaryItem term="ADAS">
    高级驾驶辅助系统，通过感知和控制辅助驾驶者。
  </GlossaryItem>
  <GlossaryItem term="AEB">自动紧急制动，识别碰撞风险后自动制动。</GlossaryItem>
  <GlossaryItem term="ESP">
    车身稳定控制系统，通过制动和动力控制帮助车辆保持稳定。
  </GlossaryItem>
</Glossary>
