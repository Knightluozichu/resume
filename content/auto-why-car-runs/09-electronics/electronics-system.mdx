## 为什么只记结论不足以掌握第 9 章：电气电子

学习“第 9 章：电气电子”时，第一步不是记住结论，而是冻结输入、上下文、版本和成功标准。只有这些条件明确，第9章 电气电子的含义才不会随着样例变化。正文已有的概念说明要与结构图、运行轨迹和失败样本互相印证，不能只凭最终输出看似正确就宣布完成。

机制验证要把9.2 仪表写成可以执行的条件。正常样本证明主路径，恰好边界样本验证等号和空值，单故障样本只破坏一个假设。三类样本使用同一份观察指标，避免因为测试口径变化而把偶然结果误认成规律。

成本分析同时记录时间、空间、延迟、耦合、可维护性和不可逆操作。9.3 空调不是一句“可能失败”，而是可复现输入、预期停点、实际轨迹、错误分类与清理步骤。任何自动重试都要有次数、预算和幂等边界。

方案比较不能只列优点。需要给出直接实现、当前方案和至少一个替代方案，逐项比较复杂度、扩展点、故障隔离和团队认知成本。当问题规模很小或变化轴稳定时，更简单的实现往往更好；模式与框架必须由真实变化压力证明。

实现阶段把大结论拆成可检查的中间产物：配置快照、结构清单、状态转移、输入输出样本、日志摘要和测试结果。每个产物带来源与生成命令，下一阶段只消费已通过门禁的版本，避免旧缓存或隐式默认值污染结论。

解释结果时必须区分相关性与因果性、接口承诺与实现细节、设计意图与运行事实。对“9.4 驾驶辅助系统”的判断要由独立证据支持，并明确适用范围；一旦输入分布、版本、硬件或组织边界改变，就重新运行最小实验。

## 章节理解报告

现代汽车不只是机械结构，也是一张电子网络。传感器采集环境和车辆状态，控制器判断要不要提示、制动、转向、点亮、制冷或展开气囊，执行器把电子决策变成真实动作。

小白常见卡点：

- 以为电子系统只是屏幕和音响，看不见 ABS、ESP、AEB、气囊和空调背后的控制链。
- 分不清主动安全和被动安全。
- 把传感器当成“能直接控制汽车”的东西，不知道中间还有控制器判断。

适合做图的是汽车电子系统分层、传感器/控制器/执行器关系、ADAS 感知范围和空调循环；适合做动画的是信号流、AEB/ABS 介入和气囊触发；适合做交互的是点击传感器、切换安全类型和模拟紧急制动。

## 本章复习

### 学习地图回顾

电气电子系统像汽车的神经系统：

- 感知层：摄像头、雷达、轮速、温度、碰撞传感器。
- 控制层：车身控制器、制动控制器、气囊 ECU、空调控制器、域控制器。
- 执行层：灯光、仪表、空调风门、制动执行器、转向执行器、安全气囊。

### 核心概念卡片

- <Term def="把外界或车辆状态转换为电信号的部件">传感器</Term>
  ：负责看见、听见或感知状态。
- <Term def="根据输入信号做判断并输出控制命令的电子单元">控制器</Term>
  ：电子系统的大脑。
- <Term def="根据控制命令执行动作的部件">执行器</Term>
  ：例如电机、阀体、灯光、气囊和制动执行机构。
- <Term def="事故发生前预防风险或主动干预的安全系统">主动安全</Term>：例如
  ABS、ESP、AEB、车道保持。
- <Term def="事故发生时保护乘员的安全系统">被动安全</Term>
  ：例如安全带预紧、气囊和车身吸能结构。
- <Term def="高级驾驶辅助系统，通过感知、判断和执行帮助驾驶者">ADAS</Term>
  ：不是自动驾驶本身，而是辅助驾驶者。

### 系统对比

| 系统     | 输入                     | 判断                 | 输出                 |
| -------- | ------------------------ | -------------------- | -------------------- |
| 灯光照明 | 光照、开关、车速、转角   | 是否需要照明或提示   | 大灯、转向灯、刹车灯 |
| 仪表     | 车速、转速、电量、故障码 | 需要显示什么状态     | 仪表和告警           |
| 空调     | 温度、湿度、阳光、设定值 | 制冷、制热、除雾策略 | 压缩机、风门、鼓风机 |
| ADAS     | 摄像头、雷达、轮速       | 是否有碰撞或偏离风险 | 提示、制动、转向辅助 |
| 气囊     | 碰撞加速度和方向         | 是否达到展开阈值     | 安全带预紧和气囊展开 |

### 易错点对比

| 错误认知                     | 更准确的看法                                     |
| ---------------------------- | ------------------------------------------------ |
| 摄像头看到障碍物就能直接刹车 | 传感器只给信号，控制器判断后才命令执行器         |
| 主动安全和被动安全差不多     | 主动安全在事故前干预，被动安全在事故中保护       |
| ABS 只是刹车更强             | ABS 的核心是防抱死，保留转向能力                 |
| 空调只是压缩机工作           | 空调还涉及传感器、控制器、风门、鼓风机和制冷循环 |
