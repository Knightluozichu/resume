## 章节理解报告

汽车不是先有零件再拼出产品，而是先有用户需求、法规边界、成本目标和性能目标。工程团队把这些目标变成尺寸、结构、动力、安全、能耗、NVH、制造和质量指标，再通过样车和测试不断修正。等设计冻结后，产线用冲压、焊装、涂装、总装把设计变成可重复制造的商品车。

小白常见卡点：

- 以为汽车设计只是外观造型，看不到工程目标、法规、安全和成本约束。
- 以为样车测试只是演示，不理解它是发现问题和修正设计的核心环节。
- 以为风阻只是赛车才关心，不知道高速能耗、续航和稳定性都受它影响。
- 把冲压、焊装、涂装、总装混在一起，不知道白车身从哪里来。

适合做图的是整车开发流程、风洞气流、四大工艺产线；适合做动画的是阶段推进和产线节拍；适合做交互的是车身形状、缺陷率、测试强度和质量通过率反馈。

## 逐项机制说明

### 12.1 设计流程

整车设计从用户与法规目标出发，逐级分解到总布置、系统和零部件，并通过仿真、样件和评审闭环；后期修改成本高，因此接口和验证条件要尽早冻结。

### 12.2 样车测试

样车测试覆盖耐久、碰撞、操稳、制动、环境、电磁兼容和软件功能等场景；单次成功不能代表量产可靠，需要边界、故障和重复样本共同验证。

### 12.3 空气动力学设计

车头、底盘、车顶和车尾共同决定气流分离、阻力、升力与冷却流量；降低阻力有利于高速能耗，但也要兼顾稳定、散热、空间和造型。

### 12.4 制造流程

冲压形成覆盖件与结构件，焊装构成白车身，涂装负责防腐与外观，总装连接动力、底盘和内饰；尺寸、扭矩、密封与软件配置都要在线检测。

## 本章复习

### 学习地图回顾

前面章节拆了发动机、传动、悬架、转向、制动、电子、轮胎和电驱。设计制造章把这些系统重新合起来：

- 设计目标决定整车定位和取舍。
- 样车测试验证各系统能不能协同。
- 风阻设计影响高速能耗、续航、噪声和稳定。
- 产线工艺决定同一设计能不能稳定复制。
- 质检和路试决定车辆能不能交付给用户。

### 核心概念卡片

- <Term def="把用户、法规、成本和性能要求整理成工程目标">目标定义</Term>
  ：决定整车开发方向。
- <Term def="用于验证设计、制造和测试问题的试制车辆">样车</Term>
  ：不是展示品，而是问题发现工具。
- <Term def="空气阻力系数，常用 Cd 表示">风阻系数</Term>
  ：影响高速能耗、续航和噪声。
- <Term def="把板材压成车身零件的工艺">冲压</Term>
  ：形成车门、翼子板、地板等钣金件。
- <Term def="把钣金件连接成车身骨架的工艺">焊装</Term>：形成白车身。
- <Term def="给车身提供防腐、颜色和外观涂层的工艺">涂装</Term>
  ：决定车漆耐久和观感。
- <Term def="把动力、底盘、内饰、电器等装到车身上的工艺">总装</Term>
  ：完成整车集成。
- <Term def="车辆下线前的尺寸、功能、安全和路试检查">质检</Term>
  ：控制批量交付风险。

### 开发流程

| 阶段     | 关键问题                                   | 输出               |
| -------- | ------------------------------------------ | ------------------ |
| 目标定义 | 这辆车服务谁，卖多少钱，必须满足什么法规？ | 产品需求和工程指标 |
| 方案设计 | 车身、底盘、动力、电气如何布置？           | 结构和系统方案     |
| 样车验证 | 方案在真实工况下有什么问题？               | 测试数据和问题清单 |
| 设计冻结 | 哪些方案可以进入量产准备？                 | 量产设计数据       |
| 产线制造 | 如何稳定、快速、一致地复制？               | 批量车辆           |
| 质量放行 | 是否满足交付标准？                         | 合格车辆           |

### 四大工艺对比

| 工艺 | 输入             | 输出     | 常见检查         |
| ---- | ---------------- | -------- | ---------------- |
| 冲压 | 钢板 / 铝板      | 钣金零件 | 尺寸、开裂、回弹 |
| 焊装 | 钣金零件         | 白车身   | 焊点、间隙、强度 |
| 涂装 | 白车身           | 涂装车身 | 色差、橘皮、防腐 |
| 总装 | 涂装车身和各系统 | 完整车辆 | 扭矩、功能、软件 |

### 易错点对比

| 错误认知           | 更准确的看法                                             |
| ------------------ | -------------------------------------------------------- |
| 汽车设计就是画外观 | 造型只是其中一部分，工程指标和制造约束同样重要           |
| 样车越接近量产越好 | 不同阶段样车目标不同，有的用于验证结构，有的用于验证制造 |
| 风阻只影响极速     | 风阻会影响高速电耗、油耗、续航、风噪和稳定               |
| 产线越快越好       | 节拍必须和质量控制匹配，过快会放大缺陷                   |
| 质检只是最后看一眼 | 质量控制贯穿设计、供应链、制造和下线                     |

### 观察题

参观展厅或看一辆新车发布时，试着判断：

1. 它的目标用户是谁？
2. 它的车身形状是否明显在追求低风阻？
3. 它宣传的测试项目对应哪些真实风险？
4. 它的制造亮点是在材料、工艺、自动化，还是质量检测？
5. 如果一辆车缝隙不均、异响多，可能分别来自哪些阶段？

## 小结

- 设计从概念到工程图
- 仿真验证减少实物试错
- 四大工艺造出整车
- 平台化共享降低开发成本
- 质量在制造中被保证

## 练习与诊断

<Exercises>

**问题 1**：为什么总布置问题越晚修改成本越高？

<Answer>
  空间和接口已经影响结构、系统、模具与验证，后期改动会跨多个团队产生连锁返工。
</Answer>

**问题 2**：样车一次道路测试通过为什么不能代表量产可靠？

<Answer>
  可靠性需要覆盖温度、载荷、寿命、故障与重复样本，单次正常路线没有触及多数边界。
</Answer>

**问题 3**：空气阻力降低是否可以牺牲所有冷却进风？

<Answer>
  不可以；动力和制动系统仍需散热，设计要在阻力、升力、冷却、空间和造型间平衡。
</Answer>

</Exercises>

## 名词解释

<Glossary>
  <GlossaryItem term="白车身">
    完成焊装但尚未涂装和总装的车身结构。
  </GlossaryItem>
  <GlossaryItem term="冲压">把板材压制成车身零件的制造工艺。</GlossaryItem>
  <GlossaryItem term="焊装">把钣金件定位并连接成白车身的工艺。</GlossaryItem>
  <GlossaryItem term="涂装">
    给车身提供防腐、颜色和外观涂层的工艺。
  </GlossaryItem>
  <GlossaryItem term="总装">
    把动力、底盘、内饰、电器等装配成完整车辆的工艺。
  </GlossaryItem>
  <GlossaryItem term="风阻系数">
    描述车身空气阻力水平的系数，常用 Cd 表示。
  </GlossaryItem>
  <GlossaryItem term="样车">
    用于验证设计、测试和制造方案的试制车辆。
  </GlossaryItem>
  <GlossaryItem term="产线节拍">
    生产线上完成一辆车或一道工序的节奏。
  </GlossaryItem>
