## 游戏世界满是对象

游戏里每个敌人有血量和 AI、每颗子弹有位置和速度、每个 UI 按钮有外观和点击响应。这些「有状态、有行为」的实体恰好对应 C++ 的类——数据（成员变量）+ 行为（成员函数）。面向对象是游戏开发的天然范式。

## 类的定义

```cpp
class Player {
private:
  int m_Hp;          // 成员变量：状态
  Vector2f m_Pos;
public:
  Player();          // 构造函数
  ~Player();         // 析构函数
  void move(float dx, float dy);  // 成员函数：行为
  int getHp() const;
};
```

类是蓝图，对象是按蓝图创建的实例。`Player p1, p2;` 创建两个独立对象，各有自己的 m_Hp 和 m_Pos。

## 访问控制

- `public`：类内、类外、子类都能访问——对外接口。
- `private`：只有类内（含友元）能访问——隐藏实现，外部不可见。
- `protected`：类内和子类能访问，类外不可——给继承体系用。

原则：成员变量尽量 private，只通过 public 方法访问。这就是封装。

## 封装的价值

把数据藏进 private、只暴露 public 方法，好处是受控访问 + 不变量维护：

```cpp
void Player::takeDamage(int d) {
  if (d < 0) return;       // 拒绝负伤害
  m_Hp -= d;
  if (m_Hp < 0) m_Hp = 0;  // 血量永不小于 0
}
```

若 m_Hp 是 public，外部可写 `p.m_Hp = -999` 制造非法状态。封装后只能走 takeDamage，「血量永远非负」这个不变量被锁在类里。

<Callout type="tip">
封装的核心收益不是「藏起来」，而是把对象的合法状态约束锁在类内部。改内部存储（如 m_Hp 从 int 换 float）只要方法签名不变，外部代码不用改。
</Callout>

## 构造与析构

构造函数在**对象创建时**调用，负责初始化成员、申请资源；析构函数在**对象销毁时**调用（离开作用域或 delete），负责清理。对象生命周期：构造 → 使用 → 析构。

析构常声明为虚函数（`virtual ~Entity()`），是为了**通过基类指针删除派生类对象时能正确调派生类析构**。否则 `delete basePtr` 只调基类析构，派生部分资源泄漏。

```cpp
Entity* e = new Player();
delete e;  // 若 Entity 析构非虚，只清理 Entity 部分，Player 资源泄漏
```

<Callout type="trap">
只要类可能被继承且通过基类指针管理（游戏里 `vector<Entity*>` 几乎必然如此），析构就应虚化。这是防内存泄漏的硬规则，忘虚析构是 C++ 新手最经典的资源泄漏坑。
</Callout>

## 继承与多态

继承让子类复用基类成员并扩展。多态让通过基类指针调用虚函数时执行子类版本：

```cpp
class Entity {
public:
  virtual ~Entity();
  virtual void update(float dt) = 0;  // 纯虚：强制子类实现
};
class Player : public Entity {
public:
  void update(float dt) override { /* 玩家专属更新 */ }
};
```

`vector<Entity*>` 可统一管理 Player、Enemy 等不同实体，各自调对 update——这就是多态的威力。子类重写时加 `override` 关键字，编译器帮你检查签名是否真覆盖，防笔误。

## 小结

- 类 = 数据（成员变量）+ 行为（成员函数），对象是实例
- public/private/protected 控制可见性，封装把不变量锁进类
- 构造初始化、析构清理，析构该虚就虚
- 继承复用 + 多态统一管理，override 防笔误

<Glossary>
<GlossaryItem term="类">
C++ 中定义对象结构与行为的蓝图，包含成员变量（数据）和成员函数（行为），是面向对象编程的基本单位。
</GlossaryItem>
<GlossaryItem term="封装">
把成员变量设为 private、只通过 public 方法访问的机制，核心收益是受控访问与不变量维护，保证对象始终处于合法状态。
</GlossaryItem>
<GlossaryItem term="构造函数">
对象创建时自动调用的特殊成员函数，负责初始化成员变量和申请资源。
</GlossaryItem>
<GlossaryItem term="虚析构">
声明为 virtual 的析构函数，保证通过基类指针删除派生类对象时能正确调用派生类析构，防止资源泄漏。
</GlossaryItem>
<GlossaryItem term="多态">
通过基类指针/引用调用虚函数时执行实际派生类版本的机制，配合继承实现「统一管理不同实体」。
</GlossaryItem>
</Glossary>
