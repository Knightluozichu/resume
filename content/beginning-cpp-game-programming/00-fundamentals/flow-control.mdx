## 顺序是底盘，控制是方向盘

程序默认从上到下顺序执行，但游戏需要判断和重复：血量归零要结束游戏、玩家没退出就反复刷新画面、有十个敌人要逐个更新。这些靠流程控制结构实现。

## 分支：if/else 与 switch

`if/else` 适合范围判断和复杂条件：

```cpp
if (hp <= 0) {
  state = GAME_OVER;
} else if (hp < 20) {
  showWarning();  // 低血量警告
}
```

`switch` 适合对一个整型/字符的多个离散等值分发。游戏菜单是典型场景：

```cpp
switch (choice) {
  case '1': startGame(); break;
  case '2': openSettings(); break;
  case '3': quit(); break;
  default:  cout << "无效选项";
}
```

<Callout type="tip">
菜单选项用 switch 比一长串 `if (choice=='1')...` 更清晰，新增选项只需加一个 case。但 switch 只能判等值、case 必须常量，判断区间或浮点仍需 if。
</Callout>

## 循环：while 与 for

`while` 适合**次数不确定、靠状态退出**的循环。游戏主循环就是它：

```cpp
while (window.isOpen()) {
  processInput();
  update();
  render();
}
```

循环次数事先未知，由玩家是否关窗口决定，没有自然的计数器。

`for` 适合**已知次数**的计数循环。遍历敌人列表是典型：

```cpp
for (int i = 0; i < enemies.size(); ++i) {
  enemies[i].update(dt);
}
```

次数已知（= 列表长度），有明确的计数变量，用 for 意图更清晰。C++11 起的范围 for 更简洁：`for (auto& e : enemies) e.update(dt);`

一句话：次数已知用 for，状态驱动用 while。

## 跳转：break 与 continue

`break` 立即跳出整个循环；`continue` 跳过本次剩余、直接进下次循环判断。

```cpp
for (auto* e : enemies) {
  if (!e->isAlive()) continue;     // 死的跳过
  if (e->isInvincible()) continue; // 无敌的跳过
  player.attack(e);
  break;                            // 找到第一个能打的就停
}
```

`continue` 用来过滤不符合条件的，避免深层嵌套 if；`break` 用来「找到即停」避免无谓遍历。

<Callout type="trap">
switch 里的 break 是「结束 case」不是跳出外层循环，新手常混淆。另外嵌套循环里 break 只破一层，要一次跳出多层得用标志位或提取成函数后 return。
</Callout>

## 在游戏中的应用

- **菜单选择**：switch 按选项分发
- **游戏主循环**：while 玩家未退出
- **遍历实体**：for 逐个更新/绘制
- **状态判断**：if 血量归零、if 碰撞发生
- **早退优化**：break 找到目标即停、continue 跳过无效项

这些结构能互相嵌套：循环里套分支，分支里套循环，组合出复杂游戏逻辑。

## 小结

- if/else 做范围与复杂条件，switch 做离散等值分发
- while 状态驱动循环（主循环），for 计数循环（遍历）
- break 跳出循环，continue 跳过本次
- 游戏逻辑由分支与循环嵌套组合而成

<GlossaryItem term="分支结构">

<GlossaryItem term="循环结构">

</GlossaryItem>
<GlossaryItem term="break">
立即跳出当前循环或 switch case 的跳转语句，常用于「找到即停」的早退优化。
</GlossaryItem>
<GlossaryItem term="continue">
跳过循环体剩余语句、直接进入下一次条件判断的跳转语句，常用于过滤不符合条件的元素。
</GlossaryItem>
