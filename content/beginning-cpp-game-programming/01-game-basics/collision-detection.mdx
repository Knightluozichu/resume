## 让物体能相互作用

画面能动起来了，但子弹打中敌人要扣血、玩家撞墙要停下——这些需要碰撞检测。碰撞检测回答一个问题：两个物体此刻是否接触/重叠？答案驱动游戏响应。

## AABB 包围盒

AABB（Axis-Aligned Bounding Box，轴对齐包围盒）用不旋转的矩形包围物体，判两矩形是否重叠。重叠条件：

```cpp
A.left < B.right && A.right > B.left
  && A.top < B.bottom && A.bottom > B.top
```

SFML 用 `sprite.getGlobalBounds()` 取 `FloatRect`，两个 rect 调 `intersects()` 即可判断。AABB 最快，但物体非矩形或旋转时会有「视觉没碰但盒子碰了」的误差。

## 圆形碰撞

每个物体用一个圆（圆心 + 半径）包围。两圆碰撞当且仅当**圆心距离 < 半径之和**：

```cpp
float dx = a.x - b.x, dy = a.y - b.y;
float r = a.radius + b.radius;
bool hit = (dx*dx + dy*dy) < r*r;  // 比平方避免开方
```

相比 AABB，圆形更适合球类、圆形物体，且物体旋转时圆不变、判断稳定。缺点是长条形物体（剑、墙）用圆包围误差大。

## 像素级碰撞

取两精灵在重叠区域内的像素，逐个检查是否**双方都非透明**（alpha > 0）。若有任一像素双方都不透明，则真碰撞。这忽略透明边角，最精确。

<Callout type="trap">
像素级碰撞极慢——每个候选对要在重叠区逐像素比对，物体多时开销爆炸。绝不能对所有物体都用它。正确做法是先粗筛（AABB/圆形）淘汰绝大多数，只对少数候选做像素精判。
</Callout>

## 两阶段策略

实战标准做法：粗筛定候选、精判定真碰。

1. **粗筛**：用 AABB/圆形快速淘汰不相交的对，只留包围盒重叠的少数候选。
2. **精判**：仅对候选对做像素级检测（必要时）。

1000 个物体里可能只有 5 对进入像素检测，性能可接受。子弹、方块敌人用 AABB 已足够，不必像素；只有不规则角色需要精确时才上像素级。

## 选型决策

- **AABB**：方块状物体、最快，首选粗筛。
- **圆形**：球/圆形物体、会旋转的物体。
- **像素**：不规则精灵、需最精确，只用于精判少数候选。

<Callout type="tip">
碰撞检测的工程智慧不是「选最精确的」，而是「在正确的地方用刚好够用的」。粗筛用快的，精判才用精确的，二者配合兼顾速度与精度。
</Callout>

## 小结

- AABB 最快但最粗，适合方块物体和粗筛
- 圆形碰撞适合球类和旋转物体
- 像素级最精确但最慢，只对少数候选精判
- 两阶段：粗筛定候选、精判定真碰
