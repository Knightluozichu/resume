## 直觉引入

Blender 的界面像一张可拼装的工作台：每个面板都是一块积木，可以拖动、分割、合并。你不需要记住菜单藏在哪——所有工具都在眼前的面板里，按 Tab、按 Z、按数字键就能切换。

这个设计的核心思想是「非重叠窗口」：不像 Photoshop 那样窗口叠窗口，Blender 的每个编辑器占满自己的区域，绝不互相遮挡。一开始可能觉得空间不够用，但熟悉后你会发现操作效率远超传统菜单式软件。

## 概念讲解

Blender 界面由多个<Term def="Blender 界面的基本组成单元，每个面板是一个编辑器">编辑器</Term>拼装而成。最常用的五个：3D 视口（建模）、属性面板（调参数）、大纲（管理对象层级）、时间线（动画）、着色器编辑器（连材质节点）。

<Term def="预设的界面布局，针对不同任务优化">工作区</Term>是 Blender 预设的界面模板，顶部 Tab 切换：Layout、Modeling、Sculpting、Shading、Animation、Rendering。

<Term def="通过鼠标和快捷键改变视角的操作">导航</Term>三件套：中键旋转视角、Shift+中键平移、滚轮缩放。数字键 1/3/7 切换正/侧/顶视图，数字键 5 切换正交/透视。

<Term def="按 Z 键弹出的饼菜单，快速切换着色模式">着色模式</Term>：线框、实体、材质预览、渲染。用 Z 键切换比点按钮快十倍。

## 代码对照

```python
# Blender Python：自定义工作区布局
import bpy

bpy.context.window.workspace = bpy.data.workspaces['Modeling']

for area in bpy.context.screen.areas:
    if area.type == 'VIEW_3D':
        for space in area.spaces:
            if space.type == 'VIEW_3D':
                space.shading.type = 'WIREFRAME'
        space.region_3d.view_distance = 5.0
        print(f'视口已配置: {space.shading.type}')

bpy.ops.view3d.view_camera()
```

## 常见误区

<Callout type="trap">
**现象 →** 找不到属性面板里的某个设置，在菜单里翻了好久。
**原因 →** Blender 的属性面板用 Tab 分页，新手容易找错 Tab。
**修法 →** 记住属性面板的 Tab 顺序：从左到右是渲染→输出→场景→世界→物体→约束→修改器→材质→数据。
</Callout>
<Callout type="trap">
**现象 →** 视口突然变成一个奇怪的角度，怎么也转不回来。
**原因 →** 误触了视角快捷键或进入了局部视图（数字键 /）。
**修法 →** 按 Home 键归位全部物体，或按数字键 .（小键盘）聚焦选中物体。如果进入了局部视图，再按 / 退出。
</Callout>

## 练习

<Exercises>
**问题**：Blender 的非重叠窗口设计有什么优势？它和传统菜单式软件的核心区别是什么？

<Answer>
非重叠窗口让每个编辑器占满自己的区域，互不遮挡，所有工具一目了然，减少点击层级。传统菜单式软件需要翻菜单找工具，而 Blender 的工具直接在面板里，操作路径更短。
</Answer>

**问题**：如何用快捷键快速切换到正视图、侧视图和顶视图？如何切换正交/透视？

<Answer>
数字键 1 切正视图、3 切侧视图、7 切顶视图。数字键 5 切换正交/透视模式。注意要用键盘顶排数字键，不是小键盘。
</Answer>
</Exercises>
