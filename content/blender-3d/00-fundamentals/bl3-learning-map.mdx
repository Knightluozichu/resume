## 直觉引入

Blender 是一个免费的 3D 创作套件，从建模到渲染到导出全部在一个软件里完成。想象一个工厂：原料进来（参考图），经过加工（建模、雕刻、展 UV、画材质），组装（绑骨、动画），最后质检出厂（渲染、导出到引擎）。Blender 就是这座全功能工厂。

这本书把 Blender 的核心能力拆成十章，按「认识工具 → 做出模型 → 赋予质感 → 让它动起来 → 交给引擎」的顺序推进。每一章都建立在前一章的产出之上，没有跳跃。

## 概念讲解

全书分四个阶段：**基础**（界面与导航）、**核心**（建模、材质、灯光、动画）、**进阶**（雕刻、渲染、游戏导出）、**复习**。

<Term def="Blender 中组织数据的基本容器">场景</Term>是所有 3D 数据的根容器。<Term def="把 3D 模型转换为引擎可用的格式">导出</Term>是 Blender 与游戏引擎之间的桥梁。<Term def="用数学曲线控制顶点位置的非破坏性修改器">修改器</Term>是 Blender 工作流的核心思想。<Term def="Cycles 追求真实，Eevee 追求实时">渲染引擎</Term>决定了最终画面的质量与速度。

### 阶段依赖
- 基础 → 核心：先熟悉界面和导航，才能高效建模。
- 核心 → 进阶：有了模型和材质，才能雕刻细节、渲染出图、导出到引擎。
- 进阶 → 复习：把所有技能串起来做综合练习。

## 代码对照

```python
# Blender Python API：批量导出选中对象为 FBX
import bpy

bpy.ops.object.select_all(action='DESELECT')
for obj in bpy.data.objects:
    if obj.type == 'MESH':
        obj.select_set(True)

bpy.ops.export_scene.fbx(
    filepath='//exported_model.fbx',
    use_selection=True,
    apply_scale_options='FBX_SCALE_ALL',
    mesh_smooth_type='FACE',
    use_mesh_modifiers=True,
)
print(f'导出完成: {len(bpy.context.selected_objects)} 个对象')
```

## 常见误区

<Callout type="trap">
**现象 →** 打开 Blender 就被密密麻麻的按钮吓退，不知道从哪开始。
**原因 →** Blender 默认显示所有编辑器面板，对新手信息过载。
**修法 →** 先只关注 3D 视口和属性面板，用快捷键 T 和 N 切换侧栏。
</Callout>
<Callout type="trap">
**现象 →** 做完模型后发现面数太高，游戏引擎跑不动。
**原因 →** 没有在建模阶段考虑游戏引擎的性能预算，也没有使用 LOD 或减面修改器。
**修法 →** 在项目初期确定面数预算，用 Decimate 修改器做减面，或高模烘焙法线贴图给低模。
</Callout>

## 练习

<Exercises>
**问题**：Blender 的四大学习阶段是什么？如果跳过建模直接学渲染会有什么问题？

<Answer>
四大阶段：基础（界面）→ 核心（建模、材质、灯光、动画）→ 进阶（雕刻、渲染、导出）→ 复习。跳过建模直接学渲染会缺少可渲染的内容——没有模型就没有材质和灯光的载体。
</Answer>

**问题**：为什么说 Blender 适合独立游戏开发者？

<Answer>
Blender 免费开源，跨平台，功能覆盖建模、雕刻、材质、动画、渲染和导出全流程，独立开发者无需购买多个软件就能完成全部美术工作。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="场景">Blender 中组织所有 3D 数据的基本容器，一个 .blend 文件可包含多个场景。</GlossaryItem>
<GlossaryItem term="导出">把 Blender 中的模型转换为 FBX、OBJ 或 glTF 等格式，供游戏引擎导入使用。</GlossaryItem>
<GlossaryItem term="修改器">非破坏性地修改网格的工具，如镜像、阵列、减面，可随时调整参数或移除。</GlossaryItem>
<GlossaryItem term="渲染引擎">Blender 内置两种：Cycles（光线追踪，慢但真实）和 Eevee（实时，快但近似）。</GlossaryItem>
</Glossary>
