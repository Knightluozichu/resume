## 直觉引入

动画的本质是「变化」。物体从一个位置移动到另一个位置，中间的每一帧由 Blender 自动插值计算。你只需要设定起点和终点的关键帧，软件帮你画中间的过渡——这就是关键帧动画。

但动画好不好看，不在于帧数多不多，而在于节奏对不对。一个角色挥拳，如果匀速运动就很机械；如果先慢后快再急停，就有力量感。控制节奏的工具叫曲线编辑器，它让动画从「能动」变成「有感觉」。

## 概念讲解

Blender 动画的核心是<Term def="记录物体在某一帧的属性值，作为动画的起止点">关键帧</Term>。选中物体，把时间线移到某一帧，按 I 键插入关键帧。两个关键帧之间 Blender 自动插值。

<Term def="管理关键帧时间轴的面板">时间线</Term>是基础操作面板。<Term def="用曲线可视化编辑关键帧插值方式的面板">曲线编辑器</Term>控制动画节奏：贝塞尔曲线的形状决定运动是匀速、加速还是弹跳。

<Term def="用骨骼控制模型变形的绑定系统">骨骼绑定</Term>分两步：先搭骨架（Armature），再绑皮肤（Weight Paint）。

### 动画节奏原则
- **缓入缓出**：运动开始和结束慢，中间快
- **预备动作**：挥拳前先收回，蓄力增加期待感
- **余动**：主体停止后，附属物继续摆动

## 代码对照

```python
# Blender Python：程序化关键帧动画
import bpy

obj = bpy.context.active_object
obj.location = (0, 0, 0)

bpy.context.scene.frame_set(1)
obj.keyframe_insert(data_path='location', frame=1)

obj.location = (0, 0, 3)
obj.keyframe_insert(data_path='location', frame=15)

obj.location = (0, 0, 0)
obj.keyframe_insert(data_path='location', frame=30)

curve = obj.animation_data.action.fcurves[2]
for kf in curve.keyframe_points:
    kf.interpolation = 'BEZIER'
    kf.easing = 'EASE_OUT'
print('弹跳动画设置完成')
```

## 常见误区

<Callout type="trap">
**现象 →** 动画看起来很机械，像机器人运动。
**原因 →** 关键帧之间用了线性插值（Linear），速度恒定无加减速。
**修法 →** 在曲线编辑器里把插值改成 Bezier，调贝塞尔手柄让运动先慢后快再慢。自然界的运动几乎不会匀速。
</Callout>
<Callout type="trap">
**现象 →** 骨骼绑定的模型变形时出现拉伸或穿模。
**原因 →** 权重绘制不正确——某些顶点被不该影响的骨头拉扯了。
**修法 →** 进入 Weight Paint 模式，检查每根骨头的权重范围。用 Subtract 笔刷减掉多余的权重。
</Callout>

## 练习

<Exercises>
**问题**：为什么动画的节奏比帧数更重要？匀速运动为什么看起来不自然？

<Answer>
节奏决定动画的「感觉」。真实世界几乎没有匀速运动——物体受力加速、摩擦减速、碰撞急停。匀速线性插值缺乏物理感。用缓入缓出让运动有加速度变化，观众才会觉得自然。
</Answer>

**问题**：骨骼绑定中权重绘制的作用是什么？如果权重不正确会怎样？

<Answer>
权重绘制决定每根骨骼影响哪些顶点以及影响强度。权重不正确会导致不该动的部位跟着动、关节处拉伸撕裂、或穿模。
</Answer>
</Exercises>

<GlossaryItem term="缓入缓出">动画运动开始和结束时慢、中间快的插值方式，符合物理直觉，是自然动画的基本原则。</GlossaryItem>
</Glossary>
