## 直觉引入

灯光是渲染的灵魂。同一个模型，在柔和的晨光下显得温暖，在强烈的顶光下显得冷酷，在霓虹灯下显得赛博朋克。灯光不是照亮物体那么简单——它决定画面的情绪。

Blender 提供四种灯光：点光（像灯泡）、聚光（像手电筒）、面光（像柔光箱）、太阳光（像日光）。加上世界环境的 HDRI 贴图提供全局环境光，就能搭出任意氛围的布光方案。

## 概念讲解

<Term def="从一个点向四面八方发光的光源，类似灯泡">点光</Term>衰减明显，适合局部照明。<Term def="从一个点向锥形范围发光的光源，类似手电筒">聚光</Term>有明确方向和范围，适合做射灯。<Term def="从一个矩形面向外发光的光源，类似柔光箱">面光</Term>产生柔和阴影，是产品渲染的主力。<Term def="模拟太阳的平行光，没有距离衰减">太阳光</Term>方向固定，适合户外场景。

### 三点布光法
1. **主光**（Key Light）：最强光源，决定亮面和阴影方向，通常放在物体侧前方 45 度。
2. **辅光**（Fill Light）：较弱，填充阴影面，降低明暗反差。
3. **轮廓光**（Rim Light）：从背后打过来，勾勒物体边缘，分离物体与背景。

<Term def="高动态范围环境贴图，存储全场景光照信息">HDRI</Term>作为世界环境提供真实环境反射和全局光照。

## 代码对照

```python
# Blender Python：三点布光自动化
import bpy, math

for obj in bpy.data.objects:
    if obj.type == 'LIGHT':
        bpy.data.objects.remove(obj)

bpy.ops.object.light_add(type='AREA', location=(4, -4, 5))
key = bpy.context.active_object
key.name = 'Key_Light'
key.data.energy = 500
key.data.size = 3.0
key.data.color = (1.0, 0.95, 0.85)

bpy.ops.object.light_add(type='AREA', location=(-4, -2, 3))
fill = bpy.context.active_object
fill.name = 'Fill_Light'
fill.data.energy = 150
fill.data.size = 4.0
fill.data.color = (0.8, 0.85, 1.0)

bpy.ops.object.light_add(type='SPOT', location=(0, 5, 4))
rim = bpy.context.active_object
rim.name = 'Rim_Light'
rim.data.energy = 300
rim.data.spot_size = math.radians(60)
print('三点布光设置完成')
```

## 常见误区

<Callout type="trap">
**现象 →** 灯光打了好几盏，画面还是灰蒙蒙的，没有层次。
**原因 →** 多盏灯光强度相近，互相抵消了明暗对比，导致整体均匀但平淡。
**修法 →** 遵循主光最强、辅光约 1/3、轮廓光适中的比例。布光的本质是制造明暗对比。
</Callout>
<Callout type="trap">
**现象 →** 阴影太硬或太模糊，看起来不自然。
**原因 →** 面光的 Size 太小阴影过硬，太大则太糊。
**修法 →** 产品渲染用大面光得到柔和阴影；户外日光用太阳光得到锐利阴影。面光的 Size 参数是关键。
</Callout>

## 练习

<Exercises>
**问题**：为什么灯光决定了画面的情绪和氛围？举例说明。

<Answer>
灯光通过明暗对比、色温和方向传达情绪。低角度暖色光制造温馨感，高角度冷色光制造冷漠感，强烈逆光制造神秘感。同一个场景换不同布光方案，情绪完全不同。
</Answer>

**问题**：三点布光法中，辅光的作用是什么？如果把辅光去掉会怎样？

<Answer>
辅光填充主光造成的阴影面，降低明暗反差，让暗部细节可见。去掉辅光后阴影面全黑，反差过大。辅光强度通常是主光的 1/3 到 1/2。
</Answer>
</Exercises>
