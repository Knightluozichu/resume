## 直觉引入

材质决定物体「看起来是什么做的」。金属还是塑料？光滑还是粗糙？生锈还是崭新？这些全靠材质节点告诉渲染器。

但材质有个前提：UV 展开。想象把一个 3D 模型的表面像剥橘子皮一样摊平到 2D 平面上，这个平面就是 UV 图。只有展好 UV，才能在正确的位置画贴图。不展 UV 就画贴图，就像没铺桌布就在折叠的桌子上画画——画完展开就全乱了。

## 概念讲解

Blender 材质用<Term def="把 3D 模型表面映射到 2D 纹理坐标的过程">UV 展开</Term>建立 2D 到 3D 的对应关系。进入 UV 编辑器，按 U 键弹出展开菜单，最常用的是 Smart UV Project 和 Mark Seam + Unwrap。

<Term def="基于物理的渲染材质，用粗糙度、金属度和反照率模拟真实表面">PBR 材质</Term>是现代标准。Blender 的 Principled BSDF 节点就是 PBR 入口，核心参数：Base Color、Metallic、Roughness。

<Term def="模拟表面微观凹凸的贴图，不增加面数">法线贴图</Term>让低模看起来像高模。<Term def="连接节点生成材质效果的可视化编辑器">着色器编辑器</Term>是核心工作区。

### PBR 四通道
- Base Color：物体的固有颜色
- Metallic：0 = 非金属，1 = 金属
- Roughness：0 = 镜面光滑，1 = 漫反射粗糙
- Normal：微观凹凸细节

<Stepper>
<Step title="第一步：UV 展开">
在编辑模式按 U 键展开 UV。简单模型用 Smart UV Project，复杂模型手动 Mark Seam 标缝后 Unwrap。检查 UV 岛有无重叠。
</Step>
<Step title="第二步：搭建 PBR 材质">
在着色器编辑器中用 Principled BSDF 节点设置 Base Color、Metallic、Roughness。连上 Image Texture 节点加载贴图。
</Step>
<Step title="第三步：烘焙贴图">
如果有高模，用 Cycles 烘焙把高模的法线信息烤到低模的法线贴图上。设置 Bake 类型为 Normal。
</Step>
</Stepper>

## 代码对照

```python
# Blender Python：程序化 PBR 材质设置
import bpy

obj = bpy.context.active_object
mat = bpy.data.materials.new(name='PBR_Material')
mat.use_nodes = True
nodes = mat.node_tree.nodes
links = mat.node_tree.links
for node in nodes:
    nodes.remove(node)

bsdf = nodes.new('ShaderNodeBsdfPrincipled')
bsdf.inputs['Base Color'].default_value = (0.8, 0.2, 0.1, 1.0)
bsdf.inputs['Metallic'].default_value = 0.0
bsdf.inputs['Roughness'].default_value = 0.4

output = nodes.new('ShaderNodeOutputMaterial')
links.new(bsdf.outputs['BSDF'], output.inputs['Surface'])

obj.data.materials.append(mat)
print('PBR 材质创建完成')
```

## 常见误区

<Callout type="trap">
**现象 →** 法线贴图导入后凹凸方向反了（该凸的地方凹了）。
**原因 →** Blender 和 Unity/Unreal 的法线贴图绿通道方向相反（OpenGL vs DirectX）。
**修法 →** 在 Image Texture 节点里把 Color Space 改为 Non-Color，在 Normal Map 节点里切换绿通道翻转。
</Callout>
<Callout type="trap">
**现象 →** UV 展开后贴图拉伸严重，某些面糊成一团。
**原因 →** UV 岛排布不合理，或者展开时没有正确标记缝合线，导致角度扭曲。
**修法 →** 在扭曲严重的区域手动加 Mark Seam，重新 Unwrap；确保 UV 岛大小比例一致。
</Callout>

## 练习

<Exercises>
**问题**：为什么 UV 展开是贴图绘制的前提？不展 UV 会怎样？

<Answer>
UV 展开建立了 3D 模型表面到 2D 纹理的映射关系。没有 UV，渲染器不知道把贴图的哪个像素贴到模型的哪个面上。不展 UV 直接画贴图，颜色会随机分布或全黑。
</Answer>

**问题**：PBR 材质中 Metallic 和 Roughness 分别控制什么？一个木头桌子该怎么设置？

<Answer>
Metallic 控制金属度（0 非金属，1 金属），Roughness 控制表面粗糙度（0 镜面光滑，1 漫反射粗糙）。木头桌子：Metallic = 0，Roughness = 0.6-0.8。
</Answer>
</Exercises>
