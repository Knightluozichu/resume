## 直觉引入

在 Blender 里做完模型，要送进游戏引擎才能用。这「最后一公里」叫导出。听起来简单——存个文件嘛——但实际上坑最多：法线反了、缩放差 100 倍、材质全黑、动画丢了……每一个问题都能让你折腾一下午。

核心原因是 Blender 和游戏引擎的坐标系、单位、材质系统都不一样。导出不是「保存」，而是「翻译」——把 Blender 的数据格式翻译成引擎能理解的格式。翻译得好，引擎里所见即所得；翻译得差，全部重做。

## 概念讲解

Blender 支持多种导出格式，游戏开发最常用的是<Term def="Autodesk 的通用 3D 交换格式，游戏引擎最广泛支持">FBX</Term>和<Term def="Khronos 的现代 3D 格式，Web 和移动端首选">glTF</Term>。

### 格式对比
- **FBX**：支持动画、骨骼、blendshape，Unity/Unreal 原生支持，但闭源、文件大
- **glTF**：开放标准、文件小、支持 PBR 材质，WebGL 首选

### 导出关键设置
- <Term def="不同软件坐标轴朝向不同，导出时需转换">坐标系</Term>转换：Unity 用 Y-up、Blender 用 Z-up
- <Term def="Blender 默认单位是米，引擎可能用厘米">缩放</Term>：导出时选 Apply Scalings
- Apply Modifiers：导出时应用修改器
- 只导出选中对象：避免把灯光和相机也导进去

<Stepper>
<Step title="第一步：检查模型">
在 Blender 中确认：模型已应用缩放（Ctrl+A → Scale），法线朝外（Ctrl+N），材质已赋值，UV 已展开。
</Step>
<Step title="第二步：配置导出">
File → Export → FBX。勾选 Selected Objects，设目标引擎坐标系（Unity: Y-forward, Z-up），Apply Scalings 选 FBX All，勾选 Apply Modifiers。
</Step>
<Step title="第三步：引擎导入验证">
把 FBX 拖入 Unity，检查：模型大小、朝向、材质颜色、法线方向。如果有问题回到 Blender 调整。
</Step>
</Stepper>

## 代码对照

```python
# Blender Python：FBX 导出脚本（针对 Unity）
import bpy

for obj in bpy.context.selected_objects:
    if obj.type == 'MESH':
        bpy.context.view_layer.objects.active = obj
        bpy.ops.object.transform_apply(location=False, rotation=False, scale=True)
        print(f'已应用缩放: {obj.name}')

bpy.ops.export_scene.fbx(
    filepath='//game_asset.fbx',
    use_selection=True,
    use_mesh_modifiers=True,
    mesh_smooth_type='FACE',
    axis_forward='Y',
    axis_up='Z',
    apply_scale_options='FBX_SCALE_ALL',
    use_tspace=True,
    bake_anim=True,
)
print('FBX 导出完成（Unity 配置）')
```

## 常见误区

<Callout type="trap">
**现象 →** 模型导入 Unity 后法线翻转或全黑。
**原因 →** Blender 和 Unity 的法线方向或切线空间不一致，或者导出时没勾选 Tangent Space。
**修法 →** 在 Blender 中 Ctrl+N 重算法线向外；导出 FBX 时勾选 Tangent Space；Unity 导入设置里 Normals 设为 Calculate。
</Callout>
<Callout type="trap">
**现象 →** 模型在 Unity 里大小不对，比预期大 100 倍。
**原因 →** Blender 默认单位是米，FBX 导出时缩放因子可能没设置正确。
**修法 →** 在 Blender 中 Ctrl+A 应用缩放；导出时 Apply Scalings 选 FBX All；Unity 导入设置里调整 Scale Factor。
</Callout>

## 练习

<Exercises>
**问题**：为什么导出是美术管线的最后一公里？导出出错会带来什么后果？

<Answer>
导出是 Blender 数据到引擎数据的翻译环节，是美术资产进入游戏的唯一入口。导出出错意味着之前所有工作在引擎里都看不到正确效果——法线反了全黑、缩放错了巨大、材质丢了全白。
</Answer>

**问题**：FBX 和 glTF 各有什么优劣？什么时候选哪个？

<Answer>
FBX 支持完整骨骼动画和材质，Unity/Unreal 原生支持好，但闭源文件大。glTF 开放标准文件小 PBR 原生支持，Web/移动端首选。PC/主机选 FBX，Web/移动选 glTF。
</Answer>
</Exercises>
