## 直觉引入

渲染是把 3D 场景变成 2D 图片的最后一关。Blender 有两个渲染引擎：Cycles 是离线光线追踪，一个像素一个像素地模拟光线弹射，慢但真实；Eevee 是实时渲染，用光栅化加各种技巧近似光照，快但不够精确。

选哪个？要最终海报级质量就用 Cycles；要快速预览或实时交互就用 Eevee。很多工作流是先用 Eevee 快速调效果，最终出图切换到 Cycles。

## 概念讲解

<Term def="光线追踪渲染引擎，逐像素模拟光线弹射">Cycles</Term>的核心是递归光线追踪：每条光线撞到物体后可能反射、折射或被吸收，继续追踪散射光线。结果物理正确，但计算量大。采样数决定画质——太少有噪点，太多渲染慢。

<Term def="实时渲染引擎，用光栅化近似光照效果">Eevee</Term>用屏幕空间技术近似反射和阴影，速度极快但有限制。

<Term def="每像素发射多少条光线，越高噪点越少">采样数</Term>是 Cycles 的核心参数。预览用 32-64，最终出图用 128-256。配合<Term def="AI 降噪，用较少采样得到干净画面">降噪</Term>可以大幅减少所需采样。

### 渲染设置清单
- 分辨率与帧率
- 采样数（Cycles）或 Eevee 质量
- 降噪开关
- 颜色管理（Filmic 更真实）

## 代码对照

```python
# Blender Python：渲染配置自动化
import bpy

scene = bpy.context.scene
scene.render.engine = 'CYCLES'
scene.cycles.device = 'GPU'
scene.cycles.samples = 128
scene.cycles.use_denoising = True
scene.cycles.denoiser = 'OPTIX'

scene.render.resolution_x = 1920
scene.render.resolution_y = 1080
scene.render.fps = 30
scene.render.image_settings.file_format = 'PNG'

scene.view_settings.view_transform = 'Filmic'
scene.view_settings.look = 'Medium High Contrast'

print(f'引擎: {scene.render.engine}')
print(f'采样: {scene.cycles.samples}')
print(f'分辨率: {scene.render.resolution_x}x{scene.render.resolution_y}')
```

## 常见误区

<Callout type="trap">
**现象 →** Cycles 渲染画面全是噪点，像电视雪花。
**原因 →** 采样数太低，每像素发射的光线太少，统计噪声大。
**修法 →** 增加采样数到 128+；或保持低采样但开启降噪，AI 会智能填补噪点。
</Callout>
<Callout type="trap">
**现象 →** Eevee 渲染的反射和阴影与 Cycles 差别很大。
**原因 →** Eevee 用屏幕空间技术近似，反射只在屏幕可见区域、SSAO 是近似的。
**修法 →** 在 Eevee 设置里开 Screen Space Reflections；增大 Shadow Cube Size。如果需要物理正确效果，切到 Cycles。
</Callout>

## 练习

<Exercises>
**问题**：为什么实时渲染（Eevee）永远比不过离线渲染（Cycles）的真实感？

<Answer>
Cycles 逐像素递归追踪光线弹射，能模拟真实的反射、折射、焦散和全局光照。Eevee 用光栅化加屏幕空间技巧近似。实时渲染受帧时间限制（16ms），必须在画质上妥协。
</Answer>

**问题**：Cycles 的采样数和降噪之间是什么关系？降噪能完全替代高采样吗？

<Answer>
采样数越高噪点越少但渲染越慢；降噪用 AI 从低采样图像推断干净画面。但降噪不能完全替代高采样——极低采样时噪点太严重，降噪会丢失细节。
</Answer>
</Exercises>

<GlossaryItem term="Eevee">Blender 的实时渲染引擎，用光栅化近似光照效果，速度快但精度不如 Cycles，适合预览。</GlossaryItem>
<GlossaryItem term="采样数">Cycles 中每个像素发射的光线数量，越高噪点越少但渲染越慢，配合降噪可降低需求。</GlossaryItem>
<GlossaryItem term="降噪">用 AI 算法从低采样图像中去除噪点，如 OptiX 或 OpenImageDenoise，可大幅减少所需采样数。</GlossaryItem>
</Glossary>
