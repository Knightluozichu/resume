## 直觉引入

这本书从界面开始，经过建模、材质、灯光、动画、雕刻、渲染、导出，把 Blender 的核心能力走了一遍。现在把它们串起来：做一个完整的游戏道具——从空场景到导出 FBX。

这个综合练习会暴露你之前忽略的细节：建模时没注意的拓扑、展 UV 时没管的重叠、材质节点的连线错误、导出时的坐标系问题。每一环都依赖前一环的产出，任何一环出错，后面的环节都会连锁失败。

## 概念讲解

全书知识可以压缩成一条流水线：<Term def="从参考图到引擎资产的完整工作流">美术管线</Term>。

### 完整管线
1. **界面与导航**：设置工作区，导入参考图
2. **建模**：搭大型 → 加细节 → 清拓扑
3. **材质**：展 UV → PBR 节点 → 烘焙法线
4. **灯光**：世界 HDRI → 三点布光
5. **动画**：关键帧 → 曲线调节 → 骨骼绑定
6. **雕刻**：高模细节 → 烘焙到低模
7. **渲染**：Cycles 出图 或 Eevee 预览
8. **导出**：FBX/glTF → 引擎导入验证

<Term def="把高模细节投射到低模纹理的过程">烘焙</Term>连接雕刻和材质。<Term def="非破坏性工作流的核心">修改器</Term>贯穿建模到导出。

## 代码对照

```python
# Blender Python：综合项目——一键准备导出
import bpy

print('=== 导出前检查清单 ===')
meshes = [o for o in bpy.context.selected_objects if o.type == 'MESH']
print(f'1. 网格对象: {len(meshes)} 个')

for m in meshes:
    bpy.context.view_layer.objects.active = m
    bpy.ops.object.transform_apply(scale=True)
    bpy.ops.object.mode_set(mode='EDIT')
    bpy.ops.mesh.select_all(action='SELECT')
    bpy.ops.mesh.normals_make_consistent(inside=False)
    bpy.ops.object.mode_set(mode='OBJECT')
    print(f'   {m.name}: 缩放已应用, 法线已重算')

has_uv = all(len(m.data.uv_layers) > 0 for m in meshes)
print(f'2. UV 展开: {"已检查" if has_uv else "缺失!"}')

has_mat = all(len(m.data.materials) > 0 for m in meshes)
print(f'3. 材质: {"已赋值" if has_mat else "缺失!"}')

print('=== 检查完成，可以导出 ===')
```

## 常见误区

<Callout type="trap">
**现象 →** 项目做到一半发现拓扑太乱，修改器效果不对。
**原因 →** 建模阶段没有规划好拓扑流（Edge Flow），随意加线导致环切和修改器变形异常。
**修法 →** 在建模初期就规划好拓扑——关节处用环线、硬表面保持四边形。发现拓扑问题越早返工成本越低。
</Callout>
<Callout type="trap">
**现象 →** 导出后引擎里材质全黑或全白。
**原因 →** Blender 的材质节点没有正确映射到引擎的材质系统，或者贴图路径丢失。
**修法 →** 使用 Principled BSDF 标准节点；导出时勾选嵌入贴图（Embed Textures）；在引擎中重新指定贴图路径。
</Callout>

## 练习

<Exercises>
**问题**：从零到导出一个游戏角色，完整步骤是什么？

<Answer>
1）导入参考图搭大型；2）建模：挤出+环切+清拓扑，加镜像做对称；3）展 UV 排布 UV 岛；4）如果需要细节，雕刻高模后烘焙法线到低模；5）用 Principled BSDF 搭 PBR 材质，连法线贴图；6）绑骨骼刷权重；7）做动画（如需）；8）应用缩放重算法线，导出 FBX；9）引擎导入验证。
</Answer>

**问题**：全书哪个环节最容易出错且返工成本最高？为什么？

<Answer>
建模最容易出错且返工成本最高。建模是所有后续环节的输入——拓扑错了导致 UV 展不好、材质贴不对、骨骼绑不上、导出面数超标。后期发现建模问题需要回退到最初重新搭型，后面所有环节都要重来。
</Answer>
</Exercises>

<GlossaryItem term="烘焙">把高模的表面细节（法线、AO）投射到低模的纹理上，连接雕刻和材质环节。</GlossaryItem>
<GlossaryItem term="修改器">非破坏性工作流的核心，贯穿建模到导出，保留随时调整的弹性。</GlossaryItem>
<GlossaryItem term="拓扑规划">建模初期规划顶点连线的流向（Edge Flow），确保关节弯曲、修改器变形自然。</GlossaryItem>
