## 问题：为什么没有重叠的 UV 仍可能导致纹理模糊和接缝明显

先预测：所有 UV 岛都在 0 到 1 范围内且不重叠，是否就一定合格？不一定。面积比例、拉伸、方向、接缝位置、像素密度和边缘 Padding 同样决定纹理结果。第八章从映射原理出发，为 Jim 的面部、身体、服装和配件建立可绘制的 UV 布局。

## 切割曲面、控制失真、分配纹理预算

UV 为每个网格角保存二维坐标。接缝把连续三维表面切成可摊平岛，算法在角度、面积和边长之间折中。角色面部优先降低可见区拉伸，接缝放在后脑或遮挡处；服装和配件按材质边界和绘制便利切分。Packing 需要统一 Texel Density、岛间 Padding、方向和镜像策略。

## 关键对象与数据流

复制最终拓扑并锁定模型版本，先用测试栅格观察面部和躯干潜在接缝。标记接缝后分区展开，逐岛检查 Stretch、镜像、翻转和方向。为面部等高关注区域分配更高面积或保持统一密度，再按目标分辨率计算 Padding 并打包。任何拓扑变化都触发 UV 回归检查。

每次修改前先保存输入版本，修改后记录输出文件、统计和截图。最终画面正确但中间资产不符合预测，也不能立即签发，因为它可能依赖隐藏偏好、未保存图像、错误链接或偶然缓存。

<Callout type="trap">
  **因果陷阱**：只追求岛塞满空间会牺牲统一密度和足够 Padding，缩小 Mip

</Callout>

<Callout type="trap">

## 验收证据

验收包含接缝图、各部件 UV 岛、Stretch Overlay、测试栅格、Texel Density 统计、Padding 像素、打包占用率和导出的 UV Layout。目标镜头中面部与手的像素预算必须可解释。

证据包同时记录文件路径、Datablock 名称、版本、参数、复现步骤、预期和实际结果。交给另一位读者后不需要猜隐藏状态即可重放，才算掌握而不只是看过。

UV 验收必须把几何正确和像素预算同时量化。先给全角色套方向明确、格子等大的测试图，在面部、手、躯干、靴子和帽子上分别截取正视与斜视图，记录弯曲线、格子面积和接缝跳变；再按最终镜头的重要度设定 Texel Density，说明面部为何可以高于不可见鞋底。打包时记录图像尺寸、最小岛尺寸、旋转策略、允许重叠的对称部件和以像素计的 Padding，并用缩小后的 Mipmap 预览检查渗色。修改模型后重跑 UV 哈希与岛数量对照，证明拓扑变化没有静默破坏已绘制纹理。

## 小结

- UV 展开是曲面切割和失真控制问题
- 接缝位置应服从可见性与绘制便利
- Texel Density 分配纹理预算
- Packing 必须同时考虑 Padding、方向和叠放策略
