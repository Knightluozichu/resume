## Image Datablock、磁盘文件与材质引用

Image Datablock 是 Blender 内存中的图像对象，Material Node 引用它，Texture Paint 写入其像素；磁盘文件是独立持久化载体。Save .blend、Save Image 和 Pack Resources 是不同动作。Base Texture 先分配皮肤、布料、金属等大色块，再用明度、色相、粗糙变化和磨损表达材质层级；细节尺度必须匹配最终镜头。

## 关键对象与数据流

为 UV 创建固定分辨率图像并立即命名、保存，连接到材质 Base Color 并设为 Paint Slot。先填材质大区，再在独立外部图层或版本文件添加色差、接缝、污渍和角色特征。每次绘制后执行 Save Image，重新打开 .blend 验证路径；导入外部修改时检查色彩空间、Alpha 和 UV 对齐。

每次修改前先保存输入版本，修改后记录输出文件、统计和截图。最终画面正确但中间资产不符合预测，也不能立即签发，因为它可能依赖隐藏偏好、未保存图像、错误链接或偶然缓存。

## 从 Blender 2.83 LTS 到当前版本

Texture Paint 界面和画笔系统会变化，但 Image Datablock、Paint Slot、磁盘持久化、色彩空间和材质引用链稳定。现代外部 PBR 工具可补充流程，本章仍需证明 Base Texture 和 Blender 回看。

## 小结

- 纹理绘制目标是 Image Datablock 与材质槽的组合
- 保存项目和保存图像是不同操作
- Base Texture 先建立材质和明度层级
- 外部往返必须验证路径、色彩空间和 UV
