- 理解《区块链开发实战》全书的五大开发阶段与十章学习路径

## 核心概念

### 五大开发阶段

《区块链开发实战》按照由浅入深、从工具到上线的原则，将全书内容划分为五个开发阶段：

1. **基础与搭建**：理解知识全景，搭建可运行的开发工具链与测试网
2. **合约开发**：掌握 Solidity 语法与合约设计模式，编写链上逻辑
3. **集成与架构**：学习 Web3 集成与 DApp 三层架构，打通前后端与链上
4. **测试与部署**：掌握测试金字塔、安全审计与主网上线流水线
5. **进阶与复习**：实战 DeFi 与 NFT，全书复习形成工程闭环

### 十章学习路径

十章内容沿着工程主线层层递进：

- 第 0 章（本章）：知识全景图，总览学习路径
- 第 1 章：开发环境搭建，构建工具链与测试网
- 第 2 章：Solidity 智能合约基础，掌握语法与类型系统
- 第 3 章：合约设计模式，学习权限、升级与工厂模式
- 第 4 章：Web3 集成开发，打通前端与合约交互
- 第 5 章：DApp 架构设计，规划三层分层与权衡
- 第 6 章：测试与安全审计，构建测试金字塔与漏洞防御
- 第 7 章：部署与主网上线，落地七阶段流水线与治理
- 第 8 章：DeFi 与 NFT 实战，组装协议乐高与资产标准
- 第 9 章：全书复习与知识整合，形成工程闭环

### 核心脉络

全书的核心理念可以概括为一条工程主线：

**搭建环境 → 编写合约 → 集成前端 → 测试审计 → 部署主网 → 进阶实战 → 知识闭环**

每个阶段都建立在前一阶段的基础上。环境是开发基座，没有可运行的工具链就无法编译验证合约；合约是链上逻辑核心，必须先写好合约才能集成前端；测试审计是上线前提，主网不可撤销要求安全前置；进阶实战则在闭环之上拓展 DeFi 与 NFT 等真实场景。

## 术语表

| 术语 | 含义 |
|------|------|
| Solidity | 面向 EVM 的智能合约编程语言 |
| Hardhat | 基于 JavaScript 的合约开发框架 |
| Foundry | 基于 Solidity 测试的高速开发框架 |
| EVM | 以太坊虚拟机，执行智能合约的运行时 |
| ABI | 合约接口描述，前端据此编码调用 |
| Gas | 衡量合约执行计算量的单位 |
| DApp | 去中心化应用，前端加链上合约的组合 |
| 代理合约 | 通过 delegatecall 实现可升级的合约模式 |
| 测试网 | 模拟主网的公开测试环境（如 Sepolia） |
| DeFi | 去中心化金融，由可组合协议构成 |
