## 学习目标

- 掌握 DeFi 协议栈四大核心组件
- 区分 ERC-721 与 ERC-1155 资产标准
- 理解乐高式可组合性与组合实例
- 认识协议组合带来的连环清算风险与防范

## 核心概念

### DeFi 协议栈

DeFi 由四大核心组件构成：DEX 去中心化交易所（如 Uniswap AMM，基于恒定乘积 x 乘 y 等于 k 的流动性池，存在滑点与手续费）、借贷（如 Aave 与 Compound 的资金池，超额抵押与清算机制）、预言机（如 Chainlink 报价与 TWAP 时间加权均价）、衍生品（永续合约与合成资产，杠杆与资金费率）。

### NFT 资产标准

NFT 有两大标准：ERC-721 是非同质化标准，每个 tokenId 唯一，适合独一无二的艺术品、收藏品、虚拟土地；ERC-1155 支持同质与非质混合，可批量转账多个代币，Gas 更省，适合游戏道具、半同质化物品。元数据通过 tokenURI 指向 IPFS 上的 JSON，链上只存哈希；市场协议支持挂单、撮合与版税（EIP-2981）。

### 乐高式可组合性

DeFi 协议彼此开放接口可互相调用，像积木一样堆叠，称为 Money Legos。一个典型组合：抵押资产存入借贷池，借出稳定币，投入 DEX 做市成为 LP，LP 凭证再抵押入另一协议生息。NFT 也可作抵押品、可碎片化、可绑定 DeFi 收益策略。可组合性带来资本效率，也叠加风险。

### 连环清算风险

组合越多，依赖链越长，单点漏洞或预言机失真会沿调用链放大：一处协议被攻击或价格异常，触发抵押率下降，引发跨协议连环清算与流动性枯竭。防范需使用 TWAP 防瞬时操纵、设置合理抵押率与清算阈值、避免过度依赖单一协议、压力测试极端行情、分叉主网验证清算路径。

## 术语表

| 术语 | 含义 |
|------|------|
| AMM | 自动做市商，恒定乘积定价 |
| 流动性池 | 资金聚集供交易兑换的池子 |
| 滑点 | 交易规模导致的价格偏移 |
| 超额抵押 | 借贷需抵押高于借款价值的资产 |
| 清算 | 抵押率不足时强制平仓 |
| ERC-721 | 非同质化代币标准 |
| ERC-1155 | 多代币混合标准 |
| EIP-2981 | NFT 版税标准 |
| 闪电贷 | 同一交易内借还的无抵押贷款 |
