- 理解区块链的定义与本质特征
- 掌握区块的链式结构与哈希指针的防篡改原理
- 认识区块链的五大核心特性（去中心化、不可篡改、公开透明、匿名性、可追溯）
- 了解 P2P 节点网络中全节点、矿工节点与轻节点的职责分工

## 核心概念

### 什么是区块链

区块链是一种以链式结构存储数据的分布式账本技术。简单来说，它就像一个所有人共同维护的记账本：每个人都能看到所有记录，但任何人都无法偷偷修改已经写下的内容。

区块链由一个个「区块」组成，每个区块包含一批交易记录。区块之间通过哈希指针首尾相连，形成一条不可断裂的链。这就是「区块链」这个名字的由来。

### 链式结构与防篡改

每个区块由两部分组成：

- **区块头**：包含版本号、前区块哈希、Merkle 根、时间戳、难度目标和 Nonce
- **区块体**：包含该区块打包的所有交易记录

关键在于「前区块哈希」字段：每个区块都存储了上一个区块的哈希值。如果有人试图篡改某个区块中的数据，该区块的哈希值会完全改变（雪崩效应），导致后续所有区块中存储的前区块哈希失配，整条链断裂。全网节点会立即识别出这是非法链并拒绝接受。

### 五大核心特性

| 特性 | 含义 | 实现方式 |
|------|------|----------|
| 去中心化 | 无单一管理中心，节点对等参与 | P2P 网络，多副本冗余 |
| 不可篡改 | 一旦上链，数据无法修改 | 哈希链式绑定 |
| 公开透明 | 账本全网可见可验证 | 公共账本，可审计 |
| 匿名性 | 地址不绑定真实身份 | 公钥派生地址，伪匿名 |
| 可追溯 | 交易全链路可查 | 链式时间戳记录 |

### P2P 节点网络

区块链运行在点对点（P2P）网络之上，没有中心服务器。网络中的节点分为三种类型：

- **全节点**：存储完整的区块链数据，独立验证所有交易和区块，是网络的基础
- **矿工节点**：在全节点基础上参与共识过程（如 PoW 挖矿），负责打包新区块
- **轻节点**：只存储区块头，通过 SPV（简化支付验证）验证与自己相关的交易

所有节点通过 P2P 协议互相连接，共同维护账本的一致性。

## 术语表

| 术语 | 含义 |
|------|------|
| 区块 | 区块链中存储交易数据的基本单元 |
| 区块头 | 区块中存储元数据的部分，包含前区块哈希等字段 |
| 区块体 | 区块中存储交易记录的部分 |
| 哈希指针 | 指向前一个区块哈希值的引用，实现链式绑定 |
| 雪崩效应 | 输入微小变化导致哈希输出完全不同的特性 |
| 全节点 | 存储完整区块链并独立验证所有数据的节点 |
| 矿工节点 | 参与共识过程并打包新区块的节点 |
| 轻节点 | 只存储区块头并通过 SPV 验证的节点 |
| P2P 网络 | 点对点网络，节点对等连接，无中心服务器 |
| SPV | 简化支付验证，轻节点无需全量数据即可验证交易 |
