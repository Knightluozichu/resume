## 学习目标

- 理解哈希函数的四大特性及其在区块链中的应用
- 掌握非对称加密中公钥与私钥的关系与工作原理
- 能够描述数字签名的完整流程及其解决的安全问题
- 理解密码学技术如何保障区块链的完整性、保密性与真实性

## 核心概念

### 哈希函数

哈希函数是将任意长度输入映射为固定长度输出的单向函数。区块链中最常用的哈希算法是 SHA-256，它将任意数据映射为 256 位（32 字节）的哈希值。

哈希函数有四大核心特性：

- **确定性**：相同的输入总是产生相同的输出
- **单向不可逆**：无法从哈希值反推原始输入
- **雪崩效应**：输入哪怕只改变一个比特，输出也会完全不同
- **抗碰撞**：难以找到两个不同的输入产生相同的哈希值

在区块链中，哈希函数用于：计算区块哈希（防篡改）、构建 Merkle 树（交易聚合验证）、派生地址（公钥哈希）等。

### 非对称加密

非对称加密使用一对数学相关的密钥：公钥和私钥。

- **公钥**：可以公开分发，用于加密数据或验证签名
- **私钥**：必须严格保密，用于解密数据或生成签名

非对称加密的两个核心用途：

1. **加密通信**：公钥加密，私钥解密——任何人都可以用你的公钥加密消息，但只有你能用私钥解密
2. **数字签名**：私钥签名，公钥验签——你用私钥签名，任何人都可以用你的公钥验证签名确实来自你

由公钥无法在计算上推算出私钥，这就是非对称加密安全性的基础。

### 数字签名

数字签名是区块链交易授权的核心机制。完整流程如下：

**发送方（签名）**：

1. 对原始消息进行哈希运算，得到消息摘要
2. 用发送方的私钥加密摘要，生成数字签名
3. 将消息和签名一起发送

**接收方（验签）**：

1. 用发送方的公钥解密签名，得到摘要 H2
2. 对收到的消息重新做哈希，得到摘要 H1
3. 比较 H1 与 H2：一致则签名有效，不一致则可能被篡改

数字签名解决了三个安全问题：

- **真实性**：确认消息确实来自声称的发送者
- **完整性**：检测消息在传输过程中是否被篡改
- **不可否认性**：发送者无法否认自己发送过该消息

### 密钥派生链路

在区块链中，密钥的派生关系为：

**私钥 → 椭圆曲线乘法生成公钥 → 哈希运算生成公钥哈希 → 加版本前缀并编码得到地址**

私钥是整个体系的根本。谁拥有私钥，谁就拥有对应地址下资产的控制权。因此私钥的安全存储是区块链安全的核心。

## 术语表

| 术语 | 含义 |
|------|------|
| 哈希函数 | 将任意长度输入映射为固定长度输出的单向函数 |
| SHA-256 | 区块链中常用的哈希算法，输出 256 位哈希值 |
| 雪崩效应 | 输入微小变化导致哈希输出完全不同的特性 |
| 非对称加密 | 使用公钥和私钥一对密钥的加密体制 |
| 公钥 | 可公开分发的密钥，用于加密和验签 |
| 私钥 | 必须保密的密钥，用于解密和签名 |
| 数字签名 | 用私钥对消息摘要加密生成的签名 |
| 消息摘要 | 消息经哈希运算得到的固定长度输出 |
| 椭圆曲线加密 | 区块链中常用的非对称加密算法（如 secp256k1） |
| Base58Check | 比特币地址的编码方式 |
