## 学习目标

- 理解共识机制的定义及其要解决的核心问题（拜占庭将军问题）
- 掌握 PoW、PoS、DPoS 三大共识机制的工作原理与代表项目
- 理解区块链不可能三角（安全性、去中心化、可扩展性）的权衡
- 区分临时分叉、最长链原则与最终性的概念

## 核心概念

### 什么是共识机制

在一个去中心化网络中，互不信任的节点如何就账本状态达成一致？这就是共识机制要解决的核心问题。

这个问题本质上是「拜占庭将军问题」：在可能存在叛节（恶意）节点的网络中，如何让诚实节点达成一致的行动方案。区块链的共识机制就是解决这个问题的算法。

共识机制需要满足两个基本条件：

- **一致性**：所有诚实节点最终接受相同的账本
- **活性**：系统能持续产生新区块，不会卡死

### PoW：工作量证明

PoW（Proof of Work）是比特币采用的共识机制。核心思想是「算力竞赛」：

1. 矿工收集待确认的交易，打包成候选区块
2. 不断尝试不同的随机数（Nonce），计算区块哈希
3. 当区块哈希小于目标值时，谜题被解开
4. 矿工广播新区块，其他节点验证后接受

PoW 的安全性来源于算力：攻击者要篡改历史，必须拥有全网 51% 以上的算力，成本极高。代价是能耗巨大、TPS 低（比特币约 7 笔/秒）。

### PoS：权益证明

PoS（Proof of Stake）是以太坊 2.0 采用的共识机制。核心思想是「持币即权力」：

1. 验证者质押一定数量的代币成为候选
2. 协议按质押量和持币时间随机选择记账者
3. 被选中的验证者出块，其他验证者确认
4. 如果验证者作恶（如双签），质押的代币会被罚没（Slashing）

PoS 不需要消耗大量算力，节能环保，TPS 较 PoW 更高。安全性来源于经济激励：作恶会被罚没质押，理性参与者不会作恶。

### DPoS：委托权益证明

DPoS（Delegated Proof of Stake）是 EOS 采用的共识机制。核心思想是「代议制民主」：

1. 持币者投票选举少量超级节点（如 21 个）
2. 获选节点按固定顺序轮流记账
3. 如果节点未出块或作恶，持币者可投票撤换

DPoS 通过减少参与共识的节点数量，大幅提升 TPS（可达数千笔/秒），但去中心化程度较弱。

### 区块链不可能三角

三种共识机制反映了「区块链不可能三角」的权衡：

| 维度 | PoW | PoS | DPoS |
|------|-----|-----|------|
| 安全性 | 最高 | 较高 | 中等 |
| 去中心化 | 最高 | 中等 | 较低 |
| 可扩展性 | 最低 | 中等 | 最高 |
| 代表项目 | 比特币 | 以太坊2.0 | EOS |

安全性、去中心化和可扩展性三者难以同时满足。任何共识机制都在这三者之间做取舍。

### 分叉与最终性

当两个矿工几乎同时出块时，链会出现分支，这称为「临时分叉」。PoW 通过「最长链原则」消解分叉：节点总是选择最长的链作为主链，短链上的交易被回滚废弃。

关于最终性：

- **PoW 是概率最终性**：区块确认数越多越安全，但理论上始终可能被更长的链取代。比特币通常需要 6 个确认才认为安全。
- **PoS/PBFT 提供绝对最终性**：一旦区块被确认（通常经过一轮投票），就不可回滚。

## 术语表

| 术语 | 含义 |
|------|------|
| 共识机制 | 去中心化网络中节点就账本状态达成一致的规则 |
| 拜占庭将军问题 | 在存在恶意节点的网络中达成一致的问题 |
| PoW | 工作量证明，通过算力竞赛获得记账权 |
| PoS | 权益证明，按持币量选举验证者 |
| DPoS | 委托权益证明，持币者投票选出代表轮流记账 |
| Nonce | 工作量证明中矿工不断尝试的随机数 |
| Slashing | PoS 中对作恶验证者罚没质押的惩罚机制 |
| 不可能三角 | 安全性、去中心化、可扩展性难以同时满足 |
| 临时分叉 | 两个矿工同时出块导致的链分支 |
| 最长链原则 | 节点选择最长链作为主链的规则 |
| 最终性 | 区块被确认后不可回滚的属性 |
