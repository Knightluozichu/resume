## 核心概念

### 钱包的本质

很多人以为区块链钱包是用来「存钱」的，但实际上钱包的核心功能是**管理密钥对和签名交易**。你的资产不在钱包里，而是在区块链上。钱包只是帮你管理私钥、用私钥签名交易的工具。

### 密钥派生与地址生成

从私钥到地址的完整派生链路：

1. **私钥**：一个 256 位的随机数，是整个体系的根本
2. **公钥**：私钥通过椭圆曲线乘法（如 secp256k1）生成公钥
3. **公钥哈希**：公钥经 SHA-256 和 RIPEMD-160 双重哈希
4. **地址**：加版本前缀后用 Base58Check 编码得到区块链地址

关键原则：由公钥无法推算出私钥，由地址无法推算出公钥。因此公开地址是安全的，但私钥必须严格保密。**谁拥有私钥，谁就拥有资产的控制权。**

### HD 钱包与助记词

HD（Hierarchical Deterministic，分层确定性）钱包通过 BIP32/BIP44 协议从主密钥按树形路径派生子密钥：

- 主密钥可以派生出无限多个子密钥
- 每个子密钥对应一个独立的地址
- 只需备份主密钥（或助记词）即可恢复所有地址

助记词（BIP39）是主密钥的人类可读形式，通常是 12 或 24 个英文单词。它的价值在于：

- **易备份**：只需抄写 12 个单词即可备份整个钱包
- **易恢复**：在任何兼容钱包中输入助记词即可恢复所有资产
- **跨平台**：助记词是行业标准，不绑定特定钱包应用

### 钱包类型对比

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 冷钱包 | 完全离线存储私钥，安全性最高 | 大额资产长期存储 |
| 热钱包 | 联网运行，便捷高效 | 日常小额交易 |
| 硬件钱包 | 专用物理设备，私钥永不离开设备 | 中等额度，兼顾安全与便捷 |
| 纸钱包 | 将私钥打印在纸上，极度离线 | 极端安全需求 |

核心安全原则：**私钥永不泄露、助记词离线备份、大额资产用冷钱包。**

### UTXO 模型与账户模型

区块链有两种主要的账户/交易模型：

**UTXO 模型（比特币）**：
- 以未花费交易输出（UTXO）为单位
- 输入花费旧 UTXO，输出创建新 UTXO
- 天然防双花，支持并行验证
- 隐私性好，但编程复杂

**账户模型（以太坊）**：
- 全局状态树记录每个账户的余额
- 类似银行账户，直接加减余额
- 合约友好，状态清晰
- 需要 Nonce 防止重放攻击，串行执行

简单理解：UTXO 模型像现金（每张钞票是独立的），账户模型像银行账户（一个数字代表余额）。

| 术语 | 含义 |
|------|------|
| 钱包 | 管理密钥对并签名交易的工具 |
| 私钥 | 256 位随机数，控制资产的根本密钥 |
| 公钥 | 由私钥派生，用于生成地址和验签 |
| 地址 | 公钥哈希编码后的字符串，用于接收资产 |
| HD 钱包 | 分层确定性钱包，从主密钥派生子密钥 |
| 助记词 | 12/24 个单词，主密钥的人类可读形式 |
| BIP32 | HD 钱包的层级派生协议 |

| 冷钱包 | 完全离线存储私钥的钱包 |
| 硬件钱包 | 专用物理设备，私钥永不离开设备 |
| UTXO 模型 | 以未花费交易输出为单位的交易模型 |
| 账户模型 | 以全局余额状态为单位的交易模型 |
