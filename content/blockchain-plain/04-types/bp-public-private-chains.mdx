## 学习目标

- 区分公有链、联盟链与私有链的核心特征与适用场景
- 理解不同链类型在准入机制、共识算法、效率与安全性的权衡
- 掌握侧链与跨链技术的概念与价值
- 能够根据实际场景选择合适的链类型

## 核心概念

### 三种链类型

区块链根据参与者的开放程度，分为三种主要类型：

**公有链**：任何人都可以参与的开放区块链。节点准入完全开放，身份匿名，使用 PoW 或 PoS 共识。安全性最高（算力或权益保护），但效率最低。代表项目：比特币、以太坊。

**联盟链**：由多个授权机构共同维护的区块链。节点需要联盟成员授权才能加入，身份已知，使用 PBFT 或 Raft 等高效共识。效率较高，在成员间保持透明。代表项目：Hyperledger Fabric、FISCO BCOS。

**私有链**：由单一组织内部控制的区块链。节点准入由组织控制，效率最高，但去中心化程度最低。主要用于内部审计和数据管理。

### 核心维度对比

| 维度 | 公有链 | 联盟链 | 私有链 |
|------|--------|--------|--------|
| 节点准入 | 完全开放 | 联盟授权 | 组织控制 |
| 共识机制 | PoW / PoS | PBFT / Raft | Raft / 简单投票 |
| 身份 | 匿名 | 已知机构 | 实名可控 |
| 效率（TPS） | 低（7-15） | 较高（千级） | 最高（万级） |
| 安全性 | 最高 | 较高 | 依赖内部 |
| 透明度 | 完全公开 | 成员间公开 | 内部可控 |
| 代表 | 比特币 | Hyperledger | 内部系统 |

### 如何选择链类型

选择链类型的关键在于分析场景需求：

- **去中心化优先**：需要抗审查、无信任参与，选公有链。如加密货币、DeFi
- **多方协作优先**：多个互不信任但身份可知的机构协作，选联盟链。如跨银行结算、供应链
- **效率可控优先**：单一组织内部需要不可篡改的审计日志，选私有链。如内部数据管理
- **混合架构**：公链加联盟链分层组合，兼顾开放与隐私

### 侧链与跨链

随着区块链生态发展，出现了侧链和跨链技术来解决链之间的隔离问题：

**侧链**：与主链并行运行的独立区块链，通过双向锚定机制实现资产在主链和侧链间转移。侧链可以扩展主链功能，如比特币的闪电网络用于快速小额支付。

**跨链**：实现不同区块链之间资产和数据互通的技术。Polkadot 通过中继链连接平行链，Cosmos 通过 IBC 协议实现链间通信。跨链技术是构建万链互联生态的关键基础设施。

## 术语表

| 术语 | 含义 |
|------|------|
| 公有链 | 任何人都可以参与的开放区块链 |
| 联盟链 | 由多个授权机构共同维护的区块链 |
| 私有链 | 由单一组织内部控制的区块链 |
| 准入机制 | 节点加入区块链网络的规则 |
| PBFT | 实用拜占庭容错，联盟链常用共识 |
| Raft | 非拜占庭场景的共识算法 |
| 侧链 | 与主链并行运行的独立区块链 |
| 双向锚定 | 主链与侧链之间资产转移的机制 |
| 跨链 | 不同区块链之间资产和数据互通的技术 |
| 中继链 | 连接多条链的中枢链（如 Polkadot） |
| IBC | Cosmos 的跨链通信协议 |
