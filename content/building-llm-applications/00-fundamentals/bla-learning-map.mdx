# LLM应用构建·知识全景图

## 学习目标

完成本章学习后，你将能够：

1. 理解《Building LLM Powered Applications》全书的核心主题与知识脉络
2. 掌握 LLM 应用构建的五大学习阶段
3. 厘清从提示工程到生产部署的完整链路
4. 明确十章的学习路径与每章定位

## 核心概念

### 全书定位

本书系统讲解如何使用大语言模型（LLM）构建实际应用。与侧重模型训练理论或前沿研究的内容不同，本书聚焦**应用构建**：如何选择合适的模型、如何通过提示工程驱动模型能力、如何用 RAG 补充领域知识、如何用编排框架串联完整流程、如何通过微调定制模型行为、如何构建自主 Agent、如何处理多模态输入、如何把原型部署到生产环境。

### 五大学习阶段

全书十章分为五个学习阶段，层层递进：

**阶段一：基础认知（ch0-ch1）**——知识全景图定位方向，LLM应用生态全景讲解模型选型与技术栈。这一阶段回答「用什么构建」。

**阶段二：核心技能（ch2-ch3）**——提示工程实践讲解从 Zero-shot 到 CoT 的提示策略，RAG应用开发讲解检索增强生成全流程。这一阶段回答「如何驱动模型」。

**阶段三：开发进阶（ch4-ch5）**——编排框架与LangChain讲解链式调用与组件组合，微调应用开发讲解 LoRA 与 QLoRA 实践。这一阶段回答「如何工程化开发」。

**阶段四：高级应用（ch6-ch7）**——Agent应用构建讲解推理循环与工具调用，多模态应用讲解图文音视融合。这一阶段回答「如何构建智能体」。

**阶段五：生产落地（ch8-ch9）**——生产部署与运维讲解从原型到上线的完整体系，全书复习整合知识闭环。这一阶段回答「如何工程落地」。

### 应用构建链路

LLM 应用构建链路包含六大核心环节：

| 环节 | 核心问题 | 代表技术 |
|------|----------|----------|
| 模型选型 | 用什么模型 | 闭源API、开源模型、嵌入模型 |
| 提示工程 | 如何驱动 | Zero-shot、Few-shot、CoT、ReAct |
| 知识增强 | 如何补知识 | RAG、向量数据库、检索重排 |
| 编排开发 | 如何串联 | LangChain、LCEL、链与Agent |
| 能力定制 | 如何调能力 | LoRA、QLoRA、全参数微调 |
| 生产部署 | 如何上线 | 网关、负载均衡、监控、安全 |

六者层层递进：模型是底座，提示是交互，RAG 是知识，编排是骨架，微调是定制，部署是落地。

## 术语表

- **LLM（Large Language Model）**：大语言模型，通过海量文本预训练获得的通用语言理解和生成模型
- **提示工程（Prompt Engineering）**：通过设计和优化输入提示来引导 LLM 产生期望输出的技术
- **RAG（Retrieval Augmented Generation）**：检索增强生成，通过检索外部知识库补充模型上下文
- **Agent**：能自主推理、规划和调用工具完成任务的智能体
- **应用构建链路**：从模型选型到生产部署的完整技术链路
