# 多模态应用

## 学习目标

完成本章学习后，你将能够：

1. 理解多模态应用的四种输入模态及其编码方式
2. 掌握多模态融合层的架构与跨模态对齐原理
3. 了解 GPT-4V、LLaVA、Qwen-VL 等多模态 LLM 的特点
4. 识别图文问答、语音助手、视频理解等典型应用场景

## 核心概念

### 从单模态到多模态

传统 LLM 只处理文本。多模态 LLM 能同时理解文本、图像、音频、视频，极大扩展了应用边界。多模态应用的核心挑战是：如何将不同模态的输入映射到统一的语义空间。

### 四种模态输入

| 模态 | 编码方式 | 代表模型 | 能力 |
|------|----------|----------|------|
| 文本 | Tokenizer + Embedding | GPT / Claude / LLaMA | 文本理解与生成 |
| 图像 | ViT / CLIP 编码 | GPT-4V / LLaVA | 图像理解与描述 |
| 音频 | Whisper / Audio 编码 | Whisper / Audio LLM | 语音识别与合成 |
| 视频 | 帧采样 + 时序编码 | Video-LLaVA / Qwen-VL | 视频理解与摘要 |

### 多模态融合层

融合层是多模态应用的核心，负责将不同模态的表示对齐到统一空间：

- **跨模态对齐**：通过 Cross-Attention 机制让不同模态的特征交互
- **投影层**：将各模态的编码投影到与文本嵌入相同的维度空间
- **共享嵌入空间**：所有模态在统一空间中表示，LLM 可以跨模态推理

### 代表多模态 LLM

| 模型 | 特点 | 能力 |
|------|------|------|
| GPT-4V | 闭源最强多模态 | 图文理解、文档分析 |
| Gemini | 原生多模态设计 | 文本+图像+音频+视频 |
| LLaVA | 开源多模态 | 图像理解、视觉问答 |
| Qwen-VL | 阿里开源 | 中英图文、文档理解 |
| CLIP | 对比学习 | 图文匹配、零样本分类 |

### 典型应用场景

**图文问答**：用户上传图片提问，模型理解图像内容并回答。适用于文档理解、图表分析、产品识别。

**语音助手**：语音输入对话，模型实时理解和回应。适用于实时翻译、会议纪要、车载交互。

**视频理解**：模型分析视频内容，生成摘要或回答问题。适用于内容审核、监控分析、视频检索。

**内容生成**：文生图、图生文、多模态创作。适用于营销素材、设计辅助、创意写作。

### 多模态应用挑战

1. **模态对齐**：不同模态的语义空间差异大，对齐质量决定跨模态理解能力
2. **计算成本**：图像和视频的 token 消耗远高于文本，成本控制是关键
3. **延迟**：多模态编码增加处理延迟，实时场景需要优化
4. **数据质量**：多模态训练数据稀缺，高质量图文对是瓶颈

## 术语表

- **多模态（Multimodal）**：能同时处理文本、图像、音频、视频等多种输入模态
- **ViT（Vision Transformer）**：将 Transformer 架构应用于图像理解的视觉模型
- **CLIP**：OpenAI 的对比学习模型，通过图文对训练实现跨模态对齐
- **Cross-Attention**：跨模态注意力机制，让不同模态的特征交互
- **帧采样**：从视频中按一定间隔提取关键帧用于视频理解
