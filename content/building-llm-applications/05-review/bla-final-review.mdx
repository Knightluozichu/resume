## 学习目标

完成本章学习后，你将能够：

1. 用五层统一视角整合全书知识
2. 理清从问题定义到生产上线的 LLM 应用决策链

4. 综合运用全书知识设计完整的 LLM 应用方案

## 核心概念

### 知识演进路径

全书十章形成「基础 → 核心技能 → 开发 → 高级 → 落地」的知识演进：

- **ch0-ch1 基础**：理解 LLM 生态与知识全景，回答「用什么构建」
- **ch2-ch3 核心技能**：掌握提示工程和 RAG，回答「如何驱动模型」
- **ch4-ch5 开发**：掌握编排框架和微调，回答「如何工程化开发」
- **ch6-ch7 高级**：掌握 Agent 和多模态，回答「如何构建智能体」
- **ch8-ch9 落地**：掌握生产部署和知识整合，回答「如何工程落地」

### 五层统一视角

| 层级 | 核心问题 | 代表技术 | 定义 |
|------|----------|----------|------|
| 基础层 | 用什么模型 | 闭源API、开源模型、嵌入模型 | 定义能力底座 |
| 交互层 | 如何驱动 | 提示工程、Few-shot、CoT、RAG | 定义交互方式 |
| 开发层 | 如何串联 | LangChain、LCEL、LoRA、QLoRA | 定义开发能力 |
| 智能层 | 如何自主 | Agent、工具调用、多模态融合 | 定义智能边界 |
| 生产层 | 如何上线 | 部署架构、监控、成本优化 | 定义工程闭环 |

五层层层递进：基础定义底座，交互定义方式，开发定义能力，智能定义边界，生产定义闭环。

### LLM 应用决策链

从问题定义到生产上线的关键决策点：

1. **问题定义**：明确场景——是问答、对话、生成还是分析？确定指标——延迟、准确率、成本
2. **模型选型**：闭源 API 还是开源模型？能力 vs 成本 vs 隐私的三角权衡
3. **提示+RAG**：先穷尽提示工程，再叠加 RAG 补充知识——无训练方案优先
4. **编排+Agent**：用 LangChain 串联流程，按需引入 Agent 自主决策
5. **微调优化**：提示和 RAG 解决不了时，用 LoRA / QLoRA 定制模型
6. **生产上线**：选择部署模式，搭建运维体系，灰度发布

每个决策点需在效果、成本、复杂度间权衡，没有银弹。

### 核心挑战与应对

| 挑战 | 应对章节 | 关键技术 |
|------|----------|----------|
| 幻觉 | ch2/ch3 | CoT 引导推理、RAG 检索约束 |
| 延迟 | ch8 | 模型路由、缓存、量化、批处理 |
| 成本 | ch5/ch8 | LoRA 微调小模型、语义缓存、模型路由 |
| 安全 | ch8 | 输入过滤、输出审核、PII 脱敏 |
| 可靠性 | ch8 | 重试机制、降级策略、灰度发布 |
| 评测 | ch3/ch8 | RAGAS、回归测试、A/B 测试 |

每个挑战都需多章技术组合应对，非单一技术能解决。

### 能力跃迁路径

理解模型 → 掌握提示 → 检索增强 → 编排开发 → 微调定制 → Agent自主 → 多模态 → 生产落地

核心脉络：从「理解模型能力」到「掌握交互方式」再到「工程化开发」最后到「生产落地」，形成完整的应用构建闭环。
