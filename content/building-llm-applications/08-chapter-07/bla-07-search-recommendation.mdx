function releaseGate(
  records: GateRecord[],
): { pass: boolean; missing: number[] } {
  const required = ["input", "config", "output", "judgment", "limits"];
  const missing = records
    .map((r, i) => (required.every((k) => k in r) ? -1 : i))
    .filter((i) => i >= 0);
  return { pass: missing.length === 0, missing };
}

## 从最小基线到应用

先实现没有记忆、检索和工具的最小模型调用，冻结五到十个正常样本及预期结构。然后每轮只加入一个能力：模板、少样本、检索、记忆、工具、代码执行或多模态输入。每一步都保留上一步基线，测量质量、延迟、成本和新引入的失败面。

输出验证分语法、语义、来源和权限四层。JSON可解析不代表事实正确；检索片段存在不代表回答受其支持；工具调用成功不代表参数获授权；前端显示顺畅也不代表多会话状态隔离。门禁失败应返回可解释状态，而不是让模型自由补写。

对话和Agent还需冻结会话ID、状态摘要、工具白名单、最大步数和终止条件。推荐与SQL应用按用户或时间分组切分，防止未来数据泄漏。代码执行放在无网络、限时限存沙箱。多模态链保存每种模态的原始输入及变换，避免只留最终文本。

## 对照、故障与回归

基线冻结任务、样本、模型、提示、知识快照、工具和判定，只改变一个因素。随机阶段至少多种子或多顺序运行，报告逐样本结果、均值、方差、尾延迟和成本。模型更大、框架更新或输出更长都不能替代受控比较。

故障轮次注入提示分隔符逃逸、空检索、过期资料、错误SQL模式、工具越权、会话串扰、代码死循环、图像OCR缺失和评测标签翻转。系统应在输入、提示、检索、权限、执行、输出或判定门禁报告首个分叉；最终答案错误只是末端症状。

修复后先重放原失败，再运行相邻边界与正常基线。上线反馈进入新的隔离数据版本，不直接污染测试集。质量、安全、延迟、成本和可复现性全部通过才晋级，发布单元冻结模型、提示、索引、工具适配器、服务镜像和评测清单。

## 容易踩的坑

**现象 →** 离线评测 NDCG 很高，上线后推荐效果骤降，用户毫无点击。
**原因 →** 切分未按时间，测试集含训练期之后的交互，未来信息泄漏到特征里。
**修法 →** 按时间戳切分训练/测试，用户与物品 ID 冻结，报告时同时给出切分边界与泄漏检查。

**现象 →** 冷启动场景下 LLM 推荐了目录中不存在的物品名，用户点击 404。
**原因 →** LLM 直接生成物品文本，未约束到候选集合，缺乏物品存在性校验。
**修法 →** 先召回合法候选集，再让 LLM 在候选内排序或生成理由，输出前校验物品 ID 是否在目录。

**现象 →** 排序结果十条里有八条是同一部电影的相似条目，用户感到单调。
**原因 →** 只按相关度排序，未引入多样性约束，长尾物品被头部压制。
**修法 →** 在排序分数中加入 MMR 或类别配额约束，同时报告命中、排序与多样性指标。

## 小结

- 冻结用户、物品、时间切分，杜绝未来交互泄漏。
- 区分召回、排序、生成三层，分别报告指标。
- 冷启动场景须约束 LLM 输出到合法候选集。
- 同时报告命中、排序、多样性、覆盖与延迟。
- 传统基线与 LLM 方案在同一切分上对照比较。

先用传统方法召回合法候选集，把候选 ID 与元数据注入提示，约束 LLM 只在候选内排序或生成推荐理由；输出前校验每个物品 ID 是否在目录中，越界直接过滤并记录失败。

</Answer>

**问题 3（独立实现）：** 独立实现一个简化版 MMR 多样性重排器：在相关度与已选物品最大相似度之间折中，选 k 条。

<Answer>

```python
def mmr(candidates, rel, sim, lam=0.5, k=5):
    selected = []
    pool = list(candidates)
    while pool and len(selected) < k:
        best = max(pool, key=lambda c: lam * rel[c] -
                   (1 - lam) * max((sim[c, s] for s in selected),
                                   default=0))
        selected.append(best)
        pool.remove(best)
    return selected
```
