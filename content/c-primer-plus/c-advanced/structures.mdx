## 为什么要把多种数据「绑」在一起？

程序里常要描述**一个整体**：一本书有书名、价格、页数；一名学生有学号、姓名、成绩。若用三个互不相关的变量，容易传参漏项、排序时对不齐。

想象一张**表格的一行**：列与列属于同一条记录。C 的 <Term def="把多个不同类型的成员组合成一种用户自定义类型；成员按声明顺序存储（含对齐 padding）。">结构体（struct）</Term> 就是给「一行数据」起名字，让编译器把各列打包进一块连续内存。

没有 struct，你只能传一长串参数或平行数组——维护成本高，也谈不上类型安全。这一章还介绍 **typedef**（起别名）、**union**（省内存的「多选一」存储）和 **enum**（可读常量）。

## 定义 struct 与成员访问

```c
struct book {
    char title[40];
    float price;
    int pages;
};

struct book novel = {
    .title = "C Primer Plus",
    .price = 29.9f,
    .pages = 720
};
```

<Term def={'结构体或联合体内部的具名字段，通过对象点号成员或指针箭头成员访问。成员类型须满足完整对象类型等声明约束。'}>成员（member）</Term> 可以是标量、数组或另一个完整结构体等对象类型；结构体最后还可按规则使用一个柔性数组成员。初始化可用 C99 指定初始化：

```c
struct book gift = { .title = "Demo", .price = 0.0f, .pages = 120 };
```

<StructMemoryLayoutDiagram />

实现为满足 <Term def="对象类型对存储地址倍数的实现要求；实现可在结构成员之间和末尾插入填充以满足成员及结构数组元素的对齐。">对齐（alignment）</Term> 可以在成员间和结构尾部插入 padding。结构体开头不会有未命名填充，非位字段成员地址按声明顺序递增，但具体偏移与 `sizeof(struct book)` 由实现决定。序列化不能把字段大小简单相加来猜布局。

## 结构体数组

数组元素可以是 struct，元素在内存中**一个接一个**：

```c
struct book shelf[3];
shelf[0].price = 19.9;
shelf[1].pages = 400;
```

若 `sizeof(struct book)` 为 52，则 `shelf[1]` 的起始地址比 `shelf[0]` 大 52 字节。这与「数组元素等宽连续」的规则一致，只是元素类型变「宽」了。

### 嵌套结构：成员本身也是完整记录

<Term def="把一个完整结构体对象声明为另一个结构体的成员；外层对象按值拥有内层对象，并用连续点号逐层访问。">嵌套结构</Term> 适合把可复用子记录组合起来：

```c
struct date {
    int year, month, day;
};

struct loan {
    struct book item;
    struct date due;
};

struct loan current = {
    .item = { .title = "C11", .price = 39.0f, .pages = 320 },
    .due = { .year = 2026, .month = 7, .day = 31 }
};
```

访问到期月份写 `current.due.month`。内层结构按值属于外层对象，不是自动分配的指针；复制 current 会连同 item 与 due 的成员一起复制。

## 结构指针：`.` 与 `->`

结构体可以按值传入函数，语义上得到独立副本；是否产生实际内存拷贝由优化器决定。需要观察同一对象或避免在接口中复制大记录时，可传 <Term def={'指向 struct 实例的指针；只有指向生存期内有效且满足对齐的对象时，才能通过箭头或先解引用后点号访问。'}>结构体指针</Term>：

```c
void show_price(const struct book *pb) {
    printf("%.2f\n", pb->price);
}

struct book b = { "Demo", 25.0f, 200 };
show_price(&b);
```

    对**结构体变量**用 **`.`**：`b.price`。左操作数必须是 struct 类型，不是指针。
  </Step>
  <Step title="第二步：取地址">
    <StructPointerAccessDiagram step={2} />
    **`&b`** 得到指向整个 b 对象的指针，类型为 struct book 指针。结构地址与其首个非位字段成员地址在适当转换后可比较相等，但两者类型和可访问范围不同。
  </Step>

    对**指针**用 **`->`**：`pb->price` 等价于 `(*pb).price`。函数形参常用 `const struct book *` 避免修改且避免拷贝。
  </Step>
</Stepper>

## 函数与结构：值传递、返回值和指针借用

<Term def="结构体对象可像标量一样作为实参按值传递、由函数返回或赋值；语义上复制成员值，源对象与目标对象随后独立。">结构体值传递</Term> 适合小型值对象：

```c
struct point { double x, y; };

struct point translated(struct point value, double dx, double dy) {
    value.x += dx;
    value.y += dy;
    return value;
}

int main(void) {
    struct point origin = {0.0, 0.0};
    struct point moved = translated(origin, 2.0, 3.0);
    return origin.x != 0.0 || moved.x != 2.0;
}
```

结构体赋值和传值包含数组成员的值，但 padding 字节不属于可移植值语义，不能用 memcmp 代替逐成员相等比较。对于借用接口，`const struct book *` 表示函数不经该指针修改对象；调用者仍负责保证指针非空（若契约要求）、对齐正确且在整个调用期间指向生存期内对象。需要函数修改调用方结构时，才传非 const 指针并在接口中说明修改哪些成员。

## typedef：给类型起别名

`struct book` 每次都要写两个单词。可用 <Term def="为已有类型创建别名；不创建新类型，只是语法糖。如 typedef struct book Book;">typedef</Term> 简化：

```c
typedef struct book {
    char title[40];
    float price;
    int pages;
} Book;

Book novel;           /* 等价 struct book novel; */
Book *ptr = &novel;
```

C11 也允许：

```c
typedef struct book Book;
struct book { ... };
```

对 enum 同样适用：`typedef enum { RED, GREEN } Color;`。别名不改变内存布局，只让声明更短、可读性更好。

### 结构体复合字面量：在表达式里创建对象

C99 的 <Term def="以括号类型名加初始化列表创建未命名结构体或联合体对象；块作用域对象具有自动存储期，可在包含块结束前取址使用。">结构体复合字面量</Term> 可以直接作为函数实参：

```c
void show_book(const struct book *value);

show_book(&(struct book){
    .title = "Temporary",
    .price = 12.5f,
    .pages = 96
});
```

这不是“只活到分号”的临时值：块作用域复合字面量对象生存到包含块结束，文件作用域复合字面量则具有静态存储期。但保存其地址并在对应生存期结束后使用仍会悬空。

## 联合体 union：同一块内存，多种解释

<Term def="所有成员重叠于同一存储并具有相同起始地址；大小足以容纳最大成员且还可能因对齐含尾部填充。">联合体（union）</Term> 与 struct 相反——成员重叠而非顺排：

```c
union hold {
    int i;
    float f;
    char c;
};

union hold u;
u.i = 65;
printf("%d\n", u.i);   /* 65 */
```

<UnionMemoryDiagram />

写入 `u.i` 后再读 `u.f` 不是把整数数值转换为浮点数，而是让另一成员类型解释相应对象表示。结果依赖 int 与 float 表示；若形成陷阱表示，求值可能产生未定义行为。只有联合体内若干结构共享的“共同初始序列”等标准特例可跨当前成员可靠观察。需要数值转换应写强制转换，需要可移植字节编码应定义格式并逐字段处理。

联合体本身不记录“当前是哪种含义”，程序应使用 enum 判别字段构成 tagged union，并在写 payload 时同步更新标签、在读 payload 前先检查标签。

典型用途：嵌入式寄存器位域、网络协议里多种 payload 互斥、在 int/float 间复用 4 字节以省内存。

## 枚举 enum：命名整数常量

<Term def="声明一组具名枚举常量并形成枚举类型；C11中各枚举常量具有int类型，枚举类型与char或某个有符号或无符号整数类型兼容，具体由实现选择。">枚举（enum）</Term> 替代魔法数字：

```c
enum color { RED, GREEN, BLUE, YELLOW };
enum color c = GREEN;

switch (c) {
    case RED:   puts("红"); break;
    case GREEN: puts("绿"); break;
    default:    break;
}
```

<EnumDiagram />

可显式赋值：`enum { JAN = 1, FEB, MAR };` 则 FEB=2。C11 要求枚举常量可表示为 int；枚举对象的兼容整数类型由实现选择。不要依赖 `sizeof(enum color) == sizeof(int)`，也不要把任意 int 都当成合法业务状态；进入 switch 前仍应验证外部数据。

## 代码详解：图书管理小片段

### 定义与 typedef

```c
typedef struct {
    char isbn[14];
    float price;
    int stock;
} Item;

Item inv = { "978-013", 59.0f, 10 };
```

### 结构体数组与指针传参

```c
void restock(Item *p, int add) {
    if (p != NULL)
        p->stock += add;
}

Item warehouse[100];
warehouse[0].stock = 5;
restock(&warehouse[0], 20);
```

### union 与 enum 配合（ tagged union 思路）

```c
enum ValueKind { VK_INT, VK_FLOAT };

struct Value {
    enum ValueKind kind;
    union {
        int i;
        float f;
    } data;
};

struct Value v;
v.kind = VK_INT;
v.data.i = 42;
/* 读 v.data.i 前应先检查 v.kind == VK_INT */
```

## 容易踩的坑

<Callout type="trap">
  **现象**：`scanf("%s", s.title)` 写 struct 里的 char 数组，超长书名溢出。
  **原因**：`title` 只是定长数组，与单独 char 数组一样无边界保护。
  **修法**：单词输入至少用与容量匹配的宽度并检查返回值，如 `scanf("%39s", s.title) == 1`；含空格标题使用 fgets，并检测换行或截断后再解析。
</Callout>

<Callout type="trap">
  **现象**：对 struct 指针 `pb` 写 `pb.price` 编译报错。
  **原因**：**`.` 用于 struct 变量**，**`->` 用于 struct 指针**；混用是语法错误。
  **修法**：改为 `pb->price`，或 `(*pb).price`。
</Callout>

<Callout type="trap">
  **现象**：union 写入 `u.i` 后读 `u.f`，得到奇怪的小数。
  **原因**：成员共享存储，读取 float 是用 float 类型解释 int 写入后的对象表示，并非数值转换；结果依赖实现，甚至可能形成陷阱表示。
  **修法**：业务变体用 enum 标签记录并验证当前成员；数值转换用显式转换，持久化编码则逐字段定义表示。
</Callout>

<Callout type="trap">
  **现象**：`fwrite(&s, sizeof s, 1, fp)` 在另一台机器 `fread` 后成员错乱。
  **原因**：结构体有实现定义的 padding、成员宽度、字节序和浮点表示，指针成员更没有跨进程意义；未初始化 padding 还可能泄露内存片段。
  **修法**：定义版本、字段宽度、字节序、长度和编码后逐字段序列化。文本格式也要定义字符编码、转义和数值语法。
</Callout>

## 小结

- **struct** 把相关成员打包；**`.`** 访问变量成员；数组元素连续存放
- 嵌套结构按值拥有子记录；结构体可赋值、传值和返回，padding 不参与可移植相等语义
- const 结构体指针表达只读借用；**`->`** 访问指针成员且要求有效生存期
- **typedef** 为 struct/enum 起别名，不新造类型
- 复合字面量创建有明确存储期的未命名对象，不一定只活到当前表达式
- **union** 成员重叠但不自带标签；enum 判别字段决定当前允许读取的 payload
- C11 枚举常量是 int，枚举类型的兼容整数类型由实现选择

<Exercises>

**问题 1（问答型）** `struct { char a; double b; }` 的 sizeof 为什么往往大于 9？

<Answer>

**char** 占 1 字节后，**double** 常要求 8 字节对齐，编译器在 `a` 后插入 **padding**；末尾也可能 padding 到 8 的倍数。故 sizeof 常为 **16**（依平台而异），而非 1+8。

</Answer>

**问题 2（改代码型）** 下面哪里错了？如何改？

```c
struct Point { int x; int y; };
struct Point *pp;
pp.x = 1;
```

<Answer>

pp 是未初始化指针，既没有指向对象，又错误使用了点号。改成让它指向一个真实对象后使用箭头：

```c
struct Point point = {0, 0};
struct Point *pp = &point;
pp->x = 1;
```

</Answer>

**问题 3（综合实现型）** 用 typedef 定义 `Student { char name[32]; int id; }`，声明含 3 个元素的数组，初始化第二名 id=1002，写函数 `void print_id(const Student *s)` 打印 id。

<Answer>

```c
#include <stdio.h>

typedef struct {
    char name[32];
    int id;
} Student;

void print_id(const Student *s) {
    if (s) printf("%d\n", s->id);
}

int main(void) {
    Student class[3] = { {"Ann", 1001}, {"Bob", 1002}, {"Cy", 1003} };
    print_id(&class[1]);  /* 1002 */
    return 0;
}
```

</Answer>

</Exercises>

## 名词解释

<Glossary>

<GlossaryItem term="结构体（struct）">
  用户自定义类型，包含多个成员；成员顺序存储，可能有 padding。见 StructMemoryLayoutDiagram。
</GlossaryItem>

<GlossaryItem term="成员（member）">
  struct 或 union 内部的具名字段；用点号或箭头访问。
</GlossaryItem>

<GlossaryItem term="对齐（alignment）">
  类型对对象地址倍数的实现要求。实现可在结构成员之间和末尾插入 padding，以满足成员及结构数组元素的对齐。
</GlossaryItem>

<GlossaryItem term="结构体指针">
  指向 struct 的指针；函数传参避免拷贝；用 -> 访问成员。
</GlossaryItem>

<GlossaryItem term="typedef">
  为已有类型创建别名，如 typedef struct book Book; 简化声明。
</GlossaryItem>

<GlossaryItem term="联合体（union）">
  成员共享起始地址与存储，大小足以容纳最大成员且可能含尾部填充。业务代码通常用枚举标签记录当前允许读取的成员。
</GlossaryItem>

<GlossaryItem term="枚举（enum）">
  命名枚举常量集合。C11 枚举常量具有 int 类型，枚举类型与某种整数类型兼容，具体选择由实现决定。见 EnumDiagram。
</GlossaryItem>

<GlossaryItem term="嵌套结构">
  一个结构体对象作为另一个结构体的成员。外层按值拥有内层记录，使用连续点号逐层访问，复制外层也复制内层成员值。
</GlossaryItem>

<GlossaryItem term="结构体值传递">
  结构体可作为实参按值传递、作为返回值或用于赋值，语义上复制成员值。padding 字节不应参与可移植相等比较。
</GlossaryItem>

<GlossaryItem term="结构体复合字面量">
  以 `(struct 类型){初始化项}` 创建未命名对象。块作用域对象生存到包含块结束，文件作用域对象具有静态存储期。
</GlossaryItem>

</Glossary>
