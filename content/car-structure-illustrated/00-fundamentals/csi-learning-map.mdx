## 学习目标

- 理解《汽车构造与知识全图解》全书的五大学习阶段与十章学习路径
- 掌握从发动机到传动到底盘到车身到安全的系统演进逻辑
- 明确各章节之间的依赖关系与核心脉络
- 建立汽车构造知识的五层系统视角（认知层、动力层、底盘层、车身层、系统层）

## 核心概念

### 五大学习阶段

《汽车构造与知识全图解》按照由浅入深、从原理到应用的原则，将全书内容划分为五个学习阶段：

1. **基础认知**：理解知识全景，掌握汽车基本构成与分类
2. **动力传动**：掌握发动机、变速器、传动系统三大核心动力部件
3. **底盘系统**：学习悬架、转向、制动三大底盘系统
4. **车身电子**：掌握车身结构、内饰、电气电子系统
5. **系统与复习**：学习空调舒适性、安全系统，全书复习形成系统闭环

### 十章学习路径

十章内容沿着认知主线层层递进：

- 第 0 章（本章）：知识全景图，总览学习路径
- 第 1 章：发动机系统，掌握四冲程与两大机构五大系统
- 第 2 章：变速器与传动系统，理解动力传递与四种变速器
- 第 3 章：底盘与悬架，掌握悬架类型与底盘四大系统
- 第 4 章：转向与制动系统，学习转向原理与ABS制动
- 第 5 章：车身与内饰，理解车身结构与内饰系统
- 第 6 章：电气与电子系统，掌握电源、ECU与CAN总线
- 第 7 章：空调与舒适性系统，学习制冷循环与NVH
- 第 8 章：安全系统，掌握主动安全与被动安全
- 第 9 章：全书复习与知识整合，形成系统闭环

### 核心脉络

全书的核心理念可以概括为一条认知主线：

**构造概览 → 发动机 → 变速传动 → 底盘悬架 → 转向制动 → 车身内饰 → 电气电子 → 空调舒适 → 安全系统 → 知识闭环**

每个阶段都建立在前一阶段的基础上。构造概览是认知基座，不理解汽车基本构成就无法理解各系统分工；发动机是动力来源，不理解四冲程就无法理解动力输出特性；变速传动是动力传递，不理解传动比就无法理解车辆行驶原理；底盘悬架是支撑基础，不理解悬架就无法理解车辆舒适性；转向制动是操控核心，不理解ABS就无法理解主动安全；车身内饰是物理承载，不理解车身结构就无法理解碰撞安全；电气电子是神经中枢，不理解ECU就无法理解现代汽车控制；空调舒适是乘坐体验，不理解制冷循环就无法理解温控；安全系统是生命保障，不理解主被动安全就无法理解汽车安全体系。

## 术语表

| 术语 | 含义 |
|------|------|
| 四冲程 | 进气、压缩、做功、排气四个活塞行程循环 |
| 传动比 | 主动轮与从动轮转速之比 |
| 悬架 | 连接车轮与车身的弹性支撑与减振系统 |
| ABS | 防抱死制动系统，紧急制动时保持转向能力 |
| ECU | 电子控制单元，汽车各子系统的控制核心 |
| CAN 总线 | 控制器局域网，ECU 之间的串行通信总线 |
| NVH | 噪声、振动、声振粗糙度，衡量舒适性 |
| ADAS | 高级驾驶辅助系统，主动安全进阶 |
| 承载式车身 | 无独立车架，车身即承力结构 |
| 溃缩吸能 | 碰撞时前后舱变形吸收能量保护乘员 |
