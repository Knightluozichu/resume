## 学习目标

- 理解四冲程发动机的工作循环（进气、压缩、做功、排气）
- 掌握曲柄连杆机构与配气机构的工作原理
- 了解燃料供给、点火、冷却、润滑、起动五大系统
- 理解发动机能量转换：化学能到热能到机械能

## 核心概念

### 四冲程工作循环

汽油发动机采用奥托循环，通过四个活塞行程完成一个工作循环。四冲程循环一次，曲轴旋转两圈（720度），做功一次：

1. **进气冲程**：活塞从上止点下行到下止点，进气门打开，排气门关闭，气缸容积增大产生负压，将空气与汽油的混合气吸入气缸
2. **压缩冲程**：进排气门全部关闭，活塞从下止点上行到上止点，压缩混合气至高温高压状态，为燃烧做准备
3. **做功冲程**：压缩接近上止点时火花塞点火，混合气燃烧膨胀，高温高压气体推动活塞下行做功，这是唯一输出动力的冲程
4. **排气冲程**：排气门打开，进气门关闭，活塞从下止点上行到上止点，将燃烧后的废气排出气缸

### 两大机构

发动机的两大机构是实现能量转换的物理基础：

**曲柄连杆机构**：将活塞的直线往复运动转化为曲轴的旋转运动。核心部件包括活塞（承受燃气压力）、连杆（传递力并转换运动形式）、曲轴（输出旋转动力）、飞轮（储存能量使非做功冲程顺利通过）。

**配气机构**：按时开闭进排气门，实现气缸的换气过程。核心部件包括凸轮轴（控制气门开闭时机和升程）、气门（进排气通道的开关）、挺柱/摇臂（传递凸轮运动）、正时链条/皮带（同步曲轴与凸轮轴的传动）。

### 五大系统

发动机正常运转依赖五大辅助系统协同工作：

- **燃料供给系统**：将燃油与空气按最佳空燃比（理论值14.7:1）混合后供入气缸。现代汽车采用电控燃油喷射（EFI），由ECU根据传感器信号精确控制喷油量
- **点火系统**：在压缩冲程末期产生高压电火花点燃混合气。核心部件包括点火线圈（升压至1-3万伏）、火花塞（产生电弧）、分电器或直接点火系统
- **冷却系统**：维持发动机在最佳工作温度（85-105摄氏度）。水泵驱动冷却液循环，散热器与风扇散热，节温器控制大/小循环
- **润滑系统**：机油泵将机油输送到各摩擦表面，实现减磨、降温、密封、清洗、防锈。机油滤清器过滤金属碎屑
- **起动系统**：起动机将蓄电池的电能转化为机械能，带动发动机从静止达到最低稳定转速（约200-300rpm）实现自主运转

### 能量转换链

发动机的本质是能量转换装置：

**化学能**（燃料的C-H键）→ **热能**（燃烧释放）→ **机械能**（曲轴旋转输出）

热效率是衡量发动机性能的核心指标，汽油机热效率约30-40%，其余能量以热和排气形式损失。

## 术语表

| 术语 | 含义 |
|------|------|
| 上止点/下止点 | 活塞在气缸中运动的最高/最低位置 |
| 压缩比 | 气缸最大容积与最小容积之比 |
| 空燃比 | 空气质量与燃油质量之比，理论值14.7:1 |
| 热效率 | 燃料化学能转化为机械能的比例 |
| 配气相位 | 进排气门开闭时刻相对于曲轴转角的关系 |
| EFI | 电控燃油喷射系统 |
| 涡轮增压 | 利用废气驱动涡轮压入更多空气提高功率 |
| 气缸排列 | 直列/L型/V型/水平对置等排列方式 |
| 排量 | 所有气缸工作容积之和 |
| 扭矩 | 发动机输出的旋转力矩 |

## 练习题

1. 描述四冲程发动机的四个冲程，并说明每个冲程气门的状态和活塞的运动方向。
2. 曲柄连杆机构如何将活塞的直线运动转化为曲轴的旋转运动？
3. 五大系统各自的作用是什么？如果冷却系统失效会引发什么后果？
4. 发动机的能量转换链是什么？热效率受哪些因素影响？
5. 空燃比为什么是14.7:1？过浓和过稀分别有什么影响？
