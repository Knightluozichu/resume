## 学习目标

- 掌握手动MT、自动AT、无级CVT、双离合DCT四种变速器的结构与特点
- 理解动力从发动机到驱动轮的完整传递路径
- 了解五种常见驱动型式（FF/FR/MR/RR/AWD）的优缺点
- 掌握传动比的概念与变速器的核心功能

## 核心概念

### 变速器的核心功能

变速器是动力传递系统的核心，承担三大功能：

1. **变速变扭**：通过不同齿比的齿轮组，改变发动机输出转速和扭矩。低速挡减速增扭（爬坡加速），高速挡超速减扭（巡航省油）
2. **改变转向**：通过倒挡齿轮实现车辆倒退行驶
3. **切断动力**：通过空挡切断发动机与驱动轮的动力连接

传动比 = 从动轮齿数 / 主动轮齿数。传动比大于1为减速增扭，小于1为超速减扭。

### 四种变速器对比

四种主流变速器各有优劣，适用于不同场景：

**手动变速器（MT）**：采用齿轮组配合干式离合器，由驾驶员手动操作换挡。传动效率最高（约95%），结构简单成本低，但操作强度大，城市拥堵驾驶疲劳。

**自动变速器（AT）**：采用液力变矩器配合行星齿轮组，由液压控制系统自动换挡。液力变矩器实现柔性传力，换挡平顺舒适，但传动效率较低（约86%），油耗略高。

**无级变速器（CVT）**：采用钢带或链条在两组锥轮之间传动，传动比连续无级变化。没有换挡冲击，加速平顺，燃油经济性优秀，但承受扭矩有限，不适合大功率车型。

**双离合变速器（DCT）**：采用两个离合器分别控制奇数挡和偶数挡，一个挡位工作时下一个挡位已预先挂好。换挡速度极快，传动效率高（约92%），运动感强，但低速偶有顿挫。

### 动力传递路径

以前置后驱（FR）为例，动力传递经历七个环节：

**发动机**（动力源）→ **离合器**（接合/切断动力）→ **变速器**（变速变扭）→ **传动轴**（传递动力）→ **主减速器**（减速增扭）→ **差速器**（分配左右轮动力）→ **驱动轮**（车辆行驶）

差速器是传动系统的关键部件，允许左右驱动轮以不同转速旋转，使车辆在转弯时内侧轮转慢、外侧轮转快，避免轮胎磨损和操控异常。

### 驱动型式

五种常见驱动型式各有特点：

- **FF 前置前驱**：发动机前置、前轮驱动。空间利用率高、成本低、雨雪天前轮抓地好，但急加速易转向不足。绝大多数家用轿车采用
- **FR 前置后驱**：发动机前置、后轮驱动。前后重量分配均衡、操控性好、转向特性中性，但传动轴占空间。运动型轿车常见
- **MR 中置后驱**：发动机中置（乘员舱后方）、后轮驱动。重心低、转动惯量小，运动性能极致，但乘员空间受限。超级跑车首选
- **RR 后置后驱**：发动机后置、后轮驱动。结构紧凑、爬坡能力强，但后轴载荷大、操控难度高。保时捷911代表
- **AWD 全轮驱动**：四个车轮均为驱动轮。抓地力最强、通过性好、全天候适应，但结构复杂、油耗略高。SUV和性能车常用

## 术语表

| 术语 | 含义 |
|------|------|
| 传动比 | 从动轮齿数与主动轮齿数之比 |
| 液力变矩器 | AT 中以液体为介质传递动力的柔性联轴器 |
| 行星齿轮 | AT 中实现自动变速的齿轮机构 |
| 差速器 | 允许左右车轮不同转速旋转的装置 |
| 主减速器 | 传动系统末端的减速增扭齿轮 |
| 离合器 | 接合或切断发动机与变速器动力连接 |
| 同步器 | MT 中使换挡齿轮转速同步的装置 |
| 驱动型式 | 发动机位置与驱动轮位置的组合 |
| 半轴 | 差速器到驱动轮的动力传递轴 |
| 分动器 | AWD 中将动力分配到前后轴的装置 |
