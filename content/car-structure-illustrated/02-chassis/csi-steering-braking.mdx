## 核心概念

### 转向系统

转向系统的功能是改变或恢复汽车的行驶方向，使驾驶员通过方向盘控制车轮偏转。

转向传递路径：**方向盘** → **转向柱**（传递扭矩+角度调节+吸能）→ **转向器**（减速增扭+改变运动方向）→ **横拉杆**（传递推拉力）→ **转向节**（带动车轮偏转）

转向器是核心部件，将方向盘的旋转运动转化为横拉杆的直线运动。常见类型有齿轮齿条式（轿车最常用）和循环球式（商用车）。

**转向比** = 方向盘转角 / 车轮偏转角。转向比越大转向越省力但圈数越多，转向比越小转向越灵敏但越费力。一般轿车转向比约15-20:1，方向盘从左打死到右打死约3-4圈。

### 助力转向

现代汽车配备助力转向系统减轻驾驶员操作强度：

- **EPS 电动助力**：电机直接安装在转向柱或齿条上提供辅助力。结构简单、节能环保、可变助力（低速轻便高速沉稳），是当前主流方案
- **EHPS 电液助力**：电机驱动液压泵提供液压助力。保留液压助力手感好的优点，但电机驱动更节能

### 制动系统

制动系统的功能是使汽车减速或停车、在下坡时保持车速、在驻车时保持静止。

制动传递路径：**制动踏板** → **制动主缸**（将脚踏力转化为液压力）→ **制动液**（传递压力至各轮）→ **制动轮缸**（液压力推动摩擦片）→ **制动器**（摩擦产生制动力）

### 两种制动器

**盘式制动器**：制动盘随车轮旋转，卡钳固定。制动时卡钳活塞推动摩擦片夹紧制动盘，产生摩擦力。散热好（开放式结构）、热稳定性好、响应快、水恢复性好，是现代轿车前后轮的主流选择。

**鼓式制动器**：制动鼓随车轮旋转，制动蹄固定在底板上。制动时轮缸推动制动蹄外张压紧制动鼓内壁。制动力大（自增力效应）、成本低、密封性好，但散热差、热衰退严重、水恢复性差。多用于商用车后轮或经济型车后轮。

### ABS 防抱死制动系统

ABS 是最重要的主动安全系统之一。当紧急制动时，如果制动力过大导致车轮抱死（完全停止旋转在路面滑移），车辆将失去转向能力且制动距离可能增加。ABS 通过三阶段循环控制防止车轮抱死：

1. **增压阶段**：踩下制动踏板，制动压力正常增大，车轮减速正常制动
2. **保压阶段**：ECU 通过轮速传感器检测到车轮接近抱死临界点（滑移率约15-25%），ABS 电磁阀关闭保持压力不变
3. **减压阶段**：如果车轮滑移率继续增大超过阈值，ABS 电磁阀开启减压通道降低制动压力，防止车轮完全抱死

减压后车轮转速恢复，系统再次进入增压阶段。三阶段循环每秒约15-20次，使车轮始终处于「即将抱死但未抱死」的最佳制动状态。

**ABS 的核心价值**：
- 保持转向能力（车轮未抱死仍可转向避障）
- 缩短制动距离（在大多数路面上）
- 防止侧滑和甩尾（维持方向稳定性）

### 制动辅助系统

在ABS基础上，现代制动系统还配备：
- **EBD 电子制动力分配**：根据载荷和路面条件自动分配前后轮制动力，避免后轮先抱死
- **BA 制动辅助**：检测紧急制动时驾驶员踏板力不足，自动增加制动力至最大

## 术语表

| 术语 | 含义 |
|------|------|
| 转向比 | 方向盘转角与车轮偏转角之比 |
| EPS | 电动助力转向系统 |
| 齿轮齿条式转向器 | 齿轮旋转带动齿条直线运动的转向器 |
| 制动主缸 | 将脚踏力转化为液压力的部件 |
| 制动液 | 传递制动压力的液压油 |
| 盘式制动器 | 摩擦片夹紧制动盘产生制动力 |
| 鼓式制动器 | 制动蹄外张压紧制动鼓产生制动力 |
| ABS | 防抱死制动系统 |
| 滑移率 | 车轮滑动速度与车速之比 |
| 热衰退 | 高温下制动力下降的现象 |
