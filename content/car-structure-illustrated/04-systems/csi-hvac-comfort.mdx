## 学习目标

- 掌握空调制冷循环的四大部件与工作原理
- 理解燃油车余热制热与电车热泵制热的差异
- 了解NVH降噪工程的技术手段
- 理解舒适性系统的多维评价指标

## 核心概念

### 空调制冷循环

汽车空调制冷基于蒸汽压缩式制冷循环，由四大部件构成闭合回路：

<CsiHvacComfortDiagram />

1. **压缩机**：由发动机皮带驱动（燃油车）或电机驱动（电车），将低温低压气态制冷剂压缩为高温高压气态。这是制冷循环的唯一动力源，消耗能量做功。

2. **冷凝器**：安装在车头散热器前方，高温高压气态制冷剂流经冷凝器管路，向外界空气散热后凝结为高温高压液态。冷凝器需要迎风气流冷却，所以开空调时风扇会高速运转。

3. **膨胀阀**（或节流孔管）：高温高压液态制冷剂经过膨胀阀的狭窄通道节流降压，压力骤降导致部分液态闪蒸为气态，整体变为低温低压的雾状液气混合物。膨胀阀根据蒸发器出口温度自动调节开度，控制制冷剂流量。

4. **蒸发器**：安装在车内仪表台内，低温低压液态制冷剂在蒸发器中吸收流过空气的热量，蒸发为低温低压气态。被夺走热量的空气变冷，由鼓风机吹入车内实现制冷。

气态制冷剂返回压缩机，完成闭合循环。常用制冷剂为R134a，新型环保制冷剂为R1234yf（GWP值更低）。

### 制热原理

燃油车和电动汽车的制热方式完全不同：

**燃油车余热制热**：利用发动机冷却液（85-105摄氏度）的热量，冷却液流经暖风水箱（小型散热器），鼓风机将空气吹过暖风水箱加热后送入车内。无需额外消耗能量，是「废物利用」。

**电车热泵制热**：没有发动机余热可用，采用热泵系统（制冷循环逆转）从外界空气吸热泵入车内。COP（制热能效比）约2-3，比PTC直接加热（COP=1）高效。极寒条件下热泵效率下降，PTC电加热作为辅助。

### 自动空调控制逻辑

自动空调通过闭环控制维持设定温度：

设定温度 → 车内/车外温度传感器反馈 → 空调ECU计算温差 → 调节压缩机功率/鼓风机风量/出风温度/出风方向 → 达到目标温度

高级自动空调支持多区独立温控（双区/三区/四区），不同乘员可设置不同温度。

### NVH 降噪工程

NVH 是衡量汽车舒适性的核心指标之一，包含三个维度：

- **Noise 噪声**：发动机噪声、风噪、胎噪、路噪
- **Vibration 振动**：发动机振动、路面振动、传动系统振动
- **Harshness 声振粗糙度**：低频振动和冲击引起的主观不适感

降噪技术手段：
- **隔声**：密封条阻隔声波传入、隔音棉吸收中高频、双层夹胶玻璃阻隔风噪
- **隔振**：液压发动机悬置吸收发动机振动、悬架橡胶衬套隔绝路面振动
- **吸声**：顶棚/门板多孔材料吸收声波能量
- **主动降噪ANC**：扬声器播放反相声波抵消低频发动机噪声
- **源头治理**：优化发动机悬置、轮胎花纹、车身气动造型

### 舒适性系统

除空调和NVH外，舒适性还包括：

**座椅舒适**：加热（电阻丝加热）、通风（风扇吸入空气穿过座垫）、按摩（气袋/电机）、电动调节（记忆位置）、材质（Nappa皮革/Alcantara）。人体工程学设计确保长途驾驶不疲劳。

**空气质量**：PM2.5高效滤芯过滤颗粒物、活性炭滤芯吸附异味、负离子发生器净化空气、香氛系统提升氛围。部分车型配备空气质量传感器自动切换内外循环。

**温控分区**：双区（左右独立）、三区（前后独立）、四区（四个座位独立），满足不同乘员温度偏好。

### 舒适性评价维度

汽车舒适性是多维度的综合体验：

- **温度**：18-26摄氏度人体最舒适
- **湿度**：40-60%相对湿度最佳
- **噪声**：60分贝以下为宜
- **空气质量**：PM2.5低于35微克/立方米
- **座椅**：支撑性、包裹性、透气性
- **空间**：头部/腿部/肩部空间充裕

## 术语表

| 术语 | 含义 |
|------|------|
| 制冷循环 | 压缩机-冷凝器-膨胀阀-蒸发器闭合回路 |
| 制冷剂 | 循环中吸热放热的工质（R134a/R1234yf） |
| 压缩机 | 驱动制冷循环的动力部件 |
| 冷凝器 | 高压气态制冷剂散热凝结为液态 |
| 膨胀阀 | 节流降压使液态变为低温低压 |
| 蒸发器 | 低温液态蒸发吸收车内热量 |
| 热泵 | 逆转制冷循环从外界吸热制热 |
| COP | 制热/制冷能效比 |
| NVH | 噪声、振动、声振粗糙度 |
| ANC | 主动降噪技术 |
