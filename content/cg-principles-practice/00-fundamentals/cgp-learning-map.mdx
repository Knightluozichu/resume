## 直觉：这不是一本按流水线排序的 API 手册

先预测：为什么书的 Light 在第 26 章，Transformations 却在第 10-13 章，Rasterization 又在第 15 章？因为第三版按“先做出图形，再回到原理与表示，最后求解光传输和系统效率”组织，并允许课程按目标跳转。

官方前言明确指出：本书不是教某个软件怎么操作，而是结合 perception、physics、mathematics、computer science 与 engineering 的原理和实践。学习地图因此不能缩成“像素→变换→光照→动画”一条线。

## 权威版本与完成口径

本项目对应 **Computer Graphics: Principles and Practice, Third Edition**，Addison-Wesley 2013，ISBN `978-0-13-337370-7`。官方目录共 38 章；出版社还特别说明第三版新增/强化 rendering equation、GPU architecture、Monte Carlo probability 与 importance sampling。

<Term def="由出版社或作者发布、可逐章核对版本和标题的目录，是判断内容覆盖而不是只看本地文件数量的基线">权威目录</Term>只证明“应该学什么”。章节通过还要求：核心概念正确、数学可核查、图示有教学作用、练习有答案、失败模式明确，并能通过自动质量门槛。

## 38 章唯一责任表

<CgpChapterOwnershipDiagram />

### A. 导论、感知与交互：`cgp-introduction`

1. **Introduction**；5. **An Introduction to Human Visual Perception**；21. **Interaction Techniques**。

这组回答图形系统为何存在、观察者怎样看见、用户怎样操纵图像与三维对象。感知不是最后“调好看”的附录，interaction 也不是简单输入事件；二者共同定义可用输出。

### B. 二维平台与变换：`cgp-2d-graphics`

2. **Introduction to 2D Graphics Using WPF**；4. **A 2D Graphics Test Bed**；10. **Transformations in Two Dimensions**；12. **A 2D and 3D Transformation Library for Graphics**。

二维页保留 WPF/test bed 的教学意义，但把平台语法与可迁移原理分开：scene graph、affine composition、corner cutting、坐标约定和 transformation library contract。

### C. 三维数学、相机与平台：`cgp-3d-graphics`

3. **An Ancient Renderer Made Modern**；6. **Introduction to Fixed-Function 3D Graphics and Hierarchical Modeling**；7. **Essential Mathematics and the Geometry of 2-Space and 3-Space**；11. **Transformations in Three Dimensions**；13. **Camera Specifications and Transformations**；16. **Survey of Real-Time 3D Graphics Platforms**。

这组从 Dürer renderer 的可见性问题进入向量/点/平面、层次模型、三维变换、camera specification，再比较 fixed-function、programmable pipeline 与完整 engine 的抽象厚度。

### D. 光栅、图像、信号与纹理：`cgp-raster-graphics`

15. **Ray Casting and Rasterization**；17. **Image Representation and Manipulation**；18. **Images and Signal Processing**；19. **Enlarging and Shrinking Images**；20. **Textures and Texture Mapping**；38. **Modern Graphics Hardware**。

这组把 coverage 算法和 image signal 连接起来：连续信号经 sampling/reconstruction 进入像素，texture 又从离散图像回到表面采样；GPU 的 parallelism、memory、latency 与 locality 决定实践形态。

### E. 形状、网格与曲面：`cgp-modeling`

8. **A Simple Way to Describe Shape in 2D and 3D**；9. **Functions on Meshes**；14. **Standard Approximations and Representations**；22. **Splines and Subdivision Curves**；23. **Splines and Subdivision Surfaces**；24. **Implicit Representations of Shape**；25. **Meshes**。

这一组比较 explicit/parametric/implicit/discrete representation。任何表示都要说明可执行 query、approximation error、continuity、conversion、editing 与 storage，而不是只展示模型截图。

### F. 光、材质、颜色与着色器：`cgp-lighting-models`

26. **Light**；27. **Materials and Scattering**；28. **Color**；33. **Shaders**。

这组追踪 spectrum/radiometry、BSDF、human color response 与 GPU shader implementation。线性 radiance、感知颜色和编码像素必须分层，不能把 RGB 常量直接当“光”。

### G. 光传输、求解与可见性：`cgp-rendering-algorithms`

29. **Light Transport**；30. **Probability and Monte Carlo Integration**；31. **Computing Solutions to the Rendering Equation: Theoretical Approaches**；32. **Rendering in Practice**；36. **Visibility Determination**；37. **Spatial Data Structures**。

这组从 rendering equation 到 Monte Carlo、radiosity/path tracing/photon mapping，再落到 depth/ray visibility 和 BVH/grid。算法比较必须同时报告 bias、variance、consistency、memory 与 query/build cost。

### H. 表现性与运动：`cgp-advanced-topics`

34. **Expressive Rendering**；35. **Motion**。

最后一组不等于“杂项”：expressive rendering 用 abstraction、stroke 和 salient feature 传达信息；motion 用 pose interpolation、dynamics integration 与 stability 把静态表示推进时间域。

## 五个视角如何汇合

<Term def="把现实或理想对象转为可计算数据结构和参数，并明确它保留、近似或丢失哪些性质的选择">图形表示</Term>连接五类问题：

1. **感知**：观察者能否识别形状、颜色、深度与运动；
2. **物理**：光、材质、相机和运动遵循什么量与约束；
3. **数学**：坐标、函数、积分、概率和离散化怎样表达问题；
4. **算法**：如何采样、重建、求交、求解与加速；
5. **系统**：平台、GPU、交互、内存和延迟怎样约束实现。

二维 affine transform 可写为齐次矩阵：

$$
\begin{bmatrix}x'\\y'\\1\end{bmatrix}=
\begin{bmatrix}a&c&t_x\\b&d&t_y\\0&0&1\end{bmatrix}
\begin{bmatrix}x\\y\\1\end{bmatrix}.
$$

图像 filter 是 convolution：

$$
(f*h)(x)=\int f(\tau)h(x-\tau)d\tau,
$$

而光传输是方向积分：

$$
L_o=L_e+\int_{\Omega}f_sL_i|n\cdot\omega_i|d\omega_i.
$$

无法解析积分时，Monte Carlo estimator 为：

$$
\hat I_N=\frac{1}{N}\sum_{i=1}^{N}\frac{f(X_i)}{p(X_i)}.
$$

四个公式不是孤立章节：它们分别展示 representation、filter、transport 与 numerical solution 如何逐层衔接。

**基础图形系统路径**：1-4 → 5 → 7-13 → 14-20 → 21-25 → 26-29 → 33 → 35-38。它优先建立可交互 2D/3D 系统，再深入图像、建模、光色和硬件。

**物理渲染路径**：1 → 26 → 5/29 → 10/13 → 15 → 36-37 → 30-32 → 27-28 → 20 → 33/38。它先明确 light/transport，再补 geometry、visibility、probability、materials 与 hardware。

选择任何路径，都应保留“输入 schema → 中间量 → reference → failure case → resource budget”的证据链。

## 常见误区

<Callout type="trap">
**现象 →** 把第三版当成 1990/1996 第二版内容，仍按 SRGP/SPHIGS 或旧章节表复刻。**原因 →** 只认书名，没有锁定 edition/ISBN。**修法 →** 以 2013 第三版官方 38 章目录和新版前言为唯一基线。
</Callout>

<Callout type="trap">
**现象 →** 学习地图列出 38 个标题便宣布覆盖完成。**原因 →** 把索引命中当教学内容。**修法 →** 每章在唯一正文页承载公式、图、算法、失败模式与练习，地图只导航。
</Callout>

<Callout type="trap">
**现象 →** 严格按 1 到 38 顺序读，却无法建立适合目标的依赖。**原因 →** 把出版顺序误认为唯一课程。**修法 →** 选择基础系统或物理渲染路径，并在跳转前检查数学、表示与采样前置。
</Callout>

## 练习

<Exercises>

**问题 1：为什么 Human Visual Perception 应在渲染算法之前参与设计？**

<Answer>
输出质量、sampling threshold、color representation、interaction feedback 与 motion stability 都由观察者感知决定。先定义可见误差和任务，再选择 representation 与算法，才能把计算花在有价值的信号上。
</Answer>

**问题 2：第 18 章 signal processing 与第 29 章 light transport 有什么共同结构？**

<Answer>
两者都把连续函数通过积分算子映射到输出，并面临离散采样与重建。前者常分析 convolution/Fourier 与 aliasing，后者分析 scattering/visibility 与 Monte Carlo；PDF、filter 和误差都必须显式。
</Answer>

**问题 3：怎样证明一个主题页真正承载了分配给它的原书章节？**

<Answer>
逐章建立核心概念、公式/算法、专用图、边界条件、练习与参考结果的对应表；自动目录 matcher 只是索引证据，还要由质量审计和可运行验证证明内容深度与正确性。
</Answer>

**问题 4：为什么 Modern Graphics Hardware 归到光栅与图像页？**

<Answer>
该页从 coverage、image sampling、texture 进入实际 GPU 执行，能直接解释 parallelism、texture/memory latency 和 locality 如何改变 raster/filter 实现；同时学习地图保留它与 shader 和 rendering algorithm 的交叉依赖。
</Answer>

</Exercises>

## 小结

第三版 38 章不是九个摘要主题，而是一套从感知和物理出发，经数学、表示、算法到交互与硬件的完整系统。学习地图负责版本、归属和依赖；真正完成仍要由 8 个正文页逐章交付图解、推导、实现与证据。
