## 直觉引入

想象你在学画画。先学握笔和调色（基础导论），再学画线和图形（2D/3D变换），然后学上色和光影（渲染与光照），最后学雕塑和动画（建模与高级专题）。CGP 就是这本「画画教科书」——从最基础的像素原理一路讲到完整的图形系统。

全书的核心线索是：先理解「像素是什么」（光栅化），再学「怎么移动像素」（变换），然后学「怎么给像素上色」（光照），最后学「怎么让像素动起来」（动画）。

## 代码对照

```cpp
// CGP 的核心：一个像素的诞生
// 1. 建模：定义3D物体
// 2. 变换：投影到2D
// 3. 光栅化：确定覆盖的像素
// 4. 着色：计算像素颜色

// 顶点变换
vec4 clipPos = projection * view * model * vec4(pos, 1.0);
// 透视除法
vec3 ndc = clipPos.xyz / clipPos.w;
// 屏幕映射
vec2 screen = (ndc.xy * 0.5 + 0.5) * screenSize;
```

## 常见误区

<Callout type="trap">
**误区：把 CGP 当 cookbook 翻。**
它是系统教材，每章建立在前一章基础上。跳过光栅化直接学渲染算法，会不理解为什么需要可见性判断；跳过变换直接学3D，会不理解投影矩阵的含义。
</Callout>

<Callout type="trap">
**误区：只看公式不写代码。**
图形学的每个概念都需要在代码中验证。比如透视投影和正交投影的差异，看公式不如写两个渲染器对比效果。CGP 的价值在于理论指导实践。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？它们之间是什么关系？

<Answer>
基础导论、2D/3D图形、渲染光照、高级专题。呈递进关系：基础导论提供领域认知和像素原理，2D/3D图形建立空间变换能力，渲染光照实现视觉真实感，高级专题拓展到建模和动画。
</Answer>

**问题 2**：为什么说「数学是工具，算法是手段，视觉是目标」？

<Answer>
数学（线性代数、微积分）是描述图形变换和光照计算的工具，不懂数学就无法理解变换矩阵和光照公式。算法（光栅化、可见性、采样）是实现渲染效果的手段，将数学公式转化为可执行的计算步骤。视觉（最终图像）是图形学的终极目标——所有数学和算法都服务于「在屏幕上生成正确的图像」。
</Answer>
</Exercises>
