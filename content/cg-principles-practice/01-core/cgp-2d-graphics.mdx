## 直觉引入

想象你在玩俄罗斯方块。按左/右键平移方块，按旋转键旋转方块，按下降键缩放（加速）。这些操作背后都是矩阵乘法——2D图形变换就是用矩阵「操控」图形的位置和形状。

关键洞察：平移不能直接用2x2矩阵表示（它是加法不是乘法），所以引入齐次坐标——用3维向量表示2D点，让平移也能变成矩阵乘法。这样所有变换统一为矩阵乘法，可以组合。

## 概念讲解

### 2D变换与齐次坐标

<Cgp2dGraphicsDiagram />

<Term def="齐次坐标用n+1维向量表示n维点，使仿射变换统一为矩阵乘法">齐次坐标</Term>是2D变换的基础：2D点(x,y)表示为(x,y,1)。

三种基本变换：
- <Term def="平移变换将所有点移动固定距离的变换">平移</Term>：[1 0 tx; 0 1 ty; 0 0 1]
- <Term def="旋转变换绕某点旋转一定角度的变换">旋转</Term>：[cos -sin 0; sin cos 0; 0 0 1]
- <Term def="缩放变换沿坐标轴拉伸或压缩的变换">缩放</Term>：[sx 0 0; 0 sy 0; 0 0 1]

<Term def="仿射变换是平移、旋转、缩放和剪切的组合，保留平行线关系">仿射变换</Term>可以组合：M = M_n x ... x M_1，点右乘矩阵链。

## 代码对照

```cpp
// 2D 变换矩阵组合
#include <cmath>

// 3x3 矩阵用 9 个 float 表示
struct Mat3 { float m[3][3]; };

Mat3 multiply(Mat3 a, Mat3 b) {
    Mat3 result = {};
    for(int i=0; i<3; i++)
        for(int j=0; j<3; j++)
            for(int k=0; k<3; k++)
                result.m[i][j] += a.m[i][k] * b.m[k][j];
    return result;
}

// 先平移(100,50) 再旋转45度 再缩放2倍
Mat3 T = {{{1,0,100},{0,1,50},{0,0,1}}};
float r = 45 * M_PI / 180;
Mat3 R = {{{cos(r),-sin(r),0},{sin(r),cos(r),0},{0,0,1}}};
Mat3 S = {{{2,0,0},{0,2,0},{0,0,1}}};
// 注意顺序：先变换的在右边
Mat3 M = multiply(S, multiply(R, T));
```

## 常见误区

<Callout type="trap">
**误区：认为变换顺序可以交换。**
先平移再旋转 ≠ 先旋转再平移。比如一个在原点的物体：先旋转45度它还在原点，再平移到(100,0)——它到了(100,0)。但如果先平移到(100,0)再旋转45度——它会绕原点旋转45度，跑到(70,70)左右。矩阵乘法不可交换。
</Callout>

<Callout type="trap">
**误区：不理解齐次坐标为什么用3维表示2D。**
2D平移是加法(x+tx, y+ty)，不是乘法，无法用2x2矩阵表示。引入齐次坐标后，(x,y)变成(x,y,1)，平移就变成了矩阵乘法。更深层的原因是：齐次坐标统一了所有仿射变换为矩阵乘法，使它们可以组合和链式应用。
</Callout>

<Exercises>
**问题 1**：齐次坐标的作用是什么？为什么2D变换需要它？

<Answer>
齐次坐标用3维向量(x,y,1)表示2D点，使平移变换也能用矩阵乘法表示。2D平移是加法(x+tx, y+ty)，无法用2x2矩阵表示（矩阵乘法是线性组合，不包含加法）。引入第3个分量w=1后，平移变为[x,y,1]×[1,0,tx; 0,1,ty; 0,0,1] = [x+tx, y+ty, 1]，统一为矩阵乘法。这使得平移、旋转、缩放可以组合成单一矩阵，大幅简化变换链的计算。
</Answer>

**问题 2**：为什么变换顺序不能交换？给出具体例子。

<Answer>
矩阵乘法不可交换，M1×M2 ≠ M2×M1。具体例子：一个在原点的三角形。方案A「先旋转45度再平移到(100,0)」：旋转后仍在原点（旋转不改变原点位置），平移后到达(100,0)。方案B「先平移到(100,0)再旋转45度」：先到(100,0)，然后绕原点旋转45度，到达约(70,70)。两个结果完全不同。实际应用中，变换顺序通常为：先缩放（改变大小）→ 再旋转（改变方向）→ 最后平移（改变位置），即 M = T × R × S。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="齐次坐标">用n+1维向量表示n维点的坐标系统，使仿射变换（包括平移）统一为矩阵乘法。</GlossaryItem>
<GlossaryItem term="仿射变换">平移、旋转、缩放和剪切的组合，保留平行线和平行线段比例关系。</GlossaryItem>
<GlossaryItem term="变换组合">多个变换矩阵相乘得到复合矩阵，顺序为变换执行顺序的逆序（先变换的在右边）。</GlossaryItem>
<GlossaryItem term="变换矩阵">用矩阵表示几何变换的数学工具，2D仿射变换用3x3齐次矩阵表示。</GlossaryItem>
</Glossary>
