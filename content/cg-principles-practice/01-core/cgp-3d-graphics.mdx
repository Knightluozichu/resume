## 直觉引入

想象你在铁轨上拍照。两条平行的铁轨在照片中汇聚到远处的一个点——这就是透视投影。如果你换成俯视图（正交投影），铁轨看起来仍然平行——没有汇聚。

透视投影模拟人眼的视觉：近处物体大，远处物体小。正交投影保持物体大小不随距离变化，适合工程图纸和2D游戏。两者的数学差异就在投影矩阵——透视投影的w分量携带深度信息，正交投影的w恒为1。

## 概念讲解

### 3D投影变换

<Cgp3dGraphicsDiagram />

<Term def="透视投影模拟人眼视角，近处物体大远处物体小的投影方式">透视投影</Term>：x' = x*n/(n-z)，w' = -z。w分量携带深度信息。

<Term def="正交投影保持平行线平行，物体大小不随距离变化的投影方式">正交投影</Term>：x' = (x-l)/(r-l)*2-1，w' = 1。无透视形变。

<Term def="透视除法是将裁剪空间坐标除以w分量得到归一化设备坐标的操作">透视除法</Term>：NDC = clip.xyz / clip.w。这是近大远小效果产生的关键步骤。

<Term def="FOV是视场角，控制相机能看到的范围大小">FOV</Term>（Field of View）和宽高比定义透视投影的视锥。

## 代码对照

```cpp
// 透视投影矩阵生成
mat4 perspective(float fovy, float aspect, float near, float far) {
    float f = 1.0f / tan(fovy / 2.0f);
    mat4 m = mat4(0.0f); // 初始化为0
    m[0][0] = f / aspect;        // x缩放
    m[1][1] = f;                  // y缩放
    m[2][2] = (far + near) / (near - far);  // z映射
    m[2][3] = -1.0f;              // w = -z (关键！)
    m[3][2] = (2 * far * near) / (near - far); // z平移
    return m;
}
// 顶点变换: clipPos = P * V * M * vec4(pos, 1.0)
// 透视除法: ndcPos = clipPos.xyz / clipPos.w
```

## 常见误区

<Callout type="trap">
**误区：认为投影矩阵直接产生屏幕坐标。**
投影矩阵产生的是裁剪空间坐标，还不是屏幕坐标。还需要透视除法（除以w）得到NDC，再视口变换映射到屏幕像素坐标。三步缺一不可。
</Callout>

<Callout type="trap">
**误区：正交投影没有深度信息。**
正交投影的w恒为1（不做透视除法），但z分量仍然映射到[-1,1]范围用于深度测试。正交投影有深度信息，只是没有透视形变（近大远小）。
</Callout>

<Exercises>
**问题 1**：透视投影为什么会产生近大远小？

<Answer>
透视投影矩阵将z分量的信息编码到w分量中（w = -z）。透视除法将x/y/z都除以w：x' = x/w = x/(-z)。当z较小（近处）时，x/w较大（物体显得大）；当z较大（远处）时，x/w较小（物体显得小）。这就是近大远小的数学原理——w分量随深度变化，除以w后坐标被深度缩放。
</Answer>

**问题 2**：透视投影和正交投影各适合什么场景？为什么？

<Answer>
透视投影适合3D游戏、模拟器、虚拟现实——模拟人眼视觉，近大远小让玩家有沉浸感。正交投影适合CAD/建筑设计（保持尺寸比例不变形，方便测量）、2D游戏（无透视干扰，远近物体一样大）、UI渲染（2D元素不应有3D形变）。选择依据：如果需要模拟真实视觉感受用透视；如果需要保持精确尺寸或避免深度形变用正交。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="透视投影">模拟人眼视角的投影方式，近处物体大远处物体小，w分量携带深度信息。</GlossaryItem>
<GlossaryItem term="正交投影">保持平行线平行的投影方式，物体大小不随距离变化，w恒为1。</GlossaryItem>
<GlossaryItem term="透视除法">将裁剪空间坐标除以w分量得到归一化设备坐标(NDC)的操作，是近大远小效果产生的原因。</GlossaryItem>
<GlossaryItem term="FOV">视场角(Field of View)，控制相机能看到的角度范围，影响透视投影的视锥形状。</GlossaryItem>
