## 直觉引入

想象你在看一部电影的发展史。从黑白默片（线框图）到彩色电影（光栅扫描）到3D IMAX（光照模型）到VR/AR（实时交互）。图形学60年的发展就是「让计算机画得越来越像真实世界」的历程。

CGP 的导论章不只是讲故事——它建立了图形学的核心框架：建模（描述世界）、变换（改变视角）、渲染（生成图像）、交互（响应用户）。后面所有章节都在这四个任务上展开。

## 概念讲解

### 图形学核心任务

<CgpIntroductionDiagram />

<Term def="计算机图形学是研究用计算机生成、处理和显示图像的学科">计算机图形学</Term>的四个核心任务：
1. <Term def="建模是用数学方法描述3D物体的形状和属性">建模</Term>：用数学描述3D世界
2. 变换：改变物体位置和视角
3. 渲染：把3D变成2D图像
4. 交互：响应用户输入

<Term def="GPU是专为图形渲染并行计算设计的处理器， thousands of cores for parallel pixels">GPU</Term>的架构本质上是为光栅化和着色的并行计算设计的——每个像素独立计算，天然适合大规模并行。

## 代码对照

```cpp
// 图形学的四个核心任务示意
// 1. 建模：定义一个三角形
struct Triangle { vec3 v[3]; vec3 color; };
Triangle tri = {{{0,0,0}, {1,0,0}, {0,1,0}}, {1,0,0}};

// 2. 变换：旋转45度
mat4 rot = rotationMatrix(Z, PI/4);
for(int i=0; i<3; i++) tri.v[i] = rot * vec4(tri.v[i], 1);

// 3. 渲染：光栅化 + 着色
for(int y=0; y<height; y++)
  for(int x=0; x<width; x++)
    if(pointInTriangle(x, y, tri))
      framebuffer[y][x] = tri.color;

// 4. 交互：鼠标旋转
if(mouseDragged) cameraAngle += deltaX;
```

## 常见误区

<Callout type="trap">
**误区：把图形学等同于「用OpenGL画图」。**
图形学是学科，OpenGL是工具。理解原理（为什么透视投影需要除以w）比记API（glFrustum的参数顺序）重要得多。工具会变，原理不变。
</Callout>

<Callout type="trap">
**误区：混淆图形学、图像处理和计算机视觉。**
图形学：模型→图像（生成）。图像处理：图像→图像（处理，如滤镜）。计算机视觉：图像→模型（理解，如人脸识别）。三者方向不同，CGP聚焦于「生成」方向。
</Callout>

<Exercises>
**问题 1**：图形学的四个核心任务是什么？

<Answer>
建模（用数学描述3D物体的形状和属性）、变换（用矩阵改变物体位置和视角）、渲染（用算法将3D场景生成2D图像）、交互（响应用户输入如鼠标键盘）。这四个任务覆盖了从「描述世界」到「呈现世界」到「与世界交互」的完整链条。
</Answer>

**问题 2**：GPU为什么是为图形学设计的？它与CPU有什么本质区别？

<Answer>
GPU拥有数千个核心，专为大规模并行计算设计。图形学的光栅化和着色阶段天然并行——每个像素独立计算颜色，每个顶点独立变换，互不依赖。CPU只有少数核心但每个核心功能强大，适合串行逻辑控制；GPU核心多但每个简单，适合并行数值计算。这就是为什么图形渲染从CPU迁移到GPU后性能提升了几个数量级。
</Answer>
</Exercises>
