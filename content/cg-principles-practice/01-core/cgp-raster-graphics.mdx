## 直觉引入

想象你在用方格纸画画。一条斜线经过的格子要涂色——但格子是离散的，线是连续的，你只能近似地选择「最接近线的格子」。这就是光栅化的本质：把连续的几何（线、三角形）转换成离散的像素。

锯齿就是这种近似的副作用——边缘出现阶梯状。抗锯齿的思路是：不要只选「是或否」，而是算出「这个像素有多少被线覆盖」，用覆盖率来决定颜色深浅。

## 代码对照

```cpp
// Bresenham 直线光栅化算法
void drawLine(int x0, int y0, int x1, int y1) {
    int dx = abs(x1 - x0), dy = abs(y1 - y0);
    int sx = x0 < x1 ? 1 : -1;
    int sy = y0 < y1 ? 1 : -1;
    int err = dx - dy;
    
    while(true) {
        setPixel(x0, y0);  // 画当前像素
        if(x0 == x1 && y0 == y1) break;
        int e2 = 2 * err;
        if(e2 > -dy) { err -= dy; x0 += sx; }  // 水平步进
        if(e2 <  dx) { err += dx; y0 += sy; }  // 垂直步进
    }
}
// 全整数运算，无浮点，无除法——极致高效
```

## 常见误区

<Callout type="trap">
**误区：认为抗锯齿只是「模糊边缘」。**
抗锯齿是计算像素被图元覆盖的精确比例，然后按比例混合图元颜色和背景颜色。这不是模糊，而是更准确地表示「这个像素一半在线内一半在线外」的真实情况。
</Callout>

<Callout type="trap">
**误区：认为MSAA就是降低分辨率的SSAA。**
MSAA只在几何边缘（三角形边界）处做多次采样，片段着色器只运行一次（用像素中心）。SSAA对整个画面每个像素多次运行着色器。MSAA质量略低但性能远好于SSAA，因为着色器计算是最贵的部分。
</Callout>

<Exercises>
**问题 1**：为什么锯齿是光栅化的必然产物？

<Answer>
光栅化把连续几何（无限精度的线/三角形）转换为离散像素（有限网格）。每个像素只能有一个颜色，但一条斜线可能只覆盖像素的一部分。如果只做「是或否」的判断（像素中心在图元内就涂色），边缘就会出现阶梯状锯齿。这是离散采样连续信号的必然结果，除非像素无限小（分辨率无限高），否则锯齿无法完全消除。
</Answer>

**问题 2**：SSAA和MSAA的原理有什么本质区别？

<Answer>
SSAA（超采样抗锯齿）：以更高分辨率渲染整个画面，然后缩小到目标分辨率。每个子像素都运行片段着色器，计算量是N倍（4xSSAA = 4倍着色器开销）。MSAA（多重采样抗锯齿）：只在几何边缘处做多次采样判断覆盖率，片段着色器只运行一次（用像素中心位置）。MSAA的着色器开销只有1倍，几何判断开销是N倍，因此远快于SSAA。质量上MSAA略低（着色器只用中心位置），但对于大多数场景视觉差异不明显。
</Answer>

<GlossaryItem term="光栅化">将连续几何图元（线、三角形）转换为离散像素的过程，是渲染管线的核心步骤。</GlossaryItem>
