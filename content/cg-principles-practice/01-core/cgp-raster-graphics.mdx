## 直觉：像素不是一块恒定颜色的小方格

先预测：把一张 1024 图像直接每隔四个 texel 取一个得到 256 图像，会保留平均亮度吗？4x MSAA 能消除细密棋盘纹理的闪烁吗？通常不能。pixel 是对某个空间、时间、波长与 aperture 的信号测量，不是连续图像中的方形积木。

Ch15 Ray Casting and Rasterization 产生 samples；Ch17 定义 image 如何存储与合成；Ch18/19 用 signal processing 解释 sampling/reconstruction；Ch20 把图像映射回 surface；Ch38 Modern Graphics Hardware 决定这些操作如何并行、缓存与隐藏延迟。

## Ch15 Ray Casting and Rasterization

<Term def="把连续图元在离散样本位置上的覆盖转换为 fragments/samples，并插值属性供后续深度与着色处理的过程">光栅化</Term>通常遍历 projected primitive 的 bounding box，用 edge function 判断 sample 是否位于 triangle：

$$
E_{ab}(p)=(p_x-a_x)(b_y-a_y)-(p_y-a_y)(b_x-a_x).
$$

三个有一致 orientation 的 edge signs 给 inside test。共享边必须使用一致的 top-left/inclusion rule，才能让相邻 triangle 不重绘或漏缝；subpixel fixed-point、winding、degenerate triangle 与 viewport clipping 都属于算法合同。

<Term def="从每个图像样本发射 ray，并寻找与场景几何的最近有效交点来决定可见表面的成像算法">光线投射</Term>按 pixels/rays 遍历，rasterization 按 primitives/coverage 遍历。两者可产生相同 primary visibility，但工作生成、加速结构、shading order 和 cache behavior 不同。

```cpp
for (Pixel p : triangleBounds(v0, v1, v2)) {
    for (Sample s : samplePattern(p)) {
        Vec3 e = edgeValues(v0, v1, v2, s.position);
        if (!insideWithTopLeftRule(e)) continue;
        Vec3 lambda = e / signedDoubleArea(v0, v1, v2);
        emitFragment(p, s, perspectiveInterpolate(lambda, attributes));
    }
}
```

screen barycentric weights 不能直接线性插值 view-space attribute。若每顶点 clip $w_i$：

$$
a(p)=\frac{\sum_i\lambda_i a_i/w_i}{\sum_i\lambda_i/w_i}.
$$

depth、early tests、sample coverage、fragment shading 与 blend 的顺序受 API/state 和 side effects 影响，不能把整个 raster pipeline 简化为“扫描线填充”。

## Ch17 Image Representation and Manipulation

<Term def="在明确采样位置、通道语义、颜色空间、alpha 约定和数值范围下存储离散二维信号的数据对象">图像表示</Term>至少包含 width/height、channel layout、component type、row stride/origin、color primaries/transfer、alpha mode 和 orientation。丢失 metadata 会让“同一 RGB”显示不同。

alpha 可能表示 coverage、opacity 或其他 mask。straight alpha 存 $(c,\alpha)$；premultiplied alpha 存 $(\alpha c,\alpha)$，over compositing 为：

$$
C_{out}=C_A+(1-\alpha_A)C_B,\qquad
\alpha_{out}=\alpha_A+(1-\alpha_A)\alpha_B.
$$

premultiplied 表示在透明边缘 filtering/compositing 更一致，但要求 texture、blend state、export 和 UI 全链匹配。颜色混合应在线性光量上执行；ID、normal、depth 等数据图像不能套颜色 transfer。

**Image Compositing（图像合成）**把多个带 coverage/opacity 的 image layers 按明确前后关系组合；Porter-Duff operator、premultiplication 与 working color space 必须成套，不能只设置一个 blend factor。

MIP map 属于多尺度 image representation；coverage mask、depth image、normal map、environment map 又有不同 reconstruction 规则。不能把所有 texture 视为“彩色照片”。

## Ch18 Images and Signal Processing

<CgpSamplingDiagram />

连续信号 $f$ 与 filter $h$ 的 convolution：

$$
(f*h)(x)=\int_{-\infty}^{\infty}f(\tau)h(x-\tau)d\tau.
$$

Fourier transform 把 convolution 变成频域乘法，帮助解释 low-pass、band limit 和 aliasing。以频率 $f_s$ 均匀采样，只能无歧义表示低于 Nyquist $f_s/2$ 的 band-limited signal；现实边缘不是 band-limited，所以抗锯齿是近似与预算选择。

<Term def="连续信号的不同频率在离散采样后映射为相同样本序列，产生阶梯、摩尔纹、闪烁等不可逆混叠">走样</Term>不仅发生在几何轮廓，也发生在 texture、normal/specular、shadow、motion 与 procedural shader。post blur 只能隐藏部分结果，不能恢复采样前丢失的频率。

reconstruction 用 kernel 从 samples 估计连续函数。box、triangle/bilinear、cubic、Lanczos 等有不同 support、frequency response、ringing 与 cost。所谓“像素小方格”只是 nearest/box display 的一种可视化。

## Ch19 Enlarging and Shrinking Images

enlarge 主要需要 reconstruction；shrink 在重新采样前必须 low-pass，移除新 Nyquist 以上频率。目标 sample $g[j]$ 可写为输入 samples 的 weighted sum：

$$
g[j]=\sum_i f[i]h\left(\frac{i+0.5}{s}-(j+0.5)\right),
$$

坐标中心、scale 定义与 kernel normalization 要固定。separable 2D filter 将二维 convolution 分成横向和纵向，复杂度显著降低；finite-support approximation 用有限 tap 换取速度，但可能 blur/ringing。

缩小 checkerboard 的测试要比较平均能量、频谱和 moving sequence，而不是只看静态截图。gamma-encoded RGB 直接平均会偏暗/偏色；alpha、normal、depth/min-max map 又需语义专用 downsample。

## Ch20 Textures and Texture Mapping

<Term def="把 surface parameter、方向或三维位置映射到离散 texture signal，并按像素 footprint 过滤重建的过程">纹理映射</Term>包括 UV assignment、seam、tangent construction、addressing、sampling、mip/anisotropy 与 data decode。

texture 不只改变 diffuse color：bump/normal 改 shading normal，displacement 改 geometry，1D/3D/procedural texture 表示不同 domain。parameterization distortion 使相同 texel 在 surface 上覆盖面积不同，atlas seam 与 padding 会影响 mip filtering。

屏幕像素在 texture space 的局部 footprint 可由 Jacobian/derivatives 估计。mip 近似各向同性 prefilter，各向异性 filter 处理斜视椭圆。MSAA 只增加 geometry coverage/depth samples，默认不能解决 texture 或 shader 内高频 aliasing；sample shading 等模式另有成本。

## Ch38 Modern Graphics Hardware

<CgpGpuDataflowDiagram />

第三版以当时 GPU 为实例讲架构，但可迁移原则仍是 parallelism、programmability、texture/memory/latency 与 locality。

<Term def="同一时间维持大量可运行工作组，在一个工作组等待 memory 时调度其他工作，以提高总体完成率的能力">延迟隐藏</Term>不同于让单次 memory access 变快。register/shared/local resource 使用过多会降低 resident groups；occupancy 是手段，不是最终性能分数。

GPU 由 command/front end、shader processors、texture units、raster/setup、depth/blend/output、caches 和 memory controllers 组成，具体 unified/tile-based 架构不同。shader lanes 按 warp/wave/subgroup 共同执行，branch divergence 和不相干访问会降低利用率，但代价必须实测。

<Term def="让相邻时间或空间的工作访问相邻或重复数据，从而提高 cache、compression、coalescing 和片上复用效率的性质">数据局部性</Term>连接算法与硬件：triangle binning、texture footprint、tile render、block compression 和 coherent rays 都在组织 locality。

roofline 近似上限：

$$
P\le\min(P_{compute}, I\,BW),\qquad I=operations/bytes.
$$

但 raster/texture/blend fixed units、cache/compression 和 synchronization 也会成为 roof。性能结论需要 GPU timestamps、pipeline statistics、memory counters 与控制变量实验。

## 常见误区

<Callout type="trap">
**现象 →** 认为 MSAA “只在边缘多采样且 shader 永远只跑一次”。**原因 →** 把典型默认行为当所有 coverage/sample shading/API 状态。**修法 →** 分别记录 coverage、depth/stencil、shading frequency 和 resolve；另测 texture/specular aliasing。
</Callout>

<Callout type="trap">
**现象 →** 缩图直接跳 texel，透明边缘出现黑边。**原因 →** 未 low-pass，且 straight/premultiplied/linear-color 约定不一致。**修法 →** 按信号语义预滤波，统一 alpha 与 transfer，再比较能量和边缘 reference。
</Callout>

<Callout type="trap">
**现象 →** occupancy 未满或 branch 存在就判定 GPU 慢。**原因 →** 用单一 counter 代替 bottleneck 证据。**修法 →** 结合时间、IPC/stall、memory transactions、cache 与工作量缩放，寻找限制 throughput 的真实 roof。
</Callout>

## 练习

<Exercises>

**问题 1：为什么共享三角形边需要统一 inclusion rule？**

<Answer>
边上的 sample 同时满足两个 triangle 的边界。若两边都包含会 double shade/blend，都排除会产生 crack。top-left 等规则让共享边恰好由一侧拥有，并需配合相同 subpixel precision/winding。
</Answer>

**问题 2：放大与缩小为何不能使用同一朴素算法？**

<Answer>
放大主要重建缺失位置；缩小把多个输入频率压入更低采样率，必须先 low-pass 新 Nyquist 以上频率。直接 nearest/bilinear shrink 对高频可能 alias，kernel support 还要随 scale 扩展。
</Answer>

**问题 3：为什么 4x MSAA 不能消除棋盘纹理闪烁？**

<Answer>
MSAA 增加几何 coverage/depth samples，默认 fragment shader/texture signal 可能仍每 pixel 一次。棋盘高频来自 texture footprint，应使用 mip/anisotropic/prefilter 或提高 shading samples，而非只增加 edge coverage。
</Answer>

**问题 4：怎样区分 compute-bound 与 bandwidth-bound？**

<Answer>
保持输出，分别减少 arithmetic、attachment/texture bytes 和 resolution；结合 GPU time、ALU utilization、memory transactions/cache 与 roofline。只有时间斜率和 counters 一致，才支持结论。
</Answer>

</Exercises>

## 小结

Ch15、17-20、38 描述一条完整采样链：geometry 产生 coverage，image 定义样本语义，signal processing 负责 filtering/reconstruction，texture 把图像带回 surface，GPU 用并行与 locality 执行。正确性、走样和性能必须用同一批 reference 与中间量闭环。
