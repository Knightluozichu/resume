## 直觉：不写实也要正确，运动也不只是位置变了

先预测：一张工程插图去掉纹理和阴影后可能更清楚还是更差？同一条轨迹用不同 timestep 播放，物理状态和 motion blur 是否一致？表现性图像的正确性由信息目标决定，运动的正确性由连续模型、离散求解和显示共同决定。

Ch34 Expressive Rendering 研究如何选择、抽象和强化视觉信息；Ch35 Motion 研究随时间变化的 representation、interpolation、dynamics 和 stability。两章都要求把“意图”变成可测试的时空信号。

## Ch34 Expressive Rendering

<Term def="不以摄影真实为唯一目标，而通过选择、抽象、夸张和风格化组织图像信息以传达特定 message 的渲染">表现性渲染</Term>可用于技术插图、地图、医学、故事、可视化和艺术。它不是简单降低 realism；有时要比照片更明确地显示 occluded structure、assembly order 或 shape cue。

设计从三件事开始：viewer/task、message、style constraints。之后才选择 contour、stroke、tone region、abstraction 和 temporal coherence。评价指标可以是 feature recognition、task time、误读率、style match 与 artist control，而非 path-traced reference error。

### Marks、strokes 与显著特征

<Term def="具有位置、方向、宽度、纹理、颜色和时间参数的图形原语，用于表达轮廓、材质、运动或强调">笔触</Term>需要附着于 screen、surface parameter 或 world path。若只在每帧屏幕随机生成，会产生 swimming/flicker；surface coherence 又可能在 silhouette/disocclusion 处断裂。

<Term def="从当前视点看，surface normal 与 view direction 垂直并分隔 front/back-facing 区域的曲线">轮廓线</Term>满足：

$$
n(p)\cdot v(p)=0.
$$

mesh 上可通过相邻 face facing sign 找 silhouette edges；image-space depth/normal edge 便宜但受 resolution、threshold 和遮挡影响。crease、boundary、ridge/valley、suggestive contour 传递不同 shape cues，不能统称“边缘”。

abstraction 可 simplify geometry、merge regions、quantize tone、suppress texture 或 exaggerate feature。每次省略都要检查 message 是否保留；salience model 只是 attention proxy，不自动知道用户任务。

### Toon 与 XToon 只是实例

toon shading 量化 diffuse/specular，XToon 可按 orientation/depth 等额外维度查 ramp。它们属于 shader-level style；完整 expressive system 还需要 geometry curves、stroke placement、layering、composition 和 temporal rules。

```glsl
float ndotl = clamp(dot(normalize(N), normalize(L)), 0.0, 1.0);
float depthCue = remapViewDepth(viewDepth);
vec3 stylized = texture(xToonRamp, vec2(ndotl, depthCue)).rgb;
float edge = contourConfidence(depth, normal, materialId);
outColor = composeStyle(stylized, edge, strokeLayer);
```

threshold 要随 resolution/depth scale 调整；color ramp 应在声明的 color space；outline thickness 需定义 screen/world unit。

## Ch35 Motion：表示随时间变化的状态

<Term def="用时间参数描述 object pose、shape、camera、light 或 simulation state 的变化函数及其采样">运动表示</Term>包括 key poses/splines、articulated hierarchy、deformation basis、particle/rigid/deformable state 与 procedural controller。

关键帧插值对 translation 可用 linear/cubic spline，对 rotation 应用 quaternion slerp/squad 等 manifold-aware 方法。直接线性插值 rotation matrix 会破坏 orthogonality；Euler angle 会受 wrap 和 gimbal parameterization 影响。

Hermite pose channel：

$$
p(t)=h_{00}(t)p_0+h_{10}(t)m_0+h_{01}(t)p_1+h_{11}(t)m_1.
$$

tangent 决定 ease/overshoot 和 segment continuity。时间 reparameterization 改速度，不等于改几何 path；arc-length parameterization 可近似恒速。

### Articulation、skinning 与 IK

<Term def="以关节父子关系和局部刚体变换表达姿态，world pose 由层次组合得到的运动表示">关节层次</Term>支持 FK；IK 从 end-effector constraint 求 joint parameters，可能多解、无解或需 joint limits/objective。

linear blend skinning：

$$
p'=\sum_jw_jM_jB_j^{-1}p,\qquad \sum_jw_j=1.
$$

它简单但会 candy-wrapper/volume loss；dual quaternion、corrective shape 或 learned deformation 改善不同 artifact。normal/tangent 也需正确变换，negative/nonuniform bone scale 要限制。

## Dynamics 与数值积分

Newton state $\dot x=v,\dot v=F(x,v,t)/m$ 需离散积分。semi-implicit Euler：

$$
v_{n+1}=v_n+a_n\Delta t,\qquad
x_{n+1}=x_n+v_{n+1}\Delta t.
$$

它常比 explicit Euler 对简单 mechanical energy 更稳健，但不是所有 stiff/constraint 系统都稳定。Verlet、Runge-Kutta、implicit methods 各有 cost/stability/damping；“更高阶”也不自动适合 contacts。

<Term def="离散求解在 timestep 和误差扰动下保持状态有界、约束可控且不出现非物理能量爆炸的性质">数值稳定性</Term>依 differential equation、integrator、timestep、stiffness、collision/constraint solver 与 floating precision。

<CgpMotionStabilityDiagram />

fixed simulation timestep 有助 determinism 和稳定；render 可在 simulation states 间 interpolate。frame-dependent `x += v / fps` 与可变大 dt 会在 hitch 时爆炸。substep、continuous collision 与 constraint iteration 需按速度/尺度和预算设计。

## Rendering motion

动画是连续运动在 display time 上的采样。aliasing 表现为 strobing、wagon-wheel 和 judder。motion blur 近似 shutter interval 的 radiance integral：

$$
I=\frac{1}{t_c-t_o}\int_{t_o}^{t_c}L(t)dt.
$$

正确 blur 需要 geometry/camera/deformation 在 shutter 内的位置，不是只模糊最终帧。real-time velocity buffer 近似会在 disocclusion、rotation、transparent 和 nonlinear motion 处失败。

pose interpolation、simulation interpolation、display interpolation/reprojection 是不同层；混淆会增加 input latency 或 double smoothing。验收要记录 state timestamp、render pose、present time 与 shutter convention。

## 常见误区

<Callout type="trap">
**现象 →** 加 toon ramp 和黑轮廓就称为 expressive rendering。**原因 →** 以 technique 代替 message、abstraction 与 viewer task。**修法 →** 建立 feature/message matrix，并用识别和误读任务评价。
</Callout>

<Callout type="trap">
**现象 →** 用 variable frame dt 直接积分，卡顿后物体穿透或爆炸。**原因 →** integrator stability region 与 collision step 被突破。**修法 →** fixed simulation timestep、bounded catch-up/substep，并扫 dt/stiffness/velocity。
</Callout>

<Callout type="trap">
**现象 →** 骨骼动画、IK 和物理模拟被当作互斥方案。**原因 →** 混淆 pose source、constraint correction 与 secondary motion。**修法 →** 声明每层 ownership、blend/order 和 timestamp，并检查 double transform/latency。
</Callout>

## 练习

<Exercises>

**问题 1：如何评价技术插图的 expressive rendering？**

<Answer>
先定义需要识别的结构/步骤和禁止误读项，再测任务完成时间、正确率、feature salience、跨视角/分辨率稳定与 style reference；photorealistic error 不是唯一指标。
</Answer>

**问题 2：geometric silhouette 与 image-space edge 有何差别？**

<Answer>
geometric silhouette 从相邻 faces 的 view-facing 变化得到，可附着几何但依 mesh/topology；image edge 从 depth/normal/material buffers 检测，简单但 resolution/threshold dependent，可能含内部 crease 或漏细线。
</Answer>

**问题 3：为什么 semi-implicit Euler 仍需 timestep 测试？**

<Answer>
它对部分系统比 explicit Euler 稳定，但高 stiffness、contacts、constraints 和大 dt 仍会 drift/爆炸。稳定性由 equation 与 solver 联合决定，需扫 dt、substeps、iterations 并监测能量/约束误差。
</Answer>

**问题 4：运动模糊怎样与 simulation timestep 解耦？**

<Answer>
simulation 产生带 timestamp 的状态；renderer 在 shutter interval 内插值/求值多个时刻并积分。render samples 不必等于 physics steps，但 interpolation/deformation 必须代表同一连续运动并处理 disocclusion。
</Answer>

</Exercises>

## 小结

Ch34、35 将图像与时间都视作信息设计问题：expressive rendering 选择并强化 message，motion 以 representation、interpolation、dynamics 和 display sampling生成时间信号。通过标准是任务、风格、时域稳定、数值误差和成本都有证据。
