## 直觉：RGB 常量不是光，shader 也不是材质本身

先预测：`vec3(0.5)` 的光强是多少瓦？HSV 中两个 hue 直接线性插值会沿最短色相路径吗？Phong highlight 在 vertex 之间消失，是材质模型错还是 sampling frequency 错？这些问题必须先分清物理量、表示和执行位置。

## Ch26 Light：从光谱到辐射度量

光可用 wave/particle 模型解释 diffraction、interference、polarization 与 energy packet；graphics 通常在尺度足够大时采用 geometric/ray optics 与连续 radiometry。选择模型就是声明忽略哪些现象，不能说 ray optics 是光的完整物理。

<Term def="单位投影面积、单位立体角方向上的辐射功率密度，是沿真空直线传输和渲染方程使用的核心量">辐亮度</Term>定义：

$$
L=\frac{d^2\Phi}{dA\cos\theta\,d\omega},
\qquad [L]=W\,m^{-2}\,sr^{-1}.
$$

- radiant flux $\Phi$：总功率 W；
- intensity $I=d\Phi/d\omega$：每立体角功率 W/sr；
- irradiance $E=d\Phi/dA$：到达表面的每面积功率 W/m²；
- radiance $L$：带方向的投影面积密度。

<Term def="物体表面对入射光谱和方向的反射比例或分布属性；它是材料响应，不是到达表面的照明颜色">反射率</Term>与 radiance 不能混用。一个白色 albedo 并不发光；输出还取决于 incident radiance、geometry 和 visibility。

blackbody spectrum 随 temperature 变化，但“色温”只描述接近黑体轨迹的 chromaticity，不决定任意光源完整 spectrum。polarization/diffraction 在常规 renderer 中常忽略，在薄膜、衍射光栅、LCD/光学系统中可能不可忽略。

## Ch27 Materials and Scattering

<CgpScatteringDiagram />

<Term def="描述入射方向和出射方向之间表面反射/透射辐亮度比例的散射函数家族，包括 BRDF、BTDF 与统一 BSDF">BSDF</Term>进入局部 transport：

$$
L_o(\omega_o)=\int_{\Omega}f_s(\omega_i,\omega_o)L_i(\omega_i)
|n\cdot\omega_i|d\omega_i.
$$

material response 可分：surface reflection/refraction、subsurface transport、participating volume scattering，以及 object-level mixture/layer/geometry。alpha blend 不是自动等价于 physical transmission，多层、absorption、refraction 与 coverage 需明确模型。

<Term def="以少量可调参数拟合观察效果但不保证物理约束的散射模型，如经典 Phong 高光">经验散射模型</Term>适合风格或低成本；measured BRDF/BTF 更贴近采样材料但体量和 interpolation 困难；physical microfacet/diffusion/volume model 参数更可解释，仍包含假设和近似。

评价 material model 应检查：nonnegative、reciprocity（适用时）、energy conservation、sampling/PDF interface、parameter range、normal/scale behavior、spectral/color representation、layering 与可编辑性。

material software interface 不应只提供 `color = shade()`。path/ray renderer 需要 evaluate、sample、pdf，raster renderer 需要 direct/IBL-compatible parameters；两者共享同一 BSDF 语义，避免 offline/real-time 材质漂移。

```cpp
struct BsdfSample {
    Vec3 wi;
    Spectrum f;
    float pdf;
    ScatterFlags flags;
};

Spectrum evaluate(const Surface& s, Vec3 wo, Vec3 wi);
BsdfSample sample(const Surface& s, Vec3 wo, Vec2 randomSample);
float pdf(const Surface& s, Vec3 wo, Vec3 wi);
```

sample 返回值、measure（solid angle/discrete）、delta event 和 transport mode 必须一致，否则 estimator 会系统偏差。

## Ch28 Color：物理光谱到设备信号

<Term def="把光谱功率分布映射为标准观察者三刺激值的颜色描述系统，是设备无关颜色计算的中间表示">CIE XYZ</Term>由 color matching functions 积分：

$$
X=\int S(\lambda)\bar x(\lambda)d\lambda,\quad
Y=\int S(\lambda)\bar y(\lambda)d\lambda,\quad
Z=\int S(\lambda)\bar z(\lambda)d\lambda.
$$

chromaticity $x=X/(X+Y+Z),y=Y/(X+Y+Z)$ 去掉 overall magnitude；它不能表达亮度，也不能说明 spectrum 唯一，因为 metamer 存在。

<Term def="由一组三原色、白点和 transfer function 定义的 RGB 数值解释范围；相同三个数在不同 RGB 空间可代表不同颜色">RGB 色彩空间</Term>必须携带 primaries/white/transfer。linear RGB 适合 lighting、convolution 和 alpha composite；sRGB-like encoded values 适合存储/显示传输，不能直接用于物理相加。

display pipeline 通常是 scene-linear working space → exposure/tone mapping → gamut mapping → output color space/transfer。超出 gamut 的颜色需 clip/compress/map，策略会改变 hue/lightness。

CMY/CMYK 是减色打印模型；YIQ 等服务特定 video encoding；HSV/HLS 是基于 RGB 的用户参数化，不是 perceptually uniform，也不适合任意 physical interpolation。hue wrap、低 saturation undefined hue 和 negative/HDR RGB 都需特殊处理。

颜色插值必须声明目标：linear-light 能量混合、premultiplied layer blend、perceptual gradient、pigment mixture 或 hue path，不存在统一“正确 lerp”。

## Ch33 Shaders：把模型放到正确频率和空间

<CgpShaderColorDiagram />

programmable shader stage 处理 vertices/primitives/fragments/compute work，但 raster/depth/blend 等仍可由 fixed units 执行。shader interface 必须声明 coordinate space、interpolation qualifier、color/data semantics、range 和 sampling frequency。

Flat shading 每 primitive 使用一个 face response；Gouraud shading 在 vertices 求 lighting 后插值 color；Phong shading 插值 normal 后在 fragments 求 lighting。triangle 内是 barycentric/perspective-correct interpolation，不是“双线性插值”。

Gouraud 丢失 narrow specular 是因为先应用 nonlinear lighting 再线性插值；Phong 也可能因 coarse geometry normal、pixel frequency、normal-map aliasing 或 undersampled light 缺失高光。“逐像素”不是无限正确，现代系统还用 per-sample、quad、tile、compute、ray-hit 和 variable-rate frequency。

```glsl
// Inputs are explicitly world-space and scene-linear.
in vec3 worldPosition;
in vec3 worldNormal;
in vec2 uv;

layout(location = 0) out vec4 sceneLinearColor;

void main() {
    vec3 N = normalize(worldNormal);
    vec3 base = decodeBaseColor(texture(baseColorMap, uv));
    BsdfParams bsdf = makeMaterial(base, roughness, metallic);
    vec3 radiance = evaluateDirectAndEnvironment(bsdf, worldPosition, N);
    sceneLinearColor = vec4(radiance, opacity); // tone/output transform is later
}
```

environment mapping 用 direction 查询 environment texture；反射 direction、normal space、roughness prefilter 和 color encoding 必须一致。toon/XToon shader 用 ramp、contour 或 view-dependent abstraction 表达风格，评价目标是 information/style consistency，不是物理误差最小。

## 从测量到显示的校准链

一个 material sphere 看起来“对”不足以证明系统。应建立：spectral/radiometric light reference、known reflectance/BSDF、calibrated camera/exposure、scene-linear capture、display transform 和 calibrated monitor/viewing condition。

白炉测试检查 energy，color checker 检查 color transform，roughness/light-size sweep 检查 lobe，shader frequency sweep 检查 sampling。把每层输出保存，才能分辨光源单位、材质、颜色转换还是 shader stage 出错。

## 常见误区

<Callout type="trap">
**现象 →** `vec3(1)` 同时被称作光强、颜色、albedo 和输出。**原因 →** 丢失单位与 color-space semantics。**修法 →** 类型/变量名标注 radiance/reflectance/linear/encoded，并在边界显式转换。
</Callout>

<Callout type="trap">
**现象 →** 声称现代 GPU 都使用“Phong 逐像素标准”。**原因 →** 把历史 interpolation technique 当固定执行模型。**修法 →** 分开 material model 与 evaluation frequency，按 fragment/sample/compute/ray/VRS 路径实测。
</Callout>

<Callout type="trap">
**现象 →** 在 sRGB 或 HSV 上直接平均 lighting/texture，gradient 变暗或绕错 hue。**原因 →** interpolation space 与目标不匹配。**修法 →** 先定义是能量、layer、perceptual 还是 UI hue interpolation，再选空间和 premultiplication。
</Callout>

## 练习

<Exercises>

**问题 1：radiance 与 reflectance 为什么不能都叫 color？**

<Answer>
radiance 是带单位的方向光能量，reflectance/BSDF 是材料对入射光的比例分布，RGB color 还依观察者/色彩空间。混用会导致距离、曝光、能量守恒和显示转换错误。
</Answer>

**问题 2：怎样验证 BSDF 的 evaluate/sample/pdf 一致？**

<Answer>
对固定 wo 用 sample 生成 wi，比较返回 f/pdf 与独立 evaluate/pdf；做 hemisphere integral、reciprocity/energy 和 white-furnace 测试，覆盖 delta/continuous lobe、roughness 极值与 grazing angle。
</Answer>

**问题 3：Gouraud 丢高光的根因是什么？**

<Answer>
lighting 尤其 specular 是 normal/view/light 的 nonlinear function。Gouraud 只在 vertices 求值再线性插值；若 narrow lobe 峰值落在 triangle 内而顶点值低，插值无法重建该峰值。
</Answer>

**问题 4：为什么 HSV 不适合所有颜色插值？**

<Answer>
它由 encoded RGB 几何变换而来，不感知均匀；hue 是环且在低 saturation 不稳定，也不表达 HDR/negative values。应按能量或感知目标选 linear RGB、XYZ/其他空间及 hue path。
</Answer>

</Exercises>

## 小结

Ch26-28、33 把光、物质、观察者/设备与执行程序连为一条有单位的数据链。可靠着色不由“Phong 还是 Gouraud”单独决定，而由 radiometry、BSDF、color transform、shader interface、sampling frequency 和 display evidence 共同决定。
