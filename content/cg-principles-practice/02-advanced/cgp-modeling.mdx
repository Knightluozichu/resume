## Ch8 A Simple Way to Describe Shape in 2D and 3D

<Term def="为形状选择数据、参数和允许操作的方式，并明确内部/边界、精度、拓扑与可执行查询">形状表示</Term>常见类别：

- boundary representation：curve/surface/mesh 描述边界，surface rendering 直接；solid inside test 需 closed/oriented/watertight；
- parametric：$C(t)$ 或 $S(u,v)$ 直接生成点与 tangent，适合 evaluation/editing；inverse mapping/trim 可能困难；
- implicit：$f(x)=0$ 描述 boundary，sign 可表达 inside/outside；参数化与纹理更难；
- sampled field：voxel/image/grid 保存离散值，regular access 简单但分辨率和 memory 明确；
- constructive/hierarchical：CSG/scene graph 保存生成历史和组合关系，query 需递归求值。

二维 polygon、三维 polyhedron 不是“连续对象本身”，而是 vertices、incidence、orientation 与 embedding 的组合。一个 closed polygon 的 fill rule（non-zero/even-odd）会改变 self-intersection 的内部定义。

## Ch9 Functions on Meshes

mesh geometry 把 topology 嵌入空间；function 可定义在 vertices、edges、faces 或 corners。position 是 vector-valued vertex function，temperature 是 scalar，UV/normal/material index 可能因 seam 需要 per-corner，而不是共享 vertex。

<Term def="定义在网格顶点、边、面或角上的标量/向量数据，并通过离散基函数在元素内部求值的函数">网格函数</Term>在 triangle 内常用 barycentric interpolation：

$$
f(p)=\lambda_0f_0+\lambda_1f_1+\lambda_2f_2,
\qquad \sum_i\lambda_i=1.
$$

它对 affine function 精确，但 normal 插值后通常要 normalize；perspective raster 中还需 $1/w$ correction。硬 normal、UV/material seam 要复制 corners/vertices，不能让 position sharing 强迫所有属性连续。

half-edge/winged-edge 等 adjacency structure 支持 one-ring、boundary traversal、edge flip/collapse；triangle index buffer 更紧凑但邻接 query 需额外构建。选择取决于 editing/query 与 rendering layout。

## Ch14 Standard Approximations and Representations

<Term def="用计算可承受的模型替代理想物理或几何对象，并记录它在尺度、频率、视角和操作上的误差边界">标准近似</Term>贯穿 graphics：finite precision real、ray optics、polygonal distant object、volume sample、scene graph、material/translucency/luminaire model。

评价 representation 至少问：

1. 能表示哪些对象，是否 closed under transform/Boolean/deformation；
2. evaluation、intersection、inside、closest point、sampling 的 cost；
3. approximation error 能否量化，是否随 view/scale 改变；
4. topology/continuity/energy 等 invariants 是否保留；
5. conversion 是否 lossless、stable、invertible。

LOD 不应只由距离决定。若 object-space deviation 为 $e$，viewport 高 $H$，view depth $z$，vertical FOV $\theta$，screen error 近似：

$$
e_{px}\approx\frac{eH}{2z\tan(\theta/2)}.
$$

silhouette、normal/material frequency、animation skin 和 shadow 还会增加 perceptual error。切换需 hysteresis/cross-fade，且 bounds/collision representation 可能与 render LOD 不同。

## Ch22 Splines and Subdivision Curves

<CgpCurveSurfaceDiagram />

Hermite cubic 由 endpoints $P_0,P_1$ 和 tangents $T_0,T_1$ 定义；Catmull-Rom 从邻近 points 自动估 tangent，并插值 data points。多个 segment 连接时区分 $C^0$ position、$C^1$ derivative 与 $G^1$ tangent-direction continuity。

<Term def="由控制点、degree 与 knot vector 定义的分段多项式曲线，具有局部支撑和可控制连续性">B-spline</Term>写为：

$$
C(t)=\sum_iN_{i,p}(t)P_i.
$$

移动一个 control point 只影响有限 knot span；knot multiplicity 会降低 continuity。de Boor algorithm 稳定 evaluation，subdivision/corner cutting 可从 refinement 角度得到同一极限曲线。

曲线 test 要检查 endpoint/interpolation contract、partition of unity、affine invariance、local support、derivative continuity、arc-length approximation 与 degenerate knots。

## Ch23 Splines and Subdivision Surfaces

tensor-product Bézier patch 由二维 Bernstein basis 定义：

$$
S(u,v)=\sum_{i=0}^{m}\sum_{j=0}^{n}B_i^m(u)B_j^n(v)P_{ij}.
$$

partial derivatives $S_u,S_v$ 给 tangent，cross product 给 normal。相邻 patch 的 shared edge control points 保证 positional continuity；切向 control relation 决定更高 continuity。trim、parameter distortion 与 patch tessellation seam 都要单独处理。

**Spline Surfaces（样条曲面）**把曲线的 basis、knots 和 continuity 推广到二维参数域；tensor-product B-spline patch 具有局部支撑，而 patch network 在 extraordinary topology 处不能只靠规则矩形参数化覆盖。

<Term def="反复细化控制网格并定义其光滑极限曲面的表示；规则区域等价于 spline patch，非规则顶点需专门规则">细分曲面</Term>中 Catmull-Clark 处理任意 polygon control mesh，规则 quad region 对应 bicubic B-spline；extraordinary vertex 附近 continuity/evaluation 不同。crease/boundary rule 是模型语义，不能靠事后 normal split 代替。

## Ch24 Implicit Representations of Shape

<Term def="把形状边界定义为标量函数的等值集 f(x)=c，并可用函数符号表达内外的表示">隐式表示</Term>的 sphere 可写 $f(x)=\|x-c\|-r=0$。signed-distance field 额外要求数值近似到 surface distance，gradient 提供 normal：

$$
n=\frac{\nabla f}{\|\nabla f\|}.
$$

一般 implicit function 不一定是 SDF；对它用 sphere tracing 的 `step=f(x)` 可能越过 surface。transform、smooth Boolean 或 interpolation 也会破坏 distance property，需要 Lipschitz bound/保守步长。

implicit → mesh 可用 marching squares/cubes、dual contouring 等 iso-surface extraction；要处理 ambiguous case、topology、crack、normal 和 adaptive cell transition。mesh → implicit 可基于 signed distance/winding/voxelization，但 open/nonmanifold mesh 会让 sign 不确定。

ray tracing implicit surface 可 root-find $f(o+td)=0$；解析、interval、bracketing/Newton 或 conservative marching 各有 convergence 边界。必须记录 iteration、residual 和 miss reason。

## Ch25 Meshes

<CgpMeshLifecycleDiagram />

<Term def="由拓扑 incidence、空间 geometry 与角/顶点/面属性共同构成的离散曲面表示">多边形网格</Term>的质量维度包括 manifoldness、orientation、boundary、degenerate/duplicate/self-intersection、aspect ratio、attribute seam 与 scale。

```cpp
struct HalfEdge {
    VertexId origin;
    FaceId face;
    HalfEdgeId next;
    HalfEdgeId twin; // invalid on boundary
};

bool canCollapse(Edge e) {
    return preservesLinkCondition(e) &&
           preservesBoundaryAndSeams(e) &&
           !createsFlippedOrDegenerateFaces(e);
}
```

mesh simplification 的 edge collapse 要在 geometry error 外保护 boundary、UV/normal/material seam、skin weights 和 topology。quadric error metric 给几何 proxy，不自动保证 silhouette/texture/shadow。mesh repair 也不能无条件封洞：医学 scan、cloth 和 CAD shell 对“正确拓扑”定义不同。

triangle-order/vertex-cache optimization 改 layout 不应改 geometry；quantization/compression 改表示精度，要记录 bounds 和 worst-case error。现代 GPU 主要高效处理 triangles，但也可通过 tessellation/mesh/compute/ray/procedural primitives 生成或查询其他表示，“GPU 只认三角形”不是普遍架构事实。

## 表示转换的误差账本

每次 conversion 都要记录：source semantics、target capability、tolerance、topology change、attribute transfer 和 inverse/check。例：Bézier patch tessellation 需 screen/curvature error 与 shared-edge factor；SDF extraction 需 iso-value/cell size；mesh LOD 需 correspondence 和 transition。

最可靠的 pipeline 不是“一律转 mesh”，而是在 authoring/simulation/query/render 各阶段保留适合表示，并在边界处做显式、有测试的 conversion。

## 常见误区

<Callout type="trap">
**现象 →** 声称增加 triangles 就能让 mesh 达到任意光滑。**原因 →** 只看采样密度，忽略 topology、normal/parameter continuity 与 approximation strategy。**修法 →** 以 geometry/normal/silhouette error 和 seam/crack 验收，不以 face count 代替质量。
</Callout>

<Callout type="trap">
**现象 →** 把任意 implicit function 当 SDF 做 sphere tracing。**原因 →** 混淆 zero set 与 distance property。**修法 →** 证明/估计 Lipschitz bound，使用保守步长和 bracketing，并记录 residual/iteration。
</Callout>

<Callout type="trap">
**现象 →** 自动 repair 封闭所有 boundary、合并所有近邻 vertex。**原因 →** 没有对象语义和 tolerance。**修法 →** 先分类 intentional boundary/seam/shell，再以单位和 downstream query 定义 repair policy。
</Callout>

## 练习

<Exercises>

**问题 1：为何 position 可共享而 UV/normal 可能不能共享？**

<Answer>
同一几何位置可以位于 UV atlas 两个 island 或 hard normal 两侧。若只允许 per-vertex 单值，就必须复制 vertex/corner；否则插值会跨 seam。topology sharing 与 attribute continuity 是两套关系。
</Answer>

**问题 2：B-spline 的 local support 有什么工程意义？**

<Answer>
移动一个 control point 只影响有限 knot spans，局部编辑不会改变整条曲线，也使 evaluation/refinement 可局部更新。影响范围由 degree 与 knot vector 决定，并需验证 continuity。
</Answer>

**问题 3：Catmull-Clark 在 extraordinary vertex 为什么要特别测试？**

<Answer>
规则 valence-4 quad 区域等价于 bicubic B-spline，extraordinary valence 处使用不同 subdivision matrix，极限位置、tangent 和 continuity 性质不同，容易出现 pinching 或 tessellation/normal artifact。
</Answer>

**问题 4：如何证明一次 mesh simplification 可接受？**

<Answer>
检查 topology/boundary/seams/skin invariants，测 object/Hausdorff 与 screen/silhouette error，在多视角、animation、shadow 下比较 reference，并记录 triangles、memory、build 与 render time；QEM 数值本身不足以证明。
</Answer>

</Exercises>
