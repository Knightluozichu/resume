## 先把图像看成二维信号，而不是一堆颜色

图像中的亮度和颜色会随着位置变化。平滑区域变化慢，边缘区域变化快；当图像被采样、缩放或滤波时，程序实际上是在处理一个二维信号，而不是只搬运像素。

本章把采样、卷积和频率分析放在同一条证据链上。先猜一猜：把平滑信号换成边缘信号，convolution 和 fourier transform 会分别强调什么？如果细节消失，是因为采样率不够，还是因为滤波器主动压低了高频？

## signal processing：从连续变化到离散样本

<Callout type="trap" title="只看像素数量，不看采样带宽">
  现象 →
  图像尺寸看起来正确，但细密纹理出现摩尔纹、闪烁或完全变成错误的低频图案。 原因
  → 采样间隔无法表达原信号的最高变化速度，或者重建时没有考虑混叠风险。 修法 →
  先估计信号带宽和屏幕采样率，必要时先低通再降采样，并用频域或边缘测试检查损失。
</Callout>

<Term def="对信号进行采样、滤波、变换、重建或分析的过程；它把连续变化转成可计算的离散表示，并控制噪声与细节。">
  signal processing
</Term>

**signal processing** 把图像看作位置函数：每个像素是某个位置的采样值，邻近像素的差异描述局部变化。采样率决定能观察到多快的变化，量化决定数值精度，滤波决定保留或抑制哪些尺度。图形学中的模糊、锐化、边缘检测和降采样都可以用这套语言解释。

<Cgp18SignalSamplingDiagram />

对一维信号，采样可以写成在位置 `nT` 读取连续函数 `x(t)`：

$$
x[n] = x(nT)
$$

人话翻译：`T` 是采样间隔；它越小，单位长度内的样本越多，能表达的变化越快。若采样过稀，高频变化会折叠成错误的低频外观，这就是混叠。图像降采样前的抗混叠滤波不是额外装饰，而是保护表示语义的一步。

## fourier transform：从空间变化到频率成分

<Term def="把信号从位置或时间域转换到频率域的数学变换；它揭示不同变化尺度的强弱，便于分析与设计滤波器。">
  fourier transform
</Term>

**fourier transform** 换了一套坐标描述同一个信号：空间域回答“哪里亮、哪里变”，频域回答“变化以哪些尺度和方向出现”。低频通常对应缓慢的亮度变化和大块结构，高频通常对应边缘、纹理和噪声。变换本身不等于滤波，只有修改频率系数并做逆变换，才会改变图像。

<Cgp18FourierDiagram />

二维图像的频率还有方向。水平条纹与竖直边缘会在频域中留下不同方向的能量分布；因此一个只保留水平频率的滤波器，会选择性保留某些结构。观察频谱时不要只看峰值大小，还要看峰值的位置、方向和是否出现周期性重复。

## convolution：用局部规则处理邻域

<Term def="让一个小型卷积核在信号或图像邻域上滑动，对窗口内样本做加权求和并生成输出的操作。">
  convolution
</Term>

**convolution** 在空间域直接处理局部邻域。一个二维核 `K` 在像素 `(i,j)` 周围滑动，每个输出位置都是邻域样本与核权重的乘积和：

$$
y[i,j] = \sum_{u}\sum_{v} K[u,v]x[i-u,j-v]
$$

人话翻译：核的正负和大小决定邻域被如何组合；平均核会平滑，中心更强的核会保留结构，带正负变化的核可以响应边缘。边界处没有完整邻域时，还必须明确 clamp、mirror、zero padding 等处理方式。

<Cgp18ConvolutionDiagram />

卷积核的选择应该对应目标。模糊核降低高频，能抑制噪声但会损失边缘；锐化核增强局部变化，可能同时放大噪声；边缘核响应亮度突变，输出不再是原始颜色而是特征证据。不要把卷积后的图像当作“真实图像”，先说明它服务于显示、分析还是后续检测。

## 频域与空间域的互相验证

在理想条件下，空间域卷积与频域乘法对应：

$$
\mathcal{F}(x * k) = \mathcal{F}(x)\mathcal{F}(k)
$$

人话翻译：同一个滤波效果可以在像素邻域中用卷积核完成，也可以在频域中通过修改频率成分完成；两者的边界、采样和数值误差不同，不能只凭公式假设结果完全一致。

一个可检查的图像滤波接口应该把输入、核、边界与输出保留下来：

```ts
const filtered = convolve(image, kernel, { boundary: "mirror" });
const spectrum = fourierTransform(image);
const reconstructed = inverseFourierTransform(
  applyFrequencyMask(spectrum, mask),
);
```

如果空间卷积和频域重建结果不一致，先检查核是否被正确变换、边界条件是否一致、FFT 的归一化和频率排列是否一致。不要先用视觉相似度掩盖中间证据的差异。

## 常见误区

<Callout type="trap" title="把频域变换当成滤波结果">
  现象 → 画出频谱后图像却没有变，或者把频谱幅值直接当作最终颜色显示。 原因 →
  fourier transform 只是改变描述域，没有修改频率系数并执行逆变换。 修法 →
  明确分析、修改 mask、逆变换三个阶段，分别保存频率峰值和重建图像。
</Callout>

<Callout type="trap" title="卷积核变大就一定更清晰">
  现象 → 增大 kernel 后图像更平滑或边缘更粗，却被误认为细节增加。 原因 →
  convolution
  的核决定保留与抑制的频率，核尺寸增加通常扩大邻域而不是凭空创造信息。 修法 →
  先说明目标是降噪、平滑、锐化还是边缘检测，再用频率响应和边缘样本验收。
</Callout>

<Callout type="trap" title="忽略边界和采样率差异">
  现象 → 图像中心看起来正确，边缘出现暗框、重复纹理或下采样后出现周期性伪影。
  原因 → 边界 padding 与采样间隔没有和卷积核、重建规则一起定义。 修法 → 明确
  boundary mode，先做抗混叠再降采样，并用非对称边缘图分别检查中心与边缘。
</Callout>

## 本章小结

- signal processing 把图像当作可采样、可滤波、可变换和可重建的离散信号。
- fourier transform 把空间变化拆成频率成分，convolution 用局部加权规则直接处理邻域。
- 采样率、边界条件、核响应和频率 mask 都会改变结果，不能只凭最终截图归因。
- 空间域与频域可以互相验证，但必须保持采样、边界、归一化和重建契约一致。

<Exercises>

**问题 1：判断采样风险。** 一张图包含细密条纹，准备缩小到原宽度的一半。你会先检查什么，并采取哪一步避免混叠？

<Answer>
  先估计条纹的最高空间频率与目标采样率，再在降采样前使用合适的低通或抗混叠滤波，之后重采样并比较频域能量。不能只直接丢掉一半像素。
</Answer>

**问题 2：修改 SignalViz。** 在平滑信号和边缘信号之间切换，分别使用 convolution 与 fourier transform，把卷积核半径从 2 调到 4，再改变采样率。记录哪个操作改变局部响应、哪个操作暴露频率峰值，以及有效样本如何变化。

<Answer>
  convolution
  直接改变邻域加权后的时域或空间域波形，核半径影响响应覆盖范围；fourier
  transform
  显示频率成分，峰值位置和强度提供不同证据。采样率改变可保留的带宽和有效样本，过低时可能产生混叠。
</Answer>

**问题 3：诊断“边缘变暗且中心正确”。** 你会如何区分卷积核、边界 padding 和颜色显示问题？

<Answer>
  先用常数或非对称测试图固定颜色显示，再分别切换 zero、clamp 或 mirror 等
  boundary mode；随后检查卷积核总和、核方向和边缘响应。如果只有边缘随 padding
  改变，问题在边界处理；若全图亮度改变，检查核归一化或颜色映射。
</Answer>
