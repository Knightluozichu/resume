## 直觉：图形学不是一条“模型到像素”的流水线

先预测：一个 path tracer 的 beauty image 正确，是否证明其 interaction、color management 和 motion 都正确？一个 WPF scene 能缩放，是否证明其 transform library 和 high-DPI sampling 正确？全书能力必须在跨章边界验收。

第三版从感知、物理、数学、计算机科学与工程共同解释 graphics。总复习因此围绕四个问题：表示了什么、怎样求解、丢失了什么、用什么证据知道。


## 官方 38 章的八个能力域

### A. 问题、观察者与交互（Ch1、5、21）

Introduction 定义领域与 abstraction；Human Visual Perception 定义观察条件和可见误差；Interaction Techniques 把 multitouch、arcball/trackball、Unicam 等输入映射为任务动作。验收必须包含 observer/display/device/timeline。

### B. 二维场景与变换（Ch2、4、10、12）

2D WPF 与 test bed 提供 retained scene 和可重复实验；2D Transformations 与 Transformation Library 固化 point/vector/frame、composition、inverse、DPI 和性质测试。

### C. 三维几何、层次与相机（Ch3、6、7、11、13、16）

Dürer renderer 建立 projection；essential geometry 提供 dot/cross/plane/barycentric；hierarchical modeling 与 3D transforms 组织 world；camera 和 platform 决定 clip/depth 与应用责任。

### D. 光栅、图像信号与硬件（Ch15、17-20、38）

Ray Casting and Rasterization 产生 samples；Image Representation、Signal Processing、Resizing、Texture Mapping 定义采样与重建；Modern Graphics Hardware 用 parallelism、memory latency 和 locality 执行。

### E. 形状表示（Ch8、9、14、22-25）

simple shape、mesh functions、standard approximations、spline/subdivision curves/surfaces、implicit shapes 和 meshes 共同回答 representation/query/conversion/error。

### F. 光、材质、颜色与 shader（Ch26-28、33）

Light 定义 radiometry；Materials and Scattering 定义 BSDF/volume/subsurface；Color 连接 spectrum、observer 与 device；Shaders 选择空间和执行频率。

### G. 光传输、可见性与加速（Ch29-32、36-37）

Light Transport 与 Monte Carlo 定义积分和 estimator；theoretical/practical rendering 比较 radiosity、path tracing、Metropolis、photon mapping；Visibility 与 Spatial Structures 提供 depth/ray/query 候选漏斗。

### H. 表现与运动（Ch34-35）

Expressive Rendering 按 message 选择 contour/stroke/abstraction；Motion 用 interpolation、hierarchy、dynamics 和 temporal sampling 生成稳定时序。

## 四个跨章不变量

帮助检查八域是否真正连接：

1. **语义不变量**：Point/Vector、radiance/reflectance、linear/encoded、coverage/opacity 不混用；
2. **几何不变量**：frame direction、orientation、topology、continuity 与 bounds 在 conversion 后可追踪；
3. **估计不变量**：sample/PDF/measure、filter normalization、visibility support 和 energy 不凭空改变；
4. **时间不变量**：state/input/render/present timestamp、simulation unit 与 shutter 定义一致。

例如 affine composition：

$$
(B\circ A)(p)=B(A(p));
$$

sampling/reconstruction：

$$
g(x)=\sum_i f_i h(x-x_i);
$$

light transport：

$$
L_o=L_e+\int f_sL_iV|n\cdot\omega_i|d\omega_i;
$$

Monte Carlo estimator：

$$
\hat I_N=\frac1N\sum_i\frac{f(X_i)}{p(X_i)}.
$$

四式分别要求 composition、filter、transport 和 probability contract；任何边界漏掉 convention 都会在最终图像放大。

## 跨章故障树


按症状先分域：

- black/missing geometry：scene lifetime → hierarchy → camera/clip → coverage → depth/visibility；
- wrong position/crack：point/vector/frame → transform order → topology/seam → interpolation/conversion；
- dark/overbright/wrong hue：units → BSDF → sample/PDF → linear RGB → tone/gamut/transfer；
- alias/flicker/ghost：continuous frequency → footprint/filter → motion/history → display sampling；
- leak/noise/firefly：visibility → structure update → path support/PDF → variance/clamp；
- lag/unstable motion：input timestamp → controller → integrator/dt → render interpolation → present。

每条链都需要 debug view 和 numeric log。只看 tone-mapped screenshot 会把多个 producer 的错误混在一起。

## 综合项目：一个可解释的交互场景

建议按能力而非文件堆功能：

1. 2D slice：retained/immediate scene、affine transform、corner-cut test、linear/premultiplied image composite；
2. 3D slice：hierarchical mesh/implicit object、camera/clip、raster 与 ray primary visibility；
3. material slice：radiometric light、BSDF、XYZ/linear RGB/output transform、shader/path evaluate consistency；
4. transport slice：direct + path/photon option、BVH/grid query、variance/debug layers；
5. temporal slice：arcball/Unicam、key pose/dynamics、expressive contour/stroke、motion/shutter。

```ts
type GraphicsEvidence = {
  semantics: string[];
  analyticCases: string[];
  imageReferences: string[];
  propertyTests: string[];
  temporalPaths: string[];
  budgets: { cpuP95Ms: number; gpuP95Ms: number; memoryMiB: number };
  fallback: string;
};
```

每个 slice 都交付 evidence，而不是最后才加 tests/profiler。

## 六维验收门槛


按问题选择：analytic matrix/curve、CPU high precision raster、frequency response、path-traced image、user-task labels 或 known trajectory。

- correctness：known points、invariants、topology、energy、PDF normalization；
- visual/perceptual：reference error、feature recognition、gamut/contrast、abstraction message；
- temporal/interaction：fixed input/camera paths、flicker、lag、task completion；
- numerical：degenerate geometry、near singular、stiffness、NaN/Inf、convergence；
- systems：CPU/GPU/present P50/P95/P99、build/query、memory/locality；
- portability/fallback：DPI、color/display、thin/thick platform、unsupported feature。

高分章节仍可能漏核心知识，所以最终门槛同时检查 official outline 38/38、章节分数、书籍分数和实际 evidence。
