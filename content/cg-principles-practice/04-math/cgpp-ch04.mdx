## 先把画面想成一张地图

想象你在一张透明地图上移动一个标记。若没有固定的原点和方向，“向右移动”没有可复核的含义；换一张地图后，同一个标记也可能出现在完全不同的位置。

本章解决的就是这个问题：把移动、转向、放大和朝向写成可以手算、可以观察、也可以交给机器重复执行的规则。

没有这套规则，物体会漂移，明暗会随意改变，更多执行单元也未必让画面更快。读完后，你应能从一个数字或一条向量证据开始，而不是凭最后一张截图猜原因。

## 计算机图形学导论：数学为什么要进入图形管线

<Term def="描述一个点或向量所依据的原点、轴方向和单位的一套参照规则。">
  坐标空间
</Term>
让计算机图形学导论中的“位置”有了可比较的意义：模型空间描述物体自身，世界空间描述物体之间的关系，观察空间描述相机看到的关系。每次转换都应留下输入、变换和输出，才能在画面异常时回到第一处不一致。

本章把 Graphics Pipeline（图形管线）看成一条数学契约：顶点从模型空间进入世界空间，再进入观察与裁剪步骤，之后才会成为片段和像素。Graphics Pipeline（图形管线）并不是一个只会吐出颜色的黑盒；每一站都接收带有坐标、方向或能量的量，并交付下一站可以验证的结果。理解这条链，才能知道公式应该放在哪里、证据应该在哪一站采集。

### 坐标空间：同一个点的不同参照

一个点写成 `(1, 0, 0)` 并不能单独说明它在屏幕上的位置，必须先知道它属于哪个坐标空间。模型空间适合表达“物体自己的顶点”，世界空间适合表达“物体放在场景哪里”；把两者混在一起，常见结果是模型跟着相机移动，或两个物体无法对齐。

先在纸上画出原点、两个轴和目标点，再把它们交给变换。可视化中橙色向量表示参照方向，绿色向量表示变换后的结果；如果方向变了但长度不该变，优先检查旋转矩阵，而不是改顶点数值。

### 齐次坐标：把平移纳入同一条链

<Term def="在三维位置后增加一个分量，使旋转、缩放和平移都能用矩阵乘法统一表示。">
  齐次坐标
</Term>
把位置写成 `(x, y, z, 1)`，把方向写成 `(x, y, z,
0)`。最后一个分量区分“需要被平移的位置”和“只表示方向的向量”，这是相机和物体变换中不能省略的检查点。

$$
\mathbf{x}' = s\,\mathbf{R}(\theta)\,\mathbf{x} + \mathbf{t}
$$

这个式子在说：先旋转方向，再按尺度放大，最后把原点平移到新的位置；顺序改变，结果也会改变。

在工程代码中，矩阵通常按列主序与着色器约定对齐。下面的伪代码只保留一段可验证的变换逻辑；它的输出应同时记录原空间和目标空间，不能只打印最终屏幕坐标。

```ts
const local = vec4(point, 1);
const world = modelMatrix * local;
const view = viewMatrix * world;
const clip = projectionMatrix * view;
return { local, world, view, clip };
```

若 `local` 正确而 `world` 错误，查模型变换；若 `world` 正确而 `clip` 越界，查相机或投影。这个分段记录比直接调整投影参数更容易复现。

### 法线与点积：方向不是位置

<Term def="垂直于表面的方向向量，用来描述表面朝向；计算前通常要归一化。">
  法线
</Term>
不是一个要被平移到远处的点。它只携带方向，所以变换时必须避免把平移当成方向的一部分；模型有非均匀缩放时，还要使用适合的法线变换并重新归一化。

两个单位方向的点积等于夹角余弦：同向接近 1，垂直接近 0，背向为负。光照只保留正值，避免背光表面得到不合理的直接能量。这个简单的数值关系把“朝向光源”从感觉变成可测量的证据。

## 光与能量：方向如何变成亮度

### Light（光）在图形管线中的位置

Light（光）从光源出发，经过传播、表面相互作用和观察方向，最后影响片段颜色。它不会把已经被裁掉的几何重新变回来，因此排查暗画面时，先确认片段存在，再确认方向与能量，最后才看颜色映射。

固定几何和相机后，一次只改变光源方向。若法线与入射方向的夹角从小变大，点积应连续下降；如果画面突然跳变，说明归一化、坐标空间或颜色范围中至少有一项没有保持一致。

### 辐射度量与反射率各自回答什么

<Term def="描述光能量如何按功率、面积、方向或立体角分布的一组物理量；它把能量输入与显示颜色分开。">
  辐射度量
</Term>
回答“有多少能量到达表面”，而
<Term def="表示入射能量中由表面保留或反射的比例；它是材质属性，不等于光源强度。">
  反射率
</Term>
回答“表面保留多少”。两者都参与光照，但不能用一个颜色常数代替。

$$
E = L_i\,\rho\,\max(0,\mathbf{n}\cdot\mathbf{l})
$$

这个式子在说：入射能量、表面保留比例和方向夹角共同决定直接能量；任何一个量改变，排查记录都应能说明改变来自哪里。

## Modern Graphics Hardware：并行仍然受等待约束

### 现代图形硬件如何执行数学

Modern Graphics Hardware（现代图形硬件）把大量相似的顶点、片段和采样任务分给许多执行单元；每个单元重复相近的算术，整体才能获得高吞吐。这个架构解释了为什么数据形状、批次大小和分支一致性会影响速度，也解释了为什么“增加任务数量”不等于“每个任务都立即完成”。

### 并行性与内存延迟

<Term def="把彼此独立的工作分给多个执行单元同时推进的能力；它提高吞吐，却不能跳过数据依赖。">
  并行性
</Term>
可以让一批独立片段同时计算，但共享资源或前一步输出仍会形成依赖。Parallelism（并行性）描述“能否同时推进”，而
memory
latency（内存延迟）描述“数据多久才能到达”；两者都必须在性能记录中分开出现，不能用线程数量代替等待时间。缓存命中与相邻访问可以隐藏一部分内存延迟，不能消除所有等待。

把性能问题写成两个可比较的量：可同时推进的任务数，以及任务等待数据的时间。若等待占比高，先检查数据布局和访问局部性；若等待低而执行单元空闲，再考虑扩大批次或提高并行度。

## 常见误区

<Callout type="trap" title="误区一：把不同坐标空间的数直接相加">
  现象 → 物体看似移动了，但相机一转，物体与其他物体的相对位置就漂移。

原因 → 模型空间、世界空间和观察空间的参照没有标注，向量的数字虽然相同，含义却不同。

修法 → 给每个向量标记所属空间，逐段记录变换前后坐标，再检查矩阵相乘顺序。

</Callout>

<Callout type="trap" title="误区二：把法线当成位置处理">
  现象 → 物体移动后明暗突然改变，或非均匀缩放让表面方向明显失真。

原因 → 法线被错误地应用平移，或者变换后没有重新归一化，导致点积不再表示真实夹角。

修法 → 区分位置的齐次分量与方向的齐次分量，使用正确的法线变换并检查长度接近一。

</Callout>

<Callout type="trap" title="误区三：用增加并行任务掩盖内存延迟">
  现象 → 执行单元更多了，吞吐却没有提升，等待格子反而变多。

原因 → 任务共享数据或访问远处内存，依赖链与缓存未命中让更多单元一起等待。

修法 → 先记录批次、访问局部性和等待比例，调整数据布局后再比较扩大并行度的收益。

</Callout>

## 本章小结

- 坐标空间给每个位置和方向提供可复核的参照。
- 齐次坐标让位置与方向在矩阵链中承担不同责任。
- 点积把法线与光方向的关系变成能量比例。
- 辐射度量和反射率分别描述能量输入与表面保留。
- 并行性提高吞吐，但内存延迟和数据依赖仍需测量。

## 练习与答案

<Exercises>

**问题 1：推导变换。** 给点 `x = (1, 0)`，先逆时针旋转 90 度，再按 2 倍尺度放大，最后平移 `(3, 1)`。写出中间结果和最终结果，并说明若把平移提前会发生什么。

<Answer>
  旋转后为 `(0, 1)`，缩放后为 `(0, 2)`，平移后为 `(3,
  3)`。若先平移再旋转，平移向量也会被旋转，最终位置不同；这正是矩阵顺序必须写清楚的原因。
</Answer>

**问题 2：修改光照实验。** 在 MathViz 中固定入射能量，只改变方向角。写下三个时刻的点积，并说明为何背光时能量不能变成负数。

<Answer>
  可选取同向、近似垂直和背向三个角度，分别记录接近一、接近零和被截断为零的点积。直接光照只保留正的方向贡献，负值代表背光而不是负的可见能量。
</Answer>

**问题 3：判断优化顺序。** 一批片段互不依赖，但数据访问很分散。你会先增加执行单元，还是先改数据布局？给出验收指标。

<Answer>
  先改数据布局与访问局部性，比较缓存命中率、等待比例和批次吞吐；若等待明显下降且仍有空闲执行单元，再增加并行任务。只看线程数或平均帧率无法证明原因。
</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="坐标空间">
  一套规定原点、方向和单位的参照系；同一个数字在不同空间里可能代表不同位置。
</GlossaryItem>

<GlossaryItem term="齐次坐标">
  给三维位置多加一个分量，让旋转、缩放和平移可以统一写进矩阵。
</GlossaryItem>

<GlossaryItem term="法线">
  垂直于表面的方向，用来判断表面朝向；它不是需要被平移的点。
</GlossaryItem>

<GlossaryItem term="辐射度量">
  描述光能量如何分布的一组量，用来区分能量输入和屏幕颜色。
</GlossaryItem>

<GlossaryItem term="反射率">
  表面保留或反射入射能量的比例，是材质属性而不是光源强度。
</GlossaryItem>

<GlossaryItem term="并行性">
  同时推进互不依赖工作的能力；它能提高吞吐，但不能跳过依赖和等待。
</GlossaryItem>

</Glossary>
