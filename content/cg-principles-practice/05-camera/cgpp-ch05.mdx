## 先把相机想成一扇可移动的窗

想象一扇窗正在看一座模型。窗的位置、朝向和开口大小决定你能看到哪一部分；把窗转过去，模型并没有移动，落在窗上的影子却会改变。

本章解决的是“同一个世界为什么会呈现出不同画面”：把移动、转向和缩放写成可复核的规则，并在每一步保留证据。

没有这些规则，物体会在转动视角时漂移，远处物体会突然变大，灯光变化也可能被误认为是相机错误。读完后，你应该能从一条边界、一组方向或一次采样等待开始定位问题。

## 计算机图形学导论：视点是图形管线的一份契约

<Term def="以相机位置为原点、以相机朝向为轴的参照系；世界中的点必须先转换到这里才能被投影。">
  观察空间
</Term>
把计算机图形学导论里的“看见”变成了可计算的对象：世界中的位置、相机的朝向和视野边界都有明确坐标。只要保留世界空间输入、相机基向量和观察空间输出，就能判断错误究竟发生在移动、旋转还是投影。

本章把 Graphics Pipeline（图形管线）看成相机参与的一条契约链：顶点先进入相机的观察空间，再经过投影、裁剪、光栅化和着色，最后才成为屏幕上的像素。Graphics Pipeline（图形管线）不会替相机猜测“向上”的方向，也不会把越过裁剪边界的点重新找回来；每个阶段都需要上一阶段交付可验证的量。

### 观察空间：先固定相机的参照

世界空间适合描述物体之间的关系，观察空间适合描述物体相对相机的位置。相机向前看的方向、屏幕右侧的方向和屏幕上方的方向必须互相垂直；如果其中两个方向混在一起，画面会倾斜或左右颠倒。

观察空间的第一条检查记录是一个三元组：相机位置、目标位置和临时上向。三者都来自同一空间，不能把世界坐标的目标和模型坐标的上向直接拼接。专属实验中的三条箭头正是这份契约的几何证据。

### 视图矩阵：把世界搬到相机眼前

<Term def="把世界空间中的位置转换到相机参照系的矩阵；它通常等价于相机位姿的逆变换。">
  视图矩阵
</Term>
不是“移动相机”的动画本身，而是把所有世界点用相反的方式变换，使相机看起来停在原点。相机向右转，世界在观察空间里就向左转；这个反向关系是调试时最容易遗漏的线索。

设前向为 `f`，临时上向为 `up`，右向为 `r`，真正的上向为 `u`。先归一化方向，再用叉积得到互相垂直的基，可以避免相机倾斜被悄悄带入投影。

$$
r = \operatorname{normalize}(f \times up), \qquad u = r \times f
$$

这个式子在说：右向从前向与临时上向的叉积得到，真正上向再由右向和前向重建；三条轴因此保持一致。

在工程代码里，先返回可检查的相机基，再构造矩阵，比把所有运算塞进一行更容易定位符号错误。

```ts
const f = normalize(target - position);
const r = normalize(cross(f, worldUp));
const u = cross(r, f);
const view = lookAt(position, target, u);
return { f, r, u, view };
```

若 `f` 的方向正确而 `r` 反了，优先检查叉积顺序；若三个向量不再接近单位长度，先归一化再看投影，避免把数值漂移误认为相机运动。

### 透视投影：距离如何改变屏幕大小

<Term def="让近处物体在屏幕上显得更大的投影方式；它通过视场角和深度把三维点映射到裁剪空间。">
  透视投影
</Term>
把深度放进分母，所以同样大小的物体越远，屏幕上的投影越小。视场角扩大时，能看到的范围变大，但同一物体占据的屏幕比例通常变小；近裁剪面和远裁剪面则决定哪些点有资格继续进入图形管线。

$$
p' = P V p
$$

这个式子在说：先用视图矩阵把世界点变成相机参照，再用投影矩阵把它变成可裁剪的坐标；顺序不能调换。

## Light（光）：相机看到的是能量的结果

Light（光）在相机里的作用不是“给画面涂一层颜色”，而是沿光线到达表面、经过方向与材质作用后，才成为可观察的片段输入。Light（光）的方向、表面朝向和相机观察方向必须处于同一参照，否则点积会比较没有意义的两个箭头。

### Radiometry（辐射度量）与 reflectance（反射率）

Radiometry（<Term def="描述光功率、面积、方向和立体角如何分布的一组物理量；它把能量输入与屏幕颜色分开。">辐射度量</Term>）描述光功率、面积、方向和立体角如何分布；reflectance（<Term def="表示表面保留或反射入射能量的比例；它是材质属性而不是相机参数。">反射率</Term>）描述表面保留或反射入射能量的比例。前者是输入能量的量纲，后者是材质属性；相机只能记录最终结果，不能从一个颜色常数反推出两者各自发生了什么。

固定相机与几何后，先记录入射方向和能量，再记录表面反射率与输出范围。若物体随视角转动而变暗，先检查法线与光方向是否仍在同一空间；若光源能量变化而输出不变，再检查曝光或颜色映射。

## Modern Graphics Hardware：相机采样也由并行任务完成

Modern Graphics Hardware（现代图形硬件）会把视野中的像素、阴影查询和纹理采样分发给许多执行单元。相机参数改变后，新增的工作通常不是一条长链，而是一批相似的小任务；这让并行计算成为可能，也让采样数量、分支差异和数据访问方式成为性能变量。

### Parallelism（并行性）与 memory latency（内存延迟）

Parallelism（<Term def="让彼此独立的采样工作同时推进的能力；它提高吞吐，却不能跳过数据依赖。">并行性</Term>）表示彼此独立的采样能否同时推进；memory latency（内存延迟）表示采样请求发出后，数据多久才能返回。两者必须分开测量：并行性高但纹理访问分散时，许多执行单元可能一起等待；等待可被其他独立任务覆盖，却不能被线程数量直接消除。

在相机调试中，保存视场内采样数、活跃任务数、缓存命中情况和等待比例。只有采样确实独立且执行单元仍有空闲时，扩大批次才可能转化为吞吐；否则应该先减少远处访问或重排数据布局。

## 常见误区

<Callout type="trap" title="误区一：把移动相机写成移动世界">
  现象 → 相机向右转时，物体也向右跑，镜头越转画面偏差越大。

原因 → 视图矩阵使用了相机位姿的同向变换，而不是把世界转换到相机参照系的逆变换。

修法 → 同时记录相机位姿和一个固定世界点，验证相机右转时该点在观察空间中的方向变化。

</Callout>

<Callout type="trap" title="误区二：只改视场角来修复消失物体">
  现象 → 物体在某个角度突然消失，扩大视场角后暂时出现，但换距离又重复消失。

原因 → 真正的错误可能是前向符号、近裁剪面或坐标空间不一致，视场角只是掩盖了边界问题。

修法 → 依次检查相机基向量、观察坐标深度和近远裁剪范围，再决定是否调整投影参数。

</Callout>

<Callout type="trap" title="误区三：用增加采样并行度解决访存等待">
  现象 → 执行单元数量增加了，帧时间不降，等待采样格子却变多。

原因 → 采样访问远处数据或共享同一依赖，memory latency 让更多任务同时停住。

修法 → 先记录局部性、缓存命中和等待比例，调整数据布局后再比较并行批次的收益。

</Callout>

## 本章小结

- 观察空间把世界位置转换成相机可解释的参照。
- 视图矩阵表达相机位姿的逆变换，基向量必须保持正交。
- 透视投影用深度和视场角决定可见范围与屏幕大小。
- 辐射度量与反射率分别描述光能量输入与表面保留比例。
- 并行性提高采样吞吐，但内存延迟仍需通过数据访问证据定位。

## 练习与答案

<Exercises>

**问题 1：推导相机基。** 相机位置为 `(0, 0, 5)`，目标为 `(0, 0, 0)`，世界上向为 `(0, 1, 0)`。写出前向、右向和上向，并说明若叉积顺序反过来会发生什么。

<Answer>
  取从相机指向目标的前向后，前向为 `(0, 0, -1)`；右向由前向与世界上向叉积得到
  `(1, 0, 0)`，上向为 `(0, 1,
  0)`。叉积顺序反过来会让右向取反，画面左右方向也会反转。
</Answer>

**问题 2：修改投影实验。** 固定目标距离，分别把视场角设为 30 度和 90 度，记录视野范围和物体屏幕占比的变化。哪一个量不应被相机矩阵改变？

<Answer>
  90
  度视场能看到更宽的范围，固定距离的物体通常占更小的屏幕比例；物体在世界空间中的位置、形状和光源入射能量不应被相机矩阵直接改变。若能量也变了，应查坐标空间或着色输入。
</Answer>

**问题 3：定位采样瓶颈。** 视场角扩大后采样数增加，但活跃任务没有增加，等待比例上升。你会先调整并行批次还是数据访问？

<Answer>
  先检查数据访问和缓存局部性，因为等待比例上升说明 memory latency
  暴露；只有局部性改善、等待下降且仍有空闲执行单元时，扩大并行批次才有意义。
</Answer>

</Exercises>

<GlossaryItem term="透视投影">

</GlossaryItem>

<GlossaryItem term="辐射度量">
  描述光能量如何按功率、面积和方向分布的一组量，不直接等于屏幕亮度。
</GlossaryItem>

  表面保留或反射入射能量的比例，是材质属性而不是相机参数。
</GlossaryItem>

<GlossaryItem term="并行性">
  同时推进互不依赖采样工作的能力；它能提高吞吐，但不能消除数据等待。
</GlossaryItem>
