## 先把三角形想成一张盖在网格上的纸

想象一张有小方格的纸被三角形盖住。只有落在纸内的格子才会得到一个待处理的位置，格子离三角形边缘多近还会影响它得到的属性。

本章解决“几何如何变成一批片段”的问题：先判断哪些采样点被覆盖，再把顶点携带的信息平滑地交给每个片段。

没有这一步，光照没有输入，屏幕就会空白；采样太多或访存太远，又会让有效片段变少、等待变长。读完后，你应该能分别检查覆盖、插值和执行证据。

## 计算机图形学导论：光栅化是图形管线的离散交接

光栅化把计算机图形学导论里连续的三角形边界转换成离散的采样位置。每个位置都应能回答三个问题：它是否被覆盖、它从顶点继承了什么属性、它是否进入了后续片段阶段。

本章把 Graphics Pipeline（图形管线）看成一条从图元到片段的离散契约：图元经过覆盖测试成为片段候选，候选再通过深度与属性规则进入着色和输出。Graphics Pipeline（图形管线）不会把未覆盖的采样点变成片段，也不会在片段为空时凭空制造光照结果；调试应从采样证据开始。

### 覆盖测试：边界先决定数量

<Term def="判断一个采样位置是否落在图元内部或边界上的测试；它决定该位置是否生成片段候选。">
  覆盖测试
</Term>
可以使用边函数、边界方向或采样规则判断点是否属于三角形。阈值和边界约定要稳定，否则相邻三角形可能在共享边上重复覆盖或同时漏掉一个采样点。

把采样网格画出来，先数接受和拒绝的格子，再看颜色。覆盖数量变为零时，光照与材质都还没有机会执行；覆盖数量正确但画面错误，才进入属性和深度检查。

### 重心坐标：用面积比例表达位置

<Term def="用点相对三角形三个顶点的面积比例表示其位置的权重；三个权重之和为一，可用于插值属性。">
  重心坐标
</Term>
把三角形内部的点写成三个顶点的加权组合。靠近某个顶点时，对应权重变大；位于三角形外时，权重可能超出可见范围，这也是覆盖测试需要先发生的原因。

$$
p = \alpha A + \beta B + \gamma C, \qquad \alpha + \beta + \gamma = 1
$$

这个式子在说：片段位置是三个顶点位置的加权和，权重总和保持为一，属性才能在三角形内部连续变化。

### 属性插值：位置和颜色遵守同一份权重

<Term def="把顶点的颜色、深度、法线或纹理坐标按重心权重组合到片段的过程；不同属性仍要遵守自己的空间和校正规则。">
  属性插值
</Term>
让片段获得顶点没有逐个写出的信息。颜色可以平滑过渡，深度用于后续测试，法线需要在正确空间中归一化；插值不是把所有数字简单平均。

下面的伪代码只保留插值契约：先计算权重，再对同一属性的三个顶点值加权。若权重和不接近一，先检查三角形坐标或覆盖边界。

```ts
const weights = barycentric(sample, triangle);
const color = weights.a * colorA + weights.b * colorB + weights.c * colorC;
const depth = weights.a * depthA + weights.b * depthB + weights.c * depthC;
return { color, depth, weights };
```

## Light（光）：只有有效片段才有能量

Light（光）在光栅阶段之后接收片段位置、法线和材质属性。Light（光）可以解释有效片段为什么变暗，却不能解释覆盖测试没有产生任何片段；先确认数量，再确认能量，是本章最重要的顺序。

### Radiometry（辐射度量）与 reflectance（反射率）

Radiometry（<Term def="描述光能量如何按功率、面积、方向或立体角分布的一组量；它是片段的能量输入。">辐射度量</Term>）描述到达表面的能量；reflectance（<Term def="表示表面保留或反射入射能量的比例；它是材质属性，不是覆盖结果。">反射率</Term>）描述材质保留多少。两者只对已经通过覆盖的片段有意义，因此空白画面先查采样数量，局部变暗才查光照和材质。

固定覆盖和几何后，只改变光源能量，再只改变反射率。记录入射能量、反射率和片段输出范围，才能分辨“片段存在但变暗”和“片段根本不存在”。

## Modern Graphics Hardware：片段是天然的并行批次

Modern Graphics Hardware（现代图形硬件）擅长同时处理大量相似片段。覆盖结果、插值属性和片段着色通常可以分成许多独立小任务，但采样访问、纹理读取和深度依赖会让一部分任务等待。

### Parallelism（并行性）与 memory latency（内存延迟）

Parallelism（<Term def="让彼此独立的片段任务同时推进的能力；它提高吞吐，却不能绕过深度、纹理或资源依赖。">并行性</Term>）表示可以同时计算的片段数；memory latency（内存延迟）表示片段读取纹理或缓冲数据时的等待时间。采样数量增加不一定让帧更快：如果访问分散，更多执行单元会一起暴露等待。

光栅性能记录至少包含覆盖片段数、活跃任务数、缓存命中和等待比例。只有有效片段足够多、访问局部性良好且执行单元仍有空闲时，增加并行批次才会转化为吞吐。

## 常见误区

<Callout type="trap" title="误区一：片段为空却先调光源">
  现象 → 三角形完全没有颜色，增加光源强度或反射率仍然空白。

原因 → 覆盖测试已经拒绝所有采样点，光照阶段没有片段可以处理。

修法 → 先记录图元、接受采样和片段数量，再决定是否检查辐射度量与反射率。

</Callout>

<Callout type="trap" title="误区二：把插值当成简单平均">
  现象 → 三角形中心颜色看似正确，但边缘深度或纹理坐标出现跳变。

原因 → 没有使用重心权重，或把不同空间、不同校正规则的属性用同一种方式平均。

修法 → 保存三个权重及其总和，分别检查颜色、深度、法线和纹理坐标的插值契约。

</Callout>

<Callout type="trap" title="误区三：增加采样数就一定更快">
  现象 → 片段任务更多了，但等待比例和帧时间同时上升。

原因 → 采样访问分散或依赖同一纹理数据，memory latency 让并行任务一起等待。

修法 → 先检查缓存命中和数据局部性，再比较有效片段吞吐；不要只看并行任务总数。

</Callout>

## 本章小结

- 覆盖测试决定哪些采样点有资格成为片段。
- 重心坐标用三个权重表达三角形内部位置。
- 属性插值把顶点信息交给片段，但每种属性仍有自己的规则。
- 辐射度量和反射率只解释已经存在的片段亮度。
- 并行性提高片段吞吐，但内存延迟会让采样等待暴露。

## 练习与答案

<Exercises>

**问题 1：计算重心权重。** 对一个三角形内部采样点，给出 `α=0.2`、`β=0.3`，求 `γ`，并说明若三者和不为一应先检查什么。

<Answer>
  因为三者之和必须为一，`γ = 1 - 0.2 - 0.3 =
  0.5`。若和不为一，先检查坐标变换、三角形顶点顺序和采样点是否真的位于覆盖区域内。
</Answer>

**问题 2：修改覆盖实验。** 把 RasterViz 的覆盖阈值推到边界外，写出为什么调高 Light（光）没有效果，以及下一步该检查什么。

<Answer>
  没有采样通过覆盖测试，就没有片段可以接收光照；下一步应检查边函数符号、三角形方向、采样位置和裁剪结果，而不是继续改辐射度量。
</Answer>

**问题 3：判断片段瓶颈。** 采样数增加后活跃片段增加，但等待片段更多。你会先扩大并行批次还是改善数据访问？

<Answer>
  先改善数据访问和缓存局部性，比较命中率、等待比例和有效片段吞吐；等待下降且仍有空闲执行单元后，再扩大并行批次。
</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="覆盖测试">
  判断采样点是否落在图元内部或边界上的测试，决定是否生成片段候选。
</GlossaryItem>

<GlossaryItem term="重心坐标">
  用三个顶点的面积比例表示三角形内部位置的三个权重，权重总和为一。
</GlossaryItem>

<GlossaryItem term="属性插值">
  按重心权重把顶点颜色、深度、法线或纹理坐标组合到片段。
</GlossaryItem>

<GlossaryItem term="辐射度量">
  描述光能量如何按功率、面积和方向分布的一组量，不直接等于屏幕颜色。
</GlossaryItem>

<GlossaryItem term="反射率">
  表面保留或反射入射能量的比例，是材质属性而不是覆盖结果。
</GlossaryItem>

<GlossaryItem term="并行性">
  同时推进互不依赖片段工作的能力；它能提高吞吐，却不能消除访存等待。
</GlossaryItem>

</Glossary>
