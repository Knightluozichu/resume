## 先把图像想成一张带地址和邻居的表

一张图像不只是“许多颜色排在一起”。它还规定了宽度、高度、通道顺序、数值范围和行步长；任何一个约定改变，像素地址和滤波邻域都可能随之改变。

本章解决“像素怎样表示、尺寸变化时怎样取样、颜色怎样传递到输出”三个相连的问题。图像表示负责保存数据，采样与滤波负责从离散数据估计新位置，颜色通路负责把物理能量和显示数值区分开。

先预测再实验：如果通道数量改变，像素地址应改变但几何位置不变；如果采样位置移动，滤波结果应连续变化而不是随机跳变；如果访问等待变长，图像数值不应凭空改变，只是生成时间变长。把地址、数值和时间分开观察，才能找准故障。

## 计算机图形学导论：Image Pipeline 是 Graphics Pipeline 的数据延伸

在计算机图形学导论中，Graphics Pipeline（图形管线）把几何和片段变成颜色、深度等像素结果。Image Pipeline（图像管线）接过这些结果后，负责把像素组织成图像、在不同尺寸间重采样，并把颜色转换成后续显示或存储可以使用的形式。

Graphics Pipeline（图形管线）决定哪些片段产生，Image Pipeline 决定这些结果怎样被保存、读取和重建。前者的错误常表现为几何或可见性不对，后者的错误常表现为通道错位、边缘模糊、色阶断裂或处理延迟；调试时要先确认像素契约。

### 图像表示与像素地址

<Term def="规定图像的尺寸、通道、数值格式、行步长和存储顺序的一组描述；它决定后续读取如何解释字节。">
  图像表示
</Term>

图像表示可以是紧密排列的 RGB，也可以包含透明通道、额外行对齐或分块布局。视觉上相同的图像，若通道顺序从 RGB 变成 BGR，读出的颜色就会互换；若行步长包含填充，下一行的起始位置也不能按宽度直接猜。

<Term def="图像网格中一个位置的离散记录，通常包含多个颜色或深度通道；它是采样和显示的基本数据单位。">
  像素
</Term>

设图像宽度为 $W$，通道数为 $C$，坐标为 $(x,y)$，通道编号为 $c$。在紧密交错存储中，样本的线性地址可以写成：

$$
i = ((yW + x)C) + c
$$

这个地址式先跳过前面的行和像素，再进入当前像素的指定通道；它不包含行对齐、压缩块或平面分离等额外布局，所以真实格式必须同时读取步长契约。

### 采样、滤波与图像重建

<Term def="在离散图像坐标中选择一个或多个邻居来估计目标位置数值的过程；它连接像素网格与连续坐标。">
  采样
</Term>

放大、缩小和旋转都会让目标位置落在原图像网格之间。最近邻采样选择距离最近的一个像素，速度快但可能出现锯齿；加权方法读取多个邻居，让结果随位置平滑变化，但会增加访问和计算。

<Term def="按照空间距离或预设核，为邻域像素分配权重并汇聚成新值的过程；核的形状决定锐利、平滑和边缘响应。">
  滤波
</Term>

两个相邻像素值为 $A$ 与 $B$，目标位置距离 $A$ 的归一化偏移为 $t$ 时，一维线性滤波可以写成：

$$
F(t) = (1-t)A + tB
$$

这个式子说明采样位置移动时，两个邻居的权重互补；二维双线性滤波只是把同样的思想扩展到四个邻居。

颜色空间描述颜色数值所在的编码和物理意义约定，例如线性空间或显示编码空间；不同空间不能直接混合计算。

<Term def="从离散像素估计连续或不同分辨率图像的过程；它依赖采样位置、滤波核和边界处理规则。">
  图像重建
</Term>

图像重建不是凭空恢复原始细节，而是在已知样本和假设的基础上估计目标位置。缩小时如果没有先做合适的低通滤波，细密纹理会折叠成摩尔纹；放大时如果只重复最近邻像素，边缘会变成明显方块。

下面的伪代码强调三个必须保持一致的输入：目标位置、邻域访问和滤波权重。边界模式也属于图像契约，不能让每个调用者临时猜测。

```cpp
Sample sampleImage(Image image, Vec2 uv, Filter filter) {
  Neighbors neighbors = filter.neighbors(image, uv);
  Weights weights = filter.weights(uv, neighbors);
  return weightedSum(neighbors.values, weights);
}
```

## Light（光）：像素数值要保留能量语义

Light（光）在片段或图像生成阶段贡献能量，图像管线则把能量编码成像素数值。若在错误的颜色空间中插值或滤波，几何位置可能完全正确，亮度却会出现不自然的边缘和渐变。

### Radiometry（辐射度量）与 Reflectance（反射率）

Radiometry（辐射度量）描述光能量按功率、面积、方向或立体角的分布，Reflectance（反射率）描述材质保留多少入射能量。二者决定线性颜色的物理意义；图像表示、滤波和颜色空间决定这些数值如何被保存和解释。

固定图像布局和滤波核后，只改变光源能量，再只改变反射率。若线性像素发生变化而地址和邻域不变，问题属于光照或材质；若线性值稳定但显示值变化，问题更可能在颜色空间转换。

### 颜色空间与输出数值

<Term def="把颜色表示为特定数值坐标的编码约定；在线性颜色空间中做能量运算，在显示空间中做输出编码。">
  颜色空间
</Term>

实际编写时应明确每个阶段的颜色空间：光照和滤波通常需要线性值，纹理资产可能带有显示编码，最终输出还可能经过伽马或色调映射。把不同空间的数值直接平均，会让中间灰度偏亮或偏暗，即使每个像素的地址都读取正确。

## Modern Graphics Hardware：图像处理在带宽与并行之间取舍

Modern Graphics Hardware（现代图形硬件）可以并行处理像素块、通道和滤波邻域，但更高分辨率和更多通道也会增加内存读写量。图像算法的速度不只取决于算术操作数，还取决于访问是否连续、邻居是否能复用以及中间结果是否需要落回内存。

### Parallelism（并行性）与 memory latency（内存延迟）

Parallelism（并行性）让多个像素或图像块同时推进，memory latency（内存延迟）表示从读取纹理、图像块或缓存行到数据可用的等待时间。一个滤波核虽然计算简单，如果每个输出都访问分散的邻域，更多并行单元也可能只是一起等待。

观察图像性能时至少记录像素数、通道数、每像素邻居数、缓存命中、处理中间带宽和尾部等待。先确认输出值是否正确，再比较不同布局和滤波核的吞吐；不要用“画面看起来相同”推断访问成本相同。

## 常见误区

<Callout type="trap" title="误区一：通道错位是光照计算错误">
  现象 → 图像中红蓝通道互换或透明度异常，继续调 Light（光）仍无法恢复正确颜色。

原因 → 图像表示的通道顺序、步长或平面布局与读取代码不一致，像素地址已经指向了错误数据。

修法 → 先打印尺寸、通道顺序、步长和单像素地址，再检查辐射度量与反射率。

</Callout>

<Callout type="trap" title="误区二：滤波可以恢复不存在的细节">
  现象 → 放大后的边缘仍然模糊，便不断换更复杂的滤波核，期待原始纹理重新出现。

原因 → 采样和滤波只能根据现有邻居估计目标位置，已经丢失的高频信息无法被算法凭空恢复。

修法 → 先检查输入分辨率、缩放方向和采样频率，再选择合适的重建核与边界策略。

</Callout>

<Callout type="trap" title="误区三：并行像素越多就一定越快">
  现象 → 增加并行任务后，图像结果不变但帧时间和等待比例上升。

原因 → 邻域访问分散或通道布局不连续，memory latency（内存延迟）让多个任务同时等待数据。

修法 → 先测量缓存局部性、带宽和每像素访问量，再决定是否增加 Parallelism（并行性）。

</Callout>

## 本章小结

- 图像表示规定像素、通道、步长和存储顺序，地址错误会先于视觉算法出问题。
- 采样选择邻居，滤波按权重汇聚邻居，图像重建不能凭空创造已丢失的细节。
- 颜色空间决定数值能否直接做能量运算，辐射度量和反射率应保留在线性语义中。
- 现代图形硬件能并行处理像素，但内存延迟、邻域复用和带宽会限制吞吐。
- 调试顺序应是“地址正确 → 邻域正确 → 颜色空间正确 → 访问代价可控”。

## 练习与答案

<Exercises>

**问题 1：计算像素通道地址。** 图像宽度为 `640`，通道数为 `4`，像素坐标为 `(5, 3)`，求通道 `c=2` 的紧密存储地址，并说明有行填充时还需要什么信息。

<Answer>
  地址为 `((3 × 640 + 5) × 4) + 2 =
  7702`。如果存在行填充，还需要真实行步长，不能只用宽度乘通道数推导下一行的起点。
</Answer>

**问题 2：修改重采样实验。** 把采样位置从 `0.30` 调到 `0.70`，解释线性滤波结果为什么变化，并指出它没有恢复什么信息。

<Answer>
  两个邻居的权重随位置互补变化，所以加权结果会从更接近左邻居变为更接近右邻居；滤波没有恢复输入中已经不存在的高频纹理或额外细节。
</Answer>

**问题 3：定位图像处理瓶颈。** 输出颜色保持一致，但提高通道数后访问等待明显增加。你会先改变对比度、滤波核还是检查布局和缓存局部性？

<Answer>
  先检查布局、通道连续性、缓存局部性和带宽，因为颜色数值没有变化而执行时间变长，证据指向数据访问成本；对比度和滤波核属于数值语义，不能直接解释该等待。
</Answer>

</Exercises>
