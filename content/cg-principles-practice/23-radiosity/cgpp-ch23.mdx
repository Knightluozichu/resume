## 先把辐射度想成一张会收敛的能量账本

光源发出的能量不会只停留在直接照亮的表面。它可以从一个面片传播到另一个面片，再被表面吸收、反射或继续传播。辐射度方法的关键，是把连续表面离散成有限个面片，给每个面片建立“收到多少、反射多少、还差多少”的账本。

本章把 The Radiosity Pipeline 拆成三条观察线：面片如何表示场景，能量如何通过形状关系传播，以及不同求解方法怎样在硬件上处理许多面片任务。先预测：只增加面片数量会让光源能量变强吗？只增加迭代次数会消除所有随机噪声吗？只增加 memory latency（内存延迟）会改变收敛目标，还是让每轮更新更慢？

## 计算机图形学导论：Graphics Pipeline 交付能量求解的输入

计算机图形学导论中，Graphics Pipeline（图形管线）负责把场景几何转换成可见的图像。辐射度阶段接收的不是一张已经完成的颜色图，而是带有位置、法线、面积、材质和可见性关系的几何输入。输入空间和单位语义如果不一致，后面即使求解收敛，也可能收敛到错误的亮度。

### 面片与离散化

<Term def="把连续表面划分成有限区域，并为每个区域记录面积、法线、材质和能量状态的离散单元。">
  面片
</Term>

面片的面积影响它能接收和发出多少能量，法线影响方向关系，材质参数影响反射比例。面片数量少时，边缘和小物体的几何变化被平均掉；面片数量增加时，空间细节更准确，但矩阵规模、可见性测试和访问任务也随之增加。离散化不是单纯追求“越细越好”，而是要让细节收益大于求解成本。

### 形状因子与可见性

<Term def="描述一个面片发出的能量有多少比例能够到达另一个面片的几何关系系数。">
  形状因子
</Term>

形状因子把面积、方向、距离和遮挡组合成面片之间的能量通道。若面片 A 看不到面片 B，A 到 B 的有效通道应为零；若两个面片彼此正对且距离较近，通道通常更强。形状因子不是材质颜色，也不是光源强度，它只回答“几何上有多少能量可以到达”。

可见性和面片离散化要分开记录：面片数量影响近似分辨率，遮挡影响能量能否通过。先预测：一个面片的反射率不变但被墙挡住时，它收到的辐射度会如何变化？答案应该来自形状关系，而不是修改材质。

## Light（光）与 Radiometry（辐射度量）：建立单位正确的能量账本

Light（光）提供能量输入，Radiometry（辐射度量）说明功率、面积、方向和立体角的量纲关系。对于一个面片，收到的能量取决于光源辐射、形状因子和遮挡；反射出去的能量还要乘以表面的 Reflectance（反射率）。

<Term def="记录面片或方向上光能量分布的量，用于把光源输入和表面响应放在同一计量语义中。">
  辐射度
</Term>

radiosity（辐射度）可以理解为每个面片最终向外离开的能量状态。一个教学用的离散方程可以写成：

$$
B_i=E_i+R_i\sum_j F_{ij}B_j
$$

其中 $B_i$ 是面片 $i$ 的辐射度，$E_i$ 是自发光输入，$R_i$ 是 Reflectance（反射率），$F_{ij}$ 是从面片 $j$ 到面片 $i$ 的形状因子。这个式子揭示了三个责任边界：Light（光）进入 $E$，几何和可见性决定 $F$，材质决定 $R$，而求解器负责让所有面片状态彼此一致。

固定形状关系后，只提高反射率，面片的反射能量应改变但遮挡关系不应改变；固定反射率后，只提高面片分辨率，能量估计可能更细但光源总输入不应凭空增加。把这两个预测分开，才能避免用曝光变化掩盖单位错误。

## solutions to the rendering equation：理论解法与随机估计

辐射度是渲染方程理论解法的一条离散路径。它假设表面属性和能量交换可以用面片状态表达，再通过迭代或矩阵求解逼近稳定结果。对漫反射、静态场景和可预计算的能量传输，这种表达尤其容易检查：每个面片都有输入、交换和残差。

### radiosity 的迭代收敛

每轮迭代可以把其他面片当前状态带来的能量加回面片 $i$：

$$
B_i^{(k+1)}=E_i+R_i\sum_jF_{ij}B_j^{(k)}
$$

迭代次数增加通常会降低残差，但不保证立刻降低所有误差。形状因子近似、面片过粗或边界条件错误都会让求解器稳定地收敛到错误结果。验证时应同时看残差、能量守恒和局部面片的变化，而不是只看画面是否平滑。

### Metropolis Light Transport（MLT）与样本噪声

Metropolis Light Transport（MLT）通过对光路进行随机探索来估计复杂的能量分布，适合难以用规则面片矩阵表达的路径。它面对的是随机估计误差：增加样本可能降低噪声，却不会自动修复错误的材质、可见性或能量单位。radiosity 和 MLT 可以被放在同一个比较框架中：前者主要暴露离散与迭代残差，后者主要暴露样本方差和路径探索覆盖。

下面的伪代码把两类证据分开记录：

```cpp
Patches patches = discretize(scene, patchCount);
FormFactors F = computeVisibleRelations(patches);
RadiosityEstimate B = iterateRadiosity(emission, reflectance, F, iterations);
PathEstimate M = sampleMetropolisPaths(scene, sampleCount);
compareEnergyAndResidual(B, M);
```

## Modern Graphics Hardware：面片更新可以并行，但账本仍有依赖

Modern Graphics Hardware（现代图形硬件）可以把不同面片、不同样本或不同矩阵行分配给多个执行单元。若面片更新读取相同的形状因子块，缓存复用有助于吞吐；若每个任务随机访问大矩阵或材质表，访问会成为主要成本。能量传播还可能需要多轮同步，因此“更多执行单元”不等于“更快收敛”。

### Parallelism（并行性）与 memory latency（内存延迟）

<Term def="让多个面片、矩阵行或光路样本同时推进的执行能力；它受共享数据和轮次同步限制。">
  并行性
</Term>

Parallelism（并行性）适合并行计算形状因子候选、更新独立面片或生成路径样本。memory latency（内存延迟）来自读取形状因子、面片状态和材质表后的等待；如果下一轮迭代必须等上一轮写回，更多并行任务只能缩短轮内计算，不能取消轮次边界。

性能排查应记录面片数、形状因子非零项、每轮更新数、样本数、缓存命中和等待比例。先减少无贡献的能量通道、改善矩阵布局，再决定是否增加 Parallelism（并行性）；否则会把内存延迟放大成更长的队列。

## 常见误区

<Callout type="trap" title="误区一：面片越多，光源能量就越大">
  现象 → 面片数量增加后，画面整体变亮，于是把结果解释为光照增强。

原因 → 离散化改变了面积、形状因子或采样近似；如果面积权重没有归一化，能量可能被重复计入。面片数量本身不应创造新的 Light（光）输入。

修法 → 固定光源功率，检查面积权重、形状因子总和与能量守恒，再比较局部面片的辐射度变化。

</Callout>

<Callout type="trap" title="误区二：迭代更多就等于误差更小">
  现象 → 迭代次数增加后，残差下降，但边缘漏光或局部亮斑仍然存在。

原因 → 求解器可能已经收敛到错误的形状因子、遮挡或反射率输入；迭代解决的是方程残差，不会修复错误的几何和单位。

修法 → 同时检查能量守恒、面片可见性、Reflectance（反射率）和局部残差，确认输入正确后再增加迭代。

</Callout>

<Callout type="trap" title="误区三：扩大 Parallelism（并行性）就能缩短全部求解时间">
  现象 → 执行单元增加后，单轮计算变快，但总收敛时间不降，memory latency（内存延迟）和同步等待上升。

原因 → 面片更新共享形状因子和状态矩阵，轮次之间存在写回依赖；更多任务会争用相同数据，无法取消同步边界。

修法 → 先重排矩阵布局、减少无贡献通道和批次间通信，再评估并行宽度是否真正提高有效吞吐。

</Callout>

## 本章小结

- Graphics Pipeline（图形管线）交付面片、材质和可见性输入，辐射度阶段把它们组织成能量交换账本。
- 面片提供离散单元，形状因子描述几何能量通道，radiosity（辐射度）记录面片离开表面的能量状态。
- Light（光）提供输入，Radiometry（辐射度量）提供计量语义，Reflectance（反射率）控制表面保留的能量。
- solutions to the rendering equation（渲染方程理论解法）可以通过迭代 radiosity 逼近，MLT 则用随机光路估计复杂传输；残差和样本噪声不是同一种误差。
- Modern Graphics Hardware（现代图形硬件）能利用 Parallelism（并行性）处理面片和样本，但 memory latency（内存延迟）与轮次同步会限制收敛吞吐。

## 练习与答案

<Exercises>

**问题 1：拆分面片方程。** 对面片 $i$，已知自发光 $E_i=0.2$、反射率 $R_i=0.5$，来自一个面片的形状因子为 $F_{ij}=0.4$、辐射度为 $B_j=0.8$。按 $B_i=E_i+R_iF_{ij}B_j$ 计算一次更新值，并说明形状因子代表什么。

<Answer>
  更新值为 $B_i=0.2+0.5\times0.4\times0.8=0.36$。形状因子表示面片 $j$
  的能量有多少比例能够沿几何和可见性关系到达面片
  $i$，它不是材质反射率，也不是光源功率。
</Answer>

**问题 2：区分残差与噪声。** 迭代次数增加后残差下降，但 MLT 图像仍有颗粒。你会增加迭代次数，还是增加样本？请说明两个量分别在解决什么问题。

<Answer>
  应增加 MLT
  样本，因为颗粒主要是随机路径估计的方差；迭代次数主要降低离散方程的残差，不能保证消除样本噪声。两者都应在固定几何、Light（光）和
  Reflectance（反射率）后单独比较。
</Answer>

**问题 3：定位硬件瓶颈。** 面片状态在每轮都正确收敛，但面片数量增加后等待比例和 memory latency（内存延迟）上升。请给出一个优先修复动作，并说明为什么不应先盲目增加 Parallelism（并行性）。

<Answer>
  优先检查形状因子矩阵和面片状态的访问局部性，减少无贡献项或重排批次。盲目扩大
  Parallelism（并行性）会让更多任务争用同一数据，并放大缓存未命中和同步等待，未必提高有效吞吐。
</Answer>

</Exercises>
