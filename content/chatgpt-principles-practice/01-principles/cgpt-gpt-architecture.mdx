## 核心概念

### GPT 的架构选择

GPT 选择**纯解码器（Decoder-only）Transformer**架构，核心组件自下而上：

- **Token Embedding + 位置编码**：把 token 映射为向量，注入位置信息
- **N 层解码器堆叠**：每层含掩码多头自注意力 + 前馈网络 FFN
- **最终 LayerNorm + LM Head**：输出下一个 token 的概率分布

### 三大核心机制

| 机制 | 作用 | 关键点 |
|------|------|--------|
| 掩码自注意力 | 建模 token 间依赖 | 因果掩码防看见未来，可并行训练 |
| 残差连接 | 缓解梯度消失 | 让 96 层仍可训练 |
| 层归一化 | 稳定训练 | Pre-Norm 比 Post-Norm 更稳 |

### 自回归生成流程

```
输入 token → 嵌入 + 位置 → N层解码器 → LM Head → 概率分布 → 采样下一个 token → 拼回输入 → 重复
```

<Callout type="info">

GPT 与 BERT 的本质区别：GPT 是解码器架构，单向注意力只能看过去，适合「生成」；BERT 是编码器架构，双向注意力能看全句，适合「理解」。GPT 用自回归换来了生成能力，这是它能对话、能续写、能创作的根本。

</Callout>

## 术语表

<Glossary>

<GlossaryItem term="解码器架构">

Transformer 的解码器部分，使用掩码自注意力保证每个位置只能看到之前的 token。GPT 纯用解码器堆叠，专为自回归生成设计。

</GlossaryItem>

<GlossaryItem term="掩码多头自注意力">

多个注意力头并行计算，每个 token 通过 Query/Key/Value 与历史 token 交互，因果掩码确保第 t 个位置看不到第 t+1 及之后的 token。

</GlossaryItem>

<GlossaryItem term="残差连接">

把子层输入直接加到输出上，即 output = sublayer(x) + x，让梯度能直通，是深层网络可训练的关键。

</GlossaryItem>

<GlossaryItem term="前馈网络 FFN">

两层 MLP 加非线性激活（GELU），中间层扩展 4 倍维度，对每个位置独立做非线性变换，增强模型表达能力。

</GlossaryItem>

<GlossaryItem term="自回归生成">

每次根据已生成内容预测下一个 token，把新 token 拼回输入再继续，循环直至结束符。是 GPT 生成文本的根本机制。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

GPT 模型采用什么架构？它的核心组件有哪些？

<Answer>

GPT 采用纯解码器 Transformer 架构。核心组件：Token Embedding 词嵌入、位置编码、N 层解码器堆叠（每层含掩码多头自注意力 + FFN，带残差连接和层归一化）、最终 LayerNorm + LM Head 输出概率分布。GPT-3 有 96 层、1750 亿参数。

</Answer>

### 问题 2

为什么 GPT 用「掩码」自注意力？它如何保证自回归生成？

<Answer>

掩码自注意力防止每个位置看到未来的 token，第 t 个位置只能和第 1 到 t 个位置计算注意力。这保证训练时可并行（用掩码一次性算），生成时严格按顺序逐 token 产出符合因果约束。掩码是「训练并行」和「生成因果」能统一的关键。

</Answer>

### 问题 3

残差连接和层归一化在 GPT 中起什么作用？

<Answer>

残差连接把子层输入直接加到输出，让梯度直通，缓解深层网络梯度消失，使 96 层可训练。层归一化对特征维度归一化，稳定每层输入分布，加速收敛。GPT 用 Pre-Norm（先归一化再进子层）更稳定。两者结合是 Transformer 能堆到上百层的基础。

</Answer>

### 问题 4

GPT 的「自回归生成」具体如何工作？它和编码器架构有什么本质区别？

<Answer>

自回归生成：给定输入计算下一个 token 概率分布，采样得新 token 拼到末尾，再重复。本质区别：GPT 解码器单向注意力只能看过去，适合生成；BERT 编码器双向注意力能看全句，适合理解。GPT 逐 token 产出无法回改，BERT 一次性编码整句。GPT 用自回归换生成能力，牺牲双向理解。

</Answer>

</Exercises>
