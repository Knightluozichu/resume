## 学习目标

<Objectives>

- 把握大模型未来演进的五大方向（多模态/Agent/开源/安全/AGI）
- 理解从「能聊天的模型」到「能做事的智能体」的能力跃迁
- 理解开源生态崛起对行业的影响与开闭源竞速格局
- 认识走向 AGI 的能力挑战与治理挑战及如何平衡发展与安全

</Objectives>

## 核心概念

### 五大演进方向

| 方向 | 核心内涵 | 代表 |
|------|----------|------|
| 多模态 | 文本/图/音/视频统一理解生成 | GPT-4o |
| Agent 自主 | 规划/记忆/工具/长程任务 | AutoGPT 类 |
| 开源生态 | 权重开放可自部署 | Llama/Qwen |
| 安全对齐 | 可解释/越狱防御/价值观 | RLHF/宪法AI |
| AGI 路径 | 通用智能/自我改进 | 长期愿景 |

<CgptEcosystemFutureDiagram />

### 能力演进路径

```
语言模型 → 多模态模型 → 工具型 Agent → 自主 Agent → 通用智能体
```

每一步扩展能力边界与自主程度，人机协作模式从「人问模型答」升级为「人说目标模型自主完成」。

### 核心挑战

- **能力挑战**：幻觉 / 长程推理 / 因果理解 / 持续学习防遗忘 / 高效训练推理
- **治理挑战**：安全可控 / 可解释 / 偏见公平 / 隐私保护 / 责任归属监管

<Callout type="info">

核心趋势：从「能聊天的模型」到「能做事的智能体」——技术、生态、安全三条线同步演进。开源闭源竞速 + 多模态融合 + Agent 自主化 = 通向 AGI 的工程路径。越强越要可控，安全能力不能落后于能力增长。

</Callout>

## 术语表

<Glossary>

<GlossaryItem term="多模态大模型">

能同时理解生成文本、图像、音频、视频的大模型，通过原生多模态训练统一多种模态，如 GPT-4o。

</GlossaryItem>

<GlossaryItem term="自主 Agent">

以大模型为推理引擎，能自主规划、记忆、调用工具执行长程任务的智能体，多 Agent 可协作，从「助手」进化为「同事」。

</GlossaryItem>

<GlossaryItem term="开源大模型">

权重公开可下载自部署的模型，如 Llama、Qwen、Mistral，降低使用门槛推动普惠化和下游创新。

</GlossaryItem>

<GlossaryItem term="可解释性">

研究模型决策为何如此输出的技术，对安全可信和责任归属至关重要，是大模型治理的核心难题。

</GlossaryItem>

<GlossaryItem term="AGI">

Artificial General Intelligence，通用人工智能。能在广泛任务上达到或超越人类水平的智能，是大模型的长期愿景。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

大模型未来演进的五大方向是什么？它们各自的核心内涵是什么？

<Answer>

五大方向：多模态（文本图音视频统一理解生成原生多模态训练）、Agent 自主（规划记忆工具长程任务自治多 Agent 协作从助手变同事）、开源生态（Llama/Qwen/Mistral 权重开放可自部署闭源差距缩小推动普惠）、安全对齐（可解释越狱防御价值观对齐越强越要可控）、AGI 路径（通用智能自我改进推理增强长期愿景）。五条线同步演进共同通向更强更安全的智能体。

</Answer>

### 问题 2

为什么说大模型正从「能聊天的模型」走向「能做事的智能体」？

<Answer>

演进路径：语言模型→多模态模型→工具型 Agent→自主 Agent→通用智能体。每步扩展两维度：能力边界（从纯文本到多模态感知从只能说到能用工具操作世界）和自主程度（从被动回答到主动规划执行从单步到长程任务自治）。驱动力：Function Calling 让模型能用工具、Memory 让它能记住上下文、规划能力让它能拆解复杂任务。人机协作从「人问模型答」到「人说目标模型自主完成」，是落地下一个范式跃迁也是 AGI 工程路径。

</Answer>

### 问题 3

开源大模型生态的崛起对行业有什么影响？开源和闭源会怎样竞速？

<Answer>

影响：降低门槛（企业个人自部署自微调不再完全依赖 API 降本且数据可控）、推动创新（开源权重催生大量下游应用和工具链）、加速迭代（社区合力快速复现改进闭源成果）、促进普惠（教育科研中小团队都能用上大模型）。竞速格局：闭源（GPT/Claude）前沿能力仍领先靠规模和算力护城河；开源（Llama/Qwen）在性价比可定制数据隐私上有优势差距持续缩小。未来两者长期并存：闭源探天花板开源做普惠相互促进。

</Answer>

### 问题 4

大模型走向 AGI 的道路上，能力挑战和治理挑战分别有哪些？如何平衡发展与安全？

<Answer>

能力挑战：幻觉（统计学习缺真值校验）、长程推理（多步出错累积）、因果理解（只学相关不学因果）、持续学习防遗忘、高效训练推理算力瓶颈。治理挑战：安全可控（防滥用）、可解释（黑盒决策难追责）、偏见公平、隐私保护、责任归属监管合规。平衡：技术上线对齐研究与能力提升同步；制度上分级风险评估红线审查透明度要求；用「越强越可控」原则让安全能力不落后于能力增长，避免「能力跑在前安全拖在后」的危险。

</Answer>

</Exercises>
