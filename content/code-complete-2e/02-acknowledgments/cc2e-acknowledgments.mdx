<Objectives>

- 能区分原始研究、作者综合、技术评审、翻译审校和读者复核各自承担的责任。
- 能从一条技术主张追到来源、版本、评审动作和独立复现，而不是把鸣谢名单当成证明。
- 能诊断“感谢关系被误读为技术背书”的故障，并从同一基线重放修订后的结论。

</Objectives>

## 为什么需要这一机制

鸣谢是一张贡献地图，不是技术主张的签名页。研究者可能提供材料，评审者可能发现错误，译者可能校正表达，读者可能指出难以复现的步骤；这些贡献都重要，但它们不能互相替代。把贡献类型写清楚，才能知道下一步应向谁追问哪一种证据。

## 先避开三个鸣谢误区

<Callout type="trap" title="误区一：被感谢就等于为全部内容背书">
  现象 → 用人名替代主张、来源和版本。原因 → 感谢关系与事实责任没有分离。修法 → 每条主张单独记录来源和复核状态。
</Callout>

<Callout type="trap" title="误区二：评审过就没有错误">
  现象 → 把一次评审当成永久正确性证明。原因 → 评审的输入、时间和范围没有记录。修法 → 写明评审条件，并在环境变化后重放关键路径。
</Callout>

<Callout type="trap" title="误区三：翻译准确就等于概念已验证">
  现象 → 只检查句子通顺，不检查术语和实例的工程含义。原因 → 表达责任与技术事实责任混在一起。修法 → 用术语表、版本来源和最小实验交叉核对。
</Callout>

## 核心合同与操作术语

本页把主张置信度写成：置信度 = 来源相关性 × 评审质量 × 独立复现 × 版本一致性。<Term def="最先提出或直接观察一个技术主张的资料、实验或规范">原始来源</Term>说明证据从哪里来；<Term def="围绕事实、逻辑、术语或表达进行的有范围检查">贡献类型</Term>说明某位参与者具体做了什么。

<Term def="未参与原决定的人按同一输入重新检查结果的动作">技术评审</Term>关注可复现的事实与推理；<Term def="检查术语、上下文和表达是否保留原意的工作">翻译审校</Term>关注表达与语义边界；<Term def="读者在自己的干净环境中重现关键结果">读者复核</Term>则把文本主张接回实践证据。

## 目录节点逐项深读

### 鸣谢

鸣谢节点的工程含义是把贡献与责任分层。先列出原始来源和版本，再标出研究、评审、翻译、出版或读者反馈对应的动作；技术结论仍需自己的实验或规范核对。最小产物是一张主张追踪表：主张、来源、贡献类型、评审条件、当前状态和失效边界。

## 最小可重放实现

~~~text
claim = state_one_technical_claim()
source = trace_to_source(claim, version)
review = inspect_contribution(source, contribution_type)
replay = independent_replay(claim, same_input)
record(source, review, replay, boundary)
~~~

正常轨迹确认来源与贡献类型一致；边界轨迹改变版本或上下文；故障轨迹把感谢名单当作背书；复位轨迹要求第二位读者重做关键检查。只有四条轨迹都留下记录，鸣谢才真正提高了可追踪性。

## 练习与答案

<Exercises>

**问题 1：拆分贡献。** 一位专家提供了例子，另一位校对了译文，第三位复现了失败路径。请分别写出三种贡献和它们不能替代的证据。

<Answer>
  例子提供上下文材料，不能替代规范或实测；翻译审校保证术语和语义边界，不能替代技术证明；失败复现提供当前环境中的观察，不能自动证明所有版本都相同。三者应在主张追踪表中分别记录。
</Answer>

**问题 2：诊断背书误读。** 读者说“鸣谢里提到维护者，所以这个 API 一定这样工作”。请指出缺失信息。

<Answer>
  缺失 API 版本、具体主张、官方规范或实现来源、输入条件和复现结果。应保留鸣谢关系，同时补一条固定版本的最小实验。
</Answer>

**问题 3：设计读者复核。** 如何让第二位读者复核一条经过翻译的技术说明？

<Answer>
  提供原始主张、译文术语、版本、输入、预期输出和边界条件；复核者独立执行并记录首个偏离。差异应回到具体表达或事实来源，而不是用“读起来没问题”结束。
</Answer>

</Exercises>

## 本页小结

鸣谢把贡献关系变成可追踪结构：感谢谁、做了什么、哪条主张仍需什么证据必须分开。来源、评审、翻译与读者复核沿同一版本和输入重放，才能让文字获得可交接的可信度。
