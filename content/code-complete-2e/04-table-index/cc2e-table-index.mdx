## 为什么需要这一机制

表目录 解决的不是一个可背诵口号，而是从 **表格数值即结论** 到 **口径一致后再做定量判断** 的可观察变化。它的核心机制是：表目录用于核对表号、变量定义、单位、样本、版本和比较口径，再决定表中差异是否支持结论。

学习 表目录 时先预测 问题、表格定位、口径核对、数据比较、决策引用 的输入与输出，再改变一个直接条件。最终结果即使看似正确，只要中间状态违反合同、故障不能隔离或重置不能回到同一基线，本页结论就不通过。
