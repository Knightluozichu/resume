## 为什么需要这一机制

图目录 解决的不是一个可背诵口号，而是从 **看图识名词** 到 **从图重建可失败的机制** 的可观察变化。它的核心机制是：图目录要求把节点解释为对象或状态、把边解释为数据或控制变化，并用代码轨迹验证方向和边界。

学习 图目录 时先预测 问题、图号定位、节点解释、边的语义、代码验证 的输入与输出，再改变一个直接条件。最终结果即使看似正确，只要中间状态违反合同、故障不能隔离或重置不能回到同一基线，本页结论就不通过。
