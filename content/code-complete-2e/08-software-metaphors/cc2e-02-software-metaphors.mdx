## 为什么需要这一机制

第2章：用隐喻来更充分地理解软件开发 解决的不是一个可背诵口号，而是从 **用一个故事替代设计** 到 **以反例约束的多模型推理** 的可观察变化。它的核心机制是：隐喻只提供候选结构和问题视角，必须列出映射成立处、遗漏处、反例和退出条件，再转化为工程决定。
