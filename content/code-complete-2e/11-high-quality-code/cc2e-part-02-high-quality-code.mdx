## 故障诊断与误区

<Callout type="trap" title="误区：类、函数和异常各自存在，却没有共同不变量">
  这个错误会让 第2部分：创建高质量的代码
  无法从“语法正确即高质量”稳定推进到“结构与验证共同承载意图”。诊断沿 复杂度 →
  抽象类 → 子程序 → 防御边界 → 伪代码实现
  前进，只在第一次出现预期与实际不一致的节点停下，不用最终症状倒猜原因。
</Callout>

<Callout type="trap" title="误区：一个指标可以代替全部证据">
  第2部分：创建高质量的代码
  的单一数值可能被样本、缓存、默认值、测量窗口或偶然次序掩盖。至少同时保存机制轨迹、边界结果、故障拒绝和复位重放，任何一项缺失都不能用平均分补偿。
</Callout>

<Callout type="tip" title="恢复顺序">
  第2部分：创建高质量的代码 的恢复顺序是：还原输入和环境，清理派生状态，重建
  抽象类，重跑 子程序，核对 伪代码实现，再注入同一故障确认拒绝可重复。
</Callout>
