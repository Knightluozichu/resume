## 为什么需要这一机制

第32章：自说明代码 解决的不是一个可背诵口号，而是从 **注释越多越清楚** 到 **代码表达做什么，注释解释为何如此** 的可观察变化。它的核心机制是：自说明代码用名称、类型、结构和测试表达可检查意图；注释补充原因、约束和非显然取舍，并与代码共同更新。

学习 第32章：自说明代码 时先预测 读者任务、清晰代码、必要注释、外部文档、同步验证 的输入与输出，再改变一个直接条件。最终结果即使看似正确，只要中间状态违反合同、故障不能隔离或重置不能回到同一基线，本页结论就不通过。
