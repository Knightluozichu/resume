- 理解《码农翻身》全书的四大学习阶段和十章学习路径

## 核心概念

### 全书定位

《码农翻身》（刘欣）是一本以故事化方式讲解计算机技术的通识读物。不同于枯燥的教材，它用生动的对话和案例，把计算机基础、编程语言、Web 开发、数据库、分布式架构、JVM 原理、DevOps 和职业成长串联起来，帮助读者**建立从底层到上层的完整技术认知体系**。

| 阶段 | 章节 | 核心主题 | 颜色编码 |

| 基础认知 | ch0-2 | 全景图、编程世界、面向对象与数据 | 蓝色 |

### 核心脉络

全书的核心理念可以浓缩为一条脉络线：

**基础 → Web数据 → 架构 → 实践成长 → 知识闭环**

这四个阶段不是孤立的模块，而是一个**递进循环**：基础是地基，Web 数据是连接，架构是骨架，实践成长是落地，知识闭环是整合。

### 学习建议

1. **顺序学习**：按章节顺序学习，每一章都建立在前一章的基础上
2. **故事导向**：每学完一个概念，尝试回忆书中的故事场景加深理解
3. **对比思考**：将不同章节的知识横向对比，发现内在联系
4. **定期回顾**：学完全书后回到本章，检验对全景图的理解是否加深

## 术语表

| 术语 | 释义 |
|------|------|
| 计算机分层 | 从硬件到应用的层次化架构设计 |
| 面向对象 | 以对象为核心组织代码的编程范式 |
| HTTP | 超文本传输协议，Web 通信的基础 |
| ACID | 事务的原子性、一致性、隔离性、持久性 |
| CAP 定理 | 分布式系统一致性、可用性、分区容错的取舍 |
| JVM | Java 虚拟机，一次编写到处运行的基础 |
| CI/CD | 持续集成与持续交付的自动化流水线 |
| 微服务 | 将单体应用拆分为独立部署的小服务 |
| 缓存策略 | Cache Aside / Read Through / Write Behind 等 |
| 知识闭环 | 将分散知识整合为系统认知的过程 |
