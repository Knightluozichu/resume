## 核心概念

### 一个请求的旅程

当你在浏览器输入网址到看到页面，背后发生了什么？《码农翻身》把这个过程比作一次「信件旅行」：从写信、投递、分拣、运输到送达，每个环节都有明确的协议和规则。

### 请求全链路

1. **DNS 解析**：域名 → IP 地址
2. **建立 TCP 连接**：三次握手
3. **发送 HTTP 请求**：请求行 + 请求头 + 请求体
4. **服务器处理**：路由分发 → 业务逻辑 → 数据库查询
5. **返回 HTTP 响应**：状态码 + 响应头 + 响应体
6. **浏览器渲染**：解析 HTML → 构建 DOM → 加载 CSS/JS → 呈现

### TCP/IP 四层模型

| 层次 | 协议 | 职责 |
|------|------|------|
| 应用层 | HTTP/HTTPS/DNS/FTP | 应用间通信 |
| 传输层 | TCP/UDP | 端到端数据传输 |
| 网络层 | IP/ICMP | 跨网络数据包传输 |
| 链路层 | 以太网/ARP | 物理帧传输 |

### TCP 三次握手

TCP 通过三次握手建立可靠连接：

1. **SYN**：客户端发起连接请求，发送序号
2. **SYN + ACK**：服务器确认并回应自己的序号
3. **ACK**：客户端确认，连接建立

为什么是三次而非两次？因为双方都需要确认对方的发送和接收能力正常。

### TCP vs UDP

| 特性 | TCP | UDP |
|------|-----|-----|
| 可靠性 | 可靠传输 | 不保证可靠 |
| 连接 | 面向连接 | 无连接 |
| 速度 | 较慢 | 较快 |
| 适用场景 | 网页/邮件/文件 | 视频/直播/游戏 |

## 术语表

| 术语 | 释义 |
|------|------|
| HTTP | 超文本传输协议，Web 通信的基础 |
| DNS | 域名系统，将域名解析为 IP 地址 |
| TCP | 传输控制协议，面向连接的可靠传输 |
| UDP | 用户数据报协议，无连接的快速传输 |
| 三次握手 | TCP 建立连接的三步过程 |
| IP 地址 | 网络中设备的唯一标识 |
| 端口 | 区分同一设备上不同应用的编号 |
| DOM | 文档对象模型，HTML 的内存表示 |
