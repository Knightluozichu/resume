## 学习目标

- 理解 CI/CD 流水线的完整流程和工程价值
- 掌握云计算三层服务模型（SaaS/PaaS/IaaS）
- 理解容器化（Docker）与编排（Kubernetes）的核心概念
- 建立自动化交付的系统认知

## 核心概念

### 交付的进化

从手动部署到自动化交付，DevOps 改变了软件交付的方式。《码农翻身》把 DevOps 比作「工厂流水线」：代码是原材料，CI/CD 是流水线，监控是质检员。一切可自动化的都自动化，人只做决策和处理异常。

- **云计算模型**：SaaS → PaaS → IaaS，从上到下用户掌控越多

### CI/CD 五个阶段

1. **代码提交**：开发者 push 代码到版本库
2. **构建**：自动编译打包，生成可部署产物
3. **测试**：自动化单元测试、集成测试、端到端测试
4. **部署**：镜像发布到生产/预发布环境
5. **监控运维**：日志收集、告警、自动扩缩容、故障自愈

### 云计算三层模型

| 模型 | 全称 | 用户管什么 | 典型产品 |
|------|------|------------|----------|
| SaaS | 软件即服务 | 只管用 | Gmail / 钉钉 / CRM |
| PaaS | 平台即服务 | 管代码 | App Engine / 容器平台 |
| IaaS | 基础设施即服务 | 管操作系统以上 | EC2 / ECS / VPC |

从 SaaS 到 IaaS，用户掌控的层级越来越低，灵活性越来越强，但运维负担也越来越大。

### 容器化与编排

#### Docker

应用 + 环境打包为镜像，一次构建到处运行。镜像分层构建，轻量级隔离。

#### Kubernetes

容器编排调度平台：自动扩缩容、滚动更新/回滚、服务发现、负载均衡。

#### Serverless

无服务器计算：按需弹性执行，事件驱动，按调用付费。开发者只写函数逻辑。

### DevOps 文化

DevOps 不仅是工具链，更是一种文化：

- **开发 + 运维一体化**：打破部门墙，共同为交付负责
- **自动化一切可自动化之事**：消除手动瓶颈
- **基础设施即代码**：用代码管理环境配置
- **持续反馈改进**：监控数据驱动流程优化

## 术语表

| 术语 | 释义 |
|------|------|
| CI/CD | 持续集成与持续交付的自动化流水线 |
| SaaS | 软件即服务，开箱即用 |
| PaaS | 平台即服务，托管运行时 |
| IaaS | 基础设施即服务，虚拟机/网络/存储 |
| Docker | 容器化工具，应用与环境打包 |
| Kubernetes | 容器编排调度平台 |
| Serverless | 无服务器计算，按需弹性执行 |
| 基础设施即代码 | 用代码管理和配置基础设施 |
