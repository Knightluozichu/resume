<Objectives>

- 能给出状态含义：`dp[i]` 为包含第 `i` 个元素的最大子数组和。
- 能说明 O(1) 空间压缩实现。
- 能处理全负数组边界。

</Objectives>

## 直觉引入

每次到达 `i`，要么把 `nums[i]` 拼接到前一个连续段（赚得更大），要么从 `nums[i]` 重新开始（丢掉负债）。  
这就是“局部最优选择”。

## 概念讲解

$$
dp[i] = \max(nums[i], dp[i-1] + nums[i])
$$

全局答案是所有 `dp[i]` 的最大值。  
用两个变量即可完成：`current` 记录 `dp[i]`，`best` 记录全局。

## 思考引导

### 1) 先问问题，不先追求最大
在判断最大子数组和时，关键不是立刻输出答案，而是问“新元素到来时，当前最优段是否值得延续”。

### 2) 识别不变式
对每个位置 i，定义到 i 的最大子段和。如果它小于 0，就不应延续；一旦延续，历史信息就被压缩成一个标量。

### 3) 为什么它一定成立
因为负贡献段只会让后续总和更差；如果前缀和负数，舍弃它等价于从更优位置重新开始，最优子结构因此成立。

### 4) 常见误区
把“最大和”理解成“必须包含正值”会误导你，实际允许全负输入，答案可能只是最大的单个元素。

### 5) 你能找到一个反例吗
[ -2,1,-3,4,-1,2,1,-5,4 ] 会验证“先到一个负数就全段重置”是否过于激进；你要仅在累积小于 0 时才重置。

### 6) 迁移到下一题
凡是“局部累计、可重启”的线性问题，先做局部状态设计。你不是在找全部组合，而是在保留一条可持续的局部最优边界。

## 实现代码

```cpp
#include <vector>
#include <limits>

class Solution {
public:
    int maxSubArray(const std::vector<int>& nums) {
        if (nums.empty()) {
            return 0;
        }

        int current = nums[0];
        int best = nums[0];

        for (int i = 1; i < (int)nums.size(); ++i) {
            current = std::max(nums[i], current + nums[i]);
            best = std::max(best, current);
        }
        return best;
    }
};
```

```typescript
function maxSubArray(nums: number[]): number {
  if (!nums.length) return 0;

  let current = nums[0];
  let best = nums[0];
  for (let i = 1; i < nums.length; i++) {
    current = Math.max(nums[i], current + nums[i]);
    best = Math.max(best, current);
  }
  return best;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 初始化为 0 导致全负数组结果错误。  
  <strong>原因 →</strong> 约定“允许空子数组”与否不一致。  
  <strong>修复 →</strong> 题目要求至少一个元素时，初始化首元并返回 `max` 的最小值。
</Callout>
