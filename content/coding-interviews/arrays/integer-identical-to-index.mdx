<Objectives>

- 能定义函数 $f(i)=nums[i]-i$ 的单调性。
- 能写出二分搜索并处理重复值、无解。
- 能说明为什么有序与不含乱序是必要前提。

</Objectives>

## 直觉引入

在升序数组中，`nums[i] - i` 是非减的。  
当这个值大于 0，说明左侧偏大、答案在左边；小于 0 说明答案在右边。于是可直接二分。

## 概念讲解

传统扫描是 $O(n)$，利用有序性后可降到 $O(\log n)$。  
循环条件是 `left <= right`，命中后可继续找左右边界或直接返回一个位置。

## 思考引导

### 1) 先问问题，不先回扫描
你要找的是是否存在满足条件的“坐标-数值一致点”。有序性是这个题的第一级条件，不利用就会退回暴力。

### 2) 识别不变式
二分判定依据是：若 mid 的值大于索引，目标只能在左边；若小于索引，目标只能在右边。每次比较直接缩小 1/2 的搜索空间。

### 3) 为什么它一定成立
数组升序使得 nums[mid]-mid 的符号随下标变化有单调趋势。单调性保证了决策方向正确，不会遗漏可行点。

### 4) 常见误区
最常见是忽略重复值和负数边界导致 mid 公式偏移。比较逻辑只有正确处理整数边界才有意义。

### 5) 你能找到一个反例吗
[ -1,0,2,3 ] 里目标是 2。若起点/终点不闭区间处理好，可能跳过边界。

### 6) 迁移到下一题
任何“值与下标有函数关系”的题都先找可二分的单调关系。二分在这里不是加速手段，而是把“关系判断”前置后的自然结果。

```cpp
#include <vector>

class Solution {
public:
    int valueEqualIndex(const std::vector<int>& nums) {
        int left = 0, right = (int)nums.size() - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] == mid) return mid;
            if (nums[mid] < mid) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return -1;
    }
};
```

```typescript
function valueEqualIndex(nums: number[]): number {
  let left = 0;
  let right = nums.length - 1;
  while (left <= right) {
    const mid = Math.floor(left + (right - left) / 2);
    if (nums[mid] === mid) return mid;
    if (nums[mid] < mid) left = mid + 1;
    else right = mid - 1;
  }
  return -1;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 对乱序数组用二分仍能跑出错误值。  
  <strong>原因 →</strong> 单调性不成立。  
  <strong>修复 →</strong> 二分前确认题目给出“排序且严格递增/非严格递增”条件。
