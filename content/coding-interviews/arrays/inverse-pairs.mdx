<Objectives>

- 能在归并排序框架下解释“跨左右数组产生的逆序对数”。
- 能用 64 位返回大规模计数并规避溢出。
- 能处理重复元素时不重复计数。

</Objectives>

## 直觉引入

逆序对 `(i, j)` 要求 `i<j` 且 `nums[i] > nums[j]`，  
纯暴力 O(n²) 只是重算大量子序列。  
在归并排序里，局部有序后很容易“一次性”算出跨越两侧的逆序对。

## 概念讲解

当左半有序、右半有序时，若 `left[i] > right[j]`，则 `left[i..mid]` 与 `right[j]` 形成逆序对，数量是 `mid - i + 1`。
这比逐个比较快很多。

## 思考引导

### 1) 先问问题，不先计数
你在数的是“多少逆序对”，不是列举多少个错序。题目问的是统计规模，必须让计数在结构上可批量汇总。

### 2) 识别不变式
归并阶段左段和右段各自有序。每次取左端大于右端时，左段中从当前下标到末尾都会形成逆序对，可一次加总。

### 3) 为什么它一定成立
有序子数组意味着右段某元素与左段剩余元素之间的比较结果是连续区间一致的，不能再逐个对比。

### 4) 常见误区
把统计当作排序附属步骤，最终却拿到了正确排序但错乱计数。计数逻辑必须和分治边界同步更新。

### 5) 你能找到一个反例吗
[1,3,2,3,1] 的逆序对可检验“只加 1”与“加剩余长度”的差别。小样本能放大统计思路错误。

### 6) 迁移到下一题
凡是跨分割线要统计配对关系的题，都先看是否可在“有序合并”里批量计算，不要在外层写两重循环。
## 交互 Demo

你可以看到每次合并时，左侧较大元素落后于右侧时一次性累加多个计数。

<QuickSortDiagram />

```cpp
#include <vector>

class Solution {
public:
    long long mergeCount(std::vector<int>& nums, int l, int r, std::vector<int>& tmp) {
        if (l >= r) return 0;
        int m = l + (r - l) / 2;
        long long cnt = mergeCount(nums, l, m, tmp) + mergeCount(nums, m + 1, r, tmp);

        int i = l, j = m + 1, k = l;
        while (i <= m && j <= r) {
            if (nums[i] <= nums[j]) {
                tmp[k++] = nums[i++];
            } else {
                cnt += (m - i + 1);
                tmp[k++] = nums[j++];
            }
        }
        while (i <= m) tmp[k++] = nums[i++];
        while (j <= r) tmp[k++] = nums[j++];
        for (int p = l; p <= r; ++p) nums[p] = tmp[p];
        return cnt;
    }

    long long inversePairs(std::vector<int>& nums) {
        if (nums.empty()) return 0;
        std::vector<int> tmp(nums.size());
        return mergeCount(nums, 0, (int)nums.size() - 1, tmp);
    }
};
```

```typescript
function inversePairs(nums: number[]): number {
  if (!nums.length) return 0;
  const arr = [...nums];
  const tmp = new Array<number>(arr.length);

  const mergeCount = (l: number, r: number): number => {
    if (l >= r) return 0;
    const m = Math.floor((l + r) / 2);
    let count = mergeCount(l, m) + mergeCount(m + 1, r);

    let i = l, j = m + 1, k = l;
    while (i <= m && j <= r) {
      if (arr[i] <= arr[j]) tmp[k++] = arr[i++];
      else {
        count += m - i + 1;
        tmp[k++] = arr[j++];
      }
    }
    while (i <= m) tmp[k++] = arr[i++];
    while (j <= r) tmp[k++] = arr[j++];
    for (let p = l; p <= r; p++) arr[p] = tmp[p];
    return count;
  };

  return mergeCount(0, arr.length - 1);
}
```

<Callout type="trap">
  <strong>现象 →</strong> 结果为负数。  
  <strong>原因 →</strong> 用 `int` 累加逆序对在大规模下溢出。  
  <strong>修复 →</strong> 计数用 `long long` / `number`（含风险说明）。
</Callout>
