<Objectives>

- 能解释为何只需维护“截至当前的最低价格”。
- 能给出 O(n) 解并与暴力法对比。
- 能处理全递减序列收益为 0 的边界。

</Objectives>

## 直觉引入

如果你希望一次买入一次卖出，任何时刻的最佳收益只和两件事有关：  
历史最低买入价和当前位置卖出价。  
前者不断更新，后者滚动计算即可。

## 概念讲解

遍历价格数组：
- 更新 `minPrice = min(minPrice, price)`；
- 更新 `maxProfit = max(maxProfit, price - minPrice)`。  
一次扫描完成，时间 $O(n)$，空间 $O(1)$。

## 思考引导

### 1) 先问问题，不先追峰谷
买卖股票一次的利润，本质是时序状态选择：每天选择持有/非持有两种状态中的更优。不是简单找局部转折。

### 2) 识别不变式
每个时刻只要记录 “截至今天不持股的最大收益” 与 “持股后的最大收益” 两个状态，就足够转移。

### 3) 为什么它一定成立
因为动作集合只有买、卖、空手三类，且历史收益可压缩为这两个状态。状态机是最小充分表示。

### 4) 常见误区
以为能多次交易时不需要额外状态，结果一旦允许多次买卖就会混淆。这里只是单次时的最小状态模型。

### 5) 你能找到一个反例吗
[3,2,6,5,0,3] 如果只取局部低谷高峰，会错过整体更优组合。状态转移能稳住这种情况。

### 6) 迁移到下一题
资源开关、库存持有、会话状态都能抽象成这种“两个状态动态更新”。关键是确认动作是否对状态闭合。

```cpp
#include <vector>
#include <algorithm>
#include <climits>

class Solution {
public:
    int maxProfit(const std::vector<int>& prices) {
        if (prices.size() < 2) return 0;

        int minPrice = prices[0];
        int best = 0;
        for (int i = 1; i < (int)prices.size(); ++i) {
            best = std::max(best, prices[i] - minPrice);
            minPrice = std::min(minPrice, prices[i]);
        }
        return best;
    }
};
```

```typescript
function maxProfit(prices: number[]): number {
  if (prices.length < 2) return 0;

  let minPrice = prices[0];
  let best = 0;
  for (let i = 1; i < prices.length; i++) {
    best = Math.max(best, prices[i] - minPrice);
    minPrice = Math.min(minPrice, prices[i]);
  }
  return best;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 结果出现负数。  
  <strong>原因 →</strong> 默认要做一次买一次卖，不能强制成交。  
  <strong>修复 →</strong> `best` 初始化为 0，并在每步 `max` 保持非负。
</Callout>
