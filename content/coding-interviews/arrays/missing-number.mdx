<Objectives>

- 能证明异或抵消用于找单一缺失值的正确性。
- 能处理数组未排序和大小不为 n 的边界。
- 能对比哈希计数与异或方案的空间差异。

</Objectives>

## 直觉引入

`a ^ a = 0`，`a ^ 0 = a`。  
把完整区间 `[0, n]` 和给出的数组里的元素全部异或一次后，  
重复数字相互抵消，只留下缺失值。

## 概念讲解

设结果 `ans = 0`，先做 `ans ^= i`（0..n），再做 `ans ^= nums[i]`。
最终 `ans` 就是缺失的那个数字。  
这个方法不受顺序影响，且只需常量额外空间。

## 思考引导

### 1) 先问问题，不先盲算
缺失数目是域完整性核验，不是“谁最小没出现”。先确认数字域是否连续、是否有重复，才能选正确方法。

### 2) 识别不变式
若域是 0..n，全部异或后消去成对值，剩下的结果就是唯一缺失者。异或的对消是不可见噪声消除机制。

### 3) 为什么它一定成立
异或具备自反性和交换律，成对元素抵消为 0，0 与 x 异或仍为 x。只要前提成立，结果可唯一恢复。

### 4) 常见误区
把它当成普适解忽视输入含重复或缺漏范围变化，导致假设失效。求和法也有溢出风险。

### 5) 你能找到一个反例吗
若数组含重复且缺口不在预期范围，异或会仍出数但不代表答案。先用小样本验证约束再走公式。

### 6) 迁移到下一题
ID 可靠性、日志序列校验都常见相同思想。先问“域定义是否完整”，再判断是否可用对消模型。
## 交互 Demo

每一步异或展示“成对消失”的过程，最后剩余位恰是缺失位。

<HashTableDiagram />

```cpp
#include <vector>

class Solution {
public:
    int missingNumber(const std::vector<int>& nums) {
        int n = nums.size();
        int ans = 0;
        for (int i = 0; i <= n; ++i) {
            ans ^= i;
        }
        for (int num : nums) {
            ans ^= num;
        }
        return ans;
    }
};
```

```typescript
function missingNumber(nums: number[]): number {
  let ans = 0;
  for (let i = 0; i <= nums.length; i++) {
    ans ^= i;
  }
  for (const num of nums) {
    ans ^= num;
  }
  return ans;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 误将区间写成 `[1,n]`。  
  <strong>原因 →</strong> 题目通常是 `[0,n]`。  
  <strong>修复 →</strong> 清楚缺失范围再执行异或。
</Callout>
