<Objectives>

- 能描述“成对消除”为什么能留下多数元素。
- 能实现一次遍历选候选，再做二次验证。
- 能处理不存在多数元素的输入。

</Objectives>

## 直觉引入

如果某个值出现次数超过一半，它与“其他所有数”都能配对消掉一部分，但仍会留下余数。  
投票法就是把这个抵消过程写成两变量流程。

## 概念讲解

阶段一：`candidate` 与 `count` 扫描，遇到相同 `++`，不同 `--`。  
`count` 为 0 时换候选。  
阶段二：对候选做完整计数验证是否超过 `n/2`。

## 思考引导

### 1) 先问问题，不先计数
超过一半元素的存在性是判定性问题。先确认是否满足前提，再判断是否要返回该候选。

### 2) 识别不变式
摩尔投票核心是不变式：不同元素两两抵消不会影响多数元素。抵消后剩余候选如果存在，即潜在多数。

### 3) 为什么它一定成立
多数元素出现次数 > n/2，任何把它和其他元素配对移除的操作都不会消掉多数元素的“净优势”。

### 4) 常见误区
第一遍只做抵消不验证最终计数，会在“并无多数”时给出伪结果。必须做二次校验。

### 5) 你能找到一个反例吗
[1,2,3,4] 不存在多数元素。仅靠抵消会留下一个候选，必须再计数确认是否过半。

### 6) 迁移到下一题
当你在日志或意见里找“主导项”时，先做候选压缩，再做计数验证，这比直接全量计数更稳。
## 交互 Demo

每一位“同号支持/异号抵消”都能直接看到计数归零与候选变化。

```cpp
#include <vector>

class Solution {
public:
    int majorityElement(const std::vector<int>& nums) {
        int candidate = 0, count = 0;
        for (int x : nums) {
            if (count == 0) {
                candidate = x;
                count = 1;
            } else if (x == candidate) {
                ++count;
            } else {
                --count;
            }
        }

        int verify = 0;
        for (int x : nums) if (x == candidate) ++verify;
        return (verify * 2 > (int)nums.size()) ? candidate : -1;
    }
};
```

```typescript
function majorityElement(nums: number[]): number {
  let candidate = 0;
  let count = 0;

  for (const x of nums) {
    if (count === 0) {
      candidate = x;
      count = 1;
    } else if (x === candidate) count++;
    else count--;
  }

  let verify = 0;
  for (const x of nums) if (x === candidate) verify++;
  return verify * 2 > nums.length ? candidate : -1;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 直接返回 `candidate` 却未验证。  
  <strong>原因 →</strong> 输入不满足“存在多数元素”时候，会被错误命中。  
  <strong>修复 →</strong> 做第二次计数校验。
</Callout>
