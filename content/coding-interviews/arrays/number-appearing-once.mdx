<Objectives>

- 能证明单独出现一次元素的异或消元性。
- 能给出 O(n) 且 O(1) 空间实现。
- 能说明该方法适用前提（成对重复）及其限制。

</Objectives>

## 直觉引入

成对重复的数异或后为 0，0 与任何数异或是其本身。  
把数组全部异或一遍后，所有成对数抵消，剩下的就是只出现一次的值。

## 概念讲解

这是最典型“位运算降维”技巧之一，循环一遍可得到结果。

## 思考引导

### 1) 先问问题，不先举例
只出现一次的数，本质是偶数次成对分布中的异常值提取。是否所有其他元素都成对，是第一约束。

### 2) 识别不变式
异或可对偶消元：任意 x xor x = 0，0 xor x = x。连续异或遍历后，成对元素消失，孤立值留存。

### 3) 为什么它一定成立
这是可交换群的性质，不依赖顺序，输入顺序变化也不影响最终残余。

### 4) 常见误区
把“只出现一次”误当作“频次最少”，会在更多异常值/重复模式下失效。题目约束决定能否只用一个聚合器。

### 5) 你能找到一个反例吗
[2,2,1,1,1] 若前提不符（不是除了一个都出现两次），异或逻辑会输出错误，需要额外校验或改方法。

### 6) 迁移到下一题
这套思路适用于“成对抵消可恢复唯一信号”的场景，如会话标识、校验码去噪。先看可消元性。
## 交互 Demo

展示每一步异或后位模式如何互相抵消，最后只留下唯一者。

<HashTableDiagram />

```cpp
#include <vector>

class Solution {
public:
    int singleNumber(const std::vector<int>& nums) {
        int x = 0;
        for (int num : nums) {
            x ^= num;
        }
        return x;
    }
};
```

```typescript
function singleNumber(nums: number[]): number {
  let x = 0;
  for (const num of nums) {
    x ^= num;
  }
  return x;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 出现一次不止一个元素时结果错误。  
  <strong>原因 →</strong> 题目前提不成立。  
  <strong>修复 →</strong> 先确认输入约束；若有变化则改用哈希计数法。
