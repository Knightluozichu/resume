## 直觉引入

所有数异或后留下的是两个只出现一次数字的异或结果 `xor2`。  
`xor2` 的某一位为 1，说明两个目标数在该位上不同。  
依据这一位将数组分成两组，分别异或即可解出两位数。

## 概念讲解

选择 `mask = xor2 & -xor2`（最低位 1），让两个只出现一次数被分入不同组；重复值会在组内成对抵消。

## 思考引导

### 1) 先问问题，不先回归朴素
两个只出现一次的数意味着“全体成对后剩两个异或结果”，不是直接分组。关键是如何找到稳定的划分位。

### 2) 识别不变式
全体异或得到一个非零差分位。这个位能把两个目标严格分到两组，组内仍满足成对可消除。

### 3) 为什么它一定成立
两个不同数在该位上必不同，按此位拆分后，其他配对元素仍在各组成对，异或后即可恢复目标。

### 4) 常见误区
随意选取分组位会把两个目标落同组，导致再次异或后仍是成对，答案消失。必须以异或差分位作为分界。

### 5) 你能找到一个反例吗
数组 [1,1,2,3] 如果你固定按最低位分组可行，但若无差分位指导，部分输入会被误划。

### 6) 迁移到下一题
这类题训练“先提炼可分离特征再局部归约”，可迁移到错误项双识别、双异常检测。

```cpp
#include <vector>

class Solution {
public:
    std::vector<int> singleNumbers(const std::vector<int>& nums) {
        int xorAll = 0;
        for (int x : nums) xorAll ^= x;

        int mask = xorAll & (-xorAll);
        int a = 0, b = 0;
        for (int x : nums) {
            if (x & mask) a ^= x;
            else b ^= x;
        }
        return {a, b};
    }
};
```

```typescript
function singleNumbers(nums: number[]): number[] {
  let xorAll = 0;
  for (const x of nums) xorAll ^= x;
  const mask = xorAll & -xorAll;

  let a = 0;
  let b = 0;
  for (const x of nums) {
    if (x & mask) a ^= x;
    else b ^= x;
  }
  return [a, b];
}
```

<Callout type="trap">
  <strong>现象 →</strong> 只找到一个数或重复值。  
  <strong>原因 →</strong> `mask` 提取错误（例如取了最高位）。  
  <strong>修复 →</strong> 使用 `xor & -xor` 保证最低不同位分组。
</Callout>
