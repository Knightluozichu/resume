<Objectives>

- 掌握**边界缩减法**（Boundary Shrink）：用 `top`、`bottom`、`left`、`right` 四个指针表示未遍历区域的边界，每遍历一条边后收缩对应指针。
- 理解为什么在遍历完上边和右边之后必须进行**边界碰撞检查**（`top > bottom` 或 `left > right`），以防止单行/单列矩阵的元素被重复打印。
- 能处理所有**边界情况**：空矩阵、1×1 矩阵、单行矩阵、单列矩阵。
- 编写包含完整防护逻辑的 C++ 和 TypeScript 实现。

</Objectives>

## 直觉引入

想象你手中有一个洋葱——你可以从最外层一圈一圈地剥：

*   **最外圈**：先沿上边从左向右划一刀，再沿右边从上向下划一刀，再沿下边从右向左划一刀，最后沿左边从下向上划一刀——这就是顺时针剥一层的完整路径。
*   **层层深入**：剥掉最外圈后，露出来的是一个小一圈的矩阵。对这个更小的矩阵重复同样的剥皮动作，直到剥到中心没有更多层为止。

这就是**边界缩减法**的核心直觉：每剥一圈，四面的边界各向内缩一步，直到边界彼此交叉代表矩阵已被完全遍历。

## 概念讲解

### 1. 四边界模型

维护四个变量表示当前"未处理矩阵"的上下左右边界：

| 变量 | 初始值 | 含义 |
|------|--------|------|
| `top` | `0` | 当前最上方未遍历行 |
| `bottom` | `rows - 1` | 当前最下方未遍历行 |
| `left` | `0` | 当前最左未遍历列 |
| `right` | `cols - 1` | 当前最右未遍历列 |

### 2. 一圈的四步遍历

在 `while (top <= bottom && left <= right)` 的循环中：

1. **上边（→）**：遍历 `matrix[top][left..right]`，然后 `top++`。
2. **右边（↓）**：遍历 `matrix[top..bottom][right]`，然后 `right--`。
3. **下边（←）**：⚠️ 先检查 `top <= bottom`，再遍历 `matrix[bottom][right..left]`，然后 `bottom--`。
4. **左边（↑）**：⚠️ 先检查 `left <= right`，再遍历 `matrix[bottom..top][left]`，然后 `left++`。

### 3. 为什么第 3、4 步需要额外检查？

考虑一个单行矩阵 `[1, 2, 3]`：

- 第 1 步遍历完后 `top=1`，此时 `top > bottom=0`。
- 如果不检查就执行第 3 步（下边从右向左），会反向重复打印 `3, 2, 1`。

类似地，单列矩阵如果不在第 4 步前检查 `left <= right`，也会重复打印已遍历的元素。

## 代码对照

<CodeTabs>
  <Tab label="C++">
```cpp
#include <vector>
using namespace std;

class Solution {
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        vector<int> result;
        if (matrix.empty() || matrix[0].empty()) return result;

        int top = 0, bottom = matrix.size() - 1;
        int left = 0, right = matrix[0].size() - 1;

        while (top <= bottom && left <= right) {
            // 上边：从左到右
            for (int i = left; i <= right; ++i)
                result.push_back(matrix[top][i]);
            ++top;

            // 右边：从上到下
            for (int i = top; i <= bottom; ++i)
                result.push_back(matrix[i][right]);
            --right;

            // 下边：从右到左（检查 top <= bottom 防止单行重复）
            if (top <= bottom) {
                for (int i = right; i >= left; --i)
                    result.push_back(matrix[bottom][i]);
                --bottom;
            }

            // 左边：从下到上（检查 left <= right 防止单列重复）
            if (left <= right) {
                for (int i = bottom; i >= top; --i)
                    result.push_back(matrix[i][left]);
                ++left;
            }
        }

        return result;
    }
};
```

```typescript
function spiralOrder(matrix: number[][]): number[] {
  if (!matrix.length || !matrix[0].length) return [];

  const result: number[] = [];
  let top = 0, bottom = matrix.length - 1;
  let left = 0, right = matrix[0].length - 1;

  while (top <= bottom && left <= right) {
    // 上边：从左到右
    for (let i = left; i <= right; i++)
      result.push(matrix[top][i]);
    top++;

    // 右边：从上到下
    for (let i = top; i <= bottom; i++)
      result.push(matrix[i][right]);
    right--;

    // 下边：从右到左（检查 top <= bottom 防止单行重复）
    if (top <= bottom) {
      for (let i = right; i >= left; i--)
        result.push(matrix[bottom][i]);
      bottom--;
    }

    // 左边：从下到上（检查 left <= right 防止单列重复）
    if (left <= right) {
      for (let i = bottom; i >= top; i--)
        result.push(matrix[i][left]);
      left++;
    }
  }

  return result;
}
```

## 常见误区

<Callout type="trap">
  <strong>现象 →</strong> 单行矩阵 <code>[1, 2, 3]</code> 输出了 <code>[1, 2, 3, 2, 1]</code>，元素被重复打印。
  <strong>原因 →</strong> 遍历完上边后 <code>top</code> 递增为 1，此时 <code>top &gt; bottom = 0</code>，但未检查就继续执行下边遍历（从右到左），反向重复扫了一遍。
  <strong>修复 →</strong> 在执行下边遍历前加入 <code>if (top &lt;= bottom)</code> 检查。同理在左边遍历前加 <code>if (left &lt;= right)</code>。
</Callout>

<Callout type="trap">
  <strong>现象 →</strong> 遍历完上边后忘记执行 <code>top++</code>，导致程序陷入无限循环。
  <strong>原因 →</strong> 边界指针没有收缩，下一轮循环仍从同一行开始遍历，四步中的遍历区域从未缩小，永远满足 <code>top &lt;= bottom</code> 条件。
  <strong>修复 →</strong> 确保每条边遍历完成后，立即将对应的边界指针收缩（<code>top++</code>、<code>right--</code>、<code>bottom--</code>、<code>left++</code>）。
</Callout>

<Callout type="trap">
  <strong>现象 →</strong> 将边界碰撞检查放在了 <code>while</code> 循环外，而不是在循环内部的第 3、4 步之前。
  <strong>原因 →</strong> 外层 <code>while</code> 条件只在每轮开始时检查一次。进入循环后执行完前两步，边界已经变化，此时需要再次检查才能保证第 3、4 步不越界。如果只依赖外层条件，奇数行/列的矩阵最后一圈仍会出问题。
  <strong>修复 →</strong> 在 <code>while</code> 循环体内部、第 3 步和第 4 步之前各加一次 <code>if</code> 检查。
</Callout>

## 小结与练习

- **边界缩减法** 是模拟类矩阵题的标准范式，适用于螺旋遍历、螺旋填充、旋转矩阵等一系列矩阵操作题。
- 关键防御点在于**每条边遍历后的碰撞检查**，这是区分「正确」和「看似正确实则有 bug」代码的分水岭。
- 时间 O(M × N)、空间 O(1)（不计输出），是该问题的最优复杂度。

<Exercises>
  <Answer question="如果要求逆时针打印矩阵，算法需要怎样调整？">
    逆时针的遍历顺序变为：左列从上到下 → 下行从左到右 → 右列从下到上 → 上行从右到左。只需把四个 for 循环的方向按逆时针重新排列，同时对应调整边界收缩的顺序（先 left++ 而非 top++），算法框架和碰撞检查逻辑完全不变。
  </Answer>
  <Answer question="如何利用相同的边界缩减法生成一个 N×N 的螺旋矩阵（把 1~N² 填入矩阵）？">
    创建一个 N×N 的空矩阵，初始化 top/bottom/left/right 四个边界。使用一个从 1 开始的计数器 num，按顺时针四方向循环往矩阵格子里填值（`matrix[r][c] = num++`），每条边填完后收缩边界并做交叉检查。循环结束时 num = N²+1，矩阵即为螺旋矩阵。时空复杂度均为 O(N²)。
  </Answer>
</Exercises>

## 名词解释

<Glossary>
  <GlossaryItem term="边界缩减法 (Boundary Shrink)">
    一种模拟遍历策略，通过维护上下左右四个边界指针来标识当前未处理区域，每遍历一条边后将对应边界向内收缩一步，层层剥洋葱般缩小范围直到所有元素被覆盖。
  </GlossaryItem>
  <GlossaryItem term="边界碰撞检查 (Boundary Collision Check)">
    在螺旋遍历中，每缩减一条边界后检查对向边界是否已经交叉（如 top > bottom 或 left > right）。这一检查是防止在单行/单列矩阵中出现元素重复打印的关键防御机制。
  </GlossaryItem>
  <GlossaryItem term="螺旋矩阵 (Spiral Matrix)">
    将连续整数按顺时针螺旋路径填入 N×N 网格后得到的矩阵，是边界缩减法的逆向应用（读取→填充）。
  </GlossaryItem>
</Glossary>
