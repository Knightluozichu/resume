<Objectives>

- 能说明数组有序时双指针为什么能 O(n)。
- 能处理重复值与不存在解的情况。
- 能对比排序后双指针与原序未排序哈希解。

</Objectives>

## 直觉引入

有序后，左指针指小数，右指针指大数。  
和偏小则左移右推；和偏大则右移左收。每步都有方向单调，复杂度降到线性。

## 概念讲解

若题目未说有序，先排序再做双指针是常见工程化路线；若要求不改动原顺序，可退化为哈希映射。

## 思考引导

### 1) 先问问题，不先遍历
先确认输入是否有序。双指针依赖单调，数组未排序时先排序会改变问题成本和约束。

### 2) 识别不变式
当和小于目标时，左指针右移只会增大和；和大于目标时，右指针左移只会减小和。这是每一步决策正确性的单调不变式。

### 3) 为什么它一定成立
有序数组中元素顺序给了值与索引的单调映射。你在区间上进行剪枝，不会漏掉解。

### 4) 常见误区
很多人忘了重复值或多解场景，直接 early return 只返回一组。必须先读明题意是找一组还是全部。

### 5) 你能找到一个反例吗
数组 [2,2,3,4], target=6 在双指针策略下可验证是否允许重复返回单解，是否会跳过可行组合。

### 6) 迁移到下一题
双端约束配对搜索适用于预算配对、时间窗口对齐等场景。先用排序与单调性让搜索线性化。
## 交互 Demo

双指针的“夹逼”过程非常适合图示：和在上下界之间收敛。

<BinarySearchDiagram />

```cpp
#include <vector>

class Solution {
public:
    std::vector<int> twoSum(const std::vector<int>& nums, int target) {
        int i = 0, j = (int)nums.size() - 1;
        while (i < j) {
            int sum = nums[i] + nums[j];
            if (sum == target) {
                return {nums[i], nums[j]};
            } else if (sum < target) {
                ++i;
            } else {
                --j;
            }
        }
        return {};
    }
};
```

```typescript
function twoSum(nums: number[], target: number): number[] {
  let left = 0;
  let right = nums.length - 1;
  while (left < right) {
    const sum = nums[left] + nums[right];
    if (sum === target) return [nums[left], nums[right]];
    if (sum < target) left++;
    else right--;
  }
  return [];
}
```

<Callout type="trap">
  <strong>现象 →</strong> 输入未排序仍用双指针失效。  
  <strong>原因 →</strong> 单调性前提丢失。  
  <strong>修复 →</strong> 先排序（允许排序时）或切换哈希解。
</Callout>
