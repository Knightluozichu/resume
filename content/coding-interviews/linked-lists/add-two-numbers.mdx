<Objectives>

- 能用一趟遍历完成两个非负整数的链式加法。
- 能处理不同长度链表和末尾进位。
- 能给出稳定的 C++ 与 TypeScript 表达式实现。

</Objectives>

## 直觉引入

把最低位看作头节点，两个链表从头开始逐位加，正好对应人算加法“从右向左进位”。  
链表正是把“位序”自然保留下来的数据结构。

## 概念讲解

核心是维护 `carry`，每步：

$$
sum = v_1 + v_2 + carry,\quad digit = sum \bmod 10,\quad carry = \lfloor sum/10 \rfloor
$$

最后若 `carry>0` 再补一位节点。

## 思考引导

### 1) 先问问题，不先算长度
链表加法本质是“异步流逐位对齐”。长度不同或 null 对齐时，关键是让每一位都有确定来源。

### 2) 识别不变式
进位只依赖当前位和上一位进位，处理完每一位后进位传到下一位。状态是常数维。

### 3) 为什么它一定成立
十进制按位加法的数学性质决定了位间独立，除了 carry 不会影响更高位前的决定。

### 4) 常见误区
漏掉尾部进位或把 null 节点当 0 处理不一致，会导致丢数。还有一种是用 while(l||r) 但没处理进位尾。

### 5) 你能找到一个反例吗
9->9 与 1->0 相加会产生新节点，若未统一处理尾进位，结果会错。这类最小反例是最有效的边界测试。

### 6) 迁移到下一题
所有流式对齐累加场景（计费分钟、时间片加总）都可借鉴“逐位递推 + 显式 carry”。
## 交互 Demo

可视化演示每一位如何加和写入，特别是最后可能出现的额外进位位。

<RecursionDiagram />

```cpp
#include <vector>

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int v) : val(v), next(nullptr) {}
};

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        ListNode dummy(0);
        ListNode* tail = &dummy;
        int carry = 0;

        while (l1 || l2 || carry) {
            int s = carry;
            if (l1) { s += l1->val; l1 = l1->next; }
            if (l2) { s += l2->val; l2 = l2->next; }

            tail->next = new ListNode(s % 10);
            tail = tail->next;
            carry = s / 10;
        }

        return dummy.next;
    }
};
```

```typescript
class ListNode {
  val: number;
  next: ListNode | null = null;
  constructor(val: number) {
    this.val = val;
  }
}

function addTwoNumbers(l1: ListNode | null, l2: ListNode | null): ListNode | null {
  const dummy = new ListNode(0);
  let p1: ListNode | null = l1;
  let p2: ListNode | null = l2;
  let carry = 0;
  let tail: ListNode = dummy;

  while (p1 || p2 || carry) {
    let sum = carry;
    if (p1) { sum += p1.val; p1 = p1.next; }
    if (p2) { sum += p2.val; p2 = p2.next; }

    tail.next = new ListNode(sum % 10);
    tail = tail.next;
    carry = Math.floor(sum / 10);
  }

  return dummy.next;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 最后一位忘记补 `carry`。  
  <strong>原因 →</strong> 条件只判断了链表是否为空。  
  <strong>修复 →</strong> 循环条件加入 `|| carry`。
</Callout>
