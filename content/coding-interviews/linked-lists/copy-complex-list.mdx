<Objectives>

- 能恢复旧节点与新节点的一一映射关系。
- 能分别解决 `random` 与 `next` 指针的复制。
- 能解释为什么先插入再拆分能实现 O(1) 额外空间。

</Objectives>

## 直觉引入

复杂链表不仅有 `next`，还有 `random`。  
复制时不能只复制 `next`，因为 `random` 可能指向任意已访问或未访问节点。  
把“旧节点 -> 新节点”关系先建立好，后续才能正确恢复 `random`。

## 概念讲解

方法一（哈希）：第一遍复制值与 next；第二遍根据 map 设置 random。  
方法二（O(1) 空间）：在原链表每个节点后插入复制节点，再修正 random 后拆解。

## 思考引导

### 1) 先问问题，不先遍历复制
复杂链表不只是复制值，而是复制身份关系。你要解决的核心是 random 指针的映射可重建性。

### 2) 识别不变式
将复制节点紧邻原节点后插入，能够让原节点与其复制节点通过 next 联系，从而在 O(1) 本地定位 random 目标。

### 3) 为什么它一定成立
每条原链边在结构上有对应复制边；插入操作保持顺序一致，使“原节点到复制节点”的关系在一次遍历中可恢复。

### 4) 常见误区
只复制 next 忘了 random，不只是内容丢失，更会破坏后续逻辑。另一个坑是拆分阶段提前恢复会破坏映射。

### 5) 你能找到一个反例吗
随机指针形成环或跨层引用的链表上，可用于检验你是否真的按身份重建，而非值匹配。

### 6) 迁移到下一题
对象图复制、缓存节点迁移都面临引用关系复原。关键从“值复制”迁移到“身份映射”。

```cpp
#include <unordered_map>

struct Node {
    int val;
    Node* next;
    Node* random;
    Node(int v) : val(v), next(nullptr), random(nullptr) {}
};

class Solution {
public:
    Node* copyRandomList(Node* head) {
        if (!head) return nullptr;
        std::unordered_map<Node*, Node*> mp;

        Node* cur = head;
        while (cur) {
            mp[cur] = new Node(cur->val);
            cur = cur->next;
        }

        cur = head;
        while (cur) {
            mp[cur]->next = mp[cur->next];
            mp[cur]->random = mp[cur->random];
            cur = cur->next;
        }

        return mp[head];
    }
};
```

```typescript
class ComplexNode {
  val: number;
  next: ComplexNode | null = null;
  random: ComplexNode | null = null;
  constructor(val: number) {
    this.val = val;
  }
}

function copyRandomList(head: ComplexNode | null): ComplexNode | null {
  if (!head) return null;
  const map = new Map<ComplexNode, ComplexNode>();
  let cur: ComplexNode | null = head;
  while (cur) {
    map.set(cur, new ComplexNode(cur.val));
    cur = cur.next;
  }
  cur = head;
  while (cur) {
    const cloned = map.get(cur)!;
    cloned.next = cur.next ? map.get(cur.next) || null : null;
    cloned.random = cur.random ? map.get(cur.random) || null : null;
    cur = cur.next;
  }
  return map.get(head) || null;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 遍历完后 `random` 全是 `null`。  
  <strong>原因 →</strong> 只复制了 `next` 关系。  
  <strong>修复 →</strong> 在映射建立后单独补充 `random` 映射。
</Callout>
