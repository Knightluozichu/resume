<Objectives>

- 能区分“值相同”和“节点相同”（地址）两种交点含义。
- 能用双指针一次走完即得交点。
- 能处理不相交、同头等边界。

</Objectives>

## 直觉引入

两个链表一旦相交，后续节点地址完全一致。  
问题变成：从哪个起点开始同步走，才能在同一时刻撞到第一段共享节点？

## 概念讲解

方法一：两次遍历先算长度 `lenA,lenB`，长链先走 `abs(lenA-lenB)` 步后齐步前进。  
第一次节点地址相同即答案。  
如果无交点，两指针同时到 `nullptr`。

## 思考引导

### 1) 先问问题，不先比值
公共节点问题判断的是“同一引用节点”首次交汇，不是 “同值节点”。把对象身份与数值拆开。

### 2) 识别不变式
两个指针各自走完一次后再重头，长度差会在走法中自动抵消，最终等速同步，首次相等即为第一交汇。

### 3) 为什么它一定成立
两条链尾齐步后，剩余步长完全相同。若存在交汇，交汇点及其后路径一致；若无则都到 null。

### 4) 常见误区
把数组式找共同值写入链表问题，或用额外集合但不保留引用语义。都不能保证题意。

### 5) 你能找到一个反例吗
两条链尾部共享值相同但非同一引用的场景，能快速暴露你是否混淆了“值”和“身份”。

### 6) 迁移到下一题
在事件流合并、调用链归并时，先想“是否需要按引用对齐”，再决定是否用长度校准策略。
## 交互 Demo

看齐后指针同步，命中前的异步节点逐步消失，最终在交点处收敛。

<TreeDiagram />

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

class Solution {
public:
    int len(ListNode* h) {
        int n = 0;
        while (h) { ++n; h = h->next; }
        return n;
    }

    ListNode* getIntersectionNode(ListNode* a, ListNode* b) {
        int la = len(a), lb = len(b);
        while (la > lb) { a = a->next; --la; }
        while (lb > la) { b = b->next; --lb; }
        while (a && b) {
            if (a == b) return a;
            a = a->next;
            b = b->next;
        }
        return nullptr;
    }
};
```

```typescript
class ListNode {
  val: number;
  next: ListNode | null = null;
  constructor(val: number) {
    this.val = val;
  }
}

function listLength(h: ListNode | null): number {
  let n = 0;
  while (h) {
    n++;
    h = h.next;
  }
  return n;
}

function getIntersectionNode(a: ListNode | null, b: ListNode | null): ListNode | null {
  let la = listLength(a);
  let lb = listLength(b);
  while (la > lb && a) {
    a = a.next;
    la--;
  }
  while (lb > la && b) {
    b = b.next;
    lb--;
  }
  while (a && b) {
    if (a === b) return a;
    a = a.next;
    b = b.next;
  }
  return null;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 比较值而非地址，导致误报交点。  
  <strong>原因 →</strong> 题目要求的是物理共享节点。  
  <strong>修复 →</strong> 对比 `a == b`（同一内存引用）。
</Callout>
