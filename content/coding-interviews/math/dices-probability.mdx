<Objectives>

- 能从单颗骰子迁移到 n 颗骰子的状态转移。
- 能避免重复统计边界并做归一化输出。
- 能比较 O(n²) 状态与滚动优化思路。

</Objectives>

## 直觉引入

一个骰子有 6 种可能。  
两个骰子就是把第一个骰子的所有和与第二个骰子的 6 种值做“卷积”。  
推广到 `n` 个骰子，仍是叠加同样的转移关系。

## 概念讲解

`dp[i][s]` 表示抛出 `i` 个骰子和为 `s` 的方案数。  
转移：

$$
dp[i][s] = \sum_{k=1}^{6} dp[i-1][s-k]
$$

可用滚动数组节省空间。

## 思考引导

### 1) 先问问题，不先查表
问的是分布演化过程，不是某个固定公式。每加一个骰子，本质是在已有分布上进行“可叠加卷积”。

### 2) 识别不变式
第 i 个骰子下和的范围是 [i,6i]，状态转移只依赖上一轮范围。越界值应保持 0，这就是边界不变式。

### 3) 为什么它一定成立
独立同分布下，和的概率是多组加和的叠加，状态转移是线性叠加且归一。

### 4) 常见误区
很多实现只写“1..6 的叠加”却没限制 j 下界/上界，导致读旧状态。范围剪裁是稳定结果的关键。

### 5) 你能找到一个反例吗
n=2 时和为 2..12 的分布很不均衡，边缘值频率能快速暴露归一与边界是否正确。

### 6) 迁移到下一题
独立事件叠加类（评分模型、分段置信）都用同套路：先定状态空间，再做卷积转移。
## 交互 Demo

每加一颗骰子，概率质量在可能和区间内向右平移并扩展，图形上会看到“峰值变宽”。

```cpp
#include <vector>

class Solution {
public:
    std::vector<double> dicesProbability(int n) {
        if (n <= 0) return {};
        const double total = std::pow(6.0, n);
        std::vector<std::vector<long long>> dp(n + 1, std::vector<long long>(6 * n + 1, 0));
        dp[0][0] = 1;

        for (int i = 1; i <= n; ++i) {
            for (int s = i; s <= 6 * i; ++s) {
                long long cnt = 0;
                for (int face = 1; face <= 6; ++face) {
                    if (s - face >= 0) cnt += dp[i - 1][s - face];
                }
                dp[i][s] = cnt;
            }
        }

        std::vector<double> prob;
        for (int s = n; s <= 6 * n; ++s) {
            prob.push_back(dp[n][s] / total);
        }
        return prob;
    }
};
```

```typescript
function dicesProbability(n: number): number[] {
  if (n <= 0) return [];
  const total = Math.pow(6, n);
  const dp: number[][] = Array.from({ length: n + 1 }, () => Array(6 * n + 1).fill(0));
  dp[0][0] = 1;

  for (let i = 1; i <= n; i++) {
    for (let s = i; s <= 6 * i; s++) {
      let cnt = 0;
      for (let face = 1; face <= 6; face++) {
        if (s - face >= 0) cnt += dp[i - 1][s - face];
      }
      dp[i][s] = cnt;
    }
  }

  const prob: number[] = [];
  for (let s = n; s <= 6 * n; s++) {
    prob.push(dp[n][s] / total);
  }
  return prob;
}
```
