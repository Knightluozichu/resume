<Objectives>

- 能推导 1 位、2 位、3 位区间贡献长度。
- 能用 `n` 的偏移量在数字范围内定位具体数字和具体位。
- 能处理越界和大数 n 的减法边界。

</Objectives>

## 直觉引入

把序列 `0,1,2,3,...` 看成块状拼接：1 位数 10 个，2 位数 90 个，3 位数 900 个...  
你可以先减掉整块，再在当前块内做局部定位，省下枚举成本。

## 概念讲解

`len=1` 时有 9 个（通常不含 0，可按题目约定）；每位数个数为 `9*10^(len-1)`，总字符数是 `count*len`。  
定位到某个数字后，通过 `(offset / len)` 和 `offset % len` 得到目标字符。

## 思考引导

### 1) 先问问题，不先拼字符串
核心不是打印 1..∞，而是从“位级块”上定位第 n 位。直接构造太慢，关键是先做层级缩放。

### 2) 识别不变式
1 位数块有 `9` 个，2 位数块有 `90*2` 位，`k` 位数块有 `9*10^(k-1)*k` 位。每次去掉完整块后 `n` 的规模严格减小。

### 3) 为什么它一定成立
数字长度分层后，每层元素长度固定，位置映射就变成整除与取模问题，不再受前缀内容影响。

### 4) 常见误区
常见错误是把起始块设成 0 位，或把每层长度写成 10^k，忽略首位不能为 0 的约束。

### 5) 你能找到一个反例吗
n 在边界 10、100 附近时最容易暴露层划分和减法顺序是否准确。

### 6) 迁移到下一题
任何“序列位置反查”问题都能先分段，再在段内定位。先把映射变成数学求解，而不是枚举。
## 交互 Demo

每轮剥离一个位数块，直到 `n` 落在某个“同位数区间”，更清晰地看到位级索引折算。

<BinarySearchDiagram />

```cpp
#include <string>

class Solution {
public:
    int kthNumberChar(int n) {
        long long len = 1;
        long long base = 1;
        while (n > (base * 9 * len)) {
            n -= base * 9 * len;
            base *= 10;
            len++;
        }
        long long index = (n - 1) / len;
        long long digit = (n - 1) % len;
        long long num = base + index;
        return std::to_string(num)[digit] - '0';
    }
};
```

```typescript
function kthNumberChar(n: number): number {
  let len = 1;
  let base = 1;
  while (n > base * 9 * len) {
    n -= base * 9 * len;
    base *= 10;
    len++;
  }
  const index = Math.floor((n - 1) / len);
  const digit = (n - 1) % len;
  const num = base + index;
  return Number(String(num).charAt(digit));
}
```

<Callout type="trap">
  <strong>现象 →</strong> 第 n 位定位偏移一个位置。  
  <strong>原因 →</strong> 常见 off-by-one（`n-1` 处理遗漏）。  
  <strong>修复 →</strong> 在计算 `index` 与 `digit` 前先用 `n-1` 建模为 0 基索引。
</Callout>
