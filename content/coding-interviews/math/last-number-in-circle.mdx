<Objectives>

- 能从删除一轮后幸存者位置映射到长度 n-1 的子问题。
- 能写出递推闭式 `f(n,m)=(f(n-1,m)+m)%n`。
- 能处理大规模 n,m 的溢出风险和 1 基下标转换。

</Objectives>

## 直觉引入

每次删去第 `m` 个元素后，下一次计数其实从被删元素的下一位重新开始。  
这和“坐标重映射”高度一致：把原问题压缩到 `n-1` 大小的问题，再把结果映射回来。

## 概念讲解

定义 `f(n)` 为有 `n` 人时最终胜者的 0 基索引。  
则

$$
f(1)=0,\quad f(n)=(f(n-1)+m)\mod n
$$

逐步扩展到 n 即可。

## 思考引导

### 1) 先问问题，不先模拟
约瑟夫问题最危险的是把“圆形淘汰”理解成 O(n^2) 模拟。真正问题是求闭式关系如何递推。

### 2) 识别不变式
每次缩减规模后，幸存者编号会发生统一偏移，缩小规模后的结果可映射回上一规模。

### 3) 为什么它一定成立
淘汰规则固定，编号变化可视作一次同构重命名；递推公式 f(n,m) = (f(n-1,m)+m)%n 反映了这种同构。

### 4) 常见误区
少了偏移 + 1 的边界处理就会整体偏移。尤其 n=1 或 m=1 时容易崩。

### 5) 你能找到一个反例吗
n=5,m=3 是经典小样本，能检验公式是否在每轮恢复原编号时偏移正确。

### 6) 迁移到下一题
循环淘汰、轮询分配、周期淘汰题可先找“规模缩减后的状态映射关系”，避免显式模拟。
## 交互 Demo

演示每次淘汰后索引如何折返，最终得到原始环上的生存者编号。

<RecursionDiagram />

```cpp
class Solution {
public:
    int lastRemaining(int n, int m) {
        long long ans = 0;
        for (int i = 2; i <= n; ++i) {
            ans = (ans + m) % i;
        }
        return (int)ans;
    }
};
```

```typescript
function lastRemaining(n: number, m: number): number {
  let ans = 0;
  for (let i = 2; i <= n; i++) {
    ans = (ans + m) % i;
  }
  return ans;
}
```

<Callout type="trap">
  <strong>现象 →</strong> 只返回 0 基索引而题目要求 1 基。  
  <strong>原因 →</strong> 题目定义与实现坐标不同。  
  <strong>修复 →</strong> 明确题目是 0..n-1 还是 1..n，必要时 `ans + 1`。
</Callout>
