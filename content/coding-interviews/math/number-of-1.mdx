<Objectives>

- 能把“从 1 到 n 数 1”拆成每个十进制位的独立贡献。
- 掌握 `high`、`cur`、`low` 三段分解，并根据当前位是否为 0、1、大于 1 套用不同公式。
- 能处理 `n <= 0`、个位、跨 10/100 边界等容易出错的输入。
- 能写出 $O(\log n)$ 时间、$O(1)$ 空间的实现。

</Objectives>

## 核心思路

暴力从 `1` 枚举到 `n` 再逐位数 1，复杂度接近 $O(n \log n)$。更好的办法是逐位统计：个位上出现多少个 1，十位上出现多少个 1，百位上出现多少个 1，然后求和。

假设当前统计的位权是 `digit`，例如个位 `digit = 1`，十位 `digit = 10`。把 `n` 拆成三段：

```text
n = high * digit * 10 + cur * digit + low
```

其中：

| 名称 | 含义 |
|---|---|
| `high` | 当前位左边的高位数字 |
| `cur` | 当前位数字 |
| `low` | 当前位右边的低位数字 |

## 公式

当前位上数字 1 的出现次数只由 `cur` 分三种情况：

- `cur == 0`：贡献 `high * digit`
- `cur == 1`：贡献 `high * digit + low + 1`
- `cur > 1`：贡献 `(high + 1) * digit`

例如 `n = 21345`，统计百位时 `digit = 100`：

```text
high = 213
cur  = 4
low  = 45
```

因为 `cur > 1`，所以百位上为 1 的完整区间多了一整轮，贡献是 `(213 + 1) * 100 = 21400`。

## 代码对照

<CodeTabs>
  <Tab label="C++">
```cpp
long long countDigitOne(long long n) {
    if (n <= 0) return 0;

    long long ans = 0;
    for (long long digit = 1; digit <= n; digit *= 10) {
        long long high = n / (digit * 10);
        long long cur = (n / digit) % 10;
        long long low = n % digit;

        if (cur == 0) {
            ans += high * digit;
        } else if (cur == 1) {
            ans += high * digit + low + 1;
        } else {
            ans += (high + 1) * digit;
        }
    }

    return ans;
}
```

function countDigitOne(n: number): number {
  if (n <= 0) return 0;

  let ans = 0;
  for (let digit = 1; digit <= n; digit *= 10) {
    const high = Math.floor(n / (digit * 10));
    const cur = Math.floor(n / digit) % 10;
    const low = n % digit;

    if (cur === 0) ans += high * digit;
    else if (cur === 1) ans += high * digit + low + 1;
    else ans += (high + 1) * digit;
  }

  return ans;
}

## 常见误区

<Callout type="trap">
  <strong>现象 →</strong> `n = 13` 算成 5 或 7。
  <strong>原因 →</strong> 当前位为 1 时没有加上 `low + 1`，或者把 `cur > 1` 的整轮贡献误套到 `cur == 1`。
  <strong>修法 →</strong> 牢牢记住三分支：0 看高位，1 看高位加低位，其余看高位加一轮。
</Callout>
