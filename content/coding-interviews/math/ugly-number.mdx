<Objectives>

- 理解丑数定义：只包含质因子 2、3、5 的正整数。
- 掌握用三个指针分别追踪下一个乘 2、乘 3、乘 5 候选值。
- 能处理重复候选值，例如 `6 = 2 * 3 = 3 * 2`。
- 能写出求第 `n` 个丑数的 $O(n)$ 时间实现。

</Objectives>

## 核心思路

丑数序列从 `1` 开始。后续每个丑数都可以由前面的某个丑数乘以 `2`、`3` 或 `5` 得到。

维护数组 `ugly`，以及三个指针：

| 指针 | 含义 |
|---|---|
| `p2` | 下一个候选值 `ugly[p2] * 2` |
| `p3` | 下一个候选值 `ugly[p3] * 3` |
| `p5` | 下一个候选值 `ugly[p5] * 5` |

每轮取三个候选值的最小值作为下一个丑数。然后所有等于这个最小值的指针都向前移动。

为什么要“所有相等指针都移动”？因为同一个丑数可能从不同路径生成，比如 `6` 可以由 `3 * 2` 或 `2 * 3` 得到。如果只移动一个指针，下一轮会重复生成 `6`。

## 代码对照

<CodeTabs>
  <Tab label="C++">
```cpp
#include <vector>
#include <algorithm>

int getUglyNumber(int n) {
    if (n <= 0) return 0;

    std::vector<int> ugly(n);
    ugly[0] = 1;
    int p2 = 0, p3 = 0, p5 = 0;

    for (int i = 1; i < n; ++i) {
        int next2 = ugly[p2] * 2;
        int next3 = ugly[p3] * 3;
        int next5 = ugly[p5] * 5;
        int next = std::min(next2, std::min(next3, next5));

        ugly[i] = next;

        while (ugly[p2] * 2 <= next) ++p2;
        while (ugly[p3] * 3 <= next) ++p3;
        while (ugly[p5] * 5 <= next) ++p5;
    }

    return ugly[n - 1];
}
```

```typescript
function getUglyNumber(n: number): number {
  if (n <= 0) return 0;

  const ugly = new Array<number>(n);
  ugly[0] = 1;
  let p2 = 0;
  let p3 = 0;
  let p5 = 0;

  for (let i = 1; i < n; i++) {
    const next = Math.min(ugly[p2] * 2, ugly[p3] * 3, ugly[p5] * 5);
    ugly[i] = next;

    while (ugly[p2] * 2 <= next) p2++;
    while (ugly[p3] * 3 <= next) p3++;
    while (ugly[p5] * 5 <= next) p5++;
  }

  return ugly[n - 1];
}
```

<Callout type="trap">
  <strong>现象 →</strong> 序列里出现重复的 6、10、15。
  <strong>原因 →</strong> 三个候选值有相等时，只移动了其中一个指针。
  <strong>修法 →</strong> 对所有满足 `candidate <= next` 的指针都前移。
</Callout>
