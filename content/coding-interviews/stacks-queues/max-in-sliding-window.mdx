## 直觉引入

普通方法每次重算窗口最大值是 O(k)，窗口有 n 次就会变成 O(nk)。
实际上我们只要保留“有可能成为最大值”的候选索引：
小于新元素的旧候选可以直接淘汰。

## 算法思路

1. 维护双端队列 `deque`（存下标），要求对应值单调递减。
2. 新索引 `r` 入队前，弹出队尾所有 `nums[idx] <= nums[r]`。
3. 移除过期索引 `deque.front <= r-k`。
4. 队首始终是当前窗口最大值位置。

## 思考引导

### 1) 先问问题，不先全量扫
这题是实时窗口最大值。若每次都扫窗口，复杂度不可控。先问每个新元素如何影响现有候选。

### 2) 识别不变式
双端队列中只保留可能成为将来最大值的递减候选，过小且更早到达的值可被淘汰。

### 3) 为什么它一定成立
若一个值前面有更大值且更早出现，那么在其过期前它永远不可能成为最大值。递减队列是可证明的可达集。

### 4) 常见误区
队列只存值不存下标会导致过期元素误判；另一类是 pop_front 条件与窗口左边界没对齐。

### 5) 你能找到一个反例吗
序列 [1,3,-1,-3,5,3,6,7], k=3，过期边界变化快，能检验是否按下标清除。

### 6) 迁移到下一题
监控、限流、实时排行都用同模式：维护候选单调性，配合窗口过期规则。

```cpp
#include <deque>
#include <vector>

class Solution {
public:
    std::vector<int> maxInWindows(const std::vector<int>& nums, int k) {
        std::deque<int> q;
        std::vector<int> ans;

        for (int r = 0; r < (int)nums.size(); ++r) {
            while (!q.empty() && nums[q.back()] <= nums[r]) q.pop_back();
            q.push_back(r);

            if (q.front() <= r - k) q.pop_front();

            if (r >= k - 1) {
                ans.push_back(nums[q.front()]);
            }
        }
        return ans;
    }
};
```

function maxSlidingWindow(nums: number[], k: number): number[] {
    const q: number[] = [];
    const ans: number[] = [];

    for (let r = 0; r < nums.length; r++) {
        while (q.length > 0 && nums[q[q.length - 1]] <= nums[r]) q.pop();
        q.push(r);

        if (q[0] <= r - k) q.shift();

        if (r >= k - 1) {
            ans.push(nums[q[0]]);
        }
    }
    return ans;
}
