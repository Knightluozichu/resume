## 直觉引入

核心是“延迟搬运”：`
`appendTail` 先进 `inStack`，`deleteHead` 从 `outStack` 弹出；
当 `outStack` 空时整体倒到 `outStack`。
每个栈里再各存一份当前最大值，查询最大值时只取两栈最大值的较大者。

## 算法思路

1. `push(x)`：入 `inStack` 时同步更新 `inMax`。
2. `max()`：比较 `inMax` 栈顶和 `outMax` 栈顶。
3. `pop()`：若 `outStack` 为空，把 `inStack` 全部转移到 `outStack`。
4. `pop` 元素时返回 `outStack` 栈顶，并同步弹出 `outMax`。

## 思考引导

### 1) 先问问题，不先写 API
普通队列要支持最大值查询，你要先问是“时间复杂度约束”还是“空间约束”。两者都不满足时才考虑替代结构。

### 2) 识别不变式
主队列按入队顺序保留元素，辅队列保留单调候选。弹出时若辅队列头等于弹出值才失效。

### 3) 为什么它一定成立
每次插入时删除比新值小的候选尾，确保辅队列从前到后非递增。这样前端始终是当前窗口最大值。

### 4) 常见误区
只维护 one stack 会失去先出先出语义，导致最大值查询错位；只维护值序列也无法剔除已出队失效项。

### 5) 你能找到一个反例吗
操作 1,3,2, 出队, 查询最大值，若没同步辅队列失效，马上暴露错误。

### 6) 迁移到下一题
有“数据结构同时满足查询与淘汰”的系统里，主副结构协同是常用模板，先确认更新与失效同步。

```cpp
#include <vector>
#include <climits>

class MaxQueue {
public:
    void push_back(int value) {
        in.push_back(value);
        int mx = inMax.empty() ? value : std::max(value, inMax.back());
        inMax.push_back(mx);
    }

    int pop_front() {
        if (out.empty()) transfer();
        int value = out.back();
        out.pop_back();
        outMax.pop_back();
        return value;
    }

    int max() const {
        int left = inMax.empty() ? INT_MIN : inMax.back();
        int right = outMax.empty() ? INT_MIN : outMax.back();
        return left > right ? left : right;
    }

private:
    void transfer() {
        while (!in.empty()) {
            int x = in.back();
            in.pop_back();
            inMax.pop_back();

            out.push_back(x);
            int mx = outMax.empty() ? x : std::max(x, outMax.back());
            outMax.push_back(mx);
        }
    }

    std::vector<int> in, inMax;
    std::vector<int> out, outMax;
};
```

```typescript
class MaxQueue {
    private in: number[] = [];
    private inMax: number[] = [];
    private out: number[] = [];
    private outMax: number[] = [];

    push(value: number): void {
        this.in.push(value);
        this.inMax.push(this.inMax.length ? Math.max(this.inMax[this.inMax.length - 1], value) : value);
    }

    pop(): number {
        if (this.out.length === 0) this.transfer();
        if (this.out.length === 0) throw new Error('queue is empty');

        this.outMax.pop();
        return this.out.pop()!;
    }

    getMax(): number {
        const left = this.inMax.length ? this.inMax[this.inMax.length - 1] : Number.NEGATIVE_INFINITY;
        const right = this.outMax.length ? this.outMax[this.outMax.length - 1] : Number.NEGATIVE_INFINITY;
        return Math.max(left, right);
    }

    private transfer(): void {
        while (this.in.length > 0) {
            const x = this.in.pop()!;
            this.inMax.pop();
            this.out.push(x);
            this.outMax.push(this.outMax.length ? Math.max(this.outMax[this.outMax.length - 1], x) : x);
        }
    }
}
```
