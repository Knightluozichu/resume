## 直觉引入

“第一次只出现一次”的字符随流变化有两类状态：

- 从未出现过（候选区）；
- 已出现超过一次（永远不可能再成为答案）。

用一个 `count[256]` 记录次数，用一个队列按到达顺序记住“可能是答案”的字符。
每次取首字符前，把队列顶部已失效的字符弹掉即可。

## 算法思路

1. `Insert(ch)`：计数加一；若第一次出现，`push` 到队列。
2. `firstAppearingOnce()`：当队列非空且队首字符 `count > 1` 时弹队。
3. 返回队首字符；若队列空返回 `#`。

## 思考引导

### 1) 先问问题，不先统计
流式第一个不重复字符不是一次性查询，是持续到达下如何保持“当前答案”。你要先确定状态更新规则。

### 2) 识别不变式
计数低于 1 的字符可能成为候选，但必须与最早到达时间配合判断。计数只能告诉你是否重复，不能告诉你“最早”。

### 3) 为什么它一定成立
输入只增不改，位置具有单调递增特征。候选集合可在每次到达后局部更新，不需重算全串。

### 4) 常见误区
很多实现只做计数数组，不跟踪首次位置；结果会在两个同频字符间选错。

### 5) 你能找到一个反例吗
流 “a b a c” 下，出现 a 重复后“a”应从候选中移除，候选变为 b 才对。

### 6) 迁移到下一题
实时日志、实时告警里同类“最新有效唯一值”问题都能复用“计数+时间”联合更新。
## 代码对照

<CodeTabs>
  <Tab label="C++">
```cpp
#include <array>
#include <queue>

class StreamChecker {
public:
    void Insert(char ch) {
        if (cnt[ch]++ == 0) {
            q.push(ch);
        }
    }

    char firstAppearingOnce() {
        while (!q.empty() && cnt[q.front()] > 1) {
            q.pop();
        }
        return q.empty() ? '#': q.front();
    }

private:
    std::array<int, 256> cnt{};
    std::queue<char> q;
};
```
  </Tab>
  <Tab label="TypeScript">
```typescript
class StreamChecker {
    private cnt: Map<string, number> = new Map();
    private queue: string[] = [];

    insert(ch: string): void {
        const next = (this.cnt.get(ch) ?? 0) + 1;
        this.cnt.set(ch, next);
        if (next === 1) {
            this.queue.push(ch);
        }
    }

    firstAppearingOnce(): string {
        while (this.queue.length > 0 && (this.cnt.get(this.queue[0]) ?? 0) > 1) {
            this.queue.shift();
        }
        return this.queue.length > 0 ? this.queue[0] : '#';
    }
}
```
  </Tab>

<Callout type="trap">
  <strong>现象 →</strong> `firstAppearingOnce` 长度越来越慢。
  <strong>原因 →</strong> 用 `Array.shift()` 每次 O(n) 移动。
  <strong>修复 →</strong> 生产实现建议用双索引队列；这里仅示意清晰性。
</Callout>
