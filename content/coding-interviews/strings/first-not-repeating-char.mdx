## 直觉引入

第一个不重复字符在不断变化：新字符进来后，原有答案可能被击败。
用“计数表 + 队列”就能在每次查询时即时判断，避免每次全表扫描。

## 算法思路

1. `Insert(ch)`：计数 +1；首次出现推入队列。
2. `firstAppearingOnce()`：把队列头部中 `count > 1` 的字符弹出。
3. 弹完后队首即为实时答案；若为空返回 `#`。

## 思考引导

### 1) 先问问题，不先遍历
你要找的是“当前字符串中最早且只出现一次”的字符，不是出现次数最低的字符。顺序约束必须进入状态。

### 2) 识别不变式
计数表判断是否唯一，队列/下标结构判断“谁最早”。两者缺一都不能确定正确答案。

### 3) 为什么它一定成立
流量或静态字符串都可看作“频次 + 位置”双约束问题。唯一性不是充分条件，位置是必要条件。

### 4) 常见误区
只在遍历后排序字符，会打乱原始顺序。应在一遍内或少遍历下保持先后关系。

### 5) 你能找到一个反例吗
字符串 "abaccdeff" 时，b 在早期是候选，但后续若变重复需立即剔除。

### 6) 迁移到下一题
推荐列表去重、指纹去抖都在做“频次与时序”的联合决策。

<CodeTabs>
  <Tab label="C++">
```cpp
#include <array>
#include <queue>

class FirstUnique {
public:
    void Insert(char ch) {
        auto &v = cnt[static_cast<unsigned char>(ch)];
        ++v;
        if (v == 1) {
            q.push(ch);
        }
    }

    char firstNotRepeating() {
        while (!q.empty() && cnt[static_cast<unsigned char>(q.front())] > 1) {
            q.pop();
        }
        return q.empty() ? '#': q.front();
    }

private:
    std::array<int, 256> cnt{};
    std::queue<char> q;
};
```

  <Tab label="TypeScript">
```typescript
class FirstUnique {
    private cnt = new Array(256).fill(0);
    private queue: string[] = [];

    insert(ch: string): void {
        const code = ch.charCodeAt(0) & 0xff;
        this.cnt[code] += 1;
        if (this.cnt[code] === 1) {
            this.queue.push(ch);
        }
    }

    firstNotRepeating(): string {
        while (
            this.queue.length > 0 &&
            this.cnt[this.queue[0].charCodeAt(0) & 0xff] > 1
        ) {
            this.queue.shift();
        }
        return this.queue.length > 0 ? this.queue[0] : '#';
    }
}
```
