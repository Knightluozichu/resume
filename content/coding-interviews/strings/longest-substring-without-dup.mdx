## 直觉引入

维持一个窗口 `[l, r]`，窗口中永远不允许重复字符。
当 `r` 扩张遇到重复，就把 `l` 移到重复字符上一次出现位置后；这样每个字符只进出一次，整体线性。

## 算法思路

1. 记录每个字符上一次出现位置 `last[char]`（初始为 `-1`）。
2. 遍历字符索引 `r`：
   - 若 `last[ch] >= l`，说明在窗口内重复，令 `l = last[ch] + 1`。
   - 更新 `last[ch] = r`。
   - 更新答案 `maxLen = max(maxLen, r-l+1)`。

## 思考引导

### 1) 先问问题，不先穷举
目标是最长无重复子串，要把“是否有冲突”变成可在线更新而非重复检索。

### 2) 识别不变式
窗口左边界只会右移；每次新字符若重复，左边界跳到重复字符上次出现+1。

### 3) 为什么它一定成立
字符串字符重复位置有界性。更新左边界后，旧冲突的字符必不在新窗口内，因而可直接舍弃。

### 4) 常见误区
只用 set 但不维护上次出现位置，会在重复字符回退时做多次移动，复杂度与正确性都变差。

### 5) 你能找到一个反例吗
"abba" 能暴露处理重复时窗口重置策略是否正确：第二个 b 到来后 l=2，a 位置也需更新。

### 6) 迁移到下一题
连续行为、登录异常窗口、点击去重都可套“窗口+最近出现位置”范式。

<CodeTabs>
  <Tab label="C++">
```cpp
#include <string>
#include <array>

class Solution {
public:
    int longestSubstringWithoutDup(const std::string& s) {
        std::array<int, 256> last;
        last.fill(-1);

        int left = 0;
        int best = 0;

        for (int right = 0; right < (int)s.size(); ++right) {
            unsigned char c = static_cast<unsigned char>(s[right]);
            if (last[c] >= left) {
                left = last[c] + 1;
            }
            last[c] = right;
            best = std::max(best, right - left + 1);
        }
        return best;
    }
};
```

function longestSubstringWithoutDup(s: string): number {
    const last = new Array(256).fill(-1);
    let left = 0;
    let best = 0;

    for (let right = 0; right < s.length; right++) {
        const code = s.charCodeAt(right) & 0xff;
        if (last[code] >= left) {
            left = last[code] + 1;
        }
        last[code] = right;
        best = Math.max(best, right - left + 1);
    }
    return best;
}
