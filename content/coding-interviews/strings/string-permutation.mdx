## 直觉引入

排列要求“每个字符只用一次”。当字符有重复时，必须把“同一层重复值重复选择”这件事剪掉，不然会大量产生日志上重复的结果。

## 算法思路

1. 排序字符，等值字符在原序列中相邻；
2. 回溯构造路径，`used[i]` 表示位置 `i` 是否已用；
3. 在同一层跳过 `chars[i] === chars[i - 1] && !used[i - 1]` 这个分支；
4. 路径长度等于长度时收割一个结果。

## 思考引导

### 1) 先问问题，不先枚举
本题考的是“状态树去重”，不是把每个字符无脑打散。重复字符会让路径爆炸。

### 2) 识别不变式
每一层只允许同一字符在同深度第一次使用。若与前一个字符重复且前一个未用，本层跳过可避免等价路径。

### 3) 为什么它一定成立
等值字符交换不改变结果序列，路径剪枝消除了同构分支，仍保留每种结果一次。

### 4) 常见误区
先生成后去重能消除重复结果但仍承担巨大计算；时间远高于在树层直接剪枝。

### 5) 你能找到一个反例吗
字符串 "aab" 若无同层剪枝会生成重复排列。用此例检验剪枝条件是否生效。

### 6) 迁移到下一题
调度、测试矩阵构造中经常有等价路径，先在状态层判断“是否重复再进入”，再做深搜。

```cpp
#include <algorithm>
#include <string>
#include <vector>

class Solution {
public:
    vector<string> Permutation(string str) {
        vector<string> ans;
        if (str.empty()) return ans;

        sort(str.begin(), str.end());
        vector<bool> used(str.size(), false);
        string path;

        function<void()> dfs = [&]() {
            if (path.size() == str.size()) {
                ans.push_back(path);
                return;
            }

            for (int i = 0; i < (int)str.size(); i++) {
                if (used[i]) {
                    continue;
                }
                if (i > 0 && str[i] == str[i - 1] && !used[i - 1]) {
                    continue;
                }

                used[i] = true;
                path.push_back(str[i]);
                dfs();
                path.pop_back();
                used[i] = false;
            }
        };

        dfs();
        return ans;
    }
};
```

```typescript
function stringPermutation(str: string): string[] {
  if (!str.length) {
    return [];
  }

  const chars = [...str].sort();
  const used = new Array(chars.length).fill(false);
  const path: string[] = [];
  const res: string[] = [];

  const dfs = () => {
    if (path.length === chars.length) {
      res.push(path.join(""));
      return;
    }

    for (let i = 0; i < chars.length; i++) {
      if (used[i]) continue;
      if (i > 0 && chars[i] === chars[i - 1] && !used[i - 1]) continue;

      used[i] = true;
      path.push(chars[i]);
      dfs();
      path.pop();
      used[i] = false;
    }
  };

  dfs();
  return res;
}
```

## 易错点

- 未明确边界时最容易误判。
- 状态更新顺序与方向一旦错误，通常会产生重复计数或遗漏。
- 若问题含重复数据或极大规模，时间复杂度和空间复用是验收重点。

## 小结

- 先写出状态定义，再写状态转移。
- 先写正常路径，再补齐边界。
- 复杂度先估，复用再做。
