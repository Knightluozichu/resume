## 直觉引入

这题是“状态机 + 溢出守卫”组合题。输入字符串按位消费时，始终只需要维护三个变量：

- 当前位置
- 符号位
- 已累积数值 `value`

每读取一位数字，`value = value * 10 + digit`，只要这一位更新会越界，就立即返回边界值。

## 算法思路

1. 跳过前导空格。
2. 处理可选符号位。
3. 逐位处理数字字符，直到遇到非数字退出。
4. 每次更新前检查是否超过 `INT_MAX/10` 或 `INT_MIN`。

## 思考引导

### 1) 先问问题，不先转值
字符串转整数先做输入语义边界定义：空白、符号、非数字、越界。没有这一步，转换会变成玄学行为。

### 2) 识别不变式
解析状态只有符号、索引、累计值三个核心量，每前进一步都应保持：当前累计值可由前值和当前字符唯一确定。

### 3) 为什么它一定成立
十进制累加是线性状态机，唯一性与前缀一致。只要越界预检充分，停止条件明确。

### 4) 常见误区
只在尾部检查越界会漏中间溢出。遇到长串必须在每步乘 10 前做边界判断。

### 5) 你能找到一个反例吗
"2147483648" 在有符号 32 位应饱和到上界。此输入可验证你是否在每步都判断了临界值。

### 6) 迁移到下一题
所有外部输入解析（配置、API 字段）都先定义协议边界，再写状态转换，不要先追求“看起来能跑”。
## 实现代码

```cpp
#include <climits>
#include <cctype>
#include <string>

class Solution {
public:
    int StrToInt(string str) {
        if (str.empty()) return 0;

        int i = 0;
        while (i < (int)str.size() && isspace(static_cast<unsigned char>(str[i]))) {
            i++;
        }
        if (i == (int)str.size()) return 0;

        int sign = 1;
        if (str[i] == '+' || str[i] == '-') {
            sign = (str[i] == '-') ? -1 : 1;
            i++;
        }
        if (i == (int)str.size() || !isdigit(static_cast<unsigned char>(str[i]))) {
            return 0;
        }

        long long value = 0;
        while (i < (int)str.size() && isdigit(static_cast<unsigned char>(str[i]))) {
            int digit = str[i] - '0';
            long long next = value * 10 + digit;

            if (sign == 1 && next > INT_MAX) return INT_MAX;
            if (sign == -1 && -next < INT_MIN) return INT_MIN;

            value = next;
            i++;
        }

        return sign == 1 ? static_cast<int>(value) : -static_cast<int>(value);
    }
};
```

```typescript
function stringToInt(str: string): number {
  const INT_MAX = 2_147_483_647;
  const INT_MIN = -2_147_483_648;

  if (str.length === 0) return 0;

  let i = 0;
  while (i < str.length && str[i] === " ") {
    i++;
  }
  if (i === str.length) return 0;

  let sign = 1;
  if (str[i] === "+" || str[i] === "-") {
    sign = str[i] === "-" ? -1 : 1;
    i++;
  }
  if (i === str.length) return 0;

  let value = 0;
  while (i < str.length) {
    const code = str.charCodeAt(i);
    if (code < 48 || code > 57) {
      break;
    }

    const next = value * 10 + (code - 48);
    if (sign === 1 && next > INT_MAX) {
      return INT_MAX;
    }
    if (sign === -1 && -next < INT_MIN) {
      return INT_MIN;
    }

    value = next;
    i++;
  }

  return sign === 1 ? value : -value;
}
```

## 易错点

- 空串、全空格、符号后无数字需要直接返回 0。
- 字符串只消费到首段有效数字，后面垃圾字符忽略。
- 溢出应在更新前拦截，不能等到返回时再处理。

## 小结

这道题的核心是“先清洗输入，再安全累加”，而不是追求复杂技巧。
