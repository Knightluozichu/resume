<Objectives>

- 能把问题转成“当前位置可选翻译数”DP。
- 能处理前导 `0` 和两位数边界。
- 能写出 C++ 与 TypeScript 的线性时空实现。

</Objectives>

## 直觉引入

把数字串当作从左到右的序列。到每个位置时可选两类切分：

- 取 1 位，前提是当前位非 `0`；
- 取 2 位，前提是 `10 <= num <= 25`。

因此 `dp[i]` 只依赖于 `dp[i+1]` 与 `dp[i+2]`。

<DynamicProgrammingDiagram />

## 算法思路

1. 定义 `dp[i]`：从 `nums[i...]` 开始可翻译的种数。
2. 初始化：`dp[n] = 1`（空串有一种不消费方式）。
3. 自右向左填表：
   - 默认 `dp[i] = dp[i+1]`；
   - 若 `nums[i..i+1]` 在 10..25 间，则再加 `dp[i+2]`。

## 思考引导

### 1) 先问问题，不先递归
这是一个分段计数问题。你先把“每个位置可选切分”抽象出来，再决定递归还是 DP。

### 2) 识别不变式
`dp[i]` 表示从第 `i` 位到末尾的翻译方法数。转移来自 `dp[i+1]`（单字）和 `dp[i+2]`（双字）两种合法状态。

### 3) 为什么它一定成立
当前选择只影响到当前位以及下一位范围。重叠子问题自然出现，DP 通过共享状态避免重复树。

### 4) 常见误区
把 `0` 当单独字符直接计入，或把两位数条件写成 `>=10` 且 `<=26` 混乱，会把非法映射引入。

### 5) 你能找到一个反例吗
"101" 能检验你是否处理了 10 与 01 的合法性边界。

### 6) 迁移到下一题
文本分词、编码路径统计都可复用“局部转移 + 合法性判断 + 重叠合并”的框架。
## 实现代码

<CodeTabs>
  <Tab label="C++">
```cpp
#include <string>
#include <vector>

class Solution {
public:
    int translateNum(string nums) {
        int n = (int)nums.size();
        if (n == 0) return 0;

        std::vector<int> dp(n + 1, 0);
        dp[n] = 1;

        for (int i = n - 1; i >= 0; --i) {
            if (nums[i] == '0') {
                dp[i] = dp[i + 1];
                continue;
            }

            dp[i] = dp[i + 1];

            if (i + 1 < n) {
                int two = (nums[i] - '0') * 10 + (nums[i + 1] - '0');
                if (two >= 10 && two <= 25) {
                    dp[i] += dp[i + 2];
                }
            }
        }

        return dp[0];
    }
};
```

```typescript
function translateNumbersToStrings(nums: string): number {
  const n = nums.length;
  if (n === 0) return 0;

  const dp = new Array(n + 1).fill(0);
  dp[n] = 1;

  for (let i = n - 1; i >= 0; i--) {
    if (nums[i] === "0") {
      dp[i] = dp[i + 1];
      continue;
    }

    let ways = dp[i + 1];
    if (i + 1 < n) {
      const two = Number(nums.slice(i, i + 2));
      if (two >= 10 && two <= 25) {
        ways += dp[i + 2];
      }
    }
    dp[i] = ways;
  }

  return dp[0];
}
```

## 易错点

- `0` 在题目语义里不能独立翻译，不可直接 `dp[i+1]`。 
- 两位数边界是 `10` 到 `25`，不是 `00` 到 `99`。
- 大多数语言都可能出现较大结果，若题目要求可加模数；当前实现按原题返回完整整数。

## 小结

这类“编码”问题常见公式：每一步都在“取单字符”与“取两字符”之间选择并叠加。
