## 直觉引入

平衡树要求“局部约束”严格控制在每个节点：左右子树高度差不能超过 1。
如果每个节点都要比较左高、右高，这个信息只有在处理完两个子树后才知道，所以前序或中序都不适合；
**后序（子问题先算完）**才能在一次递归中高效收敛答案。

## 算法思路

1. 递归函数 `height(node)`：返回该子树高度；一旦检测到该子树失衡，返回 `-1`。
2. 遍历到空节点返回高度 `0`。
3. 左右子树分别得到 `left`、`right`。
4. 任一子树高度为 `-1` 时直接返回 `-1`，避免无效继续计算。
5. 若 `abs(left - right) > 1`，返回 `-1`。
6. 否则返回 `max(left, right) + 1`。

根节点返回值不是 `-1`，说明树平衡。

## 思考引导

### 1) 先问问题，不先数层
平衡树问题是最坏路径风险控制，不是求某条路径长度。你要问：树是否允许退化？

### 2) 识别不变式
以任一节点为根，左右子树高度差绝对值不能超过 1（或约定范围）。这是平衡判定局部不变式。

### 3) 为什么它一定成立
若任一子树偏斜超过阈值，则从该点到叶子的最长路径被放大，最坏查询复杂度失控。

### 4) 常见误区
只在某一层抽样检查而不做递归聚合会误判。高度是自底向上决定的。

### 5) 你能找到一个反例吗
一棵左偏链表形状树高度极大，却可能叶子很少。最坏深度指标才是关键。

### 6) 迁移到下一题
数据库索引和缓存树结构都面临这个风险。先确定可接受的路径上界，再定义是否必须平衡。

  <Tab label="C++">
```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    bool isBalanced(TreeNode* root) {
        return height(root) != -1;
    }

private:
    int height(TreeNode* node) {
        if (node == nullptr) return 0;

        int left = height(node->left);
        if (left == -1) return -1;

        int right = height(node->right);
        if (right == -1) return -1;

        if (left - right > 1 || right - left > 1) return -1;
        return std::max(left, right) + 1;
    }
};
```

```typescript
class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;
    }
}

function isBalanced(root: TreeNode | null): boolean {
    function height(node: TreeNode | null): number {
        if (!node) return 0;

        const left = height(node.left);
        if (left === -1) return -1;

        const right = height(node.right);
        if (right === -1) return -1;

        if (Math.abs(left - right) > 1) return -1;
        return Math.max(left, right) + 1;
    }

    return height(root) !== -1;
}
```

## 常见误区

<Callout type="trap">
  <strong>现象 →</strong> 结果偶尔会错误但看不出来。
  <strong>原因 →</strong> 用前序遍历重复统计高度，虽然看起来正确但复杂度退化。
  <strong>修复 →</strong> 换成后序返回高度，并用 `-1` 做失衡短路。
</Callout>

## 小结

- 后序遍历让“子树信息”先生成。
- 以返回码携带失败状态，能把不平衡传播到根节点，且只遍历一次。

<Callout type="tip">
  <strong>复习提醒：</strong> 记住这类题的模式：递归返回一个“值”，并用特定常量表示非法/失败状态。
</Callout>
