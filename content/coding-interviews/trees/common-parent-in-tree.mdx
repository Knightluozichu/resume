<Objectives>

- 能用递归判断“目标是否在某子树”并返回最早满足的公共祖先。
- 能处理节点不存在、重复值或退化树时的边界行为。
- 能给出 C++ 与 TypeScript 的稳定实现。

</Objectives>

## 直觉引入

两个节点的最近公共祖先，本质上是“在树上寻找第一个汇合点”。
递归遍历时，每个节点只需要回答两个问题：

- 在我的左子树能不能找到 `p`/`q`？
- 在我的右子树能不能找到 `p`/`q`？

当一个节点本身就是 `p` 或 `q`，它天然是“候选”。左/右各有一侧命中时，这个节点就是最近公共祖先。

## 算法思路

1. 递归函数 `dfs(node)` 返回当前子树里“最近公共祖先”指针。
2. 若 `node` 为空，返回 `null`。
3. 若 `node` 等于 `p` 或 `q`，返回 `node`。
4. 递归查找左、右子树。
5. 若左右均非空，当前节点即 LCA；否则返回非空的一侧。

## 思考引导

### 1) 先问问题，不先并集
公共父节点不是“值一样就一致”，而是“两条路径的最早汇合点”。先确认树是否有父引用，决定是否回溯。

### 2) 识别不变式
从目标节点到根的路径形成有序祖先链，两个链的第一个公共元素即答案。

### 3) 为什么它一定成立
树有唯一根到叶路径。将两条链对齐后，后续同步扫描可找出最近公共点，这比盲目遍历节点集高效且稳定。

### 4) 常见误区
把节点值相同误判为公共节点，或者遗漏空节点边界会产生伪解。

### 5) 你能找到一个反例吗
两个树段共享某数值但无同一引用，能暴露“值比较误导”。

### 6) 迁移到下一题
版本归并、调用链比对都可抽象为路径交汇问题。先判断是否存在唯一父路径。

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        if (!root || root == p || root == q) {
            return root;
        }

        auto left = lowestCommonAncestor(root->left, p, q);
        auto right = lowestCommonAncestor(root->right, p, q);

        if (left && right) {
            return root;
        }
        return left ? left : right;
    }
};

class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;
    }
}

function lowestCommonAncestor(
    root: TreeNode | null,
    p: TreeNode | null,
    q: TreeNode | null,
): TreeNode | null {
    if (!root || root === p || root === q) {
        return root;
    }

    const left = lowestCommonAncestor(root.left, p, q);
    const right = lowestCommonAncestor(root.right, p, q);

    if (left && right) return root;
    return left || right;
}

## 常见误区

<Callout type="trap">
  <strong>现象 →</strong> 结果总是返回根节点。
  <strong>原因 →</strong> 忘了“左右都命中才是 LCA”，而不是只要当前节点非空就返回。
  <strong>修复 →</strong> 按规则返回：若左右都非空返回当前，否则返回非空一侧。
</Callout>

## 小结

- 递归天然体现“先查子树，后合并”，非常适配公共祖先这类汇合点问题。
