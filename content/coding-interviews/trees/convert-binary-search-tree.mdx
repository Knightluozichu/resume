<Objectives>

- 能解释为何 BST 的中序遍历天然给出升序序列。
- 能写出一次遍历完成链表连接的思路。
- 能处理空树与单节点边界。

</Objectives>

## 直觉引入

BST 的中序遍历会产生递增序列。把“递归输出序列”改为“边遍历边连指针”，
就能在一次遍历中把树改成双向链表，不额外申请新节点。

## 算法思路

1. 维护 `prev`（当前已处理的前驱）和 `head`（链表头）。
2. 递归中序：先左、再中、再右。
3. 到达节点 `cur` 时，把 `prev->right = cur`，`cur->left = prev`。
4. 更新 `prev = cur`。
5. 完成后把链表首尾再相连，形成循环链表。

## 思考引导

### 1) 先问问题，不先改树
将 BST 转双向链表是结构重表达。问的是顺序关系如何保留，不能丢中序语义。

### 2) 识别不变式
中序遍历得到递增序列。当前节点在遍历时只需链接前驱与后继两端，即可维持全局顺序。

### 3) 为什么它一定成立
BST 的中序是严格排序，递归先处理左，再当前，再右，天然给出前后关系。只要连接顺序不越界，线性关系成立。

### 4) 常见误区
新建节点或仅处理局部链接会导致链表不完整。错误通常出现在返回值和前置指针更新之间。

### 5) 你能找到一个反例吗
小树只有两个节点时，很容易验证双向指针是否都配置完整。

### 6) 迁移到下一题
任何树到线性结构的变换都可沿此思路：先定遍历顺序，再定义跨节点副作用。

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* convert(TreeNode* root) {
        TreeNode* head = nullptr;
        TreeNode* prev = nullptr;

        dfs(root, prev, head);

        if (head == nullptr || prev == nullptr) {
            return head;
        }
        head->left = prev;
        prev->right = head;
        return head;
    }

private:
    void dfs(TreeNode* node, TreeNode*& prev, TreeNode*& head) {
        if (!node) return;

        dfs(node->left, prev, head);

        if (!head) head = node;
        if (prev) {
            prev->right = node;
            node->left = prev;
        }
        prev = node;

        dfs(node->right, prev, head);
    }
};
```

```typescript
class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;

function convertBSTToDoublyLinkedList(root: TreeNode | null): TreeNode | null {
    let head: TreeNode | null = null;
    let prev: TreeNode | null = null;

    const dfs = (node: TreeNode | null): void => {
        if (!node) return;

        dfs(node.left);

        if (!head) head = node;
        if (prev) {
            prev.right = node;
            node.left = prev;
        }
        prev = node;

        dfs(node.right);
    };

    dfs(root);

    if (head && prev) {
        head.left = prev;
        prev.right = head;
    }
    return head;
}
```

## 常见误区

<Callout type="trap">
  <strong>现象 →</strong> 转换后链表顺序乱。
  <strong>原因 →</strong> 中序顺序没保持，或在递归后才连边。
  <strong>修复 →</strong> 严格“左-中-右”处理，并在访问中间节点时立即连上 `prev`。
</Callout>
