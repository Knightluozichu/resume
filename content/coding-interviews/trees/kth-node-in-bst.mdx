<Objectives>

- 能把第 k 个最小节点转化为中序遍历计数问题。
- 能处理 k 非法（`k <= 0` 或超界）的边界。
- 能给出可返回节点值的 C++ 与 TypeScript 实现。

</Objectives>

## 直觉引入

BST 的中序遍历是升序。
要找第 `k` 个结点，只要顺序数一遍即可，不用额外排序。

## 算法思路

1. 中序遍历左子树。
2. 命中一个节点就把计数器减一。
3. 计数器变 0 时返回该节点。
4. 继续遍历右子树。

## 思考引导

### 1) 先问问题，不先遍历到最后
第 k 大/小节点来自“有序性”而非纯搜索。你先问 BST 是否允许中序计数提前终止。

### 2) 识别不变式
中序访问次数是有序排名。访问计数达到 k 时可立即返回，无需遍历全部节点。

### 3) 为什么它一定成立
BST 中序保证严格递增，访问顺序就是从小到大顺序列表；第 k 个即为答案。

### 4) 常见误区
若不剪枝会退化为全遍历；若 k 从 1 开始或从 0 开始理解错，也会偏移。

### 5) 你能找到一个反例吗
k=1 或 k=树大小 时最能检验边界和计数起点是否一致。

### 6) 迁移到下一题
Top-k 查询、排名系统都可复用“有序结构的提前终止”思路，节省无效遍历。

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* kthNode(TreeNode* root, int k) {
        int cnt = k;
        TreeNode* ans = nullptr;
        inOrder(root, cnt, ans);
        return ans;
    }

private:
    void inOrder(TreeNode* node, int& k, TreeNode*& ans) {
        if (!node || !ans) return;
        inOrder(node->left, k, ans);
        if (--k == 0) {
            ans = node;
            return;
        }
        inOrder(node->right, k, ans);
    }
};
```

```typescript
class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;
    }
}

function kthNode(root: TreeNode | null, k: number): number | null {
    let rank = k;
    let result: number | null = null;

    const dfs = (node: TreeNode | null) => {
        if (!node || result !== null) return;
        dfs(node.left);
        if (--rank === 0) {
            result = node.val;
            return;
        }
        dfs(node.right);
    };

    dfs(root);
    return result;
}
```
