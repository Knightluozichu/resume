## 直觉引入

路径和可以看作每往下一层就“消耗”一个目标值。
一旦剩余目标变成 0 且当前是叶子，说明这条根到叶路径成立。

## 算法思路

1. 递归参数 `target`。
2. 每次减去当前节点值：`target -= node->val`。
3. 递归到叶子时检查 `target == 0`。

## 思考引导

### 1) 先问问题，不先固定根
“和为某一值的路径”要先分清“起点固定”还是“任意起点”。这一步决定是否二层 DFS。

### 2) 识别不变式
路径累计可以用前缀和表示，每个节点同时服务于“以它为起点”和“延续上层路径”两类状态。

### 3) 为什么它一定成立
树上路径是连续父子关系，前缀差提供了子路径判定条件。若不使用前缀和会重复枚举多个起点。

### 4) 常见误区
不回溯路径和会污染同支递归；又或把全局和误当路径和。

### 5) 你能找到一个反例吗
节点值 [1, -1, 1] 的简单树可检验是否真正支持任意起点。

### 6) 迁移到下一题
事件链累计、账务差分区间也可看成路径和问题，先定起点模型再决定是否前缀优化。

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    bool hasPathSum(TreeNode* root, int target) {
        if (!root) return false;

        int next = target - root->val;
        if (!root->left && !root->right) {
            return next == 0;
        }

        return hasPathSum(root->left, next) || hasPathSum(root->right, next);
    }
};
```

class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;
    }
}

function hasPathSum(root: TreeNode | null, targetSum: number): boolean {
    if (!root) return false;

    const next = targetSum - root.val;
    if (!root.left && !root.right) return next === 0;

    return hasPathSum(root.left, next) || hasPathSum(root.right, next);
}
