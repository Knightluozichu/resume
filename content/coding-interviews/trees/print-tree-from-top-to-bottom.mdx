<Objectives>

- 理解层序遍历为什么天然需要队列，而不是栈。
- 掌握“出队访问、左子入队、右子入队”的 BFS 模板。
- 能处理空树、单节点树、偏斜树等边界。
- 能说明时间复杂度 $O(N)$、空间复杂度 $O(W)$，其中 `W` 是树的最大宽度。

</Objectives>

## 核心思路

从上到下打印二叉树，本质是 BFS（广度优先搜索）。队列的先进先出特性正好对应“先进入当前层的节点先被访问”。

流程固定为：

1. 根节点入队。
2. 队列非空时，弹出队头节点并输出。
3. 如果它有左孩子，左孩子入队。
4. 如果它有右孩子，右孩子入队。

这样队列中始终保持“尚未访问的最早节点”，输出顺序自然就是从上到下、从左到右。

## 代码对照

<CodeTabs>
  <Tab label="C++">
```cpp
#include <queue>
#include <vector>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};

std::vector<int> printFromTopToBottom(TreeNode* root) {
    std::vector<int> result;
    if (root == nullptr) return result;

    std::queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        TreeNode* node = q.front();
        q.pop();
        result.push_back(node->val);

        if (node->left != nullptr) q.push(node->left);
        if (node->right != nullptr) q.push(node->right);
    }

    return result;
}
```
  </Tab>
  <Tab label="TypeScript">
```typescript
interface TreeNode {
  val: number;
  left: TreeNode | null;
  right: TreeNode | null;
}

function levelOrder(root: TreeNode | null): number[] {
  if (!root) return [];

  const result: number[] = [];
  const queue: TreeNode[] = [root];
  let head = 0;

  while (head < queue.length) {
    const node = queue[head++];
    result.push(node.val);

    if (node.left) queue.push(node.left);
    if (node.right) queue.push(node.right);
  }

  return result;
}
```
  </Tab>
</CodeTabs>

<Callout type="tip">
  TypeScript 里不要频繁使用 `Array.shift()` 做队列出队。`shift()` 会移动数组元素，可能退化为 $O(N)$。用 `head` 指针前移更稳定。
</Callout>
