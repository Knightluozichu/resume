## 直觉引入

每一层要么从左到右、要么从右到左，这种“每层翻转方向”很适合用一个方向变量驱动列表拼接。

## 算法思路

1. 用队列进行标准 BFS。
2. 每处理一层，先在当前层收集所有节点值。
3. 若当前方向是从左到右，直接入结果；否则反转后入结果。
4. 方向每层翻转。

## 思考引导

### 1) 先问问题，不先反转
题目不是考遍历顺序本身，而是“同层输出方向可切换”的策略编码能力。你要分离层次与方向。

### 2) 识别不变式
同一层内节点关系稳定，下一层只在完成后切换输出方向。方向是层级属性，不是局部节点属性。

### 3) 为什么它一定成立
层次遍历已定义访问边界，按层收集后倒序或正序输出不会改变父子关系，只改变展示顺序。

### 4) 常见误区
边遍历边反转会导致节点落层错位。先完成一层再变向能避免这类 bug。

### 5) 你能找到一个反例吗
两层树可验证方向翻转点是否只发生在层边界。

### 6) 迁移到下一题
任何“层级展示可变”场景，先把“结构层次”与“展示策略”解耦。

```cpp
#include <vector>
#include <queue>
#include <algorithm>

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    std::vector<std::vector<int>> printZigzag(TreeNode* root) {
        std::vector<std::vector<int>> ans;
        if (!root) return ans;

        std::queue<TreeNode*> q;
        q.push(root);
        bool leftToRight = true;

        while (!q.empty()) {
            int n = (int)q.size();
            std::vector<int> layer;

            for (int i = 0; i < n; ++i) {
                TreeNode* cur = q.front();
                q.pop();
                layer.push_back(cur->val);
                if (cur->left) q.push(cur->left);
                if (cur->right) q.push(cur->right);
            }

            if (!leftToRight) {
                std::reverse(layer.begin(), layer.end());
            }
            ans.push_back(layer);
            leftToRight = !leftToRight;
        }
        return ans;
    }
};
```

```typescript
class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;
    }
}

function zigzagLevelOrder(root: TreeNode | null): number[][] {
    if (!root) return [];

    const ans: number[][] = [];
    const q: (TreeNode | null)[] = [root];
    let leftToRight = true;

    while (q.length > 0) {
        const n = q.length;
        const layer: number[] = [];

        for (let i = 0; i < n; i++) {
            const cur = q.shift()!;
            if (!cur) continue;
            layer.push(cur.val);
            if (cur.left) q.push(cur.left);
            if (cur.right) q.push(cur.right);
        }

        ans.push(leftToRight ? layer : layer.reverse());
        leftToRight = !leftToRight;
    }

    return ans;
}
```
