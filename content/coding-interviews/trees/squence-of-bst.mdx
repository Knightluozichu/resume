<Objectives>

- 能用后序遍历性质定义左右子树边界。
- 能把序列递归切分为左右子树区间。
- 能正确处理重复值边界。

</Objectives>

## 直觉引入

后序序列最后一个元素是根。BST 的左子树都小于根，右子树都大于根。
所以只要能在每一段里找出第一个 `> root` 的分界，再递归验证左右区间即可。

## 算法思路

1. 递归函数 `verify(l, r)`，区间 `[l, r]` 的最后元素是当前根。
2. 从 `l` 到 `r-1` 找第一个 `> rootVal` 的位置 `m`。
3. `m` 前必须都 `< rootVal`；`m` 后到 `r-1` 必须都 `> rootVal`。
4. 左右区间分别验证。

## 思考引导

### 1) 先问问题，不先画树
后序序列是否是 BST，不是要你造树再判断，而是要用值域规则直接验真假。

### 2) 识别不变式
后序最后一个是根，左段全部小于根，右段全部大于根。递归时每层收紧值域，剩余元素才可能合法。

### 3) 为什么它一定成立
BST 的定义决定了左/右子树取值范围嵌套，值域剪枝是充分且必要的条件。

### 4) 常见误区
只看相邻关系无法检验跨段错位。必须有全局值域边界，且按递归返回判断。

### 5) 你能找到一个反例吗
后序 [1,3,2,6,5] 看似“部分有序”，但值域验证会直接判错，适合测试你的递归边界。

### 6) 迁移到下一题
序列合法性验证常见于语法树、权限树。先从局部值域约束而非局部相邻约束起步。
## 代码对照

<CodeTabs>
  <Tab label="C++">
```cpp
#include <vector>

class Solution {
public:
    bool verifyPostorder(const std::vector<int>& postorder) {
        return verify(postorder, 0, (int)postorder.size() - 1);
    }

private:
    bool verify(const std::vector<int>& a, int l, int r) {
        if (l >= r) return true;

        int rootVal = a[r];
        int m = l;
        while (m < r && a[m] < rootVal) ++m;

        for (int i = m; i < r; ++i) {
            if (a[i] < rootVal) return false;
        }

        return verify(a, l, m - 1) && verify(a, m, r - 1);
    }
};
```

function verifyPostorder(postorder: number[]): boolean {
    const dfs = (l: number, r: number): boolean => {
        if (l >= r) return true;

        const root = postorder[r];
        let m = l;
        while (m < r && postorder[m] < root) m++;

        for (let i = m; i < r; i++) {
            if (postorder[i] < root) return false;
        }

        return dfs(l, m - 1) && dfs(m, r - 1);
    };

    return dfs(0, postorder.length - 1);
}
