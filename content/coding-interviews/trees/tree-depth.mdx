## 直觉引入

树的最大深度就是从根到最远叶子经过的节点数。
递归最直接：当前节点深度 = 1 + max(左子树、右子树)。

## 算法思路

1. 空节点深度 0。
2. 非空节点深度 = `1 + max(depth(left), depth(right))`。

## 思考引导

### 1) 先问问题，不先求高度
树深是“最深单路径长度”，对你更关注的是最坏场景风险。平均值容易误导。

### 2) 识别不变式
每个节点深度由其左右子树深度的最大值 + 1。递归返回后更新全局最大值。

### 3) 为什么它一定成立
最深路径一定可拆分成某节点 + 左或右子树中的最深路径。该结构不依赖遍历次序。

### 4) 常见误区
混淆“层数”与“边数”定义，导致空树/单节点树边界 off by one。

### 5) 你能找到一个反例吗
空树和单节点树就是最稳健的边界测试，能验证你是否返回 0 或 1 的定义一致。

### 6) 迁移到下一题
性能建模、依赖树风险评估都优先看最坏深度，先定义基准后再实现统计函数。
## 代码对照

<CodeTabs>
  <Tab label="C++">
```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        return 1 + std::max(maxDepth(root->left), maxDepth(root->right));
    }
};
```

class TreeNode {
    val: number;
    left: TreeNode | null;
    right: TreeNode | null;
    constructor(val: number) {
        this.val = val;
        this.left = null;
        this.right = null;
    }
}

function maxDepth(root: TreeNode | null): number {
    if (!root) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}
