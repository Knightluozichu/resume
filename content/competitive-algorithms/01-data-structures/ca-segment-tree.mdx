## 直觉引入

假设你管理一个有 100 万人的考勤系统，经常需要查询"第 a 到 b 个人的总出勤天数"，还要批量更新"第 c 到 d 个人各加 1 天"。如果用数组，每次查询和更新都是 O(n)，100 万数据根本跑不动。

线段树就像把一本厚书拆成一棵目录树：根节点管理全部，子节点各管一半，叶节点对应单个元素。查询任意区间只需访问 O(log n) 个节点，就像查字典时先翻大章节再翻小节，而不是逐页翻。

## 概念讲解

### 区间的树形划分

<CaSegmentTreeDiagram />

<Term def="将数组区间递归二分，每个节点维护一段区间信息的二叉树结构">
线段树
</Term>

线段树把长度为 n 的数组区间 [0, n-1] 递归二分：根节点管 [0, n-1]，左子管 [0, mid]，右子管 [mid+1, n-1]，直到叶节点管单个元素。树高 O(log n)，任意区间查询只需合并 O(log n) 个节点。

### 懒标记

<Term def="延迟区间更新操作，只在必要时向子节点传播的标记机制">
懒标记
</Term>

区间更新时，如果一个节点完全被覆盖，不立即更新所有子节点，而是打一个标记。后续访问子节点时再把标记"下传"（pushdown）。这样区间更新也只需 O(log n)。

## 代码对照

```cpp
// 线段树：区间和 + 区间更新（懒标记）
int tree[4*N], lazy[4*N];

void pushdown(int node, int start, int end) {
    if (lazy[node]) {
        int mid = (start + end) / 2;
        tree[node*2] += lazy[node] * (mid - start + 1);
        lazy[node*2] += lazy[node];
        tree[node*2+1] += lazy[node] * (end - mid);
        lazy[node*2+1] += lazy[node];
        lazy[node] = 0;
    }
}

// 区间更新 [l, r] 每个元素加 val
void update(int node, int start, int end, int l, int r, int val) {
    if (l <= start && end <= r) {       // 完全覆盖
        tree[node] += val * (end - start + 1);
        lazy[node] += val;
        return;
    }
    pushdown(node, start, end);
    int mid = (start + end) / 2;
    if (l <= mid) update(node*2, start, mid, l, r, val);
    if (r > mid) update(node*2+1, mid+1, end, l, r, val);
    tree[node] = tree[node*2] + tree[node*2+1];
}
```

## 常见误区

<Callout type="trap">
**现象：区间更新后查询结果错误。**
原因 → 忘记 pushdown，子节点还保留旧值。
修法 → 每次 update 和 query 递归子节点前必须先 pushdown。
</Callout>

<Callout type="trap">
**现象：数组越界或 RE。**
原因 → 线段树数组开太小。n 个元素的线段树最多需要 4n 空间。
修法 → 一律开 4*N，不要省这 4 倍空间。
</Callout>

<Exercises>
**问题 1**：区间更新为什么需要懒标记？

<Answer>
不用懒标记则区间更新需递归到所有叶节点，最坏 O(n)。用懒标记后，完全覆盖的节点直接打标记返回，只花 O(log n)。查询时才按需下传，保证总复杂度 O(log n)。
</Answer>

**问题 2**：线段树查询任意区间 [l,r] 为什么只需 O(log n)？

<Answer>
每层最多有 2 个"部分覆盖"节点需要继续递归（最左和最右路径），其余要么完全覆盖（直接返回）要么不相交（跳过）。因此每层最多访问 4 个节点，树高 log n，总计 O(log n)。
</Answer>
</Exercises>

<GlossaryItem term="线段树">将数组区间递归二分构建的二叉树，每个节点维护一段区间的聚合信息，支持 O(log n) 区间查询和更新。</GlossaryItem>
<GlossaryItem term="懒标记">区间更新时在完全覆盖节点上打延迟标记，不在当时更新子节点，后续访问时才下传，保证区间更新 O(log n)。</GlossaryItem>
<GlossaryItem term="pushdown">将父节点的懒标记传播到子节点并更新子节点值的操作，在递归子节点前必须执行。</GlossaryItem>
<GlossaryItem term="区间聚合">线段树节点维护的区间统计量，如区间和、最大值、最小值，满足可合并性。</GlossaryItem>
