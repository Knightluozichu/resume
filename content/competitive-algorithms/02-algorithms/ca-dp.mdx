## 直觉引入

你要从城市 A 走到城市 B，中间经过若干中转站，每段路有不同代价。怎么走最省钱？你不需要枚举所有路径——只需要从 B 往回看，"到达每个中转站的最小代价"等于"从前一站过来加上这一段路费"取最小。这就是动态规划：把大问题拆成子问题，子问题的最优解组合成大问题的最优解。

关键在于：子问题之间不能互相影响（无后效性），且子问题的最优解一定包含在整体最优解中（最优子结构）。

## 概念讲解

### 状态与转移

<CaDpDiagram />

<Term def="将问题分解为重叠子问题，用表格记录子问题最优解，避免重复计算的算法范式">
动态规划
</Term>

DP 三要素：状态定义（dp[i] 表示什么）、转移方程（dp[i] 怎么从前面的状态推出）、边界条件（dp[0] 等于什么）。例如最长递增子序列：dp[i] = max(dp[j]+1)，其中 j < i 且 a[j] < a[i]。

### 无后效性

<Term def="当前状态之后的过程不会影响当前状态之前的过程的性质">
无后效性
</Term>

"未来不依赖过去的具体路径，只依赖当前状态"。如果 dp[i] 的定义使得后续状态依赖"怎么到达 i"的路径，则不满足无后效性，需要增加状态维度来消除。

## 代码对照

```cpp
// 0-1 背包问题：n 个物品各有重量和价值，容量 W 的背包，求最大价值
// dp[j] = 容量为 j 时的最大价值
int knapsack(int n, int W, int w[], int v[]) {
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; i++)
        for (int j = W; j >= w[i]; j--)    // 逆序！保证每个物品只选一次
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
    return dp[W];
}
// 时间 O(nW)，空间 O(W)（滚动数组优化）
// 逆序遍历是 0-1 背包的关键：正序会变成完全背包（物品可重复选）
```

## 常见误区

<Callout type="trap">
**现象：0-1 背包写成正序遍历，结果偏大。**
原因 → 正序遍历导致同一物品被选多次（变成完全背包）。
修法 → 0-1 背包容量必须逆序遍历：for(j=W;j>=w[i];j--)。
</Callout>

<Callout type="trap">
**现象：状态定义不满足无后效性，转移错误。**
原因 → dp[i] 的定义让后续依赖"到达 i 的路径"，而非仅依赖 i 的状态。
修法 → 增加状态维度。如"走到 (i,j) 且上一步向右"不行，改成 dp[i][j][方向]。
</Callout>

<Exercises>
**问题 1**：什么情况下用 DP 而不是贪心？

<Answer>
当问题有最优子结构但不满足贪心选择性质时用 DP。贪心要求每步局部最优能推出全局最优，DP 则枚举所有子问题取最优。如果贪心策略能被证明正确则优先贪心（更高效），否则用 DP。
</Answer>

**问题 2**：0-1 背包为什么容量要逆序遍历？

<Answer>
逆序保证计算 dp[j] 时用的 dp[j-w[i]] 还是上一轮（即不包含当前物品）的值，确保每个物品只选一次。正序遍历时 dp[j-w[i]] 可能已经包含了当前物品，导致重复选取。
</Answer>
</Exercises>
