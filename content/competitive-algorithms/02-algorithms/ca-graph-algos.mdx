## 直觉引入

想象你要在全国地图上规划从北京到各城市的最短路线。你可以从北京出发，每次选最近的未访问城市扩展，像水波一样向外扩散——这就是 Dijkstra。如果你想知道所有城市两两之间的最短路线，就需要 Floyd：对每个中转城市 k，检查"经过 k 是否更短"。

最小生成树则像用最少的电缆连接所有城市。Kruskal 每次选最短的电缆连接两个尚未连通的城市（并查集判连通），Prim 从一个城市出发每次选最近的邻接城市扩展。

## 概念讲解

### 最短路算法

<CaGraphAlgosDiagram />

<Term def="从单源点出发，每次取距离最小的未确定节点扩展，逐步确定所有点最短距离的算法">
Dijkstra
</Term>

Dijkstra 用优先队列维护"当前已知最短距离"，每次取最小距离的点确定，松弛其邻居。复杂度 O((V+E)log V)。不能处理负权边，因为"已确定的点可能被更短的负权路径更新"。

<Term def="枚举中转点 k，对每对 (i,j) 检查 dist[i][j] = min(dist[i][j], dist[i][k]+dist[k][j]) 的全源最短路算法">
Floyd
</Term>

Floyd 是动态规划：dp[k][i][j] 表示只经过前 k 个点中转时 i 到 j 的最短路。三重循环 O(V^3)，但代码极短，适合 V ≤ 500。

### 最小生成树

Kruskal 按边权排序，用并查集判连通，选 n-1 条边。Prim 从一点出发，用优先队列每次选最小邻接边。两者都 O(E log E)。

## 代码对照

```cpp
// Dijkstra（优先队列版）
typedef pair<int,int> pii;
void dijkstra(int s, vector<pii> adj[], int dist[], int n) {
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    fill(dist, dist + n + 1, INT_MAX);
    dist[s] = 0; pq.push({0, s});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;          // 过期数据跳过
        for (auto [v, w] : adj[u])
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
    }
}

// Kruskal 最小生成树
int kruskal(Edge edges[], int n, int m) {
    sort(edges, edges + m);                  // 按边权排序
    init(n);                                 // 并查集初始化
    int sum = 0, cnt = 0;
    for (int i = 0; i < m && cnt < n - 1; i++) {
        if (find(edges[i].u) != find(edges[i].v)) {
            unite(edges[i].u, edges[i].v);
            sum += edges[i].w; cnt++;
        }
    }
    return sum;
}
```

## 常见误区

<Callout type="trap">
**现象：Dijkstra 处理负权边得到错误结果。**
原因 → Dijkstra 的"已确定点不再更新"假设在有负权时不成立。
修法 → 有负权用 Bellman-Ford 或 SPFA。Dijkstra 只适用于非负权图。
</Callout>

<Callout type="trap">
**现象：Kruskal 选了 n 条边或成环。**
原因 → 忘记用并查集判连通，或边数搞错。
修法 → 最小生成树恰好 n-1 条边，每次合并前检查 find(u)!=find(v)。
</Callout>

<Exercises>
**问题 1**：Dijkstra 为什么不能处理负权边？

<Answer>
Dijkstra 每次取最小距离的点"确定"其最短路，不再更新。但负权边可能让一条更长的路径通过负权变短，导致已确定的点需要更新，违背算法假设。Bellman-Ford 通过反复松弛所有边来处理负权。
</Answer>

**问题 2**：Kruskal 和 Prim 各适合什么图？

<Answer>
Kruskal 适合稀疏图（边少），按边排序 O(E log E)。Prim 适合稠密图（边多），用邻接矩阵 O(V^2) 或优先队列 O(E log V)。Kruskal 用并查集实现简洁，竞赛中更常用。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="Dijkstra">单源最短路算法，用优先队列每次取最小距离点扩展，不能处理负权边，O((V+E)logV)。</GlossaryItem>
<GlossaryItem term="Floyd">全源最短路算法，三重循环枚举中转点，O(V^3)，代码极短适合小图。</GlossaryItem>
<GlossaryItem term="Kruskal">最小生成树算法，按边权排序+并查集判连通，选 n-1 条最小边，适合稀疏图。</GlossaryItem>
<GlossaryItem term="拓扑排序">对有向无环图(DAG)的线性排序，使每条边从前往后，用 Kahn 算法（入度为0入队）或 DFS 实现。</GlossaryItem>
</Glossary>
