## 直觉引入

计算 2^1000000，直接乘要做一百万次乘法。但注意 2^1000000 = (2^500000)^2，只需算一半再平方。递归下去，2^500000 = (2^250000)^2……每次问题规模减半，只需约 20 次乘法（log2(1000000)≈20）。这就是快速幂的核心思想：用二进制拆分把 O(n) 的幂运算压缩到 O(log n)。

竞赛中数学题占比很高，快速幂、组合数、数论是三大高频考点。这些技巧的共同特点：用数学性质大幅减少计算量。

## 概念讲解

### 快速幂

<CaMathTricksDiagram />

<Term def="利用二进制拆分将 a^n 分解为 O(log n) 次乘法的算法">
快速幂
</Term>

a^n = a^(n/2) * a^(n/2) * (n 奇数则再乘 a)。递归或迭代实现，每次 n 右移一位。竞赛中通常配合取模运算避免溢出。

### 组合数取模

<Term def="利用费马小定理 a^(p-1)≡1(mod p) 求模逆元，从而在模质数下做除法">
费马小定理求逆元
</Term>

C(n,m) = n! / (m! * (n-m)!)。在模 p 下除法变成乘逆元：a/b mod p = a * b^(p-2) mod p（p 为质数）。预处理阶乘和逆元阶乘后可 O(1) 查询。

## 代码对照

```cpp
// 快速幂（带取模）
long long qpow(long long a, long long n, long long mod) {
    long long res = 1; a %= mod;
    while (n > 0) {
        if (n & 1) res = res * a % mod;  // 当前位为1，乘入结果
        a = a * a % mod;                  // 底数平方
        n >>= 1;                          // 右移一位
    }
    return res;
}

// 组合数取模（预处理阶乘+逆元阶乘）
const int MOD = 1e9 + 7;
long long fact[N], invfact[N];
void precompute(int n) {
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i-1] * i % MOD;
    invfact[n] = qpow(fact[n], MOD - 2, MOD);   // 费马小定理求逆元
    for (int i = n - 1; i >= 0; i--) invfact[i] = invfact[i+1] * (i+1) % MOD;
}
long long C(int n, int m) {
    if (m < 0 || m > n) return 0;
    return fact[n] * invfact[m] % MOD * invfact[n-m] % MOD;
}
```

## 常见误区

<Callout type="trap">
**现象：快速幂忘记取中间模，结果溢出。**
原因 → a*a 可能超过 long long 范围（a 最大接近 mod ≈ 10^9）。
修法 → 每次乘法后立即取模：a = a * a % mod。
</Callout>

<Callout type="trap">
**现象：组合数取模在模非质数时出错。**
原因 → 费马小定理只对质数模成立，非质数模下逆元不存在。
修法 → 模非质数用扩展欧几里得或 Lucas 定理。
</Callout>

<Exercises>
**问题 1**：为什么快速幂是 O(log n) 而不是 O(n)？

<Answer>
快速幂每次将指数右移一位（除以2），n 的二进制位数是 log2(n)，循环最多执行 log2(n) 次。每次循环做一次平方和可能的乘法，都是 O(1)。总复杂度 O(log n)。朴素做法每次乘一个 a，需要 n 次乘法 O(n)。
</Answer>

**问题 2**：为什么组合数取模需要预处理逆元阶乘？

<Answer>
直接对每个 C(n,m) 用快速幂求逆元需要 O(log MOD) 次乘法，多次查询时太慢。预处理 invfact 数组后每次查询只需 3 次乘法 O(1)。预处理本身只需一次 O(n) + 一次快速幂 O(log MOD)。
</Answer>
</Exercises>

<GlossaryItem term="费马小定理">若 p 为质数，则 a^(p-1) ≡ 1 (mod p)。用于求模逆元：a^(-1) ≡ a^(p-2) (mod p)。</GlossaryItem>
<GlossaryItem term="逆元">模意义下的"倒数"，a*b≡1(mod p) 则 b 是 a 的逆元，使模意义下可以做除法。</GlossaryItem>
