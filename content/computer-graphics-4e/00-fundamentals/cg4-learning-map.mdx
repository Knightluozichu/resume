## 这本书不只讲“3D 到像素”

Hearn、Baker 与 Carithers 的第 4 版从图形硬件和系统出发，先建立输出图元、属性与实现算法，再展开 2D/3D 变换和观察；后半部覆盖层次建模、动画、对象/样条表示、可见面、局部与全局光照、纹理、颜色、交互 GUI、可编程 shader、算法建模和数据可视化。

把全书缩成“顶点 → 光栅化 → 片段”会漏掉至少三类核心：**对象如何产生**、**人如何交互**、**数据如何被解释**。渲染管线是重要骨架，但不是整本书的边界。

回答的不只是如何绘制，也包括显示、输入、建模、动画和可视化。

## 五层知识结构

### 系统层：图像在哪里产生和显示

硬件、图形系统、交互输入与 GUI 共同定义采样分辨率、刷新、颜色编码、输入事件和延迟。算法结果要落到具体 framebuffer 与显示设备，交互反馈又改变下一帧模型。

### 几何层：对象如何表示和进入观察空间

把平移、旋转、缩放与投影放入统一组合：

$$
\mathbf p_{clip}=PVM\begin{bmatrix}x&y&z&1\end{bmatrix}^{T},
\qquad
\mathbf p_{ndc}=\frac{1}{w_{clip}}\begin{bmatrix}x_{clip}&y_{clip}&z_{clip}\end{bmatrix}^{T}.
$$

2D window→viewport 也是坐标映射；层次建模又把父子局部变换组合成世界变换。顺序改变就改变几何意义，矩阵相乘不能任意交换。

### 采样层：连续几何如何覆盖离散样本

可用三角形边函数表达：

$$
E_{ij}(x,y)=(x-x_i)(y_j-y_i)-(y-y_i)(x_j-x_i).
$$

三个有一致符号的边函数决定覆盖；归一化边函数又形成重心坐标，用于插值深度、颜色、法线与纹理坐标。抗锯齿不是“模糊边缘”，而是更好近似像素滤波积分。

### 外观层：表面为何呈现这个颜色

局部 illumination model 只计算直接光照近似；texture mapping 提供空间变化参数；color model 决定数值如何编码和显示；global illumination 则考虑多次光传输。统一目标可写成渲染方程：

$$
L_o(x,\omega_o)=L_e(x,\omega_o)+
\int_{\Omega} f_r(x,\omega_i,\omega_o)L_i(x,\omega_i)
(\mathbf n\cdot\omega_i)^+\,d\omega_i.
$$

Phong 是经验模型，BRDF/光传输是更一般框架；二者不能因为都输出颜色就混为同一物理精度。

### 内容层：模型、动画与数据如何被构造

Polygon mesh、solid model 与 spline 决定形状表示；hierarchical model 与 animation 决定随时间变化；algorithmic modeling 用规则生成复杂形状；visualization 则把数据字段编码成位置、颜色、几何、glyph 或 volume。这里的“正确”还包括数据语义与感知可读性，不只是一帧没有图形 API 错误。

## 原书算法与现代实现

第 4 版同时承担原理教材和 OpenGL 编程载体。接口会老化，算法合同不会：

- Immediate/fixed-function 调用可翻译为显式 vertex buffers、shader、uniform 与 pipeline state；
- GLU/GLUT 示例的窗口和矩阵职责可由现代窗口库与数学库承担；
- Bresenham、clipping、scan conversion、spline evaluation 仍可在 CPU 实验中逐步验证；
- GPU rasterizer 替代手写逐像素循环不等于无需理解覆盖、插值和采样；
- 现代 PBR/compute/ray tracing 是扩展视角，不能抹去原书局部光照、颜色和对象表示的教学边界。

```cpp
struct VertexOut {
  Vec4 clipPosition;
  Vec3 worldNormal;
  Vec2 uv;
};

VertexOut vertexStage(const Vertex& v, const Scene& s) {
  Vec4 world = s.model * Vec4(v.position, 1.0f);
  return {
    .clipPosition = s.projection * s.view * world,
    .worldNormal = normalize(s.normalMatrix * v.normal),
    .uv = v.uv,
  };
}
```

```cpp
float edge(Vec2 a, Vec2 b, Vec2 p) {
  return (p.x - a.x) * (b.y - a.y) -
         (p.y - a.y) * (b.x - a.x);
}

for (Pixel p : triangleBoundingBox(v0, v1, v2)) {
  Vec2 sample = p.center();
  Vec3 e = {edge(v1, v2, sample), edge(v2, v0, sample), edge(v0, v1, sample)};
  if (topLeftInside(e, v0, v1, v2)) {
    Vec3 barycentric = e / signedDoubleArea(v0, v1, v2);
    writeFragment(p, perspectiveCorrectInterpolate(barycentric, attributes));
  }
}
```

```glsl
vec3 shadeDirect(Surface s, Light light, vec3 viewDir) {
    vec3 lightDir = normalize(light.position - s.position);
    float nDotL = max(dot(s.normal, lightDir), 0.0);
    vec3 diffuse = s.baseColor * nDotL;
    return light.radiance * diffuse; // 教学基线；后续章再加入 BRDF、阴影与颜色管理
}
```
