## 直觉引入

计算机图形学就像一条「工厂流水线」——原材料（3D 顶点数据）经过一道道工序（变换、光栅化、着色），最终产出成品（2D 像素图像）。全书围绕这条流水线展开：先理解管线整体架构，再逐个深入每个关键工序，最后学习如何优化和扩展。

全书的核心思想是「从 3D 到 2D 的映射」：三维世界如何被变换、投影、离散化为二维像素。每章都是这条主线上的一个关键节点。

## 概念讲解

全书分四大板块：**基础**（学习地图、图形渲染管线）、**核心**（光栅化、几何变换、可见性）、**高级**（光照模型、纹理映射、曲线曲面、高级渲染）、**复习**（总复习）。

<Term def="将3D顶点数据转化为2D像素图像的完整处理流程">渲染管线</Term>是全书骨架。<Term def="将连续几何图元离散化为像素片段">光栅化</Term>是 3D 到 2D 的关键转换。<Term def="用矩阵将顶点在不同坐标系间变换">几何变换</Term>定义了空间关系。<Term def="逐像素比较深度值确定可见表面">深度缓冲</Term>解决了遮挡问题。

### 板块依赖
- 基础 → 核心：管线概览为光栅化/变换/可见性提供框架。
- 核心 → 高级：核心阶段是光照/纹理/曲面的实现基础。
- 高级 → 复习：高级技术整合后形成完整知识体系。

### 学习建议
- 先通读学习地图，建立全局认知
- 核心三章（光栅化/变换/可见性）是重中之重
- 高级章节可根据兴趣选择性深入
- 总复习用于查漏补缺

## 代码对照

用伪代码展示全书知识架构与管线流程的对应关系：

```glsl
// 顶点着色器：几何变换的核心
#version 330 core
layout(location = 0) in vec3 aPos;
layout(location = 1) in vec2 aTexCoord;

uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;

out vec2 TexCoord;

void main() {
    // MVP 变换链：局部 → 世界 → 视图 → 裁剪空间
    gl_Position = projection * view * model * vec4(aPos, 1.0);
    TexCoord = aTexCoord;
}
```

```glsl
// 片段着色器：光照与纹理的核心
#version 330 core
in vec2 TexCoord;
in vec3 Normal;
in vec3 FragPos;

uniform sampler2D texture1;
uniform vec3 lightPos;
uniform vec3 viewPos;

void main() {
    // Phong 光照模型
    vec3 ambient = 0.1 * texture(texture1, TexCoord).rgb;
    vec3 norm = normalize(Normal);
    vec3 lightDir = normalize(lightPos - FragPos);
    float diff = max(dot(norm, lightDir), 0.0);
    vec3 diffuse = diff * texture(texture1, TexCoord).rgb;
    // 最终颜色写入帧缓冲（经深度测试后）
    FragColor = vec4(ambient + diffuse, 1.0);
}
```

这段代码体现了管线中几何变换（顶点着色器）和光照纹理（片段着色器）两大核心环节。

## 常见误区

<Callout type="trap">
**现象 →** 跳过渲染管线概览，直接学高级渲染技术。
**原因 →** 觉得概览太抽象，想快速看到效果。
**修法 →** 渲染管线是全书的骨架，不理解管线就不知道每个技术处于什么位置。先建立全局观再深入细节，否则知识碎片化难以整合。
</Callout>

<Callout type="trap">
**现象 →** 重理论轻实践，只看公式不写代码。
**原因 →** 图形学公式多，容易陷入纯数学推导。
**修法 →** 图形学是工程学科。每学一个概念都应该用 OpenGL/WebGL 实现验证。理论指导方向，代码验证理解，两者缺一不可。
</Callout>

<Exercises>
**问题**：全书四个板块的递进关系是什么？为什么是这个顺序？

<Answer>
基础→核心→高级→复习的递进关系：基础建立管线全局认知，核心深入管线三大关键阶段（光栅化/变换/可见性），高级在核心基础上扩展表现力（光照/纹理/曲面）和真实感（高级渲染），复习整合知识体系。这个顺序因为：管线是骨架（基础），核心阶段是骨架的关键关节（核心），高级技术是关节上的肌肉（高级），复习是全身协调（综合）。
</Answer>

**问题**：如果只有 3 天时间学习，你会优先学哪几章？

<Answer>
优先学：1) 图形渲染管线（建立全局认知）；2) 几何变换（MVP 矩阵是最实用的基础）；3) 光照模型（Phong 是最常用的着色模型）。这三章覆盖了从顶点到像素的核心流程，能快速建立可用的知识框架。
</Answer>
</Exercises>
