## 直觉引入

Bezier曲线就像用橡皮筋造型——控制点拉伸橡皮筋（曲线），端点固定在首尾控制点上，中间控制点拉拽方向。三次Bezier由4个控制点定义，曲线始终在控制点的凸包内，不会「飞出去」。

## 概念讲解

<Term def="由控制点通过Bernstein多项式加权定义的参数曲线">Bezier曲线</Term><Term def="Bezier曲线始终位于控制点凸包内的性质">凸包性</Term><Term def="非均匀有理B样条，支持局部控制和精确圆锥曲线">NURBS</Term><Term def="用Tessellation Shader将参数曲面细分为三角形">曲面细分</Term>

### Bezier曲线
三次Bezier由4控制点定义：B(t)=(1-t)^3*P0+3t(1-t)^2*P1+3t^2(1-t)*P2+t^3*P3。

### 凸包性
曲线始终在控制点凸包内，保证数值稳定和高效求交。

### NURBS优势
精确表示圆锥曲线、局部控制、节点向量调节参数化。

### 曲面细分
Tessellation Shader: Hull->Tessellator->Domain，自适应细分级别。

## 代码对照

```glsl
// de Casteljau算法递归求Bezier点
vec3 deCasteljau(vec3 p0, vec3 p1, vec3 p2, vec3 p3, float t) {
    vec3 a = mix(p0, p1, t);
    vec3 b = mix(p1, p2, t);
    vec3 c = mix(p2, p3, t);
    vec3 d = mix(a, b, t);
    vec3 e = mix(b, c, t);
    return mix(d, e, t);
}
```

de Casteljau算法递归线性插值，比直接计算Bernstein多项式更数值稳定。GLSL的mix函数等价于线性插值。

## 常见误区

<Callout type="trap">
**现象 →** 认为Bezier曲线经过所有控制点。
**原因 →** 控制点名称误导。
**修法 →** Bezier曲线只经过首尾控制点(P0/P3)，中间控制点(P1/P2)只控制切线方向。需要经过所有点应使用B样条。
</Callout>

<Callout type="trap">
**现象 →** 曲面细分级别固定不变。
**原因 →** 简单实现用固定细分级别。
**修法 →** 应自适应细分——根据曲率、屏幕投影面积和距离动态调整。平衡质量与性能。
</Callout>

## 练习

<Exercises>
**问题**：三次Bezier曲线由几个控制点定义？端点性质？

<Answer>
4个控制点。P0和P3是端点(曲线经过)，P1和P2控制切线方向(曲线不一定经过)。
</Answer>

**问题**：NURBS相比Bezier有什么优势？适用什么场景？

<Answer>
1)精确表示圆锥曲线 2)局部控制 3)节点向量调节参数化 4)权重调节影响力。适用CAD/CAM建模、工业设计、角色建模。
</Answer>
</Exercises>
