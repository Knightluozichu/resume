## 纹理映射是函数复合

**Texturing and Surface-Detail Methods / 纹理映射与表面细节**把表面位置映射到 texture domain，再从离散 texels 重建连续信号，最后按数据语义进入着色：

$$
\mathbf x_{surface}\xrightarrow{\phi}(u,v)
\xrightarrow{\text{filtered sample}}\mathbf t
\xrightarrow{\text{decode}}\text{material/detail}.
$$

<Term def="把曲面上的点映射到二维参数域，并定义 seam、orientation 和 distortion 的函数">UV 参数化</Term>的值不必限于 [0,1]；repeat/mirror/clamp wrap 会解释域外坐标。Normalized UV 也只是采样接口约定，参数化本身可使用任意尺度。

## Seams 与 Distortion 无法同时消失

一般闭合/复杂曲面不能无缝、无畸变地展开到单个平面矩形。UV atlas 需要 cuts 形成 charts：

- **Seam**在几何同一点复制 vertices，使两侧拥有不同 UV；
- **Stretch**使纹理单位面积与表面面积比例变化；
- **Angle distortion**扭曲方向和形状，影响法线贴图和各向异性；
- **Orientation/mirroring**改变 tangent frame handedness。

Atlas packing 还需 padding/gutter。Mip 和 bilinear taps 会跨 chart 边界读取邻居，只有 level 0 留一像素空隙远远不够；应按完整 mip chain 扩边或使用 texture arrays/virtual texturing 等隔离策略。

## 一个 Pixel 对应 Texture Footprint

<Term def="屏幕中一个 pixel/sample 在纹理参数域覆盖的区域，由 UV 对屏幕坐标偏导近似">Texture footprint</Term>可由 fragment quad derivatives 估计：

$$
\mathbf d_x=\left(\frac{\partial u}{\partial x},\frac{\partial v}{\partial x}\right),\qquad
\mathbf d_y=\left(\frac{\partial u}{\partial y},\frac{\partial v}{\partial y}\right).
$$

乘以 base texture 尺寸后，常见 isotropic footprint 尺度近似：

$$
\rho=\max(\|\mathbf d_x\|,\|\mathbf d_y\|),\qquad
\lambda=\log_2\rho.
$$

$\lambda<0$表示 magnification，$\lambda>0$表示 minification；实际 hardware LOD 细节由 API 规范、bias、clamp 和 sampler 状态决定。

在 control flow divergence 或非 fragment stage，implicit derivatives 可能未定义/不可用；应在 uniform control flow 取得 gradients并用 `textureGrad`等显式接口，或明确 LOD。

```glsl
vec2 dx = dFdx(uv);
vec2 dy = dFdy(uv);
vec4 baseColorSample = textureGrad(baseColorMap, uv, dx, dy);
```

## Nearest、Bilinear 与 Reconstruction

Nearest 选择一个 texel，保留硬边但放大呈块状；bilinear 在同一 mip level 对 2×2 邻域作 separable linear interpolation。若 fractional texel coordinate 为 $(\alpha,\beta)$：

$$
c=(1-\beta)[(1-\alpha)c_{00}+\alpha c_{10}]
+\beta[(1-\alpha)c_{01}+\alpha c_{11}].
$$

Bilinear 是 tent filter 的局部重建，不足以解决严重 minification：一个 pixel footprint 可能覆盖数百 texels，四个 taps 会 alias。

Magnification filter通常选择 nearest/linear；mip selection针对 minification，但显式 LOD 或特殊路径仍可访问各 levels，不能说“放大时绝对没有更高级别”。

## Mipmap 是 Isotropic Prefilter 近似

<Term def="将纹理逐级低通并降采样形成的多分辨率金字塔，用于近似不同大小的 isotropic footprint">Mipmap</Term>每级宽高通常减半。Trilinear filtering 在 floor/ceil LOD 两级分别 bilinear，再按 fractional LOD 混合，减少 level transition。

完整未压缩 2D、宽高为 2 的幂且无限级链的 texel 数：

$$
1+\frac14+\frac1{16}+\cdots=\frac43,
$$

所以额外约 1/3。非幂尺寸、压缩 block、array/3D texture、行对齐或截断 mip chain 的真实内存不一定正好 1/3。

Mip level 不是“对任意 footprint 的精确区域平均”。常规 mip 是 axis-aligned isotropic square prefilter；斜视表面 footprint 拉成长椭圆，选择最大轴的 isotropic level会过度模糊短轴，选择短轴又让长轴 alias。

## Anisotropic Filtering 处理拉长 Footprint

<Term def="沿 texture footprint 主轴使用多个 taps/更合适 LOD，近似过滤斜视导致的细长区域的方法">各向异性过滤</Term>提高斜角道路、地面等清晰度。它受 sampler anisotropy limit 和带宽/tap 成本约束，也不是无限精确积分。

测试应包含不同倾角、重复频率和运动；只看正对相机的 checkerboard无法证明 anisotropic path。

## Mip 生成必须尊重数据语义

Base color 在 sRGB 存储时，应先 decode 到 linear 再平均/过滤，生成后按存储格式编码。在 sRGB code 上直接平均会让中间亮度错误。

Normal map texels不是普通 RGB 颜色：decode 到向量空间、平均后重新 normalize；还需考虑 roughness/variance，因为缩小后法线分布不能只用平均方向完整表达。Roughness、metalness、ID/mask、height 和 alpha coverage 也各有适合的 reduction，不能对所有通道统一 box filter。

```cpp
Image generateBaseColorMip(const Image& srgbSource) {
  Image linear = decodeSrgb(srgbSource);
  Image filtered = downsampleWithAreaFilter(linear);
  return encodeSrgb(filtered);
}

Image generateNormalMip(const Image& encodedNormals) {
  Image vectors = decodeTangentNormals(encodedNormals);
  Image averaged = downsampleVectorField(vectors);
  return normalizeAndEncodeNormals(averaged);
}
```

Alpha-tested foliage 还要维持 coverage；简单平均 alpha 会让远处叶片逐渐消失。可按目标 threshold 调整 mip alpha distribution。

## Tangent-space Normal Mapping

<Term def="在纹理中编码逐 texel 法线，并通过 tangent-bitangent-normal frame 变换到着色空间的表面细节方法">法线贴图</Term>常将 tangent normal 从 [0,1] decode 到 [-1,1]：

$$
\mathbf n_t=normalize(2\mathbf c-1).
$$

TBN 必须与 mesh UV parameterization 和 normal orientation 一致。Tangent 可与 normal Gram-Schmidt 正交化，bitangent 常由 handedness $s\in\{-1,1\}$重建：

$$
\mathbf B=s(\mathbf N\times\mathbf T).
$$

Mirrored UV seams 会改变 s；丢失 handedness 会让一侧法线绿色通道反转。Normal texture 是线性数据，不能 sRGB decode。

```glsl
vec3 N = normalize(worldNormal);
vec3 T = normalize(worldTangent.xyz - N * dot(N, worldTangent.xyz));
vec3 B = worldTangent.w * cross(N, T);
mat3 TBN = mat3(T, B, N);
vec3 tangentNormal = normalize(texture(normalMap, uv).xyz * 2.0 - 1.0);
vec3 shadingNormal = normalize(TBN * tangentNormal);
```

导入器、tangent generator 和 baking tool 必须使用同一 tangent basis（例如 MikkTSpace 约定），否则 seam 即使数学代码正确也可见。

## Bump、Parallax 与 Displacement 边界

<Cg4SurfaceDetailDiagram />

- Bump mapping 从 height gradient 扰动 normal；
- Normal mapping 直接提供局部 normal；
- Parallax/POM 沿 view direction 在 height field 中调整 UV，改善内部视差和 self-occlusion 近似，但通常不改变 mesh silhouette；
- Displacement mapping 真正移动 vertices/micropolygons，能改变轮廓、depth 和 shadow，但需要足够 tessellation 和 bounds 扩张。

把 parallax 说成“侧面也有真实凹凸”不准确；极斜角会出现 UV 越界、层数成本和 silhouette 局限。Displacement 后 object bounds/occlusion/BLAS 等也需更新。

## 常见误区

<Callout type="trap">
**现象 →** 开启 trilinear mip 后斜视地面不闪但异常模糊。
**原因 →** Isotropic LOD 用长轴决定 square footprint，短轴被过度低通。
**修法 →** 启用并测量 anisotropic filtering，检查设备 limit；用倾斜高频场景验证，而非只看正面。
</Callout>

<Callout type="trap">
**现象 →** Normal map 在 mirrored UV seam 一侧凹凸反向。
**原因 →** Tangent handedness 丢失或 baker/runtime basis 不一致，bitangent方向错误。
**修法 →** 保存 tangent sign，用 B=sign×cross(N,T) 重建，并统一 tangent-space 生成标准。
</Callout>

<Callout type="trap">
**现象 →** 远处 base color 变暗、树叶消失或 normal 高光变平。
**原因 →** 所有纹理通道都在原始编码上直接平均：sRGB、alpha coverage 和 normal 各自语义被破坏。
**修法 →** 按语义生成 mip：颜色在线性空间滤波，normal 向量平均后归一化，alpha 保 coverage，数据通道选合适 reduction。
</Callout>

## 练习

<Exercises>

1. **LOD：** 2048² 纹理上，pixel footprint 两轴长度约 8 和 1 texels。Isotropic LOD 约是多少？为何会模糊？

<Answer>
取最大轴 $\rho=8$，$\lambda=\log_2 8=3$，会选择约第 3 mip，等效两轴都按约 8×8 footprint 过滤；真实短轴只有 1 texel，因此被过度模糊。Anisotropic filtering可沿长轴多采样、短轴保留更高分辨率。
</Answer>

2. **Mip 内存：** 为什么“完整 mip 链一定多 1/3 内存”不是普遍精确结论？

<Answer>
4/3 来自无限二维 texel 几何级数且每级字节/texel相同。真实链有限，非幂尺寸向下取整，block compression 有最小 block，row/layer alignment、array/3D volume 和截断 levels 都改变占用。因此它是常见 2D 未压缩近似，实际查资源布局。
</Answer>

3. **Normal map：** 为什么 normal texture 不能标 sRGB，mip 也不能直接平均编码 RGB？

<Answer>
法线通道是线性向量编码，不是显示颜色；sRGB decode 会非线性扭曲分量。Mip 应先 decode 到向量，按覆盖权重平均并 normalize，再编码；更高级方法还保存法线分布方差用于 roughness。TBN 和 mirrored handedness也要一致。
</Answer>

</Exercises>

## 本章回顾

- UV parameterization 必然在 seam/stretch/orientation 之间权衡，并需 mip-safe gutters；
- Texture footprint 由 UV derivatives 估计，mip 是 isotropic prefilter 近似，斜角需 anisotropic；
- Color、normal、alpha、roughness 与 height 的 mip/解码语义不同；
- Bump/normal/parallax 不真正改变所有几何边界，displacement 才改变轮廓、depth 和 bounds。
