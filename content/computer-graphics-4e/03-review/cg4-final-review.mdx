总复习就像把拼图拼完整——前面各章是散落的拼图块（光栅化、变换、可见性、光照、纹理、曲面、高级渲染），现在把它们拼成一幅完整图景：从3D顶点到2D像素的完整渲染流水线。

## 概念讲解

<Term def="从顶点数据到屏幕像素的完整处理流程">渲染管线</Term><Term def="Model-View-Projection三矩阵变换链">MVP变换</Term><Term def="逐像素比较深度确定可见表面">深度测试</Term><Term def="模拟光多次反弹的间接光照技术">全局光照</Term>

### 核心流程
顶点数据->MVP变换->图元装配->光栅化->深度测试->片段着色->帧缓冲

### 知识关联
几何变换(顶点着色器)->光栅化(属性插值)->深度测试(可见性)->片段着色(光照+纹理)

### 性能优化
减少几何量(裁剪/LOD)、减少片段执行(Early-Z/Z-Prepass)、减少带宽(纹理压缩/合批)

```python
def render_pipeline(scene, camera):
    for obj in scene.objects:
        vertices = transform(obj.vertices, obj.model_matrix)
        vertices = transform(vertices, camera.view_matrix)
        vertices = transform(vertices, camera.proj_matrix)
    fragments = rasterize(primitives)
    for frag in fragments:
        if depth_test(frag.z, zbuffer[frag.x, frag.y]):
            color = shade(frag)
            framebuffer[frag.x, frag.y] = color
            zbuffer[frag.x, frag.y] = frag.z
    return post_process(framebuffer)
```

这个伪代码展示了完整渲染管线的核心逻辑：变换->光栅化->深度测试->着色->后处理。实际GPU中各阶段高度并行化。

## 常见误区

<Callout type="trap">
**现象 →** 学了各章但无法整合成体系。
**原因 →** 各章独立学习缺乏全局视角。
**修法 →** 以渲染管线为主线串联：几何变换(顶点着色器)->光栅化->可见性(深度测试)->光照纹理(片段着色器)->高级渲染(额外Pass)。
</Callout>

<Callout type="trap">
**现象 →** 设计渲染方案时忽视性能预算。
**原因 →** 只关注效果不考虑帧率。
**修法 →** 渲染设计必须在效果和性能间权衡。先确定帧率目标(60fps=16.6ms)，再分配预算。用Profiler定位瓶颈逐个优化。
</Callout>

## 练习

<Exercises>
**问题**：用一句话概括渲染核心流程。

<Answer>
3D顶点经MVP变换->图元装配->光栅化(扫描转换为片段)->深度测试(可见性)->片段着色(光照+纹理)->帧缓冲输出2D像素。
</Answer>

**问题**：设计实时渲染管线时在哪些阶段做优化？

<Answer>
1)几何阶段:视锥裁剪/LOD/Instancing 2)光栅化前:背面剔除/Z-Prepass 3)片段阶段:Mipmap/延迟着色/Early-Z 4)带宽:顶点格式压缩/纹理压缩/合批。
</Answer>
</Exercises>
