## 从一个会失败的图像实验开始

Visible-Surface Detection Methods要回答的不是“这个名词是什么”，而是：在固定输入下，如何验证“为同一像素选择最近可见片元”，并让一个反例可重复地推翻错误实现？先写下预期像素、几何或估计量，再运行基线；只要深度格式、近远平面、比较函数和重叠片元结果无法指出差异来自哪一步，图像看起来正确也不能通过。

本页的不变量是：Visible-Surface Detection Methods的输入、公式中间量、输出与恢复结果可用同一基线复算。反例“清除值与比较函数不匹配，或用线性直觉解释非线性深度”只改变一个条件，因而正常、故障与恢复三次运行应能用同一输入直接比较。

## 原书单元与独立机制解释

### Visible-Surface Detection Methods

visible-surface detection 比较遮挡候选，z-buffer 为每个像素保存当前最近深度。算法简单但依赖深度精度、比较方向和清除值；近远平面比例过大时会出现z-fighting。

本单元的正式坐标是visible-surface detection、z-buffer。验证Visible-Surface Detection Methods时，先制造“清除值与比较函数不匹配，或用线性直觉解释非线性深度”，再检查深度格式、近远平面、比较函数和重叠片元结果能否把错误定位到为同一像素选择最近可见片元的首个分叉。

$$
z_{new}\prec z_{buffer}\Rightarrow (C,z)\leftarrow(C_{new},z_{new})
$$

## 最小可重现实验

```cpp
if (fragment.depth < depthBuffer[pixel]) {
  depthBuffer[pixel] = fragment.depth;
  colorBuffer[pixel] = shade(fragment);
}
```

运行Visible-Surface Detection Methods时固定随机种子、输入几何、坐标约定和数值精度；记录编译命令或算法版本、输出摘要与失败条件。实验输出若依赖隐藏全局状态，必须先消除该依赖再比较。

<Callout type="trap" title="本页核心误区">
  清除值与比较函数不匹配，或用线性直觉解释非线性深度。这个错误会破坏“Visible-Surface Detection Methods的输入、公式中间量、输出与恢复结果可用同一基线复算”，应先由深度格式、近远平面、比较函数和重叠片元结果定位，再讨论性能或视觉风格。
</Callout>

<Callout type="trap" title="不要把别的图形API模板套进来">
  Visible-Surface Detection Methods只解释为同一像素选择最近可见片元。若原始资料讨论纯C++路径追踪、OpenGL时代图形学或光传输积分，就不能用VkBuffer、Fence与Semaphore替代相应的几何、光栅化或蒙特卡洛机制。
</Callout>

## 练习与答案

<Exercises>

**问题 1：公式与边界。** 怎样用一个数值样本证明 $z_{new}\prec z_{buffer}\Rightarrow (C,z)\leftarrow(C_{new},z_{new})$ 中的量没有混用空间、单位或概率密度？

<Answer>
  先写出每个量的定义域与单位，选择能手算的输入，分别计算中间量和最终结果；再只扰动一个量。若深度格式、近远平面、比较函数和重叠片元结果的变化方向与公式不一致，应拒绝实现而不是调整截图。
</Answer>

**问题 2：正式坐标。** visible-surface detection、z-buffer如何进入可操作验证？

<Answer>
  1. **visible-surface detection**：在专属实验中选中该节点，保存输入与深度格式、近远平面、比较函数和重叠片元结果，注入“清除值与比较函数不匹配，或用线性直觉解释非线性深度”后恢复并重放。
  2. **z-buffer**：在专属实验中选中该节点，保存输入与深度格式、近远平面、比较函数和重叠片元结果，注入“清除值与比较函数不匹配，或用线性直觉解释非线性深度”后恢复并重放。
</Answer>

**问题 3：故障恢复。** 如何证明“清除值与比较函数不匹配，或用线性直觉解释非线性深度”已经真正修复？

<Answer>
  保存正常基线，注入故障并标记深度格式、近远平面、比较函数和重叠片元结果中的首个分叉；撤销故障后以完全相同输入重放。只有Visible-Surface Detection Methods的输入、公式中间量、输出与恢复结果可用同一基线复算重新成立、结果可复现且实验重置回初值，修复才可交接。
</Answer>

</Exercises>
