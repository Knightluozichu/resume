## 链路层概述

<CntLinkLayerDiagram />

链路层负责 **相邻节点之间**（主机-路由器、路由器-路由器）的数据帧传输。每个IP数据报从源到目的，会经过多个链路层节点逐跳传输。

### 链路层服务

| 服务 | 说明 | 示例 |
|------|------|------|
| 成帧 | 将网络层数据报封装为帧 | 以太网帧、WiFi帧 |
| 差错检测 | 检测帧传输中的比特差错 | CRC、校验和 |
| 可靠交付 | 保证帧无差错送达 | WiFi（有ACK重传） |
| 流量控制 | 防止发送方压垮接收方 | 停等协议 |
| 半双工/全双工 | 链路双向传输能力 | 以太网全双工 |

## 差错检测与纠正

### 常见差错检测方法

| 方法 | 检测能力 | 开销 | 场景 |
|------|----------|------|------|
| 奇偶校验 | 检测1位差错 | 1位 | 简单串口 |
| 校验和 | 检测多位差错 | 16位 | IP/TCP/UDP |
| CRC | 检测突发差错 | 32位 | 以太网/WiFi |

### CRC（循环冗余校验）

```text
CRC原理：
1. 发送方和接收方约定一个生成多项式G（r+1位）
2. 数据D后面追加r个0，得到 D·2^r
3. 用 D·2^r 除以 G，余数R即为CRC（r位）
4. 发送 D + R

接收方：
5. 收到 D + R，用同样的G去除
6. 余数为0 → 无差错；余数非0 → 有差错

数学：D·2^r = n·G + R（模2除法，即异或运算）
```

<Callout type="info" title="CRC为什么比校验和更强">

校验和对数据求和取反，对突发差错（连续多位翻转）检测能力弱。CRC基于多项式除法，能检测所有1位和2位差错、所有奇数位差错、所有长度小于等于r的突发差错。CRC的数学性质使其差错检测率远高于校验和，因此链路层（以太网/WiFi）统一使用CRC-32。代价是计算复杂度更高，但现代硬件已用并行电路高效实现。

</Callout>

## 多路访问协议

当多个节点共享一条广播链路时，需要 **多路访问协议（MAC）** 协调谁可以发送。

### 三大类协议

#### 1. 信道划分

| 方式 | 原理 | 特点 |
|------|------|------|
| TDMA | 时分复用，每个节点分时隙 | 无冲突，但空闲时隙浪费 |
| FDMA | 频分复用，每个节点分频段 | 无冲突，但空闲频段浪费 |
| CDMA | 码分复用，每个节点分编码 | 可同时发送，抗干扰 |

#### 2. 随机访问

```text
时隙ALOHA：
  时隙开始时发送
  成功 → 下个时隙可再发
  冲突 → 下个时隙以概率p重传，1-p等待

  最大效率：G=0.5时 S=0.368（37%）

CSMA/CD（以太网）：
  1. 发送前先听信道（载波侦听）
  2. 信道空闲 → 发送
  3. 信道忙 → 等待
  4. 发送时检测冲突（碰撞检测）
  5. 冲突 → 立即停止 → 二进制指数退避 → 重试

  二进制指数退避：
  第n次冲突后等待 {0, 1, ..., 2^n-1} × 时隙时间（n <= 10）
```

<Callout type="warning" title="CSMA/CD为什么没有在WiFi中使用">

WiFi使用无线电波，无法在发送时同时侦听（发送信号远强于接收信号，无法检测碰撞）。而且存在隐藏终端问题——A和C都能听到B但A和C互相听不到，它们同时向B发送会碰撞但A和C无法检测。因此WiFi使用CSMA/CA（碰撞避免）而非CSMA/CD（碰撞检测），配合RTS/CTS握手解决隐藏终端。

</Callout>

#### 3. 轮转协议

```text
轮询（Polling）：
  主节点轮流邀请从节点发送
  优点：无冲突、无空闲时隙
  缺点：轮询开销、主节点故障

令牌传递（Token Passing）：
  令牌在节点间循环传递
  拿到令牌才可发送
  优点：无冲突、公平
  缺点：令牌丢失/重复、节点故障
```

## 以太网

以太网是最主流的局域网技术，采用CSMA/CD多路访问协议（全双工模式下无需CD）。

### 以太网帧格式

```text
前导码(8B) | 目的MAC(6B) | 源MAC(6B) | 类型(2B) | 数据(46-1500B) | CRC(4B)

类型字段：0x0800=IPv4, 0x86DD=IPv6, 0x0806=ARP
最小帧长：64字节（含CRC），保证冲突检测
MTU：1500字节（数据字段最大长度）
```

### MAC地址

```text
MAC地址 = 48位 = 6字节
  前24位：OUI（厂商标识，IEEE分配）
  后24位：厂商自行分配

  示例：08:00:27:71:36:A0

  特殊地址：
  FF:FF:FF:FF:FF:FF = 广播地址（所有节点接收）
  01:xx:xx:xx:xx:xx = 组播地址

  与IP地址的区别：
  IP地址 = 网络层地址，层级结构，随位置变化
  MAC地址 = 链路层地址，扁平结构，固化在网卡中
```

## 交换机

交换机是链路层设备，通过 **自学习** 维护MAC地址表，实现帧的定向转发。

### 交换机工作原理

```text
交换机转发表（MAC地址表）：
  MAC地址        | 接口 | 时间戳
  AA:BB:CC:00:01 |  1   | t1
  AA:BB:CC:00:02 |  3   | t2

帧转发流程：
1. 收到帧 → 记录源MAC→接口映射（自学习）
2. 查目的MAC：
   - 表中有 → 转发到对应接口（单播）
   - 表中无 → 洪泛到所有接口（除来源）
   - 广播地址 → 洪泛到所有接口（除来源）
3. 老化机制：超时未更新的表项自动删除
```

### 交换机 vs 路由器

| 特性 | 交换机 | 路由器 |
|------|--------|--------|
| 层级 | 链路层（二层） | 网络层（三层） |
| 地址 | MAC地址 | IP地址 |
| 转发表 | MAC地址表（自学习） | 路由表（路由协议） |
| 即插即用 | 是 | 否（需配置） |
| 广播域 | 同一广播域 | 分割广播域 |
| 转发速度 | 快（硬件查表） | 较慢（需处理IP头） |

## VLAN（虚拟局域网）

VLAN将一个物理交换机划分为多个逻辑局域网，隔离广播域。

```text
无VLAN：
  端口1-8 → 同一广播域（广播帧到达所有端口）

VLAN划分（基于端口）：
  端口1-4 → VLAN 10（工程部）
  端口5-8 → VLAN 20（市场部）
  
  VLAN 10的广播帧只到达端口1-4
  VLAN 20的广播帧只到达端口5-8
  VLAN间通信需通过路由器

跨交换机VLAN（Trunk链路）：
  交换机A(VLAN10,20) ←─Trunk─→ 交换机B(VLAN10,20)
  
  Trunk帧格式：802.1Q标签
  [源MAC|类型|VLAN ID(12位)|数据|CRC]
```

<Glossary>

<GlossaryItem term="CRC（循环冗余校验）">
CRC是链路层广泛使用的差错检测方法。发送方将数据D追加r个0后用约定生成多项式G做模2除法，余数R（r位）作为CRC附在数据后发送。接收方用同样的G除收到的比特串，余数为0则无差错。CRC能检测所有1位和2位差错、所有奇数位差错、所有长度小于等于r的突发差错，检测能力远强于校验和。以太网和WiFi使用CRC-32，由硬件电路高效实现。
</GlossaryItem>

<GlossaryItem term="CSMA/CD（载波侦听多路访问/碰撞检测）">
CSMA/CD是以太网的多路访问协议。原理：①发送前先听信道（载波侦听），空闲才发送 ②发送时同时检测碰撞（碰撞检测），碰撞则立即停止 ③碰撞后执行二进制指数退避——第n次碰撞后随机等待&#123;0..2^n-1&#125;个时隙再重试。全双工交换式以太网无需CD（每条链路独占）。CSMA/CD不适合无线网络（无法边发边听、隐藏终端问题），WiFi改用CSMA/CA。
</GlossaryItem>

<GlossaryItem term="交换机（Switch）">
交换机是链路层设备，通过自学习维护MAC地址表实现帧的定向转发。收到帧时记录源MAC→接口映射，查目的MAC：有则定向转发、无则洪泛。交换机是即插即用的（无需配置），通过消除碰撞域提高网络性能（每个端口独占带宽）。与路由器相比，交换机工作在二层、用MAC地址、即插即用、不分割广播域。现代数据中心广泛使用交换机构架Clos网络。
</GlossaryItem>

<GlossaryItem term="VLAN（虚拟局域网）">
VLAN将一个物理交换机划分为多个逻辑广播域。基于端口划分最常见（端口1-4为VLAN10，端口5-8为VLAN20）。VLAN隔离广播帧——VLAN10的广播只到达VLAN10的端口，减少广播风暴风险。跨交换机VLAN通过Trunk链路传输，帧中插入802.1Q标签（含12位VLAN ID）标识所属VLAN。VLAN间通信需通过三层路由器或三层交换机。VLAN提高了网络安全性、灵活性和可管理性。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1：** CSMA/CD的工作原理是什么？二进制指数退避是什么？

<Answer>

CSMA/CD（载波侦听多路访问/碰撞检测）工作原理：①发送前先听信道（载波侦听），信道空闲才发送 ②发送数据时同时侦听信道检测碰撞（碰撞检测） ③检测到碰撞立即停止发送，发送拥塞信号 ④执行二进制指数退避后重试。二进制指数退避：第n次碰撞后，随机选择&#123;0, 1, ..., 2^k-1&#125;中的一个数（k=min(n,10)），等待该数×时隙时间后重传。随着碰撞次数增加，等待时间范围指数增长，使高负载时碰撞概率降低。第16次碰撞仍失败则放弃。全双工交换式以太网中每个端口独占链路，无需CD。
</Answer>

**问题 2：** 交换机如何自学习MAC地址表？交换机和路由器有什么区别？

<Answer>

交换机自学习过程：①交换机初始MAC地址表为空 ②收到帧时，记录源MAC地址→入接口的映射和时间戳 ③查目的MAC：表中有对应表项则定向转发到该接口，表中无则洪泛到所有接口（除来源接口），目的为广播地址则洪泛 ④表项有老化机制，超时未更新自动删除。交换机与路由器的区别：①层级——交换机工作在链路层（二层），路由器在网络层（三层） ②地址——交换机用MAC地址，路由器用IP地址 ③转发表——交换机MAC表自学习即插即用，路由器路由表需路由协议计算 ④广播域——交换机不分割广播域（同一VLAN内），路由器分割广播域 ⑤速度——交换机硬件查表更快。
</Answer>

</Exercises>
