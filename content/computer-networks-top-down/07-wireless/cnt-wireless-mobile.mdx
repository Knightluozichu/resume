## 无线网络概述

<CntWirelessMobileDiagram />

无线网络与有线网络的核心差异在于 **无线信道的物理特性**：信号衰减、干扰、多径效应，导致无线链路误码率高、带宽波动大。

### 无线链路的挑战

| 挑战 | 原因 | 影响 |
|------|------|------|
| 信号衰减 | 距离增加信号强度下降 | 远距离速率降低 |
| 干扰 | 其他无线源共享频段 | 误码率升高 |
| 多径效应 | 信号反射形成多条路径 | 码间干扰 |
| 隐藏终端 | A和C听不到彼此但都影响B | 碰撞无法检测 |
| 暴露终端 | B听到C的发送但其实不影响 | 不必要地等待 |

```text
隐藏终端问题：              暴露终端问题：
  A    B    C               A    B    C    D
  ●────●────●               ●────●────●────●
  ↘    ↑    ↗                  ↗       
  A→B  C→B                B→C（B听到A在发，实际不影响）
  A和C互相听不到           B不必要地等待A发完
  同时向B发送 → 碰撞        → 浪费带宽
```

## WiFi（IEEE 802.11）

WiFi是基于802.11标准的无线局域网技术，是最常见的无线接入方式。

### 802.11体系结构

```text
无线主机 ──── 基站(AP) ──── 有线网络

BSS（基本服务集）：AP + 关联的无线主机
ESS（扩展服务集）：多个BSS通过DS（分布式系统）互联

  BSS1(AP1) ──DS── BSS2(AP2)
  主机A, B          主机C, D
  
主机从一个AP漫游到另一个AP = 切换(Handoff)
```

### CSMA/CA协议

WiFi无法使用CSMA/CD（无法边发边听 + 隐藏终端），改用 **CSMA/CA（碰撞避免）**。

```text
CSMA/CA工作流程：
1. 发送前侦听信道DIFS时间
2. 信道空闲 → 发送
3. 信道忙 → 随机退避（二进制指数退避）
4. 发送整个帧（不检测碰撞）
5. 等待接收方ACK（SIFS后）
6. 收到ACK → 成功；超时 → 重传

RTS/CTS握手（解决隐藏终端）：
  发送方 → RTS（请求发送）→ AP
  AP → CTS（清除发送）→ 所有节点
  发送方收到CTS → 开始发送数据
  隐藏终端听到CTS → 保持沉默

  RTS/CTS小帧碰撞代价小，数据帧无碰撞
```

<Callout type="info" title="为什么WiFi用CSMA/CA而非CSMA/CD">

两个原因：①无法边发边听——WiFi发射信号强度远大于接收信号，发送时无法同时侦听碰撞 ②隐藏终端——A和C互相听不到但都能向B发送，即使载波侦听认为信道空闲仍会碰撞。CSMA/CA通过RTS/CTS预约信道和ACK确认来避免碰撞和检测丢失。SIFS（短帧间间隔）比DIFS短，确保ACK和RTS/CTS等控制帧优先发送。

</Callout>

## 蜂窝网络

蜂窝网络提供广域无线覆盖，通过基站将区域划分为 **蜂窝小区（Cell）**。

### 蜂窝架构

```text
蜂窝网络体系结构：
  移动设备 ←→ 基站(BS) ←→ 基站控制器(BSC) ←→ 移动交换中心(MSC) ←→ PSTN/互联网

小区(Cell)：一个基站覆盖的六边形区域
频率复用：不相邻小区复用相同频率，提高频谱效率
```

### 代际演进

| 代际 | 技术 | 数据速率 | 关键特性 |
|------|------|----------|----------|
| 2G | GSM/GPRS | ~100Kbps | 电路交换+分组交换 |
| 3G | UMTS/HSPA | ~10Mbps | 全分组交换 |
| 4G | LTE | ~100Mbps | 全IP扁平架构 |
| 5G | NR | ~10Gbps | 毫米波、网络切片 |

### 4G LTE全IP架构

```text
4G LTE扁平架构（全IP，无电路交换）：

  UE(用户设备) ←→ eNodeB(基站) ←→ EPC(核心网) ←→ 互联网

  EPC核心网组件：
  MME（移动管理实体）：移动性管理、信令
  S-GW（服务网关）：数据面锚点
  P-GW（PDN网关）：连接外部互联网、IP分配
```

## 移动性管理

移动性管理的核心问题是：**移动节点改变网络接入点后，如何保持通信不中断**。

### 归属网络与归属代理

```text
永久地址（归属地址）：移动节点的固定IP（在归属网络中）
转交地址：移动节点在外地网络获得的临时IP

归属网络：
  ┌──────────┐
  │ 归属代理HA│ ← 永久地址 10.0.0.1
  └──────────┘
      │ 代理
      ↓
外地网络：
  ┌──────────┐
  │ 外地代理FA│ ← 转交地址 192.168.2.1
  └──────────┘
      │
  移动节点(10.0.0.1) ←── 在外地网络中

通信对端 → 发往 10.0.0.1 → 到达HA → 隧道转发到FA → 交付移动节点
```

### 移动IP的路由

```text
间接路由（三角路由）：
  对端 → HA → 隧道 → FA → 移动节点
  问题：HA到移动节点可能绕远（三角路由问题）

直接路由：
  对端先问HA获取转交地址
  对端 → 直接隧道 → FA → 移动节点
  解决三角路由，但需要通信对端支持移动性
```

### 切换（Handoff）

```text
切换流程（移动节点从一个AP/基站移动到另一个）：

1. 移动节点检测到当前信号变弱，新AP信号变强
2. 向新AP发起关联请求
3. 新AP通知旧AP：该节点已移入
4. 旧AP将缓存的待发帧转发给新AP
5. 路由更新：归属代理更新转交地址指向新AP
6. 移动节点通过新AP继续通信

切换目标：最小化丢包和延迟，实现无缝移动
```

<Callout type="warning" title="移动IP的三角路由问题">

在间接路由中，所有发往移动节点的数据都要先到归属代理再隧道转发，即使通信对端就在移动节点附近。这就是三角路由——直接路径是「对端→移动节点」，实际路径是「对端→归属代理→移动节点」，可能绕远。解决方案是直接路由：通信对端先从归属代理获取转交地址，然后直接隧道到移动节点当前位置。但直接路由需要通信对端支持移动性协议，部署难度大。

</Callout>

<Glossary>

<GlossaryItem term="CSMA/CA（载波侦听多路访问/碰撞避免）">
CSMA/CA是WiFi(802.11)的多路访问协议。与以太网的CSMA/CD不同，WiFi无法边发边听（发射信号远强于接收信号）且存在隐藏终端问题，因此改用碰撞避免：发送前侦听信道DIFS时间空闲才发送，发送整个帧后等SIFS收ACK确认。RTS/CTS握手解决隐藏终端——发送方先发RTS预约，AP回复CTS让所有节点知道即将有传输，隐藏终端听到CTS后保持沉默。退避使用二进制指数退避。
</GlossaryItem>

<GlossaryItem term="隐藏终端与暴露终端">
隐藏终端：A和C都能与B通信但互相听不到。当A和C同时向B发送时，在B处碰撞但A和C无法检测。CSMA/CD失效。解决：RTS/CTS握手。暴露终端：B能听到A发送（A→某人），B想向C发送但其实不影响A的接收，却不必要地等待。导致频谱利用率降低。暴露终端可通过RTS/CTS的交互解决——B听到A的RTS但没听到对应的CTS（CTS由A的接收方发出），说明B发送不影响A。
</GlossaryItem>

<GlossaryItem term="移动IP">
移动IP是支持移动节点在不同网络间移动而保持IP地址不变的协议。核心机制：①移动节点有永久地址（归属网络中）和转交地址（外地网络中临时获得）②归属代理(HA)跟踪移动节点当前位置 ③发往永久地址的数据被HA截获，通过隧道转发到转交地址 ④间接路由存在三角路由问题，直接路由由对端直接隧道到当前位置解决。切换时HA更新转交地址指向新网络的外地代理。
</GlossaryItem>

<GlossaryItem term="蜂窝网络（Cellular Network）">
蜂窝网络将覆盖区域划分为六边形小区，每个小区一个基站。频率复用（不相邻小区复用频率）提高频谱效率。体系结构：移动设备←→基站(BS)←→基站控制器←→移动交换中心(MSC)←→PSTN。4G LTE采用全IP扁平架构（UE←→eNodeB←→EPC核心网），5G引入毫米波、大规模MIMO和网络切片。蜂窝网络与WiFi互补——WiFi提供热点覆盖，蜂窝提供广域覆盖。
</GlossaryItem>

</Glossary>

**问题 1：** WiFi为什么使用CSMA/CA而不是CSMA/CD？RTS/CTS如何解决隐藏终端问题？

<Answer>

WiFi使用CSMA/CA而非CSMA/CD的两个原因：①无法边发边听——WiFi发射信号强度远大于接收信号强度，发送时无法同时侦听碰撞 ②隐藏终端问题——A和C互相听不到但都能向B发送，即使载波侦听认为信道空闲仍会在B处碰撞，CSMA/CD无法检测。CSMA/CA通过碰撞避免（发送前等待DIFS、ACK确认丢失则重传）和RTS/CTS解决。RTS/CTS解决隐藏终端：发送方先发RTS（小帧）给AP，AP回复CTS广播给所有节点。隐藏终端C听到CTS后知道即将有传输，保持沉默。RTS/CTS是小帧，即使碰撞代价也小，后续数据帧无碰撞传输。SIFS比DIFS短，确保ACK和RTS/CTS优先发送。
</Answer>

**问题 2：** 移动IP的归属代理和转交地址是什么？三角路由问题是什么？

<Answer>

归属代理(HA)是移动节点归属网络中的路由器，维护移动节点的当前位置信息。转交地址是移动节点在外地网络中获得的临时IP地址，标识其当前位置。移动IP工作流程：移动节点在外地网络获得转交地址后，向归属代理注册。通信对端发往移动节点永久地址的数据到达归属代理，HA通过隧道转发到转交地址（外地代理），再交付移动节点。三角路由问题：在间接路由中，即使通信对端就在移动节点附近，数据也必须先到归属代理再绕回来——直接路径是「对端→移动节点」，实际路径是「对端→HA→移动节点」。解决方案是直接路由：通信对端先从HA获取转交地址，然后直接隧道到当前位置，但需要对端支持移动性协议。
</Answer>
