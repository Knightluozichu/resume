## 直觉引入

递归是全书的第一课。汉诺塔问题给出了最经典的递归 $T(n)=2T(n-1)+1$，而 Josephus 问题则展示了更复杂的 $J(2n)=2J(n)-1$ 型递归。

这些看似不同的问题共享同一个解题模式：先用极小的例子（$n=1,2,3$）猜出闭式，再用数学归纳法严格证明。当递归带参数时，成套方法（Repertoire Method）把解设为参数的线性组合，用已知特例反求系数——这是 Concrete Mathematics 独创的标志性技巧。

## 概念讲解

<Term def="把 n 盘问题化为 n-1 盘子问题的自我引用">递归关系</Term>的核心是找到分解与合并的方式。汉诺塔：移动 $n-1$ 盘到辅助柱，移最大盘，再移 $n-1$ 盘到目标柱，得 $T(n)=2T(n-1)+1$。

<Term def="用 n=1,2,3 的值猜测闭式再用归纳法证明">先猜后证</Term>是全书的哲学：$T(1)=1, T(2)=3, T(3)=7$ → 猜 $T(n)=2^n-1$，然后归纳验证。

<Term def="把递归通解设为参数线性组合再反求系数的方法">成套方法</Term>处理带参数的递归：设 $f(n)=A\alpha+B\beta+C\gamma$，用已知特例（$f(1)=\alpha$ 等）解出 $A,B,C$。

### Josephus 问题的求解
约瑟夫问题中 $n$ 人围成一圈，每隔一人淘汰一个，求幸存者位置 $J(n)$。
- 偶数：$J(2n)=2J(n)-1$（淘汰所有奇数位，剩余 $n$ 人重新编号）
- 奇数：$J(2n+1)=2J(n)+1$（淘汰奇数位后，1 号也被淘汰）
- 设 $n=2^m+l$（$0\leq l&lt;2^m$），则闭式 $J(n)=2l+1$

### 成套方法详解
考虑递归 $f(1)=\alpha,\; f(2n)=2f(n)+\beta,\; f(2n+1)=2f(n)+\gamma$。
设 $f(n)=A(n)\alpha+B(n)\beta+C(n)\gamma$，用特例解 $A,B,C$：
- $f(1)=\alpha$ → $A(1)=1, B(1)=0, C(1)=0$
- $f(2)=2\alpha+\beta$ → $A(2)=2, B(2)=1, C(2)=0$
- $f(3)=2\alpha+\gamma$ → $A(3)=2, B(3)=0, C(3)=1$
猜测并验证：$A(n)=2^m,\; B(n)=2^m-1-l,\; C(n)=l$（$n=2^m+l$）。

## 代码对照

用 Python 验证汉诺塔与 Josephus 的闭式解：

```python
def hanoi(n):
    return 2**n - 1

def hanoi_rec(n):
    return 1 if n == 1 else 2 * hanoi_rec(n - 1) + 1

def josephus(n):
    m = n.bit_length() - 1  # floor(log2(n))
    l = n - (1 &lt;&lt; m)        # n = 2^m + l
    return 2 * l + 1

def josephus_sim(n):
    """模拟 Josephus 问题验证闭式"""
    circle = list(range(1, n + 1))
    idx = 0
    while len(circle) > 1:
        idx = (idx + 1) % len(circle)  # 跳过一人
        circle.pop(idx)                 # 淘汰下一人
        idx = idx % len(circle)
    return circle[0]

for n in range(1, 20):
    assert hanoi(n) == hanoi_rec(n), f"Hanoi mismatch at n={n}"
    assert josephus(n) == josephus_sim(n), f"Josephus mismatch at n={n}"

print(f"Hanoi(10) = {hanoi(10)}")       # 1023
print(f"Josephus(41) = {josephus(41)}")  # 19
print(f"Josephus(8) = {josephus(8)}")    # 1 (8=2^3+0 → 2*0+1=1)

```

`josephus` 函数用 `bit_length` 快速求 $\lfloor\log_2 n\rfloor$。注意 $n=2^m$ 时 $l=0$，$J(n)=1$，即 2 的幂时 1 号位幸存。模拟函数 `josephus_sim` 验证闭式的正确性。

## 常见误区

<Callout type="trap">
**现象 →** 直接解递归时忘了验证基础情况。
**原因 →** 只关注递推式，忽略了 n=1 的边界。
**修法 →** 归纳法必须有基础步。T(0)=0 和 T(1)=1 都要验证，否则归纳链断裂。
</Callout>

<Callout type="trap">
**现象 →** Josephus 问题中不会用 2^m+l 分解。
**原因 →** 习惯性地把 n 当作普通整数，没有注意到 2 的幂的特殊性。
**修法 →** 2^m 是递归的「自然边界」：n=2^m 时 J(n)=1，非幂部分用 l 偏移。这是二进制思维的核心。
</Callout>

<Exercises>
**问题**：用成套方法求解递归 f(1)=α, f(2n)=2f(n)+β, f(2n+1)=2f(n)+γ，写出 f(n) 的闭式。

<Answer>
设 n=2^m+l（0≤l&lt;2^m）。通过特例反解：A(n)=2^m（α 的系数），B(n)=2^m-1-l（β 的系数），C(n)=l（γ 的系数）。故 f(n)=2^m·α+(2^m-1-l)·β+l·γ。验证：f(1)=1·α+0·β+0·γ=α ✓，f(2)=2α+1β ✓。
</Answer>

**问题**：Josephus 问题中 n=41，求幸存者位置。

<Answer>
41=2^5+9（2^5=32, l=9）。J(41)=2×9+1=19。验证思路：32 人时 1 号幸存，多出的 9 人先把 33~41 号对应的淘汰模式偏移，幸存者从 1 号移到 19 号。
</Answer>
</Exercises>
