## 直觉引入

取整函数 $\lfloor x \rfloor$ 和取模 $x \bmod y$ 看起来简单，但它们的组合可以产生深刻的结构。Concrete Mathematics 用整整一章展示这些「简单」函数的惊人威力。

一个核心观察：$\lfloor x \rfloor$ 把连续量离散化，而 $\lfloor n\alpha \rfloor$（$\alpha$ 为无理数）生成的序列——称为「谱」——具有均匀分布的深刻性质。Beatty 定理告诉我们，满足 $1/\alpha+1/\beta=1$ 的两个无理数的谱恰好分割所有正整数，这就是取整函数的美。

## 概念讲解

<Term def="不超过 x 的最大整数">下取整</Term> $\lfloor x \rfloor$ 满足 $\lfloor x \rfloor \leq x < \lfloor x \rfloor + 1$。<Term def="不小于 x 的最小整数">上取整</Term> $\lceil x \rceil$ 满足 $\lceil x \rceil - 1 < x \leq \lceil x \rceil$。两者关系：$\lceil x \rceil = -\lfloor -x \rfloor$。

<Term def="x 除以 y 的余数">取模</Term>定义为 $x \bmod y = x - y\lfloor x/y \rfloor$（$y > 0$）。关键性质：$\lfloor x/m \rfloor = \lfloor \lfloor x \rfloor / m \rfloor$（$m$ 为正整数），这意味着取整可以「嵌套」。

### Hermite 恒等式
$$\lfloor x \rfloor + \left\lfloor x + \frac{1}{n} \right\rfloor + \cdots + \left\lfloor x + \frac{n-1}{n} \right\rfloor = \lfloor nx \rfloor$$

### n! 中素数 p 的幂次
$$v_p(n!) = \sum_{k=1}^{\infty} \left\lfloor \frac{n}{p^k} \right\rfloor$$
这是因为每 $p$ 个数有一个 $p$ 的倍数，每 $p^2$ 个数额外贡献一个 $p$，以此类推。

### Beatty 定理
若 $\alpha, \beta$ 为正无理数且 $1/\alpha + 1/\beta = 1$，则谱 $\{\lfloor n\alpha \rfloor\}$ 与 $\{\lfloor n\beta \rfloor\}$（$n=1,2,\ldots$）恰好覆盖所有正整数且不重叠。

例：$\alpha=\phi$（黄金比），$\beta=\phi^2$，$1/\phi+1/\phi^2=1$，两谱互补。

## 代码对照

用 Python 验证取整函数性质与 n! 的素数幂次：

```python
import math

def vp_factorial(n, p):
    """n! 中素数 p 的幂次 = Σ⌊n/p^k⌋"""
    total = 0
    pk = p
    while pk <= n:
        total += n // pk
        pk *= p
    return total

def trailing_zeros(n):
    """n! 末尾零的个数 = v_5(n!)"""
    return vp_factorial(n, 5)

def hermite_identity(x, n):
    """验证 Hermite 恒等式"""
    lhs = sum(math.floor(x + k / n) for k in range(n))
    rhs = math.floor(n * x)
    return lhs == rhs

def beatty_check(alpha, n_max):
    """验证 Beatty 定理：1/α+1/β=1 时两谱互补"""
    beta = alpha / (alpha - 1)  # 由 1/α+1/β=1 推出
    s1 = set(math.floor(k * alpha) for k in range(1, n_max + 1))
    s2 = set(math.floor(k * beta) for k in range(1, n_max + 1))
    union = s1 | s2
    return s1 & s2, union == set(range(1, max(union) + 1))

print(f"100! 末尾零个数: {trailing_zeros(100)}")  # 24
print(f"v_2(10!) = {vp_factorial(10, 2)}")          # 8
print(f"Hermite(3.7, 4): {hermite_identity(3.7, 4)}")  # True

phi = (1 + math.sqrt(5)) / 2
overlap, complete = beatty_check(phi, 100)
print(f"Beatty(φ): 重叠={len(overlap)}, 覆盖={complete}")  # 0, True

# 嵌套取整验证
for x in [3.7, 5.2, 10.9]:
    for m in [2, 3, 4]:
        assert math.floor(x / m) == math.floor(math.floor(x) / m), f"嵌套取整 fail: {x}, {m}"

```

`vp_factorial` 用 $\sum\lfloor n/p^k \rfloor$ 计算 $n!$ 中 $p$ 的幂次。100! 末尾有 24 个零（$v_5(100!)=24$）。Beatty 定理对 $\phi$ 验证：两谱无重叠且完全覆盖正整数。

## 常见误区

<Callout type="trap">
**现象 →** 混淆 ⌊x⌋ 和 [x]（四舍五入）。
**原因 →** 习惯使用四舍五入而非下取整。
**修法 →** Concrete Mathematics 中 ⌊x⌋ 是下取整（floor），不是四舍五入。x=3.7 时 ⌊x⌋=3 不是 4。⌈x⌉ 是上取整（ceil），⌈3.2⌉=4。
</Callout>

<Callout type="trap">
**现象 →** mod 运算对负数结果困惑。
**原因 →** 不同语言对负数 mod 的定义不同。
**修法 →** Concrete Mathematics 定义 x mod y = x - y⌊x/y⌋，结果总在 [0,|y|) 范围内。-3 mod 5 = -3-5⌊-3/5⌋ = -3-5×(-1) = 2。Python 的 % 运算与此一致。
</Callout>

<Exercises>
**问题**：求 100! 末尾有多少个零。

<Answer>
末尾零的个数 = v_5(100!) = ⌊100/5⌋+⌊100/25⌋+⌊100/125⌋ = 20+4+0 = 24。注意不需要算 v_2，因为 v_2 > v_5 总成立，5 是瓶颈。
</Answer>

**问题**：证明 ⌊x/m⌋ = ⌊⌊x⌋/m⌋（m 为正整数）。

<Answer>
设 x = ⌊x⌋ + {x}（{x} 为小数部分）。⌊x/m⌋ = ⌊(⌊x⌋+{x})/m⌋。设 ⌊x⌋ = qm+r（0≤r<m），则 (⌊x⌋+{x})/m = q+(r+{x})/m。因 0≤r+{x}<m（因 r<m 且 {x}<1≤m），故 ⌊(r+{x})/m⌋=0，得 ⌊x/m⌋=q=⌊⌊x⌋/m⌋。
</Answer>
</Exercises>
