## 直觉引入

求和是递归的自然延伸：递归展开后得到求和式，求和式的闭式就是递归的解。Concrete Mathematics 把求和视为与积分平行的「离散积分」。

扰动法是本书对求和技术最优雅的贡献：在求和式 $S_n$ 的两端各加一项，巧妙地让一端的 $a_0$ 与另一端的 $a_{n+1}$ 对应，通过移项直接解出 $S_n$。这种方法不需要猜测，纯靠代数操作就能化简一大类求和。

## 概念讲解

求和的三条基本法则对应线性运算的性质：
- <Term def="常数可提出求和号">分配律</Term>：$\sum c\cdot a_k = c\sum a_k$
- <Term def="逐项相加">结合律</Term>：$\sum (a_k+b_k) = \sum a_k + \sum b_k$
- <Term def="改变求和下标">交换律</Term>：可交换求和顺序

<Term def="在求和两端各加一项再移项求解的技术">扰动法</Term>的核心操作：
$$S_n = \sum_{k=0}^{n} a_k \quad \Rightarrow \quad S_n + a_{n+1} = a_0 + \sum_{k=1}^{n+1} a_k$$
右端令 $j=k-1$（即 $k=j+1$）使下标从 0 开始，消去 $a_0$ 后解出 $S_n$。

### 经典幂和
- $\sum_{k=0}^{n} k = \frac{n(n+1)}{2}$
- $\sum_{k=0}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}$
- $\sum_{k=0}^{n} k^3 = \left(\frac{n(n+1)}{2}\right)^2$

注意 $\sum k^3 = (\sum k)^2$，这不是巧合——它源于下降幂与 Stirling 数的深层结构。

### 多重求和
双重求和 $\sum_{j}\sum_{k} a_{j,k}$ 可以交换顺序，但要注意求和范围的变化。用 Iverson 记号 $[P]$（条件 $P$ 为真时为 1，否则为 0）可以把求和范围编码进被加项中，极大简化多重求和的推导。

### 扰动法实例
求 $S_n = \sum_{k=0}^{n} k 2^k$：
$$S_n + (n+1)2^{n+1} = 0\cdot 2^0 + \sum_{k=1}^{n+1} k 2^k = \sum_{j=0}^{n} (j+1)2^{j+1} = 2\sum_{j=0}^{n} j 2^j + 2\sum_{j=0}^{n} 2^j$$
$$= 2S_n + 2(2^{n+1}-1)$$
解得 $S_n = (n+1)2^{n+1} - 2(2^{n+1}-1) = (n-1)2^{n+1}+2$。

## 代码对照

用 Python 验证扰动法求得的闭式：

```python
def sum_k(n):
    return n * (n + 1) // 2

def sum_k2(n):
    return n * (n + 1) * (2 * n + 1) // 6

def sum_k3(n):
    return (n * (n + 1) // 2) ** 2

def sum_k2k(n):
    """扰动法结果：Σ k*2^k = (n-1)*2^(n+1) + 2"""
    return (n - 1) * (1 << (n + 1)) + 2

for n in range(20):
    assert sum_k(n) == sum(range(n + 1)), f"Σk fail at {n}"
    assert sum_k2(n) == sum(k*k for k in range(n + 1)), f"Σk² fail at {n}"
    assert sum_k3(n) == sum(k**3 for k in range(n + 1)), f"Σk³ fail at {n}"
    assert sum_k2k(n) == sum(k * (1 << k) for k in range(n + 1)), f"Σk2^k fail at {n}"

print(f"Σk(100) = {sum_k(100)}")        # 5050
print(f"Σk²(10) = {sum_k2(10)}")       # 385
print(f"Σk³(10) = {sum_k3(10)}")       # 3025 = 55²
print(f"Σk·2^k(8) = {sum_k2k(8)}")     # 2302

# Iverson 记号演示：双重求和换序
# Σ_{j=0}^{n} Σ_{k=0}^{j} a[j][k]  ↔  Σ_{k=0}^{n} Σ_{j=k}^{n} a[j][k]
n = 5
A = [[j + k for k in range(n + 1)] for j in range(n + 1)]
s1 = sum(A[j][k] for j in range(n + 1) for k in range(j + 1))
s2 = sum(A[j][k] for k in range(n + 1) for j in range(k, n + 1))
assert s1 == s2, "换序失败"
print(f"双重求和换序验证: {s1} == {s2}")

```

`sum_k2k` 用扰动法得到的闭式 $(n-1)2^{n+1}+2$ 验证通过。注意 $\sum k^3 = (\sum k)^2$ 对所有 $n$ 成立——这是组合恒等式，源于 $k^3$ 用下降幂表示后 Stirling 数的对称性。

## 常见误区

<Callout type="trap">
**现象 →** 求和时混淆上下界，差一错误频发。
**原因 →** 没有明确 $\sum_{k=0}^{n}$ 是 0 到 n 含 n 还是 0 到 n-1。
**修法 →** Concrete Mathematics 约定 $\sum_{k=0}^{n}$ 含 $n$，$\sum_{0 \leq k \leq n}$ 同义。用 Iverson 记号 $[0 \leq k \leq n]$ 消除歧义。
</Callout>

<Callout type="trap">
**现象 →** 双重求和换序时范围出错。
**原因 →** 直接交换 $\sum_j \sum_k$ 而不调整范围。
**修法 →** 用 Iverson 记号把范围编码进被加项：$\sum_j \sum_k a_{j,k}[0\leq k \leq j]$，换序后自然变成 $\sum_k \sum_j a_{j,k}[k \leq j \leq n]$。
</Callout>

<Exercises>
**问题**：用扰动法求 S_n = Σ_{k=0}^{n} k·2^k 的闭式。

<Answer>
S_n + (n+1)2^{n+1} = 0 + Σ_{k=1}^{n+1} k·2^k。令 j=k-1，右端 = Σ_{j=0}^{n} (j+1)2^{j+1} = 2Σ j·2^j + 2Σ2^j = 2S_n + 2(2^{n+1}-1)。移项：-S_n = 2(2^{n+1}-1) - (n+1)2^{n+1}，故 S_n = (n+1)2^{n+1} - 2^{n+2} + 2 = (n-1)2^{n+1}+2。
</Answer>

**问题**：证明 Σ_{k=0}^{n} k³ = (Σ_{k=0}^{n} k)²。

<Answer>
右边 = (n(n+1)/2)²。用下降幂：k³ = k³_ + 3k²_ + k_，其中 k³_=k(k-1)(k-2), k²_=k(k-1), k_=k。Σk³_ = 6C(n+1,3), Σk²_ = 2C(n+1,2), Σk_ = C(n+1,1)。化简后 Σk³ = C(n+1,1)² = (n(n+1)/2)²。也可直接验证 Σk³ = n²(n+1)²/4 = (n(n+1)/2)²。
</Answer>
</Exercises>
