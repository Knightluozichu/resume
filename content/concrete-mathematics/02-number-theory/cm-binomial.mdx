## 直觉引入

二项式系数 $\binom{n}{k}$ 是组合数学的核心对象。Concrete Mathematics 把它推广到任意实数（甚至复数）上指标，揭示了远超「组合计数」的深刻结构。

上指标反转 $\binom{-r}{k}=(-1)^k\binom{r+k-1}{k}$ 是最重要的技巧之一——它把负上指标转化为正上指标，使得生成函数 $(1+z)^{-r}$ 的展开有了组合意义。而吸收律 $k\binom{n}{k}=n\binom{n-1}{k-1}$ 则是化简含 $k$ 的二项式求和的利器。

## 概念讲解

<Term def="从 n 个中选 k 个的组合数">二项式系数</Term> $\binom{n}{k}=\frac{n!}{k!(n-k)!}=\frac{n^{\underline{k}}}{k!}$（$n^{\underline{k}}=n(n-1)\cdots(n-k+1)$ 为下降幂）。<Term def="C(n,k)=C(n-1,k)+C(n-1,k-1)">Pascal 递推</Term>是构造杨辉三角的递归。

<Term def="把负上指标转化为正上指标">上指标反转</Term>：$\binom{-r}{k}=(-1)^k\binom{r+k-1}{k}$。这使得 $(1+z)^{-r}=\sum_k(-1)^k\binom{r+k-1}{k}z^k$ 有了组合意义。

<Term def="k·C(n,k)=n·C(n-1,k-1)">吸收律</Term>可以把含 $k$ 的项「吸收」进二项式系数内部。<Term def="ΣC(r,k)C(s,n-k)=C(r+s,n)">范德蒙卷积</Term>是二项式定理的乘法对应。

### 二项式定理
$$(1+z)^r = \sum_{k} \binom{r}{k} z^k$$
对任意实数 $r$ 成立。当 $r$ 为正整数时，$k$ 超过 $r$ 的项为零；当 $r$ 为负数时，用上指标反转得到无限级数。

### 关键求和
- $\sum_{k=0}^{n}\binom{n}{k}=2^n$（二项式定理 $z=1$）
- $\sum_{k=0}^{n}\binom{n}{k}^2=\binom{2n}{n}$（范德蒙，$r=s=n$）
- $\sum_{k=0}^{n}(-1)^k\binom{n}{k}=0$（二项式定理 $z=-1$）
- $\sum_{k=0}^{r}\binom{r}{k}\binom{s}{n-k}=\binom{r+s}{n}$（范德蒙卷积）

### 吸收律的应用
求 $\sum_{k=0}^{n}k\binom{n}{k}$：
$$k\binom{n}{k}=n\binom{n-1}{k-1} \Rightarrow \sum_{k=0}^{n}k\binom{n}{k}=n\sum_{k=1}^{n}\binom{n-1}{k-1}=n\cdot 2^{n-1}$$

### 平行求和
$$\sum_{k \leq n}\binom{r+k}{k}=\binom{r+n+1}{n}$$
这对应 Pascal 递推的反复应用——每一项「吸收」前一项。

## 代码对照

用 Python 验证二项式系数恒等式：

```python
from math import comb, factorial

def binom(n, k):
    """广义二项式系数：支持负上指标"""
    if k < 0:
        return 0
    if n >= 0:
        return comb(n, k) if k <= n else 0
    # 上指标反转：C(-r,k) = (-1)^k * C(r+k-1, k)
    r = -n
    return ((-1) ** k) * comb(r + k - 1, k)

# Pascal 递推
for n in range(10):
    for k in range(n + 1):
        if k > 0:
            assert binom(n, k) == binom(n-1, k-1) + binom(n-1, k)

# 二项式定理: ΣC(n,k) = 2^n
for n in range(15):
    assert sum(binom(n, k) for k in range(n + 1)) == 2 ** n

# 范德蒙: ΣC(r,k)C(s,n-k) = C(r+s,n)
r, s, n = 5, 4, 3
lhs = sum(binom(r, k) * binom(s, n - k) for k in range(n + 1))
assert lhs == binom(r + s, n), f"Vandermonde fail: {lhs}"
print(f"Vandermonde({r},{s},{n}) = {lhs} = C({r+s},{n})")

# 吸收律: Σk·C(n,k) = n·2^{n-1}
n = 10
result = sum(k * binom(n, k) for k in range(n + 1))
assert result == n * 2 ** (n - 1)
print(f"Σk·C({n},k) = {result} = {n}·2^{n-1}")

# ΣC(n,k)² = C(2n,n)
n = 8
result = sum(binom(n, k) ** 2 for k in range(n + 1))
assert result == binom(2 * n, n)
print(f"ΣC({n},k)² = {result} = C({2*n},{n})")

# 上指标反转验证: C(-3, k) = (-1)^k * C(k+2, k)
for k in range(8):
    assert binom(-3, k) == ((-1) ** k) * comb(k + 2, k)
print("上指标反转验证通过")

```

`binom` 函数通过上指标反转支持负上指标。验证了 Pascal 递推、二项式定理 $\sum\binom{n}{k}=2^n$、范德蒙卷积、吸收律 $\sum k\binom{n}{k}=n\cdot 2^{n-1}$ 和 $\sum\binom{n}{k}^2=\binom{2n}{n}$。

## 常见误区

<Callout type="trap">
**现象 →** 认为 C(n,k) 只在 0≤k≤n 时有定义。
**原因 →** 只接触过组合计数的定义。
**修法 →** 广义二项式系数 C(r,k)=r^k_/k! 对任意实数 r 和非负整数 k 有定义。C(-3,2)=(-1)²C(4,2)=6。负上指标通过反转公式处理。
</Callout>

<Callout type="trap">
**现象 →** 求和 Σk·C(n,k) 时不会用吸收律。
**原因 →** 直接展开 k·C(n,k)=k·n!/(k!(n-k)!) 试图化简。
**修法 →** 用吸收律 k·C(n,k)=n·C(n-1,k-1) 把 k 吸进系数内部，求和变为 n·ΣC(n-1,k-1)=n·2^{n-1}。吸收律是处理含 k 的二项式求和的标准工具。
</Callout>

<Exercises>
**问题**：用吸收律求 Σ_{k=0}^{n} k·C(n,k)。

<Answer>
由吸收律 k·C(n,k)=n·C(n-1,k-1)，故 Σk·C(n,k)=n·Σ_{k=1}^{n}C(n-1,k-1)=n·Σ_{j=0}^{n-1}C(n-1,j)=n·2^{n-1}。
</Answer>

**问题**：证明范德蒙恒等式 Σ_k C(r,k)C(s,n-k)=C(r+s,n)。

<Answer>
用生成函数：(1+z)^r·(1+z)^s=(1+z)^{r+s}。左端展开系数为 Σ_k C(r,k)C(s,n-k)，右端系数为 C(r+s,n)。两端相等故系数相等。这是生成函数视角的典型应用。
</Answer>
</Exercises>
