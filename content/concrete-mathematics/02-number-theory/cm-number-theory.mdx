## 直觉引入

数论在 Concrete Mathematics 中的定位是「组合数学的工具箱」。整除性、素数和同余不仅是数论的基础，更是求解递归和生成函数问题时的常用工具。

Euclid 算法 $\gcd(a,b)=\gcd(a \bmod b, b)$ 是算法复杂度分析的鼻祖——它的步数是 $O(\log n)$，这是由 Fibonacci 数列的最坏情况导出的。而 Euler φ 函数的求和公式 $\sum_{d|n}\varphi(d)=n$ 揭示了整数的深层结构。

## 概念讲解

<Term def="a 和 b 的最大公约数">GCD</Term>用 Euclid 算法计算：$\gcd(a,b)=\gcd(a\bmod b, b)$，基础情况 $\gcd(a,0)=a$。<Term def="存在整数 x,y 使 ax+by=gcd(a,b)">Bezout 恒等式</Term>保证 GCD 可以表示为线性组合。

<Term def="小于 n 且与 n 互素的正整数个数">Euler φ 函数</Term>满足 $\varphi(n)=n\prod_{p|n}(1-1/p)$，是<Term def="gcd(m,n)=1 时 f(mn)=f(m)f(n)">积性函数</Term>。关键恒等式：$\sum_{d|n}\varphi(d)=n$。

<Term def="同余方程组的求解定理">中国剩余定理</Term>（CRT）：若 $m_1,\ldots,m_r$ 两两互素，则 $x\equiv a_i\pmod{m_i}$ 有唯一解 $\pmod{M}$（$M=\prod m_i$）。

### Fermat 小定理与 Wilson 定理
- **Fermat 小定理**：$p$ 为素数时 $a^p \equiv a \pmod{p}$，等价于 $a^{p-1} \equiv 1 \pmod{p}$（$\gcd(a,p)=1$ 时）。
- **Wilson 定理**：$(p-1)! \equiv -1 \pmod{p}$，这是 $p$ 为素数的充要条件。

### GCD 的复杂度
Euclid 算法的最坏情况发生在 Fibonacci 数：$\gcd(F_{n+1}, F_n)$ 需要 $n$ 步。因 $F_n \approx \phi^n/\sqrt{5}$，步数为 $O(\log a)$。

### CRT 的构造性证明
给定 $x \equiv a_i \pmod{m_i}$，令 $M_i = M/m_i$，$M_i^{-1}$ 为 $M_i$ 模 $m_i$ 的逆。则解为 $x = \sum a_i M_i M_i^{-1} \pmod{M}$。

### 互素与独立剩余
若 $\gcd(m_1, m_2)=1$，则 $x \bmod m_1$ 和 $x \bmod m_2$ 独立——这就是 CRT 的本质：大模数可以分解为小模数的组合。

## 代码对照

用 Python 实现 Euclid 算法、Euler φ 函数与 CRT：

```python
from math import gcd
from functools import reduce

def extended_gcd(a, b):
    """扩展 Euclid：返回 (g, x, y) 使 ax+by=g"""
    if b == 0:
        return a, 1, 0
    g, x, y = extended_gcd(b, a % b)
    return g, y, x - (a // b) * y

def euler_phi(n):
    """φ(n) = n·∏(1-1/p)"""
    result = n
    p = 2
    temp = n
    while p * p <= temp:
        if temp % p == 0:
            while temp % p == 0:
                temp //= p
            result -= result // p
        p += 1
    if temp > 1:
        result -= result // temp
    return result

def crt(remainders, moduli):
    """中国剩余定理：解 x≡a_i mod m_i"""
    M = reduce(lambda a, b: a * b, moduli)
    x = 0
    for a_i, m_i in zip(remainders, moduli):
        M_i = M // m_i
        _, inv, _ = extended_gcd(M_i % m_i, m_i)
        x += a_i * M_i * inv
    return x % M

# 验证
print(f"gcd(48, 18) = {gcd(48, 18)}")           # 6
g, x, y = extended_gcd(48, 18)
print(f"Bezout: 48*{x}+18*{y}={48*x+18*y}")    # 48*(-1)+18*3=6

print(f"φ(12) = {euler_phi(12)}")                 # 4 (1,5,7,11)
print(f"φ(100) = {euler_phi(100)}")               # 40

# 验证 Σ_{d|n} φ(d) = n
n = 12
total = sum(euler_phi(d) for d in range(1, n + 1) if n % d == 0)
print(f"Σφ(d) for d|{n} = {total} (should be {n})")  # 12

# CRT: x≡2 mod 3, x≡3 mod 5, x≡2 mod 7
x = crt([2, 3, 2], [3, 5, 7])
print(f"CRT(2,3,5,3,2,7) = {x}")                  # 23
assert x % 3 == 2 and x % 5 == 3 and x % 7 == 2

# Fermat 小定理验证
p = 7
for a in range(1, p):
    assert pow(a, p - 1, p) == 1, f"Fermat fail at {a}"
print(f"Fermat 小定理验证通过 (p={p})")

```

`extended_gcd` 同时返回 Bezout 系数。`euler_phi` 用素因数分解计算 $\varphi(n)$。CRT 的关键是求模逆元——这里用扩展 Euclid 实现。验证 $\sum_{d|12}\varphi(d)=12$ 确认了 Euler 的求和公式。

## 常见误区

<Callout type="trap">
**现象 →** 忽略 gcd(m,n)=1 是积性函数的前提。
**原因 →** 以为积性函数对任意 m,n 都有 f(mn)=f(m)f(n)。
**修法 →** 积性函数要求 gcd(m,n)=1。如 φ(4·9)=φ(36)=12，φ(4)·φ(9)=2·6=12 成立（因 gcd(4,9)=1），但 φ(4·4)=φ(16)=8 ≠ φ(4)·φ(4)=4。
</Callout>

<Callout type="trap">
**现象 →** CRT 中忘记模数两两互素的条件。
**原因 →** 直接套 CRT 公式不检查前提。
**修法 →** CRT 要求 m_i 两两互素。若不互素，需先用 GCD 合并同余式。例如 x≡1 mod 4 和 x≡3 mod 6 不直接可解（gcd(4,6)=2），需检查 1≡3 mod 2 是否成立。
</Callout>

</Answer>

**问题**：证明 Σ_{d|n} φ(d) = n。

<Answer>
考虑分数 1/n, 2/n, ..., n/n。约分后分母为 d（d|n）的分数恰有 φ(d) 个（分子与 d 互素）。所以 Σ_{d|n}φ(d) = 总分数数 = n。这是一个优雅的双射论证。
</Answer>
