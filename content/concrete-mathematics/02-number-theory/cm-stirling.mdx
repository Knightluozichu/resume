## 直觉引入

Stirling 数是连接普通幂 $x^n$ 与阶乘幂（下降幂 $x^{\underline{n}}$）的桥梁。下降幂是组合数学的「自然语言」——它让求和变得像微积分一样简单。

下降幂 $x^{\underline{n}}=x(x-1)\cdots(x-n+1)$ 对应的「离散微积分」有完美的求和公式 $\sum_{0 \leq k < n} k^{\underline{m}} = \frac{n^{\underline{m+1}}}{m+1}$，类比 $\int x^m dx = \frac{x^{m+1}}{m+1}$。而 Stirling 数就是在普通幂和下降幂之间转换的「汇率」。

## 概念讲解

<Term def="把 n 元素分成 k 个非空无标号子集的方案数">第二类 Stirling 数</Term> $S(n,k)$ 递推：$S(n,k)=S(n-1,k-1)+k\cdot S(n-1,k)$（新元素单独成组或加入已有 $k$ 组之一）。

<Term def="把 n 元素排成 k 个轮换的方案数">第一类 Stirling 数</Term> $s(n,k)$ 递推：$s(n,k)=s(n-1,k-1)+(n-1)\cdot s(n-1,k)$（新元素单独成轮换或插入已有 $n-1$ 个位置的间隙）。

<Term def="x(x-1)...(x-n+1)">下降幂</Term> $x^{\underline{n}}$ 满足 $\Delta x^{\underline{n}} = n\cdot x^{\underline{n-1}}$（差分类比微分）。

### 互逆转换公式
普通幂 → 下降幂（用第一类 Stirling 数）：
$$x^n = \sum_{k=0}^{n} S(n,k)\, x^{\underline{k}}$$
下降幂 → 普通幂（用第一类 Stirling 数）：
$$x^{\underline{n}} = \sum_{k=0}^{n} s(n,k)\, x^k$$

两类 Stirling 矩阵 $[S(n,k)]$ 和 $[s(n,k)]$ 互为逆矩阵。

### Bell 数
$$B_n = \sum_{k=0}^{n} S(n,k)$$
Bell 数 $B_n$ 是 $n$ 个元素的任意划分总数。$B_0=1, B_1=1, B_2=2, B_3=5, B_4=15$。

### 离散微积分
差分 $\Delta f(x) = f(x+1) - f(x)$。对下降幂：$\Delta x^{\underline{n}} = n\cdot x^{\underline{n-1}}$。对应的「不定求和」：
$$\sum_{k=0}^{n-1} k^{\underline{m}} = \frac{n^{\underline{m+1}}}{m+1}$$
这是 $\int x^m dx = \frac{x^{m+1}}{m+1}$ 的离散类比。

### 阶乘幂求和
用 Stirling 数把 $k^m$ 展开为下降幂之和，再用离散微积分逐项求和：
$$\sum_{k=0}^{n} k^m = \sum_{j=0}^{m} S(m,j) \frac{(n+1)^{\underline{j+1}}}{j+1}$$

## 代码对照

用 Python 计算 Stirling 数并验证互逆关系：

```python
def stirling2(n, k):
    """第二类 Stirling 数 S(n,k)"""
    if n == 0 and k == 0:
        return 1
    if n == 0 or k == 0:
        return 0
    return stirling2(n - 1, k - 1) + k * stirling2(n - 1, k)

def stirling1(n, k):
    """第一类 Stirling 数 s(n,k)（带符号）"""
    if n == 0 and k == 0:
        return 1
    if n == 0 or k == 0:
        return 0
    return stirling1(n - 1, k - 1) + (n - 1) * stirling1(n - 1, k)

def bell(n):
    """Bell 数 B_n = ΣS(n,k)"""
    return sum(stirling2(n, k) for k in range(n + 1))

def falling_factorial(x, n):
    """下降幂 x^n_ = x(x-1)...(x-n+1)"""
    result = 1
    for i in range(n):
        result *= (x - i)
    return result

# 验证递推
for n in range(1, 8):
    for k in range(1, n + 1):
        assert stirling2(n, k) == stirling2(n-1, k-1) + k * stirling2(n-1, k)
        assert stirling1(n, k) == stirling1(n-1, k-1) + (n-1) * stirling1(n-1, k)

print("Stirling 数表 S(n,k):")
for n in range(6):
    print(f"  n={n}: {[stirling2(n, k) for k in range(n + 1)]}")
# n=4: [0, 1, 7, 6, 1] → B_4=15

print(f"Bell 数: {[bell(n) for n in range(8)]}")
# [1, 1, 2, 5, 15, 52, 203, 877]

# 验证互逆: x^n = ΣS(n,k)·x^k_  和  x^n_ = Σs(n,k)·x^k
n = 5
for x in range(10):
    # x^n = Σ S(n,k) * x^k_
    lhs1 = x ** n
    rhs1 = sum(stirling2(n, k) * falling_factorial(x, k) for k in range(n + 1))
    assert lhs1 == rhs1, f"x^n=ΣS·x^k_ fail at x={x}"
    # x^n_ = Σ s(n,k) * x^k
    lhs2 = falling_factorial(x, n)
    rhs2 = sum(stirling1(n, k) * x ** k for k in range(n + 1))
    assert lhs2 == rhs2, f"x^n_=Σs·x^k fail at x={x}"

print("互逆关系验证通过")

# 离散微积分: Σk^m_ = (n+1)^{m+1}_/(m+1)
for m in range(1, 5):
    for n in range(10):
        lhs = sum(falling_factorial(k, m) for k in range(n + 1))
        rhs = falling_factorial(n + 1, m + 1) // (m + 1)
        assert lhs == rhs, f"离散微积分 fail at m={m}, n={n}"
print("离散微积分验证通过")

```

Stirling 数的递推直接对应组合意义。验证了 $x^n=\sum S(n,k)x^{\underline{k}}$ 和 $x^{\underline{n}}=\sum s(n,k)x^k$ 的互逆关系。离散微积分 $\sum k^{\underline{m}}=\frac{(n+1)^{\underline{m+1}}}{m+1}$ 是下降幂的求和基本定理。

## 常见误区

<Callout type="trap">
**现象 →** 混淆两类 Stirling 数的组合意义。
**原因 →** 两类数递推相似但含义不同。
**修法 →** 第二类 S(n,k) 是「划分」（子集无序），第一类 s(n,k) 是「排列」（轮换有内部顺序）。递推系数也不同：S 用 k（加入 k 组之一），s 用 n-1（插入 n-1 个间隙）。
</Callout>

<Callout type="trap">
**现象 →** 不会用下降幂简化求和。
**原因 →** 习惯用普通幂，不知道下降幂的离散微积分。
**修法 →** 把 k^m 用 Stirling 数展开为下降幂之和 ΣS(m,j)k^j_，再用 Σk^j_=(n+1)^&#123;j+1&#125;_/(j+1) 逐项求和。这是 Concrete Mathematics 的标志性技巧。
</Callout>
