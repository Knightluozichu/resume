## 直觉引入

离散概率是 Concrete Mathematics 的收尾章——它把生成函数直接应用到概率论中。PGF（概率生成函数）$G_X(z)=\sum P(X=k)z^k$ 的导数直接给出矩：$E[X]=G'_X(1)$。

PGF 是连接组合数学与概率论的桥梁。独立随机变量之和的 PGF 是各自 PGF 的乘积——这与生成函数的卷积对应完全一致。用 PGF 分析散列函数的探查次数、生日问题的碰撞期望，都能得到优雅的闭式。

## 概念讲解

<Term def="随机变量的加权平均">期望</Term> $E[X]=\sum x\cdot P(X=x)$。<Term def="衡量随机变量偏离期望的程度">方差</Term> $V[X]=E[X^2]-E[X]^2$。线性性质：$E[aX+b]=aE[X]+b$；独立时 $V[X+Y]=V[X]+V[Y]$。

<Term def="G_X(z)=ΣP(X=k)z^k 编码分布的生成函数">概率生成函数</Term>（PGF）的核心性质：
- $E[X]=G'_X(1)$（一阶导在 1 处给期望）
- $V[X]=G''_X(1)+G'_X(1)-G'_X(1)^2$
- 独立和：$G_{X+Y}(z)=G_X(z)\cdot G_Y(z)$

### 生日问题
$n$ 人中至少两人同生日的期望人数：碰撞期望约为 $\sqrt{\pi n/2}$。具体地，首次碰撞的期望步数为 $1+\sum_{k=1}^{n}\frac{n!}{(n-k)!\cdot n^k}\approx\sqrt{\pi n/2}$。

### 散列分析
开地址散列中，装载因子 $\alpha=n/m$（$n$ 键，$m$ 槽）时：
- 成功查找的期望探查数：$\frac{1}{\alpha}\ln\frac{1}{1-\alpha}$
- 不成功查找的期望探查数：$\frac{1}{1-\alpha}$

### 随机排列的逆序数
排列 $\pi$ 的逆序数为 $I(\pi)=\sum_{i<j}[\pi_i>\pi_j]$。期望 $E[I]=\binom{n}{2}/2=\frac{n(n-1)}{4}$（每对 $(i,j)$ 有 $1/2$ 概率成为逆序）。方差 $V[I]=\frac{n(n-1)(2n+5)}{72}$。

### PGF 求矩实例
硬币抛 $n$ 次，正面次数 $X\sim\text{Bin}(n,p)$。PGF：$G_X(z)=(q+pz)^n$（$q=1-p$）。
- $E[X]=G'(1)=np$
- $V[X]=G''(1)+G'(1)-G'(1)^2=np(1-p)=npq$

## 代码对照

用 Python 验证 PGF 求矩与散列分析：

```python
from math import factorial, comb, log
import random

def binomial_pgf(n, p):
    """二项分布的 PGF: G(z)=(q+pz)^n"""
    q = 1 - p
    return lambda z: (q + p * z) ** n

def pgf_mean(gf, h=1e-5):
    """用数值微分求 E[X]=G'(1)"""
    return (gf(1 + h) - gf(1 - h)) / (2 * h)

def pgf_variance(gf, h=1e-5):
    """V[X]=G''(1)+G'(1)-G'(1)²"""
    g1 = (gf(1 + h) - gf(1 - h)) / (2 * h)
    g2 = (gf(1 + h) - 2 * gf(1) + gf(1 - h)) / (h ** 2)
    return g2 + g1 - g1 ** 2

# 二项分布验证
n, p = 10, 0.3
gf = binomial_pgf(n, p)
print(f"Bin({n},{p}): E[X]={pgf_mean(gf):.4f} (exact={n*p})")
print(f"Bin({n},{p}): V[X]={pgf_variance(gf):.4f} (exact={n*p*(1-p):.4f})")

# 散列分析
def hash_probes_unsuccessful(alpha):
    """不成功查找期望探查数 = 1/(1-α)"""
    return 1 / (1 - alpha)

def hash_probes_successful(alpha):
    """成功查找期望探查数 = (1/α)·ln(1/(1-α))"""
    return log(1 / (1 - alpha)) / alpha

for alpha in [0.25, 0.5, 0.75, 0.9]:
    print(f"α={alpha}: 不成功={hash_probes_unsuccessful(alpha):.2f}, 成功={hash_probes_successful(alpha):.2f}")
# α=0.5: 不成功=2.00, 成功=1.39

# 生日问题模拟
def birthday_collision(n, trials=10000):
    """模拟 n 人的生日碰撞期望"""
    total = 0
    for _ in range(trials):
        seen = set()
        for k in range(1, n + 1):
            b = random.randint(1, 365)
            if b in seen:
                total += k
                break
            seen.add(b)
        else:
            total += n
    return total / trials

print(f"生日碰撞期望(365): {birthday_collision(365):.2f} (理论≈{3.14*365/2**0.5:.2f})")

# 逆序数期望验证
def count_inversions(arr):
    count = 0
    for i in range(len(arr)):
        for j in range(i + 1, len(arr)):
            if arr[i] > arr[j]:
                count += 1
    return count

random.seed(42)
for n in [5, 10, 20]:
    trials = 10000
    total = sum(count_inversions(random.sample(range(n), n)) for _ in range(trials))
    avg = total / trials
    expected = n * (n - 1) / 4
    print(f"n={n}: 逆序数期望={avg:.2f} (理论={expected:.2f})")

```

PGF 的数值微分验证了二项分布 $E[X]=np$，$V[X]=npq$。散列分析中 $\alpha=0.5$ 时不成功查找期望 2 次探查。生日碰撞期望约 $\sqrt{\pi n/2}\approx 23.9$（365 天）。逆序数期望 $n(n-1)/4$ 验证通过。

## 常见误区

<Callout type="trap">
**现象 →** 计算 V[X] 时忘记减去 E[X]²。
**原因 →** 混淆 E[X²] 和 V[X]。
**修法 →** V[X]=E[X²]-E[X]²，不是 E[X²]。用 PGF 时 V[X]=G''(1)+G'(1)-G'(1)²，注意最后一项是平方。
</Callout>

<Callout type="trap">
**现象 →** 分析散列时忽略装载因子的影响。
**原因 →** 以为散列总是 O(1)。
**修法 →** 散列的期望探查数依赖装载因子 α。不成功查找期望 1/(1-α)，α→1 时趋于无穷。保持 α&lt;0.75 是工程惯例。
</Callout>

<Exercises>
**问题**：用 PGF 求二项分布 Bin(n,p) 的期望和方差。

<Answer>
G(z)=(q+pz)^n。G'(z)=np(q+pz)^&#123;n-1&#125;，E[X]=G'(1)=np。G''(z)=n(n-1)p²(q+pz)^&#123;n-2&#125;，G''(1)=n(n-1)p²。V[X]=G''(1)+G'(1)-G'(1)²=n(n-1)p²+np-n²p²=np-np²=npq。
</Answer>

**问题**：散列表装载因子 α=0.5 时，成功和不成功查找的期望探查数各是多少？

<Answer>
不成功：1/(1-0.5)=2。成功：(1/0.5)·ln(1/(1-0.5))=2·ln2≈1.39。不成功查找需要探查到第一个空槽，成功查找则在找到目标时停止。
</Answer>
</Exercises>
