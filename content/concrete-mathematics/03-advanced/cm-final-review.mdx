## 直觉引入

综合复习把全书工具串联成一条完整的解题链：递归建模 → 求和化简 → 数论工具 → 生成函数求解 → 概率分析。每一步都不是孤立的，而是层层递进的工具栈。

全书最重要的方法论是「先猜后证」加「成套方法」：先用小例子猜闭式，再用归纳法验证；遇到参数化递归用成套方法反求系数。而生成函数是终极武器——当其他方法都失效时，把序列编码成幂级数总能找到出路。

## 概念讲解

全书工具链：
- <Term def="把问题拆成同类型小问题">递归</Term> → 建立问题的递推关系
- <Term def="对递归展开式求闭式">求和</Term> → 用扰动法、求和法则化简
- <Term def="研究整数性质">数论</Term> → 取整函数、GCD、CRT 作为工具
- <Term def="序列编码为幂级数">生成函数</Term> → 把递归变方程，方程变闭式
- <Term def="PGF 分析随机变量">离散概率</Term> → 用 PGF 求矩与分析散列

### 工具选择决策树
1. 问题有递归结构？→ 先列递推关系
2. 递归能直接展开？→ 用扰动法或求和法则
3. 求和中含取整/mod？→ 用整函数性质化简
4. 递归带参数或难直接求？→ 构造生成函数列方程
5. 涉及随机性？→ 用 PGF 分析期望和方差

### 经典综合题
**约瑟夫问题的完整解法**：递归 $J(2n)=2J(n)-1, J(2n+1)=2J(n)+1$ → 成套方法设 $J(n)=A(n)\alpha+B(n)\beta+C(n)\gamma$ → 用特例解出 $A=2^m, B=2^m-1-l, C=l$（$n=2^m+l$）→ 闭式 $J(n)=2l+1$。

**Catalan 数的多角度推导**：递归 $C_{n+1}=\sum C_kC_{n-k}$ → 生成函数 $C(z)=1+zC(z)^2$ → 解二次方程 $C(z)=\frac{1-\sqrt{1-4z}}{2z}$ → 展开系数 $C_n=\frac{1}{n+1}\binom{2n}{n}$。

**散列分析的完整链条**：概率模型 → PGF $(q+pz)^n$ → 求导取矩 → 期望探查数 $\frac{1}{1-\alpha}$。

## 代码对照

用 Python 综合验证全书的经典结果：

```python
from math import comb, log, sqrt

# 1. 递归：Josephus
def josephus(n):
    m = n.bit_length() - 1
    return 2 * (n - (1 << m)) + 1

# 2. 求和：Σk·2^k = (n-1)·2^{n+1}+2
def sum_k2k(n):
    return (n - 1) * (1 << (n + 1)) + 2

# 3. 数论：Euler φ
def euler_phi(n):
    result, temp = n, n
    p = 2
    while p * p <= temp:
        if temp % p == 0:
            while temp % p == 0:
                temp //= p
            result -= result // p
        p += 1
    if temp > 1:
        result -= result // temp
    return result

# 4. 生成函数：Catalan
def catalan(n):
    return comb(2 * n, n) // (n + 1)

# 5. 概率：散列期望探查
def hash_unsuccessful(alpha):
    return 1 / (1 - alpha)

# 综合验证
print("=== 全书经典结果验证 ===")
print(f"1. Josephus(41) = {josephus(41)}")      # 19
print(f"2. Σk·2^k(8) = {sum_k2k(8)}")            # 2302
print(f"3. φ(100) = {euler_phi(100)}")           # 40
print(f"4. Catalan(10) = {catalan(10)}")          # 16796
print(f"5. Hash(α=0.5) = {hash_unsuccessful(0.5):.2f}")  # 2.00

# 综合题：Catalan 数的多角度验证
# 递归 → 生成函数 → 闭式
def catalan_rec(n):
    if n == 0:
        return 1
    return sum(catalan_rec(k) * catalan_rec(n - 1 - k) for k in range(n))

for n in range(12):
    assert catalan(n) == catalan_rec(n), f"Catalan fail at {n}"
print(f"Catalan(8) = {catalan(8)} (递归验证通过)")

# 综合题：Stirling 数 + 离散微积分求 Σk³
def stirling2(n, k):
    if n == 0 and k == 0:
        return 1
    if n == 0 or k == 0:
        return 0
    return stirling2(n - 1, k - 1) + k * stirling2(n - 1, k)

def falling(x, n):
    r = 1
    for i in range(n):
        r *= (x - i)
    return r

# k³ = S(3,1)k_ + S(3,2)k²_ + S(3,3)k³_ = k_ + 3k²_ + k³_
n = 10
s = sum(k**3 for k in range(n + 1))
s_formula = sum(
    stirling2(3, j) * falling(n + 1, j + 1) // (j + 1)
    for j in range(4)
)
assert s == s_formula, f"Σk³ fail: {s} != {s_formula}"
print(f"Σk³({n}) = {s} = {s_formula} (Stirling+离散微积分验证)")

```

综合验证了全书五大工具链：Josephus 递归、Σk·2^k 求和、Euler φ 数论、Catalan 生成函数、散列概率分析。Catalan 数的递归与闭式一致，Σk³ 用 Stirling 数展开下降幂后离散微积分求和验证通过。

## 常见误区

<Callout type="trap">
**现象 →** 遇到组合问题不知道该用哪个工具。
**原因 →** 没有建立工具选择决策树。
**修法 →** 先问：有递归结构？→ 递归+求和。有参数？→ 成套方法或生成函数。有取整/mod？→ 整函数。有随机性？→ PGF。先猜后证贯穿全程。
</Callout>

<Callout type="trap">
**现象 →** 生成函数列方程时不会处理基础项。
**原因 →** 忽略了 n=0 或 n=1 的边界贡献。
**修法 →** 列方程时先写出 G(z)=Σa_n z^n，递推乘 z^n 求和后，左端要减去基础项（如 G(z)-a_0-a_1 z），右端用移位法则对应。Fibonacci: G-z=zG+z²G，其中 -z 是 F_1 的贡献。
</Callout>

<Exercises>
**问题**：综合题：用全书工具链分析 Catalan 数 C_n。

<Answer>
递推：C_{n+1}=Σ_{k=0}^n C_k C_{n-k}（C_0=1），来自括号匹配的分解。生成函数：C(z)=1+zC(z)²。解二次方程：C(z)=(1-√(1-4z))/(2z)。展开系数：用广义二项式定理 √(1-4z)=Σ C(1/2,n)(-4z)^n，提取系数得 C_n=C(2n,n)/(n+1)。验证：C_3=5（五种括号匹配方式）。
</Answer>

**问题**：综合题：散列分析如何用 PGF 推导期望探查数？

<Answer>
设 X 为探查次数。不成功查找：每次探查命中已占槽的概率为 α，X 服从几何分布，PGF 为 G(z)=Σ(1-α)α^k z^k=(1-α)/(1-αz)。E[X]=G'(1)=1/(1-α)。成功查找更复杂，需对已插入键取条件期望，结果为 (1/α)ln(1/(1-α))。两者都依赖装载因子 α。
</Answer>
</Exercises>
