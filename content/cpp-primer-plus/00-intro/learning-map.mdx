## 为什么 C++ 要分三段学

C++ 是一门多范式语言，它同时支持过程式编程（C 的遗产）、面向对象编程（类与继承）、泛型编程（模板与 STL）。这三种范式解决不同层次的问题，对应不同的抽象方式。停留在任何一段，都只能用 C++ 的一部分能力。

过程式编程回答「代码怎么写」——变量、类型、控制流、函数，是组织计算的最基本手段。面向对象编程回答「程序怎么组织」——用类封装数据与行为，用继承复用接口，用多态扩展类型。泛型编程回答「抽象怎么复用」——用模板把类型参数化，用 STL 把容器与算法解耦，实现类型安全的跨类型复用。三段层层递进，每一层都建立在前一层的理解之上。

## 全书三段结构

<EppBookMap />

全书分三大板块，呈「语法怎么写 → 程序怎么组织 → 抽象怎么复用」的递进关系：

1. **C++ 基础语法**（4 章）：讲清变量声明、类型系统、`if`/`for`/`while` 控制流、函数定义。这是过程式编程的基础，回答「C++ 代码怎么写才能跑」。
2. **类与继承**（3 章）：用类封装数据与行为，用构造函数管理对象生命周期，用继承与虚函数实现多态。这是面向对象的核心，回答「数据与行为怎么组织成可维护的结构」。
3. **模板与 STL**（3 章）：用模板实现类型安全的泛型复用，用 STL 容器、算法、迭代器三件套解耦数据存储与处理。这是泛型编程的精华，回答「如何不重复地复用代码」。

三段之间是严格的依赖关系：不懂基础语法就写不出类，不懂类就理解不了模板的实例化语义。跳层学习容易陷入「背了语法却组织不出程序」或「会用 STL 却不懂其模板实现」的困境。

## 学习路径与前置依赖

建议严格按章节顺序学习。类与继承段是全书的枢纽——它把过程式的函数升级为成员函数，把全局数据封装成对象状态，是承上启下的关键。模板与 STL 段的每一项概念（模板实例化、迭代器类别、容器选择）都建立在对类与对象的理解之上。

## 常见误区

<Callout type="trap"><strong>现象 →</strong> 学了基础语法就直接跳去用 STL，遇到模板报错看不懂，也写不出自己的类。<strong>原因 →</strong> 跳过了类与继承段，没有面向对象的基础，无法理解 STL 容器是类、迭代器是类模板的实例、算法通过模板作用于容器。<strong>修法 →</strong> 回到类与继承段补齐封装、构造、继承、多态，再学模板与 STL，才能既会用也懂原理。</Callout>

## 小结与练习

全书主线一句话：从语法到对象到泛型，三段递进覆盖 C++ 全貌。先掌握基本语法与控制流，再用类与继承组织数据行为，最后用模板与 STL 实现类型安全的泛型复用。
