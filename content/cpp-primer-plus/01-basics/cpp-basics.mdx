## 最简程序解剖

理解 C++ 从一段最简程序开始。下面这五行代码构成一个可运行程序的骨架，每一行都有明确职责。

<EppCppBasicsDiagram />

**预处理指令** `#include <iostream>` 以 `#` 开头，由预处理器在编译前处理。它把 `iostream` 头文件的内容原样插入源码，让程序能用 `cin`/`cout` 做输入输出。`<iostream>` 用尖括号表示在系统目录查找，自定义头文件用双引号。

**命名空间声明** `using namespace std;` 把标准库的 `std` 命名空间引入当前作用域，省得每次写 `std::cout`。命名空间解决大型项目的名称冲突问题——不同库可能定义同名类，命名空间把它们隔离。

**程序入口** `int main()` 是程序起点，操作系统调用它。返回类型 `int` 是状态码，0 表示正常结束，非 0 表示异常。

**标准输出** `cout << "Hello";` 用插入运算符 `<<` 把文本送到标准输出（屏幕）。`<<` 设计成可链式：`cout << a << b` 依次输出 a 和 b。

**返回语句** `return 0;` 把状态码交还操作系统，标志程序结束。

## 输入输出与命名空间

`iostream` 提供两个核心对象：`cout` 做输出、`cin` 做输入。输入用提取运算符 `>>`：`cin >> x;` 从标准输入读一个值存进 x。输出用插入运算符 `<<`：`cout << x;` 把 x 送到屏幕。两者都自动根据变量类型做格式转换，比 C 的 `printf`/`scanf` 更类型安全。

<Term def="把库的名称隔离在不同作用域，避免同名冲突的机制">命名空间</Term>

命名空间的引入是为了避免名称冲突。标准库所有内容都在 `std` 命名空间里，使用时要么写 `std::cout` 显式限定，要么用 `using namespace std;` 整体引入。后者虽方便，但会把 std 里所有名称一股脑引入，可能与自定义名冲突，大型项目里应谨慎使用。

## 常见误区

<Callout type="trap"><strong>现象 →</strong> 程序能编译运行，但控制台一闪而过看不到输出。<strong>原因 →</strong> 程序正常结束太快，输出缓冲未刷新或窗口直接关闭。<strong>修法 →</strong> 在 `return` 前加 `cin.get();` 等待输入，或用 `endl` 刷新缓冲；调试期用 `cout << x << endl;` 确保输出可见。</Callout>

## 小结与练习

一段最简 C++ 程序由五要素构成：`#include` 预处理引入库、`using namespace` 简化命名、`main` 作程序入口、`cout`/`cin` 做 I/O、`return` 交还控制权。理解这五行就掌握了 C++ 程序的骨架。
