## 内置类型族谱

C++ 的内置类型分四大族：整型、浮点、字符、布尔。它们是变量声明的全部素材，决定了数据如何在内存中表示与运算。

<EppDataTypesDiagram />

**整型**族包括 `short`、`int`、`long`、`long long`，每种还分 `signed`/`unsigned`。标准只规定下限和大小关系：`short` 至少 16 位，`int` 不小于 `short`，`long` 至少 32 位，`long long` 至少 64 位。具体位数由实现决定，要精确宽度用 `cstdint` 的 `int32_t`、`int64_t`。

**浮点**族包括 `float`（通常 32 位）、`double`（通常 64 位）、`long double`（80 或 128 位），分别对应单精度、双精度、扩展精度。

**字符**族包括 `char`（至少 8 位）、`wchar_t`（宽字符）、`char16_t`、`char32_t`（C++11 Unicode 字符）。

**布尔**型 `bool` 取值 `true`/`false`，用于逻辑运算。

## 变量声明与初始化

变量声明告诉编译器「有一个叫这个名字、这种类型的存储」。C++ 提供多种初始化方式：等号初始化 `int x = 0;`、构造初始化 `int x(0);`、列表初始化 `int x{0};`（C++11）。

<Term def="用花括号 {} 初始化变量，禁止窄化转换，是 C++11 引入的安全初始化方式">列表初始化</Term>

列表初始化的独特价值在于禁止窄化转换。`int x = 3.14;` 会隐式截断成 3 只给警告，而 `int x{3.14};` 直接编译报错，阻止精度丢失。在涉及浮点转整型、长整型转短整型时，列表初始化让编译器帮你挡住隐患。新代码优先用 `{}` 初始化基本类型。

## const 与 constexpr

`const` 表示运行期只读：值可以在运行时确定（如从文件读入），一旦初始化不可再赋值。它是「不可变」的承诺，不保证编译期已知。

`constexpr` 表示编译期常量：值必须在编译时就能算出来，因此可用于数组长度、模板参数、case 标签等需要编译期常量的场合。`constexpr` 比 `const` 更强——`constexpr` 一定是 `const`，但 `const` 不一定是 `constexpr`。

推荐：能用 `constexpr` 就用，它把求值提前到编译期，既可能优化性能，又能在编译期做类型检查。只有值确实运行期才能确定时才退回 `const`。

## 常见误区

<Callout type="trap"><strong>现象 →</strong> 声明 `int x = 3.14;` 编译通过但值变成 3，而 `int x{3.14};` 却编译报错。<strong>原因 →</strong> 等号初始化允许隐式窄化转换（double 截断成 int），列表初始化禁止窄化直接报错。<strong>修法 →</strong> 优先用列表初始化 `{}`，让编译器在窄化时编译期报错，避免精度悄悄丢失。</Callout>

## 小结与练习

C++ 内置类型分整型、浮点、字符、布尔四族，宽度由实现约定但保证大小关系。`const` 表示运行期只读，`constexpr` 表示编译期常量——后者更强。列表初始化 `{}` 禁止窄化转换，是安全的首选初始化方式。
