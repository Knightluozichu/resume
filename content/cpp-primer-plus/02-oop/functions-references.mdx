## 函数四特性

函数是「参数到返回值」的封装单元，是代码复用的基本手段。C++ 函数有四个关键特性，构成函数复用的全部手段。

<EppFunctionsRefDiagram />

**函数定义**由返回类型、函数名、形参列表、函数体四部分组成。`return` 语句把结果交回调用者。返回类型为 `void` 表示无返回值。形参列表可为空。

**引用参数**是 C++ 区别于 C 的重要特性。按值参数 `void f(int x)` 把实参拷贝到形参，函数内修改不影响实参；引用参数 `void f(int& x)` 让形参成为实参的别名，修改形参即改实参，且无拷贝开销。引用参数两大用途：避免大对象拷贝（用 `const T&`）、需要修改实参或输出多个值。

**默认参数**让调用时可省略部分实参。规则是从右往左连续给默认值，调用时省略只能发生在末尾。`void f(int a, int b = 1)` 调用 `f(0)` 等价 `f(0, 1)`。

**函数重载**允许同名函数只要参数（类型/个数）不同。编译器按实参类型做重载决议，选最佳匹配。这让同一操作对多种类型复用名字，比 C 的 `print_int`/`print_double` 命名更优雅。

## 引用与传参约定

<Term def="变量的别名，操作引用即操作原对象，无拷贝开销，是 C++ 区别于 C 的核心概念">引用</Term>

引用参数是大对象传参的首选。传类对象、容器时，按值会触发拷贝构造，开销大且可能有副作用；用 `const T&` 只读引用既避免拷贝又防误改。基本类型（`int`/`double`）拷贝便宜，按值即可。

引用还支持链式调用：`cout << a << b` 之所以能工作，是因为 `operator<<` 返回流的引用，让第二个 `<<` 接着第一个的输出继续。这一机制后续会扩展到运算符重载与 `this` 指针。

## 默认参数与重载的协作

默认参数与函数重载组合时要小心二义性。若同时有 `void f(int)` 和 `void f(int, int = 0)`，调用 `f(3)` 时两者都精确匹配，编译器无法决定选哪个，报二义性错误。规则是：避免让单参重载与带默认参数的重载在调用点产生歧义。

## 常见误区

<Callout type="trap"><strong>现象 →</strong> 写了 `void f(int)` 和 `void f(double)` 两个重载，调用 `f(3)` 正常，但加了 `f(int, int=0)` 后 `f(3)` 编译报二义性。<strong>原因 →</strong> `f(3)` 既能匹配 `f(int)` 也能匹配 `f(int,int=0)`（省略默认参数后也是 int 精确匹配），两者都是最佳匹配，编译器无法决定。<strong>修法 →</strong> 去掉单参重载或去掉默认参数，或调用时显式写两个参数 `f(3, 0)`。</Callout>

## 小结与练习

C++ 函数有四个关键特性：定义结构（返回类型+形参+函数体）、引用参数（别名避免拷贝）、默认参数（右起连续赋值）、函数重载（同名按签名匹配）。引用参数是大对象传参的首选，重载让同一操作对多种类型复用名字，但与默认参数组合要防二义性。
