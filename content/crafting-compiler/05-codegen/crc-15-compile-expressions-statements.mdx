## 为什么从“IR到指令选择台”开始

第15章 编译表达式和语句沿“IR node → x86 DSL → labels/operands → assembly”转换信息。最终进程返回正确值只能证明一条执行路径；IR到指令选择台保存token、AST、绑定、类型、IR、汇编、符号、重定位或加载轨迹中的适用层，让错误停在第一处分叉。

第15章 编译表达式和语句固定C♭源码、cbc提交、JDK与JavaCC、GNU as/ld/binutils、IA-32目标、链接参数和运行环境，只改变IR类别或比较基线。本页交互只移动IR node → x86 DSL → labels/operands → assembly中的真实对象和状态，不生成置信、风险或证据分数。

## 来源、版本与独立重写边界

第15章 编译表达式和语句以青木峰郎维护的[日文原版完整详细目录](https://i.loveruby.net/ja/stdcompiler/toc.html)限定4部分、22章、86个编号小节、附录和116个正式层级；本站未取得原书正文授权，中文解释、代码、图示、实验和答案均为独立教学重写。

第15章 编译表达式和语句用[JavaCC完整语法文档](https://javacc.github.io/javacc/documentation/grammar.html)、[ELF规范](https://refspecs.linuxfoundation.org/elf/elf.pdf)、GNU [readelf](https://sourceware.org/binutils/docs/binutils/readelf.html)、[as](https://sourceware.org/binutils/docs/as/)与[ld](https://sourceware.org/binutils/docs/ld/)文档核对技术事实。原书主线是JavaCC、Linux/IA-32、GNU工具与ELF；现代JDK、x86-64、PIE和新版binutils默认值必须单独记录，不能改写原书时代坐标。
