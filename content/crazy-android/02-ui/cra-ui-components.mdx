## 直觉引入

UI布局像「房间装修」。LinearLayout是「沿墙一字排开」（水平或垂直排列，weight按比例分空间）；RelativeLayout是「以某物为参照摆放」（A在B左边、C在D下方）；TableLayout是「格子间」（TableRow分行，列可拉伸收缩）；FrameLayout是「桌上叠盘子」（层叠堆放，Fragment容器首选）；GridLayout是「棋盘格」（跨列跨行）。AdapterView是「传送带工厂」——屏幕外的item View回收复用，只重新绑定数据，不重新创建视图。

## 六大布局对比

```text
布局               布局方式              核心属性                    适用场景
──────────────────────────────────────────────────────────────────────────
LinearLayout      线性排列（水平/垂直）   orientation / weight       简单线性排列
RelativeLayout    相对定位              above/below/toLeftOf       灵活相对位置
TableLayout       行列表格              TableRow / stretchColumns   规整表单
FrameLayout       层叠堆放              gravity / layout_gravity   Fragment容器
GridLayout        网格排列              rowCount / columnCount      网格布局
AbsoluteLayout    绝对坐标（废弃）       x / y                      不推荐使用
```

## LinearLayout核心属性

```xml
<LinearLayout
    android:orientation="vertical"          <!-- horizontal / vertical -->
    android:layout_width="match_parent"
    android:layout_height="match_parent">
```

## AdapterView工作原理

```text
数据源（List/数组/Cursor）
        │
        ▼
  Adapter适配器              ← 桥接数据与视图
  │ getCount()               ← 告诉列表有多少条数据
  │ getView(position, convertView, parent)
  │   ① convertView == null → inflate新布局
  │   ② convertView != null → 复用已有布局
  │   ③ 绑定数据到控件
        │
        ▼
  AdapterView（ListView/GridView）  ← 只创建屏幕可见数量的View
```

<Callout type="insight">
**getView的convertView复用是列表性能关键**：ListView只创建屏幕可见数量+少量缓冲的item View。滑出屏幕的View进入回收池成为convertView，新进入的item复用convertView只重新绑定数据。这样无论数据量多大，View对象数量恒定，避免OOM和频繁GC。
</Callout>

## BaseAdapter + ViewHolder优化

```java
public class MyAdapter extends BaseAdapter {
    private List<String> data;
    private LayoutInflater inflater;

    // ViewHolder持有item内所有控件引用，避免重复findViewById
    static class ViewHolder {
        TextView title;
        ImageView icon;
    }

    @Override
    public View getView(int position, View convertView, ViewGroup parent) {
        ViewHolder holder;
        if (convertView == null) {
            convertView = inflater.inflate(R.layout.item, null);
            holder = new ViewHolder();
            holder.title = convertView.findViewById(R.id.title);
            holder.icon = convertView.findViewById(R.id.icon);
            convertView.setTag(holder);           // 绑定到convertView
        } else {
            holder = (ViewHolder) convertView.getTag();  // 复用
        }
        // 绑定数据
        holder.title.setText(data.get(position));
        return convertView;
    }
}
```

<Callout type="trap">
**性能误区**：不用ViewHolder → 每次getView都findViewById（遍历View树，耗时）→ 大列表滚动卡顿。正确做法：convertView复用 + ViewHolder缓存控件引用，两者缺一不可。
</Callout>

<Exercises>
**问题 1**：Android六大布局管理器各自的特点和适用场景是什么？

<Answer>
①LinearLayout——沿水平或垂直方向排列子View，orientation控制方向，weight按比例分配剩余空间。适合简单线性排列。②RelativeLayout——子View通过above/below/toLeftOf等属性相对定位。适合复杂相对位置界面。③TableLayout——以TableRow行为单位组织，支持collapseColumns/shrinkColumns/stretchColumns控制列。适合规整表单。④FrameLayout——子View层叠堆放左上角，layout_gravity定位。适合Fragment容器和层叠效果。⑤GridLayout——rowCount/columnCount定义网格，layout_columnSpan跨列。适合计算器等网格界面。⑥AbsoluteLayout——x/y绝对定位，已废弃不推荐（屏幕适配差）。
</Answer>

**问题 2**：AdapterView的工作原理是什么？Adapter在其中扮演什么角色？

<Answer>
AdapterView通过Adapter桥接数据源与列表项视图。流程：①数据源提供给Adapter。②AdapterView调用Adapter.getCount()获取数量。③对每个可见位置调用getView(position, convertView, parent)获取View。④getView负责inflate布局、findViewById获取控件、绑定数据。⑤滚动时滑出屏幕的View成为convertView被回收，新item复用convertView只重新绑定数据。Adapter类型：ArrayAdapter（数组+简单布局）、SimpleAdapter（List+Map+多列）、BaseAdapter（自定义最灵活）。核心：Adapter = 数据与视图的桥梁，convertView复用是性能关键。
</Answer>

**问题 3**：如何在ListView中通过BaseAdapter实现高效列表？convertView复用机制的原理是什么？

<Answer>
①继承BaseAdapter重写getCount/getItem/getItemId/getView。②getView中实现convertView复用：`if (convertView == null) convertView = inflate(layout, null)`，否则复用。③ViewHolder模式：创建ViewHolder类持有控件引用，convertView为null时findViewById存入ViewHolder并setTag绑定，不为null时getTag取出，避免重复findViewById。④从数据源取出position位置数据绑定到ViewHolder控件。convertView复用原理：ListView只创建屏幕可见数+少量缓冲的View，滑出的进入RecycleBin回收池，滑入的从池中取convertView复用。View对象数量恒定，避免OOM。ViewHolder避免每次getView都findViewById（耗时操作）。
</Answer>

**问题 4**：Android常用UI组件有哪些？各自的核心用途和关键属性是什么？

<Answer>
①TextView——文本显示，text/textSize/textColor/maxLines。②EditText——输入框，hint/inputType（text/password/number/phone）。③Button/ImageButton——按钮，setOnClickListener。④ToggleButton/Switch——开关。⑤CheckBox——多选框，setOnCheckedChangeListener。⑥RadioButton——单选（放RadioGroup中）。⑦ImageView——图片显示，src/scaleType。⑧ProgressBar——进度条，style/max/progress。⑨SeekBar——可拖拽进度条。⑩RatingBar——评分条。⑪Spinner——下拉选择，setAdapter。都在XML声明，findViewById获取引用。
</Answer>
