## 直觉引入

网络通信是应用的「大门和通道」。WebView是「内嵌的浏览器窗口」——在App里直接显示网页，还能Java和JS互相调用。HttpURLConnection是「寄信」——按HTTP协议向服务器发请求收响应。Socket是「电话线」——TCP是可靠电话（拨通后持续通话），UDP是广播喇叭（喊一声不管有没有人听到）。XML和JSON是「信的格式」——XML像正式公文（标签嵌套），JSON像便签纸（简洁键值对）。

## WebView内嵌浏览器

```java
WebView webView = findViewById(R.id.webView);
WebSettings settings = webView.getSettings();
settings.setJavaScriptEnabled(true);  // 开启JS

// 页面加载控制
webView.setWebViewClient(new WebViewClient() {
    @Override
    public boolean shouldOverrideUrlLoading(WebView view, String url) {
        view.loadUrl(url);  // 在WebView内打开
        return true;
    }
});

// JS对话框/进度
webView.setWebChromeClient(new WebChromeClient() {
    @Override
    public void onProgressChanged(WebView view, int progress) { /* 进度 */ }
});

webView.loadUrl("https://example.com");

// Java调JS
webView.evaluateJavascript("jsFunction()", value -> { /* 返回值 */ });

// JS调Java
webView.addJavascriptInterface(new Object() {
    @JavascriptInterface  // 必须注解
    public String get_data() { return "data from Java"; }
}, "Android");
```

## HttpURLConnection HTTP请求

```java
// 必须在子线程执行
new Thread(() -> {
    try {
        URL url = new URL("https://api.example.com/data");
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("GET");
        conn.setConnectTimeout(5000);
        conn.setReadTimeout(5000);

        // POST请求
        // conn.setRequestMethod("POST");
        // conn.setDoOutput(true);
        // OutputStream os = conn.getOutputStream();
        // os.write("key=value".getBytes());

        int code = conn.getResponseCode();
        if (code == 200) {
            InputStream is = conn.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(is));
            StringBuilder sb = new StringBuilder();
            String line;
            while ((line = reader.readLine()) != null) sb.append(line);
            String response = sb.toString();

            // 切回主线程更新UI
            runOnUiThread(() -> textView.setText(response));
        }
        conn.disconnect();
    } catch (Exception e) {
        e.printStackTrace();
    }
}).start();
```

<Callout type="trap">
**NetworkOnMainThreadException**：Android 4.0+禁止主线程网络请求。必须在子线程执行，通过Handler/runOnUiThread/AsyncTask切回主线程更新UI，否则ANR。
</Callout>

## Socket通信

```java
// TCP客户端
Socket socket = new Socket("host", 8080);
OutputStream os = socket.getOutputStream();
os.write("Hello".getBytes());
InputStream is = socket.getInputStream();
byte[] buffer = new byte[1024];
int len = is.read(buffer);

// TCP服务端（多线程处理多客户端）
ServerSocket server = new ServerSocket(8080);
while (true) {
    Socket client = server.accept();  // 阻塞等待
    new Thread(() -> handleClient(client)).start();
}

// UDP
DatagramSocket socket = new DatagramSocket();
byte[] data = "Hello".getBytes();
DatagramPacket packet = new DatagramPacket(
    data, data.length, InetAddress.getByName("host"), 8080);
socket.send(packet);
```

## XML解析

```text
SAX     事件驱动流式     内存小     适合大XML     编码复杂
DOM     全树加载内存     API简单    大文件OOM     适合小XML
PULL    流式可控制       Android内置  推荐         类似SAX更易用
```

```java
// XmlPullParser（PULL方式，推荐）
XmlPullParser parser = getResources().getXml(R.xml.data);
int eventType = parser.getEventType();
while (eventType != XmlPullParser.END_DOCUMENT) {
    if (eventType == XmlPullParser.START_TAG) {
        if ("name".equals(parser.getName())) {
            String name = parser.nextText();
        }
    }
    eventType = parser.next();
}
```

## JSON解析

```java
// org.json标准库
JSONObject json = new JSONObject(jsonString);
String name = json.getString("name");
int age = json.getInt("age");
JSONArray array = json.getJSONArray("items");
for (int i = 0; i < array.length(); i++) {
    JSONObject item = array.getJSONObject(i);
    String title = item.getString("title");
}

// Gson（推荐，自动映射对象）
Gson gson = new Gson();
User user = gson.fromJson(jsonString, User.class);
String json = gson.toJson(user);
```

<Callout type="insight">
**JSON更受推荐**：体积比XML小30%-50%（无闭合标签），解析更快，与REST API天然契合，Gson自动映射开发效率远高于XML手工解析。
</Callout>

<Exercises>
**问题 1**：Android WebView的核心API有哪些？如何实现Java与JavaScript互调？

<Answer>
核心API：①loadUrl/loadData加载网页。②goBack/goForward/reload导航。③setWebViewClient控制页面加载（shouldOverrideUrlLoading控制跳转）。④setWebChromeClient处理JS对话框/进度。⑤getSettings配置（setJavaScriptEnabled等）。Java调JS：evaluateJavascript("jsFunction()", callback)（推荐，可获取返回值）或loadUrl("javascript:jsFunction()")（旧方式）。JS调Java：addJavascriptInterface(javaObject, "jsName")暴露Java对象，JS中jsName.javaMethod()调用。@JavascriptInterface注解标注可被JS调用的方法（Android 4.2+安全要求）。
</Answer>

**问题 2**：如何使用HttpURLConnection进行HTTP请求？为什么必须在子线程中执行？

<Answer>
流程：①URL url = new URL("...") → HttpURLConnection conn = url.openConnection()。②setRequestMethod("GET"/"POST")、setConnectTimeout、setRequestProperty。③POST：setDoOutput(true)→getOutputStream().write(data)。④getResponseCode获取响应码，getInputStream读取响应流，BufferedReader逐行读取。⑤conn.disconnect()释放。必须在子线程：①Android 4.0+禁止主线程网络请求，抛NetworkOnMainThreadException。②网络是耗时IO，阻塞UI线程导致卡顿。③超5秒触发ANR。解决：子线程请求 + Handler/runOnUiThread切回主线程更新UI。
</Answer>

**问题 3**：TCP Socket和UDP Socket的区别是什么？ServerSocket如何处理多客户端？

<Answer>
TCP vs UDP：①TCP——面向连接，三次握手可靠连接，保证数据有序不丢失。Socket(host, port)创建，getInputStream/OutputStream读写。适合IM/文件传输/HTTP。②UDP——无连接，不保证到达和顺序。DatagramSocket创建，DatagramPacket封装数据包，send/receive。延迟低可丢包，适合实时音视频/游戏/广播。ServerSocket处理多客户端：①单线程：accept后处理完再accept下一个，无法并发。②多线程：每次accept返回后new Thread处理，主线程继续accept。线程过多切换开销大。③线程池：ExecutorService管理，控制最大并发避免线程爆炸。④NIO：Selector+Channel非阻塞IO，单线程管理多连接。网络操作同样在子线程。
</Answer>

**问题 4**：Android中XML和JSON数据解析各有哪几种方式？为什么JSON更受推荐？

<Answer>
XML三种：①SAX——事件驱动流式，内存小适合大XML，编码复杂。②DOM——全树加载内存，API简单但大文件OOM。③PULL（XmlPullParser）——Android内置推荐，流式可控制进度，类似SAX更易用。JSON两种：①org.json标准库——JSONObject/JSONArray，new JSONObject(jsonString)解析，getString/getInt取值。②Gson——new Gson().fromJson(json, BeanClass.class)自动映射对象，toJson序列化。无需第三方库（org.json内置）。JSON更推荐：①体积比XML小30%-50%（无闭合标签）。②解析效率高。③与REST API天然契合。④Gson自动映射开发效率远高于XML手工解析。
</Answer>

<GlossaryItem term="WebView">内嵌浏览器组件。loadUrl加载网页，setWebViewClient控制跳转，setWebChromeClient处理JS对话框/进度。addJavascriptInterface实现JS互调。</GlossaryItem>
<GlossaryItem term="HttpURLConnection">标准库HTTP客户端。openConnection→setRequestMethod→getInputStream读取响应。必须在子线程执行，主线程抛NetworkOnMainThreadException。</GlossaryItem>
<GlossaryItem term="TCP/UDP Socket">TCP面向连接可靠传输（Socket+getInputStream/OutputStream），适合IM/文件。UDP无连接可丢包（DatagramSocket+DatagramPacket），适合实时音视频。ServerSocket多线程处理多客户端。</GlossaryItem>
<GlossaryItem term="PULL解析">XmlPullParser，Android内置推荐的XML流式解析方式。getEventType+next推进，START_TAG/TEXT/END_TAG事件中提取数据，可控制解析进度。</GlossaryItem>
<GlossaryItem term="Gson">Google JSON库。fromJson(json, Class)自动映射JSON为Java对象，toJson(obj)序列化。自动处理嵌套和集合，最便捷。</GlossaryItem>
</Glossary>
