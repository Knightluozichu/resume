## 直觉引入

把计算机系统想象成一座多层翻译塔。顶层是你写的 C 代码 `printf("hello\n")`，底层是晶体管开关。中间隔着八层翻译：信息怎么编码成二进制（第 2 章），编译器怎么把 C 翻译成汇编和机器码（第 3 章），处理器怎么一条条执行这些机器码（第 4 章），存储器怎么用缓存掩盖速度差距（第 5 章），链接器怎么把多个文件拼成可执行映像（第 6 章），操作系统怎么用异常控制流实现进程切换（第 7 章），虚拟内存怎么给每个进程独立地址空间（第 8 章），最后 hello 字符串怎么通过系统级 I/O 写到屏幕（第 9 章）。本书回答的就是这些「从程序员到硬件」的系统原理问题。

## 五阶段递进

<Term def="计算机系统是从程序员的视角理解计算机的完整抽象链：上层是高级语言程序，下层是硬件实现，中间经过信息表示、机器级表示、处理器、存储、链接、异常控制流、虚拟内存、I/O 八层翻译。">计算机系统</Term>的学习可以拆成五个递进阶段。**信息与机器表示**包括整数/浮点编码和汇编——它们解决「数据怎么编码」和「代码怎么表示」。**处理器与存储**包括流水线架构和缓存层次——它们解决「指令怎么执行」和「数据怎么存取」。**构建与运行**包括链接加载和异常控制流——它们解决「程序怎么拼装」和「控制怎么切换」。**资源管理**包括虚拟内存和系统级 I/O——它们解决「内存怎么隔离」和「外设怎么访问」。**总复习**用 hello 程序的一生串联全部知识点。

```text
// 「hello 程序的一生」——从源码到屏幕的完整系统旅程
源码 hello.c:  printf("hello\n")
  // 1. 信息表示（第 2 章）：'h','e','l','l','o','\n' 的 ASCII/Unicode 编码
  //    字符 'h' = 0x68 = 104 = 01101000B

  // 2. 机器级表示（第 3 章）：编译器把 printf 调用翻译成汇编
  //    call printf@plt → 机器码 e8 xx xx xx xx

  // 3. 处理器架构（第 4 章）：CPU 流水线取指译码执行 call 指令

  // 4. 存储器层次（第 5 章）：指令和数据命中 L1 缓存，避免访存延迟

  // 5. 链接加载（第 6 章）：链接器把 hello.o 与 libc 合并，加载器把 ELF 映射进内存

  // 6. 异常控制流（第 7 章）：printf 内部触发系统调用（软中断/ syscall 指令）

  // 7. 虚拟内存（第 8 章）：内核缓冲区地址经页表翻译成物理地址

  // 8. 系统级 I/O（第 9 章）：write(fd=1, buf, 6) 把字节写到 stdout 对应的终端
```

## 常见误区

<Callout type="trap">
**误区：会用 C 语言就等于懂计算机系统。** 写 C 代码只是描述「程序该做什么」——声明变量、写循环、调函数，照语法就能写。真正懂系统的人能解释：为什么 `int` 溢出会变成负数（补码回绕）、为什么两个指针相减不一定是字节数（指针运算按类型缩放）、为什么缓存友好的代码快几十倍（局部性原理）、为什么 `fork()` 后变量不共享（写时复制）、为什么 `malloc` 不初始化（性能权衡）。把系统当黑盒的人遇到段错误只能重启调试器；懂底层的人能读懂汇编、看懂 CPU 流水线、用缓存优化代码、理解内核行为。区分标志：能否解释「程序为什么这样跑」而非只是「能写出它」。
</Callout>

<Exercises>
**问题 1**：全书五阶段递进是什么？为什么是这个顺序？

<Answer>
信息与机器表示（整数/浮点 + 汇编）→ 处理器与存储（流水线 + 缓存）→ 构建与运行（链接加载 + 异常控制流）→ 资源管理（虚拟内存 + 系统级 I/O）→ 总复习。顺序由依赖关系决定：上层依赖下层。没有信息表示就没有数据编码；没有机器级表示就没有指令表达；没有处理器架构就没有执行单元；没有存储层次就掩盖不了速度差距；没有链接加载程序就拼不起来；没有异常控制流就没有进程切换；没有虚拟内存就没有地址隔离；没有系统级 I/O 就无法访问外设。先「能表示」，再「能执行」，然后「能构建」，接着「能管理资源」，最后「能交互」。
</Answer>

**问题 2**：用「hello 程序的一生」描述全书主线。

<Answer>
源码 `printf("hello\n")`：①信息表示（第 2 章）——字符按 ASCII 编码成字节，'h'=0x68；②机器级表示（第 3 章）——编译器把调用翻译成 `call printf@plt` 机器码 e8...；③处理器架构（第 4 章）——CPU 流水线取指译码执行该指令；④存储器层次（第 5 章）——指令和数据命中 L1 缓存；⑤链接加载（第 6 章）——链接器合并 hello.o 与 libc，加载器把 ELF 映射进内存；⑥异常控制流（第 7 章）——printf 内部触发系统调用陷入内核；⑦虚拟内存（第 8 章）——内核缓冲区地址经页表翻译成物理地址；⑧系统级 I/O（第 9 章）——`write(1, buf, 6)` 把字节写到终端。一次 printf，八层全部参与。
</Answer>
</Exercises>
