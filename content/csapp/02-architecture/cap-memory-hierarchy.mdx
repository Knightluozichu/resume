## 直觉引入

工程师面临一个残酷现实：快的存储小（寄存器纳秒级但只有几十个），大的存储慢（磁盘毫秒级但 TB 起步）。没有任何单一技术既快又大又便宜。存储器层次结构的洞察是：用金字塔堆叠多层——顶层小而快，底层大而慢，靠**局部性原理**让绝大多数访问命中顶层。程序运行时虽然名义上访问内存，但实际 90%+ 的访问被 L1/L2 缓存截获，等效延迟接近寄存器。这个「自动加速」对程序员透明，但理解它的人能写出快几十倍的代码。

## 存储器金字塔

<Term def="存储器层次结构是用多层存储堆叠的金字塔：寄存器→L1 缓存→L2 缓存→L3 缓存→主存→磁盘，顶层小而快每字节贵，底层大而慢每字节便宜，靠局部性让访问多数命中顶层。">存储器层次结构</Term>是速度与容量的工程折中。典型延迟：寄存器 ~1ns、L1 ~1ns、L2 ~4ns、L3 ~12ns、主存 ~100ns、SSD ~100μs、HDD ~10ms。每层都是下一层的缓存——L1 缓存 L2，L2 缓存 L3，L3 缓存主存，主存缓存磁盘（虚拟内存/换页）。命中率是性能命脉：L1 命中率 95%+ 时等效延迟接近 1ns，一旦 miss 到主存延迟翻 100 倍。

## 局部性原理

**局部性**是缓存有效的理论基石。**时间局部性**——被访问过的数据短期内很可能再次被访问（如循环变量、热点数据）；**空间局部性**——被访问数据的相邻地址很可能被访问（如数组顺序遍历）。缓存按缓存行（cache line，通常 64 字节）加载，一次 miss 把整个行载入，后续相邻访问全部命中——这就是空间局部性被硬件自动利用。程序员能控制的是访问模式：顺序访问数组比随机访问链表快几十倍，正是因为前者空间局部性好。

## 缓存映射方式

**缓存映射**决定主存块放在缓存哪里。地址分为 tag + set index + block offset 三段。①**直接映射**——每个主存块只能放唯一位置（set 内一块），硬件简单但冲突 miss 多；②**组相联**——每个 set 有 $E$ 路，主存块可放 set 内任意一路，$E$ 路组相联是直接映射（$E=1$）与全相联（$E=$缓存块数）的折中，L1 常用 8 路组相联；③**全相联**——块可放任意位置，命中率高但硬件复杂只用于小缓存（如 TLB）。miss 分三类（3C 模型）： compulsory miss（冷启动）、capacity miss（缓存不够大）、conflict miss（映射冲突）。

## 缓存友好编程

**缓存友好**的代码能拉开数量级差距。经典案例：矩阵乘法 $C = A \times B$，三重循环顺序不同性能差 10 倍。按 $i,j,k$ 顺序 `C[i][j] += A[i][k]*B[k][j]` 时 `B` 按列访问跨缓存行 miss 严重；改成分块（blocking）把矩阵切成适配缓存的子块，命中率高 10 倍。原则：①顺序访问（利用空间局部性）；②循环顺序让最内层访问连续内存；③分块适配缓存大小；④减少指针追逐（链表 cache unfriendly）。

## 常见误区

<Callout type="trap">
**误区：算法复杂度低就一定快。** 大 O 描述的是渐进复杂度，忽略了常数因子和缓存效应。一个 $O(n \log n)$ 的算法如果缓存不友好（如随机内存访问），在中等规模下可能比 $O(n^2)$ 但缓存友好的算法慢。经典例子：对中等规模数组，插入排序（$O(n^2)$ 顺序访问）常比快排（$O(n \log n)$ 但递归跳跃）快；二分查找虽 $O(\log n)$ 但每次访问跨缓存行，对小数组线性查找可能更快。性能优化必须实测，缓存效应常让理论复杂度失真。
</Callout>

<Exercises>
**问题 1**：什么是局部性原理？时间局部性和空间局部性有何区别？举一个利用局部性的例子。

<Answer>
局部性原理指程序在一段时间内倾向访问相对集中的地址范围，是缓存有效的理论基础。时间局部性：最近访问过的数据短期内很可能再被访问——如循环变量 `i` 在每次循环都用、热点数据反复读写，缓存把它留住下次命中。空间局部性：被访问数据的相邻地址很可能被访问——如数组按顺序遍历，缓存按 64 字节行加载，一次 miss 后续相邻元素全命中。利用例子：矩阵乘法按行优先顺序访问 `A[i][k]` 利用空间局部性；循环内重用变量利用时间局部性。反例：链表节点随机分布、列优先访问 C 数组（行优先存储）破坏空间局部性，缓存 miss 严重。
</Answer>

**问题 2**：缓存的三种映射方式是什么？为什么组相联是常用的折中？

<Answer>
①直接映射——每个主存块映射到缓存唯一位置（set 内一块），地址 = tag + set index + offset。硬件最简单、查找快，但冲突 miss 多（多个热点映射到同一 set 互相驱逐）。②全相联——块可放任意位置，命中率最高无冲突 miss，但查找需并行比较所有块硬件昂贵，只用于小缓存如 TLB。③组相联——折中：缓存分成多个 set，每个 set 有 $E$ 路（块），主存块映射到固定 set 但可在 set 内任意一路。$E=1$ 退化为直接映射，$E=$总块数退化为全相联。L1 常用 8 路组相联：冲突 miss 大幅减少而硬件开销可控（每 set 只需 8 路并行比较），是命中率与复杂度的最佳平衡。
</Answer>
