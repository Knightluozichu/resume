## 直觉引入

想象两种名片。普通名片（`class`）——你给别人一张复印件，别人在复印件上改了电话号码，你的原件也变了（引用共享）。特殊名片（`record`）——你给别人一份复印件，但这份名片是「只读」的，改不了；要改就重新印一张新名片（`with` 表达式），原名片和新名片各自独立。

`record`（C# 9）是引用类型但具有值语义——它分配在堆上，但相等性按值比较（所有字段相同即相等），且默认不可变。`record struct`（C# 10）是值类型+值语义——分配在栈上，值相等，不可变。

普通 `struct` 也有值语义，但默认可变且没有自动生成 `Equals`/`GetHashCode`/`Deconstruct`。`record struct` 是 struct 的增强版——自带值相等、解构和 `with` 表达式。

## 概念讲解

### record：引用类型的值语义

<Term def="record 是 C# 9.0 引入的引用类型，具有基于值的相等语义。编译器自动合成 Equals、GetHashCode、ToString、Deconstruct 和 with 表达式支持。record 默认不可变（init-only 属性），赋值是引用复制但相等性按值比较。">

`record` 的核心特征：

1. **值相等**：两个 record 实例的所有字段相同即为相等（`==` 返回 true），即使它们是不同的堆对象。
2. **不可变**：主构造函数参数生成 init-only 属性，创建后不可修改。
3. **with 表达式**：`p with { Name = "Bob" }` 创建副本并修改指定字段，原实例不变。
4. **合成方法**：编译器自动生成 `Equals`、`GetHashCode`、`ToString`、`Deconstruct`。

```csharp
record Person(string Name, int Age);

var p1 = new Person("Alice", 30);
var p2 = new Person("Alice", 30);
p1 == p2  // true！值相等，尽管是不同对象
```

</Term>

### record struct：值类型的值语义

<Term def="record struct 是 C# 10 引入的值类型 record。分配在栈上，赋值是值复制（独立副本），具有 record 的值相等、with 表达式和解构能力。默认可变，可用 readonly record struct 标记不可变。">

`record struct` 与 `record` 的区别：

| 特性 | record (C# 9) | record struct (C# 10) |
|---|---|---|
| 类型 | 引用类型 | 值类型 |
| 内存 | 堆 | 栈/内联 |
| 赋值 | 引用复制 | 值复制 |
| 可变性 | 默认不可变 | 默认可变 |
| 值相等 | 是 | 是 |
| with 表达式 | 是 | 是 |

`readonly record struct` 标记为不可变——推荐用法，保证值类型的不可变性安全。

### with 表达式与解构

`with` 表达式创建副本并修改指定属性：

```csharp
var updated = p with { Age = 31 };  // 新实例，Name 不变，Age = 31
```

解构将 record 拆解为分量：

```csharp
var (name, age) = p;  // 调用自动生成的 Deconstruct
```

### struct 的使用场景

`struct` 适合小型（≤16 字节）、不可变、密集存储的数据。`record struct` 是 struct 的增强版——自带值相等和 `with`。大对象或需要引用共享的场景用 `class` 或 `record`。

`record Person(string Name, int Age)` 是引用类型——分配在堆上，赋值是引用复制。但相等性按值比较：`new Person("A", 30) == new Person("A", 30)` 返回 true。编译器合成 `Equals`、`GetHashCode`、`ToString`、`Deconstruct`。

`p with { Age = 31 }` 创建 p 的副本并将 Age 改为 31。原 p 不变。with 是「创建副本+修改」的语法糖——对 record 用 `with`，对 record struct 用 `with`（创建堆上的副本再复制回值）。

</Step>

<Step title="record struct：值类型+值相等">

`record struct Point(double X, double Y)` 是值类型——分配在栈上，赋值是值复制。两个 Point 变量是独立副本，修改一个不影响另一个。值相等：`new Point(1,2) == new Point(1,2)` 返回 true。用 `readonly record struct` 保证不可变。

</Step>

<Step title="class vs record vs record struct vs struct">

`class`：引用类型，引用相等，可变。适合有身份的大对象。`record`：引用类型，值相等，不可变。适合有身份的不可变数据。`record struct`：值类型，值相等，默认可变。适合小型数据。`readonly record struct`：值类型，值相等，不可变。适合小型不可变数据（如坐标、颜色）。

</Step>

## 代码对照

```csharp
// Record 与结构体：值语义、不可变性、with

// === record（C# 9）：引用类型 + 值相等 ===
record Person(string Name, int Age);

var p1 = new Person("Alice", 30);
var p2 = new Person("Alice", 30);

Console.WriteLine(p1 == p2);              // true — 值相等
Console.WriteLine(ReferenceEquals(p1, p2)); // false — 不同对象

// with 表达式：创建副本并修改
var p3 = p1 with { Age = 31 };
Console.WriteLine(p1.Age);  // 30 — 原实例不变
Console.WriteLine(p3.Age);  // 31 — 新实例

// 解构
var (name, age) = p1;
Console.WriteLine($"{name}, {age}");  // Alice, 30

// === record struct（C# 10）：值类型 + 值相等 ===
readonly record struct Point(double X, double Y);

var pt1 = new Point(1.0, 2.0);
var pt2 = pt1;           // 值复制：独立副本
Console.WriteLine(pt1 == pt2);  // true — 值相等

var pt3 = pt1 with { X = 99.0 };
Console.WriteLine(pt1.X);  // 1.0 — 原值不变
Console.WriteLine(pt3.X);  // 99.0 — 新副本

// === 普通 struct：值类型，默认引用相等 ===
struct Color
{
    public byte R { get; init; }
    public byte G { get; init; }
    public byte B { get; init; }
    // 没有自动生成 Equals/GetHashCode/Deconstruct
    // == 操作符未定义，需要手动重写
}

var c1 = new Color { R = 255, G = 0, B = 0 };
var c2 = new Color { R = 255, G = 0, B = 0 };
// c1 == c2;  // 编译错误！struct 没有自动 == 
Console.WriteLine(c1.Equals(c2));  // true（ValueType.Equals 反射比较）

// record struct 自动有 == 和 !=
readonly record struct ColorRgb(byte R, byte G, byte B);
var cr1 = new ColorRgb(255, 0, 0);
var cr2 = new ColorRgb(255, 0, 0);
Console.WriteLine(cr1 == cr2);  // true — 自动生成 ==

// === 继承（只有 record 支持）===
record Teacher(string Name, int Age, string Subject) : Person(Name, Age);

var teacher = new Teacher("Bob", 45, "Math");
if (teacher is Person { Age: > 40 } senior)
    Console.WriteLine($"{senior.Name} is senior");

// === ToString：编译器自动生成 ===
Console.WriteLine(p1);  // Person { Name = Alice, Age = 30 }
Console.WriteLine(pt1); // Point { X = 1, Y = 2 }
```

## 常见误区

<Callout type="trap">

**误区：record 是不可变的所以不能修改**

`record` 默认不可变指的是 init-only 属性——创建后不能 `p.Age = 31`。但你可以用 `with` 创建修改后的副本：`p with { Age = 31 }`。此外，`record` 可以有可变成员（`public int Counter { get; set; }`），只是这不推荐——破坏了 record 的值语义保证。`record` 的「不可变」是默认设计，不是强制约束。`readonly record struct` 才是编译时强制的不可变。

</Callout>

<Callout type="trap">

**误区：record struct 和 struct 效果一样**

普通 `struct` 没有自动生成 `Equals`/`GetHashCode`/`==`/`Deconstruct`/`ToString`/`with`——这些都要手写。`record struct` 自动合成所有这些方法。`new Point(1,2) == new Point(1,2)` 对 `record struct` 是 true（自动 `==`），对普通 `struct` 是编译错误（未定义 `==`）。`record struct` 是 struct 的「豪华版」，省去大量样板代码。

</Callout>

<Exercises>

**问题 1**：`record` 和 `class` 都分配在堆上，它们的 `==` 行为有什么不同？为什么？

<Answer>

`class` 的 `==` 默认是引用相等——两个变量指向同一个堆对象才返回 true。`record` 的 `==` 是值相等——两个变量的所有字段相同即返回 true，即使它们是不同的堆对象。

原因：`record` 编译器自动重载了 `==` 和 `!=` 操作符，调用合成的 `Equals` 方法进行值比较。`record` 的设计目的是「值语义的数据载体」——两个 Person 如果 Name 和 Age 相同，逻辑上就是「同一个人」，不管它们在内存中是不是同一个对象。`class` 的设计目的是「有身份的对象」——两个 Person 对象即使属性相同也是不同的「人」。

</Answer>

**问题 2**：什么时候用 `readonly record struct`，什么时候用 `record`？给出选择依据。

<Answer>

选择依据是**值语义 vs 引用语义**和**内存分配**：

用 `readonly record struct` 的场景：
- 小型数据（≤16 字节）：坐标点、颜色、日期范围、货币金额。
- 频繁创建/销毁：值类型在栈上分配，不增加 GC 压力。
- 需要值复制语义：每个变量是独立副本，修改不影响其他。
- 密集存储在数组中：值类型数组内存连续，缓存友好。

用 `record` 的场景：
- 较大数据：避免大结构体的复制开销。
- 需要引用共享：多个变量指向同一份数据，修改一处影响所有引用。
- 需要继承：`record struct` 不支持继承，`record` 支持继承。
- 需要多态：作为基类使用，子类型通过模式匹配区分。

经验法则：如果数据小、不可变、不需要继承，用 `readonly record struct`。如果数据大、需要继承或引用共享，用 `record`。

</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="record">

C# 9 引入的引用类型，具有值相等语义。编译器合成 Equals、GetHashCode、ToString、Deconstruct、with。默认不可变。支持继承。

</GlossaryItem>

<GlossaryItem term="record struct">

C# 10 引入的值类型 record。栈分配，值复制，值相等。默认可变，`readonly record struct` 不可变。不支持继承。

</GlossaryItem>

<GlossaryItem term="with 表达式">

创建 record/record struct 的副本并修改指定属性。`p with { Age = 31 }` 生成新实例，原实例不变。

</GlossaryItem>

<GlossaryItem term="值相等（value equality）">

两个对象的所有字段相同即为相等。`record` 和 `record struct` 默认值相等。`class` 默认引用相等。

</GlossaryItem>
