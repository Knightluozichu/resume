## 直觉引入

把 CSS 想象成做一道菜。你先要铺底——背景怎么涂、条纹怎么画（背景与形状）；然后切造型——边框怎么变圆、元素怎么裁剪（裁剪与伪元素）；接着调味——文字怎么描边、字体怎么调（排版与字体）；最后摆盘上桌——滚动怎么顺滑、动画怎么流畅（交互与动效）。本书回答的就是这些「从视觉到体验」的 CSS 实战问题。

## 四阶段递进

<Term def="CSS 揭秘体系是以背景与形状为基底、通过裁剪路径与伪元素扩展造型、用文本属性与字体特性控制排版、靠交互技巧与动效驱动体验的分层体系。">CSS 揭秘系统</Term>的学习可以拆成四个递进阶段。**背景与形状**包括渐变条纹、多重边框、圆角与连续边框——它们解决「底色怎么涂」和「轮廓怎么变」，是所有视觉表现的基底。**裁剪与伪元素**包括 clip-path 几何裁剪和伪元素妙用——它们决定「元素怎么变形」和「额外层怎么加」。**排版与字体**包括文字描边、渐变文字、OpenType 字体特性——它们精确控制「文字怎么美」。**交互与动效**包括滚动平滑、焦点高亮、视差与 loading——它们让页面「好用且能动起来」。

```css
/* 一个「按钮从背景到动效」的完整 CSS 揭秘旅程 */
.btn {
  /* 1. 背景与形状：线性渐变 + 圆角（第 2-3 章） */
  background: linear-gradient(135deg, #6a5acd, #483d8b);
  border-radius: 8px;
  box-shadow: 0 0 0 2px rgba(255,255,255,0.3); /* 多重边框 */

  /* 3. 排版与字体：字距与描边（第 6-7 章） */
  font-size: 16px;
  letter-spacing: 0.02em;
  -webkit-text-stroke: 0.5px transparent;

  /* 4. 交互与动效：hover 平滑过渡（第 8-9 章） */
  transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
.btn:hover {
  transform: translateY(-2px) scale(1.05); /* 只合成不重排 */
}

/* 2. 裁剪与伪元素：tooltip 气泡箭头（第 4-5 章） */
.btn::after {
  content: "";
  clip-path: polygon(50% 0, 0 100%, 100% 100%);
}
```

## 常见误区

<Callout type="trap">
**误区：CSS 技巧只是奇技淫巧。** 技巧背后是渲染机制——linear-gradient 为什么是背景层的、box-shadow 多重投影怎么叠加、clip-path 为什么不触发重排、伪元素为什么能创造额外层。Lea Verou 的每个「揭秘」都在解决一个真实痛点：多重边框以前只能嵌套 div、渐变文字以前只能用图片、环形文字以前只能用 SVG。理解了原理，你才能举一反三——不是背 47 个技巧，而是掌握 CSS 渲染层的心智模型。
</Callout>

<Exercises>
**问题 1**：全书四阶段是什么？为什么是这个顺序？

<Answer>
背景与形状（渐变条纹/多重边框/圆角）→ 裁剪与伪元素（clip-path/伪元素妙用）→ 排版与字体（文字特效/OpenType）→ 交互与动效（滚动/焦点/视差/loading）→ 总复习。顺序由视觉层次决定：上层依赖下层。没有背景与形状就没有视觉基底；没有裁剪与伪元素就无法扩展造型；没有排版与字体就无法控制文字；没有交互与动效就驱动不了体验。先有「能看」，再有「能变」，然后「能排」，最后「能交互」。
</Answer>

**问题 2**：为什么 `box-shadow: 0 0 0 2px` 可以模拟多重边框，而不用嵌套 div？

<Answer>
box-shadow 的 spread radius（第四个值）可以让阴影向四周扩展成实心环，叠加多个 box-shadow 就能模拟多层边框。它不占文档流空间（不影响布局），一个元素就能画多层边框。嵌套 div 需要 N 个 HTML 元素对应 N 层边框，破坏语义、增加 DOM 深度。但 box-shadow 模拟的「边框」不响应 hover 事件、不影响 box-sizing 计算，且在圆角处可能出现锯齿——需要根据场景选择 box-shadow、outline 还是 border-image。
</Answer>
