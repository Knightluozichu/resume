## 直觉引入

条纹是最常见的背景纹理。以前做条纹要切图、要考虑 retina、要控制文件大小——现在一行 CSS 搞定。秘密在于：渐变的色标放在同一位置会产生硬边，重复渐变让图案自动平铺。把这两件事拼在一起，条纹、网格、棋盘、波点全都变成纯 CSS。

## 条纹图案

<Term def="重复线性渐变（repeating-linear-gradient）会在渐变轴上以指定色标段周期性平铺，色标重合处产生硬边，从而形成条纹。">条纹生成原理</Term>的核心是让色标「贴在一起」。普通 `linear-gradient` 的色标之间会平滑过渡，但当两个色标位置相同时，过渡区域为零，颜色直接跳变——这就产生了硬边条纹。

```css
/* 水平条纹：每 30px 交替蓝白 */
.stripes-h {
  background: repeating-linear-gradient(
    to bottom,
    #58a 0,
    #58a 30px,
    #fb3 30px,
    #fb3 60px
  );
}

/* 垂直条纹 */
.stripes-v {
  background: repeating-linear-gradient(
    to right,
    #58a 0,
    #58a 30px,
    #fb3 30px,
    #fb3 60px
  );
}

/* 斜向条纹（45 度） */
.stripes-d {
  background: repeating-linear-gradient(
    45deg,
    #58a 0,
    #58a 15px,
    #fb3 15px,
    #fb3 30px
  );
}
```

## 网格背景

网格是两组条纹的叠加——水平线加垂直线。用多重 `background` 声明可以叠加多个渐变层，第一个声明的在最上层。

```css
/* 网格背景：两条渐变叠加 */
.grid {
  background:
    linear-gradient(to right, rgba(0,0,0,.1) 1px, transparent 1px),
    linear-gradient(to bottom, rgba(0,0,0,.1) 1px, transparent 1px);
  background-size: 40px 40px;
}

/* 棋盘格：用两半色块错位叠加 */
.checkerboard {
  background:
    repeating-conic-gradient(#bbb 0 25%, transparent 0 50%) 0 / 40px 40px;
}
```

## 常见误区

<Callout type="trap">
**误区：用 background-image 引入 PNG 条纹图更可控。** 实际上 CSS 渐变条纹是矢量描述，任意缩放不失真、零网络请求、改色改密度只改 CSS 不重新出图。PNG 条纹图在 retina 屏需要 2x/3x 资源、改颜色要重新打开 PS、文件大小累积影响加载。唯一 PNG 更优的场景是需要噪点、照片级纹理等渐变无法表达的复杂图案。
</Callout>

<Exercises>
**问题 1**：为什么 `repeating-linear-gradient` 中两个色标放在同一位置会产生硬边条纹？

<Answer>
渐变在两个色标之间做线性插值。当两个相邻色标位置相同（如 `#58a 30px, #fb3 30px`），插值区间为零——颜色在 30px 处瞬间从 `#58a` 跳变为 `#fb3`，没有过渡区域，因此形成清晰的硬边。如果色标之间有间距（如 `#58a 0, #fb3 30px`），颜色会在这 30px 内平滑过渡，产生渐变而非条纹。repeating-linear-gradient 会把这段色标周期在整个渐变轴上重复平铺，于是硬边条纹就周期性出现了。
</Answer>

**问题 2**：如何用纯 CSS 画一个波点（圆点）背景图案？

<Answer>
用 radial-gradient 画一个圆点，再用 background-size 控制圆点间距，背景自动平铺。代码：`background: radial-gradient(circle, #58a 25%, transparent 26%); background-size: 40px 40px;`。radial-gradient 从圆心向外辐射，25% 处是实心圆，26% 处变为透明——1% 的间隙产生抗锯齿的硬边圆。background-size 设为 40px 让这个圆点图案每 40px 重复一次，形成规整的波点阵列。要交错排列可以叠加两层不同 background-position 的波点。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="重复线性渐变">repeating-linear-gradient 在渐变轴上以色标段为周期自动平铺，色标重合处产生硬边，适合生成条纹、网格等周期性图案。</GlossaryItem>
<GlossaryItem term="多重背景">一个元素可声明多个 background 值（逗号分隔），前者在上层、后者在下层。用 background-size 和 background-position 分别控制每层，可叠加出网格、波点等复杂纹理。</GlossaryItem>
<GlossaryItem term="conic-gradient 锥形渐变">从中心点沿圆周方向旋转的渐变，配合 repeating 前缀可生成饼图、棋盘等扇形分割图案。</GlossaryItem>
</Glossary>
