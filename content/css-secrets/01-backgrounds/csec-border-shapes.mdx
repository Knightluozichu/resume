## 直觉引入

CSS 的 `border` 属性只能画一层边框。想要两层、三层怎么办？以前只能嵌套 div——每个 div 画一层。Lea Verou 的解法是：box-shadow 的 spread radius 可以让阴影向外扩展成实心环，叠加多个就成多重边框；outline 可以画在 border 外面再添一层；border-image 可以把一张图切成九宫格自动拉伸成边框。三种方案各有取舍。

## 多重边框

<Term def="box-shadow 的 spread radius（第四个值）让阴影向四周均匀扩展，当 offset 和 blur 为零时形成实心环，叠加多个逗号分隔的 box-shadow 即可模拟多重边框。">spread radius 多重边框</Term>是最灵活的方案。

```css
/* 两层边框：box-shadow 叠加 */
.multi-border {
  border: 5px solid #58a;
  box-shadow:
    0 0 0 5px #fb3,     /* 第二层 */
    0 0 0 10px #655;    /* 第三层 */
}

/* outline 方案：只能多一层，但可控制间距 */
.outline-border {
  border: 5px solid #58a;
  outline: 5px solid #fb3;
  outline-offset: 2px;  /* 边框与 outline 之间留 2px 间隙 */
}
```

## 连续边框与 border-image

当边框需要是图案（虚线、双线、花纹）时，`border-style: dashed` 的效果不可控。`border-image` 可以把一张图切九宫格，四角固定、四边拉伸或平铺。

```css
/* border-image：用渐变做边框 */
.gradient-border {
  border: 10px solid transparent;
  border-image: linear-gradient(to right, #58a, #fb3) 1;
}

/* border-image 切图法 */
.image-border {
  border: 20px solid transparent;
  border-image: url('border.png') 30 round;
  /* 30 = 切片宽度，round = 平铺重复 */
}
```

## 圆角与椭圆

`border-radius` 接受百分比，50% 就是正圆。分别设置水平和垂直半径可以画椭圆。

```css
/* 正圆 */
.circle { border-radius: 50%; }

/* 椭圆：水平半径 50%，垂直半径 30% */
.ellipse { border-radius: 50% / 30%; }

/* 不对称圆角 */
.leaf { border-radius: 0 50% 0 50%; }
```

## 常见误区

<Callout type="trap">
**误区：box-shadow 模拟的边框和真 border 完全等价。** 三点关键差异：①box-shadow 不占布局空间——它不影响盒模型尺寸，也不会把相邻元素推开；②box-shadow 不响应鼠标事件——点击在「边框」区域不会触发元素的 click；③box-shadow 在内联元素上表现可能与 border 不同。当你需要边框参与布局计算或响应交互时，还是得用 border + 嵌套元素。
</Callout>

<Exercises>
**问题 1**：用 box-shadow 模拟三重边框时，三层 shadow 的 spread 值应该怎么设置？

<Answer>
三层 box-shadow 的 spread radius 必须递增，每层的 spread = 前面所有层宽度之和 + 当前层宽度。例如 border 本身 5px，三层 shadow 各 5px：第一层 spread 为 5px（紧贴 border 外侧），第二层 spread 为 10px（5px border + 5px 第一层），第三层 spread 为 15px。代码：`box-shadow: 0 0 0 5px #fb3, 0 0 0 10px #655, 0 0 0 15px #58a;`。因为 box-shadow 是叠加的，后面的大阴影会覆盖前面的小阴影的外圈，只露出内圈那条环。
</Answer>

**问题 2**：`border-radius: 50%` 在不同宽高比的元素上分别产生什么形状？

<Answer>
border-radius: 50% 让四个角的水平和垂直半径都等于各自边长的 50%。当元素宽高相等（正方形）时，四角圆弧拼合为正圆。当宽高不等（矩形）时，水平半径 = 宽的 50%，垂直半径 = 高的 50%，四角圆弧拼合为椭圆——水平方向和垂直方向半径不同，形成贴合矩形边界的椭圆而非正圆。这就是为什么 `border-radius: 50%` 在矩形按钮上不会变成圆形，要做圆形按钮必须保证 width = height。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="spread radius">box-shadow 的第四个长度值，控制阴影向四周扩展的距离。当 offset 和 blur 为零时，spread radius 形成均匀实心环，用于模拟多重边框。</GlossaryItem>
<GlossaryItem term="border-image">将一张图片切成九宫格（四角固定、四边拉伸或平铺、中心填充），用作元素边框。可实现渐变边框、花纹边框等 border-style 无法表达的图案。</GlossaryItem>
<GlossaryItem term="outline-offset">outline 与 border 之间的间距。outline 默认紧贴 border 外侧，正值向外推、负值向内缩。outline 不影响布局、不占盒模型空间。</GlossaryItem>
</Glossary>
