## 六阶段解题链

### 1. 识别目标轮廓

先写视觉与交互契约，不写具体属性。固定 DOM、文本、视口、字体和输入方式，预测无增强样式时应保留的内容、尺寸、焦点和阅读顺序。

### 2. 选择绘制阶段

查明目标效果属于盒生成、背景绘制、边框、滤镜、字体、布局还是合成阶段。只选能直接解释目标的机制，并注明规范能力与实现边界。

### 3. 裁剪多余阴影

构造最小代码，删除重复数值、镜像状态和额外 DOM。先预测计算值与绘制区域，再运行正常样本，记录首个产生目标效果的声明。

### 4. 建立背景采样

只改变一个变量，例如容器宽度、文本长度、背景、字体、输入方式或动态偏好。停止在首个偏离点，不用更多覆盖把失败截图修平。

### 5. 控制对比度

关闭关键能力，检查自然回退是否仍可读、可操作、可布局。增强方案不能反向破坏基线，也不能以颜色、动画或装饰替代语义。

### 6. 验证无滤镜回退

清除故障后重放同一 DOM，确认没有旧内联样式、重复常量、隐藏焦点或层叠残留。把通过条件写成以后可以自动或人工复查的证据。

## 核心机制深挖

区分盒阴影、像素轮廓和背景采样，选择与目标轮廓一致的绘制机制，并为滤镜能力准备可读回退。 解题时先区分**结构事实、计算样式、绘制结果和交互状态**：结构决定语义与可访问名称，级联和布局产生计算值与使用值，背景、边框、阴影、滤镜再参与绘制，动画与输入只改变状态。把这些阶段混在一起，往往会用多余 DOM 修背景、用固定尺寸修布局、用不可见原生控件修状态，最终难以维护。

本页签发不变量是：**效果应匹配真实轮廓并维持文本对比度；关闭滤镜、透明或混合能力后，信息仍然清楚可读。** 对每个方案都要问四个问题：不支持高级能力时剩下什么；内容变长时谁负责尺寸；键盘与触摸是否仍能完成任务；删除故障声明后是否回到同一基线。只有四问都有可复现答案，技巧才从演示升级为工程方案。

## 出版社目录逐项讲解

### 第4章 视觉效果

本章区分盒轮廓、真实透明像素和背景采样。box-shadow 围绕矩形盒绘制，drop-shadow 跟随 alpha 轮廓，filter 与 backdrop-filter 位于不同采样阶段；选错阶段会得到错误边缘或不可读文字。

证据记录从“识别目标轮廓”开始：先写出未增强时的可用结果，再只加入一个 CSS 能力，比较计算样式、绘制边界、内容语义、输入状态和失败回退。若方案需要复制尺寸、隐藏真实控件、依赖固定内容或无法解释的层叠补丁，就回到最小样本重做。

### 15 单侧投影

box-shadow 可用负扩张半径收缩阴影，再沿目标方向偏移，只让一侧露出。双侧投影可叠加两条阴影；必须在圆角和不同背景上观察，不把阴影当边框，也不让视觉外延改变布局计算。

证据记录从“选择绘制阶段”开始：先写出未增强时的可用结果，再只加入一个 CSS 能力，比较计算样式、绘制边界、内容语义、输入状态和失败回退。若方案需要复制尺寸、隐藏真实控件、依赖固定内容或无法解释的层叠补丁，就回到最小样本重做。

### 16 不规则投影

带透明区域、伪元素或裁剪轮廓的对象不适合矩形 box-shadow，filter: drop-shadow 会依据合成后的 alpha 轮廓投影。滤镜可能建立新的层叠上下文，测试层级、裁剪与性能，并提供无阴影仍清晰的基线。

证据记录从“裁剪多余阴影”开始：先写出未增强时的可用结果，再只加入一个 CSS 能力，比较计算样式、绘制边界、内容语义、输入状态和失败回退。若方案需要复制尺寸、隐藏真实控件、依赖固定内容或无法解释的层叠补丁，就回到最小样本重做。

### 17 染色效果

图片染色可用滤镜链调整灰度、对比与色相，或用 background-blend-mode 将色层与图像混合。滤镜顺序会改变结果，先定义目标色与对比阈值；交互态切换时保留原图，避免颜色成为唯一状态信号。

证据记录从“建立背景采样”开始：先写出未增强时的可用结果，再只加入一个 CSS 能力，比较计算样式、绘制边界、内容语义、输入状态和失败回退。若方案需要复制尺寸、隐藏真实控件、依赖固定内容或无法解释的层叠补丁，就回到最小样本重做。

### 18 毛玻璃效果

毛玻璃需要采样元素背后的像素，backdrop-filter 是直接模型；旧方案用伪元素复制背景并模糊，但要同步背景定位。无论实现方式，都应先铺半透明实体底色保证回退，并用不同背景检测正文对比度。

证据记录从“控制对比度”开始：先写出未增强时的可用结果，再只加入一个 CSS 能力，比较计算样式、绘制边界、内容语义、输入状态和失败回退。若方案需要复制尺寸、隐藏真实控件、依赖固定内容或无法解释的层叠补丁，就回到最小样本重做。

### 19 折角效果

折角由一个背景切角与一个表示翻折面的三角渐变组合，两者尺寸和角度必须共享参数。伪元素方案可增加阴影与透视，但不能遮挡正文；在角尺寸变化、不同底色与长标题下核对折面连接。

证据记录从“验证无滤镜回退”开始：先写出未增强时的可用结果，再只加入一个 CSS 能力，比较计算样式、绘制边界、内容语义、输入状态和失败回退。若方案需要复制尺寸、隐藏真实控件、依赖固定内容或无法解释的层叠补丁，就回到最小样本重做。

## 方案比较矩阵

| 方案       | 依赖                       | 优点             | 主要风险             | 验收重点                |
| ---------- | -------------------------- | ---------------- | -------------------- | ----------------------- |
| 基线       | 正常流、实体颜色、原生语义 | 最稳定、自然回退 | 视觉较简单           | 无 CSS 增强仍可读可操作 |
| 单属性增强 | 圆角、阴影、渐变或相对单位 | 代码少、意图清楚 | 绘制区域判断错误     | 改背景、尺寸和内容      |
| 多层组合   | 多背景、伪元素、滤镜或变换 | 表达复杂效果     | 层叠、裁剪和性能     | 关闭一层仍能定位根因    |
| 动态增强   | 状态选择器、过渡、动画     | 反馈连续         | 键盘、减少动态和中断 | 快速反转与静态回退      |

## 最小可运行实验

```css
.irregular {
  filter: drop-shadow(0 0.35rem 0.4rem rgb(15 23 42 / 0.3));
}
.glass {
  background: rgb(255 255 255 / 0.72);
}
@supports (backdrop-filter: blur(1rem)) {
  .glass {
    backdrop-filter: blur(1rem);
  }
}
```

## 常见误区与故障注入

<Callout type="trap">
  **误区一：看到效果相同就认定方案等价。** 固定尺寸、额外
  DOM、隐藏溢出和无法解释的高层级可能暂时生成同一截图，却会在内容、字体、输入或能力缺失时分叉。必须比较机制与恢复轨迹。
</Callout>

<Callout type="trap">
  **误区二：把 2026 年的便利属性直接冒充 2015 年原书攻略。**
  现代替代方案可以放入比较矩阵，但必须先解释原书使用的渐变、阴影、伪元素、变换或选择器机制，并明确两者的回退与兼容边界。
</Callout>
