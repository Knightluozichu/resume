## 直觉引入

字体不只是「选一个 font-family」。现代字体文件里藏着大量 OpenType 特性：连字让 fl/ffi 合并成优美的连笔、等宽数字让表格对齐、小型大写让缩写更优雅。这些特性以前只有 InDesign 能控制，现在 CSS 直接暴露——一行 `font-variant-ligatures` 就能开关。

## 字距控制

<Term def="font-kerning 控制字偶距（kerning）——字体文件内置的特定字符对间距调整，如 AV/To/Ly 等；letter-spacing 是对所有字符统一加减间距。">字距与字偶距</Term>是两个不同层面的控制。

```css
/* 开启字偶距（需要字体支持） */
.kerned {
  font-kerning: normal; /* 默认 auto，正常排版建议 normal */
}

/* 统一加宽字距 */
.loose {
  letter-spacing: 0.1em;
}

/* 标题紧凑字距 */
.tight {
  letter-spacing: -0.02em;
}
```

## 连字

连字（ligature）把相邻字符合并成一个字形——「f」和「l」的横线连在一起更美观。

```css
/* 开启标准连字 */
.ligatures-on {
  font-variant-ligatures: common-ligatures;
}

/* 关闭连字（代码块不需要连字） */
.ligatures-off {
  font-variant-ligatures: none;
  /* 代码中 ff/fi/fl 不应合并 */
}
```

## OpenType 数字特性

数字有两种排版方式：比例数字（proportional，宽度不一）和等宽数字（tabular，宽度相同）。

```css
/* 等宽数字：表格、价格列表对齐 */
.tabular {
  font-variant-numeric: tabular-nums;
}

/* 比例数字：正文段落更自然 */
.proportional {
  font-variant-numeric: proportional-nums;
}

/* 小型大写 */
.small-caps {
  font-variant-caps: small-caps;
}

/* 底层 OpenType 特性调用 */
.otf {
  font-feature-settings: "tnum" 1, "smcp" 1;
}
```

## 常见误区

<Callout type="trap">
**误区：letter-spacing 可以替代 font-kerning。** 两者完全不同。font-kerning 调用的是字体文件内置的字偶距表——它知道 AV 这对字母应该拉近、To 这对应该正常，是逐对智能调整。letter-spacing 是对所有字符无差别加减同一个值——它不区分字符对，AV 和 aa 加减量相同。如果你想要「排版优化的紧凑感」，应该用 font-kerning: normal；如果你想要「设计感的宽松/紧凑风格」，才用 letter-spacing。两者可叠加使用。
</Callout>

<Exercises>
**问题 1**：代码块中为什么应该关闭连字（font-variant-ligatures: none）？

<Answer>
代码中字符组合如 ff、fi、fl、ffi 在开启连字时会被合并成连笔字形——这改变了代码的实际视觉形态。例如 CSS 中的 `affiliation`、HTML 中的 `diff`，如果 fl 或 ff 被合并，代码可读性下降，且与输入的原始字符不对应——开发者难以快速定位字符。更重要的是，连字字形可能让 `!=` 等符号看起来像 `≠`，造成误解。因此代码块、终端模拟器等场景应设 `font-variant-ligatures: none`，确保每个字符独立显示，忠实反映源码。
</Answer>

**问题 2**：`font-variant-numeric: tabular-nums` 和 `proportional-nums` 有什么区别？各适用什么场景？

<Answer>
tabular-nums（等宽数字）：每个数字字符占相同宽度（如 1 和 8 一样宽）。优点是数字纵向对齐——在表格、价格列表、计时器中，数字变化时不会左右抖动。proportional-nums（比例数字）：每个数字按自身字形宽度排列（1 比 8 窄）。优点是视觉更自然、阅读节奏更好——适合正文段落中的日期、数量。场景选择：财务表格/数据看板/倒计时用 tabular-nums，正文/标题用 proportional-nums。底层对应 OpenType 特性 tnum 和 pnum。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="font-kerning">控制字偶距——字体文件内置的特定字符对（如 AV、To）间距调整。与 letter-spacing 的无差别统一间距不同，kerning 是逐对智能调整。</GlossaryItem>
<GlossaryItem term="连字（ligature）">相邻字符合并为一个字形。标准连字（common-ligatures）处理 ff/fi/fl/ffi 等组合。代码场景应关闭连字以保证字符可读性。</GlossaryItem>
<GlossaryItem term="tabular-nums">等宽数字，所有数字字形宽度相同，适合表格纵向对齐。对应 OpenType 特性 tnum。proportional-nums 为比例数字，宽度各异，适合正文。</GlossaryItem>
</Glossary>
