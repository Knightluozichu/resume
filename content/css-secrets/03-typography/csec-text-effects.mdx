## 直觉引入

文字不只是黑底白字。描边让标题更有冲击力，渐变文字让 hero 区更华丽，环形文字让 logo 更有设计感。以前这些效果只能靠图片——文字一改就要重新出图。CSS 的解法是：text-stroke 画描边、background-clip:text 把渐变贴进文字、SVG textPath 让文字沿路径走。全部矢量、全部可改、全部可搜索。

## 文字描边

<Term def="-webkit-text-stroke 是非标准但广泛支持的属性，接受宽度与颜色两个值，在文字边缘绘制描边线。它绘制在文字填充色之上。">text-stroke 描边</Term>比 text-shadow 模拟描边更精准。

```css
/* 描边文字 */
.stroke-text {
  -webkit-text-stroke: 2px #58a;
  color: transparent; /* 只保留描边，去掉填充 */
}

/* text-shadow 模拟描边（兼容性更好） */
.shadow-stroke {
  color: white;
  text-shadow:
    -1px -1px 0 #58a, 1px -1px 0 #58a,
    -1px  1px 0 #58a, 1px  1px 0 #58a;
}
```

## 渐变文字

`background-clip: text` 让背景被裁剪到文字形状内——渐变就贴在了文字上。

```css
/* 渐变文字 */
.gradient-text {
  background: linear-gradient(90deg, #58a, #fb3, #e6a);
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent; /* 必须！否则文字色覆盖渐变 */
}
```

## 环形文字

文字沿圆弧排列需要 SVG 的 `textPath`——CSS 目前无法让文字沿任意路径排列。

```html
<svg viewBox="0 0 200 200">
  <defs>
    <path id="circle" d="M 100,100 m -75,0 a 75,75 0 1,1 150,0 a 75,75 0 1,1 -150,0" />
  </defs>
  <text font-size="14">
    <textPath href="#circle">文字沿圆形路径排列 · CSS揭秘 · </textPath>
  </text>
</svg>
```

## 常见误区

<Callout type="trap">
**误区：background-clip: text 不用设 color: transparent。** 渐变文字的关键是让文字填充色透明、只显示背景渐变。如果不设 `color: transparent`，文字的默认颜色（通常是黑色）会覆盖在渐变之上——你看到的还是黑字而不是渐变字。`-webkit-text-fill-color: transparent` 是更可靠的写法（优先级高于 color），但在非 WebKit 浏览器中需搭配 `color: transparent` 做回退。
</Callout>

<Exercises>
**问题 1**：`-webkit-text-stroke` 和 `text-shadow` 模拟描边各有什么优缺点？

<Answer>
text-stroke 优点：①描边宽度精确可控（直接指定 px）；②描边均匀（四个方向等宽）；③渲染清晰不模糊。缺点：①非标准属性（虽然广泛支持），②描边画在文字填充之上，细字号时可能遮住笔画内部。text-shadow 模拟优点：①标准属性兼容性极好；②可做柔和发光效果（用 blur）。缺点：①模拟描边需要 4-8 个方向的 shadow 拼合，代码冗长；②阴影是向外扩散的，描边不够锐利；③在斜角处可能出现缝隙或重叠。结论：需要精确描边用 text-stroke，需要发光效果或兼容旧浏览器用 text-shadow。
</Answer>

**问题 2**：`background-clip: text` 实现渐变文字时，为什么必须设 `color: transparent`？

<Answer>
background-clip: text 的作用是让元素的背景（如渐变）只裁剪到文字的形状内——文字形状以外的背景不可见。但文字本身仍有填充色（由 color 属性控制，默认黑色）。填充色绘制在背景之上，如果不设为透明，填充色会盖住渐变背景，你看到的还是纯色文字。设 color: transparent 后，文字填充区域变透明，透出下方的渐变背景——视觉上就是渐变色的文字。`-webkit-text-fill-color: transparent` 优先级高于 color，是更推荐的写法，因为某些浏览器中 color: transparent 可能被 user agent 样式覆盖。
</Answer>
