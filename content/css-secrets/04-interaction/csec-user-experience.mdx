## 直觉引入

好的体验是「感觉不到但有它更好」。点击导航链接，页面不是瞬移而是平滑滑到目标位置；用键盘 Tab 切换时，焦点环只在需要时出现——鼠标点击不显示、键盘操作才高亮；系统切到暗色模式，网页自动跟随。这些都不需要 JS——纯 CSS 就能搞定。

## 平滑滚动

<Term def="scroll-behavior: smooth 让滚动锚点跳转（如 #hash 链接、scrollTo）以动画方式平滑过渡，而非瞬间跳到目标位置。">平滑滚动</Term>只需一行 CSS。

```css
html {
  scroll-behavior: smooth;
}

/* 也可只对特定容器 */
.scroll-container {
  scroll-behavior: smooth;
  overflow-y: auto;
  height: 400px;
}
```

## 焦点高亮

`:focus` 在鼠标点击时也会触发——显得多余。`:focus-visible` 只在键盘导航时触发，更智能。

```css
/* 只在键盘导航时显示焦点环 */
button:focus-visible {
  outline: 2px solid #58a;
  outline-offset: 2px;
}

/* 鼠标点击时去掉默认焦点环 */
button:focus:not(:focus-visible) {
  outline: none;
}
```

## 暗色主题

`prefers-color-scheme` 媒体查询让网页自动跟随系统暗色模式——无需 JS、无需切换按钮。

```css
:root {
  --bg: #fff;
  --text: #333;
  --border: #ddd;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a2e;
    --text: #e0e0e0;
    --border: #333;
  }
}

body {
  background: var(--bg);
  color: var(--text);
}
```

## 常见误区

<Callout type="trap">
**误区：暗色主题只是把黑白反转。** 好的暗色主题不是简单取反——白色背景直接反转成纯黑（#000）会刺眼，暗色背景应该是深灰（#1a1a2e）而非纯黑。文字色不应是纯白（#fff）而应是浅灰（#e0e0e0）以降低对比疲劳。彩色在暗色背景上需要提亮饱和度才能保持视觉一致（如 #58a 在暗色模式应为 #7b9ee8）。阴影在暗色模式下应更深更不透明。这些调整需要设计系统层面的 token 映射，而非逐个属性覆盖。
</Callout>

<Exercises>
**问题 1**：`:focus-visible` 和 `:focus` 的区别是什么？为什么要用前者？

<Answer>
:focus 在元素获得焦点时触发——无论是键盘 Tab 还是鼠标点击。这意味着用户用鼠标点击按钮后，按钮会保留一个焦点环，视觉上显得多余和突兀。:focus-visible 是浏览器智能判断的伪类——只在「用户需要焦点提示时」触发，即键盘导航时。鼠标点击不触发 :focus-visible（浏览器认为用户已经知道焦点在哪），键盘 Tab 才触发。这样键盘用户能看到焦点位置（无障碍必需），鼠标用户不被多余焦点环打扰。最佳实践是 :focus-visible 设高亮样式、:focus:not(:focus-visible) 去掉默认环。
</Answer>

**问题 2**：`scroll-behavior: smooth` 设在 html 上和设在具体容器上有什么区别？

<Answer>
设在 html（或 :root）上时，影响整个文档的滚动行为——所有 #hash 锚点跳转、所有 scrollIntoView() 调用都会平滑滚动。这通常是全局期望的行为。设在具体容器上时，只影响该容器内部的滚动——当容器内容被滚动到可见区域时用平滑过渡。区别在于作用域：html 是全局文档滚动，容器是局部滚动区域。如果页面有多个可滚动区域（如侧边栏 + 主内容），可以分别控制各自的滚动行为。注意：scroll-behavior 不影响用户手动滚轮滚动，只影响程序化滚动（锚点跳转、scrollTo）。
</Answer>

<Glossary>
<GlossaryItem term="scroll-behavior: smooth">让程序化滚动（锚点跳转、scrollTo/scrollIntoView）以动画方式平滑过渡。设在 html 上影响全局文档滚动，设在容器上只影响该容器。</GlossaryItem>
<GlossaryItem term=":focus-visible">浏览器智能判断的焦点伪类，只在键盘导航时触发。相比 :focus（鼠标点击也触发），它能区分用户输入方式，避免鼠标点击后多余焦点环。</GlossaryItem>
<GlossaryItem term="prefers-color-scheme">CSS 媒体查询，检测用户系统偏好（light/dark）。配合 CSS 变量可实现自动暗色主题切换，无需 JS 和切换按钮。</GlossaryItem>
</Glossary>
