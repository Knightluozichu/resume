## 视觉旅程回顾

<Term def="一个卡片从背景到动效的完整路径：渐变铺底（第 2 章）→ 多重边框（第 3 章）→ clip-path 裁剪（第 4 章）→ 伪元素箭头（第 5 章）→ 描边渐变文字（第 6-7 章）→ 平滑滚动与 hover 动效（第 8-9 章）。">视觉旅程</Term>串联了全书所有章节。

```css
/* 全书视觉旅程：一个卡片从背景到动效 */
.card {
  /* 第 2 章：渐变背景 */
  background: linear-gradient(135deg, #6a5acd, #483d8b);

  /* 第 3 章：多重边框 + 圆角 */
  border-radius: 12px;
  box-shadow: 0 0 0 2px rgba(255,255,255,0.2);

  /* 第 4 章：clip-path 斜切顶部 */
  clip-path: polygon(0 0, 100% 0, 100% calc(100% - 20px), 0 100%);

  /* 第 6-7 章：渐变文字 + 等宽数字 */
  color: transparent;
  background-clip: text;
  font-variant-numeric: tabular-nums;

  /* 第 8-9 章：hover 动效（只合成不重排） */
  transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
.card:hover {
  transform: translateY(-4px);
}

/* 第 5 章：伪元素 tooltip 箭头 */
.card::after {
  content: "";
  clip-path: polygon(50% 0, 0 100%, 100% 100%);
}

/* 第 8 章：平滑滚动 */
html { scroll-behavior: smooth; }
```

## 选型判断矩阵

| 视觉需求 | 推荐方案 | 不推荐 | 原因 |
|---------|---------|-------|------|
| 条纹/网格背景 | repeating-linear-gradient | PNG 图片 | 矢量、零请求、可缩放 |
| 多重边框 | box-shadow spread | 嵌套 div | 不增 DOM、不影响布局 |
| 三角形/菱形 | clip-path: polygon | 透明 PNG | 矢量、可动画 |
| tooltip 箭头 | ::after + border 技巧 | 额外 HTML 标签 | 不增 DOM |
| 渐变文字 | background-clip: text | 图片文字 | 可搜索、可改 |
| 平滑锚点跳转 | scroll-behavior: smooth | JS scrollTo 动画 | 纯 CSS、无依赖 |
| 暗色主题 | prefers-color-scheme | JS 切换 class | 跟随系统、无闪烁 |

## 常见误区

<Callout type="trap">
**误区：每个技巧都独立记忆。** 全书的技巧不是孤立的——它们共享同一套 CSS 渲染层心智模型。条纹是渐变色标重合、多重边框是 box-shadow spread、tooltip 箭头是 border 三角形、clip-path 是坐标裁剪——底层都是「用 CSS 属性的副作用做非标用途」。理解了这个心智模型，你就能自己发明技巧：遇到新需求时问自己「哪个 CSS 属性的渲染行为恰好能表达这个效果？」。这是从「背 47 个技巧」到「掌握 CSS 渲染思维」的跨越。
</Callout>

<Exercises>
**问题 1**：用全书知识图谱描述「一个按钮从背景到动效」的完整渲染旅程。

<Answer>
一个按钮渲染全过程：①背景与形状——linear-gradient 铺底色、border-radius 画圆角、box-shadow spread 叠加多重边框（第 2-3 章）；②裁剪与伪元素——clip-path 裁出斜角造型、::after 伪元素画 tooltip 箭头（第 4-5 章）；③排版与字体——background-clip:text 让标题文字显示渐变、font-variant-numeric:tabular-nums 让数字等宽对齐（第 6-7 章）；④交互与动效——scroll-behavior:smooth 让锚点跳转平滑、:focus-visible 只在键盘导航时显焦点环、transition transform 做 hover 上浮（第 8-9 章）。4 层全部参与，一行样式背后是完整的 CSS 渲染思维。
</Answer>

**问题 2**：全书技巧共享的 CSS 渲染层心智模型是什么？

<Answer>
核心心智模型是「用 CSS 属性的渲染副作用做非标用途」。每个技巧都是发现某个 CSS 属性的渲染行为恰好能表达目标效果：渐变色标重合产生硬边 → 条纹；box-shadow spread 向外扩展 → 多重边框；border 拼三角 + transparent 隐藏三条 → 三角形箭头；background-clip:text 裁剪背景到文字形状 → 渐变文字；max-height 替代 height:auto → 可过渡的展开动画。这些属性的设计意图并非如此，但渲染机制恰好支持。掌握了这个思维，遇到新需求时可以问：哪个 CSS 属性的渲染行为能表达这个效果？从而自己发明技巧。
</Answer>
