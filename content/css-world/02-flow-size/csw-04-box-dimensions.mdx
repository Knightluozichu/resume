# 第 4 章 盒尺寸四大家族

本章是张鑫旭著《CSS 世界》中把基本尺寸拆成四层的核心章节，依据人民邮电出版社 2017 年 12 月版公开目录独立重构，不复制原书段落。技术解释以 CSS 2.1、作者公开资料和浏览器标准文档交叉核验；本章先完成普通盒与正常流基线，再把替换元素、表单控件和现代布局作为明确边界。

<Objectives>

- 能把 content、padding、margin、border 分别映射到内容承载、内边空间、外部间距和绘制边界。
- 能先预测再实验，解释百分比基准、替换元素、margin 合并、margin:auto、border 样式和盒尺寸模型的首个变化。
- 能用正常、窄容器、合并和边框图形样本记录计算值、使用值、外部尺寸、恢复结果与流体契约。

</Objectives>

## 从一个盒子的总宽度如何组成开始

看到盒子变宽、兄弟间距消失或三角形突然出现，先不要从最终截图猜属性。固定包含块、内容、字体和视口，先拆出<Term def="承载文本、替换内容或后代排版的盒模型最内层">content</Term>，再分别加上<Term def="内容与边框之间的内边空间">padding</Term>、<Term def="盒与外部邻接对象之间的外边空间">margin</Term>和<Term def="围绕内容与内边空间绘制的边界层">border</Term>。图中的四层盒、外边距样本和边框图形可以逐步播放；动手前先写出你预计的尺寸表达式。

## 三个必须先拆开的误区

<Callout type="trap" title="把 padding 和 margin 当成同一层空间">
  **现象：** 为了让文字离边缘更远，随意切换 padding 与
  margin，却无法解释背景和兄弟间距。**原因：**
  没有区分内边空间和外部占位。**修法：** 固定 content 和 border，分别改变
  padding、margin，记录内容盒、边界盒与邻接距离。
</Callout>

<Callout type="trap" title="把外边距合并当成尺寸丢失">
  **现象：** 两个块的 margin 相加后没有得到预期间距。**原因：**
  相邻块级正常流边界可能合并，父子边界也可能参与合并。**修法：**
  记录发生合并的边界条件，加入 padding、border 或格式化上下文改变后再比较。
</Callout>

<Callout type="trap" title="用透明 border 绘图却忘记它仍占尺寸">
  **现象：** 用透明边框做三角形后，布局宽高或命中区域变大。**原因：** border
  既参与盒尺寸，也参与绘制；透明不等于不存在。**修法：**
  分开验收几何占位、颜色透明度与绘制结果，不用截图隐藏外部尺寸变化。
</Callout>

## 四层盒的求解链

### 内容、内边、外边与边界

四层盒不是四个可随意交换的装饰属性。content 承载内容，padding 保护内容与边界之间的空间，margin 影响外部关系，border 提供可见或透明边界；最终外部尺寸还要结合包含块、格式化上下文和 box-sizing。

### 先算内部，再看外部

在固定 content、padding 和 border 后，margin 才能作为外部空间被观察。百分比 margin 和 padding 的参考基准、替换元素固有尺寸、auto 剩余空间和 margin 合并都需要单独记录，不能把所有数字简单相加。

## 出版社目录逐项映射

### 第4章 盒尺寸四大家族

本章把 content、padding、margin、border 放进同一张盒模型证据表。每个目录节点都回答：这层空间属于哪一个盒、百分比参考谁、会不会参与合并、会不会改变绘制或外部占位。

### 4.1 深入理解content

content 是内容承载层，可能来自文本、后代、替换内容或伪元素。先确定内容的固有尺寸和生成方式，再观察 padding、border 和 margin 如何包住它；内容层不是“剩下的像素”。

### 4.1.1 content与替换元素

替换元素拥有由外部资源或固有比例提供的尺寸来源，不能完全按普通文本盒推导。图片、表单控件和嵌入对象要锁定资源、加载状态和替代文本，再分别记录内容盒与外部边界。

### 4.1.2 content内容生成技术

伪元素、计数器和 attr 等内容生成方式会影响可见内容，但不应被误读为普通 DOM 子节点。实验需比较生成前后盒树、可访问语义、固有尺寸与使用值，确认内容出现在哪一个布局阶段。

### 4.2 温和的padding属性

padding 在内容与 border 之间形成内边空间，背景通常也覆盖到这里。它会增加边界盒尺寸，却不会直接改变兄弟之间的外部间距；实验要固定 margin，单独改变四个方向。

### 4.2.1 padding与元素的尺寸

padding 改变内容盒到边框的距离，也可能让总尺寸超出作者以为的 width。将 content-box 与 border-box 分别测量，才能说明指定 width 是内容尺寸还是边界尺寸。

### 4.2.2 padding的百分比值

padding 百分比需要明确参考尺寸，常见水平和垂直方向都与包含块宽度相关。窄视口实验应同时记录包含块宽度、四向 padding、内容区域和最终高度，不能只看 CSS 声明中的百分号。

### 4.2.3 标签元素内置的padding

浏览器或用户代理样式可能给按钮、输入框、列表项等标签预置 padding。重置样式前后要保存来源、计算值和实际尺寸；否则把内置 padding 误归因于作者规则，会污染盒模型结论。

### 4.2.4 padding与图形绘制

padding 可以为背景、图标和内容提供绘制缓冲区，但它不是 border。背景裁剪、背景色和可点击区域应与 content、padding 的尺寸一起验收，避免用颜色范围反推空间归属。

### 4.3 激进的margin属性

margin 位于盒外，改变的是盒与外部对象的关系。它可以产生空白、参与居中、触发合并或在某些格式化上下文中失效；所以“margin 没生效”必须先定位当前布局上下文。

### 4.3.1 margin与元素尺寸以及相关布局

元素的总外部尺寸由内容、padding、border 和 margin 共同影响，但 margin 不属于边界盒。外边距与 width、剩余空间和包含块共同决定布局位置，需把外部占位和内部尺寸分栏。

### 4.3.2 margin的百分比值

margin 百分比要记录它的参考基准、方向和包含块宽度。改变容器宽度而保持声明不变，若四向外边空间同步变化，应把原因写入计算证据，而不是称为浏览器的随机行为。

### 4.3.3 正确看待CSS世界里的margin合并

块级正常流的相邻外边距在特定边界可能发生<Term def="块级正常流的特定边界把相邻外边距合成为一个外部间距的规则">margin 合并</Term>，结果通常不是简单相加。用 padding、border、BFC 或内容改变边界后重放，比较合并前后的兄弟间距与父子位置，才能确定发生了哪类合并。

### 4.3.4 深入理解CSS中的margin:auto

<Term def="在允许的格式化上下文中把剩余空间分配给外边距的状态">
  margin:auto
</Term>
是剩余空间分配的参与者，不是无条件居中开关。需要明确
width、包含块、方向和格式化上下文；固定宽度的块可把剩余空间分到两侧，而内联或某些布局状态并不遵循同一分配路径。

### 4.3.5 margin无效情形解析

margin 可能因为内联盒、表格盒、绝对定位规则、合并边界或格式化上下文而表现不同。先确认元素是否拥有可作用的外部空间，再检查层叠和计算值，不能看到位置不变就断言属性被浏览器忽略。

### 4.4 功勋卓越的border属性

border 同时属于尺寸层和绘制层。宽度与样式改变边界盒，颜色和透明度改变可见几何；边框还能通过不同方向和透明组合构造图形，但透明边界仍可能占用空间。

### 4.4.1 为什么border-width不支持百分比值

边框宽度需要可预测的线宽和绘制几何，不能简单套用 padding 或 margin 的百分比基准。测试时对比无效百分比、长度值和用户代理回退，分别记录解析、计算和实际边框。

### 4.4.2 了解各种border-style类型

solid、dashed、double、groove 等样式改变边界的绘制算法与视觉结果。尺寸证据不能只看颜色；应同时保存宽度、样式、边界盒和像素几何，避免把绘制差异误当作空间差异。

### 4.4.3 border-color和color

border-color 可以继承 color 的当前值，也可以被单独指定。实验应先固定层叠来源，再切换 color 与 border-color，观察计算值、继承关系和四边绘制是否保持一致。

### 4.4.4 border与透明边框技巧

透明 border 常用于三角形、箭头和缺口图形。透明只影响绘制颜色，不会删除边框宽度；因此要同时记录几何占位、命中区域、相邻流位置与视觉轮廓。

### 4.4.5 border与图形构建

当一个零尺寸盒通过不同方向的边框形成图形时，图形的尖角、比例和方向来自边框宽度与颜色分配。把每一边单独开关，能确认绘制几何与 content 尺寸并非同一层。

### 4.4.6 border等高布局技术

用 border 模拟等高列时，视觉等高可能来自背景或边界绘制，并不意味着每个内容盒真实拥有相同高度。长内容、窄视口和键盘焦点样本要同时检查内容溢出与可访问区域。

## 盒尺寸证据记录

每个样本写六列：**content、padding、margin、border、计算值与使用值、恢复结果**。替换元素增加资源和固有尺寸，百分比增加包含块宽度，margin 增加合并边界，border 增加样式与透明度。截图只能辅助最后一列，不能替代四层空间的数值记录。

```text
outer = margin + border + padding + content
input = containing_block + content + one_changed_layer
branch = percentage_basis | margin_collapse | auto_space | border_paint
replay = remove_fault + same_inputs + outer_size_restored
```

```css
.avatar {
  box-sizing: border-box;
  width: 6rem;
  padding: 0.5rem;
  border: 0.25rem solid currentColor;
  margin-inline: auto;
}

.triangle {
  width: 0;
  border: 0.75rem solid transparent;
  border-top-color: currentColor;
}
```

第一个样本用于验证四层尺寸与 auto 分配，第二个样本用于验证透明边框的绘制几何。要研究百分比、内置样式或合并，另建单变量实验并保留恢复路径。

## 练习

<Exercises>

**问题 1：** 一个 `content-box` 元素的 width 不变，增加 padding 后为什么可能溢出容器？

<Answer>
  因为 width 指向内容盒，padding 和 border
  仍要加到外部边界；总外部尺寸超过包含块时就会溢出。切换 border-box
  会改变尺寸入口，但仍需检查内容最小尺寸与 min-width。
</Answer>

**问题 2：** 两个相邻块的 margin 没有相加，怎样证明这是 margin 合并？

<Answer>
  固定内容和宽度，只在边界加入 padding 或
  border，比较兄弟间距与父子位置；若边界被打断后间距改变，并且计算值仍保留各自
  margin，就能把变化归因于合并规则而不是声明丢失。
</Answer>

**问题 3：** 透明边框做出的三角形为什么仍然可能改变布局？

<Answer>
  透明只影响颜色绘制，border-width
  仍是边界盒的一部分，会改变总尺寸和命中区域。应分别检查几何占位、透明边和相邻流位置，再决定是否用伪元素或独立图层承载图形。
</Answer>

</Exercises>

## 小结

- content 承载内容，padding 留出内边空间，margin 影响外部关系，border 同时参与尺寸和绘制。
- 百分比必须写出参考基准；替换元素、用户代理样式和固有尺寸需要单独留证。
- margin 合并与 margin:auto 是两种不同机制，一个改变边界间距，一个分配剩余空间。
- 透明 border 仍占尺寸，盒模型验收必须同时检查外部占位、内部空间和视觉几何。
