## 直觉引入

文字排版的本质是两个问题：「在哪画线」和「在哪断行」。text-decoration 回答前者——上划线、删除线、下划线，三种装饰线可以叠加。white-space 回答后者——遇到空格断不断行？遇到换行符保不保留？五个取值排列组合出五种行为。理解这两个属性，就能精确控制文字的视觉呈现。

## text-decoration 三种线

<Term def="text-decoration 为文本添加装饰线，现代语法支持线型、样式、颜色分别设置，且可叠加多条。">text-decoration</Term> 的现代写法拆分为三个子属性：`text-decoration-line`（线型）、`text-decoration-style`（样式：solid/dashed/dotted/wavy）、`text-decoration-color`（颜色）。

```css
/* 经典写法 */
.del { text-decoration: line-through; }
.link { text-decoration: underline; }

/* 现代简写：线型 样式 颜色 */
.fancy {
  text-decoration: underline wavy red;
  /* 下划线 + 波浪样式 + 红色 */
}

/* 叠加多条线 */
.combo {
  text-decoration-line: underline overline;
  text-decoration-style: dashed;
}
```

## white-space 与换行控制

<Term def="white-space 控制元素内空白字符和换行符的处理方式，同时决定是否在空白处自动换行。">white-space</Term> 的五个取值可以按两个维度理解：**是否自动换行**（遇到容器边界）和**如何处理空白/换行符**。

```css
/* 单行省略：经典三件套 */
.ellipsis {
  white-space: nowrap;      /* 不换行 */
  overflow: hidden;         /* 溢出裁剪 */
  text-overflow: ellipsis;  /* 用省略号表示裁剪 */
}

/* pre：保留代码缩进和换行，不自动换行（适合短代码） */
.code { white-space: pre; }

/* pre-wrap：保留格式且可换行（适合长代码块） */
.code-block { white-space: pre-wrap; }
```

## 断词：word-break vs overflow-wrap

```css
/* word-break: break-all —— 在任意字符间断行（中文/英文都拆） */
.aggressive { word-break: break-all; }

/* word-break: keep-all —— 不拆词（中文字之间不断行） */
.cjk { word-break: keep-all; }

/* overflow-wrap: break-word —— 仅在词放不下时才拆词 */
.url-safe { overflow-wrap: break-word; }
/* 长 URL 超出容器时才断行，正常词保持完整 */
```

## 常见误区

<Callout type="trap">
**误区：`white-space: nowrap` 就能让文字不换行。** nowrap 只是「不在空格处自动换行」，但如果文本中有显式换行符（`\n`）或 `<br>`，仍然会换行。nowrap 合并空白、忽略换行符，但 HTML 的 `<br>` 是元素不是文本换行符，不受 white-space 控制。另一个常见坑是 `word-break: break-all` 会把英文单词从中间拆开，在英文为主的场景下阅读体验很差，应优先用 `overflow-wrap: break-word`（只在词放不下时才拆），保留单词完整性。
</Callout>

<Exercises>
**问题 1**：white-space 的五个取值分别如何处理「自动换行」和「空白/换行符」？

<Answer>
normal：空格处自动换行，合并空白、忽略换行符（默认）。nowrap：不自动换行，合并空白、忽略换行符。pre：不自动换行，保留空白和换行符（等宽呈现）。pre-wrap：空格处可换行，保留空白和换行符。pre-line：空格处可换行，合并空白、保留换行符。记忆：normal 是基础；nowrap 关掉换行；pre 保留一切但不换行；pre-wrap 加上换行；pre-line 保留换行符但合并空白。
</Answer>

**问题 2**：实现单行文字溢出省略号需要哪三个属性？为什么缺一不可？

<Answer>
三件套：`white-space: nowrap`（不换行，让文字溢出而非折行）、`overflow: hidden`（裁剪溢出部分）、`text-overflow: ellipsis`（在裁剪处显示省略号）。缺 nowrap：文字会折行，没有溢出可裁剪。缺 overflow:hidden：溢出文字直接显示，不裁剪。缺 text-overflow:ellipsis：裁剪但不显示省略号，文字直接被截断。三者配合才能实现「一行排满 → 裁剪 → 省略号」的完整效果。多行省略需用 `-webkit-line-clamp` 等不同方案。
</Answer>
