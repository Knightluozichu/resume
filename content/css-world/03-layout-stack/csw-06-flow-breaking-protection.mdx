## 核心机制深挖

浮动仍影响行盒环绕，absolute 则从正常流尺寸计算中退出并以包含块定位。BFC 能包裹浮动并隔离外部影响，overflow 同时带来剪裁、滚动容器和锚点定位副作用。 每个脱流元素都必须标注原流中缺失的空间、实际包含块、层叠位置和恢复策略；relative 只用于最小范围约束，不能无节制包裹整页。 实验时把浏览器开发者工具中的盒模型、计算样式和层叠上下文当成观测工具，而不是答案来源；答案必须能从规范规则和当前 DOM 结构推导出来。先删除非必要覆盖，再逐条加入约束，这样才能分辨默认流在做什么、哪条声明真正改变了结果。
