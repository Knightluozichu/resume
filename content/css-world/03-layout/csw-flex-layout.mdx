## 直觉引入

Flex 是一维弹性布局——一条主轴上排元素。核心思想是「剩余空间按比例分配」。容器装下所有项目后如果有多余空间，flex-grow 决定谁多吃；如果空间不够，flex-shrink 决定谁多让。主轴方向由 flex-direction 决定（row 水平 / column 垂直），justify-content 管主轴对齐，align-items 管交叉轴对齐。记住：Flex 只管一条轴，这是它和 Grid（同时管两条轴）的根本区别。

## 主轴与交叉轴

<Term def="主轴（main axis）是 flex 项目排列的方向轴，由 flex-direction 决定；交叉轴（cross axis）垂直于主轴。">主轴/交叉轴</Term>的方向决定了 justify-content 和 align-items 作用的方向。`flex-direction: row` 时主轴水平，justify-content 管水平对齐，align-items 管垂直对齐；`flex-direction: column` 时主轴垂直，两者互换。

```css
.container {
  display: flex;
  flex-direction: row; /* 主轴水平（默认） */
  justify-content: center;   /* 主轴居中 */
  align-items: center;       /* 交叉轴居中 */
  /* 两句配合 = 水平垂直双居中 */
}
```

## flex 三属性

<Term def="flex 简写 = flex-grow flex-shrink flex-basis，分别控制放大、收缩、基准尺寸。">flex 简写</Term>是最容易混淆的部分。flex-grow 按比例分配**剩余空间**（容器减去所有 basis 后多出的部分）；flex-shrink 空间不足时按权重收缩；flex-basis 是分配前的初始尺寸。

```css
/* flex: 1 → 1 1 0%（可放大可缩小，基准 0 → 纯按比例分） */
.a { flex: 1; }  /* 三项各 flex:1 → 等分全部空间 */

/* flex: 2 → 2 1 0%（占 2 份） */
.b { flex: 2; }  /* 与 flex:1 搭配 → 2:1 分配 */

/* flex: none → 0 0 auto（不伸缩，按内容尺寸） */
.fixed { flex: none; width: 200px; }

/* flex: auto → 1 1 auto（可伸缩，基准取内容尺寸） */
.auto { flex: auto; }
```

## 对齐控制

```css
/* justify-content：主轴对齐 */
.space-between { justify-content: space-between; } /* 两端对齐，间距均分 */
.space-around  { justify-content: space-around; }  /* 每项两侧间距相等 */

/* align-items：交叉轴对齐（所有项目统一） */
.stretch { align-items: stretch; }   /* 默认，填满交叉轴 */
.center { align-items: center; }     /* 居中 */

/* align-self：单个项目交叉轴对齐（覆盖 align-items） */
.special { align-self: flex-end; }   /* 这个项目单独靠底 */
```

## 常见误区

<Callout type="trap">
**误区：`flex: 1` 等于 `flex: 1 1 1px`。** 不对。`flex: 1` 的完整展开是 `1 1 0%`——flex-basis 是 0% 而非 1px。这意味着项目在分配空间前的初始尺寸是 0，所有空间都是「剩余空间」按 flex-grow 比例分。而 `flex: 1 1 1px` 的 basis 是 1px，项目先占 1px 再分剩余空间——当有多个项目时，结果可能不同（尤其配合 min-content 时）。另一个坑是 `flex: 1` 不等于 `flex-grow: 1`：只写 flex-grow:1 时 flex-basis 默认是 auto（取 width 或内容尺寸），而非 0%，分配逻辑完全不同。
</Callout>

<Exercises>
**问题 1**：flex 简写的三个组成部分各是什么含义？`flex: 1` 的完整展开是什么？

<Answer>
flex = flex-grow flex-shrink flex-basis。flex-grow：剩余空间按此比例放大分配（默认 0 不放大）；flex-shrink：空间不足时按此比例收缩（默认 1 可收缩）；flex-basis：分配前的初始尺寸（默认 auto，取 width 或内容尺寸）。`flex: 1` 完整展开是 `1 1 0%`：可放大（grow:1）、可收缩（shrink:1）、初始尺寸 0（basis:0%），所以所有空间都是剩余空间按 grow 比例分。注意 `flex: 1` ≠ `flex-grow: 1`，后者 basis 默认 auto。
</Answer>

**问题 2**：用 Flex 实现一个「左侧固定 200px，右侧自适应填满」的布局。

<Answer>
```css
.container { display: flex; }
.sidebar { flex: 0 0 200px; }  /* 不放大不收缩，固定 200px */
.main { flex: 1; }             /* flex: 1 1 0%，占据所有剩余空间 */
```
原理：sidebar 的 flex-basis 为 200px 且 grow:0 不抢剩余空间；main 的 basis 为 0%、grow:1，独占容器减去 200px 后的全部剩余空间。容器宽度变化时，sidebar 始终 200px，main 自适应伸缩。注意 sidebar 用 `flex: 0 0 200px` 而非 `width: 200px`，这样 flex-shrink:0 确保空间不足时也不被压缩。
</Answer>
</Exercises>

<GlossaryItem term="justify-content vs align-items">justify-content 管主轴对齐（flex-start/center/space-between 等），align-items 管交叉轴对齐（stretch/flex-start/center 等）。两者配合实现双轴居中。align-self 可覆盖单个项目的交叉轴对齐。</GlossaryItem>
