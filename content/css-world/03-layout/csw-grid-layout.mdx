## 直觉引入

Grid 是二维布局——同时控制行和列。想象一个棋盘：你定义几列几行，每个项目可以放在某个格子里，也可以跨几个格子。fr 单位像切蛋糕——`1fr 2fr 1fr` 把可用空间切成 1:2:1 三份。和 Flex 的区别：Flex 是一维的（一次管一条轴），Grid 是二维的（同时管行列），所以页面整体骨架用 Grid，局部排列用 Flex。

## 行列轨道与 fr 单位

<Term def="fr 是 Grid 的弹性单位，按比例分配容器去掉固定尺寸和 gap 后的剩余空间。">fr 单位</Term>在固定尺寸（如 px）之后分配。容器 400px、gap 20px、`1fr 2fr 1fr`：先扣两个 gap 共 40px，剩余 360px 按 1:2:1 分 → 90/180/90px。

```css
.grid {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;  /* 三列 1:2:1 */
  grid-template-rows: 60px 1fr 60px;    /* 三行，中间自适应 */
  gap: 20px;                            /* 行列间距 */
}

/* 混合固定与弹性 */
.sidebar-layout {
  grid-template-columns: 200px 1fr;  /* 侧栏固定，主区自适应 */
}
```

## grid-area 线定位

<Term def="网格线（Grid Line）是行列轨道之间的分隔线，编号从 1 开始，grid-column/grid-row 用「起线/终线」定位项目。">网格线定位</Term>用 `起线 / 终线` 表示跨哪些轨道。`grid-column: 1 / 3` 表示从第 1 条线到第 3 条线，跨 2 列轨道。也可用 `span N` 表示跨 N 个轨道。

```css
/* 经典页面骨架 */
.page {
  display: grid;
  grid-template-columns: 200px 1fr 150px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
  min-height: 100vh;
}
.header { grid-area: header; }
.main   { grid-area: main; }
.footer { grid-area: footer; }

/* 或用线定位 */
.cross-2-col {
  grid-column: 1 / 3;      /* 跨第 1-2 列 */
  grid-column: span 2;     /* 等价：自动跨 2 列 */
}
```

## gap 间距

```css
.grid {
  gap: 20px;            /* 行列同距 20px */
  row-gap: 10px;        /* 行间距单独设 */
  column-gap: 20px;     /* 列间距单独设 */
}
/* gap 不计入 fr 分配的剩余空间，先扣 gap 再分 fr */
```

## 常见误区

<Callout type="trap">
**误区：Grid 和 Flex 是二选一的关系。** 它们是互补的。Grid 擅长二维整体骨架（页面有几行几列、谁跨谁），Flex 擅长一维局部排列（一行按钮怎么排、一个卡片内部怎么对齐）。实际项目通常是 Grid 做外层骨架、Flex 做内层排列。另一个误区是以为 `grid-template-areas` 只是语法糖——它实际上是「命名网格区域」的语义化方式，让布局意图一目了然，且区域名会自动生成隐式网格线（如 header-start/header-end），比纯数字线定位更易维护。
</Callout>

<Exercises>
**问题 1**：fr 单位如何分配空间？容器 400px、gap 20px、`grid-template-columns: 1fr 2fr 1fr` 时各列宽度是多少？

<Answer>
fr 按比例分配「剩余空间」——先扣除固定尺寸和 gap，再按 fr 比例分。容器 400px，3 列有 2 个 gap 共 40px，剩余 400 - 40 = 360px。1fr 2fr 1fr 共 4 份，每份 360/4 = 90px。所以三列分别为 90px / 180px / 90px。关键：fr 在固定尺寸和 gap 之后分配，如果还有固定列（如 200px 1fr），先扣 200px 和 gap，剩余才给 fr。fr 不是绝对宽度，是比例份额。
</Answer>

**问题 2**：用 Grid 实现一个「header 跨全宽、中间三列、footer 跨全宽」的页面骨架。

<Answer>
```css
.page {
  display: grid;
  grid-template-columns: 200px 1fr 150px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "nav    main   aside"
    "footer footer footer";
  min-height: 100vh;
  gap: 16px;
}
.header { grid-area: header; }
.nav    { grid-area: nav; }
.main   { grid-area: main; }
.aside  { grid-area: aside; }
.footer { grid-area: footer; }
```
用 grid-template-areas 命名区域，语义清晰，header 和 footer 重复三列名表示跨全宽。也可用线定位：`grid-column: 1 / -1`（-1 表示最后一条线）跨全部列。areas 方式可读性更好，适合复杂骨架。
</Answer>
</Exercises>

<GlossaryItem term="fr 单位">Grid 弹性单位，按比例分配去掉固定尺寸和 gap 后的剩余空间。1fr 2fr 1fr = 1:2:1。不是绝对宽度，是份额。</GlossaryItem>
<GlossaryItem term="网格线定位">行列轨道间的分隔线，从 1 编号。grid-column: 1/3 跨第 1-2 轨道，span 2 自动跨 2 轨道。grid-template-areas 用命名区域语义化定位，可读性更好。</GlossaryItem>
<GlossaryItem term="Grid vs Flex">Grid 二维（同时管行列，适合整体骨架），Flex 一维（管一条轴，适合局部排列）。互补关系，实际项目 Grid 做外层骨架、Flex 做内层排列。</GlossaryItem>
