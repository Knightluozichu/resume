## 核心机制深挖

字体选择是逐字符匹配回退链；font-weight 数字不保证一定存在对应字形，浏览器可能合成。em 相对自身字号，rem 相对根字号，ex 关联 x-height。断行还受语言、空白和连续字符影响。 文本验收至少覆盖中英文、数字、长 URL、缺失网络字体、放大字号和不同字重；仅在本机字体齐全时截图不能证明排版稳定。 实验时把浏览器开发者工具中的盒模型、计算样式和层叠上下文当成观测工具，而不是答案来源；答案必须能从规范规则和当前 DOM 结构推导出来。先删除非必要覆盖，再逐条加入约束，这样才能分辨默认流在做什么、哪条声明真正改变了结果。
