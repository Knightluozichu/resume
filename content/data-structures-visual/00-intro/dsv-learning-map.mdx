## 直觉引入

想象你要整理一万本书。如果随手堆成一座山，找一本特定的书可能要翻半天；但如果你按字母排序放进书架，查找只需几秒。数据结构就是「数据的书架」——它决定了数据怎么摆放，直接影响查找、插入、删除的效率。

《大话数据结构》用通俗的语言把这些「书架」从最简单的数组一路讲到复杂的图，再配上排序与查找算法。全书的核心思想只有一句话：**没有最好的数据结构，只有最适合场景的数据结构**。

## 全书四段结构

<DsvBookMap />

全书分四大板块，呈「数据怎么存 → 结构怎么变 → 数据怎么处理」的递进关系：

1. **入门**（2 章）：讲清数据结构的基本概念与算法复杂度的大 O 表示法，这是后续所有章节的分析工具。
2. **线性结构**（2 章）：数组、链表、栈、队列——数据排成一条线，是一切结构的基础。
3. **树结构**（3 章）：二叉树、堆、图——从一维线性跳到二维分叉，解决层次与网络关系。
4. **算法应用**（3 章）：排序与查找是数据结构的两大应用场景，总复习串联全书。

## 学习路径与前置依赖

<Stepper>
<Step title="第一步：入门奠基">
先学基本概念（什么是数据结构、逻辑结构与物理结构的区别）和算法复杂度（大 O 表示法）。这两章是工具箱——后续每一章分析操作效率时都要用大 O 来度量。跳过这一步，后面看到 $O(n \log n)$ 会一头雾水。
</Step>
<Step title="第二步：线性结构">
数组与链表是两种最基本的存储方式（连续 vs 链式），理解它们的取舍是理解所有高级结构的前提。栈和队列是受限的线性结构，分别服务「后进先出」和「先进先出」两种场景。
</Step>
<Step title="第三步：树与图">
树是一对多关系的结构，二叉搜索树把「查找」从 $O(n)$ 降到 $O(\log n)$。堆是特殊的完全二叉树，优先队列的底层。图是多对多关系，是最通用的结构，BFS/DFS 是图遍历的两大基本策略。
</Step>
<Step title="第四步：算法应用">
排序把无序变有序，查找在有序或无序中定位目标。最后总复习把全书知识点串联起来，用一道综合题检验你是否真正理解了「选对结构、用对算法」。
</Step>
</Stepper>

## 代码对照

```python
# 数据结构选择的直觉：同一问题，不同结构天差地别
# 场景：维护一个动态集合，频繁查找最大值

# 方案A：用数组，每次找最大值要遍历全部
def find_max_array(arr):
    return max(arr)  # O(n)，每次都要扫一遍

# 方案B：用最大堆，堆顶就是最大值
def find_max_heap(heap):
    return heap[0]  # O(1)，直接取堆顶

# 如果查找最大值是高频操作，堆远优于数组
# 这就是「选对数据结构」的价值
```

## 常见误区

<Callout type="trap">
**误区：背了一堆数据结构的定义，却不知道什么时候该用哪个。**
数据结构不是用来背的，而是用来选的。学每种结构时，核心问题永远是：它擅长什么操作？不擅长什么操作？在什么场景下用它最划算？
</Callout>

<Callout type="trap">
**误区：认为数据结构和算法是两个独立的东西。**
数据结构是「数据的组织形式」，算法是「操作数据的步骤」。两者密不可分——同一个算法在不同数据结构上效率天差地别，同一个数据结构配不同算法也效果迥异。选结构就是在选算法的基础。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？它们之间是什么关系？

<Answer>
入门、线性结构、树结构、算法应用。呈递进关系：入门提供分析工具（大 O），线性结构是基础存储方式，树与图是更复杂的结构，算法应用是数据结构的实战场景。后段依赖前段的理解。
</Answer>

**问题 2**：为什么说「没有最好的数据结构，只有最适合场景的数据结构」？

<Answer>
因为每种数据结构都有取舍：数组查找快但插入删除慢，链表插入删除快但查找慢，树折中但实现复杂。选择取决于具体场景中哪些操作是高频的——高频查找用数组或哈希表，高频插入删除用链表，需要有序遍历用树。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="数据结构">
计算机存储、组织数据的方式，它决定了数据的访问效率与操作成本。常见类型包括数组、链表、栈、队列、树、图等。
</GlossaryItem>
<GlossaryItem term="逻辑结构">
数据元素之间的逻辑关系，与存储无关。分为线性结构（一对一）、树结构（一对多）、图结构（多对多）。
</GlossaryItem>
<GlossaryItem term="物理结构">
数据在计算机内存中的实际存储方式，主要分为顺序存储（连续内存）和链式存储（指针连接）。
</GlossaryItem>
<GlossaryItem term="算法复杂度">
用大 O 表示法度量算法运行时间或空间随输入规模增长的趋势，是评估数据结构操作效率的通用工具。
</GlossaryItem>
</Glossary>
