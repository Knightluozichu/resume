## 直觉引入

栈就像一摞盘子——你只能在最上面放盘子（push），也只能从最上面拿盘子（pop），先放的盘子最后才能拿到。队列就像排队买票——先到的人先买到票走人（dequeue），后到的人排在最后（enqueue），讲究先来后到。

栈和队列本质上是**受限的线性表**——只允许在特定端操作，这种限制反而带来了清晰的语义和高效的使用场景。

## 概念讲解

### 栈：后进先出

<DsvStacksQueuesDiagram />

<Term def="栈是只允许在一端（栈顶）进行插入和删除的线性结构，遵循后进先出原则">
栈
</Term>

栈的两个核心操作：**push**（压栈，把元素放入栈顶）和 **pop**（弹栈，取出栈顶元素）。两者都是 $O(1)$。还有 **peek**（查看栈顶但不弹出）。

栈的限制看似严格，却天然契合很多场景：

- **函数调用栈**：函数 A 调用 B，B 调用 C。C 先返回给 B，B 再返回给 A。最后调用的最先返回，正是 LIFO。
- **括号匹配**：遇到左括号压栈，遇到右括号弹栈匹配。栈空且无失配 = 匹配成功。
- **撤销操作（Undo）**：每步操作压栈，撤销就弹栈，最后做的最先撤销。

### 队列：先进先出

<Term def="队列是允许在一端（队尾）插入、另一端（队头）删除的线性结构，遵循先进先出原则">
队列
</Term>

队列的两个核心操作：**enqueue**（入队，从队尾添加）和 **dequeue**（出队，从队头取出）。两者都是 $O(1)$。

队列的典型应用：

- **BFS 广度优先搜索**：把起点入队，每次取出一个节点处理，把它的邻居入队。先发现的先处理，正是 FIFO。
- **任务调度**：操作系统进程调度，先到的进程先分配 CPU。
- **生产者-消费者**：生产者往队列里放数据，消费者从队列里取数据，解耦两者速率。

<Stepper>
<Step title="用栈实现括号匹配">
遍历字符串，遇到 `(`、`[`、`{` 压栈；遇到 `)`、`]`、`}` 时弹栈检查是否匹配。遍历结束后栈为空 = 全部匹配成功。
</Step>
<Step title="用队列实现 BFS">
起点入队并标记已访问。循环：出队一个节点，处理它，把所有未访问的邻居入队并标记。队列为空时遍历结束。
</Step>
<Step title="用两个栈实现队列">
栈 A 负责入队（push 到 A），栈 B 负责出队。出队时若 B 为空，把 A 中所有元素依次弹出压入 B（顺序反转），再从 B 弹出。均摊 $O(1)$。
</Step>
</Stepper>

### 循环队列

用数组实现队列时，反复出队会导致队头前方的空间浪费。循环队列把数组视为环形：`rear = (rear + 1) % capacity`，队头队尾在环上移动，充分利用空间。判满条件：`(rear + 1) % capacity == front`（牺牲一个位置区分空和满）。

## 代码对照

```python
# 栈的实现（基于列表）
class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):      # O(1) 压栈
        self.items.append(item)

    def pop(self):             # O(1) 弹栈
        return self.items.pop()

    def peek(self):            # O(1) 查看栈顶
        return self.items[-1]

    def is_empty(self):
        return len(self.items) == 0

# 队列的实现（基于 collections.deque，双端队列）
from collections import deque

class Queue:
    def __init__(self):
        self.items = deque()

    def enqueue(self, item):   # O(1) 入队
        self.items.append(item)

    def dequeue(self):         # O(1) 出队
        return self.items.popleft()

    def is_empty(self):
        return len(self.items) == 0

# 括号匹配：栈的经典应用
def is_valid(s):
    stack = Stack()
    pairs = {')': '(', ']': '[', '}': '{'}
    for ch in s:
        if ch in '([{':
            stack.push(ch)
        elif ch in ')]}':
            if stack.is_empty() or stack.pop() != pairs[ch]:
                return False
    return stack.is_empty()
```

## 常见误区

<Callout type="trap">
**误区：用 Python 列表的 pop(0) 实现队列出队。**
`list.pop(0)` 是 $O(n)$——它需要把后面所有元素前移。应该用 `collections.deque` 的 `popleft()`，它是 $O(1)$ 的双端队列。这是初学者最常犯的性能错误。
</Callout>

<Callout type="trap">
**误区：混淆栈和队列的使用场景。**
需要「回退/撤销/最近优先」用栈（LIFO）；需要「公平调度/先来后到」用队列（FIFO）。搞反了会导致逻辑错误——比如用栈做 BFS 会变成 DFS 的效果。
</Callout>

<Exercises>
**问题 1**：入栈顺序是 1, 2, 3, 4，以下哪个不可能是合法的出栈顺序？

<Answer>
出栈顺序 3, 1, 2, 4 不可能。分析：要弹出 3，必须先压入 1, 2, 3，此时栈中 [1, 2, 3]。弹出 3 后栈 [1, 2]，下一个只能弹 2，不可能弹 1。合法的出栈顺序有：4 3 2 1（全部压入再弹出）、1 2 3 4（压一个弹一个）等。
</Answer>

**问题 2**：为什么循环队列要牺牲一个存储位置？

<Answer>
因为需要区分「队空」和「队满」两种状态。如果用满所有位置，队空时 `front == rear`，队满时也是 `front == rear`，无法区分。牺牲一个位置后，队空 `front == rear`，队满 `(rear + 1) % capacity == front`，两种状态可区分。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="栈">
只允许在栈顶进行插入（push）和删除（pop）的线性结构，遵循后进先出（LIFO）原则，所有操作 O(1)。
</GlossaryItem>
<GlossaryItem term="队列">
允许在队尾插入（enqueue）、队头删除（dequeue）的线性结构，遵循先进先出（FIFO）原则，所有操作 O(1)。
</GlossaryItem>
<GlossaryItem term="LIFO">
Last In First Out，后进先出。栈的核心特性：最后压入的元素最先弹出。
</GlossaryItem>
<GlossaryItem term="循环队列">
用数组实现的环形队列，通过取模运算让队头队尾在环上移动，避免出队后前方空间浪费。
</GlossaryItem>
</Glossary>
