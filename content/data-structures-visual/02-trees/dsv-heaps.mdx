## 直觉引入

医院的急诊室不按先来后到排队——病情最重的优先看。这种「永远先处理最重要/最紧急」的需求就是优先队列，而堆是它的最佳底层实现。

堆是一棵特殊的完全二叉树：大顶堆中每个节点的值都 $\geq$ 它的子节点，所以堆顶永远是最大值。取最大值 $O(1)$，插入新元素 $O(\log n)$，比数组（取最大 $O(n)$ 或维护有序数组插入 $O(n)$）都高效。

## 概念讲解

### 堆的定义

<DsvHeapsDiagram />

<Term def="堆是完全二叉树且满足堆序性：大顶堆每个节点值≥子节点值，小顶堆每个节点值≤子节点值">
堆
</Term>

堆有两个关键性质：
1. **完全二叉树**：除了最后一层，其他层全满；最后一层从左到右排列。这意味着可以用数组紧凑存储，无指针开销。
2. **堆序性**：大顶堆中父节点 $\geq$ 子节点；小顶堆中父节点 $\leq$ 子节点。注意：堆序性只保证父子的关系，**不保证左右子的大小关系**（这与 BST 不同）。

### 数组表示与下标关系

因为是完全二叉树，堆可以用数组存储，下标关系简洁：

- 节点 $i$ 的父节点：$(i-1) / 2$（整数除法）
- 节点 $i$ 的左子：$2i + 1$
- 节点 $i$ 的右子：$2i + 2$

### 堆的核心操作

<Stepper>
<Step title="插入（上浮 / sift up）">
把新元素放在数组末尾（保持完全二叉树），然后与父节点比较：如果比父大（大顶堆），就交换，继续上浮，直到满足堆序性或到根。每层比较+交换 $O(1)$，树高 $O(\log n)$，总计 $O(\log n)$。
</Step>
<Step title="删除堆顶（下沉 / sift down）">
取走堆顶（最大值）后，把末尾元素移到堆顶，然后与较大的子节点比较：如果比子小，就交换下沉，直到满足堆序性或到叶子。同样是 $O(\log n)$。
</Step>
<Step title="建堆（heapify）">
从最后一个非叶子节点开始，从右到左、从下到上依次下沉调整。每个节点下沉 $O(\log n)$，共 $n/2$ 个节点，但总体只需 $O(n)$（不是 $O(n \log n)$，因为大多数节点在底层，下沉距离短）。
</Step>
</Stepper>

### 堆排序

堆排序 = 建堆 + 反复取堆顶。先 $O(n)$ 建大顶堆，然后每次把堆顶（最大值）与末尾交换，堆大小减一，下沉调整。重复 $n$ 次，每次 $O(\log n)$，总计 $O(n \log n)$。堆排序是原地排序，最坏也是 $O(n \log n)$，但常数比快排大。

## 代码对照

```python
class MaxHeap:
    def __init__(self):
        self.heap = []

    def push(self, val):
        """插入：放末尾，上浮"""
        self.heap.append(val)
        self._sift_up(len(self.heap) - 1)

    def pop(self):
        """删除堆顶：末尾移到顶，下沉"""
        if len(self.heap) == 0:
            return None
        top = self.heap[0]
        self.heap[0] = self.heap[-1]  # 末尾移到堆顶
        self.heap.pop()
        if self.heap:
            self._sift_down(0)
        return top

    def _sift_up(self, i):
        """上浮：与父比较，大则交换"""
        while i > 0:
            parent = (i - 1) // 2
            if self.heap[i] > self.heap[parent]:
                self.heap[i], self.heap[parent] = self.heap[parent], self.heap[i]
                i = parent
            else:
                break

    def _sift_down(self, i):
        """下沉：与较大子比较，小则交换"""
        n = len(self.heap)
        while True:
            left = 2 * i + 1
            right = 2 * i + 2
            largest = i
            if left < n and self.heap[left] > self.heap[largest]:
                largest = left
            if right < n and self.heap[right] > self.heap[largest]:
                largest = right
            if largest != i:
                self.heap[i], self.heap[largest] = self.heap[largest], self.heap[i]
                i = largest
            else:
                break

    def peek(self):
        """查看堆顶（最大值）O(1)"""
        return self.heap[0] if self.heap else None
```

## 常见误区

<Callout type="trap">
**误区：认为堆的遍历能得到有序序列。**
堆只保证父 $\geq$ 子（大顶堆），不保证左右子的关系，更不保证整体有序。中序遍历 BST 得到升序，但遍历堆得不到有序序列。要排序需要用堆排序（反复取堆顶）。
</Callout>

<Callout type="trap">
**误区：建堆的时间复杂度是 $O(n \log n)$。**
虽然看起来是 $n/2$ 个节点各下沉 $O(\log n)$，但底层节点下沉距离短（叶子不下沉，倒数第二层只下沉 1 步...），通过数学求和可证明建堆是 $O(n)$，不是 $O(n \log n)$。
</Callout>

<Exercises>
**问题 1**：数组 `[50, 30, 40, 10, 20, 35]` 是一个大顶堆吗？

<Answer>
是。验证：节点 0(50) 的子节点是 1(30) 和 2(40)，50≥30 且 50≥40。节点 1(30) 的子节点是 3(10) 和 4(20)，30≥10 且 30≥20。节点 2(40) 的子节点是 5(35)，40≥35。所有父子关系满足大顶堆性质。且数组对应完全二叉树，所以是合法的大顶堆。
</Answer>

**问题 2**：为什么优先队列用堆而不是有序数组？

<Answer>
有序数组取最小值 $O(1)$ 但插入 $O(n)$（要移动元素保持有序）。堆取最小值 $O(1)$（堆顶），插入 $O(\log n)$（上浮）。在「频繁插入+频繁取最值」的场景（如 Dijkstra、任务调度），堆的总效率远高于有序数组。而且堆是数组实现，无指针开销，缓存友好。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="堆">
满足堆序性的完全二叉树。大顶堆中父节点值≥子节点值，小顶堆中父节点值≤子节点值。可用数组紧凑存储。
</GlossaryItem>
<GlossaryItem term="完全二叉树">
除最后一层外所有层都满，最后一层从左到右连续排列的二叉树。保证可用数组无空洞存储。
</GlossaryItem>
<GlossaryItem term="上浮">
堆插入操作：新元素放末尾后，与父节点比较，不满足堆序性就交换上移，直到满足或到根。O(log n)。
</GlossaryItem>
<GlossaryItem term="优先队列">
一种抽象数据结构，每次出队的是优先级最高（或最低）的元素，而非最早入队的元素。堆是其最优底层实现。
</GlossaryItem>
</Glossary>
