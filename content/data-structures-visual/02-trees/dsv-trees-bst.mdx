## 直觉引入

公司的组织架构是一棵树：CEO 在最顶层，下面是各部门 VP，VP 下面是经理，经理下面是员工。从 CEO 到任何一个员工，路径唯一。树结构天然适合表达「一对多」的层次关系。

二叉搜索树更进一步：它给树加了一个规则——左子节点比父小，右子节点比父大。这样查找一个值时，每次比较就能排除一半子树，就像二分查找一样，把 $O(n)$ 的线性查找降到 $O(\log n)$。

## 概念讲解

### 树的基本概念

<DsvTreesBstDiagram />

<Term def="树是由 n 个节点组成的有限集合，有且仅有一个根节点，其余节点分为若干互不相交的子树">
树
</Term>

树的术语：**根**（唯一顶层节点）、**叶子**（无子节点的节点）、**深度**（根到节点的边数）、**高度**（节点到最深叶子的边数）。**二叉树**是每个节点最多两个子节点的树。

### 二叉树遍历

<Stepper>
<Step title="前序遍历（根→左→右）">
先访问根节点，再递归遍历左子树，最后递归遍历右子树。前序遍历的第一个节点一定是根。适合复制树结构。
</Step>
<Step title="中序遍历（左→根→右）">
先递归遍历左子树，再访问根，最后递归遍历右子树。对 BST 做中序遍历，得到的序列恰好是升序排列的。这是 BST 最重要的特性。
</Step>
<Step title="后序遍历（左→右→根）">
先递归遍历左子树，再递归遍历右子树，最后访问根。后序遍历的最后一个节点一定是根。适合释放树内存（先释放子节点再释放根）。
</Step>
</Stepper>

### 二叉搜索树（BST）

<Term def="二叉搜索树是左子节点值小于根、右子节点值大于根的二叉树，支持 O(log n) 查找插入删除">
二叉搜索树
</Term>

BST 的核心性质：对任意节点，左子树所有值 < 节点值 < 右子树所有值。这个性质使得三个操作高效：

- **查找**：从根开始，比根小往左走，比根大往右走，走到空则不存在。每层排除一半，$O(\log n)$（平衡时）。
- **插入**：类似查找，找到空位置挂上去。$O(\log n)$。
- **删除**：分三种情况——叶子直接删；单子节点用子节点替代；双子节点用后继（右子树最小值）替代。$O(\log n)$。

## 代码对照

```python
class TreeNode:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None

# BST 插入
def insert(root, val):
    if root is None:
        return TreeNode(val)
    if val < root.val:
        root.left = insert(root.left, val)   # 比根小往左
    elif val > root.val:
        root.right = insert(root.right, val)  # 比根大往右
    return root  # 相等不插入（去重）

# BST 查找
def search(root, val):
    if root is None or root.val == val:
        return root
    if val < root.val:
        return search(root.left, val)   # 往左找
    return search(root.right, val)      # 往右找

# 中序遍历（BST 得到升序序列）
def inorder(root, result):
    if root:
        inorder(root.left, result)    # 左
        result.append(root.val)       # 根
        inorder(root.right, result)   # 右

# 用法
root = None
for v in [50, 30, 70, 20, 40, 60, 80]:
    root = insert(root, v)
sorted_list = []
inorder(root, sorted_list)  # [20, 30, 40, 50, 60, 70, 80] ← 自动排序！
```

## 常见误区

<Callout type="trap">
**误区：认为 BST 的查找一定是 $O(\log n)$。**
BST 的 $O(\log n)$ 查找前提是树「平衡」。如果按顺序插入 1, 2, 3, 4, 5，BST 会退化成一条链（每个节点只有右子），查找变成 $O(n)$。这就是为什么需要平衡二叉树（AVL、红黑树）——它们在插入删除时自动调整形态保持平衡。
</Callout>

<Callout type="trap">
**误区：BST 删除双子节点时直接删掉就行。**
删除有左右子节点的节点不能直接删——会断掉两棵子树。正确做法是用「右子树的最小值」（或左子树的最大值）替换被删节点的值，然后删除那个最小值节点（它最多有一个右子）。这样 BST 性质不变。
</Callout>

<Exercises>
**问题 1**：对 BST 做中序遍历得到的序列有什么特点？为什么？

<Answer>
得到升序排列的序列。因为中序遍历的顺序是「左→根→右」，而 BST 的性质是左子树所有值 < 根 < 右子树所有值。所以中序遍历先访问小的（左），再访问根，最后访问大的（右），天然有序。
</Answer>

**问题 2**：按顺序 1, 2, 3, 4, 5 插入 BST，树会退化成什么形态？查找复杂度变成多少？

<Answer>
退化成一条向右倾斜的链（每个节点只有右子节点）。查找复杂度从 $O(\log n)$ 退化为 $O(n)$，等价于链表。这就是需要平衡树的原因——AVL 树或红黑树会在插入后自动旋转保持平衡，确保高度始终 $O(\log n)$。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="二叉树">
每个节点最多有两个子节点（左子、右子）的树结构，是树结构中最基础也最重要的形态。
</GlossaryItem>
<GlossaryItem term="二叉搜索树">
左子树所有值小于根、右子树所有值大于根的二叉树。支持 O(log n) 的查找、插入、删除（平衡时），中序遍历得到升序序列。
</GlossaryItem>
<GlossaryItem term="中序遍历">
二叉树遍历方式之一，顺序为「左子树→根→右子树」。对 BST 做中序遍历得到升序序列。
</GlossaryItem>
<GlossaryItem term="平衡二叉树">
任意节点的左右子树高度差不超过 1 的二叉搜索树（如 AVL 树），确保查找复杂度始终 O(log n)，不退化为链。
</GlossaryItem>
</Glossary>
