## 从“一对多层次”开始

树把线性表的唯一后继扩展为层次关系：除根外每个结点有唯一双亲，一个结点可有多个孩子；子树本身仍是树，因此定义天然递归。官方第6章依次覆盖树的定义、结点与关系，树的抽象数据类型与存储结构，二叉树的定义、特点与性质，二叉树的顺序存储与二叉链表，前序、中序、后序遍历，二叉树的建立，线索二叉树，树、森林与二叉树的转换，以及哈夫曼树与哈夫曼编码。

先预测：同一组结点只有前序与中序能否唯一恢复二叉树；完全二叉树中编号`i`的父结点如何计算；中序遍历中大量NULL child指针能否用来保存前驱/后继；哈夫曼树为何每次合并两个最小权值。

禁止普通树出现环或多父结点，否则应建模为图。

## 树的定义、结点与关系

的度是孩子数；树的度是所有结点度的最大值。度为0的结点是叶子/终端结点，度非0的是分支结点。根在第1层，孩子层次加1；树的深度/高度是最大层次。

同一双亲的孩子互为兄弟；结点的祖先是从根到其双亲路径上的结点，后代是其子树中所有结点。多个互不相交树组成森林；删除一棵树的根，其子树构成森林。与树可通过孩子兄弟表示互相转换。

边数提供基础校验：非空树有`n-1`条父子边，因为除根外每个结点恰有一条入父边。若遍历发现边数不符，可能存在多父、环、断开或计数错误。

## 树的抽象数据类型与存储结构

树ADT可提供root、parent、first_child、next_sibling、insert_child、remove_subtree、traverse和clear。操作必须声明孩子顺序是否有意义；本章按有序树处理，兄弟先后不能任意交换。

向上找父结点常数时间，找全部孩子需扫描或附加索引。枚举孩子高效，向上找父结点需额外字段。统一每结点两个指针，是后续树转二叉树的基础。

```c
#include <stddef.h>

typedef char Element;

typedef struct TreeNode {
    Element value;
    struct TreeNode *first_child;
    struct TreeNode *next_sibling;
} TreeNode;

size_t tree_size(const TreeNode *root) {
    if (root == NULL) return 0;
    size_t total = 1;
    for (const TreeNode *child = root->first_child;
         child != NULL;
         child = child->next_sibling) {
        total += tree_size(child);
    }
    return total;
}
```

这个表示中的`next_sibling`不是“右孩子”业务语义，但把它视作二叉树right链接可复用二叉遍历/转换。Owner通常是根拥有整棵子树；删除结点时先递归释放first_child森林，再沿sibling处理，避免重复释放。

## 二叉树的定义、特点与性质

不是“度不超过2的普通树”这么简单，因为左右有序。空二叉树也是合法值。


### 二叉树性质

第`i`层最多有：

$$
N_i \le 2^{i-1}\qquad(i\ge1)
$$

深度为`k`的二叉树最多有满树结点数：

$$
N \le \sum_{i=1}^{k}2^{i-1}=2^k-1
$$

任意非空二叉树，若叶结点数为`n0`、度为2的结点数为`n2`，则边数一方面是`n-1`，另一方面是`n1+2n2`；结合`n=n0+n1+n2`得：

$$
n_0=n_2+1
$$

完全二叉树按0-based层序存入数组：非根`i`的父为`(i-1)/2`，左孩子`2i+1`，右孩子`2i+2`，但孩子索引必须小于`n`。

$$
parent(i)=\left\lfloor\frac{i-1}{2}\right\rfloor,
\quad left(i)=2i+1,
\quad right(i)=2i+2
$$

这些是结构上界与关系，不自动说明树平衡。任意二叉树深度可达`n`；只有完全/平衡约束才给对数高度。

## 二叉树的顺序存储与二叉链表

对完全树紧凑，稀疏斜树会浪费大量槽位。Heap正因形状完全而适合数组。

只为存在结点分配空间，适合一般形状；代价是链接和分配。若还需父指针，必须保持child-parent双向一致。

```c
#include <stdlib.h>

typedef struct BinaryNode {
    Element value;
    struct BinaryNode *left;
    struct BinaryNode *right;
} BinaryNode;

typedef void (*Visit)(Element value, void *context);

void preorder(const BinaryNode *node, Visit visit, void *context) {
    if (node == NULL) return;
    visit(node->value, context);
    preorder(node->left, visit, context);
    preorder(node->right, visit, context);
}

void inorder(const BinaryNode *node, Visit visit, void *context) {
    if (node == NULL) return;
    inorder(node->left, visit, context);
    visit(node->value, context);
    inorder(node->right, visit, context);
}

void postorder(const BinaryNode *node, Visit visit, void *context) {
    if (node == NULL) return;
    postorder(node->left, visit, context);
    postorder(node->right, visit, context);
    visit(node->value, context);
}
```

三种遍历都访问每结点一次，时间`Theta(n)`，递归辅助栈`Theta(h)`。斜树`h=n`可能溢出调用栈；显式stack需保存等价frame phase。Callback失败如何停止遍历和传播status，也要进入API契约。

## 前序、中序、后序遍历

适合先处理父结点与带空标记序列化。在BST中产生有序key，但普通二叉树没有自动排序。适合先处理/释放孩子再处理父。


只给前序不能唯一确定形状；前序+中序在结点值唯一时可恢复，重复值需identity/位置消歧。前序加每个NULL child标记也可唯一恢复，这是更直接的序列化契约。

## 二叉树的建立

下面从前序token构建，`#`表示空。Parser cursor是共享状态，每次调用消费一个token；任意分配/输入失败必须释放已建子树，并让调用者知道消费位置。

```c
typedef struct {
    const char *tokens;
    size_t length;
    size_t cursor;
} PreorderSource;

bool build_preorder(PreorderSource *source, BinaryNode **out) {
    if (source == NULL || out == NULL || source->cursor >= source->length) {
        return false;
    }
    char token = source->tokens[source->cursor++];
    if (token == '#') { *out = NULL; return true; }

    BinaryNode *node = calloc(1, sizeof(*node));
    if (node == NULL) return false;
    node->value = token;
    if (!build_preorder(source, &node->left)
        || !build_preorder(source, &node->right)) {
        destroy_binary(node);
        return false;
    }
    *out = node;
    return true;
}
```

完整输入验收还要在根构建成功后检查`cursor == length`，否则尾部多余token应报错。`destroy_binary`用后序释放。为了strong guarantee，`*out`只在整个子树成功后写入。

## 线索二叉树

二叉链表有`n+1`个NULL child链接（总链接`2n`减边`n-1`）。把这些空位变成导航信息。

中序线索化维护`previous`：若当前left为空，令left指向中序前驱并设`ltag=THREAD`；若previous的right为空，令其right指向当前后继并设`rtag=THREAD`。遍历时只有tag为CHILD才进入子树，否则沿thread走。修改树结构后线索可能全部或局部失效，API必须重建或维护，不能把thread当child递归造成环。

## 树、森林与二叉树的转换

普通树用孩子兄弟表示时，`first_child`映射二叉树left，`next_sibling`映射right；一片森林把各树根按right链接。逆变换时，二叉结点的left及其连续right链恢复为孩子列表，森林root right链拆成多棵树。

必须保持兄弟顺序和结点identity。验证可做round trip：tree -> binary -> tree后每个结点的parent、children序列与payload一致。

## 哈夫曼树与哈夫曼编码

给叶子权值，带权路径长度`WPL`是每个叶权乘根到叶深度之和：

$$
WPL(T)=\sum_{i=1}^{m} w_i d_i
$$

通过反复选择两个最小权子树合并构造；交换论证说明小权值应更深，两个最小可以成为最深兄弟，递归合并保持最优。Priority queue使构建`O(m log m)`。

把符号放叶子，因此任何码字都不是另一完整码字的前缀，可无分隔解码。权值相同可能产生不同但同WPL编码；测试不要锁死唯一bit pattern，应验证prefix-free、往返和总加权长度。


## 统一验证：结构、遍历、owner与深度

每个树API先验证无环、唯一父结点和可达结点数；二叉树再验证left/right owner。遍历与独立迭代器输出对照；建树/序列化round trip；故障注入每个malloc位置，检查部分子树全部释放。深树使用显式栈或限制depth，防不可信输入耗尽调用栈。

遍历callback若可失败，函数应返回status并立即停止，不再访问后续结点；清理显式stack/queue后把原错误交给调用者。若callback允许修改结构，当前指针可能失效，最简单契约是遍历期间禁止结构修改；需要修改时先收集稳定ID或使用专门迭代器协议。

对来自文件/网络的“树”不能默认真是树。先以结点ID解析到临时图，检查唯一根、每个非根入度1、无环且全部可达，再commit为owner树。否则递归size/destroy可能无限循环或重复释放共享子结点。防御validator应有visited集合和结点/深度上限。

规模测试分别构造满树、完全树、左右斜树和随机树；比较递归/显式遍历输出和峰值辅助空间。斜树暴露`Theta(n)`深度，满树验证计数公式，随机树检查形状不应被值重复干扰。序列化还要限制token数量和递归深度，拒绝超限而非构建到OOM。


## 本章回顾：结构递归，证据不能递归省略

1. 普通树以唯一父结点形成层次；双亲、孩子、孩子兄弟表示优化不同导航。
2. 二叉树左右有序，满/完全是不同形状约束；性质可由层容量、边数和编号推导。
3. 顺序表示适合完全形状，二叉链表适合一般树；三种深度优先遍历只改变visit时机。
4. 建树需要足够序列信息和失败清理；线索树以tag安全复用空链接。
5. 孩子兄弟规则连接树、森林和二叉树；哈夫曼树最小化WPL并产生prefix-free编码。
