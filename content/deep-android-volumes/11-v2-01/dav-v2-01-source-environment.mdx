## 章专属复现实验

```bash
mkdir -p aosp-android-4.0.1_r1
cd aosp-android-4.0.1_r1
repo init -u https://android.googlesource.com/platform/manifest -b android-4.0.1_r1
repo sync -c

# 只在可恢复的同版本模拟器或测试机采集
adb shell getprop ro.build.fingerprint
adb shell ps
```

运行前保存主机工具链、manifest与产品目标；这些历史分支通常需要隔离的旧工具链环境。诊断命令只在可恢复模拟器或测试机执行，账号、媒体与设备标识使用隔离样本；现代设备输出不得冒充android-4.0.1_r1结果。
