## 从一个可失败的问题开始

卷III 第5章 深入理解Android输入系统不是类名清单，而是在android-4.2.2_r1中回答：贯通Linux事件、EventHub、InputReader、InputDispatcher、InputChannel到窗口反馈。先预测请求经过的线程、进程与对象所有者，再运行正常样本；如果event设备、原始/映射事件、焦点窗口、派发队列、socket通道、finish信号、ANR计时不能指出首个变化，本页结论仍不可交接。

本章不变量是在android-4.2.2_r1固定输入下，贯通Linux事件、EventHub、InputReader、InputDispatcher、InputChannel到窗口反馈的入口身份、状态拥有者、成功结果、错误返回和资源释放均可重复观察。将“只追踪触摸到View，遗漏设备发现、策略过滤、反馈和超时状态”作为反例，必须在同一版本、同一输入下看到确定的错误或状态分叉，并能恢复到基线。
