## 这本书讲什么

《深度学习入门2：自制框架》（斋藤康毅）是《深度学习入门》的续作。如果说第一部的主题是「用 NumPy 从零实现神经网络」，那么第二部的主题就是「用 Python 从零打造一个深度学习框架」——这个框架在书中命名为 DeZero。

核心理念：不调用 PyTorch 或 TensorFlow，而是亲手实现自动微分引擎、计算图、层、优化器和模型，让读者理解一个深度学习框架到底由哪些零件组成，以及它们如何协作。

全书的知识体系可以划分为三个层次：

- **基础引擎层**：Variable 与 Function——定义「数据 + 运算」的基本抽象，搭建计算图
- **自动微分层**：反向传播与梯度——让框架具备「自动求导」能力，这是框架的灵魂
- **框架工程层**：层、模型、优化器、训练——把零件组装成可用的深度学习框架

## 核心理念：自制框架

<Callout type="info">

**关键洞察**：本书不是教你怎么「用」框架，而是教你怎么「造」框架。当你亲手实现过自动微分、计算图和反向传播后，再面对 PyTorch 的 `loss.backward()` 就能做到知其然且知其所以然。这正是从「调包侠」到「工程师」的跃迁。

</Callout>

自制框架的三个原因：

| 原因 | 说明 |
|------|------|
| 理解原理 | 框架的自动微分隐藏了计算图构建和反向传播过程，亲手实现让一切透明 |
| 掌握抽象 | 学会如何用类、继承、组合来设计可扩展的计算框架 |
| 迁移能力 | 理解框架内部机制后，使用任何框架都能快速定位问题、优化性能 |

## 从手动计算到框架自动化的三个跃迁

<Callout type="tip">

**阅读策略**：建议按顺序阅读 ch1-ch4，建立从框架设计到自动微分的完整理解链。ch5 优化器可与 ch4 对照阅读。ch6-ch7 是框架工程化封装，需要前 5 章基础。ch8 把所有零件组装成完整训练流程。ch9 帮助建立全局视野。

</Callout>

1. **数据抽象跃迁**：裸 NumPy 数组 → Variable 类（包装数据 + 记录计算图），使运算可追溯
2. **求导自动化跃迁**：手写梯度公式 → 自动微分引擎（构建计算图 + 反向传播），使任意复杂函数可自动求导
3. **工程化跃迁**：散落的运算函数 → Layer/Model/Optimizer 模块化封装，使框架可复用、可扩展

## 六个核心概念预览

| 概念 | 一句话解释 | 详细章节 |
|------|-----------|---------|
| Variable | 包装 NumPy 数据并记录计算图的容器 | ch3 |
| Function | 定义运算并连接计算图的可复用单元 | ch3 |
| 计算图 | 用节点和边表示运算的有向无环图 | ch2 |
| 反向传播 | 沿计算图反向传递梯度的算法 | ch4 |
| Layer | 封装参数与运算的模块化单元 | ch6 |
| Model | 组合多个 Layer 的网络容器 | ch7 |

<Glossary>

<GlossaryItem term="DeZero">
本书从零打造的深度学习框架，名字取自「Deep Learning from Zero」。它用纯 Python + NumPy 实现，包含 Variable、Function、自动微分、层、模型、优化器等完整组件，是理解工业框架（PyTorch/TensorFlow）内部机制的微型标本。
</GlossaryItem>

<GlossaryItem term="Variable">
DeZero 的核心数据结构，包装 NumPy ndarray 并记录计算图。每个 Variable 持有 data（前向值）、grad（梯度）、creator（产生它的 Function），通过 creator 链接形成计算图。是自动微分的基础。
</GlossaryItem>

<GlossaryItem term="计算图">
用节点表示运算、用边表示数据流动的有向无环图（DAG）。DeZero 在前向传播时自动构建计算图，反向传播时沿图反向传递梯度。计算图让任意复杂运算的梯度计算系统化、自动化。
</GlossaryItem>

<GlossaryItem term="自动微分">
让计算机自动计算函数导数的技术。分正向模式（前向累计）和反向模式（反向传播）。深度学习用反向模式——一次前向、一次反向即可算出损失对所有参数的梯度，效率远高于数值微分。
</GlossaryItem>

<GlossaryItem term="反向传播">
沿计算图从输出到输入反向传递梯度的算法，利用链式法则逐节点计算。DeZero 的 backward 方法从输出 Variable 开始，递归调用各 Function 的 backward，直到输入端。
</GlossaryItem>

<GlossaryItem term="Layer">
封装参数（权重/偏置）与前向/反向运算的模块化单元。Linear 层、Sigmoid 层等可像积木一样组合，构建复杂网络。Layer 基类管理参数收集与梯度清零，是框架工程化的关键抽象。
</GlossaryItem>

</Glossary>

### 问题 1

《深度学习入门2：自制框架》一书的核心理念是什么？与第一部有何区别？

<Answer>

斋藤康毅的《深度学习入门2》核心理念是「亲手打造深度学习框架」——不调用 PyTorch 或 TensorFlow，而是用 Python + NumPy 从零实现一个名为 DeZero 的框架，包含 Variable、Function、自动微分、层、模型、优化器等完整组件。与第一部的区别：第一部（深度学习入门）的主题是「用 NumPy 从零实现神经网络」，重点是理解神经网络原理（前向传播、反向传播、CNN）；第二部的主题是「从零打造框架」，重点从「理解算法」升级到「设计框架抽象」——如何用类和继承构建可扩展的计算图引擎、如何实现自动微分、如何把运算封装成层和模型。简言之，第一部教你理解「神经网络怎么工作」，第二部教你理解「框架怎么工作」。
</Answer>

### 问题 2

全书的十章如何组织？分为哪几个层次？

<Answer>

全书十章分为三个层次：①基础引擎层（ch0-ch3）——学习地图定位方向，框架设计确立目标，自动微分奠定理论基础，Variable/Function 实现数据与运算的基本抽象，搭建计算图。②自动微分层（ch4-ch5）——梯度与反向传播让框架具备自动求导能力（这是框架的灵魂），优化器实现参数更新（SGD/Momentum/Adam）。③框架工程层（ch6-ch8）——层与模块化把散落的运算封装成可复用的 Layer，模型架构设计用 Model 容器组合多层网络，训练与评估把所有零件组装成完整训练流程（损失函数+数据集+训练循环+精度评估）。ch9 是全书复习与知识整合。这种从「零件」到「引擎」到「整车」的递进是本书的组织主线。
</Answer>

### 问题 3

为什么本书强调「自制框架」而不是直接学习 PyTorch？

<Answer>

本书强调自制框架的三个原因：①理解原理——使用框架时只需调用 `loss.backward()`，但读者无法理解计算图如何构建、梯度如何沿图反向传递、自动微分引擎到底做了什么。亲手实现让一切透明。②掌握抽象——框架设计是一门工程艺术：如何用 Variable 类包装数据、如何用 Function 类抽象运算、如何用 Layer 封装参数、如何用 Model 组合网络。这些抽象能力是从工程师到框架设计者的关键。③迁移能力——理解框架内部机制后，再使用任何框架都能快速上手、定位问题、优化性能。比如理解 DeZero 的计算图后，看 PyTorch 的 autograd 源码就不再陌生。这正是从「调包侠」到「工程师」的跃迁。
</Answer>

### 问题 4

全书的十章内容如何形成一个完整的框架知识闭环？

<Answer>

全书十章形成一个「抽象→引擎→工程→闭环」的知识闭环：①确立目标（ch0-ch1）——学习地图定位方向，框架设计明确 DeZero 要做什么（自动微分+可组合运算）。②基础抽象（ch2-ch3）——自动微分提供理论（计算图+链式法则），Variable/Function 提供实现（数据容器+运算单元+计算图连接），二者合一是「可追溯运算」的基础引擎。③自动求导（ch4-ch5）——反向传播让引擎具备自动求导能力（框架的灵魂），优化器让框架能更新参数（框架的手脚）。④工程封装（ch6-ch7）——Layer 把运算+参数封装成积木，Model 把积木组合成网络，使框架可复用、可扩展。⑤完整闭环（ch8）——训练与评估把损失、数据、训练循环、精度评估串联为完整工作流。ch9 帮助读者将以上全部整合为完整认知框架。
</Answer>
