## 为什么这一步不能跳过

步骤5 反向传播的理论知识 的增量不是 API 名称，而是把 **整体函数需要一次性求导** 变为 **局部 backward 可沿图组合**。它的核心机制是：链式法则把复合函数的局部导数按反向路径相乘，计算图明确每个中间变量的责任。

这一步验收时固定输入数组、随机种子、DeZero 前一步版本与运行设备。先写出预期的 forward、shape、creator 或状态变化，再执行实现；backward 后清空派生梯度并从相同输入重放。这样才能区分本步能力与缓存、旧图或随机性的偶然结果。

<Callout type="info" title="本步硬合同">
  前向证据、反向证据和重置后重放必须同时一致。沿前向方向乘导数或漏掉一条局部边会得到方向正确但数值错误的梯度
  时，即使最终 loss 或输出合理，也应判定 步骤5 反向传播的理论知识 失败。
</Callout>

## 最小实现草图

```python
# 反向传播的理论知识：解析梯度必须由独立数值差分核对
x = Variable(np.array(0.5))
y = target(x)
y.backward(create_graph=False)
assert relative_error(x.grad, central_diff(target, x)) < 1e-4
```
