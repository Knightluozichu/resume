## 为什么这一步不能跳过

步骤9 让函数更易用 的增量不是 API 名称，而是把 **调用类实例且手工初始化梯度** 变为 **函数式 API 仍委托核心图协议**。它的核心机制是：包装函数、默认输出梯度与 as_array 让 DeZero 运算像普通 Python 函数，同时保持 ndarray 合同。

这一步验收时固定输入数组、随机种子、DeZero 前一步版本与运行设备。先写出预期的 forward、shape、creator 或状态变化，再执行实现；backward 后清空派生梯度并从相同输入重放。这样才能区分本步能力与缓存、旧图或随机性的偶然结果。

<Callout type="info" title="本步硬合同">
  前向证据、反向证据和重置后重放必须同时一致。接受标量后不转为 ndarray 会在
  shape、dtype 或后续函数中产生分叉 时，即使最终 loss 或输出合理，也应判定 步骤9
  让函数更易用 失败。
</Callout>

## 最小实现草图

```python
# 让函数更易用：解析梯度必须由独立数值差分核对
x = Variable(np.array(0.5))
y = target(x)
y.backward(create_graph=False)
assert relative_error(x.grad, central_diff(target, x)) < 1e-4
```
