## 三种求导方法对比

要让框架自动求导，有三种可选方法：

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| 数值微分 | 用差分近似：`(f(x+h) - f(x-h)) / (2h)` | 实现简单、无需公式 | 精度低（截断误差+舍入误差）、速度慢 |
| 符号微分 | 用代数规则推导导数表达式 | 精确 | 表达式膨胀、难以处理控制流 |
| 自动微分 | 将计算分解为基本运算，用链式法则累计 | 精确、高效、支持任意复杂函数 | 需要构建计算图 |

<Callout type="info">

**关键洞察**：自动微分（Automatic Differentiation, AD）是数值微分和符号微分的「完美中间路线」——它像符号微分一样精确（无截断误差），又像数值微分一样实用（自动处理任意函数）。深度学习框架全部采用自动微分。

</Callout>

## 计算图与链式法则

<Dl2AutomaticDifferentiationDiagram />

自动微分的基础是**计算图**和**链式法则**。

### 链式法则

对于复合函数 `y = f(g(x))`，导数为：

```text
dy/dx = (df/dg) * (dg/dx)
```

在计算图上，每个节点是一个基本运算，链式法则就是**沿路径把各节点的局部导数相乘**。

### 计算图示例

以 `z = (x + y)^2` 为例，分解为两个基本运算：

```text
节点1: t = x + y        局部导数 dt/dx = 1, dt/dy = 1
节点2: z = t^2          局部导数 dz/dt = 2t

链式法则: dz/dx = (dz/dt) * (dt/dx) = 2t * 1 = 2(x+y)
```

## 正向模式

正向模式（forward-mode AD）沿计算图**前向**传递导数。

### 原理

每个节点在计算前向值的同时，还计算并传递「当前输出对某个输入的导数」。

```python
# z = (x + y)^2，求 dz/dx
# 正向模式：从 x 出发，沿计算图前向累计导数

t = x + y           # 前向值
dt_dx = 1           # t 对 x 的导数（加法节点：原样传递）

z = t ** 2          # 前向值
dz_dt = 2 * t       # z 对 t 的导数（乘方节点）

dz_dx = dz_dt * dt_dx   # 链式法则：相乘
# 结果 = 2t * 1 = 2(x+y)
```

### 效率分析

正向模式一次前向传播只能算出**对一个输入**的导数。若有 N 个输入，需要 N 次前向传播。

## 反向模式

反向模式（reverse-mode AD）沿计算图**反向**传递梯度。这就是深度学习中的**反向传播**。

### 原理

先做一次前向传播计算所有节点的输出值，然后从输出端开始，反向传递「输出对当前节点的导数」。

```python
# z = (x + y)^2，求 dz/dx 和 dz/dy
# 反向模式：从 z 出发，沿计算图反向累计梯度

# 第 1 步：前向传播（记录所有中间值）
t = x + y
z = t ** 2

# 第 2 步：反向传播（从输出端开始）
dz_dz = 1               # 输出对自身的导数
dz_dt = dz_dz * (2 * t) # 乘方节点的反向：2t * 1
dz_dx = dz_dt * 1       # 加法节点的反向：原样传递
dz_dy = dz_dt * 1       # 加法节点的反向：原样传递
# 一次反向传播，同时得到 dz/dx 和 dz/dy
```

### 效率分析

反向模式一次反向传播能同时算出**输出对所有输入**的导数。无论有多少个输入，只需一次前向 + 一次反向。

## 正向 vs 反向：效率对比

<Callout type="warning">

**核心结论**：正向模式的代价与输入数量成正比（N 个输入需 N 次传播），反向模式的代价与输出数量成正比（M 个输出需 M 次传播）。深度学习的场景是「1 个损失 → 数百万个参数」，即 1 个输出、N 个输入，因此反向模式效率远高于正向模式。

</Callout>

| 场景 | 输入数 N | 输出数 M | 最优模式 | 传播次数 |
|------|---------|---------|---------|---------|
| 深度学习 | 数百万 | 1 | 反向模式 | 1 次前向 + 1 次反向 |
| 雅可比矩阵 | N | M（M 小） | 正向模式 | M 次 |
| 一般情况 | N | M | N < M 用正向，N > M 用反向 | min(N, M) |

## 反向模式的实现要点

反向模式需要解决两个问题：

1. **前向时记录计算图**：每个运算的输入和局部导数必须保存，供反向传播使用
2. **反向时按拓扑序遍历**：必须从输出端到输入端按依赖顺序处理，保证一个节点的梯度在被使用前已计算完毕

```python
# 反向传播的拓扑排序核心逻辑
def backward(self):
    # 拓扑排序：从输出端收集所有节点，按依赖顺序排列
    funcs = []
    seen_set = set()

    def add_func(f):
        if f not in seen_set:
            seen_set.add(f)
            funcs.append(f)

    add_func(self.creator)
    while funcs:
        f = funcs.pop()           # 取出最后一个（保证拓扑序）
        gys = [output.grad for output in f.outputs]
        gxs = f.backward(*gys)    # 调用该节点的反向计算
        # 将梯度传给输入，并继续回溯
```

<Glossary>

<GlossaryItem term="数值微分">
用差分近似导数的方法：`f'(x) ≈ (f(x+h) - f(x-h)) / (2h)`（中心差分）。优点是实现极简，无需导数公式。缺点是截断误差（O(h^2)）和舍入误差（h 太小时浮点精度不足），且对每个参数需独立计算，效率低。适合做梯度检验（gradient check）验证反向传播正确性。
</GlossaryItem>

<GlossaryItem term="符号微分">
用代数规则（如 `d(uv)/dx = u'v + uv'`）推导导数的符号表达式。优点是精确。缺点是表达式膨胀（复合函数展开后公式急剧膨胀）和难以处理控制流（if/while 分支）。不适合作为框架的求导引擎。
</GlossaryItem>

<GlossaryItem term="自动微分（AD）">
将计算分解为基本运算（加、乘、sin、exp 等），用链式法则沿计算图累计导数的技术。兼具符号微分的精确性和数值微分的实用性。分正向模式（前向累计）和反向模式（反向传播）。深度学习框架全部采用反向模式自动微分。
</GlossaryItem>

<GlossaryItem term="正向模式（forward-mode AD）">
沿计算图前向传递导数，每个节点在计算前向值的同时计算并传递「输出对某输入的导数」。一次前向传播只能算出对一个输入的导数，N 个输入需 N 次传播。适合输入少、输出多的场景（如雅可比矩阵计算）。
</GlossaryItem>

<GlossaryItem term="反向模式（reverse-mode AD）">
即反向传播。先前向传播记录计算图，再从输出端反向传递梯度。一次反向传播能同时算出输出对所有输入的导数。代价是需存储前向计算的中间值（内存开销）。深度学习场景（1 个损失、数百万参数）下效率远高于正向模式。
</GlossaryItem>

<GlossaryItem term="链式法则">
复合函数求导法则：`d(f(g(x)))/dx = f'(g(x)) * g'(x)`。在计算图上，链式法则表现为沿路径把各节点的局部导数相乘。是自动微分的数学基础。对于多路径（一个输入影响多个节点），梯度沿各路径分别计算后相加。
</GlossaryItem>

</Glossary>

### 问题 1

数值微分、符号微分和自动微分各有何优缺点？为什么深度学习框架选择自动微分？

<Answer>

三种求导方法对比：①数值微分——用差分近似 `f'(x) ≈ (f(x+h)-f(x-h))/(2h)`。优点是实现极简，无需导数公式。缺点是截断误差（O(h^2)）和舍入误差（h 太小时浮点精度不足），且对每个参数需独立计算效率低。适合做梯度检验。②符号微分——用代数规则推导导数符号表达式。优点是精确。缺点是表达式膨胀（复合函数展开后公式急剧膨胀）和难以处理控制流（if/while 分支）。③自动微分——将计算分解为基本运算，用链式法则沿计算图累计导数。兼具符号微分的精确性（无截断误差）和数值微分的实用性（自动处理任意函数）。深度学习框架选择自动微分的原因：精确（不像数值微分有误差）、高效（反向模式一次反向传播即可算出损失对所有参数的梯度）、通用（支持任意可导函数和控制流）。
</Answer>

### 问题 2

正向模式和反向模式自动微分各自的原理是什么？效率有何区别？

<Answer>

正向模式：沿计算图前向传递导数。每个节点在计算前向值的同时，计算并传递「当前输出对某个输入的导数」。一次前向传播只能算出对一个输入的导数，N 个输入需要 N 次传播。反向模式：先前向传播记录计算图（保存中间值），再从输出端反向传递梯度。每个节点接收「输出对本节点的导数」，乘以局部导数后传给输入。一次反向传播能同时算出输出对所有输入的导数。效率区别：正向模式的传播次数 = 输入数 N，反向模式的传播次数 = 输出数 M。当 N > M 时反向模式更优，N < M 时正向模式更优。深度学习场景是「1 个损失（M=1）→ 数百万参数（N 巨大）」，故反向模式远优于正向模式。反向模式的代价是需要存储前向计算的中间值（内存开销），这是用空间换时间。
</Answer>

### 问题 3

以 `z = (x + y)^2` 为例，用反向模式计算 dz/dx 和 dz/dy，写出每一步。

<Answer>

以 `z = (x + y)^2` 为例，分解为两个基本运算：节点 1 `t = x + y`，节点 2 `z = t^2`。反向模式步骤：①前向传播记录中间值：t = x + y，z = t^2。②反向传播从输出端开始：dz/dz = 1（输出对自身导数）。③乘方节点 z = t^2 的反向：局部导数 dz/dt = 2t，故传给 t 的梯度 = dz/dz * dz/dt = 1 * 2t = 2t。④加法节点 t = x + y 的反向：局部导数 dt/dx = 1, dt/dy = 1（加法节点原样传递梯度），故传给 x 的梯度 = 2t * 1 = 2(x+y)，传给 y 的梯度 = 2t * 1 = 2(x+y)。结果：dz/dx = 2(x+y)，dz/dy = 2(x+y)。一次反向传播同时得到两个导数，验证了反向模式的效率优势。
</Answer>

### 问题 4

反向模式实现时为什么要做拓扑排序？拓扑排序如何保证梯度计算正确？

<Answer>

反向模式需要按拓扑序遍历计算图，原因：一个节点可能有多个输出（如 x 同时输入到两个运算），该节点的梯度是所有输出路径传回的梯度之和。必须保证在计算某节点的梯度时，它所有「下游」节点（依赖它的节点）的梯度已全部计算完毕，才能求和。拓扑排序保证的就是这个顺序——从输出端到输入端，每个节点在其所有依赖它的节点处理完后才被处理。DeZero 的实现用 `funcs` 列表 + `seen_set` 集合：每处理一个 Function，将其输入加入待处理列表。由于用 pop() 取最后一个（栈结构），加上计算图的 DAG 性质，自然形成逆拓扑序。对于多输出节点，同一节点可能被多次加入，通过 seen_set 去重并在梯度累加时用 `+=` 求和，确保所有路径的梯度被正确累加。
</Answer>
