## 为什么这一步不能跳过

步骤20 运算符重载（1） 的增量不是 API 名称，而是把 **只能调用 mul(x0,x1)** 变为 **自然乘法语法仍生成图节点**。它的核心机制是：**mul** 把 Python 乘法语法路由到 Mul Function，前向乘法的反向局部规则交换另一操作数。

这一步验收时固定输入数组、随机种子、DeZero 前一步版本与运行设备。先写出预期的 forward、shape、creator 或状态变化，再执行实现；backward 后清空派生梯度并从相同输入重放。这样才能区分本步能力与缓存、旧图或随机性的偶然结果。
