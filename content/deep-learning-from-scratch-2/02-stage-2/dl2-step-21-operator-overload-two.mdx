## 为什么这一步不能跳过

步骤21 运算符重载（2） 的增量不是 API 名称，而是把 **运算符只支持 Variable 在左侧** 变为 **混合标量与数组仍进入 DeZero 图**。它的核心机制是：as_variable 与 **rmul**/**radd** 处理 ndarray、float、int 和左右操作数优先级。

这一步验收时固定输入数组、随机种子、DeZero 前一步版本与运行设备。先写出预期的 forward、shape、creator 或状态变化，再执行实现；backward 后清空派生梯度并从相同输入重放。这样才能区分本步能力与缓存、旧图或随机性的偶然结果。

<Callout type="info" title="本步硬合同">
  前向证据、反向证据和重置后重放必须同时一致。NumPy 优先接管左侧运算会返回
  ndarray 或 object array 而不是 DeZero Variable 时，即使最终 loss
  或输出合理，也应判定 步骤21 运算符重载（2） 失败。
</Callout>
