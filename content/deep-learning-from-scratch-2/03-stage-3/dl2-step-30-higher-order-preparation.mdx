## 为什么这一步不能跳过

步骤30 高阶导数（准备篇） 的增量不是 API 名称，而是把 **梯度只是不可微 ndarray** 变为 **梯度也成为可追踪 Variable**。它的核心机制是：把 grad 从 ndarray 升级为 Variable，并让 backward 运算也通过 DeZero Function 执行，为高阶图建模。

这一步验收时固定输入数组、随机种子、DeZero 前一步版本与运行设备。先写出预期的 forward、shape、creator 或状态变化，再执行实现；backward 后清空派生梯度并从相同输入重放。这样才能区分本步能力与缓存、旧图或随机性的偶然结果。

<Callout type="info" title="本步硬合同">
  前向证据、反向证据和重置后重放必须同时一致。backward 中混入 NumPy
  运算会切断梯度本身的 creator 时，即使最终 loss 或输出合理，也应判定 步骤30
  高阶导数（准备篇） 失败。
</Callout>
