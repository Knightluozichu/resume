## Variable 类的实现

Variable 是 DeZero 的核心数据结构，它包装 NumPy 数组并记录计算图。

<Dl2VariableFunctionsDiagram />

```python
import numpy as np

class Variable:
    def __init__(self, data):
        # 数据校验：只接受 ndarray
        if data is not None:
            if not isinstance(data, np.ndarray):
                raise TypeError(f'{type(data)} is not supported')

        self.data = data          # 前向值
        self.grad = None          # 梯度（反向传播后填入）
        self.creator = None       # 产生它的 Function
        self.generation = 0       # 代数（用于拓扑排序）

    def set_creator(self, func):
        self.creator = func
        self.generation = func.generation + 1  # 比父节点代数+1
```

<Callout type="info">

**generation 的作用**：当计算图有分支时，需要按拓扑序反向传播。generation 标记每个 Variable 在计算图中的深度——代数越大离输出越近。反向传播时优先处理高代数的 Function，保证拓扑顺序正确。

</Callout>

## Function 类的实现

Function 是运算的抽象基类，子类只需实现 forward 和 backward。

```python
class Function:
    def __call__(self, *inputs):
        # 1. 取出数据
        xs = [x.data for x in inputs]
        # 2. 前向计算
        ys = self.forward(*xs)
        if not isinstance(ys, tuple):
            ys = (ys,)
        # 3. 包装为 Variable
        outputs = [Variable(y) for y in ys]

        # 4. 设置 generation（取输入的最大代数）
        self.generation = max([x.generation for x in inputs])
        # 5. 连接计算图：输出记住产生它的 Function
        for output in outputs:
            output.set_creator(self)
        # 6. 保存输入和输出（反向传播用）
        self.inputs = inputs
        self.outputs = outputs

        return outputs[0] if len(outputs) == 1 else outputs

    def forward(self, *xs):
        raise NotImplementedError()

    def backward(self, *gys):
        raise NotImplementedError()
```

## 计算图连接机制

`Function.__call__` 中的核心步骤是连接计算图：

```text
输入 Variable ──→ Function ──→ 输出 Variable
                    │                 │
                    │        output.creator = self
                    │        output.generation = func.generation + 1
                    │
            self.inputs = inputs    （保存输入，反向传播用）
            self.outputs = outputs   （保存输出，反向传播用）
```

<Callout type="warning">

**双向链接**：Function 持有 inputs（正向引用），Variable 持有 creator（反向引用）。这种双向链接让计算图既可前向（输入→输出）也可反向（输出→输入）遍历。

</Callout>

## 实现 BasicMath 运算

### Square（平方）

```python
class Square(Function):
    def forward(self, x):
        return x ** 2

    def backward(self, gy):
        x = self.inputs[0].data
        gx = 2 * x * gy        # d(x^2)/dx = 2x，乘以上游梯度
        return gx
```

### Exp（指数）

```python
class Exp(Function):
    def forward(self, x):
        return np.exp(x)

    def backward(self, gy):
        x = self.inputs[0].data
        gx = np.exp(x) * gy    # d(e^x)/dx = e^x
        return gx
```

### Add（加法，多输入）

```python
class Add(Function):
    def forward(self, x0, x1):
        return x0 + x1

    def backward(self, gy):
        # 加法节点：梯度原样传递给两个输入
        return gy, gy
```

### 便捷函数

```python
# 把 Function 子类的使用简化为函数调用
def square(x):
    return Square()(x)

def exp(x):
    return Exp()(x)

def add(x0, x1):
    return Add()(x0, x1)
```

## 组合运算示例

```python
x = Variable(np.array(2.0))
a = square(x)       # a = 4.0
b = exp(a)           # b = e^4 ≈ 54.6
c = square(b)        # c = b^2 ≈ 2981

# 计算图：x → square → a → exp → b → square → c
# 梯度通过 creator 链反向传递
```

## 多输入与多输出

DeZero 的 Function 支持多输入多输出：

```python
# 多输入：add(x0, x1) 接收两个 Variable
# 多输出：forward 返回 tuple，backward 接收多个梯度

# 例如：x0 和 x1 是同一个 Variable 时，梯度需要累加
x = Variable(np.array(2.0))
y = add(x, x)    # y = x + x = 2x
# backward 时 x 的梯度 = gy(来自第一条边) + gy(来自第二条边) = 2*gy
```

<Callout type="tip">

**梯度累加**：当一个 Variable 被多次使用（多条路径）时，反向传播会从不同路径传回多个梯度，必须累加。DeZero 在 backward 中用 `x.grad = x.grad + gx` 实现累加。

</Callout>

<Glossary>

<GlossaryItem term="Variable 类">
DeZero 的核心数据结构。持有 data（NumPy 数组前向值）、grad（梯度）、creator（产生它的 Function）、generation（计算图深度代数）。通过 creator 链接形成计算图。`__init__` 做类型校验（只接受 ndarray），set_creator 设置 creator 并更新 generation。
</GlossaryItem>

<GlossaryItem term="Function 类">
DeZero 的运算抽象基类。`__call__` 方法完成四步：取数据→forward 计算→包装输出→连接计算图（设置 creator、generation、保存 inputs/outputs）。子类只需实现 forward（前向运算）和 backward（反向梯度）。支持多输入多输出。
</GlossaryItem>

<GlossaryItem term="generation（代数）">
Variable 和 Function 在计算图中的深度标记。输入端 generation=0，每经过一个 Function 代数+1。反向传播时优先处理高代数的 Function，保证拓扑顺序正确——高代数节点离输出端更近，其梯度必须先于低代数节点计算完毕。
</GlossaryItem>

<GlossaryItem term="creator 链">
Variable.creator 指向产生它的 Function，Function.inputs 指向其输入 Variable。这种双向链接构成计算图的边。前向传播时通过 `output.set_creator(self)` 建立，反向传播时沿 creator 链从输出回溯到输入。
</GlossaryItem>

<GlossaryItem term="梯度累加">
当一个 Variable 被多条路径使用时（如 `y = add(x, x)`），反向传播会从不同路径传回多个梯度。DeZero 用 `x.grad = x.grad + gx` 实现累加，确保所有路径的梯度被正确汇总。这是链式法则在多路径场景的体现。
</GlossaryItem>

<GlossaryItem term="便捷函数">
将 `Square()(x)` 简化为 `square(x)` 的包装函数。每个 Function 子类对应一个同名小写便捷函数，内部实例化并调用。这是 DeZero 的 API 设计惯例，让用户代码更简洁，同时保持 Function 类的可扩展性。
</GlossaryItem>

</Glossary>

### 问题 1

Variable 类有哪些属性？各有什么作用？

<Answer>

Variable 类有四个核心属性：①data——前向值，存储 NumPy ndarray，是实际参与运算的数据。`__init__` 时做类型校验，只接受 ndarray（或 None），拒绝 Python list 等以避免隐式行为。②grad——梯度，反向传播后填入。初始为 None，backward 过程中存储损失对该 Variable 的导数。③creator——产生该 Variable 的 Function，通过 set_creator 设置。creator 链构成计算图的边，是反向传播回溯的路径。④generation——计算图深度代数，初始为 0，set_creator 时设为 `func.generation + 1`。反向传播时优先处理高代数的 Function，保证拓扑顺序正确——高代数节点离输出端更近，其梯度必须先于低代数节点计算完毕。这四个属性共同支撑了「数据包装+计算图记录+梯度存储」的核心功能。
</Answer>

### 问题 2

Function 类的 `__call__` 方法做了哪些事？请逐步说明。

<Answer>

Function 的 `__call__` 方法完成六步：①取数据——`xs = [x.data for x in inputs]`，从输入 Variable 中取出 NumPy 数组。②前向计算——`ys = self.forward(*xs)`，调用子类实现的 forward 方法计算输出值，支持多输出（返回 tuple）。③包装为 Variable——`outputs = [Variable(y) for y in ys]`，把 NumPy 结果包装为 Variable。④设置 generation——`self.generation = max([x.generation for x in inputs])`，取所有输入的最大代数，保证拓扑排序正确。⑤连接计算图——`output.set_creator(self)`，让输出记住产生它的 Function，同时更新 output.generation。⑥保存输入和输出——`self.inputs = inputs; self.outputs = outputs`，供反向传播使用。最后返回 outputs（单输出时解包）。这六步在每次运算时自动完成计算图构建。
</Answer>

### 问题 3

实现 Square 和 Add 的 Function 子类，写出 forward 和 backward。

<Answer>

Square（平方）的实现：`class Square(Function): def forward(self, x): return x ** 2; def backward(self, gy): x = self.inputs[0].data; return 2 * x * gy`。forward 计算 x 的平方，backward 返回 `2*x*gy`（局部导数 2x 乘以上游梯度 gy）。Add（加法）的实现：`class Add(Function): def forward(self, x0, x1): return x0 + x1; def backward(self, gy): return gy, gy`。forward 计算两数之和，backward 返回 `(gy, gy)`——加法节点的梯度原样传递给两个输入（局部导数均为 1）。两者的 backward 都遵循链式法则：返回的是局部导数乘以上游梯度。Square 的局部导数是 2x（对 x 求导），Add 的局部导数是 1（对 x0 和 x1 均为 1），所以 Add 的 backward 原样返回 gy。
</Answer>

### 问题 4

为什么当一个 Variable 被多次使用时，梯度需要累加？DeZero 如何实现？

<Answer>

当一个 Variable 被多条路径使用时（如 `y = add(x, x)`，x 同时作为 add 的两个输入），根据链式法则，损失对 x 的梯度等于所有路径传回的梯度之和。在计算图上，x 有两条出边，反向传播时每条边都会传回一个梯度，必须累加才能得到正确的总梯度。如果不累加而是覆盖，后传回的梯度会覆盖先传回的，导致结果错误。DeZero 的实现：在 backward 方法中，当向某个输入 Variable 传递梯度时，先检查 `x.grad is None`：如果是 None（第一次）则直接赋值 `x.grad = gx`；如果不是 None（已有梯度）则累加 `x.grad = x.grad + gx`。这确保同一 Variable 从不同路径收到的梯度被正确汇总。这是链式法则在多路径（分叉后再汇合）计算图中的正确实现。
</Answer>
