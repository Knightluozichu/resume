## backward 方法的设计

反向传播是 DeZero 的核心功能。Variable.backward 方法从当前 Variable 出发，沿 creator 链反向传递梯度。

<Dl2GradientBackpropDiagram />

### 基本实现

```python
class Variable:
    def backward(self):
        # 1. 初始化输出端的梯度为 1
        if self.grad is None:
            self.grad = np.ones_like(self.data)

        # 2. 收集需要反向传播的 Function（拓扑排序）
        funcs = []
        seen_set = set()

        def add_func(f):
            if f not in seen_set:
                seen_set.add(f)
                funcs.append(f)
                funcs.sort(key=lambda x: x.generation)  # 按代数排序

        add_func(self.creator)

        # 3. 循环处理所有 Function
        while funcs:
            f = funcs.pop()              # 取代数最大的（离输出最近的）
            gys = [output.grad for output in f.outputs]  # 收集输出梯度
            gxs = f.backward(*gys)       # 调用 Function 的反向计算
            if not isinstance(gxs, tuple):
                gxs = (gxs,)

            # 4. 将梯度传给输入
            for x, gx in zip(f.inputs, gxs):
                if x.grad is None:
                    x.grad = gx
                else:
                    x.grad = x.grad + gx  # 梯度累加

                if x.creator is not None:
                    add_func(x.creator)   # 继续回溯
```

## 拓扑排序的必要性

<Callout type="warning">

**关键问题**：当计算图有分叉和汇合时，一个 Function 可能被多次加入待处理列表。必须保证：①一个 Function 的所有输出梯度都已计算完毕后才处理它；②同一 Function 不被重复处理。拓扑排序 + seen_set 解决这两个问题。

</Callout>

### generation 排序

```text
计算图：x ──→ A ──→ a ──→ B ──→ b ──┐
         │                             ├──→ C ──→ y
         └────→ D ──→ d ──────────────┘

generation: x=0, A=0, a=1, B=1, b=2, D=0, d=1, C=2, y=3

反向传播顺序（按 generation 降序）：
  C(gen=2) → B(gen=1) → A(gen=0) → D(gen=0)
```

generation 越大 = 离输出越近 = 越先处理。这保证了 C 的梯度在 B 之前计算，B 的梯度在 A 之前计算。

## 复杂计算图的梯度传播

### 分支与汇合

```python
x = Variable(np.array(2.0))
a = square(x)       # a = x^2，x 有两条出边
b = add(a, a)        # b = a + a，a 被使用两次

b.backward()
# x.grad 应为 8.0
# 推导：b = 2a = 2x^2，db/dx = 4x = 8
```

<Callout type="info">

**梯度路径分析**：x → square → a，a 被加法使用两次（add(a, a)）。反向传播时：add 的 backward 传给 a 两个 gy（各为 1），a 的 grad 累加为 2。square 的 backward 传给 x：`2 * x * 2 = 8`。

</Callout>

### 多输出节点

当一个 Variable 输入到多个 Function 时，反向传播需要等所有下游 Function 都传回梯度后，才能继续向前回溯。generation 排序保证了这一点。

## 梯度清零

```python
x = Variable(np.array(3.0))
y = square(x)
y.backward()
print(x.grad)  # 6.0（正确）

# 再次计算，如果不清零
y2 = square(x)
y2.backward()
print(x.grad)  # 12.0（错误！累加了上次的 6.0）
```

### cleargrad 方法

```python
class Variable:
    def cleargrad(self):
        self.grad = None
```

```python
# 正确用法：每次反向传播前清零
x.cleargrad()
y2 = square(x)
y2.backward()
print(x.grad)  # 6.0（正确）
```

<Callout type="tip">

**最佳实践**：在训练循环中，每次 `loss.backward()` 后用 `optimizer.update()` 更新参数，然后用 `model.cleargrads()` 清零所有参数梯度。这与 PyTorch 的 `optimizer.zero_grad()` 完全一致。

</Callout>

## 反向传播的完整流程

```text
1. 用户调用 y.backward()
2. 初始化 y.grad = 1
3. 将 y.creator 加入 funcs 列表
4. 循环：
   a. 取出 generation 最大的 Function f
   b. 收集 f 所有输出的 grad
   c. 调用 f.backward(*gys) 得到输入梯度 gxs
   d. 将 gxs 累加到 f.inputs 的 grad
   e. 将 f.inputs 的 creator 加入 funcs
5. funcs 为空时结束，所有 Variable 的 grad 已计算完毕
```

## 数值梯度检验

验证反向传播正确性的方法——用数值微分对比自动微分：

```python
def numerical_grad(f, x, eps=1e-4):
    x0 = Variable(x.data - eps)
    x1 = Variable(x.data + eps)
    y0 = f(x0)
    y1 = f(x1)
    return (y1.data - y0.data) / (2 * eps)

# 测试
x = Variable(np.array(2.0))
y = square(exp(square(x)))   # 复合函数
y.backward()

# 对比
gx_auto = x.grad             # 自动微分
gx_num = numerical_grad(lambda t: square(exp(square(t))), x)
print(gx_auto, gx_num)       # 两者应非常接近
```

<Glossary>

<GlossaryItem term="backward 方法">
Variable 的反向传播方法。初始化输出端梯度为 1，收集 creator 链上的所有 Function 并按 generation 排序，循环处理每个 Function：收集输出梯度→调用 backward 计算输入梯度→累加到输入的 grad→继续回溯。是 DeZero 自动微分的运行时入口。
</GlossaryItem>

<GlossaryItem term="拓扑排序">
对计算图节点按依赖关系排序的算法。DeZero 用 generation（代数）标记节点深度，反向传播时优先处理高代数（离输出近）的 Function。这保证一个节点的所有下游梯度计算完毕后才处理该节点，是反向传播正确性的基础。
</GlossaryItem>

<GlossaryItem term="梯度累加">
当 Variable 被多条路径使用时，反向传播从不同路径传回多个梯度。DeZero 用 `x.grad = x.grad + gx` 累加，确保所有路径梯度被汇总。如果用覆盖而非累加，会丢失部分梯度导致结果错误。
</GlossaryItem>

<GlossaryItem term="梯度清零（cleargrad）">
将 Variable.grad 重置为 None 的方法。反向传播会累加梯度，若连续两次 backward 不清零，第二次结果会叠加第一次。训练循环中每次反向传播前必须清零所有参数梯度，与 PyTorch 的 optimizer.zero_grad() 作用一致。
</GlossaryItem>

<GlossaryItem term="数值梯度检验">
用数值微分验证自动微分正确性的方法：对同一函数分别用自动微分和中心差分 `(f(x+h)-f(x-h))/(2h)` 计算梯度，对比两者是否接近。是调试反向传播实现的标准手段，DeZero 全书反复使用。
</GlossaryItem>

<GlossaryItem term="generation 排序">
DeZero 拓扑排序的实现方式。每个 Variable/Function 持有 generation 属性，输入端为 0，每经过一个 Function 代数+1。反向传播时 funcs 列表按 generation 排序，pop() 取出最大的（离输出最近的），保证处理顺序正确。
</GlossaryItem>

</Glossary>

### 问题 1

Variable.backward 方法的实现步骤是什么？拓扑排序如何保证正确性？

<Answer>

backward 方法的实现步骤：①初始化输出端梯度——若 self.grad 为 None 则设为 ones_like(data)。②收集 creator 链上的 Function——用 add_func 将 self.creator 加入 funcs 列表和 seen_set 集合，funcs 按 generation 排序。③循环处理——取出 funcs 中 generation 最大的 Function f，收集 f 所有输出的 grad，调用 f.backward(*gys) 得到输入梯度 gxs，将 gxs 累加到 f.inputs 的 grad（None 时赋值，非 None 时相加），将 f.inputs 的 creator 加入 funcs。④funcs 为空时结束。拓扑排序的正确性保证：generation 越大离输出越近，优先处理高代数 Function 保证一个 Function 的所有输出梯度都已计算完毕后才处理它。seen_set 保证同一 Function 不被重复处理。对于多路径（Variable 被多次使用），梯度累加（`x.grad = x.grad + gx`）确保所有路径梯度被汇总。
</Answer>

### 问题 2

为什么需要梯度清零？不清零会导致什么问题？

<Answer>

需要梯度清零的原因：DeZero 的反向传播采用累加机制——当 `x.grad` 不为 None 时，新梯度会叠加到旧值上（`x.grad = x.grad + gx`）。这是为了处理同一 Variable 被多条路径使用时的正确累加。但如果连续两次 backward 不清零，第二次的梯度会叠加第一次的残留值，导致结果错误。例如：`x = Variable(3.0); y = square(x); y.backward()` 得 x.grad=6。若不清零再算 `y2 = square(x); y2.backward()`，x.grad 变成 12（6+6）而非正确的 6。解决方法：每次反向传播前调用 `x.cleargrad()` 将 grad 重置为 None。在训练循环中，用 `model.cleargrads()` 批量清零所有参数梯度，与 PyTorch 的 `optimizer.zero_grad()` 作用一致。这是框架使用的基本规范。
</Answer>

### 问题 3

对于 `b = add(square(x), square(x))`，手动推导反向传播过程，求 x.grad。

<Answer>

计算 `b = add(square(x), square(x))`，设 x=2.0。前向传播：两次 square(x) 得到两个 a=4.0，add 得到 b=8.0。计算图：x 同时输入到两个 square（记为 S1、S2），S1 和 S2 的输出都输入到 add。反向传播：①b.grad=1。②add 的 backward：梯度原样传递，传给 S1 的输出 grad=1，传给 S2 的输出 grad=1。③S1 的 backward：`2 * x * 1 = 2*2*1 = 4`，传给 x。④S2 的 backward：`2 * x * 1 = 2*2*1 = 4`，传给 x。⑤x 被两条路径传回梯度 4 和 4，累加得 x.grad = 8。验证：b = x^2 + x^2 = 2x^2，db/dx = 4x = 4*2 = 8。正确。这个例子展示了分支（x 分叉到两个 square）和汇合（两个输出汇合到 add）场景下的梯度累加。
</Answer>

### 问题 4

什么是数值梯度检验？为什么它是验证反向传播正确性的有效手段？

<Answer>

数值梯度检验是用数值微分验证自动微分正确性的方法：对同一函数分别用自动微分（backward）和中心差分 `(f(x+h)-f(x-h))/(2h)` 计算梯度，对比两者是否接近。实现：`def numerical_grad(f, x, eps=1e-4): x0=Variable(x.data-eps); x1=Variable(x.data+eps); y0=f(x0); y1=f(x1); return (y1.data-y0.data)/(2*eps)`。它是有效手段的原因：①数值微分只依赖函数的前向计算，不涉及 backward 实现，是独立的验证源——如果 backward 写错了梯度公式，数值微分仍能给出正确值，两者对比即可发现错误。②中心差分的精度足够（误差 O(eps^2)），eps=1e-4 时通常能匹配到 4-5 位有效数字。③适合任意复合函数，无需手动推导解析导数。DeZero 全书反复使用此方法，每实现一个新的 Function 都用数值梯度检验验证 backward 的正确性。
</Answer>
