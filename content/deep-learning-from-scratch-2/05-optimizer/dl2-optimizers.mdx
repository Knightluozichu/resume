## 优化器的角色

优化器（Optimizer）是框架的「手脚」——它接收参数和梯度，按特定策略更新参数。反向传播算出梯度后，由优化器执行实际的参数更新。

<Dl2OptimizersDiagram />

### 核心接口

```python
class Optimizer:
    def __init__(self):
        self.target = None       # 要优化的目标（Model 或 Layer）
        self.hooks = []          # 预处理钩子（如梯度裁剪）

    def setup(self, target):
        self.target = target
        return self

    def update(self):
        params = self.target.params()   # 收集所有参数
        for param in params:
            self._update_one(param)      # 逐个更新

    def _update_one(self, param):
        raise NotImplementedError()
```

<Callout type="info">

**设计要点**：Optimizer 不直接操作单个参数，而是通过 `target.params()` 收集目标对象的所有参数。这使得 Optimizer 可以统一处理 Layer、Model 等任意层级的参数容器。

</Callout>

## SGD（随机梯度下降）

最基础的优化器，沿负梯度方向更新：

```python
class SGD(Optimizer):
    def __init__(self, lr=0.01):
        super().__init__()
        self.lr = lr

    def _update_one(self, param):
        param.data -= self.lr * param.grad
```

```text
更新公式：W ← W - lr * grad
```

<Callout type="warning">

**SGD 的局限**：对于病态曲率（如椭圆形损失面），SGD 会在陡峭方向剧烈震荡、平缓方向进展缓慢。这就是需要 Momentum 和 Adam 的原因。

</Callout>

## Momentum（动量）

引入「速度」概念，累积历史梯度方向：

```python
class Momentum(Optimizer):
    def __init__(self, lr=0.01, momentum=0.9):
        super().__init__()
        self.lr = lr
        self.momentum = momentum
        self.vs = {}    # 每个参数的速度

    def _update_one(self, param):
        v = self.vs.get(id(param), np.zeros_like(param.data))
        v = self.momentum * v - self.lr * param.grad
        self.vs[id(param)] = v
        param.data += v
```

```text
更新公式：
  v ← momentum * v - lr * grad
  W ← W + v
```

### Momentum 的直觉

```text
v = 0.9 * v_prev + (-0.01 * grad)
    └────────────┘   └──────────┘
     历史惯性(90%)    当前梯度(10%)
```

- **惯性**：0.9 倍的历史速度让更新方向更稳定，抵消震荡
- **加速**：在一致梯度方向上不断加速，收敛更快

## Adam（自适应矩估计）

结合 Momentum（一阶矩）和 RMSProp（二阶矩），自适应调节每个参数的学习率：

```python
class Adam(Optimizer):
    def __init__(self, alpha=0.001, beta1=0.9, beta2=0.999, eps=1e-8):
        super().__init__()
        self.alpha = alpha
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.ms = {}    # 一阶矩（梯度的指数移动平均）
        self.vs = {}    # 二阶矩（梯度平方的指数移动平均）
        self.t = 0      # 时间步

    def _update_one(self, param):
        key = id(param)
        if key not in self.ms:
            self.ms[key] = np.zeros_like(param.data)
            self.vs[key] = np.zeros_like(param.data)

        m, v = self.ms[key], self.vs[key]
        self.t += 1

        # 一阶矩更新
        m = self.beta1 * m + (1 - self.beta1) * param.grad
        # 二阶矩更新
        v = self.beta2 * v + (1 - self.beta2) * param.grad ** 2

        # 偏差修正
        m_hat = m / (1 - self.beta1 ** self.t)
        v_hat = v / (1 - self.beta2 ** self.t)

        # 参数更新
        param.data -= self.alpha * m_hat / (np.sqrt(v_hat) + self.eps)

        self.ms[key], self.vs[key] = m, v
```

```text
更新公式：
  m ← β1 * m + (1-β1) * grad           (一阶矩)
  v ← β2 * v + (1-β2) * grad^2         (二阶矩)
  m_hat ← m / (1 - β1^t)               (偏差修正)
  v_hat ← v / (1 - β2^t)               (偏差修正)
  W ← W - α * m_hat / (√v_hat + ε)
```

## 三种优化器对比

| 优化器 | 核心思想 | 优点 | 缺点 | 超参数 |
|--------|---------|------|------|--------|
| SGD | 沿负梯度方向更新 | 简单、稳定 | 震荡、收敛慢 | lr |
| Momentum | 累积历史梯度（惯性） | 抵消震荡、加速收敛 | 需调 momentum | lr, momentum |
| Adam | 自适应学习率 + 动量 | 收敛快、少调参 | 内存占用大 | alpha, beta1, beta2 |

<Callout type="tip">

**选择建议**：大多数情况下直接用 Adam（alpha=0.001），它是「开箱即用」的默认选择。SGD+Momentum 在精细调参时可达到更好泛化。学习率是最重要的超参数，Adam 的默认值通常足够好。

</Callout>

## 与 Layer/Model 集成

```python
# 1. 定义模型
model = MLP((100, 10))       # 含参数的 Model
# 2. 设置优化器（自动收集模型参数）
optimizer = Adam().setup(model)

# 3. 训练循环
for epoch in range(epochs):
    for x, t in dataloader:
        # 前向 + 反向
        y = model(x)
        loss = softmax_cross_entropy(y, t)
        model.cleargrads()           # 清零梯度
        loss.backward()              # 反向传播
        # 优化器更新
        optimizer.update()           # 自动更新所有参数
```

<Glossary>

<GlossaryItem term="优化器（Optimizer）">
框架中负责根据梯度更新参数的组件。核心接口：setup(target) 绑定目标（Model/Layer），update() 收集所有参数并逐个更新。DeZero 的 Optimizer 基类通过 target.params() 抽象参数收集，使优化器可统一处理任意层级的参数容器。
</GlossaryItem>

<GlossaryItem term="SGD">
随机梯度下降，最基础的优化器。更新公式 `W ← W - lr * grad`，沿负梯度方向更新。优点是简单稳定，缺点是对病态曲率（椭圆形损失面）会在陡峭方向震荡、平缓方向进展缓慢。学习率 lr 是唯一超参数。
</GlossaryItem>

<GlossaryItem term="Momentum">
动量优化器，引入「速度」概念累积历史梯度。更新公式 `v ← momentum*v - lr*grad; W ← W + v`。momentum（通常0.9）提供惯性，抵消震荡方向、加速一致方向。比 SGD 更快收敛，尤其在病态曲率下。
</GlossaryItem>

<GlossaryItem term="Adam">
自适应矩估计优化器，结合 Momentum（一阶矩）和 RMSProp（二阶矩）。维护梯度的指数移动平均（m）和梯度平方的指数移动平均（v），自适应调节每个参数的学习率。偏差修正消除初始零偏。收敛快、少调参，是「开箱即用」的默认选择。超参数：alpha(0.001)、beta1(0.9)、beta2(0.999)。
</GlossaryItem>

<GlossaryItem term="偏差修正">
Adam 优化器中消除初始零偏的技术。m 和 v 初始为 0，早期估计偏小，用 `m_hat = m / (1 - β1^t)` 修正。t 是时间步，随训练进行 1-β^t 趋近 1，修正量趋近 0。保证训练初期更新幅度不会过小。
</GlossaryItem>

<GlossaryItem term="参数收集（params）">
Optimizer 通过 target.params() 收集目标对象的所有参数。Model/Layer 递归遍历子层，汇总所有 Variable 参数。这使得 Optimizer 可统一处理单层或整个网络，无需用户手动传入参数列表。
</GlossaryItem>

</Glossary>

### 问题 1

优化器在框架中扮演什么角色？Optimizer 基类的接口设计是怎样的？

<Answer>

优化器在框架中扮演「参数更新者」的角色——反向传播算出梯度后，优化器根据梯度按特定策略更新参数。Optimizer 基类的接口设计：①__init__——初始化超参数和 hooks（预处理钩子）。②setup(target)——绑定要优化的目标（Model 或 Layer），返回 self 支持链式调用。③update()——核心方法，通过 `self.target.params()` 收集目标的所有参数，逐个调用 `_update_one(param)` 更新。④_update_one(param)——抽象方法，子类实现具体更新策略（SGD/Momentum/Adam）。设计要点：Optimizer 不直接操作单个参数，而是通过 target.params() 收集，这使得一个 Optimizer 实例可统一处理 Layer、Model 等任意层级的参数容器。hooks 机制允许在更新前做梯度裁剪等预处理。
</Answer>

### 问题 2

实现 SGD 和 Momentum 优化器，说明 Momentum 相比 SGD 的优势。

<Answer>

SGD 实现：`class SGD(Optimizer): def __init__(self, lr=0.01): self.lr=lr; def _update_one(self, param): param.data -= self.lr * param.grad`。更新公式 `W ← W - lr*grad`。Momentum 实现：`class Momentum(Optimizer): def __init__(self, lr=0.01, momentum=0.9): self.lr=lr; self.momentum=momentum; self.vs={}; def _update_one(self, param): v=self.vs.get(id(param), np.zeros_like(param.data)); v=self.momentum*v - self.lr*param.grad; self.vs[id(param)]=v; param.data += v`。更新公式 `v ← momentum*v - lr*grad; W ← W + v`。Momentum 相比 SGD 的优势：①抵消震荡——在病态曲率（椭圆形损失面）下，SGD 会在陡峭方向来回震荡。Momentum 的 0.9 倍历史速度提供惯性，使震荡方向的更新因正负抵消而减弱。②加速收敛——在一致梯度方向上，速度不断累积加速，比 SGD 更快到达最优。③更平稳——惯性平滑了梯度噪声的影响。
</Answer>

### 问题 3

Adam 优化器的更新公式是什么？一阶矩和二阶矩各有什么作用？

<Answer>

Adam 的更新公式：①一阶矩 `m ← β1*m + (1-β1)*grad`（梯度的指数移动平均，β1=0.9）。②二阶矩 `v ← β2*v + (1-β2)*grad^2`（梯度平方的指数移动平均，β2=0.999）。③偏差修正 `m_hat = m/(1-β1^t); v_hat = v/(1-β2^t)`。④参数更新 `W ← W - α * m_hat / (√v_hat + ε)`（α=0.001, ε=1e-8）。一阶矩的作用：类似 Momentum，累积梯度方向的历史信息，提供惯性使更新更平稳。二阶矩的作用：衡量梯度的历史幅度，用于自适应调节学习率——梯度大的参数学习率自动减小（除以 √v_hat），梯度小的参数学习率自动增大。两者结合使 Adam 既有 Momentum 的平稳性，又有 RMSProp 的自适应性。偏差修正消除 m、v 初始为 0 带来的早期偏小问题。
</Answer>

### 问题 4

在训练循环中如何使用优化器？与 PyTorch 的用法有何对应？

<Answer>

DeZero 训练循环使用优化器的标准模式：①定义模型 `model = MLP((100,10))`。②设置优化器 `optimizer = Adam().setup(model)`——setup 自动收集模型所有参数。③训练循环：前向计算 `y = model(x)`，算损失 `loss = softmax_cross_entropy(y, t)`，清零梯度 `model.cleargrads()`，反向传播 `loss.backward()`，更新参数 `optimizer.update()`。与 PyTorch 的对应：①DeZero `Adam().setup(model)` ↔ PyTorch `optim.Adam(model.parameters())`。②DeZero `model.cleargrads()` ↔ PyTorch `optimizer.zero_grad()`。③DeZero `loss.backward()` ↔ PyTorch `loss.backward()`。④DeZero `optimizer.update()` ↔ PyTorch `optimizer.step()`。两者流程几乎一致，区别仅在于 API 命名（update/step、cleargrads/zero_grad）。这种相似性说明 DeZero 成功复刻了工业框架的训练范式。
</Answer>
