## 为什么这一步不能跳过

步骤53 模型的保存和加载 的增量不是 API 名称，而是把 **训练结束权重只存在内存** 变为 **稳定 state 字典支持保存和恢复**。它的核心机制是：Layer 递归展平参数为稳定层级键，保存前转 CPU，加载时按键和 shape 写回现有 Parameter。

这一步验收时固定输入数组、随机种子、DeZero 前一步版本与运行设备。先写出预期的 forward、shape、creator 或状态变化，再执行实现；backward 后清空派生梯度并从相同输入重放。这样才能区分本步能力与缓存、旧图或随机性的偶然结果。

<Callout type="info" title="本步硬合同">
  前向证据、反向证据和重置后重放必须同时一致。依赖对象遍历偶然顺序会让模型结构微调后权重错配
  时，即使最终 loss 或输出合理，也应判定 步骤53 模型的保存和加载 失败。
</Callout>
