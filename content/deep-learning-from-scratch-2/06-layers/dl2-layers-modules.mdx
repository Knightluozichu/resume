## 为什么要模块化

在前面的章节中，运算是通过函数调用的：`y = square(x)`、`z = add(a, b)`。但当网络变复杂时，这种散落的函数调用难以管理参数（权重、偏置）。

**Layer 的核心价值**：把「运算 + 参数」封装为一个对象，使网络可以像搭积木一样组合。

## Layer 基类设计

```python
class Layer:
    def __init__(self):
        self._params = set()    # 该层持有的参数名

    def __setattr__(self, name, value):
        # 自动收集 Variable 类型的属性为参数
        if isinstance(value, (Parameter, Layer)):
            self._params.add(name)
        super().__setattr__(name, value)

    def params(self):
        # 递归收集所有参数（包括子 Layer 的参数）
        for name in self._params:
            obj = self.__dict__[name]
            if isinstance(obj, Parameter):
                yield obj
            elif isinstance(obj, Layer):
                yield from obj.params()    # 递归子层

    def cleargrads(self):
        for param in self.params():
            param.cleargrad()

    def forward(self, *xs):
        raise NotImplementedError()

    def __call__(self, *xs):
        return self.forward(*xs)
```

<Callout type="info">

**参数自动收集**：`__setattr__` 在赋值时自动检测——如果是 Parameter 类型就加入 `_params` 集合。用户无需手动声明参数列表，`self.W = Parameter(...)` 即自动被收集。这与 PyTorch 的 nn.Module 机制一致。

</Callout>

## Parameter 类

Parameter 是特殊的 Variable，用于标记「这是需要学习的参数」：

```python
class Parameter(Variable):
    pass
```

仅靠类型区分，使 Layer.params() 能从普通 Variable 中筛出参数。

## Linear 层的实现

Linear（全连接层）是神经网络最常用的层：

```python
class Linear(Layer):
    def __init__(self, out_size, nobias=False, dtype=np.float32, in_size=None):
        super().__init__()
        self.in_size = in_size
        self.out_size = out_size
        self.dtype = dtype

        # 延迟初始化：首次前向时根据输入形状创建权重
        self.W = Parameter(None, name='W')
        if in_size is not None:
            self._init_W()

        if nobias:
            self.b = None
        else:
            self.b = Parameter(np.zeros(out_size, dtype=dtype), name='b')

    def _init_W(self):
        # Xavier 初始化
        I, O = self.in_size, self.out_size
        W_data = np.random.randn(I, O).astype(self.dtype) * np.sqrt(1 / I)
        self.W.data = W_data

    def forward(self, x):
        # 延迟初始化权重
        if self.W.data is None:
            self.in_size = x.shape[1]
            self._init_W()

        # 前向计算：y = x · W + b
        y = matmul(x, self.W)
        if self.b is not None:
            y = add(y, self.b)
        return y
```

<Callout type="warning">

**延迟初始化**：Linear 支持在 `__init__` 时不指定 in_size，首次前向传播时根据输入 x 的形状自动推断。这省去了用户手动计算输入维度，是框架易用性的重要细节。

</Callout>

## 激活层

激活层无参数，仅封装运算：

### Sigmoid 层

```python
class Sigmoid(Layer):
    def forward(self, x):
        # y = 1 / (1 + exp(-x))
        y = 1 / (1 + exp(-x))
        return y
```

### ReLU 层

```python
class ReLU(Layer):
    def forward(self, x):
        # y = max(0, x)
        y = maximum(0, x)
        return y
```

### Tanh 层

```python
class Tanh(Layer):
    def forward(self, x):
        # y = (exp(x) - exp(-x)) / (exp(x) + exp(-x))
        y = 2 * sigmoid(2 * x) - 1
        return y
```

## 层组合

Layer 可以嵌套组合，构建复杂网络：

```python
class TwoLayerNet(Layer):
    def __init__(self, hidden_size, out_size):
        super().__init__()
        self.fc1 = Linear(hidden_size)    # 第一层
        self.activate1 = Sigmoid()         # 激活
        self.fc2 = Linear(out_size)        # 第二层

    def forward(self, x):
        z1 = self.fc1(x)
        a1 = self.activate1(z1)
        z2 = self.fc2(a1)
        return z2
```

```python
# 使用
model = TwoLayerNet(100, 10)
y = model(x)                       # 前向传播

# 参数自动收集（包括子层）
for param in model.params():
    print(param.name, param.data.shape)
# W (784, 100), b (100,), W (100, 10), b (10,)

# 优化器自动更新所有参数
optimizer = SGD().setup(model)
optimizer.update()
```

<Callout type="tip">

**递归收集**：`model.params()` 递归遍历 fc1、fc2 等子层，汇总所有参数。这是 Layer 可无限嵌套的关键——无论网络多深，优化器都能自动找到所有参数。

</Callout>

## Layer 与 Function 的关系

| 维度 | Function | Layer |
|------|----------|-------|
| 角色 | 底层运算单元 | 高层模块化单元 |
| 参数 | 无（纯运算） | 有（管理权重/偏置） |
| 复用 | 函数调用 | 对象组合 |
| 层级 | 计算图节点 | 网络构建积木 |

Layer 内部使用 Function 实现前向计算（如 Linear 内部用 matmul + add），Layer 是 Function 之上的工程化封装。

<Glossary>

<GlossaryItem term="Layer">
封装参数与前向/反向运算的模块化单元。基类通过 `__setattr__` 自动收集 Parameter 属性，params() 递归收集所有参数（含子层）。Linear、Sigmoid 等层可像积木组合构建复杂网络。是框架工程化的关键抽象，对应 PyTorch 的 nn.Module。
</GlossaryItem>

<GlossaryItem term="Parameter">
特殊的 Variable，用于标记「需要学习的参数」。Layer 通过 `__setattr__` 自动检测 Parameter 类型并加入 _params 集合，使 params() 能从普通 Variable 中筛出参数。仅靠类型区分，不添加额外功能。
</GlossaryItem>

<GlossaryItem term="参数自动收集">
Layer 的 `__setattr__` 在赋值时检测类型，若为 Parameter 或 Layer 则加入 _params 集合。params() 递归遍历 _params，对 Parameter 直接 yield，对子 Layer 递归调用其 params()。这使得网络可无限嵌套，优化器自动找到所有参数。
</GlossaryItem>

<GlossaryItem term="Linear 层">
全连接层，神经网络最常用的层。前向计算 `y = x·W + b`，内部用 matmul 和 add 两个 Function 实现。支持延迟初始化（首次前向时根据输入形状推断 in_size）和 Xavier 初始化。对应 PyTorch 的 nn.Linear。
</GlossaryItem>

<GlossaryItem term="延迟初始化">
Linear 在 `__init__` 时不强制指定 in_size，首次前向传播时根据输入 x 的 shape 自动推断并创建权重。省去用户手动计算输入维度，是框架易用性的重要细节。
</GlossaryItem>

<GlossaryItem term="层组合">
Layer 可嵌套组合构建复杂网络。外层 Layer 在 `__init__` 中创建子 Layer 作为属性，forward 中依次调用子层。params() 递归收集所有层级的参数，优化器自动更新。这是「搭积木」式网络构建的基础。
</GlossaryItem>

</Glossary>

### 问题 1

Layer 基类如何实现参数的自动收集？请说明 `__setattr__` 和 `params()` 的机制。

<Answer>

Layer 基类通过两个机制实现参数自动收集：①`__setattr__`——在属性赋值时自动检测类型。当执行 `self.W = Parameter(...)` 时，`__setattr__` 拦截赋值操作，检查 value 是否为 Parameter 或 Layer 类型。如果是，将属性名 name 加入 `self._params` 集合，然后调用 `super().__setattr__` 完成实际赋值。这样用户无需手动声明参数列表，任何 Parameter 类型的属性都自动被收集。②`params()`——递归收集所有参数。遍历 _params 集合中的每个属性名，取出对应对象：如果是 Parameter 直接 yield（它是叶参数）；如果是 Layer（子层），递归调用 `yield from obj.params()` 继续深入。这种递归设计使网络可无限嵌套——无论外层 Model 包含多少层子 Layer，params() 都能找到所有叶参数。cleargrads() 遍历 params() 对每个参数调用 cleargrad()。这与 PyTorch 的 nn.Module.parameters() 机制一致。
</Answer>

### 问题 2

实现 Linear 层，说明延迟初始化和 Xavier 初始化的作用。

<Answer>

Linear 层实现：`__init__` 接收 out_size、可选 nobias、dtype、in_size。创建 `self.W = Parameter(None)` 和 `self.b = Parameter(np.zeros(out_size))`。`_init_W` 方法用 Xavier 初始化：`W_data = np.random.randn(I, O) * np.sqrt(1/I)`。forward 方法中检查 `self.W.data is None`，若是则根据 x.shape[1] 推断 in_size 并调用 `_init_W`，然后计算 `y = matmul(x, self.W)`，若 b 不为 None 则 `y = add(y, self.b)`。延迟初始化的作用：允许用户在 `__init__` 时不指定 in_size（`Linear(100)`），首次前向传播时根据输入 x 的形状自动推断。省去用户手动计算输入维度（尤其在复杂网络中容易出错）。Xavier 初始化的作用：权重初始值设为 `randn * sqrt(1/I)`（I 是输入维度），使各层激活值方差大致相同，避免前向传播时信号指数增长或消失。 Xavier 适合 sigmoid/tanh，He 初始化（sqrt(2/I)）适合 ReLU。
</Answer>

### 问题 3

Layer 和 Function 有什么关系？为什么要在这两者之上再封装 Layer？

<Answer>

Layer 和 Function 的关系：Function 是底层运算单元（无参数，纯运算，是计算图节点），Layer 是高层模块化单元（管理参数，可组合，是网络构建积木）。Layer 内部使用 Function 实现前向计算——如 Linear 内部用 matmul 和 add 两个 Function，Sigmoid 内部用 exp 和 div 等 Function。Layer 是 Function 之上的工程化封装。在 Function 之上再封装 Layer 的原因：①参数管理——Function 是无状态的无状态运算，无法持有权重/偏置。Layer 把「运算+参数」封装为对象，通过 `__setattr__` 自动收集参数，params() 递归汇总。②模块化组合——散落的函数调用（`y=square(x); z=add(y,b)`）难以管理。Layer 可嵌套组合（TwoLayerNet 包含 fc1、activate1、fc2），像搭积木构建复杂网络。③复用性——同一个 Layer 实例可多次调用，权重在调用间共享。④API 一致性——所有层统一通过 `__call__` 调用，优化器统一通过 params() 收集参数，降低使用心智负担。
</Answer>

### 问题 4

如何用 Layer 组合构建一个两层网络？参数是如何被优化器收集的？

<Answer>

用 Layer 组合构建两层网络：`class TwoLayerNet(Layer): def __init__(self, hidden_size, out_size): super().__init__(); self.fc1 = Linear(hidden_size); self.activate1 = Sigmoid(); self.fc2 = Linear(out_size); def forward(self, x): z1=self.fc1(x); a1=self.activate1(z1); z2=self.fc2(a1); return z2`。`__init__` 中创建 fc1（Linear）、activate1（Sigmoid）、fc2（Linear）三个子层作为属性。`__setattr__` 自动将这三个 Layer 属性加入 _params。forward 中依次调用：fc1 做线性变换，activate1 做激活，fc2 做第二层线性变换。优化器收集参数的过程：`optimizer = SGD().setup(model)` 调用 setup 绑定 model 为 target。`optimizer.update()` 调用 `self.target.params()`，从 model 开始递归：model 的 _params 含 fc1、activate1、fc2。fc1 是 Layer，递归调用 fc1.params()，yield fc1.W 和 fc1.b。activate1 是 Layer 无参数。fc2 同理 yield fc2.W 和 fc2.b。最终优化器拿到 W(784,100)、b(100,)、W(100,10)、b(10,) 四个参数，逐个用 _update_one 更新。
</Answer>
