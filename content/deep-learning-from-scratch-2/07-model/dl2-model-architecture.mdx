## Model 类的设计

Model 是特殊的 Layer，用作「网络容器」。它继承 Layer 的所有能力（参数收集、梯度清零），并添加网络级的功能。

<Dl2ModelArchitectureDiagram />

```python
class Model(Layer):
    """Layer 之上，提供网络容器的抽象"""

    def plot(self, *inputs, to_file='model.png'):
        # 可视化计算图（调试用）
        y = self.forward(*inputs)
        return utils.plot_dot_graph(y, verbose=True, to_file=to_file)

    # Layer 的 params()、cleargrads()、__call__ 等继承即可
```

<Callout type="info">

**Model vs Layer**：在 DeZero 中 Model 继承自 Layer，不添加太多功能。这种设计强调「一切皆 Layer」——Model 只是一个语义标记，表示「这是一个完整的网络」。这与 PyTorch 的 nn.Module 既是层又是模型的设计一致。

</Callout>

## 网络组合模式

### 模式一：顺序组合

```python
class MLP(Layer):
    """多层感知机"""
    def __init__(self, fc_output_sizes, activation=Sigmoid):
        super().__init__()
        self.activation = activation()
        self.layers = []

        for i, out_size in enumerate(fc_output_sizes):
            layer = Linear(out_size)
            setattr(self, f'fc{i}', layer)    # 自动收集为参数
            self.layers.append(layer)

    def forward(self, x):
        # 依次通过各层 + 激活（最后一层不加激活）
        for i, layer in enumerate(self.layers):
            x = layer(x)
            if i < len(self.layers) - 1:
                x = self.activation(x)
        return x
```

### 模式二：嵌套组合

```python
class BigNet(Model):
    def __init__(self):
        super().__init__()
        self.block1 = SmallBlock()    # SmallBlock 也是 Layer
        self.block2 = SmallBlock()
        self.head = Linear(10)

    def forward(self, x):
        x = self.block1(x)
        x = self.block2(x)
        x = self.head(x)
        return x
```

<Callout type="tip">

**无限嵌套**：params() 递归收集，所以无论网络嵌套多深，优化器都能自动找到所有参数。block1 内部的子层参数也会被收集。这是「搭积木」设计的核心优势。

</Callout>

## 参数管理完整链路

```text
定义参数          收集参数              更新参数
─────────       ─────────            ─────────
Linear.__init__  →  Model.params()  →  Optimizer.update()
self.W = Param      递归遍历子层          逐个 param.data -= lr*grad
self.b = Param      yield Parameter      自动清零下一轮
```

### 定义阶段

```python
model = MLP((100, 50, 10))
# fc0: W(784,100), b(100,)
# fc1: W(100,50),  b(50,)
# fc2: W(50,10),   b(10,)
```

### 收集阶段

```python
optimizer = Adam().setup(model)
# optimizer.target = model
# update() 时调用 model.params() 递归收集所有 Parameter
```

### 更新阶段

```python
# 每轮训练
loss = compute_loss(model, x, t)
model.cleargrads()         # 清零所有参数梯度
loss.backward()            # 反向传播填充梯度
optimizer.update()         # 用梯度更新参数
```

## 常见网络架构

### MLP（多层感知机）

```python
model = MLP((100, 10))     # 输入→100→10
y = model(x)                # 前向传播
```

### 带卷积的网络

```python
class SimpleCNN(Model):
    def __init__(self):
        super().__init__()
        self.conv1 = Conv2d(16, 3, pad=1)   # 卷积层
        self.relu1 = ReLU()
        self.pool1 = MaxPool2d(2)           # 池化层
        self.fc = Linear(10)                # 全连接输出

    def forward(self, x):
        x = self.conv1(x)
        x = self.relu1(x)
        x = self.pool1(x)
        x = reshape(x, (x.shape[0], -1))   # 展平
        x = self.fc(x)
        return x
```

## Model 的生命周期

```text
1. 定义：model = MLP((100, 10))
2. 绑定优化器：optimizer = Adam().setup(model)
3. 训练循环：
   a. 前向：y = model(x)
   b. 损失：loss = criterion(y, t)
   c. 清零：model.cleargrads()
   d. 反向：loss.backward()
   e. 更新：optimizer.update()
4. 评估：acc = accuracy(model, test_data)
5. 保存/加载（DeZero 后续扩展）
```

<Glossary>

<GlossaryItem term="Model 类">
继承自 Layer 的网络容器抽象。复用 Layer 的参数收集、梯度清零等能力，添加 plot（计算图可视化）等网络级功能。在 DeZero 中 Model 与 Layer 区分不大，强调「一切皆 Layer」的设计哲学。对应 PyTorch 的 nn.Module。
</GlossaryItem>

<GlossaryItem term="顺序组合">
网络构建模式之一。在 Layer 的 forward 中依次调用各子层，数据线性流过。如 MLP 依次通过 fc0→activate→fc1→activate→fc2。简单直观，适合线性结构的网络。
</GlossaryItem>

<GlossaryItem term="嵌套组合">
网络构建模式之一。外层 Model 包含多个子 Block（也是 Layer），子 Block 内部又包含子层。params() 递归收集，使网络可无限嵌套。适合构建 ResNet 等含重复模块的复杂网络。
</GlossaryItem>

<GlossaryItem term="参数管理链路">
参数从定义到更新的完整流程：①定义——Linear.__init__ 中 `self.W = Parameter(...)`，`__setattr__` 自动收集。②收集——optimizer.setup(model) 绑定目标，update() 调用 model.params() 递归汇总。③更新——update() 逐个用梯度更新参数 data。④清零——cleargrads() 清零所有参数 grad，为下一轮准备。
</GlossaryItem>

<GlossaryItem term="MLP（多层感知机）">
最基础的前馈神经网络。由多个 Linear 层 + 激活层交替组成，数据从输入层经隐藏层流向输出层。DeZero 的 MLP 类接收各层输出维度元组，自动构建对应数量的 Linear 层。
</GlossaryItem>

<GlossaryItem term="计算图可视化">
DeZero 的 Model.plot 方法，将前向传播产生的计算图导出为 Graphviz DOT 格式图片。能直观展示各层连接、运算节点、数据流向，是调试复杂网络的有力工具。
</GlossaryItem>

</Glossary>

### 问题 1

Model 类与 Layer 类有什么关系？为什么说「一切皆 Layer」？

<Answer>

Model 类继承自 Layer，复用 Layer 的所有能力（`__setattr__` 参数自动收集、params() 递归收集、cleargrads() 梯度清零、`__call__` 前向转发），并添加网络级功能如 plot（计算图可视化）。在 DeZero 中 Model 与 Layer 区分不大，Model 更多是一个语义标记，表示「这是一个完整的网络」而非单个层。说「一切皆 Layer」的原因：①统一抽象——Linear、Sigmoid、MLP、CNN 都是 Layer，都用 `__call__` 调用，都用 params() 收集参数，优化器统一处理。②无限嵌套——Layer 内部可包含子 Layer（Model 也是 Layer），params() 递归收集，网络可任意嵌套。③一致性——无论网络多复杂，训练流程一致：前向→损失→cleargrads→backward→update。这种设计对应 PyTorch 的 nn.Module 既是层又是模型的哲学，降低了学习心智负担。
</Answer>

### 问题 2

DeZero 支持哪两种网络组合模式？各举一个例子。

<Answer>

DeZero 支持两种网络组合模式：①顺序组合——在 Layer 的 forward 中依次调用各子层，数据线性流过。例如 MLP：`class MLP(Layer): def __init__(self, sizes): for i,out_size in enumerate(sizes): setattr(self, f'fc{i}', Linear(out_size)); def forward(self, x): for i,layer in enumerate(self.layers): x=layer(x); if i<len-1: x=activate(x); return x`。简单直观，适合线性结构网络。②嵌套组合——外层 Model 包含多个子 Block（也是 Layer），子 Block 内部又包含子层。例如 BigNet：`class BigNet(Model): def __init__(self): self.block1=SmallBlock(); self.block2=SmallBlock(); self.head=Linear(10); def forward(self, x): x=self.block1(x); x=self.block2(x); x=self.head(x); return x`。params() 递归收集，使 block1、block2 内部的子层参数也被自动找到。适合构建 ResNet 等含重复模块的复杂网络。两种模式可混用。
</Answer>

### 问题 3

描述参数从定义到更新的完整管理链路。

<Answer>

参数管理链路分四个阶段：①定义阶段——在 Linear.__init__ 中 `self.W = Parameter(...); self.b = Parameter(...)`。Layer 的 `__setattr__` 拦截赋值，检测到 Parameter 类型后自动将属性名加入 `self._params` 集合。用户无需手动声明参数列表。②收集阶段——`optimizer = Adam().setup(model)` 绑定 model 为 target。update() 时调用 `model.params()`，递归遍历 model 的 _params：对 Parameter 直接 yield，对子 Layer 递归调用其 params()。无论网络多深，所有叶参数都被收集。③更新阶段——`optimizer.update()` 逐个取出参数，调用 `_update_one(param)`，用 `param.data -= lr * param.grad`（SGD）或更复杂策略更新参数 data。④清零阶段——`model.cleargrads()` 遍历 params() 对每个参数调用 `param.cleargrad()`（grad=None），为下一轮反向传播准备，防止梯度累加。这四步在训练循环中反复执行。
</Answer>

### 问题 4

如何在 DeZero 中实现一个简单的 CNN？参数是如何被收集的？

<Answer>

DeZero 中实现简单 CNN：`class SimpleCNN(Model): def __init__(self): super().__init__(); self.conv1=Conv2d(16,3,pad=1); self.relu1=ReLU(); self.pool1=MaxPool2d(2); self.fc=Linear(10); def forward(self, x): x=self.conv1(x); x=self.relu1(x); x=self.pool1(x); x=reshape(x,(x.shape[0],-1)); x=self.fc(x); return x`。`__init__` 中创建 conv1（Conv2d，含卷积核权重）、relu1（ReLU，无参数）、pool1（MaxPool2d，无参数）、fc（Linear，含权重和偏置）四个子层。`__setattr__` 将这四个 Layer 属性加入 _params。参数收集过程：`optimizer.setup(model)` 绑定 model。update() 调用 model.params() 递归：conv1 是 Layer，递归收集其 W（卷积核）和 b（偏置）。relu1 无参数。pool1 无参数。fc 递归收集其 W 和 b。最终优化器拿到 conv1.W、conv1.b、fc.W、fc.b 四个参数，逐个更新。激活层和池化层无参数不参与收集。
</Answer>
