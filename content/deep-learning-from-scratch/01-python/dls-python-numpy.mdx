## 为什么用 NumPy

神经网络的核心运算是大规模矩阵乘法。Python 原生列表无法高效执行矩阵运算，而 NumPy 底层用 C 实现，支持向量化运算，速度快数十到数百倍。全书所有神经网络代码都基于 NumPy 构建。

<DlsPythonNumpyDiagram />

## ndarray 核心属性

NumPy 的核心数据结构是 `ndarray`（N-dimensional array），它有四个关键属性：

```python
import numpy as np

A = np.array([[1, 2, 3], [4, 5, 6]])
print(A.shape)   # (2, 3) —— 形状
print(A.dtype)   # int64  —— 元素类型
print(A.ndim)    # 2      —— 维度数
print(A.size)    # 6      —— 元素总数
```

## 向量化运算

向量化运算是 NumPy 的核心优势——对整个数组做运算时无需 Python `for` 循环：

```python
# Python 列表：需要循环
x = [1, 2, 3, 4]
y = [i ** 2 for i in x]  # [1, 4, 9, 16]

# NumPy：一行搞定
x = np.array([1, 2, 3, 4])
y = x ** 2  # array([1, 4, 9, 16])
```

<Callout type="info">

**关键洞察**：神经网络的矩阵乘法 `np.dot(X, W)` 一次性处理整个 mini-batch（N 个样本），无需 for 循环遍历每个样本。这是全书代码的基础模式。

</Callout>

## 广播（Broadcasting）

广播是 NumPy 对不同形状数组进行运算的机制，无需显式复制数据：

```python
# 标量广播
A = np.array([[1, 2], [3, 4]])  # shape (2, 2)
B = A + 10  # 每个元素加 10 → [[11, 12], [13, 14]]

# 一维广播（神经网络偏置加法）
X = np.random.randn(100, 784)   # (N, D) 100个样本
W = np.random.randn(784, 50)    # (D, H) 权重
b = np.random.randn(50)         # (H,)  偏置
Y = np.dot(X, W) + b            # (N, H) 偏置自动广播到每行
```

广播规则：

1. 维度从尾部（最右轴）对齐
2. 某维度大小相等或其中一个为 1，则可广播
3. 缺失维度视为 1
4. 最终形状取各维度最大值

## axis 参数与聚合

`axis` 参数指定聚合运算沿哪个轴进行：

```python
A = np.array([[1, 2, 3], [4, 5, 6]])  # shape (2, 3)

np.sum(A, axis=0)  # [5, 7, 9] —— 沿行方向，对每列求和
np.sum(A, axis=1)  # [6, 15]  —— 沿列方向，对每行求和
```

在神经网络中，计算 batch 平均损失或 BatchNorm 统计量时常用 `axis` 参数。

| 操作 | 代码 | 说明 |

</GlossaryItem>

<GlossaryItem term="广播（Broadcasting）">
NumPy 对不同形状数组进行算术运算的机制。规则：维度从尾部对齐，大小相等或为 1 的维度可广播，最终形状取最大值。在神经网络中用于偏置加法：矩阵 (N,H) + 向量 (H,) 自动广播。
</GlossaryItem>

<GlossaryItem term="向量化运算">
用 NumPy 数组运算替代 Python for 循环，一次性处理整个数组。底层用 C 实现，速度快数十到数百倍。例如 `x ** 2` 替代 `[i**2 for i in x]`。

</GlossaryItem>

<GlossaryItem term="np.dot">
NumPy 矩阵乘法函数。对于二维数组等价于矩阵乘法，是神经网络前向传播 `Y = np.dot(X, W) + b` 和反向传播 `dW = np.dot(X.T, dY)` 的核心运算。
</GlossaryItem>

### 问题 1

NumPy 的 ndarray 有哪些核心属性？为什么神经网络代码要用 NumPy 而非 Python 列表？

<Answer>

NumPy ndarray 的核心属性包括：shape（形状，表示各维度大小）、dtype（元素数据类型）、ndim（维度数）、size（元素总数）。神经网络代码使用 NumPy 而非 Python 列表的原因：①向量化运算——NumPy 底层用 C 实现，对整个数组做运算时无需 Python 循环，速度快数十到数百倍。②矩阵运算——神经网络的本质是矩阵乘法（np.dot），NumPy 原生支持高效矩阵操作。③广播机制——不同形状的数组可以自动对齐运算，代码简洁。④内存连续——ndarray 在内存中连续存储，CPU 缓存命中率高。全书所有神经网络代码都基于 NumPy 向量化运算构建。

</Answer>

### 问题 2

什么是 NumPy 广播（Broadcasting）？广播规则是什么？举例说明。

<Answer>

广播是 NumPy 对不同形状的数组进行算术运算的机制，无需显式复制数据即可将较小数组「扩展」到较大数组的形状。广播规则：①维度从尾部（最右轴）对齐。②如果某维度大小相等或其中一个为 1，则可以广播。③缺失的维度视为 1。④最终形状取各维度最大值。举例：①标量广播——A(3,4) + 5，标量 5 广播为 (3,4)。②一维广播——A(3,4) + B(4,)，B 沿第 0 轴复制为 (3,4)。③二维广播——A(3,1) + B(1,4)，均复制为 (3,4)。广播在神经网络中用于偏置加法：矩阵 W·x 的形状为 (N, M)，偏置 b 的形状为 (M,)，通过广播 b 自动加到每一行。

</Answer>

### 问题 3

NumPy 中 axis 参数的作用是什么？在神经网络中如何使用？

<Answer>

axis 参数指定聚合运算（如 sum、mean、max）沿哪个轴进行。对于二维数组 A(shape=(3,4))：axis=0 表示沿行方向（第 0 轴）聚合，结果形状为 (4,)，即对每一列求和；axis=1 表示沿列方向（第 1 轴）聚合，结果形状为 (3,)，即对每一行求和。在神经网络中的使用：①计算 batch 的平均损失——对 mini-batch 的 N 个样本损失求平均。②softmax 沿类别维度归一化——对每个样本的输出向量沿类别轴做 exp/sum，需要 `x - x.max(axis=1, keepdims=True)` 做数值稳定。③BatchNorm 计算均值和方差——沿 batch 轴（axis=0）计算每个特征的统计量。keepdims=True 保持维度以便广播运算。

</Answer>

### 问题 4

在神经网络实现中，如何用 NumPy 高效实现矩阵乘法和广播偏置？写出关键代码并解释。

<Answer>

神经网络前向传播的核心是矩阵乘法加偏置。对于输入 X(shape=(N, D))，权重 W(shape=(D, H))，偏置 b(shape=(H,))，前向传播代码：`A = np.dot(X, W) + b`。解释：①np.dot(X, W) 计算矩阵乘法，结果形状为 (N, H)。②加偏置 b 时利用广播机制：b 的形状 (H,) 自动广播为 (N, H)，即 b 加到每个样本的对应位置。③无需 for 循环遍历 batch，一次性处理整个 mini-batch。反向传播时梯度计算同样利用矩阵运算：`dW = np.dot(X.T, dA)`、`dX = np.dot(dA, W.T)`、`db = np.sum(dA, axis=0)`。全书的神经网络实现都是基于这种 NumPy 矩阵运算模式构建的。

</Answer>
