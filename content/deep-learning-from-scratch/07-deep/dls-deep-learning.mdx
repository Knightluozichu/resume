## 类层级框架封装

本书将所有组件设计为统一的「层」接口，每个层实现 `forward` 和 `backward` 两个方法：

```python
class Affine:
    def forward(self, x): ...
    def backward(self, dout): ...

class ReLU:
    def forward(self, x): ...
    def backward(self, dout): ...

class SoftmaxWithLoss:
    def forward(self, x, t): ...
    def backward(self, dout=1): ...
```

用 `OrderedDict` 串联各层构建模型，`Trainer` 类封装训练循环：

```python
class TwoLayerNet:
    def __init__(self, ...):
        self.layers = OrderedDict()
        self.layers['Affine1'] = Affine(W1, b1)
        self.layers['ReLU1'] = ReLU()
        self.layers['Affine2'] = Affine(W2, b2)
        self.last_layer = SoftmaxWithLoss()

    def predict(self, x):
        for layer in self.layers.values():
            x = layer.forward(x)
        return x
```

<Callout type="info">

**设计思想**：添加新层只需实现 forward/backward，模型组合变得灵活。这种设计为迁移到 PyTorch 等框架打下基础——PyTorch 的 `nn.Module` 遵循同样的 `forward` 接口理念。

</Callout>

## GPU 加速

深度学习的核心运算是大规模矩阵乘法，CPU 核心数少（4-16 核），并行度不足。GPU 有数千个轻量核心，天然适合并行执行矩阵运算中的大量独立乘加操作。

CUDA（Compute Unified Device Architecture）是 NVIDIA 的并行计算平台，将矩阵乘法分解为大量线程，每个线程计算输出矩阵的一个元素，分配到 GPU 的数千核心上同时执行。

实际使用中，PyTorch/TensorFlow 通过 cuDNN 库自动将运算调度到 GPU，用户只需将模型和数据 `.to('cuda')` 即可。

## 学习率衰减

训练初期需要大学习率快速接近最优区域，但接近最优解时大学习率会导致振荡。衰减策略让学习率逐步减小，实现「先快后稳」。

| 策略 | 公式 | 特点 |
|------|------|------|
| 指数衰减 | `η = η0 · α^epoch` | 简单常用，α 如 0.95 |
| 余弦退火 | `η = ηmin + 0.5(η0-ηmin)(1+cos(πt/T))` | 平滑衰减，效果优 |
| 阶跃衰减 | 每 N epoch 乘固定因子 | 简单直观 |

## 从手写到框架的迁移

<Callout type="tip">

**关键对应**：理解手写原理后再用框架，能做到「知其然且知其所以然」。手写的 Affine 层 → `nn.Linear`，反向传播 → `loss.backward()` 自动完成，SGD/Adam → `torch.optim`。

</Callout>

| 手写实现 | PyTorch |
|---------|---------|
| Affine 层 | `nn.Linear` |
| ReLU 层 | `nn.ReLU` |
| Convolution 层 | `nn.Conv2d` |
| Pooling 层 | `nn.MaxPool2d` |
| 手写反向传播 | `loss.backward()` 自动完成 |
| 手写 SGD/Adam | `torch.optim.SGD/Adam` |
| CPU 运行 | `.to('cuda')` 自动 GPU |

<Glossary>

<GlossaryItem term="类层级框架">
将神经网络组件设计为统一接口的类（每个层实现 forward/backward），用 OrderedDict 串联成模型。本书的 DeeperNetWriter 框架，设计思想与 PyTorch 的 nn.Module 一致。添加新层只需实现两个方法。
</GlossaryItem>

<GlossaryItem term="Trainer">
封装训练循环的类。接收模型和数据，执行 mini-batch 迭代、前向传播、损失计算、反向传播、参数更新，并记录 loss/accuracy 曲线。将训练逻辑与模型定义分离。
</GlossaryItem>

<GlossaryItem term="CUDA">
NVIDIA 的并行计算平台。将矩阵乘法分解为大量线程，分配到 GPU 的数千核心上同时执行。PyTorch/TensorFlow 通过 cuDNN 自动调度到 GPU，用户只需 .to('cuda')。矩阵乘法速度比 CPU 快数十到数百倍。
</GlossaryItem>

<GlossaryItem term="学习率衰减">
训练过程中逐步减小学习率的策略。初期大学习率快速接近最优区域，后期小学习率稳定收敛。常用：指数衰减（η=η0·α^epoch）、余弦退火、阶跃衰减。是最重要的超参数之一。
</GlossaryItem>

<GlossaryItem term="自动微分">
框架自动计算梯度的能力。用户只需定义前向传播，框架通过计算图自动反向传播计算所有参数梯度。PyTorch 的 loss.backward() 即自动微分。替代了手写反向传播，大幅减少代码量和出错可能。
</GlossaryItem>

</Glossary>

### 问题 1

本书如何实现类层级的神经网络框架（DeeperNetWriter）？有哪些核心类？

<Answer>

核心设计思想是「所有层实现 forward 和 backward 两个方法」。核心类：①Affine 层——全连接层。②ReLU/Sigmoid 层——激活函数层。③Softmax-with-Loss 层——将 softmax 和交叉熵合并。④Convolution 层——卷积层，用 im2col 优化。⑤Pooling 层——池化层。⑥BatchNormalization 层。⑦Dropout 层。这些层通过 OrderedDict 串联成 Sequential 模型。Trainer 类封装训练循环：接收模型和数据，执行 mini-batch 迭代、前向传播、损失计算、反向传播、参数更新，并记录曲线。添加新层只需实现 forward/backward，为迁移到 PyTorch 打下基础。

</Answer>

### 问题 2

为什么深度学习需要 GPU？CUDA 如何加速矩阵运算？

<Answer>

深度学习需要 GPU 的原因：①计算密集——核心运算是大规模矩阵乘法，CPU 核心数少（4-16核），并行度不足。②GPU 架构优势——有数千个轻量核心，天然适合并行执行矩阵运算中的大量独立乘加操作。CUDA 加速矩阵运算的原理：将矩阵乘法分解为大量线程，每个线程计算输出矩阵的一个元素或一小块，分配到 GPU 的数千核心上同时执行。GPU 的高带宽显存配合大规模并行核心，可使矩阵乘法速度比 CPU 快数十到数百倍。PyTorch/TensorFlow 通过 cuDNN 库自动调度到 GPU，用户只需 .to('cuda')。

</Answer>

### 问题 3

学习率衰减有哪些策略？为什么需要学习率衰减？

<Answer>

需要衰减的原因：训练初期需大学习率快速接近最优区域，但接近最优解时大学习率会导致振荡无法收敛。策略：①指数衰减——η=η0·α^epoch，每轮乘衰减率α（如0.95），简单常用。②余弦退火——η=ηmin+0.5(η0-ηmin)(1+cos(πt/T))，从η0平滑衰减到ηmin，效果通常优于指数。③阶跃衰减——每训练一定epoch后乘固定因子。④Warmup——前若干步用小学习率逐渐增大再衰减，用于稳定训练初期。⑤自适应优化器内置——Adam本身有自适应学习率，但仍可叠加全局衰减。学习率和衰减策略是最重要的超参数之一，通常通过验证集选择。

</Answer>

### 问题 4

从手写 NumPy 实现迁移到 PyTorch 框架时，有哪些关键对应关系？框架的优势是什么？

<Answer>

关键对应关系：①层定义——手写 Affine→nn.Linear，ReLU→nn.ReLU，Convolution→nn.Conv2d，Pooling→nn.MaxPool2d。②模型组装——OrderedDict→nn.Sequential 或自定义 Module。③损失函数——手写 softmax+交叉熵→nn.CrossEntropyLoss（内置softmax）。④自动微分——手写 backward()→loss.backward() 自动完成。⑤优化器——手写 SGD/Adam→torch.optim.SGD/Adam。⑥GPU——.to('cuda') 自动调度。框架优势：①自动微分减少代码量和出错。②预置组件开箱即用。③一行代码切换 CPU/GPU。④生态：预训练模型、可视化、分布式训练。理解手写原理后再用框架，能做到知其然且知其所以然。

</Answer>
