## 判别模型 vs 生成模型

机器学习模型可以分为两大类：**判别模型**和**生成模型**。理解它们的区别是学习生成模型的起点。

<DlgGenerativeModelsBasicsDiagram />

### 判别模型

判别模型学习条件分布 `P(y|x)`——给定输入 x，预测标签 y。例如图像分类器学习「这张图片是猫还是狗」。判别模型关注**决策边界**——如何最好地区分不同类别。

### 生成模型

生成模型学习数据分布 `P(x)` 或联合分布 `P(x,y)`——学习数据本身长什么样。生成模型关注**数据分布**——如何最好地建模数据的统计规律。一旦学会了数据分布，就能从中采样生成全新的、从未见过的样本。

<Callout type="info">

**关键区别**：判别模型学会「区分」数据，生成模型学会「创造」数据。生成模型能做判别模型能做的事（通过贝叶斯定理 `P(y|x) = P(x,y)/P(x)`），反之不行。

</Callout>

## 生成模型的核心目标

生成模型的核心目标是学习一个模型分布 `P_model(x)`，使其尽可能逼近真实数据分布 `P_data(x)`。

### 形式化描述

给定训练集 `{x_1, x_2, ..., x_n}`（假设从 `P_data` 独立采样），找到模型参数 theta 使 `P_model(x; theta)` 最接近 `P_data(x)`。

### 训练方法

| 方法 | 说明 | 代表模型 |
|------|------|---------|
| 最大似然估计 | 最大化 `log P_model(x_i; theta)` 的平均 | VAE / 流模型 |
| 对抗训练 | 让生成分布逼近数据分布（不显式建模 P(x)） | GAN |
| 迭代去噪 | 通过逐步去噪近似数据分布 | 扩散模型 |

## 生成模型家族

生成模型按密度建模方式分为四大类：

### 1. 显式密度模型

显式定义并优化 `P_model(x)`：

- **VAE**：用变分下界（ELBO）近似 `log P(x)`，不精确但有理论保证
- **流模型**：用可逆变换精确计算 `log P(x)`，精确但架构受限

### 2. 隐式密度模型

不显式建模 `P(x)`，通过对抗训练让生成样本分布逼近数据分布：

- **GAN**：生成器与判别器博弈，生成清晰但不稳定

### 3. 迭代采样模型

通过多步迭代逐步逼近数据分布：

- **扩散模型**：前向加噪 + 反向去噪，质量最高但采样慢

### 4. 条件生成

在上述模型基础上引入条件信息（文本、类别等），实现可控生成：

- **文生图**：文本条件引导扩散模型生成图像

## 噪声采样的作用

生成模型通常从噪声 `z ~ N(0, I)` 采样开始，通过模型 G(z) 将简单分布变换为复杂数据分布。

<Callout type="tip">

**为什么从噪声开始？** 噪声 z 是一个已知的、易于采样的简单分布。模型学习一个映射 G(z) 将简单分布变换为复杂的数据分布 P_data(x)。不同的 z 产生不同的生成样本，自然地提供了生成多样性。z 的每个维度可以编码数据的语义特征，通过操纵 z 可以实现可控生成。

</Callout>

```python
# 生成模型的基本范式：从噪声到数据
import torch

# 1. 从标准正态分布采样噪声
z = torch.randn(1, 100)  # 100维噪声向量

# 2. 通过生成器模型变换
# G 是一个神经网络，将 100 维噪声映射为图像
generated_image = G(z)  # 输出: [1, 3, 64, 64] 的图像

# 3. 不同的 z 生成不同的图像
z2 = torch.randn(1, 100)
another_image = G(z2)  # 不同的生成结果
```

## 生成模型的评估挑战

与判别模型不同，生成模型的评估没有简单的「准确率」指标：

| 挑战 | 说明 |
|------|------|
| 逼真度 | 生成样本是否看起来像真实数据？ |
| 多样性 | 生成样本是否覆盖了数据分布的所有模式？ |
| 语义一致性 | 条件生成是否遵循了条件约束？ |

这些挑战催生了 FID、IS、CLIP Score 等评估指标（详见 ch8）。

<Glossary>

<GlossaryItem term="判别模型（Discriminative Model）">
学习条件分布 P(y|x) 的模型。给定输入 x，预测标签 y。关注决策边界——如何最好地区分不同类别。代表：逻辑回归、SVM、CNN 分类器。判别模型不能生成新样本，只能做预测。
</GlossaryItem>

<GlossaryItem term="生成模型（Generative Model）">
学习数据分布 P(x) 或联合分布 P(x,y) 的模型。能从学习到的分布中采样生成新样本。关注数据分布——如何最好地建模数据的统计规律。代表：VAE、GAN、扩散模型、流模型。生成模型能做判别模型能做的事（通过贝叶斯定理），反之不行。
</GlossaryItem>

<GlossaryItem term="最大似然估计（MLE）">
生成模型的核心训练方法。给定训练集 {x_1,...,x_n}，最大化对数似然的平均：max_theta (1/n) sum log P_model(x_i; theta)。等价于最小化 KL(P_data || P_model)。VAE 用 ELBO 近似最大似然，流模型可精确计算似然，GAN 不使用最大似然（隐式密度）。
</GlossaryItem>

<GlossaryItem term="显式密度 vs 隐式密度">
显式密度模型（VAE、流模型）显式定义 P_model(x) 并优化它——可以计算（或近似计算）任意数据点的概率密度。隐式密度模型（GAN）不显式定义 P(x)，而是通过对抗训练让生成样本分布逼近数据分布——无法计算单个样本的概率密度，但可以采样生成。扩散模型介于两者之间：有明确的概率框架（变分推断），但实际训练用简化的去噪损失。
</GlossaryItem>

<GlossaryItem term="噪声空间（Noise Space / Latent Space）">
生成模型的输入空间。通常为标准正态分布 N(0,I) 的低维空间（如 100 维或 256 维）。模型学习从噪声空间到数据空间的映射 G(z)。噪声空间的每个点 z 对应一个生成样本。噪声空间的结构决定了生成模型的能力——VAE 的隐空间连续可插值，GAN 的隐空间有语义方向，扩散模型在隐空间（LDM）中扩散加速计算。
</GlossaryItem>

</Glossary>

### 问题 1

什么是生成模型？它与判别模型有什么本质区别？

<Answer>

生成模型是一类学习数据分布 P(x)（或联合分布 P(x,y)）的机器学习模型，能够从学习到的分布中采样生成新样本。判别模型学习条件分布 P(y|x)——给定输入 x 预测标签 y。本质区别：判别模型关注「如何区分」不同类别（学习决策边界），生成模型关注「数据长什么样」（学习数据分布）。举例：对于猫狗图片，判别模型学会区分猫和狗（输出标签），生成模型学会猫和狗各自长什么样（能生成新图片）。生成模型可以做判别模型能做的事（通过贝叶斯定理 P(y|x) = P(x,y)/P(x)），反之不行。
</Answer>

### 问题 2

生成模型的核心目标是什么？如何形式化描述？

<Answer>

生成模型的核心目标是学习一个模型分布 P_model(x)，使其尽可能逼近真实数据分布 P_data(x)。形式化：给定训练集 {x_1, ..., x_n}（假设从 P_data 独立采样），找到模型参数 theta 使 P_model(x; theta) 最接近 P_data(x)。常用方法：①最大似然估计——最大化 log P_model(x_i; theta) 的平均，等价于最小化 KL(P_data || P_model)。②显式密度——VAE 用变分下界（ELBO）近似，流模型用变量替换精确计算。③隐式密度——GAN 不显式建模 P(x)，而是通过对抗训练让生成样本分布逼近数据分布。④迭代采样——扩散模型通过逐步去噪近似数据分布。
</Answer>

### 问题 3

生成模型家族分为哪几大类？各自的特点是什么？

<Answer>

生成模型家族分为四大类：①显式密度模型——VAE 和流模型。VAE 用变分推断优化 ELBO 下界（不精确但有理论保证），流模型用可逆变换精确计算对数似然（精确但架构受限）。②隐式密度模型——GAN。不显式建模 P(x)，通过生成器-判别器对抗博弈让生成分布逼近数据分布，生成质量高但训练不稳定。③迭代采样模型——扩散模型。通过前向加噪和反向去噪过程学习生成，训练稳定且质量最高，但采样速度慢。④条件生成——在上述模型基础上引入条件信息（如文本、类别），实现可控生成，文生图是典型应用。
</Answer>

### 问题 4

为什么生成模型通常从噪声 z 采样开始？噪声分布的作用是什么？

<Answer>

生成模型从噪声 z 采样开始的原因：①可控生成——噪声 z ~ N(0, I) 是一个已知的、易于采样的简单分布。模型学习一个映射 G(z) 将简单分布变换为复杂的数据分布 P_data(x)，这个过程是「从简单到复杂」的变换。②数学便利——高斯分布有良好的数学性质（可微分、解析概率密度），使得最大似然训练和梯度优化可行。③隐空间结构——z 的每个维度可以编码数据的某种语义特征，通过在隐空间中插值或操纵可以实现可控生成。④多样性——不同的 z 采样产生不同的生成样本，自然地提供了生成多样性。VAE、GAN、流模型和扩散模型都采用了这一范式。
</Answer>
