## 自编码器：学习数据的压缩表示

**自编码器（Autoencoder, AE）**是最简单的生成模型雏形。它由编码器和解码器组成，通过重建输入来学习数据的压缩表示。

<DlgAutoencoderVaeDiagram />

### AE 的结构

```text
输入 x → [编码器] → 隐向量 z → [解码器] → 重建 x'
```

编码器将高维输入 $x$ 映射到低维隐向量 $z = \text{Encoder}(x)$，解码器将隐向量重建为 $x' = \text{Decoder}(z)$。训练目标是最小化重建误差 $\|x - x'\|^2$。

### AE 的局限性

<Callout type="warning">

**AE 不能直接用于生成**：AE 的隐向量 $z$ 是确定性映射，不是概率分布。隐空间可能不连续、有空洞——从隐空间随机采样 $z$ 不能保证解码出有意义的样本。AE 只能「重建」已见过的数据，不能「创造」新数据。

</Callout>

## 变分自编码器（VAE）

**VAE** 通过将隐空间改为概率分布，解决了 AE 不能生成的问题。

### 概率隐空间

VAE 的编码器不输出确定性向量 $z$，而是输出**均值 $\mu$** 和**方差 $\sigma^2$**，隐向量 $z$ 从分布 $\mathcal{N}(\mu, \sigma^2)$ 采样：

```text
x → [编码器] → (mu, sigma^2) → 采样 z ~ N(mu, sigma^2) → [解码器] → x'
```

### 重参数化技巧

直接从 $\mathcal{N}(\mu, \sigma^2)$ 采样 $z$ 不可微分（采样操作有随机性，无法反向传播梯度）。

**重参数化**将采样改写为：

$$z = \mu + \sigma \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

这样梯度可以通过 $\mu$ 和 $\sigma$ 传播，随机性被转移到 $\epsilon$（不需要梯度），使整个模型可以端到端训练。

```python
# VAE 重参数化的 PyTorch 实现
class VAE(nn.Module):
    def __init__(self, input_dim=784, hidden_dim=400, latent_dim=20):
        super().__init__()
        # 编码器：输出均值和对数方差
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        # 解码器
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid(),
        )

    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)  # 随机噪声，不需要梯度
        return mu + std * eps        # 重参数化：梯度可通过 mu 和 std 传播

    def forward(self, x):
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        z = self.reparameterize(mu, logvar)  # 采样
        x_recon = self.decoder(z)
        return x_recon, mu, logvar
```

## VAE 损失函数：ELBO

VAE 的损失函数是**变分下界（ELBO）**的负数：

$$\mathcal{L} = \underbrace{-\mathbb{E}_{q(z|x)}[\log P(x|z)]}_{\text{重建损失}} + \underbrace{KL(q(z|x) \| \mathcal{N}(0, I))}_{\text{KL 散度}}$$

### 重建损失

衡量解码器从采样的 $z$ 重建原始输入 $x$ 的能力。通常用交叉熵（二值图像）或均方误差（连续图像）。这一项确保模型能准确重建训练数据。

### KL 散度

衡量编码器输出的后验分布 $q(z|x) = \mathcal{N}(\mu, \sigma^2)$ 与先验标准正态分布 $\mathcal{N}(0, I)$ 的差异。这一项**正则化**隐空间，使其接近标准正态分布，从而能从 $\mathcal{N}(0, I)$ 采样生成有意义的新样本。

<Callout type="tip">

**两项的权衡**：重建损失保证保真度，KL 散度保证生成能力。如果 KL 权重过大，重建模糊；如果过小，隐空间退化为 AE（不能生成）。`beta-VAE` 通过调节 KL 权重 $\beta$ 控制隐空间的解耦程度。

</Callout>

### KL 散度的解析形式

对于高斯分布，KL 散度有解析解：

$$KL(\mathcal{N}(\mu, \sigma^2) \| \mathcal{N}(0, 1)) = \frac{1}{2} \sum_{j=1}^{d} \left(\mu_j^2 + \sigma_j^2 - \ln \sigma_j^2 - 1\right)$$

```python
# VAE 损失函数
def vae_loss(x_recon, x, mu, logvar):
    # 重建损失（BCE 适用于 [0,1] 归一化的图像）
    recon_loss = F.binary_cross_entropy(x_recon, x, reduction='sum')
    # KL 散度（解析形式）
    kl_div = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    return recon_loss + kl_div
```

## VAE 生成图像模糊的原因

<Callout type="info">

**VAE 模糊的根源**：重建损失（MSE/BCE）对所有像素等权，模型倾向于生成「平均」图像来最小化期望损失。加上高斯假设和采样噪声，VAE 的生成质量不如 GAN 和扩散模型。

</Callout>

### 改进方向

| 方法 | 思路 |
|------|------|
| VQ-VAE | 用离散隐空间替代连续采样 |
| VAE-GAN | 结合 GAN 判别器提升细节 |
| 层次化 VAE | 多层级隐变量建模更复杂分布 |
| 扩散模型 | 多步去噪替代单步重建 |

<Glossary>

<GlossaryItem term="自编码器（AE）">
由编码器和解码器组成的神经网络。编码器将输入 x 映射到低维隐向量 z = Encoder(x)，解码器将隐向量重建为 x' = Decoder(z)。训练目标是最小化重建误差 ||x - x'||^2。AE 用于降维、去噪、特征提取，但不能生成新样本——因为隐空间是确定性映射，不连续、有空洞。VAE 是 AE 的概率扩展，解决了生成问题。
</GlossaryItem>

<GlossaryItem term="重参数化技巧（Reparameterization Trick）">
VAE 的核心技术。直接从 N(mu, sigma^2) 采样 z 不可微分，无法反向传播。重参数化将采样改写为 z = mu + sigma * eps，其中 eps ~ N(0, I)。梯度通过 mu 和 sigma 传播，随机性转移到 eps（不需梯度），使整个模型端到端可训练。这是 VAE 能用梯度下降优化的关键。
</GlossaryItem>

<GlossaryItem term="ELBO（Evidence Lower Bound）">
变分推断中的对数似然下界。log P(x) >= ELBO = E_q[log P(x|z)] - KL(q(z|x)||p(z))。VAE 最大化 ELBO——第一项是重建项（让解码器能从 z 重建 x），第二项是正则项（让编码器输出的后验接近先验）。ELBO 与真实对数似然的差距等于 KL(q(z|x)||p(z|x))，当后验近似完美时差距为零。VAE 是「近似最大似然」——用变分分布 q(z|x) 近似真实后验 p(z|x)。
</GlossaryItem>

<GlossaryItem term="KL 散度（Kullback-Leibler Divergence）">
衡量两个概率分布差异的非对称度量。KL(P||Q) = sum P(x) * log(P(x)/Q(x))。在 VAE 中，KL 项迫使编码器输出的后验分布 q(z|x)（高斯）接近先验分布 p(z) = N(0,I)。KL=0 时两分布相同。KL 散度非负、非对称（KL(P||Q) != KL(Q||P)）。KL(q(z|x)||N(0,I)) 的解析形式 = 0.5 * sum(mu^2 + sigma^2 - log(sigma^2) - 1)。
</GlossaryItem>

<GlossaryItem term="beta-VAE">
VAE 的变体，通过调节 KL 散度的权重 beta 控制隐空间的解耦程度。损失 = 重建损失 + beta * KL。beta > 1 时强制更强的正则化，隐空间维度更容易编码独立的语义因子（如姿态、颜色、形状分别由不同维度控制），实现「解耦表示」。beta-VAE 是学习可解释隐空间的重要方法。
</GlossaryItem>

<GlossaryItem term="后验坍缩（Posterior Collapse）">
VAE 训练中的问题。当解码器足够强大时，它可以忽略输入 z 直接从自身参数生成输出，导致 KL(q(z|x)||p(z)) 趋近于 0（q(z|x) 退化为先验 p(z)），隐空间不携带任何信息。解决方法：减弱解码器能力、KL 退火（训练初期降低 KL 权重）、引入自回归解码器等。后验坍缩是 VAE 实践中最常见的训练失败模式之一。
</GlossaryItem>

</Glossary>

### 问题 1

自编码器（AE）的基本结构是什么？它能用于生成吗？

<Answer>

自编码器由编码器和解码器两部分组成。编码器将输入 x 映射到低维隐向量 z = Encoder(x)，解码器将隐向量重建为 x' = Decoder(z)。训练目标是最小化重建误差 ||x - x'||^2。AE 的作用是学习数据的压缩表示（降维），可用于去噪、特征提取。但标准 AE 不能直接用于生成——因为隐空间不是连续的概率分布，而是确定性映射。从隐空间随机采样 z 不能保证解码出有意义的样本（隐空间可能不连续、有空洞）。AE 的隐向量 z 只是对训练数据的精确编码，没有学习到数据的分布结构。
</Answer>

### 问题 2

VAE 与 AE 的关键区别是什么？重参数化技巧的作用是什么？

<Answer>

VAE 与 AE 的关键区别：①概率隐空间——AE 的 z 是确定性编码，VAE 的 z 是概率分布（编码器输出均值 mu 和方差 sigma，z 从 N(mu, sigma^2) 采样）。②损失函数——AE 只有重建损失，VAE 增加了 KL 散度项，迫使隐空间接近标准正态分布 N(0,I)。③生成能力——AE 不能生成新样本（隐空间不连续），VAE 可以从 N(0,I) 采样 z 并解码生成新样本。重参数化技巧的作用：直接从 N(mu, sigma^2) 采样 z 不可微分（采样操作有随机性，无法反向传播梯度）。重参数化将采样改写为 z = mu + sigma * eps，其中 eps ~ N(0, I)。这样梯度可以通过 mu 和 sigma 传播，而随机性被转移到 eps 上，使整个模型可以端到端训练。
</Answer>

### 问题 3

VAE 的损失函数是什么？每一项的作用是什么？

<Answer>

VAE 的损失函数（ELBO 的负数）= 重建损失 + KL 散度。①重建损失 = E_{q(z|x)}[log P(x|z)]——衡量解码器从采样的 z 重建原始输入 x 的能力。通常用交叉熵（二值图像）或均方误差（连续图像）。这一项确保模型能准确重建训练数据。②KL 散度 = KL(q(z|x) || N(0,I))——衡量编码器输出的后验分布 q(z|x)（即 N(mu, sigma^2)）与先验标准正态分布 N(0,I) 的差异。这一项起正则化作用：迫使隐空间接近标准正态分布，使隐空间连续、无空洞，从而能从 N(0,I) 采样生成有意义的新样本。两项的权衡：重建损失保证保真度，KL 散度保证生成能力。如果 KL 权重过大，重建模糊；如果过小，隐空间退化（类似 AE 不能生成）。
</Answer>

### 问题 4

VAE 生成图像通常模糊的原因是什么？有哪些改进方向？

<Answer>

VAE 生成图像模糊的原因：①损失函数特性——重建损失（MSE 或交叉熵）对所有像素等权，模型倾向于生成「平均」图像来最小化期望损失，导致模糊。②高斯假设——VAE 假设 P(x|z) 是高斯分布（或伯努利分布），对复杂图像细节的建模能力有限。③后验坍缩——当解码器足够强大时，KL 散度项可能被忽略（q(z|x) 退化为先验），隐空间不携带信息。④采样噪声——从 q(z|x) 采样 z 引入噪声，解码器需要「平均」多种可能的 z，导致输出模糊。改进方向：①VQ-VAE——用离散隐空间替代连续采样。②扩散模型——将生成分解为多步去噪，每步只需做微小修正。③VAE-GAN——结合 GAN 的判别器提升细节锐度。④层次化 VAE——多层级隐变量建模更复杂的数据分布。
</Answer>
