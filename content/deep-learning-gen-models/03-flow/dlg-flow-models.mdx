## 标准化流：精确的密度建模

**标准化流（Normalizing Flow）**是一种显式密度生成模型。它通过一系列**可逆变换**将简单分布（标准高斯 $\mathcal{N}(0, I)$）逐步变换为复杂的数据分布 $P_{\text{data}}(x)$。

<DlgFlowModelsDiagram />

### 核心思想

```text
正向（编码）：x → f_1 → f_2 → ... → f_K → z  （z ~ N(0,I)）
反向（生成）：z → f_K^(-1) → ... → f_2^(-1) → f_1^(-1) → x
```

从简单分布采样 $z$，经过逆变换链生成数据 $x$。关键优势：可以**精确计算**数据的对数似然，不像 VAE 只能用下界近似。

## 变量替换定理

流模型的理论基础是**变量替换定理**：如果 $z = f(x)$ 是可逆变换，则 $x$ 的概率密度可以通过 $z$ 的密度表示：

$$P(x) = P(z) \cdot \left|\det\left(\frac{\partial f}{\partial x}\right)\right|$$

取对数：

$$\log P(x) = \log P(z) + \sum_{i=1}^{K} \log \left|\det\left(\frac{\partial f_i}{\partial z_{i-1}}\right)\right|$$

### 为什么需要雅可比行列式

<Callout type="info">

**雅可比行列式度量变换对概率密度的「体积变化率」**。如果变换将空间放大 2 倍，密度需要除以 2（概率总量归一化）。行列式正是多维空间中体积变化率的度量。

</Callout>

如果雅可比是**三角矩阵**（如耦合层设计），行列式等于对角元素之积，计算复杂度从 $O(D^3)$ 降为 $O(D)$，使高维数据可行。

## 耦合层（Coupling Layer）

耦合层是流模型实现可逆变换的核心组件。以 **RealNVP** 仿射耦合为例：

### 设计

将输入向量 $x$ 分为两部分 $x = (x_a, x_b)$：

1. $x_a$ 直接复制到输出：$y_a = x_a$
2. $x_b$ 通过由 $x_a$ 参数化的仿射变换：$y_b = x_b \cdot \exp(s(x_a)) + t(x_a)$

其中 $s$ 和 $t$ 是任意神经网络（不需要可逆）。

### 可逆性

给定 $y$ 可以精确求逆：

$$x_a = y_a, \quad x_b = (y_b - t(y_a)) \cdot \exp(-s(y_a))$$

### 三角雅可比

因为 $y_a = x_a$（对角为 1），$y_b$ 只依赖 $x_b$（对角为 $\exp(s(x_a))$），雅可比矩阵是**下三角**，行列式 = $\prod \exp(s(x_a)) = \exp(\sum s(x_a))$，计算复杂度 $O(D)$。

```python
# RealNVP 耦合层的简化实现
class CouplingLayer(nn.Module):
    def __init__(self, dim, hidden_dim):
        super().__init__()
        # s 和 t 网络（任意神经网络，不需要可逆）
        self.st_net = nn.Sequential(
            nn.Linear(dim // 2, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, dim),  # 输出 s 和 t
        )

    def forward(self, x):
        # 分割为两半
        x_a, x_b = x.chunk(2, dim=-1)
        st = self.st_net(x_a)
        s, t = st.chunk(2, dim=-1)
        s = torch.tanh(s)  # 限制缩放范围
        y_a = x_a
        y_b = x_b * torch.exp(s) + t
        y = torch.cat([y_a, y_b], dim=-1)
        # 雅可比对数行列式 = sum(s)
        log_det = s.sum(dim=-1)
        return y, log_det

    def inverse(self, y):
        y_a, y_b = y.chunk(2, dim=-1)
        st = self.st_net(y_a)
        s, t = st.chunk(2, dim=-1)
        s = torch.tanh(s)
        x_a = y_a
        x_b = (y_b - t) * torch.exp(-s)
        return torch.cat([x_a, x_b], dim=-1)
```

### 多层堆叠

单层耦合中 $x_a$ 不变，通过多层**交替分割不同维度**（如奇偶交替），确保所有维度都被变换。

## 代表模型

| 模型 | 耦合方式 | 特点 |
|------|---------|------|
| NICE | 加性耦合 $y_b = x_b + t(x_a)$ | 最简单，无缩放 |
| RealNVP | 仿射耦合 $y_b = x_b \cdot \exp(s) + t$ | 增加缩放，更灵活 |
| Glow | 可逆 $1 \times 1$ 卷积 | 处理通道维度，图像生成 |

## 流模型的优势与劣势

<Callout type="tip">

**流模型最适合需要精确概率密度的场景**——如异常检测（低概率样本判为异常）、密度估计、数据压缩。但在纯图像生成任务中，生成质量不如 GAN 和扩散模型。

</Callout>

| 优势 | 劣势 |
|------|------|
| 精确对数似然（非下界） | 架构约束大（必须可逆、维度保持） |
| 双向可逆（编码+生成） | 表达能力受限 |
| 训练稳定（直接最大似然） | 内存开销大 |

<Glossary>

<GlossaryItem term="标准化流（Normalizing Flow）">
一种显式密度生成模型。通过一系列可逆变换将简单分布（高斯）逐步变换为复杂的数据分布。利用变量替换定理可精确计算数据似然：log P(x) = log P(z) + sum log|det(J)|。正向变换用于编码（x→z），逆变换用于生成（z→x）。代表模型有 NICE、RealNVP、Glow。优势是精确似然和双向可逆，劣势是架构约束大。
</GlossaryItem>

<GlossaryItem term="变量替换定理（Change of Variables）">
概率论基本定理。如果 z = f(x) 是可逆变换，则 x 的概率密度 P(x) = P(z) * |det(df/dx)|，其中 |det(df/dx)| 是雅可比矩阵的行列式绝对值。行列式度量变换对概率密度的体积变化率。流模型用这一定理精确计算数据似然——将复杂分布的数据 x 通过可逆变换映射到简单分布的 z，再用 z 的已知密度反推 x 的密度。
</GlossaryItem>

<GlossaryItem term="耦合层（Coupling Layer）">
流模型实现可逆变换的核心组件。将输入分为两部分 x_a 和 x_b：x_a 直接复制，x_b 通过 x_a 参数化的变换映射。RealNVP 用仿射变换 y_b = x_b * exp(s(x_a)) + t(x_a)。耦合层的雅可比矩阵是三角矩阵，行列式等于对角元素之积（O(D) 计算），使高维数据可行。多层交替分割不同维度确保所有维度被变换。NICE 是加性耦合（无缩放），RealNVP 增加缩放，Glow 引入可逆 1x1 卷积。
</GlossaryItem>

<GlossaryItem term="雅可比矩阵（Jacobian Matrix）">
多变量函数的一阶偏导数矩阵。J_ij = df_i/dx_j，度量变换 f 在各维度上的局部变化率。雅可比行列式 |det(J)| 是体积变化率——变换将局部空间放大或缩小的倍数。在流模型中，雅可比行列式用于变量替换定理计算概率密度。三角雅可比的行列式 = 对角元素之积，计算复杂度从 O(D^3) 降为 O(D)，是耦合层设计的核心动机。
</GlossaryItem>

<GlossaryItem term="RealNVP">
Real-valued Non-Volume Preserving，流模型的代表架构。使用仿射耦合层（y_b = x_b * exp(s(x_a)) + t(x_a)）实现可逆变换，比 NICE 的加性耦合增加了缩放参数，表达能力更强。通过多层交替分割（奇偶/上下分割）确保所有维度被变换。RealNVP 在图像生成上取得了较好的效果，是流模型从理论走向实用的关键工作。
</GlossaryItem>

</Glossary>

### 问题 1

什么是标准化流（Normalizing Flow）？它的核心思想是什么？

<Answer>

标准化流是一种显式密度生成模型。核心思想：通过一系列可逆变换将简单分布（如标准高斯 N(0,I)）逐步变换为复杂的数据分布 P_data(x)。正向（编码）：数据 x 经过 K 个可逆变换 f_1, f_2, ..., f_K 映射到隐变量 z（z 服从简单分布）。反向（生成）：从简单分布采样 z，经过逆变换 f_K^(-1), ..., f_1^(-1) 生成数据 x。关键优势：通过变量替换定理可以精确计算数据的对数似然 log P(x) = log P(z) + sum log|det(df_i/dz_i)|，不像 VAE 只能用下界近似。代表模型：NICE、RealNVP、Glow。
</Answer>

### 问题 2

流模型的变量替换定理是什么？为什么需要雅可比行列式？

<Answer>

变量替换定理：如果 z = f(x) 是可逆变换，则 x 的概率密度可以通过 z 的密度表示：P(x) = P(z) * |det(df/dx)|，其中 |det(df/dx)| 是变换 f 的雅可比矩阵的行列式绝对值。取对数：log P(x) = log P(z) + log|det(df/dx)|。对于 K 个变换的链：log P(x) = log P(z_K) + sum log|det(df_i/dz_{i-1})|。需要雅可比行列式的原因：概率密度在变换时会「拉伸」或「压缩」——雅可比行列式度量了变换对概率密度的体积变化率。如果变换将空间放大 2 倍，密度需要除以 2。行列式正是多维空间中体积变化率的度量。如果雅可比是三角矩阵，行列式等于对角元素之积，计算复杂度从 O(D^3) 降为 O(D)。
</Answer>

### 问题 3

流模型的耦合层是如何设计的？为什么它能让雅可比行列式易于计算？

<Answer>

耦合层设计（以 RealNVP 仿射耦合为例）：将输入向量 x 分为两部分 x = (x_a, x_b)。①x_a 直接复制到输出：y_a = x_a。②x_b 通过由 x_a 参数化的仿射变换：y_b = x_b * exp(s(x_a)) + t(x_a)。优势：①可逆——给定 y 可以精确求逆：x_a = y_a，x_b = (y_b - t(y_a)) * exp(-s(y_a))。②雅可比是三角矩阵——因为 y_a = x_a（对角为 1），y_b 只依赖 x_b（对角为 exp(s(x_a))），雅可比矩阵是下三角，行列式 = prod exp(s(x_a)) = exp(sum s(x_a))，计算复杂度 O(D)。③多层堆叠——单层耦合中 x_a 不变，通过多层交替分割不同维度（如奇偶交替），确保所有维度都被变换。
</Answer>

### 问题 4

流模型与 VAE、GAN 相比有什么优劣？为什么流模型在实践中不如扩散模型流行？

<Answer>

流模型的优势：①精确似然——可以精确计算 P(x)，不像 VAE 用 ELBO 下界，GAN 完全没有密度估计。②双向映射——编码（x→z）和解码（z→x）都精确可逆，适合异常检测、数据压缩。③训练稳定——直接最大似然训练，无对抗博弈。劣势：①架构约束——变换必须可逆且维度保持，限制了网络设计自由度。②表达能力受限——可逆约束使模型难以学习非常复杂的分布，生成质量通常不如 GAN 和扩散模型。③内存开销大。流模型不如扩散模型流行的原因：扩散模型虽然采样慢，但生成质量远超流模型，且架构设计自由（任何网络都可作为去噪网络），无需可逆约束。流模型更适合需要精确概率密度的场景。
</Answer>
