## GAN：对抗博弈的生成范式

**生成对抗网络（GAN）**用一种全新的思路解决生成问题：不显式建模数据分布 P(x)，而是通过两个网络的**对抗博弈**让生成分布逼近数据分布。

<DlgGanBasicsDiagram />

### 两个角色

- **生成器 G**：输入随机噪声 `z ~ N(0, I)`，输出假样本 `G(z)`。目标是生成足够逼真的样本欺骗判别器。
- **判别器 D**：输入样本（真实数据 x 或生成数据 G(z)），输出该样本为真实的概率 `D(x)`。目标是正确区分真实样本和生成样本。

### 对抗博弈

G 试图最小化 D 的判别能力（让 `D(G(z))` 接近 1），D 试图最大化判别能力（让 `D(x)` 接近 1，`D(G(z))` 接近 0）。当达到纳什均衡时，G 生成的样本分布等于真实数据分布，D 无法区分（输出 0.5）。

## GAN 损失函数

GAN 的原始损失函数是**极小极大博弈**：

```text
min_G max_D V(D, G) = E[log D(x)] + E[log(1 - D(G(z)))]
```

- 判别器 D 最大化 V（正确分类真实和生成样本）
- 生成器 G 最小化 V（让 D 无法区分真假）

### 非饱和损失

<Callout type="warning">

**梯度消失问题**：在训练初期，生成器 G 很差，D 很容易区分真假，`D(G(z))` 接近 0。此时 `log(1 - D(G(z)))` 接近 `log(1) = 0`，梯度几乎为零，G 无法有效学习。

</Callout>

**解决方案**：生成器改为最大化 `log(D(G(z)))`。当 `D(G(z))` 接近 0 时，`log(D(G(z)))` 趋向负无穷，梯度很大，G 能快速学习。这个改动在理论目标上等价，但提供了更强的梯度信号。

```python
# GAN 训练的 PyTorch 伪代码
import torch
import torch.nn as nn
import torch.optim as optim

# 判别器损失：真实样本标签 1，生成样本标签 0
criterion = nn.BCELoss()

def train_discriminator(D, G, real_data, z, optimizer_d):
    optimizer_d.zero_grad()
    # 真实样本
    d_real = D(real_data)
    loss_real = criterion(d_real, torch.ones_like(d_real))
    # 生成样本
    fake_data = G(z).detach()  # detach 防止梯度传到 G
    d_fake = D(fake_data)
    loss_fake = criterion(d_fake, torch.zeros_like(d_fake))
    loss_d = loss_real + loss_fake
    loss_d.backward()
    optimizer_d.step()
    return loss_d

def train_generator(D, G, z, optimizer_g):
    optimizer_g.zero_grad()
    fake_data = G(z)
    d_fake = D(fake_data)
    # 非饱和损失：最大化 log(D(G(z)))
    loss_g = criterion(d_fake, torch.ones_like(d_fake))
    loss_g.backward()
    optimizer_g.step()
    return loss_g
```

## GAN 的训练挑战

### 1. 模式崩溃（Mode Collapse）

生成器只学会生成少数几种样本（甚至只生成一种），缺乏多样性。判别器无法惩罚这种「偷懒」行为——因为少量逼真样本就能骗过 D。

### 2. 训练不稳定

GAN 是两人零和博弈，需要找到纳什均衡。但梯度下降只保证找到局部最优，不保证找到博弈均衡。D 和 G 的交替更新可能陷入振荡或发散。

### 3. 梯度消失

如果 D 太强（`D(G(z))` 约等于 0），G 的梯度消失；如果 D 太弱，G 的梯度无意义。需要保持 D 和 G 的能力平衡。

<Callout type="info">

**GAN 训练本质上是博弈问题而非优化问题**——这是 GAN 与 VAE（优化 ELBO）和扩散模型（优化去噪 MSE）的根本区别，也是 GAN 难以训练的理论根源。

</Callout>

## 缓解方法

| 方法 | 思路 |
|------|------|
| WGAN | 用 Wasserstein 距离替代 JS 散度，提供更平滑梯度 |
| Minibatch discrimination | 判别器同时看一批样本，检测多样性 |
| 经验回放 | 保留历史生成器，增加判别器看到的样本多样性 |
| 标签平滑 | 用 0.9 替代 1 作为真实标签，防止 D 过自信 |

<Glossary>

<GlossaryItem term="生成对抗网络（GAN）">
由生成器 G 和判别器 D 组成的对抗博弈生成模型。G 从噪声 z 生成假样本 G(z)，D 区分真假样本。两者博弈：G 试图骗过 D，D 试图识破 G。形式化为极小极大博弈 min_G max_D E[log D(x)] + E[log(1-D(G(z)))]。GAN 是隐式密度模型——不显式建模 P(x)。优势是生成清晰锐利，劣势是训练不稳定和模式崩溃。
</GlossaryItem>

<GlossaryItem term="极小极大博弈（Minimax Game）">
GAN 的训练框架。生成器 G 最小化博弈值 V（让 D 无法区分真假），判别器 D 最大化 V（正确区分真假）。V = E[log D(x)] + E[log(1-D(G(z)))]。这是两人零和博弈——一方的收益是另一方的损失。理论上当 G 和 D 达到纳什均衡时，生成分布等于真实分布，D 输出 0.5。但实践中梯度下降不保证找到纳什均衡，导致训练不稳定。
</GlossaryItem>

<GlossaryItem term="模式崩溃（Mode Collapse）">
GAN 训练中最常见的问题。生成器只学会生成少数几种样本（甚至一种），缺乏多样性。原因：生成器的梯度只告诉它「如何让当前样本更逼真」，而非「如何覆盖更多模式」。生成器找到 D 的弱点后不断利用，忽略数据分布的其他模式。缓解方法包括 WGAN、Minibatch discrimination、Unrolled GAN 等。模式崩溃是 GAN 最棘手的问题之一。
</GlossaryItem>

<GlossaryItem term="非饱和损失（Non-saturating Loss）">
GAN 的实用损失设计。原始 GAN 损失中生成器最小化 log(1-D(G(z)))，在训练初期 D 太强时梯度消失。非饱和损失改为最大化 log(D(G(z)))，当 D(G(z)) 接近 0 时梯度很大，解决了训练初期的梯度消失问题。这个改动在理论目标上等价（都是让 D(G(z)) 增大），但提供了更强的梯度信号。实践中所有 GAN 变体都使用非饱和损失。
</GlossaryItem>

<GlossaryItem term="WGAN（Wasserstein GAN）">
GAN 的改进变体。用 Wasserstein 距离（推土机距离）替代原始 GAN 的 JS 散度。Wasserstein 距离即使在分布不重叠时也能提供有意义的梯度，缓解了梯度消失和模式崩溃。WGAN 的判别器（称 critic）输出实数而非概率，需满足 Lipschitz 连续性约束（通过权重裁剪或梯度惩罚实现）。WGAN 训练更稳定，但生成质量与原始 GAN 相当。
</GlossaryItem>

<GlossaryItem term="JS 散度（Jensen-Shannon Divergence）">
原始 GAN 隐式最小化的散度度量。JS(P||Q) = 0.5*KL(P||M) + 0.5*KL(Q||M)，M = (P+Q)/2。JS 散度有界（[0, log2]）、对称。但当两个分布不重叠时，JS 散度为常数 log2，梯度为零——这是 GAN 训练不稳定的数学根源。WGAN 用 Wasserstein 距离替代 JS 散度解决了这一问题。
</GlossaryItem>

</Glossary>

### 问题 1

生成对抗网络（GAN）的基本原理是什么？生成器和判别器各自的作用是什么？

<Answer>

GAN 由生成器 G 和判别器 D 两个网络组成，通过对抗博弈训练。生成器 G：输入随机噪声 z ~ N(0,I)，输出假样本 G(z)，目标是生成足够逼真的样本欺骗判别器。判别器 D：输入样本（真实数据 x 或生成数据 G(z)），输出该样本为真实的概率 D(x)，目标是正确区分真实样本和生成样本。对抗博弈：G 试图最小化 D 的判别能力（让 D(G(z)) 接近 1），D 试图最大化判别能力（让 D(x) 接近 1，D(G(z)) 接近 0）。当达到纳什均衡时，G 生成的样本分布等于真实数据分布，D 无法区分（输出 0.5）。GAN 是隐式密度模型——不显式建模 P(x)。
</Answer>

### 问题 2

GAN 的损失函数是什么？为什么生成器不直接最小化 log(1-D(G(z)))？

<Answer>

GAN 的原始损失函数：min_G max_D V(D,G) = E[log D(x)] + E[log(1 - D(G(z)))]。生成器不直接最小化 log(1 - D(G(z))) 的原因：在训练初期，生成器 G 很差，D 很容易区分真假，D(G(z)) 接近 0，此时 log(1 - D(G(z))) 接近 log(1) = 0，梯度几乎为零，G 无法有效学习（梯度消失问题）。解决方案（非饱和 GAN 损失）：生成器改为最大化 log(D(G(z)))。当 D(G(z)) 接近 0 时，log(D(G(z))) 趋向负无穷，梯度很大，G 能快速学习。这个改动在理论目标上等价，但在实践中提供了更强的梯度信号，解决了训练初期的梯度消失问题。
</Answer>

### 问题 3

GAN 训练中的模式崩溃（Mode Collapse）是什么？如何缓解？

<Answer>

模式崩溃：生成器只学会生成少数几种样本（甚至只生成一种），缺乏多样性。判别器无法惩罚这种「偷懒」行为——因为少量逼真样本就能骗过 D。原因：生成器的梯度只告诉它「如何让当前样本更逼真」，而非「如何覆盖更多模式」。缓解方法：①WGAN——用 Wasserstein 距离替代 JS 散度，提供更平滑的梯度。②Minibatch discrimination——判别器同时看一批样本，检测生成样本的多样性。③Unrolled GAN——生成器考虑判别器未来几步的更新。④经验回放——保留历史生成器，增加判别器看到的样本多样性。⑤标签平滑——用 0.9 替代 1 作为真实标签，防止判别器过自信。
</Answer>

### 问题 4

GAN 的训练为什么不稳定？与 VAE 和扩散模型相比，GAN 的训练有什么本质困难？

<Answer>

GAN 训练不稳定的本质原因：①博弈论困境——GAN 是两人零和博弈，需要找到纳什均衡。但梯度下降只保证找到局部最优，不保证找到博弈均衡。D 和 G 的交替更新可能陷入振荡或发散。②梯度问题——如果 D 太强，G 的梯度消失；如果 D 太弱，G 的梯度无意义。③JS 散度缺陷——当真实分布和生成分布不重叠时，JS 散度为常数 log2，梯度为零。④评估困难——没有明确的训练目标，难以判断训练是否正确。与 VAE 和扩散模型对比：VAE 优化明确的 ELBO 下界，训练稳定但生成模糊。扩散模型优化明确的去噪 MSE 损失，训练稳定且质量高。GAN 用对抗博弈替代显式损失函数，虽然能生成清晰图像，但训练本质上是博弈问题而非优化问题，缺乏收敛保证。
</Answer>
