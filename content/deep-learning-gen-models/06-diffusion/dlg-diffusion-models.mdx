## 扩散模型：逐步去噪的生成范式

**扩散模型**通过前向加噪和反向去噪两个过程实现生成。它将生成问题转化为一系列去噪问题，每步只需做微小修正，大幅降低了学习难度。

## 前向过程：逐步加噪

前向过程是一个固定的马尔可夫链（**无需学习**），从原始数据 $x_0$ 逐步添加高斯噪声：

$$q(x_t | x_{t-1}) = \mathcal{N}\left(\sqrt{1 - \beta_t} \cdot x_{t-1}, \, \beta_t I\right)$$

其中 $\beta_t$ 是预设的**噪声调度**（如线性从 0.0001 到 0.02），$T$ 通常为 1000 步。

### 跳步计算

前向过程的重要性质：可以跳步直接计算任意 $x_t$：

$$x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1 - \bar{\alpha}_t} \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

其中 $\alpha_t = 1 - \beta_t$，$\bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$。这使得训练时无需逐步加噪，可以直接采样任意时间步 $t$ 的加噪样本。

## 反向过程：逐步去噪

反向过程从纯噪声 $x_T$ 开始，学习一个神经网络逐步去噪：

$$p_\theta(x_{t-1} | x_t) = \mathcal{N}\left(\mu_\theta(x_t, t), \, \sigma_\theta(x_t, t)\right)$$

<Callout type="info">

**核心思想**：将生成问题转化为去噪问题。每步只需做微小修正（去除一步噪声），降低了学习难度。这比 GAN 的「一次性生成」或 VAE 的「单步解码」更稳定、质量更高。

</Callout>

## DDPM 训练目标

**DDPM（Denoising Diffusion Probabilistic Models）**的关键贡献是简化了训练目标：**预测噪声 $\epsilon$**。

### 简化损失

$$\mathcal{L} = \mathbb{E}_{t, x_0, \epsilon}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$$

训练步骤：

1. 从训练集采样 $x_0$
2. 随机采样时间步 $t \sim \text{Uniform}(1, T)$
3. 采样噪声 $\epsilon \sim \mathcal{N}(0, I)$
4. 计算加噪样本 $x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1 - \bar{\alpha}_t} \cdot \epsilon$
5. 用神经网络 $\epsilon_\theta$ 预测加入的噪声 $\epsilon$
6. 最小化预测噪声与真实噪声的 MSE

### 为什么预测噪声而非直接预测 $x_0$

从 $x_t$ 和 $\epsilon$ 可以解析地求出 $x_0 = (x_t - \sqrt{1-\bar{\alpha}_t} \cdot \epsilon) / \sqrt{\bar{\alpha}_t}$，两者等价。但预测噪声 $\epsilon$ 是预测一个零均值、单位方差的标准化量，网络输出范围稳定，易于优化。

```python
# DDPM 训练的 PyTorch 伪代码
class DDPM:
    def __init__(self, T=1000, beta_start=1e-4, beta_end=0.02):
        self.T = T
        # 线性噪声调度
        self.betas = torch.linspace(beta_start, beta_end, T)
        self.alphas = 1 - self.betas
        self.alpha_bars = torch.cumprod(self.alphas, dim=0)

    def training_step(self, model, x_0):
        batch_size = x_0.shape[0]
        # 1. 随机采样时间步
        t = torch.randint(0, self.T, (batch_size,))
        # 2. 采样噪声
        eps = torch.randn_like(x_0)
        # 3. 计算加噪样本（跳步计算）
        alpha_bar_t = self.alpha_bars[t].view(-1, 1, 1, 1)
        x_t = torch.sqrt(alpha_bar_t) * x_0 + torch.sqrt(1 - alpha_bar_t) * eps
        # 4. 预测噪声
        eps_pred = model(x_t, t)
        # 5. MSE 损失
        loss = F.mse_loss(eps_pred, eps)
        return loss
```

## 噪声调度

噪声调度 $\beta_t$ 定义了每步添加的噪声量，直接影响生成质量。

| 调度 | 公式 | 特点 |
|------|------|------|
| 线性 | $\beta_t$ 从 $10^{-4}$ 线性增长到 0.02 | DDPM 原始论文 |
| 余弦 | $\bar{\alpha}_t$ 按余弦曲线衰减 | 噪声增长更均匀 |
| 学习式 | $\beta_t$ 作为可学习参数 | 自适应优化 |

<Callout type="tip">

**噪声调度的影响**：如果后期噪声太大，模型难以恢复细节；如果前期噪声太小，模型学不到全局结构。余弦调度在多种数据集上优于线性调度。

</Callout>

## 扩散模型的优势与缺点

### 优势

| 优势 | 说明 |
|------|------|
| 训练稳定 | 优化明确的去噪 MSE 损失，无对抗博弈 |
| 生成质量高 | 多步迭代去噪，超越 GAN |
| 多样性好 | 从纯噪声采样，覆盖完整数据分布 |
| 理论优美 | 基于非平衡热力学的变分推断 |

### 主要缺点与加速

**采样速度慢**：生成一张图像需要 $T=1000$ 步迭代，比 GAN 慢数百倍。

| 加速方法 | 原理 | 步数 |
|----------|------|------|
| DDIM | 修改反向过程为非马尔可夫，允许跳步 | ~50 步 |
| DPM-Solver | 基于扩散 ODE 的高阶求解器 | ~20 步 |
| 潜在扩散（LDM） | 在隐空间扩散，降低每步计算量 | 大幅加速 |
| 一致性模型 | 蒸馏为单步生成 | 1 步 |

<Glossary>

<GlossaryItem term="扩散模型（Diffusion Model）">
基于迭代去噪的生成模型。前向过程逐步对数据加高斯噪声直到纯噪声（无需学习），反向过程用神经网络逐步去噪恢复数据。训练目标简化为预测噪声的 MSE 损失。扩散模型训练稳定、生成质量最高、多样性好，已取代 GAN 成为主流。主要缺点是采样慢，可通过 DDIM、潜在扩散等加速。代表模型：DDPM、Stable Diffusion、DALL-E 2。
</GlossaryItem>

<GlossaryItem term="DDPM（Denoising Diffusion Probabilistic Models）">
扩散模型的奠基性工作。关键贡献：①将训练目标简化为预测噪声的 MSE 损失 L = E[||eps - eps_theta(x_t, t)||^2]，从变分下界推导而来。②证明扩散模型能生成与 GAN 相当甚至更好的图像。③使用 U-Net 架构作为去噪网络。DDPM 奠定了现代扩散模型的基础，后续的 Stable Diffusion、DALL-E 2 都基于 DDPM 框架。
</GlossaryItem>

<GlossaryItem term="噪声调度（Noise Schedule）">
前向过程中每步添加的噪声量 beta_t 的定义。alpha_t = 1 - beta_t，alpha_bar_t = prod alpha_i。常见调度：线性（beta 从 0.0001 到 0.02）、余弦（alpha_bar 按余弦衰减，更均匀）。噪声调度影响生成质量——后期噪声太大难以恢复细节，前期噪声太小学不到全局结构。噪声调度是扩散模型的重要超参数。
</GlossaryItem>

<GlossaryItem term="DDIM（Denoising Diffusion Implicit Models）">
扩散模型的加速采样方法。修改反向过程为非马尔可夫（不依赖严格的马尔可夫链），允许跳步采样。50 步即可接近 1000 步的生成质量，加速 20 倍。DDIM 是确定性采样（相同噪声生成相同图像），而 DDPM 是随机采样。DDIM 使扩散模型在实际应用中可行，是 Stable Diffusion 等模型的默认采样器之一。
</GlossaryItem>

<GlossaryItem term="潜在扩散模型（Latent Diffusion Model, LDM）">
在压缩的隐空间而非像素空间进行扩散的模型。先用自编码器将图像压缩到低维隐空间（如 64x64x4），在隐空间训练扩散模型，再用解码器恢复图像。优势：计算效率大幅提升（隐空间维度远低于像素空间）、感知质量更高（隐空间过滤了高频噪声）。Stable Diffusion 是 LDM 的开源实现，是文生图领域最重要的模型之一。
</GlossaryItem>

<GlossaryItem term="U-Net">
扩散模型中常用的去噪网络架构。编码器-解码器结构加跳跃连接，输入加噪图像 x_t 和时间步 t，输出预测噪声 eps_theta。U-Net 的跳跃连接保留了高分辨率特征，有利于恢复图像细节。时间步 t 通过位置编码注入网络。U-Net 是 DDPM 及后续扩散模型的标准去噪网络。
</GlossaryItem>

</Glossary>

### 问题 1

扩散模型的基本原理是什么？前向过程和反向过程分别做什么？

<Answer>

扩散模型由前向过程和反向过程组成。前向过程（加噪）：从原始数据 x_0 开始，逐步添加高斯噪声，经过 T 步后得到纯噪声 x_T。每一步 q(x_t|x_&#123;t-1&#125;) = N(sqrt(1-beta_t)*x_&#123;t-1}, beta_t*I)。前向过程是固定的（无需学习），且可以跳步直接计算 x_t = sqrt(alpha_bar_t)*x_0 + sqrt(1-alpha_bar_t)*eps。反向过程（去噪/生成）：从纯噪声 x_T 开始，学习神经网络逐步去噪 p_theta(x_&#123;t-1&#125;|x_t) = N(mu_theta, sigma_theta)，直到恢复出干净图像 x_0。核心思想：将生成问题转化为去噪问题，每步只需做微小修正，降低了学习难度。
</Answer>

### 问题 2

扩散模型的训练目标是什么？为什么预测噪声 epsilon 比直接预测 x_0 更好？

<Answer>

扩散模型的训练目标（DDPM 简化损失）：L = E_&#123;t, x_0, eps&#125;[||eps - eps_theta(x_t, t)||^2]。训练步骤：①采样 x_0。②随机采样 t。③采样噪声 eps。④计算加噪样本 x_t。⑤用网络 eps_theta 预测噪声。⑥最小化预测噪声与真实噪声的 MSE。预测噪声而非直接预测 x_0 的原因：①数学等价性——从 x_t 和 eps 可以解析地求出 x_0，两者等价。②训练稳定性——预测噪声 eps 是预测零均值、单位方差的标准化量，网络输出范围稳定，易于优化。而直接预测 x_0 需要输出与图像像素同范围的值，不同时间步的目标分布差异大，训练不稳定。③理论推导——从变分下界推导出的自然结果。
</Answer>

### 问题 3

扩散模型的噪声调度是什么？它如何影响生成质量？

<Answer>

噪声调度定义了前向过程中每步添加的噪声量 beta_t。常见调度：①线性调度——beta_t 从 0.0001 线性增长到 0.02（DDPM 原始论文）。②余弦调度——alpha_bar_t 按余弦曲线衰减，使噪声增长更均匀，改善高分辨率图像生成。③学习式调度——beta_t 作为可学习参数。噪声调度的影响：①生成质量——如果后期噪声太大，模型难以恢复细节；如果前期噪声太小，模型学不到全局结构。余弦调度在多种数据集上优于线性调度。②采样速度——较大的 beta_t 步长可以用更少的步数完成前向/反向过程，加速采样。③信息保留——alpha_bar_t 度量了在步骤 t 时原始数据保留的比例。
</Answer>

### 问题 4

扩散模型相比 GAN 和 VAE 有什么优势？它的主要缺点是什么？有哪些加速采样的方法？

<Answer>

扩散模型的优势：①训练稳定——优化明确的去噪 MSE 损失，无 GAN 的对抗博弈困境。②生成质量高——多步迭代去噪使每步只需做微小修正，生成质量超越 GAN。③多样性好——从纯噪声采样天然覆盖整个数据分布。④理论优美——基于非平衡热力学的变分推断。主要缺点：采样速度慢——生成一张图像需要 T=1000 步迭代，比 GAN 慢数百倍。加速采样的方法：①DDIM——修改反向过程为非马尔可夫，允许跳步采样，50 步即可接近 1000 步质量。②DPM-Solver——基于扩散 ODE 的高阶求解器，10-20 步即可生成高质量图像。③潜在扩散——在压缩的隐空间而非像素空间扩散，大幅降低每步计算量。④一致性模型——将扩散过程蒸馏为单步生成模型。这些方法使扩散模型的采样速度提升数百倍。
</Answer>
