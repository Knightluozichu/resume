## 这本书讲什么

《深度学习进阶：自然语言处理》（斋藤康毅）是《深度学习入门》的续作。如果说第一部聚焦「用 NumPy 从零实现神经网络」（前向传播、反向传播、CNN），那么本书聚焦「自然语言处理」——处理离散的文本序列而非连续的图像像素。

核心理念：不调用 PyTorch 或 TensorFlow 的高级 API，而是用 Python + NumPy 从零实现 word2vec、CBOW、RNN、LSTM、seq2seq、注意力机制直至 Transformer，让读者理解现代 NLP 和大语言模型的每一个零件是如何工作的。

全书的知识体系可以划分为四个阶段：

- **语言与词嵌入**：NLP 基础与 word2vec——将离散单词变为可计算的稠密向量
- **序列建模**：RNN 与 LSTM——处理变长序列，捕获时序依赖
- **注意力与生成**：注意力与 Transformer——动态聚焦、完全并行
- **全书整合**：从 word2vec 到 Transformer 的知识闭环

## 核心理念：从零实现 NLP

<Callout type="info">

**关键洞察**：本书不是教你怎么「用」NLP 框架，而是教你怎么「造」NLP 模型。当你亲手实现过 word2vec 的 CBOW、LSTM 的门控、Transformer 的多头注意力后，再面对 GPT/BERT 就能做到知其然且知其所以然。这正是从「调包侠」到「理解者」的跃迁。

</Callout>

从零实现的三个原因：

| 原因 | 说明 |
|------|------|
| 理解原理 | 高级框架隐藏了注意力计算、门控更新等细节，亲手实现让一切透明 |
| 掌握抽象 | 学会如何用 NumPy 矩阵运算构建可训练的神经网络组件 |
| 迁移能力 | 理解 word2vec 和 Transformer 内部机制后，使用任何 NLP 模型都能快速定位问题 |

## 三个关键跃迁

<Callout type="tip">

**阅读策略**：建议按顺序阅读 ch1-ch3，建立从文本处理到词嵌入的完整理解。ch4-ch5 是序列建模，需要前3章基础。ch6-ch7 是本书高潮——注意力到 Transformer 的跃迁。ch8 是应用实践，ch9 帮助建立全局视野。

</Callout>

1. **离散 → 连续跃迁**：one-hot 稀疏高维 → 词嵌入稠密低维，单词有了可计算的语义空间
2. **固定 → 动态跃迁**：固定上下文向量 → 注意力动态加权，模型获得选择性关注能力
3. **串行 → 并行跃迁**：RNN 逐步循环 → Transformer 全并行，GPU 友好可大规模扩展

## 六个核心概念预览

| 概念 | 一句话解释 | 详细章节 |
|------|-----------|---------|
| word2vec | 将单词映射为稠密向量的模型 | ch2 |
| CBOW | 用上下文预测中心词的 word2vec 模型 | ch3 |
| RNN | 通过循环隐状态处理序列的神经网络 | ch4 |
| LSTM | 用门控解决梯度消失的 RNN 变体 | ch4 |
| 注意力 | 让解码器动态关注编码器不同位置的机制 | ch6 |
| Transformer | 完全基于注意力的并行序列模型 | ch7 |

<Glossary>

<GlossaryItem term="word2vec">
Google 提出的词嵌入模型，包含 CBOW 和 Skip-gram 两种架构。基于分布式假设（上下文相似的词含义相似），通过预测任务学习将每个单词映射为低维稠密向量。是现代 NLP 的基础技术——理解 word2vec 才能理解 Transformer 的嵌入层。
</GlossaryItem>

<GlossaryItem term="分布式假设">
「一个词的含义由它的上下文决定」——在相似上下文中出现的词具有相似含义。这是现代 NLP 的基石：word2vec 基于此学习词向量，RNN 基于此建模序列上下文，Transformer 基于此计算注意力。没有分布式假设，就无法从文本中自动学习语义。
</GlossaryItem>

<GlossaryItem term="注意力机制">
让解码器在生成每个词时，动态计算对编码器各隐状态的关注权重，加权求和得到当前步专属的上下文向量。打破了 seq2seq 的固定瓶颈，是 Transformer 自注意力的原型。核心是「查询-键-值」检索框架。
</GlossaryItem>

<GlossaryItem term="Transformer">
2017 年 Google 提出的序列模型，完全去掉 RNN 的循环结构，仅用自注意力实现序列建模。所有位置可并行计算，GPU 友好，是 GPT/BERT 等大语言模型的基础架构。核心组件：多头注意力、前馈网络、位置编码、残差连接。
</GlossaryItem>

<GlossaryItem term="自回归生成">
文本生成的基本方式——每一步生成都以之前生成的所有词作为上下文，逐步预测下一个词。GPT 等生成式语言模型的核心工作方式。训练时用 Teacher Forcing（输入正确答案），推理时用自回归（输入上一步预测）。
</GlossaryItem>

<GlossaryItem term="负采样">
word2vec 中加速训练的技术。将「从 V 个词中分类」的多分类问题，转化为「判断这个词是不是正确的」二分类问题。正样本1个 + 随机负采样 k 个，大幅降低计算量。采样概率用 freq(w)^(3/4) 平衡高低频词。
</GlossaryItem>

</Glossary>

### 问题 1

《深度学习进阶：自然语言处理》（斋藤康毅）一书的核心理念是什么？

<Answer>

本书核心理念是「用 NumPy 从零实现自然语言处理的核心模型」——不调用高级框架的黑箱 API，而是从词嵌入（word2vec）开始，逐步用 Python + NumPy 实现 CBOW、RNN、LSTM、seq2seq、注意力机制直至 Transformer，让读者理解现代 NLP 和大语言模型的每一个零件是如何工作的。与《深度学习入门》第一部的区别：第一部聚焦「用 NumPy 从零实现神经网络」（前向传播、反向传播、CNN），本书聚焦「自然语言处理」——处理离散的文本序列而非连续的图像像素，核心挑战从「空间模式识别」升级为「序列建模与语言理解」。
</Answer>

### 问题 2

全书的十章如何组织？分为哪几个阶段？

<Answer>

全书十章分为四个阶段：①语言与词嵌入（ch0-ch3）——学习地图定位方向，NLP基础与预处理建立文本处理流水线，词嵌入与word2vec引入分布式表示，CBOW实现将理论落地为代码。②序列建模（ch4-ch5）——RNN与LSTM处理变长序列并解决梯度消失，seq2seq实现编码器-解码器翻译架构。③注意力与生成（ch6-ch8）——注意力机制打破固定上下文瓶颈，Transformer实现完全并行的注意力架构，文本生成实践将语言模型应用于生成任务。④全书整合（ch9）——从word2vec到Transformer的知识闭环。这种从「词」到「序列」到「注意力」到「生成」的递进是本书的组织主线。
</Answer>

### 问题 3

为什么本书从 word2vec 开始而不是直接学 Transformer？

<Answer>

本书从 word2vec 开始的三个原因：①理解表示——NLP 的根本问题是「如何把离散的单词变成计算机可计算的向量」。word2vec 是第一个成功的分布式表示方法，理解它才能理解为什么 Transformer 需要嵌入层。②理解训练——word2vec 的 CBOW 是一个完整的神经网络（输入层→隐藏层→输出层+Softmax），用最简单的结构展示了「定义模型→前向传播→计算损失→反向传播→更新参数」的完整训练流程，是后续所有模型的微缩标本。③理解注意力——word2vec 的权重矩阵 W_in 本质上就是一个「查询-键-值」检索：输入 one-hot 查询 W_in 得到嵌入向量，这与注意力机制 softmax(QK^T)V 的检索逻辑一脉相承。跳过 word2vec 直接学 Transformer 会缺乏这些直觉基础。
</Answer>

### 问题 4

全书十章内容如何形成一个从 word2vec 到 Transformer 的知识闭环？

<Answer>

全书形成一个「表示→序列→注意力→并行→闭环」的知识演进：①表示层（ch1-ch3）——NLP预处理把文本变成ID，word2vec把ID变成稠密向量（分布式假设让词有了可计算的语义空间），CBOW给出可训练的代码实现。②序列层（ch4-ch5）——RNN/LSTM处理变长序列（解决了词嵌入无法建模词序的问题），seq2seq实现跨语言映射。③注意力层（ch6-ch7）——注意力打破seq2seq的固定上下文瓶颈（每步动态聚焦），Transformer把注意力推向极致（去掉RNN实现完全并行）。④应用层（ch8）——文本生成将语言模型落地。⑤闭环（ch9）——从word2vec的「查表式表示」到Transformer的「注意力式表示」，底层统一为可微矩阵运算+梯度下降。三个关键跃迁贯穿始终：离散→连续（词嵌入）、固定→动态（注意力）、串行→并行（Transformer）。
</Answer>
