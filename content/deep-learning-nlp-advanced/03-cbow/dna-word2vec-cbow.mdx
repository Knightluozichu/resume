## CBOW 网络结构

CBOW 是一个三层神经网络：输入层 → 中间层 → 输出层。

<DnaWord2vecCbowDiagram />

### 三层结构

```text
输入层:  上下文词的 one-hot (V维，V=词表大小)
   ↓ W_in (V×H)
中间层:  h = mean(W_in[context])  (H维，如100)
   ↓ W_out (H×V)
输出层:  scores = W_out · h  (V维)
   ↓ Softmax
概率:   P(word | context)
```

### NumPy 实现：前向传播

```python
import numpy as np

class CBOW:
    def __init__(self, vocab_size, hidden_size):
        V, H = vocab_size, hidden_size
        # 初始化权重（小型随机值）
        self.W_in = 0.01 * np.random.randn(V, H)
        self.W_out = 0.01 * np.random.randn(H, V)

    def forward(self, contexts):
        # contexts: 上下文词的ID列表 [c1, c2, ...]
        # 中间层：查表 + 平均
        h = np.mean(self.W_in[contexts], axis=0)  # (H,)
        # 输出层分数
        scores = np.dot(self.W_out.T, h)  # (V,)
        # Softmax
        scores = scores - np.max(scores)  # 数值稳定
        probs = np.exp(scores) / np.sum(np.exp(scores))
        return h, probs
```

## Softmax 计算瓶颈

原始 Softmax 的分母需要遍历整个词表：

```text
P(w_i | context) = exp(score_i) / Σ_j exp(score_j)
```

当 V = 10000+ 时，每次预测都要计算所有词的分数，计算量极大。

<Callout type="warning">

**核心瓶颈**：Softmax 分母需要对 V 个词求 exp 和。V 通常上万甚至百万，是 word2vec 训练的主要计算开销。

</Callout>

## 负采样优化

负采样（Negative Sampling）的核心思想：**将多分类转为二分类**。

不预测「哪个词是正确的」，而是判断「这个词是不是正确的」：
- 正样本1个（正确目标词）
- 随机负采样 k 个（通常5-15个）

### 负采样损失函数

```text
L = -log σ(h · w_out[t]) - Σ log σ(-h · w_out[n_i])
```

其中 σ 是 sigmoid 函数，t 是正确目标词，n_i 是负样本。

```python
def sigmoid(x):
    return 1 / (1 + np.exp(-x))

def negative_sampling_loss(h, target, neg_samples, W_out):
    # 正样本：让 h·w_out[t] 尽量大
    pos_score = np.dot(h, W_out[:, target])
    pos_loss = -np.log(sigmoid(pos_score) + 1e-10)
    
    # 负样本：让 h·w_out[n] 尽量小
    neg_scores = np.dot(h, W_out[:, neg_samples])
    neg_loss = -np.sum(np.log(sigmoid(-neg_scores) + 1e-10))
    
    return pos_loss + neg_loss
```

### 采样概率设计

负采样概率用 `freq(w)^(3/4)` 而非直接词频：

```python
# 计算采样概率
word_freqs = np.array([count_freq(w) for w in range(V)])
sampling_probs = word_freqs ** 0.75
sampling_probs = sampling_probs / np.sum(sampling_probs)

# 采样
neg_samples = np.random.choice(V, size=k, p=sampling_probs)
```

<Callout type="info">

**为什么用 3/4 次方**：高频词（the, of）词频极高，直接按词频采样几乎只采到它们。3/4 次方压缩高频词频率、提升低频词频率，使所有词都有合理的被采样概率。

</Callout>

## 分层 Softmax

另一种优化方法：用霍夫曼树组织词表，沿树路径做 log(V) 次二分类。

| 方法 | 复杂度 | 优点 | 缺点 |
|------|--------|------|------|
| 原始 Softmax | O(V) | 精确 | 计算量大 |
| 负采样 | O(k) | 简单高效 | 近似 |
| 分层 Softmax | O(log V) | 精确 | 实现复杂 |

## 完整训练流程

```python
# CBOW + 负采样的训练循环
model = CBOW(vocab_size=V, hidden_size=100)
lr = 0.1  # 学习率

for epoch in range(epochs):
    for contexts, target in data_loader:
        # 1. 前向传播
        h = np.mean(model.W_in[contexts], axis=0)
        
        # 2. 负采样
        neg_samples = np.random.choice(V, size=k, p=sampling_probs)
        
        # 3. 计算损失
        pos_score = np.dot(h, model.W_out[:, target])
        neg_scores = np.dot(h, model.W_out[:, neg_samples])
        
        # 4. 反向传播
        d_pos = sigmoid(pos_score) - 1  # 正样本梯度
        d_neg = sigmoid(neg_scores)     # 负样本梯度
        
        # 5. 更新 W_out
        model.W_out[:, target] -= lr * d_pos * h
        model.W_out[:, neg_samples] -= lr * d_neg * h
        
        # 6. 更新 W_in（梯度传回上下文词）
        dh = d_pos * model.W_out[:, target] + np.sum(d_neg[:, None] * model.W_out[:, neg_samples], axis=0)
        for ctx in contexts:
            model.W_in[ctx] -= lr * dh / len(contexts)
```

<Glossary>

<GlossaryItem term="负采样（Negative Sampling）">
word2vec 中加速训练的技术。将「从 V 个词中分类」的多分类问题转化为「判断这个词是不是正确的」二分类问题。正样本1个 + 随机负采样 k 个，计算复杂度从 O(V) 降为 O(k)。采样概率用 freq(w)^(3/4) 平衡高低频词。
</GlossaryItem>

<GlossaryItem term="分层 Softmax（Hierarchical Softmax）">
用霍夫曼树组织词表的 Softmax 优化方法。每个词对应树上一条路径，预测变为沿路径做 log(V) 次二分类。复杂度从 O(V) 降为 O(log V)。高频词路径短（叶子靠近根），低频词路径长。
</GlossaryItem>

<GlossaryItem term="freq(w)^(3/4) 采样">
负采样中平衡高低频词的采样概率设计。直接用词频会导致高频词被过度采样、低频词几乎不被采到。3/4 次方压缩高频词频率、提升低频词频率，使所有词都有合理被采样概率。3/4 是 word2vec 原论文的经验调优值。
</GlossaryItem>

<GlossaryItem term="sigmoid 函数">
σ(x) = 1 / (1 + exp(-x))，将任意实数压缩到 (0,1) 区间。在负采样中用于二分类概率：σ(h·w) 表示「这个词是正样本」的概率。正样本让 σ(h·w_t) 趋近1，负样本让 σ(h·w_n) 趋近0。
</GlossaryItem>

<GlossaryItem term="W_in / W_out">
word2vec 的两个权重矩阵。W_in（V×H）是输入层到中间层的权重，每行是一个词的嵌入向量（训练完成后即词嵌入）。W_out（H×V）是中间层到输出层的权重，每列是一个词的输出向量。负采样中只用正样本和负样本对应的列，无需计算全部 V 列。
</GlossaryItem>

</Glossary>

### 问题 1

CBOW 模型的三层网络结构是什么？前向传播的过程是怎样的？

<Answer>

CBOW 三层网络结构：①输入层——上下文窗口内每个词的 one-hot 向量（V维，V=词表大小）。②中间层（隐藏层）——将输入层 one-hot 与权重矩阵 W_in（V×H）相乘得到 H 维向量，多个上下文词的向量取平均（这就是「词袋」的含义——不考虑上下文词的顺序），得到中间层向量 h（H维）。③输出层——将 h 与权重矩阵 W_out（H×V）相乘得到 V 维分数，再经过 Softmax 归一化为概率分布，表示每个词作为中心词的概率。前向传播过程：context one-hot → W_in 查表得嵌入向量 → 取平均得 h → W_out 乘 h 得分数 → Softmax 得概率。训练目标：让正确中心词的概率最大（交叉熵损失）。
</Answer>

### 问题 2

原始 Softmax 在 word2vec 中有什么计算瓶颈？负采样和分层 Softmax 如何解决？

<Answer>

原始 Softmax 瓶颈：Softmax 分母需要计算所有 V 个词的分数并求和（exp(score_i)），V 通常为上万甚至百万级，每次预测都要遍历整个词表，计算量极大。负采样（Negative Sampling）解决方案：不预测「哪个词是正确的」，而是做二分类——「这个词是不是正确的」。正样本1个（正确目标词）+ 随机采样的负样本 k 个（通常5-15个），将 V 分类问题转化为 k+1 个二分类问题。损失函数：L = -log σ(h·w_t) - Σ log σ(-h·w_{n_i})。分层 Softmax（Hierarchical Softmax）解决方案：用霍夫曼树组织词表，每个词对应树上一条路径，预测变为沿路径做 log(V) 次二分类（左走或右走），复杂度从 O(V) 降为 O(log V)。实践中负采样更常用，实现简单且效果好。
</Answer>

### 问题 3

负采样的采样概率为什么用 freq(w)^(3/4) 而不是直接用词频？

<Answer>

负采样用 freq(w)^(3/4) 而非直接词频的原因：平衡高频词和低频词的采样概率。直接用词频的问题：高频词（如 the, of, is）在语料中出现频率极高，按词频采样会几乎只采到这些高频词作为负样本，低频词几乎不会被采为负样本，导致低频词的嵌入向量得不到充分训练。freq(w)^(3/4) 的效果：指数 3/4 小于1，对高频词的频率做「压缩」（如频率0.1的词，0.1^0.75≈0.178，相对占比降低），对低频词的频率做「提升」（如频率0.001的词，0.001^0.75≈0.0056，相对占比提升）。这样高频词仍更容易被采到（符合它们在语料中更常见的现实），但低频词也有合理的被采样概率，使得所有词的嵌入都能得到充分训练。这个 3/4 次方的经验值来自 word2vec 原论文的实验调优。
</Answer>

### 问题 4

用 Python/NumPy 简述 CBOW + 负采样的训练流程，包括前向传播、损失计算和反向传播。

<Answer>

CBOW + 负采样训练流程（简化伪代码）：# 前向传播：context_idxs = [word_to_id[w] for w in context_words]  # 上下文词ID；h = np.mean(W_in[context_idxs], axis=0)  # 查表+平均得中间向量(H维)；# 负采样：neg_idxs = np.random.choice(V, size=k, p=neg_sampling_dist)  # 按freq^0.75采样k个负样本；# 正样本分数：pos_score = np.dot(h, W_out[target_idx])  # h·w_out[t]；pos_prob = sigmoid(pos_score)；# 负样本分数：neg_scores = np.dot(h, W_out[neg_idxs])  # h·w_out[neg]；neg_probs = sigmoid(-neg_scores)；# 损失：loss = -np.log(pos_prob) - np.sum(np.log(neg_probs))；# 反向传播：d_pos = pos_prob - 1  # 正样本梯度；d_neg = sigmoid(neg_scores)  # 负样本梯度(=1-sigmoid(-x))；# 更新W_out：W_out[target_idx] -= lr * d_pos * h；W_out[neg_idxs] -= lr * d_neg[:, None] * h；# 更新W_in（梯度传回上下文词）：dh = d_pos * W_out[target_idx] + np.sum(d_neg[:, None] * W_out[neg_idxs], axis=0)；W_in[context_idxs] -= lr * dh / len(context_idxs)  # 平均分摊。核心：正样本让 h·w_t 增大，负样本让 h·w_n 减小。
</Answer>
