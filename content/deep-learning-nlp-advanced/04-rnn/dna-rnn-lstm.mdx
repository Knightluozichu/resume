## RNN：处理序列的神经网络

词嵌入解决了「如何表示单个词」的问题，但语言是**有序列**的——\"dog bites man\" 和 \"man bites dog\" 含义完全不同。RNN（循环神经网络）专门处理序列数据。

<DnaRnnLstmDiagram />

### RNN 基本结构

在每个时间步 t，RNN 接收当前输入 $x_t$ 和上一时间步的隐状态 $h_{t-1}$，计算当前隐状态：

```text
h_t = tanh(W_x · x_t + W_h · h_{t-1} + b)
```

- $W_x$：输入到隐状态的权重矩阵
- $W_h$：隐状态到隐状态的权重矩阵（循环权重）
- $h_t$：截至当前时间步所有历史信息的压缩表示

### 参数共享

RNN 的关键特性：**所有时间步共享同一组权重** $W_x$ 和 $W_h$。无论输入序列多长，模型参数量不变。这使得 RNN 可以处理任意长度的序列。

### 时间展开

RNN 在时间维度上展开后，等价于一个深度网络——每一层对应一个时间步，不同层共享同一组权重。反向传播沿时间维度进行，称为 **BPTT**（Backpropagation Through Time）。

## 梯度消失与梯度爆炸

<Callout type="warning">

**RNN 的致命弱点**：在长序列上反向传播时，梯度沿时间反复乘以 $W_h$，导致梯度消失（趋近0）或爆炸（趋向无穷），使 RNN 无法学习长距离依赖。

</Callout>

### 数学原因

反向传播时，梯度链式法则要求连乘各时间步的雅可比矩阵：

```text
∂L/∂h_0 = ∏ (∂h_t/∂h_{t-1}) · ∂L/∂h_T
```

每个 $\partial h_t / \partial h_{t-1}$ 包含 $W_h$ 和 $tanh'$：

- 当 $|W_h| < 1$ 时，连乘 → 0（**梯度消失**）
- 当 $|W_h| > 1$ 时，连乘 → ∞（**梯度爆炸**）

tanh 的导数最大值为1（输入为0时），大部分情况小于1，进一步加剧消失。

### 后果

RNN 只能记住近期信息（约10-20步），远距离依赖丢失。例如 \"The cat, which was sitting on the mat, **sat**\" 中，\"sat\" 依赖远处的 \"cat\"，普通 RNN 无法建立这种联系。

## LSTM：门控解决梯度消失

LSTM（Long Short-Term Memory）通过**门控机制**和**细胞状态**解决梯度消失问题。

### 三个门和一个细胞状态

| 组件 | 公式 | 作用 |
|------|------|------|
| 遗忘门 $f_t$ | $\sigma(W_f \cdot [h_{t-1}, x_t])$ | 决定丢弃多少旧信息 |
| 输入门 $i_t$ | $\sigma(W_i \cdot [h_{t-1}, x_t])$ | 决定写入多少新信息 |
| 候选值 $g_t$ | $\tanh(W_g \cdot [h_{t-1}, x_t])$ | 生成候选新信息 |
| 输出门 $o_t$ | $\sigma(W_o \cdot [h_{t-1}, x_t])$ | 决定输出多少信息 |

### 细胞状态更新

```text
C_t = f_t * C_{t-1} + i_t * g_t    （加法更新，非替换）
h_t = o_t * tanh(C_t)
```

### 梯度高速公路

<Callout type="info">

**关键洞察**：LSTM 的细胞状态 $C$ 是**加法更新**（$C_t = f_t \cdot C_{t-1} + ...$），而非 RNN 的替换式更新。梯度可以从 $C_t$ 通过 $f_t$ 直接流回 $C_{t-1}$——只要遗忘门 $f_t$ 接近1，梯度就能无衰减地传播很长距离。这被称为「梯度高速公路」。

</Callout>

## LSTM vs RNN 对比

| 特性 | RNN | LSTM |
|------|-----|------|
| 状态 | 单一隐状态 $h_t$ | 细胞状态 $C_t$ + 隐状态 $h_t$ |
| 更新方式 | 替换（全覆盖） | 加法（选择性累加） |
| 门控 | 无 | 三门精确控制 |
| 梯度路径 | 必经 $W_h$ 和 $tanh$ | 细胞状态直接流动 |
| 长距离依赖 | 差（约10-20步） | 好（数百步） |
| 参数量 | 少 | 多（约4倍） |

## NumPy 实现：LSTM 单元

```python
class LSTM:
    def __init__(self, input_size, hidden_size):
        H = hidden_size
        # 合并四个门的权重（效率更高）
        self.W = np.random.randn(input_size + H, 4 * H) * 0.01
        self.b = np.zeros(4 * H)
    
    def forward(self, x, h_prev, C_prev):
        # 拼接输入和隐状态
        combined = np.concatenate([h_prev, x], axis=-1)
        
        # 一次计算四个门
        gates = np.dot(combined, self.W) + self.b
        f = sigmoid(gates[:, :H])          # 遗忘门
        i = sigmoid(gates[:, H:2*H])       # 输入门
        g = np.tanh(gates[:, 2*H:3*H])     # 候选值
        o = sigmoid(gates[:, 3*H:])        # 输出门
        
        # 细胞状态更新（加法！）
        C_next = f * C_prev + i * g
        # 隐状态
        h_next = o * np.tanh(C_next)
        
        return h_next, C_next
```

## 梯度爆炸的处理

LSTM 解决了梯度消失，但梯度爆炸仍可能发生。常用**梯度裁剪**（Gradient Clipping）：

```python
def clip_grads(grads, max_norm):
    total_norm = 0
    for grad in grads:
        total_norm += np.sum(grad ** 2)
    total_norm = np.sqrt(total_norm)
    
    if total_norm > max_norm:
        rate = max_norm / (total_norm + 1e-6)
        for grad in grads:
            grad *= rate
```

当梯度总范数超过阈值时，按比例缩小，防止爆炸。

<Glossary>

<GlossaryItem term="RNN（循环神经网络）">
通过循环隐状态处理序列数据的神经网络。每个时间步接收当前输入和上一隐状态，计算新隐状态。所有时间步共享权重，可处理变长序列。致命弱点是梯度消失——无法学习长距离依赖，被 LSTM 取代。
</GlossaryItem>

<GlossaryItem term="BPTT（时间反向传播）">
Backpropagation Through Time，RNN 的反向传播算法。将 RNN 在时间维度展开为深度网络，沿时间维度反向传播梯度。梯度需连乘各时间步的雅可比矩阵，导致梯度消失或爆炸。
</GlossaryItem>

<GlossaryItem term="梯度消失/爆炸">
RNN 在长序列上反向传播时，梯度沿时间反复乘以 W_h。当 W_h 特征值小于1时梯度指数衰减（消失），大于1时指数增长（爆炸）。tanh 导数最大为1进一步加剧消失。梯度爆炸可用梯度裁剪解决，梯度消失需要 LSTM 门控。
</GlossaryItem>

<GlossaryItem term="LSTM（长短期记忆网络）">
通过门控机制解决 RNN 梯度消失的网络。包含遗忘门、输入门、输出门三个门和细胞状态。细胞状态用加法更新（C_t = f_t·C_&#123;t-1&#125; + i_t·g_t），梯度可通过 f_t 直接流动（梯度高速公路），实现长距离依赖建模。
</GlossaryItem>

<GlossaryItem term="梯度高速公路">
LSTM 细胞状态的加法更新机制。RNN 的 h_t 是替换式更新（完全被新输入覆盖），梯度必须经过 W_h 和 tanh 反复相乘。LSTM 的 C_t 是加法更新（f_t·C_&#123;t-1&#125; + ...），梯度可通过 f_t 直接从 C_t 流回 C_&#123;t-1&#125;，只要 f_t 接近1就能无衰减传播。
</GlossaryItem>

<GlossaryItem term="梯度裁剪（Gradient Clipping）">
防止梯度爆炸的技术。计算所有梯度参数的总范数，当超过阈值时按比例缩小。LSTM 解决了梯度消失但梯度爆炸仍可能发生，实践中通常配合梯度裁剪使用。
</GlossaryItem>

</Glossary>

### 问题 1

RNN 的基本结构是什么？它如何处理变长序列？

<Answer>

RNN（循环神经网络）基本结构：在每个时间步 t，RNN 接收当前输入 x_t 和上一时间步的隐状态 h_&#123;t-1&#125;，计算当前隐状态 h_t = tanh(W_x · x_t + W_h · h_&#123;t-1&#125; + b)。隐状态 h_t 是对「截至当前时间步所有历史信息」的压缩表示。RNN 处理变长序列的方式：权重矩阵 W_x 和 W_h 在所有时间步共享（参数共享），无论输入序列多长，模型参数量不变。处理时将序列逐个时间步输入，每步更新隐状态。输出可以是每步的 h_t（用于序列标注）或最后一步的 h_N（用于序列分类）。时间展开：RNN 在时间维度上展开后等价于一个深度网络，不同层共享同一组权重，反向传播沿时间维度进行（BPTT，Backpropagation Through Time）。
</Answer>

### 问题 2

RNN 的梯度消失/爆炸问题是什么？为什么会发生？

<Answer>

RNN 梯度消失/爆炸问题：在长序列上反向传播时，梯度会沿时间维度反复乘以权重矩阵 W_h，导致梯度要么趋近于0（消失），要么趋向无穷（爆炸），使 RNN 无法学习长距离依赖。发生原因：反向传播时，梯度链式法则要求将各时间步的雅可比矩阵连乘：梯度 = ∏ (∂h_t/∂h_&#123;t-1&#125;)。而 ∂h_t/∂h_&#123;t-1&#125; 包含 W_h 和 tanh 的导数。当 W_h 的特征值小于1时，连乘导致梯度指数衰减→消失；当 W_h 的特征值大于1时，连乘导致梯度指数增长→爆炸。tanh 的导数最大值为1（在输入为0时），大部分情况下小于1，进一步加剧梯度消失。结果：RNN 只能记住近期信息（约10-20步），远距离的依赖关系丢失。梯度爆炸可通过梯度裁剪（gradient clipping）缓解，但梯度消失更难处理，需要 LSTM 等门控结构。
</Answer>

### 问题 3

LSTM 的三个门和细胞状态各自的作用是什么？它如何解决梯度消失？

<Answer>

LSTM 的三个门和细胞状态：①遗忘门 f_t = σ(W_f·[h_&#123;t-1}, x_t])——决定从细胞状态 C_&#123;t-1&#125; 中丢弃多少信息（0全忘，1全留）。②输入门 i_t = σ(W_i·[h_&#123;t-1}, x_t])——决定将多少新信息写入细胞状态。③输出门 o_t = σ(W_o·[h_&#123;t-1}, x_t])——决定从更新后的细胞状态中输出多少到隐状态。候选值 g_t = tanh(W_g·[h_&#123;t-1}, x_t])——生成候选新信息。细胞状态更新：C_t = f_t * C_&#123;t-1&#125; + i_t * g_t，隐状态 h_t = o_t * tanh(C_t)。解决梯度消失的原理：细胞状态 C 的更新是加法操作（C_t = f_t * C_&#123;t-1&#125; + ...）而非乘法替换，梯度可以从 C_t 直接流回 C_&#123;t-1&#125;（通过 f_t），只要遗忘门 f_t 接近1，梯度就能无衰减地传播很长距离。这被称为「梯度高速公路」——细胞状态提供了一条梯度可以直接流动的路径，绕过了反复乘以 W_h 的问题。
</Answer>

### 问题 4

LSTM 与普通 RNN 在结构上的核心区别是什么？为什么 LSTM 在实际中几乎总是优于普通 RNN？

<Answer>

核心区别：①状态分裂——RNN 只有一个隐状态 h_t，既是记忆又是输出；LSTM 分裂为细胞状态 C_t（长期记忆）和隐状态 h_t（短期输出），职责分离。②更新方式——RNN 的 h_t 完全被新输入覆盖（h_t = tanh(...)，是「替换」式更新）；LSTM 的 C_t 是加法更新（C_t = f_t*C_&#123;t-1&#125; + i_t*g_t，是「累加」式更新），旧信息不会被完全覆盖。③门控机制——RNN 无门控，信息流不受控制；LSTM 有三个门精确控制信息的遗忘、写入和输出。④梯度路径——RNN 梯度必须经过 W_h 和 tanh 反复相乘；LSTM 梯度可通过细胞状态的加法路径直接流动。LSTM 几乎总是优于 RNN 的原因：梯度高速公路解决了长距离依赖问题，门控机制让模型学会「什么时候记住、什么时候忘记」，在机器翻译、文本生成等需要长程上下文的任务上表现远超 RNN。RNN 仅在极短序列或计算资源极度受限时才有优势。
</Answer>
