## 知识全景：从 word2vec 到 Transformer

<DnaFinalReviewDiagram />

本书十章构成了一个完整的知识闭环：从「如何表示单词」到「如何理解序列」到「如何生成文本」，底层统一为可微矩阵运算 + 梯度下降。

## 四个演进阶段

### 阶段一：词嵌入（ch1-ch3）

**解决的核心问题**：如何把离散单词变成计算机可计算的向量。

- ch1 NLP基础：文本预处理流水线（分词→词表→ID），同现矩阵的局限
- ch2 词嵌入：分布式假设，CBOW 与 Skip-gram 原理
- ch3 word2vec实现：CBOW 三层网络，负采样加速训练

**关键突破**：从 one-hot 稀疏高维到词嵌入稠密低维，单词有了可计算的语义空间。

### 阶段二：序列建模（ch4-ch5）

**解决的核心问题**：如何处理词的顺序和上下文。

- ch4 RNN与LSTM：循环结构处理变长序列，门控解决梯度消失
- ch5 seq2seq：编码器-解码器实现跨语言映射

**关键突破**：从独立词向量到序列化隐状态，模型能理解词序和上下文。

### 阶段三：注意力与生成（ch6-ch8）

**解决的核心问题**：如何选择性关注、如何并行计算、如何生成文本。

- ch6 注意力：动态上下文向量，QKV 检索框架
- ch7 Transformer：完全并行，多头注意力，位置编码
- ch8 文本生成：自回归生成，采样策略，评价方法

**关键突破**：从固定上下文到动态加权，从串行循环到全并行注意力。

### 阶段四：全书整合（ch9）

**核心任务**：建立知识闭环，理解现代 NLP 的技术基因。

## 三个关键跃迁

<Callout type="info">

**贯穿全书的三条主线**：每个跃迁都代表了 NLP 能力的一次根本性升级。

</Callout>

### 跃迁一：离散 → 连续（词嵌入）

| | 之前 | 之后 |
|---|------|------|
| 表示 | one-hot 稀疏高维 | 词嵌入稠密低维 |
| 语义 | 所有词距离相同 | 相似词距离近 |
| 变化 | 符号操作 | 连续数学 |

### 跃迁二：固定 → 动态（注意力）

| | 之前 | 之后 |
|---|------|------|
| 上下文 | 固定向量 | 动态加权 |
| 选择性 | 无 | 有 |
| 变化 | 被动接收 | 主动检索 |

### 跃迁三：串行 → 并行（Transformer）

| | 之前 | 之后 |
|---|------|------|
| 计算 | RNN 逐步循环 | 自注意力全并行 |
| GPU | 利用率低 | 高度友好 |
| 变化 | 不可大规模扩展 | 可训练千亿参数 |

## 底层统一：共同的「基因」

所有模型共享同一套底层机制：

| 模型 | 核心运算 | 训练方式 |
|------|---------|---------|
| word2vec | `one-hot × W_in`（矩阵乘法查表） | 交叉熵 + 反向传播 |
| RNN/LSTM | `h_t = tanh(W·x + U·h)` | 交叉熵 + BPTT |
| 注意力 | `softmax(QK^T)V` | 交叉熵 + 反向传播 |
| Transformer | 多头注意力 + FFN | 交叉熵 + 反向传播 |

<Callout type="tip">

**共同基因**：①一切都是可微矩阵运算——所有模型本质都是矩阵乘法+非线性激活的组合。②训练统一为梯度下降——交叉熵损失+反向传播+参数更新。③表示统一为向量——从输入到输出，信息以向量形式流动。④都是「预测下一个词」的变体。

</Callout>

## 知识闭环：从零件到系统

```text
词嵌入（W_in * one-hot）
    ↓ 提供输入表示
RNN/LSTM（h_t = f(W*h + U*x)）
    ↓ 处理序列
注意力（softmax(QK^T)V）
    ↓ 动态聚焦
Transformer（多头注意力 + FFN）
    ↓ 并行建模
文本生成（自回归采样）
    ↓ 应用落地
```

训练流程一以贯之：**定义模型 → 前向传播 → 计算损失 → 反向传播 → 更新参数**。

## 与现代大语言模型的联系

| 本书概念 | LLM 中的对应 |
|---------|-------------|
| word2vec 嵌入层 | GPT/BERT 的 token embedding |
| Transformer 编码器 | BERT 的架构 |
| Transformer 解码器 | GPT 的架构 |
| 自注意力 | GPT/BERT 每一层的核心 |
| 自回归生成 | GPT 的生成方式 |
| 负采样 | 对比学习的原型 |
| 位置编码 | GPT/BERT 的位置嵌入 |

<Callout type="warning">

**本书知识在 LLM 时代仍然重要**：①理解原理才能有效使用——知道注意力如何工作才能理解 prompt 工程。②理解原理才能调试优化——知道训练流程才能理解 fine-tuning、LoRA。③LLM 不会淘汰基础理解——正如高级语言不淘汰数据结构。本书教的是 NLP 的技术基因，LLM 是这些基因的规模化表达。

</Callout>

<GlossaryItem term="知识闭环">
全书从 word2vec 的「查表式表示」到 Transformer 的「注意力式表示」，底层统一为可微矩阵运算+梯度下降。理解这个闭环 = 理解现代 NLP/LLM 的技术基因。三个跃迁贯穿始终：离散→连续、固定→动态、串行→并行。
</GlossaryItem>

<GlossaryItem term="三个关键跃迁">
①离散→连续（词嵌入）：one-hot 到稠密向量，单词有语义空间。②固定→动态（注意力）：固定上下文到动态加权，模型有选择性关注。③串行→并行（Transformer）：RNN 循环到自注意力并行，可大规模扩展。三个跃迁将 NLP 从小模型推进到大模型时代。
</GlossaryItem>

<GlossaryItem term="技术基因">
所有 NLP 模型共享的底层机制：可微矩阵运算、梯度下降训练、向量表示、预测下一个词。这些基因从 word2vec 到 GPT 一脉相承，理解基因就能理解任何新模型——区别只在于规模和组合方式。
</GlossaryItem>

<GlossaryItem term="GPT（Generative Pre-trained Transformer）">
基于 Transformer 解码器的生成式语言模型。核心是本书 ch7 的 Transformer 解码器（掩码自注意力+FFN）加上 ch8 的自回归生成，通过海量预训练学会生成连贯文本。GPT 系列证明了「大模型 + 大数据 + 自回归预训练」的威力。
</GlossaryItem>

<GlossaryItem term="BERT（Bidirectional Encoder Representations from Transformers）">
基于 Transformer 编码器的双向语言模型。用本书 ch7 的编码器部分（自注意力无掩码），预训练任务为掩码语言模型（完形填空）。BERT 证明了双向注意力在理解类任务上的优势。
</GlossaryItem>

### 问题 1

全书从 word2vec 到 Transformer 经历了哪四个演进阶段？每个阶段解决了什么核心问题？

<Answer>

四个演进阶段：①阶段一：词嵌入（word2vec/CBOW）——解决「如何表示单词」的问题。基于分布式假设，将离散单词映射为稠密向量，使单词有了可计算的语义空间。核心突破：从 one-hot 稀疏高维到嵌入稠密低维。②阶段二：序列建模（RNN/LSTM）——解决「如何处理词的顺序」的问题。通过循环结构和门控机制处理变长序列，捕获时序依赖。核心突破：从独立词向量到序列化隐状态。③阶段三：注意力（seq2seq+Attention）——解决「如何选择性关注」的问题。动态计算上下文向量，打破固定瓶颈。核心突破：从固定上下文到动态加权。④阶段四：Transformer——解决「如何高效并行建模」的问题。完全去掉 RNN，纯用自注意力实现并行计算。核心突破：从串行循环到全并行注意力。四个阶段分别对应 NLP 的四个根本问题：表示、序列、关注、效率。
</Answer>

### 问题 2

全书贯穿的三个关键跃迁是什么？每个跃迁的「之前」和「之后」有什么本质变化？

<Answer>

三个关键跃迁：①离散 → 连续（词嵌入）——之前：one-hot 编码，每个词是 V 维稀疏向量，所有词距离相同无语义。之后：词嵌入，每个词是低维稠密向量，相似词距离近。本质变化：单词有了可计算的语义空间，NLP 从符号操作变为连续数学。②固定 → 动态（注意力）——之前：seq2seq 用固定上下文向量，整个源序列压缩为一个向量，解码器每步看同一个向量。之后：注意力动态计算上下文，解码器每步聚焦不同源词。本质变化：模型获得了「选择性关注」能力，从被动接收固定信息到主动检索相关信息。③串行 → 并行（Transformer）——之前：RNN 逐步循环，h_t 依赖 h_{t-1}，无法并行。之后：自注意力全并行，所有位置同时计算关系。本质变化：GPU 友好的矩阵运算取代串行循环，使模型可大规模扩展（这是 GPT/BERT 等大模型的技术前提）。三个跃迁共同将 NLP 从「小模型手工特征」推进到「大模型自动学习」。
</Answer>

### 问题 3

从底层实现的角度，word2vec、RNN、注意力、Transformer 有什么共同的「基因」？

<Answer>

共同基因：①一切都是可微矩阵运算——word2vec 是 one-hot×W_in（矩阵乘法查表），RNN 是 h_t = tanh(W_x·x + W_h·h)（矩阵乘法+激活），注意力是 softmax(QK^T)V（矩阵乘法+归一化），Transformer 是多头注意力+FFN（多个矩阵乘法组合）。所有模型本质都是矩阵乘法+非线性激活的组合。②训练统一为梯度下降——所有模型都用交叉熵损失（或类似损失）+ 反向传播 + 梯度下降训练。反向传播通过链式法则自动计算梯度，梯度下降沿梯度反方向更新参数。③表示统一为向量——从输入（词嵌入）到中间表示（隐状态/注意力输出）到输出（词表概率分布），所有信息都以向量形式流动。④都是「预测下一个词」的变体——word2vec 预测中心词/上下文词，RNN 语言模型预测下一个词，GPT 预测下一个词。训练目标的一致性使得模型可以不断堆叠和扩展。理解这个共同基因，就能理解为什么 Transformer 可以从 NLP 扩展到视觉（ViT）、语音等所有领域——矩阵运算+梯度下降是通用范式。
</Answer>

### 问题 4

如何将全书的 NLP 知识体系与现代大语言模型（GPT/BERT）联系起来？本书的知识在 LLM 时代是否仍然重要？

<Answer>

与现代 LLM 的联系：①GPT = Transformer 解码器 + 自回归生成 + 大规模预训练——GPT 的核心就是本书 ch7 的 Transformer 解码器（掩码自注意力+FFN）加上 ch8 的自回归生成，只是参数从百万扩展到千亿，训练数据从 MB 扩展到 TB。②BERT = Transformer 编码器 + 双向注意力 + 预训练——BERT 用的是本书 ch7 的编码器部分（自注意力无掩码），预训练任务改为掩码语言模型（完形填空）。③词嵌入仍是基础——GPT/BERT 的第一层都是嵌入层（token embedding + position embedding），与 word2vec 的 W_in 本质相同，只是加入了位置编码和分段编码。④注意力仍是核心——GPT/BERT 的每一层都以注意力为核心，本书学的 QKV 框架、多头、缩放点积公式完全适用。本书知识在 LLM 时代仍然重要的原因：①理解原理才能有效使用——知道注意力如何工作才能理解为什么 prompt 需要特定格式，知道位置编码才能理解长文本截断的影响。②理解原理才能调试优化——知道梯度下降和训练流程才能理解 fine-tuning、LoRA 等技术。③LLM 不会淘汰基础理解——正如高级语言不淘汰对数据结构的理解。本书教的是「NLP 的技术基因」，LLM 是这些基因的规模化表达。
</Answer>
