## Transformer：完全基于注意力的序列模型

2017 年 Google 论文「Attention Is All You Need」提出了 Transformer——完全去掉 RNN 的循环结构，仅用注意力实现序列建模。这是 NLP 的一次范式转变，也是 GPT/BERT 等大语言模型的基础架构。

<DnaTransformerDiagram />

## 与 RNN 的核心区别

| 特性 | RNN | Transformer |
|------|-----|-------------|
| 序列处理 | 逐步循环（h_t 依赖 h_{t-1}） | 全并行（所有位置同时计算） |
| 长距离依赖 | 弱（梯度消失） | 强（直接注意力连接） |
| 计算并行性 | 低（串行） | 高（纯矩阵运算） |
| GPU 利用率 | 低 | 高 |

<Callout type="info">

**为什么完全并行**：自注意力计算 `softmax(Q·K^T / √d_k) · V` 是纯矩阵运算，Q、K、V 可一次性由整个序列算出，位置间的注意力分数也是一次性矩阵乘法完成。RNN 需要 N 次串行计算，Transformer 只需1次矩阵运算。

</Callout>

## 自注意力

自注意力（Self-Attention）：Q、K、V 都来自**同一序列**的线性变换。

```text
Q = X · W_q    (N×d → N×d_k)
K = X · W_k    (N×d → N×d_k)
V = X · W_v    (N×d → N×d_v)

Attention(Q, K, V) = softmax(Q · K^T / √d_k) · V
```

每个位置可以**直接关注**序列中所有其他位置，无需通过循环逐步传递。

### 缩放点积注意力

```text
Attention(Q, K, V) = softmax(Q · K^T / √d_k) · V
```

为什么要除以 $\sqrt{d_k}$：当 $d_k$ 很大时，点积值很大，Softmax 会进入梯度趋近0的饱和区。除以 $\sqrt{d_k}$ 将方差缩回1，保持梯度稳定。

## 多头注意力

多头注意力：将 Q、K、V 分别投影到 h 个子空间，独立计算注意力后拼接。

```text
head_i = Attention(Q·W_q^i, K·W_k^i, V·W_v^i)
MultiHead = Concat(head_1, ..., head_h) · W_o
```

<Callout type="tip">

**为什么需要多个头**：不同的头可以学习关注不同类型的关系——一个头关注语法（主谓），一个头关注语义（同义），一个头关注位置（相邻词）。单头只能学到一种关注模式，多头从多视角捕获关系。实践中通常用 8-16 个头。

</Callout>

## 位置编码

自注意力本身是**位置无关**的——打乱输入顺序，输出只是对应行重排。但语言中词序至关重要，所以需要显式注入位置信息。

### 正弦位置编码

```text
PE(pos, 2i) = sin(pos / 10000^{2i/d})
PE(pos, 2i+1) = cos(pos / 10000^{2i/d})
```

不同维度对应不同频率的 sin/cos，能表达相对位置关系。位置编码与词嵌入**相加**后输入模型。

## 编码器与解码器

### 编码器子层

每层包含两个子层，都有残差连接 + LayerNorm：

1. **多头自注意力**（Q=K=V来自同一序列）
2. **前馈网络**（两层线性变换 + ReLU）

### 解码器子层

每层包含三个子层：

1. **掩码多头自注意力**（防止看到未来词）
2. **编码器-解码器交叉注意力**（Q来自解码器，K=V来自编码器）
3. **前馈网络**

### 掩码自注意力

<Callout type="warning">

**为什么需要掩码**：解码器训练时虽然用 Teacher Forcing 并行输入整个目标序列，但生成第 t 个词时不能看到第 t+1 个词（否则就是「作弊」）。掩码将注意力矩阵上三角（未来位置）设为负无穷，Softmax 后权重为0，确保位置 i 只能关注位置 0~i。

</Callout>

```python
def masked_attention(Q, K, V):
    d_k = Q.shape[-1]
    scores = np.dot(Q, K.T) / np.sqrt(d_k)
    
    # 创建掩码：上三角设为 -inf
    mask = np.triu(np.ones_like(scores), k=1) * -np.inf
    scores = scores + mask
    
    attention = softmax(scores)
    return np.dot(attention, V)
```

## 残差连接与 LayerNorm

每个子层的输出为：

```text
output = LayerNorm(x + Sublayer(x))
```

- **残差连接**：`x + Sublayer(x)`，让梯度可以直接流过，解决深层网络的梯度消失
- **LayerNorm**：对每个样本的特征维度归一化，稳定训练

## Transformer 的意义

<Callout type="info">

**范式转变**：Transformer 的完全并行特性使其可以扩展到超大模型（GPT-4 有万亿级参数）。这是 RNN 无法做到的——RNN 的串行特性限制了模型规模。Transformer 是大语言模型时代的技术基石。

</Callout>

<Glossary>

<GlossaryItem term="Transformer">
2017 年 Google 提出的序列模型，完全去掉 RNN 循环结构，仅用自注意力实现序列建模。所有位置可并行计算，GPU 友好。核心组件：多头自注意力、前馈网络、位置编码、残差连接+LayerNorm。是 GPT/BERT 等大语言模型的基础架构。
</GlossaryItem>

<GlossaryItem term="自注意力（Self-Attention）">
Q、K、V 都来自同一序列的注意力机制。每个位置可以直接关注序列中所有其他位置，无需通过循环逐步传递。公式：Attention(Q,K,V) = softmax(Q·K^T/√d_k)·V。自注意力是 Transformer 的核心创新。
</GlossaryItem>

<GlossaryItem term="多头注意力（Multi-Head Attention）">
将 Q、K、V 投影到 h 个子空间独立计算注意力，拼接后线性变换。不同头可学习关注不同类型的关系（语法、语义、位置）。总计算量与单头相同（每个头维度降低），但表达能力更强。通常用 8-16 个头。
</GlossaryItem>

<GlossaryItem term="位置编码（Positional Encoding）">
为自注意力注入位置信息的技术。自注意力本身位置无关，需要显式添加位置信息。正弦位置编码用不同频率的 sin/cos 函数生成位置向量，与词嵌入相加。能表达相对位置关系，无需训练，可推广到更长序列。
</GlossaryItem>

<GlossaryItem term="掩码自注意力（Masked Self-Attention）">
解码器中的自注意力，用掩码矩阵将未来位置的注意力权重设为0，确保位置 i 只能关注位置 0~i。防止训练时解码器「看到未来词」（作弊），保证训练时的并行计算与推理时的逐步生成行为一致。
</GlossaryItem>

<GlossaryItem term="缩放点积注意力">
Attention(Q,K,V) = softmax(Q·K^T/√d_k)·V。除以 √d_k 是因为当 d_k 很大时点积值很大，Softmax 进入饱和区梯度趋近0。√d_k 将方差缩回1，保持梯度稳定。是 Transformer 的标准注意力计算方式。
</GlossaryItem>

<GlossaryItem term="残差连接（Residual Connection）">
x + Sublayer(x)，让梯度可以直接流过子层，解决深层网络的梯度消失问题。Transformer 每个子层都使用残差连接，配合 LayerNorm 稳定训练。残差连接使得可以堆叠很多层（GPT-4 有上百层）。
</GlossaryItem>

</Glossary>

### 问题 1

Transformer 与 RNN 的核心区别是什么？为什么说 Transformer 是「完全并行」的？

<Answer>

核心区别：RNN 依赖循环结构——必须逐步处理序列（h_t 依赖 h_{t-1}），无法并行计算不同时间步；Transformer 完全去掉循环，仅用自注意力——序列中所有位置同时计算相互关系，无逐步依赖。Transformer 完全并行的原因：自注意力计算 Attention(Q, K, V) = softmax(Q·K^T / √d_k) · V 是纯矩阵运算，Q、K、V 可以一次性由整个序列算出（Q = X·W_q），位置间的注意力分数（Q·K^T）也是一次性矩阵乘法完成，不需要像 RNN 那样等前一步算完才能算下一步。这意味着一个长度为 N 的序列，RNN 需要 N 次串行计算，Transformer 只需要1次矩阵运算（GPU 高度优化）。并行性是 Transformer 可大规模扩展（训练千亿参数模型）的关键前提——GPU 擅长批量矩阵运算，RNN 的串行特性无法充分利用 GPU。
</Answer>

### 问题 2

Transformer 为什么需要位置编码？常用的位置编码方法是什么？

<Answer>

需要位置编码的原因：自注意力机制本身是「位置无关」的——它只计算词与词之间的注意力分数，不包含位置信息。如果打乱输入序列的顺序，自注意力的输出只是对应的行重排，不会改变每行的内容。但语言中词序至关重要（"狗咬人" 和 "人咬狗" 含义完全不同），所以必须显式注入位置信息。常用方法：①正弦位置编码（原论文）——用不同频率的 sin/cos 函数生成位置向量：PE(pos, 2i) = sin(pos / 10000^{2i/d})，PE(pos, 2i+1) = cos(pos / 10000^{2i/d})。不同维度对应不同频率，能表达相对位置关系（固定偏移的任意位置对有线性关系）。优点是无需训练、可推广到训练时未见过的长度。②学习式位置编码——为每个位置分配一个可学习的向量，随训练更新。简单直接但不能推广到更长序列。实践中正弦编码更常用。位置编码与词嵌入相加后输入模型。
</Answer>

### 问题 3

多头注意力是什么？为什么需要多个「头」而不是一个？

<Answer>

多头注意力（Multi-Head Attention）：将 Q、K、V 分别投影到 h 个不同的子空间（每个头有独立的 W_q^i, W_k^i, W_v^i），在每个子空间独立计算注意力，最后将所有头的输出拼接后再做一次线性变换。公式：MultiHead = Concat(head_1, ..., head_h) · W_o，其中 head_i = Attention(Q·W_q^i, K·W_k^i, V·W_v^i)。需要多个头的原因：①多视角关注——不同的头可以学习关注不同类型的关系。例如一个头关注语法关系（主谓），一个头关注语义关系（同义），一个头关注位置关系（相邻词）。单头注意力只能学到一种关注模式。②表达能力增强——多头等价于将高维注意力分解为多个低维注意力，类似 CNN 中多个卷积核捕获不同特征。③计算效率——多头总计算量与单头相同（每个头维度降低 d/h，但头数 h，总维度不变），但表达能力更强。实践中通常用 8-16 个头。
</Answer>

### 问题 4

Transformer 编码器和解码器各包含哪些子层？解码器的掩码自注意力是什么？为什么需要掩码？

<Answer>

编码器子层（每层）：①多头自注意力（Q=K=V来自同一序列）+ 残差连接 + LayerNorm。②前馈网络（两层线性变换+ReLU）+ 残差连接 + LayerNorm。解码器子层（每层）：①掩码多头自注意力 + 残差连接 + LayerNorm。②编码器-解码器交叉注意力（Q来自解码器，K=V来自编码器输出）+ 残差连接 + LayerNorm。③前馈网络 + 残差连接 + LayerNorm。掩码自注意力：在解码器的自注意力中，用掩码矩阵将注意力分数矩阵的上三角（未来位置）设为负无穷，Softmax 后这些位置的权重为0，确保位置 i 只能关注位置 0~i（不能看到未来的词）。需要掩码的原因：解码器是自回归生成的——训练时虽然用 Teacher Forcing 并行输入整个目标序列，但生成第 t 个词时不能看到第 t+1 个词（否则就是「作弊」，利用了未来信息）。掩码保证训练时的并行计算与推理时的逐步生成行为一致。没有掩码，模型会直接从未来词「抄答案」，训练看似很好但推理时完全无法生成。
</Answer>
