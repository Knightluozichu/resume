## 文本生成：让模型「写」文字

有了语言模型（RNN/LSTM/Transformer），我们可以让它**生成文本**——给定前缀，逐词预测下一个词，循环直到结束。这是 GPT 等生成式语言模型的核心工作方式。

## 自回归生成流程

文本生成的基本循环：

```python
def generate_text(model, prefix, max_length=100):
    tokens = tokenize(prefix)  # 前缀分词
    
    for _ in range(max_length):
        # 1. 模型预测下一个词的概率分布
        probs = model.predict(tokens)  # P(next | context)
        
        # 2. 根据概率分布选词（采样策略）
        next_token = sample(probs)
        
        # 3. 拼接到已生成序列
        tokens.append(next_token)
        
        # 4. 遇到结束符则停止
        if next_token == EOS:
            break
    
    return detokenize(tokens)
```

<Callout type="info">

**自回归**：每步生成都以之前生成的所有词作为上下文。第1步以前缀为上下文，第2步以前缀+词1为上下文，依此类推。语言模型本质是在学习 P(w_t | w_1, ..., w_{t-1})。

</Callout>

## 采样策略

### 贪心搜索（Greedy）

每步选概率最高的词。

```python
def greedy_sample(probs):
    return np.argmax(probs)
```

- 优点：简单快速
- 缺点：输出重复呆板，可能陷入循环（如 \"I I I I\"）

### 温度采样（Temperature）

将概率分布除以温度 T 后重新 Softmax，再随机采样。

```python
def temperature_sample(probs, temperature=1.0):
    probs = np.log(probs + 1e-10) / temperature
    probs = np.exp(probs) / np.sum(np.exp(probs))
    return np.random.choice(len(probs), p=probs)
```

- T > 1：分布变平滑，更随机（更多样但可能出错）
- T < 1：分布变尖锐，更确定（更保守但呆板）
- T = 1：原始分布

### Top-k 采样

只从概率最高的 k 个词中采样，过滤长尾低质量词。

```python
def top_k_sample(probs, k=10):
    # 取概率最高的k个词
    top_k_idx = np.argsort(probs)[-k:]
    top_k_probs = probs[top_k_idx]
    top_k_probs = top_k_probs / np.sum(top_k_probs)
    return np.random.choice(top_k_idx, p=top_k_probs)
```

### Top-p 采样（Nucleus Sampling）

只从累计概率达到 p 的最小词集合中采样，集合大小动态适应。

```python
def top_p_sample(probs, p=0.9):
    sorted_idx = np.argsort(probs)[::-1]  # 降序
    sorted_probs = probs[sorted_idx]
    cumsum = np.cumsum(sorted_probs)
    
    # 找到累计概率刚超过p的位置
    cutoff = np.searchsorted(cumsum, p) + 1
    top_idx = sorted_idx[:cutoff]
    top_probs = probs[top_idx]
    top_probs = top_probs / np.sum(top_probs)
    return np.random.choice(top_idx, p=top_probs)
```

<Callout type="tip">

**实践推荐**：Top-k/Top-p + 温度调节是实际最常用的策略。Top-p 比固定 k 更灵活——概率分布集中时选少数词，分布分散时选更多词。

</Callout>

## 生成质量评价

### 困惑度（Perplexity）

评估语言模型本身的质量——模型对真实文本的预测能力。

```text
PPL = exp(-1/N · Σ log P(w_i | w_{<i}))
```

- PPL 越低越好
- PPL = 1：完美预测
- PPL = V（词表大小）：随机猜测
- 不需要参考答案，只需测试文本

```python
def perplexity(model, text):
    log_probs = 0
    n = 0
    for i in range(1, len(text)):
        probs = model.predict(text[:i])
        log_probs += np.log(probs[text[i]] + 1e-10)
        n += 1
    return np.exp(-log_probs / n)
```

### BLEU 分数

评估生成文本（如机器翻译）与参考译文的匹配程度。

```text
BLEU = BP × exp(Σ w_n × log p_n)
```

- $p_n$：n-gram 精确率（生成文本中 n-gram 有多少出现在参考译文中）
- BP：长度惩罚（防止过短输出）
- BLEU 越高越好（0-1）
- 需要参考答案

| 指标 | 评估对象 | 需要参考答案 | 适用场景 |
|------|---------|-------------|---------|
| 困惑度 | 模型概率分布 | 否 | 语言模型训练评估 |
| BLEU | 生成文本质量 | 是 | 翻译、摘要评估 |

## 从 word2vec 到 GPT 的能力演进

```text
word2vec → RNN/LSTM → seq2seq → 注意力 → Transformer → GPT
 静态词嵌入  序列建模   跨序列映射  动态关注   并行建模    自回归生成
```

| 阶段 | 核心能力 | 关键突破 |
|------|---------|---------|
| word2vec | 词的语义表示 | 分布式假设 |
| RNN/LSTM | 词序与上下文 | 循环+门控 |
| seq2seq | 序列到序列转换 | 编码器-解码器 |
| 注意力 | 选择性关注 | 动态上下文 |
| Transformer | 大规模并行 | 纯注意力 |
| GPT | 生成连贯文本 | 自回归+预训练 |

<Callout type="info">

**本质演进**：从「理解单个词」到「理解序列」到「生成序列」。GPT 的核心就是 Transformer 解码器 + 自回归生成 + 大规模预训练——本书 ch7 的解码器加上本章的生成策略，只是参数从百万扩展到千亿。

</Callout>

<Glossary>

<GlossaryItem term="自回归生成">
文本生成的基本方式——每一步生成都以之前生成的所有词作为上下文，逐步预测下一个词。GPT 等生成式语言模型的核心工作方式。训练时用 Teacher Forcing（输入正确答案），推理时用自回归（输入上一步预测）。
</GlossaryItem>

<GlossaryItem term="贪心搜索（Greedy Search）">
每步选概率最高的词的生成策略。简单快速但输出重复呆板，可能陷入循环。局部最优不等于全局最优——贪心可能错过整体更好的序列。
</GlossaryItem>

<GlossaryItem term="温度采样（Temperature Sampling）">
将概率分布除以温度T后重新Softmax再随机采样。T>1更随机（多样但可能出错），T<1更确定（保守但呆板）。可调节生成文本的多样性。
</GlossaryItem>

<GlossaryItem term="Top-k 采样">
只从概率最高的k个词中随机采样，过滤长尾低质量词。兼顾多样性（仍随机采样）和质量（过滤垃圾词）。缺点是k固定，不同语境下最优k不同。
</GlossaryItem>

<GlossaryItem term="Top-p 采样（Nucleus Sampling）">
只从累计概率达到p的最小词集合中采样。集合大小动态适应概率分布——分布集中时选少数词，分散时选更多词。比固定k的Top-k更灵活，是实际最常用的策略。
</GlossaryItem>

<GlossaryItem term="困惑度（Perplexity）">
评估语言模型质量的指标。PPL = exp(平均交叉熵)，表示模型在每个位置「平均有多少个等概率候选词」。PPL越低越好，1为完美，V（词表大小）为随机猜测。不需要参考答案。
</GlossaryItem>

<GlossaryItem term="BLEU 分数">
评估生成文本与参考译文匹配程度的指标。基于n-gram精确匹配+长度惩罚。BLEU越高越好（0-1）。需要参考答案，适用于翻译、摘要等有标准答案的生成任务。
</GlossaryItem>

</Glossary>

### 问题 1

语言模型的文本生成基本流程是什么？什么是自回归生成？

<Answer>

文本生成基本流程：①输入前缀文本（如 "The cat"）→ ②语言模型计算下一个词的概率分布 P(next | context) → ③根据概率分布采样一个词（如 "sat"）→ ④将采样的词拼接到前缀后（"The cat sat"）→ ⑤重复②-④直到生成结束符 <EOS> 或达到最大长度。自回归生成：每一步生成都以之前生成的所有词作为上下文——第1步以输入前缀为上下文生成词1，第2步以前缀+词1为上下文生成词2，依此类推。每步的输入都包含上一步的输出，形成自回归循环。这是 GPT 等生成式语言模型的基本工作方式。语言模型本质是在学习 P(w_t | w_1, w_2, ..., w_{t-1})——给定历史序列预测下一个词的概率分布。
</Answer>

### 问题 2

贪心搜索、温度采样和 Top-k 采样各自的原理和优缺点是什么？

<Answer>

贪心搜索：每步选概率最高的词。优点：简单快速、输出确定性强。缺点：容易陷入重复循环（如 "I I I I"）、输出呆板缺乏多样性、可能错过全局最优序列（局部最优不等于全局最优）。温度采样：将概率分布除以温度 T 后重新 Softmax。T>1 分布变平滑（更随机），T<1 分布变尖锐（更确定），T=1 原始分布。按调整后的概率随机采样。优点：可调节随机性，平衡多样性和质量。缺点：可能采到低概率的垃圾词。Top-k 采样：只从概率最高的 k 个词中按概率采样，过滤掉长尾低质量词。优点：兼顾多样性（仍随机采样）和质量（过滤垃圾词）。缺点：k 是固定的，不同语境下最优 k 不同。实践中 Top-p（nucleus sampling）更灵活——只从累计概率达到 p 的最小词集合中采样，集合大小动态适应概率分布。综合效果：Top-k/Top-p + 温度调节是实际最常用的策略。
</Answer>

### 问题 3

困惑度（Perplexity）和 BLEU 分数分别评估什么？它们的计算方式有什么区别？

<Answer>

困惑度（Perplexity, PPL）：评估语言模型本身的质量——模型对真实文本的预测能力。计算：PPL = exp(平均交叉熵) = exp(-1/N Σ log P(w_i | w_{<i}))。含义：PPL 表示模型在每个位置「平均有多少个等概率候选词」——PPL=1 完美预测，PPL=V（词表大小）随机猜测。PPL 越低越好。适用场景：评估语言模型的训练效果（如 GPT 在不同 checkpoint 的 PPL 对比），不需要参考答案，只需测试文本。BLEU 分数：评估生成文本（如机器翻译）的质量——与参考译文的匹配程度。计算：基于 n-gram 精确匹配（生成文本中 n-gram 有多少出现在参考译文中），加上长度惩罚（防止过短输出）。BLEU = BP × exp(Σ w_n × log p_n)，p_n 是 n-gram 精确率。BLEU 越高越好（0-1之间）。适用场景：评估翻译、摘要等有参考答案的生成任务。区别：PPL 评估「模型概率分布是否准确」，BLEU 评估「生成文本是否与参考匹配」。PPL 是连续的概率度量，BLEU 是离散的匹配度量。
</Answer>

### 问题 4

从 word2vec 到 GPT 风格的文本生成，NLP 模型的能力是如何逐步扩展的？每一步的关键突破是什么？

<Answer>

能力扩展路径：①word2vec（静态词嵌入）——学会了「词的含义」（分布式表示），但每个词只有一个固定向量，不理解上下文。"bank" 在「河岸」和「银行」中向量相同。②RNN/LSTM（序列建模）——学会了「词的顺序和上下文」，h_t 编码了截至当前的所有历史信息，同一个词在不同上下文中有不同表示。但串行计算慢，长距离依赖仍弱。③seq2seq（跨序列映射）——学会了「序列到序列的转换」（翻译、摘要），但固定瓶颈限制了长序列质量。④注意力（动态上下文）——学会了「选择性关注」，每步动态聚焦最相关的信息，打破瓶颈。⑤Transformer（完全并行注意力）——学会了「大规模并行建模序列内关系」，多头注意力从多视角捕获关系，可扩展到超大模型。⑥GPT（自回归生成）——将 Transformer 解码器用于「从左到右逐词生成」，通过海量预训练学会「生成连贯文本」。每一步突破：word2vec→分布式表示，RNN→时序建模，seq2seq→跨序列映射，注意力→动态聚焦，Transformer→并行扩展，GPT→生成能力。本质演进：从「理解单个词」到「理解序列」到「生成序列」。
</Answer>
