## MDP：强化学习的数学语言

强化学习问题需要形式化描述才能严谨求解。**马尔可夫决策过程（MDP）**就是 RL 的数学框架。

<DlrMdpDiagram />

### 五元组

MDP 用五元组 $(S, A, P, R, \gamma)$ 描述：

| 符号 | 含义 | 说明 |
|------|------|------|
| $S$ | 状态集 | 环境可能处于的所有状态 |
| $A$ | 动作集 | 智能体可执行的所有动作 |
| $P(s'\|s,a)$ | 转移概率 | 在状态 $s$ 执行动作 $a$ 后转移到 $s'$ 的概率 |
| $R(s,a)$ | 奖励函数 | 在状态 $s$ 执行动作 $a$ 获得的即时奖励 |
| $\gamma$ | 折扣因子 | 控制未来奖励权重，$\gamma \in (0,1)$ |

## 马尔可夫性质

<Callout type="info">

**核心假设**：下一个状态 $s_{t+1}$ 的概率分布只依赖当前状态 $s_t$ 和动作 $a_t$，与历史无关：

`P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, ..., s_0, a_0) = P(s_{t+1} | s_t, a_t)`

即「给定现在，未来与过去独立」。

</Callout>

### 为什么马尔可夫性质至关重要

1. **可计算性**——如果未来依赖全部历史，状态空间指数爆炸；马尔可夫性质让问题降维为「只需当前状态即可决策」
2. **定义值函数**——只有当前状态包含决策所需的全部信息，$V(s) = \mathbb{E}[G_t | s_t = s]$ 才有意义
3. **贝尔曼方程成立**——递归分解 $V(s) = \mathbb{E}[r + \gamma V(s')]$ 依赖马尔可夫性质
4. **实际意义**——状态表示设计得好则近似满足，否则是 POMDP（更难求解）

## 折扣回报

从时间步 $t$ 开始的累计折扣回报：

```text
G_t = r_{t+1} + gamma * r_{t+2} + gamma^2 * r_{t+3} + ...
    = sum_{k=0}^{inf} gamma^k * r_{t+k+1}
```

### 为什么需要折扣因子

| 原因 | 说明 |
|------|------|
| 数学收敛 | 无折扣的无限累计回报趋向无穷，无法比较策略好坏 |
| 不确定性 | 未来奖励越远越不确定，低权重合理 |
| 即时偏好 | 实践中通常更希望尽快获得奖励 |

<Callout type="tip">

**gamma 的选择**：接近 1（如 0.99）重视长远，适合稀疏奖励任务；较小（如 0.9）重视近期，适合密集奖励任务。$\gamma = 1$ 仅适用于有限 episode。

</Callout>

## 状态转移示例

以网格世界为例：智能体在网格中移动，目标是到达终点。

```text
状态 s ──动作 a──> 状态 s' ──动作 a'──> 终止
         │                    │
    P(s'|s,a)            P(s''|s',a')
    R(s,a,s')            R(s',a',s'')
```

每一步的转移由 $P(s'|s,a)$ 决定，奖励由 $R(s,a,s')$ 给出。

## 部分可观测 MDP（POMDP）

当智能体无法直接观测真实状态，只能观测到观测值 $o$（由观测函数 $O(o|s,a)$ 生成）时，问题变为 POMDP。

### POMDP 的挑战

- **马尔可夫性质被破坏**——观测 $o$ 不包含全部信息
- **需要信念状态**——对真实状态的概率分布估计 $b(s)$
- **需要记忆机制**——RNN/LSTM 隐式维护历史信息

```python
# MDP 的简单 Python 表示
class MDP:
    def __init__(self, states, actions, transitions, rewards, gamma=0.9):
        self.S = states          # 状态集
        self.A = actions         # 动作集
        self.P = transitions     # P(s'|s,a) 转移概率
        self.R = rewards         # R(s,a,s') 奖励函数
        self.gamma = gamma       # 折扣因子

    def step(self, state, action):
        # 按转移概率采样下一个状态
        probs = self.P(state, action)
        next_state = np.random.choice(self.S, p=probs)
        reward = self.R(state, action, next_state)
        return next_state, reward
```

<Glossary>

<GlossaryItem term="马尔可夫决策过程（MDP）">
强化学习问题的数学形式化，用五元组 (S, A, P, R, gamma) 描述。S 是状态集，A 是动作集，P(s'|s,a) 是转移概率，R 是奖励函数，gamma 是折扣因子。核心假设是马尔可夫性质——未来只依赖当前状态和动作。所有 RL 算法都在求解 MDP（或其变体），区别在于是否已知模型（P 和 R）、如何处理大状态空间。
</GlossaryItem>

<GlossaryItem term="马尔可夫性质">
下一个状态的概率分布只依赖当前状态和动作，与历史无关：P(s_{t+1}|s_t,a_t,...,s_0,a_0) = P(s_{t+1}|s_t,a_t)。这是 MDP 的核心假设，让问题可计算（降维到当前状态）、让值函数和贝尔曼方程成立。如果状态表示设计得好则近似满足；否则是 POMDP。状态表示工程（特征选择、编码）的目标就是让状态近似满足马尔可夫性质。
</GlossaryItem>

<GlossaryItem term="折扣回报 G_t">
从时间步 t 开始的累计折扣奖励：G_t = r_{t+1} + gamma*r_{t+2} + gamma^2*r_{t+3} + ... = sum gamma^k * r_{t+k+1}。折扣因子 gamma 在 (0,1) 保证级数收敛（无限 episode）、体现未来不确定性、反映即时偏好。gamma 接近1 重视长远，适合稀疏奖励；较小重视近期，适合密集奖励。值函数 V(s) = E[G_t|s_t=s] 就是折扣回报的期望。
</GlossaryItem>

<GlossaryItem term="转移概率 P(s'|s,a)">
MDP 五元组之一。在状态 s 执行动作 a 后转移到状态 s' 的概率。满足 sum_s' P(s'|s,a) = 1（概率归一化）。转移概率描述环境的动态特性——确定性环境中 P 只取 0 或 1（同一 s,a 总是转到同一 s'），随机环境中有多个 s' 可能。DP 算法需要已知 P，MC/TD 算法不需要（通过采样隐式估计）。
</GlossaryItem>

<GlossaryItem term="部分可观测 MDP（POMDP）">
智能体无法直接观测真实状态 s，只能观测到观测值 o 的 MDP 变体。观测函数 O(o|s,a) 从真实状态生成观测。马尔可夫性质被破坏——观测 o 不含全部信息。解决方法：维护信念状态 b(s)（对真实状态的概率分布），在信念状态上满足马尔可夫性质；或用 RNN 等记忆机制处理观测历史。POMDP 比 MDP 难得多，是 RL 研究的前沿方向。
</GlossaryItem>

<GlossaryItem term="信念状态（Belief State）">
POMDP 中对真实状态的概率分布估计 b(s)。由于观测不完整，智能体无法确定真实状态，只能维护一个概率分布。每次观测后用贝叶斯更新信念状态：b'(s') ∝ O(o|s',a) * sum_s P(s'|s,a) * b(s)。在信念状态上问题重新满足马尔可夫性质（信念状态的马尔可夫性），可用标准 MDP 算法求解，但信念状态空间是连续的（概率分布），通常需要函数近似。
</GlossaryItem>

</Glossary>

### 问题 1

什么是马尔可夫决策过程（MDP）？它的五元组是什么？

<Answer>

马尔可夫决策过程（MDP, Markov Decision Process）是强化学习问题的数学形式化，用五元组 (S, A, P, R, gamma) 描述：①S（状态集）——环境可能处于的所有状态的集合。②A（动作集）——智能体可以执行的所有动作的集合。③P（转移概率）——P(s'|s,a) 表示在状态 s 执行动作 a 后转移到状态 s' 的概率。④R（奖励函数）——R(s,a) 或 R(s,a,s') 表示在状态 s 执行动作 a（并转移到 s'）时获得的即时奖励。⑤gamma（折扣因子）——在 (0,1) 区间，控制未来奖励的权重，越接近1越重视长远回报。MDP 的核心假设是马尔可夫性质：未来只依赖当前状态和动作，与历史无关。这个假设让 RL 问题可计算——如果未来依赖全部历史，状态空间会爆炸。MDP 是全书所有算法的基础框架。
</Answer>

### 问题 2

马尔可夫性质是什么？为什么它对强化学习至关重要？

<Answer>

马尔可夫性质：下一个状态 s_{t+1} 的概率分布只依赖当前状态 s_t 和动作 a_t，与之前的历史无关。形式化：P(s_{t+1} | s_t, a_t, s_{t-1}, a_{t-1}, ..., s_0, a_0) = P(s_{t+1} | s_t, a_t)。即「给定现在，未来与过去独立」。对 RL 至关重要的原因：①可计算性——如果未来依赖全部历史，需要建模整个轨迹分布，状态空间指数爆炸。马尔可夫性质让问题降维为「只需当前状态即可决策」。②定义值函数——V(s) 和 Q(s,a) 的定义依赖马尔可夫性质：只有当前状态包含决策所需的全部信息，V(s) = E[G_t | s_t=s] 才有意义。③贝尔曼方程成立——贝尔曼方程的递归分解 V(s) = E[r + gamma V(s')] 依赖马尔可夫性质（s' 的分布只依赖 s 和 a）。④实际意义——如果状态表示设计得好（包含足够信息），近似满足马尔可夫性质；否则就是 POMDP（部分可观测 MDP），更难求解。
</Answer>

### 问题 3

折扣回报 G_t 是什么？为什么要引入折扣因子 gamma？

<Answer>

折扣回报 G_t 是从时间步 t 开始的累计折扣奖励：G_t = r_{t+1} + gamma * r_{t+2} + gamma^2 * r_{t+3} + ... = sum_{k=0}^{inf} gamma^k * r_{t+k+1}。引入折扣因子 gamma（0 < gamma < 1）的原因：①数学收敛——如果 episode 无限持续且奖励恒正，无折扣的累计回报会趋向无穷，无法比较策略好坏。gamma^k 随 k 指数衰减保证级数收敛。②不确定性——未来的奖励越远越不确定（环境可能变化、模型可能不准），给远期奖励更低权重是合理的。③即时偏好——实践中通常更希望尽快获得奖励（如今天拿100元比明年拿100元更有价值），gamma 体现这种时间偏好。gamma 的选择：接近1（如0.99）重视长远，适合稀疏奖励任务；较小（如0.9）重视近期，适合密集奖励任务。gamma=1 仅适用于有限 episode（有限步终止）的情况。
</Answer>

### 问题 4

在 MDP 中，「状态」的设计如何影响问题求解？什么是部分可观测 MDP（POMDP）？

<Answer>

状态设计的影响：①马尔可夫性是否满足——如果状态包含决策所需的全部信息（如棋盘局面），满足马尔可夫性质，可用标准 MDP 算法；如果状态信息不完整（如只看到棋盘一角），未来依赖历史，违反马尔可夫性质。②状态空间大小——离散状态少可用表格法，连续或高维状态需函数近似（神经网络）。③信噪比——好的状态表示滤除无关信息、保留关键特征，加速学习。POMDP（部分可观测 MDP）：智能体无法直接观测真实状态 s，只能观测到观测值 o（o 由观测函数 O(o|s,a) 从真实状态生成）。例如自动驾驶中，传感器只能看到周围有限范围，无法知道全局路况。POMDP 的挑战：①马尔可夫性质被破坏——观测 o 不包含全部信息，V(o) 不再是良好的值函数。②需要维护信念状态（belief state）——对真实状态的概率分布估计 b(s)，在信念状态上重新满足马尔可夫性质。③通常需要 RNN 等记忆机制——深度 RL 中用 LSTM/Transformer 处理观测历史，隐式维护信念状态。状态表示工程（特征工程、状态编码）是 RL 实践中最关键的设计决策之一。
</Answer>
