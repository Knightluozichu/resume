## 动态规划：有模型的精确求解

动态规划（DP）是强化学习中最基础的算法族——它假设**已知完整的 MDP 模型**（转移概率 $P$ 和奖励函数 $R$），通过贝尔曼方程迭代计算值函数和最优策略。

<DlrDynamicProgrammingDiagram />

<Callout type="warning">

**DP 的前提**：必须知道环境的完整模型（$P$ 和 $R$）。现实问题通常不知道模型，所以 DP 很少直接可用。但它是 RL 的理论基石——MC、TD、Q学习等无模型算法都是 DP 思想在「不知道模型」情况下的近似推广。

</Callout>

## 策略评估

给定策略 $\pi$，迭代求 $V_\pi$：

```text
V_{k+1}(s) = sum_a pi(a|s) sum_s' P(s'|s,a) [ R(s,a,s') + gamma * V_k(s') ]
```

反复迭代直到 $V$ 收敛（$V_{k+1} \approx V_k$）。

### Python 实现

```python
def policy_evaluation(policy, P, R, gamma, n_states, theta=1e-6):
    V = np.zeros(n_states)
    while True:
        delta = 0
        V_new = np.zeros(n_states)
        for s in range(n_states):
            for a in range(n_actions):
                for s_next in range(n_states):
                    V_new[s] += policy[s, a] * P[s, a, s_next] * (
                        R[s, a, s_next] + gamma * V[s_next]
                    )
            delta = max(delta, abs(V_new[s] - V[s]))
        V = V_new
        if delta < theta:
            break
    return V
```

## 策略改进

基于 $V_\pi$ 贪心改进策略：

```text
pi'(s) = argmax_a sum_s' P(s'|s,a) [ R(s,a,s') + gamma * V_pi(s') ]
```

### 策略改进定理

对任意策略 $\pi$，贪心改进后的 $\pi'$ 满足 $V_{\pi'}(s) \geq V_\pi(s)$ 对所有 $s$ 成立——策略迭代单调递增直至最优。

## 策略迭代

交替执行「完整评估」和「改进」：

```text
初始化 pi_0
重复：
  1. 策略评估：求 V_{pi_k}（迭代到收敛）
  2. 策略改进：pi_{k+1} = greedy(V_{pi_k})
直到 pi_{k+1} = pi_k（策略不再变化）
```

## 价值迭代

将评估和改进合并为一步，每步直接用贝尔曼最优方程：

```text
V_{k+1}(s) = max_a sum_s' P(s'|s,a) [ R(s,a,s') + gamma * V_k(s') ]
```

### Python 实现

```python
def value_iteration(P, R, gamma, n_states, n_actions, theta=1e-6):
    V = np.zeros(n_states)
    while True:
        delta = 0
        for s in range(n_states):
            q_values = np.zeros(n_actions)
            for a in range(n_actions):
                for s_next in range(n_states):
                    q_values[a] += P[s, a, s_next] * (
                        R[s, a, s_next] + gamma * V[s_next]
                    )
            v_new = np.max(q_values)
            delta = max(delta, abs(v_new - V[s]))
            V[s] = v_new
        if delta < theta:
            break
    # 从 V 提取最优策略
    policy = np.zeros((n_states, n_actions))
    for s in range(n_states):
        q_values = np.zeros(n_actions)
        for a in range(n_actions):
            for s_next in range(n_states):
                q_values[a] += P[s, a, s_next] * (
                    R[s, a, s_next] + gamma * V[s_next]
                )
        policy[s, np.argmax(q_values)] = 1.0
    return V, policy
```

## 策略迭代 vs 价值迭代

| 特性 | 策略迭代 | 价值迭代 |
|------|---------|---------|
| 流程 | 完整评估 + 改进（分离） | 评估+改进合并（每步含 max） |
| 中间值 | 某策略的真实值函数 | 不一定对应任何策略 |
| 开销 | 每轮大（评估需多次迭代） | 每轮小（一次备份） |
| 轮次 | 少 | 多 |

<Callout type="tip">

**实践选择**：状态空间小、模型简单时策略迭代更直接；状态空间大时价值迭代每轮便宜更实用。两者可以混合——广义策略迭代（GPI）不要求任一步完全收敛。

</Callout>

## 广义策略迭代（GPI）

GPI 不要求策略评估和策略改进任一步完全收敛，两者任意交织、互相驱动：

```text
评估（让 V 逼近 pi 的真实值）  ←──→  改进（让 pi 逼近 V 的贪心策略）
```

只要评估和改进持续进行，最终都会收敛到最优。

<Callout type="info">

**GPI 是所有 RL 算法的统一框架**：策略迭代和价值迭代是 GPI 的极端特例；MC/TD 控制用采样代替精确评估 + epsilon-贪心代替完全贪心，也是 GPI；DQN 用神经网络近似 Q + argmax 选动作，还是 GPI；策略梯度中 Actor 和 Critic 交替更新，同样是 GPI。

</Callout>

<Glossary>

<GlossaryItem term="策略评估">
给定策略 pi，迭代求 V_pi 的过程。用贝尔曼期望方程反复备份：V_&#123;k+1&#125;(s) = sum_a pi(a|s) sum_s' P(s'|s,a)[R + gamma*V_k(s')]，直到收敛。是 DP 的预测步骤，也是控制算法中「评估当前策略」的环节。实践中可用「截断评估」（只迭代几步不求完全收敛）来加速，仍是 GPI 的合法实例。
</GlossaryItem>

<GlossaryItem term="策略改进">
基于值函数贪心地更新策略：pi'(s) = argmax_a sum_s' P(s'|s,a)[R + gamma*V(s)]。策略改进定理保证 V_pi' >= V_pi（单调递增），这是策略迭代收敛到最优的理论基础。在控制算法中，改进通常用 epsilon-贪心（近似贪心）而非完全贪心，以保持探索能力。
</GlossaryItem>

<GlossaryItem term="策略迭代">
DP 的控制算法之一。交替执行完整策略评估和策略改进，直到策略不再变化。收敛快（通常几轮），但每轮评估开销大（需多次迭代求精确 V）。与价值迭代是 DP 控制的两种经典方法，都收敛到 V* 和 pi*。策略迭代是 GPI 的极端特例（评估完全收敛后再改进）。
</GlossaryItem>

<GlossaryItem term="价值迭代">
DP 的控制算法之一。将策略评估和改进合并为一步，每步直接用贝尔曼最优方程更新：V_&#123;k+1&#125;(s) = max_a sum_s' P(s'|s,a)[R + gamma*V_k(s')]。每轮开销小（一次备份）但总轮次多。与策略迭代等价（都收敛到 V*），区别在于评估和改进不分离。价值迭代也是 GPI 的极端特例（每步只做一次备份就改进）。
</GlossaryItem>

<GlossaryItem term="广义策略迭代（GPI）">
所有 RL 算法的统一框架。不要求策略评估和改进任一步完全收敛，两者任意交织、互相驱动，最终收敛到最优。策略迭代和价值迭代是 GPI 的两个极端特例；MC/TD 控制用采样近似评估 + epsilon-贪心近似改进，也是 GPI；DQN 用神经网络近似 Q + argmax，还是 GPI；Actor-Critic 中 Actor（策略）和 Critic（值函数）交替更新，同样是 GPI。GPI 揭示了所有 RL 算法的共同结构。
</GlossaryItem>

<GlossaryItem term="贝尔曼备份">
用贝尔曼方程更新值函数的操作。期望备份（用于策略评估）：V(s) ← sum_a pi(a|s) sum_s' P[R + gamma*V(s')]。最优备份（用于价值迭代）：V(s) ← max_a sum_s' P[R + gamma*V(s')]。DP 通过反复备份使值函数逐步逼近真值。MC/TD 用采样替代精确求和，是备份的随机近似。DQN 用神经网络计算 Q，是备份的函数近似版本。
</GlossaryItem>

</Glossary>

### 问题 1

动态规划（DP）在强化学习中解决什么问题？它的前提条件是什么？

<Answer>

动态规划（DP）在 RL 中解决「有模型的预测和控制问题」：已知完整的 MDP 模型（转移概率 P 和奖励函数 R），通过贝尔曼方程迭代计算值函数和最优策略。DP 的两个核心算法：①策略评估（预测）——给定策略 pi，迭代求 V_pi：V_&#123;k+1&#125;(s) = sum_a pi(a|s) sum_s' P(s'|s,a)[R + gamma*V_k(s')]，反复迭代直到收敛。②策略改进——基于 V_pi 贪心改进：pi'(s) = argmax_a sum_s' P(s'|s,a)[R + gamma*V_pi(s')]。前提条件：①已知模型——必须知道 P(s'|s,a) 和 R(s,a,s')，这是 DP 的最大限制（现实问题通常不知道模型）。②有限状态空间——DP 需要对每个状态迭代，状态空间大时计算不可行（维度灾难）。③马尔可夫性质——MDP 假设必须成立。尽管 DP 在实际中很少直接可用（因为需要完整模型），但它是 RL 的理论基石：MC、TD、Q学习等无模型算法都是 DP 思想在「不知道模型」情况下的近似推广。
</Answer>

### 问题 2

策略迭代（Policy Iteration）的流程是什么？为什么它能收敛到最优策略？

<Answer>

策略迭代流程：①初始化——任意策略 pi_0 和任意 V_0。②策略评估——对当前策略 pi_k，迭代计算 V_&#123;pi_k&#125; 直到收敛（用贝尔曼期望方程反复备份）。③策略改进——基于 V_&#123;pi_k&#125; 贪心改进：pi_&#123;k+1&#125;(s) = argmax_a sum_s' P(s'|s,a)[R + gamma*V_&#123;pi_k&#125;(s')]。④重复②③直到策略不再变化（pi_&#123;k+1&#125; = pi_k），此时已收敛。收敛性保证：策略改进定理——对任意策略 pi，贪心改进后的 pi' 满足 V_pi'(s) >= V_pi(s) 对所有 s 成立。因此策略迭代中值函数单调递增，而值函数有上界（最优值函数 V*），所以序列必定收敛。当策略不再改变时，pi 已满足贝尔曼最优方程，即为最优策略 pi*。策略迭代的特点：收敛快（通常几轮就收敛），但每轮策略评估需要多次迭代（计算开销大）。实践中可用「截断评估」（只迭代几步不求完全收敛）来加速。
</Answer>

### 问题 3

价值迭代（Value Iteration）与策略迭代的区别是什么？

<Answer>

价值迭代与策略迭代的区别：①流程——策略迭代交替执行「完整评估」和「改进」两步，评估需迭代到收敛；价值迭代将两步合并，每步直接用贝尔曼最优方程更新：V_&#123;k+1&#125;(s) = max_a sum_s' P(s'|s,a)[R + gamma*V_k(s')]，即每步评估时直接取 max（含改进），不分离评估和改进。②收敛特性——策略迭代的值函数中间值是某个策略的真实值函数（有意义）；价值迭代的中间值不一定对应任何策略的值函数（只是迭代过程的中间量）。③效率——策略迭代每轮开销大（评估需多次迭代）但总轮次少；价值迭代每轮开销小（一次备份）但总轮次多。④等价性——两者都收敛到 V* 和 pi*，只是路径不同。实践选择：状态空间小、模型简单时策略迭代更直接；状态空间大时价值迭代每轮便宜更实用。两种方法可以混合：广义策略迭代（GPI）——评估和改进任意交织，不必等任一步完全收敛，这是所有 RL 算法（包括 DQN、策略梯度）的通用框架。
</Answer>

### 问题 4

什么是广义策略迭代（GPI）？为什么它是理解所有强化学习算法的统一框架？

<Answer>

广义策略迭代（GPI, Generalized Policy Iteration）：不要求策略评估和策略改进任一步完全收敛，两者任意交织、互相驱动——只要评估和改进持续进行，最终都会收敛到最优策略和最优值函数。GPI 的核心洞察：①评估和改进是竞争与合作——评估让值函数逼近当前策略的真实值，改进让策略逼近当前值函数的贪心策略，两者互相推动。②不必精确——即使评估没完全收敛就改进，或改进不完全贪心，只要整体趋势正确，仍能收敛（策略改进定理保证单调递增性在近似下仍近似成立）。③统一框架——策略迭代和价值迭代是 GPI 的两个极端特例；MC/TD 控制用采样代替精确评估（近似评估）+ epsilon-贪心代替完全贪心（近似改进），也是 GPI；DQN 用神经网络近似 Q + 周期性更新目标网络（近似评估）+ argmax 选动作（改进），还是 GPI；策略梯度中 Actor（策略）和 Critic（值函数）交替更新，同样是 GPI。GPI 揭示了所有 RL 算法的共同结构：「评估值函数」和「改进策略」两个过程互相驱动——区别仅在于如何近似这两个过程。
</Answer>
