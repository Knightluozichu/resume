## 为什么从这个强化学习问题开始

本章把贝尔曼等式变成反复扫状态的程序，并把策略评估与策略改善分成两个可检查阶段。 “第4章 动态规划法”的贯穿任务是：为“第4章 动态规划法”冻结环境、状态/动作语义、奖励、终止规则、策略版本、训练预算和随机种子，再对照参考路径与单故障路径。 动手前先写下哪个状态、动作、奖励、收益/目标、价值、梯度、策略概率或评估哈希会先变化；运行后补理由不算预测。

围绕“怎样区分一次状态扫描、一次完整评估和一次策略改善，并用停止条件证明算法结束？”，“第4章 动态规划法”建立参考、故障与恢复路径。只有“第4章 动态规划法”守住“转移模型、扫描方式、旧新价值快照、贪心改善与收敛容差保持一致；第4章 动态规划法的结论不得越过原版目录、实验数据和评估边界”并交付第4章 动态规划法的环境快照、转移五元组、收益/目标手算、更新前后状态、随机性记录、失败复现与冻结评估报告，奖励曲线或成功轨迹才构成机制证据。
