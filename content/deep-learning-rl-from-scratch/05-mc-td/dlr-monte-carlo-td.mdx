## 从有模型到无模型

动态规划需要完整 MDP 模型（$P$ 和 $R$），但现实问题通常不知道。**蒙特卡洛（MC）和时序差分（TD）**通过与环境交互采样经验，无需模型即可估计值函数。

<DlrMonteCarloTdDiagram />

## 蒙特卡洛方法（MC）

用完整 episode 的**实际回报** $G_t$ 更新值函数：

```text
V(s) ← V(s) + alpha * [ G_t - V(s) ]
```

- $G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + ... + \gamma^{T-t-1} r_T$（完整折扣回报）
- **无偏**——用的是实际回报，期望正确
- **高方差**——整个 episode 的随机性累积
- **必须等 episode 结束**才能更新

## 时序差分学习（TD）

用**一步实际奖励 + 下一步的估计值**更新：

```text
V(s) ← V(s) + alpha * [ r + gamma * V(s') - V(s) ]
```

- TD 目标 = $r + \gamma V(s')$（用估计值 $V(s')$ 替代未知的 $G_t$）
- **有偏**——$V(s')$ 是估计值，含误差
- **低方差**——只有一步随机性
- **每步即可更新**（在线学习）

<Callout type="info">

**自举（Bootstrapping）**：TD 用当前 $V$ 的估计值 $V(s')$ 作为更新目标的一部分——「用估计更新估计」。这是 TD 方差小的原因（只一步随机性），也是偏差来源（$V(s')$ 可能不准）。

</Callout>

## TD 误差

```text
delta_t = r_{t+1} + gamma * V(s_{t+1}) - V(s_t)
```

TD 误差衡量「新估计与旧估计的差值」：

- $\delta > 0$：实际比预期好（V 被低估），应增大 $V(s)$
- $\delta < 0$：实际比预期差（V 被高估），应减小 $V(s)$

TD 误差是所有 TD 类算法（SARSA、Q学习、DQN）的核心学习信号。

## MC vs TD 对比

| 特性 | 蒙特卡洛 | 时序差分 |
|------|---------|---------|
| 更新目标 | 完整实际回报 $G_t$ | $r + \gamma V(s')$ |
| 偏差 | 无偏 | 有偏（自举） |
| 方差 | 高（完整 episode 累积） | 低（只一步） |
| 更新时机 | episode 结束后 | 每步（在线） |
| 连续任务 | 不适用 | 适用 |
| 马尔可夫性 | 不依赖（更鲁棒） | 依赖 $V(s')$ |

## n 步回报与 TD(lambda)

### n 步回报

```text
G_t^(n) = r_{t+1} + gamma*r_{t+2} + ... + gamma^(n-1)*r_{t+n} + gamma^n * V(s_{t+n})
```

前 n 步用实际奖励，第 n 步后用值函数估计。

- $n=1$ → TD(0)：$G_t^{(1)} = r + \gamma V(s')$
- $n \to \infty$ → MC：$G_t^{(\infty)} = G_t$（完整回报）

### TD(lambda)

用 $\lambda$ 加权混合所有 n 步回报：

- $\lambda = 0$ → TD(0)
- $\lambda = 1$ → MC

<Callout type="tip">

**偏差-方差权衡**：n 越大越接近 MC（无偏但高方差），n 越小越接近 TD（有偏但低方差）。TD(lambda) 是 MC 和 TD 的连续统一体。

</Callout>

## Python 示例：TD(0) 预测

```python
def td_zero_prediction(env, policy, alpha=0.1, gamma=0.9, episodes=1000):
    V = {}  # 状态值表
    for _ in range(episodes):
        state = env.reset()
        while True:
            action = policy(state)
            next_state, reward, done = env.step(action)
            # 初始化
            if state not in V:
                V[state] = 0.0
            if next_state not in V:
                V[next_state] = 0.0
            # TD 更新
            td_target = reward + gamma * V[next_state] * (1 - done)
            td_error = td_target - V[state]
            V[state] += alpha * td_error
            state = next_state
            if done:
                break
    return V
```

<Glossary>

<GlossaryItem term="蒙特卡洛方法（MC）">
无模型预测方法。用完整 episode 的实际回报 G_t 更新值函数：V(s) ← V(s) + alpha[G_t - V(s)]。无偏但高方差（完整 episode 随机性累积），必须等 episode 结束才能更新。不自举（不用 V(s') 估计），对非马尔可夫环境更鲁棒。在 episodic 任务、稀疏奖励、非马尔可夫场景中仍有价值。
</GlossaryItem>

<GlossaryItem term="时序差分学习（TD）">
无模型在线预测方法。用一步奖励加下一步估计值更新：V(s) ← V(s) + alpha[r + gamma*V(s') - V(s)]。有偏（自举引入偏差）但低方差（只一步随机性），每步可更新。TD 误差 delta = r + gamma*V(s') - V(s) 是学习信号。TD 是实践中最常用的预测方法，也是 Q学习和 SARSA 的基础。
</GlossaryItem>

<GlossaryItem term="TD 误差">
delta_t = r_&#123;t+1&#125; + gamma*V(s_&#123;t+1&#125;) - V(s_t)。衡量当前值函数与新观测的偏差，是 TD 学习的核心信号。delta > 0 表示 V 被低估（应增大），delta < 0 表示 V 被高估（应减小）。TD 误差传播值信息——当 V(s') 更新后，后续访问 s_t 时 delta_t 也变，信息逐步从终止状态向后传播。Q学习和 SARSA 的更新都基于 TD 误差。
</GlossaryItem>

<GlossaryItem term="自举（Bootstrapping）">
用当前的估计值更新估计值——TD 用 V(s') 作为更新目标的一部分，就是自举。与 MC 用实际回报（不自举）相对。自举的代价是引入偏差（V(s') 可能不准），收益是降低方差（只一步随机性）和加速信息传播（值信息逐步向后传）。DP 全自举（用模型精确计算），MC 不自举（用完整回报），TD 部分自举（一步实际+一步估计），DQN 自举（用目标网络的 Q 估计）。
</GlossaryItem>

<GlossaryItem term="n 步回报与 TD(lambda)">
n 步回报 G_t^(n) 用前 n 步实际奖励 + 第 n 步后的值函数估计。n=1 是 TD(0)，n→∞ 是 MC，中间 n 在偏差与方差间权衡。TD(lambda) 用 lambda 加权混合所有 n 步回报（lambda=0 是 TD(0)，lambda=1 是 MC），是 MC 和 TD 的连续统一体。后向视角用资格迹高效实现，每步增量更新。
</GlossaryItem>

<GlossaryItem term="资格迹（Eligibility Traces）">
TD(lambda) 后向视角的高效实现机制。记录近期访问过的状态-动作，用一个衰减的「迹」标记它们对当前 TD 误差的「资格」。当 TD 误差出现时，按资格分配给近期访问的状态——实现信用分配。迹的衰减率由 lambda 控制：lambda=0 只有当前状态获得更新（TD(0)），lambda=1 所有近期状态均等获得（MC 效果）。资格迹让长程信用传播在不存储完整 episode 的情况下高效实现。
</GlossaryItem>

</Glossary>

### 问题 1

蒙特卡洛（MC）方法和时序差分（TD）方法的核心区别是什么？

<Answer>

核心区别在于如何估计值函数：①蒙特卡洛（MC）——用完整 episode 的实际回报 G_t = r_&#123;t+1&#125; + gamma*r_&#123;t+2&#125; + ... + gamma^(T-t-1)*r_T 来更新值函数：V(s) ← V(s) + alpha[G_t - V(s)]。必须等 episode 结束才能更新，用的是无偏但方差大的完整回报。②时序差分（TD）——用一步实际奖励加下一步的估计值来更新：V(s) ← V(s) + alpha[r_&#123;t+1&#125; + gamma*V(s_&#123;t+1&#125;) - V(s)]。每步即可更新（在线学习），用 r + gamma*V(s') 作为 G_t 的近似（称为 TD 目标），有偏但方差小。关键差异总结：MC 用实际完整回报（无偏、高方差、需等结束），TD 用采样+自举（bootstrapping，有偏、低方差、在线更新）。TD 的自举——用当前 V 的估计值 V(s') 作为目标的一部分，形成「用估计更新估计」的递归结构。这是 TD 方差小的原因（只一步随机性），也是偏差来源（V(s') 可能不准）。
</Answer>

### 问题 2

什么是 TD 误差（TD Error）？它在 TD 学习中起什么作用？

<Answer>

TD 误差 delta_t = r_&#123;t+1&#125; + gamma * V(s_&#123;t+1&#125;) - V(s_t)。它衡量「新估计（r + gamma*V(s')）与旧估计 V(s) 的差值」，即当前值函数与新观测之间的偏差。TD 误差的作用：①学习信号——TD 更新公式 V(s) ← V(s) + alpha*delta_t，用 delta_t 作为梯度方向调整值函数。如果 delta_t > 0，说明实际比预期好（V 被低估），应增大 V(s)；如果 delta_t < 0，说明实际比预期差（V 被高估），应减小 V(s)。②无需等 episode 结束——delta_t 只需当前步的 r 和 s' 即可计算，使 TD 能在线学习。③自举结构——delta_t 中含 V(s_&#123;t+1&#125;)（旧估计），形成递归传播：当 V(s_&#123;t+1&#125;) 更新后，后续访问 s_t 时 delta_t 也会变化，值信息逐步从终止状态向后传播。④控制算法的基础——Q 学习和 SARSA 的更新都基于 TD 误差：delta = r + gamma*Q(s',a') - Q(s,a)（SARSA）或 delta = r + gamma*max_a' Q(s',a') - Q(s,a)（Q学习）。TD 误差是连接预测与控制的桥梁。
</Answer>

### 问题 3

什么是 n 步回报和 TD(lambda)？它们如何统一 MC 和 TD？

<Answer>

n 步回报 G_t^(n) = r_&#123;t+1&#125; + gamma*r_&#123;t+2&#125; + ... + gamma^(n-1)*r_&#123;t+n&#125; + gamma^n * V(s_&#123;t+n&#125;)——前 n 步用实际奖励，第 n 步之后用值函数估计。n 步 TD 更新：V(s_t) ← V(s_t) + alpha[G_t^(n) - V(s_t)]。统一关系：①n=1 → TD(0)：G_t^(1) = r_&#123;t+1&#125; + gamma*V(s_&#123;t+1&#125;)，就是标准 TD。②n → episode 长度 → MC：G_t^(inf) = G_t（完整实际回报），就是蒙特卡洛。③中间的 n 在偏差与方差之间权衡——n 越大越接近 MC（无偏但方差大），n 越小越接近 TD（有偏但方差小）。TD(lambda)：不选单一 n，而是用 lambda 加权混合所有 n 步回报（lambda 在 [0,1]）。lambda=0 等价 TD(0)，lambda=1 等价 MC。TD(lambda) 的前向视角用 lambda-回报 G_t^lambda = (1-lambda)*sum_&#123;n=1&#125;^T lambda^(n-1) * G_t^(n)；后向视角用资格迹（eligibility traces）高效实现，每步增量更新。TD(lambda) 是 MC 和 TD 的连续统一体，实践中 lambda=0 或接近 0 最常用（简单有效），但资格迹在需要快速信用传播的任务中有优势。
</Answer>

### 问题 4

为什么 TD 方法在实践中比 MC 更常用？MC 在什么情况下更有优势？

<Answer>

TD 比 MC 更常用的原因：①在线学习——TD 每步即可更新，无需等 episode 结束。在连续任务（无终止）或长 episode 中，MC 无法更新而 TD 可以。②低方差——TD 目标只含一步随机性（r 和 s'），MC 回报含整个 episode 的随机性累积，方差大导致学习慢。③自举加速——TD 用 V(s') 估计传播信息，即使 V(s') 尚未收敛也提供了有用的归纳偏置，通常收敛更快。④数据效率——TD 可在每步复用后续状态的信息，MC 每个 (s,a) 只用其对应的 G_t。MC 更有优势的情况：①Episode 必须完整才有意义——如棋类游戏的胜负只在结束时确定，中间奖励为零或误导性，TD 的自举可能传播错误值（V(s') 对胜负无预测力）。②不满足马尔可夫性质——MC 不自举（不依赖 V(s')），对非马尔可夫环境更鲁棒；TD 依赖 V(s') 的准确性，马尔可夫性被破坏时偏差更大。③离策略评估——某些 MC 变体（如重要性采样）在离策略设置下更灵活。实践中：TD（尤其 TD(0) 和 Q 学习）是主流，但 MC 在 episodic 任务、稀疏奖励、非马尔可夫场景中仍有价值。
</Answer>
