## 知识全景：从 MDP 到深度强化学习

<DlrFinalReviewDiagram />

本书十章构成了一个完整的知识闭环：从「如何形式化决策问题」到「如何评估策略」到「如何学习最优策略」到「如何用深度学习扩展」，底层统一为贝尔曼方程 + 梯度下降。

## 四个演进阶段

### 阶段一：建模（ch1-ch2）

**解决的核心问题**：如何将决策问题形式化为可计算的结构。

- ch1 RL基础：智能体-环境交互闭环，探索-利用困境，延迟奖励
- ch2 MDP：五元组 (S,A,P,R,gamma)，马尔可夫性质，折扣回报

**关键突破**：从模糊的「学习做决策」到精确的数学框架 (S,A,P,R,gamma)。

### 阶段二：预测（ch3-ch5）

**解决的核心问题**：如何评估一个策略的好坏。

- ch3 值函数：V(s) 和 Q(s,a)，贝尔曼方程的递归分解
- ch4 动态规划：有模型精确求解（策略评估+策略改进）
- ch5 MC/TD：无模型采样估计（完整回报 vs 一步自举）

**关键突破**：从「需要完整模型」到「只需采样经验」——DP→MC→TD 的演进。

### 阶段三：控制（ch6-ch7）

**解决的核心问题**：如何学习最优策略。

- ch6 Q学习/SARSA：无模型控制（离策略 vs 在策略）
- ch7 DQN：神经网络近似 Q，处理大状态空间

**关键突破**：从「表格存 Q」到「神经网络近似 Q」——打通深度学习与 RL。

### 阶段四：策略方法（ch8）

**解决的核心问题**：如何直接优化策略。

- ch8 策略梯度：直接学 pi_theta(a|s)，支持连续动作和随机策略
- Actor-Critic：策略+值函数结合，现代深度RL基石

**关键突破**：从「间接学 Q 再选动作」到「直接优化策略」。

## 三个关键跃迁

<Callout type="info">

**贯穿全书的三个跃迁**：

1. **有模型 → 无模型**：DP 需完整 MDP → MC/TD 只需采样，让 RL 能应用于真实世界
2. **表格 → 函数近似**：小状态表格存 Q → 大状态神经网络近似，打通深度学习
3. **值方法 → 策略方法**：间接学 Q 再选动作 → 直接优化策略，支持连续动作

</Callout>

## 统一框架：贝尔曼方程的近似求解

所有 RL 算法都在求解贝尔曼方程（或其变体），区别在于「如何近似」：

| 算法 | 模型 | 评估方式 | 控制方式 |
|------|------|---------|---------|
| DP | 有模型 | 精确贝尔曼备份 | 策略迭代/价值迭代 |
| MC | 无模型 | 完整 episode 回报 | 蒙特卡洛控制 |
| TD | 无模型 | 一步自举 | SARSA/Q学习 |
| DQN | 无模型 | 神经网络近似 Q | argmax（离策略） |
| 策略梯度 | 无模型 | Critic 值函数 | 直接梯度上升 |

### 底层统一

```text
所有算法 = 可微参数 + 梯度下降 + 贝尔曼递归
```

## 算法选择指南

| 场景 | 推荐算法 | 原因 |
|------|---------|------|
| 小状态、有模型 | DP | 精确求解 |
| 小状态、无模型、离散动作 | Q学习/SARSA | 表格法简单有效 |
| 大状态、离散动作 | DQN/Rainbow | 神经网络+经验回放 |
| 连续动作、精确控制 | SAC/TD3 | 策略梯度+值函数 |
| 通用首选 | PPO | 稳定易调 |

## 三大权衡

<Callout type="warning">

**RL 的三大本质权衡**：

1. **探索-利用**：尝试新动作 vs 利用已知最优——epsilon-贪心、softmax、UCB
2. **偏差-方差**：MC 无偏高方差 vs TD 有偏低方差——n 步回报、TD(lambda)
3. **有偏-无偏**：自举有偏但高效 vs 非自举无偏但低效——Actor-Critic 平衡

</Callout>

## 与现代深度 RL 的联系

| 本书算法 | 现代扩展 | 改进方向 |
|---------|---------|---------|
| Q学习 | Rainbow | 经验回放+目标网络+Dueling |
| DQN | DDPG/TD3 | 连续动作扩展 |
| 策略梯度 | PPO | 裁剪目标函数，稳定训练 |
| Actor-Critic | SAC | 最大熵正则化，鼓励探索 |
| Actor-Critic | RLHF | 大模型对齐，人类反馈强化学习 |

<Glossary>

<GlossaryItem term="强化学习知识闭环">
全书十章形成的完整知识体系：建模（MDP）→预测（值函数+贝尔曼方程）→控制（Q学习/SARSA）→深度（DQN）→策略（策略梯度）。所有算法统一为「贝尔曼方程的近似求解+梯度下降」，区别在于如何近似（精确/采样/神经网络）和优化什么（值函数/策略）。三个关键跃迁贯穿始终：有模型→无模型、表格→函数近似、值方法→策略方法。
</GlossaryItem>

<GlossaryItem term="三个关键跃迁">
贯穿全书的三个核心演进：①有模型→无模型——DP 需完整 MDP，MC/TD 只需采样，让 RL 可用于真实世界。②表格→函数近似——表格法不可扩展，DQN 用神经网络处理大状态空间，打通深度学习与 RL。③值方法→策略方法——值方法无法处理连续动作，策略梯度直接优化策略支持连续动作和随机策略。三个跃迁层层递进：第一个让 RL 可用，第二个让 RL 可扩展，第三个让 RL 可泛化。
</GlossaryItem>

<GlossaryItem term="贝尔曼方程统一框架">
所有 RL 算法都在近似求解贝尔曼方程的视角。DP 精确求解（有模型）、MC 用完整回报采样估计（无模型不自举）、TD 用一步自举采样估计（无模型自举）、DQN 用神经网络近似 Q（函数近似自举）、策略梯度绕过 Q 直接优化策略（但 Critic 仍用贝尔曼）。底层统一为「可微参数+梯度下降+贝尔曼递归」，区别仅在于如何近似和优化什么。
</GlossaryItem>

<GlossaryItem term="三大权衡">
RL 的三个本质困难：①探索-利用——尝试新动作 vs 利用已知最优，epsilon-贪心/softmax/UCB 是不同解法。②偏差-方差——MC 无偏高方差 vs TD 有偏低方差，n 步回报和 TD(lambda) 在两者间权衡。③有偏-无偏——自举有偏但高效 vs 非自举无偏但低效，Actor-Critic 平衡两者。没有免费午餐，每个算法都在这三轴上选择不同位置。理解这些权衡才能理解为什么有这么多算法、如何为具体任务选择。
</GlossaryItem>

<GlossaryItem term="GPI（广义策略迭代）">
所有 RL 算法的统一框架。不要求策略评估和改进完全收敛，两者任意交织、互相驱动。策略迭代和价值迭代是 GPI 的极端特例；MC/TD 控制用采样近似评估+epsilon-贪心近似改进，也是 GPI；DQN 用神经网络近似 Q+argmax，还是 GPI；Actor-Critic 中 Actor 和 Critic 交替更新，同样是 GPI。GPI 揭示了所有 RL 算法的共同结构：「评估值函数」和「改进策略」两个过程互相驱动。
</GlossaryItem>

<GlossaryItem term="现代深度RL">
本书基础算法的现代扩展。DQN→Rainbow（组合所有改进）→DDPG/TD3（连续动作）。策略梯度→PPO（裁剪目标函数）→SAC（最大熵正则化）。Actor-Critic 是这些算法的共同骨架。最新发展：RLHF（人类反馈强化学习）用策略梯度对齐大语言模型，是 RL 在 AI 最前沿的应用。本书的从零实现为理解这些现代算法提供了坚实基础。
</GlossaryItem>

</Glossary>

### 问题 1

全书从 MDP 到深度强化学习的知识脉络是怎样的？所有算法的统一框架是什么？

<Answer>

知识脉络：①建模（ch1-ch2）——RL 基础建立交互闭环心智，MDP 形式化为五元组 (S,A,P,R,gamma)，贝尔曼方程定义递归结构。②预测（ch3-ch5）——值函数 V/Q 定义「好坏」，DP 在有模型下精确求解贝尔曼方程，MC 用完整 episode 无模型估计，TD 用一步自举无模型在线估计（DP→MC→TD 是有模型→无模型、完整回报→一步估计的演进）。③控制（ch6-ch7）——Q 学习/SARSA 将预测扩展到最优策略（离策略 max vs 在策略实际），DQN 用神经网络近似 Q 处理大状态空间。④策略方法（ch8）——策略梯度直接优化 pi_theta，支持连续动作和随机策略。统一框架：所有算法都在近似求解贝尔曼方程——DP 精确求解（有模型），MC/TD 采样估计（无模型），DQN 神经网络近似（大状态），策略梯度绕过 Q 直接优化策略（但 Critic 仍用贝尔曼）。底层统一为「可微参数 + 梯度下降 + 贝尔曼递归」，区别仅在于「如何近似贝尔曼方程」和「优化值函数还是策略」。
</Answer>

### 问题 2

贯穿全书的三个关键跃迁是什么？它们各自解决了什么问题？

<Answer>

三个关键跃迁：①有模型 → 无模型——DP 需要完整 MDP（P 和 R 已知），但现实问题通常不知道环境模型。MC/TD 通过采样经验（与环境交互产生 (s,a,r,s') 数据）绕过模型未知，用统计估计替代精确计算。解决：让 RL 能应用于不知道环境动态的真实世界问题。②表格 → 函数近似——表格法为每个 (s,a) 存 Q 值，状态空间大时不可行（维度灾难）。DQN 用神经网络 Q_theta(s,a) 近似，参数量与状态数无关，且能泛化到未见状态。解决：让 RL 能处理高维连续状态空间（如像素、传感器数据），打通深度学习与 RL 的结合。③值方法 → 策略方法——值方法（Q学习/DQN）学 Q 再 argmax 选动作，无法处理连续动作（max 在连续空间无解析解）且只能产生确定性策略。策略梯度直接优化 pi_theta(a|s)，从概率分布采样，天然支持连续动作和随机策略。解决：让 RL 能处理连续控制（机器人关节角度）和多模态策略（多种最优选择）。三个跃迁层层递进：第一个让 RL 可用，第二个让 RL 可扩展，第三个让 RL 可泛化——最终形成现代深度强化学习的完整能力。
</Answer>

### 问题 3

Q 学习、SARSA、DQN、策略梯度之间的关系和区别是什么？如何选择？

<Answer>

关系与区别：①Q 学习——离策略，用 max Q(s',a') 更新，表格法，离散动作，需模型未知但状态空间小。②SARSA——在策略，用 Q(s',a') 更新（实际 a'），表格法，离散动作。与 Q 学习的区别：考虑探索代价，更安全。③DQN——Q 学习 + 神经网络 + 经验回放 + 目标网络，处理大状态空间，离散动作。是 Q 学习在深度学习时代的扩展。④策略梯度——直接优化 pi_theta(a|s)，支持连续动作和随机策略，不依赖 max。与值方法的区别：优化对象不同（策略 vs 值函数）。选择指南：①状态空间小、离散动作、有模型——DP 或表格 Q 学习。②状态空间大（如像素）、离散动作——DQN 及变体（Double/Dueling/Rainbow）。③连续动作、需精确控制——策略梯度类（DDPG/TD3/SAC），或 Actor-Critic。④需要随机策略（探索、多模态）——策略梯度或 SAC。⑤在线控制、探索有代价——SARSA 或在策略 Actor-Critic（A2C/PPO）。⑥样本效率优先、可用旧数据——离策略方法（Q学习/DQN/SAC，支持经验回放）。实践：PPO 是通用首选（稳定易调），SAC 是连续控制 SOTA，DQN/Rainbow 是离散动作 SOTA。现代 RL 趋势：Actor-Critic 统一值方法和策略方法，成为主流框架。
</Answer>

### 问题 4

强化学习中的「探索-利用」、「偏差-方差」、「有偏-无偏」三大权衡如何贯穿全书？

<Answer>

三大权衡贯穿全书：①探索-利用——RL 没有标签，必须通过尝试收集信息。epsilon-贪心（Q学习/SARSA）、softmax 采样、UCB、最大熵正则化（SAC）都是不同解决方案。贯穿：所有控制算法都需探索策略（不能纯贪心），否则陷入局部最优。②偏差-方差——MC 回报无偏但高方差（完整 episode 累积噪声），TD 目标有偏但低方差（自举引入偏差但只一步噪声）。n 步回报和 TD(lambda) 在两者间连续权衡。贯穿：DP（无偏无方差但需模型）、MC（无偏高方差）、TD（有偏低方差）、DQN（有偏低方差但函数近似引入额外偏差）、策略梯度（无偏高方差，需基线/Actor-Critic 降方差）。③有偏-无偏——与偏差-方差相关但不同。自举（TD/DQN）有偏：用估计更新估计，V(s') 的误差传播到 V(s)。MC/策略梯度无偏：用实际回报，期望正确。有偏方法通常方差低、样本效率高（TD/DQN），无偏方法方差大但理论干净（MC/REINFORCE）。Actor-Critic 的核心：Actor 用无偏的策略梯度方向（但 MC 高方差），Critic 提供有偏但低方差的优势估计（TD），两者结合达到最优权衡。这三大权衡是 RL 的本质困难——没有免费午餐，每个算法都在这三轴上选择不同位置。理解这些权衡才能理解为什么有这么多算法、如何为具体任务选择。
</Answer>
