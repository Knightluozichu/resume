## 从预测到控制

前面章节解决了「评估给定策略」的预测问题。**控制问题**更进一步——学习最优策略 $\pi^*$。Q学习和 SARSA 是最经典的无模型控制算法。

<DlrQLearningDiagram />

## Q 学习（离策略）

用**下一个状态的最优动作值**更新：

```text
Q(s,a) ← Q(s,a) + alpha * [ r + gamma * max_a' Q(s',a') - Q(s,a) ]
```

- TD 目标 = $r + \gamma \cdot \max_{a'} Q(s',a')$
- **离策略**——目标策略（贪心）与行为策略（如 epsilon-贪心）可不同
- 可从任意行为策略产生的经验中学习最优策略

## SARSA（在策略）

用**下一个状态的实际动作值**更新：

```text
Q(s,a) ← Q(s,a) + alpha * [ r + gamma * Q(s',a') - Q(s,a) ]
```

- TD 目标 = $r + \gamma \cdot Q(s',a')$（$a'$ 是行为策略实际选的动作）
- **在策略**——目标策略 = 行为策略
- 名字来源：$(s, a, r, s', a')$ 五元组

<Callout type="info">

**核心区别**：Q 学习用 $\max$（乐观，假设下一步选最优），SARSA 用实际 $a'$（保守，考虑探索代价）。在悬崖行走等有探索惩罚的环境中，SARSA 学到更安全的路径。

</Callout>

## epsilon-贪心探索

```text
以概率 epsilon：随机选动作（探索）
以概率 1-epsilon：选 argmax_a Q(s,a)（利用）
```

### epsilon 衰减

训练初期 epsilon 大（多探索），后期逐渐减小（多利用）：

```python
epsilon = max(epsilon_min, epsilon * decay_rate)
```

<Callout type="warning">

**不要衰减到 0**：若完全停止探索，可能因 Q 估计的初始偏差永远错过更优动作。通常保留一个小的 epsilon（如 0.01）。

</Callout>

## 最大化偏差

Q 学习的 $\max$ 操作会系统性高估 Q 值——噪声正向最大的那个被选中，导致过估。

### Double Q 学习

维护两个独立 Q 函数 $Q_1$ 和 $Q_2$：

```text
用 Q1 选动作：a* = argmax_a Q1(s',a)
用 Q2 估值：目标 = r + gamma * Q2(s',a*)
```

由于 $Q_1$ 和 $Q_2$ 独立，噪声不相关，消除最大化偏差。

## Python 实现

```python
import numpy as np

class QLearning:
    """Q 学习（离策略）"""
    def __init__(self, n_states, n_actions, alpha=0.1, gamma=0.9, epsilon=0.1):
        self.Q = np.zeros((n_states, n_actions))
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon

    def select_action(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.Q.shape[1])
        return np.argmax(self.Q[state])

    def update(self, s, a, r, s_next):
        td_target = r + self.gamma * np.max(self.Q[s_next])
        self.Q[s, a] += self.alpha * (td_target - self.Q[s, a])


class SARSA:
    """SARSA（在策略）"""
    def __init__(self, n_states, n_actions, alpha=0.1, gamma=0.9, epsilon=0.1):
        self.Q = np.zeros((n_states, n_actions))
        self.alpha = alpha
        self.gamma = gamma
        self.epsilon = epsilon

    def select_action(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.Q.shape[1])
        return np.argmax(self.Q[state])

    def update(self, s, a, r, s_next, a_next):
        td_target = r + self.gamma * self.Q[s_next, a_next]  # 用实际 a_next
        self.Q[s, a] += self.alpha * (td_target - self.Q[s, a])
```

## Q学习 vs SARSA 选择指南

| 场景 | 推荐 | 原因 |
|------|------|------|
| 离线学习、经验回放 | Q 学习 | 离策略，可复用旧数据 |
| 在线控制、探索有代价 | SARSA | 考虑探索代价，更安全 |
| 离散动作 | 两者均可 | 核心区别在更新目标 |
| 需要稳定性 | SARSA | 不过度乐观 |

<Glossary>

<GlossaryItem term="Q学习">
离策略无模型控制算法。更新公式 Q(s,a) ← Q(s,a) + alpha[r + gamma*max_a' Q(s',a') - Q(s,a)]，用下一个状态的最优动作值更新，与行为策略无关。可从任意行为策略产生的经验中学习最优策略，是 DQN 的基础。缺点是最大化偏差——max 操作导致 Q 值系统过估，需 Double Q 学习改进。
</GlossaryItem>

<GlossaryItem term="SARSA">
在策略无模型控制算法。更新公式 Q(s,a) ← Q(s,a) + alpha[r + gamma*Q(s',a') - Q(s,a)]，用实际动作 a' 的 Q 值更新。名字来源：五元组 (s, a, r, s', a')。与 Q 学习的区别：考虑探索代价，在悬崖行走等有探索惩罚的环境中更安全。行为策略必须等于目标策略。
</GlossaryItem>

<GlossaryItem term="离策略（Off-policy）">
目标策略（要学的策略）与行为策略（产生数据的策略）不同的学习模式。Q 学习是离策略——目标是最优贪心策略，行为是 epsilon-贪心。优势：可从任意行为策略（旧策略、人类示教、其他算法）的经验中学习最优策略，支持经验回放（DQN 的基础）。缺点：可能有过估问题。
</GlossaryItem>

<GlossaryItem term="在策略（On-policy）">
目标策略与行为策略相同的学习模式。SARSA 是在策略——行为策略是 epsilon-贪心，评估的也是这个 epsilon-贪心策略。优点：考虑了探索代价，学到的 Q 值反映「遵循当前策略（含探索）的期望回报」，更安全。缺点：不能复用旧策略的数据（数据必须由当前策略产生），样本效率低。
</GlossaryItem>

<GlossaryItem term="epsilon-贪心">
最简单且广泛使用的探索策略。以概率 epsilon 随机选动作（探索），1-epsilon 选 argmax Q（利用）。训练初期 epsilon 大（多探索），后期衰减（多利用）。不能衰减到0（需保留探索能力）。是 Q学习和 SARSA 的默认探索策略。
</GlossaryItem>

<GlossaryItem term="最大化偏差">
Q 学习 max 操作导致的 Q 值系统过估问题。Q 是估计值含噪声，取 max 时倾向选中「被高估最多」的动作（噪声正向最大的），使该 Q 被进一步高估。后果：次优动作被高估，策略可能长期次优。解决：Double Q 学习用两个独立 Q 函数——一个选动作、一个估值，消除相关性。Double DQN 是此思想在深度 RL 中的应用。
</GlossaryItem>

</Glossary>

### 问题 1

Q 学习的更新公式是什么？为什么它被称为「离策略」算法？

<Answer>

Q 学习更新公式：Q(s,a) ← Q(s,a) + alpha * [ r + gamma * max_a' Q(s',a') - Q(s,a) ]。TD 目标是 r + gamma * max_a' Q(s',a')——用下一个状态 s' 的最优动作值（max_a' Q(s',a')）来更新当前 Q(s,a)，无论智能体实际采取了什么动作。称为「离策略」（off-policy）的原因：①目标策略与行为策略不同——目标策略（要学的最优策略）是贪心的：pi*(s) = argmax_a Q(s,a)；行为策略（实际产生数据的策略）可以是任意策略（如 epsilon-贪心用于探索）。②Q 学习从行为策略产生的经验中学习目标策略——它用 max_a' Q(s',a')（目标策略的动作值）而非实际采取的 a' 的 Q 值。③优势——可以用任意行为策略（包括旧策略、人类示教、其他算法的策略）产生的数据学习最优策略，数据利用率高。这是 DQN 经验回放的基础——回放缓冲区里的旧经验可以用任意行为策略收集，但都用于更新同一个最优 Q 函数。对比：SARSA 是「在策略」，用实际 a' 的 Q 值更新，行为策略必须等于目标策略。
</Answer>

### 问题 2

Q 学习与 SARSA 的核心区别是什么？在什么场景下各有优势？

<Answer>

核心区别：①更新目标——Q 学习用 r + gamma*max_a' Q(s',a')（最优动作值），SARSA 用 r + gamma*Q(s',a')（实际动作值，a' 是行为策略实际选的动作）。②策略关系——Q 学习离策略（目标=贪心，行为=任意），SARSA 在策略（目标=行为=同一策略）。③对探索的态度——Q 学习假设下一步会选最优动作（max），忽略了探索可能带来的代价；SARSA 考虑了实际行为策略（含探索），学到的 Q 值反映「遵循当前策略（含探索）的期望回报」。场景优势：①Q 学习——离策略，可用经验回放复用旧数据，样本效率高，适合离线学习、大规模状态空间（DQN 的基础）。但在有「探索惩罚」的环境（如悬崖行走，探索可能掉下悬崖）中，Q 学习会过乐观（学到走边缘的最优路径，但行为时探索会掉下去）。②SARSA——在策略，考虑探索代价，学到更安全的路径（远离悬崖边缘）。适合需要在线控制、探索有代价、行为策略就是目标策略的场景。总结：Q 学习「学最优但可能乐观」，SARSA「学当前策略但更安全」。
</Answer>

### 问题 3

epsilon-贪心策略是什么？它如何平衡探索与利用？epsilon 应该如何设置？

<Answer>

epsilon-贪心策略：以概率 epsilon 随机选择动作（探索），以概率 1-epsilon 选择 argmax_a Q(s,a)（利用）。这是最简单且广泛使用的探索策略。平衡机制：①epsilon 控制探索强度——epsilon=0 完全利用（可能陷入局部最优），epsilon=1 完全随机（无法利用已学知识）。②典型值——epsilon 在 0.01 到 0.3 之间，保证大部分时间利用、偶尔探索。③epsilon 衰减——训练初期 epsilon 大（多探索收集信息），随着学习进行逐渐减小（多利用已学策略）。常见衰减：线性衰减到一个小值（如 0.01）或指数衰减。衰减的直觉：早期对 Q 估计信心不足需多探索，后期 Q 逐渐准确应多利用。注意事项：①不能衰减到 0——若完全停止探索，可能因 Q 估计的初始偏差永远错过更优动作。②非平稳环境——如果环境变化，需保持一定 epsilon 持续探索。③替代方案——softmax 采样（按 Q 的 softmax 概率选择，温度参数控制探索强度）、UCB（置信上界，按不确定性加权，自动平衡探索利用）。epsilon-贪心虽简单但在实践中效果很好，是 Q学习和 SARSA 的默认探索策略。
</Answer>

### 问题 4

Q 学习的「最大化偏差」是什么？SARSA 为什么通常没有这个问题？

<Answer>

最大化偏差（Maximization Bias）：Q 学习的更新目标含 max_a' Q(s',a')，而 max 操作会系统性地高估真实值。原因——Q 值是估计值（含噪声），取 max 时倾向于选中「被高估最多」的动作（噪声正向最大的那个），导致 Q 被持续过估。例如：某状态所有动作真实 Q 值相同，但估计有随机波动，max 会选中估计最高的（正向噪声），使该 Q 值被进一步高估。后果：次优动作被高估，策略可能长期次优。SARSA 通常无此问题：更新目标 r + gamma*Q(s',a') 用实际 a' 的 Q 值，不取 max，没有「选最高噪声」的偏差。虽然 SARSA 的 Q 也有噪声，但不被 max 放大。解决方案——Double Q 学习：维护两个独立的 Q 函数 Q1 和 Q2，用 Q1 选动作 argmax_a Q1(s',a)，用 Q2 估值 Q2(s',a*)。由于 Q1 和 Q2 独立，Q1 的噪声和 Q2 的噪声不相关，期望上消除了最大化偏差。实践影响：最大化偏差在确定性奖励环境中影响小（Q 估计噪声小），在随机奖励环境中影响大。Double DQN（DQN 的改进版）用目标网络选动作、主网络估值，正是 Double Q 思想在深度 RL 中的应用，显著提升了 Atari 等任务的稳定性。
</Answer>
