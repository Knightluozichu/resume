## 从表格到神经网络

当状态空间巨大（如 Atari 游戏的像素状态），表格法无法为每个状态存 Q 值。**深度Q网络（DQN）**用神经网络 $Q_\theta(s,a)$ 近似 Q 函数，打通深度学习与强化学习。

<DlrDeepQNetworkDiagram />

### DQN 与表格法 Q 学习的区别

| 特性 | 表格法 Q 学习 | DQN |
|------|-------------|-----|
| 参数化 | 直接存 Q(s,a) | 神经网络参数 theta |
| 泛化 | 无（未见状态 Q=0） | 有（相似状态相似输出） |
| 更新 | 只更新被访问的 (s,a) | 更新 theta 后所有 Q 都变 |
| 稳定性 | 天然稳定 | 需经验回放+目标网络 |

## Q 网络结构

```text
输入状态 s → 全连接层 + ReLU → 输出 Q(s, a_1)...Q(s, a_n) → argmax 选动作
```

网络输出所有动作的 Q 值，通过 argmax 选最优动作。

## 损失函数

```text
L = E [ ( r + gamma * max_a' Q_target(s', a') - Q(s,a) )^2 ]
```

TD 误差的均方——目标值用**目标网络**计算，避免「追着自己跑」。

## 三大关键技巧

### 1. 经验回放（Experience Replay）

- **存储**：将每步交互 $(s, a, r, s', done)$ 存入回放缓冲区 $D$
- **采样**：训练时从 $D$ 随机采样小批量
- **解决的问题**：打破样本相关性、提高数据利用率、降低梯度方差

### 2. 目标网络（Target Network）

- 维护两个 Q 网络：主网络 $Q_\theta$（每步更新）和目标网络 $Q_{\theta'}$（定期复制）
- TD 目标用目标网络：$y = r + \gamma \cdot \max_{a'} Q_{\theta'}(s', a')$
- **解决的问题**：稳定训练目标，切断反馈环

<Callout type="warning">

**为什么需要目标网络**：如果用同一个网络计算 TD 目标和当前 Q，每步 theta 更新后目标也变，相当于「追着自己跑」，导致训练发散或振荡。目标网络让目标在 C 步内固定。

</Callout>

### 3. 帧堆叠（Frame Stacking）

- 连续几帧作为状态，提供时序信息
- 弥补单帧无法表示速度的缺陷

## DQN 训练流程

```python
import numpy as np
import torch
import torch.nn as nn

class QNetwork(nn.Module):
    def __init__(self, state_dim, n_actions):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(state_dim, 128),
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, n_actions)
        )

    def forward(self, x):
        return self.net(x)

class DQN:
    def __init__(self, state_dim, n_actions, gamma=0.99, epsilon=0.1):
        self.main_net = QNetwork(state_dim, n_actions)
        self.target_net = QNetwork(state_dim, n_actions)
        self.target_net.load_state_dict(self.main_net.state_dict())
        self.optimizer = torch.optim.Adam(self.main_net.parameters(), lr=1e-3)
        self.replay_buffer = []
        self.gamma = gamma
        self.epsilon = epsilon
        self.n_actions = n_actions
        self.update_count = 0

    def select_action(self, state):
        if np.random.random() < self.epsilon:
            return np.random.randint(self.n_actions)
        with torch.no_grad():
            q_values = self.main_net(torch.FloatTensor(state))
        return q_values.argmax().item()

    def store(self, transition):
        self.replay_buffer.append(transition)

    def train_step(self, batch_size=32):
        if len(self.replay_buffer) < batch_size:
            return
        # 随机采样小批量
        batch = random.sample(self.replay_buffer, batch_size)
        states, actions, rewards, next_states, dones = zip(*batch)

        states = torch.FloatTensor(states)
        actions = torch.LongTensor(actions)
        rewards = torch.FloatTensor(rewards)
        next_states = torch.FloatTensor(next_states)
        dones = torch.FloatTensor(dones)

        # 当前 Q 值
        q_values = self.main_net(states).gather(1, actions.unsqueeze(1)).squeeze()

        # TD 目标（用目标网络）
        with torch.no_grad():
            next_q = self.target_net(next_states).max(dim=1)[0]
            td_target = rewards + self.gamma * next_q * (1 - dones)

        # MSE 损失
        loss = nn.functional.mse_loss(q_values, td_target)
        self.optimizer.zero_grad()
        loss.backward()
        self.optimizer.step()

        # 定期更新目标网络
        self.update_count += 1
        if self.update_count % 100 == 0:
            self.target_net.load_state_dict(self.main_net.state_dict())
```

## DQN 的挑战与改进

| 挑战 | 改进方案 |
|------|---------|
| 过估偏差 | Double DQN（主网络选动作，目标网络估值） |
| Q 值分解效率低 | Dueling DQN（V + 优势函数 A） |
| 采样效率低 | 优先经验回放（PER，按 TD 误差加权） |
| 探索不足 | Noisy DQN（参数化探索） |
| 组合所有改进 | Rainbow |

<Callout type="tip">

**DQN 的历史意义**：2015 年 DeepMind 的 DQN 是首个在 Atari 游戏上从原始像素达到人类水平的深度 RL 算法，奠定了「神经网络+贝尔曼方程」的深度 RL 范式。

</Callout>

<Glossary>

<GlossaryItem term="深度Q网络（DQN）">
用神经网络近似 Q 函数的深度 RL 算法。三大关键技巧：经验回放（随机采样打破相关性）、目标网络（稳定训练目标）、帧堆叠（提供时序信息）。首个在 Atari 游戏上从原始像素达到人类水平的深度 RL 算法，奠定了「神经网络+贝尔曼方程」的深度 RL 范式。损失函数是 TD 误差的均方，目标值用目标网络计算。
</GlossaryItem>

<GlossaryItem term="经验回放">
DQN 的关键技巧之一。将每步交互 (s,a,r,s',done) 存入回放缓冲区，训练时随机采样小批量。解决三个问题：①打破样本相关性（连续交互高度相关，随机采样近似独立同分布）。②提高数据效率（旧经验多次复用）。③降低梯度方差。配合 Q 学习的离策略特性，回放缓冲区可包含不同时期行为策略的经验。
</GlossaryItem>

<GlossaryItem term="目标网络">
DQN 的关键技巧之一。维护独立的目标 Q 网络 Q_theta'，定期从主网络复制参数。TD 目标用目标网络计算 y = r + gamma*max Q_theta'(s',a')，而当前 Q 用主网络 Q_theta(s,a)。解决「追着自己跑」的不稳定——如果用同一网络计算目标和当前值，每步更新后目标也变，导致发散。目标网络让目标在 C 步内固定，形成稳定回归目标。
</GlossaryItem>

<GlossaryItem term="函数近似">
用参数化函数（如神经网络）近似值函数的技术。表格法为每个 (s,a) 存 Q 值，状态空间大时不可行（维度灾难）。函数近似用参数 theta 的 Q_theta(s,a) 近似，参数量与状态数无关，且能泛化到未见状态。代价：非稳目标（theta 变化导致目标变化）、收敛性不保证（需经验回放和目标网络稳定训练）。DQN 是函数近似的代表。
</GlossaryItem>

<GlossaryItem term="Double DQN">
DQN 的改进版本，消除最大化偏差。用主网络选动作 a* = argmax_a Q_main(s',a)，用目标网络估值 Q_target(s',a*)。由于主网络和目标网络参数独立，噪声不相关，期望上消除了 max 操作导致的过估。显著提升 Atari 等随机奖励任务的稳定性。是 Double Q 学习思想在深度 RL 中的应用。
</GlossaryItem>

<GlossaryItem term="Dueling DQN">
DQN 的改进版本，将 Q(s,a) 分解为 V(s) + A(s,a)（状态值+优势函数）。V 评估状态本身的价值（与动作无关），A 评估各动作相对于最优的优劣。网络输出两个分支：V(s) 和 A(s,a)，合成 Q(s,a) = V(s) + A(s,a) - mean_a A(s,a)。优势：V 和 A 分别学习，对动作差异不大的状态更高效，加速学习。
</GlossaryItem>

</Glossary>

### 问题 1

DQN 为什么要用神经网络近似 Q 函数？它与表格法 Q 学习的区别是什么？

<Answer>

DQN 用神经网络近似 Q 函数的原因：①状态空间太大——表格法需要为每个 (s,a) 存一个 Q 值，当状态空间巨大或连续时（如 Atari 像素状态 84x84x4 帧堆叠，约 10^6 维），表格不可行。②泛化能力——神经网络可以从相似状态泛化到未见过的状态。表格法对未见过的状态 Q 值初始化为0，无法迁移；神经网络通过特征学习，相似输入产生相似输出。③端到端学习——无需手工设计状态特征，直接从原始观测（像素）学习。与表格法 Q 学习的区别：①参数化——表格法直接存 Q(s,a)（参数量=|S|*|A|），DQN 用参数 theta 的神经网络 Q_theta(s,a)（参数量=网络权重数，与 |S| 无关）。②更新方式——表格法只更新被访问的 (s,a)，DQN 更新 theta 后所有 (s,a) 的 Q 都变（泛化）。③非稳目标——表格法的 TD 目标 r+gamma*max Q(s',a') 在 (s',a') 确定后是稳定的；DQN 中 Q 由 theta 计算，theta 每步变化，目标随之变化（追着移动的目标），训练不稳定。④需要技巧——DQN 必须用经验回放和目标网络才能稳定训练，表格法不需要。DQN 是首个在 Atari 游戏上从原始像素达到人类水平的深度 RL 算法。
</Answer>

### 问题 2

DQN 的经验回放（Experience Replay）机制是什么？它解决了什么问题？

<Answer>

经验回放机制：①存储——将每步交互 (s, a, r, s', done) 存入回放缓冲区 D（大小固定，如 10^6）。②采样——训练时从 D 中随机采样小批量（mini-batch，如 32 条），用这些样本计算梯度更新 Q 网络。解决的问题：①打破样本相关性——连续交互产生的 (s,a,r,s') 序列高度相关（相邻步骤状态相似），直接用序列训练神经网络会导致过拟合到局部时序模式。随机采样打乱了时间顺序，使小批量样本近似独立同分布，满足 SGD 的假设。②提高数据效率——表格法每条经验只用一次，经验回放允许多次复用（每条经验可能被采样多次），尤其在高样本效率需求时重要。③平滑训练——随机小批量降低梯度方差，使训练更稳定。④离策略学习——回放缓冲区包含不同时期行为策略产生的经验（旧策略的旧经验），Q 学习是离策略的，可以从任意行为策略的经验中学习，使复用合法。注意事项：①缓冲区大小——太小则旧经验快速丢失，太大则旧经验可能过时（策略已变）。②优先经验回放（PER）——按 TD 误差大小加权采样，TD 误差大的样本学习价值更高，进一步提升效率。
</Answer>

### 问题 3

DQN 的目标网络（Target Network）是什么？为什么需要它？

<Answer>

目标网络机制：维护两个 Q 网络——①主网络 Q_theta——每步用梯度下降更新。②目标网络 Q_theta'——定期从主网络复制参数（如每 C 步硬复制 theta'=theta），期间保持不变。计算 TD 目标时用目标网络：y = r + gamma * max_a' Q_theta'(s',a')，而计算当前 Q 用主网络 Q_theta(s,a)。损失函数 L = E[(y - Q_theta(s,a))^2]，梯度只对 theta 求。需要目标网络的原因：①稳定训练目标——如果用同一个网络计算 y 和 Q(s,a)，每步 theta 更新后 y 也变，相当于「追着自己跑」，目标非平稳导致训练发散或振荡。目标网络让 y 在 C 步内固定，形成稳定的回归目标。②打破相关性——Q_theta(s,a) 和 Q_theta(s',a') 共享参数，梯度更新会同时影响两者，形成反馈环。目标网络用独立参数计算目标，切断了这个环。③代价——目标网络延迟了信息传播（theta' 滞后 theta），但稳定性收益远大于延迟代价。实践细节：硬复制（每 C 步完全复制）最常见；软更新 theta' ← tau*theta + (1-tau)*theta'（tau 小，如 0.001）更平滑。Double DQN 进一步改进：用主网络选动作 argmax_a' Q_theta(s',a')，用目标网络估值 Q_theta'(s',a*)，消除最大化偏差。
</Answer>

### 问题 4

DQN 在实践中面临哪些主要挑战？后续有哪些重要改进？

<Answer>

DQN 的主要挑战：①过估偏差——max 操作导致 Q 值系统过估（见 Q学习的最大化偏差），在神经网络中更严重（泛化放大偏差）。②训练不稳定——尽管有经验回放和目标网络，DQN 仍可能在某些任务上振荡或发散，原因包括：高方差梯度、值函数过估、策略崩溃。③探索不足——epsilon-贪心在高维连续状态空间中探索效率低，难以发现稀疏奖励。③超参数敏感——学习率、网络结构、回放大小、目标网络更新频率等需精细调参。④只能处理离散动作——输出层为每个动作一个 Q 值，无法直接处理连续动作空间。⑤样本效率低——通常需要数百万步交互才能学好，样本成本高。重要改进：①Double DQN——用主网络选动作、目标网络估值，消除最大化偏差。②Dueling DQN——将 Q(s,a) 分解为 V(s) + A(s,a)（优势函数），分别建模状态价值和动作优势，提升学习效率。③Prioritized Experience Replay——按 TD 误差优先采样重要经验。③Noisy DQN——网络参数加可学习噪声，实现参数化探索替代 epsilon-贪心。④Rainbow——组合上述所有改进，大幅提升性能。⑤连续动作扩展——DDPG、SAC 等演员-评论家算法处理连续动作。这些改进使深度 RL 在更复杂任务上更稳定高效，但 DQN 作为奠基算法，其「经验回放+目标网络+神经网络函数近似」的范式仍贯穿所有后续工作。
</Answer>
