## 概率论：不确定性建模的语言

机器学习本质上是在不确定性中做决策——数据有噪声、模型不完美、未来不可预知。花书第三章用概率论来描述这种不确定性，用信息论来度量它。

## 概率的基本概念

**随机变量** $x$ 是一个可能取多个值的变量。**概率分布**描述随机变量取各值的可能性。

- **离散型**：概率质量函数 $P(x)$，满足 $\sum_x P(x) = 1$
- **连续型**：概率密度函数 $p(x)$，满足 $\int p(x) dx = 1$

### 概率公理（柯尔莫哥洛夫公理）

1. **非负性**：$P(x) \geq 0$
2. **归一化**：$\sum_x P(x) = 1$（离散）或 $\int p(x) dx = 1$（连续）
3. **可加性**：互斥事件 $P(A \cup B) = P(A) + P(B)$

### 条件概率与链式法则

条件概率 $P(y|x) = \frac{P(x,y)}{P(x)}$，表示已知 $x$ 发生时 $y$ 的概率。联合概率可分解为：

$$P(x_1, x_2, \ldots, x_n) = P(x_1) \prod_{i=2}^{n} P(x_i | x_1, \ldots, x_{i-1})$$

## 贝叶斯定理

**贝叶斯定理**是机器学习的核心公式，它描述了如何从先验知识和观测数据更新信念：

$$P(y|x) = \frac{P(x|y) P(y)}{P(x)}$$

| 术语 | 含义 | 机器学习对应 |
|------|------|------------|
| $P(y)$ | 先验概率 | 模型参数的先验分布 |
| $P(x\|y)$ | 似然 | 数据在给定参数下的概率 |
| $P(y\|x)$ | 后验概率 | 观测数据后的参数分布 |
| $P(x)$ | 证据 | 归一化常数（边际似然） |

<Callout type="info">

**贝叶斯视角**：最大似然估计（MLE）= 忽略先验，找使似然 $P(x|\theta)$ 最大的参数。最大后验估计（MAP）= 加入先验，找使 $P(\theta|x) \propto P(x|\theta)P(\theta)$ 最大的参数。L2 正则化等价于高斯先验的 MAP，L1 正则化等价于拉普拉斯先验的 MAP。

</Callout>

## 常见概率分布

| 分布 | 概率密度 | 参数 | 用途 |
|------|---------|------|------|
| 伯努利 | $P(x) = p^x(1-p)^{1-x}$ | $p \in (0,1)$ | 二分类 |
| 分类 | $P(x=i) = p_i$ | $\sum p_i = 1$ | 多分类 |
| 正态（高斯） | $\mathcal{N}(\mu,\sigma^2)$ | $\mu, \sigma^2$ | 连续建模 |
| 指数 | $p(x) = \lambda e^{-\lambda x}$ | $\lambda > 0$ | 等待时间 |
| Laplace | $\propto e^{-|x-\mu|/b}$ | $\mu, b$ | L1 正则化 |

### 多元正态分布

$$\mathcal{N}(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{(2\pi)^{n/2}|\boldsymbol{\Sigma}|^{1/2}} \exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top \boldsymbol{\Sigma}^{-1} (\mathbf{x}-\boldsymbol{\mu})\right)$$

其中 $\boldsymbol{\mu}$ 是均值向量，$\boldsymbol{\Sigma}$ 是协方差矩阵。当协方差矩阵是对角矩阵时，各维度独立；当是各向同性（$\boldsymbol{\Sigma} = \sigma^2 \mathbf{I}$）时，各维度独立且方差相同。

## 信息论：度量不确定性

信息论用**信息量**衡量「看到某个事件有多惊讶」。越不可能的事件，包含的信息量越大。

### 自信息与熵

**自信息**：$I(x) = -\log P(x)$。**香农熵**是自信息的期望，衡量分布的不确定程度：

$$H(P) = -\sum_x P(x) \log P(x)$$

熵越大，分布越均匀（越不确定）；熵越小，分布越集中（越确定）。

### 交叉熵与 KL 散度

**交叉熵**衡量用分布 $Q$ 编码来自分布 $P$ 的数据所需的平均信息量：

$$H(P, Q) = -\sum_x P(x) \log Q(x)$$

**KL 散度**衡量两个分布的差异：

$$D_{KL}(P \| Q) = \sum_x P(x) \log \frac{P(x)}{Q(x)} = H(P, Q) - H(P)$$

<Callout type="tip">

**关键关系**：交叉熵 = 熵 + KL 散度。即 $H(P,Q) = H(P) + D_{KL}(P\|Q)$。当 $P$ 固定时（如真实标签），最小化交叉熵等价于最小化 KL 散度。这就是为什么分类问题用交叉熵损失——它等价于让模型分布 $Q$ 逼近真实分布 $P$。

</Callout>

### KL 散度的性质

- 非负：$D_{KL}(P\|Q) \geq 0$，当且仅当 $P = Q$ 时为零
- 非对称：$D_{KL}(P\|Q) \neq D_{KL}(Q\|P)$
- $D_{KL}(P\|Q)$ 中 $P$ 的支撑集必须包含在 $Q$ 中（否则为无穷）

## 概率视角下的机器学习

<Callout type="warning">

**统一视角**：最大似然估计（MLE）是最小化经验分布 $\hat{P}_{data}$ 与模型分布 $P_{model}$ 之间的 KL 散度：

$$\min_\theta D_{KL}(\hat{P}_{data} \| P_{model}) = \min_\theta -\mathbb{E}_{\hat{P}_{data}}[\log P_{model}(x; \theta)]$$

这就是负对数似然损失。交叉熵损失、负对数似然、KL 散度最小化在数学上是等价的。

</Callout>

<Glossary>

<GlossaryItem term="贝叶斯定理（Bayes' Theorem）">
概率论的核心公式：P(y|x) = P(x|y)P(y) / P(x)。它描述了如何从先验概率 P(y) 和似然 P(x|y) 计算后验概率 P(y|x)。在机器学习中，贝叶斯定理将「学习」定义为「用数据更新对模型参数的信念」。最大似然估计（MLE）忽略先验只最大化似然 P(x|theta)；最大后验估计（MAP）在似然基础上乘以先验 P(theta)。L2 正则化等价于高斯先验的 MAP 估计，L1 正则化等价于拉普拉斯先验的 MAP 估计。贝叶斯推断的完整版本计算整个后验分布而非点估计。
</GlossaryItem>

<GlossaryItem term="KL 散度（Kullback-Leibler Divergence）">
衡量两个概率分布差异的非对称度量。D_KL(P||Q) = sum P(x) log(P(x)/Q(x)) = E_P[log P(x)] - E_P[log Q(x)]。性质：非负（>=0，当且仅当 P=Q 时为 0）、非对称（D_KL(P||Q) != D_KL(Q||P)）。KL 散度 = 交叉熵 - 熵。当真实分布 P 固定时，最小化交叉熵等价于最小化 KL 散度。在 VAE 中 KL 项迫使后验接近先验，在知识蒸馏中用 KL 散度让学生模型模仿教师输出。注意 KL 散度不是真正的距离度量（不满足对称性和三角不等式）。
</GlossaryItem>

<GlossaryItem term="香农熵（Shannon Entropy）">
衡量概率分布不确定性的度量。H(P) = -sum P(x) log P(x)（离散）或 H(p) = -integral p(x) log p(x) dx（连续）。均匀分布熵最大（最不确定），确定性分布熵为零。熵在信息论中表示编码分布所需的最短平均比特数。在机器学习中，熵用于决策树分裂准则（信息增益）、强化学习的探索（熵正则化鼓励探索）和决策的不确定性度量。交叉熵损失 = H(P) + D_KL(P||Q)，当 P 固定时（如 one-hot 标签）H(P) 是常数，故最小化交叉熵 = 最小化 KL 散度。
</GlossaryItem>

<GlossaryItem term="最大似然估计（MLE）">
统计学最常用的参数估计方法。给定数据集 X，MLE 找到使似然 P(X|theta) 最大的参数 theta。等价于最小化负对数似然 NLL = -log P(X|theta)。在独立同分布假设下，对数似然 = sum log P(x_i|theta)。MLE 的概率解释：最小化经验分布与模型分布之间的 KL 散度。交叉熵损失、负对数似然损失和 KL 散度最小化在数学上等价。MLE 的缺点：没有先验信息时可能过拟合（高方差），MAP 估计通过引入先验缓解此问题。
</GlossaryItem>

<GlossaryItem term="协方差矩阵（Covariance Matrix）">
描述多元随机变量各维度之间线性关系的方阵。Cov(X)_ij = E[(X_i - mu_i)(X_j - mu_j)]。对角元素是各维度方差，非对角元素是维度间协方差。协方差矩阵是半正定对称矩阵，可做特征分解得到主成分方向（PCA）。在深度学习中，BatchNorm 用批协方差矩阵的对角元素（方差）做归一化；多元高斯分布以协方差矩阵为参数；协方差矩阵的迹等于总方差。
</GlossaryItem>

<GlossaryItem term="交叉熵（Cross-Entropy）">
用分布 Q 编码来自分布 P 的数据所需的平均信息量。H(P,Q) = -sum P(x) log Q(x) = H(P) + D_KL(P||Q)。在分类问题中，P 是 one-hot 标签分布，Q 是模型 softmax 输出。最小化交叉熵 = 最小化 KL 散度 = 让模型分布逼近真实分布。交叉熵损失 = -sum y_i log(p_i)，当 y 是 one-hot 时简化为 -log(p_correct)。相比均方误差，交叉熵在分类问题中梯度更合理（不会因 sigmoid 饱和而梯度消失），是深度学习分类任务的标准损失函数。
</GlossaryItem>

</Glossary>

### 问题 1

贝叶斯定理的各部分在机器学习中分别对应什么？MLE 和 MAP 的关系是什么？

<Answer>

贝叶斯定理 P(theta|x) = P(x|theta)P(theta) / P(x) 中：P(theta) 是先验（对参数的初始信念），P(x|theta) 是似然（数据在参数下的概率），P(theta|x) 是后验（观测数据后对参数的信念），P(x) 是证据（归一化常数）。MLE（最大似然估计）忽略先验，找使似然 P(x|theta) 最大的参数——等价于均匀先验的贝叶斯估计。MAP（最大后验估计）加入先验，找使后验 P(theta|x) 正比于 P(x|theta)P(theta) 最大的参数。关系：MAP = MLE + 先验。当先验为均匀分布时 MAP 退化为 MLE。L2 正则化等价于高斯先验的 MAP（lambda 对应先验方差的倒数），L1 正则化等价于拉普拉斯先验的 MAP。MLE 无先验可能过拟合，MAP 通过先验约束缓解过拟合。
</Answer>

### 问题 2

信息熵、交叉熵和 KL 散度之间的关系是什么？为什么分类问题用交叉熵损失？

<Answer>

关系：交叉熵 = 熵 + KL 散度，即 H(P,Q) = H(P) + D_KL(P||Q)。①信息熵 H(P) = -sum P(x) log P(x) 衡量分布 P 本身的不确定性。②交叉熵 H(P,Q) = -sum P(x) log Q(x) 衡量用 Q 编码来自 P 的数据所需的平均信息量。③KL 散度 D_KL(P||Q) = H(P,Q) - H(P) 衡量 Q 偏离 P 的额外信息量。分类问题用交叉熵的原因：在分类中 P 是 one-hot 标签分布（确定性分布，H(P) = 0），所以交叉熵 H(P,Q) = D_KL(P||Q) = -log Q(correct)。最小化交叉熵 = 最小化 KL 散度 = 让模型分布 Q 逼近真实分布 P。相比均方误差，交叉熵的梯度 log(p_i) - y_i 不受 sigmoid 饱和影响（均方误差梯度含 sigmoid 导数会消失），训练更高效。
</Answer>

### 问题 3

KL 散度有哪些性质？它为什么不是真正的距离度量？

<Answer>

KL 散度 D_KL(P||Q) = sum P(x) log(P(x)/Q(x)) 的性质：①非负性——D_KL(P||Q) >= 0，当且仅当 P=Q 时为 0（由 Gibbs 不等式保证）。②非对称性——D_KL(P||Q) != D_KL(Q||P)，方向不同结果不同。③不满足三角不等式——D_KL(P||R) 不一定 <= D_KL(P||Q) + D_KL(Q||R)。④支撑集要求——前向 KL D_KL(P||Q) 要求 Q 在 P 非零处非零（否则为无穷），反向 KL D_KL(Q||P) 要求 P 在 Q 非零处非零。KL 散度不是真正距离度量的原因：距离度量必须满足对称性和三角不等式，KL 散度都不满足。前向 KL（P||Q）是「zero-avoiding」（Q 试图覆盖 P 的所有支撑），反向 KL（Q||P）是「zero-forcing」（Q 试图集中在 P 的支撑内）。VAE 中最小化的是反向 KL，GAN 隐式最小化的是前向 KL，这是两者生成特性不同的原因之一。
</Answer>

### 问题 4

如何用概率视角统一理解最大似然估计、交叉熵损失和 KL 散度？

<Answer>

三者是等价的：最大似然估计 = 最小化负对数似然 = 最小化经验分布与模型分布的 KL 散度 = 最小化交叉熵。推导过程：①MLE 目标是最大化 sum log P_model(x_i; theta)，等价于最小化 -sum log P_model(x_i; theta) = N * E_hat[-log P_model(x; theta)]，其中 E_hat 是经验分布。②交叉熵 H(P_hat, P_model) = -sum P_hat(x) log P_model(x) = E_hat[-log P_model(x)]，与负对数似然一致。③KL 散度 D_KL(P_hat || P_model) = H(P_hat, P_model) - H(P_hat) = 交叉熵 - 经验熵。当数据集固定时 H(P_hat) 是常数，故最小化交叉熵 = 最小化 KL 散度。统一视角的意义：分类问题的交叉熵损失、回归问题的均方误差（高斯似然的负对数）、VAE 的 ELBO 本质上都是最大似然——让模型分布逼近数据分布。正则化（L1/L2）对应 MAP 估计——在最大似然基础上加入先验。
</Answer>
