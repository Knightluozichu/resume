## 深度网络：可微的函数逼近器

前馈神经网络（feedforward neural network）是深度学习最基础的模型。它将输入通过多层非线性变换映射到输出，整个过程是一个可微分函数，可以用梯度下降端到端优化。

## 前馈网络结构

**前馈网络**由输入层、若干隐藏层和输出层组成。信息从输入单向流向前方（无反馈循环），每层对上一层的输出做线性变换加非线性激活：

```text
输入 x → [W1·x+b1] → [激活σ] → [W2·+b2] → [激活σ] → ... → 输出 y
         线性变换    非线性      线性变换     非线性
```

第 $l$ 层的计算：

$$\mathbf{h}^{(l)} = \sigma(\mathbf{W}^{(l)} \mathbf{h}^{(l-1)} + \mathbf{b}^{(l)})$$

其中 $\mathbf{W}^{(l)}$ 是权重矩阵，$\mathbf{b}^{(l)}$ 是偏置向量，$\sigma$ 是激活函数。

<Callout type="info">

**为什么需要激活函数**：如果没有非线性激活函数，多层线性变换的复合仍然是线性变换——$\mathbf{W}_2(\mathbf{W}_1 \mathbf{x}) = (\mathbf{W}_2\mathbf{W}_1)\mathbf{x}$，多层网络等价于单层线性模型，无法逼近非线性函数。激活函数引入非线性，使网络能表示复杂的非线性映射。

</Callout>

## 激活函数

| 激活函数 | 公式 | 特点 |
|---------|------|------|
| Sigmoid | $\sigma(x) = \frac{1}{1+e^{-x}}$ | 输出 (0,1)，饱和区梯度消失 |
| Tanh | $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$ | 输出 (-1,1)，零中心化 |
| ReLU | $\max(0, x)$ | 计算简单，缓解梯度消失 |
| Leaky ReLU | $\max(0.01x, x)$ | 解决 ReLU 的神经元死亡 |
| ELU | $x$ if $x>0$; $\alpha(e^x-1)$ if $x \leq 0$ | 负区平滑，零中心化 |

<Callout type="warning">

**梯度消失问题**：Sigmoid 和 Tanh 在饱和区导数接近零，反向传播时梯度连乘导致深层梯度指数衰减。ReLU 的导数在正区恒为 1，有效缓解梯度消失，是深度网络默认激活函数。但 ReLU 在负区导数为零，可能导致「神经元死亡」（永远不被激活）。

</Callout>

## 反向传播算法

**反向传播**（backpropagation）用链式法则高效计算损失对每个参数的梯度。

### 前向传播

从输入层到输出层逐层计算，保存中间值：

```text
z^(l) = W^(l) · h^(l-1) + b^(l)    # 线性变换
h^(l) = σ(z^(l))                    # 非线性激活
L = Loss(h^(L), y)                   # 计算损失
```

### 反向传播

从输出层到输入层逐层计算梯度，复用前向传播的中间值：

```text
δ^(L) = ∇_h L · σ'(z^(L))           # 输出层误差
δ^(l) = (W^(l+1))^T · δ^(l+1) · σ'(z^(l))  # 逐层回传
∇_W L = δ^(l) · (h^(l-1))^T         # 权重梯度
∇_b L = δ^(l)                       # 偏置梯度
```

<Callout type="tip">

**反向传播的本质**：反向传播是链式法则在计算图上的高效实现。前向传播构建计算图并保存中间结果，反向传播从输出向输入沿计算图反向传播梯度。计算复杂度与前向传播同阶（约 2 倍前向计算量），是深度学习可扩展的关键。现代深度学习框架（PyTorch、TensorFlow）的自动微分就是自动构建计算图并执行反向传播。

</Callout>

## 万能逼近定理

**万能逼近定理**（Universal Approximation Theorem）指出：一个具有至少一个隐藏层、使用非多项式激活函数的前馈网络，只要隐藏层足够宽，就能以任意精度逼近任意连续函数。

$$\forall f \in C([0,1]^n), \forall \epsilon > 0, \exists \text{ 网络 } g: \sup_x |f(x) - g(x)| < \epsilon$$

<Callout type="warning">

**定理的局限**：万能逼近定理保证表达能力（存在性），但不保证：①可学习性——网络可能需要指数级数据才能训练；②效率——浅层网络可能需要指数级宽度，而深层网络用线性宽度就能达到同样效果；③优化——梯度下降可能找不到最优解。实践中深度比宽度更有效——深度网络用更少参数就能逼近复杂函数。

</Callout>

## 输出层设计

| 任务类型 | 输出层激活 | 损失函数 |
|---------|-----------|---------|
| 二分类 | Sigmoid | 二元交叉熵 |
| 多分类 | Softmax | 交叉熵 |
| 回归 | 线性（无激活） | 均方误差 |
| 多标签 | Sigmoid（每维独立） | 二元交叉熵 |

Softmax 将任意实数向量归一化为概率分布：

$$\text{softmax}(\mathbf{z})_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

## 代价函数的梯度

对于 softmax + 交叉熵的组合，梯度有非常简洁的形式：

$$\frac{\partial \mathcal{L}}{\partial \mathbf{z}^{(L)}} = \hat{\mathbf{y}} - \mathbf{y}$$

即预测概率减去真实标签。这是为什么分类问题推荐用 softmax + 交叉熵而非 MSE——梯度简洁且不会因 sigmoid 饱和而消失。

<Glossary>

<GlossaryItem term="前馈神经网络（Feedforward Neural Network）">
最基础的深度学习模型。信息从输入层单向流经隐藏层到输出层，无反馈循环。每层对上层输出做线性变换（W·h + b）加非线性激活（sigma）。多个线性+非线性层的复合构成复杂非线性函数。也叫多层感知机（MLP），虽然严格说感知机指使用阶跃激活函数的模型。前馈网络是卷积网络、循环网络等更复杂架构的基础。万能逼近定理保证其理论表达能力，反向传播使其可高效训练。
</GlossaryItem>

<GlossaryItem term="反向传播（Backpropagation）">
用链式法则高效计算深度网络梯度的算法。前向传播从输入到输出逐层计算并保存中间值，反向传播从输出到输入逐层计算偏导数，复用前向传播的中间结果避免重复计算。对于 N 个参数的网络，反向传播的计算复杂度为 O(N)，与前向传播同阶。反向传播本质是计算图上的自动微分（reverse-mode autodiff），等价于动态规划。现代框架（PyTorch、TensorFlow）自动构建计算图并执行反向传播，开发者只需定义前向传播。
</GlossaryItem>

<GlossaryItem term="激活函数（Activation Function）">
引入非线性的函数。没有激活函数，多层线性变换的复合仍是线性的，网络等价于单层线性模型。常见激活函数：Sigmoid（输出 0-1，但饱和区梯度消失）、Tanh（输出 -1 到 1，零中心化但仍有梯度消失）、ReLU（max(0,x)，正区梯度恒为 1，缓解梯度消失，但负区可能导致神经元死亡）、Leaky ReLU（负区给小斜率避免死亡）、ELU（负区平滑）。ReLU 是现代深度网络的默认选择，因为计算简单且有效缓解梯度消失问题。
</GlossaryItem>

<GlossaryItem term="万能逼近定理（Universal Approximation Theorem）">
前馈网络的理论基础。定理指出：具有至少一个隐藏层、非多项式激活函数的前馈网络，只要足够宽，就能以任意精度逼近任意连续函数。这保证了深度网络的表达能力上限。但定理有三个局限：①不保证可训练——可能需要指数级数据；②不保证效率——浅层网络可能需要指数级宽度，深层网络用线性宽度即可；③不保证优化能找到最优解。实践中深度网络比浅层网络更有效，用更少参数就能逼近复杂函数——这是「深度」优于「宽度」的经验证据。
</GlossaryItem>

<GlossaryItem term="梯度消失/爆炸（Vanishing/Exploding Gradients）">
深度网络训练中的梯度问题。反向传播通过链式法则将各层梯度相乘。当每层梯度小于 1 时，深层梯度指数衰减（梯度消失），浅层参数几乎不更新；当每层梯度大于 1 时，深层梯度指数增长（梯度爆炸），训练发散。Sigmoid/Tanh 在饱和区导数接近零导致梯度消失。解决方案：ReLU 激活（正区梯度为 1）、残差连接（Skip Connection 提供梯度直接通路）、BatchNorm/LayerNorm（归一化激活值稳定梯度）、梯度裁剪（限制梯度范数防爆炸）、LSTM/GRU 门控（缓解 RNN 的梯度消失）。
</GlossaryItem>

<GlossaryItem term="计算图（Computational Graph）">
将数学运算表示为有向无环图（DAG）的数据结构。节点表示运算（加、乘、激活），边表示数据流动。前向传播沿图正向计算输出，反向传播沿图反向传播梯度。自动微分（autodiff）框架自动构建计算图并执行反向传播。reverse-mode autodiff（反向模式自动微分）= 反向传播，只需一次前向+一次反向就能计算所有参数的梯度，复杂度与前向同阶。PyTorch 用动态计算图（每次前向传播重建），TensorFlow 1.x 用静态计算图（先定义后执行），TF2 默认动态图。
</GlossaryItem>

</Glossary>

### 问题 1

前馈神经网络的基本结构是什么？为什么需要激活函数？

<Answer>

前馈神经网络由输入层、若干隐藏层和输出层组成。每层对上一层的输出做线性变换（W·h + b）后加非线性激活 sigma，信息从输入单向流向前方。第 l 层计算 h^(l) = sigma(W^(l) · h^(l-1) + b^(l))。需要激活函数的原因：如果没有非线性激活，多层线性变换的复合仍然是线性变换——W2(W1·x) = (W2·W1)·x，多层网络等价于单层线性模型，无法逼近非线性函数。激活函数引入非线性，使网络能表示复杂的非线性映射。常见激活函数：Sigmoid（输出 0-1，但饱和区梯度消失）、Tanh（输出 -1 到 1，零中心化）、ReLU（max(0,x)，正区梯度恒为 1，缓解梯度消失，是默认选择）。ReLU 的问题是负区导数为零可能导致「神经元死亡」，Leaky ReLU 在负区给小斜率解决此问题。
</Answer>

### 问题 2

反向传播算法的原理是什么？它的计算复杂度如何？

<Answer>

反向传播用链式法则高效计算损失函数对网络中每个参数的梯度。过程分两步：①前向传播——从输入层到输出层逐层计算 z^(l) = W^(l)·h^(l-1) + b^(l) 和 h^(l) = sigma(z^(l))，保存中间值 z 和 h。计算损失 L = Loss(h^(L), y)。②反向传播——从输出层到输入层逐层计算误差信号 delta 和梯度：delta^(L) = grad_h L · sigma'(z^(L))，delta^(l) = (W^(l+1))^T · delta^(l+1) · sigma'(z^(l))，权重梯度 grad_W L = delta^(l) · (h^(l-1))^T，偏置梯度 grad_b L = delta^(l)。计算复杂度与前向传播同阶（约 2 倍前向计算量），因为反向传播复用前向传播保存的中间值，避免重复计算。对于 N 个参数的网络，反向传播复杂度为 O(N)，是深度学习可扩展到亿级参数的关键。本质是计算图上的 reverse-mode 自动微分。
</Answer>

### 问题 3

万能逼近定理的内容是什么？它有什么局限性？

<Answer>

万能逼近定理指出：一个具有至少一个隐藏层、使用非多项式激活函数的前馈网络，只要隐藏层足够宽，就能以任意精度逼近任意连续函数。即对于任意连续函数 f 和任意精度 epsilon > 0，存在一个网络 g 使得 sup|f(x) - g(x)| < epsilon。定理的局限性：①不保证可学习性——定理只说「存在」这样的网络，但不保证梯度下降能找到它。可能需要指数级数据量才能训练出这样的网络。②不保证效率——浅层网络（单隐藏层）可能需要指数级宽度才能逼近复杂函数，而深层网络用线性宽度就能达到同样效果。这解释了为什么「深度」比「宽度」更有效。③不保证优化——损失函数是非凸的，梯度下降可能陷入局部最小值或鞍点。④实际泛化——定理只保证训练集上的逼近能力，不保证测试集上的泛化。实践中深度网络比浅层网络更有效，用更少的参数就能逼近复杂函数。
</Answer>

### 问题 4

梯度消失和梯度爆炸的原因是什么？有哪些解决方案？

<Answer>

原因：反向传播通过链式法则将各层梯度相乘。delta^(l) = (W^(l+1))^T · delta^(l+1) · sigma'(z^(l))。当各层 |W · sigma'| < 1 时，深层梯度指数衰减（梯度消失），浅层参数几乎不更新；当 |W · sigma'| > 1 时，深层梯度指数增长（梯度爆炸），训练发散。Sigmoid/Tanh 在饱和区导数接近零（Sigmoid 最大导数 0.25），是梯度消失的主要原因。解决方案：①激活函数——用 ReLU（正区梯度恒为 1）替代 Sigmoid/Tanh，有效缓解梯度消失。②残差连接（Skip Connection）——h^(l+1) = F(h^(l)) + h^(l)，梯度可以直接通过加法通路回传，不受乘法链影响。这是 ResNet 能训练上百层的关键。③归一化——BatchNorm/LayerNorm 归一化激活值的范围，使梯度更稳定。④梯度裁剪——当梯度范数超过阈值时缩放，防止梯度爆炸（RNN 中常用）。⑤门控机制——LSTM/GRU 的门控结构提供梯度直接通路，缓解 RNN 的梯度消失。⑥权重初始化——Xavier/He 初始化使各层激活值方差一致，避免梯度逐层放大或缩小。
</Answer>
