## 正则化：在偏差与方差之间取得平衡

正则化是深度学习控制泛化的核心手段。花书第七章系统介绍了从参数惩罚到结构约束的各种正则化策略，它们共同的目标是：在训练误差和泛化间隙之间取得更好的平衡。

## 参数范数惩罚

最经典的正则化方法是在损失函数中加入参数范数惩罚，约束权重大小：

$$\mathcal{L}_{reg}(\boldsymbol{\theta}) = \mathcal{L}(\boldsymbol{\theta}) + \alpha \Omega(\boldsymbol{\theta})$$

### L2 正则化（权重衰减）

$$\Omega(\boldsymbol{\theta}) = \frac{1}{2} \|\mathbf{w}\|_2^2 = \frac{1}{2} \sum_i w_i^2$$

L2 正则化让权重更新变为：

$$\mathbf{w} \leftarrow \mathbf{w} - \eta (\nabla_{\mathbf{w}} \mathcal{L} + \alpha \mathbf{w}) = (1 - \eta \alpha) \mathbf{w} - \eta \nabla_{\mathbf{w}} \mathcal{L}$$

即每步先将权重缩小 $(1 - \eta\alpha)$ 倍，再沿梯度方向更新——这就是「权重衰减」名称的由来。

<Callout type="info">

**L2 的几何直觉**：L2 约束区域是球体，优化时等高线与球面相切，倾向于让所有权重都变小但不为零。L2 等价于高斯先验 $\mathbf{w} \sim \mathcal{N}(0, \sigma^2)$ 的 MAP 估计。

</Callout>

### L1 正则化

$$\Omega(\boldsymbol{\theta}) = \|\mathbf{w}\|_1 = \sum_i |w_i|$$

L1 正则化的梯度为 $\alpha \cdot \text{sign}(\mathbf{w})$，每次更新将权重向零推进固定步长 $\eta\alpha$，当权重接近零时会被直接置零——这就是 L1 产生稀疏解的原因。

<Callout type="tip">

**L1 vs L2**：L1 约束区域是菱形（有尖角在坐标轴上），等高线最先与尖角相切，使某些维度恰好为零。L2 约束区域是球体（无尖角），权重小但不为零。L1 适用于特征选择，L2 适用于一般正则化。

</Callout>

## 早停

**早停**（Early Stopping）在验证误差上升时停止训练，是一种通过限制有效训练时长来控制容量的正则化方法。

```text
误差
 ↑  训练误差（持续下降）
 │ ╲
 │  ╲         验证误差
 │   ╲       ╱  ╲
 │    ╲     ╱    ╲ → 过拟合区
 │     ╲   ╱
 │      ╲ ╱
 │       ↑ 最佳停止点
 └────────────────→ 训练轮数
```

<Callout type="warning">

**早停与 L2 的等价性**：花书证明了早停在数学上等价于 L2 正则化——训练轮数 $t$ 对应 L2 系数 $\alpha$，训练越久正则化越弱。早停的优点是无需调正则化系数（自动确定），且训练一次就能得到不同正则化强度的模型。

</Callout>

## Dropout

**Dropout** 在训练时随机将一部分神经元的输出置零（以概率 $p$ 丢弃），测试时使用全部神经元但输出乘以 $(1-p)$。

```text
训练时:        测试时:
[1] [0] [1]    [0.5] [0.5] [0.5]   (p=0.5)
 ↓   ↓   ↓      ↓     ↓     ↓
[1] [0] [1]    [0.5] [0.5] [0.5]
```

### Dropout 的正则化机制

1. **近似集成**：每个 mini-batch 训练一个不同的子网络，测试时近似平均所有子网络
2. **减少共适应**：神经元不能依赖特定其他神经元的存在，被迫学习更鲁棒的特征
3. **噪声注入**：随机置零等效于向激活值注入噪声，增强鲁棒性

### 反向 Dropout 实现

```python
# 训练时：随机丢弃 + 缩放（inverted dropout）
mask = (torch.rand(h.shape) > p).float() / (1 - p)  # 缩放补偿
h = h * mask

# 测试时：无需任何操作（已通过训练时缩放补偿）
```

## 数据增强

**数据增强**通过对训练数据施加变换来扩充数据集，等效增加数据量：

| 数据类型 | 增强方式 |
|---------|---------|
| 图像 | 翻转、旋转、裁剪、颜色抖动、Cutout |
| 文本 | 同义词替换、回译、随机删除 |
| 音频 | 加噪、变速、频移 |
| 通用 | Mixup（线性插值两张样本）、CutMix |

<Callout type="info">

**数据增强的本质**：数据增强隐式地告诉模型「这些变换不改变标签」，是一种注入先验知识的正则化。例如对图像分类做水平翻转增强，等于告诉模型「左翻和右翻的猫都是猫」。

</Callout>

## 批归一化（BatchNorm）

**批归一化**（Batch Normalization）对每个 mini-batch 的激活值做归一化，使其均值为零、方差为一，然后通过可学习的缩放和平移参数恢复表示能力：

$$\hat{\mathbf{h}} = \frac{\mathbf{h} - \boldsymbol{\mu}_B}{\sqrt{\boldsymbol{\sigma}_B^2 + \epsilon}}, \quad \mathbf{y} = \boldsymbol{\gamma} \hat{\mathbf{h}} + \boldsymbol{\beta}$$

BatchNorm 的多重作用：

- **稳定训练**：归一化使各层激活值分布稳定，允许更大学习率
- **缓解梯度问题**：激活值不在饱和区，梯度更稳定
- **正则化效果**：mini-batch 的均值/方差引入噪声，有轻微正则化作用
- **降低对初始化的敏感性**：归一化后初始权重的尺度影响减小

## 其他正则化技术

| 技术 | 机制 | 适用场景 |
|------|------|---------|
| 权重绑定 | 共享参数减少自由度 | CNN、RNN |
| 稀疏激活 | 惩罚激活值的 L1 范数 | 特征选择 |
| 标签平滑 | 将 one-hot 标签替换为软标签 | 分类防过自信 |
| 噪声注入 | 向输入或激活值加噪声 | 鲁棒性 |
| 混合训练 | 多任务联合训练 | 迁移学习 |
| 对抗训练 | 加入对抗样本 | 防对抗攻击 |

<Glossary>

<GlossaryItem term="L2 正则化（权重衰减）">
在损失函数中加 alpha * ||w||^2_2 = alpha * sum(w_i^2) 的正则化方法。每步更新将权重先缩小 (1-eta*alpha) 倍再沿梯度更新，故称权重衰减。几何上约束区域是球体，优化时等高线与球面相切，让所有权重都变小但不为零。贝叶斯解释：等价于高斯先验 w ~ N(0, sigma^2) 的 MAP 估计，alpha 对应先验强度的倒数。L2 是深度学习最常用的正则化，通过 weight_decay 参数在优化器中直接设置。效果：防止权重过大导致过拟合，提高泛化。
</GlossaryItem>

<GlossaryItem term="L1 正则化">
在损失函数中加 alpha * ||w||_1 = alpha * sum(|w_i|) 的正则化方法。梯度为 alpha * sign(w)，每次将权重向零推进固定步长，接近零时直接置零，产生稀疏权重。几何上约束区域是菱形（有尖角在坐标轴上），等高线最先与尖角相切使某些维度为零。贝叶斯解释：等价于拉普拉斯先验的 MAP 估计。L1 适用于特征选择（自动去除无用特征），但不如 L2 通用。L1 在零点不可微，需要次梯度或 proximal gradient 方法处理。
</GlossaryItem>

<GlossaryItem term="Dropout">
训练时随机将一部分神经元（以概率 p 丢弃）输出置零的正则化技术。机制：①近似集成——每个 mini-batch 训练不同子网络，测试时近似平均所有子网络。②减少共适应——神经元不能依赖特定其他神经元，被迫学习更鲁棒特征。③噪声注入——随机置零等效注入噪声。反向 Dropout（inverted dropout）在训练时做缩放补偿（除以 1-p），测试时无需操作。Dropout 广泛用于全连接层（p=0.5 常见），也用于卷积层（p 较小）和注意力机制。Dropout 是深度学习最有效的正则化之一，与 L2、数据增强互补。
</GlossaryItem>

<GlossaryItem term="早停（Early Stopping）">
在验证误差上升时停止训练的正则化方法。训练初期模型学到通用模式（泛化好），后期开始记忆训练集细节（过拟合），在转折点停止可获最佳泛化。花书证明早停在数学上等价于 L2 正则化：训练轮数 t 对应 L2 系数 alpha，训练越久正则化越弱。优点：无需调正则化系数（自动确定），训练一次就能得到不同正则化强度的模型（检查点）。早停是最简单实用的正则化，几乎所有深度学习训练都使用。
</GlossaryItem>

<GlossaryItem term="批归一化（Batch Normalization）">
对每个 mini-batch 的激活值做归一化（减均值除标准差），再用可学习的 gamma 和 beta 做缩放平移。作用：①稳定训练——激活值分布稳定，允许更大学习率。②缓解梯度问题——激活值不在饱和区。③正则化效果——mini-batch 的均值/方差引入噪声。④降低初始化敏感性。BatchNorm 要求 batch size 不能太小（否则均值方差估计不准），不适用于在线学习（batch size = 1）。LayerNorm 是 BatchNorm 的变体，对单个样本的各维度归一化，适用于 RNN/Transformer。
</GlossaryItem>

<GlossaryItem term="数据增强（Data Augmentation）">
通过对训练数据施加变换来扩充数据集的正则化技术。图像增强包括翻转、旋转、裁剪、颜色抖动、Cutout、Mixup、CutMix 等。文本增强包括同义词替换、回译、随机删除。数据增强隐式告诉模型「这些变换不改变标签」，是一种注入先验知识的正则化。效果：增加有效数据量，减少过拟合，提高对输入扰动的鲁棒性。数据增强是图像分类、目标检测等视觉任务的标准组件，在现代深度学习中被广泛使用且效果显著。
</GlossaryItem>

</Glossary>

### 问题 1

L1 和 L2 正则化的数学形式和几何直觉是什么？为什么 L1 产生稀疏解？

<Answer>

数学形式：L2 在损失函数中加 alpha * ||w||^2_2 = alpha * sum(w_i^2)，梯度为 alpha * w，更新时 w <- (1-eta*alpha)*w - eta*grad，即每步先缩小再更新（权重衰减）。L1 加 alpha * ||w||_1 = alpha * sum(|w_i|)，梯度为 alpha * sign(w)，每次将权重向零推进固定步长 eta*alpha。几何直觉：L2 约束区域是球体（圆滑），等高线与球面相切，所有权重都变小但不为零。L1 约束区域是菱形（有尖角在坐标轴上），等高线最先与尖角相切，使某些维度恰好为零。L1 产生稀疏的原因：①几何上——菱形顶点在坐标轴上，相切点大概率在顶点，某些维度为零。②梯度上——L1 梯度恒为 ±alpha（与 w 大小无关），当 w 接近零时会被直接推到零；L2 梯度为 alpha*w，w 接近零时梯度也接近零，不会被推到零。L1 适用于特征选择，L2 适用于一般正则化。
</Answer>

### 问题 2

Dropout 的正则化机制是什么？反向 Dropout 如何实现？

<Answer>

Dropout 的正则化机制：①近似集成——每个 mini-batch 随机丢弃不同神经元，等效训练大量不同子网络，测试时近似平均所有子网络的预测（类似 Bagging）。②减少共适应——神经元不能依赖特定其他神经元的存在（因为它们可能被丢弃），被迫学习更鲁棒、更独立的特征。③噪声注入——随机置零等效向激活值注入乘性噪声，增强模型对扰动的鲁棒性。反向 Dropout（inverted dropout）实现：训练时生成随机掩码 mask = (rand > p) / (1-p)，将激活值 h = h * mask（除以 1-p 做缩放补偿，使期望值不变）。测试时无需任何操作——因为训练时已做缩放补偿，测试时直接用全部神经元输出即可。反向 Dropout 的优点是测试时无额外计算，且不依赖 p 的具体值。Dropout 广泛用于全连接层（p=0.5 常见），与 L2、数据增强互补。
</Answer>

### 问题 3

早停为什么是一种正则化？它与 L2 正则化有什么关系？

<Answer>

早停是正则化的原因：训练初期模型学到通用模式（泛化好），后期开始记忆训练集细节（过拟合），在验证误差上升时停止可获最佳泛化。通过限制有效训练时长来控制模型的有效容量——训练轮数越少，有效容量越小（类似更简单的模型）。与 L2 正则化的关系：花书证明早停在数学上等价于 L2 正则化。具体来说，在线性模型中，训练 t 步的早停等价于 L2 系数 alpha = 1/(eta*t) 的权重衰减——训练越久 alpha 越小（正则化越弱），训练越少 alpha 越大（正则化越强）。这解释了为什么早停和 L2 有相似的正则化效果。早停的优点：①无需调正则化系数（通过验证集自动确定停止时机）。②训练一次就能得到不同正则化强度的模型（通过保存不同轮数的检查点）。③计算高效（不需要额外计算正则化项的梯度）。早停是最简单实用的正则化方法，几乎所有深度学习训练都使用。
</Answer>

### 问题 4

批归一化（BatchNorm）的作用是什么？它为什么有正则化效果？

<Answer>

BatchNorm 对每个 mini-batch 的激活值做归一化（减均值除标准差），再用可学习的 gamma 和 beta 做缩放平移：h_hat = (h - mu_B) / sqrt(sigma_B^2 + epsilon)，y = gamma * h_hat + beta。作用：①稳定训练——归一化使各层激活值分布稳定（均值零、方差一），减少内部协变量偏移（internal covariate shift），允许更大学习率加速训练。②缓解梯度问题——激活值不在激活函数的饱和区，梯度更稳定，缓解梯度消失/爆炸。③降低初始化敏感性——归一化后初始权重的尺度影响减小，训练更鲁棒。④正则化效果——mini-batch 的均值 mu_B 和方差 sigma_B^2 是对真实统计量的噪声估计，这种噪声等效于向激活值注入随机扰动，有轻微正则化作用（类似 Dropout）。BatchNorm 的限制：要求 batch size 不能太小（否则均值方差估计不准），不适用于在线学习（batch size=1）。LayerNorm 是其变体，对单个样本的各维度归一化，适用于 RNN/Transformer。
</Answer>
