## 专用架构：为数据结构量身定制

全连接网络用相同参数处理所有位置，忽略了数据的空间/时序结构。花书第九章介绍卷积网络（CNN）处理网格数据（图像）、循环网络（RNN）处理序列数据，它们通过引入「先验结构」实现参数高效和性能提升。

## 卷积神经网络（CNN）

### 卷积层的三个核心思想

<Callout type="info">

**CNN 的归纳偏置**：CNN 假设数据具有「平移不变性」（特征可出现在任意位置）和「局部性」（局部像素相关性最强）。这两个先验通过参数共享和局部连接实现，使 CNN 用远少于全连接网络的参数达到更好的效果。

</Callout>

| 思想 | 全连接 | 卷积 |
|------|--------|------|
| 局部连接 | 每个输出与全部输入相连 | 每个输出只与局部输入相连 |
| 参数共享 | 每个连接有独立权重 | 同一卷积核在所有位置共享 |
| 等变表示 | 无 | 平移等变（输入平移→输出平移） |

### 卷积运算

卷积核（filter）在输入上滑动，逐位置做 element-wise 乘加：

```text
输入 (H×W×C_in)         卷积核 (k×k×C_in×C_out)        输出 (H'×W'×C_out)
┌─────────────┐         ┌───┐
│ □ □ □ □ □ □ │         │ □ │  滑动        ┌───────┐
│ □ □ □ □ □ □ │  ×      │ □ │  ────→       │ □ □ □ │
│ □ □ □ □ □ □ │         │ □ │              │ □ □ □ │
│ □ □ □ □ □ □ │         └───┘              │ □ □ □ │
└─────────────┘                           └───────┘
```

输出尺寸：$H' = \lfloor (H + 2p - k) / s \rfloor + 1$，其中 $p$ 是 padding，$s$ 是 stride。

### 池化层

**池化**（Pooling）对局部区域做下采样，减少参数量和计算量：

| 池化类型 | 操作 | 特点 |
|---------|------|------|
| 最大池化 | 取局部最大值 | 保留最显著特征 |
| 平均池化 | 取局部平均值 | 平滑特征 |
| 全局池化 | 对整个特征图操作 | 替代全连接层 |

<Callout type="tip">

**感受野**（Receptive Field）：输出上一个像素对应输入上的区域大小。层数越深、卷积核越大、stride 越大，感受野越大。深层 CNN 的感受野可覆盖整张图像——浅层捕获局部纹理，深层捕获全局语义。

</Callout>

### 经典 CNN 架构演进

| 架构 | 年份 | 关键创新 |
|------|------|---------|
| LeNet | 1998 | 首个成功 CNN，卷积+池化+全连接 |
| AlexNet | 2012 | ReLU + Dropout + GPU 训练 |
| VGG | 2014 | 小卷积核（3x3）堆叠深层 |
| GoogLeNet | 2014 | Inception 模块（多尺度并行） |
| ResNet | 2015 | 残差连接，训练 152 层 |
| DenseNet | 2017 | 密集连接，特征复用 |

## 循环神经网络（RNN）

### RNN 的核心思想

**RNN** 处理序列数据 $\mathbf{x}^{(1)}, \mathbf{x}^{(2)}, \ldots, \mathbf{x}^{(T)}$，通过隐藏状态 $\mathbf{h}^{(t)}$ 传递历史信息：

$$\mathbf{h}^{(t)} = \tanh(\mathbf{W}_{hh} \mathbf{h}^{(t-1)} + \mathbf{W}_{xh} \mathbf{x}^{(t)} + \mathbf{b})$$

```text
h0 → h1 → h2 → h3 → ... → hT
     ↑     ↑     ↑              ↑
     x1    x2    x3             xT
```

<Callout type="info">

**参数共享**：RNN 在所有时间步共享相同的权重 $\mathbf{W}_{hh}, \mathbf{W}_{xh}$，使模型能处理任意长度的序列。这与 CNN 在所有空间位置共享权重类似——先验假设「序列中的模式可出现在任意时刻」。

</Callout>

### RNN 的梯度问题

通过时间反向传播（BPTT）时，梯度需要连乘 $\mathbf{W}_{hh}^{(T)}$：

- 当 $\mathbf{W}_{hh}$ 的特征值小于 1 时，梯度指数衰减 → **梯度消失**（长程依赖丢失）
- 当 $\mathbf{W}_{hh}$ 的特征值大于 1 时，梯度指数增长 → **梯度爆炸**

### LSTM（长短期记忆网络）

**LSTM** 通过门控机制解决 RNN 的梯度消失问题，维护一个细胞状态 $\mathbf{c}^{(t)}$：

```text
遗忘门: f = σ(W_f · [h_prev, x])    # 决定丢弃多少旧信息
输入门: i = σ(W_i · [h_prev, x])    # 决定写入多少新信息
候选值: g = tanh(W_g · [h_prev, x])  # 生成候选新信息
细胞态: c = f * c_prev + i * g       # 更新细胞状态（加法通路！）
输出门: o = σ(W_o · [h_prev, x])    # 决定输出多少
隐藏态: h = o * tanh(c)              # 输出
```

<Callout type="warning">

**LSTM 的关键创新**：细胞状态的更新用加法（`c = f * c_prev + i * g`）而非乘法，梯度可以通过加法通路直接回传，不受连乘衰减影响。遗忘门控制何时「记住」或「遗忘」，使 LSTM 能建模长程依赖。

</Callout>

### GRU（门控循环单元）

**GRU** 是 LSTM 的简化版，合并了细胞状态和隐藏状态，将三个门简化为两个：

```text
重置门: r = σ(W_r · [h_prev, x])
更新门: z = σ(W_z · [h_prev, x])
候选态: h_tilde = tanh(W · [r * h_prev, x])
隐藏态: h = (1-z) * h_prev + z * h_tilde
```

GRU 参数更少、计算更快，在很多任务上与 LSTM 效果相当。

### 双向 RNN 与深度 RNN

| 变体 | 结构 | 用途 |
|------|------|------|
| 双向 RNN | 正向+反向 RNN 拼接 | 利用未来上下文 |
| 深度 RNN | 多层 RNN 堆叠 | 更强表达能力 |
| Encoder-Decoder | 编码器 RNN + 解码器 RNN | 序列到序列（翻译） |

<Glossary>

<GlossaryItem term="卷积神经网络（CNN）">
专为网格数据（如图像）设计的神经网络。三个核心思想：①局部连接——每个输出只与局部输入相连，匹配图像的局部相关性。②参数共享——同一卷积核在所有位置共享，实现平移等变（特征出现在任意位置都能检测到）。③层次化特征——浅层捕获边缘/纹理，深层组合出部件/物体。相比全连接网络，CNN 参数量大幅减少且效果更好。经典架构：LeNet（1998）、AlexNet（2012，ReLU+Dropout+GPU）、VGG（小卷积核堆叠）、ResNet（残差连接训练超深网络）。CNN 是计算机视觉的基础架构。
</GlossaryItem>

<GlossaryItem term="感受野（Receptive Field）">
CNN 中某个输出特征对应输入图像上的区域大小。感受野由卷积核大小、层数、stride 和池化决定。浅层感受野小（捕获局部纹理），深层感受野大（捕获全局语义）。增大感受野的方法：增大卷积核、增加层数、使用 stride>1 的卷积或池化、使用空洞卷积（dilated convolution）。感受野是理解 CNN 特征层次的关键概念——只有当感受野覆盖整个物体时，网络才能识别该物体。
</GlossaryItem>

<GlossaryItem term="循环神经网络（RNN）">
处理序列数据的神经网络。通过隐藏状态 h(t) = tanh(W_hh * h(t-1) + W_xh * x(t) + b) 在时间步间传递信息，所有时间步共享相同权重。RNN 能处理任意长度序列，适用于语言建模、机器翻译、语音识别等。主要问题是梯度消失/爆炸——通过时间反向传播（BPTT）时梯度连乘 W_hh^T，长序列梯度消失。解决方案：LSTM/GRU 的门控机制、梯度裁剪、残差连接。RNN 是序列建模的基础，后来被 Transformer 部分取代，但在资源受限场景和小数据量任务中仍有价值。
</GlossaryItem>

<GlossaryItem term="LSTM（长短期记忆网络）">
解决 RNN 梯度消失的门控循环网络。维护细胞状态 c(t)，通过三个门控制信息流：遗忘门 f（丢弃多少旧信息）、输入门 i（写入多少新信息）、输出门 o（输出多少）。细胞状态更新用加法 c = f*c_prev + i*g，梯度可通过加法通路直接回传不受连乘衰减——这是 LSTM 能建模长程依赖的关键。LSTM 在机器翻译、语音识别、时间序列预测等任务中广泛使用。GRU 是简化版（合并细胞状态和隐藏状态，两个门替代三个），参数更少效果相近。
</GlossaryItem>

<GlossaryItem term="残差连接（Residual Connection / Skip Connection）">
h^(l+1) = F(h^(l)) + h^(l) 的连接方式。梯度可以直接通过加法通路回传（d(h^(l+1))/d(h^(l)) = dF/dh + 1），不受乘法链影响，有效缓解梯度消失。残差连接使训练超深网络（152 层 ResNet、上百层 Transformer）成为可能——没有残差连接，超过 30 层的网络几乎无法训练。残差连接的另一个解释：网络学习的是残差 F(h) = h^(l+1) - h^(l) 而非完整映射，当最优映射接近恒等映射时残差接近零，学习更容易。残差连接是现代深度学习的标准组件。
</GlossaryItem>

<GlossaryItem term="编码器-解码器（Encoder-Decoder）">
序列到序列建模的架构。编码器（通常是 RNN/LSTM/Transformer）将输入序列编码为固定长度的上下文向量，解码器从上下文向量生成输出序列。用于机器翻译（输入源语言序列，输出目标语言序列）、文本摘要、语音识别等。Attention 机制解决了固定长度上下文向量的瓶颈——解码器在每步动态关注输入序列的不同部分。Transformer 的 Encoder-Decoder 架构（如原始 Transformer、BERT 是纯编码器、GPT 是纯解码器）成为现代 NLP 的基础架构。
</GlossaryItem>

</Glossary>

### 问题 1

CNN 的三个核心思想是什么？它们为什么使 CNN 比全连接网络更适合处理图像？

<Answer>

CNN 的三个核心思想：①局部连接——每个输出只与输入的局部区域（感受野）相连，而非全部输入。匹配图像的局部相关性（相邻像素相关性最强，远距离像素相关性弱）。②参数共享——同一卷积核在图像的所有位置共享权重，实现平移等变（特征出现在任意位置都能用相同模式检测到）。③层次化特征——多层卷积堆叠使浅层捕获简单模式（边缘、角点），深层组合出复杂语义（部件、物体）。CNN 比全连接网络更适合处理图像的原因：①参数量大幅减少——全连接层一层需要 H*W*C_in*C_out 个参数，卷积层只需 k*k*C_in*C_out 个参数（如 3x3 卷积比全连接少 100 倍以上），减少过拟合和计算量。②利用空间结构——图像具有平移不变性和局部性，CNN 的归纳偏置匹配这些结构，用更少数据学到更好的特征。③层次化表示——多层卷积自然构建从低级到高级的特征层次，符合视觉系统的层次结构。
</Answer>

### 问题 2

RNN 的梯度消失问题是什么？LSTM 如何解决？

<Answer>

RNN 梯度消失问题：通过时间反向传播（BPTT）时，梯度需要连乘 W_hh^T（T 是序列长度）。当 W_hh 的特征值小于 1 时，梯度指数衰减（梯度消失），长序列中浅层时间步几乎不更新，无法建模长程依赖。当特征值大于 1 时梯度指数增长（梯度爆炸），训练发散。根本原因是 RNN 的隐藏状态更新用乘法 h(t) = tanh(W_hh * h(t-1) + ...)，梯度必须通过 tanh 和 W_hh 的连乘回传。LSTM 的解决方案：引入细胞状态 c(t)，其更新用加法而非乘法——c(t) = f(t) * c(t-1) + i(t) * g(t)。梯度对 c(t-1) 的偏导 d(c(t))/d(c(t-1)) = f(t)，当遗忘门 f(t) 接近 1 时梯度几乎无损通过（加法通路），不受 tanh 连乘衰减。三个门的作用：遗忘门 f 决定保留多少旧信息（长程记忆），输入门 i 决定写入多少新信息（短期更新），输出门 o 决定输出多少。LSTM 通过门控让网络自己学习何时记忆、何时遗忘，有效建模长程依赖。
</Answer>

### 问题 3

残差连接的作用是什么？它为什么能帮助训练超深网络？

<Answer>

残差连接的公式 h^(l+1) = F(h^(l)) + h^(l)，将输入直接加到输出上。作用：①缓解梯度消失——梯度 d(h^(l+1))/d(h^(l)) = dF/d(h^(l)) + 1，即使 dF/dh 趋于零，梯度至少为 1（通过加法通路），保证深层网络梯度能有效回传。②使恒等映射容易学习——当最优映射接近恒等映射时，只需让 F(h) 趋于零即可，网络学习残差 F(h) = h^(l+1) - h^(l) 而非完整映射，学习更容易。③平滑损失曲面——残差连接使损失曲面更平滑，减少鞍点和尖锐区域，优化更容易。残差连接帮助训练超深网络的原因：没有残差连接，超过 30 层的网络梯度严重消失几乎无法训练。残差连接通过加法通路保证梯度至少为 1，使 152 层的 ResNet 甚至上千层的网络都能有效训练。残差连接是现代深度学习的标准组件——ResNet、Transformer、扩散模型的 U-Net 都大量使用残差连接。
</Answer>

### 问题 4

CNN 和 RNN 各自适合什么类型的数据？它们的设计哲学有什么共同点？

<Answer>

CNN 适合网格数据（如图像、音频频谱图、棋盘状态），这些数据具有空间局部性和平移不变性。RNN 适合序列数据（如文本、语音、时间序列、股票价格），这些数据具有时序依赖性。设计哲学的共同点：①参数共享——CNN 在所有空间位置共享卷积核权重，RNN 在所有时间步共享转移权重。这使得模型能用有限参数处理任意大小/长度的输入，且在数据的不同位置/时刻复用学到的模式。②引入领域先验——CNN 假设「局部相关 + 平移不变」，RNN 假设「时序依赖 + 时间不变」，这些归纳偏置使模型用更少数据学到更好的特征。③层次化/递归结构——CNN 通过多层堆叠构建从局部到全局的特征层次，RNN 通过时间步递归累积从短期到长期的信息。两者都将「全连接」这种无结构的通用模型替换为「有结构的专用模型」，用领域知识换取参数效率和性能。
</Answer>
