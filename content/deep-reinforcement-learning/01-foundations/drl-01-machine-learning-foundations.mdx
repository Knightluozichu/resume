## 为什么先冻结环境、轨迹与参数版本

<Term def="线性模型是第1章 机器学习基础的第1个可执行证据坐标。">线性模型</Term>、<Term def="交叉熵是第1章 机器学习基础的第2个可执行证据坐标。">交叉熵</Term>、<Term def="softmax是第1章 机器学习基础的第3个可执行证据坐标。">softmax</Term>、<Term def="全连接网络是第1章 机器学习基础的第4个可执行证据坐标。">全连接网络</Term>、<Term def="卷积网络是第1章 机器学习基础的第5个可执行证据坐标。">卷积网络</Term>、<Term def="反向传播是第1章 机器学习基础的第6个可执行证据坐标。">反向传播</Term>共同构成本页坐标。从监督学习的损失函数和概率输出出发，建立后续策略网络、价值网络与梯度优化共用的机器学习语言。

阅读时把环境状态、采样数据、学习目标、优化参数和评价策略分成五份账。每一条转移至少保存状态、动作、奖励、下一状态、终止与截断标记、行为概率和采集时的参数版本；每一次更新保存目标值、损失、梯度范数、更新前后参数摘要和随机种子。这样才能判断改进来自正确算法，而不是信息泄漏、状态污染或评价仍在学习。

<Callout type="info">
  **验收命题：** 能写出模型输入、参数、输出和损失的shape，手算一次前向与梯度，并用有限差分核对反向传播。
</Callout>

## 数学骨架

$$
\hat y=\mathbf w^\top\mathbf x+b
$$

$$
p_k=\frac{e^{z_k}}{\sum_j e^{z_j}}
$$

$$
L=-\sum_k y_k\log p_k
$$

$$
\theta\leftarrow\theta-\eta\nabla_\theta L
$$

公式必须落实为shape与版本合同。奖励是标量，动作可以是离散索引或连续向量，终止转移的未来项固定为零；行为策略负责产生数据，目标策略负责定义学习目标，在线参数与冻结参数不能靠变量名猜测。先用一个两状态、两动作或两智能体样例手算，再运行批量训练。

## 最小实现骨架

```python
def record_transition(env, policy, observation):
    action, logp, policy_version = policy.sample(observation)
    next_observation, reward, terminated, truncated, info = env.step(action)
    return {
        "observation": observation,
        "action": action,
        "reward": float(reward),
        "next_observation": next_observation,
        "terminated": bool(terminated),
        "truncated": bool(truncated),
        "behavior_logp": float(logp),
        "policy_version": policy_version,
    }
```

```python
def one_step_target(transition, bootstrap_value, gamma):
    future = 0.0 if transition["terminated"] else bootstrap_value
    return transition["reward"] + gamma * future
```

```python
def audit_update(before, target, loss, gradient, after):
    assert target.isfinite().all()
    assert loss.isfinite().all()
    assert gradient.isfinite().all()
    return {"before": before.digest(), "target": target.detach(),
            "grad_norm": gradient.norm(), "after": after.digest()}
```

这三段代码不替代具体算法，而是固定共同边界：环境只产生事实，目标函数只读取冻结转移，优化器只在审计通过后更新。章节中的DQN、SARSA、策略梯度、A3C、MADDPG或MCTS都必须映射回这套生命周期。

## 常见失败与回退

<Callout type="trap">
  **本章高风险失败：** 把分类概率、动作概率和Q值混为一谈，或只观察损失下降而不检查标签编码、梯度方向和数据泄漏。
</Callout>

<Callout type="trap">
  **最终曲线不是充分证据：** 奖励上升可能与错误终止、评价继续训练、数据泄漏、错误动作缩放或挑选随机种子同时出现。
</Callout>

<Callout type="tip">
  **回退顺序：** 环境转移 → 轨迹边界 → 手算目标 → 前向输出 → 梯度 → 参数更新 → 冻结评价。第一处不一致未消除前，不增加网络、worker或训练步数。
</Callout>

## 本章回顾

从监督学习的损失函数和概率输出出发，建立后续策略网络、价值网络与梯度优化共用的机器学习语言。 最终掌握标准不是复述算法名，而是能说明每个量来自哪里、由哪版策略产生、在哪个边界归零、如何手算，以及故障样本应在哪一步被发现。通过标准是：能写出模型输入、参数、输出和损失的shape，手算一次前向与梯度，并用有限差分核对反向传播。

<Exercises>

1. 如何为第1章 机器学习基础建立最小可手算样例？

<Answer>
  只保留两个状态、两个动作、两步轨迹或两个智能体，固定奖励、折扣、参数和随机种子；先写预期中间值，再运行一次更新并比较状态、目标、梯度与参数摘要。
</Answer>

2. 如何证明“能写出模型输入、参数、输出和损失的shape，手算一次前向与梯度，并用有限差分核对反向传播。”不是一次高回报偶然满足？

<Answer>
  用同一输入并排运行正常路径与只破坏一个终止标记、策略版本、采样概率、动作边界或梯度符号的路径。检测器必须在预期首个中间量区分两者，并在独立评价中保持结论。
</Answer>

3. 修复第1章 机器学习基础后按什么顺序回归？

<Answer>
  先验证环境与轨迹，再核对目标与前向，然后核对梯度和更新，最后冻结策略做多随机种子评价；任何早期证据失败都停止后续长训练。
</Answer>

</Exercises>
