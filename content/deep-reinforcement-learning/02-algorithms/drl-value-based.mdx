## 核心概念

### DQN核心思想

DQN（Deep Q-Network）用神经网络替代Q表，近似 `Q(s,a;theta) ≈ Q*(s,a)`：

- **输入**：状态 s（如Atari的4帧堆叠图像）
- **网络**：CNN提取特征 + 全连接层输出每个动作的Q值
- **输出**：每个动作一个Q值，选 `argmax_a Q(s,a)` 配合epsilon-贪心

<DrlValueBasedDiagram />

### 两大稳定化技术

| 技术 | 解决的问题 | 原理 |
|------|-----------|------|
| 经验回放 | 数据相关性高 | 存转移到缓冲区，随机采样训练 |
| 目标网络 | TD目标不稳定 | 用独立网络计算TD目标，定期同步 |

### DQN损失函数

```
L(theta) = E[(Q(s,a;theta) - y)^2]
y = r + gamma * max_a' Q(s',a';theta_minus)    // TD目标
```

<Callout type="info">

TD目标 `y` 用目标网络参数 `theta_minus` 计算，而非主网络 `theta`。目标网络每隔N步从主网络硬拷贝，期间保持固定，使训练目标稳定。

</Callout>

### DQN变体演进

| 变体 | 改进点 | 核心公式/方法 |
|------|--------|--------------|
| Double DQN | 解决Q值过估计 | 主网络选动作，目标网络估Q值 |
| Dueling DQN | 提升学习效率 | Q(s,a) = V(s) + A(s,a) |
| Prioritized Replay | 加速收敛 | 按TD误差大小采样 |
| Rainbow | 集大成者 | 六种改进组合 |

## 术语表

<Glossary>

<GlossaryItem term="DQN (Deep Q-Network)">

用神经网络近似Q函数的深度RL算法，是深度RL的开山之作。输入状态，输出每个动作的Q值。

</GlossaryItem>

<GlossaryItem term="经验回放 (Experience Replay)">

将转移 `(s,a,r,s')` 存入环形缓冲区，训练时随机采样minibatch。打破数据时间相关性，提高样本利用率。

</GlossaryItem>

<GlossaryItem term="目标网络 (Target Network)">

独立于主网络的Q网络，参数定期同步，用于计算TD目标。防止目标值随主网络频繁变化导致训练不稳定。

</GlossaryItem>

<GlossaryItem term="TD目标 (TD Target)">

`y = r + gamma * max Q(s',a';theta_minus)`，用目标网络计算的下一状态最优Q值加即时奖励，作为Q回归的目标。

</GlossaryItem>

<GlossaryItem term="Double DQN">

将选动作（主网络）和估Q值（目标网络）解耦，降低max操作导致的系统性过估计偏差。

</GlossaryItem>

<GlossaryItem term="Dueling DQN">

将Q值分解为 `Q(s,a) = V(s) + A(s,a)`，分离状态值与优势函数，提升学习效率。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

DQN的核心思想是什么？它是如何用神经网络近似Q函数的？

<Answer>

DQN用神经网络替代Q表，近似Q函数 Q(s,a;theta) ≈ Q*(s,a)。输入状态s（如Atari的4帧堆叠图像），经过CNN提取特征加全连接层，输出每个动作的Q值。动作选择用argmax_a Q(s,a)配合epsilon-贪心。训练用贝尔曼方程构造TD目标 y = r + gamma * max Q(s',a';theta_minus)，定义损失 L = E[(Q(s,a;theta) - y)^2]，用梯度下降更新。两大创新是经验回放和目标网络。

</Answer>

### 问题 2

经验回放和目标网络分别解决什么问题？为什么DQN需要这两个技术？

<Answer>

经验回放解决数据相关性问题——RL数据是高度相关的连续序列，直接训练导致过拟合和梯度方差大。将转移存入缓冲区随机采样，打破时间相关性，使数据更接近i.i.d.。目标网络解决TD目标不稳定问题——TD目标用同一网络计算，参数每步变化导致目标漂移。用独立网络定期同步计算TD目标，使目标在一段时间内稳定。两者缺一不可：没有经验回放数据相关性太强，没有目标网络目标值不稳定。

</Answer>

### 问题 3

Double DQN和Dueling DQN各改进了什么？原理是什么？

<Answer>

Double DQN解决Q值过估计——标准DQN的max操作导致系统性高估。解耦选动作（主网络theta）和估Q值（目标网络theta_minus），a* = argmax Q(s',a';theta)，y = r + gamma * Q(s',a*;theta_minus)，两者偏差不完全正相关，降低过估计。Dueling DQN提升学习效率——将Q分解为 Q(s,a) = V(s) + A(s,a)，V(s)学状态值不需对每动作分别学，A(s,a)只学差异，收敛更快。

</Answer>

### 问题 4

DQN训练中如果Q值发散不收敛，可能的原因和解决方案是什么？

<Answer>

可能原因：学习率过大（降学习率或用Adam）、目标网络更新频率不当（调500-1000步硬更新或软更新tau=0.005~0.01）、奖励尺度太大（奖励裁剪到[-1,1]或归一化）、经验回放太小（增大缓冲区）、探索不足（增大epsilon起始值减慢衰减）、梯度爆炸（梯度裁剪加BatchNorm）、状态未归一化（图像归一化到[0,1]连续状态标准化）。调试方法：打印max Q值曲线、梯度范数、loss曲线定位发散起点。

</Answer>

</Exercises>
