## 核心概念

### 三大算法速览

| 算法 | 类型 | 核心思想 | 优势 |
|------|------|----------|------|
| PPO | on-policy | 截断策略更新幅度 | 稳定易调，工业首选 |
| SAC | off-policy | 最大熵 + 双Q | 样本高效，内置探索 |
| TD3 | off-policy | 双Q + 延迟更新 | 精确控制，防过估计 |

<DrlAdvancedAlgorithmsDiagram />

### PPO：截断策略更新

PPO用截断的重要性采样比限制更新幅度：

```
L = clip(r, 1-eps, 1+eps) * A
// r = pi_new(a|s) / pi_old(a|s)  重要性采样比
// A = 优势函数
```

<Callout type="info">

PPO是TRPO（信任域策略优化）的简化版——TRPO用KL散度约束保证单调改进但计算复杂，PPO用简单的clip达到类似效果。稳定可靠、通用性强、易于实现，是OpenAI和工业界的事实标准。

</Callout>

### SAC：最大熵RL

SAC的目标函数加入策略熵奖励：

```
J = E[ Sum (r_t + alpha * H(pi)) ]
// H(pi) = 策略熵，alpha = 温度系数（自动调节）
```

- alpha大 → 偏重探索（高熵）
- alpha小 → 偏重利用（低熵）
- alpha自动调节：早期大（多探索），后期小（多利用）

### TD3：三个改进

| 改进 | 解决的问题 | 方法 |
|------|-----------|------|
| 双Q网络 | Q值过估计 | `y = r + gamma * min(Q1, Q2)` |
| 延迟更新 | Actor跟随错误Q | Critic每步更新，Actor每d步更新 |
| 策略平滑 | Q函数对动作敏感 | TD目标动作加截断噪声 |

### 共享核心技术

| 技术 | PPO | SAC | TD3 |
|------|-----|-----|-----|
| 目标网络 | 否 | 是（软更新） | 是（软更新） |
| 经验回放 | 否（on-policy） | 是 | 是 |
| 双Q网络 | 否 | 是 | 是 |
| 梯度裁剪 | 是 | 是 | 是 |

## 术语表

<Glossary>

<GlossaryItem term="PPO (Proximal Policy Optimization)">

on-policy策略优化算法，用截断重要性采样比 clip(r, 1-eps, 1+eps) 限制策略更新幅度。稳定可靠、易调参，是工业界首选。

</GlossaryItem>

<GlossaryItem term="SAC (Soft Actor-Critic)">

off-policy最大熵RL算法，目标函数加入策略熵奖励 `J = r + alpha * H(pi)`。自动平衡探索与利用，样本效率高。

</GlossaryItem>

<GlossaryItem term="TD3 (Twin Delayed DDPG)">

off-policy确定性策略算法，三个改进：双Q取min防过估计、延迟策略更新、目标策略平滑。解决DDPG训练不稳定。

</GlossaryItem>

<GlossaryItem term="最大熵RL">

在标准RL目标上加策略熵奖励，鼓励策略保持随机性。高熵意味着更多探索，SAC通过自动调节alpha实现自适应探索。

</GlossaryItem>

<GlossaryItem term="重要性采样比 r">

`r = pi_new(a|s) / pi_old(a|s)`，新策略与旧策略在该动作上的概率比。PPO通过clip限制r的范围来控制更新幅度。

</GlossaryItem>

<GlossaryItem term="on-policy vs off-policy">

on-policy只能用当前策略采的数据训练（PPO），off-policy可用旧策略数据训练（SAC/TD3，配合经验回放）。off-policy样本效率更高。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

PPO的核心思想是什么？为什么它成为工业界首选的RL算法？

<Answer>

PPO核心思想是限制每次策略更新幅度，用截断重要性采样比 clip(r, 1-eps, 1+eps) 防止新策略偏离旧策略太远。成为工业首选原因：稳定可靠（clip机制防止策略崩溃，训练曲线平滑）；on-policy但高效（多步epoch重用数据）；通用性强（支持离散和连续动作）；易于实现和扩展（代码简洁，配合GAE效果优秀）；大规模训练友好（支持分布式）；OpenAI背书大量验证。缺点是样本效率不如SAC，但稳定性优势使其在工业场景更受青睐。

</Answer>

### 问题 2

SAC的最大熵原理如何平衡探索与利用？目标函数与普通RL有何不同？

<Answer>

SAC目标 J = E[Sum(r_t + alpha * H(pi))]，在标准RL奖励上加策略熵奖励。普通RL只最大化奖励学到确定性策略，SAC同时最大化奖励和熵鼓励随机性。alpha控制探索强度：大则偏重探索，小则偏重利用。SAC关键创新是自动调节alpha——通过约束优化保持策略熵在目标值，早期alpha大（多探索）后期alpha小（多利用）。SAC还有off-policy经验回放（样本效率高）和双Q网络取min（消除过估计）。

</Answer>

### 问题 3

TD3的三个核心改进分别解决什么问题？

<Answer>

双Q网络解决Q值过估计——DDPG的max操作放大噪声导致系统高估，训练两个独立Q网络取min使估计更保守。延迟策略更新解决Actor跟随错误Q——Critic每步更新但Actor每d步（d=2）才更新，等Critic相对准确后再更新Actor。目标策略平滑解决Q函数对动作敏感——在TD目标的动作上加截断噪声使Q函数对动作依赖更平滑，防止策略利用Q函数尖峰。三个改进共同解决DDPG训练不稳定和Q值过估计。

</Answer>

### 问题 4

面对一个连续控制任务，如何在PPO、SAC、TD3之间选择？

<Answer>

考虑因素：样本成本——仿真快样本免费选PPO（大规模并行），样本贵选SAC（off-policy样本效率最高）。训练稳定性——PPO最稳定几乎不需调参，不确定时先用PPO。探索需求——需持续探索选SAC（最大熵自动探索），简单任务TD3确定性策略更精确。动作维度——低维三者都行，高维SAC和TD3的off-policy优势明显。工程成熟度——PPO最成熟社区支持最好。总结：大规模仿真追求稳定用PPO，真实环境样本贵用SAC，精确控制低维用TD3，不确定先跑PPO baseline。

</Answer>

</Exercises>
