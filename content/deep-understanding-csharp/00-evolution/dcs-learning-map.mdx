## 为什么先锁定第四版Identity与权威目录

本课程对应Jon Skeet的*C# in Depth, Fourth Edition*，Manning于2019年3月出版，ISBN 9781617294532。全书是4个Part、15章，从Chapter 1的语言/平台/社区演进背景，经过C# 2-5与C# 6，进入C# 7和当时的C# 8 preview。课程结构以Manning publisher/liveBook目录为准。

版本身份不是书目信息装饰。第四版Chapter 11是**Composition using tuples**，没有C# 9 records；若把后来的records并进来，就会替换原书问题而非补充版本边界。同样，Chapter 15的任务是保留2019 preview视角，再说明后来shipping semantics，不能把今天的完整语言历史倒写成作者当时的确定结论。

先预测：按delegates、async、records等热门主题抽取十页能否代表本书；直接用最新C# syntax重写每章是否仍忠实；能解释语法但不能说出lowering、execution或lifetime是否算掌握。三个答案都是否。

<Term def="以作者、出版社、第四版、出版时间、ISBN及4 Parts/15 Chapters目录共同定义的课程结构基准。">edition identity contract</Term>

## 四个Part的纵向路线

### Part 1: C# in context

Chapter 1 **Survival of the sharpest**先建立方法论：language、platform、community和book本身持续演进。Reader需要区分语言syntax、runtime/BCL capability、compiler/tooling和社区practice，后面每个feature都按这四层定位。

### Part 2: C# 2-5

Chapters 2-7是整书机制主干。C# 2引入generics、nullable value types、delegate simplification与iterators；C# 3用properties、inference、initializers、anonymous types、lambda、extensions、query expressions汇聚为LINQ；C# 4处理dynamic、optional/named、COM与variance；C# 5用async/await改变asynchronous flow，并下探state machine implementation与bonus features。

### Part 3: C# 6

Chapters 8-10把高频code写得更直接：property/initializer与expression-bodied members，interpolation/FormattableString/nameof，以及using static、enhanced initializers、null conditional和exception filters。简洁不是省字符，而是把construction、culture、null propagation与handler selection放到更清楚的位置。

### Part 4: C# 7 and beyond

Chapters 11-15扩展data shape与memory model：tuples、deconstruction、patterns、ref locals/returns、in/readonly/ref-like structs、C# 7.x concise features，以及C# 8 nullable references、switch expressions、recursive patterns、indexes/ranges、async streams/disposal的preview。每个现代补充都需标first version。

## 四条横向Dependency Chain

纵向按version读能回答“何时加入”，横向chain回答“机制如何连接”。

1. **Type chain**：generics/nullable values，经inference、anonymous types、variance与dynamic boundary，到tuples、patterns和nullable references。
2. **Execution chain**：delegate、iterator与query expression，经async state machine、exception filter，到async stream/disposal。
3. **Data-shape chain**：initializer/property、text formatting，经tuple/deconstruction，到recursive classification与external schema boundary。
4. **Memory chain**：value/reference copy、closure/state capture，经in/readonly，到ref return与ref-like lifetime。

<Term def="从generics与inference经过binding、tuple/pattern，直到nullable contract都保持type intent可验证的链路。">type evolution chain</Term>

<Term def="从delegate/iterator调用到query、async state machine、filter和async sequence的真实执行时序链。">execution evolution chain</Term>

  <Step title="切换type、execution、shape与memory"><DcsVersionDependencyLab /></Step>
  <Step title="从一个value追踪到最终boundary">例如Order从generic repository进入LINQ expression，经async materialization，组成tuple，再被pattern分类。</Step>
  <Step title="找出最早可证明或拒绝的位置">能compile-time表达就不拖到dynamic/runtime，能在scope内materialize就不让deferred work逃逸。</Step>
</Stepper>

```csharp
var query = repository.Orders.Where(order => order.Total > minimum);
var snapshot = await query.ToListAsync(token);
var result = (count: snapshot.Count, total: snapshot.Sum(x => x.Total));
```

<Callout type="trap" title="Feature是独立语法点，分别记住Example即可">
真实缺陷发生在连接处：closure改变deferred query参数，async continuation改变execution context，tuple position泄露public shape，ref view跨suspension违反lifetime。学习证据必须跨至少两个机制。
</Callout>

<Exercises>

**问题 1：为什么学习async要回看iterators和delegates？**

<Answer>Iterator先展示source method如何生成可恢复state machine，delegate/lambda解释continuation callback与capture；async/await在此基础上增加awaiter protocol、suspension与Task completion。用source、generated states和execution timeline对照，才能解释同步完成、异常、context与cancellation。</Answer>

**问题 2：一个现代record应该放进Chapter 11正文吗？**

<Answer>不应。第四版Chapter 11的官方主题是tuples及其literal/type/conversion/CLR/alternatives/use。Record是C# 9后续nominal data feature，可在alternatives处标“现代版本补充”，但不能改标题、替换tuple内容或改变目录coverage。</Answer>

**问题 3：一个章节最小的100分闭环是什么？**

<Answer>逐项匹配publisher concept；写3个actionable objectives、5个Term/Glossary、2个trap、3个code、3个exercise/answer；操作3个专属交互实验共9 steps；覆盖normal/boundary/fault/version；审计维度100并通过MDX/type/targeted lint。</Answer>

</Exercises>
