## 为什么从“Java体系与源码入口台”开始

第一部分 走近Java不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。Java体系与源码入口台沿“Java SE规范 → OpenJDK源码 → HotSpot构建 → 镜像”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第一部分 走近Java固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变事实层次或时间边界；图中只呈现本章真实运行时对象、状态边与证据出口；高亮表示当前分析路径，不冒充真实吞吐、停顿、对象大小或线程安全证明。
