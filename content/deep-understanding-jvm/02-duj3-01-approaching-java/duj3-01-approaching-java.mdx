## 为什么从“OpenJDK构建与调试台”开始

第1章 走近Java不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。OpenJDK构建与调试台沿“source commit → configure → build → images → debugger”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第1章 走近Java固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变构建阶段或调试入口；交互分数只表达因果方向，不冒充真实吞吐、停顿、对象大小或线程安全证明。
