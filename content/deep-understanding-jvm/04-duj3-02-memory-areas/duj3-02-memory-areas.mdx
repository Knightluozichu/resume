## 为什么从“运行时数据区与OOM台”开始

第2章 Java内存区域与内存溢出异常不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。运行时数据区与OOM台沿“thread/frame/heap/metaspace/direct → failure”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第2章 Java内存区域与内存溢出异常固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变受限区域或故障类型；交互分数只表达因果方向，不冒充真实吞吐、停顿、对象大小或线程安全证明。
