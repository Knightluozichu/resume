## 为什么从“对象存活与收集器台”开始

第3章 垃圾收集器与内存分配策略不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。对象存活与收集器台沿“allocation → remembered set → mark/relocate → pause”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第3章 垃圾收集器与内存分配策略固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变收集器或工作负载；交互分数只表达因果方向，不冒充真实吞吐、停顿、对象大小或线程安全证明。
