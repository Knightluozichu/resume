## 为什么从“对象存活与收集器台”开始

第3章 垃圾收集器与内存分配策略不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。对象存活与收集器台沿“allocation → remembered set → mark/relocate → pause”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第3章 垃圾收集器与内存分配策略固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变收集器或工作负载；图中只呈现本章真实运行时对象、状态边与证据出口；高亮表示当前分析路径，不冒充真实吞吐、停顿、对象大小或线程安全证明。

## 来源、勘误与独立重写边界

第3章 垃圾收集器与内存分配策略依据作者[第3版样例与持续勘误仓库](https://github.com/fenixsoft/jvm_book)核定代码和已知修正，并用[出版社版式目录](https://18636251.s21i.faiusr.com/61/ABUIABA9GAAg8dqTugYo3O7rmwQ.pdf)限定5个部分、13章、附录A–E和282个正式节点。第3章 垃圾收集器与内存分配策略未取得出版正文授权，目录只限定范围，中文解释、命令、图示、实验与答案均为独立教学重写。
