## 为什么从“Class文件解剖台”开始

第6章 类文件结构不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。Class文件解剖台沿“magic/version → constant pool → members → attributes → code”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第6章 类文件结构固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变查看粒度或编译选项；图中只呈现本章真实运行时对象、状态边与证据出口；高亮表示当前分析路径，不冒充真实吞吐、停顿、对象大小或线程安全证明。
