## 为什么从“Class文件解剖台”开始

第6章 类文件结构不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。Class文件解剖台沿“magic/version → constant pool → members → attributes → code”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第6章 类文件结构固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变查看粒度或编译选项；图中只呈现本章真实运行时对象、状态边与证据出口；高亮表示当前分析路径，不冒充真实吞吐、停顿、对象大小或线程安全证明。

## 来源、勘误与独立重写边界

第6章 类文件结构依据作者[第3版样例与持续勘误仓库](https://github.com/fenixsoft/jvm_book)核定代码和已知修正，并用[出版社版式目录](https://18636251.s21i.faiusr.com/61/ABUIABA9GAAg8dqTugYo3O7rmwQ.pdf)限定5个部分、13章、附录A–E和282个正式节点。第6章 类文件结构未取得出版正文授权，目录只限定范围，中文解释、命令、图示、实验与答案均为独立教学重写。

第6章 类文件结构保留原书2019年的JDK 12 / JDK 13预览期语境；现代复核以[JVMS 25](https://docs.oracle.com/javase/specs/jvms/se25/html/index.html)、[JLS 25线程与锁](https://docs.oracle.com/javase/specs/jls/se25/html/jls-17.html)、[JDK 25工具规范](https://docs.oracle.com/en/java/javase/25/docs/specs/man/index.html)、[OpenJDK 25发布页](https://openjdk.org/projects/jdk/25/)与[OpenJDK源码](https://github.com/openjdk/jdk)为事实依据。第6章 类文件结构的JDK 25注记不是原书内容，任何默认值和实现细节都必须重新测量。
