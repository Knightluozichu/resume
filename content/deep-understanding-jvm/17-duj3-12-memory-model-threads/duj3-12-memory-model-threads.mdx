## 为什么从“happens-before与线程台”开始

第12章 Java内存模型与线程不能把语言、JVMS、HotSpot和某个JDK发行版混成一层。happens-before与线程台沿“actions → synchronization order → visibility/ordering”保存输入和原始输出，让每个结论都能回到规范条款、实现状态和目标版本。

第12章 Java内存模型与线程固定JDK镜像、VM参数、工作量、采集窗口和资源限制，只改变共享方式或线程载体；图中只呈现本章真实运行时对象、状态边与证据出口；高亮表示当前分析路径，不冒充真实吞吐、停顿、对象大小或线程安全证明。
