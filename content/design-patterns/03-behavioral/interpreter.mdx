## 痛点场景：布尔表达式求值

系统需要支持规则引擎：用户输入 `A AND (B OR C)`，系统根据变量值计算结果。

不用模式：手写解析器，代码复杂且难扩展。

## 解决方案：文法树

```typescript
// 表达式接口
interface BooleanExpression {
  interpret(context: Map<string, boolean>): boolean;
}

// 终结符表达式：变量
class Variable implements BooleanExpression {
  constructor(private name: string) {}
  interpret(context: Map<string, boolean>): boolean {
    return context.get(this.name) ?? false;
  }
}

// 非终结符表达式：AND
class AndExpression implements BooleanExpression {
  constructor(private left: BooleanExpression, private right: BooleanExpression) {}
  interpret(context: Map<string, boolean>): boolean {
    return this.left.interpret(context) && this.right.interpret(context);
  }
}

// 非终结符表达式：OR
class OrExpression implements BooleanExpression {
  constructor(private left: BooleanExpression, private right: BooleanExpression) {}
  interpret(context: Map<string, boolean>): boolean {
    return this.left.interpret(context) || this.right.interpret(context);
  }
}
```

使用：

```typescript
// 构建 A AND (B OR C)
const expr = new AndExpression(
  new Variable("A"),
  new OrExpression(new Variable("B"), new Variable("C"))
);

// 求值
const context = new Map([["A", true], ["B", false], ["C", true]]);
console.log(expr.interpret(context)); // true AND (false OR true) = true
```

## 终结符 vs 非终结符

| 类型 | 角色 | 示例 |
|------|------|------|
| 终结符表达式 | 文法树的叶子节点，不可再分 | 变量 A、常量 true |
| 非终结符表达式 | 文法的分支节点，持有子表达式 | AND、OR、NOT |

<Callout type="info">
文法树的叶子是终结符，分支是非终结符。整棵树递归调用 `interpret()`，叶子返回基础值，分支组合子表达式的结果。
</Callout>

## 现代替代方案

解释器模式在现代开发中很少直接使用，因为：

1. **性能差**：递归遍历文法树，复杂表达式效率低
2. **文法复杂时类爆炸**：每条文法规则一个类
3. **更好的替代**：
   - **ANTLR / tree-sitter**：生成解析器，支持复杂文法
   - **DSL 脚本引擎**：嵌入 Lua、JavaScript、Python
   - **规则引擎**：Drools、json-rules-engine
   - **函数式组合**：用高阶函数替代文法树

<Callout type="warning">
GoF 解释器模式的价值在于**思想**（用树形结构表示和执行语言），而非**实践**（实际项目很少手写）。理解它有助于理解编译器 AST、规则引擎的工作原理。
</Callout>

## 小结

- 解释器 = 用文法树表示语言 + 递归解释执行
- 终结符 = 叶子（变量/常量），非终结符 = 分支（AND/OR/NOT）
- 适合：简单 DSL、规则引擎、正则表达式（概念上）
- 现代实践：优先用 ANTLR、脚本引擎或函数式组合替代

<Glossary>

<GlossaryItem term="解释器模式">

给定一个语言，定义它的文法的一种表示，并定义一个解释器，这个解释器使用该表示来解释语言中的句子。

</GlossaryItem>

<GlossaryItem term="终结符表达式">

文法树的叶子节点，表示文法中不可再分的基本元素（如变量、常量）。直接返回值，不递归。

</GlossaryItem>

<GlossaryItem term="非终结符表达式">

文法树的分支节点，表示文法中的组合规则（如 AND、OR）。持有子表达式，递归调用子表达式的 interpret 后组合结果。

</GlossaryItem>

<GlossaryItem term="DSL">

Domain-Specific Language，领域特定语言。为特定领域设计的小型语言，如 SQL、正则表达式、配置规则。

</GlossaryItem>

</Glossary>
