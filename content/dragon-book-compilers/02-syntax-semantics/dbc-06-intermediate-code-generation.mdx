## 为什么从这个问题开始

“第6章 中间代码生成”围绕“源级类型、值、地址和控制边怎样在IR中保持可验证语义？”建立贯穿任务：把含数组、短路布尔、循环、switch和调用的程序降到SSA式IR。先写下哪个输入、表示、栈/图状态、IR、目标代码或验证结果会最先变化，再运行参考、故障和恢复路径；运行后补理由不算预测。只有守住“类型、定义—使用、基本块、控制边、phi输入、地址计算与源位置一致”并交付AST/DAG、类型证明、CFG、SSA定义—使用链与回填日志，编译成功、分析收敛、目标码长度或基准加速才构成机制证据。
