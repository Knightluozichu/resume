## 机器无关优化的目标

机器无关优化在 IR 层做等价变换，目标是产出**更快**或**更短**的代码，而不改变程序语义，且不依赖目标机器特性。优化的基础是**数据流分析**。

## 数据流分析

数据流分析通过**迭代到不动点**求解，在控制流图上推导程序性质。三种经典分析：

### 到达定义分析（前向 / 并集）

哪些变量定义能到达某点：

$$OUT[b] = GEN[b] \cup (IN[b] - KILL[b])$$

$$IN[b] = \bigcup_{p \in pred(b)} OUT[p]$$

用于未初始化变量检测、UD 链构建。

### 可用表达式分析（前向 / 交集）

已计算且操作数未被重定义的表达式：

$$IN[b] = \bigcap_{p \in pred(b)} OUT[p]$$

$$OUT[b] = (IN[b] \cup GEN[b]) - KILL[b]$$

交集保证「所有前驱都可用才可用」（保守），用于全局公共子表达式消除。

### 活跃变量分析（后向 / 并集）

变量在之后是否被使用：

$$OUT[b] = \bigcup_{s \in succ(b)} IN[s]$$

$$IN[b] = (OUT[b] - DEF[b]) \cup USE[b]$$

用于死代码消除和寄存器分配。

<Callout type="info">

数据流分析追求**保守近似**——宁可漏报优化机会（少优化），也不能误报（改变语义）。例如可用表达式用交集，偏向保守。

</Callout>

## 冗余消除

### 公共子表达式消除（CSE）

基于可用表达式分析。若表达式 `b+c` 已计算且 b、c 未被重定义（表达式可用），则后续 `b+c` 可复用之前的结果：

```text
a = b + c    // 计算
d = b + c    // b、c 未变 → 可用 → 替换为 d = a
```

### 常量传播（Constant Propagation）

前向数据流分析，值域为 $\{\bot, c, \text{NAC}, \top\}$（未定义 / 常量 / 非常量 / 不确定）。若变量在所有到达路径上都是同一常量，则用该常量替换引用：

```text
x = 5
y = x + 1   →  y = 6   （常量折叠）
```

### 死代码消除（DCE）

后向活跃变量分析驱动。若指令的计算结果从不被使用（不活跃），则该指令是死代码，可安全删除。删除一条可能暴露更多死代码，需**级联迭代**删除。

## 循环优化

基于**支配关系**和**归纳变量**分析，循环优化是中端性能提升的核心：

### 代码外提（LICM）

循环中每次迭代结果都相同的计算（循环不变量）移到循环外：

```text
优化前: for (i=0; i<n; i++) a[i] = x * y + i;   // x*y 每次重算
优化后: t = x * y; for (i=0; i<n; i++) a[i] = t + i;  // x*y 只算一次
```

### 归纳变量优化

循环中多个同步递增的归纳变量（如 `i++` 和 `j = i*4`），删除冗余的，只保留最便宜的。

### 强度削弱

用更便宜的运算替代昂贵的运算：

```text
优化前: for (i=0; i<n; i++) j = i * 4;    // 乘法
优化后: j = 0; for (i=0; i<n; i++) { j += 4; }  // 加法替代乘法
```

<Callout type="tip">

循环优化的共同前提是**循环识别**——通过支配关系找出循环头和回边。三种优化常配合使用：先外提不变量，再削弱强度，最后删除冗余归纳变量。

</Callout>

### 问题 1

机器无关优化的目标是什么？数据流分析的迭代求解是如何工作的？

<Answer>

目标：在 IR 层做等价变换，产出更快或更短的代码，不改变程序语义，且不依赖目标机器特性。数据流分析迭代求解：①为每个基本块初始化 IN/OUT 值 ②反复应用传递函数（OUT[b]=F_b(IN[b])）和交汇运算（前向：IN[b]=∧OUT[p]，后向：OUT[b]=∧IN[s]）更新各块值 ③当所有值不再变化时达到不动点，求解完成。因值域是有限格且传递函数单调，迭代一定收敛。分析结果是保守近似——宁可漏报优化机会也不能误报改变语义。

</Answer>

### 问题 2

到达定义分析、可用表达式分析和活跃变量分析的区别是什么？

<Answer>

三者方向、交汇和用途不同：①到达定义分析——前向、并集交汇，找出哪些变量定义能到达某点（OUT=GEN∪(IN-KILL)）。用于未初始化变量检测、UD 链构建。②可用表达式分析——前向、交集交汇，找出已计算且操作数未变的表达式（IN=∩OUT[p]）。交集保证「所有前驱都可用才可用」（保守）。用于全局公共子表达式消除。③活跃变量分析——后向、并集交汇，找出变量在之后是否被使用（OUT=∪IN[s], IN=(OUT-DEF)∪USE）。用于死代码消除和寄存器分配。前两者前向传播「有什么」，后者后向传播「需要什么」。

</Answer>

### 问题 3

公共子表达式消除（CSE）和常量传播是如何工作的？

<Answer>

CSE：基于可用表达式分析。若表达式 `b+c` 已在某点计算过且 b、c 未被重定义（即表达式可用），则后续 `b+c` 可直接复用之前的结果而非重新计算。例如 `a=b+c; d=b+c` → `a=b+c; d=a`。常量传播：前向数据流分析，值域为 &#123;⊥（未定义）, c（常量值）, NAC（非常量）, ⊤（不确定）&#125;。若变量 x 在所有到达路径上都是同一常量 c，则用 c 替换 x 的引用。例如 `x=5; y=x+1` → `x=5; y=6`。常量传播可与折叠结合（编译期算出 6），进一步触发死代码消除（删除 x=5 若 x 不再使用）。

</Answer>

### 问题 4

循环优化中的代码外提、归纳变量优化和强度削弱各是什么？

<Answer>

代码外提（LICM）：循环中每次迭代结果都相同的计算（循环不变量）移到循环外只算一次，如 `for i: a[i]=x*y+i` 中 `x*y` 不变，外提为 `t=x*y; for i: a[i]=t+i`。需确保不在异常路径、无副作用。归纳变量优化：循环中多个同步递增的归纳变量（如 `i++` 和 `j=i*4`）删除冗余的，只保留最便宜的。强度削弱：用更便宜的运算替代昂贵的，如 `j=i*4` 在循环内每次 `i++` 后改为 `j+=4`（加法替代乘法）。三者都依赖循环识别（通过支配关系和回边找自然循环），是中端性能提升的核心。

</Answer>
