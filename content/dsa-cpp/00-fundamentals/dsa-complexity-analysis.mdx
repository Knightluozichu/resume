## 直觉引入

`vector::push_back` 偶尔需要扩容（$O(n)$），但大多数时候是 $O(1)$。那么它的「真实」复杂度是多少？这不是简单的大 O 能回答的——需要均摊分析。

复杂度分析不只是「数循环层数」。均摊分析处理「一系列操作的总代价」，递推关系处理「递归算法的代价」。这些工具让你能精确评估从 `vector` 扩容到归并排序的任何操作。

## 概念讲解

### 大 O 的严格定义

<DsaComplexityDiagram />

<Term def="f(n) = O(g(n)) 表示存在正常数 c 和 n₀，使所有 n ≥ n₀ 有 f(n) ≤ c·g(n)">
大 O 表示法
</Term>

大 O 是上界，$\Omega$ 是下界，$\Theta$ 是确界（上下界同阶）。$f(n) = \Theta(g(n))$ 当且仅当 $f(n) = O(g(n))$ 且 $f(n) = \Omega(g(n))$。

### 均摊分析

<Stepper>
<Step title="聚集法（Aggregate）">
直接计算 $n$ 次操作的总代价 $T(n)$，均摊代价 $= T(n)/n$。例如 `vector` 倍增扩容：$n$ 次 `push_back` 的总代价 $= n + 1 + 2 + 4 + \cdots + n/2 + n < 3n$，均摊 $O(1)$。
</Step>
<Step title="记账法（Accounting）">
给每次操作预付「费用」，多余的部分存入「信用」供未来昂贵操作使用。`push_back` 预付 3 单位：1 单位用于当前插入，2 单位存入信用。扩容时用信用支付搬迁代价。信用始终 $\geq 0$，证明均摊 $O(1)$。
</Step>
<Step title="势能法（Potential）">
定义势能函数 $\Phi(D_i)$ 作用于数据结构状态。均摊代价 $\hat{c}_i = c_i + \Phi(D_i) - \Phi(D_{i-1})$。`vector` 的势能 $\Phi = 2 \cdot \text{size} - \text{capacity}$（$\text{size} > \text{capacity}/2$ 时），可证明每次 `push_back` 均摊 $\leq 3$。
</Step>
</Stepper>

### 递推关系求解

递归算法的复杂度通常表示为递推式 $T(n) = aT(n/b) + f(n)$。

**主定理**：若 $f(n) = O(n^d)$，$a \geq 1, b > 1$，则：
- $a < b^d$：$T(n) = O(n^d)$（根节点代价主导）
- $a = b^d$：$T(n) = O(n^d \log n)$（各层代价均衡）
- $a > b^d$：$T(n) = O(n^{\log_b a})$（叶子节点代价主导）

应用：归并排序 $T(n) = 2T(n/2) + O(n)$，$a=2, b=2, d=1$，$a = b^d$，所以 $T(n) = O(n \log n)$。

## 代码对照

```cpp
#include <vector>
#include <iostream>

// 均摊分析示例：vector 的 push_back
// 单次最坏 O(n)（扩容），均摊 O(1)
void demonstrate_amortized() {
    std::vector<int> v;
    // n 次 push_back 的总代价 = O(n)
    // 因为扩容次数 = log₂n，每次扩容搬迁 2^k 个元素
    // 总搬迁 = 1 + 2 + 4 + ... + n/2 + n < 2n
    // 加上 n 次普通插入 = 3n → 均摊 O(1)
    for (int i = 0; i < 1000000; ++i) {
        v.push_back(i);  // 均摊 O(1)
    }
}

// 递归算法的复杂度分析
// 归并排序 T(n) = 2T(n/2) + O(n) → O(n log n) by Master Theorem
void merge_sort(int* arr, int lo, int hi) {
    if (lo >= hi) return;          // T(1) = O(1)
    int mid = lo + (hi - lo) / 2;
    merge_sort(arr, lo, mid);      // T(n/2)
    merge_sort(arr, mid + 1, hi);  // T(n/2)
    // merge: O(n)
    std::inplace_merge(arr + lo, arr + mid + 1, arr + hi + 1);
}

// 二分查找 T(n) = T(n/2) + O(1) → O(log n) by Master Theorem
// a=1, b=2, d=0, a = b^d = 1 → O(log n)
int binary_search(int* arr, int n, int target) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
```

## 常见误区

<Callout type="trap">
**误区：把均摊复杂度和平均复杂度混为一谈。**
均摊分析针对**一系列操作**的总代价，不涉及概率。平均复杂度针对**单一操作**在随机输入下的期望代价，依赖概率假设。`vector::push_back` 的均摊 $O(1)$ 是确定的（不需要概率假设），而快排的平均 $O(n \log n)$ 依赖 pivot 随机性。
</Callout>

<Callout type="trap">
**误区：主定理的三个情形覆盖所有递推。**
主定理只适用于 $T(n) = aT(n/b) + O(n^d)$ 形式的递推。对于 $T(n) = T(n-1) + T(n/2) + n$ 这种不等分或多项递推，主定理不适用，需要用代入法或递归树法直接求解。
</Callout>

<Exercises>
**问题 1**：用聚集法分析 `vector` 的 $n$ 次 `push_back` 的均摊复杂度。

<Answer>
$n$ 次 `push_back` 中，扩容发生在 size = 1, 2, 4, ..., n/2 时（倍增策略）。每次扩容搬迁当前所有元素。总搬迁代价 = $1 + 2 + 4 + \cdots + n/2 = n - 1 < n$。加上 $n$ 次普通插入的代价 $n$，总代价 $< 2n$。均摊到每次操作 $= 2n/n = O(1)$。
</Answer>

**问题 2**：用主定理求解 $T(n) = 4T(n/2) + n$。

<Answer>
$a = 4, b = 2, d = 1$。$b^d = 2^1 = 2$。$a = 4 > b^d = 2$，属于第三种情形（$a > b^d$），所以 $T(n) = O(n^{\log_b a}) = O(n^{\log_2 4}) = O(n^2)$。叶子节点的总代价主导（有 $n^2$ 个叶子）。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="均摊分析">
分析一系列操作的总代价并均摊到每次操作。三种方法：聚集法（总代价/n）、记账法（预付信用）、势能法（势能函数）。不涉及概率。
</GlossaryItem>
<GlossaryItem term="主定理">
求解 T(n)=aT(n/b)+O(n^d) 的工具。a < b^d → O(n^d)；a = b^d → O(n^d log n)；a > b^d → O(n^(log_b a))。
</GlossaryItem>
<GlossaryItem term="势能函数">
均摊分析中定义在数据结构状态上的函数 Φ(D)。均摊代价 = 实际代价 + ΔΦ。Φ 始终非负则证明均摊上界。
</GlossaryItem>
<GlossaryItem term="递推关系">
递归算法复杂度的数学表达 T(n) = aT(n/b) + f(n)。用代入法、递归树法或主定理求解。
</GlossaryItem>
</Glossary>
