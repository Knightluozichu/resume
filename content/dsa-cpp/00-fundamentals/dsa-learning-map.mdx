## 直觉引入

数据结构与算法分析的核心问题：给定一个计算任务，如何选择最高效的数据结构和算法？这本书不仅教你「有什么结构」，更教你「为什么这个结构在这个场景下最优」——用严格的数学分析来量化效率。

与前两本书不同，本书用 C++ 实现所有结构，强调工程实践与理论分析的结合。从最基础的复杂度分析出发，到链表、树、散列表的实现，再到图算法和动态规划，每一章都在回答：这个结构/算法的时间空间代价是多少？在什么条件下它是最优选择？

## 全书四段结构

<DsaBookMap />

全书分四大板块，呈「分析工具 → 基本结构 → 高级结构 → 算法设计」的递进关系：

1. **基础**（2 章）：算法复杂度分析（大 O、均摊分析）是后续所有章节的评估工具。
2. **数据结构**（2 章）：线性表（数组/链表/STL vector）和树（BST/AVL/B 树），从最基本到自平衡结构。
3. **散列与图**（3 章）：散列表（$O(1)$ 查找）、并查集（近 $O(1)$ 合并查询）、图算法（BFS/DFS/Dijkstra/MST）。
4. **算法设计**（3 章）：排序（从 $O(n^2)$ 到 $O(n \log n)$）、动态规划（重叠子问题的系统化求解）、总复习。

## 代码对照

```cpp
#include <vector>
#include <iostream>

// C++ 模板化数据结构示例：动态数组（简化版 vector）
template <typename T>
class DynamicArray {
private:
    T* data;
    int capacity;
    int size;

    void resize() {
        capacity *= 2;  // 倍增策略：均摊 O(1)
        T* newData = new T[capacity];
        for (int i = 0; i < size; ++i)
            newData[i] = data[i];
        delete[] data;
        data = newData;
    }

public:
    DynamicArray() : capacity(1), size(0) { data = new T[capacity]; }

    ~DynamicArray() { delete[] data; }

    // O(1) 均摊：尾部插入
    void push_back(const T& val) {
        if (size == capacity) resize();
        data[size++] = val;
    }

    // O(1)：随机访问
    T& operator[](int i) { return data[i]; }

    int get_size() const { return size; }
};

// 算法分析的价值：
// 知道 push_back 均摊 O(1) → 放心高频调用
// 知道 operator[] 是 O(1) → 适合随机访问场景
```

## 常见误区

<Callout type="trap">
**误区：只学数据结构的实现，不学算法分析。**
数据结构的实现是「怎么做」，算法分析是「为什么这样做」。不学分析，你无法判断：这个场景该用 `vector` 还是 `list`？该用 `map` 还是 `unordered_map`？分析能力是选择结构的科学依据。
</Callout>

<Callout type="trap">
**误区：认为 C++ 的 STL 容器不需要理解底层实现。**
STL 容器是高效的，但不是万能的。`vector` 在头部插入是 $O(n)$，`list` 随机访问是 $O(n)$，`unordered_map` 最坏 $O(n)$。不理解底层实现和分析，就会在不合适的场景用错容器，导致性能问题。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？为什么说算法分析是「基石」？

<Answer>
基础（复杂度分析）、数据结构（表与树）、散列与图（散列表/并查集/图算法）、算法设计（排序/动态规划）。算法分析是基石因为后续每一章都要用大 O 和均摊分析来评估结构和算法的效率，不掌握分析就无法判断结构是否适合场景。
</Answer>

**问题 2**：为什么本书强调 C++ 实现与分析并重？

<Answer>
C++ 实现让你理解数据结构的底层细节（指针、内存管理、模板），算法分析让你量化每个操作的代价。两者结合才能做出工程最优选择：知道 `vector` 的 `push_back` 均摊 $O(1)$ 但头部插入 $O(n)$，才知道什么场景用 `vector`、什么场景用 `list`。实现是「怎么做」，分析是「为什么」。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="算法分析">
用数学方法量化算法的时间和空间代价，包括大 O 表示法、均摊分析、递推关系求解。是选择数据结构和算法的科学依据。
</GlossaryItem>
<GlossaryItem term="均摊分析">
分析一系列操作的总代价并均摊到每次操作。如动态数组倍增扩容时单次 O(n) 但均摊 O(1)。分聚集法、记账法、势能法三种技术。
</GlossaryItem>
<GlossaryItem term="数据结构">
组织和存储数据的方式，决定操作效率。本书覆盖线性表、树、散列表、并查集、图等，每种结构用 C++ 模板实现并用算法分析评估。
</GlossaryItem>
<GlossaryItem term="STL容器">
C++ 标准模板库提供的容器（vector、list、map、set、unordered_map 等），封装了常用数据结构。理解其底层实现和分析才能正确选用。
</GlossaryItem>
</Glossary>
