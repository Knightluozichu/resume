## 直觉引入

C++ STL 提供了 `vector` 和 `list` 两种线性容器，它们分别对应数组和链表。但 STL 不是简单的封装——`vector` 的倍增扩容策略让 `push_back` 均摊 $O(1)$，`list` 的双向链表实现让任意位置插入 $O(1)$。

理解这些实现细节，才能避免迭代器失效、内存泄漏等陷阱，才能在正确的场景选择正确的容器。

## 概念讲解

### 数组与 vector

<DsaListsDiagram />

<Term def="vector 是 C++ STL 的动态数组，用倍增策略实现均摊 O(1) 的 push_back">
vector
</Term>

`vector` 的核心：连续内存 + 倍增扩容。当 `size == capacity` 时，分配新数组（容量翻倍），搬迁旧元素，释放旧数组。虽然单次扩容 $O(n)$，但均摊 $O(1)$。

| 操作 | vector 复杂度 | 说明 |
|---|---|---|
| `operator[]` / `at` | $O(1)$ | 连续内存，直接算地址 |
| `push_back` | $O(1)$ 均摊 | 偶尔扩容 $O(n)$ |
| `pop_back` | $O(1)$ | 直接减 size |
| `insert(pos)` / `erase(pos)` | $O(n)$ | 需移动后续元素 |
| `size()` | $O(1)$ | 维护计数器 |

### 链表与 list

<Term def="list 是 C++ STL 的双向链表，插入删除 O(1)（已知位置），但不支持随机访问">
list
</Term>

`list` 的每个节点包含 `prev`、`next` 指针和数据。内存不连续，无法 `[]` 随机访问，但任意已知位置的插入删除只需改指针 $O(1)$。

### vector vs list 选择

<Stepper>
<Step title="选 vector 的场景">
需要随机访问（`[]`）、尾部增删为主、缓存友好性重要（连续内存对 CPU 缓存友好）。绝大多数场景应优先 vector——即使中间插入 $O(n)$，常数小+缓存友好往往比 list 的 $O(1)$ 指针操作更快。
</Step>
<Step title="选 list 的场景">
频繁在已知位置（持有迭代器）插入删除、不需要随机访问、元素体积大（搬迁代价高）。list 的 $O(1)$ 插入删除在频繁中间操作时胜出。
</Step>
<Step title="迭代器失效规则">
vector：扩容或插入/删除会使指向被影响位置及之后的迭代器失效。list：只有被删除节点的迭代器失效，其他不受影响。这是选择容器时必须考虑的工程因素。
</Step>
</Stepper>

## 代码对照

```cpp
#include <vector>
#include <list>
#include <iostream>

// vector：动态数组实现
template <typename T>
class MyVector {
    T* data;
    int theSize;
    int theCapacity;

    void resize() {
        theCapacity = theCapacity == 0 ? 1 : theCapacity * 2;  // 倍增
        T* newData = new T[theCapacity];
        for (int i = 0; i < theSize; ++i)
            newData[i] = std::move(data[i]);  // 移动语义避免拷贝
        delete[] data;
        data = newData;
    }

public:
    MyVector() : data(nullptr), theSize(0), theCapacity(0) {}
    ~MyVector() { delete[] data; }

    // O(1) 均摊
    void push_back(const T& val) {
        if (theSize == theCapacity) resize();
        data[theSize++] = val;
    }

    // O(1)
    T& operator[](int i) { return data[i]; }

    // O(n)：中间插入，后续元素全部后移
    void insert(int pos, const T& val) {
        if (theSize == theCapacity) resize();
        for (int i = theSize; i > pos; --i)
            data[i] = std::move(data[i - 1]);  // 后移
        data[pos] = val;
        ++theSize;
    }

    int size() const { return theSize; }
};

// list：双向链表实现
template <typename T>
class MyList {
    struct Node {
        T data;
        Node* prev;
        Node* next;
        Node(const T& d) : data(d), prev(nullptr), next(nullptr) {}
    };

    Node* head;
    Node* tail;
    int theSize;

public:
    MyList() : head(nullptr), tail(nullptr), theSize(0) {}
    ~MyList() { clear(); }

    // O(1)：尾部插入
    void push_back(const T& val) {
        Node* node = new Node(val);
        node->prev = tail;
        if (tail) tail->next = node;
        else head = node;
        tail = node;
        ++theSize;
    }

    // O(1)：已知节点后插入（vector 需要 O(n)！）
    void insert_after(Node* pos, const T& val) {
        Node* node = new Node(val);
        node->next = pos->next;
        node->prev = pos;
        if (pos->next) pos->next->prev = node;
        else tail = node;
        pos->next = node;
        ++theSize;
    }

    // O(n)：随机访问（vector 是 O(1)！）
    T& at(int index) {
        Node* cur = head;
        for (int i = 0; i < index; ++i) cur = cur->next;
        return cur->data;
    }

    void clear() {
        Node* cur = head;
        while (cur) { Node* next = cur->next; delete cur; cur = next; }
        head = tail = nullptr; theSize = 0;
    }
};
```

## 常见误区

<Callout type="trap">
**误区：认为 list 的插入删除一定比 vector 快。**
list 的插入删除本身 $O(1)$，但先要定位到插入位置——`list` 的随机访问是 $O(n)$。如果先 `at(i)` 再 `insert`，总代价 $O(n)$，和 `vector` 的 $O(n)$ 相当甚至更慢（缓存不友好）。list 的优势在于持有迭代器时的 $O(1)$ 操作。
</Callout>

<Callout type="trap">
**误区：vector 扩容时忘记迭代器失效。**
`vector` 扩容会分配新内存、搬迁元素、释放旧内存。所有指向旧内存的迭代器、指针、引用全部失效。扩容后继续使用旧迭代器是未定义行为。`list` 的节点内存独立，插入删除不影响其他迭代器（除了被删节点本身）。
</Callout>

<Exercises>
**问题 1**：`vector` 的 `push_back` 为什么均摊 $O(1)$？用聚集法分析。

<Answer>
倍增策略下，$n$ 次 `push_back` 的扩容发生在 size=1,2,4,...,n/2 时。总搬迁代价 $= 1+2+4+\cdots+n/2 < n$。加上 $n$ 次普通插入代价 $n$，总代价 $< 2n$，均摊 $2n/n = O(1)$。关键在于倍增使扩容次数仅 $O(\log n)$，每次搬迁代价呈等比数列。
</Answer>

**问题 2**：什么场景用 `vector`，什么场景用 `list`？

<Answer>
用 `vector`：需要随机访问、尾部增删为主、关心缓存性能。用 `list`：频繁在已知位置（持有迭代器）插入删除、不需要随机访问、元素体积大。绝大多数场景优先 `vector`——连续内存的缓存友好性使实际性能常优于 `list`，即使理论复杂度相同。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="vector">
C++ STL 动态数组。连续内存 + 倍增扩容，push_back 均摊 O(1)，随机访问 O(1)，中间插入删除 O(n)。
</GlossaryItem>
<GlossaryItem term="list">
C++ STL 双向链表。分散内存 + 指针串联，已知位置插入删除 O(1)，随机访问 O(n)。
</GlossaryItem>
<GlossaryItem term="迭代器失效">
容器操作导致迭代器指向无效内存的现象。vector 扩容/插入/删除会使相关迭代器失效；list 只有被删节点的迭代器失效。
</GlossaryItem>
<GlossaryItem term="缓存友好性">
连续内存布局对 CPU 缓存友好的特性。vector 的连续内存使缓存命中率高，实际性能常优于理论复杂度更优但缓存不友好的 list。
</GlossaryItem>
</Glossary>
