## 从“树快不快取决于高度”开始

tree preliminaries（）先建立成本坐标。树操作通常沿一条 root-to-node path 前进，时间取决于 height h，而不是只取决于节点数 N。

先预测把1到10000按升序插入普通 BST。每个新 key 都落在最右侧，树退化成 linked list，最后一次 search 走近10000层；若保持平衡，height 约为 log2 10000，小于14。写“BST search O(log N)”而不附 balance condition 是错误的。

官方八节依次为 **Tree Preliminaries、Binary Trees、Binary Search Trees、AVL Trees、Splay Trees、Tree Traversals、B-Trees、Sets and Maps in the Standard Library**。它们不是八种互斥容器，而是从通用层次结构逐步加入 arity、ordering、balance、access adaptation 与 storage-page constraints。


## 4.1 Preliminaries

root 没有 parent；除 root 外每个 node 恰有一个 parent；从 ancestor 到 descendant 的 edges 构成 path。node depth 是从 root 到它的 edge 数，tree height 是最深 node 的 depth。leaf 没有 children，subtree 由某 node 及全部 descendants 构成。

含 N 个 nodes 的 tree 恰有 N-1 条 parent-child edges。证明可从“除 root 外每个 node 各贡献一条 incoming edge”得到。这个关系用于检查 clone、serialize 和 deletion 是否丢边或成环。

## 4.2 Binary Trees

binary trees（）的左右位置有语义，即使只有一个 child 也要区分 left/right。height 为 h 的 binary tree：

$$
h+1 \le N \le 2^{h+1}-1
$$

左边是完全退化链，右边是每层填满的 full tree。反推任意 N-node binary tree 的最小可能 height 约为 log2 N，最大为 N-1。


binary expression tree 的 leaves 是 operands，internal nodes 是 operators；filesystem tree 通常不限两个 children，需要 first-child/next-sibling 或 child vector。树的 shape 与 node payload 是两个维度。

## 4.3 The Search Tree ADT — Binary Search Trees

binary search trees（）把 comparison result 转成 path direction。第3版默认忽略 duplicate；若需要 multiset，必须把 count 或 tie policy 写入 invariant。


官方 `BinarySearchTree.h` 用 `BinaryNode*& t` 让递归 helper 能改写 parent 的 child pointer：

```cpp
void insert(const Comparable& x, BinaryNode*& t) {
    if (t == nullptr)
        t = new BinaryNode{x, nullptr, nullptr};
    else if (x < t->element)
        insert(x, t->left);
    else if (t->element < x)
        insert(x, t->right);
}
```

deletion 分三种：

1. leaf 直接删除并置 null；
2. one child 让 parent link 绕过旧 node；
3. two children 用 right subtree minimum 替换当前 key，再删除那个 successor。

```cpp
if (t->left && t->right) {
    t->element = findMin(t->right)->element;
    remove(t->element, t->right);
} else {
    BinaryNode* old = t;
    t = t->left ? t->left : t->right;
    delete old;
}
```

replacement 必须来自 right minimum 或 left maximum，才能保持两侧 ordering。copy assignment 先 `makeEmpty`，再递归 `clone`，确保两个 tree 不共享 nodes。


## 4.4 AVL Trees

AVL trees（）在 node 中保存 height。一次 insertion 先按 BST path 递归，再沿返回路径更新 height，找到第一个 imbalance。


若新 key 插入 left-left 或 right-right，single rotation；left-right 或 right-left，double rotation。rotation 必须同时保持 inorder key sequence 和重新计算受影响 nodes 的 heights。

最少节点数 S(h) 满足：

$$
S(h)=S(h-1)+S(h-2)+1
$$

取空树高度为 -1、单节点高度为 0，则边界条件与第一次展开是：

$$
S(-1)=0,\qquad S(0)=1,\qquad S(1)=2
$$

它按 Fibonacci 速度增长，所以 h=O(log N)。search/insert worst-case logarithmic。忠实于第3版官方代码要注意：该 `AvlTree.h` 的 insertion 完整实现，但 `remove` 明确仍是 unimplemented；本章不能把删除代码假装成原书示例已提供。

## 4.5 Splay Trees

splay trees（）允许单次操作 O(N)，但任意足够长操作序列的 amortized cost 是 O(log N)。重复访问热点 key 时，它会停在靠近 root 的位置。


zig 是 parent 为 root 的单旋；zig-zig 对同方向祖孙做两次同向旋转；zig-zag 对相反方向做两次相反旋转。第3版后续完整实现采用 top-down splay：搜索时把较小/较大 fragments 暂存在 header 两侧，最后一次性重组。

Splay 适合 access locality、无需每 node height/color metadata；却不适合要求每次 operation latency 都有 logarithmic worst-case 的场景。amortized guarantee 不是 per-operation guarantee。

## 4.6 Tree Traversals Revisited

tree traversals（）把 recursive structure 映射成线性序列：

- preorder：root、left、right，适合复制/前缀表示；
- inorder：left、root、right，BST 输出 sorted keys；
- postorder：left、right、root，适合释放 subtree；
- level order：按 depth，用 Queue 做 BFS。


官方 BST `printTree` 用 inorder；`makeEmpty` 用 postorder，必须先释放 children 再 delete parent。若先删 parent 再读取 child pointers，会 use-after-free。

```cpp
void makeEmpty(BinaryNode*& t) {
    if (t != nullptr) {
        makeEmpty(t->left);
        makeEmpty(t->right);
        delete t;
    }
    t = nullptr;
}
```

recursive traversal 时间 Θ(N)，额外 stack 是 O(h)。对退化树 h=N，递归销毁也可能 stack overflow；这是 tree shape 与 implementation strategy 的共同风险。

## 4.7 B-Trees

B-trees（）针对外部存储。binary tree node 只含一个 key，随机读取一条 path 会触发许多 page I/O；B-Tree 让一个 page 装 m-1 keys 与最多 m children，一次 I/O 排除更大范围。


除 root 外节点至少半满；所有 leaves 位于同一 depth。insert 向 leaf 前进，full page split 并把 separator 提升 parent；delete 若 underflow，则从 sibling borrow 或 merge。高度约：

$$
O(\log_m N)
$$

fanout m 由 page size、key/pointer width 与 fill policy 决定。单纯增大 m 会增加 page 内 search cost，但通常可用 binary search；最重要的是减少慢层级访问。

## 4.8 Sets and Maps in the Standard Library

标准库set与map（）通常由平衡搜索树实现，但标准只承诺 observable semantics 与 complexity，不承诺一定是某种红黑树布局。

`set<Key>` 只保存 unique key；`map<Key,Value>` 的 iterator dereference 得到 pair，key 是 const，value 可改。ordered iteration 依据 comparator，而不是 insertion order。


官方 `mapDemo.cpp` 演示了一个重要副作用：`salaries["Jan"]` 在 key 不存在时插入 default `double{}`，即0；只读存在性查询应使用 `find` 或现代 `contains`。在 const map 上也没有 mutating `operator[]`。

## 本章回顾

1. Tree operation cost 通常由 height 控制，N 相同的不同 shape 可差一个数量级。
2. Binary tree 每 node 至多两个 ordered children，height 介于 log N 和 N-1。
3. BST ordering 支持定向 search；two-child deletion 用 successor/predecessor 保持顺序。
4. 普通 BST 无平衡保证，sorted insertion 会退化。
5. AVL 通过四类 rotation 保持 balance factor，给出 worst-case logarithmic height。
6. Splay 把 accessed node 移到 root，提供 amortized 而非每次 logarithmic。
7. Inorder 输出 BST sorted keys，postorder 适合安全释放。
8. B-Tree 用 page-sized multiway nodes 降低外存 I/O path。
9. std::set/map 承诺 ordered associative semantics；map operator[] 会插入缺失 key。
