## 直觉引入

想象你在用导航软件规划路线。城市是节点，公路是边，你要找从 A 到 B 的最短路径——这就是图算法解决的核心问题。

图是数据结构中最通用的结构：树是图的特例（无环连通图），链表是退化的树。图的算法远比线性表复杂，因为节点间可以任意连接，形成环和交叉路径。

本章覆盖四大经典图算法：遍历（BFS/DFS）、最短路径（Dijkstra）、最小生成树（Prim/Kruskal）、拓扑排序。它们是面试和工程中的高频考点。

## 概念讲解

### 图的表示

<DsaGraphAlgsDiagram />

<Term def="邻接矩阵用 n×n 二维数组存储边，matrix[i][j]=1 表示有边 i→j，查边 O(1) 但空间 O(V²)">
邻接矩阵
</Term>

<Term def="邻接表为每个顶点维护一个链表/向量，存储其所有邻居，空间 O(V+E) 适合稀疏图">
邻接表
</Term>

| 表示法 | 空间 | 查边 | 遍历邻居 | 适用场景 |
|---|---|---|---|---|
| 邻接矩阵 | $O(V^2)$ | $O(1)$ | $O(V)$ | 稠密图、频繁查边 |
| 邻接表 | $O(V+E)$ | $O(\deg(v))$ | $O(\deg(v))$ | 稀疏图、大多数场景 |

实际工程中绝大多数图是稀疏的（边数远小于 $V^2$），因此邻接表更常用。

### BFS 与 DFS

<Term def="广度优先搜索用队列逐层扩展，先访问起点，再访问所有邻居，再访问邻居的邻居">
BFS（广度优先搜索）
</Term>

BFS 用队列实现，天然适合求**无权图最短路径**：第一次到达目标节点的层数就是最短距离。

<Term def="深度优先搜索用栈/递归沿一条路走到底再回溯，适合连通性判断和拓扑排序">
DFS（深度优先搜索）
</Term>

DFS 用递归（隐式栈）实现，适合连通性判断、环检测、拓扑排序。两者的时间复杂度均为 $O(V+E)$。

### Dijkstra 最短路径

Dijkstra 算法用贪心策略求**非负权图**的单源最短路径：每次从未确定节点中选距离最小的，确定其最短路径，再用它松弛邻居。

<Stepper>
<Step title="初始化">
源点距离设 0，其余设 $\infty$。所有节点放入优先队列（最小堆）。
</Step>
<Step title="取最小节点">
从优先队列取出距离最小的节点 u，标记为已确定。
</Step>
<Step title="松弛操作">
对 u 的每条边 (u,v,w)：若 $dist[u] + w < dist[v]$，更新 $dist[v]$ 并入队。
</Step>
<Step title="重复直到队列空">
所有节点确定后，dist 数组即为源点到各点的最短距离。总复杂度 $O((V+E)\log V)$。
</Step>
</Stepper>

### 最小生成树

<Term def="最小生成树是连通无向图中权值之和最小的生成树，包含所有顶点的子图且无环">
最小生成树（MST）
</Term>

- **Prim**：从一个点出发，每次选最小权边连接新顶点（贪心扩展，适合稠密图，$O(V^2)$）
- **Kruskal**：所有边排序，逐条加入（用并查集判环，适合稀疏图，$O(E\log E)$）

### 拓扑排序

拓扑排序对**有向无环图（DAG）**的顶点排成线性序列，使所有有向边从前指向后。用 DFS 逆后序或 BFS（Kahn 算法，每次取入度为 0 的节点）实现。

## 代码对照

```cpp
#include <vector>
#include <queue>
#include <climits>
using namespace std;

// 邻接表表示：pair<邻居, 权值>
using Graph = vector<vector<pair<int,int>>>;

// Dijkstra 最短路径（非负权图）
vector<int> dijkstra(const Graph& g, int src) {
    int n = g.size();
    vector<int> dist(n, INT_MAX);
    // 最小堆：pair<距离, 节点>
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;

    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        // 延迟删除：旧的最小值可能还在堆里
        if (d > dist[u]) continue;

        for (auto [v, w] : g[u]) {
            // 松弛操作：经 u 到 v 是否更短？
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

// BFS 求无权图最短路径
vector<int> bfs(const Graph& g, int src) {
    int n = g.size();
    vector<int> dist(n, -1);
    queue<int> q;

    dist[src] = 0;
    q.push(src);

    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (auto [v, w] : g[u]) {
            if (dist[v] == -1) {  // 未访问
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    return dist;
}
```

## 常见误区

<Callout type="trap">
**误区：Dijkstra 可以处理负权边**
Dijkstra 的贪心假设是「已确定最短路径的节点不会被后续更新」。一旦存在负权边，后续路径可能更短，导致已确定节点需要重新处理——这破坏了算法正确性。有负权边时必须用 Bellman-Ford（$O(VE)$）。
</Callout>

<Callout type="trap">
**误区：BFS 适用于带权图的最短路径**
BFS 逐层扩展，隐含「每条边权值相同」的假设。带权图的最短路径必须用 Dijkstra（非负权）或 Bellman-Ford（含负权）。用 BFS 求带权图最短路径会得到错误结果。
</Callout>

<Callout type="trap">
**误区：拓扑排序可以对有环图进行**
拓扑排序的前提是 DAG（有向无环图）。如果图中有环，环内节点互相依赖，无法排成线性序列。Kahn 算法中，如果输出节点数 < 总节点数，说明存在环。
</Callout>

<Exercises>
**问题 1**：Dijkstra 算法不能处理负权边，根本原因是什么？

<Answer>
Dijkstra 的核心是贪心：每次取距离最小的未确定节点，标记为「已确定最短路径」后不再修改。这个贪心选择在非负权图上正确（后续路径只会更长）。但负权边可能使后续路径更短，已确定节点需要更新——贪心失效。Bellman-Ford 通过反复松弛所有边（V-1 轮）来正确处理负权边。
</Answer>

**问题 2**：有 $V$ 个顶点 $E$ 条边的稀疏图，应该用邻接矩阵还是邻接表？

<Answer>
邻接表。稀疏图 $E \ll V^2$，邻接矩阵空间 $O(V^2)$ 大量浪费。邻接表空间 $O(V+E)$ 更省，且遍历邻居 $O(\deg(v))$ 而非 $O(V)$。BFS/DFS 的 $O(V+E)$ 也只有在邻接表下才高效。邻接矩阵仅适合稠密图或频繁 $O(1)$ 查边的场景。
</Answer>

**问题 3**：Prim 和 Kruskal 分别适合什么类型的图？

<Answer>
Prim 适合稠密图（$E \approx V^2$）：从单点扩展，用数组维护最小边 $O(V^2)$，不受边数影响。Kruskal 适合稀疏图（$E \ll V^2$）：排序边 $O(E\log E)$ + 并查集判环 $O(E\alpha(V))$，边数少时高效。两者都产生正确的 MST，区别在于常数因子。
</Answer>

**问题 4**：Kahn 算法（BFS 拓扑排序）如何检测图中是否有环？

<Answer>
Kahn 算法维护入度数组，每次取入度为 0 的节点入队并对其邻居入度减 1。如果最终输出的节点数等于总顶点数，则无环；如果小于总顶点数，说明有节点始终入度 >0——即存在环，环上节点互相依赖，无法入队。这是检测 DAG 中环的标准方法。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="邻接矩阵">
用 $V \times V$ 的二维数组表示图，`matrix[i][j]` 存储边的信息。查边 $O(1)$ 但空间 $O(V^2)$，适合稠密图。
</GlossaryItem>
<GlossaryItem term="邻接表">
每个顶点维护一个链表/向量存储其邻居。空间 $O(V+E)$，遍历邻居 $O(\deg(v))$，适合稀疏图，是实际中最常用的图表示法。
</GlossaryItem>
<GlossaryItem term="松弛操作">
在 Dijkstra/Bellman-Ford 中，检查经中间节点 u 到 v 是否比当前已知路径更短（`dist[u]+w < dist[v]`），若是则更新。松弛是最短路径算法的核心原语。
</GlossaryItem>
<GlossaryItem term="拓扑排序">
将有向无环图（DAG）的顶点排成线性序列，使所有有向边从前指向后。可用 DFS 逆后序或 Kahn 算法（BFS 取入度 0 节点）实现，$O(V+E)$。
</GlossaryItem>
</Glossary>
