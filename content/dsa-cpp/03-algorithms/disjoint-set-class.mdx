## 从“只合并，不拆分”的动态分区开始

等价关系（）描述“属于同一组”。对所有元素 a、b、c：

$$
a\sim a,\qquad
a\sim b\Rightarrow b\sim a,\qquad
a\sim b\land b\sim c\Rightarrow a\sim c
$$

先预测已知0与1等价、1与2等价后，是否还要显式存储0与2的边。Transitivity 已经要求答案为 true；并查集不保存完整 relation matrix，只维护每个 equivalence class 的 representative。

官方七节依次为 **Equivalence Relations、The Dynamic Equivalence Problem、Basic Data Structure、Smart Union Algorithms、Path Compression、Worst Case for Union-by-Rank and Path Compression、An Application**。本章保持从数学 contract 到实现 heuristic，再到严格复杂度和应用的顺序。


## 8.1 Equivalence Relations

一个 equivalence relation 唯一诱导 partition：每个 element 恰属于一个 class，不同 classes 不相交。反过来，任何 partition 也定义 relation：两元素等价当且仅当处于同一 block。

元素 x 的 equivalence class 定义为：

$$
[x]=\{y\mid y\sim x\}
$$

这解释了 API 为什么只需 `find(x)` 返回 representative，和 `union(a,b)` 合并两个 classes。Representative 的具体编号没有业务意义；不同 union order 可选择不同 root，但 `find(a)==find(b)` 的 partition semantics 应一致。

## 8.2 The Dynamic Equivalence Problem

动态等价问题（）包含两个 operations：

- `union(a,b)`：把包含 a、b 的两个 classes 合并；
- `find(x)`：返回 x 当前 class 的 name/root，据此判断两元素是否 connected。


它不是完全动态 connectivity：不支持删除 relation 或 split class。若业务需要断边、回滚或历史版本，需要 rollback DSU、offline divide-and-conquer 或 dynamic graph data structure，不能从 parent tree 中随意剪边。

## 8.3 Basic Data Structure

并查集基本数据结构（）初始化 N 棵 singleton trees。最直白版本令 `parent[i]=i`；第3版 `DisjSets` 用负值表示 root，并把负值幅度用于 rank：

```cpp
explicit DisjSets(int count) : parent(count, -1) {}

int find(int x) const {
    if (parent[x] < 0) return x;
    return find(parent[x]);
}
```


不带 heuristic 时，`union(root1,root2)` 可简单让一个 root 指向另一个。N-1 次精心安排的 union 能造出 height N-1 chain，使 find O(N)。Array representation 紧凑，但性能完全取决于 tree shape。

官方实现明确假设 `unionSets` 收到两个 distinct roots，并省略 bounds/error checks。现代安全 wrapper 常先调用 find：

```cpp
bool unite(int a, int b) {
    int rootA = find(a);
    int rootB = find(b);
    if (rootA == rootB) return false;
    unionRoots(rootA, rootB);
    return true;
}
```


## 8.4 Smart Union Algorithms

智能合并算法（）有两种常见策略：

- union-by-size：smaller tree root 指向 larger tree root；
- union-by-rank：lower rank root 指向 higher rank root，rank 相等时任选新 root 并把 rank 加1。


若 rank 从0开始，rank 为 r 的 root 至少包含：

$$
2^r\ \text{elements}
$$

因为 rank 只在两棵相同 rank trees 合并时增加。因此 rank 至多 floor(log2 N)，单独使用 union-by-rank 就给出 O(log N) find。

第3版用 `s[root]` 的负数编码 rank：更负表示更深；相等时把新 root 再减1。这个值在加入 path compression 后不再等于真实 height，只是 monotonic upper-bound rank，不能在压缩后重新解释成精确树高。

## 8.5 Path Compression

路径压缩（）把一次昂贵 find 的路径改短：

```cpp
int find(int x) {
    if (parent[x] < 0) return x;
    return parent[x] = find(parent[x]);
}
```


Assignment 必须接收 recursive find 的 root，而不是只改成 grandparent 后错误终止。Compression 不改变 partition，也不要求更新 rank：rank 用于未来 root-to-root union 决策，不是实时 height。

可以用 iterative two-pass 避免深递归：第一遍找 root，第二遍沿原路径改 parent。若输入可能来自不可信 serialized state，还应检测 out-of-range parent 和 cycles，否则 find 可能无限循环。

## 8.6 Worst Case for Union-by-Rank and Path Compression

按秩合并与路径压缩最坏情形（）不是简单把两个 O(log N) 相加。对 N 个 elements、m 次 make/find/union operations，经典 bound 为：

$$
O\bigl(m\,\alpha(N)\bigr)
$$

其中 alpha 是 inverse Ackermann function，增长极慢，在任何可实际存储的 N 上都小于很小常数。严格说它不是字面 O(1) worst-case per operation；这是 sequence-level amortized result。


只用 path compression 而任意 union，或只用 union-by-rank 而不 compression，bound 和常数都不同。测试要分别关闭 heuristics，构造 chain、balanced merges 和重复 find，证明优化真正生效。

## 8.7 An Application

并查集应用（）的代表是 Kruskal minimum spanning tree：

1. 把 edges 按 weight 升序；
2. 若 `find(u)!=find(v)`，接受 edge 并 unite；
3. 若 roots 相同，拒绝 edge，因为它会在当前 forest 中成环；
4. 接受 V-1 条 edges 后结束。


```cpp
for (const Edge& edge : edgesByWeight) {
    if (sets.find(edge.u) == sets.find(edge.v))
        continue;
    tree.push_back(edge);
    sets.unite(edge.u, edge.v);
}
```

Sorting 成本 O(E log E)，DSU 部分约 O(E alpha(V))。若 graph 不连通，输出是 minimum spanning forest；不能在不足 V-1 条 edges 时仍宣称得到 spanning tree。

Randomized maze generation 也可把 cells 初始化为 singleton sets，随机选相邻墙；若两侧 roots 不同就拆墙并 union，直到全连通。DSU 保证不形成 cycle，从而生成 spanning tree maze。

## 本章回顾

1. Equivalence relation与partition互相定义，representative编号本身不属于业务语义。
2. Dynamic equivalence只支持classes合并和find，不支持split/delete。
3. Parent array把classes表示成rooted trees；naive union可退化成linear chain。
4. Union-by-size/rank把较小较浅tree挂到较大较深root，限制height。
5. Path compression在find返回时重写整条路径，不改变partition。
6. Rank在压缩后不是精确height。
7. 两种heuristics组合给出O(m alpha(N)) amortized sequence bound。
8. Kruskal用find拒绝成环edge，用union维护forest components。
