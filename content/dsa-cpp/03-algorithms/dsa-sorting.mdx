## 直觉引入

排序是计算机科学中最基本也最重要的算法。想象整理一手扑克牌：你会把每张牌插入到正确位置——这就是插入排序。但如果有两叠已经排好的牌，你会先合并它们——这就是归并排序的思想。

排序算法的设计体现了算法设计的核心思想：**分治**（归并、快排）、**贪心**（选择排序）、**增量构造**（插入排序）。理解排序算法是理解算法分析的起点。

## 概念讲解

### 算法全景

<DsaSortingDiagram />

### 插入排序

<Term def="插入排序将每个元素插入到已排序前缀的正确位置，类似整理扑克牌">
插入排序
</Term>

最坏/平均 $O(n^2)$，最好 $O(n)$（已排序）。对小数组（$n < 20$）非常高效，因为常数小且是**稳定排序**。C++ STL 的 `std::sort` 在分区到小数组时切换到插入排序。

### 归并排序

<Term def="归并排序用分治法将数组对半切分排序后合并，保证 O(n log n) 且稳定">
归并排序
</Term>

<Stepper>
<Step title="分割">
将数组对半切分，递归排序左半和右半。
</Step>
<Step title="合并">
用双指针将两个有序子数组合并为一个有序数组，$O(n)$。
</Step>
<Step title="复杂度">
分割 $\log n$ 层，每层合并 $O(n)$，总计 $O(n\log n)$。空间 $O(n)$（需临时数组）。稳定排序。
</Step>
</Stepper>

归并排序的**保证 $O(n\log n)$** 且稳定，但需要额外 $O(n)$ 空间。外部排序（数据放磁盘）的首选。

### 快速排序

<Term def="快速排序选一个基准值将数组分为小于和大于两部分，递归排序，平均 O(n log n) 但最坏 O(n²)">
快速排序
</Term>

快速排序的关键是**选基准（pivot）**：
- 固定选第一个/最后一个：有序数据退化为 $O(n^2)$
- 随机选择：期望 $O(n\log n)$，但最坏仍 $O(n^2)$
- 三数取中（median-of-three）：取首、中、尾的中位数，实践中效果好
- **内省排序（introsort）**：递归深度超过 $2\log n$ 时切换到堆排序，保证 $O(n\log n)$——这正是 C++ `std::sort` 的实现

### 堆排序

<Term def="堆排序先建最大堆，反复取堆顶（最大值）放到末尾，逐步缩小堆，原地 O(n log n)">
堆排序
</Term>

堆排序利用二叉堆的性质：①建堆 $O(n)$②每次取顶 + 下沉 $O(\log n)$，共 $n-1$ 次。总计 $O(n\log n)$，**原地排序**（空间 $O(1)$），但**不稳定**且缓存不友好（跳跃式访问）。

### 复杂度对比

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 插入排序 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 是 |
| 快速排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | $O(\log n)$ | 否 |
| 堆排序 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 否 |

## 代码对照

```cpp
#include <vector>
#include <algorithm>
using namespace std;

// 快速排序（三数取中 + 分区）
void quickSort(vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;

    // 小数组切换插入排序（优化常数）
    if (hi - lo < 16) {
        for (int i = lo + 1; i <= hi; i++) {
            int key = a[i], j = i - 1;
            while (j >= lo && a[j] > key) {
                a[j + 1] = a[j];
                j--;
            }
            a[j + 1] = key;
        }
        return;
    }

    // 三数取中选基准
    int mid = lo + (hi - lo) / 2;
    if (a[mid] < a[lo]) swap(a[lo], a[mid]);
    if (a[hi] < a[lo]) swap(a[lo], a[hi]);
    if (a[mid] < a[hi]) swap(a[mid], a[hi]);
    int pivot = a[hi];  // 中位数放末尾

    // Lomuto 分区
    int i = lo;
    for (int j = lo; j < hi; j++) {
        if (a[j] < pivot) {
            swap(a[i], a[j]);
            i++;
        }
    }
    swap(a[i], a[hi]);

    quickSort(a, lo, i - 1);
    quickSort(a, i + 1, hi);
}

// 归并排序
void mergeSort(vector<int>& a, vector<int>& tmp, int lo, int hi) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, tmp, lo, mid);
    mergeSort(a, tmp, mid + 1, hi);

    // 合并两个有序段
    int i = lo, j = mid + 1, k = lo;
    while (i <= mid && j <= hi) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi) tmp[k++] = a[j++];
    for (int x = lo; x <= hi; x++) a[x] = tmp[x];
}
```

## 常见误区

<Callout type="trap">
**误区：快速排序的最坏情况 O(n²) 在实践中很常见**
如果用三数取中或随机选基准，最坏情况出现的概率极低。C++ `std::sort` 用内省排序（introsort）：递归深度超过 $2\log n$ 时自动切换到堆排序，**保证** $O(n\log n)$。所以实际工程中 `std::sort` 几乎不会退化。
</Callout>

<Callout type="trap">
**误区：O(n log n) 的排序一定比 O(n²) 快**
对于小数组（$n < 16$），插入排序比快排/归并更快，因为常数小、无递归开销。这就是为什么 `std::sort` 在分区到小数组时切换到插入排序。算法复杂度只描述增长趋势，常数因子在小数据量时起决定性作用。
</Callout>

<Callout type="trap">
**误区：堆排序因为 O(n log n) 且原地，是最优排序**
堆排序虽然是 $O(n\log n)$ 原地排序，但实际比快排慢 2-3 倍。原因是堆的操作访问数组是跳跃式的（父→子索引 $2i, 2i+1$），缓存命中率极低。快排的分区是顺序访问，缓存友好。工程中堆排序主要用于优先队列，而非通用排序。
</Callout>

<Exercises>
**问题 1**：C++ `std::sort` 用的是什么排序算法？

<Answer>
内省排序（introsort）：以快速排序为主，三数取中选基准；递归深度超过 $2\log n$ 时切换到堆排序保证最坏 $O(n\log n)$；分区到小数组（通常 $n < 16$）时切换到插入排序优化常数。这三种算法的组合使 `std::sort` 在各种数据分布下都有优秀表现。
</Answer>

**问题 2**：为什么归并排序是稳定的，而快速排序不是？

<Answer>
归并排序合并时，当两个元素相等时先取左半的（`a[i] <= a[j]`），保证相等元素的相对顺序不变。快速排序的分区操作会交换不相邻元素，相等元素的相对顺序可能被打乱。稳定性取决于相等元素是否可能被跨越式交换。
</Answer>

**问题 3**：对几乎已排序的数组，哪种排序最优？

<Answer>
插入排序最优。已排序数据下插入排序只需比较 $n-1$ 次（每个元素发现已在正确位置），时间 $O(n)$。而快排在三数取中下虽不退化但仍是 $O(n\log n)$。归并排序也是 $O(n\log n)$。因此对接近有序的数据，插入排序（或 Timsort，它就是插入+归并的混合）是最优选择。
</Answer>

**问题 4**：外部排序（数据在磁盘上）为什么用归并排序？

<Answer>
外部排序的数据量超过内存，无法全部加载。归并排序的分治结构天然适合：①将数据分块读入内存排序后写回②对有序块进行多路归并。每路归并只需顺序读写（磁盘友好），且归并是稳定的。快排/堆排需要随机访问，在磁盘上性能极差。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="插入排序">
将每个元素逐个插入到已排序前缀的正确位置。最好 $O(n)$，最坏 $O(n^2)$，稳定。小数组下常数最小，是快排/归并的基础情形。
</GlossaryItem>
<GlossaryItem term="归并排序">
分治法：对半切分排序后合并。保证 $O(n\log n)$ 且稳定，但需 $O(n)$ 额外空间。外部排序和链表排序的首选。
</GlossaryItem>
<GlossaryItem term="内省排序">
C++ `std::sort` 的实现策略：快排为主 + 深度超限时切堆排 + 小数组切插入排序。综合三者优势，保证 $O(n\log n)$ 最坏复杂度且常数优秀。
</GlossaryItem>
<GlossaryItem term="稳定性">
排序后相等元素的相对顺序是否保持不变。稳定排序允许按多关键字排序（先按次要关键字排，再按主要关键字排）。归并、插入稳定；快排、堆排不稳定。
</GlossaryItem>
</Glossary>
