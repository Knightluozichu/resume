## 从“先确认图的语义，再运行算法”开始

图的定义（<Term def="以vertices和edges表示关系，并明确direction、weight、path、cycle、degree与connectivity。">图的定义</Term>）决定算法是否适用。同一组 endpoints，在 directed graph 中可达性不对称；在 weighted graph 中最少 edges 不一定是最短 distance；负 edge 又会破坏 Dijkstra 的 greedy finalization。

先预测 A 到 B 权重2、A 到 C 权重5、B 到 C 权重1。按 edge count，A-C 一步最短；按 weight，A-B-C 成本3更短。若需求只写“shortest”，实现无法判断优化的是 hops、distance、time 还是风险。

官方七节依次为 **Definitions、Topological Sort、Shortest-Path Algorithms、Network Flow Problems、Minimum Spanning Tree、Applications of Depth-First Search、Introduction to NP-Completeness**。它们从 graph model 和 traversal 逐步进入优化问题，最后说明哪些问题不应期待已知 polynomial exact algorithm。

## 9.1 Definitions

令 graph G=(V,E)。Undirected edge `{u,v}` 可双向走；directed edge `(u,v)` 只从 u 到 v。Path 是相邻 edges 连接的 vertex sequence，simple path 不重复 vertices；cycle 从某 vertex 出发并返回。Directed acyclic graph 简称 DAG。

Sparse graph 通常用 adjacency list，storage 为：

$$
O(|V|+|E|)
$$

Matrix 用 O(V²) space，查询任意 edge O(1)，适合 dense graph 或 bitset operations。Adjacency list traversal 的 BFS/DFS 为 O(V+E)，前提是每条 edge只被常数次处理。

<DsaGraphDefinitionsLab />

实现要决定 vertex identity、parallel edges、self-loops、missing vertex 和 numeric overflow。Distance 加 weight 前若 lhs 是 infinity sentinel，会 overflow；大型权重也不应挤进过窄 integer。

## 9.2 Topological Sort

拓扑排序（<Term def="对DAG输出linear order，使每条directed edge u到v都满足u先于v。">拓扑排序</Term>）用于 build dependencies、course prerequisites 和 task scheduling。Kahn algorithm 维护 in-degree：

```cpp
queue<Vertex> ready;
for (Vertex v : vertices)
    if (indegree[v] == 0) ready.push(v);

while (!ready.empty()) {
    Vertex u = ready.front();
    ready.pop();
    order.push_back(u);
    for (Vertex v : outgoing[u])
        if (--indegree[v] == 0) ready.push(v);
}
```

<DsaTopologicalSortLab />

若输出数少于 V，剩余 subgraph 含 directed cycle，不存在 topological order。多个 zero-in-degree vertices 意味着结果不唯一；需要 deterministic build 时，用 min-heap 或固定 ordering 选择 ready vertex。

DFS 也可按 finish time 逆序生成 topological order，但必须用 gray/active state 检测 back edge。只用 visited boolean 会把 cycle 漏成一个看似合法 sequence。

## 9.3 Shortest-Path Algorithms

最短路径算法（<Term def="依据edge-weight前提，通过relaxation求source到vertices的minimum path cost与parent证据。">最短路径算法</Term>）共享 relaxation：

$$
d[v]\leftarrow \min\bigl(d[v],\,d[u]+w(u,v)\bigr)
$$

但 worklist 与 finalization 条件不同：

- unweighted graph：BFS FIFO queue，第一次发现给出最少 hops，O(V+E)；
- nonnegative weights：Dijkstra min-priority queue，extract-min vertex 可 finalized；
- DAG：按 topological order relax，即使有 negative edges 也可 O(V+E)；
- general negative edges：Bellman-Ford 做 V-1 rounds，并用额外 round 检测 reachable negative cycle。

<DsaShortestPathLab />

```cpp
while (!queue.empty()) {
    auto [distance, u] = queue.top();
    queue.pop();
    if (distance != best[u]) continue;
    for (const Edge& edge : graph[u])
        if (relax(u, edge.to, edge.weight))
            queue.push({best[edge.to], edge.to});
}
```

这段 lazy Dijkstra 用 duplicate entries 替代 decrease-key；只在 all weights nonnegative 时正确。Parent pointers 应能重建 path，并满足每条 selected parent edge 的 distance equation。

<Callout type="trap" title="Dijkstra遇到negative edge继续跑">
Dijkstra把当前minimum标为final依赖未来paths不会再降低它。Negative edge能从较远vertex把已settled distance拉低；程序可能结束且数字貌似合理，却不是shortest path。
</Callout>

Unreachable vertex 保持 infinity；negative cycle reachable 时不存在有限 shortest distance，不能只返回最后一轮数组。

## 9.4 Network Flow Problems

网络流问题（<Term def="在directed capacity network中满足capacity与flow conservation，并最大化source到sink总流量。">网络流问题</Term>）给每条 edge capacity c(u,v)，flow 满足：

$$
0\le f(u,v)\le c(u,v),\qquad
\sum_u f(u,x)=\sum_v f(x,v)
$$

对 source/sink 之外每个 vertex 都守恒。Residual network 的 forward residual 是 c-f，reverse residual 是 f；reverse edge 允许后续 augmenting path 撤销早期决策。

<DsaResidualFlowLab />

Ford-Fulkerson 反复找 source-to-sink augmenting path，并增加 path 上最小 residual capacity。Integral capacities 下得到 integral flow；用 BFS 选最短 augmenting path 是 Edmonds-Karp，给出 polynomial O(VE²) bound。

Max-flow min-cut theorem 提供 certificate：没有 augmenting path 时，从 source 在 residual graph 可达的 set S 与其余 vertices 构成 cut，cut capacity 等于 flow value。验收不只看一个数字，还要验证 capacity、conservation 和 cut equality。

## 9.5 Minimum Spanning Tree

最小生成树（<Term def="在connected undirected weighted graph中连接所有vertices、无cycle且总edge weight最小的tree。">最小生成树</Term>）与 shortest-path tree 不同。MST 最小化整棵 tree 的 total weight，不保证 source 到每个 vertex 的 path 最短。

Kruskal 按 weight 扫 edges，用 disjoint sets 拒绝 cycle；Prim 从当前 tree 到外部的 crossing edges 中取最轻。两者都基于 cut property：对任意 cut，跨越它的 minimum-weight edge 是某棵 MST 的 safe choice。

<DsaMinimumSpanningTreeLab />

Kruskal 主要成本 O(E log E) sorting；Prim 用 binary heap 和 adjacency list 是 O(E log V)。Disconnected graph 输出 minimum spanning forest，不是 spanning tree。Equal weights 可能产生多棵不同但同总重 MST。

## 9.6 Applications of Depth-First Search

深度优先搜索应用（<Term def="利用DFS forest、discovery/finish time与low-link信息分析cycles、components和critical structure。">深度优先搜索应用</Term>）不止“访问所有 nodes”：

- undirected connected components 与 cycle detection；
- articulation points 和 biconnected components；
- directed strongly connected components；
- Euler circuits/trails；
- topological sort 与 directed cycle detection。

<DsaDfsApplicationsLab />

对 undirected DFS tree，low(v) 是 v subtree 通过 zero or more tree edges 加最多一条 back edge 能到达的最早 discovery time：

$$
\operatorname{low}(v)=\min\left(
\operatorname{disc}(v),
\operatorname{disc}(w)_{\text{back edge}},
\operatorname{low}(child)
\right)
$$

Non-root vertex v 若存在 child c 使 `low(c) >= disc(v)`，v 是 articulation point；root 则需至少两个 DFS children。Undirected graph 遇到 parent edge 时不能误判成 back edge。

```cpp
disc[u] = low[u] = ++clock;
for (Vertex v : adjacent[u]) {
    if (disc[v] == 0) {
        dfs(v, u);
        low[u] = std::min(low[u], low[v]);
        if (parent != none && low[v] >= disc[u])
            articulation[u] = true;
    } else if (v != parent) {
        low[u] = std::min(low[u], disc[v]);
    }
}
```

SCC 算法可用两遍 DFS 的 Kosaraju，或一遍 DFS stack 的 Tarjan。无论哪种，component output 应验证 component 内 mutual reachability，component condensation graph 必须是 DAG。

## 9.7 Introduction to NP-Completeness

NP完全性简介（<Term def="区分polynomial solvability、polynomial verification与NP-hard reductions，识别NP-complete decision problems。">NP完全性简介</Term>）首先区分 decision 与 optimization。P 是能在 polynomial time 求解的 decision problems；NP 是给定 certificate 后能在 polynomial time 验证 yes answer 的 problems。

Problem X 是 NP-complete，需要：

1. X 属于 NP；
2. 一个已知 NP-complete problem Y 可在 polynomial time 归约到 X。

<DsaNpCompletenessLab />

归约方向是 `Y <=p X`：若能快速解 X，就能通过转换快速解 Y，因此 X 至少和 Y 一样难。把 X 归约到 Y 只能说明 X 不比 Y 更难，不能证明 X NP-hard。

<Callout type="trap" title="归约方向写反">
证明新问题hard时，要把known-hard instances变成new-problem instances，并保持yes/no。画出“known solver借助new solver”的调用方向，再写转换，避免只凭题目相似性声称NP-complete。
</Callout>

NP-complete 不等于“小输入绝对不能解”。工程上可用 exact exponential search、branch-and-bound、parameterized algorithms、approximation 或 heuristics；必须清楚声明 optimality 与 failure guarantees。

## 本章回顾

1. Graph direction、weight与path objective必须在选择算法前固定。
2. Adjacency list让sparse graph遍历达到O(V+E)。
3. Topological order只存在于DAG，输出不足V是cycle certificate。
4. BFS、Dijkstra、DAG relaxation和Bellman-Ford分别对应不同weight前提。
5. Residual reverse edges让max-flow撤销旧flow，min-cut给出最优certificate。
6. MST最小化总tree weight，不是source shortest paths。
7. DFS discovery/finish/low-link支持SCC、articulation和Euler结构分析。
8. NP-complete证明要求in NP加known-hard到new problem的polynomial reduction。

<Exercises>

**问题 1：Kahn算法结束只输出V-2个vertices说明什么？**

<Answer>剩余subgraph中每个vertex都有positive in-degree，因此包含directed cycle；graph不是DAG，不存在完整topological order。已输出prefix仍满足其已处理edges，但不能冒充完整结果。</Answer>

**问题 2：有negative edge但无negative cycle时该选什么shortest-path算法？**

<Answer>若graph是DAG，可按topological order linear relaxation；一般directed graph可用Bellman-Ford。Dijkstra不适用，因为settled vertex可能被后来的negative edge降低。</Answer>

**问题 3：capacity 8、current flow 3的edge在residual graph中两方向capacity是多少？**

<Answer>Forward residual是8-3=5，reverse residual是3。Forward还能增加最多5，reverse可撤销最多3的既有flow。</Answer>

**问题 4：为什么把new problem归约到SAT不能证明new problem NP-hard？**

<Answer>该方向只说明若有SAT solver就能解new problem，即new problem不比SAT更难。要证明new problem至少同样难，应把已知NP-complete problem如SAT归约到new problem。</Answer>
