## 为什么需要一张地图

学 C++ 容易卡在两个坎上：一是语法本身不少，变量、类型、控制流、函数、类一层叠一层；二是 C++ 的知识有严格的依赖关系，函数是类的基础，类是继承的基础，模板需要类型系统知识。两件事搅在一起容易顾此失彼。

高桥麻奈的《Easy C++（第5版）》给了一条清晰的路：先写控制台程序练语法，再用类组织数据与行为，最后接触模板与标准库。这张地图帮你提前看清全貌，知道现在在哪、下一步去哪。

## 三大板块一览

全书 10 章分三大板块，对应三段递进：

- **C++ 入门（4 章）**：学习路线图、第一个 C++ 程序、变量与类型、控制流。目标是建立「用 C++ 表达逻辑」的能力，全在控制台里跑，不被复杂结构干扰。
- **类与对象（3 章）**：函数、类与对象、继承与多态。引入面向对象编程，学会用类组织数据与行为，用继承复用代码，用多态统一接口。
- **STL 与进阶（3 章）**：模板入门、STL 入门、总复习。接触泛型编程与标准库工具，学会用 `vector`、`string`、`sort` 等现成设施提效。

<Callout type="tip">
三段别跳。类里的成员函数就是函数，继承要用类，模板和 STL 容器是类模板。语法地基越牢，后面组装越顺。
</Callout>

## 日系入门教材的风格

本书作为日系入门 C++ 教材，风格通俗易懂、图解丰富。几乎每个知识点都配示意图，把抽象的内存布局、控制流走向、类与对象关系画出来。从最简单的 `cout` 输出开始，一章只引入一组概念，每章都有可运行的示例代码，学完就能动手试。篇幅精简，只讲最核心的 C++ 子集，适合快速建立全局认知。

<Term def="从零开始建立 C++ 语法基础、再用类组织结构、最后用标准库提效的三段递进学习法">三段递进</Term>

## 推荐学习路径

按依赖关系走，先打地基再盖楼：

```
第 1 站  学习路线图      ← 先看清全貌（本章）
第 2 站  第一个 C++ 程序 ← 写出能运行的代码
第 3 站  变量与类型      ← C++ 地基的第一块砖
第 4 站  控制流          ← 让程序能判断、能循环
第 5 站  函数            ← 把逻辑拆成可复用单元
第 6 站  类与对象        ← 用对象组织数据与行为
第 7 站  继承与多态      ← 复用代码、统一接口
第 8 站  模板入门        ← 一份代码多种类型
第 9 站  STL 入门        ← 用标准库提效
第 10 站 总复习          ← 串联全书
```

<Callout type="trap">
<strong>现象 →</strong> 跳过函数和类直接学 STL，看不懂 `vector` 的模板参数和迭代器。<strong>原因 →</strong> STL 容器是类模板，算法以迭代器为参数，没有类和模板的基础就像带着语法盲区读文章。<strong>修法 →</strong> 按三段顺序学习，每段扎实再进下一段。
</Callout>

## 小结与练习

全书主线一句话：先用 C++ 写逻辑，再用类组织结构，最后用 STL 提效。三段结构不是随意编排，而是「语法 → 对象 → 库」的依赖链。
