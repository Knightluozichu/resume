## 为什么全书地图必须服从官方 16 课

《やさしいC++ 第5版》的官方目录从 Lesson 1「はじめの一歩」一路推进到 Lesson 16「ファイルの入出力」。它不是“基础、OOP、STL”三个模糊主题的合集：表达式与运算符、函数、指针、数组、大规模程序、各种类型、类的连续四课以及文件 I/O 都有独立责任。

<Term def="由出版社目录确认的 16 个 Lesson 及其先后关系，学习地图、正文和复习题都以它作为结构基线。">官方课序</Term>

旧地图只有第一个程序、变量、控制流、函数、类、继承、模板和 STL，既合并了关键课，也把非官方独立章节当成主线。新路线保留原书核心进阶关系：先证明代码如何变成结果，再证明路径如何执行，接着证明数据如何存在，最后证明对象和持久记录如何保持有效。

## 第一阶段：Lesson 1–4 建立可重复的程序实验

Lesson 1 建立编辑、保存、编译、运行与观察的闭环；Lesson 2 解释 `main`、语句、`cout`、`cin` 与注释；Lesson 3 把输入和中间结果放进有类型、范围与初始化状态的变量；Lesson 4 再研究表达式、算术/赋值运算符、优先级与类型转换。

<Term def="从修改源代码开始，经编译与运行取得结果，再用预期和实际差异修正解释的可重复过程。">程序实验闭环</Term>

这一阶段的最小作品不是“Hello World 截图”，而是一份实验表：改动是什么、预计编译是否通过、预计输出是什么、实际结果是什么、差异由语法错误、类型规则还是需求错误造成。相同源码必须从干净产物重建，避免把旧可执行文件当作新代码结果。

```bash
c++ -std=c++17 -Wall -Wextra lesson.cpp -o lesson
./lesson
```

## 第二阶段：Lesson 5–7 从路径枚举到函数契约

Lesson 5 用关系和逻辑运算符表达条件，以 `if` 与 `switch` 覆盖互斥路径；Lesson 6 用 `for`、`while`、`do while` 表达重复，并要求每轮都向终止条件推进；Lesson 7 用参数、返回值、作用域和重载把一段逻辑变成可独立验证的函数。

<Term def="一个函数对合法输入、输出结果、副作用、错误处理和调用前后状态所作的明确约定。">函数契约</Term>

练习成绩分类时，先写出 `-1, 0, 59, 60, 89, 90, 100, 101` 的期望表，再编码条件；批量处理时写出循环不变量和退出证据；抽成函数后分别测试正常值、边界值和非法值。只有“每条路径都有预期”，才算从语句进入程序设计。

```cpp
std::string grade(int score) {
    if (score < 0 || score > 100) return "invalid";
    if (score >= 90) return "A";
    if (score >= 60) return "pass";
    return "retry";
}
```

<Callout type="trap" title="陷阱：样例输出正确就说明控制流正确">
  一个样例只穿过一条路径。区间重叠、边界遗漏、循环不终止和非法输入都可能仍隐藏。先枚举输入类和边界，再让测试覆盖每条边与失败出口。
</Callout>

## 第三阶段：Lesson 8–11 把数据边界连接到构建边界

Lesson 8 解释地址、指针、引用、动态内存与生命周期；Lesson 9 解释数组初始化、半开下标、多维数组、数组退化和字符串终止规则；Lesson 10 把声明、定义、头文件、翻译单元、分离编译、链接、作用域和命名空间串成多文件构建；Lesson 11 用 struct、enum、union 与类型别名表达不同数据形状。

<Term def="对象仍然存在、地址仍指向该对象且访问范围落在合法区域内的联合约束。">内存有效性</Term>

这一阶段要同时画两张图：运行图标明对象、地址、长度、所有者和销毁点；构建图标明声明来自哪个头文件、定义由哪个源文件产生、哪个目标文件被链接。越界、悬空、未定义符号和重复定义现象不同，不能用“再 include 一个文件”统一处理。

## 第四阶段：Lesson 12–16 从对象不变量走到持久化

Lesson 12 用 class、对象、数据成员、成员函数和访问控制建立封装；Lesson 13 加入构造、析构、成员初始化列表、this、静态成员和运算符重载；Lesson 14 用基类、派生类、override 与 virtual 建立替换契约；Lesson 15 进入抽象类、纯虚函数、多态对象集合、运行时类型检查与多重继承；Lesson 16 把有效状态写入文件，再通过路径、模式、流状态、格式和往返读取验证持久化结果。

<Term def="对象从构造成功到每次公开操作结束都必须满足、否则类型语义失效的状态条件。">对象不变量</Term>

最终练习可以是一个成绩册：构造时拒绝非法分数，基类接口统一展示不同记录类型，`unique_ptr` 明确所有权；保存时固定字段格式与打开模式，关闭后重新读取到新对象并逐字段比较。这样前 15 课的值、路径、函数、数组、类型与对象知识都在 Lesson 16 的往返证据中汇合。

```cpp
{
    std::ofstream output{path};
    output << record.name() << ' ' << record.score() << '\n';
}
std::ifstream input{path};
// 读取到新对象后比较字段，而不是只检查文件存在。
```

<Callout type="trap" title="陷阱：学完类就跳过文件 I/O 去学模板和 STL">
  第5版官方主线的终点是文件输入输出。模板与 STL 可以作为后续扩展，但不能替代路径、打开模式、EOF、格式错误和往返校验；否则内存中的对象无法形成可验证的持久记录。
</Callout>

## 四个阶段都用可复查证据放行

## 小结

- 官方结构是 16 个 Lesson，不是旧地图中的 8 个主题，也没有把模板和 STL 列为第5版独立主课
- Lesson 1–4 建立开发闭环与值规则，Lesson 5–7 建立控制和函数契约
- Lesson 8–11 把地址、数组边界、数据形状与多文件构建连接起来
- Lesson 12–16 用封装、生命周期、继承、多态和文件往返保持状态有效
- 每段以预测、作品、边界、故障和解释作为闸门，不以阅读页数或一次正确输出作为完成证据

<Exercises>
  1. **问题 1：还原课序。** 把 16 课分为四个阶段，并为每段写出一个最终产物。

  <Answer question="官方 16 课如何形成四段能力链？">L1–4 是程序与表达式，产物是可重复构建的输入/输出实验；L5–7 是控制与分解，产物是带边界表的函数；L8–11 是内存与组织，产物是地址/长度/翻译单元证据图；L12–16 是对象与持久化，产物是保持不变量并能文件往返的对象系统。</Answer>

  2. **问题 2：设计阶段闸门。** 学完 Lesson 8–11 后，怎样证明自己不只是会写数组语法？

  <Answer question="内存与组织阶段需要哪些通过证据？">用不同长度和边界测试数组遍历，画出数组退化后长度为何丢失；构造悬空或越界反例并解释生命周期；把声明和定义拆到头/源文件，分别复现未定义符号与重复定义。能从现象定位到内存边界或构建阶段，才通过。</Answer>

  3. **问题 3：串联全书。** 设计一个成绩册往返练习，说明至少会复用哪八课的知识。

  <Answer question="成绩册怎样连接前置课程？">用 L3 变量和类型表示字段，L5 条件验证范围，L6 循环处理记录，L7 函数拆分解析，L9 数组或序列保存数据，L10 多文件分离接口与实现，L12–15 维护对象不变量和多态接口，L16 固定路径/模式/格式并重读比较。每层都要覆盖失败路径。</Answer>
</Exercises>
