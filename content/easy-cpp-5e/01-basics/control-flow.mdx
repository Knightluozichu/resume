## 分支：if-else 与 switch

程序默认从上到下顺序执行。控制流让程序能判断和循环，从「直线走」变成「能拐弯、能绕圈」。

`if-else` 是最基本的分支：条件为真执行 A，为假执行 B。可以串联 `else if` 处理多分支，但分支多时代码会嵌套很深。`switch` 适合对整型/字符做等值判断，用 `case` 标签分发，编译器可能用跳转表优化。但 `switch` 只能等值判断不能做范围判断，且容易忘 `break` 导致贯穿（fall-through）。

## 循环：for、while、do-while

三种循环各有适用场景：

- `for`：已知循环次数时用。初始化、条件、更新三段写在一行，结构清晰。
  ```cpp
  for (int i = 1; i <= 10; i++) { sum += i; }
  ```
- `while`：未知次数、按条件驱动时用。先判断后执行，可能一次都不执行。
  ```cpp
  while (n > 0) { n /= 2; count++; }
  ```
- `do-while`：循环体至少执行一次时用。先执行后判断，适合菜单驱动等场景。
  ```cpp
  do { showMenu(); cin >> choice; } while (choice != 0);
  ```

## break 与 continue

`break` 立即终止整个循环，不再执行后续迭代。`continue` 跳过本次循环剩余语句，直接进入下一次迭代。两者都可以用在 `for`、`while`、`do-while` 中。

```cpp
for (int i = 1; i <= 100; i++) {
    if (i == 50) break;        // 到 50 退出
    if (i % 10 == 0) continue; // 跳过 10 的倍数
    if (i % 2 == 0) sum += i;  // 累加偶数
}
```

<Callout type="trap">
<strong>现象 →</strong> `switch` 语句多个 case 都执行了，或循环多跑了一轮。<strong>原因 →</strong> switch 忘了 `break` 导致 fall-through 贯穿到下一个 case；循环条件边界写错（如 `i <= n` 写成 `i < n` 少跑一轮）。<strong>修法 →</strong> switch 每个 case 末尾加 `break`（除非故意贯穿并注释说明）；循环条件仔细检查边界，用 `do-while` 时注意至少执行一次的特性。
</Callout>

## 小结与练习

C++ 控制流分分支（`if-else` / `switch`）和循环（`for` / `while` / `do-while`）两大类。`for` 适合已知次数，`while` 适合条件驱动，`do-while` 保证至少执行一次。`break` 终止循环，`continue` 跳过本次。
