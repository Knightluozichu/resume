## Hello, World!

学一门新语言，传统从 Hello World 开始。别小看这几行代码，它包含了 C++ 程序的基本骨架：

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

逐行拆解：`#include <iostream>` 是预处理指令，引入输入输出流头文件，让程序能用 `cout` 和 `cin`。`using namespace std;` 声明使用标准命名空间，省去每次写 `std::` 前缀。`int main()` 是程序入口，操作系统从这里开始执行。`cout << "Hello, World!" << endl;` 用输出流把字符串打印到屏幕，`endl` 换行并刷新缓冲区。`return 0;` 返回 0 表示程序正常结束。

## 输入与输出

C++ 用流（stream）做输入输出。`cout` 是标准输出流，配合 `<<`（插入运算符）把数据送到屏幕。`cin` 是标准输入流，配合 `>>`（提取运算符）从键盘读取数据存入变量。

```cpp
string name;
cout << "请输入你的名字：";
cin >> name;
cout << "你好，" << name << "！" << endl;
```

注意 `cin >> name` 遇到空格会停止读取。如果输入可能含空格（如全名），需要用 `getline(cin, name)` 读取整行。

<Term def="C++ 标准库提供的输入输出设施，cout 输出流用 << 插入数据，cin 输入流用 >> 提取数据">流（stream）</Term>

## 编译流程

C++ 程序从源码到运行经历四个阶段。预处理阶段处理 `#` 开头的指令，`#include` 把头文件内容复制到源文件。编译阶段做语法和类型检查，`using namespace` 在此阶段生效——它影响编译器如何解析 `cout` 这样的名字。汇编阶段把汇编代码翻译成机器码，生成目标文件。链接阶段把目标文件与标准库连接，解析符号地址，生成可执行文件。

<Callout type="trap">
<strong>现象 →</strong> 改了头文件但程序行为没变，或编译报「未定义引用」。<strong>原因 →</strong> 头文件修改后需要重新预处理和编译；链接错误通常是函数声明了但没定义，或忘了链接库。<strong>修法 →</strong> 理解四阶段，用 `g++ hello.cpp -o hello` 一步完成编译链接，或分步排查问题出在哪个阶段。
</Callout>

## 小结与练习

C++ 程序的基本骨架是 `#include` + `using namespace` + `main` 函数。`cout` 输出、`cin` 输入是日常最常用的设施。源码经预处理、编译、汇编、链接四阶段变成可执行文件。

<Exercises>
  <Answer question='#include 和 using namespace std 分别做什么？不用 using namespace 时 cout 怎么写？'>#include 在预处理阶段把头文件内容插入源文件，using namespace 在编译阶段声明使用 std 命名空间省略前缀。不用时 cout 写成 std::cout，endl 写成 std::endl。大型项目推荐不用 using namespace 避免命名冲突。</Answer>
  <Answer question='C++ 程序从源码到运行经历哪四个阶段？#include 和 using namespace 各在哪个阶段起作用？'>预处理、编译、汇编、链接四阶段。#include 在预处理阶段起作用（文本替换展开头文件），using namespace 在编译阶段起作用（名字解析，把 cout 关联到 std::cout）。运行时两者都已消失。</Answer>
</Exercises>
