## 四大类型族

C++ 的基本数据类型分四大族：整型（`short`、`int`、`long`、`long long`）存整数；浮点型（`float`、`double`、`long double`）存小数；字符型（`char`）存单个字符，本质是 1 字节小整数；布尔型（`bool`）存真假，只有 `true` 和 `false`。

选类型看三个维度：范围（值有多大）、精度（小数点后几位）、是否可能为负。计数用 `int`，大数用 `long long`，小数用 `double`（精度约 15 位，比 `float` 的 7 位更可靠），非负计数可用 `unsigned`。

## 变量与内存

变量是「贴了名字的内存盒子」——在内存中开辟一块空间，给它一个名字，用来存数据。`int x = 10;` 做了两件事：声明（分配 4 字节内存，命名为 `x`）和初始化（把 10 写入这块内存）。

C++ 建议变量声明时就初始化。未初始化的局部变量含垃圾值，直接读取是未定义行为——程序可能输出任何结果，甚至崩溃。

```cpp
int age = 20;
double temp = 36.5;
char grade = 'A';
bool passed = true;
```

## 类型转换

把一种类型的值赋给另一种类型时，编译器会做类型转换。`int` 转 `double` 是「提升」，小整数变成小数，信息无损。`double` 转 `int` 是「窄化」，小数部分被截断（不是四舍五入），3.99 变成 3，丢失信息。从高精度转低精度要小心数据丢失，必要时用 `static_cast<int>(c)` 显式转换表明意图。

`const` 修饰符声明不可变值，如 `const double PI = 3.14159;`，编译器阻止意外修改，既防 bug 又给优化器更多信息。`unsigned` 声明非负整数，把负数空间换成更大的正数上限（`int` 约 21 亿，`unsigned int` 约 42 亿），语义上明确「不会为负」。

<Callout type="trap">
<strong>现象 →</strong> `double` 转 `int` 后结果不符预期，如 3.99 变成 3 而非 4。<strong>原因 →</strong> 窄化转换是截断不是四舍五入，小数部分直接丢弃。<strong>修法 →</strong> 需要四舍五入用 `static_cast<int>(c + 0.5)`，或用 `round()` 函数；高精度转低精度时用 `static_cast` 显式表明意图，消除编译器警告。
</Callout>

## 小结与练习

C++ 基本类型分整型、浮点、字符、布尔四族，选类型看范围、精度、正负。变量是命名的内存空间，声明时应初始化。类型转换分提升（无损）和窄化（有损），`const` 防修改、`unsigned` 标记非负。
