## 类是图纸，对象是实例

类是一种自定义数据类型，把数据（成员变量）和操作数据的函数（成员函数）打包在一起。类是「图纸」，对象是按图纸造出的「实例」。一个类可以创建多个对象，每个对象有各自的成员变量值，但共享同一套成员函数。

```cpp
class Student {
public:
    string name;
    int score;
    void display() { cout << name << ":" << score; }
};

Student s1; s1.name = "张三"; s1.score = 85;
Student s2; s2.name = "李四"; s2.score = 50;
```

`s1` 和 `s2` 各有独立的 `name` 和 `score`，但调用的是同一份 `display` 代码。这就是面向对象的基本组织方式：用对象把相关数据和行为绑在一起。

## 构造函数与析构函数

构造函数是与类同名的特殊成员函数，对象创建时自动调用，用于初始化成员变量。没有返回类型，可以有参数，支持重载。析构函数名为 `~类名`，对象销毁时自动调用，用于释放资源。没有参数和返回类型，每个类只能有一个。

```cpp
class Student {
public:
    string name; int score;
    Student(string n, int s) : name(n), score(s) {}  // 构造
    ~Student() { /* 释放资源 */ }                      // 析构
};
```

构造函数保证对象一创建就处于有效状态，析构函数保证对象销毁前清理资源。用初始化列表 `: name(n), score(s)` 比在函数体里赋值更高效，直接构造而非先默认构造再赋值。

## 访问控制与封装

`public` 成员类外可访问，是对外的接口。`private` 成员只有类自己的成员函数能访问，是对内的实现细节。`protected` 成员类自己和派生类能访问，用于继承场景。

把成员变量设为 `private`、通过 `public` 函数访问的好处是封装：外部不能随意修改内部状态，可以在 setter 里检查合法性；内部实现可自由改变只要接口不变就不影响调用方；所有修改经过函数便于加日志和断言。这是面向对象「隐藏实现细节，只暴露稳定接口」的核心原则。

```cpp
class Student {
public:
    void setScore(int s) { if (s >= 0) score = s; }  // 拦截非法值
    int getScore() { return score; }
private:
    int score;  // 外部不能直接改
};
```

<Callout type="trap">
<strong>现象 →</strong> 成员变量被外部代码改成非法值（如分数为负），或改了成员变量名后大量调用方编译失败。<strong>原因 →</strong> 成员变量设为 public，外部直接访问绕过了合法性检查，且耦合了实现细节。<strong>修法 →</strong> 成员变量设为 private，通过 public 的 getter/setter 访问，在 setter 里做合法性校验。改成员变量名只影响类内部，调用方代码不用改。
</Callout>

## 小结与练习

类是图纸，对象是实例，每个对象有独立的成员变量值但共享成员函数。构造函数初始化对象，析构函数清理资源。`public`/`private`/`protected` 实现封装：隐藏实现细节，只暴露稳定接口。
