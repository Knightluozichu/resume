## 函数的基本结构

函数是把一段逻辑打包成可复用单元的机制。定义函数时指定返回类型、函数名、参数列表和函数体：

```cpp
int add(int a, int b) {
    return a + b;
}
```

`int` 是返回类型，`add` 是函数名，`int a, int b` 是参数列表，`return a + b;` 计算并返回结果。调用时 `add(3, 5)` 传入实参，函数返回 8。如果函数不返回值，用 `void`。

函数的价值在于复用和分解：写一次，调用多次；把大问题拆成小函数，每个函数只做一件事，便于测试和维护。

## 值传递与引用传递

值传递把实参的值复制一份给形参，函数内修改形参不影响实参。引用传递用 `&` 声明形参为实参的别名，函数内修改形参直接改实参。

```cpp
void addTen(int x)  { x += 10; }  // 值传递，改副本
void addTen(int &x) { x += 10; }  // 引用传递，改实参
```

用引用传递的三个理由：需要在函数内修改实参（如 `swap`）、避免大对象的复制开销、只读大对象时用 `const` 引用（如 `void print(const string &s)`）。`const` 引用既避免复制又防止误修改，是 C++ 函数参数的最佳实践之一。

<Term def="用 & 声明形参为实参的别名，函数内修改形参直接改实参，避免复制开销">引用传递</Term>

## 重载、默认参数与内联

函数重载让同名函数适配不同类型，编译器根据实参类型自动选择最匹配的版本。参数列表必须不同（个数、类型或顺序），返回类型不同不能构成重载。

默认参数给参数设默认值，调用时可省略。规则是默认参数必须从右往左连续设置。`void log(string msg, int level = 0)` 调用时 `log("hi")` 等价于 `log("hi", 0)`。

内联函数（`inline`）适合短小、频繁调用的函数，编译器把函数体展开到调用处，省去调用开销。不适合递归或大函数。

<Callout type="trap">
<strong>现象 →</strong> 传了大对象给函数后程序变慢，或想修改实参却没生效。<strong>原因 →</strong> 大对象值传递会复制整个对象，耗时耗内存；想修改实参却用了值传递，改的是副本。<strong>修法 →</strong> 大对象用 `const` 引用传递避免复制；需要修改实参用引用传递（非 const）；小对象（int、double）值传递即可，开销可忽略。
</Callout>

## 小结与练习

函数由返回类型、函数名、参数列表、函数体构成。值传递复制实参，引用传递操作实参本身。重载让同名函数适配多类型，默认参数简化常用调用，`inline` 优化短函数性能。
