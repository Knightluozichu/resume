## 继承：is-a 关系

继承让一个类（派生类）复用另一个类（基类）的成员变量和成员函数，在不修改基类的情况下扩展功能。`Dog` 继承 `Animal` 表示「Dog 是一种 Animal」，这是 is-a 关系。

```cpp
class Animal {
public:
    string name;
    void eat() { cout << name << "吃东西"; }
};

class Dog : public Animal {
public:
    void bark() { cout << name << "汪汪叫"; }
};
```

`Dog` 自动获得 `name` 和 `eat()`，自己新增 `bark()`。继承实现了代码复用，但要注意别滥用——只有真正的 is-a 关系才用继承，has-a 关系（如 Car 有 Engine）应该用组合。

## 虚函数与多态

虚函数用 `virtual` 修饰，表示可在派生类中被覆盖（override）。多态是面向对象的核心：通过基类指针或引用调用虚函数时，实际执行哪个版本取决于对象的真实类型而非指针的声明类型。

```cpp
Animal *p = new Dog();
p->speak();  // 无 virtual → 调用 Animal::speak()
             // 有 virtual → 调用 Dog::speak()
```

不用 `virtual` 时是静态绑定，按指针类型调用。用 `virtual` 时是动态绑定，通过虚函数表（vtable）查找实际地址，按对象真实类型调用。`override` 关键字（C++11）让编译器检查是否真的覆盖了基类虚函数，防止拼写错误导致的意外隐藏。

多态的价值在于「同一接口，不同行为」：用基类指针数组统一管理不同派生类对象，新增子类不用改调用代码。

## 虚析构函数

基类析构函数必须声明为 `virtual`。否则 `delete` 基类指针时只调用基类析构，派生类资源泄漏：

```cpp
class Animal {
public:
    virtual ~Animal() {}  // 虚析构，确保正确释放
};
```

```cpp
Animal *p = new Dog();
delete p;  // virtual 析构 → 先 Dog 析构再 Animal 析构 ✓
           // 非 virtual → 只 Animal 析构，Dog 资源泄漏 ✗
```

<Callout type="trap">
<strong>现象 →</strong> 基类指针指向派生类对象，调用虚函数却执行了基类版本；或 `delete` 基类指针后派生类资源泄漏。<strong>原因 →</strong> 忘了加 `virtual` 导致静态绑定；基类析构非 virtual 导致 `delete` 只调基类析构。<strong>修法 →</strong> 需要多态的成员函数加 `virtual`，派生类覆盖加 `override`，基类析构必须 `virtual`。只要类有虚函数，析构就应 virtual。
</Callout>

## 小结与练习

继承表达 is-a 关系实现代码复用。虚函数实现多态：基类指针按对象真实类型调用对应版本。`override` 确保正确覆盖，基类析构必须 `virtual` 防资源泄漏。
