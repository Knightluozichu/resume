## 五大核心知识块

回顾全书，C++ 入门需要掌握五大核心知识块，它们有严格的依赖链：基本语法（变量与类型、运算符）是程序的积木，定义和处理数据的基础；控制流（if/for/while）让程序能判断和循环；函数把逻辑拆成可复用单元；类与对象用对象组织数据与行为，引入面向对象；模板与 STL 接触泛型编程和标准库工具。

依赖关系是：语法 → 控制流 → 函数 → 类 → 模板/STL。每一块是下一块的地基：函数体内有判断和循环，成员函数就是类内的函数，STL 容器是类模板。顺序不能乱。

## 三种编程范式

C++ 支持三种编程范式，各解决不同问题：

- **面向过程**（语法 + 控制流 + 函数）：解决「如何用代码表达逻辑」。用变量存数据、控制流做判断循环、函数拆分复用。适合简单脚本和算法题。局限是数据和处理数据的函数分离，数据多了难管理。
- **面向对象**（类 + 继承 + 多态）：解决「如何组织复杂程序中数据和操作的关系」。用封装隐藏实现、继承复用代码、多态统一接口。适合大型软件和模拟现实实体。
- **泛型编程**（模板 + STL）：解决「如何让代码不依赖具体类型」。用模板写类型无关代码，用 STL 复用现成数据结构和算法。适合库开发和多类型复用。

三者递进：面向过程打底，面向对象组织结构，泛型编程最大化复用。C++ 的强大在于三者共存，按需选用。

## 综合应用

用全书知识设计一个「学生成绩管理」程序：定义 `Student` 基类含 `name`、`score` 和虚函数 `getGrade()`；派生 `HonorStudent` 覆盖 `getGrade()` 提高标准；用 `vector<Student*>` 管理所有学生利用多态统一处理；用 `sort` 算法配合 lambda 比较器按分数排序。

```cpp
vector<Student*> students = {
    new Student("张三", 85),
    new HonorStudent("李四", 92),
    new Student("王五", 50)
};
sort(students.begin(), students.end(),
     [](Student* a, Student* b) { return a->score > b->score; });
for (auto s : students) {
    cout << s->name << " " << s->getGrade() << endl;
}
```

这一个例子综合运用了类定义、构造函数、继承、虚函数多态、`vector` 容器、`sort` 算法、lambda 表达式、范围 for 循环——全书核心知识全串起来了。

<Callout type="tip">
学完本书不是终点。进阶方向：语言深度（现代 C++ 的智能指针、移动语义、lambda、concepts）、内存与底层（对象模型、RAII、虚函数表实现）、标准库深入（容器选择策略、多线程并发）、工程实践（设计模式、CMake、测试）。建议优先学现代 C++ 特性补齐日常工具，再做一个小项目把知识用起来。
</Callout>

## 小结与练习

全书主线：语法 → 控制流 → 函数 → 类 → 模板/STL，五块递进有严格依赖。三种范式分别解决表达逻辑、组织结构、类型复用的问题。学完做项目实践，再按方向进阶。
