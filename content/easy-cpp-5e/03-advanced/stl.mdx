## STL 是什么

STL（Standard Template Library，标准模板库）是 C++ 标准库的核心部分，提供通用的数据结构、算法和迭代器，都用模板实现，「拿来即用」。它让你不用手写链表、排序、查找，直接用现成的、经过充分测试的工具。

STL 分三大组件：容器管理数据集合（如 `vector`、`string`、`map`）；算法操作容器中的数据（如 `sort`、`find`、`count`）；迭代器是连接容器和算法的「通用指针」（如 `begin()`、`end()`）。

## vector：动态数组

`vector` 是最常用的容器，相比普通数组它大小动态变化、自带 `size()` 方法、支持赋值和比较、自动管理内存、和 STL 算法无缝配合。优先用 `vector` 只有需要固定大小且追求极致零开销时才用普通数组。

```cpp
vector<int> v;
v.push_back(3); v.push_back(1); v.push_back(4);
// v = {3, 1, 4}

sort(v.begin(), v.end());           // 排序：{1, 3, 4}
auto it = find(v.begin(), v.end(), 3);  // 查找
for (int x : v) cout << x << " ";   // 遍历：1 3 4
```

`push_back()` 尾部追加元素自动扩容，`sort()` 传迭代器范围排序，`find()` 返回迭代器找不到等于 `end()`，范围 for 循环遍历简洁安全。

<Term def="连接容器和算法的通用指针，begin 指向首元素 end 指向尾后，算法通过迭代器访问容器不依赖容器具体类型">迭代器</Term>

## 三层解耦设计

STL 的精妙之处在于三层解耦：容器只管存数据，算法只管处理数据，迭代器是两者之间的桥梁。一套算法（如 `sort`）通过迭代器可用于所有容器，不用为每个容器重写。容器也不用内置全部算法，接口精简。

算法不写成容器的成员函数的原因：避免容器接口膨胀（几十个算法做成成员函数会让每个容器类极其臃肿）；统一接口（算法以迭代器范围为参数与容器类型无关，普通数组也能用）；编译期多态（通过迭代器类型在编译期选择最优实现，比运行时虚函数分派高效）。

少数算法确实做成成员函数（如 `list::sort`、`map::find`），因为它们依赖容器内部结构才能高效实现。

<Callout type="trap">
<strong>现象 →</strong> `find` 返回的迭代器直接用，没检查是否等于 `end()`，程序崩溃。<strong>原因 →</strong> `find` 找不到时返回 `end()` 迭代器，解引用 `end()` 是未定义行为。<strong>修法 →</strong> 用 `find` 后必须检查 `if (it != v.end())` 再使用；用 `at()` 而非 `[]` 访问需要越界检查的场景（`at()` 抛异常，`[]` 不检查）。
</Callout>

## 小结与练习

STL 由容器、算法、迭代器三层组成。`vector` 动态数组最常用，`sort`、`find` 等算法以迭代器范围为参数。迭代器解耦容器与算法，使一套算法可用于所有容器。
