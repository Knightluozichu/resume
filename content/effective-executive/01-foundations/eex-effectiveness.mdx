## 学习目标

- 区分效率与有效性的本质差异
- 理解知识工作者为何迫切需要有效性
- 掌握有效性的五项习惯及其相互关系
- 认识有效性作为习惯「可学会但不可被教」的特性

## 核心概念

### 效率与有效性

大多数人把「效率」与「有效性」混为一谈，但两者截然不同。效率关注的是「把事情做对」，追求更高的输入产出比、更快的速度与更低的成本；而有效性关注的是「做正确的事」，追求对组织真正有价值的成果。一个极其高效地做错误事情的人，只会把错误做得更大。

有效性之所以困难，是因为管理者的工作成果并不直接产生价值，而要通过组织被他人使用才能转化为成果。这意味着有效性不能靠直觉，必须靠有意识的实践。

### 知识工作者为何需要有效性

知识工作者面临三重处境，使其天然倾向于低效：

1. **时间属于别人**：各种需求从四面八方涌来，自己的时间被切碎，难以自主安排
2. **身处组织之中**：自己的贡献被他人使用，价值须通过组织才能转化为成果，而非自己直接产出
3. **外部被过滤**：只能看到组织内部的信息，真实的外部世界被层层抽象与过滤

这三重处境意味着，知识工作者若不刻意追求有效性，就会陷入忙碌却无产出的陷阱。

### 五项习惯

有效性由五项习惯构成：

1. **掌握时间**：记录、管理并集中自己的时间，认识时间的稀缺性
2. **聚焦贡献**：把视线从内部转向外部，关注「我能贡献什么」
3. **发挥长处**：发挥自己、上司、同事的长处，让短处变得无关紧要
4. **要事优先**：集中精力于少数要务，一次只做一件事
5. **有效决策**：在关键时刻做出经过对峙的判断

这五项习惯相互独立又彼此关联，共同构成有效性的整体。

### 可学会 但不可被教

有效性不是天赋，而是一套习惯复合体。习惯可以通过反复练习来学会，但它不能通过听课来获得——听再多课也不会让人变有效，唯有自己去实践、去练习，才能在做中形成习惯。这正是本书的核心信念：有效性可以学会，但必须自己去做。

## 术语表

| 术语 | 释义 |
|------|------|
| 有效性 | 做正确的事，产出对组织有价值的成果 |
| 效率 | 把事情做对，追求输入产出比 |
| 知识工作者 | 以知识而非体力产出价值的人 |
| 习惯复合体 | 五项实践相互独立又彼此关联构成的整体 |
| 时间属于别人 | 管理者时间被各方需求侵占的处境 |
| 外部被过滤 | 组织内部只能看到被抽象的外部信息 |
| 五项习惯 | 掌握时间、聚焦贡献、发挥长处、要事优先、有效决策 |
| 可学会不可被教 | 有效性须通过实践练习获得，无法靠听课传授 |

## 练习题

1. 有效性与效率的区别是什么？为什么这个区分如此重要？
2. 知识工作者面临哪三重处境？这些处境如何使其倾向于低效？
3. 有效性的五项习惯是什么？它们之间有何关联？
4. 为什么说有效性「可以学会但不可被教」？这对学习管理者意味着什么？
