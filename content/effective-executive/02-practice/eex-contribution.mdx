## 学习目标

- 理解从「我该做什么」到「我能贡献什么」的问题转向
- 掌握贡献的三个领域：直接成果、价值确认、培养人才
- 认识聚焦贡献如何带来有效的人际关系
- 学会用三个关键问题指导自己的贡献思考

## 核心概念

### 问题转向

大多数人关注的是「我该做什么工作」，这把视线局限在自己的职权范围。而有效的管理者关注的是「我能贡献什么」，这把视线从内部转向外部、从努力转向成果。前者问的是我的位置，后者问的是组织的需要。这个看似细微的转向，却决定了一个人是忙碌还是有效。

### 贡献的三个领域

任何管理者的贡献都体现在三个领域：

1. **直接成果**：组织存在的直接目的，如企业的销售与利润、医院的病人救治。成果必须清晰具体、可衡量可验证。
2. **价值的确认**：组织秉持的信念与标准，需要不断被重申与体现。组织若失去价值确认，就会涣散无力。
3. **培养人才**：组织持续的生命力所在。明天需要什么样的人，今天就要去培养；让他人因我而获得成长与提升。

### 聚焦贡献带来有效的人际关系

聚焦贡献自然带来有效的人际关系——不是靠一团和气，而是靠实质：

- **沟通**：下属理解对自己的期望与贡献要求，而非被动接受命令
- **团队合作**：围绕成果自发横向协作，而非依赖层级
- **自我发展**：为做出贡献而主动学习提升所需能力
- **培养他人**：要求高标准以激发他人向上

有效的人际关系看重实质而非和谐——挑战与异议比一团和气更有价值。

### 三个关键问题

以贡献为导向，管理者应反复问自己：

1. **我的成果在何处被使用？谁需要我的产出？**——明确服务对象
2. **我必须产出什么成果，才算真正做出贡献？**——明确成果标准
3. **我必须具备什么能力，才能产出这些成果？**——明确自我发展

这三个问题把注意力从「我」转向「组织」，从「过程」转向「结果」。

## 术语表

| 术语 | 释义 |
|------|------|
| 贡献 | 对组织外部成果有价值的产出 |
| 直接成果 | 组织存在的直接目的所要求的产出 |
| 价值的确认 | 对组织信念与标准的不断重申 |
| 培养人才 | 为组织的明天培养所需要的人 |
| 有效的人际关系 | 看重实质与成果而非一团和气的关系 |
| 问题转向 | 从「我该做什么」到「我能贡献什么」 |
| 沟通 | 让他人理解对自己的贡献要求 |
| 自我发展 | 为贡献而主动提升所需能力 |
