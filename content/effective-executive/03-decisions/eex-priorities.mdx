## 学习目标

- 理解集中精力为何是有效性的秘诀
- 掌握集中的两个前提：摆脱过去、新事排在旧事之前
- 学会决定优先级的四条规则
- 认识优先与后置同样需要勇气

## 核心概念

### 集中是秘诀

有效性的秘诀是集中——一次只做一件事，且先做最重要的事。管理者可自由支配的时间本就少得可怜，唯有集中才能办成要事。如果什么都想兼顾，结果是什么都做不好。集中不是一种技巧，而是一种纪律。

### 集中的两个前提

要做到集中，必须先满足两个前提：

1. **摆脱已经不再有价值的过去**：系统地问自己——如果不做这件事，是否还会去做？若答案是「不会」，就果断放弃。必须定期剪除昨天，否则昨天的遗产会消耗今天的资源与机会。
2. **新任务排在旧任务之前**：资源有限，要开始新的必须先放下旧的。先确定后事，再定先事——先想清楚放弃什么，才能集中精力做新的事。

### 决定优先级的四条规则

决定优先级靠的不是缜密的分析，而是勇气。四条规则：

1. **重将来，轻过去**：面向未来选择，而非沉湎过去。不为昨天的遗产消耗今天的资源与机会。
2. **重机会，轻问题**：聚焦机会而非只盯问题。问题只求解决，机会才创造真正的成果。
3. **重方向，轻盲从**：选择自己的方向，不随大流。独立判断，走自己的路。
4. **重高远，轻安稳**：志存高远，追求能产生真正差异的事，而非安全易行的事。

### 优先与后置

集中不只是决定「做什么」（优先事项），同样重要的是明确「不做什么」（后置事项）。把资源集中到少数优先事项上，必然意味着把另一些事推迟甚至放弃。决定放弃也需要勇气——许多人明知该放弃某事，却因惯性或人情而拖延。真正的集中，是先事与后事同样果断。

## 术语表

| 术语 | 释义 |
|------|------|
| 集中 | 一次只做一件事，把精力投入少数要务 |
| 摆脱昨天 | 系统地放弃已不再有价值的事 |
| 先定后事再定先事 | 先决定放弃什么，再决定做什么 |
| 优先事项 | 专注投入资源、真正做好的少数要务 |
| 后置事项 | 明确决定推迟或放弃的事 |
| 重机会轻问题 | 聚焦创造成果的机会，而非只求解决问题 |
| 重高远轻安稳 | 追求有差异的事，而非安全易行的事 |

## 练习题

1. 为什么集中精力是有效性的秘诀？为什么不能同时兼顾多件要事？
2. 集中的两个前提是什么？为什么要先摆脱昨天？
3. 决定优先级的四条规则是什么？为什么靠勇气而不靠分析？
4. 优先事项与后置事项是什么关系？为什么放弃也需要勇气？
