## 为什么要迁移到现代 C++

C++11/14 提供了一批新语法与工具，让代码更安全、更清晰。条款 7-10 聚焦「迁移」层面的改进：花括号初始化统一了初始化语法、nullptr 修正了空指针的重载陷阱、别名声明取代 typedef、作用域枚举消除了命名污染。与此同时，资源管理从裸 new/delete 迁移到智能指针，是这一板块最根本的跃迁。

## 三种智能指针的所有权分工

从 C++98 迁移的第一步，是用智能指针取代裸 new/delete。三种指针按所有权语义分工：<Term def="独占所有权的智能指针，不可拷贝可移动，零开销。">unique_ptr</Term> 独占资源（默认选择，零开销），<Term def="共享所有权的智能指针，通过引用计数管理。">shared_ptr</Term> 共享资源（引用计数，多所有者），<Term def="不控制生命周期的观察者指针，配合 shared_ptr 打破循环引用。">weak_ptr</Term> 观察资源（不增计数，打破循环）。

迁移原则：默认用 unique_ptr，需要多所有者才用 shared_ptr，循环引用处配 weak_ptr。unique_ptr 可隐式转 shared_ptr，反之不可，所以从独占开始是安全降级。

## 花括号初始化（条款 7）

条款 7 区分 `()` 与 `{}`。花括号初始化有三优势：禁窄化转换（`int x{3.14}` 编译错误）、不受最烦人的解析影响、是「最通用的初始化语法」。但它有 initializer_list 构造函数的强偏好：当类型有 initializer_list 构造函数时，`Widget w{1, 2}` 会优先匹配它而非 `Widget(int, int)`。

## nullptr 取代 0 与 NULL（条款 8）

0 和 NULL 本质是整型字面量，在指针重载下会误匹配整型重载：

```cpp
void f(int);
void f(void*);
f(0);        // 调 f(int)，不是 f(void*)
f(nullptr);  // 明确调 f(void*)
```

nullptr 是独立的 `std::nullptr_t` 类型，不是整型，不会误匹配整型重载，且能与模板推导配合。所有「空指针」场景一律用 nullptr。

## 作用域枚举（条款 10）

条款 10 的 `enum class` 相比传统 `enum` 解决三大问题：命名不污染外层作用域、不隐式转 int（强制 `static_cast`）、可指定底层类型并前置声明。新写的枚举应一律用 `enum class`。

<Callout type="tip">
<strong>建议 →</strong> 迁移时优先把「裸 new 的结果直接交给 unique_ptr」：`auto p = std::make_unique<Widget>();`。一处统一，既消除 new/delete 配对负担，又为后续升级 shared_ptr 留好降级路径。
</Callout>

<Callout type="trap">
<strong>现象 →</strong> 用 0 传给期望空指针的重载，结果调到了 int 版本。<strong>原因 →</strong> 0 是整型，重载决议优先匹配整型形参。<strong>修法 →</strong> 一律用 nullptr，它不是整型，只会匹配指针重载。
</Callout>

## 小结与练习

- 三种智能指针按所有权分工：unique 独占、shared 共享、weak 观察
- 花括号初始化禁窄化、防最烦人解析，但偏好 initializer_list 构造函数
- nullptr 是独立类型，不误匹配整型重载，取代 0/NULL
- 作用域枚举 enum class 解决命名污染、隐式转换、底层类型三大问题

## 名词解释

<Glossary>
  <GlossaryItem term="unique_ptr">独占所有权的智能指针，同一时刻只有一个指针持有资源，不可拷贝但可 move 转移，零开销，是管理动态资源的默认选择。</GlossaryItem>
  <GlossaryItem term="shared_ptr">共享所有权的智能指针，多个指针可指向同一资源，通过引用计数管理，计数归零时释放，有原子计数开销和循环引用风险。</GlossaryItem>
  <GlossaryItem term="weak_ptr">不控制生命周期的观察者智能指针，不增加引用计数，通过 lock() 提升为 shared_ptr 安全访问，用于打破循环引用。</GlossaryItem>
  <GlossaryItem term="nullptr">C++11 引入的空指针字面量，类型为 std::nullptr_t，不是整型，不会误匹配整型重载，取代 0 和 NULL。</GlossaryItem>
  <GlossaryItem term="作用域枚举">用 `enum class` 声明的枚举，枚举名不污染外层作用域、不隐式转 int、可指定底层类型并前置声明，取代传统 enum。</GlossaryItem>
</Glossary>
