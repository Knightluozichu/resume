## 优化的目标

代码优化在 IR 层做等价变换，目标是产出**更快**或**更短**的代码，而不改变程序语义。优化分局部（基本块内）和全局（跨基本块）两个层次。

## 数据流分析框架

数据流分析是全局优化的理论基础，统一为**四要素框架**：

| 要素 | 含义 | 例子 |
|------|------|------|
| 方向 $D$ | 前向或后向 | 前向：可用表达式；后向：活跃变量 |
| 值域 $V$ | 可能取值的集合（通常是格） | `{⊥, T, F, ⊤}` 或表达式集合的幂集 |
| 传递函数 $F$ | 块内如何变换 | `OUT[b] = F_b(IN[b])` |
| 交汇运算 $\land$ | 多前驱如何合并 | 交集（必须性质）或并集（可能性质） |

### 迭代求解

数据流方程通过**不动点迭代**求解：从初始值开始，反复应用传递函数和交汇运算更新每个基本块的 `IN`/`OUT` 值，直到所有值不再变化。

<Callout type="info">

数据流分析追求**保守近似**——宁可漏报优化机会（少优化），也不能误报（改变语义）。例如可用表达式用交集（所有前驱都可用才算可用），偏向保守。

</Callout>

## 冗余消除三剑客

### 局部值编号（LVN）

基本块内的优化。给每个计算出的值分配一个**编号**，相同表达式（操作数编号 + 运算符相同）复用之前的结果：

```text
a = b + c    // 编号 #1
d = b + c    // 编号相同 #1 → 替换为 d = a
```

### 可用表达式分析

全局前向数据流分析，找出「已计算且操作数未被重定义」的表达式：

$$IN[b] = \bigcap_{p \in pred(b)} OUT[p]$$

$$OUT[b] = (IN[b] \cup GEN[b]) - KILL[b]$$

其中 $GEN[b]$ 是块内新计算的表达式，$KILL[b]$ 是因操作数被重定义而失效的表达式。分析结果用于全局公共子表达式消除。

### 死代码消除（DCE）

后向活跃变量分析驱动。若某条指令的计算结果从未被使用（不活跃），则该指令是死代码，可安全删除：

$$OUT[b] = \bigcup_{s \in succ(b)} IN[s]$$

$$IN[b] = (OUT[b] - DEF[b]) \cup USE[b]$$

删除一条后可能暴露更多死代码，需级联迭代删除。

## 循环优化

基于**支配关系**和**归纳变量**分析，循环优化是中端性能提升的核心：

### 归纳变量简化

循环中常有多个同步递增的归纳变量（如 `i++` 和 `p += 4`），可删除冗余的，只保留最便宜的一个。

### 循环不变量外提（LICM）

将循环中每次迭代结果都相同的计算**移到循环外**，只算一次：

```text
优化前: for (i=0; i<n; i++) a[i] = x * y + i;  // x*y 每次重算
优化后: t = x * y; for (i=0; i<n; i++) a[i] = t + i;  // x*y 只算一次
```

需确保外提不改变语义（不在异常路径、无副作用）。

### 强度削弱

用更便宜的运算替代昂贵的运算：

```text
优化前: for (i=0; i<n; i++) j = i * 4;   // 乘法
优化后: j = 0; for (i=0; i<n; i++) { j += 4; }  // 加法替代乘法
```

<Callout type="tip">

循环优化的共同前提是**循环识别**——通过支配关系找出循环头和回边。SSA 形式使这些分析更精确。

</Callout>

<GlossaryItem term="数据流分析框架">
统一描述数据流分析的四要素模型：方向 D（前向/后向）、值域 V（格）、传递函数 F（`OUT[b]=F_b(IN[b])`）、交汇运算 ∧（交集/并集）。通过不动点迭代求解。
</GlossaryItem>

<GlossaryItem term="局部值编号（LVN）">
基本块内优化，给每个值分配编号，相同表达式复用结果，消除块内冗余计算。
</GlossaryItem>

<GlossaryItem term="死代码消除（DCE）">
后向活跃变量分析驱动，若指令结果从未被使用则删除，需级联迭代删除暴露的新死代码。
</GlossaryItem>

<GlossaryItem term="强度削弱">
用更便宜的运算替代昂贵运算，如循环内用加法（`t += 4`）替代乘法（`i * 4`）。
</GlossaryItem>

<GlossaryItem term="不动点迭代">
数据流分析的求解方法，反复应用传递函数和交汇运算直到值不再变化。因值域是有限格且函数单调，故一定收敛。
</GlossaryItem>

</Glossary>

<Exercises>

### 问题 1

数据流分析框架的四要素是什么？以「可用表达式分析」为例说明。

<Answer>

四要素：①方向 D——前向或后向 ②值域 V——可能取值集合（通常是格） ③传递函数 F——`OUT[b] = F_b(IN[b])` ④交汇运算 ∧——多前驱值合并。以可用表达式为例：①方向前向 ②值域为可用表达式集合的幂集 ③传递函数 `OUT[b] = (IN[b] ∪ GEN[b]) - KILL[b]` ④交汇为交集 `IN[b] = ∩ OUT[p]`（所有前驱都可用才可用）。迭代到不动点即得各块可用表达式集。

</Answer>

### 问题 2

局部值编号（LVN）、可用表达式分析和死代码消除（DCE）分别做什么？

<Answer>

LVN：基本块内优化，给每个值编号，相同表达式（操作数编号+运算符相同）复用结果，消除块内冗余。可用表达式分析：全局前向分析，找出已计算且操作数未变的表达式，用于全局公共子表达式消除。DCE：后向活跃变量分析驱动，结果从未使用的指令是死代码可删除，需级联迭代。三者配合：LVN 处理块内冗余，可用表达式处理跨块冗余，DCE 清理无用计算。

</Answer>

### 问题 3

循环优化中的归纳变量简化、循环不变量外提（LICM）和强度削弱各是什么？

<Answer>

归纳变量简化：循环中多个同步递增的归纳变量（如 i++ 和 p+=4），删除冗余的只保留最便宜的。LICM：循环中每次迭代结果相同的计算移到循环外只算一次，需确保不改变语义。强度削弱：用更便宜的运算替代昂贵的，如循环内 `i*4` 每次递增 4，可用 `t += 4`（加法）替代 `i*4`（乘法）。三者都依赖循环结构识别和支配关系分析。

</Answer>

### 问题 4

什么是数据流分析的不动点迭代？为什么数据流分析一定能收敛？

<Answer>

不动点迭代：从初始值开始反复应用传递函数和交汇运算更新 IN/OUT 值，直到不再变化（达到不动点）。一定能收敛的原因：①值域是有限格，值只能沿格单调变化 ②传递函数和交汇运算是单调函数，单调函数在有限格上迭代必到达不动点 ③有限格保证移动次数有限。保守性：数据流分析追求安全近似——宁可漏报优化机会也不能误报改变语义，故分析结果偏向保守（如可用表达式用交集）。

</Answer>
