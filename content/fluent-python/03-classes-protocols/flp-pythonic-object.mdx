## 核心模型与责任

Python风格对象通过数据模型与语言协作，而不是复制内置类型全部API。先定义不可变性、表示、构造和比较不变量，再实现最小协议，调用端自然获得repr、format和hash等能力。
这一章的阅读方法是先写出输入和不变量，再观察解释器或标准库采取哪条路径，最后用反例确认边界。这样学习得到的是可迁移的判断，而不是只能复述示例。

## 机制一：第一条执行链

对象表示与备选构造器把可诊断表示和输入格式分开。repr最好尽量能重建对象，classmethod从字节或文本构造并尊重子类，避免把解析逻辑堆进init。
```python
from array import array
class Vector2d:
    typecode = 'd'
    def __iter__(self): return (i for i in (self.x, self.y))
    def __repr__(self): return f'Vector2d({self.x!r}, {self.y!r})'
```

运行后记录对象身份、返回类型和异常位置；再改变一个输入，确认变化来自协议本身，而不是偶然的实现细节。

## 机制二：状态、类型与协作

classmethod与staticmethod都改变描述符绑定方式：classmethod接收类并适合多态构造器，staticmethod只是放在命名空间里的普通函数。若函数不依赖类，模块级函数通常更清楚。

```python
@classmethod
def frombytes(cls, octets):
    typecode = chr(octets[0])
    values = memoryview(octets[1:]).cast(typecode)
    return cls(*values)
```

评审这段代码时，先问调用端依赖什么能力，再问实现是否扩大了共享状态或静默吞掉错误。接口越小，替换和测试通常越直接。

## 机制三：边界条件与成本

格式化显示与可哈希对象涉及format协议、只读属性、相等与hash一致性。可哈希对象必须在参与哈希期间不可变，相等对象必须给出相同hash。
私有属性、slots与类属性是约定和布局工具。双下划线会名称改写而非安全封装，slots减少实例字典但影响弱引用和动态属性；优化前要测量实例规模。
```python
def __hash__(self): return hash((self.x, self.y))
def __format__(self, spec=''):
    components = (format(c, spec) for c in self)
    return f'({", ".join(components)})'
```
