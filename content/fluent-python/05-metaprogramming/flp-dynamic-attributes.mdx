## 机制一：第一条执行链

使用动态属性处理JSON数据可把映射键包装成属性并递归转换嵌套结构。必须处理关键字、非法标识符和缺失字段，并保留原始数据入口，避免神奇访问掩盖输入错误。 <Term def="使用new灵活创建对象发生在init之前，可根据原始数据返回不同类型或完成不可变基类构造。多数场景工厂类方法更直观，只有实例创建协议确实需要控制时才覆盖new。">使用new灵活创建对象</Term>

```python
class FrozenJSON:
    def __init__(self, mapping): self.__data = dict(mapping)
    def __getattr__(self, name):
        try: value = self.__data[name]
        except KeyError as error: raise AttributeError(name) from error
        return FrozenJSON.build(value)
```

运行后记录对象身份、返回类型和异常位置；再改变一个输入，确认变化来自协议本身，而不是偶然的实现细节。

## 机制二：状态、类型与协作

使用new灵活创建对象发生在init之前，可根据原始数据返回不同类型或完成不可变基类构造。多数场景工厂类方法更直观，只有实例创建协议确实需要控制时才覆盖new。 <Term def="计算特性与缓存特性把派生值放在property或cached_property后。缓存只适合依赖不可变输入或有失效策略的数据；把缓存值写入实例字典会影响后续描述符查找。">计算特性与缓存特性</Term>

<FlpDynamicAttributesBoundaryLab />

```python
class LineItem:
    def __init__(self, weight): self.weight = weight
    @property
    def weight(self): return self._weight
    @weight.setter
    def weight(self, value):
        if value <= 0: raise ValueError('weight must be positive')
        self._weight = value
```

评审这段代码时，先问调用端依赖什么能力，再问实现是否扩大了共享状态或静默吞掉错误。接口越小，替换和测试通常越直接。

## 机制三：边界条件与成本

计算特性与缓存特性把派生值放在property或cached_property后。缓存只适合依赖不可变输入或有失效策略的数据；把缓存值写入实例字典会影响后续描述符查找。 <Term def="属性验证与处理由getter、setter和deleter维护不变量。验证应在赋值边界失败并给出字段上下文，多个字段联合约束则适合显式命令或不可变构造。">属性验证与处理</Term>

属性验证与处理由getter、setter和deleter维护不变量。验证应在赋值边界失败并给出字段上下文，多个字段联合约束则适合显式命令或不可变构造。 <Term def="用可复现实验判断动态属性与特性实现是否保持协议、不变量与失败语义。">动态属性与特性验证边界</Term>

class Record:
