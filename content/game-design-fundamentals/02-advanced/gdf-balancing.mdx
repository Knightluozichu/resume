## 直觉引入

石头剪刀布是完美平衡的——每个选择都有克星。但如果改成石头剪刀布蜥蜴斯波克呢？选择多了但平衡更难调。游戏平衡就像调天平：不是让两边完全一样重，而是让每种选择都有用武之地。

好的平衡不是「所有选项一样强」，而是「不同场景下不同选项各有所长」。绝对平衡可能让选择变得无趣——如果 A 和 B 完全等价，选哪个都一样，选择本身就失去了意义。

## 概念讲解

### 平衡的类型

<GdfBalancingDiagram />

<Term def="所有选项在所有场景下效力相等，适合纯竞技游戏">对称平衡</Term>让每个选择在统计上胜率趋近 50%。如格斗游戏中角色属性对称。

<Term def="不同选项在不同场景下各有所长，适合策略深度游戏">非对称平衡</Term>让每个选择有明确优势和劣势。如 RTS 中种族各有特色。

<Term def="单一策略明显优于其他所有策略，导致玩家只用这一种">统治策略</Term>是平衡的最大敌人。如果存在统治策略，其他选择就是假选择，游戏深度被破坏。

### 平衡的评价

平衡不是看「所有选项使用率相等」，而是看「多个策略都可行」。使用率分布健康（多个策略被使用）比均匀分布更重要。

## 代码对照

```csharp
// 平衡性参数与调节
public class BalanceConfig {
    // 武器平衡（非对称：各有优劣）
    public class Weapon {
        public string name;
        public float damage;     // 伤害
        public float range;      // 射程
        public float fireRate;   // 射速
        public float mobility;   // 移动惩罚
    }
    
    Weapon[] weapons = {
        new() { name="狙击", damage=100, range=100, fireRate=0.5f, mobility=0.3f },
        new() { name="冲锋", damage=20,  range=20,  fireRate=10f,  mobility=1.0f },
        new() { name="步枪", damage=40,  range=60,  fireRate=5f,   mobility=0.7f },
    };
    // 狙击高伤远射但慢且笨重，冲锋快但近距低伤
    // 不同场景各有所长=非对称平衡
}
```

## 常见误区

<Callout type="trap">
**现象：追求绝对平衡，所有选项数值一样。**
原因：绝对平衡让选择无趣——选项完全等价时选择失去意义。修法：用非对称平衡，让选项各有优劣，不同场景下各有所长。平衡的目标是「多个策略可行」而非「所有选项等价」。
</Callout>

<Callout type="trap">
**现象：一次大幅调整多个参数。**
原因：同时改多个参数无法判断哪个改动导致了什么效果。修法：每次只调 1-2 个参数，幅度 5-10%，观察数据后再决定下一步。平衡调整是迭代过程，不是一次到位。
</Callout>

<Exercises>
**问题 1**：对称平衡和非对称平衡的区别是什么？各适合什么游戏？

<Answer>
对称平衡让所有选项在所有场景下效力相等（如格斗游戏角色属性对称），适合纯竞技游戏强调公平。非对称平衡让不同选项在不同场景下各有所长（如 RTS 种族各有特色），适合策略深度游戏强调选择。非对称平衡更有趣因为选择有策略含义，但更难调因为需要确保每种选择都有用武之地。
</Answer>

**问题 2**：什么是统治策略？为什么它是平衡的最大敌人？

<Answer>
统治策略是单一策略明显优于其他所有策略，导致玩家只用这一种。它是平衡的最大敌人因为：如果存在统治策略，其他选择就是假选择（选了就输），游戏深度被破坏（只有一种玩法），多样性丧失（所有玩家行为一致），游戏很快变得无聊。平衡的首要任务是消除统治策略。
</Answer>
</Exercises>
