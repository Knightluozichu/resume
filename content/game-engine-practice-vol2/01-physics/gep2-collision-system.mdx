## 直觉引入

一百个箱子掉在地上，要判断谁碰了谁。最笨的办法是两两精确检测——O(n²) 次，箱子一多帧率直接崩。聪明的做法是分两步：先用廉价的包围盒快速排除「显然没碰」的对，只把「可能碰」的少数交给精确算法；最后把碰撞结果翻译成物理引擎能用的接触信息。这就是碰撞系统的三级流水线。

## 三阶段流水线

<Term def="广相用廉价的包围盒快速排除显然不相交的物体对，只输出可能相交的候选对，把精确检测的工作量压到可控。">
  广相
</Term>
是第一道筛子。它用 AABB（轴对齐包围盒）做 Sweep and
Prune：把所有包围盒在轴上排序扫掠，只有轴端点重叠的才可能相交，输出「候选对列表」。**窄相**对候选对用
GJK 或 SAT
精确判断凸体是否相交，相交则求接触点。**流形**把相交结果构造为接触法线、穿透深度、接触位置，输出
Contact Manifold 交给物理求解器。

```cpp
// 三阶段流水线
void CollisionSystem::Detect() {
    pairs.clear();
    broadphase.SweepAndPrune(bodies, pairs);   // O(n log n) 筛候选对
    for (auto& [a, b] : pairs) {
        Manifold m;
        if (narrowphase.GJK(a, b, m)) {         // 精确判断+求接触
            narrowphase.EPA(a, b, m);           // 求穿透深度/法线
            m.contactPoints = ClipManifold(m);  // 流形裁剪成多点
            solver.AddContact(m);               // 交给物理求解器
        }
    }
}
```

## 分工的本质

广相做减法（排除），窄相做精度（判断），流形做翻译（构造求解输入）。三者分工把 O(n²) 的全配对压到接近 O(n + k)，k 为真正接近的对数。GJK 求「两凸体最短距离」，距离 ≤ 0 即相交，但它无法给穿透深度；EPA 从 GJK 的单纯形向外扩展，求出穿透深度和法线。GJK 定性、EPA 定量，配合给出完整接触信息。

<Callout type="trap">
  **误区：只取单个接触点。**
  面接触的物体（箱子放地上）若只给一个接触点，求解器施冲量会产生错误力矩，箱子翻转打滑无法堆叠。多点流形（如
  4 个角点）让冲量分布，堆叠才稳定。
</Callout>

<Exercises>
**问题 1**：为什么不能直接两两做窄相检测？

<Answer>
  窄相（GJK/SAT）精确但开销大，n 个物体两两就是 O(n²)
  次检测，物体上千时帧率崩盘。广相用廉价 AABB
  先排除绝大多数显然不相交的对，只把可能相交的少数交给窄相，把 O(n²) 压到接近
  O(n + k)，k 为真正接近的对数。
</Answer>

**问题 2**：GJK 和 EPA 如何配合？

<Answer>
GJK 求两凸体最短距离：用 Minkowski 差和支持点迭代逼近原点，距离大于 0 不相交、等于 0 刚好接触。当 GJK 发现 Minkowski 差包含原点（相交）时它无法给穿透深度，交给 EPA：从 GJK 的单纯形向外扩展，找到原点到 Minkowski 差边界的最近点，得到穿透深度和法线。GJK 定性、EPA 定量，配合给出完整接触信息。
</Answer>
</Exercises>

<Glossary>
  <GlossaryItem term="广相 Broadphase">
    用 AABB 扫掠排序快速排除不相交对，输出候选对列表，把精确检测工作量压到可控。
  </GlossaryItem>
  <GlossaryItem term="GJK">
    求两凸体最短距离的迭代算法，用 Minkowski 差和支持点逼近原点，判断是否相交。
  </GlossaryItem>
  <GlossaryItem term="接触流形">
    碰撞的接触法线、穿透深度、接触点集合，是物理求解器施加冲量的输入。
  </GlossaryItem>
</Glossary>
