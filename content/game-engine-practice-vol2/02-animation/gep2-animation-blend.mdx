## 直觉引入

角色从待机切到行走，如果直接换动画，姿势会瞬间跳一下，很突兀。玩家推摇杆让角色加速，从走到跑如果只有一个 Walk 动画，速度变快时脚还在原地踏，像在冰上滑。这两个问题分别由「状态机过渡」和「混合树」解决——前者管「何时切换」，后者管「多个动画如何融合」，组合起来才不抖、不滑步。

## 状态机与混合树

<Term def="动画状态机用状态节点和带条件转移决定当前播放哪个动画，转移带过渡时间做 cross-fade 平滑切换。">动画状态机</Term>管「播什么、何时切换」。状态节点（Idle/Walk/Run/Jump）之间用带条件的转移连接（如 speed>0 从 Idle 切到 Walk），过渡期内两动画按权重交叉淡入淡出（cross-fade），掩盖瞬间跳变。**混合树**管「多个动画如何加权融合」：按一个参数（如 speed）在 Idle/Walk/Run 间插值，输出 $\sum w(\text{speed}) \cdot \text{pose}_i$，让动画随速度连续变化。

```cpp
// 1D 混合树：按 speed 在 Idle/Walk/Run 间插值
Pose BlendTree1D::Sample(float speed) {
    // 找到 speed 落在哪两个采样点之间，做线性插值
    auto [lo, hi] = FindSamples(speed);        // lo.speed <= speed <= hi.speed
    float t = (speed - lo.speed) / (hi.speed - lo.speed);
    return Lerp(lo.pose, hi.pose, t);          // w_lo = 1-t, w_hi = t
}

// 状态机过渡：cross-fade 混合新旧动画
Pose FSM::Tick(float dt) {
    if (transitionTimer < transitionDuration) {
        float a = transitionTimer / transitionDuration;
        transitionTimer += dt;
        return Lerp(fromAnim.Sample(), toAnim.Sample(), a);  // 旧→新淡入淡出
    }
    return toAnim.Sample();
}
```

## 滑步与平滑

滑步是动画里脚在动、但脚的位移和角色逻辑位移不匹配，看着脚在地上滑。混合树按移动速度插值，让动画的「脚部周期位移」接近角色真实速度——慢走 Idle/Walk、快跑混入 Run，避免高速还播 Walk。2D 混合树按「方向角+速度」二维插值，适合 8 方向移动。惯性化（Inertializing）比 cross-fade 更现代：给姿态变化加弹簧式衰减过渡，即使混合树本身不连续也能无跳变，还省动画。

<Callout type="trap">
  **误区：状态机切换不做过渡。**
  直接换动画会让骨骼姿势瞬间跳变，视觉上像「跳帧」。过渡期内的 cross-fade
  让切换在几十毫秒内平滑，这是状态机不可省的一环。
</Callout>

<Exercises>
**问题 1**：状态机和混合树各自负责什么？

<Answer>
  状态机负责「播什么、何时切换」：用状态节点和带条件转移决定当前动画，转移带过渡做
  cross-fade。混合树负责「多个动画如何加权融合」：按参数在多个采样动画间插值输出融合姿态。二者组合才能既切换合理又过渡平滑。
</Answer>

**问题 2**：什么是滑步？混合树如何缓解？

<Answer>
滑步指动画里脚在动但脚的位移和角色逻辑位移不匹配，脚在地上滑。混合树按移动速度参数在 Idle/Walk/Run 间插值，让动画的脚部周期位移尽量接近角色真实速度，避免高速时还播 Walk 导致脚划空。完全消除还需根运动或位移驱动动画，但混合树是第一道防线。
</Answer>
</Exercises>

<Glossary>
  <GlossaryItem term="cross-fade">
    状态切换时两动画按权重交叉淡入淡出，掩盖瞬间跳变。
  </GlossaryItem>
  <GlossaryItem term="混合树">
    按参数在多个采样动画间加权插值，输出融合姿态，让动画随参数连续变化。
  </GlossaryItem>
  <GlossaryItem term="惯性化">
    给姿态变化加弹簧式衰减过渡，让任何突变平滑收敛，比 cross-fade 更省动画。
  </GlossaryItem>
</Glossary>
