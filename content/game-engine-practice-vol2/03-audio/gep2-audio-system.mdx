## 直觉引入

枪声从左边传来，你会不自觉朝左看——这就是 3D 音频提供的方位信息。但如果背景音乐也「从左边传来」，听起来就诡异了：歌手像在场景里绕着你的头跑。音频系统的难点不是播放声音，而是「哪些声音该有空间感、哪些不该有」，以及「怎么把成百上千个声源有条理地混成一路输出」。

## 空间化与混音

<Term def="3D 空间化根据声源相对听众的位置，对声音施加距离衰减、声像分配和多普勒效果，模拟声音从空间某点传来。">
  3D 空间化
</Term>
有三个要素：**距离衰减**让音量随距离减弱（近场封顶不放大、远场渐隐至 0）；**声像
Panning** 按声源方位分配到左右声道（HRTF
做立体）；**多普勒/遮挡**按相对速度变调、按几何遮挡低通滤波。空间化只对音效做，结果汇入
**混音总线**：SFX/Music/Voice 各自一条分总线，再汇入 Master 主总线统一压限输出。

```cpp
// 3D 声源：计算距离衰减与声像
void AudioEmitter::Update(Vector3 listenerPos, Vector3 listenerVel) {
    Vector3 toSource = position - listenerPos;
    float dist = toSource.Length();
    // 距离衰减：近场不放大、远场线性渐隐
    float vol = (dist <= innerRadius) ? 1.0f
              : 1.0f - (dist - innerRadius) / (outerRadius - innerRadius);
    vol = Clamp(vol, 0.0f, 1.0f);
    // 声像：按方向在左右声道分配
    float pan = Normalize(toSource).Dot(listenerRight);  // [-1,1]
    voice->SetVolume(vol);
    voice->SetPan(pan);
    ApplyDoppler(listenerVel);   // 相对速度变调
}
```

## 总线分层

混音分总线让不同类别音量可独立调节（玩家调音乐不影响语音）、便于统一施加效果（音乐加压缩）、支持闪避（语音出现时压低音乐）。Master 主总线做最终压限和响度归一，防多声源叠加削波。关键边界：空间化只对「场景内、有明确位置」的声源（枪声、脚步）做；音乐和语音是「非场景内」的伴奏与提示，需要清晰稳定，走非空间化总线，否则听感诡异且忽大忽小。

<Callout type="trap">
  **误区：把所有声源都做 3D 空间化。**
  音乐和语音不在场景内，给它们加空间化会让歌手像绕头跑、语音忽大忽小。空间化的边界是「场景内、有明确位置的声源」，其余走非空间化总线。
</Callout>

<Exercises>
**问题 1**：3D 音频的距离衰减为什么「近场不放大」？

<Answer>
  若简单用
  1/distance，声源贴脸时音量趋向无穷大刺耳。设近场半径：距离小于它时音量封顶不放大（避免近场爆音），大于它时按曲线渐隐到
  0。这样既符合远场衰减听感，又防止声源靠近时音量失控。
</Answer>

**问题 2**：混音为什么要分总线？

<Answer>
分总线让不同类别音量可独立调节（调音乐不影响语音）、便于统一施加效果（如音乐加压缩）、支持闪避（语音出现时压低音乐）。Master 主总线做最终压限和响度归一，防多声源叠加削波。若所有声源直接混到一路，这些独立控制和效果都无法实现。
</Answer>

  <GlossaryItem term="3D 空间化">
    根据声源相对听众位置施加距离衰减、声像、多普勒，模拟声音从空间某点传来。
  </GlossaryItem>
  <GlossaryItem term="混音总线">

  </GlossaryItem>
  <GlossaryItem term="闪避 Ducking">
    某类声音（如语音）出现时自动压低另一类（如音乐），保证关键声音清晰。
  </GlossaryItem>
