### 五个核心抓手

1. **向量与点**：点描述位置，向量描述位移；两点相减得到向量，点加向量得到点。
2. **单位向量**：长度为一的向量只保留方向，单位化前必须处理零向量。
3. **点积**：分量乘积之和，也等于两向量长度乘夹角余弦。
4. **叉积**：生成垂直于两个输入的向量，方向由坐标手性决定。
5. **线性代数恒等式**：交换、结合、分配等规则决定公式能否安全重排。

## 从空间与约定开始

任何三维公式都先写对象类型、来源空间、目标空间、单位和约定。点描述位置，向量描述位移；两点相减得到向量，点加向量得到点。 长度为一的向量只保留方向，单位化前必须处理零向量。 若只保存三个或四个浮点数而丢失语义，错误通常会延迟到渲染、碰撞或插值阶段才显现。

$$
\mathcal C=(\text{object type},\text{source space},\text{target space},\text{units},\text{convention})
$$

工程接口应让非法组合尽早失败：点与方向不能随意相加，局部法线不能直接与世界光向量点积，度数不能静默传入弧度API。先画出原点和基向量，再检查结果，比只盯最终像素更可解释。

## 可核查推导

$$
\mathbf a\cdot\mathbf b=\|\mathbf a\|\|\mathbf b\|\cos\theta,\qquad \|\mathbf a\times\mathbf b\|=\|\mathbf a\|\|\mathbf b\|\sin\theta
$$

点积把一个向量投影到另一个方向，归一化后可直接求夹角余弦；叉积的长度等于两向量张成平行四边形的面积，方向按右手或左手约定确定。 推导时每一步标明使用了定义、正交性、单位化、线性、连续性还是近似；若条件被非均匀缩放、退化图元或有限时间步破坏，就必须切换算法或返回显式状态。

```python
from math import sqrt

def normalize(v):
    length = sqrt(sum(x*x for x in v))
    if length == 0: raise ValueError("zero vector")
    return tuple(x/length for x in v)

assert normalize((3, 4, 0)) == (0.6, 0.8, 0.0)
```

手算、代码和交互图应在一个非对称样例上得到一致结果。单位矩阵、零角度和原点只能做冒烟测试，因为它们经常让转置、符号和顺序错误互相抵消。

## 几何机制与数据流

**向量与点**：点描述位置，向量描述位移；两点相减得到向量，点加向量得到点。

**单位向量**：长度为一的向量只保留方向，单位化前必须处理零向量。

**点积**：分量乘积之和，也等于两向量长度乘夹角余弦。

数据流必须能逐段记录：输入对象先按约定进入数学表示，经变换或求解得到中间状态，再由渲染、物理或工具消费。每个中间状态保留空间标签和残差，才能区分源数据错误、公式错误与下游显示错误。

## 数值误差与边界

**叉积**：生成垂直于两个输入的向量，方向由坐标手性决定。

**线性代数恒等式**：交换、结合、分配等规则决定公式能否安全重排。

边界集至少覆盖零长度、平行、共面、极小尺度、负尺度、角度跨界、时间步变化和浮点接近阈值。相对误差与绝对误差要按量纲选用，不能让一个全局epsilon同时承担位置、角度和点积判断。

$$
e_{abs}=\|\hat{\mathbf y}-\mathbf y\|,\qquad e_{rel}=\frac{e_{abs}}{\max(\|\mathbf y\|,s_{min})}
$$

```python
experiment={"normal":"non-symmetric input","boundary":"degenerate or near threshold","counterexample":"把点和向量都存成三个数后忘记语义，结果对两个位置做了无意义的相加。","replay":"fixed inputs and conventions"}
assert set(experiment)=={"normal","boundary","counterexample","replay"}
```

## 验收证书

$$
\operatorname{accept}=\text{conventions fixed}\land\text{invariants hold}\land\text{error within budget}\land\text{replay succeeds}
$$

验收证书拒绝“看起来差不多”。它必须回答用了哪套手性和向量约定、哪个不变量被检查、误差预算是多少、退化输入如何返回，以及另一台机器怎样从输入重建结果。

## 常见误区

<Callout type="trap" title="约定或边界被隐藏">把点和向量都存成三个数后忘记语义，结果对两个位置做了无意义的相加。 修复时先让空间、单位、参数范围与退化状态显式化。</Callout>

<Callout type="trap" title="只验收最终画面">单位化零向量或极短向量，产生NaN并污染后续矩阵。 应同时检查中间数值、不变量、调试图和可重放反例。</Callout>
