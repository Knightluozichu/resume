### 五个核心抓手

1. **旋转矩阵**：正交且行列式为一，保持长度、角度和朝向。
2. **缩放与剪切**：分别改变基向量长度或让一个轴随另一个轴偏移。
3. **正交投影**：删除垂直于目标直线或平面的分量。
4. **变换组合**：矩阵乘法把多个步骤折叠为一次映射，但顺序不可交换。
5. **变换分类**：线性、仿射、可逆、正交和刚体类别给出不同不变量。

## 从空间与约定开始

任何三维公式都先写对象类型、来源空间、目标空间、单位和约定。正交且行列式为一，保持长度、角度和朝向。 分别改变基向量长度或让一个轴随另一个轴偏移。 若只保存三个或四个浮点数而丢失语义，错误通常会延迟到渲染、碰撞或插值阶段才显现。

$$
\mathcal C=(\text{object type},\text{source space},\text{target space},\text{units},\text{convention})
$$

工程接口应让非法组合尽早失败：点与方向不能随意相加，局部法线不能直接与世界光向量点积，度数不能静默传入弧度API。先画出原点和基向量，再检查结果，比只盯最终像素更可解释。

## 可核查推导

$$
R_z(\theta)=\begin{bmatrix}\cos\theta&-\sin\theta&0\\\sin\theta&\cos\theta&0\\0&0&1\end{bmatrix},\qquad \mathbf p'=S R\mathbf p
$$

旋转后两个单位基向量的坐标组成矩阵列；任意向量由原基线性组合，因此同一矩阵作用于所有点。复合时右侧变换先作用，交换缩放和旋转会改变非均匀缩放方向。 推导时每一步标明使用了定义、正交性、单位化、线性、连续性还是近似；若条件被非均匀缩放、退化图元或有限时间步破坏，就必须切换算法或返回显式状态。

```python
from math import cos, sin

def rotate2(p, theta):
    c,s=cos(theta),sin(theta)
    return c*p[0]-s*p[1], s*p[0]+c*p[1]

assert rotate2((1,0), 0) == (1.0,0.0)
```

手算、代码和交互图应在一个非对称样例上得到一致结果。单位矩阵、零角度和原点只能做冒烟测试，因为它们经常让转置、符号和顺序错误互相抵消。

## 几何机制与数据流

**旋转矩阵**：正交且行列式为一，保持长度、角度和朝向。

**缩放与剪切**：分别改变基向量长度或让一个轴随另一个轴偏移。

**正交投影**：删除垂直于目标直线或平面的分量。

数据流必须能逐段记录：输入对象先按约定进入数学表示，经变换或求解得到中间状态，再由渲染、物理或工具消费。每个中间状态保留空间标签和残差，才能区分源数据错误、公式错误与下游显示错误。


## 数值误差与边界

**变换组合**：矩阵乘法把多个步骤折叠为一次映射，但顺序不可交换。

**变换分类**：线性、仿射、可逆、正交和刚体类别给出不同不变量。

边界集至少覆盖零长度、平行、共面、极小尺度、负尺度、角度跨界、时间步变化和浮点接近阈值。相对误差与绝对误差要按量纲选用，不能让一个全局epsilon同时承担位置、角度和点积判断。

$$
e_{abs}=\|\hat{\mathbf y}-\mathbf y\|,\qquad e_{rel}=\frac{e_{abs}}{\max(\|\mathbf y\|,s_{min})}
$$

## 工程案例

模型实例的SRT组合必须用一组非均匀缩放、非零旋转和非零平移的测试姿态验收；只测原点、单位尺度或零角度，会让错误顺序看起来正确。 报告同时保存输入、空间约定、参数、关键中间值、残差与调试图层。若重放后结论改变，先比较约定和数据版本，再比较算法实现。

```python
evidence=[("旋转矩阵","definition"),("正交投影","derivation"),("变换分类","replay")]
assert len({name for name,_ in evidence})==3
```

1. 选一个非对称、可手算的正常样例，记录所有空间、单位和正方向。
2. 一次只改变一个参数，比较公式、代码与交互图的中间状态。
3. 加入退化或近阈值输入，确认返回状态与容差策略一致。
4. 固定输入与时间步重放，保存残差、失败原因和未覆盖范围。

## 验收证书

$$
\operatorname{accept}=\text{conventions fixed}\land\text{invariants hold}\land\text{error within budget}\land\text{replay succeeds}
$$

验收证书拒绝“看起来差不多”。它必须回答用了哪套手性和向量约定、哪个不变量被检查、误差预算是多少、退化输入如何返回，以及另一台机器怎样从输入重建结果。
