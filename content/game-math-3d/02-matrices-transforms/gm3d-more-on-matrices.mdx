## 从空间与约定开始

任何三维公式都先写对象类型、来源空间、目标空间、单位和约定。度量有向面积或体积缩放，零值意味着变换压扁维度而不可逆。 撤销可逆变换；数值实现应避免显式求逆并检查条件。 若只保存三个或四个浮点数而丢失语义，错误通常会延迟到渲染、碰撞或插值阶段才显现。

$$
\mathcal C=(\text{object type},\text{source space},\text{target space},\text{units},\text{convention})
$$

工程接口应让非法组合尽早失败：点与方向不能随意相加，局部法线不能直接与世界光向量点积，度数不能静默传入弧度API。先画出原点和基向量，再检查结果，比只盯最终像素更可解释。

## 可核查推导

$$
\mathbf p_{clip}=P\mathbf p_{view},\qquad \mathbf p_{ndc}=\frac{1}{w_{clip}}(x_{clip},y_{clip},z_{clip})
$$

针孔相机中的屏幕坐标与深度成反比，这不是三维线性映射。引入齐次w后先做四维线性映射，再除以w，便能用矩阵统一表达透视。 推导时每一步标明使用了定义、正交性、单位化、线性、连续性还是近似；若条件被非均匀缩放、退化图元或有限时间步破坏，就必须切换算法或返回显式状态。

```python
def perspective_divide(p):
    x,y,z,w=p
    if abs(w) < 1e-8: raise ValueError("point at infinity")
    return x/w,y/w,z/w

assert perspective_divide((2,4,6,2)) == (1,2,3)
```

手算、代码和交互图应在一个非对称样例上得到一致结果。单位矩阵、零角度和原点只能做冒烟测试，因为它们经常让转置、符号和顺序错误互相抵消。

## 几何机制与数据流

**行列式**：度量有向面积或体积缩放，零值意味着变换压扁维度而不可逆。

**逆矩阵**：撤销可逆变换；数值实现应避免显式求逆并检查条件。

**正交矩阵**：基向量两两垂直且单位化，逆等于转置。

数据流必须能逐段记录：输入对象先按约定进入数学表示，经变换或求解得到中间状态，再由渲染、物理或工具消费。每个中间状态保留空间标签和残差，才能区分源数据错误、公式错误与下游显示错误。


## 数值误差与边界

**齐次坐标**：用第四分量区分点和方向，并把平移纳入矩阵乘法。

**透视投影**：在齐次裁剪空间编码视锥，随后透视除法产生近大远小。

边界集至少覆盖零长度、平行、共面、极小尺度、负尺度、角度跨界、时间步变化和浮点接近阈值。相对误差与绝对误差要按量纲选用，不能让一个全局epsilon同时承担位置、角度和点积判断。

$$
e_{abs}=\|\hat{\mathbf y}-\mathbf y\|,\qquad e_{rel}=\frac{e_{abs}}{\max(\|\mathbf y\|,s_{min})}
$$

```python
experiment={"normal":"non-symmetric input","boundary":"degenerate or near threshold","counterexample":"用行列式不为零作为唯一数值稳定标准，忽略接近奇异的病态矩阵。","replay":"fixed inputs and conventions"}
assert set(experiment)=={"normal","boundary","counterexample","replay"}
```

## 工程案例

相机投影调试要保存视图空间、裁剪空间、NDC和屏幕空间四组坐标，并测试近平面、远平面和w接近零的点；只看最终像素无法区分矩阵与除法错误。 报告同时保存输入、空间约定、参数、关键中间值、残差与调试图层。若重放后结论改变，先比较约定和数据版本，再比较算法实现。

```python
evidence=[("行列式","definition"),("正交矩阵","derivation"),("透视投影","replay")]
assert len({name for name,_ in evidence})==3
```

1. 选一个非对称、可手算的正常样例，记录所有空间、单位和正方向。
2. 一次只改变一个参数，比较公式、代码与交互图的中间状态。
3. 加入退化或近阈值输入，确认返回状态与容差策略一致。
4. 固定输入与时间步重放，保存残差、失败原因和未覆盖范围。

## 验收证书

$$
\operatorname{accept}=\text{conventions fixed}\land\text{invariants hold}\land\text{error within budget}\land\text{replay succeeds}
$$

验收证书拒绝“看起来差不多”。它必须回答用了哪套手性和向量约定、哪个不变量被检查、误差预算是多少、退化输入如何返回，以及另一台机器怎样从输入重建结果。
