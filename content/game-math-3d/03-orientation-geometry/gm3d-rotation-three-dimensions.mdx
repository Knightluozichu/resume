### 五个核心抓手

1. **欧拉角**：按约定顺序绕三个轴旋转，直观但有顺序依赖与万向节锁。
2. **轴角与指数映射**：用旋转轴和角度描述角位移，适合小旋转与优化。
3. **单位四元数**：单位四元数表示三维旋转，q与负q代表同一方位。
4. **球面插值**：Slerp沿单位四元数球面的短弧以恒定角速度插值。
5. **表示转换**：矩阵、欧拉角、轴角与四元数各有边界，转换必须固定约定。

## 从空间与约定开始

任何三维公式都先写对象类型、来源空间、目标空间、单位和约定。按约定顺序绕三个轴旋转，直观但有顺序依赖与万向节锁。 用旋转轴和角度描述角位移，适合小旋转与优化。 若只保存三个或四个浮点数而丢失语义，错误通常会延迟到渲染、碰撞或插值阶段才显现。

$$
\mathcal C=(\text{object type},\text{source space},\text{target space},\text{units},\text{convention})
$$

工程接口应让非法组合尽早失败：点与方向不能随意相加，局部法线不能直接与世界光向量点积，度数不能静默传入弧度API。先画出原点和基向量，再检查结果，比只盯最终像素更可解释。

## 可核查推导

$$
q=(\cos\frac{\theta}{2},\ \hat{\mathbf n}\sin\frac{\theta}{2}),\qquad \operatorname{slerp}(q_0,q_1,t)=\frac{\sin((1-t)\Omega)}{\sin\Omega}q_0+\frac{\sin(t\Omega)}{\sin\Omega}q_1
$$

单位四元数的实部和虚部分别编码半角余弦与轴乘半角正弦。两个单位四元数先选择点积为正的同半球表示，再沿大圆短弧插值，避免长路径和速度不匀。 推导时每一步标明使用了定义、正交性、单位化、线性、连续性还是近似；若条件被非均匀缩放、退化图元或有限时间步破坏，就必须切换算法或返回显式状态。

```python
def same_hemisphere(a,b):
    dot=sum(x*y for x,y in zip(a,b))
    return tuple(-x for x in b) if dot < 0 else b

assert same_hemisphere((1,0,0,0),(-1,0,0,0)) == (1,0,0,0)
```

手算、代码和交互图应在一个非对称样例上得到一致结果。单位矩阵、零角度和原点只能做冒烟测试，因为它们经常让转置、符号和顺序错误互相抵消。

## 数值误差与边界

**球面插值**：Slerp沿单位四元数球面的短弧以恒定角速度插值。

**表示转换**：矩阵、欧拉角、轴角与四元数各有边界，转换必须固定约定。

边界集至少覆盖零长度、平行、共面、极小尺度、负尺度、角度跨界、时间步变化和浮点接近阈值。相对误差与绝对误差要按量纲选用，不能让一个全局epsilon同时承担位置、角度和点积判断。

$$
e_{abs}=\|\hat{\mathbf y}-\mathbf y\|,\qquad e_{rel}=\frac{e_{abs}}{\max(\|\mathbf y\|,s_{min})}
$$

```python
experiment={"normal":"non-symmetric input","boundary":"degenerate or near threshold","counterexample":"对四元数四个分量直接线性插值后不归一化，导致旋转漂移。","replay":"fixed inputs and conventions"}
assert set(experiment)=={"normal","boundary","counterexample","replay"}
```

## 验收证书

$$
\operatorname{accept}=\text{conventions fixed}\land\text{invariants hold}\land\text{error within budget}\land\text{replay succeeds}
$$

验收证书拒绝“看起来差不多”。它必须回答用了哪套手性和向量约定、哪个不变量被检查、误差预算是多少、退化输入如何返回，以及另一台机器怎样从输入重建结果。

## 常见误区

<Callout type="trap" title="约定或边界被隐藏">对四元数四个分量直接线性插值后不归一化，导致旋转漂移。 修复时先让空间、单位、参数范围与退化状态显式化。</Callout>

<Callout type="trap" title="只验收最终画面">忽略q与负q等价，Slerp选择长弧并出现突然翻转。 应同时检查中间数值、不变量、调试图和可重放反例。</Callout>
