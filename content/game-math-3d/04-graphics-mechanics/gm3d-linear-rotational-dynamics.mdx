### 五个核心抓手

1. **牛顿定律**：合力等于动量变化率；作用与反作用力大小相等方向相反。
2. **动量与冲量**：冲量是力对时间的积分，直接改变线动量。
3. **碰撞响应**：沿接触法线求冲量，并结合恢复系数和摩擦处理速度变化。
4. **转动惯量**：物体对角速度变化的阻抗，取决于质量相对转轴的分布。
5. **数值积分**：实时模拟离散推进状态，时间步与积分器决定稳定性和误差。

## 从空间与约定开始

任何三维公式都先写对象类型、来源空间、目标空间、单位和约定。合力等于动量变化率；作用与反作用力大小相等方向相反。 冲量是力对时间的积分，直接改变线动量。 若只保存三个或四个浮点数而丢失语义，错误通常会延迟到渲染、碰撞或插值阶段才显现。

$$
\mathcal C=(\text{object type},\text{source space},\text{target space},\text{units},\text{convention})
$$

工程接口应让非法组合尽早失败：点与方向不能随意相加，局部法线不能直接与世界光向量点积，度数不能静默传入弧度API。先画出原点和基向量，再检查结果，比只盯最终像素更可解释。

## 可核查推导

$$
\mathbf J=\int\mathbf Fdt=\Delta\mathbf p,\qquad j=-\frac{(1+e)\mathbf v_{rel}\cdot\mathbf n}{m_A^{-1}+m_B^{-1}+\text{rotational terms}}
$$

碰撞持续时间极短，直接积分巨大接触力不稳定，因此使用冲量。令碰撞后的法向相对速度等于碰撞前的负e倍，再把线速度和角速度对冲量的响应代入即可解出标量冲量。 推导时每一步标明使用了定义、正交性、单位化、线性、连续性还是近似；若条件被非均匀缩放、退化图元或有限时间步破坏，就必须切换算法或返回显式状态。

```python
def normal_impulse(relative_speed, restitution, inv_mass_sum):
    if relative_speed >= 0: return 0.0
    return -(1+restitution)*relative_speed/inv_mass_sum

assert normal_impulse(-4,.5,2) == 3.0
```

手算、代码和交互图应在一个非对称样例上得到一致结果。单位矩阵、零角度和原点只能做冒烟测试，因为它们经常让转置、符号和顺序错误互相抵消。

**动量与冲量**：冲量是力对时间的积分，直接改变线动量。

数据流必须能逐段记录：输入对象先按约定进入数学表示，经变换或求解得到中间状态，再由渲染、物理或工具消费。每个中间状态保留空间标签和残差，才能区分源数据错误、公式错误与下游显示错误。


## 数值误差与边界

**转动惯量**：物体对角速度变化的阻抗，取决于质量相对转轴的分布。

**数值积分**：实时模拟离散推进状态，时间步与积分器决定稳定性和误差。

边界集至少覆盖零长度、平行、共面、极小尺度、负尺度、角度跨界、时间步变化和浮点接近阈值。相对误差与绝对误差要按量纲选用，不能让一个全局epsilon同时承担位置、角度和点积判断。

$$
e_{abs}=\|\hat{\mathbf y}-\mathbf y\|,\qquad e_{rel}=\frac{e_{abs}}{\max(\|\mathbf y\|,s_{min})}
$$

4. 固定输入与时间步重放，保存残差、失败原因和未覆盖范围。

## 验收证书

$$
\operatorname{accept}=\text{conventions fixed}\land\text{invariants hold}\land\text{error within budget}\land\text{replay succeeds}
$$

验收证书拒绝“看起来差不多”。它必须回答用了哪套手性和向量约定、哪个不变量被检查、误差预算是多少、退化输入如何返回，以及另一台机器怎样从输入重建结果。
