### 五个核心抓手

1. **最近点**：通过投影或逐轴钳制找到图元上距离查询点最近的位置。
2. **相交参数**：将两个图元方程联立，求满足各自参数范围的解。
3. **分离判据**：找到能把两个图元分开的轴或平面即可证明不相交。
4. **退化输入**：零方向、零面积、平行、共面和切触需要明确结果语义。
5. **容差策略**：容差应与尺度和计算误差相关，不能用一个全局魔法常数。

## 从空间与约定开始

任何三维公式都先写对象类型、来源空间、目标空间、单位和约定。通过投影或逐轴钳制找到图元上距离查询点最近的位置。 将两个图元方程联立，求满足各自参数范围的解。 若只保存三个或四个浮点数而丢失语义，错误通常会延迟到渲染、碰撞或插值阶段才显现。

## 可核查推导

$$
t^*=\operatorname{clamp}\left(\frac{(\mathbf p-\mathbf o)\cdot\mathbf d}{\mathbf d\cdot\mathbf d},t_{min},t_{max}\right),\qquad \mathbf q=\mathbf o+t^*\mathbf d
$$

点到参数直线的平方距离是t的二次函数，对t求导并令其为零得到投影参数；线段或射线再把参数钳制到合法区间。方向长度不必为一，但方向为零必须单独处理。 推导时每一步标明使用了定义、正交性、单位化、线性、连续性还是近似；若条件被非均匀缩放、退化图元或有限时间步破坏，就必须切换算法或返回显式状态。

```python
def closest_on_segment(p,a,b):
    d=tuple(y-x for x,y in zip(a,b))
    denom=sum(x*x for x in d)
    if denom==0: return a
    t=max(0,min(1,sum((p[i]-a[i])*d[i] for i in range(3))/denom))
    return tuple(a[i]+t*d[i] for i in range(3))

assert closest_on_segment((3,1,0),(0,0,0),(2,0,0)) == (2,0,0)
```

手算、代码和交互图应在一个非对称样例上得到一致结果。单位矩阵、零角度和原点只能做冒烟测试，因为它们经常让转置、符号和顺序错误互相抵消。

## 几何机制与数据流

**最近点**：通过投影或逐轴钳制找到图元上距离查询点最近的位置。

**相交参数**：将两个图元方程联立，求满足各自参数范围的解。

**分离判据**：找到能把两个图元分开的轴或平面即可证明不相交。

数据流必须能逐段记录：输入对象先按约定进入数学表示，经变换或求解得到中间状态，再由渲染、物理或工具消费。每个中间状态保留空间标签和残差，才能区分源数据错误、公式错误与下游显示错误。

## 数值误差与边界

**退化输入**：零方向、零面积、平行、共面和切触需要明确结果语义。

**容差策略**：容差应与尺度和计算误差相关，不能用一个全局魔法常数。

边界集至少覆盖零长度、平行、共面、极小尺度、负尺度、角度跨界、时间步变化和浮点接近阈值。相对误差与绝对误差要按量纲选用，不能让一个全局epsilon同时承担位置、角度和点积判断。

$$
e_{abs}=\|\hat{\mathbf y}-\mathbf y\|,\qquad e_{rel}=\frac{e_{abs}}{\max(\|\mathbf y\|,s_{min})}
$$

```python
experiment={"normal":"non-symmetric input","boundary":"degenerate or near threshold","counterexample":"先单位化零长度方向，再让NaN通过所有比较分支。","replay":"fixed inputs and conventions"}
assert set(experiment)=={"normal","boundary","counterexample","replay"}
```

## 工程案例

为每个几何查询固定返回结构：是否命中、参数、最近点、法线和退化状态；测试明确区分穿过、切触、平行、共面、端点和零尺寸输入。 报告同时保存输入、空间约定、参数、关键中间值、残差与调试图层。若重放后结论改变，先比较约定和数据版本，再比较算法实现。

```python
evidence=[("最近点","definition"),("分离判据","derivation"),("容差策略","replay")]
assert len({name for name,_ in evidence})==3
```

1. 选一个非对称、可手算的正常样例，记录所有空间、单位和正方向。
2. 一次只改变一个参数，比较公式、代码与交互图的中间状态。
3. 加入退化或近阈值输入，确认返回状态与容差策略一致。
4. 固定输入与时间步重放，保存残差、失败原因和未覆盖范围。

## 验收证书

$$
\operatorname{accept}=\text{conventions fixed}\land\text{invariants hold}\land\text{error within budget}\land\text{replay succeeds}
$$

验收证书拒绝“看起来差不多”。它必须回答用了哪套手性和向量约定、哪个不变量被检查、误差预算是多少、退化输入如何返回，以及另一台机器怎样从输入重建结果。

## 常见误区

<Callout type="trap" title="约定或边界被隐藏">先单位化零长度方向，再让NaN通过所有比较分支。 修复时先让空间、单位、参数范围与退化状态显式化。</Callout>

<Callout type="trap" title="只验收最终画面">不同查询对边界是否算命中采用不同规则，造成宽阶段与窄阶段不一致。 应同时检查中间数值、不变量、调试图和可重放反例。</Callout>
