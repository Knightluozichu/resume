## 核心模型

前四章建立分析语言：规则怎样形成离散或连续机制，涌现与进程怎样组合，复杂系统为何会产生难以直接预测的玩法，以及资源、实体和经济函数怎样构成内部经济。

第五至第九章把分析变成工具：Machinations 用节点和连接器表达资源流，第六章扩展反馈与随机机制，第七章抽取可复用模式，第八章用人工玩家做模拟平衡，第九章以 Caesar III 与 Lunar Colony 展示经济设计。

最后三章把系统接回体验：关卡空间承担教学和挑战编排，渐进机制把锁钥与资源进程结合，有意义的机制则要求规则、玩家行动和表达主题相互一致。三个附录提供符号、模式和工具操作的复验入口。

## 可复现实验

从一款熟悉游戏选择一条核心循环，分别写出规则、资源流、可测输出和玩家感受，再标注它对应本书哪一章；无法落位的环节就是阅读缺口。

使用下面的实验契约记录每次运行。它故意把模型、种子和终止原因放进结果，避免只保留最终均值。

```ts
type RunEvidence = {
  modelVersion: string;
  seed: number;
  stages: readonly string[];
  observations: readonly number[];
  firstDeviation: string | null;
  termination: "complete" | "rejected" | "timeout";
};

const stages = ["目录身份","规则模型","资源流图","模拟样本","体验验证","签发证据"] as const;

function validateRun(run: RunEvidence): boolean {
  return run.stages.length === stages.length &&
    run.observations.length === stages.length &&
    run.termination !== "timeout";
}
```

证据表至少包含以下列，且同一对照组只能修改一个计划变量。

```text
model,seed,variant,stage,input,state_before,state_after,metric,first_deviation,termination
gma-official-learning-map,17,baseline,目录身份,fixed,0,1,1.0,,complete
gma-official-learning-map,17,failure,资源流图,fixed,1,9,9.0,资源流图,rejected
```

## 验收矩阵

| 维度 | 正常样本 | 边界样本 | 失败样本 | 通过条件 |
| --- | --- | --- | --- | --- |
| 目录 | 官方主题逐项可定位 | 相邻主题交叉 | 故意漏一项 | 覆盖无空洞 |
| 状态 | 同输入可重放 | 容量或阈值附近 | 注入首个偏离 | 因果可定位 |
| 分布 | 多策略多种子 | 长尾与极端输入 | 统治策略或失控 | 结论不过拟合 |
| 体验 | 模型与玩家一致 | 新手或回退路径 | 误解、软锁或反表达 | 四门同时通过 |
