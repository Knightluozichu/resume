## 核心模型

突现系统把内容压缩进规则：棋类和模拟游戏的深度来自规则交互。渐进系统把内容编码进序列：冒险、任务和谜题通过预制节点保证节奏、叙事和教学。

比较两者不能只看自由度。应记录内容生产成本、玩家路径数量、状态可恢复性、失败后重试成本和设计者控制力。突现过强会失去节奏，渐进过强会降低重玩价值。

融合结构通常让渐进层解锁新的规则、资源或空间，再让突现层在每个阶段产生多种解法。验收重点是阶段门是否真的扩大行为空间，以及旧策略是否仍有意义。

本页采用下式作为最小可核查模型：

$$
D=\frac{|S_{reachable}|}{|R|+|C_{authored}|}
$$

## 可复现实验

选择同一战斗主题，制作一个完全线性的三关版本和一个规则驱动的竞技场版本，再增加阶段解锁形成混合版；用路径数和策略分布比较三者。

使用下面的实验契约记录每次运行。它故意把模型、种子和终止原因放进结果，避免只保留最终均值。

```ts
type RunEvidence = {
  modelVersion: string;
  seed: number;
  stages: readonly string[];
  observations: readonly number[];
  firstDeviation: string | null;
  termination: "complete" | "rejected" | "timeout";
};

const stages = ["内容节点","规则集合","可达状态","玩家路径","阶段门","重玩证据"] as const;

function validateRun(run: RunEvidence): boolean {
  return run.stages.length === stages.length &&
    run.observations.length === stages.length &&
    run.termination !== "timeout";
}
```

证据表至少包含以下列，且同一对照组只能修改一个计划变量。

```text
model,seed,variant,stage,input,state_before,state_after,metric,first_deviation,termination

gma-02-emergence-progression,17,failure,可达状态,fixed,1,9,9.0,可达状态,rejected
```
