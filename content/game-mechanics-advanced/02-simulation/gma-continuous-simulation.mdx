## 直觉引入

想象你在推一个雪球下山。雪球越滚越大，滚得越来越快——这是正反馈。现在想象你在拉橡皮筋，拉得越远回弹力越大——这是负反馈。游戏中的反馈环路也是这样：正反馈放大差异（滚雪球），负反馈缩小差异（橡皮筋）。

## 概念讲解

### 积分器与连续更新

<GmaContinuousSimulationDiagram />

<Term def="用数值方法近似计算积分，每帧用 x += v*dt 更新状态">欧拉积分</Term>是连续模拟的基础。每帧更新：位置 += 速度 * dt，速度 += 加速度 * dt。dt 是帧时间（如 1/60 秒）。简单直观但有累积误差。

### 反馈环路

<Term def="放大差异的反馈循环，领先者更领先，制造滚雪球效应">正反馈</Term>：击杀→经验→升级→更强→杀更快。制造爽感但过度会过早失去悬念。

<Term def="缩小差异的反馈循环，落后者更容易追赶，维持竞争悬念">负反馈</Term>：落后者获得更好道具（橡皮筋效应）。维持悬念但过度会让领先无意义。

## 代码对照

```csharp
// 连续模拟：每帧更新
public class ContinuousSimulator {
    void Update(float dt) {
        // 欧拉积分更新位置
        position += velocity * dt;
        velocity += acceleration * dt;

        // 正反馈：击杀→经验→升级→更强
        if (enemyKilled) {
            xp += 20;
            if (xp >= xpToLevel) {
                level++;
                damage *= 1.1f; // 越来越强
            }
        }

        // 负反馈：动态难度
        float difficultyScale = 1f + (playerLevel - enemyLevel) * 0.1f;
        enemyDamage *= difficultyScale; // 玩家越强敌人也越强
    }
}
```

## 常见误区

<Callout type="trap">
**现象：正反馈过强，一局游戏过早失去悬念。**
原因：滚雪球效应让领先者不可逆转。修法：加入负反馈——动态难度、追赶机制、边际递减（升级所需经验指数增长）。
</Callout>

<Callout type="trap">
**现象：橡皮筋效应被玩家发现，感到被操纵。**
原因：负反馈太明显，玩家觉得「领先反而被惩罚」。修法：橡皮筋要隐蔽且有上限，让追赶可能但领先仍有优势。
</Callout>

<Exercises>
**问题 1**：正反馈和负反馈在游戏设计中各起什么作用？

<Answer>
正反馈放大差异，制造滚雪球效应和爽感，但过度导致过早失去悬念。负反馈缩小差异，维持竞争悬念，但过度让领先无意义。好游戏通常正负反馈混合：正反馈制造爽感，负反馈维持悬念。
</Answer>
</Exercises>
