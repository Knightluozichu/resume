## 直觉引入

想象你在管理一个医院急诊室。病人不是匀速到来的——有时没病人，有时同时来三个。你不需要每秒检查「有没有病人」，你只需要在病人到达时处理。这就是离散事件模拟：系统只在事件发生时变化，时间跳到下一个事件时刻。

## 概念讲解

### 事件队列驱动

<GmaDiscreteSimulationDiagram />

<Term def="一种模拟方法，系统状态只在离散的事件发生时改变，时间跳到下一个事件时刻">离散事件模拟（DES）</Term>的核心是维护一个按时间排序的事件队列。循环执行：取出最早事件→处理事件（可能产生新事件）→新事件按时间入队→跳到下一个事件。

适用于状态变化离散的系统——回合制 RPG、棋牌、卡牌、ATB 战斗。

### 因果关系与同时事件

处理事件 A 可能产生新事件 B，B 的时间戳必须 &gt;= A 的时间戳（不能回到过去）。两个事件时间戳相同时，需要确定性消歧策略——优先级队列或按事件类型排序。

## 代码对照

```csharp
// 离散事件模拟器核心
public class EventSimulator {
    // 优先队列：按时间戳排序
    private PriorityQueue<GameEvent, float> queue = new();

    public void Run() {
        while (queue.Count > 0) {
            var evt = queue.Dequeue();
            ProcessEvent(evt); // 处理可能产生新事件
        }
    }

    void ProcessEvent(GameEvent evt) {
        switch (evt.Type) {
            case EventType.SpawnEnemy:
                SpawnEnemy();
                Enqueue(new GameEvent(EventType.PlayerTurn, evt.Time + 1f));
                break;
            case EventType.Attack:
                float damage = CalculateDamage();
                Enqueue(new GameEvent(EventType.DeathCheck, evt.Time + 0.1f));
                break;
            // ...
        }
    }

    void Enqueue(GameEvent evt) {
        queue.Enqueue(evt, evt.Time); // 按时间排序
    }
}
```

## 常见误区

<Callout type="trap">
**现象：同时事件处理顺序不确定，导致模拟不可复现。**
原因：两个事件时间戳相同时，如果用普通队列，处理顺序不确定。修法：用确定性消歧——给事件加优先级字段，同时事件按优先级排序。
</Callout>

<Exercises>
**问题 1**：离散事件模拟的核心思想是什么？

<Answer>
系统状态只在离散的事件发生时改变，时间不连续推进而是跳到下一个事件时刻。维护一个按时间排序的事件队列，循环执行：取出最早事件→处理事件→产生新事件入队→跳到下一个事件。
</Answer>
</Exercises>
