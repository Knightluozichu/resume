## 直觉引入

想象游戏经济是一个水池。水龙头往里注水（资源产出），水槽往外排水（资源消耗）。如果水龙头比水槽大，水池溢出——通货膨胀，金币不值钱。如果水槽比水龙头大，水池干涸——通货紧缩，玩家挫败。经济设计的核心就是让水龙头和水槽匹配。

## 概念讲解

### 水龙头与水槽

<GmaEconomyDesignDiagram />

<Term def="资源进入游戏的机制，如怪物掉落、任务奖励、资源采集">水龙头（Faucet）</Term>是资源产出。<Term def="资源离开游戏的机制，如升级消耗、商店购买、死亡掉落">水槽（Sink）</Term>是资源消耗。经济平衡的核心：产出率 ≈ 消耗率。

### 经济类型

静态经济：固定产出/消耗速率，简单可预测但缺乏策略深度。动态经济：产出随行为变化，有策略深度。多体经济：多资源互相转换（通过转换器），最复杂，能涌现交易行为。

## 代码对照

```csharp
// 游戏经济系统
public class GameEconomy {
    // 水龙头：资源产出
    public int goldPerKill = 10;
    public int goldPerQuest = 50;

    // 水槽：资源消耗
    public int upgradeCost = 100;
    public int repairCost = 5;

    // 转换器：资源转换
    public bool CraftWeapon(int ironOre, int coal) {
        if (ironOre >= 3 && coal >= 2) {
            // 3 铁矿 + 2 煤 → 1 武器
            return true;
        }
        return false;
    }

    // 平衡检查：每回合产出 vs 消耗
    public bool IsBalanced() {
        float production = goldPerKill * avgKillsPerRound + goldPerQuest;
        float consumption = upgradeCost * avgUpgradesPerRound + repairCost;
        return Mathf.Abs(production - consumption) < production * 0.1f; // 10% 以内
    }
}
```

## 常见误区

<Callout type="trap">
**现象：只加水龙头不加水槽，资源无限积累。**
原因：产出没有对应的消耗，金币越积越多，贬值成废纸。修法：每加一个水龙头必须对应一个水槽——新增掉落就新增消耗（如新装备升级费）。
</Callout>

<Exercises>
**问题 1**：游戏经济系统的「水龙头」和「水槽」分别是什么？

<Answer>
水龙头是资源进入游戏的机制（怪物掉落、任务奖励），水槽是资源离开游戏的机制（升级消耗、商店购买）。经济平衡的核心是产出率 ≈ 消耗率。产出&gt;消耗=通货膨胀，消耗&gt;产出=通货紧缩。
</Answer>
</Exercises>
