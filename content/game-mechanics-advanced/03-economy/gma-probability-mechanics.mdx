## 直觉引入

掷骰子是均匀分布——每面等概率。人的身高是正态分布——大多数人中等，极高极矮很少。地震是指数分布——小震频繁，大震极罕。游戏中的随机也一样：选对分布能塑造不同的玩家体验。

## 概念讲解

### 三种随机类型

<GmaProbabilityMechanicsDiagram />

<Term def="游戏开始时生成的随机内容，如地图种子，玩家可适应且有公平感">输入随机</Term>：生成后不变，玩家能规划策略。<Term def="运行时实时判定的随机，如暴击率，增加紧张感但过度让玩家失控">过程随机</Term>。<Term def="结果确定后随机加成，如掉落品质，制造惊喜但过度导致赌博式上瘾">输出随机</Term>。

### 概率分布

均匀分布（等概率）：掷骰子、抽卡。正态分布（钟形曲线）：伤害波动、属性生成。指数分布（长尾）：稀有掉落。选择关键：均匀=公平透明，正态=自然真实，指数=制造稀有性。

### 伪随机分布（PRD）

纯随机 90% 命中率可能连续 miss 两次（1% 概率），玩家觉得不公平。PRD 逐渐提高概率：第一次降低，miss 后提升，总体命中率不变但消除极端连续 miss。玩家感知的公平比数学公平更重要。

## 代码对照

```csharp
// 伪随机分布（PRD）实现
public class PRD {
    private float baseChance = 0.9f;  // 基础命中率
    private int missCount = 0;         // 连续 miss 次数

    public bool Roll() {
        // PRD：连续 miss 后概率递增
        float currentChance = baseChance + missCount * 0.05f;
        currentChance = Mathf.Min(currentChance, 0.99f); // 上限 99%

        if (Random.value < currentChance) {
            missCount = 0;  // 重置
            return true;    // 命中
        } else {
            missCount++;    // 累计 miss
            return false;   // 未命中
        }
    }
}

// 指数分布：稀有掉落
public Item RollDrop() {
    float r = Random.value;
    if (r < 0.01f) return Item.Legendary;  // 1% 传说
    if (r < 0.10f) return Item.Epic;       // 9% 史诗
    if (r < 0.40f) return Item.Rare;       // 30% 稀有
    return Item.Common;                     // 60% 普通
}
```

## 常见误区

<Callout type="trap">
**现象：用纯随机导致极端非酋，玩家觉得被系统针对。**
原因：纯随机不关心历史，连续 miss 虽然概率低但必然发生。修法：用 PRD 逐渐提高概率，或加保底机制（连续 miss N 次后必中）。
</Callout>

<Exercises>
**问题 1**：游戏设计中三种随机类型分别是什么？

<Answer>
输入随机：游戏开始时生成随机内容（地图种子），玩家可适应且有公平感。过程随机：运行时实时判定（暴击率），增加紧张感但过度让玩家失控。输出随机：结果确定后随机加成（掉落品质），制造惊喜但过度导致赌博式上瘾。
</Answer>
</Exercises>
