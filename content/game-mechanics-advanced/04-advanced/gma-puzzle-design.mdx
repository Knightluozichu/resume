## 直觉引入

玩一个好游戏时，你会进入一种「时间飞逝」的状态——不太简单（不会无聊），也不太难（不会焦虑）。这叫心流。谜题设计的核心就是把难度曲线维持在这个心流通道里：玩家掌握一个技能后立刻面临稍难的新挑战。

## 概念讲解

### 心流通道

<GmaPuzzleDesignDiagram />

<Term def="难度曲线维持在焦虑区（太难）和无事可（太易）之间的通道，让玩家持续处于心流状态">心流通道</Term>要求难度阶梯式递进——每步增幅小但持续，让玩家始终处于「刚好能应对但需要专注」的状态。

### 谜题三层次

单一解：只有一个正确解法，适合教学关卡。多解：有 2-3 种解法各有优劣，适合中级关卡。涌现解：设计师未预设但规则允许的解法，适合高级关卡，成就感最强。

设计原则：每个新机制先教学（单一解）→ 再挑战（多解）→ 后组合（涌现解）。

## 代码对照

```csharp
// 渐进难度系统
public class DifficultyCurve {
    public int level = 1;

    // 难度随关卡递进
    public float GetDifficulty() {
        // 心流通道：难度 = 基础 * (1 + level * 增幅)
        return 1f * (1f + level * 0.15f);
    }

    // 检查是否在心流通道内
    public DifficultyZone CheckZone(float playerSkill) {
        float diff = GetDifficulty();
        float ratio = diff / playerSkill;

        if (ratio > 1.3f) return DifficultyZone.Anxiety;  // 太难
        if (ratio < 0.7f) return DifficultyZone.Boredom;   // 太易
        return DifficultyZone.Flow;                         // 心流
    }
}

public enum DifficultyZone { Flow, Anxiety, Boredom }
```

## 常见误区

<Callout type="trap">
**现象：难度跳跃太大，玩家从心流直接掉入焦虑区。**
原因：相邻关卡难度增幅过大。修法：每步增幅控制在 10-15% 以内，中间加过渡关卡让玩家适应新机制。
</Callout>

<Exercises>
**问题 1**：谜题设计中「心流通道」是什么概念？

<Answer>
心流通道指难度曲线维持在焦虑区（太难，玩家挫败）和无事区（太易，玩家无聊）之间的通道。难度随玩家技能提升而渐进增加，让玩家持续处于「刚好能应对但需要专注」的心流状态。
</Answer>
</Exercises>
