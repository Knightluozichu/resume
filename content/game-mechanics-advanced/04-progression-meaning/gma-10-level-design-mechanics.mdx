## 核心模型

自由玩法让玩家探索机制可能性，目标导向玩法把可能性组织成挑战。关卡不应只是容器，它通过地形、距离、视线、资源和敌人配置改变机制的实际价值。

任务图描述目标依赖，游戏空间图描述位置连接。把机制映射到两张图，可以发现某项技能是否从未被要求、多个任务是否争用同一空间，以及捷径是否破坏教学顺序。

技能原子把感知、决策、动作和反馈组成最小学单元。教学关卡先隔离原子，再组合与变体化；难度提升应改变判断深度，而不是只增加数值压力。

本页采用下式作为最小可核查模型：

$$
L_{challenge}=K_{known}+N_{new}+I_{interaction}
$$

式子只定义要观察的关系，不能单独证明设计成立。必须保存输入上下文、逐步轨迹、边界样本和玩家行为对照。

<Term def="由感知、判断、动作和反馈构成的最小可学习玩法循环">技能原子</Term>必须在本页实验中留下可观察状态，不能只作为术语出现。

## 可复现实验

为一个移动加攻击机制制作教学、组合和边界三间房，逐间记录玩家首次成功时间、错误类型和是否理解反馈，再故意颠倒顺序观察失败。

使用下面的实验契约记录每次运行。它故意把模型、种子和终止原因放进结果，避免只保留最终均值。

```ts
type RunEvidence = {
  modelVersion: string;
  seed: number;
  stages: readonly string[];
  observations: readonly number[];
  firstDeviation: string | null;
  termination: "complete" | "rejected" | "timeout";
};

const stages = ["机制玩具","技能原子","任务依赖","空间拓扑","挑战组合","学习验证"] as const;

function validateRun(run: RunEvidence): boolean {
  return run.stages.length === stages.length &&
    run.observations.length === stages.length &&
    run.termination !== "timeout";
}
```

证据表至少包含以下列，且同一对照组只能修改一个计划变量。

```text
model,seed,variant,stage,input,state_before,state_after,metric,first_deviation,termination
gma-10-level-design-mechanics,17,baseline,机制玩具,fixed,0,1,1.0,,complete
gma-10-level-design-mechanics,17,failure,任务依赖,fixed,1,9,9.0,任务依赖,rejected
```

## 两个必须主动制造的失败样本

<Callout type="trap" title="结构或目录边界丢失">
  用敌人血量替代新挑战，或在未教学前同时要求多个陌生机制。保存错误模型、首个偏离节点和原始轨迹，再恢复本页官方主题逐项复验。
</Callout>

<Callout type="trap" title="数字改善但设计目标恶化">
  故意让平均指标变好，同时减少有效选择、制造软锁、转移资源成本或破坏意义表达。若主指标改善但“每个新增挑战都能指出复用了哪个已教技能，并提供可读的失败反馈”不成立，签发门必须拒绝。
</Callout>

## 验收矩阵

| 维度 | 正常样本 | 边界样本 | 失败样本 | 通过条件 |
| --- | --- | --- | --- | --- |
| 目录 | 官方主题逐项可定位 | 相邻主题交叉 | 故意漏一项 | 覆盖无空洞 |
| 状态 | 同输入可重放 | 容量或阈值附近 | 注入首个偏离 | 因果可定位 |
| 分布 | 多策略多种子 | 长尾与极端输入 | 统治策略或失控 | 结论不过拟合 |
| 体验 | 模型与玩家一致 | 新手或回退路径 | 误解、软锁或反表达 | 四门同时通过 |

**问题 1** 第10章覆盖哪些官方主题？任选三个，写出它们之间的因果关系。

<Answer>
  本页覆盖 From Toys to Playgrounds、Goal-Oriented and Free-Form Play、Missions and Game Spaces、Mapping Mechanics to Missions、Mapping Mechanics to Game Spaces、Learning to Play、Skill Atoms。合格答案不是罗列名称，而要写出上游输入怎样改变中间状态，再怎样产生下游可观察结果。
</Answer>

**问题 2** 怎样主动制造“用敌人血量替代新挑战，或在未教学前同时要求多个陌生机制”并证明修复有效？

<Answer>
  固定模型版本、参数和随机种子，只注入该故障；保存首个偏离节点与完整轨迹。修复后用相同输入复验，并确认指标、选择空间、可达性和体验没有发生新的转移性回归。
</Answer>

**问题 3** 为什么“每个新增挑战都能指出复用了哪个已教技能，并提供可读的失败反馈”必须作为签发不变量？

<Answer>
  因为它连接了本页结构与最终设计目标。缺少该不变量时，局部数值可能改善，但系统可能通过隐藏成本、统治策略、软锁或错误表达把问题转移到其他位置。
</Answer>
