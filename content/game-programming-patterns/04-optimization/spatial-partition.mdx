## 痛点：两两比较扛不住

100 个敌人要做碰撞检测，朴素做法是每个跟其他所有个比一遍——O(n²) 就是 10000 次比较。敌人到 1000 个就是 100 万次，帧率直接崩。但绝大多数比较是白费：地图两头的敌人根本不可能撞上。

## 解决方案：先分区，只比邻居

把空间切成若干区域，每个对象归入它所在的区域。碰撞检测时，只跟同区域（及相邻区域）的对象比。地图两头的敌人压根不在同一个区域，直接跳过。

```typescript
class Grid {
  private cells: Map<string, Actor[]> = new Map();
  private cellSize = 64;

  private key(x: number, y: number) {
    return `${Math.floor(x / this.cellSize)},${Math.floor(y / this.cellSize)}`;
  }

  add(actor: Actor) {
    const k = this.key(actor.x, actor.y);
    if (!this.cells.has(k)) this.cells.set(k, []);
    this.cells.get(k)!.push(actor);
  }

  // 只跟同格及相邻格的对象比
  nearby(actor: Actor): Actor[] {
    const result: Actor[] = [];
    for (let dx = -1; dx <= 1; dx++)
      for (let dy = -1; dy <= 1; dy++) {
        const k = this.key(actor.x + dx * this.cellSize, actor.y + dy * this.cellSize);
        result.push(...(this.cells.get(k) ?? []));
      }
    return result;
  }
}
```

每个对象只跟同格及周围 8 格比，比较次数从 O(n²) 降到接近 O(n)。

<Callout type="tip">
空间分区的本质是「用空间换时间」：多花一点内存维护分区结构，换来比较次数的大幅下降。对象越分散、分布越均匀，收益越明显。
</Callout>

## 网格 vs 四叉树

- **均匀网格**：把空间切成大小相同的方格，查找快、实现简单。适合对象分布比较均匀的 2D 游戏。分布极端不均（全挤在角落）时，一个格子里塞太多对象，退化回 O(n²)。
- **四叉树**：空间递归四等分，密的地方分得细、疏的地方分得粗。适合对象分布不均的场景。但实现复杂，插入删除开销大。

分布均匀选网格，分布不均选四叉树——别为简单场景上四叉树，开销可能反而更高。

## 对象移动时的维护

对象移动后可能跨入新区域。维护方式：

- **每帧重建**：清空网格，把所有对象重新插入。简单但每帧 O(n)。
- **增量更新**：对象移动时算出新格，从旧格移除、插入新格。复杂但只动变化的部分。

移动频繁且分布稳定时增量更新更优；对象不多时每帧重建反而更简单。

## 常见误区

### 误区 1：「网格切得越细越快」

格子太细，每个对象要查的相邻格变多、格子管理的开销也变大；格子太粗，一个格子里挤太多对象又退化。格子的尺寸应略大于最大物体的尺寸，让一个对象只占一到几个格子。

### 误区 2：「四叉树一定比网格快」

四叉树在分布不均时优势明显，但它的插入、删除、遍历都比网格复杂。对象分布均匀或数量不多时，网格的常数开销更低，往往比四叉树快。别为「高级」而选四叉树。

### 误区 3：「分完区就不用做精确检测了」

空间分区只是「粗筛」——快速排除不可能碰撞的对象。同区域内的对象是否真碰撞，仍要做精确的形状相交检测。分区减少的是候选对数，不是检测本身。

## 小结

- 空间分区把空间切成区域，碰撞检测只比同区及邻区，从 O(n²) 降到接近 O(n)
- 均匀网格适合分布均匀的 2D 游戏，四叉树适合分布不均的场景
- 对象移动时靠每帧重建或增量更新维护分区
- 格子尺寸应略大于最大物体，分区只做粗筛，精确检测不可省

<Glossary>
<GlossaryItem term="空间分区">
把游戏空间划分为若干区域，将对象按位置归入对应区域，使碰撞或查询只需检查同区域及邻近区域，从而减少比较次数。
</GlossaryItem>
<GlossaryItem term="均匀网格">
把空间切成大小相同的方格的分区结构。实现简单、查找快，适合对象分布较均匀的场景，分布不均时单格会过载。
</GlossaryItem>
<GlossaryItem term="四叉树">
将二维空间递归四等分的树形分区结构。密的区域分得细、疏的区域分得粗，适合对象分布不均的场景，但实现和维护更复杂。
</GlossaryItem>
