# 5. Prototype


{/* GPP_QUALITY_V2 */}

## 为什么“5. Prototype”从问题证据开始

每个怪物种类都固化成类会让内容扩展依赖程序重新编译。本页不把模式当成必选答案，而是先保存无模式基线，再验证候选机制是否真正改变可观察结果。通过条件是“克隆实例可独立变化且不会反向修改原型”，而不是类或接口数量增加。
