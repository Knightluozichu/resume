```text
initial state -> 拆分诉求 -> 显式创建 -> 注入依赖 -> 验证唯一 -> 控制销毁
fault injection -> 惰性初始化在后台线程首次访问时发生竞争
pass condition -> 依赖、创建时机和销毁顺序都能从调用边界读出
reset -> initial state
```

该骨架只保存实验合同；真实项目还要把平台、构建、场景、输入和统计窗口固定下来，并保留基线实现以便回退。
