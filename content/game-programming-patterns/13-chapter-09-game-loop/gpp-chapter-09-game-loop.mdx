## 为什么“9. Game Loop”从问题证据开始

每次循环固定移动量会让更快处理器上的游戏运行得更快。本页不把模式当成必选答案，而是先保存无模式基线，再验证候选机制是否真正改变可观察结果。通过条件是“相同真实时长内的模拟推进量与机器速度无关”，而不是类或接口数量增加。
