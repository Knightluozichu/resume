## 为什么“13. Type Object”从问题证据开始

每个怪物品种一个语言子类会把内容集合锁死在编译期。本页不把模式当成必选答案，而是先保存无模式基线，再验证候选机制是否真正改变可观察结果。通过条件是“同类型实例共享定义但不共享逐实例可变状态”，而不是类或接口数量增加。
