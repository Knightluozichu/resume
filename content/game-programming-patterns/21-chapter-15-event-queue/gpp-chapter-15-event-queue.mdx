## 可迁移实现或计算骨架

```text
initial state -> 构造事件 -> 复制入队 -> 等待调度 -> 顺序消费 -> 处理反馈
fault injection -> 处理器再次入队同类事件形成无界反馈
pass condition -> 事件的顺序、寿命和处理所有者都可从队列记录恢复
reset -> initial state
```

该骨架只保存实验合同；真实项目还要把平台、构建、场景、输入和统计窗口固定下来，并保留基线实现以便回退。
