# 17. Data Locality


{/* GPP_QUALITY_V2 */}

## 为什么“17. Data Locality”从问题证据开始

对象分散在堆上时，逐帧遍历会为少量热字段加载大量无关字节。本页不把模式当成必选答案，而是先保存无模式基线，再验证候选机制是否真正改变可观察结果。通过条件是“热循环只触碰所需字段且存活项保持紧凑”，而不是类或接口数量增加。
