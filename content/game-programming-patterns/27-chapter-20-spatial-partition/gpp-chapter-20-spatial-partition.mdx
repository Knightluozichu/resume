```text
fault injection -> 单位跨格移动后旧链表节点未移除
pass condition -> 分区查询不漏掉范围内对象，也不重复返回同一身份
reset -> initial state
```

该骨架只保存实验合同；真实项目还要把平台、构建、场景、输入和统计窗口固定下来，并保留基线实现以便回退。

掌握“20. Spatial Partition”意味着能从“全体两两距离检查随单位数平方增长”出发，解释对象进入网格或层级分区，移动时更新归属，查询只遍历相交单元，再用单元坐标、对象链、候选数、命中集合与全量真值推翻或保留实现。若“分区查询不漏掉范围内对象，也不重复返回同一身份”不能稳定复现，本章仍未通过。
