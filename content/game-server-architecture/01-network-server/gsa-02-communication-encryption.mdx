## 常见误区与故障注入

  最终成功可能只是重试或覆盖掩盖了错误，必须保存每阶段状态摘要和拒绝原因。

## 小结

- **对称加密**：通信双方使用同一密钥完成高吞吐数据加解密。
- **非对称加密**：使用公钥与私钥分离身份认证或密钥协商职责。
- **证书链**：把服务端公钥绑定到受信身份的逐级签名链。
- **TLS握手**：协商版本、算法和会话密钥并认证对端的状态机。
- **消息摘要**：把任意输入映射为固定长度指纹，用于完整性而非保密。
