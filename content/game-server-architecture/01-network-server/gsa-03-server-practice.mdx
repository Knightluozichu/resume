### 1. 握手只完成协议升级

Sec-WebSocket-Key、版本和Upgrade头必须验证，成功后仍要限制帧长度、控制帧和消息累计上限。

### 2. GIL不等于线程无用

I/O等待可以释放执行机会，但CPU密集任务仍要进程化或下沉；选择依据是测量过的等待比和复制成本。

## 小结

- **WebSocket**：在HTTP升级后维持双向帧通信的长连接协议。
- **握手**：验证升级头并协商从HTTP切换到WebSocket的过程。

- **GIL**：CPython中限制同一进程同时执行Python字节码的全局锁。
- **线程池**：复用固定数量工作线程并限制并发任务数量的执行器。
