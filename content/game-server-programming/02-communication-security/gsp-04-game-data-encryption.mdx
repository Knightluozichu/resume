## 从第4章的核心问题开始

加密不是把字节变得不可读，而是针对明确攻击者保护机密性、完整性与身份。算法可以公开，安全性必须依赖受控密钥；网络游戏还要处理重放、降级、密钥泄露和客户端不可信。2007 年常见算法的历史背景应保留，但新实现必须采用经过审查的认证协议。

### 算法与密钥分离

算法不应靠保密实现；密钥要有生成、分发、存储、轮换和吊销流程。把固定密钥编译进客户端等于向攻击者交付密钥。

### 机密性不等于完整性

## 可复现实验

固定一条登录消息，先预测加密后任意改动是否一定能被发现。分别翻转密文字节、标签字节、序号、会话标识和协议版本，再重放原包；保存验证顺序和拒绝原因，确认任何失败都不会进入业务解析。

### 最小实现

```ts
type SecureEnvelope = {
  version: number;
  sessionId: bigint;
  sequence: bigint;
  ciphertext: Uint8Array;
  tag: Uint8Array;
};
```

### 边界处理

```ts
function receive(envelope: SecureEnvelope, session: Session) {
  session.replayWindow.assertFresh(envelope.sequence);
  const plain = session.aead.open({
    nonce: makeNonce(envelope.sequence),
    aad: encodeHeader(envelope),
    ciphertext: envelope.ciphertext,
    tag: envelope.tag,
  });
  return parseMessage(plain);
}
```
