## 直觉引入

点、向量、射线、平面是图形学的「原子」。所有复杂的空间数据结构——四叉树、BVH、R-Tree——最终都归结为对这些基本图元的空间关系判定。

两个核心运算贯穿全书：点积 $\mathbf{a}\cdot\mathbf{b}=|\mathbf{a}||\mathbf{b}|\cos\theta$ 判断方向关系（同向/反向/垂直），叉积 $\mathbf{a}\times\mathbf{b}$ 生成法向量并计算面积。射线-平面相交则是光线追踪和碰撞检测的基本操作。

## 概念讲解

<Term def="空间中的位置">点</Term> $P=(x,y,z)$ 表示位置。<Term def="有方向和大小的量">向量</Term> $\mathbf{v}=(v_x,v_y,v_z)$ 表示方向。点-向量加法得到新点（平移），点-点减法得到向量（方向）。

<Term def="从一点出发沿一方向的半直线">射线</Term>参数方程 $\mathbf{R}(t)=\mathbf{O}+t\mathbf{D}$（$t\geq 0$）。<Term def="空间中的平坦面">平面</Term>方程 $\mathbf{N}\cdot\mathbf{X}+d=0$（$\mathbf{N}$ 为法向量）。

<Term def="三角形内点的参数化表示">重心坐标</Term>：$P=\alpha A+\beta B+\gamma C$（$\alpha+\beta+\gamma=1$，$\alpha,\beta,\gamma\geq 0$ 表示在三角形内部）。

### 射线-平面相交
射线 $\mathbf{R}(t)=\mathbf{O}+t\mathbf{D}$，平面 $\mathbf{N}\cdot\mathbf{X}+d=0$：
$$t = -\frac{\mathbf{N}\cdot\mathbf{O}+d}{\mathbf{N}\cdot\mathbf{D}}$$
- $t < 0$：交点在射线反方向（无效）
- $\mathbf{N}\cdot\mathbf{D} = 0$：射线与平面平行（无交点或共面）
- $t \geq 0$：有效交点 $\mathbf{O}+t\mathbf{D}$

### 射线-三角形相交（Moller-Trumbore）
利用重心坐标：$P = \mathbf{O}+t\mathbf{D} = (1-u-v)\mathbf{V_0}+u\mathbf{V_1}+v\mathbf{V_2}$
解线性方程组得 $t, u, v$，当 $t\geq 0, u\geq 0, v\geq 0, u+v\leq 1$ 时有效。

### AABB（轴对齐包围盒）
由 $\min$ 和 $\max$ 两点定义：$[x_{\min}, x_{\max}]\times[y_{\min}, y_{\max}]\times[z_{\min}, z_{\max}]$。射线-AABB 相交用 slab method（每轴求进出区间取交集），$O(1)$ 复杂度。

## 代码对照

用 Python 实现核心几何运算：

```python
import numpy as np

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def cross(a, b):
    return np.cross(a, b)

def length(v):
    return sum(x * x for x in v) ** 0.5

def normalize(v):
    L = length(v)
    return [x / L for x in v] if L > 0 else v

def ray_plane_intersect(O, D, N, d):
    """射线 O+tD 与平面 N·X+d=0 的交点"""
    denom = dot(N, D)
    if abs(denom) < 1e-10:  # 平行
        return None
    t = -(dot(N, O) + d) / denom
    if t < 0:  # 交点在射线反方向
        return None
    return [O[i] + t * D[i] for i in range(3)]

def ray_aabb_intersect(O, D, bmin, bmax):
    """射线与 AABB 的 slab method 相交测试"""
    tmin, tmax = -float('inf'), float('inf')
    for i in range(3):
        if abs(D[i]) < 1e-10:
            if O[i] < bmin[i] or O[i] > bmax[i]:
                return False  # 射线平行且在 slab 外
        else:
            t1 = (bmin[i] - O[i]) / D[i]
            t2 = (bmax[i] - O[i]) / D[i]
            if t1 > t2:
                t1, t2 = t2, t1
            tmin = max(tmin, t1)
            tmax = min(tmax, t2)
            if tmin > tmax:
                return False
    return tmax >= 0  # 射线起点可以在盒内

def moller_trumbore(O, D, V0, V1, V2):
    """射线-三角形相交 (Moller-Trumbore)"""
    EPS = 1e-10
    e1 = [V1[i] - V0[i] for i in range(3)]
    e2 = [V2[i] - V0[i] for i in range(3)]
    p = cross(D, e2)
    det = dot(e1, p)
    if abs(det) < EPS:
        return None  # 平行
    inv_det = 1.0 / det
    t_vec = [O[i] - V0[i] for i in range(3)]
    u = dot(t_vec, p) * inv_det
    if u < 0 or u > 1:
        return None
    q = cross(t_vec, e1)
    v = dot(D, q) * inv_det
    if v < 0 or u + v > 1:
        return None
    t = dot(e2, q) * inv_det
    return t if t > EPS else None

# 测试
O, D = [0, 0, 0], [0, 0, 1]  # 沿 z 轴的射线
N, d = [0, 0, -1], 5          # 平面 z=5
hit = ray_plane_intersect(O, D, N, d)
print(f"射线-平面交点: {hit}")  # [0, 0, 5]

bmin, bmax = [-1, -1, 3], [1, 1, 7]
print(f"射线-AABB 相交: {ray_aabb_intersect(O, D, bmin, bmax)}")  # True

V0, V1, V2 = [0, 0, 5], [2, 0, 5], [0, 2, 5]
t = moller_trumbore(O, D, V0, V1, V2)
print(f"射线-三角形 t={t}")  # t=5

```

`ray_plane_intersect` 检查平行（分母为 0）和反方向（$t<0$）。`ray_aabb_intersect` 用 slab method 逐轴求进出区间取交集。`moller_trumbore` 在 $O(1)$ 内完成射线-三角形测试，返回重心坐标 $u,v$ 和参数 $t$。

## 常见误区

<Callout type="trap">
**现象 →** 混淆点和向量的语义。
**原因 →** 两者都是三元组，但语义不同。
**修法 →** 点表示位置，向量表示方向。点+向量=点（平移），点-点=向量（方向）。在代码中用不同类型区分（如 Point3D vs Vec3），避免语义混淆。
</Callout>

<Callout type="trap">
**现象 →** 射线与平面平行时直接返回无交点。
**原因 →** 忽略了射线在平面上的退化情况。
**修法 →** N·D=0 时检查 N·O+d 是否也为 0。如果是，射线在平面上（无穷多交点）；如果不是，射线与平面平行不相交。
</Callout>

<Exercises>
**问题**：射线 O=(0,0,0), D=(1,1,1) 与平面 x+y+z=6 是否相交？求交点。

<Answer>
N=(1,1,1), d=-6。t=-(N·O+d)/(N·D)=-((0+0+0)-6)/(1+1+1)=6/3=2。t=2≥0，交点=O+2D=(2,2,2)。验证：2+2+2=6 ✓。
</Answer>

**问题**：用 Moller-Trumbore 算法说明射线-三角形相交的时间复杂度。

<Answer>
O(1)。算法步骤：2次叉积+3次点积+若干标量运算，全部是常数时间操作。不需要预处理三角形，每对射线-三角形独立计算。BVH 的作用是把 N 次测试降为 O(log N) 次叶节点测试。
</Answer>
</Exercises>
