## 直觉引入

四叉树把 2D 空间递归地分成四个象限，每个节点要么是叶子（存少量对象），要么继续细分。这种自适应分割让密集区域有更深的树、稀疏区域有浅树，比均匀网格更灵活。

八叉树是四叉树的自然 3D 推广——每个节点分 8 个卦限。游戏引擎中八叉树常用于粒子系统、体素渲染和视锥剔除。四叉树/八叉树的核心优势是实现简单、直观，但缓存局部性不如 BVH。

## 概念讲解

<Term def="将 2D 空间递归分成四个象限的树结构">四叉树</Term>每个内部节点有 4 个子节点（NE/NW/SE/SW）。插入对象时，从根开始递归判断对象属于哪个象限，直到叶节点。当叶节点对象数超过阈值（如 4）时，分裂为 4 个子节点。

<Term def="四叉树的 3D 推广">八叉树</Term>每个节点分 8 个卦限。空间复杂度 $O(n)$，查询复杂度 $O(\log n + k)$（$k$ 为结果数）。

<Term def="查询矩形范围内的所有对象">范围查询</Term>：从根开始，递归进入与查询矩形相交的子节点，收集叶节点中的对象。

### 构建流程
1. 创建根节点覆盖整个空间 $[0,W]\times[0,H]$。
2. 插入对象：递归判断属于哪个象限。
3. 当叶节点对象数 $>$ 阈值（如 4）时分裂。
4. 分裂后把对象重新分配到 4 个子节点。

### 范围查询
```
query(node, rect):
    if not intersects(node.bounds, rect): return []
    if is_leaf(node): return objects in node
    results = []
    for child in node.children:
        results += query(child, rect)
    return results
```

### 最近邻查询
用优先队列（按到查询点的距离排序），先访问最近的子树。维护当前最近距离 $d$，剪枝距离 $> d$ 的子树。

### 松散四叉树（Loose Quadtree）
标准四叉树中，跨越象限边界的对象需要存多个子节点或存在父节点。松散四叉树扩大每个子节点的边界（如 2 倍），减少跨界问题。

## 代码对照

用 Python 实现四叉树的构建与查询：

```python
class QuadTreeNode:
    def __init__(self, x, y, w, h, capacity=4, depth=0, max_depth=10):
        self.x, self.y, self.w, self.h = x, y, w, h
        self.capacity = capacity
        self.depth = depth
        self.max_depth = max_depth
        self.points = []
        self.children = None
    
    def contains(self, px, py):
        return self.x <= px < self.x + self.w and self.y <= py < self.y + self.h
    
    def subdivide(self):
        hw, hh = self.w / 2, self.h / 2
        self.children = [
            QuadTreeNode(self.x, self.y, hw, hh, self.capacity, self.depth+1, self.max_depth),      # NW
            QuadTreeNode(self.x+hw, self.y, hw, hh, self.capacity, self.depth+1, self.max_depth),   # NE
            QuadTreeNode(self.x, self.y+hh, hw, hh, self.capacity, self.depth+1, self.max_depth),   # SW
            QuadTreeNode(self.x+hw, self.y+hh, hw, hh, self.capacity, self.depth+1, self.max_depth),# SE
        ]
        for px, py in self.points:
            for child in self.children:
                if child.contains(px, py):
                    child.points.append((px, py))
                    break
        self.points = []
    
    def insert(self, px, py):
        if not self.contains(px, py):
            return False
        if self.children is None:
            self.points.append((px, py))
            if len(self.points) > self.capacity and self.depth < self.max_depth:
                self.subdivide()
            return True
        for child in self.children:
            if child.insert(px, py):
                return True
        return False
    
    def query_range(self, qx, qy, qw, qh):
        """范围查询"""
        if self.x + self.w < qx or self.x > qx + qw or self.y + self.h < qy or self.y > qy + qh:
            return []  # 不相交
        if self.children is None:
            return [(px, py) for px, py in self.points
                    if qx <= px < qx + qw and qy <= py < qy + qh]
        results = []
        for child in self.children:
            results.extend(child.query_range(qx, qy, qw, qh))
        return results

# 测试
import random
qt = QuadTreeNode(0, 0, 100, 100)
for _ in range(1000):
    qt.insert(random.random() * 100, random.random() * 100)

results = qt.query_range(20, 20, 30, 30)
print(f"范围查询结果数: {len(results)}")

# 遍历树深度
def max_depth(node):
    if node.children is None:
        return node.depth
    return max(max_depth(c) for c in node.children)
print(f"最大树深: {max_depth(qt)}")

```

`QuadTreeNode` 实现了插入（超阈值则 `subdivide`）和范围查询（递归进入相交子节点）。1000 个随机点构建后，范围查询 $[20,50]\times[20,50]$ 只需访问相关象限，远快于遍历全部 1000 点。

## 常见误区

<Callout type="trap">
**现象 →** 四叉树退化成链表，深度极大。
**原因 →** 所有点集中在同一位置或沿一条线分布，导致反复细分同一象限。
**修法 →** 设置最大深度限制。或使用松散四叉树扩大子节点边界。也可改用 BVH（对象分割不受空间退化影响）。
</Callout>

<Callout type="trap">
**现象 →** 跨象限边界的对象存了多份。
**原因 →** 对象跨越多个象限的边界，标准四叉树要求每个对象属于唯一象限。
**修法 →** 方案一：把对象存在能完全包含它的最小节点。方案二：用松散四叉树扩大子节点边界。方案三：允许对象存多份（查询时去重）。
</Callout>

<Exercises>
**问题**：四叉树的范围查询复杂度是多少？最坏情况是什么？

<Answer>
平均 O(log n + k)（k 为结果数）。最坏 O(n)：所有点集中在查询矩形覆盖的同一个叶节点中（树退化）。设最大深度限制可避免退化但牺牲精度。
</Answer>

**问题**：八叉树与四叉树的关系是什么？在什么场景下选八叉树？

<Answer>
八叉树是四叉树的 3D 推广，每个节点分 8 个卦限（2^3=8）而非 4 个象限（2^2=4）。选八叉树：3D 体素数据、粒子系统、3D 碰撞检测、视锥剔除。选四叉树：2D 地形 LOD、2D 碰撞、图像压缩。八叉树内存开销是四叉树的 2 倍（8 vs 4 子节点指针）。
</Answer>
</Exercises>
