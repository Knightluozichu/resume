### 核心对象

1. **BSP树**：以任意超平面递归划分空间并在两侧保存子问题的二叉树。
2. **分类谓词**：根据有符号距离把点或多边形判为前侧、后侧或共面。
3. **分裂片元**：跨越分割面的图元被切成分别落在两侧的片段。
4. **画家顺序**：依据观察点相对分割面的方位递归产生从远到近的绘制次序。
5. **代价启发式**：平衡树深、查询概率与片元分裂数量的构建目标。

## 查询与表示契约

先固定数据域、维数、闭开边界、查询输出和数值语义。树高或节点数不是独立目标；只有候选完备、结果无重复、复杂度含输出规模且数值分支一致时，结构才算正确。

$$
s(x)=n\cdot x+d
$$

$$
t=\frac{s(a)}{s(a)-s(b)}
$$

$$
C(H)=\alpha|n_f-n_b|+\beta n_s
$$

$$
T(h)=T(h_f)+T(h_b)+O(n_s)
$$

分类由平面方程的符号决定，跨越平面的边按线性插值求交点。画家算法先访问观察点远侧，再处理共面图元，最后访问近侧。集合并、交、差通过把一棵BSP递归裁入另一棵的空间分类；构建质量通常在平衡与分裂代价间取舍。 每个剪枝判断都应能回答两个问题：被排除的集合是什么，以及哪个不变量证明它不含答案。

## 可核查构建与查询

节点保存归一化平面、共面图元和前后孩子。分类使用带误差边界的谓词，只有符号可靠时才切分；布尔运算为每个叶标注内外语义。构建时采样多个候选面，记录左右数量、分裂数和历史查询权重。


```python
def query_with_trace(root, request):
    stack, hits, trace = [root], [], []
    while stack:
        node = stack.pop()
        trace.append(node.id)
        if node.disjoint(request):
            continue
        if node.is_leaf:
            hits.extend(node.exact_matches(request))
        else:
            stack.extend(node.children)
    return sorted(set(hits)), trace
```

通用骨架必须由本章的具体不变量实例化：区域不相交、包围体不重叠、空邻域、证书未失效或静态块版本有效。不能把候选生成误写成最终答案，叶节点仍需执行本章定义的精确测试。

## 复杂度与工程取舍

复杂度报告分离构建、查询、更新、内存和输出规模。平均值之外记录P95与最坏样例；同时保存访问节点、候选对象和精确谓词次数，这样才能判断瓶颈来自树质量、数据分布还是数值回退。

```python
metrics = {
    "build_ms": 0.0,
    "visited_nodes": 0,
    "candidates": 0,
    "exact_tests": 0,
    "update_ms": 0.0,
}
assert set(metrics) == {"build_ms", "visited_nodes", "candidates", "exact_tests", "update_ms"}
```

只在结果集合与基线一致后比较性能。构建更慢可能换来大量查询收益，更新更便宜也可能逐渐恶化结构；因此工作负载中的查询次数、更新比例和生命周期必须写入报告。

## 边界、退化与反例

共面多边形的朝向、观察点落在分割面、细长片元和循环数值误差最容易破坏拓扑。若每次切分都重新舍入顶点，裂缝会累积；应复用交点并保存来源边。

```python
audit = {
    "normal": "representative geometry",
    "boundary": "closed-open convention",
    "degenerate": "duplicate or co-located input",
    "baseline": "brute-force exact result",
}
assert all(audit.values())
```

## 图形学应用

在没有深度缓冲的透明多边形场景中，用BSP生成稳定的远近顺序；对两个闭合实体做并交差后，用随机点分类和体积采样验证叶标签。 应用层还要记录从世界坐标到结构坐标的变换，避免把坐标系错误误判为数据结构错误。

## 验收证书

验收包包含原始输入、结构参数、节点或图邻接、查询日志、候选集合、精确结果、复杂度计数和失败反例。对候选面计算平衡与分裂联合代价，并用查询分布校正静态启发式。 任何无法重放的截图或孤立耗时都不能替代证书。
