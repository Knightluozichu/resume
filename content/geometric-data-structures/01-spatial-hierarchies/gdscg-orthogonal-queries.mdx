### 核心对象

1. **刺穿查询**：给定点或查询对象，报告所有与其相交的已存对象。
2. **窗口查询**：报告完全位于或与轴对齐查询盒相交的对象。
3. **线段树**：把基本区间分层存储，使跨越查询点的区间可按规范节点报告。
4. **kd树**：循环选择坐标轴并按位置切分点集的二叉空间树。
5. **范围树**：主排序树的每个规范节点携带下一维关联结构。

## 查询与表示契约

先固定数据域、维数、闭开边界、查询输出和数值语义。树高或节点数不是独立目标；只有候选完备、结果无重复、复杂度含输出规模且数值分支一致时，结构才算正确。

$$
T_{1D}=O(\log n+k)
$$

$$
T_{range}=O(\log^d n+k)
$$

$$
M_{range}=O(n\log^{d-1}n)
$$

$$
R=\{p\in P\mid a_i\le p_i\le b_i\}
$$

一维平衡搜索树把窗口分成对数个规范子树；线段树把区间存到完全覆盖且父节点不完全覆盖的规范节点。多层结构和范围树通过关联结构提升维度，kd树则用几何切分直接剪除不相交区域。复杂度必须包含输出项k，不能把报告本身隐藏在常数中。 每个剪枝判断都应能回答两个问题：被排除的集合是什么，以及哪个不变量证明它不含答案。

## 可核查构建与查询

先实现一维区间树并以端点扫描作基线，再实现kd树与二维范围树。每次查询记录完全包含节点、部分相交节点和报告对象，保证没有重复。纹理合成把特征向量做窗口查询，形状匹配把高维描述子范围搜索与精确距离复核分开。

```python
def query_with_trace(root, request):
    stack, hits, trace = [root], [], []
    while stack:
        node = stack.pop()
        trace.append(node.id)
        if node.disjoint(request):
            continue
        if node.is_leaf:
            hits.extend(node.exact_matches(request))
        else:
            stack.extend(node.children)
    return sorted(set(hits)), trace
```

通用骨架必须由本章的具体不变量实例化：区域不相交、包围体不重叠、空邻域、证书未失效或静态块版本有效。不能把候选生成误写成最终答案，叶节点仍需执行本章定义的精确测试。


## 复杂度与工程取舍

复杂度报告分离构建、查询、更新、内存和输出规模。平均值之外记录P95与最坏样例；同时保存访问节点、候选对象和精确谓词次数，这样才能判断瓶颈来自树质量、数据分布还是数值回退。

```python
metrics = {
    "build_ms": 0.0,
    "visited_nodes": 0,
    "candidates": 0,
    "exact_tests": 0,
    "update_ms": 0.0,
}
assert set(metrics) == {"build_ms", "visited_nodes", "candidates", "exact_tests", "update_ms"}
```

只在结果集合与基线一致后比较性能。构建更慢可能换来大量查询收益，更新更便宜也可能逐渐恶化结构；因此工作负载中的查询次数、更新比例和生命周期必须写入报告。

## 边界、退化与反例

零长度区间、端点相接、重复坐标和查询窗零面积会暴露闭区间约定冲突。高维范围树内存快速增长，kd树在高维也会接近全扫描；报告复杂度时应同时给维数和输出规模。

## 图形学应用

二维矩形窗口查询先由主树分解x范围，再在关联结构筛y范围；形状匹配先取候选描述子，再用原始几何变换验证。验收将输出排序去重后与穷举集合完全比较。 应用层还要记录从世界坐标到结构坐标的变换，避免把坐标系错误误判为数据结构错误。

1. 用五到十个对象手算结构，标出节点覆盖、邻接或证书。
2. 执行一个正常查询和一个恰落在边界的查询，逐节点记录剪枝理由。
3. 删除一个一般位置或静态假设，构造首个失败样例。
4. 与穷举答案逐项比较，再扩大规模测构建、查询、更新和内存。

## 验收证书

验收包包含原始输入、结构参数、节点或图邻接、查询日志、候选集合、精确结果、复杂度计数和失败反例。把复杂度写成搜索开销加输出规模，并单独统计候选与最终命中。 任何无法重放的截图或孤立耗时都不能替代证书。
