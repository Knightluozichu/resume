## 直觉引入

Voronoi 图把空间按最近邻分割：每个站点的区域包含所有离它最近的点。它是计算几何的基础结构，与 Delaunay 三角剖分互为对偶。

Voronoi 图的边界是两个站点中垂线的一部分，顶点是三个站点外接圆的圆心。Fortune 扫描线算法用巧妙的「抛物线海滩线」在 $O(n \log n)$ 时间内构建 Voronoi 图，是计算几何最优算法的代表。

## 概念讲解

<Term def="每个站点的最近邻区域">Voronoi 区域</Term> $V(p_i) = \{x : d(x, p_i) \leq d(x, p_j), \forall j\}$。区域边界是两个站点的中垂线段。<Term def="三个站点等距的点">Voronoi 顶点</Term>是三个站点外接圆的圆心。

<Term def="Voronoi 图与 Delaunay 三角剖分的互逆关系">对偶性</Term>：Voronoi 顶点 ↔ Delaunay 三角形外心，Voronoi 边 ↔ Delaunay 边，Voronoi 区域 ↔ Delaunay 星形。

### Fortune 扫描线算法
用一条水平扫描线从上到下扫过所有站点。扫描线上方已确定 Voronoi 结构，下方待处理。关键是「海滩线」——由抛物线弧段组成，每段对应一个站点。当扫描线经过站点时插入新弧段，当弧段消失时产生 Voronoi 顶点。事件队列管理两种事件：站点事件（弧段插入）和圆事件（弧段消失）。复杂度 $O(n \log n)$。

### 应用场景
- **最近邻查询**：给定点落在哪个站点区域 → 定位问题。
- **设施选址**：最大空圆问题——在最大 Voronoi 顶点放置新设施。
- **生物学建模**：细胞结构、森林树种竞争区。
- **路径规划**：避开障碍物的 Voronoi 路径（最大化与障碍距离）。

## 代码对照

用 Python 从 Delaunay 三角剖分推导 Voronoi 图：

```python
import math

def voronoi_from_delaunay(triangles):
    """从 Delaunay 三角形推导 Voronoi 顶点和边"""
    # Voronoi 顶点 = Delaunay 三角形外心
    vertices = []
    for tri in triangles:
        cc = circumcircle(*tri)
        if cc:
            vertices.append((cc[0], cc[1]))
    
    # Voronoi 边 = 相邻 Delaunay 三角形外心的连线
    edges = set()
    for i, t1 in enumerate(triangles):
        for j, t2 in enumerate(triangles):
            if i >= j:
                continue
            # 找共享边
            shared = set(map(tuple, t1)) & set(map(tuple, t2))
            if len(shared) == 2:
                edges.add((i, j))
    
    return vertices, edges

def circumcircle(p1, p2, p3):
    ax, ay = p1
    bx, by = p2
    cx, cy = p3
    d = 2 * (ax * (by - cy) + bx * (cy - ay) + cx * (ay - by))
    if abs(d) < 1e-10:
        return None
    ux = ((ax**2+ay**2)*(by-cy)+(bx**2+by**2)*(cy-ay)+(cx**2+cy**2)*(ay-by)) / d
    uy = ((ax**2+ay**2)*(cx-bx)+(bx**2+by**2)*(ax-cx)+(cx**2+cy**2)*(bx-ax)) / d
    r = math.sqrt((ax-ux)**2 + (ay-uy)**2)
    return (ux, uy, r)

def nearest_site(point, sites):
    """Voronoi 查询：找最近站点"""
    best_d, best_i = float('inf'), -1
    for i, s in enumerate(sites):
        d = (point[0]-s[0])**2 + (point[1]-s[1])**2
        if d < best_d:
            best_d, best_i = d, i
    return best_i

# 测试
sites = [(1,1), (5,3), (3,7), (8,6), (2,8)]
# 假设有 Delaunay 三角形
tris = [[sites[0], sites[1], sites[2]], [sites[1], sites[3], sites[2]], [sites[2], sites[3], sites[4]]]
verts, edges = voronoi_from_delaunay(tris)
print(f"{len(sites)} 站点, {len(verts)} Voronoi 顶点, {len(edges)} Voronoi 边")

# 最近邻查询
q = (4, 4)
ni = nearest_site(q, sites)
print(f"查询点 {q} 最近站点: {sites[ni]} (索引 {ni})")

```

`voronoi_from_delaunay` 利用对偶关系从 Delaunay 三角形推导 Voronoi：外心=顶点，共享边的三角形对=Voronoi 边。`nearest_site` 是 Voronoi 查询的暴力版本——实际用 Voronoi 图可加速到 $O(\log n)$。

## 常见误区

<Callout type="trap">
**现象 →** 混淆 Voronoi 顶点和站点。
**原因 →** Voronoi 图中有两类点：站点（输入）和顶点（输出）。
**修法 →** 站点是输入的控制点，Voronoi 顶点是三站点外接圆心。Voronoi 区域围绕站点，边界由中垂线组成，顶点在边界交汇处。
</Callout>

<Callout type="trap">
**现象 →** 用暴力方法做 Voronoi 查询（遍历所有站点）。
**原因 →** 不知道 Voronoi 图可以加速查询。
**修法 →** 预处理构建 Voronoi 图后，用定位查询（point location）找查询点所在区域，O(log n)。暴力 O(n) 在大规模场景中不可接受。
</Callout>

<Exercises>
**问题**：解释 Voronoi 图与 Delaunay 三角剖分的对偶关系。

<Answer>
Voronoi 顶点 = Delaunay 三角形外心；Voronoi 边 = 连接两个相邻 Delaunay 三角形外心，对应 Delaunay 边；Voronoi 区域 = 围绕一个站点的多边形，对应该站点在 Delaunay 中的星形（所有含该站点的三角形）。从 Delaunay 可直接推导 Voronoi。
</Answer>

**问题**：Fortune 扫描线算法的核心思想是什么？时间复杂度？

<Answer>
用水平扫描线从上到下扫过站点。海滩线（抛物线弧段）跟踪已确定的 Voronoi 边界。站点事件：新弧段插入海滩线。圆事件：弧段消失产生 Voronoi 顶点。用优先队列管理事件，每个事件 O(log n) 处理，共 O(n) 个事件，总复杂度 O(n log n)。
</Answer>
</Exercises>
