### 核心对象

1. **距离场**：为域内每个位置记录到目标集合最短距离的标量场。
2. **有符号距离**：在封闭表面内外赋予相反符号，并以零等值面表示表面。
3. **传播方法**：从已知边界距离向邻域按局部更新规则扩散近似最短距离。
4. **投影方法**：把几何或较高维距离函数投影到离散网格和基函数表示。
5. **等值面**：距离场中取固定数值的一组位置，零等值面通常恢复原表面。

## 查询与表示契约

先固定数据域、维数、闭开边界、查询输出和数值语义。树高或节点数不是独立目标；只有候选完备、结果无重复、复杂度含输出规模且数值分支一致时，结构才算正确。

$$
d(x,S)=\inf_{y\in S}\|x-y\|
$$

$$
|d(x,S)-d(z,S)|\le\|x-z\|
$$

$$
\|\nabla d(x)\|=1
$$

$$
S_r=\{x\mid d_s(x)=r\}
$$

欧氏距离场满足1-Lipschitz性质，精确有符号距离在光滑区域的梯度模长为一。离散传播从种子单元出发松弛邻居，投影则在有限表示中近似距离函数。形态偏移可取不同等值面，两个场的插值可生成变形，但拓扑变化与采样误差必须显式检查。 每个剪枝判断都应能回答两个问题：被排除的集合是什么，以及哪个不变量证明它不含答案。

## 可核查构建与查询

先对小网格逐体素穷举最近三角形作为基线，再实现多源队列传播。每个体素保存距离、符号来源和最近特征，查询时用三线性插值并限制步长。建模操作后重新检查符号一致性与零面封闭性。

```python
def query_with_trace(root, request):
    stack, hits, trace = [root], [], []
    while stack:
        node = stack.pop()
        trace.append(node.id)
        if node.disjoint(request):
            continue
        if node.is_leaf:
            hits.extend(node.exact_matches(request))
        else:
            stack.extend(node.children)
    return sorted(set(hits)), trace
```

通用骨架必须由本章的具体不变量实例化：区域不相交、包围体不重叠、空邻域、证书未失效或静态块版本有效。不能把候选生成误写成最终答案，叶节点仍需执行本章定义的精确测试。


## 复杂度与工程取舍

复杂度报告分离构建、查询、更新、内存和输出规模。平均值之外记录P95与最坏样例；同时保存访问节点、候选对象和精确谓词次数，这样才能判断瓶颈来自树质量、数据分布还是数值回退。

```python
metrics = {
    "build_ms": 0.0,
    "visited_nodes": 0,
    "candidates": 0,
    "exact_tests": 0,
    "update_ms": 0.0,
}
assert set(metrics) == {"build_ms", "visited_nodes", "candidates", "exact_tests", "update_ms"}
```

只在结果集合与基线一致后比较性能。构建更慢可能换来大量查询收益，更新更便宜也可能逐渐恶化结构；因此工作负载中的查询次数、更新比例和生命周期必须写入报告。

## 边界、退化与反例

开放曲面没有天然内外符号；尖角和中轴附近距离不可微；离散传播依赖邻域模板，可能产生各向异性。若把近似值当严格下界用于球追踪，会越过表面。

```python
audit = {

    "baseline": "brute-force exact result",

assert all(audit.values())
```

## 图形学应用

把两个封闭模型转为同一网格上的有符号距离场，做平滑并、偏移和形变。用采样点最近距离、零面Hausdorff近似和符号分类三项共同验收。 应用层还要记录从世界坐标到结构坐标的变换，避免把坐标系错误误判为数据结构错误。

1. 用五到十个对象手算结构，标出节点覆盖、邻接或证书。
2. 执行一个正常查询和一个恰落在边界的查询，逐节点记录剪枝理由。
3. 删除一个一般位置或静态假设，构造首个失败样例。
4. 与穷举答案逐项比较，再扩大规模测构建、查询、更新和内存。

## 验收证书

验收包包含原始输入、结构参数、节点或图邻接、查询日志、候选集合、精确结果、复杂度计数和失败反例。先检测封闭与定向；开放表面使用无符号距离或显式窄带语义。 任何无法重放的截图或孤立耗时都不能替代证书。
