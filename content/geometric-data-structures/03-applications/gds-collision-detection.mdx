## 直觉引入

碰撞检测是游戏物理的核心。直接对 $n$ 个对象两两测试需要 $O(n^2)$ 次——完全不可行。两阶段架构先用宽相快速剔除不可能碰撞的对，再用窄相精确检测。

宽相用 AABB（轴对齐包围盒）重叠测试剔除大部分不碰撞的对，再用空间索引（网格/BVH）进一步加速。窄相用 SAT 或 GJK 做精确的凸体碰撞检测。时间一致性（帧间位移小）使得增量更新非常高效。

## 概念讲解

<Term def="快速剔除不可能碰撞的对象对">宽相</Term>用 AABB 重叠测试：两个 AABB 在所有轴上都有重叠时才可能碰撞。配合空间索引只检查近邻对。输出候选碰撞对列表。

<Term def="精确检测候选对是否真正碰撞">窄相</Term>用 <Term def="两个凸体不碰撞当且仅当存在分离轴">SAT</Term>（分离轴定理）：对凸多边形的每条边的法向量（2D）或面法向+边叉积（3D）测试投影是否分离。

<Term def="基于 Minkowski 差的碰撞检测">GJK</Term>：两个凸体的 Minkowski 差包含原点当且仅当它们碰撞。用单纯形迭代逼近原点。

### AABB 重叠测试
两个 AABB $[a_{\min}, a_{\max}]$ 和 $[b_{\min}, b_{\max}]$ 重叠当且仅当所有轴上都有重叠：
$$a_{\min}^i \leq b_{\max}^i \text{ 且 } b_{\min}^i \leq a_{\max}^i \quad \forall i$$
这是一个 $O(1)$ 的常数时间操作（3D 只需 6 次比较）。

### 扫描剪枝（Sweep and Prune）
沿某轴（如 x 轴）排序所有 AABB 的 min 和 max 端点。扫描时维护活跃列表，只有活跃列表中的 AABB 对才可能在该轴上重叠。复杂度 $O(n \log n + k)$（$k$ 为候选对数），利用时间一致性（帧间排序几乎不变）可达近 $O(n)$。

### SAT 详解（2D）
两个凸多边形不碰撞 $\iff$ 存在一条分离轴（某条边的法向量），使两者在该轴上的投影不重叠。对每条边的法向量做投影测试，若找到一条分离轴则不碰撞，否则碰撞。复杂度 $O(m+n)$（$m,n$ 为边数）。

### GJK 算法
1. 计算 Minkowski 差 $A \ominus B = \{a - b : a \in A, b \in B\}$。
2. $A$ 和 $B$ 碰撞 $\iff$ 原点 $\in A \ominus B$。
3. 用 support 函数迭代构建单纯形（点/线/三角形/四面体），判断原点是否在单纯形内。
4. 若原点在单纯形内 → 碰撞；否则沿原点方向扩展单纯形。

## 代码对照

用 Python 实现 AABB 重叠测试与 SAT 碰撞检测：

```python
def aabb_overlap(a_min, a_max, b_min, b_max):
    """AABB 重叠测试 O(1)"""
    for i in range(len(a_min)):
        if a_min[i] > b_max[i] or b_min[i] > a_max[i]:
            return False
    return True

def project_polygon(vertices, axis):
    """将多边形投影到轴上，返回 [min, max]"""
    dots = [v[0]*axis[0] + v[1]*axis[1] for v in vertices]
    return min(dots), max(dots)

def get_normals(vertices):
    """获取多边形每条边的法向量（2D）"""
    normals = []
    n = len(vertices)
    for i in range(n):
        edge = (vertices[(i+1)%n][0]-vertices[i][0], vertices[(i+1)%n][1]-vertices[i][1])
        normal = (-edge[1], edge[0])  # 垂直方向
        length = (normal[0]**2 + normal[1]**2) ** 0.5
        if length > 0:
            normals.append((normal[0]/length, normal[1]/length))
    return normals

def sat_collision(poly_a, poly_b):
    """SAT 分离轴定理：凸多边形碰撞检测"""
    for normals in [get_normals(poly_a), get_normals(poly_b)]:
        for axis in normals:
            min_a, max_a = project_polygon(poly_a, axis)
            min_b, max_b = project_polygon(poly_b, axis)
            if max_a < min_b or max_b < min_a:
                return False  # 找到分离轴 → 不碰撞
    return True  # 无分离轴 → 碰撞

def sweep_and_prune(boxes):
    """扫描剪枝：宽相候选对生成"""
    # boxes = [(id, min_x, max_x, ...), ...]
    # 按 min_x 排序
    sorted_boxes = sorted(boxes, key=lambda b: b[1])
    active = []
    candidates = []
    for box in sorted_boxes:
        bid, bmin_x, bmax_x = box[0], box[1], box[2]
        # 移除不再活跃的
        active = [a for a in active if a[2] >= bmin_x]
        for a in active:
            candidates.append((a[0], bid))
        active.append(box)
    return candidates

# 测试
print("=== AABB 测试 ===")
print(f"重叠: {aabb_overlap([0,0], [2,2], [1,1], [3,3])}")  # True
print(f"不重叠: {aabb_overlap([0,0], [1,1], [2,2], [3,3])}")  # False

print("\n=== SAT 测试 ===")
square1 = [(0,0), (2,0), (2,2), (0,2)]
square2 = [(1,1), (3,1), (3,3), (1,3)]
square3 = [(5,5), (7,5), (7,7), (5,7)]
print(f"重叠正方形: {sat_collision(square1, square2)}")  # True
print(f"分离正方形: {sat_collision(square1, square3)}")  # False

print("\n=== 扫描剪枝 ===")
boxes = [(0, 0, 2), (1, 1, 3), (2, 2, 4), (5, 5, 7)]
cands = sweep_and_prune(boxes)
print(f"候选对: {cands}")

```

`aabb_overlap` 用 6 次比较完成 3D AABB 测试。`sat_collision` 对凸多边形每条边法向量做投影分离测试。`sweep_and_prune` 沿 x 轴排序生成候选对，利用时间一致性可达近 O(n)。

## 常见误区

<Callout type="trap">
**现象 →** 宽相用 O(n²) 两两 AABB 测试。
**原因 →** 不知道可以用空间索引或扫描剪枝加速。
**修法 →** 用扫描剪枝（Sweep and Prune）沿轴排序，O(n log n + k)。或用空间哈希/BVH 只检查近邻对。1000 个对象从 50 万对降到几千候选对。
</Callout>

<Callout type="trap">
**现象 →** SAT 只能用于凸多边形，凹多边形怎么办？
**原因 →** SAT 的分离轴定理只对凸体成立。
**修法 →** 凹多边形分解为凸部件（凸分解），对每对凸部件做 SAT。或用 GJK+凹分解。也可用 BVH 包裹凹体部件做层次检测。
</Callout>

<Exercises>
**问题**：碰撞检测为什么要分宽相和窄相两阶段？

<Answer>
宽相用 O(1) 的 AABB 测试快速剔除不可能碰撞的对，将 O(n²) 对缩减到少量候选对。窄相对候选对做精确检测（SAT/GJK），避免对全部对做昂贵的精确测试。两阶段利用了「大部分对象对不碰撞」的先验。
</Answer>

**问题**：SAT 的原理是什么？为什么只测边法向量就够？

<Answer>
两个凸体不碰撞当且仅当存在分离轴。分离轴一定平行于某条边的法向量（凸性保证：最短分离距离在边法向方向取得）。所以只需测试所有边法向量方向的投影是否分离。2D 复杂度 O(m+n)，3D 需额外测试边叉积方向。
</Answer>
</Exercises>
