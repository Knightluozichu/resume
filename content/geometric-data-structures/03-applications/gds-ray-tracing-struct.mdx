## 直觉引入

光线追踪每帧发射数百万条射线，每条射线需与场景中所有三角形求交。没有空间加速结构，这是 $O(n \times \text{rays})$ 的灾难。BVH 把每条射线的测试从 $O(n)$ 降为 $O(\log n)$。

Moller-Trumbore 算法在 $O(1)$ 内完成射线-三角形相交测试，是 BVH 叶节点的核心操作。GPU 光线追踪用紧凑 BVH（32B 节点对齐）和多分支 BVH（MBVH 4/8 叉）减少 warp 分歧。NVIDIA RTX 用硬件加速 BVH 遍历。

## 概念讲解

<Term def="射线从 BVH 根到叶的递归遍历">BVH 射线遍历</Term>：从根开始测试射线与 AABB 相交，递归进入相交子树。前向排序（近子树先访问）+ 剪枝（远子树被 $t_{\text{best}}$ 裁掉）使复杂度为 $O(\log n)$。

<Term def="射线与三角形的高效相交算法">Moller-Trumbore</Term>：利用重心坐标 $P = (1-u-v)\mathbf{V_0} + u\mathbf{V_1} + v\mathbf{V_2} = \mathbf{O} + t\mathbf{D}$，解 3x3 方程组得 $t, u, v$。有效条件：$t \geq 0, u \geq 0, v \geq 0, u+v \leq 1$。$O(1)$ 复杂度。

### BVH 射线遍历伪代码
```
traverse(node, ray):
    if not ray_aabb(node.aabb, ray): return INF
    if is_leaf(node):
        t_best = INF
        for tri in node.triangles:
            t = moller_trumbore(ray, tri)
            t_best = min(t_best, t)
        return t_best
    # 前向排序
    near, far = sort_by_distance(node.children, ray)
    t_near = traverse(near, ray)
    if far.aabb_min_dist < t_near:  # 剪枝
        t_far = traverse(far, ray)
        return min(t_near, t_far)
    return t_near
```

### KD-Tree 与绳索结构
KD-Tree 用轴对齐平面递归分割空间。射线遍历时按射线方向确定子节点遍历顺序。绳索结构（Rope Structure）允许射线从一个叶节点直接跳到相邻叶节点，无需回溯到根。

### GPU 优化
- **紧凑 BVH**：节点用 32B 对齐（AABB min/max + 子指针/三角形索引），提高缓存利用率。
- **MBVH（多分支 BVH）**：4 叉或 8 叉 BVH，减少树高和 warp 分歧。
- **队列式遍历**：用线程局部队列替代栈，避免递归开销。
- **NVIDIA RTX**：硬件光线追踪核心，BVH 遍历在专用硬件上执行。

### 射线-AABB 相交（Slab Method）
逐轴计算射线进出 slab 的参数 $t_1, t_2$，取所有轴 $t_{\min} = \max(t_1)$ 和 $t_{\max} = \min(t_2)$。若 $t_{\min} \leq t_{\max}$ 且 $t_{\max} \geq 0$ 则相交。$O(1)$。

## 代码对照

用 Python 实现 BVH 射线遍历与 Moller-Trumbore：

```python
import math

def ray_aabb_slab(O, D, bmin, bmax):
    """射线-AABB 相交 (Slab Method) O(1)"""
    tmin, tmax = -math.inf, math.inf
    for i in range(3):
        if abs(D[i]) < 1e-10:
            if O[i] < bmin[i] or O[i] > bmax[i]:
                return -1  # 平行且在 slab 外
        else:
            t1 = (bmin[i] - O[i]) / D[i]
            t2 = (bmax[i] - O[i]) / D[i]
            if t1 > t2:
                t1, t2 = t2, t1
            tmin = max(tmin, t1)
            tmax = min(tmax, t2)
            if tmin > tmax:
                return -1
    return tmin if tmin >= 0 else (tmax if tmax >= 0 else -1)

def moller_trumbore(O, D, V0, V1, V2):
    """射线-三角形相交 O(1)"""
    EPS = 1e-10
    e1 = [V1[i]-V0[i] for i in range(3)]
    e2 = [V2[i]-V0[i] for i in range(3)]
    p = cross3(D, e2)
    det = dot3(e1, p)
    if abs(det) < EPS:
        return -1  # 平行
    inv_det = 1.0 / det
    t_vec = [O[i]-V0[i] for i in range(3)]
    u = dot3(t_vec, p) * inv_det
    if u < 0 or u > 1:
        return -1
    q = cross3(t_vec, e1)
    v = dot3(D, q) * inv_det
    if v < 0 or u + v > 1:
        return -1
    t = dot3(e2, q) * inv_det
    return t if t > EPS else -1

def cross3(a, b):
    return [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]]

def dot3(a, b):
    return sum(a[i]*b[i] for i in range(3))

class BVHNode:
    def __init__(self, bmin, bmax, left=None, right=None, tris=None):
        self.bmin, self.bmax = bmin, bmax
        self.left, self.right = left, right
        self.tris = tris  # 叶节点: [(V0,V1,V2), ...]
    
    def is_leaf(self):
        return self.tris is not None

def ray_traverse(node, O, D, t_best=math.inf):
    """BVH 射线遍历（前向排序+剪枝）"""
    t_aabb = ray_aabb_slab(O, D, node.bmin, node.bmax)
    if t_aabb < 0 or t_aabb >= t_best:
        return t_best  # 剪枝
    
    if node.is_leaf():
        for tri in node.tris:
            t = moller_trumbore(O, D, *tri)
            if t > 0 and t < t_best:
                t_best = t
        return t_best
    
    # 前向排序：近子树先访问
    t_left = ray_aabb_slab(O, D, node.left.bmin, node.left.bmax)
    t_right = ray_aabb_slab(O, D, node.right.bmin, node.right.bmax)
    if t_left <= t_right:
        near, far = node.left, node.right
        t_near, t_far = t_left, t_right
    else:
        near, far = node.right, node.left
        t_near, t_far = t_right, t_left
    
    t_best = ray_traverse(near, O, D, t_best)
    if t_far < t_best:  # 远子树可能更近
        t_best = ray_traverse(far, O, D, t_best)
    return t_best

# 测试
O, D = [0, 0, 0], [0, 0, 1]
leaf1 = BVHNode([0,-1,8], [2,1,12], tris=[
    ([0,-1,10],[2,-1,10],[0,1,10])
])
leaf2 = BVHNode([3,-1,15], [5,1,20], tris=[
    ([3,-1,18],[5,-1,18],[3,1,18])
])
root = BVHNode([0,-1,8], [5,1,20], left=leaf1, right=leaf2)

t = ray_traverse(root, O, D)
print(f"最近交点 t={t}")  # t≈10

```

`ray_aabb_slab` 用 slab method 做 $O(1)$ 相交测试。`moller_trumbore` 用重心坐标在 $O(1)$ 内测试射线-三角形。`ray_traverse` 实现前向排序+剪枝的 BVH 遍历：近子树先访问，$t_{\text{best}}$ 剪远子树。10 万三角形场景从 10 万次测试降为约 20 次 AABB + 少量三角形测试。

## 常见误区

<Callout type="trap">
**现象 →** 射线遍历 BVH 时没有前向排序，两棵子树都遍历。
**原因 →** 忽略了剪枝优化的前提是先访问近子树。
**修法 →** 前向排序：按子节点 AABB 到射线原点的距离排序。先访问近子树得到 t_best，远子树 AABB 最近距离≥t_best 时跳过。这把最坏 O(n) 降为 O(log n)。
</Callout>

<Callout type="trap">
**现象 →** GPU 光线追踪性能不理想，warp 分歧严重。
**原因 →** 二叉 BVH 树高较大，不同射线的遍历路径分歧多。
**修法 →** 用 MBVH（4 叉或 8 叉）减少树高。紧凑节点布局（32B 对齐）提高缓存利用率。队列式遍历替代递归栈。NVIDIA RTX 用硬件核心加速 BVH 遍历。
</Callout>

<Exercises>
**问题**：光线追踪中 BVH 把射线-场景相交从 O(n) 降为 O(log n)，关键机制是什么？

<Answer>
前向排序+剪枝。射线从 BVH 根开始，先测 AABB 相交（O(1) slab method）。不相交的子树直接剪枝。相交的子树中，近子树先访问得到 t_best，远子树 AABB 最近距离≥t_best 时也剪枝。这样每条射线只访问 O(log n) 个节点 + 少量叶节点三角形。
</Answer>

**问题**：Moller-Trumbore 算法的原理和优势是什么？

<Answer>
利用重心坐标 P=(1-u-v)V0+uV1+vV2=O+tD，解 3x3 方程组得 t,u,v。有效条件：t≥0, u≥0, v≥0, u+v≤1。优势：O(1) 复杂度，无需预计算三角形外接圆/平面方程，一次计算同时给出交点参数 t 和重心坐标 (u,v)（后者用于插值法向/纹理），数值稳定性好。
</Answer>
</Exercises>
