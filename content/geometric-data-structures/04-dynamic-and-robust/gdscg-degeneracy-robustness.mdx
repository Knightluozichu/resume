### 核心对象

1. **鲁棒谓词**：即使输入接近退化也返回与精确算术一致符号的离散判断。
2. **精确几何计算**：以精确谓词保证组合拓扑，再按需要近似构造坐标的计算范式。
3. **退化**：输入落在使一般位置假设失效的低维配置，如共线、共圆或重复。
4. **符号扰动**：用无穷小的确定性次序打破平局而不实际移动坐标。
5. **误差过滤器**：先用快速浮点估计及误差界判断符号，不确定时升级精度。

## 查询与表示契约

先固定数据域、维数、闭开边界、查询输出和数值语义。树高或节点数不是独立目标；只有候选完备、结果无重复、复杂度含输出规模且数值分支一致时，结构才算正确。

$$
orient_2(a,b,c)=\det\begin{pmatrix}a_x&a_y&1\\b_x&b_y&1\\c_x&c_y&1\end{pmatrix}
$$

$$
|\widehat p-p|\le E
$$

$$
|\widehat p|>E\Longrightarrow sign(\widehat p)=sign(p)
$$

$$
x_i(\epsilon)=x_i+\epsilon^{\pi(i)}
$$

几何拓扑通常由行列式符号决定，而近退化时真实值小于舍入误差。过滤谓词先计算近似值和可证明误差界，只有绝对值大于界时接受符号，否则转向扩展精度或整数算术。真退化需单独定义语义，符号扰动通过输入ID形成全局一致的平局规则。 每个剪枝判断都应能回答两个问题：被排除的集合是什么，以及哪个不变量证明它不含答案。

## 可核查构建与查询

每个谓词返回符号、使用精度和误差界，不返回含糊epsilon布尔值。测试集覆盖尺度变换、坐标置换和接近退化序列；拓扑算法保存每次谓词调用，失败时可重放。构造点采用延迟精确表示或经验证的区间。


```python
def query_with_trace(root, request):
    stack, hits, trace = [root], [], []
    while stack:
        node = stack.pop()
        trace.append(node.id)
        if node.disjoint(request):
            continue
        if node.is_leaf:
            hits.extend(node.exact_matches(request))
        else:
            stack.extend(node.children)
    return sorted(set(hits)), trace
```

通用骨架必须由本章的具体不变量实例化：区域不相交、包围体不重叠、空邻域、证书未失效或静态块版本有效。不能把候选生成误写成最终答案，叶节点仍需执行本章定义的精确测试。

## 复杂度与工程取舍

复杂度报告分离构建、查询、更新、内存和输出规模。平均值之外记录P95与最坏样例；同时保存访问节点、候选对象和精确谓词次数，这样才能判断瓶颈来自树质量、数据分布还是数值回退。

```python
metrics = {
    "build_ms": 0.0,
    "visited_nodes": 0,
    "candidates": 0,
    "exact_tests": 0,
    "update_ms": 0.0,
}
assert set(metrics) == {"build_ms", "visited_nodes", "candidates", "exact_tests", "update_ms"}
```

只在结果集合与基线一致后比较性能。构建更慢可能换来大量查询收益，更新更便宜也可能逐渐恶化结构；因此工作负载中的查询次数、更新比例和生命周期必须写入报告。

## 边界、退化与反例

统一epsilon不具尺度不变性，可能同时产生a在b左侧和b在a左侧；NaN比较会静默落入错误分支；直接随机扰动不能复现。鲁棒性不仅是避免崩溃，还要维持组合不变量。

```python
audit = {
    "normal": "representative geometry",
    "boundary": "closed-open convention",
    "degenerate": "duplicate or co-located input",
    "baseline": "brute-force exact result",
}
assert all(audit.values())
```

## 图形学应用

增量Delaunay在近共圆点集上分别使用普通浮点、固定epsilon和自适应精确谓词，比较非法边、非流形次数和耗时。只有拓扑正确且结果与输入排列无关的策略通过。 应用层还要记录从世界坐标到结构坐标的变换，避免把坐标系错误误判为数据结构错误。

## 验收证书

验收包包含原始输入、结构参数、节点或图邻接、查询日志、候选集合、精确结果、复杂度计数和失败反例。使用带推导误差界的过滤谓词，并为精确零值提供确定性退化处理。 任何无法重放的截图或孤立耗时都不能替代证书。

本页覆盖鲁棒谓词、精确几何计算、退化、符号扰动、误差过滤器。掌握标准是能从查询契约选择表示，推导剪枝或邻近条件，实现构建与更新，并用精确基线、退化输入和复杂度计数形成可重放证书。
