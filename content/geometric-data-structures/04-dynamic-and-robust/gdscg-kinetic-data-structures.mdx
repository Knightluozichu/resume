### 核心对象

1. **动力数据结构**：对象沿已知轨迹运动时，通过局部事件维护组合关系的数据结构。
2. **证书**：当前为真的局部谓词，其共同成立保证全局结构正确。
3. **失效时间**：证书谓词沿轨迹下一次变号或到达零点的时间。
4. **事件队列**：按失效时间排序并驱动局部修复的优先队列。
5. **外部事件**：由应用改变轨迹或增删对象、而非证书自然失效触发的更新。

## 查询与表示契约

先固定数据域、维数、闭开边界、查询输出和数值语义。树高或节点数不是独立目标；只有候选完备、结果无重复、复杂度含输出规模且数值分支一致时，结构才算正确。

$$
c_i(t)>0
$$

$$
t_i^*=\inf\{t>t_0\mid c_i(t)=0\}
$$

$$
T=O(E\log C+U)
$$

$$
\operatorname{valid}(S,t)=\bigwedge_i c_i(t)\ge0
$$

静态线段树的端点次序和规范节点决定存储位置；运动后只要相关次序证书仍成立，组合结构无需改变。每个证书求下一失效根并入队，事件发生时局部交换、更新受影响节点并重新计算证书。动力BSP同样以局部分类和相交关系为证书。 每个剪枝判断都应能回答两个问题：被排除的集合是什么，以及哪个不变量证明它不含答案。

## 可核查构建与查询

事件记录证书版本、对象ID和时间，弹出时先检查版本避免处理陈旧事件。所有轨迹都限定有效时间区间，外部更新先撤销旧证书再建立新证书。小场景每个事件后按当前坐标重建静态结构并比较查询结果。

```python
def query_with_trace(root, request):
    stack, hits, trace = [root], [], []
    while stack:
        node = stack.pop()
        trace.append(node.id)
        if node.disjoint(request):
            continue
        if node.is_leaf:
            hits.extend(node.exact_matches(request))
        else:
            stack.extend(node.children)
    return sorted(set(hits)), trace
```

通用骨架必须由本章的具体不变量实例化：区域不相交、包围体不重叠、空邻域、证书未失效或静态块版本有效。不能把候选生成误写成最终答案，叶节点仍需执行本章定义的精确测试。


## 复杂度与工程取舍

复杂度报告分离构建、查询、更新、内存和输出规模。平均值之外记录P95与最坏样例；同时保存访问节点、候选对象和精确谓词次数，这样才能判断瓶颈来自树质量、数据分布还是数值回退。

```python
metrics = {
    "build_ms": 0.0,
    "visited_nodes": 0,
    "candidates": 0,
    "exact_tests": 0,
    "update_ms": 0.0,
}
assert set(metrics) == {"build_ms", "visited_nodes", "candidates", "exact_tests", "update_ms"}
```

只在结果集合与基线一致后比较性能。构建更慢可能换来大量查询收益，更新更便宜也可能逐渐恶化结构；因此工作负载中的查询次数、更新比例和生命周期必须写入报告。

## 边界、退化与反例

同时事件、切触不换序、重根、时间倒退和浮点根排序都会破坏事件顺序。若两个证书在同一时间互相依赖，应批处理同一时间戳并在处理后重新验证全局不变量。

```python
audit = {
    "normal": "representative geometry",
    "boundary": "closed-open convention",
    "degenerate": "duplicate or co-located input",
    "baseline": "brute-force exact result",
}
assert all(audit.values())
```

## 图形学应用

维护运动线段的刺穿查询：端点顺序事件更新线段树，查询在任意时间先推进到该时刻再执行。报告事件数量、局部修复规模、陈旧事件比例和与逐帧重建的交叉点。 应用层还要记录从世界坐标到结构坐标的变换，避免把坐标系错误误判为数据结构错误。

1. 用五到十个对象手算结构，标出节点覆盖、邻接或证书。
2. 执行一个正常查询和一个恰落在边界的查询，逐节点记录剪枝理由。
3. 删除一个一般位置或静态假设，构造首个失败样例。
4. 与穷举答案逐项比较，再扩大规模测构建、查询、更新和内存。

## 验收证书

验收包包含原始输入、结构参数、节点或图邻接、查询日志、候选集合、精确结果、复杂度计数和失败反例。给证书加版本号和轨迹世代，处理事件前验证其仍对应当前状态。 任何无法重放的截图或孤立耗时都不能替代证书。
