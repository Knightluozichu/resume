### 原书小节覆盖

1. 静态层次：四叉树、kd树、BSP与BVH
2. 连续结构：距离场、Voronoi图与邻近图
3. 时间维度：动力证书与事件处理
4. 工程可靠性：退化、精确谓词与动态重建
5. 综合验收：正确性、复杂度、内存和更新尾延迟

### 核心对象

1. **结构选型矩阵**：按对象类型、查询形状、维数、更新模式和数值风险比较候选结构。
2. **剪枝证书**：证明一个节点或对象集合不可能包含答案的可重放条件。
3. **拓扑证书**：由精确谓词和退化规则共同保证的组合结构不变量。
4. **更新证书**：记录动力事件或重建策略保持结构新鲜的依据。
5. **交叉验收**：用穷举、另一种结构和理论不变量三路核对同一结果。

## 查询与表示契约

先固定数据域、维数、闭开边界、查询输出和数值语义。树高或节点数不是独立目标；只有候选完备、结果无重复、复杂度含输出规模且数值分支一致时，结构才算正确。

$$
C=(T_{build},T_{query},T_{update},M,\varepsilon)
$$

$$
R_{fast}=R_{brute}
$$

$$
speedup=\frac{T_{baseline}}{T_{candidate}}
$$

$$
\operatorname{pass}=correct\land robust\land reproducible
$$

全书的共同模式是把全集分成可排除的子集，并给排除决策配证书。树结构依靠区域或包围不变量，距离与邻近结构依靠度量关系，动力结构依靠时间证书，动态化依靠摊还重建，鲁棒计算则保证所有离散分支的符号可信。 每个剪枝判断都应能回答两个问题：被排除的集合是什么，以及哪个不变量证明它不含答案。

## 可核查构建与查询

综合实验使用同一对象仓库和查询日志，结构适配器统一build、query、update、validate接口。每次运行保存版本、参数、随机种子、访问轨迹和基线差异；性能数据只有在结果集合完全相等后才参与比较。

```python
def query_with_trace(root, request):
    stack, hits, trace = [root], [], []
    while stack:
        node = stack.pop()
        trace.append(node.id)
        if node.disjoint(request):
            continue
        if node.is_leaf:
            hits.extend(node.exact_matches(request))
        else:
            stack.extend(node.children)
    return sorted(set(hits)), trace
```

通用骨架必须由本章的具体不变量实例化：区域不相交、包围体不重叠、空邻域、证书未失效或静态块版本有效。不能把候选生成误写成最终答案，叶节点仍需执行本章定义的精确测试。


## 复杂度与工程取舍

复杂度报告分离构建、查询、更新、内存和输出规模。平均值之外记录P95与最坏样例；同时保存访问节点、候选对象和精确谓词次数，这样才能判断瓶颈来自树质量、数据分布还是数值回退。

```python
metrics = {
    "build_ms": 0.0,
    "visited_nodes": 0,
    "candidates": 0,
    "exact_tests": 0,
    "update_ms": 0.0,
}
assert set(metrics) == {"build_ms", "visited_nodes", "candidates", "exact_tests", "update_ms"}
```

只在结果集合与基线一致后比较性能。构建更慢可能换来大量查询收益，更新更便宜也可能逐渐恶化结构；因此工作负载中的查询次数、更新比例和生命周期必须写入报告。

## 边界、退化与反例

高维、密集重叠、近退化、事件风暴、频繁删改和空输出分别击穿不同假设。总复习不接受单一平均耗时，而要求说明渐近界、常数、内存、尾延迟和误差语义。

```python
audit = {
    "normal": "representative geometry",
    "boundary": "closed-open convention",
    "degenerate": "duplicate or co-located input",
    "baseline": "brute-force exact result",
}
assert all(audit.values())
```

## 图形学应用

设计一份结构决策报告：先写查询契约，再列两种候选，给出理论成本、可视化访问轨迹和反例，最后用固定基准确认选择。任何优化都必须保留可关闭开关和正确性基线。 应用层还要记录从世界坐标到结构坐标的变换，避免把坐标系错误误判为数据结构错误。

1. 用五到十个对象手算结构，标出节点覆盖、邻接或证书。
2. 执行一个正常查询和一个恰落在边界的查询，逐节点记录剪枝理由。
3. 删除一个一般位置或静态假设，构造首个失败样例。
4. 与穷举答案逐项比较，再扩大规模测构建、查询、更新和内存。

## 验收证书

验收包包含原始输入、结构参数、节点或图邻接、查询日志、候选集合、精确结果、复杂度计数和失败反例。从查询形状、数据分布和更新模型重新推导候选，并用统一基线做交叉验收。 任何无法重放的截图或孤立耗时都不能替代证书。
