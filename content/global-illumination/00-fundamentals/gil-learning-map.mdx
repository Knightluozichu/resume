## 直觉：全局光照不是“多弹几次光线”

先预测：同一个 Cornell box 中，为什么 path tracing 会表现为像素噪声，radiosity 会表现为网格离散误差，photon mapping 又会表现为半径模糊？三者近似的是同一光传输过程，但选择了不同的状态表示、采样分布和重建算子。只记“直接光 + 间接光”无法解释这些误差的来源。

真实感图像合成还不止于求一个漂亮像素。输入包括光源、几何、材质和观察系统；中间是 radiance 在路径上的传输；输出还要经过显示与人类视觉。**Advanced Global Illumination, Second Edition** 的组织方式正是从物理量和积分方程出发，逐步构造随机路径、随机辐射度与混合算法，最后讨论参与介质、次表面散射、色调映射、快速计算和未解决问题。

## 权威版本与复刻边界

本项目锁定 Philip Dutré、Kavita Bala、Philippe Bekaert 编写的 **Advanced Global Illumination, Second Edition**，A K Peters，2006，ISBN-10 `1-56881-307-4`、ISBN-13 `978-1-56881-307-3`。核对口径是该版目录的 9 个正文章和 3 个附录，而不是把后来出现的 LPV、DDGI 或硬件光追倒灌成原书主线。

第二版相对前版的重要变化也决定了复刻范围：第 5 章加入 environment map illumination；第 7、8 章扩展 scalable rendering 与 precomputed radiance transfer；每章增加 exercises。因此，本地页面既要保留 2006 年原书的历史边界，也要提供公式、图解、算法步骤与可判定答案。

<Term def="由可核对的版本、作者、ISBN 与原书目录共同确定的内容集合，用来防止错版、漏章和现代概念倒灌">权威版本基线</Term>只规定“必须覆盖什么”。它不授权逐字复制原书表述；这里复刻的是核心知识结构、推理链和实践能力，并用独立中文讲解与自制图示实现。

## 九章与三个附录

### 第一组：物理与数值基础

1. **Introduction**：真实感图像合成、全局光照框架，以及 acquisition、transport、display 三个环节。
2. **The Physics of Light Transport**：radiometry、emission、BRDF、rendering equation、importance 与 measurement equation。
3. **Monte Carlo Methods**：概率回顾、Monte Carlo integration、随机变量采样、inversion/rejection、variance reduction、stratification 与 quasi-Monte Carlo。
4. **Strategies for Computing Light Transport**：radiance/importance 的伴随关系、GRDF、算法分类和 path formulation。

### 第二组：三类核心求解器

5. **Stochastic Path-Tracing Algorithms**：ray setup、stochastic path tracing、direct/environment/indirect illumination 与 light tracing。
6. **Stochastic Radiosity**：classic radiosity、form factor、stochastic relaxation、random walk、density estimation、hierarchical refinement 与 clustering。
7. **Hybrid Algorithms**：final gathering、multipass、bidirectional tracing、Metropolis light transport、irradiance caching、photon mapping、instant radiosity 与 lightcuts。

### 第三组：真实感边界、总结与实现材料

8. **The Quest for Ultimate Realism and Speed**：participating media、subsurface scattering、tone mapping、human perception、fast GI 与 precomputed radiance transfer。
9. **Conclusion**：回看 photorealistic rendering 的成果、局限和 unresolved issues。
A. **A Class Library for Global Illumination**：path node、light source sampler、support classes 与算法接口。
B. **Hemispherical Coordinates**：solid angle、球面/半球坐标及 hemisphere integration。
C. **Theoretical Analysis of Stochastic Relaxation Radiosity**：随机松弛辐射度的收敛与 variance analysis。

## 一条方程怎样分裂成多种算法

<Term def="描述一点沿出射方向的辐亮度等于自发光与所有入射方向散射贡献之和的积分方程">渲染方程</Term>是共同起点：

$$
L_o(x,\omega_o)=L_e(x,\omega_o)+\int_{\Omega_x}f_r(x,\omega_i,\omega_o)L_i(x,\omega_i)\,|n\cdot\omega_i|\,d\omega_i.
$$

若把传播与散射写成算子 $\mathcal K$，则 $L=L_e+\mathcal K L$。路径追踪展开 Neumann series，依次估计零次、一次和多次散射：

$$
L=\sum_{k=0}^{\infty}\mathcal K^k L_e.
$$

对一般积分 $I=\int_D f(x)dx$，从密度 $p$ 采样得到 Monte Carlo estimator：

$$
\widehat I_N=\frac{1}{N}\sum_{i=1}^{N}\frac{f(X_i)}{p(X_i)},\qquad X_i\sim p.
$$

其方差揭示 importance sampling 的目标：让 $p$ 尽量追随 $|f|$，但必须覆盖所有非零贡献区域。

$$
\operatorname{Var}[\widehat I_N]=\frac{1}{N}\left(\int_D\frac{f(x)^2}{p(x)}dx-I^2\right).
$$

<Term def="对表面划分离散单元，以形状因子描述单元间能量交换，并求解有限维能量平衡系统的方法">辐射度法</Term>没有改变物理问题，而是选用表面基函数和 form factor 离散算子。随机辐射度再用 random walk 或 stochastic relaxation 估计能量交换。<Term def="把多种求解器、端点方向或缓存表示组合起来，以降低单一方法在困难路径上的方差或成本">混合算法</Term>则在 path tracing、light tracing、density estimation 和 cache 之间分配工作。

## 算法不能只按“是否无偏”排序

无偏估计器满足 $\mathbb E[\widehat I]=I$，但有限样本图像可能噪声极大；有偏估计器可能在给定半径、缓存阈值或离散网格下产生系统误差，却在同等时间内有更低 mean squared error。评价一章中的算法至少要记录：

1. **bias** 是否随样本、网格或核半径缩小而消失；
2. **variance** 是否由稀有高贡献路径、可见性突变或 PDF mismatch 主导；
3. **consistency** 是否在资源趋于无穷时收敛到正确解；
4. **cost** 的时间、内存、预计算和重用边界；
5. **failure signature** 是噪声、漏光、模糊、闪烁还是能量漂移。

例如 photon density estimate 对有限半径有偏，但若半径随样本数按正确速率收缩，可以保持一致性；纯 path tracing 常被称为无偏，却可能在 caustic 或狭小光源场景下几乎采不到有效路径。书中策略分类的价值就在于解释“贡献从哪一端生成、在哪个域重建、用什么概率连接”，而不是贴一个好坏标签。

## 两条阅读路径

**方程到渲染器路径**：1 → 2/B → 3 → 4 → 5/A → 7 → 8 → 9。适合实现者：先统一量纲、测度与 PDF，再构造 camera/light subpath，最后加入缓存、双向连接和快速近似。

**能量传播与有限元路径**：1 → 2/B → 6/C → 4 → 7 → 8 → 9。适合关注 diffuse interreflection、form factor、hierarchical refinement 与 stochastic relaxation 的读者。第 3 章仍是必修前置，因为随机松弛和 random walk 的误差需要概率工具解释。

无论选哪条路径，都要能把一个像素追溯为：测量函数选择路径 → 路径经过可见性和散射 → estimator 除以联合 PDF → 多样本聚合 → tone mapping/display。跳读不应切断这条 producer-to-consumer 链。

## 常见误区

<Callout type="trap">
**现象 →** 把“全局光照”页写成 RSM、LPV、RTX、降噪的现代名词表。**原因 →** 没锁定 2006 第二版目录。**修法 →** 先还原原书的 radiometry、Monte Carlo、path/radiosity/hybrid 主线；现代方法只能作为标明年代的延伸。
</Callout>

<Callout type="trap">
**现象 →** 认为无偏算法在有限时间内一定优于有偏算法。**原因 →** 只看 expectation，不看 variance、MSE 和一致性。**修法 →** 固定工作量比较误差，并说明半径、缓存和离散化参数怎样随预算变化。
</Callout>

<Callout type="trap">
**现象 →** 列出 12 个标题就宣布原书覆盖 100%。**原因 →** 把目录 matcher 当成内容审查。**修法 →** 每个单元必须在唯一正文页出现概念、公式、专用图、算法过程、失败模式、练习和参考证据。
</Callout>

## 练习

<Exercises>

**问题 1：为什么附录 B 的半球坐标应与第 2 章一起学习？**

<Answer>
渲染方程在表面上对入射方向积分，立体角是方向域的测度，球面坐标变换还会引入 Jacobian。若不理解 $d\omega=\sin\theta\,d\theta\,d\phi$，就无法判断 cosine-weighted sampling、PDF 和 estimator 的量纲是否正确。
</Answer>

**问题 2：路径追踪和随机辐射度怎样近似同一传输过程？**

<Answer>
路径追踪在路径空间随机生成顶点序列并累计路径 throughput；辐射度先以表面基函数离散 diffuse 能量，再通过 form factor 求解单元交换，随机版本用 random walk 或 relaxation 估计该交换。差别在表示与数值求解，不在物理定律。
</Answer>

**问题 3：为什么光子映射有独立本地页面，却不能记作独立原书章？**

<Answer>
它在原书中属于第 7 章 Hybrid Algorithms 的 7.6 节。本地独立页面是为了深入 photon tracing、空间索引和 density estimation；目录覆盖仍归入第 7 章，避免虚增原书单元数量。
</Answer>

**问题 4：怎样验收一个 environment map importance sampler？**

<Answer>
检查球面测度和像素到方向的 Jacobian；验证 PDF 归一化并覆盖非零亮度；用常量环境检查无方向偏差，用单个高亮 texel 检查采样集中度；固定样本数与均匀采样比较 variance，同时记录极点和纹理边界的失败情况。
</Answer>

</Exercises>

## 小结

第二版的 9 章与 3 个附录组成一条完整链：定义光传输量与测度，用 Monte Carlo 建立数值工具，以路径、辐射度和混合方法求解，再把结果放回介质、感知、速度和工程实现中评估。本地图负责版本、归属、依赖和验收；8 个正文页必须逐单元交付真正可学习、可推导、可验证的核心内容。
