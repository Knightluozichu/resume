## 直觉引入

想象一个房间。阳光从窗户射入，直接照亮地板——这是直接光照。但墙壁、天花板也被照亮了，因为光在房间内多次弹射——这是间接光照。没有间接光照，阴影区域会纯黑，角落会不自然。全局光照（GI）就是计算这些光弹射的技术。

全书从最简单的直接光照出发，经过辐射度、路径追踪等离线方法，到重要性采样等数学工具，最终追求实时GI的工程化。

## 代码对照

```cpp
// GI 的核心：直接光 + 间接光
Spectrum L = directLighting + indirectLighting;

// 直接光：显式采样光源
L_direct = sum(Light) BRDF * Li * cos / pdf;

// 间接光：递归追踪反射光线
L_indirect = BRDF * Li(reflectRay) * cos / pdf;

// GI = 直接光 + 间接光（多次弹射）
```

## 常见误区

<Callout type="trap">
**误区：把GI等同于路径追踪。**
离线GI用蒙特卡洛路径追踪，采样数无上限。实时GI预算只有几毫秒，必须用近似方法（如RSM将反射阴影映射到纹理，LPV将光照注入3D网格传播）。两者是不同的技术栈。
</Callout>

<Callout type="trap">
**误区：认为实时GI和离线GI用相同方法。**
实时GI用大量近似（屏幕空间技术、预计算、低精度传播），离线GI用精确的蒙特卡洛采样。混淆两者会导致方法选型错误。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？它们之间是什么关系？

<Answer>
直接与间接光、离线GI方法、采样理论、实时GI。呈递进关系：直接/间接光是概念基础，离线方法是原理学习，采样理论是数学工具，实时GI是工程目标。每一层都建立在前一层之上。
</Answer>

**问题 2**：为什么只有直接光照的渲染看起来不真实？

<Answer>
因为真实世界中光会多次弹射——墙壁反射的光照亮天花板，桌面的反射光照亮椅子下方。只有直接光照时，阴影区域纯黑（没有间接光填充），色彩不渗透（红色墙壁不会给旁边白色物体染上红色），整体看起来扁平不自然。间接光照是真实感的关键。
</Answer>
</Exercises>
