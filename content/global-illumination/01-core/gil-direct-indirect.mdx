## 直觉：一个像素到底测量了什么

先预测：若把一个面光源放大四倍，同时把它的总 radiant flux 保持不变，照在墙上的亮度会怎样变化？若只存“光源颜色 × 强度”，很难回答；若明确 area emitter 的 radiance、表面接收的 irradiance、BRDF 和相机 measurement function，就能逐项核对能量与几何关系。

真实感图像合成（realistic image synthesis）的目标不是模仿照片滤镜，而是给定现实采集或人工设计的场景描述，预测成像系统将测到的光。原书第 1 章把问题置于更大的系统中：先获取/建模几何、材质与光源，再计算场景中的全局光照（global illumination framework），最后通过相机、显示和人类视觉解释结果。

<GilDirectIndirectDiagram />

一张物理正确但 tone mapping 错误的 HDR 图会显示失败；一个几何与 BRDF 不可信的场景也不会因求解器无偏而“真实”。因此，第 1 章的框架要求把 scene acquisition、light transport 与 visual display 分开验收。本页重点建立中间的物理契约，并说明它如何被测量端使用。

## 能量、功率与辐射度量

<Term def="以可加、守恒的物理量描述辐射能在时间、面积与方向上的分布，是光传输算法的量纲基础">辐射度量</Term>（radiometry）从 radiant energy $Q$ 开始。Radiant flux 是单位时间通过的能量，$\Phi=dQ/dt$，单位 watt。Irradiance $E$ 是入射到表面的 flux density，单位 $\mathrm{W/m^2}$；radiant exitance 则描述离开表面的通量密度。

<GilRadiometryBalanceDiagram />

<Term def="单位投影面积、单位立体角上的辐射通量密度；在真空直线传播中保持不变，是路径追踪携带的核心量">辐亮度</Term>（radiance）同时保留位置和方向。沿方向 $\omega$ 穿过面积 $dA$、立体角 $d\omega$ 的微分 flux 为：

$$
d^2\Phi=L(x,\omega)\,|n\cdot\omega|\,dA\,d\omega.
$$

余弦不是经验“压暗项”，而是面积投影：斜射方向看到的有效面积是 $dA_\perp=|n\cdot\omega|dA$。若 sampler 的 PDF 已按 projected solid angle 定义，却又额外乘一次 cosine，就会发生双重计权。

## 半球坐标与立体角

方向积分不是普通二维角度积分。附录 B 用 hemispherical coordinates（半球坐标）明确：以表面法线为极轴，方向由 polar angle $\theta$ 和 azimuth $\phi$ 表示，单位球面的面积就是 solid angle（立体角）。

<GilHemisphereMeasureDiagram />

球面参数化的 Jacobian 给出：

$$
d\omega=\sin\theta\,d\theta\,d\phi,
\qquad \theta\in[0,\pi/2],\quad\phi\in[0,2\pi).
$$

用它检查整个上半球的立体角：$\int_0^{2\pi}\int_0^{\pi/2}\sin\theta\,d\theta d\phi=2\pi$ sr。再检查 cosine-weighted normalization：$\int_{\Omega^+}\cos\theta\,d\omega=\pi$。因此 Lambertian BRDF 为 $\rho/\pi$，而常用 cosine-weighted PDF 为 $p(\omega)=\cos\theta/\pi$。

## 发射、散射与 BRDF

表面可以自发光，也可以把入射 radiance 散射到出射方向。<Term def="双向反射分布函数，定义单位入射 irradiance 对指定出射 radiance 的贡献，并受能量守恒与互易性约束">双向反射分布函数</Term>（BRDF）定义为：

$$
f_r(x,\omega_i,\omega_o)=\frac{dL_o(x,\omega_o)}{dE_i(x,\omega_i)}.
$$

它的单位是 $\mathrm{sr^{-1}}$。物理可行 BRDF 至少要满足非负、能量守恒；在 Helmholtz reciprocity 成立的普通被动材料上还有 $f_r(\omega_i,\omega_o)=f_r(\omega_o,\omega_i)$。镜面 delta distribution 不能当普通有限函数代入数值积分，采样与 PDF 必须在相同测度下处理。

Emission 给出 $L_e$；reflection 把 hemisphere 上的 $L_i$ 变为 $L_o$；visibility 与 geometry 负责把另一点的出射 radiance 连接为当前点的入射 radiance。光传输因此是局部散射和全局传播的交替。

## 渲染方程与直接/间接分解

<Term def="描述一点沿出射方向的辐亮度等于自发光与所有入射方向散射贡献之和的积分方程">渲染方程</Term>（rendering equation）写为：

$$
L_o(x,\omega_o)=L_e(x,\omega_o)+
\int_{\Omega_x^+}f_r(x,\omega_i,\omega_o)L_i(x,\omega_i)|n\cdot\omega_i|d\omega_i.
$$

$L_i$ 又来自别处的 $L_o$，所以这是递归积分方程。把入射域按“下一段是否命中 emitter”划分，才得到算法上的 direct illumination 与 indirect illumination；它不是简单用固定弹射次数定义。相机直接看见光源对应 emission/零次散射；相机射线命中表面后显式连接光源通常称直接光；其余经过非发光表面再传播的贡献称间接光。

色渗透来自能量与 spectrum 的连续散射：白光被红墙的 spectral BRDF 选择性反射，再作为邻近表面的 $L_i$。阴影不纯黑、亮部互反射和 caustic 都可由同一方程解释，不需要另造“效果项”。Ambient light 和 ambient occlusion 只能是某些场景/方向分布下的低维近似，不能替代一般 $L_i(x,\omega)$。

## 重要度与测量方程

只从光源向外追踪会生成大量永远不进入相机的能量。原书同时引入 <Term def="从传感器或目标测量向场景反向传播的敏感度函数，用于判断某段传输对最终测量的价值">重要度</Term>（importance）：radiance 描述能量从 emitter 流向场景，importance 描述 camera measurement 对位置方向状态的敏感度。二者的传输方程互为 adjoint，为后续 light tracing 与 bidirectional methods 奠基。

像素值不是某条相机 ray 上的单点 radiance，而是 radiance 与 sensor response 的积分。令 $W_e$ 表示像素/镜头/时间/波长的 measurement function，抽象测量方程可写成：

$$
M=\int_{\mathcal R} W_e(r)\,L(r)\,d\mu(r).
$$

这里的域 $\mathcal R$ 可以包含 sensor position、direction、time 与 wavelength。Pinhole camera、finite aperture、motion blur 和 spectral sensor 只是选择不同 $W_e$。把 importance 与 radiance 分开，可以解释为什么“对场景能量很大”不等于“对某个像素贡献很大”。

## 从方程到可执行估计器

渲染器应保留量纲和 producer-to-consumer 关系，而不是把所有值都装进 `Color`：

```cpp
Radiance estimate(const Surface& x, Direction wo, Sampler& rng) {
    Radiance Lo = x.emission(wo);
    Lo += sampleEmitterConnection(x, wo, rng); // direct estimator

    auto s = x.bsdf.sample(wo, rng);           // wi, f, pdf in solid angle
    if (!s.valid || s.pdf == 0) return Lo;
    const auto Li = trace(nextRay(x, s.wi), rng);
    return Lo + s.f * Li * absDot(x.normal, s.wi) / s.pdf;
}
```

代码中的 `Li` 必须是 radiance，`s.f` 是 $\mathrm{sr^{-1}}$，cosine 无单位，`pdf` 是 $\mathrm{sr^{-1}}$；乘除后仍为 radiance。若 emitter connection 与 BSDF continuation 都可能采到同一直接路径，还要用 MIS 权重避免重复计数，而不是把两项无条件相加。

## 常见误区

<Callout type="trap">
**现象 →** 把 irradiance、radiance 和 RGB 都叫“光照强度”。**原因 →** 忽略面积、方向与单位。**修法 →** 为每个变量写 quantity、unit、domain 和 measure，再做乘积量纲检查。
</Callout>

<Callout type="trap">
**现象 →** 用“弹一次是直接、弹两次是间接”分类所有路径。**原因 →** 混淆从相机端计数、从光源端计数和散射事件。**修法 →** 明确 path convention，并按 emitter connection 与非发光表面 continuation 分解 estimator。
</Callout>

<Callout type="trap">
**现象 →** 在 $d\theta d\phi$ 上均匀采样就宣称方向均匀。**原因 →** 丢失球面 Jacobian $\sin\theta$。**修法 →** 在 solid angle 上验证 PDF normalization，并用球面积分测试样本直方图。
</Callout>

## 练习

<Exercises>

**问题 1：为什么 radiance 适合作为路径传播量，而 irradiance 不适合？**

<Answer>
Radiance 保留方向，在无参与介质的真空直线段上不随距离变化，可在两个端点间直接传递；irradiance 已对接收半球方向积分，丢失了光从何处到来的信息，无法继续经过方向相关 BRDF 传播。
</Answer>

**问题 2：证明 Lambertian BRDF 中为什么有 $1/\pi$。**

<Answer>
若 $f_r=\rho/\pi$，常量入射 radiance 为 $L_i$，反射出射 radiance为 $(\rho/\pi)L_i\int_{\Omega^+}\cos\theta d\omega=(\rho/\pi)L_i\pi=\rho L_i$。因此半球总反射比例是 albedo $\rho$，满足能量守恒。
</Answer>

**问题 3：一个像素的 measurement function 可能包含哪些维度？**

<Answer>
至少包含 sensor/film 上的空间滤波与镜头方向；有限孔径还包含 aperture position，motion blur 包含 time，光谱成像包含 wavelength。像素值是这些维度上 radiance 与响应函数的积分，而不是理想中心 ray 的单个值。
</Answer>

**问题 4：怎样发现 cosine 被重复计算？**

<Answer>
先确认 BRDF、采样 PDF 和积分使用的测度。若 PDF 是 projected-solid-angle density，cosine 已吸收到测度；估计器再乘 cosine 会重复。用常量环境照明和 Lambertian 白炉测试：正确结果应与方向旋转无关且不凭空损失能量。
</Answer>

</Exercises>

## 小结

第 1、2 章和附录 B 共同建立全书契约：真实感图像合成从场景获取经 global illumination 到测量显示；radiometry 给每个值明确量纲；hemispherical coordinates 给方向积分明确测度；rendering equation 连接 emission、scattering 与 visibility；importance 和 measurement equation 再说明哪些传输会影响最终像素。后续所有算法只是对这套物理与测量系统的不同数值求解。
