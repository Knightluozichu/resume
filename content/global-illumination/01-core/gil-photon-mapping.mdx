## 直觉引入

想象你往房间里撒一把发光的沙子。每粒沙子代表一个光子，从光源出发，在场景中弹射，最终停在某个表面上。沙子密集的地方亮，稀疏的地方暗。这就是光子映射——从光源正向追踪光子，统计表面上的光子密度来估算光照。

光子映射擅长路径追踪不擅长的焦散——因为光子从光源出发经过镜面是自然的路径，而从相机反向追踪到镜面再到光源很难。

## 代码对照

```cpp
// 光子映射两遍算法
// Pass 1: 光子追踪
void TracePhotons(Scene scene, int numPhotons) {
    for (int i = 0; i < numPhotons; i++) {
        Ray ray = light.EmitPhoton();
        TracePhoton(ray, scene);  // 弹射并存入photonMap
    }
    photonMap.BuildKDTree();
}

// Pass 2: 渲染（辐射度估计）
Spectrum EstimateRadiance(Point p, Vector n) {
    auto photons = photonMap.NearestNeighbors(p, N, radius);
    Spectrum flux(0);
    for (auto &ph : photons)
        flux += ph.flux * BRDF(ph.dir, n);
    return flux / (PI * radius * radius);  // 密度估计
}
```

## 常见误区

<Callout type="trap">
**误区：认为光子映射是无偏的。**
光子映射是有偏的——辐射度估计用有限半径的圆盘近似点密度，引入系统性模糊（偏差）。但它是「一致的」——光子数趋于无穷且半径趋于零时收敛到正确值。有偏但一致在实践中可接受。
</Callout>

<Callout type="trap">
**误区：认为光子映射可以完全替代路径追踪。**
光子映射擅长焦散和漫反射间接光，但不擅长直接光照（用NEE更高效）和镜面反射（delta分布无法用密度估计）。实际中通常混合使用：路径追踪处理直接光和镜面，光子映射处理焦散和漫反射间接光。
</Callout>

<Exercises>
**问题 1**：光子映射的两遍算法流程是什么？

<Answer>
有偏性来自辐射度估计——用有限半径r的圆盘上的光子密度近似点的光子密度。这相当于低通滤波，引入系统性模糊。半径r越大模糊越严重（偏差越大），但方差越小（噪声越少）。一致性保证：当光子数N→无穷且半径r→0时，偏差→0，收敛到正确值。这需要N的增长比r的缩小快（如r ∝ 1/sqrt(N)）。
</Answer>

**问题 2**：渐进式光子映射(PPM)如何解决传统光子映射的内存问题？

<Answer>
传统光子映射需要存储数百万光子在kd-tree中，内存消耗巨大。PPM不存储所有光子，而是：1)从相机发射光线确定交点；2)每遍迭代发射少量光子，在固定交点上累积命中光子的能量；3)每遍迭代后缩小搜索半径r（r_new = r_old * (N+alpha)/(N+1)）；4)半径趋近零时收敛到无偏结果。PPM只需存储交点的累积统计量（几个浮点数），不需存储光子贴图，内存消耗与光子数无关。
</Answer>
