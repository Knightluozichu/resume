## 直觉：不是把场景切成方块就结束了

先预测：若把一个大墙面均匀切成一万个 patch，是否一定比自适应切成一千个 patch 更准？不一定。阴影边界与强能量梯度需要细分，平坦远场不需要；均匀细分还会把 form-factor 数量推到 $O(n^2)$。随机辐射度的目标正是避免预先精确计算整张传输矩阵，同时把样本花在重要交换上。

第 6 章 Stochastic Radiosity 先以 classical radiosity 建立 diffuse finite-element 基线，再用 stochastic relaxation、random walk 和 photon density estimation 随机估计 transfer。Hierarchical refinement 与 clustering 控制空间离散和交互数量；附录 C 再分析 stochastic relaxation radiosity 的期望、variance 与稳定条件。


## 经典辐射度方程

对 Lambertian surface，出射 radiance 与方向无关，可用 $B(x)$ 表示。连续方程为 emission 与反射 irradiance 之和。用 piecewise-constant basis 把表面分成 patches，得到：

$$
B_i=E_i+\rho_i\sum_{j=1}^{n}F_{ij}B_j,
\qquad (I-RF)B=E.
$$

$B_i$、$E_i$ 单位为 $\mathrm{W/m^2}$，$\rho_i$ 无量纲。这里约定 $F_{ij}$ 是从 receiver $i$ 看 source $j$ 的 transfer fraction；不同文献可能交换下标，因此实现必须用 reciprocity test 固定 convention。

（form factor）双面积分为：

$$
F_{ij}=\frac{1}{A_i}\int_{A_i}\int_{A_j}
\frac{V(x,y)\cos\theta_x\cos\theta_y}{\pi\|x-y\|^2},dA_y,dA_x.
$$

它满足 $A_iF_{ij}=A_jF_{ji}$（reciprocity），封闭环境中行和应接近 1，开放环境缺失部分对应逃逸能量。Hemicube、ray casting 与 Monte Carlo area/direction sampling 都可估计 $F$，但分辨率、遮挡和近场 singular behavior 不同。

## 为什么随机化 form-factor 计算

显式构造 $n\times n$ 的 $F$ 矩阵需要大量 visibility query 与存储。对固定 receiver $i$，反射项 $S_i=\sum_jF_{ij}B_j$ 可通过 $J\sim p_{ij}$ 估计：

$$
\widehat S_i=\frac{F_{iJ}B_J}{p_{iJ}},
\qquad
\operatorname{Var}[\widehat S_i]=\sum_j\frac{(F_{ij}B_j)^2}{p_{ij}}-S_i^2.
$$

最优离散 proposal 与 $|F_{ij}B_j|$ 成比例。实际可按 solid angle、unshot power、coarse hierarchy 或 mixture 近似，并保留小的全支持分量。Uniform patch index 往往极差，因为 patch area 与 transfer 相差数个数量级。


## Stochastic relaxation：随机更新线性系统

（stochastic relaxation radiosity）可采取 gathering 或 shooting。Gathering 为 receiver 随机采 source 并估计 incoming sum；shooting 选择具有 unshot energy 的 source，将随机 transfer 样本分配给 receiver。

设线性 fixed point 为 $B=E+AB$，随机算子 $\widehat A_k$ 满足 $\mathbb E[\widehat A_k\mid B^k]=A$。带 relaxation 的更新可写为：

$$
B^{k+1}=(1-\alpha_k)B^k+\alpha_k(E+\widehat A_kB^k).
$$

条件期望指向确定性 fixed-point step，但这不自动保证单条随机序列收敛。需要 transfer operator 稳定（通常 spectral radius $\rho(A)<1$）、二阶矩有限、每个有效 interaction 被持续采样，以及 step-size/averaging 满足相应随机近似条件。固定大步长可能在正确均值附近保持噪声而不逐点静止。

Southwell-style shooting 优先选择最大 unshot power，可快速传播强光；随机选择 source 时用 selection PMF 补权。每次更新都应守恒：source 发出的估计功率、receiver 接收功率和逃逸功率能对账。

## Random walk 与 Neumann series

（random walk）利用：

$$
B=(I-RF)^{-1}E=\sum_{k=0}^{\infty}(RF)^kE.
$$

从 emitter patch 按 emitted power 选起点，按 form-factor distribution 选择下一 patch，乘 reflectance 后继续。Absorption 或 Russian roulette 终止 walk。它与 path tracing 都估计 Neumann series，但 state 被离散为 diffuse surface patches，measurement/reconstruction 也不同。

Collision estimator 在到达 patch 时累计，absorption estimator 在终止处累计，next-event estimator 可显式连接目标 patch/observer。选择不同 tally 会改变 variance，不改变目标系统。Random walk 尤其适合 sparse stochastic transfer，不需要保存所有 $F_{ij}$。

## Photon density estimation 在辐射度中的角色

（photon density estimation）从 emitter 追踪 diffuse bounces，把 hit position 与 carried power 存储。对位置 $x$，面积 kernel 半径 $h$ 下可估计：

$$
\widehat E_h(x)=\frac{1}{Nh^2}\sum_{k=1}^{N}
K\!\left(\frac{\|x-X_k\|}{h}\right)\Phi_k.
$$

固定 $h$ 会平滑 visibility/geometry 变化并有 bias；$h$ 太小又使 neighbor count 低、variance 大。一致性要求 $h\to0$ 且 $Nh^2\to\infty$（二维表面上的典型条件）。边界附近核支持被截断，还需 boundary correction 或拒绝跨不连续面的邻居。

第 7 章 photon mapping 会更深入 kd-tree、caustic/global map 与 final gathering；本页只说明 density estimation 如何成为 stochastic radiosity 的一种能量重建方式。

## Hierarchical refinement 与 clustering


减少 basis/discretization bias。误差指示器可以比较 parent/child transfer、估计 irradiance gradient 或 visibility variance；只按几何三角形大小细分会错过小光源投影和阴影边界。

Clustering 把远距离的一组 patches/objects 聚合成 cluster interaction，类似以界限决定“一对多”是否足够平滑；近场或遮挡复杂处再展开。目标是将显式 pair interactions 从 $O(n^2)$ 降到近线性或 $O(n\log n)$ 的可控集合。聚类近似引入额外 bias，必须与 stochastic variance 分开报告。

Progressive refinement 可边求解边细分，但 coarse solution 向 child 投影时要守恒。若网格改变后仍复用旧 form-factor samples，必须重解释 sample measure 或重新采样，避免面积/Jacobian 不一致。

## 附录 C：variance analysis 的验收口径

不能只计算某一步的 sample variance。附录 C 关注 stochastic relaxation 的理论行为：随机 transfer noise 会被后续 $A$ 反复传播；高 reflectance/封闭场景使 spectral radius 接近 1，低频误差衰减慢；差的 proposal 产生重尾更新，使有限二阶矩假设失效。

实践中至少记录：每轮 residual norm、总能量 balance、多随机 seed 的 patch mean/variance、variance 随 sample count 的斜率，以及 hierarchy level/kernel radius。若 mean 正确但 variance 不降，检查 step size 与相关样本；若 mean 漂移，检查 PDF、reciprocity、visibility 或能量补权。

## 最小随机 gather 实现

```cpp
for (int i = 0; i < patchCount; ++i) {
    auto [j, pSelect] = transferSampler.sampleSource(i, rng.next());
    float Fij = estimateFormFactor(i, j, rng.next2D());
    float incoming = Fij * B[j] / pSelect;
    estimate[i].add(E[i] + rho[i] * incoming);
}

// 每批独立样本后再做 relaxation / averaging，
// 并单独保存 mean、variance、residual 与 energy balance。
```

`estimateFormFactor` 若内部也随机采点/方向，其条件 PDF 必须继续进入权重；外层 patch PMF 不能替代内层 area/solid-angle PDF。
