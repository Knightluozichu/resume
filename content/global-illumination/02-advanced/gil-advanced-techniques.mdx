## 直觉引入

想象你在黑暗中找钥匙。随机摸索（路径追踪）可能很久找不到。但如果你找到过一次，就知道大概位置，下次在附近找（MLT变异）。或者你记得客厅灯开关的位置，直接去摸（辐照度缓存）。又或者你在钥匙可能多的地方多摸几把（自适应采样）。

高级GI技术就是这些「聪明策略」——MLT在找到好路径后局部探索，辐照度缓存复用已有结果，自适应采样把预算花在刀刃上。现代渲染器不是用一种方法，而是组合多种取长补短。

## 代码对照

```cpp
// 混合渲染器架构
Spectrum Li(Ray ray, Scene scene) {
    Spectrum L(0);
    SurfaceInteraction si = scene.Intersect(ray);
    
    // 1. 直接光: NEE + MIS
    L += estimateDirectNEE(si, scene);
    
    // 2. 漫反射间接: 辐照度缓存
    if (si.bsdf->isDiffuse()) {
        if (cache.isValid(si))
            L += cache.interpolate(si);  // 有偏但快
        else {
            Spectrum irr = pathTraceDiffuse(si);
            cache.add(si, irr);  // 计算并缓存
            L += irr;
        }
    }
    
    // 3. 焦散: 光子映射
    L += photonMap.estimateCaustics(si);
    
    // 4. 光泽间接: 路径追踪
    if (si.bsdf->isGlossy())
        L += pathTraceGlossy(si);
    
    return L;
}
```

## 常见误区

<Callout type="trap">
**误区：认为MLT是万能的。**
辐照度缓存的插值假设间接光空间平滑，但在几何突变处（如角落、边缘）失效，导致漏光或漏暗。需要梯度引导的插值和遮挡检测。
</Callout>

<Callout type="trap">
**误区：辐照度缓存总是安全的。**
辐照度缓存的插值假设间接光在空间上平滑变化。但在几何突变处（角落、门框边缘）间接光变化剧烈，插值会导致漏光或暗斑。好的实现需要遮挡检测和梯度引导插值，在平滑区域用缓存，在突变区域回退到完整计算。
</Callout>

<Exercises>
**问题 1**：MLT的工作原理是什么？它解决了路径追踪的什么问题？

<Answer>
因为不同GI技术各有擅长：路径追踪通用但焦散差，光子映射擅长焦散但直接光差，辐照度缓存快但只适合漫反射，MLT擅长困难光路但收敛不均。混合渲染器按场景特征分工：直接光用NEE+MIS（高效无噪声），漫反射间接光用辐照度缓存（插值快10-100倍），焦散用光子映射（正向追踪天然处理），光泽间接光用路径追踪（BRDF采样高效），困难光路用MLT补充。每种技术只做自己擅长的部分，整体效率和质量远超单一方法。
</Answer>

**问题 2**：为什么现代渲染器混合多种GI技术？举例说明各技术的分工。

<Answer>
不同GI技术各有擅长和短板。混合渲染器按场景特征分工：1)直接光用NEE+MIS——高效无噪声；2)漫反射间接用辐照度缓存——插值快10-100倍；3)焦散用光子映射——正向追踪天然处理；4)光泽间接用路径追踪——BRDF采样高效；5)困难光路用MLT补充——局部探索高效。每种技术只做擅长的部分，整体效率和质量远超单一方法。代价是系统复杂度增加——需要管理多种算法的接口和数据结构。
</Answer>
