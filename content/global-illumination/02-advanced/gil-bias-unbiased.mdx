## 直觉：同一方程为什么需要很多算法

先预测：一个小光源经镜面反射后照到 diffuse 墙面，再进入相机的 `L S D E` 路径，为什么普通 camera path tracing 很难，而 light tracing 或 bidirectional connection 更容易？答案不在渲染方程是否正确，而在算法从哪一端生成随机决策，以及其 PDF 是否覆盖高贡献路径。

第 4 章 Strategies for Computing Light Transport 位于概率工具和具体算法之间。它不只是讨论“有偏还是无偏”，而是建立统一分类语言：radiance 从 emitter 传播，importance 从 measurement 传播；local scattering 由广义核表示；最终测量可以写成方向/表面积分，也可以展开成 path space 上不同长度路径的积分。算法只是选择其中哪些变量、从哪一端、以何种分布采样或离散。


## 正向辐亮度方程

把表面位置与方向组成 phase-space 状态，用 $L_e$ 表示 emission，$\mathcal K$ 表示“一次传播 + 一次散射”的线性算子，radiance equation 可写为：

$$
L=L_e+\mathcal K L,
\qquad L=(I-\mathcal K)^{-1}L_e.
$$

若能量守恒且系统稳定，逆算子可展开为 $L=\sum_{k=0}^{\infty}\mathcal K^kL_e$。第 $k$ 项对应包含 $k$ 次散射的 transport。Path tracing 是对这些项的随机估计；radiosity 是选择表面基函数后对算子的有限维近似；二者不是不同物理。

（GRDF, generalized reflectance distribution function）用于抽象 local scattering。普通 BRDF 只处理同侧反射方向；广义形式可把 reflection/transmission 以及 delta event 纳入统一状态空间。实现时仍必须明确连续 solid-angle density 与离散 delta probability，不能把所有事件都当普通浮点 PDF。

## 重要度伴随方程

（importance function）从 sensor emission $W_e$ 出发，通过伴随算子 $\mathcal K^*$ 传播：

$$
W=W_e+\mathcal K^*W.
$$

这就是（adjoint equation）。伴随不是简单把 ray 方向取反；它要求在选定内积和 measure 下满足 $\langle W,\mathcal K L\rangle=\langle\mathcal K^*W,L\rangle$。对 reciprocal scattering，正反局部核常有对称关系，但 sensor response、emitter distribution 与非互易材料仍需分别处理。

测量可以从任一端计算：

$$
M=\langle W_e,L\rangle=\langle W,L_e\rangle.
$$

Camera tracing 从 $W_e$ 支持集开始，沿 importance 方向寻找 emission；light tracing 从 $L_e$ 支持集开始，沿 radiance 方向寻找 sensor；bidirectional 方法同时生成两端 subpath 并连接。这个对偶解释了不同策略为何对不同 path family 有完全不同的方差。

## 从积分方程到路径表述

（path formulation）令路径 $\bar x=(x_0,\ldots,x_k)$ 从 emitter 到 sensor。简化的路径贡献可写为：

$$
f(\bar x)=L_e(x_0\!\to x_1)
\left[\prod_{i=1}^{k-1} f_s(x_{i-1}\!\to x_i\!\to x_{i+1})G(x_i,x_{i+1})V(x_i,x_{i+1})\right]
W_e(x_{k-1}\!\to x_k).
$$

$G$ 包含两端 cosine 与 inverse-square distance，$V$ 是 visibility，$f_s$ 是 GRDF/BSDF。完整测量是对所有 $k$ 的路径流形积分。表面面积与方向两种参数化之间要用 geometry Jacobian 转换；否则连接策略的 PDF 无法在同一 measure 下比较。

路径表示使“困难路径”可精确定义：策略是否能生成它？联合 PDF 多大？delta constraint 是否使某种连接概率为零？哪些顶点可重采样、缓存或 density estimate？这比按“实时/离线”或“新/旧”分类更有解释力。

## 光传输策略矩阵

（light transport strategy）至少包含 endpoint、state representation、sampling/solver、estimator 和 reconstruction 五项。


**Camera path tracing** 天然只生成到达 sensor 的路径，不浪费在不可见区域，但从 diffuse 顶点随机命中小 emitter 或经 specular chain 找 caustic 的概率低。**Light tracing** 能从小光源高效分发能量，却很难随机命中 pinhole sensor，通常要显式连接 sensor。**Bidirectional tracing** 连接两个 subpath，覆盖更多 path family，但连接数、PDF bookkeeping 与 delta compatibility 更复杂。

**Finite-element/radiosity** 选择空间 basis 并求解系数，适合 diffuse transport 和重用；**density estimation** 在空间邻域聚合 photon，改变了重建域；**caching/interpolation** 在平滑假设成立处复用 indirect illumination。后续章节的算法都能放回这张矩阵，而不只是罗列名字。

## 偏差、方差、一致性与工作量


为 $b_N=\mathbb E[\widehat I_N]-I$。Mean squared error 分解为：

$$
\operatorname{MSE}(\widehat I_N)=\operatorname{Var}(\widehat I_N)+b_N^2.
$$

Unbiased 只表示 $b_N=0$。Consistent 表示当预算与相关参数按规定增长时，$\widehat I_N\to I$；有偏估计器也可一致。Photon density estimation 需要 photon 数增加同时 kernel radius 收缩；固定半径只增加光子会收敛到模糊解。Irradiance cache 是否一致则取决于 record spacing/error threshold 是否随预算收紧，不能一概断言“永远不一致”。

无偏也不自动保证低 MSE。普通 path tracing 对 caustic 可能有极高 variance；适当的有偏 density estimate 在固定时间更准确。另一方面，denoiser 或 clamp 引入的 bias 可能抹去小而真实的高频能量。策略报告应给出 bias proxy、sample variance、work-normalized error、memory 和 temporal stability。

## 算法分类的执行口径

对一个具体 integrator，逐项回答：

1. **Transport direction**：radiance、importance，还是双向；
2. **State domain**：surface point/direction、path vertex、finite element、photon density 或 cache record；
3. **Generation**：random walk、deterministic quadrature、matrix solve、mutation 或 connection；
4. **Estimator**：sample contribution 与联合 PDF 如何配对，是否 MIS；
5. **Reconstruction**：像素平均、kernel density、basis expansion 或 interpolation；
6. **Limits**：delta path、参与介质、动态场景、memory 与 preprocessing 如何处理。

这套分类会直接暴露重复计数。例如 camera subpath 与 light subpath 的多个连接策略都能生成同一 full path 时，每个 estimator 都要知道所有竞争策略的 path-space density，并用合法权重使权重和为 1。

## 最小路径贡献记录

```cpp
struct PathVertex {
    Point p;
    Normal n;
    Spectrum throughput;
    float pdfForwardArea;
    float pdfReverseArea;
    EventType event; // diffuse, glossy, delta, medium, endpoint
};

Contribution connect(const PathVertex& light, const PathVertex& camera) {
    if (!compatible(light, camera) || !visible(light.p, camera.p)) return {};
    auto value = light.throughput * scatter(light, camera)
               * geometry(light, camera) * scatter(camera, light)
               * camera.throughput;
    return {value, pathSpaceMisWeight(light, camera)};
}
```

Forward/reverse area PDF 是连接和 MIS 的证据，不是可选调试字段。若某顶点是 delta event，普通面积 density 可能不存在，`compatible` 必须阻止不合法连接。

## 小结

第 4 章把后续算法放进同一坐标系：radiance equation 正向传播能量，importance adjoint equation 反向传播测量敏感度，GRDF 统一局部散射，path formulation 把测量展开成各长度路径积分。光传输策略由生成端、状态域、连接、估计与重建共同定义，并必须以 bias、variance、consistency 和 work 四维验收。
