## 原书单元与独立机制解释

### Stochastic Path-Tracing Algorithms

stochastic path tracing 从传感器逐次采样散射，direct illumination 通常用显式光源连接降低噪声，indirect illumination 则来自后续反弹。吞吐量必须累计BRDF、余弦、PDF和终止概率。

本单元的正式坐标是stochastic path tracing、direct illumination、indirect illumination。验证Stochastic Path-Tracing Algorithms时，先制造“显式光源采样与BSDF路径重复计数，或俄罗斯轮盘后不补偿存活概率”，再检查路径顶点、吞吐量、每步PDF、直接项和终止事件能否把错误定位到沿随机路径同时估计直接与间接光的首个分叉。

$$
\beta_{k+1}=\beta_k\frac{f_r|n\cdot\omega|}{p(\omega)}
$$

## 最小可重现实验

```cpp
Spectrum beta(1), L(0);
for (int bounce = 0; bounce < maxDepth; ++bounce) {
  Hit h = intersect(ray);
  L += beta * sample_direct_light(h);
  auto s = h.bsdf.sample(rng);
  beta *= s.f * abs_dot(h.n, s.wi) / s.pdf;
  ray = Ray(h.p, s.wi);
}
```

运行Stochastic Path-Tracing Algorithms时固定随机种子、输入几何、坐标约定和数值精度；记录编译命令或算法版本、输出摘要与失败条件。实验输出若依赖隐藏全局状态，必须先消除该依赖再比较。

<Callout type="trap" title="本页核心误区">
  显式光源采样与BSDF路径重复计数，或俄罗斯轮盘后不补偿存活概率。这个错误会破坏“Stochastic Path-Tracing Algorithms的输入、公式中间量、输出与恢复结果可用同一基线复算”，应先由路径顶点、吞吐量、每步PDF、直接项和终止事件定位，再讨论性能或视觉风格。
</Callout>
