## 从一个会失败的图像实验开始

Stochastic Radiosity要回答的不是“这个名词是什么”，而是：在固定输入下，如何验证“用随机松弛或随机游走求解漫反射面片能量”，并让一个反例可重复地推翻错误实现？先写下预期像素、几何或估计量，再运行基线；只要面片面积、F矩阵、残差、随机路径权重和能量和无法指出差异来自哪一步，图像看起来正确也不能通过。

本页的不变量是：Stochastic Radiosity的输入、公式中间量、输出与恢复结果可用同一基线复算。反例“形状因子行和超出物理范围，或随机游走权重与转移概率不匹配”只改变一个条件，因而正常、故障与恢复三次运行应能用同一输入直接比较。

## 原书单元与独立机制解释

### Stochastic Radiosity

stochastic radiosity 把漫反射传输系统转成随机迭代，form factor 描述面片间几何耦合，random walk 在面片图上传播能量。收敛判断应基于残差或独立批次，而非仅看图像变亮。

本单元的正式坐标是stochastic radiosity、form factor、random walk。验证Stochastic Radiosity时，先制造“形状因子行和超出物理范围，或随机游走权重与转移概率不匹配”，再检查面片面积、F矩阵、残差、随机路径权重和能量和能否把错误定位到用随机松弛或随机游走求解漫反射面片能量的首个分叉。

$$
B=E+RFB,\qquad B=\sum_{k=0}^{\infty}(RF)^kE
$$

## 最小可重现实验

```cpp
Vector B = emission;
for (int iteration = 0; iteration < maxIterations; ++iteration) {
  int i = sample_patch(rng);
  double residual = emission[i] + reflectance[i]*dot(F.row(i), B) - B[i];
  B[i] += relaxation * residual / patch_probability(i);
}
```

运行Stochastic Radiosity时固定随机种子、输入几何、坐标约定和数值精度；记录编译命令或算法版本、输出摘要与失败条件。实验输出若依赖隐藏全局状态，必须先消除该依赖再比较。

<Callout type="trap" title="本页核心误区">
  形状因子行和超出物理范围，或随机游走权重与转移概率不匹配。这个错误会破坏“Stochastic Radiosity的输入、公式中间量、输出与恢复结果可用同一基线复算”，应先由面片面积、F矩阵、残差、随机路径权重和能量和定位，再讨论性能或视觉风格。
</Callout>

<Callout type="trap" title="不要把别的图形API模板套进来">
  Stochastic Radiosity只解释用随机松弛或随机游走求解漫反射面片能量。若原始资料讨论纯C++路径追踪、OpenGL时代图形学或光传输积分，就不能用VkBuffer、Fence与Semaphore替代相应的几何、光栅化或蒙特卡洛机制。
</Callout>

## 练习与答案

<Exercises>

**问题 1：公式与边界。** 怎样用一个数值样本证明 $B=E+RFB,\qquad B=\sum_{k=0}^{\infty}(RF)^kE$ 中的量没有混用空间、单位或概率密度？

<Answer>
  先写出每个量的定义域与单位，选择能手算的输入，分别计算中间量和最终结果；再只扰动一个量。若面片面积、F矩阵、残差、随机路径权重和能量和的变化方向与公式不一致，应拒绝实现而不是调整截图。
</Answer>

**问题 2：正式坐标。** stochastic radiosity、form factor、random walk如何进入可操作验证？

<Answer>
  1. **stochastic radiosity**：在专属实验中选中该节点，保存输入与面片面积、F矩阵、残差、随机路径权重和能量和，注入“形状因子行和超出物理范围，或随机游走权重与转移概率不匹配”后恢复并重放。
  2. **form factor**：在专属实验中选中该节点，保存输入与面片面积、F矩阵、残差、随机路径权重和能量和，注入“形状因子行和超出物理范围，或随机游走权重与转移概率不匹配”后恢复并重放。
  3. **random walk**：在专属实验中选中该节点，保存输入与面片面积、F矩阵、残差、随机路径权重和能量和，注入“形状因子行和超出物理范围，或随机游走权重与转移概率不匹配”后恢复并重放。
</Answer>

**问题 3：故障恢复。** 如何证明“形状因子行和超出物理范围，或随机游走权重与转移概率不匹配”已经真正修复？

<Answer>
  保存正常基线，注入故障并标记面片面积、F矩阵、残差、随机路径权重和能量和中的首个分叉；撤销故障后以完全相同输入重放。只有Stochastic Radiosity的输入、公式中间量、输出与恢复结果可用同一基线复算重新成立、结果可复现且实验重置回初值，修复才可交接。
</Answer>

</Exercises>

## 本章回顾
