先预测：一张图出现墙角漏光，最先应该增加 SPP、缩小 photon radius、细化 radiosity mesh，还是失效 irradiance cache？没有上下文无法回答。必须先知道贡献由哪个 estimator 生成、存储在哪个 domain、以什么 kernel/validity 重建，再选择实验。

## 统一方法选择矩阵

<GilMethodSelectionDiagram />

选择方法的顺序应是：先识别 dominant path family 与 scene dynamics；再确定 state representation 与 estimator support；然后比较 work-normalized error；最后才考虑工程实现。常见组合示例：

1. **Diffuse static architecture**：hierarchical/stochastic radiosity 或 PRT/cache，重点验收 basis/visibility 与 invalidation；
2. **General dynamic scene**：camera path + NEE/MIS，必要时 BDPT，重点验收 path PDF 与 variance；
3. **Strong caustic**：caustic photon density、BDPT/MLT，重点验收 kernel bias 或 chain mixing；
4. **Participating medium**：volume path sampling，重点验收 transmittance/free-flight/phase PDFs；
5. **Interactive fixed geometry lighting**：PRT/VPL/lightcuts，重点验收 representation frequency、bounds 和 update scope。

方法不是互斥标签。组合时必须用 path partition、MIS 或 proposal/control-variate relation说明责任，不能凭经验把输出相加。

## 从症状回到根因

<GilFailureDiagnosisDiagram />

<Term def="随路径或像素输出生成的中间证据层，如 throughput、PDF、path length、visibility、neighbor count、radius、cache validity 和 energy sum">传输诊断层</Term>让最终图像可解释。最低集合包括：

- direct/emission/indirect/caustic/medium component AOV；
- path event sequence 与 per-vertex forward/reverse PDF；
- throughput magnitude、roulette survival 和 MIS weight sum；
- photon/cache/VPL neighbor count、radius、validity/bound；
- linear energy totals、sample mean/variance、runtime/memory；
- tone-map 前后 luminance 与 clipped pixels。

调试实验一次只改变一个维度。亮度随 sampler 改变，先查 PDF/measure；噪声随 samples 不按预期下降，查 heavy tail/correlation；漏光随 radius/cache threshold 改变，查 reconstruction boundary；动态拖影查 invalidation/history；只有显示图错而 HDR 对，查 exposure/tone/color encoding。

## 一套完整验收场景

最小 suite 不追求艺术性，而要隔离 path family：

1. Constant environment + Lambertian plane：PDF/cosine/rotation；
2. Two-patch enclosure：form factor/reciprocity/matrix energy；
3. Cornell box：diffuse multi-bounce/color transfer；
4. Small area light + glossy/delta object：NEE/MIS/specular support；
5. Glass caustic：photon/BDPT/MLT difficult paths；
6. Thin wall/doorway：cache/kernel/cluster boundary；
7. Homogeneous fog：transmittance/single/multiple scattering；
8. Subsurface slab：entry-exit distance/scale；
9. Rotating HDR environment on static object：PRT basis/runtime；
10. HDR chart/display sweep：exposure/tone/color encoding。

每个场景固定 unit scale、spectral/RGB convention、seed/budget 和 reference；否则不同算法比较的不是同一目标。

## 常见误区

<Callout type="trap">
**现象 →** 用“弹射次数”一条线总结全书。**原因 →** 丢失 measurement/importance、state representation、adjoint/path strategy、media/perception 与实现理论。**修法 →** 按 12 单元逐项复述并用统一 transport chain 连接。
</Callout>

<Callout type="trap">
**现象 →** 根据“路径追踪无偏、光子映射有偏”直接选算法。**原因 →** 忽略有限预算 variance、path support、consistency schedule 与 lifecycle。**修法 →** 比较 work-normalized MSE、dominant paths 和动态更新约束。
</Callout>

<Callout type="trap">
**现象 →** 最终图片相似就宣称方法正确。**原因 →** tone map 与多种误差可能互相抵消。**修法 →** 检查 linear reference、energy、path/PDF AOV 和参数扫描，再固定显示变换。
</Callout>

## 练习

<Exercises>

**问题 1：为什么“直接光一次弹射、间接光多次弹射”不足以作为全书总纲？**

<Answer>
它无法表达 measurement/importance 对偶、solid-angle/path measure、Monte Carlo estimator、finite-element/density representation、hybrid overlap、media/subsurface 的额外维度、PRT lifecycle 和 tone/perception。弹射次数只能粗略描述一部分 path length。
</Answer>

**问题 2：给定动态博物馆、玻璃焦散和体积雾，怎样设计可审计方案？**

<Answer>
Camera path + NEE/MIS 处理一般动态表面；caustic 用支持 `L-S+-D-E` 的 photon/BDPT/MLT component并明确与 path tracer 分区；雾用 free-flight/transmittance/phase sampling。缓存仅用于有可靠 invalidation 的平滑区域。输出 direct/caustic/medium AOV、PDF/path、kernel/variance 和 linear HDR reference。
</Answer>

**问题 3：为什么一个固定 photon radius 的结果可能越来越平滑却不越来越正确？**

<Answer>
增加 photons 使该固定邻域内 variance 下降，但 estimate 收敛到 kernel-smoothed field；跨 gradient/boundary 的 bias 不消失。需令 $h_N\to0$ 且邻域样本数仍增长，并处理 surface boundary。
</Answer>

**问题 4：怎样区分 transport 错误与 display 错误？**

<Answer>
先在 scene-linear HDR 中比较 radiance/energy/reference 和 component AOV；若已经错，问题在模型或 estimator。若 HDR 正确而显示错，固定 exposure、tone curve、color space、transfer function 和 display range 逐层比较，检查 clipping/gamma/hue。
</Answer>

</Exercises>

## 小结

第二版的完整能力不是记住几种 GI 名称，而是从真实感图像合成链出发，以 radiometry、hemisphere measure、rendering/measurement/adjoint equations 定义问题；用 Monte Carlo、path formulation、finite element、density 和 hybrid state 求解；再把 media、subsurface、PRT、display/perception 与 unresolved issues 纳入同一证据体系。最终验收必须同时证明 12 单元覆盖、方法选择逻辑、失败诊断、linear reference 和资源生命周期。
