## 直觉引入

想象一束阳光从窗户射入。它直接照亮地板（直接光），地板反射的光照亮墙壁（一次间接光），墙壁再反射照亮天花板（二次间接光）……每一次弹射都是GI的一个层次。

全书就是沿着这束光的弹射旅程展开：直接光是起点，间接光是核心，辐射度/路径追踪/光子映射是不同求解策略，重要性采样/有偏无偏是优化理论，实时GI是工程目标。总复习就是把这条光的旅程完整走一遍。

## 代码对照

```cpp
// GI 全景：从概念到工程
Spectrum FullGI(Ray ray, Scene scene) {
    // 1. 直接光 (NEE + MIS)
    Spectrum L_direct = estimateDirectNEE_MIS(si, scene);
    
    // 2. 间接光 (按材质选择方法)
    Spectrum L_indirect(0);
    if (si.isDiffuse)
        L_indirect = irradianceCache.interpolate(si);  // 缓存加速
    else if (si.isCaustic)
        L_indirect = photonMap.estimate(si);  // 光子映射
    else
        L_indirect = pathTrace(si);  // 路径追踪
    
    // 3. 组合
    Spectrum L = L_direct + L_indirect;
    
    // 4. 降噪 (实时)
    if (realtime) L = SVGF_denoise(L);
    
    return L;  // 直接光 + 间接光 = 全局光照
}
```

## 常见误区

<Callout type="trap">
**误区：孤立学习各章不串联。**
GI的核心是权衡——精度vs速度、无偏vs有偏、通用vs专用。不理解权衡就无法选择方法。
</Callout>

<Callout type="trap">
**误区：只学方法不学权衡。**
GI每种方法都有代价：路径追踪无偏但慢，光子映射快但偏，辐照度缓存更快但更偏。不理解这些权衡就无法在工程中做选择。学方法要同时学它的「适用条件」和「失效条件」。
</Callout>

<Exercises>
**问题 1**：用光的弹射次数串联全书四大板块。

<Answer>
1)直接与间接光：0-1次弹射（直接光）vs 2+次弹射（间接光），建立GI基本概念。2)离线GI方法：辐射度用矩阵求解所有弹射（漫反射），路径追踪用随机游走递归弹射（通用），光子映射用正向追踪弹射（焦散）。3)采样理论：重要性采样让每次弹射的采样更高效，有偏无偏决定弹射估计的性质，MIS组合不同弹射方向的采样。4)实时GI：在毫秒内近似所有弹射（RSM一次弹射，LPV多弹射低精度，降噪处理低采样噪声）。
</Answer>

**问题 2**：给定一个有玻璃窗(焦散)、红砖墙(色渗透)、金属雕塑(光泽反射)的博物馆场景，设计完整的GI方案。

<Answer>
1)直接光：NEE+MIS处理所有光源，保证硬阴影和直接照明质量。2)玻璃焦散：光子映射——从光源正向追踪光子经玻璃聚焦到地面，密度估计计算焦散图案。3)红砖墙色渗透：路径追踪或辐照度缓存——红墙反射红光照到邻近白色展品表面，漫反射间接光用缓存插值加速。4)金属雕塑光泽反射：路径追踪BRDF采样——Cook-Torrance重要性采样高效处理镜面反射方向。5)多弹射环境光：辐照度缓存——多次弹射后的环境光在空间上平滑，用稀疏点缓存插值。6)自适应采样：焦散区域和阴影边缘增加采样，纯色墙面减少采样。7)如果实时：1spp路径追踪+SVGF降噪，或RSM+LPV组合。整体：直接光NEE，焦散PM，漫反射IC，光泽PT，自适应分配，降噪后处理——混合架构取长补短。
</Answer>
</Exercises>
