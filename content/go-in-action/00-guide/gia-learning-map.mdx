## 从十个主题页的错位开始

先预测：把Channel拆成独立章节、把包管理与测试合成一页，能否还原原书？不能。官方第一版只有9章：Go语言介绍、Go快速入门、包与工具、数组切片和映射、类型系统、并发、并发模式、标准库、测试和性能。<Term def="由版本、官方章号、标题和本地页面共同确定的位置。">official chapter coordinate</Term>要求每章有唯一坐标。

## 第1至3章：语言、完整程序与工具

第1章说明开发速度、并发、类型系统与内存管理；第2章直接解剖RSS搜索程序的main、search package、feed与matcher；第3章再解释package、import、init、go tool、协作和依赖。<Term def="从入口、包、外部数据、matcher到输出的端到端执行关系。">search program chain</Term>让语法始终落在真实程序中。

```go
func main() {
    search.Run("golang")
}
```

## 第4至5章：数据表示与类型行为

数组是值，切片是共享底层数组的描述符，map由运行时管理；自定义类型、方法、接口和嵌入再把表示变成行为。<Term def="记录值复制、底层共享、方法集、接口满足和导出范围的模型。">Go value contract</Term>用于解释append别名、pointer receiver和nil interface。

```go
values := []int{1, 2, 3}
copyOfValues := append([]int(nil), values...)
copyOfValues[0] = 9
```

## 第6至7章：并发机制与模式

第6章统一并发并行、goroutine、竞态、锁与channel；第7章用Runner、Pooling和Work解决程序寿命、复用资源和工作池。<Term def="包含启动、通信、同步、超时、关闭和等待的并发生命周期。">concurrency lifecycle contract</Term>禁止只描述“开了几个goroutine”。

```go
jobs := make(chan Job)
go worker(jobs)
close(jobs)
```

## 第8至9章：标准库与验证

标准库用文档源码、log、JSON、Reader与Writer连接包；最后用unit test、httptest、Example和benchmark验证行为与性能。<Term def="由测试语义、失败诊断、输入边界和可重复基准组成的证据。">verification evidence</Term>才是全书出口。

## 掌握门禁

<Term def="先预测结果，再执行固定命令，随后注入边界失败，最后脱离示例解释机制。">four-stage Go gate</Term>要求记录Go版本、命令、race结果、输入输出和退出状态。

<Callout type="trap" title="Go简单，所以可以跳过类型和工具章节">语法小不等于运行时、slice共享、interface nil、包初始化和依赖简单。跳过会把错误推迟到并发与部署。</Callout>
<Callout type="trap" title="Channel是独立于并发章的额外章节">原书把channel与goroutine、竞态和锁放在第6章；脱离共享状态和调度后只背语法，无法选择正确同步工具。</Callout>

## 本章回顾

9章从原因到完整程序，再到构建、数据、类型、并发、模式、标准库与验证。目录坐标、search program chain、value contract、concurrency lifecycle和verification evidence共同形成可回查路线。

<Exercises>
**问题 1：为什么第3章与第9章不能合并？**<Answer>第3章组织源码、包、工具与依赖；第9章验证行为、HTTP、示例和性能。构建边界与证据边界相关但职责不同。</Answer>
**问题 2：并发故障先查哪两章？**<Answer>先查第6章goroutine、race、锁和channel，再查第7章Runner、Pool、Work的超时、归还和关闭。</Answer>
**问题 3：一章何时通过？**<Answer>能预测、固定环境运行、扰动失败边界，并解释最早失效不变量，而不只是复述代码。</Answer>
</Exercises>
