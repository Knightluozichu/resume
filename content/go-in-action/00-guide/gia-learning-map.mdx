## 从十个主题页的错位开始

先预测：把Channel拆成独立章节、把包管理与测试合成一页，能否还原原书？不能。官方第一版只有9章：Go语言介绍、Go快速入门、包与工具、数组切片和映射、类型系统、并发、并发模式、标准库、测试和性能。要求每章有唯一坐标。


## 第1至3章：语言、完整程序与工具

第1章说明开发速度、并发、类型系统与内存管理；第2章直接解剖RSS搜索程序的main、search package、feed与matcher；第3章再解释package、import、init、go tool、协作和依赖。让语法始终落在真实程序中。

```go
func main() {
    search.Run("golang")
}
```

## 第4至5章：数据表示与类型行为

数组是值，切片是共享底层数组的描述符，map由运行时管理；自定义类型、方法、接口和嵌入再把表示变成行为。用于解释append别名、pointer receiver和nil interface。

```go
values := []int{1, 2, 3}
copyOfValues := append([]int(nil), values...)
copyOfValues[0] = 9
```

## 第6至7章：并发机制与模式

第6章统一并发并行、goroutine、竞态、锁与channel；第7章用Runner、Pooling和Work解决程序寿命、复用资源和工作池。禁止只描述“开了几个goroutine”。

```go
jobs := make(chan Job)
go worker(jobs)
close(jobs)
```

## 第8至9章：标准库与验证

标准库用文档源码、log、JSON、Reader与Writer连接包；最后用unit test、httptest、Example和benchmark验证行为与性能。才是全书出口。


## 掌握门禁

要求记录Go版本、命令、race结果、输入输出和退出状态。


## 本章回顾

9章从原因到完整程序，再到构建、数据、类型、并发、模式、标准库与验证。目录坐标、search program chain、value contract、concurrency lifecycle和verification evidence共同形成可回查路线。
