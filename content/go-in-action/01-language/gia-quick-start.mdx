## 从完整程序而不是语法清单开始
先预测：若一个worker网络失败，结果channel是否仍能正常关闭？只有错误、WaitGroup和唯一关闭者协议完整时才可以。

Go快速入门用一个真实搜索器读取feed配置，并发抓取内容，按类型选择matcher，最后显示结果。让每个语法点都有owner和失败位置。


## Main包：装配与进程边界

Main package提供进程入口，解析搜索词、加载配置、调用search并决定日志与退出。不应包含RSS解析细节。

```go
func main() {
    if err := search.Run("golang"); err != nil { log.Fatal(err) }
}
```

## Search包：类型、变量、函数与方法

`Feed`描述源配置，`Result`描述命中，函数负责流程，方法把行为附着到类型。隐藏实现并公开最小API。

```go
type Feed struct { Name, URI, Type string }
type Result struct { Field, Content string }
```

## search.go、feed.go、match.go与default.go

这些文件同属search包：search.go协调，feed.go加载配置，match.go定义接口与注册表，default.go提供fallback。不是四个可独立部署模块。

## RSS Matcher与接口

Matcher接口只声明搜索行为；RSS实现负责XML与内容规则。具体类型隐式满足接口，注册表按feed Type选择。必须处理重复注册和未知类型。

```go
type Matcher interface { Search(Feed, string) ([]Result, error) }
```


## Goroutine、Channel与错误

每个feed可启动goroutine，结果发送到channel；WaitGroup知道生产者何时完成，由单独协调者关闭channel。错误是普通值，不能在worker里静默丢失。防止send on closed channel与永久阻塞。
