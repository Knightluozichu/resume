## 从赋值后是否共享开始
先预测：两个slice赋值后修改一个，另一个是否可见？若仍指向同一底层数组且索引重叠就可见；append迁移后则未必。

数组、切片和映射语法相近，复制语义完全不同。是本章主线。


## 数组内部实现与基础

数组是固定长度连续值，长度属于类型；赋值复制全部元素，函数按值参数也复制。适合固定协议和小值。

```go
a := [3]int{1, 2, 3}
b := a
b[0] = 9
fmt.Println(a[0]) // 1
```

## 声明、初始化、多维与传参

`[...]T`由字面量推导长度，多维数组是数组元素仍为数组。大型数组传参优先指针或slice，但指针表达整个固定布局，slice表达动态视图。

```go
matrix := [2][2]int{{1, 2}, {3, 4}}
```

## Slice内部实现与基础

Slice描述符含pointer、len、cap，多个slice可共享底层数组。要求len不大于cap。

## Nil、空Slice与Append

Nil slice和空slice长度都为0，但与nil比较和JSON编码可能不同。Append容量足够时写共享数组，否则迁移新数组；必须接收返回值。会改变别名关系。

```go
s := make([]int, 0, 1)
s = append(s, 1)
s = append(s, 2)
```


## Map内部实现与基础

Map变量指向运行时哈希结构；nil map可读取零值但写入panic，`make`后可写。要求不能只凭零值判断存在。

## 迭代、删除与函数传递

Map迭代顺序不稳定，`delete`不存在key安全；传参复制轻量header并共享内容。。普通map不支持无同步并发写。


## 验收实验：画出别名关系
准备容量恰好与容量有余两组slice，各自建立子slice后append，再修改新旧索引；记录pointer、len、cap和观察结果。随后测试nil map读取、写入panic、comma-ok、随机迭代和排序输出。目标不是背诵“slice是引用”，而是每次append后重新判断是否共享，并解释函数传参为何复制描述符却共享数据。
