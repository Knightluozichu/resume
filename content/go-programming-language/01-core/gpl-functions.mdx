## 直觉引入

Go 的函数就像乐高积木——标准接口、自由组合。函数可以赋值给变量、作为参数传递、从函数返回。多返回值让错误处理变得自然（返回 result, error）。闭包让函数「记住」外部变量。defer 让资源清理永远在函数退出时执行——即使 panic 也不漏。

## 概念讲解

### 一等公民函数

<Term def="Go 函数是一等公民：可赋值给变量、作为参数传递、从函数返回。支持匿名函数和闭包。">
Go 函数是一等公民（first-class citizen）：

```go
// 赋值给变量
add := func(a, b int) int { return a + b }

// 作为参数（回调）
func apply(f func(int) int, x int) int { return f(x) }

// 作为返回值（工厂函数）
func multiplier(factor int) func(int) int {
    return func(x int) int { return x * factor }
}
```

闭包捕获外部变量：
```go
func counter() func() int {
    count := 0
    return func() int {
        count++ // 捕获外层 count
        return count
    }
}
c := counter()
c() // 1
c() // 2
```

闭包捕获的是变量引用（不是值拷贝），所以多次调用共享同一个 count。
</Term>

### defer 与多返回值

<Term def="defer 延迟执行到函数返回前，LIFO 顺序。用于资源清理。多返回值让 error 作为返回值自然传递。">
**defer** 延迟执行：
```go
func readFile(path string) error {
    f, err := os.Open(path)
    if err != nil { return err }
    defer f.Close() // 函数返回前执行，即使 panic 也执行
    // ... 读取文件 ...
    return nil
}
```

defer 的三个规则：
1. **LIFO 顺序**：多个 defer 后进先出
2. **参数立即求值**：`defer fmt.Println(x)` 中 x 在 defer 语句时求值，不是执行时
3. **可修改命名返回值**：`defer func(){ err = wrap(err) }()` 可修改命名返回值

**多返回值**：
```go
func divide(a, b float64) (float64, error)
val, err := divide(10, 0)
```
Go 用多返回值实现错误处理——error 作为普通返回值，调用者必须处理。命名返回值可作文档，也可在 defer 中修改。
</Term>

## 代码对照

```go
package main

import (
    "fmt"
    "sync"
)

// 多返回值 + 命名返回值
func divide(a, b float64) (result float64, err error) {
    if b == 0 {
        err = fmt.Errorf("division by zero")
        return // 裸 return 返回命名返回值
    }
    result = a / b
    return
}

// 闭包：捕获变量引用
func makeCounter() func() int {
    count := 0
    return func() int {
        count++
        return count
    }
}

// defer LIFO 顺序
func deferOrder() {
    for i := 0; i < 3; i++ {
        defer fmt.Println(i) // 参数立即求值：2,1,0
    }
}

// defer 用于锁释放
func safeUpdate(mu *sync.Mutex, m map[string]int, key string) {
    mu.Lock()
    defer mu.Unlock() // 函数返回时解锁，即使 panic 也执行
    m[key]++
}

// 函数作为参数（函数式编程）
func mapInts(nums []int, f func(int) int) []int {
    result := make([]int, len(nums))
    for i, v := range nums {
        result[i] = f(v)
    }
    return result
}

func main() {
    // 多返回值
    val, err := divide(10, 3)
    fmt.Println(val, err)

    // 闭包
    c := makeCounter()
    fmt.Println(c(), c(), c()) // 1 2 3

    // defer 顺序
    deferOrder() // 输出: 2 1 0

    // 函数作为参数
    doubled := mapInts([]int{1, 2, 3}, func(x int) int { return x * 2 })
    fmt.Println(doubled) // [2 4 6]
}
```

## 常见误区

<Callout type="trap">
**误区：闭包捕获的是变量值**
闭包捕获的是变量引用（地址），不是值拷贝。循环中 `for i := 0; i < 3; i++ { go func() { println(i) }() }` 可能输出 3,3,3——所有闭包共享同一个 i，循环结束时 i=3。修法：`for i := 0; ... { i := i; go func(){ println(i) }() }` 创建局部副本。
</Callout>

<Callout type="trap">
**误区：defer 参数在执行时求值**
defer 的参数在 defer 语句执行时立即求值，不是在函数返回时。`x := 1; defer fmt.Println(x); x = 2` 输出 1（不是 2）。如果要延迟求值，用闭包：`defer func(){ fmt.Println(x) }()` 输出 2。
</Callout>

<Exercises>
**问题 1**：以下代码输出什么？为什么？for i:=0;i<3;i++{ defer fmt.Println(i) }

<Answer>
输出 2 1 0。两个原因：1.defer 参数立即求值——i 在每次 defer 时求值，分别是 0,1,2。2.defer LIFO 顺序——后进先出，所以执行顺序是 2,1,0。如果用 defer func(){ fmt.Println(i) }()，则输出 3,3,3（闭包捕获 i 引用，循环结束 i=3）。
</Answer>

**问题 2**：Go 的多返回值如何实现错误处理？相比异常有什么优缺点？

<Answer>
Go 函数返回 (result, error)，调用者必须处理 err。优点：1.错误处理路径显式清晰——if err != nil 一眼可见。2.无控制流跳跃——不像异常跳过中间逻辑。3.编译器强制——不处理 err 编译不过。缺点：1.代码冗长——大量 if err != nil。2.错误处理分散——每个调用点都要写。Go 团队认为显式优于简洁，这是刻意的哲学选择。
</Answer>

</Exercises>
