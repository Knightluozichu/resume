## REST Web服务

REST以资源、统一接口和表示驱动交互。要求GET安全、PUT与DELETE幂等语义明确，创建通常返回201与Location。


## XML解析与创建

encoding/xml通过导出字段和标签映射元素与属性。要限制输入规模与深度，处理命名空间、未知元素和格式错误，输出前确定编码与Content-Type。

```go
type ThreadXML struct {
    XMLName xml.Name `xml:"thread"`
    ID int `xml:"id,attr"`
    Title string `xml:"title"`
}
```

## JSON解析与创建

encoding/json按字段和标签编码，Decoder适合stream。要求区分缺失与显式零值，必要时DisallowUnknownFields，并确认首个值后没有意外尾随对象。

```go
dec := json.NewDecoder(http.MaxBytesReader(w, r.Body, 1<<20))
dec.DisallowUnknownFields()
if err := dec.Decode(&input); err != nil { http.Error(w, "bad json", 400); return }
```


## 创建Go Web服务

Handler先验证method与Content-Type，再解码DTO、调用用例、映射领域错误，最后编码响应。阻止数据库结构直接成为公开API。

## 状态码与错误表示

错误响应应稳定包含机器码、消息和可关联ID。要求验证失败、未找到、冲突和内部错误不混成200或500。


## 验收实验：同一资源两种表示

为Thread资源实现JSON与XML读取和创建，发送正常、未知字段、超限body、坏XML、尾随JSON、缺失资源和重复创建。保存method、URI、Content-Type、状态、Location和错误body，确保表示变化不改变领域结果。
