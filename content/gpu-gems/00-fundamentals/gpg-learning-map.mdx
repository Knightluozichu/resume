## 直觉：这是一套论文式案例集，不是一条线性教程

GPU Gems 三卷横跨可编程 GPU 早期到 CUDA 出现：第一卷强调自然效果、光影、材质、图像处理和早期 GPGPU；第二卷扩展几何复杂度、高质量渲染、流式架构与数值算法；第三卷加入 geometry shader、GPU 物理和 CUDA 数据并行。

把它压成“水、阴影、Bloom、粒子”会丢失绝大多数原章。正确做法是保留 131 章库存，再以主题页重组学习，同时让每个原章都有明确承载位置和验收证据。

是覆盖验收基线。


先预测：如果一个 GPU Gems 1 案例依赖 fragment shader 把数据写入浮点纹理，它的核心算法今天是否已经失效？先不要用“API 很旧”作答；应把采样域、邻域依赖、迭代顺序和精度要求抽出来，再判断它可否迁移为 compute/image/SSBO 路径。后续每个主题页都用这套判据区分算法寿命与接口寿命。

## 三卷能力演进

### GPU Gems 1：可编程图形管线的效果与方法

第一卷六个 Part 依次是 Natural Effects、Lighting and Shadows、Materials、Image Processing、Performance and Practicalities、Beyond Triangles。其关键贡献既有 water、noise、shadow、BRDF、glow，也包括 pipeline bottleneck、occlusion query、shader integration、fluid、volume rendering 和计算工具箱。

### GPU Gems 2：几何复杂度到 GPGPU 算法

第二卷六个 Part 覆盖 Geometric Complexity、Shading/Lighting/Shadows、High-Quality Rendering、GPGPU Primer、Image-Oriented Computing、Simulation/Numerical Algorithms。它把 geometry clipmap、instancing、deferred shading、filtering 与 reduction、sorting、linear solver、FFT 放到同一 GPU 映射框架中。

### GPU Gems 3：统一着色器、CUDA 与数据并行

第三卷六个 Part 是 Geometry、Light and Shadows、Rendering、Image Effects、Physics Simulation、GPU Computing。geometry shader、deferred rendering、importance sampling、rigid body、N-body、collision、scan 和 CUDA 应用共同展示 GPU 从渲染器走向通用并行处理器。

三卷总数满足：

$$
42+48+41=131.
$$

避免重复点名造成虚假覆盖。

## “复刻核心”不等于照搬旧 API

应被现代复现保留。Cg fragment program、pbuffer、固定纹理单元限制等是历史载体，不应无解释照抄。

例如早期 ping-pong fragment pass 可翻译为 compute shader + image/SSBO；occlusion query 的异步原则仍成立；scan、reduction、sorting 的工作/跨度与存储访问仍需分析。现代实现必须标注“原章方案”和“现代等价路径”，并说明行为是否完全等价。

```cpp
struct GemReproduction {
  std::string originalChapter;
  std::string invariant;
  std::string legacyCarrier;
  std::string modernPath;
  Evidence oracle;
  BoundaryConditions limits;
};
```

## 从效果案例提取可验证模型

自然/图像类章节通常可写成“输入信号 → 变换/过滤 → 合成”。若离散卷积核为 $k$，输出为：

$$
y[p]=\sum_q k[q]x[p-q].
$$

物理/计算类章节通常是“状态 → 并行更新 → 约束/归约 → 下一步消费”。GPU 版本除了数值误差，还要验证数据竞争、边界和 CPU/GPU 传输。

```glsl
layout(local_size_x = 256) in;
void main() {
    uint i = gl_GlobalInvocationID.x;
    if (i >= count) return;
    outputData[i] = reproduceGem(inputData[i], parameters);
}
```

不能只看“画面像”。图像类要比较误差/频谱/时序，模拟类要比较守恒/稳定性，性能类要固定设备和负载。
