## 直觉引入

想象你是一个厨师。GPU Gems 不是一本教你「怎么切菜」的基础教材，而是一本「米其林大厨私房菜谱」——它假设你已经会基本刀工（写着色器），然后手把手教你做水波纹、火焰、毛发光泽这些「硬菜」。每道菜都有完整配方（代码），告诉你火候（性能）怎么控制。

全书的核心线索是：从「让画面好看」（自然效果、光照材质）到「让画面高效」（图像处理、几何优化）再到「让 GPU 做更多事」（粒子、GPGPU）。

### 学习路径

先从视觉直觉强的自然效果入手（水、火、毛发），建立对着色器能做什么的感受；再学光照与材质（物理基础），理解效果背后的原理；然后是图像后处理和几何细分（处理能力）；最后是粒子物理和 GPU 通用计算（能力跃迁）。

## 代码对照

```glsl
// GPU Gems 的核心套路：噪声驱动效果
// 水面法线扰动（简化版）
vec3 getWaveNormal(vec2 uv, float time) {
    float wave = sin(uv.x * 10.0 + time) * 0.5
               + cos(uv.y * 8.0 + time * 1.3) * 0.3;
    // 从高度场近似法线
    vec3 normal = normalize(vec3(
        -ddx(wave), -ddy(wave), 1.0
    ));
    return normal;
}
// 同样的噪声思路也用于火焰、云层、地形
```

## 常见误区

<Callout type="trap">
**误区：把 GPU Gems 当理论教材从头读到尾。**
它是案例集，正确的用法是「带着问题查对应章节」。先想「我要做什么效果」，再翻到相关章节看实现方案。
</Callout>

<Callout type="trap">
**误区：照抄代码但不理解性能代价。**
GPU Gems 的案例有些是早期硬件的方案，在现代 GPU 上可能有更优写法。比如早期的 GPGPU 用纹理伪装数据，现在应该用 Compute Shader。
</Callout>

<Exercises>
**问题 1**：GPU Gems 全书九大主题是什么？它们之间是什么关系？

<Answer>
自然效果、光照阴影、材质着色器、图像处理、几何细分、粒子物理、GPU 计算、高级技术、总复习。呈递进关系：前四章建立「效果与原理」的基础，中间三章展示「处理与模拟能力」，最后两章走向「通用计算与综合实战」。
</Answer>

**问题 2**：为什么说 GPU Gems 是「效果驱动」的？

<Answer>
因为每个技术都从一个具体的视觉需求出发（比如「水要看起来有波纹」），再推导出实现方案（噪声扰动法线）。这跟先讲理论再举例的传统教材相反，更贴近实际开发流程。
</Answer>
</Exercises>
