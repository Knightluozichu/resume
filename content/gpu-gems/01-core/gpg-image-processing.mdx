## 直觉：图像处理不仅是“最终画面加滤镜”

这 24 章处理的是离散信号：有的在 HDR/颜色域，有的在纹理/覆盖域，有的把几何烘焙为图像，有的从视频图像提取对象。滤波核、采样足迹、编码和时间曝光决定结果，不能用 Bloom + tone mapping 概括。

先预测：在线性 RGB 上做模糊与在 sRGB 数值上做同一核，结果是否相同？不相同。卷积是线性运算，必须先把非线性编码解码到正确工作域。

是跨 24 章的统一验收单位。

- **Real-Time Glow**：提取/扩散高亮并合成，建立早期 HDR glow 数据流；

- **High-Quality Filtering**：用 GPU 纹理取样组合更高阶重建/缩放核；
- **Fast Filter-Width Estimates with Texture Maps**：在缺少方便导数时估计映射足迹宽度；
- **The OpenEXR Image File Format**：half、HDR 通道、压缩、窗口/元数据和生产交换；
- **A Framework for Image Processing**：将 GPU filter 组织成资源、pass 和依赖图。

离散卷积：

$$
y[p]=\sum_{q\in K}k[q]x[p-q].
$$

应说明是否归一化、是否有负 lobes、边界如何扩展及在哪个颜色域执行。

```glsl
vec3 convolveLinear(sampler2D src, vec2 uv, vec2 texel) {
  vec3 sum = vec3(0.0); float weight = 0.0;
  for (int i=0; i<tapCount; ++i) {
    vec3 c = decodeToLinear(texture(src, uv + offsets[i]*texel).rgb);
    sum += weights[i] * c; weight += weights[i];
  }
  return sum / weight;
}
```

Glow/Bloom 的阈值、软膝、降采样和合成位置由创作目标决定。若是模拟镜头散射，通常在 scene-linear/high-range 域工作；若是显示风格光晕，也可能在显示映射后设计。不存在无条件“必须在 tone mapping 前”。

### Footprint、DOF 与 OpenEXR

纹理足迹可由导数近似，LOD：

$$
\lambda\approx\log_2\max(\|\partial(u,v)/\partial x\|,\|\partial(u,v)/\partial y\|).
$$

Fast Filter-Width Estimates 与 Mipmap-Level Measurement 都要求把像素覆盖的纹理区域可视化，而非只看最终纹理是否模糊。

薄透镜景深的 circle of confusion（比例形式）随焦距差增大：

$$
c\propto A\left|\frac{z-z_f}{z}\right|,
$$

其中 $A$ 与光圈相关、$z_f$ 为焦平面。后处理 DOF 缺少被前景遮挡的背景信息，容易 foreground bleed；分层/散射 gather 与真实多样本各有边界。

不是“让画面自动 HDR”。读写必须保持 channel name/type、色度/颜色空间和 premultiplication 元数据约定。

## 线性光与颜色出口

是 lighting、filtering、resampling 和 alpha composite 的默认工作域。sRGB 是编码传输函数，不是“gamma 2.2 精确等价”。

直通 alpha 合成在线性域：

$$
C_o=\alpha_sC_s+(1-\alpha_s)C_d.
$$

若源为 premultiplied，存储 $C'_s=\alpha_sC_s$，则 $C'_o=C'_s+(1-\alpha_s)C'_d$。OpenEXR、粒子、hair 和后处理图之间必须统一 straight/premultiplied。

## Impostor、Normal Baking 与 Vector Coverage

True Impostors 用深度/层信息让平面表示产生视差和正确交点；验收旋转视角、silhouette、层穿插与深度写入。Normal baking 要比较高模几何法线经 tangent basis 编码后的结果，检查 mirrored UV handedness 和 cage miss。

矢量图形的核心是像素对曲线/填充区域的 coverage。预滤波线把距离到线的积分/lookup 映射为 alpha；High-Quality Antialiased Rasterization 和 Rendering Vector Art on the GPU 都要以 subpixel reference 检查边缘面积，而不是只看锯齿少。

## 时域：Motion Blur、DOF 与视频

曝光运动模糊近似积分：

$$
C=\frac1{\Delta t}\int_{t_0}^{t_0+\Delta t}L(x(t),t)dt.
$$

post-process velocity blur 只有当前可见层的速度/深度，disocclusion 无历史背景；需要 neighborhood clamp、前后景分离和相机/物体速度正确性。DOF 也有类似层缺失问题。

视频颜色检测要固定 camera transfer、white balance 和颜色空间；阈值后还需形态学/连通性，并记录端到端 latency。GPU 更快不代表分类在光照变化下稳健。

```glsl
vec3 accumulateMotion(sampler2D color, sampler2D depth, vec2 uv, vec2 velocity) {
  vec3 sum = vec3(0.0); float w = 0.0;
  for (int i=0; i<sampleCount; ++i) {
    float t = (i + 0.5) / sampleCount - 0.5;
    vec2 q = uv + t * velocity;
    float accept = depthCompatible(depth, uv, q);
    sum += accept * texture(color, q).rgb; w += accept;
  }
  return sum / max(w, 1e-5);
}
```
