## 直觉：这些章节不构成“硬阴影到软阴影”的单线演进

24 章同时讨论阴影表示、可见性管理、光照架构、材质数据、间接光、非真实感、天空介质、水面和后处理。shadow volume 与 shadow map 是不同可见性表示；deferred shading 是数据/执行架构；AO 是间接可见性近似；大气散射和折射又属于介质传输。

先预测：把 3×3 PCF 核扩大能否自动产生随遮挡距离增大的物理半影？不能。固定核只过滤 shadow test，半影几何需要光源尺寸、blocker 与接收距离关系。

是阴影技术共享的不变量。


## 24 个原章与核心承载


### GPU Gems 1 Ch9-15：阴影表示与艺术灯光

- **Efficient Shadow Volume Rendering**：轮廓边挤出、z-pass/z-fail、封闭体与 stencil fill-rate；
- **Cinematic Lighting**：以 artist controls 组织灯形、衰减、cookie 和分层贡献，而非只套一个 BRDF；
- **Shadow Map Antialiasing**：对深度比较结果做 percentage-closer filtering（PCF）；
- **Omnidirectional Shadow Mapping**：点光源六方向/cubemap 深度与面边界；
- **Generating Soft Shadows Using Occlusion Interval Maps**：静态遮挡区间预计算与移动光路径上的软影；
- **Perspective Shadow Maps: Care and Feeding**：用后投影视锥重分配 shadow texel，并处理奇异/退化情况；
- **Managing Visibility for Per-Pixel Lighting**：按光体积和物体/光源可见集减少 batch 与像素工作。

shadow map 比较可写为：

$$
V(\mathbf p)=\mathbf 1[z_L(\mathbf p)-b\le D_L(x_L,y_L)].
$$

主要处理离散 aliasing；固定核不包含面光源几何，不能称为物理正确软影。

```glsl
float pcf(sampler2DShadow sm, vec3 q, vec2 texel) {
  float visible = 0.0;
  for (int y=-1; y<=1; ++y)
    for (int x=-1; x<=1; ++x)
      visible += texture(sm, vec3(q.xy + vec2(x,y)*texel, q.z));
  return visible / 9.0;
}
```

shadow volume 不受 shadow-map 分辨率影响，却依赖稳健 silhouette、封闭体、stencil 和几何/fill 成本。现代 geometry/mesh shader 可生成体，但 CPU 预处理或 compute compact 也可能更好，必须测场景拓扑。

### GPU Gems 2 Ch9-19：渲染架构、材质与介质

- **Deferred Shading in S.T.A.L.K.E.R.**：G-buffer 解耦几何与多光源着色，同时承担带宽、透明和 MSAA 代价；
- **Real-Time Computation of Dynamic Irradiance Environment Maps**：在线更新环境 irradiance，而非只使用静态 cubemap；
- **Approximate Bidirectional Texture Functions**：压缩/查表近似 BTF 的视向和光向变化；
- **Tile-Based Texture Mapping**：用有限 tile 合成大面积细节并抑制重复；
- **Implementing the mental images Phenomena Renderer on the GPU**：把生产级 shader/phenomena 抽象映射到 GPU；
- **Dynamic Ambient Occlusion and Indirect Lighting**：用 surface elements/disk form factor 近似动态 AO 与一次间接光；
- **Blueprint Rendering and "Sketchy Drawings"**：轮廓、线条纹理和抖动构造非真实感表达；
- **Accurate Atmospheric Scattering**：沿视线积分大气内散射和透射；
- **Efficient Soft-Edged Shadows Using Pixel Shader Branching**：利用分支提前结束无须软边计算的像素；
- **Using Vertex Texture Displacement for Realistic Water Rendering**：顶点纹理位移与几何/法线一致；
- **Generic Refraction Simulation**：屏幕空间/环境纹理偏移近似折射并处理遮挡边界。

把复杂度由“物体×光源提交”转为可见像素上的光体积计算，但不保证更快。近似工作量可比较：

$$
C_{forward}\sim\sum_o L_oP_o,\qquad
C_{deferred}\sim G+\sum_l P_l+B_{gbuffer}.
$$

其中 $B_{gbuffer}$ 是读写带宽。透明表面仍需前向/其他路径；现代 MSAA、tile/clustered 路径改变权衡，但不抹去原章的数据分解。

```cpp
renderGeometryToGBuffer();
for (Light light : visibleLights) {
  setLightVolume(light);
  shadePixelsInsideVolume(gbuffer, light);
}
renderForwardTransparent();
```

大气单散射沿视线可概括为：

$$
L(s)=T(0,s)L_0+\int_0^s T(t,s)\,\sigma_s\,p(\theta)\,L_i(t)\,dt.
$$

步长、相函数、密度尺度高度和太阳遮挡决定误差。Generic Refraction Simulation 的屏幕纹理缺失背面/屏外信息，必须显式回退，不能冒充完整光线传输。

### GPU Gems 3 Ch8-13：可过滤阴影、级联、AO 与后处理介质

- **Summed-Area Variance Shadow Maps**：存深度矩并用 variance/Chebyshev 上界过滤，SAT 支持大可变核；
- **Interactive Cinematic Relighting with Global Illumination**：预计算传输/分解，使艺术家交互改变灯光并保留 GI 响应；
- **Parallel-Split Shadow Maps on Programmable GPUs**：把相机视锥分段，为近远区域分配独立 shadow map；
- **Efficient and Robust Shadow Volumes Using Hierarchical Occlusion Culling and Geometry Shaders**：结合层次遮挡与 GPU 挤出减少 shadow-volume 工作；
- **High-Quality Ambient Occlusion**：更高质量采样/层次近似环境遮蔽；
- **Volumetric Light Scattering as a Post-Process**：从光源屏幕位置沿图像径向采样，近似 god rays。

VSM 保存一、二阶矩 $\mu=E[z]$、$m_2=E[z^2]$，方差 $\sigma^2=m_2-\mu^2$。当接收深度 $t>\mu$ 时用：

$$
P(z\ge t)\le\frac{\sigma^2}{\sigma^2+(t-\mu)^2}.
$$

支持大核，但会 light leaking；minimum variance、bleeding reduction 只是缓解，不能恢复丢失的多峰深度分布。

PSSM/CSM 级联 split 可混合均匀与对数分割：

$$
d_i=\lambda n(f/n)^{i/m}+(1-\lambda)\left[n+(f-n)i/m\right].
$$

验收包括 texel density、级联接缝、稳定投影和相机移动 shimmering。


## AO 与 GI：遮蔽不是光

常写为：

$$
A(\mathbf x)=\frac{1}{\pi}\int_{\Omega}V(\mathbf x,\omega)(\mathbf n\cdot\omega)^+d\omega.
$$

Dynamic AO and Indirect Lighting 与 High-Quality Ambient Occlusion 都比“屏幕变暗”更强调几何采样；但任何有限元素/屏幕近似都有漏采、尺度和 bias。Interactive Cinematic Relighting 的 GI 则包含光照变化下的预计算传输响应，不能与 AO 合并称同一算法。
