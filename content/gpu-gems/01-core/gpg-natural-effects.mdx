## 直觉：八章不是同一个“噪声效果”

自然效果 Part 同时处理连续表面、光传输、半透明材质、角色变形、随机场、粒子体积、海量植被和波动光学。噪声只在部分问题中提供信号，不能替代几何、可见性或能量模型。

## 八章原始问题与唯一承载

<GpgNaturalChapterMatrixDiagram />

### Ch1 Effective Water Simulation from Physical Models

水面用多组方向波叠加高度或位移。深水色散关系可写成 $\omega^2=gk$；简化高度场：

$$
h(\mathbf x,t)=\sum_i A_i\sin(\mathbf k_i\cdot\mathbf x-\omega_i t+\phi_i).
$$

解析偏导给切线/法线，比对高度做屏幕导数更稳定。原章还强调反射、折射与波面一致；现代实现可用 compute 频谱或 tessellation，但要保留相位速度、振幅和法线不变量。

```glsl
float h = 0.0; vec2 grad = vec2(0.0);
for (int i=0; i<waveCount; ++i) {
  float phase = dot(k[i], x) - omega[i] * time + phi[i];
  h += A[i] * sin(phase);
  grad += A[i] * k[i] * cos(phase);
}
vec3 normal = normalize(vec3(-grad.x, 1.0, -grad.y));
```

### Ch2 Rendering Water Caustics

焦散来自折射光线在接收面上的面积压缩。水面点经 Snell 定律得到折射方向，再与池底相交；相邻水面微元投影面积越小，辐照度越高。折射满足：

$$
n_1\sin\theta_1=n_2\sin\theta_2.
$$

现代实现可 rasterize 光束网格、splat 能量或离线/实时 photon-like accumulation。必须做能量归一化、全反射边界和时序稳定测试，不能只滚动一张亮斑贴图。

### Ch3 Skin in the "Dawn" Demo

皮肤不是普通 Lambert。原章用多层纹理、法线细节、specular 与近似次表面效果塑造 Dawn。核心是区分表皮镜面与皮下扩散，并由厚度/区域 mask 控制参数。

<Term def="光进入介质后在表面下散射并从附近位置离开的现象；实时皮肤通常用多尺度模糊、预积分或屏幕空间近似">次表面散射</Term>不能被常数 ambient 代替。现代复现需在线性颜色空间比较未模糊/多尺度 diffuse、独立 specular 和耳缘透射。

### Ch4 Animation in the "Dawn" Demo

角色动画结合骨骼蒙皮和 facial blend shapes。线性 blend shape：

$$
\mathbf p'=\mathbf p_0+\sum_j w_j(\mathbf p_j-\mathbf p_0).
$$

权重范围、组合冲突、法线/切线变形和 CPU/GPU 数据布局都是合同。现代 compute/vertex 路径要与 CPU 对少量顶点比较，并检查极端表情和骨骼+表情叠加顺序。

### Ch5 Implementing Improved Perlin Noise

改进 Perlin noise 使用格点伪随机梯度、平滑 fade 和插值。改进 fade：

$$
f(t)=6t^5-15t^4+10t^3
$$

在格点端点一、二阶导数为零，减少视觉接缝。<Term def="由格点梯度与到采样点位移做点积，再用平滑权重插值得到的连续伪随机场">梯度噪声</Term>不是独立随机 texel；验收要检查周期、均值、梯度连续性和频谱。现代 hash/texture 实现必须保持梯度集合和插值定义。

```glsl
float fade(float t) { return t*t*t*(t*(t*6.0-15.0)+10.0); }
float noise3(vec3 p) {
  ivec3 cell = ivec3(floor(p));
  vec3 f = fract(p), u = fade(f);
  return trilerpGradientDots(cell, f, u);
}
```

### Ch6 Fire in the "Vulcan" Demo

火焰用粒子/切片表示随时间变化的密度与温度，再做发光颜色、soft intersection 和 alpha/additive 合成。它不是物理燃烧模拟；核心是高填充率下的粒子组织、动画纹理和视觉层次。

<Term def="用大量面向相机的四边形或体切片近似参与介质，每个元素携带年龄、尺寸、密度和温度等状态的渲染方法">粒子体积近似</Term>要验证排序/预乘 Alpha、overdraw、深度软化和低帧率下时间积分。

### Ch7 Rendering Countless Blades of Waving Grass

草地以 cluster/billboard 减少几何，按距离 LOD，顶点阶段叠加低频风与局部弯曲。根部固定、叶尖位移增大可用高度权重 $s$：

$$
\Delta\mathbf p=s^q\,\mathbf w(\mathbf x,t).
$$

必须检查 silhouette、视角 pop、alpha coverage、阴影与 overdraw。现代 instancing/mesh shader 只是载体升级，内容密度与风场相干性仍是核心。

### Ch8 Simulating Diffraction

衍射由微结构尺度与可见光波长相近产生方向性色散。光栅近似满足：

$$
d(\sin\theta_i+\sin\theta_o)=m\lambda.
$$

<Term def="表面周期微结构使不同波长在不同方向发生相长/相消干涉，从而产生彩虹色高光的波动光学现象">衍射</Term>不同于薄膜干涉或普通 RGB Fresnel。现代 shader 可按方向求允许波长并映射光谱颜色，需检查周期、级次、视角与能量上限。

## 现代复现的共同数据流

八章可组织为三类管线：surface（water/skin/diffraction）、deformation（Dawn/grass）、field/volume（noise/fire/caustics）。每类都要明确坐标域、时间步、过滤和合成。

```cpp
for (Frame frame : testSequence) {
  updateFields(frame.time);        // waves, noise, wind, particles
  deformGeometry();                // water, blend shapes, grass
  renderOpticalResponse();         // skin, caustics, diffraction, fire
  captureIntermediatesAndTiming();
  compareWithOracle(frame);
}
```

原书效果受当时硬件限制，现代实现不应伪称像素完全一致；应证明核心趋势：波相位与法线一致、焦散随曲率聚焦、噪声连续、动画权重可控、火/草时序稳定、衍射随波长分离。

## 常见误区

<Callout type="trap">
**现象 →** 用一张滚动 noise 纹理同时解释水、焦散、火和草。
**原因 →** 把共同扰动信号误当成各章的几何与光学模型。
**修法 →** 分别保留波面导数、折射聚焦、介质合成和根叶形变合同，noise 只作输入之一。
</Callout>

<Callout type="trap">
**现象 →** Dawn 皮肤换成现代 PBR 后宣布 Ch3/4 都已复现。
**原因 →** 混淆皮肤外观与 blend shape/蒙皮动画，且未验证次表面趋势。
**修法 →** 外观、几何变形分开做 CPU/GPU 探针，再在角色场景组合验收。
</Callout>

<Callout type="trap">
**现象 →** 火焰和草地静态截图漂亮，运动时闪烁或 LOD 跳变。
**原因 →** 只验收单帧，忽略随机场相干、alpha coverage 和时间积分。
**修法 →** 固定相机轨迹和时间序列，比较帧间差、频谱、coverage 与 GPU overdraw。
</Callout>

## 练习

<Exercises>

**问题 1：Ch1 水面和 Ch2 焦散为何必须共享波面定义？**

<Answer>
焦散折射方向来自水面位置与法线；若水面渲染和焦散使用不同高度/导数，亮斑不会与可见波峰同步。应由同一波参数或纹理产生几何、法线和折射输入。
</Answer>

**问题 2：Improved Perlin Noise 的“improved”怎样验收？**

<Answer>
在格点边界检查 fade 的一、二阶连续性，比较旧/新梯度集合的轴向伪影与频谱；固定 seed 检查周期和确定性，而不是只看一张云纹理。
</Answer>

**问题 3：给八章设计一个综合场景。**

<Answer>
让 Dawn 角色站在有波浪/焦散的水边，周围有风草和粒子火，皮肤使用分层着色，光盘表面显示衍射；所有扰动共享可记录时间轴。分别显示波导数、焦散能量、blend 权重、noise cell、粒子密度、草 LOD 和衍射波长附件。
</Answer>

</Exercises>

## 小结

GPU Gems 1 第 1-8 章涵盖八种不同问题。完整复现要保留波、折射、皮肤层、角色变形、梯度噪声、粒子介质、植被 LOD 和衍射的独立核心，再用现代 GPU 路径和时序证据组合，而不是用“程序化噪声”一词抹平边界。

<GlossaryItem term="自然效果分层模型">把驱动场、状态、光学响应和时间演化分开验证的模型。</GlossaryItem>

<GlossaryItem term="粒子体积近似">用粒子面片或切片近似动态参与介质的渲染方式。</GlossaryItem>
<GlossaryItem term="衍射">周期微结构按波长和方向产生干涉色散的现象。</GlossaryItem>
