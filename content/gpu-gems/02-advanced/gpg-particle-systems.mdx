## 直觉：这不是一个粒子更新教程

十三章横跨分子搜索、线性代数、金融 Monte Carlo、排序、流体、医学 FFT、刚体/碰撞、距离场和病毒签名匹配。共同点是把大规模规则计算映射到 GPU，不是“每个对象一个线程”这么简单。

先预测：GPU 期权定价 kernel 比 CPU 快，但随机序列相关导致价格偏差，能否算成功？不能。科学/金融加速必须先证明统计与数值正确，再讨论吞吐。

是十三章共享主线。

### 线性系统与残差

线性方程：

$$
A\mathbf x=\mathbf b,
\qquad r_k=\mathbf b-A\mathbf x_k.
$$

必须报告残差范数、迭代数和条件数敏感性。GPU kernel 快但需要更多迭代，不一定端到端更快。

```cpp
for (int k=0; k<maxIterations; ++k) {
  spmv(A, x, Ax);
  subtract(b, Ax, r);
  double norm = reduceNorm(r);
  if (!finite(norm) || norm < tolerance) break;
  applyPreconditionerAndUpdate(A, x, r);
}
```

### Options、蛋白质与随机搜索

欧式 call 的 Monte Carlo 估计：

$$
\hat C=e^{-rT}\frac1N\sum_{i=1}^N\max(S_T^{(i)}-K,0).
$$

误差约按 $O(N^{-1/2})$，要报告置信区间、seed/subsequence 和与解析 Black-Scholes/CPU 参考的偏差。蛋白质结构预测同样涉及巨大候选空间和能量函数；GPU 只加速评分/更新，不证明模型能找到生物学正确结构。

适用于期权、蛋白质搜索和后续 N-body/RNG 输入。

### Sorting 与 FFT reconstruction

排序是 broad phase、构建索引和分桶的基础。验收全同、逆序、重复 key、稳定性需求、非幂二长度和 key/value 配对；只测随机均匀数组会隐藏最差路径。

离散傅里叶变换：

$$
X_k=\sum_{n=0}^{N-1}x_n e^{-i2\pi kn/N}.
$$

需要复数布局、归一化、频率索引和边界一致。医学重建要与 phantom/已知 k-space 对照，不能用视觉锐利度代替误差。

### N-body：工作复用与数值边界

粒子 $i$ 的加速度：

$$
\mathbf a_i=G\sum_{j\ne i}m_j\frac{\mathbf r_j-\mathbf r_i}{(\|\mathbf r_j-\mathbf r_i\|^2+\epsilon^2)^{3/2}}.
$$

CUDA tile 让一组 body positions 被多个线程复用，降低 global loads；仍是 $O(N^2)$ all-pairs。softening $\epsilon$、时间积分和浮点累加顺序影响能量/轨道，必须与 CPU double 小场景比较。

```cuda
for (int tile=0; tile<numTiles; ++tile) {
  sharedPos[threadIdx.x] = positions[tile*BLOCK + threadIdx.x];
  __syncthreads();
  for (int j=0; j<BLOCK; ++j) accel += interaction(self, sharedPos[j]);
  __syncthreads();
}
```

### Broad phase、LCP 与刚体

常用 sort-and-sweep 或 uniform grid。验证候选 pair 完备性、重复 pair、极端密集/大物体和排序成本。

接触 LCP：

$$
\mathbf w=A\mathbf z+\mathbf q,\quad
\mathbf z\ge0,\ \mathbf w\ge0,\ \mathbf z^T\mathbf w=0.
$$

$z$ 可表示非负接触 impulse，$w$ 表示分离速度/约束余量。并行迭代可能因接触耦合收敛慢；应检查 penetration、complementarity residual、能量和堆叠稳定性。

刚体更新还需 orientation 正规化、惯量空间转换和固定/休眠物体；“实时”依赖 body/contact 数与迭代预算。

### Complex-boundary/3D fluids

Flow Simulation with Complex Boundaries 要在 solid/fluid interface 正确施加 no-slip/free-slip、压力和插值；体素 stair-step 会引入误差。Real-Time Simulation and Rendering of 3D Fluids 再把三维 density/velocity 与 volume renderer 连接。

验收 divergence、边界通量、质量/密度、CFL/时间步和体绘制 transfer function；渲染好看不能掩盖流体穿墙或质量漂移。

### Tetrahedra SDF 与 virus matching

理想满足 $|\nabla d|\approx1$（远离不可微中轴）。tetrahedra scan conversion 将几何局部距离贡献 rasterize 到体素；要验证符号、覆盖无孔洞、重叠 min reduction 和非流形边界。

病毒签名匹配是字节/字符串流问题：pattern set、automaton/state、chunk overlap 和 variable-length output 决定正确性。测试跨 chunk signature、重叠匹配、二进制零字节和最坏重复输入；吞吐需包含 I/O/传输。

```cpp
for (Chunk chunk : streamWithOverlap(maxPatternLength - 1)) {
  Matches gpu = matchGpu(automaton, chunk);
  appendDeduplicated(globalMatches, gpu, chunk.baseOffset);
}
compareMatches(globalMatches, cpuReference);
```
