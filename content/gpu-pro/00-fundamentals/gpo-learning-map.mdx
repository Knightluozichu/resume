## 直觉引入

GPU Pro 系列就像一本「渲染技术烹饪书」。每章是一道菜——从基础渲染管线（锅碗瓢盆）到光照阴影（调味料），从图像空间效果（摆盘装饰）到 GPU 物理模拟（分子料理），从程序化生成（预制食材）到体积渲染（汤品慢炖）。全书的核心是：如何把学术研究中的渲染技术，工程化为实时游戏可用的方案。

## 代码对照

```hlsl
// GPU Pro 技术栈核心概念（简化伪码）
// 1. 延迟渲染 G-Buffer
struct GBuffer {
    float4 albedo : SV_Target0;
    float4 normal : SV_Target1;
    float4 material : SV_Target2; // metallic, roughness, ...
};

// 2. SSAO（屏幕空间环境光遮蔽）
float SSAO(float2 uv, float3 posVS, float3 normalVS) {
    float occlusion = 0;
    for (int i = 0; i < KERNEL_SIZE; i++) {
        float3 samplePos = posVS + kernel[i] * radius;
        float sampleDepth = samplePos.z; // 从深度图重建
        occlusion += (sampleDepth > posVS.z) ? 1.0 : 0.0;
    }
    return 1.0 - occlusion / KERNEL_SIZE;
}

// 3. 体积渲染 Ray Marching
float4 VolumetricRayMarch(float3 rayOrigin, float3 rayDir) {
    float transmittance = 1.0;
    float3 scatteredLight = 0;
    for (int i = 0; i < STEPS; i++) {
        float3 pos = rayOrigin + rayDir * (i * stepSize);
        float density = SampleDensity(pos);
        float3 light = SampleLightScattering(pos);
        scatteredLight += transmittance * density * light;
        transmittance *= exp(-density * stepSize * extinction);
    }
    return float4(scatteredLight, transmittance);
}
```

## 常见误区

<Callout type="trap">
**误区：把 GPU Pro 当教材从头读。**
GPU Pro 是技术合集，各章相对独立。应按需求选读：需要光照看光照卷，需要体积渲染看体积章节。先建立全局认知（学习地图），再按项目需求深入特定技术。
</Callout>

<Callout type="trap">
**误区：直接照搬论文实现忽视性能。**
GPU Pro 的技术源自学术研究，原始实现可能不适合实时游戏。需根据目标平台（PC/移动端）做近似优化：减少采样数、用 LUT 替代计算、降分辨率渲染。关键是理解原理后做工程近似。
</Callout>

<Exercises>
**问题 1**：GPU Pro 的核心定位是什么？全书四大板块是什么？

<Answer>
核心定位是「论文工程化」——将 SIGGRAPH/GDC 等学术会议的渲染研究成果转化为实时游戏可用的工程方案。四大板块：渲染技术基础（前向/延迟/可见性缓冲）、光照与图像空间（PBR/GI/SSAO/SSR）、GPU 计算与程序化（物理模拟/噪声/地形）、高级渲染（体积/移动端/高级着色）。呈递进关系：高效渲染 → 真实光照 → 屏幕空间效果 → GPU 计算 → 高级效果。
</Answer>

**问题 2**：为什么说 GPU Pro 的技术需要做「工程近似」？

<Answer>
GPU Pro 技术源自学术研究，原始论文实现追求质量而非实时性，通常采样数多、计算量大。实时游戏有帧率约束（30/60fps），不能直接照搬。工程近似策略：1) 减少采样数（如 SSAO 从 64 样本降到 16）；2) 用查找表（LUT）替代运行时计算（如 BRDF 积分 LUT）；3) 降分辨率渲染再上采样（如体积雾用 1/4 分辨率）；4) 时间复用累积（如 TAA 的历史帧混合）；5) 用 half 精度替代 float（移动端）。关键是理解原理后根据平台做合理近似。
</Answer>
</Exercises>
