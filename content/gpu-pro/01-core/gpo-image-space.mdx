## 直觉引入

想象你看一面镜子。镜子里的画面是你眼睛能看到的内容的反射——但如果你反射的角度超出了屏幕范围，你就看不到反射内容了。图像空间效果（SSAO/SSR）就像这面镜子——只能利用屏幕内已有的信息，超出屏幕的部分只能靠猜测或降级方案补充。

## 代码对照

```hlsl
// SSAO（简化）
float ComputeSSAO(float2 uv, float3 posVS, float3 normalVS, sampler2D depthTex) {
    float occlusion = 0;
    [unroll] for (int i = 0; i < KERNEL_SIZE; i++) {
        // 在法线方向的半球内采样
        float3 sampleDir = reflect(kernels[i], normalVS); // 随机旋转载体
        float3 samplePos = posVS + sampleDir * radius;
        // 投影到屏幕空间
        float4 offset = mul(projMatrix, float4(samplePos, 1.0));
        offset.xy /= offset.w;
        // 采样深度比较
        float sampleDepth = tex2D(depthTex, offset.xy).r;
        float linearDepth = LinearizeDepth(sampleDepth);
        if (linearDepth >= samplePos.z + bias) occlusion += 1.0;
    }
    return 1.0 - occlusion / KERNEL_SIZE;
}

// SSR Hi-Z Ray March（简化）
float3 ComputeSSR(float3 posVS, float3 normalVS, float3 viewDir) {
    float3 reflectDir = reflect(viewDir, normalVS);
    float3 rayPos = posVS;
    for (int i = 0; i < MAX_STEPS; i++) {
        rayPos += reflectDir * stepSize;
        float4 screenPos = mul(projMatrix, float4(rayPos, 1.0));
        screenPos.xy /= screenPos.w;
        float sampledDepth = tex2Dlod(depthPyramid, float4(screenPos.xy, mipLevel, 0)).r;
        if (abs(rayPos.z - sampledDepth) < thickness) {
            return tex2D(colorTex, screenPos.xy).rgb; // 命中
        }
        stepSize *= 1.5; // 自适应步长
    }
    return 0; // 未命中 → 降级
}
```

## 常见误区

<Callout type="trap">
**误区：SSAO 采样核越大越好。**
大采样核会覆盖远处几何导致过度遮蔽（如在墙角采样到另一面墙）。正确做法：根据像素深度调整采样半径（远处小半径近处大半径），或限制采样核在法线方向的半球内。
</Callout>

<Callout type="trap">
**误区：SSR 不需要降级方案。**
SSR 只能反射屏幕内可见物体——屏幕外的反射完全丢失。当反射方向指向屏幕外、或 Ray March 未命中时，反射颜色为黑。必须有降级方案：用 Reflection Probe 填充未命中区域，用粗糙度调制 SSR 与 Probe 的混合比例（光滑全用 SSR，粗糙全用 Probe）。
</Callout>

<Exercises>
**问题 1**：SSAO 的工作原理是什么？输入需要什么？

<Answer>
SSAO 在屏幕空间对每个像素，沿法线方向的半球内生成多个采样点，将每个采样点投影到屏幕空间并采样深度图比较——如果采样点的深度比深度图中存储的深度更远，说明该方向被几何遮挡，统计遮挡比例作为环境光遮蔽因子。输入需要：深度图（Depth Texture）和法线图（Normal Texture，可从深度图重建或从 G-Buffer 读取）。输出是 0~1 的遮蔽因子，乘以环境光颜色。
</Answer>

**问题 2**：图像空间效果的共同局限是什么？SSR 如何解决屏幕外反射丢失？

<Answer>
共同局限：只能利用屏幕内可见信息，屏幕外的几何和颜色完全丢失。具体表现：SSAO 在屏幕边缘遮蔽不正确，SSR 的屏幕外反射为空，SSGI 的屏幕外间接光丢失。SSR 解决屏幕外反射丢失的方法：1) Ray March 未命中时降级到 Reflection Probe 采样；2) 按材质粗糙度混合 SSR 和 Probe——光滑表面（低粗糙度）主要用 SSR（锐利反射），粗糙表面（高粗糙度）主要用 Probe（模糊反射）；3) 用屏幕边缘衰减权重平滑 SSR 到 Probe 的过渡，避免边界突变。
</Answer>
</Exercises>
