## 直觉引入

想象一盏路灯。近处的影子锐利清晰，远处的影子逐渐模糊——因为光源不是点而是有面积的。PCF 只是模糊处理阴影边缘，PCSS 则模拟这个物理现象：根据遮挡体到接收面的距离动态调整阴影柔度。这就是 GPU Pro 光照阴影章节的核心——从「能产生阴影」到「物理正确的软阴影」。

## 代码对照

```hlsl
// PCSS 物理软阴影（简化）
float PCSS(sampler2D shadowMap, float3 shadowCoord, float2 texelSize) {
    // 1. Blocker Search：搜索遮挡体平均距离
    float blockerDist = 0;
    int blockerCount = 0;
    for (int x = -SEARCH_RADIUS; x <= SEARCH_RADIUS; x++) {
        for (int y = -SEARCH_RADIUS; y <= SEARCH_RADIUS; y++) {
            float z = tex2D(shadowMap, shadowCoord.xy + float2(x,y)*texelSize).r;
            if (z < shadowCoord.z) { // 遮挡
                blockerDist += z;
                blockerCount++;
            }
        }
    }
    blockerDist /= blockerCount;

    // 2. 计算柔化核大小（光源面积 / 遮挡距离 * (接收距离 - 遮挡距离)）
    float penumbra = (shadowCoord.z - blockerDist) / blockerDist * LIGHT_SIZE;

    // 3. PCF 采样
    return PCF(shadowMap, shadowCoord, penumbra * texelSize);
}

// VSM 方差阴影（简化）
float VSM(sampler2D shadowMapVS, float3 shadowCoord) {
    float2 moments = tex2D(shadowMapVS, shadowCoord.xy).rg;
    float p = (moments.x >= shadowCoord.z) ? 1.0 : 0.0;
    float variance = moments.y - moments.x * moments.x;
    variance = max(variance, MIN_VARIANCE);
    float d = shadowCoord.z - moments.x;
    float pMax = variance / (variance + d * d); // 切比雪夫上界
    return max(p, pMax);
}
```

## 常见误区

<Callout type="trap">
**误区：PCSS 质量高就直接用。**
PCSS 的 Blocker Search 需要大量采样（如 7x7=49 次），加上 PCF 柔化采样，总采样数可达 100+。移动端完全不可用，PC 端也需限制采样半径或用 Hi-Z 加速。实际项目通常用 PCSS 近似（减少搜索步数）或直接用 PCF + 固定核大小。
</Callout>

<Callout type="trap">
**误区：VSM 没有缺点。**
VSM 支持预滤波柔化（只需对 Shadow Map 做高斯模糊），速度远快于 PCSS。但 VSM 有漏光问题——当多个遮挡体深度差异大时，切比雪夫不等式的上界估计偏高，导致本该全阴影的区域漏光。解决方法：MSM（Moment Shadow Map）用四阶矩替代二阶矩，减少漏光但增加存储和计算。
</Callout>

<Exercises>
**问题 1**：PCSS 如何产生物理正确的软阴影？三步流程是什么？

<Answer>
PCSS 三步：1) Blocker Search——在 Shadow Map 上搜索当前像素周围的遮挡体，计算平均遮挡距离；2) 计算柔化核大小——根据光源面积、遮挡距离和接收距离按比例计算（penumbra = lightSize * (receiverDist - blockerDist) / blockerDist），遮挡体越近核越大（越柔和），越远核越小（越锐利）；3) PCF 采样——用计算出的核大小做 PCF 采样。物理正确性来自：面光源产生的阴影中，遮挡体越靠近接收面阴影越锐利，越远离越柔和，PCSS 精确模拟了这个几何关系。
</Answer>

**问题 2**：VSM 的原理和漏光问题分别是什么？

<Answer>
VSM 存储深度的均值（一阶矩）和深度平方的均值（二阶矩），用切比雪夫不等式估算遮挡概率上限：P(unoccluded) ≤ variance / (variance + d^2)，其中 variance = E[x^2] - E[x]^2，d = 当前深度 - 均值深度。优势：支持预滤波（对 VSM 做高斯模糊等价于柔化阴影），无需逐像素多次采样。漏光问题：当同一采样区域内有多个不同深度的遮挡体时（如一个近一个远），方差变大，切比雪夫上界估计偏高，导致本该全阴影的区域出现漏光。解决：MSM（四阶矩）提高精度，或用分层 VSM（每级 CSM 独立 VSM）。
</Answer>
