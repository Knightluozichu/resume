## 直觉引入

想象你有一台「无限花纹打印机」。普通纹理是打印好的照片（分辨率固定，存储占空间），程序化纹理是这台打印机本身（随用随打印，无限分辨率，零存储）。噪声函数就是打印机的「墨水」——Perlin 噪声产生柔和云雾，Worley 噪声产生细胞裂纹，fbm 叠加多层噪声产生山脉纹理。

## 代码对照

```hlsl
// Perlin 噪声（简化）
float PerlinNoise(float2 p) {
    int2 i = floor(p);
    float2 f = frac(p);
    // 四个角的随机梯度
    float2 g00 = hashGradient(i);
    float2 g10 = hashGradient(i + int2(1,0));
    float2 g01 = hashGradient(i + int2(0,1));
    float2 g11 = hashGradient(i + int2(1,1));
    // 梯度点积
    float n00 = dot(g00, f);
    float n10 = dot(g10, f - float2(1,0));
    float n01 = dot(g01, f - float2(0,1));
    float n11 = dot(g11, f - float2(1,1));
    // 平滑插值
    float2 u = smoothstep(0, 1, f);
    return lerp(lerp(n00, n10, u.x), lerp(n01, n11, u.x), u.y);
}

// fbm 分形布朗运动
float fbm(float2 p, int octaves) {
    float value = 0;
    float amplitude = 0.5;
    float frequency = 1.0;
    for (int i = 0; i < octaves; i++) {
        value += amplitude * PerlinNoise(p * frequency);
        frequency *= 2.0;  // 频率翻倍
        amplitude *= 0.5;   // 振幅减半
    }
    return value;
}

// 程序化地形高度
float TerrainHeight(float2 worldPos) {
    float h = fbm(worldPos * 0.01, 6); // 低频大山
    h += fbm(worldPos * 0.05, 4) * 0.3; // 中频丘陵
    h += fbm(worldPos * 0.2, 3) * 0.1;  // 高频细节
    // 侵蚀效果（域扭曲）
    float erosion = worley(worldPos * 0.03);
    h -= erosion * 0.2;
    return h;
}
```

## 常见误区

<Callout type="trap">
**误区：程序化纹理一定比预计算纹理好。**
程序化纹理的 ALU 开销可能比纹理采样高数倍。在高频纹理（如法线贴图、细节贴图）上，每像素调用 fbm（6 octave × 4 次梯度 = 24 次计算）远比一次纹理采样慢。正确策略：低频结构（地形高度、云层分布）用程序化，高频细节（法线、颜色纹理）用预计算纹理。
</Callout>

<Callout type="trap">
**误区：fbm 的 octave 数越多越好。**
octave 数增加，频率翻倍振幅减半，高 octave 的贡献越来越小（amplitude = 0.5^N）。通常 4-6 个 octave 就够，更多只增加 ALU 开销而视觉差异微乎其微。应根据纹理用途和平台性能选择 octave 数。
</Callout>

<Exercises>
**问题 1**：Perlin 噪声和 Worley 噪声的区别是什么？各适合什么纹理？

<Answer>
Perlin 噪声是梯度噪声：在网格顶点定义随机梯度向量，在网格内用平滑插值计算梯度点积，产生连续平滑的噪声值。适合云雾、大理石、地形高度等需要平滑过渡的纹理。Worley 噪声是细胞噪声：在空间中随机散布特征点，计算每个位置到最近特征点的距离，产生蜂窝状/细胞状结构。适合水面波纹、岩石裂纹、龟裂地面等需要离散细胞结构的纹理。
</Answer>

**问题 2**：fbm 的原理是什么？为什么能产生自然纹理？

<Answer>
fbm（Fractal Brownian Motion）叠加多层不同频率和振幅的噪声：value = sum(amplitude^i * noise(frequency^i * p))。每层频率翻倍（细节增加），振幅减半（贡献减小）。自然界的许多现象（山脉、云层、海岸线）具有分形特征——不同尺度下有相似的细节结构。fbm 通过叠加多尺度噪声模拟这种自相似性：低频层提供大结构（山脉走向），高频层提供小细节（岩石纹理），合成产生自然的分形纹理。通常 4-6 个 octave 足够，更多 octave 的振幅贡献可忽略。
</Answer>
