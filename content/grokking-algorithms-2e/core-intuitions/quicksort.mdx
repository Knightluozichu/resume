## 从1680乘640的土地开始

先预测：一块1680乘640的长方形土地，要切成尽可能大的同尺寸正方形并铺满，不留余地。第一刀切出640乘640后，剩下的1040乘640仍不是正方形；怎样继续，最后的正方形边长是多少？

不是某一个固定算法，而是解决新问题的思考方法。原章先用土地分块说明：切掉当前能处理的正方形后，剩余部分仍是“把矩形切成最大同尺寸正方形”的同一种问题，只是尺寸更小。

<DivideConquerFarmDiagram />

持续处理余下矩形，边长问题等价于反复求余，最终得到80。重点不是记住1680、640和80，而是识别两个设计动作：先确定能直接回答的最小情形，再把当前输入变成严格更小的同类输入。

## 分治先找基线，再决定怎样缩小

决定递归在哪里停止；决定怎样继续。分治先确定基线条件，因为没有终点，后续拆分无法证明会停止。

必须可度量。土地问题中，余下矩形至少一边缩短；数组问题中，可以删除一个元素或把数组分成更短区间。每一步都应回答：

1. 最简单的合法输入是什么？
2. 怎样把当前输入缩小到更容易解决的规模？
3. 子问题返回后，怎样得到当前问题答案？
4. 缩小是否对所有递归路径都成立？


## 递归求数组元素之和

数组求和可用分治描述：空数组之和为0；非空数组之和等于首元素加上剩余数组之和。下面用下标避免Python切片在每层复制新列表：

```python
from collections.abc import Sequence

def recursive_sum(values: Sequence[int], index: int = 0) -> int:
    if index == len(values):
        return 0
    return values[index] + recursive_sum(values, index + 1)

assert recursive_sum([]) == 0
assert recursive_sum([2, 4, 6]) == 12
```


递归求数组元素之和把长度为 `n` 的问题缩成长度为 `n-1` 的问题。每个元素读取一次，时间为 `Theta(n)`；同时存在的调用帧最多为 `n+1`，附加调用栈空间为 `Theta(n)`。循环求和同样是线性时间，却只需常数个循环状态。

若写成 `values[0] + recursive_sum(values[1:])`，伪代码很清楚，但Python的 `values[1:]` 会复制切片。所有层复制长度之和可能达到平方级。分析实际代码时，要把语言容器操作的成本也算进去，不能只数递归调用次数。


## 归纳思维：为什么较小问题足以支撑当前问题

与递归代码结构相呼应。对数组求和：

- 基线：空数组返回0，正确。
- 归纳假设：从 `index+1` 开始的后缀和能正确返回。
- 归纳步骤：当前函数返回 `values[index]` 加正确的后缀和，因此当前后缀也正确。

这个论证不是说“函数调用自己，所以正确”，而是把正确性建立在严格更小的问题上。快速排序也使用同样结构：长度小于2的数组已经有序；若两个更小分区能正确排序，且分区关系成立，拼接结果就整体有序。

## 快速排序：选择基准、分区、递归

对长度小于2的数组直接返回。对更长数组，先，英文常称pivot；然后执行。

以下版本用于展示书中的算法结构。它取第一个元素为基准，创建两个新列表；相等元素放入左组，避免遗漏重复值：

```python
from collections.abc import Sequence

def quicksort(values: Sequence[int]) -> list[int]:
    if len(values) < 2:
        return list(values)

    pivot = values[0]
    lower_or_equal = [value for value in values[1:] if value <= pivot]
    greater = [value for value in values[1:] if value > pivot]

    return quicksort(lower_or_equal) + [pivot] + quicksort(greater)
```


把元素分成小于基准和大于基准两组后，两组内部仍可能无序，因此还要递归排序两个分区。由于左组每项不大于基准，右组每项大于基准，若递归结果各自有序，则“有序左组 + 基准 + 有序右组”整体有序。

复制分区版没有在原数组中把pivot交换到某个下标，而是返回新列表；它会分配 `lower_or_equal`、`greater` 和拼接结果。常见原地快速排序使用Lomuto或Hoare等分区方案，修改原数组并有不同的不变量。两类实现都叫快速排序，但空间、稳定性和“基准是否已经处于原数组最终位置”的叙述不能混用。


## 平衡分区：每层线性工作

一次分区要比较当前子数组中的元素，成本与子数组长度同阶。若每次基准大致位于中间，递归树每下降一层，子数组规模约减半；高度约为 `log₂n`。同一层所有不相交子数组的长度总和仍为 `n`，所以每层总工作为 `Theta(n)`：

$$
T(n)=2T(n/2)+cn
\quad\Longrightarrow\quad
T(n)=\Theta(n\log n).
$$

这解释快速排序平均O(n log n)的来源。更严谨地说，对于随机选择基准的版本，对任意固定输入排列，期望运行时间为 `Theta(n log n)`；“平均情况”必须说明随机性来自输入分布还是算法自己的随机选择。

不要求每次正好一半，只要长期没有持续产生极端的一边空、一边接近原规模，递归树就能保持较低高度。

## 持续失衡：退化为平方时间

若已排序数组总选择第一个元素作为基准，每次可能得到空分区和长度 `n-1` 的分区。递归树退化为链，高度为 `Theta(n)`：

$$
T(n)=T(n-1)+cn
\quad\Longrightarrow\quad
T(n)=\Theta(n^2).
$$

这就是快速排序最坏O(n²)。偶尔出现并不可怕；危险是输入与固定选择规则相互作用，导致许多层持续失衡。

递归栈高度取决于分区平衡：平衡时活动调用深度为 `Theta(log n)`，持续极端失衡时可达 `Theta(n)`。高质量原地实现还会先递归较小分区、循环处理较大分区，把最坏调用栈控制得更稳；时间最坏情况与栈深度是相关但可分别改进的指标。


## 随机基准与归并排序

可在每个子数组中均匀随机选择基准。随机选择基准降低持续失衡风险，因为输入顺序不再能稳定预测每次基准；它给出良好的期望复杂度，却不删除理论上的最坏分区序列，也不能用一个简单的独立乘方概率草率证明“最坏不可能”。

```python
from random import Random

def randomized_quicksort(values: list[int], rng: Random) -> list[int]:
    if len(values) < 2:
        return values.copy()

    pivot_index = rng.randrange(len(values))
    pivot = values[pivot_index]
    remaining = values[:pivot_index] + values[pivot_index + 1:]
    lower_or_equal = [value for value in remaining if value <= pivot]
    greater = [value for value in remaining if value > pivot]
    return (
        randomized_quicksort(lower_or_equal, rng)
        + [pivot]
        + randomized_quicksort(greater, rng)
    )

assert randomized_quicksort([3, 1, 3, 2], Random(7)) == [1, 2, 3, 3]
```

始终O(n log n)，因为它按位置对半分割，不依赖元素值决定子问题规模。常见数组归并实现需要 `Theta(n)` 辅助空间并可保持稳定；常见原地快排额外数组空间较少但通常不稳定。复制分区快排则同样会申请新数组，不能用“快排原地”概括所有实现。

解释了为什么大O相同也可能有不同常数因子。平均快排和归并排序同为 `Theta(n log n)`，但比较、移动、分配、缓存局部性、稳定性和最坏延迟要求不同。先用渐近复杂度排除增长过快方案，再以真实实现和工作负载测量。


## 原章概念回查

分而治之先确定能直接回答的基线，再把问题缩小到更容易解决的规模。递归求数组元素之和展示了“当前元素加更短后缀之和”的通用分治结构。

快速排序选择基准值，然后把元素分成小于基准和大于基准两组，最后递归排序两个分区。平衡时快速排序平均O(n log n)，持续失衡时快速排序最坏O(n²)，所以必须明确平均情况与最坏情况。

随机选择基准降低持续失衡风险，但不抹去理论最坏情况。递归栈高度取决于分区平衡：平衡树约为对数高度，退化链为线性高度。归并排序始终O(n log n)，但大O相同也可能有不同常数因子，还要比较空间、稳定性与访问模式。

## 本章回顾

1. 分而治之先找基线条件，再构造严格更小的同类问题。
2. 土地分块展示余下矩形如何继续同一种求解。
3. 递归数组求和以空数组为基线，每层处理一个元素。
4. Python切片会复制，实际成本不能只看伪代码层数。
5. 快速排序选择基准、分区，再递归排序两个分区。
6. 复制分区版与原地分区版有不同空间和不变量。
7. 平衡递归树每层工作为线性，高度为对数。
8. 随机基准快排的期望时间为 `Theta(n log n)`。
9. 持续极端失衡让时间退化为 `Theta(n²)`。
10. 调用栈高度随分区平衡从对数变为线性。
11. 归并排序有确定的 `Theta(n log n)` 时间上界。
12. 渐近量级相同不代表常数、空间和稳定性相同。
