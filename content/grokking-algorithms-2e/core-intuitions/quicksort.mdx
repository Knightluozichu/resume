## 从1680乘640的土地开始

先预测：一块1680乘640的长方形土地，要切成尽可能大的同尺寸正方形并铺满，不留余地。第一刀切出640乘640后，剩下的1040乘640仍不是正方形；怎样继续，最后的正方形边长是多少？

<Term def="把问题递归地缩小为一个或多个同结构子问题，再组合子问题答案的通用策略。">分而治之</Term>不是某一个固定算法，而是解决新问题的思考方法。原章先用土地分块说明：切掉当前能处理的正方形后，剩余部分仍是“把矩形切成最大同尺寸正方形”的同一种问题，只是尺寸更小。

<DivideConquerFarmDiagram />

持续处理余下矩形，边长问题等价于反复求余，最终得到80。重点不是记住1680、640和80，而是识别两个设计动作：先确定能直接回答的最小情形，再把当前输入变成严格更小的同类输入。

## 分治先找基线，再决定怎样缩小

<Term def="无需继续分解即可直接求解的最小问题。">基线条件</Term>决定递归在哪里停止；<Term def="把当前问题交给更小同类问题并组合答案的分支。">递归条件</Term>决定怎样继续。分治先确定基线条件，因为没有终点，后续拆分无法证明会停止。

<Term def="让输入规模严格减少并保持问题类型不变的转换。">缩小步骤</Term>必须可度量。土地问题中，余下矩形至少一边缩短；数组问题中，可以删除一个元素或把数组分成更短区间。每一步都应回答：

1. 最简单的合法输入是什么？
2. 怎样把当前输入缩小到更容易解决的规模？
3. 子问题返回后，怎样得到当前问题答案？
4. 缩小是否对所有递归路径都成立？

<Stepper>
  <Step title="写出最小合法输入"><DivideConquerFarmDiagram />先说明空集合、单元素或可整除矩形怎样直接回答。</Step>
  <Step title="选择缩小度量">用元素个数、区间长度或矩形短边描述规模，确保它不能无限下降。</Step>
  <Step title="构造同类子问题">删除一个元素或保留余下矩形，检查子问题的输入输出契约与原问题一致。</Step>
  <Step title="写出组合规则">说明子问题答案怎样与当前元素、基准值或已切方块组合为完整答案。</Step>
</Stepper>

## 递归求数组元素之和

数组求和可用分治描述：空数组之和为0；非空数组之和等于首元素加上剩余数组之和。下面用下标避免Python切片在每层复制新列表：

```python
from collections.abc import Sequence

def recursive_sum(values: Sequence[int], index: int = 0) -> int:
    if index == len(values):
        return 0
    return values[index] + recursive_sum(values, index + 1)

assert recursive_sum([]) == 0
assert recursive_sum([2, 4, 6]) == 12
```

<RecursiveSumLab />

递归求数组元素之和把长度为 `n` 的问题缩成长度为 `n-1` 的问题。每个元素读取一次，时间为 `Theta(n)`；同时存在的调用帧最多为 `n+1`，附加调用栈空间为 `Theta(n)`。循环求和同样是线性时间，却只需常数个循环状态。

若写成 `values[0] + recursive_sum(values[1:])`，伪代码很清楚，但Python的 `values[1:]` 会复制切片。所有层复制长度之和可能达到平方级。分析实际代码时，要把语言容器操作的成本也算进去，不能只数递归调用次数。

<Callout type="trap" title="伪代码有n层，所以任何语言实现都是O(n)">
若每层还复制长度递减的切片，总复制量是 `n+(n-1)+...+1`。用下标或半开区间传递边界，才能让每层除递归调用外只做常数工作。
</Callout>

## 归纳思维：为什么较小问题足以支撑当前问题

<Term def="先证明最小情形，再假设较小规模成立并据此证明当前规模的证明方法。">归纳证明</Term>与递归代码结构相呼应。对数组求和：

- 基线：空数组返回0，正确。
- 归纳假设：从 `index+1` 开始的后缀和能正确返回。
- 归纳步骤：当前函数返回 `values[index]` 加正确的后缀和，因此当前后缀也正确。

这个论证不是说“函数调用自己，所以正确”，而是把正确性建立在严格更小的问题上。快速排序也使用同样结构：长度小于2的数组已经有序；若两个更小分区能正确排序，且分区关系成立，拼接结果就整体有序。

## 快速排序：选择基准、分区、递归

<Term def="通过选择基准、分区并递归排序两个分区完成排序的分治算法。">快速排序</Term>对长度小于2的数组直接返回。对更长数组，先<Term def="快速排序中用于比较并把其余元素分到两侧的参照元素。">选择基准值</Term>，英文常称pivot；然后执行<Term def="扫描其余元素并按与基准的比较结果划分为两个集合的过程。">分区</Term>。

以下版本用于展示书中的算法结构。它取第一个元素为基准，创建两个新列表；相等元素放入左组，避免遗漏重复值：

```python
from collections.abc import Sequence

def quicksort(values: Sequence[int]) -> list[int]:
    if len(values) < 2:
        return list(values)

    pivot = values[0]
    lower_or_equal = [value for value in values[1:] if value <= pivot]
    greater = [value for value in values[1:] if value > pivot]

    return quicksort(lower_or_equal) + [pivot] + quicksort(greater)
```

<QuickSortPartitionLab />

把元素分成小于基准和大于基准两组后，两组内部仍可能无序，因此还要递归排序两个分区。由于左组每项不大于基准，右组每项大于基准，若递归结果各自有序，则“有序左组 + 基准 + 有序右组”整体有序。

复制分区版没有在原数组中把pivot交换到某个下标，而是返回新列表；它会分配 `lower_or_equal`、`greater` 和拼接结果。常见原地快速排序使用Lomuto或Hoare等分区方案，修改原数组并有不同的不变量。两类实现都叫快速排序，但空间、稳定性和“基准是否已经处于原数组最终位置”的叙述不能混用。

<Stepper>
  <Step title="检查基线"><QuickSortPartitionLab />长度0或1的序列已排序，直接返回副本，不再选基准。</Step>
  <Step title="选择一个基准">从当前子数组取参照元素；选择策略会影响后续两个分区是否持续失衡。</Step>
  <Step title="扫描并建立分区">每个非基准元素恰好进入一个分区，确认重复值不会丢失。</Step>
  <Step title="递归并拼接">分别排序两个更小分区，再按左、基准、右的比较关系组合结果。</Step>
</Stepper>

## 平衡分区：每层线性工作

一次分区要比较当前子数组中的元素，成本与子数组长度同阶。若每次基准大致位于中间，递归树每下降一层，子数组规模约减半；高度约为 `log₂n`。同一层所有不相交子数组的长度总和仍为 `n`，所以每层总工作为 `Theta(n)`：

$$
T(n)=2T(n/2)+cn
\quad\Longrightarrow\quad
T(n)=\Theta(n\log n).
$$

这解释快速排序平均O(n log n)的来源。更严谨地说，对于随机选择基准的版本，对任意固定输入排列，期望运行时间为 `Theta(n log n)`；“平均情况”必须说明随机性来自输入分布还是算法自己的随机选择。

<Term def="两个子问题规模处于同一数量级，使递归树保持对数高度的分区结果。">平衡分区</Term>不要求每次正好一半，只要长期没有持续产生极端的一边空、一边接近原规模，递归树就能保持较低高度。

## 持续失衡：退化为平方时间

若已排序数组总选择第一个元素作为基准，每次可能得到空分区和长度 `n-1` 的分区。递归树退化为链，高度为 `Theta(n)`：

$$
T(n)=T(n-1)+cn
\quad\Longrightarrow\quad
T(n)=\Theta(n^2).
$$

这就是快速排序最坏O(n²)。<Term def="某次分区产生一个极小分区和一个接近原规模分区的结果。">失衡分区</Term>偶尔出现并不可怕；危险是输入与固定选择规则相互作用，导致许多层持续失衡。

递归栈高度取决于分区平衡：平衡时活动调用深度为 `Theta(log n)`，持续极端失衡时可达 `Theta(n)`。高质量原地实现还会先递归较小分区、循环处理较大分区，把最坏调用栈控制得更稳；时间最坏情况与栈深度是相关但可分别改进的指标。

  <Step title="计算平衡高度">规模每层减半，直到1，共约log₂n层；线性层成本乘高度得到n log n。</Step>

普通快速排序有平方级最坏情况。写复杂度时要区分期望、平均与最坏，并说明基准选择策略、输入假设和分区实现。
</Callout>

## 随机基准与归并排序

<Term def="运行过程中使用随机选择来降低固定输入触发系统性坏行为概率的算法。">随机化算法</Term>可在每个子数组中均匀随机选择基准。随机选择基准降低持续失衡风险，因为输入顺序不再能稳定预测每次基准；它给出良好的期望复杂度，却不删除理论上的最坏分区序列，也不能用一个简单的独立乘方概率草率证明“最坏不可能”。

```python
from random import Random

def randomized_quicksort(values: list[int], rng: Random) -> list[int]:
    if len(values) < 2:
        return values.copy()

    pivot_index = rng.randrange(len(values))
    pivot = values[pivot_index]
    remaining = values[:pivot_index] + values[pivot_index + 1:]
    lower_or_equal = [value for value in remaining if value <= pivot]
    greater = [value for value in remaining if value > pivot]
    return (
        randomized_quicksort(lower_or_equal, rng)
        + [pivot]
        + randomized_quicksort(greater, rng)
    )

assert randomized_quicksort([3, 1, 3, 2], Random(7)) == [1, 2, 3, 3]
```

<Term def="把序列递归分半排序，再线性合并两个有序结果的分治排序算法。">归并排序</Term>始终O(n log n)，因为它按位置对半分割，不依赖元素值决定子问题规模。常见数组归并实现需要 `Theta(n)` 辅助空间并可保持稳定；常见原地快排额外数组空间较少但通常不稳定。复制分区快排则同样会申请新数组，不能用“快排原地”概括所有实现。

<Term def="渐近记号忽略、但会影响相同增长阶算法实际耗时的固定倍率与单步成本。">常数因子</Term>解释了为什么大O相同也可能有不同常数因子。平均快排和归并排序同为 `Theta(n log n)`，但比较、移动、分配、缓存局部性、稳定性和最坏延迟要求不同。先用渐近复杂度排除增长过快方案，再以真实实现和工作负载测量。

<Callout type="trap" title="随机选择基准就消除了最坏情况">
随机化降低固定输入持续命中坏基准的风险，并给出期望 `Theta(n log n)`；它没有让极端分区序列在数学上消失。需要确定最坏 `O(n log n)` 时，应选择有该保证的算法或内省排序等混合策略。
</Callout>

## 原章概念回查

分而治之先确定能直接回答的基线，再把问题缩小到更容易解决的规模。递归求数组元素之和展示了“当前元素加更短后缀之和”的通用分治结构。

快速排序选择基准值，然后把元素分成小于基准和大于基准两组，最后递归排序两个分区。平衡时快速排序平均O(n log n)，持续失衡时快速排序最坏O(n²)，所以必须明确平均情况与最坏情况。

随机选择基准降低持续失衡风险，但不抹去理论最坏情况。递归栈高度取决于分区平衡：平衡树约为对数高度，退化链为线性高度。归并排序始终O(n log n)，但大O相同也可能有不同常数因子，还要比较空间、稳定性与访问模式。

## 本章回顾

1. 分而治之先找基线条件，再构造严格更小的同类问题。
2. 土地分块展示余下矩形如何继续同一种求解。
3. 递归数组求和以空数组为基线，每层处理一个元素。
4. Python切片会复制，实际成本不能只看伪代码层数。
5. 快速排序选择基准、分区，再递归排序两个分区。
6. 复制分区版与原地分区版有不同空间和不变量。
7. 平衡递归树每层工作为线性，高度为对数。
8. 随机基准快排的期望时间为 `Theta(n log n)`。
9. 持续极端失衡让时间退化为 `Theta(n²)`。
10. 调用栈高度随分区平衡从对数变为线性。
11. 归并排序有确定的 `Theta(n log n)` 时间上界。
12. 渐近量级相同不代表常数、空间和稳定性相同。

<Exercises>

**问题 1：用分治写出求数组最大值的基线条件和递归条件。**

<Answer>可把单元素数组作为基线，最大值就是该元素；对更长数组，比较首元素与剩余数组的递归最大值并返回较大者。还应拒绝空数组或为它定义明确的哨兵契约。</Answer>

**问题 2：复制分区版对 `[5, 3, 8, 4, 2, 7, 1, 10]` 做一次分区，两个组是什么？**

<Answer>取5为基准，小于等于组为 `[3,4,2,1]`，大于组为 `[8,7,10]`。两组内部尚未排序，需要递归；最终结果按“有序左组、5、有序右组”拼接。</Answer>

**问题 3：为什么已升序数组配合“总选首元素”会退化？随机基准改善了什么？**

<Answer>首元素每次都是最小值，产生空分区和长度少1的分区，递归树成为线性链，扫描总量为平方级。随机基准打破输入顺序与选择规则的固定关联，使期望树高为对数，但仍保留理论最坏情况。</Answer>

**问题 4：归并排序和快速排序都写作O(n log n)时，还应比较哪些指标？**

<Answer>应区分期望与最坏保证，再比较额外空间、稳定性、比较和移动常数、内存分配、缓存局部性、递归栈高度以及真实数据分布。还要明确讨论的是复制分区快排还是原地实现。</Answer>

</Exercises>
