## 线性回归

用直线或超平面拟合数据。原章以房屋面积和售价为例：在散点间拟合一条趋势线，再把3000平方英尺代入，得到一个起始价格预测。

一元模型写成 `y = intercept + slope * x`。下面用最小二乘闭式公式拟合斜率和截距；生产使用还要划分训练/验证数据、检查异常值与残差，并给出误差区间，不能把一条线当成因果证明。

```python
from statistics import fmean

def fit_line(xs: list[float], ys: list[float]) -> tuple[float, float]:
    if len(xs) != len(ys) or len(xs) < 2:
        raise ValueError("need paired observations")
    x_mean = fmean(xs)
    y_mean = fmean(ys)
    denominator = sum((x - x_mean) ** 2 for x in xs)
    if denominator == 0:
        raise ValueError("x values need variation")
    slope = sum(
        (x - x_mean) * (y - y_mean) for x, y in zip(xs, ys)
    ) / denominator
    intercept = y_mean - slope * x_mean
    return intercept, slope

areas = [1200, 1800, 2400, 3200]
prices = [240000, 315000, 390000, 510000]
intercept, slope = fit_line(areas, prices)
predicted_3000 = intercept + slope * 3000
```

多特征时，输入从一个面积数值变成面积、卧室数、地段等向量，直线推广为超平面。线性模型适合建立可解释基线；若关系明显非线性、误差分布或外推范围不合理，就要改特征、模型或评估假设。

## 倒排索引

从词映射到包含它的文档。普通文档存储回答“这个页面有哪些词”，倒排索引把方向反过来，回答“这个词在哪些页面”。搜索引擎使用倒排索引，不必为每次查询重新扫描所有网页。

```python
import re
from collections import defaultdict

def tokenize(text: str) -> list[str]:
    return re.findall(r"[a-z0-9]+", text.lower())

def build_inverted_index(
    documents: dict[str, str]
) -> dict[str, list[str]]:
    postings: dict[str, set[str]] = defaultdict(set)
    for document_id, text in documents.items():
        for term in tokenize(text):
            postings[term].add(document_id)
    return {
        term: sorted(document_ids)
        for term, document_ids in postings.items()
    }

documents = {
    "doc1": "hi algorithm",
    "doc2": "algorithm music",
    "doc3": "hi music",
}
index = build_inverted_index(documents)
assert index["hi"] == ["doc1", "doc3"]
```

真实搜索还要存词频、位置、字段、文档长度与更新信息，以支持短语查询和相关性排序。分词规则依赖语言；删除或修改文档时也要更新posting list。索引用额外存储和构建成本换取低延迟查询。


## 傅里叶变换

把信号分解成频率成分。时域波形难以直接看出低音、高音或周期噪声，频域表示能显示各频率贡献；图像也可按空间频率分析平滑区域与细节。

傅里叶变换用于音频压缩与信号分析，但“做一次变换”本身不会自动压缩。压缩系统通常还要利用人类感知、量化不重要系数并熵编码；有损阶段带来不可逆误差。快速傅里叶变换是高效计算离散傅里叶变换的一族算法，常见复杂度为 `O(n log n)`。

## 并行算法

把工作拆到多个处理器。数组分块求和、图像分块处理或批量模型推理都可能并行，但不是把核心数乘上去就得到同比加速。

并行加速受串行部分与通信开销限制。若程序比例 `s` 必须串行，使用 `p` 个处理器的理想加速上界可用Amdahl形式理解：`1 / (s + (1-s)/p)`。同步、数据复制、缓存竞争、负载不均和任务调度还会进一步降低实际收益。

## MapReduce

包含map和reduce两个阶段，中间还有按键分区、排序与shuffle。map把输入转换为中间键值对，reduce按键聚合中间结果。

经典词频例子中，每个文档可独立map；系统把相同单词的1发送到同一reduce，再求和：

```python
from collections import defaultdict

def map_words(document: str) -> list[tuple[str, int]]:
    return [(word, 1) for word in tokenize(document)]

def reduce_counts(
    pairs: list[tuple[str, int]]
) -> dict[str, int]:
    grouped: dict[str, list[int]] = defaultdict(list)
    for key, value in pairs:
        grouped[key].append(value)
    return {
        key: sum(values)
        for key, values in grouped.items()
    }

mapped = [
    pair
    for document in documents.values()
    for pair in map_words(document)
]
assert reduce_counts(mapped) == {"hi": 2, "algorithm": 2, "music": 2}
```

这个本地模拟省略了分布式系统最昂贵的部分：shuffle网络传输、失败重试、数据倾斜和落盘。MapReduce适合可分区的大规模批处理，不是低延迟交互查询的默认答案。

## Bloom过滤器与HyperLogLog

用于回答“元素可能存在还是肯定不存在”。插入时把多个哈希位置设为1；查询时只要某一位为0，就确定未插入，若全部为1则只表示“可能存在”。

Bloom过滤器允许假阳性但不允许假阴性，这一结论有条件：使用同一哈希方案、只做正确插入与查询、位数组未损坏且不直接清位删除。标准Bloom过滤器清除共享位会制造假阴性；若需要删除，应使用计数Bloom等变体并遵守其计数规则。

近似统计不同元素数量。它对哈希值前导零等统计特征做分桶估计，不存储所有原元素，因此可在流式数据中低内存估算独立用户数。输出带统计误差，不能列出这些用户，也不能回答某个具体用户是否出现。


## SHA与局部敏感哈希

生成固定长度摘要。密码学哈希追求原像困难、第二原像困难和抗碰撞等性质，输入微小变化应显著改变摘要。SHA不是加密：摘要不可用密钥正常解密回原文，也不提供保密性。

文件完整性可比较可信渠道提供的摘要；数字签名通常对消息摘要签名，但完整安全方案还涉及算法版本、密钥与证书。密码存储不能只做一次快速SHA，应使用带盐、专为口令设计且成本可调的口令哈希方案。

寻找近似相似项。它与SHA目标几乎相反：SHA希望相近输入的摘要也不可预测地不同，LSH希望相似向量更可能碰撞，以快速生成候选，再做精确距离验证。

## Diffie-Hellman密钥交换

在公开信道协商共享秘密。双方交换公开值，各自用私有值计算出相同结果；窃听者看到公开参数与公开值，但在所选困难问题假设下难以恢复共享秘密。

协商结果通常送入密钥派生函数，再用于认证加密，而不是直接当消息或密码。基本Diffie-Hellman不认证通信对端，中间人可分别与双方建立秘密；实际协议必须结合签名、证书、预共享密钥或其他身份认证。

## 线性规划

在线性约束下优化线性目标。例如工厂决定两种产品产量，目标是最大利润，约束是工时、原料和需求上限；变量、目标与约束都保持线性。

连续变量模型可用成熟求解器高效处理大量实际问题。若产量必须取整数，模型变成整数线性规划，求解难度可能显著增加；若目标或约束非线性，也需要其他优化方法。建模时先写变量、目标、约束和单位，再选择求解器。


## 按问题领域选择路线

后续学习应按问题领域选择路线：

- 连续预测与可解释基线：深入统计、线性代数、回归诊断和机器学习评估。
- 全文检索：深入分词、posting压缩、BM25、向量检索与混合排序。
- 音频图像与科学计算：学习复数、采样、卷积、FFT和数字信号处理。
- 大规模计算：学习并发正确性、分布式存储、数据分区、容错和流处理。
- 概率数据结构：学习误差界、参数选择、合并语义与线上监控。
- 安全系统：从经过审查的协议和库入手，系统学习认证、密钥管理与威胁模型。
- 运筹优化：学习线性规划对偶、整数规划、网络流与求解器建模。

本章每个入口都能扩展成一门课。最有效的顺序是先选一个正在解决的问题，写清所需输出、允许误差、数据规模、延迟和安全约束，再沿对应路线深入并用成熟实现验证。

## 本章回顾

1. 线性回归为连续值关系建立直线或超平面基线。
2. 倒排索引把词项映射到文档列表，加速关键词检索。
3. 傅里叶变换提供频域表示，压缩还需量化与编码。
4. 并行加速受串行比例、通信、同步和负载均衡约束。
5. MapReduce以map、shuffle、reduce处理可分区批任务。
6. Bloom过滤器做近似成员查询，阳性需要权威存储确认。
7. HyperLogLog用小内存近似不同元素数量。
8. SHA是固定长度密码学摘要，不是可逆加密。
9. LSH用概率碰撞生成相似候选，与SHA安全目标不同。
10. Diffie-Hellman协商秘密但本身不认证对端。
11. 线性规划要求目标和约束线性，整数变量会改变问题类别。
12. 后续学习路线应由真实问题、误差、规模、延迟和安全要求决定。
