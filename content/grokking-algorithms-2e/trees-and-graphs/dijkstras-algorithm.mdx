## 直觉引入

打开手机地图，输入起点和终点。地图不会让你绕遍全城来比较每条路——它高效地算出一条最短路径。你自己开车时面对路网也不会这样傻：你知道有些路更短有些路更长，你会优先探索看起来代价最小的方向。

狄克斯特拉算法就是导航引擎的心脏。它面对一张<strong>带权重的图</strong>——每条边不是「走一秒」，而是有具体的长度（10 公里、3 分钟、5 块钱）——然后一步步找出从起点到所有节点的最短路径。它的策略很朴素：每次从「还没确定最短路径的节点」里挑一个当前代价最小的，锁定它，再用它的好消息去<strong>松弛</strong>它的邻居。

这章解决的核心问题：在有不同边权重的图上，如何找到真实的「最省代价」路径？BFS 只能找到边数最少的路，但带权图里「边少 ≠ 代价低」。

## 概念讲解

### 带权图与最短路径问题

<Term def="每条边都标有一个数值权重（距离、时间、费用等）的图。最短路径是权重之和最小的路径。">带权图</Term>是现实世界问题的最自然建模方式。道路长度不同、红绿灯等待时间不同、过路费不同——这些差异由边上的权重来体现。

<Term def="每次都选当前看起来最优的选项，不回溯。狄克斯特拉的贪心体现在「每次锁定代价最小的未处理节点」。">贪心策略</Term>是狄克斯特拉的决策哲学。它不事先规划整条路径，而是每一步都做当下最好的选择：在未锁定的节点中，选一个当前已知代价最小的。这个节点一旦锁定，它的最短路径就确定了——不会再被后续更新推翻。

<DijkstraDiagram />

看图：每个节点旁标注了从起点出发的当前最短代价。绿色是已锁定节点（代价已确定，不再变化），橙色是当前被选中锁定的节点。虚线标注了松弛操作——邻居代价可能被当前节点更新。

### 松弛：狄克斯特拉的核心操作

<Term def="检查是否可以通过当前节点找到一条到邻居的更短路径。公式：如果 dist[current] + weight(current, neighbor) < dist[neighbor]，则更新 dist[neighbor]。">松弛</Term>这个名字很形象——绷紧的绳子被「松一松」，看能不能找到更短的路径。每次锁定一个节点后，检查它的所有邻居：如果「走到当前节点 + 从当前节点走到邻居」的总代价小于邻居已知的代价，就更新邻居的代价并记录当前节点为邻居的前驱。

狄克斯特拉算法的流程：
1. 初始化：起点代价为 0，其他所有节点代价为无穷大（∞）。所有节点都是未锁定状态。
2. 从未锁定节点中选出当前代价最小的，锁定它。
3. 对刚锁定节点的每个邻居执行松弛：尝试用「锁定节点代价 + 边权重」更新邻居的代价。
4. 重复 2–3，直到所有节点都被锁定（或目标节点被锁定时可提前结束）。

## 数学推导

### 符号表

| 符号 | 含义 |
|------|------|
| s | 起点 |
| d[v] | 从起点到节点 v 的当前已知最短代价 |
| w(u, v) | 从节点 u 到节点 v 的边的权重 |
| S | 已锁定（最短路径已确定）的节点集合 |
| relax(u, v) | 如果 d[u] + w(u, v) &lt; d[v]，则 d[v] = d[u] + w(u, v) |

### 松弛公式与正确性直觉

松弛操作的核心公式：

$$d[v] = \min(d[v],\; d[u] + w(u, v))$$

这个式子在说：我们已知从起点到 u 的最好路径代价是 d[u]，从 u 到 v 有一条权重为 w(u, v) 的边。那么可以凑出一条新路线：「到 u 的好路径」+「u→v 这一步」，总代价是 d[u] + w(u, v)。如果这个新路线比已知的 d[v] 更短，就更新 d[v]。

为什么锁定操作是安全的？因为所有边的权重都 ≥ 0：
- 每个被锁定的节点 u 是当前 S 之外代价最小的。
- 如果存在一条更短的路径到达 u，那条路径必须经过另一个未锁定节点 x。
- 但由于所有权重 ≥ 0，从起点到 x 的代价 ≤ 从起点经过 x 再到 u 的代价。
- 所以 d[x] ≤ d[u]——但这和我们选 u 为最小代价矛盾。

因此锁定节点的最短路径已经确定，后续不会被打脸。这个证明在出现负权边时就崩塌了。

### 为什么负权边会毁掉狄克斯特拉

设图：起点 s，节点 A，边 s→A 权重 5，边 A→s 权重 -10。按照狄克斯特拉：
1. 锁定 s（代价 0），松弛 A：d[A] = 0 + 5 = 5。
2. 锁定 A（代价 5），因为它是唯一的未锁定节点。
3. 松弛 s（已锁定，跳过）。

但我们知道：s→A→s 绕一圈只花 -5 的代价，可以无限绕圈让代价降到 -∞。更致命的是：即使不绕圈，狄克斯特拉锁定了 A 之后就不会再更新它的代价——即使后来发现更短的路径也来不及了。这就是狄克斯特拉的硬限制：<strong>所有边权重必须 ≥ 0</strong>。

$$
\text{狄克斯特拉适用前提：对所有边 } (u, v),\ w(u, v) \geq 0
$$

这个式子在说：只要你承诺每走一条边代价都不会减少（可以增加或不变），狄克斯特拉就能保证每一步的贪心选择都是全局正确的。如果存在负权边，需要贝尔曼-福特算法（Bellman-Ford）。

### 时间复杂度分析

用优先队列（最小堆）实现时，每次取出最小代价节点是 O(log V)，每个节点被取一次（V 次操作）；每条边触发一次可能的松弛和堆更新（E 次操作）。总复杂度：O((V+E) log V)。如果图很稠密（E ≈ V²），可退化到 O(V²) 用朴素数组实现。

## 常见误区

<Callout type="trap">
  <strong>现象 →</strong> 图中有负权边，狄克斯特拉给出错误结果。<strong>原因 →</strong> 狄克斯特拉的核心假设是「每加一条边，代价不会减少」。一旦锁定一个节点就不再撤销——但如果存在负权边，后面发现的路径可能回过来把已锁定节点的代价压低，而算法已经不能再改了。<strong>修法 →</strong> 存在负权边时用贝尔曼-福特算法（O(VE)）或 SPFA。检测负权回路可以用贝尔曼-福特多跑一轮看是否还有松弛发生。
</Callout>

<Callout type="trap">
  <strong>现象 →</strong> 用普通队列替代优先队列实现狄克斯特拉，性能退化。<strong>原因 →</strong> 狄克斯特拉的贪心选择要求「每次取最小代价节点」，普通队列是 FIFO 不会自动维护最小。如果每次取都要全量扫描找最小，每次取最低代价节点是 O(V)，总复杂度 O(V²)。<strong>修法 →</strong> 用最小堆实现的优先队列，取最小值 O(log V)，更新 O(log V)，总复杂 O((V+E) log V)。
</Callout>

## 小结与练习

- 狄克斯特拉算法 = 贪心（每次锁定最小代价节点）+ 松弛（用锁定节点的信息更新邻居代价）。
- 核心前提：所有边权重 ≥ 0。负权边会破坏贪心选择的正确性。
- 时间复杂度 O((V+E) log V)（优先队列实现），BFS 是其所有边权重相等时的特例。
- 松弛公式 d[v] = min(d[v], d[u] + w(u, v)) 是核心操作，每次锁定后对邻居执行。

    初始化 d[A]=0, d[B]=∞, d[C]=∞, d[D]=∞。锁定 A（0）→ 松弛：d[B]=4, d[C]=2。未锁定最小是 C（2）→ 锁定 C → 松弛：d[B]=min(4, 2+1)=3, d[D]=min(∞, 2+5)=7。未锁最小是 B（3）→ 锁定 B → 松弛：d[D]=min(7, 3+3)=6。锁定 D（6）。最终：A=0, B=3, C=2, D=6。
  </Answer>
  <Answer question="推导：如果图中存在一条负权边但没有负权回路，狄克斯特拉一定错吗？">
    不一定。如果狄克斯特拉在负权边的终点被锁定之前，先通过其他路径更新了该节点的代价并且那个路径的总代价恰好比「经过负权边过来的路径」更大，锁定后就不会再被更新，答案是错的。但如果负权边不影响锁定的先后顺序（很罕见），碰巧也能正确。不过实际中不应该依赖这种「碰巧」——有负权边就该换贝尔曼-福特。
  </Answer>
  <Answer question="怎样改造 BFS 让它变成狄克斯特拉？">
    BFS 的队列换成优先队列（最小堆）。BFS 的「距离加 1」换成「当前代价 + 边权重」。BFS 的「首次访问即最短」（无权成立）换成「只有锁定才确定最短」（贪心 + 非负保证）。改造后 BFS 就是狄克斯特拉在所有边权重 = 1 时的特例。
  </Answer>
</Exercises>

## 名词解释

<Glossary>
  <GlossaryItem term="狄克斯特拉算法">
    用贪心策略在非负权图上找单源最短路径的算法。每次锁定代价最小的未处理节点，再用松弛操作更新邻居代价。时间复杂度 O((V+E) log V)。详见「概念讲解」和「数学推导」节。
  </GlossaryItem>
  <GlossaryItem term="松弛">
    检查通过当前节点能否找到到邻居的更短路径：如果 d[u] + w(u, v) &lt; d[v]，更新 d[v]。这是狄克斯特拉的核心操作。详见「数学推导」节。
  </GlossaryItem>
  <GlossaryItem term="带权图">
    每条边标有权重的图。权重可以是距离、时间、费用等。狄克斯特拉处理带权图，BFS 只能处理无权图（或所有边权重相等的特例）。详见「概念讲解」节。
  </GlossaryItem>
  <GlossaryItem term="贪心策略">
    每次都做当下看起来最优的选择，不回溯。狄克斯特拉的贪心体现在「从未锁定节点中选代价最小的锁定」。在非负权图上，这个贪心选择恰好是全局最优的。详见「概念讲解」节。
  </GlossaryItem>
</Glossary>
