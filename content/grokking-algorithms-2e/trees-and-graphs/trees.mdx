## 从文件目录开始

先预测：从 `/home` 查找 `notes.txt`，进入 `docs` 后发现它不在第一个子目录中。程序如何记住“稍后还要回来检查其他目录”，又如何保证不会从一个文件走出两条不同的父路径？

第7章先建立树的术语，再运行深度优先搜索，最后用霍夫曼编码展示二叉树怎样承载真实算法。BST、AVL、伸展树和B树属于下一章；本章的“二叉树”只限制孩子数量，不包含键值排序规则。

<Term def="指定一个根节点，并从根解释父子层级关系的树。">有根树</Term>由节点和边组成。<Term def="有根树中没有父节点、作为所有层级起点的节点。">根节点</Term>引出其余节点；<Term def="某节点上一层的直接前驱。">父节点</Term>与<Term def="某节点下一层的直接后继。">子节点</Term>描述相对关系；<Term def="没有子节点的树节点。">叶节点</Term>位于分支末端。

有根树由根节点引出所有其他节点。根节点没有父节点，叶节点没有孩子；一个内部节点既可以是父节点，也可以是更高层节点的孩子。

## 文件目录形成树，但真实文件系统可能超出树

<Term def="用目录包含子目录与文件来组织路径的层级结构。">文件目录</Term>形成树：目录对应内部节点，文件常对应叶节点，从根目录到目标文件是一条层级路径。树模型让递归遍历自然成立，因为每个子目录仍是一个更小目录树。

教学模型通常忽略符号链接、硬链接、挂载点和循环链接。加入这些特性后，一个对象可能有多个入口，甚至形成环，结构就更接近一般图；此时遍历需要已访问集合、设备边界或链接策略。好模型必须明确抽掉了哪些真实特性。

```python
from dataclasses import dataclass, field
from collections.abc import Iterator

@dataclass
class TreeNode:
    name: str
    children: list["TreeNode"] = field(default_factory=list)

def dfs_recursive(node: TreeNode) -> Iterator[str]:
    yield node.name
    for child in node.children:
        yield from dfs_recursive(child)

tree = TreeNode(
    "/home",
    [
        TreeNode("docs", [TreeNode("notes.txt"), TreeNode("book.pdf")]),
        TreeNode("photos", [TreeNode("trip.jpg")]),
    ],
)

assert list(dfs_recursive(tree)) == [
    "/home", "docs", "notes.txt", "book.pdf", "photos", "trip.jpg"
]
```

严格树没有回边，也没有共享孩子，所以从父到子遍历时无需 `visited`。一旦输入可能是一般图，必须恢复第6章的已访问集合，否则递归可能沿环无限重复。

<Stepper>
  <Step title="标出根节点"><TreeAnatomyDiagram />选择唯一层级起点，确认其余节点都能从根沿孩子关系到达。</Step>
  <Step title="标出父子关系">每个非根节点恰有一个父节点；内部节点可同时拥有父节点和若干孩子。</Step>
  <Step title="识别叶节点">没有孩子的文件或末端目录是递归的自然基线，处理后直接返回。</Step>
  <Step title="检查模型边界">若存在链接、共享子树或环，把结构按一般图处理并加入去重策略。</Step>
</Stepper>

<Callout type="trap" title="目录长得像树，所以任何文件系统遍历都不需要visited">
符号链接可能指回祖先，硬链接或挂载也可能破坏单一父关系。只有确认输入满足严格树契约时，才能省略已访问集合。
</Callout>

## 深度优先搜索：沿一条分支走到底

<Term def="优先沿当前分支不断深入，无法继续时再回到最近未完成分叉点的遍历算法。">深度优先搜索</Term>简称DFS。DFS沿一条分支深入后回溯：先访问 `/home`，进入 `docs`，再到 `notes.txt`；叶子没有孩子，于是返回 `docs` 检查 `book.pdf`，完成后再返回 `/home` 进入 `photos`。

<Term def="从当前分支返回最近仍有未探索孩子的祖先，并继续其他分支的动作。">回溯</Term>不是“重新从根搜索”。递归实现中，尚未执行的循环位置保存在调用栈帧里；叶子返回后，上一帧从下一个孩子继续。

<DepthFirstTraversalLab />

DFS使用调用栈或显式栈。递归版依靠<Term def="保存活动函数调用和返回位置的后进先出结构。">调用栈</Term>；迭代版使用<Term def="由程序自行维护、保存待访问节点的后进先出容器。">显式栈</Term>：

```python
from collections.abc import Iterator

def dfs_iterative(root: TreeNode) -> Iterator[str]:
    stack = [root]

    while stack:
        node = stack.pop()
        yield node.name
        stack.extend(reversed(node.children))

assert list(dfs_iterative(tree)) == list(dfs_recursive(tree))
```

这里反转孩子列表，是因为栈后进先出：若希望左边孩子先访问，就要让右边孩子先压栈。去掉 `reversed` 不会让DFS失效，却会改变同层兄弟的访问顺序；测试若依赖顺序，应把孩子顺序写进契约。

<Stepper>
  <Step title="访问并压住返回点"><DepthFirstTraversalLab />处理当前节点；递归版创建帧，迭代版把待访问节点保存在显式栈。</Step>
  <Step title="选择第一个孩子">继续沿当前分支深入，不先处理同层其他节点。</Step>
  <Step title="叶节点触发返回">没有孩子时弹出当前状态，恢复最近仍有未访问孩子的父节点。</Step>
  <Step title="回溯直到栈空">每个孩子都完成后继续向上弹栈；根帧完成意味着整棵树遍历结束。</Step>
</Stepper>

## DFS与BFS的探索顺序

DFS与BFS的探索顺序不同。DFS用后进先出状态，优先增加深度；BFS用先进先出队列，优先处理同一深度。两者在树上都会访问每个节点一次，时间都是 `O(V)`，因为树有 `V-1` 条边。

DFS递归空间取决于树高 `h`，最深时保存 `O(h)` 个活动帧；显式栈的峰值取决于尚未处理的分支。BFS队列峰值通常取决于最宽一层。链状深树可能让递归DFS栈溢出，极宽浅树可能让BFS队列很大。

若目标是无权一般图的最少边数路径，使用BFS；若要遍历目录、求树的后序结果、检查一条路径后回退，DFS往往更贴合结构。在严格树中任意两点路径唯一，因此从根找到某节点后路径本身没有“另一条更短候选”，但发现顺序和内存峰值仍不同。

<Callout type="trap" title="DFS和BFS都会访问全部节点，所以可以随意互换">
完整遍历的渐近时间可能相同，但输出顺序、首次命中路径、前沿内存和可提前终止性质不同。先明确目标是最短层级、深层搜索还是完整处理，再选容器。
</Callout>

## 更严格地定义树

<Term def="任意两个节点之间都存在路径的图性质。">连通</Term>表示没有孤立分量；<Term def="从某节点出发沿不同边最终回到该节点的闭合路径。">环</Term>若不存在，图就是无环。对无向图，树是连通无环图。

这个定义带来等价性质：树中任意两节点只有一条简单路径。<Term def="除端点约定外不重复经过节点的路径。">简单路径</Term>若有两条，就能沿一条去、另一条回形成环；若没有路径，图又不连通。具有 `n` 个节点的树恰有 `n-1` 条边，新增一条边会形成环，删去一条边会断开。

<TreePropertyLab />

<Term def="每个节点至多拥有左、右两个孩子的树。">二叉树</Term>每个节点至多两个孩子。它不自动有序，也不自动平衡；“左孩子键更小、右孩子键更大”属于下一章的二叉搜索树约束。第7章用二叉树来表达每次读取0或1的霍夫曼编码。

## 霍夫曼编码：用路径长度分配比特

<Term def="根据符号频率构造二叉前缀码的无损压缩方法。">霍夫曼编码</Term>是无损压缩：编码后可恢复完全相同的符号序列。它不为所有字符分配固定长度，而是让<Term def="某符号在待编码数据或训练分布中出现的次数或概率。">字符频率</Term>决定编码长度，高频字符使用更短编码，低频字符使用更长编码。

构树时，先把每个字符作为带频率的叶节点放入最小优先队列；反复合并频率最小的两个节点，新父节点频率为二者之和，再放回队列。只剩一个根时，左边记0、右边记1，从根走到每个叶子就得到该字符编码。

<HuffmanCodingDiagram />

图中A频率5，获得1比特编码 `0`；B频率2，获得 `10`；C与D各频率1，获得3比特编码。固定长度表示4个字符需要每个2比特，共18比特；霍夫曼主体为15比特。真实文件还要让解码端获得码表或树，并考虑头部开销，小数据不一定因此变小。

<Term def="不同符号可使用不同位数的编码方案。">变长编码</Term>若任意字符码都不是另一个字符码的前缀，就构成<Term def="没有任何码字是其他码字前缀、可从左到右唯一解析的编码集合。">前缀码</Term>。前缀码保证无歧义解码：从根逐位走，抵达叶子就输出字符并回到根，不需要分隔符。

```python
from dataclasses import dataclass
from heapq import heapify, heappop, heappush
from itertools import count

@dataclass
class HuffmanNode:
    frequency: int
    symbol: str | None = None
    left: "HuffmanNode | None" = None
    right: "HuffmanNode | None" = None

def build_huffman(frequencies: dict[str, int]) -> HuffmanNode:
    if not frequencies or any(value <= 0 for value in frequencies.values()):
        raise ValueError("frequencies must be positive")

    serial = count()
    heap = [
        (frequency, next(serial), HuffmanNode(frequency, symbol))
        for symbol, frequency in frequencies.items()
    ]
    heapify(heap)

    while len(heap) > 1:
        left_frequency, _, left = heappop(heap)
        right_frequency, _, right = heappop(heap)
        parent = HuffmanNode(
            left_frequency + right_frequency,
            left=left,
            right=right,
        )
        heappush(heap, (parent.frequency, next(serial), parent))

    return heap[0][2]
```

构树代码用序号打破相同频率的堆比较平局，所以同一频率表可能得到不同但同样最优的码字。完整实现还要遍历树生成码表，并处理只有一种字符的特殊输入，通常给它编码 `0`，不能让空路径吞掉全部符号。

霍夫曼算法在已知频率下得到最小加权长度的二进制前缀码，但“最优”限定在这类码和这份频率分布中。若后续数据分布明显改变，原码表可能不再高效；静态方案需重建码表，自适应方案则要让编码端与解码端同步更新状态。

<Stepper>
  <Step title="统计每个字符频率"><HuffmanCodingDiagram />把字符和正频率作为叶节点放入最小堆，确认总频率等于输入长度。</Step>
  <Step title="合并两个最小节点">每轮取出最低频的两棵树，建立频率为二者之和的新父节点并放回。</Step>
  <Step title="从根生成码字">约定左边0、右边1，只有叶节点代表字符；沿路径累积比特。</Step>
  <Step title="编码后再解码验证">逐位走树，抵达叶子输出字符并回根；最终必须回到根且原文完全一致。</Step>
</Stepper>

<Callout type="trap" title="霍夫曼总能让任何文件变小">
压缩收益取决于频率偏斜，还要支付码表或树的元数据。字符近似等频或输入很短时，头部开销可能抵消主体节省；无损只保证可恢复，不保证每个输入都缩小。
</Callout>

## 原章概念回查

有根树由根节点引出所有其他节点，根节点没有父节点，叶节点没有孩子。文件目录形成树，是理解父子层级和递归遍历的第一个例子。

深度优先搜索沿一条分支深入后回溯；DFS使用调用栈或显式栈。DFS与BFS的探索顺序不同，分别优先深度与层级。

树是连通无环图，因此树中任意两节点只有一条简单路径。二叉树每个节点至多两个孩子，但二叉树不等于二叉搜索树。

霍夫曼编码是无损压缩。字符频率决定编码长度，高频字符使用更短编码；构树时反复合并频率最小的两个节点，叶节点字符沿左右分支得到比特编码，前缀码保证无歧义解码。

## 本章回顾

1. 有根树用唯一根节点解释父子层级。
2. 根没有父节点，叶没有孩子，内部节点兼具父子角色。
3. 文件目录是树模型，链接可能让真实结构成为一般图。
4. DFS沿一支深入，在叶子处返回并回溯。
5. 递归DFS使用调用栈，迭代DFS使用显式栈。
6. DFS和BFS的顺序、路径保证与内存前沿不同。
7. 无向树等价于连通且无环的图。
8. 树中任意两节点只有一条简单路径。
9. 二叉树只限制每个节点至多两个孩子。
10. 霍夫曼算法反复合并最低频节点构造二叉树。
11. 高频字符路径短，低频字符路径长。
12. 叶子码构成前缀码，可逐位无歧义恢复原文。

<Exercises>

**问题 1：为什么严格树的父到子DFS不需要visited，而带符号链接的目录遍历可能需要？**

<Answer>严格树无环且每个非根节点只有一个父节点，同一节点不会由另一条路径再次到达。符号链接可能指向祖先或共享目标，产生环或多条路径；必须记录已访问对象并定义是否跟随链接。</Answer>

**问题 2：递归DFS和显式栈DFS怎样保证左孩子先访问？**

<Answer>递归版按孩子列表顺序调用即可。显式栈后进先出，所以要把孩子按相反顺序压栈，右孩子先压、左孩子后压，弹出时才会左孩子先处理。</Answer>

**问题 3：给一个连通无向图新增一条边后出现环，它为什么不再是树？**

<Answer>新增边与原本两端之间的唯一路径合起来形成环，也使这两个节点之间出现两条简单路径，违反树的无环和唯一路径性质。</Answer>

**问题 4：码表A=0、B=10、C=110、D=111为何不需要分隔符？**

<Answer>它是前缀码，没有任何完整码字是另一码字的前缀。解码从根逐位走，一到叶子就能唯一确定字符并重回根；例如0110只能拆成0和110，即A、C。</Answer>

</Exercises>
