## 直觉引入

计算机世界里一切皆是 0 和 1。位运算就是直接操作这些 0 和 1。AND 像筛选器（只保留掩码为 1 的位），OR 像合并器（把掩码为 1 的位设为 1），XOR 像翻转器（掩码为 1 的位翻转），NOT 像取反器。

掩码就是一个特殊的二进制数，用来"选择"其他数的某些位。比如掩码 0xFF 选取最低 8 位，0xF0 选取中间 4 位。掌握掩码是位操作的基础。

## 概念讲解

### 基本位运算

<HdBitManipulationDiagram />

<Term def="位同为 1 则 1，否则 0。用于选取特定位（掩码为 1 的位保留，为 0 的位清零）">AND（与）</Term>

<Term def="位有 1 则 1。用于设置特定位为 1（掩码为 1 的位置 1，其余不变）">OR（或）</Term>

<Term def="位不同则 1，相同则 0。用于翻转特定位（掩码为 1 的位翻转）">XOR（异或）</Term>

XOR 重要性质：a^a=0（自反），a^0=a（恒等），a^b^b=a（可逆）。这些性质是加密、校验、去重的基础。

### 掩码技巧

设置第 k 位：x | (1&lt;&lt;k)。清除第 k 位：x & ~(1&lt;&lt;k)。翻转第 k 位：x ^ (1&lt;&lt;k)。测试第 k 位：x & (1&lt;&lt;k)。取最低有效 1：x & -x。

## 代码对照

```c
// 掩码操作
#define SET_BIT(x, k)    ((x) | (1U &lt;&lt; (k)))   // 设置第k位为1
#define CLEAR_BIT(x, k)  ((x) & ~(1U &lt;&lt; (k)))  // 清除第k位为0
#define FLIP_BIT(x, k)   ((x) ^ (1U &lt;&lt; (k)))   // 翻转第k位
#define TEST_BIT(x, k)   (((x) >> (k)) & 1)     // 测试第k位

// popcount：Brian Kernighan 法
int popcount(unsigned int x) {
    int count = 0;
    while (x) {
        x &= x - 1;  // 清除最低位的1
        count++;
    }
    return count;     // 循环次数 = 1的个数
}

// 取最低有效 1（lowbit）
unsigned int lowbit(unsigned int x) {
    return x & (-x);  // 例：x=12(1100), -x=...10100, x&-x=4(100)
}

// 判断 2 的幂
int is_power_of_2(unsigned int x) {
    return x && !(x & (x - 1));  // 2的幂只有一个1
}
```

## 常见误区

<Callout type="trap">
**现象：有符号数右移结果不确定。**
原因 → 有符号数右移是算术右移（补符号位）还是逻辑右移（补0）是 C 语言实现定义。
修法 → 用无符号数右移（保证逻辑右移补0），或明确使用算术右移的场景。
</Callout>

<Callout type="trap">
**现象：移位超过位数导致未定义行为。**
原因 → C 语言中移位 >= 类型位数是未定义行为（如 int 移位 32 位）。
修法 → 移位量用掩码限制：shift & 31（对 32 位 int）。
</Callout>

<Exercises>
**问题 1**：XOR 有哪些重要性质？

<Answer>
1.自反性：a^a=0。2.恒等性：a^0=a。3.可逆性：a^b^b=a。4.交换律和结合律：a^b=b^a，(a^b)^c=a^(b^c)。这些性质使 XOR 广泛用于加密、校验、去重（如找数组中唯一的数）。
</Answer>

**问题 2**：Brian Kernighan 法数 1 的个数为什么比逐位统计快？

<Answer>
逐位统计检查所有 32 位，循环 32 次。Brian Kernighan 法用 x&(x-1) 消除最低位的 1，循环次数等于 1 的个数。如果只有 3 个 1，只需 3 次循环而非 32 次。
</Answer>
</Exercises>
