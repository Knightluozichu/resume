## 直觉引入

普通算法教材教你"用什么数据结构"，Hacker's Delight 教你"如何榨干每一个 bit"。这本书充满了用位运算替代算术运算、用数学等价消除分支的技巧——比如不用 if 判断绝对值，不用循环数 1 的个数，不用除法算取模。

这些技巧源于早期计算机资源极度匮乏的年代，但在今天依然有价值：GPU 和嵌入式系统没有硬件除法器，分支预测失败代价巨大，位运算技巧能让代码快 2-10 倍。

全书分四大板块：位操作基础（基本位运算、掩码技巧）、算术技巧（加减乘除的位运算实现）、高级技巧（幂运算、非常规进位制、浮点数）、实际应用（CRC 纠错、哈希搜索）。

### 核心思想

位操作技巧的核心理念：1.用位运算的数学等价替代昂贵的操作（除法→移位、分支→位运算）；2.利用补码、二进制的数学性质简化计算；3.在同一条指令中完成多个逻辑操作。

## 代码对照

```c
// 经典位运算技巧对比
// 方案A：用 if 求绝对值（有分支）
int abs_if(int x) {
    if (x < 0) return -x;
    return x;
}

// 方案B：无分支求绝对值（位运算）
int abs_bit(int x) {
    int mask = x >> 31;      // 负数全1，正数全0
    return (x ^ mask) - mask; // 负数取反+1=取负，正数不变
}
// 无分支版本避免分支预测失败，在流水线 CPU 上更快
```

## 常见误区

<Callout type="trap">
**现象：过度使用位运算导致代码不可读。**
原因 → 为了"炫技"用位运算替代清晰的算术表达。
修法 → 位运算用于性能关键路径。普通代码可读性优先，必要时加注释。
</Callout>

<Callout type="trap">
**现象：位运算技巧在不同平台结果不同。**
原因 → 有符号数右移是算术右移还是逻辑右移取决于实现。
修法 → 尽量用无符号数。跨平台代码避免依赖实现定义行为。
</Callout>

**问题 1**：Hacker's Delight 与普通算法教材的区别是什么？

<Answer>
普通算法教材关注"用什么数据结构和算法"，Hacker's Delight 关注"如何用位运算榨取每个 bit 的性能"。它教你用数学等价替代昂贵的操作（除法→移位、分支→位运算），适合 GPU、嵌入式等资源受限场景。
</Answer>

**问题 2**：全书四大板块是什么？为什么是这个顺序？

<Answer>
位操作基础（基本位运算+掩码）、算术技巧（加减乘除的位运算实现）、高级技巧（幂运算+非常规进位制+浮点数）、实际应用（CRC+哈希）。基础是语言，算术是核心算法，高级技巧是综合运用，应用是工程落地。递进关系。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="位操作技巧">利用二进制位运算性质替代算术运算或分支的编程技巧。</GlossaryItem>
<GlossaryItem term="掩码">用于选取或清除特定位的位模式，通过与/或运算实现位筛选。</GlossaryItem>
<GlossaryItem term="无分支代码">不使用 if/else 等条件跳转的代码，用位运算替代，避免分支预测失败。</GlossaryItem>
<GlossaryItem term="补码">计算机中表示有符号整数的方式，正数不变，负数取反加一。</GlossaryItem>
</Glossary>
