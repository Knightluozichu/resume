## 直觉引入

IEEE 754 浮点数在内存中是一串位，如果能把它当整数操作，有些运算会快得惊人。最经典的例子是快速平方根倒数（Quake III 中的 `0x5f3759df`）：

```c
float fast_inv_sqrt(float x) {
    int i = *(int*)&x;
    i = 0x5f3759df - (i >> 1);  // 魔法！
    return *(float*)&i;
}
```

这比 `1.0/sqrt(x)` 快 4 倍。原理是：浮点数的指数部分除以 2（右移1）相当于开平方，取负（减去魔法数）相当于取倒数。一次整数操作近似了浮点运算。

## 概念讲解

### IEEE 754 浮点数

<HdFloatingPointDiagram />

<Term def="用 1 位符号 + 8 位指数 + 23 位尾数表示浮点数的标准格式（32 位单精度）">
IEEE 754 单精度
</Term>

float 的位布局：1 位符号 S，8 位指数 E（偏移 127），23 位尾数 M。值 = (-1)^S × 1.M × 2^(E-127)。如果把 float 的位当 int 看，指数在高位，比较 int 大小近似比较 float 大小（正数时）。

### 快速平方根倒数

<Term def="利用浮点数位级表示，用一次整数操作近似计算 1/sqrt(x) 的技巧">
快速平方根倒数
</Term>

原理：log2(1/sqrt(x)) = -0.5 × log2(x)。浮点数的位模式近似 log2(x)（因为指数在高位）。所以 i >> 1 近似除以 2（开平方），0x5f3759df - (i>>1) 近似取负（倒数）。再用一次 Newton 迭代修正精度。

## 代码对照

```c
#include <stdint.h>

// 快速平方根倒数（Quake III 经典实现）
float fast_inv_sqrt(float x) {
    float x2 = x * 0.5f;
    int32_t i = *(int32_t*)&x;         // float 位模式转 int
    i = 0x5f3759df - (i >> 1);          // 魔法数 - 指数/2 ≈ 1/sqrt(x)
    float y = *(float*)&i;              // 转回 float
    y = y * (1.5f - x2 * y * y);       // Newton 迭代修正
    return y;  // 近似 1/sqrt(x)，精度 ~99.8%
}

// 原理分析：
// float 位模式 i ≈ (E+127)<<23 + M
// log2(x) ≈ (i - 偏移) / 2^23 （近似线性关系）
// -0.5 * log2(x) ≈ (0x5f3759df - i/2) / 2^23
// 所以 0x5f3759df - (i>>1) 近似 1/sqrt(x) 的位模式

// 浮点数整数比较优化（正数时）
int float_less(float a, float b) {
    int32_t ia = *(int32_t*)&a;
    int32_t ib = *(int32_t*)&b;
    // 正数时 int 比较等价于 float 比较
    if (ia > 0 && ib > 0) return ia < ib;
    return a < b;  // 混合符号时回退到浮点比较
}
```

## 常见误区

<Callout type="trap">
**现象：快速平方根倒数在现代 CPU 上不一定更快。**
原因 → 现代 CPU 有专门的 rsqrtss 指令（SSE），硬件实现更快。
修法 → 快速平方根倒数的价值在历史意义和教学。现代代码用 rsqrtss 或直接 1.0f/sqrtf(x)。
</Callout>

<Callout type="trap">
**现象：float 和 int 之间的类型双关有严格别名问题。**
原因 → C 标准中通过不同类型指针访问同一内存是未定义行为。
修法 → 用 memcpy 或 union（C99+）做类型双关，避免严格别名违规。
</Callout>

<Exercises>
**问题 1**：为什么"魔法数 0x5f3759df"能近似平方根倒数？

<Answer>
浮点数的位模式近似 log2(x) 的线性表示。1/sqrt(x) = 2^(-0.5·log2(x))，所以对位模式做"除以2取负"（i>>1 后用魔法数减）近似 1/sqrt(x) 的位模式。0x5f3759df 是精心选择的偏移量，使近似误差最小。再经一次 Newton 迭代修正到 99.8% 精度。
</Answer>

**问题 2**：IEEE 754 单精度浮点数的位布局？

<Answer>
32 位：1 位符号 S + 8 位指数 E（偏移 127）+ 23 位尾数 M。值 = (-1)^S × 1.M × 2^(E-127)。特殊值：E=0 且 M=0 为零，E=255 且 M=0 为无穷，E=255 且 M≠0 为 NaN。指数在高位使正浮点数的 int 比较等价于 float 比较。
</Answer>
</Exercises>
