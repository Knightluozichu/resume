## 直觉引入

计算 2^1000000 不需要乘一百万次。用二进制拆分：2^1000000 = (2^500000)^2，递归下去只需 log2(1000000)≈20 次乘法。这就是快速幂。

整数开方也有巧妙的位运算方法。最直觉的是 Newton 迭代：猜一个值 x0，用 x1=(x0+n/x0)/2 逼近 sqrt(n)，每次迭代精度翻倍。还有逐位确定法：从最高位开始，逐位测试能否设为 1，类似二分。

## 概念讲解

### 快速幂

<HdPowerDiagram />

<Term def="用二进制拆分将 a^n 的计算从 O(n) 优化到 O(log n) 的算法">
快速幂
</Term>

a^n = a^(n/2)^2 * (n 奇数则乘 a)。迭代实现：检查 n 的每一位，为 1 则乘入结果，底数平方。Hacker's Delight 还讨论了 2 的幂的特殊优化。

### 整数平方根

<Term def="用 x_{k+1}=(x_k+n/x_k)/2 迭代逼近 sqrt(n) 的方法，二次收敛">
Newton 迭代法
</Term>

<Term def="从最高位开始逐位测试能否设为 1，类似手算开方的位运算开方法">
逐位确定法
</Term>

Newton 迭代：x_{k+1} = (x_k + n/x_k) / 2，每次迭代有效位数翻倍（二次收敛），5 次迭代即可精确到 32 位。逐位确定法从 bit 15 开始（对 32 位），逐位测试。

## 代码对照

```c
// 快速幂（迭代版）
long long qpow(long long a, long long n) {
    long long res = 1;
    while (n) {
        if (n & 1) res *= a;  // 当前位为1，乘入结果
        a *= a;                // 底数平方
        n >>= 1;               // 右移一位
    }
    return res;  // O(log n)
}

// 整数平方根：Newton 迭代法
unsigned int isqrt_newton(unsigned int n) {
    if (n == 0) return 0;
    unsigned int x = n;
    unsigned int y = (x + 1) / 2;  // 初始猜测
    while (y < x) {
        x = y;
        y = (x + n / x) / 2;       // Newton 迭代
    }
    return x;  // x = floor(sqrt(n))
}

// 整数平方根：逐位确定法
unsigned int isqrt_bitwise(unsigned int n) {
    unsigned int res = 0;
    unsigned int bit = 1U << 30;  // 从最高可能位开始
    while (bit > n) bit >>= 2;    // 找到不超过 n 的最高位
    while (bit) {
        if (n >= res + bit) {      // 测试能否设该位为1
            n -= res + bit;
            res = (res >> 1) + bit;
        } else {
            res >>= 1;
        }
        bit >>= 2;
    }
    return res;  // floor(sqrt(n))
}
```

## 常见误区

<Callout type="trap">
**现象：Newton 迭代初始猜测不好导致收敛慢。**
原因 → 初始猜测离真实值太远。
修法 → 初始猜测用 n/2 或查表预估。对 32 位整数，5 次迭代足够收敛。
</Callout>

<Callout type="trap">
**现象：整数开方结果差 1。**
原因 → Newton 迭代返回 floor 还是 ceil 没明确，或终止条件不对。
修法 → 明确返回 floor(sqrt(n))。Newton 法收敛后验证 x^2 ≤ n < (x+1)^2。
</Callout>

<Exercises>
**问题 1**：Newton 迭代法求平方根的收敛速度？

<Answer>
二次收敛：每次迭代有效位数翻倍。从 1 位精度开始，5 次迭代达 32 位精度，10 次达 1024 位。收敛速度远快于二分法的线性收敛（每次 1 位）。
</Answer>

**问题 2**：逐位确定法开方的原理是什么？

<Answer>
从最高可能位开始，逐位测试：假设当前结果 res 的某位设为 1，测试 (res+bit)^2 是否超过 n。不超过则设该位为 1 并减去 (res+bit)。类似手算开方的逐位确定过程。每次处理 2 位（因为平方后位移 2 位）。
</Answer>
</Exercises>
