## 直觉引入

普通二进制从 0 数到 1 到 2 到 3：000, 001, 010, 011——注意 001→010 时有两位同时变化。如果这是物理开关，两位同时变化可能导致中间状态（000→010 可能瞬间出现 011 或 000）。

Gray 码解决这个问题：000, 001, 011, 010——每次只变一位。这在旋转编码器、Karnaugh 图、错误检测中至关重要。Hacker's Delight 还讨论了更奇特的负二进制（base -2），它能用正数表示正负数而无需符号位。

## 概念讲解

### Gray 码

<HdUnusualBasesDiagram />

<Term def="相邻两个数只有一位不同的二进制编码，又称反射二进制码">
Gray 码
</Term>

二进制转 Gray：g = b ^ (b >> 1)。Gray 转二进制：b = g ^ (g >> 1) ^ (g >> 2) ^ ...（最高位开始逐位异或）。Gray 码保证相邻数只差 1 位，避免多位同时跳变。

### 负二进制和 BCD

<Term def="以 -2 为基数的进位制，无需符号位即可表示正负数">
负二进制（base -2）
</Term>

负二进制：位权为 (-2)^0=1, (-2)^1=-2, (-2)^2=4, (-2)^3=-8...。所有整数（正负）都能用 0/1 表示而无需符号位。BCD（Binary Coded Decimal）每 4 位表示一个十进制数字，用于金融计算避免浮点误差。

## 代码对照

```c
// 二进制 → Gray 码
unsigned int bin2gray(unsigned int b) {
    return b ^ (b >> 1);  // 一条指令完成
}

// Gray 码 → 二进制
unsigned int gray2bin(unsigned int g) {
    unsigned int b = g;
    b ^= b >> 16;  // 32位：分5步逐级异或
    b ^= b >> 8;
    b ^= b >> 4;
    b ^= b >> 2;
    b ^= b >> 1;
    return b;
    // 原理：b[i] = g[i] ^ g[i+1] ^ g[i+2] ^ ...
}

// 负二进制转换：十进制 → base -2
void to_negabase(int n, char buf[]) {
    if (n == 0) { buf[0] = '0'; buf[1] = 0; return; }
    int i = 0;
    while (n != 0) {
        int rem = n % (-2);
        n /= (-2);
        if (rem < 0) { rem += 2; n++; }  // 修正负余数
        buf[i++] = rem + '0';
    }
    buf[i] = 0;
    // 反转得到正确顺序
}

// BCD 加法（需修正 >9 的结果）
unsigned int bcd_add(unsigned int a, unsigned int b) {
    unsigned int sum = a + 0x06666666;  // 预加 6 修正
    unsigned int carry = sum & 0x11111110;  // 检查进位
    sum = a + b - carry + (carry >> 2);  // 修正
    return sum;
}
```

## 常见误区

<Callout type="trap">
**现象：Gray 码转二进制用循环逐位异或，效率低。**
原因 → 32 位需要 31 次异或。
修法 → 用"分治异或"：b^=b>>16; b^=b>>8; ... b^=b>>1，5 步完成 32 位转换。
</Callout>

<Callout type="trap">
**现象：负二进制转换结果不对。**
原因 → 负基数取模可能得到负余数，需要修正。
修法 → 余数为负时加 |base| 并商加 1。保证余数在 [0, |base|) 范围内。
</Callout>

<Exercises>
**问题 1**：Gray 码相比普通二进制的优势是什么？

<Answer>
Gray 码相邻两个数只有一位不同，避免了多位同时跳变导致的中间状态错误。在物理设备（旋转编码器、位置传感器）中，多位同时变化可能瞬间产生错误值。Gray 码保证任何时刻只有一位在变，消除这种风险。还用于 Karnaugh 图简化逻辑电路设计。
</Answer>

**问题 2**：负二进制（base -2）如何无需符号位表示正负数？

<Answer>
负二进制的位权为 1, -2, 4, -8, 16, -32...（交替正负）。奇数位权为负，偶数位权为正。通过 0/1 的组合可以表示任意正负整数。例如 3 = 4 + (-2) + 1 = 111_{-2}，-3 = -8 + 4 + 1 = 1101_{-2}。无需单独的符号位。
</Answer>
</Exercises>
