## 直觉引入

你发送一串数据，接收方怎么知道有没有出错？最简单的是校验和（所有字节加起来取模），但它检测不到顺序交换。CRC（循环冗余校验）用更强大的数学工具：把数据当多项式，用生成多项式做 XOR 除法，余数就是校验码。

CRC 能检测所有 1-2 位错误和大多数突发错误，广泛用于网络传输和存储。汉明码更进一步：不仅能检测错误，还能纠正单比特错误。这些技术的核心都是位运算和多项式数学。

## 概念讲解

### CRC 原理

<HdCrcErrorDiagram />

<Term def="将数据视为多项式系数，用生成多项式做模 2 除法，余数作为校验码的错误检测方法">
CRC
</Term>

CRC 把数据的每一位当多项式系数（如 1011 = x^3+x+1），用预定的生成多项式 G(x) 做 XOR 除法（模 2 多项式除法，无进位借位）。余数 R(x) 就是 CRC 校验码，附在数据后面发送。接收方用同样的 G(x) 除，余数为 0 则无错。

### 汉明码

<Term def="通过在数据中插入校验位，能检测并纠正单比特错误的线性纠错码">
汉明码
</Term>

汉明码在 2^k 位置放校验位，其余放数据位。每个校验位覆盖特定位置（位置号的二进制第 k 位为 1 的位置）。收到数据后重新计算校验位，不一致的位置号异或起来就是错误位置，翻转该位即纠正。

## 代码对照

```c
// CRC-32 查表法
static uint32_t crc_table[256];

void crc32_init() {
    for (uint32_t i = 0; i < 256; i++) {
        uint32_t crc = i;
        for (int j = 0; j < 8; j++) {
            crc = (crc >> 1) ^ (0xEDB88320 & -(crc & 1));  // 无分支
        }
        crc_table[i] = crc;
    }
}

uint32_t crc32(const uint8_t* data, int len) {
    uint32_t crc = 0xFFFFFFFF;
    for (int i = 0; i < len; i++) {
        crc = (crc >> 8) ^ crc_table[(crc ^ data[i]) & 0xFF];
    }
    return crc ^ 0xFFFFFFFF;
}

// 汉明码(7,4)：4 位数据 + 3 位校验 = 7 位码字
// p1 覆盖位置 1,3,5,7; p2 覆盖 2,3,6,7; p4 覆盖 4,5,6,7
uint8_t hamming_encode(uint8_t data) {
    // data = d1 d2 d3 d4 (4 bits)
    uint8_t p1 = ((data>>0) ^ (data>>1) ^ (data>>3)) & 1;
    uint8_t p2 = ((data>>0) ^ (data>>2) ^ (data>>3)) & 1;
    uint8_t p4 = ((data>>1) ^ (data>>2) ^ (data>>3)) & 1;
    return (p1<<0) | (p2<<1) | (data&1)<<2 | (p4<<3)
         | ((data>>1)&1)<<4 | ((data>>2)&1)<<5 | ((data>>3)&1)<<6;
}
```

## 常见误区

<Callout type="trap">
**现象：CRC 用普通整数除法而不是 XOR 除法。**
原因 → CRC 是模 2 多项式除法，没有进位借位，用 XOR 替代加减法。
修法 → 理解 CRC 的多项式本质：每一位是多项式系数，除法是 XOR 多项式除法。
</Callout>

<Callout type="trap">
**现象：汉明码只能纠单比特错误，双比特错误怎么办？**
原因 → 汉明码的最小汉明距离为 3，只能纠 1 位错检 2 位错。
修法 → 扩展汉明码（SECDED）加一个总校验位，能纠 1 位错检 2 位错。
</Callout>

<Exercises>
**问题 1**：CRC 为什么用 XOR 多项式除法而不是普通除法？

<Answer>
CRC 是模 2 多项式除法，每一位是多项式系数（0 或 1），运算在 GF(2) 上进行。GF(2) 中加法和减法都是 XOR（无进位借位）。这种数学结构使 CRC 对突发错误有很好的检测能力，且硬件实现简单（只需移位寄存器和 XOR 门）。
</Answer>

**问题 2**：汉明码如何定位并纠正单比特错误？

<Answer>
汉明码在 2^k 位置放校验位，每个校验位覆盖位置号的第 k 位为 1 的所有位置。收到数据后重新计算每个校验位，不一致的校验位对应的 2^k 值异或起来就是错误位置。翻转该位置即纠正错误。例如 p1 和 p4 不一致，错误位置 = 1+4 = 5。
</Answer>
</Exercises>
