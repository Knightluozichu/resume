## 直觉引入

Hacker's Delight 不是一本"背公式"的书，而是一种思维方式：看到任何运算都问"能不能用位运算更快地完成？"。除法能不能变乘法？分支能不能消除？循环能不能用位运算替代？

但这不意味着所有代码都该用位运算。核心原则是：在性能关键路径上用位运算，在非关键路径上保持可读性。读完这本书，你应该掌握"什么时候用、怎么用、什么时候不用"的判断力。

## 概念讲解

### 知识体系回顾

<HdFinalReviewDiagram />

<Term def="用位运算的数学等价替代昂贵的算术运算或分支，以提升性能的编程哲学">
位运算优化
</Term>

全书四大板块串联：位操作基础（AND/OR/XOR/移位/掩码）是语言，算术技巧（无分支/魔法数除法）是核心算法，高级技巧（快速幂/Gray码/浮点位操作）是综合运用，实际应用（CRC/哈希）是工程落地。

### 核心原则

1.理解硬件：除法慢（20-40周期），乘法快（3-5周期），位运算最快（1周期）。2.消除分支：不可预测的分支用位运算替代。3.利用数学等价：补码、XOR 自反性、浮点位模式。4.可读性权衡：非关键路径不用位运算。

## 代码对照

```c
// Hacker's Delight 技巧速查
// 1. 判断 2 的幂
int is_pow2(unsigned x) { return x && !(x & (x-1)); }

// 2. 无分支绝对值
int abs_nobranch(int x) { int m = x>>31; return (x^m)-m; }

// 3. 最低有效 1
unsigned lowbit(unsigned x) { return x & -x; }

// 4. popcount (Brian Kernighan)
int popcount(unsigned x) { int c=0; while(x){x&=x-1;c++;} return c; }

// 5. 除以 3（魔法数）
unsigned div3(unsigned x) { return (unsigned)((unsigned long long)x*0xAAAAAAAB>>33); }

// 6. 快速平方根倒数
float inv_sqrt(float x) {
    int i=*(int*)&x; i=0x5f3759df-(i>>1);
    float y=*(float*)&i; return y*(1.5f-0.5f*x*y*y);
}

// 7. x%8 → x&7
// 8. Gray码 → 二进制：b=g; b^=b>>1; b^=b>>2; b^=b>>4; ...
```

## 常见误区

<Callout type="trap">
**现象：处处用位运算导致代码不可维护。**
原因 → 过度优化，非关键路径也用位运算。
修法 → 只在性能关键路径用位运算，其余保持清晰。加注释说明原理。
</Callout>

<Callout type="trap">
**现象：位运算优化后反而变慢。**
原因 → 现代编译器已经很聪明，手动优化可能干扰编译器优化。或位运算破坏了分支预测。
修法 → 先测量再优化。编译器可能已经自动优化了 x/4 为 x>>2。
</Callout>

<Exercises>
**问题 1**：Hacker's Delight 的核心思想是什么？

<Answer>
核心思想是"用位运算的数学等价替代昂贵的操作"。具体包括：1.用移位替代除以2的幂；2.用魔法数乘法替代常量除法；3.用掩码运算消除不可预测的分支；4.利用补码、XOR自反性、浮点位模式等数学性质简化计算。核心原则是在性能关键路径上优化，非关键路径保持可读性。
</Answer>

**问题 2**：全书四大板块如何串联？

<Answer>
位操作基础（AND/OR/XOR/移位/掩码）是语言工具，算术技巧（无分支/魔法数除法）是核心应用，高级技巧（快速幂/Gray码/浮点位操作）是综合运用，实际应用（CRC/哈希/纠错码）是工程落地。递进关系：工具→核心算法→高级技巧→工程应用。
</Answer>
</Exercises>
