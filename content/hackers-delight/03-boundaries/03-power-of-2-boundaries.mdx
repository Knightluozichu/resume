## 从“低位归零为何就是对齐”开始

先预测：以16为boundary size时，十进制93的low 4 bits是13。向下对齐只需清掉这4 bits，得到80；向上对齐则要走到下一个low-4-bits全零的value 96。Power-of-2 boundaries的特殊性在于division remainder、bit field与memory alignment三种语言完全重合。

若boundary size $a=2^k$，任意nonnegative $x$都可唯一写成

$$
x=qa+r,
\qquad
0\le r\lt a.
$$

其中$r$就是$x$的low $k$ bits，$q$是其余high prefix。Chapter 3的全部技巧都从这个分解出发：清low field完成按已知2的幂倍数取整；扩散highest one完成取整到下一个2的幂；比较high prefix或检查low-field carry完成检测2的幂边界跨越。

## 3.1 Rounding to a multiple of a known power of 2

### The low-bit remainder

为$m=a-1$。因为$m$在low $k$ positions全为1，

$$
x\bmod a=x\mathbin{\&}m,
\qquad
\left\lfloor\frac{x}{a}\right\rfloor a
=
x\mathbin{\&}(\operatorname{NOT}m).
$$


（rounding to a multiple of a known power of 2）对nonnegative unsigned input给出

$$
\operatorname{down}_a(x)=x\mathbin{\&}(-a),
\qquad
\operatorname{up}_a(x)=(x+a-1)\mathbin{\&}(-a).
$$

在fixed-width two's complement中，$-a$与$\operatorname{NOT}(a-1)$具有相同bit pattern。向上公式先加mask，让任意nonzero remainder产生进入high prefix的carry，再清掉low bits；已经对齐时，增加的mask不足以产生carry，因此value保持不变。


```c
#include <stdbool.h>
#include <stdint.h>

static bool is_power_of_two_u32(uint32_t a) {
    return a != 0u && (a & (a - 1u)) == 0u;
}

static uint32_t align_down_u32(uint32_t x, uint32_t a) {
    return x & ~(a - 1u); // Precondition: a is a nonzero power of two.
}

static bool align_up_u32(uint32_t x, uint32_t a, uint32_t *out) {
    uint32_t mask = a - 1u;
    if (!is_power_of_two_u32(a) || x > UINT32_MAX - mask) return false;
    *out = (x + mask) & ~mask;
    return true;
}
```

这里的overflow check不是附属优化。若$x+a-1$回绕，mask仍会生成一个“对齐”的small value，但它已经不再是不小于$x$的mathematical multiple。

### Signed inputs require a rounding contract

对negative two's-complement integer直接clear low bits通常得到toward negative infinity的floor multiple。例如负19按8对齐得到负24；但许多application所谓“向下”其实指toward zero，即负16。Ceiling又得到负16。名称不够，API必须写明floor、ceil还是truncate。


若要signed ceiling，可以从quotient/remainder定义推导，而不是盲目沿用positive bias。还必须检查addition和minimum value边界。Address、size和capacity通常天然是unsigned；把它们保持为unsigned可消除一大类含糊，但不能消除representability问题。

### Alignment is a value property, not an allocation proof

`address & (a - 1)`为zero能证明numeric address是$a$的multiple，却不能证明该pointer指向有效object、满足language provenance或有足够remaining storage。Memory allocator还需保证returned region size、lifetime和type alignment。

按2的幂对齐广泛用于cache lines、SIMD loads、pages、packet blocks与arena allocation。若hardware或ABI允许non-power-of-two alignment，就应回到division/remainder，而不是强行使用mask。

## 3.2 Rounding to the next power of 2

### Recognize an exact one-hot boundary

（one-hot power）满足清掉最右1后为zero：

$$
x\ne0
\quad\land\quad
(x\mathbin{\&}(x-1))=0.
$$


Explicit nonzero guard不可省略。Zero也满足`0 & (0 - 1) == 0`，但通常不属于positive powers of two。若某个API刻意规定`ceil_pow2(0) = 1`或返回0 sentinel，这属于separate input contract，不能借predicate暗示。

### Spread the highest one, then add one

（bit spreading）从$x-1$开始。Subtract one确保已经是power boundary的input保持在前一个all-ones suffix，而不是跳到double size。随后

$$
\begin{aligned}
v&=x-1,\\
v&=v\mathbin{|}(v\mathbin{\mathrm{shr}}1),\\
v&=v\mathbin{|}(v\mathbin{\mathrm{shr}}2),\\
v&=v\mathbin{|}(v\mathbin{\mathrm{shr}}4),\ \ldots
\end{aligned}
$$

每一步把filled suffix的覆盖距离翻倍。经过$\lceil\log_2 w\rceil$次后，highest one及其lower positions全部为1；最后加一产生next one-hot value。


（rounding to the next power of 2）示例实现：

```c
static bool ceil_pow2_u32(uint32_t x, uint32_t *out) {
    if (x == 0u) return false;
    if (x > 0x80000000u) return false;
    uint32_t v = x - 1u;
    v |= v >> 1;
    v |= v >> 2;
    v |= v >> 4;
    v |= v >> 8;
    v |= v >> 16;
    *out = v + 1u;
    return true;
}
```


For 32-bit unsigned，largest representable one-hot power is $2^{31}$。A mathematical result of $2^{32}$ does not fit；spreading produces all ones and final addition wraps to zero。Returning zero can be a deliberate sentinel only if zero cannot be mistaken for a valid capacity and every caller checks it.


### Leading zeros and the exponent view

若有count-leading-zeros primitive，highest set bit可直接定位。对positive $x$，

$$
\operatorname{ceilLog2}(x)
=
\begin{cases}
0,&x=1,\\
w-\operatorname{clz}(x-1),&x\gt1.
\end{cases}
$$

然后candidate为$2^{\operatorname{ceilLog2}(x)}$，但shift exponent等于word width时仍要在shift之前报告overflow。


Bit spreading便于portable reference，CLZ/bit-width standard primitive通常更直接。Compiler可能把两种source都识别成target instructions，因此选择应依据clarity、defined edge behavior和generated code，而不是source operator count。

### Capacities, rings, and allocation classes

Power-of-two capacity使modulo化为mask：logical index到physical slot的mapping为`index & (capacity - 1)`。它适用于ring buffers、hash tables和buddy allocation，但前提是capacity确实是nonzero one-hot。


向上取2幂会引入slack。Request刚超过boundary时，capacity接近double；系统设计应权衡fast masking、allocator classes与memory overhead。不能因为bit trick便宜，就假设rounding policy也便宜。

## 3.3 Detecting a power-of-2 boundary crossing

### Fix the interval convention first

适合address range，但“是否cross boundary”仍要定义：是range内含boundary point，还是range覆盖多个buckets？

对nonempty half-open byte range$[s,s+n)$，last covered address为$e=s+n-1$。令bucket size$a=2^k$，则覆盖多个buckets当且仅当

$$
(s\mathbin{\mathrm{shr}}k)
\ne
(e\mathbin{\mathrm{shr}}k).
$$

（detecting a power-of-2 boundary crossing）本质是high prefixes不同。


如果range恰好结束在boundary point但不包含它，例如$[0,16)$，它只覆盖bucket 0，不算跨越；错误使用end-exclusive 16去比较prefix会误报。若业务定义“触达boundary”而非“覆盖多个buckets”，结果则不同，所以endpoint rule必须进入函数名或documentation。

### Detect crossing from the low remainder

Start所在bucket剩余room为$a-(s\bmod a)$。Nonempty length $n$超过这段room时cross：

$$
(s\mathbin{\&}(a-1))+n\gt a.
$$

这里strict inequality来自inclusive last element：remainder 11、length 5恰好覆盖positions 11到15，不跨16；length 6才进入next bucket。


另一个等价视角是观察low $k$ bits addition是否产生carry。若处理的是从point $x$移动delta后的endpoint，而不是length，predicate会随inclusive/exclusive convention改变。不要在这两种参数含义之间复用同一表达式却不改边界条件。

```c
static bool range_crosses_pow2_u64(uint64_t start, uint64_t length,
                                   unsigned k, bool *crosses) {
    if (length == 0u || k >= 64u) return false;
    if (start > UINT64_MAX - (length - 1u)) return false;
    uint64_t last = start + length - 1u;
    *crosses = (start >> k) != (last >> k);
    return true;
}
```

Function先排除empty range、invalid shift和last-address overflow，再比较prefix。若省略overflow guard，wrapped last可能落回small bucket并产生反向结论。

### Page spans and other system uses

Page size常为2的幂，因此first page与last page分别由address right shift得到。Pages touched为last page减first page再加一。


同一模型适用于cache-line split loads、DMA descriptors、file blocks、vector tails和network fragments。Performance implication各不相同：跨cache line不一定fault，跨page也不一定miss；bit predicate只回答geometry，不替代architecture measurement。

## 小结

Chapter 3 Power-of-2 Boundaries建立三条统一链路。按已知2的幂倍数取整利用low $k$ bits恰是modulo remainder；clear low field向floor multiple，先加mask再clear可对nonnegative input向ceiling multiple，但必须防overflow。

取整到下一个2的幂先区分exact one-hot boundary，再通过bit spreading或leading-zero count定位ceiling exponent。Zero、largest representable power和one-past-word结果必须写入contract。

检测2的幂边界跨越则比较nonempty interval首尾元素的high prefixes，或观察low remainder加length是否进入next bucket。Closed、half-open、empty range和last-address overflow会改变predicate。真正可靠的bit trick不是一行expression，而是一套domain、proof、guard和test共同组成的接口。
