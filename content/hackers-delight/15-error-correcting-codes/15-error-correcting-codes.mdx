## 从“检测到错误以后，数据还能继续用吗”开始

先预测：一个32-bit memory word在读取时有one bit flipped。如果只有CRC，receiver知道“有错”却通常不知道修哪一位；如果codewords刻意隔开，received word也许仍离original valid word最近，可以不请求sender而恢复。

Error-Correcting Codes（纠错码）研究这种redundant representation。Chapter 15限于binary forward error-correcting block codes：alphabet是zero/one，固定长度block编码成，receiver凭当前block纠错，不依赖retransmission。


CRC与ECC不是竞争关系。System可用ECC纠正常见small faults，再用CRC检测larger or structured corruption；选择取决于channel model、latency、storage and bandwidth budget。

## 15.1 Introduction

### Redundancy creates geometric separation

设encoder把$k$ information bits映射为$n$-bit codeword，加入$r=n-k$ redundant bits。为

$$
R=\frac{k}{n}.
$$

Higher redundancy通常允许larger error radius，但增加storage、bandwidth、energy和latency。Correction不是“凭空猜回”data，而是codebook只使用$2^n$ possible words中的$2^k$个，使valid words之间留出empty Hamming space。

Threefold repetition把zero编码000、one编码111。Two codewords distance three；one flip后majority仍唯一。


它的rate只有one third。Hamming codes用carefully chosen parity equations，以much lower redundancy完成single-error correction。

### Detection, correction, and miscorrection are distinct outcomes

Decoder API至少返回：

- Clean：syndrome与overall checks均一致。
- Corrected：在guaranteed radius内定位并修复，附error location或counter。
- Detected uncorrectable：知道超出correction contract，data不得静默使用。
- Invalid or ambiguous：metadata、layout或decoder assumption不匹配。

超过guaranteed fault count时，decoder可能检测、漏检或miscorrect。绝不能把“实现会输出某个word”当作“该word已被证明正确”。

## 15.2 The Hamming Code

The Hamming Code（汉明码）把each codeword position赋予unique nonzero binary label。Check equations对应label bits；one flipped position会让exactly those checks fail，failed-check vector就是position label。

记为$s$。Linear algebra形式是

$$
s=Hr^{\mathsf T},
$$

其中$H$的each column是该position的unique nonzero label。Valid codeword $c$满足$Hc^{\mathsf T}=0$；若$r=c+e_j$，则syndrome恰为$H$的column $j$。

### Hamming(7,4) makes the indexing visible

Classic Hamming(7,4)在positions 1、2、4放parity，positions 3、5、6、7放four data bits。Parity $p_1$覆盖label low bit为one的positions，$p_2$覆盖next label bit，$p_4$覆盖top label bit。


Even parity encoder可写成：

```c
static uint8_t hamming74_encode(uint8_t data) {
    unsigned d0 = (data >> 0) & 1u;
    unsigned d1 = (data >> 1) & 1u;
    unsigned d2 = (data >> 2) & 1u;
    unsigned d3 = (data >> 3) & 1u;
    unsigned p1 = d0 ^ d1 ^ d3;
    unsigned p2 = d0 ^ d2 ^ d3;
    unsigned p4 = d1 ^ d2 ^ d3;
    return (uint8_t)(p1 | (p2 << 1) | (d0 << 2) |
                     (p4 << 3) | (d1 << 4) |
                     (d2 << 5) | (d3 << 6));
}
```

Syndrome可直接XOR all set-bit position labels：

```c
static unsigned hamming74_syndrome(uint8_t received) {
    unsigned syndrome = 0;
    for (unsigned position = 1; position <= 7u; ++position) {
        if (((received >> (position - 1u)) & 1u) != 0u) {
            syndrome ^= position;
        }
    }
    return syndrome;
}
```

If syndrome nonzero且fault model guarantees at most one error，flip position `syndrome`。


Plain Hamming(7,4) minimum distance是three：可correct one error，或detect up to two errors only when not simultaneously claiming correction。若two bits flip，their labels XOR成third nonzero label；naive single-error decoder会flipthird bit并miscorrect。

### Overall parity raises distance from three to four

在whole Hamming codeword外再加one，得到extended Hamming SEC-DED（single-error correcting, double-error detecting）。

Decoder联合Hamming syndrome $s$与received all-bit parity $p_o$：

| Overall parity | Syndrome | Meaning | Action |
| --- | --- | --- | --- |
| even | zero | no error | return data |
| odd | nonzero | one error in Hamming portion | flip syndrome position |
| odd | zero | overall parity bit error | repair or ignore check bit |
| even | nonzero | two errors | report uncorrectable |


Three or more errors超出guarantee。某些odd-weight patterns会looks like single error并触发miscorrection；API必须让fault model和status visible。

## 15.3 Software for SEC-DED on 32 Information Bits

Software for SEC-DED on 32 Information Bits（32信息位单错纠正双错检测）是原章的machine-word case。对$k=32$，six Hamming check bits足够，因为

$$
2^6
\ge
32+6+1
=
39.
$$

Six syndrome bits可标识zero plus38 possible error positions。再加one overall parity，total codeword是32 data + 6 Hamming checks + 1 overall = 39 bits。


Conceptual layout把six parity bits放positions 1、2、4、8、16、32，把32 data bits填入其余positions 1 through 38，再放overall bit。原章software为了machine access把32 information bits保留在one word，seven check bits单独pack；这只是layout transform，syndrome columns和decision table不变。

### Generate six checks from position labels

Clear reference implementation可先构造conceptual 38-bit word。Each data bit映射到next non-power-of-two position；for parity mask one、two、four、eight、sixteen、thirty-two，XOR all covered data bits得到check。

```c
static uint8_t secded32_checks(uint32_t data) {
    uint8_t checks = 0;
    unsigned data_bit = 0;
    for (unsigned position = 1; position <= 38u; ++position) {
        if ((position & (position - 1u)) == 0u) continue;
        if (((data >> data_bit) & 1u) != 0u) {
            checks ^= (uint8_t)position;
        }
        ++data_bit;
    }
    return checks; // six-bit Hamming syndrome contribution.
}
```

Encoding sets six check bits equal tothis value，then computes overall parity across data and six checks。Optimized implementation can useparallel XOR folds and masks as原章code does, but must match this reference for all input basis bits。


### Correct only in the proven quadrant

Received check bits为`pr`，information为`ur`。Recompute checks from`ur`，XOR received six checks to obtainsyndrome；compute parity acrossall 39 received bits：

```c
enum ecc_status {
    ECC_CLEAN,
    ECC_CORRECTED,
    ECC_DOUBLE_ERROR
};

static enum ecc_status secded32_classify(unsigned syndrome,
                                         unsigned overall_odd,
                                         unsigned *error_position) {
    if (!overall_odd && syndrome == 0u) return ECC_CLEAN;
    if (!overall_odd && syndrome != 0u) return ECC_DOUBLE_ERROR;
    if (syndrome == 0u) {
        *error_position = 39u; // Overall parity bit.
        return ECC_CORRECTED;
    }
    *error_position = syndrome; // Position 1 through 38.
    return ECC_CORRECTED;
}
```

If corrected position isone ofsix check positions，data word unchanged；otherwise map conceptual position back todata bit index and XOR that bit。Do not correct whenoverall parity even andsyndrome nonzero：that quadrant is guaranteed double error。

### Exhaustive fault injection is small enough

One 39-bit codeword has

$$
1+39+\binom{39}{2}=781
$$

patterns with zero, one, or two flipped bits。For each representative data pattern，test all 39 single faults and741 double pairs：

```c
for (unsigned first = 0; first < 39u; ++first) {
    assert_single_fault_is_corrected(first);
    for (unsigned second = first + 1u; second < 39u; ++second) {
        assert_double_fault_is_detected_not_corrected(first, second);
    }
}
```

Because syndrome islinear and independent ofdata value，basis-vector tests plus algebra can proveall data；random/full-pattern differential tests still catchpacking and position-mapping bugs。Clean decode must beidentity。

## 15.4 Error Correction Considered More Generally

Error Correction Considered More Generally（一般纠错）用minimum distance统一code capability。为$d_{\min}$：

$$
d_{\min}
=
\min_{c_1\ne c_2}
d_H(c_1,c_2).
$$

Code guaranteed detects up to$d_{\min}-1$ errors；nearest-codeword decoder guaranteed corrects

$$
t
=
\left\lfloor
\frac{d_{\min}-1}{2}
\right\rfloor
$$

unknown errors。


Hamming code distance three gives SEC；extended Hamming distance four gives SEC-DED。Distance four仍只guaranteesone-error correction，因为two radius spheres would overlap。

### Sphere packing limits how many messages fit

Radius-$t$ Hamming ball in$n$ dimensions contains

$$
V(n,t)
=
\sum_{j=0}^{t}\binom{n}{j}
$$

words。If $2^k$ codewords each needdisjoint correction ball：

$$
2^kV(n,t)\le2^n.
$$

对Hamming(7,4)、$t=1$取equality：16 codewords × 8 words per ball =128，so it isperfect one-error-correcting code。


### Known erasures consume less distance than unknown errors

If receiver知道which positions unreliable，these are。With $t$ unknown errors and$e$ erasures，unique decoding guarantee常写为

$$
2t+e\lt d_{\min}.
$$

Unknown error既要locate又要value，cost two distance units；erasure location已知，只cost one。


### Match the code to the channel

Independent bit flips、long bursts、symbol errors和permanent stuck bits需要different designs。Interleaving把one physical burst分散到multiple codewords，使each decoder block落回small-error radius，但增加buffering and latency。


Larger systems可选BCH、Reed-Solomon、convolutional、LDPC或product codes；这里的selection principle不是追求largest distance alone，而是平衡rate、block length、decoder complexity、soft information、latency、power和measured fault distribution。

Memory SEC-DED还需要scrubbing：read时纠正若不write back，latent one-bit error会留在storage，之后second fault变成uncorrectable double error。Telemetry应区分corrected与uncorrectable counts，并支持retirement or repair policy。

## 小结

Chapter 15 Error-Correcting Codes把redundancy解释为code-space separation。Hamming code使用unique nonzero position labels构造parity-check columns；one error syndrome就是position，Hamming(7,4)以three checks保护four data bits。

Extended overall parity把distance从three提升到four，形成SEC-DED。For 32 information bits，six Hamming checks加one overall parity得到39-bit codeword；syndrome与overall parity four-case table确保single correction、double detection，software必须穷举all fault positions。

Error correction considered generally由minimum distance统一：detect radius是$d-1$，unknown-error correction radius是floor half，errors plus erasures满足$2t+e\lt d$。Real ECC subsystem还需channel model、uncorrectable status、scrubbing和telemetry。
