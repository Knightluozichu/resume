## 从“一条线怎样访问二维网格”开始

先预测：把$16\times16$ image pixels排成one-dimensional array，row-major在row end会从$(15,y)$跳到$(0,y+1)$。有没有ordering让每个successive index都移动one grid unit，同时递归保持quadrant locality？

<Term def="连续极限可覆盖square、有限order在power-of-two grid上以unit-adjacent path访问every point的recursive space-filling curve。">希尔伯特曲线</Term>（Hilbert's curve）提供这种ordering。Machine code操作的是finite-order approximation，不是直接存储continuous mathematical curve。

Order $n$的grid side为

$$
N=2^n,
$$

point count与distance range为

$$
N^2=4^n,
\qquad
0\le s\lt4^n.
$$

Each coordinate用$n$ bits，distance用$2n$ bits。Core contract是all grid points exactly once，且

$$
\lVert H(s+1)-H(s)\rVert_1=1.
$$

## 16.1 A Recursive Algorithm for Generating the Hilbert Curve

A Recursive Algorithm for Generating the Hilbert Curve（Hilbert曲线递归生成）从order one的four-point U path开始。To reach next order，把previous curve复制到four quadrants；entry/exit quadrants rotate or reflect，使four copies首尾相接。

<HD16RecursiveCurveLab />

<Term def="Hilbert approximation每次细分的level；order n对应side 2的n次方和4的n次方points。">曲线阶数</Term>增加one，points变four times，segments满足

$$
S_n=4^n-1.
$$

### Orientation is part of the recursive state

只缩放并复制same orientation会在quadrant boundaries断开。Recursive state需要current direction与rotation sign；first and last subcurves使用opposite turn以对齐entry/exit。

<HD16QuadrantOrientationLab />

原章generator可写成如下shape：

```c
static void hilbert(int direction, int rotation, int order) {
    if (order == 0) return;

    direction += rotation;
    hilbert(direction, -rotation, order - 1);
    step(direction);

    direction -= rotation;
    hilbert(direction, rotation, order - 1);
    step(direction);

    hilbert(direction, rotation, order - 1);
    direction -= rotation;
    step(direction);

    hilbert(direction, -rotation, order - 1);
}
```

`step`把direction modulo four映射为right、up、left、down。Proof induction保留three invariants：

- Each recursive copy coversits quadrant exactly once。
- Consecutive points within copy remainunit-adjacent。
- Each copy exit与next copy entry相邻。

Base case显然；orientation rules完成inductive connection。

## 16.2 Coordinates from Distance along the Hilbert Curve

Coordinates from Distance（由距离求坐标）输入order $n$和$2n$-bit<Term def="Finite Hilbert path上从zero开始的one-dimensional index，range为zero through 4的n次方减one。">希尔伯特距离</Term> $s$，输出$n$-bit $(x,y)$。

<HD16DistanceToCoordinateLab />

### Four orientation states consume distance in bit pairs

原章使用A、B、C、D four states。Each state representsone rotation/reflection mapping。Scan distance bit pairs frommost significant side；each row：

1. Reads next base-four digit。
2. Outputs one x bit and one y bit。
3. Transitions to next orientation state。

Example order three、$s=52$：

$$
s=(110100)_2.
$$

Starting in state A，input pairs 11、01、00 emit coordinate pairs 10、01、11，packed output 100111。Odd/even streams yield

$$
x=(101)_2=5,
\qquad
y=(011)_2=3.
$$

<Term def="把每个distance base-four digit映射为one x bit、one y bit，同时更新rotation/reflection的finite-state machine state。">方向状态机</Term>使mapping只需$n$ iterations。

### A rotate-and-offset formulation reads low base-four digits

Equivalent iterative algorithm从scale one向上构造point。For each low base-four digit derive$rx,ry$，rotate/reflect accumulated subcurve，再add quadrant offset：

```c
static void hilbert_xy_from_s(unsigned order, uint64_t distance,
                              uint32_t *x_out, uint32_t *y_out) {
    uint32_t x = 0;
    uint32_t y = 0;
    uint32_t side = UINT32_C(1) << order;

    for (uint32_t scale = 1; scale < side; scale <<= 1) {
        uint32_t rx = (distance >> 1) & 1u;
        uint32_t ry = (distance ^ rx) & 1u;
        hilbert_rotate(scale, &x, &y, rx, ry);
        x += scale * rx;
        y += scale * ry;
        distance >>= 2;
    }
    *x_out = x;
    *y_out = y;
}
```

`hilbert_rotate`在$ry$为zero时根据$rx$ optional reflect，然后swap coordinates。All shifts与range要满足type width；$2n$不能超过distance type bits。

## 16.3 Distance from Coordinates on the Hilbert Curve

Distance from Coordinates（由坐标求距离）是inverse problem。Scan x/y bit pairs frommost significant level，current orientation决定输出哪一个base-four distance digit，再transition。

<HD16CoordinateToDistanceLab />

原章example order three、coordinate $(4,3)$：

$$
x=(100)_2,
\qquad
y=(011)_2.
$$

State sequence emits 11、01、01，so

$$
s=(110101)_2=53.
$$

Rotate formulation从largest quadrant向smallest：

```c
static uint64_t hilbert_s_from_xy(unsigned order,
                                  uint32_t x, uint32_t y) {
    uint32_t side = UINT32_C(1) << order;
    uint64_t distance = 0;

    for (uint32_t scale = side >> 1; scale != 0; scale >>= 1) {
        uint32_t rx = (x & scale) != 0u;
        uint32_t ry = (y & scale) != 0u;
        distance += (uint64_t)scale * scale * ((3u * rx) ^ ry);
        hilbert_rotate(scale, &x, &y, rx, ry);
    }
    return distance;
}
```

Inputs must satisfyboth coordinates below$2^n$。Silent masking would aliasout-of-range coordinate tovalid point；API应reject instead。

### Two directions are one contract

<Term def="对all valid s验证xy-to-distance of distance-to-xy equals original，并对all coordinates验证reverse composition。">双向逆映射</Term>要求

$$
H^{-1}(H(s))=s,
\qquad
H(H^{-1}(x,y))=(x,y).
$$

<HD16RoundTripLab />

Testing onlyone direction may miss matching-but-wrong orientation conventions。Known examples、full small-order enumeration与two-way inverse都必要。

## 16.4 Incrementing the Coordinates on the Hilbert Curve

Incrementing the Coordinates（坐标递增）给定current $(x,y)$，直接求next point，而不是先算$s$、increment、再decode。

<HD16IncrementCoordinateLab />

Reference path可以compose inverse/forward mappings，最易证明：

```c
static bool hilbert_next_reference(unsigned order,
                                   uint32_t *x, uint32_t *y) {
    uint64_t distance = hilbert_s_from_xy(order, *x, *y);
    uint64_t count = UINT64_C(1) << (2u * order);
    if (distance + 1u == count) return false;
    hilbert_xy_from_s(order, distance + 1u, x, y);
    return true;
}
```

原章direct algorithm scans coordinate bits throughsame orientation state。It maintains candidate delta $(dx,dy)$；某些state/coordinate rows update delta toone of four unit directions，finish后adds delta。No explicit distance word is formed。

Direct increment仍needsend-of-curve policy。Final point没有successor unless cyclic extension separately defined；blind wrap may jumpmore thanone grid unit。

## 16.5 Non-Recursive Generating Algorithms

Non-Recursive Generating Algorithms（非递归生成算法）有three practical forms：

- Iterate distance，each time use state-table or rotate formulation to getcoordinate。
- Startatfirst coordinate，repeatedly run direct coordinate increment。
- Use packed lookup tables to processmultiple levels per operation。

<HD16NonRecursiveCostLab />

Mappingonepoint is$O(n)$ time and$O(1)$ extra storage。Generatingwholecurve by independently decodingeach distance costs$O(n4^n)$；recursive step generator or well-designed incremental generator emitsall points in$O(4^n)$ total steps。

Table-packed constants can replace16 transition rows withshifts/masks, as原章demonstrates。Those constants areorientation-specific and hard toreview；keep clear table/reference implementation and exhaustive equivalence tests。

## 16.6 Other Space-Filling Curves

Other Space-Filling Curves（其他空间填充曲线）use different recursion and locality tradeoffs：

- <Term def="把x与y coordinate bits交错形成one-dimensional key的recursive Z-shaped ordering。">Morton码</Term> or Z-order hasvery cheap encode/decode bybit interleaving，but consecutive indices can make long jumps。
- Peano curve uses3-by-3 subdivision rather than2-by-2。
- Sierpinski-like and scan orders may fittriangular domains orhardware traversal。
- Row-major isnot space-filling incontinuous sense，but isbaseline withsimple arithmetic andexcellent contiguous-row locality。

<HD16OtherCurvesLab />

Hilbert guaranteesconsecutive unit steps；it doesnot guarantee everyspatial neighbor hasnearby distance。Space-to-line mapping cannot preserveall two-dimensional distances perfectly。

## 16.7 Applications

Applications（应用）depend onmeasured locality：

- Image and texture traversal，where nearby pixels benefitcache lines orprogressive access。
- Spatial databases，using Hilbert distance asB-tree key anddecomposingrectangle queries intoindex intervals。
- Domain decomposition andload balancing，assigning contiguous distance ranges toworkers。
- Cache-oblivious layouts，matrix blocks，voxel storage andgeographic tiling。

<Term def="Spatially nearby points在one-dimensional ordering中仍倾向于nearby的property；必须按actual workload和metric测量。">空间局部性</Term>不是yes/no label。Compare adjacent-step maximum、window interval count、cache misses、range-query false positives与encode cost。

<HD16LocalityLab />

Rectangle通常映射为multiple Hilbert intervals，不是single range。Index planner递归coverquery window，merge adjacent intervals，再filter exact coordinates。

<HD16RangeQueryLab />

Non-power-of-two domain可pad to enclosing square、clip invalid points或partition intomultiple blocks。Choice affectswasted key space andlocality；must beexplicit。

<HD16ApplicationContractLab />

<Callout type="trap" title="Hilbert index保证所有二维邻居在一维上都接近">
Curve只guarantees consecutive indices是grid neighbors，并提供useful average locality。Some adjacent spatial points can befar apart inindex。修法是按range-query、cache或partition workload benchmark against Morton and row-major。
</Callout>

<Callout type="trap" title="交换x和y也能round-trip所以orientation无所谓">
Encoder与decoder若一起使用same wrong orientation，round-trip仍可pass，却与stored data或other implementation不兼容。修法是加入order-one sequence、s52 maps to5,3和coordinate4,3 maps to53等known vectors。
</Callout>

## 小结

Chapter 16 Hilbert's Curve从recursive generation建立finite grid path：order$n$访问$4^n$points，four subcurves通过rotation/reflection连接，each successor move one grid unit。

Coordinates from distance与distance from coordinates用four orientation states或rotate-and-offset recurrence处理one level per iteration。Incrementing coordinates可直接deriveunit delta；non-recursive algorithms用constant state和packed tables避免recursion。

Other space-filling curves中Morton code更易bit-interleave却有long jumps。Hilbert applications必须以exact orientation、two-way inverse、unique coverage和workload-specific locality benchmark闭环。

<Exercises>

**问题 1**：order three Hilbert grid的side、point count与distance bit width是多少？

<Answer>
Side是2的3次方等于8；point count是4的3次方等于64；distance range zero through63，需要six bits，也就是two times order。
</Answer>

**问题 2**：原章state mapping为何把$s=52$映射到$(5,3)$？

<Answer>
Fifty-two的six-bit form是110100，pair sequence为11、01、00。Starting state A依次输出coordinate pairs 10、01、11；拆取x和y streams得到x为101即5，y为011即3。
</Answer>

**问题 3**：为什么Hilbert recursion不能把four previous curves以same orientation直接拼接？

<Answer>
Same orientation copies的exit与next entry通常位于quadrant far corners，boundary会产生jump。First and last copies必须rotate或reflect，让each exit与next entry只差one grid coordinate unit。
</Answer>

**问题 4**：Hilbert与Morton都可作为spatial key，为什么仍要benchmark？

<Answer>
Hilbert保证consecutive unit steps但encode更complex；Morton bit interleavingcheap却可long jump。Rectangle interval count、cache lines、partition balance和update pattern决定actual benefit，没有single ordering对all workloads最优。
</Answer>
