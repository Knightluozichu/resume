## 从“整数函数为什么会画出纹理”开始

先预测：把$x$放在横轴、$y$放在纵轴，再用颜色表示$f(x,y)$，普通加法会出现斜向色带，异或会出现递归方块，整数商会出现阶梯扇区。图像并没有给函数增加新信息，却把逐点数表中很难察觉的周期、对称、断点和位边界同时摆在眼前。

<HDAppendixCLogicalHeatmapLab />

本附录所说的<Term def="把有限整数定义域上的函数值映射为位置、颜色或高度，以观察周期、对称、断点和位结构的一组图。">离散函数图形集</Term>不是连续函数作图的缩小版。输入只取有限个整数点；每个像素或方格都是一个真实样本，不需要在相邻整数之间插值。设字长为$w$，二元函数的基本绘图契约可写为

$$
f:D_x\times D_y\longrightarrow R,
\qquad
D_x=D_y=\{0,1,\ldots,2^w-1\}.
$$

位置回答“输入是什么”，颜色或高度回答“输出如何编码”。若没有注明有符号还是无符号、原始结果还是模$2^w$结果、颜色是否按全局值域归一化，同一段程序能画出外观完全不同的图。因此，读图第一步不是猜图案含义，而是先复原定义域、值域和机器语义。

```ts
function sampleGrid(
  size: number,
  f: (x: number, y: number) => number,
) {
  return Array.from({ length: size * size }, (_, index) => {
    const x = index % size;
    const y = Math.floor(index / size);
    return { x, y, value: f(x, y) };
  });
}
```

## C.1 Plots of Logical Operations on Integers（整数逻辑运算图）

AND、OR、XOR逐位独立运算。某个输出位只由两个输入的同一位决定，所以整幅图是多个<Term def="固定观察输出的某一位，把该位的零一结果单独画成二值图。">位平面</Term>叠加出来的。对第$k$位，输入沿任一坐标轴每经过$2^k$个值就翻转一次，完整周期为$2^{k+1}$：

$$
b_k(x)=\left\lfloor\frac{x}{2^k}\right\rfloor\bmod 2,
\qquad
b_k(x\mathbin{\mathrm{xor}}y)=b_k(x)\mathbin{\mathrm{xor}}b_k(y).
$$

<HDAppendixCBitPlaneLab />

在位平面模式中选择bit 0，会看到最细的棋盘；选择更高位，方块边长依次翻倍。这种由各位周期叠加形成的<Term def="整数位函数沿坐标轴按二的幂重复，从而在热图中出现方块、条带或棋盘的规律。">周期纹理</Term>解释了为何XOR图具有自相似：把定义域扩大一倍，新图的四个象限由旧图及其补色组成。

AND的亮区只在两个输入位都为一的象限出现；OR的暗区只在两个输入位都为零的象限出现；XOR在两个输入位不同的象限出现。三者都满足交换对称，所以图关于主对角线镜像。这个对称性是可执行的不变量：若采样器把$x$、$y$索引或行列顺序写错，对称图会立刻暴露问题。

<Callout type="trap" title="常见误区：颜色相近就表示函数值相近">

颜色只是编码。连续渐变适合比较数值大小，却会掩盖单个位的翻转；二值位平面适合观察周期，却不表达完整数值。读图时必须先问当前是原始值、归一化值还是某一输出位，不能从综合色调直接推断汉明距离或算术距离。

</Callout>

## C.2 Plots of Addition, Subtraction, and Multiplication（加减乘图）

<HDAppendixCArithmeticHeatmapLab />

在无限精度整数上，$x+y=c$是斜率为负一的等值线，$x-y=c$是斜率为正一的等值线，$xy=c$形成离散双曲线族。但机器字只保留低$w$位时，显示值变为

$$
\operatorname{wrap}_w(z)=z\bmod 2^w.
$$

越过$2^w-1$后，颜色突然回到零。这是<Term def="固定字长机器只保留结果低位，使加减乘越过边界后按模二的字长重新开始。">模环绕</Term>，不是采样噪声。减法中的负结果同样按模数折回高端。例如4位机器上$3-5$的数学整数结果为$-2$，机器字结果是$14$。切换实验中的raw与modulo 16，可以直接看到一条连续算术平面被边界折叠成周期表面。

<HDAppendixCArithmeticSectionLab />

固定$y$后，二维表面退化为一条剖面：

$$
g_y(x)=x+y,\qquad h_y(x)=x-y,\qquad p_y(x)=xy.
$$

前两者的斜率分别为一和一，区别在截距方向；乘法斜率等于固定的$y$。因此剖面是检验热图解释的好工具：如果你认为某条纹代表常数和，就固定一行检查其数值；如果认为乘法图的某区域来自大因子，就比较不同$y$下剖面的斜率。图像负责提出结构假设，数值剖面负责证伪。

乘法图比加减法复杂，因为零行与零列全为零，交换律产生对角对称，合数拥有多组因子坐标，而质数在有限域内只有平凡因子位置。模$2^w$后，偶数因子还会快速抹掉低位，产生宽阔重复条带。这里看到的是整数因子结构和二进制环结构共同作用的结果。

## C.3 Plots of Functions Involving Division（除法函数图）

无符号欧几里得除法对$x\ge0$、$y\gt0$定义唯一的$q,r$：

$$
x=qy+r,
\qquad
q=\left\lfloor\frac{x}{y}\right\rfloor,
\qquad
0\le r\lt y.
$$

<HDAppendixCDivisionHeatmapLab />

商$q$在$x$跨越$y$的倍数时增加一，于是固定除数的曲线是台阶；二维热图则把这些台阶扩展为扇形边界。这种<Term def="整数商在被除数跨过除数倍数时跳变一级而形成的阶梯结构。">商阶梯</Term>越靠近小除数行越密，除数变大后阶梯变宽。余数$r$从零逐步增长到$y-1$，随后在下一个倍数处重置，因此出现<Term def="余数随被除数周期性从零增长并在除数倍数处重置形成的重复色带。">余数条带</Term>。

<HDAppendixCDivisionDiscontinuityLab />

商和余数的断点完全对齐：在$x=ky$处，商从$k-1$跳到$k$，余数从$y-1$回到零。这个配对比单独看一张图更可靠，因为它直接对应恒等式$x=qy+r$。实验排除了$y=0$；这不是把零除“画成黑色”，而是明确该点不属于函数定义域。

```cpp
struct DivResult {
    unsigned quotient;
    unsigned remainder;
};

DivResult divide_unsigned(unsigned x, unsigned y) {
    if (y == 0) throw std::domain_error("zero divisor");
    DivResult result{x / y, x % y};
    assert(result.quotient * y + result.remainder == x);
    assert(result.remainder < y);
    return result;
}
```

有符号除法还必须声明舍入约定。向零截断与向下取整在负数区域产生不同的商，余数符号也随语言定义变化。为了让图形可复现，本章交互使用非负$x$和正$y$，不把语言相关约定混入当前图形。

<Callout type="trap" title="常见误区：把零除点涂成零就算处理完成">

给未定义点任意赋零会制造一条看似有意义的暗线，并破坏读者对函数域的判断。正确做法是排除、留空或使用专门的无效标记，同时在图例中写清楚。错误值和无定义不是同一件事。

</Callout>

## C.4 Plots of the Compress, SAG, and Rotate Left Functions（压缩SAG与循环左移函数图）

### Compress：从稀疏位置收集到低位

`compress(x,m)`按从低位到高位的顺序扫描掩码$m$。掩码位为一时，取出$x$在同一位置的位，并把它放到结果下一个连续低位。若掩码的一位位置依次为$p_0,p_1,\ldots,p_{t-1}$，则

$$
\operatorname{compress}(x,m)
=\sum_{j=0}^{t-1}
\left(\left\lfloor\frac{x}{2^{p_j}}\right\rfloor\bmod2\right)2^j.
$$

<HDAppendixCCompressLab />

结果的有效宽度是$\operatorname{popcount}(m)$。未被选择的源位不会影响结果，所以固定掩码的二维图会沿未选位方向重复；掩码增加一个选择位时，结果域宽度增加一位。该函数不是普通`x & m`：按位与保留原位置，compress会改变位置并消除孔洞。

### SAG：稳定地把两组位分到左右

SAG把掩码选中的位收集到高端，把未选中的位收集到低端，并分别保持源位次序：

$$
\operatorname{SAG}(x,m)
=\operatorname{compressLeft}(x,m)
\mathbin{\mathrm{or}}
\operatorname{compress}(x,\mathbin{\mathrm{not}}m).
$$

<HDAppendixCSAGLab />

这是一种<Term def="按照掩码把位分成两组并保持每组内部源顺序的位级稳定划分。">稳定位分组</Term>。所有源位恰好进入其中一组，因此结果仍有$w$位，且1位总数保持不变。图中左区和右区的分界位置由$\operatorname{popcount}(m)$决定；改变掩码不仅改变取值，还改变分组边界。

### Rotate left：在环上重新编号

宽度$w$的循环左移把源位置$i$送到$(i+k)\bmod w$：

$$
\operatorname{rotl}_w(x,k)
=\left((x\ll k)\mathbin{\mathrm{or}}(x\gg(w-k))\right)
\bmod 2^w.
$$

<HDAppendixCRotateLeftLab />

普通左移会丢弃越过高端的位并在低端补零，循环左移则让越界位回到低端，所以它是位位置的双射。其逆操作是循环右移同样的$k$，或循环左移$w-k$。它保持popcount，也保持所有位的多重集合；这些性质比检查几个示例更适合做穷举验收。

```cpp
std::uint8_t compress8(std::uint8_t x, std::uint8_t mask) {
    std::uint8_t result = 0;
    unsigned destination = 0;
    for (unsigned source = 0; source != 8; ++source) {
        if ((mask & (1u << source)) == 0) continue;
        result |= ((x >> source) & 1u) << destination++;
    }
    return result;
}

std::uint8_t sag8(std::uint8_t x, std::uint8_t mask) {
    const unsigned selected = std::popcount(mask);
    const unsigned left = compress8(x, mask) << (8 - selected);
    const unsigned right = compress8(x, static_cast<std::uint8_t>(~mask));
    return static_cast<std::uint8_t>(left | right);
}

std::uint8_t rotl8(std::uint8_t x, unsigned k) {
    k &= 7;
    if (k == 0) return x;
    return static_cast<std::uint8_t>((x << k) | (x >> (8 - k)));
}
```

## C.5 2D Plots of Some Unary Functions（一元函数二维图）

<HDAppendixCUnaryPlotLab />

一元函数只需要横轴输入和纵轴输出。这种<Term def="把一元整数函数的输入放在横轴、输出放在纵轴，逐点观察台阶、尖峰和置换的图。">一元离散剖面</Term>保留每个整数样本，不连接成“真实连续曲线”。实验提供五种代表结构：

- `popcount(x)`的值域只有零到字长，但局部峰谷按二进制进位递归出现。
- `nlz(x)`在二的幂边界处下降一级，形成越来越宽的台阶。
- `ntz(x)`大多数点为零，在偶数、四的倍数、八的倍数处出现层级尖峰。
- Gray编码$x\mathbin{\mathrm{xor}}(x\gg1)$是输入集合到自身的置换，相邻输入只改变一位，但数值图并不单调。
- bit reverse也是置换；低位变化被送到高位，因此相邻输入常在纵轴上大幅跳跃。

以8位前导零和尾随零为例，零输入需要单独约定为8：

$$
\operatorname{nlz}_8(0)=\operatorname{ntz}_8(0)=8.
$$

如果省略这个约定，数学定义会在零点无定义，而机器指令或语言库可能选择不同返回值。图中的单个端点会因此改变，测试也必须跟随API契约，而不是跟随视觉印象。

## 同一个函数，为何会有三张不同的图

<HDAppendixCScaleLab />

原始乘积、4位模结果和选定位平面来自同一张乘法表，却回答不同问题。原始值图适合观察大小与因子；模图适合观察固定字长环绕；位平面适合观察某一输出位的布尔周期。选择色阶、归一化范围和位宽，实质上是在选择要保留的信息。

若每张图都按自己的最小值、最大值自动拉伸，局部对比会更清楚，但不同图之间的颜色不能直接比较；若所有图共用全局色阶，跨图比较可靠，小范围结构却可能被压暗。工程文档应把这个选择写进<Term def="规定图形定义域、数值解释、色阶、无效点和可执行不变量，使他人能够重画并核验结果。">可视化契约</Term>。

```ts
for (let x = 0; x !== 256; ++x) {
  for (let y = 1; y !== 256; ++y) {
    const q = Math.floor(x / y);
    const r = x % y;
    console.assert(q * y + r === x);
    console.assert(0 <= r && r < y);
  }
  for (let k = 0; k !== 8; ++k) {
    console.assert(rotr8(rotl8(x, k), k) === x);
    console.assert(popcount(rotl8(x, k)) === popcount(x));
  }
}
```

## 小结

A Gallery of Graphs of Discrete Functions（离散函数图形集）把整数数表转成可检验的空间结构。整数逻辑运算图由独立位平面叠加，呈现二的幂周期与对角对称；加减乘图显示线性等值线、因子结构和固定字长环绕；除法函数图通过商阶梯与余数条带暴露同一组倍数断点。compress改变稀疏位的位置，SAG完成稳定两组划分，rotate left在位环上实现双射。一元函数二维图则揭示计数台阶、尾零尖峰与位置换。真正可靠的图不止有纹理，还明确域、值、约定、色阶和不变量，能够被另一份实现重新生成并逐点核对。

  <GlossaryItem term="模环绕">固定字长结果越界后按模二的字长重新进入值域。</GlossaryItem>
  <GlossaryItem term="商阶梯">整数商只在被除数跨过除数倍数时跳变的台阶。</GlossaryItem>
  <GlossaryItem term="余数条带">余数从零增长并在每个除数倍数处重置的周期色带。</GlossaryItem>
  <GlossaryItem term="稳定位分组">按掩码分组并保持各组源位顺序的位排列。</GlossaryItem>
  <GlossaryItem term="一元离散剖面">逐点绘制一元整数输入与输出的二维图。</GlossaryItem>
  <GlossaryItem term="可视化契约">使离散图能够重画和核验的域、值、色阶、无效点与不变量约定。</GlossaryItem>
