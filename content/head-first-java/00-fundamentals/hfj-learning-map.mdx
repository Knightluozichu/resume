## 直觉引入

把 Java 编程想象成一个「盖房子的过程」。你要先学会「砌砖」（Java基础语法——变量、类型、运算符），再用砖头盖出「房间」（面向对象——类、对象、封装）；有了房间需要「家具和收纳」（核心API——ArrayList、HashMap等集合框架）；想让房子更高级就要学会「继承和扩展」（继承与多态——子类复用父类设计）；房子要住人需要「外观和门面」（Swing GUI——窗口、按钮、文本框）；住进去后要响应「门铃和开关」（事件处理——监听器、事件分发）；家里人多需要「多人同时干活」（并发与多线程——Thread、synchronized）；最后房子要和「外面的世界连通」（网络编程——Socket、ServerSocket）。

## 五阶段递进

<Term def="一次编写到处运行是Java的核心承诺——源码编译成平台无关的字节码，由各平台的JVM解释执行，实现跨平台。">一次编写到处运行</Term>是贯穿全书的基础。全书可以拆成五个递进阶段。**Java入门与OOP基础**解决「怎么写代码」和「怎么组织代码」——变量/类型/方法、类/对象/封装。**核心API与继承多态**解决「怎么复用代码」和「怎么扩展设计」——集合框架、继承、多态、接口。**Swing GUI与事件处理**解决「怎么交互」和「怎么响应」——窗口/组件/布局、监听器/事件队列/EDT。**并发与网络编程**解决「怎么并发」和「怎么通信」——Thread/synchronized、Socket/ServerSocket。

## 常见误区

<Callout type="trap">
**误区：会写 Java 语法就等于懂 Java 编程。** 会写 `System.out.println`、`new ArrayList` 只是「会用 API」——照着文档抄就能做。真正懂 Java 的人能解释：为什么 String 不可变（安全+线程安全+字符串常量池）、为什么 wait 要在 synchronized 内（需要持有锁才能释放）、为什么 EDT 是单线程（避免 GUI 组件并发访问）、为什么 Socket 通信要 flush（缓冲区数据未刷新）。把 Java 当黑盒的人遇到 NullPointerException 只会加 if 判空；懂机制的人知道是引用为 null 时调用了方法，知道用 Optional 或提前校验。区分标志：能否解释「Java 为什么这样设计」而非只是「能编译它」。
</Callout>

<Exercises>
**问题 1**：全书五阶段递进是什么？为什么是这个顺序？

<Answer>
Java入门与OOP基础 → 核心API与继承多态 → Swing GUI与事件处理 → 并发与网络编程 → 全书复习。顺序由依赖关系决定：先掌握基本语法和面向对象思维（这是 Java 编程的地基），再学习标准库集合和继承多态机制（有了类才能用集合，有了继承才能扩展）；GUI 需要类设计和 API 基础；事件处理依赖 GUI 组件；并发需要理解对象和线程生命周期；网络编程需要并发基础来处理多客户端。先「会写代码」，再「会用类库」，然后「能做界面」，接着「能处理交互」，再「能并发」，最后「能网络通信」。
</Answer>

**问题 2**：用「一个聊天室应用」描述全书主线。

<Answer>
一个聊天室应用经过全书多个知识点：①基础语法（第1章）——定义变量、控制流处理消息逻辑；②面向对象（第2章）——设计 Message 类、User 类封装消息和用户信息；③核心API（第3章）——用 ArrayList 管理消息历史，HashMap 管理在线用户；④继承多态（第4章）——抽象 Message 父类，TextMessage/ImageMessage 子类多态处理；⑤Swing GUI（第5章）——JFrame 聊天窗口、JTextArea 消息显示；⑥事件处理（第6章）——按钮点击发送消息的 ActionListener；⑦并发（第7章）——每个客户端一个线程，synchronized 保护共享消息列表；⑧网络（第8章）——ServerSocket 接受连接，Socket 收发消息。一个应用，全书知识点全部参与。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="一次编写到处运行">Java 的核心承诺。源码（.java）编译成平台无关的字节码（.class），由各平台的 JVM 解释或 JIT 编译执行。不同操作系统有各自的 JVM 实现，负责把同一份字节码翻译成平台机器指令。是 Java 跨平台的基础。</GlossaryItem>
<GlossaryItem term="五阶段递进">Java入门与OOP基础 → 核心API与继承多态 → Swing GUI与事件处理 → 并发与网络编程 → 全书复习。每层解决前一层的遗留问题：基础解决「怎么写代码」，API解决「怎么复用」，GUI解决「怎么交互」，并发解决「怎么同时」，网络解决「怎么通信」。</GlossaryItem>
<GlossaryItem term="JVM">Java虚拟机。Java 字节码的运行时环境，负责加载 .class 文件、解释/编译执行字节码、管理内存（堆/栈/方法区）和垃圾回收。是「一次编写到处运行」的实现核心。</GlossaryItem>
<GlossaryItem term="EDT">事件分发线程（Event Dispatch Thread）。Swing 的单线程事件处理模型，所有 GUI 事件和组件绘制都在 EDT 上串行执行。耗时操作不能在 EDT 上执行，否则界面冻结。</GlossaryItem>
</Glossary>
