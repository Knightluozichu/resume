## 从源码到运行

<Term def="字节码是Java源码编译后的中间格式，存储在.class文件中，与平台无关，由JVM解释或JIT编译执行。">字节码</Term>是 Java 跨平台的核心。Java 程序的生命周期分三步。

<HfjJavaBasicsDiagram />

```java
// 1. 编写源码 Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

// 2. 编译: javac Hello.java -> 生成 Hello.class (字节码)
// 3. 运行: java Hello -> JVM 加载 Hello.class, 执行 main 方法
```

## 基本数据类型

Java 有 8 种基本数据类型，它们直接存储值，不需要 new 创建对象。

```java
// 整数类型
byte   b = 127;        // 8位,  -128 ~ 127
short  s = 32767;      // 16位, -32768 ~ 32767
int    i = 2147483647; // 32位, 默认整数类型
long   l = 9999999999L;// 64位, 需加 L 后缀

// 浮点类型
float  f = 3.14f;      // 32位, 需加 f 后缀
double d = 3.14159;    // 64位, 默认浮点类型

// 字符类型
char   c = 'A';        // 16位 Unicode, 单引号

// 布尔类型
boolean flag = true;   // true 或 false
```

## 栈与堆

基本类型和引用类型在内存中的存储方式完全不同。

```java
// 基本类型: 值直接在栈上
int x = 42;         // 栈上直接存 42
double d = 3.14;    // 栈上直接存 3.14
boolean f = true;   // 栈上直接存 true

// 引用类型: 栈存引用地址, 堆存对象
String s = new String("hi");  // 堆上创建对象, 栈上 s 存地址
int[] arr = new int[]{1,2,3}; // 堆上创建数组, 栈上 arr 存地址

// 引用赋值 vs 基本类型赋值
int a = 10;
int b = a;    // 值拷贝: b=10, a 和 b 互不影响
b = 20;       // a 还是 10

String s1 = new String("hi");
String s2 = s1; // 引用拷贝: s2 和 s1 指向同一堆对象
s2 = new String("bye"); // s2 指向新对象, s1 不变
```

## 运算符与控制流

```java
// 算术运算符
int sum = 10 + 20;   // 30
int mod = 10 % 3;    // 1 (取余)

// 比较运算符: == != > < >= <=
// 逻辑运算符: && || !

// 条件语句
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}

// 循环语句
for (int j = 0; j < 5; j++) {
    System.out.println(j); // 0 1 2 3 4
}

// 数组
int[] nums = {10, 20, 30};
for (int n : nums) {
    System.out.println(n); // 10 20 30
}
```

## 常见误区

<Callout type="trap">
**误区：`==` 比较两个 String 的内容。** `==` 对引用类型比较的是地址（是否指向同一对象），不是内容。`new String("a") == new String("a")` 为 false，因为创建了两个不同对象。比较 String 内容必须用 `.equals()`：`"a".equals("a")` 为 true。字符串常量池是优化，不要依赖它——始终用 `.equals()` 比较内容。
</Callout>

<Exercises>
**问题 1**：`int x = 5;` 和 `String s = new String("hi");` 在内存中分别如何存储？

<Answer>
`int x = 5;`——x 是基本类型变量，值 5 直接存储在栈上，没有堆对象。`String s = new String("hi");`——分两步：①在堆上创建 String 对象存储 "hi"；②在栈上创建引用变量 s 存储堆对象的地址。s 不直接存 "hi"，而是存指向堆对象的引用。`String s2 = s;` 则 s2 和 s 指向同一个堆对象；而 `int y = x;` 是纯粹的值拷贝，y 和 x 互不影响。
</Answer>

**问题 2**：Java 的 main 方法为什么是 `public static void main(String[] args)`？

<Answer>
`public`——JVM 需从外部调用，必须公开。`static`——JVM 启动时没有对象实例，static 方法属于类可直接调用。`void`——main 不返回值给 JVM。`main`——JVM 约定的入口名称，必须精确匹配。`String[] args`——命令行参数数组。如果签名不匹配，JVM 会报 NoSuchMethodError。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="字节码">Java 源码（.java）经 javac 编译后的中间格式，存储在 .class 文件中。与平台无关，由各平台的 JVM 解释或 JIT 编译执行。是「一次编写到处运行」的技术基础。</GlossaryItem>
<GlossaryItem term="基本数据类型">Java 的 8 种内置类型：byte/short/int/long（整数）、float/double（浮点）、char（字符）、boolean（布尔）。变量直接存储值，在栈上分配，有默认值。</GlossaryItem>
<GlossaryItem term="引用类型">除基本类型外的所有类型（String、数组、自定义类等）。变量存储对象的地址（引用），对象在堆上分配。赋值是引用拷贝，多个引用可指向同一对象。</GlossaryItem>
<GlossaryItem term="栈与堆">栈存放方法局部变量（基本类型值、引用地址），方法结束自动回收，线程私有。堆存放 new 创建的对象，由 GC 回收，所有线程共享。基本类型在栈上存值，引用类型在堆上存对象。</GlossaryItem>
</Glossary>
