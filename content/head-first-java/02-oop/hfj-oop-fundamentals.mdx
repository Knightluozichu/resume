## 类与对象

<Term def="类是对象的蓝图（设计图纸），定义了属性（实例变量）和行为（方法）。对象是根据类创建的实例，各有自己的状态但共享同一套方法。">类与对象</Term>是面向对象编程的基础。类定义结构，对象承载状态。

<HfjOopFundamentalsDiagram />

```java
// 类 = 蓝图
class Dog {
    // 实例变量（状态）——每个对象各有自己的值
    int size;
    String breed;
    String name;

    // 方法（行为）——所有对象共用同一套方法
    void bark() {
        if (size > 60) {
            System.out.println("汪汪汪!");
        } else if (size > 14) {
            System.out.println("汪汪!");
        } else {
            System.out.println("汪!");
        }
    }
}

// 对象 = 实例
Dog dogA = new Dog();   // 堆上创建对象, 栈上 dogA 存引用
dogA.size = 70;
dogA.breed = "金毛";
dogA.name = "旺财";
dogA.bark();            // "汪汪汪!" —— 根据 size 选择

Dog dogB = new Dog();   // 另一个独立对象
dogB.size = 20;
dogB.bark();            // "汪汪!" —— 各自独立的状态
```

## 封装

封装是面向对象的核心原则：隐藏内部状态，只通过公开方法访问。

```java
// 不封装（坏实践）——外部可随意修改
class DogBad {
    int size; // public 默认, 外部可直接改
}
DogBad bad = new DogBad();
bad.size = -999; // 合法但荒谬! 狗的大小不可能是负数

// 封装（好实践）——用 private 隐藏, 用 public 暴露
class DogGood {
    private int size; // 外部不能直接访问

    public int getSize() {           // getter: 读取
        return size;
    }

    public void setSize(int s) {     // setter: 写入, 带校验
        if (s > 0) {
            size = s;                // 只允许正数
        }
    }
}
DogGood good = new DogGood();
good.setSize(70);   // 合法, size = 70
good.setSize(-1);   // 被拒绝, size 仍为 70
good.getSize();     // 70
```

## 构造器

```java
class Dog {
    private String name;
    private int size;

    // 构造器: 方法名=类名, 无返回类型
    public Dog(String name, int size) {
        this.name = name;    // this 指向当前对象
        this.size = size;
    }

    // 重载: 多个构造器, 参数不同
    public Dog(String name) {
        this(name, 40);      // 调用另一个构造器
    }

    void info() {
        System.out.println(name + ": " + size);
    }
}

Dog d1 = new Dog("旺财", 70);  // 调用两参构造器
Dog d2 = new Dog("小花");       // 调用单参构造器, size=40
d1.info();  // "旺财: 70"
d2.info();  // "小花: 40"

// 注意: 如果不写任何构造器, 编译器自动生成无参默认构造器
// 但一旦写了构造器, 编译器就不再生成默认无参构造器
```

## 实例变量 vs 局部变量

```java
class Example {
    // 实例变量: 在类中方法外
    // 存储在堆上(随对象), 有默认值(int=0, 引用=null)
    private int instanceVar = 10;

    public void myMethod() {
        // 局部变量: 在方法内
        // 存储在栈上(随方法栈帧), 必须初始化才能用
        int localVar = 20;

        System.out.println(instanceVar); // 10
        System.out.println(localVar);    // 20
    }
    // 方法结束: localVar 从栈上消失
    // instanceVar 随对象存在, 直到对象被 GC 回收
}
```

## 常见误区

<Callout type="trap">
**误区：构造器有返回类型。** 构造器没有返回类型，连 void 都没有。如果写了 `public void Dog()`，那不是构造器，而是一个普通的实例方法（名字碰巧叫 Dog）。调用 `new Dog()` 时不会调用它，而是调用编译器生成的默认无参构造器。构造器与普通方法的区别：①名称必须与类名相同；②无返回类型；③只能用 new 调用，不能用对象.方法名() 调用；④不能被继承（但子类构造器可调 super()）。
</Callout>

<Exercises>
**问题 1**：类和对象的关系是什么？用代码说明。

<Answer>
类是蓝图，对象是实例。一个类可创建无数对象，每个对象有相同的结构（相同的实例变量和方法）但各有自己的状态。例如 `class Dog` 定义了 size、breed、name 属性和 bark() 方法。`new Dog()` 创建一个对象 size=70, name="旺财"；再 `new Dog()` 创建另一个 size=20, name="小花"。它们共用同一套方法代码，但各自独立存储属性值。类定义在堆上不存在，对象通过 new 在堆上分配内存。
</Answer>

**问题 2**：实例变量和局部变量有什么区别？

<Answer>
实例变量：①声明在类中方法外，属于对象；②在堆上随对象分配；③有默认值（int=0, boolean=false, 引用=null）；④生命周期与对象相同。局部变量：①声明在方法内；②在栈上随方法栈帧分配；③没有默认值，必须初始化后才能使用；④生命周期与方法调用相同，方法返回时消失。关键区别：实例变量属于对象状态多个方法共享，局部变量属于方法临时数据方法间不共享。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="类">对象的蓝图/模板。定义了属性（实例变量）和行为（方法）。类本身不占堆内存，通过 new 创建对象时才在堆上分配。</GlossaryItem>
<GlossaryItem term="对象">根据类创建的实例。每个对象有独立的实例变量值（状态），但共享类中定义的方法代码。通过 new 在堆上分配，引用变量在栈上存储其地址。</GlossaryItem>
<GlossaryItem term="封装">面向对象核心原则。将数据（实例变量）用 private 隐藏，通过 public 方法（getter/setter）访问。好处：保护不变量（setter 中校验）、控制访问（只读/只写）、降低耦合（内部实现可变）。</GlossaryItem>
<GlossaryItem term="构造器">用于初始化对象的特殊方法。名称与类名相同，无返回类型，在 new 时自动调用。如果不写构造器，编译器生成默认无参构造器；一旦写了构造器，编译器不再生成默认无参构造器。</GlossaryItem>
</Glossary>
