## 集合框架

<Term def="集合框架是Java标准库提供的用于存储和操作一组对象的统一架构，核心接口是Collection和Map，各有多种实现类。">集合框架</Term>是 Java 最常用的 API。ArrayList 和 HashMap 是两大核心。

## ArrayList

```java
import java.util.ArrayList;

// 创建 ArrayList——只能存引用类型, 基本类型用包装类
ArrayList<String> list = new ArrayList<>();  // 菱形语法, 类型推断

// 增
list.add("Java");           // [Java]
list.add("Python");         // [Java, Python]
list.add(0, "C++");         // [C++, Java, Python] 指定位置插入

// 查
list.get(1);                // "Java" 按索引取
list.size();                // 3
list.contains("Java");      // true
list.indexOf("Python");     // 2

// 删
list.remove("C++");         // [Java, Python] 按值删
list.remove(0);             // [Python] 按索引删

// 遍历
for (String s : list) {
    System.out.println(s);
}

// ArrayList vs 数组
String[] arr = new String[3];  // 长度固定3
ArrayList<String> list = new ArrayList<>(); // 长度可变, 自动扩容
```

## HashMap

```java
import java.util.HashMap;

// 创建 HashMap<K, V>
HashMap<String, Integer> map = new HashMap<>();

// 增/改
map.put("Java", 1995);      // {Java=1995}
map.put("Python", 1991);    // {Java=1995, Python=1991}
map.put("Java", 1996);      // {Java=1996, Python=1991} 键相同则覆盖

// 查
map.get("Java");            // 1996
map.containsKey("Java");    // true
map.containsValue(1991);    // true
map.size();                 // 2

// 删
map.remove("Python");       // {Java=1996}

// 遍历
for (String key : map.keySet()) {
    System.out.println(key + ": " + map.get(key));
}
```

## 泛型与包装类

```java
// 泛型: 编译期类型检查, 避免运行时 ClassCastException
ArrayList<String> list = new ArrayList<>();
list.add("hi");
// list.add(123);  // 编译报错! 只能存 String

// 包装类: 基本类型 -> 引用类型
// int -> Integer, double -> Double, boolean -> Boolean
ArrayList<Integer> nums = new ArrayList<>();
nums.add(42);       // 自动装箱: int 42 -> Integer 对象
int n = nums.get(0);// 自动拆箱: Integer -> int

// Integer 缓存: -128~127 范围内的 Integer.valueOf() 返回缓存对象
Integer a = 127;
Integer b = 127;
System.out.println(a == b);   // true (缓存)

Integer c = 128;
Integer d = 128;
System.out.println(c == d);   // false (超出缓存范围, 新对象)
```

## 常见误区

<Callout type="trap">
**误区：用 `==` 比较 Integer 对象。** Integer 有缓存（-128~127），这个范围内 `==` 可能为 true，但超出范围就为 false。`new Integer(200) == new Integer(200)` 永远为 false，因为 new 总是创建新对象。比较 Integer 内容始终用 `.equals()`。同理，HashMap 的键如果是自定义类，必须正确重写 `hashCode()` 和 `equals()`——hashCode 决定桶位置，equals 决定是否匹配。两者不一致会导致 HashMap 找不到值或重复存储。
</Callout>

<Exercises>
**问题 1**：ArrayList 和普通数组有什么区别？

<Answer>
普通数组：①长度固定，创建后不可变；②可存基本类型和引用类型；③访问 O(1)。ArrayList：①长度可变，自动扩容（容量不足增长约1.5倍）；②只能存引用类型（基本类型用包装类）；③add/remove/get 方法丰富；④底层是动态数组，查询 O(1)，中间插入删除 O(n)。当元素数量不确定或需要频繁增删时用 ArrayList，元素数量固定且性能要求极高时用数组。
</Answer>

**问题 2**：为什么 ArrayList 不能存 int？HashMap 的 hashCode 和 equals 有什么作用？

<Answer>
ArrayList 泛型参数必须是引用类型，int 是基本类型不是 Object。必须用 `ArrayList<Integer>`。HashMap 的 put/get 原理：①用 key.hashCode() 定位桶位置；②用 key.equals() 在桶内精确匹配键。hashCode 决定存放位置（快速定位），equals 决定是否同一键（精确匹配）。如果 a.equals(b) 为 true，则 a.hashCode() 必须等于 b.hashCode()。自定义类作为键必须正确重写这两个方法。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="ArrayList">有序可重复的动态数组列表。底层用数组实现，查询 O(1)，中间插入删除 O(n)。自动扩容，容量不足时增长约 1.5 倍。是 List 接口最常用的实现。</GlossaryItem>
<GlossaryItem term="HashMap">键值映射表。底层用哈希表+链表/红黑树实现，增删查 O(1)。键唯一（重复 put 覆盖旧值），无序。键的 hashCode 定位桶，equals 精确匹配。是 Map 接口最常用的实现。</GlossaryItem>
<GlossaryItem term="泛型">编译期类型安全机制。`ArrayList<String>` 只能存 String，编译器检查类型，避免运行时 ClassCastException。菱形语法 `<>` 让编译器推断类型。集合只能用引用类型泛型。</GlossaryItem>
<GlossaryItem term="自动装箱/拆箱">Java 5+ 的自动类型转换。装箱：int → Integer（基本类型→包装类对象），拆箱：Integer → int。`list.add(42)` 自动装箱，`int n = list.get(0)` 自动拆箱。有性能开销，循环中大量操作要注意。Integer 有 -128~127 缓存。</GlossaryItem>
</Glossary>
