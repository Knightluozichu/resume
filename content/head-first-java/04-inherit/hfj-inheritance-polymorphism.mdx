## 继承

<Term def="IS-A测试是判断继承关系是否合理的方法：如果B是一个A在语义上成立，则B extends A是合理的。">IS-A 测试</Term>是判断继承合理性的标准。继承让子类复用父类的代码。

<HfjInheritancePolymorphismDiagram />

```java
// 父类
class Animal {
    String name;

    public Animal(String name) {
        this.name = name;
    }

    public void eat() {
        System.out.println(name + " is eating");
    }

    public void makeSound() {
        System.out.println("...");
    }
}

// 子类: extends 继承父类
class Dog extends Animal {
    public Dog(String name) {
        super(name);  // 调用父类构造器, 必须是第一行
    }

    @Override  // 标记重写, 编译器检查
    public void makeSound() {
        System.out.println("汪汪!");
    }

    public void fetch() {
        System.out.println(name + " fetches the ball");
    }
}

Dog dog = new Dog("旺财");
dog.eat();        // 继承自 Animal: "旺财 is eating"
dog.makeSound();  // 重写后: "汪汪!"
dog.fetch();      // Dog 独有方法

// IS-A 测试
// Dog IS-A Animal? 是 → 继承合理
// Animal IS-A Dog? 否 → 不能反过来继承
```

## 多态

```java
// 多态: 父类引用指向子类对象
Animal a1 = new Dog("旺财");
Animal a2 = new Cat("小花");
Animal a3 = new Wolf("灰太狼");

// 编译时类型都是 Animal, 运行时类型各不同
a1.makeSound();  // "汪汪!"  —— 调用 Dog 的重写方法
a2.makeSound();  // "喵喵"   —— 调用 Cat 的重写方法
a3.makeSound();  // "嗷呜"   —— 调用 Wolf 的重写方法

// 编译时类型 Animal 只能调 Animal 的方法
// a1.fetch();  // 编译报错! Animal 没有 fetch()

// 向下转型: 显式转换回子类类型
Dog d = (Dog) a1;
d.fetch();  // 现在可以调 Dog 独有方法了

// 安全转型: instanceof 检查
if (a1 instanceof Dog) {
    Dog dog = (Dog) a1;
    dog.fetch();
}
```

## 重写 vs 重载

```java
class Animal {
    public void makeSound() {
        System.out.println("...");
    }

    // 重载(overload): 同类中, 方法名同, 参数不同
    public void eat(String food) {
        System.out.println("eating " + food);
    }
    public void eat(String food, int amount) {
        System.out.println("eating " + amount + " " + food);
    }
}

class Dog extends Animal {
    // 重写(override): 父子类间, 方法签名完全相同
    @Override
    public void makeSound() {
        System.out.println("汪汪!");
    }

    // 重写不能缩小访问权限: 父public, 子不能protected
    // 重写返回类型可以是父类返回类型的子类型
}
```

## 接口与抽象类

```java
// 接口: 定义行为契约, 可多实现
interface Pet {
    void play();           // 抽象方法
    default void rest() {  // Java 8+ 默认方法
        System.out.println("resting");
    }
}

interface Swimmer {
    void swim();
}

// 抽象类: 提供共性代码, 只能单继承
abstract class Animal {
    String name;
    abstract void makeSound();  // 抽象方法, 子类必须实现
    void breathe() {            // 具体方法, 子类直接继承
        System.out.println("breathing");
    }
}

// 一个类可继承一个抽象类 + 实现多个接口
class Dog extends Animal implements Pet, Swimmer {
    @Override
    void makeSound() { System.out.println("汪汪!"); }

    @Override
    public void play() { System.out.println("playing"); }

    @Override
    public void swim() { System.out.println("swimming"); }
}
```

## 常见误区

<Callout type="trap">
**误区：重写（override）和重载（overload）是一样的。** 完全不同。重写发生在父子类间，方法签名完全相同，运行时根据对象实际类型决定调用哪个（动态绑定），是多态的基础。重载发生在同一个类内，方法名相同但参数列表不同，编译时根据参数类型决定调用哪个（静态绑定），不是多态，只是方法名复用。口诀：重写改实现，重载改参数。用 @Override 注解可以防止误写重写为重载。
</Callout>

<Exercises>
**问题 1**：多态的「编译时类型」和「运行时类型」是什么？

<Answer>
编译时类型（声明类型）：变量声明时的类型，编译器用于类型检查。`Animal a = new Dog();` 中 a 的编译时类型是 Animal，只能调 Animal 中声明的方法。运行时类型（实际类型）：对象创建时的实际类型，JVM 运行时决定调用哪个方法实现。`new Dog()` 的实际类型是 Dog。方法调用时编译器先检查编译时类型是否有该方法，运行时 JVM 根据实际对象类型调用对应重写实现——这就是动态绑定，多态的核心。
</Answer>

**问题 2**：接口和抽象类有什么区别？什么时候用哪个？

<Answer>
区别：①继承限制——一个类只能 extends 一个抽象类，但可 implements 多个接口；②成员变量——抽象类可有实例变量，接口只有常量；③方法实现——抽象类可有具体方法，Java 8 前接口全抽象；④构造器——抽象类有构造器，接口没有。何时用接口：定义行为契约/能力（如 Comparable、Runnable），需多继承。何时用抽象类：在继承体系中提供共性代码和模板方法，子类共享状态和部分实现。原则：优先用接口，需要共享代码时才引入抽象类。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="继承">子类通过 extends 获得父类的非 private 成员。子类可添加新成员或重写父类方法。IS-A 测试判断合理性：Dog IS-A Animal 成立。private 成员不继承，构造器不继承但子类构造器先调 super()。</GlossaryItem>
<GlossaryItem term="多态">父类引用指向子类对象，运行时动态绑定调用实际类型的方法。编译时类型决定能调什么方法，运行时类型决定调哪个实现。是多态的核心机制，让代码可扩展（新增子类不改旧代码）。</GlossaryItem>
<GlossaryItem term="方法重写">父子类间，方法签名完全相同，运行时动态绑定。用 @Override 注解标记。不能缩小访问权限，返回类型可为父类返回类型的子类型。是多态的基础。</GlossaryItem>
<GlossaryItem term="方法重载">同一个类内，方法名相同但参数列表不同，编译时静态绑定。不是多态，只是方法名复用。不能仅靠返回类型区分。</GlossaryItem>
</Glossary>
