## 组件层级

<Term def="JFrame是Swing的顶层窗口容器，ContentPane是实际存放用户组件的内容面板，默认使用BorderLayout布局。">JFrame 与 ContentPane</Term>是 Swing GUI 的基础。

<HfjSwingGuiDiagram />

```java
import javax.swing.*;

// 1. 创建顶层窗口
JFrame frame = new JFrame("我的第一个窗口");
frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);

// 2. 创建组件
JButton button = new JButton("点击我");
JLabel label = new JLabel("Hello, Swing!");
JTextField input = new JTextField(20);  // 20列宽

// 3. 添加组件到 ContentPane
// frame.add() 自动转发到 contentPane
frame.add(label, BorderLayout.NORTH);     // 上方
frame.add(input, BorderLayout.CENTER);    // 中间
frame.add(button, BorderLayout.SOUTH);    // 下方

// 4. 设置窗口大小并显示
frame.setSize(400, 300);
frame.setVisible(true);  // 最后调用!
```

## 布局管理器

```java
// BorderLayout: 5个区域 (JFrame默认)
// NORTH(上) SOUTH(下) EAST(右) WEST(左) CENTER(中)
frame.setLayout(new BorderLayout());
frame.add(button1, BorderLayout.NORTH);
frame.add(button2, BorderLayout.CENTER);  // CENTER 占据剩余空间

// FlowLayout: 从左到右排列, 排满换行 (JPanel默认)
JPanel panel1 = new JPanel(new FlowLayout());
panel1.add(new JButton("按钮1"));
panel1.add(new JButton("按钮2"));
panel1.add(new JButton("按钮3"));

// GridLayout: 网格, 等大单元格
JPanel panel2 = new JPanel(new GridLayout(3, 2)); // 3行2列
panel2.add(new JButton("1"));
panel2.add(new JButton("2"));
panel2.add(new JButton("3"));
panel2.add(new JButton("4"));
panel2.add(new JButton("5"));
panel2.add(new JButton("6"));

// BoxLayout: 水平或垂直排列, 不换行
JPanel panel3 = new JPanel();
panel3.setLayout(new BoxLayout(panel3, BoxLayout.Y_AXIS)); // 垂直
panel3.add(new JButton("上"));
panel3.add(new JButton("中"));
panel3.add(new JButton("下"));
```

## JPanel 中间容器

```java
// JPanel 用于分组和嵌套布局
JPanel northPanel = new JPanel(new FlowLayout());
northPanel.add(new JLabel("用户名:"));
northPanel.add(new JTextField(15));
northPanel.add(new JLabel("密码:"));
northPanel.add(new JPasswordField(15));

JPanel southPanel = new JPanel(new FlowLayout());
southPanel.add(new JButton("登录"));
southPanel.add(new JButton("注册"));

JFrame frame = new JFrame("登录界面");
frame.add(northPanel, BorderLayout.NORTH);
frame.add(southPanel, BorderLayout.SOUTH);
frame.add(new JTextArea("欢迎信息"), BorderLayout.CENTER);
frame.pack();       // 自动调整大小
frame.setVisible(true);
```

## 常见误区

<Callout type="trap">
**误区：setVisible(true) 可以在任何时候调用。** setVisible(true) 会触发窗口的首次布局计算和绘制。如果在此之前组件没添加完、布局没设置好，窗口显示时就会出现错误布局或空白。之后再添加组件虽然也能显示，但需要调用 revalidate() 和 repaint() 手动触发重排和重绘。最佳实践：先把所有组件添加好、布局设置好、大小设好，最后才调 setVisible(true)。
</Callout>

<Exercises>
**问题 1**：布局管理器的作用是什么？BorderLayout 和 FlowLayout 有什么区别？

<Answer>
布局管理器负责决定容器内组件的大小和位置，自动适应不同平台和窗口大小。BorderLayout 将容器分为5个区域（北南东西中），每个区域最多放一个组件，CENTER 占据剩余空间并拉伸，是 JFrame 的默认布局。FlowLayout 从左到右排列组件，排满换行，组件保持自然大小不拉伸，是 JPanel 的默认布局，适合按钮排列。
</Answer>

**问题 2**：JPanel 在 Swing 中扮演什么角色？为什么需要中间容器？

<Answer>
JPanel 是中间容器，用于：①分组——把相关组件组织到一起；②嵌套布局——不同 JPanel 用不同布局，组合实现复杂界面。需要中间容器的原因：JFrame 的 ContentPane 用 BorderLayout 只有5个区域，每个区域只能放一个组件。要放多个组件就需要先放在 JPanel 里，再把 JPanel 放到 ContentPane。没有中间容器，复杂界面无法用布局管理器组合实现。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="JFrame">Swing 顶层窗口容器。包含 JRootPane → ContentPane 层级。ContentPane 是实际存放用户组件的面板，默认使用 BorderLayout。通过 setSize/setVisible 控制大小和显示。</GlossaryItem>
<GlossaryItem term="布局管理器">决定容器内组件大小和位置的策略。BorderLayout 五区域、FlowLayout 流式排列、GridLayout 等大网格、BoxLayout 固定方向。跨平台自适应，不用手动设坐标。</GlossaryItem>
<GlossaryItem term="JPanel">Swing 中间容器。可设置自己的布局管理器，用于分组组件和嵌套布局。是 JComponent 子类，可复用和自定义。没有 JPanel 无法用布局管理器组合实现复杂界面。</GlossaryItem>
<GlossaryItem term="常用组件">JButton（按钮）、JLabel（标签/图标）、JTextField（单行输入）、JTextArea（多行输入）、JPasswordField（密码输入）、JScrollPane（滚动面板）。都是 JComponent 子类。</GlossaryItem>
</Glossary>
