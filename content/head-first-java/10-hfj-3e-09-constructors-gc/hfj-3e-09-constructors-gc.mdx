## 为什么“第9章 对象的生与死：构造器与垃圾回收”必须从可运行证据开始

追踪栈帧、堆对象、构造链和可达性，解释初始化顺序与对象何时具备回收资格。本页属于正式单元，目标不是复制原书正文、插图或趣味题，而是依照 O'Reilly 官方第3版完整目录，把核心标题重构为预测、代码、对象图、失败注入和验收工件。正式节点共21个，最终产物是栈/堆时序图、构造链日志与可达性判定表。

Java 程序同时存在源代码、编译期类型、字节码、运行时对象、调用栈、线程和外部资源七种观察面。只看最终输出，可能把引用别名、异常传播、惰性求值或竞态隐藏起来；只背语言规则，又无法证明自己能在真实程序中定位状态。因此每个结论都要同时回答“编译器允许什么”“运行时发生什么”“证据怎样复现”。
