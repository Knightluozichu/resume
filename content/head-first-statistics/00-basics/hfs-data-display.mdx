## 直觉引入

给你 200 个考试成绩，密密麻麻的数字看不出任何规律。但如果画成直方图，你一眼就能看到：大部分人在 70-80 分，有人特别低，分布大致对称。这就是可视化的力量——让数据「说话」。

数据展示不是装饰，而是分析。不同类型的需要不同的图表：名目型数据（如性别、颜色）用条形图和饼图，数值型数据（如身高、成绩）用直方图和频率折线图。选错图表会误导分析。

## 概念讲解

### 数据类型

<Term def="名目型数据是无内在顺序的类别数据，如性别、颜色、品牌">名目型数据</Term>用条形图和饼图展示。

<Term def="数值型数据是有大小关系的数值，如身高、成绩、温度">数值型数据</Term>用直方图、频率折线图、箱线图展示。

### 频率表与直方图

<Term def="频率表是将数据按区间分组并统计每组频数的表格">频率表</Term>把连续数据分成若干区间（组距），统计落入每组的频数。

<Term def="直方图是用柱形表示数值型数据频率分布的图表，柱宽=组距，柱高=频率密度">直方图</Term>是频率表的可视化。关键区别：条形图的柱之间有间隔（离散），直方图的柱相连（连续）。

### 累积频率

<Term def="累积频率曲线（OGIVE）是逐组累加频率并连线得到的曲线，用于读取百分位数">累积频率曲线</Term>可以快速估计「低于某值的比例」。

<Stepper>
<Step title="第一步：确定组数和组距">
组数通常取 $\lceil \sqrt{n} \rceil$ 或 Sturges 公式 $k = 1 + 3.322 \log n$。组距 = (最大值 - 最小值) / 组数。例如 200 个数据，$\sqrt{200} \approx 14$ 组。成绩范围 40-100，组距 = 60/14 ≈ 5。
</Step>
<Step title="第二步：制作频率表">
按组距分组，统计每组的频数和频率。例如 60-65 分有 8 人（频率 4%），65-70 分有 15 人（频率 7.5%），70-75 分有 40 人（频率 20%），75-80 分有 60 人（频率 30%）。
</Step>
<Step title="第三步：画直方图">
横轴是数值区间，纵轴是频率密度（频率/组距）。柱相连无间隔。从直方图可以看出分布形态：对称、左偏、右偏、单峰、双峰。累积频率曲线可读出百分位数。
</Step>
</Stepper>

## 代码对照

```python
# 数据可视化
import numpy as np
from collections import Counter

# 生成考试成绩数据
np.random.seed(42)
scores = np.random.normal(75, 10, 200).clip(0, 100).astype(int)

# 1. 频率表
def frequency_table(data, num_bins=10):
    data_min, data_max = min(data), max(data)
    bin_width = (data_max - data_min) / num_bins
    bins = [data_min + i * bin_width for i in range(num_bins + 1)]
    freq = [0] * num_bins
    for v in data:
        idx = min(int((v - data_min) / bin_width), num_bins - 1)
        freq[idx] += 1
    for i in range(num_bins):
        lo, hi = bins[i], bins[i+1]
        pct = freq[i] / len(data) * 100
        print(f"  [{lo:.0f}, {hi:.0f}): {freq[i]:3d} ({pct:.1f}%)")
    return freq

print("频率表:")
freq = frequency_table(scores)

# 2. 累积频率
cum_freq = np.cumsum(freq) / len(scores) * 100
print(f"\n中位数估计（累积频率50%）: {np.interp(50, cum_freq, np.linspace(40, 100, 10)):.1f}")

# 3. 名目型数据：条形图
colors = ['红', '蓝', '绿', '黄']
counts = [45, 30, 15, 10]
print("\n名目型数据（颜色偏好）:")
for c, n in zip(colors, counts):
    print(f"  {c}: {'█' * (n // 2)} {n}")
```

## 常见误区

<Callout type="trap">
**误区：直方图和条形图可以互换使用。**
直方图用于数值型数据（连续，柱相连），条形图用于名目型数据（离散，柱有间隔）。混用会误导：用条形图画连续数据会丢失「连续」的信息，用直方图画离散类别会暗示不存在的连续性。
</Callout>

<Callout type="trap">
**误区：组数越多直方图越准确。**
组数太少会过度平滑（看不到细节），太多会过度噪化（每组只有一两个数据）。Sturges 公式 $k = 1 + 3.322 \log n$ 是经验起点，实际应根据数据量和分布形态调整。200 个数据通常用 10-15 组。
</Callout>

<Exercises>
**问题 1**：为什么可视化是统计分析的第一步？

<Answer>
因为人眼擅长识别图形模式但不擅长从数字表格中提取信息。可视化能快速揭示分布形态（对称/偏态）、集中趋势（峰值位置）、离散程度（数据散布范围）、异常值（远离主体的点）和分组模式（单峰/双峰）。这些信息指导后续统计分析——例如右偏分布用中位数而非均值，双峰分布可能需要分组分析。跳过可视化直接计算统计量可能选错分析方法。
</Answer>

**问题 2**：名目型数据和数值型数据各用什么图表？为什么不能混用？

<Answer>
名目型数据（如性别、品牌）用条形图和饼图——柱有间隔表示类别离散，饼图表示占比。数值型数据（如身高、成绩）用直方图——柱相连表示连续。混用的问题：用条形图画连续数据会丢失连续性信息（如 70-75 和 75-80 之间不是断裂的），用直方图画离散类别会暗示不存在的连续过渡（如红色和蓝色之间没有「红蓝色」）。
</Answer>
</Exercises>

<GlossaryItem term="名目型数据">
无内在顺序的类别数据，如性别、颜色、品牌。用条形图和饼图展示。
