## 直觉引入

你手头有一组考试成绩，怎么从中提取信息？第一步是画图看分布（数据展示），第二步是算均值看中心（集中趋势），第三步是算方差看波动（离散程度），第四步是建模型预测（概率分布），第五步是从样本推断总体（统计推断）。

《深入浅出统计学》按这个逻辑组织：先学「怎么描述数据」，再学「数据服从什么规律」，最后学「怎么从局部推断全局」。全书的核心思想是：**统计学是从数据中提取信息、在不确定性中做决策的科学**。

## 概念讲解

### 全书四大板块

<Term def="统计基础是收集、整理和展示数据的方法——频率表、直方图、条形图">统计基础</Term>是全书的起点。在分析数据之前，先要「看见」数据。

<Term def="集中趋势和离散程度是描述数据分布的两大维度——均值/中位数/众数描述中心，极差/方差/标准差描述散布">集中趋势与离散</Term>是描述统计的核心。光知道「平均分 75」不够，还需要知道「标准差 10」才能判断分布形态。

<Term def="概率与分布是将现实世界随机现象数学模型化的工具——从古典概率到二项分布到正态分布">概率与分布</Term>连接了描述统计和推断统计。正态分布是统计推断的理论基础。

### 描述统计 vs 推断统计

<Term def="推断统计是从样本数据推断总体特征的统计方法——抽样分布、置信区间、假设检验">推断统计</Term>是统计学的终极目标。我们关心的通常是总体（如全国选民），但只能观测样本（如 1000 名受访者）。

## 代码对照

```python
# 统计学全流程演示
import numpy as np
import matplotlib.pyplot as plt

# 1. 统计基础：生成数据并展示
np.random.seed(42)
scores = np.random.normal(75, 10, 200)  # 模拟考试成绩

# 2. 集中趋势
mean = np.mean(scores)
median = np.median(scores)
print(f"均值: {mean:.1f}, 中位数: {median:.1f}")

# 3. 离散程度
variance = np.var(scores)
std = np.std(scores)
print(f"方差: {variance:.1f}, 标准差: {std:.1f}")

# 4. 概率分布：检查是否近似正态
from scipy import stats
# 正态性检验
stat, p = stats.shapiro(scores)
print(f"正态性检验 p值: {p:.4f} (p>0.05 表示正态)")

# 5. 统计推断：从样本推断总体
# 95% 置信区间
n = len(scores)
se = std / np.sqrt(n)  # 标准误
margin = 1.96 * se
print(f"总体均值 95% CI: [{mean-margin:.1f}, {mean+margin:.1f}]")
```

## 常见误区

<Callout type="trap">
**误区：认为统计学就是算均值和画图表。**
描述统计（均值、图表）只是统计学的入门。统计学的核心价值在于推断统计——从样本推断总体、评估不确定性、做出有置信度的决策。A/B 测试、民意调查、药物试验的本质都是统计推断。
</Callout>

<Callout type="trap">
**误区：认为概率论和统计学是同一个东西。**
概率论是「已知模型推结果」（如已知骰子公平，求掷出 6 的概率）。统计学是「已知结果推模型」（如掷了 1000 次骰子，推断骰子是否公平）。方向相反，但工具相通。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？描述统计和推断统计的区别是什么？

<Answer>
四大板块：统计基础（数据展示）、集中趋势与离散（描述统计）、概率与分布（模型化）、统计推断（从样本推总体）。描述统计总结已知数据（均值、方差），推断统计从样本推断未知总体（置信区间、假设检验）。描述是基础，推断是目标。
</Answer>

**问题 2**：为什么统计推断是统计学的终极目标？

<Answer>
因为我们关心的通常是总体（如全国选民支持率、全部产品的合格率），但观测全部总体成本太高或不可能。只能抽取样本观测，然后用统计方法推断总体特征。统计推断提供了「从局部推断全局」的数学框架——置信区间量化推断的不确定性，假设检验控制推断的错误率。没有统计推断，统计学就停留在数据描述层面，无法支撑决策。
</Answer>
</Exercises>

收集、整理和展示数据的方法——频率表、直方图、条形图。可视化是统计分析的第一步。

</GlossaryItem>
<GlossaryItem term="正态分布">
钟形对称分布，是中心极限定理的基础。统计推断的理论支撑，许多统计方法假设数据服从正态分布。
