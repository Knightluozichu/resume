## 直觉引入

假设你要向朋友描述一个班级的成绩：「平均分 75 分」是一种说法，「一半人不到 72 分」是另一种，「最常见的分数是 70 分」是第三种。三种说法描述了同一个数据集的「中心」，但角度不同。

均值利用所有数据点的信息但怕异常值；中位数鲁棒但只用了中间位置；众数最直观但可能不存在或不唯一。选哪个取决于数据分布和你的目的。

## 概念讲解

### 均值

<Term def="均值是所有数据之和除以数据个数，是最常用的集中趋势度量">均值</Term>：$\bar{x} = \frac{1}{n}\sum x_i$

均值利用了每个数据点的信息，但对异常值极其敏感。

### 中位数

<Term def="中位数是将数据排序后位于中间位置的值，对异常值不敏感">中位数</Term>：$n$ 为奇数时取第 $(n+1)/2$ 个；$n$ 为偶数时取中间两个的平均。

### 众数

<Term def="众数是数据中出现频率最高的值，唯一可用于名目型数据的集中趋势度量">众数</Term>可能有多个（双峰分布），也可能不存在（所有值都不同）。

### 偏态中的关系

<Term def="偏态是分布不对称的程度。右偏（正偏）均值>中位数>众数；左偏（负偏）均值<中位数<众数">偏态</Term>：

- 右偏分布（如收入）：均值 > 中位数 > 众数（高端异常值拉高均值）
- 左偏分布（如退休年龄）：均值 < 中位数 < 众数
- 对称分布：均值 = 中位数 = 众数

<Step title="第一步：判断数据类型">
名目型数据（如品牌偏好）只能用众数——均值和中位数对类别无意义。数值型数据可以用均值、中位数或众数。
</Step>
<Step title="第二步：检查偏态和异常值">
画直方图或箱线图检查分布形态。如果对称且无异常值，用均值（信息量最大）。如果右偏或有异常值（如收入），用中位数（鲁棒）。
</Step>
<Step title="第三步：考虑目的">
如果关心「总量分配」（如人均 GDP），用均值。如果关心「典型个体」（如中等收入），用中位数。如果关心「最常见值」（如最热销尺码），用众数。
</Step>
</Stepper>

## 代码对照

```python
# 集中趋势度量
import statistics
import numpy as np

# 成绩数据
scores = [65, 70, 72, 68, 75, 80, 72, 68, 90, 72]

mean = statistics.mean(scores)
median = statistics.median(scores)
mode = statistics.mode(scores)
print(f"均值: {mean}")      # 73.2
print(f"中位数: {median}")   # 72
print(f"众数: {mode}")       # 72

# 收入数据（右偏，有极端值）
incomes = [30, 35, 40, 42, 45, 50, 55, 60, 200]  # 200是异常值
print(f"\n收入均值: {statistics.mean(incomes):.1f}")   # 61.9（被200拉高）
print(f"收入中位数: {statistics.median(incomes)}")      # 45（不受200影响）
print(f"收入众数: 无（各值唯一）")

# 偏态判断
mean_income = statistics.mean(incomes)
median_income = statistics.median(incomes)
if mean_income > median_income:
    print("均值 > 中位数 → 右偏分布（高端异常值拉高均值）")
    print("→ 应报告中位数（更能代表典型收入）")

# 加权均值示例
weights = [3, 5, 2]  # 学分
grades = [85, 90, 78]  # 成绩
weighted_mean = sum(w * g for w, g in zip(weights, grades)) / sum(weights)
print(f"\n加权均值（GPA）: {weighted_mean:.1f}")  # 85.9
```

## 常见误区

<Callout type="trap">
**误区：均值总是最好的集中趋势度量。**
均值对异常值极其敏感。收入数据中，少数亿万富翁让人均收入虚高，但大多数人的收入远低于均值。右偏分布应报告中位数。「人均收入 10 万」可能掩盖了「中位数收入 5 万」的现实。
</Callout>

<Callout type="trap">
**误区：众数没有用。**
众数在特定场景下是最合适的度量。服装店的「最热销尺码」用众数而非均值（均码没有意义）。搜索引擎的「最常见查询」用众数。众数是唯一适用于名目型数据的集中趋势度量。
</Callout>

<Exercises>
**问题 1**：为什么收入数据用中位数而非均值？

<Answer>
收入数据是右偏分布——少数极高收入（亿万富翁）会大幅拉高均值，使均值远高于大多数人的实际收入。例如 9 人收入 30-60 万 + 1 人收入 200 万，均值 62 万但中位数 45 万。中位数不受极端值影响，更能反映「典型收入」。各国政府报告中位数收入而非人均收入正是因为此。
</Answer>

**问题 2**：数据 [65,70,72,68,75,80,72,68,90,72] 的均值、中位数、众数各是多少？判断分布形态。

<Answer>
均值 = 732/10 = 73.2。中位数：排序 [65,68,68,70,72,72,72,75,80,90]，取第5、6个平均 = 72。众数 = 72（出现3次最多）。均值 73.2 > 中位数 72 > 众数 72，略右偏（90 分拉高了均值）。但偏斜不大，三者接近，分布大致对称。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="均值">
所有数据之和除以数据个数。利用所有数据点的信息，但对异常值敏感。适合对称分布。
</GlossaryItem>
<GlossaryItem term="中位数">
排序后中间位置的值。对异常值鲁棒，适合偏态分布（如收入）。
</GlossaryItem>
<GlossaryItem term="众数">
出现频率最高的值。唯一适用于名目型数据的集中趋势度量。可能多个或不存在。
</GlossaryItem>
<GlossaryItem term="偏态">
分布不对称程度。右偏：均值>中位数>众数。左偏：均值<中位数<众数。对称：三者相等。
</GlossaryItem>
