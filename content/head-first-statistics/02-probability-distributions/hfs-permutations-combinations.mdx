### 核心单元

1. **阶乘**：n个不同对象全排列的数量，递归满足n乘(n减1)阶乘。
2. **排列**：从n个不同对象取r个且顺序重要。
3. **组合**：从n个不同对象取r个但内部顺序不重要。
4. **重复对象排列**：相同类型交换不产生新结果，需要除以各类型数量的阶乘。
5. **计数假设**：等可能性、可区分性和是否放回必须先声明。

## 验收证书

证书包括原始计数、阶乘定义、排列变换、组合计算、重复对象排列边界和计数假设结论。每个百分比都能回到分子分母，每个图都标明尺度和样本量，每个检验都给效应与区间，每个随机过程都记录种子。

## 可核查推导

$$
P(n,r)=\frac{n!}{(n-r)!},\qquad {n\choose r}=\frac{n!}{r!(n-r)!}
$$

有序选择r个位置时依次有n、n减1直到n减r加1种，得到排列数。每个无序集合在排列中被内部r阶乘种次序重复计算，因此除以r阶乘得到组合数。 每一步都要注明使用定义、独立性、分布假设还是渐近近似；若只在大样本下成立，就不能把小样本结果包装成精确结论。

```python
from math import factorial

def choose(n, r):
    return factorial(n) // (factorial(r) * factorial(n-r))

assert choose(20, 3) == 1140
```

程序只检查有限实例。解析公式、模拟频率和独立实现应三路对照；若三者不一致，先检查参数化、端点、自由度和随机种子。

## 机制与数据流

**阶乘**：n个不同对象全排列的数量，递归满足n乘(n减1)阶乘。

**排列**：从n个不同对象取r个且顺序重要。

**组合**：从n个不同对象取r个但内部顺序不重要。

数据流写成“总体 → 抽样或观察 → 统计量 → 抽样分布 → 决策”。任何聚合都保留分母、缺失数和分组规则，避免统计量脱离生成过程。


## 边界与失败模式

**重复对象排列**：相同类型交换不产生新结果，需要除以各类型数量的阶乘。

**计数假设**：等可能性、可区分性和是否放回必须先声明。

边界测试包括零样本、单样本、不平衡类别、概率极端、离群点、强偏态、相关观测和数值退化。失败应返回明确状态，不能用NaN或一张空图悄悄结束。
