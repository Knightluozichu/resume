## 直觉引入

人的身高不是 170cm 或 171cm——它可以是从 170.000 到 171.000 之间的任何值。连续随机变量的概率不能像离散变量那样用「有利/总数」计算，因为可能值有无限多个。

取而代之的是概率密度函数（PDF）——它不直接给出某点的概率（单点概率为 0），而是给出曲线下面积的「概率密度」。最常见的连续分布是正态分布——那个钟形曲线几乎无处不在。

## 概念讲解

### 概率密度函数

<Term def="概率密度函数 f(x) 描述连续随机变量在各点的密度，概率等于曲线下面积：P(a<X<b) = ∫f(x)dx">概率密度</Term>。单点概率为 0（面积 0），但区间概率非 0。

### 正态分布

<Term def="正态分布 N(μ,σ²) 是钟形对称分布，由均值 μ 和标准差 σ 决定">正态分布</Term>。

<Term def="Z 分数将任意正态分布标准化为标准正态 N(0,1)：Z = (x-μ)/σ">Z 分数</Term>。通过 Z 分数查标准正态表可得任意区间的概率。

68-95-99.7 法则：$\mu \pm 1\sigma$ 覆盖 68%，$\mu \pm 2\sigma$ 覆盖 95%，$\mu \pm 3\sigma$ 覆盖 99.7%。

### 其他连续分布

<Term def="均匀分布在区间 [a,b] 上每点密度相等：f(x) = 1/(b-a)">均匀分布</Term>。

<Term def="指数分布描述两次稀有事件之间的等待时间：f(x) = λe^(-λx)，期望 1/λ">指数分布</Term>。与泊松分布对偶——泊松数次数，指数等时间。

<Stepper>
<Step title="第一步：确定参数"> 确定均值 μ 和标准差 σ。例如考试成绩服从 N(75, 10²)，μ=75，σ=10。</Step>
<Step title="第二步：计算 Z 分数"> 将目标值 x 转为 Z 分数：$Z = (x - \mu) / \sigma$。例如成绩 85 对应 $Z = (85-75)/10 = 1$。成绩 60 对应 $Z = (60-75)/10 = -1.5$。</Step>
<Step title="第三步：查表求概率"> 查标准正态表。P(Z&lt;1) = 0.8413，所以 P(X&gt;85) = 1 - 0.8413 = 0.1587（约 15.9%）。P(Z&lt;-1.5) = 0.0668，所以 P(X&lt;60) = 6.68%。P(60&lt;X&lt;85) = P(Z&lt;1) - P(Z&lt;-1.5) = 0.8413 - 0.0668 = 0.7745。</Step>
</Stepper>

## 代码对照

```python
# 连续概率分布
from scipy import stats
import numpy as np

# 1. 正态分布：考试成绩 N(75, 10²)
mu, sigma = 75, 10

# P(X > 85) = P(Z > 1)
p_above_85 = 1 - stats.norm.cdf(85, mu, sigma)
print(f"P(X>85) = {p_above_85:.4f}")  # 约 0.1587

# P(60 &lt; X &lt; 85) = P(-1.5 &lt; Z &lt; 1)
p_between = stats.norm.cdf(85, mu, sigma) - stats.norm.cdf(60, mu, sigma)
print(f"P(60<X<85) = {p_between:.4f}")  # 约 0.7745

# 68-95-99.7 法则验证
within_1 = stats.norm.cdf(mu+sigma, mu, sigma) - stats.norm.cdf(mu-sigma, mu, sigma)
within_2 = stats.norm.cdf(mu+2*sigma, mu, sigma) - stats.norm.cdf(mu-2*sigma, mu, sigma)
within_3 = stats.norm.cdf(mu+3*sigma, mu, sigma) - stats.norm.cdf(mu-3*sigma, mu, sigma)
print(f"±1σ: {within_1:.4f}, ±2σ: {within_2:.4f}, ±3σ: {within_3:.4f}")

# 2. Z 分数计算
z_85 = (85 - mu) / sigma  # 1.0
z_60 = (60 - mu) / sigma  # -1.5
print(f"\nZ(85) = {z_85}, Z(60) = {z_60}")

# 3. 均匀分布：等公交车 0-10 分钟
a, b = 0, 10
# P(等3-7分钟) = (7-3)/(10-0) = 0.4
p_uniform = (7 - 3) / (b - a)
print(f"\n均匀 P(3<X&lt;7) = {p_uniform}")  # 0.4

# 4. 指数分布：平均5分钟一个电话，等下一个电话
lam_exp = 1/5  # λ = 1/期望
# P(等待&lt;3分钟) = 1 - e^(-λt)
p_wait_3 = 1 - np.exp(-lam_exp * 3)
print(f"指数 P(等待&lt;3分钟) = {p_wait_3:.4f}")  # 约 0.4512
```

## 常见误区

<Callout type="trap">
**误区：概率密度函数的值是概率。**
PDF 的值 f(x) 可以大于 1（如均匀分布 U(0, 0.5) 的密度是 2）。概率是曲线下面积（积分），不是密度值本身。单点概率为 0——连续变量取任何特定值的概率都是 0，只有区间概率才有意义。
</Callout>

<Callout type="trap">
**误区：所有连续数据都服从正态分布。**
正态分布常见（中心极限定理），但不是万能。等待时间服从指数分布，随机选取的位置服从均匀分布，收入服从对数正态分布。用 Q-Q 图或假设检验验证分布类型。盲目假设正态会导致错误的概率估计。
</Callout>

<Exercises>
**问题 1**：为什么正态分布是统计推断的核心？

<Answer>
因为中心极限定理：样本均值的分布随样本量增大趋近正态分布，无论总体分布如何。这意味着：(1) 大样本下可以用正态分布构造置信区间和假设检验；(2) 许多统计量（如 t 统计量、卡方统计量）的分布从正态导出；(3) 正态分布的数学性质优美（线性变换保持正态性、独立正态变量之和仍正态）。正态分布是统计推断的「通用语言」。
</Answer>

**问题 2**：考试成绩 N(75, 10²)，求 P(X>85) 和 P(60&lt;X&lt;85)。

<Answer>
P(X>85)：Z=(85-75)/10=1，P(Z>1)=1-0.8413=0.1587（约15.9%）。P(60&lt;X&lt;85)：Z₁=(60-75)/10=-1.5，Z₂=(85-75)/10=1。P(-1.5&lt;Z&lt;1)=P(Z&lt;1)-P(Z&lt;-1.5)=0.8413-0.0668=0.7745（约77.5%）。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="概率密度函数">
描述连续随机变量密度的函数 f(x)。概率=曲线下面积=积分。单点概率为0，区间概率非0。
</GlossaryItem>
<GlossaryItem term="正态分布">
钟形对称分布 N(μ,σ²)。68-95-99.7 法则。中心极限定理使其成为统计推断核心。
</GlossaryItem>
<GlossaryItem term="Z 分数">
标准化正态分布：Z=(x-μ)/σ。将任意正态分布转为标准正态 N(0,1)，便于查表求概率。
</GlossaryItem>
<GlossaryItem term="指数分布">
描述两次稀有事件间等待时间的连续分布。f(x)=λe^(-λx)。期望 1/λ。与泊松分布对偶。
</GlossaryItem>
</Glossary>
