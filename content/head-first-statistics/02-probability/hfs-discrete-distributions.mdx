## 直觉引入

投篮 10 次中 3 次的概率是多少？等第一辆车经过要等多久？每小时接到几个电话？这三个看似不同的问题，分别对应三种离散概率分布：二项分布、几何分布和泊松分布。

离散概率分布描述离散随机变量的概率规律。选对分布模型，就能用简洁的数学公式计算复杂事件的概率，而不用逐一列举所有可能。

## 概念讲解

### 二项分布

<Term def="二项分布 B(n,p) 描述 n 次独立伯努利试验中成功 k 次的概率：P(X=k) = C(n,k)·p^k·(1-p)^(n-k)">二项分布</Term>。

期望 $E[X] = np$，方差 $\text{Var}(X) = np(1-p)$。

### 几何分布

<Term def="几何分布描述首次成功所需的试验次数：P(X=k) = (1-p)^(k-1)·p">几何分布</Term>。

期望 $E[X] = 1/p$。例如投篮命中率 30%，平均需投 $1/0.3 \approx 3.3$ 次才首次命中。

### 泊松分布

<Term def="泊松分布 Poisson(λ) 描述单位时间/空间内稀有事件发生次数：P(X=k) = λ^k·e^(-λ)/k!">泊松分布</Term>。

期望和方差都等于 $\lambda$。当二项分布的 $n$ 大、$p$ 小（$np \to \lambda$）时，泊松分布是二项分布的良好近似。

## 代码对照

```python
# 离散概率分布
from scipy import stats
import numpy as np

# 1. 二项分布：投篮10次命中3次（命中率40%）
n, p = 10, 0.4
prob_3 = stats.binom.pmf(3, n, p)
print(f"二项 P(X=3) = {prob_3:.4f}")  # 约 0.2150
print(f"E[X] = {n*p}, Var = {n*p*(1-p)}")  # 4, 2.4

# 累积概率：P(X<=3)
prob_le3 = stats.binom.cdf(3, n, p)
print(f"P(X<=3) = {prob_le3:.4f}")  # 约 0.3823

# 2. 几何分布：首次命中需要投几次（命中率40%）
p_geo = 0.4
# P(X=1) = 0.4, P(X=2) = 0.6*0.4 = 0.24, P(X=3) = 0.6²*0.4 = 0.144
for k in range(1, 6):
    prob = (1 - p_geo)**(k-1) * p_geo
    print(f"几何 P(X={k}) = {prob:.4f}")
print(f"E[X] = {1/p_geo:.1f}")  # 2.5 次首次命中

# 3. 泊松分布：每小时5个电话，接到3个的概率
lam = 5
prob_3_calls = stats.poisson.pmf(3, lam)
print(f"\n泊松 P(X=3) = {prob_3_calls:.4f}")  # 约 0.1404
print(f"E[X] = Var(X) = {lam}")  # 5

# 4. 泊松近似二项：n=1000, p=0.005, λ=np=5
n_approx, p_approx = 1000, 0.005
binom_p = stats.binom.pmf(3, n_approx, p_approx)
poisson_p = stats.poisson.pmf(3, n_approx * p_approx)
print(f"\n二项 P(X=3) = {binom_p:.6f}")
print(f"泊松 P(X=3) = {poisson_p:.6f}")  # 几乎相同
```

## 常见误区

<Callout type="trap">
**误区：二项分布的「n 次试验」可以不等概率。**
二项分布要求 n 次试验独立且每次成功概率 p 相同。如果概率不同（如不同难度的题目），不能用二项分布。同理如果试验不独立（如不放回抽样），需要用超几何分布。
</Callout>

<Callout type="trap">
**误区：泊松分布和指数分布是同一个东西。**
泊松分布描述「单位时间内事件发生次数」（离散，k=0,1,2,...）。指数分布描述「两次事件之间的等待时间」（连续，t>0）。两者相关但不同——泊松是计数，指数是等待时间。
</Callout>

<Exercises>
**问题 1**：泊松分布何时近似二项分布？为什么？

<Answer>
当 n 大（≥20）、p 小（≤0.05）时，泊松分布 Poisson(λ=np) 是二项分布 B(n,p) 的良好近似。因为泊松分布描述「大量试验中稀有事件的发生次数」，与二项分布在 n 大 p 小时的物理场景一致。近似的好处是泊松只有一个参数 λ，比二项的 n、p 两个参数更简洁，且计算量更小。
</Answer>

**问题 2**：投篮命中率 40%，投 10 次恰好中 3 次的概率和期望各是多少？

<Answer>
二项分布 B(10, 0.4)。P(X=3) = C(10,3) × 0.4³ × 0.6⁷ = 120 × 0.064 × 0.02799 ≈ 0.2150。期望 E[X] = np = 10 × 0.4 = 4 次。方差 Var(X) = np(1-p) = 10 × 0.4 × 0.6 = 2.4。标准差 ≈ 1.55。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="二项分布">
n 次独立伯努利试验中成功 k 次的概率。P(X=k)=C(n,k)·p^k·(1-p)^(n-k)。E=np, Var=np(1-p)。
</GlossaryItem>
<GlossaryItem term="几何分布">
首次成功所需试验次数。P(X=k)=(1-p)^(k-1)·p。E=1/p。
</GlossaryItem>
<GlossaryItem term="泊松分布">
单位时间/空间内稀有事件发生次数。P(X=k)=λ^k·e^(-λ)/k!。E=Var=λ。
</GlossaryItem>
<GlossaryItem term="伯努利试验">
只有成功和失败两种结果的单次随机试验，成功概率 p。是二项分布和几何分布的基本单元。
</GlossaryItem>
</Glossary>
