## 直觉引入

抛一枚硬币，正面朝上的概率是 1/2。这谁都懂。但如果连续抛 10 次都是正面，第 11 次正面的概率还是 1/2 吗？是的——每次抛硬币独立，之前的結果不影响下一次。但很多人直觉认为「该出反面了」，这就是「赌徒谬误」。

概率论用严格的数学语言描述不确定性。理解样本空间（所有可能结果）、事件（结果的子集）和概率法则（如何组合概率），是学习概率分布和统计推断的基础。

## 概念讲解

### 样本空间与事件

<Term def="样本空间是一个随机试验所有可能结果的集合，记为 Ω">样本空间</Term>。抛硬币的样本空间 $\Omega = \{正面, 反面\}$。掷骰子的 $\Omega = \{1,2,3,4,5,6\}$。

<Term def="事件是样本空间的子集。P(A) = 有利结果数 / 总结果数（等可能时）">事件</Term>。

### 概率法则

<Term def="加法法则：P(A∪B) = P(A) + P(B) - P(A∩B)，互斥时 P(A∩B)=0">加法法则</Term>处理「或」关系。

<Term def="乘法法则：P(A∩B) = P(A) × P(B|A)，独立时 P(B|A)=P(B)">乘法法则</Term>处理「且」关系。

### 独立与互斥

<Term def="独立事件是 P(B|A) = P(B)，即 A 的发生不影响 B 的概率。互斥事件是 A 和 B 不可能同时发生 P(A∩B)=0">独立与互斥</Term>是两个不同的概念——独立事件可以同时发生，互斥事件一定不独立。

<Stepper>
<Step title="第一步：定义样本空间">
列出所有可能结果。例如掷两个骰子，样本空间有 36 种 (1,1) 到 (6,6)。确认每个结果是否等可能——如果不是等可能，不能直接用「有利/总数」公式。
</Step>
<Step title="第二步：确定事件关系">
判断事件之间是「或」（加法）还是「且」（乘法）。判断是否独立（P(B|A)=P(B)）或互斥（P(A∩B)=0）。例如「掷出偶数」和「掷出大于3」不互斥也不独立。
</Step>
<Step title="第三步：套用法则计算">
或：P(A∪B) = P(A)+P(B)-P(A∩B)。且：P(A∩B) = P(A)×P(B|A)。独立时简化为 P(A)×P(B)。互斥时 P(A∪B) = P(A)+P(B)。
</Step>
</Stepper>

## 代码对照

```python
# 概率计算
from itertools import product
from fractions import Fraction

# 1. 样本空间：掷两个骰子
sample_space = list(product(range(1, 7), repeat=2))
print(f"样本空间大小: {len(sample_space)}")  # 36

# 2. 事件：点数和为7
sum_7 = [r for r in sample_space if sum(r) == 7]
p_sum7 = Fraction(len(sum_7), len(sample_space))
print(f"P(点数和=7) = {len(sum_7)}/{len(sample_space)} = {p_sum7}")  # 6/36 = 1/6

# 3. 加法法则：P(偶数和 ∪ 和>10)
even_sum = {r for r in sample_space if sum(r) % 2 == 0}
gt_10 = {r for r in sample_space if sum(r) > 10}
both = even_sum & gt_10  # 交集
p_union = Fraction(len(even_sum | gt_10), len(sample_space))
p_formula = (Fraction(len(even_sum), 36) + Fraction(len(gt_10), 36)
             - Fraction(len(both), 36))
print(f"P(偶数和 ∪ 和>10) = {p_union} = {float(p_union):.4f}")  # 验证公式

# 4. 条件概率：P(和=7 | 第一个骰子=3)
first_3 = [r for r in sample_space if r[0] == 3]
sum7_given_first3 = [r for r in first_3 if sum(r) == 7]
p_cond = Fraction(len(sum7_given_first3), len(first_3))
print(f"P(和=7|第一个=3) = {p_cond}")  # 1/6

# 5. 独立性检验
# P(A) * P(B) == P(A∩B)?
p_even = Fraction(len(even_sum), 36)
p_gt10 = Fraction(len(gt_10), 36)
p_both = Fraction(len(both), 36)
print(f"独立? {p_even * p_gt10 == p_both}")  # True/False
```

## 常见误区

<Callout type="trap">
**误区：连续出现正面后，反面「该来了」（赌徒谬误）。**
每次抛硬币独立——之前的结果不影响下一次。连续 10 次正面后，第 11 次正面的概率仍是 1/2。赌徒谬误源于将「长期频率」误用于「短期序列」。大数定律说长期频率趋近概率，但短期序列可以有连续相同结果。
</Callout>

<Callout type="trap">
**误区：独立和互斥是同一个意思。**
完全相反！独立是「A 发生不影响 B 的概率」（可以同时发生）。互斥是「A 和 B 不可能同时发生」（A 发生反而影响 B 的概率，P(B|A)=0）。两个互斥事件一定不独立（除非至少一个概率为 0）。
</Callout>

<Exercises>
**问题 1**：条件概率如何改变事件的概率？

<Answer>
条件概率 P(A|B) 是已知 B 发生后 A 的概率。它通过缩小样本空间到 B 来更新概率。例如 P(下雨)=0.3，但 P(下雨|阴天)=0.6——已知阴天后，下雨概率翻倍。信息改变概率是贝叶斯推理的核心：新证据更新旧认知。P(A|B) = P(A∩B)/P(B) 分子是 A 和 B 同时发生的概率，分母是 B 发生的概率（缩小的样本空间）。
</Answer>

**问题 2**：掷两个骰子，P(点数和=7) 和 P(点数和=7|第一个骰子=3) 各是多少？

<Answer>
P(点数和=7) = 6/36 = 1/6（6 种组合：(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)）。P(点数和=7|第一个=3)：第一个是 3 时，第二个必须是 4 才能和为 7。6 种等可能结果中只有 (3,4) 满足，所以 P = 1/6。两者相同——说明「点数和=7」和「第一个骰子=3」独立。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="样本空间">
随机试验所有可能结果的集合 Ω。抛硬币 Ω={正,反}，掷骰子 Ω={1,2,3,4,5,6}。
</GlossaryItem>
<GlossaryItem term="事件">
样本空间的子集。P(A) = 有利结果数/总结果数（等可能时）。
</GlossaryItem>
<GlossaryItem term="独立事件">
P(B|A) = P(B)，A 的发生不影响 B 的概率。独立事件可以同时发生。
</GlossaryItem>
<GlossaryItem term="互斥事件">
A 和 B 不可能同时发生，P(A∩B)=0。互斥事件一定不独立（除非概率为0）。
</GlossaryItem>
</Glossary>
