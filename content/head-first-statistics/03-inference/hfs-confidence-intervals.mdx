## 直觉引入

你抽了 100 个人的身高，均值 170cm。你能说「全国平均身高就是 170cm」吗？不能——样本均值只是估计。但你能说「全国平均身高有 95% 的把握在 168-172cm 之间」。这就是置信区间——它不给你一个点估计，而是给你一个「可能范围」加上「把握程度」。

置信区间的核心思想是：**点估计会错，但区间估计有概率包含真值**。区间越窄估计越精确，置信水平越高越可靠——但两者不可兼得。

## 概念讲解

### 置信区间公式

<Term def="置信区间是用样本统计量构造的总体参数的区间估计：x̄ ± z·(σ/√n)">置信区间</Term>：

$$\bar{x} \pm z \cdot \frac{\sigma}{\sqrt{n}}$$

其中 $z$ 是临界值（由置信水平决定），$\sigma/\sqrt{n}$ 是标准误。

### 置信水平

<Term def="置信水平是区间包含总体参数的概率（频率学派解释：重复抽样中包含真值的比例）">置信水平</Term>。常用值：

| 置信水平 | z 临界值 |
|---------|---------|
| 90% | 1.645 |
| 95% | 1.96 |
| 99% | 2.576 |

### 边际误差

<Term def="边际误差是置信区间 half-width：ME = z·(σ/√n)，反映估计的精度">边际误差</Term>。

样本量 $n$ 越大，ME 越小（区间越窄）。置信水平越高，$z$ 越大，ME 越大（区间越宽）。

<Stepper>
<Step title="第一步：计算样本统计量">
从样本计算均值 x̄ 和标准误 SE = σ/√n（σ 已知）或 s/√n（σ 未知，大样本用 s 代替）。例如 x̄=170, σ=10, n=100, SE=10/√100=1。
</Step>
<Step title="第二步：选择置信水平">
选择置信水平（通常 95%），查对应 z 临界值。95% → z=1.96, 90% → z=1.645, 99% → z=2.576。置信水平越高区间越宽但越可靠。
</Step>
<Step title="第三步：构造区间">
CI = x̄ ± z·SE = 170 ± 1.96×1 = [168.04, 171.96]。解释：「我们有 95% 的置信度认为总体均值在 168.04 到 171.96 之间」。严格含义：重复抽样 100 次，约 95 个区间包含真值。
</Step>
</Stepper>

## 代码对照

```python
# 置信区间计算
import numpy as np
from scipy import stats

# 样本数据
np.random.seed(42)
sample = np.random.normal(170, 10, 100)  # n=100 的样本

n = len(sample)
x_bar = np.mean(sample)
sigma = 10  # 假设总体标准差已知

# 1. 95% 置信区间
se = sigma / np.sqrt(n)
z_95 = 1.96
margin_95 = z_95 * se
ci_95 = (x_bar - margin_95, x_bar + margin_95)
print(f"95% CI: [{ci_95[0]:.2f}, {ci_95[1]:.2f}]")
print(f"边际误差: {margin_95:.2f}")

# 2. 不同置信水平对比
for conf, z in [(90, 1.645), (95, 1.96), (99, 2.576)]:
    margin = z * se
    ci = (x_bar - margin, x_bar + margin)
    print(f"{conf}% CI: [{ci[0]:.2f}, {ci[1]:.2f}], 宽度={2*margin:.2f}")

# 3. 不同样本量对比（95% CI）
for n_val in [25, 100, 400, 1000]:
    se_n = sigma / np.sqrt(n_val)
    margin = 1.96 * se_n
    print(f"n={n_val}: 边际误差={margin:.2f}")

# 4. 用 t 分布（σ 未知，小样本）
# 当 σ 未知且 n 小时，用 t 分布而非 z
sample_small = np.random.normal(170, 10, 15)
n_small = len(sample_small)
x_small = np.mean(sample_small)
s_small = np.std(sample_small, ddof=1)
t_crit = stats.t.ppf(0.975, df=n_small-1)  # t 临界值
se_small = s_small / np.sqrt(n_small)
ci_t = (x_small - t_crit * se_small, x_small + t_crit * se_small)
print(f"\n小样本 t CI: [{ci_t[0]:.2f}, {ci_t[1]:.2f}]")
```

## 常见误区

<Callout type="trap">
**误区：95% 置信区间意味着真值有 95% 的概率落在这个区间内。**
频率学派中真值是固定的（不是随机变量），区间是随机的。正确的频率解释：重复抽样 100 次，构造 100 个置信区间，约 95 个包含真值。不能说「这个特定区间有 95% 的概率包含真值」——真值要么在要么不在，没有概率可言。
</Callout>

<Callout type="trap">
**误区：99% 置信区间比 95% 更好。**
99% 区间更宽（更可靠但更不精确），95% 更窄（更精确但可靠度稍低）。选择是精度与可靠性的权衡。99% 区间可能宽到没有实际意义。通常 95% 是标准选择——在精度和可靠性间的平衡。
</Callout>

<Exercises>
**问题 1**：95% 置信区间意味着什么？

<Answer>
频率学派解释：如果重复抽样 100 次，每次构造一个 95% 置信区间，约 95 个区间包含总体真值。注意：真值是固定的（不是随机的），区间是随机的。对于已构造的某个特定区间，真值要么在要么不在，不能说「有 95% 的概率在」。95% 是对「方法」的置信度——这个方法构造的区间中，95% 会包含真值。
</Answer>

**问题 2**：样本均值 170，σ=10，n=100，求 95% 置信区间。n 翻 4 倍呢？

<Answer>
SE = σ/√n = 10/√100 = 1。95% CI = 170 ± 1.96×1 = [168.04, 171.96]。n 翻 4 倍（n=400）：SE = 10/√400 = 0.5。CI = 170 ± 1.96×0.5 = [169.02, 170.98]。区间宽度从 3.92 缩小到 1.96——精度翻倍。但 n 翻 4 倍才让精度翻倍，边际效益递减。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="置信区间">
用样本统计量构造的总体参数区间估计。x̄ ± z·(σ/√n)。给出「可能范围」而非单点。
</GlossaryItem>
<GlossaryItem term="置信水平">
重复抽样中区间包含真值的比例。常用 90%/95%/99%。95% 对应 z=1.96。
</GlossaryItem>
<GlossaryItem term="边际误差">
置信区间半宽 ME = z·(σ/√n)。反映估计精度。n 越大 ME 越小，置信水平越高 ME 越大。
</GlossaryItem>
<GlossaryItem term="t 分布">
σ 未知且小样本时用 t 分布替代 z 分布。自由度 n-1，比正态分布略宽（有「胖尾」）。
</GlossaryItem>
</Glossary>
