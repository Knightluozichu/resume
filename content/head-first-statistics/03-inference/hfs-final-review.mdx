## 直觉引入

回顾全书，四大板块形成完整的统计思维链条：数据展示（看见数据）→ 集中趋势与离散（描述数据）→ 概率与分布（建模数据）→ 统计推断（从样本推断总体）。

中心极限定理是连接描述统计与推断统计的桥梁——它告诉我们样本均值近似正态分布，使得置信区间和假设检验成为可能。统计学的核心方法论是：**用描述统计总结数据，用概率分布建模随机性，用推断统计从局部推断全局**。

## 概念讲解

### 全书知识网络

<Term def="数据展示是统计分析的起点——用频率表、直方图让数据可视化">数据展示</Term>让数据「说话」，揭示分布形态、异常值和模式。

<Term def="集中趋势与离散程度是描述数据分布的两大维度">描述统计</Term>：均值/中位数/众数描述中心，方差/标准差/IQR 描述散布。两者一起完整刻画数据分布。

<Term def="概率分布将现实随机现象数学模型化——二项/几何/泊松（离散）和正态/均匀/指数（连续）">概率分布</Term>是描述统计到推断统计的桥梁。

<Term def="中心极限定理：n≥30 时样本均值近似正态，使得置信区间和假设检验成为可能">中心极限定理</Term>是统计推断的基石。

### 核心方法论

统计学三步循环：**描述（数据长什么样）→ 建模（数据服从什么规律）→ 推断（总体长什么样）**。

<Step title="第一步：描述统计贯穿始终">
数据展示 → 集中趋势 → 离散程度。这三个步骤是任何统计分析的起点——先画图看分布，再算均值看中心，再算标准差看波动。跳过描述统计直接做推断会选错方法。
</Step>
<Step title="第二步：概率分布连接描述与推断">
描述统计揭示了数据分布形态，概率分布用数学模型刻画这个形态。正态分布是最重要的模型——许多统计方法假设正态性。概率分布提供了从描述到推断的数学语言。
</Step>
<Step title="第三步：中心极限定理支撑推断">
抽样 → 标准误 → 中心极限定理 → 置信区间。中心极限定理保证大样本下样本均值近似正态，使得我们可以构造置信区间量化推断的不确定性。这是统计学的终极目标——从局部推断全局。
</Step>

## 代码对照

```python
# 统计学全流程综合应用
import numpy as np
from scipy import stats

# 场景：从样本推断总体平均身高

# 1. 数据展示（统计基础）
np.random.seed(42)
sample = np.random.normal(170, 8, 50)  # 50人样本
print("=== 1. 数据展示 ===")
print(f"最小值: {sample.min():.1f}, 最大值: {sample.max():.1f}")
print(f"分组统计: {np.histogram(sample, bins=5)}")

# 2. 描述统计（集中趋势与离散）
print("\n=== 2. 描述统计 ===")
print(f"均值: {np.mean(sample):.2f}")
print(f"中位数: {np.median(sample):.2f}")
print(f"标准差: {np.std(sample, ddof=1):.2f}")
print(f"IQR: {np.percentile(sample,75)-np.percentile(sample,25):.2f}")

# 3. 概率分布检查
print("\n=== 3. 概率分布 ===")
stat, p = stats.shapiro(sample)
print(f"正态性检验 p={p:.4f} ({'正态' if p>0.05 else '非正态'})")

# 4. 统计推断（置信区间）
print("\n=== 4. 统计推断 ===")
n = len(sample)
x_bar = np.mean(sample)
s = np.std(sample, ddof=1)
se = s / np.sqrt(n)

# 95% CI
t_crit = stats.t.ppf(0.975, df=n-1)
margin = t_crit * se
ci = (x_bar - margin, x_bar + margin)
print(f"总体均值 95% CI: [{ci[0]:.2f}, {ci[1]:.2f}]")
print(f"边际误差: {margin:.2f}")
print(f"解释: 我们有95%的置信度认为总体平均身高在{ci[0]:.1f}到{ci[1]:.1f}cm之间")
```

## 常见误区

<Callout type="trap">
**误区：学完统计学就能做数据科学了。**
统计学是数据科学的基础，但数据科学还需要编程（Python/R）、机器学习（回归、分类、聚类）、数据清洗、可视化工具（Tableau/PowerBI）和领域知识。统计学提供的是「思维框架」——如何设计实验、如何解读结果、如何避免常见谬误——这些比具体技术更重要。
</Callout>

<Callout type="trap">
**误区：p 值小于 0.05 就是显著的结果。**
p&lt;0.05 是约定俗成的阈值，不是自然法则。p 值衡量「在零假设为真的前提下观测到当前或更极端结果的概率」，不直接反映「零假设为假的概率」。多重比较、p-hacking（选择性报告）、大样本下微小效应也「显著」等问题让 p 值容易被误用。应该同时看效应大小、置信区间和领域意义。
</Callout>

<Exercises>
**问题 1**：统计学的核心方法论是什么？

<Answer>
统计学三步循环：(1) 描述——用频率表/直方图展示数据，用均值/中位数/方差/标准差描述分布特征；(2) 建模——用概率分布（二项/正态/泊松等）将随机现象数学模型化；(3) 推断——用抽样分布和中心极限定理从样本推断总体，用置信区间量化不确定性。核心思想是「从局部推断全局，在不确定性中做决策」。
</Answer>

**问题 2**：举例说明中心极限定理如何连接概率分布与统计推断。

<Answer>
以估计全国平均身高为例：(1) 概率分布——身高近似正态分布 N(μ,σ²)；(2) 抽样——随机抽 100 人，计算样本均值 x̄；(3) 中心极限定理——无论身高分布如何，x̄ 近似正态 N(μ, σ²/100)；(4) 统计推断——基于正态分布构造 95% 置信区间 x̄±1.96·(σ/√100)。中心极限定理让我们不需要知道总体分布的精确形状，只需大样本就能用正态分布做推断。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="数据展示">
用频率表、直方图、条形图等可视化数据。统计分析的起点——先「看见」数据再分析。
</GlossaryItem>
<GlossaryItem term="描述统计">
用均值/中位数/众数和方差/标准差/IQR 描述数据分布的集中趋势和离散程度。
</GlossaryItem>
<GlossaryItem term="中心极限定理">
n≥30 时样本均值近似正态 N(μ,σ²/n)。连接概率分布与统计推断的桥梁。
</GlossaryItem>
<GlossaryItem term="置信区间">
用样本构造的总体参数区间估计 x̄±z·SE。量化推断不确定性。95% CI 是标准选择。
</GlossaryItem>
