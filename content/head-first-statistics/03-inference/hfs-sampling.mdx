## 直觉引入

你想知道全国成年人的平均身高，不可能测量 14 亿人。但你随机抽 1000 人测平均身高，这个「样本均值」有多大把握接近「总体均值」？中心极限定理回答了这个问题——无论总体分布如何，样本均值的分布随样本量增大趋近正态分布。

这就是统计推断的基石：我们不需要知道总体分布的形状，只要样本量够大，样本均值就服从正态分布，可以用正态分布计算概率、构造置信区间。

## 概念讲解

### 抽样方法

<Term def="简单随机抽样是每个个体被抽中的概率相等的抽样方法">简单随机抽样</Term>。

<Term def="分层抽样是将总体分成互不重叠的层，在每层内独立抽样，保证各层都有代表">分层抽样</Term>。

<Term def="整群抽样是将总体分成群，随机抽取若干群，对选中群内全部个体调查">整群抽样</Term>。

### 样本均值的分布

<Term def="样本均值的期望等于总体均值 E[x̄] = μ，标准误 SE = σ/√n">样本均值的分布</Term>。

关键：样本量越大，标准误越小——样本均值越集中在总体均值附近。$n$ 翻 4 倍，标准误减半。

### 中心极限定理

<Term def="中心极限定理：无论总体分布如何，当样本量 n 足够大时（通常 n≥30），样本均值的分布近似正态分布 N(μ, σ²/n)">中心极限定理</Term>。

这是统计推断的基石——不需要知道总体分布形状，大样本下样本均值就近似正态。

<Stepper>
<Step title="第一步：确认样本量">
样本量 $n \geq 30$ 时中心极限定理生效（总体严重偏态时需要更大）。确认总体均值 μ 和标准差 σ 是否已知。如果未知，用样本均值 x̄ 和样本标准差 s 估计。
</Step>
<Step title="第二步：计算标准误">
标准误 $SE = \sigma / \sqrt{n}$。例如总体标准差 10，样本量 100，SE = 10/√100 = 1。样本均值以 SE=1 的精度估计总体均值。n 越大 SE 越小。
</Step>
<Step title="第三步：用正态分布推断">
由中心极限定理，x̄ ~ N(μ, SE²)。可以计算 P(x̄ > 某值) 或构造置信区间。例如 P(x̄ 在 μ±1.96SE 内) = 95%。这是 95% 置信区间的来源。
</Step>
</Stepper>

## 代码对照

```python
# 中心极限定理演示
import numpy as np

# 总体：掷骰子（均匀分布，非正态）
np.random.seed(42)
population = np.random.randint(1, 7, size=1000000)
pop_mean = population.mean()  # 3.5
pop_std = population.std()    # 约 1.708

print(f"总体均值: {pop_mean:.4f}")
print(f"总体标准差: {pop_std:.4f}")

# 不同样本量下，样本均值的分布
for n in [1, 5, 30, 100]:
    sample_means = [np.random.choice(population, n).mean() for _ in range(10000)]
    se_theory = pop_std / np.sqrt(n)  # 理论标准误
    se_actual = np.std(sample_means)   # 实际标准误
    print(f"\nn={n}: 样本均值标准差={se_actual:.4f}, 理论SE={se_theory:.4f}")
    # n=1: 1.708 (等于总体σ，不正态)
    # n=5: 0.764 (开始集中)
    # n=30: 0.312 (接近正态)
    # n=100: 0.171 (很集中，接近正态)

# 验证：n=30 时样本均值近似正态
from scipy import stats
n = 30
sample_means = [np.random.choice(population, n).mean() for _ in range(10000)]
# 正态性检验
stat, p = stats.shapiro(sample_means)
print(f"\nn=30 正态性检验 p值: {p:.4f} (p>0.05表示正态)")

# 简单随机抽样 vs 分层抽样
# 分层抽样：从1-2,3-4,5-6三个层各抽1/3
strata = [population[population<=2], population[(population>2)&(population<=4)], population[population>4]]
stratified_sample = np.concatenate([np.random.choice(s, 100) for s in strata])
print(f"\n分层抽样均值: {stratified_sample.mean():.4f} (更接近3.5)")
```

## 常见误区

<Callout type="trap">
**误区：中心极限定理说总体分布是正态的。**
中心极限定理说的是**样本均值**的分布趋近正态，不是总体分布。总体可以是均匀分布（如骰子）、偏态分布甚至双峰分布——只要 n 足够大，样本均值就近似正态。这就是为什么我们不需要知道总体分布形状就能做统计推断。
</Callout>

<Callout type="trap">
**误区：样本量越大结果一定越准。**
样本量越大标准误越小（精度越高），但如果抽样有偏（如只在网上调查），再大的样本也只会精确地估计错误的目标——「精确地犯错」。抽样质量比样本量更重要。1936 年《文学文摘》调查 240 万人预测总统选举结果错误，就是抽样偏差的典型案例。
</Callout>

<Exercises>
**问题 1**：为什么大样本下样本均值近似正态分布？

<Answer>
中心极限定理：大量独立同分布随机变量之和（或均值）的分布趋近正态分布，无论原始分布如何。直觉解释：样本均值是 n 个独立随机变量的平均，每个变量贡献一个「扰动」。当 n 大时，这些扰动按概率叠加，根据中心极限定理，叠加结果趋近正态。n≥30 通常是足够大的经验阈值。这使得我们不需要知道总体分布形状就能用正态分布做统计推断。
</Answer>

**问题 2**：总体标准差 10，样本量 100，标准误是多少？样本量翻 4 倍呢？

<Answer>
标准误 SE = σ/√n = 10/√100 = 1。样本量翻 4 倍（n=400）：SE = 10/√400 = 10/20 = 0.5。标准误减半——精度提升一倍。这说明提升精度的边际效益递减：n 翻 4 倍 SE 才减半。在实际中，需要权衡采样成本和精度需求。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="简单随机抽样">
每个个体被抽中概率相等的抽样方法。最基本但需要完整抽样框。
</GlossaryItem>
<GlossaryItem term="中心极限定理">
无论总体分布如何，n≥30 时样本均值近似正态 N(μ,σ²/n)。统计推断的理论基石。
</GlossaryItem>
<GlossaryItem term="标准误">
样本均值的标准差 SE=σ/√n。衡量样本均值估计总体均值的精度。n 越大 SE 越小。
</GlossaryItem>
<GlossaryItem term="分层抽样">
将总体分层后在层内独立抽样。保证各层有代表，通常比简单随机抽样更精确。
</GlossaryItem>
</Glossary>
