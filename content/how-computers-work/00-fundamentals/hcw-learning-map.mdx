## 直觉引入

把计算机想象成一栋大楼。你先要打地基——CPU 怎么算、内存怎么存、总线怎么连（硬件基础）；然后砌砖墙——二进制怎么编码数字、补码怎么表示负数、字符怎么映射（数据表示）；接着拉电线——汇编语言怎么指挥硬件、编译器怎么把代码变成可执行文件（软件与编译）；再装门窗——操作系统怎么管理进程、文件系统怎么组织磁盘（操作系统与文件系统）。本书回答的就是这些「从晶体管到应用程序」的计算机原理问题。

## 四阶段递进

<Term def="计算机系统是以二进制为数据基础、以 CPU 为执行核心、以操作系统为资源管理者、以编译器为软件桥梁的分层体系。">计算机系统</Term>的学习可以拆成四个递进阶段。**硬件基础**包括 CPU 架构和内存层次——它们解决「计算在哪里发生」和「数据存在哪里」，是所有上层软件的物理基底。**二进制与数据表示**包括进制转换和补码/浮点数/编码——它们决定「信息怎么表示」和「数值怎么运算」。**软件与编译**包括汇编语言和编译链接——它们让人类「能编程」和「能编译」。**操作系统与文件系统**包括进程管理和文件存储——它们解决「资源怎么管理」和「数据怎么持久化」。**总复习**串联全部知识点。

```text
// 一次「从按键到屏幕显示字符」的完整计算机运行时旅程
用户按下键盘 'A' 键:
  // 1. 硬件层：键盘控制器产生扫描码，通过中断通知 CPU
  //    CPU 从端口读取扫描码存入寄存器（第 2-3 章 CPU 与内存）

  // 2. 数据层：扫描码是二进制数，经编码转换成 ASCII 字符
  //    'A' = 0x41 = 65 = 01000001B（第 4-5 章二进制与数据表示）

  // 3. 软件层：操作系统的中断处理程序用汇编/机器指令响应
  //    应用程序经编译链接后的代码处理输入（第 6-7 章汇编与编译）

  // 4. 系统层：操作系统调度进程、管理内存
  //    通过文件系统保存文档（第 8-9 章操作系统与文件系统）

  // 5. 输出：CPU 写入显存，显卡刷新屏幕显示 'A'
```

## 常见误区

<Callout type="trap">
**误区：会用电脑就等于懂电脑。** 用电脑只是操作表层——点鼠标、敲键盘、装软件，这些照说明书就会。真正懂原理的人能解释：为什么程序会崩溃（内存越界/段错误）、为什么电脑会变慢（磁盘碎片/内存不足/缓存失效）、为什么文件删了还能恢复（磁盘只是标记删除）、为什么不同编程语言性能差异巨大（编译 vs 解释/抽象层级）。把电脑当黑盒的人遇到问题只能重启；懂底层的人能定位根因、写出高效代码、做系统级优化。
</Callout>

<Exercises>
**问题 1**：全书四阶段是什么？为什么是这个顺序？

<Answer>
硬件基础（CPU/内存/总线）→ 二进制与数据表示（进制转换/补码/编码）→ 软件与编译（汇编/编译链接）→ 操作系统与文件系统（进程/内存管理/文件存储）→ 总复习。顺序由依赖关系决定：上层依赖下层。没有硬件就没有执行单元；没有二进制就没有数据表达；没有编译就没有软件；没有操作系统就没有资源管理。先有「能算」，再有「能表示」，然后「能编程」，接着「能管理」，最后「能存储」。
</Answer>

**问题 2**：用「从按键到屏幕显示一个字符」的完整旅程描述全书主线。

<Answer>
用户按键：①硬件层——键盘控制器产生扫描码，通过中断通知 CPU，CPU 从端口读取数据存入寄存器（第 2-3 章）；②数据层——扫描码是二进制数，经编码转换成 ASCII/Unicode 字符（第 4-5 章）；③软件层——操作系统的中断处理程序用汇编/机器指令响应，应用程序经编译链接后的代码处理输入（第 6-7 章）；④系统层——操作系统调度进程、管理内存、通过文件系统保存文档（第 8-9 章）；⑤输出——CPU 写入显存，显卡刷新屏幕显示字符。一次按键，四层全部参与。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="计算机系统">以二进制为数据基础、以 CPU 为执行核心、以操作系统为资源管理者、以编译器为软件桥梁的分层体系。所有软件行为建立在这四层之上。</GlossaryItem>
<GlossaryItem term="四阶段递进">硬件基础（CPU/内存）→ 二进制与数据表示（进制/补码/编码）→ 软件与编译（汇编/编译链接）→ 操作系统与文件系统（进程/内存/文件）→ 总复习。每层解决前一层的遗留问题：硬件层提供执行能力，数据层补表达方式，软件层补编程手段，系统层补管理框架。</GlossaryItem>
<GlossaryItem term="运行时旅程">一次用户按键从硬件中断到屏幕显示的完整路径：中断响应（第 2-3 章硬件）→ 二进制编码转换（第 4-5 章数据）→ 汇编/编译代码执行（第 6-7 章软件）→ 操作系统调度与文件存储（第 8-9 章系统）→ 显存输出。全书以这条主线串联各章节。</GlossaryItem>
</Glossary>
