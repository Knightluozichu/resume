## 直觉引入

CPU 只懂一种语言——由 0 和 1 组成的机器语言（如 10110000 01100001）。但人类读这些数字像读天书。于是人们发明了汇编语言——用 MOV 代替 10110000，用 AX 代替 01100001，让指令变成人类可读的「MOV AX, 5」。汇编与机器指令一一对应，只是换了件「外衣」。再往上，高级语言（C/Python）用更接近人类语言的语法描述逻辑，通过编译器翻译成机器语言，实现了跨平台。

## 三种语言的关系

<Term def="汇编语言是机器语言的助记符版本，与机器指令一一对应，用英文缩写（MOV/ADD/JMP）代替二进制操作码，但仍与具体 CPU 架构绑定。">汇编语言</Term>位于机器语言和高级语言之间。**机器语言**是 CPU 直接执行的二进制指令，不同 CPU 架构不同。**汇编语言**是机器语言的助记符版本——用简短英文缩写代替二进制操作码，但与机器指令一一对应，仍与具体 CPU 架构绑定。**高级语言**用接近人类语言的语法描述逻辑，通过编译器/解释器翻译成机器语言，与硬件解耦。三层抽象递进：机器语言最底层（直接执行）、汇编语言中间层（可读的机器码）、高级语言最上层（平台无关）。

## 指令格式

汇编指令格式为「助记符 操作数1, 操作数2」（Intel 语法）。以 `MOV AX, 5` 为例：MOV 是助记符（操作码），指定「做什么」（传送数据）；AX 是操作数1（目标寄存器）；5 是操作数2（源立即数）。操作数可以是**立即数**（直接给出的常量）、**寄存器**（如 AX/BX）、**内存地址**（如 [BX] 表示 BX 中地址指向的内存）。MOV 是最常用的指令，但不能直接做内存到内存的传送。

## 寻址方式

七种常见寻址方式：①**立即寻址**——操作数在指令中（MOV AX, 5），赋常量；②**寄存器寻址**——操作数在寄存器中（MOV AX, BX），最快；③**直接寻址**——地址直接给出（MOV AX, [2000H]），全局变量；④**间接寻址**——地址在寄存器中（MOV AX, [BX]），指针/遍历；⑤**基址寻址**——基址+偏移（MOV AX, [BX+8]），结构体成员；⑥**变址寻址**——变址+偏移（MOV AX, [SI+4]），数组元素；⑦**基址变址**——两寄存器相加（MOV AX, [BX+SI]），二维数组。

## 应用场景

日常应用开发几乎不需要写汇编，但理解汇编是「懂计算机」的关键。需要用汇编的场景：①操作系统内核——bootloader、中断处理、上下文切换；②驱动开发——直接读写硬件寄存器；③性能关键路径——编解码热点、加密 SIMD 优化；④逆向工程——分析恶意软件、漏洞挖掘；⑤嵌入式开发——资源极度受限的 MCU。

## 常见误区

<Callout type="trap">
**误区：汇编语言已经过时，现代程序员不需要学。** 汇编语言本身确实很少直接用来写应用，但理解汇编能帮助开发者写出更好的高级语言代码。不懂汇编的人看崩溃报告只能猜；懂汇编的人能用 gdb 读栈帧、理解寄存器分配和内存布局，精准定位 segfault/stack overflow。此外，编译器优化、JIT、逆向工程都以汇编为基础。
</Callout>

<Exercises>
**问题 1**：机器语言、汇编语言和高级语言之间的关系是什么？

<Answer>
机器语言是 CPU 直接执行的二进制指令。汇编语言是机器语言的助记符版本，与机器指令一一对应但仍与架构绑定。高级语言用接近人类语言的语法，通过编译器/解释器翻译成机器语言，与硬件解耦。三层抽象递进：机器语言最底层、汇编语言中间层、高级语言最上层。
</Answer>
