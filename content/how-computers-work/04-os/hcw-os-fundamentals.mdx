## 直觉引入

如果没有操作系统，你打开浏览器时浏览器要自己写键盘驱动、自己分配内存、自己管理磁盘扇区、自己防止和其他程序冲突。每写一个程序都要从头造一遍轮子。操作系统就是「公共管家」——它替所有程序管理硬件资源，提供统一接口（系统调用），让程序员只需关注业务逻辑。没有操作系统，现代计算机几乎无法使用。

## 五大核心功能

<Term def="操作系统是硬件与应用之间的资源管理者和抽象提供者，核心功能包括进程管理、内存管理、文件系统、设备管理和网络与安全。">操作系统</Term>有五大核心功能：①**进程管理**——创建/调度/销毁进程，分配 CPU 时间，实现多任务并发；②**内存管理**——分配/回收内存，虚拟内存/分页/换页，隔离进程地址空间；③**文件系统**——把磁盘数据组织成文件和目录；④**设备管理**——通过驱动程序管理外设，提供统一接口；⑤**网络与安全**——网络协议栈、权限管理、进程隔离。

## 进程 vs 线程

**进程**是程序的一次运行实例，有独立的地址空间和资源。**线程**是进程内的执行单元，同进程的多个线程共享地址空间但各自有独立栈。区别：进程是资源分配单位，线程是 CPU 调度单位；进程间内存隔离（一个崩溃不影响另一个），线程间共享内存（一个写坏数据影响全部）；进程切换需换页表（开销大），线程切换不换页表（开销小 10-100 倍）。需要线程的原因：多核并行、高效切换、简化通信。

## 内存管理与分页

操作系统通过**虚拟内存 + 分页**管理内存。每个进程有独立的虚拟地址空间，CPU 产生的虚拟地址经 MMU 查**页表**转换为物理地址。分页把虚拟空间和物理空间都分成 4KB 的页，虚拟页到物理页框的映射记录在页表中。分页解决：①碎片化——消除外部碎片；②隔离——每个进程独立页表；③按需加载——只有被访问的页才调入内存；④换页——内存不足时把不活跃页写到磁盘。TLB 缓存页表项避免每次翻译都遍历多级页表。

## 中断与系统调用

**中断**是 CPU 暂停当前程序转去处理紧急事件的机制。分硬件中断（键盘/网卡/定时器，异步）和软件中断（除零/缺页/非法指令，同步）。**系统调用**是用户程序请求操作系统服务的机制——用户程序运行在用户态（权限低），需要读写文件/创建进程时执行特殊指令（syscall）触发软中断进入内核态。系统调用是用户态与内核态的「门」，所有硬件操作都必须经过它。

## 常见误区

<Callout type="trap">
**误区：多线程一定比单线程快。** 多线程在 CPU 密集型任务上确实可以多核并行加速，但线程切换本身有开销（保存/恢复寄存器、缓存失效），且线程间共享内存需要加锁同步，锁竞争可能让多线程比单线程还慢。此外，I/O 密集型任务用异步 I/O（如 epoll）可能比多线程更高效。线程数不是越多越好——通常最佳线程数约等于 CPU 核心数（CPU 密集型）或 2 倍核心数（I/O 密集型）。
</Callout>

<Exercises>
**问题 1**：进程和线程有什么区别？为什么有了进程还需要线程？

<Answer>
进程是程序运行实例，有独立地址空间，是资源分配单位。线程是进程内执行单元，共享地址空间但各自有独立栈，是 CPU 调度单位。区别：进程间内存隔离但切换开销大，线程间共享内存但切换快 10-100 倍。需要线程的原因：多核并行、高效切换、简化通信（共享内存比进程间通信简单）。
</Answer>

**问题 2**：什么是中断和系统调用？它们在操作系统中的作用是什么？

<Answer>
中断是 CPU 暂停当前程序转去处理紧急事件的机制，分硬件中断（异步，如键盘/定时器）和软件中断（同步，如除零/缺页）。系统调用是用户程序请求操作系统服务的机制——用户态程序执行 syscall 触发软中断进入内核态，操作系统代为执行后返回。系统调用是用户态与内核态的「门」，所有硬件操作必须经过它。
</Answer>
</Exercises>
