## 直觉引入

把内存想象成一排带编号的储物柜。每个柜子有唯一的编号（地址），每个柜子能放一个字节（8 位）的东西。你声明一个变量 `int a = 42`，编译器其实是在柜子里挑出连续 4 个空柜子（int 占 4 字节），把 42 这个数放进去，然后记住「a 就是第 1000-1003 号柜子」。从此以后 `a` 这个名字只是这 4 个柜子的别名——CPU 真正打交道的是地址，不是变量名。程序「跑起来」的第一步，就是把自己摊开铺进这排柜子里。

## 字节编址

<Term def="内存以字节（8 位）为最小可寻址单位，每个字节都有一个唯一的编号称为地址，CPU 通过地址读写对应字节。">字节编址</Term>是内存的最基本性质。一根 32 位地址总线能寻址 $2^{32}$ = 4GB 个字节，64 位则理论上能寻址 $2^{64}$ 字节（实际受物理限制远小于此）。多字节类型（如 int 占 4 字节、double 占 8 字节）占据连续多个字节，其地址取首字节地址。这里有个**字节序（Endianness）**问题：小端序（x86/ARM 默认）把低位字节存放在低地址，大端序（网络字节序/部分嵌入式）则相反。数字 `0x12345678` 在小端序内存里从低到高存的是 `78 56 34 12`——这个细节在调试二进制数据、网络通信时极易踩坑。

## 程序内存布局

一个程序加载进内存后，地址空间从低到高分为若干段：**代码段（Text）** 存编译后的机器指令，只读且共享（多个进程跑同一程序可共享代码段）；**数据段（Data）** 存已初始化的全局变量和静态变量，可读写；**BSS 段** 存未初始化的全局/静态变量，加载时清零（因此不占可执行文件空间）；**堆（Heap）** 从低地址向高地址增长，供 `malloc`/`new` 动态分配；**栈（Stack）** 从高地址向低地址增长，存函数栈帧（局部变量、返回地址）。堆和栈之间是空闲区，二者相向生长——栈用太多或堆用太多都可能撞到对方，导致崩溃。

## 虚拟地址

程序看到的地址不是物理内存的真实地址，而是**虚拟地址**。每个进程都有自己独立的虚拟地址空间（64 位系统通常是 48 位有效地址），由 CPU 的内存管理单元（MMU）通过页表把虚拟地址翻译成物理地址。虚拟内存的意义有三：①**隔离**——每个进程以为自己独占整个地址空间，互相看不到，A 进程写 0x1000 不会影响 B 进程的 0x1000；②**保护**——页表带权限位，代码段设只读，写它就触发段错误；③**扩展**——物理内存不够时可以把不常用的页换到磁盘（交换区），让程序能用比物理内存更大的地址空间。

## 变量名与地址

源代码里的变量名在编译后就不存在了——编译器把每个变量映射成一个地址（栈上的偏移或全局段的固定地址）。`int a = 42;` 编译后是「把 42 写入地址 0x... 」。这就是为什么 C 语言有指针：指针就是「直接保存地址」的变量，让你能在运行时动态地操作任意地址。理解了「变量名只是地址的别名，CPU 只认地址」，后面指针、函数调用、内存泄漏的一切都顺理成章。

## 常见误区

<Callout type="trap">
**误区：内存里存的是变量名和类型。** 内存里只有 0 和 1，按字节编址。变量名、类型、作用域都是编译期的概念，运行时全部消失——内存里既没有 `a` 这个名字，也没有「这是 int」的标签。`int a` 和 `float b` 如果碰巧在同一地址（通过 union 或强制转换），CPU 读出来的是同一串 0/1，只是解释方式不同。这就是为什么 C 的强制类型转换能「work」也更危险：它绕过了类型检查，直接按你的解释读那串字节。
</Callout>

<Exercises>
**问题 1**：程序的内存布局从低地址到高地址有哪几段？各自存什么？

<Answer>
从低到高：①代码段（Text）——存编译后的机器指令，只读可共享；②数据段（Data）——存已初始化的全局变量和静态变量，可读写；③BSS 段——存未初始化的全局/静态变量，加载时清零，不占可执行文件空间；④堆（Heap）——从低向高增长，供 malloc/new 动态分配；⑤栈（Stack）——从高向低增长，存函数栈帧（局部变量、返回地址）。堆栈之间是空闲区，相向生长。
</Answer>

**问题 2**：什么是虚拟地址？为什么操作系统要给每个进程独立的虚拟地址空间？

<Answer>
虚拟地址是程序看到的地址，不是物理内存的真实地址，由 MMU 通过页表翻译成物理地址。给每个进程独立虚拟地址空间有三个意义：①隔离——每个进程以为自己独占整个地址空间，互相看不到，A 进程写 0x1000 不影响 B 进程；②保护——页表带权限位，代码段设只读，写它触发段错误；③扩展——物理内存不够时可把不常用的页换到磁盘，让程序用比物理内存更大的地址空间。
</Answer>
