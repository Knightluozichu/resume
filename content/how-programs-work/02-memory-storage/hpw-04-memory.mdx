## 核心机制深挖

内存向程序暴露线性地址空间，类型决定连续字节的解释；指针保存地址，数组使用连续区域，栈队列约束访问顺序，链表和树通过引用表达非连续关系。 每次实验统一登记六类证据：**源码与输入、制品字节、机器状态、接口所有者、首个失败、恢复结果**。CPU页看寄存器和程序计数器，存储页看地址与页面，构建页看符号和映射，硬件页看寄存器、中断与DMA；观察对象不同，因果账本一致。

本页签发不变量是：**每次读写都落在有效对象边界，指针仍指向存活对象；插入删除后结构可达，空、满和根节点状态都有定义。**。正常样本证明主路径，边界样本暴露字长和容量，失败样本确认责任层，恢复样本证明同一输入能回到受控结果。任何无法定位到首个状态分叉的成功都不是完整证据。
