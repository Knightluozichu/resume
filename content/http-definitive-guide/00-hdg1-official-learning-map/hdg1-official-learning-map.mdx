# 2002年首版权威学习地图

“2002年首版权威学习地图”锁定David Gourley、Brian Totty、Marjorie Sayer、Sailu Reddy、Anshu Aggarwal著，陈涓、赵振平译《HTTP权威指南》，人民邮电出版社，2012年，ISBN 9787115281487；英文原版HTTP: The Definitive Guide，O'Reilly Media，2002年9月，656页，ISBN 1565925092。O'Reilly官方页面确认英文首版的5个正文部分、21章和8个附录；中文版完整印刷目录另含“第六部分 附录”和索引。忠实度分母共586个部分、章、编号节/小节、附录与索引节点。

“2002年首版权威学习地图”未取得未获授权的完整中文正文；课程以 [O’Reilly 官方在线版](https://www.oreilly.com/library/view/http-the-definitive/1565925092/) 与 [章级导览](https://www.oreilly.com/library/view/http-the-definitive/1565925092/pr02s02.html) 界定首版范围，中文解释、报文、实验和练习均为独立教学重写。现代语义仅以 [RFC 9110](https://www.rfc-editor.org/rfc/rfc9110.html)、[RFC 9111](https://www.rfc-editor.org/rfc/rfc9111.html) 和 [RFC 9112](https://www.rfc-editor.org/rfc/rfc9112.html) 核对差异。

## 从一条可证伪的HTTP事务开始

先预测：用HTTP/2、HTTP/3、OAuth、JWT、SameSite或现代CDN术语覆盖原书，会丢失HTTP-NG、Digest、WebDAV、WPAD等真实结构。把预测写成“URL/资源、连接、请求报文、中间实体、响应报文、身份与编码”六行，再运行客户端、代理或服务器。结果不同先定位首个字节或状态偏差。

本页主问题是：按5个正文部分、21章、8附录与索引还原HTTP/1.0、HTTP/1.1时代Web协议与架构。每条消息要注明发送者、接收者、HTTP版本、连接复用、逐跳/端到端首部、主体边界与历史协议状态。

验收不变量是：任何结论都能定位到原书正式节点、原始HTTP报文、中间实体状态、历史版本边界和复现实验。最终页面正常、状态码200或TLS通道建立都只是局部事实，不能单独证明资源身份、缓存变体、代理转发与证书身份全部正确。

```text
Host: example.test
Connection: keep-alive
Accept: */*
```

```text
HTTP/1.1 200 OK
Date: Tue, 01 Jan 2002 00:00:00 GMT
Content-Type: text/plain
Content-Length: 5

hello
```

```text
evidence = request_bytes + response_bytes + tcp_timeline + intermediary_state + recovery
```

<Callout type="trap" title="把端到端首部当成逐跳首部">

</Callout>

<Callout type="trap" title="用现代HTTP覆盖原书">

</Callout>
