# 索引

本课程锁定David Gourley、Brian Totty、Marjorie Sayer、Sailu Reddy、Anshu Aggarwal著，陈涓、赵振平译《HTTP权威指南》，人民邮电出版社，2012年，ISBN 9787115281487；英文原版HTTP: The Definitive Guide，O'Reilly Media，2002年9月，656页，ISBN 1565925092。O'Reilly官方页面确认英文首版的5个正文部分、21章和8个附录；中文版完整印刷目录另含“第六部分 附录”和索引。忠实度分母共586个部分、章、编号节/小节、附录与索引节点。

<Objectives>

- 能解释“索引”的全部正式节点及其HTTP事务位置。
- 能绘制请求、响应、TCP连接、中间实体和资源状态。
- 能设计单变量实验，验证“索引检索结果能回到唯一术语语境，并与章、节、附录和版次边界一致”。
- 能写出含首版边界、原始报文、故障、恢复和复核人的证据包。

</Objectives>

## 从一条可证伪的HTTP事务开始

先预测：只按现代同名术语理解索引，会把历史协议和后来标准混为一谈。把预测写成“URL/资源、连接、请求报文、中间实体、响应报文、身份与编码”六行，再运行客户端、代理或服务器。结果不同先定位首个字节或状态偏差。

本页主问题是：把协议名、首部、状态码、认证、缓存、代理、编码和发布术语反向定位到原书页与正式节点。每条消息要注明发送者、接收者、HTTP版本、连接复用、逐跳/端到端首部、主体边界与历史协议状态。

验收不变量是：索引检索结果能回到唯一术语语境，并与章、节、附录和版次边界一致。最终页面正常、状态码200或TLS通道建立都只是局部事实，不能单独证明资源身份、缓存变体、代理转发与证书身份全部正确。

## 核心机制深读

### 先从术语画出事务

把协议名、首部、状态码、认证、缓存、代理、编码和发布术语反向定位到原书页与正式节点。先固定资源身份和请求目标，再标出客户端、中间实体与源服务器，任何优化或安全结论都不能跳过原始报文。

### 区分术语与交叉引用

术语和交叉引用可能在同一事务中协作，但责任、状态位置和失败语义不同。对比正常请求、单个首部变化和单个连接故障，定位首个偏差。

## 可复现实验记录

```text
GET /resource HTTP/1.1\nHost: example.test\nConnection: keep-alive\nAccept: */*
```

```text
HTTP/1.1 200 OK\nDate: Tue, 01 Jan 2002 00:00:00 GMT\nContent-Type: text/plain\nContent-Length: 5\n\nhello
```

```text
evidence = request_bytes + response_bytes + tcp_timeline + intermediary_state + recovery
```

动手试：保存一次正常请求、一次缓存或连接边界和一次单变量故障。记录客户端、代理、缓存、网关与源服务器看到的原始报文，以及统一时间戳和恢复动作。

<Callout type="trap" title="把端到端首部当成逐跳首部">
  Connection及其列出的字段只能作用于当前连接，代理必须移除；误转发会破坏持久连接、缓存和下游解释。
</Callout>

<Callout type="trap" title="用现代HTTP覆盖原书">
  本书的HTTP-NG、Cookie版本1、Digest、FrontPage、WebDAV、WPAD等内容必须按历史状态讲解。现代替代技术不能改写原书目录。
</Callout>
