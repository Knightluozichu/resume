## 从神经元到神经网络

深度学习的核心是**人工神经网络**——受生物神经元启发的计算模型。一个神经元接收输入 `x`，加权求和后加上偏置 `b`，再通过激活函数得到输出：

```text
z = W * x + b
a = activation(z)
```

多个神经元组成**层**，多个层堆叠形成**网络**。「深度」学习即指网络有多层（隐藏层），能自动学习层次化的特征表示——浅层学边缘，深层学部件，更深层学整体。

## 前向传播与反向传播

### 前向传播

数据从输入层经隐藏层到输出层逐层计算。每一层的输出是下一层的输入：

```text
输入 x → 隐藏层1 → 隐藏层2 → ... → 输出 y_hat
```

### 反向传播

反向传播（Backpropagation）是训练神经网络的核心算法。它利用**链式法则**从输出层向输入层逐层计算损失函数对每个权重的梯度，然后用梯度下降更新权重。

```text
前向：x → z=Wx+b → a=activation(z) → ... → 损失 L
反向：dL/dW = (dL/da) * (da/dz) * (dz/dW)  ← 链式法则
更新：W = W - learning_rate * dL/dW
```

<Callout type="info">

**反向传播的本质**：反向传播就是链式法则在计算图上的高效实现。它避免了对每个权重单独数值求导的 O(n^2) 开销，以 O(n) 的代价一次性算出所有梯度。自动微分框架（PyTorch/TensorFlow）自动完成这一过程。

</Callout>

## 激活函数

激活函数引入非线性，使神经网络能拟合复杂函数。没有激活函数，多层网络等价于单层线性变换。

| 激活函数 | 公式 | 特点 | 适用场景 |
|---------|------|------|---------|
| ReLU | max(0, x) | 计算快，缓解梯度消失 | 隐藏层默认选择 |
| Sigmoid | 1 / (1 + e^(-x)) | 输出 (0,1)，易梯度消失 | 二分类输出层 |
| Tanh | (e^x - e^(-x)) / (e^x + e^(-x)) | 输出 (-1,1)，零中心化 | RNN 隐藏层 |
| Softmax | e^xi / sum(e^xj) | 归一化为概率分布 | 多分类输出层 |

## 经典架构

### CNN（卷积神经网络）

CNN 利用图像的局部性和平移不变性，通过**卷积层**（局部感知 + 权值共享）和**池化层**（降维 + 平移不变）替代全连接层，大幅减少参数量。

- **卷积层**：卷积核在输入上滑动，提取局部特征
- **池化层**：Max/Avg 池化降低分辨率，增强鲁棒性
- **全连接层**：整合特征做最终分类

### RNN（循环神经网络）

RNN 通过**隐藏状态**在时间步之间传递信息，适合处理序列数据（文本、语音、时间序列）。

```text
h_t = activation(W_hh * h_{t-1} + W_xh * x_t + b)
```

**LSTM / GRU**：通过门控机制（遗忘门、输入门、输出门）解决 RNN 的长程依赖和梯度消失问题。

### Transformer

Transformer 用**自注意力机制**替代循环结构，实现完全并行化的序列建模，是当今 NLP 的基石。

```text
Attention(Q, K, V) = softmax(Q * K^T / sqrt(d)) * V
```

<Callout type="tip">

**架构选择指南**：图像用 CNN（或 ViT），短序列用 RNN/LSTM，长序列和自然语言用 Transformer。Transformer 已逐渐跨界到视觉（ViT）和语音领域，成为通用架构。

</Callout>

## 梯度消失与残差连接

深层网络面临**梯度消失**问题：反向传播时梯度经多层连乘后趋近于零，浅层权重几乎不更新。ReLU 激活函数（梯度为 0 或 1）部分缓解了这个问题。

**残差连接（ResNet）**：引入跳跃连接 `y = F(x) + x`，让梯度可以绕过非线性层直接反传，使得训练上百层的网络成为可能。

## 优化器

| 优化器 | 思路 | 特点 |
|--------|------|------|
| SGD | 随机梯度下降 | 基础，需调学习率 |
| Momentum | 累积历史梯度方向 | 加速收敛，减少振荡 |
| Adam | 自适应学习率 + 动量 | 最常用，默认选择 |

### 问题 1

神经网络中前向传播和反向传播分别做什么？反向传播如何利用链式法则计算梯度？

<Answer>

前向传播是数据从输入层经隐藏层到输出层的逐层计算过程：每层先计算线性变换 z = Wx + b，再经激活函数 a = activation(z) 得到输出，输出作为下一层输入，最终得到预测值 y_hat 和损失 L。反向传播是训练神经网络的核心算法，它从损失 L 出发，利用链式法则从输出层向输入层逐层计算损失对每个权重的梯度。对于一层，损失对权重 W 的梯度为 dL/dW = (dL/da) * (da/dz) * (dz/dW)，其中 dL/da 来自上一层（反向意义）的反传梯度，da/dz 是激活函数的导数，dz/dW = x（该层输入）。算出梯度后用梯度下降更新：W = W - learning_rate * dL/dW。反向传播的精妙在于以 O(n) 代价一次性算出所有权重梯度，避免了对每个权重单独数值求导的 O(n^2) 开销，自动微分框架（PyTorch/TensorFlow）自动完成这一过程。

</Answer>

### 问题 2

常见的激活函数有哪些？各自的特点和适用场景是什么？为什么需要激活函数？

<Answer>

需要激活函数的原因：没有激活函数，多层神经网络的每一层只是线性变换 Wx+b，多层线性变换的复合仍是线性的，等价于单层，无法拟合非线性函数。激活函数引入非线性，使网络能学习复杂模式。常见激活函数：①ReLU：f(x) = max(0, x)，计算极快（只需比较），梯度为 0 或 1 有效缓解梯度消失，是隐藏层的默认选择，但负区梯度为零可能导致「神经元死亡」。②Sigmoid：f(x) = 1/(1+e^(-x))，输出 (0,1) 可解释为概率，适合二分类输出层，但深层网络中易梯度消失（导数最大值仅 0.25）且输出非零中心化。③Tanh：f(x) = (e^x - e^(-x))/(e^x + e^(-x))，输出 (-1,1) 零中心化，常用于 RNN 隐藏层，但仍可能梯度消失。④Softmax：将向量归一化为概率分布（各分量之和为 1），用于多分类输出层。选择建议：隐藏层用 ReLU，二分类输出用 Sigmoid，多分类输出用 Softmax，RNN 用 Tanh。

</Answer>

### 问题 3

CNN、RNN、Transformer 三大架构的核心思想分别是什么？各自适合处理什么类型的数据？

<Answer>

①CNN（卷积神经网络）核心思想是局部感知和权值共享——卷积核在输入上滑动提取局部特征，同一核在整个输入上共享权重，大幅减少参数量。通过卷积层（特征提取）+ 池化层（降维和平移不变性）+ 全连接层（分类）的堆叠，由浅到深学习从边缘到部件到整体的层次化特征。适合处理具有空间局部性和平移不变性的数据，如图像。代表网络：AlexNet、ResNet、VGG。②RNN（循环神经网络）核心思想是通过隐藏状态在时间步之间传递信息——h_t = activation(W_hh * h_&#123;t-1&#125; + W_xh * x_t + b)，当前输出依赖历史信息，适合处理序列数据如文本、语音、时间序列。但标准 RNN 有长程依赖和梯度消失问题，LSTM/GRU 通过门控机制（遗忘门、输入门、输出门）解决。③Transformer 核心思想是用自注意力机制替代循环结构——Attention(Q,K,V) = softmax(QK^T/sqrt(d))V，每个位置直接关注序列中所有位置，实现完全并行化计算，解决了 RNN 无法并行和长程依赖的问题。适合处理自然语言等长序列，已跨界到视觉（ViT）和语音领域，是当今 AI 的通用架构。

</Answer>

### 问题 4

梯度消失问题是什么？ReLU 激活函数和残差连接（ResNet）如何缓解这个问题？

<Answer>

梯度消失问题：在深层神经网络中，反向传播时梯度需要经过多层激活函数导数的连乘。如果激活函数导数小于 1（如 Sigmoid 最大导数 0.25，Tanh 最大导数 1），多层连乘后梯度呈指数衰减趋近于零，导致浅层权重几乎不更新，网络无法有效训练。梯度消失使得深层网络在 2015 年前难以训练超过 20-30 层。ReLU 缓解方式：ReLU 的导数在正区为 1、负区为 0，正区梯度不会衰减，相比 Sigmoid/Tanh 的导数始终小于 1，ReLU 有效减缓了梯度消失。但负区梯度为零可能导致「神经元死亡」（永不被激活）。残差连接（ResNet）缓解方式：引入跳跃连接 y = F(x) + x，在前向传播时将输入直接加到输出上，反向传播时梯度可以通过跳跃连接直接反传（梯度路径中有一个恒等映射 1），绕过非线性层的导数连乘，使梯度能高效传播到浅层。这使得训练上百层甚至上千层的网络成为可能，ResNet-152 是经典代表。两者结合（ReLU + 残差连接）是训练深度网络的标准配置。

</Answer>
