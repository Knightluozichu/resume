## 从感知机到神经网络

### 感知机

感知机是最早的神经网络模型，由 Rosenblatt 于 1958 年提出。它是一个单层、二分类的线性模型：

```text
z = w^T * x + b
y = 1 if z >= 0 else 0
```

感知机只能解决**线性可分**问题。它的致命缺陷是无法解决 XOR（异或）问题——这导致了第一次 AI 寒冬。

### 多层感知机（MLP）

为了解决非线性问题，在输入和输出之间加入**隐藏层**，并用非线性激活函数：

```text
输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层
```

每一层的计算：`a = activation(W * x + b)`

- 没有激活函数时，多层线性变换的叠加仍是线性的，加隐藏层无意义
- 激活函数引入非线性，使网络能拟合任意复杂的函数（万能逼近定理）

## 激活函数

激活函数为神经网络引入非线性，是深度学习的核心组件。

| 激活函数 | 公式 | 特点 | 适用场景 |
|---------|------|------|---------|
| Sigmoid | `1 / (1 + e^(-z))` | 输出 (0,1)，饱和区梯度消失 | 二分类输出层 |
| Tanh | `(e^z - e^(-z)) / (e^z + e^(-z))` | 输出 (-1,1)，零中心化 | 隐藏层（RNN） |
| ReLU | `max(0, z)` | 计算简单，缓解梯度消失 | 隐藏层（默认选择） |
| Softmax | `e^(z_i) / sum(e^(z_j))` | 输出概率分布，和为 1 | 多分类输出层 |

<Callout type="info">

**ReLU 为何成为默认选择**：①计算极简——只需 `max(0, z)`，比 Sigmoid/Tanh 的指数运算快得多；②缓解梯度消失——正区间梯度恒为 1，深层网络也能有效传播梯度；③稀疏激活——负输入输出 0，使网络具有稀疏性。但 ReLU 有「神经元死亡」问题：负输入梯度为 0，神经元可能永久不更新。Leaky ReLU 用 `max(0.01z, z)` 修正此问题。

</Callout>

## 万能逼近定理

万能逼近定理（Universal Approximation Theorem）指出：只要隐藏层有足够多的神经元，且使用非线性激活函数，一个前馈神经网络就能以任意精度逼近任意连续函数。

这一定理的意义：

- **理论保证**：证明了 MLP 有能力表示任意复杂的映射关系
- **非线性的必要性**：定理前提是必须使用非线性激活函数
- **深度 vs 宽度**：实践中「深度」比「宽度」更有效率——深层网络用更少参数表示同样的函数

<Callout type="tip">

**注意**：万能逼近定理只保证「表示能力」，不保证「可学习性」（优化算法能否找到最优解）。这也是深度学习训练仍需要技巧的原因。

</Callout>

## 激活函数的演进

| 代际 | 激活函数 | 年代 | 解决的问题 |
|------|---------|------|-----------|
| 第一代 | Sigmoid/Tanh | 1980s | 引入非线性 |
| 第二代 | ReLU | 2010s | 缓解梯度消失 |
| 改进 | Leaky ReLU/PReLU/ELU | 2015+ | 修复神经元死亡 |
| 现代 | GELU/Swish | 2017+ | 平滑+自门控（Transformer 常用） |

<Glossary>

<GlossaryItem term="感知机">
最早的神经网络模型，单层线性二分类器。只能解决线性可分问题，无法解决 XOR 问题。多层感知机通过加隐藏层和激活函数克服了这一局限。
</GlossaryItem>

<GlossaryItem term="激活函数">
为神经网络引入非线性的函数。没有激活函数，多层线性变换的叠加仍是线性的。常用激活函数：Sigmoid（输出层二分类）、ReLU（隐藏层默认选择）、Tanh（RNN）、Softmax（多分类输出层）。
</GlossaryItem>

<GlossaryItem term="ReLU">
`ReLU(z) = max(0, z)`，最常用的隐藏层激活函数。优点：计算简单、正区间梯度恒为 1 缓解梯度消失、稀疏激活。缺点：负输入梯度为 0 可能导致神经元死亡。Leaky ReLU 用 `max(0.01z, z)` 修正。
</GlossaryItem>

<GlossaryItem term="万能逼近定理">
只要隐藏层有足够多神经元且使用非线性激活函数，前馈神经网络能以任意精度逼近任意连续函数。这从理论上保证了神经网络的表达能力，是深度学习的理论基础。
</GlossaryItem>

<GlossaryItem term="神经元死亡">
ReLU 激活函数的缺陷：如果某神经元输入持续为负，其梯度为 0，权重永远不更新，神经元永久失活。解决方案：Leaky ReLU（负区间给小斜率）、PReLU（斜率可学习）、ELU（指数平滑）。
</GlossaryItem>

<GlossaryItem term="GELU">
高斯误差线性单元，`GELU(z) = z * Phi(z)`（Phi 为标准正态分布的 CDF）。平滑且保留 ReLU 优点，BERT/GPT 等 Transformer 模型常用。比 ReLU 在大模型上表现更好。
</GlossaryItem>

</Glossary>

### 问题 1

感知机是什么？它有什么局限性？多层感知机如何克服这一局限性？

<Answer>

感知机是最早的神经网络模型，由 Rosenblatt 于 1958 年提出。它是一个单层、二分类的线性模型：z = w^T * x + b，当 z >= 0 输出 1 否则输出 0。感知机的局限性是只能解决线性可分问题——它只能学到一个线性决策边界（超平面），无法解决 XOR（异或）等非线性可分问题，这导致了第一次 AI 寒冬。多层感知机（MLP）通过在输入层和输出层之间加入隐藏层来克服这一局限性。关键在于非线性激活函数：如果没有激活函数，多层线性变换的叠加 W2*(W1*x) = (W2*W1)*x 仍是线性的，加再多隐藏层也等价于一层。激活函数（如 ReLU、Sigmoid）引入非线性变换，使网络能拟合任意复杂函数（万能逼近定理）。

</Answer>

### 问题 2

常见的激活函数有哪些？各自的公式、特点和适用场景是什么？

<Answer>

常见激活函数：①Sigmoid——1/(1+e^(-z))，输出 (0,1) 区间，S 形曲线。优点是输出可解释为概率，适合二分类输出层。缺点是饱和区梯度趋近 0 导致梯度消失，输出非零中心化。②Tanh——(e^z-e^(-z))/(e^z+e^(-z))，输出 (-1,1)，零中心化，比 Sigmoid 好但仍存在饱和区，常用于 RNN。③ReLU——max(0,z)，正区间线性、负区间输出 0。计算极简、正区间梯度恒为 1 缓解梯度消失、稀疏激活，是隐藏层默认选择。缺点是负输入梯度为 0 可能导致神经元死亡，Leaky ReLU 用 max(0.01z,z) 修正。④Softmax——e^(z_i)/sum(e^(z_j))，将多个得分转化为概率分布（和为 1），用于多分类输出层。

</Answer>

### 问题 3

什么是万能逼近定理？它对深度学习有什么意义？

<Answer>

万能逼近定理指出：只要隐藏层有足够多的神经元，且使用非线性激活函数，一个前馈神经网络就能以任意精度逼近任意连续函数。意义：①理论保证——证明了 MLP 有能力表示任意复杂的映射关系。②非线性的必要性——定理前提是必须使用非线性激活函数，解释了为什么激活函数是核心组件。③深度 vs 宽度——定理只说「宽度足够」就行，但实践中「深度」更有效率：深层网络用更少总参数表示同样的函数（深度指数级减少所需参数），这是深度学习「深」的理论基础。④注意——定理只保证「表示能力」，不保证「可学习性」（优化算法能否找到最优解），这也是深度学习训练仍需要技巧的原因。

</Answer>

### 问题 4

ReLU 为什么成为隐藏层的默认选择？它有什么缺陷及改进方案？

<Answer>

ReLU 成为隐藏层默认选择的三个原因：①计算极简——只需 max(0,z) 运算，比 Sigmoid/Tanh 的指数运算快得多；②缓解梯度消失——ReLU 正区间导数恒为 1，反向传播时梯度不会因连乘而衰减，使深层网络也能有效训练；③稀疏激活——负输入输出 0，同一时刻只有部分神经元被激活，网络具有稀疏性，有正则化效果。缺陷：神经元死亡问题——如果某个神经元的输入持续为负，其梯度为 0，权重永远不更新，神经元永久失活。改进方案：①Leaky ReLU——max(0.01z, z)，负区间给一个小的斜率；②PReLU——把负区间斜率作为可学习参数；③ELU——负区间用指数函数平滑过渡；④GELU——高斯误差线性单元，BERT/GPT 等 Transformer 模型常用。

</Answer>
