## 前向传播概述

前向传播是输入数据从输入层经过隐藏层到输出层的计算过程。每一层的计算模式都是「线性变换 + 激活函数」：

```text
z = W * x + b     # 线性变换（加权求和 + 偏置）
a = activation(z)  # 非线性激活
```

- `W` 是权重矩阵，`b` 是偏置向量
- `z` 是线性变换的中间结果（pre-activation）
- `a` 是激活后的输出（activation），也是下一层的输入

## 两层网络的前向传播

以两层网络（一个隐藏层 + 一个输出层）为例：

```text
# 第一层（隐藏层）
z1 = W1 * x + b1      # 线性变换
a1 = ReLU(z1)          # 激活函数引入非线性

# 第二层（输出层）
z2 = W2 * a1 + b2      # 线性变换
a2 = softmax(z2)       # 输出概率分布
```

- `W1` 维度 `h x n`（h 是隐藏层神经元数，n 是输入维度）
- `W2` 维度 `K x h`（K 是输出类别数）
- `a2` 是最终预测结果（概率分布）

## 为什么需要激活函数

如果没有激活函数（或使用线性激活函数），多层网络的计算如下：

```text
a1 = W1 * x + b1                         # 隐藏层（线性）
a2 = W2 * a1 + b2                        # 输出层（线性）
   = W2 * (W1 * x + b1) + b2
   = (W2 * W1) * x + (W2 * b1 + b2)      # 仍是一个线性变换
```

两个线性变换的叠加 `W2*(W1*x)` 等于一个单一的线性变换 `(W2*W1)*x`，整个网络退化为单层线性模型。无论加多少隐藏层，表达能力都和没有隐藏层一样。

<Callout type="info">

**核心结论**：激活函数通过非线性变换打破线性叠加的等价性。ReLU 将负值截断为 0，Sigmoid 将输出压缩到 (0,1)，这些非线性操作使每一层都能学习到新的特征表示，从而让网络能拟合任意复杂函数。

</Callout>

## Softmax 与多分类

Softmax 函数将一个实数向量转化为概率分布：

```text
softmax(z_i) = e^(z_i) / sum(e^(z_j))
```

- 输入：模型输出层的原始得分（logits）`z = [z1, z2, ..., zK]`
- 输出：K 个非负实数，和为 1，可解释为每个类别的预测概率
- 预测：取概率最大的类别 `argmax(softmax(z))`

<Callout type="tip">

**Softmax + 交叉熵的优美性质**：当 Softmax 配合交叉熵损失使用时，梯度简化为 `dL/dz = a - y`（预测值减真实标签），计算极其高效。这是分类任务几乎统一使用交叉熵损失的根本原因。

</Callout>

## 权重与偏置的作用

| 参数 | 作用 | 维度 |
|------|------|------|
| 权重矩阵 W | 决定输入特征如何组合变换 | `m x n`（m 个输出，n 个输入） |
| 偏置向量 b | 提供平移能力，使决策边界不必过原点 | `m x 1` |

参数量计算：每层参数量 = `m * n`（权重）+ `m`（偏置）。例如输入 3 特征、隐藏层 4 神经元，则 `W1` 为 `4x3`（12 个权重）+ `b1` 为 `4x1`（4 个偏置）= 16 个参数。

<Glossary>

<GlossaryItem term="前向传播">
输入数据从输入层经过隐藏层到输出层的计算过程。每一层计算 `a = activation(W * x + b)`，前一层的输出是下一层的输入，最终得到预测结果。
</GlossaryItem>

<GlossaryItem term="权重矩阵（W）">
神经网络的可学习参数，决定输入特征如何线性组合变换。W 的维度为 `m x n`（m 个输出神经元，n 个输入特征），W[i][j] 表示第 j 个输入对第 i 个输出的贡献权重。
</GlossaryItem>

<GlossaryItem term="偏置向量（b）">
神经网络的可学习参数，提供平移能力。没有偏置时线性变换只能做过原点的变换；加上偏置后可以做任意平移，增强模型表达能力。
</GlossaryItem>

<GlossaryItem term="Softmax">
将实数向量转化为概率分布的函数。`softmax(z_i) = e^(z_i) / sum(e^(z_j))`，输出 K 个非负值和为 1。用于多分类输出层，与交叉熵损失配合时梯度简化为 `a - y`。
</GlossaryItem>

<GlossaryItem term="Logits">
模型输出层的原始得分（Softmax 之前），是未归一化的实数。Softmax 将 logits 转化为概率分布。有些损失函数（如 `CrossEntropyLoss`）内部集成了 Softmax，可直接输入 logits。
</GlossaryItem>

<GlossaryItem term="线性变换的叠加等价性">
两个线性变换的叠加等价于一个线性变换：`W2*(W1*x) = (W2*W1)*x`。这意味着没有非线性激活函数时，多层网络退化为单层线性模型，加隐藏层无意义。激活函数打破这一等价性。
</GlossaryItem>

</Glossary>

### 问题 1

什么是前向传播？请以两层网络为例描述完整的计算流程。

<Answer>

前向传播是输入数据从输入层经过隐藏层到输出层的计算过程。以两层网络（一个隐藏层 + 一个输出层）为例：①输入层接收原始数据 x = [x1, x2, ..., xn]。②隐藏层计算——先做线性变换 z1 = W1 * x + b1（W1 是权重矩阵，b1 是偏置向量），再通过激活函数引入非线性 a1 = ReLU(z1)。③输出层计算——以隐藏层激活值 a1 为输入，先做线性变换 z2 = W2 * a1 + b2，再通过输出层激活函数 a2 = softmax(z2)。④最终输出 a2 即为模型的预测结果。每一层的计算模式都是「线性变换 + 激活函数」，前一层的输出是下一层的输入。前向传播的目的是得到预测值，用于与真实标签比较计算损失。

</Answer>

### 问题 2

为什么神经网络需要激活函数？如果没有激活函数会怎样？

<Answer>

神经网络需要激活函数的核心原因是引入非线性。如果没有激活函数，多层网络的计算如下：隐藏层输出 a1 = W1 * x + b1，输出层 a2 = W2 * a1 + b2 = W2 * (W1 * x + b1) + b2 = (W2 * W1) * x + (W2 * b1 + b2)。两个线性变换的叠加 W2*(W1*x) 等于一个单一的线性变换 (W2*W1)*x，整个网络等价于一个单层线性模型。无论加多少隐藏层，网络的表达能力都和没有隐藏层的线性模型相同，无法解决任何非线性问题（如 XOR）。激活函数通过非线性变换打破这一等价性：ReLU 将负值截断为 0，Sigmoid 将输出压缩到 (0,1)，这些非线性操作使每一层都能学习到新的特征表示，从而让网络能拟合任意复杂函数。

</Answer>

### 问题 3

Softmax 函数是什么？它在多分类任务中如何工作？

<Answer>

Softmax 函数将一个实数向量转化为概率分布。公式：softmax(z_i) = e^(z_i) / sum(e^(z_j))。工作方式：①输入——模型输出层的原始得分（logits）z = [z1, z2, ..., zK]，K 是类别数。②计算——对每个 z_i 取指数 e^(z_i)，然后除以所有指数之和进行归一化。③输出——得到 K 个非负实数，和为 1，可解释为每个类别的预测概率。④预测——取概率最大的类别 argmax(softmax(z))。特点：①放大差异——指数运算放大了较大得分的优势；②可微——梯度可计算，适合反向传播；③与交叉熵配合——Softmax + 交叉熵损失的梯度有优美的简化形式 dL/dz = a - y（预测值减真实标签），计算高效。

</Answer>

### 问题 4

前向传播中的权重矩阵和偏置向量各自起什么作用？它们的维度如何确定？

<Answer>

权重矩阵 W 决定输入特征如何组合变换。W 的每一行代表一个输出神经元，每一列代表一个输入特征，W[i][j] 表示第 j 个输入对第 i 个输出的贡献权重。偏置向量 b 提供平移能力——没有偏置时，线性变换 z = W*x 只能做过原点的线性变换；加上偏置 z = W*x + b 后，可以做任意平移，使激活函数的决策边界不必过原点。维度确定：假设前一层的输出维度为 n（神经元数），当前层的神经元数为 m，则 W 的维度为 m x n（m 行 n 列），b 的维度为 m x 1。例如输入层 3 个特征、隐藏层 4 个神经元，则 W1 维度为 4x3，b1 维度为 4x1。参数量计算：每层参数量 = m*n（权重） + m（偏置）。

</Answer>
