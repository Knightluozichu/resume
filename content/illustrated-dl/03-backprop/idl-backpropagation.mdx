## 反向传播概述

反向传播是训练神经网络的核心算法，用**链式法则**从输出层向输入层逐层计算损失函数对每个参数的梯度。

### 完整训练循环

```text
1. 前向传播：计算各层激活值和最终预测
2. 计算损失：用预测值与真实值计算损失（如交叉熵）
3. 反向传播：从输出层向输入层逐层计算梯度
4. 参数更新：用梯度下降更新所有权重和偏置
5. 重复 1-4 直到收敛
```

## 链式法则

如果 `y = f(g(x))`，则 `dy/dx = f'(g(x)) * g'(x)`。

在神经网络中，损失 L 是多层复合函数，梯度需要逐层展开：

```text
# 前向计算
z1 = W1 * x + b1       →  a1 = ReLU(z1)
z2 = W2 * a1 + b2      →  a2 = softmax(z2)
L = CrossEntropy(a2, y)

# 反向传播（从后向前）
dL/dz2 = a2 - y                    # 交叉熵 + softmax 的简化形式
dL/dW2 = dL/dz2 * a1^T             # 输出层权重梯度
dL/db2 = dL/dz2                    # 输出层偏置梯度

dL/da1 = W2^T * dL/dz2             # 梯度传到隐藏层
dL/dz1 = dL/da1 * ReLU'(z1)        # 乘以激活函数导数
dL/dW1 = dL/dz1 * x^T              # 隐藏层权重梯度
dL/db1 = dL/dz1                    # 隐藏层偏置梯度
```

<Callout type="info">

**为什么叫「反向传播」**：每一层的梯度都依赖于后一层的梯度（`dL/da1` 依赖 `dL/dz2`），因此必须从输出层向输入层逐层计算，方向与前向传播相反。

</Callout>

## 参数更新

计算完梯度后，用梯度下降更新参数：

```text
W = W - lr * dL/dW
b = b - lr * dL/db
```

`lr` 是学习率，控制每次更新的步长。太大则震荡发散，太小则收敛缓慢。

## 交叉熵 + Softmax 的梯度简化

交叉熵损失 `L = -sum(y_i * log(a_i))` 配合 Softmax 输出 `a = softmax(z)`，其梯度有优美的简化形式：

```text
dL/dz = a - y    # 预测值减真实标签
```

这一简化避免了计算 Softmax 的完整雅可比矩阵，计算高效且梯度稳定。

<Callout type="tip">

**实际意义**：当预测完全正确时 `a = y`，梯度为 0，参数不更新；当预测错误时梯度较大，参数快速调整。这种自适应的梯度大小使训练更高效，是分类任务几乎统一使用交叉熵损失的根本原因。

</Callout>

## 梯度消失与梯度爆炸

深层网络中，梯度在反向传播经过多层时会连乘激活函数的导数和权重矩阵。

| 问题 | 成因 | 结果 | 解决方案 |
|------|------|------|---------|
| 梯度消失 | 导数 < 1（Sigmoid 最大 0.25） | 浅层权重不更新 | ReLU / BatchNorm / 残差连接 |
| 梯度爆炸 | 权重值大，连乘发散 | 参数震荡，损失变 NaN | 梯度裁剪 / 权重初始化 |

### 解决方案详解

- **ReLU 激活函数**：正区间导数恒为 1，梯度不衰减
- **BatchNorm**：标准化每层输入，使激活值在非饱和区
- **残差连接（ResNet）**：`y = F(x) + x`，梯度可通过跳跃连接直达浅层
- **梯度裁剪**：限制梯度范数，防止爆炸
- **权重初始化**：Xavier（Sigmoid/Tanh）/ He（ReLU）

<GlossaryItem term="反向传播">
训练神经网络的核心算法，用链式法则从输出层向输入层逐层计算损失函数对每个参数的梯度。计算完梯度后用梯度下降更新参数。完整循环：前向传播 → 计算损失 → 反向传播 → 参数更新。
</GlossaryItem>

<GlossaryItem term="链式法则">
微积分中复合函数求导的法则。如果 y = f(g(x))，则 dy/dx = f'(g(x)) * g'(x)。在神经网络中，损失是多层复合函数，链式法则用于逐层展开计算梯度。
</GlossaryItem>

<GlossaryItem term="梯度下降">
用梯度更新参数的优化算法。W = W - lr * dL/dW，lr 是学习率。每次沿损失函数下降最快的方向（负梯度方向）更新参数，逐步逼近最小值。
</GlossaryItem>

<GlossaryItem term="梯度消失">
深层网络中梯度经过多层连乘激活函数导数后趋近于 0 的现象。Sigmoid 的最大导数为 0.25，多层连乘后梯度极小，浅层权重几乎不更新。解决方案：ReLU 激活函数、批归一化、残差连接。
</GlossaryItem>

<GlossaryItem term="梯度爆炸">
深层网络中梯度经过多层连乘后趋向无穷的现象。当权重矩阵的值较大时，多层连乘后梯度以指数级增长，参数震荡发散，损失变为 NaN。解决方案：梯度裁剪、合适的权重初始化。
</GlossaryItem>

<GlossaryItem term="交叉熵损失">
分类任务的标准损失函数。L = -sum(y_i * log(a_i))。配合 Softmax 输出时，梯度简化为 dL/dz = a - y（预测值减真实标签），计算高效且训练稳定。
</GlossaryItem>

</Glossary>

### 问题 1

什么是反向传播？请描述完整的前向传播-反向传播训练循环。

<Answer>

反向传播是训练神经网络的核心算法，用链式法则从输出层向输入层逐层计算损失函数对每个参数的梯度。完整训练循环包含四个步骤：①前向传播——输入数据从输入层经过隐藏层到输出层，计算各层激活值和最终预测。隐藏层：z1 = W1*x + b1，a1 = ReLU(z1)；输出层：z2 = W2*a1 + b2，a2 = softmax(z2)。②计算损失——用预测值 a2 和真实标签 y 计算损失函数（如交叉熵）。③反向传播——用链式法则从输出层向输入层逐层计算梯度。输出层：dL/dz2 = a2 - y，dL/dW2 = dL/dz2 * a1^T；隐藏层：dL/da1 = W2^T * dL/dz2，dL/dz1 = dL/da1 * ReLU'(z1)，dL/dW1 = dL/dz1 * x^T。④参数更新——用梯度下降更新所有参数：W = W - lr * dL/dW。重复 1-4 直到损失收敛。

</Answer>

### 问题 2

链式法则在反向传播中如何应用？请以两层网络为例推导梯度计算过程。

<Answer>

链式法则：如果 y = f(g(x))，则 dy/dx = f'(g(x)) * g'(x)。在神经网络中，损失 L 是多层复合函数，梯度需要逐层展开。以两层网络为例，前向计算为 z1 = W1*x + b1 → a1 = ReLU(z1) → z2 = W2*a1 + b2 → a2 = softmax(z2) → L = CE(a2, y)。反向推导：①输出层梯度——dL/dz2 = a2 - y（交叉熵 + softmax 的简化形式）。②输出层参数梯度——dL/dW2 = dL/dz2 * a1^T，dL/db2 = dL/dz2。③隐藏层梯度（链式法则反向传播）——dL/da1 = W2^T * dL/dz2（梯度从输出层传到隐藏层），dL/dz1 = dL/da1 ⊙ ReLU'(z1)（逐元素乘以激活函数的导数）。④隐藏层参数梯度——dL/dW1 = dL/dz1 * x^T，dL/db1 = dL/dz1。每一层的梯度都依赖于后一层的梯度，因此必须从后向前计算。

</Answer>

### 问题 3

什么是梯度消失和梯度爆炸？各自的成因和解决方案是什么？

<Answer>

梯度消失和梯度爆炸是深层网络训练中的核心问题，根源在于反向传播时梯度经过多层的连乘。梯度消失：当激活函数导数 < 1 时（如 Sigmoid 最大导数 0.25），多层连乘后梯度以指数级衰减趋近于 0，浅层权重几乎不更新，网络无法学习有效特征。梯度爆炸：当权重值较大时，多层连乘后梯度以指数级增长趋向无穷，参数震荡发散，损失变为 NaN。解决方案：①使用 ReLU 激活函数——正区间导数恒为 1，梯度不衰减；②批归一化（BatchNorm）——标准化每层输入，使激活值在非饱和区；③残差连接（ResNet）——引入跳跃连接 y = F(x) + x，梯度可直接传到浅层；④梯度裁剪——对梯度做范数裁剪；⑤合适的权重初始化——Xavier（Sigmoid/Tanh）或 He（ReLU）初始化。

</Answer>

### 问题 4

为什么交叉熵损失配合 Softmax 输出层能简化梯度计算？这对训练有什么实际意义？

<Answer>

交叉熵损失 L = -sum(y_i * log(a_i)) 配合 Softmax 输出 a = softmax(z)，其梯度简化为 dL/dz = a - y（预测值减真实标签）。推导：①先求 dL/da_i = -y_i / a_i。②再求 softmax 的雅可比矩阵 da_i/dz_j = a_i * (delta_ij - a_j)。③用链式法则组合：dL/dz_j = sum_i (-y_i/a_i * a_i * (delta_ij - a_j)) = -y_j + a_j * sum_i(y_i) = a_j - y_j（因为 sum(y_i) = 1）。实际意义：①计算高效——无需计算 softmax 的完整雅可比矩阵，直接用预测值减标签。②梯度稳定——预测正确时梯度为 0，预测错误时梯度较大，自适应调整。③避免学习速度饱和——用均方误差 + Sigmoid 时梯度中多一个 sigmoid'(z) 项，饱和时趋近 0 导致停滞；交叉熵 + Softmax 消除了这一项。这是分类任务统一使用交叉熵损失的根本原因。

</Answer>
