## 从感知机到 Transformer

深度学习的核心发展脉络，每一步都在解决前一步的关键瓶颈：

| 阶段 | 时间 | 关键技术 | 解决的问题 |
|------|------|---------|-----------|
| 基础期 | 1958-1986 | 感知机 → 反向传播 | 神经网络「能不能训练」 |
| 架构期 | 1998-2014 | CNN（LeNet/AlexNet）+ RNN（LSTM） | 图像空间特征 + 序列时序建模 |
| 优化期 | 2012-2015 | Dropout/BatchNorm/Adam/ResNet | 「如何训练更深的网络」 |
| 生成期 | 2014-2017 | GAN/VAE | 从判别模型到生成模型 |
| 统一期 | 2017-至今 | Transformer/大模型 | 架构统一 + 规模化 |

<Callout type="info">

**核心洞察**：深度学习的发展不是随机的技术堆叠，而是一条「解决瓶颈→出现新瓶颈→解决新瓶颈」的演进链。理解每个技术为什么出现、解决了什么问题，比记住公式更重要。

</Callout>

## CNN vs RNN：设计思想对比

| 维度 | CNN | RNN |
|------|-----|-----|
| 核心假设 | 空间局部性 | 时序依赖性 |
| 参数共享 | 空间维度（卷积核滑动） | 时间维度（权重共享） |
| 信息流 | 前馈单向 | 时间维度循环 |
| 适合数据 | 图像（空间网格） | 文本/语音（时间序列） |
| 并行性 | 完全并行 | 时间步顺序计算 |

<Callout type="tip">

**Transformer 融合两者优点**：自注意力机制既支持并行计算（像 CNN），又能建模长距离依赖（超越 RNN），这是 Transformer 能统一各领域的原因。

</Callout>

## 正则化策略体系

解决过拟合需要从数据、模型、训练三个层面系统施策：

```text
数据层面：增加数据量 / 数据增强 / 数据清洗
模型层面：降低复杂度 / L2正则化 / Dropout / BatchNorm
训练层面：Early Stopping / 学习率调度 / 交叉验证 / 集成学习
```

**实践原则**：先用简单模型做基线 → 逐步增加复杂度 → 始终监控训练/验证损失曲线 → 优先增加数据而非模型复杂度。

## 端到端工程实践

一个完整的深度学习项目流程：

```text
需求分析 → 数据准备 → 模型选择 → 训练配置 → 评估 → 调优 → 部署
```

| 阶段 | 关键决策 |
|------|---------|
| 模型选择 | 基线 ResNet-50 → 预训练权重 → 微调 |
| 训练配置 | 优化器 Adam / 学习率 1e-4 / batch size / 轮数 |
| 正则化 | Dropout 0.5 / 权重衰减 1e-4 / 数据增强 |
| 部署 | ONNX 导出 → INT8 量化 → 服务化 → 监控 |

## 核心知识链路

全书的知识可以串联为一条主线：

- **基础**：感知机 → 前向传播（线性+激活） → 反向传播（链式法则+梯度下降）
- **网络**：CNN（空间特征） + RNN（时序特征） → 正则化（泛化） + 生成模型（创造）
- **应用**：CV / NLP / 语音 → Transformer 统一架构 → 大模型与多模态

### 问题 1

从感知机到 Transformer，深度学习的核心发展脉络是什么？每一步解决了什么关键问题？

<Answer>

深度学习的核心发展脉络：①感知机（1958）——最早的神经网络模型，解决线性分类问题。关键问题：只能处理线性可分数据，无法解决 XOR。②多层感知机 + 反向传播（1986）——加隐藏层和非线性激活函数，用反向传播算法训练。关键问题：解决了非线性分类，但深层网络梯度消失、训练困难，算力不足。③CNN（1998 LeNet → 2012 AlexNet）——卷积+池化提取空间特征，权值共享减少参数。关键问题：解决了图像特征提取，AlexNet 利用 GPU+大数据引爆深度学习。④RNN/LSTM（1997-2014）——循环结构处理序列数据，门控机制解决长距离依赖。关键问题：解决了序列建模，但训练无法并行、长序列仍有限。⑤残差连接 ResNet（2015）——跳跃连接使上百层网络可训练。关键问题：解决了深层网络的梯度消失和退化问题。⑥Transformer（2017）——自注意力替代循环，全局并行计算。关键问题：解决了 RNN 无法并行和长距离依赖问题，统一了 NLP 架构。⑦预训练大模型（2018 BERT → 2020 GPT-3 → 2023 GPT-4）——大规模预训练+微调/提示学习。关键问题：统一了多任务架构，Scaling Law 驱动涌现能力。

</Answer>

### 问题 2

CNN 和 RNN 分别擅长处理什么类型的数据？它们的核心设计思想有何本质区别？

<Answer>

CNN 擅长处理空间数据（如图像），RNN 擅长处理时序数据（如文本、语音）。核心设计思想的本质区别：①空间 vs 时序——CNN 的核心假设是「空间局部性」：相邻像素相关性高。通过局部卷积核提取局部特征，逐层组合成全局特征。RNN 的核心假设是「时序依赖性」：当前输出依赖历史信息，通过隐藏状态传递记忆。②参数共享方式——CNN 在空间维度上共享权重（卷积核滑动），捕获平移不变性。RNN 在时间维度上共享权重，捕获时间不变性。③信息流方向——CNN 是前馈的，信息单向流动无内部循环。RNN 是反馈的，信息在时间维度上循环流动。④感受野 vs 记忆窗口——CNN 通过堆叠卷积层扩大空间感受野。RNN 通过隐藏状态维护时序记忆窗口。⑤并行性——CNN 可完全并行计算。RNN 时间步必须顺序计算。Transformer 的自注意力融合两者优点：既支持并行计算（像 CNN），又能建模长距离依赖（超越 RNN），这也是 Transformer 能统一各领域的原因。

</Answer>

### 问题 3

深度学习训练中如何系统性地解决过拟合问题？请从数据、模型、训练三个层面给出策略。

<Answer>

系统性解决过拟合的三个层面策略。数据层面：①增加数据量——收集更多训练数据，数据增强（翻转/裁剪/旋转/颜色扰动）可低成本扩充。②数据清洗——去除噪声标签和异常值。③特征筛选——去除冗余和噪声特征。模型层面：①降低模型复杂度——减少层数/神经元数。②L2 正则化——惩罚大权重。③Dropout——随机丢弃神经元打破共适应。④BatchNorm/LayerNorm——标准化激活值，附带正则化。⑤早停——验证集性能下降时停止。训练层面：①学习率调度——余弦退火等。②优化器选择——Adam 自适应学习率。③交叉验证——K 折评估泛化能力。④集成学习——多模型投票/平均。⑤对抗训练——加入对抗样本提升鲁棒性。实践原则：先用简单模型做基线，逐步增加复杂度；始终监控训练/验证损失曲线；优先增加数据而非模型复杂度；正则化强度通过验证集调参。

</Answer>

### 问题 4

如果让你设计一个图像分类项目，从前向传播到部署的完整流程是什么？需要做哪些关键决策？

<Answer>

完整流程和关键决策：①需求分析——确定分类类别数、精度要求、延迟要求、部署平台。②数据准备——收集标注数据，划分训练/验证/测试集（70/15/15），分析类别分布。关键决策：数据增强策略、是否需要预训练模型的数据预处理。③模型选择——基线用 ResNet-50（成熟稳定），追求精度用 ViT/Swin Transformer，边缘部署用 MobileNet。关键决策：模型容量与数据量匹配、是否用预训练权重（ImageNet 预训练几乎总是应该用）。④训练配置——前向传播计算预测，交叉熵损失计算误差，反向传播计算梯度，Adam 优化器更新参数。关键决策：学习率（预训练用 1e-4）、batch size、训练轮数（配合早停）、学习率调度（余弦退火）。⑤正则化——Dropout（全连接层 0.5）、权重衰减（1e-4）、数据增强、BatchNorm。⑥评估——测试集计算准确率/精确率/召回率/F1，混淆矩阵分析错误模式。⑦优化调参——根据评估结果调整。⑧部署——模型导出（ONNX）、量化（INT8）、服务化（REST API）、监控。核心是：简单基线 → 评估 → 迭代改进，避免一开始就用复杂方案。

</Answer>
