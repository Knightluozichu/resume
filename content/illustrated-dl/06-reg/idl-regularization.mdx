## 过拟合与欠拟合

| 状态 | 训练集表现 | 验证集表现 | 原因 |
|------|-----------|-----------|------|
| 欠拟合 | 差 | 差 | 模型太简单 |
| 恰好 | 好 | 好 | 模型复杂度匹配 |
| 过拟合 | 很好 | 差 | 模型太复杂/数据不足 |

**判断方法**：监控训练损失和验证损失——如果训练损失持续下降但验证损失开始上升，说明过拟合开始发生。

## 常见正则化方法

### L2 正则化（权重衰减）

在损失函数中加入权重惩罚项：

```text
L_total = L_data + lambda * ||W||^2
```

限制权重过大，使模型更平滑。`lambda` 越大正则化越强。

### Dropout

训练时随机将一部分神经元的输出置为 0（丢弃率通常 0.2-0.5），迫使网络不依赖任何单个神经元。

- **训练时**：以概率 p 随机丢弃神经元
- **推理时**：不丢弃，使用完整网络（需做缩放补偿）
- **效果**：打破共适应 + 模型集成效应

<Callout type="info">

**Dropout 为什么有效**：①打破共适应——神经元不能依赖特定其他神经元的存在，增强鲁棒性。②模型集成——每次 Dropout 采样不同的子网络，推理时用完整网络相当于子网络的近似集成。

</Callout>

### Batch Normalization

对每层输入做标准化（均值 0、方差 1），再用可学习参数恢复表达能力：

```text
z_norm = (z - mu) / sqrt(sigma^2 + epsilon)
z_out = gamma * z_norm + beta
```

- **训练时**：使用当前 mini-batch 的均值和方差
- **推理时**：使用训练过程中累积的移动平均统计量

### Early Stopping

监控验证集损失，当其连续若干轮不下降时停止训练，防止过训练。

## 优化器对比

| 优化器 | 公式 | 特点 |
|--------|------|------|
| SGD | `W -= lr * dW` | 基础，需调 lr |
| Momentum | `v = 0.9*v + dW; W -= lr * v` | 惯性加速收敛 |
| RMSprop | `s = 0.9*s + 0.1*dW^2; W -= lr * dW / sqrt(s)` | 自适应学习率 |
| Adam | 结合 Momentum + RMSprop | 最常用默认选择 |

<Callout type="tip">

**实践建议**：先用 Adam 快速实验（通常不需要精细调参就有好效果），如果需要极致性能再尝试 SGD+Momentum 配合学习率调度（余弦退火等）。

</Callout>

## 数据增强

数据增强也是有效的正则化手段：

- **图像**：水平翻转、随机裁剪、颜色抖动、旋转
- **文本**：同义词替换、回译、随机删除
- **音频**：加噪、变速、音调变换

通过扩充训练数据提升泛化能力，等效于增加数据量。

<Glossary>

<GlossaryItem term="过拟合">
模型在训练集上表现很好但在验证/测试集上表现差的现象。模型「记住」了训练数据的细节和噪声而非学到通用规律。判断：训练损失下降但验证损失上升。解决方案：正则化、Dropout、数据增强、Early Stopping。
</GlossaryItem>

<GlossaryItem term="Dropout">
训练时随机将部分神经元输出置为 0 的正则化技术。迫使网络不依赖任何单个神经元（打破共适应），等效于训练大量子网络的集成。训练时丢弃，推理时使用完整网络。通常用在全连接层，丢弃率 0.2-0.5。
</GlossaryItem>

<GlossaryItem term="Batch Normalization（BatchNorm）">
对每层输入做标准化的技术。训练时用 mini-batch 的均值/方差，推理时用累积的移动平均。作用：加速训练（可用更大学习率）、降低对初始化的敏感性、正则化效果。缺点是 batch size 小时效果不稳定。
</GlossaryItem>

<GlossaryItem term="Adam 优化器">
结合 Momentum（一阶矩）和 RMSprop（二阶矩）的自适应优化器。维护梯度的动量和梯度平方的移动平均，做偏差校正后更新参数。兼具加速和稳定性，是最常用的默认优化器。
</GlossaryItem>

<GlossaryItem term="L2 正则化">
在损失函数中加入 lambda*||W||^2 惩罚项，限制权重过大。使模型更平滑，防止过拟合。也叫权重衰减（weight decay）。lambda 越大正则化越强。
</GlossaryItem>

<GlossaryItem term="数据增强">
通过翻转、裁剪、旋转等变换扩充训练数据的正则化手段。等效于增加数据量，提升模型泛化能力。图像最常用（水平翻转、随机裁剪、颜色抖动），文本和音频也有各自的增强方式。
</GlossaryItem>

</Glossary>

### 问题 1

什么是过拟合？如何判断模型是否过拟合？有哪些常见正则化方法？

<Answer>

过拟合是模型在训练集上表现很好但在验证集/测试集上表现差的现象——模型「记住」了训练数据的细节和噪声而非学到通用规律。判断方法：监控训练损失和验证损失——如果训练损失持续下降但验证损失开始上升，说明过拟合开始发生；如果训练准确率远高于验证准确率也是信号。常见正则化方法：①L2 正则化（权重衰减）——在损失函数中加入 lambda*||W||^2 惩罚项，限制权重过大。②Dropout——训练时随机将一部分神经元输出置为 0，迫使网络不依赖任何单个神经元。③Batch Normalization——对每层输入做标准化，附带正则化效果。④Early Stopping——验证集损失上升时停止训练。⑤数据增强——通过翻转/裁剪/旋转等变换扩充训练数据。⑥L1 正则化——产生稀疏权重，有特征选择效果。

</Answer>

### 问题 2

Dropout 的工作原理是什么？训练和推理时有什么区别？为什么能防止过拟合？

<Answer>

Dropout 的工作原理：训练时在每个 mini-batch 的前向传播中，以概率 p 随机将部分神经元的输出置为 0，被丢弃的神经元不参与计算和梯度更新。训练和推理的区别：①训练时——以概率 p 随机丢弃神经元，每次使用不同的子网络。②推理时——不丢弃任何神经元，使用完整网络，但需将权重乘以 (1-p) 缩放（或训练时做 inverted dropout），保证训练和推理时每层期望输出一致。为什么能防止过拟合：①打破共适应——没有 Dropout 时神经元可能形成固定的协作关系，Dropout 迫使每个神经元独立工作，增强鲁棒性。②模型集成效应——每次 Dropout 采样不同的子网络，相当于训练了大量子网络的集成，推理时用完整网络相当于近似集成。③稀疏激活——网络不会过度依赖少数「明星神经元」。Dropout 通常用在全连接层。

</Answer>

### 问题 3

SGD、Momentum、RMSprop、Adam 四种优化器的原理和特点分别是什么？

<Answer>

四种优化器：①SGD——W = W - lr * dW，最基础，每次用 mini-batch 梯度更新。简单稳定但学习率固定、容易在鞍点震荡。②Momentum——v = beta*v + dW，W = W - lr*v（beta 通常 0.9）。引入动量累积历史梯度方向，在一致方向上加速，在震荡方向上抵消，比 SGD 收敛更快。③RMSprop——s = beta*s + (1-beta)*dW^2，W = W - lr*dW/(sqrt(s)+epsilon)。维护梯度平方的移动平均，对梯度大的参数减小学习率，梯度小的参数增大学习率，适合非平稳目标。④Adam——结合 Momentum 和 RMSprop，同时维护梯度的一阶矩 m（动量）和二阶矩 v（自适应学习率），做偏差校正后更新。兼具动量的加速和自适应学习率的稳定性，是最常用的默认优化器。实践建议：先用 Adam 快速实验，如果需要极致性能再尝试 SGD+Momentum 配合学习率调度。

</Answer>

### 问题 4

Batch Normalization 的工作原理是什么？它有哪些作用？训练和推理时有什么区别？

<Answer>

Batch Normalization 的工作原理：在每个 mini-batch 内，对每一层的输入做标准化——计算 batch 内的均值 mu 和方差 sigma^2，然后 z_norm = (z - mu) / sqrt(sigma^2 + epsilon)，最后通过可学习的缩放和平移参数恢复表达能力：z_out = gamma * z_norm + beta。作用：①加速训练——标准化后激活值在非饱和区，梯度能有效传播，允许使用更大学习率。②降低对初始化的敏感性。③正则化效果——batch 内统计量引入噪声，有类似 Dropout 的作用。④缓解内部协变量偏移。训练和推理的区别：①训练时——使用当前 mini-batch 的均值和方差做标准化。②推理时——使用训练过程中累积的移动平均均值和方差，因为推理时可能只有单个样本。这也是 BatchNorm 在 batch size 很小时效果不好的原因。后续的 Layer Norm（对单个样本所有维度做标准化）不依赖 batch size，在 Transformer 中广泛使用。

</Answer>
