## 这本书讲什么

《图解机器学习》是一本面向工程师和学生的 ML 入门教材。它以视觉优先的方式，从机器学习的基础概念出发，逐步展开线性模型、分类、决策树、神经网络、支持向量机、无监督学习与模型评估的完整知识图谱。每一章都用图解 + 表格 + 对比的方式建立直觉，而非堆砌公式。

机器学习的知识体系可以划分为四个层次：

- **基础层**：ML 基础概念（三大范式、训练流程）——这是理解所有后续内容的前提
- **监督模型层**：线性回归、逻辑回归分类、决策树与集成学习——这是经典监督学习的主干
- **进阶模型层**：神经网络基础、支持向量机、无监督学习与聚类——这是向深度学习和无标注场景延伸的关键
- **实践与整合层**：模型评估与调优、全书复习与知识整合——这是从理论走向工程实践的桥梁

## 监督、无监督、强化的边界

机器学习按学习信号的类型分为三大范式：

```text
机器学习 (ML)
  ├── 监督学习 (Supervised)     —— 有标签 (X, y)
  ├── 无监督学习 (Unsupervised)  —— 无标签 X，找结构
  └── 强化学习 (Reinforcement)   —— 有奖励信号，学策略
```

| 范式 | 数据形式 | 学习目标 | 代表算法 | 本书章节 |
|------|---------|---------|---------|---------|
| 监督学习 | `(X, y)` | 学习 X → y 映射 | 线性回归 / 逻辑回归 / SVM / 决策树 | ch1-ch6 |
| 无监督学习 | `X` | 发现数据内在结构 | K-Means / PCA / DBSCAN | ch7 |
| 强化学习 | `(s, a, r)` | 学习最优策略 | Q-learning / 策略梯度 | （本书不深入） |

<Callout type="info">

**关键洞察**：本书聚焦监督学习和无监督学习两大范式。监督学习是 ML 的主干（ch1-ch6），无监督学习是重要补充（ch7）。强化学习属于另一条技术路线，本书仅在 ch0 学习地图中提及其定位，不深入展开。理解三大范式的边界，才能在遇到新问题时正确选择技术路线。

</Callout>

| 概念 | 一句话解释 | 详细章节 |

<Glossary>

<GlossaryItem term="机器学习（ML）">
让计算机从数据中自动学习规律的学科。Tom Mitchell 的定义：如果程序在任务 T 上的性能 P 随经验 E 的增加而提高，则称该程序从经验 E 中学习。分为监督学习、无监督学习和强化学习三大范式。
</GlossaryItem>

<GlossaryItem term="监督学习">
使用有标签数据 `(X, y)` 学习输入到输出映射的机器学习范式。分为回归（连续标签）和分类（离散标签），代表算法包括线性回归、逻辑回归、决策树、SVM 和神经网络。
</GlossaryItem>

<GlossaryItem term="无监督学习">
在无标签数据中发现内在结构的机器学习范式。主要任务包括聚类（K-Means/DBSCAN，将数据分组）和降维（PCA，压缩高维数据）。
</GlossaryItem>

<GlossaryItem term="特征工程">
从原始数据中提取、选择和变换特征的过程，是传统机器学习性能的关键。包括特征提取、特征选择、编码（One-Hot/Label）和归一化（Min-Max/Z-Score）。
</GlossaryItem>

<GlossaryItem term="泛化能力">
模型在未见过的数据上的表现能力，是机器学习的核心追求。过拟合的模型泛化能力差（记住训练数据而非学到通用规律），欠拟合的模型连训练数据都无法很好拟合。
</GlossaryItem>

<GlossaryItem term="模型评估">
用量化指标衡量模型性能的过程。分类任务用准确率/精确率/召回率/F1，回归任务用 MSE/MAE/R²。评估需在独立测试集上进行，避免数据泄露。
</GlossaryItem>

</Glossary>

### 问题 1

《图解机器学习》的知识体系如何分层？每层包含哪些章节和核心内容？

<Answer>

知识体系分为四层：①基础层（ch1 机器学习基础概念）——涵盖三大范式（监督/无监督/强化）、训练流程（数据收集→特征工程→训练→评估→部署）、数据划分（训练/验证/测试集），是理解所有后续内容的前提；②监督模型层（ch2 线性模型与回归 + ch3 分类与逻辑回归 + ch4 决策树与集成学习）——涵盖线性回归/梯度下降/正则化、逻辑回归/sigmoid/交叉熵、信息增益/剪枝/随机森林/Boosting，是经典监督学习的主干；③进阶模型层（ch5 神经网络基础 + ch6 支持向量机 + ch7 无监督学习与聚类）——涵盖感知机/激活函数/反向传播、最大间隔/核函数/软间隔、K-Means/层次聚类/PCA，是向深度学习和无标注场景延伸的关键；④实践与整合层（ch8 模型评估与调优 + ch9 全书复习与知识整合）——涵盖指标体系/交叉验证/超参搜索和端到端知识整合，是从理论走向工程实践的桥梁。

</Answer>

### 问题 2

监督学习、无监督学习、强化学习三大范式的数据形式和学习目标有什么区别？

<Answer>

三大范式的核心区别在于学习信号的类型：①监督学习——使用有标签数据 `(X, y)`，学习从输入 X 到输出 y 的映射关系。分为回归（连续标签，如房价预测）和分类（离散标签，如垃圾邮件检测），代表算法有线性回归、逻辑回归、SVM、决策树、神经网络。②无监督学习——使用无标签数据 `X`，目标是发现数据的内在结构。主要任务包括聚类（K-Means/DBSCAN，将相似数据分组）和降维（PCA，压缩高维数据），示例为用户群体分群。③强化学习——数据形式为 `(s, a, r)`（状态-动作-奖励），没有标签但有奖励信号，通过试错学习最优策略。目标是最大化长期累积回报，代表算法有 Q-learning、策略梯度，示例为 AlphaGo 和机器人控制。核心区别：监督学习有标准答案、无监督学习无答案找结构、强化学习无答案但有反馈信号。

</Answer>

### 问题 3

十章的学习路径和章节依赖关系是怎样的？

<Answer>

学习路径：ch0 学习地图 → ch1 ML 基础 → ch2 线性模型 → ch3 分类 → ch4 决策树 → ch5 神经网络 → ch6 SVM → ch7 无监督 → ch8 模型评估 → ch9 全书复习。依赖关系：ch1 无前置依赖（建立 ML 全景认知）；ch2 依赖 ch1（需理解监督学习和训练流程）；ch3 依赖 ch2（逻辑回归是线性模型的扩展，需先理解线性回归和梯度下降）；ch4 依赖 ch1（决策树是独立的监督学习算法，只需 ML 基础）；ch5 依赖 ch2（神经网络的训练用梯度下降和反向传播，需先理解线性模型和优化）；ch6 依赖 ch3（SVM 是分类算法，需理解分类问题和决策边界）；ch7 依赖 ch1（无监督学习是独立范式，只需 ML 基础）；ch8 依赖 ch1-ch7（评估需理解各类模型）；ch9 依赖全部（端到端整合）。

</Answer>

### 问题 4

本书为什么聚焦监督学习和无监督学习，而不深入强化学习？

<Answer>

本书定位是机器学习入门教材，聚焦监督学习和无监督学习两大范式有三个原因：①覆盖面——监督学习和无监督学习是 ML 最核心、应用最广的两大范式。监督学习涵盖回归和分类两大任务，是绝大多数工业 ML 应用的基础（从房价预测到垃圾邮件检测）；无监督学习涵盖聚类和降维，是数据探索和特征工程的重要工具。②知识递进——从线性模型到神经网络，从决策树到 SVM，再到 K-Means 和 PCA，这些内容构成了一条从基础到进阶的完整知识链路，能帮助读者建立系统的 ML 认知。③边界清晰——强化学习属于另一条技术路线（序列决策+试错学习），其数学基础（MDP/贝尔曼方程）和学习范式与监督/无监督学习差异较大，深入展开会超出入门教材的范畴。本书在 ch0 学习地图中明确提及强化学习的定位，帮助读者建立完整的 ML 全景认知，但不深入展开，避免分散焦点。

</Answer>
