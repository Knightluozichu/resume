## 线性回归模型

线性回归是最基础的监督学习算法，用线性关系描述特征与目标之间的关系。

### 模型表示

对于 n 个特征 `x_1, x_2, ..., x_n`，线性回归模型为：

```text
y_hat = w_1*x_1 + w_2*x_2 + ... + w_n*x_n + b
```

用向量表示：`y_hat = w^T * x + b`，其中 w 是权重向量，b 是偏置。

| 符号 | 含义 | 说明 |
|------|------|------|
| `x` | 输入特征 | n 维向量 |
| `w` | 权重 | 每个特征的重要性，n 维向量 |
| `b` | 偏置 | 整体偏移量，标量 |
| `y_hat` | 预测值 | 模型输出 |

### 损失函数：均方误差

均方误差（MSE）衡量预测值与真实值之间的平均差距：

```text
MSE = (1/m) * sum( (y_hat_i - y_i)^2, i=1..m )
```

其中 m 是样本数。MSE 越小，模型拟合越好。训练的目标就是找到使 MSE 最小的 w 和 b。

## 梯度下降

梯度下降是最常用的优化算法，通过迭代更新参数来最小化损失函数。

### 核心思想

```text
repeat until convergence:
    w = w - alpha * dL/dw
    b = b - alpha * dL/db
```

其中 `alpha` 是学习率，`dL/dw` 和 `dL/db` 是损失函数对参数的偏导数（梯度）。

### 直觉理解

想象你站在山坡上，要走到谷底（损失最小）。梯度告诉你当前最陡的上坡方向，所以你沿负梯度方向走一步。重复这个过程直到到达谷底。

### 学习率的影响

| 学习率 | 表现 | 结果 |
|-------|------|------|
| 太小 | 每步走得太短 | 收敛极慢 |
| 适中 | 稳定下降 | 正常收敛 |
| 太大 | 步长过大，跨越谷底 | 震荡或发散 |

<Callout type="warning">

**学习率选择**：学习率是梯度下降最重要的超参数。太大导致损失函数震荡甚至发散（无法收敛），太小导致训练极其缓慢。实践中通常从 0.01 或 0.001 开始尝试，用验证集观察损失曲线调整。也可使用学习率衰减（先大后小）或自适应学习率（Adam/RMSProp）。

</Callout>

### 梯度下降变体

| 变体 | 每次更新用的数据 | 特点 |
|------|----------------|------|
| 批量梯度下降 (BGD) | 全部训练数据 | 稳定但慢 |
| 随机梯度下降 (SGD) | 单个样本 | 快但噪声大 |
| 小批量梯度下降 (Mini-batch) | 一小批数据（如 32/64） | 平衡速度与稳定性 |

## 正则化

当模型过于复杂时，容易过拟合（训练误差低但测试误差高）。正则化通过在损失函数中加入惩罚项，抑制权重过大。

### L1 正则化（Lasso）

```text
Loss = MSE + lambda * sum(|w_j|)
```

- 惩罚权重的绝对值
- 倾向于产生**稀疏权重**（部分 w 变为 0）
- 可用于特征选择（被置零的特征等于被剔除）

### L2 正则化（Ridge）

```text
Loss = MSE + lambda * sum(w_j^2)
```

- 惩罚权重的平方
- 倾向于产生**平滑权重**（所有 w 都较小但不为 0）
- 更常用，数值稳定性更好

### L1 vs L2 对比

| 对比维度 | L1 (Lasso) | L2 (Ridge) |
|---------|------------|------------|
| 惩罚项 | `sum(\|w\|)` | `sum(w^2)` |
| 权重效果 | 稀疏（部分为 0） | 平滑（都较小） |
| 特征选择 | 是 | 否 |
| 计算效率 | 较低（非光滑） | 较高（光滑可导） |
| 适用场景 | 特征选择/高维稀疏 | 一般回归/防过拟合 |

`lambda` 是正则化系数，控制惩罚强度：`lambda` 越大惩罚越强、模型越简单。

## 多项式回归

线性回归只能拟合线性关系。当数据呈非线性时，可通过添加多项式特征扩展为多项式回归：

```text
y_hat = w_1*x + w_2*x^2 + w_3*x^3 + b
```

多项式回归本质上仍是线性回归（对权重 w 是线性的），只是对输入 x 做了非线性变换。多项式次数过高会导致过拟合。

<Callout type="tip">

**正则化系数选择**：`lambda` 是关键超参数。`lambda = 0` 时无正则化（可能过拟合），`lambda` 过大时模型过于简单（可能欠拟合）。通常用交叉验证在 `[0.001, 0.01, 0.1, 1, 10, 100]` 等量级中搜索最优值。

</Callout>

</GlossaryItem>

</GlossaryItem>

<GlossaryItem term="L1 正则化（Lasso）">
在损失函数中加入 `lambda * sum(|w|)` 惩罚项，倾向于产生稀疏权重（部分 w 为 0），可用于特征选择。适合高维稀疏数据场景。
</GlossaryItem>

<GlossaryItem term="L2 正则化（Ridge）">

</GlossaryItem>

<GlossaryItem term="多项式回归">
通过添加多项式特征（x^2, x^3...）将线性回归扩展为非线性回归的方法。本质仍是对权重线性，但对输入做非线性变换。次数过高易过拟合。
</GlossaryItem>

### 问题 1

线性回归的模型表示和损失函数是什么？请写出公式并解释每个符号的含义。

<Answer>

线性回归模型表示：`y_hat = w_1*x_1 + w_2*x_2 + ... + w_n*x_n + b`，用向量表示为 `y_hat = w^T * x + b`。其中 x 是输入特征向量（n 维），w 是权重向量（n 维，表示每个特征的重要性），b 是偏置（标量，整体偏移量），y_hat 是模型的预测值。损失函数使用均方误差（MSE）：`MSE = (1/m) * sum((y_hat_i - y_i)^2, i=1..m)`，其中 m 是样本数，y_hat_i 是第 i 个样本的预测值，y_i 是第 i 个样本的真实值。MSE 衡量预测值与真实值之间的平均差距，对大误差更敏感（平方放大）。训练的目标就是找到使 MSE 最小的 w 和 b。MSE 对所有误差平等加权且处处可导，适合用梯度下降优化。

</Answer>

### 问题 2

梯度下降的原理是什么？学习率大小对训练有什么影响？

<Answer>

梯度下降的核心思想是沿损失函数的负梯度方向迭代更新参数来最小化损失。更新规则：`w = w - alpha * dL/dw`，`b = b - alpha * dL/db`，其中 alpha 是学习率，dL/dw 和 dL/db 是损失函数对参数的偏导数（梯度）。直觉理解：想象站在山坡上要走到谷底（损失最小），梯度告诉你当前最陡的上坡方向，所以沿负梯度方向走一步，重复直到到达谷底。学习率的影响：①太小——每步走得太短，收敛极慢，需要大量迭代才能到达最小值；②适中——稳定下降，正常收敛到最优解；③太大——步长过大，可能跨越谷底到对面山坡，导致损失函数震荡甚至发散（无法收敛）。实践中通常从 0.01 或 0.001 开始尝试，用验证集观察损失曲线调整。也可使用学习率衰减（先大后小）或自适应学习率优化器（Adam/RMSProp）。梯度下降的变体：BGD 用全部数据（稳定但慢）、SGD 用单个样本（快但噪声大）、Mini-batch 用一小批数据（平衡速度与稳定性，最常用）。

</Answer>

### 问题 3

L1 正则化和 L2 正则化的原理和区别是什么？各适用于什么场景？

<Answer>

正则化通过在损失函数中加入惩罚项来抑制权重过大，防止过拟合。L1 正则化（Lasso）：`Loss = MSE + lambda * sum(|w|)`，惩罚权重的绝对值。特点是倾向于产生稀疏权重——部分 w 会变为 0，相当于自动剔除不重要的特征，因此可用于特征选择。适合高维稀疏数据场景（特征数远大于样本数），或希望模型简洁可解释的场景。L2 正则化（Ridge）：`Loss = MSE + lambda * sum(w^2)`，惩罚权重的平方。特点是倾向于产生平滑权重——所有 w 都较小但一般不为 0，不会自动剔除特征。数值稳定性更好（处处可导），计算效率更高。适合一般回归任务和防止过拟合，是最常用的正则化方式。两者区别：①权重效果——L1 稀疏（部分为 0），L2 平滑（都较小）；②特征选择——L1 是，L2 否；③计算效率——L1 较低（绝对值在 0 处非光滑），L2 较高（处处可导）；④适用场景——L1 适合特征选择/高维稀疏，L2 适合一般回归/防过拟合。lambda 是正则化系数，控制惩罚强度：lambda=0 时无正则化，lambda 过大时模型过于简单（欠拟合）。通常用交叉验证搜索最优值。

</Answer>

### 问题 4

什么是多项式回归？它与线性回归的关系是什么？使用时需要注意什么？

<Answer>

多项式回归是通过添加多项式特征（x^2, x^3, ...）将线性回归扩展为非线性回归的方法。模型表示：`y_hat = w_1*x + w_2*x^2 + w_3*x^3 + b`。与线性回归的关系：多项式回归本质上仍是线性回归——它对权重 w 是线性的，只是对输入 x 做了非线性变换。可以把 x^2、x^3 视为新的特征 x_2 = x^2、x_3 = x^3，这样问题就回到了标准线性回归 `y_hat = w_1*x_1 + w_2*x_2 + w_3*x_3 + b`。因此多项式回归可以复用线性回归的全部训练方法（最小二乘、梯度下降、正则化）。使用时的注意事项：①次数选择——多项式次数过低无法捕捉非线性关系（欠拟合），次数过高会记住训练数据中的噪声（过拟合），需用验证集或交叉验证选择合适次数；②特征缩放——x^2、x^3 等高次项的数值范围可能与 x 差异很大，必须做特征缩放（归一化/标准化），否则梯度下降收敛困难；③正则化——高次多项式容易过拟合，通常需要配合 L1/L2 正则化使用；④外推风险——多项式回归在训练数据范围外的外推能力很差（高次项会剧烈变化），不适合做远距离预测。

</Answer>
