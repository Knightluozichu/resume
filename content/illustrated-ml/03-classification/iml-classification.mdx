## 分类任务

分类是监督学习的两大任务之一，目标是预测样本属于哪个离散类别。

| 类型 | 类别数 | 示例 |
|------|-------|------|
| 二分类 | 2 个 | 垃圾邮件检测（垃圾/正常） |
| 多分类 | 3+ 个 | 手写数字识别（0-9） |
| 多标签 | 每样本多标签 | 文章标注（科技/财经/娱乐） |

## 逻辑回归

逻辑回归虽然名字带「回归」，但实际上是**分类算法**。它用线性模型计算得分，再通过 sigmoid 函数将得分映射为概率。

### 模型表示

```text
z = w^T * x + b          # 线性得分
p = sigmoid(z) = 1 / (1 + e^(-z))   # 映射为概率
```

- `z` 是线性得分（可正可负，无界）
- `p` 是预测为正类的概率，范围 `(0, 1)`
- 阈值通常取 0.5：`p >= 0.5` 判为正类，否则判为负类

### Sigmoid 函数

```text
sigmoid(z) = 1 / (1 + e^(-z))
```

| z 值 | sigmoid(z) | 含义 |
|------|-----------|------|
| 很大正数 | 接近 1 | 强烈预测为正类 |
| 0 | 0.5 | 边界，不确定 |
| 很大负数 | 接近 0 | 强烈预测为负类 |

Sigmoid 的 S 形曲线将任意实数压缩到 `(0, 1)` 区间，天然适合表示概率。

## 决策边界

决策边界是模型区分不同类别的分界线（面）。

- **线性决策边界**：`w^T * x + b = 0`，在特征空间中是一条直线（二维）或超平面（高维）
- **非线性决策边界**：通过多项式特征或核函数可以实现非线性边界

阈值的选择影响决策边界的位置：

| 阈值 | 效果 | 适用场景 |
|------|------|---------|
| 0.5（默认） | 平衡精确率与召回率 | 一般分类 |
| 高阈值（如 0.8） | 更保守，提高精确率 | 垃圾邮件（不错杀） |
| 低阈值（如 0.3） | 更激进，提高召回率 | 疾病筛查（不漏诊） |

<Callout type="info">

**逻辑回归 vs 线性回归**：线性回归直接输出连续值（如房价），不适合分类——因为线性输出无界，不能解释为概率。逻辑回归在线性输出的基础上加了 sigmoid，将输出压缩到 `(0, 1)` 表示概率，再用阈值做分类决策。这是从回归到分类的关键一步。

</Callout>

## 交叉熵损失

分类任务不用 MSE，而用**交叉熵损失**（Cross-Entropy Loss），因为它更适合概率预测。

### 二分类交叉熵

```text
Loss = -[ y * log(p) + (1-y) * log(1-p) ]
```

- 当真实标签 `y = 1` 时，损失为 `-log(p)`，p 越接近 1 损失越小
- 当真实标签 `y = 0` 时，损失为 `-log(1-p)`，p 越接近 0 损失越小
- 模型预测越准确，损失越接近 0；预测越离谱，损失越大（log 惩罚）

### 多分类交叉熵

```text
Loss = -sum( y_i * log(p_i), i=1..C )
```

其中 C 是类别数，`y_i` 是 one-hot 编码的真实标签，`p_i` 是 softmax 输出的预测概率。

### Softmax 函数

多分类时用 softmax 将多个得分转化为概率分布：

```text
p_i = e^(z_i) / sum(e^(z_j), j=1..C)
```

Softmax 的特点：所有类别概率之和为 1，概率最大的类别即为预测类别。

<Callout type="tip">

**为什么分类用交叉熵而不用 MSE**：①凸优化——交叉熵 + sigmoid 的组合是凸函数，保证梯度下降找到全局最优；MSE + sigmoid 是非凸的，可能陷入局部最优。②梯度特性——当预测严重错误时（如 y=1 但 p 接近 0），交叉熵的梯度更大，收敛更快；MSE 的梯度在 sigmoid 饱和区趋近 0，导致学习停滞。③概率语义——交叉熵直接衡量预测概率分布与真实分布的差异，语义更清晰。

</Callout>

## 多分类策略

| 策略 | 原理 | 适用场景 |
|------|------|---------|
| Softmax 回归 | 直接多分类，输出 C 个概率 | 类别互斥 |
| 一对多 (OvR) | 训练 C 个二分类器，取最高分 | 简单高效 |
| 一对一 (OvO) | 训练 C(C-1)/2 个二分类器，投票 | SVM 常用 |

<Glossary>

<GlossaryItem term="逻辑回归">
用于分类的线性模型，用 sigmoid 函数将线性得分映射为概率。虽然名为「回归」，实际是分类算法。二分类用 sigmoid，多分类用 softmax。决策边界是线性的（可用多项式特征扩展为非线性）。
</GlossaryItem>

<GlossaryItem term="Sigmoid 函数">
`sigmoid(z) = 1 / (1 + e^(-z))`，将任意实数压缩到 (0, 1) 区间的 S 形函数。在逻辑回归中将线性得分映射为概率，在神经网络中用作激活函数。
</GlossaryItem>

<GlossaryItem term="决策边界">
模型区分不同类别的分界面。逻辑回归的决策边界是 `w^T * x + b = 0` 对应的超平面。阈值调整会移动决策边界，影响精确率与召回率的权衡。
</GlossaryItem>

<GlossaryItem term="交叉熵损失">
分类任务的标准损失函数。二分类：`-[y*log(p) + (1-y)*log(1-p)]`；多分类：`-sum(y_i*log(p_i))`。相比 MSE，交叉熵 + sigmoid 是凸函数，且预测错误时梯度更大、收敛更快。
</GlossaryItem>

<GlossaryItem term="Softmax 函数">
`p_i = e^(z_i) / sum(e^(z_j))`，将多个得分转化为概率分布（所有概率之和为 1）。用于多分类逻辑回归的输出层，将原始得分转为各类别的预测概率。
</GlossaryItem>

<GlossaryItem term="一对多（OvR）">
将多分类问题转化为多个二分类问题的策略：为每个类别训练一个「该类 vs 其他所有类」的二分类器，预测时取置信度最高的类别。简单高效，适用于大多数分类算法。
</GlossaryItem>

</Glossary>

### 问题 1

逻辑回归的模型表示是什么？sigmoid 函数有什么作用？为什么逻辑回归是分类算法而不是回归算法？

<Answer>

逻辑回归模型分两步：①线性得分 `z = w^T * x + b`，与线性回归完全相同；②概率映射 `p = sigmoid(z) = 1 / (1 + e^(-z))`，将线性得分压缩到 (0, 1) 区间表示概率。预测时取阈值（通常 0.5）：p >= 0.5 判为正类，否则判为负类。Sigmoid 函数的作用是将无界的线性得分映射为有界的概率值：z 很大正数时 p 接近 1（强烈预测正类），z = 0 时 p = 0.5（边界不确定），z 很大负数时 p 接近 0（强烈预测负类）。Sigmoid 的 S 形曲线天然适合表示概率。逻辑回归是分类算法而非回归算法的原因：①输出语义——逻辑回归输出的是概率（0 到 1 之间），再用阈值做离散分类决策（正类/负类），而非直接预测连续数值；②标签类型——逻辑 regression 的标签是离散类别（0 或 1），而回归的标签是连续数值；③损失函数——逻辑回归用交叉熵损失而非 MSE。名字中的「回归」来源于它内部使用了线性回归的得分计算，但整体功能是分类。

</Answer>

### 问题 2

什么是决策边界？阈值的选择如何影响分类结果？

<Answer>

决策边界是模型区分不同类别的分界线（或面）。逻辑回归的决策边界是 `w^T * x + b = 0` 对应的超平面——在二维特征空间中是一条直线，在高维空间中是超平面。位于边界一侧的样本被预测为正类，另一侧被预测为负类。阈值的选择直接影响决策边界的位置和分类结果：①默认阈值 0.5——平衡精确率与召回率，适用于一般分类场景；②高阈值（如 0.8）——更保守地预测正类，只有当概率很高时才判为正类，提高精确率（预测为正的确实大多是正类），但可能降低召回率（漏掉一些真实正例）。适用于「不错杀」场景，如垃圾邮件检测（宁可放过一些垃圾邮件，也不能误删正常邮件）；③低阈值（如 0.3）——更激进地预测正类，只要概率稍高就判为正类，提高召回率（尽量捕获所有正例），但可能降低精确率（预测为正的中有更多假阳性）。适用于「不漏判」场景，如疾病筛查（宁可误报，也不能漏诊）。阈值选择是精确率-召回率权衡的直接体现，需根据业务场景的代价不对称性来决定。

</Answer>

### 问题 3

交叉熵损失的公式是什么？为什么分类任务用交叉熵而不用 MSE？

<Answer>

交叉熵损失公式：二分类 `Loss = -[y * log(p) + (1-y) * log(1-p)]`，其中 y 是真实标签（0 或 1），p 是模型预测为正类的概率。当 y=1 时损失为 -log(p)，p 越接近 1 损失越小；当 y=0 时损失为 -log(1-p)，p 越接近 0 损失越小。多分类 `Loss = -sum(y_i * log(p_i), i=1..C)`，其中 y_i 是 one-hot 编码的真实标签，p_i 是 softmax 输出的预测概率。分类任务用交叉熵而不用 MSE 的三个原因：①凸优化——交叉熵 + sigmoid（或 softmax）的组合是凸函数，梯度下降保证收敛到全局最优解；而 MSE + sigmoid 是非凸函数，可能陷入局部最优。②梯度特性——当预测严重错误时（如 y=1 但 p 接近 0），交叉熵的梯度仍然很大，驱动参数快速更新、收敛快；而 MSE + sigmoid 在 sigmoid 饱和区（p 接近 0 或 1）梯度趋近于 0，导致学习几乎停滞（梯度消失）。③概率语义——交叉熵直接衡量预测概率分布与真实分布之间的差异（信息论中的 KL 散度），语义更清晰，且当预测概率与真实标签一致时损失趋近 0，不一致时损失趋向无穷大（log 惩罚），比 MSE 更适合概率预测。

</Answer>

### 问题 4

多分类有哪些策略？Softmax 回归和一对多（OvR）各有什么特点？

<Answer>

多分类的三种主要策略：①Softmax 回归（多项逻辑回归）——直接进行多分类，输出层用 softmax 函数将 C 个得分转化为 C 个概率（概率之和为 1），用多分类交叉熵损失训练。特点是类别互斥（每个样本只属于一个类别），模型同时考虑所有类别的关系，概率输出可直接比较。适用于手写数字识别（0-9 互斥）、图像分类等。②一对多（One-vs-Rest, OvR）——将 C 类问题转化为 C 个二分类问题：为每个类别训练一个「该类 vs 其他所有类」的二分类器，预测时取置信度最高的分类器的类别。特点是简单高效，可复用任何二分类算法（如逻辑回归、SVM），但每个分类器面临类别不平衡问题（正类少、负类多），且各分类器独立训练未考虑类别间关系。③一对一（One-vs-One, OvO）——训练 C(C-1)/2 个二分类器（每两个类别一个），预测时投票决定最终类别。特点是每个分类器只用到两个类别的数据，训练更快，但分类器数量随类别数平方增长。SVM 多分类常用此策略。Softmax 回归 vs OvR：Softmax 是端到端多分类，概率校准好；OvR 是组合多个二分类器，灵活但概率校准较差。

</Answer>
