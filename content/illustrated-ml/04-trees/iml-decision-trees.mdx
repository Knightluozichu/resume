## 决策树结构

决策树是一种基于树形结构进行决策的算法，通过递归划分特征空间来分类或回归。

```text
          [根节点] 年龄?
         /          \
      <30            >=30
      /                \
 [内部节点] 收入?     [叶节点] 不买
   /        \
  高         低
  /          \
[叶节点]    [叶节点]
不买         买
```

| 组成 | 作用 | 示例 |
|------|------|------|
| 根节点 | 第一个划分条件 | 年龄? |
| 内部节点 | 后续划分条件 | 收入? |
| 叶节点 | 最终决策 | 买/不买 |
| 分支 | 划分结果 | `<30` / `>=30` |

决策树的优点：可解释性强（白盒模型）、可处理类别和数值特征、不需要特征缩放。

## 特征划分准则

决策树在每个节点选择「最佳特征」进行划分，选择依据是让划分后子节点的「纯度」最高（同一类样本尽量在一起）。

### 信息增益（ID3 算法）

信息增益 = 划分前的信息熵 - 划分后的信息熵（加权和）。

```text
信息熵 H(D) = -sum( p_k * log2(p_k) )
信息增益 = H(D) - sum( |D_v|/|D| * H(D_v) )
```

信息熵衡量不确定性：纯度越高（全是一类），熵越小。选择使信息增益最大的特征进行划分。

### 信息增益比（C4.5 算法）

信息增益偏向取值多的特征。信息增益比用固有值做修正：

```text
增益比 = 信息增益 / 固有值
固有值 = -sum( |D_v|/|D| * log2(|D_v|/|D|) )
```

### 基尼指数（CART 算法）

```text
Gini(D) = 1 - sum( p_k^2 )
```

基尼指数衡量从数据集中随机取两个样本类别不同的概率。纯度越高，Gini 越小。CART 算法用基尼指数，计算比信息熵更高效（不需要 log）。

<Callout type="info">

**三种准则对比**：信息增益（ID3）最直观但偏向多值特征；信息增益比（C4.5）修正了偏向但可能偏好取值少的特征；基尼指数（CART）计算最高效且效果与熵接近，是工程实践最常用的选择。三者大多数情况下选出的划分特征一致。

</Callout>

## 剪枝

决策树容易过拟合——如果不限制，树会一直生长到每个叶节点只有一个样本。剪枝是防止过拟合的关键手段。

### 预剪枝

在树生长过程中提前停止：

- 限制最大深度（`max_depth`）
- 限制叶节点最小样本数（`min_samples_leaf`）
- 限制信息增益阈值（增益太小不再划分）

**优点**：计算效率高。**缺点**：可能欠拟合（目光短浅，当前增益小不代表后续划分不好）。

### 后剪枝

先让树完全生长，再自底向上剪掉提升不大的子树：

- 代价复杂度剪枝：比较剪枝前后在验证集上的性能
- 最小误差剪枝：用验证集评估每个子树

**优点**：比预剪枝更准确。**缺点**：计算开销大（需先建完整树）。

## 集成学习

集成学习通过组合多个「弱学习器」构建「强学习器」，核心思想是「三个臭皮匠顶个诸葛亮」。

### Bagging：随机森林

Bagging（Bootstrap Aggregating）通过对数据做有放回采样训练多个模型，再投票/取平均。

**随机森林**是 Bagging 的代表：

- 每棵树用有放回采样的一份数据训练
- 每次划分时只考虑随机选取的部分特征
- 分类：多数投票；回归：取平均

| 特点 | 说明 |
|------|------|
| 降低方差 | 多棵树投票抵消个体波动 |
| 不易过拟合 | 树之间相互独立 |
| 可评估特征重要性 | 统计特征在划分中的贡献 |
| 适合并行 | 树之间无依赖 |

### Boosting：AdaBoost / GBDT

Boosting 通过串行训练多个弱学习器，每个新模型关注前一个模型分错的样本。

**AdaBoost**：

1. 训练第一个弱学习器
2. 提高分错样本的权重
3. 训练下一个弱学习器（关注高权重样本）
4. 加权组合所有弱学习器

**GBDT（梯度提升决策树）**：

1. 初始化预测值（如均值）
2. 计算残差 = 真实值 - 当前预测值
3. 训练新树拟合残差
4. 更新预测值 = 旧预测值 + 学习率 * 新树预测
5. 重复步骤 2-4

<Callout type="tip">

**Bagging vs Boosting**：Bagging（随机森林）是并行集成，树之间独立，降低方差，适合高方差模型（如深决策树）。Boosting（GBDT）是串行集成，树之间有依赖，降低偏差，适合高偏差模型（如浅决策树）。实践中 GBDT/XGBoost/LightGBM 通常比随机森林精度更高，但更容易过拟合，需更仔细调参。

</Callout>

<Glossary>

<GlossaryItem term="决策树">
基于树形结构进行决策的算法，通过递归划分特征空间来分类或回归。由根节点、内部节点、叶节点组成。优点是可解释性强（白盒模型）、可处理类别和数值特征、不需要特征缩放。代表算法：ID3/C4.5/CART。
</GlossaryItem>

<GlossaryItem term="信息增益">
划分前后信息熵的减少量，衡量特征划分带来的纯度提升。ID3 算法使用信息增益选择划分特征，但偏向取值多的特征。
</GlossaryItem>

<GlossaryItem term="基尼指数">
`Gini(D) = 1 - sum(p_k^2)`，衡量从数据集中随机取两个样本类别不同的概率。CART 算法使用基尼指数，计算比信息熵高效（不需要 log）。
</GlossaryItem>

<GlossaryItem term="剪枝">
防止决策树过拟合的技术。预剪枝在树生长过程中提前停止（限制深度/叶节点样本数），效率高但可能欠拟合。后剪枝先建完整树再自底向上剪枝，更准确但开销大。
</GlossaryItem>

<GlossaryItem term="随机森林">
Bagging 的代表算法。每棵树用有放回采样的数据训练，划分时只考虑随机选取的部分特征，最终投票/取平均。降低方差，不易过拟合，可并行训练，可评估特征重要性。
</GlossaryItem>

<GlossaryItem term="Boosting（GBDT）">
串行集成方法。GBDT 每次训练新树拟合前一轮的残差（真实值减当前预测值），逐步降低偏差。AdaBoost 通过调整样本权重关注难分样本。Boosting 通常比 Bagging 精度更高但更易过拟合。
</GlossaryItem>

</Glossary>

### 问题 1

决策树的结构是什么？它的主要优点有哪些？请举一个实际例子说明决策过程。

<Answer>

决策树由根节点、内部节点、叶节点和分支组成。根节点是第一个划分条件（如「年龄?」），内部节点是后续的划分条件（如「收入?」），叶节点是最终决策结果（如「买/不买」），分支是划分的结果（如「<30 / >=30」）。决策过程从根节点开始，根据样本的特征值沿分支向下走，直到到达叶节点得到预测结果。例如预测一个人是否会买房：根节点问「年龄?」，如果 <30 则到内部节点问「收入?」，如果收入高则到叶节点「不买」，如果收入低则到叶节点「买」；如果年龄 >=30 则直接到叶节点「不买」。决策树的主要优点：①可解释性强——决策路径清晰可见，是白盒模型，可以解释每个预测的原因，适合需要可解释性的场景（如医疗、金融）；②可处理混合类型特征——同时支持类别特征（如性别）和数值特征（如年龄），不需要预先编码；③不需要特征缩放——基于阈值划分，对特征的量纲不敏感，不需要归一化或标准化；④可处理非线性关系——通过递归划分可以拟合非线性决策边界。

</Answer>

### 问题 2

信息增益、信息增益比和基尼指数分别是什么？它们有什么区别？

<Answer>

三种特征划分准则都用于在决策树节点选择最佳划分特征，核心思想是让划分后子节点的纯度最高。①信息增益（ID3 算法）——信息增益 = 划分前的信息熵 - 划分后子节点信息熵的加权和。信息熵 `H(D) = -sum(p_k * log2(p_k))` 衡量不确定性，纯度越高（全是一类）熵越小。选择使信息增益最大的特征划分。缺点是偏向取值多的特征（如 ID 编号，每个值一个样本，划分后熵为 0 但无泛化能力）。②信息增益比（C4.5 算法）——增益比 = 信息增益 / 固有值，固有值 `= -sum(|D_v|/|D| * log2(|D_v|/|D|))` 衡量特征本身取值的数量和均匀度。用固有值做修正，减少对多值特征的偏向。但可能矫枉过正，偏好取值少的特征。③基尼指数（CART 算法）——`Gini(D) = 1 - sum(p_k^2)`，衡量从数据集中随机取两个样本类别不同的概率。纯度越高 Gini 越小。CART 用基尼指数，计算比信息熵高效（不需要 log 运算）。三者区别：信息增益最直观但偏向多值特征；信息增益比修正了偏向但可能偏好少值特征；基尼指数计算最高效且效果与熵接近。大多数情况下三种准则选出的划分特征一致，工程实践中最常用基尼指数（CART）。

</Answer>

### 问题 3

什么是剪枝？预剪枝和后剪枝各有什么优缺点？

<Answer>

剪枝是防止决策树过拟合的关键技术。如果不限制，决策树会一直生长到每个叶节点只有一个样本（或纯度最高），这会导致严重过拟合——在训练集上 100% 正确但在测试集上表现差。剪枝分为两种：①预剪枝（Pre-pruning）——在树生长过程中提前停止。常用策略包括：限制最大深度（max_depth，树最多长到指定层）、限制叶节点最小样本数（min_samples_leaf，叶节点至少要有 N 个样本）、限制信息增益阈值（增益小于阈值不再划分）。优点是计算效率高（不需要建完整树），训练快。缺点是可能欠拟合——「目光短浅」，当前划分的信息增益小不代表后续划分不好，提前停止可能错过有用的划分。②后剪枝（Post-pruning）——先让树完全生长（可能过拟合），再自底向上剪掉对验证集性能提升不大的子树。常用方法：代价复杂度剪枝（比较剪枝前后在验证集上的性能）、最小误差剪枝。优点是比预剪枝更准确（基于完整树的信息做决策，不会目光短浅）。缺点是计算开销大（需要先建完整树再剪枝）。实践中常结合两者：先用预剪枝限制树的大小，再用后剪枝精细调整。

</Answer>

### 问题 4

Bagging 和 Boosting 的原理分别是什么？随机森林和 GBDT 各有什么特点？

<Answer>

Bagging 和 Boosting 是集成学习的两大思路，都通过组合多个弱学习器构建强学习器。①Bagging（Bootstrap Aggregating）——并行集成，树之间相互独立。对训练数据做有放回采样（Bootstrap），每份采样数据训练一个模型，最终投票（分类）或取平均（回归）。代表算法是随机森林：每棵树用有放回采样的一份数据训练，每次划分时只考虑随机选取的部分特征，分类时多数投票、回归时取平均。随机森林的特点：降低方差（多棵树投票抵消个体波动）、不易过拟合（树之间独立）、可评估特征重要性、适合并行训练（树之间无依赖）。适合高方差模型（如深决策树）。②Boosting——串行集成，树之间有依赖。每个新模型关注前一个模型分错的样本，逐步降低偏差。AdaBoost：训练第一个弱学习器后，提高分错样本的权重，训练下一个弱学习器关注高权重样本，加权组合所有弱学习器。GBDT（梯度提升决策树）：初始化预测值（如均值），计算残差 = 真实值 - 当前预测值，训练新树拟合残差，更新预测值 = 旧预测值 + 学习率 * 新树预测，重复迭代。GBDT 的特点：降低偏差（逐步逼近真实值）、精度通常比随机森林更高（XGBoost/LightGBM 是 Kaggle 竞赛利器）、但更容易过拟合（需仔细调学习率、树的数量、树的深度等超参数）。适合高偏差模型（如浅决策树）。核心区别：Bagging 降方差（树独立并行），Boosting 降偏差（树串行依赖）。

</Answer>
