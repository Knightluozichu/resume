## 从感知机到神经网络

### 感知机

感知机是最早的神经网络模型，由 Rosenblatt 于 1958 年提出。它是一个单层、二分类的线性模型：

```text
z = w^T * x + b
y = 1 if z >= 0 else 0
```

感知机只能解决**线性可分**问题。它的致命缺陷是无法解决 XOR（异或）问题——这导致了第一次 AI 寒冬。

### 多层感知机（MLP）

为了解决非线性问题，在输入和输出之间加入**隐藏层**，并用非线性激活函数：

```text
输入层 → 隐藏层1 → 隐藏层2 → ... → 输出层
```

每一层的计算：`a = activation(W * x + b)`

- 没有激活函数时，多层线性变换的叠加仍是线性的，加隐藏层无意义
- 激活函数引入非线性，使网络能拟合任意复杂的函数（万能逼近定理）

## 激活函数

激活函数为神经网络引入非线性，是深度学习的核心组件。

| 激活函数 | 公式 | 特点 | 适用场景 |
|---------|------|------|---------|
| Sigmoid | `1 / (1 + e^(-z))` | 输出 (0,1)，饱和区梯度消失 | 二分类输出层 |
| Tanh | `(e^z - e^(-z)) / (e^z + e^(-z))` | 输出 (-1,1)，零中心化 | 隐藏层（RNN） |
| ReLU | `max(0, z)` | 计算简单，缓解梯度消失 | 隐藏层（默认选择） |
| Softmax | `e^(z_i) / sum(e^(z_j))` | 输出概率分布，和为 1 | 多分类输出层 |

<Callout type="info">

**ReLU 为何成为默认选择**：①计算极简——只需 max(0, z)，比 Sigmoid/Tanh 的指数运算快得多；②缓解梯度消失——正区间梯度恒为 1，深层网络也能有效传播梯度；③稀疏激活——负输入输出 0，使网络具有稀疏性。但 ReLU 有「神经元死亡」问题：负输入梯度为 0，神经元可能永久不更新。Leaky ReLU 用 `max(0.01z, z)` 修正此问题。

</Callout>

## 前向传播

前向传播是输入数据从输入层经过隐藏层到输出层的计算过程。

以两层网络为例：

```text
# 第一层（隐藏层）
z1 = W1 * x + b1
a1 = ReLU(z1)

# 第二层（输出层）
z2 = W2 * a1 + b2
a2 = sigmoid(z2)   # 二分类输出概率
```

- `W1, W2` 是权重矩阵，`b1, b2` 是偏置向量
- `a1` 是隐藏层激活值，`a2` 是输出层激活值（预测结果）
- 每一层的输出是下一层的输入

## 反向传播

反向传播是训练神经网络的核心算法，用**链式法则**从输出层向输入层逐层计算损失函数对每个参数的梯度。

### 链式法则

如果 `y = f(g(x))`，则 `dy/dx = f'(g(x)) * g'(x)`。

在神经网络中，损失 L 是多层复合函数，梯度需要逐层展开：

```text
# 输出层梯度
dL/dz2 = a2 - y              # 交叉熵 + sigmoid 的简化形式
dL/dW2 = dL/dz2 * a1^T
dL/db2 = dL/dz2

# 隐藏层梯度（链式法则）
dL/da1 = W2^T * dL/dz2
dL/dz1 = dL/da1 * ReLU'(z1)  # 激活函数的导数
dL/dW1 = dL/dz1 * x^T
dL/db1 = dL/dz1
```

### 参数更新

计算完梯度后，用梯度下降更新参数：

```text
W = W - alpha * dL/dW
b = b - alpha * dL/db
```

### 完整训练循环

```text
1. 前向传播：计算各层激活值和最终预测
2. 计算损失：用预测值与真实值计算损失（如交叉熵）
3. 反向传播：从输出层向输入层逐层计算梯度
4. 参数更新：用梯度下降更新所有权重和偏置
5. 重复 1-4 直到收敛
```

<Callout type="tip">

**梯度消失与梯度爆炸**：深层网络中，梯度在反向传播经过多层时会连乘激活函数的导数。如果导数 < 1（如 Sigmoid 最大导数 0.25），多层连乘后梯度趋近 0（梯度消失），浅层权重几乎不更新。如果导数 > 1，多层连乘后梯度爆炸（趋向无穷）。解决方案：用 ReLU 激活函数（正区间导数为 1）、批归一化（BatchNorm）、残差连接（ResNet）。

</Callout>

<GlossaryItem term="感知机">

<GlossaryItem term="激活函数">
为神经网络引入非线性的函数。没有激活函数，多层线性变换的叠加仍是线性的。常用激活函数：Sigmoid（输出层二分类）、ReLU（隐藏层默认选择）、Tanh（RNN）、Softmax（多分类输出层）。
</GlossaryItem>

<GlossaryItem term="ReLU">
`ReLU(z) = max(0, z)`，最常用的隐藏层激活函数。优点：计算简单、正区间梯度恒为 1 缓解梯度消失、稀疏激活。缺点：负输入梯度为 0 可能导致神经元死亡。Leaky ReLU 用 `max(0.01z, z)` 修正。
</GlossaryItem>

<GlossaryItem term="前向传播">
输入数据从输入层经过隐藏层到输出层的计算过程。每一层计算 `a = activation(W * x + b)`，前一层的输出是下一层的输入，最终得到预测结果。
</GlossaryItem>

<GlossaryItem term="反向传播">
训练神经网络的核心算法，用链式法则从输出层向输入层逐层计算损失函数对每个参数的梯度。计算完梯度后用梯度下降更新参数。完整循环：前向传播 → 计算损失 → 反向传播 → 参数更新。
</GlossaryItem>

<GlossaryItem term="梯度消失">
深层网络中梯度经过多层连乘激活函数导数后趋近于 0 的现象。Sigmoid 的最大导数为 0.25，多层连乘后梯度极小，浅层权重几乎不更新。解决方案：ReLU 激活函数、批归一化、残差连接。
</GlossaryItem>

### 问题 1

感知机有什么局限性？多层感知机如何克服这一局限性？激活函数在其中起什么作用？

<Answer>

感知机是最早的神经网络模型，是一个单层、二分类的线性分类器：`z = w^T * x + b`，当 z >= 0 输出 1 否则输出 0。感知机的局限性是只能解决线性可分问题——它只能学到一个线性决策边界（超平面），无法解决 XOR（异或）等非线性可分问题。XOR 问题中，两类样本无法用一条直线分开，感知机无法收敛。这一局限性导致了第一次 AI 寒冬。多层感知机（MLP）通过在输入层和输出层之间加入隐藏层来克服这一局限性。多层感知机的每一层计算 `a = activation(W * x + b)`，前一层的输出作为下一层的输入。激活函数在其中起关键作用：①引入非线性——如果没有激活函数（或用线性激活函数），多层线性变换的叠加 `W2 * (W1 * x) = (W2*W1) * x` 仍是线性的，加再多层也等价于一层，无法解决非线性问题。激活函数（如 ReLU、Sigmoid）的非线性变换使网络能拟合任意复杂的函数（万能逼近定理）；②特征变换——隐藏层通过激活函数对输入进行非线性特征变换，使原本线性不可分的数据在新的特征空间中变得线性可分。例如两层网络可以解决 XOR 问题：第一个隐藏层将输入映射到新的特征空间使两类可分，输出层在新空间中做线性分类。

</Answer>

### 问题 2

常见的激活函数有哪些？ReLU 为什么成为隐藏层的默认选择？

<Answer>

常见激活函数：①Sigmoid——`1 / (1 + e^(-z))`，输出 (0, 1) 区间，S 形曲线。优点是输出可解释为概率，适合二分类输出层。缺点是饱和区（z 很大或很小）梯度趋近 0 导致梯度消失，且输出非零中心化（全正）影响梯度传播。②Tanh——`(e^z - e^(-z)) / (e^z + e^(-z))`，输出 (-1, 1) 区间，零中心化。比 Sigmoid 好但仍存在饱和区梯度消失，常用于 RNN。③ReLU——`max(0, z)`，正区间线性、负区间输出 0。④Softmax——`e^(z_i) / sum(e^(z_j))`，将多个得分转化为概率分布（和为 1），用于多分类输出层。ReLU 成为隐藏层默认选择的三个原因：①计算极简——只需 max(0, z) 运算，比 Sigmoid/Tanh 的指数运算快得多，大幅提升训练速度；②缓解梯度消失——正区间梯度恒为 1，反向传播时梯度不会因连乘而衰减，使深层网络也能有效训练（这是深度学习可行的关键之一）；③稀疏激活——负输入输出 0，使同一时刻只有部分神经元被激活，网络具有稀疏性，有正则化效果。但 ReLU 有「神经元死亡」问题：如果某个神经元的输入持续为负，其梯度为 0，权重永远不更新，神经元永久失活。Leaky ReLU 用 `max(0.01z, z)` 修正——负区间给一个小的斜率（0.01），避免梯度完全为 0。

</Answer>

### 问题 3

前向传播和反向传播的完整流程是什么？请以两层网络为例说明。

<Answer>

完整训练循环包括前向传播、计算损失、反向传播和参数更新四个步骤。以两层网络（一个隐藏层 + 一个输出层）为例：①前向传播——输入数据从输入层经过隐藏层到输出层的计算。隐藏层：`z1 = W1 * x + b1`（线性变换），`a1 = ReLU(z1)`（激活函数引入非线性）。输出层：`z2 = W2 * a1 + b2`，`a2 = sigmoid(z2)`（二分类输出概率）。其中 W1/W2 是权重矩阵，b1/b2 是偏置向量，a1 是隐藏层激活值，a2 是预测结果。②计算损失——用预测值 a2 和真实标签 y 计算损失函数。二分类用交叉熵：`L = -[y * log(a2) + (1-y) * log(1-a2)]`。③反向传播——用链式法则从输出层向输入层逐层计算损失对每个参数的梯度。输出层梯度：`dL/dz2 = a2 - y`（交叉熵 + sigmoid 的简化形式），`dL/dW2 = dL/dz2 * a1^T`，`dL/db2 = dL/dz2`。隐藏层梯度（链式法则反向传播）：`dL/da1 = W2^T * dL/dz2`（梯度从输出层传到隐藏层），`dL/dz1 = dL/da1 * ReLU'(z1)`（乘以激活函数导数），`dL/dW1 = dL/dz1 * x^T`，`dL/db1 = dL/dz1`。④参数更新——用梯度下降更新所有参数：`W1 = W1 - alpha * dL/dW1`，`b1 = b1 - alpha * dL/db1`，`W2 = W2 - alpha * dL/dW2`，`b2 = b2 - alpha * dL/db2`。alpha 是学习率。重复步骤 1-4 直到损失收敛。

</Answer>

### 问题 4

什么是梯度消失和梯度爆炸？如何解决？

<Answer>

梯度消失和梯度爆炸是深层神经网络训练中的核心问题，根源在于反向传播时梯度需要经过多层的连乘。梯度在反向传播中通过链式法则逐层计算，每一层都要乘以激活函数的导数和权重矩阵。①梯度消失——当激活函数的导数 < 1 时（如 Sigmoid 的最大导数为 0.25，Tanh 的最大导数为 1 但大部分区域 < 1），多层连乘后梯度以指数级衰减趋近于 0。结果是浅层（靠近输入层）的权重梯度极小，几乎不更新，导致浅层无法学习有效特征，网络性能受限。这是深度网络难以训练的主要原因。②梯度爆炸——当权重矩阵的值较大或激活函数导数 > 1 时，多层连乘后梯度以指数级增长趋向无穷。结果是参数更新幅度极大，权重震荡发散，损失变为 NaN，训练崩溃。解决方案：①使用 ReLU 激活函数——ReLU 正区间导数恒为 1，梯度在反向传播中不会衰减，是缓解梯度消失最有效的方法。这也是 ReLU 成为隐藏层默认选择的核心原因；②批归一化（Batch Normalization）——对每一层的输入做标准化（均值为 0、方差为 1），使激活值落在激活函数的非饱和区，避免梯度消失/爆炸；③残差连接（ResNet）——引入跳跃连接 `y = F(x) + x`，梯度可以直接通过跳跃连接传到浅层，不经过激活函数导数的连乘，使超深层网络（上百层）可训练；④梯度裁剪——在反向传播后对梯度做裁剪（限制范数），防止梯度爆炸；⑤合适的权重初始化——如 Xavier 初始化（Sigmoid/Tanh）或 He 初始化（ReLU），使各层激活值和梯度的方差保持在合理范围。

</Answer>
