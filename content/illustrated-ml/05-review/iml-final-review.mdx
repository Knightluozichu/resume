## 核心算法对比

| 算法 | 类型 | 优势 | 劣势 | 适用场景 |
|------|------|------|------|---------|
| 线性回归 | 回归 | 简单可解释 | 只能线性 | 线性关系 / 基线 |
| 逻辑回归 | 分类 | 输出概率可解释 | 线性决策边界 | 二分类 / 基线 |
| 决策树 | 分类/回归 | 可解释、不需缩放 | 易过拟合 | 需要可解释性 |
| 随机森林 | 分类/回归 | 不易过拟合、特征重要性 | 模型大、慢 | 通用分类/回归 |
| GBDT | 分类/回归 | 精度高 | 易过拟合、需调参 | 竞赛 / 高精度 |
| 神经网络 | 分类/回归 | 万能逼近、自动特征 | 黑箱、需大数据 | 复杂模式 / 深度学习 |
| SVM | 分类 | 最大间隔、核函数 | 大数据慢 | 中小数据高精度 |
| K-Means | 聚类 | 简单高效 | 需指定 K | 球形簇 / 分群 |
| PCA | 降维 | 线性高效 | 只能线性 | 特征压缩 / 可视化 |

<Callout type="info">

**算法选型原则**：①先简后繁——先用简单模型（线性回归/逻辑回归）做基线，再尝试复杂模型。简单模型往往够用且可解释；②数据驱动——数据量小用 SVM/决策树，数据量大用随机森林/GBDT/神经网络；③可解释性优先——医疗/金融等场景优先决策树/逻辑回归，牺牲精度换取可解释性；④No Free Lunch——没有万能算法，需根据具体问题尝试多个模型并交叉验证比较。

</Callout>

## ML 项目完整流程

### 1. 问题定义

- 明确任务类型：分类 / 回归 / 聚类 / 降维
- 明确评估指标：准确率 / F1 / MSE / 业务指标
- 明确约束条件：延迟 / 可解释性 / 数据量

### 2. 数据准备

- 数据收集：采集、清洗、标注
- 探索性分析：统计分布、缺失值、异常值
- 特征工程：提取、选择、编码、缩放
- 数据划分：训练/验证/测试集

### 3. 模型训练

- 基线模型：线性回归/逻辑回归
- 模型选择：决策树/随机森林/SVM/神经网络
- 超参数调优：网格搜索/随机搜索 + 交叉验证

### 4. 模型评估

- 在测试集上评估泛化能力
- 分析误差：混淆矩阵/残差分析
- 检查过拟合/欠拟合：学习曲线

### 5. 部署监控

- 上线推理
- 持续监控性能
- 发现数据漂移后重新训练

<Callout type="tip">

**工程实践建议**：①数据 > 算法——更多更好的数据通常比更复杂的算法更有效。在花时间调参之前，先确保数据质量和特征工程做到位；②基线先行——永远先用最简单的模型建立基线（如逻辑回归），再逐步尝试复杂模型。如果复杂模型提升不大，优先选简单模型；③交叉验证——不要只看单次划分的结果，用 K 折交叉验证获得更可靠的性能估计；④警惕过拟合——训练集表现好不等于好模型。始终在独立的测试集上评估，关注泛化能力而非训练性能。

</Callout>

## 知识整合：从线性到非线性

全书算法按「处理非线性能力」递进：

| 层次 | 算法 | 非线性方式 |
|------|------|-----------|
| 线性 | 线性回归 / 逻辑回归 | 无（线性决策边界） |
| 半线性 | 多项式回归 / 决策树 | 多项式特征 / 递归划分 |
| 非线性 | SVM + 核函数 / 神经网络 | 核映射 / 激活函数 |
| 集成 | 随机森林 / GBDT | 多模型组合 |

<Glossary>

<GlossaryItem term="算法选型">
根据任务类型、数据规模、可解释性需求和计算资源选择合适算法的过程。原则：先简后繁（线性模型做基线）、数据驱动（小数据 SVM/大树，大数据 GBDT/NN）、可解释性优先（医疗金融用决策树）、No Free Lunch（没有万能算法，需交叉验证比较）。
</GlossaryItem>

<GlossaryItem term="基线模型">
用最简单的模型（如线性回归/逻辑回归）建立的性能基准。作用：①提供比较基准——复杂模型必须显著超过基线才有价值；②快速验证——基线模型能快速跑通整个流程，发现数据和流程中的问题；③简单优先——如果基线效果已经足够好，就不需要复杂模型。
</GlossaryItem>

<GlossaryItem term="数据漂移">
部署后数据分布发生变化的现象（如用户行为变化、季节性变化）。导致模型性能逐渐下降。解决方案：持续监控预测分布和性能指标，发现漂移后重新训练模型。
</GlossaryItem>

<GlossaryItem term="ML 项目流程">
完整流程：问题定义（任务类型/评估指标/约束）→ 数据准备（收集/探索/特征工程/划分）→ 模型训练（基线/模型选择/调参）→ 模型评估（测试集/误差分析/学习曲线）→ 部署监控（推理/监控/重训练）。
</GlossaryItem>

<GlossaryItem term="No Free Lunch 定理">
没有一种算法在所有问题上都最优。不同算法在不同数据分布上有不同表现，需根据具体问题尝试多个模型并交叉验证比较。实践中通常尝试 3-5 种算法，选表现最好的。
</GlossaryItem>

<GlossaryItem term="从线性到非线性">
全书算法按非线性能力递进：线性（线性/逻辑回归）→ 半线性（多项式回归/决策树）→ 非线性（SVM 核函数/神经网络激活函数）→ 集成（随机森林/GBDT）。理解这一递进有助于选择合适复杂度的模型。
</GlossaryItem>

</Glossary>

### 问题 1

请对比全书介绍的几种核心算法（线性回归、逻辑回归、决策树、随机森林、SVM、神经网络）的优缺点和适用场景。

<Answer>

核心算法对比：①线性回归——类型回归，优势是简单可解释、训练快，劣势是只能拟合线性关系，适用场景是线性关系建模和作为基线模型。②逻辑回归——类型二分类，优势是输出概率可解释、训练快、适合大数据，劣势是线性决策边界（需多项式特征扩展非线性），适用场景是二分类基线、需要概率输出的场景（如风险评估）、可解释性要求高的场景。③决策树——类型分类/回归，优势是可解释性强（白盒模型）、可处理混合类型特征、不需特征缩放、可捕捉非线性，劣势是单棵树易过拟合、不稳定（数据小变化树结构大变），适用场景是需要可解释性的场景（医疗/金融）、特征类型混合的场景。④随机森林——类型分类/回归，优势是不易过拟合（降低方差）、可评估特征重要性、可并行训练、不需调太多参数，劣势是模型大、推理慢、可解释性不如单棵树，适用场景是通用的分类/回归任务、特征重要性分析、作为强基线模型。⑤GBDT（梯度提升树）——类型分类/回归，优势是精度高（XGBoost/LightGBM 是竞赛利器）、可处理缺失值，劣势是易过拟合、需仔细调参（学习率/树数量/深度）、串行训练慢，适用场景是高精度分类/回归、Kaggle 竞赛、表格数据。⑥SVM——类型分类，优势是最大间隔泛化好、核函数优雅实现非线性、中小数据精度高，劣势是训练复杂度 O(n^2)-O(n^3) 不适合大数据、不直接输出概率、多分类需 OvR/OvO，适用场景是中小数据集高精度分类、生物信息学等特征数接近样本数的场景。⑦神经网络——类型分类/回归，优势是万能逼近（可拟合任意复杂函数）、自动特征学习（无需手工特征工程），劣势是黑箱不可解释、需大数据和大量调参、计算资源需求高，适用场景是复杂模式识别（图像/语音/文本）、数据量大的场景、作为深度学习的入门。

</Answer>

### 问题 2

ML 项目的完整流程是什么？每个阶段的关键任务和注意事项是什么？

<Answer>

ML 项目完整流程分五个阶段：①问题定义——明确任务类型（分类/回归/聚类/降维）、评估指标（准确率/F1/MSE/业务指标）、约束条件（延迟/可解释性/数据量）。关键是要与业务方对齐目标，确保 ML 指标与业务价值一致。注意不要用准确率评估类别不平衡问题（用 F1/AUC）。②数据准备——数据收集（采集/清洗/标注）、探索性分析（统计分布/缺失值/异常值）、特征工程（提取/选择/编码/缩放）、数据划分（训练/验证/测试集）。关键是数据质量决定模型上限（Garbage In Garbage Out）。注意事项：先划分再做特征工程防数据泄露；测试集严格隔离只在最终用一次；特征缩放对 SVM/神经网络/梯度下降很重要但对决策树不需要。③模型训练——先用简单模型建立基线（线性回归/逻辑回归），再尝试复杂模型（决策树/随机森林/SVM/神经网络），用网格搜索/随机搜索 + K 折交叉验证调超参数。关键是基线先行——复杂模型必须显著超过基线才有价值。注意事项：不是越复杂越好，简单模型往往够用且可解释；用交叉验证而非单次划分评估；记录所有实验便于复现。④模型评估——在独立测试集上评估泛化能力，分析误差（混淆矩阵/残差分析），检查过拟合/欠拟合（学习曲线）。关键是关注泛化能力而非训练性能。注意事项：测试集绝对不参与训练和调参；分析错误样本找改进方向；如果训练好但测试差说明过拟合，都差说明欠拟合。⑤部署监控——上线推理，持续监控性能指标和预测分布，发现数据漂移后重新训练。关键是 ML 不是一次性项目，模型会随时间衰减。注意事项：监控数据分布变化（数据漂移）；建立重训练机制；保留模型版本便于回滚。

</Answer>

### 问题 3

什么是算法选型？请阐述算法选型的原则和决策框架。

<Answer>

算法选型是根据任务类型、数据规模、可解释性需求和计算资源选择最合适算法的过程。选型原则：①先简后繁——永远先用最简单的模型（如线性回归/逻辑回归）建立基线，再逐步尝试复杂模型。简单模型往往够用且可解释，如果复杂模型提升不大，优先选简单模型（Occam's razor）。②数据驱动——数据量小（几千到几万）用 SVM/决策树，数据量中等（几万到几十万）用随机森林/GBDT，数据量大（几十万以上）用 GBDT/神经网络。数据特征数接近样本数时 SVM 表现好。③可解释性优先——医疗诊断、金融风控等场景需要解释模型决策原因，优先决策树/逻辑回归（白盒模型），牺牲一定精度换取可解释性。不需要可解释性时用随机森林/GBDT/神经网络（黑盒模型）追求更高精度。④No Free Lunch——没有一种算法在所有问题上都最优，不同算法在不同数据分布上有不同表现。实践中通常尝试 3-5 种算法，用交叉验证比较，选表现最好的。决策框架：①确定任务类型——回归选线性回归/决策树/随机森林/GBDT/神经网络；分类选逻辑回归/SVM/决策树/随机森林/GBDT/神经网络；聚类选 K-Means/DBSCAN/层次聚类；降维选 PCA。②评估数据规模——小数据 SVM/决策树/逻辑回归（不易过拟合）；大数据随机森林/GBDT/神经网络（需要数据驱动复杂模型）。③确定可解释性需求——高可解释性决策树/逻辑回归；低可解释性随机森林/GBDT/神经网络。④考虑计算资源——训练快逻辑回归/决策树/随机森林（可并行）；训练慢 SVM（大数据慢）/神经网络（需 GPU）。⑤交叉验证比较——在验证集上用 K 折交叉验证比较候选算法，选最优者。

</Answer>

### 问题 4

全书算法按「处理非线性能力」如何递进？请从线性到非线性的角度整合全书知识。

<Answer>

全书算法按处理非线性能力递进分四个层次：①线性层——线性回归和逻辑回归。线性回归 `y = wX + b` 直接用线性关系建模，决策边界是线性的（超平面）。逻辑回归在线性得分上加 sigmoid，但决策边界仍是线性的 `w^T * x + b = 0`。优势是简单可解释、训练快，劣势是只能处理线性关系。适合作为基线模型和可解释性要求高的场景。②半线性层——多项式回归和决策树。多项式回归通过添加多项式特征（x^2, x^3...）使线性模型能拟合非线性曲线，但本质仍是对权重线性。决策树通过递归划分特征空间（if-else 规则）实现非线性决策边界——每次划分是一次阈值判断，多次划分组合出非线性的阶梯状边界。优势是比纯线性模型能力强，决策树还可解释；劣势是多项式回归次数过高易过拟合，决策树单棵也易过拟合。③非线性层——SVM（核函数）和神经网络（激活函数）。SVM 通过核函数将数据隐式映射到高维（甚至无限维）空间，在高维空间中寻找线性超平面，等价于在原始空间中实现非线性决策边界。RBF 核可拟合任意复杂边界。神经网络通过激活函数（ReLU/Sigmoid/Tanh）引入非线性，多层网络可拟合任意复杂函数（万能逼近定理），隐藏层自动学习特征。优势是强大的非线性拟合能力；劣势是 SVM 大数据训练慢，神经网络需大数据和大量调参且黑箱不可解释。④集成层——随机森林（Bagging）和 GBDT（Boosting）。随机森林通过多棵决策树投票/取平均，降低方差，组合出更平滑的非线性决策边界。GBDT 通过串行训练多棵树拟合残差，逐步降低偏差，精度通常最高。集成的非线性能力来自多模型组合，而非单个模型的复杂度。这一递进的知识整合：理解从线性到非线性的递进，有助于根据问题的非线性程度选择合适复杂度的模型——简单线性关系用线性/逻辑回归，中等非线性用决策树/随机森林，高度非线性用 SVM 核函数/神经网络/GBDT。这也为后续学习深度学习打下了基础——神经网络的非线性能力（激活函数 + 多层结构）正是深度学习的核心。

</Answer>
