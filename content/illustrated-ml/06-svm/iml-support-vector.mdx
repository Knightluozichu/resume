## 最大间隔分类

支持向量机（SVM）的核心思想是寻找一个分类超平面，使它到最近的样本点（支持向量）的间隔最大化。

```text
        ← 间隔 →
   ○ ○ ○ | ◇ ◇ ◇
  ○ ○ ○  | ◇ ◇ ◇    ← 支持向量在间隔边界上
 ○ ○ ○ ○ | ◇ ◇ ◇ ◇
─────────────────────  ← 决策边界 (w^T * x + b = 0)
```

### 数学模型

决策边界：`w^T * x + b = 0`

间隔宽度：`2 / ||w||`

最大化间隔等价于最小化 `||w||^2`，即：

```text
minimize: (1/2) * ||w||^2
subject to: y_i * (w^T * x_i + b) >= 1,  for all i
```

## 支持向量

支持向量是离决策边界最近的样本点，它们满足 `y_i * (w^T * x_i + b) = 1`（恰好在间隔边界上）。

| 特性 | 说明 |
|------|------|
| 决定决策边界 | 只有支持向量影响超平面位置 |
| 非支持向量无关 | 移除非支持向量不影响模型 |
| 稀疏性 | 通常只有少量样本是支持向量 |
| 鲁棒性 | 对远离边界的噪声不敏感 |

<Callout type="info">

**SVM 的几何直觉**：想象在两类样本之间放一条最宽的「路」。路的中心线是决策边界，路的宽度就是间隔。路的边缘恰好碰到最近的几个样本——这些就是支持向量。SVM 要做的就是让这条路尽可能宽。与逻辑回归的区别：逻辑回归关注所有样本的总体概率，SVM 只关注边界附近的样本（支持向量）。

</Callout>

## 核函数

当数据线性不可分时，SVM 通过核函数将数据隐式映射到高维空间，在高维空间中寻找线性超平面。

### 核技巧的原理

```text
原始空间（线性不可分） → 高维空间（线性可分）
```

例如二维空间的 XOR 问题，映射到三维后可以用一个平面分开。

核函数的好处是**不需要显式计算高维映射**，直接在原始空间中计算内积：

```text
K(x_i, x_j) = phi(x_i)^T * phi(x_j)
```

### 常用核函数

| 核函数 | 公式 | 特点 | 适用场景 |
|-------|------|------|---------|
| 线性核 | `K(x, y) = x^T * y` | 无映射，计算快 | 线性可分 / 高维稀疏 |
| 多项式核 | `K(x, y) = (x^T * y + 1)^d` | 可控多项式次数 | 中等非线性 |
| RBF 核 | `K(x, y) = exp(-gamma * ||x-y||^2)` | 无限维映射，最常用 | 通用非线性 |
| Sigmoid 核 | `K(x, y) = tanh(alpha * x^T * y + c)` | 类似神经网络 | 特殊场景 |

<Callout type="tip">

**RBF 核为何最常用**：RBF（高斯核）将数据映射到无限维空间，理论上可以拟合任意复杂的决策边界。超参数 `gamma` 控制影响范围：gamma 大时每个样本影响范围小（容易过拟合），gamma 小时影响范围大（容易欠拟合）。通常和正则化参数 C 一起用网格搜索调优。

</Callout>

## 软间隔

严格的最大间隔 SVM 要求所有样本必须正确分类（硬间隔）。当数据有噪声或类别重叠时，这会导致无解或过拟合。软间隔允许部分样本违反间隔约束，引入松弛变量：

```text
minimize: (1/2) * ||w||^2 + C * sum(xi_i)
subject to: y_i * (w^T * x_i + b) >= 1 - xi_i,  xi_i >= 0
```

### 正则化参数 C

| C 值 | 行为 | 效果 |
|------|------|------|
| C 很大 | 严格分类，少容忍违规 | 间隔窄，易过拟合 |
| C 适中 | 平衡间隔与分类错误 | 泛化好 |
| C 很小 | 多容忍违规 | 间隔宽，易欠拟合 |

C 是 SVM 最重要的超参数，控制「最大化间隔」与「最小化分类错误」之间的权衡。

## SVM vs 逻辑回归

| 对比维度 | SVM | 逻辑回归 |
|---------|-----|---------|
| 核心思想 | 最大间隔 + 支持向量 | 概率建模 |
| 关注样本 | 边界附近的支持向量 | 所有样本 |
| 核函数 | 天然支持核技巧 | 需手动特征映射 |
| 概率输出 | 不直接输出概率 | 直接输出概率 |
| 非线性 | 核函数优雅实现 | 需多项式特征 |
| 大数据 | 训练复杂度 O(n^2)-O(n^3) | 训练快，适合大数据 |

<GlossaryItem term="支持向量机（SVM）">
寻找最大间隔分类超平面的二分类算法。决策边界由离它最近的样本点（支持向量）决定。通过核函数可实现非线性分类，通过软间隔可容忍噪声。适合中小数据集的高精度分类。
</GlossaryItem>

<GlossaryItem term="支持向量">
离决策边界最近的样本点，恰好在间隔边界上。只有支持向量影响超平面的位置，移除非支持向量不影响模型。这使得 SVM 具有稀疏性和对远端噪声的鲁棒性。
</GlossaryItem>

<GlossaryItem term="核函数">
将数据隐式映射到高维空间进行线性分类的技巧。`K(x_i, x_j) = phi(x_i)^T * phi(x_j)`，不需要显式计算高维映射。常用核：线性核、多项式核、RBF 核（高斯核，最常用）。
</GlossaryItem>

<GlossaryItem term="RBF 核（高斯核）">
`K(x, y) = exp(-gamma * ||x-y||^2)`，将数据映射到无限维空间。gamma 控制影响范围：大 gamma 容易过拟合，小 gamma 容易欠拟合。是 SVM 最常用的非线性核函数。
</GlossaryItem>

允许部分样本违反间隔约束的 SVM 变体，引入松弛变量 xi 处理噪声和类别重叠。正则化参数 C 控制容忍度：C 大严格分类易过拟合，C 小多容忍违规易欠拟合。
</GlossaryItem>

<GlossaryItem term="正则化参数 C">
SVM 的核心超参数，控制「最大化间隔」与「最小化分类错误」的权衡。C 大时间隔窄、分类严格、易过拟合；C 小时间隔宽、容忍错误、易欠拟合。通常用网格搜索调优。
</GlossaryItem>

### 问题 1

SVM 的核心思想是什么？什么是支持向量？支持向量有什么特殊性质？

<Answer>

SVM 的核心思想是寻找一个分类超平面，使它到最近的样本点（支持向量）的间隔最大化。决策边界为 `w^T * x + b = 0`，间隔宽度为 `2/||w||`，最大化间隔等价于最小化 `||w||^2`。直觉理解：在两类样本之间放一条最宽的「路」，路的中心线是决策边界，路的宽度就是间隔。支持向量是离决策边界最近的样本点，它们恰好在间隔边界上，满足 `y_i * (w^T * x_i + b) = 1`。支持向量的特殊性质：①决定决策边界——只有支持向量影响超平面的位置和方向，决策边界完全由支持向量确定；②非支持向量无关——移除非支持向量（离边界较远的样本）不影响模型，因为它们不在间隔边界上，不参与约束；③稀疏性——通常只有少量样本是支持向量（离边界最近的那些），大多数样本不影响模型，这使得 SVM 具有计算上的稀疏性；④鲁棒性——对远离边界的噪声不敏感，因为远端样本不是支持向量，不影响决策边界。与逻辑回归的区别：逻辑回归关注所有样本的总体概率（每个样本都贡献梯度），SVM 只关注边界附近的样本（只有支持向量参与决策边界确定）。

</Answer>

### 问题 2

核函数的作用是什么？RBF 核为什么是最常用的核函数？

<Answer>

核函数的作用是将线性不可分的数据隐式映射到高维空间，在高维空间中寻找线性超平面，从而实现非线性分类。原理是：原始空间中线性不可分的数据，映射到高维空间后可能变得线性可分。例如二维空间的 XOR 问题，映射到三维后可以用一个平面分开。核技巧的好处是不需要显式计算高维映射 `phi(x)`，直接在原始空间中计算高维空间的内积：`K(x_i, x_j) = phi(x_i)^T * phi(x_j)`。这避免了高维映射的计算开销（映射后的维度可能极高甚至无限维）。常用核函数：①线性核 `K(x,y) = x^T * y`——无映射，计算快，适用于线性可分或高维稀疏数据（如文本分类）；②多项式核 `K(x,y) = (x^T*y + 1)^d`——可控多项式次数 d，适用于中等非线性问题；③RBF 核（高斯核）`K(x,y) = exp(-gamma * ||x-y||^2)`——最常用；④Sigmoid 核——类似神经网络，特殊场景使用。RBF 核最常用的原因：①无限维映射——RBF 核将数据映射到无限维空间，理论上可以拟合任意复杂的决策边界，表达能力强；②局部性强——RBF 核基于样本间的欧氏距离，距离越近核值越大（影响越强），具有局部性，适合大多数实际数据分布；③超参数少——只有 gamma 一个超参数（加上正则化参数 C），调参相对简单；④通用性好——在不知道数据先验结构时，RBF 核通常是最好的默认选择。gamma 控制影响范围：gamma 大时每个样本影响范围小（决策边界复杂，容易过拟合），gamma 小时影响范围大（决策边界平滑，容易欠拟合）。通常和 C 一起用网格搜索调优。

</Answer>

### 问题 3

什么是软间隔？正则化参数 C 的作用是什么？

<Answer>

软间隔是允许部分样本违反间隔约束的 SVM 变体。严格的最大间隔 SVM（硬间隔）要求所有样本必须正确分类且满足 `y_i * (w^T * x_i + b) >= 1`。但当数据有噪声或类别重叠时，硬间隔 SVM 会导致无解（线性不可分时无法找到满足所有约束的超平面）或过拟合（为了分对所有噪声点，间隔变得极窄）。软间隔引入松弛变量 xi_i，允许部分样本违反间隔约束：`y_i * (w^T * x_i + b) >= 1 - xi_i`，xi_i >= 0。目标函数变为 `minimize (1/2)*||w||^2 + C*sum(xi_i)`，其中 C*sum(xi_i) 是对违规的惩罚项。正则化参数 C 的作用是控制「最大化间隔」与「最小化分类错误」之间的权衡：①C 很大时——对违规的惩罚很重，模型倾向于严格分类所有样本（xi_i 尽量为 0），间隔变窄，容易过拟合（为了分对噪声而牺牲间隔宽度）；②C 适中时——在间隔宽度和分类错误之间取得平衡，泛化能力好；③C 很小时——对违规的惩罚很轻，模型倾向于放宽间隔（容忍更多分类错误），间隔变宽，容易欠拟合（太宽松导致很多样本被错分）。C 是 SVM 最重要的超参数，通常在对数尺度上用网格搜索调优（如 C in [0.001, 0.01, 0.1, 1, 10, 100, 1000]）。对于 RBF 核 SVM，C 和 gamma 一起构成二维超参数空间，需要联合调优。

</Answer>

### 问题 4

SVM 和逻辑回归有什么区别？各自的适用场景是什么？

<Answer>

SVM 和逻辑回归都是经典的二分类算法，但核心思想和适用场景不同。核心区别：①核心思想——SVM 寻找最大间隔分类超平面，关注边界附近的样本（支持向量），目标是使间隔最大化；逻辑回归用 sigmoid 将线性得分映射为概率，关注所有样本的总体概率，目标是最大化似然（最小化交叉熵）。②关注样本——SVM 只有支持向量（离边界最近的样本）参与决策边界确定，非支持向量不影响模型，具有稀疏性；逻辑回归的每个样本都贡献梯度，都影响模型参数。③核函数——SVM 天然支持核技巧，通过核函数优雅地实现非线性分类（只需替换内积为核函数）；逻辑回归需要手动构造非线性特征（如多项式特征）来实现非线性分类。④概率输出——逻辑回归直接输出概率（0 到 1 之间），适合需要概率估计的场景；SVM 不直接输出概率（输出的是到决策边界的距离），需要额外校准（如 Platt scaling）才能得到概率。⑤非线性能力——SVM 用 RBF 核可以实现无限维映射，非线性能力强；逻辑回归的多项式特征受限于人工设计的次数。⑥训练复杂度——SVM 的训练复杂度为 O(n^2) 到 O(n^3)，不适合大数据集；逻辑回归训练快，适合大规模数据。适用场景：SVM 适合中小数据集（几千到几万样本）、高精度分类、需要非线性决策边界的场景，尤其适合特征数与样本数接近的情况（如生物信息学）；逻辑回归适合大数据集、需要概率输出的场景（如排序、风险评估）、需要模型可解释性的场景、以及作为基线模型快速验证。实践中，数据量大时优先逻辑回归，数据量中小且需要高精度时优先 SVM（RBF 核）。

</Answer>
