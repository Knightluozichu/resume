## 无监督学习概览

无监督学习在没有标签的数据中发现内在结构，主要分为两大任务：

| 任务 | 目标 | 代表算法 | 应用场景 |
|------|------|---------|---------|
| 聚类 | 将数据分成若干组 | K-Means / DBSCAN / 层次聚类 | 用户分群 / 异常检测 |
| 降维 | 压缩高维数据 | PCA / t-SNE / UMAP | 可视化 / 特征压缩 |

## K-Means 聚类

K-Means 是最经典的聚类算法，目标是将数据分成 K 个簇，使组内相似度高、组间相似度低。

### 迭代流程

```text
1. 初始化：随机选择 K 个点作为簇中心
2. 分配：每个样本分配到最近的簇中心
3. 更新：重新计算每个簇的中心（均值）
4. 重复步骤 2-3 直到簇中心不再变化（收敛）
```

### 特点

| 优点 | 缺点 |
|------|------|
| 算法简单，计算高效 | 需预先指定 K 值 |
| 适合大规模数据 | 对初始中心敏感（可能陷入局部最优） |
| 簇为凸形时效果好 | 只能发现球形簇，不适合非凸形状 |
| 结果易解释 | 对噪声和异常值敏感 |

### K 值选择

- **肘部法则（Elbow Method）**：绘制 K vs 簇内方差曲线，选择「肘部」处的 K
- **轮廓系数**：衡量每个样本到同簇和最近簇的平均距离，取值 `[-1, 1]`，越大越好

<Callout type="info">

**K-Means 的局限**：K-Means 假设簇是球形（凸形）且大小相近，对于非凸形状的簇（如环形分布）效果差。此时可用 DBSCAN——基于密度发现任意形状的簇，还能自动识别噪声点。K-Means++ 改进了初始化策略，通过概率分布选择初始中心，减少陷入局部最优的风险。

</Callout>

## 层次聚类

层次聚类不需要预先指定 K 值，通过构建聚类树（树状图）展示数据的层次结构。

### 自底向上（凝聚型）

1. 每个样本自成一簇
2. 合并最近的两个簇
3. 重复直到所有样本合并为一簇
4. 在树状图上选择切割高度确定簇数

### 簇间距离度量

| 方法 | 定义 |
|------|------|
| 单链接 | 两个簇间最近样本的距离 |
| 全链接 | 两个簇间最远样本的距离 |
| 平均链接 | 两个簇间所有样本对的平均距离 |
| Ward | 合并后使簇内方差增量最小 |

## DBSCAN

DBSCAN（基于密度的空间聚类）通过密度连通性发现任意形状的簇。

### 核心概念

- **核心点**：在半径 eps 内有不少于 min_samples 个邻居
- **边界点**：在核心点的 eps 邻域内但自身不是核心点
- **噪声点**：既不是核心点也不是边界点

### 流程

1. 从任意未访问点出发
2. 如果是核心点，创建新簇，将 eps 邻域内所有点加入
3. 递归扩展核心点的邻居
4. 不是核心点则标记为噪声

| 优点 | 缺点 |
|------|------|
| 可发现任意形状的簇 | 对 eps 和 min_samples 敏感 |
| 自动确定簇数 | 密度不均匀时效果差 |
| 可识别噪声点 | 高维数据距离度量失效 |

## PCA 降维

主成分分析（PCA）是最经典的线性降维方法，通过正交变换将高维数据投影到低维空间，保留最大方差方向。

### 核心思想

```text
原始高维空间 → 投影到低维子空间 → 保留主要信息（最大方差）
```

### 计算步骤

1. 数据标准化（去均值）
2. 计算协方差矩阵
3. 计算协方差矩阵的特征值和特征向量
4. 选最大的 k 个特征值对应的特征向量（主成分）
5. 将数据投影到这 k 个特征向量构成的子空间

### 方差解释比

每个主成分解释的方差占比 = 该特征值 / 所有特征值之和。通常选择累计方差解释比达到 95% 的主成分数量。

<Callout type="tip">

**PCA 的应用场景**：①数据可视化——将高维数据降到 2D/3D 用于可视化（但 t-SNE/UMAP 的可视化效果通常更好）；②特征压缩——减少特征数量，降低存储和计算开销；③去噪——保留大方差方向（信号），丢弃小方差方向（噪声）；④加速训练——降维后特征更少，训练更快。注意：PCA 是线性降维，无法捕捉非线性结构；且 PCA 假设方差大 = 信息多，这不总是成立。

</Callout>

<Glossary>

<GlossaryItem term="K-Means 聚类">
最经典的聚类算法。迭代流程：随机初始化 K 个簇中心 → 每个样本分配到最近簇 → 更新簇中心为簇内均值 → 重复直到收敛。优点是简单高效，缺点是需指定 K、只适合球形簇、对初始中心和异常值敏感。
</GlossaryItem>

<GlossaryItem term="肘部法则">
选择 K-Means 簇数 K 的方法。绘制 K vs 簇内方差曲线，选择方差下降率骤减的「肘部」点作为 K 值。也可用轮廓系数辅助选择。
</GlossaryItem>

<GlossaryItem term="层次聚类">
不需要预先指定 K 值的聚类方法。自底向上（凝聚型）逐步合并最近的簇，构建聚类树（树状图），在合适高度切割确定簇数。簇间距离可用单链接/全链接/平均链接/Ward 方法度量。
</GlossaryItem>

<GlossaryItem term="DBSCAN">
基于密度的聚类算法。通过核心点（eps 邻域内至少有 min_samples 个点）和密度连通性发现任意形状的簇，可自动识别噪声点。优点是无需指定簇数、可发现非凸形状，缺点是对参数敏感、密度不均匀时效果差。
</GlossaryItem>

<GlossaryItem term="PCA（主成分分析）">
最经典的线性降维方法。通过计算协方差矩阵的特征向量，将高维数据投影到最大方差方向构成的低维子空间。用于数据可视化、特征压缩、去噪。方差解释比衡量每个主成分保留的信息量。
</GlossaryItem>

<GlossaryItem term="轮廓系数">
评估聚类质量的指标。`s = (b-a)/max(a,b)`，其中 a 是样本到同簇其他样本的平均距离，b 是样本到最近簇的平均距离。取值 [-1, 1]，越大表示聚类效果越好。可用于选择 K 值。
</GlossaryItem>

</Glossary>

### 问题 1

K-Means 聚类的迭代流程是什么？它有什么优缺点？如何选择 K 值？

<Answer>

K-Means 聚类的迭代流程：①初始化——随机选择 K 个点作为初始簇中心；②分配——计算每个样本到 K 个簇中心的距离，将每个样本分配到最近的簇中心；③更新——重新计算每个簇的中心，即簇内所有样本的均值；④重复步骤 2-3，直到簇中心不再变化（收敛）或达到最大迭代次数。优点：①算法简单直观，容易实现和理解；②计算效率高，时间复杂度为 O(n*K*d*iter)，适合大规模数据；③当簇为凸形（球形）且大小相近时效果好；④聚类结果易于解释，每个簇有明确的中心。缺点：①需要预先指定簇数 K，而 K 的选择通常不直观；②对初始簇中心敏感——不同的初始化可能导致不同的聚类结果，可能陷入局部最优（K-Means++ 通过智能初始化缓解此问题）；③只能发现球形（凸形）簇，对于非凸形状的簇（如环形、月牙形）效果差；④对噪声和异常值敏感——异常点会拉偏簇中心；⑤簇数 K 固定，不能自动发现簇的数量。K 值选择方法：①肘部法则（Elbow Method）——绘制 K 值 vs 簇内方差（inertia）的曲线，簇内方差随 K 增大而减小，选择方差下降率骤减的「肘部」点作为 K 值。直觉是：肘部之前增加 K 能显著减少方差，肘部之后增加 K 收益递减；②轮廓系数——`s = (b-a)/max(a,b)`，其中 a 是样本到同簇其他样本的平均距离，b 是样本到最近簇的平均距离。轮廓系数取值 [-1, 1]，越大表示聚类越好。计算不同 K 值下的平均轮廓系数，选择使轮廓系数最大的 K。

</Answer>

### 问题 2

层次聚类和 DBSCAN 各有什么特点？它们与 K-Means 相比有什么优势？

<Answer>

层次聚类的特点：不需要预先指定 K 值，通过构建聚类树（树状图）展示数据的层次结构。自底向上（凝聚型）的流程：每个样本自成一簇 → 合并最近的两个簇 → 重复直到所有样本合并为一簇 → 在树状图上选择切割高度确定簇数。簇间距离度量方法包括单链接（最近样本距离）、全链接（最远样本距离）、平均链接（所有样本对的平均距离）、Ward（合并后簇内方差增量最小）。与 K-Means 相比的优势：①无需预先指定 K——可以在树状图上直观地选择不同切割高度得到不同簇数，适合不确定最佳簇数的探索性分析；②层次结构——树状图展示了数据的层次聚类关系，可以看到簇之间的嵌套和合并过程，提供比 K-Means 更丰富的信息；③灵活性——可以在不同粒度上分析数据结构。DBSCAN（基于密度的空间聚类）的特点：通过密度连通性发现任意形状的簇。核心概念：核心点（eps 半径内不少于 min_samples 个邻居）、边界点（在核心点邻域内但自身非核心）、噪声点（既非核心也非边界）。流程：从未访问点出发，如果是核心点则创建新簇并递归扩展其 eps 邻域，不是核心点则标记为噪声。与 K-Means 相比的优势：①可发现任意形状的簇——DBSCAN 基于密度而非距离，可以发现环形、月牙形等非凸形状的簇，而 K-Means 只能发现球形簇；②自动确定簇数——不需要预先指定簇数 K，簇的数量由数据密度结构自动决定；③可识别噪声点——明确标记不属于任何簇的噪声点，而 K-Means 强制每个样本属于某个簇；④对异常值鲁棒——噪声点不影响簇的形成。但 DBSCAN 的缺点是对 eps 和 min_samples 参数敏感，密度不均匀时效果差。

</Answer>

### 问题 3

PCA 降维的核心思想和计算步骤是什么？它有什么应用场景和局限？

<Answer>

PCA（主成分分析）的核心思想是通过正交变换将高维数据投影到低维子空间，保留数据中方差最大的方向（主成分），从而在降维的同时尽可能保留原始数据的信息。直觉理解：数据在不同方向上的「展开程度」（方差）不同，方差大的方向包含更多信息，PCA 找到方差最大的几个方向作为新的坐标轴。计算步骤：①数据标准化——对每个特征去均值（使数据中心在原点），必要时做缩放使不同量纲的特征可比；②计算协方差矩阵——协方差矩阵描述各特征之间的相关性，大小为 d*d（d 是原始特征数）；③计算特征值和特征向量——对协方差矩阵做特征值分解，得到 d 个特征值和对应的特征向量。特征值表示该方向上的方差大小，特征向量表示该方向的方向；④选择主成分——将特征值从大到小排序，选最大的 k 个特征值对应的特征向量作为主成分（k 是目标维度）；⑤投影——将原始数据投影到这 k 个特征向量构成的子空间，得到降维后的数据 `X_reduced = X * W_k`（W_k 是 k 个特征向量组成的矩阵）。方差解释比：每个主成分解释的方差占比 = 该特征值 / 所有特征值之和。通常选择累计方差解释比达到 95% 的主成分数量。应用场景：①数据可视化——将高维数据降到 2D/3D 用于可视化（但 t-SNE/UMAP 的可视化效果通常更好，因为它们保留局部结构）；②特征压缩——减少特征数量，降低存储和计算开销；③去噪——大方差方向通常是信号，小方差方向通常是噪声，丢弃小方差方向等于去噪；④加速训练——降维后特征更少，模型训练更快。局限性：①PCA 是线性降维——只能捕捉线性结构，无法处理非线性流形（如 Swiss Roll 数据），此时需要 t-SNE/UMAP 等非线性方法；②方差大不等于信息多——PCA 假设方差大 = 信息多，但有些情况下方差小的方向可能包含重要的判别信息（如分类任务中方差小的方向可能是区分类别的关键）；③不可解释性——主成分是原始特征的线性组合，通常没有明确的物理含义；④对缩放敏感——如果特征量纲差异大且未做标准化，大量纲特征会主导主成分方向。

</Answer>

### 问题 4

无监督学习与监督学习有什么本质区别？在什么场景下应该使用无监督学习？

<Answer>

无监督学习与监督学习的本质区别在于是否有标签：①数据形式——监督学习使用有标签数据 (X, y)，有标准答案作为学习目标；无监督学习使用无标签数据 X，没有标准答案，需要自行发现数据中的结构。②学习目标——监督学习的目标是学习从输入 X 到输出 y 的映射关系（分类或回归），有明确的预测目标；无监督学习的目标是发现数据的内在结构（聚类找分组、降维找主成分），没有明确的预测目标。③评估方式——监督学习有客观的评估指标（准确率/MSE 等），可以用测试集评估泛化能力；无监督学习没有标签，评估更主观（轮廓系数/方差解释比等间接指标），难以客观衡量结果好坏。④任务类型——监督学习主要是分类和回归；无监督学习主要是聚类和降维。应该使用无监督学习的场景：①数据探索与理解——面对一个新数据集，不了解其结构时，先用聚类看数据有哪些自然分组，用降维可视化看数据分布。这是数据分析的第一步；②无标签数据丰富但有标签数据稀缺——标注成本高（如医学影像需专家标注），大量原始数据无法全部标注，可用无监督学习从无标签数据中提取结构信息；③用户分群/市场细分——商业场景中不知道用户应该分成哪些群体，用聚类算法自动发现用户群体（如 K-Means 将用户按消费行为分群），用于精准营销；④异常检测——正常数据聚类后，远离所有簇中心的点可能是异常（如信用卡欺诈检测），DBSCAN 明确标记的噪声点也可能是异常；⑤特征工程/降维——用 PCA 降维作为预处理步骤，减少特征数量、去除冗余、加速后续监督学习；⑥推荐系统——用户和物品的聚类用于协同过滤的预处理。实践中，无监督学习常与监督学习结合：先用无监督学习做数据探索和特征工程，再用监督学习做预测。

</Answer>
