## 学习目标

- 理解《图解新能源汽车》全书的五大学习阶段与十章学习路径
- 掌握从电池到电机到充电到整车的系统演进逻辑
- 明确各章节之间的依赖关系与核心脉络
- 建立新能源汽车知识的五层系统视角（认知层、动力层、管理层、架构层、未来层）

## 核心概念

### 五大学习阶段

《图解新能源汽车》按照由浅入深、从原理到应用的原则，将全书内容划分为五个学习阶段：

1. **基础认知**：理解知识全景，掌握新能源汽车类型与三电系统概念
2. **动力系统**：掌握电池、驱动电机、电力电子三大核心动力部件
3. **充电与管理**：学习充电系统、BMS 电池管理与热管理
4. **整车架构**：掌握底盘与车身平台化设计
5. **未来与复习**：学习安全技术与未来趋势，全书复习形成系统闭环

### 十章学习路径

十章内容沿着认知主线层层递进：

- 第 0 章（本章）：知识全景图，总览学习路径
- 第 1 章：新能源汽车概览，理解 BEV/PHEV/HEV 类型与三电系统
- 第 2 章：电池系统，掌握电芯到电池包的三级结构
- 第 3 章：驱动电机与控制，学习 PMSM 与 FOC 矢量控制
- 第 4 章：电力电子与变换，理解逆变器/DC-DC/OBC
- 第 5 章：充电系统，掌握交流与直流充电
- 第 6 章：电池管理与热管理，学习 BMS 与温控
- 第 7 章：底盘与车身架构，掌握平台化与滑板底盘
- 第 8 章：安全技术与未来趋势，学习高压安全与智能化
- 第 9 章：全书复习与知识整合，形成系统闭环

### 核心脉络

全书的核心理念可以概括为一条认知主线：

**理解类型 → 掌握电池 → 驱动电机 → 电力变换 → 充电系统 → 管理温控 → 整车架构 → 安全趋势 → 知识闭环**

每个阶段都建立在前一阶段的基础上。类型是认知基座，不理解 BEV/PHEV/HEV 区别就无法理解三电系统配置差异；电池是能量来源，不理解电芯结构就无法理解充电策略与热管理；电机是动力输出，不理解 FOC 控制就无法理解再生制动；电力电子是能量枢纽，不理解逆变器就无法理解能量转换；充电是能量补给，不理解充电协议就无法理解快充限制；BMS 与热管理是安全保障，不理解温度影响就无法理解电池寿命；底盘车身是物理承载，不理解平台化就无法理解空间利用；安全是生命线，不理解高压防护就无法理解新能源汽车的可靠运行。

## 术语表

| 术语 | 含义 |
|------|------|
| NEV | 新能源汽车（New Energy Vehicle）的统称 |
| BEV | 纯电动汽车，仅由电池驱动电机 |
| PHEV | 插电式混合动力车，发动机+电机双动力可外充 |
| HEV | 油电混合动力车，发动机为主电机辅助不可外充 |
| 三电系统 | 电池、电机、电控三大核心系统的统称 |
| BMS | 电池管理系统，监控保护均衡电池 |
| FOC | 磁场定向控制，电机矢量控制方法 |
| OBC | 车载充电机，交流充电时 AC→DC |
| CTP | 电芯直集成电池包，跳过模组 |
| CTC | 电芯直集成底盘，电池即车身 |
