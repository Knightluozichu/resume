## 学习目标

- 理解 BEV、PHEV、HEV 三大新能源汽车类型的架构差异
- 掌握三电系统（电池、电机、电控）的概念与角色
- 理解不同类型车辆的能量流动路径
- 建立新能源汽车整车认知框架

## 核心概念

### 新能源汽车三大类型

新能源汽车按动力系统架构分为三大类型，核心区别在于发动机有无、电池容量大小和外接充电能力：

1. **BEV 纯电动**：仅由动力电池驱动电机，无发动机、零排放、可外接充电，纯电续航 400-700km
2. **PHEV 插电混动**：发动机+电机双动力，电池中等容量，可外接充电，纯电续航 50-150km
3. **HEV 油电混动**：发动机为主力、电机辅助，电池小容量，不可外接充电，纯电续航 1-5km

### 三电系统

新能源汽车的核心是「三电系统」——电池、电机、电控，取代了燃油车的「三大件」——发动机、变速箱、底盘：

- **电池**：能量存储单元，化学能与电能相互转换，是整车的「油箱」
- **电机**：能量转换单元，电能与机械能相互转换，是整车的「发动机」
- **电控**：能量管理单元，包含逆变器、MCU、BMS 等，是整车的「大脑」

### 能量流动路径

三种类型的能量流动路径截然不同：

- **BEV**：电网 → 电池 → 电机 → 车轮（纯电驱动，无发动机参与）
- **PHEV**：油/电 → 电池 → 发动机/电机 → 车轮（双动力串联或并联）
- **HEV**：燃油 → 发动机 → 电机辅助 → 车轮（发动机为主，电机辅助）

### 核心特征对比

| 特征 | BEV | PHEV | HEV |
|------|-----|------|-----|
| 纯电续航 | 400-700km | 50-150km | 1-5km |
| 外接充电 | 是 | 是 | 否 |
| 发动机 | 无 | 有 | 有 |
| 排放 | 零排放 | 低排放 | 较低排放 |

## 术语表

| 术语 | 含义 |
|------|------|
| BEV | 纯电动汽车（Battery Electric Vehicle） |
| PHEV | 插电式混合动力车（Plug-in Hybrid EV） |
| HEV | 油电混合动力车（Hybrid EV） |
| 三电系统 | 电池、电机、电控三大核心系统 |
| 能量流动 | 能量从源头到车轮的传递路径 |
| 再生制动 | 电机反转发电回收制动能量 |
| 串联混动 | 发动机仅发电不直接驱动车轮 |
| 并联混动 | 发动机和电机均可直接驱动车轮 |
