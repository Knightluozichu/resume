## 学习目标

- 掌握电池系统电芯→模组→电池包的三级结构
- 理解磷酸铁锂（LFP）与三元锂（NCM）化学体系的差异
- 了解半固态/固态电池的技术方向
- 掌握 CTP 与 CTC 结构创新的原理与优势

## 核心概念

### 电池系统三级结构

新能源汽车的动力电池采用三级层级结构，从最小单元到完整总成逐级集成：

1. **电芯 Cell**：最小单元，额定电压约 3.7V，实现化学能与电能的转换。按形态分为圆柱、方形、软包三种
2. **模组 Module**：中间单元，由多个电芯串并联组成（如 4P12S），含汇流排、采样板和模组框架，电压约 48V
3. **电池包 Pack**：完整总成，由 12-24 个模组组成，含 BMS 采集板、高压分配盒、液冷管路、防护结构（IP67+），电压约 400V

### 电芯化学体系

主流电芯化学体系决定了电池的能量密度、安全性、成本和寿命：

- **磷酸铁锂 LFP**：能量密度中（约 160Wh/kg），安全性高（热稳定性好），成本低，循环寿命长（3000+次），适合经济型车型
- **三元锂 NCM**：能量密度高（约 250Wh/kg），安全性中，成本高，循环寿命中（2000次），适合长续航车型
- **半固态/固态电池**：能量密度极高（350+Wh/kg），安全性极高（不可燃电解质），成本很高，尚在量产探索阶段

### 串并联设计

电芯通过串联（S）和并联（P）组合达到所需的电压和容量：

- 串联提升电压但不增加容量（V = N x 3.7V）
- 并联提升容量但不增加容量（C = N x 单电芯容量）
- 4P12S 表示 12 串 4 并，总电芯数 48 个，电压约 44.4V（模组级）

### CTP 与 CTC 结构创新

传统三级结构正在被结构创新打破：

- **CTP（Cell to Pack）**：跳过模组层级，电芯直接集成到电池包，减少结构件，体积利用率提升 15-20%
- **CTC（Cell to Chassis）**：电芯直接集成到车身底盘，电池包成为车身结构件，进一步减重提升空间利用率

## 术语表

| 术语 | 含义 |
|------|------|
| 电芯 Cell | 电池最小单元，约 3.7V |
| 模组 Module | 电芯串并联组合，含管理组件 |
| 电池包 Pack | 完整高压总成，含防护与热管理 |
| LFP | 磷酸铁锂，安全性高成本低 |
| NCM | 三元锂，能量密度高 |
| 能量密度 | 单位质量/体积存储的能量 |
| CTP | 电芯直集成电池包 |
| CTC | 电芯直集成底盘 |
| IP67 | 防尘防水等级 |
