## 核心概念

### 主流驱动电机类型

新能源汽车驱动电机主要有三种类型，永磁同步电机（PMSM）是绝对主流：

1. **永磁同步 PMSM**：转子使用永磁体，效率 95-97%，功率密度最高，绝大多数 NEV 首选
2. **交流异步 ACIM**：转子鼠笼绕组，效率 90-93%，可靠性高成本低，Tesla 早期双电机后轴
3. **开关磁阻 SRM**：转子凸极铁芯，效率 88-92%，成本最低，商用车探索阶段

PMSM 成为首选的核心原因：效率最高（直接影响续航）、功率密度最高（体积小重量轻）、扭矩响应快（加速性能好）。缺点是依赖稀土材料成本较高。

### FOC 矢量控制

FOC（Field Oriented Control）是永磁同步电机的核心控制方法，通过坐标变换将交流电机等效为直流电机控制：

**控制链路**：速度指令 → PI 调节器 → Park 逆变换 → SVPWM → 逆变器 → 驱动电机

**反馈环路**：编码器/旋变 → Clarke/Park 变换 → Id/Iq 实际值

**坐标变换**：
- **Clarke 变换**：三相电流（ia/ib/ic）→ 两相静止坐标（iα/iβ），减少变量维度
- **Park 变换**：两相静止坐标（iα/iβ）→ 旋转坐标（Id/Iq），实现直流解耦
- **Id 控制磁通**，**Iq 控制转矩**，解耦后可像直流电机一样独立精确控制

### 再生制动

再生制动是新能源汽车的核心优势之一：

- **原理**：车辆减速时电机切换为发电机模式，车轮驱动电机发电，动能 → 电能 → 充入电池
- **协调策略**：中高速缓制动优先再生（回收效率高），紧急制动再生+液压同时工作，低速时液压补足
- **挑战**：再生量随 SOC 和温度变化，需动态调整液压补偿保证踏板感一致性

## 术语表

| 术语 | 含义 |
|------|------|
| PMSM | 永磁同步电机，转子永磁体 |
| ACIM | 交流异步电机，鼠笼绕组 |
| SRM | 开关磁阻电机，凸极铁芯 |
| FOC | 磁场定向控制，矢量控制方法 |
| Clarke 变换 | 三相→两相静止坐标变换 |
| Park 变换 | 静止→旋转坐标变换 |
| SVPWM | 空间矢量脉宽调制 |
| Id/Iq | 磁通电流/转矩电流 |
| 再生制动 | 电机发电回收制动能量 |
