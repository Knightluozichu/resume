## 核心概念

### 纯电专属平台 vs 油改电

纯电专属平台从零开始为电动汽车设计，相比在燃油车底盘上改造（油改电）有显著优势：

**纯电专属平台优势**：
- 电池包满铺底盘无中央通道限制，空间利用率高
- 轴距加长（无传动轴限制），后排空间大
- 重心降低（电池包底部贴地），操控性和稳定性提升
- 前后备箱均有储物空间（无发动机舱占用）
- 碰撞安全设计从零优化（电池包防撞结构）

**油改电局限**：电池包受限于燃油车底盘形状（排气管、传动轴通道），容量和空间受限。

### 滑板底盘

滑板底盘是将电池+电机+底盘一体化的扁平平台，是下一代架构方向：

- **CTC 电池即底盘**：电池包成为车身结构件的一部分
- **线控底盘**：转向/制动/驱动全部电信号控制，无机械连接
- **上下车体解耦**：底盘通用，上车体可换，缩短研发周期
- **前后双电机模块化**：支持前驱/后驱/四驱灵活配置

### 底盘四大系统

底盘由四大系统构成，新能源汽车在多个方面有革命性变化：

1. **驱动系统**：电机+减速器取代发动机+变速箱，简化结构，单/双电机前驱/后驱/四驱
2. **悬架系统**：前麦弗逊/双叉臂，后多连杆/扭力梁，高端配置空气悬架+CDC 自适应阻尼
3. **转向系统**：电动助力 EPS → 线控转向 SBW（去机械连接，可变传动比）
4. **制动系统**：液压盘式 + 再生制动（能量回收）+ 线控制动 One-Box（集成化）

### 车身结构特点

新能源汽车车身设计有三个重点方向：

- **轻量化材料**：铝合金+高强钢+碳纤维组合，减重提升续航
- **碰撞安全设计**：电池包防撞结构+溃缩吸能区，保护电池和乘员
- **空气动力学**：底盘平整化+主动进气格栅+低风阻造型，降低风阻系数提升高速续航

## 术语表

| 术语 | 含义 |
|------|------|
| 油改电 | 在燃油车底盘上改装为电动车 |
| 纯电平台 | 从零为电动汽车设计的底盘平台 |
| 滑板底盘 | 电池+电机+底盘一体化的扁平平台 |
| CTC | 电芯直集成底盘，电池即车身 |
| 线控底盘 | 转向/制动/驱动全电信号控制 |
| EPS | 电动助力转向 |
| SBW | 线控转向（Steer by Wire） |
| One-Box | 制动系统一体化集成 |
| 空气悬架 | 利用空气弹簧调节高度和阻尼 |
