## 学习目标

- 掌握新能源汽车高压安全的五道防线
- 理解热失控五级防护链与最终目标
- 了解 ISO 26262 功能安全与 SOTIF 预期功能安全的区别
- 掌握 E/E 架构从分布式到车云一体的四阶段演进

## 核心概念

### 高压安全

新能源汽车高压系统（400V/800V）必须有多重安全保障：

1. **绝缘检测**：实时监测高压系统对地绝缘电阻，低于阈值报警
2. **高压互锁 HVIL**：高压连接器断开时自动切断回路，防止触电
3. **主动/被动放电**：断电后主动释放高压电容残余电量，被动放电电阻兜底
4. **碰撞断电 MSD**：碰撞传感器触发手动维护开关 MSD 熔断，瞬间切断高压
5. **漏电保护 + 等电位**：车身等电位搭接防止电位差触电

### 热失控防护链

电池热失控是最大安全风险，通过五级防护链层层阻隔：

- **电芯级**：正温度系数材料抑制过流
- **模组级**：隔热云母板阻隔热蔓延
- **包级**：泄压阀定向排气 + 防火涂层延缓
- **系统级**：BMS 熔断 + 报警 + 主动降温
- **整车级**：乘员舱隔离 5 分钟以上，为逃生争取时间

最终目标：热失控后 5 分钟内无明火进入乘员舱（国标要求）。

### 功能安全

- **ISO 26262**：针对电子电气系统故障（硬件/软件失效），通过 HARA 确定 ASIL 等级（A-D），采用冗余设计（双 MCU、双传感器）确保故障安全降级
- **SOTIF（ISO 21448）**：针对系统功能不足（非硬件故障，如感知算法在雨雾中误识别），通过场景分析识别不安全触发条件
- **ISO 21434**：网络安全，防止车载系统被远程入侵

### E/E 架构演进

汽车电子电气架构经历四个阶段演进：

1. **分布式架构**：ECU 100+ 个，功能独立，线束复杂
2. **域集中架构**：5 大域控制器（动力/底盘/座舱/智驾/车身）
3. **中央集中架构**：中央计算 + 区域控制器，以太网骨干 + SOA
4. **车云一体架构**：云端大模型协同，OTA 持续迭代

### 未来趋势

- **智能驾驶**：L2 → L3 → L4 演进，感知+决策+执行，域控制器集中化
- **固态电池**：能量密度 400+Wh/kg，不可燃电解质，2027+ 量产预期
- **800V/超充**：充电 5 分钟 200km，SiC 功率器件普及
- **V2X 车网互联**：V2G 反向供电、V2V 车车互充、V2L 外放电

## 术语表

| 术语 | 含义 |
|------|------|
| HVIL | 高压互锁，连接器断开自动断电 |
| MSD | 手动维护开关，碰撞熔断断电 |
| 热失控 | 电池自加热链式反应导致起火 |
| ISO 26262 | 功能安全标准，ASIL A-D 等级 |
| SOTIF | 预期功能安全（非故障类不安全） |
| ASIL | 汽车安全完整性等级 |
| E/E 架构 | 电子电气架构 |
| SOA | 面向服务的架构 |
| OTA | 空中下载升级 |
