## 直觉引入

你要比较两个算法哪个快。一个跑 3n 步，另一个跑 5n 步。在 n=10 时差距明显，但在 n=100万时，两个都是"线性级别"——常数因子被输入规模淹没。渐近分析就是忽略常数因子和低阶项，只看"增长趋势"：O(n) 比 O(n^2) 快，无论常数多大。

递归是分治算法的自然表达。归并排序把数组分两半各排再合并，T(n)=2T(n/2)+O(n)。怎么求解这种递归式？主定理给出了一刀切的公式。

## 概念讲解

### 渐近记号

<IalFoundationsDiagram />

<Term def="f(n)=O(g(n)) 表示存在常数 c 和 n0，使所有 n>n0 有 f(n)≤c·g(n)，即上界">
大O记号
</Term>

O 是上界，Ω 是下界，Θ 是紧确界（上下界同阶）。f(n)=Θ(g(n)) 当且仅当 f(n)=O(g(n)) 且 f(n)=Ω(g(n))。实践中用 Θ 表示精确复杂度，O 表示"不超过"。

### 主定理

<Term def="求解 T(n)=aT(n/b)+f(n) 形式递归式的通用定理，分三种情况比较 f(n) 与 n^(log_b a)">
主定理
</Term>

主定理比较 f(n) 与 n^(log_b a)：若 f(n) 多项式小于则 T(n)=Θ(n^(log_b a))；若同阶则 T(n)=Θ(n^(log_b a)·log n)；若多项式大于则 T(n)=Θ(f(n))。

<Step title="第一步：渐近记号">O=上界，Ω=下界，Θ=紧确界。2n^2+3n=Θ(n^2)，忽略常数和低阶项。</Step>
<Step title="第二步：代入法">猜 T(n)=O(n log n)，用数学归纳法证明 T(n)≤c·n·log n。</Step>

## 代码对照

```python
# 归并排序：T(n) = 2T(n/2) + O(n)
# 用主定理分析：a=2, b=2, f(n)=n, n^(log_2 2)=n^1=n
# f(n)=Θ(n^(log_b a)) → 情况2 → T(n)=Θ(n log n)

def merge_sort(a):
    if len(a) <= 1: return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])    # T(n/2)
    right = merge_sort(a[mid:])   # T(n/2)
    return merge(left, right)     # O(n)

def merge(a, b):
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]: result.append(a[i]); i += 1
        else: result.append(b[j]); j += 1
    result.extend(a[i:]); result.extend(b[j:])
    return result
```

## 常见误区

<Callout type="trap">
**现象：说"快排是 O(n log n)"但不准确。**
原因 → 快排平均 O(n log n)，最坏 O(n^2)。大O只是上界，应说平均 Θ(n log n)。
修法 → 区分最坏、平均、最好情况，用 Θ 表示紧确界。
</Callout>

<Callout type="trap">
**现象：主定理情况判断错误。**
原因 → 没注意"多项式大于/小于"的条件，特别是情况3的正则条件 af(n/b)≤kf(n)。
修法 → 先算 n^(log_b a)，再与 f(n) 比较。情况3还需验证正则条件。
</Callout>

<Exercises>
**问题 1**：主定理的三种情况分别在什么条件下适用？

<Answer>
情况1：f(n)=O(n^(log_b a - ε))，f(n) 多项式小于 n^(log_b a)，则 T(n)=Θ(n^(log_b a))。情况2：f(n)=Θ(n^(log_b a))，同阶，则 T(n)=Θ(n^(log_b a)·log n)。情况3：f(n)=Ω(n^(log_b a + ε)) 且满足正则条件 af(n/b)≤kf(n) (k<1)，则 T(n)=Θ(f(n))。
</Answer>

**问题 2**：用主定理分析归并排序 T(n)=2T(n/2)+O(n)。

<Answer>
a=2, b=2, f(n)=n。n^(log_2 2)=n^1=n。f(n)=Θ(n)=Θ(n^(log_b a))，属于情况2。因此 T(n)=Θ(n·log n)。
</Answer>
</Exercises>
