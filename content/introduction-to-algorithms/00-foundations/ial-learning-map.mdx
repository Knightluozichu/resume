## 直觉引入

算法导论（CLRS）是算法领域的"百科全书"。它的核心方法论不是"教你写代码"，而是"教你证明算法正确并分析其效率"。全书从最基础的算法分析开始，经过排序、数据结构，最终深入图算法和高级 DP，形成一套严密的算法理论体系。

如果把算法比作建筑，很多教材教你"怎么搬砖"，CLRS 教你"为什么这栋楼不会倒"——每个算法都有正确性证明和复杂度分析。

### 学习路径

先掌握渐近分析和递归求解（主定理），这是全书的数学基础。然后学排序算法理解分治和比较下界。接着进入数据结构理解如何高效组织数据。最后用图算法和 DP 解决复杂优化问题。

## 代码对照

```python
# 同一问题：在有序数组中查找元素
# 方案A：顺序查找 O(n)
def linear_search(a, key):
    for i in range(len(a)):
        if a[i] == key: return i
    return -1

# 方案B：二分查找 O(log n) — CLRS 经典范例
def binary_search(a, key):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == key: return mid
        elif a[mid] < key: lo = mid + 1
        else: hi = mid - 1
    return -1
# CLRS 强调：算法效率的差异来自问题结构（有序性）的利用
```

## 常见误区

<Callout type="trap">
**现象：只记结论不理解证明。**
原因 → CLRS 的核心价值在于严密证明，跳过证明等于丢掉精髓。
修法 → 每个算法至少理解循环不变式和正确性证明的思路。
</Callout>

<Callout type="trap">
**现象：混淆 O 和 Θ。**
原因 → O 是上界，Θ 是确界。说"算法是 O(n^2)"可能其实跑 O(n)。
修法 → 用 Θ 表示紧确界，O 只在只需要上界时使用。
</Callout>

<Exercises>
**问题 1**：CLRS 与其他算法教材的核心区别是什么？

<Answer>
CLRS 的核心区别在于严密性：每个算法都有正确性证明（通常用循环不变式）和完整的复杂度分析（渐近记号）。它不只是"教算法"，而是"教算法为什么对、为什么快"。
</Answer>

**问题 2**：全书四大板块是什么？为什么是这个顺序？

<Answer>
基础（分析工具）、排序与查找（经典范式）、数据结构（数据组织）、高级算法（图论+DP）。基础提供数学语言，排序是分治入门，数据结构是后续算法的基础设施，高级算法综合运用前三者。
</Answer>
</Exercises>
