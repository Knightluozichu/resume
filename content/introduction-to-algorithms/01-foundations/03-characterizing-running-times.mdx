## 直觉引入：订单翻倍以后，哪条产线先扛不住

把每条生产线想象成处理一张随规模增长的订单。一号线的耗时随订单量平铺着涨，二号线却按平方涨：今天订单小，二线反而便宜，你会误判它是赢家。

渐近分析要回答的不是“今天谁快”，而是“订单一直翻倍下去，谁终将拖垮交付”。它故意忽略每台机器的脾气、常数开销和小规模时的偶然领先，只保留增长率的骨架；工程上的常数优化不是被否认，而是被安排到选好增长等级之后的下一轮比较。

这一章把“谁终将赢”翻译成可以签字画押的数学对象：一对函数、一个固定见证常数、一个覆盖阈值，再加上一条不能交换的量词顺序。

## 上界、下界与紧确界

记号刻画的是函数之间的长期支配关系。设 $f$ 与 $g$ 在充分大的输入上非负，三种记号各自要求一族不等式从某个阈值起恒成立：

$$
\begin{aligned}
f\in O(g)&\Longleftrightarrow \exists\,c>0,\ \exists\,n_0>0,\ \forall\,n\ge n_0:\ 0\le f(n)\le c\,g(n),\\
f\in \Omega(g)&\Longleftrightarrow \exists\,c>0,\ \exists\,n_0>0,\ \forall\,n\ge n_0:\ 0\le c\,g(n)\le f(n),\\
f\in \Theta(g)&\Longleftrightarrow \exists\,c_1,c_2>0,\ \exists\,n_0>0,\ \forall\,n\ge n_0:\ 0\le c_1 g(n)\le f(n)\le c_2 g(n).
\end{aligned}
$$

这组式子在说：O 只要一条固定的包络线从阈值起罩住 $f$；Ω 要求 $f$ 最终压住 $g$ 的某个固定倍数；Θ 两条都要，所以 $f$ 与 $g$ 被夹在同一个增长等级里。

渐近记号的形式化定义只由三个量词零件依次搭成：先存在一个常数 $c$，再存在一个阈值 $n_0$，然后承诺对全部 $n\ge n_0$ 逐点成立。以 O 记号（O-notation）为例，一份完整证明必须同时交付三样东西：常数、阈值，以及不随 $n$ 漂移的推理链。口语里的“$f$ 迟早被 $g$ 的某个常数倍罩住”，只有把这三样补齐，才升格为可以机械检验的定理；缺任何一件，命题都还停留在印象层面。

严格地说，<Term def="用 O、Ω、Θ 与小写 o、ω 表示函数间最终支配关系的记号族；每个记号对应一个函数集合，而不是一个数值。">渐近记号</Term> 的成员都是集合，严谨写法是 $f\in O(g)$。文献里的等号写法 $f=O(g)$ 是一种约定：右端代表集合中某个未命名的成员，不能像普通等式那样左右颠倒，由 $f=O(g)$ 推不出 $g=O(f)$。

看一个具体的见证演算。取 $f(n)=3n^2+2n+1$、$g(n)=n^2$：当 $n\ge1$ 时 $2n+1\le3n^2$，所以 $f(n)\le6n^2$；同时 $f(n)\ge3n^2$ 恒成立。于是 $(c_1,c_2,n_0)=(3,6,1)$ 就是一份有效见证，$f\in\Theta(n^2)$。

<Term def="Θ 记号表达的界；f 与 g 互相被固定常数倍夹住，属于同一增长等级，但不保留精确系数。">
  紧确界
</Term>
只承诺常数倍精度：$4n^2+3n$ 与 $n^2$ 的比值趋近 4，写成 $\Theta(n^2)$ 就把这个 4
抹掉了。要预测真实延迟，必须另外保留操作成本与测量误差，不能把一条 Θ
结论当成精确公式。

由定义立刻得到 $\Theta(g)=O(g)\cap\Omega(g)$。反过来，一个函数可以拥有松上界：$n+10\in O(n^2)$ 为真但不紧确；报告结果时应给出能证明的最紧常用界，例如这里的 $\Theta(n)$。

还要区分两件事：最坏、平均、最好情形先各自产生运行时间函数 $T_{\text{worst}}(n)$、$T_{\text{avg}}(n)$、$T_{\text{best}}(n)$，然后才能对这些函数谈 $O$、$\Omega$、$\Theta$。“最坏情形是 $O(n^2)$”与“平均情形是 $\Omega(n\log n)$”是两条独立的断言，需要各自的证据。

## 量词顺序：见证必须先固定

定义的灵魂在量词顺序。O 记号的展开式是 $\exists c>0,\ \exists n_0>0,\ \forall n\ge n_0$，常数与阈值必须在“对所有后续 $n$”之前定死，之后不许反悔。

如果允许每个 $n$ 各选一个 $c(n)=f(n)/g(n)$，那么几乎每个正函数都能“通过”任何候选 $g$——每个采样点都恰好贴身通过，却没有任何一个常数能被写进 $\exists c$。量词一交换，命题就失去了区分增长率的能力。

<Term def="小写 o 表达的严格低阶关系：对每个 ε>0 都存在阈值，使 f(n) < ε·g(n)；ω 是其反向，表示 f 严格快于 g。">
  小 o 记号
</Term>
与 ω 把“同阶”进一步劈开。当极限存在且 $g$ 最终为正时，可以用比值快速判别：

$$
\lim_{n\to\infty}\frac{f(n)}{g(n)}=
\begin{cases}
0 &\Rightarrow f\in o(g)\ \text{（}f\text{ 严格更低阶）},\\
L,\ 0<L<\infty &\Rightarrow f\in \Theta(g),\\
\infty &\Rightarrow f\in \omega(g).
\end{cases}
$$

这个判别法在说：比值趋于 0 表示 $f$ 被 $g$ 甩开的速度超过任何固定倍数；趋于正有限值表示同阶；趋于无穷表示 $f$ 严格更快。它只是方便工具而不是定义本身——极限不存在时，仍要回到最终不等式。

渐近关系还自带代数结构：Θ 是自反、对称、传递的等价关系；O 与 Ω 各自传递，并满足转置对称 $f\in O(g)\iff g\in\Omega(f)$；非负函数的和由较快增长项支配，$\Theta(f_1)+\Theta(f_2)=\Theta(\max\{f_1,f_2\})$。这些性质让多步推导可以串联，但每一步都要确认函数最终非负。

## 取整与模运算：离散规模的归一化

算法面对的是整数规模。分治把 $n$ 个元素切成两半时，奇数 $n$ 切不出两个相等的半份，于是 <Term def="把实数压到不超过它的最近整数（⌊x⌋），或抬到不小于它的最近整数（⌈x⌉）；两者差不足 1。">取整函数</Term> 登场：左半 $\lfloor n/2\rfloor$ 格，右半 $\lceil n/2\rceil$ 格，恒等式 $\lfloor n/2\rfloor+\lceil n/2\rceil=n$ 保证不多不少。

取整的基本夹逼是 $\lfloor x\rfloor\le x\le\lceil x\rceil$：误差永远不足 1，所以在渐近分析里通常不改变增长等级；但在递推基例、数组下标边界和精确计数里，这个不足 1 的差就是越界与不越界的分界，不能直接删除。

模运算把任意整数归一到固定的余数集合 $a\bmod m\in\{0,1,\ldots,m-1\}$，环形缓冲区、哈希桶和周期状态都靠它定位。要当心负数：数学定义要求余数非负，$((a\bmod m)+m)\bmod m$ 给出结果；而不少语言的 `%` 是截断向零语义，$-5\bmod 4$ 在 C 风格语义下是 $-1$ 而不是 $3$。证明与代码必须用同一语义，否则负数一步就走出数组。

## 常用函数的增长等级

渐近记号需要一套化简词汇。次数为 $d$、首项系数为正的多项式满足 $p(n)\in\Theta(n^d)$：和式里最高次项支配一切低次项与常数项。指数则是另一条赛道：固定底数 $b>1$ 的 $b^n$ 最终超过任何固定次数的多项式，而且不同底数的指数之间不是常数倍差距，$2^n$ 与 $3^n$ 隔着 $(3/2)^n$ 这个无穷因子。

对数把乘法规模折算成加法层数。换底公式

$$
\log_b n=\frac{\log_a n}{\log_a b}
$$

的分母 $\log_a b$ 只是一个固定常数，所以 $\log_b n=\Theta(\log_a n)$：底数在渐近记号里可以省略，分析中写 $\lg n$（以 2 为底）只是习惯。常用恒等式 $\lg(ab)=\lg a+\lg b$、$\lg(a^k)=k\lg a$ 和 $a^{\lg_b n}=n^{\lg_b a}$ 是递归树分析的记账工具，最后一个等式专门用来把分支数改写成 $n$ 的幂。

阶乘数的是排列个数，增长快于任何固定底数指数、又慢于 $n^n$。Stirling 公式给出紧刻画：

$$
n!=\sqrt{2\pi n}\left(\frac ne\right)^n\left(1+\Theta\!\left(\frac1n\right)\right),
\qquad \lg(n!)=\Theta(n\lg n).
$$

前一行说 $n!$ 大体上是 $(n/e)^n$ 再乘一个多项式修正；取对数后 $\lg(n!)$ 与 $n\lg n$ 同阶——比较排序下界 $\Omega(n\lg n)$ 正是从“$n$ 个元素的排列有 $n!$ 种、每次比较至多砍掉一半”这条账推出来的。

<Term def="对 n 反复取对数直到结果不超过 1 所需次数；记作 lg* n，增长慢于任何 log 的固定次幂，但不是常数。">
  迭代对数
</Term>
$\lg^* n$ 把“折半再折半”的层数本身变成对象：即使 $n$ 大到写不下来，$\lg^* n$
依然是个位数量级。它出现在并查集等结构的分析里，提醒存在比任何 $\log^k n$
都慢的增长档。

Fibonacci 序列 $F_i=F_{i-1}+F_{i-2}$ 按黄金比例 $\varphi=(1+\sqrt5)/2$ 指数增长：Binet 公式 $F_i=\bigl(\varphi^i-\psi^i\bigr)/\sqrt5$（其中 $|\psi|<1$）说明 $F_i$ 与 $\varphi^i/\sqrt5$ 的相对误差指数衰减。斐波那契堆里“节点规模至少按 $F_i$ 增长、因此度数为 $O(\log n)$”这类结论，靠的就是这条指数骨架。

## 代码对照：用标准库复算见证

下面的 Python 片段只依赖标准库，与三个实验的机制一一对应：扫描器复算包络穿破点，取整/模助手复算界标与落槽。把两段合并成一个文件即可运行。

第一段是见证扫描器：对每个候选 $c$，从 $n_0$ 起逐点检查覆盖，找出第一个穿破点。它只负责找反例；要证明全称命题，仍须回到代数推导。

```python
def witness_scan(f, g, c, n0=1, n_max=64):
    """返回固定 c 从 n0 起覆盖失败的首个 n；全程覆盖则返回 None。"""
    for n in range(n0, n_max + 1):
        if f(n) > c * g(n) + 1e-9:
            return n
    return None

quad = (lambda n: 3 * n * n + 2 * n + 1, lambda n: n * n)
for c in (2, 4, 6):
    print(c, witness_scan(*quad, c))
```

输出是 `2 1`、`4 1`、`6 None`：$c=2$ 与 $c=4$ 在 $n=1$ 处就被穿破，$c=6$ 才能从 1 起全程覆盖——与实验一的扫描读数一致。

第二段复算离散归一化：两半切分、数学 floor-mod 与截断余数对照，外加一个 $n!$ 的对数版 ranking 助手（`math.lgamma` 避免大数溢出）。

```python
from math import floor, ceil, log2, lgamma

def split_halves(n):
    return floor(n / 2), ceil(n / 2)

def floor_mod(a, m):
    return ((a % m) + m) % m   # 数学语义，余数落在 [0, m)

def trunc_mod(a, m):
    return a % m               # C 风格语义，余数跟随 a 的符号

def log_factorial(n):
    return lgamma(n + 1)       # ln(n!)，排序与比较都用对数域
print(split_halves(13), floor_mod(-5, 4), trunc_mod(-5, 4))
print(round(log_factorial(64) / log2(2.718281828), 1))  # ≈ 64·lg(64/e)
```

`split_halves(13)` 给出 `(6, 7)`；`floor_mod(-5, 4)` 给出 `3` 而 `trunc_mod(-5, 4)` 给出 `-1`——这正是实验二幽灵槽的数值本尊。对数域里的 $\lg(n!)$ 与 $n\lg n$ 同阶，也印证了 Stirling 一行的读法。

## 常见误区

<Callout type="trap" title="误区：每个 n 都能配一个常数，就等于 O 成立">
  **现象：** 采样验证全绿，于是宣布 $f\in O(g)$。**原因：** 量词被偷换——允许 $c$
  随 $n$ 变化时，$c(n)=f(n)/g(n)$ 让任何正函数 trivially 通过。**修法：**
  先固定一个 $c$，再检查是否存在 $n_0$ 使覆盖对全部 $n\ge n_0$
  成立；实验一的“量词作弊”开关演示的就是这种伪证书。
</Callout>

<Callout type="trap" title="误区：取整误差不足 1，渐近里就可以删掉">
  **现象：** 写递推时直接把 $\lfloor n/2\rfloor$ 换成
  $n/2$，基例和边界一并省略。**原因：** 不足 1
  的误差在增长等级上通常无害，但在整数下标上就是半格——奇数 $n$
  的界标会切进元素中间。**修法：**
  渐近推导可放松，实现与基例必须保留取整；用实验二的 $n=9$
  切分视图核对界标两侧格数。
</Callout>

<Callout type="trap" title="误区：小 n 跑得快的一方，增长等级就低">
  **现象：** 基准只测到
  $n\le4$，线性带大常数的实现输给了二次实现，于是宣布二次算法“更快”。**原因：**
  常数与低阶项在小规模时主导读数，超越点远在测量范围之外。**修法：**
  明确报告测量区间，并用渐近分析预言区间外的格局；实验三的“小样本宣判”故障就是这类结论的墓志铭。
</Callout>

## 小结

- O 给最终上界、Ω 给最终下界、Θ 要求双边同时成立，o 与 ω 表达严格的低阶与高阶。
- 每个记号都是函数集合，证明的要件是固定见证 $c$、阈值 $n_0$ 和覆盖全部 $n\ge n_0$ 的推导。
- 取整 $\lfloor n/2\rfloor/\lceil n/2\rceil$ 管界标，模运算管落槽；负数余数语义必须前后一致。
- 多项式由最高次支配，固定底对数只差常数，指数超多项式，阶乘由 Stirling 刻画，$\lg(n!)=\Theta(n\lg n)$。
- $\lg^* n$ 比任何 $\log^k n$ 都慢却不是常数；$F_i$ 按 $\varphi^i$ 指数增长。
- 增长等级阶梯上的每个“≺”都附带前提：参与比较的参数必须固定。

## 练习

<Exercises>

1. 证明 $f(n)=4n^2+3n$ 属于 $\Theta(n^2)$：给出 $c_1$、$c_2$、$n_0$ 的一组具体取值并验证不等式链；再把见证扫描器跑到 $c=3$ 上，报告首个穿破点并解释它为什么不妨碍 $\Theta$ 结论。

   <Answer>

   下界取 $c_1=4$：$4n^2+3n\ge4n^2$ 对所有 $n\ge1$ 成立。上界取 $c_2=6$：$4n^2+3n\le6n^2$ 等价于 $3n\le2n^2$，即 $n\ge2$，故 $n_0=2$ 起成立。于是 $4n^2\le4n^2+3n\le6n^2$ 对一切 $n\ge2$ 成立，$f\in\Theta(n^2)$。

   扫描 $c=3$ 时 $4n^2+3n\le3n^2$ 即 $n^2+3n\le0$，在 $n\ge1$ 上处处失败，首个穿破点是 $n=1$。这不构成反驳：O 与 Θ 都是存在性命题，单个 $(c,n_0)$ 失败只说明这份见证无效，$(4,6,2)$ 仍然有效。

   </Answer>

2. 计算并排序：(1) $n=13$ 的两半切分格数与界标位置；(2) $-5\bmod4$ 在数学 floor-mod 与 C 截断语义下各是多少，再列出起点 $-5$、步长 $+2$ 在 4 槽环上前 4 步的落槽；(3) 按增长从慢到快排列 $\lg n$、$\sqrt n$、$n$、$n\lg n$、$n^2$、$2^n$、$n!$（$n$ 充分大）。

   <Answer>

   (1) $\lfloor13/2\rfloor=6$、$\lceil13/2\rceil=7$，界标在索引 6 之前，$6+7=13$。(2) 数学语义 $((-5\bmod4)+4)\bmod4=3$；截断语义 $-5\bmod4=-1$。起点 $-5$、步长 $+2$ 的落槽序列是 $3,1,3,1$（每步先加 2 再 floor-mod 4）。(3) 从慢到快：$\lg n\prec\sqrt n\prec n\prec n\lg n\prec n^2\prec2^n\prec n!$。其中 $\sqrt n=n^{1/2}$ 是分数次多项式，仍快于任何对数、慢于线性。

   </Answer>

3. 打开本批附带的 `body.py`，把 `WITNESS_CASES` 中 quad-mix 一行的见证常数从 6 改成 2，先预测扫描输出，再运行验证；随后对 `n+10` 对 $n^2$ 分别以 $c=2$ 和 $c=10$ 运行，说明为什么同一个 O 命题对不同 $c$ 的扫描结果不同，以及 $n_0$ 在其中扮演的角色。

   <Answer>

   quad-mix 换成 $c=2$ 后，$3n^2+2n+1\le2n^2$ 在 $n=1$ 处即失败，扫描输出首个穿破点 $1$。$n+10$ 对 $n^2$：$c=2$ 时首个穿破点是 $n=1$（$11>2$），$c=10$ 时仍在 $n=1$ 穿破（$11>10$），但从 $n_0=3$ 起覆盖成立（$n=3$ 起 $n+10\le2n^2$）。扫描总是从 $n_0=1$ 起报告第一个失败点；O 命题只要求存在某个 $(c,n_0)$ 组合，所以穿破点的存在不否定命题——它只告诉你这份见证需要调参。

   </Answer>

</Exercises>

## 名词解释

<Glossary>

<GlossaryItem term="渐近记号">表示函数间“越过某个阈值以后的支配关系”的记号族，包括 O、Ω、Θ 与严格版 o、ω；每个记号对应一个函数集合。</GlossaryItem>
<GlossaryItem term="紧确界">Θ 记号表达的界：f 与 g 互相被固定常数倍夹住，属于同一增长等级，但不保留精确系数。详见“上界、下界与紧确界”。</GlossaryItem>
<GlossaryItem term="小 o 记号">严格低阶关系：对每个 ε>0 都有阈值使 $f(n)<\varepsilon\,g(n)$，即 f/g 趋于 0；ω 是其反向。用极限比值可以快速判别。</GlossaryItem>
<GlossaryItem term="取整函数">⌊x⌋ 向下压到最近整数，⌈x⌉ 向上抬到最近整数，两者差不足 1；夹逼恒等式 ⌊x⌋≤x≤⌈x⌉ 是分治切分的边界依据。</GlossaryItem>
<GlossaryItem term="迭代对数">对 n 反复取对数直到不超过 1 的次数，记 lg* n；增长慢于任何 log 的固定次幂，但永远不是常数。详见“常用函数的增长等级”。</GlossaryItem>

</Glossary>
