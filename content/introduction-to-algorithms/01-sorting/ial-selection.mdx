## 直觉引入

找数组中第 k 小的元素，最直觉的做法是先排序再取第 k 个，O(n log n)。但你只需要一个元素，排序整个数组是浪费——就像你只想知道全班考试的中位数，不需要排名所有人。

CLRS 展示了一个精妙的算法：用类似快排的分区，但只递归有答案的那一边。如果每次 pivot 能把数组分成均匀的两半，T(n)=T(n/2)+O(n)=O(n)。关键在于如何保证 pivot 不太差——BFPRT 算法用"中位数的中位数"作为 pivot，保证最坏也是 O(n)。

## 概念讲解

### 顺序统计量

<IalSelectionDiagram />

<Term def="数组中第 i 小的元素，i=1 是最小值，i=n 是最大值，i=(n+1)/2 是中位数">
顺序统计量
</Term>

选择问题：给定数组 A[1..n] 和整数 i，找第 i 小的元素。随机化选择：随机选 pivot 分区，只递归包含目标的一侧。期望 O(n)，最坏 O(n^2)。

### BFPRT 算法

<Term def="用中位数的中位数作为 pivot 保证最坏 O(n) 的选择算法，又称"中位数的中位数"算法">
BFPRT
</Term>

将数组每 5 个一组，取每组中位数，再递归取这些中位数的中位数作为 pivot。可证明 pivot 至少大于 3n/10 个元素且小于 3n/10 个元素，保证每次分区至少排除 30% 的元素。T(n)≤T(n/5)+T(7n/10)+O(n)=O(n)。

## 代码对照

```python
# 随机化选择：期望 O(n)
import random
def randomized_select(a, lo, hi, i):
    if lo == hi: return a[lo]
    p = random.randint(lo, hi)
    a[p], a[hi] = a[hi], a[p]
    pivot = a[hi]
    # 分区
    k = lo  # k 是 pivot 的最终位置
    for j in range(lo, hi):
        if a[j] <= pivot:
            a[k], a[j] = a[j], a[k]
            k += 1
    a[k], a[hi] = a[hi], a[k]
    # 只递归有答案的一侧
    if i == k: return a[k]
    elif i < k: return randomized_select(a, lo, k-1, i)
    else: return randomized_select(a, k+1, hi, i)

# 与快排的区别：快排递归两侧，选择只递归一侧
# T(n) = T(n/2) + O(n) = O(n) vs 快排 T(n) = 2T(n/2) + O(n) = O(n log n)
```

## 常见误区

<Callout type="trap">
**现象：认为找中位数必须先排序。**
原因 → 没意识到选择问题比排序问题更简单。
修法 → 选择只需找第 k 小，不需全排序。用 randomized_select 或 BFPRT 可 O(n)。
</Callout>

<Callout type="trap">
**现象：BFPRT 实践中比随机选择慢。**
原因 → BFPRT 常数大（分组+递归取中位数），虽最坏 O(n) 但期望比随机选择慢。
修法 → 实践中用随机选择（期望 O(n)、常数小），BFPRT 的价值是理论保证。
</Callout>

<Exercises>
**问题 1**：为什么选择问题可以 O(n) 而排序需要 O(n log n)？

<Answer>
排序需要确定所有 n 个元素的相对顺序，共 n! 种排列，需 Ω(n log n) 次比较。选择只需找第 k 小的一个元素，不需要完全排序。分区后只递归一侧 T(n)=T(n/2)+O(n)=O(n)，比排序的两侧递归 T(n)=2T(n/2)+O(n)=O(n log n) 少了一半递归。
</Answer>

**问题 2**：BFPRT 如何保证 pivot 不太差？

<Answer>
将 n 个元素每 5 个一组取中位数（n/5 个），再取这些中位数的中位数作为 pivot。可证明此 pivot 至少大于 n/5 组中一半的中位数，每组中位数又大于等于 3 个元素，所以 pivot 至少大于 3(n/5)/2≈3n/10 个元素。同理小于 3n/10。因此每次分区至少排除 30% 的元素。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="顺序统计量">数组中第 i 小的元素，是最小值(i=1)、最大值(i=n)和中位数的推广。</GlossaryItem>
<GlossaryItem term="BFPRT">用中位数的中位数做 pivot 的选择算法，保证最坏 O(n)，又称"中位数的中位数"算法。</GlossaryItem>
<GlossaryItem term="随机化选择">随机选 pivot 分区只递归一侧的选择算法，期望 O(n)，最坏 O(n^2)。</GlossaryItem>
<GlossaryItem term="分区">选定 pivot 后将数组分为小于、等于、大于 pivot 三部分的操作，是快排和选择的核心。</GlossaryItem>
</Glossary>
