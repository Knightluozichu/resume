## 直觉引入

排序是算法的"Hello World"。比较排序（通过比较元素大小来排序）有一个理论极限：任何比较排序算法最坏情况下至少需要 Ω(n log n) 次比较。这是因为 n 个元素有 n! 种排列，每次比较最多排除一半，需要 log2(n!) ≈ n log n 次比较。

但如果不比较元素大小，而是利用元素本身的性质（如整数范围），就可以突破这个下界——计数排序和基数排序能达到 O(n)。代价是它们不是通用排序，只适用于特定数据类型。

## 概念讲解

### 比较排序下界

<IalSortingDiagram />

<Term def="基于元素两两比较的排序算法，最坏情况下至少需要 Ω(n log n) 次比较">
比较排序
</Term>

决策树模型：n 个元素的排列有 n! 种，决策树至少 n! 个叶节点，高度至少 log2(n!) = Ω(n log n)。因此归并、堆排、快排等比较排序都无法突破此下界。

### 堆排序与快速排序

<Term def="利用堆数据结构，反复取最大值放末尾的比较排序，O(n log n) 原地排序">
堆排序
</Term>

堆排序先建大顶堆 O(n)，再反复取堆顶（最大值）与末尾交换并下沉，共 n-1 轮每轮 O(log n)，总 O(n log n)，原地排序。

快速排序随机选 pivot，分区后递归。期望 O(n log n)，最坏 O(n^2) 但随机化后概率极低。实践中最快因为常数小且缓存友好。

## 代码对照

```python
# 快速排序（随机化 pivot）
import random

def quicksort(a, lo, hi):
    if lo < hi:
        p = partition(a, lo, hi)
        quicksort(a, lo, p - 1)
        quicksort(a, p + 1, hi)

def partition(a, lo, hi):
    # 随机选 pivot 并交换到末尾
    r = random.randint(lo, hi)
    a[r], a[hi] = a[hi], a[r]
    pivot = a[hi]
    i = lo - 1
    for j in range(lo, hi):
        if a[j] <= pivot:
            i += 1
            a[i], a[j] = a[j], a[i]
    a[i+1], a[hi] = a[hi], a[i+1]
    return i + 1

# 计数排序 O(n+k)，k 是元素范围
def counting_sort(a, k):
    count = [0] * (k + 1)
    for x in a: count[x] += 1
    for i in range(1, k+1): count[i] += count[i-1]
    result = [0] * len(a)
    for x in reversed(a):
        count[x] -= 1
        result[count[x]] = x
    return result
```

## 常见误区

<Callout type="trap">
**现象：认为 O(n log n) 是所有排序的下界。**
原因 → 混淆了比较排序和非比较排序。
修法 → Ω(n log n) 只是比较排序的下界。计数排序、基数排序利用元素值而非比较，可达 O(n)。
</Callout>

<Callout type="trap">
**现象：快排最坏 O(n^2) 为什么还说它快？**
原因 → 没理解随机化的作用。最坏情况在随机 pivot 下概率极低。
修法 → 随机化后期望 O(n log n)，且常数因子比归并小，缓存友好，实践中最快。
</Callout>

<Exercises>
**问题 1**：为什么计数排序可以突破 O(n log n) 下界？

<Answer>
O(n log n) 下界只适用于比较排序——通过元素两两比较来排序。计数排序不比较元素，而是用元素值作为数组索引直接定位，利用了元素是有限范围内整数的性质。因此不受决策树下界约束，可达 O(n+k)。
</Answer>

**问题 2**：堆排序和快速排序各有什么优劣？

<Answer>
堆排序：最坏 O(n log n) 有保证，原地排序，但常数大、缓存不友好（跳跃式访问数组）。快速排序：期望 O(n log n)，最坏 O(n^2) 但随机化后概率极低，常数小、缓存友好（顺序访问），实践中更快。需要最坏保证用堆排，追求平均速度用快排。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="比较排序">通过元素两两比较来排序的算法，最坏 Ω(n log n)。包括归并、堆排、快排等。</GlossaryItem>
<GlossaryItem term="决策树模型">将比较排序的执行过程建模为二叉树，每个叶节点对应一种排列，树高即比较次数。</GlossaryItem>
<GlossaryItem term="堆排序">利用大顶堆反复取最大值放末尾的原地排序算法，最坏 O(n log n)。</GlossaryItem>
<GlossaryItem term="计数排序">用元素值做数组索引的非比较排序，O(n+k)，k 为元素值范围，可突破比较下界。</GlossaryItem>
</Glossary>
