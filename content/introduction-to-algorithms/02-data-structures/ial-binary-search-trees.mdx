## 直觉引入

二叉搜索树（BST）就像一本字典的目录：左子树所有词比当前小，右子树所有词比当前大。查找一个词就是从根开始，比当前小往左走，比当前大往右走。如果树是平衡的（左右差不多高），查找 O(log n)。

问题是：如果按顺序插入 1,2,3,...,n，BST 会退化成一条链，查找变 O(n)。红黑树通过给节点着色并维护五条性质，保证树高最多 2log(n+1)，所有操作最坏 O(log n)。

## 概念讲解

### 二叉搜索树

<IalBinarySearchTreesDiagram />

<Term def="每个节点的左子树所有值小于该节点、右子树所有值大于该节点的二叉树">
二叉搜索树（BST）
</Term>

BST 的查找、插入、删除都是 O(h)，h 是树高。平衡时 h=O(log n)，退化为链时 h=O(n)。删除操作最复杂：被删节点有两个子节点时，找后继节点替换。

### 红黑树

<Term def="通过节点着色和旋转操作保证树高 O(log n) 的自平衡二叉搜索树">
红黑树
</Term>

红黑树五条性质：1.每个节点红或黑；2.根是黑；3.叶节点(NIL)是黑；4.红节点的子节点是黑（不能连续红）；5.任意节点到叶子的所有路径包含相同数量的黑节点（黑高相同）。这保证树高 ≤2log(n+1)。

## 代码对照

```python
# BST 查找和插入
class Node:
    def __init__(self, key):
        self.key = key
        self.left = self.right = None

def bst_search(root, key):
    while root and root.key != key:
        root = root.left if key < root.key else root.right
    return root  # O(h)，平衡时 O(log n)

def bst_insert(root, key):
    if root is None: return Node(key)
    if key < root.key:
        root.left = bst_insert(root.left, key)
    elif key > root.key:
        root.right = bst_insert(root.right, key)
    return root
    # O(h)，但顺序插入会退化成链 → 需要 RB-tree

# 红黑树：在 BST 基础上增加颜色和修复逻辑
# 旋转操作：保持 BST 性质的同时调整树形
def rotate_left(root, x):
    y = x.right
    x.right = y.left
    if y.left: y.left.parent = x
    y.parent = x.parent
    if not x.parent: root = y
    elif x == x.parent.left: x.parent.left = y
    else: x.parent.right = y
    y.left = x
    x.parent = y
    # 旋转 O(1)，红黑树插入最多 2 次旋转恢复平衡
```

## 常见误区

<Callout type="trap">
**现象：BST 顺序插入后查找变慢。**
原因 → 顺序插入使 BST 退化为链，高度 O(n)。
修法 → 用红黑树、AVL 等自平衡树，保证高度 O(log n)。
</Callout>

<Callout type="trap">
**现象：红黑树删除后性质破坏难修复。**
原因 → 删除可能违反多条性质，修复逻辑复杂。
修法 → CLRS 用 case 分析（4 种情况），通过变色+旋转逐步修复，最多 3 次旋转。
</Callout>

<Exercises>
**问题 1**：普通 BST 为什么需要红黑树？

<Answer>
普通 BST 的高度取决于插入顺序。顺序插入时退化为链，高度 O(n)，操作退化为 O(n)。红黑树通过五条性质保证高度 ≤2log(n+1)，所有操作最坏 O(log n)，不受插入顺序影响。
</Answer>

**问题 2**：红黑树的五条性质如何保证树高 O(log n)？

<Answer>
性质4（不能连续红）+性质5（黑高相同）保证：从根到叶子的最长路径（红黑交替）不超过最短路径（全黑）的 2 倍。设黑高为 bh，则节点数 n≥2^bh-1，即 bh≤log(n+1)。最长路径 ≤2bh≤2log(n+1)。因此树高 O(log n)。
</Answer>
</Exercises>

<GlossaryItem term="二叉搜索树（BST）">左子树值<节点值<右子树值的二叉树，查找/插入/删除 O(h)，平衡时 O(log n)。</GlossaryItem>
<GlossaryItem term="红黑树">通过五条着色性质保证树高 O(log n) 的自平衡 BST，操作最坏 O(log n)。</GlossaryItem>
<GlossaryItem term="旋转">保持 BST 性质的同时调整树形的操作，左旋/右旋均 O(1)，是红黑树修复的核心。</GlossaryItem>
<GlossaryItem term="黑高">从某节点到叶节点路径上的黑色节点数（不含自身），红黑树保证所有路径黑高相同。</GlossaryItem>
