## 直觉引入

栈就像一摞盘子：你只能从顶上放和取（后进先出）。队列就像排队买饭：先来的先服务（先进先出）。链表就像一串珠子：每颗珠子知道下一颗在哪，可以随时插入和摘除。

这些是最基本的数据结构，但 CLRS 用它们引入一个重要概念：amortized analysis（摊还分析）。动态数组每次满了要扩容 O(n)，但均摊到每次插入只有 O(1)——因为 n 次插入后才扩容一次。

## 概念讲解

### 栈与队列

<IalDataStructuresDiagram />

<Term def="后进先出（LIFO）的线性结构，支持 push 和 pop 操作">
栈
</Term>

栈用数组实现，push 和 pop 都是 O(1)。应用：函数调用栈、括号匹配、表达式求值。队列用循环数组实现，入队和出队 O(1)。应用：BFS、任务调度。

### 动态数组与摊还分析

<Term def="对一系列操作的总成本取平均，即使单次操作可能昂贵但整体平均廉价的分析方法">
摊还分析
</Term>

动态数组满时扩容两倍。单次扩容 O(n)，但 n 次插入才扩容一次，总成本 O(n)+O(n)=O(2n)，均摊每次 O(1)。CLRS 用"聚合法""核算法""势能法"三种方式分析。

## 代码对照

```python
# 动态数组栈：push 均摊 O(1)
class DynamicStack:
    def __init__(self):
        self.data = [None] * 1
        self.top = 0

    def push(self, x):
        if self.top == len(self.data):  # 满了，扩容
            new_data = [None] * (2 * len(self.data))
            for i in range(self.top):
                new_data[i] = self.data[i]
            self.data = new_data
        self.data[self.top] = x
        self.top += 1

    def pop(self):
        self.top -= 1
        return self.data[self.top]

# 摊还分析：n 次 push，扩容发生在 1,2,4,8,... 次时
# 总复制成本 = 1+2+4+...+n = 2n-1 = O(n)
# 均摊每次 push = O(n)/n = O(1)
```

## 常见误区

<Callout type="trap">
**现象：认为动态数组 push 是 O(n)。**
原因 → 只看单次最坏（扩容时 O(n)），忽略均摊。
修法 → 用摊还分析：n 次 push 总成本 O(n)，均摊每次 O(1)。
</Callout>

<Callout type="trap">
**现象：循环队列判空判满搞混。**
原因 → front==rear 既可能是空也可能是满。
修法 → 留一个空位：(rear+1)%size==front 为满，front==rear 为空。或用 count 变量。
</Callout>

<Exercises>
**问题 1**：动态数组扩容为什么 amortized O(1)？

<Answer>
扩容发生在 size=1,2,4,...,2^k 时，每次扩容复制 2^i 个元素。n 次 push 的总复制成本 = 1+2+4+...+2^k ≤ 2n。加上 n 次 push 本身 O(n)，总 O(3n)，均摊每次 O(1)。
</Answer>

**问题 2**：栈和队列的核心区别是什么？各适合什么场景？

<Answer>
栈是 LIFO（后进先出），队列是 FIFO（先进先出）。栈适合需要"回退"的场景：函数调用、DFS、括号匹配。队列适合"公平"的场景：BFS、任务调度、缓冲区。底层都是数组，区别在于操作端不同。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="栈">后进先出（LIFO）的线性结构，push 和 pop 均 O(1)，用于函数调用栈、DFS 等。</GlossaryItem>
<GlossaryItem term="队列">先进先出（FIFO）的线性结构，入队出队 O(1)，用于 BFS、任务调度。</GlossaryItem>
<GlossaryItem term="摊还分析">对一系列操作取平均成本的分析方法，即使单次操作可能昂贵，整体均摊可能廉价。</GlossaryItem>
<GlossaryItem term="动态数组">容量满时自动扩容的数组，push 均摊 O(1)，支持随机访问 O(1)。</GlossaryItem>
</Glossary>
