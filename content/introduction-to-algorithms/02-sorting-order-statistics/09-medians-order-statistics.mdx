## 从“只要第i小，为什么要排完整数组”开始

先预测：求100万个数的中位数，先排序需要$\Theta(n\lg n)$比较；是否存在只做$\Theta(n)$工作的算法？存在。选择算法利用partition一次确定主元秩，然后只保留包含目标秩的一侧，另一侧无需内部有序。

统一了最小值、最大值、分位数和中位数。


当$n$为奇数，中位数秩为$(n+1)/2$；当$n$为偶数，CLRS区分秩$n/2$的lower median与秩$n/2+1$的upper median。统计学中有时取二者平均，但这可能不是输入元素，算法contract必须先选定义。

## 9.1 Minimum and maximum

### 单独寻找最小值

维护已扫描前缀最小值，每读入一个新元素比较一次，恰好$n-1$次。这个数量也是下界：若某元素从未在比较中“输过”，它仍可能是最小值；要排除$n-1$个非最小候选，每个比较至多让一个元素输一次。


```cpp
int minimum(std::span<const int> values) {
    if (values.empty()) throw std::invalid_argument("empty input");
    int best = values.front();
    for (std::size_t i = 1; i < values.size(); ++i) {
        if (values[i] < best) best = values[i];
    }
    return best;
}
```

空输入没有最小值，应由类型或错误contract处理。重复最小键时，返回值不受影响；若返回记录身份，比较条件决定保留第一个还是最后一个最小记录。

### 同时寻找最小和最大

分别扫描需要$2n-2$次比较。让每两个元素花3次比较：一场内部比较、一场与当前minimum比较、一场与current maximum比较。


偶数$n$时先比较前两个元素初始化min与max，剩余$(n-2)/2$对各3次：

$$
1+3\frac{n-2}{2}=\frac{3n}{2}-2.
$$

奇数$n$时用首元素同时初始化min与max，剩余$(n-1)/2$对各3次，总计$3(n-1)/2$。统一上界为$\lceil3n/2\rceil-2$。配对法减少约$n/2$次比较，却仍读取每个元素，时间为$\Theta(n)$。

比较下界可用候选状态解释：每个元素起初都可能同时是min和max，一次两未知元素比较把胜者排除出min候选、败者排除出max候选。合理安排首次比较后，后续只需分别淘汰；这正是配对法的竞赛结构。

## 9.2 Selection in expected linear time

### 只递归包含目标秩的一侧

与randomized quicksort共享partition，但控制流不同。设partition后主元局部秩$k=q-p+1$：

- 若$i=k$，主元就是答案。
- 若$i\lt k$，递归左侧并保持目标秩$i$。
- 若$i\gt k$，递归右侧，新的局部秩为$i-k$。


```cpp
int randomized_select(std::vector<int>& a, int p, int r, int i, Rng& rng) {
    if (p == r) return a[p];
    int q = randomized_partition(a, p, r, rng);
    int k = q - p + 1;
    if (i == k) return a[q];
    if (i < k) return randomized_select(a, p, q - 1, i, rng);
    return randomized_select(a, q + 1, r, i - k, rng);
}
```


正确性来自partition秩语义和归纳：主元左侧每个键不大于它，右侧每个键大于它，因此目标秩只可能位于上述唯一分支。右侧秩必须减去已经排除的左侧$k-1$个元素与主元，共$k$个；漏做平移会返回错误次序。

### 期望为何是Θ(n)

最坏随机路径仍可能每次只淘汰主元，产生$\Theta(n^2)$；期望分析利用好pivot常概率出现。随机主元落在中间一半的概率至少$1/2$，此时下一子问题至多$3n/4$。等待一次好pivot的期望尝试数为常数，每次尝试总扫描当前规模。


把同一规模阶段的坏尝试合并，期望工作受几何级数控制：

$$
\mathbb E[T(n)]
\le cn+c\frac{3n}{4}+c\left(\frac34\right)^2n+\cdots
=O(n).
$$

必须加上读取或partition的$\Omega(n)$下界，所以期望时间为$\Theta(n)$。期望对算法内部随机位计算，对每个固定输入排列成立；若随机源有偏或可被对手预测，pivot秩不再均匀。

另一种精确递推按主元秩对最大递归侧取平均，也得到线性解。几何阶段证明更直观地说明：算法不要求每次都好，只要求好进展以固定概率反复出现。


## 9.3 Selection in worst-case linear time

### 五元组构造有保证的主元

随机化给期望线性，但某次运行仍可能退化。用额外线性工作换确定的pivot质量：

1. 把$n$个元素分成$\lceil n/5\rceil$组。
2. 对每组至多5个元素排序并取中位数。
3. 递归选择这些组中位数的中位数$x$。
4. 围绕$x$ partition。
5. 只在含目标秩的一侧递归。


每个完整五元组中位数有两个元素不小于它和两个不大于它。至少一半组中位数不小于$x$；排除$x$所在组和可能不满组后，可保证至少约$3n/10-6$个元素不小于$x$，对称地也有同数量不大于$x$。

$$
\min\{\#(A\le x),\#(A\ge x)\}
\ge 3\left\lfloor\frac{\lceil n/5\rceil}{2}\right\rfloor-6
\ge \frac{3n}{10}-O(1).
$$


因此partition后较大递归侧至多$7n/10+6$。算法还需递归选择约$n/5$个组中位数的中位数，分组、组内常数排序与partition总计$\Theta(n)$：

$$
T(n)\le
T(\lceil n/5\rceil)
+T(7n/10+6)
+\Theta(n).
$$


两个递归规模的渐近比例和为$1/5+7/10=9/10$，留出一成线性余量。假设较小参数满足$T(m)\le cm$，代入得到最多$0.9cn+O(c)+dn$；选择足够大$c$并用固定阈值直接排序基例，便可把线性项吸收，证明$T(n)=O(n)$。读取输入给$\Omega(n)$，所以最坏$\Theta(n)$。

### 为什么是五元组

组大小必须在“找组中位数成本”和“主元淘汰保证”之间平衡。五元组能以常数比较得到中位数，并让递归比例和严格小于1。三元组的简单分析可能得到比例和等于1，无法从同一递推推出线性；更大奇数组也能保证线性，但常数和实现复杂度提高。

的理论意义是证明选择问题无需完整排序；实践中常用quickselect并在深度异常时切换median-of-medians，兼顾平均常数与最坏保证。

```text
SELECT(A, i)
1  if A is small, sort A and return rank i
2  split A into groups of at most five and collect their medians M
3  x = SELECT(M, ceil(|M| / 2))
4  partition A into keys below, equal to, and above x
5  return x if i is in the equal block; otherwise recurse on one side
```

小输入基例的阈值只影响常数；递归正确性仍要求每次目标秩落入唯一返回分支。伪代码使用三路partition，因此重复键不会削弱淘汰保证，也不会让全相等数组继续递归。

重复键要求partition返回等值区间而非假设主元唯一。若目标秩落在等值块内可立即返回；否则从左右侧递归并按“小于块大小加等值块大小”平移秩。这样既保留正确性，也避免全相等输入反复递归。


## 小结

Chapter 9 Medians and Order Statistics把最小值、最大值、中位数和任意第$i$小统一为选择问题。最小值需要$n-1$次比较，同时找min/max可用配对法降到约$3n/2$次。RANDOMIZED-SELECT围绕随机主元partition并只递归目标侧，好pivot常概率出现使期望时间为$\Theta(n)$。

确定性SELECT把元素分成五元组，以组中位数的中位数为主元，保证两侧各淘汰约$3n/10$，递推$T(n)\le T(n/5)+T(7n/10+6)+\Theta(n)$给出最坏$\Theta(n)$。选择正确性的核心是主元秩、右侧秩平移、单侧递归和重复键等值块政策。
