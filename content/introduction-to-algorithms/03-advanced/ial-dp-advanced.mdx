## 直觉引入

CLRS 对动态规划的方法论特别清晰：1.刻画最优解的结构；2.递归定义最优解的值；3.自底向上计算；4.构造最优解。这套方法论适用于所有 DP 问题。

矩阵链乘法是 CLRS 的经典 DP 例子：矩阵 A1×A2×...×An，不同的结合顺序计算量差异巨大。比如 (A1A2)A3 和 A1(A2A3) 的乘法次数可能差几百倍。DP 找出最优结合顺序。

### 经典问题

<Term def="Ai×Ai+1×...×Aj 的最少乘法次数，按断点 k 分割为两半递归求解的 DP 问题">
矩阵链乘法
</Term>

矩阵链乘法：m[i,j]=min(m[i,k]+m[k+1,j]+p_&#123;i-1&#125;·p_k·p_j)。LCS：c[i,j]=c[i-1,j-1]+1 if x_i=y_j else max(c[i-1,j],c[i,j-1])。最优 BST：e[i,j]=min(e[i,k-1]+e[k+1,j]+w(i,j))。

<Step title="第三步：自底向上">按链长 l=2,3,...,n 填表，每个 m[i,j] 依赖更短的子链。O(n^3)。</Step>

## 代码对照

```python
# 矩阵链乘法 DP
def matrix_chain(p):
    n = len(p) - 1  # n 个矩阵
    m = [[0]*n for _ in range(n)]    # m[i][j] = Ai..Aj 最少乘法次数
    s = [[0]*n for _ in range(n)]    # s[i][j] = 最优断点

    for l in range(2, n+1):           # l = 链长
        for i in range(n-l+1):
            j = i + l - 1
            m[i][j] = float('inf')
            for k in range(i, j):     # 枚举断点
                cost = m[i][k] + m[k+1][j] + p[i]*p[k+1]*p[j+1]
                if cost < m[i][j]:
                    m[i][j] = cost
                    s[i][j] = k
    return m[0][n-1], s  # O(n^3)

# LCS 最长公共子序列
def lcs(X, Y):
    m, n = len(X), len(Y)
    c = [[0]*(n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if X[i-1] == Y[j-1]:
                c[i][j] = c[i-1][j-1] + 1
            else:
                c[i][j] = max(c[i-1][j], c[i][j-1])
    return c[m][n]  # O(mn)
```

## 常见误区

<Callout type="trap">
**现象：DP 状态定义错误导致递归依赖环。**
原因 → 子问题之间有循环依赖，无法自底向上填表。
修法 → 确保状态定义满足"子问题在原问题之前求解"，即拓扑序存在。
</Callout>

<Callout type="trap">
**现象：矩阵链乘法枚举断点遗漏。**
原因 → 断点 k 范围搞错，k 应从 i 到 j-1（不含 j）。
修法 → k∈[i,j-1]，保证左半 Ai..k 和右半 A(k+1)..j 都非空。
</Callout>

<Exercises>
**问题 1**：什么问题适合用 DP？四个步骤是什么？

<Answer>
适合 DP 的问题需要两个性质：最优子结构（最优解包含子问题最优解）和重叠子问题（子问题被重复计算）。四步：1.刻画最优解结构；2.递归定义最优解值（状态转移方程）；3.自底向上计算（填表）；4.构造最优解（回溯）。
</Answer>

**问题 2**：矩阵链乘法的时间复杂度是多少？为什么？

<Answer>
O(n^3)。有 O(n^2) 个子问题 m[i,j]（i≤j），每个子问题枚举 O(n) 个断点 k，所以总 O(n^3)。空间 O(n^2) 存表。这是典型的区间 DP 模式。
</Answer>
</Exercises>
