## 直觉引入

CLRS 不是一本"背算法"的书，而是一本"学方法论"的书。读完它，你不应该只记住 100 个算法，而应该掌握一套思维框架：看到问题先分析结构，再选范式（分治/贪心/DP/图论），然后证明正确性和分析复杂度。

这本复习章把全书的算法按"设计范式"重新组织，帮你从"记住算法"升级为"设计算法"。

## 概念讲解

### 算法设计范式

<IalFinalReviewDiagram />

<Term def="将问题分解为独立子问题分别求解再合并的算法设计范式">
分治
</Term>

全书算法可按设计范式归类：分治（归并排序、矩阵链乘）、贪心（活动选择、Huffman、最小生成树）、DP（LCS、最优BST、矩阵链乘）、图论（BFS/DFS、最短路、流网络）。每种范式有适用条件和正确性证明方法。

### 方法论总结

CLRS 的核心方法论：1.分析问题结构；2.选择设计范式；3.证明正确性（循环不变式/数学归纳）；4.分析复杂度（渐近分析/主定理/摊还分析）；5.实现与验证。

## 代码对照

```python
# 算法设计范式速查
# 1. 分治：问题可分解为独立子问题
#    归并排序 T(n)=2T(n/2)+O(n) → O(n log n)

# 2. 贪心：有贪心选择性质，局部最优→全局最优
#    活动选择：按结束时间排序，选最早结束的

# 3. DP：最优子结构+重叠子问题
#    LCS: c[i][j] = c[i-1][j-1]+1 if match else max(c[i-1][j], c[i][j-1])

# 4. 图论：BFS/DFS遍历，Dijkstra最短路，Kruskal最小生成树

# 选择原则：能贪心则贪心（最简单），不能则DP（最通用）
# 图问题用图算法，序列问题用分治或DP
```

## 常见误区

<Callout type="trap">
**现象：面对新问题不知选什么算法。**
原因 → 缺乏范式识别能力，只会套学过的具体算法。
修法 → 先分析问题结构（有无最优子结构、贪心性质等），再选范式。
</Callout>

<Callout type="trap">
**现象：会用算法但不会证明正确性。**
原因 → 跳过了 CLRS 的证明部分。
修法 → 学习循环不变式法，每个算法至少理解证明思路。
</Callout>

<Exercises>
**问题 1**：面对新问题，如何选择算法范式？

<Answer>
1.分析问题结构：有无最优子结构？子问题是否重叠？有无贪心选择性质？2.选范式：有贪心性质优先贪心（最简单高效）；有最优子结构+重叠子问题用DP；问题可分解为独立子问题用分治；涉及网络/路径/连通用图论。3.证明正确性+分析复杂度。
</Answer>

**问题 2**：全书四大板块的知识如何串联？

<Answer>
基础（渐近分析+递归）是数学语言，贯穿全书。排序与查找是分治和比较下界的经典应用。数据结构（BST/散列/红黑树）是高效算法的基础设施。高级算法（图论+DP）综合运用前三者的工具解决复杂优化问题。四者递进：语言→工具→基础设施→综合应用。
</Answer>
</Exercises>

<GlossaryItem term="循环不变式">循环每次迭代前后保持不变的性质，CLRS 证明算法正确性的核心工具。</GlossaryItem>
