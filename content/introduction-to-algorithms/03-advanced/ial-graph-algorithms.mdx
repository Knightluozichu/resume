## 直觉引入

图就像一张地铁线路图：站点是顶点，线路是边。BFS（广度优先）像水波扩散——从起点一站一站向外扩展，先到的一定是最少站数的。DFS（深度优先）像走迷宫——一条路走到黑再回头。

最短路算法是图论核心：Dijkstra 适合非负权图（像地铁票价都非负），Bellman-Ford 能处理负权（像有些线路有折扣），Floyd-Warshall 一次算出所有站点对之间的最短路（适合站点少的情况）。

## 概念讲解

### BFS 与 DFS

<IalGraphAlgorithmsDiagram />

<Term def="从源点出发逐层扩展，先访问距离近的节点的图遍历算法，用队列实现">
BFS
</Term>

BFS 用队列，先入先出，逐层扩展。在无权图中，BFS 自然得到最短路径（先到达的一定跳数最少）。O(V+E)。DFS 用栈（或递归），一条路走到底再回退，用于拓扑排序、连通分量。O(V+E)。

### 最短路算法

<Term def="对每条边松弛 |V|-1 轮，能处理负权边并检测负权环的单源最短路算法">
Bellman-Ford
</Term>

Dijkstra：贪心，每次取最小距离点确定，O((V+E)log V)。不能处理负权。Bellman-Ford：对所有边松弛 V-1 轮，能处理负权，O(VE)。第 V 轮还能松弛说明有负权环。Floyd-Warshall：DP 枚举中转点，O(V^3)，全源最短路。

## 代码对照

```python
from collections import deque

# BFS：无权图最短路
def bfs(adj, s):
    dist = {v: float('inf') for v in adj}
    dist[s] = 0
    q = deque([s])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == float('inf'):
                dist[v] = dist[u] + 1
                q.append(v)
    return dist  # O(V+E)

# Bellman-Ford：处理负权边
def bellman_ford(edges, n, s):
    dist = [float('inf')] * n
    dist[s] = 0
    for _ in range(n - 1):          # 松弛 n-1 轮
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    # 检测负环：再松弛一轮，还能更新则有负环
    for u, v, w in edges:
        if dist[u] + w < dist[v]:
            return None  # 负权环存在
    return dist  # O(VE)
```

## 常见误区

<Callout type="trap">
**现象：Dijkstra 用于负权图得到错误结果。**
原因 → Dijkstra 确定点不再更新的假设在负权下不成立。
修法 → 有负权用 Bellman-Ford。Dijkstra 只适用于非负权图。
</Callout>

<Callout type="trap">
**现象：Bellman-Ford 超时。**
原因 → O(VE) 对稠密大图太慢。
修法 → 如果无负权用 Dijkstra O((V+E)logV)。Bellman-Ford 只在需要处理负权时用。
</Callout>

<Exercises>
**问题 1**：Bellman-Ford 如何检测负权环？

<Answer>
Bellman-Ford 对所有边松弛 V-1 轮（因为最短路径最多 V-1 条边）。如果第 V 轮还能松弛任何边，说明存在可无限缩短的路径，即负权环。检测时再遍历一遍所有边，若仍有 dist[u]+w<dist[v] 则有负环。
</Answer>

**问题 2**：BFS 为什么能求无权图最短路？

<Answer>
BFS 逐层扩展，先到达的节点跳数一定最少。队列保证按距离顺序处理：距离 0 的先出队，扩展出距离 1 的入队，再出队距离 1 的扩展距离 2 的……因此第一次到达某节点时的距离就是最短跳数。
</Answer>
</Exercises>
