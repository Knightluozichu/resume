## 从“同一组值怎样支持不同操作”开始

先预测：10个元素放进数组、链表或树中，存储的值可以相同，但访问成本会一样吗？不会。数据结构把值与一组结构关系组合起来，表示方式决定哪些操作是常数时间、哪些需要遍历，以及哪些状态必须额外记录。

Elementary Data Structures先建立最基础的表示不变式。后续散列表、搜索树和图算法都会把这些结构当成组件。

## 10.1 Simple array-based data structures: arrays, matrices, stacks, queues

### Arrays and matrices

的关键不是“可以装很多值”，而是地址可计算。零基数组A中：

$$
\operatorname{address}(A[i])
=\operatorname{base}(A)+i\cdot w,
$$

其中$w$为元素宽度。只要索引已知，访问为$\Theta(1)$；在无序数组中按值搜索仍为$\Theta(n)$。


越界索引计算仍能得到某个地址，却不属于数组对象。低层语言中这会触发未定义行为或内存破坏；高层容器可能抛错。复杂度分析假设contract合法，生产接口必须单独验证边界。

矩阵可把二维索引线性化。$m\times n$矩阵按row-major存储时：

$$
\operatorname{offset}(i,j)=i\cdot n+j.
$$


column-major则为$j\cdot m+i$。两者都能常数定位，但遍历顺序决定缓存局部性：row-major应让列索引在内层连续变化。子矩阵view还需保存stride，不能假设逻辑列数等于物理行跨度。

### Stacks

用数组前缀和`top`表示。`PUSH`写入下一个空位并增大top，`POP`先检查非空再缩小top并返回原顶部。


```cpp
template<class T>
class Stack {
    std::vector<T> data_;
public:
    bool empty() const { return data_.empty(); }
    void push(T value) { data_.push_back(std::move(value)); }
    T pop() {
        if (empty()) throw std::underflow_error("empty stack");
        T value = std::move(data_.back());
        data_.pop_back();
        return value;
    }
};
```

固定容量数组需要overflow政策；动态数组push在扩容时可能$\Theta(n)$，但按几何增长可摊还$\Theta(1)$，这将在摊还分析章节严格证明。pop空栈是underflow，返回哨兵值会与合法数据冲突，通常应使用错误、optional或前置条件。

### Queues

若每次dequeue都左移数组，成本为$\Theta(n)$。环形数组用模运算让head与tail在容量范围内循环：

$$
\operatorname{next}(i)=(i+1)\bmod capacity.
$$


只存head和tail时，二者相等可能表示空，也可能表示满。常见方案是额外存`size`，或永远保留一个空槽；前者用满容量，后者状态判定更简单但可用容量少1。


```cpp
void enqueue(int value) {
    if (size == capacity) throw overflow_error{};
    buffer[tail] = value;
    tail = (tail + 1) % capacity;
    ++size;
}

int dequeue() {
    if (size == 0) throw underflow_error{};
    int value = buffer[head];
    head = (head + 1) % capacity;
    --size;
    return value;
}
```

队列不变式是逻辑第$t$个元素位于`buffer[(head+t) mod capacity]`，其中$0\le t\lt size$。每次操作只修改常数个位置和索引，因此$\Theta(1)$；并发队列还需原子顺序与可见性协议，不包含在这个顺序模型中。


## 10.2 Linked lists

### 指针表达逻辑相邻

不要求节点物理连续。头节点prev为空、尾节点next为空；内部节点$x$满足：

$$
x.next.prev=x,\qquad x.prev.next=x.
$$


按键搜索从head沿next最坏访问所有节点，$\Theta(n)$。若调用者已经持有节点$x$，在其前后插入或删除$x$只改常数个指针，$\Theta(1)$。因此“链表删除是O(1)”隐含目标handle已知；若先按值定位，总操作仍是$\Theta(n)$。


```cpp
void erase(Node* x) {
    x->prev->next = x->next;
    x->next->prev = x->prev;
    delete x;
}
```

这段代码假设边界也有有效prev/next。普通nil终点版本需要分别处理head和tail；循环使`sentinel.next`指向首节点、`sentinel.prev`指向尾节点，空表时二者都指回自己。


哨兵删除公式无需分支，但必须禁止删除sentinel本身。节点所有权也要明确：裸指针版由谁释放、迭代器删除后何时失效、节点是否能属于多个链表。垃圾回收语言省去显式free，却不能自动修复断链或多表别名。

sentinel的生命周期必须覆盖整条链表，移动容器时也要重新建立首尾节点对新sentinel的引用。调试检查可以从sentinel沿next走一圈，验证节点数与size一致、每条next/prev互逆且最终恰好回到sentinel；再反向走一圈可捕获只更新单向指针的半断链。哨兵减少操作分支，但不替代这些结构完整性检查。

单链表只存next，空间更小、前向遍历简单；已知前驱时删除为常数，但只有目标节点时通常无法找到前驱。尾插是否常数还取决于是否保存tail指针。


## 10.3 Representing rooted trees

### Parent and child pointers

有根树给每个非根节点唯一parent。只存parent数组可以常数向上走，却要扫描所有节点才能列出孩子；为每个节点保存children列表可快速向下遍历，但增加容器与维护成本。


二叉树节点保存`left`和`right`，可再存parent支持向上导航。表示不变式包括：根parent为空；每条孩子边反向parent指回当前节点；除根外每个节点恰有一个父；从任意节点沿parent最终到根，不能形成环。

递归遍历会使用与树高相同的栈空间。退化链高度$n$时可能栈溢出，可改显式栈；BFS则用队列按层访问。选择遍历结构正是本章stack和queue的组合应用。

### Arbitrary-degree rooted trees

每个节点保存动态children数组很直观，但不同节点分配不同大小。让每节点固定两个指针：

- `left-child`指向最左孩子，没有孩子则为空。
- `right-sibling`指向下一个兄弟，最后兄弟为空。


列出一个节点的全部孩子：先到left-child，再沿right-sibling链走，成本与孩子数量成正比。查找第$k$个孩子不是常数；插入最左孩子可常数完成，按给定兄弟位置插入也可常数完成。

这种编码在形状上像二叉树，但right-sibling边不是“右子树”语义。遍历原树时，访问节点后递归其第一个孩子，再沿兄弟链处理同父节点其余孩子；把二进制树遍历公式机械套用会误读层级。


## 小结

Chapter 10 Elementary Data Structures从表示决定操作成本。数组和矩阵用地址公式实现随机访问；栈在同一端后进先出；环形队列用head、tail、size和模运算实现常数enqueue/dequeue。每种数组结构都需要显式越界、underflow和overflow政策。

双向链表以next/prev表达逻辑相邻，已有handle时插入删除为常数，按键搜索仍为线性；循环哨兵消除首尾分支。有根树可用parent、二叉孩子指针或左孩子右兄弟编码，选择会改变向上、向下和按序访问成本。正确实现依赖状态不变式、所有权和边界测试，而不只是操作名称。
