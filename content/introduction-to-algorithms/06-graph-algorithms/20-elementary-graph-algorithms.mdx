## 从“同一张图为何会有两种完全不同的遍历形状”开始

先预测：从A出发，BFS先访问所有一跳neighbors，形成按distance展开的layers；DFS则沿一个neighbor走到尽头再回退，形成嵌套时间区间。它们读取同一graph，差别来自frontier policy与算法要证明的问题。

<Term def="以图表示为基础，用系统遍历得到距离、搜索森林、依赖次序和强连通分解的一组线性时间算法。">基本图算法</Term>的“线性”指$O(V+E)$，前提是adjacency-list让每个vertex与edge只被常数次检查。若使用matrix，扫描neighbors本身可能变为$\Theta(V^2)$。

## 20.1 Representations of graphs

### Lists and matrices

<Term def="用vertex集合与edge关系编码图，常见形式为按vertex列neighbors的邻接表和以二维布尔单元记录edge的邻接矩阵。">图的表示</Term>必须先声明directed、undirected、weighted、parallel edges和self-loops语义。

Adjacency list空间：

$$
\Theta(V+E)\text{ for directed graphs},
\qquad
\Theta(V+2E)=\Theta(V+E)\text{ for undirected graphs}.
$$

Undirected edge $\{u,v\}$通常在$u$与$v$的lists各出现一次；遍历时若要每条logical edge只处理一次，需要edge id或次序过滤。

<CLRS4GraphRepresentationLab />

Adjacency matrix占$\Theta(V^2)$，edge membership为$O(1)$，适合dense graph或频繁pair query。List枚举$u$ neighbors为$\Theta(deg(u))$，但判断特定edge可能线性于degree，除非额外hash/index。

<CLRS4GraphStorageLab />

Transpose $G^T$反转每条directed edge；adjacency lists可在$O(V+E)$重建。Weighted graph把neighbor entry扩为`(v,weight)`，但BFS shortest-path结论只适用于所有edge等成本的unweighted metric。

<Callout type="trap" title="无向edge只存一次也能直接BFS">
若只在一个endpoint的adjacency中存edge，另一个方向无法发现neighbor，表示语义变成有向。修法是为undirected edge保存两个incidences，或使用能从任一endpoint枚举对端的共享edge结构。
</Callout>

## 20.2 Breadth-first search

### FIFO layers

<Term def="从source用FIFO queue按非降距离探索vertices，在unweighted graph中计算最少edge数距离与最短路parent tree。">广度优先搜索</Term>维护WHITE、GRAY、BLACK lifecycle。WHITE未发现；发现时立即设distance与parent并enqueue为GRAY；出队扫描完全部neighbors后变BLACK。

```text
BFS(G, s)
1  initialize every vertex WHITE, distance infinity, parent NIL
2  color s GRAY, set s.distance = 0, enqueue s
3  while queue is not empty
4      u = dequeue
5      for each v in G.Adj[u]
6          if v is WHITE
7              color v GRAY; v.distance = u.distance + 1
8              v.parent = u; enqueue v
9      color u BLACK
```

<CLRS4BFSFrontierLab />

在任意edge $(u,v)$上，source shortest distance满足：

$$
\delta(s,v)\le\delta(s,u)+1.
$$

BFS queue中vertices距离最多相差1；当$v$首次由$u$发现时，所有更短layer已入队或处理，故$d[v]=d[u]+1=\delta(s,v)$。首次发现后不再改parent，形成breadth-first tree。

<CLRS4BFSShortestPathLab />

打印path时沿parents从target回到source再reverse。Unreachable vertex保持infinity和NIL。Adjacency-list BFS为$O(V+E)$：每个vertex最多enqueue一次，每个adjacency entry扫描一次。

## 20.3 Depth-first search

### Discovery and finish times

<Term def="沿未发现neighbor递归深入、无路后回退，并为每个vertex记录discovery和finish时间的图遍历。">深度优先搜索</Term>也生成forest。WHITE首次进入时记录$d[u]$并置GRAY；所有edges扫描完，置BLACK并记录$f[u]$。

```cpp
void dfs_visit(Vertex u) {
    color[u] = GRAY;
    discover[u] = ++time;
    for (Vertex v : adjacency[u])
        if (color[v] == WHITE) {
            parent[v] = u;
            dfs_visit(v);
        }
    color[u] = BLACK;
    finish[u] = ++time;
}
```

Parenthesis theorem说明任意vertices $u,v$的interval $[d[u],f[u]]$与$[d[v],f[v]]$要么disjoint，要么一个完整包含另一个；包含关系恰对应DFS forest ancestor：

$$
u\text{ is an ancestor of }v
\iff
d[u]\lt d[v]\lt f[v]\lt f[u].
$$

<CLRS4DFSTimestampsLab />

Directed DFS edges分tree、back、forward、cross。扫描到GRAY ancestor产生back edge；图有directed cycle当且仅当DFS存在back edge。Undirected DFS只有tree与back类别，且两个adjacency incidences不能误算成两个logical edge。

<CLRS4DFSEdgeClassLab />

DFS同样$O(V+E)$。Recursive实现还需考虑call-stack depth最坏$O(V)$；大图可用显式stack并保存“下一个neighbor index”，否则pop/push顺序可能改变finish time语义。

## 20.4 Topological sort

### Reverse finish order

<Term def="把有向无环图vertices排成线性次序，使每条edge都从较早位置指向较晚位置。">拓扑排序</Term>只对DAG存在。运行DFS，在每个vertex finish时prepend到list，等价于按$f[u]$递减排序。

对每条DAG edge $(u,v)$：

$$
f[u]\gt f[v],
\qquad
position(u)\lt position(v).
$$

若DFS从$u$看到WHITE $v$，$v$先finish；若$v$已BLACK，finish也早于$u$；若$v$GRAY则是back edge，说明graph不是DAG。

<CLRS4TopologicalOrderLab />

<CLRS4DAGCycleLab />

Topological order通常不唯一，neighbor iteration与tie policy会影响witness。验证器不应只比较一个expected array，而应检查每个vertex恰好一次且每条edge位置递增。

<Callout type="trap" title="有向图都能按finish逆序当拓扑序">
Cycle中的back edge会让某条edge违反线性次序。修法是在DFS中显式检测GRAY target；发现back edge就报告not a DAG，而不是仍输出看似完整的vertex列表。
</Callout>

## 20.5 Strongly connected components

### Two DFS passes

<Term def="有向图中任意两vertices彼此可达的最大集合；把每个集合收缩后得到无环condensation graph。">强连通分量</Term>是mutual reachability的equivalence classes。Kosaraju算法：

1. 在$G$运行DFS并记录finish times。
2. 构造transpose $G^T$。
3. 按第一遍finish time递减顺序，在$G^T$运行DFS。
4. 第二遍每棵DFS tree恰为一个SCC。

```text
STRONGLY-CONNECTED-COMPONENTS(G)
1  DFS(G) to compute finish times
2  build transpose GT
3  order vertices by decreasing finish time from the first pass
4  DFS(GT) in that order
5  output each second-pass DFS tree as one SCC
```

<CLRS4SCCPassLab />

为何顺序有效？把SCC收缩成component graph $G^{SCC}$，它必为DAG；若components之间成cycle，它们实际彼此可达，应属于同一SCC。第一遍finish order让第二遍总从transpose condensation中的source component开始，DFS无法越到尚未输出的其他component，却能覆盖本SCC全部vertices。

$$
G^{SCC}\text{ is a DAG}.
$$

<CLRS4CondensationLab />

Transpose不改变每个SCC内部的mutual reachability，只反转component之间edges。若第二遍误在原$G$上运行，可能沿outgoing component edge吞并多个SCC。两遍总时间与构造transpose均为$O(V+E)$。

## 小结

Chapter 20 Elementary Graph Algorithms从representations of graphs建立$V+E$成本模型。Breadth-first search用FIFO layers求unweighted shortest paths；depth-first search产生nested timestamps和edge classification；topological sort按reverse finish order排列DAG；strongly connected components用$G$与$G^T$两遍DFS分解directed graph。

这些算法共同依赖“每个vertex发现一次、每个adjacency entry扫描常数次”。正确性证书则各不相同：BFS是distance frontier，DFS是parenthesis intervals，topological sort是每条edge向前，SCC是condensation DAG与transpose pass。

<Exercises>

**问题 1**：无向adjacency list为何空间仍写$O(V+E)$，尽管每条edge存两次？

<Answer>
每条logical edge贡献两个adjacency entries，总entry数为$2E$。渐近记号忽略常数2，因此总空间$\Theta(V+2E)=\Theta(V+E)$；实现计数和edge processing仍需记住两个incidences。
</Answer>

**问题 2**：BFS为何在enqueue时而不是dequeue时把vertex标为已发现？

<Answer>
Enqueue时标记可阻止其他同层parents重复enqueue同一vertex，保证每个vertex只进queue一次，第一次发现的distance与parent即最短。若等到dequeue才标记，queue可能出现大量duplicates并破坏简单复杂度证明。
</Answer>

**问题 3**：DFS发现directed back edge为何能证明存在cycle？

<Answer>
Edge从当前descendant $u$指向仍GRAY的ancestor $v$，DFS tree已提供从$v$到$u$的directed tree path，再加$(u,v)$闭合成directed cycle。反之cycle上最早发现的vertex会在某条返祖edge扫描时仍为GRAY。
</Answer>

**问题 4**：SCC第二遍为何必须在transpose上按第一遍finish递减顺序？

<Answer>
Finish order选择component condensation中的正确起点，transpose反转component edges，使第二遍DFS不会越入尚未输出的其他component，同时SCC内部互达性保持。缺任一条件都可能把多个components合并或漏分。
</Answer>
