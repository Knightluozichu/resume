## 从“同一条RELAX为什么能支撑三种算法”开始

先预测：当前$d[u]=4$、edge weight为$-2$、$d[v]=7$，经过$u$可给候选2，应更新$v$并令parent为$u$。Bellman-Ford、DAG shortest paths与Dijkstra都执行这个动作；差别只是何时可以确信所有必要edges已按正确顺序relax。

令path $p=\langle v_0,\ldots,v_k\rangle$的weight为edges之和，$\delta(s,v)$为所有$s$到$v$ paths的minimum。


### Initialize and relax

所有算法先令$d[s]=0$、其他$d[v]=\infty$、parents为NIL。$d[v]$始终是某条已发现path的weight upper bound。

定义：

$$
d[v]\leftarrow\min\{d[v],d[u]+w(u,v)\}.
$$


```cpp
void relax(Vertex u, Vertex v, Weight w) {
    if (distance[u] != INF && distance[v] > distance[u] + w) {
        distance[v] = distance[u] + w;
        parent[v] = u;
    }
}
```

Guard避免infinity与负weight相加溢出。Integer实现还要检查finite addition overflow；floating point需定义epsilon与tie policy。

## 22.1 The Bellman-Ford algorithm

### Negative edges and cycle detection

允许negative edges。若不存在source-reachable negative cycle，任一shortest path可取simple path，最多$|V|-1$ edges。

```text
BELLMAN-FORD(G, w, s)
1  INITIALIZE-SINGLE-SOURCE(G, s)
2  repeat |V|−1 times
3      for each edge (u,v) in G.E
4          RELAX(u,v,w)
5  for each edge (u,v) in G.E
6      if d[v] > d[u] + w(u,v), return false
7  return true
```

第$i$轮后，只要某条shortest path的前$i$条edges已按path order被relax，其endpoint就converge。固定edge iteration可能在一轮传播多条edge，只会提前收敛，不破坏上界。


时间$O(VE)$、空间$O(V)$。若某轮没有update可early stop；这改善具体实例，不改变worst-case bound。

### Reachable negative cycles

若source可达cycle $c$且$w(c)\lt0$，绕cycle任意多次可让walk weight无界下降，affected vertices没有finite shortest path：

$$
\delta(s,v)=-\infty.
$$

在$|V|-1$轮后仍可relax的edge证明存在reachable negative cycle；unreachable negative cycle因$d[u]=\infty$不影响source problem。


## 22.2 Single-source shortest paths in directed acyclic graphs

### One topological pass

允许negative edges，因为没有cycle可反复降低weight。

```text
DAG-SHORTEST-PATHS(G, w, s)
1  topologically sort G
2  INITIALIZE-SINGLE-SOURCE(G, s)
3  for each vertex u in topological order
4      for each v in G.Adj[u]
5          RELAX(u,v,w)
```


当处理$u$时，所有可能进入$u$的path predecessors都位于topological order之前，因此$d[u]$已是$\delta(s,u)$；relax outgoing edges把正确候选传向后继。总时间$O(V+E)$，也可求critical path：把目标从min改成max或取负weights，但需同步初始化与比较方向。

## 22.3 Dijkstra's algorithm

### Settling the nearest vertex

维护settled set $S$。每轮从$V-S$ extract minimum $u$；证明$d[u]=\delta(s,u)$后永久加入$S$。


证明反设存在到$u$更短path。取该path上第一个不在$S$的vertex $y$及其settled predecessor $x$。当$x$被settle时edge $(x,y)$已relax，且nonnegative suffix保证$d[y]\le\delta(s,u)\lt d[u]$，与$u$为extract-min矛盾。

Negative edge会破坏“尚未走的suffix不会降低cost”：一个已settled vertex可能后来经负edge得到更短path，算法却不再修复。


Adjacency list加binary heap为：

$$
O((V+E)\log V)=O(E\log V)
\quad\text{for a connected graph}.
$$

Fibonacci heap理论界$O(E+V\log V)$；dense matrix加array为$O(V^2)$。Lazy priority queue可push duplicate entries并在pop时丢弃stale distance，代码简单但heap元素数与常数不同。


## 22.4 Difference constraints and shortest paths

### Constraints as edges

：

$$
x_j-x_i\le b_k
\quad\Longleftrightarrow\quad
x_j\le x_i+b_k.
$$

把constraint转为edge $(v_i,v_j)$ weight $b_k$。新增super-source $v_0$，向每个$v_i$连weight 0 edge，使全部constraint vertices reachable。


若constraint graph无negative cycle，Bellman-Ford distances给一组solution $x_i=\delta(v_0,v_i)$。Triangle inequality保证对每条edge：

$$
\delta(v_0,v_j)\le\delta(v_0,v_i)+b_k.
$$

若存在negative cycle，把cycle对应不等式相加，left变量telescopes为0，right为negative，得到不可能的$0\le w(c)\lt0$，所以system infeasible。


Constraint solutions通常不唯一；所有variables同时加常数仍保持differences。Super-source只是建立可达性，不向原system添加业务变量约束。

## 22.5 Proofs of shortest-paths properties

### Reusable proof toolkit

最短路径性质证明共享：

1. Triangle inequality：$\delta(s,v)\le\delta(s,u)+w(u,v)$。
2. Upper-bound property：任何relax sequence都保持$d[v]\ge\delta(s,v)$。
3. No-path property：若不可达，$d[v]$保持infinity。
4. Convergence property：若$d[u]=\delta(s,u)$且$(u,v)$在某shortest path上，relax后$d[v]=\delta(s,v)$。
5. Path-relaxation property：按某shortest path的edge order relax，endpoint最终converge，中间可穿插其他relax。


这些properties把算法差异缩成“何时保证shortest-path edges按可用order被处理”。Bellman-Ford枚举足够轮数，DAG用topological order，Dijkstra用nonnegative weights证明extract-min已converged。

### Predecessor subgraph

若所有reachable vertices的distances正确，且每个非source parent edge满足tightness：

$$
d[v]=d[\pi[v]]+w(\pi[v],v),
$$

parents应形成以source为root的shortest-path tree。Equal shortest paths会产生不同合法parents；tie policy决定witness但不改变distances。


验证结果时可独立检查：$d[s]=0$；每条edge满足$d[v]\le d[u]+w(u,v)$；每个finite非source vertex有tight parent edge；parent chains终止于source且无cycle。对Bellman-Ford还需报告negative-cycle status，对Dijkstra需证明weights nonnegative。


## 小结

Chapter 22 Single-Source Shortest Paths以initialize与relax统一算法。Bellman-Ford处理negative edges并检测reachable negative cycle；directed acyclic graph shortest paths用一次topological pass；Dijkstra's algorithm依赖nonnegative weights与extract-min settlement；difference constraints转为constraint graph并复用Bellman-Ford。

Proofs of shortest-paths properties通过triangle inequality、upper bound、convergence和path relaxation解释不同顺序何时足够。最终交付不只是distance array，还应包含算法前置条件、negative-cycle状态、tight predecessor witness与独立edge-inequality audit。
