## 从“为什么已经发送的flow还能撤回”开始

先预测：第一次把1 unit沿$u\to v$发送，后来发现应该走另一条route。若只看原graph，choice似乎不可撤销；residual graph会新增$v\to u$ capacity 1，允许后续augmenting path取消这1 unit并重新分配。

不是找一条最宽path，而是允许多条paths共享与竞争capacities。输出必须同时给edge flows和value，且可由cut独立验证optimality。


## 24.1 Flow networks

### Capacity and conservation

$G=(V,E)$中$c(u,v)\ge0$。标准约束：

$$
0\le f(u,v)\le c(u,v)
\quad\text{for each }(u,v)\in E.
$$

对每个$v\in V-\{s,t\}$：

$$
\sum_{u}f(u,v)=\sum_{w}f(v,w).
$$


Flow value是source净流出，也等于sink净流入：

$$
|f|=\sum_v f(s,v)-\sum_v f(v,s).
$$

若input允许antiparallel original edges，应为每个directed edge保存独立capacity与flow，再构造residual contribution；不要用单一矩阵slot覆盖两条业务edges。

### Residual networks

$G_f$对original edge $(u,v)$提供：

$$
c_f(u,v)=c(u,v)-f(u,v),
\qquad
c_f(v,u)\mathrel{+}=f(u,v).
$$


Residual reverse edge不是原network可发送的新业务方向，而是取消旧flow的记账动作。Augmentation后，若path走forward就增加original flow，走reverse就减少对应original flow。

### Cuts

一个$s$-$t$ cut $(S,T)$满足$s\in S,t\in T$。Cut capacity只sum original edges从$S$到$T$：

$$
c(S,T)=\sum_{u\in S}\sum_{v\in T}c(u,v).
$$

任意feasible flow都满足$|f|\le c(S,T)$，因为跨cut净flow等于flow value，forward flow受capacity限制，reverse flow只会降低净值。


## 24.2 The Ford-Fulkerson method

### Augmenting paths

以zero flow开始。Residual $s$-$t$ path $p$的bottleneck：

$$
c_f(p)=\min_{(u,v)\in p}c_f(u,v).
$$


```cpp
void augment(const vector<ResidualEdge>& path) {
    Capacity delta = path_min_residual(path);
    for (const auto& edge : path) {
        if (edge.is_forward) flow[edge.original] += delta;
        else flow[edge.original] -= delta;
        update_residual_pair(edge, delta);
    }
}
```


每次augmentation保持capacity与conservation，并令flow value增加bottleneck。Integer capacities下delta为positive integer，因此最多$|f^*|$次augmentation，朴素上界$O(E|f^*|)$；这是pseudo-polynomial，依赖数值而非bit length。

Path strategy很重要。对irrational capacities，任意选择的Ford-Fulkerson甚至可能不终止收敛到optimum。Edmonds-Karp每次用BFS选residual edge数最少的augmenting path，保证：

$$
O(VE^2).
$$

```text
EDMONDS-KARP(G, s, t)
1  initialize zero flow and residual graph
2  while BFS finds an s-to-t residual path p
3      delta = minimum residual capacity on p
4      augment forward and reverse residual edges by delta
5  return flow
```

### Max-flow min-cut theorem

连接算法termination与optimality。

当residual中无$s$到$t$ path，令$S$为从$s$ residual-reachable vertices，$T=V-S$。从$S$到$T$的original edges必须saturated，否则有forward residual edge；从$T$到$S$的flow必须0，否则有reverse residual edge。故：

$$
|f|=f(S,T)-f(T,S)=c(S,T).
$$

任意flow不超过任意cut，而当前flow达到一个cut上界，因此二者都optimal。


### Integrality

若capacities为integers，存在integer maximum flow，Ford-Fulkerson从zero开始会产生一份，因为每次bottleneck与flow update都integer。


Integrality不是说所有optimal flows都integer，而是至少存在一份integer optimum；linear programming solver也可能返回fractional convex combination。

## 24.3 Maximum bipartite matching

### Reduction to unit-capacity flow

将$G=(L\cup R,E)$转为flow network：

1. 新source $s$向每个$u\in L$连capacity 1。
2. 每条bipartite edge从$L$指向$R$，capacity 1。
3. 每个$v\in R$向sink $t$连capacity 1。


Unit capacities与flow conservation保证integer flow中每个left/right vertex最多通过1 unit。Matching $M$对应value $|M|$的flow；反之把flow为1的$L$到$R$ edges取出即matching。

$$
|f|=|M|.
$$


```cpp
for (const Edge& edge : bipartite_edges)
    if (flow[left(edge)][right(edge)] == 1)
        matching.push_back(edge);
```

一般max-flow算法可求maximum bipartite matching；专门算法会在第25章进一步提升并扩展到stable marriage与assignment。


## 小结

Chapter 24 Maximum Flow从flow networks的capacity、conservation、value、residual network与cut开始。Ford-Fulkerson method反复沿augmenting paths增加bottleneck，Edmonds-Karp用BFS给出polynomial bound；max-flow min-cut theorem把无augmenting path转成tight cut certificate。

Maximum bipartite matching用unit-capacity network归约，integrality让1-unit flows与matching edges一一对应。可靠交付应包含original edge flows、residual graph、value、source reachable cut与application witness，而不只是一个最大数值。
