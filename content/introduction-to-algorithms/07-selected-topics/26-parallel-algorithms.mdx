## 从“八个core为什么不一定快八倍”开始

先预测：总work 80、critical path 12，即使有无限processors也至少耗时12，最大parallelism约$80/12$；给16 cores不会获得16倍speedup。并行性能同时受work law与span law限制。

不能只数threads。正确模型先描述computation DAG，再把算法成本与scheduler和processor count组合。


## 26.1 The basics of fork-join parallelism

### Strands, spawn, and sync

把连续instruction序列压成strands，spawn/continue edges表示fork，sync dependencies表示join。

```text
PARALLEL-SUM(A, lo, hi)
1  if hi - lo is below grain, return sequential sum
2  mid = floor((lo + hi) / 2)
3  spawn left = PARALLEL-SUM(A, lo, mid)
4  right = PARALLEL-SUM(A, mid, hi)
5  sync
6  return left + right
```

漏掉sync会在`left`尚未ready时combine；把两个recursive calls都写成普通calls则保持正确却丢失parallelism。

### Work and span

 $T_1$是所有vertex cost之和，也是最优sequential simulation上界。

 $T_\infty$是critical path。

$$
T_P\ge\frac{T_1}{P},
\qquad
T_P\ge T_\infty.
$$


Parallelism：

$$
\frac{T_1}{T_\infty}
$$

是可利用processor数量的平均上限。Work-efficient要求$T_1$不比best sequential algorithm渐近更差；低span但work爆炸的算法可能实际更慢。

Greedy scheduler只要有ready strands就分配给idle processors，可保证：

$$
T_P\le\frac{T_1}{P}+T_\infty.
$$


这不包含spawn、cache、communication、NUMA和contention常数，实际测量仍需grain control。

### Parallel loops and races

Parallel for适用于iterations独立。若两iterations无同步读写同一location且至少一个write，存在data race，结果不由DAG value dependencies完全定义。


Reduction不能让所有tasks执行`sum += value`；应使用private partials再以tree combine，或使用有明确成本的atomic operation。


## 26.2 Parallel matrix multiplication

### Independent output cells

对$C=AB$：

$$
c_{ij}=\sum_{k=1}^{n}a_{ik}b_{kj}.
$$

不同$(i,j)$ cells只读$A,B$并写独立$C[i,j]$，天然race-free。


```cpp
parallel_for (int i = 0; i < n; ++i)
    parallel_for (int j = 0; j < n; ++j) {
        Value sum = 0;
        for (int k = 0; k < n; ++k)
            sum += A[i][k] * B[k][j];
        C[i][j] = sum;
    }
```

该版本work $\Theta(n^3)$，每cell inner loop sequential，span包含$\Theta(n)$ dot product，加parallel-loop scheduling depth。Parallelism约$\Theta(n^2)$，通常已足够。

若每个dot product也用balanced reduction，multiplications work仍$\Theta(n)$、span降至$\Theta(\log n)$：


$$
T_1(n)=\Theta(n^3),
\qquad
T_\infty(n)=\Theta(\log n)
$$

在理想nested parallel loops与tree reduction模型下成立，但需要temporary partials并可能增加memory traffic。Blocked matrix multiply往往因cache locality胜过理论上更细的tasks。

Recursive block multiplication必须避免8个subproducts同时累加到4个same output blocks造成races。可分两waves并sync，或给products private temporaries后parallel reduce；两者work相近，span与memory不同。


## 26.3 Parallel merge sort

### Parallel merge

的关键不是spawn两次sort，而是merge也必须有低span，否则每层linear merge沿critical path累积。

Parallel merge对两个sorted runs，选较长run median $x$，在另一run binary search lower bound；$x$的output rank由两个prefix lengths相加得到。左右subproblems读取disjoint input ranges并写disjoint output ranges。


```text
P-MERGE(A[p:r], B[q:s], T[o:])
1  choose median x from the longer input range
2  binary-search x's split point in the other range
3  place x at its exact output rank
4  spawn merge of the two lower ranges into lower output
5  merge the two upper ranges into upper output
6  sync
```


每次split让largest child至多为constant fraction，binary search花$\Theta(\log n)$ span。Standard construction有merge work $\Theta(n)$、span $\Theta(\log^2 n)$。

### Sorting recurrence

两half sorts并发，所以span只取一个half critical path，再加parallel merge：

$$
T_1(n)=2T_1(n/2)+\Theta(n)=\Theta(n\log n),
$$

$$
T_\infty(n)
=
T_\infty(n/2)+\Theta(\log^2 n)
=\Theta(\log^3 n).
$$


Parallelism为$\Theta(n/\log^2 n)$。Base cutoff应在small arrays切换sequential sort；实际实现还要复用temporary buffer，避免每recursive call allocation。

Stability要求binary-search tie policy一致：例如左run pivot在right run使用lower bound，并让equal left elements先输出。若只验证sorted multiset，可能漏掉stability regression。


## 小结

Chapter 26 Parallel Algorithms先建立the basics of fork-join parallelism：computation DAG、work、span、parallelism与greedy scheduling。Parallel matrix multiplication把output cells独立化，并可用tree reduction降低dot-product span。Parallel merge sort通过median partition生成disjoint submerges，保持$\Theta(n\log n)$ work与polylog span。

并行正确性要求dependency完整与race-free，性能要求work-efficient、span足够低且grain合理。只报告cores或task数没有意义；应交付$T_1,T_\infty,T_P$ bounds、scheduler assumptions、output ownership和practical cutoff。
