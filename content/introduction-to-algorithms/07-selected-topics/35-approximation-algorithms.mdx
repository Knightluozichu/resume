## 从“求不到最优，怎样仍给出可证明答案”开始

先预测：面对NP-hard optimization problem，输出一个feasible solution并不困难，真正困难的是回答“它离最优有多远”。不以“看起来不错”为验收标准，而是把solution、bound与proof一起交付。

近似结论至少包含四层：problem version、feasibility、performance ratio、running time。Randomized algorithm还要说明保证是expectation还是high probability；scheme还要说明accuracy parameter如何进入runtime。遗漏这些限定，经验结果再漂亮也不能替代理论保证。

### Approximation ratio

通常取$\rho(n)\ge1$。Minimization要求$C_A\le\rho(n)C^*$；maximization要求$C_A\ge C^*/\rho(n)$。也可统一写为

$$
\max\left(
\frac{C_A}{C^*},
\frac{C^*}{C_A}
\right)
\le \rho(n).
$$


Ratio是multiplicative，不等同于absolute error。若optimal value接近0，additive error小也可能对应巨大ratio；反过来，大规模instance上的constant ratio可能容许很大absolute gap。交付时最好同时报告objective、proven ratio、independent lower bound与observed gap。

### Schemes

Polynomial-time approximation scheme（PTAS）对任意fixed $\epsilon>0$给出$1+\epsilon$ minimization guarantee或$1-\epsilon$ maximization guarantee，且对fixed $\epsilon$按input size为polynomial。Fully polynomial-time approximation scheme（FPTAS）进一步要求runtime同时对input size和$1/\epsilon$为polynomial。

PTAS的runtime可以是$n^{1/\epsilon}$，所以不是FPTAS。Accuracy越高通常越慢；用户选定$\epsilon$后，certificate必须记录该值、实际runtime和最终bound。

## 35.1 The vertex-cover problem

### Maximal matching construction

（vertex-cover problem）是minimum vertex cover。一个简单algorithm反复选择任意uncovered edge $(u,v)$，把两个endpoints都放入cover，并删除所有incident edges。

```text
APPROX-VERTEX-COVER(G)
1  C = empty set
2  E' = copy of G.edges
3  while E' is not empty
4      choose any edge (u, v) from E'
5      add u and v to C
6      delete every edge incident on u or v from E'
7  return C
```


Selected edges彼此不共享endpoint，因此形成matching $M$。Algorithm输出两个endpoints，所以$|C|=2|M|$。任意vertex cover必须触碰$M$中的每条edge；matching edges disjoint，至少需要$|M|$个different vertices。

$$
|M|
\le |C^*|
\quad\Longrightarrow\quad
|C|=2|M|
\le 2|C^*|.
$$


这是2-approximation。Proof的核心不是“每轮看起来合理”，而是algorithm同时构造了一个可验证lower bound $|M|$。Matching只需maximal，不需maximum；选择顺序可改变具体cover和实际size，但worst-case factor保持2。


Weighted vertex cover不能直接按“两个endpoint都选”沿用同一cardinality proof。可使用LP relaxation、rounding或primal-dual方法，但bound必须按weights重新建立。

## 35.2 The traveling-salesperson problem

### Why metric structure matters

（traveling-salesperson problem，TSP）在arbitrary nonnegative costs下很难获得一般finite factor：missing graph edges可被编码为极大cost，任何承诺较小factor的algorithm都会区分是否存在Hamiltonian cycle。

Metric TSP要求complete undirected graph、nonnegative symmetric costs并满足triangle inequality：

$$
c(u,v)
\le c(u,w)+c(w,v).
$$


Triangle inequality允许shortcut repeated vertices而不增加cost，这是MST-based proof的关键，不是可省略的数据“常识”。现实distance若asymmetric、受turn restrictions影响或随time变化，就不能直接套用metric guarantee。

### MST preorder 2-approximation

先求minimum spanning tree $T$。任意optimal tour删除一条edge后是spanning tree，因此

$$
c(T)\le c(C^*).
$$

把$T$中每条edge走两次得到Eulerian walk，cost为$2c(T)$。按preorder或Euler walk首次出现顺序访问vertices，跳过already visited vertices，并用direct edge shortcut；triangle inequality保证cost不增加。


最终tour $C$满足

$$
c(C)
\le 2c(T)
\le 2c(C^*).
$$

Algorithm的三个证据互相独立：MST提供lower bound，doubling提供可遍历walk，metric shortcut把walk转成Hamiltonian tour。若只报告最终tour，无法确认factor；若没有triangle inequality，shortcut甚至可能使cost变大。

```text
APPROX-METRIC-TSP(G)
1  compute a minimum spanning tree T
2  walk an Euler tour of the graph formed by doubling every T edge
3  list vertices in order of first appearance
4  shortcut repeated vertices using direct metric edges
5  close the tour and return it
```

更精细的metric TSP方法可改善2这个factor，但本节要掌握的是lower bound加feasible transformation的证明模板，而不是只记一个常数。

## 35.3 The set-covering problem

### Greedy by uncovered gain

（set-covering problem）给定universe $X$和subsets family $\mathcal{F}$。Unweighted greedy每轮选择覆盖最多uncovered elements的set；weighted version选择cost除以newly covered count最小的set。

```text
GREEDY-SET-COVER(X, F)
1  U = copy of X
2  C = empty collection
3  while U is not empty
4      choose S in F maximizing |S intersect U|
5      add S to C
6      remove every element of S from U
7  return C
```


注意gain只计算尚未覆盖的elements。一个large set如果大部分内容已covered，当前marginal gain可能很小；按original set size排序会破坏greedy proof。

### Charging proof

当greedy选择覆盖$k$个new elements的set时，向每个new element收取$1/k$。每个selected set的charges总和为1，所以总charge就是algorithm选取sets数量。

考虑optimal solution中的任意set $S$，按其中elements被greedy覆盖的顺序观察。覆盖第$i$个remaining element时，$S$本身仍能覆盖至少$|S|-i+1$个new elements，因此greedy选择的set gain不小于它，该element charge至多$1/(|S|-i+1)$。于是一个optimal set承担的charges至多harmonic number。

$$
H_n
=
\sum_{i=1}^{n}\frac1i
\le \ln n+1.
$$


把optimal sets的charges相加，得到greedy使用至多$H_{|X|}\cdot OPT$个sets。更紧的bound可用maximum set size，但$\ln|X|+1$已清楚显示：set cover有logarithmic而非constant guarantee。

## 35.4 Randomization and linear programming

### Random assignment for MAX-3-CNF

（randomization and linear programming）提供两类通用工具：随机化让global objective等于local indicator expectations之和；LP relaxation把discrete feasible region扩展为fractional region，得到可计算bound，再通过rounding恢复integral solution。

在MAX-3-CNF中，目标是满足尽量多clauses。若每个clause含三个distinct variables且无trivial tautology，uniform independent assignment使特定clause失败的概率为$1/8$，满足概率为$7/8$。Linearity of expectation不要求clauses彼此independent：

$$
\mathbb{E}[X]
=
\sum_{j=1}^{m}\Pr[\text{clause }j\text{ satisfied}]
=
\frac78m
\ge
\frac78OPT.
$$


这是expected guarantee，不表示每次sample都满足至少$7m/8$ clauses。可做independent restarts并保留best run提高success probability；也可用method of conditional expectation依次固定variables，每步选择不降低conditional expected value的一侧，得到deterministic solution。


### LP relaxation and rounding

Integer program用$x_i\in\{0,1\}$表达选择；LP relaxation把它改为$0\le x_i\le1$。对于minimization，relaxed feasible region更大，所以LP optimum是integer optimum的lower bound。Rounding不是任意取整：必须证明rounded result feasible，并证明cost相对LP bound至多扩大某factor。

$$
OPT_{\mathrm{LP}}
\le
OPT_{\mathrm{integer}}
\le
C_{\mathrm{rounded}}.
$$


Vertex cover LP含每条edge constraint $x_u+x_v\ge1$。选择所有$x_v\ge1/2$的vertices会cover每条edge，cost至多fractional objective的2倍，从而得到2-approximation。这个proof也说明LP的价值：它既指导selection rule，又提供与未知OPT相连的lower bound。

Randomized rounding把fractional coordinate解释为selection probability。Expected cost容易由linearity计算，但feasibility可能只以某个probability成立，需要repetition、alteration或concentration bound。报告必须写清expected cost、failure probability和repair step。


## 35.5 The subset-sum problem

### Exact list dynamic programming

（subset-sum problem）可维护所有不超过target $t$的reachable sums。处理item $x_i$时，把旧list $L_{i-1}$与每项加$x_i$后的list合并、去重、排序，并删除超过$t$的values。


Exact list可能每轮接近翻倍，最终包含exponentially many sums。若按target建boolean table，runtime又可能对numeric target polynomial、对binary encoding pseudo-polynomial。这两种现象解释了为什么需要controlled approximation。

### Trimming near-duplicate sums

TRIM按sorted order保留第一个value，之后只保留比last retained value大超过multiplicative factor $1+\delta$的values。每个discarded value都有一个不大于它、又在multiplicative neighborhood内的representative。

```text
APPROX-SUBSET-SUM(S, target, epsilon)
1  L = [0]
2  delta = epsilon / (2 * |S|)
3  for each item x in S
4      L = sorted unique merge of L and [y + x for y in L]
5      L = TRIM(L, delta)
6      delete values greater than target
7  return the largest value in L
```


每轮trimming引入small multiplicative loss；选择$\delta=\epsilon/(2n)$控制$n$轮累计误差。最终output $z$保持feasible且

$$
z
\ge
\frac{OPT}{1+\epsilon}.
$$

（FPTAS）要求list length也被polynomially bounded。Positive sums在multiplicative buckets中逐步增长，bucket count依赖$\log t$和$1/\delta$，所以runtime对binary input length与$1/\epsilon$为polynomial。


Trimming不能保留大于target的representative代替较小feasible value；因此先保证representative不大于被discarded value，再删除超过target的values。Zeros、duplicate items和empty set也要定义清楚。

## 一份可复查的近似证书

不同算法的bound来源不同：vertex cover用matching lower bound，metric TSP用MST lower bound与triangle inequality，set cover用charging，MAX-3-CNF用expectation，LP rounding用relaxation bound，subset sum用trimming invariant。统一交付模板是feasible output、OPT proxy、ratio derivation、runtime和assumptions。


## 小结

Chapter 35 Approximation Algorithms把“polynomial time内求不到exact optimum”转成“polynomial time内交付可证明距离”。Approximation ratio需要feasible solution与OPT bound；PTAS对fixed accuracy polynomial，FPTAS还对$1/\epsilon$ polynomial。

Vertex-cover problem通过maximal matching构造2-approximation。Metric traveling-salesperson problem通过MST、doubling与triangle-inequality shortcut得到2-approximation。Set-covering problem的greedy algorithm用charging得到$H_n$ bound。Randomization用linearity of expectation分析MAX-3-CNF，conditional expectation可derandomize；linear programming用relaxation和rounding连接fractional lower bound与integral solution。Subset-sum problem用multiplicative trimming控制state explosion并形成FPTAS。

所有结论都依赖明确前提。没有metric就不能shortcut，没有lower bound就没有ratio，只给expectation不能声称每次成功，只说“用了LP”不能保证rounded feasibility。完整近似结果必须同时交付solution、checker、bound、proof、runtime和assumptions。
