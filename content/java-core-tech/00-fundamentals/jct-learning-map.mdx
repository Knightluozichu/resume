## 直觉引入

把 Java 编程想象成「建造一栋大厦」。你要先学会「砌砖」（Java基础语法——变量、类型、运算符、控制流），再用砖头搭出「房间」（面向对象——类、对象、封装、继承、多态）；有了房间需要「家具和收纳」（接口Lambda与集合泛型——函数式接口、ArrayList、HashMap、泛型类型安全）；大厦要运转需要「水电管道」（I/O流——字节流/字符流/NIO/Stream API）；人多需要「多人同时干活」（并发编程——Thread、synchronized、Lock、线程池）；要智能化需要「自动化控制系统」（高级特性——注解、反射、类加载器）；最后大厦要和「外面的世界连通」（XML与网络——DOM/SAX解析、Socket通信、HttpClient）。

## 四阶段递进

<Term def="一次编写到处运行是Java的核心承诺——源码编译成平台无关的字节码，由各平台的JVM解释或JIT编译执行，实现跨平台。">一次编写到处运行</Term>是贯穿全书的基础。全书可以拆成四个递进阶段。**基础语法与面向对象**解决「怎么写代码」和「怎么组织代码」——变量/类型/方法、类/对象/封装/继承/多态。**接口Lambda与集合泛型**解决「怎么抽象」和「怎么操作数据」——接口/default方法/Lambda、集合框架/泛型/Stream。**I/O流与并发编程**解决「怎么读写」和「怎么并发」——字节流/字符流/NIO、Thread/synchronized/线程池。**高级特性与XML网络**解决「怎么动态」和「怎么通信」——注解/反射/类加载、XML/JSON/Socket/HttpClient。

## 常见误区

<Callout type="trap">
**误区：会用 Java API 就等于懂 Java 编程。** 会写 `System.out.println`、`new ArrayList` 只是「会用 API」——照着文档抄就能做。真正懂 Java 的人能解释：为什么 String 不可变（安全+线程安全+字符串常量池）、为什么 HashMap 链表过长要转红黑树（O(n)→O(log n) 防止哈希碰撞攻击）、为什么 volatile 不保证原子性（只保证可见性，`count++` 仍是读-改-写三步）、为什么类加载要双亲委派（防止核心类被篡改）。把 Java 当黑盒的人遇到 NullPointerException 只会加 if 判空；懂机制的人知道用 Optional 或提前校验。区分标志：能否解释「Java 为什么这样设计」而非只是「能编译它」。
</Callout>

<Exercises>
**问题 1**：全书四阶段递进是什么？为什么是这个顺序？

<Answer>
基础语法与面向对象 → 接口Lambda与集合泛型 → I/O流与并发编程 → 高级特性与XML网络 → 全书复习。顺序由依赖关系决定：先掌握基本语法和面向对象思维（这是 Java 编程的地基），再学习接口抽象和集合框架（有了类才能用接口，有了泛型才能类型安全地操作集合）；IO 需要理解流和异常处理基础；并发需要理解对象和线程生命周期；高级特性如反射需要理解类加载机制；网络编程需要 IO 和并发基础来处理通信。先「会写代码」，再「能抽象」，然后「能读写」，接着「能并发」，最后「能反射和通信」。
</Answer>

**问题 2**：用「一个员工管理系统」描述全书主线。

<Answer>
一个员工管理系统经过全书多个知识点：①基础语法（第1章）——定义变量、控制流、异常处理业务逻辑；②面向对象（第2章）——设计 Employee 类封装姓名/薪资，Manager 继承 Employee 重写 getSalary 实现多态；③接口Lambda（第3章）——Comparable 排序，Comparator 用 Lambda 自定义比较；④集合泛型（第4章）——ArrayList 管理员工列表，HashMap 按部门分组，泛型保证类型安全；⑤I/O流（第5章）——try-with-resources 读写员工数据文件，Stream API 统计薪资；⑥并发（第6章）——线程池批量导入，ConcurrentHashMap 线程安全缓存；⑦高级特性（第7章）——@Entity 注解标记实体，反射动态读取字段生成报表；⑧XML与网络（第8章）——XML 导出配置，JSON API 对外提供服务。一个系统，全书知识点全部参与。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="一次编写到处运行">Java 的核心承诺。源码（.java）编译成平台无关的字节码（.class），由各平台的 JVM 解释或 JIT 编译执行。不同操作系统有各自的 JVM 实现，负责把同一份字节码翻译成平台机器指令。是 Java 跨平台的基础。</GlossaryItem>
<GlossaryItem term="四阶段递进">基础语法与面向对象 → 接口Lambda与集合泛型 → I/O流与并发编程 → 高级特性与XML网络 → 全书复习。每层解决前一层的遗留问题：基础解决「怎么写代码」，接口集合解决「怎么抽象和操作」，IO并发解决「怎么读写和并发」，高级网络解决「怎么动态和通信」。</GlossaryItem>
<GlossaryItem term="JVM">Java虚拟机。Java 字节码的运行时环境，负责加载 .class 文件、解释/编译执行字节码、管理内存（堆/栈/方法区）和垃圾回收。是「一次编写到处运行」的实现核心。</GlossaryItem>
<GlossaryItem term="JIT编译">即时编译（Just-In-Time）。JVM 运行时将热点字节码（频繁调用的方法/循环）编译为本地机器码缓存执行，大幅提升性能。混合模式：解释器启动快，JIT 运行快。</GlossaryItem>
</Glossary>
