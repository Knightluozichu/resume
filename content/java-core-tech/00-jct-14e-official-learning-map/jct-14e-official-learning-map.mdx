## 为什么从“两卷学习路径编排器”开始

《Java核心技术（第14版·全两卷）》权威学习地图要解决的不是 API 名称记忆，而是把两卷25章编排成从语言语义、标准库到边界系统的可验证学习路径，并要求每次跨章迁移都保留工具链与失败证据。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把起点知识层从“对象与类型”切换为“系统边界”，路径闭环度与跨层跳跃风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
