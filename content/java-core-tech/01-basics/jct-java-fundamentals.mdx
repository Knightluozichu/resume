## 数据类型

<Term def="Java是强类型语言,每个变量必须声明类型。8种基本类型直接存值于栈,引用类型存地址于堆。">强类型</Term>是 Java 的核心特征。

<JctJavaFundamentalsDiagram />

```java
// 基本类型: 8种, 直接存值
int age = 25;
double price = 99.99;
boolean active = true;
char grade = 'A';
long population = 7_800_000_000L;  // 下划线分隔, 需加L

// 引用类型: 存地址, 指向堆中对象
String name = "Alice";              // 不可变字符串
int[] arr = new int[5];             // 数组也是对象
Integer count = 42;                 // 包装类, 自动装箱

// == vs equals
String a = new String("hello");
String b = new String("hello");
System.out.println(a == b);        // false (不同对象, 地址不同)
System.out.println(a.equals(b));   // true  (内容相同)

// String 常量池
String c = "hello";                // 字面量进常量池
String d = "hello";
System.out.println(c == d);        // true  (同一常量池对象)
```

## 控制流与异常

```java
// 条件分支
int score = 85;
if (score >= 90) {
    System.out.println("A");
} else if (score >= 80) {
    System.out.println("B");
} else {
    System.out.println("C");
}

// switch 表达式 (Java 14+)
String grade = switch (score / 10) {
    case 9, 10 -> "A";
    case 8     -> "B";
    case 7     -> "C";
    default    -> "F";
};

// 循环
for (int i = 0; i < 5; i++) { /* 经典for */ }
for (int n : arr) { /* for-each */ }
while (condition) { /* while */ }

// 异常处理: try-catch-finally
try {
    var in = new FileInputStream("data.txt");
    // ...
} catch (FileNotFoundException e) {
    System.err.println("文件不存在: " + e.getMessage());
} catch (IOException e) {
    System.err.println("IO错误: " + e.getMessage());
} finally {
    // 总会执行 (即使有return)
}

// try-with-resources (Java 7+): 自动关闭
try (var reader = new BufferedReader(new FileReader("data.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        System.out.println(line);
    }
} // reader.close() 自动调用, 即使异常也会关闭
```

## String 与包装类

```java
// String 不可变: 每次修改创建新对象
String s = "Hello";
s = s + " World";  // 创建了新对象 "Hello World"
// 循环拼接效率低: 每次new StringBuilder + new String

// StringBuilder: 可变字符串, 单线程推荐
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(", ");
}
String result = sb.toString();

// 包装类: 基本类型 <-> 引用类型
// int->Integer  double->Double  boolean->Boolean
Integer a = 127;    // 自动装箱: Integer.valueOf(127)
Integer b = 127;
System.out.println(a == b);   // true (Integer缓存 -128~127)

Integer c = 128;
Integer d = 128;
System.out.println(c == d);   // false (超出缓存, 新对象)
System.out.println(c.equals(d)); // true (内容比较)

int n = a;          // 自动拆箱: a.intValue()
```

## 常见误区

<Callout type="trap">
**误区：用 `==` 比较 String 或 Integer 内容。** String 是引用类型，`==` 比较的是地址。`new String("a") == new String("a")` 为 false。Integer 有 -128~127 缓存，范围内 `==` 可能为 true，超出则为 false——`Integer.valueOf(128) == Integer.valueOf(128)` 为 false。正确做法：始终用 `.equals()` 比较内容。循环拼接 String 用 StringBuilder，否则每次 `+=` 都创建新 String 和临时 StringBuilder 对象。
</Callout>

<Exercises>
**问题 1**：Java 有哪些基本数据类型？基本类型和引用类型在内存中有什么区别？

<Answer>
8种基本类型：byte(1字节)、short(2)、int(4)、long(8)、float(4)、double(8)、char(2)、boolean。基本类型直接存值于栈内存，赋值是值拷贝，效率高。引用类型（String、数组、对象、包装类）存地址于栈，实际对象在堆内存，赋值是引用拷贝（指向同一对象）。基本类型有默认值（int→0, boolean→false），局部变量无默认值必须初始化。自动装箱：int→Integer（基本→包装），自动拆箱：Integer→int。Integer 有 -128~127 缓存，此范围 `==` 可能为 true。比较内容始终用 equals()。
</Answer>

**问题 2**：try-with-resources 解决了什么问题？它的原理是什么？

<Answer>
try-with-resources 解决资源泄漏和代码冗余问题。原理：声明的资源必须实现 AutoCloseable 接口，编译器自动在 try 块结束后调用 close()，即使异常也会关闭。资源关闭顺序是声明的逆序。优势：①避免忘记 close 导致泄漏；②无需 finally 手动关闭和 null 检查；③异常不被 close() 异常掩盖——try 块异常优先，close() 异常被 addSuppressed 附加。语法：`try (var in = new BufferedReader(new FileReader("f.txt"))) { ... }`。Java 9+ 支持引用外部 effectively final 变量。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="基本数据类型">Java 8 种原生类型：byte/short/int/long（整数）、float/double（浮点）、char（字符）、boolean（布尔）。直接存值于栈内存，效率高。int 是默认整数类型，double 是默认浮点类型。long 需加 L 后缀，float 需加 F 后缀。</GlossaryItem>
<GlossaryItem term="自动装箱/拆箱">Java 5+ 的自动类型转换。装箱：int→Integer（基本→包装类），拆箱：Integer→int。`list.add(42)` 自动装箱，`int n = list.get(0)` 自动拆箱。Integer 有 -128~127 缓存，valueOf 在此范围返回同一对象。大量装箱拆箱有性能开销。</GlossaryItem>
<GlossaryItem term="String不可变">String 对象创建后内容不可修改。修改操作（拼接、截取）创建新对象。不可变的好处：线程安全、可缓存 hashCode、字符串常量池复用。频繁修改用 StringBuilder（可变，单线程）或 StringBuffer（可变，线程安全）。</GlossaryItem>
<GlossaryItem term="try-with-resources">Java 7+ 语法糖。自动关闭实现 AutoCloseable 的资源，无需 finally 手动 close()。资源关闭顺序为声明逆序。try 块异常优先，close() 异常被 addSuppressed 附加。避免资源泄漏和代码冗余。</GlossaryItem>
</Glossary>
