## 类与封装

<Term def="封装是隐藏内部实现细节,暴露公共接口。Java用访问修饰符private/protected/public控制可见性。">封装</Term>是面向对象的第一支柱。

<JctOopDesignDiagram />

```java
public class Employee {
    // private: 只能本类访问——封装核心
    private String name;
    private double salary;
    private LocalDate hireDate;

    // 构造器: 初始化对象
    public Employee(String name, double salary, int year, int month, int day) {
        this.name = name;                                    // this 区分参数和字段
        this.salary = salary;
        this.hireDate = LocalDate.of(year, month, day);
    }

    // getter: 受控读取
    public String getName() { return name; }
    public double getSalary() { return salary; }
    public LocalDate getHireDate() { return hireDate; }

    // 方法: 业务逻辑
    public void raiseSalary(double byPercent) {
        double raise = salary * byPercent / 100;
        salary += raise;
    }
}
```

## 继承与多态

```java
// 父类
public class Employee {
    private String name;
    private double salary;

    public Employee(String name, double salary) {
        this.name = name;
        this.salary = salary;
    }

    public double getSalary() { return salary; }

    public String getDescription() {
        return "员工: " + name + ", 薪资: " + salary;
    }
}

// 子类: extends 继承父类
public class Manager extends Employee {
    private double bonus;

    public Manager(String name, double salary, double bonus) {
        super(name, salary);    // 调用父类构造器, 必须在第一行
        this.bonus = bonus;
    }

    public void setBonus(double bonus) { this.bonus = bonus; }

    // @Override: 重写父类方法
    @Override
    public double getSalary() {
        // super.getSalary() 调用父类版本
        return super.getSalary() + bonus;
    }

    @Override
    public String getDescription() {
        return "经理: " + getName() + ", 薪资+奖金: " + getSalary();
    }
}

// 多态: 父类引用指向子类对象
Employee[] staff = new Employee[3];
staff[0] = new Employee("Alice", 50000);
staff[1] = new Manager("Bob", 80000, 10000);
staff[2] = new Employee("Carol", 60000);

// 动态绑定: 运行时根据实际对象类型调用方法
for (Employee e : staff) {
    System.out.println(e.getDescription());
    // staff[0] -> "员工: Alice, 薪资: 50000.0"
    // staff[1] -> "经理: Bob, 薪资+奖金: 90000.0"  (调用Manager的getSalary)
    // staff[2] -> "员工: Carol, 薪资: 60000.0"
}
```

## final 与对象构造

```java
// final 类: 不能被继承
public final class String { ... }  // String 是 final

// final 方法: 不能被重写
public class Base {
    public final void coreMethod() { ... }  // 子类不能重写
}

// final 变量: 只能赋值一次
final int MAX_SIZE = 100;
MAX_SIZE = 200;  // 编译错误!
// final 引用: 引用不可变, 对象内部可变
final List<String> list = new ArrayList<>();
list.add("a");           // 合法: 修改对象内容
// list = new ArrayList<>(); // 非法: 改变引用

// 对象构造顺序: 父类静态块 → 子类静态块
//             → 父类字段初始化 → 父类构造器
//             → 子类字段初始化 → 子类构造器
public class Manager extends Employee {
    private double bonus = 1000;  // 4. 子类字段初始化

    public Manager(String name, double salary) {
        super(name, salary);       // 3. 父类构造器 (先调)
        // 5. 子类构造器体
        System.out.println("Manager created");
    }
}
```

## 常见误区

<Callout type="trap">
**误区：构造器中调用可被子类重写的方法。** 构造器执行时子类字段尚未初始化，但动态绑定会调用子类版本的方法，此时子类字段还是默认值（0/null），导致难以排查的 NPE 或错误行为。正确做法：构造器中只调 final 或 private 方法（不可重写）。另一个常见错误：忘记 `@Override` 注解——它帮助编译器检查是否正确重写，如果方法名拼错（如 `getsalary` 而非 `getSalary`），编译器会报错而非静默创建一个新方法。
</Callout>

<Exercises>
**问题 1**：封装、继承、多态分别解决什么问题？

<Answer>
封装解决「数据保护」——隐藏内部细节，用 private 字段 + getter/setter 控制访问。继承解决「代码复用」——子类 extends 父类复用字段和方法，Java 单继承。多态解决「扩展性」——父类引用指向子类对象，调用重写方法时运行时动态绑定到子类版本，新增子类类型不需改旧代码（开闭原则）。三者关系：封装是基础（先有类才能继承），继承是桥梁（先有继承才能多态），多态是目标。
</Answer>

**问题 2**：对象构造的完整过程是什么？`new Manager("Bob", 80000)` 时发生了什么？

<Answer>
①类加载：如果 Manager 未加载，先加载父类 Employee（静态初始化块和静态字段从 Object→Employee→Manager 顺序执行）；②分配内存：堆上分配，所有字段清零；③调用构造器：Manager 构造器第一行隐式或显式调 super()，执行 Employee 构造器，Employee 也先调 super() 到 Object；④初始化：从 Object 往下执行实例初始化块和字段赋值；⑤构造器体：Employee 构造器体→Manager 构造器体；⑥返回引用。注意：构造器中调用虚方法（可重写方法）会动态绑定到子类版本，但此时子类字段尚未初始化——这是构造器调用虚方法的陷阱。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="封装">隐藏内部实现细节，暴露公共接口。Java 用 private/protected/public/default 访问修饰符控制可见性。字段通常设为 private，通过 getter/setter 提供受控访问。封装的好处：数据保护、内部实现可变、降低耦合。</GlossaryItem>
<GlossaryItem term="继承">子类复用父类的字段和方法。Java 用 extends 实现单继承（一个类只能 extends 一个父类）。子类用 super 调用父类构造器和方法。所有类的根是 Object。继承是 is-a 关系：Manager is-a Employee。</GlossaryItem>
<GlossaryItem term="多态">同一接口不同实现，运行时根据实际对象类型决定调用哪个方法。三要素：继承、重写、父类引用指向子类对象。动态绑定：JVM 在运行时根据对象的实际类型（而非声明类型）查找方法。多态是开闭原则的基础。</GlossaryItem>
<GlossaryItem term="final">三种用法：①final 变量只能赋值一次（常量）；②final 方法不能被子类重写；③final 类不能被继承（如 String、Integer）。final 引用锁定引用而非对象——引用不可变但对象内部可变。</GlossaryItem>
</Glossary>
