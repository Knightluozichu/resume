## 接口

<Term def="接口是行为规范的抽象契约,Java 8+支持default/static/private方法。类可实现多个接口(implements),实现接口的类必须实现其抽象方法。">接口</Term>是面向抽象的关键工具。

<JctInterfacesLambdaDiagram />

```java
// 定义接口
public interface Comparable<T> {
    int compareTo(T other);  // 抽象方法, 无方法体
}

// Java 8+ default 方法: 接口提供默认实现
public interface Named {
    String getName();
    default String getDisplayName() {  // 子类可选重写
        return "User: " + getName();
    }
    static Named anonymous() {  // static 方法
        return () -> "Anonymous";
    }
}

// 实现接口
public class Employee implements Comparable<Employee>, Named {
    private String name;

    @Override
    public String getName() { return name; }

    @Override
    public int compareTo(Employee other) {
        return this.name.compareTo(other.name);
    }
    // getDisplayName() 使用默认实现
}

// 接口 vs 抽象类:
// 接口: 多实现, 无字段(仅常量), default/static方法
// 抽象类: 单继承, 可有字段和构造器, 可有具体方法
```

## Lambda 与函数式接口

```java
// 函数式接口: 只有一个抽象方法
@FunctionalInterface
public interface Runnable {
    void run();
}

// 匿名内部类 vs Lambda
// 旧: 匿名内部类
new Thread(new Runnable() {
    @Override
    public void run() {
        System.out.println("running");
    }
}).start();

// 新: Lambda (Java 8+)
new Thread(() -> System.out.println("running")).start();

// Lambda 语法
Runnable r1 = () -> System.out.println("hi");           // 无参
Comparator<String> c = (a, b) -> a.length() - b.length(); // 有参
Function<String, Integer> f = s -> s.length();            // 有返回值
BinaryOperator<Integer> add = (a, b) -> a + b;           // 两个参数

// 方法引用: Lambda的简写
// 类名::静态方法    Integer::parseInt
// 对象::实例方法    System.out::println
// 类名::实例方法    String::length
// 类名::new         Employee::new
list.forEach(System.out::println);
list.stream().map(String::toUpperCase).toList();
```

## Stream API

```java
import java.util.stream.*;

List<String> names = List.of("Alice", "Bob", "Charlie", "David");

// 中间操作 (惰性): filter / map / flatMap / sorted / distinct
// 终止操作 (触发): collect / reduce / count / forEach / toList

// 链式操作
List<String> result = names.stream()
    .filter(n -> n.length() > 3)           // 过滤: Alice, Charlie, David
    .map(String::toUpperCase)               // 映射: ALICE, CHARLIE, DAVID
    .sorted()                               // 排序: ALICE, CHARLIE, DAVID
    .toList();                              // 收集为List (Java 16+)

// reduce: 聚合
int sum = List.of(1, 2, 3, 4).stream()
    .reduce(0, Integer::sum);               // 10

// collect: 分组
Map<Integer, List<String>> byLength = names.stream()
    .collect(Collectors.groupingBy(String::length));
// {3=[Bob], 5=[Alice, David], 7=[Charlie]}

// 数值流: 避免装箱拆箱
double avg = List.of(1.0, 2.0, 3.0).stream()
    .mapToDouble(Double::doubleValue)
    .average()
    .orElse(0.0);

// 并行流: .parallelStream() 或 .parallel()
long count = names.parallelStream()
    .filter(n -> n.length() > 3)
    .count();
```

## 常见误区

<Callout type="trap">
**误区：Stream API 总是比 for 循环快。** Stream 有额外开销（创建流水线、Lambda 调用、装箱拆箱），简单遍历时 for 循环通常更快。Stream 的优势在于声明式可读性和并行化（parallelStream）。而且 Lambda 捕获的局部变量必须 effectively final——`list.forEach(x -> count++)` 编译错误，因为 count 不是 final。解决：用 AtomicInteger 或改用 reduce/collect 代替可变状态。最佳实践：Lambda 应无副作用，不修改外部状态。
</Callout>

<Exercises>
**问题 1**：什么是函数式接口？Lambda 如何与它配合？

<Answer>
函数式接口是只有一个抽象方法的接口（可以有多个 default/static 方法）。用 @FunctionalInterface 注解标记。Lambda 表达式是函数式接口实例的简写：`(参数) -> {方法体}`。编译器根据目标类型（函数式接口）推断参数类型。例如 `Runnable r = () -> System.out.println("hi")` 等价于匿名内部类。方法引用是进一步简写：`String::length` 等价于 `s -> s.length()`。常用函数式接口：Supplier<T>（无参返回T）、Consumer<T>（接收T无返回）、Function<T,R>（接收T返回R）、Predicate<T>（接收T返回boolean）。
</Answer>

**问题 2**：Stream 的中间操作和终止操作有什么区别？什么是惰性求值？

<Answer>
中间操作（filter/map/sorted等）返回新 Stream，不会立即执行。终止操作（collect/reduce/forEach等）触发流水线执行，产生最终结果。惰性求值的意义：①短路优化——findFirst() 找到第一个就停止；②融合优化——filter+map 在一次遍历中完成；③支持无限流——iterate() 生成的无限流只有遇到终止操作才求值。无状态操作（filter/map）不依赖其他元素，有状态操作（sorted/distinct）需缓存全部元素。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="接口">行为规范的抽象契约。Java 8+ 支持 default 方法（默认实现，子类可选重写）、static 方法（工具方法）、private 方法（Java 9+，内部复用）。类可实现多个接口。接口用于定义行为规范，抽象类用于共享代码。</GlossaryItem>
<GlossaryItem term="函数式接口">只有一个抽象方法的接口。@FunctionalInterface 注解让编译器检查。Lambda 表达式是函数式接口实例的简写。java.util.function 包提供常用函数式接口：Supplier、Consumer、Function、Predicate、BiFunction 等。</GlossaryItem>
<GlossaryItem term="Lambda表达式">函数式接口实例的匿名简写。语法 `(参数) -> {方法体}`。单参数可省括号 `x -> ...`，单语句可省花括号和 return。捕获的外部局部变量必须 effectively final。方法引用是 Lambda 的进一步简写（String::length）。</GlossaryItem>
<GlossaryItem term="Stream API">Java 8+ 的函数式数据处理管道。中间操作（filter/map/sorted）惰性求值，终止操作（collect/reduce/forEach）触发计算。支持串行和并行流。声明式、链式、可组合，适合集合数据处理。不同于 IO 流。</GlossaryItem>
</Glossary>
