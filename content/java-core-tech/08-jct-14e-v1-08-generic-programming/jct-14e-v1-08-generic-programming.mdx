## 为什么从“泛型约束与擦除观察台”开始

卷I 第8章 泛型程序设计要解决的不是 API 名称记忆，而是用类型参数、界限、通配符捕获、擦除与可具体化类型解释泛型代码能做什么和不能做什么。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把类型约束从“无界参数”切换为“有界通配符”，编译期约束率与堆污染风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
