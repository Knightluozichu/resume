## 为什么从“并发任务与关闭轨迹台”开始

卷I 第10章 并发要解决的不是 API 名称记忆，而是比较平台线程与虚拟线程，建立任务协调、happens-before、线程安全集合、异步计算和进程关闭边界。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把线程模型从“固定线程池”切换为“每任务虚拟线程”，任务完成率与竞争与泄漏风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
