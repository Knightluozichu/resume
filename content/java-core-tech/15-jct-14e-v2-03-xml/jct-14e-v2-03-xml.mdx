## 为什么从“XML 解析策略与攻击面台”开始

卷II 第3章 XML要解决的不是 API 名称记忆，而是从 XML 良构、命名空间和验证约束出发，比较 DOM、流式解析、XPath、生成与 XSLT 的安全边界。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把解析模型从“SAX事件”切换为“StAX拉取”，结构提取率与实体与内存风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
