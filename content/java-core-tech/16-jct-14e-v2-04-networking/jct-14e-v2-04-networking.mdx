## 为什么从“网络请求状态机”开始

卷II 第4章 网络要解决的不是 API 名称记忆，而是沿 DNS、连接、请求、响应、超时和关闭路径比较 Socket、服务端、HTTP Client、简单服务器与邮件交接。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把连接方式从“HTTP Client”切换为“本地HTTP Server”，协议完成率与挂起与重试风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
