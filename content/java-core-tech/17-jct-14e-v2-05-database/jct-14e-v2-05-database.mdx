## 为什么从“JDBC 事务与资源轨迹台”开始

卷II 第5章 数据库编程要解决的不是 API 名称记忆，而是从 JDBC 驱动、SQL 参数、结果集、元数据、事务到连接池建立一致性、隔离与资源归还合同。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把语句构造从“参数语句”切换为“批处理参数”，数据一致率与注入与半提交风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
