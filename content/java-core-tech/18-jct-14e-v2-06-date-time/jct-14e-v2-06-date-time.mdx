## 为什么从“时间语义与 DST 推演台”开始

卷II 第6章 日期与时间 API要解决的不是 API 名称记忆，而是区分 Instant、LocalDate/Time 与 ZonedDateTime，显式处理时区规则、DST、格式化和旧 API 迁移。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把时间类型从“Instant”切换为“ZonedDateTime”，时刻还原率与DST歧义风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
