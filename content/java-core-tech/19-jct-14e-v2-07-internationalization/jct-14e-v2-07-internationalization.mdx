## 为什么从“Locale 与文本边界对照台”开始

卷II 第7章 国际化要解决的不是 API 名称记忆，而是用 Locale、数字日期格式、排序归一化、消息占位、文本边界与资源包构建可迁移的本地化输出。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把区域环境从“zh-CN”切换为“de-DE”，本地化正确率与默认区域漂移会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
