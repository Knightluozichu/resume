## 为什么从“签名与加密边界验证台”开始

卷II 第9章 安全要解决的不是 API 名称记忆，而是沿类加载、身份认证、数字签名、加解密和密钥生命周期建立信任边界，拒绝自制密码与含混授权。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把安全目标从“身份认证”切换为“机密性”，信任验证率与密钥暴露风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。

## Java 25 最小可执行切片

```java
var signature = java.security.Signature.getInstance("Ed25519");
signature.initVerify(publicKey);
signature.update(message);
boolean valid = signature.verify(bytes);
```
