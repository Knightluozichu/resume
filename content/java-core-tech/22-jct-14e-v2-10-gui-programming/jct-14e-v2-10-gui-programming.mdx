## 为什么从“Swing EDT 响应轨迹台”开始

卷II 第10章 图形用户界面编程要解决的不是 API 名称记忆，而是以 EDT 为状态串行化边界，拆开 Frame、绘制、事件处理和 Preferences 持久化。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把任务位置从“后台执行”切换为“后台加EDT提交”，界面响应率与线程违规风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
