## 为什么从“表格树与打印管线台”开始

卷II 第12章 高级 Swing 与图形要解决的不是 API 名称记忆，而是分离表格/树模型、渲染器与编辑器状态，管理 AWT 绘制、位图内存、坐标变换和打印分页。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把数据规模从“万行”切换为“百万像素”，渲染一致率与内存与坐标风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
