## 为什么从“FFM ABI 与生命周期台”开始

卷II 第13章 外部函数与内存 API要解决的不是 API 名称记忆，而是比较 JNI 与 FFM，显式管理 Linker、Arena、MemorySegment、MemoryLayout、下调句柄和回调生命周期。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把互操作方式从“FFM downcall”切换为“FFM upcall”，ABI匹配率与越界与悬垂风险会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。

## 三个必须主动触发的误区
