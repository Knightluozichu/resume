## 为什么从“Java 25 跨层故障答辩台”开始

《Java核心技术（第14版·全两卷）》全书总复习要解决的不是 API 名称记忆，而是把语言、对象、集合、并发、模块、I/O、数据、安全、UI 与本地内存串成一次 Java 25 跨层故障答辩。 直觉上，编译成功只排除了部分静态错误；运行一次成功也没有覆盖空值、极值、取消、并发、资源关闭、区域、协议与版本边界。

先预测：把故障所在层从“资源与并发”切换为“协议与本地内存”，跨层定位率与错误归因率会如何变化？随后只改这一项运行探针；结果不符时修改机制假设，不移动输入边界。
