## 直觉引入

把 JavaScript 程序想象成一条流水线。原料是源码字符——Unicode 文本怎么切分成 token、分号怎么决定语句边界（词法结构）；加工成数据后——数字字符串布尔值怎么表示、类型怎么转换（类型与值）；接着组装成行为——函数怎么封装、闭包怎么记住状态、类怎么组织复用（函数与类模块）；再用工具箱加工——数组对象的内置方法、集合类型、甚至改写语言默认行为的元编程（标准库与元编程）；最后装上轮子开上公路——操作 DOM、监听事件、发请求、存数据、开线程（Web 平台）。本书回答的就是这条「从字符到网页」的完整链路上的 JavaScript 工程问题。

## 四阶段递进

<Term def="JavaScript 运行时旅程是源码字符经词法解析成程序、程序用类型与函数组织行为、靠标准库加工数据、最终通过 DOM 与浏览器 API 驱动网页响应的完整链路。">运行时旅程</Term>的学习可以拆成四个递进阶段。**语言核心**包括词法结构与类型值——它们解决「字符如何组成程序」和「数据如何表示」，是所有上层逻辑的基底。**函数抽象**包括函数闭包与类模块——它们决定「行为如何封装」和「代码如何组织复用」。**标准库与元编程**包括数组对象与集合元编程——它们提供「内置数据结构开箱即用」和「改写语言默认行为」的能力。**Web 平台**包括 DOM 事件与浏览器 API——它们连接「代码与网页世界」和「代码与浏览器能力」。**总复习**串联全部知识点。

```javascript
// 一次「import 模块 → 发请求 → 处理数据 → 更新 DOM」的完整运行时旅程
import { fetchUser } from "./api.js"; // 【类与模块】ESM 静态 import（第 5 章）

btn.addEventListener("click", async () => { // 【DOM 事件】事件监听（第 8 章）
  const handler = (data) => ({ ...data, time: Date.now() }); // 【函数闭包】箭头函数 + 展开运算（第 4、6 章）

  const raw = await fetchUser(123); // 【浏览器 API】Fetch + async/await（第 9 章）
  const result = handler(raw);      // 【类型与值】对象按引用传递（第 3 章）

  const map = new Map(Object.entries(result)); // 【集合元编程】Map 集合（第 7 章）
  display.textContent = JSON.stringify([...map]); // 【数组对象】展开 + 字符串化（第 6 章）
});
// 词法结构：分号、Unicode、标识符贯穿始终（第 2 章）
```

## 常见误区

<Callout type="trap">
**误区：把 JavaScript 当成「写网页的脚本」就够了。** 只会操作 DOM 和发请求，写出的代码能跑但脆弱。真正的 JavaScript 工程能力是一条完整链路：词法层面理解分号插入为什么有时出错、类型层面预判 `0.1+0.2` 的精度陷阱、函数层面用闭包封装状态而非污染全局、模块层面用 ESM 静态分析支持 tree-shaking、标准库层面选对数据结构（Map 而非对象当字典）、元编程层面理解响应式框架如何用 Proxy 拦截、Web 层面用事件委托减少监听器、用 Worker 卸载 CPU 密集计算。把每一层当独立知识点背，遇到组合场景就抓瞎；以「运行时旅程」为主线串联，才能从「会写脚本」升级到「懂 JavaScript 工程」。
</Callout>

<Exercises>
**问题 1**：全书四阶段是什么？为什么是这个顺序？

<Answer>
语言核心（词法结构/类型值）→ 函数抽象（函数闭包/类模块）→ 标准库与元编程（数组对象/集合元编程）→ Web 平台（DOM事件/浏览器API）→ 总复习。顺序由依赖关系决定：上层依赖下层。没有词法与类型就没有程序的基本构成；没有函数与类就没有行为封装与代码组织；没有标准库就没有高效的数据加工工具；没有 Web 平台就和浏览器世界无关。先有「能组成程序」，再有「能封装行为」，然后「能加工数据」，接着「能驱动网页」，最后用总复习把链路串通。
</Answer>

**问题 2**：用「从源码字符到页面响应」的完整运行时旅程描述全书主线。

<Answer>
源码字符经词法解析：Unicode 文本被切分成 token、ASI 决定语句边界、标识符与关键字被识别（第 2 章）；解析出的表达式求值：原始类型按值存储、对象按引用传递、类型转换由抽象操作驱动（第 3 章）；行为被封装：函数定义形式决定 this 绑定、闭包延续作用域记住状态、类与模块组织代码复用（第 4-5 章）；数据被加工：数组方法分纯函数与副作用、解构与展开声明式操作、Map/Set 提供有序集合、Proxy/Reflect 改写默认行为（第 6-7 章）；驱动网页：事件流三阶段传播、委托利用冒泡减负、Fetch 发请求、Storage 存数据、Worker 卸载计算（第 8-9 章）。一条链路，十章知识点全部参与。
</Answer>
</Exercises>
