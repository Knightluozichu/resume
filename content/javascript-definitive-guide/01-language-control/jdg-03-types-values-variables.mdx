## 本章定位

<Term def="JavaScript 的值分为不可变原始值与可变对象引用；数值、文本、布尔、null、undefined、Symbol、BigInt 以及显式和隐式转换共同决定表达式的真实语义。">原始值</Term> 是本章的入口观察量。JavaScript 的值分为不可变原始值与可变对象引用；数值、文本、布尔、null、undefined、Symbol、BigInt 以及显式和隐式转换共同决定表达式的真实语义。 这意味着阅读不能停在 API 名称或最终打印值，而要回答：输入何时进入、值或对象怎样变化、控制权在哪里转移、错误如何传播、宿主资源由谁清理。

## 六阶段机制链

### 1. 识别值的类型

固定源码、运行环境和输入，在动作发生前记录可见绑定、值类型、对象身份、待处理任务和已打开资源。若起点不稳定，后续比较没有意义。

### 2. 区分原始值与对象引用

只执行本阶段最小动作，记录它读取了什么、写入了什么，以及控制权交给语言运行时还是浏览器、Node 或工具链。

### 3. 执行数值或文本运算

检查抽象规则是否被真正满足。不要用最终输出反推过程；对象引用、隐式转换、短路与异步调度都可能产生表面相同的结果。

### 4. 应用类型转换

在边界值、重复输入、迟到结果和错误宿主状态下重放。保存第一个与正常轨迹不同的位置，而不是只保存最后一条异常。

### 5. 绑定 let、const 或 var

让失败沿规定通道传播，并核对调用者是否能区分可重试、应停止和必须降级的情况。静默吞错不能作为恢复策略。

### 6. 检查相等性与可变性

修复单一故障后重放完全相同的输入。只有绑定、值、任务、句柄和生成产物都回到可预测状态，本章才可以签发。
