## 边界记录模板

每次实验都建立一行六列证据：**输入快照、当前阶段、语言状态、宿主资源、首个偏离点、恢复结果**。语言核心章节要展开变量绑定、对象身份和调用栈；浏览器章节要增加节点连接状态、事件监听数量、网络请求与页面地址；Node.js 章节要增加请求流、响应是否结束、文件或数据库连接和事务状态。执行“核验原书身份”前先写预测，经过“掌握函数对象与异步”后只比较一项受控变化，到“完成 Node 数据闭环”时重放同一输入。若最终值相同但对象、任务、监听器、流或连接数量不同，仍判定失败；若异常被捕获但部分状态已经提交，也不能签发。这个模板把 API 记忆转换成可复查的因果链，并让正常、边界、失败和恢复样本可以逐列对照。
