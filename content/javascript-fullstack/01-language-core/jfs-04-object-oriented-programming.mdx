## 最小可运行实验

```javascript
const accountMethods = {
  deposit(amount) {
    if (amount <= 0) throw new RangeError("amount");
    this.balance += amount;
  },
};
const account = Object.assign(Object.create(accountMethods), { balance: 10 });
account.deposit(5);
console.log(account.balance, accountMethods.isPrototypeOf(account));
```

## 四类样本与验收

| 样本 | 注入方式                         | 必查证据                         | 通过条件                   |
| ---- | -------------------------------- | -------------------------------- | -------------------------- |
| 正常 | 合法输入与单次执行               | 值、对象、调用点、任务、宿主资源 | 六阶段按预期完成           |
| 边界 | 空值、极值、重复输入、慢 I/O     | 类型与协议边界、停止条件         | 不发生隐式越界或重复提交   |
| 失败 | 错误参数、拒绝、断流、数据库失败 | 首个偏离点与错误通道             | 明确停止、传播或回滚       |
| 恢复 | 清除故障后重放相同输入           | 清理后的状态与资源数             | 无旧任务、监听器、流和连接 |

本页签发不变量是：**JavaScript 的面向对象建立在对象与原型委托之上；类语法提供更清晰的构造接口，但属性所有权、原型链和方法接收者仍是运行时真相。** 单次输出、截图或一次请求成功不能替代值语义、对象身份、控制流、任务顺序和宿主资源的完整轨迹。
