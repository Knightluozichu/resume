## 六阶段机制链

### 1. 提交异步操作

固定源码、运行环境、输入与初始状态，先预测值、对象身份、调用点、任务队列和宿主资源。不要从最终输出反推过程；一旦出现分歧，保存首个偏离点再继续。

### 2. 让出当前调用栈

只执行当前最小动作，记录值、对象身份、调用点、任务队列和宿主资源。不要从最终输出反推过程；一旦出现分歧，保存首个偏离点再继续。

### 3. 宿主完成外部工作

只执行当前最小动作，记录值、对象身份、调用点、任务队列和宿主资源。不要从最终输出反推过程；一旦出现分歧，保存首个偏离点再继续。

### 5. 恢复并传播结果

## 边界记录模板

每次实验都建立一行六列证据：**输入快照、当前阶段、语言状态、宿主资源、首个偏离点、恢复结果**。语言核心章节要展开变量绑定、对象身份和调用栈；浏览器章节要增加节点连接状态、事件监听数量、网络请求与页面地址；Node.js 章节要增加请求流、响应是否结束、文件或数据库连接和事务状态。执行“提交异步操作”前先写预测，经过“宿主完成外部工作”后只比较一项受控变化，到“取消或清理剩余任务”时重放同一输入。若最终值相同但对象、任务、监听器、流或连接数量不同，仍判定失败；若异常被捕获但部分状态已经提交，也不能签发。这个模板把 API 记忆转换成可复查的因果链，并让正常、边界、失败和恢复样本可以逐列对照。

### 第 5 章 异步编程

**第 5 章 异步编程** 的核心是：围绕任务生命周期组织非阻塞操作，避免把语法上的顺序误当成实际完成顺序。先预测正常输入经过“提交异步操作”时会读取和修改哪些值，再运行最小样例，保存“事件循环”的实际状态。边界样本必须覆盖空值、重复输入、非法格式或迟到结果；失败样本只注入一个变量，并停在首个偏离点。最后清除故障、重放同一输入，确认输出、任务、监听器、连接和持久化状态都已收敛。

### 5.1 何谓异步编程

**5.1 何谓异步编程** 的核心是：区分调用返回、外部操作完成和结果处理三个时刻，观察调用栈与任务队列。先预测正常输入经过“让出当前调用栈”时会读取和修改哪些值，再运行最小样例，保存“回调函数”的实际状态。边界样本必须覆盖空值、重复输入、非法格式或迟到结果；失败样本只注入一个变量，并停在首个偏离点。最后清除故障、重放同一输入，确认输出、任务、监听器、连接和持久化状态都已收敛。

## 最小可运行实验

```javascript
async function loadPair(load) {
  const controller = new AbortController();
  try {
    return await Promise.all([
      load("profile", controller.signal),
      load("orders", controller.signal),
    ]);
  } catch (error) {
    controller.abort();
    throw error;
  }
}
```

## 四类样本与验收

| 样本 | 注入方式                         | 必查证据                         | 通过条件                   |
| ---- | -------------------------------- | -------------------------------- | -------------------------- |
| 正常 | 合法输入与单次执行               | 值、对象、调用点、任务、宿主资源 | 六阶段按预期完成           |
| 边界 | 空值、极值、重复输入、慢 I/O     | 类型与协议边界、停止条件         | 不发生隐式越界或重复提交   |
| 失败 | 错误参数、拒绝、断流、数据库失败 | 首个偏离点与错误通道             | 明确停止、传播或回滚       |
| 恢复 | 清除故障后重放相同输入           | 清理后的状态与资源数             | 无旧任务、监听器、流和连接 |

## 小结

- **事件循环**：对应“提交异步操作”阶段的核心观察量。
- **回调函数**：对应“让出当前调用栈”阶段的核心观察量。
- **Promise**：对应“宿主完成外部工作”阶段的核心观察量。
- **async/await**：对应“排队回调或反应”阶段的核心观察量。
- **异步流程控制**：对应“恢复并传播结果”阶段的核心观察量。
- 6 个公开目录条目已经全部映射到本页证据链。
- 正常、边界、失败和恢复样本共同决定是否通过，最终输出不是唯一证据。
