## 最小可运行实验

```javascript
import { readFile } from "node:fs/promises";

async function readConfig(file) {
  const text = await readFile(file, "utf8");
  const value = JSON.parse(text);
  if (!value.port) throw new Error("missing port");
  return value;
}

readConfig(process.argv[2]).then(console.log, (error) => {
  console.error(error.message);
  process.exitCode = 1;
});
```

## 四类样本与验收

| 样本 | 注入方式                         | 必查证据                         | 通过条件                   |
| ---- | -------------------------------- | -------------------------------- | -------------------------- |
| 正常 | 合法输入与单次执行               | 值、对象、调用点、任务、宿主资源 | 六阶段按预期完成           |
| 边界 | 空值、极值、重复输入、慢 I/O     | 类型与协议边界、停止条件         | 不发生隐式越界或重复提交   |
