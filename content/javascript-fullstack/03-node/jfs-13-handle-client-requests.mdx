## 最小可运行实验

```javascript
import { URL } from "node:url";

function route(request, response) {
  const url = new URL(request.url, "http://localhost");
  if (request.method !== "GET" || url.pathname !== "/hello") {
    response.writeHead(404).end();
    return;
  }
  const name = url.searchParams.get("name") || "visitor";
  response.writeHead(200, { "content-type": "text/plain; charset=utf-8" });
  response.end("hello, " + name);
}
```

## 四类样本与验收

| 样本 | 注入方式                         | 必查证据                         | 通过条件                   |
| ---- | -------------------------------- | -------------------------------- | -------------------------- |
| 正常 | 合法输入与单次执行               | 值、对象、调用点、任务、宿主资源 | 六阶段按预期完成           |
| 边界 | 空值、极值、重复输入、慢 I/O     | 类型与协议边界、停止条件         | 不发生隐式越界或重复提交   |
| 失败 | 错误参数、拒绝、断流、数据库失败 | 首个偏离点与错误通道             | 明确停止、传播或回滚       |
| 恢复 | 清除故障后重放相同输入           | 清理后的状态与资源数             | 无旧任务、监听器、流和连接 |

本页签发不变量是：**可靠服务器先解析并限制请求，再选择表示形式和模板生成响应；路由、正文读取、内容协商、静态文件和模板输出都必须防止越界输入与重复响应。** 单次输出、截图或一次请求成功不能替代值语义、对象身份、控制流、任务顺序和宿主资源的完整轨迹。
