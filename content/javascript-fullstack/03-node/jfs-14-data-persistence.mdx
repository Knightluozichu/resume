## 最小可运行实验

```javascript
async function transfer(db, from, to, amount) {
  if (!Number.isFinite(amount) || amount <= 0) throw new RangeError("amount");
  return db.transaction(async (tx) => {
    const changed = await tx.run(
      "UPDATE accounts SET balance = balance - ? WHERE id = ? AND balance >= ?",
      [amount, from, amount],
    );
    if (changed !== 1) throw new Error("insufficient funds");
    await tx.run("UPDATE accounts SET balance = balance + ? WHERE id = ?", [
      amount,
      to,
    ]);
  });
}
```

## 四类样本与验收

| 样本 | 注入方式                         | 必查证据                         | 通过条件                   |
| ---- | -------------------------------- | -------------------------------- | -------------------------- |
| 正常 | 合法输入与单次执行               | 值、对象、调用点、任务、宿主资源 | 六阶段按预期完成           |
| 边界 | 空值、极值、重复输入、慢 I/O     | 类型与协议边界、停止条件         | 不发生隐式越界或重复提交   |
| 失败 | 错误参数、拒绝、断流、数据库失败 | 首个偏离点与错误通道             | 明确停止、传播或回滚       |
| 恢复 | 清除故障后重放相同输入           | 清理后的状态与资源数             | 无旧任务、监听器、流和连接 |

本页签发不变量是：**程序状态要跨请求和重启存在，就必须明确内存、文件、会话与数据库的生命周期；数据库访问还需参数化查询、事务边界、连接释放和错误回滚。** 单次输出、截图或一次请求成功不能替代值语义、对象身份、控制流、任务顺序和宿主资源的完整轨迹。
