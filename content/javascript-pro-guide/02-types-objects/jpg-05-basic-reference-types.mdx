## 机制拆解

### 1. 时间点与日历表示分开

Date内部是时间戳，但构造和格式化会受时区影响。协议传输应使用明确时区的ISO表示或时间戳，业务日历还要单独处理时区、夏令时和仅日期语义。

先预测：若省略这一层，哪个绑定、任务、权限或资源会先偏离？

### 2. 全局正则带lastIndex状态

带g或y标志的RegExp在test与exec之间更新lastIndex，共享实例会让相同输入得到不同结果。迭代匹配时显式管理状态，单次验证可避免全局标志或每次创建实例。

先预测：若省略这一层，哪个绑定、任务、权限或资源会先偏离？

### 3. 不要显式创建包装对象

new Boolean(false)是对象，因此在条件中为真；原始字符串调用方法时的自动装箱是短暂规范行为。API应返回原始值，类型检查也要区分typeof与instanceof。
