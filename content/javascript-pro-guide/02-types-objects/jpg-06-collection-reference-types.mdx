## 机制拆解

### 1. 数组方法按语义分组

push/pop表示栈，shift/unshift表示队列但移动索引成本高，map/filter返回新数组，sort默认按字符串比较且原地修改。代码评审应同时确认返回值、是否修改原集合和稀疏项行为。

先预测：若省略这一层，哪个绑定、任务、权限或资源会先偏离？

### 2. 二进制数据由缓冲区与视图分层

ArrayBuffer只是一段字节，DataView可显式字节序读写，定型数组提供同类型连续视图。切片、共享缓冲和偏移必须在协议边界校验，避免把元素长度当成字节长度。

先预测：若省略这一层，哪个绑定、任务、权限或资源会先偏离？

### 3. Map、Set与弱集合表达所有权

Map适合任意键和频繁增删，Set表达成员唯一性；WeakMap适合给外部对象附加不延长生命周期的元数据。弱集合不可迭代正是为了不暴露垃圾回收时机，不能拿来做可枚举注册表。

先预测：若省略这一层，哪个绑定、任务、权限或资源会先偏离？

## 小结

- **Array**：按非负整数索引组织、有length和稳定顺序语义的可变集合。
- **定型数组**：在ArrayBuffer上以固定数值类型解释连续二进制内存的数组视图。
- **Map**：按SameValueZero键语义保存任意键值并保持插入顺序的集合。
- **WeakMap**：以对象为弱键、不会因键记录本身阻止键被回收的不可迭代映射。
- **Set**：按SameValueZero去重并保持插入顺序的值集合。
