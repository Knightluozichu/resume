## 直觉引入

把网页想象成一棵倒挂的树。树根是 document，往上长出一根主干叫 html，html 分叉成两根大树枝——head（放标题、元信息）和 body（放可见内容），body 上又长出 div、p、span 等小枝丫，层层嵌套。每个枝丫叫一个节点（Node），你可以爬上去摘果子（读属性）、嫁接新枝（插入节点）、锯掉枯枝（删除节点）。这就是 DOM——文档对象模型。而 BOM 则是这棵树长在的「花盆」——浏览器窗口本身，包括地址栏（location）、历史记录（history）、屏幕信息（screen）等花盆的属性。

## DOM 文档树与节点操作

<Term def="DOM（文档对象模型）是将 HTML 文档表示为节点树的结构化 API。document 为根，下含 html，html 含 head 与 body，层层嵌套形成树。每个节点是 Node 对象，可通过 querySelector、createElement、appendChild 等 API 增删改查。DOM 操作会触发重排（layout）与重绘（repaint），是前端性能的主要瓶颈。">DOM</Term>是 JS 操作网页的桥梁。常用 API：查找（getElementById、querySelector）、创建（createElement、createTextNode）、修改（textContent、setAttribute、appendChild、insertBefore）、删除（removeChild）、遍历（children、parentNode）。每个 DOM 节点都是对象，继承自 Node 与 EventTarget 原型链。

```javascript
// 查找
const btn = document.querySelector("#btn");          // CSS 选择器，返回首个
const items = document.querySelectorAll(".item");    // 返回 NodeList

// 创建与插入
const li = document.createElement("li");
li.textContent = "新项";
li.classList.add("active");
li.setAttribute("data-id", "1");
document.querySelector("ul").appendChild(li); // 插入末尾

// 批量插入：用 DocumentFragment 离线操作，只触发一次重排
const frag = document.createDocumentFragment();
for (let i = 0; i < 100; i++) {
  const li = document.createElement("li");
  li.textContent = `项 ${i}`;
  frag.appendChild(li); // 先挂到离线片段，不触发重排
}
ul.appendChild(frag); // 一次性插入，只 1 次重排

// 事件监听与委托
// 朴素：每个 li 各加监听（100 个监听器）
// 委托：在父节点加 1 个，利用冒泡判断 target
ul.addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    console.log(e.target.dataset.id); // 1 个监听器管所有 li
  }
});
```

## BOM 对象层级

<Term def="BOM（浏览器对象模型）是以 window 为根的浏览器环境对象层级。window 是全局对象，包含 document（DOM 入口）、location（URL）、history（会话历史）、navigator（浏览器信息）、screen（屏幕）、performance（性能计时）等。JS 通过 BOM 与浏览器窗口及环境交互。">BOM</Term>让 JS 能访问浏览器本身。`window` 是全局对象，所有全局变量和 BOM API 都挂在它上面。`location` 读写 URL（href/search/hash），`history` 管理会话历史（back/forward/pushState），`navigator` 探测环境（userAgent/geolocation），`screen` 提供屏幕尺寸，`performance` 提供高精度计时与性能数据。localStorage/sessionStorage 也属于 BOM 范畴。

```javascript
// location：URL 读写与跳转
console.log(location.href, location.pathname, location.search);
location.href = "https://example.com"; // 跳转（整页刷新）
history.pushState({page: 1}, "", "/page1"); // SPA 路由，不刷新

// navigator：环境探测
console.log(navigator.userAgent, navigator.language);
navigator.geolocation.getCurrentPosition(pos => console.log(pos.coords));

// storage：本地存储
localStorage.setItem("key", JSON.stringify(data)); // 持久
const d = JSON.parse(localStorage.getItem("key"));
sessionStorage.setItem("temp", "x"); // 仅当前会话

// performance：高精度计时
const t0 = performance.now();
// ... 操作
console.log(`耗时 ${performance.now() - t0}ms`);
```

## 常见误区

<Callout type="trap">
**误区：频繁操作 DOM 只是慢一点点，不用刻意优化。** 每次 DOM 修改（尺寸、位置、内容）都可能触发**重排**（layout，重新计算几何）和**重绘**（repaint，重绘像素）。重排是昂贵的——它会让浏览器重新计算整个或部分文档的布局，连带影响后续所有元素。循环里 100 次 appendChild 触发 100 次重排，用 DocumentFragment 合并成 1 次，性能差几十倍。读写交替（读 offsetHeight 触发布局，再写 style 又触发）会造成「布局抖动」（layout thrashing），强制同步布局多次。优化原则：批量写、用 rAF、读写分离、用 transform 替代 top/left（transform 不触发重排）。
</Callout>

<Exercises>
**问题 1**：DOM 和 BOM 的关系是什么？window 和 document 谁是根？

<Answer>
BOM 以 window 为根对象，document 是 window 的一个属性（window.document），DOM 是 document 之下的文档节点树。所以 window 是 BOM 的根，document 是 DOM 的根，而 DOM 寄生于 BOM 之内（document 挂在 window 上）。DOM 专门操作 HTML 文档结构（节点树、增删改查），BOM 操作浏览器窗口与环境（location/history/navigator/screen/storage）。JS 通过 BOM 访问浏览器，通过 DOM（BOM 的 document 部分）访问页面内容。两者共同构成「JS 与浏览器交互」的完整 API。
</Answer>

**问题 2**：什么是事件委托？它解决什么问题？

<Answer>
事件委托（event delegation）是利用事件冒泡机制，把本应绑定在多个子元素上的监听器，改为绑定在它们的共同父元素上，通过 e.target 判断实际触发的子元素。解决的问题：① 内存——100 个 li 各加监听器需 100 个监听器对象，委托只需 1 个；② 动态元素——后增删的 li 无需重新绑定/解绑，父节点监听器自动覆盖；③ 代码简洁——统一处理逻辑集中在一处。局限：不冒泡的事件（如 focus/blur，需用 focusin/focusout 替代）无法直接委托；需要精确判断 target（如 e.target.closest('li')）避免点到子元素误判。现代框架（React 合成事件）底层就用委托。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="DOM">文档对象模型，将 HTML 表示为节点树。document 为根，含 html → head/body → ...。通过 querySelector/createElement/appendChild 等 API 增删改查。操作触发重排重绘，是性能瓶颈。</GlossaryItem>
<GlossaryItem term="BOM">浏览器对象模型，以 window 为根的环境对象层级。含 document（DOM 入口）、location（URL）、history（会话历史）、navigator（环境）、screen（屏幕）、performance（计时）、localStorage（存储）。JS 通过 BOM 与浏览器交互。</GlossaryItem>
<GlossaryItem term="DocumentFragment">轻量文档片段，可作为节点的离线容器。在其上批量操作不触发重排，最后一次性 appendChild 到真实 DOM，只触发一次重排。批量插入的性能优化手段。</GlossaryItem>
<GlossaryItem term="事件委托">利用冒泡把子元素监听器绑定到父元素，通过 e.target 判断源。节省内存（1 个监听器管多个）、自动覆盖动态元素、代码集中。现代框架合成事件的底层。</GlossaryItem>
<GlossaryItem term="重排与重绘">重排（layout）是重新计算元素几何（尺寸/位置改变触发），昂贵；重绘（repaint）是重绘像素（颜色等改变触发，不重排）。重排必伴随重绘。transform/opacity 走合成层不触发重排，是动画首选。</GlossaryItem>
</Glossary>
