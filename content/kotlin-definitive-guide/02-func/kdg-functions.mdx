## 函数声明与默认参数

Kotlin的函数声明比Java更简洁，支持默认参数和命名参数：

```kotlin
// 标准函数
fun add(a: Int, b: Int): Int {
    return a + b
}

// 表达式体函数——单行函数用=简写
fun double(x: Int): Int = x * 2

// 默认参数——调用时可省略
fun greet(name: String = "World", greeting: String = "Hello"): String {
    return "$greeting, $name!"
}

greet()                    // "Hello, World!"
greet("Kotlin")            // "Hello, Kotlin!"
greet(greeting = "Hi")     // "Hi, World!" —— 命名参数
```

<Callout type="insight">
**核心理念**：默认参数和命名参数让Kotlin不需要方法重载。Java中要写多个`greet()`重载，Kotlin一个函数加默认参数就搞定。命名参数还让调用更可读——`greet(greeting = "Hi")`比`greet("World", "Hi")`清晰得多。
</Callout>

## 高阶函数与函数类型

高阶函数是接收函数作为参数或返回函数的函数。Kotlin用函数类型`(参数类型) -> 返回类型`来描述：

```kotlin
// 函数作为参数
fun apply(f: (Int) -> Int, x: Int): Int = f(x)
apply({ it * 2 }, 5)   // 10

// 函数作为返回值
fun multiplier(n: Int): (Int) -> Int = { it * n }
val triple = multiplier(3)
triple(5)  // 15

// 常见高阶函数：集合操作
list.map { it * 2 }          // 变换
list.filter { it > 0 }       // 过滤
list.reduce { a, b -> a + b } // 聚合
list.forEach { println(it) }  // 遍历
```

## Lambda表达式

Lambda是匿名函数的简洁写法：

```kotlin
// 完整Lambda
val square = { x: Int -> x * x }
square(5)  // 25

// 类型已知时可省略参数类型
val square2: (Int) -> Int = { x -> x * x }

// 单参数Lambda可用it隐式名
val square3: (Int) -> Int = { it * it }

// 末尾Lambda约定——最后一个参数是函数时，Lambda可移到括号外
list.filter({ it > 0 })   // 完整写法
list.filter { it > 0 }     // 末尾Lambda，省略括号

// 无参数时用空括号
val greet = { println("Hi") }
```

<Callout type="trap">
**误区**：在不需要Lambda的地方滥用Lambda。当函数逻辑简单且只用一次时，Lambda很合适；但当逻辑复杂或需复用时，应提取为命名函数。命名函数有明确的签名和名字，可读性和可测试性更好。
</Callout>

## 集合函数式操作

Kotlin集合操作是函数式编程的典型应用：

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

// map: 变换每个元素
numbers.map { it * 2 }           // [2, 4, 6, 8, 10]

// filter: 过滤
numbers.filter { it % 2 == 0 }   // [2, 4]

// sortedBy: 排序
numbers.sortedByDescending { it } // [5, 4, 3, 2, 1]

// groupBy: 分组
numbers.groupBy { it % 2 == 0 }  // {false=[1,3,5], true=[2,4]}

// reduce: 聚合
numbers.reduce { acc, i -> acc + i }  // 15

// fold: 带初始值的聚合
numbers.fold(0) { acc, i -> acc + i } // 15

// 链式调用
numbers
    .filter { it > 1 }
    .map { it * 10 }
    .sortedBy { it }
    .forEach { println(it) }  // 20 30 40 50
```

## inline内联函数

高阶函数默认有闭包开销——Lambda在运行时编译为匿名类对象。`inline`关键字让编译器将Lambda体直接展开到调用处：

```kotlin
// 内联函数——Lambda体在调用处展开，无闭包对象
inline fun <T> withLock(lock: Lock, body: () -> T): T {
    lock.lock()
    try {
        return body()
    } finally {
        lock.unlock()
    }
}

// 调用处编译后等价于：
// lock.lock()
// try { /* body的代码直接展开 */ } finally { lock.unlock() }
```

**问题 1**：Kotlin高阶函数是什么？函数类型如何声明？

<Answer>
高阶函数是接收函数作为参数或返回函数作为结果的函数。Kotlin用函数类型来描述函数的签名：`(参数类型列表) -> 返回类型`。例如`(Int) -> Int`表示接收一个Int参数返回Int的函数；`(String, Int) -> Boolean`表示接收String和Int返回Boolean的函数；`() -> Unit`表示无参无返回值的函数。高阶函数的典型用途：①函数作为参数——`fun apply(f: (Int) -> Int, x: Int) = f(x)`，将行为参数化。②函数作为返回值——`fun multiplier(n: Int): (Int) -> Int = { it * n }`，函数工厂模式。③集合操作——`list.map { it * 2 }`中map的参数`(T) -> R`就是函数类型。高阶函数是函数式编程的基础，让代码更灵活、更声明式。
</Answer>

**问题 2**：Kotlin的Lambda表达式有哪些语法约定？

<Answer>
Kotlin Lambda语法约定：①完整语法——`{ 参数列表 -> 函数体 }`，如`{ x: Int, y: Int -> x + y }`。②类型推断——当Lambda赋值给有明确类型的变量时，可省略参数类型：`val f: (Int) -> Int = { x -> x * 2 }`。③it隐式参数——单参数Lambda的参数可省略，用`it`引用：`{ it * 2 }`等价于`{ x -> x * 2 }`。④末尾Lambda约定——函数的最后一个参数是函数类型时，Lambda可移到括号外：`list.filter({ it > 0 })`简化为`list.filter { it > 0 }`。⑤无参Lambda——`{ println("hi") }`。⑥多参数Lambda——`{ a, b -> a + b }`。这些约定让Kotlin的函数式代码非常简洁，尤其是末尾Lambda约定使得DSL式API成为可能（如`html { body("text") }`）。
</Answer>

**问题 3**：Kotlin集合的`map`、`filter`、`reduce`各自的作用是什么？如何链式组合？

<Answer>
Kotlin集合三大核心操作：①map——变换（映射），对集合每个元素应用函数，生成新集合。`listOf(1,2,3).map { it * 2 }`得到`[2,4,6]`。类型从`List<T>`变为`List<R>`。②filter——过滤，保留满足条件的元素。`listOf(1,2,3,4).filter { it % 2 == 0 }`得到`[2,4]`。类型不变，元素可能减少。③reduce——聚合，将集合合并为单个值。`listOf(1,2,3).reduce { acc, i -> acc + i }`得到`6`。链式组合：每个操作返回新集合，可直接链式调用。例如`numbers.filter { it > 1 }.map { it * 10 }.sortedBy { it }.forEach { println(it) }`。注意：每次中间操作都创建新集合（ eager求值），对大数据集可用`asSequence()`转为惰性序列。还有fold（带初始值的reduce）、groupBy（分组）、flatMap（扁平化映射）等操作。
</Answer>

**问题 4**：`inline`内联函数的作用是什么？什么场景下应该使用？

<Answer>
`inline`内联函数让编译器将函数体和Lambda参数体直接展开到调用处，消除运行时闭包对象创建开销。原理：普通高阶函数中，Lambda参数被编译为`Function`接口的匿名类对象，每次调用都创建对象、有内存分配和GC压力。`inline`标记后，编译器在调用处内联展开函数体和Lambda体，无需创建闭包对象。适用场景：①性能敏感的高阶函数——如`withLock`、`forEach`等被频繁调用的标准库函数。②需要非局部返回（non-local return）——内联函数中的Lambda可以直接return外层函数，普通Lambda不行。③reified类型参数——`inline fun <reified T>`需要在调用处知道T的具体类型，只有内联才能实现。不适用场景：①函数体很大——内联会增大字节码体积。②接收非内联Lambda——用`noinline`标记不想内联的参数。④公共API中过度使用——会增加下游编译产物体积。标准库的`let`/`run`/`with`/`apply`/`also`和集合操作函数都是inline的。
</Answer>
