## 最小可执行切片

```kotlin
fun toDragonSpeak(phrase: String): String = phrase
    .split(" ")
    .joinToString(" ") { word ->
        word.replace("th", "ss", ignoreCase = true)
    }

check(toDragonSpeak("the hearth").isNotBlank())
```
