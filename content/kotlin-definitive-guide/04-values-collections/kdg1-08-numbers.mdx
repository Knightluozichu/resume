## 最小可执行切片

```kotlin
fun remainingPints(raw: String, price: Double): Int {
    val balance = raw.toDoubleOrNull() ?: return 0
    require(price > 0.0)
    return (balance / price).toInt().coerceAtLeast(0)
}

check(remainingPints("10.0", 2.5) == 4)
```

运行切片时固定 Kotlin/JDK 或 Android 工具链版本、输入数据和命令；保存标准输出、编译诊断及断言。迁移实验必须另建记录，不能静默改写2018年的历史坐标。

<Callout type="trap" title="本章核心陷阱">
  假设数值会隐式扩宽，或把Double格式化结果当精确金额。先缩小到最小反例，明确是类型合同、对象所有权、求值顺序还是平台边界失效，再用同输入验证修复。
</Callout>
