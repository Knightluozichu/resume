## 最小可执行切片

```kotlin
data class Player(var name: String = "", var health: Int = 100)

val player = Player().apply {
    name = "Madrigal"
}.also { require(it.health in 0..100) }

val label = player.takeIf { it.health > 0 }?.let { it.name }
```
