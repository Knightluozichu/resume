## 最小可执行切片

```kotlin
val patronGold = mutableMapOf("Madrigal" to 10)

fun charge(name: String, price: Int): Boolean {
    val balance = patronGold[name] ?: return false
    if (balance < price) return false
    patronGold[name] = balance - price
    return true
}
```

运行切片时固定 Kotlin/JDK 或 Android 工具链版本、输入数据和命令；保存标准输出、编译诊断及断言。迁移实验必须另建记录，不能静默改写2018年的历史坐标。
