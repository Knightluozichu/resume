## 最小可执行切片

```kotlin
interface Fightable {
    val health: Int
    fun attack(): Int
    fun isAlive(): Boolean = health > 0
}

abstract class Monster(override val health: Int) : Fightable
class Goblin(health: Int) : Monster(health) { override fun attack() = 4 }
```

运行切片时固定 Kotlin/JDK 或 Android 工具链版本、输入数据和命令；保存标准输出、编译诊断及断言。迁移实验必须另建记录，不能静默改写2018年的历史坐标。
