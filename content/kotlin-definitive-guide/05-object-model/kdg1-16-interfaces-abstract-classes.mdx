## 最小可执行切片

```kotlin
interface Fightable {
    val health: Int
    fun attack(): Int
    fun isAlive(): Boolean = health > 0
}

abstract class Monster(override val health: Int) : Fightable
class Goblin(health: Int) : Monster(health) { override fun attack() = 4 }
```
