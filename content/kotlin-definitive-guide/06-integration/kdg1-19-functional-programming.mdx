## 从本章问题开始

19. Functional Programming Basics要解决的不是语法记忆，而是用变换、过滤、合并和惰性Sequence构造透明数据管线，并通过评估定位代价。先写出输入和期望结果，再运行最小切片；如果无法解释失败落在编译期、边界层还是运行期，程序即使输出一次正确答案也未通过。

本页不把 val 等同深度不可变，也不把简洁语法等同动态类型。Kotlin 的类型、可空性、求值规则和对象模型共同压缩非法状态；本章不变量是用变换、过滤、合并和惰性Sequence构造透明数据管线，并通过评估定位代价的输入、类型边界、求值结果和失败路径都能由独立读者重放。

## 最小可执行切片

```kotlin
val result = (1..1_000_000)
    .asSequence()
    .filter { it % 2 == 0 }
    .map { it * it }
    .take(5)
    .toList()

check(result == listOf(4, 16, 36, 64, 100))
```

运行切片时固定 Kotlin/JDK 或 Android 工具链版本、输入数据和命令；保存标准输出、编译诊断及断言。迁移实验必须另建记录，不能静默改写2018年的历史坐标。
