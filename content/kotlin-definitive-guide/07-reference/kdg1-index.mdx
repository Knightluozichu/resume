## 从本章问题开始

索引要解决的不是语法记忆，而是用问题、符号、概念关系和章节定位来检索全书，而不是线性翻找关键词。先写出输入和期望结果，再运行最小切片；如果无法解释失败落在编译期、边界层还是运行期，程序即使输出一次正确答案也未通过。

本页不把 val 等同深度不可变，也不把简洁语法等同动态类型。Kotlin 的类型、可空性、求值规则和对象模型共同压缩非法状态；本章不变量是用问题、符号、概念关系和章节定位来检索全书，而不是线性翻找关键词的输入、类型边界、求值结果和失败路径都能由独立读者重放。

## 正式目录逐项深读

### Index

Index服务于用问题、符号、概念关系和章节定位来检索全书，而不是线性翻找关键词。把这个目录坐标翻译成一个可执行或可判定合同，明确输入、状态变化、可见结果和反例，并以问题索引、符号索引、关系图、章节反向链接和检索测试完成独立复核。

在 索引 的 界定责任 阶段，Index先声明可接受输入和状态拥有者，再说明为何得到当前结果。随后进入比较方案，使用同一份输入把正常路径与把同名API命中当成语义答案，忽略版本和上下文产生的反例并排保存。

对 Index 的四级验收分别是：正文出现该坐标；解释它如何参与用问题、符号、概念关系和章节定位来检索全书，而不是线性翻找关键词；在章专属实验中选择该节点并观察反馈；最后凭问题索引、符号索引、关系图、章节反向链接和检索测试回答练习、复位并重放。

## 最小可执行切片

```kotlin
val index = mapOf(
    "null safety" to listOf("6", "20"),
    "function type" to listOf("5", "20"),
    "state restoration" to listOf("21"),
)

check(index.getValue("null safety").contains("6"))
```

运行切片时固定 Kotlin/JDK 或 Android 工具链版本、输入数据和命令；保存标准输出、编译诊断及断言。迁移实验必须另建记录，不能静默改写2018年的历史坐标。
