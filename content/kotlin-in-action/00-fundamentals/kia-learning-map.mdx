## 知识体系全景

<KiaLearningMapDiagram />

《Kotlin实战》基于 Dmitry Jemerov 和 Svetlana Isakova 的经典著作，系统讲解 Kotlin 语言的核心特性、类型系统和并发编程。全书分为三大知识维度，十个章节递进展开。

## 三大知识维度

### 维度一：语言核心

语言核心是 Kotlin 编程的表达基础，覆盖第 1-4 章：

```kotlin
// Kotlin 简介——为什么选择 Kotlin
// Kotlin 基础——val/var、when、字符串模板
// 函数定义与调用——扩展函数、默认参数
// 类、对象与接口——data class、sealed class、object
```

<Callout type="info" title="递进关系">
简介确立设计哲学 → 基础提供语法手段 → 函数提供封装能力 → OOP 提供建模手段。每一章建立在前一章之上。
</Callout>

### 维度二：类型与抽象

类型与抽象是 Kotlin 的安全基石和设计能力，覆盖第 5-7 章：

```kotlin
// Lambda 编程——高阶函数、inline、集合操作
// 类型系统与泛型——空安全、智能转换、out/in 型变
// DSL 与领域建模——带接收者 Lambda、@DslMarker
```

<Callout type="warning" title="关键交叉点">
Lambda × 函数类型 = 高阶函数；类型系统 × OOP = data class + 泛型；Lambda × DSL = 带接收者 Lambda。这些交叉点构成了 Kotlin 最强大的表达能力。
</Callout>

### 维度三：并发与工程

并发与工程是 Kotlin 的落地能力，覆盖第 8 章：

```kotlin
// 并发与协程——suspend、launch/async、Flow
// 结构化并发——coroutineScope、自动取消
suspend fun fetchUser(id: String): User = withContext(Dispatchers.IO) {
    api.getUser(id)
}
```

## 全书核心线索

```kotlin
// 一条主线贯穿全书：让代码更简洁、更安全、更惯用

// 简洁——data class 一行替代样板代码
data class User(val name: String, val age: Int)

// 安全——类型系统编译期消除 NPE
fun greet(name: String?): String = name?.let { "Hello, $it" } ?: "Hello, World"

// 惯用——扩展函数 + 协程替代继承 + 回调
fun String.lastChar(): Char = this[length - 1]
```

<Callout type="success" title="学习建议">
按顺序学习每个章节，每章读完后做对应复习题。重点是理解「为什么这样设计」而非「语法是什么」。Kotlin 不是「更好的 Java」，而是用不同的思维方式写更安全、更简洁的代码。
</Callout>

<Glossary>

<GlossaryItem term="语言核心">
Kotlin 的基础语法和面向对象特性，包括变量声明、控制流、函数、类、接口等。是表达任何 Kotlin 程序的基础。
</GlossaryItem>

<GlossaryItem term="类型系统">
Kotlin 对类型的定义和约束规则，包括空安全（String vs String?）、泛型（out/in 型变）、智能转换等。是代码安全的编译期保障。
</GlossaryItem>

<GlossaryItem term="结构化并发">
Kotlin 协程的并发模型，父子协程有明确的生命周期关系——父协程取消时所有子协程自动取消。避免线程泄漏。
</GlossaryItem>

<GlossaryItem term="带接收者Lambda">
Kotlin DSL 的核心机制，Lambda 块内的 `this` 指向接收者对象，可直接访问其成员。是类型安全构建器的基础。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1**：全书的知识体系结构和递进逻辑是什么？

<Answer>
全书分为十个章节（含学习地图和全书复习），覆盖三大知识维度：语言核心（简介、基础、函数、OOP）、类型与抽象（Lambda、类型系统、DSL）、并发与工程（协程、Flow）。递进逻辑：从基础语法到函数到 OOP 到 Lambda 到类型系统到 DSL 到协程，每个主题建立在前一个之上。
</Answer>

**问题 2**：Kotlin 与 Java 在语言设计哲学上有什么核心区别？

<Answer>
Kotlin 强调简洁（data class 消除样板代码）、安全（编译期消除 NPE）、惯用（扩展函数/协程/DSL 替代设计模式），同时保持与 Java 100% 互操作。Java 默认可继承、运行时检查 null、靠工具类和回调。
</Answer>

**问题 3**：用一次完整的项目开发流程串联全书知识体系。

<Answer>
从数据建模（data class）开始，用 sealed class 表达状态，扩展函数增强 API，Lambda 处理集合，泛型抽象数据层，DSL 构建配置 API，最后用协程处理异步网络请求。每个知识点在实际项目中都有明确的落地场景。
</Answer>

**问题 4**：三大知识维度之间有什么内在联系？

<Answer>
语言核心是地基（表达基础），类型与抽象是上层建筑（安全+通用），并发与工程是落地能力（异步编程）。交叉点：函数×Lambda=高阶函数，OOP×类型=data class+泛型，Lambda×DSL=带接收者 Lambda，协程×Lambda=Flow。
</Answer>

</Exercises>
