## 变量与类型

<KiaKotlinBasicsDiagram />

### val vs var

```kotlin
// val（只读引用）——赋值后不可重新赋值，相当于 Java final
val name = "Kotlin"  // 类型推断为 String
// name = "Java"     // 编译错误：val 不能重新赋值

// var（可变引用）——可重新赋值
var age = 10
age = 11  // OK

// val 引用不可变，但对象本身可变
val list = mutableListOf(1, 2, 3)
list.add(4)      // OK——修改对象内容
// list = mutableListOf()  // 编译错误——val 不可重新赋值
```

<Callout type="success" title="最佳实践">
默认用 val，只有确实需要变更时才用 var。val 让代码更安全（不可变引用减少意外修改）、更可读（读者知道变量不会变）、更易并发（不可变对象天生线程安全）。
</Callout>

### 基本类型

```kotlin
// Kotlin 基本类型是类（有方法），编译时尽可能用 JVM 基本类型避免装箱
val i: Int = 42          // 对应 Java int
val l: Long = 42L        // 对应 Java long
val d: Double = 3.14     // 对应 Java double
val f: Float = 3.14f     // 对应 Java float
val b: Boolean = true
val s: String = "hello"
val c: Char = 'A'

// Any = 所有非空类型的根（相当于 Java Object）
val any: Any = "hello"

// Unit = 无返回值（相当于 Java void，但是一个类型）
fun printHello(): Unit { println("Hello") }

// Nothing = 永远不会有值（如无限循环、总是抛异常）
fun fail(msg: String): Nothing { throw IllegalArgumentException(msg) }
```

### 类型推断

```kotlin
// 全面类型推断——无需显式声明类型
val x = 42              // Int
val s = "hello"         // String
val list = listOf(1, 2) // List<Int>
val map = mapOf("a" to 1)  // Map<String, Int>

// 函数返回类型也可推断（表达式体函数）
fun double(x: Int) = x * 2  // 返回类型推断为 Int
```

## 控制流

### when 表达式

```kotlin
// when 是表达式有返回值，分支无需 break
val desc = when (x) {
    1 -> "one"
    2, 3 -> "two or three"           // 多值匹配
    in 4..10 -> "small"              // 范围匹配
    is Int -> "integer: $x"          // 类型匹配 + 智能转换
    else -> "unknown"
}

// when 配合 sealed class 实现编译期穷尽检查
sealed class Result
class Success(val data: String) : Result()
class Error(val msg: String) : Result()

fun handle(r: Result) = when (r) {
    is Success -> println("OK: ${`r.data`}")   // 智能转换为 Success
    is Error -> println("ERR: ${`r.msg`}")      // 智能转换为 Error
    // 无需 else——编译器知道已覆盖所有情况
}
```

### if 表达式

```kotlin
// if 也是表达式有返回值
val max = if (a > b) a else b

// 多行 if
val result = if (score >= 60) {
    println("passed")
    "PASS"
} else {
    println("failed")
    "FAIL"
}
```

### 区间与迭代

```kotlin
// 闭区间 1..10
for (i in 1..10) print("$i ")       // 1 2 3 ... 10

// 半开区间 1 until 10
for (i in 1 until 10) print("$i ")  // 1 2 3 ... 9

// 降序
for (i in 10 downTo 1) print("$i ") // 10 9 8 ... 1

// 步长
for (i in 1..10 step 2) print("$i ") // 1 3 5 7 9

// 集合迭代
val list = listOf("a", "b", "c")
for ((index, value) in list.withIndex()) {
    println("$index: $value")
}
```

## 字符串模板与集合

### 字符串模板

```kotlin
val name = "Kotlin"
val count = 3

// $ 变量名
println("Hello, $name!")              // Hello, Kotlin!

// ${`表达式`}
println("Length: ${`name.length`}")    // Length: 6
println("Count: ${`count + 1`}")       // Count: 4

// 三引号字符串（raw string）——多行无需转义
val json = """
    {
        "name": "$name",
        "count": $count
    }
""".trimIndent()
```

### 集合创建

```kotlin
// 只读集合
val list = listOf(1, 2, 3)           // List<Int>
val set = setOf("a", "b")            // Set<String>
val map = mapOf("key" to "value")    // Map<String, String>

// 可变集合
val mList = mutableListOf(1, 2)
mList.add(3)

val mSet = mutableSetOf("a")
mSet.add("b")

// 只读集合不是不可变集合——它只是接口不暴露修改方法
// 底层实现可能是可变的（如 Java ArrayList）
```

<Callout type="info" title="只读 vs 不可变">
Kotlin 的 `listOf` 返回的是「只读」接口（List），底层实现可能是可变的。真正的不可变集合需用 kotlinx.collections.immutable 库的 `persistentListOf`。
</Callout>

<Glossary>

<GlossaryItem term="val（只读引用）">
赋值后不可重新赋值的变量声明关键字，相当于 Java 的 final。引用不可变但对象内容可能可变。优先使用 val。
</GlossaryItem>

<GlossaryItem term="when表达式">
Kotlin 的多分支控制流结构，是表达式有返回值。支持值匹配、范围匹配、类型匹配，配合 sealed class 实现编译期穷尽检查。
</GlossaryItem>

<GlossaryItem term="字符串模板">
用 `$变量名` 或 `${'表达式'}` 在字符串中嵌入值。相比 Java 字符串拼接更简洁可读。
</GlossaryItem>

<GlossaryItem term="类型推断">
编译器根据右侧表达式自动推断变量类型，无需显式声明。Kotlin 全面支持类型推断（局部变量、字段、函数返回值）。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1**：val 和 var 的区别是什么？为什么推荐 val？

<Answer>
val 是只读引用（不可重新赋值），var 是可变引用（可重新赋值）。推荐 val 因为更安全（减少意外修改）、更可读（读者知道不会变）、更易并发（不可变对象线程安全）。注意 val 引用不可变但对象内容可能可变。
</Answer>

**问题 2**：Kotlin 的 when 表达式相比 Java switch 有什么优势？

<Answer>
when 是表达式有返回值；支持值/范围/类型/条件匹配；配合 is 实现智能转换；配合 sealed class 实现编译期穷尽检查；无 fall-through 不需 break；支持多值匹配。
</Answer>

**问题 3**：Kotlin 的字符串模板和三引号字符串如何使用？

<Answer>
$ 变量名和 `${'表达式'}` 嵌入值。三引号 `"""..."""` 支持多行无需转义，配合 trimIndent() 去缩进。三引号中仍可用模板。
</Answer>

**问题 4**：Kotlin 的基本类型与 Java 有什么区别？

<Answer>
Kotlin 基本类型是类（Int/Long 等有方法），编译时尽可能用 JVM 基本类型避免装箱。Any 是非空类型根，Unit 相当于 void 但是单例类型，Nothing 是永远不会有值的类型。全面类型推断。
</Answer>

</Exercises>
