## Lambda 语法

<KiaLambdaMembersDiagram />

```kotlin
// 函数类型：(参数类型) -> 返回类型
val sum: (Int, Int) -> Int = { x, y -> x + y }
val result = sum(1, 2)  // 3

// Lambda 语法约定
// 1. 完整语法
list.map({ x: Int -> x * 2 })

// 2. 类型推断
list.map({ x -> x * 2 })

// 3. it 隐式参数（单参数时）
list.map({ it * 2 })

// 4. 末尾 Lambda 约定（最后一个参数是函数类型时，Lambda 放括号外）
list.map() { it * 2 }

// 5. 省略空括号
list.map { it * 2 }
```

<Callout type="info" title="末尾 Lambda 的意义">
末尾 Lambda 约定让嵌套的 Lambda 调用看起来像自然语言的块结构，是 Kotlin DSL 设计的基础。如 `html { body { p("text") } }`。
</Callout>

## 集合函数式操作

```kotlin
data class Student(val name: String, val score: Int, val subject: String)

val students = listOf(
    Student("Alice", 85, "Math"),
    Student("Bob", 60, "Math"),
    Student("Charlie", 90, "Physics"),
    Student("Dave", 75, "Physics"),
)

// map——变换每个元素
val names = students.map { it.name }
// [Alice, Bob, Charlie, Dave]

// filter——过滤
val passed = students.filter { it.score >= 60 }
// [Alice(85), Bob(60), Charlie(90), Dave(75)]

// sortedBy——排序
val ranked = students.sortedByDescending { it.score }
// [Charlie(90), Alice(85), Dave(75), Bob(60)]

// groupBy——分组
val bySubject = students.groupBy { it.subject }
// {Math=[Alice, Bob], Physics=[Charlie, Dave]}

// flatMap——扁平映射
val allChars = listOf("ab", "cd").flatMap { it.toList() }
// [a, b, c, d]

// reduce——聚合
val sum = listOf(1, 2, 3).reduce { acc, i -> acc + i }  // 6

// fold——带初始值聚合
val product = listOf(1, 2, 3).fold(1) { acc, i -> acc * i }  // 6

// 链式操作
val topMath = students
    .filter { it.subject == "Math" }
    .sortedByDescending { it.score }
    .map { "${it.name}: ${it.score}" }
// [Alice: 85, Bob: 60]
```

## inline 内联函数

```kotlin
// 问题：普通高阶函数的 Lambda 编译为 Function 匿名类对象，有 GC 压力
// 解决：inline 关键字让编译器将函数体和 Lambda 体直接展开到调用处

inline fun measure(block: () -> Unit): Long {
    val start = System.currentTimeMillis()
    block()
    return System.currentTimeMillis() - start
}

// 调用处会被内联展开，无匿名类创建
val time = measure {
    repeat(1000) { println(it) }
}

// inline 的额外能力：
// 1. 非局部返回——Lambda 中的 return 直接从外层函数返回
inline fun forEach(str: String, action: (Char) -> Unit) {
    for (c in str) action(c)
}

fun findFirstDigit(str: String): Char? {
    forEach(str) {
        if (it.isDigit()) return it  // 非局部返回——直接从 findFirstDigit 返回
    }
    return null
}

// 2. reified 类型参数——运行时保留泛型类型信息
inline fun <reified T> List<*>.filterByType(): List<T> {
    return this.filter { it is T } as List<T>
}

val strings = listOf(1, "a", 2, "b").filterByType<String>()  // [a, b]
```

## 标准库作用域函数

```kotlin
// 五个作用域函数：let / run / apply / also / with

// apply——this + 返回对象本身（对象配置）
val builder = StringBuilder().apply {
    append("Hello")
    append(", ")
    append("Kotlin")
}

// also——it + 返回对象本身（副作用链式调用）
val list = mutableListOf(1, 2, 3).also {
    println("Created: $it")  // 不改原对象
}.also {
    println("Size: ${`it.size`}")
}

// let——it + 返回 Lambda 结果（null 安全作用域）
val name: String? = getName()
val length = name?.let {
    println("Processing: $it")
    it.length
} ?: 0

// run——this + 返回 Lambda 结果（对象配置后返回结果）
val result = "Hello".run {
    length + 5  // this 是 "Hello"，返回 10
}

// with——this + 返回 Lambda 结果（分组操作，非扩展函数）
val config = Config()
with(config) {
    setHost("localhost")
    setPort(8080)
    setTimeout(5000)
}
```

<Callout type="success" title="选择口诀">
配置用 apply/also（返回本身），计算用 let/run/with（返回结果）；需重命名用 let（it 可改名），需 this 上下文用 apply/run/with。
</Callout>

<Glossary>

<GlossaryItem term="高阶函数">
接受函数类型作为参数或返回函数类型的函数。如 `map`、`filter`、`forEach` 等。
</GlossaryItem>

<GlossaryItem term="末尾 Lambda">
当函数最后一个参数是函数类型时，Lambda 可放在括号外甚至省略空括号。让 DSL 式 API 成为可能。
</GlossaryItem>

<GlossaryItem term="inline 内联函数">
用 `inline` 关键字标记的函数，编译器将函数体和 Lambda 体直接展开到调用处。消除匿名类创建开销，支持非局部返回和 reified。
</GlossaryItem>

<GlossaryItem term="作用域函数">
标准库提供的 let/run/apply/also/with 五个函数，用于在特定作用域内方便地操作对象。区别在于接收者引用（this/it）和返回值（对象本身/Lambda 结果）。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1**：Kotlin 的 Lambda 语法有哪些约定？什么是末尾 Lambda？

<Answer>
完整语法 `{ x: Int -> x * 2 }`，类型推断省略类型，单参数用 it，末尾 Lambda 放括号外。末尾 Lambda 约定让嵌套调用像块结构，是 DSL 基础。
</Answer>

**问题 2**：inline 内联函数解决了什么问题？原理是什么？

<Answer>
解决高阶函数 Lambda 的匿名类创建开销和 GC 压力。原理：编译器将函数体和 Lambda 体直接展开到调用处。额外支持非局部返回和 reified 类型参数。代价是代码膨胀。
</Answer>

**问题 3**：五个作用域函数有什么区别？如何选择？

<Answer>
apply（this+返回本身，配置）；also（it+返回本身，副作用链）；let（it+返回结果，null 安全）；run（this+返回结果，配置后返回）；with（this+返回结果，非扩展，分组操作）。口诀：配置用 apply/also，计算用 let/run/with。
</Answer>

**问题 4**：用集合函数式操作实现一个数据处理场景。

<Answer>
`scores.filter { it.score >= 0 }.groupBy { it.subject }.mapValues { it.value.map { it.score }.average() }.filterValues { it >= 60 }`。链式调用表达数据管道，每个操作返回新集合符合不可变原则。
</Answer>
