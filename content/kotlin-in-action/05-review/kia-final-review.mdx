## 三大维度回顾

### 维度一：语言核心

```kotlin
// 简介——四大设计目标
// 简洁（data class）/ 安全（空安全）/ 互操作（Java 兼容）/ 工具友好

// 基础——变量、控制流、集合
val name = "Kotlin"              // val 优先
val desc = when (score) {        // when 表达式
    in 90..100 -> "A"
    in 60..89 -> "Pass"
    else -> "Fail"
}
val list = listOf(1, 2, 3)       // 只读集合

// 函数——扩展、默认参数
fun String.lastChar(): Char = this[length - 1]  // 扩展函数
fun greet(name: String = "World") = "Hi, $name!" // 默认参数

// OOP——data class、sealed、object
data class User(val name: String, val age: Int)
sealed class State { object Loading : State(); data class Done(val d: Data) : State() }
object Database { fun connect() = Unit }
```

### 维度二：类型与抽象

```kotlin
// Lambda——高阶函数、集合操作、inline
list.map { it * 2 }.filter { it > 5 }.sortedBy { it }
inline fun <T> measure(block: () -> T): T { /* ... */ }

// 类型系统——空安全、智能转换、泛型
val s: String? = null
val len = s?.length ?: 0          // 空安全
if (e is String) e.length         // 智能转换
interface Producer<out T> { fun produce(): T }  // 协变

// DSL——带接收者 Lambda、@DslMarker
fun html(init: HTML.() -> Unit) { /* ... */ }
@DslMarker annotation class HtmlDsl
```

### 维度三：并发与工程

```kotlin
// 协程——suspend、launch/async、结构化并发
suspend fun fetch(): Data = withContext(Dispatchers.IO) { api.get() }
coroutineScope {
    val a = async { fetchA() }
    val b = async { fetchB() }
    combine(a.await(), b.await())
}

// Flow——异步流
fun search(q: Flow<String>): Flow<Result> = q
    .debounce(300)
    .flatMapLatest { flow { emit(api.search(it)) } }
```

## 场景选型矩阵

| 场景 | Kotlin 方案 | Java 写法 |
|------|------------|-----------|
| 数据建模 | `data class User(val name, val age)` | 手写 equals/hashCode |
| 状态分支 | `sealed class + when`（穷尽检查） | `enum + switch` |
| 空值处理 | `String? + ?. + ?:` | `if (x != null)` |
| 集合操作 | `list.map { }.filter { }` | Stream / for 循环 |
| 异步编程 | `suspend + Flow` | 回调 / CompletableFuture |
| 单例模式 | `object Singleton` | 双重检查锁 |
| 工具函数 | 顶层函数 + 扩展函数 | `XxxUtils.static()` |
| 配置构建 | 带接收者 Lambda + @DslMarker | Builder 模式 |

## 综合应用

```kotlin
// 用一段完整代码串联全书核心特性

// data class（第4章）+ 空安全（第6章）
data class User(val id: String, val name: String, val score: Int?)

// sealed class（第4章）+ when 穷尽检查
sealed class SearchState {
    object Loading : SearchState()
    data class Success(val users: List<User>) : SearchState()
    data class Error(val msg: String) : SearchState()
}

// 扩展函数（第3章）+ 集合操作（第5章）
fun List<User>.topScorers(n: Int) = filter { it.score != null }
    .sortedByDescending { it.score }
    .take(n)

// suspend（第8章）+ withContext
suspend fun searchUsers(query: String): List<User> =
    withContext(Dispatchers.IO) {
        api.search(query).map { it.toDomain() }
    }

// Flow（第8章）+ 高阶函数（第5章）
fun searchFlow(query: Flow<String>): Flow<SearchState> = query
    .debounce(300)
    .distinctUntilChanged()
    .flatMapLatest { q ->
        flow {
            emit(SearchState.Loading)
            try {
                emit(SearchState.Success(searchUsers(q).topScorers(10)))
            } catch (e: Exception) {
                emit(SearchState.Error(e.message ?: "unknown"))
            }
        }
    }

// 使用——when 智能转换（第6章）
fun main() = runBlocking {
    searchFlow(flowOf("Kotlin")).collect { state ->
        when (state) {
            is SearchState.Loading -> println("Loading...")
            is SearchState.Success -> state.users.forEach { println(it) }
            is SearchState.Error -> println("Error: ${`state.msg`}")
        }
    }
}
```

<Callout type="success" title="核心设计哲学">
简洁（val 优先 / data class 消除样板）、安全（空安全 / sealed 穷尽检查）、惯用（扩展函数 / 协程 / DSL 替代设计模式）。Kotlin 不是「更好的 Java」，而是用不同的思维方式写更安全、更简洁的代码。
</Callout>

<Exercises>

**问题 1**：Kotlin 的核心设计哲学是什么？用三个关键词概括。

<Answer>
简洁（消除样板代码，data class / 默认参数 / 类型推断）；安全（编译期消除 NPE，空安全 / sealed 穷尽检查 / 默认 final）；惯用（用扩展函数 / 协程 / DSL 替代设计模式，而非照搬 Java）。
</Answer>

**问题 2**：对比 Kotlin 和 Java 在常见场景中的解决方案。

<Answer>
数据建模 data class vs 手写；状态分支 sealed+when vs enum+switch；空值 String?+?. vs if-null；集合 map/filter vs Stream；异步 suspend+Flow vs 回调；单例 object vs 双检锁；工具扩展函数 vs Utils 类；配置 DSL vs Builder。
</Answer>

**问题 3**：用完整代码示例展示全书特性综合运用。

<Answer>
data class 建模 + sealed class 状态 + 扩展函数增强 API + 集合操作处理数据 + suspend/withContext 网络请求 + Flow 搜索流 + when 智能转换处理状态。每个特性在实际项目中有明确落地。
</Answer>

**问题 4**：如何从 Java 迁移到 Kotlin？注意事项？

<Answer>
渐进式迁移（新文件用 Kotlin）。从 data class 开始，消除 null（Java 平台类型注意），回调转协程，工具类转扩展函数。注意 @JvmStatic/@JvmField/@JvmOverloads 注解、平台类型可空性、团队培训。
</Answer>
