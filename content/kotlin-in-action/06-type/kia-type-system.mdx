## 空安全机制

<KiaTypeSystemDiagram />

```kotlin
// 类型系统区分非空和可空
var a: String = "hello"    // 非空——不可赋 null
var b: String? = null      // 可空——可持有 null

// a.length  // OK——非空类型直接访问
// b.length  // 编译错误——可空类型不能直接访问

// 四个空安全操作符

// 1. ?. 安全调用——null 时不执行，返回 null
val len1: Int? = b?.length

// 2. ?: Elvis 运算符——null 时返回默认值
val len2: Int = b?.length ?: 0

// 3. !! 非空断言——null 时抛 NPE（慎用）
val len3: Int = b!!.length

// 4. let + ?. 组合——null 安全作用域
b?.let {
    println("Length: ${`it.length`}")  // it 是非空 String
}
```

<Callout type="warning" title="平台类型">
Java 互操作时，Java 返回值在 Kotlin 中是平台类型（`String!`），可能为空也可能非空。需显式处理可空性或加 `@Nullable` 注解。
</Callout>

## 智能转换

```kotlin
// is 类型检查后自动转换
fun process(e: Any): Int {
    if (e is String) {
        // e 自动从 Any 转为 String——无需强制转换
        return e.length
    }
    if (e is Int) {
        return e + 1  // e 自动转为 Int
    }
    return 0
}

// !is 否定检查 + 提前返回
fun getStringLength(obj: Any): Int {
    if (obj !is String) return 0
    return obj.length  // obj 自动转为 String
}

// when + is 分支自动转换
fun describe(e: Any): String = when (e) {
    is String -> "String of length ${`e.length`}"
    is Int -> "Int: $e"
    is List<*> -> "List of size ${`e.size`}"
    else -> "Unknown"
}

// as? 安全转换——失败返回 null 而非 ClassCastException
val str: String? = e as? String  // e 不是 String 时返回 null
```

<Callout type="info" title="智能转换的限制">
只在 val 局部变量和不可变属性上生效。var 可变属性（可能被其他线程修改）或有自定义 getter 的属性不进行智能转换。
</Callout>

## 泛型与型变

### out 协变与 in 逆变

```kotlin
// out 协变（生产者）——T 只能出现在返回位置
interface Producer<out T> {
    fun produce(): T
}

// Producer<String> 是 Producer<Any> 的子类型
val p: Producer<Any> = ProducerImpl<String>()  // OK

// in 逆变（消费者）——T 只能出现在参数位置
interface Consumer<in T> {
    fun consume(t: T)
}

// Consumer<Any> 是 Consumer<String> 的子类型
val c: Consumer<String> = ConsumerImpl<Any>()  // OK

// 不变（invariant）——既读又写，无父子关系
// MutableList<String> 和 MutableList<Any> 无父子关系

// PECS 原则：Producer Extends, Consumer Super
// 生产者用 out（extends），消费者用 in（super）
```

### 星投影

```kotlin
// * 表示类型参数未知
// Array<*> 等价于 Array<out Any?>（只读 Any?）
fun printArray(array: Array<*>) {
    for (item in array) println(item)  // item 是 Any?
    // array[0] = "x"  // 编译错误——不能写入未知类型
}

// 星投影用于类型不确定时的 API 签名
fun getSize(map: Map<*, *>): Int = map.size
```

### reified 具体化

```kotlin
// 问题：JVM 泛型类型擦除，运行时无法检查 T 的类型
// 解决：reified 让 inline 函数在运行时保留 T 的类型信息

inline fun <reified T> List<*>.filterByType(): List<T> {
    return this.filter { it is T } as List<T>
}

// 调用——运行时检查 is T
val mixed: List<Any> = listOf(1, "a", 2, "b", 3.14)
val strings = mixed.filterByType<String>()  // [a, b]
val ints = mixed.filterByType<Int>()        // [1, 2]

// 实际用途
// 1. 类型安全的 JSON 解析
inline fun <reified T> parseJson(json: String): T =
    gson.fromJson(json, T::class.java)

// 2. 简化的 Activity 跳转（Android）
inline fun <reified T : Activity> Context.startActivity() {
    startActivity(Intent(this, T::class.java))
}

// 3. 依赖注入
inline fun <reified T : ViewModel> Fragment.injectViewModel(): T =
    ViewModelProvider(this)[T::class.java]
```

<Callout type="warning" title="reified 的限制">
必须配合 inline 函数使用（依赖内联展开）；不能用于普通类的泛型参数；Java 侧不可调用（是 Kotlin 编译器特性）。
</Callout>

<Glossary>

<GlossaryItem term="?.（安全调用）">
当接收者非空时调用方法/属性，为 null 时返回 null。支持链式：`person?.address?.city`。
</GlossaryItem>

<GlossaryItem term="?:（Elvis 运算符）">
左侧为 null 时返回右侧默认值。如 `name ?: "unknown"`。
</GlossaryItem>

<GlossaryItem term="out 协变">
`Producer<out T>`——T 只出现在返回位置（生产者）。Producer<String> 是 Producer<Any> 的子类型。
</GlossaryItem>

<GlossaryItem term="in 逆变">
`Consumer<in T>`——T 只出现在参数位置（消费者）。Consumer<Any> 是 Consumer<String> 的子类型。
</GlossaryItem>

<GlossaryItem term="reified">
用 `inline fun <reified T>` 让编译器在调用处将 T 替换为实际类型，运行时可用 `T::class.java` 获取类型信息。解决泛型类型擦除问题。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1**：Kotlin 空安全有哪些操作符？各自作用？

<Answer>
?. 安全调用（null 时返回 null）；?: Elvis（null 时返回默认值）；!! 非空断言（null 时抛 NPE，慎用）；智能转换（if (s != null) 后自动非空）。
</Answer>

**问题 2**：out 协变和 in 逆变是什么？PECS 原则？

<Answer>
out 协变——T 只在返回位置（生产者），Producer<String> 是 Producer<Any> 子类型。in 逆变——T 只在参数位置（消费者），Consumer<Any> 是 Consumer<String> 子类型。PECS：Producer Extends, Consumer Super。Kotlin 在声明处指定型变。
</Answer>

**问题 3**：智能转换如何工作？有什么限制？

<Answer>
is 检查后自动转为具体类型，无需强制转换。when 分支内也自动转换。限制：只在 val 局部变量和不可变属性上生效，var 可变属性和有自定义 getter 的属性不生效。
</Answer>

**问题 4**：reified 具体化解决了什么问题？

<Answer>
解决 JVM 泛型类型擦除——运行时无法检查 T 的类型。reified 让 inline 函数在运行时保留 T 类型信息，可用 `T::class.java` 和 `it is T`。用途：JSON 解析、Activity 跳转、依赖注入。限制：必须 inline，不能用于类泛型，Java 不可调用。
</Answer>

</Exercises>
