## 核心概念

### 什么是 LangChain 编程

LangChain 编程是**以 LangChain 框架为核心，构建大语言模型应用**的完整工程实践，其核心链路是**从框架理解到生产部署**：

- **理解**：掌握 LangChain 架构设计、Runnable 接口和 LCEL 表达式语言
- **组装**：通过 Model I/O 和 Chains 组装基础推理管道
- **增强**：通过 Memory 维持对话状态，通过 RAG 接入外部知识
- **自主**：通过 Agent 和 Tools 让模型从被动问答进化为主动执行
- **部署**：通过流式、缓存、追踪、容错将原型变为可靠线上服务

## 术语表

<Glossary>

<GlossaryItem term="LangChain">

开源的大语言模型应用开发框架，通过 Runnable 接口标准化所有组件的调用方式，用 LCEL 表达式语言实现模块化组合，支持数百种模型和工具集成。

</GlossaryItem>

<GlossaryItem term="Runnable 接口">

LangChain 的核心抽象，所有组件（Prompt、Model、Parser、Retriever 等）都实现该接口，提供统一的 invoke/stream/batch 调用模式，使组件可以无缝组合。

</GlossaryItem>

<GlossaryItem term="LCEL (LangChain Expression Language)">

LangChain 表达式语言，用管道符 | 连接 Runnable 组件，自动传递数据，原生支持流式输出、异步调用、批量处理和 LangSmith 可观测性追踪。

</GlossaryItem>

<GlossaryItem term="Model I/O">

LangChain 的基础管道模块，包含三个阶段：Prompts（提示模板格式化输入）、Models（LLM/ChatModel 统一调用）、Output Parsers（输出解析结构化）。

</GlossaryItem>

<GlossaryItem term="Agent">

以大语言模型为推理引擎，能够自主选择工具、规划步骤、循环执行直到完成任务的智能系统。ReAct 循环（思考-行动-观察）是其核心执行模式。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

《LangChain 编程从入门到实践》全书的核心主题是什么？LangChain 解决什么问题？

<Answer>

全书核心主题是系统讲解如何使用 LangChain 框架开发大语言模型应用。LangChain 解决的核心问题是：大语言模型本身只提供文本输入输出接口，构建完整应用需要提示管理、链式调用、记忆状态、工具集成、检索增强等大量工程化能力。LangChain 通过标准化抽象（Runnable 接口）、模块化组件和 LCEL 表达式语言，将异构模型和复杂流程统一为可组合、可编排、可部署的应用框架。

</Answer>

### 问题 2

全书十章如何组织？分为哪几个学习阶段？

<Answer>

全书十章分为四个学习阶段：基础概念（ch0-ch1）——知识全景图定位学习方向，LangChain 框架概览讲解架构与核心模块。核心组件（ch2-ch4）——模型与提示模板讲解 Model I/O，链与序列操作讲解 LLMChain 和 LCEL 管道，记忆与状态管理讲解四种 Memory 类型。高级应用（ch5-ch7）——工具与智能体讲解 Agent 执行循环，RAG 系统实现讲解检索增强生成，高级链与路由讲解 LCEL 原语和动态分发。生产实践（ch8-ch9）——生产部署与优化讲解流式缓存追踪容错，全书复习整合知识闭环。

</Answer>

### 问题 3

LangChain 的技术栈包含哪些核心模块？它们之间是什么关系？

<Answer>

五大核心模块：Model I/O 是基础管道，处理提示格式化、模型调用和输出解析。Chains 是流程编排，将组件按顺序组合。Memory 维持多轮对话上下文状态。Agents 实现自主执行，LLM 作为推理引擎选择工具和规划步骤。Retrieval 提供知识增强，文档加载分块向量化存储检索。关系：Model I/O 是基础，Chains 是编排，Memory 维持状态，Agents 实现自主，Retrieval 提供知识。五者通过 Runnable 接口统一组合。

</Answer>

### 问题 4

全书如何形成一个从框架理解到生产部署的完整知识闭环？

<Answer>

全书形成"框架-组件-智能应用-生产部署-整合"的知识演进：框架层理解 LangChain 架构和 Runnable/LCEL 抽象，组件层掌握 Model I/O、Chains、Memory 三大核心组件，应用层通过 Agent、RAG、高级链构建智能应用，工程层通过流式/缓存/追踪/容错实现生产部署，整合层用统一视角串联全书知识。核心脉络：框架理解定义边界，组件掌握定义能力，智能应用定义场景，生产部署定义可靠，知识闭环定义整合。

</Answer>

</Exercises>
