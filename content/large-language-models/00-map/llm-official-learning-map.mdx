## 为什么先看地图

挑一本书，最容易从自己最想做的项目那一页读起。但前面没走过的路不会因此消失：当某一页看不下去，你需要知道回到哪里补课，而不是继续搜更多同类文章。

这页解决两个问题：书里有哪些位置；为眼下的任务，哪些位置应当先经过。没有这张地图，目录里的重复入口容易被数成新内容，读过几个热门主题也容易被误认为走完了全书。

### 从图读出前置闭包

<Term def="从目标出发，反复把所有直接先修加入，直到不再增加的最小集合；它包含目标自身。">
  前置闭包
</Term>
把“先补哪里”变成一个可以复算的问题。设目标集合为 T，pred(S) 是 S
中所有章的直接先修：

$$
C_0=T,\qquad C_{k+1}=C_k\cup\mathrm{pred}(C_k)
$$

这在说：先写目标，再补上一层先修；一直补到集合不再变化。图只有12个章且不成环，因此有限轮就会停止。第8章的直接先修是第4、5章，第5章又依赖第4章，第4章依赖第3章，第3章依赖第2章，最后得到 {2,3,4,5,8}。这不是把1到8全部照单全收。

<Term def="把图中每条先修边的起点放在终点之前的一种排序，通常不止一种。">
  拓扑序
</Term>
把集合变成可执行的阅读顺序。本页用升序作为确定性的择序规则，因为当前每条边都从小编号指向大编号。真实学习可以回看；这里禁止的是在排课时声称“先修已经完成”，实际却还没有安排它。

### 为什么浅80不能替代深153

浅层“3.7 推理优化”是一个入口，深层还有推测解码、简化、修剪、蒸馏、混合精度和扩展推理六个不同地址。把入口当成这些地址全部展开，会让后续排课以为没有细分任务。树中的柱长只统计各深度可见的坐标数量，**不是掌握程度、正文忠实率或质量分数**。

搜索“完全不存在的节点”应明确显示没有匹配，不能悄悄回退为全目录。搜索也不替代阅读：即便153个位置都可展开，本轮仍只访问到书目与目录，没有读到原书正文，更不能从目录名称推断作者的具体立场。

## 用14个根定位全书

以下是现有学习地图 profile 的全部14个概念根：前言、12章、参考文献。每节给出本站建议的问题与返回位置；更细的139个编号坐标在实验二按原名展开。这里讲的是如何进入各章，不把目录里的每个术语再讲成一门压缩课程。

### 前言

前言是正式坐标，但不是训练技术的第1个步骤。读它时先写下自己的问题、已有基础与输出期待，再决定沿哪个任务走。实验二把它保留为独立根，实验三把“先读前言确定问题”固定放在排课之前；这里不臆造前言中作者的承诺或结论。

### 第1章 大语言模型：辩论、争议与未来发展方向

这个入口适合先区分“表现得像”和“证明具有”。目录的意识、具身化、世界模型、沟通意图与系统泛化各有不同问题，不应由一句流畅回答代替。本页把它接到第10章的风险讨论，而不是接成技术训练的强制入口。[Butlin等2023年的报告摘要](https://arxiv.org/abs/2308.08708)按多种意识理论提出指标，结论依赖这些理论；[Bender与Koller的2020年立场论文摘要](https://aclanthology.org/2020.acl-main.463/)强调形式与意义的区分。二者提供争论的坐标，不是已经解决争论的统一裁决。

### 第2章 语言模型和分词

先明确文本被分成什么单位，再谈单位之间的概率。按空格、字符、子词、无分词器、可学习分词是树上不同地址，不能用“都是切字符串”抹平。本页将第2章作为技术入口并连向第3章：输入单位变了，序列长度和后续计算的对象也会变。可先写出同一句话的两种切分，再带着单位问题进入下一章。

### 第3章 Transformer

这一章是技术路线的枢纽：编码器、编码器—解码器、位置、长上下文、外部记忆、效率与推理优化都可在目录树逐级找到。[2017年原始论文](https://arxiv.org/html/1706.03762)以注意力为核心描述架构，并单列位置编码；这支持先识别结构和位置信息，再讨论目标与输出的学习顺序，不意味着论文包含本书全部后续细节。若看第8章时分不清记忆进入哪一环，先回到这里，而不是只换问答提示。

### 第4章 预训练目标和解码策略

目录把架构、预训练目标、代表性模型、解码放在一个章内，提醒读者分别追问“训练时预测什么”和“输出时如何选取”。本站让第4章接在结构之后，再通向上下文、训练扩展、检索和对齐。路线检查若缺这章，含义是缺少比较目标与生成规则的共同语言，不是说读者不能先尝试工具。

### 第5章 上下文学习和轻量级微调

进入此章先区分“给定输入中的示例”与“改变模型的一部分参数”这两类阅读问题。示例选择、排序、思维链、递归提示、校准以及不同轻量微调方法，在树上都有自己的编号。本站把第5章置于检索和偏好路线之前，以便比较提示、检索提供的上下文和参数更新各在何处起作用；不能看到一个好回答就把改进全归给微调。

### 第6章 训练更大的模型

读此章不能只记参数规模。目录将尺度法则、涌现、加速器、数据／流水线／张量并行、专家混合、低精度及省内存设计分开。资源任务从第3、4章进入这里，是为了把“算什么”与“怎样分配计算”连起来；它再通向第7与12章。这里没有把任何尺度关系外推成无条件性能保证，更没有在浏览器里测量训练速度。

### 第7章 稀疏专家模型

这一章的深层目录尤其不能省略：词元选专家、专家选词元、全局分配、随机路由、双层路由和领域专家不等同于一个“路由”按钮。先从第6章带来计算与通信问题，再在第7章询问谁被分给谁、容量不足时发生什么。实验二搜索“7.2”可检查这六个地址是否真实存在；实验三的资源任务会将第7章排在第6章之后。

### 第8章 检索增强型语言模型

做带出处的问答从此章设目标，但不等于只读此章。预训练检索、词元级检索、多跳、检索增强Transformer、黑盒模型与视觉增强是目录的不同分支。本站建议先读第4、5章，才容易问清检索结果改变的是上下文还是训练过程。交付时保存检索片段与回答引用的对应关系；读完目录不会自动获得真实系统的检索准确率。

### 第9章 对齐语言模型与人类偏好

把“输出更受欢迎”和“所有输出更安全”分成两个问题。此章从人类反馈延伸到语言、监督、AI、自我反馈与偏好预训练；KL散度和强化学习方法是深层地址，不宜从目录名自行补写公式。本站让第9章接第4、5章，再接第10章：先识别改变的目标与数据，再检查偏好之外可能遗漏的伤害。

### 第10章 减少偏见和有害性

此章应接住具体的受影响对象，而不是被一条平均分替代。树分别保留偏见、有害性以及解码、提示、数据、投影／正则化、风格转换、反馈训练等减少策略。建议带着第1章的主张边界和第9章的偏好对照进入，写出要比较的群体、提示与失败情形。问答任务仍需回看这里；它不是用检索路线自动“顺便覆盖”的附属品。

### 第11章 视觉语言模型

图文任务要询问视觉信息从哪里进入、是否训练以及如何与文本对应。目录区分无额外训练、轻量适配、图文联合训练、检索增强和视觉指令调整，并保留视觉引导解码、前缀嵌入与交叉注意力等地址。本站用第3、5、8章作建议先修，以便对照结构、适配与检索，而不是把所有图文系统画成同一个黑盒。验收可设计同问换图的对照，但本页不运行视觉模型。

### 第12章 环境影响

环境影响不是训练速度的别名。目录分开能源与温室气体排放、训练排放估算以及小结；建议先带着第6章的资源配置进入，再写清估算范围、运行时长、功率与地区等假设。实验三让资源任务以第7、12章为共同目标，避免只学专家分配而不看环境边界。这里没有测得GPU速度或排放，不能把排课图上的步数换算成能耗。

### 参考文献

参考文献是正式坐标，也是每条任务路线的返回点：把主张、原始来源与访问范围一项项对上，找不到依据便保留待查。地图可以告诉你该去哪个主题，但不能替代核读论文，更不能用出版社书目页为技术断言背书。实验二保留这个根，实验三在编号章之后固定要求回来复核，而不把它画成有训练输出的新章。

## 用完整Python复算阅读调度

下面四块按顺序复制到同一文件，用Python 3标准库直接执行。它与界面使用同一组建议依赖，是有限图的计算模拟，不加载模型、SDK或训练数据。它只检验“给定边与已读集合时的调度”，不证明你学会了章节，也不检验任何真实模型能力。

### 第一步：写出图与确定性顺序

字典的键是章编号，值是直接先修。断言检查每条边都符合这里选择的升序；若以后加入反向边，就应换用真正的拓扑排序并检测环，不能沿用这个简化条件。

```python
PRE = {
    1: (), 2: (), 3: (2,), 4: (3,), 5: (4,),
    6: (3, 4), 7: (6,), 8: (4, 5), 9: (4, 5),
    10: (1, 9), 11: (3, 5, 8), 12: (6,),
}
ORDER = tuple(range(1, 13))
assert set(PRE) == set(ORDER)
assert all(p < n for n in PRE for p in PRE[n])
```

### 第二步：反复补齐先修

栈保存尚未展开的章，集合保证同一个位置不会重复计入。故障只漏掉3→4这条边，其他输入完全不变；返回时按固定顺序排序，让恢复能够逐项比较。

```python
def closure(targets, broken=False):
    found, pending = set(), list(targets)
    while pending:
        n = pending.pop()
        if n in found:
            continue
        found.add(n)
        pending.extend(p for p in PRE[n]
                       if not (broken and p == 3 and n == 4))
    return [n for n in ORDER if n in found]

reference = closure([8])
fault = closure([8], broken=True)
assert reference == [2, 3, 4, 5, 8]
assert fault == [4, 5, 8]
assert set(reference) - set(fault) == {2, 3}
assert closure([8]) == reference  # 撤销故障，恢复同一结果
print("闭包:", reference, "漏边后:", fault)
```

### 第三步：排课并传播阻塞

只有先修真正满足的章才加入done。若把有缺口的课次也加入，就会出现“第9章没读通，但第10章被算作已有基础”的假恢复。这里保留每步缺失集合，排到某一步不等于通过了那一步。

```python
def schedule(targets, known=(), skip=False):
    chosen = list(targets) if skip else closure(targets)
    return [n for n in chosen if n not in known]


def check(plan, known=()):
    done, trace = set(known), []
    for n in plan:
        missing = sorted(set(PRE[n]) - done)
        trace.append((n, missing))
        if not missing:
            done.add(n)
    return trace

plan = schedule([11], known=(2, 3, 4))
assert plan == [5, 8, 11]
assert check(plan, (2, 3, 4)) == [(5, []), (8, []), (11, [])]
print("图文补课:", check(plan, (2, 3, 4)))
```

### 第四步：同时测故障、恢复与独立入口

最后一个测试专门验证“进度走过阻塞章”不会抹掉下游阻塞。四块拼接程序执行到最后一行，才算完成本页的模拟练习。

```python
broken_plan = schedule([9, 10], skip=True)
assert check(broken_plan) == [(9, [4, 5]), (10, [1, 9])]
restored = schedule([9, 10])
assert restored == [1, 2, 3, 4, 5, 9, 10]
assert all(not missing for _, missing in check(restored))
assert schedule([8], known=reference) == []
assert closure([1]) == [1]  # 争议讨论是独立入口
assert closure([7, 12]) == [2, 3, 4, 6, 7, 12]
print("只读目标:", check(broken_plan))
print("恢复排课:", restored)
print("全部断言通过；结果只适用于这张建议依赖图。")
```

## 容易走错的路

这里纠正的是地图使用方式，而不是给学习者打分。故障开关可以复现第一、二种错误，第三种则必须靠来源范围约束自己。

<Callout type="trap" title="入口数相同，就算目录完整？">
  现象：把浅层入口当成全部细分内容。原因：没有做坐标集合匹配。修法：在实验二注入浅目录故障，展开丢失的73项；查3.7下的不同推理优化地址，而不是只看总数。
</Callout>

<Callout type="trap" title="拖到最后一步，就算补齐先修？">
  现象：只读目标时，第11章仍缺第3、5、8章。原因：进度是游标，不是已读证书。修法：恢复闭包排课，或只声明真实已有的2、3、4章，再观察第5、8章仍需安排。
</Callout>

<Callout type="trap" title="有目录、有论文，就能写作者观点？">
  现象：把本站先修边称为作者规定，或把意识争论写成定论。原因：混淆目录、研究观点与原书正文。修法：边标为教学建议，研究注明年份与访问范围；未读的原书正文保持未知。
</Callout>
