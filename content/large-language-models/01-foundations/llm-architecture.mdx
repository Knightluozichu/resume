## 核心概念

### Transformer 架构总览

Transformer 是大语言模型的骨架，由嵌入层和 N 个 Transformer Block 堆叠而成。每个 Block 包含两个子层：多头自注意力（Multi-Head Self-Attention）和前馈网络（FFN），每个子层都配有残差连接和 LayerNorm。输入文本先经过 token 嵌入和位置编码，然后逐层通过 Block 处理，最终经线性层和 Softmax 输出概率分布。

### 自注意力机制

自注意力是 Transformer 的核心创新，让模型动态聚焦相关信息：

- **Q（查询）**：当前 token 的查询向量——「我在找什么」
- **K（键）**：所有 token 的索引向量——「我有什么」
- **V（值）**：所有 token 的内容向量——「我的实际内容」

计算过程：Q 与 K 做点积得到注意力分数（相关性），除以 sqrt(dk) 缩放防止梯度消失，Softmax 归一化为权重，用权重对 V 加权求和得到输出。

### 多头注意力

将 Q/K/V 分成 h 个头并行计算，每个头在独立子空间中关注不同类型的关系。优势：多视角建模（语法、语义、共指等）、子空间分解更高效、并行计算不增加串行开销、表达能力增强。实践中 8-96 头是常见配置。

### 残差连接与 LayerNorm

- **残差连接**：output = x + Sublayer(x)，让输入信息直接传递到输出，子层只需学习增量。缓解梯度消失，支持深层堆叠。
- **LayerNorm**：对每个样本的特征维度归一化，稳定每层激活值分布，加速收敛，减少对初始化的敏感。
- 二者配合让数十到上百层 Transformer 可稳定训练。

### 注意力变体

| 变体 | 特点 | 适用场景 |
|------|------|----------|
| 全注意力 | 每个 token 关注所有位置，复杂度 O(n^2) | 编码器、短序列 |
| 因果注意力 | 只关注当前位置及之前，防看到未来 | 自回归生成（GPT） |
| 稀疏注意力 | 只关注部分关键位置，降低复杂度 | 超长序列 |

<Callout type="info">

核心：注意力让模型动态聚焦相关信息——不是固定规则，而是根据内容自动决定关注什么。多头机制捕获多维度语义关系，残差连接保障深层训练稳定性。Transformer 的革命性在于用全并行的自注意力替代了 RNN 的序列计算，让大规模并行训练成为可能。

</Callout>

## 术语表

<Glossary>

<GlossaryItem term="自注意力">

Self-Attention，Transformer 的核心机制。让序列中每个 token 与所有 token 计算相关性（注意力分数），动态聚焦相关信息。计算公式：Attention(Q,K,V) = softmax(QK^T / sqrt(dk)) V。

</GlossaryItem>

<GlossaryItem term="多头注意力">

Multi-Head Attention，将 Q/K/V 分成多个头并行计算注意力，每个头在独立子空间关注不同关系。拼接后线性变换输出。让模型同时从多个维度理解语义。

</GlossaryItem>

<GlossaryItem term="前馈网络">

Feed-Forward Network，FFN。两层线性变换加非线性激活，对每个位置独立做非线性变换。FFN(x) = W2 * activation(W1 * x + b1) + b2，是 Transformer Block 的第二个子层。

</GlossaryItem>

<GlossaryItem term="残差连接">

Residual Connection，output = x + Sublayer(x)。让输入直接传递到输出，子层只需学习增量。缓解梯度消失，支持深层网络堆叠，是深层 Transformer 可训练的关键。

</GlossaryItem>

<GlossaryItem term="因果注意力">

Causal Attention，通过上三角掩码让每个 token 只关注当前位置及之前，防止看到未来信息。是 GPT 等自回归生成模型使用的注意力变体。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

自注意力机制的计算公式是什么？Q、K、V 分别代表什么？

<Answer>

缩放点积注意力公式：Attention(Q,K,V) = softmax(QK^T / sqrt(dk)) * V。Q（Query 查询）代表当前 token 的查询向量，K（Key 键）代表所有 token 的索引向量，V（Value 值）代表所有 token 的内容向量。计算过程：Q 和 K 做点积得到注意力分数，除以 sqrt(dk) 缩放，Softmax 归一化为权重，用权重对 V 加权求和。直观理解：Q 是「我在找什么」，K 是「我有什么」，V 是「我的实际内容」。

</Answer>

### 问题 2

多头注意力机制为什么比单头注意力更有效？它是如何工作的？

<Answer>

多头注意力将 Q/K/V 分成 h 个头并行计算注意力，然后拼接并线性变换。优势：①多视角建模——不同头关注不同类型关系（语法、语义、共指）；②子空间分解——高维向量分成多个低维子空间更高效；③并行计算——各头独立可并行；④表达能力增强——等价于多个注意力函数集成。如 8 头注意力中，某些头关注局部依赖，某些关注长距离依赖，某些关注实体关系。

</Answer>

### 问题 3

Transformer Block 由哪些组件构成？残差连接和 LayerNorm 为什么重要？

<Answer>

Transformer Block 由两个子层组成：多头自注意力 + 残差连接 + LayerNorm；前馈网络 + 残差连接 + LayerNorm。残差连接重要因为：缓解梯度消失（梯度可通过捷径回流）、信息保留（子层只需学习增量）、支持深层堆叠。LayerNorm 重要因为：稳定训练（控制激活值分布）、加速收敛（梯度更稳定可用更大学习率）、减少对初始化敏感。二者配合让深层 Transformer 训练可行。

</Answer>

### 问题 4

全注意力、因果注意力和稀疏注意力各有什么特点？分别适用于什么场景？

<Answer>

全注意力：每个 token 关注所有位置，信息传递最充分，复杂度 O(n^2)，适用于编码器和短序列。因果注意力：通过上三角掩码只关注当前位置及之前，防止看到未来，适用于自回归生成（GPT），可用 KV Cache 优化。稀疏注意力：只关注部分关键位置，复杂度降为 O(n*log n) 或更低，适用于超长序列。选择原则：短序列用全/因果保证质量，长序列用稀疏平衡效率，生成任务必须用因果防泄露。

</Answer>

</Exercises>
