## 核心概念

### 四大数学支柱

大语言模型建立在四大数学支柱之上，它们分别解决不同层面的问题：

| 支柱 | 解决问题 | 关键概念 |
|------|----------|----------|
| 概率论 | 如何建模语言 | 条件概率 / 链式法则 / 交叉熵 / Softmax |
| 线性代数 | 如何表示语言 | 向量 / 矩阵乘法 / 嵌入 / 特征分解 |
| 优化理论 | 如何学习参数 | 梯度下降 / 反向传播 / Adam / 学习率 |
| 信息论 | 如何度量信息 | 熵 / KL散度 / 困惑度 / 互信息 |

<LlmFoundationsDiagram />

### 语言模型的概率视角

语言模型的本质是估计 token 序列的概率分布。给定序列 x1, x2, ..., xn，其联合概率可用链式法则分解为各 token 条件概率的连乘——这就是自回归分解。模型每次根据已生成的上下文预测下一个 token 的条件概率，训练时最大化联合概率（等价于最小化交叉熵损失），生成时逐 token 采样。

### 训练流程：从概率到优化

大模型训练是一个「预测 → 计算损失 → 反向传播 → 更新参数」的循环：

1. **输入序列**：将文本 token 化为 ID 序列
2. **模型预测**：Transformer 计算每个位置的条件概率分布
3. **交叉熵损失**：衡量预测分布与真实 token 的偏差
4. **反向传播**：用链式法则高效计算梯度
5. **参数更新**：Adam 优化器根据梯度更新模型参数

### 关键评估指标

- **交叉熵损失**：越低越好，衡量预测偏差。损失 = -log P(真实token | 上下文)
- **困惑度 PPL**：exp(交叉熵)，直观含义是「模型在每个位置平均有多少个等概率候选」
- **梯度范数**：监控训练稳定性，过大可能梯度爆炸，过小可能梯度消失

<Callout type="info">

核心思想：语言建模 = 概率估计 + 向量表示 + 梯度优化 + 信息度量。概率论定义「学什么」（语言概率分布），线性代数定义「怎么算」（矩阵运算），优化理论定义「怎么学」（梯度下降），信息论定义「怎么评」（熵和困惑度）。四者协同构成大模型的数学基础。

</Callout>

## 术语表

<Glossary>

<GlossaryItem term="交叉熵损失">

Cross-Entropy Loss，衡量模型预测分布与真实分布的差异。对于真实 token y，损失 = -log P(y | context)。模型给正确 token 分配的概率越低，损失越大。是大模型训练最常用的损失函数。

</GlossaryItem>

<GlossaryItem term="困惑度">

Perplexity，PPL = exp(交叉熵损失)。是交叉熵的指数变换，直观含义是「模型在每个位置平均有多少个等概率候选 token」。PPL=1 表示完全确定，越低越好。

</GlossaryItem>

<GlossaryItem term="Softmax">

将一组实数（logits）转换为概率分布的函数：P(xi) = exp(xi) / sum(exp(xj))。保证输出非负且和为 1，是大模型输出层的标准组件。

</GlossaryItem>

<GlossaryItem term="反向传播">

Backpropagation，利用链式法则从输出层向输入层逐层计算偏导数的算法。复杂度仅约一次前向传播的 2-3 倍，让百万到万亿参数的梯度计算可行。

</GlossaryItem>

<GlossaryItem term="Adam 优化器">

结合动量（一阶矩估计）和自适应学习率（二阶矩估计）的优化器。对学习率初始值不敏感，适合大规模稀疏梯度场景，是大模型训练最常用的优化器。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

语言模型建模语言背后的概率公式是什么？如何用链式法则分解？

<Answer>

语言模型将语言建模为概率分布：给定 token 序列 x1, x2, ..., xn，其联合概率 P(x1, x2, ..., xn) 可用链式法则分解为各 token 条件概率的连乘：P(x1) * P(x2|x1) * ... * P(xn|x1,...,xn-1)。这就是自回归分解——每次根据前面所有已生成 token 预测下一个 token 的条件概率。训练目标是最大化联合概率（等价于最小化交叉熵），生成时逐 token 采样。

</Answer>

### 问题 2

交叉熵损失和困惑度（PPL）分别是什么？它们之间有什么关系？

<Answer>

交叉熵损失衡量模型预测分布与真实分布的差异：损失 = -log P(y|context)，模型给正确 token 分配的概率越低损失越大。困惑度 PPL = exp(交叉熵损失)，是交叉熵的指数变换。关系：PPL = exp(loss)，loss 越低 PPL 越低。PPL 直观含义是「模型在每个位置平均有多少个等概率候选 token」——PPL=1 表示完全确定，PPL=10 表示约 10 个候选间犹豫。

</Answer>

### 问题 3

梯度下降和反向传播在大模型训练中分别起什么作用？Adam 优化器有何优势？

<Answer>

梯度下降是优化策略：计算损失对参数的梯度，沿反方向更新参数 theta = theta - lr * grad。反向传播是高效计算梯度的算法：利用链式法则从输出层向输入层逐层计算偏导数，让万亿参数的梯度计算可行。Adam 优化器结合动量（加速收敛、抑制震荡）和自适应学习率（为每个参数分配独立学习率），对学习率初始值不敏感，适合大规模稀疏梯度，是大模型训练最常用优化器。

</Answer>

### 问题 4

大语言模型训练涉及哪四大数学支柱？它们各自解决什么问题？如何协同工作？

<Answer>

四大支柱：①概率论——建模语言概率分布，条件概率定义预测，链式法则分解联合概率，Softmax 转概率，交叉熵度量偏差，解决「如何建模语言」。②线性代数——向量与矩阵表示语言，嵌入将 token 映射为向量，矩阵乘法实现注意力计算，解决「如何表示语言」。③优化理论——梯度下降最小化损失，反向传播高效计算梯度，Adam 自适应优化，解决「如何学习参数」。④信息论——熵度量不确定性，KL 散度衡量分布差异，困惑度评估质量，解决「如何度量信息」。四者协同：概率论定义目标，线性代数实现计算，优化理论驱动学习，信息论度量质量。

</Answer>

</Exercises>
