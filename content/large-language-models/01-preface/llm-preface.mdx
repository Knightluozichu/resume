## 为什么先辨认这张地图

拿到一张地图，先看它画的是哪一年、画到多深，再决定沿哪条路走。本页解决的也是这个问题：哪些是这本书的范围，哪些是我们后来补上的说明。

不先分清两者，很容易把新路画成旧路，把地图上没有画出的小路说成根本不存在。更危险的是，读者会把本站写的话误认为作者原话。

## 前言：本站阅读说明，不是作者前言

本页对应的唯一正式目录位置是“前言”。我们访问到的是书目与目录，没有读取原书前言正文，因此不能复现作者的写作缘起、读者寄语或章节取舍理由。下面的阅读建议、交互和程序均为本站独立教学写作，不是翻译，也不是对作者前言内容的摘要。

### 先认准书，再谈时间

熊涛著《大语言模型：基础与前沿》是**中文原创著作，不是译著**。人民邮电出版社出版，异步图书品牌，ISBN 9787115634887。这里的 <Term def="用于判断资料早晚的发行月份；不是作者实际采用资料的截止日期。">出版时点</Term> 为 **2024-04**：得到发行记录与豆瓣月份交叉确认；馆藏记录只确认 2024 年、作者、出版社和 ISBN。**260 纸本页**仅由豆瓣书目交叉记录确认，不能归功于当前馆藏页面。

出版月能帮我们排除明显的时间倒置，却不能证明此前每篇研究都进入了书中。作者可能未采用一篇早期论文；同月资料还存在日粒度先后不明的问题。第一个实验只做月份比较，不预测作者选择。

### 不是新版书的“后续资料”

我们把出版后出现、或当前实现才引入的补充称为 <Term def="在原书出版时间之外另行标记的材料，不倒填为原书已经讨论的事实。">后续资料</Term>。它可以有教学价值，但必须单独标出日期与来源，不能以“前沿”二字消除时间限制。日期应属于具体文献版本或实现版本，而不是网页最近更新时间。

猜一猜：截止月从 2024-04 提前到 2023-12，切线会移动，但下面三篇真实论文会被剔除吗？再开启倒填故障，观察虚构记录如何越过切线。该记录只是假设的 2025-01 教学条目，不是后续模型发布事实。

BERT 使用 ACL Anthology 收录的 **NAACL 2019-06 正式会议发表日期**，不是首次预印本日期；不能把这里的 2019 当作研究首次公开年。Few-shot 使用预印本初次提交的 2020-05，推测解码使用 **ICML 2023-07 正式会议发表日期**，也不代表其首次预印本日期。上述两个截止月是负例，相容数均为 3；再把截止月改为 **2023-06**，ICML 发表记录越过切线，相容数降至 2。这里比较的是所选文献版本，绝非推断研究何时首次出现。故障将虚构记录误记为 2023-01：截止月为默认的 2024-04 时，相容数由 3 变为 4；截止月为 2023-06 时，相容数则由 2 变为 3。**正确结论仍只能是“时间相容”，而不是“书中已写过”。**实验的播放逐阶段强调来源、比较、页面结论，不模拟历史真实发生速度。

## 目录范围：看见多深，不等于书有多深

目录中的 <Term def="可逐项核对的原书标题位置，例如前言、章标题和编号节；不是本站新增教学段落。">正式坐标</Term> 是阅读定位，不是正文知识已经被核实的标志。全书分母为 **153 = 139 个编号节/小节 + 12 个章标题 + 前言 + 参考文献**。本页只占“前言”一个坐标；本站学习地图与复习页不加入原书分母。

### 浅层目录为何会少数小节

所谓 <Term def="实际拿到的来源层次，例如目录、摘要或全文；只能按已访问层次做主张。">访问级别</Term> 限定了我们能说什么。得到的 83 条记录包括版权信息、内容提要和资源与支持等浅层项目，不覆盖全部深层小节，不能拿 83 当正式分母。豆瓣详细目录补齐编号坐标，也仍然只是目录，不是原书正文。

## 引文路径：本站不能凭转引扩大来源权限

这里的 <Term def="把一项主张沿原始来源、摘录和本站说明追溯；中继不能增加源头没有支持的内容。">来源传递</Term> 解决的是“这句话究竟靠什么站住”。书目可以支持出版信息，目录可以支持标题存在，研究摘要可以支持它明确报告的实验设置；三者不能互相冒充。本站解释是阅读辅助，不会因为附了一个链接就变成作者原话。

### 支持沿链只能保留，不能凭空增加

实验把三项主张编号：1 是 260 页，2 是作者熊涛，3 是 Few-shot 论文摘要所述“GPT-3 在任务评估中通过文本示范、不作梯度更新或微调”。豆瓣支持集合为 1、2；当前馆藏支持 2、不支持 1；论文摘要支持 3，不支持书目。数字只是本实验的主张编号，**不是可信度评分**。

沿每一条边，传下来的支持集合等于“上游支持”与“当前主张”的交集。若摘录失去了原始链接，本站端按空集处理，表示本页无法追溯，不表示主张必然为假。程序并不理解自然语言，集合由人工按已读来源标记；它不自动判定语义，更不验证原书正文忠实性。

## 用标准库 Python 复算三种边界

把下面四个代码块按顺序拼成同一个 `preface_check.py`，用 Python 3 执行。它是日期、目录计数和集合传播的**玩具计算模拟**，不训练或运行真实语言模型，不调用 SDK，也不测 GPU 性能。每块都对应上面的可观察结果，全部断言通过才打印末行。

### 第一步：建立按月记录

使用整数月份避免把字符串年月误当小数。条目日期是本页教学数据：前三项对应所引研究的年月，最后一项特意标成虚构。

```python
from dataclasses import dataclass

@dataclass(frozen=True)
class Record:
    name: str
    month: str
    fictional: bool = False

def month_index(value):
    year, month = map(int, value.split("-"))
    assert 1 <= month <= 12
    return year * 12 + month - 1

records = [
    Record("BERT", "2019-06"),
    Record("Few-shot", "2020-05"),
    Record("Speculative", "2023-07"),
    Record("Teaching-only", "2025-01", True),
]
```

### 第二步：截断与倒填

这个函数只返回时间相容的名字，不返回“原书已讨论”。最后一个断言显示故障的直接后果：同一虚构条目因错误日期进入集合。恢复时从不可变原记录重新比较。

```python
def compatible(items, cutoff):
    limit = month_index(cutoff)
    return [r.name for r in items if month_index(r.month) <= limit]

baseline = compatible(records, "2024-04")
assert len(baseline) == 3
assert compatible(records, "2023-12") == baseline
assert len(compatible(records, "2023-06")) == 2
bad = records[:-1] + [Record("Teaching-only", "2023-01", True)]
assert len(compatible(bad, "2024-04")) == 4
assert compatible(records, "2024-04") == baseline
print("date:", baseline, "crossing=2", "fault_count=4", "restored=3")
```

### 第三步：目录树不能因来源变浅而缩小

列表中的每个数对应一个一级节所含深层节数，分别来自第3章与第9章详细目录。这里保留一级节标题的层级，不把 3.3 与 3.3.1 当成互相替代的坐标。故障函数模拟错误删去深层叶子。

```python
branches = {
    3: [0, 0, 2, 0, 0, 4, 6, 0],
    9: [6, 0, 0, 0, 0, 0, 0],
}

def chapter_total(chapter, erase=False):
    rows = branches[chapter]
    return 1 + len(rows) + (0 if erase else sum(rows))

assert chapter_total(3) == 21
assert chapter_total(9) == 14
assert chapter_total(3, erase=True) == 9
assert chapter_total(9, erase=True) == 8
assert chapter_total(3) == 21
assert 139 + 12 + 1 + 1 == 153
print("tree: baseline=21/14 fault=9/8 restored=21/14 book=153")
```

### 第四步：追溯集合、故障与恢复

链上的中继只允许保留选定主张；它不能扩大支持集合。断链会返回空集。断言既测正常结果，也测不匹配的来源、故障和恢复，最后打印可复核结果。修改集合并不修改真实世界，只修改人工记录。

```python
supports = {"douban": {1, 2}, "library": {2}, "fewshot": {3}}

def transmit(source, claim, broken=False):
    excerpt = supports[source] & {claim}
    page = set() if broken else excerpt & {claim}
    return page

assert transmit("douban", 1) == {1}
assert transmit("library", 1) == set()
assert transmit("library", 2) == {2}
assert transmit("fewshot", 3) == {3}
assert transmit("fewshot", 3, broken=True) == set()
assert transmit("fewshot", 3) == {3}
print("citation: supported / mismatch / broken / restored verified")
print("all assertions passed; no model execution")
```

## 容易混淆的三件事

错误的共同点是把来源能证明的一小步，扩展成它没有证明的一大步。用以下三条检查自己的阅读笔记，而不是只检查有没有链接。

<Callout type="trap" title="早于出版，不等于出现在书中">
  **现象 →** 给早期论文加上“原书认为”。**原因 →** 将时间相容误作正文证据。**修法
  →** 只写“本页补充引用”，没有原书正文访问就不归因作者；用切线实验检查倒填。
</Callout>

<Callout type="trap" title="少列目录，不等于少了内容">
  **现象 →** 用 83 条浅目录替代 153 个正式坐标。**原因 →**
  混入前置材料，又漏掉深层节。**修法 →**
  区分来源记录数与正式分母；观察范围树的空心叶，不删除未列出的项。
</Callout>

<Callout type="trap" title="公开可读，不等于允许改编">
  **现象 →** 看到公开入口就复制正文，或给原书附上网站许可证。**原因 →**
  把访问权与改编授权混同。**修法 →**
  只按实际访问层次作独立说明，不复制原书正文与图表，不宣称取得改编许可。
</Callout>

## 小结与练习

阅读前言的成果不是背诵模型名，而是知道接下来每条解释应归到哪里。下面三道题分别回收时间、范围、来源路径；先操作再展开答案，并保留自己的错误预测。

- 本页是独立阅读说明，不冒充作者前言。
- 日期比较只判断相容，不能证明书中出现。
- 浅目录改变可见层次，不改变正式分母。
- 引文中继不能增加源头没有的支持。
