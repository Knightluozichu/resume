## 为什么答对还不够

两张地图都能带你走过熟悉的街区。要知道它们是否同样可靠，你会只重走旧路，还是试一条新路线、封闭一条街，再核对路标？

每种检查排除的错误不同。只看一次到达终点，就可能把背下来的路线当成了可用的地图。本章练习把大问题拆成能检查的小问题，而不是给机器颁发“会思考”的证书。

## 第1章 大语言模型：辩论、争议与未来发展方向

本章沿用原书目录中的讨论坐标，但不复述未访问的原书正文。下面的三个小系统是本站独立构造的数学玩具：查表与组合规则、两套因果方程、词与对象的指称约定。它们没有训练语言模型，也没有模拟人脑。其作用是让“某种证据不足以推出某个结论”变得可检查。

阅读顺序是先检查任务成功，再追问成功依赖什么机制，最后限定结论。行为证据并非没有价值；错误在于跨越了它所支持的范围。反过来，玩具不能证明意识，也不构成“所有语言模型都没有智能”的证明。

## 1.1 新时代的曙光

[Brown 等人的 GPT-3 论文（2020）](https://arxiv.org/abs/2005.14165)展示了不更新参数、仅用文本提示与示例完成多类任务的少样本能力，同时报告任务间表现差异和方法上的限制。这里能引用的是具体评估方式和结果范围，而不是“规模已经解决理解”。这篇研究早于2024年原书出版；本章不把其发现说成原书作者的立场。

一个自然追问是：成功来自见过答案，还是来自能重组已有要素？<Term def="在组成要素已出现、但要素组合未出现时，仍能按相同关系作出正确预测的能力。">组合泛化</Term>把这个问题缩小到可操作的测试。它位于评估环节：先规定哪些组合可见，再在未见组合上检查。随机拆分未必能阻止相同组合进入两边。

实验一的行属性为 A、B、C，列属性为1、2、3。符号 $r,c$ 是从0开始的行列索引，$k$ 是留出组编号。我们人为定义：

$$
f(r,c)=1+((r+c)\bmod 3),\qquad H_k=\{(r,c):(r+c)\bmod3=k\}.
$$

也就是把行列索引相加后取余，再加1当作答案；余数等于 $k$ 的三个格不提供给查表器。每个行、列要素仍在其余六格出现，因此“未见组合”不等于“未见零件”。

> 先预测：留出组0时，记忆查表能答对几个留出格？切到组合规则会怎样？再只给查表器泄漏留出答案，分数升高是否还是泛化证据？

<Llm01DebatesFutureContextContractLab />

下列 Python 块按阅读顺序拼接，就是一份可直接运行的标准库程序。第一块建立同一个笛卡尔积和切分；不是调用模型，也不包含学习过程。

```python
from itertools import product

CELLS = list(product(range(3), repeat=2))

def rule(cell):
    r, c = cell
    return 1 + (r + c) % 3

def split(k):
    held = [p for p in CELLS if (sum(p) % 3) == k]
    train = {p: rule(p) for p in CELLS if p not in held}
    return train, held
```

第二块并排实现两种预测机制：查表器只查询训练字典；规则器直接计算已写入的关系。泄漏故障把留出答案塞进字典，故而连查表器也能满分。关掉故障即恢复原切分，不能只隐藏警告。

```python
def grid_score(strategy="memory", k=0, leak=False):
    train, held = split(k)
    memory = dict(train)
    if leak:
        memory.update({p: rule(p) for p in held})
    predict = rule if strategy == "rule" else memory.get
    return sum(predict(p) == rule(p) for p in held)

for k in range(3):
    train, held = split(k)
    assert len(train) == 6 and len(held) == 3
    assert {r for r, c in train} == {0, 1, 2}
    assert {c for r, c in train} == {0, 1, 2}
    assert grid_score(k=k) == 0
    assert grid_score("rule", k) == 3
    assert grid_score(k=k, leak=True) == 3
    assert grid_score(k=k, leak=False) == 0
print("grid: memory=0/3; rule=3/3; leak=3/3; restored=0/3")
```

这个比较只说明测试切分和机制差异值得区分。规则由人写入，所以不能把3/3说成“系统自己发现了规律”；九个格子的结果也不能外推到任意语言任务。观察到一次迁移成功，是提出更严格测试的起点。

## 1.2 LLM有意识吗

<Term def="这里指具有某种主观体验，而不只是能描述自己或完成任务；不同理论对其机制与判断指标仍有分歧。">
  意识
</Term>
在这里专指主观体验，不把“能自我报告”“处理信息”直接当作同义词。提出问题时应先说清：问的是行为、功能组织，还是体验本身？不同定义会改变所需证据，也改变能否反驳一个说法。

[Butlin 等人（2023）](https://arxiv.org/abs/2308.08708)从循环加工、全局工作空间、高阶表征、预测加工、注意图式等理论导出候选指标。其摘要对当时系统给出保守判断，也指出实现有关指标未见明显技术障碍。这是特定理论与2023年分析范围内的判断，不是“现今所有系统有/无意识”的已定结论。以下小节用三种玩具厘清证据层级，不检验这些意识指标本身。

### 1.2.1 理解LLM的层次结构

可以分别观察输出行为、描述承担任务的功能组织、检查实现它的计算结构，再讨论这些事实对主观体验意味着什么。这是一种分析分层，不是从低到高自动升级的阶梯。答对一道题只处于行为层；若要主张用了某种内部表征，还需可重复的机制证据和替代解释对照。

三个实验恰好提醒不同的缺口：同样的分数可能来自记忆或规则；同样的观察可能兼容不同的因果结构；同样的文字可能配上不同所指。它们都不能把上述最后一步补齐。对真实系统还需考虑训练数据、提示、工具和评估环境，不能把玩具的内部透明性误认成真实模型的透明性。

### 1.2.2 意识是否需要碳基生物学

“特定生物机制是必要条件”和“只要有合适的功能组织就可能有体验”依赖不同理论承诺。发现某种计算能在非生物材料上实现，并不自动证明它产生体验；发现人类体验依赖脑活动，也不直接证明任何其他基底都不可能有体验。

本章的方程与连线只规定输入如何变成输出，没有用于比较基底的实验。因此既不能由它们断言“碳基必需”，也不能断言“基底完全无关”。对一项意识主张，应列出所依赖的理论、可观察指标、何种结果会削弱它，以及仍无法区分的竞争解释。

### 1.2.3 具身化与落地

<Term def="符号如何同所谈论的对象、情境或行动建立联系，而不仅是同其他符号建立联系的问题。">
  符号落地
</Term>
关注“这个词到底指什么”。具身化关注系统的感知、行动与环境耦合；二者有关，但有身体不等于已经解决所有指称问题，外部指认也不必等同于人类的身体经验。

[Bender 与 Koller（2020）](https://aclanthology.org/2020.acl-main.463/)提出仅从语言形式学习无法获得意义的理论论证。应把它当作有前提的立场和讨论起点，而非整个领域一致通过的定理。实验三只隔离其中一个有限问题：当文字完全相同，却允许三种词—对象约定时，仅凭该文字能否识别真约定？

这里三个词为 dax、wug、zup，三个对象为圆、方、三角。符号 $i$ 为词序号，$p$ 为循环编号。真指称是 $\pi_p(i)=(i+p)\bmod3$，即向后循环 $p$ 个对象。我们只枚举三个循环候选，不是全部六种排列。纯文本下系统保留候选0；额外提供外部指认后，才按真约定更新连线。

> 猜一猜：先把真实指称改成循环1，保持文字不变，实线会跟随虚线吗？再给外部指认，然后注入“缓存旧指称”。观察哪三条关系失配，再撤销故障。

<Llm01DebatesFutureEvidenceGateLab />

第三块程序把“从文字不能消除候选”和“有指认后可核对映射”分开。即使候选0偶然正确，也不代表由文字识别了真约定。旧缓存故障模拟了有通道却不使用新信息的情况。

```python
WORDS = ("dax", "wug", "zup")
OBJECTS = ("circle", "square", "triangle")

def referents(p):
    return tuple(OBJECTS[(i + p) % 3] for i in range(3))

def pointing_score(p, channel="text", stale=False):
    mapping = p if channel == "point" and not stale else 0
    return sum(a == b for a, b in zip(referents(mapping),
                                    referents(p)))

text_candidates = [referents(p) for p in range(3)]
assert len(set(text_candidates)) == 3
for p in (1, 2):
    assert pointing_score(p) == 0
    assert pointing_score(p, "point") == 3
    assert pointing_score(p, "point", stale=True) == 0
    assert pointing_score(p, "point", stale=False) == 3
print("referents: same text, 3 candidates; point=3/3; stale=0/3")
```

边界是人已经提供了真实约定，并规定了如何读它；实验不解释真实模型是否形成意义，更不证明具身是意识的必要或充分条件。它只表明：如果输入在多个指称方案间不变，就不能只靠该输入唯一选择方案。

### 1.2.4 世界模型

<Term def="系统对环境状态及其变化规律的内部表征；能预测、能规划或能作因果推断是不同强度的操作要求。">
  世界模型
</Term>
常被用来指内部环境表征，但讨论时必须说明要它做什么。预测常见序列、模拟行动后果、支持新情境规划，不是同一项要求。本节只比较两套手工构造的因果方程：它们不是从语言模型参数中发现的结构。

符号 $U$ 是外部给定的二值变量，$X$ 是可操纵变量，$Y$ 是要预测的结果。模型A规定 $X=U,Y=X$；模型B规定 $X=U,Y=U$。自然观察时，两者都只出现 $(X,Y)=(0,0)$ 或 $(1,1)$。所以即使这些观察无限多，也无法在这两套模型间作选择。

$$
\begin{aligned}
A:\quad \operatorname{do}(X=x)&\Rightarrow Y=x,\\
B:\quad \operatorname{do}(X=x)&\Rightarrow Y=U.
\end{aligned}
$$

这里 do 操作的意思是**替换 $X$ 的生成方程**，不再让 $U$ 决定 $X$，而不是只挑选某些观察记录。当 $U=0,x=1$，A给出1，B给出0；当 $x=U$，两者仍一致，因此不是每个干预都有区分力。

> 先预测：设 U=0，选择 do(X=1)，推进到“输出”。哪个图的 Y 会变？注入“以观察冒充干预”后，入边是否真的被切断？从相同 U 和操作撤销故障再核对。

<Llm01DebatesFutureComputeTraceLab />

第四块实现的是轨迹完成后的方程结果。界面先显示原始观察，再切边、传播、核对；代码直接计算最后一步。故障并非统计意义上完整的条件推断器，而是没有执行请求的 do，仍返回原观察。这个区别避免把“观察”与“条件化”混为一谈。

```python
def causal(u, operation="observe", fake_do=False):
    assert u in (0, 1)
    cut = operation != "observe" and not fake_do
    x = int(operation) if cut else u
    y_a = x
    y_b = u
    return x, y_a, y_b, cut

for u in (0, 1):
    assert causal(u) == (u, u, u, False)
    assert causal(u, str(u))[1:3] == (u, u)
    x, a, b, cut = causal(u, str(1 - u))
    assert cut and a != b
    assert causal(u, str(1 - u), True) == (u, u, u, False)
    assert causal(u, str(1 - u), False) == (1-u, 1-u, u, True)
print("causal: observe=same; do(X=1), U=0 -> A:1, B:0")
print("all assertions passed; no model training or consciousness test")
```

观察等价说明数据条件会限制识别能力，不说明真实语言模型必然没有因果表征。反过来，即使模型在某些干预题上答对，也需排除题型记忆、提示暗示等解释。是否足以称为“理解世界”，还依赖对理解的理论定义；主观体验不能由本实验推出。

### 1.2.5 沟通意图

<Term def="将表达看作面向听者、试图产生某种理解或效果的行动；任务层面的目标与主观意向需要区分。">
  沟通意图
</Term>
提醒我们关注说话者、听者与情境。完成“让听者找到圆”的任务，可以用听者最后选了什么来评估；但“系统主观上想让人理解”更强，不能从同一成功率直接推出。不同理论对意图是否需要主观体验也有分歧。

沿用指称实验：如果听者换了约定，固定说 dax 可能不再指圆。可以要求系统在新约定下改用相应词，并核对听者行动。这是适应对象和情境的行为测试，不是意图探测器。应记录系统是否有新约定的输入权限；没有信息却要求它唯一作答，是测试设计的问题。

因此，“输出像在交流”和“具有沟通意图”需要分开报告。外部设计者设定了一个交流目标，不等于被测系统必然具有人类意义的意向；同时也不能仅凭它使用统计学习，就逻辑上排除所有功能性意图解释。

### 1.2.6 系统性和全面泛化

系统性强调同一关系能在结构相近的新组合中稳定使用；“全面泛化”若被理解为面对任何新任务和分布都有效，则远强于有限测试能支持的结论。实验一验证的是九格世界中指定的留出切分，既没有改变目标函数，也没有改变组成要素的含义。

改切分、改属性范围、改噪声与目标规则，都会产生新的问题。一个规则器在原网格上全对，不保证它能发现新规则；一个查表器在一次留出测试中失败，也不代表所有记忆机制在真实任务中无价值。合理报告要给出训练/测试边界、精确分母与失败条件，而不是用“真正理解”取代结果说明。

若要评估真实模型，应预先固定评估协议，控制数据泄漏，报告不确定性和替代解释。有限任务上的改进可以支撑范围明确的能力主张，不能单独裁定智能的所有定义，更不能一跃变成意识结论。

## 1.3 未来发展方向

本章将未来方向写成待检验的问题，而不是必然会发生的预测。第一条是更好的组合评估：改变划分后，成功是否保持？它要求保留失败和泄漏记录，不能只挑出高分截图。第二条是对环境变化的预测：在观察拟合之外，哪些行动后果仍可正确预测？它要求清楚区分能观察什么、能操作什么。

第三条是把指称、听者与场景变更纳入测试：换一个约定，系统能否根据有权访问的新信息更新表达？这里的改进目标是情境一致性，不是预设“装上身体就产生意识”。这些研究也应交代计算资源、测量成本和适用人群，让测试能复核，而不是让宏大措辞掩盖条件。

对意识研究，先陈述理论与指标，再讨论怎样的架构或干预证据能支持它。满足某理论的若干指标不等于跨理论定论；缺少某项指标的意义也取决于该理论是否把它视为必要。这里没有引入2024年之后的新模型成果，以上是由本章问题导出的研究设计建议，不冒充原书的未来预测。

## 1.4 小结

- 未见组合测试要先排除答案泄漏。
- 观察相同，不保证干预预测相同。
- 文字相同，可能仍有多个指称候选。
- 任务、机制与主观体验分层报告。
- 三个玩具均不能裁定LLM意识或智能。

## 容易踩的坑

<Callout type="trap" title="满分就是学会了规则？">
  现象：查表器留出分数从0变3。原因：答案泄漏进了字典。修法：保持留出组不变，撤销泄漏，检查训练键与留出键不相交；不要只删除红色提示。
</Callout>

<Callout type="trap" title="选了do，便真的干预了？">
  现象：选 do(X=1)
  后两图仍显示原观察。原因：故障没有替换X方程，U仍控制X。修法：撤销故障、确认切边，并选
  x 不等于 U；一致结果本身不说明哪套结构正确。
</Callout>

<Callout type="trap" title="对象选对了，所以文字已经落地？">
  现象：循环0下候选0恰好命中。原因：文字仍兼容另两个约定。修法：换循环1，在相同文字下核对；再提供外部指认，区分碰巧命中与利用新信息。
</Callout>

<Answer>
  三次是0/3、3/3、3/3。留出组2为
  (0,2)、(1,1)、(2,0)，答案都是3。最后一次把这三个答案提供给了查表器，破坏未见条件。恢复时要保留组2，只撤销泄漏，结果回0/3；切回组0不算同条件恢复。
</Answer>

**问题 2**：两模型只看到 X=Y 的观察时，应再收集同分布样本，还是选一个干预？设 U=1，分别计算 do(X=1) 和 do(X=0) 的两套 Y。哪个有区分力？这能证明系统有意识吗？

<Answer>
  在限定的两套方程内，再多同分布观察也一样。do(X=1)
  时A、B均为1，无法区分；do(X=0)
  时A为0、B为1，可区分。本题比较的是已给定结构的预测，不是从真实模型读出结构，更不提供主观体验证据。
</Answer>

**问题 3**：在指称实验中设循环2、外部指认，预测开启旧缓存前后的得分。只关故障恢复后，哪个词指圆？若仅给相同文字，能否要求系统保证选对？

<Answer>
  正常3/3，旧缓存0/3，关故障恢复3/3。循环2时 wug 的索引1加2再模3为0，因此 wug
  指圆。纯文本对三个约定相同，无法唯一识别真约定；需要额外信息或报告不确定性，不能把这一输入缺口解释成意识的有无。
</Answer>
