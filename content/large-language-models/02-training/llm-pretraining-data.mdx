## 核心概念

### 数据处理流水线

预训练数据工程是将海量原始文本转化为高质量训练数据的系统化流程，包含五个关键步骤：

1. **数据采集**：从网页（Common Crawl）、书籍、论文（ArXiv）、代码（GitHub）、对话（Reddit）等来源收集
2. **质量过滤**：去除噪声内容（乱码、广告、低质页面），用启发式规则和分类器筛选
3. **去重**：精确去重（完全相同）和模糊去重（MinHash/LSH 近似重复）
4. **分词**：将文本切分为 token 序列（BPE/WordPiece/SentencePiece）
5. **数据混合**：按比例混合不同来源，确保多样性和平衡性

### 数据来源分布

| 来源 | 特点 | 作用 |
|------|------|------|
| 网页数据 | 占比最大，覆盖面广，质量参差 | 通用知识，需重度清洗 |
| 书籍论文 | 高质量文本，长篇推理，学术深度 | 知识密集，推理增强 |
| 代码数据 | 结构化强，逻辑训练 | 编程能力，推理增强 |
| 对话数据 | 交互格式，口语化，多样性 | 对齐辅助 |

### 分词技术对比

- **BPE**：从字符逐步合并高频对，GPT 系列使用，平衡频率和粒度
- **WordPiece**：基于似然的子词划分，BERT 系列使用，注重语言学合理性
- **SentencePiece**：语言无关的分词框架，支持多语言混合，LLaMA/T5 使用

### 数据质量原则

| 原则 | 说明 |
|------|------|
| 多样性 | 覆盖多领域多格式，避免偏科 |
| 高质量 | 过滤低质噪声内容 |
| 大规模 | 万亿级 token 量 |
| 去污染 | 排除测试集泄露 |

<Callout type="info">

核心：数据质量决定模型上限——「Garbage In, Garbage Out」。大模型的能力不仅来自架构和参数量，更来自训练数据的质量、多样性和规模。最好的架构配最差的数据，产出的模型也必然是差的。

</Callout>

## 术语表

<Glossary>

<GlossaryItem term="BPE 分词">

Byte Pair Encoding，从字符级开始反复合并出现频率最高的相邻字符对，逐步构建子词词表。GPT 系列使用 BPE，优点是平衡频率和粒度，未登录词可用子词组合表示。

</GlossaryItem>

<GlossaryItem term="SentencePiece">

语言无关的分词框架，直接处理原始 Unicode 文本（不需要预分词），将空格也作为特殊符号处理。支持 BPE 和 Unigram 两种算法，适用于多语言混合场景。

</GlossaryItem>

<GlossaryItem term="数据去重">

去除训练数据中的重复内容。精确去重逐字节比较文档，完全相同才去重。模糊去重用 MinHash/LSH 计算文档相似度，超阈值即去重，能去除近似重复。去重防止记忆、节省算力、减少偏差。

</GlossaryItem>

<GlossaryItem term="数据污染">

Data Contamination，评估基准的测试数据出现在模型预训练数据中，导致评估结果虚高。应对方法包括动态更新题库、污染检测、私有评估集、时间分割等。

</GlossaryItem>

<GlossaryItem term="Chinchilla 最优比例">

约 20 tokens/参数，即每个参数训练约 20 个 token。在此比例下模型效果最优，算力利用最充分。纠正了之前重参数轻数据的倾向。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

大模型预训练数据工程包含哪些关键步骤？数据流水线的目标是什么？

<Answer>

五个关键步骤：①数据采集——从网页/书籍/论文/代码/对话收集原始文本。②质量过滤——去除噪声内容，用启发式规则和分类器筛选高质量文本。③去重——精确去重和模糊去重，减少冗余防止记忆。④分词——将文本切分为 token 序列（BPE/WordPiece/SentencePiece）。⑤数据混合——按比例混合不同来源确保多样性平衡。目标：将海量原始文本转化为高质量、多样化、无冗余的 token 序列。核心原则：「Garbage In, Garbage Out」。

</Answer>

### 问题 2

BPE、WordPiece 和 SentencePiece 三种分词方法有什么区别？各适用于什么场景？

<Answer>

BPE：从字符开始反复合并频率最高的相邻字符对，GPT 系列使用，平衡频率和粒度。WordPiece：类似 BPE 但合并标准是似然增益（最大化语言模型似然），BERT 系列使用，更注重语言学合理性。SentencePiece：语言无关的分词框架，直接处理原始 Unicode 文本，将空格作为特殊符号，支持多语言混合，LLaMA/T5 使用。选择原则：英文生成模型用 BPE，理解模型用 WordPiece，多语言场景用 SentencePiece。

</Answer>

### 问题 3

为什么数据去重对大模型预训练至关重要？精确去重和模糊去重有什么区别？

<Answer>

去重至关重要因为：①防止记忆过拟合——重复数据让模型记忆特定文本而非学习通用规律；②浪费算力——重复数据等效训练量少于 token 数；③评估污染——测试集内容在训练数据中评估虚高；④偏差放大——重复内容被赋予过高权重。精确去重：逐字节比较，完全相同才去重，精确无误差但只能去除完全重复。模糊去重：用 MinHash/LSH 计算相似度，超阈值即去重，能去近似重复但有误判风险。实践先精确再模糊。

</Answer>

### 问题 4

如何设计一个高质量的预训练数据混合策略？需要考虑哪些因素？

<Answer>

需考虑：①来源比例——网页 50-70%、书籍论文 10-20%、代码 5-15%、对话 5-10%。②领域覆盖——平衡科学/技术/人文/法律/医学等。③语言比例——多语言模型平衡各语言。④质量分层——高质量数据可重复采样，低质减少比例。⑤课程学习——先通用再高质量数据。⑥动态调整——监控各领域 loss 曲线调整比例。⑦去污染——确保评估基准不在训练数据中。⑧版权合规。核心：让模型获得广博知识和强推理能力的平衡。

</Answer>

</Exercises>
