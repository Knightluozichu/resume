## 核心概念

### 六大前沿方向

大语言模型的前沿研究围绕六大方向展开：

<LlmFrontiersDiagram />

| 方向 | 核心 | 代表 |
|------|------|------|
| 多模态融合 | 文本+图像+音频+视频统一理解与生成 | GPT-4V / Gemini / LLaVA |
| Agent 自主智能体 | 规划+工具+记忆，多步推理与自主决策 | LangGraph / AutoGPT |
| 混合专家 MoE | 稀疏激活，以小推理成本获大模型容量 | Mixtral / DeepSeek-MoE |
| 长上下文窗口 | 从 4K 到 1M+ tokens | RoPE 外推 / RingAttention |
| 高效训练技术 | 分布式训练+显存优化 | ZeRO / FSDP / 混合精度 |
| 安全与可信 | 可解释性+幻觉缓解+价值对齐 | Constitutional AI / 水印 |

### 多模态大模型

核心架构「视觉编码器 + 模态对齐 + LLM」：视觉编码器（如 CLIP ViT）将图像编码为视觉 token，投影层将视觉特征映射到 LLM 的 embedding 空间，视觉 token 与文本 token 拼接为统一序列输入 LLM。代表：GPT-4V、Gemini（原生多模态）、LLaVA（开源）。

### LLM Agent

Agent 是以大模型为大脑、能自主规划、使用工具、与环境交互的智能体。核心组件：

- **规划**：将复杂目标分解为子步骤（ReAct / Tree-of-Thought）
- **工具使用**：调用外部工具扩展能力（Function Calling）
- **记忆**：短期上下文 + 长期向量数据库
- **环境交互**：感知-决策-行动闭环

### 混合专家 MoE

将 FFN 层替换为多个专家网络，路由器为每个 token 选择 Top-K 个专家。稀疏激活——总参数量大但每个 token 只激活少量参数，以小推理成本获得大模型容量。

### 技术演进趋势

```
单模态 → 多模态 → 工具增强 → Agent → 自主 AGI 探索
```

<Callout type="info">

核心：多模态扩展感知，Agent 扩展行动，MoE 提升效率，长上下文增强记忆——大模型向通用智能演进。开源与闭源生态并驾齐驱：闭源（GPT-4/Claude/Gemini）性能领先，开源（LLaMA/Qwen/Mistral）可自部署可微调。

</Callout>

## 术语表

<Glossary>

<GlossaryItem term="多模态大模型">

能同时理解和生成多种模态（文本、图像、音频、视频）的大模型。核心架构：视觉编码器提取视觉特征，投影层对齐到 LLM 空间，统一序列处理。代表：GPT-4V、Gemini、LLaVA。

</GlossaryItem>

<GlossaryItem term="LLM Agent">

以大模型为大脑的自主智能体。核心组件：规划（分解任务）、工具使用（Function Calling）、记忆（短期+长期）、环境交互（感知-决策-行动闭环）。从对话工具到自主行动的关键演进。

</GlossaryItem>

<GlossaryItem term="MoE">

Mixture of Experts，混合专家模型。将 FFN 替换为多个专家网络，路由器为每个 token 选择 Top-K 专家。稀疏激活——总参数量大但每 token 只激活少量，以小成本获大容量。代表：Mixtral 8x7B。

</GlossaryItem>

<GlossaryItem term="长上下文">

Long Context，将模型处理窗口从 4K 扩展到 128K 甚至 1M+ tokens。关键技术：RoPE 位置编码外推、RingAttention、Flash Attention。用「大海捞针」（NIAH）评估长文本检索能力。

</GlossaryItem>

<GlossaryItem term="Constitutional AI">

宪法 AI，用一组规则（「宪法」）约束模型行为，在有用和安全间找平衡。模型自己根据宪法规则评估和修正自己的回答，减少对人工标注的依赖。是 Anthropic 提出的对齐方法。

</GlossaryItem>

</Glossary>

## 练习题

<Exercises>

### 问题 1

多模态大模型的核心架构是什么？文本和视觉信息如何融合？

<Answer>

核心架构「视觉编码器 + 模态对齐 + LLM」三部分：①视觉编码器（如 CLIP ViT）将图像分割为 patch 编码为视觉 token 序列。②模态对齐——通过投影层将视觉特征映射到 LLM 的 embedding 空间，使视觉 token 与文本 token 在同一语义空间对齐。③LLM 处理——将视觉 token 与文本 token 拼接为统一序列输入 LLM 理解和生成。融合方式：早期融合（token 级拼接最常见）、晚期融合（各自编码后融合）、混合融合。代表：GPT-4V、Gemini（原生多模态）、LLaVA（开源）。挑战：视觉 token 数量多导致序列过长、细粒度视觉理解、视频时序、音频统一。

</Answer>

### 问题 2

什么是 LLM Agent？它的核心组件有哪些？与普通 LLM 对话有什么区别？

<Answer>

LLM Agent 是以大模型为大脑、能自主规划、使用工具、与环境交互并完成复杂任务的智能体。核心组件：①规划——将复杂目标分解为子步骤，常用 ReAct 或 Tree-of-Thought。②工具使用——调用搜索引擎、代码执行器、API 等，通过 Function Calling 实现。③记忆——短期记忆（对话上下文）+ 长期记忆（向量数据库）。④环境交互——感知-决策-行动闭环。与普通对话区别：①对话是单轮或简单多轮文本交互，Agent 是多步自主行动循环；②对话只输出文本，Agent 能调用工具执行真实操作；③对话无状态，Agent 有记忆可跨会话学习；④对话被动响应，Agent 可主动规划。代表框架：LangGraph、AutoGPT。

</Answer>

### 问题 3

混合专家模型（MoE）的工作原理是什么？它如何平衡模型容量和推理效率？

<Answer>

原理：①将 FFN 层替换为多个专家网络（如 8 或 64 个 FFN）。②路由器对每个 token 计算各专家权重，选择 Top-K（通常 K=1 或 2）个专家处理。③稀疏激活——每个 token 只被少量专家处理，未选中的不参与计算。④输出按路由权重加权求和。平衡容量和效率：①容量——总参数量等于所有专家参数之和（如 8x7B=47B 总参数），容量接近 47B 模型。②效率——每 token 只激活 2/8 参数，实际计算量约等于 14B 模型。③以小推理成本获大模型容量。代表：Mixtral 8x7B、DeepSeek-MoE。挑战：显存占用大（所有专家都要加载）、负载均衡（防路由集中少数专家）、通信开销（多卡分布式时专家分布不同卡）。

</Answer>

### 问题 4

大模型从单模态对话到通用人工智能（AGI）的演进路径上，还面临哪些核心挑战？

<Answer>

核心挑战：①多模态统一——当前多为「拼接式」，真正统一多模态理解与生成仍不成熟，需解决跨模态对齐、细粒度理解、视频时序。②长程推理与规划——复杂多步推理中容易出错（幻觉累积、逻辑断裂），需系统性推理能力而非模式匹配。③世界模型——缺乏对物理世界的内在理解，需构建世界模型支持因果推理。④持续学习——训练后知识固化，无法高效学新知识而不遗忘，需突破灾难性遗忘。⑤自主性边界——自主性越高风险越大，如何在自主行动中保持安全可控是开放问题。⑥可解释性——当前模型是黑箱，理解内部决策机制对安全和信任至关重要。⑦效率——AGI 需要的算力可能远超当前规模，需算法和硬件突破。⑧评估——缺乏评估 AGI 级能力的标准方法。路径：多模态感知 → Agent 行动 → 世界模型 → 推理规划 → 持续学习 → 安全可控。

</Answer>

</Exercises>
