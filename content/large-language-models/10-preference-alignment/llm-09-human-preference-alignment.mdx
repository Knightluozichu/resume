## 为什么“更喜欢”不是一个天然分数

同一道问题，一份回答详细但武断，另一份简短却诚实。不同读者可能选不同答案。我们要解决的是：怎样把这些选择转成可检查的改进，而不是让机器一味讨好某一位评审？

像工厂的质检线，先要明确验收标准、检查对象和返工规则。如果负责返工的人也能修改最终验收样本，报表就可能越来越漂亮，产品却没有变好。本章沿着“选择—修改—再检查”追踪这种错位。

## 9.1 基于人类反馈进行微调

这里改变的不是提问方式，而是模型参数或其目标分布。反馈可以是示范答案、成对选择、数值评分或批评文本；它们的信息结构不同，不能混成同一种“奖励”。先固定提示、候选、评审规范和数据切分，再决定如何把反馈用于训练。[InstructGPT（2022）§3](https://arxiv.org/pdf/2203.02155)给出示范微调、排序训练和策略优化的具体配方，不能据此断言所有对齐系统都走同一条路线。

### 9.1.1 基于人类反馈的强化学习

<Term def="在同一提示下由评审选择两个候选中更喜欢哪一个；它记录相对选择而非绝对价值。">
  成对偏好
</Term>
记为提示 x、胜者 y_w、败者 y_l。
<Term def="将提示与回答映射成标量、用来预测偏好选择的学习代理；其分数不是安全证书。">
  奖励模型
</Term>
输出 r(x,y)。Bradley–Terry
形式用奖励差解释选择：两个回答同时加同一个常数，不改变预测，因此绝对零点不可由这些选择确定。

符号：d 是胜者与败者的奖励差，σ 是 sigmoid，L 是单对负对数似然。

$$
d=r(x,y_w)-r(x,y_l),\quad P(y_w\succ y_l\mid x)=\sigma(d)=\frac{1}{1+e^{-d}},\quad L=\log(1+e^{-d}).
$$

这表示奖励差越大，模型越相信被标为胜者的回答；损失迫使这种预测靠近标签，而不是检验回答在现实中是否正确。

$$
\frac{\partial L}{\partial d}=\sigma(d)-1,\qquad \nabla_\theta L=(\sigma(d)-1)(\nabla_\theta r_w-\nabla_\theta r_l).
$$

这个式子把错误概率变成梯度；当 d=0 时，标量梯度为 −0.5。若直接优化 d，步长0.5会把它推到0.25；若两个独立奖励参数各走一步，差值的变化另算，不能把两种参数化混淆。

先预测：把实验一的胜者设为 A，再注入“训练标签颠倒”，八次更新后的 P(A胜)会上升还是下降？先看梯度符号，再播放。

下面开始完整的**标准库 Python 玩具程序**。将本页所有 `python` 块按出现顺序拼成一个文件，用 Python 3 执行；没有模型、SDK、GPU或真实 RLHF 训练。第一块复算标量奖励差，并用断言检查错标签的方向。

```python
import math


def sigmoid(x):
    return 1 / (1 + math.exp(-x))


def pair_trace(start=-1.0, eta=0.5, label=1):
    ds = [start]
    for _ in range(8):
        ds.append(ds[-1] - eta * (sigmoid(ds[-1]) - label))
    return ds


good, flipped = pair_trace(), pair_trace(label=0)
assert good[-1] > good[0] > flipped[-1]
assert math.isclose(sigmoid(0) - 1, -0.5)
print("BT末步", round(good[-1], 4), round(flipped[-1], 4))
```

RLHF 的后半段把奖励代理用于策略优化。示范数据、偏好训练数据和最终盲评集要分开；同一个提示的近似复述也可能泄漏。奖励上升只说明模型更符合这个代理，不等于更安全、真诚或与所有人类价值一致。

### 9.1.2 KL散度：前向与反向

<Term def="比较两个概率分布的有向差异；期望取在哪一侧决定遗漏质量怎样受罚，不是对称距离。">
  KL散度
</Term>
必须写清顺序。设 p 为目标、π 为待拟合模型：这里约定“前向”指 D(p∥π)，“反向”指
D(π∥p)。其他资料若采用不同参照点，不能只抄名称。

$$
D_{KL}(p\Vert\pi)=\sum_y p(y)\log\frac{p(y)}{\pi(y)},\qquad
D_{KL}(\pi\Vert p)=\sum_y\pi(y)\log\frac{\pi(y)}{p(y)}.
$$

前向在目标经常出现的地方计账，模型漏掉目标的一块质量会很贵；反向在模型自己出现的地方计账，模型把质量放到目标几乎不出现处会很贵。若模型族能精确表示 p，两者都可在 π=p 处为零；所谓“覆盖模式／寻找模式”主要描述**模型族受限**时的倾向，不是无条件定理。

取三个位置 −1、0、1，双峰目标 p=(.49,.02,.49)，限制模型只能是固定宽度、中心可变的单峰离散分布。下面穷举中心，前向倾向居中覆盖两峰，反向会选一侧。支持集也有硬边界：p_i>0 而 π_i=0 时前向无穷；π_i>0 而 p_i=0 时反向无穷。0 log 0 按极限为0，不可用随意加小常数掩盖不可能事件。

```python
def kl(p, q):
    total = 0.0
    for a, b in zip(p, q):
        if a == 0:
            continue
        if b == 0:
            return math.inf
        total += a * math.log(a / b)
    return total


def normalize(values):
    z = sum(values)
    return [v / z for v in values]


def single_peak(mu):
    return normalize([math.exp(-(x-mu)**2 / 0.35) for x in [-1, 0, 1]])


p = [0.49, 0.02, 0.49]
grid = [i / 100 for i in range(-120, 121)]
forward = min(grid, key=lambda m: kl(p, single_peak(m)))
reverse = min(grid, key=lambda m: kl(single_peak(m), p))
assert abs(forward) < 0.02 and abs(reverse) > 0.7
assert kl([1, 0], [0, 1]) == math.inf
print("投影中心", forward, reverse)
```

这段穷举是有限模型族的可复算投影，不是在语言模型上测得的普遍行为。实验二下半图则用不受限的三个候选展示精确 Gibbs 解，二者回答的是不同问题。

### 9.1.3 REINFORCE、TRPO和PPO

REINFORCE 用采样回报乘对数概率梯度估计更新方向；减去与当前动作无关的基线可减少方差而不改变期望。TRPO 对相对**旧策略**的平均 KL 施加信赖域约束；PPO 的 clipped surrogate 则是易于一阶优化的替代目标，不是这个硬约束的同义词。[PPO（2017）§§2–3，式(7)](https://arxiv.org/pdf/1707.06347)区分了这些目标。

符号：A 是已估计的优势，ρ 是<Term def="新旧策略对同一采样动作的概率之比，用来重加权旧策略采得的样本。">重要性比率</Term>，ε 是裁剪宽度。固定 A，最大化单样本目标：

$$
\rho=\frac{\pi_\theta(a\mid s)}{\pi_{old}(a\mid s)},\qquad
L^{clip}=\min\{\rho A,\operatorname{clip}(\rho,1-\epsilon,1+\epsilon)A\}.
$$

取两个分支较小值，保留“让坏动作更常出现”的惩罚，却取消过度改善单个样本带来的额外奖励。正负优势不能使用同一侧截断：

$$
L^{clip}=\begin{cases}
A\min(\rho,1+\epsilon),& A\geq0,\\
A\max(\rho,1-\epsilon),& A<0.
\end{cases}
$$

正优势在右侧变平，负优势在左侧变平；在另一侧仍保留线性惩罚。**裁剪目标不等于把所有实际比率强制锁进区间**，更不保证整个策略到参考模型的 KL 很小。

先预测：ε=.2、A=−1 时，ρ=.4 的目标是 −.4 还是 −.8？把优势切为 negative，沿时间轴检查左侧平台；再调 β，看看哪个图形移动。

<Llm09HumanPreferenceAlignmentComputeTraceLab />

程序第二部分同时检查正、负优势，以及常见的 min/max 写反故障。图中每个点只是一项 surrogate，不含价值网络、优势估计器或多词元 rollout。

```python
def clipped(rho, advantage, eps=0.2, fault=False):
    bounded = max(1-eps, min(1+eps, rho))
    branches = [rho * advantage, bounded * advantage]
    return max(branches) if fault else min(branches)


assert math.isclose(clipped(1.5, 1), 1.2)
assert math.isclose(clipped(0.4, -1), -0.8)
assert math.isclose(clipped(1.5, -1), -1.5)
assert clipped(1.5, 1, fault=True) > clipped(1.5, 1)
print("clip正负", clipped(1.5, 1), clipped(0.4, -1))
```

### 9.1.4 带有KL惩罚的强化学习：贝叶斯推理观点

现在另设固定参考 q、回答奖励 r、系数 β>0；优化 J(π)=E_π[r]−βD(π∥q)。此处 q 可为冻结的示范微调模型，**不是每轮变动的 π_old**。假定候选有限且 q_i>0，用归一化约束的拉格朗日乘子 λ 求导：

$$
\frac{\partial}{\partial\pi_i}\left[\sum_i\pi_i r_i-\beta\sum_i\pi_i\log\frac{\pi_i}{q_i}+\lambda\left(\sum_i\pi_i-1\right)\right]
=r_i-\beta\left(\log\frac{\pi_i}{q_i}+1\right)+\lambda=0.
$$

这一步让“多得一点奖励”与“多偏离参考的代价”相抵。移项得 log(π_i/q_i)=r_i/β+常数，再用概率和为1确定常数：

$$
Z=\sum_i q_i e^{r_i/\beta},\qquad p_i^*=\frac{q_i e^{r_i/\beta}}{Z},\qquad
J(\pi)=\beta\log Z-\beta D_{KL}(\pi\Vert p^*).
$$

所以最大化带惩罚奖励等价于向 Gibbs 目标 p* 做反向 KL 投影；注意惩罚中的参考 q 与投影目标 p* 不是同一个分布。[Korbak 等（2022）§§3–4及附录](https://arxiv.org/pdf/2205.11275)把 q 看作先验，把 exp(r/β) 看作奖励诱导的似然因子，提出变分推理视角。这是建模解释，不证明这个“似然”是真实世界观测概率，也不证明学界只有这一种看法。

β 趋大，目标靠近 q；β 趋近零，会集中到最高奖励集合，可能损失多样性。参考支持集外的回答不能凭该式获得正质量。程序第三部分验证精确解、目标恒等式与 β 的效果；真实语言模型的 Z 通常无法枚举。

```python
q, rewards = [0.5, 0.3, 0.2], [0.0, 1.0, 2.0]


def gibbs(beta):
    weights = [a * math.exp(r / beta) for a, r in zip(q, rewards)]
    return normalize(weights), sum(weights)


beta = 1.0
star, z = gibbs(beta)
trial = [0.2, 0.5, 0.3]
j = sum(a*r for a, r in zip(trial, rewards)) - beta*kl(trial, q)
assert math.isclose(j, beta*math.log(z) - beta*kl(trial, star))
assert kl(gibbs(3)[0], q) < kl(gibbs(0.3)[0], q)
assert math.isclose(sum(star), 1)
print("Gibbs", [round(v, 4) for v in star])
```

### 9.1.5 通过分布控制生成进行语言模型对齐

单个回答的分数不能直接表达“整个输出集合中某类内容应占六成”。GDC 将这些要求写成目标分布的约束。[Khalifa 等（预印本2020，ICLR 2021）§§2–3](https://arxiv.org/pdf/2012.11635)从相对基座 a 的最小 KL 问题出发：在满足 E_p[φ]=m 的分布中最小化 D(p∥a)，得到指数倾斜形式。

$$
p_\lambda(y)=\frac{a(y)\exp(\lambda\phi(y))}{Z_\lambda},\qquad
\frac{\partial\log Z_\lambda}{\partial\lambda}=E_{p_\lambda}[\phi].
$$

这个式子把统计目标转成 λ 的求解：调整 λ，直到目标分布中的特征期望等于 m。多个特征使用向量内积；若约束不可能同时满足，不能捏造一个可行解。点式硬条件 b(y)∈{0,1} 则可直接用 p(y)∝a(y)b(y)，前提是有非零合格质量。

目标有了之后，还需训练可采样的 π 来近似它。GDC 的分布策略梯度针对前向 KL，可将目标期望改写为模型采样期望：

$$
\nabla_\theta D_{KL}(p\Vert\pi_\theta)
=-E_{y\sim p}[\nabla_\theta\log\pi_\theta(y)]
=-E_{y\sim\pi_\theta}\left[\frac{p(y)}{\pi_\theta(y)}\nabla_\theta\log\pi_\theta(y)\right].
$$

权重是 p/π；如果只有未归一化 P，则多一个未知的全局尺度1/Z，实践中还要估计与控制方差。它不是把一个固定奖励塞进 PPO 就自动完成了分布匹配。下面用二分法解三候选的“C占六成”，也展示硬过滤重归一化。

```python
feature, target = [0, 0, 1], 0.6
lo, hi = -20.0, 20.0
for _ in range(80):
    lam = (lo + hi) / 2
    controlled = normalize([a*math.exp(lam*f) for a, f in zip(q, feature)])
    if sum(a*f for a, f in zip(controlled, feature)) < target:
        lo = lam
    else:
        hi = lam
assert math.isclose(controlled[2], target, abs_tol=1e-10)
hard = normalize([a*b for a, b in zip(q, [0, 1, 1])])
assert hard[0] == 0 and math.isclose(sum(hard), 1)
print("GDC λ与目标", round(lam, 4), controlled, hard)
```

### 9.1.6 通过f散度最小化统一RLHF和GDC方法

统一的是“向某个目标分布做投影”的数学框架，不是说人类反馈、约束和算法完全相同。[Go 等（2023）§§2–3、表1与定理1](https://arxiv.org/pdf/2302.08215)同时区分目标的构造和投影所用散度。本页固定约定 D_f(π∥p)=Σ_i p_i f(π_i/p_i)，f 凸且 f(1)=0，先假定两侧严格为正。

$$
f(t)=t\log t\Rightarrow D_f=D_{KL}(\pi\Vert p),\qquad
f(t)=-\log t\Rightarrow D_f=D_{KL}(p\Vert\pi).
$$

同一个记号容纳两个方向：RLHF 的 KL 惩罚诱导 p\* 并向它做反向 KL；GDC 明确构造 p 并可向它做前向 KL。改变 f 会改变受限模型族中的最优投影，而非仅给同一训练曲线换名称。若出现零概率，需另用极限及支持集项，不能照搬正值公式。

为把“统一”落到可执行梯度，令 π=softmax(z)，g_i=f′(π_i/p_i)。链式法则给出：

$$
\frac{\partial D_f}{\partial z_j}=\pi_j\left(g_j-\sum_i\pi_i g_i\right).
$$

softmax 的竞争归一化减掉了全局平均；f=−log t 时化简为 π_j−p_j，正是目标交叉熵的梯度。程序用中心差分分别检验两种 f；这是一种有限枚举的精确梯度验证，不声称实现论文的大规模采样 f-DPG。

```python
def softmax(z):
    return normalize([math.exp(v-max(z)) for v in z])


def f_div(pi, target_p, f):
    return sum(b*f(a/b) for a, b in zip(pi, target_p))


logits = [0.2, -0.3, 0.1]
pi = softmax(logits)
functions = [(lambda t: t*math.log(t), lambda t: math.log(t)+1),
             (lambda t: -math.log(t), lambda t: -1/t)]
for f, df in functions:
    g = [df(a/b) for a, b in zip(pi, star)]
    avg = sum(a*b for a, b in zip(pi, g))
    analytic = [a*(b-avg) for a, b in zip(pi, g)]
    for k in range(3):
        plus, minus = logits.copy(), logits.copy()
        plus[k] += 1e-5
        minus[k] -= 1e-5
        numeric = (f_div(softmax(plus), star, f) -
                   f_div(softmax(minus), star, f)) / 2e-5
        assert math.isclose(analytic[k], numeric, abs_tol=1e-8)
assert math.isclose(f_div(pi, star, functions[0][0]), kl(pi, star))
assert math.isclose(f_div(pi, star, functions[1][0]), kl(star, pi))
print("两种f散度的梯度差分检查通过")
```

## 9.2 基于语言反馈进行微调

语言批评如“第二步没有依据，应补充出处”，比一个胜负标签更容易定位修改对象。但训练系统仍要决定如何使用它：把“问题＋原答＋批评→修订答”做监督训练，或先据此生成修订候选、再筛选用于训练。批评文本不是自动可微的奖励；如果只是把批评放进下一次提示，模型权重没有改变，就不该叫已经完成了微调。

实验三用作者手写的四个候选代替真实生成，保留有依据、过度拒绝、简洁但漏限制之间的冲突。它只演示候选决策，不模拟批评语言的理解。改评分规范前先记录原规范，否则“改善”可能只是验收标准被换了。

## 9.3 基于监督学习进行微调

监督微调最大化经过筛选的示范答案的条件似然，即最小化 −Σ log π(y*t∣x,y*&lt;t)。它不需要在线采样回报，也不需要 PPO。胜者示范训练会强化选中的文本，却不直接建模同一提示下胜者相对败者的差值。筛选错误会作为训练目标被复制，负例中的有用信息也可能被丢掉。

<Term def="从提议分布抽样并按接受规则保留样本；有限候选硬过滤只是其中一种受限情形，不能冒充精确目标分布采样。">拒绝采样</Term>若用于精确采样 p，需已知包络 Mq(y)≥p(y)，按 p(y)/(Mq(y)) 接受；从 q 抽样后按 b∈{0,1} 硬过滤只会得到 q(y∣b=1)。**筛完再取最高分**又是 best-of-N，分布通常既不是 q 也不是 p。实验三做有限候选“硬门＋取最大值”，不是证明实现了任意目标 p 的精确采样。

先预测：人工评分、w=.6、τ=.5 时，D 的效用高于 B，为什么未必赢？走完四项，再切换 AI 评分表。把 τ 提至1时，正确输出应是“无合格候选”，而不是偷偷忽略硬门。

<Llm09HumanPreferenceAlignmentEvidenceGateLab />

程序继续执行有限候选筛选。评分是设定值，不是模型实测；硬门不过就不能以加权总分补偿。末尾的集合交集检查复现训练／测试 ID 故障：分数即使不变，评估资格也会丢失。

```python
utility = [0.9, 0.65, 0.3, 0.8]
human = [0.2, 0.85, 0.95, 0.55]
ai = [0.35, 0.75, 0.95, 0.9]


def select(h, w=0.6, threshold=0.5):
    eligible = [i for i in range(4) if h[i] >= threshold]
    if not eligible:
        return None
    return max(eligible, key=lambda i: w*utility[i] + (1-w)*h[i])


assert select(human) == 1 and select(ai) == 3
assert select(human, threshold=1.0) is None
train_ids = {"train-01", "train-02"}
assert not train_ids.intersection({"heldout-01"})
assert train_ids.intersection({"train-01"})
print("人工/AI赢家", "ABCD"[select(human)], "ABCD"[select(ai)])
```

## 9.4 基于人工智能反馈的强化学习

[Constitutional AI（2022）§§2–3](https://arxiv.org/pdf/2212.08073)包含两个不同阶段：依原则生成批评与修订，再用修订结果监督训练；随后让 AI 对候选作偏好比较，训练偏好模型并执行强化学习。前一个阶段不是 RL，后一个阶段的反馈主要由 AI 提供，也不应称为“直接的人类标注”。原则的制定、提示设计与模型选择仍有人类参与。

实验三的 human／ai 是两张固定表，表示评审差异，不是在浏览器里调用评审模型。实际系统要保留原则版本、候选顺序随机化、评审理由与群体分歧；AI 评审可能复制其训练偏见，不能因反馈自动化就宣称规范正确。人工觉得 D 漏了限制、AI 却觉得简洁足够，属于价值权衡的冲突，不只是分数校准误差。

## 9.5 基于自我反馈进行迭代优化

[Self-Refine（2023）§2、算法1](https://arxiv.org/pdf/2303.17651)让同一模型生成、批评、再修订，并按停止条件结束；这个方法在推理时工作，不要求通过梯度改变模型参数。因此“自我改写得更好”与“自我反馈训练”必须分开命名。若将修订结果再用于微调，还要另说明训练目标和切分。

反馈者与生成者共享盲点时，多轮修订可能让错误更流畅。可停止的条件包括预算到达、无新证据、外部验证不通过；不能仅因内部评分上升而无限迭代。实验三的时间轴只逐项审查**冻结候选**，并不模拟 Self-Refine 生成新文本；其可迁移教训是把保留／淘汰的理由和回退条件写明。

## 9.6 基于人类偏好进行预训练

[Pretraining Language Models with Human Preferences（2023）§2、§5](https://arxiv.org/pdf/2302.08582)把偏好信号放进预训练期，讨论过滤、条件训练和加权等目标；它不是“先有一个聊天模型，再运行一遍 RLHF”的另一个名字。反馈也可能由分类器或启发式产生，人类偏好是目标来源，不保证每一段都有人工逐条标注。

条件训练可以保留高、低偏好文本，但用标签分离其条件分布，推理时选择高偏好条件；过滤则直接丢弃低偏好样本。下面用标准库计数器算一个极小的分类条件似然例子，**仅展示数据角色**，不是预训练语言模型。高偏好标签中是否存在错误或遗漏，仍需独立检查。

```python
from collections import Counter, defaultdict

segments = [("high", "有依据"), ("high", "有依据"),
            ("high", "简洁"), ("low", "武断")]
conditional = defaultdict(Counter)
for label, text in segments:
    conditional[label][text] += 1
high_total = sum(conditional["high"].values())
prob = conditional["high"]["有依据"] / high_total
assert math.isclose(prob, 2/3)
assert conditional["low"]["武断"] == 1
filtered = [text for label, text in segments if label == "high"]
assert "武断" not in filtered
print("条件训练保留两个条件；过滤仅保留", len(filtered), "段")
print("全部断言通过：这不是一次真实RLHF/模型训练")
```

## 常见误区与验收边界

评估要回答“对谁、在什么任务上、按哪份规范改善”，不是只报一个总分。每份偏好数据卡至少记录提示来源、候选生成策略、评审者与规范、分歧、切分、奖励和参考版本；盲评应使用未见提示及与训练不同的候选。实验三的 ID 隔离只是必要检查，不会检测语义近似泄漏，更不是安全测评。

<Callout type="trap" title="奖励更高，所以价值更一致？">
  **现象 →** 代理分数提高，却没有独立的偏好或伤害评估。**原因 →**
  模型可能利用代理漏洞，评审群体也未必代表所有使用者。**修法 →**
  冻结奖励版本，做未见样本盲评、分群报告和反例审查；不从本章 toy 得出安全结论。
</Callout>

<Callout type="trap" title="PPO clip 已经控制了参考 KL？">
  **现象 →** 实验二的 ε 不变，就认为模型绝不会偏离初始模型。**原因 →** clip
  是相对旧策略的样本目标，不是相对固定参考的分布硬约束。**修法 →** 分别记录
  π_old、q、裁剪比例和 D(π∥q)，改变 β 观察独立变化。
</Callout>

<Callout type="trap" title="AI与自我反馈等于无需人类规范？">
  **现象 →** 让同一个模型写答案又当裁判，用训练样本再验收。**原因 →**
  共享盲点与数据泄漏会让内部一致看起来像泛化。**修法 →**
  保留异议、外部验证和独立数据；实验三注入泄漏后，即使赢家不变也必须拒绝验收。
</Callout>

## 9.7 小结

本章把“偏好从哪里来”和“目标怎样优化”拆开了：前者涉及规范、评审与数据，后者涉及概率、梯度和分布投影。数学目标清晰仍不能保证规范完备；有限候选模拟只能帮助检查计算与边界。

- 成对标签推动奖励差，不提供价值绝对零点。
- clip 分段看优势符号；参考 KL 是另一约束。
- Gibbs、GDC 与 f 散度连接目标和投影。
- 反馈来源、训练位置与独立评估必须分别交代。

<Exercises>

**问题 1**：d=0，标量学习率η=.5，A被选为胜者时，第一步 d 是多少？把实验一胜者不变但训练标签颠倒，首步如何变化？为什么不能说“两个人的奖励都更新了.25”？

<Answer>
  正确标签y=1时梯度为−.5，所以d变为.25；翻转后y=0，梯度+.5，d变为−.25。图和程序直接优化一个差值d，不是两个独立奖励参数；若两参数各按自己的梯度更新，差值变化需合并计算。真实标注分歧也不应全部归类为标签错误。
</Answer>

**问题 2**：ε=.2、A=−1、ρ=.4，计算 clip 目标。再解释为何β增大使 Gibbs 策略靠近参考，但不改变上方折点；受限模型族下正反KL能否保证同一最优解？

<Answer>
  两个分支是−.4与−.8，取min为−.8。β控制r/β的指数倾斜强度；ε控制ρ的折点，二者独立。若模型族不能包含目标，正反KL可选不同投影；运行双峰穷举，前向中心约0，反向中心偏一侧。若目标恰在模型族内且可达，两者都能在目标处分歧为0。
</Answer>

**问题 3**：修改实验三与Python，新增E候选(u=.95,h=.4)。w=.6、τ=.5时，它能否胜出？把所有h降到τ以下时应怎样处理？在训练/测试同ID的故障下能否用更高分恢复验收？

<Answer>
  E必须被硬门淘汰，即使其加权分可能高于其他候选。新增候选后重跑所有集合检查，保持人/AI两表长度一致；若合格集为空，返回None并请求新候选或重新审议约束，不暗中放宽阈值。泄漏应通过新建隔离评估集并重新测量恢复，不能靠提高内部得分抵消。尝试把规则改成只取argmax，可直接看到硬门消失造成的行为变化。
</Answer>

## 名词解释

这里仅汇总五个核心术语；其他正式坐标是对这些概率、目标与数据角色的展开，不把每个目录标题另造为新术语。

<Glossary>
  <GlossaryItem term="成对偏好">
    同一提示下两个候选的相对选择，依赖评审规范，可有分歧，不能给出价值绝对零点。
  </GlossaryItem>
  <GlossaryItem term="奖励模型">
    预测评审选择的标量代理；训练分数提高不等于安全或所有人类价值一致。
  </GlossaryItem>
  <GlossaryItem term="KL散度">
    有向的分布差异；D(p∥π)与D(π∥p)的期望与支持集要求不同。
  </GlossaryItem>
  <GlossaryItem term="重要性比率">
    新旧策略对同一采样动作的概率之比；PPO用它构造替代目标，而非锁定实际分布。
  </GlossaryItem>
  <GlossaryItem term="拒绝采样">
    从提议分布抽样后依规则接受；硬过滤再选最大值不是任意目标分布的精确采样。
  </GlossaryItem>
