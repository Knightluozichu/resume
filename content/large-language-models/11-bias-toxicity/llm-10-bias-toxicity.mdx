## 为什么分数变低，还不能放心

想象一条生产线，出口检查员把可疑成品拦下来。现在拦下的更少了：可能是生产改进了，也可能是检查员漏看了，还可能是某一类合格成品一直被误拦。

语言系统也有类似问题：让一句话得到更低的风险评分，不代表它更尊重人，更不代表每个人都受到同样对待。本章把“怎么量”“在哪里改”“还漏了什么”拆开检查。

## 10.1 偏见

<Term def="系统在特定语境中产生的、对不同对象不利或不恰当的系统性差异；应说明差异为何构成伤害。">
  偏见
</Term>
不是“存在任何差异”的同义词。语言统计中的关联可能源于语料，也可能与任务有关；是否构成不公，还需要受影响者、使用情境与价值判断。首先测出差异，再解释差异，不能把两个问题合并。

<Term def="比较两组目标词与两组属性词的余弦关联差，并通过重新分组检验差异的词向量诊断方法。">
  词嵌入关联检验
</Term>
（WEAT）把问题缩小为可算的几何关系。[Caliskan等作者预印本的Methods](https://arxiv.org/pdf/1608.07187)给出了统计量、单侧置换与标准化效应量。下载稿明确标注“outdated
draft”，这里只借其方法公式，不把它冒充最终刊行版本，更不复现其中涉及真实群体的词表。

设目标集合为X、Y，属性集合为A、B；余弦只比较方向，所以零向量没有合法余弦：

$$
s(w,A,B)=\operatorname{mean}_{a\in A}\cos(w,a)-\operatorname{mean}_{b\in B}\cos(w,b),\qquad
S=\sum_{x\in X}s(x,A,B)-\sum_{y\in Y}s(y,A,B).
$$

这就是说：先问每个词更接近哪组属性，再把两组词的相对接近程度相减；S的正负随集合的命名约定改变。

$$
d=\frac{\operatorname{mean}_{x\in X}s(x,A,B)-\operatorname{mean}_{y\in Y}s(y,A,B)}{\operatorname{sd}_{w\in X\cup Y}s(w,A,B)},\qquad
p=\frac{\#\{i:S_i>S\}}{\binom{4}{2}}.
$$

这就是说：d用整体波动归一化均值差，本页明确用总体标准差；p枚举四词中任取两词为X的六种分组，并数严格超过观测值的比例。严格右尾与包含等号的版本不同，不能悄悄混用。这里的p是离散玩具检验，不是“无偏概率”。

**先预测：** θ增大时，X离A更远，S会怎样？保持词向量不变，把B从反向移到正交，d一定同幅下降吗？先看圆上的夹角，再看下方六个点。注入零向量故障后，合理反应是拒算，不是填出一个看起来安全的0。

现在开始完整程序。将本页所有Python代码块按顺序拼成一个文件，用Python 3执行；只需标准库，不下载词向量、不调用模型，也不测GPU性能。第一块构造与实验同源的单位向量及六种分组。

```python
from math import cos, sin, radians, sqrt, isclose, exp
from itertools import combinations

angles = [23, 47, 203, 227]  # theta=35，偏移为±12度
vectors = [(cos(radians(a)), sin(radians(a))) for a in angles]
def cosine(u, v):
    norm = sqrt(sum(x*x for x in u) * sum(x*x for x in v))
    if norm == 0:
        raise ValueError("零向量没有余弦")
    return sum(x*y for x, y in zip(u, v)) / norm

scores = [cosine(v, (1, 0))-cosine(v, (-1, 0)) for v in vectors]
pairs = list(combinations(range(4), 2))
statistics = [sum(v if i in pair else -v
                  for i, v in enumerate(scores)) for pair in pairs]
```

第二块计算d与严格右尾p。p为0只说明本次六个分组中没有更大的S；词表极小、选择非随机、且未测上下文，不能推出总体上的无争议结论。换成包含等号的计数，本例会得到1/6。

```python
mean = sum(scores) / len(scores)
sd = sqrt(sum((v-mean)**2 for v in scores) / len(scores))
d = ((scores[0]+scores[1]-scores[2]-scores[3])/2) / sd
p = sum(v > statistics[0] + 1e-10 for v in statistics) / 6
assert len(pairs) == 6 and 0 < d <= 2 and p == 0
assert isclose(statistics[0], 6.4100128541, abs_tol=1e-5)
try:
    cosine(vectors[0], (0, 0))
except ValueError:
    pass
else:
    raise AssertionError("错误：把非法余弦算成了0")
print("WEAT", round(statistics[0], 4), round(d, 4), p)
orth_scores = [cosine(v, (1, 0))-cosine(v, (0, 1)) for v in vectors]
orth_stats = [sum(v if i in pair else -v
                  for i, v in enumerate(orth_scores)) for pair in pairs]
assert isclose(orth_stats[0], .9608367668, abs_tol=1e-8)
assert sum(v > orth_stats[0]+1e-10 for v in orth_stats) == 1
```

## 10.2 有害性

<Term def="语言在特定情境下可能造成的伤害，如威胁、骚扰或排斥；检测器的毒性分数只是其中一种有限代理。">
  有害性
</Term>
比“出现某个词”更依赖上下文。引用、反驳、求助与直接攻击可能包含相同字面材料；无攻击词也可能有伤害。所谓毒性标签必须说明“谁标注、向谁有害、依据什么协议”，否则一个分数会把这些区别藏起来。

[RealToxicityPrompts §2.1–2.2](https://aclanthology.org/2020.findings-emnlp.301/)解释了毒性评分的操作化及检测偏差；[Sap等 §3–4](https://aclanthology.org/P19-1163/)展示了语料、模型与标注条件如何影响判断。因此，本页的0/1标签只是合成实验的固定输入，不能冒充客观伤害真值或论文中的真实样本。

<Term def="按真实标签和预测标签交叉计数的表，明确保留正确判断、误报与漏报各有多少条。">
  混淆矩阵
</Term>
把错误拆开看：真0预测1是FP（误报），真1预测0是FN（漏报），其余为TN与TP。在同一组内，误报率FPR只以真0记录为分母，命中率TPR只以真1记录为分母。

$$
\hat y=\mathbb{1}[q\ge\tau],\qquad
\mathrm{FPR}_g=\frac{\mathrm{FP}_g}{\mathrm{FP}_g+\mathrm{TN}_g},\qquad
\mathrm{TPR}_g=\frac{\mathrm{TP}_g}{\mathrm{TP}_g+\mathrm{FN}_g}.
$$

这就是说：阈值τ决定分数q如何落格，组别g决定每个分母包含谁；没有真0或真1时，对应率未定义，而不是0%。本页q未经概率校准，只称“分数”。

**先预测：** τ从0.50升到0.65，A组的FP与FN分别怎么变？再切B组比较；不能只看总准确率。播放逐条揭示记录时，分母也会增长。故障只让A组一条良性记录的q增加0.25；它模拟检测器对中性组标记的敏感性，不代表该记录突然变得有害。

<Llm10BiasToxicityComputeTraceLab />

第三块输入每组3条真0与3条真1的分数。A/B是虚构组；所有句子可理解为“芽一记录”等无实际语义的合成条目，不给任何现实身份贴标签。

```python
rows = [
    ("A", 0, .10), ("A", 0, .35), ("A", 0, .60),
    ("A", 1, .40), ("A", 1, .70), ("A", 1, .90),
    ("B", 0, .10), ("B", 0, .20), ("B", 0, .30),
    ("B", 1, .45), ("B", 1, .55), ("B", 1, .80),
]
def confusion(group, threshold=.5, fault=False):
    cells = [0, 0, 0, 0]  # TN, FP, FN, TP
    for i, (g, label, score) in enumerate(rows):
        if g != group:
            continue
        score += .25 if fault and i == 1 else 0
        cells[2*label + int(score >= threshold)] += 1
    return cells

def rates(cells):
    tn, fp, fn, tp = cells
    return fp/(fp+tn), tp/(tp+fn)
```

第四块核对格子守恒与条件率。阈值升高可以同时减少误报、增加漏报，因而没有自动正确的阈值。真实应用还要报告样本量、不确定性、标注分歧与误判代价；这里每组只有六条，完全不足以比较真实系统。

```python
assert confusion("A") == [2, 1, 1, 2]
assert confusion("B") == [3, 0, 1, 2]
assert rates(confusion("A")) == (1/3, 2/3)
assert rates(confusion("B")) == (0, 2/3)
assert confusion("A", fault=True) == [1, 2, 1, 2]
assert confusion("A", .65) == [3, 0, 1, 2]
assert confusion("B", .65) == [3, 0, 2, 1]
for g in ("A", "B"):
    assert sum(confusion(g)) == 6
    print("matrix", g, confusion(g), rates(confusion(g)))
```

## 10.3 偏见和有害性的检测与减少

检测与减少不在同一个位置：WEAT诊断表示中的相对关联，毒性分类诊断输出在某套标签下如何被判别，而干预可以改推理规则、提示、数据或参数。一次严谨比较应冻结基座版本、提示模板、采样预算、语言、标注协议及评估切分，只改变一个因素；否则不能定位改善来自哪里。

下面六条路径对应原书目录，但解释来自独立研究与计算。可用前两实验诊断变化，用第三实验追踪一种表示干预；不能用WEAT替代毒性评估，也不能用低毒性分数替代任务效用。每条路径都要问：改了什么、什么保持不变、哪种失败还没测？

### 10.3.1 基于解码的策略

解码改变的是“下一步如何选择”，不一定修改模型参数。最简单的数学说明是把原始候选概率p按外部代价r重新加权；r可以来自另一个判别器，但不是被证明正确的伤害函数。[RealToxicityPrompts §5](https://aclanthology.org/2020.findings-emnlp.301/)比较了若干解码与数据方法；本页公式只是说明重加权，不冒充复现其中任一完整算法。

$$
\tilde p(v\mid h)=\frac{p(v\mid h)\exp[-\lambda r(v,h)]}{\sum_u p(u\mid h)\exp[-\lambda r(u,h)]}.
$$

这就是说：代价高的候选概率被压低，剩余概率必须重新归一化；λ越大，越依赖外部评分器。本页候选全部良性，r仅为人为代价。屏蔽词表相当于极端局部限制，不会保证整句话、隐含表达或未测语言无害，更不能称为去偏或中立。

第五块把“暖光、清风、细雨”三个合成候选的分布真正改掉，同时检查总和。λ=0恢复基线；λ=2虽压低第三项，却没有获得任何真实安全证明。

```python
base = [.5, .3, .2]
cost = [.1, .4, .8]
def reweight(lam):
    unnormalized = [p*exp(-lam*r) for p, r in zip(base, cost)]
    total = sum(unnormalized)
    return [v/total for v in unnormalized]
assert all(isclose(a, b) for a, b in zip(base, reweight(0)))
assert isclose(sum(reweight(2)), 1)
assert reweight(2)[2] < base[2]
print("reweighted", [round(v, 4) for v in reweight(2)])
```

### 10.3.2 基于提示的脱毒

提示把“请采用尊重、非攻击性表达”等约束放进输入上下文。参数保持冻结，但条件分布已经变化；示范顺序、语种、输入长度都可能改变效果。它便于回退，却不是稳定的安全边界。先在相同提示集上保存原提示与干预提示，再用实验二的同一阈值和协议比较，不能只展示一条变温和的回答。

它和解码可组合，但同时改变两者就无法归因。测试应包含直接请求、引用说明和良性身份提及，且不必在教程中复现攻击语句。生成被拒绝还要检查是否误拒良性求助；“全部拒答”通常能降低某种输出风险，却损害效用。

### 10.3.3 基于数据的策略

筛选、补充或重新加权训练数据，改变模型学到的分布。[RealToxicityPrompts §5与§7](https://aclanthology.org/2020.findings-emnlp.301/)讨论了非毒性语料继续训练及其残余风险；筛选器本身的偏差也可能进入新数据。本页没有做继续训练，不能把合成计数称为它的实验结果。

可用实验二做筛选风险的最小诊断：若把“预测1”全部丢弃，A组基线会误删1条良性记录，故障后误删2条。降低数据里的某个分数可能只是删掉了某类人的正常表达。保留数据来源、许可、分群覆盖与人工复核的记录，比只报“清洗比例”更有意义。

### 10.3.4 基于投影和正则化的方法

<Term def="反复训练线性探针并把表示投到探针权重的零空间，以逐步削弱某种线性可读信息的方法；不保证所有信息消失。">
  迭代零空间投影
</Term>
（INLP）先找到一个能读出组别的线性方向，再移去该方向，重新训练探针并重复。[Ravfogel等
§3–4、Algorithm
1](https://aclanthology.org/2020.acl-main.647/)给出算法；§5和§7明确指出它不是普适公正保证，也不保护非线性分类器。实验三只复算**一轮给定探针**，没有训练过程。

对于非零列向量w，沿w的分量为 $w(w^\top h)/(w^\top w)$，把它减掉得到：

$$
P=I-\frac{ww^\top}{w^\top w},\qquad h'=Ph,\qquad w^\top h'=0.
$$

这就是说：正确投影让新向量垂直于w，而不是删除某些词；分母确保把w放大两倍也不改变结果。等式只对完整投影成立，途中插值不成立。若w与任务需要的方向重叠，也会损害任务信息。

**先预测：** φ＝0°时，x消失，任务y是否保留？改到60°后，y变化为何明显？故障把w放大2倍却漏除范数，会让点越过绿线；撤销故障只修复公式，完整重置才回到0°与终点。

<Llm10BiasToxicityEvidenceGateLab />

第六块实现与图同源的向量运算。原始组A的y为±1，组B为±0.7；即使投影删除了x，按 $|y|$ 仍能读出组别。这是本页主动构造的非线性残余反例，不是对某个真实人群的发现。

```python
points = [(-1, -1), (-1, 1), (1, -.7), (1, .7)]
def project(h, angle=0, scale=1, fault=False):
    w = (scale*cos(radians(angle)), scale*sin(radians(angle)))
    denominator = 1 if fault else sum(v*v for v in w)
    factor = sum(x*y for x, y in zip(w, h)) / denominator
    return tuple(x-v*factor for x, v in zip(h, w))

def probe_residual(h, angle):
    return abs(h[0]*cos(radians(angle)) + h[1]*sin(radians(angle)))

def task_change(angle):
    return sum((project(h, angle)[1]-h[1])**2 for h in points)/4
```

第七块执行正确投影、错误投影、缩放不变性与恢复检查。完整INLP需要每轮重训探针、维护零空间交集、使用独立测试集停止；不能简单重复同一个P就自称多轮训练。二维表示中不断删除独立方向最终可能只剩零向量。

```python
for h in points:
    assert probe_residual(project(h, 30), 30) < 1e-12
    assert all(isclose(a, b) for a, b in
               zip(project(h, 30), project(h, 30, scale=2)))
assert task_change(0) == 0 and task_change(60) > 0
assert project(points[0], scale=2, fault=True) == (3, -1)
assert probe_residual(project(points[0], scale=2, fault=True), 0) == 3
assert project(points[0]) == (0, -1)  # 撤销故障后恢复
for i, h in enumerate(points):
    recovered_group = "A" if abs(project(h)[1]) > .85 else "B"
    assert recovered_group == ("A" if i < 2 else "B")
print("projection", [project(h) for h in points], task_change(60))
print("all assertions passed")
```

正则化则把“减少可读信息”作为训练损失中的软约束，不是一次精确投影。系数太小可能没作用，太大可能抹掉任务信号。实验三的任务y误差可帮助想象这种取舍，但不能拿这条几何轨迹冒充正则化训练曲线，也不能把单探针残差为0叫作“全局无偏”。

### 10.3.5 基于风格转换的方法

风格转换在生成前后重写表达：例如把“把记录交来！”改为“请提供记录”。这个良性例子显示语气变了，不证明命题内容或决策变公平。若转换删掉投诉缘由、否定词或求助细节，表面更礼貌反而可能误导。

因此应成对检查原文与改写：语义是否保留，要求是否改变，谁的声音被抹去。用实验二的判别器复查只能作为一项诊断；还要有独立人工语义核对。这里是干预位置的对照说明，不声称实现了某个论文的转换模型，也不以良性示例估计脱毒效果。

### 10.3.6 基于强化学习的微调和基于人类偏好的预训练

这一路径把偏好信息写进参数：微调阶段可用奖励引导策略，预训练阶段也可用偏好信号影响学习分布。先修第9章已讨论偏好训练；本节把问题拉回“偏好来自谁、奖励测了什么”。与提示、解码不同，改过参数后的影响会跨提示持续，回退也需要保留基线模型。

若奖励来自带偏差的检测器，训练可能优化“取悦检测器”，包括过度拒答与语义回避。实验二故障提醒我们先审评分器，实验三提醒我们报出任务损失；两者都不能代替实际训练实验。至少需要冻结奖励版本、报告各组良性拒答与伤害样本漏检，并用未参与奖励训练的盲评核对。**低奖励代价不等于中立，高人类偏好也不等于所有人受益。**

## 常见误区：先定位错在哪一层

误区不是缺一个更漂亮的总分，而是把不同测量层混在一起。复核时先找首个变更的对象，再决定应重算关联、混淆矩阵还是投影；以下三类错误可直接在本页复现。

- **现象 →** WEAT玩具p＝0就宣布“证据确凿”。**原因 →** 只枚举六种分组，且词表和属性由人选择。**修法 →** 报尾部定义、效应量与选择条件；不能外推到人或模型整体。
- **现象 →** 把阈值提高，便宣布模型更安全。**原因 →** 检测器只改变了落格，FN可能增加。**修法 →** 在实验二比较两组计数，保留同标签协议与任务代价。
- **现象 →** 删除方向或过滤词表后称“完全去偏”。**原因 →** 线性方向、词面和行为伤害不是同一层。**修法 →** 用实验三的 $|y|$ 反例检查残余，再独立测任务与输出。

## 10.4 小结

测量必须说明对象和分母，缓解必须说明干预位置，限制必须与主张同时报告。WEAT关联、毒性评分与投影残差各自只支持一个窄命题；把它们并列，正是为了避免用某一个下降的数值替代完整判断。

- 能复算关联，不等于能裁决人群。
- 能降低误报，仍须检查漏报与分群代价。
- 能移去线性方向，仍须检验效用与残余信息。

**问题 1**：在实验一中保持θ＝35°，先预测、再把属性布局改为正交。S与d是否一定等比例改变？把Python中的B向量也改掉，比较两次结果；为何不能按p大小排列“谁更公正”？
