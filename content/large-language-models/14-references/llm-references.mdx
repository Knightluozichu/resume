## 为什么一张来源地图还不够

地图上的两个地点之间画着一条路，并不表示路已修好，更不表示沿路能抵达你想找的那间房。只抄地点名称，会把“知道在哪里”误认成“已经进去检查过”。

研究阅读也要分开这两件事。本页先说明实际看到了哪些材料，再把三种检查落到可计算的小例子里：沿路找资料、逐项算数、比较两组实验。先修是第2章的词元与第6章的训练预算；这里不训练真实模型。

## 沿引用边检索：集合与重复路径

<Term def="把研究作品作为节点、把引用者指向被引者作为有向边的图；边的存在只表示引用关系。">
  引用图
</Term>
适合找阅读入口，而不是给论文排真伪或给思想影响做因果归因。下面只保留原始参考表中核验过的六条边：C→G、C→K、G→A、G→B、G→K、B→A。省略其余引用不表示它们不存在。

### 作品身份不是具体版本身份

G的参考表把B写成2018年arXiv预印本，而本站实际读的是2019年ACL版本。因此图中B归并的是“BERT这一研究作品”，不能把G→B写成“GPT-3引用了本站这份ACL PDF”。K和C的本次下载固定为v1；原参考条目没有指定v几的边，不补造版本号。要核对某个式子的改动，必须另建逐版本差异记录，而非只靠这张作品图。

### 为什么七次到达只有五篇论文

设起点为C，边沿“引用者→被引者”追溯。第0层有C；第1层到G、K；第2层从G到A、B、K；第3层从B再次到A。这里数的是长度不超过三跳的有向 walk（沿边行走）总到达次数，包含起点C的零跳 walk：1+2+3+1=7。它不是边数；这个子图共六条边。去重集合只有C、G、K、A、B五篇。此处子图无环，walk 也都是路径；更一般的有环引用图仍须限制最大跳数，不能无限展开。

$$
R_{t+1}=R_t\cup\{v\mid u\in R_t,\ (u,v)\in E\},\qquad R_0=\{C\}.
$$

这个式子在说：每扩一跳把邻居加入集合，已经见过的论文只保留一次。图中圆内到达次数可以大于1，但不能因此凭空多出一篇文献。引用链也不传递“支持”：C引用G、G引用A，不意味着C对任何关于A的主张都提供了直接证据。

## 从概率到论文报告口径：逐词元算损失

<Term def="对每个目标词元的条件概率取负对数，再按指定单位求和或平均的预测损失。">
  负对数似然
</Term>
能把“论文采用哪种平均方式”变成明确的算术。K的§1.3将交叉熵损失写为nats，通常在上下文内按词元平均。本实验不取得论文模型的真实概率，而是提供六个正概率，让读者复算同一种口径。

### 一条计算链，两个必须配套的单位

给定同一上下文规则下六个目标词元的条件概率0.5、0.25、0.8、0.4、0.2、0.1。这里每个数只是对应位置上目标词元的概率，不是让这六个数共同构成一个归一分布；也不声称由一个模型实际生成了它们。

$$
\ell_i=-\ln p_i,\qquad H=\frac{1}{n}\sum_{i=1}^n\ell_i,\qquad \mathrm{PPL}=e^H.
$$

这个式子在说：概率越小，惩罚越大；先累计每个位置的惩罚，再除以位置数，最后指数化。若用以2为底的对数，损失改用bits，此时困惑度是2的损失次方，而不是再用e。

### 平均文档分数为什么会改答案

把前两个位置看作短文档A，后四个看作文档B。正确语料均值按词元加权：A有两个位置，B有四个。若先各算一个文档均值再对两篇等权平均，就让短文档中每个位置拥有长文档位置两倍的权重。这不是数值精度问题，而是评估对象改变了；“每篇文档等权”的任务可以合理，但必须明说，不能标成同一语料词元损失。

$$
H_{\text{token}}=\frac{2H_A+4H_B}{6},\qquad H_{\text{doc}}=\frac{H_A+H_B}{2}.
$$

这个式子在说：两种均值只有在文档等长或文档均值恰好相等时才必然相同。本例词元均值为1.188483 nats，困惑度约3.282099；文档等权均值约1.151293 nats。图中阶梯每次上升正好是一个位置的负对数概率，不是模型学习曲线。

## 复现实验设计：预算曲线与独立数据

<Term def="固定明确的计算量口径，让候选方案消耗相同预算后再比较；它不自动保证耗时相同或质量可比。">
  等算力对照
</Term>
先回答“到底固定了什么”。K的§2.1忽略某些较小计算项，得到每个训练词元约6N次浮点运算；C的§3.3也使用6ND近似，而附录F提供更细的计算并包含嵌入项。两篇的参数计数与详细预算口径并非可以无条件互换。

### 双曲线只固定预算，不给出最优质量

这里N是参数数目，D是**训练中处理的词元总数**，不是去重后的独立语料数量。对固定预算C，N增加必须相应减少D。C的§2与§3说明其经验缩放结论与较早工作有差异，并讨论训练词元、学习率日程和拟合范围；不能把一个简单比值当成任何模型的永久最优配方。

$$
C\approx6ND,\qquad D\approx\frac{C}{6N}.
$$

这个式子在说：若预算是600 EFLOP，N=5B时D=20B，N=2B时D=50B。B是十亿，EFLOP是10的18次方次浮点运算；它是总工作量，不是EFLOP/s速度。固定D=100B后把N从2B增到5B，计算量从1200变成3000 EFLOP，已经不是同预算对照。曲线没有拟合质量，也没有测量GPU时间。

### 同预算仍可能在测试中见过同一来源

<Term def="本应独立的评估集合包含了训练中可获得的信息，从而使评估不再回答原定泛化问题。">
  数据泄漏
</Term>
是另一个独立问题。将同一源文档切成两个片段，一个放训练、一个放测试，不等于测试文档是全新来源。G的§4讨论潜在污染的检测；C的语言建模评估也提醒更多训练数据可能增加泄漏风险。本图用源文档身份交集做最小反例，不模仿论文的完整检测算法。

六份源文档a至f各有两个片段。按文档切分时，a至d全入训练、e和f全入测试，源身份交集为空；交错片段时，每份的片1训练、片2测试，交集包含全部六份。即使文件ID完全隔离，也不能排除跨ID的近重复、预训练污染或相同题目改写。

### 把设计算术变成可交接的实验单

真实复现至少还要冻结：模型与分词器的文件版本、源数据与切分规则、训练词元数、目标函数、优化器和学习率日程、随机种子、硬件／精度／软件环境，以及所用的预算估计式。先用开发数据决定超参数，最终测试数据不参与选择；只公布最好种子会混入选择偏差，应说明全部预定运行及其分布。

## 连续Python实践：同一批输入的三个核算

把下面四段依次保存到一个 `reference_recheck.py` 文件，再运行 `python3 reference_recheck.py`。只用标准库，无网络、无模型权重、无训练框架。第一段固定已核验的作品引用子图，并保留重复路径次数；`Counter`不是去重结果。

```python
from collections import Counter
from math import exp, isclose, log

edges = {"C": ["G", "K"], "G": ["A", "B", "K"], "B": ["A"]}

def trace(root, hops):
    frontier = [root]
    visits = Counter(frontier)
    for _ in range(hops):
        frontier = [v for u in frontier for v in edges.get(u, [])]
        visits.update(frontier)
    return visits

visits = trace("C", 3)
assert len(visits) == 5 and sum(visits.values()) == 7
assert visits["A"] == 2 and visits["K"] == 2
assert len(trace("C", 1)) == sum(trace("C", 1).values()) == 3
```

第二段按位置计算负对数概率，并显式改变分组权重。注意均值相等的测试不是“程序总是正确”：它刻意展示故障被一个不敏感样本掩盖的情况。不同底数要使用配套的指数，最后还原同一困惑度。

```python
probabilities = [0.5, 0.25, 0.8, 0.4, 0.2, 0.1]
losses = [-log(p) for p in probabilities]
mean = sum(losses) / len(losses)
doc_mean = (sum(losses[:2]) / 2 + sum(losses[2:]) / 4) / 2
bits = [-log(p, 2) for p in probabilities]
assert not isclose(mean, doc_mean)
assert isclose(exp(mean), 2 ** (sum(bits) / len(bits)))
equal_docs = (sum(losses[:3]) / 3 + sum(losses[3:]) / 3) / 2
assert isclose(mean, equal_docs)
assert isclose(mean, 1.1884831373839, abs_tol=1e-6)
```

第三段在B参数、B词元和EFLOP之间换算。用这些单位时，十亿乘十亿恰好对应10的18次方，因此可以直接写 `6*n*d`；若改用原始整数参数，就不能再套同一数字单位。

```python
budget = 600  # EFLOP
allocations = [(n, budget / (6 * n)) for n in (2, 5, 10)]
assert allocations == [(2, 50.0), (5, 20.0), (10, 10.0)]
for n, d in allocations:
    assert isclose(6 * n * d, budget)
wrong_compute = 6 * 5 * 100
assert wrong_compute == 3000 and wrong_compute != budget
```

最后按源文档ID而非片段文件名检查交集。这只能识别例子中的身份泄漏；真实数据还要检查重复内容及污染。恢复时重新建立隔离集合，不是把警告字符串删掉。

```python
sources = list("abcdef")
train_by_doc, test_by_doc = set(sources[:4]), set(sources[4:])
train_by_chunk, test_by_chunk = set(sources), set(sources)
assert not (train_by_doc & test_by_doc)
assert len(train_by_chunk & test_by_chunk) == 6
recovered_train, recovered_test = set(sources[:4]), set(sources[4:])
assert not (recovered_train & recovered_test)
print("citations", len(visits), "visits", sum(visits.values()))
print("H", round(mean, 6), "PPL", round(exp(mean), 6))
print("allocations", allocations, "fault EFLOP", wrong_compute)
```

运行后应得到五篇论文、七次到达；损失与页面同输入同口径；三组预算都为600 EFLOP。该程序不读取任何论文训练数据，不应给它贴上“复现了GPT-3或Chinchilla”的标签。

## 三个常见误区

这三种错误分别发生在来源关系、聚合口径和实验条件，修复其中一处不能代替另外两处。每个错误都能在上面的实验中找到一个可被推翻的预测。

### 误区一：引用链就是证明链

**现象 →** A被G引用，G又被C引用，于是用C证明A的任意结论。 **原因 →** 把书目关系当作支持关系的传递闭包。 **修法 →** 沿图找原文，但回到直接支持主张的段落；去重计数也不能证明结论正确。

### 误区二：写“平均损失”就只有一种答案

**现象 →** 同样六个概率算出不同损失。 **原因 →** 文档等权与词元等权改变了权重，不是舍入误差。 **修法 →** 记录分母、文档长度与log单位；用2+4反例发现差异，再用3+3解释故障为何被掩盖。

### 误区三：同算力自动意味着公平、无泄漏

**现象 →** 固定训练词元但增大模型，仍宣称同预算；或同预算下使用重叠来源测试。 **原因 →** 没分别检查实际6ND与数据身份交集。 **修法 →** 先核对预算曲线，再核对数据切分；仍不把近似FLOPs当耗时或质量保证。

## 小结

- 书目定位材料，不冒充原书实际参考条目。
- 引用路径要去重；引用边不是因果或证明。
- 概率、平均权重、log单位必须一起核查。
- 等预算与独立数据是两项不同检查。
- 算术复核不等于重跑论文训练实验。

## 练习与答案

先给预测，再修改实验参数或程序。折叠答案只核对本页的限定输入，不把玩具结果外推成真实模型结论。

<Exercises>

**问题 1**：以C为起点追溯两跳与三跳，分别有多少不同论文、多少次到达？为什么不能用这些数字衡量论文质量？

<Answer>

两跳：C、G、K、A、B共5篇，到达次数1+2+3=6；三跳仍5篇，到达次数变7，因为B再次到A。次数取决于截取的子图、起点和深度；引用可能是背景、方法、比较甚至批评，不能由次数推出质量或因果影响。

</Answer>

**问题 2**：修改第二实验，先完成六个token，保持2+4并注入文档等权故障；再改3+3与bits。解释哪次改变了评估权重，哪次只改变了单位。把Python加上对应断言。

<Answer>

2+4故障改变位置权重，短文档每个token权重更大。3+3时两个文档等长，故障均值与正确均值恰好相等，不证明故障不存在。bits只改变log单位；使用2的幂得到与nats下e的幂相同的PPL。可断言 `isclose(mean, equal_docs)` 及 `isclose(exp(mean), 2 ** (sum(bits) / 6))`。

</Answer>

**问题 3**：在第三实验设预算1200 EFLOP、N=2B并完成切分核查。固定D=100B故障此时是否暴露？改N=5B会怎样？再切为交错片段，这两次问题能否用同一修法解决？

<Answer>

N=2B时正确D恰好100B，故障暂被掩盖；N=5B时正确D=40B，故障仍用100B，实际3000 EFLOP而非1200。交错片段另外造成六份源文档身份重叠。预算问题需恢复D=C/(6N)，泄漏需重新按源身份切分；恢复预算不会自动消除数据重叠。这里均未测量真实训练时间。

</Answer>

## 名词解释

以下五项与正文首现高亮一一对应。文献版本、平均权重、文档身份都是为了把它们落实为可执行检查，而不是添加新的原书目录坐标。

<Glossary>
  <GlossaryItem term="参考文献">
    让别人能找到具体研究材料的作者、题名、年份与版本信息。列出材料不等于它支持所有结论。
  </GlossaryItem>
  <GlossaryItem term="引用图">
    论文作为节点、引用者指向被引者的箭头图。适合追溯阅读，不是质量排名或因果证明。
  </GlossaryItem>
  <GlossaryItem term="负对数似然">
    目标词元越不可能，惩罚越大；把负对数概率按明确的单位累加或平均。
  </GlossaryItem>
  <GlossaryItem term="等算力对照">
    按同一计算量估计口径固定预算，再比较候选方案。不自动意味着同耗时、同数据或同质量。
  </GlossaryItem>
  <GlossaryItem term="数据泄漏">
    本应独立的测试中出现训练可利用的信息，使分数不再回答原定泛化问题。
  </GlossaryItem>
</Glossary>
