```python
def compare_controlled(baseline, candidate, changed):
    assert len(changed) == 1, "一次只改变一个可归因因素"
    return {key: candidate[key] - baseline[key] for key in baseline}
```

```python
def evidence_gate(records):
    required = {"source", "inputs", "config", "outputs", "limits"}
    missing = [i for i, record in enumerate(records)
               if not required.issubset(record)]
    return {"pass": not missing, "missing_records": missing}
```

第一段产生不可变运行清单，第二段强制单变量对照，第三段在结论前检查证据。接入HuggingFace、DeepSpeed、MOSS、LangChain或vLLM时，只由薄适配器提供真实执行对象；清单字段、对照顺序和失败协议保持稳定，使库升级导致的默认值变化成为可见差异。

## 固定样例与手算

取三个目标词元的条件概率0.8、0.5和0.25，平均负对数似然约为0.998，困惑度约为2.71。若另一分词器把相同文本切为六个词元，词元级困惑度不能直接横比；应报告完整序列对数似然、字符或字节单位，并附切分结果和未知字符。

注意力例取二维查询q=(1,0)，键k1=(1,0)、k2=(0,1)，值v1=(2,0)、v2=(0,2)。缩放得分为1/根号2和0，softmax权重约0.67与0.33，输出约(1.34,0.66)。加入因果mask后，被遮蔽位置权重严格为0；否则损失下降可能来自未来信息泄漏。

训练例令标量参数为2、梯度为0.3、学习率为0.1，更新后参数应为1.97。若梯度累积四次却未除以累积步数，等效更新扩大四倍；若数据并行又做求和归约，世界规模也会改变有效梯度。资源账本必须同时记录全局批量、词元数、峰值显存、通信字节和每秒有效词元。

## 实验设计与故障注入

基线冻结数据、分词、初始化、预算和评测，只改变一个因素：过滤规则、mask、位置方法、并行拓扑、LoRA秩、奖励符号、检索器或解码参数。运行至少一个正常样本、一个边界样本和一个单故障样本；随机阶段用多种子报告均值、方差和逐样本结果。

故障轮次依次注入近重复跨集合泄漏、标签mask错一位、有效批量不等、断点缺失优化器状态、奖励方向翻转、检索证据为空、工具参数越权和群体切片遗漏。系统应在数据、张量、资源、反馈、服务或评测门禁处报告首个分叉，而不是等待用户看到错误答案。

修复后先重放原失败，再运行相邻边界和正常基线。确定性阶段逐项一致，随机阶段落入预先声明区间；若只提升平均质量却恶化尾延迟、安全切片或成本预算，候选版本不能晋级。线上反馈进入新的隔离数据版本，不能直接污染测试集或奖励协议。

## 正式目录逐项讲解

### 前言

“前言”建立稳定定位、版本、定义、前置关系、实验对象和未知项。读者应能从术语回到原始来源与执行证据，也能从失败记录反向找到公式和章节；无法访问的数据、代码或配置明确标记为不可完整复现。

针对“前言”，先预测只改变数据、mask、参数、并行拓扑、反馈或评测协议时哪个中间对象最先分叉，再运行正常与单故障路径。保存来源、配置、阶段产物和判断依据，不用最终平均分覆盖前序失败。

## 六类构建证据

### 来源与版本合同

保存第一版官方PDF、出版信息、原始论文、代码提交、模型卡和数据卡。区分原书陈述、原始研究结果、本站复现和工程推断；无法取得训练语料或完整配置时写明不可完整复现，不用近似实验冒充原结果。

### 数据与词元合同

记录许可、来源、时间、哈希、语言、质量过滤、去重簇、隐私动作、切分和词表。派生样本按来源组切分，避免模板或近重复跨集合；任何删除都保留原因码和聚合统计，使模型差异能追到数据动作。

### 模型与目标合同

记录层数、隐藏维、头数、位置方法、归一化、激活、参数共享、mask、目标函数和冻结参数。模型名称相同不保证配置、权重、分词或上下文语义相同；小张量单测先于大规模训练。

### 训练与资源合同

保存有效词元、全局批量、学习率日程、优化器、数值格式、并行拓扑、吞吐、显存、通信和断点。比较在相同预算下进行或明确预算差异，恢复训练要验证数据游标、随机状态、优化器和调度器连续。

### 反馈、应用与安全合同

偏好标注记录协议、一致性和分歧；检索与代理记录证据片段、工具权限、状态和回退。提示注入、敏感信息、越权工具、奖励黑客、幻觉和过度拒答分别测试，聚合分数不能替代失败样本。

### 评测与发布合同

冻结任务、样本、提示、解码、判定和聚合规则，结果可下钻到输入、输出与理由。质量、安全、性能、成本和复现门禁全部通过才发布；发布单元包含模型、词元器、适配器、索引、提示、服务镜像和评测清单，并能整体回滚。

<Callout type="tip">
  **回退顺序：** 来源版本 → 数据切分 → 词元与mask → 模型与目标 → 训练预算 →
  反馈或工具 → 评测切片 → 发布边界。首个差异未解释前不比较最终结论。
</Callout>

<Answer>
