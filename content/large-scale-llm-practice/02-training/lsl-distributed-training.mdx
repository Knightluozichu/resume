# 分布式训练

## 学习目标

完成本章学习后，你将能够：

1. 理解数据并行、张量并行、流水线并行三种并行策略的原理与瓶颈
2. 掌握 ZeRO 优化器三阶段的显存切分策略与通信权衡
3. 运用混合精度训练和激活重计算优化显存
4. 设计 3D 并行策略训练千亿参数模型

## 核心概念

### 为什么需要分布式训练

一个 175B 参数模型用 FP16 训练，仅参数、梯度和 Adam 优化器状态就需约 840GB 显存，远超单卡 80GB（A100）。分布式训练通过切分计算和显存到多卡多机，让训练超大模型成为可能。

### 三大并行策略

**数据并行（DP）**：每张 GPU 持有完整模型副本，将训练数据切分到各卡，各卡独立做前向/反向，通过 AllReduce 同步梯度。瓶颈：模型必须能装入单卡显存，无法训练超大模型。

**张量并行（TP）**：将模型权重矩阵按行或列切分到不同 GPU，每卡持有部分参数，层内通过 AllReduce 通信。瓶颈：层内通信频繁且量大，通常限制在同一机内（NVLink 高带宽）。

**流水线并行（PP）**：将模型按层切分到不同 GPU，每卡持有一段连续层，数据以微批次流水线方式流过各卡。瓶颈：产生流水线气泡——某些 GPU 在等待时空闲。

三种并行互补：DP 扩规模、TP 切大层、PP 切层数，3D 组合（DP x TP x PP）可训练万亿参数模型。

### ZeRO 显存优化

ZeRO（Zero Redundancy Optimizer）通过切分训练状态消除数据并行中的显存冗余：

| 阶段 | 切分内容 | 显存节省 | 通信代价 |
|------|----------|----------|----------|
| ZeRO-1 | 优化器状态 | ~4x | 与 DP 相同 |
| ZeRO-2 | +梯度 | ~8x | 与 DP 相当 |
| ZeRO-3 | +参数 | Nx（N=卡数） | 增大约 1.5x |

ZeRO-1/2 几乎无额外通信开销，是「免费午餐」；ZeRO-3 用更多通信换显存，适合模型极大的场景。实践中常用 ZeRO-2（性价比最优）或 ZeRO-3（模型极大时）。

### 训练显存构成

训练时显存由四部分构成：

- **模型参数**：FP16 约 2 bytes/param
- **梯度**：FP16 约 2 bytes/param
- **优化器状态**：Adam 约 12 bytes/param（FP32 的动量和方差）
- **激活值**：随 batch 和 seqlen 增长

以 7B 模型 FP16 训练为例：参数 14GB + 梯度 14GB + Adam 56GB = 84GB（不含激活），ZeRO-3 可将前三项分摊到多卡。

### 混合精度与激活重计算

**混合精度训练**：用 FP16/BF16 做前向反向计算（快、省显存），用 FP32 维护主权重和优化器状态（精度高）。BF16 有与 FP32 相同的动态范围，无需损失缩放，是现代 GPU 上的主流选择。

**激活重计算（Gradient Checkpointing）**：只保存部分检查点，反向时重新前向计算恢复激活。用约 33% 的额外计算换取激活显存大幅降低。选择性重计算只重计算占用显存大但计算量小的激活（如注意力矩阵），进一步优化。

### 3D 并行设计

为千亿参数模型设计 3D 并行需综合考虑：

1. **TP 范围**：通信量大，限制在同一机内（8 卡 NVLink），TP 度取 4-8
2. **PP 范围**：通信量小，可跨机，PP 度根据层数和节点数确定
3. **DP 扩规模**：TP*PP 确定单副本卡数后，剩余卡做 DP 扩展
4. **ZeRO 配合**：在 DP 维度叠加 ZeRO-1/2 进一步切分优化器状态

示例：175B 模型用 TP=8 x PP=8 x DP=8 = 512 卡训练。

## 术语表

- **数据并行（DP）**：每卡完整模型副本，切分数据，AllReduce 同步梯度
- **张量并行（TP）**：切分权重矩阵，层内 AllReduce 通信
- **流水线并行（PP）**：按层切分到不同卡，微批次流水线执行
- **ZeRO**：零冗余优化器，切分优化器状态/梯度/参数消除显存冗余
- **混合精度训练**：FP16/BF16 计算 + FP32 主权重的训练方式
- **激活重计算**：只存检查点，反向时重算激活的显存优化技术
- **流水线气泡**：流水线并行中 GPU 等待空闲造成的计算浪费
