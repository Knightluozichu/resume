## 为什么“接得顺”还不够

把一套会写字的系统看成工厂：第一道工序学会把句子接下去，第二道工序练习按订单生产，后面还要学会在两件产品中选择更合用的一件。它们都改变成品，却不是同一道工序。

本章要拆开“会续写、会按要求回答、回答可靠”这三件事。不拆开，就会把一句顺口的回答误当事实，或误以为只要机器更大，所有工序就自动完成。

## 1.1 大规模语言模型基本概念

语言模型先回答“给定前缀，下一段文字有多大概率”，并不直接回答“这句话是否属实”。本节用实验 A 的分支树把条件概率、终止符与整条路径的联合概率连起来，再解释计数模型为何截断历史、神经模型为何共享参数。读完后用正文 Python 第一段复算乘积；模型规模只描述特定时代的参数、数据和计算背景，不设跨时代固定门槛。

### 从分支树到一条句子的概率

<Term def="给文字序列分配概率的模型；生成式模型据此前缀逐步预测下一段文字">
  语言模型
</Term>
描述文字序列的分布。实际系统常把文字切成 token：一个 token
可以是字、词片段或标点，并不必然等于一个词。它先给下一个 token
的各候选分配概率，再按选定规则输出；这发生在训练完成后的生成环节。

看实验 A 的树：起点 BOS 是开始标记，“我”和“你”分走首步概率。同一个“喜欢”接在不同前缀后，概率可以不同；这就是条件概率，而不是给“喜欢”贴一个永不变化的分数。实验中的分支、概率和句子都是自造的教学数据。

本节符号：

- $w_i$：位置 $i$ 的 token；$w_{<i}$：它前面的全部 token。
- $P$：教学模型的概率分布；$m$：序列长度，含终止符 EOS。

$$
P(w_1,\ldots,w_m)=\prod_{i=1}^{m}P(w_i\mid w_{<i})
$$

这在说：沿一条路径，把每次“已到这里后走下一步”的概率相乘。它是概率的链式法则，不需要假设各词独立。只对树作分解本身并不会减少要估计的条件分布数量。

先预测：把实验 A 的首词概率从 0.60 调到 0.80，选“我 / 喜欢 / EOS”，其余不改，完整路径会变成多少？逐步走到“终止与乘积”：默认为 $0.60\times0.70\times0.80=0.336$；修改后为 $0.448$。切换“你 / 喜欢 / EOS”，则是 $0.20\times0.40\times0.75=0.06$。先完整重置，再打开“忽略前缀”故障，对照第二层边宽与乘积。

### 为什么要共享参数，“大”又是什么意思

直接给每个前缀存一张概率表会很快遇到没见过的组合。n-gram 用最近的 $n-1$ 个词近似完整历史，节省估计量，但丢失更远的依赖；平滑给没见过的组合留出概率，不能凭空恢复被截掉的历史。实验 A 把第二步都改成 0.50，展示的是更极端的“删除前缀”错误，不是一个训练良好的 n-gram 实现。

神经方法用共享参数计算不同前缀的分布，并把词映射到可学习的向量；相似上下文可以共享统计信息，不必逐条存表。这是从稀疏计数走向共享表示的动机，不意味着神经模型不会犯错。下面正文 Python 第 1 段把概率因子显式列出，便于看清共享模型最终仍须输出哪些数。

“大规模”是时代、参数量、数据量和计算量相联系的描述，不是永恒不变的某个参数门槛。第一版开篇用当时的规模语境介绍 LLM；不应据此把一个固定数字当成所有时代的分类标准。更大的参数容量不直接保证更好的数据、对齐或事实可靠性。

<Callout type="trap" title="概率高，所以回答是真的？">
  **现象 →** 把流畅回答或高路径概率当作事实置信度。
  <br />
  **原因 →** 训练分布中常见的说法也可能错误；生成概率衡量续写倾向。
  <br />
  **修法 →** 用可核查资料验证事实。实验 A
  的所有数只描述路径，未定义任何“真值评分”。
</Callout>

## 1.2 大规模语言模型发展历程

理解模型历史，关键是跟踪结构怎样改变可用信息、训练目标又要求预测什么。本节先对照计数方法、ELMo、GPT、BERT 与 T5 的机制，再在实验 B 切换因果、双向和源—目标可见矩阵，观察把答案泄漏进输入会破坏什么。正文 Python 的严格下三角断言只核对 GPT 的历史约束；它不能证明其他架构已经实现，也不能把推理中的示例学习当成参数训练。

### 历史的变化是结构与目标，不只是年份

<Term def="训练某个目标时，模型被允许读取哪些输入位置；与使用后参数是否更新是两回事">
  上下文可见性
</Term>
决定模型能从哪里找线索。需要它，是因为“把中间缺字补回来”和“在末尾继续写”允许的信息不同。实验
B 位于训练目标层面：行是待预测位置，列是可读的原始
token，**不是注意力强弱，也不是逐层 attention mask 的逐格实现**。

### 把偷看答案画出来

猜一猜：训练 GPT 预测 t3 时，把 t3 本身开放给模型，损失可能降低吗？在实验 B 选 GPT，跳到第三步，再打开泄漏。新增的斜线格含目标与未来；损失可能很小，却不能用于不知道未来的真实续写。

## 1.3 大规模语言模型构建流程

同一份文字在不同阶段可以充当预测目标、回答示范或偏好比较，监督信号改变，参与更新的参数也随之改变。本节沿实验 C 的 PT、SFT、RM 与 RL 状态，分别检查目标 token 的 loss-mask、人标偏好对，以及策略、奖励模型和参考策略的更新或冻结角色。正文 Python 复算掩码损失和一对排序损失并更新一个标量；这些是可核算的原理，不是未公开产品训练流程的完整重放。

### PT：从连续文字学习分布

<Term def="先用大量文本的预测目标学习通用参数的训练阶段，常以文本自身构造监督信号">
  预训练
</Term>
（PT）把文本本身变成预测题：给前缀，预测真实下一个
token。它需要覆盖面来学语言统计，通常消耗构建流程中的主要计算；第一版所列 GPU
数量和天数是历史示例，不是每种模型的固定预算。

实验 C 的 PT 行把目标 token 画成“天 / 气 / 晴 / EOS”，隐含前面有 BOS；四格均参与损失。这里使用有效等长序列，省略 padding。**loss-mask** 是损失选择标记，1 表示该目标参与，0 表示不参与；它不是实验 B 限制输入可读范围的掩码。PT 每步通过损失更新模型参数 θ，不会自动学会所有指令格式。

### SFT：示范怎样按要求回答

<Term def="在已有模型上用输入与理想回复组成的示范继续训练参数">有监督微调</Term>
（SFT）把任务要求和理想回复拼接起来，让基础模型更倾向给出示范式回答。实验 C 的
SFT 样本把“问 / 题”作为提示，“答 / 案 / EOS”作为回复，使用回答-only损失：mask 是
`0 0 1 1 1`。

前两格虽然不计自身预测损失，仍然能被后面的回答读取、影响参数梯度。并非所有 SFT 实现都采用完全相同的 mask；本例选择它，是为了说明“提供上下文”和“让模型模仿输出”不同。与 1.2 的 ICL 相比，SFT 真正改变参数；ICL 只在当次上下文放示例。

### 奖励建模与 RL：偏好不是又一份标准答案

<Term def="利用人对答案的比较或评价，调整策略更符合某种偏好的过程；本页展示奖励模型加强化学习的RLHF路线">
  偏好对齐
</Term>
在示范之外提供“哪个更好”的信号。奖励建模（RM）给同一问题准备 A、B
两个答案，由人标出偏好；学习奖励参数 φ，让被偏好答案得分更高。实验 C
假设人偏好“查天气”而拒绝“乱断言”，不是声称所有人或情境都有同一排序。

随后 RL 从 SFT 策略生成新答案，冻结奖励模型 φ 来评分，同时冻结参考策略 θref，用 KL 偏离约束抑制策略为追逐奖励而偏得太远；更新的是当前策略 θ。完整算法还可能有价值模型、裁剪和其他训练项；实验 C 只展示角色与信号，不实现 PPO，也不保证偏好等于真理。

猜一猜：到 SFT 后打开故障，哪些 token 从不计损失变成计损失？再到 RM，把奖励差从 2 改成 0，原偏好对损失为什么上升？最后到 RL，检查谁更新、谁冻结。**完整重置**应同时恢复 PT、奖励差 2、故障关闭和暂停，不只是把图跳回第一张。

### 一步算清目标函数

- $p_i$：模型赋给第 $i$ 个真实目标的条件概率；$a_i$：该目标的 loss-mask。
- $r_\phi(x,y)$：奖励模型对输入 $x$ 和答案 $y$ 的分数；$y^+$/$y^-$：人偏好/拒绝的答案。
- $\theta$：当前策略参数；$\theta_{\mathrm{ref}}$：冻结参考策略；$\beta$：偏离惩罚强度。

$$
L_{\mathrm{text}}=-\frac{\sum_i a_i\log p_i}{\sum_i a_i}
$$

这在说：只对 mask 为 1 的真实目标求平均负对数概率；全零 mask 没有可训练目标，必须报错或跳过，不能除以零。

$$
L_{\mathrm{pair}}=\log\left(1+\exp\left[-(r_\phi(x,y^+)-r_\phi(x,y^-))\right]\right)
$$

这在说：人偏好的答案分数比另一个高得越多，这一对的排序损失越小；分数差为零时损失为 $\log 2$，不是零。

$$
J(\theta)=\mathbb{E}_{y\sim\pi_\theta(\cdot\mid x)}[r_\phi(x,y)]-\beta D_{\mathrm{KL}}(\pi_\theta\Vert\pi_{\theta_{\mathrm{ref}}})
$$

这在说：一个简化的 RL 目标要同时追求高奖励、避免偏离参考策略太远；不是把奖励模型的参数也一起朝高分修改。实现可用采样估计 KL，也可能加其他项。

<Callout type="trap" title="跑通四步就是重放 ChatGPT？">
  **现象 →** 把 toy 的损失下降称为完整复现某产品。
  <br />
  **原因 →** 未公开数据、筛选、训练细节与产品系统不在实验内；奖励也不等于事实。
  <br />
  **修法 →** 只报告可复算的
  mask、排序损失和一步参数变化；称为原理模拟，不声称完全重放 ChatGPT。
</Callout>

## 正文实践：仅用 Python 标准库复算

这是一份完整脚本，**按顺序把下方三个 Python 块连接为 `introduction.py`**，运行 `python3 introduction.py`；无需下载模型、安装包或读取附件。它检验 A 的乘积、C 的 mask 与一对偏好，再在一个标量玩具模型上更新一步。B 的可见性由第二段中的严格下三角断言对应；这不是训练 Transformer。

第一段对应 A：显式保留条件概率。`masked_nll` 同时拒绝越界概率、长度不匹配与全零 mask，免得没有监督信号还报告成功。

```python
import math


def path_probability(first=0.6, second=0.7, eos=0.8):
    return math.prod((first, second, eos))


def masked_nll(probabilities, mask):
    if len(probabilities) != len(mask) or not any(mask):
        raise ValueError("invalid loss mask")
    if any(a not in (0, 1) for a in mask):
        raise ValueError("mask must be binary")
    if any(not 0 < p <= 1 for p in probabilities):
        raise ValueError("invalid probability")
    return -sum(a * math.log(p) for p, a in
                zip(probabilities, mask)) / sum(mask)


probs = [0.8, 0.5, 0.25, 0.5, 0.8]
pt_loss = masked_nll(probs, [1, 1, 1, 1, 1])
sft_loss = masked_nll(probs, [0, 0, 1, 1, 1])
assert math.isclose(path_probability(), 0.336)
assert math.isclose(path_probability(0.8), 0.448)
print(f"path={path_probability():.4f}")
print(f"PT={pt_loss:.4f}, SFT={sft_loss:.4f}")
```

第二段对应 C 的 RM：把 A 的奖励设为 θ，B 的奖励设为 −θ，则差为 2θ。损失对 θ 的导数为 `-2/(1+exp(2*theta))`；沿负梯度更新会提高原偏好对的分差。这里把标量当奖励参数，和真实 RM 的高维 φ 不同；没有实现 RL。最后三行对应 B 的 GPT 可见矩阵，不包含 BOS。

```python
def pair_loss(theta):
    return math.log1p(math.exp(-2 * theta))


theta, learning_rate = 1.0, 0.1
before = pair_loss(theta)
gradient = -2 / (1 + math.exp(2 * theta))
theta -= learning_rate * gradient
assert pair_loss(theta) < before
assert pair_loss(-1.0) > before
assert math.isclose(pair_loss(0), math.log(2))
print(f"pair={before:.4f}, reversed={pair_loss(-1):.4f}")
print(f"theta={theta:.6f}, pair_after={pair_loss(theta):.4f}")
causal = [[j < i for j in range(4)] for i in range(4)]
assert [sum(row) for row in causal] == [0, 1, 2, 3]
assert not any(causal[i][j] for i in range(4) for j in range(i, 4))
```

第三段故意测试三种坏输入，并改成 SFT 的故障 mask。预期故障 mask 恰好退回 PT 的数值；**数值更低不说明回答更好**，因为改变了参加平均的目标集合。

```python
bad_inputs = [([0.5], [0]), ([0.0], [1]), ([0.5], [1, 1])]
rejected = 0
for probabilities, mask in bad_inputs:
    try:
        masked_nll(probabilities, mask)
    except ValueError:
        rejected += 1
assert rejected == 3
fault_loss = masked_nll(probs, [1, 1, 1, 1, 1])
assert math.isclose(fault_loss, pt_loss)
assert not math.isclose(fault_loss, sft_loss)
print(f"bad_inputs_rejected={rejected}, fault={fault_loss:.4f}")
```

预期五行输出依次为 `path=0.3360`、`PT=0.6438, SFT=0.7675`、`pair=0.1269, reversed=2.1269`、`theta=1.023841, pair_after=0.1214`、`bad_inputs_rejected=3, fault=0.6438`。第二行同时报告两个损失；请以这五条数值记录核对，不把它当模型能力测评。

## 小结

- 路径概率来自条件因子相乘，不是事实正确率。
- 可见上下文随目标变化，偷看未来会制造假成功。
- 样本、mask 和更新角色共同区分四个训练阶段。
