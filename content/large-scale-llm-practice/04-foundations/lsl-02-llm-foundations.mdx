## 为什么“能读上下文”还不等于“会预测下一词”：直觉

设输入是“我 喜欢 茶”。模型若在预测“喜欢”时看见了“喜欢”，训练误差会很好看，却没有学会从“我”出发预测未知的下一个词。因果限制不是生成阶段才打开的开关，而是决定训练任务是否成立的约束。

本章沿着一条可计算路径走：词元 ID 查表成为向量，注意力搬运上下文，FFN 改写每个位置的特征，残差和归一化稳定多层计算，最后用任务目标学习参数。三个实验分别观察**信息从哪来、向量怎样变、生成时哪些值可复用**，不是测模型聪明程度。

## 第2章 大语言模型基础

语言模型给序列一个联合概率。按概率链式法则，$P(x_1,\ldots,x_T)=\prod_{t=1}^T P(x_t\mid x_{<t})$。神经网络输出词表中每个候选的分数，经 softmax 变成条件概率。分布会随上下文改变，但“概率较大”不等于“事实正确”。本章关注这套计算怎样实现，不讨论对齐、工具调用或大规模分布式训练。

## 2.1 Transformer结构

记批量 B、长度 T、隐藏维 d、词表大小 V、查询头数 H。一个块的输入输出通常都是 $[B,T,d]$，所以可以逐层堆叠。注意力沿**词元轴**整合信息，前馈网络沿**特征轴**非线性变换；它们不是两个名称不同但功能相同的全连接层。以下忽略 dropout，计算使用行向量右乘权重的约定。

### 2.1.1 嵌入表示层

<Term def="按词元 ID 查找可学习向量的表；ID 数值差不代表语义距离。">嵌入</Term>是查表：参数矩阵 $E\in\mathbb R^{V\times d}$，整数 ID 张量 $[B,T]$ 选取相应行，得到 $[B,T,d]$。ID 本身的大小不表示词义距离；第 7 行不比第 8 行更“早”。重复 ID 会共享同一行参数，训练梯度也会累积到该行。

若没有位置信息，自注意力对输入排列具有置换等变性，不能自行识别“甲追乙”和“乙追甲”的语序。原始 Transformer 加正弦位置编码：

$$
PE(p,2i)=\sin(p/10000^{2i/d}),\quad PE(p,2i+1)=\cos(p/10000^{2i/d}).
$$

实际输入为 $X=\sqrt d\,E[ids]+PE$，形状不变；也可学习位置表，但必须说明是哪一种。正弦公式可计算更远位置，不代表模型就学会了任意长上下文。

实验 A 为便于手算，**另用手设偏移** $P=[(0,0),(0.5,0),(1,0)]$，不含 $\sqrt d$ 缩放。其嵌入行为 $(1,0),(0,1),(1,1)$，所以 $X=[(1,0),(0.5,1),(2,1)]$。不要把该教学矩阵当作某个 tokenizer 或真实模型的参数。先预测：关掉位置偏移，第二行的 Q、K 会怎样变？操作后看其分数和权重一起改变，再完整重置 A。

### 2.1.2 注意力层

<Term def="把 Q 与 K 点积缩放、按可见位置归一化，再用所得权重加权 V。">缩放点积注意力</Term>通过 Q 查询、K 匹配、V 搬运内容。单头时 $Q=XW_Q$、$K=XW_K$、$V'=XW_V$，其中 $W_Q,W_K\in\mathbb R^{d\times d_k}$，$W_V\in\mathbb R^{d\times d_v}$。这里用 $V'$ 区分值张量和词表大小 V。注意力为：

$$
S=QK^\top/\sqrt{d_k},\quad A=\operatorname{softmax}_{\text{每行}}(S+M),\quad O=AV'.
$$

单头 shapes 是 $[B,T,d_k]$、$[B,T,T]$、$[B,T,d_v]$。softmax 沿键位置轴归一化，而非沿特征轴。缩放是在分量方差适当的假设下控制点积尺度，避免分数随 $d_k$ 增大而使 softmax 过度饱和；它不是“消除一切梯度爆炸”的保证。

<Term def="在 softmax 之前禁止当前位置读取未来词元，保证训练与生成的前缀条件一致。">
  因果掩码
</Term>
规定 $M_{ij}=0$（$j\leq i$），否则为负无穷。屏蔽必须发生在 softmax
**之前**；若先 softmax 再把未来置零但不重归一化，行和会小于 1。padding mask
与因果 mask
也不同：前者排除填充位置，后者排除未来。若一整行全被屏蔽，常见实现会出现
NaN，不能把它解释成均匀分布。

实验 A 固定 $W_Q=W_K=I_2$、$W_V=\operatorname{diag}(1,2)$。默认查询第二词元时：

- Q 为 $(0.5,1)$，三个缩放分数为 $(0.354,0.884,1.414)$。
- 因果模式只对前两个分数做 softmax，权重约 $(0.370,0.630,0)$。
- 值行为 $(1,0),(0.5,2),(2,2)$，输出约 $(0.685,1.259)$，仍是二维。

先预测：打开“未来泄漏”，第三列能否保持为 0？点击后看矩阵的上三角从叉号变成非零，第二行输出不再等于参考值。切换第一行，因果输出必等于第一个 V，因为它只看得见自己。最后重置。

多头不是把完整注意力结果复制 H 份。常见 $d_k=d_v=d/H$，先投影并拆成 $[B,H,T,d/H]$，每头各自匹配；拼接回 $[B,T,d]$ 后乘 $W_O\in\mathbb R^{d\times d}$。例如 B=2、T=3、d=8、H=2，Q 是 $[2,2,3,4]$，分数是 $[2,2,3,3]$。当 d 不能被 H 整除时，这种均分实现应直接拒绝配置。

<Callout type="trap" title="误区一：训练时看见未来，生成时再遮住就好">
  现象：训练 loss
  很低，自回归生成却不断重复。原因：训练条件分布包含答案，而推理条件分布不包含答案；低
  loss 测量了错误任务。修法：同时检查右移标签和每行 mask，用实验 A
  第二行的未来非零权重定位泄漏，而不只比较生成文本。
</Callout>

### 2.1.3 前馈层

<Term def="每个位置独立使用同一组升维、非线性与降维参数，不在此子层混合词元。">
  逐位置前馈网络
</Term>
对每个词元应用同一组参数：$F(x)=\operatorname{ReLU}
(xW_1+b_1)W_2+b_2$。$W_1:[d,d_{ff}]$ 升维，$W_2:[d_{ff},d]$ 降维，整体
$[B,T,d]\to[B,T,d_{ff}
]\to[B,T,d]$。**逐位置**不是每个位置都有自己的参数，也不是在相邻词元之间做卷积。两个线性层之间若没有非线性，它们可合并成一个线性映射，表达能力会受限。

实验 B 使用明确的二维到三维再到二维变换：

$$
W_1=\begin{bmatrix}1&0&1\\0&1&-1\end{bmatrix},\quad
W_2=\begin{bmatrix}0.5&0\\0&0.5\\1&-1\end{bmatrix},\quad
b_1=0,\quad b_2=(0.5,-0.5).
$$

对 $x=(1,3)$，隐藏值先是 $(1,3,-2)$，ReLU 后为 $(1,3,0)$，输出 $F(x)=(1,1)$。图中的二维轨迹是**特征坐标**，不是二维词义聚类结果。下方柱高直接画第一分量，可与正文逐项相乘核对。

### 2.1.4 残差连接与层归一化

<Term def="把子层输入直接加回其输出，保留信息与恒等梯度通道。">残差连接</Term>
把输入直接加回子层输出：$z=x+F(x)$，因而两者维数必须一致。反向传播中存在恒等梯度通道
$I+\partial F/\partial x$，有助于深层优化，但不保证所有层梯度稳定。

<Term def="在单词元的特征维上减均值并按标准差缩放，再施加可学习仿射变换。">
  LayerNorm
</Term>
在一个词元的 d 个特征上求均值与方差：

$$
\mu=\frac1d\sum_i z_i,\quad
\operatorname{LN}(z)_i=\gamma_i\frac{z_i-\mu}{\sqrt{\frac1d\sum_j(z_j-\mu)^2+\epsilon}}+\beta_i.
$$

它不跨批量计算，不能用 BatchNorm 的“运行均值”解释。原始 Transformer 的 post-LN 子层为 $y=\operatorname{LN}(x+F(x))$。实验 B 设置 $\gamma=1,\beta=0,\epsilon=10^{-6}$，$z=(2,4)$、均值 3、方差 1，输出约 $(-1,1)$。两次子层分别归一化，而不是整个模型只做一次。

先预测：删除残差后会怎样？实验 B 的 $F(x)=(1,1)$ 方差为 0，LN 输出变成 $(0,0)$，不是报除零，因为有 ε。然后切换 pre-RMSNorm：输入先归一化再进 FFN，残差最后相加；观察输出和中间轨迹全部改变。此模式只比较**顺序与归一化公式**，仍沿用 toy ReLU FFN；完整 LLaMA 的 SwiGLU 留到 2.3.1。完整重置 B 会恢复 post-LN、c=0、残差开启和暂停首帧。

### 2.1.5 编码器和解码器结构

编码器每层是双向自注意力加 FFN；源句全部已知，所以源位置可互看。解码器则依次为**因果自注意力、对源句的交叉注意力、FFN**，原始结构各子层带 Add & Norm。目标序列右移一位输入，不能把目标词本身当作它的可见前缀。

交叉注意力的 Q 来自目标隐藏状态，K/V 来自编码器输出。源长度 S、目标长度 T 时，分数是 $[B,H,T,S]$，不是 $[B,H,T,T]$。源 padding 要遮住，但不应对已知源句套目标的三角 mask。例：源 4 词、目标 3 词，每头交叉分数有 12 个位置；目标自注意力只有 6 个允许的因果位置。

实验 A 关因果可类比**源句双向编码**，不能据此认为 decoder 的未来泄漏也合法。GPT 的 decoder-only 移除了对编码器输出的交叉注意力；“decoder-only”不是删除因果约束，也不是照搬原始翻译解码器的全部模块。

## 2.2 生成式预训练语言模型GPT

GPT 的关键是把通用语言建模和任务适配分开。原始 GPT 采用仅解码器结构，学习词元与位置嵌入，使用因果自注意力。预训练得到的是条件分布参数，不是预存一份答案表；同样结构可以承担生成，也能通过任务头承担分类。

### 2.2.1 无监督预训练

称作“无监督”是因为不需人工逐条标注；监督信号由文本自己生成，今天也常称自监督。<Term def="用当前位置及之前的前缀预测后一个词元，标签与可见输入相差一位。">下一词预测</Term>最小化：

$$
L_{PT}=-\sum_t\log P_\theta(x_t\mid x_{<t}).
$$

取序列 `[BOS, 我, 喜欢, 茶]`，输入为 `[BOS, 我, 喜欢]`，标签为 `[我, 喜欢, 茶]`。logits 的形状 $[B,3,V]$，每行对应其**后一个**词元。实际库有的在模型内部 shift；不可外部和内部同时移位。损失只计算有效标签，padding 不计入均值；mask 决定谁可见，label-ignore 决定哪里计分，二者不互相替代。

若三个正确词概率是 $0.5,0.25,0.8$，总 NLL 为 $-\log0.1=2.302585$，平均为 $0.767528$，困惑度为 $e^{0.767528}\approx2.154435$。这只对相同 tokenizer、同样有效词元和评估数据有可比性。下文程序还对一个 bigram 分布做真实的一步梯度更新，验证优化能降低该样本损失；不是训练 Transformer 或复现 GPT。

### 2.2.2 有监督下游任务微调

本节原始 GPT 范式不是默认聊天指令微调。对带标签样本 $(x,y)$，取末个**有效词元**的隐藏向量 $h\in\mathbb R^d$，接分类矩阵 $W_y\in\mathbb R^{d\times C}$，得到 $[B,C]$ logits，最小化 $L_{FT}=-\log P(y\mid x)$。例如 $h=(1,2)$、$W_y=I$，两类概率约 $(0.269,0.731)$，标签为第二类时损失 $0.313262$。程序用这个 h 更新分类权重，固定主干，演示最小线性探针；真实全参数微调还会更新主干。

任务优化可能损伤通用语言能力，即灾难性遗忘。原文讨论混合目标 $L=L_{FT}+\lambda L_{PT}$。假设 $\lambda=0.2$，用上文**平均** PT 损失，混合标量约 $0.466767$。必须统一 reduction 和 token 数量：直接把总 PT loss 加到平均 FT loss，实际权重会随句长漂移。混合目标不保证一定不遗忘，仍须分别评估语言建模和下游任务。

### 2.2.3 基于HuggingFace的预训练语言模型实践

**原书在此具体构建的是 BERT，不是 GPT。**任务是 <Term def="从双向可见上下文恢复部分被选位置的原词；未选位置不计该项损失。">掩码语言建模</Term>（MLM），通过双向上下文恢复被选中的位置。原文使用 BookCorpus 与英文 Wikipedia 合并、90/10 划分、WordPiece 训练、BertForMaskedLM、Trainer，最后用 fill-mask 补空。这条流程不能因为上一节讲 GPT 就改成自回归续写。

| 环节                | 输入输出与职责                                                           | 需要守住的边界                                                                                 |
| ------------------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| 语料与划分          | 文档字符串 → 训练集/测试集                                               | 先按文档划分并排除重复泄漏；不能拿测试集训练 tokenizer                                         |
| WordPiece           | 文本 → token 字符串 → ID；训练词表并保存特殊词元                         | 同一 tokenizer 的词表大小必须匹配模型 V；PAD/UNK/CLS/SEP/MASK 职责不同                         |
| 分块/整理           | ID 序列 → 长度不超过 512 的块；批量 input_ids、attention_mask 为 $[B,T]$ | 截断会丢尾部；拼接后切块可能跨文档，需明确边界与余数处理                                       |
| MLM collator        | 动态选择部分普通词元为预测位置，labels 为 $[B,T]$                        | 书例 `mlm_probability=0.2` 是选择预测位置比例，不表示每个被选位置必替换成 MASK；特殊词元应排除 |
| BERT + MLM head     | 隐藏状态 $[B,T,d]$ → 词表 logits $[B,T,V]$                               | 只在被选位置算交叉熵，未选位置常用 -100 忽略；attention_mask 通常屏蔽 PAD，而非三角因果 mask   |
| Trainer / fill-mask | 优化损失与保存检查点；取 MASK 位置的词表 top-k                           | 填空允许看左右文，不等于从左到右生成；并非分类头 $[B,C]$                                       |

例如 `[CLS, 我, MASK, 茶, SEP]`，标签只有第三个位置为“喜欢”，其余为 -100；模型可利用右侧“茶”。这与 GPT 在“我”后预测“喜欢”的**输入条件**不同，二者 loss 数值不能直接作能力排名。

书内代码是历史示例：包含旧的数据集加载名、旧的训练参数拼写和 tokenizer 导入描述。本页**未下载数据、未跑当前 transformers/datasets API，也未训练 BERT**，不将旧日志充作本站实测。若迁移到真实 HF 环境，先锁定库版本、检查许可证与数据可用性、核对 tokenizer 所属包和特殊 ID，再做小批前向检查 `[B,T,V]` 和有限 loss；Trainer 能启动不代表数据目标正确。下面代码只用标准库显式构造 MLM 标签，验证职责，不实现 WordPiece 学习或 BERT。

<Callout type="trap" title="误区二：BERT和GPT都有词表softmax，所以可以互换标签">
  现象：把 MLM 的 labels 右移，或让 GPT
  双向读入所有真实词后计分。原因：忽略了输入条件与计分位置；同为 [B,T,V]
  不能证明任务相同。修法：写出某一行具体可见的词与正确标签。BERT 的 MASK

## 2.3 大语言模型结构

扩大参数并不改变基本张量职责，但会放大数值稳定性、内存搬运与长序列开销。读结构时先区分三个维度：归一化/激活改变向量变换，位置机制改变匹配方式，注意力优化改变连接或执行策略。不能用“模型更大”替代这些差别。

### 2.3.1 LLaMA的模型结构

LLaMA 在 decoder-only 骨架中采用 pre-normalization、RMSNorm、SwiGLU 和 RoPE。一个块可写为：

$$
h=x+\operatorname{Attn}(\operatorname{RMS}(x)),\qquad
y=h+\operatorname{SwiGLU}(\operatorname{RMS}(h)).
$$

<Term def="按均方根缩放特征而不减均值的归一化，和前置/后置的位置选择是不同概念。">RMSNorm</Term>用均方根而不减均值：$\operatorname{RMS}(x)_i=\gamma_i x_i/\sqrt{\frac1d\sum_jx_j^2+\epsilon}$。对 $(1,3)$，RMS 为 $\sqrt5$，结果约 $(0.447,1.342)$；LN 约为 $(-1,1)$。所以 RMSNorm 不是把 LayerNorm 换个简称，它不会强制零均值。实验 B 切到 pre 模式，得到 $F(\operatorname{RMS}(x))\approx(0.724,0.171)$，最终约 $(1.724,3.171)$。把两分量同时平移 c，可看见 pre-RMS 路径与 post-LN 路径的不同。

原文此处有 GPT-2 与 RMSNorm 叙述连写，须区分：**GPT-2 使用前置 LayerNorm，LLaMA 使用前置 RMSNorm**。pre/post 是放置位置，LN/RMS 是计算公式，不能把两个维度捆成同义词。

SwiGLU 令 $a=xW_g$、$b=xW_u$，先算 $\operatorname{SiLU}(a)\odot b$，再乘 $W_d$ 回到 d；$\operatorname{SiLU}(a)=a\sigma(a)$。两条投影都为 $[B,T,m]$，逐元素门控后仍为该形状，最终 $[B,T,d]$。例如 $a=(1,-1),b=(2,3)$，门控约 $(1.462,-0.807)$；负分量不会像 ReLU 那样一概清零。忽略 bias 时三矩阵参数量 $3dm$，若与传统 $d_{ff}=4d$ 的 $2d\cdot4d=8d^2$ 对齐，取 $m\approx8d/3$，再按实现倍数取整，而非任意压小维度。

<Term def="按位置旋转 Q/K 成对分量，让内积携带相对位置信息。">RoPE</Term>在 Q/K
的成对分量上旋转。二维旋转 $R(\phi)=\left[\begin
{smallmatrix}\cos\phi&-\sin\phi\\\sin\phi&\cos\phi\end{smallmatrix}
\right]$，位置 m 用 $R(m\theta)q$，位置 n 用 $R(n\theta)k$，内积为 $q^\top
R((n-m)\theta)k$。取 $q=k=(1,0)$、$\theta=\pi/2$，同位置内积 1，相差 1 内积
0，相差 2 内积
-1；两者共同平移一个位置不改变相对内积。高维对不同分量对使用不同频率；通常旋转
Q/K 而不是 V。数学上能旋转更远位置不保证长上下文任务正确。

### 2.3.2 注意力机制优化

本节原文重点展开**稀疏注意力、FlashAttention、多查询注意力**。GQA 在下表作为 MHA/MQA 的分组推广补充，不能据此给第一版增造一个正式小节。

**第一类：改变可见连接。**稀疏方法不再让每个 Q 与所有 K 匹配。基于位置的五类是全局节点、带状窗口、膨胀间隔、随机连接、局部块；组合例包括 Star-Transformer 的环邻域加全局节点、Longformer 的窗口加全局、ETC 的全局与局部通道、BigBird 的窗口/全局/随机。固定宽 w 的窗口每层约 $O(Tw)$ 对，但远距离信息可能需要多层转接，复杂度减少不等于无损保留稠密行为。基于内容的 Routing Transformer 按 Q/K 聚类，只在同簇交互；Reformer 按局部敏感哈希分桶。两者都要考虑路由/分桶成本和漏掉重要连接的代价，不能仅把 $T^2$ 换成一个理想线性数字。

**第二类：不改变数学连接，改变搬运。**<Term def="用分块和在线 softmax 减少注意力矩阵的显存搬运，仍计算稠密注意力。">FlashAttention</Term>用片上小容量 SRAM 分块计算，减少对较慢大容量 HBM 的读写，不完整落地 $T\times T$ 分数/概率矩阵。它仍算稠密注意力，核心算术复杂度仍是 $O(T^2d)$，不是删掉上三角之外的任意“低权重位置”。浮点顺序变化可能带来微小误差，不要求逐位相同。

在线 softmax 能精确合并分块统计量：每块保留最大值 m、指数和 l、未归一化加权和 u。旧/新块最大值取 $m'=\max(m,m_b)$，再算 $l'=e^{m-m'}l+e^{m_b-m'}l_b$，$u'=e^{m-m'}u+e^{m_b-m'}u_b$，最后输出 $u'/l'$。例：分数 `[0, ln 2]`、值 `[2,4]`，两块合并后权重为 `[1/3,2/3]`，结果 $10/3$。正文程序实际复算，避免把“逐块各自 softmax 再平均”误当同一算法。此 toy 不测 SRAM/HBM 或 GPU 性能。

**第三类：生成时复用历史 K/V，并减少 KV 头。**<Term def="保存因果模型历史各层的键和值，后续生成只计算新位置并复用历史状态。">KV缓存</Term>只存历史层的 K/V，新词元只需投影自己的 Q/K/V，再用新 Q 读取历史 K/V。历史表示不受未来影响是复用成立的关键，因此依赖因果结构、固定参数和正确位置；双向 BERT 添词时旧隐藏状态可能改变，不能直接套用同一缓存逻辑。

| 方案        | 查询头 Hq=4 时的 KV 头 Hkv | 主要改变                                     |
| ----------- | -------------------------- | -------------------------------------------- |
| MHA         | 4                          | 每个查询头有独立 K/V                         |
| MQA         | 1                          | 所有查询头共享一组 K/V；Q 仍为四头           |
| GQA（补充） | 2                          | 每组两个查询头共享一组 K/V；组数须与实现匹配 |

原书 MQA 段引用的文献 [63] 正是 GQA（generalized multi-query）研究，但没有单列 GQA 的正式小节。这里的两组示意是对书内引用方向的补充解释，不冒充原文展开。

MQA 修改模型参数结构，通常需要训练支持；不是给一个任意 MHA 检查点点开关就能无损压缩。若 $d=8,Hq=4,d_h=2$，融合 QKV 的输出宽度为 $d+2Hkv d_h$，MHA 为 24，MQA 为 12，GQA 为 16。原文 MQA 例为 $d=768,Hq=8,d_h=96$，故融合宽度 960，而非 MHA 的 2304。

缓存理论字节为 $2LBTHkv d_hs$，2 代表 K 与 V，L 为层数，s 为每元素字节；不包括权重和临时激活。例：B=1、L=2、T=4、Hkv=4、$d_h=2$、s=2 时为 256 字节，MQA 为 64 字节，分组补充为 128 字节。实际系统还存在内存分配、padding、分页等开销，本章不模拟它们。

实验 C 默认暂停在长度 t=1；先预测，点末步到 t=4，再切换缓存：不缓存累计重投影 $1+2+3+4=10$ 个词元；缓存只投影 4 次。若只计**因果允许的 QK 对**，全前缀重算累计 $1+3+6+10=20$，缓存累计 $1+2+3+4=10$（单头、单层）。它没有把注意力变成常数时间：每个新 Q 仍读长度 t 的 K/V，生成 N 个词的注意力总量仍随 N 平方增长。先把长度改到 8，比较两种三角形；在缓存开启时再打开“丢首词KV”，观察存储缺口。无缓存时每轮重算完整前缀，丢缓存故障不适用；切换到无缓存会清空并禁用故障，不能把它说成丢失上下文。这不是无损优化，除非模型本来就允许相同截窗。完整重置 C 恢复所有参数与时间线。

## 可运行实验：只用 Python 标准库

将下方完整代码保存为 `foundations_toy.py`，用 Python 3.10+ 执行 `python3 foundations_toy.py`。无第三方包、无网络、无随机数，也不下载模型。它检查注意力、FFN/LN/RMS、PT 与分类头的一步更新、MLM 标签、RoPE 内积、分块 softmax、缓存/重算生成一致性。生成用固定二维向量与 argmax，是确定性演算，**不是训练好的语言模型**；MLM 部分只检查标签职责，不实现 BERT 或 WordPiece。

```python
import math


def softmax(scores):
    m = max(scores)
    exps = [math.exp(v - m) for v in scores]
    return [v / sum(exps) for v in exps]


def dot(a, b):
    return sum(x * y for x, y in zip(a, b))


def close(a, b):
    assert len(a) == len(b)
    assert all(abs(x - y) < 1e-6 for x, y in zip(a, b)), (a, b)


E = [[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]]
X = [[e[0] + i / 2, e[1]] for i, e in enumerate(E)]
values = [[x[0], 2 * x[1]] for x in X]
scores = [dot(X[1], k) / math.sqrt(2) for k in X]
weights = softmax(scores[:2]) + [0.0]
output = [sum(w * v[d] for w, v in zip(weights, values)) for d in range(2)]
leaked = softmax(scores)
assert leaked[2] > 0 and weights[2] == 0
close([sum(weights)], [1.0])
print("attention", [round(v, 6) for v in output])


def ffn(x):
    h = [max(0, x[0]), max(0, x[1]), max(0, x[0] - x[1])]
    return [h[0] / 2 + h[2] + 0.5, h[1] / 2 - h[2] - 0.5]


def norm(x, rms=False):
    mean = 0 if rms else sum(x) / len(x)
    scale = math.sqrt(sum((v - mean) ** 2 for v in x) / len(x) + 1e-6)
    return [(v - mean) / scale for v in x]


x = [1, 3]
f = ffn(x)
close(f, [1, 1])
post = norm([a + b for a, b in zip(x, f)])
close(norm(f), [0, 0])  # 删除残差后的退化
pre = [a + b for a, b in zip(x, ffn(norm(x, rms=True)))]
print("post/pre", [round(v, 6) for v in post], [round(v, 6) for v in pre])

# GPT式标签右移；此处没有框架内部再shift。
ids = [0, 1, 2, 3]  # BOS, 我, 喜欢, 茶
inputs, targets = ids[:-1], ids[1:]
assert inputs == [0, 1, 2] and targets == [1, 2, 3]
pt_mean = -sum(math.log(p) for p in [0.5, 0.25, 0.8]) / 3
print("PT mean/PPL", round(pt_mean, 6), round(math.exp(pt_mean), 6))
# 对一个bigram条件分布做真正的一步SGD，不是Transformer反传。
logits = [0.0] * 4
p = softmax(logits)
before = -math.log(p[1])
logits = [v - 0.1 * (p[j] - int(j == 1)) for j, v in enumerate(logits)]
after = -math.log(softmax(logits)[1])
assert after < before

# 固定隐藏向量，只更新分类头；不称为全模型微调。
h = [1, 2]
W = [[1.0, 0.0], [0.0, 1.0]]
class_p = softmax([sum(h[i] * W[i][j] for i in range(2)) for j in range(2)])
ft_before = -math.log(class_p[1])
for i in range(2):
    for j in range(2):
        W[i][j] -= 0.1 * h[i] * (class_p[j] - int(j == 1))
ft_after = -math.log(softmax([sum(h[i] * W[i][j] for i in range(2)) for j in range(2)])[1])
assert ft_after < ft_before
print("FT/mixed", round(ft_before, 6), round(ft_before + 0.2 * pt_mean, 6))
print("SGD decreased", after < before, ft_after < ft_before)

# BERT式MLM：只在选中位置恢复原词；特殊ID为手设，不是HF词表。
cls, sep, mask = 4, 5, 6
original = [cls, 1, 2, 3, sep]
mlm_input = original.copy()
mlm_input[2] = mask
labels = [-100, -100, original[2], -100, -100]
assert labels[2] == 2 and mlm_input[2] == mask
assert sum(v != -100 for v in labels) == 1
assert mlm_input[3] == 3  # 右侧上下文仍可见
print("MLM labels", labels)


def rotate(v, angle):
    c, s = math.cos(angle), math.sin(angle)
    return [c * v[0] - s * v[1], s * v[0] + c * v[1]]


q, k = [1, 0], [1, 0]
close([dot(rotate(q, math.pi / 2), rotate(k, math.pi))], [0])
close([dot(q, rotate(k, math.pi))], [-1])

# 两块在线softmax：保留最大值、分母、未归一化分子。
m, l, u = -math.inf, 0.0, 0.0
for score, value in [(0.0, 2.0), (math.log(2), 4.0)]:
    new_m = max(m, score)
    old_scale = math.exp(m - new_m)
    new_scale = math.exp(score - new_m)
    l = old_scale * l + new_scale
    u = old_scale * u + new_scale * value
    m = new_m
close([u / l], [10 / 3])
print("online softmax", round(u / l, 6))

# 固定的单层因果toy：K含手设位置偏移，缓存必须保留原位置。
def kv(token, position):
    key = [E[token][0] + position / 2, E[token][1]]
    return key, [key[0], 2 * key[1]]


def generate(cached):
    tokens, keys, vals, outputs = [0], [], [], []
    for _ in range(4):
        if cached:
            key, val = kv(tokens[-1], len(tokens) - 1)
            keys.append(key)
            vals.append(val)
        else:
            pairs = [kv(token, pos) for pos, token in enumerate(tokens)]
            keys = [p[0] for p in pairs]
            vals = [p[1] for p in pairs]
        query = keys[-1]
        a = softmax([dot(query, key) / math.sqrt(2) for key in keys])
        out = [sum(w * v[d] for w, v in zip(a, vals)) for d in range(2)]
        outputs.append(out)
        token_logits = [dot(out, row) for row in E]
        tokens.append(max(range(3), key=lambda j: token_logits[j]))
    return tokens, outputs


full_tokens, full_out = generate(False)
cache_tokens, cache_out = generate(True)
assert full_tokens == cache_tokens
for a, b in zip(full_out, cache_out):
    close(a, b)
print("cache tokens", cache_tokens)
# 对全部N=1..8及三种KV头计数，不假装测量真实分配器。
for n in range(1, 9):
    assert sum(range(1, n + 1)) == n * (n + 1) // 2
    assert sum(t * (t + 1) // 2 for t in range(1, n + 1)) == n * (n + 1) * (n + 2) // 6
    for kv_heads in [1, 2, 4]:
        memory = 2 * 2 * 1 * n * kv_heads * 2 * 2
        assert memory == 16 * n * kv_heads
print("cache bytes MHA/MQA/GQA", [2 * 2 * 1 * 4 * heads * 2 * 2 for heads in [4, 1, 2]])
print("PASS: deterministic standard-library toy; no HF/model/GPU benchmark")
```

预期关键结果：attention 约 `[0.68522, 1.25912]`，post 约 `[-1,1]`，pre 约 `[1.723607,3.17082]`；PT mean 为 `0.767528`，FT 为 `0.313262`，mixed 为 `0.466767`；两次 SGD 的下降断言均为 True；在线 softmax 为 `3.333333`；缓存和重算的生成 ID 完全相同，MHA/MQA/GQA 理论字节依次为 `[256,64,128]`。末行 PASS 表示这些有限断言成立，不是任何训练质量或真实性能认证。

## 小结

- 先算 shape、可见位置、权重，再谈生成内容。
- FFN 改特征，残差留直通，归一化顺序不可交换。
- GPT、BERT、分类头的输入条件与标签职责不同。
- 缓存省重算，FlashAttention 省搬运，MQA 省 KV 头。
