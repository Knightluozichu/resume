# 服务化与推理优化

## 学习目标

完成本章学习后，你将能够：

1. 理解 KV 缓存的加速原理和显存占用计算
2. 掌握 vLLM 的 PagedAttention 和连续批处理技术

4. 理解投机解码的加速原理和适用场景

## 核心概念

### 推理优化的动机

大模型推理是**内存带宽受限**的：每生成一个 Token 需读取全部模型权重，但计算量很小，GPU 计算利用率低。推理优化的核心目标是在保证质量的前提下提升吞吐量（tokens/s）和降低延迟（TTFT/TPOT）。

### KV 缓存

自回归生成时，每生成一个新 Token 需计算它与之前所有 Token 的注意力。若不缓存，每步需重新计算所有历史 Token 的 Key/Value 投影，计算量为 O(n^2)。

KV 缓存将之前步骤算出的 K/V 向量缓存下来，新 Token 只需计算自己的 Q/K/V，然后用新 Q 与缓存的 K 算注意力。每步计算量降为 O(n)，总推理从 O(n^3) 降为 O(n^2)。

显存占用：$\text{KV Cache} = 2 \times n_{layers} \times n_{heads} \times d_{head} \times \text{seqlen} \times \text{batch} \times 2\text{bytes}$。以 LLaMA-7B 为例，约 0.5MB/Token，2048 上下文单条约 1GB，batch=32 约 32GB，与模型参数相当甚至更大。

### PagedAttention（vLLM）

传统方式为每个请求预分配最大上下文长度的连续 KV 缓存空间，导致大量显存浪费和碎片化。PagedAttention 借鉴 OS 虚拟内存分页机制：

- 将 KV 缓存划分为固定大小的块，用块表映射逻辑块到物理块
- 按需分配，无需预分配最大空间，显存利用率从 20-40% 提升到接近 100%
- Copy-on-Write 共享——多请求共享相同前缀（如 system prompt）的 KV 块
- 消除外部碎片和内部碎片

vLLM 实测吞吐比 HuggingFace Transformers 高 2-4 倍。

### 连续批处理

传统静态批处理等一个 batch 的所有请求都生成完才处理下一 batch，长请求拖累短请求。连续批处理在 iteration 级别动态调度：某请求生成完立即移除，新请求立即加入，不同长度请求共存。GPU 持续满载，吞吐提升 3-8 倍。

### 量化策略

| 精度 | 显存 | 精度损失 | 适用场景 |
|------|------|----------|----------|
| FP16 | 1x | 无损 | 基线 |
| INT8 | 0.5x | 近似无损 | 通用部署 |
| INT4 | 0.25x | 轻微（1-3%） | 显存受限 |
| AWQ/GPTQ | 0.25x | 最小 | 精度最优 |

**AWQ**（激活感知量化）：保护激活值大的重要通道保持高精度，其余量化到 INT4。**GPTQ**：基于 Hessian 信息的逐层量化，用误差补偿减少精度损失。

### 投机解码

用小「草稿模型」快速生成 k 个候选 Token，大模型一次前向并行验证。若草稿模型准确率高，大模型一次前向可确认多个 Token，减少大模型前向次数。若 4 个 Token 验证通过 3 个，速度提升近 4 倍。关键是草稿模型要小且快，同时与大模型分布接近。

### 主流推理框架

| 框架 | 特点 |
|------|------|
| vLLM | PagedAttention 高吞吐，最流行 |
| TGI | HuggingFace 生产级部署 |
| TensorRT-LLM | NVIDIA 极致优化 |
| llama.cpp | CPU/边缘部署 |

### 服务关键指标

- **TTFT**（Time To First Token）：首 Token 延迟，影响首屏体验
- **TPOT**（Time Per Output Token）：每 Token 延迟，影响生成速度
- **吞吐量**（tokens/s）：单位时间生成的 Token 数
- **显存利用率**：GPU 显存使用效率

## 术语表

- **KV 缓存**：缓存自注意力的 Key/Value 避免重复计算的加速技术
- **PagedAttention**：借鉴 OS 分页机制管理 KV 缓存的技术（vLLM）
- **连续批处理**：iteration 级动态调度请求的批处理技术
- **量化**：将 FP16 权重映射到 INT8/INT4 减少显存和加速计算
- **AWQ**：激活感知权重量化，保护重要通道
- **GPTQ**：基于 Hessian 信息的逐层量化方法
- **投机解码**：用小模型生成草稿、大模型验证的加速技术
- **TTFT/TPOT**：首 Token 延迟/每 Token 延迟
