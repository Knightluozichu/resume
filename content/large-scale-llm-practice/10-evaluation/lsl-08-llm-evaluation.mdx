## 第8章 大语言模型评估

设想模型 A 擅长短步骤题，模型 B 擅长长步骤题。用短题考试时 A 领先，真实用户多问长题时却是 B 更可靠。两张榜单都可能算对，冲突出在“代表谁”。再把熟悉的题重复五次，分数不变，某些检验却显得更有把握。评估因此不只是运行评分器，而是约定问题、样本、输出和推断范围。

本章以三种可观察的变化贯穿第 8 章：**换分母、换分布、换证据单位**。它们分别解释为什么词匹配不等于完整答案，为什么单一总分不能代表所有用户，以及为什么排行榜领先不一定构成统计证据。交互和 Python 均使用自造小数据，不是真实模型评测、训练或性能重放。

## 8.1 模型评估概述

评估要回答模型在未见数据上的泛化表现。训练集用于拟合参数，验证集用于选择超参数、提示或检查点，测试集用于冻结方案后的最终比较。即使测试题没有出现在训练集中，若反复根据测试分数修改提示，它也已参与选择，不能继续被当作未触碰的检验。独立样本还不必然代表部署分布：时间、语言、人群和任务长度都可能发生变化。

把问题划成同分布 ID 与分布外 OOD 等可解释组，就是本章的<Term def="按任务长度、领域、语言等条件分组，分别测量表现并说明与目标人群的关系">分布切片</Term>。原文用符号推理从短序列延长到长序列说明外推难点。这里固定每片 20 题：A 在 ID 答对 18 题、OOD 答对 6 题，B 分别答对 16、14 题。两片等量测试集直接合并是 A 60%、B 75%；它只对应测试集的 50%/50% 混合，不自动等于用户流量。

令部署的 OOD 比例为 $w$，则 $a_A(w)=0.9(1-w)+0.3w$，$a_B(w)=0.8(1-w)+0.7w$。当 $w=0.1$ 时 A 为 84%、B 为 79%；当 $w=0.8$ 时 A 为 42%、B 为 72%。这不是模型突然退化，而是被估计的目标群体变了。先预测：只调 OOD 比例、不动任何一条答题记录，哪条结果条会缩短得更快？再打开“只保留 ID”故障，观察被排除的分布区域。

生成式评估还有额外困难：同一意思有多种正确表达，格式错误、事实错误和不安全建议又是不同失败。预训练模型侧重续写与基础能力，SFT 模型学习指令响应，RL 后模型可能改变拒答和偏好风格。应同时冻结生成参数、答案抽取规则、拒答处理和评测集版本，再比较这些阶段，不能把“更像聊天”当作通用能力提升。

## 8.2 大语言模型评估体系

体系决定“考什么”，指标决定“怎么计分”。原章把体系分为知识与能力、伦理与安全、垂直领域三条线。它们不是一个从低到高的总等级：通过法律选择题不能代替隐私测试，通过安全测试也不保证数学推理可靠。制定评测时先列预期用途、受影响人群、输入分布与不能接受的失败，再选择下面的任务与判据。

### 8.2.1 知识与能力

任务中心的路线把语言任务拆成可复用场景。[HELM](https://arxiv.org/abs/2211.09110)以任务、领域和语言描述场景，领域还可以区分内容、时间和参与者。原章介绍其历史设置中的 42 类场景、16 个核心场景，重视准确性之外的稳健、公平等维度；当时主要覆盖英语，不能据此宣布已经测完所有语言。把“摘要”细化为“某一时期的中文医疗摘要”，才暴露出取样与判分约束。

人类考试中心的路线则借助高考、资格考试等已知难度的题目。AGIEval 研究模型解答人类标准化考试的能力；MMLU 侧重跨学科知识。考试成绩容易复算，但选项排除、训练题记忆和真正开放式决策并不相同。下表把两条路线放在可核验的输出上，而不是按基准名称堆榜单。

| 路线     | 固定什么                     | 观察什么                       | 不能推出什么                   |
| -------- | ---------------------------- | ------------------------------ | ------------------------------ |
| 任务场景 | 输入域、语言、答案或参考材料 | 每个切片的正确率、稳健性与风险 | 某场景高分不代表所有场景领先   |
| 人类考试 | 试卷、题型、答案抽取方式     | 解题正确性与学科差异           | 通过考试不等于具备完整人类能力 |
| 开放生成 | 用户目标、事实依据与评分细则 | 正确、完整、连贯及可执行性     | 流利长文不等于事实可靠         |

### 8.2.2 伦理与安全

有帮助、诚实、无害（3H）需要分别判定。例如面对无法证实的医疗问题，承认不确定并建议寻求专业意见，可能比编造确定诊断更诚实、更安全；但对无害问题一概拒答也会损害帮助性。安全评估必须同时统计有害服从和无害误拒，避免靠“全部拒绝”拿到漂亮的单一安全分数。

原章列举的安全数据覆盖八类风险：侮辱谩骂、不公平与歧视、违法活动、敏感话题、身体伤害、心理健康、隐私与财产、伦理道德。攻击性指令还包含目标劫持、提示泄露、角色扮演、不安全指令主题、隐蔽注入和反向暴露六种形式。这里仅界定评测类别，不提供可用于伤害的提示。CrowS-Pairs 用成对语句比较刻板偏好，Winogender 通过替换性别等条件观察预测变化；成对测试应尽量保持除敏感属性以外的条件不变。

| 检查对象 | 要保留的证据                           | 不能混在一起的分母             |
| -------- | -------------------------------------- | ------------------------------ |
| 帮助性   | 是否解决用户的合法任务、是否误拒       | 无害请求数，而非全部风险请求   |
| 诚实性   | 事实依据、可验证引用、合理的不确定表达 | 可核查声明数，而非回答字数     |
| 无害性   | 风险类别、严重程度、攻击下的响应       | 每类有效攻击数，并另报无害误拒 |

红队评估让一个模型生成测试，目标模型回答，再由有害性分类器或人类审阅。原章比较零样本、从有效样本池少样本生成、SFT 和带 KL 约束的 RL 生成路线。红队生成器、被测模型、判定器职责不同：分类器误报会污染“攻击成功率”，只追求高攻击分又可能反复产生同一类题。应去重并人工抽查，分别报告攻击覆盖面、有效性和伤害判定，不把生成数量当发现数量。

### 8.2.3 垂直领域评估

领域评估先定义可观察的终点。知识推理可用 CSQA、StrategyQA 等检查答案与支持证据；符号推理可拼接单词末字母或跟踪硬币翻转，答案能精确验证。若示例只有两个词，测试延长到三个、四个词，改变的是步骤外推难度。数学任务中 GSM8K、SVAMP、MATH 的答案准确率与 LISA、miniF2F 等形式化证明任务的验证成功率也不是同一件事：写出似是而非的证明，不等于通过证明检查器。

交互环境需要区分计划的语言描述、动作合法性和最终完成情况。在 VirtualHome 一类环境，动作/对象标识符必须能被执行；可执行序列仍可能没达到目标。GITM 把任务拆解、规划和接口反馈接起来，API-Bank 检查工具使用。评估时应保存工具参数、返回结果、重试预算及终止状态；不能只根据最后一句“已完成”计成功。

| 领域终点       | 原章代表任务                          | 适宜判据与边界                                               |
| -------------- | ------------------------------------- | ------------------------------------------------------------ |
| 法律文本理解   | CUAD 条款抽取                         | 证据跨度的精确率/召回率；不是法律意见的充分性                |
| 法律决策辅助   | 判决预测、LeCaRD 类案检索             | 类别准确率或检索相关性；不等于依法裁判                       |
| 医学知识与问答 | MultiMedQA 的考试、论文和用户健康问题 | 客观题核答案；长回答另审事实和伤害，不能把考试分数当临床安全 |
| 环境与工具     | VirtualHome、GITM、API-Bank           | 动作合法、任务完成、调用正确分别记录                         |

## 8.3 大语言模型评估方法

选定场景后，必须把模型输出映射成可测对象。分类输出可以归入混淆矩阵，数值预测要计算误差，自由文本则可能既需要字符串指标也需要人工细则。这一层的关键是<Term def="一个比值以哪些对象计总量，例如所有样本、预测正例、实际正例或参考词元">指标分母</Term>：同样两个命中，除以候选词数与除以参考词数回答的是不同问题。先固定测量对象与抽样单位，再考虑均值和显著性。

### 8.3.1 评估指标

**分类。** 真正例 TP、假正例 FP、假反例 FN、真反例 TN 组成四格表。对正类检出，精确率 $P=TP/(TP+FP)$ 表示“报为正的有多少是真的”，召回率 $R=TP/(TP+FN)$ 表示“实际为正的找到了多少”。准确率为 $(TP+TN)/(TP+FP+FN+TN)$，$F_1=2PR/(P+R)$。分母为零时必须写明约定，不能默默丢弃该类。阈值移动会同时改变 FP 和 FN；ROC 以 FPR 与 TPR 画出阈值轨迹，AUC 概括排序能力，不等于部署阈值下的正类精确率。类别极不均衡时，还应检查 PR 曲线及少数类计数。

**回归。** 令 $e_i=\hat y_i-y_i$，以下量不能换个名字当同一分数。平方项更惩罚大偏差，百分比项更重视小真值，中位数更抗少量极端值。应报告单位、尺度与异常值处理，尤其不能把“MAPE 自动跳过零值”隐藏在实现里。

| 指标       | 计算                                            | 解释与边界                         |
| ---------- | ----------------------------------------------- | ---------------------------------- |
| MAE        | $\frac1N\sum_i \lvert e_i\rvert$                | 平均绝对偏差，保留原单位           |
| MSE / RMSE | $\frac1N\sum_i e_i^2$ 及其平方根                | MSE 单位平方；RMSE 回到原单位      |
| MAPE       | $\frac{100}{N}\sum_i \lvert e_i/y_i\rvert$      | $y_i=0$ 时未定义；接近零也会放大   |
| MSLE       | $\frac1N\sum_i[\log(1+\hat y_i)-\log(1+y_i)]^2$ | 常用非负目标；须检查对数定义域     |
| MedAE      | $\operatorname{median}_i \lvert e_i\rvert$      | 典型绝对误差，可能掩盖少数严重错误 |

**语言模型。** 对同一分词后的序列，交叉熵 $H=-\frac1N\sum_t\log_2 p(x_t\mid x_{<t})$，困惑度 $PPL=2^H$。平均每个词元预测概率越小，PPL 越高。比较时必须对齐测试语料、分词器、上下文窗口和损失掩码，否则“每个词元”的分母不同。PPL 评价对给定文本的概率建模，不直接度量指令遵循或事实正确性。

**文本生成。** [BLEU 原始论文](https://aclanthology.org/P02-1040/)用截断 n-gram 精确率的加权几何平均并施加长度惩罚：$BLEU=BP\exp(\sum_n w_n\log p_n)$。单参考长度为 $r$、候选长度为 $c>0$ 时，$BP=\min(1,\exp(1-r/c))$。截断要求一个词组最多按参考中允许的次数计命中；候选过短可能精确率很高，却受到长度惩罚。[ROUGE 原始论文](https://aclanthology.org/W04-1013/)的 ROUGE-N 召回以参考 n-gram 总数为分母，ROUGE-L 则利用最长公共子序列（LCS）衡量顺序相似性。需注明所用精确率、召回率或 F 值变体、分词与多参考聚合策略。

下面固定单个参考 `the cat sat on the mat`。先预测：候选 `the cat` 的截断一元精确率是否为 1？它覆盖了参考的多少？再改成重复句，观察第三个 `the` 为什么不再命中。图中只实现一元截断匹配和 ROUGE-1 召回，**不是完整 BLEU**。

字符串相似不等于语义或事实正确。例如替换否定词后仍可能共享许多词元。原章进一步按三个层面检查生成质量：语言层检查词汇、语法、篇章；语义层检查准确、连贯与风格；知识层检查知识正确性、丰富性与一致性。应把这些变成独立评分项并配锚点例子，而不是让“文风好”补偿“事实错”。

### 8.3.2 评估方法

人工评估先选评委：领域专家、众包人员与真实用户拥有不同背景。再决定绝对评分还是相对比较，是否提供参考答案、上下文和解释理由。Likert 等级量表必须说明每一档含义；平均意见分 MOS 是评分的算术均值，中位数或投票是另一种聚合。均值相同可能隐藏截然不同的意见分歧，所以还要保存每个评委的原始评分。

<Term def="多个评委对相同对象作出相同或相近判断的程度，不等同于判断本身正确">
  评委一致性
</Term>
可以先看直接一致率。Cohen 的 $\kappa=(P_a-P_e)/(1-P_e)$
扣除按边际比例计算的偶然一致：$P_a$ 是实际一致率，$P_e$
是随机独立给标签时的期望一致率。两位评委各给一半“是”、一半“否”，四题中只同意两题，则
$P_a=P_e=0.5$，$\kappa=0$。完全反着给标签时可以为负数，不应把 κ 的取值笼统限制为
0 到 1。多评委可考虑 Fleiss κ；序数评分还需选合适的一致性度量。

LLM 评委需要与人类一样明确细则、参考信息和输出解析规则，还必须检查其对位置、篇幅和自家风格的偏好。可以交换 A/B 顺序复评，把无法解析、平局和两者都差单列，再与人类逐项标注比较。模型既出题又判题而没有独立抽查，会形成闭环偏差，不会因为换了“裁判”称呼而消失。

比较两个模型的正确率，应在**同一批题**上保留四种配对结果。令 $b$ 为仅 A 对、$c$ 为仅 B 对；两者都对或都错不提供谁更强的方向信息。McNemar 大样本统计量为 $\chi^2=(b-c)^2/(b+c)$，连续性校正版使用 $(|b-c|-1)^2/(b+c)$；小不一致计数时，本章使用<Term def="在相同问题上对齐两模型结果，再根据不一致配对推断差异的方法">配对检验</Term>的精确二项形式。在零假设下，$X\sim Binomial(b+c,1/2)$，双侧 $p=\min(1,2\Pr[X\le\min(b,c)])$。不同题之间需要独立；关联题簇应换用按题簇设计的推断，不能假装独立。

**自行复算而非转录原文数值：** $b=1,c=7$ 时 $p=2(1+8)/256=0.0703125$，在事先选定的 0.05 水平下不能拒绝等表现假设。作为方法校核，$b=11,c=1$ 的精确双侧值是 0.00634765625，而 $b=25,c=15$ 的精确值约为 0.153860；不能把连续性校正近似值当作精确值，也不能把较大的 p 值解释为显著。p 值不是“零假设为真”的概率，更不表示实际收益大小。

## 8.4 大语言模型评估实践

实践应同时交付题目版本、提示模板、生成设置、答案抽取规则和逐题记录。基础模型的概率分数、指令模型的多维人工评分、公开投票的偏好排名，分别面向不同输出与用途；直接拼成一个总分会丢掉这些差异。下面按预训练与 SFT/RL 两种阶段讨论，并用可重复的小例子演示审计流程，而不声称复现真实 GPT-3、Arena 或 LLMEVAL 实验。

### 8.4.1 基础模型评估

基础模型可以用 PPL 衡量续写，也可以通过上下文学习解题。少样本提示里的示例不更新参数，但示例选择与答案格式依然会影响成绩。原章用 GPT-3 的历史实验说明语言建模与任务评测的区别：在同一套协议下报告零样本、单样本或少样本设置，不把其中最有利的值混成同一列。

<Term def="评测题目或近似内容进入模型训练、提示选择等开发过程，使测试不再独立">
  测试污染
</Term>
是基础模型评测的重要限制。[GPT-3
论文](https://arxiv.org/abs/2005.14165)及原章讨论以 13-gram
等重叠线索识别可能受污染样本，短样本还需按全长处理，并比较原集合与清理后的子集。这个历史策略不是当前所有模型通用的检测标准：找不到字面重叠不能排除改写后的泄漏，清理后分数下降也可能来自题目难度变化，不能单独证明模型在“背题”。

| 评测设置       | 原章关注的设计                                          | 使用限制                                                                     |

| MMLU           | 57 个学科；每学科开发示例用于少样本提示，验证与测试分工 | 开发集示例不是最终测试；统一抽取选项                                         |
| C-Eval         | 52 个学科、4 个层次，另设困难子集                       | [原始论文](https://arxiv.org/abs/2305.08322)的中文知识范围不等于所有中文能力 |

### 8.4.2 SFT/RL模型评估

SFT/RL 模型通常输出较长的指令回答。盲测双模型可以减少品牌影响，Arena 的历史形式是在展示匿名回答后收集偏好，再揭示模型；Elo 一类评分从成对结果更新相对排名。偏好并不等于事实正确或安全。原章对其评测设置观察到排名受噪声与顺序影响，应理解为需要审计的实验结果，而非“所有 Elo 在所有条件下必然失效”的定理。

原章 LLMEVAL1 使用 17 类、453 个问题，考察正确、流畅、信息、逻辑、无害等项，比较专家逐项评分、众包盲测、公众比较和 GPT-4 评委。成对结果包括 A 好、B 好、都好、都差；即使采用胜者 1 分、平局各 0.5 分的历史聚合，也要保留“都差”，不能把平局解释成合格。LLMEVAL2 则覆盖 12 个学科、480 题，区分客观与主观题；其主观量表把准确性满分设为 5 分、信息/流畅/逻辑各 3 分。这是特定评测的细则，不是通用权重。

| 方法               | 适合快速发现                 | 必须补充的审计                 |
| ------------------ | ---------------------------- | ------------------------------ |
| 专家逐项评分       | 事实缺陷、专业风险、错误类型 | 标注培训、锚点例子与一致性     |
| 众包/公众成对偏好  | 使用者感受与风格偏好         | 每人评分数、长度偏好、样本来源 |
| LLM 单项或成对评分 | 大批量回归中的明显变化       | 顺序交换、解析失败、人类复核   |
| 相对排名           | 特定题集/人群的比较          | 配对表、样本量、噪声与不确定性 |

### 可独立执行的算术模拟

下列完整 Python 仅用标准库，复制为 `evaluation.py` 后运行 `python3 evaluation.py`。它重算三个图的核心数字，还演示混淆矩阵、κ 和 MAPE 的零值失败与恢复。长代码块为完整可执行实验保留，不依赖网络、模型 API 或随机采样。正确行为不是“总能给出一个数”，而是在输入不满足指标定义时明确报错。

```python
from collections import Counter
from math import comb, isclose, log2


def overlap(reference, candidate, wrong=False):
    matched = sum((Counter(reference) & Counter(candidate)).values())
    denominator = len(candidate) if wrong else len(reference)
    return matched / len(candidate), matched / denominator


def mixture(w):
    return 0.9 * (1 - w) + 0.3 * w, 0.8 * (1 - w) + 0.7 * w


def exact_p(b, c):
    n = b + c
    return min(1.0, 2 * sum(comb(n, k) for k in range(min(b, c) + 1)) / 2**n)


def paired(rows):
    if len({r[0] for r in rows}) != len(rows):
        raise ValueError("同题复制不是独立证据")
    b = sum(a and not b for _, a, b, _ in rows)
    c = sum(b and not a for _, a, b, _ in rows)
    scores = tuple(sum(r[column] for r in rows) / len(rows) for column in (1, 2))
    return scores, exact_p(b, c)


def mape(actual, predicted):
    if not actual or len(actual) != len(predicted):
        raise ValueError("需要等长非空数据")
    if any(y == 0 for y in actual):
        raise ValueError("MAPE 在真值为零时未定义")
    return 100 * sum(abs((p - y) / y) for y, p in zip(actual, predicted)) / len(actual)


ref = "the cat sat on the mat".split()
assert overlap(ref, "the cat".split()) == (1, 1 / 3)
assert overlap(ref, "the the the cat".split()) == (3 / 4, 1 / 2)
assert overlap(ref, "the cat".split(), wrong=True) == (1, 1)
print("denominator: fault recall=1; recovery recall=1/3")
for w, expected in [(0.1, (0.84, 0.79)), (0.5, (0.6, 0.75)), (0.8, (0.42, 0.72))]:
    assert all(isclose(a, b) for a, b in zip(mixture(w), expected))
    print("mixture", w, tuple(round(s, 2) for s in mixture(w)))

# Each row is (stable question ID, A correct, B correct, overlapping).
clean = [(f"both-{i}", True, True, False) for i in range(8)]
clean += [("a-only", True, False, False)]
clean += [(f"b-only-{i}", False, True, False) for i in range(7)]
clean += [(f"neither-{i}", False, False, False) for i in range(4)]
all_rows = clean + [(f"leak-{i}", True, False, True) for i in range(8)]
all_scores, _ = paired(all_rows)
clean_scores, p = paired([r for r in all_rows if not r[3]])
assert all_scores[0] > all_scores[1] and clean_scores == (0.45, 0.75)
assert isclose(p, 0.0703125) and p > 0.05
print("filter", all_scores, "->", clean_scores, "exact p", p)

# A naive counter would report a smaller p from duplicate questions.
naive = exact_p(5, 35)
assert naive < 0.05
print("INVALID pseudo-replication p", naive)
try:
    paired(clean * 5)
    raise AssertionError("duplicate guard failed")
except ValueError as error:
    print("expected failure:", error)
restored = list({r[0]: r for r in clean * 5}.values())
assert paired(restored) == paired(clean)
print("recovery: unique questions", len(restored))
assert isclose(exact_p(11, 1), 0.00634765625)
assert isclose(exact_p(25, 15), 0.1538599441628321)

TP, FP, FN, TN = 3, 1, 2, 4
precision, recall = TP / (TP + FP), TP / (TP + FN)
assert isclose((TP + TN) / 10, 0.7)
assert isclose(2 * precision * recall / (precision + recall), 2 / 3)
pa, pe = 0.5, 0.5
assert (pa - pe) / (1 - pe) == 0  # half agreement is not always good
probabilities = [0.5, 0.25]
entropy = -sum(log2(x) for x in probabilities) / len(probabilities)
assert isclose(2**entropy, 8**0.5)
try:
    mape([0, 10], [1, 12])
    raise AssertionError("zero guard failed")
except ValueError as error:
    print("expected failure:", error)
mae = sum(abs(p - y) for y, p in zip([0, 10], [1, 12])) / 2
assert mae == 1.5  # use and label MAE instead of hiding zero targets
assert isclose(mape([10, 20], [12, 18]), 15)
print("recovery: explicitly choose MAE=", mae)
print("ALL ASSERTIONS PASSED; teaching arithmetic only")
```

预期输出包括三组部署混合值、过滤前后的排名反转、干净子集的 `exact p 0.0703125`、两次 `expected failure` 和最终通过提示。恢复路径分别去掉重复题 ID、明确改用 MAE；没有把异常值悄悄改成零，也没有重新编号重复题来绕过独立性检查。真实评测还要处理题簇依赖、多次比较和采样不确定性，本脚本不提供这些额外保证。

## 8.5 实践思考

原章结语延续到实体页 274，重点不是再造一张榜单，而是说明评委与聚合方式会扭曲它：众包评委可能偏爱长回答，公众评委每人只评少量题时一致性难以保证，噪声可能改变相对排序。GPT-4 评委也有位置和长度偏差，并非所有问题上都与人类充分一致。[MT-Bench / Chatbot Arena 研究](https://arxiv.org/abs/2306.05685)进一步讨论 LLM 裁判的局限。对高风险领域应优先使用专家细则和逐项证据；自动评分适合快速趋势检查，不宜独立充当上线安全证明。

一份可复查报告应让读者重建三个分母：**有哪些题、每个指标计什么、推断以什么作为独立单位**。报告分片结果及目标权重，保存污染筛选规则与筛前/筛后样本数，列出拒答、无效输出、解析失败和评委分歧。配对比较同时给出效应量与不确定性，不能只用一颗显著性星号替代实际用途判断。发现数据依赖时，应回到采样设计，而不是再复制几遍记录。

### 常见误区

<Callout type="trap" title="短答案精确率高，所以回答完整">
  **现象 →** `the cat` 的截断精确率为 1。**原因 →**
  分母只有两个候选词，没有计算参考中遗漏的四个词。**修法 →** 对照 ROUGE-1 召回
  1/3；完整 BLEU 还需长度惩罚，不拿一元精确率冒名。
</Callout>

<Callout type="trap" title="短题榜第一，适合长步骤部署">
  **现象 →** A 在 ID 上 90%，就被选作 OOD 为主的服务。**原因 →**
  使用了错误的目标人群与分母。**修法 →** 先报 A/B 的 ID、OOD
  分片，再按实际流量权重比较，不漏报困难分片。
</Callout>

<Callout type="trap" title="复制后显著，或 p 大说明两模型相同">
  **现象 →** 同题复制让 p 下降，或 p 大就宣称等价。**原因 →**
  伪重复破坏独立性，未拒绝也不是接受等价。**修法 →** 保留唯一题
  ID，报告有效题数、效应大小和正确检验；等价性需要预先定义容差与专门设计。
</Callout>

### 小结

- 任务、风险与人群先于指标和排名。
- 分母和评分规则决定数字的含义。
- 污染与伪重复不能兑换泛化证据。

**问题 1：模型选型与分布**

A、B 的四个分片成绩不变，求部署 OOD 比例为多少时两者打平。若线上 80% 是 OOD，应优先选谁，还缺什么证据？

</Answer>

**问题 2：改动模拟的分母**

把候选改成 `the the the cat`，不用运行先算命中、精确率和召回率。再修改 Python 的候选验证；如果错误地允许每个 `the` 无限匹配，会出现什么读数？

<Answer>

参考里 `the` 只有两次，故第三次不命中；加上 `cat` 共命中 3。截断精确率为 3/4，召回率为 3/6=1/2。若无限重复匹配，会误计为 4，读出精确率 1、召回率 2/3。修法保留 Counter 多重集交集，而非只检查候选词是否存在于参考词集合。

</Answer>

**问题 3：统计与评委审计**

干净子集 A 为 45%、B 为 75%，精确 p=0.0703125。能否说两者一样好？若 LLM 评委总偏好较长回答，应怎样改评测，而不是只换个模型名？

<Answer>

不能。30 个百分点是该样本的效应，p 大只表示当前独立题数不足以在 0.05 水平拒绝零假设，不构成等价性证明。增加独立、代表性的新题而非复制旧题；固定细则、交换候选顺序、对长度分层并请专家逐项复核，保存都差、平局和解析失败，核对人机一致性。长度匹配是诊断偏差的一种控制，不保证清除所有偏差。

</Answer>
