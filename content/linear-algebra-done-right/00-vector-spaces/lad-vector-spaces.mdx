## 直觉引入

向量空间是线性代数的地基。Axler 不把向量限定为“一列数”，而是抽象出任何满足加法与标量乘法公理的对象——多项式、函数、矩阵都可以是向量。

这样抽象的好处是：只要结构满足公理，所有定理都通用。基给出“坐标系”，维数给出“自由度”，它们不依赖具体的数值表示。

换句话说，向量空间是一种“形状无关”的结构：只要你承认这八条公理，无论是数组、多项式还是函数，都共享同一套关于基、维数、子空间的定理。这种抽象不是故弄玄虚，而是让一套工具同时适用于多个领域的代价最小化策略。

## 概念讲解

<Term def="带加法与标量乘法且满足八条公理的集合">向量空间</Term>的核心是八条公理：加法交换/结合、零元、负元，以及标量乘的分配与结合（$1v=v$）。验证一个集合是向量空间，就是逐条核对公理。

<Term def="本身是向量空间且包含在原空间中的子集">子空间</Term>是闭于加法与标量乘的子集，必含零元。子空间的交仍是子空间，但并一般不是。

<Term def="所有线性组合构成的集合">张成</Term>$\mathrm{span}(v_1,\ldots,v_n)$ 是包含这些向量的最小子空间。<Term def="只有平凡组合才能得到零元的向量组">线性无关</Term>意味着没有冗余：$a_1v_1+\cdots+a_nv_n=0$ 必推出所有 $a_i=0$。

<Term def="既线性无关又张成全空间的向量组">基</Term>给出坐标系。Axler 证明：有限维空间中，任意两个基的长度相同，这个长度就是<Term def="基的长度，与基的选择无关">维数</Term> $\dim V$。关键引理：线性无关组长度 $\leq$ 张成组长度 $\leq \dim V$。

### 性质速查
- 子空间的交是子空间，并一般不是（需取张成才封闭）。
- 线性无关组可扩充为基；张成组可缩减为基。
- $\dim U + \dim W = \dim(U+W) + \dim(U\cap W)$（维数公式）。
- $\dim(U_1+\cdots+U_m)\leq \sum\dim U_i$，等号当且仅当直和。
- 多项式空间 $\mathcal P(\mathbb F)$ 是无限维的，本书主要讨论有限维。

### 典型例子
$\mathbb R^3$ 中，$U=\mathrm{span}((1,0,0),(0,1,0))$（$xy$ 平面）与 $W=\mathrm{span}((0,1,0),(0,0,1))$（$yz$ 平面）。$\dim U=\dim W=2$，$\dim(U\cap W)=1$（交为 $y$ 轴），$\dim(U+W)=3$（全空间），恰好 $2+2=3+1$。

### 深入一点
把向量从“一列数”解放出来后，许多结论变得自然：多项式求导是 $\mathcal P_n\to\mathcal P_{n-1}$ 的线性映射，积分是从常函数空间出发的线性映射。一旦认出结构，不同领域的问题就能用同一套定理处理——这就是抽象的力量。

### 公式卡
$$\mathrm{span}(v_1,\ldots,v_n) = \{\,a_1v_1+\cdots+a_nv_n : a_k\in\mathbb F\,\}$$
$$\text{线性无关} \iff \left(\sum_k a_kv_k=0 \Rightarrow a_1=\cdots=a_n=0\right)$$
$$\dim U + \dim W = \dim(U+W) + \dim(U\cap W)$$

## 代码对照

用 NumPy 检验线性无关并求子空间维数：

```python
import numpy as np

V = np.array([[1, 2, 1], [0, 1, 1], [1, 0, 1]], dtype=float).T  # 三个 R^3 向量
rank = np.linalg.matrix_rank(V)
print('主元数 =', rank, '→ 线性无关' if rank == V.shape[1] else '→ 线性相关')

# 过原点平面 x+y+z=0 的一个基
basis = np.array([[1, -1, 0], [1, 0, -1]], dtype=float)
print('平面维数 =', np.linalg.matrix_rank(basis))  # 应为 2

# 多项式空间 P_2 的加法与标量乘只是系数运算
def padd(a, b): return [x+y for x, y in zip(a, b)]
def pscale(c, a): return [c*x for x in a]
print(padd([1,2,3], [0,1,-1]))   # [1,3,2] 对应 x^2+3x+2

# 维数公式数值验证：dim(U)+dim(W) = dim(U+W)+dim(U∩W)
U = np.array([[1,0,0],[0,1,0]], dtype=float)
W = np.array([[0,1,0],[0,0,1]], dtype=float)
UW = np.vstack([U, W])
inter = np.vstack([U, W])  # 交空间取公共方向 (0,1,0)
print('dim U + dim W =', np.linalg.matrix_rank(U) + np.linalg.matrix_rank(W))
print('dim(U+W) + dim(U∩W) =', np.linalg.matrix_rank(UW) + 1)

```

`matrix_rank` 给出主元个数即极大无关组长度。三个 $\mathbb R^3$ 向量秩为 3 说明线性无关；过原点平面的基秩为 2，印证 $\dim=2$。维数公式段数值验证 $2+2=3+1$，把抽象等式落成可算的秩。

## 常见误区

<Callout type="trap">
**现象 →** 认为“向量就是一列数”。
**原因 →** 只接触过 R^n 的具体例子。
**修法 →** 记住公理定义：多项式、连续函数、矩阵都能构成向量空间，只要满足八条公理。基与维数对它们同样适用。
</Callout>

<Callout type="trap">
**现象 →** 把子空间和子集混为一谈。
**原因 →** 忽略了“封闭性”要求。
**修法 →** 子空间必须过原点（含零元）且对加法、标量乘封闭。不过原点的平面不是子空间，尽管它“看起来像”。
</Callout>

<Exercises>
**问题**：证明：有限维向量空间中，任意线性无关组的长度不超过任意张成组的长度。

<Answer>
设线性无关组 $v_1,\ldots,v_m$，张成组 $w_1,\ldots,w_n$。把每个 $v_i$ 用 $w_j$ 表出，逐个把 $v_i$ 加入 $w$ 组并剔除一个 $w_j$（因 $w$ 张成，加入 $v_1$ 后必线性相关，可剔 $w$）。若 $m>n$，则剔除所有 $w$ 后仍有 $v$ 剩余，但剩余 $v$ 组张成空（矛盾，因其线性无关）。故 $m\leq n$。
</Answer>

**问题**：为什么任意两个基的长度相同？

<Answer>
设基 $A$（长度 $p$）既线性无关又张成，基 $B$（长度 $q$）同样。把 $A$ 视为线性无关组、$B$ 视为张成组，由引理得 $p\leq q$；互换角色得 $q\leq p$。故 $p=q$，这个公共长度即维数。
</Answer>
</Exercises>

<GlossaryItem term="子空间">闭于加法与标量乘且含零元的子集，本身也是向量空间。</GlossaryItem>
<GlossaryItem term="线性无关">只有平凡组合为零元的向量组，意味着无冗余；长度受维数上界约束。</GlossaryItem>
<GlossaryItem term="基与维数">基=线性无关且张成全空间的向量组；维数=基的长度，与基的选择无关。</GlossaryItem>
