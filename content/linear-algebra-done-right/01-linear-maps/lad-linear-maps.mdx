## 直觉引入

线性映射是连接两个向量空间的桥梁。它保持加法与标量乘，因此完全由它在基上的取值决定——给出基向量的像，整个映射就确定了。

核告诉你“哪些向量被压成零”，像告诉你“能到达哪里”。秩-零度定理把这两个维数拼回出发维数，是全书最常用的等式之一。

换句话说，线性映射是把一个空间的“线性结构”搬到另一个空间的过程。它不能弯曲、不能折叠出非线性的褶皱——正是这种克制，让我们能用维数这一个量来精确度量它丢失了多少、传递了多少。

## 概念讲解

<Term def="保持加法与标量乘的映射">线性映射</Term> $T:V\to W$ 满足 $T(u+v)=Tu+Tv$ 与 $T(\lambda v)=\lambda Tv$。所有 $V\to W$ 的线性映射构成空间 $\mathcal L(V,W)$，其维数为 $(\dim V)(\dim W)$。

<Term def="被映为零的向量集合">核</Term> $\mathrm{null}\,T=\{v:Tv=0\}$ 是 $V$ 的子空间，衡量映射塌缩了多少。<Term def="所有像构成的集合">像</Term> $\mathrm{range}\,T=\{Tv:v\in V\}$ 是 $W$ 的子空间，衡量映射到达了多远。

判据非常干净：$T$ 单射当且仅当 $\mathrm{null}\,T=\{0\}$；$T$ 满射当且仅当 $\mathrm{range}\,T=W$。<Term def="塌缩维数加到达维数等于出发维数">秩-零度定理</Term>断言：$$\dim V = \dim\mathrm{null}\,T + \dim\mathrm{range}\,T$$即塌缩掉的维数加上到达的维数，正好等于出发的维数。

### 性质速查
- $\mathcal L(V,W)$ 自身是向量空间，$\dim\mathcal L(V,W)=(\dim V)(\dim W)$。
- $T$ 单射 $\Leftrightarrow$ $\mathrm{null}\,T=\{0\}$；$T$ 满射 $\Leftrightarrow$ $\mathrm{range}\,T=W$。
- 有限维等维空间中，单射、满射、双射三者等价。
- $\mathrm{rank}\,T\leq\min(\dim V,\dim W)$。
- 映射复合保持线性性：$S,T$ 线性则 $ST$ 线性。

### 典型例子
微分算子 $D:\mathcal P_4\to\mathcal P_3$，$Dp=p'$。$\mathrm{null}\,D$ 为常函数（维数 1），$\mathrm{range}\,D=\mathcal P_3$（维数 3），而 $\dim\mathcal P_4=4$，恰好 $4=1+3$。微分把次数降 1，核是常数——秩-零度在这里一目了然。

### 深入一点
秩-零度定理的几何是“维数守恒”：信息要么保留在像里，要么丢失在核里，两者不重不漏。这条等式之所以反复出现，是因为它把映射的两个侧面（塌缩与到达）压缩进一个不变量，成为后续特征值、对角化论证的脚手架。

### 公式卡
$$\mathrm{null}\,T = \{v\in V : Tv=0\},\qquad \mathrm{range}\,T = \{Tv : v\in V\}$$
$$T\text{ 单射} \iff \mathrm{null}\,T=\{0\}$$
$$\dim V = \dim\mathrm{null}\,T + \dim\mathrm{range}\,T$$

<Stepper>
<Step title="第一步：求核">
解方程 $Tv=0$。核是齐次方程的解空间，其维数 = 自由变量个数。核越大，映射塌缩越严重。
</Step>
<Step title="第二步：求像">
把基向量的像排好，像 = 这些像的张成。像的维数（秩）= 像向量组的极大无关组长度。
</Step>
<Step title="第三步：套秩-零度">
验证 $\dim V = \dim\mathrm{null}\,T + \dim\mathrm{range}\,T$。满射时 $\mathrm{range}=W$，故 $\dim\mathrm{null}=\dim V-\dim W$。
</Step>
</Stepper>

## 代码对照

用 NumPy 求核、像并验证秩-零度定理：

```python
import numpy as np

A = np.array([[1, 2, -1, 0], [0, 1, 1, 2]], dtype=float)  # T: R^4 -> R^2
m, n = A.shape
rank = np.linalg.matrix_rank(A)         # 像的维数
nullity = n - rank                       # 核的维数
print('dim V =', n)
print('null T + rank T =', nullity + rank)

# 求核的一组基（零空间）
_, _, Vh = np.linalg.svd(A)
null_basis = Vh[rank:].conj().T         # 后 n-rank 个右奇异向量
print('核的基维数:', null_basis.shape[1])
print('检验 A @ null_basis ≈ 0:', np.allclose(A @ null_basis, 0))

# 构造一个 R^4 -> R^2 的线性映射并完整求核、像
A = np.array([[1, 2, -1, 0], [0, 1, 1, 2]], dtype=float)
r = np.linalg.matrix_rank(A)
print('rank(像维数) =', r, '| nullity(核维数) =', A.shape[1] - r)
# 像的基 = A 的列的极大无关组（行变换取主元列）
_, piv = np.linalg.qr(A.T)
print('像由', r, '个独立方向张成，核由', A.shape[1]-r, '个自由方向构成')

```

矩阵 $A$ 的秩为 2 即像的维数，零度为 $4-2=2$。SVD 的右奇异向量中后 $n-r$ 个正交张成核空间，验证 $A$ 乘它们为零——这把抽象的“核”落成了可算的奇异向量。

## 常见误区

<Callout type="trap">
**现象 →** 混淆“单射”和“满射”的判据。
**原因 →** 没把核与像分别对应起来。
**修法 →** 记住：单射看核（null T={0}），满射看像（range T=W）。核小则不塌缩→单射，像大则全覆盖→满射。
</Callout>

<Callout type="trap">
**现象 →** 觉得秩-零度定理只是个公式，不理解为何成立。
**原因 →** 没看到“维数守恒”的几何。
**修法 →** 把核的一组基扩充成 V 的基，映射作用后核基变零、其余基映成像的基，所以 dim V = nullity + rank。
</Callout>

<Exercises>
**问题**：R^5→R^3 的满射，核至少几维？

<Answer>
满射意味着 $\mathrm{range}\,T=W$，$\dim\mathrm{range}=3$。由秩-零度 $\dim\mathrm{null}=\dim V-\dim\mathrm{range}=5-3=2$。核恰为 2 维（满射时无多余约束）。
</Answer>

**问题**：证明：T 单射当且仅当 null T = {0}。

<Answer>
若 null T={0} 且 Tu=Tv，则 T(u-v)=0，故 u-v=0，u=v，即单射。反之若 T 单射且 Tv=0=T0，则 v=0，故 null T={0}。双向得证。
</Answer>
</Exercises>
