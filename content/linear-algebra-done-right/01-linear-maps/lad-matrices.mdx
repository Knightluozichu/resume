## 直觉引入

抽象的线性映射看不见摸不着，选定基后它就变成了矩阵——一张“坐标照片”。换一组基，照片就变了，但拍的是同一个映射。

理解这点后，矩阵的很多性质（特征值、秩、迹、行列式）就不再依赖基的选择：它们是映射本身的属性，而非某张照片的偶然。

换言之，矩阵不是映射本身，而是映射在某个坐标系下的“投影”。换一个坐标系，矩阵就变一张脸，但映射的内核——特征值、秩、迹——纹丝不动。理解了这一点，你就不会再被具体的数字表象迷惑。

## 概念讲解

给定 $V$ 的基 $v_1,\ldots,v_n$ 和 $W$ 的基 $w_1,\ldots,w_m$，<Term def="线性映射在给定基下的坐标矩阵">矩阵表示</Term> $\mathcal M(T)$ 的第 $j$ 列就是 $Tv_j$ 在 $W$ 基下的坐标。矩阵乘法对应映射复合：$\mathcal M(ST)=\mathcal M(S)\mathcal M(T)$。

换基时，设新基由可逆矩阵 $P$ 给出，则同一映射的新矩阵为$$\mathcal M'(T) = P^{-1}\mathcal M(T)P$$<Term def="形如 P⁻¹AP 的矩阵关系">相似</Term>刻画的就是“同一映射在不同基下的矩阵”。相似矩阵有相同的特征值、迹、行列式、秩——这些都是映射的不变量。

矩阵可逆当且仅当对应映射可逆（双射），而这又等价于方阵的列为线性无关（$\dim\mathrm{null}=0$）。秩在矩阵层面表现为列秩=行秩。

### 性质速查
- $\mathcal M(ST)=\mathcal M(S)\mathcal M(T)$，矩阵乘法源于映射复合。
- $\mathcal M(T)$ 可逆 $\Leftrightarrow$ $T$ 可逆 $\Leftrightarrow$ 列线性无关。
- 相似保持：特征值、迹、行列式、秩、特征多项式。
- 列秩 $=$ 行秩（秩定理），故“行独立”与“列独立”的维数相同。
- 对角矩阵对应“在各基方向独立缩放”的映射。

### 典型例子
$A=\begin{pmatrix}4&1\\2&3\end{pmatrix}$ 在标准基下特征值为 $2,5$。换基矩阵 $P=\begin{pmatrix}1&1\\0&1\end{pmatrix}$ 给出相似矩阵 $A_2=P^{-1}AP$。两者特征值都是 $2,5$、迹都是 7、行列式都是 10——相似只换“照片”不换“人”。

### 深入一点
矩阵是映射的坐标表示，这意味着同一映射在不同基下可以有完全不同的数值面貌。理解了相似，你就不会再把“矩阵”等同于“映射”：矩阵是可替换的外衣，映射才是本体。这也解释了为何不变量如此重要——它们是剥去外衣后剩下的本质。

### 公式卡
$$\mathcal M(ST) = \mathcal M(S)\,\mathcal M(T) \quad\text{（复合对应乘积）}$$
$$\mathcal M'(T) = P^{-1}\,\mathcal M(T)\,P \quad\text{（基变更 / 相似）}$$
$$\text{列秩} = \text{行秩} = \mathrm{rank}\,T$$

对每个基向量 $v_j$ 算 $Tv_j$，再把它拆成 $W$ 基的线性组合，系数填入第 $j$ 列。这一步把抽象映射落成可算的数表。
</Step>
<Step title="第二步：换基">
新基与旧基由可逆矩阵 $P$ 联系。新坐标 = $P^{-1}$×旧坐标，作用一次再换回，得到 $M'=P^{-1}MP$。这就是相似。
</Step>
<Step title="第三步：认不变量">
相似变换下不变的性质就是映射的本质：特征值、迹、行列式、秩、特征多项式都相似不变。换基只换“照片”不换“人”。
</Step>

## 代码对照

验证相似矩阵特征值相同：

```python
import numpy as np

A = np.array([[4, 1], [2, 3]], dtype=float)
P = np.array([[1, 1], [0, 1]], dtype=float)      # 换基矩阵
A2 = np.linalg.inv(P) @ A @ P                     # 相似矩阵
print('A 特征值:', np.sort(np.linalg.eigvals(A)).real)
print('A2 特征值:', np.sort(np.linalg.eigvals(A2)).real)
print('迹相同:', np.isclose(np.trace(A), np.trace(A2)))
print('行列式相同:', np.isclose(np.linalg.det(A), np.linalg.det(A2)))
print('秩相同:', np.linalg.matrix_rank(A) == np.linalg.matrix_rank(A2))

# 用特征向量作为换基矩阵，相似后应得到对角矩阵
A = np.array([[4, 1], [2, 3]], dtype=float)
vals, P = np.linalg.eig(A)
D = np.linalg.inv(P) @ A @ P
print('相似后矩阵（应近似对角）:')
print(np.round(D, 6))
print('对角元 = 特征值:', np.round(np.diag(D), 6))

```

相似变换后特征值、迹、行列式、秩全部不变。用特征向量作换基矩阵，相似后矩阵近似对角——这预示了可对角化算子总能被相似变换成对角形，正是特征值理论的落点。

## 常见误区

<Callout type="trap">
**现象 →** 以为相似矩阵是“差不多的两个矩阵”。
**原因 →** 把相似当成数值近似。
**修法 →** 相似=同一映射在不同基下的表示。它们是“同一个人的不同角度照片”，特征值等本质属性完全相同。
</Callout>

<Callout type="trap">
**现象 →** 搞反换基公式，写成 $PMP^{-1}$。
**原因 →** 没分清“新基用旧基表”还是“旧基用新基表”。
**修法 →** 约定 $P$ 是“新基在旧基下的坐标”，则坐标变换为 $[v]_{旧}=P[v]_{新}$，代入得 $M'=P^{-1}MP$。记住方向：先 $P$ 进入新坐标，作用，再 $P^{-1}$ 回旧坐标。
</Callout>

<Exercises>
**问题**：为什么相似矩阵有相同的特征值？

<Answer>
若 $B=P^{-1}AP$，则 $B-\lambda I=P^{-1}(A-\lambda I)P$，两者只差可逆因子，可逆性相同。故 $\det(B-\lambda I)=\det(A-\lambda I)$，特征多项式相同，特征值相同。
</Answer>

**问题**：把映射 T(x,y)=(x+y, 2y) 在标准基下的矩阵，换到新基 &#123;(1,1),(1,-1)&#125; 下。

<Answer>
标准基下 $A=\begin{pmatrix}1&1\\0&2\end{pmatrix}$。新基在旧基下 $P=\begin{pmatrix}1&1\\1&-1\end{pmatrix}$。$M'=P^{-1}AP$，算得 $P^{-1}=\frac12\begin{pmatrix}1&1\\1&-1\end{pmatrix}$，$M'=\begin{pmatrix}2&0\\0&1\end{pmatrix}$（对角化，因新基恰是特征向量）。
</Answer>
</Exercises>
