### 核心定义

1. **张成**：一个向量列表所有线性组合构成的集合，是包含该列表的最小子空间。
2. **线性无关**：只有全零系数才能给出零向量的线性组合，意味着表示没有冗余。
3. **基**：既线性无关又张成空间的向量列表，使每个向量拥有唯一坐标。
4. **维数**：有限维空间任意基的长度相同，这个长度是空间的不变量。
5. **基扩充**：线性无关列表可扩充为基，张成列表可删减为基。

## 先声明假设

证明前先写标量域、定义域、陪域、维数以及是否给定内积。许多错误并非推导失误，而是把实数域结论搬到复数域、把有限维结论搬到无限维，或把一般算子当作正规算子。

$$
\mathcal A=(\mathbb F, V, W, \dim V, \text{inner product if any})
$$

张成与线性无关必须放在同一组假设下比较。定义中的“任意”“存在”“唯一”和“非零”都影响证明方向，不能在转述时省略。

$$
\text{assumptions}\Longrightarrow\text{lemma}\Longrightarrow\text{invariant}\Longrightarrow\text{claim}
$$

```python
def pivot_columns(rows):
    a=[list(map(float,row)) for row in rows]; pivots=[]; r=0
    for c in range(len(a[0])):
        p=next((i for i in range(r,len(a)) if abs(a[i][c])>1e-9),None)
        if p is None: continue
        a[r],a[p]=a[p],a[r]; pivots.append(c); r+=1
    return pivots

assert pivot_columns([[1,0,1],[0,1,1]]) == [0,1]
```

## 结构图与证明骨架

**张成**：一个向量列表所有线性组合构成的集合，是包含该列表的最小子空间。

**线性无关**：只有全零系数才能给出零向量的线性组合，意味着表示没有冗余。

**基**：既线性无关又张成空间的向量列表，使每个向量拥有唯一坐标。

先从定义构造对象，再找到保持不变的子空间、维数或多项式，最后把局部结论拼成全空间结论。若构造依赖选择基，要继续说明最终结论为何与基无关。


## 反例与边界

**维数**：有限维空间任意基的长度相同，这个长度是空间的不变量。

**基扩充**：线性无关列表可扩充为基，张成列表可删减为基。

边界集至少覆盖零空间、零映射、重复特征值、线性相关列表、实数与复数域切换、缺少内积和接近秩亏。抽象证明用反例检查必要性，数值实现用残差和条件尺度检查稳定性。

r=\|\text{left side}-\text{right side}\|,\qquad r\le\tau_{abs}+\tau_{rel}\|\text{reference}\|
