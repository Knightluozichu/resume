## 直觉引入

线性映射在一个空间里到处“搅动”，但总有些方向它只做伸缩——这些方向就是特征向量，伸缩倍数就是特征值。找到它们，等于把复杂的映射拆成最简单的“缩放”零件。

Axler 用不变子空间来讲特征值：在一维不变子空间里，映射只能缩放，于是特征值自然浮现。这套讲法几何清晰，不依赖行列式。

换句话说，特征值是映射“自我揭示”的时刻：在绝大多数方向上它复杂地搅动，但在某些特殊方向上它只做最朴素的缩放。找出这些方向，就等于把一个复杂映射分解成一堆简单缩放的叠加——这正是“对角化”的全部魅力。

## 概念讲解

<Term def="被映射映回自身的子空间">不变子空间</Term> $U$ 满足 $T(U)\subseteq U$。一维不变子空间给出<Term def="满足 Tv=λv 的非零向量 v">特征向量</Term>：$Tv=\lambda v$（$v\neq 0$），$\lambda$ 称为<Term def="使 T-λI 不可逆的标量 λ">特征值</Term>。

等价定义：$\lambda$ 是特征值当且仅当 $T-\lambda I$ 不可逆（即 $\mathrm{null}(T-\lambda I)\neq\{0\}$）。<Term def="det(T-zI) 的多项式">特征多项式</Term> $p(z)=\det(T-zI)$ 的根就是特征值。

<Term def="特征值作为根的重数">代数重数</Term>是 $\lambda$ 作为 $p$ 根的重数；<Term def="特征空间的维数">几何重数</Term>是特征空间 $\mathrm{null}(T-\lambda I)$ 的维数，且几何重数 $\leq$ 代数重数。

<Term def="特征向量能凑成基的算子">可对角化</Term>条件：各特征空间的维数之和 $=\dim V$。复数域上由代数基本定理，每个算子的特征多项式都有根，故必有特征值；实数域则未必（如 90° 旋转）。

### 性质速查
- 不同特征值对应的特征向量线性无关。
- 几何重数 $\leq$ 代数重数；严格小于时算子不可对角化。
- 可对角化 $\Leftrightarrow$ 各特征空间维数之和 $=\dim V$。
- 复数域上每个算子都有特征值；实数域未必。
- 上三角矩阵的对角元即其特征值。

### 典型例子
$A=\begin{pmatrix}4&1&0\\0&4&1\\0&0&3\end{pmatrix}$：特征值 $4$（代数重数 2）、$3$。但 $\mathrm{null}(A-4I)$ 维数为 1（几何重数 1 $<$ 代数重数 2），缺一个特征向量，故不可对角化，需 Jordan 块。对比 $\mathrm{diag}(2,5,7)$ 三特征值互异，必可对角化。

### 深入一点
特征值的本质是“不变子空间里的缩放”。可对角化意味着空间能被特征向量完全拆解成互相独立的缩放方向；不能对角化时，存在“纠缠”方向（广义特征向量），映射在那里除了缩放还带着一点平移。这种纠缠正是 Jordan 标准型要刻画的结构。

### 公式卡
$$Tv = \lambda v\ (v\neq 0) \iff \lambda\text{ 是特征值} \iff T-\lambda I\text{ 不可逆}$$
$$p(z) = \det(T - zI),\qquad \text{特征值} = p\text{ 的根}$$
$$\dim\mathrm{null}(T-\lambda I) \leq \text{代数重数}(\lambda)$$

## 交互 Demo

> 猜一猜：一个 3×3 矩阵有三个不同的特征值，它一定可对角化吗？

<LadEigenvaluesDiagram />

<Stepper>
<Step title="第一步：找不变子空间">
解 $(T-\lambda I)v=0$，非零解即特征向量，它张成一维不变子空间。不同特征值对应的特征向量自动线性无关。
</Step>
<Step title="第二步：比重数">
对每个特征值算几何重数（特征空间维数）与代数重数（根重数）。几何重数 ≤ 代数重数，严格小于则该特征值“缺”特征向量。
</Step>
<Step title="第三步：判可对角化">
把所有特征空间的维数相加，等于 dim V 则可对角化（特征向量凑成基）；否则不能。不同特征值个数 = dim V 时必可对角化。
</Step>
</Stepper>

## 代码对照

求特征值与特征向量，检验可对角化：

```python
import numpy as np

A = np.array([[4, 1, 0], [0, 4, 1], [0, 0, 3]], dtype=float)
vals, vecs = np.linalg.eig(A)
print('特征值:', vals)
print('代数重数: 4 出现 2 次, 3 出现 1 次')
# 特征值 4 的几何重数 = null(A-4I) 的维数
geo = np.linalg.matrix_rank(np.eye(3) * 4 - A)
print('λ=4 几何重数:', 3 - geo, ' < 代数重数 2 ⇒ 不可对角化')

B = np.diag([2.0, 5.0, 7.0])  # 三个不同特征值
print('B 可对角化:', len(np.unique(np.round(B.diagonal(), 6))) == 3)

# 可对角化判定：特征向量矩阵能否凑成满秩方阵
A = np.array([[4, 1, 0], [0, 4, 1], [0, 0, 3]], dtype=float)
vals, vecs = np.linalg.eig(A)
print('特征向量矩阵秩 =', np.linalg.matrix_rank(vecs), '< 3 ⇒ 不可对角化')
B = np.diag([2.0, 5.0, 7.0])
_, vB = np.linalg.eig(B)
print('B 特征向量矩阵秩 =', np.linalg.matrix_rank(vB), '= 3 ⇒ 可对角化')

```

$A$ 的特征值 4 出现两次但几何重数只有 1，说明它有缺陷、不可对角化。判定关键看特征向量矩阵是否满秩：满秩则特征向量凑成基、可对角化，否则有 Jordan 纠缠。

## 常见误区

<Callout type="trap">
**现象 →** 认为“有 n 个特征值就能对角化”。
**原因 →** 忽略了重数与缺陷。
**修法 →** 看特征向量够不够凑成基。若某特征值几何重数 < 代数重数（如上三角对角全 4 但有 1 在超对角），则缺特征向量，不可对角化，需用广义特征向量（Jordan 块）。
</Callout>

<Callout type="trap">
**现象 →** 以为实矩阵总有实特征值。
**原因 →** 只算过对称矩阵的例子。
**修法 →** 旋转矩阵 $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ 特征值为 $\pm i$，无实特征值。实数域不一定有特征值，复数域才有保证。
</Callout>

<Exercises>
**问题**：3×3 矩阵有三个不同特征值，一定可对角化吗？

<Answer>
一定。不同特征值对应的特征向量线性无关，三个不同特征值给出三个线性无关特征向量，在三维空间中凑成基，故可对角化。
</Answer>

**问题**：证明：不同特征值对应的特征向量线性无关。

<Answer>
设 $Tv_i=\lambda_i v_i$，$\lambda_i$ 互不相同。设有 $\sum a_i v_i=0$，取使 $a_i\neq0$ 的最少项数组合。作用 $(T-\lambda_1 I)$ 得 $\sum_{i>1} a_i(\lambda_i-\lambda_1)v_i=0$，项数更少，由最小性必全为零，但 $\lambda_i-\lambda_1\neq0$ 故 $a_i=0$，矛盾。故线性无关。
</Answer>
</Exercises>
