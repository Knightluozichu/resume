## 直觉引入

抽象向量空间没有“长度”和“角度”。引入内积后，几何感就回来了：范数量长度，正交量角度，投影找最近点。

这一章是谱定理的准备：只有在内积空间里，才能谈论“正交对角化”。Gram-Schmidt 把任意基变成正交规范基，让一切计算变简单。

换言之，内积是几何重返代数的桥梁。一旦有了内积，我们就能在任意抽象空间里谈“垂直”“长度”“最近点”——从函数逼近到信号处理，再到机器学习里的最小二乘，背后都是同一套投影逻辑。

## 概念讲解

<Term def="满足共轭对称、线性、正定性的二元函数">内积</Term> $\langle u,v\rangle$ 满足共轭对称 $\langle u,v\rangle=\overline{\langle v,u\rangle}$、对第一变元线性、正定性 $\langle v,v\rangle\geq 0$ 且等于零仅当 $v=0$。

由此定义<Term def="向量长度 √⟨v,v⟩">范数</Term> $\|v\|=\sqrt{\langle v,v\rangle}$。两条核心不等式：<Term def="|⟨u,v⟩| ≤ ‖u‖‖v‖">柯西-施瓦茨不等式</Term> 与勾股定理（正交则 $\|u+v\|^2=\|u\|^2+\|v\|^2$）。

<Term def="把任意基变成正交规范基的算法">Gram-Schmidt 正交化</Term>逐步减去已生成方向的投影并归一化，得到正交规范基 $e_k$。在标准正交基下，内积退化为点积，<Term def="v 到子空间 U 的最近点">正交投影</Term> $P_Uv=\sum\langle v,e_k\rangle e_k$。

最佳逼近定理：$P_Uv$ 是 $U$ 中离 $v$ 最近的点，残差 $v-P_Uv$ 正交于 $U$。这是最小二乘的几何基础。

### 性质速查
- $\|v\|^2=\langle v,v\rangle$；正交 $\Leftrightarrow$ $\langle u,v\rangle=0$。
- 柯西-施瓦茨：$|\langle u,v\rangle|\leq\|u\|\|v\|$，等号当且仅当线性相关。
- 勾股定理：正交则 $\|u+v\|^2=\|u\|^2+\|v\|^2$。
- 标准正交基下 $\langle u,v\rangle=\sum u_k\overline{v_k}$（退化为点积）。
- $V=U\oplus U^\perp$（有限维），任意向量唯一分解为投影加正交残差。

### 典型例子
在 $\mathcal P_2$ 上取内积 $\langle p,q\rangle=\int_0^1 p(x)q(x)\,dx$。对基 $\{1,x,x^2\}$ 做 Gram-Schmidt 得到正交多项式（勒让德多项式的缩影）。这把“正交”从几何直观推广到了函数空间，使最小二乘拟合有了内积空间的统一语言。

### 深入一点
内积把长度与角度请回抽象空间，让“最近”“垂直”“投影”都有了精确含义。最佳逼近定理是最小二乘的几何内核：拟合误差正交于模型空间。理解了这层，从线性回归到傅里叶级数都是同一套投影逻辑的不同实例。

### 公式卡
$$\|v\| = \sqrt{\langle v,v\rangle},\qquad |\langle u,v\rangle| \leq \|u\|\,\|v\|$$
$$e_k = \frac{v_k - \sum_{j<k}\langle v_k,e_j\rangle e_j}{\left\|v_k - \sum_{j<k}\langle v_k,e_j\rangle e_j\right\|} \quad\text{（Gram-Schmidt）}$$
$$P_U v = \sum_k \langle v,e_k\rangle e_k,\qquad \|v-P_Uv\| = \min_{u\in U}\|v-u\|$$

<Stepper>
<Step title="第一步：定义内积">
R^n 用点积；多项式空间可用 $\langle p,q\rangle=\int_0^1 p(x)q(x)dx$。内积确定后范数与正交才有意义。
</Step>
<Step title="第二步：Gram-Schmidt">
对每个 $v_k$，减去它在已有 $e_1,\ldots,e_{k-1}$ 上的投影，再归一化。若某步得到零向量，说明 $v_k$ 线性相关于前面，跳过。
</Step>
<Step title="第三步：最佳逼近">
要求 $v$ 在子空间 $U$ 的最近点，先取 $U$ 的正交规范基，投影 $P_Uv=\sum\langle v,e_k\rangle e_k$ 即为答案，残差正交于 $U$。
</Step>
</Stepper>

## 代码对照

实现 Gram-Schmidt 并验证正交性与最佳逼近：

```python
import numpy as np

def gram_schmidt(V):
    Q = []
    for v in V:
        q = v.copy()
        for e in Q:
            q -= np.dot(v, e) * e          # 减去已有方向的投影
        if np.linalg.norm(q) > 1e-9:
            Q.append(q / np.linalg.norm(q)) # 归一化
    return np.array(Q).T

V = np.array([[1, 1, 0], [1, 0, 1], [0, 1, 1]], dtype=float)
Q = gram_schmidt(V)
print('正交性:', np.allclose(Q.T @ Q, np.eye(Q.shape[1])))

# 最佳逼近：v 到 Q 列空间的投影
v = np.array([3, 2, 1], dtype=float)
proj = Q @ (Q.T @ v)
print('残差正交于空间:', np.allclose(Q.T @ (v - proj), 0))

# 最小二乘：超定方程 Ax=b 的最佳逼近解 = 正交投影
A = np.array([[1, 0], [1, 1], [1, 2]], dtype=float)
b = np.array([1, 2, 2], dtype=float)
x, *_ = np.linalg.lstsq(A, b, rcond=None)
print('最小二乘解:', x)
print('残差正交于列空间:', np.allclose(A.T @ (A @ x - b), 0))

```

Gram-Schmidt 后 $Q^TQ=I$ 验证正交规范。投影 $Q(Q^Tv)$ 是 $v$ 在列空间的最近点，残差正交于空间——最小二乘解的残差 $A^T(Ax-b)=0$ 正是这一定理的数值化身。

## 常见误区

<Callout type="trap">
**现象 →** Gram-Schmidt 后向量不严格正交。
**原因 →** 数值上近线性相关时，减投影放大舍入误差。
**修法 →** 用修改版 Gram-Schmidt 或直接用 QR 分解（Householder），数值稳定。近线性相关时正交基对误差极敏感。
</Callout>

<Callout type="trap">
**现象 →** 以为投影就是“最近的点”凭直觉成立。
**原因 →** 没用残差正交性证明。
**修法 →** 对任意 u∈U，‖v-u‖²=‖v-Pu‖²+‖Pu-u‖²（因 v-Pu⊥U 而 Pu-u∈U），故 ‖v-u‖≥‖v-Pu‖，等号仅当 u=Pu。正交投影确为最近点。
</Callout>

<Exercises>
**问题**：证明柯西-施瓦茨不等式 |⟨u,v⟩| ≤ ‖u‖‖v‖。

<Answer>
若 v=0 显然。否则对任意 $\lambda$，$0\leq\|u-\lambda v\|^2=\|u\|^2-2\mathrm{Re}(\bar\lambda\langle u,v\rangle)+|\lambda|^2\|v\|^2$。取 $\lambda=\langle u,v\rangle/\|v\|^2$，化简得 $0\leq\|u\|^2-|\langle u,v\rangle|^2/\|v\|^2$，即 $|\langle u,v\rangle|\leq\|u\|\|v\|$。
</Answer>

**问题**：为什么正交投影给出最小距离？

<Answer>
对任意 $u\in U$，$\|v-u\|^2=\|v-P_Uv\|^2+\|P_Uv-u\|^2$（因 $v-P_Uv\perp U$ 而 $P_Uv-u\in U$）。故 $\|v-u\|\geq\|v-P_Uv\|$，等号仅当 $u=P_Uv$。投影即最近点。
</Answer>
</Exercises>
