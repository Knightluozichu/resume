## 直觉引入

在内积空间里，算子可以拥有“最美的结构”：存在一组正交规范基使它变成对角矩阵。这意味着映射在各个正交方向上各自独立地缩放，没有剪切、没有旋转纠缠。

谱定理精确刻画了哪些算子享有这种结构：复数域上是正规算子，实数域上是自伴算子。这是线性代数的高潮，也是 SVD、主成分分析的数学根基。

换言之，谱定理回答了一个极美的问题：什么样的映射可以“完全不纠缠”——在各个正交方向上各自独立地缩放？答案是复数域的正规算子与实数域的自伴算子。这个结论既是代数的巅峰，也是几何的极致简洁。

## 概念讲解

<Term def="T 等于其伴随 T*">自伴算子</Term>满足 $T=T^*$（实数域即对称矩阵）；<Term def="TT*=T*T 的算子">正规算子</Term>满足 $TT^*=T^*T$，自伴是其特例。还有<Term def="可写为 S*S 的算子">正算子</Term>与<Term def="保持长度的算子 T*T=I">等距同构</Term>。

<Term def="正规算子可被正交对角化">复谱定理</Term>：复内积空间上，$T$ 正规当且仅当存在正交规范基使其对角化，即 $T=\sum\lambda_k\langle\cdot,e_k\rangle e_k$。正规 $\Leftrightarrow$ 正交可对角化。

<Term def="自伴算子可被正交对角化">实谱定理</Term>：实内积空间上，$T$ 自伴当且仅当存在正交规范基使其对角化。实数域要求更强的“自伴”前提，因为实正规算子（如 90° 旋转）未必有实特征值。

推论：每个算子有极分解 $T=S\sqrt{T^*T}$（$S$ 等距），<Term def="√(T*T) 的特征值">奇异值</Term>即 $\sqrt{T^*T}$ 的特征值，支撑 SVD。

### 性质速查
- 自伴 $T=T^*$；正规 $TT^*=T^*T$；自伴是正规的特例。
- 自伴算子特征值为实数：$\lambda=\langle Tv,v\rangle/\langle v,v\rangle\in\mathbb R$。
- 不同特征值对应的特征向量在自伴/正规算子下正交。
- 正算子 $\Leftrightarrow$ 自伴且特征值全非负 $\Leftrightarrow$ $T=S^*S$。
- 等距算子特征值的模为 1，保长保内积。

### 典型例子
$A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ 实对称（自伴），特征值 $1,3$，特征向量 $(1,-1),(1,1)$ 正交。用正交矩阵 $Q$ 对角化：$A=Q\,\mathrm{diag}(1,3)\,Q^T$。这就是实谱定理：自伴算子在正交基下变成纯缩放，没有剪切、没有旋转纠缠。

### 深入一点
谱定理是线性代数的高潮，因为它把代数（算子结构）与几何（正交）合二为一。可正交对角化的算子，其作用就是沿一组正交方向各自独立缩放——这是最干净、最易理解的映射形态。SVD、主成分分析、量子力学中的可观测量，都建立在这条定理之上。

### 公式卡
$$\text{自伴}: T=T^*;\qquad \text{正规}: TT^*=T^*T$$
$$T\text{ 正规} \iff \exists\text{ 正交规范基 } \{e_k\}: Tv = \sum_k \lambda_k\langle v,e_k\rangle e_k$$
$$T = S\sqrt{T^*T}\quad\text{（极分解）},\qquad \text{奇异值} = \sqrt{T^*T}\text{ 的特征值}$$

## 代码对照

验证实谱定理与极分解：

```python
import numpy as np

# 实对称（自伴）算子：实谱定理
A = np.array([[2, 1], [1, 2]], dtype=float)
vals, Q = np.linalg.eigh(A)              # 正交特征向量
print('正交基:', np.allclose(Q.T @ Q, np.eye(2)))
print('对角化:', np.allclose(Q @ np.diag(vals) @ Q.T, A))

# 极分解 T = S @ sqrt(T*T)
T = np.array([[1, -2], [3, 0]], dtype=float)
U, S, Vt = np.linalg.svd(T)              # S 即奇异值
sqrtTT = Vt.T @ np.diag(S) @ Vt          # √(T*T)
iso = U @ Vt                              # 等距部分
print('极分解重构:', np.allclose(iso @ sqrtTT, T))
print('等距性:', np.allclose(iso.T @ iso, np.eye(2)))

# 主成分分析：协方差矩阵(自伴)的谱定理 = 找最大方差方向
X = np.array([[2, 0, 0], [0, 3, 0], [1, 1, 2]], dtype=float)
C = np.cov(X, rowvar=False)          # 对称正定
vals, vecs = np.linalg.eigh(C)       # 谱定理：正交特征基
order = np.argsort(vals)[::-1]
print('主成分方向(特征向量):', vecs[:, order].T)
print('方差(特征值):', vals[order])

```

`eigh` 专为对称矩阵设计，返回正交特征向量。PCA 正是实谱定理的应用：协方差矩阵（自伴）的正交特征基给出主成分方向，大特征值对应高方差方向——谱定理直接支撑了数据分析的核心方法。

## 常见误区

<Callout type="trap">
**现象 →** 以为实正规算子都能正交对角化。
**原因 →** 把复谱定理条件直接搬到实数域。
**修法 →** 实谱定理只对自伴算子成立。90° 旋转是实正规算子（正交矩阵），但特征值为 ±i，无实特征基，不能实对角化。
</Callout>

<Callout type="trap">
**现象 →** 混淆自伴与正算子。
**原因 →** 名字都“正面”。
**修法 →** 自伴 T=T*（实即对称），未必特征值非负；正算子要求自伴且特征值全非负（等价于 T=S*S）。正算子是自伴的特例。
</Callout>

<Exercises>
**问题**：实对称矩阵的特征向量能选成正交吗？为什么？

<Answer>
能。实对称矩阵是自伴算子，由实谱定理存在正交规范特征基。具体地，不同特征值对应的特征向量正交（因 (λ-μ)⟨u,v⟩=⟨Tu,v⟩-⟨u,Tv⟩=0），同特征值空间内可用 Gram-Schmidt 正交化。
</Answer>

**问题**：为什么实谱定理要求自伴，而复谱定理只要求正规？

<Answer>
复数域特征多项式总有根，正规算子有足够特征向量凑成正交基。实数域正规算子（如旋转）可能无实特征值，无法实对角化；自伴算子特征值为实数（λ=⟨Tv,v⟩∈R），才有实正交特征基，故实谱定理需更强前提。
</Answer>
</Exercises>
