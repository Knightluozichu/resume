## 直觉引入

实向量空间有个“缺口”：有些算子（如旋转）没有实特征值，无法对角化。复数能补上这个缺口——把实空间形式上“加个 i”，得到复化空间，特征值就成对出现了。

复化是 Axler 统一实与复的关键技巧：先在复化上用复谱定理，再让结果“回流”到实空间，推出实谱定理。复数不是额外负担，而是理解实结构的镜子。

换言之，复数不是额外负担，而是看清实空间结构的一面放大镜。实数域里藏着的旋转、纠缠，一旦放到复数域下就显形成共轭特征对；看清之后再回到实空间，那些原本“无解”的结构就变得可以理解、可以证明。

## 概念讲解

<Term def="V + iV 形式扩张得到的复向量空间">复化</Term> $V_{\mathbb C}=V+iV$，元素形如 $u+iv$（$u,v\in V$）。实算子 $T$ 自然扩张为 $T_{\mathbb C}(u+iv)=Tu+i(Tv)$，仍保持线性性（对复标量）。

复化后，$T_{\mathbb C}$ 的特征值若为非实数 $\lambda$，则 $\bar\lambda$ 也是特征值，对应特征向量 $\overline{v}$——<Term def="复化后成对出现的共轭特征值">共轭特征对</Term>。实空间的旋转 $\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ 复化后特征值为 $\pm i$。

复化的威力在于证明<Term def="用复化回流得到的实谱定理">实谱定理</Term>：对实自伴算子 $T$，先在 $V_{\mathbb C}$ 上用复谱定理（$T_{\mathbb C}$ 仍自伴故正规），得到正交特征基；因 $T$ 自伴其特征值为实数，特征向量可取实的，回流到 $V$ 上即得实正交特征基。

对比：复谱定理要求正规即可；实谱定理要求更强的自伴。复化让我们用“更宽松的复结论”去证明“更严格的实结论”。

### 性质速查
- $V_{\mathbb C}=V+iV$，$\dim V_{\mathbb C}=2\dim V$（实维数计）。
- 实算子复化后特征值成共轭对 $\lambda,\bar\lambda$。
- 自伴算子特征值为实数，复化后特征向量可取实。
- 复谱定理要求正规；实谱定理要求更强的自伴。
- 实正规算子的实标准型是“对角块 + 二维旋转块”。

### 典型例子
90° 旋转 $R=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$ 实数域无实特征值。复化后特征方程 $\lambda^2+1=0$，得 $\lambda=\pm i$，对应特征向量 $(1,\mp i)$。这对共轭特征值对应实空间中一个二维不变子空间——旋转本身，复数只是补齐了实数域看不到的特征结构。

### 深入一点
复化是连接实与复的桥梁。实空间的“缺口”（无实特征值）用复数补上后，复谱定理就能用；再让结论回流（自伴特征值为实、特征向量可取实），就证出了实谱定理。这套“上去再下来”的技巧，体现了用更宽松的环境证明更严格结论的典型数学策略。

### 公式卡
$$V_{\mathbb C} = V + iV,\qquad T_{\mathbb C}(u+iv) = Tu + i(Tv)$$
$$\lambda\text{ 特征值} \Rightarrow \bar\lambda\text{ 特征值}\quad\text{（共轭对）}$$
$$T=T^* \Rightarrow \lambda = \frac{\langle Tv,v\rangle}{\langle v,v\rangle}\in\mathbb R$$

<Stepper>
<Step title="第一步：构造复化">
把实空间 V 扩张为 V_C=V+iV，实算子 T 扩张为 T_C(u+iv)=Tu+iTv。复化后可对复标量线性。
</Step>
<Step title="第二步：看共轭对">
T_C 的特征多项式是实系数多项式在复域的分解，非实根成共轭对 λ,λ̄，特征向量也共轭。旋转复化得 ±i。
</Step>
<Step title="第三步：回流实空间">
自伴算子特征值为实数，复化特征基可取实向量回流到 V，得实正交特征基，证出实谱定理。非自伴则留二维不变块（旋转+伸缩）。
</Step>
</Stepper>

## 代码对照

观察旋转矩阵复化后的共轭特征对：

```python
import numpy as np

# 90 度旋转：实空间无实特征值
R = np.array([[0, -1], [1, 0]], dtype=float)
vals = np.linalg.eigvals(R)
print('复化特征值:', vals)          # [i, -i] 共轭对
print('共轭对:', np.isclose(vals[0], np.conj(vals[1])))
print('实特征值?', np.all(np.isreal(vals)))

# 对称（自伴）算子：复化后特征值为实，可回流实对角化
A = np.array([[2, 1], [1, 2]], dtype=float)
avals = np.linalg.eigvals(A)
print('自伴特征值:', avals, ' 全实?', np.all(np.isreal(avals)))

# 实正规但非自伴的算子：复化后看共轭对，实域只留旋转块
R = np.array([[0, -1], [1, 0]], dtype=float)   # 旋转，正规非自伴
print('复化特征值:', np.linalg.eigvals(R))      # ±i
print('实域可对角化?', np.all(np.isreal(np.linalg.eigvals(R))))
S = np.array([[1, -2], [2, 1]], dtype=float)    # 旋转+伸缩
print('S 复化特征值:', np.linalg.eigvals(S))     # 1±2i

```

旋转矩阵特征值为 $\pm i$ 且互为共轭，实部为零说明无实特征值。$S=\begin{pmatrix}1&-2\\2&1\end{pmatrix}$ 复化后得 $1\pm2i$，对应实空间一个“旋转+伸缩”二维块——这正是实正规算子标准型的缩影。

## 常见误区

<Callout type="trap">
**现象 →** 以为实矩阵只能有实特征值。
**原因 →** 只算过对称矩阵。
**修法 →** 旋转矩阵是实矩阵但特征值为 ±i。实矩阵特征多项式实系数，根成共轭对，非实根成对出现。复化后才能完整看到。
</Callout>

<Callout type="trap">
**现象 →** 不理解复化如何“回流”证明实谱定理。
**原因 →** 没注意自伴算子特征值为实这一关键。
**修法 →** T 自伴则 T_C 自伴，复谱定理给正交特征基；自伴特征值 λ=⟨Tv,v⟩∈R 为实数，故特征向量可取实（实部虚部分别是实特征向量），回流到 V 得实正交基。
</Callout>

<Exercises>
**问题**：90° 旋转矩阵复化后的特征值是什么？

<Answer>
$R=\begin{pmatrix}0&-1\\1&0\end{pmatrix}$，特征方程 $\lambda^2+1=0$，复化后特征值为 $\lambda=\pm i$，成共轭对。实空间无实特征值，复化补齐。
</Answer>

**问题**：用复化解释为何实谱定理只需自伴而复谱定理需正规。

<Answer>
复域特征多项式总有根，正规算子即可正交对角化。实域正规算子（旋转）可能只有非实特征值，无法实对角化；自伴算子特征值为实（λ=⟨Tv,v⟩∈R），复化后特征向量可取实回流到 V，故实谱定理只需自伴即可保证实正交特征基。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="复化">V_C=V+iV，把实空间形式上扩张为复空间，使实算子获得复特征值。</GlossaryItem>
<GlossaryItem term="共轭特征对">实算子复化后非实特征值成对 λ,λ̄ 出现，特征向量也共轭。</GlossaryItem>
<GlossaryItem term="回流">复化上得到的结论（特征值为实、特征向量可取实）回到实空间，证明实谱定理。</GlossaryItem>
<GlossaryItem term="复谱 vs 实谱">复谱定理要求正规，实谱定理要求更强的自伴；复化是连接二者的桥梁。</GlossaryItem>
</Glossary>
