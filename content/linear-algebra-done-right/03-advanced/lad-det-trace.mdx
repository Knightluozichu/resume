## 直觉引入

很多教材把行列式放在开头，用来判可逆、算特征值。Axler 却把它压到全书末尾——因为行列式是“汇总工具”，理解算子结构要靠不变子空间与谱定理，而非算 det。

放在最后看，行列式与迹的意义反而更清晰：det 是体积缩放因子，等于所有特征值之积；trace 是对角和，等于所有特征值之和。它们是全局不变量，一网打尽全部特征值。

换言之，把行列式与迹放在最后，不是贬低它们，而是还它们以本来面目：它们不是理解算子的钥匙，而是算子特征的“年度总结”。当你已经看清了算子的结构，这两个全局量只是把全部特征值打包成两个数字，方便你一眼判断可逆性与总体规模。

## 概念讲解

<Term def="衡量体积缩放因子的标量">行列式</Term> $\det T$ 满足 $\det(ST)=\det S\cdot\det T$，几何上是单位平行体的体积缩放倍数（带符号，$(-1)^N$ 反映定向翻转）。$T$ 可逆当且仅当 $\det T\neq 0$。

<Term def="对角元之和">迹</Term> $\mathrm{trace}\,T$ 是矩阵对角元之和，与基无关。关键性质 $\mathrm{trace}(ST)=\mathrm{trace}(TS)$ 保证了迹是映射的不变量。

两者与特征值的关系（在复数域上，算子有全部特征值 $\lambda_1,\ldots,\lambda_n$，计重数）：$$\det T = \prod_{k=1}^n \lambda_k,\qquad \mathrm{trace}\,T = \sum_{k=1}^n \lambda_k$$

特征多项式可读作 $p(z)=z^n-(\mathrm{tr}\,T)z^{n-1}+\cdots+(-1)^n\det T$，系数由主子式决定（Vieta 公式）。Axler 的点睛：det 与 trace 只是特征值的“积”与“和”，理解算子要靠结构，det/trace 用于汇总与判别。

### 性质速查
- $\det(ST)=\det S\cdot\det T$；$\det I=1$；$\det(T^{-1})=1/\det T$。
- $T$ 可逆 $\Leftrightarrow$ $\det T\neq0$。
- $\mathrm{trace}(ST)=\mathrm{trace}(TS)$（循环性），由此推出相似不变。
- $\det T=\prod\lambda_k$，$\mathrm{trace}\,T=\sum\lambda_k$（计重数，复域）。
- 特征多项式 $p(z)=z^n-(\mathrm{tr}\,T)z^{n-1}+\cdots+(-1)^n\det T$。

### 典型例子
$A=\begin{pmatrix}3&1\\1&3\end{pmatrix}$，特征值 $2,4$。$\det A=8=2\times4$，$\mathrm{trace}\,A=6=2+4$。对比 $B=\mathrm{diag}(1,5)$：迹同为 6 但 $\det B=5\neq8$。迹约束和、行列式约束积，和同积可不同——两个全局量刻画了特征值分布的不同侧面。

### 深入一点
把行列式与迹放最后看，它们的意义反而最清晰：det 是体积缩放、判可逆；trace 是对角和、给特征值中心。它们不是理解算子的主线（那是算子与不变子空间的事），而是收尾的汇总工具——一网打尽全部特征值的积与和。

### 公式卡
$$\det(ST) = \det S\cdot\det T,\qquad T\text{ 可逆}\iff \det T\neq 0$$
$$\det T = \prod_{k=1}^{n}\lambda_k,\qquad \mathrm{trace}\,T = \sum_{k=1}^{n}\lambda_k$$
$$p(z) = z^n - (\mathrm{tr}\,T)z^{n-1} + \cdots + (-1)^n\det T$$

## 代码对照

验证 det/trace 等于特征值之积/和：

```python
import numpy as np

A = np.array([[3, 1], [1, 3]], dtype=float)
vals = np.linalg.eigvals(A)
print('特征值:', vals)
print('det A =', np.linalg.det(A), ' 特征值之积 =', np.prod(vals))
print('trace A =', np.trace(A), ' 特征值之和 =', np.sum(vals))

# 乘性
B = np.array([[1, 2], [0, 1]], dtype=float)
print('det(AB)=detA·detB:',
      np.isclose(np.linalg.det(A@B), np.linalg.det(A)*np.linalg.det(B)))
# 循环性
print('trace(AB)=trace(BA):',
      np.isclose(np.trace(A@B), np.trace(B@A)))

# 用特征多项式系数反推 det 与 trace（Vieta）
import numpy as np
A = np.array([[3, 1], [1, 3]], dtype=float)
p = np.poly(A)                       # 特征多项式系数（高次在前）
print('特征多项式系数:', np.round(p, 4))
print('trace = -p[1]/p[0] =', -p[1]/p[0], '| 实际', np.trace(A))
print('det = (-1)^n p[-1] =', (-1)**A.shape[0]*p[-1], '| 实际', np.linalg.det(A))

```

数值验证 $\det A$ 等于特征值之积、$\mathrm{trace}\,A$ 等于特征值之和。特征多项式系数段用 Vieta 公式由 $p$ 反推 trace 与 det——这把多项式、特征值、全局量三者串成一个闭环。

## 常见误区

<Callout type="trap">
**现象 →** 用 det 判可逆，却不理解为何 det=0 即不可逆。
**原因 →** 把 det 当成“算出来的数”，没看到体积含义。
**修法 →** det 是体积缩放因子：det=0 意味着把空间压扁到更低维（核非零），映射不可逆；det≠0 则体积保形，可逆。
</Callout>

<Callout type="trap">
**现象 →** 以为 trace 依赖基的选择。
**原因 →** trace 定义为对角和，换基对角变了对吗？
**修法 →** 由 trace(ST)=trace(TS) 可证相似不变：trace(P⁻¹AP)=trace(APP⁻¹)=trace(A)。故 trace 是映射的不变量，与基无关。
</Callout>

<Exercises>
**问题**：两个矩阵迹相等，行列式一定相等吗？

<Answer>
不一定。例如 $A=\mathrm{diag}(2,2)$ 与 $B=\mathrm{diag}(1,3)$，trace 都为 4，但 $\det A=4$，$\det B=3$。迹只约束特征值之和，行列式是积，和相同积可不同。
</Answer>

**问题**：证明 trace(ST)=trace(TS)。

<Answer>
设 $S$ 为 $m\times n$，$T$ 为 $n\times m$。$\mathrm{trace}(ST)=\sum_i\sum_j S_{ij}T_{ji}$，$\mathrm{trace}(TS)=\sum_j\sum_i T_{ji}S_{ij}$。两者都是 $\sum_{i,j}S_{ij}T_{ji}$，求和顺序可换，故相等。
</Answer>
</Exercises>
