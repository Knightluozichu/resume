### 核心定义

1. **伴随算子**：T星满足内积Tv,w等于内积v,T星w，把映射从一个槽移到另一个槽。
2. **谱定理**：复正规算子或实自伴算子存在正交规范特征向量基。
3. **正算子**：对所有v都有内积Tv,v非负，并且拥有唯一正平方根。
4. **奇异值分解**：任意线性映射可由两个正交规范基和非负奇异值表示。
5. **低秩近似**：截断SVD在算子范数或Frobenius范数下给出最佳指定秩近似。

## 先声明假设

证明前先写标量域、定义域、陪域、维数以及是否给定内积。许多错误并非推导失误，而是把实数域结论搬到复数域、把有限维结论搬到无限维，或把一般算子当作正规算子。

$$
\mathcal A=(\mathbb F, V, W, \dim V, \text{inner product if any})
$$

伴随算子与谱定理必须放在同一组假设下比较。定义中的“任意”“存在”“唯一”和“非零”都影响证明方向，不能在转述时省略。

## 定理与可核查推导

$$
T=U\Sigma V^*,\qquad T^*T=V\Sigma^2V^*,\qquad \|T-T_k\|=\sigma_{k+1}
$$

对正算子T星T应用谱定理，取其正交规范特征向量和非负特征值平方根作为奇异值。非零奇异值对应的Tv归一化后彼此正交，从而构造输出基并得到SVD。 证明验收要求逐步标注定义、已有定理和新构造，不能用待证结论的等价形式循环论证。

$$
\text{assumptions}\Longrightarrow\text{lemma}\Longrightarrow\text{invariant}\Longrightarrow\text{claim}
$$

```python
singular_values=[5.0,2.0,.4]
def rank_k_error(values,k): return values[k] if k < len(values) else 0.0
assert rank_k_error(singular_values,2)==.4
energy=sum(x*x for x in singular_values[:2])/sum(x*x for x in singular_values)
assert energy>.99
```

代码不是证明，但能暴露维数、顺序、共轭和边界错误。至少使用一个非对角、非对称或不满秩样例；单位矩阵与零算子只能作为冒烟测试。

先从定义构造对象，再找到保持不变的子空间、维数或多项式，最后把局部结论拼成全空间结论。若构造依赖选择基，要继续说明最终结论为何与基无关。

**奇异值分解**：任意线性映射可由两个正交规范基和非负奇异值表示。

## 工程与学习案例

压缩或降维时不能只给保留秩；应报告奇异值谱、截断误差、保留能量与下游任务变化。QR用于稳定正交化，Cholesky只适用于正定结构。 交付物同时保存定义域和陪域、基、矩阵或算子表示、关键中间子空间、残差、反例以及结论适用范围。

```python
evidence=[("伴随算子","definition"),("正算子","proof"),("低秩近似","counterexample")]
assert len({name for name,_ in evidence})==3
```

1. 原样写出定义中的量词、域、空间和非零条件。
2. 画出子空间、映射或分解关系，并标记要保持的不变量。
3. 用最小非平凡例子逐步重算，再删除一个假设寻找反例。
