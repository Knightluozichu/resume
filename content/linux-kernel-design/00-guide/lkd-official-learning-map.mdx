## 为什么先画全书坐标

、、、、共同构成本页坐标。按机械工业出版社完整目录与InformIT原版目录，把20章404个层级组织为内核基础、进程接口、中断并发、内存I/O和工程社区五条源码路线。

## 版本与验收边界

原书基于Linux 2.6.34。学习时保留CFS、tasklet、BKL、基树、旧块层和回写线程等历史实现，再用迁移表对照现代内核；不能让现代API替换正式目录，也不能把历史细节伪装成当前实现。

核心不变量是：**20章404个正式层级都有唯一教学归属；Linux 2.6.34历史实现与现代内核迁移说明明确分开。** 每个结论都要回答源码在哪里、对象由谁拥有、在哪个上下文运行、锁保护什么、状态何时变化、失败后怎样恢复。

## 二十章路线

### 第1章 Linux内核简介

从UNIX历史、操作系统边界、Linux单体内核特征、版本模型和开发者社区建立全书坐标。 主线为“回看UNIX传统 → 划定内核职责 → 比较内核设计 → 定位Linux特征 → 识别版本基线 → 连接开发社区”，对应8个正式目录层级。

### 第2章 从内核出发

把源码获取、源码树、配置编译、安装和内核开发约束连接成可重复的开发环境。 主线为“取得源码 → 核对源码树 → 配置内核 → 并行编译 → 安装与回退 → 检查开发约束”，对应20个正式目录层级。

### 第3章 进程管理

围绕task_struct、进程状态、上下文、家族树、fork写时拷贝、线程和退出回收解释Linux进程生命周期。 主线为“定位任务描述符 → 读取进程状态 → 建立家族关系 → 复制或共享资源 → 运行线程 → 退出并回收”，对应20个正式目录层级。

### 第4章 进程调度

从多任务和策略进入CFS调度类、时间记账、进程选择、睡眠唤醒、抢占、实时策略和调度系统调用。 主线为“分类工作负载 → 映射优先级权重 → 进入运行队列 → 选择下个任务 → 处理睡眠唤醒 → 验证抢占与实时”，对应26个正式目录层级。

### 第5章 系统调用

区分API、POSIX、C库和系统调用，追踪调用号、陷入处理、参数验证、实现绑定与系统调用上下文。 主线为“区分API与ABI → 选择调用号 → 进入内核入口 → 复制并验证参数 → 执行内核实现 → 返回用户空间”，对应17个正式目录层级。

### 第6章 内核数据结构

比较内核链表、kfifo、idr映射、红黑树和复杂度，用侵入式结构、所有权和访问模式选择数据结构。 主线为“描述访问模式 → 选择结构 → 初始化所有权 → 插入与查找 → 并发遍历 → 删除并销毁”，对应32个正式目录层级。

### 第7章 中断和中断处理

从中断来源、注册释放、共享处理、上下文限制、控制状态和/proc/interrupts解释上半部。 主线为“识别中断源 → 注册处理程序 → 确认共享来源 → 保存最小状态 → 唤起下半部 → 释放并核对计数”，对应19个正式目录层级。

### 第8章 下半部和推后执行的工作

比较软中断、tasklet、工作队列和历史BH/任务队列，按上下文、并发、延迟与睡眠需求选择延后机制。 主线为“切分紧急工作 → 选择执行上下文 → 安排软中断 → 串行化tasklet → 下放工作队列 → 禁用排空并卸载”，对应19个正式目录层级。

### 第9章 内核同步介绍

从临界区、竞争来源、保护对象、死锁、争用和可扩展性建立内核同步问题模型。 主线为“列出共享状态 → 识别并发来源 → 写出不变量 → 划定临界区 → 证明锁序无环 → 测量争用扩展”，对应10个正式目录层级。

### 第10章 内核同步方法

系统比较原子操作、自旋锁、读写锁、信号量、互斥体、完成量、顺序锁、抢占控制与内存屏障。 主线为“确认执行上下文 → 判断能否睡眠 → 评估读写比例 → 选择同步原语 → 规定内存顺序 → 验证释放与唤醒”，对应24个正式目录层级。

### 第11章 定时器和时间管理

从HZ、jiffies回绕、硬时钟、时钟中断、实际时间、内核定时器和延迟执行理解时间管理。 主线为“选择时间基准 → 换算节拍 → 处理回绕 → 注册定时器 → 执行回调 → 取消同步并释放”，对应24个正式目录层级。

### 第12章 内存管理

从页和区进入页分配、kmalloc/vmalloc、slab、内核栈、高端内存与每CPU分配，建立分配选择树。 主线为“确定容量连续性 → 选择内存区 → 设置GFP上下文 → 分配并初始化 → 观察缓存与映射 → 按来源释放”，对应26个正式目录层级。

### 第13章 虚拟文件系统

用VFS抽象连接超级块、inode、dentry、file对象及其操作表，解释文件系统和进程相关结构。 主线为“进入通用接口 → 定位超级块 → 解析inode → 命中目录项缓存 → 创建file对象 → 调用操作并释放”，对应18个正式目录层级。

### 第14章 块I/O层

从块设备、buffer_head、bio、I/O向量、请求队列和调度器解释块I/O合并、排队与派发。 主线为“拆分块设备请求 → 构造bio向量 → 进入请求队列 → 合并与排序 → 派发到驱动 → 完成并唤醒”，对应16个正式目录层级。

### 第15章 进程地址空间

围绕mm_struct、VMA、区域树/链表、find_vma、mmap/munmap和页表解释进程地址空间。 主线为“定位内存描述符 → 枚举VMA区间 → 查找相交区域 → 创建映射 → 更新页表 → 解除映射并回收”，对应19个正式目录层级。

### 第16章 页高速缓存和页回写

从缓存策略、address_space、基树、缓冲区缓存和flusher线程解释脏页、回收与页回写。 主线为“定位缓存映射 → 查找缓存页 → 标记脏页 → 触发回写 → 处理拥塞 → 回收并核对持久性”，对应15个正式目录层级。

### 第17章 设备与模块

从设备类型和模块生命周期进入依赖、参数、符号导出、kobject/ktype/kset、引用计数、sysfs和uevent。 主线为“分类设备 → 构建加载模块 → 解析依赖参数 → 建立设备模型 → 发布sysfs属性 → 注销排空并卸载”，对应23个正式目录层级。

### 第18章 调试

从printk和日志缓冲进入oops、符号、调试配置、SysRq、gdb/kgdb、探测、二分搜索与社区求助。 主线为“冻结故障输入 → 提高可观察性 → 捕获oops与符号 → 缩小探测范围 → 二分定位提交 → 整理证据求助”，对应27个正式目录层级。

### 第19章 可移植性

从字长、类型、对齐、结构填补、字节序、时间、页长、处理器排序和配置差异建立可移植内核代码规则。 主线为“识别架构假设 → 固定宽度类型 → 检查对齐填补 → 转换字节序 → 适配页长时间 → 验证SMP与配置”，对应18个正式目录层级。

### 第20章 补丁、开发和社区

把社区协作、编码风格、维护系统、错误报告、补丁创建、Git提交和发送评审连接成交付闭环。 主线为“定位维护者 → 重现并描述问题 → 形成最小改动 → 运行风格与测试 → 生成发送补丁 → 回应评审并迭代”，对应23个正式目录层级。
