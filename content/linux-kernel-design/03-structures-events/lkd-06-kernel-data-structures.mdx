## 为什么从这个问题开始

第6章 内核数据结构围绕“链表、kfifo、ID映射与树怎样按操作、并发和生命周期选择？”建立贯穿任务。先冻结构建和对象身份，再以小输入观察状态与trace，最后用单故障和同输入恢复验收；只有守住“成员集合、次序、引用和锁在每次操作前后成立”并交付容器状态图、操作计数、并发保护与当前接口迁移表，目录术语、源码字段或一次成功启动才可能升级为机制证据。
