## 为什么从这个问题开始

第12章 内存管理围绕“页、区、kmalloc/vmalloc、slab、栈、高端内存与per-CPU分配怎样按约束选择？”建立贯穿任务。先冻结构建和对象身份，再以小输入观察状态与trace，最后用单故障和同输入恢复验收；只有守住“连续性、上下文、NUMA、生命周期和释放协议均满足”并交付分配标志、页/folio、slab、失败注入、内存与释放轨迹，目录术语、源码字段或一次成功启动才可能升级为机制证据。
