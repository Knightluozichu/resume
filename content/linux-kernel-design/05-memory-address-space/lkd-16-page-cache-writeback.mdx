## 机制、对象与故障模型

从缓存策略、address_space、基树、缓冲区缓存和flusher线程解释脏页、回收与页回写。

本章核心不变量是：**缓存页归属和脏状态可追踪；回写、错误和回收不会丢失用户已确认的数据语义。** 它必须同时约束正常、边界、失败和恢复样本。函数返回成功只是一条证据，还要检查对象引用、上下文限制、锁、状态更新和异步清理。

最小实验：用固定文件写入比较缓存增长、脏页阈值、writeback事件和fsync完成时刻。

故障实验：注入慢设备、回写错误和内存压力，观察脏页节流与数据错误传播。

源码证据表至少包含提交、配置、入口、调用栈、当前上下文、对象/字段、锁、预期状态、实际状态、首错和清理十一列。涉及性能还需保存CPU/NUMA放置、预热、采样窗口和延迟分位；涉及异步回调还需保存注册、进入、注销与排空时刻。

## 四类样本与验收

| 样本 | 只改变什么               | 必查证据                 | 通过条件   |
| ---- | ------------------------ | ------------------------ | ---------- |
| 基线 | 固定提交、配置与输入     | 对象、上下文、状态和日志 | 与预测一致 |
| 边界 | 容量、亲和、长度或时序   | 第一处饱和或拒绝         | 边界可解释 |
| 失败 | 一个指针、锁序或异步故障 | 首错栈、字段和责任层     | 故障可定位 |
| 恢复 | 撤销设置或恢复快照       | 残留对象与同输入重放     | 回到基线   |
