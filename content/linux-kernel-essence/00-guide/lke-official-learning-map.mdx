## 版本、机制与验收

按机械工业出版社中文版完整目录，把8章75个HACK组织为开发、资源、存储网络、虚拟化省电和诊断追踪五条证据链。

核心不变量是：**8个章标题和75个HACK都有唯一教学归属；原书Linux 2.6.18～3.0语境与现代迁移说明明确分开。** 复习时不能只记命令，因为相同命令在不同发行版、内核配置、cgroup层级、虚拟化后端和追踪接口上可能得到不同语义。每一项都要回答“对象在哪里、内核做了什么、信号先在哪里变化、怎样撤销”。

建立四层证据：版本层保存提交、配置和工具；结构层保存控制组、接口、挂载、虚拟机或探针关系；时间层保存计数、事件、栈和转储；恢复层证明撤销设置或恢复快照后同输入回到基线。

## 八章路线

### 第1章 内核入门 · 6个HACK

把源码获取、配置编译、模块生命周期、Git补丁和快速重编译连接成可重复的内核开发反馈环。 主线为“确认基线版本 → 取得源码与配置 → 编译内核与模块 → 加载最小模块 → 审查补丁格式 → 缩短反馈回路”。验收不只检查命令结果，还检查内核源码树、Kconfig、内核模块、Git补丁、localmodconfig的状态、首错和恢复。

### 第2章 资源管理 · 10个HACK

用cgroup控制器、namespace、调度组、cpuset、内存限制、块I/O权重和OOM路径解释Linux怎样隔离并仲裁竞争资源。 主线为“建立可重复负载 → 隔离进程视图 → 分配CPU集合 → 限制内存用量 → 调节块I/O → 解释压力与OOM”。验收不只检查命令结果，还检查cgroup、namespace、组调度、cpuset、OOM Killer的状态、首错和恢复。

### 第3章 文件系统 · 5个HACK

以ext4启用与迁移、挂载调优、fio基准和FUSE用户态文件系统串起格式、缓存、持久性与性能证据。 主线为“盘点磁盘与特性 → 建立可回滚镜像 → 迁移并校验ext4 → 固定挂载参数 → 运行fio矩阵 → 比较FUSE路径”。验收不只检查命令结果，还检查ext4、日志模式、挂载选项、fio、FUSE的状态、首错和恢复。

### 第4章 网络 · 6个HACK

从流量控制进入TUN/TAP、网桥、VLAN、bonding与丢包监控，建立虚拟二层设备到排队和故障证据的路径图。 主线为“绘制接口拓扑 → 生成固定流量 → 施加队列规则 → 叠加二层虚拟设备 → 注入链路故障 → 定位丢包层级”。验收不只检查命令结果，还检查qdisc、TUN/TAP、网桥、VLAN、bonding的状态、首错和恢复。

### 第5章 虚拟化 · 12个HACK

比较Xen与KVM，贯通无介质安装、vCPU布局、EPT、IOMMU、SR-IOV、KSM、磁盘挂载、环境识别和客户机调试。 主线为“冻结宿主客户基线 → 创建虚拟机 → 布局vCPU与内存 → 验证二级页表 → 隔离设备直通 → 调试并恢复客户机”。验收不只检查命令结果，还检查Xen、KVM、EPT、IOMMU、SR-IOV的状态、首错和恢复。

### 第6章 省电 · 12个HACK

从ACPI系统状态、CPU C/P状态进入PCI/USB/显示/网络/键盘/硬盘电源管理，并用PowerTOP把节能与唤醒延迟量化。 主线为“建立功耗基线 → 识别系统电源状态 → 测量CPU驻留 → 约束设备唤醒 → 验证网络与存储 → 回归睡眠唤醒”。验收不只检查命令结果，还检查ACPI、S状态、C/P状态、runtime PM、PowerTOP的状态、首错和恢复。

### 第7章 调试 · 12个HACK

从SysRq、diskdump/Kdump和崩溃测试进入看门狗、soft lockup、crash、用户态core、lockdep与内存泄漏检测。 主线为“配置恢复与转储 → 验证符号匹配 → 触发受控故障 → 保存完整现场 → 定位栈与资源 → 修复后同输入重放”。验收不只检查命令结果，还检查SysRq、Kdump、watchdog、crash、lockdep的状态、首错和恢复。

### 第8章 概要分析与追踪 · 12个HACK

用perf、ftrace、trace-cmd、动态探针和SystemTap从统计采样进入函数、事件和脚本化追踪，形成假设驱动的性能诊断链。 主线为“提出性能假设 → 选择计数或采样 → 限定函数与事件 → 采集统一时间线 → 关联用户与内核栈 → 关闭探针并复测”。验收不只检查命令结果，还检查perf、ftrace、tracepoint、kprobe、SystemTap的状态、首错和恢复。
