## 四类样本与验收

| 样本 | 控制方式               | 关键证据                 | 通过条件     |
| ---- | ---------------------- | ------------------------ | ------------ |
| 基线 | 固定版本、配置与负载   | 原始计数、日志、对象关系 | 与预测一致   |
| 边界 | 只改变容量、亲和或时间 | 首个饱和点与延迟分位     | 边界可解释   |
| 失败 | 注入一个错误或故障     | 首错、栈、事件或转储     | 责任层可定位 |
| 恢复 | 撤销配置或恢复快照     | 残留对象与同输入结果     | 回到基线     |

## 小结

- qdisc：连接“绘制接口拓扑”的机制前提与证据。
- TUN/TAP：连接“生成固定流量”的机制前提与证据。
- 网桥：连接“施加队列规则”的机制前提与证据。
- VLAN：连接“叠加二层虚拟设备”的机制前提与证据。
- bonding：连接“注入链路故障”的机制前提与证据。
