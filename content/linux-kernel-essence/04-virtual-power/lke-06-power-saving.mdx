## 四类样本与验收

| 样本 | 控制方式               | 关键证据                 | 通过条件     |
| ---- | ---------------------- | ------------------------ | ------------ |
| 基线 | 固定版本、配置与负载   | 原始计数、日志、对象关系 | 与预测一致   |
| 边界 | 只改变容量、亲和或时间 | 首个饱和点与延迟分位     | 边界可解释   |
| 失败 | 注入一个错误或故障     | 首错、栈、事件或转储     | 责任层可定位 |
| 恢复 | 撤销配置或恢复快照     | 残留对象与同输入结果     | 回到基线     |

## 小结

- ACPI：连接“建立功耗基线”的机制前提与证据。
- S状态：连接“识别系统电源状态”的机制前提与证据。
- C/P状态：连接“测量CPU驻留”的机制前提与证据。
- runtime PM：连接“约束设备唤醒”的机制前提与证据。
- PowerTOP：连接“验证网络与存储”的机制前提与证据。
