## 直觉引入

把 Linux 服务器想象成一座「工厂」。你刚装好一台 Ubuntu，它就像一座空厂房——你得先学会在车间里走动（命令行基础，第 1 章），然后给不同工人发门禁卡（文件权限，第 2 章）；接着招聘员工、分配岗位（用户管理，第 3 章），采购设备和原材料（包管理，第 4 章）；厂区要通路通网（网络配置，第 5 章），还要装门禁安防（防火墙安全，第 6 章）；机器要能自动运转、坏了能自启（systemd 服务，第 7 章）；最后把重复劳动写成自动流程（Shell 脚本，第 8 章）。本书回答的就是「一台 Linux 服务器从裸机到生产级运维」需要什么技能。

## 四阶段递进

<Term def="Linux 运维是通过命令行管理服务器系统资源的工程实践：从文件操作到用户管理、从网络配置到服务部署、从安全防护到自动化脚本，核心目标是以高效可靠的方式让服务器持续提供服务。">Linux 运维</Term>的学习可以拆成四个递进阶段。**命令行与权限**包括终端操作和文件权限——它们解决「怎么操作服务器」和「谁能访问什么」。**用户与包管理**包括用户管理和包管理——它们解决「系统里有谁」和「怎么安装软件」。**网络与安全**包括网络配置和防火墙——它们解决「怎么联网」和「怎么防护」。**服务与自动化**包括 systemd 服务和 Shell 脚本——它们解决「服务怎么持续运行」和「怎么自动化运维」。最后总复习用一台服务器从装好到上线串联全部知识点。

```text
// 「一台服务器从装好到上线」——Linux 运维全程参与的生命周期
$ ssh deploy@server
  // 1. 命令行基础（第 1 章）：在终端中操作文件、目录、进程
  //    ls/cd/cp/rm/grep/管道重定向，这是所有运维工作的基础

  // 2. 文件权限（第 2 章）：rwx 权限控制文件访问
  //    chmod 755 file / setfacl -m u:alice:rw file

  // 3. 用户管理（第 3 章）：创建用户、分配组、sudo 提权
  //    useradd -m -s /bin/bash deploy / usermod -aG sudo deploy

  // 4. 包管理（第 4 章）：安装、更新、卸载软件包
  //    apt update && apt install nginx

  // 5. 网络配置（第 5 章）：配置 IP 地址、网关、DNS
  //    ip addr / netplan apply

  // 6. 防火墙安全（第 6 章）：控制入站出站流量
  //    ufw allow 22/tcp / ufw enable

  // 7. systemd 服务（第 7 章）：管理服务生命周期和开机自启
  //    systemctl enable --now nginx

  // 8. Shell 脚本（第 8 章）：自动化备份、监控、部署
  //    crontab -e / ./backup.sh
```

## 常见误区

<Callout type="trap">
**误区：会用 Linux 桌面就等于懂 Linux 运维。** 在 Ubuntu 桌面点鼠标装软件、用文件管理器拷文件只是「会用桌面环境」——图形界面封装了底层逻辑。真正懂运维的人能解释：为什么 `chmod 755` 比 `777` 更安全（最小权限原则）、为什么 sudo 比 su root 更好（审计+最小权限）、为什么 netplan 比 ifconfig 更可靠（声明式配置+持久化）、为什么 ufw 默认拒绝比默认放行更安全（白名单优先）、为什么 systemd 比 init 脚本更高效（并行启动+依赖管理）、为什么 Shell 脚本要加 `set -e`（遇错即停防止隐患）。把 Linux 当黑盒的人遇到服务起不来只能重启；懂运维的人能看 systemctl status、查 journalctl 日志、用 ss 排查端口、理解权限链路。区分标志：能否解释「系统为什么这样设计」而非只是「能操作它」。
</Callout>

<Exercises>
**问题 1**：全书四阶段递进是什么？为什么是这个顺序？

<Answer>
命令行与权限（命令行基础 + 文件权限）→ 用户与包管理（用户管理 + 包管理）→ 网络与安全（网络配置 + 防火墙）→ 服务与自动化（systemd + Shell脚本）→ 总复习。顺序由依赖关系决定：先会操作终端、理解权限，才能管理用户和安装软件；软件装好后要联网，联网后要防护；服务跑起来后用脚本自动化运维。先「能操作」，再「能管理」，然后「能联网防护」，接着「能自动化」，最后「能贯通」。
</Answer>

**问题 2**：用「一台服务器从装好到上线」描述全书主线。

<Answer>
新装服务器：①命令行基础——终端操作 ls/cd/grep/管道重定向；②文件权限——rwx/UGO/chmod/setfacl 控制访问；③用户管理——useradd 创建用户、sudo 提权、SSH 密钥；④包管理——apt install nginx 安装服务；⑤网络配置——ip addr/netplan 配置 IP 和网关；⑥防火墙安全——ufw allow 22 放行 SSH、deny 3306 拒绝 MySQL 外网；⑦systemd 服务——systemctl enable nginx 开机自启；⑧Shell 脚本——自动化备份、日志清理、监控。八步串成从裸机到生产级运维的完整链路。
</Answer>
</Exercises>
