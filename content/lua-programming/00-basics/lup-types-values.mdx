## 直觉引入

在 Python 中你写 `x: int = 10`，变量 x 有类型 int。在 Lua 中你写 `local x = 10`——x 没有类型，10 有类型 number。你可以接着写 `x = "hello"`——x 现在指向一个 string。这不是"类型不安全"，而是"动态类型"：类型绑定在值上，不绑定在变量上。

Lua 只有 8 种类型：nil、boolean、number、string、function、table、userdata、thread。没有 int/float 之分（统一为 number），没有 list/dict/set 之分（统一为 table）。极简的类型系统，但足以构建任何复杂结构。

## 概念讲解

### 八种基本类型

<Term def="Lua 有 8 种基本类型：nil（缺失）、boolean（布尔）、number（数字）、string（字符串）、function（函数）、table（表）、userdata（C 数据）、thread（协程）。用 type() 返回类型名。">

```lua
print(type(nil))       -- nil
print(type(true))      -- boolean
print(type(3.14))      -- number
print(type("hi"))      -- string
print(type(print))     -- function
print(type({}))        -- table
print(type(coroutine.create(function() end)))  -- thread
```

</Term>

### 动态类型语义

```lua
local x = 10          -- x 指向 number
print(type(x))        -- number
x = "hello"           -- x 现在指向 string
print(type(x))        -- string
x = nil               -- x 不指向任何值
print(type(x))        -- nil
```

变量没有类型——它只是一个名字，可以指向任何类型的值。类型属于值本身。

### 真与假

<Term def="Lua 中只有 nil 和 false 为假，其余所有值（包括 0、空字符串、空表）都为真。这与许多语言不同。">

```lua
if 0 then print("0 is true!") end       -- 打印！0 是真
if "" then print("empty string true!") end  -- 打印！
if {} then print("empty table true!") end   -- 打印！
if nil then print("nil is true") else print("nil is false") end  -- nil is false
```

这在其他语言中是常见陷阱：C 中 0 为假，Python 中空容器为假。但 Lua 中只有 nil 和 false 为假。

</Term>

### table：唯一数据结构

```lua
-- 数组（索引从 1 开始！）
local arr = {10, 20, 30}
print(arr[1])     -- 10（不是 arr[0]）
print(#arr)       -- 3（长度运算符）

-- 字典
local dict = {name = "Alice", age = 20}
print(dict["name"])  -- Alice
print(dict.name)     -- Alice（语法糖）

-- 混合
local mixed = {1, 2, name = "Bob"}
print(mixed[1])      -- 1
print(mixed.name)    -- Bob
print(#mixed)        -- 2（只算数组部分）

-- 遍历
for i, v in ipairs(arr) do print(i, v) end    -- 遍历数组
for k, v in pairs(dict) do print(k, v) end    -- 遍历所有键值对
```

### string 不可变

```lua
local s = "hello"
local s2 = s .. " world"  -- .. 是连接运算符，创建新字符串
print(s)   -- hello（不变）
print(s2)  -- hello world

-- 字符串和数字自动转换
print("10" + 20)  -- 30（字符串转数字做算术）
print(10 .. 20)   -- "1020"（数字转字符串做连接）
```

<Step title="第一步：理解动态类型">

Lua 变量没有类型，值有类型。`local x = 10` 中 x 是变量名，10 是 number 类型的值。x 可以重新指向任何类型的值。用 `type(x)` 检查当前指向的值的类型。这与静态类型语言（C/Java）完全不同——变量不是类型的容器，而是值的标签。

</Step>

<Step title="第二步：掌握 table">

table 是 Lua 唯一的数据结构。用 `{}` 创建空表，`{1,2,3}` 创建数组（索引从 1 开始），`{name="A"}` 创建字典。`t[k]` 访问元素，`t.k` 是 `t["k"]` 的语法糖。`#t` 获取数组长度。`ipairs` 遍历数组部分，`pairs` 遍历所有键值对。

</Step>

<Step title="第三步：真值与转换">

只有 nil 和 false 为假——0、空字符串、空表都为真。字符串和数字在需要时自动转换：`"10" + 20` = 30（算术转数字），`10 .. 20` = "1020"（连接转字符串）。但建议显式转换（`tonumber`/`tostring`）避免意外。

</Step>

## 代码对照

```lua
-- 类型与值综合示例

-- 1. 动态类型
local function describe(val)
    local t = type(val)
    if t == "nil" then return "无值"
    elseif t == "boolean" then return val and "真" or "假"
    elseif t == "number" then return string.format("数字: %.2f", val)
    elseif t == "string" then return "字符串: " .. val
    elseif t == "table" then
        local count = 0
        for _ in pairs(val) do count = count + 1 end
        return "表（" .. count .. " 个字段）"
    elseif t == "function" then return "函数"
    else return t
    end
end

print(describe(nil))       -- 无值
print(describe(true))      -- 真
print(describe(3.14))      -- 数字: 3.14
print(describe("hello"))   -- 字符串: hello
print(describe({1, 2, 3})) -- 表（3 个字段）

-- 2. table 作为多种结构
-- 数组
local colors = {"red", "green", "blue"}
for i = 1, #colors do
    print(i, colors[i])
end

-- 字典
local config = {host = "localhost", port = 8080, debug = true}
for key, value in pairs(config) do
    print(key, "=", value)
end

-- 对象（table + 函数）
local counter = {
    count = 0,
    increment = function(self)
        self.count = self.count + 1
        return self.count
    end
}
print(counter:increment())  -- 1（冒号语法隐式传 self）
print(counter:increment())  -- 2
```

## 常见误区

<Callout type="trap">

**误区：Lua 数组索引从 0 开始**

Lua 数组索引从 1 开始，不是 0。`arr = {10, 20, 30}`，`arr[1]` 是 10，`arr[0]` 是 nil。`#arr` 和 `ipairs` 都假设从 1 开始的连续整数索引。如果你用 0 开始，`#arr` 和 `ipairs` 会返回意外结果。

</Callout>

<Callout type="trap">

**误区：认为 0 或空表为假**

Lua 中只有 nil 和 false 为假。0 为真、空字符串为真、空表为真。`if 0 then ... end` 会执行。如果你从 C/Python 过来，这会导致逻辑错误。检查"空"要用 `if x == nil` 或 `if #t == 0`，不能用 `if t then`。

</Callout>

<Exercises>

**问题 1**：以下代码输出什么？解释原因。

```lua
local x = 0
if x then
    print("true")
else
    print("false")
end
```

<Answer>

输出 `true`。

原因：Lua 中只有 nil 和 false 为假，其余所有值（包括 0）都为真。x = 0 是 number 类型的值 0，在条件判断中为真。这与 C 语言不同（C 中 0 为假），也和 Python 不同（Python 中 0 为假）。

如果要检查 x 是否为"零值"，需要显式比较：`if x ~= 0 then`。如果要检查变量是否已赋值，用 `if x ~= nil then`。

</Answer>

**问题 2**：Lua 的 `#` 运算符对 table 返回什么？有什么限制？

<Answer>

`#` 运算符返回 table 的"数组部分"长度——即从 1 开始的连续整数索引的个数。

```lua
print(#{10, 20, 30})      -- 3
print(#{10, 20, nil, 40}) -- 不确定！可能是 2 或 4
print(#{name="A"})         -- 0（没有数组部分）
```

限制：
1. **只算数组部分**：`#{name="A"}` 返回 0，因为字典字段不算数组长度
2. **遇到 nil 不确定**：如果数组中间有 nil（`{10, nil, 30}`），`#` 的返回值不确定——可能返回 nil 前的位置，也可能返回 nil 后的位置
3. **不适用于稀疏数组**：如果数组不连续，`#` 结果不可靠

正确做法：保持数组从 1 开始连续无 nil，需要字典长度时自己维护计数器或用 `pairs` 遍历计数。

</Answer>

</Exercises>
