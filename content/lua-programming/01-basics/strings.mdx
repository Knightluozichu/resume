## 从Byte Sequence开始，而不是从Character开始

Lua string是不可变byte sequence，可以包含任意bytes，包括zero byte；语言不自动附加UTF-8、locale或normalization。让同一type既能保存user text，也能保存network frame、compressed data或digest，但调用方必须知道当前value是哪一种。

先预测：`#"你好"`是2还是6；`string.sub`能否按汉字切；embedded zero是否截断；循环`result = result .. piece`是否原地扩容；内容相同的strings能否安全作table key。答案分别涉及byte length、byte index、binary safety、immutability与value equality。

String不可原地修改；concatenation、substitution和case conversion产生new value。Implementation可共享storage，但程序不能依赖identity。Equality按bytes，ordering也不是语言学collation。

## Literal Strings与Escape Contract

Single/double quoted literals处理newline、tab、quote、backslash、numeric byte等escape；Lua 5.3也可从Unicode code point产生UTF-8 bytes。Source encoding决定直接写入的non-ASCII bytes。Protocol fixture若要求exact bytes，应hex-assert而不是依赖editor normalization。

```lua
local quoted = "line one\nline two"
local unicode = "你好"
local binary = string.char(0x41, 0x00, 0x42)

assert(#quoted == 17)
assert(#unicode == 6) -- 两个code points，各3个UTF-8 bytes
assert(#binary == 3 and string.byte(binary, 2) == 0)
```

Embedded zero不会终止Lua string；传给NUL-terminated C API时却可能截断，必须用pointer+length contract。Quoted literal中的unknown escape应在load阶段失败，不能把syntax error变成运行时fallback。

## Long Strings与Levelled Delimiter

Long string使用`[[...]]`，内容不按普通escape处理；opening delimiter后的第一个newline可被忽略。若内容包含`]]`，增加等号level，例如`[=[...]=]`。也用于long comments。

不要用固定`[[`包裹任意user input生成source；输入可提前关闭literal并注入code。首选把data作为argument、environment value或serialized payload传给chunk。Long literal减少escaping，不等于sandbox。


## Coercions与Explicit Conversion Gate

Lua 5.3在部分arithmetic context可把numeric string转number，也可在concatenation中把number转string；隐式coercion易受版本、format和invalid input影响。`tonumber`、`tostring`、`string.format`更明确。避免large integer、NaN、locale decimal与trailing junk静默漂移。

`tostring`主要用于human-readable表示，不保证float round-trip或stable wire schema；`string.format`能控制base、precision与padding，但specifier必须匹配value representation。ID优先decimal integer text，money使用minor units或decimal policy。不要用`value .. ""`替代serialization。

## String Length与Byte Indexing Boundary

`#s`返回bytes；`string.sub(s,i,j)`使用inclusive byte positions，negative index从end计。要求API明确叫`byteOffset`、`codePointIndex`或`graphemeIndex`，不能统称character position。

Lua index从1开始。`string.byte`返回byte values，`string.char`从bytes构造string。对binary protocol这是正确工具；对Unicode text则使用`utf8`library或完整segmentation library。`string.sub("你好",1,1)`只取得第一个UTF-8 byte，不是“你”。

## The String Library

常用functions包括`len`、`rep`、`reverse`、`lower`、`upper`、`sub`、`byte`、`char`、`format`以及pattern functions。第10章再系统学习pattern。Method syntax `s:sub(2,4)`只是在调用时传入receiver，不会使string可变。

`lower`/`upper`不等于完整Unicode case folding；`reverse`按bytes会破坏multibyte text；`rep`要限制count；`string.dump`生成precompiled function bytes，不是portable data format。Format string若由untrusted input控制，也需要长度与specifier限制。


## Efficient Construction：Fragments再Concat

String immutable，循环append可能反复复制旧累计内容，形成quadratic bytes copied。把fragments放proper sequence，最后`table.concat`；large output则直接stream。Buffer owner要限制fragment count、total bytes和escaping，不能把untrusted input无限积在memory。

```lua
local function csv_line(fields)
  local out = {}
  for index, value in ipairs(fields) do
    local text = tostring(value)
    assert(not text:find('[",\r\n]'), "escaping omitted in fixture")
    out[index] = text
  end
  return table.concat(out, ",")
end

assert(csv_line({ "alpha", 42, true }) == "alpha,42,true")
```

真实CSV必须escape quotes/newlines；示例用assert暴露未实现边界。Sequence中的nil还会破坏length/concat assumptions。需要borrowed buffer或incremental writer时，lifetime与failure必须由caller/owner共同定义。

## Unicode：UTF-8 Library处理Code Points

Lua 5.3标准`utf8`library按UTF-8 code points工作：`utf8.len`计points并报告invalid byte，`utf8.codes`迭代position/value，`utf8.codepoint`解码，`utf8.char`编码，`utf8.offset`定位边界。不解决grapheme、normalization、case folding或display width。

Emoji modifier、combining mark与ZWJ sequence可能多个code points形成一个grapheme。UI cursor/delete与长度限制需要segmentation；database equality可能需要normalization/collation；terminal alignment需要display width。标准`utf8`library只是code-point层。


```lua
local function inspect_utf8(text)
  local count, invalid = utf8.len(text)
  if not count then return nil, { kind = "invalid-utf8", byte = invalid } end

  local points = {}
  for byte_offset, code_point in utf8.codes(text) do
    points[#points + 1] = { byte_offset, code_point }
  end
  return { bytes = #text, code_points = count, points = points }
end

local info = assert(inspect_utf8("A你好"))
assert(info.bytes == 7 and info.code_points == 3)
```


## External Boundary与Security

File/network/DB boundary固定encoding、BOM、invalid sequence、newline、size和normalization policy。Binary payload不做text normalization；text入口验证后才进入domain。Visually identical strings的bytes可能不同，identifier/confusable不能只lowercase。

C boundary始终携带pointer+length，避免NUL截断path、credential或payload。Pattern input、format string、repeat count和concat size都需要budget。String可保存任何bytes，不代表每个consumer都安全接受。

## 本章回顾：String是Bytes，Text是Contract

1. Lua string不可变且binary-safe，`#`与core indexes默认都是bytes。
2. Quoted literal处理escape；long bracket按matching level分隔，但不提供trust。
3. Numeric/text coercion要显式parse、range与format，display不是wire schema。
4. String library的sub/reverse/case不自动提供Unicode character semantics。
5. Fragments加`table.concat`减少重复复制；large output仍需stream和limit。
6. UTF-8 library处理code points；grapheme、normalization、case folding和display width另有责任层。
