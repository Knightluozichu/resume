## 直觉引入

运算符是语言的基本词汇。Python 的 `!=` 在 Lua 里是 `~=`，Python 的 `//` 在 Lua 里也是 `//`（向下取整除），但 Python 的 `and` 返回布尔值，Lua 的 `and` 返回操作数本身。这些细微差异是从其他语言迁移到 Lua 时的主要障碍。

Lua 的运算符体系体现了"少即是多"：没有自增自减（`++`/`--`），没有位运算符（5.3 前用函数），没有三元运算符（用 `and/or` 模拟）。但每种运算符都有明确的语义，组合起来足以表达任何逻辑。

## 概念讲解

### 算术运算符

<Term def="Lua 算术运算符：+ - * / // % ^。其中 // 是向下取整除，^ 是幂运算（不是位异或）。">

```lua
print(5 / 2)    -- 2.5  （普通除法，总是浮点）
print(5 // 2)   -- 2    （向下取整除）
print(-5 // 2)  -- -3   （向下取整，不是截断！）
print(5 % 2)    -- 1    （取模）
print(2 ^ 10)   -- 1024.0（幂运算，返回浮点）
```

注意：`^` 是幂运算，不是 C 语言的位异或。Lua 5.3 引入了整数子类型，但 `//` 总是向负无穷取整（向下取整），不是向零截断。

</Term>

### 关系运算符

```lua
print(1 ~= 2)   -- true  （~= 是不等于，不是 !=）
print(1 == 1.0) -- true  （数值比较不区分整数和浮点）
print("a" < "b") -- true （字符串按字典序比较）

-- table 按引用比较
local t1 = {}
local t2 = {}
print(t1 == t2)  -- false（不同对象）
print(t1 == t1)  -- true （同一对象）
```

### 逻辑运算符与短路求值

<Term def="Lua 的 and/or 返回操作数本身而非布尔值。and 返回第一个假值或最后一个值，or 返回第一个真值或最后一个值。这可以模拟三元表达式。">

```lua
-- and：如果第一个为假，返回第一个；否则返回第二个
print(nil and 1)    -- nil
print(false and 1)  -- false
print(2 and 3)      -- 3（2 为真，返回第二个）

-- or：如果第一个为真，返回第一个；否则返回第二个
print(nil or 1)     -- 1
print(false or 1)   -- 1
print(2 or 3)       -- 2（2 为真，返回第一个）

-- 惯用法1：默认值
local name = playerName or "Guest"

-- 惯用法2：三元表达式模拟
local max = (a > b) and a or b
-- 注意：如果 a 为 false/nil，这个模式会出错
```

</Term>

### 字符串连接与长度

```lua
local s = "Hello" .. " " .. "World"  -- .. 连接
print(s)  -- Hello World

-- 数字自动转字符串
print(10 .. 20)  -- "1020"

-- 长度运算符 #
print(#"hello")  -- 5
print(#{1, 2, 3})  -- 3
```

### table 构造器

```lua
-- 数组风格
local arr = {10, 20, 30}

-- 字典风格
local dict = {name = "Alice", age = 20}

-- 混合
local mixed = {10, 20, name = "Bob", [5] = "five"}

-- 记录风格（最后一项可以是函数调用或可变参数）
local funcs = {
    function() return 1 end,
    function() return 2 end,
}
```

Lua 的 `//` 是向下取整除（向负无穷取整，不是向零截断）。`^` 是幂运算（不是位异或）。`~=` 是不等于（不是 `!=`）。数值比较不区分整数和浮点（`1 == 1.0` 为 true）。table 按引用比较——两个空表不相等。

<Step title="第二步：逻辑运算符短路求值">

`and` 返回第一个假值或最后一个值，`or` 返回第一个真值或最后一个值。不是返回 true/false！惯用法：`x or default` 设默认值，`(cond) and a or b` 模拟三元表达式。注意后者在 a 为 false/nil 时会出错。

</Step>

<Step title="第三步：连接、长度与 table 构造">

`..` 连接字符串（数字自动转字符串）。`#` 获取字符串长度或 table 数组部分长度。`{}` 构造 table——数组风格（逗号分隔）、字典风格（`key = value`）、混合风格。`[expr] = value` 允许任意键。

</Step>

## 代码对照

```lua
-- 表达式综合示例：字符串处理工具

local function format_name(first, last)
    -- and/or 惯用法：默认值
    first = first or "Unknown"
    last = last or ""

    -- .. 连接字符串
    if last == "" then
        return first
    else
        return first .. " " .. last
    end
end

local function clamp(value, min, max)
    -- 三元表达式模拟
    value = (value < min) and min or value
    value = (value > max) and max or value
    return value
end

local function split(s, sep)
    -- 使用 # 和字符串操作
    local result = {}
    local start = 1
    local sep_len = #sep

    while true do
        local pos = string.find(s, sep, start, true)
        if not pos then
            table.insert(result, string.sub(s, start))
            break
        end
        table.insert(result, string.sub(s, start, pos - 1))
        start = pos + sep_len
    end

    return result
end

-- 使用
print(format_name("Alice", "Smith"))  -- Alice Smith
print(format_name(nil, "Jones"))      -- Unknown Jones
print(clamp(15, 0, 10))               -- 10
print(clamp(-5, 0, 10))               -- 0

local parts = split("a,b,c,d", ",")
for i, v in ipairs(parts) do
    print(i, v)  -- 1 a / 2 b / 3 c / 4 d
end
```

## 常见误区

<Callout type="trap">

**误区：用 != 而非 ~= 表示不等于**

Lua 用 `~=` 表示不等于，不是 `!=`。这是从 C/Python/Java 迁移时最常见的语法错误。`~` 在 Lua 中是"非"的语义（`~=` = 不等于，5.3 后 `~` 也是位异或运算符）。

</Callout>

<Callout type="trap">

**误区：(cond) and a or b 在 a 为 false/nil 时出错**

`max = (a > b) and a or b` 在 a 为 false/nil 时会返回 b 即使 a > b。因为 `and` 返回 false，然后 `false or b` 返回 b。解决方案：确保 a 不为 false/nil，或用 if-else 代替。Lua 5.3 没有三元运算符——复杂条件用 if-else 更安全。

</Callout>

<Exercises>

**问题 1**：以下代码输出什么？

```lua
print(5 // 2)
print(-5 // 2)
print(2 and 3)
print(nil or "default")
```

<Answer>

```
2
-3
3
default
```

解释：
- `5 // 2` = 2：向下取整除
- `-5 // 2` = -3：向下取整是向负无穷取整，-2.5 向下 = -3（不是截断为 -2）
- `2 and 3` = 3：and 返回第一个假值或最后一个值。2 为真，返回第二个值 3
- `nil or "default"` = "default"：or 返回第一个真值或最后一个值。nil 为假，返回第二个值 "default"

</Answer>

**问题 2**：为什么 `(a > b) and a or b` 在 a = nil 时会出错？如何安全地实现求最大值？

<Answer>

问题：当 a = nil 时，`a > b` 可能报错（nil 与数字比较）。即使不报错（假设 a = false），`false and a` = false，然后 `false or b` = b——即使 a 应该是"真"的情况也返回 b。

更准确地说，惯用法 `(cond) and a or b` 要求 a 不为假值。如果 a 可能是 false 或 nil，这个模式会失败：`(true) and nil or b` = `nil or b` = b——即使条件为真也返回 b。

安全方案：
```lua
-- 方案1：用 if-else（最安全）
local max
if a > b then max = a else max = b end

-- 方案2：确保 a 不为假值时才用 and/or
-- 如果确定 a 和 b 都是数字，可以用：
local max = (a > b) and a or b  -- a 和 b 都是数字，不会为 false/nil
```

</Answer>

</Exercises>
