## 直觉引入

如果说表达式是词汇，语句就是句子。你用语句组织程序的逻辑流——做判断（if）、重复执行（循环）、声明变量（local）、提前退出（break/return）。

Lua 的语句设计有两个显著特点：第一，变量默认全局，必须用 `local` 声明局部——这和大多数语言相反。第二，没有 `continue`、没有 `switch`、没有 `++`——极简主义。这些"缺失"不是缺陷，而是"提供机制而非策略"哲学的体现。需要 continue？用 `goto` 或重构逻辑。需要 switch？用 table 查找。

## 概念讲解

### local 声明

<Term def="Lua 变量默认全局——必须用 local 声明局部变量。局部变量更快（数组访问 vs 哈希查找），且不污染全局环境。">

```lua
-- 全局变量（慎用！）
count = 0           -- 没有 local，是全局变量

-- 局部变量（推荐）
local name = "Alice"
local x, y = 10, 20 -- 多重赋值

-- local 限定作用域
do
    local temp = compute()
    process(temp)
end
-- temp 在 do...end 外不可访问
```

</Term>

### if-elseif-else

```lua
local score = 85

if score >= 90 then
    grade = "A"
elseif score >= 80 then
    grade = "B"
elseif score >= 70 then
    grade = "C"
else
    grade = "F"
end
```

注意：Lua 用 `then` 而非花括号开始 if 块，用 `end` 结束。`elseif` 是一个词（不是 `else if`）。

### 循环

```lua
-- while：先判断后执行
local i = 1
while i <= 5 do
    print(i)
    i = i + 1       -- Lua 没有 ++，必须写 i = i + 1
end

-- repeat-until：先执行后判断（至少执行一次）
repeat
    input = io.read()
until input == "quit"

-- 数值 for：已知范围
for i = 1, 10 do       -- 1 到 10，步进 1
    print(i)
end
for i = 10, 1, -1 do   -- 10 到 1，步进 -1
    print(i)
end
for i = 0, 10, 2 do    -- 0 到 10，步进 2
    print(i)
end

-- 泛型 for：遍历迭代器
local t = {10, 20, 30}
for i, v in ipairs(t) do    -- 遍历数组部分
    print(i, v)
end
for k, v in pairs(t) do     -- 遍历所有键值对
    print(k, v)
end
```

### break 与 return

```lua
-- break：跳出最内层循环
for i = 1, 100 do
    if found(i) then
        break
    end
end

-- return：从函数返回
local function find(t, target)
    for i, v in ipairs(t) do
        if v == target then
            return i  -- 找到就返回
        end
    end
    return nil  -- 没找到
end

-- 注意：return 必须是块的最后一条语句
-- 如果需要在 do...end 中间 return，用 do return end
```

### goto（Lua 5.2+）

```lua
-- Lua 没有 continue，但可以用 goto 模拟
for i = 1, 10 do
    if i % 2 == 0 then
        goto continue  -- 跳过偶数
    end
    print(i)
    ::continue::       -- 标签
end
```

<Step title="第一步：local 声明与作用域">

Lua 变量默认全局——这是最大的陷阱。所有变量都应该用 `local` 声明：局部变量更快（编译为寄存器/数组访问），不污染全局环境，作用域更清晰。用 `do...end` 创建显式作用域块，限制临时变量的可见范围。

</Step>

<Step title="第二步：if-elseif-else 条件分支">

if 用 `then` 开始块，`end` 结束。`elseif` 是一个词（不是 `else if`）。Lua 没有 switch 语句——用 table 查找或 if-elseif 链替代。条件中只有 nil 和 false 为假。

</Step>

<Step title="第三步：for 循环两种形式">

数值 for：`for i = start, stop, step do ... end`。循环变量 i 是每次迭代创建的新局部变量，修改不影响循环。泛型 for：`for k, v in pairs/ipairs(t) do ... end`。ipairs 遍历数组部分（遇到 nil 停止），pairs 遍历所有键值对（顺序不确定）。

</Step>

</Stepper>

## 代码对照

```lua
-- 语句综合示例：简易命令行计算器

local function calculate(op, a, b)
    -- 用 table 模拟 switch
    local operations = {
        add = function(x, y) return x + y end,
        sub = function(x, y) return x - y end,
        mul = function(x, y) return x * y end,
        div = function(x, y)
            if y == 0 then
                return nil, "除以零"
            end
            return x / y
        end,
        mod = function(x, y) return x % y end,
        pow = function(x, y) return x ^ y end,
    }

    -- table 查找替代 switch
    local fn = operations[op]
    if not fn then
        return nil, "未知操作: " .. op
    end

    return fn(a, b)
end

-- 主循环
print("计算器（输入 quit 退出）")
while true do
    io.write("> ")
    local input = io.read()
    if input == "quit" or input == nil then
        break
    end

    -- 解析输入
    local op, a, b = input:match("(%a+)%s+(%d+)%s+(%d+)")
    if not op then
        print("格式: op num1 num2（如 add 3 4）")
        -- goto 模拟 continue（Lua 没有 continue）
        goto next
    end

    local result, err = calculate(op, tonumber(a), tonumber(b))
    if result then
        print(string.format("%s %s %s = %g", a, op, b, result))
    else
        print("错误: " .. (err or "未知"))
    end

    ::next::
end

print("再见！")
```

## 常见误区

<Callout type="trap">

**误区：忘记 local 导致全局变量泄漏**

`x = 10` 在 Lua 中创建全局变量，不是局部变量。忘记 local 是最常见的 Lua bug：全局变量被意外覆盖，性能下降（全局访问通过哈希表查找），代码难以维护。规则：所有变量都用 local 声明，除非确实需要全局。用 `lua -e` 或 luacheck 工具检测未声明的全局变量。

</Callout>

<Callout type="trap">

**误区：在数值 for 循环中修改循环变量**

`for i = 1, 10 do i = i + 5 end` 不会跳过迭代——Lua 的 for 循环变量是每次迭代创建的新局部变量。修改它不影响下一次迭代的值。如果需要自定义步进，用 while 循环。

</Callout>

<Exercises>

**问题 1**：以下代码输出什么？解释 for 循环变量的行为。

```lua
for i = 1, 3 do
    i = i + 10
    print(i)
end
```

<Answer>

输出：
```
11
12
13
```

解释：Lua 数值 for 循环的变量 i 是每次迭代创建的**新的局部变量**。在循环体内修改 i（`i = i + 10`）只影响当前迭代的局部变量——下一次迭代时 i 会被重新赋值为循环计数器的下一个值。

所以三次迭代中 i 分别被设为 1+10=11、2+10=12、3+10=13。循环仍然执行 3 次（1 到 3），修改循环变量不会改变迭代次数或步进。

如果需要根据条件跳过某些值或自定义步进，应该用 while 循环。

</Answer>

**问题 2**：Lua 没有 continue 语句。给出两种模拟 continue 的方法。

<Answer>

方法1：使用 goto（Lua 5.2+）
```lua
for i = 1, 10 do
    if i % 2 == 0 then
        goto continue  -- 跳到标签
    end
    print(i)           -- 只打印奇数
    ::continue::       -- 标签定义
end
```

方法2：使用 if-else 结构
```lua
for i = 1, 10 do
    if i % 2 ~= 0 then
        print(i)       -- 只打印奇数
    end
    -- else 分支什么都不做，等价于 continue
end
```

方法3（某些场景）：将循环体提取为函数，用 return 模拟 continue
```lua
local function process(i)
    if i % 2 == 0 then return end  -- 等价于 continue
    print(i)
end
for i = 1, 10 do
    process(i)
end
```

推荐：简单条件用 if-else，复杂逻辑用 goto。goto 是 Lua 5.2 引入的，跳转到标签只能在同一作用域内，且不能跳入局部变量作用域。

</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="local 声明">

Lua 变量默认全局，必须用 local 声明局部变量。局部变量更快（寄存器/数组访问），不污染全局环境。`local x = 10` 声明局部变量，`local x, y = 1, 2` 多重赋值。用 do...end 创建显式作用域。

</GlossaryItem>

<GlossaryItem term="if-elseif-else">

条件分支结构。用 `then` 开始块（不是花括号），`end` 结束。`elseif` 是一个词。Lua 没有 switch 语句——用 table 查找或 if-elseif 链替代。条件中只有 nil 和 false 为假。

</GlossaryItem>

<GlossaryItem term="数值 for">

`for i = start, stop, step do ... end`。循环变量 i 是每次迭代的新局部变量，修改不影响循环。step 可省略（默认 1），可为负数。适合已知范围的迭代。

</GlossaryItem>

<GlossaryItem term="泛型 for">

`for k, v in pairs(t) do ... end` 或 `for i, v in ipairs(t) do ... end`。ipairs 遍历数组部分（从 1 开始，遇到 nil 停止）。pairs 遍历所有键值对（顺序不确定）。适合遍历 table。

</GlossaryItem>

</Glossary>
