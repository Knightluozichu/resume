## 线性模型概述

线性模型是机器学习最基础的模型，形式简单、可解释性强，是理解更复杂模型的起点。基本形式：

```text
f(x) = w^T x + b
```

其中 `w` 是权重向量，`b` 是偏置。线性模型试图学得一个通过属性的线性组合进行预测的函数。

## 线性回归

线性回归试图让预测值 `f(x)` 逼近真实值 `y`，用最小二乘法最小化均方误差：

```text
min_w  Σ(yi - w^T xi)²
```

将目标函数写成矩阵形式 `E = ||y - Xw||²`，对 `w` 求导并令为零，得到闭式解：

```text
w* = (X^T X)^{-1} X^T y
```

<Callout type="info">

**条件**：当 `X^T X` 可逆（满秩）时才有闭式解。若存在多重共线性（属性间高度相关），`X^T X` 不可逆，需引入正则化（岭回归）或用伪逆求解。

</Callout>

### 广义线性模型

通过联系函数 `g(·)` 将线性模型推广到非线性空间：

```text
y = g^{-1}(w^T x + b)
```

选择不同的联系函数可得到不同的模型——对数几率回归就是联系函数取 Sigmoid 的特例。

## 对数几率回归（逻辑回归）

### 从回归到分类

对于二分类任务，输出需为离散标签（0 或 1）。选择 Sigmoid 函数将线性模型输出映射到 `(0,1)` 区间作为概率估计：

```text
σ(z) = 1 / (1 + e^{-z})
```

对数几率（logit）形式：

```text
ln(p/(1-p)) = w^T x + b
```

即输出概率的对数几率是输入的线性函数。

### 参数估计

用极大似然法估计参数，最大化对数似然：

```text
max  Σ [yi ln σ(zi) + (1-yi) ln(1-σ(zi))]
```

由于没有闭式解，用梯度下降迭代求解：

```text
w ← w + η X^T (y - σ(Xw))
```

<Callout type="tip">

**名字由来**：「对数几率回归」中「回归」是因为它本质是对概率的回归，但实际用于分类。它是工业界最常用的二分类基线模型之一。

</Callout>

## 线性判别分析（LDA）

LDA 的核心思想：将数据投影到一条直线上，使得**同类样本投影点尽可能近、异类样本投影点尽可能远**。

### 散度矩阵

- **类内散度矩阵** `Sw`：各类内部样本到类均值的散度之和
- **类间散度矩阵** `Sb`：两类均值之间的散度

### 目标函数

```text
max  J = (w^T Sb w) / (w^T Sw w)
```

利用拉格朗日乘子法，转化为广义特征值问题 `Sb w = λ Sw w`。多分类推广时可找到 `C-1` 个投影方向。

## 多分类学习

将二分类推广到多分类的两种经典策略：

| 策略 | 分类器数量 | 预测方式 | 特点 |
|------|-----------|---------|------|
| 一对一（OvO） | `N(N-1)/2` | 投票 | 存储大但每个训练数据少 |
| 一对多（OvR） | `N` | 取置信度最高者 | 效率高但类别不平衡 |

## 类别不平衡问题

当正负样本比例悬殊时（如 `m+` 远小于 `m-`），分类阈值 `0.5` 不再适用。

**再缩放策略**：

```text
y'/(1-y') = (y/(1-y)) × (m⁻/m⁺)
```

将决策阈值从 `0.5` 调整为 `m⁺/(m⁺+m⁻)`。实际方法还包括：欠采样、过采样（SMOTE）、代价敏感学习。

<GlossaryItem term="线性模型">
通过属性的线性组合进行预测的模型：f(x) = w^T x + b。形式简单、可解释，是 ML 的基础。通过联系函数可推广为广义线性模型。

<GlossaryItem term="最小二乘法">
线性回归的参数估计方法，最小化均方误差 Σ(yi - f(xi))²。当 X^T X 可逆时有闭式解 w* = (X^T X)^{-1} X^T y。
</GlossaryItem>

<GlossaryItem term="对数几率回归（逻辑回归）">
用 Sigmoid 函数将线性模型映射为概率的二分类方法。对数几率 ln(p/(1-p)) = w^T x + b 是输入的线性函数。参数用极大似然估计 + 梯度下降求解。
</GlossaryItem>

<GlossaryItem term="线性判别分析（LDA）">
通过最大化类间散度与类内散度之比来寻找最优投影方向的分类方法。目标函数 max (w^T Sb w)/(w^T Sw w)，转化为广义特征值问题求解。也可用于降维。
</GlossaryItem>

<GlossaryItem term="广义线性模型">
通过联系函数 g(·) 将线性模型 w^T x + b 映射到非线性空间的模型：y = g^{-1}(w^T x + b)。逻辑回归是其特例（g 为 logit 函数）。
</GlossaryItem>

<GlossaryItem term="类别不平衡">
正负样本比例悬殊时，分类阈值需调整。再缩放策略将阈值从 0.5 调整为 m⁺/(m⁺+m⁻)，或用欠采样/过采样/代价敏感学习处理。
</GlossaryItem>

### 问题 1

什么是线性模型？请推导线性回归的最小二乘法闭式解。

<Answer>

线性模型试图学得一个通过属性的线性组合进行预测的函数：f(x) = w^T x + b，其中 w 是权重向量，b 是偏置。线性回归试图让预测值 f(x) 逼近真实值 y，用最小二乘法最小化均方误差：min_w Σ(yi - w^T xi)²。将目标函数写成矩阵形式：E = ||y - Xw||² = (y-Xw)^T(y-Xw)。对 w 求导并令其为零：dE/dw = -2X^T(y-Xw) = 0 → X^T X w = X^T y。当 X^T X 可逆（满秩）时，闭式解为 w* = (X^T X)^&#123;-1&#125; X^T y。如果 X^T X 不可逆（多重共线性），可引入正则化或用伪逆求解。

</Answer>

### 问题 2

对数几率回归（逻辑回归）是如何从线性回归推广到分类任务的？请说明其核心思想。

<Answer>

对数几率回归（Logistic Regression）将线性回归推广到二分类任务。核心思想：①对于分类任务，输出需为离散标签，但线性回归的输出是连续值，需通过单调可微函数将线性模型输出映射到 [0,1] 区间；②选择 Sigmoid 函数 σ(z) = 1/(1+e^&#123;-z&#125;) 作为联系函数，将线性模型 w^T x + b 的输出转为概率估计；③对数几率（logit）：ln(p/(1-p)) = w^T x + b，即输出概率的对数几率是输入的线性函数；④参数估计用极大似然法：最大化 L = Σ[yi ln σ(zi) + (1-yi) ln(1-σ(zi))]；⑤由于没有闭式解，用梯度下降（或牛顿法）迭代求解：w ← w + η X^T(y - σ(Xw))。名字中的「回归」是因为它本质是对概率的回归，实际用于分类。

</Answer>

### 问题 3

什么是线性判别分析（LDA）？其目标函数和求解方法是什么？

<Answer>

线性判别分析（LDA）是一种经典的线性分类方法，核心思想是「投影后类内散度小、类间散度大」。定义类内散度矩阵 Sw = Σ Σ(x-μi)(x-μi)^T（各类内部样本到类均值的散度之和），类间散度矩阵 Sb = (μ1-μ2)(μ1-μ2)^T（两类均值之间的散度）。LDA 的目标是找到一个投影方向 w，使得投影后类间散度与类内散度的比值最大：max J = (w^T Sb w)/(w^T Sw w)。利用拉格朗日乘子法，该优化问题转化为广义特征值问题 Sb w = λ Sw w，解为 w = Sw^&#123;-1&#125;(μ1-μ2)（二分类时）。多分类推广时，Sb 推广为全局散度减去类内散度，最多可找到 C-1 个投影方向（C 为类别数）。LDA 也可用于降维——将高维数据投影到低维空间，同时保持类别区分性。

</Answer>

### 问题 4

多分类学习和类别不平衡问题如何处理？请说明常见策略。

<Answer>

多分类学习策略（将二分类推广到多分类）：①一对一（OvO）：将 N 个类别两两配对，训练 N(N-1)/2 个二分类器，预测时投票，存储开销大但训练每个分类器的数据少；②一对多（OvR）：每次将一个类作为正类、其余作为负类，训练 N 个二分类器，预测时取置信度最高者，训练效率高但类别不平衡；③多对多（MvM）：将若干类作为正类、若干类作为负类，常用纠错输出码（ECOC）编码。类别不平衡问题处理：当正负样本比例悬殊时（如 m+ 远小于 m-），分类阈值 0.5 不再适用。再缩放策略：将决策阈值从 0.5 调整为 m+/(m++m-)，等价于 y'/(1-y') = (y/(1-y)) × (m-/m+)。实际方法还包括：欠采样（去除多数类样本）、过采样（增加少数类样本如 SMOTE）、阈值移动、代价敏感学习。

</Answer>
