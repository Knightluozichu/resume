## 决策树概述

决策树是一种基于树结构进行决策的算法，每个内部节点测试一个属性，每个分支代表一个属性测试结果，每个叶节点代表一个类别。决策树学习的核心是**递归地选择最优划分属性**，将训练集分割为越来越纯的子集。

## 基本流程

```text
1. 若当前样本全部属于同一类 → 标记为叶节点（该类）
2. 若属性集为空或样本在属性上取值相同 → 标记为叶节点（多数类）
3. 选择最优划分属性 a*，按 a* 的取值划分子集
4. 对每个子集递归调用决策树学习
```

## 划分选择准则

### 信息增益（ID3）

信息熵衡量数据集 `D` 的纯度：

```text
Ent(D) = -Σ pk log2 pk    （pk 为第 k 类样本占比，Ent 越小纯度越高）
```

用属性 `a` 划分后的信息增益：

```text
Gain(D,a) = Ent(D) - Σ |Dv|/|D| Ent(Dv)
```

选择信息增益最大的属性。但信息增益偏好取值数多的属性（取值越多越容易分纯）。

### 增益率（C4.5）

用固有值 `IV(a)` 惩罚取值数多的属性：

```text
Gain_ratio(D,a) = Gain(D,a) / IV(a)
IV(a) = -Σ |Dv|/|D| log2(|Dv|/|D|)
```

C4.5 先找出信息增益高于平均水平的属性，再从中选增益率最高的。

### 基尼指数（CART）

基尼值衡量纯度，越小越纯：

```text
Gini(D) = 1 - Σ pk²
Gini_index(D,a) = Σ |Dv|/|D| Gini(Dv)
```

CART 选基尼指数最小的属性，且每次只做二分（生成二叉树）。

<Callout type="info">

**对比**：信息增益偏好取值多的属性，增益率偏好取值少的属性（C4.5 用启发式折中），基尼指数与信息熵趋势相似但计算更简单（无需对数运算）。CART 的二分策略使其能复用属性。

</Callout>

## 剪枝

剪枝是决策树对付过拟合的主要手段。

| 策略 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| 预剪枝 | 划分前评估，无提升则停止 | 训练快、树小 | 可能欠拟合（贪心） |
| 后剪枝 | 先建完整树，自底向上回溯 | 欠拟合风险小 | 训练开销大 |

<Callout type="tip">

**实际选择**：后剪枝的泛化性能通常优于预剪枝，但计算开销更大。在计算资源充足时优先选后剪枝。

</Callout>

## 连续值与缺失值处理

### 连续值处理（C4.5）

将连续属性排序，取相邻值的中点作为候选划分点，选择信息增益最大的点。连续属性可在不同层被重复使用（每次取不同阈值）。

### 缺失值处理（C4.5）

- **属性选择时**：只用非缺失样本计算信息增益，并按非缺失比例缩放
- **样本分配时**：缺失样本按各子集比例同时分配到所有子节点，赋予权重

## CART 算法

CART（Classification and Regression Tree）是二叉树，既可分类也可回归：

- 分类树：用基尼指数选择划分
- 回归树：用平方误差最小化选择划分

### 问题 1

决策树学习的基本流程是什么？信息增益如何用于划分选择？

<Answer>

决策树学习的基本流程是递归地选择最优划分属性，将训练集分割为子集，直到子集全部属于同一类或没有可用属性为止。信息增益用于 ID3 算法的划分选择：①信息熵 Ent(D) = -Σ pk log2 pk 衡量数据集 D 的纯度，pk 为第 k 类样本占比，Ent 越小纯度越高；②用属性 a 对 D 划分后，各子集的加权信息熵为 Σ |Dv|/|D| Ent(Dv)；③信息增益 Gain(D,a) = Ent(D) - Σ |Dv|/|D| Ent(Dv)，表示用属性 a 划分后纯度提升的程度；④选择信息增益最大的属性作为当前节点的划分属性。信息增益越大，意味着用该属性划分后数据集纯度提升越多。但信息增益对取值数多的属性有偏好（取值越多越容易「分纯」），C4.5 用增益率修正此问题。

</Answer>

### 问题 2

C4.5 的增益率和 CART 的基尼指数分别如何解决信息增益的缺陷？

<Answer>

信息增益偏好取值数多的属性（极端情况下，ID 属性的信息增益最大但无泛化能力）。C4.5 增益率修正：①定义固有值 IV(a) = -Σ |Dv|/|D| log2(|Dv|/|D|)，属性取值数越多 IV 越大；②增益率 Gain_ratio(D,a) = Gain(D,a) / IV(a)，用固有值惩罚取值数多的属性；③C4.5 不是直接选增益率最大的属性，而是先从候选属性中找出信息增益高于平均水平的，再从中选增益率最高的，避免增益率对取值数少的属性偏好的反转。CART 基尼指数：①基尼值 Gini(D) = 1 - Σ pk² 衡量纯度，越小越纯（直观含义是从 D 中随机抽两个样本类别不同的概率）；②基尼指数 Gini_index(D,a) = Σ |Dv|/|D| Gini(Dv)；③CART 选基尼指数最小的属性划分，且每次只做二分（而非多分），因此 CART 生成的是二叉树。基尼指数与信息熵趋势相似但计算更简单（无需对数运算）。

</Answer>

### 问题 3

什么是决策树剪枝？预剪枝和后剪枝各有什么优缺点？

<Answer>

剪枝是决策树对付过拟合的主要手段。决策树生成过程中会不断分支以拟合训练数据，分支过多导致过拟合——树太深，学到了训练集的噪声。预剪枝（Pre-pruning）：在决策树生成过程中，对每个节点在划分前先进行评估，若当前节点的划分不能带来泛化性能提升（用验证集评估），则停止划分并将当前节点标记为叶节点。优点：训练快、树小。缺点：基于贪心策略，有些分支当前划分无提升但后续划分可能有提升，导致欠拟合。后剪枝（Post-pruning）：先从训练集生成一棵完整的决策树，然后自底向上考察非叶节点，若将该节点对应的子树替换为叶节点能带来泛化性能提升，则替换。优点：欠拟合风险小，泛化性能通常优于预剪枝。缺点：训练开销大（需生成完整树再回溯）。实际中后剪枝更常用。

</Answer>

### 问题 4

决策树如何处理连续值属性和缺失值？CART 的连续值处理与离散值有何不同？

<Answer>

连续值处理（C4.5 采用）：①将连续属性 a 的取值排序，取相邻值的中点作为候选划分点 t；②对每个候选点 t，将样本分为 a≤t 和 a>t 两组，计算信息增益；③选择信息增益最大的划分点。连续属性在决策树中可在不同层被重复使用（每次取不同阈值），而离散属性在一条路径上只使用一次。缺失值处理（C4.5 采用）：①属性选择（划分时）——计算信息增益时，只用该属性非缺失的样本，并将结果乘以非缺失样本占比进行缩放；②样本划分（分配时）——对于属性缺失的样本，按各子集样本数的比例将其同时分配到所有子节点，并赋予相应权重。CART 对连续值也是二分处理，对离散值也做二分编码，统一用基尼指数选择最优划分。CART 的连续值处理与 C4.5 类似，但每次只做二分裂。

</Answer>
