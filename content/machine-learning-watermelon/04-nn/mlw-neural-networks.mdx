## 神经网络概述

神经网络是从生物神经系统启发而来的计算模型。基本单元是神经元（M-P 模型），多个神经元分层连接组成网络。神经网络的核心优势是**万能逼近定理**——含一个隐层的前馈网络可以逼近任意连续函数。

<MlwNeuralNetworksDiagram />

## M-P 神经元模型

每个神经元接收多个输入 `xi`，每个输入带权重 `wi`，计算加权求和后减去阈值 `θ`，再通过激活函数 `f` 输出：

```text
y = f(Σ wi·xi - θ)
```

## 感知机

感知机是单层神经元，只有输入层和输出层（无隐层），使用 `sign` 阶跃函数：

```text
f(x) = sign(w^T x + b)
```

权重更新规则：

```text
w ← w + η(y - ŷ)x
```

<Callout type="warning">

**局限性**：感知机仅对线性可分数据保证收敛，无法解决 XOR（异或）等非线性问题。这导致了第一次 AI 寒冬。

</Callout>

## 多层前馈网络

在输入层和输出层之间加入一个或多个**隐层**，每层神经元全互连但同层不连接、不跨层连接。

```text
输入层 → 隐层（激活函数） → 输出层（激活函数）

前向传播：
  h = f(W1·x + b1)       # 隐层
  ŷ = f(W2·h + b2)       # 输出层
```

### 万能逼近定理

含一个隐层的前馈网络，只要有足够多的隐层神经元，可以以任意精度逼近任意连续函数。这保证了神经网络的理论表达能力。

## BP 误差逆传播算法

BP 是训练多层神经网络的核心算法，用**链式法则**从输出层向输入层逐层计算梯度。

### 完整流程

```text
1. 前向传播：输入经隐层到输出层，计算各层激活值和预测输出
2. 计算误差：E = 1/2 Σ(yj - ŷj)²
3. 反向传播：
   输出层误差项：δj = ŷj(1-ŷj)(yj - ŷj)
   隐层误差项：  δh = fh(1-fh) Σ w_hj·δj
4. 参数更新：
   w_hj ← w_hj + η·δj·h
   v_ih ← v_ih + η·δh·xi
5. 重复 1-4 直到收敛
```

<Callout type="info">

**标准 BP vs 累积 BP**：标准 BP 每次用一个样本更新参数（在线学习），更新频繁但可能震荡；累积 BP 用整个数据集的累积误差更新（批量学习），更稳定但收敛慢。

</Callout>

## 激活函数

| 激活函数 | 公式 | 优点 | 缺点 |
|---------|------|------|------|
| Sigmoid | `σ(z) = 1/(1+e^{-z})` | 平滑可导，输出概率 | 梯度消失（最大 0.25），非零中心 |
| Tanh | `tanh(z)` | 零中心化 | 仍有梯度消失 |
| ReLU | `max(0, z)` | 正区间导数 1，计算简单 | Dead ReLU（负区间梯度为 0） |
| Leaky ReLU | `max(αz, z)` | 解决 Dead ReLU | 需调 α |

<Callout type="tip">

**选择建议**：隐层多用 ReLU 及其变体（缓解梯度消失），输出层根据任务选择——二分类用 Sigmoid，多分类用 Softmax，回归用线性。

</Callout>

## 训练挑战

- **过拟合**：正则化、Dropout、早停
- **局部最优**：多次随机初始化、动量法、自适应学习率
- **梯度消失/爆炸**：ReLU、批归一化、残差连接

### 问题 1

什么是 M-P 神经元模型？感知机与多层前馈神经网络有什么区别？

<Answer>

M-P 神经元模型：接收多个输入 xi，每个输入带权重 wi，计算加权求和后减去阈值 θ，再通过激活函数 f 输出：y = f(Σ wi·xi - θ)。激活函数常用 Sigmoid（将输出压缩到 (0,1)）。感知机是单层神经元，只有输入层和输出层（无隐层），使用 sign 阶跃函数，本质是线性分类器 f(x) = sign(w^T x + b)。感知机仅对线性可分数据保证收敛，无法解决 XOR 等非线性问题。多层前馈神经网络：在输入层和输出层之间加入一个或多个隐层，每层神经元全互连但同层不连接、不跨层连接。隐层的存在使网络能拟合非线性函数（万能逼近定理）。信号前向传播：输入经隐层到输出层逐层计算。多层网络的训练用 BP 算法（误差逆传播），通过链式法则反向计算梯度更新权重。

</Answer>

### 问题 2

请详细描述 BP 误差逆传播算法的完整流程。

<Answer>

BP 算法完整流程：①前向传播——输入 x 经隐层计算 h = f(W1·x + b1)，再经输出层计算 ŷ = f(W2·h + b2)，其中 f 是激活函数（如 Sigmoid）。②计算误差——对输出层第 j 个神经元，误差项 δj = ŷj(1-ŷj)(yj - ŷj)（Sigmoid 的导数形式），其中 yj 是真实标签。③反向传播——隐层第 h 个神经元的误差项 δh = fh(1-fh) Σ w_hj·δj，即用输出层误差的加权和乘以隐层激活函数的导数。④参数更新——输出层权重 w_hj ← w_hj + η·δj·h，隐层权重 v_ih ← v_ih + η·δh·xi，其中 η 是学习率。⑤重复①-④直到收敛。BP 的核心是链式法则——损失对权重的梯度等于从输出层到该权重的路径上所有偏导的乘积。标准 BP 每次用一个样本更新（在线学习），累积 BP 用整个数据集的累积误差更新（批量学习），后者更稳定但收敛慢。

</Answer>

### 问题 3

神经网络训练中常见的挑战有哪些？如何解决？

<Answer>

神经网络训练常见挑战及解决方案：①过拟合——网络复杂度过高导致拟合训练集噪声。解决：正则化（L1/L2 权重衰减）、Dropout（随机丢弃神经元）、早停（验证误差上升时停止训练）、数据增强。②局部最优——损失函数非凸，梯度下降可能陷入局部最小值。解决：多次随机初始化、动量法（Momentum）、自适应学习率（Adam/RMSProp）。③梯度消失/爆炸——深层网络中梯度经多层连乘后趋近于零或爆炸。解决：ReLU 激活函数（正区间导数恒为 1）、批归一化（BatchNorm）、残差连接（ResNet）、梯度裁剪。④学习率选择——太大震荡发散，太小收敛缓慢。解决：学习率衰减、自适应学习率优化器（Adam）。⑤隐藏层结构设计——层数和每层神经元数需调参。解决：网格搜索、经验法则（先宽后深）、参考经典架构。西瓜书主要关注 BP 算法本身，现代深度学习优化技术（Adam/BatchNorm/ResNet）在后续 DL 书中展开。

</Answer>

### 问题 4

常见的激活函数有哪些？各自的优缺点是什么？

<Answer>

常见激活函数：①Sigmoid σ(z) = 1/(1+e^{-z})——输出 (0,1)，平滑可导，适合二分类输出层。缺点：梯度最大值仅 0.25，深层网络梯度消失；输出非零中心（均值偏正），影响收敛；指数运算开销大。②Tanh tanh(z) = (e^z-e^{-z})/(e^z+e^{-z})——输出 (-1,1)，零中心化。缺点：仍有梯度消失问题（导数最大 1）。③ReLU max(0,z)——正区间导数恒为 1，缓解梯度消失；计算简单（无指数运算）；稀疏激活（负区间输出 0）。缺点：负区间梯度为 0，可能导致神经元「死亡」（Dead ReLU）。④Leaky ReLU max(αz, z)（α 为小常数如 0.01）——解决 Dead ReLU 问题，负区间有微小梯度。⑤ELU——负区间平滑过渡，更接近零均值。实际中隐层多用 ReLU 及其变体，输出层根据任务选择（二分类用 Sigmoid，多分类用 Softmax，回归用线性）。

</Answer>
