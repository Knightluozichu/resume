## SVM 概述

支持向量机（SVM）是一种二分类模型，核心思想是找到一个分离超平面，使两类样本之间的**间隔最大化**。SVM 的三大优势：最大间隔提升泛化、核技巧处理非线性、凸优化保证全局最优。

## 最大间隔分离超平面

超平面 `w^T x + b = 0`，样本到超平面的距离为 `|w^T x + b| / ||w||`。

要求两类样本的函数间隔 `yi(w^T xi + b) ≥ 1`（归一化后），则几何间隔为 `2/||w||`。

```text
最大化间隔 = 最大化 2/||w|| = 最小化 ||w||²/2

原始问题：
  min  1/2 ||w||²
  s.t. yi(w^T xi + b) ≥ 1  （对所有 i）
```

**支持向量**：距离超平面最近的训练样本点（满足 `yi(w^T xi+b) = 1`），它们决定了超平面的位置——其他样本的移动不影响解。

## 对偶问题

通过拉格朗日乘子法将原始问题转化为对偶问题：

```text
对偶问题：
  max  Σαi - 1/2 ΣΣ αiαj yi yj xi^T xj
  s.t. Σαi yi = 0,  αi ≥ 0

解出 α 后：
  w = Σ αi yi xi    （仅 αi > 0 的支持向量有贡献）
  b  由支持向量满足 yi(w^T xi + b) = 1 求出
```

<Callout type="info">

**对偶形式的优势**：①自然引入内积 `xi^T xj`，为核技巧铺垫；②求解效率与特征维度无关，只与样本数有关；③KKT 条件保证解的稀疏性。

</Callout>

## 核技巧

将原始空间中线性不可分的数据映射到高维特征空间使其线性可分，且无需显式计算映射函数 `φ(·)`。

```text
核函数：K(xi, xj) = φ(xi)^T φ(xj)
```

SVM 对偶形式中只出现样本内积，用核函数替代即可隐式地在高维空间计算。

### 常见核函数

| 核函数 | 公式 | 特点 |
|-------|------|------|
| 线性核 | `K(x,z) = x^T z` | 不映射，等价线性 SVM |
| 多项式核 | `K(x,z) = (x^T z + 1)^d` | 映射到多项式特征空间 |
| 高斯核（RBF） | `K(x,z) = exp(-\|\|x-z\|\|²/2σ²)` | 映射到无穷维空间 |
| 拉普拉斯核 | `K(x,z) = exp(-\|\|x-z\|\|/σ)` | 类似高斯核 |

**Mercer 定理**：函数 `K` 是有效核当且仅当其核矩阵（Gram 矩阵）半正定。

## 软间隔 SVM

现实数据可能有噪声或离群点，硬间隔可能无解或间隔极小。软间隔引入松弛变量 `ξi ≥ 0`：

```text
min  1/2 ||w||² + C Σξi
s.t. yi(w^T xi + b) ≥ 1 - ξi,  ξi ≥ 0
```

`C` 是惩罚参数——`C` 大则严格（趋向硬间隔），`C` 小则宽容。

## 支持向量回归（SVR）

将 SVM 推广到回归任务，引入 `ε` 不敏感损失带：

```text
仅当 |f(x) - y| > ε 时才计算损失
```

```text
min  1/2 ||w||² + C Σ(ξi + ξi*)
s.t. yi - w^T xi - b ≤ ε + ξi
     w^T xi + b - yi ≤ ε + ξi*
     ξi, ξi* ≥ 0
```

### 问题 1

什么是支持向量机？最大间隔分离超平面的直觉和数学表述是什么？

<Answer>

支持向量机（SVM）是一种二分类模型，核心思想是找到一个分离超平面，使两类样本之间的「间隔」最大化。直觉：在所有能正确分类的超平面中，选择离两类最近样本都尽可能远的那个，这样对新样本的泛化能力最强。数学表述：超平面 w^T x + b = 0，样本到超平面的距离为 |w^T x + b|/||w||。要求两类样本的函数间隔 yi(w^T xi + b) ≥ 1（归一化后），则几何间隔为 2/||w||（两类支持向量到超平面的距离之和）。最大化间隔等价于最大化 2/||w||，即最小化 ||w||²/2。原始优化问题：min 1/2 ||w||²，s.t. yi(w^T xi + b) ≥ 1（对所有 i）。距离超平面最近的训练样本点（满足 yi(w^T xi+b)=1）就是支持向量，它们决定了超平面的位置——其他样本的移动不影响解。

</Answer>

### 问题 2

如何从 SVM 的原始问题推导到对偶问题？对偶形式有什么优势？

<Answer>

原始问题：min 1/2||w||² s.t. yi(w^T xi+b) ≥ 1。推导对偶问题：①对每个约束引入拉格朗日乘子 αi ≥ 0，构建拉格朗日函数 L(w,b,α) = 1/2||w||² - Σ αi[yi(w^T xi+b)-1]。②对 w 和 b 求偏导并令为零：w = Σ αi yi xi，Σ αi yi = 0。③代入 L 消去 w 和 b，得到对偶问题：max Σαi - 1/2 ΣΣ αiαj yi yj xi^T xj，s.t. Σαi yi = 0，αi ≥ 0。④解出 α 后，w = Σαi yi xi（仅 αi>0 的样本即支持向量有贡献），b 由支持向量满足 yi(w^T xi+b)=1 求出。对偶形式的优势：①自然引入内积 xi^T xj，为核技巧铺垫——将内积替换为核函数 K(xi,xj) 即可处理非线性；②求解效率与特征维度无关，只与样本数有关——高维数据（如文本）中样本数远小于特征数时更高效；③KKT 条件保证解的稀疏性（非支持向量的 αi=0）。

</Answer>

### 问题 3

什么是核技巧？常见的核函数有哪些？核函数有效需满足什么条件？

<Answer>

核技巧（Kernel Trick）：将原始空间中线性不可分的数据映射到高维特征空间使其线性可分，且无需显式计算映射函数 φ(·)。关键观察：SVM 对偶形式中只出现样本内积 xi^T xj，用核函数 K(xi,xj) = φ(xi)^T φ(xj) 替代内积即可隐式地在高维空间计算。常见核函数：①线性核 K(x,z) = x^T z——不映射，等价于线性 SVM；②多项式核 K(x,z) = (x^T z + 1)^d——映射到多项式特征空间；③高斯核（RBF）K(x,z) = exp(-||x-z||²/2σ²)——映射到无穷维空间，最常用，σ 控制局部性；④拉普拉斯核 K(x,z) = exp(-||x-z||/σ)；⑤Sigmoid 核 K(x,z) = tanh(βx^T z + θ)。Mercer 定理：函数 K 是有效核当且仅当对任意有限样本集，其核矩阵（Gram 矩阵）半正定。核技巧使 SVM 能处理任意非线性分类问题，是 SVM 最强大的特性之一。

</Answer>

### 问题 4

软间隔 SVM 和支持向量回归（SVR）分别解决了什么问题？请说明核心思想。

<Answer>

软间隔 SVM 解决线性不可分/噪声数据问题。现实中数据可能有噪声或离群点，硬间隔要求所有样本严格满足 yi(w^T xi+b) ≥ 1 可能导致无解或间隔极小。软间隔引入松弛变量 ξi ≥ 0 允许部分样本违反间隔约束：yi(w^T xi+b) ≥ 1-ξi。目标函数变为 min 1/2||w||² + C Σξi，其中 C 是惩罚参数控制对违反间隔的容忍度——C 大则严格（趋向硬间隔），C 小则宽容。ξi > 1 的样本被误分类，0 < ξi < 1 的样本在间隔内但分类正确。支持向量回归（SVR）将 SVM 推广到回归任务。核心思想引入 ε 不敏感损失带：仅当 |f(x)-y| > ε 时才计算损失（即预测值在真实值 ε 范围内视为零损失）。优化目标：min 1/2||w||² + C Σ(ξi+ξi*)，s.t. yi - w^T xi - b ≤ ε+ξi，w^T xi+b-yi ≤ ε+ξi*，ξi,ξi* ≥ 0。SVR 使超平面在 ε 管道内拟合数据，仅管道外的样本（支持向量）影响模型。软间隔和 SVR 都体现了 SVM 的核心优势——通过凸优化保证全局最优解。

</Answer>
