## 核心概念

### 全书定位

《认知天性》（Peter C. Brown 等）是一本基于认知心理学研究成果的学习科学读物。不同于市面上大量「学习技巧」类书籍，它以严格的实验证据为基础，揭示了我们以为有效的学习方法（如重复阅读、集中练习）为何实际上低效，以及真正有效的学习方法（如检索练习、间隔穿插）背后的科学原理。

### 核心脉络

全书的核心理念可以浓缩为一条脉络线：

**迷思破除 → 检索编码 → 间隔巩固 → 反思校准 → 模型建构 → 终身成长**

这四个阶段不是孤立的模块，而是一个**递进循环**：迷思破除是起点，检索编码是核心方法，间隔巩固是长期保障，反思校准是质量保证，模型建构是终极目标，终身成长是持续动力。

### 学习建议

1. **破除迷思优先**：先理解为什么旧方法无效，再接受新方法
2. **实践导向**：每学完一个原则，立即在日常学习中尝试
3. **对比思考**：将书中的科学方法与自己的学习习惯对比
4. **定期回顾**：学完全书后回到本章，检验对全景图的理解是否加深

## 术语表

| 术语 | 释义 |
|------|------|
| 检索练习 | 通过主动回忆提取记忆，而非被动重复阅读 |
| 间隔练习 | 将学习分散到多个时间点，利用遗忘曲线巩固记忆 |
| 穿插练习 | 混合不同类型的内容进行练习，培养辨识和迁移能力 |
| 精细化 | 用自己的语言解释新知识，与已有知识建立关联 |
| 生成效应 | 自己生成答案比阅读现成答案记忆更牢固的现象 |
| 流畅性错觉 | 因重复阅读产生的熟悉感，误以为已经学会了 |
| 合意困难 | 短期增加学习难度但长期促进记忆的条件 |
| 心智模型 | 对某领域知识的结构化理解，可推理和迁移 |
| 校准 | 让自我判断与实际水平保持一致的过程 |
| 成长型思维 | 认为能力可以通过努力发展的思维模式 |
