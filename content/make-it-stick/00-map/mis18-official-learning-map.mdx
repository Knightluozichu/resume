## 为什么“感觉会了”不能作为终点

《认知天性》权威学习地图属于 **全书权威学习地图**。按13个正式单元和63个目录节点建立从学习误解、记忆巩固到角色化应用的完整路径。 本课程不复制原书正文、案例叙事或实验表述，而把公开目录命题重构为学习合同、练习调度、交互实验、失败样本与证据包。学习结果必须在离开材料、经历延迟或进入新情境后仍可观察，不能由重读时的熟悉感定义。

本单元覆盖的目录坐标是：1 学习是挑战天性的必修课、2 学习的本质：知识链和记忆结、3 “后刻意练习”时代的到来、4 知识的“滚雪球”效应、5 打造适合自己的心智模型、6 选择适合自己的学习风格、7 终身学习者基本的基本、8 写给大家的学习策略。每个坐标都在正文中单独解释，不把八章改写成任意“技巧清单”。原作反复穿插案例与研究，是为了让读者在不同语境检索同一原则；课程保留这种跨情境复现，但要求显式记录样本、对照、时间和拒绝条件。

## 四个可手算指标

延迟保持率按延迟后正确项目与可评分项目之比计算：

$$
K = N_{delayed-correct} / N_{scored}
$$

检索成功率记录无提示或限定线索下的成功比例：

$$
Q = N_{retrieved} / N_{attempted}
$$

校准误差比较预测信心与实际正确率，越接近零越好：

$$
E = |C_{predicted} - P_{actual}|
$$

迁移收益比较训练组与相同初始水平对照组在新任务上的差异：

$$
T = P_{new-task,trained} - P_{new-task,control}
$$

指标必须同时报告样本量、评分规则、延迟、先备知识和不确定性。即时正确率高但延迟保持低，说明可能只是集中练习；保持高但新任务迁移低，说明知识仍与原线索绑定；信心高而正确率低，则需要增加低风险测验和反馈。

## 权威目录坐标与核心知识

### 1 学习是挑战天性的必修课

**版次目录。** 熟悉、顺畅和高信心都可能来自最近接触，而非可独立提取。用机制一表示快速直觉，用机制二表示费力审查；二者是教学模型而非脑区标签。无提示测验、同伴解释和错误日志用于校准主观判断。 对“《认知天性》权威学习地图”还要追问：短期表现与长期学习是否被混淆，效应来自哪一个比较条件，结论能否外推到当前任务。答案必须写进学习记录而非只留在主观感受中。

### 2 学习的本质：知识链和记忆结

**证据主张。** 检索不是检查学习之后才发生的附属步骤，而是改变记忆的学习事件。先在无提示条件下努力提取，再获得纠错反馈，并在延迟后再次提取；即时正确率只反映当前表现，延迟保持与迁移才接近学习结果。 对“《认知天性》权威学习地图”还要追问：短期表现与长期学习是否被混淆，效应来自哪一个比较条件，结论能否外推到当前任务。答案必须写进学习记录而非只留在主观感受中。

**误差校准。** 困难只有在任务可达、先备知识足够、反馈可用时才可能合意。适度遗忘提高检索努力，再巩固会更新记忆；过高负荷、无反馈噪声或不可克服障碍不会自动促进学习，必须以表现曲线区分。 对“《认知天性》权威学习地图”还要追问：短期表现与长期学习是否被混淆，效应来自哪一个比较条件，结论能否外推到当前任务。答案必须写进学习记录而非只留在主观感受中。

## 把主张转成可执行学习协议

本单元主链是“误解诊断 → 检索巩固 → 练习调度 → 校准建模 → 角色迁移”。1. **误解诊断**检查版次目录；2. **检索巩固**检查证据主张；3. **练习调度**检查策略组合；4. **校准建模**检查误差校准；5. **角色迁移**检查行动验收。每步写出正常值、恰好边界和拒绝信号，并规定下一次测量时间。

先用同一份前测估计起点，再随机或交替安排两个策略，保持材料、总时长和评分一致。学习结束只记录即时表现，不立刻下结论；在预定延迟后进行无提示检索，最后加入表面不同但依赖同一规则的迁移题。若无法控制分组，就采用单人交叉设计并记录项目难度和顺序。

## 最小可重放实现

第一段生成逐渐拉开的检索日程，参数而非日历感受决定复习：

```ts
function schedule(startDay: number, gaps: number[]) {
  let day = startDay;
  return gaps.map((gap, index) => {
    day += gap;
    return { attempt: index + 1, day, mode: "free-recall" };
  });
}

const plan = schedule(0, [1, 3, 7, 14]);
```

第二段同时保存预测与实际，显式计算校准误差：

```python
def score(predicted, answers, key):
    actual = sum(a == b for a, b in zip(answers, key)) / len(key)
    return {
        "actual": actual,
        "calibration_error": abs(predicted - actual),
    }
```

第三段把学习实验声明为数据，防止结果出现后修改指标：

```yaml
unit: "mis18-official-learning-map"
primary_outcome: delayed_recall
secondary_outcomes: [calibration_error, discrimination, transfer]
controls: [same_material, same_total_time, same_scoring]
scenarios: [normal, exact_boundary, mismatched_strategy]
record: [prediction, attempts, feedback, immediate, delayed, transfer]
```

代码只是记录合同。真实实验还需固定题目抽样、评分盲法、缺失数据规则和延迟窗口；涉及学生或员工评价时，应获得适当同意并避免把探索性结果当成人事结论。

## 设计矩阵与策略剂量

| 决策轴 | 可接受设计                   | 必留证据                   | 拒绝信号               |
| ------ | ---------------------------- | -------------------------- | ---------------------- |
| 检索   | 低风险、无提示优先、随后反馈 | 尝试、答案、反馈与再次检索 | 直接看答案冒充自测     |
| 间隔   | 允许部分遗忘但仍可恢复       | 每次间隔与成功率           | 完全遗忘仍机械拉长     |
| 穿插   | 混合需要辨识的相关类别       | 类别、顺序与选择理由       | 随机混杂无共同规则     |
| 困难   | 可达、有反馈、服务目标       | 负荷、错误类型与恢复       | 噪声、羞辱或不可达任务 |
| 迁移   | 新表面、同底层规则           | 先备知识与新任务评分       | 只重做原题宣称迁移     |

策略不是越多越好。检索过密会退化成复述，间隔过长会导致无法恢复，穿插无关内容只增加切换成本，反馈过早会阻止生成，反馈过晚又可能让错误固化。剂量必须根据检索成功率和错误类型调整。

<Callout type="trap" title="陷阱：把当场表现当成持久学习">
  集中练习通常更流畅、即时正确率更高，却可能在延迟测验中衰退。必须预先指定延迟保持或迁移指标，不能只用课堂顺利和学习者满意度验收。
</Callout>

<Callout type="trap" title="陷阱：把困难本身当成有效机制">
  无关噪声、过高认知负荷、羞辱与缺乏反馈不是合意困难。困难只有促进目标加工、仍可成功检索并获得纠正时，才可能改善学习。
</Callout>

## 证据包、局限与独立复核

证据包至少保存中文版版次、目录坐标、学习目标、样本与先备知识、材料版本、项目难度、分组或顺序、总时长、间隔、检索提示、反馈时机、信心预测、即时得分、延迟得分、迁移得分、缺失数据和分析脚本。只报告平均值会掩盖个体差异，应保留逐次轨迹。

先重放原失败，再运行相邻策略和正常基线。若延迟保持改善但校准更差，要检查提示与评分；若原题保持却不能迁移，要增加规则辨识与多样化；若所有指标同时上升，也要排除材料泄漏、重复暴露和评分变化。独立复核者应从原始记录重算四个指标，并能指出至少一个不被数据支持的解释。

再建立一份“主张到账本”：每条主张占一行，依次记录目录坐标、研究或案例类型、干预变量、对照条件、即时指标、延迟指标、边界与尚未回答的问题。推荐序和前言提出的方向性判断也要进入账本，不能因为位于正文之前就降低证据要求；推荐阅读与致谢中的来源线索则用于回查研究脉络和贡献责任，不能被误写成新的因果证据。复核者随机抽取一行，应能从目录定位到实验合同，再从原始记录重算结论，并明确哪些外推仍需新样本。

## 本章回顾

《认知天性》权威学习地图不是技巧口号，而是“误解诊断 → 检索巩固 → 练习调度 → 校准建模 → 角色迁移”中的可检验学习单元。掌握它意味着能区分表现与学习，给出策略的适用边界，预先安排延迟和迁移测量，并让他人从记录复核。最终目标不是让学习主观上最费力，而是在可承受难度内获得更持久、可校准、可迁移的能力。

  冻结误解诊断、检索巩固、练习调度、校准建模、角色迁移，固定材料、总时长、评分、先备知识和延迟。学习前写预测，保存即时表现、延迟保持、信心与迁移，并说明版次目录、证据主张、策略组合、误差校准、行动验收各自的拒绝阈值。
</Answer>

2. 怎样证明观察到的是学习而不是短期表现？

<Answer>
  不以当堂顺畅或重复原题验收；在预定延迟后无提示检索，并用表面不同、底层规则相同的新任务测迁移。比较相同练习总量的对照，报告校准误差与逐次轨迹。
</Answer>

3. 发现策略失配后怎样做相邻回归？

<Answer>
  只调整一个间隔、提示、穿插或反馈条件，先重放原失败，再测恰好边界和正常基线。确认原首差消失、没有引入新错误，并由独立复核者从原始记录得到相同结论。
</Answer>
