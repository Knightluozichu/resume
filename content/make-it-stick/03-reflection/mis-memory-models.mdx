## 学习目标

- 理解三阶段记忆模型及其各阶段特点
- 掌握心智模型的构建过程和四个特征
- 对比死记硬背与心智模型在理解深度上的差异
- 学会从孤立事实逐步构建可迁移的心智模型

## 核心概念

### 三阶段记忆模型

| 阶段 | 持续时间 | 容量 | 功能 |
|------|----------|------|------|
| 感觉记忆 | ~0.5 秒 | 大 | 感官信息暂存，大部分被丢弃 |
| 工作记忆 | ~30 秒 | 4±1 组块 | 进行 conscious 加工 |
| 长期记忆 | 数十年~终身 | 近乎无限 | 通过编码和检索巩固 |

信息流：感觉记忆 →（注意）→ 工作记忆 →（编码）→ 长期记忆 →（检索）→ 工作记忆

### 心智模型的构建过程

1. **孤立事实**——碎片化知识点，缺乏关联
2. **建立关联**——发现知识点之间的因果关系、层级关系
3. **形成结构**——把关联组织为有意义的框架
4. **心智模型**——可推理、可迁移的结构化理解

### 良好心智模型的四个特征

| 特征 | 含义 | 价值 |
|------|------|------|
| 连贯性 | 各部分逻辑一致，无自相矛盾 | 不同情境下给出一致判断 |
| 灵活性 | 能适应不同情境，不僵化套用 | 面对新问题能调整适用范围 |
| 可迁移性 | 能跨领域应用底层原理 | 在无关领域发现共通规律 |
| 可修正性 | 能接受新证据并持续迭代 | 面对反例时修正而非固执 |

### 死记硬背 vs 心智模型

| 维度 | 死记硬背 | 心智模型 |
|------|----------|----------|
| 知识形态 | 孤立事实 | 结构化理解 |
| 推理能力 | 无法推理新问题 | 可推理未见过的问题 |
| 迁移能力 | 无法迁移 | 可跨领域应用 |
| 记忆持久 | 易遗忘 | 长期保持 |
| 学习层次 | 知道是什么 | 理解为什么和怎么用 |

### 构建心智模型的实践建议

- **积累事实**：先快速过材料建立全局印象
- **建立关联**：问「这个和前面学的有什么关系？」
- **形成结构**：画思维导图或概念图
- **验证模型**：用费曼学习法向别人解释整个框架
- **迭代修正**：用模型解决新问题，根据反馈修正

## 术语表

| 术语 | 释义 |
|------|------|
| 感觉记忆 | 感官信息极短暂的记忆暂存 |
| 工作记忆 | 短时容量有限的加工系统 |
| 长期记忆 | 容量近乎无限的持久记忆 |
| 组块 | 工作记忆中的信息单元 |
| 心智模型 | 对某领域知识的结构化理解 |
| 编码 | 将信息从工作记忆转化为长期记忆 |
| 检索 | 从长期记忆提取信息到工作记忆 |
| 概念图 | 展示知识关联结构的可视化工具 |
