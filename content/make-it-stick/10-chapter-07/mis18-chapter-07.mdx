## 为什么“感觉会了”不能作为终点

7 终身学习者基本的基本属于 **能力可塑性与专家成长**。在承认遗传与环境差异的同时，考察脑可塑性、成长心态、有效训练和专家式结构对能力发展的作用。 本课程不复制原书正文、案例叙事或实验表述，而把公开目录命题重构为学习合同、练习调度、交互实验、失败样本与证据包。学习结果必须在离开材料、经历延迟或进入新情境后仍可观察，不能由重读时的熟悉感定义。

本单元覆盖的目录坐标是：7 终身学习者基本的基本、双胞胎的认知能力也会天差地别、性格、求知欲和家庭条件对学习的影响、脑力训练可以提升学习自信、想要终身成长，请像专家一样思考、学习执行力比学习技巧更重要、掌握几个适合自己的记忆方法、小结。每个坐标都在正文中单独解释，不把八章改写成任意“技巧清单”。原作反复穿插案例与研究，是为了让读者在不同语境检索同一原则；课程保留这种跨情境复现，但要求显式记录样本、对照、时间和拒绝条件。

## 四个可手算指标

延迟保持率按延迟后正确项目与可评分项目之比计算：

$$
K = N_{delayed-correct} / N_{scored}
$$

检索成功率记录无提示或限定线索下的成功比例：

$$
Q = N_{retrieved} / N_{attempted}
$$

校准误差比较预测信心与实际正确率，越接近零越好：

$$
E = |C_{predicted} - P_{actual}|
$$

迁移收益比较训练组与相同初始水平对照组在新任务上的差异：

$$
T = P_{new-task,trained} - P_{new-task,control}
$$

指标必须同时报告样本量、评分规则、延迟、先备知识和不确定性。即时正确率高但延迟保持低，说明可能只是集中练习；保持高但新任务迁移低，说明知识仍与原线索绑定；信心高而正确率低，则需要增加低风险测验和反馈。

## 把主张转成可执行学习协议

本单元主链是“起始能力 → 挑战任务 → 有效策略 → 反馈坚持 → 能力增长”。1. **起始能力**检查个体差异；2. **挑战任务**检查可塑边界；3. **有效策略**检查策略质量；4. **反馈坚持**检查自我效能；5. **能力增长**检查专家模型。每步写出正常值、恰好边界和拒绝信号，并规定下一次测量时间。

先用同一份前测估计起点，再随机或交替安排两个策略，保持材料、总时长和评分一致。学习结束只记录即时表现，不立刻下结论；在预定延迟后进行无提示检索，最后加入表面不同但依赖同一规则的迁移题。若无法控制分组，就采用单人交叉设计并记录项目难度和顺序。

## 最小可重放实现

第一段生成逐渐拉开的检索日程，参数而非日历感受决定复习：

```ts
function schedule(startDay: number, gaps: number[]) {
  let day = startDay;
  return gaps.map((gap, index) => {
    day += gap;
    return { attempt: index + 1, day, mode: "free-recall" };
  });
}

const plan = schedule(0, [1, 3, 7, 14]);
```

第二段同时保存预测与实际，显式计算校准误差：

```python
def score(predicted, answers, key):
    actual = sum(a == b for a, b in zip(answers, key)) / len(key)
    return {
        "actual": actual,
        "calibration_error": abs(predicted - actual),
    }
```

第三段把学习实验声明为数据，防止结果出现后修改指标：

```yaml
unit: "mis18-chapter-07"
primary_outcome: delayed_recall
secondary_outcomes: [calibration_error, discrimination, transfer]
controls: [same_material, same_total_time, same_scoring]
scenarios: [normal, exact_boundary, mismatched_strategy]
record: [prediction, attempts, feedback, immediate, delayed, transfer]
```

代码只是记录合同。真实实验还需固定题目抽样、评分盲法、缺失数据规则和延迟窗口；涉及学生或员工评价时，应获得适当同意并避免把探索性结果当成人事结论。

## 设计矩阵与策略剂量

| 决策轴 | 可接受设计                   | 必留证据                   | 拒绝信号               |
| ------ | ---------------------------- | -------------------------- | ---------------------- |
| 检索   | 低风险、无提示优先、随后反馈 | 尝试、答案、反馈与再次检索 | 直接看答案冒充自测     |
| 间隔   | 允许部分遗忘但仍可恢复       | 每次间隔与成功率           | 完全遗忘仍机械拉长     |
| 穿插   | 混合需要辨识的相关类别       | 类别、顺序与选择理由       | 随机混杂无共同规则     |
| 困难   | 可达、有反馈、服务目标       | 负荷、错误类型与恢复       | 噪声、羞辱或不可达任务 |
| 迁移   | 新表面、同底层规则           | 先备知识与新任务评分       | 只重做原题宣称迁移     |

策略不是越多越好。检索过密会退化成复述，间隔过长会导致无法恢复，穿插无关内容只增加切换成本，反馈过早会阻止生成，反馈过晚又可能让错误固化。剂量必须根据检索成功率和错误类型调整。


## 证据包、局限与独立复核

证据包至少保存中文版版次、目录坐标、学习目标、样本与先备知识、材料版本、项目难度、分组或顺序、总时长、间隔、检索提示、反馈时机、信心预测、即时得分、延迟得分、迁移得分、缺失数据和分析脚本。只报告平均值会掩盖个体差异，应保留逐次轨迹。

先重放原失败，再运行相邻策略和正常基线。若延迟保持改善但校准更差，要检查提示与评分；若原题保持却不能迁移，要增加规则辨识与多样化；若所有指标同时上升，也要排除材料泄漏、重复暴露和评分变化。独立复核者应从原始记录重算四个指标，并能指出至少一个不被数据支持的解释。

再建立一份“主张到账本”：每条主张占一行，依次记录目录坐标、研究或案例类型、干预变量、对照条件、即时指标、延迟指标、边界与尚未回答的问题。推荐序和前言提出的方向性判断也要进入账本，不能因为位于正文之前就降低证据要求；推荐阅读与致谢中的来源线索则用于回查研究脉络和贡献责任，不能被误写成新的因果证据。复核者随机抽取一行，应能从目录定位到实验合同，再从原始记录重算结论，并明确哪些外推仍需新样本。

## 本章回顾

7 终身学习者基本的基本不是技巧口号，而是“起始能力 → 挑战任务 → 有效策略 → 反馈坚持 → 能力增长”中的可检验学习单元。掌握它意味着能区分表现与学习，给出策略的适用边界，预先安排延迟和迁移测量，并让他人从记录复核。最终目标不是让学习主观上最费力，而是在可承受难度内获得更持久、可校准、可迁移的能力。
