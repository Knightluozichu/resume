## 学习目标

- 理解《精通以太坊》全书的五大学习阶段与十章学习路径
- 掌握从账户密钥到 EVM 执行到合约应用的系统演进逻辑
- 明确各章节之间的依赖关系与核心脉络
- 建立以太坊知识的四层系统视角（认知层、机制层、执行层、应用层）

## 核心概念

### 五大学习阶段

《精通以太坊》按照由浅入深、从原理到应用的原则，将全书内容划分为五个学习阶段：

1. **基础认知**：理解知识全景，掌握以太坊设计原理与世界计算机架构
2. **基础机制**：掌握账户与密钥、交易与 Gas 两大核心机制
3. **核心运行**：学习 EVM 虚拟机与字节码执行，理解状态转换
4. **合约与代币**：掌握 Solidity 编程、合约安全与 ERC 代币标准
5. **应用与复习**：学习 DApp 与预言机，全书复习形成系统闭环

### 十章学习路径

十章内容沿着认知主线层层递进：

- 第 0 章（本章）：知识全景图，总览学习路径
- 第 1 章：以太坊概览，理解历史背景与世界计算机设计
- 第 2 章：账户与密钥，掌握椭圆曲线与地址推导
- 第 3 章：交易与 Gas 机制，理解账户模型与费用计量
- 第 4 章：EVM 与字节码，学习虚拟机架构与执行模型
- 第 5 章：Solidity 编程，掌握合约语言基础
- 第 6 章：智能合约安全，学习漏洞与防护机制
- 第 7 章：代币与标准，理解 ERC20 与 ERC721
- 第 8 章：DApp 与预言机，掌握去中心化应用架构
- 第 9 章：全书复习与知识整合，形成系统闭环

### 核心脉络

全书的核心理念可以概括为一条认知主线：

**理解原理 → 掌握账户 → 解析交易 → EVM执行 → 合约编程 → 安全防护 → 代币标准 → DApp应用 → 知识闭环**

每个阶段都建立在前一阶段的基础上。原理是认知基座，不理解世界计算机设计就无法理解智能合约的价值；账户是交易基础，没有签名授权就没有有效交易；交易是执行的输入，没有 Gas 计量就无法限制计算资源；EVM 是运行引擎，不理解虚拟机就无法理解合约如何执行；Solidity 是编程工具，没有合约代码就没有可编程价值；安全是合约的生命线，部署不可篡改意味着漏洞不可修补；代币标准是生态基础，没有 ERC 标准就没有 DeFi 与 NFT 生态；DApp 与预言机是应用出口，将链上能力连接到真实世界。

## 术语表

| 术语 | 含义 |
|------|------|
| EVM | 以太坊虚拟机，执行智能合约的图灵完备运行环境 |
| EOA | 外部拥有账户，由私钥控制的用户账户 |
| CA | 合约账户，由代码控制的账户 |
| Gas | 交易手续费计量单位，限制计算资源消耗 |
| Solidity | 以太坊主流智能合约编程语言 |
| ERC | 以太坊意见征求稿，代币与接口标准 |
| ERC-20 | 同质化代币标准 |
| ERC-721 | 非同质化代币（NFT）标准 |
| Keccak-256 | 以太坊使用的哈希函数 |
| 预言机 | 将链外数据引入链内的桥梁 |
