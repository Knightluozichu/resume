- 理解代币的概念与 ERC 标准的意义

## 核心概念

### 代币与 ERC 标准

代币是链上可编程资产，由智能合约实现。ERC（Ethereum Request for Comments）是以太坊的意见征求稿，定义了代币的统一接口标准。标准化的意义在于：钱包、交易所、DApp 无需为每种代币单独适配，只要遵循同一标准就能即插即用——这是以太坊生态爆发的基础设施。

### ERC-20 同质化代币

ERC-20 是最基础的代币标准，定义了同质化代币接口——每个代币等价可互换，就像纸币一样。核心方法包括：

- **transfer**：直接转账
- **approve / transferFrom**：授权第三方代为转账（DEX、借贷协议依赖此机制）
- **balanceOf**：查询余额
- **totalSupply**：查询总发行量

事件包括 Transfer（转账）和 Approval（授权）。ERC-20 广泛用于稳定币（USDT、USDC）、治理代币（UNI、COMP）和各种项目代币。

### ERC-721 非同质化代币（NFT）

ERC-721 定义了非同质化代币——每个代币有唯一 ID，不可互换不可分割。核心方法包括：

- **ownerOf**：查询某个 tokenId 的持有者
- **safeTransferFrom**：安全转移（含接收方校验）
- **tokenURI**：返回代币的元数据 URI（图片、属性等）

ERC-721 开创了 NFT 生态，用于数字艺术品（CryptoPunks、BAYC）、链游道具、数字收藏品和实体资产凭证。每个 NFT 都是独一无二的链上资产。

### ERC-1155 多代币标准

ERC-1155 是更高效的多代币标准——单个合约可同时管理多种类型的代币（既可同质化也可非同质化）。核心优势：

- **批量转移**：safeBatchTransferFrom 一次转移多种代币，大幅节省 Gas
- **半同质化**：同一 ID 可有多个实例（如游戏中的某类道具 100 个）
- **单合约管理**：减少合约部署与管理开销

ERC-1155 广泛用于游戏物品（一件合约管理所有装备）和批量发放场景。

### 标准化的价值

ERC 标准化带来三大价值：统一接口让钱包无需为每种代币单独适配；即插即用让 DEX、借贷协议自动支持新发行的合规代币；可组合性让代币像乐高积木在协议间自由流转，催生了 DeFi 的繁荣。没有标准，就没有以太坊的生态网络效应。

## 术语表

| 术语 | 含义 |
|------|------|
| ERC | 以太坊意见征求稿，标准接口 |
| ERC-20 | 同质化代币标准 |
| ERC-721 | 非同质化代币（NFT）标准 |
| ERC-1155 | 多代币标准 |
| 同质化 | 每个代币等价可互换 |
| 非同质化 | 每个代币唯一不可分 |
| approve | 授权第三方代为操作代币 |
| tokenURI | NFT 的元数据地址 |
