## 直觉引入

数学女孩系列用对话和故事把数学从冰冷的公式变成温暖的探索。从「质数为什么无穷」到「机器如何学习」，每一步都是好奇心驱动的旅程。

全书的独特之处在于：它不把数学当孤立的公式集，而是把数学与编程连接起来——数论是密码学的基础，线性代数是机器学习的语言，概率是算法分析的工具。理解数学，才能真正理解算法为什么有效。

## 全书四段结构

<MglBookMap />

全书分四大板块，呈「数学基础 → 代数工具 → 离散建模 → 算法应用」的递进关系：

1. **数学与编程**（2 章）：数论基础（质数、模运算、GCD）与编程的交汇，这是密码学和算法数论的基础。
2. **代数世界**（2 章）：方程求解与函数论，从初等代数到函数变换，为后续建模提供代数工具。
3. **离散数学**（3 章）：组合计数、图论、概率论——离散结构是计算机科学的核心数学语言。
4. **算法与机器学习**（3 章）：算法设计、机器学习基础，把数学知识转化为解决实际问题的计算方法。

## 学习路径与前置依赖

<Stepper>
<Step title="第一步：数论奠基">
数论是「数学的女王」。质数、最大公约数（GCD）、模运算是密码学（RSA）和哈希算法的基石。理解数论，才能理解为什么 RSA 安全、为什么哈希函数能工作。
</Step>
<Step title="第二步：代数工具">
方程求解训练逻辑推理能力，函数论建立「输入→输出」的映射思维。函数是编程中函数的数学原型，理解函数的变换（复合、逆）有助于理解算法的数据流。
</Step>
<Step title="第三步：离散建模">
组合数学教你怎么数（计数原理、排列组合），图论教你怎么表示关系（网络、路径），概率论教你怎么处理不确定性。这三者是算法分析的核心工具——复杂度分析靠组合，图算法靠图论，随机算法靠概率。
</Step>
<Step title="第四步：算法与ML">
把前三步的数学知识转化为算法。算法设计用数论和组合，图算法用图论，机器学习用线性代数和概率。最终回到「数学如何驱动计算」的闭环。
</Step>
</Stepper>

## 代码对照

```python
# 数学与编程的交汇：欧几里得算法（GCD）
# 数论中的古老算法，至今仍是密码学的核心

def gcd(a, b):
    """欧几里得算法：gcd(a, b) = gcd(b, a % b)"""
    while b:
        a, b = b, a % b  # 辗转相除
    return a

# 扩展欧几里得：求 ax + by = gcd(a,b) 的解
def extended_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = extended_gcd(b, a % b)
    return g, y, x - (a // b) * y

# 应用：RSA 密码学中求模逆元
# 如果 gcd(a, m) = 1，则 a 在模 m 下有逆元
def mod_inverse(a, m):
    g, x, _ = extended_gcd(a, m)
    if g != 1:
        return None  # 逆元不存在
    return x % m

# 这就是数学驱动编程的典型例子
```

## 常见误区

<Callout type="trap">
**误区：认为学编程不需要数学。**
初级编程确实不需要太多数学，但算法分析需要组合数学（复杂度计算），图算法需要图论，机器学习需要线性代数和概率论。数学是算法的天花板——不学数学，编程只能停留在调用 API 的层面。
</Callout>

<Callout type="trap">
**误区：把数学当公式背，不理解直觉。**
数学女孩系列的精髓在于「为什么」而非「是什么」。质数无穷不是因为欧几里得的证明背下来就行，而是要理解反证法的思路：假设有限个质数，构造新数，矛盾。理解直觉才能举一反三。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？它们之间的递进关系是什么？

<Answer>
数学与编程、代数世界、离散数学、算法与机器学习。递进关系是「数学基础 → 代数工具 → 离散建模 → 算法应用」：数论奠基，代数提供工具，离散数学建模，最终转化为算法和机器学习。
</Answer>

**问题 2**：为什么说数学是算法的理论基础？

<Answer>
算法的效率分析依赖组合数学（复杂度计算），图算法依赖图论（路径、连通性），随机算法依赖概率论，密码学依赖数论，机器学习依赖线性代数和概率论。不理解数学，只能调用 API 而无法理解算法为什么有效、何时失效。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="数论">
研究整数性质的数学分支，核心包括质数、整除、模运算、最大公约数等，是密码学和哈希算法的理论基础。
</GlossaryItem>
<GlossaryItem term="离散数学">
研究离散结构的数学分支，包括组合计数、图论、逻辑、集合论等，是计算机科学的核心数学语言。
</GlossaryItem>
<GlossaryItem term="算法复杂度">
用组合数学方法分析算法运行时间随输入规模增长的趋势，是评估算法效率的数学工具。
</GlossaryItem>
<GlossaryItem term="机器学习">
让计算机从数据中学习规律的学科，数学基础是线性代数（向量矩阵）、概率论（不确定性建模）和微积分（优化）。
</GlossaryItem>
</Glossary>
