## 直觉引入

 cryptography（密码学）看似神秘，其核心不过是几条简单的数论规则。RSA 加密——保护着你每次网购的安全性——依赖的仅仅是：大数分解很难，而质数相乘很容易。

数论研究整数的性质。高斯说「数学是科学的女王，数论是数学的女王」。这一章从最基础的质数出发，走到模运算和欧几里得算法，最终看到这些古老数学如何驱动现代密码学。

## 概念讲解

### 质数与唯一分解

<MglNumberTheoryDiagram />

<Term def="质数是大于1且只能被1和自身整除的整数，是整数的「原子」">
质数
</Term>

**算术基本定理**：每个大于 1 的整数都能唯一分解为质数的乘积。如 $12 = 2^2 \times 3$，$60 = 2^2 \times 3 \times 5$。质数是整数的「原子」，一切整数由它们组合而成。

**质数无穷的证明**（欧几里得反证法）：假设质数有限，设为 $p_1, p_2, \ldots, p_n$。构造 $N = p_1 \times p_2 \times \cdots \times p_n + 1$。$N$ 除以任何 $p_i$ 都余 1，所以 $N$ 要么本身是质数，要么有一个不在列表中的质因子。矛盾！所以质数无穷。

### 最大公约数与欧几里得算法

<Term def="欧几里得算法用辗转相除法求 GCD：gcd(a,b) = gcd(b, a mod b)，直到余数为0">
欧几里得算法
</Term>

<Stepper>
<Step title="GCD 的递推关系">
$\gcd(a, b) = \gcd(b, a \bmod b)$。原理：若 $d | a$ 且 $d | b$，则 $d | (a - kb)$ 对任意 $k$ 成立。取 $k = \lfloor a/b \rfloor$，则 $a - kb = a \bmod b$，所以 $d$ 也整除 $a \bmod b$。
</Step>
<Step title="扩展欧几里得算法">
不仅求 $\gcd(a,b)$，还求 $ax + by = \gcd(a,b)$ 的整数解 $(x,y)$。递推回代：若 $b=0$ 则 $\gcd=a, x=1, y=0$；否则 $\gcd(b, a \bmod b)$ 的解 $(x', y')$ 回代得 $x = y', y = x' - \lfloor a/b \rfloor \cdot y'$。
</Step>
<Step title="求模逆元">
若 $\gcd(a, m) = 1$，扩展欧几里得给出 $ax + my = 1$，模 $m$ 后 $ax \equiv 1 \pmod{m}$，所以 $x \bmod m$ 就是 $a$ 在模 $m$ 下的逆元。这是 RSA 解密的关键。
</Step>
</Stepper>

### 模运算与 RSA

模运算 $(a \bmod n)$ 是取余数。关键性质：
- $(a + b) \bmod n = ((a \bmod n) + (b \bmod n)) \bmod n$
- $(a \times b) \bmod n = ((a \bmod n) \times (b \bmod n)) \bmod n$

**欧拉定理**：若 $\gcd(a, n) = 1$，则 $a^{\varphi(n)} \equiv 1 \pmod{n}$，其中 $\varphi(n)$ 是欧拉函数（小于 $n$ 且与 $n$ 互质的正整数个数）。

**RSA 原理**：选两个大质数 $p, q$，令 $n = pq$，$\varphi(n) = (p-1)(q-1)$。选 $e$ 与 $\varphi(n)$ 互质，求 $d = e^{-1} \bmod \varphi(n)$。公钥 $(e, n)$，私钥 $d$。加密 $c = m^e \bmod n$，解密 $m = c^d \bmod n$。安全性来自大数分解的困难性。

## 代码对照

```python
# 欧几里得算法求 GCD
def gcd(a, b):
    while b:
        a, b = b, a % b  # 辗转相除
    return a

# 扩展欧几里得：ax + by = gcd(a, b)
def extended_gcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x, y = extended_gcd(b, a % b)
    return g, y, x - (a // b) * y

# 模逆元：a^(-1) mod m
def mod_inverse(a, m):
    g, x, _ = extended_gcd(a, m)
    if g != 1:
        raise ValueError("逆元不存在：gcd(a,m) != 1")
    return x % m

# 快速幂取模：计算 a^b mod m，O(log b)
def pow_mod(a, b, m):
    result = 1
    a = a % m
    while b > 0:
        if b % 2 == 1:          # b 的最低位是 1
            result = (result * a) % m
        a = (a * a) % m          # 平方
        b //= 2                  # 右移
    return result

# RSA 简化示例
p, q = 61, 53                    # 两个质数
n = p * q                        # n = 3233
phi = (p - 1) * (q - 1)          # φ(n) = 3120
e = 17                           # 公钥指数（与 φ(n) 互质）
d = mod_inverse(e, phi)          # 私钥 d = 2753

message = 42
encrypted = pow_mod(message, e, n)   # 加密
decrypted = pow_mod(encrypted, d, n) # 解密，应等于 42
```

## 常见误区

<Callout type="trap">
**误区：认为模运算就是取余数，没什么深意。**
模运算是有限数学的基础。计算机中所有整数运算都在模 $2^{32}$ 或 $2^{64}$ 下进行。密码学、哈希、随机数生成都依赖模运算的性质。理解模运算的代数结构（模 $n$ 下的环），才能理解为什么 RSA 能工作。
</Callout>

<Callout type="trap">
**误区：认为质数无穷的证明很难理解。**
欧几里得的反证法其实极其简洁：假设有限个质数，把它们全乘起来加 1，这个新数要么是质数（不在列表中），要么有质因子（也不在列表中），都导致矛盾。这是数学之美的典范——用最简单的构造推翻假设。
</Callout>

<Exercises>
**问题 1**：用欧几里得算法求 $\gcd(48, 18)$ 的步骤。

<Answer>
$\gcd(48, 18)$：$48 = 2 \times 18 + 12$，$\gcd(18, 12)$：$18 = 1 \times 12 + 6$，$\gcd(12, 6)$：$12 = 2 \times 6 + 0$。余数为 0，所以 $\gcd(48, 18) = 6$。共 3 步辗转相除。
</Answer>

**问题 2**：RSA 的安全性基于什么数学难题？为什么大数分解困难就能保证安全？

<Answer>
RSA 安全性基于大数分解的困难性：已知 $n = pq$（两个大质数的乘积），求 $p$ 和 $q$ 很难（没有已知的多项式算法）。攻击者需要从公钥 $(e, n)$ 求私钥 $d$，而 $d = e^{-1} \bmod \varphi(n)$，求 $\varphi(n) = (p-1)(q-1)$ 需要知道 $p$ 和 $q$，即需要分解 $n$。当 $n$ 足够大（如 2048 位），分解在当前计算能力下不可行。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="质数">
大于 1 且只能被 1 和自身整除的整数。算术基本定理保证每个大于 1 的整数唯一分解为质数乘积。
</GlossaryItem>
<GlossaryItem term="欧几里得算法">
用辗转相除法求最大公约数：gcd(a,b) = gcd(b, a mod b)，直到余数为 0。时间复杂度 O(log(min(a,b)))。
</GlossaryItem>
<GlossaryItem term="模逆元">
若 gcd(a,m)=1，则存在 x 使 ax≡1 (mod m)，x 称为 a 在模 m 下的逆元。用扩展欧几里得算法求解。
</GlossaryItem>
<GlossaryItem term="欧拉定理">
若 gcd(a,n)=1，则 a^φ(n)≡1 (mod n)，其中 φ(n) 是小于 n 且与 n 互质的正整数个数。RSA 的理论基础。
</GlossaryItem>
</Glossary>
