## 质数与唯一分解

### 先分清1、质数与合数

<Term def="大于1且正因数只有1和自身的正整数。">质数</Term>不是“不能再分”的含糊说法，而是明确限制在大于1的正整数。<Term def="大于1且存在除1和自身之外正因数的整数。">合数</Term>可以写成两个更小正整数之积。数字1是<Term def="乘法中满足1·a=a的元素；为了保证质因数分解唯一，1不归入质数。">乘法单位元</Term>，既不是质数也不是合数。

<Term def="每个大于1的正整数都能写成质数乘积，且忽略次序后分解唯一。">算术基本定理</Term>把整数乘法结构变成质因数指数结构。例如：

$$
60=2^2\cdot3\cdot5.
$$

唯一性很重要。若允许1成为质数，同一个数就能随意添上任意多个1，分解不再唯一。

### 质数为什么无穷

假设质数只有有限个：

$$
p_1,p_2,\ldots,p_n.
$$

构造：

$$
N=p_1p_2\cdots p_n+1.
$$

对任意`i`，都有`N`除以`pᵢ`余1，所以列表中的任何质数都不整除`N`。但`N>1`，根据算术基本定理，`N`本身是质数，或至少拥有质因数；这个质因数不在原列表中，产生矛盾。

注意证明不要求`N`一定是质数。例如：

$$
2\cdot3\cdot5\cdot7\cdot11\cdot13+1=30031=59\cdot509.
$$

关键是30031的质因数59和509都不在原有限列表里。<Term def="先假设目标结论不成立，再构造与假设不相容的对象或事实。">反证法</Term>的力量来自精确构造，不来自“乘积加一看起来像质数”。

## 整除、互质与欧几里得算法

### 最大公约数是一个不变量

若存在整数`q,r`使：

$$
a=qb+r,\qquad 0\le r<|b|,
$$

那么同时整除`a,b`的整数，也同时整除`b,r`；反向同样成立。因此两对数的公因数集合完全相同：

$$
\gcd(a,b)=\gcd(b,a\bmod b).
$$

这就是<Term def="反复用较小的数和余数替换原数对，直到余数为0以求最大公约数的算法。">欧几里得算法</Term>的循环不变量。第二参数每轮严格减小且保持非负，所以算法必然停止；停止在`b=0`时返回`|a|`。

以48和18为例：

$$
\begin{aligned}
48&=2\cdot18+12,\\
18&=1\cdot12+6,\\
12&=2\cdot6+0.
\end{aligned}
$$

故`gcd(48,18)=6`。

### 从回代到贝祖等式

<Term def="存在整数x,y使ax+by=gcd(a,b)的线性组合等式。">贝祖等式</Term>可以由辗转相除逆向回代得到。对48与18：

$$
6=18-12=18-(48-2\cdot18)=3\cdot18-48.
$$

因此一组贝祖系数是`x=-1,y=3`。

若`gcd(a,m)=1`，贝祖等式给出：

$$
ax+my=1.
$$

对模`m`取同余：

$$
ax\equiv1\pmod m.
$$

此时`x`是<Term def="若ax同余于1模m，则x称为a在模m下的乘法逆元；它存在当且仅当gcd(a,m)=1。">模逆元</Term>。<Term def="最大公约数为1的两个整数。">互质</Term>不是“两个数都是质数”；例如8与15都是合数，但互质。

```ts
export function gcd(a: bigint, b: bigint): bigint {
  a = a < 0n ? -a : a;
  b = b < 0n ? -b : b;

  while (b !== 0n) {
    [a, b] = [b, a % b];
  }

  return a;
}

export function extendedGcd(
  a: bigint,
  b: bigint,
): { gcd: bigint; x: bigint; y: bigint } {
  if (b === 0n) {
    return { gcd: a, x: 1n, y: 0n };
  }

  const next = extendedGcd(b, a % b);
  return {
    gcd: next.gcd,
    x: next.y,
    y: next.x - (a / b) * next.y,
  };
}
```

代码验收不能只看返回的GCD。还要检查：

$$
a\cdot x+b\cdot y=\gcd(a,b).
$$

## 同余与有限结构

### 同余不是“只剩一个余数”

<Term def="当m整除a-b时，称a与b模m同余，记作a≡b (mod m)。">同余</Term>是整数间的等价关系。它把所有整数分成`m`个<Term def="模m同余关系下的等价类，每类包含余数相同的全部整数。">剩余类</Term>，并允许加法与乘法在类上良好定义：

$$
\begin{aligned}
a\equiv b\pmod m,\ c\equiv d\pmod m
&\Rightarrow a+c\equiv b+d\pmod m,\\
&\Rightarrow ac\equiv bd\pmod m.
\end{aligned}
$$

第2卷第7章用“发型”为模建立直觉，第6章则让读者看到<Term def="带有封闭运算、结合律、单位元和逆元的集合；若运算可交换则为阿贝尔群。">阿贝尔群</Term>。可逆剩余类在乘法下形成群，这正是欧拉定理和RSA教学模型使用的结构。

### 快速模幂

直接计算`aᵉ`再取模会产生巨大中间数。<Term def="利用指数二进制展开，通过反复平方和条件乘法在对数轮数内计算幂。">平方—乘算法</Term>每轮将指数折半：

```ts
export function modPow(
  base: bigint,
  exponent: bigint,
  modulus: bigint,
): bigint {
  if (modulus <= 0n || exponent < 0n) {
    throw new RangeError("modulus must be positive and exponent non-negative");
  }

  let result = 1n % modulus;
  base %= modulus;

  while (exponent > 0n) {
    if (exponent % 2n === 1n) result = (result * base) % modulus;
    base = (base * base) % modulus;
    exponent /= 2n;
  }

  return result;
}
```

它只需`O(log e)`轮，并在每轮将中间值限制在模数范围内。

## RSA教学模型与安全边界

### 代数链条

在简化教学模型中，选择不同质数`p,q`，令`n=pq`，并计算欧拉函数：

$$
\varphi(n)=(p-1)(q-1).
$$

选择`e`满足`gcd(e,φ(n))=1`，再求`d`使：

$$
ed\equiv1\pmod{\varphi(n)}.
$$

模幂把消息代表元`m`变成`c≡mᵉ (mod n)`，再用`d`恢复。这里复用了唯一分解、互质、贝祖等式、模逆元和快速模幂。

### 不能越过的结论

<Term def="只为展示代数关系而使用小整数和简化运算的模型，不具备生产安全性。">教学RSA</Term>必须与真实密码系统分开：

- 分解`n`会暴露`p,q`，进而计算私钥参数；
- 但不能因此声称“破解一般RSA已经证明与整数分解完全等价”；
- 裸RSA是确定性的，不提供现代协议需要的语义安全；
- 真实加密或签名需要标准填充、足够密钥长度、侧信道防护和成熟密码库；
- 不能把课堂代码直接用于密钥、身份或资金安全。

## 本章回顾：从整除关系到可执行证明

1. 本页是第2卷相关概念的跨卷导读，不替代十个原书章节。
2. 质数大于1，数字1是乘法单位元，不是质数。
3. 算术基本定理保证大于1整数的质因数分解存在且唯一。
4. 质数无穷证明构造乘积加一，只需产生列表外质因子。
5. 欧几里得算法保持公因数集合不变，余数严格下降保证终止。
6. 贝祖等式由辗转相除逆向回代得到。
7. 模逆元存在当且仅当对应整数与模数互质。
8. 同余把整数划分成剩余类，加法和乘法可传递到类上。
9. 模除法只有除数可逆时才合法。
10. 平方—乘算法用`O(log e)`轮计算模幂。
11. RSA教学模型复用互质、模逆元和模幂，但不等于生产密码系统。
12. 分解模数可恢复私钥参数，不代表一般RSA破解已证明等价于分解。
13. 第2卷还包含勾股数组、代数结构、无穷递降和复数，必须回到原章学习。

<Exercises>

**问题 1：为什么欧几里得的构造不需要证明`N=p₁p₂⋯pₙ+1`本身是质数？**

<Answer>因为`N>1`必有质因数。列表中每个`pᵢ`除`N`都余1，所以没有任何已列质数能成为`N`的质因数。只要存在一个列表外质因数，就已经与“列表包含全部质数”矛盾。</Answer>

**问题 2：用欧几里得算法求`gcd(252,105)`，并写出一组贝祖系数。**

<Answer>`252=2×105+42`，`105=2×42+21`，`42=2×21`，所以GCD为21。回代得`21=105-2×42=105-2(252-2×105)=5×105-2×252`，故可取`x=-2,y=5`。</Answer>

**问题 3：从`6x≡9 (mod 15)`直接约去3是否安全？约分后还缺什么信息？**

<Answer>3在模15下不可逆，因为`gcd(3,15)=3`，不能当作普通除法。原同余等价于`2x≡3 (mod 5)`，但解应理解为模15中的三个剩余类提升，而不只是模5中的一个类；直接约分若忽略模数同步缩小会丢失解的结构。</Answer>

**问题 4：为什么教学RSA代码不能用于真实业务？**

<Answer>小整数可被立即分解，裸RSA还是确定性的，没有标准填充带来的安全性质；实现还缺少密钥生成规范、侧信道防护和协议校验。真实系统应使用标准方案与成熟密码库，教学代码只验证代数链条。</Answer>
