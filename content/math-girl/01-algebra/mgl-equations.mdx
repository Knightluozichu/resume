## 直觉引入

方程是数学的「天平」——等号两边保持平衡，你可以在两边做相同操作（加减乘除）来求解未知数。解方程的过程就是一系列保持平衡的变换，直到未知数被孤立出来。

从最简单的 $x + 3 = 7$ 到复杂的 $x^5 - 3x^2 + 1 = 0$，方程的思维贯穿所有数学。而韦达定理揭示了一个深刻的联系：方程的根与其系数之间存在确定的关系，不需要解出根就能知道根的性质。

## 概念讲解

### 线性方程与方程组

<Term def="方程是含有未知数的等式，求解就是找到使等式成立的未知数值">
方程
</Term>

线性方程 $ax + b = 0$ 的解是 $x = -b/a$。线性方程组 $\begin{cases} a_1x + b_1y = c_1 \\ a_2x + b_2y = c_2 \end{cases}$ 可用消元法或矩阵法求解。矩阵形式 $A\mathbf{x} = \mathbf{b}$，当 $\det(A) \neq 0$ 时有唯一解 $\mathbf{x} = A^{-1}\mathbf{b}$。

### 二次方程与韦达定理

二次方程 $ax^2 + bx + c = 0$ 的求根公式：$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$。判别式 $\Delta = b^2 - 4ac$ 决定根的性质：$\Delta > 0$ 两个不同实根，$\Delta = 0$ 一个重根，$\Delta < 0$ 两个共轭复根。

<Stepper>
<Step title="韦达定理（二次）">
设 $x_1, x_2$ 是 $ax^2 + bx + c = 0$ 的两根，则：$x_1 + x_2 = -b/a$，$x_1 \cdot x_2 = c/a$。根的和与积直接由系数决定，无需实际求根。
</Step>
<Step title="韦达定理推广（n 次）">
对 $n$ 次多项式 $a_n x^n + a_{n-1} x^{n-1} + \cdots + a_0 = 0$，根 $r_1, \ldots, r_n$ 满足：$\sum r_i = -a_{n-1}/a_n$，$\sum_{i<j} r_i r_j = a_{n-2}/a_n$，$\prod r_i = (-1)^n a_0/a_n$。
</Step>
<Step title="韦达定理的应用">
已知根的对称函数（和、积）可以反推方程系数。在算法中，韦达定理用于分析递推关系的特征方程，从而确定递归算法的复杂度。
</Step>
</Stepper>

### 高次方程与不可解性

三次方程有卡尔丹诺公式，四次方程有费拉里公式。但**五次及以上方程没有通用求根公式**——这是阿贝尔-鲁菲尼定理的结论。这意味着对于五次及以上方程，不存在用有限次加减乘除和开方表达的求根公式。这一发现催生了群论（伽罗瓦理论）。

## 代码对照

```python
import math

# 二次方程求解
def solve_quadratic(a, b, c):
    """ax² + bx + c = 0"""
    discriminant = b**2 - 4*a*c  # 判别式
    if discriminant > 0:
        x1 = (-b + math.sqrt(discriminant)) / (2*a)
        x2 = (-b - math.sqrt(discriminant)) / (2*a)
        return (x1, x2), "两个不同实根"
    elif discriminant == 0:
        x = -b / (2*a)
        return (x,), "一个重根"
    else:
        real = -b / (2*a)
        imag = math.sqrt(-discriminant) / (2*a)
        return (complex(real, imag), complex(real, -imag)), "两个共轭复根"

# 韦达定理验证
def vieta_verify(a, b, c, roots):
    """验证 x1+x2=-b/a, x1*x2=c/a"""
    if len(roots) == 2:
        sum_roots = sum(roots)
        product_roots = roots[0] * roots[1]
        print(f"根的和: {sum_roots:.6f}, -b/a = {-b/a:.6f}")
        print(f"根的积: {product_roots:.6f}, c/a = {c/a:.6f}")

# 牛顿迭代法求高次方程的数值解
def newton_method(f, df, x0, tolerance=1e-10, max_iter=100):
    """牛顿法：x_{n+1} = x_n - f(x_n)/f'(x_n)"""
    x = x0
    for _ in range(max_iter):
        fx = f(x)
        if abs(fx) < tolerance:
            return x
        dfx = df(x)
        if dfx == 0:
            break
        x = x - fx / dfx  # 牛顿迭代
    return x

# 求解 x³ - 2x - 5 = 0
f = lambda x: x**3 - 2*x - 5
df = lambda x: 3*x**2 - 2
root = newton_method(f, df, 2.0)  # ≈ 2.0946
```

## 常见误区

<Callout type="trap">
**误区：认为所有方程都有求根公式。**
一次到四次方程有求根公式，但五次及以上没有（阿贝尔-鲁菲尼定理）。这不是「还没找到」而是「数学上证明不存在」。高次方程只能用数值方法（如牛顿迭代）求近似解。
</Callout>

<Callout type="trap">
**误区：韦达定理只是考试技巧，没有实际用处。**
韦达定理揭示了根与系数的深层联系。在算法分析中，递推关系的特征方程的根决定算法复杂度（如斐波那契的黄金比例）。在信号处理中，多项式的根决定滤波器的稳定性。韦达定理是理解这些应用的数学基础。
</Callout>

<Exercises>
**问题 1**：方程 $x^2 - 5x + 6 = 0$ 的两根之和与两根之积分别是多少？（用韦达定理，不解方程）

<Answer>
由韦达定理：$x_1 + x_2 = -b/a = 5/1 = 5$，$x_1 \cdot x_2 = c/a = 6/1 = 6$。验证：两根为 2 和 3，$2+3=5$，$2 \times 3=6$。韦达定理无需解方程即可知道根的对称性质。
</Answer>

**问题 2**：为什么五次及以上方程没有通用求根公式？

<Answer>
阿贝尔-鲁菲尼定理证明了五次及以上的一般多项式方程不存在用有限次加减乘除和开方表达的求根公式。伽罗瓦理论进一步解释了原因：方程的可解性取决于其伽罗瓦群是否可解，五次及以上一般方程的伽罗瓦群（$S_n$, $n \geq 5$）不可解。这是数学史上划时代的发现。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="韦达定理">
多项式方程的根与系数之间的关系。二次方程 ax²+bx+c=0 的两根满足 x₁+x₂=-b/a, x₁x₂=c/a。推广到 n 次方程。
</GlossaryItem>
<GlossaryItem term="判别式">
Δ=b²-4ac，决定二次方程根的性质。Δ>0 两个实根，Δ=0 重根，Δ<0 共轭复根。
</GlossaryItem>
<GlossaryItem term="阿贝尔-鲁菲尼定理">
五次及以上的一般多项式方程不存在通用的根式求根公式。此发现催生了群论和伽罗瓦理论。
</GlossaryItem>
<GlossaryItem term="牛顿迭代法">
用切线逼近求方程数值解的方法：x_{n+1}=x_n-f(x_n)/f'(x_n)，收敛速度快（二阶收敛）。
</GlossaryItem>
</Glossary>
