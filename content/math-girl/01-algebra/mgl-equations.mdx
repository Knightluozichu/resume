## 从解集开始：方程不是“把x挪到一边”

先预测：等号两边执行同一个操作，是否总能保持方程的全部解？

不能。<Term def="使方程两边都有定义并且相等的全部未知量取值集合。">解集</Term>才是求解对象；变形必须说明它与原方程是等价，还是只有单向推出。<Term def="未知量允许取值且所有表达式都有意义的范围。">定义域</Term>在第一步就应写出。

本页是<Term def="重组前四卷中同类数学工具、用于回查而不取代原章的编辑性内容。">跨卷导读</Term>。方程线索散布在：

- 第1卷第1章的数列模型与第4章的递推关系；
- 第1卷第3章的复数、单位根与多项式；
- 第2卷第2章的勾股方程和第10章的费马方程；
- 第3卷极限章节中对方程近似与连续性的语言；
- 第4卷第7章的线性方程组、矩阵和特征值；
- 第4卷第10章把递推方程用于快速排序运行时间。

这些原章各自有叙事和证明任务，不能压缩成一个“方程求解章”的完成进度。

## 等价变形与候选解

### 哪些操作保持解集

<Term def="变形前后方程在同一允许范围内拥有完全相同解集。">等价变形</Term>允许我们改变外形而不改变答案：

- 两边加上或减去同一个有定义的式子，通常等价；
- 两边乘以一个已知非零量，等价；
- 两边除以一个已知非零量，等价；
- 交换两个方程或用一个方程的倍数加到另一个方程，在线性系统中等价。

风险来自“非零”或“可逆”条件没有落实。例如从：

$$
x(x-1)=0
$$

两边除以`x`会丢掉解`x=0`；乘以可能为0的表达式则可能引入额外解。

### 平方、开方与通分

从`x=2`可推出`x²=4`，但反向只能推出`x=±2`。平方是<Term def="原方程的每个解都满足新方程，但新方程可能拥有额外候选解的变形。">单向推出</Term>，需要代回筛选<Term def="由不可逆变形产生、满足变形后方程却不满足原方程的候选值。">增根</Term>。

含分式方程还要先排除分母为0的值。含偶次根式时，在实数域内还要要求被开方数非负。可靠流程是：

1. 写定义域；
2. 标注每一步是等价还是单向推出；
3. 得到候选集；
4. 代回原方程；
5. 输出最终解集。

</Callout>

## 二次方程、因式分解与韦达关系

### 从配方得到求根公式

对`a≠0`：

$$
ax^2+bx+c=0.
$$

除以`a`并配方：

$$
\left(x+\frac{b}{2a}\right)^2
=\frac{b^2-4ac}{4a^2}.
$$

于是：

$$
x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}.
$$

<Term def="二次方程中Δ=b²-4ac，用于判断实根数量和重数。">判别式</Term>`Δ`在实数域中区分两个不同实根、一个二重根和无实根。在复数域中，根据<Term def="每个非常数复系数多项式在复数域中至少有一个根，并按重数完全分解。">代数基本定理</Term>，二次方程总有两个根并计重数。

### 根与系数

若根为`r₁,r₂`：

$$
a(x-r_1)(x-r_2)
=ax^2-a(r_1+r_2)x+ar_1r_2.
$$

比较系数得到<Term def="把多项式根的初等对称量与系数联系起来的公式族。">韦达关系</Term>：

$$
r_1+r_2=-\frac ba,\qquad r_1r_2=\frac ca.
$$

它的价值不是“少算一次求根公式”，而是在不知道单个根时，直接计算<Term def="交换任意两个变量后值不变的多项式表达式，如根和与根积。">对称多项式</Term>。高次版本把根的各阶初等对称多项式对应到归一化系数。

### 一般高次方程的边界

<Term def="一般五次及更高次多项式不存在只用有限次四则运算和开方写成的统一求根公式。">阿贝尔-鲁菲尼定理</Term>限定的是**一般方程的通用根式公式**：

- 某些五次或更高次方程仍可因式分解并用根式求解；
- 数值算法仍可近似求根；
- 使用特殊函数也可表达某些解；
- 伽罗瓦理论用<Term def="刻画多项式根之间对称关系、决定根式可解性的群。">伽罗瓦群</Term>说明何时存在根式解。

</Callout>

## 线性方程组：答案不只有一个向量

### 矩阵形式与行变换

线性系统可写成：

$$
A\mathbf x=\mathbf b.
$$

<Term def="交换两行、把一行乘非零常数、把一行的倍数加到另一行的三类可逆操作。">初等行变换</Term>保持方程组解集。高斯消元把增广矩阵化为阶梯形，再根据主元和矛盾行分类：

- 出现`0=非零`的行：无解；
- 每个未知量列都有主元：唯一解；
- 无矛盾且存在自由变量：无穷多解。

对二阶方阵：

$$
A=
\begin{pmatrix}
a&b\\
c&d
\end{pmatrix},
\qquad
\det(A)=ad-bc.
$$

若`det(A)≠0`，矩阵可逆且有唯一解。若`det(A)=0`，不能直接说“无解”；还要检查增广矩阵，结果可能是无解或无穷多解。

<Term def="线性系统中不由主元列约束、可作为参数任意选择的未知量。">自由变量</Term>决定无穷多解的维数。<Term def="线性变换把不同输入压到同一输出，导致逆变换不存在的性质。">奇异性</Term>解释了行列式为0为何失去唯一反解。

### 递推方程也是方程

第1卷斐波那契递推：

$$
F_{n+2}=F_{n+1}+F_n
$$

尝试`Fₙ=rⁿ`得到<Term def="把线性常系数递推的指数试探解代入后得到的多项式方程。">特征方程</Term>：

$$
r^2-r-1=0.
$$

它的两个根决定通解的增长模式。第4卷矩阵方法又把同一递推写成状态转移，并由特征值解释长期增长。方程因此连接数列、矩阵与算法复杂度。

## 数值求根：近似值也要交付证据

### 牛顿迭代

对可微函数`f`，从初值`x₀`出发：

$$
x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}.
$$

<Term def="用当前点切线与横轴交点作为下一近似值的迭代求根方法。">牛顿迭代</Term>在根附近且满足合适正则条件时收敛很快，但可能因导数接近0、初值不当或迭代跳跃而失败。

```ts
type NewtonResult =
  | { ok: true; root: number; iterations: number; residual: number }
  | { ok: false; reason: string; iterations: number };

export function newton(
  f: (x: number) => number,
  derivative: (x: number) => number,
  initial: number,
  tolerance = 1e-10,
  maxIterations = 50,
): NewtonResult {
  let x = initial;

  for (let iteration = 0; iteration < maxIterations; iteration += 1) {
    const residual = Math.abs(f(x));
    if (residual <= tolerance) {
      return { ok: true, root: x, iterations: iteration, residual };
    }

    const slope = derivative(x);
    if (!Number.isFinite(slope) || Math.abs(slope) < 1e-14) {
      return { ok: false, reason: "derivative too small", iterations: iteration };
    }

    x -= f(x) / slope;
    if (!Number.isFinite(x)) {
      return { ok: false, reason: "iteration diverged", iterations: iteration };
    }
  }

  return { ok: false, reason: "iteration limit reached", iterations: maxIterations };
}
```

### 残差不是全部误差

<Term def="把候选解代回方程后得到的不平衡量，如|f(x)|或矩阵范数||Ax-b||。">残差</Term>衡量“候选满足方程到什么程度”；<Term def="计算近似值与真实解之间的距离。">前向误差</Term>衡量“答案离真值多远”。病态问题中，小残差也可能对应较大前向误差，必须结合<Term def="衡量输入微小扰动会被问题本身放大多少的数值指标。">条件数</Term>判断。

对连续函数若已知`f(L)`与`f(R)`异号，<Term def="不断把含根区间对半并保留异号半区间的可靠求根方法。">二分法</Term>收敛较慢，却提供明确包围区间。工程实现常用二分法保护牛顿步。

代数上等价的方程，在浮点计算中也可能表现不同。把很大且接近的数直接相减会损失有效数字；先展开再求值可能比保留因式结构产生更大舍入误差；方程各项尺度相差悬殊时，停止条件也不能只用固定绝对阈值。可靠实现通常同时使用绝对残差与相对残差，并对变量和方程做尺度调整。对多项式求值，霍纳形式减少运算次数，也减少不必要的中间舍入。这些措施不改变精确解集，却决定计算机能否稳定地接近它。

因此“求到了一个数”只是开始。还要保存输入尺度、迭代轨迹和停止原因，使别人能够用同一初值复现结果；再换一组初值或更高精度计算，检查结果是否稳定。方程求解从纸面变成程序后，证明责任由等价变形扩展为数值误差与失败路径。

## 回到原书：方程是表达问题的语言

前四卷并没有一章叫“方程求解”。它通过不同对象反复展示方程语言：

- 数列递推方程描述时间推进；
- 勾股方程和费马方程约束整数解；
- 复数方程揭示单位根对称；
- `ε-δ`定义把极限要求写成量词关系；
- 矩阵方程描述线性变换和随机状态；
- 快排递推方程描述平均与期望运行步数。

本导读的验收不是背求根公式，而是看到方程时先问：未知量在哪个域？目标是精确解、全部解还是近似解？每一步保持了什么？最后用什么证据验收？

## 本章回顾：求解等于维护解集并交付证据

1. 方程求解的对象是定义域内的完整解集。
2. 等价变形保持解集，单向推出需要代回筛选。
3. 除以可能为0的式子会漏根，平方与通分可能增根。
4. 二次求根公式来自配方，判别式在实数域判断根数。
5. 韦达关系来自根式因子展开与系数比较。
6. 阿贝尔-鲁菲尼定理否定一般五次以上的通用根式公式。
7. 特殊高次方程仍可能有根式解，也可以数值近似。
8. 线性系统可能无解、唯一解或无穷多解。
9. `det(A)=0`只排除唯一解，不能单独区分无解与无穷多解。
10. 递推特征方程把数列增长转成多项式根问题。
11. 牛顿迭代需要初值、导数保护、容差和迭代上限。
12. 残差、前向误差与条件数回答不同数值问题。
13. 本页只做跨卷回查，不替代任何原书章节。

<Exercises>

**问题 1：解`√(x+2)=x`，并指出平方产生的增根。**

<Answer>定义域要求`x≥0`。平方得`x+2=x²`，即`x²-x-2=0`，候选为2和-1。代回原方程，2满足`√4=2`；-1不在定义域且`√1≠-1`，所以-1是增根，最终解集为`{2}`。</Answer>

**问题 2：不直接求根，计算`2x²-7x+3=0`两根的`r₁²+r₂²`。**

<Answer>韦达关系给`r₁+r₂=7/2`、`r₁r₂=3/2`。因此`r₁²+r₂²=(r₁+r₂)²-2r₁r₂=49/4-3=37/4`。</Answer>

**问题 3：为什么`det(A)=0`不能推出线性系统无解？各举一个无解与无穷多解例子。**

<Answer>行列式为0只说明系数矩阵不可逆。`x+y=1`与`2x+2y=3`矛盾，故无解；`x+y=1`与`2x+2y=2`是同一约束，故有无穷多解。二者系数矩阵行列式都为0，必须检查增广矩阵。</Answer>

**问题 4：数值算法返回`x`且`|f(x)|<10⁻¹²`，还需要报告什么？**

<Answer>至少报告初值或包围区间、迭代次数、停止原因、最终残差、步长以及方法失败保护。若要说明答案接近真实根，还需条件数、导数下界或包围区间来把残差转成前向误差界。</Answer>

</Exercises>
