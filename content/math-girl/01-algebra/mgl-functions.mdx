## 直觉引入

函数就像一台机器：输入一个数，输出一个数。投入 3，机器按规则 $f(x) = x^2$ 加工，输出 9。数学中的函数和编程中的函数本质相同——都是「输入→变换→输出」的映射。

理解函数的关键不是背公式，而是理解变换的「组合」与「逆转」。两个函数可以串联（复合），一个函数可以反向操作（逆函数）。这些操作在编程中对应函数组合和反序列化。

## 概念讲解

### 函数的定义

<MglFunctionsDiagram />

<Term def="函数是从定义域到值域的映射，每个输入对应唯一输出">
函数
</Term>

函数的三要素：**定义域**（输入集合）、**值域**（输出集合）、**对应法则**（输入到输出的映射）。记作 $f: X \to Y$，$x \mapsto f(x)$。

### 函数的性质

- **单调性**：$x_1 < x_2 \Rightarrow f(x_1) < f(x_2)$（单调增）或 $f(x_1) > f(x_2)$（单调减）。单调函数有逆函数。
- **奇偶性**：$f(-x) = f(x)$（偶函数，关于 $y$ 轴对称），$f(-x) = -f(x)$（奇函数，关于原点对称）。
- **周期性**：存在 $T > 0$ 使 $f(x+T) = f(x)$。如 $\sin(x)$ 的周期是 $2\pi$。

### 复合与逆函数

<Stepper>
<Step title="函数复合">
$(f \circ g)(x) = f(g(x))$。先执行 $g$，再执行 $f$。就像编程中的函数链式调用 `f(g(x))`。复合满足结合律：$(f \circ g) \circ h = f \circ (g \circ h)$，但不满足交换律：$f \circ g \neq g \circ f$（一般情况）。
</Step>
<Step title="逆函数">
若 $f$ 是双射（一一对应），则存在逆函数 $f^{-1}$ 使 $f^{-1}(f(x)) = x$。逆函数是「撤销」操作——编程中的解码（反序列化）就是编码函数的逆。
</Step>
<Step title="函数与编程">
数学函数 $f: X \to Y$ 对应编程中的纯函数 `f(x: X) -> Y`。复合对应函数组合，逆函数对应反操作。理解数学函数有助于设计无副作用的纯函数，这在函数式编程中至关重要。
</Step>
</Stepper>

### 常见函数族

- **多项式函数**：$f(x) = a_n x^n + \cdots + a_0$。连续、光滑，是数值分析的基础。
- **指数函数**：$f(x) = a^x$。增长极快，$a^x = e^{x \ln a}$。算法复杂度中 $O(2^n)$ 就是指数增长。
- **对数函数**：$f(x) = \log_a x$。增长极慢，$O(\log n)$ 算法的高效来源。对数是指数的逆函数。
- **三角函数**：$\sin, \cos, \tan$。周期函数，信号处理和图形学的基础。

## 代码对照

```python
import math

# 数学函数的编程表示
def f(x):
    """f(x) = x² + 1"""
    return x ** 2 + 1

def g(x):
    """g(x) = 2x"""
    return 2 * x

# 函数复合：(f ∘ g)(x) = f(g(x))
def compose(f, g):
    """返回复合函数 f(g(x))"""
    return lambda x: f(g(x))

fg = compose(f, g)  # f(g(x)) = (2x)² + 1 = 4x² + 1
print(fg(3))  # f(g(3)) = f(6) = 37

# 逆函数：f(x) = x² + 1 的逆（限制定义域 x≥0）
def f_inverse(y):
    """f⁻¹(y) = √(y-1)，仅当 y≥1"""
    if y < 1:
        raise ValueError("不在值域内")
    return math.sqrt(y - 1)

print(f_inverse(10))  # √9 = 3，因为 f(3) = 10

# 高阶函数：函数作为参数/返回值（函数式编程核心）
def memoize(fn):
    """记忆化：缓存函数结果，用空间换时间"""
    cache = {}
    def wrapper(x):
        if x not in cache:
            cache[x] = fn(x)
        return cache[x]
    return wrapper

# 斐波那契数列：递推关系 f(n) = f(n-1) + f(n-2)
@memoize
def fib(n):
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)  # 递推 = 函数的自引用
```

## 常见误区

<Callout type="trap">
**误区：把数学函数和编程中的「函数」完全等同。**
数学函数是纯映射——相同输入永远产生相同输出，没有副作用。编程中的「函数」可能有副作用（修改全局变量、I/O 操作）。函数式编程的核心理念就是回归数学函数的纯粹性——用纯函数和无副作用构建可靠系统。
</Callout>

<Callout type="trap">
**误区：认为所有函数都有逆函数。**
只有双射（一一对应）函数才有逆函数。$f(x) = x^2$ 在全体实数上没有逆（因为 $f(2) = f(-2) = 4$，不一一对应），但限制定义域到 $x \geq 0$ 后就有逆 $f^{-1}(y) = \sqrt{y}$。在数据压缩中，有损压缩没有逆函数（信息丢失），无损压缩才有。
</Callout>

<Exercises>
**问题 1**：函数复合 $f \circ g$ 和 $g \circ f$ 是否相等？举例说明。

<Answer>
一般不相等。设 $f(x) = x^2$，$g(x) = x + 1$。$(f \circ g)(x) = f(g(x)) = (x+1)^2 = x^2 + 2x + 1$。$(g \circ f)(x) = g(f(x)) = x^2 + 1$。两者不同。函数复合满足结合律但不满足交换律，这和矩阵乘法类似。
</Answer>

**问题 2**：为什么 $f(x) = x^2$ 在全体实数上没有逆函数？如何让它有逆？

<Answer>
因为 $x^2$ 不是一一对应（双射）：$f(2) = f(-2) = 4$，同一个输出对应两个输入，无法确定逆。要让它有逆，需限制定义域到 $[0, +\infty)$（或 $(-\infty, 0]$），此时函数单调（一一对应），逆函数为 $f^{-1}(y) = \sqrt{y}$（或 $-\sqrt{y}$）。
</Answer>
</Exercises>

<GlossaryItem term="函数">
从定义域到值域的映射，每个输入对应唯一输出。记作 f: X→Y，x↦f(x)。
</GlossaryItem>
<GlossaryItem term="函数复合">
(f∘g)(x) = f(g(x))，先执行 g 再执行 f。满足结合律但不满足交换律。对应编程中的函数链式调用。
</GlossaryItem>
<GlossaryItem term="逆函数">
双射函数 f 的逆 f⁻¹ 满足 f⁻¹(f(x))=x。只有一一对应的函数才有逆。对应编程中的反操作/解码。
</GlossaryItem>
<GlossaryItem term="双射">
既是单射（一一对应，不同输入不同输出）又是满射（覆盖整个值域）的函数。只有双射才有逆函数。
</GlossaryItem>
</Glossary>
