## 先看一支三步舞

想象一个小点沿圆周匀速走动。你从正面看，它时而向右、时而向左；从侧面看，它又有另一条同样规律的往返路线。两个方向的变化不是两支舞，而是同一个运动留下的影子。

本章要解决的问题是：怎样把“方向”和“长度”放进同一个数里，并用一条乘法规则追踪点的下一步？没有这种表示，旋转只能靠画图，周期只能靠列很多项，三个方向为何刚好抵消也很难看见。

先预测：连续乘以 `i` 会经历哪些位置？`x^3=1` 为什么不是只有 1？如果一个点每次转三分之一圆，第三步为什么必然回到起点？先凭图猜，再用式子验。

<Callout type="trap" title="陷阱一：把复数乘法当成交换实虚部">
**现象 →** 看到乘以 `i` 就把实部和虚部互换，忘记其中一个分量还要变号，旋转方向因此错掉。

**原因 →** 只记住坐标结果，没有把乘法解释成长度变化与角度变化，也没有用 `i²=-1` 检查四步是否回到起点。

**修法 →** 同时做一次笛卡尔展开和一次几何检查：模长是否按比例变化，角度是否增加 90 度，连续四次是否回到原点位姿。

</Callout>

## ω的华尔兹

“ω的华尔兹”不是给符号起一个好听的昵称，而是把三次单位根看成每步转 120 度的三步舞。它的首要验收是：每一步都有确定的位置，第三步回到 1，并且三点不能重复或漏掉。

## 振动与旋转

本节的振动与旋转讨论同一个状态的两种观察：圆周上的点持续改变方向，投影到横轴和纵轴后就分别出现余弦与正弦的周期变化。把这两种观察连起来，才能解释为什么一个乘法更新同时描述两个相位相差四分之一周期的振动。

### 复平面把两个坐标装进一个数

<Term def="写成 a+bi 的对象，其中 i²=-1；也可以看作平面上的有序点">复数</Term>
可以写成 $z=a+bi$，其中 $a$ 是水平坐标，$b$
是竖直坐标。加法按两个坐标分别相加；乘法则会同时影响长度和方向。于是同一个对象既能做代数运算，也能画成平面上的点。

从点到原点的距离叫 <Term def="复数在平面上到原点的距离，|a+bi|=√(a²+b²)">模长</Term>，记为 $|z|$。它满足

$$
|a+bi|=\sqrt{a^2+b^2},\qquad z\overline z=|z|^2.
$$

这个式子在说：一个复数乘以它的镜像，会把方向消掉，只留下距离的平方。只要 $z\ne0$，就能用共轭写出逆元 $1/z=\overline z/|z|^2$。

同一非零复数还可以按长度与方向写成

$$
z=r(\cos\theta+i\sin\theta),\qquad r=|z|>0.
$$

这个式子在说：先从原点走长度 $r$，再转到角度 $\theta$ 的方向；角度加上整圈 $2\pi k$ 仍表示同一方向。

### 乘法就是缩放与转角

对 $z=r(\cos\theta+i\sin\theta)$ 和 $w=s(\cos\varphi+i\sin\varphi)$ 展开，并使用三角加法公式：

$$
zw=rs\bigl(\cos(\theta+\varphi)+i\sin(\theta+\varphi)\bigr).
$$

这个式子在说：模长相乘，角度相加。若 $|w|=1$，乘以 $w$ 不改变长度，只会把点旋转；乘以 `i` 增加 90 度，乘以 `-1` 增加 180 度。

把 $z_n=e^{in\theta}$ 看作离散时刻的状态，它的实部和虚部是

$$
\operatorname{Re}(z_n)=\cos(n\theta),\qquad \operatorname{Im}(z_n)=\sin(n\theta).
$$

这个式子在说：二维圆周运动投影到两个坐标轴，就得到两条由同一个角度驱动的振动曲线；旋转和振动不是互相竞争的解释。

## 复数与单位根

本节的复数与单位根把“解方程”与“找圆周上的对称点”合在一起：方程给出候选，模长和辐角负责排除重复分支，几何图形负责检查是否均匀分布。

### 解方程 $x^3=1$

先因式分解：

$$
x^3-1=(x-1)(x^2+x+1)=0.
$$

这个式子在说：一个根是 1，另外两个根来自二次因式。由求根公式得到

$$
\omega=-\frac12+\frac{\sqrt3}{2}i,\qquad \omega^2=-\frac12-\frac{\sqrt3}{2}i.
$$

这个式子在说：两个非实根关于实轴对称，实部同为 $-1/2$，虚部大小相反；平方符号这里是命名约定，也正好等于 ω 的第二次旋转。

从极形式也能完整枚举。若 $z^3=1$，则 $|z|^3=1$，所以 $|z|=1$；若辐角为 $\theta$，则 $3\theta=2\pi k$。在一个整圈内只取 $k=0,1,2$，得到

$$
z_k=\exp\!\left(\frac{2\pi i k}{3}\right),\qquad k=0,1,2.
$$

这个式子在说：三个根是单位圆上角度 0、$2\pi/3$、$4\pi/3$ 的三个点；继续增加 k 只会重复这三个位置。

<Term def="满足 z^N=1 的复数；它们位于单位圆上并形成等角分布">单位根</Term>
的名字来自“某个正整数次幂回到 1”。三次单位根是最小的非平凡例子；四次单位根给出
$1,i,-1,-i$，它们都可以用“模长 1、角度等分”检查。

<MglComplexRootsDiagram />

<Callout type="trap" title="陷阱二：只列出实根，或把角度分支重复无穷次">
**现象 →** 把 `x³=1` 的答案写成只有 1，或让 `k` 取所有整数后报告无穷多个不同根。

**原因 →** 没有同时检查模长与角度的等价关系；角度加整圈不会产生新点，非实根也不能被实数轴上的直觉排除。

**修法 →** 先固定一个完整角度区间，取恰好三个余数类 `k=0,1,2`，再用因式分解与单位圆图互相复核。

</Callout>

## 周期与对称

本节的周期与对称是同一结构的两面：周期回答状态在第几步复现，对称回答多个方向为什么平均到原点。ω 的三步循环把这两件事压缩成一组可以手算、画图和写代码检查的证据。

### ω的幂、逆元与共轭

因为 $\omega^3=1$，对任意非负整数 $n$ 有

$$
\omega^n=\omega^{n\bmod 3}.
$$

这个式子在说：指数除以 3 的余数决定状态，余数 0、1、2 分别对应 $1,\omega,\omega^2$。这就是最小正 <Term def="使离散状态重新回到初始状态的正整数步数">周期</Term>为 3 的严格含义。

又因为 $\omega\omega^2=\omega^3=1$，所以 $\omega^{-1}=\omega^2$。而单位圆上的镜像会把角度 $2\pi/3$ 变成 $-2\pi/3$，因此 <Term def="把复数 a+bi 变成 a−bi 的关于实轴镜像操作">共轭</Term>满足 $\overline\omega=\omega^2$。逆元、平方和共轭从不同方向指向同一个点，是很好的交叉验算。

### 为什么 $1+\omega+\omega^2=0$

三个根来自 $x^2+x+1=0$，所以直接得到

$$
1+\omega+\omega^2=0.
$$

这个式子在说：三个等角单位向量的总和为零。代入坐标也能检查：实部为 $1-1/2-1/2=0$，虚部为 $\sqrt3/2-\sqrt3/2=0$。

几何证明更短：三个点是正三角形的顶点，且以原点为中心。把三条向量同时乘以 ω，只会循环置换它们；若总和是 $S$，旋转后仍是同一组向量，所以 $\omega S=S$。因为 $\omega\ne1$，只能有 $S=0$。

### 从三次推广到 N 次

所有 $N$ 次单位根可以写成

$$
\zeta_k=\exp\!\left(\frac{2\pi i k}{N}\right),\qquad k=0,1,\ldots,N-1.
$$

这个式子在说：它们是正 $N$ 边形的顶点；乘以 $\zeta_1$ 会把每个顶点推到下一个顶点。要注意满足 $z^N=1$ 不等于“第一次在第 N 步回到 1”，例如 $-1$ 是四次单位根，但它的实际阶是 2。

从集合的对称性看，只要 $N>1$，所有 $N$ 次单位根的和都为 0。若代码要验证它，既要检查每个点的 $N$ 次方接近 1，也要检查点数、角度间隔与总和误差，不能只看一个浮点输出。

```ts
type RootCheck = { angle: number; real: number; imag: number };

export function rootsOfUnity(n: number): RootCheck[] {
  return Array.from({ length: n }, (_, k) => {
    const angle = (2 * Math.PI * k) / n;
    return { angle, real: Math.cos(angle), imag: Math.sin(angle) };
  });
}

export function residual(point: RootCheck, n: number) {
  const poweredAngle = point.angle * n;
  return Math.hypot(Math.cos(poweredAngle) - 1, Math.sin(poweredAngle));
}
```

代码只负责产生和测试点，精确结论仍来自因式分解、角度枚举与对称证明。把两种证据分开，才能知道误差是浮点近似，还是公式本身写错。

<Callout type="trap" title="陷阱三：把周期、阶和浮点近似混成一件事">
**现象 →** 看到 `ω⁴` 的数值接近 `ω` 就说周期“可能是 4”，或把 `0.999999999` 当成一个新根。

**原因 →** 没有区分最小正周期、满足某次方为 1 的条件，以及浮点数的近似误差。

**修法 →** 用指数模 3 得出精确周期，用最小正整数定义阶，再用残差阈值报告数值检查，而不是改写符号结论。

</Callout>

## 小结：四条不变量

- 复数同时携带两个坐标，极形式把模长和方向分开。
- 单位根位于单位圆，乘法更新就是固定角度的旋转。
- ω 的指数按模 3 循环，逆元与共轭都等于 ω²。
- 正三角形的三条向量相互抵消，所以 $1+\omega+\omega^2=0$。

## 练习与答案

<Exercises>

1. **问题 1：振动与旋转**

为什么 $z=e^{i\theta}$ 的实部和虚部可以看成两条振动？请说明它们由什么共同驱动，并指出乘以单位复数时哪一个量保持不变。

<Answer>

由欧拉形式，$z=\cos\theta+i\sin\theta$，所以实部是 $\cos\theta$，虚部是 $\sin\theta$，二者都由同一个角度随时间变化。乘以模长为 1 的复数时模长保持不变，只增加辐角。

</Answer>

2. **问题 2：复数与单位根**

用两种方法验证 $x^3=1$ 的根是 $1,\omega,\omega^2$：一次用因式分解，一次用模长和辐角。为什么角度只需取三个值？

<Answer>

因式分解为 $(x-1)(x^2+x+1)$，得到 $1$ 和二次因式的两个根。极形式要求模长为 1、$3\theta=2\pi k$；在一个完整圆周内，$k=0,1,2$ 已给出三个不同角度，其他整数只重复它们。

</Answer>

3. **问题 3：周期与对称**

计算 $\omega^8$、$\omega^{-1}$ 和 $1+\omega+\omega^2$。请分别用指数余数、乘法逆元和几何对称说明答案。

<Answer>

因为 $8\bmod3=2$，所以 $\omega^8=\omega^2$；由 $\omega\omega^2=1$，得 $\omega^{-1}=\omega^2$；三个单位根构成以原点为中心的正三角形，向量和为 0，因此 $1+\omega+\omega^2=0$。

</Answer>

4. **问题 4：改 Demo 代码**

在 `rootsOfUnity` 中加入一个 `sum` 检查，返回所有根的实部和虚部，并显示 $N=3$ 时它们都接近 0。你还要怎样避免把 `N=1` 的特殊情况误当成“非平凡对称”？

<Answer>

用循环累加 `real` 与 `imag`，再用 `Math.hypot(sumReal, sumImag)` 得到总和残差。将“总和应接近 0”的断言限制在 `n > 1`，并单独处理 `n <= 0` 的非法输入；`N=1` 只有根 1，不是多点抵消的例子。

</Answer>

</Exercises>
