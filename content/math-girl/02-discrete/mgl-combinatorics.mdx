## 加法原理与乘法原理

### 互斥分类才直接相加

若有限集合`A,B`不相交：

$$
|A\cup B|=|A|+|B|.
$$

这就是。若类别重叠，直接相加会重复计数，必须先改成互斥分类或使用容斥。

### 分阶段选择才相乘

若第一步有`m`种选择，并且每个第一步结果之后都有`n`种第二步选择，则：

$$
m\cdot n
$$

个结果。这是。若后续选择数依赖前面的具体选择，不能机械乘一个固定数；应画决策树，对各分支的后续数量求和。

### 排列与组合

从`n`个不同元素中选`k`个并排成有序位置：

$$
P(n,k)=n(n-1)\cdots(n-k+1)=\frac{n!}{(n-k)!}.
$$

关心顺序。若只选一个`k`元素子集，每个子集在排列中被重复`k!`次，所以数为：

$$
\binom nk=\frac{n!}{k!(n-k)!}.
$$

交换两个已选元素后若结果不变，就应使用组合；若对应不同职位、时间或位置，就应使用排列。


## 二项式系数与格路径

### 帕斯卡递推

固定一个特别元素`e`。从`n`个元素选`k`个的子集可互斥分成“包含e”和“不包含e”：

$$
\binom nk
=\binom{n-1}{k-1}+\binom{n-1}{k}.
$$

这既是递推，也是动态规划转移。边界是：

$$
\binom n0=\binom nn=1.
$$

：

$$
(a+b)^n=\sum_{k=0}^{n}\binom nk a^{n-k}b^k.
$$

它把代数展开与“n次选择中有k次选b”连接起来。

### 无约束格路径

从`(0,0)`走到`(r,u)`，每步只向右或向上。任何路径由`r+u`个符号构成，只需选择哪`r`个位置放右移：

$$
\#\text{paths}=\binom{r+u}{r}.
$$

若路径不得越过边界，简单组合数不再够用。第4卷钢琴问题使用；也可以用逐格统计。

## 卡特兰数：同一递推背后的不同对象

合法括号串、满二叉树、凸多边形三角剖分和不过界格路径都由计数：

$$
C_0=1,\qquad
C_{n+1}=\sum_{i=0}^{n}C_iC_{n-i}.
$$

闭式是：

$$
C_n=\frac1{n+1}\binom{2n}{n}.
$$

但看到公式相同还不算证明。必须给出：

- 把对象按根或第一对括号拆成左右子对象的递推；
- 或者构造两个对象集合间的；
- 或者从生成函数推导系数。


## 卷积、生成函数与整数分拆

### 卷积记录“总规模怎样拆开”

两个数列`aₙ,bₙ`的：

$$
c_n=\sum_{i=0}^{n}a_i b_{n-i}.
$$

它表达“先把总规模n拆成i与n-i，再独立选择左右对象”。若：

$$
A(x)=\sum_{n\ge0}a_nx^n,\qquad
B(x)=\sum_{n\ge0}b_nx^n,
$$

则乘积中`xⁿ`的系数正是卷积：

$$
[x^n]A(x)B(x)=c_n.
$$

把递归计数变成代数方程，这是第1卷的重要主线。

### 分拆不等于组成

例如4有：

$$
4,\quad3+1,\quad2+2,\quad2+1+1,\quad1+1+1+1
$$

五种。若顺序重要，`3+1`与`1+3`不同，那叫，数量完全不同。第1卷第10章通过分拆数展示“同一个总量可以怎样由局部结构组成”。

## 容斥与可执行验证

### 容斥纠正重复

对两个集合：

$$
|A\cup B|=|A|+|B|-|A\cap B|.
$$

扩展到多个集合时，要加入所有单集合、减去所有两两交集、加回三重交集，依次交替。漏掉高阶交集会得到错误答案。

### 动态规划与小规模穷举

组合公式应有第二条证据。下面用大整数动态规划计算二项式系数：

```ts
export function choose(n: number, k: number): bigint {
  if (!Number.isInteger(n) || !Number.isInteger(k) || n < 0 || k < 0 || k > n) {
    return 0n;
  }

  const width = Math.min(k, n - k);
  const dp = Array<bigint>(width + 1).fill(0n);
  dp[0] = 1n;

  for (let row = 1; row <= n; row += 1) {
    for (let column = Math.min(row, width); column >= 1; column -= 1) {
      dp[column] += dp[column - 1];
    }
  }

  return dp[width];
}
```

倒序更新是为了防止当前行的新值覆盖仍需使用的上一行状态。验收可同时检查：

$$
\binom nk=\binom n{n-k},\qquad
\sum_{k=0}^{n}\binom nk=2^n.
$$

再对小`n`枚举全部位掩码，按1的个数分组，与每个`C(n,k)`对照。


## 从计数到概率与算法

在有限等可能样本空间中：

$$
\Pr(E)=\frac{|E|}{|\Omega|}.
$$

但非均匀随机过程不能只除数量。第4卷随机漫步路径既要数合法路径，也要乘每种步型的概率；随机3-SAT精确分析把“靠近”和“远离”路径数与`1/3、2/3`权重结合。

计数也解释候选空间尺度：

- 元素无序对有`C(n,2)=Θ(n²)`个；
- `n`元素全部子集有`2ⁿ`个；
- 全排列有`n!`个。

这些是问题规模，不自动等于算法步数。还要说明算法访问哪些候选、是否重复、每个候选处理多久。

若任务要求把所有对象逐一输出，计数还能给出：输出`N`个彼此不同的对象至少要产生`N`份可区分结果，算法不可能比输出本身还少做数量级上的工作。但决策问题只问“是否存在”，不需要列出全部候选，可能借助结构、动态规划或代数方法绕开枚举。因而同一个组合集合，在“计数”“列举”“随机抽样”“判断存在性”四类任务中会产生不同算法边界。

## 本章回顾：先定义对象，再选择公式

1. 计数前先写对象、同一性标准、顺序、重复和边界。
2. 加法原理要求分类互斥，乘法原理要求阶段选择数明确。
3. 排列关心顺序，组合只关心子集。
4. 帕斯卡递推来自是否包含固定元素的互斥分类。
5. 二项式定理把代数展开与逐次选择连接起来。
6. 无约束格路径由选择步型位置得到组合数。
7. 边界路径需要反射原理或动态规划。
8. 卡特兰公式必须由递推、双射或生成函数证明。
9. 卷积枚举总规模拆分，生成函数乘法自动完成卷积。
10. 整数分拆忽略加数顺序，整数组成保留顺序。
11. 容斥按交集阶数交替加减以纠正重复。
12. 动态规划结果应与恒等式和小规模穷举交叉验证。
13. 概率还需说明等可能性或路径权重。
14. 本页是跨卷导读，不替代原书章节。
