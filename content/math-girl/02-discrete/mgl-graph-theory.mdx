## 建图合同：先决定允许什么

### 简单图、多重图与有向图

<Term def="边没有方向，连接关系对两个端点对称的图。">无向图</Term>适合表达互相连接；<Term def="每条边有起点和终点、关系可能不对称的图。">有向图</Term>适合表达依赖、调用或状态转移。<Term def="同一对顶点之间允许存在多条不同边的图。">多重图</Term>可表示两块陆地间多座桥；若用邻接集合去重，就会在算法开始前丢掉桥。

<Term def="两个端点为同一顶点的边，在无向图的顶点度中贡献2。">自环</Term>也必须进入模型合同。哥尼斯堡七桥是无向多重图：桥是独立边，即使端点相同也不能合并。

### 度与握手定理

无向多重图中，顶点`v`的<Term def="与顶点关联的边端数量；无向自环贡献两个边端。">度</Term>记作`deg(v)`。每条非自环边给两个端点各贡献1，自环给同一顶点贡献2，所以：

$$
\sum_{v\in V}\deg(v)=2|E|.
$$

这就是<Term def="无向图全部顶点度数之和等于边数两倍的恒等式。">握手定理</Term>。右边是偶数，因此奇度顶点数量必为偶数。

### 路径与连通分量

<Term def="相邻顶点之间由边连接形成的顶点与边序列。">路径</Term>表达可达性。若任意两顶点互相可达，图连通；一般图会分成若干<Term def="内部任意两点可达且不能再加入其他顶点的最大连通子图。">连通分量</Term>。孤立顶点度为0，在“是否能走遍所有已有边”的欧拉问题中可以忽略，但不能在“访问所有顶点”的哈密顿问题中忽略。

## BFS、DFS与遍历证据

### 广度优先搜索

<Term def="用队列按距起点边数逐层访问图顶点的遍历算法。">广度优先搜索</Term>简称BFS。在无权图中，顶点第一次被发现时的层数就是从起点出发的最短边数。它应输出：

- `distance[v]`：最短边数；
- `parent[v]`：一条最短路径树中的父节点；
- 访问状态，防止重复入队。

### 深度优先搜索

<Term def="沿未访问邻接点不断深入，无法继续时回退的遍历算法。">深度优先搜索</Term>简称DFS。它适合寻找连通分量、检测环、建立拓扑结构。递归实现依赖调用栈，深图中可能栈溢出；显式栈实现更容易控制资源。

无论BFS还是DFS，邻接表上的时间复杂度都是：

$$
\Theta(|V|+|E|),
$$

前提是每个顶点和每条边只被常数次处理。多重无向边若在两个端点邻接表都出现，仍只是`2|E|`个边端。

```ts
export function bfs(
  adjacency: ReadonlyArray<ReadonlyArray<number>>,
  start: number,
): { distance: number[]; parent: Array<number | null> } {
  const distance = Array<number>(adjacency.length).fill(-1);
  const parent = Array<number | null>(adjacency.length).fill(null);
  const queue = [start];
  distance[start] = 0;

  for (let head = 0; head < queue.length; head += 1) {
    const vertex = queue[head];
    for (const neighbor of adjacency[vertex]) {
      if (distance[neighbor] !== -1) continue;
      distance[neighbor] = distance[vertex] + 1;
      parent[neighbor] = vertex;
      queue.push(neighbor);
    }
  }

  return { distance, parent };
}
```

验收不只看访问顺序，还要对每条树边检查`distance[child]=distance[parent]+1`，并对每条图边检查两个端点层数差至多1。

## 树：多个条件在何时等价

在有限无向简单图中，以下条件对`n≥1`等价：

1. 图连通且无环；
2. 任意两顶点间恰有一条简单路径；
3. 图连通且边数为`n-1`；
4. 图无环且边数为`n-1`。

满足这些条件的图叫<Term def="有限无向图中连通且无环的图。">树</Term>。只说“有`n-1`条边”不够：一个三角形加一个孤立点有4个顶点、3条边，却不是树。

树的边数关系可单独写成：

$$
|E|=|V|-1.
$$

它既可用删除叶节点归纳证明，也可从“每加入一个新顶点，恰好用一条边连接且不成环”理解。反向使用时必须同时带上连通或无环条件。

第1卷卡特兰数计数某些有根有序二叉树；第4卷比较排序的<Term def="内部节点表示一次比较、分支表示比较结果、叶子表示最终排列的树。">比较决策树</Term>用叶子数量推导比较下界。这里的“树”共享无环分支结构，但节点语义不同。

## 欧拉路径：过边问题

<Term def="在一次行走中恰好使用图中每条边一次的路径。">欧拉路径</Term>关心边，不要求每个顶点只出现一次。对于有限无向多重图：

- 所有度数非零的顶点必须在同一个连通分量；
- 恰有0个奇度顶点时存在<Term def="使用每条边一次并回到起点的欧拉路径。">欧拉回路</Term>；
- 恰有2个奇度顶点时存在起终点不同的欧拉开路径；
- 其他情况不存在。

必要性来自中间顶点每次进入都要用另一条未用边离开，所以使用的边端成对；开路径只有起点和终点各留下一个奇数边端。充分性可由Hierholzer算法构造。

哥尼斯堡七桥的四个陆地顶点度数为`3,3,3,5`，有4个奇度顶点，因此不可能每桥恰走一次。

下面的分类函数显式检查非零度顶点连通，并用独立边列表保留平行边和自环：

```ts
type Edge = { u: number; v: number };

export function classifyEulerTrail(
  vertexCount: number,
  edges: ReadonlyArray<Edge>,
): "circuit" | "open-trail" | "none" {
  const degree = Array<number>(vertexCount).fill(0);
  const adjacency = Array.from({ length: vertexCount }, () => [] as number[]);

  edges.forEach(({ u, v }, edgeId) => {
    degree[u] += 1;
    degree[v] += 1;
    adjacency[u].push(edgeId);
    adjacency[v].push(edgeId);
  });

  const start = degree.findIndex((value) => value > 0);
  if (start === -1) return "circuit";

  const visited = new Set<number>([start]);
  const stack = [start];
  while (stack.length > 0) {
    const vertex = stack.pop()!;
    for (const edgeId of adjacency[vertex]) {
      const { u, v } = edges[edgeId];
      const neighbor = u === vertex ? v : u;
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        stack.push(neighbor);
      }
    }
  }

  if (degree.some((value, vertex) => value > 0 && !visited.has(vertex))) {
    return "none";
  }

  const oddCount = degree.filter((value) => value % 2 === 1).length;
  return oddCount === 0 ? "circuit" : oddCount === 2 ? "open-trail" : "none";
}
```

自环在边列表中令`u=v`，两次执行度数加一，正确贡献2。

## 哈密顿、TSP与最小生成树

### 哈密顿回路：过点问题

<Term def="经过图中每个顶点恰好一次并回到起点的回路。">哈密顿回路</Term>关心顶点。一般图的哈密顿回路判定是NP完全问题，不能套用欧拉问题的奇偶度条件。给出一条候选回路后，可以在多项式时间验证顶点不重复、全部覆盖且相邻项有边；高效寻找候选则是另一回事。

### 旅行商问题

<Term def="在带权完全图中寻找访问每个顶点一次并回到起点的最小权重回路。">旅行商问题</Term>简称TSP，是优化问题且一般情形NP困难。精确算法、近似算法和启发式要区分：

- Held-Karp动态规划仍需指数级状态；
- Christofides算法只对满足对称性和三角不等式的<Term def="边权非负、对称且满足三角不等式的旅行商实例。">度量TSP</Term>保证不超过最优值的1.5倍；
- 最近邻、局部搜索和模拟退火可能实用，但没有同样的一般最坏近似保证。

### 最小生成树

<Term def="包含连通带权图全部顶点、无环且总边权最小的子图。">最小生成树</Term>不要求形成回路，也不要求顶点访问顺序。Kruskal按边权排序并用并查集避免成环；Prim从已连接顶点集合跨割选择最轻边。正确性依赖<Term def="任意割上某条最轻跨割边可以安全加入某棵最小生成树的性质。">割性质</Term>，不是“每次选最短边”这一句直觉。

## 与矩阵和随机漫步的连接

对顶点编号后，<Term def="第i行第j列记录顶点i到j是否有边或边数的矩阵。">邻接矩阵</Term>`A`把一步关系写成代数。矩阵幂`(Aᵏ)ᵢⱼ`在适当图模型下计数从`i`到`j`长度为`k`的游走。

随机漫步则用<Term def="第i行第j列记录状态i一步转移到状态j概率的矩阵。">转移矩阵</Term>`P`：

$$
\mathbf p_{t+1}=P\mathbf p_t.
$$

第4卷孤零零随机漫步正是二状态图；特征值解释分布如何趋向稳定。图提供关系，矩阵提供可重复复合的运算表示。

## 本章回顾：先建对图，再选算法

1. 本页是补充导读，不属于前四卷权威章节。
2. 建图必须声明顶点、边、方向、平行边和自环。
3. 无向自环对顶点度贡献2，握手定理给出度数和等于两倍边数。
4. 奇度顶点数必为偶数。
5. BFS提供无权最短层次，DFS提供深入与回退结构。
6. 在有限无向简单图中，连通无环、唯一路径和连通且n-1边等价。
7. 只有n-1条边不能单独推出是树。
8. 欧拉路径过边，必须同时检查非零度连通性和奇度数。
9. 哈密顿回路过点，一般判定为NP完全。
10. TSP寻找最短哈密顿回路，一般优化问题为NP困难。
11. Christofides的1.5保证只适用于度量对称TSP。
12. 最小生成树由割性质支撑，不等同于TSP。
13. 邻接矩阵和转移矩阵把图关系接到第4卷矩阵与随机漫步。

<Exercises>

**问题 1：一个无向图由一个四边形分量和一个三角形分量组成。所有顶点度都为2，它有欧拉回路吗？**

<Answer>没有覆盖全部边的单个欧拉回路。虽然奇度顶点数为0，但所有非零度顶点不在同一连通分量，无法从一个分量走到另一个分量。</Answer>

**问题 2：证明无向图奇度顶点数量必为偶数。**

<Answer>握手定理给`Σdeg(v)=2|E|`，总和为偶数。偶度顶点贡献偶数，剩余奇度顶点的奇数之和也必须为偶数；奇数个奇数之和为奇数，因此奇度顶点个数只能是偶数。</Answer>

**问题 3：构造一个有4个顶点、3条边但不是树的简单无向图。**

<Answer>让三个顶点组成三角形，第四个顶点孤立。总顶点数4、边数3等于n-1，但图不连通且含环，因此不是树。</Answer>

**问题 4：为什么不能把Christofides的1.5近似比用于任意TSP？**

<Answer>证明依赖边权对称与三角不等式，以便用最小生成树、奇度顶点匹配和捷径化控制代价。非度量或非对称实例不满足这些步骤的代价上界，因此保证不成立。</Answer>

</Exercises>
