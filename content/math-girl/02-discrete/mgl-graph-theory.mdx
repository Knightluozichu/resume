## 直觉引入

哥尼斯堡七桥问题：城市有 4 块陆地、7 座桥，能否每座桥走一次且仅走一次？欧拉在 1736 年证明了不可能，并由此创立了图论。

把陆地看作顶点，桥看作边，问题变成：能否在图上找到一条经过每条边恰好一次的路径？这就是欧拉路径问题。图论就是用顶点和边来描述关系，是网络、路由、社交分析的数学基础。

## 概念讲解

### 图论基本概念

<MglGraphTheoryDiagram />

<Term def="图 G=(V,E) 由顶点集 V 和边集 E 组成，边连接顶点表示关系">
图
</Term>

- **度**：与顶点相连的边数。
- **连通图**：任意两个顶点之间都有路径。
- **树**：无环的连通图。$n$ 个顶点的树恰好有 $n-1$ 条边。

### 欧拉路径与回路

<Stepper>
<Step title="欧拉路径的判定">
一条经过每条边恰好一次的路径。存在条件：图连通，且**恰好有 0 个或 2 个奇度顶点**。0 个奇度顶点时起点终点相同（欧拉回路），2 个时起点终点不同。
</Step>
<Step title="哥尼斯堡七桥">
4 块陆地的度数分别是 3, 3, 3, 5——全是奇数，有 4 个奇度顶点。不满足「0 个或 2 个奇度顶点」的条件，所以欧拉路径不存在。这就是欧拉证明「不可能」的方法。
</Step>
<Step title="欧拉回路">
经过每条边一次且回到起点的回路。条件：图连通且**所有顶点度数为偶数**。 Fleury 算法或 Hierholzer 算法可构造欧拉回路。
</Step>
</Stepper>

### 哈密顿回路与旅行商

<Term def="哈密顿回路是经过每个顶点恰好一次并回到起点的回路，判定是 NP 完全问题">
哈密顿回路
</Term>

哈密顿回路要求经过每个**顶点**一次（欧拉要求经过每条**边**一次）。判定一个图是否有哈密顿回路是 NP 完全问题——没有已知的多项式算法。

**旅行商问题（TSP）**：访问所有城市各一次再返回，求最短路径。是哈密顿回路的优化版本，也是 NP 困难。实际中用近似算法（如最近邻、模拟退火）求解。

### 树与生成树

**树**是连通无环图，是最重要的图结构之一。$n$ 个顶点的树有 $n-1$ 条边，任意两点间路径唯一。**生成树**是连通图的子图，包含所有顶点且是树。**最小生成树**（MST）是边权之和最小的生成树，用 Kruskal 或 Prim 算法求解。

## 代码对照

```python
# 判断图是否有欧拉路径/回路
def has_eulerian(graph):
    """
    graph: 邻接表 {顶点: [邻居列表]}
    返回: 'circuit'（欧拉回路）/ 'path'（欧拉路径）/ 'none'
    """
    # 统计每个顶点的度
    degrees = {v: len(neighbors) for v, neighbors in graph.items()}

    # 检查连通性（简化：假设已检查）
    # 统计奇度顶点数
    odd_count = sum(1 for d in degrees.values() if d % 2 == 1)

    if odd_count == 0:
        return 'circuit'  # 所有度数为偶数 → 欧拉回路
    elif odd_count == 2:
        return 'path'     # 恰好 2 个奇度顶点 → 欧拉路径
    else:
        return 'none'     # 其他情况 → 不存在

# 哥尼斯堡七桥：度数 [3, 3, 3, 5] → 4 个奇度 → 不存在
konigsberg = {'A': ['B','B','C'], 'B': ['A','A','C'], 'C': ['A','B','D'], 'D': ['C','C','C']}
print(has_eulerian(konigsberg))  # 'none'

# Hierholzer 算法求欧拉回路
def find_euler_circuit(graph, start):
    circuit = []
    def visit(node):
        while graph[node]:
            neighbor = graph[node].pop()
            graph[neighbor].remove(node)  # 双向删除边
            visit(neighbor)
        circuit.append(node)
    visit(start)
    return circuit[::-1]  # 逆序输出

# 最小生成树（Kruskal 算法）核心思路：
# 1. 所有边按权值排序
# 2. 从小到大选边，不形成环就加入
# 3. 用并查集检测环
```

## 常见误区

<Callout type="trap">
**误区：混淆欧拉路径和哈密顿回路。**
欧拉路径要求经过每条**边**一次，判定条件简单（奇度顶点数 0 或 2）。哈密顿回路要求经过每个**顶点**一次，判定是 NP 完全问题（没有简单条件）。一个图可能有欧拉路径但没哈密顿回路，反之亦然。
</Callout>

<Callout type="trap">
**误区：认为旅行商问题有最优解的高效算法。**
TSP 是 NP 困难问题，没有已知的多项式时间最优算法。精确解法（如动态规划 Held-Karp）是 $O(n^2 2^n)$，只能处理小规模。大规模问题用近似算法（如 Christofides 算法保证 1.5 倍近似比）或启发式算法（模拟退火、遗传算法）。
</Callout>

<Exercises>
**问题 1**：一个连通图有 4 个顶点，度数分别为 2, 3, 3, 4。它有欧拉路径吗？有欧拉回路吗？

<Answer>
奇度顶点有 2 个（度数为 3 的两个顶点），满足欧拉路径的条件（恰好 2 个奇度顶点），所以有欧拉路径。但不满足欧拉回路的条件（需要所有顶点度数为偶数），所以没有欧拉回路。欧拉路径的起点和终点分别是两个奇度顶点。
</Answer>

**问题 2**：$n$ 个顶点的树有多少条边？为什么？

<Answer>
$n$ 个顶点的树有 $n-1$ 条边。证明：树是连通无环图。从任意顶点开始，每加一个新顶点恰好需要一条边连接（连通且不形成环），所以 $n$ 个顶点需要 $n-1$ 条边。反过来，$n-1$ 条边的连通图一定是树（无环）。这个性质在最小生成树算法中至关重要。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="欧拉路径">
经过图中每条边恰好一次的路径。存在条件：图连通且奇度顶点数为 0 或 2。
</GlossaryItem>
<GlossaryItem term="哈密顿回路">
经过图中每个顶点恰好一次并回到起点的回路。判定是 NP 完全问题，无简单充要条件。
</GlossaryItem>
<GlossaryItem term="树">
连通无环图。n 个顶点的树有 n-1 条边，任意两点间路径唯一。是数据结构中树（BST、堆）的数学基础。
</GlossaryItem>
<GlossaryItem term="最小生成树">
连通图中边权之和最小的生成树。Kruskal 算法（按边权排序+并查集）和 Prim 算法（贪心扩展）可在 O(E log V) 求解。
</GlossaryItem>
</Glossary>
