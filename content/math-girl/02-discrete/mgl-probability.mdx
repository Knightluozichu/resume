## 直觉引入

抛硬币正面朝上的概率是 1/2，但如果已知硬币被做了手脚（正面更重），概率就变了。这就是条件概率——在已知部分信息时更新概率。

贝叶斯定理把这种「根据新证据更新信念」的过程精确化。它是垃圾邮件过滤、医学诊断、机器学习的核心。理解概率，就是理解如何在不确定性中做决策。

## 概念讲解

### 概率基础

<MglProbabilityDiagram />

<Term def="概率是随机事件发生可能性的度量，取值 [0,1]，满足非负性、规范性和可列可加性">
概率
</Term>

- **样本空间** $\Omega$：所有可能结果的集合。
- **事件** $A$：样本空间的子集。$P(A) = |A|/|\Omega|$（等可能模型）。
- **概率公理**：$P(A) \geq 0$，$P(\Omega) = 1$，互斥事件之并的概率等于概率之和。

### 条件概率与贝叶斯定理

<Stepper>
<Step title="条件概率">
$P(A|B) = \frac{P(A \cap B)}{P(B)}$。在 $B$ 已发生的条件下 $A$ 发生的概率。如 $P(\text{下雨}|\text{阴天}) > P(\text{下雨})$。
</Step>
<Step title="贝叶斯定理">
$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$。根据观察到的证据 $B$ 更新假设 $A$ 的概率。核心思想：后验概率 = 似然 × 先验概率 / 证据。
</Step>
<Step title="贝叶斯应用示例">
医学检测：某病发病率 1%（先验），检测准确率 99%。检测阳性时真患病的概率 $P(\text{病}|\text{阳性}) = \frac{0.99 \times 0.01}{0.99 \times 0.01 + 0.01 \times 0.99} = 50\%$。直觉上 99% 准确，但阳性时只有 50% 真患病——因为假阳性率在健康人群中基数大。
</Step>
</Stepper>

### 期望与方差

<Term def="期望是随机变量的平均值，方差度量偏离期望的程度">
期望
</Term>

- **期望**：$E[X] = \sum x_i \cdot P(x_i)$。抛骰子的期望 = $(1+2+3+4+5+6)/6 = 3.5$。
- **方差**：$\text{Var}(X) = E[(X - E[X])^2]$。方差越大，波动越大。
- **期望的线性性**：$E[aX + bY] = aE[X] + bE[Y]$（无论 $X, Y$ 是否独立）。快速排序的平均比较次数分析就用到期望线性性。

## 代码对照

```python
import random

# 蒙特卡洛模拟：用随机采样估计概率
def estimate_pi(n=1000000):
    """用蒙特卡洛方法估计 π"""
    inside = 0
    for _ in range(n):
        x, y = random.random(), random.random()
        if x**2 + y**2 <= 1:  # 在单位圆内
            inside += 1
    return 4 * inside / n  # π ≈ 4 × (圆内点数 / 总点数)

# 贝叶斯定理计算
def bayes(prior, likelihood, false_positive_rate):
    """
    prior: P(病) 先验概率
    likelihood: P(阳性|病) 真阳性率
    false_positive_rate: P(阳性|无病) 假阳性率
    返回: P(病|阳性) 后验概率
    """
    # P(阳性) = P(阳性|病)×P(病) + P(阳性|无病)×P(无病)
    evidence = likelihood * prior + false_positive_rate * (1 - prior)
    # 贝叶斯: P(病|阳性) = P(阳性|病)×P(病) / P(阳性)
    posterior = likelihood * prior / evidence
    return posterior

# 医学检测示例
p_disease = 0.01         # 发病率 1%
p_positive_given_disease = 0.99  # 真阳性率 99%
p_positive_given_healthy = 0.01  # 假阳性率 1%
result = bayes(p_disease, p_positive_given_disease, p_positive_given_healthy)
print(f"检测阳性时真患病的概率: {result:.1%}")  # 50.0%

# 期望计算：随机算法分析
def expected_comparisons_quickselect(n):
    """Quickselect 找第 k 小的平均比较次数 ≈ 2n"""
    return 2 * n  # 期望线性性分析的结果
```

## 常见误区

<Callout type="trap">
**误区：检测准确率 99% 意味着阳性就是 99% 患病。**
这是「基础率谬误」。99% 是 $P(\text{阳性}|\text{病})$，而你关心的是 $P(\text{病}|\text{阳性})$。当发病率很低（1%）时，假阳性人数（99%×1% = 0.99%）接近真阳性人数（1%×99% = 0.99%），所以阳性时只有约 50% 真患病。贝叶斯定理精确计算了这个差异。
</Callout>

<Callout type="trap">
**误区：认为期望就是最可能出现的值。**
期望是加权平均，不一定是最可能的值。抛骰子期望 3.5，但你永远掷不出 3.5。期望衡量的是「长期平均」，大数定律保证多次实验的均值趋近期望。
</Callout>

<Exercises>
**问题 1**：用贝叶斯定理计算：发病率 0.1%，检测灵敏度 99%，特异度 95%（假阳性率 5%）。检测阳性时真患病的概率是多少？

<Answer>
$P(\text{病}|\text{阳性}) = \frac{P(\text{阳性}|\text{病}) \times P(\text{病})}{P(\text{阳性})} = \frac{0.99 \times 0.001}{0.99 \times 0.001 + 0.05 \times 0.999} = \frac{0.00099}{0.00099 + 0.04995} \approx \frac{0.00099}{0.05094} \approx 1.94\%$。即使检测阳性，真患病概率仅约 2%——因为发病率极低，假阳性人数远超真阳性。
</Answer>

**问题 2**：为什么快速排序的平均时间复杂度分析需要用到期望？

<Answer>
快排的运行时间取决于 pivot 的选择，是随机的。每次划分把数组分成两部分的比例不确定。通过期望分析：$E[T(n)] = E[\text{划分时间}] + E[T(\text{左半})] + E[T(\text{右半})]$。利用期望的线性性和 pivot 的均匀分布假设，可以证明 $E[T(n)] = O(n \log n)$。期望分析是随机算法复杂度分析的核心工具。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="条件概率">
P(A|B)=P(A∩B)/P(B)，在 B 已发生的条件下 A 发生的概率。是贝叶斯定理的基础。
</GlossaryItem>
<GlossaryItem term="贝叶斯定理">
P(A|B)=P(B|A)×P(A)/P(B)，根据证据 B 更新假设 A 的概率。后验=似然×先验/证据。
</GlossaryItem>
<GlossaryItem term="期望">
随机变量的加权平均值 E[X]=ΣxᵢP(xᵢ)。期望具有线性性 E[aX+bY]=aE[X]+bE[Y]。
</GlossaryItem>
<GlossaryItem term="基础率谬误">
忽视先验概率（基础率）导致的概率判断错误。如检测准确率高但发病率低时，阳性预测值远低于直觉。
</GlossaryItem>
</Glossary>
