## 直觉引入

算法设计的三大范式——分治、贪心、动态规划——本质上是三种不同的数学思维。

分治是「分而治之」，把大问题拆成小问题，像递归一样。贪心是「目光短浅」，每步选当前最优，期望全局最优。动态规划是「记住过去」，避免重复计算，用空间换时间。选择哪种范式，取决于问题的数学结构。

### 分治法

<Term def="分治法把问题分解为同类子问题，递归求解后合并结果">
分治法
</Term>

三步：**分解**（分成子问题）→ **递归**（求解子问题）→ **合并**（合并子问题的解）。

归并排序是典型：把数组对半分，递归排序两半，合并。$T(n) = 2T(n/2) + O(n) = O(n \log n)$。快速排序也是分治：选 pivot 划分，递归排序两部分。

### 贪心算法

<Term def="贪心算法每步选择当前最优解，期望得到全局最优">
贪心算法
</Term>

贪心算法简单高效，但**不保证全局最优**。只有当问题具有**贪心选择性质**（局部最优能导向全局最优）时才正确。

- **正确案例**：找零钱（用最大面额优先）、Dijkstra 最短路（每次选最近节点）、Huffman 编码。
- **错误案例**：找零钱面额为 [1, 3, 4]，找 6 元。贪心选 4+1+1=3 枚，但最优是 3+3=2 枚。

### 动态规划

<Stepper>
<Step title="两个核心条件">
①**最优子结构**：问题的最优解包含子问题的最优解。②**重叠子问题**：子问题被反复计算。DP 用记忆化（表格）避免重复计算。
</Step>
<Step title="自底向上 vs 自顶向下">
自底向上：从最小子问题开始填表，如斐波那契 `dp[0]=0, dp[1]=1, dp[i]=dp[i-1]+dp[i-2]`。自顶向下：递归+记忆化，从大问题出发，遇到子问题先查缓存。
</Step>
<Step title="经典案例：背包问题">
0-1 背包：$n$ 个物品各有重量 $w_i$ 和价值 $v_i$，背包容量 $W$，求最大价值。状态 `dp[i][j]` = 前 $i$ 个物品、容量 $j$ 的最大价值。转移：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])`。
</Step>
</Stepper>

## 代码对照

```python
# 分治：归并排序
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])     # 分解+递归
    right = merge_sort(arr[mid:])
    return merge(left, right)        # 合并

# 贪心：Dijkstra 最短路（每步选最近未访问节点）
import heapq
def dijkstra(graph, start):
    dist = {v: float('inf') for v in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)     # 贪心：取距离最小的
        if d > dist[u]:
            continue
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                heapq.heappush(pq, (dist[v], v))
    return dist

# 动态规划：0-1 背包
def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        for j in range(capacity + 1):
            dp[i][j] = dp[i-1][j]  # 不选第 i 个
            if j >= weights[i-1]:
                dp[i][j] = max(dp[i][j],
                               dp[i-1][j-weights[i-1]] + values[i-1])  # 选
    return dp[n][capacity]

# 动态规划：最长公共子序列（LCS）
def lcs(s1, s2):
    m, n = len(s1), len(s2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1  # 字符相同
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]
```

## 常见误区

<Callout type="trap">
**误区：贪心算法总是能得到最优解。**
贪心只在具有「贪心选择性质」的问题上有效。找零钱用标准面额（1,5,10,25）时贪心正确，但面额 [1,3,4] 找 6 元时贪心给出 3 枚（4+1+1），最优是 2 枚（3+3）。使用贪心前必须证明贪心选择性质。
</Callout>

<Callout type="trap">
**误区：动态规划和分治是一回事。**
两者都把问题分成子问题，但分治的子问题**不重叠**（如归并排序的两半独立），DP 的子问题**重叠**（如斐波那契的 fib(n-2) 被多次计算）。DP 用表格记忆化避免重复，分治不需要。
</Callout>

<Exercises>
**问题 1**：什么条件下动态规划适用？分治和动态规划的区别是什么？

<Answer>
DP 需要：①最优子结构（最优解包含子问题最优解）②重叠子问题（子问题被反复计算）。区别：分治的子问题不重叠（各独立），不需记忆化；DP 的子问题重叠，用表格避免重复计算。归并排序是分治（两半独立），斐波那契是 DP（fib(n-2) 被重复计算）。
</Answer>

**问题 2**：面额 [1, 3, 4] 找 6 元，贪心和最优解分别是什么？为什么贪心失败？

<Answer>
贪心：选最大面额 4，剩 2，选 1+1，共 4+1+1=3 枚。最优：3+3=2 枚。贪心失败因为不具备贪心选择性质——选当前最大面额 4 不能导向全局最优。这类问题应用动态规划：`dp[j] = min(dp[j], dp[j-w[i]] + 1)`。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="分治法">
把问题分解为同类子问题，递归求解后合并。子问题独立不重叠。如归并排序 O(n log n)。
</GlossaryItem>
<GlossaryItem term="贪心算法">
每步选当前最优，期望全局最优。仅在具贪心选择性质时正确。如 Dijkstra、Huffman 编码。
</GlossaryItem>
<GlossaryItem term="动态规划">
利用最优子结构和重叠子问题，用表格记忆化避免重复计算。自底向上填表或自顶向下记忆化。如背包、LCS。
</GlossaryItem>
<GlossaryItem term="最优子结构">
问题的最优解包含子问题的最优解。是动态规划和贪心算法适用的必要条件。
</GlossaryItem>
</Glossary>
