### 主线一：数学基础的层层递进

<Stepper>
<Step title="数论（第1章）→ 密码学">
质数、GCD、模运算是 RSA 的基石。欧几里得算法求模逆元，欧拉定理保证 RSA 解密正确。古老数论驱动现代密码学。
</Step>
<Step title="代数（第2-3章）→ 函数思维">
方程求解训练逻辑推理，函数论建立「输入→输出」映射。函数复合对应编程函数组合，逆函数对应反操作。这是函数式编程的数学原型。
</Step>
<Step title="离散数学（第4-6章）→ 算法分析">
组合计数是复杂度分析的工具（$C(n,2) \to O(n^2)$），图论是图算法的语言（BFS/DFS/MST），概率论是随机算法和 ML 的基础（贝叶斯/期望）。
</Step>
<Step title="算法与ML（第7-8章）→ 数学应用">
算法设计三大范式（分治/贪心/DP）依赖数学分析，机器学习是线性代数（矩阵）+ 微积分（梯度）+ 概率（模型）的综合应用。
</Step>
</Stepper>

### 主线二：数学与编程的对应关系

| 数学概念 | 编程对应 | 应用 |
|---|---|---|
| 函数 $f: X \to Y$ | 纯函数 | 函数式编程 |
| 函数复合 $f \circ g$ | 函数组合 | 管道/链式调用 |
| 逆函数 $f^{-1}$ | 反序列化/解码 | 数据编解码 |
| 模运算 | 哈希/取模 | 哈希表、RSA |
| 组合计数 | 复杂度分析 | $O(n^2), O(2^n)$ |
| 梯度下降 | 参数优化 | 机器学习训练 |

## 代码对照

```python
# 综合案例：用数学知识实现一个简单的加密+搜索系统
import hashlib

# 数论：模运算实现简单哈希
def simple_hash(data, mod=2**32):
    """利用模运算和质数性质做简单哈希"""
    h = 0
    for ch in data:
        h = (h * 31 + ord(ch)) % mod  # 31 是质数
    return h

# 组合数学：分析算法复杂度
def analyze_complexity(n):
    """用组合计数理解复杂度"""
    pairs = n * (n - 1) // 2     # C(n,2) → O(n²)
    subsets = 2 ** n              # 所有子集 → O(2ⁿ)
    permutations = 1
    for i in range(1, n + 1):
        permutations *= i         # n! → O(n!)
    return pairs, subsets, permutations

# 概率：蒙特卡洛估算
import random
def monte_carlo_pi(n=100000):
    inside = sum(1 for _ in range(n)
                 if random.random()**2 + random.random()**2 <= 1)
    return 4 * inside / n

# 机器学习：线性回归（代数+微积分）
def linear_fit(xs, ys):
    """y = ax + b，最小二乘法"""
    n = len(xs)
    sx, sy = sum(xs), sum(ys)
    sxx = sum(x * x for x in xs)
    sxy = sum(x * y for x, y in zip(xs, ys))
    # 解析解（线性代数）
    a = (n * sxy - sx * sy) / (n * sxx - sx * sx)
    b = (sy - a * sx) / n
    return a, b

# 全书闭环：数学驱动编程
# 数论 → 哈希加密
# 组合 → 复杂度分析
# 概率 → 蒙特卡洛
# 代数+微积分 → 机器学习
```

## 常见误区

<Callout type="trap">
**误区：学数学只是为了面试做题。**
数学是算法和 ML 的天花板。不懂数论就无法理解密码学，不懂线性代数就无法理解深度学习，不懂概率就无法理解随机算法。数学不是工具，而是理解计算本质的语言。
</Callout>

<Callout type="trap">
**误区：数学各分支是独立的。**
数学各分支深度关联：数论用到代数（费马大定理的证明用到椭圆曲线），图论用到组合（图的计数），机器学习同时需要线性代数+微积分+概率。全书的四段递进正是展现这种内在联系。
</Callout>

<Exercises>
**问题 1**：全书四大板块如何串联成「数学驱动计算」的闭环？

<Answer>
数论（质数/GCD/模运算）→ 密码学（RSA）；代数（方程/函数）→ 函数式编程思维；离散数学（组合/图论/概率）→ 算法分析与建模；算法与ML → 把前三步数学转化为计算方法。数学是理论基础，算法和ML是应用出口，形成闭环。
</Answer>

**问题 2**：举一个同时用到多个数学分支的算法/ML案例。

<Answer>
神经网络训练同时用到：①线性代数（矩阵乘法做前向传播）②微积分（偏导数和链式法则做反向传播）③概率论（交叉熵损失、随机梯度下降）④组合数学（网络结构和参数空间的复杂度分析）。这说明数学各分支在计算中是综合应用的，不是孤立的。
</Answer>
</Exercises>

</GlossaryItem>
<GlossaryItem term="算法分析">
用组合数学和概率论分析算法的时间和空间复杂度，是评估算法效率的数学工具。
</GlossaryItem>
