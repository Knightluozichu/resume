## 直觉引入

机器学习不是魔法，而是数学。线性回归是线性代数（矩阵求逆），梯度下降是微积分（偏导数），神经网络是函数复合（链式法则）。理解了这些数学，机器学习就不再是黑盒。

全书从数论走到机器学习，形成完整闭环：数论提供密码学的基石，代数提供函数变换的工具，离散数学提供建模语言，最终汇聚到机器学习——用数学让机器从数据中学习。

## 概念讲解

### 机器学习范式

<MglMachineLearningDiagram />

<Term def="监督学习是从标注数据中学习输入到输出的映射函数">
监督学习
</Term>

- **监督学习**：给数据贴标签（输入-输出对），学习映射 $f: X \to Y$。如线性回归、分类。
- **无监督学习**：不给标签，发现数据内部结构。如聚类、降维。
- **强化学习**：通过试错和奖励学习策略。如 AlphaGo。

### 线性回归

模型：$\hat{y} = w_1 x_1 + w_2 x_2 + \cdots + w_n x_n + b = \mathbf{w}^T \mathbf{x} + b$。

目标：最小化损失函数 $L = \frac{1}{m} \sum_{i=1}^{m} (\hat{y}_i - y_i)^2$（均方误差 MSE）。

最小二乘法的解析解：$\mathbf{w} = (X^T X)^{-1} X^T \mathbf{y}$（当 $X^T X$ 可逆时）。

### 梯度下降

<Stepper>
<Step title="梯度下降原理">
沿损失函数的负梯度方向更新参数：$w \leftarrow w - \eta \frac{\partial L}{\partial w}$。$\eta$ 是学习率。梯度指向函数增长最快的方向，负梯度就是下降最快的方向。
</Step>
<Step title="学习率的影响">
学习率太大会跳过最优点（震荡发散），太小收敛太慢。实际中常用学习率衰减：开始大步探索，后期小步微调。或用自适应学习率（Adam）。
</Step>
<Step title="链式法则与反向传播">
神经网络是多层数函数复合 $f(g(h(x)))$。梯度通过链式法则逐层传递：$\frac{\partial L}{\partial w_1} = \frac{\partial L}{\partial f} \cdot \frac{\partial f}{\partial g} \cdot \frac{\partial g}{\partial h} \cdot \frac{\partial h}{\partial w_1}$。这就是反向传播的数学本质。
</Step>
</Stepper>

### 神经网络

<Term def="神经网络是通过非线性激活函数的复合来逼近复杂函数的模型">
神经网络
</Term>

单层神经元：$\mathbf{y} = \sigma(\mathbf{W}^T \mathbf{x} + \mathbf{b})$，$\sigma$ 是激活函数（如 ReLU $\max(0, x)$、Sigmoid $\frac{1}{1+e^{-x}}$）。

多层网络 = 多次非线性变换的复合。万能逼近定理：含一个隐藏层的前馈网络可以逼近任意连续函数（但可能需要指数级多的神经元，深度网络用更少参数达到同样效果）。

## 代码对照

```python
import numpy as np

# 线性回归：最小二乘法解析解
def linear_regression(X, y):
    """
    X: (m, n) 特征矩阵，y: (m,) 目标值
    返回: w 权重向量
    """
    # w = (X^T X)^(-1) X^T y
    X_with_bias = np.c_[np.ones(len(X)), X]  # 添加偏置列
    w = np.linalg.inv(X_with_bias.T @ X_with_bias) @ X_with_bias.T @ y
    return w

# 梯度下降：迭代优化
def gradient_descent(X, y, lr=0.01, epochs=1000):
    m, n = X.shape
    w = np.zeros(n)
    b = 0
    for _ in range(epochs):
        # 前向传播
        y_pred = X @ w + b
        # 损失梯度
        dw = (2/m) * X.T @ (y_pred - y)  # ∂L/∂w
        db = (2/m) * np.sum(y_pred - y)  # ∂L/∂b
        # 参数更新（沿负梯度方向）
        w -= lr * dw
        b -= lr * db
    return w, b

# 简单神经网络（1 个隐藏层）
def neural_network(X, y, hidden=4, lr=0.1, epochs=1000):
    m, n = X.shape
    # 初始化权重
    W1 = np.random.randn(n, hidden) * 0.01
    b1 = np.zeros(hidden)
    W2 = np.random.randn(hidden, 1) * 0.01
    b2 = np.zeros(1)

    for _ in range(epochs):
        # 前向传播
        Z1 = X @ W1 + b1           # 线性变换
        A1 = np.maximum(0, Z1)     # ReLU 激活（非线性）
        Z2 = A1 @ W2 + b2          # 输出层
        y_pred = Z2

        # 反向传播（链式法则）
        dZ2 = (y_pred - y.reshape(-1, 1)) / m
        dW2 = A1.T @ dZ2
        db2 = dZ2.sum(axis=0)
        dA1 = dZ2 @ W2.T
        dZ1 = dA1 * (Z1 > 0)       # ReLU 的导数
        dW1 = X.T @ dZ1
        db1 = dZ1.sum(axis=0)

        # 参数更新
        W2 -= lr * dW2
        b2 -= lr * db2
        W1 -= lr * dW1
        b1 -= lr * db1

    return W1, b1, W2, b2
```

## 常见误区

<Callout type="trap">
**误区：认为神经网络是「黑盒」，无法用数学理解。**
神经网络的每个组件都有明确的数学含义：线性变换（矩阵乘法）、非线性激活（ReLU/Sigmoid）、损失函数（均方误差/交叉熵）、优化（梯度下降）。反向传播就是链式法则。理解这些数学，神经网络就不再是黑盒，而是一系列可解释的数学操作。
</Callout>

<Callout type="trap">
**误区：学习率越大收敛越快。**
学习率过大会导致参数在最优点附近来回震荡甚至发散（损失不降反升）。学习率过小收敛极慢。合适的学习率需要实验调参，或用自适应方法（Adam、AdaGrad）自动调节每个参数的学习率。
</Callout>

<Exercises>
**问题 1**：梯度下降为什么要沿负梯度方向更新参数？

<Answer>
梯度 $\nabla L$ 指向损失函数增长最快的方向，所以负梯度 $-\nabla L$ 指向下降最快的方向。沿负梯度更新 $w \leftarrow w - \eta \nabla L$ 能最快减小损失。这是微积分中方向导数的直接应用——梯度方向是函数变化率最大的方向。
</Answer>

**问题 2**：神经网络的反向传播算法本质上用的是什么数学法则？

<Answer>
反向传播本质是微积分的**链式法则**。神经网络是多层数函数的复合 $L(f(g(h(x))))$，求损失对底层参数的梯度需要链式法则逐层展开：$\frac{\partial L}{\partial w} = \frac{\partial L}{\partial f} \cdot \frac{\partial f}{\partial g} \cdot \frac{\partial g}{\partial h} \cdot \frac{\partial h}{\partial w}$。反向传播从输出层向输入层逐层计算并传递梯度，避免正向计算时的重复求导。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="监督学习">
从标注数据（输入-输出对）中学习映射函数 f:X→Y。包括回归（连续输出）和分类（离散输出）。
</GlossaryItem>
<GlossaryItem term="梯度下降">
沿损失函数负梯度方向迭代更新参数：w←w-η∂L/∂w。η 是学习率，控制步长。
</GlossaryItem>
<GlossaryItem term="反向传播">
神经网络训练算法，本质是链式法则逐层计算损失对参数的梯度，从输出层向输入层反向传递。
</GlossaryItem>
<GlossaryItem term="激活函数">
引入非线性的函数，如 ReLU=max(0,x)、Sigmoid=1/(1+e⁻ˣ)。没有激活函数，多层网络等价于单层线性变换。
</GlossaryItem>
</Glossary>
