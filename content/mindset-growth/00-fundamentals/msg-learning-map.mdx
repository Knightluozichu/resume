- 理解《终身成长》全书的五大学习阶段和十章学习路径

## 核心概念

### 全书定位

《终身成长》（Carol S. Dweck）是一本基于数十年心理学研究的思维科学读物。不同于市面上大量「成功学」书籍，它以严格的实验证据为基础，揭示了人们对能力的信念如何深刻影响行为路径和人生成就。核心发现是：相信能力固定不变的人（固定型思维）与相信能力可以发展的人（成长型思维），在面对挑战、失败、努力和批评时表现出截然不同的行为模式，最终走向不同的人生轨迹。

### 核心脉络

全书的核心理念可以浓缩为一条脉络线：

**信念决定思维 → 思维驱动行为 → 行为塑造成就 → 成长型思维实现终身成长**

这五个阶段不是孤立的模块，而是一个**递进循环**：信念是起点，思维是分野，行为是表现，应用是验证，整合是升华。

### 学习建议

1. **信念优先**：先理解两种思维模式的核心信念差异，再看行为表现
2. **对比思考**：将书中的案例与自己的经历对比，识别自己的思维模式
3. **实践导向**：每学完一章，尝试在日常情境中应用成长型思维
4. **定期回顾**：学完全书后回到本章，检验对全景图的理解是否加深

## 术语表

| 术语 | 释义 |
|------|------|
| 固定型思维 | 认为能力是天生的、固定不变的思维模式 |
| 成长型思维 | 认为能力可以通过努力和学习不断发展的思维模式 |
| 核心信念 | 对能力本质的根本看法，决定思维模式 |
| 行为模式 | 在特定情境下的典型反应方式 |
| 天才文化 | 崇拜天赋、轻视努力的组织文化 |
| 发展文化 | 重视学习、鼓励成长的组织文化 |
| 「还没有」 | 成长型思维的语言，暗示能力是可发展的过程 |
| 证明自己 | 固定型思维的核心关注点，不断展示已有能力 |
| 提升自己 | 成长型思维的核心关注点，持续学习和进步 |
| 终身成长 | 成长型思维的终极目标，持续突破能力边界 |
