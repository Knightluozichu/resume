## 学习目标

- 理解赞美智力与赞美努力的本质差异和长期影响
- 掌握面对孩子失败时的成长型回应方式
- 学会运用四大培育策略培养成长型思维
- 建立成长型教师的核心特征认知

## 核心概念

### 教育中的思维模式

父母和教师是孩子思维模式的主要塑造者。每一次赞美、每一次回应失败、每一次设立标准，都在向孩子传递关于能力本质的信念。培育成长型思维不是空谈「你可以做到」，而是需要具体的方法和持续的努力。

### 赞美方式：最关键的工具

赞美是塑造孩子思维模式最强大的工具，也是最容易用错的工具：

| 赞美方式 | 话语 | 传递的信念 | 后果 |
|----------|------|-----------|------|
| 赞美智力（固定型） | 「你真聪明！」「你真有天赋！」 | 成功 = 天生聪明 | 害怕挑战、回避努力 |
| 赞美努力（成长型） | 「你的努力让进步很大！」「策略很棒！」 | 成功 = 努力 + 策略 | 拥抱挑战、持续投入 |

研究证明：被赞美智力的孩子在面对困难任务时更容易放弃，因为他们害怕失败会否定「聪明」的标签。被赞美努力的孩子则更愿意尝试更难的任务，因为他们把困难视为学习的机会。

### 面对孩子失败时

| 回应方式 | 话语 | 传递的信念 |
|----------|------|-----------|
| 固定型回应 | 「没关系，下次会更好」（安慰但不指明方向） | 能力天定，运气问题 |
| 固定型回应 | 「不是每个人都擅长数学」 | 能力天定，放弃 |
| 成长型回应 | 「你还没有掌握，我们来看看哪里可以改进」 | 能力可发展，需要策略 |
| 成长型回应 | 「需要更多练习和不同的策略」 | 能力可发展，需要投入 |

### 四大培育策略

1. **关注过程**：关注策略、努力、选择和进步，而非只看分数和结果
2. **建设性反馈**：具体指出哪里可以改进，而非笼统评价「好」或「差」
3. **设立高标准**：相信孩子能达到，并提供支持，而非降低标准来「保护」自尊
4. **培养「还没有」**：遇到困难时说「你还没有学会」，而非「你做不到」

### 成长型教师的特征

- **相信每个学生**：不给学生贴「笨」标签，相信每个学生都能进步
- **关注学习过程**：不只看分数，更看进步和策略
- **给予挑战和支持**：设立高标准，同时提供充足的脚手架和支持

### 核心原则

教育的目标不是「确认」孩子的能力，而是「发展」孩子的潜能。核心原则：不是夸孩子聪明，而是帮助他们**学会热爱挑战、享受努力、从错误中学习**。

## 术语表

| 术语 | 释义 |
|------|------|
| 赞美智力 | 夸奖天赋的固定型赞美方式 |
| 赞美努力 | 夸奖努力和策略的成长型赞美方式 |
| 建设性反馈 | 具体指出改进方向的反馈 |
| 「还没有」 | 成长型教育的核心语言工具 |
| 高标准 | 相信孩子能达到的成长型期望 |
| 脚手架 | 帮助学生达到高标准的支持 |
| 过程导向 | 关注策略、努力和进步的教育方式 |
| 结果导向 | 只看分数的固定型教育方式 |

## 练习题

1. 赞美智力和赞美努力有什么本质差异？它们各自的长期后果是什么？
2. 面对孩子失败时，固定型回应和成长型回应有什么不同？
3. 四大培育策略分别是什么？如何在教育中实施？
4. 成长型教师有哪三个核心特征？为什么它们比教学技巧更重要？
