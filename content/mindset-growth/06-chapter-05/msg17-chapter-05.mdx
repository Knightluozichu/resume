## 为什么不能把“成长型”当作好人标签

第 5 章 商业：思维模式和领导力承担 **组织文化、决策与领导行为**。从人才迷信走向组织学习系统，比较固定型与成长型领导行为，并用决策记录、发言分布和人才发展证据检验企业文化。 本课程不复制原书正文、案例叙事或研究表述，而把公开目录命题重构为机制图、交互实验、反例、行动协议与证据包。思维模式是随领域和情境变化的信念状态，不是固定人格，也不是道德等级。

本页目录坐标为：第 5 章 商业：思维模式和领导力、人才至上的思维模式、成长型企业、对思维模式与管理决策的研究、领导力与固定型思维模式、固定型思维模式领导者的行为、成长型思维模式领导者的行为、一项关于团体行为的研究、群体思维和团体讨论、当被夸奖的一代进入职场、谈判技巧是天生的吗、管理才能是天生的吗、领导才能是天生的吗、企业的思维模式。本页逐项覆盖14个公开目录节点。 课程特别拒绝“只要努力便能达成任何目标”的误读：能力发展需要有效策略、纠错反馈、时间、资源和机会；身体条件、先备知识、健康、安全与制度约束不能被积极口号抹去。成长型响应也不取消高标准、现实判断、责任或退出有害情境的权利。

## 四个可手算的操作指标

以下公式是本课程的观察工具，不是原书提出的临床量表，也不主张跨人群的统一常模。挑战投入率记录在可达挑战中主动进入并完成首轮尝试的比例：

$$
C = N_{attempted\ challenges} / N_{available\ challenges}
$$

策略更新率记录收到可操作反馈后，真正改变方法并再次验证的比例：

$$
S = N_{revised\ and\ retested} / N_{actionable\ feedback}
$$

校准误差比较事前信心与按外部规则得到的表现，越接近零越好：

$$
E = |P_{predicted} - P_{observed}|
$$

迁移收益比较新情境中采用有效策略前后的差异；必须保持评分规则一致并报告样本：

$$
T = P_{new\ context,after} - P_{new\ context,baseline}
$$

高投入但低策略更新通常表示重复用力；低校准误差却没有挑战，可能只是任务过易；迁移只在原题复现，则不能证明底层能力。四项指标必须与机会数量、任务难度、支持条件和不确定性一起报告。

## 把主张变成改变协议

本单元主链是“人才假设 → 信息流动 → 管理决策 → 团队学习 → 组织结果”。第一步固定领域、任务、标准和观察窗口；第二步在行动前写下预测与自动叙事；第三步只改变一个策略或支持条件；第四步收集挑战选择、反馈利用与结果；第五步在表面不同的新情境复测。若结果没有改善，要区分策略失配、练习不足、目标不合适与环境约束，不把失败自动归咎于态度。

建立两条并行记录。一条是“事件账本”，保存触发器、情绪、解释和即时行为；另一条是“发展账本”，保存技能基线、策略、反馈、重复次数与迁移结果。前者解释为什么某次反应被启动，后者检验能力是否真的发展。只做心理重构而没有技能训练，或只刷练习而不处理身份威胁，都可能使改变停在表面。

```ts
type MindsetEvent = {
  domain: string;

  interpretation: string;

  support: string[];

const event: MindsetEvent = {
  domain: "组织文化、决策与领导行为",
  trigger: "人才文化",

  interpretation: "这是当前策略的测试，不是永久身份判决",
  strategy: "请求一个具体反馈并重做相邻任务",
  support: ["明确标准", "可达示例"],

```

第二段根据原始记录计算校准与策略更新，不以“感觉更积极”验收：

```python
def evaluate(predicted, observed, feedback_items, revised_items):
    calibration_error = abs(predicted - observed)
    strategy_update = (
        revised_items / feedback_items if feedback_items else 0.0
    )
    return {
        "calibration_error": calibration_error,
        "strategy_update": strategy_update,
    }
```

第三段预注册边界和拒绝条件，防止结果出现后只保留支持理念的案例：

```yaml
unit: "msg17-chapter-05"

```

| 学习     | 选择可达挑战并更换无效策略     | 基线、反馈、重测、迁移   | 只增加时长仍重复同错   |
| 工作     | 坏消息可上行，决策能因反证改变 | 决策日志、异议、后果     | 用成长口号要求无偿透支 |
| 关系     | 从人格审判回到需求、边界和修复 | 具体事件、请求、后续行为 | 以成长为由容忍伤害     |
| 教育     | 高标准与策略、支持同时提供     | 任务机会、反馈、进步轨迹 | 只夸努力或给孩子定型   |
| 自我改变 | 接受触发器并执行相邻行动       | 预测、行为、复发与复盘   | 宣称身份改变却无证据   |

矩阵要求同一概念在多个领域保持机制一致，同时允许边界不同。体育中的坚持不能直接搬到伤病恢复，企业中的试错不能取消合规，关系中的共同成长不能覆盖安全风险。迁移前必须重新检查任务、权力、资源和损失上限。


## 证据包、局限与独立复核

证据包至少保存中文版版次、目录坐标、领域、任务、外部标准、先备能力、机会与资源、触发器、事前预测、自动解释、挑战选择、策略、反馈、支持、即时结果、延迟结果、迁移结果、缺失记录和退出原因。对案例只能陈述观察到的变化，不应把相关性写成唯一因果。

独立复核者先确认任务难度与机会相当，再从原始记录重算四项指标；随后抽取一个成功案例寻找替代解释，抽取一个失败案例判断是策略、支持还是目标问题。若删掉“固定型/成长型”标签后仍能从行为和结果复现结论，证据才具有可读性。任何跨人群外推都必须说明样本、情境和伦理边界。

## 本章回顾

第 5 章 商业：思维模式和领导力不是励志口号，而是“人才假设 → 信息流动 → 管理决策 → 团队学习 → 组织结果”中的可检验单元。掌握本页意味着能逐项定位公开目录坐标，区分信念、策略、支持与结果，识别只有努力话语却没有学习机制的虚假版本，并在新情境中提交可复核证据。成长的最低承诺不是“我一定成功”，而是用更准确的模型选择下一步，并允许现实证据修改目标和方法。
