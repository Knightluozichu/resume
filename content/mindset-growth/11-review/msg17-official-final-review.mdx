## 为什么不能把“成长型”当作好人标签

## 四个可手算的操作指标

以下公式是本课程的观察工具，不是原书提出的临床量表，也不主张跨人群的统一常模。挑战投入率记录在可达挑战中主动进入并完成首轮尝试的比例：

$$
C = N_{attempted\ challenges} / N_{available\ challenges}
$$

策略更新率记录收到可操作反馈后，真正改变方法并再次验证的比例：

$$
S = N_{revised\ and\ retested} / N_{actionable\ feedback}
$$

校准误差比较事前信心与按外部规则得到的表现，越接近零越好：

$$
E = |P_{predicted} - P_{observed}|
$$

迁移收益比较新情境中采用有效策略前后的差异；必须保持评分规则一致并报告样本：

$$
T = P_{new\ context,after} - P_{new\ context,baseline}
$$

高投入但低策略更新通常表示重复用力；低校准误差却没有挑战，可能只是任务过易；迁移只在原题复现，则不能证明底层能力。四项指标必须与机会数量、任务难度、支持条件和不确定性一起报告。

## 把主张变成改变协议

本单元主链是“抽取触发 → 解释分岔 → 选择策略 → 收集证据 → 跨场景迁移”。第一步固定领域、任务、标准和观察窗口；第二步在行动前写下预测与自动叙事；第三步只改变一个策略或支持条件；第四步收集挑战选择、反馈利用与结果；第五步在表面不同的新情境复测。若结果没有改善，要区分策略失配、练习不足、目标不合适与环境约束，不把失败自动归咎于态度。

建立两条并行记录。一条是“事件账本”，保存触发器、情绪、解释和即时行为；另一条是“发展账本”，保存技能基线、策略、反馈、重复次数与迁移结果。前者解释为什么某次反应被启动，后者检验能力是否真的发展。只做心理重构而没有技能训练，或只刷练习而不处理身份威胁，都可能使改变停在表面。

```python
    )
    return {
        "calibration_error": calibration_error,
        "strategy_update": strategy_update,
    }
```

第三段预注册边界和拒绝条件，防止结果出现后只保留支持理念的案例：

```yaml
unit: "msg17-official-final-review"
chain: ["抽取触发", "解释分岔", "选择策略", "收集证据", "跨场景迁移"]
scenarios: [supported_strategy, resource_boundary, slogan_only]
controls: [same_goal, same_task, same_scoring, same_window]
record: [trigger, prediction, choice, strategy, feedback, support, result]
reject_when: [no_strategy_change, no_external_feedback, unsafe_context]
```

这些实现只负责记录与复核。涉及儿童、员工评价、亲密关系或心理健康时，应遵守同意、隐私、公平和安全要求；课程指标不能代替专业测评，也不能用于惩罚不接受标签的人。

## 场景矩阵与拒绝条件

| 场景     | 应观察的行为                   | 必留证据                 | 拒绝信号               |
| -------- | ------------------------------ | ------------------------ | ---------------------- |
| 学习     | 选择可达挑战并更换无效策略     | 基线、反馈、重测、迁移   | 只增加时长仍重复同错   |
| 工作     | 坏消息可上行，决策能因反证改变 | 决策日志、异议、后果     | 用成长口号要求无偿透支 |
| 关系     | 从人格审判回到需求、边界和修复 | 具体事件、请求、后续行为 | 以成长为由容忍伤害     |
| 教育     | 高标准与策略、支持同时提供     | 任务机会、反馈、进步轨迹 | 只夸努力或给孩子定型   |
| 自我改变 | 接受触发器并执行相邻行动       | 预测、行为、复发与复盘   | 宣称身份改变却无证据   |

矩阵要求同一概念在多个领域保持机制一致，同时允许边界不同。体育中的坚持不能直接搬到伤病恢复，企业中的试错不能取消合规，关系中的共同成长不能覆盖安全风险。迁移前必须重新检查任务、权力、资源和损失上限。

<Callout type="trap" title="陷阱：把成长型思维等同于努力">
  努力只有在方向可行、策略有效、反馈可用且条件允许时才可能促进发展。重复无效方法、忽略休息或要求弱势者独自克服结构障碍，属于虚假成长型思维。
</Callout>

<Callout type="trap" title="陷阱：把人永久分成固定型和成长型">
  思维模式会随领域、时点和威胁变化。应描述“某人在某任务触发后采用了某解释和行为”，并允许新证据更新判断；人格贴标签会重演本书要纠正的固定化。
</Callout>

## 证据包、局限与独立复核

证据包至少保存中文版版次、目录坐标、领域、任务、外部标准、先备能力、机会与资源、触发器、事前预测、自动解释、挑战选择、策略、反馈、支持、即时结果、延迟结果、迁移结果、缺失记录和退出原因。对案例只能陈述观察到的变化，不应把相关性写成唯一因果。

独立复核者先确认任务难度与机会相当，再从原始记录重算四项指标；随后抽取一个成功案例寻找替代解释，抽取一个失败案例判断是策略、支持还是目标问题。若删掉“固定型/成长型”标签后仍能从行为和结果复现结论，证据才具有可读性。任何跨人群外推都必须说明样本、情境和伦理边界。

## 本章回顾

《终身成长》全书综合复核不是励志口号，而是“抽取触发 → 解释分岔 → 选择策略 → 收集证据 → 跨场景迁移”中的可检验单元。掌握本页意味着能逐项定位公开目录坐标，区分信念、策略、支持与结果，识别只有努力话语却没有学习机制的虚假版本，并在新情境中提交可复核证据。成长的最低承诺不是“我一定成功”，而是用更准确的模型选择下一步，并允许现实证据修改目标和方法。

<Glossary>

<GlossaryItem term="可塑性信念">
  对某项能力能否以及如何发展的情境化判断；它允许更新，不等于保证任何目标都能实现。
</GlossaryItem>
<GlossaryItem term="目标取向">
  面对任务时偏向学习、证明或回避的方向，应由挑战选择与反馈行为交叉验证。
</GlossaryItem>
<GlossaryItem term="策略质量">
  方法与目标、水平和反馈的匹配程度；投入时长高并不能自动证明策略有效。
</GlossaryItem>
<GlossaryItem term="反馈校准">
  比较预测、外部标准与结果后修正判断，既防止自我贬低，也防止无限乐观。
</GlossaryItem>
<GlossaryItem term="情境触发器">
  容易启动身份防御的失败、批评、竞争或关系事件，记录它是改变反应链的入口。
</GlossaryItem>

</Glossary>

<Exercises>

1. 如何为《终身成长》全书综合复核建立不贴人格标签的最小基线？

<Answer>
  选择一个具体领域和任务，固定标准与窗口；记录触发器、事前预测、自动解释、挑战选择、策略、反馈、支持和结果。用“人在情境中的反应”描述，而不是宣布此人属于哪一类。
</Answer>

2. 怎样识别本单元中的虚假成长型思维？

<Answer>
  检查是否只赞美努力，却没有有效策略、具体反馈、资源支持、结果复测和现实边界；再运行“只有口号”与“策略加支持”条件。若前者持续重复同错，就应修改方法或目标，而不是要求更多自我说服。
</Answer>

3. 怎样证明变化能够跨情境保持？

<Answer>
  在表面不同但需要同一底层能力的新任务中，重新观察挑战选择、策略更新、校准误差和结果；报告机会、难度与支持差异，并让复核者从原始记录重算，不能只重演原案例。
</Answer>

</Exercises>
