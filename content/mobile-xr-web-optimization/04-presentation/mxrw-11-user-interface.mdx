## 核心模型与不可变条件

UGUI成本来自Canvas重建、布局、几何批次、过绘和射线。按更新频率拆Canvas，虚拟化列表，关闭无交互Raycast Target，并在全屏界面隐藏后方渲染。

不可变条件是：**UI修改只重建必要Canvas，交互区域和焦点保持正确，多分辨率无裁切，批次与过绘在预算内。** 如果测试上下文、视觉或玩法结果发生变化，就不能把两次数字直接相减。先解释变化，再决定是否建立新基线。

## 两个必须主动制造的失败样本

<Callout type="trap" title="官方边界或测试上下文丢失">
  把所有HUD和静态背景放在一个Canvas，计时文本每帧变化导致整个界面反复重建。
  保存错误结论、首个偏离节点和原始数据，再恢复官方边界与相同条件复验。
</Callout>

<Callout type="trap" title="数字变好但结果或维护成本恶化">
  故意降低画质、跳过玩法工作、扩大永久缓存或增加难以维护的平台分支。若主指标改善但视觉、行为、内存、热量或发布可靠性变差，发布门必须拒绝。
</Callout>
