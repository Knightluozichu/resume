# 多智能体系统·知识全景图

## 学习目标

完成本章学习后，你将能够：

1. 理解《多智能体系统》（Wooldridge）全书的核心主题与知识脉络
2. 掌握多智能体系统研究的五大学习阶段
3. 厘清从智能体基础到系统应用的完整链路
4. 明确十章的学习路径与每章定位

## 核心概念

### 全书定位

本书系统讲解多智能体系统（MultiAgent Systems, MAS）的核心理论与方法。与侧重单一智能体设计或机器学习的内容不同，本书聚焦**多智能体**：当多个自主智能体共存于同一环境，它们之间如何交互、如何博弈、如何通信、如何协调、如何合作、如何分布式求解问题。作者 Michael Wooldridge 是 MAS 领域奠基人之一，本书是该领域公认的入门经典。

### 五大学习阶段

全书十章分为五个学习阶段，层层递进：

**阶段一：基础理论（ch0-ch2）**——知识全景图定位方向，智能体基础概念讲解定义与结构，理性智能体与决策讲解效用与搜索。这一阶段回答「什么是智能体」。

**阶段二：交互与博弈（ch3-ch4）**——多智能体交互讲解依赖关系与均衡，博弈论与策略讲解收益矩阵与纳什均衡。这一阶段回答「智能体如何交互」。

**阶段三：通信与协调（ch5-ch6）**——通信与协商讲解言语行为与协议，协调与合作机制讲解组织、合同网与社会法则。这一阶段回答「智能体如何协作」。

**阶段四：系统架构（ch7）**——分布式问题求解讲解任务分解、结果聚合与计算范式。这一阶段回答「如何构建系统」。

**阶段五：应用与整合（ch8-ch9）**——应用与未来展望讲解现实系统与 LLM 融合，全书复习整合知识闭环。这一阶段回答「如何落地应用」。

### 多智能体系统构建链路

MAS 构建链路包含六大核心环节：

| 环节 | 核心问题 | 代表技术 |
|------|----------|----------|
| 智能体建模 | 什么是智能体 | 自主性、反应性、主动性、社交性 |
| 理性决策 | 如何选择行动 | 效用函数、期望效用、搜索 |
| 交互分析 | 如何相互影响 | 依赖关系、博弈论、均衡 |
| 通信协商 | 如何交换信息 | 言语行为、ACL、协商协议 |
| 协调合作 | 如何管理依赖 | 组织结构、合同网、社会法则 |
| 系统求解 | 如何分布式计算 | 任务分解、结果聚合、黑板系统 |

六者层层递进：建模是基础，决策是内核，交互是关系，通信是手段，协调是机制，求解是落地。

## 术语表

- **智能体（Agent）**：置身于环境中、能自主行动以达成目标的计算机系统
- **多智能体系统（MAS）**：由多个交互智能体组成的系统
- **理性（Rationality）**：在信息有限下选择使期望效用最大化的行动
- **均衡（Equilibrium）**：交互中无人有动机单方面偏离的稳定结局
- **协调（Coordination）**：管理智能体间依赖关系的过程
