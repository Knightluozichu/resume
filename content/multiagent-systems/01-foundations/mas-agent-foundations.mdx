# 智能体基础概念

## 学习目标

完成本章学习后，你将能够：

1. 准确表述 Wooldridge 对智能体的标准定义
2. 描述智能体的「感知-决策-执行」基本循环
3. 区分五类智能体架构及其适用场景
4. 阐述多智能体系统的四大关键特性

## 核心概念

### 智能体的定义

Wooldridge 给出被广泛引用的定义：**智能体是置身于某个环境中、能够自主行动以达成其设计目标的计算机系统**。这个定义有三个要点：一是「置身于环境」，智能体不是孤立的计算过程，而是与外部世界交互；二是「自主行动」，智能体在没有外部直接控制的情况下自行决定动作；三是「达成目标」，智能体的行为是目标导向的而非随机的。

### 智能体基本循环

智能体的运行遵循一个闭环：环境产生**感知（percepts）**，智能体通过**传感器**接收感知，**智能体函数**将感知序列映射为**动作（actions）**，动作通过**执行器**作用于环境，环境状态随之改变并产生新的感知。这个循环是所有智能体的共同骨架。

### 智能体类型谱系

按决策复杂度递增，智能体分为五类：

1. **简单反射型**：仅依赖当前感知，用「条件-动作」规则直接映射。如温控器。缺点是无法处理不可见状态。
2. **基于模型的反射型**：维护内部状态，跟踪不可见的世界部分。如自动驾驶车记录他车历史位置。
3. **基于目标型**：显式持有目标，用目标导向搜索选择动作。比反射型更灵活但计算更重。
4. **基于效用型**：用效用函数量化偏好，选择期望效用最高的动作。能处理冲突目标与不确定性。
5. **学习型**：包含性能元件、学习元件、评价元件和问题生成器，能从经验中改进自身。

### 多智能体系统的关键特性

Wooldridge 提出智能体的四大特性，也是 MAS 的根基：

- **自主性（Autonomy）**：无需人工干预自主行动，对自己的行为负责
- **反应性（Reactivity）**：及时感知环境变化并响应
- **主动性（Pro-activeness）**：目标驱动，主动产生行为而非仅被动响应
- **社交性（Social ability）**：能与其他智能体（或人）交互协作

这四性中，社交性是区分「单智能体」与「多智能体」的关键——它要求智能体能理解他人、协调行动。

## 术语表

- **智能体函数（Agent Function）**：从感知序列到动作的映射，是智能体的数学本质
- **感知（Percept）**：智能体通过传感器在某一时刻获得的环境输入
- **自主性（Autonomy）**：智能体在没有外部直接控制下自主决策的能力
- **社交性（Social Ability）**：智能体与他人交互协作的能力，MAS 的核心特性
- **环境（Environment）**：智能体置身其中并与之交互的外部世界
