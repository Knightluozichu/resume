# 通信与协商

## 学习目标

完成本章学习后，你将能够：

1. 阐述智能体通信的价值与必要性
2. 用言语行为理论分类通信原语
3. 区分 KQML 与 FIPA ACL 两种通信语言
4. 描述协商协议的流程与三类协商策略

## 核心概念

### 通信的价值

多智能体系统中，通信不是可选项而是必需品。通信的四大价值：**信息共享**（传递状态与意图，降低不确定性）、**请求协助**（委托任务与能力）、**承诺协调**（建立互信与契约，约束未来行为）、**协商分利**（在冲突利益间达成双赢协议）。没有通信，智能体只能在「盲交互」中博弈；有通信，智能体可以显式协调。

### 言语行为理论

通信不只是传递信息，更是**做事**。言语行为理论（Speech Act Theory，源自 Austin 与 Searle）将通信原语分为四类：

- **断言类（Assertives）**：描述世界，如 inform、confirm，真值可验
- **指令类（Directives）**：要求行动，如 request、order，期待服从
- **承诺类（Commissives）**：承担义务，如 promise、commit，约束未来
- **声明类（Declaratives）**：改变世界，如 declare，话说即事实

每条通信都兼具「命题内容」（说了什么）和「言语行为类型」（用这句话做什么）。

### 智能体通信语言 ACL

为了让智能体机器可读地通信，发展出两种标准通信语言：

- **KQML（Knowledge Query and Manipulation Language）**：较早的智能体通信语言，消息由 performative（行为类型）+ content（内容）+ language（内容语言）+ ontology（本体）构成。
- **FIPA ACL**：FIPA 组织制定的标准，定义了一组通信原语：inform（告知）、request（请求）、propose（提案）、accept（接受）、reject（拒绝）、agree（同意）等。FIPA ACL 是当前主流标准。

### 协商协议流程

协商（Negotiation）是智能体在冲突利益间通过提案-反报价达成可接受契约的过程。标准流程：

1. **提出提案**：一方 propose 初始方案
2. **评估权衡**：接收方计算提案对自己的效用
3. **反报价**：若不满意，counter-offer 提出新方案
4. **接受/拒绝**：双方就某方案达成 accept 或最终 reject
5. **达成契约**：accept 后形成具有约束力的 agree

### 协商策略

三种典型协商策略：

- **合同网协议**：通过招标-投标-中标机制分配任务，适合任务分配场景
- **Monotonic 让步**：每轮提案不劣于上一轮（在己方效用上单调递减），保证收敛
- **论证式协商**：提案附带理由，尝试说服对手接受，比纯讨价还价更高效

## 术语表

- **言语行为（Speech Act）**：通信不仅是传递信息，更是执行一种行为
- **ACL（Agent Communication Language）**：智能体间机器可读的通信语言
- **KQML**：知识查询与操作语言，早期智能体通信标准
- **FIPA ACL**：FIPA 标准通信原语集，当前主流
- **协商（Negotiation）**：通过提案-反报价达成可接受契约的过程
