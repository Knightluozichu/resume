void Actor::drain(std::size_t budget) {
    assert(std::this_thread::get_id() == owner_thread_);
    for (std::size_t i = 0; i < budget; ++i) {

        if (!message) break;
        apply(*message);
    }
}

## 小结

- **游戏主循环**：按固定阶段消费输入、更新状态、发送输出并记录耗时的循环。
- **Actor**：串行拥有私有状态并仅通过异步消息交互的并发单元。
- **邮箱**：保存发送给Actor且等待按序消费的有界消息队列。
- **线程亲和**：Actor在一个调度代际中固定由指定执行线程消费的约束。
- **背压**：下游达到容量预算后主动减速、拒绝或降级上游输入的机制。
