## 直觉：先找唯一事实

通过多login进程、appmgr、HTTP/Mongoose解析、Packet网络标识和分块传输建立可发现、可管理、可压测的多进程服务。 真正的难点不是把接口调用成功，而是让每次输入只产生一份事实，旧连接、旧实体、旧进程和旧定时器不能越过代际边界。先预测：如果只保留最终成功截图，本章最可能隐藏哪一种重复执行、状态污染或资源泄漏？
