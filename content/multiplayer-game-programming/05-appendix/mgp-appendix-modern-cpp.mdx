## 机制拆解

### 1. 引用表达借用，不表达所有权

函数以引用接收对象时，调用方仍负责生命周期；返回或异步保存引用前必须证明被引用对象更长寿。网络回调常跨越事件循环，捕获栈引用会形成悬空访问，应改用值、稳定句柄或明确共享所有权。

### 2. 智能指针要匹配真实所有权

unique_ptr表示唯一所有者并支持移动，shared_ptr只在确有共同生命周期时使用，weak_ptr用于观察而不延长生命。套接字等系统资源还需自定义RAII封装，即使异常、早退或连接失败也只释放一次。

先预测：若省略这一层，哪一个序号、所有权或时间预算会最先失真？

### 3. 容器和迭代器是性能与正确性契约

vector连续且缓存友好，但扩容会使指针和迭代器失效；unordered_map便于按网络ID查找，却不能依赖遍历顺序。修改容器时要遵循失效规则，确定性模拟还需显式排序或选择稳定结构。

## 最小实现骨架

以下代码是独立复现实验骨架，不复制原书代码。序号比较必须处理回绕，生产实现还需补齐平台错误、认证、容量与资源清理。

```cpp
struct NetworkEvidence {
  std::uint32_t sequence;
  std::uint32_t worldVersion;
  std::uint64_t objectId;
  double sentAtMs;
  double appliedAtMs;
};

bool accepts(const NetworkEvidence& next, const NetworkEvidence& current) {
  return next.objectId == current.objectId &&
         next.worldVersion >= current.worldVersion;
}
```
