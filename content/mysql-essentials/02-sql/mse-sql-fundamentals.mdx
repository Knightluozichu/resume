## SQL四大分类

<MseSqlFundamentalsDiagram />

SQL语言分为四大类：DDL（数据定义）、DML（数据操作）、DQL（数据查询）、DCL（数据控制）。每类负责不同层面：DDL管结构，DML管数据，DQL管检索，DCL管权限和事务。

## DML增删改

```
-- INSERT 插入
INSERT INTO users (username, email, age) VALUES ('alice', 'alice@test.com', 25);
INSERT INTO users (username, email) VALUES ('bob', 'bob@test.com'), ('carol', 'carol@test.com');

-- UPDATE 更新（务必加WHERE！）
UPDATE users SET age = 26, balance = 100.00 WHERE username = 'alice';

-- DELETE 删除（务必加WHERE！）
DELETE FROM users WHERE status = 0;

-- TRUNCATE vs DELETE
-- TRUNCATE: 清空全表，重置AUTO_INCREMENT，不记日志，不可回滚
-- DELETE: 按条件删除，不重置AUTO_INCREMENT，记日志，可回滚
```

<Callout type="warning" title="UPDATE/DELETE务必加WHERE">
不带WHERE的UPDATE/DELETE会影响全表数据！生产环境中执行前先用SELECT确认影响范围，或开启安全模式 `SET sql_safe_updates = 1;`。
</Callout>

## DQL查询基础

```
-- 基本查询
SELECT username, email, age FROM users WHERE age >= 18 ORDER BY age DESC LIMIT 10;

-- 条件运算符
-- = != > < >= <=  BETWEEN...AND  IN(...)  LIKE  IS NULL  IS NOT NULL
SELECT * FROM users WHERE age BETWEEN 18 AND 60 AND status = 1;
SELECT * FROM users WHERE username IN ('alice', 'bob', 'carol');
SELECT * FROM users WHERE email LIKE '%@test.com';  -- 左通配不走索引

-- 聚合函数 + GROUP BY
SELECT dept, COUNT(*) AS emp_count, AVG(salary) AS avg_salary,
       MAX(salary) AS max_sal, MIN(salary) AS min_sal, SUM(salary) AS total
FROM employees
WHERE status = 'active'
GROUP BY dept
HAVING AVG(salary) > 10000
ORDER BY avg_salary DESC;
```

## SELECT执行顺序

<Callout type="success" title="执行顺序是核心">
书写顺序：`SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT`
实际执行：`FROM → ON → JOIN → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT`

关键区别：①WHERE在GROUP BY之前，不能用聚合函数；②HAVING在GROUP BY之后，可以用聚合函数；③ORDER BY在SELECT之后，可以用列别名。
</Callout>

## WHERE vs HAVING

| 特性 | WHERE | HAVING |
|------|-------|--------|
| 执行时机 | 分组前 | 分组后 |
| 聚合函数 | 不能用 | 能用 |
| 过滤对象 | 单行数据 | 分组结果 |
| 性能 | 先过滤再分组（好） | 先分组再过滤（差） |

```
-- 正确：WHERE过滤行，HAVING过滤组
SELECT dept, AVG(salary) AS avg_sal
FROM employees
WHERE status = 'active'          -- 先过滤非活跃员工
GROUP BY dept
HAVING AVG(salary) > 10000       -- 再过滤平均薪资不够的部门
ORDER BY avg_sal DESC;
```

<Glossary>

<GlossaryItem term="DDL">
数据定义语言（Data Definition Language），用于定义和修改数据库结构——CREATE创建、ALTER修改、DROP删除、TRUNCATE清空。操作的是表/视图/索引的结构，不是数据行。
</GlossaryItem>

<GlossaryItem term="DML">
数据操作语言（Data Manipulation Language），用于操作表中的数据行——INSERT插入、UPDATE更新、DELETE删除。是日常开发最常用的SQL类型。
</GlossaryItem>

<GlossaryItem term="执行顺序">
SELECT语句的逻辑执行顺序与书写顺序不同。FROM先确定数据源，WHERE先过滤行，GROUP BY再分组，HAVING过滤组，SELECT选择列，ORDER BY排序，LIMIT截取。理解执行顺序是写对复杂SQL和优化的基础。
</GlossaryItem>

<GlossaryItem term="聚合函数">
对一组值进行计算返回单个值的函数——COUNT计数、SUM求和、AVG平均、MAX最大、MIN最小。通常搭配GROUP BY使用，COUNT(*)统计含NULL的总行数，COUNT(列)统计非NULL行数。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1**：SQL语言分为哪四大类？每类包含哪些核心语句？

<Answer>
DDL（数据定义）：CREATE/ALTER/DROP/TRUNCATE，操作库表结构。DML（数据操作）：INSERT/UPDATE/DELETE/REPLACE，操作数据行。DQL（数据查询）：SELECT/FROM/WHERE/GROUP BY/HAVING/ORDER BY/LIMIT，检索数据。DCL（数据控制）：GRANT/REVOKE/COMMIT/ROLLBACK，控制权限和事务。
</Answer>

**问题 2**：SELECT语句的书写顺序和实际执行顺序分别是什么？

<Answer>
书写顺序：SELECT→FROM→WHERE→GROUP BY→HAVING→ORDER BY→LIMIT。实际执行：FROM→ON→JOIN→WHERE→GROUP BY→HAVING→SELECT→DISTINCT→ORDER BY→LIMIT。重要性：WHERE在GROUP BY之前不能用聚合函数；ORDER BY在SELECT之后可以用别名。
</Answer>

**问题 3**：WHERE和HAVING有什么区别？请用一个查询说明：查询平均薪资大于10000的部门。

<Answer>
WHERE在分组前过滤行不能用聚合函数，HAVING在分组后过滤组可以用聚合函数。示例：SELECT dept, AVG(salary) as avg_salary FROM employees WHERE status='active' GROUP BY dept HAVING AVG(salary)>10000 ORDER BY avg_salary DESC; WHERE先排除非活跃员工，HAVING再筛选平均薪资够的部门。
</Answer>

**问题 4**：COUNT(*)、COUNT(列名)和COUNT(DISTINCT 列名)有什么区别？

<Answer>
COUNT(*)统计总行数含NULL，InnoDB专门优化性能最好。COUNT(列名)统计该列非NULL值数量。COUNT(DISTINCT 列名)统计去重后非NULL值数量，性能最差。性能排序：COUNT(*) >= COUNT(1) > COUNT(列) > COUNT(DISTINCT 列)。
</Answer>

</Exercises>
