## 六阶段执行链

### 1. 声明编码

固定 Node 版本、启动参数、环境变量和输入，先预测同步调用栈、异步资源与最终输出。没有版本证据的示例无法区分书中历史行为与当前运行时。

### 2. 计算字节数

明确数据是字符串、字节、流、报文、请求、事件还是数据库记录，并标出所有者。创建资源的代码必须同时设计 error、timeout、abort 或 close 路径。

### 3. 分配缓冲区

只保留最小处理器和一个完成出口。回调、Promise 与事件不得为同一操作重复签发结果；监听器注册顺序和一次性语义要能从代码读出。

### 4. 读写字段

注入一个边界：空输入、长输入、半包、慢消费者、权限拒绝、数据库回滚或客户端断开。停止在首个偏离点，保存错误对象、资源状态与未完成数量。

### 5. 验证边界

检查旧接口在现代 Node 的状态：仍支持、语义变化、弃用或移出核心。现代替代必须保持原章节要解决的问题，同时说明迁移不能自动保证的兼容行为。

### 6. 释放引用

清除故障并重放同一输入，等待文件、套接字、连接池和子进程排空。退出码、最终响应和资源计数全部收敛，才算恢复而不是暂时停止报错。

## 核心机制深挖

区分字符、编码后字节和缓冲区容量，用显式编码与端序完成字符串、数值、JSON 和复制边界。 所有案例统一记录五类证据：**输入表示、调度边界、资源所有者、错误出口、关闭条件**。输入表示错误会造成编码、分帧或查询歧义；调度边界错误会把同步事件误认为异步回调；所有权不清会留下描述符和连接；错误出口重复会产生二次响应；关闭条件缺失会让进程一直存活或强行丢数据。

本页签发不变量是：**字符长度与字节长度不混用，分配、读写偏移和端序都有边界证据，不使用不安全的旧 Buffer 构造方式。** 代码必须能回答正常路径完成了什么、边界输入限制在哪里、失败由谁观察、取消怎样传播、关闭等待哪些资源，以及 2014 年 API 在当前版本中是否仍适合新代码。只展示成功日志或最终页面，不能证明这些条件。

## 版本兼容账本

原书出版于 2014 年，示例所处的 Node、npm、Express、Socket.IO 与数据库驱动生态都早于当前版本。重构保留原书问题与模块身份，但代码采用安全、可运行的现代形式，并为 domain、punycode、旧 Buffer 构造器和旧框架 API 标记历史状态。读者迁移旧项目时应先固定原版本复现，再逐层替换接口与测试，不能一次升级所有依赖后凭报错猜测语义变化。

兼容账本至少包含：原书接口、当时用途、当前支持状态、推荐替代、行为差异和删除旧兼容层的条件。核心原理例如 TCP 无消息边界、流需要背压、事务需要回滚不会因版本改变；具体函数签名、默认超时、模块入口和错误类型则可能变化。把稳定原理与易变 API 分开，才能既忠实复刻知识体系，又不误导今天的新代码。

## 资源与失败矩阵

| 资源           | 正常完成       | 常见边界         | 失败出口       | 关闭证据     |
| -------------- | -------------- | ---------------- | -------------- | ------------ |
| Buffer 或消息  | 完整编码、解析 | 空、截断、超长   | 校验错误       | 无越界读写   |
| 文件或流       | 读写、管道结束 | 权限、慢目标     | pipeline 拒绝  | 描述符关闭   |
| 套接字或请求   | 响应一次       | 半包、断线、超时 | error 或 abort | close 已观察 |
| 子进程或连接池 | 退出或归还     | stderr、回滚     | 非零码或异常   | 无悬挂资源   |

## 最小可运行实验

```js
const payload = "节点";
const bytes = Buffer.from(payload, "utf8");
const frame = Buffer.alloc(4 + bytes.length);
frame.writeUInt32BE(bytes.length, 0);
bytes.copy(frame, 4);
console.log(frame.readUInt32BE(0), frame.subarray(4).toString("utf8"));
```

## 常见误区与故障注入

<Callout type="trap">
  **误区一：把“异步”理解成自动并行、自动安全。**
  回调仍可能阻塞主线程，异步资源仍会耗尽，多个完成出口仍会竞态。必须记录队列、并发上限、背压和资源关闭。
</Callout>
