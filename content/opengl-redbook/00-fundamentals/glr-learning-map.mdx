## 直觉引入

OpenGL红宝书就像一本烹饪教科书——从认识厨房用具(OpenGL基础)、学习基本刀工(着色器)、到掌握复杂菜式(现代OpenGL实践)。全书围绕可编程管线展开，从初始化到高级技术逐步深入。

## 概念讲解

<Term def="OpenGL状态的集合，所有操作在当前上下文中进行">OpenGL上下文</Term><Term def="运行在GPU上的GLSL程序">着色器</Term><Term def="顶点缓冲对象存储数据，顶点数组对象封装配置">VBO/VAO</Term><Term def="从顶点数据到屏幕像素的完整流程">渲染管线</Term>

全书分四大板块：**基础**(学习地图、OpenGL基础)、**核心**(着色器、几何、纹理)、**高级**(光照、帧缓冲、高级缓冲、现代实践)、**复习**(总复习)。

### 学习路线
基础->核心->高级->复习。先理解OpenGL初始化和上下文，再学着色器编程和几何处理，然后深入纹理和光照，最后掌握帧缓冲和现代实践。

## 代码对照

```cpp
// OpenGL初始化核心步骤
glfwInit();
glfwWindowHint(GLFW_CONTEXT_VERSION_MAJOR, 3);
glfwWindowHint(GLFW_CONTEXT_VERSION_MINOR, 3);
glfwWindowHint(GLFW_OPENGL_PROFILE, GLFW_OPENGL_CORE_PROFILE);
GLFWwindow* window = glfwCreateWindow(800, 600, "OpenGL", NULL, NULL);
glfwMakeContextCurrent(window);
gladLoadGLLoader((GLADloadproc)glfwGetProcAddress);
glViewport(0, 0, 800, 600);
```

OpenGL 3.3+ Core Profile是现代OpenGL的起点。GLFW创建窗口，GLAD加载OpenGL函数指针。

## 常见误区

<Callout type="trap">
**现象 →** 跳过基础直接写着色器。
**原因 →** 急于看到渲染效果。
**修法 →** OpenGL是状态机——不理解上下文和状态模型，着色器代码无法正确工作。先学初始化再写着色器。
</Callout>

<Callout type="trap">
**现象 →** 使用已废弃的即时模式(glBegin/glEnd)。
**原因 →** 老教程还在教即时模式。
**修法 →** 现代OpenGL(Core Profile)已移除即时模式。必须使用VBO/VAO和着色器。
</Callout>

## 练习

<Exercises>
**问题**：OpenGL红宝书分哪四个板块？

<Answer>
基础(学习地图、OpenGL基础)、核心(着色器、几何、纹理)、高级(光照、帧缓冲、高级缓冲、现代实践)、复习(总复习)。
</Answer>

**问题**：为什么现代OpenGL要移除即时模式？

<Answer>
即时模式每帧从CPU发送数据到GPU，带宽瓶颈且无法利用GPU并行。VBO将数据驻留GPU，一次上传反复绘制。
</Answer>
</Exercises>
