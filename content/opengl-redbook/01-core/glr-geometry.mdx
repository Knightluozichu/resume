## 直觉引入

VBO/VAO/EBO就像快递系统——VBO是货物(顶点数据)，VAO是包装规格(属性配置)，EBO是配送路线(索引顺序)。VBO把数据从CPU运到GPU，VAO记录如何解析，EBO告诉GPU用哪些顶点组成图元。

## 概念讲解

<Term def="顶点缓冲对象，在GPU内存中存储顶点数据">VBO</Term><Term def="顶点数组对象，封装顶点属性配置">VAO</Term><Term def="元素缓冲对象，存储顶点索引">EBO</Term><Term def="GL_POINTS/GL_LINES/GL_TRIANGLES等绘制模式">图元类型</Term>

### VBO/VAO/EBO关系
VBO存储数据，VAO记录如何读取(格式/偏移/位置)，EBO存储索引避免重复顶点。

### 顶点属性配置
glVertexAttribPointer(位置, 分量数, 类型, 归一化, 步长, 偏移)

### 图元类型
GL_TRIANGLES(每3顶点一个三角形)、GL_TRIANGLE_STRIP(连续三角形)、GL_TRIANGLE_FAN(扇形)

## 代码对照

```cpp
// VBO/VAO/EBO配置
float vertices[] = {
    0.5f, 0.5f, 0.0f, 1.0f, 1.0f,
    0.5f,-0.5f, 0.0f, 1.0f, 0.0f,
   -0.5f,-0.5f, 0.0f, 0.0f, 0.0f,
   -0.5f, 0.5f, 0.0f, 0.0f, 1.0f
};
unsigned int indices[] = {0,1,3, 1,2,3};
glGenVertexArrays(1, &VAO);
glGenBuffers(1, &VBO);
glGenBuffers(1, &EBO);
glBindVertexArray(VAO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, EBO);
glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 5*sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
glVertexAttribPointer(1, 2, GL_FLOAT, GL_FALSE, 5*sizeof(float), (void*)(3*sizeof(float)));
glEnableVertexAttribArray(1);
glDrawElements(GL_TRIANGLES, 6, GL_UNSIGNED_INT, 0);
```

交织布局(位置和UV在同一数组)利于缓存局部性。EBO避免重复顶点，立方体从36顶点减到24顶点。

## 常见误区

<Callout type="trap">
**现象 →** 每帧重新上传VBO数据。
**原因 →** 认为每次绘制都需要上传。
**修法 →** 静态数据用GL_STATIC_DRAW一次上传。只有动态数据(粒子)才用GL_DYNAMIC_DRAW每帧更新。
</Callout>

<Callout type="trap">
**现象 →** 忽略顶点数据对齐。
**原因 →** 随意排列顶点属性。
**修法 →** 顶点数据应4字节对齐。交织布局通常比分离布局缓存友好。vec3后加padding对齐vec4可提升性能。
</Callout>

## 练习

<Exercises>
**问题**：VBO和VAO的区别？

<Answer>
VBO存储实际顶点数据(位置/UV/法线等)，VAO存储顶点属性配置(如何从VBO读取数据)。一个VAO可绑定多个VBO。
</Answer>

**问题**：为什么用EBO？

<Answer>
EBO用索引引用顶点避免重复。立方体8个唯一顶点被3个面共享(不同法线)，用EBO可以用24个顶点代替36个顶点。
</Answer>
</Exercises>
