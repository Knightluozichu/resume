## 直觉：光照是几何、单位和采样合同的交点

OpenGL 没有“自动光照”。shader 接收位置、法线、材质和光源，选择一个 lighting model 输出颜色。若向量不在同一空间、颜色未在线性域计算、法线未正确变换，公式看似完整也没有物理或几何意义。

先预测：模型带非均匀缩放时，直接用 `mat3(model)` 变换法线会只改变法线长度，还是也改变方向？会改变方向，并破坏与切平面的垂直关系。

包括经典 Phong/Blinn-Phong 等；常数 ambient 只是间接光近似，不是 global illumination。


## 空间与法线矩阵

位置、法线、光向量和视向量必须统一到世界或观察空间。模型线性部分为 $M$ 时，为保持法线 $mathbf n$ 与切线 $mathbf t$ 的垂直关系，法线变换为：

$$
N=(M^{-1})^T,\qquad (N\mathbf n)\cdot(M\mathbf t)=\mathbf n\cdot\mathbf t=0.
$$

在刚体或统一缩放时可简化，但一般实现不应无条件使用 model matrix。顶点法线经过插值后长度不再为一，片段阶段需重新 normalize。


## Diffuse 与 Specular

令单位法线 $mathbf n$、指向光的单位向量 $mathbf l$、指向观察者的 $mathbf v$。Lambert 漫反射：

$$
L_d=k_d\odot I\,\max(\mathbf n\cdot\mathbf l,0).
$$

Blinn-Phong 使用半程向量 $mathbf h=\frac{\mathbf l+\mathbf v}{\|\mathbf l+\mathbf v\|}$：

$$
L_s=k_s\odot I\,\max(\mathbf n\cdot\mathbf h,0)^p.
$$

不可直接当 PBR roughness。Phong/Blinn-Phong 是教学与风格化模型，不自动能量守恒，也不应宣称 Blinn 一定更快或更自然。

```glsl
vec3 shadeLocal(Surface s, Light light, vec3 eye) {
    vec3 n = normalize(s.worldNormal);
    vec3 l = normalize(light.position - s.worldPosition);
    vec3 v = normalize(eye - s.worldPosition);
    vec3 h = normalize(l + v);
    float ndotl = max(dot(n, l), 0.0);
    float spec = ndotl > 0.0 ? pow(max(dot(n, h), 0.0), s.shininess) : 0.0;
    return light.radiance * (s.diffuse * ndotl + s.specular * spec);
}
```

所有颜色运算应在线性空间进行，最后再编码到 sRGB 显示目标。把 sRGB texel 数字直接相乘会低估或扭曲能量。

## 光源类型与衰减

方向光只有方向，无距离衰减；点光由位置产生 $mathbf l$ 和距离 $r$；聚光再乘锥角权重。物理点光近似按：

$$
E(r)=\frac{I}{r^2}.
$$

实时应用常用 $1/(k_c+k_lr+k_qr^2)$ 做艺术控制，但参数和有效范围必须记录。$r\to0$ 时需半径/最小距离避免奇异值。

聚光可在内外圆锥余弦之间 smoothstep，不能直接对角度线性插值后忘记单位。光源方向、位置和表面数据仍需同空间。

## 材质与法线细节

可通过 UBO/SSBO、纹理和实例 id 组织。材质参数的颜色空间、范围和缺省值必须固定。

Normal mapping 把纹理方向从切线空间通过 TBN 转到着色空间。TBN 要处理 UV 镜像 handedness，并在插值后正交化；高度 bump mapping 则由高度偏导扰动法线。二者改变着色法线，不改变几何轮廓或真实遮挡。

## Shadow mapping：从光源判断可见性

把可见性问题离散为深度纹理查询。

```cpp
// Pass 1: light depth
glBindFramebuffer(GL_DRAW_FRAMEBUFFER, shadowFbo);
glViewport(0, 0, shadowSize, shadowSize);
glClear(GL_DEPTH_BUFFER_BIT);
drawScene(lightDepthProgram);

// Pass 2: camera shading
glBindFramebuffer(GL_DRAW_FRAMEBUFFER, cameraFbo);
glBindTextureUnit(5, shadowDepth);
drawScene(litProgram);
```

相机 pass 中计算：

$$
\mathbf q=Bias\,P_LV_L\mathbf p_W,
\qquad shadow=[q_z-bias>d(q_x,q_y)].
$$

必须检查 $q$ 是否在有效投影域。方向光常用正交投影，聚光用透视，点光可用 cubemap 六面深度。


## Bias、过滤与伪影

shadow acne 来自有限深度精度和表面自比较；常数 bias 过大又造成 peter-panning。可结合 slope-scaled polygon offset、法线/斜率相关 bias，并用正反面策略谨慎减少自阴影。

PCF 在邻域做多次二值比较再平均，软化采样边缘但不是物理半影。分辨率、光投影范围和 texel footprint 决定 aliasing；扩大方向光范围会降低单位世界面积的 texel 密度。级联阴影解决大视距分配问题，同时引入 split 和级联接缝合同。

```glsl
float shadowPCF(sampler2DShadow map, vec3 q, vec2 texel) {
    float sum = 0.0;
    for (int y=-1; y<=1; ++y)
      for (int x=-1; x<=1; ++x)
        sum += texture(map, vec3(q.xy + vec2(x,y)*texel, q.z));
    return sum / 9.0;
}
```

## 小结

光照正确性从统一空间和法线不变量开始，并在线性颜色空间逐项计算材质响应；阴影映射再用光空间深度近似可见性。模型、偏差和过滤各有边界，必须通过分项附件和参数扫描验证，而不是以“看起来有立体感”验收。
