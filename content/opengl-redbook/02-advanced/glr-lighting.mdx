## 直觉引入

在OpenGL中实现光照就像搭舞台——灯光(光源)、演员(物体材质)和导演(着色器)。灯光决定光从哪来什么颜色，材质决定物体如何反射光，着色器把两者结合计算最终颜色。

## 概念讲解

<Term def="物体表面反射光的属性(环境/漫反射/镜面系数和光泽度)">材质</Term><Term def="mat3(transpose(inverse(model))))，正确变换法线">法线矩阵</Term><Term def="平行光(方向)、点光(位置+衰减)、聚光(位置+方向+锥角)">光源类型</Term><Term def="用纹理控制材质属性，如漫反射贴图、镜面贴图">光照贴图</Term>

### Phong光照实现
顶点着色器：变换法线和位置到世界空间。片段着色器：计算ambient+diffuse+specular。

### 法线变换
法线需用normalMatrix=transpose(inverse(mat3(model)))变换，不能直接用model矩阵。

### 光源类型
平行光(只有方向)、点光(位置+距离衰减)、聚光(位置+方向+内外锥角)

## 代码对照

```glsl
// 顶点着色器
#version 330 core
layout(location=0) in vec3 aPos;
layout(location=1) in vec3 aNormal;
out vec3 Normal;
out vec3 FragPos;
uniform mat4 model, view, projection;
void main() {
    FragPos = vec3(model * vec4(aPos, 1.0));
    Normal = mat3(transpose(inverse(model))) * aNormal;
    gl_Position = projection * view * vec4(FragPos, 1.0);
}
```

法线矩阵=transpose(inverse(mat3(model)))确保非均匀缩放时法线方向正确。多光源循环累加。

## 常见误区

<Callout type="trap">
**现象 →** 直接用model矩阵变换法线。
**原因 →** model矩阵能变换顶点就能变换法线。
**修法 →** 非均匀缩放时model矩阵会使法线方向错误。必须用法线矩阵。
</Callout>

<Callout type="trap">
**现象 →** 所有物体用相同的材质参数。
**原因 →** 简化处理用一个材质。
**修法 →** 不同物体应有不同材质。用材质结构体或纹理控制每物体材质属性。
</Callout>

## 练习

<Exercises>
**问题**：为什么法线不能直接用model矩阵变换？

<Answer>
非均匀缩放时model矩阵会扭曲法线方向。法线矩阵=transpose(inverse(mat3(model)))是保证法线正确的数学变换。
</Answer>

**问题**：点光源的衰减如何计算？

<Answer>
衰减=1.0/(constant+linear*distance+quadratic*distance^2)。constant通常1.0，linear和quadratic根据距离范围选择。
</Answer>
</Exercises>
