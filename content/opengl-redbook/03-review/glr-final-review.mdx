## 直觉引入

总复习把OpenGL知识拼成完整图景：从初始化(上下文/状态机)到数据管理(VBO/VAO/EBO)，从着色器(GLSL编程)到渲染技术(纹理/光照/帧缓冲)，从高级缓冲(UBO/SSBO)到现代实践(实例化/间接绘制)。

## 概念讲解

<Term def="从顶点到像素的完整处理流程">渲染管线</Term><Term def="顶点数据管理的三大核心对象">VBO/VAO/EBO</Term><Term def="运行在GPU上的GLSL程序">着色器</Term><Term def="OpenGL通过设置状态影响绘制">状态机</Term>

### 核心流程
初始化->VBO/VAO上传顶点->着色器变换和着色->纹理采样->深度测试->混合->帧缓冲

### 知识关联
着色器(顶点变换+片段着色)是核心；VBO/VAO是数据基础；纹理/光照是表现层；帧缓冲是输出层；高级缓冲/实例化是优化层

### 性能优化
减少Draw Call(实例化/合批)、减少状态切换(排序)、减少带宽(压缩/Mipmap)、减少CPU-GPU通信(间接绘制)

## 代码对照

```cpp
// 现代OpenGL渲染循环骨架
while(!glfwWindowShouldClose(window)) {
    glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT);
    glUseProgram(shaderProgram);
    glBindVertexArray(VAO);
    // 实例化渲染减少Draw Call
    glDrawElementsInstanced(GL_TRIANGLES, indexCount, GL_UNSIGNED_INT, 0, instanceCount);
    glfwSwapBuffers(window);
    glfwPollEvents();
}
```

这个循环展示了现代OpenGL核心：一个着色器+一个VAO+实例化绘制。实际场景需要排序、多Pass、FBO等。

## 常见误区

<Callout type="trap">
**现象 →** 学了API但不知道怎么组合使用。
**原因 →** 各章独立学习缺乏整合。
**修法 →** 以渲染管线为主线串联：初始化->VBO/VAO(数据)->着色器(处理)->纹理/光照(表现)->帧缓冲(输出)->高级(优化)。
</Callout>

<Callout type="trap">
**现象 →** 忽视性能只追求功能实现。
**原因 →** 先实现再说。
**修法 →** 应在设计阶段就考虑性能：Draw Call数量、状态切换频率、带宽使用。用Profiler定位瓶颈。
</Callout>
