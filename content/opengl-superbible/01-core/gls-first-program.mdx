## 直觉引入

第一个OpenGL程序就像学骑自行车——初始配置繁琐但一旦跑通就一通百通。核心是三件事：初始化窗口(GLFW)、加载函数(GLAD)、渲染循环(清空→绘制→交换)。渲染一个三角形是图形学的Hello World。

## 概念讲解

<Term def="创建窗口和管理OpenGL上下文的库">GLFW</Term><Term def="跨平台加载OpenGL函数指针的库">GLAD</Term><Term def="持续处理输入、清空缓冲、绘制、交换缓冲的循环">渲染循环</Term><Term def="顶点缓冲对象存储数据，顶点数组对象封装配置">VBO/VAO</Term>

### 第一个程序流程
1. GLFW初始化+创建窗口 2. GLAD加载函数 3. 编译着色器 4. 创建VBO/VAO上传三角形 5. 渲染循环

### 三角形数据
3个顶点，每个3个float(x,y,z)。VBO存储9个float，VAO配置属性(3分量)，glDrawArrays(GL_TRIANGLES,0,3)。

### 着色器
顶点着色器：gl_Position=vec4(aPos,1.0)。片段着色器：FragColor=vec4(1.0,0.5,0.2,1.0)。

## 代码对照

```cpp
// 第一个三角形：核心代码
// 着色器
const char* vs = "#version 330 core\nlayout(location=0) in vec3 aPos;\nvoid main(){gl_Position=vec4(aPos,1.0);}";
const char* fs = "#version 330 core\nout vec4 FragColor;\nvoid main(){FragColor=vec4(1.0,0.5,0.2,1.0);}";
// 顶点数据
float vertices[] = {-0.5f,-0.5f,0.0f, 0.5f,-0.5f,0.0f, 0.0f,0.5f,0.0f};
// VBO/VAO
glGenVertexArrays(1, &VAO);
glGenBuffers(1, &VBO);
glBindVertexArray(VAO);
glBindBuffer(GL_ARRAY_BUFFER, VBO);
glBufferData(GL_ARRAY_BUFFER, sizeof(vertices), vertices, GL_STATIC_DRAW);
glVertexAttribPointer(0, 3, GL_FLOAT, GL_FALSE, 3*sizeof(float), (void*)0);
glEnableVertexAttribArray(0);
// 渲染循环
while(!glfwWindowShouldClose(window)) {
    glClear(GL_COLOR_BUFFER_BIT);
    glUseProgram(shaderProgram);
    glBindVertexArray(VAO);
    glDrawArrays(GL_TRIANGLES, 0, 3);
    glfwSwapBuffers(window);
    glfwPollEvents();
}
```

第一个程序虽然代码不多但涉及初始化、着色器编译、VBO/VAO配置、渲染循环等核心概念。

## 常见误区

<Callout type="trap">
**现象 →** 窗口创建后白屏不渲染。
**原因 →** 着色器或VBO配置错误。
**修法 →** 逐步排查：1)检查着色器编译错误 2)检查VAO是否绑定 3)检查glDrawArrays参数 4)检查视口设置。
</Callout>

<Callout type="trap">
**现象 →** 着色器源码字符串中忘记换行符。
**原因 →** 字符串拼接写在一起。
**修法 →** GLSL源码必须每行用\n分隔。常见错误是多个layout/in/out写在一行导致编译失败。
</Callout>
