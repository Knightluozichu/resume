## 概念讲解

### 核心流程
初始化->着色器管线(顶点→[曲面细分]→[几何]→光栅化→片段)->缓冲管理->纹理光照->性能优化

### 知识关联
着色器管线是核心(处理流程)；缓冲对象是数据层(VBO/UBO/SSBO)；纹理映射是表现层；性能优化是效率层

### 实践路线
第一个程序→管线理解→顶点/片段着色→纹理→缓冲→几何着色器→性能优化

## 代码对照

```cpp
// OpenGL渲染引擎核心架构(伪代码)
class RenderEngine {
    void render(Scene& scene, Camera& camera) {
        // 1. GPU剔除(Compute Shader)
        computeShader.dispatch(scene.objects);
        glMemoryBarrier(GL_COMMAND_BARRIER_BIT);
        
        // 2. Z-Prepass(简单着色器写深度)
        simpleShader.use();
        glDrawElementsIndirect(GL_TRIANGLES, ...);
        
        // 3. 几何Pass(复杂着色器,Early-Z剔除)
        complexShader.use();
        glDrawElementsIndirect(GL_TRIANGLES, ...);
        
        // 4. 透明Pass(前向+排序)
        renderTransparent(scene.transparentObjects);
        
        // 5. 后处理(FBO)
        glBindFramebuffer(postProcessFBO);
        renderQuad(postProcessShader);
    }
};
```

完整渲染引擎整合:GPU剔除+Z-Prepass+实例化+间接绘制+透明排序+后处理。

## 常见误区

<Callout type="trap">
**现象 →** 学了各技术但不知道怎么组合成引擎。
**原因 →** 各章独立学习缺乏整合。
**修法 →** 以着色器管线为核心:初始化→VBO/VAO(数据)→着色器(处理)→纹理/光照(表现)→缓冲(优化)→性能(效率)。每层技术对应引擎的一个子系统。
</Callout>

<Callout type="trap">
**现象 →** 忽视性能只追求功能。
**原因 →** 先实现再说。
**修法 →** 应在设计阶段考虑性能:Draw Call数量、状态切换、带宽使用。用Profiler定位瓶颈。性能优化是持续过程不是最后步骤。
</Callout>

## 练习

<Exercises>
**问题**：用一句话概括OpenGL编程实践核心。

<Answer>
OpenGL是状态机+可编程管线：设置状态(VBO/VAO/着色器/纹理)后绘制，着色器控制顶点变换和片段着色，缓冲管理GPU数据，性能优化减少CPU-GPU通信。
</Answer>

**问题**：一个完整渲染引擎需要整合哪些技术？

<Answer>
GPU剔除(Compute)+Z-Prepass+实例化+间接绘制(减少Draw Call)+纹理压缩+Mipmap(减少带宽)+延迟着色(多光源)+透明排序+后处理(FBO)。各技术对应管线不同阶段。
</Answer>
</Exercises>
