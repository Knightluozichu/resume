## 栈 vs 堆：100 倍的差距

C++ 中动态分配内存有两种方式：栈分配和堆分配。它们的成本差异可达 100-1000 倍。

栈分配只需移动栈指针寄存器（1 条指令，约 1 纳秒），因为栈是连续的，分配和释放都是指针移动。堆分配（`malloc`/`new`）则复杂得多：分配器要在空闲链表或树中搜索合适大小的块，可能触发系统调用（`brk`/`mmap`），还要修改页表——整个过程数百纳秒到微秒。

这意味着：一次堆分配的开销，相当于 100-1000 次栈分配。如果热路径中每次迭代都 malloc 一次，分配开销可能占整体耗时的 30% 以上。

## 减少分配的三种策略

### 1. 栈优先

<Term def="优先在栈上分配内存，避免堆分配的策略">栈优先</Term>

能用栈就不用堆。固定大小的数组用 `std::array` 替代 `std::vector`，临时缓冲区用栈数组替代 `new`。栈分配零成本、无碎片、自动释放。

```cpp
// 低效：堆分配
int* buf = new int[1024];
// ... 使用 buf ...
delete[] buf;

// 高效：栈分配
int buf[1024];  // 零成本
// ... 使用 buf ...
// 自动释放
```

注意：栈空间有限（通常 1-8MB），大数组仍需堆分配。

### 2. 对象池

频繁创建销毁的同类型对象，用对象池预分配一批，取/还都是 O(1) 的链表操作：

```cpp
// 对象池：预分配 N 个对象，复用
template<typename T>
class ObjectPool {
    std::vector<std::unique_ptr<T>> pool;
public:
    T* acquire() { /* 从池中取 */ }
    void release(T* obj) { /* 归还到池中 */ }
};
```

把 N 次 malloc 合并为 1 次预分配，后续取/还无 malloc。

### 3. Arena 分配器

一个请求/任务内所有临时对象从同一块 arena 分配（指针移动，O(1)），任务结束后整块释放：

```cpp
// Arena：批量分配，整块释放
Arena arena(1024 * 1024);  // 预分配 1MB
auto* a = arena.alloc<Parser>();  // 指针移动，无 malloc
auto* b = arena.alloc<Response>();  // 同上
// ... 任务结束 ...
arena.reset();  // 整块回收，无逐个 free
```

### 4. 线程局部缓冲复用

热路径中的临时 `vector` 用 `thread_local` 复用：

```cpp
void process(const std::vector<int>& data) {
    thread_local std::vector<int> temp;  // 只分配一次
    temp.resize(data.size());
    // ... 使用 temp ...
}
```

<Callout type="tip">
换分配器是零改动优化：链接 tcmalloc 或 jemalloc 替代 glibc malloc，多线程分配性能提升 2-5 倍，无需改一行代码。这是性价比最高的内存优化。
</Callout>

## 常见误区

<Callout type="trap">
<strong>现象 →</strong> 热路径中每次调用都创建临时 `vector`，profiling 显示 30% 时间在 `malloc`。 <strong>原因 →</strong> 临时对象在函数内创建、析构时释放，每次调用都 malloc/free 一轮。 <strong>修法 →</strong> 用 `thread_local` 缓冲复用（只分配一次），或让调用方传入缓冲区。把 N 次 malloc 降为 1 次。
</Callout>

## 小结与练习

- 栈分配比堆分配快 100-1000 倍——能用栈就不用堆
- 对象池：预分配 + 复用，把 N 次 malloc 合并为 1 次
- Arena：批量分配 + 整块释放，适合请求级临时对象
- `thread_local` 缓冲复用热路径临时对象
- 换 tcmalloc/jemalloc 是零改动优化

## 名词解释

<Glossary>
<GlossaryItem term="对象池">
预分配一批同类型对象，需要时从池中取空闲槽，用完归还，不调用 malloc/free。把 N 次分配合并为 1 次预分配。
</GlossaryItem>
<GlossaryItem term="Arena 分配器">
预分配大块内存，内部按指针移动分配，任务结束后整块释放。适合请求级临时对象，无碎片、无逐个 free。
</GlossaryItem>
<GlossaryItem term="tcmalloc/jemalloc">
Google/Facebook 的高性能 malloc 替代实现，多线程下用线程局部缓存减少锁竞争，比 glibc malloc 快 2-5 倍，零代码改动。
</GlossaryItem>
</Glossary>
