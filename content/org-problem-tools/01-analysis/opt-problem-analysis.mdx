## 学习目标

- 掌握5W2H分析法的七个维度，能够全面界定问题边界
- 理解SWOT分析的内外结合框架，能够评估组织态势
- 学会力场分析，识别变革中的驱动力与阻力
- 掌握MECE原则，确保问题拆解不重叠、不遗漏

## 核心概念

### 问题分析的本质

问题分析是解决组织问题的第一步——在动手解决之前，必须先搞清楚「问题到底是什么」。许多组织问题之所以反复出现，不是解决方案不好，而是问题定义错了。问题分析工具的核心价值在于：用结构化方法替代直觉判断，确保我们对问题的理解是全面的、准确的、可沟通的。

### 5W2H分析法

5W2H是用七个问题全面描述问题的框架：

| 维度 | 问题 | 作用 |
|------|------|------|
| What（何事） | 发生了什么问题？ | 界定问题本身 |
| Why（何因） | 为什么是问题？ | 明确问题意义 |
| Who（何人） | 谁涉及其中？ | 识别利益相关者 |
| When（何时） | 何时发生？ | 确定时间范围 |
| Where（何地） | 在哪里发生？ | 确定空间范围 |
| How（如何） | 如何发生？ | 描述发生机制 |
| How much（几何） | 影响多大？ | 量化问题严重性 |

### SWOT分析

SWOT从内部和外部两个维度，正向和负向两个方向，构建四象限态势矩阵：

- **S（优势）**：内部正向因素，组织的核心竞争力
- **W（劣势）**：内部负向因素，组织的短板和不足
- **O（机会）**：外部正向因素，环境提供的有利条件
- **T（威胁）**：外部负向因素，环境带来的挑战

### 力场分析

力场分析认为，任何现状都是驱动力和阻力动态平衡的结果。变革不是简单的「推动」，而是识别并增强驱动力、削弱阻力的过程。

### MECE原则

MECE（Mutually Exclusive, Collectively Exhaustive）是所有分析工具的底层思维：**相互独立、完全穷尽**。即拆解后的子项之间不重叠，合起来覆盖全部情况。

### 问题分析四步流程

1. **界定**：用5W2H描述问题
2. **拆解**：用MECE分解结构
3. **分析**：用SWOT评估态势
4. **判断**：用力场分析定方向

### 工具选择指南

| 场景 | 推荐工具 |
|------|----------|
| 问题不清晰 | 先用5W2H界定，再用MECE拆解 |
| 需要战略判断 | 用SWOT分析内外态势 |
| 面临变革阻力 | 用力场分析识别驱动力与阻力 |
| 复杂问题 | 多种工具组合使用，先界定再拆解 |

| 术语 | 释义 |
|------|------|
| 5W2H | 七维度问题界定框架 |
| SWOT | 优势-劣势-机会-威胁四象限分析 |
| 力场分析 | 驱动力与阻力的动态平衡分析 |
| MECE | 相互独立、完全穷尽的拆解原则 |
| 态势分析 | 对组织内外环境的综合评估 |
| 驱动力 | 推动变革向目标方向前进的力量 |
| 阻力 | 阻碍变革或维持现状的力量 |

## 练习题

1. 用5W2H分析法描述你工作中遇到的一个实际问题。
2. SWOT分析的四个象限如何区分内部与外部、正向与负向？
3. 力场分析如何帮助管理者制定变革策略？
4. MECE原则为什么是所有分析工具的底层思维？违反MECE会导致什么后果？
