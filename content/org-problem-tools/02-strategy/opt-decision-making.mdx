## 核心概念

### 决策制定的本质

决策制定是在多个可行方案中选择最优解的过程。与战略规划（定方向）不同，决策制定（选方案）更关注在不确定性条件下的选择质量。好的决策不等于好的结果——但用结构化工具做决策，能显著提高长期成功率。

### 决策矩阵（加权评分法）

决策矩阵是最实用的决策工具：列出方案和评估维度，为每个维度赋予权重，对每个方案在各维度打分，加权求和后比较总分。

**操作步骤：**
1. 确定评估维度和权重（权重之和为1）
2. 对每个方案在各维度打分（通常1-10分）
3. 计算加权得分 = 各维度得分 × 权重之和
4. 选择加权得分最高的方案

### AHP层次分析法

AHP将复杂决策分解为三个层次：

- **目标层**：决策的最终目标
- **准则层**：评估方案的多项准则
- **方案层**：可选的备选方案

通过两两比较确定各层权重，最终合成各方案的综合优先度。AHP的优势在于将主观判断转化为一致的量化权重。

### 德尔菲法

德尔菲法通过匿名迭代收敛专家意见：

1. **第1轮**：专家独立填写问卷，给出判断和理由
2. **汇总**：整理所有意见，匿名反馈给每位专家
3. **第2轮**：专家看到他人意见后修正自己的判断
4. **收敛**：重复2-3轮，直到意见趋于一致

德尔菲法的关键是**匿名性**——避免权威效应和从众心理。

### 情景分析

情景分析不预测单一未来，而是构建多个可能的情景（乐观、基准、悲观），为每个情景制定应对预案。它的价值不在于预测准确，而在于**让组织提前思考不同未来下的应对策略**。

### 决策制定四步流程

1. **明确决策目标**：想清楚要解决什么问题
2. **列举可行方案**：不少于三个备选方案
3. **加权评估排序**：用决策矩阵或AHP量化对比
4. **情景验证与决策**：用情景分析检验稳健性

### 核心原则

**量化对比替代直觉判断，多情景预演降低不确定性风险**

## 练习题

1. 用决策矩阵对一个你面临的三选一决策进行加权评分，写出维度、权重和打分。
2. AHP层次分析法的三个层次分别是什么？它与决策矩阵相比有什么优势？
3. 德尔菲法为什么要保持匿名性？如果不匿名会有什么问题？
4. 情景分析与单一预测相比有什么优势？如何为悲观情景制定预案？
