## 学习目标

- 掌握PEST分析，扫描外部宏观环境的四个维度
- 理解波特五力模型，评估行业竞争结构与利润空间
- 学会波士顿矩阵（BCG），基于增长率和份额配置业务资源
- 掌握价值链分析，识别组织的价值创造环节与竞争优势

## 核心概念

### 战略规划的本质

战略规划回答「组织应该往哪个方向走」的问题。它不是一份文档，而是一套从外到内、从宏观到微观的系统思考方法：先扫描外部环境（PEST），再评估行业竞争（五力），接着配置业务组合（BCG），最后找到价值创造的关键环节（价值链）。

### PEST分析

PEST从四个维度扫描组织面临的外部宏观环境：

| 维度 | 关注点 | 典型因素 |
|------|--------|----------|
| P（政治） | 政策法规 | 政策变化、法规调整、政治稳定性 |
| E（经济） | 经济趋势 | 增长率、利率汇率、通胀水平 |
| S（社会） | 社会变迁 | 人口结构、消费观念、生活方式 |
| T（技术） | 技术发展 | 技术趋势、研发投入、数字化转型 |

### 波特五力模型

五力模型认为，行业利润空间由五股竞争力量共同决定：

1. **行业内竞争**：现有竞争者的对抗强度
2. **新进入者威胁**：行业壁垒的高低
3. **替代品威胁**：替代产品/服务的吸引力
4. **供应商议价力**：上游的控制力
5. **买方议价力**：下游的控制力

### 波士顿矩阵（BCG）

BCG基于市场增长率和相对份额两个维度，将业务分为四类：

| 类型 | 增长率 | 份额 | 策略 |
|------|--------|------|------|
| 明星 | 高 | 高 | 加大投资，保持领先 |
| 问号 | 高 | 低 | 选择性投资或放弃 |
| 现金牛 | 低 | 高 | 榨取利润，供给其他业务 |
| 瘦狗 | 低 | 低 | 收缩或退出 |

### 价值链分析

价值链将组织的活动分为主体活动和支持活动：

- **主体活动**：进货物流 → 生产运营 → 发货物流 → 营销销售 → 售后服务
- **支持活动**：采购、技术开发、人力资源管理、基础设施

通过分析每个环节的成本和价值贡献，识别竞争优势所在。

### 战略规划四步流程

**从外到内：宏观环境（PEST） → 行业竞争（五力） → 业务组合（BCG） → 价值创造环节（价值链）**

## 术语表

| 术语 | 释义 |
|------|------|
| PEST | 政治-经济-社会-技术宏观环境分析 |
| 五力模型 | 波特提出的五种竞争力量分析框架 |
| 波士顿矩阵 | 基于增长率和份额的业务组合矩阵 |
| 价值链 | 组织从输入到输出的价值创造活动序列 |
| 明星业务 | 高增长高份额的业务，需加大投资 |
| 现金牛业务 | 低增长高份额的业务，提供稳定现金流 |
| 问号业务 | 高增长低份额的业务，需选择性投资 |
| 瘦狗业务 | 低增长低份额的业务，应考虑退出 |

## 练习题

1. PEST分析的四个维度分别关注什么？请为每个维度举出一个影响你所在行业的因素。
2. 波特五力模型中，哪一股力量对你的行业利润影响最大？为什么？
3. 波士顿矩阵的四类业务分别应该采取什么策略？
4. 价值链分析如何帮助组织识别竞争优势？主体活动和支持活动的区别是什么？
