## 学习目标

- 掌握PDCA循环，理解持续改进的螺旋上升机制
- 学会六西格玛DMAIC五步法，用数据驱动降低变异
- 理解精益生产的七大浪费，聚焦客户价值
- 掌握价值流图与看板管理，实现拉动式生产

## 核心概念

### 流程改善的本质

流程改善回答「如何把事情做得更好」的问题。它不是一次性的项目，而是持续的循环——每一次改进都是下一轮改进的起点。流程改善的核心理念是：消除浪费、降低变异、持续循环。

### PDCA循环

PDCA是持续改进的基础引擎，由四个阶段构成一个螺旋上升的循环：

| 阶段 | 含义 | 关键活动 |
|------|------|----------|
| P（Plan） | 计划 | 制定目标、分析现状、设计方案 |
| D（Do） | 执行 | 实施方案、收集数据 |
| C（Check） | 检查 | 评估效果、对比目标 |
| A（Act） | 改进 | 标准化成功经验、进入下一轮 |

每完成一轮PDCA，改进水平就上升一个台阶。

### 六西格玛DMAIC

六西格玛以数据驱动降低变异，目标是每百万次缺陷不超过3.4（6西格玛水平）。DMAIC是其核心五步法：

1. **D（Define）定义**：确定问题和客户需求
2. **M（Measure）测量**：收集数据，建立基线绩效
3. **A（Analyze）分析**：识别根因和关键影响因素
4. **I（Improve）改进**：实施方案，优化流程
5. **C（Control）控制**：建立监控机制，维持成果

### 精益生产

精益生产的核心是消除七大浪费——任何不为客户创造价值的活动都是浪费：

1. **过量生产**：生产多于需求
2. **等待**：人等物、物等人
3. **搬运**：不必要的物料移动
4. **过度加工**：超出客户要求的加工
5. **库存**：过多的原材料、在制品或成品
6. **动作**：人的不必要动作
7. **不良品**：返工和报废

### 价值流图（VSM）

价值流图将从原材料到客户的整个流程可视化，区分增值时间和非增值时间（等待），帮助识别改善重点。

### 看板管理

看板实现拉动式生产——后工序只在前工序有需求时才生产，通过控制在制品数量，减少库存浪费。

### 改善工具选择指南

| 场景 | 推荐工具 |
|------|----------|
| 日常改进 | PDCA循环 |
| 质量缺陷 | 六西格玛DMAIC |
| 效率提升 | 精益生产 + 价值流图 |

### 核心原则

**消除浪费、降低变异、持续循环——改善永无终点**

## 练习题

1. PDCA循环的四个阶段分别是什么？为什么说它是「螺旋上升」而非「原地打转」？
2. 六西格玛DMAIC五步法的每一步目标是什么？6西格玛水平的缺陷率是多少？
3. 精益生产的七大浪费分别是什么？请为每种浪费举出一个你工作中的例子。
4. 价值流图如何区分增值时间和非增值时间？看板管理如何实现拉动式生产？
