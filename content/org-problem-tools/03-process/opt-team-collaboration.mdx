## 学习目标

- 掌握RACI责任分配矩阵，确保每项任务有且仅有一个负责人
- 学会六顶思考帽，用平行思维将对抗式讨论变为协作式探索
- 理解头脑风暴与名义小组技术的组合使用，兼顾发散与收敛
- 掌握托马斯-基尔曼冲突管理模型，根据场景选择合适的冲突策略

## 核心概念

### 团队协作的本质

团队协作回答「如何让一群人高效地一起工作」的问题。团队效率不等于个人效率之和——如果没有清晰的责任、有效的讨论机制和冲突管理能力，团队产出可能远低于个人之和。团队协作工具的价值在于：从个体效率到团队协同，让对的人在对的时间用对的方式做对的事。

### RACI责任分配矩阵

RACI为每项任务明确四种角色：

| 角色 | 含义 | 职责 |
|------|------|------|
| R（Responsible） | 负责 | 实际执行任务 |
| A（Accountable） | 批准 | 对结果负最终责任，有且仅有一个 |
| C（Consulted） | 咨询 | 提供意见和专长 |
| I（Informed） | 知会 | 需被告知结果 |

**核心原则：每项任务有且仅有一个A（负责人）。**

### 六顶思考帽

六顶思考帽用六种颜色代表六种思维模式，要求团队在同一时间用同一种视角思考：

| 颜色 | 思维模式 | 关注点 |
|------|----------|--------|
| 白帽 | 数据事实 | 有什么信息和数据 |
| 红帽 | 直觉情感 | 感觉和直觉是什么 |
| 黑帽 | 风险批判 | 有什么风险和问题 |
| 黄帽 | 积极价值 | 有什么好处和价值 |
| 绿帽 | 创新创意 | 有什么新想法 |
| 蓝帽 | 流程控制 | 如何组织和推进 |

**典型流程：蓝帽开场 → 白帽事实 → 红帽直觉 → 黄帽价值 → 黑帽风险 → 绿帽创意 → 蓝帽总结**

### 头脑风暴与名义小组

两种工具组合使用，兼顾发散与收敛：

- **头脑风暴（发散）**：自由提出想法，禁止批评，求数量，欢迎联想
- **名义小组（收敛）**：独立写→轮流说→投票排序

### 冲突管理模型（托马斯-基尔曼）

基于「坚持自身利益」和「合作程度」两个维度，五种冲突策略：

| 策略 | 坚持 | 合作 | 适用场景 |
|------|------|------|----------|
| 竞争 | 高 | 低 | 紧急决策、原则问题 |
| 合作 | 高 | 高 | 双方都有价值的复杂问题 |
| 妥协 | 中 | 中 | 双方都需让步的谈判 |
| 回避 | 低 | 低 | 问题不重要或需冷静 |
| 迁就 | 低 | 高 | 维护关系比问题本身重要 |

### 团队协作核心逻辑

**明确责任（RACI） → 平行思考（六帽） → 发散收敛（头脑风暴+名义小组） → 管理冲突（TKI）**

## 术语表

| 术语 | 释义 |
|------|------|
| RACI | 负责-批准-咨询-知会责任分配矩阵 |
| 六顶思考帽 | 六种颜色代表六种平行思维模式 |
| 头脑风暴 | 自由发散、禁止批评的创意生成方法 |
| 名义小组 | 独立写-轮流说-投票排序的决策方法 |
| 平行思维 | 同一时间用同一视角思考的方法 |
| TKI模型 | 托马斯-基尔曼冲突管理模型 |
| 竞争策略 | 高坚持低合作的冲突应对方式 |
| 合作策略 | 高坚持高合作的冲突应对方式 |

## 练习题

1. RACI矩阵中R和A的区别是什么？为什么每项任务只能有一个A？
2. 六顶思考帽的六种颜色分别代表什么思维模式？为什么要「平行思维」？
3. 头脑风暴和名义小组技术如何组合使用？为什么不能只用其中一种？
4. 托马斯-基尔曼模型的五种冲突策略分别适用于什么场景？
