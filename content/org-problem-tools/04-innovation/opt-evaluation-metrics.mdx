## 学习目标

- 掌握OKR（目标与关键结果），用方向性目标加量化关键结果驱动挑战

## 核心概念

### 评估度量的本质

评估度量回答「做得怎么样」的问题。没有度量就没有改进——无法量化的东西无法管理。评估度量工具的价值在于：将战略目标转化为可度量的指标体系，提供反馈闭环，驱动持续改进。

### OKR（目标与关键结果）

OKR由一个方向性目标（O）和若干可量化的关键结果（KR）组成：

- **O（目标）**：方向性、鼓舞人心、定性描述
- **KR（关键结果）**：可量化、有时间限制、可验证

OKR鼓励挑战——70%的完成度即视为成功，不与绩效奖金直接挂钩。

### KPI（关键绩效指标）

KPI是衡量绩效达标情况的量化指标，遵循SMART原则：

| 原则 | 含义 |
|------|------|
| S（Specific） | 具体明确 |
| M（Measurable） | 可量化 |
| A（Achievable） | 可达成 |
| R（Relevant） | 与目标相关 |
| T（Time-bound） | 有时限 |

**OKR vs KPI**：OKR重方向与挑战，KPI重考核与达标；OKR不与奖金直接挂钩，KPI通常挂钩。

### 平衡计分卡（BSC）

BSC从四个维度平衡战略落地，避免只看财务指标的短视：

| 维度 | 核心问题 | 典型指标 |
|------|----------|----------|
| 财务 | 股东怎么看我们 | 利润、ROI、成本 |
| 客户 | 客户怎么看我们 | 满意度、市占率 |
| 内部流程 | 我们必须擅长什么 | 效率、质量、周期 |
| 学习成长 | 能否持续创造价值 | 培训、创新、文化 |

### 360度评估

360度评估从多个维度收集反馈：上级、下级、平级、外部客户和本人，形成全方位的行为评价。它的价值在于：打破单一视角的盲区。

### NPS（净推荐值）

NPS用一个问题衡量客户忠诚度：「你有多大可能推荐我们？」

- **推荐者（9-10分）**：忠实客户
- **被动者（7-8分）**：满意但不忠诚
- **贬损者（0-6分）**：不满意可能负面传播

**NPS = 推荐者百分比 - 贬损者百分比**

### 评估度量核心逻辑

**战略目标（OKR） → 过程指标（KPI+BSC四维） → 行为反馈（360度） → 客户声音（NPS） → 闭环改进**

## 术语表

| 术语 | 释义 |
|------|------|
| OKR | 目标与关键结果，方向性目标加量化验证 |
| KPI | 关键绩效指标，衡量达标情况的量化指标 |
| SMART | 具体-可量化-可达成-相关-有时限原则 |
| 平衡计分卡 | 财务+客户+流程+成长四维度战略落地工具 |
| 360度评估 | 多维度全方位收集行为反馈的评估方法 |
| NPS | 净推荐值，衡量客户忠诚度的单一指标 |
| 推荐者 | NPS中打9-10分的忠实客户 |
| 贬损者 | NPS中打0-6分的不满意客户 |

## 练习题

4. NPS的计算公式是什么？推荐者、被动者和贬损者的分值范围分别是多少？
