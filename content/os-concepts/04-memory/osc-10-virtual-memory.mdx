从请求调页、写时复制和页面置换进入帧分配、抖动、工作集、内存压缩、内核分配及 Linux/Windows/Solaris 实例。 每个目录概念都放回“访问虚拟页面 → 检测缺页 → 选择物理帧 → 执行页面置换 → 更新驻留集合 → 恢复故障指令”资源状态机。输入可能是系统调用、地址、字节流、中断、资源请求或远程消息；状态可能位于进程表、页表、设备队列、文件元数据、虚拟机或保护域；输出同时说明返回值、所有权与下一阶段可依赖的承诺。

本页不变量是：**缺页处理可重启且不丢失程序状态；置换遵守脏页与固定页约束，驻留集和负载控制避免持续抖动。**。正常和错误路径都必须保持它。一次成功只证明一个样本可用，不能证明边界安全；所以每项机制进入正常、边界、失败和恢复四条轨迹，并写清谁检测、谁阻塞或重试、谁逆序清理、谁上报。

用最小工作负载沿“访问虚拟页面 → 检测缺页 → 选择物理帧 → 执行页面置换 → 更新驻留集合 → 恢复故障指令”记录系统调用、内核对象和资源状态，再注入单一边界并重放。 运行前把预期写成快照，运行后逐字段比较。并发记录同步边，地址记录位宽权限，I/O 记录缓冲区与完成事件，持久化区分提交与落盘，分布式记录丢失、重复和重排。

注入权限、容量、时序或设备故障，在“访问虚拟页面”之后的首个偏离点停止，逆序清理并验证同一输入恢复。 删除故障后以相同输入重放，确认返回值、内核对象、外部结果和清理状态一起恢复。只修正末端输出却留下线程、页、设备请求、文件引用、虚拟状态或权限污染，仍不通过。

第10版使用 Linux、Windows 10、多核、NVM、云和容器作为实例。现代版本会改变实现与性能数值，但进程状态、地址翻译、I/O 分层、持久化、虚拟化隔离和保护域仍可验证。现代对照不能覆盖2018英文原版与2023中文出版版的目录身份。
