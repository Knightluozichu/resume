## 直觉引入

把磁盘想象成一台老式黑胶唱片机。唱针（磁头）固定在臂上，需要移动到指定轨道（柱面）才能读——这就是**寻道时间**，最慢的环节。然后等唱片转到目标位置（扇区）——这是**旋转延迟**。最后读取数据——这是**传输时间**。因为寻道涉及机械移动（毫秒级），远比电子操作慢，所以调度算法的核心就是减少磁臂移动距离。**FCFS** 像随机点歌——唱针到处跑。**SCAN** 像电梯——唱针沿一个方向扫到头再折返。**C-SCAN** 像单向电梯——只在一个方向上服务，到头后快速跳回起点重新扫。而 **RAID** 把多台唱片机组合起来——RAID 0 是并行播放（快但一台坏全毁），RAID 1 是双机镜像（安全但费盘），RAID 5 是分布式校验（折中最常用）。

## 磁盘调度算法

<Term def="磁盘调度算法通过重排 I/O 请求顺序减少磁臂寻道距离，从而降低平均访问时间。核心思想是让磁臂沿一个方向扫过多个请求，而非来回跳跃。">磁盘调度</Term>的优化目标是减少寻道时间——三者中最慢且唯一可控的部分。**FCFS** 按请求到达顺序服务，简单但磁臂来回跳，寻道距离大。**SSTF**（最短寻道时间优先）选离当前磁头最近的请求，寻道短但远端请求可能饥饿。**SCAN**（电梯算法）磁臂沿一个方向扫到端点再折返，无饥饿但端点等待不均匀。**C-SCAN** 只沿一个方向服务，到端点后跳回起点重新扫，各位置等待更均匀。**LOOK/C-LOOK** 是变体——不走到端点，只到最远请求就折返，减少空跑。

```text
// 磁盘调度对比（请求队列：98, 183, 37, 122, 14, 124, 65, 67，磁头起始 53）

// FCFS: 53→98→183→37→122→14→124→65→67
//    总寻道 = 640 柱面（来回跳，最差）

// SSTF: 53→65→67→37→14→98→122→124→183
//    总寻道 = 236 柱面（贪心最近，但远端可能饥饿）

// SCAN（向 0 方向先扫）: 53→37→14→0→65→67→98→122→124→183
//    总寻道 = 236 柱面（单向扫，无饥饿）

// C-SCAN（向 199 方向扫）: 53→65→67→98→122→124→183→199→0→14→37
//    到头跳回起点，各位置等待均匀

// LOOK: SCAN 变体，不走到 0/199，只到最远请求
// C-LOOK: C-SCAN 变体，不走到端点
```

## RAID 磁盘冗余阵列

**RAID 0**（条带化）：数据分散写在多个磁盘上，无冗余。读写最快，利用率 100%，但零容错——任一盘故障全数据丢失。**RAID 1**（镜像）：数据完全复制到两块盘。容错最强，利用率 50%。**RAID 4**：块级条带 + 专用校验盘。容错 1 盘，但校验盘是写瓶颈。**RAID 5**：校验信息分散在所有盘上（无专用校验盘）。容错 1 盘，利用率 (N-1)/N，最常用。**RAID 6**：双校验，容错 2 盘，校验开销更大。**RAID 1+0**：先镜像再条带，高性能高可靠，利用率 50%。

## 常见误区

<Callout type="trap">
**误区：SSD 也需要磁盘调度算法。** 不对。SSD 没有机械运动部件（无磁臂、无旋转盘片），任何逻辑块地址的访问延迟几乎相同——所以 FCFS 和 SCAN 在 SSD 上没有区别，磁盘调度算法失去意义。SSD 面临的新挑战完全不同：①**磨损均衡**（wear leveling）——闪存块有擦写次数限制，必须均匀分布写入以延长寿命。FTL（闪存转换层）负责把逻辑地址映射到不同物理块。②**垃圾回收**——闪存不能直接覆写，必须先擦除整个块，GC 把有效数据搬到新块再擦旧块。③**写放大**——实际写入量大于逻辑写入量（GC 和磨损均衡导致）。SSD 把问题从「机械寻道优化」转向「闪存寿命管理」。
</Callout>

<Exercises>
**问题 1**：磁盘访问时间由哪三部分组成？为什么寻道时间是优化的核心目标？

<Answer>
磁盘访问时间 = 寻道时间 + 旋转延迟 + 传输时间。寻道时间：磁臂移动到目标柱面的时间（毫秒级），最慢的——涉及机械运动。旋转延迟：目标扇区转到磁头下方的时间（毫秒级），也是机械运动。传输时间：数据读写时间（微秒级）。寻道是优化核心因为：①它是三者中最慢的；②它是唯一可以通过调度算法优化的——旋转延迟和传输时间由物理位置决定无法改变，但访问顺序可以重排减少磁臂移动距离。SSD 无机械部件，调度算法意义不大，但面临磨损均衡等新课题。
</Answer>

**问题 2**：RAID 0、RAID 1 和 RAID 5 的数据分布和容错能力分别是什么？

<Answer>
RAID 0（条带化）：数据分散写在多个磁盘上，无冗余。读写最快，利用率 100%，但零容错——任一盘故障全数据丢失。适合性能优先且可重建的数据。RAID 1（镜像）：数据完全复制到两块盘。容错最强（坏一块仍可用），利用率 50%。适合关键数据。RAID 5（分布式校验）：数据和奇偶校验信息分散存在所有盘上。容错 1 盘，利用率 (N-1)/N，读写性能较好。缺点是写入需计算校验（小写惩罚），重建较慢。RAID 5 是最常见的折中方案。
</Answer>
