## 线性回归：PRML 的第一个模型

线性回归是 PRML 的入门模型，也是理解贝叶斯方法的最佳载体。本章从最简单的最小二乘出发，逐步加入先验（正则化）和后验分布，展示从频率派到贝叶斯派的完整递进。

## 线性基函数模型

最简单的线性模型直接对输入做线性组合 $y(\mathbf{x},\mathbf{w}) = w_0 + w_1 x_1 + \cdots + w_D x_D$。但真正的非线性关系需要**基函数**将输入映射到高维特征空间：

$$y(\mathbf{x}, \mathbf{w}) = \sum_{j=0}^{M-1} w_j \phi_j(\mathbf{x}) = \mathbf{w}^\top \boldsymbol{\phi}(\mathbf{x})$$

其中 $\phi_0(\mathbf{x}) = 1$（偏置项），$\phi_j(\mathbf{x})$ 是基函数。虽然模型对参数 $\mathbf{w}$ 是线性的，但通过基函数可以对输入做非线性映射。

### 常用基函数

| 基函数 | 形式 | 特点 |
|--------|------|------|
| 多项式 | $\phi_j(x) = x^j$ | 全局影响，高次项边缘振荡 |
| 高斯 | $\phi_j(x) = \exp\left(-\frac{(x-\mu_j)^2}{2s^2}\right)$ | 局部影响，紧凑 |
| Sigmoid | $\phi_j(x) = \sigma\left(\frac{x-\mu_j}{s}\right)$ | 神经网络联系 |
| 傅里叶 | $\sin/\cos$ 分量 | 周期信号 |

<Callout type="info">

**基函数的意义**：线性模型 + 非线性基函数 = 非线性回归。这是「特征工程」的数学本质——手动设计好的特征映射。神经网络的突破在于让基函数本身也可学习，无需手动设计。

</Callout>

## 第一层：最大似然线性回归（MLE）

假设目标值由模型加高斯噪声产生：$t = y(\mathbf{x},\mathbf{w}) + \epsilon$，其中 $\epsilon \sim \mathcal{N}(0, \beta^{-1})$。则似然函数为：

$$p(\mathbf{t}|\mathbf{X},\mathbf{w},\beta) = \prod_n \mathcal{N}(t_n|\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n), \beta^{-1})$$

对数似然为：

$$\ln p(\mathbf{t}|\mathbf{w},\beta) = -\frac{\beta}{2}\sum_n (t_n - \mathbf{w}^\top\boldsymbol{\phi}_n)^2 + \text{const}$$

最大化似然等价于**最小化平方误差和**（SSE）。令梯度为零得到正规方程：

$$\mathbf{w}_{ML} = (\boldsymbol{\Phi}^\top\boldsymbol{\Phi})^{-1}\boldsymbol{\Phi}^\top\mathbf{t}$$

其中 $\boldsymbol{\Phi}$ 是设计矩阵，第 $n$ 行为 $\boldsymbol{\phi}(\mathbf{x}_n)^\top$。

<Callout type="warning">

**MLE 的问题**：①过拟合——当基函数数量 $M$ 接近样本数 $N$ 时，$\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$ 接近奇异，权重爆炸。②无不确定性——MLE 只给点估计，不知道参数有多可信。③无法自动选择复杂度——需要交叉验证调 $M$。

</Callout>

## 第二层：最大后验（MAP）/ 正则化

加入高斯先验 $p(\mathbf{w}) = \mathcal{N}(\mathbf{0}, \alpha^{-1}\mathbf{I})$，MAP 估计最大化后验：

$$p(\mathbf{w}|\mathbf{t}) \propto p(\mathbf{t}|\mathbf{w})p(\mathbf{w})$$

取负对数后，等价于最小化：

$$\frac{\beta}{2}\|\mathbf{t}-\boldsymbol{\Phi}\mathbf{w}\|^2 + \frac{\alpha}{2}\|\mathbf{w}\|^2$$

这正是 **L2 正则化（岭回归）**！解析解为：

$$\mathbf{w}_{MAP} = (\boldsymbol{\Phi}^\top\boldsymbol{\Phi} + \lambda\mathbf{I})^{-1}\boldsymbol{\Phi}^\top\mathbf{t}$$

其中 $\lambda = \alpha/\beta$。正则化项 $\lambda\mathbf{I}$ 使矩阵可逆，抑制过拟合。

<Callout type="tip">

**正则化 = 先验**：L2 正则化等价于高斯先验的 MAP；L1 正则化等价于拉普拉斯先验的 MAP。这是 PRML 的核心洞察——正则化不是 ad-hoc 的工程技巧，而是贝叶斯先验的体现。

</Callout>

## 第三层：全贝叶斯回归

全贝叶斯方法不取后验的众数（MAP），而是保留完整的后验分布并做边际化预测。

### 后验分布

高斯先验 + 高斯似然 → 后验仍是高斯：

$$p(\mathbf{w}|\mathbf{t}) = \mathcal{N}(\mathbf{w}|\mathbf{m}_N, \mathbf{S}_N)$$

$$\mathbf{m}_N = \beta\mathbf{S}_N\boldsymbol{\Phi}^\top\mathbf{t}, \quad \mathbf{S}_N^{-1} = \alpha\mathbf{I} + \beta\boldsymbol{\Phi}^\top\boldsymbol{\Phi}$$

后验均值 $\mathbf{m}_N$ 就是 MAP 估计，但后验还给出了协方差 $\mathbf{S}_N$（参数不确定性）。

### 预测分布

对新输入 $\mathbf{x}_*$，预测分布为：

$$p(t_*|\mathbf{x}_*,\mathbf{t}) = \int p(t_*|\mathbf{x}_*,\mathbf{w})p(\mathbf{w}|\mathbf{t})d\mathbf{w} = \mathcal{N}(t_*|\mathbf{m}_N^\top\boldsymbol{\phi}_*, \sigma_N^2(\mathbf{x}_*))$$

预测均值 = $\mathbf{m}_N^\top\boldsymbol{\phi}_*$（与 MAP 相同），预测方差：

$$\sigma_N^2(\mathbf{x}_*) = \frac{1}{\beta} + \boldsymbol{\phi}_*^\top\mathbf{S}_N\boldsymbol{\phi}_*$$

<Callout type="info">

**预测方差的两个部分**：$\frac{1}{\beta}$ 是观测噪声（数据固有的不可约噪声），$\boldsymbol{\phi}_*^\top\mathbf{S}_N\boldsymbol{\phi}_*$ 是参数不确定性（模型对参数不确信带来的额外方差）。数据多的区域参数不确定性小，方差低；数据少的区域不确定性大，方差高。

</Callout>

## 证据近似：自动调超参

超参数 $\alpha$（先验精度）和 $\beta$（噪声精度）可用**证据框架**自动学习：最大化边际似然（证据）$p(\mathbf{t}|\alpha,\beta)$。证据近似自动平衡拟合与正则化，无需交叉验证。

## 偏差-方差分解

期望损失可分解为：$\text{期望损失} = \text{偏差}^2 + \text{方差} + \text{噪声}$

- **偏差**：模型平均预测与真值的偏离（欠拟合）
- **方差**：不同训练集预测的波动（过拟合）
- **噪声**：数据固有不可约误差

<Callout type="warning">

**贝叶斯 vs 频率的偏差-方差**：频率派通过控制模型复杂度在偏差和方差间权衡。贝叶斯方法通过边际化自动实现这种权衡——先验约束等效于降低方差，后验平均等效于模型平均。

</Callout>

<Glossary>

<GlossaryItem term="基函数（Basis Function）">
将原始输入 x 映射到特征空间的非线性函数 φ_j(x)。线性模型 y=wᵀφ(x) 对参数 w 线性，但通过基函数可拟合非线性关系。常用基函数包括多项式（全局）、高斯（局部）、sigmoid（神经网络联系）。基函数的选择是「特征工程」的数学本质。神经网络的突破在于让基函数本身也可学习（φ 的参数也参与训练），从而自动学习特征映射。PRML 的核方法（ch5）通过核技巧隐式地使用无限维基函数。
</GlossaryItem>

<GlossaryItem term="贝叶斯线性回归（Bayesian Linear Regression）">
对线性回归施加贝叶斯处理的完整方法。高斯先验 p(w)=N(0,α⁻¹I) + 高斯似然 → 高斯后验 p(w|t)=N(m_N, S_N)，m_N=βS_NΦᵀt，S_N⁻¹=αI+βΦᵀΦ。后验均值即 MAP 估计，后验协方差 S_N 量化参数不确定性。预测分布 p(t*|x*,t)=∫p(t*|x*,w)p(w|t)dw=N(m_Nᵀφ*, σ_N²(x*))，预测方差=1/β(噪声)+φ*ᵀS_Nφ*(参数不确定性)。全贝叶斯的核心优势：①输出预测置信区间；②数据少时自动增大不确定性；③通过证据框架自动调超参 α,β，无需交叉验证。
</GlossaryItem>

<GlossaryItem term="证据框架（Evidence Framework / Empirical Bayes）">
自动学习超参数的方法。在贝叶斯线性回归中，先验精度 α 和噪声精度 β 是超参数。证据框架最大化边际似然（证据）p(t|α,β)=∫p(t|w,β)p(w|α)dw，即对所有可能的参数做积分后的数据概率。证据自动平衡拟合与正则化——太简单的模型证据低（偏差大），太复杂的模型证据也低（边际化惩罚高复杂度），最优 α,β 在中间。证据框架又称二型最大似然（Type II MLE），是经验贝叶斯的一种。高斯过程的超参学习也用同一方法。
</GlossaryItem>

<GlossaryItem term="偏差-方差分解（Bias-Variance Decomposition）">
频率派分析泛化误差的工具。期望损失 = 偏差² + 方差 + 噪声。偏差是模型平均预测与真值的偏离（欠拟合，模型太简单），方差是不同训练集预测的波动（过拟合，模型太复杂），噪声是数据固有不可约误差。增大模型复杂度→偏差降低但方差升高（过拟合）；降低复杂度→方差降低但偏差升高（欠拟合）。贝叶斯方法通过先验约束（等效降方差）和后验边际化（等效模型平均）自动在偏差和方差间权衡，无需手动调复杂度。
</GlossaryItem>

<GlossaryItem term="L2 正则化的贝叶斯解释">
L2 正则化（权重衰减/岭回归）在损失函数中加入 λ‖w‖²，等价于高斯先验 N(0,α⁻¹I) 的 MAP 估计（λ=α/β）。贝叶斯视角揭示了正则化的本质——不是工程补丁，而是先验知识的注入：高斯先验表达「权重应该小」的信念。L1 正则化等价于拉普拉斯先验，产生稀疏解。全贝叶斯进一步指出：不仅 MAP 估计有正则化效果，后验分布本身通过边际化预测也实现了隐式正则化（模型平均）。正则化强度 λ 由证据框架自动确定，无需交叉验证。
</GlossaryItem>

<GlossaryItem term="设计矩阵（Design Matrix）">
将 N 个样本的 M 个基函数值排列成 N×M 矩阵 Φ，第 n 行第 j 列为 φ_j(x_n)。正规方程 w=(ΦᵀΦ)⁻¹Φᵀt 的核心。当 M 接近 N 时 ΦᵀΦ 接近奇异（不可逆），导致过拟合和数值不稳定。正则化加入 λI 使矩阵可逆（岭回归）。对偶表示将 ΦᵀΦ(M×M) 替换为 ΦΦᵀ(N×N)，当 M>>N 时对偶更高效，这是核方法的基础（ch5）。
</GlossaryItem>

</Glossary>

### 问题 1

为什么最大似然线性回归会过拟合？贝叶斯方法如何解决这个问题？

<Answer>

MLE 过拟合的原因：①无先验约束——MLE 只最大化似然 p(D|w)，当基函数数量 M 接近样本数 N 时，模型有足够自由度完美拟合每个数据点（包括噪声），导致 ΦᵀΦ 接近奇异、权重爆炸。②点估计——MLE 输出单一参数值，不量化参数不确定性，无法判断哪些权重是「真实信号」哪些是「噪声拟合」。③复杂度不可控——M 的选择需要交叉验证，无自动机制。贝叶斯方法的解决：①先验正则化——高斯先验 p(w)=N(0,α⁻¹I) 约束权重大小，等效于 L2 正则化，使 ΦᵀΦ+λI 可逆，抑制过拟合。正则化强度 λ=α/β 由证据框架自动学习。②后验分布——保留完整后验 p(w|t)=N(m_N,S_N) 而非点估计，S_N 量化参数不确定性。③边际化预测——预测分布 p(t*|x*,t)=∫p(t*|x*,w)p(w|t)dw 积分掉参数不确定性，实现模型平均，自动平衡偏差与方差。④证据框架——最大化边际似然 p(t|α,β) 自动选择最优正则化强度，无需交叉验证。
</Answer>

### 问题 2

全贝叶斯回归的预测方差由哪两部分组成？各自代表什么含义？

<Answer>

预测方差 σ_N²(x*) = 1/β + φ*ᵀS_Nφ* 由两部分组成：①1/β 是观测噪声（数据固有不可约不确定性），β 是噪声精度。这部分方差对所有输入相同，代表数据本身的随机性，无法通过增加数据或改进模型消除。②φ*ᵀS_Nφ* 是参数不确定性，S_N 是后验协方差矩阵。这部分方差随输入 x* 变化——在训练数据密集的区域，后验对参数更确信（S_N 小），方差低；在训练数据稀疏的区域，后验不确定（S_N 大），方差高。随训练数据增加，后验逐渐集中（S_N→0），参数不确定性趋于零，预测方差收敛到 1/β（仅剩噪声）。全贝叶斯预测方差的价值：量化预测置信度——数据丰富处预测可信（方差小），数据稀疏处自动增大不确定性，这对安全关键应用（医疗、自动驾驶）至关重要，而 MLE/MAP 只能给点预测无此信息。
</Answer>

### 问题 3

为什么说 L2 正则化等价于高斯先验？这个等价关系有何意义？

<Answer>

等价性推导：L2 正则化的目标函数为 min (β/2)‖t-Φw‖² + (α/2)‖w‖²。取负对数后验：-ln p(w|t) = -ln p(t|w) - ln p(w) + const = (β/2)‖t-Φw‖² + (α/2)‖w‖² + const。其中似然 p(t|w)=∏N(t_n|wᵀφ_n, β⁻¹) 产生 (β/2)‖t-Φw‖² 项，先验 p(w)=N(0,α⁻¹I) 产生 (α/2)‖w‖² 项。因此 L2 正则化 = 高斯先验的 MAP 估计，正则化系数 λ=α/β。这个等价关系的意义：①理论统一——正则化不是 ad-hoc 的工程技巧，而是贝叶斯先验的体现。所有正则化都可用先验解释：L1=拉普拉斯先验（产生稀疏）、L2=高斯先验（权重衰减）、早停=限制先验范围。②自动调参——正则化强度 λ 由证据框架自动学习（最大化边际似然），无需交叉验证。③不确定性量化——贝叶斯不仅给出 MAP（=正则化解），还给出后验协方差 S_N 量化参数不确定性。④模型比较——贝叶斯证据 p(t|α,β) 可用于自动选择基函数数量 M，无需交叉验证。这个等价关系是 PRML 的核心洞察之一。
</Answer>

### 问题 4

证据框架如何自动确定正则化超参数？它的贝叶斯本质是什么？

<Answer>

证据框架（Empirical Bayes / Type II MLE）最大化边际似然 p(t|α,β)=∫p(t|w,β)p(w|α)dw，即对所有可能的参数 w 做积分后的数据概率。由于高斯先验+高斯似然，这个积分有解析解，可以关于 α,β 求导得到迭代更新公式。证据自动平衡拟合与正则化：①太简单模型（α 大）→ 先验太强→偏差大→证据低；②太复杂模型（α 小）→ 先验太弱→方差大→边际化后证据也低（高复杂度被证据惩罚）；③最优 α,β 在中间。贝叶斯本质：证据框架是分层贝叶斯的近似——完整贝叶斯应对超参 α,β 也加先验 p(α,β) 做全积分 p(t)=∫∫p(t|w,β)p(w|α)p(α,β)dwdαdβ。但这个双重积分无解析解，证据框架用 α,β 的点估计（众数）近似——即最大化 p(t|α,β)。这是一种「经验贝叶斯」：用数据估计超参而非指定固定值。优势：无需交叉验证（证据自动选模型复杂度），适用于超参数多的场景（如高斯过程的核参数学习）。局限：点估计近似忽略了超参本身的不确定性。
</Answer>
