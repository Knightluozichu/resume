## 稀疏核机：SVM 的最大间隔

核方法（ch5）中高斯过程的预测依赖所有训练样本，计算开销大。支持向量机（SVM）通过最大间隔原则实现**稀疏性**——预测只依赖少量「支持向量」，大幅提升推理效率。

<PrlSparseKernelsDiagram />

## 最大间隔分类器

SVM 的核心思想：不仅要求正确分类，还要求决策边界两侧留有最大的「间隔」（margin），使分类对噪声最鲁棒。

### 间隔的几何意义

决策边界 $\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}) + b = 0$ 到最近样本的距离为 $1/\|\mathbf{w}\|$，间隔宽度为 $2/\|\mathbf{w}\|$。最大化间隔等价于最小化 $\frac{1}{2}\|\mathbf{w}\|^2$。

### 优化问题

$$\min_{\mathbf{w},b} \frac{1}{2}\|\mathbf{w}\|^2 \quad \text{s.t.} \quad t_n(\mathbf{w}^\top\boldsymbol{\phi}(\mathbf{x}_n) + b) \geq 1, \quad n=1,\ldots,N$$

其中 $t_n \in \{+1, -1\}$ 是类别标签。约束要求所有样本正确分类且在间隔边界之外。

<Callout type="info">

**最大间隔的贝叶斯解释**：最小化 $\|\mathbf{w}\|^2$ 等价于高斯先验的 MAP，间隔最大化可视为一种正则化。但 SVM 不输出概率，只输出判别值——这是它与逻辑回归、GP 的区别。

</Callout>

## 拉格朗日对偶与支持向量

引入拉格朗日乘子 $a_n \geq 0$，对偶问题为：

$$\max_{\mathbf{a}} \sum_n a_n - \frac{1}{2}\sum_n\sum_m a_n a_m t_n t_m k(\mathbf{x}_n, \mathbf{x}_m)$$

约束：$a_n \geq 0$，$\sum_n a_n t_n = 0$

### 支持向量

KKT 条件给出 $a_n[t_n(\mathbf{w}^\top\boldsymbol{\phi}_n + b) - 1] = 0$：

- $a_n > 0$ 的样本恰好在间隔边界上 → **支持向量**
- $a_n = 0$ 的样本在间隔外 → 对决策边界无影响

预测函数只依赖支持向量：

$$y(\mathbf{x}) = \sum_{n \in SV} a_n t_n k(\mathbf{x}_n, \mathbf{x}) + b$$

<Callout type="tip">

**稀疏性的价值**：大量非支持向量的 $a_n = 0$ 可丢弃，预测只计算支持向量的核函数。这使得 SVM 在推理时比 GP（依赖所有样本）高效得多。

</Callout>

## 软间隔 SVM

真实数据通常线性不可分（或噪声导致个别样本越界）。软间隔引入**松弛变量** $\xi_n \geq 0$ 允许少量违反：

$$\min \frac{1}{2}\|\mathbf{w}\|^2 + C\sum_n \xi_n \quad \text{s.t.} \quad t_n(\mathbf{w}^\top\boldsymbol{\phi}_n + b) \geq 1 - \xi_n$$

参数 $C$ 控制间隔宽度与违反量的权衡：

| C 值 | 间隔 | 违反容忍 | 效果 |
|------|------|---------|------|
| 大 | 窄 | 严格 | 可能过拟合 |
| 小 | 宽 | 宽松 | 可能欠拟合 |

对偶形式与硬间隔相同，只是 $a_n$ 的约束变为 $0 \leq a_n \leq C$。$a_n = C$ 的样本是越界点（间隔内或错分），$0 < a_n < C$ 的样本在间隔边界上。

## 核 SVM

将核技巧（ch5）应用于 SVM，在（无限维）特征空间中找最大间隔决策边界。常用核包括高斯核（RBF）和多项式核。核 SVM 可拟合高度非线性的决策边界。

<Callout type="warning">

**核选择**：高斯核的 $\sigma$ 和软间隔的 $C$ 是关键超参，通常用交叉验证选择。$\sigma$ 太小 → 过拟合（每个样本自成一簇）；$\sigma$ 太大 → 欠拟合（退化为线性）。

</Callout>

## 支持向量回归（SVR）

SVM 的回归版本使用 $\epsilon$ **不敏感损失**：当预测值与真实值之差小于 $\epsilon$ 时损失为零，只有超出 $\epsilon$ 带的样本才产生损失。

$$L_\epsilon(t, y(\mathbf{x})) = \max(0, |t - y(\mathbf{x})| - \epsilon)$$

间隔带内的样本损失为零 → 不成为支持向量 → 预测稀疏。只有间隔带外的样本才成为支持向量。

## SVM 与其他方法的对比

| 维度 | SVM | 逻辑回归 | 高斯过程 |
|------|-----|---------|---------|
| 优化目标 | 最大间隔 | 最大似然 | 贝叶斯后验 |
| 概率输出 | 无（需后处理） | 有 | 有 |
| 稀疏性 | 有（支持向量） | 无 | 无 |
| 不确定度 | 无 | 有 | 有（方差） |
| 核化 | 自然 | 需改造 | 自然 |

<Glossary>

<GlossaryItem term="支持向量机（SVM）">
基于最大间隔原则的分类器。核心思想：不仅正确分类，还要求决策边界两侧留最大间隔，使分类对噪声最鲁棒。优化目标 min ½‖w‖² s.t. t_n(wᵀφ(x_n)+b)≥1。拉格朗日对偶将问题转化为核函数形式，a_n>0 的样本（恰在间隔边界上）= 支持向量，其余样本 a_n=0 可丢弃 → 稀疏性。软间隔引入松弛变量 ξ_n 允许少量违反，参数 C 控制间隔与违反的权衡。核 SVM 用核技巧在无限维空间找最大间隔，可拟合高度非线性边界。SVM 的优势：稀疏高效、最大间隔泛化好、核化自然。劣势：不输出概率（需 Platt 缩放后处理）、不量化不确定度、超参 C 和核参数需交叉验证。SVM 是结构风险最小化（SRM）的典范。
</GlossaryItem>

<GlossaryItem term="支持向量（Support Vector）">
SVM 中拉格朗日乘子 a_n>0 的训练样本，恰好落在间隔边界上（硬间隔）或间隔内/错分（软间隔 a_n=C）。KKT 条件保证非支持向量的 a_n=0，对决策边界无影响。预测 y(x)=Σ_{n∈SV} a_n t_n k(x_n,x)+b 只计算支持向量的核函数 → 稀疏性。支持向量的数量通常远小于总样本数，使 SVM 推理高效。支持向量的几何含义：它们是「最难分」的样本（离决策边界最近），决定了间隔的位置和宽度。移除非支持向量不影响模型——这是 SVM 与 GP（依赖所有样本）的关键区别。支持向量数量可作为模型复杂度的指标（越多越复杂）。
</GlossaryItem>

<GlossaryItem term="最大间隔（Maximum Margin）">
SVM 的核心原则。决策边界到最近样本的距离为 1/‖w‖，间隔宽度 2/‖w‖。最大化间隔 ≡ 最小化 ½‖w‖²。间隔大的决策边界对噪声和样本扰动更鲁棒（泛化好），因为分类边界离样本远。最大间隔的统计学基础是结构风险最小化（SRM）——VC 维与间隔成反比，大间隔 → 低 VC 维 → 低泛化误差上界。最大间隔的贝叶斯解释：min ½‖w‖² 等价于高斯先验的 MAP，间隔最大化是一种正则化。但 SVM 不输出概率，与贝叶斯方法的概率推断不同。最大间隔原则也可推广到回归（ε 不敏感损失的间隔带）。
</GlossaryItem>

<GlossaryItem term="软间隔（Soft Margin）">
允许少量样本违反间隔约束的 SVM 变体。引入松弛变量 ξ_n≥0，约束变为 t_n(wᵀφ(x_n)+b)≥1-ξ_n。优化目标 min ½‖w‖²+CΣξ_n，参数 C 控制间隔宽度与违反量的权衡。C 大→严格（接近硬间隔，可能过拟合）；C 小→宽松（容忍更多违反，可能欠拟合）。对偶形式中 a_n 的约束变为 0≤a_n≤C：a_n=C 的样本越界（间隔内或错分），0<a_n<C 的样本在间隔边界上，a_n=0 的样本在间隔外。软间隔使 SVM 能处理线性不可分数据和噪声，是实际应用的标准形式。C 通常用交叉验证选择。
</GlossaryItem>

<GlossaryItem term="ε 不敏感损失（ε-Insensitive Loss）">
支持向量回归（SVR）的损失函数。L_ε(t,y)=max(0,|t-y|-ε)：预测值与真实值之差小于 ε 时损失为零，只有超出 ε 带的样本产生损失。效果：间隔带内的样本不成为支持向量 → 预测稀疏。只有超出 ε 带的样本才成为支持向量。ε 控制间隔带宽度：ε 大→容忍大误差→支持向量少→模型简单；ε 小→严格→支持向量多→模型复杂。ε 与 C 一起通过交叉验证选择。ε 不敏感损失使 SVR 比 GP 回归更稀疏高效（GP 依赖所有样本）。ε 不敏感损失的统计性质：对应一种鲁棒回归——对带内误差不惩罚，对超出带的误差线性惩罚（比平方误差更鲁棒）。
</GlossaryItem>

<GlossaryItem term="结构风险最小化（SRM）">
SVM 的统计学习理论基础。泛化误差上界 = 经验风险 + 置信区间（与 VC 维相关）。VC 维与间隔成反比——大间隔 → 低 VC 维 → 低置信区间 → 低泛化误差上界。SVM 通过最大化间隔同时控制经验风险（分类正确）和置信区间（VC 维低），直接最小化泛化误差上界，而非仅最小化训练误差。这是 SVM 泛化能力强的理论依据。与贝叶斯方法对比：贝叶斯通过边际化（模型平均）控制复杂度，SVM 通过最大间隔（VC 维控制）控制复杂度，两者殊途同归。SRM 是 Vapnik 的统计学习理论核心，适用于样本量有限但模型复杂度可调的场景。
</GlossaryItem>

</Glossary>

### 问题 1

SVM 的最大间隔原则是什么？为什么大间隔能带来更好的泛化？

<Answer>

最大间隔原则：SVM 不仅要求正确分类，还要求决策边界两侧留最大间隔。决策边界 wᵀφ(x)+b=0 到最近样本的距离为 1/‖w‖，间隔宽度 2/‖w‖。最大化间隔 ≡ 最小化 ½‖w‖²。约束 t_n(wᵀφ(x_n)+b)≥1 保证所有样本在间隔边界之外且正确分类。大间隔带来更好泛化的原因：①几何鲁棒性——大间隔意味着决策边界离样本远，样本的微小扰动（噪声）不会跨越边界导致误分。②统计学习理论——泛化误差上界 = 经验风险 + 置信区间。置信区间与 VC 维相关，VC 维与间隔成反比（大间隔→低 VC 维→低置信区间→低泛化误差上界）。SVM 通过最大间隔直接最小化泛化误差上界（结构风险最小化 SRM），而非仅最小化训练误差。③贝叶斯解释——min ½‖w‖² 等价于高斯先验的 MAP，间隔最大化是一种正则化，抑制过拟合。对比：逻辑回归只最大化似然（最小化训练误差），无显式间隔约束；SVM 的最大间隔提供了额外的泛化保证，在中小样本场景尤为有效。
</Answer>

### 问题 2

什么是支持向量？SVM 的稀疏性从何而来？它与高斯过程有何区别？

<Answer>

支持向量是 SVM 中拉格朗日乘子 a_n>0 的训练样本，恰好落在间隔边界上（硬间隔）或间隔内/错分（软间隔 a_n=C）。KKT 条件 a_n[t_n(wᵀφ(x_n)+b)-1]=0 保证：间隔外的样本满足 t_n(wᵀφ(x_n)+b)>1，故 a_n=0，对决策边界无影响。稀疏性从何而来：优化问题的 KKT 条件使大量样本的 a_n=0，只有少数「最难分」的样本（离边界最近）a_n>0 成为支持向量。预测 y(x)=Σ_{n∈SV}a_n t_n k(x_n,x)+b 只计算支持向量的核函数，非支持向量可丢弃。与高斯过程的区别：①稀疏性——SVM 预测只依赖支持向量（少数），GP 预测依赖所有训练样本（无稀疏性），SVM 推理更高效。②概率输出——SVM 不输出概率（需 Platt 缩放后处理），GP 输出完整预测分布（均值+方差）。③优化目标——SVM 最大化间隔（结构风险最小化），GP 最大化边际似然（贝叶斯证据）。④不确定度——SVM 无不确定度量化，GP 预测方差量化置信度。⑤理论——SVM 基于 VC 维/SRM，GP 基于贝叶斯推断。两者都是核方法但哲学不同：SVM 是频率派稀疏方法，GP 是贝叶斯概率方法。
</Answer>

### 问题 3

软间隔 SVM 如何处理线性不可分数据？参数 C 的作用是什么？

<Answer>

软间隔 SVM 引入松弛变量 ξ_n≥0 允许少量样本违反间隔约束：约束变为 t_n(wᵀφ(x_n)+b)≥1-ξ_n。ξ_n=0 表示样本在间隔外（严格满足）；0<ξ_n<1 表示样本在间隔内但分类正确；ξ_n>1 表示样本被错分。优化目标 min ½‖w‖²+CΣξ_n，CΣξ_n 惩罚总违反量。参数 C 的作用：控制间隔宽度与违反量的权衡。①C 大→惩罚重→严格（接近硬间隔）→间隔窄、违反少→可能过拟合（为避免违反而弯曲边界）。②C 小→惩罚轻→宽松→间隔宽、违反多→可能欠拟合（容忍大量越界）。对偶形式中 a_n 的约束变为 0≤a_n≤C：a_n=C 的样本越界（ξ_n>0），0<a_n<C 的样本在间隔边界上（ξ_n=0），a_n=0 的样本在间隔外。C 的选择：通常用交叉验证。C 与核参数（如高斯核 σ）共同决定模型复杂度——大 C + 小 σ → 过拟合，小 C + 大 σ → 欠拟合。软间隔使 SVM 能处理：①线性不可分数据（通过容忍违反避免硬间隔的无解）；②噪声数据（少量标签错误不会主导模型）。核 SVM + 软间隔是实际应用的标准配置。
</Answer>

### 问题 4

SVM 与逻辑回归、高斯过程分别有什么异同？在什么场景下选择 SVM？

<Answer>

SVM vs 逻辑回归：相同——都是线性分类器（可用核/基函数扩展到非线性）；都输出决策边界。不同——①优化目标：SVM 最大化间隔（min ½‖w‖²），逻辑回归最大化似然（min 交叉熵）。②损失函数：SVM 用 hinge loss max(0,1-ty)，逻辑回归用交叉熵 -ln σ(ty)。③概率输出：SVM 不输出概率（需后处理），逻辑回归直接输出概率。④稀疏性：SVM 有（支持向量），逻辑回归无。⑤鲁棒性：hinge loss 只关注间隔内的样本（间隔外损失为零），交叉熵关注所有样本，SVM 对远端噪声更鲁棒。SVM vs 高斯过程：相同——都是核方法。不同——①概率：SVM 非概率，GP 完全概率（预测分布）。②稀疏：SVM 稀疏（支持向量），GP 非稀疏。③不确定度：SVM 无，GP 有（方差）。④优化：SVM 凸二次规划（全局最优），GP 边际似然优化（非凸但实践中可行）。选择 SVM 的场景：①中小样本、高维特征——SVM 的最大间隔在小样本时泛化好（SRM 理论保证）。②需要稀疏高效推理——支持向量少，预测快。③不需要概率输出——只需分类标签。④非线性分类——核 SVM 简洁有效。不选 SVM 的场景：①需要概率/不确定度→选 GP 或逻辑回归。②大数据（N>10万）→SVM 二次规划 O(N²-N³) 太慢，选深度学习或线性 SVM。③多分类——SVM 原生二分类，需 OvO/OvR 扩展。
</Answer>
