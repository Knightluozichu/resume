## 直觉引入

想象一面墙和一面镜子。墙把光均匀散射到四面八方（漫反射），镜子把光精确反射到特定方向（镜面反射）。同样是一束光打上来，为什么效果完全不同？因为它们的 BRDF（双向反射分布函数）不同。

BRDF 就是材料反射特性的「身份证」——它告诉你「从方向 A 射入的光，会从方向 B 反射多少」。PBRT 用 BxDF 统称所有双向散射函数（反射+透射+次表面）。

## 代码对照

```cpp
// Cook-Torrance BRDF
Spectrum CookTorrance(Vector3f wi, Vector3f wo, Vector3f n) {
    Vector3f h = Normalize(wi + wo);
    
    // D: 法线分布函数 (GGX/Trowbridge-Reitz)
    float D = GGX_D(h, n, alpha);
    
    // G: 几何遮蔽/阴影 (Smith)
    float G = Smith_G(wi, wo, n, alpha);
    
    // F: 菲涅尔 (Schlick近似)
    Spectrum F = SchlickFresnel(dot(wi, h), F0);
    
    // 组合
    return D * G * F / (4 * dot(n,wi) * dot(n,wo));
}
```

## 常见误区

<Callout type="trap">
**误区：认为 BRDF 可以是任意函数。**
物理正确的 BRDF 必须满足两条约束：1）互易性 f(ωi,ωo)=f(ωo,ωi)；2）能量守恒——对所有出射方向积分不超过1。Phong 模型违反能量守恒，不是物理正确的 BRDF。
</Callout>

<Callout type="trap">
**误区：不理解微表面粗糙度参数的物理含义。**
粗糙度 α 不是「表面有多粗糙」的直接度量，而是微表面法线分布的宽度。α=0 是完美镜面，α=1 是极粗糙。它控制高光的大小和锐度——α 越小高光越锐利越小，α 越大高光越弥散越暗。
</Callout>

<Exercises>
**问题 1**：BRDF 的两条物理约束是什么？为什么它们重要？

<Answer>
1）互易性：f(ωi,ωo) = f(ωo,ωi)，交换入射和出射方向结果相同。这来自光路可逆性。2）能量守恒：对所有出射方向的反射能量积分不超过入射能量。这两条约束确保 BRDF 描述的是物理可能的材料，而非任意数学函数。违反能量守恒会导致渲染偏亮，违反互易性会导致双向路径追踪等算法失效。
</Answer>

**问题 2**：Cook-Torrance 模型的 D、G、F 三项分别建模什么物理现象？

<Answer>
D（法线分布函数）：建模微表面法线与半角向量对齐的概率，决定高光的形状和大小。G（几何遮蔽/阴影）：建模微表面之间的相互遮挡，一个微面可能被另一个挡住（遮蔽）或投射阴影（阴影），在掠射角时效果显著。F（菲涅尔项）：建模光在介质界面的反射率随入射角变化，决定高光颜色和强度。三者乘积除以归一化因子 4(n·wi)(n·wo) 得到物理正确的 BRDF。
</Answer>
</Exercises>
