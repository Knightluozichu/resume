## 直觉：不是“随机猜”，而是设计平均值

要估算一个形状不规则的湖面面积，可以在包围它的矩形里随机撒点。落入湖中的比例乘以矩形面积，就是一次面积估计。这个方法的关键并不是“点够多就行”，而是每个点都来自已知分布，并且它对最终平均值的贡献经过正确加权。

PBRT 面对的积分比湖面面积难得多：一个像素可能同时依赖镜头位置、时间、光源、表面方向、波长和多次反弹。规则网格的样本数会随维度指数增长，而蒙特卡洛估计的收敛阶不依赖维数，因此它适合高维光传输。代价是结果带有方差，也就是渲染图里的噪声。

## 1. 先把概率语言说准确

<Term def="由随机过程产生的值；大写 X 表示变量本身，小写 x 表示一次具体取值">随机变量</Term>可以是离散的灯光编号，也可以是连续的镜头位置或半球方向。离散事件用概率质量函数描述，连续变量用<Term def="描述连续随机变量在各位置相对出现可能性的函数；它在整个定义域上的积分必须为 1">概率密度函数（PDF）</Term>描述。PDF 在某一点的值不是概率，只有对一个区间积分后才得到概率。

设随机变量 $X$ 的密度是 $p(x)$，函数 $g$ 在这个分布下的<Term def="把每个可能结果按其出现概率加权后得到的长期平均值">期望</Term>为：

$$
\mathbb{E}_p[g(X)] = \int_{\Omega} g(x)\,p(x)\,\mathrm{d}x.
$$

这个式子在说：如果反复从 $p$ 采样并计算 $g(X)$，样本平均会趋近右侧积分。后面所有无偏性证明，都只是把目标积分改写成某个随机变量的期望。

PDF 必须满足两个底线：$p(x)\ge 0$，并且 $\int_\Omega p(x)\,\mathrm{d}x=1$。为了估计 $f$ 的积分，还要求在 $f(x)\ne 0$ 的地方不能有 $p(x)=0$，否则那块贡献永远采不到。

## 2. 从期望推导蒙特卡洛估计量

目标是计算 $I=\int_\Omega f(x)\,\mathrm{d}x$。在积分里乘除同一个 PDF：

$$
I = \int_\Omega \frac{f(x)}{p(x)}p(x)\,\mathrm{d}x
  = \mathbb{E}_p\!\left[\frac{f(X)}{p(X)}\right].
$$

这个式子在说：一次样本的贡献不是单独的 $f(X)$，而是 $f(X)/p(X)$。稀有样本一旦出现，必须获得更大的权重；常见样本则获得较小权重。

对 $N$ 个独立样本取平均，得到<Term def="用有限个随机样本近似积分的随机变量；它的期望应等于目标积分">蒙特卡洛估计量</Term>：

$$
\widehat I_N = \frac{1}{N}\sum_{i=1}^{N}\frac{f(X_i)}{p(X_i)},
\qquad X_i\sim p.
$$

这个式子在说：每个样本先按 PDF 校正，再把全部贡献平均。均匀采样只是特例；若区间为 $[a,b]$，则 $p=1/(b-a)$，估计量自然变成 $(b-a)\sum f(X_i)/N$。

利用期望的线性性，可逐步证明无偏：

$$
\mathbb{E}[\widehat I_N]
= \frac{1}{N}\sum_{i=1}^{N}
  \int_\Omega \frac{f(x)}{p(x)}p(x)\,\mathrm{d}x
= \frac{1}{N}\sum_{i=1}^{N}I
= I.
$$

这个式子在说：一次样本的平均贡献已经等于真实积分，重复 $N$ 次再平均不会改变期望。<Term def="估计量的期望等于真实目标值；它不保证单次结果准确，只保证长期平均不系统偏高或偏低">无偏估计</Term>描述的是长期平均，不是“每一帧都正确”。

```cpp
Spectrum EstimateIntegral(const Function &f, const Distribution &dist, int n) {
    Spectrum sum(0.f);
    for (int i = 0; i < n; ++i) {
        Sample sample = dist.sample();
        if (sample.pdf == 0.f) continue;
        sum += f(sample.x) / sample.pdf;
    }
    return sum / n;
}
```

代码中的 `pdf == 0` 不是普通容错：如果此时 `f(x)` 可能非零，直接跳过会造成偏差。调用者必须保证采样分布覆盖被积函数的非零区域。

## 3. 误差、方差与“4 倍样本减半噪声”

<Term def="随机估计围绕其期望波动的平方尺度；渲染中它表现为像素噪声">方差</Term>定义为 $\mathbb{V}[Y]=\mathbb{E}[(Y-\mathbb{E}[Y])^2]$。当样本独立且同分布时，平均值的方差为：

$$
\mathbb{V}[\widehat I_N]
= \frac{1}{N}\mathbb{V}\!\left[\frac{f(X)}{p(X)}\right]
= \frac{\sigma^2}{N}.
$$

这个式子在说：样本数翻 4 倍，方差变为四分之一；但人眼感受到的噪声幅度更接近标准差，所以只变为原来的一半。

$$
\operatorname{StdErr}(\widehat I_N)=\frac{\sigma}{\sqrt{N}}.
$$

这个式子在说：若想把噪声幅度缩小到十分之一，通常需要约 100 倍样本。单纯堆样本很贵，渲染器更应该降低单样本贡献的方差 $\sigma^2$。

<PbtConvergenceDiagram />

无偏不等于一定更好。有偏估计量可能以很小的偏差换来更低方差。比较算法时应看均方误差 $\mathrm{MSE}=\mathrm{Variance}+\mathrm{Bias}^2$，还要把运行时间算进去；更慢但方差只略低的估计器，实际效率可能更差。

## 4. 分层采样：先阻止样本扎堆

<Term def="把积分域分成互不重叠的小区域，并在每个区域内采样，以减少遗漏和扎堆">分层采样</Term>不需要知道函数形状。以一个像素为例，把像素区域划成 $k\times k$ 网格，每格抖动一个样本，比在整块像素里独立撒 $k^2$ 个点更稳定。

分层估计是各层估计的加权和。只要分层完整覆盖原域并保持正确权重，它仍然无偏。它减少的是“不同层均值差异”带来的额外方差；但在高维空间做完全分层需要指数级样本，因此实践中只对强相关维度分组分层。

```cpp
for (int y = 0; y < strataY; ++y) {
    for (int x = 0; x < strataX; ++x) {
        Point2f u((x + rng.uniform()) / strataX,
                  (y + rng.uniform()) / strataY);
        accumulate(traceCameraSample(pixel, u));
    }
}
```

## 5. 重要性采样：把预算投向高贡献区域

<Term def="选择与被积函数幅度相似的 PDF，让高贡献区域获得更多样本，从而降低方差">重要性采样</Term>改变的是样本落点，不改变 $f/p$ 的加权规则。估计量方差可写为：

$$
\mathbb{V}[\widehat I_N]
= \frac{1}{N}\left(
  \int_\Omega \frac{f(x)^2}{p(x)}\,\mathrm{d}x-I^2
  \right).
$$

这个式子在说：当 $|f|$ 大而 $p$ 很小时，$f/p$ 会形成极亮离群样本，噪声暴涨。若 $f$ 非负且能够令 $p(x)\propto f(x)$，则 $f/p$ 接近常数，理论方差趋近 0。现实中无法预知完整被积函数，只能匹配其中一个已知因子，例如用余弦分布匹配漫反射 BRDF 的余弦项。

## 6. MIS：不知道哪种 PDF 更好时，让它们互相兜底

光传输被积函数常是“入射辐亮度 × BSDF × 余弦项”的乘积。按光源采样能找到小而亮的灯，按 BSDF 采样能找到尖锐反射方向，但没有一种 PDF 在所有材质和场景中都占优。

<Term def="组合多个采样策略，并按各策略在样本位置的概率密度分配权重，以抑制 PDF 失配造成的离群值">多重重要性采样（MIS）</Term>从多个分布取样，再让更适合当前样本的策略获得更大权重。权重必须满足 $\sum_i w_i(x)=1$ 才能保持无偏。常用的幂启发式为：

$$
w_i(x)=\frac{(n_i p_i(x))^\beta}
{\sum_j(n_j p_j(x))^\beta},\qquad \beta=2.
$$

这个式子在说：某策略在该点给出的 PDF 越高，它越像是“知道这里重要”，权重就越大；平方会进一步压低不合适策略的贡献。

```cpp
float PowerHeuristic(int nf, float pdfF, int ng, float pdfG) {
    float f = nf * pdfF;
    float g = ng * pdfG;
    return (f * f) / (f * f + g * g);
}
```

## 7. 逆 CDF 与分布变换：从均匀随机数制造目标样本

<Term def="先计算目标分布的累积分布函数，再用它的反函数把 [0,1) 均匀样本映射为目标分布样本">逆变换采样</Term>是 PBRT 反复使用的基础工具。若 $\xi\sim U[0,1)$，目标 CDF 为 $P(x)$，则 $X=P^{-1}(\xi)$ 服从目标 PDF。

离散情况下，把每个事件概率累加成 CDF，找到满足 $P_{i-1}\le \xi<P_i$ 的区间即可选中事件。连续情况下，若变换 $y=T(x)$ 一一对应，则密度要乘逆雅可比：

$$
p_Y(y)=p_X(x)\left|\frac{\mathrm{d}T(x)}{\mathrm{d}x}\right|^{-1}.
$$

这个式子在说：变换把一小段输入拉宽时，单位输出区间里的样本会变稀，PDF 必须相应降低。二维及更高维时，用雅可比行列式描述面积或体积的缩放；半球、球面和三角形采样都依赖这条规则。

## 8. 俄罗斯轮盘赌：省掉昂贵工作而不截断能量

<Term def="以存活概率 q 决定是否继续低贡献路径；存活路径除以 q 补偿被终止的样本">俄罗斯轮盘赌</Term>解决的是成本，不是方差本身。设原贡献为 $L$，路径以概率 $q$ 存活：

$$
L'=
\begin{cases}
L/q, & \text{概率 }q,\\
0, & \text{概率 }1-q.
\end{cases}
\quad\Longrightarrow\quad
\mathbb{E}[L']=q\frac{L}{q}+(1-q)0=L.
$$

这个式子在说：多数低贡献路径被提前终止，少数存活路径承担更大权重，长期平均仍保持原能量。$q$ 太小会制造高权重离群样本；太大又节省不了时间，因此通常根据路径吞吐量设置下限和上限。

## 10. 容易踩的坑

<Callout type="trap">
**现象 →** 样本均值偶尔出现极亮白点。**原因 →** 高贡献区域的 PDF 太小，导致 `f/p` 权重爆炸。**修法 →** 检查 PDF 是否覆盖并匹配被积函数，组合光源与 BSDF 采样时使用 MIS。
</Callout>

<Callout type="trap">
**现象 →** 俄罗斯轮盘赌开启后画面整体变暗。**原因 →** 路径存活后没有除以存活概率 $q$。**修法 →** 同时实现随机终止和权重补偿，并用一个可解析场景比较开关前后的长期均值。
</Callout>

<Callout type="trap">
**现象 →** 把采样数从 64 提到 128，画面几乎没有变干净。**原因 →** 标准误差按 $1/\sqrt N$ 而不是 $1/N$ 下降。**修法 →** 优先寻找方差来源，改进分层、PDF 或 MIS，再考虑增加样本。
</Callout>

## 小结

- 目标积分可改写为 $f(X)/p(X)$ 的期望
- 无偏保证长期平均正确，方差决定噪声大小
- 分层防扎堆，重要性采样把预算投向高贡献区域
- MIS 组合互补 PDF，俄罗斯轮盘赌控制路径成本
- 逆 CDF 与雅可比把均匀样本变成目标分布样本

<Exercises>
**问题 1**：从期望定义推导 $\widehat I_N=\frac1N\sum f(X_i)/p(X_i)$ 的无偏性。PDF 需要满足什么覆盖条件？

<Answer>
把每项的期望写成积分：$\mathbb E[f(X_i)/p(X_i)]=\int f(x)/p(x)\,p(x)\,dx=I$，再利用期望的线性性得到 $N$ 项平均的期望仍为 $I$。必须在所有 $f(x)\ne0$ 的位置满足 $p(x)>0$，否则缺失区域永远不会被采到，估计会产生系统偏差。
</Answer>

**问题 2**：独立估计器在 64 spp 时标准误差为 0.08。若不改变采样策略，要降到 0.02 需要多少 spp？

<Answer>
标准误差与 $1/\sqrt N$ 成正比。误差缩小到四分之一，样本数需要扩大 $4^2=16$ 倍，因此需要 $64\times16=1024$ spp。这说明只堆样本的代价很高。
</Answer>

**问题 3**：为“很小但很亮的面光源照亮粗糙金属”设计采样策略。只按光源采样或只按 BSDF 采样各会漏掉什么？

<Answer>
光源采样容易命中小光源，但在粗糙金属的高响应方向之外可能得到很低 BSDF；BSDF 采样能覆盖材质高响应方向，却很难命中小光源。应分别从光源 PDF 和 BSDF PDF 取样，再用 MIS 幂启发式按两种 PDF 加权，以避免任一策略失配时出现高方差。
</Answer>

**问题 4**：实现一个离散灯光采样器：输入未归一化功率数组和 $\xi\in[0,1)$，返回灯光索引及其 PMF；再验证十万次采样频率是否接近目标分布。

<Answer>
先求功率总和并构造累计权重；把 $\xi$ 乘总和，在累计数组中查找第一个大于该值的位置。返回的 PMF 是该灯功率除以总功率。测试时统计每个索引的频率，并与 PMF 比较；误差应随样本数增加按约 $1/\sqrt N$ 缩小。
</Answer>
</Exercises>
