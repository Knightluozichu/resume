## 直觉引入

想象你站在阳光下。你的皮肤感受到的「热」就是 irradiance——单位面积接收的光功率。但如果你拿一个放大镜聚焦阳光，聚焦点更亮——因为 radiance（单位面积单位立体角的光功率）被集中了。

辐射度量学就是给这些「光的感受」赋予精确的物理量和单位。它是 PBRT 的数学语言——所有公式都用这些量来表达。

## 概念讲解

### 四大辐射量

<PbtRadiometryDiagram />

<Term def="辐射通量（Flux）是单位时间内通过某表面的辐射能量，单位瓦特(W)">辐射通量</Term>是最基本的辐射量，表示光源发出的总功率。

<Term def="辐照度（Irradiance）是单位面积上接收的辐射通量，单位 W/m²">辐照度</Term>描述表面接收的光能密度，等于 flux 除以面积。

<Term def="辐亮度（Radiance）是单位面积单位立体角的辐射通量，单位 W/(m²·sr)">辐亮度</Term>是最核心的量，描述光在特定方向上的能量密度。

<Term def="辐射强度（Intensity）是点光源在单位立体角内的辐射通量，单位 W/sr">辐射强度</Term>描述光源的方向性分布。

## 代码对照

```cpp
// PBRT 中的辐射量定义
// Flux: 总功率
Float Flux = power;  // Watts

// Irradiance: 单位面积通量
Float Irradiance = Flux / area;  // W/m²

// Radiance: 单位面积单位立体角通量
Float Radiance = dFlux / (dA * dCosTheta * dOmega);  // W/(m²·sr)

// 关键关系: Irradiance = ∫ Radiance * cosθ dω
Float irradiance = 0;
for (auto &wi : samples) {
    irradiance += radiance(wi) * abs(dot(n, wi)) * pdf(wi);
}
```

## 常见误区

<Callout type="trap">
**误区：混淆 irradiance 和 radiance。**
Irradiance 是所有方向射入单位面积的总功率（W/m²），Radiance 是特定方向上单位面积单位立体角的功率（W/(m²·sr)）。Irradiance 是 Radiance 对半球面的积分。相机接收的是 Radiance，不是 Irradiance。
</Callout>

<Callout type="trap">
**误区：不理解 radiance 守恒的意义。**
Radiance 在真空中沿光线守恒意味着：从物体到相机的路径上不需要计算衰减。这一性质使得渲染器只需计算交点处的 radiance，而非追踪路径上每一点的能量变化。
</Callout>

<Exercises>
**问题 1**：Radiance 的单位是什么？为什么说它是辐射度量学中最核心的量？

<Answer>
Radiance 的单位是 W/(m²·sr)（瓦每平方米每球面度）。它最核心是因为：1）它在真空中沿光线守恒，使渲染只需计算交点处的值；2）相机传感器直接测量 radiance；3）光传输方程的积分对象就是 radiance；4）BxDF 的输入输出都是 radiance。其他量都可以从 radiance 积分得到。
</Answer>

**问题 2**：写出 irradiance 与 radiance 的关系式，并解释物理含义。

<Answer>
Irradiance E = 真实积分号 L(p,ω) · cosθ · dω，对半球面积分。物理含义：单位面积接收的总功率等于所有方向射入的 radiance 乘以余弦因子（投影面积）的积分。cosθ 项来自 Lambert 余弦定律——斜射光的能量在面积上被「摊薄」了。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="辐射通量(Flux)">单位时间内通过某表面的辐射能量，单位瓦特(W)，是最基本的辐射量。</GlossaryItem>
<GlossaryItem term="辐照度(Irradiance)">单位面积上接收的辐射通量，单位 W/m²，是 radiance 对半球的积分。</GlossaryItem>
<GlossaryItem term="辐亮度(Radiance)">单位面积单位立体角的辐射通量，单位 W/(m²·sr)，在真空中沿光线守恒。</GlossaryItem>
<GlossaryItem term="立体角(Solid Angle)">三维空间中从一点出发的锥面所张的角度，单位球面度(sr)，整个球面为 4π sr。</GlossaryItem>
