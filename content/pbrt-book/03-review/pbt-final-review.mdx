## 为什么总复习必须从“背名词”变成“核对不变量”

把 radiance、BxDF、MIS、BVH 和 wavefront 各背一遍，并不能证明渲染器正确。真正的总复习应该回答：一个像素样本如何变成 ray，ray 如何得到稳健交点，每次散射为何按某个 PDF 加权，路径贡献如何进入 Film，以及每个数值能否追溯到明确的单位、坐标系与算法状态。

把全书从知识清单变成诊断工具。例如 radiance 沿真空直线保持不变；BSDF 采样后，函数值、余弦项与 PDF 必须在同一测度下更新路径吞吐；新 ray 的原点必须位于已知交点误差区域之外。

## 1. 十六章脊柱：每一层都在交付契约

PBRT 第 4 版的[正式目录](https://www.pbr-book.org/4ed/contents)包含 16 个主体章节。第 1–4 章定义系统、蒙特卡洛估计、几何与变换、辐射度量和光谱颜色；第 5–8 章把样本变成 ray，令 ray 稳健地穿过 Shape、Primitive、BVH，再进入采样与图像重建；第 9–12 章描述表面、纹理材质、介质和光源；第 13–16 章求解全局光传输、转向 GPU wavefront，并用回顾检查设计选择的历史条件。

第 1 章还解释了 PBRT 的方法。代码出现的顺序服务于概念依赖，而非最终文件布局；因此复习实现时要同时核对书中叙事位置和生成后的源码位置，不能把“原文在何处解释”与“编译器从何处读取”混为一谈。

<PbtBookSpineDiagram />

这条脊柱有严格依赖。要求：

1. 几何层必须明确点、向量、法线和 ray 处于哪个空间，不能让 material 猜坐标系。
2. 散射层必须同时提供函数值与可抽样分布，不能只给一个看起来合理的高光公式。
3. 积分器必须知道每次随机选择的概率与测度，不能在立体角 PDF 和面积 PDF 之间直接相加。
4. Film 必须知道样本对应的像素位置、滤波权重、波长和相机权重，不能只接收最终 RGB。

因此，PBRT 的[建议阅读方式](https://www.pbr-book.org/4ed/Introduction/How_to_Proceed_through_This_Book)不是把所有实现细节一次记完，而是先建立主链，再沿感兴趣的模块下钻。总复习反过来做：从最终像素倒查主链中每个状态是否有来源。

## 2. 像素到账本：先追踪一条路径的贡献

经 Camera 生成 ray。若相机返回权重 $w_c$，一条路径最终估计的光谱 radiance 为 $\widehat L$，其进入 Film 的样本贡献可写成

$$
C = w_c\,\widehat L.
$$

Film 还会按重建滤波器 $r$ 把相邻样本分配到像素。像素 $p$ 的归一化结果是

$$
\widehat I(p)=
\frac{\sum_i r(p-p_i)\,C_i}
{\sum_i r(p-p_i)}.
$$

对积分 $I=\int_\Omega f(x)\,dx$，从密度 $p(x)$ 抽取 $N$ 个样本的为

$$
\widehat I_N=\frac{1}{N}\sum_{i=1}^{N}\frac{f(X_i)}{p(X_i)},
\qquad X_i\sim p.
$$

蒙特卡洛并非所有积分的“唯一可行方法”：简单场景可能有解析解，也可使用确定性求积等数值方法。PBRT 广泛采用它，是因为一般光传输积分高维、有遮挡、含非光滑项，随机估计能统一处理这些结构并给出可分析的收敛行为。

<PbtPathLedgerDiagram />

通常记作 $\beta$。对连续的表面散射，若第 $j$ 次采样得到 $f_j$、方向余弦和立体角 PDF $p_j$，则

$$
\beta_k=w_c\prod_{j=1}^{k}
\frac{f_j\,|\cos\theta_j|}{p_j}.
$$

这不是“能量越乘越小”的经验式，而是路径空间估计量的权重。任何一次更新若漏掉余弦、重复除 PDF，或混合了不同测度，都会让整条路径失去可解释性。

## 3. 几何、变换与 BVH：先证明命中可信

写成

$$
\mathbf p(t)=\mathbf o+t\mathbf d,
\qquad 0<t<t_{\max}.
$$

Point、Vector、Normal 的变换规则不同，尤其非均匀缩放下 normal 要用逆转置矩阵。交点返回的不只是 $t$：还包括位置、几何和着色法线、纹理坐标、位置微分、介质边界与。后续散射依赖这些状态，不能把求交视为一个布尔函数。

是传输与几何的结合点；则只改变查询成本，不改变几何语义。ray 可能同时穿过两个子包围盒，包围盒重叠严重时会访问大量节点，所以 BVH 的最坏复杂度仍可达 $O(N)$，不能无条件写成 $O(\log N)$。

面积转换是跨模块常见断点。若从光源表面面积密度 $p_A(y)$ 转成立体角密度，几何关系给出

$$
p_\omega(y)=p_A(y)\frac{\|x-y\|^2}{|\mathbf n_y\cdot(-\omega_i)|}.
$$

若这一转换与遮挡、法线方向或两点坐标系不一致，MIS 权重即使公式正确也会偏。

## 4. Shapes：紧凑表示与数值稳健性是一条链

第 6 章 [Shapes](https://www.pbr-book.org/4ed/Shapes/Triangle_Meshes) 不能被“BVH 会求交”替代。一个不为每个面复制三个顶点；PBRT 的 `Triangle` 只保存 `meshIndex` 与 `triIndex`，实际位置和属性来自共享 mesh。顶点位置预先变换到 rendering space，避免为每条 ray 重复变换整套数据。

<PbtShapeRobustnessDiagram />

稳健三角形求交必须避免相邻面在共享边上给出互相矛盾的 inside/outside 结果。PBRT 的 watertight 方法计算一致的边函数，仅在需要时用更高精度回退。命中点由重心权重 $b_i$ 插值得到：

$$
\mathbf p=b_0\mathbf p_0+b_1\mathbf p_1+b_2\mathbf p_2,
\qquad b_0+b_1+b_2=1.
$$

浮点结果还要传播。官方[误差管理](https://www.pbr-book.org/4ed/Shapes/Managing_Rounding_Error)给三角形交点构造保守上界；可概括为

$$
\mathbf p_{\mathrm{error}}
=\gamma(7)\sum_{i=0}^{2}|b_i\mathbf p_i|,
\qquad
\gamma(n)=\frac{n\epsilon}{1-n\epsilon}.
$$

`OffsetRayOrigin` 根据误差盒、几何法线和新 ray 方向，把起点移动到误差区域之外。固定 `rayEpsilon` 过小会自相交，过大又会穿过薄几何；它无法适应坐标尺度和计算路径，因此不是可靠修复。

## 5. Radiometry、光谱、相机与 Film：单位不能在接口处消失

 $L$ 连接相机、光源、表面和介质。表面点 $x$ 的出射辐亮度满足

$$
L_o(x,\omega_o)=L_e(x,\omega_o)+
\int_{\mathcal H^2}
f_s(x,\omega_i,\omega_o)L_i(x,\omega_i)
|\cos\theta_i|\,d\omega_i.
$$

这里 $f_s$ 的单位、立体角积分和余弦投影必须配套。光谱渲染还要求采样的波长集合贯穿 Camera、Light、BxDF、Medium 与 Film，最后才通过颜色匹配函数和输出色彩空间变成 RGB。过早把光谱压成三通道，会丢失色散和窄带光源等效应。

Camera 不只是“从像素发 ray”：投影模型、镜头孔径、焦平面、快门时间和传感器响应共同定义测量过程。Film 不只是数组：它接收连续 film position，执行滤波、累积和归一化，再做光谱到颜色以及输出编码。总复习时应记录 `pixel`, `pFilm`, `pLens`, `time`, `lambda`, `cameraWeight`，才能区分几何错、曝光错与滤波错。

## 6. BxDF、纹理、材质与光源：局部模型必须可评估也可采样

回答给定入射与出射方向的散射强度。物理模型至少检查非负性、能量守恒和互易性适用条件：

$$
\int_{\mathcal H^2} f_s(\omega_i,\omega_o)
|\cos\theta_o|\,d\omega_o\le 1.
$$

Texture 产生随位置变化的参数，Material 组合纹理并创建 BSDF/BSSRDF。纹理值的颜色语义、法线贴图所在空间和粗糙度参数化必须明确；否则局部公式本身正确，输入仍可能错误。Texture 的同样属于材料正确性：应依据纹理坐标微分选择滤波范围，而不是只在最终图像上模糊结果。

Light 同时要实现发射评估和与其匹配的采样/PDF。点光源、面光源、环境光和方向光的测度不同。直接照明连接两个顶点时常见
$$
G(x,y)=
\frac{|\mathbf n_x\cdot\omega_{xy}|
|\mathbf n_y\cdot\omega_{yx}|}
{\|x-y\|^2}.
$$

Delta light 或 specular BxDF 不具有普通有限立体角密度；代码必须通过类型标记和专门分支处理，不能把它们硬塞进连续 PDF 公式。

## 7. 表面与体积光传输：贡献、可见性和概率必须一起乘

路径追踪在每个顶点累积发光和 next-event estimation，再采样 BSDF 延伸路径。对某次直接光连接，可把贡献结构写成

$$
\Delta L=\beta\,f_s\,L_e\,G\,V\,w_{\mathrm{MIS}},
$$

其中 $V$ 是可见性，$w_{\mathrm{MIS}}$ 是组合光源采样与 BSDF 采样的权重。PBRT 常用的幂启发式为

$$
w_a(x)=\frac{(n_a p_a(x))^2}
{(n_a p_a(x))^2+(n_b p_b(x))^2}.
$$

参与介质中，沿长度 $d$ 的均匀段透射率为

$$
T_r(d)=e^{-\sigma_t d},
\qquad \sigma_t=\sigma_a+\sigma_s.
$$

介质路径还要采样自由飞行距离、区分真实/零碰撞并评估 phase function。表面法线余弦不能照搬到体积顶点，介质 PDF 也不能漏出 $\beta$ 账本。只比较最终图像很难发现这类成对错误；固定随机种子后输出每个 bounce 的 `beta`, `Tr`, `pdf`, `L`, `depth` 更有效。

第 14 章还用展示同一传输思想如何作用于微观层间路径。它不是简单相加两个 BRDF；层内方向、透射、反射、PDF 与终止策略仍要构成一个正确的局部随机估计。

固定 `maxDepth` 会截断长路径并引入偏差。只有在存活分支正确重加权时才保持无偏；它降低平均成本，但可能增加方差。

## 8. Integrator、Sampler 与系统架构：同一方程可以有不同执行形状

Integrator 决定如何枚举或采样路径；Sampler 为每个像素样本提供可复现的随机维度；Scene 解析与对象创建决定资源所有权；Aggregate 提供求交；Film 汇总结果。路径追踪、双向路径追踪、MLT 和 wavefront path tracing 不是“质量等级”，而是不同路径生成分布和执行架构。

CPU 逐路径实现让一个 worker 连续完成一条 path，局部状态容易留在 cache；通常采用，让大量同类工作一起运行，减少执行组分支发散，但增加 path state 的队列读写。选择架构要报告硬件、场景、spp、路径长度、队列占用、内存流量与 kernel 时间，而不是只说“GPU 更快”。

一个可审计的路径循环应显式携带状态：

```cpp
struct PathState {
    RayDifferential ray;
    SampledSpectrum beta = 1;
    SampledSpectrum L = 0;
    SampledWavelengths lambda;
    bool specularBounce = false;
    int depth = 0;
};

while (state.depth < maxDepth) {
    auto hit = Intersect(state.ray);              // tHit, interaction, pError
    if (!hit) {
        state.L += state.beta * InfiniteLe(state.ray, state.lambda);
        break;
    }

    state.L += EmittedRadiance(*hit, -state.ray.d, state.lambda);
    state.L += state.beta * SampleDirect(*hit, sampler, state.lambda);

    auto s = hit->bsdf.Sample_f(-state.ray.d, sampler.Get2D());
    if (!s || s->pdf == 0) break;
    state.beta *= s->f * AbsDot(s->wi, hit->shading.n) / s->pdf;
    state.ray = hit->SpawnRay(s->wi);             // uses pError
    state.specularBounce = s->IsSpecular();
    ++state.depth;

    if (ShouldTerminate(state.beta, sampler.Get1D())) break;
}

film.AddSample(pixel, state.L, cameraWeight);
```

这段伪代码省略了介质、MIS 的 delta 分支、波长终止补偿和微分传播，但保留了审计边界。所谓“物理正确”必须同时满足：模型与目标物理过程匹配，估计量及 PDF 配对正确，数值与实现不破坏这些约束。仅仅使用 path tracing 并不能自动保证正确。

## 9. 回顾与未来：默认算法也是历史选择

第 16 章[回顾与未来](https://pbr-book.org/4ed/Retrospective_and_the_Future)比较各版变化、硬件对架构与性能的影响，以及可替代的设计。路径追踪从早期版本就存在，但直到第 3 版才成为默认积分器；这说明默认值服务于当时的教学覆盖、硬件能力和典型场景，并非永恒结论。

<PbtRetrospectiveDiagram />

必须带条件比较。例如逐路径与 wavefront、面向对象接口与 tagged pointer、递归树与线性 BVH，都要在吞吐、内存、可读性、设备限制和扩展成本之间权衡。脱离硬件和负载谈“最佳架构”没有可证伪性。

未来方向之一是。同一像素变化可能由纹理、形状、光照、镜面反射或阴影解释，因此单图重建具有歧义。未来系统需要把可微估计、多视角观测、先验和不确定性联合起来；前向渲染器中清晰的参数、测度与状态边界，正是构建可靠逆问题的基础。

## 小结

PBRT 的完整能力不在某个积分器，而在可组合的契约：辐射度量与光谱定义传输量；Camera 和 Film 定义测量；Shape、Primitive 与 BVH提供稳健几何；BxDF、Material、Medium 与 Light 定义局部相互作用；Sampler 与 Integrator 把光传输写成可估计路径；CPU 与 GPU 架构让同一物理语义适配不同硬件。总复习的通过标准，是能沿任意路径解释每个状态、物理因子、概率和误差边界。
