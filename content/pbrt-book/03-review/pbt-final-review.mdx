## 直觉引入

想象一条光线从相机出发，穿过镜头、进入场景、打到一个表面、被反射到另一个表面、最终命中光源。这条光线的旅程，就是 PBRT 全书的缩影——相机模型生成它，BVH 找到交点，BxDF 决定反射方向，蒙特卡洛采样选择路径，光传输方程计算贡献，系统架构保证一切高效运行。

总复习就是把这条光线的旅程完整走一遍，把每一步对应的知识点串联起来。

## 代码对照

```cpp
// PBRT 全书核心：一条光线的完整旅程
Spectrum Li(Ray ray, Scene &scene, Sampler &sampler, int depth) {
    // 1. 系统架构：BVH 加速求交
    SurfaceInteraction si;
    if (!scene.bvh.Intersect(ray, &si))
        return scene.environmentLe(ray);  // 环境光
    
    // 2. 辐射度量学：自发光
    Spectrum L = si.Le;
    
    // 3. BxDF + 蒙特卡洛：直接光照(MIS)
    for (auto &light : scene.lights)
        L += EstimateDirect(si, light, scene, sampler);  // MIS
    
    // 4. 光传输方程：间接光照(递归)
    if (depth < maxDepth) {
        auto [wi, f, pdf] = si.bsdf->Sample_f(ray.d, sampler);
        Spectrum Li_indirect = Li(Ray(si.p, wi), scene, sampler, depth+1);
        L += f * Li_indirect * abs(dot(si.n, wi)) / pdf;
    }
    
    return L;  // radiance —— 辐射度量学的核心量
}
```

## 常见误区

<Callout type="trap">
**误区：孤立学习各章而不串联。**
PBRT 的五大板块不是独立章节，而是一条链：辐射度量学是词汇，BxDF 是语法，光传输方程是句子，蒙特卡洛是翻译方法，系统架构是印刷机。不串联就只看到碎片，看不到全貌。
</Callout>

<Callout type="trap">
**误区：重理论轻实践。**
PBRT 的每章都有 C++ 实现。只读公式不跑代码，会错过工程细节（如浮点精度、内存布局、并行同步）对渲染结果的影响。建议编译运行 pbrt-v4，修改参数观察效果。
</Callout>

<Exercises>
**问题 1**：用一条光线的旅程串联全书五大板块。

<Answer>
1）相机模型：从像素生成光线（薄透镜、景深）。2）系统架构：BVH 加速求交，找到光线与场景的交点。3）BxDF：在交点查询材料的反射特性（Cook-Torrance DGF）。4）光传输方程：计算该点的出射 radiance = 自发光 + 直接光照 + 间接光照。5）蒙特卡洛：用随机采样（重要性采样、MIS、俄罗斯轮盘赌）求解光传输方程的积分。每个像素重复多次取平均，得到最终图像。
</Answer>

**问题 2**：PBRT 如何实现「物理正确」与「工程可行」的平衡？

<Answer>
物理正确性体现在：用辐射度量学定义光的能量，用光传输方程描述光的传播，用物理测量的 BxDF 数据描述材料，用无偏的蒙特卡洛方法求解。工程可行性体现在：用 BVH 把求交从 O(N) 降到 O(logN)，用瓦片化并行充分利用多核，用重要性采样和 MIS 在有限采样数下降低方差，用俄罗斯轮盘赌控制递归深度。两者平衡的关键是蒙特卡洛——它既保证无偏（物理正确），又支持自适应采样（工程可控）。
</Answer>
