## 核心概念

### 全书定位

《企业应用架构模式》（Patterns of Enterprise Application Architecture, PoEAA）是 Martin Fowler 撰写的经典企业应用架构指南。不同于一般的设计模式书，它关注的是**如何组织企业应用的内部结构**——从分层架构到领域逻辑，从数据源到 Web 表现，从并发到分布式，为企业应用提供了一套完整的模式语言。

### 核心脉络

全书的核心理念可以浓缩为一条脉络线：

**分层架构 → 领域逻辑 → 数据源 → Web 表现 → 分布式 → 知识闭环**

这四个阶段不是孤立的模块，而是一个**递进循环**：基础架构是骨架，数据源是落地，Web 表现是交互，分布式是扩展，知识闭环是整合。

### 学习建议

1. **顺序学习**：按章节顺序学习，每一章都建立在前一章的基础上
2. **模式导向**：每学完一个模式，尝试在实际项目中识别和应用
3. **分层理解**：将每个模式归入其所属的架构层，理解它在整体中的角色
4. **定期回顾**：学完全书后回到本章，检验对全景图的理解是否加深

## 术语表

| 术语 | 释义 |
|------|------|
| 企业应用 | 处理大量数据、复杂业务逻辑、多用户并发的信息系统 |
| 分层架构 | 将系统分为表现层、领域层、数据源层的架构风格 |
| 领域逻辑 | 系统中与业务规则相关的核心逻辑 |
| 数据源 | 负责持久化和外部系统交互的架构层 |
| 事务脚本 | 以过程为单位组织领域逻辑的简单模式 |
| 领域模型 | 以对象为单位承载行为和数据的模式 |
| 数据映射器 | 独立映射器负责对象与数据库的转换 |
| 远程外观 | 将细粒度操作聚合为粗粒度远程调用的模式 |
| DTO | 在远程调用间传输数据的纯数据容器 |
| 工作单元 | 维护对象变更列表并统一提交的模式 |
