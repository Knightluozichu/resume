## 为什么 第3章 映射到关系数据库 值得单独学习

系统处理对象身份、关系、加载、更新、继承、元数据和连接生命周期的阻抗失配。 第3章 映射到关系数据库 的核心不是套用某个框架 API，而是回答：如何在对象身份、关联、继承和写回之间保住一致语义，同时控制查询与映射成本。在 订单聚合持久化 中，如果无法说清责任、状态和失败由谁承担，即使正常请求能够返回，架构决定也没有完成。

本页以 2024 年中文版公开目录限定 **第3章 映射到关系数据库** 的范围，并依据 Martin Fowler 的作者图书页和模式目录独立重写。它不复现原书正文、插图或代码；目录只决定“要讲什么”，这里的案例、实验、判断题和答案均为本课程原创。

## 先建立直觉：问题、机制与代价

第3章 映射到关系数据库 面对的具体压力是“同一身份实例数、查询次数、脏对象集合与关联装载范围”。它采用的机制可以概括为：系统处理对象身份、关系、加载、更新、继承、元数据和连接生命周期的阻抗失配。 机制带来的收益必须与新增间接层、同步责任或迁移成本同时记录，否则学习者只会得到一个没有拒绝条件的模式名称。

对 第3章 映射到关系数据库，优先比较的替代路线是：根据领域复杂度选择入口、活动记录、映射器、工作单元及结构映射组合。本页的通过条件是“能解释映射到关系数据库的边界与选择轴，逐项覆盖9个目录节点，并在同一应用切片中验证”；若实验只能显示结果而不能指出 身份 从何处越界，就不能据此选择 第3章 映射到关系数据库。

## 专属设计案例：订单聚合持久化

把 订单聚合持久化 切成“对象图 → 身份关系 → 读取 → 变更跟踪 → 写回”五个观察点。第3章 映射到关系数据库 的设计草案必须写出谁拥有状态、谁作出业务决定、失败怎样传播，以及 身份、工作单元、关系映射、继承映射、连接边界 中哪个指标最先提示当前方案不再适用。

设计记录采用五个可换行字段：单元键为 **poeaa24-chapter-03-relational-mapping**；模式族为 **mapping**；裁决是“能解释映射到关系数据库的边界与选择轴，逐项覆盖9个目录节点，并在同一应用切片中验证”；观测项包括 身份、工作单元、关系映射、继承映射、连接边界；拒绝条件是“身份 超过团队为 第3章 映射到关系数据库 设定的边界”。

配置不是生产框架语法，而是一张评审卡。对 第3章 映射到关系数据库 的任何实现都要能把运行证据重新映射到这张卡；如果更换 ORM、Web 框架或部署平台后无法回答同一组问题，说明决定依赖的是工具偶然行为而不是模式语义。

## 阻抗失配解剖

对象模型和关系模型之间存在根本性的结构差异。理解这些差异是选择映射策略的前提：

## 选择与拒绝矩阵

| 评审问题 | 选择 第3章 映射到关系数据库 的证据 | 应拒绝或改用其他方案的信号                      |
| -------- | ---------------------------------- | ----------------------------------------------- |
| 责任     | 对象图 到 写回 的所有者清晰        | 身份关系 可以绕过边界直接改写状态               |
| 变化     | 身份 的变化被局部吸收              | 一次小改动同时触及 工作单元、关系映射、继承映射 |
| 失败     | 故障能在 写回 前被识别并回退       | 只能看到最终错误，无法定位 身份 的首个异常      |
| 替代     | 已与同族候选比较并保留撤回路径     | 因框架内置或团队习惯而跳过问题分析              |

<Callout
  type="trap"
  title="误区：把数据库行和内存对象的身份生命周期视为天然相同"
>
  对 第3章 映射到关系数据库，这种做法会让 身份
  的真实所有者消失。修复方式是回到“对象图 → 身份关系 → 读取 → 变更跟踪 →
  写回”逐点标出读取、决策、写入和错误翻译。
</Callout>

<Callout type="trap" title="误区：用一次正常查询掩盖 N+1、重复实例或部分写回">
  第3章 映射到关系数据库 必须接受临界与故障输入；只展示成功路径会掩盖 工作单元
  的代价，也无法证明方案可以复位或撤回。
</Callout>

## 本章小结

掌握 第3章 映射到关系数据库 的标志不是记住定义，而是能在 订单聚合持久化 中解释“对象图 → 身份关系 → 读取 → 变更跟踪 → 写回”的责任链，利用 身份、工作单元、关系映射、继承映射、连接边界 作出可证伪的选择，并在出现“把数据库行和内存对象的身份生命周期视为天然相同”时明确拒绝当前实现。

1. 为 第3章 映射到关系数据库 写一条最小设计合同：哪一个输入变化必须引起哪一个可观察结果？
