## 核心概念

### 全书定位

《程序员修炼之道：通向务实的最高境界》是 Andy Hunt 和 Dave Thomas 合著的软件工程经典。不同于一般的编程技术书，它关注的是**如何成为一个务实的程序员**——不仅仅是写代码，而是从心智、方法、工具、实践到团队协作的全方位修炼。

### 核心脉络

全书的核心理念可以浓缩为一条脉络线：

**务实心智 → 日常实践 → 高级技艺 → 代码工艺 → 知识闭环**

这五个阶段不是孤立的模块，而是一个**递进循环**：务实心智是基础，日常实践是落地，高级技艺是进阶，代码工艺是精进，知识闭环是整合与升华。

### 学习建议

1. **顺序学习**：按章节顺序学习，每一章都建立在前一章的基础上
2. **实践导向**：每学完一个概念，尝试在实际项目中应用
3. **知识组合**：将本书视为知识组合的一部分，与其他技术书互补
4. **定期回顾**：学完全书后回到本章，检验对全景图的理解是否加深

## 术语表

| 术语 | 释义 |
|------|------|
| 务实程序员 | 注重结果、持续学习、有效沟通的程序员 |
| 知识组合 | 程序员的知识资产，需要像投资组合一样管理 |
| DRY 原则 | Don't Repeat Yourself，不要重复自己 |
| 正交性 | 消除不相关事物间的影响 |
| 曳光弹 | 用最小代码打通全链路验证架构 |
| 软件熵 | 软件系统随时间趋向无序的自然倾向 |
| 破窗理论 | 未修复的坏代码会传递质量不重要的信号 |
| 德米特法则 | 一个对象只与直接朋友交谈 |
| 无情测试 | 全面、持续、自动化的测试策略 |
| 持续集成 | 频繁合并、自动构建测试的开发实践 |
