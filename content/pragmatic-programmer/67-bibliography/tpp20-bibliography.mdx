- 能区分来源支持的事实、作者综合的推断与本项目需要重新验证的实践

## 参考文献

本页依据 David Thomas、Andrew Hunt《程序员修炼之道：通向务实的最高境界（第2版·20周年版）》，云风译，电子工业出版社，2020 年 4 月，ISBN 9787121384356 的公开中文目录，独立重构 **参考文献**。正文、代码、图示、实验和练习都是本课程重新设计的教学材料，不复制原书正文、插图或答案。

参考文献不是把链接堆在页面末尾，而是回答一个可复核的问题：某个主张由什么来源支持，来源覆盖到哪里，哪些部分只是作者综合，迁移到当前项目后还缺什么验证。目录、出版信息和官方页面能确定范围，却不能自动证明每个工程结论在今天仍然成立。

## 三个会让引用链失真的陷阱

<Callout type="trap" title="把有链接误当成有证据">

- **现象**：页面有多个 URL，却没有引用坐标、版本、段落或证据类型，复核者无法知道链接支持哪句话。
- **原因**：来源被当作装饰，主张和证据之间没有明确映射。
- **修法**：为每个核心主张记录来源类型、精确坐标、支持范围和不支持范围；打不开或无法定位时暂停结论。

</Callout>

<Callout type="trap" title="把目录摘要写成原书正文">

- **现象**：独立重写把公开目录中的标题扩展成看似逐字复述的断言，读者误以为课程掌握了原书全部论证。
- **原因**：没有区分目录事实、作者综合和当前项目的实验结果。
- **修法**：在 Attribution 中声明来源边界，把教学模型标为 independent rewrite；原书正文无法核对时不制造引文或页码。

</Callout>

<Callout type="trap" title="忽略时间和环境边界">

- **现象**：2020 年版本中的工具、组织假设和案例被直接套到云服务、AI 辅助开发或受监管系统。
- **原因**：只核对标题，没有记录版本、团队约束、数据敏感性和反馈窗口。
- **修法**：先冻结适用边界，再做当前复核；若环境改变，缩小结论或重新运行实验。

</Callout>

## 五个词把引用变成证据链

`<Term def="记录主张对应的书目、章节、标题、版本或公开页面位置，使另一个人能回到同一处。">引用坐标</Term>`不是笼统的“见参考资料”，而是能让复核者重新定位的坐标。坐标不完整时，来源只能算线索。

`<Term def="直接描述对象、版本和观察结果的材料，而不是对材料的再次概括。">原始证据</Term>`可以是官方规范、实验记录、版本页面或可重放的日志。它必须说明观察到了什么，也说明没有观察到什么。

`<Term def="证据可以支持的时间、环境、对象、团队和风险范围；范围外的应用需要重新验证。">适用边界</Term>`防止一条历史经验被包装成普遍定律。边界应该包括版本、输入、责任人和失效条件。

`<Term def="由第二来源、独立复现实验或不同记录检查同一主张，寻找版本漂移和解释偏差。">交叉核对</Term>`不是收集更多链接，而是比较来源之间是否真的谈论同一个对象。

`<Term def="不依赖原作者的记忆、点击顺序或期待答案，由另一名复核者重建结论。">独立复核</Term>`要求提供冻结输入、验收命题、边界和失败日志；只有最终结论而没有过程，不能算可复核证据。

五个词形成一条责任链：先写目录主张，再给出引用坐标，提取原始证据，声明适用边界，最后交给独立复核。链条中任一节点缺失，结论都应停在缺口处，而不是跳到“已验证”。

## 从目录主张到当前复核

### 目录主张

公开目录可以确认单元标题、顺序和范围。它是课程的范围依据，不等同于原书正文、作者论证或当前项目的结果。先写“我要验证的具体句子”，避免让标题承担超出来源能力的含义。

### 引用定位与原始证据

为主张记录 ISBN、版次、章节标题、公开页面和获取日期；能提供页码或稳定锚点时再补充。随后标注证据等级：目录事实、官方规范、实验观察、作者综合和待复核假设不能混为一谈。

### 适用边界与当前复核

把时间、工具版本、团队规模、数据敏感性、发布频率和监管约束写进边界。当前项目要重新运行代表性样本；自动化检查通过，只能证明它声明覆盖的分支，不会自动替代语义复核。

## 证据合同

```ts
type EvidenceClaim = {
  claim: string;
  citation: string;
  sourceKind: "catalog" | "official" | "experiment" | "synthesis";
  boundary: string[];
  crossCheck: string;
  reviewer: string;
  decision: "accept" | "narrow" | "pause";
};

function canPublish(claim: EvidenceClaim) {
  return (
    claim.claim.length > 0 &&
    claim.citation.length > 0 &&
    claim.boundary.length > 0 &&
    claim.crossCheck.length > 0 &&
    claim.decision !== "pause"
  );
}
```

这个合同不把证据压成一个分数。它强制记录主张、坐标、来源类型、边界、交叉核对和复核人；如果主张无法定位、超出边界或仍需暂停，就不能用“有参考文献”掩盖缺口。

## 四步复核流程

<Stepper>

<Step title="1. 写出主张和范围">

把一个模糊标题改写成可判定的句子，注明对象、预期结果、版本和不在范围内的部分。目录只负责确定课程边界，不替代主张本身。

</Step>

<Step title="2. 固定引用坐标">

保存来源名称、版次、章节或标题、URL、获取时间和支持的句子。若只能找到二手摘要，标记为线索，不把它升级成原始证据。

</Step>

<Step title="3. 检查边界与交叉来源">

比较第二来源或独立实验是否谈论相同版本和对象，记录冲突、缺口与适用边界。版本漂移、环境差异和无法复现都应成为证据，而不是被删除的噪声。

</Step>

<Step title="4. 交给独立复核者">

只提供冻结输入、验收命题和边界，让复核者先预测首个变化，再重放样本。根据结果接受、缩小结论或暂停发布，并保留决定与恢复动作。

</Step>

</Stepper>

## 正常、边界与单一故障证据

<Tpp20BibliographyEvidenceDiagram />

| 样本     | 只改变的变量                     | 预期判定                       | 必存证据                   |
| -------- | -------------------------------- | ------------------------------ | -------------------------- |
| 正常     | 版本、坐标、原始证据和边界完整   | 主张可定位，复核者能重建       | 来源、坐标、输入和复核记录 |
| 边界     | 版本、环境或证据等级恰好越过阈值 | 缩小结论或暂停，不假装普遍有效 | 阈值、冲突、未覆盖范围     |
| 单一故障 | 一个坐标、来源或交叉核对失效     | 在首个证据缺口停下并恢复       | 首差、错误上下文和修复     |

## 最小证据包与反例

最小证据包包含主张、ISBN 与目录坐标、来源版本、获取日期、输入和代码哈希、工具版本、边界、观察日志、输出哈希、用户或系统结果、复核人、决定和恢复动作。截图、覆盖率或格式化结果只能辅助定位，不能单独证明掌握。

反例不是“我不同意”。它必须在相同前提下产生相反结果，或指出前提在目标环境并不成立。发现反例后，缩小适用范围、更新模型并重放旧样本；不能删除失败记录来保持主张永远正确。

## 练习

<Exercises>

**问题 1：** 你要引用一句“某实践能降低缺陷”，但手头只有目录标题和一篇未注明版本的博客。如何处理？

<Answer>

先把它标成待复核假设，记录目录坐标和博客作为线索，不宣称有原始证据。寻找对应版本的官方材料或可重放实验，明确对象、指标、时间窗口和不支持的结论；在证据链闭合前选择 `pause` 或缩小主张。

</Answer>

**问题 2：** 一个 2020 年的工具建议迁移到今天的 AI 辅助开发流程。你要补充哪些边界？

<Answer>

补充工具和模型版本、数据敏感性、团队权限、人工复核点、反馈延迟、发布频率、监管要求和失败回退。用代表性和边界样本重新验证；旧来源只能支持历史背景，不能直接支持当前效果。

</Answer>

**问题 3：** 独立复核者无法根据你的资料重建结论，但最终截图看起来正确。你会如何决定？

<Answer>

暂停接受结论，记录首个缺口是坐标、输入、边界还是日志，并补齐最小证据包。让复核者在不接收期待答案的情况下重放；如果仍无法复现，就缩小或撤回主张，而不是用截图替代证据。

</Answer>

</Exercises>

## 本单元回顾

参考文献的价值不在于链接数量，而在于主张、引用坐标、原始证据、适用边界和独立复核可以互相接上。目录能确定范围，实验能验证当前行为，交叉核对能暴露漂移；证据不足时，暂停或缩小结论本身就是专业的结果。
