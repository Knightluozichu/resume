## 从输入到结论的诊断链

主链为：**CPU总时间 → 线程分流 → Timeline定位 → Hierarchy归因 → 标记验证 → 跨线程复验**。每个节点保存构建提交、设备ID、场景检查点、帧号或快照ID、当前预算、实际值和首个异常。下一节点只消费上一节点已验证的事实，不能用“感觉更流畅”跨过中间归因。

### 1. CPU-bound

主线程热点常见于脚本Update、物理准备、动画更新、对象创建销毁和垃圾回收。先按帧在Timeline观察尖峰，再在Hierarchy用Self Time找可直接修改的叶节点。

```csharp
using Unity.Profiling;

static readonly ProfilerMarker SenseMarker = new("AI.Sense");
static readonly ProfilerMarker ApplyMarker = new("AI.ApplyResults");

void Update()
{
    using (SenseMarker.Auto()) ScheduleSenseJobs();
    using (ApplyMarker.Auto()) CompleteAndApplyResults();
}
```
