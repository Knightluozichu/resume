## 从输入到结论的诊断链

主链为：**GPU总时间 → 分辨率实验 → 阶段定位 → 带宽检查 → 热稳态 → 档位签发**。每个节点保存构建提交、设备ID、场景检查点、帧号或快照ID、当前预算、实际值和首个异常。下一节点只消费上一节点已验证的事实，不能用“感觉更流畅”跨过中间归因。

### 1. GPU-bound

把内部渲染分辨率明显降低：若GPU时间近似按像素数下降，优先怀疑填充、过绘或后处理；若变化很小，检查顶点、Draw Call、带宽或同步。这个实验只用于归因。

### 3. Adjust frame budgets on mobile

```csharp
public void ApplyThermalTier(int tier)
{
    Application.targetFrameRate = tier >= 2 ? 30 : 60;
    QualitySettings.SetQualityLevel(tier >= 2 ? 0 : 2, true);
    UniversalRenderPipeline.asset.renderScale = tier >= 2 ? 0.75f : 1.0f;
}

// Production code should add hysteresis and a minimum hold duration.
```
