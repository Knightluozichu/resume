## 直觉引入

0 是数学中最伟大的发明之一。没有 0，就没有位值制记数法，没有负数，没有微积分。在计算机中，0 更是基石——所有信息最终都表示为 0 和 1 的序列。

为什么是 0 和 1 而不是 0 到 9？因为电子元件最容易区分两种状态（高电压/低电压、开/关、有磁/无磁）。两种状态对应 0 和 1，这就是二进制的物理基础。

## 概念讲解

### 0 的意义

<Term def="0 是表示「没有」的数，也是位值制记数法中的占位符，使得不同位上的数字有不同权重">零</Term>在数学中有三重含义：数量的「没有」、数轴的原点、位值制的占位符。第三重含义最关键——没有 0 作为占位符，就无法区分 12、102、1002。

### 二进制

<Term def="二进制是基数为 2 的记数法，只用 0 和 1 两个数字，每位权重是 2 的幂">二进制</Term>是计算机的母语。十进制的 $13_{10}$ 在二进制中是 $1101_2$：

$$13 = 1 \times 2^3 + 1 \times 2^2 + 0 \times 2^1 + 1 \times 2^0 = 8 + 4 + 0 + 1$$

### 布尔代数

<Term def="布尔代数是处理真值（true/false，即 1/0）的代数系统，基本运算有与（AND）、或（OR）、非（NOT）">布尔代数</Term>是计算机逻辑的数学基础。$1 \land 1 = 1$（真且真=真），$1 \lor 0 = 1$（真或假=真），$\neg 1 = 0$（非真=假）。

</Step>

小数部分不断乘 2 取整。例如 0.625：0.625×2=1.25 取 1，0.25×2=0.5 取 0，0.5×2=1.0 取 1。从上往下读：101。所以 0.625 = 0.101₂。注意 0.1 无法精确表示为有限二进制小数。
</Step>

## 代码对照

```python
# 二进制与布尔代数

# 1. 十进制转二进制
def dec_to_bin(n):
    if n == 0:
        return "0"
    bits = []
    while n > 0:
        bits.append(str(n % 2))
        n //= 2
    return "".join(reversed(bits))

print(dec_to_bin(13))  # 1101
print(bin(13))         # 0b1101（Python 内置）

# 2. 布尔运算（位运算）
a = 0b1100  # 12
b = 0b1010  # 10
print(f"a & b = {bin(a & b)}")  # 0b1000 (AND)
print(f"a | b = {bin(a | b)}")  # 0b1110 (OR)
print(f"a ^ b = {bin(a ^ b)}")  # 0b0110 (XOR)
print(f"~a    = {~a}")          # -13 (NOT)

# 3. 位运算的实际应用：权限管理
READ  = 0b1000  # 读权限
WRITE = 0b0100  # 写权限
EXEC  = 0b0010  # 执行权限
DEL   = 0b0001  # 删除权限

user_perm = READ | WRITE  # 用户有读和写权限
print(f"可读: {bool(user_perm & READ)}")   # True
print(f"可删: {bool(user_perm & DEL)}")    # False
```

## 常见误区

<Callout type="trap">
**误区：认为 0 就是「什么都没有」，没有数学意义。**
0 在数学中极其重要。作为占位符，它使位值制成为可能——没有 0 就无法区分 12 和 102。作为原点，它是数轴的中心，负数和正数对称分布。在计算机中，0 是所有逻辑运算的基础，与 1 构成完整的布尔代数。
</Callout>

<Callout type="trap">
**误区：认为二进制只是程序员的工具，与日常无关。**
二进制思维渗透在日常编程中。位运算比算术运算快，权限管理用位掩码，颜色用 RGB 值，网络地址用 IP（32位整数）。理解二进制是理解计算机如何表示和处理一切信息的前提。
</Callout>

<Exercises>
**问题 1**：为什么计算机使用二进制而非十进制？

<Answer>
计算机使用二进制是因为物理实现简单可靠。电子元件最容易区分两种状态（高/低电压、开/关、有磁/无磁），对应 0 和 1。两种状态的电路设计简单、抗干扰能力强、可靠性高。如果用十进制（10 种状态），每种状态的区分需要更复杂的电路，且电压波动容易导致误判。此外，布尔代数为二进制提供了完整的数学基础，所有逻辑运算都可以用 0 和 1 表达。
</Answer>

**问题 2**：手算十进制 25.375 的二进制表示。

<Answer>
整数部分 25：25÷2=12余1，12÷2=6余0，6÷2=3余0，3÷2=1余1，1÷2=0余1，逆序 = 11001。小数部分 0.375：0.375×2=0.75取0，0.75×2=1.5取1，0.5×2=1.0取1，顺序 = 011。合在一起 = 11001.011₂。验证：16+8+1+0.25+0.125 = 25.375 ✓。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="零">
表示「没有」的数，也是位值制记数法中的占位符。没有 0 就无法区分 12 和 102，它是数学中最伟大的发明之一。
</GlossaryItem>
<GlossaryItem term="二进制">
基数为 2 的记数法，只用 0 和 1 两个数字。每位权重是 2 的幂。是计算机的母语，因为电子元件最易区分两种状态。
</GlossaryItem>
<GlossaryItem term="布尔代数">
处理真值（1/0）的代数系统。基本运算有与（AND）、或（OR）、非（NOT）、异或（XOR）。是计算机逻辑的数学基础。
</GlossaryItem>
<GlossaryItem term="位值制">
数字的值取决于其位置的记数法。在二进制中，从右到左各位权重是 1, 2, 4, 8, ...。0 作为占位符是位值制的关键。
</GlossaryItem>
