## 原书章节定位

本页对应权威目录中的“第3章 余数：周期性和分组”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：余数把无限整数压缩成有限个等价类。时钟、环形缓冲区、奇偶性、校验位和分片路由都利用周期性；真正的边界是不同语言对负数取模的定义，以及模运算能保留什么、丢失什么。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **带余除法**：给定正模数m，整数a可唯一写成qm+r且余数位于0到m减1。
2. **同余**：两个整数除以m余数相同，记作模m同余；它把整数划分为m组。
3. **周期性**：状态每经过固定步数回到同一余数类，因此可以只保存当前位置而非累计次数。
4. **模运算规则**：加法和乘法可先取模再计算；除法只有在逆元存在时才能安全迁移。
5. **环形索引**：逻辑位置对容量取模得到物理槽位，但覆盖策略和空满判定仍需额外状态。

这些单元构成一条依赖链。带余除法负责给定正模数m，整数a可唯一写成qm+r且余数位于0到m减1。 同余负责两个整数除以m余数相同，记作模m同余；它把整数划分为m组。 周期性负责状态每经过固定步数回到同一余数类，因此可以只保存当前位置而非累计次数。 模运算规则负责加法和乘法可先取模再计算；除法只有在逆元存在时才能安全迁移。 环形索引负责逻辑位置对容量取模得到物理槽位，但覆盖策略和空满判定仍需额外状态。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：带余除法处理的对象是什么，同余保留了哪些信息，周期性执行后哪些量应保持不变，模运算规则依赖哪些前提，环形索引用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

给定正模数m，整数a可唯一写成qm+r且余数位于0到m减1。 因而第一张检查表记录定义和非例；两个整数除以m余数相同，记作模m同余；它把整数划分为m组。 第二张检查表记录表示变化；状态每经过固定步数回到同一余数类，因此可以只保存当前位置而非累计次数。 第三张检查表记录推导所保持的不变量。加法和乘法可先取模再计算；除法只有在逆元存在时才能安全迁移。 负责指出退化边界，逻辑位置对容量取模得到物理槽位，但覆盖策略和空满判定仍需额外状态。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现带余除法和同余的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造模运算规则的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“认为同余意味着数值相等；同余只说明在指定模数下属于同一组。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。容量为8的环形队列把逻辑序号13映射到槽5，但槽5可能属于旧数据也可能属于新数据。生产系统会同时维护读写序号，用差值判断元素数，用取模定位数组槽；只保存两个余数会丢失绕圈次数并产生空满二义性。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写带余除法与同余的输入域和单位；推导栏逐步说明周期性使用的规则；边界栏记录模运算规则在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用环形索引对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
a=qm+r,\quad 0\le r<m;\qquad (a+b)\bmod m=((a\bmod m)+(b\bmod m))\bmod m
$$

若a与a'模m同余，b与b'模m同余，则差值分别是m的倍数；两差相加仍是m的倍数，因此和保持同余。乘法可把ab-a'b'拆成a(b-b')加b'(a-a')，两项也都含m。这个证明同时解释为何普通除法不能直接照搬。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
class RingIndex:
    def __init__(self, capacity: int):
        if capacity <= 0:
            raise ValueError("capacity must be positive")
        self.capacity = capacity

    def physical(self, logical: int) -> int:
        return logical % self.capacity

assert RingIndex(8).physical(13) == 5
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**带余除法**：给定正模数m，整数a可唯一写成qm+r且余数位于0到m减1。

**同余**：两个整数除以m余数相同，记作模m同余；它把整数划分为m组。

**周期性**：状态每经过固定步数回到同一余数类，因此可以只保存当前位置而非累计次数。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**模运算规则**：加法和乘法可先取模再计算；除法只有在逆元存在时才能安全迁移。

**环形索引**：逻辑位置对容量取模得到物理槽位，但覆盖策略和空满判定仍需额外状态。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "带余除法到环形索引的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "认为同余意味着数值相等；同余只说明在指定模数下属于同一组。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

容量为8的环形队列把逻辑序号13映射到槽5，但槽5可能属于旧数据也可能属于新数据。生产系统会同时维护读写序号，用差值判断元素数，用取模定位数组槽；只保存两个余数会丢失绕圈次数并产生空满二义性。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("带余除法", "definition"),
    ("周期性", "derivation"),
    ("环形索引", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
