## 直觉引入

天气预报说「降雨概率 70%」是什么意思？不是「100 次预报中 70 次下雨」，而是「在当前天气条件下，历史上类似情况中有 70% 下了雨」。这就是概率——对不确定性的量化。

概率论的核心工具是条件概率和贝叶斯定理。条件概率告诉你「已知 B 发生了，A 发生的概率多大」；贝叶斯定理反过来——「已知 A 发生了，原因 B 的概率多大」。这个逆转是机器学习、医学诊断、垃圾邮件过滤的数学基础。

## 概念讲解

### 古典概率

<Term def="古典概率定义为有利事件数除以总事件数，前提是每个基本事件等可能">古典概率</Term>：

$$P(A) = \frac{\text{有利事件数}}{\text{总事件数}}$$

掷骰子得到偶数的概率 = 3/6 = 1/2（3 个偶数 / 6 个面）。

### 条件概率

<Term def="条件概率 P(A|B) 是在已知 B 发生的条件下 A 发生的概率：P(A|B) = P(A∩B)/P(B)">条件概率</Term>是概率论的核心概念。例如：P(下雨|阴天) ≠ P(下雨)。

### 贝叶斯定理

<Term def="贝叶斯定理将条件概率逆转：P(B|A) = P(A|B)·P(B)/P(A)，是从结果推断原因的工具">贝叶斯定理</Term>：

$$P(B|A) = \frac{P(A|B) \cdot P(B)}{P(A)}$$

这个式子在说：已知结果 A 发生了，原因 B 的概率 = B 导致 A 的概率 × B 的先验概率 / A 的总概率。

<Step title="第一步：已知条件">
某病发病率 1%（先验 P(病)=0.01）。检测准确率 99%（P(阳性|病)=0.99）。误报率 5%（P(阳性|无病)=0.05）。问：检测阳性时真有病的概率 P(病|阳性)？
</Step>
<Step title="第二步：计算 P(阳性)">
用全概率公式：P(阳性) = P(阳性|病)×P(病) + P(阳性|无病)×P(无病) = 0.99×0.01 + 0.05×0.99 = 0.0099 + 0.0495 = 0.0594。
</Step>
<Step title="第三步：套用贝叶斯">
P(病|阳性) = P(阳性|病)×P(病) / P(阳性) = 0.99×0.01 / 0.0594 = 0.0099/0.0594 ≈ 16.7%。即使检测阳性，真有病的概率仅 16.7%——因为发病率低，误报人数远超确诊人数。
</Step>
</Stepper>

## 代码对照

```python
# 概率论基础实现

# 1. 古典概率：掷骰子
import random
def dice_prob(target, trials=1000000):
    count = sum(1 for _ in range(trials) if random.randint(1, 6) == target)
    return count / trials

print(f"P(掷出6) ≈ {dice_prob(6):.4f}")  # 约 0.1667 = 1/6

# 2. 条件概率：P(A|B) = P(A∩B) / P(B)
# 场景：P(下雨)=0.3, P(阴天)=0.4, P(下雨且阴天)=0.25
p_rain = 0.3
p_cloudy = 0.4
p_rain_and_cloudy = 0.25
p_rain_given_cloudy = p_rain_and_cloudy / p_cloudy
print(f"P(下雨|阴天) = {p_rain_given_cloudy:.2%}")  # 62.5%

# 3. 贝叶斯定理：医学检测
def bayes(p_b, p_a_given_b, p_a_given_not_b):
    # P(B|A) = P(A|B)*P(B) / P(A)
    # P(A) = P(A|B)*P(B) + P(A|¬B)*P(¬B)
    p_a = p_a_given_b * p_b + p_a_given_not_b * (1 - p_b)
    return (p_a_given_b * p_b) / p_a

# 发病率1%, 检出率99%, 误报率5%
p_disease = 0.01
p_pos_given_disease = 0.99
p_pos_given_healthy = 0.05
p_disease_given_pos = bayes(p_disease, p_pos_given_disease, p_pos_given_healthy)
print(f"P(病|阳性) = {p_disease_given_pos:.2%}")  # 约 16.7%
```

## 常见误区

<Callout type="trap">
**误区：认为检测准确率 99% 意味着阳性结果 99% 是真阳性。**
这是「基础概率忽视」谬误。即使检测准确率 99%、误报率 5%，当发病率只有 1% 时，阳性结果的真阳性率仅 16.7%。因为健康人远多于病人（99:1），5% 的误报率产生的误报人数（4.95%）远超真阳性人数（0.99%）。贝叶斯定理正式揭示了这一点。
</Callout>

<Callout type="trap">
**误区：认为 P(A|B) = P(B|A)。**
这是常见混淆。P(下雨|阴天) ≠ P(阴天|下雨)。下雨时几乎总是阴天（P(阴天|下雨)≈95%），但阴天不一定下雨（P(下雨|阴天)≈62.5%）。贝叶斯定理就是用来在 P(A|B) 和 P(B|A) 之间转换的工具。
</Callout>

<Exercises>
**问题 1**：为什么贝叶斯定理被称为「概率论的逆推理引擎」？

<Answer>
贝叶斯定理将条件概率逆转：从 P(结果|原因) 推出 P(原因|结果)。通常我们知道原因推结果（如「有病→检测阳性」概率 99%），但实际需要的是从结果推原因（如「检测阳性→真有病」概率）。贝叶斯定理 P(原因|结果) = P(结果|原因)×P(原因)/P(结果) 实现了这个逆转，让我们从观测到的证据推断最可能的原因。这在医学诊断（症状→疾病）、垃圾邮件过滤（关键词→垃圾邮件）、机器学习（数据→模型）中无处不在。
</Answer>

**问题 2**：某病发病率 1%，检测准确率 99%，误报率 5%。求阳性时真有病的概率。

<Answer>
用贝叶斯定理。P(病)=0.01, P(无病)=0.99, P(阳性|病)=0.99, P(阳性|无病)=0.05。P(阳性) = 0.99×0.01 + 0.05×0.99 = 0.0099 + 0.0495 = 0.0594。P(病|阳性) = 0.99×0.01/0.0594 = 0.0099/0.0594 ≈ 16.7%。即使检测阳性，真有病概率仅 16.7%，因为健康人的误报（4.95%）远超病人的真阳性（0.99%）。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="古典概率">
有利事件数除以总事件数，前提是每个基本事件等可能。P(A) = 有利/总数。
</GlossaryItem>
<GlossaryItem term="条件概率">
已知 B 发生时 A 发生的概率。P(A|B) = P(A∩B)/P(B)。是概率推理的核心工具。
</GlossaryItem>
<GlossaryItem term="贝叶斯定理">
将条件概率逆转：P(B|A) = P(A|B)·P(B)/P(A)。从结果推断原因的数学工具。
</GlossaryItem>
<GlossaryItem term="先验概率">
在获得新证据之前对事件概率的估计。贝叶斯定理中用新证据更新先验得到后验。
</GlossaryItem>
</Glossary>
