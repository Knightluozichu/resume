## 先做预测

先不要计算。预测当输入规模、随机机制、基底或数值精度变化时，结论是否仍成立；再写出你依赖的假设。最后一章连接回归、主成分分析、随机游走、卡尔曼滤波、马尔可夫链和信息论。共同主线是：用概率模型压缩不确定性，依据观测更新状态，并用损失或信息量评价预测。 本章用、、、、建立可检查的语言。

### 核心单元索引

1. **回归分析**：用条件均值描述输入与输出关系，残差结构决定线性模型是否可信。
2. **主成分分析**：对协方差矩阵特征分解，选择最大方差方向进行旋转与降维。
3. **随机过程**：按时间索引的一族随机变量，需要描述状态转移和跨时间依赖。
4. **卡尔曼滤波**：在线组合动态预测与带噪观测，以协方差权衡两类信息。
5. **信息熵**：平均编码下限与不确定性度量，概率越均匀，熵通常越高。

这些单元构成一条依赖链。回归分析负责用条件均值描述输入与输出关系，残差结构决定线性模型是否可信。 主成分分析负责对协方差矩阵特征分解，选择最大方差方向进行旋转与降维。 随机过程负责按时间索引的一族随机变量，需要描述状态转移和跨时间依赖。 卡尔曼滤波负责在线组合动态预测与带噪观测，以协方差权衡两类信息。 信息熵负责平均编码下限与不确定性度量，概率越均匀，熵通常越高。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：回归分析处理的对象是什么，主成分分析保留了哪些信息，随机过程执行后哪些量应保持不变，卡尔曼滤波依赖哪些前提，信息熵用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

用条件均值描述输入与输出关系，残差结构决定线性模型是否可信。 因而第一张检查表记录定义和非例；对协方差矩阵特征分解，选择最大方差方向进行旋转与降维。 第二张检查表记录表示变化；按时间索引的一族随机变量，需要描述状态转移和跨时间依赖。 第三张检查表记录推导所保持的不变量。在线组合动态预测与带噪观测，以协方差权衡两类信息。 负责指出退化边界，平均编码下限与不确定性度量，概率越均匀，熵通常越高。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现回归分析和主成分分析的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造卡尔曼滤波的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“做PCA前不中心化或不统一量纲，让大单位变量支配主方向。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。位置融合系统用运动模型预测下一状态，再用GPS观测修正。GPS噪声变大时滤波器应更信任预测，模型不稳定时应更信任观测。协方差不是装饰参数，它决定增益；错误单位或未建模偏差会让估计看似平滑却系统性错误。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写回归分析与主成分分析的输入域和单位；推导栏逐步说明随机过程使用的规则；边界栏记录卡尔曼滤波在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用信息熵对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
H(X)=-\sum_x p(x)\log_2 p(x),\qquad x_t=Ax_{t-1}+w_t
$$

若符号x的理想码长取负log2 p(x)，平均码长就是熵。高概率符号码短，低概率符号码长。信源编码把概率模型转成存储成本；模型偏差会增加实际码长，因此压缩率也是概率预测质量的证据。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
from math import log2

def entropy(probabilities):
    return -sum(p * log2(p) for p in probabilities if p > 0)

assert entropy([0.5, 0.5]) == 1.0
assert entropy([1.0, 0.0]) == 0.0
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**回归分析**：用条件均值描述输入与输出关系，残差结构决定线性模型是否可信。

**主成分分析**：对协方差矩阵特征分解，选择最大方差方向进行旋转与降维。

**随机过程**：按时间索引的一族随机变量，需要描述状态转移和跨时间依赖。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**卡尔曼滤波**：在线组合动态预测与带噪观测，以协方差权衡两类信息。

**信息熵**：平均编码下限与不确定性度量，概率越均匀，熵通常越高。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "回归分析到信息熵的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "做PCA前不中心化或不统一量纲，让大单位变量支配主方向。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

位置融合系统用运动模型预测下一状态，再用GPS观测修正。GPS噪声变大时滤波器应更信任预测，模型不稳定时应更信任观测。协方差不是装饰参数，它决定增益；错误单位或未建模偏差会让估计看似平滑却系统性错误。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("回归分析", "definition"),
    ("随机过程", "derivation"),
    ("信息熵", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
