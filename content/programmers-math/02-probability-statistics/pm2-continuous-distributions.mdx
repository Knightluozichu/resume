### 核心单元索引

1. **概率密度**：密度值不是点概率，曲线在区间下的面积才是概率，总面积为1。
2. **累积分布函数**：给出X不大于x的概率，单调且从0趋近1，可统一处理分位数。
3. **均匀分布**：有限区间内密度恒定；端点和随机数离散化会影响实现。
4. **指数分布**：恒定到达率下的等待时间模型，具有无记忆性。
5. **正态分布**：由均值和方差决定的钟形分布，适合加性扰动但不自动适合所有数据。

这些单元构成一条依赖链。概率密度负责密度值不是点概率，曲线在区间下的面积才是概率，总面积为1。 累积分布函数负责给出X不大于x的概率，单调且从0趋近1，可统一处理分位数。 均匀分布负责有限区间内密度恒定；端点和随机数离散化会影响实现。 指数分布负责恒定到达率下的等待时间模型，具有无记忆性。 正态分布负责由均值和方差决定的钟形分布，适合加性扰动但不自动适合所有数据。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：概率密度处理的对象是什么，累积分布函数保留了哪些信息，均匀分布执行后哪些量应保持不变，指数分布依赖哪些前提，正态分布用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

密度值不是点概率，曲线在区间下的面积才是概率，总面积为1。 因而第一张检查表记录定义和非例；给出X不大于x的概率，单调且从0趋近1，可统一处理分位数。 第二张检查表记录表示变化；有限区间内密度恒定；端点和随机数离散化会影响实现。 第三张检查表记录推导所保持的不变量。恒定到达率下的等待时间模型，具有无记忆性。 负责指出退化边界，由均值和方差决定的钟形分布，适合加性扰动但不自动适合所有数据。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现概率密度和累积分布函数的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造指数分布的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“把密度曲线在某点的高度解释为该点概率；连续变量的单点概率通常为零。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。延迟分布通常右偏并有长尾，平均值和正态假设会掩盖少量严重慢请求。服务等级应使用经验分位数；若拟合对数正态或混合模型，需用留出数据检查尾部，而不是只看中部曲线贴合。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写概率密度与累积分布函数的输入域和单位；推导栏逐步说明均匀分布使用的规则；边界栏记录指数分布在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用正态分布对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
P(a\le X\le b)=\int_a^b f(x)\,dx,\qquad F(x)=\int_{-\infty}^{x}f(t)\,dt
$$

密度在区间积分得到概率，因此把区间切得更细时，每个小段概率近似为密度乘宽度。单点宽度趋于零，概率也趋于零。累积分布的导数在可导处回到密度，两种表示互相转换。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
from math import erf, sqrt

def normal_cdf(x, mean=0.0, std=1.0):
    if std <= 0:
        raise ValueError("std must be positive")
    z = (x - mean) / (std * sqrt(2))
    return 0.5 * (1 + erf(z))

assert abs(normal_cdf(0) - 0.5) < 1e-12
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**概率密度**：密度值不是点概率，曲线在区间下的面积才是概率，总面积为1。

**累积分布函数**：给出X不大于x的概率，单调且从0趋近1，可统一处理分位数。

**均匀分布**：有限区间内密度恒定；端点和随机数离散化会影响实现。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**指数分布**：恒定到达率下的等待时间模型，具有无记忆性。

**正态分布**：由均值和方差决定的钟形分布，适合加性扰动但不自动适合所有数据。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "概率密度到正态分布的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "把密度曲线在某点的高度解释为该点概率；连续变量的单点概率通常为零。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

延迟分布通常右偏并有长尾，平均值和正态假设会掩盖少量严重慢请求。服务等级应使用经验分位数；若拟合对数正态或混合模型，需用留出数据检查尾部，而不是只看中部曲线贴合。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("概率密度", "definition"),
    ("均匀分布", "derivation"),
    ("正态分布", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
