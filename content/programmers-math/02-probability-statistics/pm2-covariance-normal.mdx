## 原书章节定位

本页对应权威目录中的“第5章 协方差矩阵、多元正态分布与椭圆”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：多变量概率需要同时描述各维尺度和共同变化。协方差矩阵的对角线是方差，非对角线是协方差；特征向量给出椭圆主轴，特征值给出轴向扩散，连接概率统计与线性代数。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **协方差**：衡量两个变量围绕各自均值共同增减的方向与尺度，受单位影响。
2. **相关系数**：用标准差归一化协方差，位于负1到1，但只刻画线性关系。
3. **协方差矩阵**：对称半正定矩阵，汇总所有变量方差和两两协方差。
4. **多元正态分布**：由均值向量和协方差矩阵确定，等密度面是椭圆或椭球。
5. **马氏距离**：按协方差缩放和旋转后的距离，能区分高方差方向与异常方向。

这些单元构成一条依赖链。协方差负责衡量两个变量围绕各自均值共同增减的方向与尺度，受单位影响。 相关系数负责用标准差归一化协方差，位于负1到1，但只刻画线性关系。 协方差矩阵负责对称半正定矩阵，汇总所有变量方差和两两协方差。 多元正态分布负责由均值向量和协方差矩阵确定，等密度面是椭圆或椭球。 马氏距离负责按协方差缩放和旋转后的距离，能区分高方差方向与异常方向。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：协方差处理的对象是什么，相关系数保留了哪些信息，协方差矩阵执行后哪些量应保持不变，多元正态分布依赖哪些前提，马氏距离用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

衡量两个变量围绕各自均值共同增减的方向与尺度，受单位影响。 因而第一张检查表记录定义和非例；用标准差归一化协方差，位于负1到1，但只刻画线性关系。 第二张检查表记录表示变化；对称半正定矩阵，汇总所有变量方差和两两协方差。 第三张检查表记录推导所保持的不变量。由均值向量和协方差矩阵确定，等密度面是椭圆或椭球。 负责指出退化边界，按协方差缩放和旋转后的距离，能区分高方差方向与异常方向。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现协方差和相关系数的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造多元正态分布的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“看到相关系数接近零就断言变量独立；非线性依赖可能让线性相关为零。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。CPU和请求量高度正相关时，单独用CPU阈值会产生误报。联合模型可把沿正常相关方向的变化视为常态，而把垂直主轴的偏移识别为异常。但均值和协方差也会被异常点污染，应配合稳健估计和分群。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写协方差与相关系数的输入域和单位；推导栏逐步说明协方差矩阵使用的规则；边界栏记录多元正态分布在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用马氏距离对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
\Sigma=E[(X-\mu)(X-\mu)^T],\qquad (x-\mu)^T\Sigma^{-1}(x-\mu)=c
$$

对中心化向量z，任意向量a满足a转置Sigma a等于随机变量a转置z的方差，因此非负，说明协方差矩阵半正定。对Sigma特征分解后，在特征向量坐标中二次型变为各轴平方除以特征值，等值线自然是椭圆。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
def covariance(xs, ys):
    if len(xs) != len(ys) or len(xs) < 2:
        raise ValueError("paired samples required")
    mx, my = sum(xs) / len(xs), sum(ys) / len(ys)
    return sum((x - mx) * (y - my) for x, y in zip(xs, ys)) / (len(xs) - 1)

assert covariance([1, 2, 3], [2, 4, 6]) == 2.0
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**协方差**：衡量两个变量围绕各自均值共同增减的方向与尺度，受单位影响。

**相关系数**：用标准差归一化协方差，位于负1到1，但只刻画线性关系。

**协方差矩阵**：对称半正定矩阵，汇总所有变量方差和两两协方差。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。

## 边界与失败模式

**多元正态分布**：由均值向量和协方差矩阵确定，等密度面是椭圆或椭球。

**马氏距离**：按协方差缩放和旋转后的距离，能区分高方差方向与异常方向。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "协方差到马氏距离的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "看到相关系数接近零就断言变量独立；非线性依赖可能让线性相关为零。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 常见误区

<Callout type="trap" title="模型前提被省略">看到相关系数接近零就断言变量独立；非线性依赖可能让线性相关为零。 修复方式是回到对象、输入域和不变量，写出能推翻当前结论的最小反例。</Callout>

<Callout type="trap" title="数值等于证明">直接求协方差逆矩阵，没有处理样本不足、共线性和近奇异数值问题。 有限样例、模拟和浮点结果只能提供实现证据；普遍结论仍需要推导，统计结论还需要不确定性说明。</Callout>
