## 原书章节定位

本页对应权威目录中的“第3章 离散值的概率分布”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：离散随机变量通过概率质量函数分配可数结果。伯努利、二项、几何和泊松分布对应不同生成机制；期望与方差压缩中心和波动，但不能唯一决定整个分布。选分布应从试验结构出发。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **概率质量函数**：为每个离散取值分配非负概率，所有取值概率之和为1。
2. **伯努利分布**：一次成功或失败试验，参数p描述成功概率。
3. **二项分布**：n次独立同分布伯努利试验中的成功次数；独立和固定p是关键假设。
4. **期望**：按概率加权的长期平均，可用线性性拆分，即使变量不独立也成立。
5. **方差**：平方偏差的期望，衡量离均值的扩散；标准差恢复原量纲。

这些单元构成一条依赖链。概率质量函数负责为每个离散取值分配非负概率，所有取值概率之和为1。 伯努利分布负责一次成功或失败试验，参数p描述成功概率。 二项分布负责n次独立同分布伯努利试验中的成功次数；独立和固定p是关键假设。 期望负责按概率加权的长期平均，可用线性性拆分，即使变量不独立也成立。 方差负责平方偏差的期望，衡量离均值的扩散；标准差恢复原量纲。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：概率质量函数处理的对象是什么，伯努利分布保留了哪些信息，二项分布执行后哪些量应保持不变，期望依赖哪些前提，方差用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

为每个离散取值分配非负概率，所有取值概率之和为1。 因而第一张检查表记录定义和非例；一次成功或失败试验，参数p描述成功概率。 第二张检查表记录表示变化；n次独立同分布伯努利试验中的成功次数；独立和固定p是关键假设。 第三张检查表记录推导所保持的不变量。按概率加权的长期平均，可用线性性拆分，即使变量不独立也成立。 负责指出退化边界，平方偏差的期望，衡量离均值的扩散；标准差恢复原量纲。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现概率质量函数和伯努利分布的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造期望的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“看见计数数据就套泊松或二项分布，不检查独立性、固定概率和观察窗口。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。请求重试次数若每次成功概率固定且尝试独立，可用几何分布估计尾部；但真实服务的故障会成批相关，p随时间变化。工程上应先画经验分布和条件分层，再决定经典分布是否只是近似。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写概率质量函数与伯努利分布的输入域和单位；推导栏逐步说明二项分布使用的规则；边界栏记录期望在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用方差对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
P(X=k)={n\choose k}p^k(1-p)^{n-k},\quad E[X]=np,\quad Var(X)=np(1-p)
$$

恰有k次成功时，任一指定成功位置组合的概率是p的k次方乘(1-p)的n-k次方；共有n选k种位置组合，且这些事件互斥，所以乘组合数得到二项概率。概率总和由二项式定理归一为1。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
from math import comb

def binomial_pmf(n, k, p):
    return comb(n, k) * p ** k * (1 - p) ** (n - k)

probs = [binomial_pmf(10, k, 0.3) for k in range(11)]
assert abs(sum(probs) - 1.0) < 1e-12
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**概率质量函数**：为每个离散取值分配非负概率，所有取值概率之和为1。

**伯努利分布**：一次成功或失败试验，参数p描述成功概率。

**二项分布**：n次独立同分布伯努利试验中的成功次数；独立和固定p是关键假设。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**期望**：按概率加权的长期平均，可用线性性拆分，即使变量不独立也成立。

**方差**：平方偏差的期望，衡量离均值的扩散；标准差恢复原量纲。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "概率质量函数到方差的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "看见计数数据就套泊松或二项分布，不检查独立性、固定概率和观察窗口。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

请求重试次数若每次成功概率固定且尝试独立，可用几何分布估计尾部；但真实服务的故障会成批相关，p随时间变化。工程上应先画经验分布和条件分层，再决定经典分布是否只是近似。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("概率质量函数", "definition"),
    ("二项分布", "derivation"),
    ("方差", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
