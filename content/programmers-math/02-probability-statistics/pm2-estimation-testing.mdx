## 先做预测

先不要计算。预测当输入规模、随机机制、基底或数值精度变化时，结论是否仍成立；再写出你依赖的假设。统计推断用样本回答总体问题。点估计给一个数，区间估计表达不确定性；假设检验控制在原假设成立时误报的概率。p值不是原假设为真的概率，统计显著也不等于工程效果足够大。 本章用、、、、建立可检查的语言。

### 核心单元索引

1. **点估计**：用样本统计量估计总体参数，需讨论偏差、方差和一致性。
2. **置信区间**：重复抽样程序中按指定比例覆盖真参数的区间，不是参数随机落入的概率。
3. **原假设**：检验暂时采用的基准模型，拒绝需要预先定义的统计量和显著性水平。
4. **p值**：在原假设成立时观察到当前或更极端数据的概率，不是原假设后验概率。
5. **第一二类错误**：误拒真实原假设与未拒错误原假设之间存在取舍，功效随样本和效应变化。

这些单元构成一条依赖链。点估计负责用样本统计量估计总体参数，需讨论偏差、方差和一致性。 置信区间负责重复抽样程序中按指定比例覆盖真参数的区间，不是参数随机落入的概率。 原假设负责检验暂时采用的基准模型，拒绝需要预先定义的统计量和显著性水平。 p值负责在原假设成立时观察到当前或更极端数据的概率，不是原假设后验概率。 第一二类错误负责误拒真实原假设与未拒错误原假设之间存在取舍，功效随样本和效应变化。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：点估计处理的对象是什么，置信区间保留了哪些信息，原假设执行后哪些量应保持不变，p值依赖哪些前提，第一二类错误用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

用样本统计量估计总体参数，需讨论偏差、方差和一致性。 因而第一张检查表记录定义和非例；重复抽样程序中按指定比例覆盖真参数的区间，不是参数随机落入的概率。 第二张检查表记录表示变化；检验暂时采用的基准模型，拒绝需要预先定义的统计量和显著性水平。 第三张检查表记录推导所保持的不变量。在原假设成立时观察到当前或更极端数据的概率，不是原假设后验概率。 负责指出退化边界，误拒真实原假设与未拒错误原假设之间存在取舍，功效随样本和效应变化。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现点估计和置信区间的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造p值的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“把p值0.03解释成原假设只有3%概率为真，混淆条件方向。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。A/B测试应在实验前写主要指标、最小实际效应、样本量和停止规则。每天查看并在显著时停止会膨胀误报率。报告同时给效应差、置信区间、样本缺失与分流校验，才能判断是否值得发布。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写点估计与置信区间的输入域和单位；推导栏逐步说明原假设使用的规则；边界栏记录p值在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用第一二类错误对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
\bar X\pm z_{1-\alpha/2}\frac{s}{\sqrt n},\qquad p=P(T\ge T_{obs}\mid H_0)
$$

样本均值的标准误随样本量平方根下降，所以把样本扩大四倍才把随机误差约减半。置信区间中心、临界值与标准误共同决定宽度；若数据相关或重尾，独立正态近似会低估不确定性。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
from math import sqrt

def mean_interval(values, z=1.96):
    n = len(values)
    mean = sum(values) / n
    variance = sum((x - mean) ** 2 for x in values) / (n - 1)
    margin = z * sqrt(variance / n)
    return mean - margin, mean + margin

lo, hi = mean_interval([10, 12, 9, 11, 13, 8])
assert lo < 10.5 < hi
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**点估计**：用样本统计量估计总体参数，需讨论偏差、方差和一致性。

**置信区间**：重复抽样程序中按指定比例覆盖真参数的区间，不是参数随机落入的概率。

**原假设**：检验暂时采用的基准模型，拒绝需要预先定义的统计量和显著性水平。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**p值**：在原假设成立时观察到当前或更极端数据的概率，不是原假设后验概率。

**第一二类错误**：误拒真实原假设与未拒错误原假设之间存在取舍，功效随样本和效应变化。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "点估计到第一二类错误的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "把p值0.03解释成原假设只有3%概率为真，混淆条件方向。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

A/B测试应在实验前写主要指标、最小实际效应、样本量和停止规则。每天查看并在显著时停止会膨胀误报率。报告同时给效应差、置信区间、样本缺失与分流校验，才能判断是否值得发布。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("点估计", "definition"),
    ("原假设", "derivation"),
    ("第一二类错误", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
