## 先做预测

先不要计算。预测当输入规模、随机机制、基底或数值精度变化时，结论是否仍成立；再写出你依赖的假设。联合分布描述变量如何共同出现，边缘分布只看其中一部分，条件概率则在观察信息后重新分配质量。独立性是联合分布可分解的强假设，相关或条件关系不能凭变量名称猜测。 本章用、、、、建立可检查的语言。

### 核心单元索引

1. **联合分布**：为变量组合分配概率，完整保留相互作用，是边缘与条件计算的来源。
2. **边缘分布**：对其他变量求和或积分后得到单个变量分布，会丢失依赖结构。
3. **条件概率**：已知事件B后，只在B内部重新归一化A所占的概率质量。
4. **独立性**：联合概率等于边缘概率乘积；零相关通常不足以推出独立。
5. **贝叶斯公式**：把似然与先验组合成后验，同时用证据概率完成归一化。

这些单元构成一条依赖链。联合分布负责为变量组合分配概率，完整保留相互作用，是边缘与条件计算的来源。 边缘分布负责对其他变量求和或积分后得到单个变量分布，会丢失依赖结构。 条件概率负责已知事件B后，只在B内部重新归一化A所占的概率质量。 独立性负责联合概率等于边缘概率乘积；零相关通常不足以推出独立。 贝叶斯公式负责把似然与先验组合成后验，同时用证据概率完成归一化。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：联合分布处理的对象是什么，边缘分布保留了哪些信息，条件概率执行后哪些量应保持不变，独立性依赖哪些前提，贝叶斯公式用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

为变量组合分配概率，完整保留相互作用，是边缘与条件计算的来源。 因而第一张检查表记录定义和非例；对其他变量求和或积分后得到单个变量分布，会丢失依赖结构。 第二张检查表记录表示变化；已知事件B后，只在B内部重新归一化A所占的概率质量。 第三张检查表记录推导所保持的不变量。联合概率等于边缘概率乘积；零相关通常不足以推出独立。 负责指出退化边界，把似然与先验组合成后验，同时用证据概率完成归一化。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现联合分布和边缘分布的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造独立性的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“把P(A给定B)与P(B给定A)互换，忽略先验和归一化项。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。异常检测器命中率很高，但若真实异常极少，阳性样本中仍可能多数是假警报。计算后验必须带入异常先验、召回率和误报率。监控面板只展示“准确率”而不展示基率，会让值班人员高估告警可信度。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写联合分布与边缘分布的输入域和单位；推导栏逐步说明条件概率使用的规则；边界栏记录独立性在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用贝叶斯公式对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
P(A\mid B)=\frac{P(A\cap B)}{P(B)},\qquad P(A\mid B)=\frac{P(B\mid A)P(A)}{P(B)}
$$

由条件概率定义，P(A交B)既等于P(A给定B)乘P(B)，也等于P(B给定A)乘P(A)。令两式相等并除以P(B)，得到贝叶斯公式。每一项都必须来自同一总体和同一条件机制。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
def posterior(prior, sensitivity, false_positive):
    evidence = sensitivity * prior + false_positive * (1 - prior)
    return sensitivity * prior / evidence

# 1%基率、99%召回、5%误报
assert round(posterior(0.01, 0.99, 0.05), 3) == 0.167
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**联合分布**：为变量组合分配概率，完整保留相互作用，是边缘与条件计算的来源。

**边缘分布**：对其他变量求和或积分后得到单个变量分布，会丢失依赖结构。

**条件概率**：已知事件B后，只在B内部重新归一化A所占的概率质量。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**独立性**：联合概率等于边缘概率乘积；零相关通常不足以推出独立。

**贝叶斯公式**：把似然与先验组合成后验，同时用证据概率完成归一化。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "联合分布到贝叶斯公式的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "把P(A给定B)与P(B给定A)互换，忽略先验和归一化项。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

异常检测器命中率很高，但若真实异常极少，阳性样本中仍可能多数是假警报。计算后验必须带入异常先验、召回率和误报率。监控面板只展示“准确率”而不展示基率，会让值班人员高估告警可信度。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("联合分布", "definition"),
    ("条件概率", "derivation"),
    ("贝叶斯公式", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
