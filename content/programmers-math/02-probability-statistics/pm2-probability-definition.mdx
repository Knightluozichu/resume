## 原书章节定位

本页对应权威目录中的“第1章 概率的定义”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：概率从样本空间、事件和概率测度开始。蒙提霍尔问题揭示直觉容易忽略主持人的条件化行为；频率实验能帮助校验，但有限模拟不是定义本身。模型必须说明等可能性从何而来。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **样本空间**：一次随机试验所有可能基本结果的集合；遗漏结果会破坏后续概率。
2. **事件**：样本空间的子集；事件发生表示实际结果落在该子集中。
3. **概率公理**：非负、全集概率为1、互斥事件可列可加，其他规则由此推出。
4. **条件信息**：观察或机制改变后应缩小样本空间并重新归一化，而非沿用先验直觉。
5. **蒙提霍尔问题**：主持人知道奖品位置且必开空门，这个选择机制保留了初选门的三分之一概率。

这些单元构成一条依赖链。样本空间负责一次随机试验所有可能基本结果的集合；遗漏结果会破坏后续概率。 事件负责样本空间的子集；事件发生表示实际结果落在该子集中。 概率公理负责非负、全集概率为1、互斥事件可列可加，其他规则由此推出。 条件信息负责观察或机制改变后应缩小样本空间并重新归一化，而非沿用先验直觉。 蒙提霍尔问题负责主持人知道奖品位置且必开空门，这个选择机制保留了初选门的三分之一概率。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：样本空间处理的对象是什么，事件保留了哪些信息，概率公理执行后哪些量应保持不变，条件信息依赖哪些前提，蒙提霍尔问题用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

一次随机试验所有可能基本结果的集合；遗漏结果会破坏后续概率。 因而第一张检查表记录定义和非例；样本空间的子集；事件发生表示实际结果落在该子集中。 第二张检查表记录表示变化；非负、全集概率为1、互斥事件可列可加，其他规则由此推出。 第三张检查表记录推导所保持的不变量。观察或机制改变后应缩小样本空间并重新归一化，而非沿用先验直觉。 负责指出退化边界，主持人知道奖品位置且必开空门，这个选择机制保留了初选门的三分之一概率。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现样本空间和事件的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造条件信息的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“主持人开门后把两扇门视为各二分之一，忽略主持人的知情选择机制。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。A/B实验的样本空间不仅是点击或未点击，还包含分流规则、曝光成功与机器人过滤。若随机分配在客户端失败，实际概率模型已改变。数据管道应记录分桶依据和排除原因，才能解释频率是否估计了目标概率。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写样本空间与事件的输入域和单位；推导栏逐步说明概率公理使用的规则；边界栏记录条件信息在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用蒙提霍尔问题对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
P(\Omega)=1,\quad P(A)\ge0,\quad A\cap B=\varnothing\Rightarrow P(A\cup B)=P(A)+P(B)
$$

初选门中奖概率是三分之一，奖品在其余两门的总概率是三分之二。主持人必定从其余门中排除一扇空门，因此三分之二并未平均重置，而是集中到唯一剩余门。换门胜率为三分之二。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
import random

def monty_trial() -> bool:
    prize = random.randrange(3)
    chosen = random.randrange(3)
    opened = next(d for d in range(3) if d != prize and d != chosen)
    switched = next(d for d in range(3) if d != chosen and d != opened)
    return switched == prize

rate = sum(monty_trial() for _ in range(20_000)) / 20_000
assert 0.63 < rate < 0.70
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**样本空间**：一次随机试验所有可能基本结果的集合；遗漏结果会破坏后续概率。

**事件**：样本空间的子集；事件发生表示实际结果落在该子集中。

**概率公理**：非负、全集概率为1、互斥事件可列可加，其他规则由此推出。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。

## 边界与失败模式

**条件信息**：观察或机制改变后应缩小样本空间并重新归一化，而非沿用先验直觉。

**蒙提霍尔问题**：主持人知道奖品位置且必开空门，这个选择机制保留了初选门的三分之一概率。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "样本空间到蒙提霍尔问题的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "主持人开门后把两扇门视为各二分之一，忽略主持人的知情选择机制。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

A/B实验的样本空间不仅是点击或未点击，还包含分流规则、曝光成功与机器人过滤。若随机分配在客户端失败，实际概率模型已改变。数据管道应记录分桶依据和排除原因，才能解释频率是否估计了目标概率。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

## 常见误区

<Callout type="trap" title="模型前提被省略">主持人开门后把两扇门视为各二分之一，忽略主持人的知情选择机制。 修复方式是回到对象、输入域和不变量，写出能推翻当前结论的最小反例。</Callout>

<Callout type="trap" title="数值等于证明">用一次频率结果反向定义概率；模拟只能在模型和随机源可信时提供近似证据。 有限样例、模拟和浮点结果只能提供实现证据；普遍结论仍需要推导，统计结论还需要不确定性说明。</Callout>
