## 原书章节定位

本页对应权威目录中的“第7章 伪随机数”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：伪随机数生成器由有限内部状态确定性地产生看似随机的序列。均匀整数、浮点映射和目标分布采样都可能引入偏差；模拟要求可复现种子，安全用途则要求不可预测的密码学随机源。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **确定性生成器**：同一算法和种子产生同一序列，便于重放，也意味着普通生成器可预测。
2. **种子**：初始化内部状态；测试应记录种子，生产安全密钥不应使用可猜种子。
3. **周期**：有限状态序列最终重复；周期长只是必要条件，不保证统计质量。
4. **分布变换**：从均匀随机数构造目标分布，需处理离散精度、尾部和拒绝效率。
5. **密码学随机**：要求即使观察大量输出也难以预测后续值，接口和威胁模型不同于模拟PRNG。

这些单元构成一条依赖链。确定性生成器负责同一算法和种子产生同一序列，便于重放，也意味着普通生成器可预测。 种子负责初始化内部状态；测试应记录种子，生产安全密钥不应使用可猜种子。 周期负责有限状态序列最终重复；周期长只是必要条件，不保证统计质量。 分布变换负责从均匀随机数构造目标分布，需处理离散精度、尾部和拒绝效率。 密码学随机负责要求即使观察大量输出也难以预测后续值，接口和威胁模型不同于模拟PRNG。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：确定性生成器处理的对象是什么，种子保留了哪些信息，周期执行后哪些量应保持不变，分布变换依赖哪些前提，密码学随机用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

同一算法和种子产生同一序列，便于重放，也意味着普通生成器可预测。 因而第一张检查表记录定义和非例；初始化内部状态；测试应记录种子，生产安全密钥不应使用可猜种子。 第二张检查表记录表示变化；有限状态序列最终重复；周期长只是必要条件，不保证统计质量。 第三张检查表记录推导所保持的不变量。从均匀随机数构造目标分布，需处理离散精度、尾部和拒绝效率。 负责指出退化边界，要求即使观察大量输出也难以预测后续值，接口和威胁模型不同于模拟PRNG。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现确定性生成器和种子的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造分布变换的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“用固定种子的普通PRNG生成密码、令牌或密钥，把可复现性误当安全随机。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。游戏掉落可以用记录种子的普通PRNG重放争议局；密码重置令牌必须使用操作系统密码学随机源，且令牌还需足够熵、短时有效和一次性消费。把两个需求统一成一个random调用会同时伤害调试与安全。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写确定性生成器与种子的输入域和单位；推导栏逐步说明周期使用的规则；边界栏记录分布变换在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用密码学随机对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
x_{n+1}=(ax_n+c)\bmod m
$$

线性同余生成器的下一状态只依赖当前状态且状态总数有限，因此鸽巢原理保证最终进入循环。参数选择影响是否覆盖完整周期，但低位相关等结构缺陷仍可能存在，所以不能只用周期长度评价随机质量。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
class LCG:
    def __init__(self, seed):
        self.state = seed
    def next(self):
        self.state = (1664525 * self.state + 1013904223) % (2 ** 32)
        return self.state

a = [LCG(7).next() for _ in range(1)]
b = [LCG(7).next() for _ in range(1)]
assert a == b
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**确定性生成器**：同一算法和种子产生同一序列，便于重放，也意味着普通生成器可预测。

**种子**：初始化内部状态；测试应记录种子，生产安全密钥不应使用可猜种子。

**周期**：有限状态序列最终重复；周期长只是必要条件，不保证统计质量。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**分布变换**：从均匀随机数构造目标分布，需处理离散精度、尾部和拒绝效率。

**密码学随机**：要求即使观察大量输出也难以预测后续值，接口和威胁模型不同于模拟PRNG。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "确定性生成器到密码学随机的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "用固定种子的普通PRNG生成密码、令牌或密钥，把可复现性误当安全随机。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

游戏掉落可以用记录种子的普通PRNG重放争议局；密码重置令牌必须使用操作系统密码学随机源，且令牌还需足够熵、短时有效和一次性消费。把两个需求统一成一个random调用会同时伤害调试与安全。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("确定性生成器", "definition"),
    ("周期", "derivation"),
    ("密码学随机", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
