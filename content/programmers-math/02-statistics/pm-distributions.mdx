## 直觉引入

如果你统计 1000 个人的身高，画成直方图，会看到一个钟形曲线。这不是巧合——自然界中大量随机现象都服从正态分布。这就是为什么正态分布被称为「分布之王」。

不同的随机现象有不同的数学模型：抛硬币的结果服从二项分布，单位时间内的事件数服从泊松分布，连续测量值服从正态分布。选对分布模型，才能正确分析和预测随机现象。

## 概念讲解

### 二项分布

<Term def="二项分布描述 n 次独立伯努利试验中成功 k 次的概率：P(X=k) = C(n,k)·p^k·(1-p)^(n-k)">二项分布</Term>。抛 10 次硬币出现 3 次正面的概率 = $C(10,3) \cdot 0.5^{10} \approx 0.117$。

期望 $E[X] = np$，方差 $\text{Var}(X) = np(1-p)$。

### 正态分布

<Term def="正态分布是钟形对称分布，由均值 μ 和标准差 σ 决定：f(x) = (1/(σ√2π))·e^(-(x-μ)²/(2σ²))">正态分布</Term>是自然界最常见的分布。68-95-99.7 法则：

- 约 68% 数据在 $\mu \pm 1\sigma$ 内
- 约 95% 数据在 $\mu \pm 2\sigma$ 内
- 约 99.7% 数据在 $\mu \pm 3\sigma$ 内

### 泊松分布

<Term def="泊松分布描述单位时间/空间内稀有事件发生 k 次的概率：P(X=k) = (λ^k·e^(-λ))/k!">泊松分布</Term>。例如单位时间内收到邮件数、网站访问量、放射性衰变次数。期望和方差都等于 $\lambda$。

<Step title="第一步：判断试验类型">
如果是「n 次独立试验，每次成功概率 p」→ 二项分布。例如抛 10 次硬币、射击 20 次命中。如果是「单位时间/空间内稀有事件」→ 泊松分布。例如每小时接到电话数。如果是「连续测量值受多种因素影响」→ 正态分布。例如身高、考试成绩。
</Step>
<Step title="第二步：确定参数">
二项分布参数：n（试验次数）和 p（成功概率）。泊松分布参数：λ（单位时间平均事件数）。正态分布参数：μ（均值）和 σ（标准差）。参数确定后分布完全确定。
</Step>
<Step title="第三步：计算和验证">
用公式或查表计算概率。正态分布用 Z 分数 $Z = (x - \mu)/\sigma$ 转标准正态后查表。验证：模拟 10000 次试验，比较实际频率与理论概率是否吻合。

## 代码对照

```python
# 概率分布计算
from scipy import stats
import numpy as np

# 1. 二项分布：抛10次硬币，3次正面的概率
n, p = 10, 0.5
prob_3 = stats.binom.pmf(3, n, p)
print(f"P(X=3) = {prob_3:.4f}")  # 约 0.117

# 二项分布的期望和方差
print(f"E[X] = {n*p}")            # 5.0
print(f"Var(X) = {n*p*(1-p)}")    # 2.5

# 2. 正态分布：考试成绩 N(75, 10²)
mu, sigma = 75, 10
# P(X > 85) = P(Z > 1)
p_above_85 = 1 - stats.norm.cdf(85, mu, sigma)
print(f"P(X>85) = {p_above_85:.4f}")  # 约 0.1587

# 68-95-99.7 法则验证
within_1sigma = stats.norm.cdf(mu+sigma, mu, sigma) - stats.norm.cdf(mu-sigma, mu, sigma)
within_2sigma = stats.norm.cdf(mu+2*sigma, mu, sigma) - stats.norm.cdf(mu-2*sigma, mu, sigma)
print(f"±1σ: {within_1sigma:.4f}")  # 约 0.6827
print(f"±2σ: {within_2sigma:.4f}")  # 约 0.9545

# 3. 泊松分布：每小时接到5个电话，求接到3个的概率
lam = 5
prob_3_calls = stats.poisson.pmf(3, lam)
print(f"P(X=3) = {prob_3_calls:.4f}")  # 约 0.1404

# 泊松分布的期望和方差都等于 λ
print(f"E[X] = Var(X) = {lam}")  # 5
```

## 常见误区

<Callout type="trap">
**误区：认为所有数据都服从正态分布。**
正态分布确实常见（中心极限定理），但不是万能的。收入分布是右偏的（对数正态更合适），网络连接数是重尾的（幂律分布），等待时间是指数分布。盲目套正态分布会给出错误的概率估计。先用 Q-Q 图或假设检验验证分布类型。
</Callout>

<Callout type="trap">
**误区：泊松分布只是二项分布的近似。**
泊松分布可以作为二项分布的近似（当 n 大、p 小时），但它有独立的物理意义——描述单位时间/空间内独立稀有事件的发生次数。它只有一个参数 λ（等于期望和方差），比二项分布更简洁。放射性衰变、排队论、保险精算都以泊松分布为基础。
</Callout>

<Exercises>
**问题 1**：为什么正态分布被称为「分布之王」？

<Answer>
三个原因：(1) 中心极限定理——大量独立随机变量之和的分布趋近正态分布，无论原始分布是什么。这解释了为什么身高、考试成绩等受多种因素影响的量近似正态。(2) 统计推断的基础——t 分布、卡方分布、F 分布都从正态分布导出。(3) 数学性质优美——完全由 μ 和 σ 两个参数决定，线性变换保持正态性，便于解析处理。正态分布是统计学中最重要的分布。
</Answer>

**问题 2**：抛 10 次公平硬币，恰好 3 次正面的概率是多少？

<Answer>
二项分布 $P(X=3) = C(10,3) \times 0.5^3 \times 0.5^7 = 120 \times 0.5^{10} = 120/1024 \approx 0.117$。期望 $E[X] = np = 10 \times 0.5 = 5$，方差 $\text{Var}(X) = np(1-p) = 10 \times 0.5 \times 0.5 = 2.5$。
</Answer>
</Exercises>

<GlossaryItem term="二项分布">
n 次独立伯努利试验中成功 k 次的概率。P(X=k) = C(n,k)·p^k·(1-p)^(n-k)。期望 np，方差 np(1-p)。
</GlossaryItem>
<GlossaryItem term="正态分布">
钟形对称分布，由 μ 和 σ 决定。68-95-99.7 法则。中心极限定理使其成为最常见分布。
</GlossaryItem>
<GlossaryItem term="泊松分布">
单位时间/空间内稀有事件发生次数的分布。P(X=k) = λ^k·e^(-λ)/k!。期望和方差都等于 λ。
</GlossaryItem>
<GlossaryItem term="68-95-99.7 法则">
正态分布中约 68%/95%/99.7% 的数据落在 μ±1σ/2σ/3σ 范围内。快速判断数据是否异常的经验法则。
</GlossaryItem>
</Glossary>
