## 直觉引入

掷骰子的结果是不确定的——可能是 1 到 6 中任何一个。但如果我让你掷 1000 次骰子取平均，结果会非常接近 3.5。这个 3.5 就是「期望」——随机变量的长期平均值。

随机变量把概率论从「事件」提升到「数值」。不再问「是否下雨」，而是问「降雨量是多少」。期望和方差是描述随机变量的两个核心数字——期望告诉你「中心在哪」，方差告诉你「波动多大」。

## 概念讲解

### 随机变量

<Term def="随机变量是将随机试验的结果映射为数值的函数，分为离散型（取可数个值）和连续型（取连续区间）">随机变量</Term>。例如掷骰子的点数是离散型（1,2,3,4,5,6），人的身高是连续型。

### 期望

<Term def="期望是随机变量的加权平均，权重为各值的概率：E[X] = Σ x·P(X=x)">期望</Term>：

$$E[X] = \sum_{x} x \cdot P(X = x)$$

这个式子在说：每个可能值乘以其概率，加起来就是期望。掷骰子的期望 = $1 \times \frac{1}{6} + 2 \times \frac{1}{6} + \dots + 6 \times \frac{1}{6} = 3.5$。

期望具有线性性质：$E[aX + bY] = aE[X] + bE[Y]$（即使 X 和 Y 不独立）。

### 方差

<Term def="方差衡量随机变量偏离期望的程度：Var(X) = E[(X-E[X])²] = E[X²] - (E[X])²">方差</Term>：

$$\text{Var}(X) = E[(X - E[X])^2] = E[X^2] - (E[X])^2$$

方差的平方根是标准差。

## 代码对照

```python
# 随机变量的期望和方差
import numpy as np

# 1. 离散随机变量：掷骰子
values = [1, 2, 3, 4, 5, 6]
probs = [1/6] * 6

# 期望 E[X] = Σ x * P(x)
expectation = sum(v * p for v, p in zip(values, probs))
print(f"E[X] = {expectation}")  # 3.5

# 方差 Var(X) = E[X²] - (E[X])²
e_x2 = sum(v**2 * p for v, p in zip(values, probs))
variance = e_x2 - expectation**2
print(f"Var(X) = {variance:.4f}")  # 约 2.917
print(f"Std(X) = {variance**0.5:.4f}")  # 约 1.708

# 2. 期望的线性性质：E[2X+3] = 2E[X]+3
print(f"E[2X+3] = {2*expectation + 3}")  # 10.0

# 3. 蒙特卡洛模拟验证
samples = np.random.choice(values, size=1000000, p=probs)
print(f"模拟均值: {np.mean(samples):.4f}")      # 约 3.5
print(f"模拟方差: {np.var(samples):.4f}")        # 约 2.917
print(f"模拟标准差: {np.std(samples):.4f}")      # 约 1.708

# 4. 两个独立随机变量的方差：Var(X+Y) = Var(X) + Var(Y)
# 掷两个骰子的方差 = 2 * 单骰子方差
print(f"两骰子和的方差: {2 * variance:.4f}")     # 约 5.833
print(f"两骰子和的标准差: {(2*variance)**0.5:.4f}")  # 约 2.415
```

## 常见误区

<Callout type="trap">
**误区：认为期望就是最可能出现的值。**
期望是加权平均，不一定等于任何可能值。掷骰子的期望是 3.5，但骰子永远不可能掷出 3.5。期望是「长期平均值」的预测——掷很多次后，平均值趋近于期望。
</Callout>

<Callout type="trap">
**误区：认为 Var(X+Y) = Var(X) + Var(Y) 总是成立。**
只有当 X 和 Y 独立时才成立。一般情况下 $\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X,Y)$。如果 X 和 Y 正相关，方差更大；负相关，方差更小。这就是分散投资降低风险的数学原理。
</Callout>

<Exercises>
**问题 1**：为什么期望被称为「加权平均」？

<Answer>
因为期望 $E[X] = \sum x \cdot P(X=x)$ 中，每个可能值 $x$ 乘以权重 $P(X=x)$ 再求和。概率大的值对期望贡献大，概率小的贡献小。这与普通平均（等权重 1/n）不同——期望是按概率加权的平均。例如不公平骰子，6 的概率是 1/2，其余各 1/10，期望 = 1×0.1+2×0.1+3×0.1+4×0.1+5×0.1+6×0.5 = 4.5，偏向 6 因为 6 的权重大。
</Answer>

**问题 2**：计算掷骰子的期望和方差。

<Answer>
期望 $E[X] = (1+2+3+4+5+6)/6 = 21/6 = 3.5$。$E[X^2] = (1+4+9+16+25+36)/6 = 91/6 \approx 15.17$。方差 $\text{Var}(X) = E[X^2] - (E[X])^2 = 91/6 - (3.5)^2 = 91/6 - 12.25 = 91/6 - 73.5/6 = 17.5/6 \approx 2.917$。标准差 $\approx 1.708$。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="随机变量">
将随机试验结果映射为数值的函数。离散型取可数个值（如骰子点数），连续型取连续区间（如身高）。
</GlossaryItem>
<GlossaryItem term="期望">
随机变量的加权平均 E[X] = Σx·P(x)。长期平均值的预测。不一定等于任何可能值（如骰子期望 3.5）。
</GlossaryItem>
<GlossaryItem term="方差">
随机变量偏离期望的程度 Var(X) = E[X²] - (E[X])²。方差越大，随机变量的值越分散。
</GlossaryItem>
<GlossaryItem term="线性性质">
期望的线性性质：E[aX+bY] = aE[X]+bE[Y]，即使 X 和 Y 不独立也成立。但 Var(aX+bY) 需要 X、Y 独立才能简单相加。
</GlossaryItem>
</Glossary>
