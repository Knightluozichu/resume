## 直觉引入

给你 1000 个数字，你能一眼看出它们的特征吗？不能。但如果我告诉你「均值 75，标准差 10」，你立刻就知道大部分数据在 65-85 之间。这就是描述统计的力量——用几个数字概括大量数据的特征。

描述统计分两类：集中趋势（数据「中心」在哪）和离散程度（数据「分散」多大）。两者缺一不可——同样的均值 75，标准差 2 和标准差 20 描述的是完全不同的数据。

## 概念讲解

### 集中趋势

<Term def="均值是所有数据之和除以数据个数，是最常用的集中趋势度量">均值</Term>：$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$

<Term def="中位数是将数据排序后位于中间位置的值，对异常值不敏感">中位数</Term>：排序后第 $\lceil n/2 \rceil$ 个值。

<Term def="众数是数据中出现频率最高的值">众数</Term>：可能有多个（多峰分布）。

### 离散程度

<Term def="方差衡量数据偏离均值的程度：Var = (1/n)·Σ(xᵢ - x̄)²，标准差是方差的平方根">方差</Term>：

$$\sigma^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$

这个式子在说：每个数据点偏离均值多少，平方后求平均。平方是为了消除正负抵消。

### 异常值的影响

均值对异常值极其敏感——一个极端值可以大幅拉偏均值。中位数对异常值鲁棒。例如收入数据：少数亿万富翁会大幅拉高人均收入（均值），但中位数更能反映「普通人」的收入水平。

<Step title="第一步：计算集中趋势">
先算均值 $\bar{x}$、中位数和众数。如果三者接近，数据大致对称；如果均值 >> 中位数，右偏（有高端异常值）；如果均值 &lt;&lt; 中位数，左偏。
</Step>
<Step title="第二步：计算离散程度">
算方差和标准差。标准差与原始数据同单位，更直观。例如均值 75、标准差 10 意味着大部分数据在 65-85 之间（经验法则约 68%）。
</Step>
<Step title="第三步：检查异常值">
用箱线图或 3σ 准则检查异常值。如果存在异常值，报告中位数而非均值，或使用截尾均值。思考异常值的来源——是数据错误还是真实极端事件。
</Step>

## 代码对照

```python
# 描述统计实现
import statistics

data = [65, 70, 72, 68, 75, 80, 72, 68, 90, 72]

# 1. 集中趋势
mean = statistics.mean(data)
median = statistics.median(data)
mode = statistics.mode(data)
print(f"均值: {mean}")    # 73.2
print(f"中位数: {median}") # 72.0
print(f"众数: {mode}")     # 72

# 2. 离散程度
variance = statistics.variance(data)  # 样本方差（除以 n-1）
stdev = statistics.stdev(data)
print(f"方差: {variance:.2f}")   # 约 56.4
print(f"标准差: {stdev:.2f}")    # 约 7.51

# 3. 异常值对均值 vs 中位数的影响
data_with_outlier = data + [1000]  # 加一个极端异常值
print(f"加异常值后均值: {statistics.mean(data_with_outlier):.1f}")    # 165.6（大幅偏移）
print(f"加异常值后中位数: {statistics.median(data_with_outlier)}")     # 72.5（几乎不变）

# 4. 百分位数
import numpy as np
p25 = np.percentile(data, 25)  # Q1
p75 = np.percentile(data, 75)  # Q3
iqr = p75 - p25  # 四分位距
print(f"Q1={p25}, Q3={p75}, IQR={iqr}")  # IQR 衡量中间50%的离散
```

## 常见误区

<Callout type="trap">
**误区：报告数据时只看均值。**
均值对异常值极其敏感。收入数据中，少数亿万富翁让人均收入虚高，但大多数人的收入远低于均值。报告收入时应同时给出中位数。Anscombe 四重奏展示了四组均值、方差相同但分布完全不同的数据——仅看摘要统计量会被误导。
</Callout>

<Callout type="trap">
**误区：方差除以 n 还是 n-1 无所谓。**
有所谓。除以 n 是总体方差，除以 n-1 是样本方差（无偏估计）。用样本估计总体时，除以 n 会系统性地低估方差（因为样本集中在样本均值附近比集中在总体均值附近更紧）。除以 n-1 修正了这个偏差。
</Callout>

<Exercises>
**问题 1**：为什么需要多种集中趋势度量（均值、中位数、众数）？

<Answer>
因为不同的度量适用于不同的数据分布和场景。均值适合对称分布、无异常值的数据，它利用了所有数据点的信息。中位数适合有异常值或偏态分布的数据，因为它对极端值不敏感。众数适合分类数据或离散数据，能揭示最典型值。例如收入数据右偏（少数极高收入），均值远高于中位数，此时中位数更能反映「典型收入」。只用均值会掩盖分布的偏态。
</Answer>

**问题 2**：数据 [65, 70, 72, 68, 75, 80, 72, 68, 90, 72] 的均值和中位数各是多少？

<Answer>
均值 = (65+70+72+68+75+80+72+68+90+72)/10 = 732/10 = 73.2。中位数：排序后 [65, 68, 68, 70, 72, 72, 72, 75, 80, 90]，10 个数据取第 5 和第 6 个的平均 = (72+72)/2 = 72。均值 > 中位数，说明数据略右偏（90 是偏高端的值）。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="均值">
所有数据之和除以数据个数。最常用的集中趋势度量，但对异常值敏感。
</GlossaryItem>
<GlossaryItem term="中位数">
排序后中间位置的值。对异常值鲁棒，适合偏态分布。收入数据用中位数更合理。
</GlossaryItem>
<GlossaryItem term="方差">
数据偏离均值的平方的平均。衡量离散程度。样本方差除以 n-1（无偏估计）。
</GlossaryItem>
<GlossaryItem term="标准差">
方差的平方根。与原始数据同单位，更直观。经验法则：约 68% 数据在均值±1标准差内。
</GlossaryItem>
</Glossary>
