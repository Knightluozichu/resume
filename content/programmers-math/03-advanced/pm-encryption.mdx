## 直觉引入

你想给朋友寄一封密信，但快递员会看到信封。怎么办？你和朋友约定：她挂一把开锁的公钥在门口（任何人都能锁），但只有她有私钥能开锁。这就是非对称加密的核心思想。

RSA 是最著名的非对称加密算法。它的数学基础是模运算和欧拉定理——加密是 $c = m^e \mod n$，解密是 $m = c^d \mod n$。看似简单的幂模运算，安全性却建立在「大数分解很困难」这一数论难题上。

## 概念讲解

### 模运算

<Term def="模运算是计算整数除法余数的运算，满足 (a·b) mod n = ((a mod n)·(b mod n)) mod n">模运算</Term>是密码学的数学基础。关键性质：模运算对加法、减法、乘法封闭，但不总是对除法封闭（需要逆元）。

### 欧拉函数与费马小定理

<Term def="欧拉函数 φ(n) 是小于 n 且与 n 互素的正整数个数">欧拉函数</Term>：若 $n = pq$（$p,q$ 为素数），则 $\varphi(n) = (p-1)(q-1)$。

<Term def="欧拉定理：若 gcd(a,n)=1，则 a^φ(n) ≡ 1 (mod n)">欧拉定理</Term>是 RSA 的理论基石。费马小定理是其特例（$n$ 为素数时 $a^{p-1} \equiv 1 \pmod{p}$）。

### RSA 加密

<Term def="RSA 是基于大数分解困难性的非对称加密算法：公钥(e,n)加密，私钥(d,n)解密">RSA</Term>流程：
1. 选两个大素数 $p, q$，计算 $n = pq$
2. 计算 $\varphi(n) = (p-1)(q-1)$
3. 选 $e$ 与 $\varphi(n)$ 互素（公钥指数）
4. 求 $d = e^{-1} \mod \varphi(n)$（私钥指数）
5. 加密：$c = m^e \mod n$，解密：$m = c^d \mod n$

正确性依赖欧拉定理：$c^d = m^{ed} = m^{1 + k\varphi(n)} = m \cdot (m^{\varphi(n)})^k \equiv m \cdot 1^k = m \pmod{n}$。

</Step>
<Step title="第三步：解密">
收到密文 $c = 2790$。解密：$m = c^d \mod n = 2790^{2753} \mod 3233 = 65$。恢复出原文 65。正确性由欧拉定理保证：$m^{ed} \equiv m^{1+k\varphi(n)} \equiv m \pmod{n}$。
</Step>

## 代码对照

```python
# RSA 加密演示（用小素数演示原理）
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a

def mod_inverse(e, phi):
    # 扩展欧几里得算法求模逆元
    def ext_gcd(a, b):
        if a == 0:
            return b, 0, 1
        g, x, y = ext_gcd(b % a, a)
        return g, y - (b // a) * x, x
    g, x, _ = ext_gcd(e, phi)
    return x % phi if g == 1 else None

def mod_pow(base, exp, mod):
    # 快速模幂（平方乘法）
    result = 1
    base %= mod
    while exp > 0:
        if exp % 2:
            result = (result * base) % mod
        exp //= 2
        base = (base * base) % mod
    return result

# 1. 生成密钥
p, q = 61, 53
n = p * q              # 3233
phi = (p-1) * (q-1)    # 3120
e = 17                 # 公钥指数
d = mod_inverse(e, phi) # 2753 私钥指数
print(f"公钥: ({e}, {n})")
print(f"私钥: ({d}, {n})")

# 2. 加密
m = 65  # 明文
c = mod_pow(m, e, n)
print(f"加密: {m} -> {c}")  # 65 -> 2790

# 3. 解密
m_dec = mod_pow(c, d, n)
print(f"解密: {c} -> {m_dec}")  # 2790 -> 65

# 安全性：已知 n=3233 容易分解为 61×53
# 但如果 n 是 2048 位（约 600 位十进制数），
# 分解它需要数千年的计算时间
```

## 常见误区

<Callout type="trap">
**误区：认为 RSA 加密是因为算法不可逆才安全。**
RSA 的加密算法 $c = m^e \mod n$ 是完全公开的。安全性不在于算法保密，而在于「没有私钥 $d$ 就无法在合理时间内解密」。而求 $d$ 需要知道 $\varphi(n)$，求 $\varphi(n)$ 需要分解 $n = pq$。大数分解目前没有多项式时间算法，这就是 RSA 的安全基础。
</Callout>

<Callout type="trap">
**误区：RSA 可以加密任意大小的数据。**
RSA 加密的明文 $m$ 必须小于 $n$。如果 $m \geq n$，解密无法恢复原值。实际应用中，RSA 不直接加密大数据，而是加密一个对称密钥（如 AES 密钥），再用对称加密加密数据。这叫「混合加密」。
</Callout>

<Exercises>
**问题 1**：为什么 RSA 加密依赖大数分解的困难性？

<Answer>
RSA 的安全性在于：已知公钥 $(e, n)$，无法在合理时间内求出私钥 $d$。求 $d$ 需要知道 $\varphi(n)$，而 $\varphi(n) = (p-1)(q-1)$ 需要知道 $p$ 和 $q$。从 $n = pq$ 反推 $p, q$ 就是大数分解。目前没有多项式时间的大数分解算法——2048 位的 $n$ 分解需要数千年的计算。如果有人发明了快速分解算法（如量子计算机的 Shor 算法），RSA 就不再安全。
</Answer>

**问题 2**：用 p=61, q=53, e=17，计算 RSA 的私钥 d 并验证加解密。

<Answer>
$n = 61 \times 53 = 3233$。$\varphi(n) = 60 \times 52 = 3120$。求 $d$ 使 $17d \equiv 1 \pmod{3120}$。用扩展欧几里得算法：$d = 2753$（验证 $17 \times 2753 = 46801 = 15 \times 3120 + 1$ ✓）。加密 $m=65$：$c = 65^{17} \mod 3233 = 2790$。解密：$m = 2790^{2753} \mod 3233 = 65$ ✓。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="模运算">
计算整数除法余数的运算。对加法、乘法封闭，是密码学的数学基础。
</GlossaryItem>
<GlossaryItem term="欧拉函数">
φ(n) 是小于 n 且与 n 互素的正整数个数。n=pq 时 φ(n)=(p-1)(q-1)。RSA 的核心。
</GlossaryItem>
<GlossaryItem term="欧拉定理">
若 gcd(a,n)=1，则 a^φ(n) ≡ 1 (mod n)。RSA 解密正确性的理论保证。
</GlossaryItem>
<GlossaryItem term="RSA">
基于大数分解困难性的非对称加密。公钥加密 c=m^e mod n，私钥解密 m=c^d mod n。
