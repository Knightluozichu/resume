## 直觉引入

学完全书，回顾四大板块的递进关系：数学基础（0和1）提供了表示工具，排列组合提供了计数工具，概率论提供了推理工具，统计学提供了分析工具，递归和加密是综合应用。

全书的核心方法论是：**从直觉到形式化到代码验证**。先用日常语言建立直觉，再用数学语言精确定义，最后用代码验证——这三步循环是程序员学习数学的最佳路径。

## 概念讲解

### 全书知识网络

<Term def="数学基础（0和1、二进制、布尔代数）是理解计算机表示和处理信息的起点">数学基础</Term>是全书的根。不理解二进制，就无法理解位运算、权限管理、数据编码。

<Term def="排列组合是概率论的基础——算不对「总情况数」和「有利情况数」，概率就算不对">排列组合</Term>是计数工具。乘法原理、加法原理、容斥原理构成计数问题的完整方法论。

<Term def="概率论（古典概率、条件概率、贝叶斯定理）是量化不确定性的数学工具">概率论</Term>从排列组合发展而来。贝叶斯定理的「从结果推原因」是机器学习的数学基础。

<Term def="统计学（描述统计、随机变量、分布）是从数据中提取信息的工具">统计学</Term>把概率论应用于实际数据分析。期望和方差是描述随机变量的核心数字。

### 核心方法论

全书贯穿三步循环：**直觉 → 形式化 → 代码验证**。

## 代码对照

```python
# 全书知识综合应用：贝叶斯垃圾邮件过滤
import re
from collections import defaultdict

class NaiveBayesSpamFilter:
    # 综合运用：概率论（贝叶斯）+ 统计（频率估计）
    def __init__(self):
        self.spam_word_count = defaultdict(int)
        self.ham_word_count = defaultdict(int)
        self.spam_total = 0
        self.ham_total = 0

    def train(self, text, is_spam):
        words = re.findall(r'\w+', text.lower())
        for w in words:
            if is_spam:
                self.spam_word_count[w] += 1
                self.spam_total += 1
            else:
                self.ham_word_count[w] += 1
                self.ham_total += 1

    def predict(self, text):
        words = re.findall(r'\w+', text.lower())
        # 贝叶斯：P(spam|words) ∝ P(words|spam) * P(spam)
        log_spam = 0
        log_ham = 0
        for w in words:
            # 拉普拉斯平滑
            p_spam = (self.spam_word_count[w] + 1) / (self.spam_total + len(self.spam_word_count) + 1)
            p_ham = (self.ham_word_count[w] + 1) / (self.ham_total + len(self.ham_word_count) + 1)
            log_spam += __import__('math').log(p_spam)
            log_ham += __import__('math').log(p_ham)
        return log_spam > log_ham

# 训练
filter = NaiveBayesSpamFilter()
filter.train("free money now", True)
filter.train("hello team meeting", False)
print(f"'free money' is spam: {filter.predict('free money')}")  # True
print(f"'team meeting' is spam: {filter.predict('team meeting')}")  # False
```

## 常见误区

<Callout type="trap">
**误区：学完程序员的数学就够用了。**
这个系列是入门，覆盖了离散数学的基础。但机器学习需要线性代数和微积分，密码学需要更深的数论，性能分析需要概率论的高级内容。这个系列是起点，不是终点。
</Callout>

<Callout type="trap">
**误区：数学知识学了不用就会忘。**
数学思维比数学知识更重要。即使忘了贝叶斯公式的具体形式，「从结果推原因」的思维方式一旦内化就不会忘。代码验证是巩固记忆的最佳方式——用 Python 实现贝叶斯过滤器，比背十遍公式更有效。
</Callout>

<Exercises>
**问题 1**：程序员的数学核心方法论是什么？

<Answer>
全书的核心方法论是三步循环：(1) 直觉——用日常语言和类比建立概念直觉（如「0是占位符」「期望是加权平均」）；(2) 形式化——用数学语言精确定义（如 E[X] = Σx·P(x)）；(3) 代码验证——用 Python 实现验证理论（如蒙特卡洛模拟验证概率）。这三步循环确保既理解了「为什么」又掌握了「怎么做」。
</Answer>

**问题 2**：举例说明排列组合如何支撑概率论。

<Answer>
古典概率 P(A) = 有利事件数 / 总事件数。计算这两个数需要排列组合。例如「从52张牌中抽5张，全是红心的概率」：有利 = C(13,5)（13张红心选5张），总 = C(52,5)（52张选5张）。P = C(13,5)/C(52,5) = 1287/2598960 ≈ 0.000495。不掌握排列组合就无法正确计数，概率自然算不对。
</Answer>
