## 直觉引入

站在两面镜子之间，你会看到无限重复的自己——这就是递归的直觉。函数调用自己，每次缩小问题规模，直到触达基准情形。递归是一种思维方式：把大问题拆成「同类型的小问题」加「一步组合」。

递推关系是递归的数学表达：$T(n) = aT(n/b) + f(n)$。求解它就能知道递归算法的复杂度。主定理是求解分治递推的万能公式——但理解推导过程比记公式更重要。

## 概念讲解

### 递归与递推

<Term def="递归是函数直接或间接调用自身的编程技术，每次调用缩小问题规模直到基准情形">递归</Term>：$\text{fact}(n) = n \times \text{fact}(n-1)$，$\text{fact}(0) = 1$。

<Term def="递推关系是用较小输入上的值定义较大输入的数学等式，如 T(n) = 2T(n/2) + n">递推关系</Term>是递归的数学模型。

### 求解方法

<Term def="主定理是求解 T(n) = aT(n/b) + f(n) 型递推的公式化方法，分三种情况比较 f(n) 与 n^(log_b a)">主定理</Term>：

比较 $f(n)$ 与 $n^{\log_b a}$：
1. 若 $f(n) = O(n^{\log_b a - \epsilon})$，则 $T(n) = \Theta(n^{\log_b a})$
2. 若 $f(n) = \Theta(n^{\log_b a})$，则 $T(n) = \Theta(n^{\log_b a} \log n)$
3. 若 $f(n) = \Omega(n^{\log_b a + \epsilon})$，则 $T(n) = \Theta(f(n))$

### 经典例子

归并排序：$T(n) = 2T(n/2) + O(n)$，$a=2, b=2, f(n)=n$，$n^{\log_2 2} = n$，情况 2，$T(n) = O(n \log n)$。

## 代码对照

```python
# 递归与递推关系

# 1. 递归实现：阶乘（简单递推 T(n) = T(n-1) + O(1)）
def fact(n):
    if n <= 1:
        return 1
    return n * fact(n - 1)  # T(n) = T(n-1) + O(1) => O(n)

# 2. 递归实现：Fibonacci（T(n) = 2T(n-1) + O(1) => O(2^n) 糟糕！）
def fib_recursive(n):
    if n <= 1:
        return n
    return fib_recursive(n-1) + fib_recursive(n-2)

# 3. 递推实现（动态规划）：Fibonacci O(n)
def fib_dp(n):
    if n <= 1:
        return n
    a, b = 0, 1
    for _ in range(2, n + 1):
        a, b = b, a + b
    return b

# 4. 分治递归：归并排序 T(n) = 2T(n/2) + O(n) => O(n log n)
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])    # T(n/2)
    right = merge_sort(arr[mid:])   # T(n/2)
    return merge(left, right)       # O(n)

def merge(a, b):
    result = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i]); i += 1
        else:
            result.append(b[j]); j += 1
    result.extend(a[i:])
    result.extend(b[j:])
    return result

# 5. 主定理验证
# T(n) = 2T(n/2) + n  =>  a=2, b=2, n^(log_2 2) = n = f(n)  =>  情况2  =>  O(n log n)
# T(n) = 4T(n/2) + n  =>  a=4, b=2, n^(log_2 4) = n² > f(n)=n  =>  情况1  =>  O(n²)
# T(n) = 2T(n/2) + n² =>  a=2, b=2, n^1 < f(n)=n²  =>  情况3  =>  O(n²)
```

## 常见误区

<Callout type="trap">
**误区：递归一定比迭代慢，所以不该用递归。**
朴素递归确实有重复计算的代价（如 Fibonacci 的 $O(2^n)$），但可以通过记忆化或动态规划优化到 $O(n)$。更重要的是，递归往往比迭代更直观——树遍历、分治算法用递归写更清晰。尾递归优化还能让递归不额外消耗栈空间。
</Callout>

<Callout type="trap">
**误区：主定理能解所有递推关系。**
主定理只适用于 $T(n) = aT(n/b) + f(n)$ 的分治递推。对于 $T(n) = T(n-1) + T(n-2)$（Fibonacci 型）或 $T(n) = T(n-1) + n$（渐进型），需要用递归树、生成函数或代入法。不理解推导原理，遇到变体就会出错。
</Callout>

<Exercises>
**问题 1**：为什么递归有时比迭代更直观但效率更低？

<Answer>
递归更直观是因为它直接映射了问题的递归结构——树遍历、分治、回溯用递归写更清晰，代码更短。效率更低是因为：(1) 函数调用开销（压栈、跳转、返回）；(2) 重复计算（如朴素 Fibonacci 的 T(n)=2T(n-1) 导致 O(2^n)）；(3) 栈空间消耗（最坏 O(n) 栈帧）。优化方法：记忆化、动态规划（转递推）、尾递归优化。
</Answer>

**问题 2**：用主定理求 T(n) = 4T(n/2) + n 的复杂度。

<Answer>
参数：$a=4, b=2, f(n) = n$。计算 $n^{\log_b a} = n^{\log_2 4} = n^2$。比较：$f(n) = n = O(n^{2-1}) = O(n^{2-\epsilon})$，$\epsilon = 1 > 0$，属于情况 1。因此 $T(n) = \Theta(n^{\log_b a}) = \Theta(n^2)$。子问题太多（4 个），合并代价太小（$n$），总代价由叶子节点主导。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="递归">
函数调用自身的编程技术。每次调用缩小问题规模直到基准情形。直观但有调用开销和重复计算风险。
</GlossaryItem>
<GlossaryItem term="递推关系">
用较小输入上的值定义较大输入的数学等式。是递归算法复杂度分析的数学工具。
</GlossaryItem>
<GlossaryItem term="主定理">
求解 T(n)=aT(n/b)+f(n) 型分治递推的公式。比较 f(n) 与 n^(log_b a) 分三种情况。
</GlossaryItem>
<GlossaryItem term="分治">
将问题分成独立子问题分别求解再合并的策略。归并排序、快速排序是经典例子。
</GlossaryItem>
</Glossary>
