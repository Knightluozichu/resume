## 原书章节定位

本页对应权威目录中的“第4章 特征值、对角化与Jordan标准形”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：特征向量是在映射下方向不变的轴，特征值给出该轴的缩放。对角化把耦合系统变为独立标量模式；不可对角化时Jordan块揭示额外多项式增长。离散系统稳定性由特征值模控制。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **特征值**：沿某特殊方向的缩放因子，可能为复数并控制迭代增长或旋转。
2. **特征向量**：非零且映射后方向保持的向量，为系统提供自然坐标轴。
3. **对角化**：拥有足够独立特征向量时换基到特征坐标，使矩阵变成对角。
4. **稳定性**：离散迭代中所有特征值模小于1通常衰减，大于1的模式会增长。
5. **Jordan标准形**：特征向量不足时用广义特征向量形成块，幂中出现n等多项式因子。

这些单元构成一条依赖链。特征值负责沿某特殊方向的缩放因子，可能为复数并控制迭代增长或旋转。 特征向量负责非零且映射后方向保持的向量，为系统提供自然坐标轴。 对角化负责拥有足够独立特征向量时换基到特征坐标，使矩阵变成对角。 稳定性负责离散迭代中所有特征值模小于1通常衰减，大于1的模式会增长。 Jordan标准形负责特征向量不足时用广义特征向量形成块，幂中出现n等多项式因子。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：特征值处理的对象是什么，特征向量保留了哪些信息，对角化执行后哪些量应保持不变，稳定性依赖哪些前提，Jordan标准形用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

沿某特殊方向的缩放因子，可能为复数并控制迭代增长或旋转。 因而第一张检查表记录定义和非例；非零且映射后方向保持的向量，为系统提供自然坐标轴。 第二张检查表记录表示变化；拥有足够独立特征向量时换基到特征坐标，使矩阵变成对角。 第三张检查表记录推导所保持的不变量。离散迭代中所有特征值模小于1通常衰减，大于1的模式会增长。 负责指出退化边界，特征向量不足时用广义特征向量形成块，幂中出现n等多项式因子。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现特征值和特征向量的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造稳定性的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“认为每个方阵都能对角化；重根且独立特征向量不足时需要Jordan结构。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。推荐系统的状态更新若每轮乘转移矩阵，最大特征值和对应向量决定长期分布。归一化可防数值发散，但若矩阵随时间变化或存在多个单位模模式，单一稳态解释不再成立，必须检查谱间隙和周期性。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写特征值与特征向量的输入域和单位；推导栏逐步说明对角化使用的规则；边界栏记录稳定性在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用Jordan标准形对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
Av=\lambda v,\qquad A=S\Lambda S^{-1},\qquad A^n=S\Lambda^nS^{-1}
$$

若A等于S Lambda S逆，则A平方中间的S逆S抵消，推广到A的n次方只需把对角元素各自乘方。长期行为由绝对值最大的特征值主导；Jordan块还会乘上n的幂，因此单位模也可能不稳定。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
def power_iteration(A, steps=30):
    v = [1.0] * len(A)
    for _ in range(steps):
        w = [sum(row[j] * v[j] for j in range(len(v))) for row in A]
        scale = max(abs(x) for x in w)
        v = [x / scale for x in w]
    return scale, v

value, vector = power_iteration([[2, 0], [0, 1]])
assert abs(value - 2) < 1e-6
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**特征值**：沿某特殊方向的缩放因子，可能为复数并控制迭代增长或旋转。

**特征向量**：非零且映射后方向保持的向量，为系统提供自然坐标轴。

**对角化**：拥有足够独立特征向量时换基到特征坐标，使矩阵变成对角。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。

## 边界与失败模式

**稳定性**：离散迭代中所有特征值模小于1通常衰减，大于1的模式会增长。

**Jordan标准形**：特征向量不足时用广义特征向量形成块，幂中出现n等多项式因子。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "特征值到Jordan标准形的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "认为每个方阵都能对角化；重根且独立特征向量不足时需要Jordan结构。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```
