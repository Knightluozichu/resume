## 原书章节定位

本页对应权威目录中的“第3章 计算机上的计算（一）：LU分解”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：LU分解把一般矩阵拆成下三角和上三角，复杂求解转为两次代入。对同一系数矩阵的多个右端项，分解成本只付一次；部分主元选取消除零主元并改善数值稳定性。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **高斯消元**：用行操作逐列消去下方元素，把系统化为上三角形式。
2. **LU分解**：把消元乘子存入L、消元结果存入U，复用一次消元过程。
3. **前向后向代入**：三角系统按依赖顺序逐项求解，成本为平方量级。
4. **部分主元**：每列选择绝对值较大的候选行交换到主元位置，避免除零并降低误差。
5. **残差**：用b减Ax检查方程满足程度；小残差仍需结合条件数判断解误差。

这些单元构成一条依赖链。高斯消元负责用行操作逐列消去下方元素，把系统化为上三角形式。 LU分解负责把消元乘子存入L、消元结果存入U，复用一次消元过程。 前向后向代入负责三角系统按依赖顺序逐项求解，成本为平方量级。 部分主元负责每列选择绝对值较大的候选行交换到主元位置，避免除零并降低误差。 残差负责用b减Ax检查方程满足程度；小残差仍需结合条件数判断解误差。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：高斯消元处理的对象是什么，LU分解保留了哪些信息，前向后向代入执行后哪些量应保持不变，部分主元依赖哪些前提，残差用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

用行操作逐列消去下方元素，把系统化为上三角形式。 因而第一张检查表记录定义和非例；把消元乘子存入L、消元结果存入U，复用一次消元过程。 第二张检查表记录表示变化；三角系统按依赖顺序逐项求解，成本为平方量级。 第三张检查表记录推导所保持的不变量。每列选择绝对值较大的候选行交换到主元位置，避免除零并降低误差。 负责指出退化边界，用b减Ax检查方程满足程度；小残差仍需结合条件数判断解误差。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现高斯消元和LU分解的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造部分主元的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“在主元很小或为零时仍直接相除，导致溢出或严重舍入误差。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。电路仿真每个时间步可能共享同一拓扑矩阵却有不同激励向量。缓存带主元的LU分解能显著减少重复工作，但只在矩阵未变时有效；元件状态改变后必须失效缓存，并记录残差监控数值退化。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写高斯消元与LU分解的输入域和单位；推导栏逐步说明前向后向代入使用的规则；边界栏记录部分主元在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用残差对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
PA=LU,\qquad Ly=Pb,\quad Ux=y
$$

高斯消元第k步用主元行的倍数消去下方元素，乘子m_ik记录在L对应位置。所有消元后得到U；行交换汇总为置换矩阵P，所以PA等于LU。求解先应用置换，再解两个三角系统。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
def forward_substitution(L, b):
    y = []
    for i, row in enumerate(L):
        value = b[i] - sum(row[j] * y[j] for j in range(i))
        y.append(value / row[i])
    return y

assert forward_substitution([[1, 0], [2, 1]], [3, 7]) == [3.0, 1.0]
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**高斯消元**：用行操作逐列消去下方元素，把系统化为上三角形式。

**LU分解**：把消元乘子存入L、消元结果存入U，复用一次消元过程。

**前向后向代入**：三角系统按依赖顺序逐项求解，成本为平方量级。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。

## 边界与失败模式

**部分主元**：每列选择绝对值较大的候选行交换到主元位置，避免除零并降低误差。

**残差**：用b减Ax检查方程满足程度；小残差仍需结合条件数判断解误差。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "高斯消元到残差的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "在主元很小或为零时仍直接相除，导致溢出或严重舍入误差。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

电路仿真每个时间步可能共享同一拓扑矩阵却有不同激励向量。缓存带主元的LU分解能显著减少重复工作，但只在矩阵未变时有效；元件状态改变后必须失效缓存，并记录残差监控数值退化。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("高斯消元", "definition"),
    ("前向后向代入", "derivation"),
    ("残差", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。

## 常见误区

<Callout type="trap" title="模型前提被省略">在主元很小或为零时仍直接相除，导致溢出或严重舍入误差。 修复方式是回到对象、输入域和不变量，写出能推翻当前结论的最小反例。</Callout>

<Callout type="trap" title="数值等于证明">只比较求出的x，不计算残差、条件数和分解重建误差。 有限样例、模拟和浮点结果只能提供实现证据；普遍结论仍需要推导，统计结论还需要不确定性说明。</Callout>
