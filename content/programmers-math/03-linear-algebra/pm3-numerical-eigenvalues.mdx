## 原书章节定位

本页对应权威目录中的“第5章 计算机上的计算（二）：特征值算法”，不是把多本数学书的相近主题拼成一章。原书在这里要解决的中心问题是：五次以上一般多项式没有统一根式公式，数值特征值计算必须通过迭代。幂法寻找主特征对，QR迭代逐步显露全部特征值；停止条件、缩放、移位和残差决定答案是否可信。 阅读时先辨认对象和关系，再看符号如何压缩这些关系，最后检查程序是否保持同一语义。

### 核心单元索引

1. **幂法**：重复乘矩阵并归一化，在主特征值唯一且初始向量有投影时收敛。
2. **Rayleigh商**：用v转置Av除以v转置v估计与v对应的特征值。
3. **QR分解**：把矩阵分成正交Q与上三角R，为稳定迭代和最小二乘提供基础。
4. **QR迭代**：反复QR分解并交换RQ，保持相似性并趋向上三角或准上三角。
5. **特征残差**：范数Av减lambda v直接衡量特征对满足程度，是停止与验收证据。

这些单元构成一条依赖链。幂法负责重复乘矩阵并归一化，在主特征值唯一且初始向量有投影时收敛。 Rayleigh商负责用v转置Av除以v转置v估计与v对应的特征值。 QR分解负责把矩阵分成正交Q与上三角R，为稳定迭代和最小二乘提供基础。 QR迭代负责反复QR分解并交换RQ，保持相似性并趋向上三角或准上三角。 特征残差负责范数Av减lambda v直接衡量特征对满足程度，是停止与验收证据。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：幂法处理的对象是什么，Rayleigh商保留了哪些信息，QR分解执行后哪些量应保持不变，QR迭代依赖哪些前提，特征残差用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

重复乘矩阵并归一化，在主特征值唯一且初始向量有投影时收敛。 因而第一张检查表记录定义和非例；用v转置Av除以v转置v估计与v对应的特征值。 第二张检查表记录表示变化；把矩阵分成正交Q与上三角R，为稳定迭代和最小二乘提供基础。 第三张检查表记录推导所保持的不变量。反复QR分解并交换RQ，保持相似性并趋向上三角或准上三角。 负责指出退化边界，范数Av减lambda v直接衡量特征对满足程度，是停止与验收证据。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现幂法和Rayleigh商的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造QR迭代的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“迭代次数到了就返回结果，不检查残差、正交性或收敛停滞。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。主成分分析不应显式构造巨大稠密协方差矩阵再求全部谱。若只需前几个方向，可对中心化数据使用迭代SVD或随机方法；验收要报告解释方差、正交误差、残差和不同种子的稳定性。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写幂法与Rayleigh商的输入域和单位；推导栏逐步说明QR分解使用的规则；边界栏记录QR迭代在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用特征残差对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
A_k=Q_kR_k,\qquad A_{k+1}=R_kQ_k=Q_k^TA_kQ_k
$$

QR迭代中A下一步等于R Q，又因A等于Q R，所以R Q等于Q转置A Q。新旧矩阵相似，拥有相同特征值；迭代目标不是改变答案，而是把矩阵变成更容易读取特征值的形态。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
def rayleigh(A, v):
    Av = [sum(row[j] * v[j] for j in range(len(v))) for row in A]
    return sum(x * y for x, y in zip(v, Av)) / sum(x * x for x in v)

A = [[3.0, 0.0], [0.0, 1.0]]
assert rayleigh(A, [1.0, 0.0]) == 3.0
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**幂法**：重复乘矩阵并归一化，在主特征值唯一且初始向量有投影时收敛。

**Rayleigh商**：用v转置Av除以v转置v估计与v对应的特征值。

**QR分解**：把矩阵分成正交Q与上三角R，为稳定迭代和最小二乘提供基础。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。

## 边界与失败模式

**QR迭代**：反复QR分解并交换RQ，保持相似性并趋向上三角或准上三角。

**特征残差**：范数Av减lambda v直接衡量特征对满足程度，是停止与验收证据。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "幂法到特征残差的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "迭代次数到了就返回结果，不检查残差、正交性或收敛停滞。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 常见误区

<Callout type="trap" title="模型前提被省略">迭代次数到了就返回结果，不检查残差、正交性或收敛停滞。 修复方式是回到对象、输入域和不变量，写出能推翻当前结论的最小反例。</Callout>

<Callout type="trap" title="数值等于证明">用幂法寻找全部特征值，忽略它主要收敛到模最大的可见特征模式。 有限样例、模拟和浮点结果只能提供实现证据；普遍结论仍需要推导，统计结论还需要不确定性说明。</Callout>
