### 核心单元索引

1. **核空间**：被映射到零的输入方向；非零核表示不同输入可能产生同一输出。
2. **像空间**：所有可达输出组成的子空间，维数就是矩阵秩。
3. **秩**：独立列或独立行的数量，表示映射实际保留的独立信息维数。
4. **逆矩阵**：撤销双射线性映射；存在性等价于方阵满秩和零核。
5. **最小二乘与正则化**：无精确解或病态时最小化残差，并用惩罚项限制不稳定方向。

这些单元构成一条依赖链。核空间负责被映射到零的输入方向；非零核表示不同输入可能产生同一输出。 像空间负责所有可达输出组成的子空间，维数就是矩阵秩。 秩负责独立列或独立行的数量，表示映射实际保留的独立信息维数。 逆矩阵负责撤销双射线性映射；存在性等价于方阵满秩和零核。 最小二乘与正则化负责无精确解或病态时最小化残差，并用惩罚项限制不稳定方向。 如果跳过定义直接套公式，计算可能正确，却无法判断结论何时失效。

## 从问题开始

先把“会计算”改写成五个可反驳的问题：核空间处理的对象是什么，像空间保留了哪些信息，秩执行后哪些量应保持不变，逆矩阵依赖哪些前提，最小二乘与正则化用什么观测验收？回答时必须给出对象集合、输入域、单位或概率机制。若这些信息缺失，同一个符号可能在相邻步骤中悄悄换义，后面的精确计算也无法挽救模型。

被映射到零的输入方向；非零核表示不同输入可能产生同一输出。 因而第一张检查表记录定义和非例；所有可达输出组成的子空间，维数就是矩阵秩。 第二张检查表记录表示变化；独立列或独立行的数量，表示映射实际保留的独立信息维数。 第三张检查表记录推导所保持的不变量。撤销双射线性映射；存在性等价于方阵满秩和零核。 负责指出退化边界，无精确解或病态时最小化残差，并用惩罚项限制不稳定方向。 则把数学结论翻译成可观察证据。五张表共同回答“为什么这一步可以做”，而不只回答“怎么算”。

$$
\mathcal M:X\longrightarrow Y,\qquad x\mapsto y
$$

这里的映射符号不是说所有章节都线性，而是要求明确输入集合X、输出集合Y和模型M。离散章节的M可以是逻辑规则或递归，概率章节可以是分布或条件化，线性代数章节则常由矩阵实现。模型改变时，旧结论必须重新验收。

## 反例推演

从正常样例开始：选择一个能同时出现核空间和像空间的最小输入，手算中间状态；随后把规模减到零或一，检查定义是否仍有意义；再制造逆矩阵的退化情形，观察结果是不存在、不唯一、偏差增大还是数值不稳定。最后使用“求解线性方程默认先显式计算逆矩阵，增加计算量和数值误差；应优先直接分解求解。”作为反例方向，指出最先失效的定义或等式。

反例不是为了否定整章，而是标记结论的边界。一个合格说明要写成“在条件A、B、C下得到结论Q；删除B时，输入x产生现象R，因此Q不能外推”。只说“这个例子不工作”不足以区分模型错误、实现错误与资源耗尽。传感器标定方程可能因两个特征几乎共线而近奇异。直接求逆会放大测量噪声；更稳妥的做法是用带主元分解求解，报告条件数，并在必要时增加独立观测或使用正则化，而不是把巨大系数当真实信号。

$$
\varepsilon=\operatorname{distance}(y_{observed},y_{predicted})
$$

距离的含义随章节变化：精确离散结果可用相等或不变量，概率模拟可用频率误差与区间，数值线性代数可用残差范数和相对误差。先定义误差，再运行实验；不能看到输出以后才挑一个对自己有利的指标。

## 验收证书

验收证书包含五栏。定义栏写核空间与像空间的输入域和单位；推导栏逐步说明秩使用的规则；边界栏记录逆矩阵在零值、极值和退化输入下的状态；实现栏保存算法版本、依赖和随机种子；结论栏用最小二乘与正则化对应的误差或反例决定通过。任何一栏缺失，都只能称为演示，不能称为可复核结论。

$$
\operatorname{accept}=\bigl(\text{assumptions hold}\bigr)\land\bigl(\varepsilon\le\tau\bigr)\land\bigl(\text{counterexamples explained}\bigr)
$$

阈值tau必须在看结果前定义，并与业务或数值预算关联。精确问题的阈值可以是零，浮点问题应按尺度使用相对容差，统计问题应报告区间与功效而不是硬凑单点。验收结论还要注明未覆盖范围，使下一位读者知道哪里需要重新建模。

## 可核查推导

$$
\dim\ker A+\operatorname{rank}A=n,\qquad x=A^{-1}b\ 	ext{only when A is nonsingular}
$$

若A存在逆矩阵且Ax等于0，两边左乘逆得到x等于0，所以核只有零向量。反之，有限维方阵零核意味着列线性无关，秩等于维数，像覆盖整个输出空间，于是每个b有唯一原像。 推导中的每个等号都应能说明用了定义、代数恒等式还是额外假设。若某一步只在有限、独立、满秩或可导等条件下成立，就把条件写在该步旁边，而不是藏在结论之后。

```python
def solve_2x2(a, b):
    det = a[0][0] * a[1][1] - a[0][1] * a[1][0]
    if abs(det) < 1e-12:
        raise ValueError("singular or ill-conditioned")
    x = (b[0] * a[1][1] - a[0][1] * b[1]) / det
    y = (a[0][0] * b[1] - b[0] * a[1][0]) / det
    return x, y

assert solve_2x2([[2, 1], [1, 1]], [5, 3]) == (2.0, 1.0)
```

上面的程序是推导的一个有限投影。它能发现实现错误，却不能单独证明对所有输入成立。验收时至少用手算小例、随机样例和故意破坏假设的反例三路比较。

## 机制与数据流

**核空间**：被映射到零的输入方向；非零核表示不同输入可能产生同一输出。

**像空间**：所有可达输出组成的子空间，维数就是矩阵秩。

**秩**：独立列或独立行的数量，表示映射实际保留的独立信息维数。

把数据流写成“输入对象 → 表示 → 变换 → 结果 → 证据”。这样可以定位单位、概率质量、维度或状态在哪一步丢失，也能区分数学模型错误与代码实现错误。


## 边界与失败模式

**逆矩阵**：撤销双射线性映射；存在性等价于方阵满秩和零核。

**最小二乘与正则化**：无精确解或病态时最小化残差，并用惩罚项限制不稳定方向。

边界测试不只包括零、空集合和单元素。离散问题要检查规模翻倍与溢出，概率问题要检查归一化、相关性和尾部，线性代数问题要检查维度、秩、条件数与浮点残差。只有失败状态也能被解释，模型才可用于工程决策。

```python
experiment = {
    "claim": "核空间到最小二乘与正则化的关系",
    "normal_case": "满足本章全部假设",
    "boundary_case": "零规模、退化分布或近奇异输入",
    "counterexample": "求解线性方程默认先显式计算逆矩阵，增加计算量和数值误差；应优先直接分解求解。",
}
assert set(experiment) == {"claim", "normal_case", "boundary_case", "counterexample"}
```

## 工程案例

传感器标定方程可能因两个特征几乎共线而近奇异。直接求逆会放大测量噪声；更稳妥的做法是用带主元分解求解，报告条件数，并在必要时增加独立观测或使用正则化，而不是把巨大系数当真实信号。 案例验收应同时保存输入快照、参数与单位、算法版本、随机种子、退出状态和摘要结果。若只保存最终图或最终数字，后来无法区分数据变化、模型变化和实现变化。

```python
evidence = [
    ("核空间", "definition"),
    ("秩", "derivation"),
    ("最小二乘与正则化", "boundary-and-counterexample"),
]
assert len({name for name, _ in evidence}) == 3
```

1. 手算一个最小非平凡样例，标注每个符号的语义和单位。
2. 运行程序并与手算结果比较，再加入零、边界、非法和退化输入。
3. 故意删除一个关键假设，记录哪个推导步骤首先失效。
4. 固定环境与随机种子重跑，保存残差、频率或复杂度，而不只保存“通过”。
