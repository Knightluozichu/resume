## 直觉引入

想象一个超大的签到表。如果用布尔数组（每元素1字节），1000万人签到需要10MB。但如果用位向量（每元素1 bit），只需1.25MB——节省8倍空间。Bentley 的电话号码去重案例就是位向量的经典应用：1000万个7位号码用1.25MB位向量即可表示全部存在性。

## 概念讲解

### 位向量

<PpBitVectorsDiagram />

<Term def="位向量是用bit数组表示集合的数据结构，每个bit对应一个元素是否存在，空间效率比布尔数组高8倍">
位向量
</Term>

位向量用整型数组的每个 bit 表示一个元素的存在性。元素 i 对应第 i/32 个整数的第 i%32 位。设置 bit（arr[i/32] |= 1&lt;&lt;(i%32)）、清除 bit（arr[i/32] &= ~(1&lt;&lt;(i%32))）、测试 bit（arr[i/32] & (1&lt;&lt;(i%32))）。空间 O(n/8) 字节。

### 位运算加速

位运算的硬件优势：CPU单周期执行，可并行处理一个字内多个bit（64位CPU一次处理64bit），缓存友好（数据紧凑）。位向量排序比比较排序快是因为利用了整数的位级并行。

## 代码对照

```java
class BitVector {
    private int[] bits;
    public BitVector(int n) { bits = new int[(n+31)/32]; }
    public void set(int i) { bits[i/32] |= (1 << (i%32)); }
    public void clear(int i) { bits[i/32] &= ~(1 << (i%32)); }
    public boolean get(int i) { return (bits[i/32] & (1<<(i%32))) != 0; }
}

// 应用：电话号码去重排序
BitVector bv = new BitVector(10_000_000);
while (scanner.hasNextInt()) bv.set(scanner.nextInt());
for (int i = 0; i < 10_000_000; i++)
    if (bv.get(i)) System.out.println(i);  // 有序去重输出
```

## 常见误区

<Callout type="trap">
**误区：位向量只适用于整数。**
位向量要求元素是非负整数且范围已知。字符串或浮点数需先映射到整数空间（哈希），但可能冲突。
</Callout>

<Callout type="trap">
**误区：位向量排序是万能的。**
只适用于整数、范围已知且不太大、无重复或允许去重。大范围稀疏数据空间不可行。
</Callout>

<Exercises>
**问题 1**：位向量排序的复杂度？

<Answer>
时间O(n+N)（n次设置+N次扫描），空间O(N/8)字节。N为值域。当N与n同阶时优于O(n log n)。
</Answer>
</Exercises>
