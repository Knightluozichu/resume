## 直觉引入

想象一位老匠人退休前的最后一课。他不教具体技术（那些你已经学了），而是传受心法——如何看待手艺、如何对待问题、如何持续成长。Bentley 的尾声就是这最后一课：总结全书的编程哲学，从技术上升到智慧层面。核心信息：编程不仅是技术，更是一门需要思考、审美和持续学习的艺术。

## 概念讲解

### 编程哲学

<PpEpilogDiagram />

<Term def="Bentley的编程哲学核心是问题理解优先于代码编写，正确性优先于效率，思考优先于行动">
编程哲学
</Term>

全书的核心思想可以浓缩为一句话：在写代码之前先想清楚。想清楚问题是什么、方案有哪些、权衡是什么、正确性如何验证。Bentley 用十几个真实案例证明：90%的编程问题不是编码能力不足，而是思考不够深入。

### 编程的三个层次

第一层正确：代码做对的事情。第二层高效：代码用最少的资源做对的事情。第三层优雅：代码简洁、可读、可维护，让人赏心悦目。大多数程序员停留在第一层，优秀程序员达到第二层，卓越程序员追求第三层。

## 交互Demo

<Stepper>
<Step title="正确">代码必须正确。用断言、不变式、测试验证正确性。正确性是基础，没有正确性其他都无意义。</Step>
<Step title="高效">在正确的基础上优化效率。选择合适的算法和数据结构，profile定位瓶颈，针对性优化。</Step>
<Step title="优雅">在正确高效的基础上追求优雅。清晰命名、合理抽象、最小复杂度。优雅代码让人读后觉得「就该这样写」。</Step>
</Stepper>

## 代码对照

```java
// 编程三个层次的体现：求最大子数组和

// 层次1：正确（暴力 O(n^3)）
int maxSubSum_correct(int[] a) {
    int max = 0;
    for (int i = 0; i < a.length; i++)
        for (int j = i; j < a.length; j++) {
            int sum = 0;
            for (int k = i; k <= j; k++) sum += a[k];
            max = Math.max(max, sum);
        }
    return max;
}

// 层次2：高效（Kadane O(n)）
int maxSubSum_efficient(int[] a) {
    int max = 0, sum = 0;
    for (int x : a) {
        sum = Math.max(sum + x, 0);
        max = Math.max(max, sum);
    }
    return max;
}

// 层次3：优雅（简洁+正确+高效）
// 一行核心逻辑，含义清晰：
// 「到当前位置的最大和 = max(延续前面的和, 重新开始)」
// 「全局最大 = max(全局最大, 当前最大)」
// 这就是优雅——简洁中蕴含深刻的洞察

// Bentley的哲学总结：
// 1. 先理解问题再写代码
// 2. 先保证正确再追求效率
// 3. 先写简单再优化
// 4. 先思考再行动
// 5. 持续学习，持续反思
```

## 常见误区

<Callout type="trap">
**误区：认为编程只是写代码。**
编程的核心是思考而非打字。Bentley全书证明：90%的问题在思考阶段就能解决。花1小时思考可能省掉1天的编码和调试。
</Callout>

<Callout type="trap">
**误区：追求效率忽视优雅。**
代码被读的次数远多于被写的次数。优雅的代码更易维护、更少bug、更长寿。在正确和高效的基础上，优雅是终极追求。
</Callout>
