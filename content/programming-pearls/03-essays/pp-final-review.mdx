## 直觉引入

想象你在学武功。基础思维是内功心法（问题定义/拆解），算法优化是招式套路（二分/位向量），程序设计是兵器选择（设计原则/调优/估算），专题文章是实战心得（视角/哲学）。总复习就是把内功、招式、兵器、心得融会贯通，从会一招变成成体系。Bentley 的核心信息：编程是思考的艺术，不只是编码的技术。

## 概念讲解

### 知识体系

知识体系

全书四板块形成理解问题→优化算法→设计程序→反思智慧的闭环。核心问题：基础思维——怎么理解问题？算法优化——怎么用算法解决？程序设计——怎么写好代码？专题文章——怎么持续提升？

### 思维链路

从问题到代码的完整思维链路：1）定义问题（输入/输出/约束）；2）分析结构（数据特征/问题类型）；3）选择方案（算法/数据结构）；4）验证正确性（不变式/测试）；5）优化效率（profile/调优）；6）反思提升（换角度/总结）。

## 代码对照

```java
// 全书思维方法综合应用：解决一个实际问题
// 问题：找出10亿个32位整数中缺失的一个整数，内存限制1MB

// 第1步：定义问题
// 输入：10亿个32位整数（文件）
// 输出：一个缺失的整数
// 约束：内存1MB
// 正确性：输出确实不在输入中

// 第2步：分析结构
// 32位整数范围 [0, 2^32)，共约43亿
// 只有10亿个，缺失约33亿个
// 内存1MB = 250万个int
// 位向量需要 2^32 bit = 512MB，不可行！

// 第3步：换角度思考（换角度思维）
// 不需要找出所有缺失的，只需找一个
// 分治：按高位分成两半
// [0, 2^31) 和 [2^31, 2^32)
// 缺失的整数在某一半中

// 第4步：算法设计
// 1. 第一遍扫描：统计高位为0和为1的整数个数
//    [0, 2^31) 最多2^31个，如果实际<2^31则有缺失
// 2. 选择有缺失的那一半，递归
// 3. 每次范围减半，最多32次扫描

int findMissing(String file) {
    int lo = 0, hi = 0xFFFFFFFF;
    for (int bit = 31; bit >= 0; bit--) {
        int count0 = 0, count1 = 0;
        // 扫描文件统计当前位为0和1的个数
        // （只统计在[lo,hi]范围内的）
        // ...
        int mid = lo + (hi - lo) / 2;
        if (count0 < (1 << bit)) {
            hi = mid;  // 0的那半有缺失
        } else {
            lo = mid + 1;  // 1的那半有缺失
        }
    }
    return lo;
}
// 时间 O(32n) = O(n)，空间 O(1)
// 体现了：问题定义→换角度→分治→正确性
```

## 常见误区

<Callout type="trap">
**误区：复习时只看结论不重做案例。**
编程珠玑的价值在于案例的推导过程而非结论。复习时重新推导每个案例，体会思维转换的过程。
</Callout>
