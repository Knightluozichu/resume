## 直觉引入

想象你看一座山。从南面看是尖峰，从北面看是平坡，从空中看是个圆点。同一个问题，换个角度可能完全不同。Bentley 的视角章就是教你换角度看问题：把时间换空间、把精确换近似、把通用换专用、把复杂换简单。很多看似困难的问题，换个视角就豁然开朗。

## 概念讲解

### 换角度思考

<PpPerspectivesDiagram />

<Term def="换角度思考是从不同维度（时间/空间/精确/简洁）分析问题，寻找更优解决方案的思维方法">
换角度思考
</Term>

Bentley 展示了多种换角度的案例：1）时间换空间——用位向量（空间少）替代排序（时间多）；2）精确换近似——布隆过滤器用小概率误判换巨大空间节省；3）通用换专用——针对特定数据分布优化；4）复杂换简单——Kadane算法用一行代码替代三层循环。

### 核心权衡

计算机科学的核心权衡：时间vs空间（缓存用空间换时间）、精确vs近似（近似算法用误差换速度）、通用vs专用（特化优化用灵活性换性能）、简洁vs高效（抽象层用性能换可读性）。

## 交互Demo

<Stepper>
<Step title="时间↔空间">缓存：用内存（空间）存结果避免重复计算（时间）。压缩：用CPU（时间）解压数据节省存储（空间）。</Step>
<Step title="精确↔近似">精确算法保证正确但可能慢。近似算法用小误差换大加速。如布隆过滤器、蒙特卡洛。</Step>
<Step title="通用↔专用">通用算法适应所有输入但非最优。专用算法针对特定数据分布优化，更快但不通用。</Step>
</Stepper>

## 代码对照

```java
// 换角度思考案例：判断元素是否在集合中

// 视角1：精确（散列表）— 空间大但100%正确
Set<Integer> exact = new HashSet<>(data);
boolean has1 = exact.contains(x);  // O(1), 100%正确
// 空间：n * 4字节（整数指针）

// 视角2：近似（布隆过滤器）— 空间小但有小概率误判
BitSet bloom = new BitSet(n * 10);  // 只需1/4空间
// 用k个哈希函数设置bit
for (int h : hashFunctions(x)) bloom.set(h);
boolean has2 = checkAllBits(bloom, x);  // O(1), 有假阳性
// 空间：n * 10bit（比散列表小32倍）

// 视角3：专用（位向量）— 只适用于稠密整数
BitVector bv = new BitVector(maxValue);
bv.set(x);
boolean has3 = bv.get(x);  // O(1), 100%正确
// 空间：maxValue/8字节

// 权衡：
// 精确+通用 → 散列表（空间大）
// 近似+通用 → 布隆过滤器（空间小，有误差）
// 精确+专用 → 位向量（仅整数，空间最优）
```

## 常见误区

<Callout type="trap">
**误区：只从一个角度看问题。**
同一个问题可能有完全不同的解法，取决于你从哪个角度切入。只从一个角度（如只考虑精确匹配）可能错过更优方案（如近似匹配）。
</Callout>

<Callout type="trap">
**误区：忽视权衡的代价。**
每种选择都有代价。时间换空间意味着更多CPU，精确换近似意味着可能的误差。必须明确权衡的代价，根据场景选择。
</Callout>

<Answer>
