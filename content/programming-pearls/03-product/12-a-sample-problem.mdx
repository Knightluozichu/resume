## 从“把几百个名字输进电脑”开始

Column 12的A Sample Problem来自early 1980s一家public-opinion polling company。Employee每次要从printed precinct list中抽20到40个names，手工查random-number table需boring one hour。她提出：输入all precinct names与`m`，program随机输出`m`个names。

Automation direction正确，interface却继承了manual workflow的waste。几百个names每个最长约12 characters，全部typing既tedious又error-prone，而program最终忽略绝大多数。更好的boundary是：printed list已经存在，program只需输出要在纸上mark的positions。

先预测：`n=200,m=20`时，输入all names与只输入two integers相比，哪个更少出错？切换program boundary，观察输入量与discarded work。


抽象后的The Problem是：

> Input为integers $m,n$，其中$0\le m\le n$。Output为range $0..n-1$中的sorted list of exactly $m$ distinct random integers，并且每个$m$-element subset等概率。

若$m=20,n=200$，output可能以`4,15,17,...`开头。User沿printed list计数并mark第4、第15、第17个precinct。原本one-hour task缩为few minutes，且无需给computer重复提供已有names。

Selection Without Replacement（）比“每个integer有相同marginal probability”更强。设所有valid outputs组成集合：

$$
|\Omega|=\binom{n}{m},
\qquad
\Pr(S)=\frac{1}{\binom{n}{m}}
\quad\text{for every }|S|=m.
$$


Equal marginal inclusion只要求每个item被选概率$m/n$；correlated algorithm可能满足marginals却偏爱某些pairs/subsets。Acceptance必须检查subset distribution或使用可证明construction。

## 12.1 The Problem

The Problem（）的关键不是random function，而是problem definition。

### Perceived problem与abstract problem分离

Perceived problem含有solution suggestion：“输入names然后随机挑”。Abstract problem只保留真正需求：在physical ordered list上定位uniform sample。Names、string lengths与text parsing都不属于core computation。

这个变化同时改善：

- Usability：operator不必转录hundreds of names。
- Correctness：消除typos、duplicate names与encoding errors。
- Performance：input与storage从$O(nL)$降到$O(1)$ parameters。
- Generality：同一sampler可用于precincts、inventory bins或audit rows。
- Verification：finite integer contract更容易证明与测试。


### RNG interface也是specification

原书假设`bigrand()`返回远大于$m,n$的large random integer，并用`bigrand() % r`得到range。Modern implementation必须明确：

- Generator是否适合simulation、statistics或security。
- Seed是否需要reproducible，如何记录version。
- `randint(l,u)`是closed range且无overflow。
- Modulo reduction在generator period不能被$r$整除时会有bias。

若source有$R$ equally likely values而取modulo $r$，前$R\bmod r$个remainders会多一个preimage。Unbiased bounded generation可rejection掉incomplete tail：

$$
L=R-(R\bmod r),
\qquad
X<L\text{ 时返回 }X\bmod r.
$$

## 12.2 One Solution

Bentley回忆Knuth *Seminumerical Algorithms*中的Algorithm S。One Solution（）不存储population，也不存储selected set。

```cpp
void genknuth(int m, int n) {
    for (int i = 0; i < n; ++i) {
        // select m of the remaining n-i positions
        if (bounded_random(n - i) < m) {
            cout << i << "\n";
            --m;
        }
    }
}
```

在candidate `i`处，还有$r=n-i$个positions、必须再选$s=m$个。Current item以$s/r$概率selected；若selected，新state为$(s-1,r-1)$，否则为$(s,r-1)$。


### Exact cardinality invariant

Sampling Invariant（）初始化为$m\le n$。

- 若`select == 0`，threshold为0，后续均skip。
- 若`select == remaining`，threshold覆盖整个range，后续均select。
- 每step使`remaining`减1；selected branch也使`select`减1。

因此loop结束时exactly original $m$ items emitted，不可能更多或更少。


### Uniformity proof

固定某个target subset $S$。在state $(s,r)$，若current item属于$S$，algorithm选它的probability是$s/r$，剩余target的conditional probability由induction为$1/\binom{r-1}{s-1}$；若不属于，则skip probability是$(r-s)/r$，conditional probability为$1/\binom{r-1}{s}$。两条都化为：

$$
\frac{s}{r}\cdot\frac{1}{\binom{r-1}{s-1}}
=
\frac{r-s}{r}\cdot\frac{1}{\binom{r-1}{s}}
=
\frac{1}{\binom{r}{s}}.
$$

所以每个$m$-subset都有$1/\binom{n}{m}$ probability。Ascending scan天然保证sorted output，不需post-sort。

### Original engineering result

Knuth的reference让code很快落地。Including titles、input/output与range checks，final Basic program只有13 lines；problem defined后half an hour完成，并多年使用无问题。它只用few dozen bytes，对company常见few hundred precincts几乎instant。

成本是scan all $n$ candidates：time $\Theta(n)$，extra memory $O(1)$，random tests至多$n$。原书指出，用它在$n=2^{32}$中取few values约需12 minutes；面对48-或64-bit universe，linear scan根本不可行。这一failure boundary推动12.3的Design Space。

## 12.3 The Design Space

Design Space（）先允许low-tech answer。West Point一名cadet建议复印precinct list、裁成slips、放入paper bag摇匀后抽取。这一haha insight提醒：问题允许computer，不代表必须用computer。

从这里开始只研究program输出`0..n-1`中的$m$个sorted integers。

### Candidate A：ordered set with rejection

反复生成uniform integer并insert ordered set；duplicate自动被忽略，最后in-order report：

```cpp
void gensets(int m, int n) {
    set<int> selected;
    while (selected.size() < static_cast<size_t>(m)) {
        selected.insert(bounded_random(n));
    }
    for (int value : selected) cout << value << "\n";
}
```

Set and Ranges（）让real code与pseudocode同样短。C++ STL insert为$O(\log m)$，report为$O(m)$；space为$O(m)$。

若set size已是$k$，next draw被接受概率$(n-k)/n$，期待draws为：

$$
\mathbb{E}[D]
=\sum_{k=0}^{m-1}\frac{n}{n-k}
=n(H_n-H_{n-m}).
$$

当$m<n/2$时draws少于约$2m$；当$m$接近$n$，最后一个missing value像blind guessing，rejections爆炸。


原书machine上，这个program生成并打印one million sorted distinct 31-bit integers约20 seconds；仅生成并打印one million unsorted integers就需12.5 seconds，所以set operations约7.5 seconds。这个decomposition表明I/O与RNG baseline不可忽略。

### Candidate B：partial shuffle

建立array `0..n-1`，只执行Fisher-Yates前$m$步，每step从remaining suffix均匀选one item换到prefix；最后sort prefix：

```cpp
void genshuf(int m, int n) {
    vector<int> x(n);
    iota(x.begin(), x.end(), 0);
    for (int i = 0; i < m; ++i) {
        int j = randint(i, n - 1);
        swap(x[i], x[j]);
    }
    sort(x.begin(), x.begin() + m);
    for (int i = 0; i < m; ++i) cout << x[i] << "\n";
}
```

Partial shuffle使用exactly $m$ random choices，但time $O(n+m\log m)$、memory $O(n)$。若array本来就存在且可mutate，它很合适；若only abstract integer universe存在，初始化全部$n$反而浪费。


### Candidate C：sample the complement

若$n=1{,}000{,}000$且$m=n-10$，直接生成almost whole selected set很笨。均匀抽10个excluded positions，再顺序report其complement。每个size-10 excluded set与一个size-$(n-10)$ selected set一一对应，所以uniformity preserved。


这是一条general normalization：令$k=\min(m,n-m)$，围绕smaller side设计，再根据需要materialize complement。但若output本身含$m$个items，至少仍有$\Omega(m)$ reporting time。

### Candidate D：Floyd’s exactly-m-draw algorithm

原书Solution 12.9给出Bob Floyd的search-based construction。对$j=n-m..n-1$，从`0..j`抽`t`；若`t`不在set中insert `t`，否则insert `j`：

```cpp
void genfloyd(int m, int n) {
    set<int> selected;
    for (int j = n - m; j < n; ++j) {
        int t = bounded_random(j + 1);
        if (!selected.contains(t)) selected.insert(t);
        else selected.insert(j);
    }
    for (int value : selected) cout << value << "\n";
}
```


Before iteration `j`，set只含values小于`j`，因此collision时`j`一定absent，cardinality恰增1。Induction可证明每次后set是在`0..j`上的uniform fixed-size subset。它exactly uses $m$ random draws，ordered-tree implementation time $O(m\log m)$、space $O(m)$，不随huge $n$ linear scan。

### Candidate E：oversample, sort, deduplicate

若$m=10{,}000{,}000$、$n=2^{31}$，density仍低。可生成略多于$m$的draws，例如11 million，sort、deduplicate；不足再补，最后取uniform method或以strict proof校正。这个方向强调batch sorting/cache throughput，但naive “取前m个unique”需要认真证明distribution，不应因looks random就宣称uniform。

原书第二版errata修正了这一例中$m,n$曾互换的印刷错误。Parameter names不是装饰；反转会把feasible sparse sample变成impossible request。


| Candidate | Time | Extra space | Random draws | Sorted output | Best regime |
|---|---:|---:|---:|---|---|
| Knuth sequential | $O(n)$ | $O(1)$ | up to $n$ | Direct | moderate n, tiny memory |
| Ordered set rejection | expected $O(D\log m)$ | $O(m)$ | expected $D$ | Set traversal | sparse m/n |
| Partial shuffle | $O(n+m\log m)$ | $O(n)$ | exactly $m$ | Sort prefix | materialized mutable population |
| Complement | depends on sampler + $O(n)$ report | $O(n-m)$ | small side | Direct scan | m close to n |
| Floyd | $O(m\log m)$ | $O(m)$ | exactly $m$ | Set traversal | huge n, moderate m |


## 12.4 Principles

本栏把Programming Process（）总结为five stages，并明确真实设计会反复跳转。


### Understand the Perceived Problem

与user讨论context、frequency、physical artifacts、error cost与existing workflow。Early statement常夹带solution idea，应consider而非slavishly follow。Printed list就是本案可复用的external representation。

### Specify an Abstract Problem

Clean crisp statement让团队先解决current problem，再看见generic applicability。这里是uniform sorted fixed-size subset，而不是polling names。Preconditions、probability semantics与output ordering必须可test。

### Explore the Design Space

过早写“the solution”会think one minute and code one day。Pseudocode表达control flow，abstract data type表达crucial data structure；literature knowledge在这一阶段价值最高。先列candidates与regimes，再决定哪些值得prototype。

### Implement One Solution

有时one candidate明显胜出；有时prototype top few。Implementation应straightforward并使用most powerful available operations。原书提醒，software engineering的目的在control complexity，不是create it。五行可清楚证明的program，不需要膨胀成dozen procedures与elaborate ceremony。

### Retrospect

Polya的*How to Solve It*强调：总有something to do，可以改进solution或至少改进understanding。Retrospective检查：还能删除哪些inputs？哪些regime会失败？有无complement、batch、stream或library alternative？哪些证据应进入next problem checklist？

## 12.5 Problems

原书Problems把randomness与design process继续推开：

- 用约15-bit `rand()`组合至少30 random bits，并实现closed-range `bigrand`/`randint`；modern version还要避免signed overflow与modulo bias。
- 区分“each integer equal probability”与“each m-subset equal probability”，构造counterexample并写distribution test。
- 比较sampling with replacement、without replacement、ordered output与random permutation prefixes。
- 设计unknown-length stream上的one-item或m-item reservoir sampling；在第$t$个item以$m/t$概率纳入并随机替换existing slot。
- 实现Floyd algorithm并用all small `n,m` exhaustive states验证uniformity。
- 对same contract测Knuth、set、shuffle、complement与Floyd，分离RNG、container与printing costs。


Testing pyramid：

```text
deterministic properties:
  size == m
  values in [0,n)
  strictly increasing
  reproducible for fixed seed/version

exhaustive small domains:
  enumerate all RNG decision paths
  compare every subset probability

statistical large domains:
  item frequencies, pair frequencies, subset buckets
  multiple seeds and corrected significance thresholds
```

Never use production security tokens from pedagogical PRNG code。Security sampling需要cryptographic generator、domain separation、audit logs与explicit threat model。

## 12.6 Further Reading

Knuth的*The Art of Computer Programming, Volume 2: Seminumerical Algorithms*给出Algorithm S及其probabilistic analysis，也系统讨论pseudorandom numbers。Floyd的method展示了如何用search/set representation把runtime从depend on $n$转为depend on $m$。

Polya的*How to Solve It*支持12.4的retrospective习惯；James L. Adams的*Conceptual Blockbusting*对应paper-bag式跳出默认medium。Further reading的共同点不是记住更多recipes，而是训练problem reformulation、design-space search与proof。

## 小结

- A Sample Problem先解决interface：不用输入hundreds of precinct names，只输入$m,n$并输出printed-list positions。
- Abstract contract是sorted、distinct、exactly $m$、range `0..n-1`且all subsets equiprobable。
- Selection Without Replacement的valid outputs有$\binom{n}{m}$个，每个probability为其倒数。
- Knuth One Solution按顺序scan，以still-needed/remaining probability选择current item，extra space为constant。
- Sampling Invariant $0\le select\le remaining$同时证明不会多选或少选。
- Sequential algorithm time为$O(n)$，适合few hundred precincts，却不适合$2^{32}$或更大universe。
- Ordered set rejection code短、输出有序，sparse regime高效；sample density接近1时duplicates主导。
- Partial shuffle只需$m$ random swaps，却仍存储并initialize所有$n$ integers。
- Sample complement把$m\approx n$转成small excluded set；bijection保持uniformity。
- Floyd algorithm exactly uses$m$ random draws，以collision时insert current `j`保证set每轮增长。
- Design Space没有one universal winner；必须按$n,m$、memory、output order、RNG与available population representation选择。
- Programming Process包含understand、specify、explore、implement、retrospect，并在evidence驱动下迭代。
- Uniformity需要proof加small-domain exhaustive tests；只看item frequency会漏掉subset correlation。
