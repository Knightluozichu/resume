## 代码对照

```python
# 全书知识综合应用：异步数据处理管道
import asyncio
import multiprocessing as mp
from functools import wraps

# 1. 装饰器：重试+日志（高级语法）
def resilient(max_retries=3):
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            for attempt in range(max_retries):
                try:
                    return await func(*args, **kwargs)
                except Exception:
                    if attempt == max_retries - 1:
                        raise
                    await asyncio.sleep(2 ** attempt)
        return wrapper
    return decorator

# 2. 生成器：流式数据（高级语法）
def stream_records(path):
    with open(path) as f:
        for line in f:
            yield line.strip().split(',')

# 3. asyncio：并发IO（并发编程）
@resilient(max_retries=3)
async def fetch_data(url):
    await asyncio.sleep(0.1)
    return f'data from {url}'

async def pipeline(urls):
    tasks = [asyncio.create_task(fetch_data(u)) for u in urls]
    return await asyncio.gather(*tasks)

# 4. multiprocessing：CPU并行（并发编程）
def process_chunk(chunk):
    return sum(int(x) for x in chunk)

if __name__ == '__main__':
    data = asyncio.run(pipeline(['url1', 'url2']))
    with mp.Pool() as pool:
        results = pool.map(process_chunk, [data, data])
```

## 常见误区

<Callout type="trap">
**误区：复习时只看笔记不动手。**
编程是实践技能，复习必须动手写代码。每个知识点至少写一个小例子验证。
</Callout>

<Callout type="trap">
**误区：性能优化不分场景。**
IO 密集用 asyncio，CPU 密集用 multiprocessing，计算密集用 Cython。先 profile 定位瓶颈。
</Callout>
