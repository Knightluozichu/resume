## 直觉引入

想象你有一堆贴了标签的箱子。标签上写着"message"，箱子里面装着"Hello"。标签不是箱子本身——你可以把标签撕下来贴到另一个箱子上。这就是 Python 变量的本质：变量是标签，指向内存中的对象，而非存储值的盒子。

列表就像一排编了号的箱子。第一个箱子编号 0（不是 1），你可以通过编号快速找到任何箱子。想加新箱子？在末尾追加一个。想拿走？按编号取出。列表是 Python 中最常用的数据结构，理解它的操作模式是一切后续学习的基础。

## 概念讲解

### 变量的引用语义

<Term def="Python 变量是标签而非盒子——变量名绑定到内存中的对象，多个变量可以绑定同一对象。">

在 C 语言中，变量是盒子——`int a = 5` 表示在内存中开一个 int 大小的盒子，放入 5。在 Python 中，变量是标签——`a = 5` 表示创建一个整数对象 5，然后把标签 `a` 贴上去。`b = a` 不是复制盒子，而是再贴一个标签 `b` 到同一个对象上。

</Term>

这个区别在处理可变对象时至关重要：

```python
a = [1, 2, 3]
b = a           # b 和 a 指向同一个列表
b.append(4)     # 修改 b 也就是修改 a
print(a)        # [1, 2, 3, 4] — a 也变了！
```

### 列表操作

列表是有序的可变序列，支持索引、切片、增删改查：

```python
fruits = ["apple", "banana", "cherry"]

# 索引（从 0 开始，支持负索引）
fruits[0]       # "apple" — 第一个
fruits[-1]      # "cherry" — 最后一个

# 切片 [start:stop:step]
fruits[0:2]     # ["apple", "banana"] — 不含 stop
fruits[:2]      # 同上，省略 start
fruits[1:]      # ["banana", "cherry"] — 省略 stop

# 增删
fruits.append("date")      # 末尾追加
fruits.insert(0, "avocado") # 指定位置插入
fruits.pop()               # 弹出末尾元素
fruits.remove("banana")    # 按值删除

# 排序
fruits.sort()              # 原地排序（修改原列表）
sorted_fruits = sorted(fruits)  # 返回新列表（不改原列表）
```

### 字典与集合

字典是键值对映射，集合是无序不重复元素的集合：

```python
# 字典：键→值映射
student = {"name": "Alice", "age": 20}
student["name"]          # "Alice"
student["grade"] = "A"   # 添加键值对
del student["age"]       # 删除键

# 集合：不重复元素
unique_nums = {1, 2, 3, 2, 1}  # {1, 2, 3} — 自动去重
unique_nums.add(4)
unique_nums & {2, 3, 5}   # 交集 {2, 3}
```

创建变量 `a = [1, 2, 3]`，Python 在堆中创建列表对象 `[1, 2, 3]`，把标签 `a` 贴上去。执行 `b = a` 时，`b` 也贴到同一个列表对象——不是复制。此时 `a is b` 为 True。用 `b = a.copy()` 或 `b = a[:]` 才能创建独立副本。

</Step>

<Step title="第二步：列表索引与切片">

列表通过索引访问元素，索引从 0 开始。负索引从末尾倒数（-1 是最后一个）。切片 `[start:stop]` 返回子列表，左闭右开。切片创建新列表，不影响原列表——这是浅拷贝的一种方式。

</Step>

<Step title="第三步：可变 vs 不可变">

整数、字符串、元组是不可变对象——"修改"实际上是创建新对象。列表、字典、集合是可变对象——可以直接修改内容。函数传递可变对象时，函数内修改会影响调用者。这是 Python 最常见的 bug 来源之一。

</Step>

</Stepper>

## 代码对照

```python
# 变量与列表核心操作

# === 引用语义 ===
a = [1, 2, 3]
b = a              # b 和 a 指向同一对象
b.append(4)
print(a)           # [1, 2, 3, 4] — a 也变了

# 浅拷贝：创建新列表，但元素仍共享
c = a.copy()       # 或 a[:] 或 list(a)
c.append(5)
print(a)           # [1, 2, 3, 4] — a 不受影响

# === 列表遍历 ===
numbers = [10, 20, 30]

# 遍历元素
for num in numbers:
    print(num)

# 遍历索引+元素
for i, num in enumerate(numbers):
    print(f"索引 {i}: {num}")

# 列表推导式
squares = [x**2 for x in range(5)]       # [0, 1, 4, 9, 16]
even = [x for x in numbers if x > 15]    # [20, 30]

# === 字典操作 ===
scores = {"Alice": 90, "Bob": 85}
for name, score in scores.items():
    print(f"{name}: {score}")
```

## 常见误区

<Callout type="trap">

**误区：变量是盒子，赋值就是复制**

Python 变量是标签不是盒子。`b = a` 只是让 `b` 指向 `a` 指向的同一个对象，不会复制。修改 `b`（如果是可变对象）会影响 `a`。要创建独立副本，必须用 `copy()`、`[:]` 或 `list()`。嵌套结构需要 `copy.deepcopy()` 做深拷贝。

</Callout>

<Callout type="trap">

**误区：可变默认参数**

函数定义 `def add_item(item, lst=[])` 中的默认值 `[]` 只在函数定义时创建一次。多次调用不传 `lst` 时，所有调用共享同一个列表——这是一个经典陷阱。正确做法是用 `None` 做默认值，在函数内部创建新列表。

</Callout>

<Exercises>

**问题 1**：以下代码的输出是什么？解释原因。

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```

<Answer>

输出是 `[1, 2, 3, 4]`。

原因：Python 变量是引用（标签）。`b = a` 让 `b` 指向 `a` 指向的同一个列表对象，不是创建副本。`b.append(4)` 修改了这个共享的列表对象，所以 `a` 看到的内容也变了。要避免这个行为，应该用 `b = a.copy()` 或 `b = a[:]` 创建独立副本。

</Answer>

**问题 2**：如何安全地定义一个接受可选列表参数的函数？

<Answer>

使用 `None` 作为默认值，在函数内部创建新列表：

```python
def add_item(item, lst=None):
    if lst is None:
        lst = []  # 每次调用创建新列表
    lst.append(item)
    return lst
```

不能直接用 `def add_item(item, lst=[])`，因为默认值 `[]` 在函数定义时只创建一次。如果多次调用不传 `lst` 参数，所有调用会共享同一个列表对象，导致前一次调用的结果残留到后一次调用中。

</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="引用语义">

Python 变量是标签而非盒子。变量名绑定到内存中的对象，赋值 `b = a` 是让 `b` 指向 `a` 指向的同一对象，不是复制。多个变量可以绑定同一对象。

</GlossaryItem>

<GlossaryItem term="列表（list）">

有序可变序列，支持索引、切片、追加、插入、删除。用方括号 `[]` 创建。索引从 0 开始，支持负索引。切片 `[start:stop]` 返回新列表（浅拷贝）。

</GlossaryItem>

<GlossaryItem term="可变对象 vs 不可变对象">

可变对象（list、dict、set）可以直接修改内容。不可变对象（int、str、tuple）"修改"时实际创建新对象。函数传递可变对象时，函数内修改会影响调用者。

</GlossaryItem>

<GlossaryItem term="浅拷贝与深拷贝">

浅拷贝（`copy()`、`[:]`）创建新容器，但元素仍共享引用。深拷贝（`copy.deepcopy()`）递归复制所有嵌套对象，完全独立。处理嵌套列表时必须用深拷贝才能避免共享。

</GlossaryItem>

</Glossary>
