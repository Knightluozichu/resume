## 直觉引入

函数就像一台榨汁机。你放进水果（输入参数），它榨出果汁（返回值）。你不需要知道里面刀片怎么转——你只需要知道放什么进去、出来什么。一旦做好了一台榨汁机，你可以反复用它榨不同的水果。

编程中的函数也是这样：把一段逻辑封装起来，取个名字，之后调用时传入不同的参数就能得到不同的结果。函数是代码复用的基本单位——没有函数，每个功能都要从头写；有了函数，写一次就能用无数次。

## 概念讲解

### 函数定义与调用

<Term def="函数用 def 关键字定义，包含函数名、参数列表和函数体。函数通过 return 返回值，无 return 时返回 None。">

```python
def greet(name, msg="Hello"):
    """向指定的人打招呼（文档字符串）"""
    message = f"{msg}, {name}!"
    return message

# 调用
print(greet("Alice"))              # Hello, Alice!
print(greet("Bob", msg="Hi"))      # Hi, Bob!
```

</Term>

### 参数类型

Python 函数支持多种参数形式：

```python
# 位置参数：按顺序传递
def add(a, b):
    return a + b
add(1, 2)  # a=1, b=2

# 默认值参数：可省略
def greet(name, msg="Hi"):
    return f"{msg}, {name}"
greet("Alice")           # msg 用默认值 "Hi"
greet("Alice", "Hello")  # msg="Hello"

# 关键字参数：按名称传递，不依赖顺序
greet(msg="Hello", name="Alice")

# 任意数量位置参数：*args 收集为元组
def sum_all(*args):
    return sum(args)
sum_all(1, 2, 3, 4)  # args=(1,2,3,4)

# 任意数量关键字参数：**kwargs 收集为字典
def print_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")
print_info(name="Alice", age=20)
```

### 返回值

函数可以返回多个值（实际是元组）：

```python
def min_max(numbers):
    return min(numbers), max(numbers)

smallest, largest = min_max([3, 1, 4, 1, 5])  # 解包
```

### 作用域：LEGB 规则

<Term def="LEGB 是 Python 变量查找顺序：Local（局部）→ Enclosing（嵌套）→ Global（全局）→ Built-in（内置）。">

Python 查找变量时按 LEGB 顺序从内到外查找。函数内部定义的变量是局部变量，函数外不可访问。要在函数内修改全局变量，需要用 `global` 声明。

</Term>

```python
x = "global"  # 全局变量

def outer():
    x = "enclosing"  # 嵌套作用域

    def inner():
        x = "local"  # 局部变量
        print(x)     # 先找局部 → "local"

    inner()

# 修改全局变量
count = 0
def increment():
    global count  # 声明使用全局变量
    count += 1
```

### 传递可变与不可变对象

```python
# 不可变对象（int, str, tuple）：函数内"修改"不影响外部
def try_change_int(x):
    x = 100  # 创建新对象，不影响外部

n = 10
try_change_int(n)
print(n)  # 10 — 不变

# 可变对象（list, dict）：函数内修改影响外部
def add_item(lst):
    lst.append(4)  # 修改同一对象

numbers = [1, 2, 3]
add_item(numbers)
print(numbers)  # [1, 2, 3, 4] — 变了
```

用 `def 函数名(参数):` 定义函数，函数体缩进 4 格。用 `return` 返回结果。调用时传入参数，函数执行后返回值。无 return 时返回 None。函数定义必须在使用之前——Python 从上到下执行，遇到 def 才创建函数对象。

<Step title="第二步：灵活的参数传递">

位置参数按顺序传递，关键字参数按名称传递（不依赖顺序）。默认值参数可以省略。`*args` 收集多余位置参数为元组，`**kwargs` 收集多余关键字参数为字典。参数顺序：位置参数 → 默认值参数 → *args → **kwargs。

</Step>

<Step title="第三步：理解作用域与传递语义">

变量查找遵循 LEGB 规则：先局部，再嵌套，再全局，最后内置。函数内可以读取外部变量，但修改需要 global 声明。函数传递的是对象引用——不可变对象"修改"会创建新对象（不影响外部），可变对象修改直接影响外部。

</Step>

</Stepper>

## 代码对照

```python
# 函数综合示例：学生成绩管理

def calculate_stats(scores, weight=None):
    """
    计算成绩统计信息。

    参数:
        scores: 分数字典 {学生名: 分数}
        weight: 可选权重字典 {学生名: 权重}

    返回:
        平均分, 最高分学生, 最低分学生
    """
    if not scores:
        return 0, None, None

    # 应用权重（如果有）
    if weight:
        weighted = {name: score * weight.get(name, 1.0)
                    for name, score in scores.items()}
    else:
        weighted = scores

    avg = sum(weighted.values()) / len(weighted)
    top_student = max(weighted, key=weighted.get)
    bottom_student = min(weighted, key=weighted.get)

    return avg, top_student, bottom_student

# 调用
scores = {"Alice": 90, "Bob": 85, "Charlie": 78}
avg, top, bottom = calculate_stats(scores)

print(f"平均分: {avg:.1f}")         # 84.3
print(f"最高: {top}")               # Alice
print(f"最低: {bottom}")            # Charlie

# 使用关键字参数
weights = {"Alice": 1.2, "Bob": 0.8}
avg_w, top_w, _ = calculate_stats(scores, weight=weights)
```

## 常见误区

<Callout type="trap">

**误区：可变默认参数**

`def add(item, lst=[])` 中的 `[]` 在函数定义时只创建一次。多次调用不传 `lst` 时共享同一个列表。正确做法：`def add(item, lst=None): if lst is None: lst = []`。

</Callout>

<Callout type="trap">

**误区：在函数内修改全局变量不加 global**

函数内 `count += 1` 会报 UnboundLocalError——Python 看到 `=` 把 count 当局部变量，但它还没赋值。要修改全局变量必须在函数内 `global count` 声明。但更好的做法是避免用全局变量，通过参数和返回值传递数据。

</Callout>

<Exercises>

**问题 1**：以下代码的输出是什么？为什么？

```python
def append_to(item, target=[]):
    target.append(item)
    return target

print(append_to(1))
print(append_to(2))
```

<Answer>

输出：
```
[1]
[1, 2]
```

原因：默认参数 `[]` 在函数定义时只创建一次，之后所有调用共享同一个列表。第一次调用 `append_to(1)` 往这个列表加了 1，返回 `[1]`。第二次调用 `append_to(2)` 没有传 target，使用的还是同一个列表（现在已经 `[1]`），追加 2 后变成 `[1, 2]`。

修复方法：`def append_to(item, target=None): if target is None: target = []`，这样每次调用不传 target 时都创建新列表。

</Answer>

**问题 2**：解释 LEGB 作用域查找规则，并说明何时需要使用 global 关键字。

<Answer>

LEGB 是 Python 变量查找顺序：
- **L (Local)**：函数内部定义的变量
- **E (Enclosing)**：外层嵌套函数的变量
- **G (Global)**：模块级别定义的变量
- **B (Built-in)**：Python 内置名称（如 len、print）

Python 从内到外依次查找。函数内可以读取全局变量（查找时到达 G 层），但如果要在函数内**修改**全局变量（赋值），Python 会把该变量当作局部变量——除非用 `global` 声明。例如 `count = 0; def inc(): global count; count += 1`。不过最佳实践是避免全局变量，通过参数传入、返回值传出。

</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="函数（def）">

用 `def 关键字 函数名(参数):` 定义的代码块。通过 return 返回值，无 return 时返回 None。函数是代码复用的基本单位，封装逻辑后可反复调用。

</GlossaryItem>

<GlossaryItem term="参数类型">

Python 支持：位置参数（按顺序）、关键字参数（按名称）、默认值参数（可省略）、`*args`（收集多余位置参数为元组）、`**kwargs`（收集多余关键字参数为字典）。

</GlossaryItem>

<GlossaryItem term="LEGB 规则">

变量查找顺序：Local（局部）→ Enclosing（嵌套函数）→ Global（模块全局）→ Built-in（内置）。从内到外依次查找。修改全局变量需用 global 声明。

</GlossaryItem>

<GlossaryItem term="传递语义">

Python 函数传递的是对象引用。不可变对象（int/str/tuple）在函数内"修改"会创建新对象，不影响外部。可变对象（list/dict/set）在函数内修改直接影响外部，因为内外引用同一对象。

</GlossaryItem>

</Glossary>
