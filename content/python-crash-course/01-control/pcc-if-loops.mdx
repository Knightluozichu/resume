## 直觉引入

你站在十字路口。向左走是学校，向右走是超市，直走是公园。你根据目的做选择——这就是条件判断。到了公园，你要绕湖跑 5 圈——重复执行同一动作——这就是循环。跑到第 3 圈下雨了，你决定不跑了——这就是 break。

程序的世界和现实一样：需要根据条件做不同处理（if），需要重复执行某些操作（循环），需要在特定情况下中断或跳过（break/continue）。控制流让程序从"直线执行"变成"能判断、能重复、能跳转"。

## 概念讲解

### 条件判断

<Term def="if-elif-else 是 Python 的条件分支结构：if 检查第一个条件，elif 检查后续条件，else 处理所有未匹配的情况。">

Python 用缩进（4 个空格）表示代码块，而非花括号。条件表达式不需要括号，结尾用冒号。多个条件用 elif 连接（不是 else if），只有一个分支会被执行。

</Term>

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "F"
```

### while 循环

`while` 在条件为 True 时重复执行，适合不确定迭代次数的场景：

```python
# 倒计时
count = 5
while count > 0:
    print(count)
    count -= 1      # 必须修改条件变量，否则死循环
print("发射！")
```

### for 循环

`for` 遍历可迭代对象，适合已知迭代范围的场景：

```python
# 遍历列表
for fruit in ["apple", "banana", "cherry"]:
    print(fruit)

# range() 生成数字序列
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)
for i in range(2, 8):     # 2, 3, 4, 5, 6, 7
    print(i)
for i in range(0, 10, 2): # 0, 2, 4, 6, 8
    print(i)
```

### break 与 continue

```python
# break：跳出整个循环
for num in range(1, 100):
    if num > 50:
        break        # num > 50 时停止循环

# continue：跳过当前迭代
for num in range(10):
    if num % 2 == 0:
        continue     # 跳过偶数
    print(num)       # 只打印奇数
```

### 列表推导式

列表推导式用一行代码生成列表，比 for 循环更简洁：

```python
# 传统写法
squares = []
for x in range(10):
    squares.append(x ** 2)

# 列表推导式
squares = [x ** 2 for x in range(10)]

# 带条件的列表推导式
even_squares = [x ** 2 for x in range(10) if x % 2 == 0]
```

<Step title="第一步：if-elif-else 分支">

if 从上到下依次检查条件。第一个为 True 的分支执行后，跳过所有后续 elif 和 else。如果所有条件都不满足，执行 else。每个分支的代码块用缩进表示。条件判断中，空列表、空字符串、0、None 都被视为 False。

</Step>

<Step title="第二步：while 条件循环">

while 在每次迭代前检查条件。条件为 True 就继续循环，为 False 就退出。必须确保循环体内有修改条件变量的操作，否则会造成死循环。可以用 break 在循环内强制退出，用 continue 跳过当前轮次。

</Step>

<Step title="第三步：for 遍历循环与列表推导式">

for 循环遍历可迭代对象的每个元素。range() 生成数字序列，常用于按次数循环。列表推导式 `[表达式 for 变量 in 可迭代对象 if 条件]` 是 Python 的特色语法，一行代码完成过滤和变换，比传统 for 循环更简洁高效。

</Step>

## 代码对照

```python
# 控制流综合示例：猜数字游戏

import random

answer = random.randint(1, 100)  # 随机答案
attempts = 0
max_attempts = 7

print("猜一个 1-100 的数字！")

while attempts < max_attempts:
    # 输入验证
    guess = int(input(f"第 {attempts + 1} 次猜: "))

    if guess < 1 or guess > 100:
        print("请输入 1-100 之间的数字！")
        continue  # 跳过本次，不算尝试

    attempts += 1

    if guess == answer:
        print(f"恭喜！{attempts} 次猜中！")
        break  # 猜中，跳出循环
    elif guess < answer:
        print("太小了！")
    else:
        print("太大了！")
else:
    # while 的 else：循环正常结束（非 break）时执行
    print(f"游戏结束！答案是 {answer}")

# 列表推导式：统计游戏数据
results = [random.randint(1, 100) for _ in range(20)]
wins = [r for r in results if r > 50]
print(f"20 局中 {len(wins)} 局获胜")
```

## 常见误区

<Callout type="trap">

**误区：while 循环忘记修改条件变量**

`while count > 0: print(count)` 会导致死循环——count 永远不变。while 循环体内必须有改变条件变量的操作。调试死循环时，在循环体内加 `print` 看变量变化，或用 Ctrl+C 强制中断。

</Callout>

<Callout type="trap">

**误区：在遍历列表时修改列表**

`for item in lst: lst.remove(item)` 会导致跳过元素——因为 remove 改变了列表长度和索引对应关系。正确做法是遍历列表的副本 `for item in lst[:]:`，或用列表推导式创建新列表。

</Callout>

<Exercises>

**问题 1**：以下代码输出什么？

```python
for i in range(1, 6):
    if i == 3:
        continue
    if i == 5:
        break
    print(i)
```

<Answer>

输出：
```
1
2
4
```

解释：i=1 时打印 1。i=2 时打印 2。i=3 时 continue 跳过打印。i=4 时打印 4。i=5 时 break 跳出循环，不打印 5。continue 跳过当前轮次但不终止循环，break 直接终止整个循环。

</Answer>

**问题 2**：用列表推导式生成 1-20 中所有能被 3 整除的数的平方。

<Answer>

```python
result = [x ** 2 for x in range(1, 21) if x % 3 == 0]
# [9, 36, 81, 144, 225, 324]
```

列表推导式结构是 `[表达式 for 变量 in 可迭代对象 if 条件]`。`range(1, 21)` 生成 1 到 20，`if x % 3 == 0` 筛选能被 3 整除的数，`x ** 2` 对每个筛选后的数求平方。

</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="if-elif-else">

Python 的条件分支结构。if 检查第一个条件，elif 检查后续条件（可以有多个），else 处理所有未匹配情况。只有第一个为 True 的分支会执行。代码块用缩进表示。

</GlossaryItem>

<GlossaryItem term="while 循环">

条件循环：条件为 True 时重复执行循环体。适合不确定迭代次数的场景。循环体内必须修改条件变量，否则死循环。while 可以搭配 else，在循环正常结束（非 break）时执行。

</GlossaryItem>

<GlossaryItem term="for 循环">

遍历循环：遍历可迭代对象（列表、range、字符串等）的每个元素。range(start, stop, step) 生成数字序列。适合已知迭代范围的场景。

</GlossaryItem>

<GlossaryItem term="列表推导式">

Python 特色语法，一行代码生成列表：`[表达式 for 变量 in 可迭代对象 if 条件]`。比传统 for 循环更简洁，支持过滤和变换。可嵌套但不宜超过两层，否则影响可读性。

</GlossaryItem>

</Glossary>
