## 直觉引入

类是一张蓝图，实例是根据蓝图造出来的产品。一张"汽车"蓝图可以造出很多辆汽车——它们都有轮子、发动机（属性），都能加速、刹车（方法），但每辆车的颜色、型号不同（实例属性）。

没有类，你用字典和函数管理数据：`{"name": "Rex", "age": 3}` 加一个 `def speak(dog): ...`。有了类，你把数据和操作数据的方法绑在一起：`Dog` 类有 `name`、`age` 属性和 `speak()` 方法。这不只是语法糖——它让代码结构更清晰、复用更方便、扩展更容易。

## 概念讲解

### 类定义与实例化

<Term def="类用 class 关键字定义，__init__ 是构造方法，在创建实例时自动调用。self 指向当前实例，所有实例方法第一个参数都是 self。">

```python
class Dog:
    """表示一只狗的类"""

    def __init__(self, name, age):
        """构造函数：初始化实例属性"""
        self.name = name    # 实例属性
        self.age = age

    def speak(self):
        """实例方法"""
        return f"{self.name} says Woof!"

# 实例化
my_dog = Dog("Rex", 3)     # 自动调用 __init__
print(my_dog.speak())       # Rex says Woof!
print(my_dog.name)          # Rex — 访问属性
```

</Term>

### 类属性与实例属性

```python
class Dog:
    species = "Canis familiaris"  # 类属性：所有实例共享

    def __init__(self, name):
        self.name = name          # 实例属性：每个实例独立

d1 = Dog("Rex")
d2 = Dog("Buddy")
print(d1.species)  # Canis familiaris — 访问类属性
print(d2.species)  # 同上
# 修改类属性影响所有实例
Dog.species = "Canis lupus"
```

### 继承与多态

<Term def="继承让子类获得父类的所有属性和方法，可以重写方法实现多态——同一接口、不同行为。">

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("子类必须实现 speak")

class Dog(Animal):       # Dog 继承 Animal
    def speak(self):     # 重写父类方法
        return f"{self.name} says Woof!"

class Cat(Animal):
    def speak(self):
        return f"{self.name} says Meow!"

# 多态：同一调用，不同行为
animals = [Dog("Rex"), Cat("Whiskers")]
for animal in animals:
    print(animal.speak())  # 各自调用重写后的方法
```

</Term>

### 特殊方法

特殊方法（魔术方法）以双下划线开头和结尾，让自定义类支持 Python 内置操作：

```python
class Book:
    def __init__(self, title, author):
        self.title = title
        self.author = author

    def __str__(self):           # print() / str() 时调用
        return f"{self.title} by {self.author}"

    def __repr__(self):          # repr() / 调试时调用
        return f"Book('{self.title}', '{self.author}')"

    def __eq__(self, other):     # == 运算符
        return self.title == other.title and self.author == other.author

book = Book("1984", "Orwell")
print(book)       # 1984 by Orwell — 调用 __str__
print(repr(book)) # Book('1984', 'Orwell') — 调用 __repr__
```

### super() 调用父类

```python
class GuideDog(Dog):
    def __init__(self, name, handler):
        super().__init__(name, 0)  # 调用父类 __init__
        self.handler = handler

    def speak(self):
        base = super().speak()     # 调用父类 speak
        return f"{base} (trained by {self.handler})"
```

<Step title="第一步：定义类与实例化">

用 `class 类名:` 定义类。`__init__` 是构造方法，创建实例时自动调用。`self` 是第一个参数，指向当前实例——通过 `self.属性名 = 值` 设置实例属性。实例化用 `实例名 = 类名(参数)`，不需要传 self。

</Step>

<Step title="第二步：继承与重写">

子类用 `class 子类(父类):` 继承父类。子类自动获得父类所有属性和方法。重写父类方法只需在子类中定义同名方法。多态的核心是：调用 `animal.speak()` 时，Python 根据实例的实际类型（Dog 还是 Cat）决定调用哪个 speak 实现。

</Step>

<Step title="第三步：特殊方法与 super()">

`__str__` 控制 print 输出，`__repr__` 控制调试表示，`__eq__` 控制相等比较。`super()` 在子类中调用父类方法——常用于 `__init__` 中初始化父类属性。使用特殊方法让自定义类像内置类型一样自然。

</Step>

</Stepper>

## 代码对照

```python
# 面向对象综合示例：餐厅菜单系统

class MenuItem:
    """菜单项基类"""

    def __init__(self, name, price):
        self.name = name
        self.price = price

    def describe(self):
        return f"{self.name} — ¥{self.price:.2f}"

    def __str__(self):
        return self.describe()

class Appetizer(MenuItem):
    """开胃菜"""

    def __init__(self, name, price, portion):
        super().__init__(name, price)  # 调用父类构造
        self.portion = portion         # "小" / "中" / "大"

    def describe(self):                # 重写
        return f"{super().describe()} ({self.portion}份)"

class MainCourse(MenuItem):
    """主菜"""

    def __init__(self, name, price, spicy=False):
        super().__init__(name, price)
        self.spicy = spicy

    def describe(self):                # 重写
        suffix = " [辣]" if self.spicy else ""
        return f"{super().describe()}{suffix}"

# 多态：统一调用 describe()
menu = [
    Appetizer("沙拉", 28, "中"),
    MainCourse("宫保鸡丁", 58, spicy=True),
    MainCourse("清蒸鱼", 88),
]

for item in menu:
    print(item.describe())
# 沙拉 — ¥28.00 (中份)
# 宫保鸡丁 — ¥58.00 [辣]
# 清蒸鱼 — ¥88.00
```

## 常见误区

<Callout type="trap">

**误区：忘记 self 参数**

实例方法第一个参数必须是 self（名称可变但约定用 self）。`def speak():` 会导致调用时参数数量不匹配。self 不需要手动传入——Python 自动将实例作为第一个参数传入。

</Callout>

<Callout type="trap">

**误区：类属性作为可变默认值**

`class Dog: tricks = []` 是类属性，所有实例共享同一个列表。`dog1.tricks.append("sit")` 会影响 `dog2.tricks`。如果需要每个实例独立的列表，应该在 `__init__` 中创建 `self.tricks = []`。

</Callout>

<Exercises>

**问题 1**：解释 self 的作用，以及为什么实例方法需要它。

<Answer>

`self` 是实例方法的第一个参数，指向调用该方法的实例对象。Python 在调用 `my_dog.speak()` 时，自动将 `my_dog` 作为 `self` 传入 `speak(self)` 方法。

self 的作用：
1. 访问实例属性：`self.name` 获取当前实例的 name 属性
2. 调用实例方法：`self.other_method()` 调用同一实例的其他方法
3. 区分实例属性和局部变量：`self.name` 是实例属性，`name` 是局部变量

没有 self，方法无法知道操作的是哪个实例的数据。self 让同一方法能服务于不同实例——`dog1.speak()` 和 `dog2.speak()` 访问各自的数据。

</Answer>

**问题 2**：什么是多态？以下代码如何体现多态？

```python
for animal in [Dog("Rex"), Cat("Whiskers")]:
    print(animal.speak())
```

<Answer>

多态（Polymorphism）是指同一接口（方法名）在不同类型上有不同的实现。调用者不需要知道对象的具体类型，只需调用统一接口，实际执行的方法由对象的实际类型决定。

上述代码中，`animal.speak()` 的调用方式完全相同，但 Dog 实例调用 Dog.speak() 返回 "Rex says Woof!"，Cat 实例调用 Cat.speak() 返回 "Whiskers says Meow!"。循环不需要判断 animal 是 Dog 还是 Cat——Python 的方法分派机制自动找到正确的实现。

多态的好处是：新增动物类型（如 Bird）时，只需定义 Bird 类并实现 speak()，循环代码不需要任何修改。这就是"对扩展开放、对修改关闭"。

</Answer>

</Exercises>

<Glossary>

<GlossaryItem term="类与实例">

类是创建对象的蓝图（模板），定义了属性和方法。实例是根据类创建的具体对象。一个类可以创建多个实例，每个实例有独立的数据但共享方法定义。

</GlossaryItem>

<GlossaryItem term="__init__ 构造方法">

在实例化时自动调用的特殊方法，用于初始化实例属性。`self` 指向正在创建的实例。`Dog("Rex")` 会调用 `Dog.__init__(self, "Rex")`。

</GlossaryItem>

<GlossaryItem term="继承（inheritance）">

子类通过 `class 子类(父类):` 获得父类所有属性和方法。子类可以重写父类方法（override）实现不同行为。`super()` 在子类中调用父类方法，常用于 `__init__` 中初始化父类属性。

</GlossaryItem>

<GlossaryItem term="多态（polymorphism）">

同一方法调用在不同类型上表现出不同行为。调用者不需要知道对象的具体类型，Python 根据实例的实际类型分派到正确的方法实现。多态让代码更容易扩展——新增类型不需修改调用方代码。

</GlossaryItem>

</Glossary>
