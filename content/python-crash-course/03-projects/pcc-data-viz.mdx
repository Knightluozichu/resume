## 直觉引入

一堆数字摆在面前：`[17, 20, 22, 19, 24, 26, 23, 25, 21, 18]`。你能一眼看出趋势吗？很难。但如果画成折线图——先降后升再降的曲线一目了然。这就是数据可视化的力量：把数字变成图形，让人眼快速识别模式、趋势和异常。

本书的数据可视化项目教你用两个库画图：Matplotlib 适合生成静态的、可发表的高质量图表（论文、报告）；Plotly 适合生成交互式图表（鼠标悬停看数值、缩放、筛选）。两者搭配使用，覆盖从数据分析到 Web 展示的全部场景。

## 概念讲解

### Matplotlib 基础

<Term def="Matplotlib 是 Python 最基础的绘图库，pyplot 模块提供类似 MATLAB 的简洁 API。plot() 画折线，scatter() 画散点，hist() 画直方图。">

```python
import matplotlib.pyplot as plt

# 折线图：趋势变化
squares = [1, 4, 9, 16, 25]
plt.plot(squares, linewidth=3)        # 画线
plt.title("Square Numbers", fontsize=20)
plt.xlabel("Value", fontsize=12)
plt.ylabel("Square of Value", fontsize=12)
plt.tick_params(axis='both', labelsize=10)
plt.show()                            # 显示图表

# 散点图：变量关系
x_values = list(range(1, 1001))
y_values = [x**2 for x in x_values]
plt.scatter(x_values, y_values, c='red', s=10)
plt.axis([0, 1100, 0, 1100000])       # 设置坐标轴范围
plt.show()

# 直方图：数据分布
dice_results = [random.randint(1, 6) for _ in range(1000)]
plt.hist(dice_results, bins=6, color='blue', alpha=0.7)
plt.show()
```

</Term>

### 自定义样式

```python
# 多条线 + 图例
months = range(1, 13)
tokyo = [5, 6, 9, 14, 18, 22, 26, 27, 23, 18, 12, 7]
sapporo = [-3, -2, 1, 7, 12, 17, 21, 22, 18, 12, 6, 0]

plt.plot(months, tokyo, label='Tokyo', linewidth=2)
plt.plot(months, sapporo, label='Sapporo', linewidth=2)
plt.title("Monthly Average Temperature", fontsize=16)
plt.xlabel("Month")
plt.ylabel("Temperature (°C)")
plt.legend()                          # 显示图例
plt.grid(True)                        # 显示网格
plt.savefig('temp.png', dpi=300)      # 保存图片
```

### Plotly 交互图表

```python
import plotly.express as px

# 交互式散点图
df = px.data.iris()
fig = px.scatter(df, x="sepal_width", y="sepal_length",
                 color="species", size="petal_length",
                 title="Iris Dataset")
fig.show()                            # 在浏览器中打开交互图

# 交互式折线图
fig = px.line(x=months, y=tokyo, title="Tokyo Temperature")
fig.write_html("tokyo_temp.html")     # 导出为 HTML
```

Plotly 的优势是交互性：鼠标悬停显示数值、滚轮缩放、点击图例筛选、框选放大。

### API 数据获取

```python
import requests

# 从 API 获取数据
url = "https://api.github.com/search/repositories"
params = {"q": "language:python", "sort": "stars", "order": "desc"}
response = requests.get(url, params=params)
response.raise_for_status()           # 检查请求是否成功

data = response.json()                # 解析 JSON 响应
repo_dicts = data["items"]

# 提取数据用于可视化
names = [repo["name"] for repo in repo_dicts[:10]]
stars = [repo["stargazers_count"] for repo in repo_dicts[:10]]

# 用 Plotly 绘制条形图
fig = px.bar(x=names, y=stars, title="Top 10 Python Repos")
fig.show()
```

## 代码对照

```python
# 综合示例：全球地震数据可视化

import requests
import plotly.express as px

# 1. 从 API 获取地震数据
url = "https://earthquake.usgs.gov/fdsnws/event/1/query"
params = {
    "format": "geojson",
    "starttime": "2024-01-01",
    "endtime": "2024-12-31",
    "minmagnitude": 5.0,
}
response = requests.get(url, params=params)
response.raise_for_status()
data = response.json()

# 2. 提取数据
mags = []    # 震级
lons = []    # 经度
lats = []    # 纬度
titles = []  # 标题

for eq in data["features"]:
    mags.append(eq["properties"]["mag"])
    lons.append(eq["geometry"]["coordinates"][0])
    lats.append(eq["geometry"]["coordinates"][1])
    titles.append(eq["properties"]["title"])

# 3. 用 Plotly 绘制散点地图
fig = px.scatter_geo(
    lat=lats, lon=lons,
    size=mags,               # 点的大小映射震级
    color=mags,              # 点的颜色映射震级
    color_continuous_scale="Viridis",
    hover_name=titles,       # 悬停显示标题
    title="2024年全球5级以上地震",
    projection="natural earth",
)
fig.write_html("earthquakes.html")  # 保存为交互式 HTML
fig.show()
```

## 常见误区

<Callout type="trap">

**误区：选错图表类型**

折线图展示趋势（时间变化），散点图展示关系（两个变量），直方图展示分布（频率统计），条形图展示对比（分类数据）。用错图表类型会误导读者——比如用折线图连接不连续的分类数据，或者用饼图展示超过 5 个分类。选择图表前先问：我要展示什么关系？

</Callout>

<Callout type="trap">

**误区：API 请求不做错误处理**

`requests.get()` 可能因网络问题失败，API 可能返回错误状态码。不做 `raise_for_status()` 检查直接 `response.json()` 可能得到意外结果或崩溃。正确的做法是 try-except 包裹，处理网络异常和 HTTP 错误状态码。

</Callout>

<Exercises>

**问题 1**：Matplotlib 和 Plotly 各自适合什么场景？给出选择依据。

<Answer>

**Matplotlib 适合**：静态高质量图表，用于论文、报告、出版物。优点是控制精细（每个元素都可自定义）、输出格式多（PNG/PDF/SVG）、学术领域标准。缺点是无交互性。

**Plotly 适合**：交互式图表，用于数据探索、Web 展示、仪表盘。优点是鼠标悬停看数值、缩放、筛选、导出 HTML。缺点是对出版级精细控制不如 Matplotlib。

选择依据：
- 需要打印或发表 → Matplotlib
- 需要在浏览器交互探索 → Plotly
- 需要地图投影 → Plotly（scatter_geo）
- 需要精细排版控制 → Matplotlib

实际项目中两者常搭配使用：用 Plotly 快速探索数据，确定要展示的内容后用 Matplotlib 生成出版级图表。

</Answer>

**问题 2**：以下 API 调用代码有什么风险？如何改进？

```python
response = requests.get(url)
data = response.json()
print(data["results"])
```

<Answer>

风险：
1. **网络异常**：`requests.get()` 可能因网络问题抛出 ConnectionError 或 Timeout
2. **HTTP 错误**：服务器可能返回 404、500 等错误状态码，但 `response.json()` 仍尝试解析错误页面
3. **JSON 解析失败**：响应可能不是有效 JSON
4. **键不存在**：`data["results"]` 可能因 API 返回格式变化而 KeyError

改进：

```python
try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()  # 检查 HTTP 状态码
    data = response.json()
    results = data.get("results", [])  # 安全取值
    print(results)
except requests.ConnectionError:
    print("网络连接失败")
except requests.Timeout:
    print("请求超时")
except requests.HTTPError as e:
    print(f"HTTP 错误: {e}")
except ValueError:
    print("响应不是有效 JSON")
except KeyError:
    print("响应格式不符合预期")
```

</Answer>

<GlossaryItem term="Matplotlib">

Python 最基础的绘图库。pyplot 模块提供 plot（折线）、scatter（散点）、hist（直方图）等函数。适合生成静态高质量图表用于论文和报告。自定义精细但无交互性。

</GlossaryItem>

<GlossaryItem term="Plotly">

交互式图表库。plotly.express 提供简洁高级 API。图表在浏览器中支持悬停、缩放、筛选。write_html() 导出为独立 HTML。适合数据探索和 Web 展示。

</GlossaryItem>

<GlossaryItem term="图表类型选择">

折线图展示趋势（时间变化）、散点图展示关系（两个变量）、直方图展示分布（频率统计）、条形图展示对比（分类数据）。选错类型会误导读者。

</GlossaryItem>

<GlossaryItem term="API 数据获取">

用 requests.get() 从 Web API 获取 JSON 数据。raise_for_status() 检查 HTTP 状态码，json() 解析响应。提取字段后传入可视化库。完整流程：API 请求 → JSON 解析 → 数据提取 → 可视化。

</GlossaryItem>
