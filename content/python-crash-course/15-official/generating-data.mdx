## 直觉：先画一张路线明确的地图

想检查一张地图是否画对，最好先走一条自己知道的路线。只看陌生数据生成的漂亮图片，很难判断问题出在数据还是画法。

本章先自己造数：算平方、逐步移动、反复掷骰。每张图都有可核对的规则。这样不仅能画出来，还能解释图上的位置、形状和偏差从哪里来。

## 五个概念，把生成和绘制分开

### 1. 同一批点，连起来和不连起来回答不同问题

<Term def="按输入顺序连接数据点，强调相邻样本变化的图。">线图</Term>（line graph）适合展示有顺序的变化。Matplotlib 的 `ax.plot(x, y)` 不会替你按 x 排序；如果顺序乱了，线就来回折返。

<Term def="用点的位置表示每个观测的两个数值，不默认连接相邻观测的图。">散点图</Term>（scatter plot）把关注点放在每个位置上，使用 `ax.scatter(x, y)`。实验①把线与圆点叠加：圆点是实际计算出的值，线段只是连接，不是新增测量。

显式传入 `x=[1,2,3,4,5]` 很重要。只给平方值 `[1,4,9,16,25]` 时，默认横坐标是 `0..4`，于是第一点被错放到 x=0。下面 `square.py` 用相同 x/y 同时绘制两种图，让错位很容易被发现。

### 2. 样式是图的说明书，不是装饰

标题回答“画的是什么”，轴标签回答“两个方向各量什么”，刻度让读者估计数值。`plt.subplots()` 返回整张画布 `fig` 和具体绘图区 `ax`；标题、刻度、点线一般设置在 `ax` 上，保存整张图使用 `fig`。

<Term def="把一组数值按同一规则映射为颜色，例如值越大颜色越深。">颜色映射</Term>（colormap）可由 `scatter(c=y, cmap="Blues")` 指定，旁边的颜色条解释深浅。单一颜色则用 `color="royalblue"`。不要同时设置互相冲突的 `c` 与 `color`，也不要用颜色暗示数据里不存在的类别。

实验①的圆点越高越深；Python 图还带颜色条。`set_xticks()` 选择哪些值出现，`tick_params(labelsize=...)` 控制刻度字号。刻度文字、标签与颜色应在导出后再看一遍，不能只确认文件存在。

### 3. 随机游走是累加位移，不是独立撒点

<Term def="从起点出发，每次随机选一个位移，并把它累加到当前位置得到下一点的过程。">随机游走</Term>（random walk）先有 `(0,0)`，随后分别选 x、y 的方向和距离。下一点是“上一点加本次位移”。如果每次直接随机生成绝对坐标，那是在撒点，不是游走。

本章每轴距离取 `0..最大步长` 的整数，方向取正或负。两个位移都是零时不记录新点；一轴为零、另一轴不为零则是合法移动。点数含原点，所以 N 个点只有 N−1 次被接受的移动。把最大步长设为零却又拒绝原地步，会导致循环无法完成；示例和实验都在入口拒绝该值。

<Term def="初始化伪随机生成器状态的值；同一实现中配合相同调用顺序，可重复生成序列。">随机种子</Term>（random seed）用于复现一次实验。`Random(seed)` 建立局部生成器，不扰动其他代码的随机状态。实验②用 seed 和 seed+1 生成两条路径；同参数再生成，坐标不变。

### 4. 路径的起终点与坐标轴会改变读图方式

实验②用空心圆标原点、方形标终点，以实线和虚线区别两条路径，不只依赖颜色。A 的点从浅到深表示时间先后。两条路径必须共享相同范围，横纵一单位也应占相同长度，否则同样的位移会看起来偏长或偏短。

Python 中用 `set_aspect("equal", adjustable="box")` 保持等比例；两轴使用共同的对称上下限。隐藏轴适合突出路径形状，但会丢失距离信息。实验的“坐标轴”按钮只改变显示，图下仍保留数值范围和终点，数据没有消失。把点数增加五倍，路径范围不一定增加五倍，因为前后移动可能抵消。

### 5. 骰子的柱高来自计数，理论来自组合

<Term def="某个结果在全部试验中出现的次数；除以试验总数才是频率。">频数</Term>（frequency count）是柱子的高度。对离散骰子结果，先计数再画柱状图很直观；不是把已经汇总的次数误当成原始投掷数据再重复分箱。

<Term def="根据模型计算的各结果概率，而不是从有限样本中数出来的比例。">理论分布</Term>（theoretical distribution）为实际柱形提供参照。两颗公平且独立的六面骰有 6×6=36 个等可能的有序组合。和为 2 只有 `(1,1)`；和为 7 有 `(1,6)` 到 `(6,1)` 六种。和从 2 到 12 的组合数依次为 `1,2,3,4,5,6,5,4,3,2,1`，分别除以 36 才是概率。

投 N 次时，某根柱的理论期望次数为 `N × 对应组合数 / 36`，可以不是整数。用 Plotly Express 的 `px.bar()` 画实际频数，再叠加期望折线。实验③展示两者差异；“错误理论”会把期望错画为 `N/11`，暴露“每个和都等可能”的误解。

## 交互实验：先预测，再改一个量

猜一猜：把数量从 120 调到 600，和为 7 的柱一定最高吗？保持种子不变，只把步长从 4 调到 6，骰子图应不应该变化？

<PccGeneratingDataLab />

1. 记录默认的 A 前四点、终点和双骰频数，再按一次“生成样本”。三个结果都应相同。
2. 只改 N 为 600，检查旧路径是否是新路径的前段。比较的是**频率**与概率，不是两张图的绝对柱高；图会自动重算坐标范围。
3. 保持 N 与 seed，只改步长。游走变化，骰子不变，因为掷骰程序不使用步长。
4. 开启“错误理论”，找出水平线为何不适合双骰。关闭后恢复三角形期望，再隐藏/恢复坐标轴，判断哪些信息丢失了。
5. 输入 N=1、空 seed 或步长=0，再生成：应出现边界提示并保留旧图。按“完整重置”，输入值、样本、坐标轴和错误开关均回到默认。

<Callout type="info" title="复现的边界：不要跨语言硬对序列">

网页使用 JavaScript 的 32 位线性同余伪随机生成器，Python 使用 `random.Random`。两者算法不同；相同 seed **不保证生成相同的骰子或坐标**。复现应记录语言、版本、算法、参数以及随机函数调用顺序。网页图服务于机制演示，不是 Python 输出的截图。

</Callout>

## 代码实践：四个文件，无需下载外部数据

下面是本站独立编写的完整小程序，不是原书代码复刻。把四段分别保存为标明的文件名，放在同一目录。运行前三个入口脚本前，需要当前解释器环境已安装 `matplotlib`、`plotly` 和 `pandas`；后者支持 Plotly Express 的数据处理。`random_walk.py` 是本章同时提供的本地模块，不是额外依赖。

### square.py：线、散点、样式与 PNG

先选 `Agg` 无界面绘图后端，再导入 `pyplot`，这样没有桌面的机器也能导出。显式 x 防止错位；`c=y` 把颜色与平方值关联，`set_xticks` 保留所有五个采样位置。保存后关闭画布，重复运行不会积累未关闭的图。

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [value ** 2 for value in x]
fig, ax = plt.subplots(figsize=(6, 4), layout="constrained")
ax.plot(x, y, linewidth=2, color="gray", label="Connecting samples")
points = ax.scatter(x, y, c=y, cmap="Blues", s=80, edgecolors="black")
ax.set_title("Square numbers", fontsize=16)
ax.set_xlabel("Input value", fontsize=12)
ax.set_ylabel("Squared value", fontsize=12)
ax.set_xticks(x)
ax.tick_params(axis="both", labelsize=11)
ax.grid(alpha=0.25)
ax.legend(fontsize=10)
fig.colorbar(points, ax=ax, label="Squared value")
fig.savefig("square.png", dpi=160, bbox_inches="tight")
plt.close(fig)
assert y == [1, 4, 9, 16, 25]
print("square.png", list(zip(x, y)))
```

`fig.savefig()` 是真实图片导出；扩展名 `.png` 决定格式，`dpi` 控制像素密度，`bbox_inches="tight"` 使外侧标签也纳入边界。它不会保留 Plotly 那样的交互操作。这里使用英文图内标签，避免机器缺少中文字体时出现方块，中文解释留在正文。

### random_walk.py：只负责生成坐标

构造器先验证参数，避免零步长导致永远在拒绝原地步。每次 `generate()` 都从给定 seed 和原点重新开始，所以对同一实例重复调用也可复现。方向和距离分别随机选取，与一次性从 `-step..step` 均匀抽整数的概率规则并不相同；改生成规则就不是同一个实验了。

```python
from random import Random

class RandomWalk:
    def __init__(self, num_points=120, max_step=4, seed=42):
        if any(type(v) is not int for v in (num_points, max_step, seed)):
            raise ValueError("parameters must be integers")
        if not 2 <= num_points <= 1200 or not 1 <= max_step <= 6:
            raise ValueError("points: 2..1200; step: 1..6")
        if not 0 <= seed <= 4294967295:
            raise ValueError("seed: 0..4294967295")
        self.num_points, self.max_step, self.seed = num_points, max_step, seed

    def generate(self):
        rng = Random(self.seed)
        xs, ys = [0], [0]
        while len(xs) < self.num_points:
            dx = rng.choice((-1, 1)) * rng.randint(0, self.max_step)
            dy = rng.choice((-1, 1)) * rng.randint(0, self.max_step)
            if dx == 0 and dy == 0:
                continue
            xs.append(xs[-1] + dx)
            ys.append(ys[-1] + dy)
        return xs, ys
```

这里 x、y 数组始终等长；只在接受一步之后才同时追加。模型不关心点的颜色、轴是否可见或文件名，这使生成逻辑可以单独测试。

### walks.py：两条路径、共同起点、各自终点与轴

先拿到两组坐标，再统一计算范围。散点颜色从第 0 点到末点渐变，B 另加虚线；空心圆和方形还提供不依赖颜色的辨识方式。`ax.set_axis_off()` 可隐藏轴；比较距离时应保留现在的轴，不要对两条路径分别自动缩放后比较大小。

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from random_walk import RandomWalk

walks = [RandomWalk(seed=seed).generate() for seed in (42, 43)]
fig, ax = plt.subplots(figsize=(6, 6), layout="constrained")
for i, (xs, ys) in enumerate(walks):
    ax.plot(xs, ys, linestyle="-" if i == 0 else "--", alpha=0.6)
    ax.scatter(xs, ys, c=range(len(xs)), cmap="Blues" if i == 0 else "Oranges", s=12)
    ax.scatter(xs[-1], ys[-1], marker="s", s=90, label=f"End {i + 1}")
    print(f"walk {i + 1}: first4={list(zip(xs, ys))[:4]}, end={xs[-1], ys[-1]}")
ax.scatter(0, 0, marker="o", s=130, facecolors="none", edgecolors="black", label="Start")
bound = max(1, max(abs(v) for walk in walks for axis in walk for v in axis)) + 2
ax.set(xlim=(-bound, bound), ylim=(-bound, bound), xlabel="x", ylabel="y")
ax.set_aspect("equal", adjustable="box")
ax.set_title("Two random walks: 120 points each")
ax.tick_params(labelsize=11)
ax.legend()
fig.savefig("random_walks.png", dpi=160, bbox_inches="tight")
plt.close(fig)
```

把两处种子改成相同值时，两条路径应该重合；重合是可重复性的证据，不是“第二条没生成”。只增加点数通常会扩展范围，但不会保证终点离原点更远。

### dice.py：汇总双骰结果，并导出独立 HTML

`Die` 只负责生成一颗骰子的点数。两颗骰子共用同一个局部生成器，轮流取下一次随机数；不要每掷一次就重新用同一 seed 创建生成器，否则会反复得到同样的结果。列表 `values` 明确枚举 2–12，`Counter` 对缺失的结果返回 0，因此少量投掷也不会丢失类别。

```python
from random import Random
from collections import Counter
import plotly.express as px

class Die:
    def __init__(self, rng, sides=6):
        if type(sides) is not int or sides < 2:
            raise ValueError("sides must be an integer >= 2")
        self.rng, self.sides = rng, sides

    def roll(self):
        return self.rng.randint(1, self.sides)

rng = Random(42)
die_1, die_2 = Die(rng), Die(rng)
n = 1200
counts = Counter(die_1.roll() + die_2.roll() for _ in range(n))
values = list(range(2, 13))
frequencies = [counts[value] for value in values]
expected = [n * (6 - abs(value - 7)) / 36 for value in values]
assert sum(frequencies) == n and set(counts) <= set(values)
fig = px.bar(x=values, y=frequencies, labels={"x": "Sum", "y": "Frequency"}, title="Two fair D6")
fig.add_scatter(x=values, y=expected, mode="lines+markers", name="Expected count")
fig.update_xaxes(dtick=1)
fig.write_html("dice.html", include_plotlyjs=True, full_html=True, auto_open=False)
print("dice.html", dict(zip(values, frequencies)))
```

`write_html()` 才是网页导出，不能把 `savefig` 当成 Plotly 方法。`include_plotlyjs=True` 把所需脚本写入文件，文件较大但不依赖 CDN；`auto_open=False` 不会擅自启动浏览器。这里的“独立”表示绘图代码和数据已嵌入，不代表网页截图已经验收。若改成外链脚本模式，离线打开可能只看到空白。

## 常见误区与修法

<Callout type="trap" title="第一点为何落到 x=0？">

**现象 →** 平方值 1 被画在 x=0，而不是 x=1。<br />
**原因 →** 只传 y，绘图库使用从零开始的下标作 x。<br />
**修法 →** 同时传入相同长度的 x 和 y；对照实验①检查五个圆点的坐标。

</Callout>

<Callout type="trap" title="为什么增加样本后，柱子仍不完全贴理论？">

**现象 →** N 增大，实际次数与理论期望仍有差距。<br />
**原因 →** 有限样本存在随机波动，期望不是必须实现的配额；绝对次数差还可能增大。<br />
**修法 →** 比较频率差；先关闭实验中的“错误理论”，再检查独立、公平的生成规则。

</Callout>

<Callout type="trap" title="游走程序卡住，或形状被拉长">

**现象 →** 步长为零时没有输出；或对角方向看起来被拉伸。<br />
**原因 →** 拒绝原地步后循环无法前进，或横纵轴单位比例不同。<br />
**修法 →** 入口拒绝零步长，并使用等比例轴；网页非法输入应报错而不是冻结。

</Callout>

<Callout type="trap" title="图文件存在，就算完成了吗？">

**现象 →** 图片标签被截断，或离线 HTML 无图。<br />
**原因 →** 只查文件名，不查内容；也可能把绘图脚本放在外部 CDN。<br />
**修法 →** 查看实际 PNG 的边界；用内嵌脚本导出 HTML，再单独完成浏览器打开与交互检查。

</Callout>

## 小结与练习

- 同一坐标可画线或点；标签和颜色须解释数据。
- 生成与绘制分离，种子、步长与等比例轴各司其职。
- 双骰概率来自组合；计数总和与导出结果都要核查。

**问题 2：** 在实验中固定 seed=42，令 N 从 120 改为 600，再只改最大步长。哪些结果应保持不变？若允许步长=0，需要怎样改程序才不会卡住？

**小分问：读图诊断。** 固定同一份点数据，在非正方形绘图区把等比例改成不等比例，再隐藏坐标轴：真实起终点位移、路径的视觉形状和数值可读性分别是否改变？不要重新生成随机点。标出起点和终点，并用断言确认坐标没有被这些显示设置改写。比较实际距离与展示路径轮廓时，你会分别如何选择坐标轴？

<Answer>

只增加 N，先前的坐标序列与骰子结果序列仍是新序列的前缀，但终点、范围和汇总频数可能变化。只改步长则骰子计数保持不变，路径不保证按比例放大，因为可选距离及原地步的拒绝次数都会变化。步长为零且拒绝原地步时无法补足点数。本章选择入口报错；若另一种模型要允许零步长，就必须允许把重复位置记录为一步，并明确 N 记录的是时间点，不能直接保留当前拒绝规则。

小分问中，真实位移始终是 `(xs[-1] - xs[0], ys[-1] - ys[0])`。同样的坐标范围放进宽长方形绘图区，使用 [`set_aspect("auto")`](https://matplotlib.org/stable/api/_as_gen/matplotlib.axes.Axes.set_aspect.html) 会让横纵单位的屏幕长度不同，路径看起来被拉伸，但点数据和真实位移没变。`"equal"` 才保证横纵一个数据单位等长；正方形绘图区恰好可能掩盖错误，不能只看外观猜设置。

隐藏轴不会删点，也不会自动修复比例；刻度与轴标签消失，读者更难判断坐标和距离。比较实际距离时保留刻度、标签及等比例；只展示轮廓可隐藏轴，但仍保留等比例、起终点标记与图例，不能要求读者从无刻度图中读出精确位移。以下代码与正文 `random_walk.py` 放在同一目录，故意导出不等比例、无轴的诊断图：

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from random_walk import RandomWalk

xs, ys = RandomWalk(seed=42).generate()
before = (tuple(xs), tuple(ys))
fig, ax = plt.subplots(figsize=(8, 4))
ax.plot(xs, ys)
start = ax.scatter(xs[0], ys[0], marker="o", label="Start")
end = ax.scatter(xs[-1], ys[-1], marker="s", label="End")
bound = max(1, *(abs(v) for v in xs + ys)) + 2
ax.set(xlim=(-bound, bound), ylim=(-bound, bound), xlabel="x", ylabel="y")
ax.set_aspect("equal", adjustable="box")
assert ax.get_aspect() == 1.0 and ax.axison
ax.set_aspect("auto")
ax.set_axis_off()
assert ax.get_aspect() == "auto" and not ax.axison
assert (tuple(xs), tuple(ys)) == before
assert tuple(start.get_offsets()[0]) == (xs[0], ys[0])
assert tuple(end.get_offsets()[0]) == (xs[-1], ys[-1])
ax.legend()
fig.savefig("walk_axis_diagnosis.png", dpi=160)
plt.close(fig)
```

恢复为 `ax.set_aspect("equal", adjustable="box")` 和 `ax.set_axis_on()` 后另存一张对照图；起终点仍相同。数据断言只证明没有改坐标，比例和轴状态断言才检查显示选择，不能用前者替代后者。

</Answer>

## 名词解释

<Glossary>
  <GlossaryItem term="线图">Line graph：依输入顺序连接相邻数据点，适合观察有顺序的变化，不会自动排序。</GlossaryItem>
  <GlossaryItem term="散点图">Scatter plot：每个点用横纵位置表示一对数值，不默认把观测连成线。</GlossaryItem>
  <GlossaryItem term="颜色映射">Colormap：数值到颜色的对应规则；颜色条帮助读者把颜色还原成数值。</GlossaryItem>
  <GlossaryItem term="随机游走">Random walk：逐次累加随机位移得到路径；不是每次独立随机挑一个绝对位置。</GlossaryItem>
  <GlossaryItem term="随机种子">Random seed：初始化伪随机生成器的值；复现还依赖实现与调用顺序，并非跨语言通用的序列编号。</GlossaryItem>
  <GlossaryItem term="频数">Frequency count：结果出现的次数；相对频率 relative frequency 则是次数除以总数，两者不要混用。</GlossaryItem>
  <GlossaryItem term="理论分布">Theoretical distribution：由模型推导出的概率安排；乘试验次数得到期望次数，不保证样本恰好等于期望。</GlossaryItem>
</Glossary>
