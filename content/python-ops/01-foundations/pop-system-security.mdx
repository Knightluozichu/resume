## 核心模型与责任

Python与系统安全首先是权限与证据工程。自动化工具只在明确授权范围运行，输入目标、扫描时间、操作者和结果摘要写入审计记录，任何破坏性动作都要求单独批准。
本章按照原书核心模块建立最小实验，再用现代Python和安全默认重写边界。工具版本可以变化，但目标选择、输入验证、结果聚合和审计证据不能消失。

## 机制一：采集或控制入口

集中式病毒扫描让客户端把文件流或路径送给ClamAV服务，结果要区分干净、命中、引擎失败和超时。扫描前限制大小和类型，隔离命中文件而不是直接删除。
```python
import clamd
scanner = clamd.ClamdUnixSocket()
assert scanner.ping() == 'PONG'
result = scanner.scan('/quarantine/upload.bin')
print(result or {'status': 'clean'})
```

运行前固定测试目标与时间窗，运行后保存结构化结果、耗时和异常类型。不要把打印了几行输出当成成功，也不要让示例凭据进入源码。

## 机制二：状态、网络与批量

pyClamd与ClamAV通过Unix socket或TCP连接clamd。网络暴露的clamd没有天然认证，必须放在受控网络或本地socket后；病毒库版本与扫描引擎版本也是结果证据。

```python
import asyncio
async def probe(host, port):
    try:
        reader, writer = await asyncio.wait_for(asyncio.open_connection(host, port), 0.5)
        writer.close(); await writer.wait_closed()
        return port, 'open'
    except (TimeoutError, OSError):
        return port, 'closed'
```

批量任务要先预览匹配目标，再限制并发并逐目标汇总。成功、失败、超时和未返回是不同状态；只展示总成功率会掩盖关键主机失败。

## 机制三：证据与恢复

高效端口扫描器可用有界线程或异步连接并发探测，但并发、超时和目标范围必须受预算控制。连接成功只表示端口接受连接，不等于服务身份或安全性。
安全扫描授权与边界包括书面许可、允许网段、端口、速率、时间窗和数据留存。扫描器默认拒绝公网或超范围目标，日志不记录密钥，失败时可立即停止全部任务。
```python
from ipaddress import ip_address, ip_network
AUTHORIZED = ip_network('192.0.2.0/24')
def authorize(target):
    address = ip_address(target)
    if address not in AUTHORIZED:
        raise PermissionError('target outside approved scope')
    return address
```
