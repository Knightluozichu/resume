## 从一次运维变更开始

先预测：脚本在一台测试机成功，是否就能安全用于批量生产？不能。还要说明目标、权限、超时、部分失败、证据和回滚。必须落进可观察的执行链。


## 核心模型与责任

轻量级WebServer章节通过Yorserver串联套接字、请求解析和功能分派。教学实现用来理解协议边界，不应直接暴露到生产；请求行、header大小、路径和超时都必须有限制。
本章按照原书核心模块建立最小实验，再用现代Python和安全默认重写边界。工具版本可以变化，但目标选择、输入验证、结果聚合和审计证据不能消失。

## 机制一：采集或控制入口

Yorserver配置与架构把监听、静态文件、缓存、压缩、TLS、目录和CGI拆成模块。配置在启动时验证，运行期只读取不可变快照，重载失败继续保留旧配置。
```python
from http.server import ThreadingHTTPServer, SimpleHTTPRequestHandler
server = ThreadingHTTPServer(('127.0.0.1', 8080), SimpleHTTPRequestHandler)
try: server.serve_forever()
finally: server.server_close()
```

运行前固定测试目标与时间窗，运行后保存结构化结果、耗时和异常类型。不要把打印了几行输出当成成功，也不要让示例凭据进入源码。

## 机制二：状态、网络与批量

HTTP缓存与压缩依据Cache-Control、ETag、If-None-Match和Accept-Encoding协商。压缩只用于合适内容类型并设置Vary，缓存键必须包含会影响表示的请求维度。

```python
from hashlib import sha256
def etag(payload: bytes) -> str:
    return '"' + sha256(payload).hexdigest() + '"'
if request.headers.get('If-None-Match') == etag(body):
    send_status(304)
```

批量任务要先预览匹配目标，再限制并发并逐目标汇总。成功、失败、超时和未返回是不同状态；只展示总成功率会掩盖关键主机失败。

## 机制三：证据与恢复

HTTP SSL与目录列表的安全边界包括现代TLS配置、证书轮换和路径规范化。目录列表默认关闭；若开启，根目录固定、HTML转义文件名并拒绝父目录逃逸。
动态CGI功能用子进程环境与标准输入输出连接脚本，风险包括命令注入、资源耗尽和权限扩大。现代服务通常使用WSGI或ASGI进程模型，但仍需理解网关如何隔离请求。
```python
from pathlib import Path
ROOT = Path('/srv/public').resolve()
def safe_path(raw):
    target = (ROOT / raw.lstrip('/')).resolve()
    if ROOT not in target.parents and target != ROOT:
        raise PermissionError('path escapes document root')
    return target
```
