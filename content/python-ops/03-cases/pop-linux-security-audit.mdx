## 核心模型与责任

Linux系统安全审计收集登录、账号、进程、端口和配置变化，目标是不可抵赖的时间线而不是监控所有内容。采集范围遵守最小必要与隐私规则，原始事件只追加。 <Term def="审计平台架构由主机agent、认证上报、队列、规范化服务、不可变存储和查询组成。agent断网时本地有界缓冲，重连按事件ID去重；服务器时钟偏差单独记录。">审计平台架构</Term>
