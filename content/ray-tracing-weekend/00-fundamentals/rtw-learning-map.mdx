## 直觉引入

把渲染想成「反向追光」：真实世界里光从光源出发，弹射无数次后进入眼睛；而光线追踪反过来——从眼睛（相机）发射射线，穿过像素，撞到物体后计算它「看见了什么颜色」。这样不需要猜物体该亮还是该暗，只要老老实实模拟光的弹射路径，阴影、反射、折射自然就出现了。

这本书用一个周末的时间，带你从「画一个渐变背景」开始，一步步加上球体、相机、材质、散射，最后渲染出一张布满玻璃球与金属球的真实感图片。没有第三方引擎，全部用几百行 C++ 从零写出来。

## 概念讲解

全书分四个阶段：**基础**（输出、向量、射线）、**几何与采样**（球体、法线、多物体、抗锯齿）、**材质**（漫反射、金属、玻璃）、**相机与收尾**（可定位相机、景深、最终场景）。

是追踪的最小单位。
是材质的本质。
是真实感的来源。
是画质的关键。

### 阶段依赖

- 基础 → 几何：有了射线方程，才能求它与球体的交点。
- 几何 → 材质：有了相交点和法线，材质才知道往哪散射。
- 材质 → 收尾：散射加上景深与多采样，画面才真实。

## 原书十二单元如何落到当前专题

官方 2025 版不是“直接写一个球”就结束。它先要求你能够稳定输出像素，再构造向量工具，之后才有相机射线。当前路径把相邻且共享代码骨架的原书单元合在同一专题里，但不会省略它们：每一个单元都能在后续专题中找到明确的实现落点。

### 1. 输出与数学底座

1. **Output an Image**：先写 PPM，把每个像素的线性颜色输出为文件。没有可检查的输出，之后的几何错误没有落点。
2. **The vec3 Class**：用同一个 `vec3` 表示方向、`point3` 位置与 `color` 颜色；它们是点积、反射、折射和颜色累乘的共同语言。
3. **Rays, a Simple Camera, and Background**：从相机穿过像素发出 `ray`，未命中时返回天空渐变。当前“光线与射线相交”和“相机与光线生成”共同承载它。

### 2. 几何、法线与采样

4. **Adding a Sphere**：把射线代入球方程，以判别式判断命中并取最近正根。
5. **Surface Normals and Multiple Objects**：记录 `hit_record`、统一 `hittable` 接口，并通过 `front_face` 让法线方向可靠。
6. **Antialiasing**：一个像素不只发一条中心射线；加入随机子像素偏移后平均，并在线性平均后做伽马校正。

### 3. 三种散射材质

7. **Diffuse Materials**：哑光表面把能量按反照率衰减，并用随机方向继续追踪。
8. **Metal**：反射方向围绕法线镜像；`fuzz` 控制由清晰倒影到磨砂高光的过渡。
9. **Dielectrics**：玻璃需要在折射、全内反射和 Schlick 反射概率之间选择路径。

### 4. 相机与成片

10. **Positionable Camera**：通过 `lookfrom`、`lookat`、`vup` 建立相机坐标架，而不是把相机钉死在原点。
11. **Defocus Blur**：从透镜圆盘而非单点发射样本，只有焦平面附近保持清晰。
12. **Final Render**：把世界、材质、相机、采样数和递归深度组装成一个可重复渲染的测试场景。

当前项目用八个实作专题承载上述十二单元，再以本页建立依赖关系、用总复习做故障定位。这样既保留原书学习顺序，也避免把同一段 C++ 骨架拆成没有独立练习价值的碎页。

### 学习节奏建议

- 第一章通读全图，建立全局观；
- 第 2–4 章是「能渲染出球」的骨架，必须动手写；
- 第 5–8 章是「能渲染出材质」的血肉，逐个加；
- 第 9–10 章是组装与复盘。

## 代码对照

全书核心循环的骨架（C++），三件事：生成光线、求交散射、累加颜色。

```cpp
// 主渲染循环：逐像素发射光线
for (int j = image_height - 1; j >= 0; --j) {
  for (int i = 0; i < image_width; ++i) {
    color pixel_color(0, 0, 0);
    for (int s = 0; s < samples_per_pixel; ++s) {
      auto u = (i + random_double()) / (image_width - 1);
      auto v = (j + random_double()) / (image_height - 1);
      ray r = cam.get_ray(u, v);
      pixel_color += ray_color(r, world, max_depth);
    }
    write_color(std::cout, pixel_color, samples_per_pixel);
  }
}

// 递归着色：撞到物体就按材质散射，没撞到就返回背景
color ray_color(const ray& r, const hittable& world, int depth) {
  hit_record rec;
  if (depth <= 0) return color(0, 0, 0);          // 递归上限
  if (world.hit(r, 0.001, infinity, rec)) {
    ray scattered; color attenuation;
    if (rec.mat_ptr->scatter(r, rec, attenuation, scattered))
      return attenuation * ray_color(scattered, world, depth - 1);
    return color(0, 0, 0);
  }
  vec3 unit_dir = unit_vector(r.direction());
  auto t = 0.5 * (unit_dir.y() + 1.0);
  return (1.0 - t) * color(1.0, 1.0, 1.0) + t * color(0.5, 0.7, 1.0);
}
```

`samples_per_pixel` 控制抗锯齿与降噪，`max_depth` 控制反射弹射次数，两者是画质与耗时的旋钮。

下面这段最小输出代码对应原书的第一个单元。它不着色任何几何体，却能验证像素遍历顺序、颜色范围和 PPM 文件是否正确；后续所有 `ray_color` 的结果都会流进同一个 `write_color` 边界。

```cpp
void write_color(std::ostream& out, const color& pixel_color) {
  const auto r = std::clamp(pixel_color.x(), 0.0, 0.999);
  const auto g = std::clamp(pixel_color.y(), 0.0, 0.999);
  const auto b = std::clamp(pixel_color.z(), 0.0, 0.999);
  out << int(256 * r) << ' ' << int(256 * g) << ' ' << int(256 * b) << '\n';
}

for (int j = 0; j < image_height; ++j) {
  for (int i = 0; i < image_width; ++i) {
    write_color(std::cout, color(double(i) / image_width, double(j) / image_height, 0));
  }
}
```

这一步应先看到红绿渐变的 PPM，再接入相机和场景。若一开始就把 PPM、射线、材质和景深同时接上，任何全黑或上下翻转都无法快速归因。

## 小结

- 先让 PPM 与 `vec3` 正确工作，再让相机为每个像素产生射线。
- `hit_record` 把几何信息交给统一的 `scatter` 接口，材质因此可以递归组合。
- 多样本平均解决锯齿与随机噪点，`max_depth` 则限制每条路径允许弹射的次数。
- 原书的十二个核心单元已映射到当前八个实作专题、全书地图和总复习；按依赖顺序完成比跳章更容易定位错误。
