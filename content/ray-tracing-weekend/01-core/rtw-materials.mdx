## 直觉引入

同样一束光打在墙、镜子和玻璃上，结果完全不同：墙把光随机弹向四面八方（哑光），镜子把光按原路反射（清晰成像），玻璃让光穿过去并弯折（折射）。这些「光被打到后变成什么样」的行为，就是材质。

光线追踪把材质抽象成一个统一的问答：给你入射光和命中信息，请告诉我（1）这束光被吸收了多少、剩多少颜色（衰减），（2）它沿着哪条新方向继续走（散射光）。只要每种材质回答这两个问题，递归就能无限组合下去。

## 概念讲解

的核心方法是 `scatter(r_in, rec, attenuation, scattered)`：输入入射射线与命中记录，输出（attenuation，一个颜色向量）和（scattered）。

### 三种内置材质
- **漫反射（lambertian）**：散射方向 = 交点法线 + 随机单位向量，attenuation = 基础色。
- **金属（metal）**：散射方向 = 入射方向关于法线的镜面反射 + 模糊扰动，attenuation = 金属色。
- **电介质（dielectric）**：按折射定律在反射与折射间选择，attenuation ≈ 白（不吸收）。

### 材质与命中记录绑定
球创建时传入材质指针，求交命中后写入 `rec.mat_ptr`。ray_color 拿到 rec 后调 `rec.mat_ptr->scatter(...)`，材质只关心 rec 里的法线、交点、front_face，与几何体类型解耦。

### scatter 的返回值定义路径是否继续

`scatter` 返回 `true` 并不表示“这次反射一定更亮”，它只表示材质为当前入射光采样出了一条下一跳射线。`attenuation` 是这条路径的乘子：红色墙会让后续任何天空、金属或玻璃的贡献都先乘上红色比例；多次弹射后，权重自然变小。

把递归写成数学式会更清楚。若当前命中材质给出衰减 $\boldsymbol{\alpha}$ 与下一条射线 $r'$，则当前估计颜色是：

$$
L(r)=\boldsymbol{\alpha}\odot L(r',\mathrm{depth}-1)
$$

其中 $\odot$ 是 RGB 逐分量乘法，不是点积。若 `scatter` 返回 `false`，材质没有给出下一跳，路径就在此终止并返回黑色；这为以后“完全吸收”的表面提供了明确语义。它不是异常情况，也不应回退去采样天空背景。

### 一条路径只采样一个散射方向

真实表面会向许多方向散射光，但这个小型路径追踪器不会在一次命中时复制成成百上千条子射线。它选择一个随机方向、让这条路径继续；同一像素跨许多样本重复该过程并取平均。正是“少量递归代码也能得到间接光”的原因。

因此 `scattered` 的方向和 `attenuation` 的权重必须成对设计。漫反射可用法线附近的随机方向配合反照率；金属可用镜面反射加扰动；玻璃在反射和折射中按概率选一个。若随机选方向却忘记更新对应权重，平均值会系统性偏亮或偏暗，而不是单纯增加噪点。

### 指针所有权与命中记录的不变量

解释了为何示例使用 `shared_ptr<material>`。多个球可以共享同一个漫反射对象，避免复制；更重要的是，`hit_record` 只在 `hit` 成功时写入 `mat_ptr`，于是 `ray_color` 可以把“命中成功意味着材质可调用”当作不变量。若某个几何体忘记赋材质，问题应在构建场景时被发现，而不是在深层递归中解引用空指针。

## 代码对照

C++ 材质抽象与 ray_color 调用：

```cpp
class material {
  public:
    virtual ~material() = default;
    virtual bool scatter(const ray& r_in, const hit_record& rec,
                         color& attenuation, ray& scattered) const = 0;
};

// ray_color 只认 scatter 接口，不关心是哪种材质
color ray_color(const ray& r, const hittable& world, int depth) {
  hit_record rec;
  if (depth <= 0) return color(0,0,0);
  if (world.hit(r, interval(0.001, infinity), rec)) {
    ray scattered; color attenuation;
    if (rec.mat_ptr->scatter(r, rec, attenuation, scattered))
      return attenuation * ray_color(scattered, world, depth-1);
    return color(0,0,0);                 // 全吸收
  }
  return background(r);
}

// 球创建时绑定材质
world.add(make_shared<sphere>(point3(0,0,-1), 0.5,
           make_shared<lambertian>(color(0.1,0.2,0.5))));
world.add(make_shared<sphere>(point3(0,-100.5,-1), 100,
           make_shared<lambertian>(color(0.8,0.8,0.0))));
```

`attenuation * ray_color(...)` 是关键：颜色逐层相乘衰减，深处的贡献被前面材质的色调过滤。

下面是最小的漫反射实现。`near_zero` 分支处理“随机向量刚好抵消法线”的退化情形，避免生成长度接近零、没有确定方向的射线：

```cpp
class lambertian : public material {
public:
  explicit lambertian(const color& albedo) : albedo(albedo) {}

  bool scatter(const ray&, const hit_record& rec,
               color& attenuation, ray& scattered) const override {
    auto direction = rec.normal + random_unit_vector();
    if (direction.near_zero()) direction = rec.normal;
    scattered = ray(rec.p, direction);
    attenuation = albedo;
    return true;
  }

private:
  color albedo;
};
```

也可以用一个刻意“吞光”的材质测试返回值约定。它不产生伪造的散射方向，调用者只会得到终止路径的黑色：

```cpp
class absorbing_material : public material {
public:
  bool scatter(const ray&, const hit_record&, color&, ray&) const override {
    return false;
  }
};

// 将一个测试球绑到 absorbing_material 后，它应遮住背景，
// 而不是变成天空色或访问未初始化的 scattered。
```

这两个极端案例共同检验接口：一个材质必须同时写出衰减和新射线再返回 `true`；另一个材质只要返回 `false`，递归就必须停止。金属和玻璃只是把第一种情况的方向生成方式替换掉。

## 小结

- `scatter=true` 必须同时提供 attenuation 与 scattered；`false` 明确表示路径在该表面被终止。
- attenuation 是沿路径逐分量相乘的吞吐量，不是直接写入屏幕的表面颜色。
- 单条路径只采样一个方向，多样本平均才近似完整的散射积分。
- 几何体把材质写入成功的 hit_record，递归层只依赖这份契约，不依赖几何类型。
