## 直觉引入

想象你站在原点朝远处开了一枪：子弹有一条起点 A 和一个方向 b，沿着 b 飞出去，任意时刻子弹的位置就是「起点 + 方向×时间」。这就是射线的全部数学。

现在场景里有一个球，球心 C、半径 r。问子弹什么时候撞上球？把子弹位置代入「到球心距离等于 r」这个方程，就得到一个关于时间 t 的一元二次方程。有实数解说明射线穿过球，取最小的正 t 就是第一个撞点。

## 概念讲解

写作 $\mathbf{P}(t) = \mathbf{A} + t\,\mathbf{b}$，$\mathbf{A}$ 是起点、$\mathbf{b}$ 是方向、$t$ 是参数。写作 $|\mathbf{P}-\mathbf{C}| = r$。

### 推导相交
把 $\mathbf{P}(t)$ 代入球面方程并两边平方：

$$
|\mathbf{A}+t\mathbf{b}-\mathbf{C}|^2 = r^2
$$

令 $\mathbf{o}=\mathbf{A}-\mathbf{C}$（起点相对球心的偏移），展开 $|\mathbf{o}+t\mathbf{b}|^2$ 得到标准二次型：

$$
(\mathbf{b}\cdot\mathbf{b})\,t^2 + 2(\mathbf{o}\cdot\mathbf{b})\,t + (\mathbf{o}\cdot\mathbf{o})-r^2 = 0
$$

记 $a=\mathbf{b}\cdot\mathbf{b}$，$h=\mathbf{o}\cdot\mathbf{b}$，$c=\mathbf{o}\cdot\mathbf{o}-r^2$，判别式 $\Delta=h^2-ac$。$\Delta&lt;0$ 无交点（射线错过球）；$\Delta=0$ 相切；$\Delta>0$ 两个交点，取较小的正根 $t=(-h-\sqrt\Delta)/a$。

### 根的顺序与命中区间

避免了标准公式里的 `2b` 和 `4ac`。只要 `a` 仍保留，方向向量没有归一化也完全合法：方向长度变成两倍时，根 `t` 会变成一半，但 `ray::at(t)` 得到的空间交点不变。问题不在于方向是否单位化，而在于不能一边保留非单位方向、一边又偷用 `a=1` 的简化公式。

$$
t_0 = \frac{-h-\sqrt{\Delta}}{a},\qquad
t_1 = \frac{-h+\sqrt{\Delta}}{a},\qquad t_0\le t_1
$$

离相机最近的根通常是 `t0`，但“最近”仍必须满足一个：`[t_min, t_max]`。先尝试 `t0`；若它不在区间内，再尝试 `t1`；两个都不在就报告未命中。这样能同时处理相机在球外、相机在球内和浮点误差造成的 `t≈0` 自相交。

### 从交点得到可检查的法线

球的外法线不需要额外求导。已知命中点 `p = r.at(root)`，只需从球心指向该点并除以半径：

$$
\mathbf{n}_{out}=\frac{\mathbf{p}-\mathbf{C}}{r}
$$

是建立材质前最有价值的检查图：右侧应偏红、上侧偏绿、朝向相机的一侧偏蓝。若颜色反转，优先检查 `p-center` 的减法顺序和根的正负，而不是先修改反射或折射代码。

背景渐变也需要单位方向，因为它把 `direction.y` 当作 [-1,1] 的插值输入。几何求交和背景着色对方向长度的要求不同，是初学者常把 `unit_vector` 放错位置的原因：求交保留 `a`，背景在读取 y 分量前归一化。

## 代码对照

C++ 实现射线类与球面求交：

```cpp
class ray {
  public:
    ray() {}
    ray(const point3& origin, const vec3& direction) : orig(origin), dir(direction) {}
    point3 origin() const    { return orig; }
    vec3   direction() const { return dir; }
    point3 at(double t) const { return orig + t * dir; }
  private:
    point3 orig;
    vec3   dir;
};

// 返回最近正根；负数表示未命中。
double hit_sphere(const point3& center, double radius, const ray& r) {
    vec3 oc = r.origin() - center;          // o = A - C
    auto a = dot(r.direction(), r.direction());
    auto h = dot(oc, r.direction());        // 半 b
    auto c = dot(oc, oc) - radius * radius;
    auto discriminant = h * h - a * c;
    if (discriminant < 0) return -1.0;

    auto root = (-h - sqrt(discriminant)) / a;
    if (root > 0.001) return root;
    root = (-h + sqrt(discriminant)) / a;
    return root > 0.001 ? root : -1.0;
}

// 没命中返回背景渐变；命中则按法线着色（红→蓝可视化）
color ray_color(const ray& r) {
    auto root = hit_sphere(point3(0, 0, -1), 0.5, r);
    if (root > 0) {
        vec3 N = unit_vector(r.at(root) - point3(0,0,-1));
        return 0.5 * color(N.x()+1, N.y()+1, N.z()+1);
    }
    vec3 unit_dir = unit_vector(r.direction());
    auto t = 0.5 * (unit_dir.y() + 1.0);
    return (1.0-t)*color(1,1,1) + t*color(0.5,0.7,1.0);
}
```

背景渐变是把射线方向 y 分量线性插值白→蓝，模拟天空。

## 小结

- 保留 `a=dot(direction,direction)` 时，射线方向无须在求交前单位化。
- 先检查小根、再检查大根，并始终以 `[t_min,t_max]` 排除背向命中与自相交。
- 从 `r.at(root)` 到球心的向量直接给出外法线；法线颜色图是材质前的可靠回归测试。
- 未命中的天空渐变需要单位方向，但这是着色需要，不是球体求交的前置条件。
