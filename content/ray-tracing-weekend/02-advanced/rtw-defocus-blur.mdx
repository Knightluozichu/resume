## 直觉引入

之前的相机是个「针孔」：所有光线都从同一个点出发，所以远近物体都一样清晰。真实相机有镜头，镜头有一定大小，光线从镜头各处进入并汇聚——只有恰好在「对焦距离」上的物体落在焦平面上最清晰，太近或太远的物体会发散成一团光斑，这就是景深/散焦模糊。

光线追踪用「薄透镜近似」模拟它：相机不再是单点，而是一个小圆盘；每条光线的起点在圆盘上随机取一点，但方向仍指向视口上同一像素对应的对焦点。对焦点固定在焦平面上，于是焦平面上的物体清晰，前后物体因不同起点出发的光线落点错开而模糊。

## 概念讲解

。设半径 $r$、 $f_d$。

### 构造散焦光线
1. 视口仍按焦距 $f_d$ 摆放（而非单位 1），使视口正好落在焦平面上。
2. 对像素 $(u,v)$，先算焦平面上的目标点 $\mathbf{t}$ = `lower_left_corner + u·horizontal + v·vertical`。
3. 在相机所在圆盘上随机取起点 $\mathbf{o}'=\mathbf{o}+\vec{p}_{disk}\cdot r$。
4. 该像素的这条采样光线 = `ray(o', t − o')`。

### 先建立能移动的相机坐标基

“圆盘在相机位置”不是指它永远躺在世界 XY 平面。应从 `lookfrom`、`lookat`、`vup` 构造：

$$
\mathbf{w}=\frac{\mathbf{lookfrom}-\mathbf{lookat}}{\|\mathbf{lookfrom}-\mathbf{lookat}\|},\qquad
\mathbf{u}=\frac{\mathbf{vup}\times\mathbf{w}}{\|\mathbf{vup}\times\mathbf{w}\|},\qquad
\mathbf{v}=\mathbf{w}\times\mathbf{u}
$$

`w` 指向镜头的后方，所以焦平面中心位于 `origin - focus_dist * w`。`u` 和 `v` 是透镜平面的两个轴；将单位圆盘里的二维样本 `(x,y)` 写成 `x*u + y*v`，光圈就会随相机旋转。若直接把 `(x,y,0)` 加到世界坐标，只有相机恰好朝 -Z 时景深才看起来正确。

### 光圈半径与离焦角是同一件事的两种参数

是官方新版更推荐的控制量；旧式 `aperture` 则直接给出透镜直径。两者的关系是：

$$
r_{lens}=\frac{\mathrm{aperture}}{2}
=f_d\tan\left(\frac{\mathrm{defocus\_angle}}{2}\right)
$$

当 `focus_dist` 变大而 aperture 半径固定时，构图尺度改变会连带改变离焦观感；用固定离焦角时，透镜半径随焦距比例调整，镜头语言更稳定。两种参数化都能工作，但项目里必须只选一种作为源参数，不能同时乘两次 `focus_dist`。

### 两类随机样本不能混用

与像素采样都发生在 `get_ray` 附近，却解决不同问题。像素样本改变焦平面上的目标点：

$$
\mathbf{p}_{focus}=\mathbf{pixel}_{00}+(i+\xi)\Delta\mathbf{u}+(j+\eta)\Delta\mathbf{v}
$$

透镜样本改变起点但不改变该次样本对应的焦点：

$$
\mathbf{o}'=\mathbf{o}+r_{lens}(x\mathbf{u}+y\mathbf{v}),\qquad
\mathbf{r}(t)=\mathbf{o}'+t(\mathbf{p}_{focus}-\mathbf{o}')
$$

若只做像素抖动，边缘会平滑但景深仍为零；若只做透镜采样，焦外会模糊但边缘锯齿仍存在。两者都要在同一像素的多次路径中平均，且样本数不足时，散焦区域会先表现为颗粒噪点而不是柔滑光斑。

### 为什么产生模糊
焦平面上的点：无论从圆盘哪个起点出发，方向都指向同一目标点，最终汇聚到同一像素——清晰。不在焦平面的点：不同起点出发的光线指向同一像素目标但实际经过该点的不同位置，叠加后散成一团——模糊。距离焦平面越远，散得越开，越模糊。

是景深可见效果的几何原因。不要把“背景模糊”误解为统一高斯滤镜：近景和远景会以不同尺度发散，遮挡边缘也会出现前景遮住背景光斑的复杂关系，这些都是逐路径几何采样自然产生的结果。

## 代码对照

C++ 散焦相机：

```cpp
class camera {
  public:
    camera(double vfov, double aspect, double focus_dist, double aperture) {
      auto theta = degrees_to_radians(vfov);
      auto h = tan(theta/2);
      viewport_height = 2 * h;
      viewport_width  = aspect * viewport_height;

      w = unit_vector(lookfrom - lookat);     // 视线反方向
      u = unit_vector(cross(vup, w));          // 右
      v = cross(w, u);                          // 上

      origin = lookfrom;
      horizontal = focus_dist * viewport_width * u;
      vertical   = focus_dist * viewport_height * v;
      lower_left_corner = origin - horizontal/2 - vertical/2
                          - focus_dist*w;
      lens_radius = aperture / 2;
    }
    ray get_ray(double s, double t) const {
      vec3 rd = lens_radius * random_in_unit_disk();   // 圆盘采样
      vec3 offset = u*rd.x() + v*rd.y();
      // 起点偏移，方向仍指向焦平面上的同一点
      return ray(origin + offset,
                 lower_left_corner + s*horizontal + t*vertical
                 - origin - offset);
    }
  private:
    point3 origin, lower_left_corner;
    vec3 horizontal, vertical, u, v, w;
    double lens_radius;
};
```

`random_in_unit_disk` 在单位圆内均匀采样；`offset` 让起点在光圈圆盘内游走，方向始终锁向焦平面对焦点。

```cpp
vec3 random_in_unit_disk() {
  while (true) {
    auto p = vec3(random_double(-1, 1), random_double(-1, 1), 0);
    if (p.length_squared() < 1) return p;
  }
}

double defocus_radius(double focus_dist, double defocus_angle_degrees) {
  return focus_dist * std::tan(degrees_to_radians(defocus_angle_degrees / 2));
}
```

拒绝采样得到的是圆盘**面积**内均匀样本，而不是只在圆周上取点；若误用单位圆周，模糊能量会集中在离焦圆边缘，形成不自然的空心轮廓。将圆盘样本乘以 `u`、`v` 后再加到 origin，才是任意朝向相机的透镜偏移。

## 小结

- `w/u/v` 将相机的焦平面和透镜圆盘从世界坐标中解耦，使任意朝向都可对焦。
- focus_dist 决定焦平面的位置；aperture 半径或 defocus_angle 决定透镜圆盘的大小。
- 像素采样和透镜采样分别处理抗锯齿与景深，两者都应在路径平均之前完成。
- 焦外模糊来自不同透镜起点的几何视差，而不是后处理模糊滤镜。
