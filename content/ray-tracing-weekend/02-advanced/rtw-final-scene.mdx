## 直觉引入

前面九章攒齐了所有零件：射线、求交、相机、漫反射、金属、玻璃、景深。最终场景就是把它们组装起来——一片大地、三个主角球（哑光、金属、玻璃），再撒一把随机大小、随机材质的小球。就像把学到的调料全用上做一道大菜。

随机生成让画面充满细节又不重复，而三种材质的混合让反射、折射、漫反射同时出现，互相映照——这才是检验光线追踪是否正确的最好测试图。

## 概念讲解

### 场景构成
- **地面**：一个极大的漫反射球（半径 1000），充当大地。
- **三个主角**：中央哑光球、左侧金属球、右侧玻璃球，分别展示三种材质。
- **随机小球**：用循环在地面网格上随机生成上百个小球，材质按概率分配（多数漫反射、少数金属/玻璃）。

### 材质分配策略
<Term def="按概率随机选择材质类型使画面分布自然">材质抽样</Term>：用一个随机数决定每个小球是漫反射（80%）、金属（15%）还是玻璃（5%），并随机颜色，避免人工排列的呆板感。

### 渲染参数
- `samples_per_pixel`：每像素采样数，越高越平滑越慢。
- `max_depth`：递归深度，决定反射能弹几次，太浅玻璃和镜面发暗。
- `image_width`/`aspect`：分辨率与宽高比。

## 代码对照

C++ 最终场景生成：

```cpp
hittable_list world;

// 地面（极大漫反射球）
auto ground = make_shared<lambertian>(color(0.5, 0.5, 0.5));
world.add(make_shared<sphere>(point3(0,-1000,0), 1000, ground));

// 三个主角
auto mat1 = make_shared<lambertian>(color(0.1,0.2,0.5));    // 哑光蓝
auto mat2 = make_shared<dielectric>(1.5);                    // 玻璃
auto mat3 = make_shared<metal>(color(0.8,0.6,0.2), 0.0);     // 金属
world.add(make_shared<sphere>(point3(0, 1, 0), 1.0, mat2));
world.add(make_shared<sphere>(point3(-4, 1, 0), 1.0, mat1));
world.add(make_shared<sphere>(point3( 4, 1, 0), 1.0, mat3));

// 随机小球：按概率分配材质
for (int a = -11; a < 11; a++) {
  for (int b = -11; b < 11; b++) {
    auto choose_mat = random_double();
    point3 center(a + 0.9*random_double(), 0.2, b + 0.9*random_double());
    if ((center - point3(4,0.2,0)).length() > 0.9) {        // 避开主角
      shared_ptr<material> sphere_mat;
      if (choose_mat < 0.8) {                                // 80% 漫反射
        auto albedo = color::random() * color::random();
        sphere_mat = make_shared<lambertian>(albedo);
      } else if (choose_mat < 0.95) {                        // 15% 金属
        auto albedo = color::random(0.5, 1);
        sphere_mat = make_shared<metal>(albedo, random_double(0,0.5));
      } else {                                               // 5% 玻璃
        sphere_mat = make_shared<dielectric>(1.5);
      }
      world.add(make_shared<sphere>(center, 0.2, sphere_mat));
    }
  }
}

// 相机与渲染参数
camera cam(20, 16.0/9.0, /*aperture*/ 0.1, /*focus_dist*/ 10.0);
cam.render(world, /*samples*/ 500, /*max_depth*/ 50);
```

`choose_mat` 的概率分段让多数小球是哑光、少数反光/折射，画面既丰富又有视觉重点。

## 常见误区

<Callout type="trap">
**现象 →** 玻璃球看起来发黑，里面一片漆黑。
**原因 →** max_depth 太小，光线进入玻璃后还没折射出来就到递归上限被截断成黑色。
**修法 →** 把 max_depth 提到 50 左右，让光线能在玻璃内外多次折射后射出，玻璃才会透亮。
</Callout>

<Callout type="trap">
**现象 →** 小球与主角球重叠穿插，画面出现奇怪的交线。
**原因 →** 随机生成时没排除主角球所在区域，小球生成在主角内部。
**修法 →** 用 (center − 主角中心).length()>0.9 判断避开主角，保证小球不与主角重叠。
</Callout>

## 练习

<Exercises>
**问题**：为什么最终场景要大量随机小球而不是几个大球？材质按概率分配有什么好处？

<Answer>
大量随机小球能提供丰富的反射/折射细节——玻璃球里映出无数小球的倒影、金属球表面反射出周围的彩色小球，能充分检验光线追踪是否正确（反射/折射方向对不对）。按概率分配材质（多漫反射、少金属/玻璃）让画面分布自然、有视觉重点，避免全是镜面或全是哑光的呆板感，更接近真实场景的材质比例。
</Answer>

**问题**：采样数和递归深度分别影响什么？为什么两者都不能太小也不能盲目调大？

<Answer>
采样数影响噪点：太少画面满是噪点，太多耗时线性增长但画质提升递减（√N 收敛）。递归深度影响反射/折射的层次：太浅玻璃和镜面发黑（光没弹出来），太深则大多数深层贡献趋近于 0 却白白消耗计算。两者都要在画质与耗时间权衡，典型取 samples=500、depth=50。
</Answer>
</Exercises>

<GlossaryItem term="程序化场景">用循环和随机数批量生成几何体与材质，避免手工排列，画面丰富自然。</GlossaryItem>
<GlossaryItem term="材质抽样">按概率随机选择材质类型，使多种材质在场景中按自然比例分布。</GlossaryItem>
<GlossaryItem term="采样数">每像素发射的光线条数，决定噪点多少与渲染耗时。</GlossaryItem>
<GlossaryItem term="递归深度">光线散射的最大层数，决定反射/折射能弹几次，影响玻璃与镜面亮度。</GlossaryItem>
