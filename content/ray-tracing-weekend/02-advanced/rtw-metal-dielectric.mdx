## 直觉引入

金属像镜子：光打上去沿「入射角等于反射角」的方向弹回，只是被金属本色染了一下色。玻璃则让光穿过去并弯折——这就是折射，吸管插进水杯看起来「断」了的原因。

光线追踪里，金属用一个简单公式算反射方向，再加一点随机扰动模拟磨砂金属；玻璃要判断光「该反射还是该折射」（角度越斜越容易反射），并用 Snell 定律算折射方向。两者都用前面 scatter 接口，只是算方向的公式不同。

## 概念讲解

### 金属：镜面反射 + 模糊
公式：

$$
\mathbf{r} = \mathbf{d} - 2(\mathbf{d}\cdot\mathbf{N})\mathbf{N}
$$

金属散射方向 = $\mathbf{r} + \text{fuzz}\cdot\vec{s}_{rand}$，fuzz 越大反射越散（磨砂）。attenuation = 金属反照率（基础色）。

### 电介质：Snell 折射 + Schlick 反射
：$\eta_i\sin\theta_i = \eta_t\sin\theta_t$。折射方向：

$$
\mathbf{r}_{\perp} = \frac{\eta_i}{\eta_t}(\mathbf{d} + \cos\theta_i\,\mathbf{N}),\quad \mathbf{r}_{\parallel} = -\sqrt{1-|\mathbf{r}_{\perp}|^2}\,\mathbf{N}
$$

给出反射概率 $R\approx R_0+(1-R_0)(1-\cos\theta)^5$，其中 $R_0=((\eta_i-\eta_t)/(\eta_i+\eta_t))^2$。每次命中按 R 与随机数比较决定走反射还是折射。

必须随入射侧改变。由于 `rec.normal` 已始终迎向入射光，`cos_theta = min(dot(-unit_direction, rec.normal), 1)` 为非负；若 `front_face=true`，光从空气进入玻璃，比例是 `1.0/ir`；否则从玻璃离开空气，比例是 `ir`。

$$
\eta=\frac{\eta_i}{\eta_t},\qquad
\sin\theta_t=\eta\sin\theta_i,qquad
\eta\sin\theta_i>1\Rightarrow\text{全内反射}
$$

解释了为什么“能折射”并不等于“一定折射”：即使没有全内反射，掠射角的玻璃也应更像镜子。单路径实现以概率 `R` 选其中一个方向；当随机数小于 R 时反射，否则折射。跨许多样本平均后，这个随机选择才近似两条路径的能量比例。

### 金属 fuzz 的有效范围

fuzz 只是给已经正确的镜面方向增加随机扰动，不是把光线任意打向球内。它应限制在 [0,1]：0 保持清晰反射，接近 1 时反射波瓣变宽；扰动后若新方向与法线点积不为正，说明方向钻入表面，应由 `scatter` 返回 `false` 终止该条路径。负 fuzz 没有合理的材质含义，构造器应在边界处钳制，而不是让它反向放大随机向量。

### 全内反射
当 $\sin\theta_t>1$（无实数解）时光无法折射，全部反射——这就是，发生在从水/玻璃射向空气且角度足够大时。

## 代码对照

C++ 金属与电介质材质：

```cpp
// 镜面反射向量
vec3 reflect(const vec3& v, const vec3& n) {
  return v - 2 * dot(v, n) * n;
}

class metal : public material {
  public:
    metal(const color& a, double f) : albedo(a), fuzz(std::clamp(f, 0.0, 1.0)) {}
    bool scatter(const ray& r_in, const hit_record& rec,
                 color& attenuation, ray& scattered) const override {
      vec3 reflected = reflect(unit_vector(r_in.direction()), rec.normal);
      scattered   = ray(rec.p, reflected + fuzz*random_unit_vector());
      attenuation = albedo;
      // 反射方向若钻入表面则视为吸收
      return (dot(scattered.direction(), rec.normal) > 0);
    }
  private:
    color albedo; double fuzz;
};

// 折射向量
vec3 refract(const vec3& uv, const vec3& n, double etai_over_etat) {
  auto cos_theta = fmin(dot(-uv, n), 1.0);
  vec3 r_out_perp = etai_over_etat * (uv + cos_theta*n);
  vec3 r_out_para = -sqrt(fabs(1.0 - r_out_perp.length_squared())) * n;
  return r_out_perp + r_out_para;
}

class dielectric : public material {
  public:
    dielectric(double index) : ir(index) {}
    bool scatter(const ray& r_in, const hit_record& rec,
                 color& attenuation, ray& scattered) const override {
      attenuation = color(1,1,1);
      double ratio = rec.front_face ? (1.0/ir) : ir;
      vec3 unit_d = unit_vector(r_in.direction());
      double cos_theta = fmin(dot(-unit_d, rec.normal), 1.0);
      double sin_theta = sqrt(1 - cos_theta*cos_theta);
      bool cannot_refract = ratio * sin_theta > 1.0;     // 全内反射
      vec3 dir = (cannot_refract || schlick(cos_theta, ratio) > random_double())
                 ? reflect(unit_d, rec.normal)           // 反射
                 : refract(unit_d, rec.normal, ratio);   // 折射
      scattered = ray(rec.p, dir);
      return true;
    }
  private:
    double ir;   // 折射率
};
```

`cannot_refract` 即全内反射判定；`schlick` 返回反射概率与随机数比较实现蒙特卡洛选择。

```cpp
double schlick(double cosine, double refraction_ratio) {
  auto r0 = (1.0 - refraction_ratio) / (1.0 + refraction_ratio);
  r0 = r0 * r0;
  return r0 + (1.0 - r0) * std::pow(1.0 - cosine, 5.0);
}

// 若概率路径采用“只选一条”的估计器，必须用同一概率解释样本统计；
// 本书的基础实现选择方向以展示行为，后续可进一步做 PDF 权重处理。
```

反射率函数的参数可用相对折射率，也可用材料折射率；因为 $R_0$ 对比值取倒数后不变，前提是调用和推导使用同一约定。不要把 `front_face` 的判断挪到 Schlick 外面重复翻转，否则会把“来自哪一侧”的信息应用两次。

## 小结

- 金属先镜面反射，再用 [0,1] 的 fuzz 扰动；进入表面的方向应终止而非继续递归。
- `front_face` 决定相对折射率的方向，`ratio * sin_theta > 1` 是全内反射的硬条件。
- Schlick 近似处理“可折射但仍会反射”的角度相关概率；随机数小于 R 才选择反射。
- 一条路径只选择反射或折射之一，多样本平均才重建两者的统计比例。
