## 分而治之

空间分割的思路：把世界空间切成若干区域，每个物体只可能与自己所在区域（及相邻区域）的物体碰撞。这样查询碰撞只需检查同区域的少量物体，而不是全部 N 个。<Term def="均匀网格将空间划分为等大小的立方格，物体按位置哈希到格子，查询只检查自身及相邻格子。">均匀网格</Term>最简单——用定长格子切世界，物体按中心坐标哈希到格子，碰撞查询只看自身和相邻的 27 个格子（3x3x3）。

## 三种策略对比

**均匀网格**适合物体分布均匀的场景（如粒子系统），插入和查询都是 $O(1)$ 哈希定位。但如果物体分布不均（大量挤在一个角落），那个格子会退化成 $O(n^2)$。**八叉树**递归地把空间八等分，密集区域继续细分、稀疏区域保持粗粒度，自适应密度——但插入和查询是 $O(\log n)$，且物体移动时可能触发树的重建。**松散四叉树**把每个节点的边界放大 $k$ 倍（如 2 倍），让跨界物体仍能归入唯一一个节点，避免重复存储。

```cpp
// 均匀网格：插入与查询
class UniformGrid {
    int cellSize;
    unordered_map<CellCoord, vector<Body*>> cells;

    void insert(Body* b) {
        auto coord = hashPos(b->center, cellSize);
        cells[coord].push_back(b);           // O(1) 定位
    }

    vector<Pair> queryPairs(Body* b) {
        auto coord = hashPos(b->center, cellSize);
        vector<Pair> pairs;
        // 只检查自身格 + 26 个相邻格
        for (int dx = -1; dx <= 1; dx++)
          for (int dy = -1; dy <= 1; dy++)
            for (int dz = -1; dz <= 1; dz++) {
                auto& bucket = cells[coord + CellCoord{dx,dy,dz}];
                for (auto* other : bucket)
                    if (other->id > b->id)    // 避免重复对
                        pairs.push_back({b, other});
            }
        return pairs;
    }
};
```

## 松散四叉树的价值

标准四叉树的一个痛点：物体正好跨在格子边界上时，必须同时存入多个子节点，导致重复存储和重复检测。松散四叉树把每个节点的有效区域放大（比如格子边长 $L$ 变成 $kL$），只要物体中心仍在放大后的区域内就只存这一个节点。代价是节点间有重叠区域，但物体只存一份，大幅减少维护成本。

<Callout type="trap">
**误区：场景不均也用均匀网格。** 如果 1000 个物体挤在地图一角的 3 个格子里，那 3 个格子内部仍是 $O(n^2)$。网格只适合分布均匀的场景。分布不均时应该用八叉树——密集区域自动细分，每个叶子节点内物体数可控，不会退化。
</Callout>

<Exercises>
**问题 1**：均匀网格在什么情况下会退化？如何解决？

<Answer>
当物体分布极度不均时退化——大量物体挤在少数格子里，那几个格子内部仍是 $O(n^2)$ 的两两检测。解决方法：①改用八叉树，密集区域自动递归细分，把每个叶子内的物体数控制在阈值以下；②对热点格子动态再切分（层次网格）；③调整格子大小使每格平均物体数适中。核心是让数据结构能自适应密度，而不是用固定粒度硬套。
</Answer>

**问题 2**：松散四叉树的「松散」指什么？解决了什么问题？

<Answer>
「松散」指把每个节点的边界区域放大 $k$ 倍（通常 $k=2$）。标准四叉树中，跨在格子边界上的物体必须同时存入多个子节点，导致重复存储和重复碰撞检测。松散四叉树放大边界后，只要物体中心在放大区域内就只存一个节点——跨界物体被「包容」进唯一节点。代价是相邻节点的有效区域有重叠（物体可能落入多个节点的放大区），但通过取最近的节点仍保证只存一份。这大幅减少了移动物体的更新开销。
</Answer>

<GlossaryItem term="均匀网格">将空间等分为定长格子，物体按坐标哈希定位，查询只看自身及相邻格，适合均匀分布。</GlossaryItem>
<GlossaryItem term="八叉树">三维空间递归八等分的树结构，密集区细分、稀疏区粗放，自适应物体密度。</GlossaryItem>
<GlossaryItem term="松散四叉树">节点边界放大 k 倍的四叉树变体，跨界物体只存一个节点，减少重复存储。</GlossaryItem>
