## 从点到轨迹

<Term def="扫掠体是物体沿运动轨迹扫过的空间体积，连续碰撞检测通过判断扫掠体与障碍物的相交来求碰撞时间。">扫掠体</Term>是 CCD 的核心概念。一个球从 $P_0$ 匀速运动到 $P_1$，扫过的体积是一个胶囊体（两端球 + 中间圆柱）。一个盒子运动一段距离，扫掠体是一个更大的多面体。CCD 不再问「此刻碰了没」，而是问「从 $t_0$ 到 $t_1$ 这段时间里，有没有某一时刻碰了」——如果有，求出最早的碰撞时刻 $t_{hit}$。

## 保守推进法

<Term def="保守推进法是一种迭代式 CCD 算法，每步按当前最短距离与最大速度计算安全时间步长，逐步逼近碰撞时刻。">保守推进法</Term>简单且安全：每步计算两体当前最短距离 $d$ 和相对速度 $v$，如果 $d > 0$（未碰），则前进 $\Delta t = d / v$（这是保证不穿透的最大安全步长），然后重新计算距离。重复直到 $d$ 收敛到 0 或小于阈值。优点是通用——任何能算距离的形状都适用；缺点是收敛慢（可能需要很多步），速度差大时尤其明显。

```cpp
// 保守推进法：球-球 CCD
float conservativeAdvancement(const Sphere& a, const Vec3& va,
                               const Sphere& b, const Vec3& vb,
                               float maxTime) {
    float t = 0;
    Sphere sa = a, sb = b;
    while (t < maxTime) {
        float d = distance(sa.center, sb.center) - (sa.r + sb.r);
        if (d <= EPSILON) return t;  // 碰撞
        Vec3 relVel = va - vb;
        float speed = length(relVel);
        if (speed < EPSILON) return -1;  // 相对静止，不会碰
        float dt = d / speed;             // 安全步长
        t += dt;
        sa.center += va * dt;             // 推进
        sb.center += vb * dt;
    }
    return -1;  // 时间范围内未碰
}
```

## 解析法

解析法直接建立运动方程求解。以球-球为例：相对位置 $P(t) = P_0 + v_{rel} \cdot t$，碰撞条件 $|P(t)|^2 = (r_a + r_b)^2$，展开为二次方程 $At^2 + Bt + C = 0$，取最小正根即为 $t_{hit}$。解析法精确且一步到位，但每种形状组合需要单独推导方程——球-球简单，但凸多面体-凸多面体的解析解极其复杂，通常退回保守推进或基于 GJK 的迭代 CCD。

<Callout type="trap">
**误区：CCD 只需检测起始和终止位置。** 这正是离散检测的错误做法。CCD 的本质是检测整段连续轨迹。即使起点和终点都不与障碍物相交，物体也可能在中间时刻穿过薄障碍物。扫掠体正是为了覆盖「中间时刻」——它代表了物体在整段时间内占据的所有空间。只看两端等于退化回 DCCD。
</Callout>

<Exercises>
**问题 1**：保守推进法为什么是「保守」的？它的收敛速度受什么影响？

<Answer>
「保守」指每步只前进「保证不穿透的最大安全步长」$dt = d / v$，绝不会越过碰撞点。它算的是「以当前速度，最快多久会碰到」的上界，实际碰撞可能更早（因为运动方向不一定指向最近点）。收敛速度受「运动方向与最近点方向的夹角」影响：如果正对运动，一步就收敛；如果擦边运动，$d$ 减小很慢，需要很多步。速度差越大、初始距离越远，步数越多。
</Answer>

**问题 2**：球-球 CCD 的解析法如何推导 $t_{hit}$？

<Answer>
两球匀速运动，相对位置 $P(t) = P_0 + v_{rel} t$，其中 $P_0 = A_0 - B_0$，$v_{rel} = v_a - v_b$。碰撞条件是球心距等于半径和：$|P(t)|^2 = (r_a + r_b)^2$。展开：$(P_0 + v_{rel} t) \cdot (P_0 + v_{rel} t) = R^2$，即 $|v_{rel}|^2 t^2 + 2(P_0 \cdot v_{rel}) t + (|P_0|^2 - R^2) = 0$。用求根公式解二次方程，取 $[0, \Delta t]$ 范围内的最小非负根即为 $t_{hit}$。判别式小于 0 则轨迹不相交，无碰撞。
</Answer>
