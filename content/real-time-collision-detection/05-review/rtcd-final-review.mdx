## 一帧的碰撞旅程

全书讲了碰撞检测的各个环节，但它们不是孤立的——每帧物理步进都会把它们串成一条管线。理解各环节如何协作，比单独记住每个算法更重要。下面用「一帧的碰撞旅程」把全书知识穿成一条线。

## 管线执行顺序

帧开始，每个物体先更新自己的 <Term def="包围体是包裹物体的简单几何形状，用于快速排除不可能碰撞的物体对，是 Broad Phase 的基本数据。">包围体</Term>（AABB 重算或 OBB 乘旋转矩阵）。然后进入 **Broad Phase**：用 Sweep and Prune 或空间分割，把 N 个物体的 $O(n^2)$ 两两组合压缩成少量「候选对」——只有包围体相交的对。接着 **Narrow Phase**：对候选对用 GJK 或 SAT 做精确凸体检测，确认是否真正相交，输出接触点、法向和穿透深度。如果物体高速运动，**CCD** 旁路介入，用扫掠体求精确 $t_{hit}$ 防穿透。最后碰撞响应交给物理引擎。

```cpp
// 一帧 = 全书知识的协作
void PhysicsStep(float dt) {
    for (auto& b : bodies)
        b.updateBV();                       // 包围体更新（第3章）

    auto pairs = broadPhase.generate(bodies); // 粗筛（第4-5章）
    // broadPhase 内部：Sap 排序端点 或 空间分割分桶

    Contacts contacts;
    for (auto& [a, b] : pairs) {
        if (a.isFast || b.isFast) {
            float t = ccd.detect(a, b, dt);   // CCD 旁路（第8章）
            if (t >= 0) contacts.add(a, b, t);
        } else {
            auto c = narrowPhase.detect(a, b); // 精算（第6-7章）
            // narrowPhase 内部：GJK 迭代 或 SAT 投影
            if (c) contacts.add(*c);
        }
    }
    // 优化贯穿全程：SoA 布局 + SIMD + 多核并行（第9章）
    solver.resolve(contacts);                 // 碰撞响应
}
```

## 三层协作的依赖

**基础层**（类型/包围体）是管线的「数据格式」——决定用什么形状做检测。**检测层**（Broad/Narrow Phase）是管线的「主流程」——粗筛减量、精算确认。**优化层**（CCD/性能）是管线的「保障」——CCD 保证高速物体不穿透，SIMD/缓存/并行保证整体吞吐。下层不知道上层存在，上层依赖下层——这条规则贯穿全书。

<Callout type="trap">
**误区：认为学了 GJK/SAT 就够用。** 算法只是管线上的一环。实际项目中，Broad Phase 的效率决定帧率（候选对太多 Narrow Phase 再快也崩），数据布局决定 SIMD 能否生效（AoS 布局下 GJK 无法向量化），CCD 决定物理正确性（没有它子弹会穿墙）。只懂 Narrow Phase 算法而忽略管线全貌，遇到性能问题会无从下手。
</Callout>

<Exercises>
**问题 1**：用一帧的旅程描述 Broad Phase、Narrow Phase、CCD 的调用顺序，并解释为什么。

<Answer>
顺序：Broad Phase →（对每对候选对判断）→ 高速对走 CCD，普通对走 Narrow Phase → 碰撞响应。原因：Broad Phase 先用包围体减量，只把「可能碰」的对传下去，避免对全部 $O(n^2)$ 组合做精确检测。拿到候选对后，按速度分流——高速物体（一帧位移可能超过障碍厚度）走 CCD 求精确 $t_{hit}$ 防穿透，普通物体走 GJK/SAT 做离散精确检测。最后把接触信息交给物理引擎解算。这个顺序保证了「先减量再精确，先防穿透再算接触」的优先级。
</Answer>

**问题 2**：如果 Broad Phase 的候选对数量过多，会导致什么连锁问题？如何定位和解决？

<Answer>
连锁问题：候选对多 → Narrow Phase 检测量大 → 帧时间飙升。可能原因：①包围体太松（AABB 比物体大很多，大量误判），解决：换更紧的包围体或缩小 AABB；②空间分割策略不当（物体分布不均但用了均匀网格，热点格子退化），解决：改用八叉树或松散四叉树；③物体密集在一小片区域（如爆炸后碎片聚集），解决：对该区域做层次分割或限制最大候选对数。定位方法：用 Profiler 统计候选对数量与 Narrow Phase 耗时占比，对比包围体体积与实际体积比，找到「误判率」最高的环节。
</Answer>
