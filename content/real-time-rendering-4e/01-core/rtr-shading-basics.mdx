## 直觉：外观不是三个颜色相加

先预测：把 sRGB 纹理值直接相加再写回 sRGB framebuffer，亮度会正确吗？把雾简单写成 `mix(scene, fogColor, distance)`，不同步长下结果会一致吗？答案都是否定的；着色必须追踪量的物理含义、工作色域、采样位置和表示方式。

Ch5 建立着色计算，Ch8 定义光与颜色的量，Ch10 讨论局部光源，Ch13-15 则把外观扩展到点/粒子/隐式表示、参与介质和非真实感风格。它们共享同一条链：**representation → incident light → material/medium response → sampling/filtering → display transform**。


## Ch5 Shading Basics：在哪里算、插什么值

不仅是一个光照公式，还包括计算频率和属性来源。flat shading 每个图元一次，Gouraud 在顶点求光照再插值颜色，per-pixel/per-sample shading 插值属性后求光照；三者对小高光、法线贴图和边缘采样的保真度不同。

三角形内部通常对投影后的属性做 perspective-correct interpolation。若顶点属性为 $a_i$、clip-space 的 $w_i$、屏幕重心权重为 $\lambda_i$：

$$
a=\frac{\sum_i \lambda_i a_i/w_i}{\sum_i \lambda_i/w_i}.
$$

直接线性插值 UV 会产生透视游动。法线、切线和由插值得到的方向通常还需归一化；shader derivative 可估计纹理 footprint，但在非均匀控制流、helper invocation 和不连续属性附近要谨慎。

### 经验模型的边界

Lambert 漫反射 BRDF 为 $f_d=\rho_d/\pi$，直接光项含 $max(\mathbf n\cdot\mathbf l,0)$。Phong/Blinn-Phong 是经验镜面模型，不保证能量守恒；所谓 ambient 常数只是补光近似，不等于真实间接光。

Blinn-Phong 用半角向量 $\mathbf h=normalize(\mathbf l+\mathbf v)$，Phong 用反射向量。两者指数不可直接互换，哪个更快依硬件、编译器和实现，不能断言 Blinn-Phong 必然更自然或更高效。背光时还要限制镜面项，避免光从表面背面泄漏。

## Ch8 Light and Color：先知道正在计算什么


 $L$ 的单位是 $W\,m^{-2}\,sr^{-1}$。与它相邻的辐射度量不能混用：

- radiant flux $\Phi$：总功率，单位 W；
- radiant intensity $I=d\Phi/d\omega$：单位立体角功率，$W/sr$；
- irradiance $E=d\Phi/dA$：落到表面的单位面积功率，$W/m^2$；
- radiance $L=d^2\Phi/(dA\cos\theta\,d\omega)$：带方向的面积密度。

点光源的 irradiance 在无介质时近似按 $1/r^2$ 衰减。把 attenuation 写成任意线性函数可以服务艺术需求，但不再是物理距离模型。

不是 RGB 三通道的同义词。颜色管线还需区分 spectrum、CIE XYZ、色域 primaries、white point、linear RGB 和 transfer function。

sRGB 数值通常带非线性传递函数；纹理采样后应解码到线性光空间再做光照和混合，输出阶段再经 tone mapping、gamut mapping 与显示编码。normal、roughness、metalness 等数据纹理不应做 sRGB 解码。

## Ch10 Local Illumination：局部光源仍需要积分

表面一点的直接照明是对可见光源方向的积分：

$$
L_o(\mathbf x,\mathbf v)=\int_{\Omega}f_r(\mathbf l,\mathbf v)L_i(\mathbf l)
V(\mathbf x,\mathbf l)(\mathbf n\cdot\mathbf l)^+d\omega.
$$

directional、point 和 spot light 可视为理想化 delta light，通常单次求值；area light、emissive mesh 和 environment map 有有限角域，需要采样并处理 visibility。只取面光源中心会得到过硬且随尺寸错误的结果。

可按光源功率、立体角、BRDF 或 environment luminance 分布采样。多重要性采样组合 light sampling 与 BRDF sampling；实时系统也可用预积分、LTC、clustered light lists 或 reservoir reuse，但都要保留 estimator/近似的适用边界。

```glsl
vec3 evaluateDirect(Surface s, LightSample ls, vec3 V) {
    vec3 L = normalize(ls.position - s.position);
    float NoL = max(dot(s.normal, L), 0.0);
    if (NoL == 0.0 || !ls.visible) return vec3(0.0);

    vec3 f = evaluateBRDF(s, L, V);       // BRDF, not pre-multiplied color
    vec3 Li = ls.radiance;                // linear radiometric quantity
    return f * Li * NoL / max(ls.pdf, 1e-6);
}
```

单位测试要检查 inverse-square ratio、零距离保护、背光、遮挡、PDF 和单位；图像测试则扫光源尺寸、roughness、距离和 HDR 强度。

## Ch13 Beyond Polygons：表示决定采样规则

“超越多边形”不表示完全不用三角形，而是场景原语与表面定义不局限于静态 polygon mesh：

- point sprites、billboards、particles：适合火花、植被 impostor 和大量小元素；要处理相机朝向、排序、soft intersection 与 temporal stability；
- implicit surface / signed distance field：用 $f(\mathbf x)=0$ 或距离场定义边界，可 ray march、mesh extraction 或用于碰撞/阴影；
- voxel、height field、procedural geometry：按规则生成或采样，适合地形、破坏和稠密空间数据；
- hair/ribbon/curve primitives：需要各向异性着色、抗锯齿和细几何覆盖处理。

## Ch14 Volumetric and Translucency Rendering：路径中也会吸收和散射


在均匀介质距离 $d$ 上为：

$$
T(d)=e^{-\sigma_t d},\qquad \sigma_t=\sigma_a+\sigma_s.
$$

$\sigma_a$ 是吸收系数，$\sigma_s$ 是外散射系数，phase function 描述散射方向分布。沿 ray 的辐射传输包含 attenuated background 与 in-scattering 积分；“距离线性混雾”通常不具备步长不变性和正确遮挡。

实时体积常用 froxel grid、ray marching、shadow map、temporal reprojection 和 blue-noise/jitter。每步应由 segment transmittance 合成，早停基于累计透射率；改变 step size 后结果应收敛。半透明表面 alpha blending 是覆盖/合成模型，不自动等同体吸收；straight 与 premultiplied alpha 的混合因子也不同。

皮肤、蜡等 translucent material 还涉及 subsurface scattering。屏幕空间模糊便宜但会跨轮廓泄漏，profile diffusion、texture-space 或 path-based 方法对厚度与几何更准确。

## Ch15 Non-Photorealistic Rendering：风格也是可测的系统

NPR 通过选择性省略、夸张和符号化传达形状或语义。toon shading 可量化 diffuse/specular ramp；轮廓可从 geometry silhouette、inverted hull 或 depth/normal image-space edge 提取；hatching/stipple 需要随表面与运动稳定，而不是在屏幕上游泳。

仍需正确的空间、遮挡和抗锯齿。验收应包含风格 reference、轮廓连续性、时间稳定性、可读性和性能，而非只比较物理误差。
