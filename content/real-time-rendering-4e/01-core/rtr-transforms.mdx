## Ch4：空间、齐次坐标与投影

对列向量约定，完整链为：

$$
\mathbf p_{clip}=\mathbf P\mathbf V\mathbf M\mathbf p_{model},\qquad
\mathbf p_{ndc}=\mathbf p_{clip}/w_{clip}.
$$

`Model` 把局部几何放入世界，`View` 通常是相机世界变换的逆，`Projection` 生成用于裁剪的齐次坐标。图元在 clip space 按齐次半空间裁剪，随后才做透视除法；因此 **clip space 不是 NDC**。

<Term def="以额外 w 分量统一表示点、方向、仿射变换和透视投影的坐标表示">齐次坐标</Term>中，点常写为 $(x,y,z,1)$，方向写为 $(x,y,z,0)$。这让平移只影响点，也使投影后的 $w$ 携带透视除法所需信息。

### 矩阵内存布局不决定乘法语义

“row-major/column-major”描述内存布局；“row vector/column vector”描述代数约定。OpenGL API 与 GLSL 常见列向量写法是 `M * v`，但不能据此断言所有 DirectX/HLSL 代码都必须 `v * M`。决定顺序的是项目约定、shader 写法和上传时是否转置。

```glsl
layout(location = 0) in vec3 aPosition;
layout(location = 1) in vec3 aNormal;

uniform mat4 uModel;
uniform mat4 uView;
uniform mat4 uProjection;

out vec3 vWorldNormal;

void main() {
    vec4 world = uModel * vec4(aPosition, 1.0);
    mat3 normalMatrix = transpose(inverse(mat3(uModel)));
    vWorldNormal = normalize(normalMatrix * aNormal);
    gl_Position = uProjection * uView * world;
}
```

### 法线、旋转与插值

方向可用线性部分变换，但法线必须继续垂直于切平面。存在非均匀缩放或 shear 时：

$$
\mathbf n' = (\mathbf M_{3\times3}^{-1})^T\mathbf n.
$$

纯旋转或统一缩放时可简化；奇异矩阵不可求逆，应在资产/变换系统中拒绝或采用明确降级策略。切线空间还要同时维护 tangent、normal 和 handedness，重建 bitangent 后重新正交化。

<Term def="用一个标量和三维虚部表示旋转、避免欧拉角万向节锁并支持稳定插值的四元数">旋转四元数</Term>组合后需归一化。短路径球面插值 `slerp` 适合大角度恒角速度；归一化线性插值 `nlerp` 更便宜但角速度不恒定。若点积为负，先翻转一个四元数以选择短弧。

## Ch16：多边形技术不是“只有三角形”

<RtrMeshTopologyDiagram />

一个可渲染 mesh 至少包含拓扑（indices/adjacency）、几何属性（position/normal/tangent/UV/color/skin weights）、material ranges 和 bounds。共享位置不代表所有顶点属性都可共享：UV seam、硬边和材质边界通常需要拆分顶点。

### 面方向、法线与切线

- winding 与 front-face 约定共同决定正反面；负尺度会翻转朝向；
- 顶点法线是相邻面法线的加权结果，硬边要拆分或按 smoothing group 处理；
- tangent basis 必须匹配 UV 参数化和 normal-map 约定，镜像 UV 需要 handedness；
- 三角形退化、重复索引、NaN 属性和零面积 UV 会污染法线或切线生成。

### 简化和 LOD 必须用屏幕误差验收

网格简化通常在满足边界、属性 seam、skin 和法线约束下做 edge collapse；quadric error metric 估计几何误差。仅按相机距离切换 LOD 会忽略 FOV、分辨率和对象尺度，更稳健的是投影误差：

$$
e_{px}\approx \frac{e_{object}\,H}{2z\tan(\theta/2)}.
$$

其中 $e_{object}$ 是简化误差，$H$ 是 viewport 高度，$z$ 是观察空间深度，$\theta$ 是垂直 FOV。切换时使用 hysteresis 或 cross-fade，避免阈值附近闪烁。

## Ch17：曲线、曲面与离散化

<RtrCurvesDiagram />

三次 Bézier 曲线由四个控制点定义：

$$
\mathbf B(t)=(1-t)^3\mathbf P_0+3(1-t)^2t\mathbf P_1+3(1-t)t^2\mathbf P_2+t^3\mathbf P_3.
$$

它具有端点插值和凸包性质，适合分段设计；多段连接时要显式满足位置连续 $C^0$、切向连续 $G^1/C^1$ 或更高连续性。de Casteljau 算法通过重复线性插值稳定求值，也自然支持 subdivision。

<Term def="以局部支撑基函数、控制点和 knot vector 定义的分段多项式曲线；移动一个控制点只影响有限参数区间">B-spline</Term>比单段 Bézier 更适合长曲线；NURBS 加入齐次权重，可精确表示圆锥曲线。参数曲面把 $(u,v)$ 映射到 3D，切向偏导的叉积给出法线。

<Term def="反复细分控制网格并平滑极限曲面的表示方法；规则区域与非规则顶点需采用对应规则">细分曲面</Term>可从低多边形控制笼生成平滑极限面。Catmull-Clark 常用于四边形控制网格，Loop 常用于三角形；extraordinary vertex 附近的连续性和求值需要特别处理。

### Tessellation 与裂缝

屏幕空间自适应 tessellation 应由曲率、silhouette、displacement 频率和像素误差共同驱动。共享边若两侧独立选择 tessellation factor，会出现 T-junction/crack。修复策略是共享/量化边因子、邻接约束、无裂缝参数化，或用 skirt 作为有代价的降级方案。

## 常见误区

<Callout type="trap">
**现象 →** 非均匀缩放后高光方向扭曲。**原因 →** 法线直接乘 model matrix。**修法 →** 使用逆转置线性矩阵，并在 shader 中归一化；同时检查奇异变换。
</Callout>

<Callout type="trap">
**现象 →** 认为 OpenGL 一定“列主序左乘”、DirectX 一定“行主序右乘”。**原因 →** 把内存布局、API 上传规则和代数约定混成一件事。**修法 →** 用一个已知点做端到端单元测试，并在 CPU/shader 边界写明约定。
</Callout>

<Callout type="trap">
**现象 →** LOD 在移动时跳动，曲面 patch 边缘漏光。**原因 →** 距离阈值无 hysteresis，邻接 patch 的离散级别不一致。**修法 →** 使用屏幕误差与滞回，保证共享边因子一致并加入裂缝回归图。
</Callout>

## 练习

<Exercises>

**问题 1：为什么 clip coordinates 不能标成 NDC？**

<Answer>
clip coordinates 仍是四维齐次坐标，并在透视除法前参与裁剪；NDC 是各分量除以 $w$ 后的三维坐标。混淆两者会让裁剪、深度范围和屏幕映射推导出错。
</Answer>

**问题 2：一个带非均匀缩放和镜像 UV 的模型要检查哪些方向数据？**

<Answer>
法线用 model 线性部分的逆转置并归一化；tangent 按相同空间约定转换后与 normal 正交化；利用 tangent handedness 重建 bitangent；检查负 determinant、镜像 UV seam 和 normal-map 的 Y/handedness 约定。
</Answer>

**问题 3：怎样证明 LOD 改动既更快又没有破坏轮廓？**

<Answer>
在多分辨率、FOV、距离和运动轨迹上记录投影误差、silhouette 差异、切换次数、三角形数和 GPU 时间分位数；使用 hysteresis 后比较基线图像，并覆盖 seam、skin 和阴影 pass。
</Answer>

**问题 4：两块曲面为何会在 tessellation 后产生裂缝？**

<Answer>
即使几何边界相同，只要两侧独立计算的 tessellation factor 或边参数化不同，就会生成不匹配的边顶点。应共享并量化边因子、约束邻接层级，或采用明确的无裂缝拼接方案。
</Answer>

</Exercises>

## 小结

Ch4 给出空间变换和旋转工具，Ch16 把拓扑与属性组织成可靠多边形表面，Ch17 用曲线/曲面与 tessellation 控制连续表示。验收标准不是“模型能显示”，而是空间约定一致、法线与 seam 正确、LOD 稳定、曲面无裂缝，并且误差与成本都有数据。
