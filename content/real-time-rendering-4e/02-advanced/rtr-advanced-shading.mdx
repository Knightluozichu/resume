## 直觉引入

想象你在鉴定宝石。经验模型（Phong）像用肉眼估光泽——看起来差不多就行。基于物理的BRDF像用光谱仪测量——每个参数都有物理意义，能量必须守恒。Phong说「这个高光看起来对」就够了，PBR说「这个材质在不同光照下都对」。

PBR的核心是微表面理论：表面由无数微小镜面组成，它们的朝向分布决定了反射模式。粗糙表面微镜面朝向混乱，反射光散开；光滑表面微镜面整齐，反射光集中。

## 代码对照

```glsl
// Cook-Torrance BRDF 实现 (GLSL)

// GGX 法线分布函数 D
float D_GGX(float NdotH, float roughness) {
    float a = roughness * roughness;
    float a2 = a * a;
    float NdotH2 = NdotH * NdotH;
    float denom = NdotH2 * (a2 - 1.0) + 1.0;
    return a2 / (3.14159265 * denom * denom);
}

// Schlick 菲涅尔近似 F
vec3 F_Schlick(float cosTheta, vec3 F0) {
    return F0 + (1.0 - F0) * pow(1.0 - cosTheta, 5.0);
}

// Smith 几何遮蔽 G
float G_Smith(float NdotV, float NdotL, float roughness) {
    float r = roughness + 1.0;
    float k = (r * r) / 8.0;
    float gv = NdotV / (NdotV * (1.0 - k) + k);
    float gl = NdotL / (NdotL * (1.0 - k) + k);
    return gv * gl;
}

// 最终 BRDF
vec3 cookTorrance(vec3 N, vec3 L, vec3 V, vec3 F0, float roughness) {
    vec3 H = normalize(L + V);
    float NdotL = max(dot(N, L), 0.0);
    float NdotV = max(dot(N, V), 0.0);
    float NdotH = max(dot(N, H), 0.0);
    float D = D_GGX(NdotH, roughness);
    vec3 F = F_Schlick(max(dot(H, V), 0.0), F0);
    float G = G_Smith(NdotV, NdotL, roughness);
    vec3 spec = (D * F * G) / (4.0 * NdotL * NdotV + 0.001);
    return spec * NdotL;
}
```

## 常见误区

<Callout type="trap">
**误区：把粗糙度和金属度混为一谈。**
粗糙度控制高光的扩散程度（光滑→锐利高光，粗糙→散开高光），金属度控制反射率和颜色（金属=反射率高且无漫反射，非金属=反射率低且有漫反射）。两者是完全独立的材质属性。
</Callout>

<Callout type="trap">
**误区：忽略能量守恒。**
PBR要求反射光能量不超过入射光能量。如果k_d + k_s > 1，表面会「发光」。正确做法是从Fresnel计算k_s，然后k_d = 1 - k_s（对金属k_d=0），保证总能量守恒。
</Callout>

<Exercises>
**问题 1**：Cook-Torrance模型的D、F、G三个函数分别描述什么物理现象？

<Answer>
D（法线分布函数）描述微表面法线与半角向量H对齐的比例，控制高光的形状和锐度（GGX比Blinn更真实）；F（菲涅尔项）描述反射率随入射角增大而增大的现象（掠射角时接近全反射）；G（几何遮蔽函数）描述微表面之间相互遮挡的比例，产生边缘暗化效果。三者乘积除以归一化因子4(N·L)(N·V)得到镜面反射BRDF。
</Answer>

**问题 2**：为什么PBR需要能量守恒？不守恒会怎样？

<Answer>
能量守恒保证反射光不超过入射光，这是物理定律。不守恒时：1）表面可能「发光」（反射比入射还亮）；2）在不同光照条件下材质表现不一致（白天看起来对、夜晚太亮）；3）无法跨场景复用材质参数。PBR通过Fresnel计算k_s再用k_d=(1-k_s)保证漫反射+镜面反射之和不超过入射能量，使同一组参数在任何光照下都正确。
</Answer>

<GlossaryItem term="BRDF">双向反射分布函数，描述光线从入射方向到反射方向的能量分布比例。</GlossaryItem>
<GlossaryItem term="Cook-Torrance">基于微表面理论的物理BRDF模型，镜面项由D（法线分布）、F（菲涅尔）、G（几何遮蔽）三个函数组成。</GlossaryItem>
<GlossaryItem term="微表面理论">假设表面由无数微小镜面组成，它们的朝向统计分布决定宏观反射特性的理论模型。</GlossaryItem>
