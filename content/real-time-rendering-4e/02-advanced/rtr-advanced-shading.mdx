## 直觉：看起来合理不等于可迁移

先预测：把 roughness 从 0.2 改成 0.4，高光峰值和总反射能量会怎样变化？把 normal map 缩到远处，若只平均法线而不调整 roughness，是否仍稳定？物理着色的价值不是“用了金属度”，而是模型在光照、视角、尺度和引擎之间保持可解释行为。

Ch9 Physically Based Shading 从经验高光推进到受物理约束的反射模型、材质参数化与生产验证。PBR 仍包含近似；每个近似都应声明输入域、单位、色彩空间、能量和采样假设。


## BRDF 与渲染方程

定义为：

$$
f_r(\mathbf l,\mathbf v)=\frac{dL_o(\mathbf v)}{dE_i(\mathbf l)}.
$$

不发光表面的反射项进入渲染方程：

$$
L_o(\mathbf v)=\int_{\Omega^+} f_r(\mathbf l,\mathbf v)L_i(\mathbf l)
(\mathbf n\cdot\mathbf l)d\omega_l.
$$

物理可行 BRDF 通常要求非负、Helmholtz reciprocity $f_r(\mathbf l,\mathbf v)=f_r(\mathbf v,\mathbf l)$，以及对任意出射方向：

$$
\int_{\Omega^+}f_r(\mathbf l,\mathbf v)(\mathbf n\cdot\mathbf l)d\omega_l\le 1.
$$

“diffuse 权重 + specular 权重不超过 1”只是特定分解的启发式检查，不能代替对完整 BRDF 与采样/积分实现的能量验证。

## 微表面 Cook-Torrance：D、F、G 各管一件事


的常见镜面 BRDF 为：

$$
f_s(\mathbf l,\mathbf v)=\frac{D(\mathbf h)F(\mathbf v,\mathbf h)G(\mathbf l,\mathbf v)}
{4|\mathbf n\cdot\mathbf l||\mathbf n\cdot\mathbf v|}.
$$

- **D, normal distribution function**：微法线朝向 $\mathbf h$ 的面积密度。GGX/Trowbridge-Reitz 有长尾高光；NDF 必须按投影面积归一化。
- **F, Fresnel**：单个微镜面反射比例，随角度、波长和折射率变化；掠射角趋近 1。
- **G, masking-shadowing**：从入射和出射方向可见的微镜面比例。Smith 模型可配 GGX，相关/不相关近似并不等价。

常见各向同性形式：

$$
D_{GGX}(\mathbf h)=\frac{\alpha^2}{\pi[(\mathbf n\cdot\mathbf h)^2(\alpha^2-1)+1]^2}.
$$

perceptual roughness 到 $\alpha$ 的映射是引擎约定，常见 `alpha = roughness²`，但不能跨实现盲目复用；还要设最小值避免 delta-like lobe 的数值问题。

## Fresnel、介质与导体

对无吸收介质，法线入射反射率为：

$$
F_0=\left(\frac{\eta_i-\eta_t}{\eta_i+\eta_t}\right)^2.
$$

Schlick 近似 $F=F_0+(1-F_0)(1-\mathbf v\cdot\mathbf h)^5$ 便宜但不是所有 IOR/导体的精确解。导体使用复折射率 $\eta+i\kappa$，产生有色 specular，体内透射快速吸收，通常没有常规模型下的 diffuse lobe。

把 metalness 视作端点/混合约定：非金属 base color 主要代表 diffuse，F0 由 IOR/规范值给出；金属 base color 代表 specular F0。中间 metalness 常用于材质混合或抗锯齿，不意味着现实中存在“半金属分子”。

非金属 F0 并非永远 `0.04`；它约对应 IOR 1.5 的空气界面。水、皮肤涂层、宝石等范围不同。资产规范应给出允许范围并保留超出值的例外通道。

## 漫反射、能量与多次散射

Lambert $f_d=\rho/pi$ 是理想漫反射。粗糙介质可用 Oren-Nayar 等模型；皮肤/蜡还需要 subsurface。简单 `diffuse *= (1-F)` 能降低单次界面反射后的剩余能量，却不自动解决 GGX 微表面内部多次散射、方向积分和 diffuse/specular 耦合。

单次散射微表面模型在高 roughness 下可能显著变暗，因为被 mask 的能量被当作吸收。multiple-scattering compensation、方向 albedo LUT 或多次散射 BRDF 可回收部分能量；选择必须与 IBL 预积分和 direct-light 路径一致。

```glsl
vec3 evaluateMicrofacet(Surface s, vec3 L, vec3 V) {
    float NoL = max(dot(s.N, L), 0.0);
    float NoV = max(dot(s.N, V), 0.0);
    if (NoL == 0.0 || NoV == 0.0) return vec3(0.0);

    vec3 H = normalize(L + V);
    float alpha = max(s.perceptualRoughness * s.perceptualRoughness, 0.002);
    float D = D_GGX(s.N, H, alpha);
    float G = G_SmithCorrelated(NoL, NoV, alpha);
    vec3 F = F_Schlick(max(dot(V, H), 0.0), s.F0);
    return D * G * F / max(4.0 * NoL * NoV, 1e-6);
}
```

函数返回 BRDF，不应在内部又乘 `NoL` 后被调用方重复乘；接口命名与单位比短代码更重要。

## 材质采样、法线与 IBL

normal map 改变微观/中尺度方向，却不会自动调整 roughness。缩小时平均向量长度下降，直接归一化会恢复过强高频法线并产生 specular aliasing。Toksvig、LEAN/CLEAN、normal variance 到 roughness、几何 normal anti-aliasing 等方法用不同代价保留分布方差。

environment lighting 对 BRDF 与球面 radiance 积分。常见 split-sum IBL 预过滤 environment 的 GGX lobe，并以 2D LUT 近似 Fresnel/visibility 积分；其 roughness mapping、NDF sampling、mip convention 与 runtime BRDF 必须一致。diffuse irradiance、specular prefilter、BRDF LUT 和 exposure 任一空间不一致都会让材质失真。
