## 直觉：GI 的困难是高维积分与可见性

先预测：红墙移到白墙旁边，烘焙 lightmap、screen-space GI 和动态探针分别何时更新？镜头看不到红墙后，SSGI 还能保留它的反弹光吗？技术选择取决于它存了什么、能看见什么、何时更新。

Ch11 Global Illumination 处理表面之间的间接能量交换；Ch26 Real-Time Ray Tracing 提供查询几何可见性和路径样本的现代执行方式。光追不自动等于 GI，也不自动精确：结果还取决于路径 estimator、样本数、材质、加速结构、降噪与历史有效性。


## Ch11 Global Illumination：递归 transport，不是一个 ambient 项

来自渲染方程的递归：入射 radiance 又是其他表面的出射 radiance。

$$
L_o(x,v)=L_e(x,v)+\int_{\Omega^+}f_r(x,l,v)L_i(x,l)V(x,l)(n\cdot l)d\omega.
$$

可以把 $L_i$ 按直接光源与其他表面贡献拆分，但 direct/indirect 的具体路径定义要与 estimator 一致。计算困难不只是“路径数量指数增长”：路径空间维度高、visibility 不连续、亮光源/高光路径导致方差，动态场景又限制预计算与时间复用。

是可见性/几何项近似，不等同于 GI，也不应无条件乘到所有 direct/specular/indirect light。SSAO 只看屏幕 depth/normal，缺少屏外、背面和距离之外的信息。

## 表示、缓存与更新策略


### 预计算 lightmap 与 probes

lightmap 把静态表面的 irradiance/radiance 烘焙到 UV atlas，质量高且运行时便宜，但受 UV、texel density、静态几何/光照和方向表示约束。directional lightmap 或 basis coefficients 可恢复部分法线/方向响应。

常用球谐函数压缩低频方向信号。插值需考虑墙体可见性，否则探针会跨墙漏光；tetrahedral/visibility-aware interpolation、probe relocation/classification 可改善。

### 动态探针、体素和距离场

不是“必然用体素存 irradiance”。典型 probe grid 更新 ray radiance 与 depth moments，使用 hysteresis 降噪；需要处理 probe 位于几何内、快速光照变化、薄墙漏光和 scrolling volume。

voxel cone tracing 把场景/辐射体素化并构建 mip，cone 近似方向积分；内存、各向异性、voxel leak 和动态更新是主要边界。SDF 方法擅长粗略 visibility/距离 marching，但薄几何、非均匀缩放与场组合误差需要保守处理。

### 屏幕空间与混合 GI

SSGI 从当前 frame buffers 追踪/采样，能复用已着色 radiance，成本低但缺屏外、被遮挡和背面信息，并受 depth thickness 近似限制。混合系统通常用 screen-space 取近场细节，probe/lightmap 供稳定低频，ray tracing 处理高价值缺口；每层需要 confidence 和明确 fallback。

## Ch26 Real-Time Ray Tracing：查询路径与加速结构


（BVH）把平均查询从线性枚举降到层次遍历，但复杂度依空间分布、构建质量和 ray coherence。

现代系统通常将 geometry 放在 BLAS，把 instance transform/reference 放在 TLAS。静态 BLAS 可高质量 build/compact；变形几何可 refit 或 rebuild；TLAS 随实例变换更新。build/update、scratch、compaction、memory residency 和同步都属于帧预算。

一条 ray 工作流包括 ray generation/query → TLAS/BLAS traversal → primitive intersection → any-hit/alpha decision → closest-hit shading 或 miss。硬件可加速 traversal/intersection，但 shader divergence、随机 memory、复杂 any-hit 与深递归仍昂贵。

```cpp
RayDesc ray = makeSecondaryRay(position, normal, sampledDirection);
RayHit hit = traceScene(tlas, ray, geometryMask);

if (hit.valid) {
    Surface next = fetchSurface(hit.instance, hit.primitive, hit.barycentrics);
    sample.radiance = emitted(next) + estimateDirect(next, rng);
    sample.throughput *= evaluateBsdfPdfRatio(surface, sampledDirection);
} else {
    sample.radiance = sampleEnvironment(ray.direction);
}
```

ray origin 必须按几何尺度稳健偏移，避免 self-intersection 又不穿过薄面；instance mask、alpha-tested any-hit、double-sided 与 motion transform 都要匹配 raster path。

## 低样本估计、复用与降噪

实时预算常只有每像素每效果少量 rays。Monte Carlo estimator：

$$
\hat L=\frac{1}{N}\sum_{i=1}^{N}\frac{f(X_i)}{p(X_i)},
\qquad Var[\hat L]\propto\frac{1}{N}.
$$

噪声标准差只按 $1/\sqrt N$ 下降，不能靠少量增加 samples 快速消失。importance sampling、next-event estimation、MIS、reservoir sampling 和 spatiotemporal reuse 用更好分布或更多候选降低方差，但必须保留正确权重与有效性。

通常包括：demodulation（可选）、temporal reprojection/accumulation、history validation、variance estimation、edge-aware spatial filter、remodulation。它会引入 bias；firefly clamp、history clamp 和 blur 必须用 reference 验证，不能只看“更干净”。

路径 throughput 在每次反射乘 BRDF、cosine、visibility 并除 PDF。Russian roulette 以存活概率继续长路径并除权，保持无偏而减少平均工作；固定截断则产生可解释但有偏的缺失能量。

## GI 方法的统一误差账本

任何实时 GI 都应记录四类误差：

- **representation**：lightmap/probe/voxel/GBuffer/ray scene 丢了哪些频率与几何；
- **sampling**：ray/direction/probe 更新是否覆盖主要贡献，PDF/权重是否正确；
- **reuse/filter**：历史、空间插值和 denoise 引入多少 lag、leak、blur、bias；
- **systems**：build/update、memory、streaming、queue 与 shader 成本是否满足 frame/latency budget。

## 小结

Ch11 与 Ch26 把间接光传输和实时几何查询连接起来。lightmap、probe、screen-space、voxel/SDF 与 ray tracing 只是不同的信息与更新选择；最终质量由 estimator、可见性、样本、复用和系统预算共同决定，必须以分层可视化、边界场景和高样本 reference 验收。
