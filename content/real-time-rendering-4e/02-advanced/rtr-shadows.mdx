## 直觉：阴影是一个可见性查询

先预测：把 shadow map 分辨率翻倍，acne 会自动消失吗？把 bias 加大，所有自阴影错误都会被修复吗？都不一定。阴影错误来自有限分辨率、投影参数、深度量化、receiver slope、过滤核、caster 几何和坐标约定的组合。

Ch7 Shadows 的核心问题是：从着色点沿光源方向，是否能看见发光体。shadow map 把三维 visibility 离散成光源视图中的 depth lookup；ray tracing 直接查询几何；其他方法则在精度、覆盖、软化和成本之间选择近似。


## Shadow map：深度是光源看到的第一层

通常包含：

1. 选择 light view/projection 与 caster set；
2. 渲染最接近光的 depth，包含 alpha-tested caster 的一致裁剪；
3. 把 receiver 变换到 light clip/NDC/texture coordinates；
4. 比较 receiver depth 与过滤后的 stored depth，得到 visibility；
5. 将 visibility 只作用于对应直接光，不能把环境光和 emissive 一并乘黑。

方向光使用正交投影，spot light 常用透视投影，point light 可用 cube 的六个面或其他全向参数化。不同 API 的 clip-depth range、reversed-Z、comparison sampler、border mode 与 Y orientation 必须端到端一致。

```glsl
float sampleShadow(vec4 lightClip, vec3 normalWS, vec3 lightDirWS) {
    vec3 ndc = lightClip.xyz / lightClip.w;
    vec3 uvz = ndcToShadowTexture(ndc); // API-specific depth range and Y
    if (any(lessThan(uvz.xy, vec2(0.0))) || any(greaterThan(uvz.xy, vec2(1.0))))
        return shadowOutsidePolicy;

    float bias = computeWorldAndSlopeBias(normalWS, lightDirWS, uvz.z);
    return texture(shadowCompareSampler, vec3(uvz.xy, uvz.z - bias));
}
```

constant depth bias、slope-scaled bias、normal offset 和 receiver-plane depth bias 处理不同误差。近似 slope bias 可随 $\tan\theta$ 增长：

$$
b=b_{constant}+b_{slope}\tan\theta,
\qquad \cos\theta=\mathbf n\cdot\mathbf l.
$$

但 grazing angle 时必须 clamp；单位还可能是 shadow depth、depth ULP、texel 或 world distance，不能把示例常数跨场景复制。

shadow texel 对应的 world-space footprint 随 projection 和位置变化。增大分辨率可缩小 footprint，却不能修复错误 near/far、坐标变换、bias 单位或 caster 缺失。首先可视化 cascade、light frustum、uvz、bias 和 raw comparison。

## 过滤与软阴影

必须“先比较、后平均”；直接线性过滤 depth 再比较并不等价。固定 PCF 核提供抗锯齿/模糊边界，但不会自然产生随 blocker-receiver-light 几何变化的 penumbra。

对宽度 $w_L$ 的面光源，简化平行平面下的 penumbra 尺度近似：

$$
w_P \propto w_L\frac{z_R-z_B}{z_B},
$$

其中 $z_B$ 是 blocker 距离，$z_R$ 是 receiver 距离。PCSS 先搜索 blocker，估计平均 blocker depth，再按 penumbra 调整 PCF 核；它仍有 blocker 搜索、采样噪声和复杂遮挡近似误差。

存储 $E[z]$ 与 $E[z^2]$，用 Chebyshev 上界估计遮挡。它支持普通过滤，却会 light bleeding；variance clamp、bleed reduction、EVSM/MSM 改善但会带来指数溢出、精度或额外矩成本。


## CSM：覆盖、稳定和接缝是一个系统

让近处小覆盖获得高 texel density，远处大覆盖保留阴影。split 可混合 uniform 与 logarithmic：

$$
d_i=\lambda n(f/n)^{i/N}+(1-\lambda)\left[n+(f-n)i/N\right].
$$

每 cascade 需要选择 caster volume、fit light projection，并处理：

- texel snapping/stable projection，防止相机微动导致阴影游泳；
- cascade overlap 与 cross-fade，隐藏分界跳变；
- receiver 选层与 caster 扩张，避免跨层漏影；
- 每层独立 bias/filter footprint，避免世界尺度不一致；
- 合理 far distance 与 fallback，而不是无限扩大最后一层。

## 全向、透明与混合方案

point-light cube shadow 要保持六面 orientation、seam、radial depth 与 near/far 一致；一次 geometry amplification 不一定比六次 pass 更快，应测量。大量局部光可用 atlas、cache、update scheduling 与 importance 管理成本。

alpha-tested foliage 在 shadow pass 必须使用与可见 pass 一致的 cutout 规则与 mip/LOD，否则叶片形状不一致。普通 shadow map 表示单层二值 visibility，不能直接表达彩色半透明或多层 transmittance；需 deep/opacity map、stochastic transparency、ray tracing 或领域近似。

ray-traced shadow 能直接采样面光源和几何 visibility，但仍需 samples、denoising、temporal reuse 与 fallback。常见混合是 CSM 提供主要方向光覆盖，screen/ray query 补 contact shadow，distance field/probe 处理特殊范围。屏幕空间 contact shadow 缺少屏外 caster，必须有置信度与降级路径。
