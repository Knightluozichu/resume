## 直觉引入

想象你在组装一台相机。管线是机身骨架（数据流向），变换是镜头调焦（空间变换），着色是感光元件（颜色计算），纹理是滤镜（细节增强），BRDF是色彩科学（物理精度），阴影和GI是补光灯（真实感增强），优化是快门速度（性能保证）。

每一步都建立在前一步之上：没有管线就没有数据流，没有变换就没有3D空间，没有着色就没有颜色。总复习的目标是把它们串成一条完整的链。

## 代码对照

```glsl
// 从零搭建渲染器的实现顺序（伪代码）
// Phase 1: 管线+变换（能画出三角形）
//   顶点着色器：MVP变换，片段着色器：纯色输出
// Phase 2: 基础着色（能画出光照效果）
//   Phong光照：ambient + diffuse + specular
vec3 phong(vec3 N, vec3 L, vec3 V) {
    vec3 ambient = vec3(0.1);
    vec3 diffuse = max(dot(N, L), 0.0) * vec3(0.8);
    vec3 specular = pow(max(dot(reflect(-L, N), V), 0.0), 32.0) * vec3(1.0);
    return ambient + diffuse + specular;
}
// Phase 3: 纹理（能画出细节）—— 采样diffuse贴图
// Phase 4: BRDF（物理精度）—— Cook-Torrance替换Phong镜面项
// Phase 5: 阴影+GI（真实感）—— Shadow Map + SSAO
// Phase 6: 优化（性能）—— 剔除 + 合批 + LOD
```

## 常见误区

<Callout type="trap">
**误区：学完每个章节就等于理解了全书。**
各章节不是孤立的——管线的光栅化决定了片段着色器的输入，着色模型的选择影响阴影实现方式，BRDF的物理性约束了GI的能量守恒。总复习要建立章节间的联系，而非只记单点知识。
</Callout>

<Callout type="trap">
**误区：认为实时渲染的理论已经「完成」了。**
实时渲染仍在快速演进：RTX硬件光线追踪改变了GI方案，神经网络渲染（NeRF/神经着色）正在兴起，可变速率着色(VRS)改变了着色策略。RTR4 覆盖的是当前工业实践的基础，不是终点。
</Callout>

<Exercises>
**问题 1**：如果从零搭建一个渲染器，应该按什么顺序实现？为什么？

<Answer>
按六阶段顺序：1) 管线+变换——先能画出三角形（MVP变换+纯色输出）；2) 基础着色——加Phong光照（能看出立体感）；3) 纹理——加diffuse贴图（能看出材质细节）；4) BRDF——用Cook-Torrance替换Phong（物理精度）；5) 阴影+GI——加Shadow Map和SSAO（真实感）；6) 优化——加剔除/合批/LOD（性能）。原因：每一步都依赖前一步，先功能后质量后性能，循序渐进。
</Answer>

**问题 2**：全书九大知识点之间的核心关系链是什么？

<Answer>
核心关系链：管线（定义数据流架构）→ 变换（定位几何到屏幕）→ 着色（计算基础颜色）→ 纹理（增加表面细节）→ BRDF（提升物理精度）→ 阴影（模拟光遮挡）→ GI（模拟间接光弹射）→ 优化（保证实时性能）。前四步是「能画出来」，中间三步是「画得真实」，最后一步是「画得够快」。优化贯穿全程，每加一个特性都要考虑性能影响。
</Answer>
</Exercises>

<GlossaryItem term="BRDF">双向反射分布函数，描述表面反射光物理特性的数学模型，PBR的核心。</GlossaryItem>
<GlossaryItem term="渲染优化">通过剔除、合批、LOD等技术保证渲染在帧预算内完成的工程化手段。</GlossaryItem>
