## 三个必须主动触发的误区

### 误区 1
**现象 →** 脚本里写死循环
**原因 →** 服务器被脚本锁死
**修法 →** 脚本保持短平快并设时限

### 误区 2
**现象 →** 频繁传全脚本
**原因 →** 带宽与解析浪费
**修法 →** SCRIPT LOAD + EVALSHA 缓存

### 误区 3
**现象 →** 脚本内做非确定操作
**原因 →** 复制回放结果分叉
**修法 →** 避免 RANDOMKEY/Time 等非确定命令

## 小结

- Lua 脚本原子执行多步操作
- EVAL 与 EVALSHA 两种调用
- 脚本缓存减少传输与编译
- 复制与 AOF 按效果传播
- 脚本过长会阻塞服务器

## 练习、答案与节点验证

<Exercises>

**问题 1：** Lua 脚本的原子性边界在哪里？

<Answer>
脚本执行期间不插入其他命令，但脚本内命令逐个生效；脚本崩溃时已执行部分不回滚。
</Answer>

**问题 2：** EVALSHA 相比 EVAL 的优势？

<Answer>
SCRIPT LOAD 预编译缓存，后续按 SHA1 调用，省去每次传输脚本体的带宽与解析成本。
</Answer>

**问题 3：** 用 Lua 实现一个限流器：每秒最多 N 次请求。（独立实现）

<Answer>
INCR 计数键，首次设 1 秒 TTL，超 N 返回 0；脚本原子完成检查与递增。
</Answer>

</Exercises>
