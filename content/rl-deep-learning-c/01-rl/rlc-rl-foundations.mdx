## 强化学习：通过试错学习决策

强化学习（Reinforcement Learning, RL）是机器学习三大范式之一。与监督学习从标注数据中学习不同，RL通过智能体（Agent）与环境（Environment）交互、试错来学习最优决策。智能体没有被告知「正确答案」，只收到延迟的奖励信号——就像学骑自行车，没人能告诉你每一秒该怎么动肌肉，但摔倒（负奖励）和保持平衡（正奖励）的反馈会让你逐渐学会。

## 五大核心概念

RL的交互循环围绕五个核心概念展开：

| 概念 | 符号 | 含义 |
|------|------|------|
| 智能体 | Agent | 做决策的学习者，内部含策略、值函数 |
| 环境 | Environment | 智能体交互的外部世界，定义转移和奖励 |
| 状态 | `s` | 环境在某一时刻的描述，智能体据此决策 |
| 动作 | `a` | 智能体在某个状态下可执行的操作 |
| 奖励 | `r` | 环境对动作的即时反馈标量 |

交互循环：智能体观察状态 `s_t` → 根据策略π选择动作 `a_t` → 环境执行动作并返回新状态 `s_{t+1}` 和奖励 `r_{t+1}` → 智能体更新策略，循环往复。**目标是最大化长期累积折扣回报** `G_t = Σ γ^k r_{t+k+1}`。

<Callout type="info">

**RL与监督学习的区别**：监督学习有标注数据 `(x, y)`，告诉模型「正确答案」；RL只有奖励信号，且通常是**延迟**的——下棋时一步好棋的价值要到几十步后才知道。这引出了RL的核心难题：**信用分配**（credit assignment），即如何将最终的奖励归因到具体的动作。

</Callout>

## 马尔可夫决策过程（MDP）

RL的数学形式化是**马尔可夫决策过程（MDP）**，用五元组 `(S, A, P, R, γ)` 定义：

- **S**：状态空间，所有可能状态的集合
- **A**：动作空间，所有可执行动作的集合
- **P(s'|s,a)**：状态转移概率，在状态s执行动作a后转移到s'的概率
- **R(s,a)**：奖励函数，执行动作后获得的期望奖励
- **γ**：折扣因子 `∈ [0,1]`，权衡即时与长期奖励

**马尔可夫性质**：未来只取决于现在，不依赖过去——`P(s_{t+1}|s_t, a_t, s_{t-1}, ...) = P(s_{t+1}|s_t, a_t)`。这一性质使RL问题可解，否则需考虑全部历史，计算不可行。

## 策略与值函数

**策略** `π(a|s)` 是智能体在状态s下选择动作a的概率分布。确定性策略直接输出动作 `π(s) = a`；随机策略输出概率分布。

**值函数**衡量一个状态（或状态-动作对）的「好坏」：

- **状态值函数** `V^π(s)`：在状态s下遵循策略π的期望累积折扣回报
- **动作值函数** `Q^π(s,a)`：在状态s执行动作a后遵循策略π的期望回报

### 贝尔曼方程

贝尔曼方程将值函数递归分解为「即时奖励 + γ × 下一状态值」：

```text
V(s) = Σ_a π(a|s) Σ_s' P(s'|s,a) [R(s,a,s') + γ V(s')]
Q(s,a) = Σ_s' P(s'|s,a) [R(s,a,s') + γ max_a' Q(s',a')]
```

<Callout type="tip">

**贝尔曼方程是RL的基石**：Q-Learning（ch2）的更新公式 `Q(s,a) ← Q(s,a) + α[r + γ max Q(s',a') - Q(s,a)]` 就是贝尔曼方程的采样近似版本。DQN（ch5）的损失函数 `(Q(s,a;θ) - [r + γ max Q(s',a';θ⁻)])²` 也是贝尔曼方程的神经网络回归形式。理解贝尔曼方程，就理解了RL算法的核心。

</Callout>

## RL三大方法族

| 方法族 | 核心思想 | 代表算法 | 适用场景 |
|--------|---------|---------|---------|
| 基于价值 | 学习值函数V/Q，间接推导策略 | Q-Learning, DQN | 离散动作空间 |
| 基于策略 | 直接参数化策略π_θ，优化期望回报 | REINFORCE, PPO | 连续动作空间 |
| 基于模型 | 学习环境模型P/R，用模型规划 | Dyna-Q, MCTS | 样本昂贵场景 |

本书重点覆盖前两类：ch2的Q-Learning和ch5的DQN属于基于价值，ch6的Policy Gradient属于基于策略。

## C语言视角：RL的最小实现

在C语言中，RL的最小实现（Q表法）只需要几个核心数据结构：

```c
// Q表：二维数组
double q_table[N_STATES][N_ACTIONS];

// 训练循环
for (int ep = 0; ep < MAX_EPISODES; ep++) {
    int s = env_reset(&env);
    while (!done) {
        int a = epsilon_greedy(q_table, s, epsilon);
        EnvStep step = env_step(&env, a);
        double max_q = max_action_value(q_table[step.state]);
        double td_target = step.reward + gamma * max_q;
        q_table[s][a] += alpha * (td_target - q_table[s][a]);
        s = step.state;
    }
}
```

这就是RL的核心——**用贝尔曼更新修改表格中的值**。后续章节将逐步用神经网络替代Q表，但这个「观察→行动→更新」的循环不变。

<Glossary>

<GlossaryItem term="马尔可夫决策过程（MDP）">
强化学习的数学形式化框架，用五元组 `(S, A, P, R, γ)` 定义：状态集S、动作集A、转移概率P(s'|s,a)、奖励函数R、折扣因子γ。马尔可夫性质：未来只取决于当前状态，不依赖历史。MDP是所有RL算法的理论基础。
</GlossaryItem>

<GlossaryItem term="折扣因子（Discount Factor γ）">
权衡即时奖励与长期奖励的参数 `γ ∈ [0,1)`。γ接近0时智能体目光短浅（只看即时奖励），γ接近1时智能体目光长远（重视未来回报）。γ小于1保证无限horizon的回报级数收敛。常用值0.9-0.99。
</GlossaryItem>

<GlossaryItem term="探索与利用（Exploration vs Exploitation）">
RL的核心权衡。探索（Exploration）尝试新动作发现更优策略；利用（Exploitation）选择当前已知最优动作获取最大奖励。ε-贪心策略是经典平衡方法：以ε概率随机探索，1-ε概率利用。本书ch2详细讲解。
</GlossaryItem>

<GlossaryItem term="TD误差（Temporal Difference Error）">
时序差分误差，即「TD目标 - 当前估计」`δ = r + γ max Q(s',a') - Q(s,a)`。TD误差驱动Q-Learning的更新——正值说明当前Q值低估了，需增大；负值说明高估了，需减小。TD误差是RL中「学习信号」的核心载体。
</GlossaryItem>

<GlossaryItem term="on-policy与off-policy">
on-policy算法（如SARSA）用同一策略采样和更新，学的是当前行为策略的值；off-policy算法（如Q-Learning）用行为策略采样但用目标策略（贪心）更新，能从旧经验中学习。off-policy支持经验回放（DQN的基础），样本效率更高。
</GlossaryItem>

</Glossary>

### 问题 1

强化学习中「智能体」「环境」「状态」「动作」「奖励」五个核心概念分别是什么？它们如何交互？

<Answer>

强化学习的五个核心概念：①智能体（Agent）——做决策的学习者，内部包含策略π、值函数V/Q。②环境（Environment）——智能体交互的外部世界，定义状态转移和奖励规则。③状态（State s）——环境在某一时刻的描述。④动作（Action a）——智能体可执行的操作。⑤奖励（Reward r）——环境对动作的即时反馈标量。交互循环：智能体观察状态s_t → 根据策略π选择动作a_t → 环境执行动作并返回新状态s_{t+1}和奖励r_{t+1} → 智能体更新策略，循环往复。目标是最大化长期累积折扣回报 `G_t = Σ γ^k r_{t+k+1}`。
</Answer>

### 问题 2

什么是马尔可夫决策过程（MDP）？写出其五元组定义和马尔可夫性质。

<Answer>

MDP用五元组 `(S, A, P, R, γ)` 定义：①S——状态空间。②A——动作空间。③P——状态转移概率 `P(s'|s,a)`。④R——奖励函数 `R(s,a)`。⑤γ——折扣因子 `∈ [0,1]`。马尔可夫性质：「未来只取决于现在，不依赖过去」——`P(s_{t+1}|s_t, a_t, s_{t-1}, ...) = P(s_{t+1}|s_t, a_t)`，状态s_t包含了所有历史相关信息。这一性质使RL问题可解，否则需要考虑全部历史，计算不可行。
</Answer>

### 问题 3

写出状态值函数和动作值函数的贝尔曼方程，并解释其含义。

<Answer>

状态值：`V^π(s) = Σ_a π(a|s) Σ_s' P(s'|s,a) [R(s,a,s') + γ V^π(s')]`，即当前状态的值 = 对所有动作按策略加权 × 对所有下一状态按转移概率加权 × （即时奖励 + γ × 下一状态值）。动作值：`Q^π(s,a) = Σ_s' P(s'|s,a) [R(s,a,s') + γ Σ_a' π(a'|s') Q^π(s',a')]`。贝尔曼方程将「无穷horizon的期望」递归分解为「即时奖励 + 下一状态值」，是值迭代、Q-Learning等算法的理论基础。最优值函数满足 `Q*(s,a) = Σ_s' P(s'|s,a)[R + γ max_a' Q*(s',a')]`。
</Answer>

### 问题 4

RL有哪三大方法族？各自的核心思想和代表算法是什么？

<Answer>

①基于价值——学习值函数V/Q，间接推导策略。代表：Q-Learning、DQN。适合离散动作空间。②基于策略——直接参数化策略π_θ，梯度上升优化期望回报。代表：REINFORCE、PPO。适合连续动作空间。③基于模型——先学习环境模型P/R，再用模型规划。代表：Dyna-Q、MCTS。适合样本昂贵场景。本书ch2和ch5属于基于价值，ch6属于基于策略。
</Answer>
