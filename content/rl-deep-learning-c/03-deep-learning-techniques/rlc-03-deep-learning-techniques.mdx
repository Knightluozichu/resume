## 数学骨架

$$
z_j=\sum_iw_{ji}x_i+b_j,\qquad y_j=f(z_j)
$$

$$
\delta_j=f'(z_j)\sum_k w_{kj}\delta_k
$$

$$
w_{ji}\leftarrow w_{ji}-\eta\delta_jx_i
$$

$$
h_{r,c,k}=f\!\left(b_k+\sum_{u,v,d}K_{u,v,d,k}x_{r+u,c+v,d}\right)
$$

公式进入 C 循环前逐项映射变量：写清标量与数组、输入和输出长度、旧值和新值、学习率与折扣因子的范围。浮点运算后检查有限值；argmax 只遍历合法动作；网络目标只修改被选择动作的输出，其他输出保持当前预测。

## 三段可编译核心

```c
double neuron(const double *x, const double *w, int n, double bias) {
    double z = bias;
    for (int i = 0; i < n; ++i) z += w[i] * x[i];
    return 1.0 / (1.0 + exp(-z));
}
```

```c
for (int j = 0; j < hidden_count; ++j) {
    hidden_delta[j] = hidden[j] * (1.0 - hidden[j]);
    double downstream = 0.0;
    for (int k = 0; k < output_count; ++k)
        downstream += output_weight[k][j] * output_delta[k];
    hidden_delta[j] *= downstream;
}
```

```c
for (int r = 0; r < out_h; ++r)
    for (int c = 0; c < out_w; ++c) {
        double sum = bias;
        for (int u = 0; u < kh; ++u)
            for (int v = 0; v < kw; ++v)
                sum += image[r + u][c + v] * kernel[u][v];
        feature[r][c] = sum;
    }
```

代码片段刻意保留显式循环和状态结构。复现时使用编译器告警、地址/未定义行为检测和固定种子；对每个数组维度增加断言，并将环境、学习器和评价器分开，避免评价过程继续更新 Q 表或网络权重。

## 七类实现证据

### 输入与内存合同

固定数据、迷宫和随机种子，声明所有静态数组的容量、有效长度与所有权。每次 episode 开始前写明状态、轨迹和梯度是否清零；释放或复用动态内存时保留唯一责任方，编译器告警必须视为失败。

### 环境转移合同

环境函数只根据当前状态与动作产生下一状态、奖励和终止标记，不读取 Q 表或网络参数。非法动作在进入学习器前拒绝；同一状态动作在确定性迷宫中必须得到相同转移，随机环境则保存随机数序列。

### Q学习合同

保存旧 Q、即时奖励、下一状态合法动作最大值、TD 目标、TD 误差和新 Q。终止状态的未来值固定为零，argmax 与探索采样必须使用同一合法动作集合，更新后的值不能被误用于同一步目标。

### 网络前向合同

逐层保存加权和与激活，偏置只加一次，输入和输出节点次序与状态/动作编码一致。对 nn1.c、nn2.c、nn3.c 和深度强化程序使用相同的激活定义与数值范围，防止训练和评价路径分叉。

### 反向传播合同

先计算输出层局部误差，再用更新前权重传播到隐藏层，最后统一更新参数。用中心有限差分核对一个权重；若符号、量级或相对误差不满足容差，禁止增加隐藏单元或训练轮数。

### 卷积与融合合同

卷积要声明步幅、边界、核翻转约定与输出尺寸，手算一个窗口。Q 学习与网络融合时，网络所有动作输出先复制到目标数组，只替换所选动作的 TD 目标，并确保终止转移不访问下一状态网络输出。

### 回退与评价合同

评价从固定初态开始，冻结探索率和学习开关，不读取上一 episode 的隐藏状态或梯度。出现分叉时依次回退环境、Q 目标、前向、反向和参数更新；最小样例一致后才运行书中的完整迷宫。

  **用现代 DQN 概念覆盖原书程序：** 本书展示的是 Q
  学习与前馈网络的直接融合，没有经验回放、目标网络或策略梯度；必须忠于 q21dl.c
  和 q22dl.c 的实际边界。
</Callout>

<Callout type="tip">
  **最小重放顺序：** 先用两状态两动作手算 Q
  更新，再用单神经元核对梯度，最后才把网络接入迷宫。
</Callout>

## 本章回顾

从单个人工神经元进入分层网络，依次重放 nn1.c、反向传播 nn2.c、多输出 nn3.c，再以卷积核、特征图和共享权重说明卷积神经网络的算法与 C 数组实现。验收底线是：nn1.c、nn2.c、nn3.c 和卷积实现都能保存激活、局部误差和更新前后权重；反向梯度通过有限差分，多输出维度与卷积边界均有断言。掌握标准是能在运行前预测首个变化，逐行解释 C 循环，复现实验，解释失败样本，并证明评价不改变学习状态。

</Answer>
