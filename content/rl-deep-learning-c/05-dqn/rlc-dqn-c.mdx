## DQN：Q-Learning + 神经网络

ch2的Q-Learning用Q表存储值函数，只能处理小规模离散状态空间。当状态连续（如CartPole的 `[x, ẋ, θ, θ̇]`）或高维（如Atari像素），Q表无法枚举所有状态。DQN（Deep Q-Network）的核心改进是**用神经网络替代Q表**作为函数近似器 `Q(s,a;θ) ≈ Q*(s,a)`，输入状态s，输出每个动作的Q值。

## 核心改进：两大稳定化技巧

直接将NN接入Q-Learning会导致训练不稳定（序列数据相关、目标值不断变化），DQN引入两个关键技巧：

### 1. 经验回放（Experience Replay）

将转移 `(s, a, r, s', done)` 存入缓冲区，训练时**随机采样**打破时序相关性。

```c
#define BUFFER_SIZE 10000
#define STATE_DIM 4

typedef struct {
    double states[BUFFER_SIZE][STATE_DIM];
    int actions[BUFFER_SIZE];
    double rewards[BUFFER_SIZE];
    double next_states[BUFFER_SIZE][STATE_DIM];
    int dones[BUFFER_SIZE];
    int size;
    int idx;
} ReplayBuffer;

void store(ReplayBuffer* buf, double* s, int a, double r, double* s_next, int done) {
    for (int i = 0; i < STATE_DIM; i++) {
        buf->states[buf->idx][i] = s[i];
        buf->next_states[buf->idx][i] = s_next[i];
    }
    buf->actions[buf->idx] = a;
    buf->rewards[buf->idx] = r;
    buf->dones[buf->idx] = done;
    
    buf->idx = (buf->idx + 1) % BUFFER_SIZE;  // 环形覆盖
    if (buf->size < BUFFER_SIZE) buf->size++;
}
```

<Callout type="info">

**为什么随机采样？** 连续的转移高度相关（同一episode内状态相近），直接用序列训练会使网络过拟合局部轨迹。随机采样使minibatch内的经验来自不同时间步，近似独立同分布（i.i.d.），满足SGD假设。同时一条经验可多次复用，提高数据效率。

</Callout>

### 2. 目标网络（Target Network）

用独立的网络计算TD目标，参数θ⁻定期从主网络复制，使目标值在一段时间内稳定。

```c
NeuralNetwork q_net;       // 主网络（在线学习）
NeuralNetwork target_net;  // 目标网络（计算TD目标）

// 每C步硬更新目标网络
void update_target_network(NeuralNetwork* target, NeuralNetwork* source) {
    memcpy(target->W, source->W, sizeof(source->W));
    memcpy(target->b, source->b, sizeof(source->b));
}
```

<Callout type="tip">

**为什么需要目标网络？** 如果用同一网络同时计算预测值和目标值 `r + γ max Q(s',a';θ)`，每次更新θ后目标也变了——「追逐移动的靶子」，导致发散。目标网络θ⁻固定不动，使回归问题可收敛。

</Callout>

## DQN损失函数

```text
L(θ) = E[(Q(s,a;θ) - y)²]
y = r + γ · max_a' Q(s',a';θ⁻)    （TD目标，用目标网络算）
```

本质是回归问题——让Q网络的预测逼近TD目标。

## C语言训练循环

```c
#define BATCH_SIZE 32
#define TARGET_UPDATE_FREQ 500

NeuralNetwork q_net, target_net;
ReplayBuffer buffer;

init_network(&q_net, (int[]){STATE_DIM, 64, 32, N_ACTIONS}, 4);
init_network(&target_net, (int[]){STATE_DIM, 64, 32, N_ACTIONS}, 4);
update_target_network(&target_net, &q_net);  // 初始同步

int total_steps = 0;

for (int ep = 0; ep < MAX_EPISODES; ep++) {
    double state[STATE_DIM];
    env_reset(&env, state);
    int done = 0;
    double total_reward = 0.0;
    
    while (!done) {
        // 1. ε-贪心选动作
        forward(&q_net, state);
        int action = epsilon_greedy(q_net.a[q_net.n_layers-1], N_ACTIONS, epsilon);
        
        // 2. 执行动作
        EnvStep step = env_step(&env, action);
        
        // 3. 存入经验回放
        store(&buffer, state, action, step.reward, step.state, step.done);
        
        // 4. 训练（缓冲区够大时）
        if (buffer.size >= BATCH_SIZE) {
            train_dqn(&q_net, &target_net, &buffer);
        }
        
        // 5. 定期更新目标网络
        if (total_steps % TARGET_UPDATE_FREQ == 0)
            update_target_network(&target_net, &q_net);
        
        // 6. 衰减ε
        epsilon = fmax(epsilon * 0.995, 0.01);
        
        memcpy(state, step.state, sizeof(double) * STATE_DIM);
        done = step.done;
        total_reward += step.reward;
        total_steps++;
    }
}
```

### 单步训练函数

```c
void train_dqn(NeuralNetwork* q_net, NeuralNetwork* target_net, ReplayBuffer* buf) {
    // 随机采样minibatch
    int indices[BATCH_SIZE];
    for (int i = 0; i < BATCH_SIZE; i++)
        indices[i] = rand() % buf->size;
    
    for (int b = 0; b < BATCH_SIZE; b++) {
        int idx = indices[b];
        double* s = buf->states[idx];
        int a = buf->actions[idx];
        double r = buf->rewards[idx];
        double* s_next = buf->next_states[idx];
        int done = buf->dones[idx];
        
        // 计算TD目标
        double td_target;
        if (done) {
            td_target = r;
        } else {
            forward(target_net, s_next);
            double max_q = max_action_value(target_net->a[target_net->n_layers-1], N_ACTIONS);
            td_target = r + gamma * max_q;
        }
        
        // 前向传播主网络
        forward(q_net, s);
        
        // 构造目标向量（只改动作a的Q值）
        double target[N_ACTIONS];
        for (int i = 0; i < N_ACTIONS; i++)
            target[i] = q_net->a[q_net->n_layers-1][i];
        target[a] = td_target;
        
        // 反向传播更新
        backward(q_net, target, learning_rate);
    }
}
```

<Glossary>

<GlossaryItem term="DQN（Deep Q-Network）">
用神经网络近似Q函数的深度强化学习算法，由DeepMind于2013年提出。核心：NN替代Q表处理连续/高维状态空间，配合经验回放和目标网络稳定训练。损失 `L=(Q(s,a;θ)-[r+γ max Q(s',a';θ⁻)])²`。是第一个在复杂任务上稳定训练的深度RL算法。
</GlossaryItem>

<GlossaryItem term="经验回放（Experience Replay）">
将转移 `(s,a,r,s',done)` 存入缓冲区，训练时随机采样minibatch的技术。作用：①打破时序相关性使数据近似i.i.d. ②一条经验多次复用提高数据效率。C语言用环形缓冲区实现。
</GlossaryItem>

<GlossaryItem term="目标网络（Target Network）">
DQN中用于计算TD目标的独立网络，参数θ⁻定期从主网络复制。作用：使TD目标在一段时间内稳定，避免「追逐移动靶子」的发散问题。更新方式：硬更新（每C步完整复制）或软更新（每步小步幅加权平均）。
</GlossaryItem>

<GlossaryItem term="过估计问题（Overestimation Bias）">
DQN的TD目标用 `max Q(s',a')` 会系统性高估Q值（Jensen不等式）。解决：Double DQN用主网络选动作、目标网络估值，解耦「选」和「评」。C语言实现只需多一次前向传播。
</GlossaryItem>

</Glossary>

### 问题 1

DQN相比Q-Learning解决了什么问题？核心改进是什么？

<Answer>

Q-Learning用Q表存储值函数，只能处理离散小规模状态空间。DQN用神经网络替代Q表作为函数近似器 `Q(s,a;θ)≈Q*(s,a)`，能处理连续高维状态空间。核心改进是两个稳定化技巧：①经验回放——存入缓冲区随机采样打破时序相关性。②目标网络——用独立网络算TD目标，参数定期同步，使目标值稳定。这两点使DQN成为第一个在复杂任务上稳定训练的深度RL算法。
</Answer>

### 问题 2

DQN的损失函数是什么？为什么需要目标网络？目标网络参数如何更新？

<Answer>

损失：`L(θ)=E[(Q(s,a;θ)-y)²]`，TD目标 `y=r+γ·max_a' Q(s',a';θ⁻)`。需要目标网络：若用同一网络算预测和目标，每次更新θ后目标也变，「追逐移动靶子」导致发散。目标网络θ⁻固定使回归可收敛。更新方式：①硬更新——每C步完整复制 `memcpy(target.W, q_net.W, ...)`。②软更新——每步 `θ⁻←τ·θ+(1-τ)·θ⁻`（τ很小）。C语言维护两个NeuralNetwork结构体。
</Answer>

### 问题 3

经验回放缓冲区在C语言中如何实现？为什么需要随机采样？

<Answer>

C语言用环形缓冲区实现：`typedef struct { double states[BUFFER_SIZE][STATE_DIM]; int actions[BUFFER_SIZE]; ... int idx; } ReplayBuffer;`，存入时 `idx=(idx+1)%BUFFER_SIZE` 循环覆盖。随机采样：`int idx = rand() % size` 取minibatch。需要随机采样原因：①打破时序相关性——连续转移高度相关，随机采样使minibatch近似i.i.d.满足SGD假设。②提高数据效率——一条经验多次复用。③平滑训练分布——混合新旧策略经验防止训练崩溃。
</Answer>

### 问题 4

DQN训练中Q值过估计问题的原因是什么？如何用Double DQN解决？

<Answer>

过估计原因：TD目标用 `max Q(s',a')`，由于Q值估计有噪声，取max系统性偏向高估（Jensen不等式 `E[max(Q)]≥max(E[Q])`），高估值通过贝尔曼方程传播发散。Double DQN解法：解耦「选」和「评」——用主网络选动作 `a*=argmax Q_main(s',a')`，用目标网络估值 `Q_target(s',a*)`。TD目标改为 `y=r+γ·Q_target(s', argmax Q_main(s',a'))`。即使Q_main高估某动作，Q_target给保守评估。C语言实现：先forward(q_net,s')算argmax，再forward(target_net,s')取该动作Q值，改动小效果好。
</Answer>
