## 直觉引入

想象你搬进了新家。你有一个名字（局部变量，只在你的房间有效），你家的门牌号（实例变量，属于你家的房子），小区共享的游泳池（类变量，所有住户共享），还有市政厅登记的城市信息（全局变量，全市可见）。

在 Ruby 中，变量不是盒子（装值），而是标签（贴在对象上）。当你写 `a = "hello"`，你是在创建一个字符串对象，然后把标签 `a` 贴在它上面。`b = a` 不是复制对象，而是再贴一个标签 `b` 到同一个对象。

## 概念讲解

### 一切皆对象

<Term def="Ruby 中所有值都是对象——数字、字符串、布尔值、甚至类本身都是某个类的实例。继承链为 obj → 类 → Class → Object → BasicObject。">

在 Ruby 中，`5` 是 `Integer` 的实例，`Integer` 是 `Class` 的实例，`Class` 的父类是 `Module`，`Module` 的父类是 `Object`，`Object` 的父类是 `BasicObject`。

```ruby
5.class              # => Integer
Integer.class        # => Class
Class.superclass     # => Module
Module.superclass    # => Object
Object.superclass    # => BasicObject
```

这意味着：类本身也是对象（`Class` 的实例），可以接收方法调用、被赋值给变量、作为参数传递。这是 Ruby 元编程的基础。

</Term>

### 四种变量类型

<Term def="Ruby 变量按前缀分四种作用域：局部变量（小写）、实例变量（@）、类变量（@@）、全局变量（$）。还有常量（大写开头）。">

```ruby
# 局部变量：方法/块内有效，出了作用域不可访问
name = "Ruby"

# 实例变量：@开头，属于对象实例，每个对象独立
@name = "Alice"

# 类变量：@@开头，类及所有子类/实例共享
@@count = 0

# 全局变量：$开头，程序任何地方可访问
$DEBUG = true

# 常量：大写开头，赋值后不应修改（修改会有警告）
MAX_RETRIES = 3
```

类变量 `@@` 和类实例变量 `@`（在类上下文中的 `@`）容易混淆：类变量被子类共享，类实例变量不共享。

</Term>

### 变量是引用

<Term def="Ruby 变量存储的是对象的引用（reference），不是值。赋值传递引用，多个变量可指向同一对象。">

```ruby
a = "hello"
b = a        # b 和 a 指向同一个字符串对象
b << "!"     # 原地修改
puts a       # => "hello!"（a 也变了！）

# 如果需要独立副本
c = a.dup    # 浅拷贝（复制对象，但不复制内部引用的对象）
d = a.clone  # 类似 dup，但保留冻结状态和单例方法
```

注意：`dup` 和 `clone` 都是浅拷贝。深拷贝需要用 `Marshal.load(Marshal.dump(obj))` 或自定义实现。

</Term>

<Step title="理解继承链">
在 irb 中输入 `5.class.class.superclass`，你会得到 `Object`。这说明：`5` 是 `Integer` 的实例，`Integer` 是 `Class` 的实例，`Class` 继承自 `Object`。每个对象都知道自己的类，每个类知道自己的父类。这就是 Ruby 的对象模型——自洽而统一。
</Step>
<Step title="区分四种变量">
在类定义中，`@x` 是实例变量（每个对象独立），`@@x` 是类变量（所有实例共享），`$x` 是全局变量（全程序可见）。选择原则：能用局部变量就不用实例变量，能用实例变量就不用全局变量——最小化作用域减少耦合。
</Step>
<Step title="理解引用语义">
`a = [1,2,3]; b = a; b[0] = 99` 之后 `a` 也变成 `[99,2,3]`。因为 `b = a` 只是复制引用。要独立修改，用 `b = a.dup`。这在方法参数传递时尤其重要——方法内修改参数会影响调用者的原始对象。
</Step>
</Stepper>

## 代码对照

```ruby
# === 对象模型 ===
class Person
  @@population = 0          # 类变量：所有 Person 共享

  def initialize(name)
    @name = name            # 实例变量：每个 Person 独立
    @@population += 1
  end

  def name
    @name                   # 读取实例变量
  end

  def self.population
    @@population            # 类方法读取类变量
  end
end

p1 = Person.new("Alice")
p2 = Person.new("Bob")

puts p1.name               # => Alice（各自的 @name）
puts p2.name               # => Bob
puts Person.population     # => 2（共享的 @@population）

# === 引用语义 ===
original = "hello"
reference = original       # 同一对象
reference.upcase!          # 原地修改
puts original              # => HELLO（原对象被改了）

copy = original.dup        # 独立副本
copy.downcase!
puts original              # => HELLO（不受影响）
puts copy                  # => hello
```

## 常见误区

<Callout type="trap">
**误区：认为 `0` 和 `""` 是假值**
在 C/Python/JavaScript 中，`0`、空字符串、空数组都是假值。但在 Ruby 中，**只有 `nil` 和 `false` 为假**，其他一切（包括 `0`、`""`、`[]`）都是真值。写 `if 0 then puts "真" end` 会打印"真"。这是初学者最常踩的坑。
</Callout>

<Callout type="trap">
**误区：混淆 `dup` 和 `clone`**
`dup` 和 `clone` 都是浅拷贝，但有微妙差异：`clone` 保留对象的冻结状态（frozen?）和单例方法，`dup` 不保留。冻结的字符串 `clone` 后仍冻结，`dup` 后不冻结。需要完全独立的副本时，两者都不能满足深拷贝需求——用 `Marshal.load(Marshal.dump(obj))`。
</Callout>

<Exercises>
**问题 1**：以下代码输出什么？解释原因。

```ruby
a = "hello"
b = a
b << " world"
puts a
```

<Answer>
输出：`hello world`

原因：`b = a` 不是复制字符串，而是让 `b` 和 `a` 指向同一个字符串对象。`<<` 是原地追加操作（修改原对象），所以 `a` 指向的对象也被修改了。

如果想要独立修改，应该用 `b = a.dup` 创建副本：
```ruby
a = "hello"
b = a.dup        # 独立副本
b << " world"
puts a           # => hello（不受影响）
```

核心概念：Ruby 变量是引用，赋值传递引用而非值。`<<` 和 `upcase!` 等带 `!` 的方法通常是原地修改。
</Answer>

**问题 2**：类变量 `@@count` 和类实例变量 `@count`（在类方法中）有什么区别？

<Answer>
`@@count` 是类变量，被类和所有子类共享——修改父类的 `@@count`，子类也能看到变化，反之亦然。这容易导致意外的耦合。

`@count` 在类上下文中是类实例变量，只属于当前类，不与子类共享。它比 `@@count` 更安全。

```ruby
class Parent
  @@shared = 0
  @isolated = 0

  def self.inc_shared; @@shared += 1; end
  def self.inc_isolated; @isolated += 1; end
end

class Child < Parent
  def self.read_shared; @@shared; end  # 能看到 Parent 的 @@shared
  # @isolated 在 Child 中是 nil（各自独立）
end

Parent.inc_shared  # @@shared = 1
Child.read_shared  # => 1（共享！）
```

Ruby 社区倾向用类实例变量替代类变量，避免继承带来的意外共享。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="引用语义">
Ruby 变量存储对象的引用而非值本身。赋值 `b = a` 让 b 和 a 指向同一对象。修改一个会影响另一个，除非用 dup/clone 创建副本。
</GlossaryItem>
<GlossaryItem term="继承链">
Ruby 的对象-类-元类层次：obj → 类 → Class → Module → Object → BasicObject。每个对象通过 `.class` 找到所属类，类通过 `.superclass` 找到父类。
</GlossaryItem>
<GlossaryItem term="真值规则">
Ruby 中只有 `nil` 和 `false` 为假，其他所有值（包括 `0`、`""`、`[]`）都是真值。这与 C/Python/JS 不同，是初学者常踩的坑。
</GlossaryItem>
<GlossaryItem term="dup vs clone">
两者都是浅拷贝。`clone` 保留冻结状态和单例方法，`dup` 不保留。深拷贝需用 `Marshal.load(Marshal.dump(obj))`。
</GlossaryItem>
</Glossary>
