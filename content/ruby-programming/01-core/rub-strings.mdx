## 直觉引入

字符串就像橡皮泥——在 Ruby 中你可以随意揉捏它。`"hello" << "!"` 直接在原橡皮泥上加了一笔，而不是拿一块新的。这与 Symbol 形成鲜明对比——Symbol 更像印章，刻好了就永远不变，每次盖章都是同一个印记。

Ruby 的字符串插值 `"#{expr}"` 让你像写模板一样自然地嵌入表达式——不需要 `+` 拼接，不需要 `sprintf` 格式化，直接在字符串里写 Ruby 代码。

## 概念讲解

### 字符串的可变性

<Term def="Ruby 字符串是可变的——`<<`、`upcase!`、`concat` 等方法直接修改原对象。`+` 创建新字符串。Symbol 不可变且同名唯一。">

```ruby
s = "hello"
t = s        # t 和 s 指向同一对象
s << "!"     # 原地追加（修改原对象）
puts t       # => "hello!"（t 也变了）

s2 = s + "!" # 创建新字符串
puts s2      # => "hello!!"
puts s       # => "hello!"（s 不变）
```

带 `!` 的方法（如 `upcase!`、`gsub!`）通常是原地修改版本，不带 `!` 的返回新对象。这是 Ruby 的命名约定。

</Term>

### 字符串插值

<Term def="字符串插值 `"#{expr}"` 在双引号字符串中嵌入任意 Ruby 表达式，单引号字符串不解析插值。">

```ruby
name = "Ruby"
version = 3.2

# 双引号：支持插值和转义
puts "Hello, #{name}!"           # => Hello, Ruby!
puts "Version: #{version}"       # => Version: 3.2
puts "1 + 2 = #{1 + 2}"         # => 1 + 2 = 3

# 单引号：原样输出（除了 \' 和 \\）
puts 'Hello, #{name}!'           # => Hello, #{name}!
puts 'Tab:\t'                    # => Tab:\t（不转义）
```

单引号更快（无需解析），双引号更灵活。需要插值或转义时用双引号，纯文本用单引号。

</Term>

### String 与 Symbol

<Term def="String 可变且每次创建新对象，Symbol 不可变且同名始终同一对象。Symbol 适合做哈希键和枚举值。">

```ruby
# String：每次创建新对象
"hello".object_id  # => 60（某个值）
"hello".object_id  # => 80（另一个值！）

# Symbol：同名始终同一对象
:hello.object_id   # => 123456
:hello.object_id   # => 123456（相同！）

# Symbol 更高效——做哈希键时
hash = { name: "Alice", age: 30 }  # 等价于 { :name => "Alice", :age => 30 }
hash[:name]  # => Alice
```

Symbol 是 Ruby 独有的类型——内部以整数存储，不可变，GC 友好。做方法名、哈希键、状态标识时用 Symbol，做用户输入文本时用 String。

</Term>

## 代码对照

```ruby
# === 创建与插值 ===
name = "World"
double = "Hello, #{name}!"   # 双引号 + 插值
single = 'Hello, #{name}!'   # 单引号：原样输出

puts double  # => Hello, World!
puts single  # => Hello, #{name}!

# === 可变性演示 ===
s = "hello"
original_id = s.object_id

s << " world"            # 原地追加（object_id 不变）
puts s.object_id == original_id  # => true

s2 = s + "!"             # 创建新对象
puts s2.object_id == original_id # => false

# === 常用操作 ===
text = "  Ruby Programming  "

text.strip              # => "Ruby Programming"（去首尾空白）
text.upcase             # => "  RUBY PROGRAMMING  "
text.downcase.strip     # => "ruby programming"（链式调用）
text.split(" ")         # => ["", "Ruby", "Programming", ""]
text.gsub(/Ruby/, "Rails")  # => "  Rails Programming  "
text.include?("Ruby")   # => true
text.length             # => 21

# === Symbol ===
status = :active         # Symbol 做 enum
status == :active        # => true
:active.to_s             # => "active"（转 String）
"active".to_sym          # => :active（转 Symbol）

# 做哈希键
config = { host: "localhost", port: 3000 }
config[:host]            # => "localhost"
config.keys              # => [:host, :port]（键是 Symbol）
```

## 常见误区

<Callout type="trap">
**误区：在循环中用 `+` 拼接字符串**
`+` 每次创建新字符串对象，在循环中会产生大量临时对象，GC 压力大。应该用 `<<` 或 `concat` 原地追加，或者用 `Array#join`。`result = ""; items.each { |i| result << i.to_s }` 比 `result = items.map(&:to_s).reduce(:+)` 高效得多。
</Callout>

<Callout type="trap">
**误区：用 String 做哈希键而不用 Symbol**
`{ "name" => "Alice" }` 每次访问 `hash["name"]` 都可能创建新字符串（取决于 Ruby 版本优化）。用 Symbol `{ name: "Alice" }` 更高效——`:name` 始终是同一对象，哈希查找更快，内存更少。规则：键名用 Symbol，用户输入数据用 String。
</Callout>

<Exercises>
**问题 1**：以下代码输出什么？解释 `<<` 和 `+` 的区别。

```ruby
a = "hello"
b = a
a << " world"
c = a + "!"
puts a
puts b
puts c
```

<Answer>
输出：
```
hello world
hello world
hello world!
```

- `a << " world"`：`<<` 是原地追加，直接修改 `a` 指向的对象。因为 `b = a` 让 b 指向同一对象，所以 `b` 也变成了 `"hello world"`。
- `c = a + "!"`：`+` 创建新字符串，`c` 指向新对象 `"hello world!"`，`a` 不受影响。

核心区别：`<<` 修改原对象（in-place），`+` 创建新对象（returns new）。带 `!` 的方法（如 `upcase!`）同理——修改原对象。
</Answer>

**问题 2**：什么时候该用 Symbol，什么时候该用 String？

<Answer>
用 Symbol 的场景：
- 哈希键：`{ name: "Alice" }` 而非 `{ "name" => "Alice" }`
- 方法名：`send(:upcase)` 而非 `send("upcase")`
- 状态/枚举：`status = :active` 而非 `status = "active"`
- 标识符：`attr_accessor :name` 中的 `:name`

用 String 的场景：
- 用户输入：`gets.chomp` 返回 String
- 文本处理：需要 `upcase`、`gsub`、`split` 等操作
- 动态内容：拼接、插值、格式化
- 文件/网络数据：读写都是 String

核心原则：Symbol 是"名字"（固定标识符），String 是"文本"（可变内容）。如果值需要修改或来自外部，用 String；如果是固定的标识，用 Symbol。
</Answer>
</Exercises>

<GlossaryItem term="字符串插值">
双引号字符串中 `"#{expr}"` 语法，嵌入任意 Ruby 表达式。单引号不解析插值。是 Ruby 最自然的字符串拼接方式。
</GlossaryItem>
<GlossaryItem term="可变性">
Ruby 字符串可变——`<<`、`concat`、`upcase!` 等方法修改原对象。`freeze` 可冻结为不可变。Symbol 天生不可变。
</GlossaryItem>
<GlossaryItem term="Symbol">
Ruby 独有类型，以 `:name` 表示。不可变、同名唯一、内部以整数存储。适合做哈希键、方法名、枚举值。GC 友好。
</GlossaryItem>
<GlossaryItem term="bang 方法">
带 `!` 后缀的方法（如 `upcase!`、`gsub!`）通常是原地修改版本，不带 `!` 的返回新对象。这是 Ruby 的命名约定——`!` 提醒"危险"。
</GlossaryItem>
