## 直觉引入

类就像一个工厂的模具——你设计一个 `Dog` 模具，然后用它生产出一个个具体的狗（实例对象）。每个狗都有自己的名字（实例变量），但它们共享同一套行为（实例方法：叫、跑、吃）。

Ruby 的类设计简洁而强大：`initialize` 是构造函数（`new` 时自动调用），`attr_accessor` 一行代码自动生成读写方法，`<` 表示继承。没有 C++/Java 那么多模板代码——几行就能定义一个完整的类。

## 概念讲解

### 类的定义

<Term def="Ruby 类通过 class 关键字定义。initialize 是构造函数（new 时调用）。attr_accessor/attr_reader/attr_writer 自动生成属性方法。">

```ruby
class Dog
  # 自动生成 name 和 name= 方法
  attr_accessor :name, :age

  # 类常量
  SPECIES = "Canis lupus"

  # 构造函数
  def initialize(name, age)
    @name = name    # @name 是实例变量
    @age = age
  end

  # 实例方法
  def bark
    "#{@name} says Woof!"
  end

  # 类方法（self 前缀）
  def self.create_puppy(name)
    Dog.new(name, 0)  # age=0 表示幼犬
  end
end

dog = Dog.new("Rex", 3)
puts dog.bark       # => Rex says Woof!
dog.name = "Max"    # 通过 attr_accessor 生成的 name= 方法
puts dog.name       # => Max
puppy = Dog.create_puppy("Lucky")
```

`attr_accessor :name` 等价于自动生成：
```ruby
def name; @name; end       # getter
def name=(value); @name = value; end  # setter
```

</Term>

### 继承与 super

<Term def="Ruby 使用 < 表示继承，只支持单继承。子类可重写父类方法，super 调用父类同名方法。">

```ruby
class Animal
  def initialize(name)
    @name = name
  end

  def describe
    "Animal: #{@name}"
  end
end

class Dog < Animal  # Dog 继承 Animal
  def initialize(name, breed)
    super(name)      # 调用父类 initialize，传 name
    @breed = breed
  end

  def describe
    super + " (#{breed})"  # super 调用 Animal#describe
  end
end

dog = Dog.new("Rex", "Labrador")
puts dog.describe  # => Animal: Rex (Labrador)
```

`super` 的三种形式：
- `super`：传递所有参数给父类
- `super()`：不传参数
- `super(arg1, arg2)`：传指定参数

</Term>

### 访问控制

<Term def="Ruby 有三种访问控制：public（任何人可调用）、protected（同类实例可调用）、private（只能隐式 self 调用）。">

```ruby
class BankAccount
  def initialize(balance)
    @balance = balance
  end

  # public：外部可调用
  def deposit(amount)
    validate(amount)  # private 方法可在内部调用
    @balance += amount
  end

  # protected：同类实例之间可调用
  def transfer_to(other, amount)
    if other.balance >= amount  # 访问另一个实例的 protected 方法
      other.deduct(amount)
      @balance += amount
    end
  end

  protected
  def balance; @balance; end

  private
  def validate(amount)
    raise "负数" if amount < 0
  end

  def deduct(amount)
    @balance -= amount
  end
end
```

private 的关键限制：不能显式指定接收者——`self.validate(10)` 会报错，只能写 `validate(10)`。

</Term>

## 代码对照

```ruby
# === 完整的类定义 ===
class Person
  attr_reader :name, :age      # 只读（getter）
  attr_writer :email           # 只写（setter）
  attr_accessor :phone         # 读写

  @@population = 0              # 类变量

  def initialize(name, age)
    @name = name
    @age = age
    @@population += 1
  end

  # 实例方法
  def greet(other)
    "Hi #{other.name}, I'm #{@name}"
  end

  # 重写 Object#to_s
  def to_s
    "#{@name} (#{@age})"
  end

  # 类方法
  def self.population
    @@population
  end

  # private 方法
  private
  def secret_code
    @name.hash
  end
end

# === 继承 ===
class Student < Person
  attr_reader :school

  def initialize(name, age, school)
    super(name, age)    # 调用 Person#initialize
    @school = school
  end

  def greet(other)
    "Hey #{other.name}, I'm #{@name} from #{@school}"
  end

  def study
    "#{@name} is studying at #{@school}"
  end
end

# === 使用 ===
p = Person.new("Alice", 30)
s = Student.new("Bob", 20, "MIT")

puts p.greet(s)    # => Hi Bob, I'm Alice
puts s.greet(p)    # => Hey Alice, I'm Bob from MIT
puts s.study       # => Bob is studying at MIT
puts s.to_s        # => Bob (20)（继承自 Person）
puts Person.population  # => 2

# s.secret_code     # => NoMethodError（private 不可外部调用）
```

## 常见误区

<Callout type="trap">
**误区：在 initialize 中忘记调用 super**
子类的 `initialize` 不会自动调用父类的 `initialize`。如果父类在 `initialize` 中设置了关键实例变量，子类必须显式 `super()`。忘记调用会导致子类实例缺少父类的初始化状态——`@name` 可能是 `nil`，引发后续 `NoMethodError`。
</Callout>

<Callout type="trap">
**误区：混淆 private 和 protected 的语义**
Ruby 的 private 比 Java/C++ 的更严格——不能显式指定接收者，连 `self.method` 都不行。protected 的用途很窄：只在需要访问另一个实例的内部方法时用（如 `==` 实现中访问另一个对象的 `@balance`）。大多数情况下用 public 或 private 就够了，protected 很少需要。
</Callout>

<Exercises>
**问题 1**：以下代码能正确执行吗？如果不能，问题出在哪里？

```ruby
class Counter
  def initialize
    @count = 0
  end

  def increment
    @count += 1
  end

  def ==(other)
    other.count == @count
  end

  private
  def count; @count; end
end

a = Counter.new
b = Counter.new
a.increment
puts a == b
```

<Answer>
不能正确执行。`other.count` 会抛 `NoMethodError`。

问题：`count` 是 private 方法，在 `==` 中通过 `other.count` 调用——显式指定了接收者 `other`。Ruby 的 private 方法不能显式指定接收者，即使是同类实例也不行。

修复方案：将 `count` 改为 `protected`：

```ruby
class Counter
  def initialize; @count = 0; end
  def increment; @count += 1; end

  def ==(other)
    other.count == @count  # protected 允许同类实例间调用
  end

  protected               # 改为 protected
  def count; @count; end
end
```

这就是 protected 存在的意义——允许同类实例之间访问彼此的内部方法，常用于 `==`、`<=>` 等比较方法的实现。
</Answer>

**问题 2**：解释 `attr_accessor :name` 等价于什么？为什么不能直接用 `@name` 访问实例变量？

<Answer>
`attr_accessor :name` 等价于自动生成两个方法：

```ruby
def name        # getter
  @name
end

def name=(value)  # setter
  @name = value
end
```

不能直接从外部访问 `@name` 的原因：
- `@name` 是实例变量，Ruby 的实例变量默认是"封装"的——外部无法直接读写
- 必须通过方法（getter/setter）间接访问——这是封装的体现
- `attr_accessor` 就是为了省去手写 getter/setter 的样板代码

对比其他语言：
- Java：需要手写 `getName()`/`setName()`，或用 IDE 生成
- Python：可以直接 `obj.name`（无封装），或用 `@property`
- Ruby：用 `attr_accessor` 自动生成方法，既有封装又有简洁

子类可以重写 getter 来添加逻辑：
```ruby
class Person
  attr_writer :name

  def name         # 重写 getter，不用 attr_reader
    @name&.upcase  # 访问时自动大写
  end
end
```

这就是 Ruby 的设计：实例变量永远私有，通过方法控制访问。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="initialize">
Ruby 的构造函数方法。`Class.new(args)` 创建对象时自动调用，初始化实例变量。与 Java/C++ 的 constructor 作用相同，但 Ruby 中 new 是类方法，initialize 是实例方法。
</GlossaryItem>
<GlossaryItem term="attr_accessor">
自动生成 getter 和 setter 方法的宏。`attr_accessor :name` 生成 `name` 和 `name=`。`attr_reader` 只生成 getter，`attr_writer` 只生成 setter。
</GlossaryItem>
<GlossaryItem term="super">
在子类方法中调用父类同名方法。`super` 传所有参数，`super()` 不传参数，`super(a, b)` 传指定参数。用于扩展父类行为而非完全重写。
</GlossaryItem>
<GlossaryItem term="private">
Ruby 最严格的访问控制——private 方法只能隐式 self 调用，不能显式指定接收者。protected 允许同类实例间调用，public 对外完全开放。
</GlossaryItem>
</Glossary>
