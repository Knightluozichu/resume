## 直觉引入

Rust 的内存管理就像一套严格的「产权登记」制度：每件物品（值）只能有一个所有者，所有者搬走时物品跟着走（move），所有者离开时物品被销毁（drop）。想借用？可以，但必须遵守借用规则。这套制度让 Rust 在没有垃圾回收器的情况下保证内存安全——全在编译期完成，运行时零开销。

## 概念讲解

### 所有权三规则

<Term def="每个值有唯一所有者；所有者离开作用域值被 drop；赋值或传参时所有权转移（move）。">
Rust 所有权系统的三条规则：

1. **每个值在任意时刻有且仅有一个所有者**（owner）
2. **当所有者离开作用域，值被 drop**（自动释放）
3. **赋值或传参时所有权转移（move）**，原变量失效

这三条规则让 Rust 在编译期保证内存安全——无 use-after-free、无 double-free、无悬空指针。无需垃圾回收器，运行时零开销。

所有后续内容（借用、生命周期、trait、并发）都建立在这三条规则之上。不理解所有权就无法写任何 Rust 代码。
</Term>

### 学习路径

<Term def="四大板块按因果链组织：基础语法→类型系统→高级特性→并发与异步。">
本书四大板块：

1. **基础语法**（第 0-1 章）：所有权系统是 Rust 一切的基础
2. **类型系统**（第 2-3 章）：借用和生命周期建立在所有权之上
3. **高级特性**（第 4-6 章）：trait、错误处理、泛型是类型系统的高级应用
4. **并发与异步**（第 7-9 章）：Send/Sync 标记依赖所有权，async 状态机依赖生命周期

每个板块建立在前一个之上，形成因果链：不理解 move 就无法理解借用为什么需要规则；不理解生命周期就无法定义正确的 trait bound；不理解所有权就无法理解为什么 Arc<Mutex<T>> 是线程安全的共享可变状态。
</Term>

## 代码对照

```rust
// 所有权三规则演示
fn main() {
    // 规则1: 每个值有唯一所有者
    let s1 = String::from("hello");

    // 规则3: 赋值时 move，s1 失效
    let s2 = s1;
    // println!("{}", s1); // 编译错误: borrow of moved value

    // 传参也 move
    takes_ownership(s2); // s2 的所有权转移到函数
    // println!("{}", s2); // 编译错误: s2 已 move

    // 规则2: 离开作用域自动 drop
    let s3 = String::from("world");
} // s3 离开作用域，drop 被调用，内存释放

fn takes_ownership(s: String) {
    println!("{}", s);
} // s 离开作用域，drop 被调用
```

## 常见误区

<Callout type="trap">
**误区：Rust 的所有权系统只是语法限制**
所有权系统不是限制而是保障。它让 Rust 在编译期消除整类内存错误（use-after-free、double-free、数据竞争），运行时零开销。C/C++ 需要开发者手动保证这些，GC 语言需要运行时开销。所有权是 Rust 独特优势的根源。
</Callout>

<Callout type="trap">
**误区：不理解所有权也能写 Rust**
所有权不是可选知识点。函数传参、集合存储、闭包捕获——所有代码都受所有权约束。不理解 move 语义，连基本的函数调用都会编译失败。必须先掌握所有权才能进入后续内容。
</Callout>

<Exercises>
**问题 1**：Rust 相比 C/C++ 和 GC 语言在内存管理上有什么独特优势？

<Answer>
相比 C/C++：编译期保证内存安全（无 use-after-free、double-free、悬空指针），所有权自动决定释放时机。相比 GC 语言：无运行时 GC 停顿，确定性释放（离开作用域即 drop），零运行时开销。独特优势：编译期内存安全+确定性释放+零运行时开销。
</Answer>

**问题 2**：为什么说所有权是 Rust 一切的基础？

<Answer>
所有权三规则约束所有代码：函数传参 move 使原变量失效，需理解借用才能解决；集合存储转移所有权到集合；闭包捕获变量可能已 drop 需理解 move 闭包。借用规则、生命周期、trait bound、Send/Sync 都建立在所有权之上。不理解所有权连基本代码都无法编译。
</Answer>

</Exercises>

<Glossary>
<GlossaryItem term="所有权（Ownership）">
Rust 内存管理的核心：每个值有唯一所有者，离开作用域自动 drop，赋值/传参时 move。
</GlossaryItem>
<GlossaryItem term="move 语义">
赋值或传参时所有权转移，原变量失效。避免 double-free，栈上指针复制不复制堆数据。
</GlossaryItem>
<GlossaryItem term="drop">
所有者离开作用域时自动调用的释放方法，释放堆内存和资源。无需手动 free。
</GlossaryItem>
<GlossaryItem term="零成本抽象">
Rust 的设计原则：编译期完成的安全检查在运行时零开销。所有权系统是零成本抽象的典范。
</GlossaryItem>
