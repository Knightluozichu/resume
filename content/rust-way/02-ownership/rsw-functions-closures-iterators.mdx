## 从一段行为是否携带环境开始

函数、闭包和迭代器都能封装计算，但表示与owner不同。命名函数项不捕获环境，函数指针保存代码地址；闭包是编译器生成的匿名类型，字段保存捕获值；迭代器则保存“下一步计算到哪里”的状态。让高阶API不再只是“把函数传进去”。

先预测：闭包读取外部String但不修改时通常可实现Fn；若把String move出闭包，至少只能按FnOnce调用。


## 函数与高阶函数

函数签名定义参数、返回、泛型和ABI；函数项是零大小的具体类型，可转换为`fn`指针。高阶函数接收或返回可调用值。必须声明调用次数、是否并发、是否允许修改环境以及返回值寿命。

```rust
fn apply_twice<T>(mut value: T, mut operation: impl FnMut(T) -> T) -> T {
    value = operation(value);
    operation(value)
}

assert_eq!(apply_twice(3, |n| n + 2), 7);
```

## 闭包实现与捕获所有权

闭包按需要以共享引用、独占引用或move捕获环境。`move`强制闭包取得捕获表达式的值，但Copy值仍复制；它不自动使闭包满足`'static`，捕获值内部仍可能带短引用。决定闭包是否能离开当前scope、发送到线程或重复调用。

```rust
let prefix = String::from("id-");
let render = move |number: u32| format!("{prefix}{number}");
assert_eq!(render(7), "id-7");
assert_eq!(render(8), "id-8");
```

## Fn、FnMut与FnOnce

所有闭包至少实现FnOnce，因为调用可能消费self；不移出捕获值的闭包还可实现FnMut；不修改捕获环境的闭包还可实现Fn。是包含关系，不是三种互斥语法。


## 闭包作为参数、返回值与HRTB

参数常用`impl Fn...`或泛型以静态分派；异构存储使用`Box<dyn Fn...>`。返回`impl Fn`隐藏一个具体闭包类型。若回调必须接受任意足够短的借用，可使用`for<'a>`高阶生命周期约束。常见于接受临时引用的回调边界。

## Iterator与IntoIterator

Iterator核心是关联类型Item和`next`；IntoIterator把集合、共享引用或独占引用转换为iterator。`for`循环会调用IntoIterator，因此`for x in values`、`&values`与`&mut values`表达消费、只读借用和独占借用三种owner动作。是阅读循环的第一步。

```rust
struct Countdown(u8);

impl Iterator for Countdown {
    type Item = u8;
    fn next(&mut self) -> Option<Self::Item> {
        if self.0 == 0 { None } else { self.0 -= 1; Some(self.0 + 1) }
    }
}

assert_eq!(Countdown(3).collect::<Vec<_>>(), vec![3, 2, 1]);
```

## 适配器、消费者与惰性

`map`、`filter`、`take`等适配器返回新的iterator并保持惰性；`collect`、`fold`、`sum`、`find`等消费者驱动`next`。允许融合多步计算，不表示所有链都无分配或自动并行。
