## 从“谁负责释放”开始

所有权系统把值的释放责任、可用绑定和引用许可组合成编译期状态机。每个非Copy值有一个逻辑owner；move转移责任，Drop在owner离开scope时运行。比“变量不能用两次”更接近真实规则。

先预测：把String传给按值参数后，调用者还能否使用？不能，除非函数返回它、参数改为引用或调用者显式clone。

```rust
fn length(text: &str) -> usize { text.len() }

let text = String::from("ownership");
assert_eq!(length(&text), 9);
assert_eq!(text.len(), 9);
```

## 绑定、作用域与移动

绑定是名字与值的词法关系，scope决定绑定可见和自动清理位置。Copy类型赋值产生独立副本；非Copy类型赋值通常move。不会调用用户可见复制，也不会让旧位置保持“空对象”。

## 借用：共享读取与独占修改

`&T`共享借用允许多个reader，`&mut T`独占借用允许一个writer，二者有效期重叠时互斥。防止迭代器引用在Vec扩容后继续使用，也让数据竞争在safe代码中难以表达。

```rust
fn append_tag(values: &mut Vec<String>, tag: &str) {
    for value in values {
        value.push_str(tag);
    }
}

let mut values = vec!["a".to_owned(), "b".to_owned()];
append_tag(&mut values, "!");
```


## 生命周期参数、省略与约束

生命周期标注描述多个引用有效区间的关系，不延长数据寿命，也不在运行期计时。输入引用各有参数；单输入引用可决定输出；方法中self引用常决定输出，这些省略规则只隐藏常见关系。在多个候选输入、结构体持引用和返回闭包时需要显式表达。

```rust
fn longest<'a>(left: &'a str, right: &'a str) -> &'a str {
    if left.len() >= right.len() { left } else { right }
}
```

Trait object省略生命周期有独立默认规则；公开API应在关系不明显时显式写出。`'static`引用意味着数据可活到程序结束，`T: 'static`则表示T不含短寿命借用，不等于T值永不释放。


## Rc与Weak：单线程共享所有权

Rc强计数大于零时保持值，clone只增加计数；Weak不拥有值，upgrade返回Option。树和图通常用强边表达owner，用弱边表达父指针、缓存观察者或回链。能主动避免引用环。

## Cell、RefCell与内部可变性

Cell适合Copy值替换或take，不提供内部引用；RefCell把共享/独占借用检查移到运行期，违规会panic。适合单线程缓存、测试记录器和图结构，不是逃避所有权设计的通用开关。

## Cow、NLL与并发安全

Cow可持有borrowed或owned数据，只读路径不复制，`to_mut`在需要写时克隆。NLL根据引用最后使用位置结束借用，而非机械等到花括号；它放宽合法程序，却不改变一写多读规则。跨线程共享通常从Rc/RefCell切换到Arc/Mutex等Send与Sync组合，编译器检查类型能否安全移动或共享。
