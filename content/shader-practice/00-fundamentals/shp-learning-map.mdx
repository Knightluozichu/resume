## 直觉引入

Shader 开发就像学做菜——先认识厨房布局（渲染管线），再学刀工和火候（HLSL 语法），然后从切菜（顶点着色器）到调味（像素着色器），逐步掌握煎炒烹炸（光照、后处理、高级特效），最后学会控制成本（性能优化）。每一步都配实战代码，不是纸上谈兵。

## 概念讲解

全书分四大板块：**基础**（学习地图、渲染管线）、**核心**（HLSL 基础、顶点着色器、像素着色器、光照着色器）、**高级**（后处理、性能优化、高级特效）、**复习**（总复习）。

### 学习主线
从渲染管线整体认知出发，掌握 HLSL 语法后逐阶段实现顶点和像素着色器，叠加光照，进入后处理，最后做性能优化和高级特效。每个阶段配实战代码，由浅入深。

## 代码对照

```hlsl
// 第一个 HLSL 着色器核心结构
cbuffer Constants : register(b0) {
    float4x4 WorldViewProj;
};

struct VSInput {
    float3 Position : POSITION;
    float2 TexCoord : TEXCOORD0;
};

struct VSOutput {
    float4 Position : SV_POSITION;
    float2 TexCoord : TEXCOORD0;
};

VSOutput VSMain(VSInput input) {
    VSOutput output;
    output.Position = mul(WorldViewProj, float4(input.Position, 1.0));
    output.TexCoord = input.TexCoord;
    return output;
}
```

## 常见误区

<Callout type="trap">
**现象 →** 跳过渲染管线直接写 Shader。
**原因 →** 觉得管线理论太枯燥，想直接上手写代码。
**修法 →** 管线是 Shader 的骨架。不理解顶点和像素着色器在管线中的位置，就无法理解数据从哪来、到哪去。先通读管线章节再写代码。
</Callout>

<Callout type="trap">
**现象 →** 只学语法不做实战项目。
**原因 →** 觉得理解了 HLSL 语法就够了。
**修法 →** Shader 是工程技能。每个语法点都要配实战代码验证。从第一个顶点着色器开始逐步增加功能：变换→纹理→光照→后处理。
</Callout>
