## 直觉引入

HLSL 就像 Shader 世界的普通话——不管你用什么引擎（Unity/Unreal/自研），GPU 着色器最终都讲这门语言。数据类型是词汇，语义是语法角色（主语宾语），内置函数是常用短语，cbuffer 是笔记本。掌握这三样就能写出基本的着色器。

## 概念讲解

<Term def="float/half/int 标量 + floatN 向量 + floatNxN 矩阵">数据类型</Term><Term def="POSITION/NORMAL/SV_POSITION 等阶段间数据标签">语义</Term><Term def="mul/dot/cross/lerp/normalize 等内置数学函数">内置函数</Term><Term def="从 CPU 传递到 GPU 的常量数据块">Constant Buffer</Term>

### 三大基石
1. 数据类型：float4 和 float4x4 最常用，half 用于低精度优化
2. 语义：POSITION 是输入语义，SV_POSITION 是输出语义，SV_TARGET 是像素着色器输出
3. 内置函数：mul 做矩阵乘法，dot/cross 做向量运算，lerp 做插值，normalize 做归一化

### mul 函数的参数顺序
mul(M, v) 是行主序矩阵乘列向量，mul(v, M) 是行向量乘矩阵。参数顺序决定存储约定，顺序错误会导致变换结果完全错误。

## 代码对照

```hlsl
// Constant Buffer — 注意对齐
cbuffer Constants : register(b0) {
    float4x4 World;        // 16 字节对齐
    float4x4 ViewProj;     // 16 字节对齐
    float3   LightDir;     // 需补齐为 float4
    float    Time;         // 填充到同一 16 字节槽
};

// 顶点着色器
struct VSInput {
    float3 Position : POSITION;
    float3 Normal   : NORMAL;
    float2 TexCoord : TEXCOORD0;
};

VSOutput VSMain(VSInput input) {
    VSOutput output;
    float4 worldPos = mul(World, float4(input.Position, 1.0));
    output.Position = mul(ViewProj, worldPos);
    output.Normal = normalize(mul((float3x3)World, input.Normal));
    output.TexCoord = input.TexCoord;
    return output;
}
```

cbuffer 中 float3 后面紧跟 float 刚好凑满 16 字节。mul 的参数顺序要与 C++ 侧矩阵存储约定一致。

## 常见误区

<Callout type="trap">
**现象 →** cbuffer 中成员顺序随意排列导致数据错位。
**原因 →** 不了解 HLSL 的 packing rule。
**修法 →** cbuffer 中每个 float4 占 16 字节边界。float3 虽然只用 12 字节但也会占满 16 字节槽。按从大到小排列（float4x4 在前），避免浪费空间。
</Callout>

<Callout type="trap">
**现象 →** mul 函数参数顺序写反导致模型变形。
**原因 →** 混淆了行主序和列主序。
**修法 →** HLSL 默认行主序。mul(World, pos) 是矩阵乘列向量。如果 C++ 侧用列主序存储（如 OpenGL 习惯），需要 transpose 或改用 mul(pos, World)。
</Callout>

## 练习

<Exercises>
**问题**：HLSL 中 mul 函数的参数顺序为什么重要？

<Answer>
mul(matrix, vector) 表示行主序矩阵乘列向量，mul(vector, matrix) 表示行向量乘矩阵。参数顺序决定了矩阵的存储约定，顺序错误会导致变换结果完全错误。
</Answer>

**问题**：如何在 HLSL 中正确使用 Constant Buffer？

<Answer>
1)cbuffer 中按从大到小排列成员 2)注意 packing rule：每个 float4 占 16 字节边界 3)C++ 侧结构体需匹配对齐规则 4)使用 alignas(16) 或手动填充 5)避免在 cbuffer 中放动态长度数组。
</Answer>
</Exercises>
