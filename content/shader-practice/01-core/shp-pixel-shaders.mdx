## 直觉引入

像素着色器就像画师的画笔——画布上的每个像素点都经过它的手。它接收光栅化插值后的属性（UV 坐标、法线、颜色），在纹理上调色，和光照混合，最终决定这个像素点画什么颜色。因为画布有数百万个点，所以它执行次数最多，优化也最重要。

## 概念讲解

<Term def="光栅化后逐片段执行的着色器">像素着色器</Term><Term def="从纹理图像中根据 UV 坐标获取颜色的操作">纹理采样</Term><Term def="丢弃不满足条件的像素的指令">clip</Term><Term def="用 lerp 函数在两个颜色间做线性插值">渐变色</Term>

### 输入输出
输入：光栅化插值后的顶点属性（UV、法线、颜色）和系统值（SV_Position）。输出：最终颜色 SV_TARGET。每个像素执行一次。

### 纹理采样
声明 Texture2D 和 SamplerState，用 .Sample(sampler, uv) 方法采样，返回 float4 颜色值。采样器控制过滤模式（点/线性）和寻址模式（重复/钳制）。

### clip 指令
clip(x) 在 x<0 时丢弃当前像素，常用于 alpha test。注意使用 clip 后该像素不写深度缓冲，过度使用会降低 GPU 早期剔除效率。

## 代码对照

```hlsl
// 像素着色器 — 纹理采样 + alpha test
Texture2D DiffuseTexture : register(t0);
SamplerState Sampler : register(s0);

float4 PSMain(VSOutput input) : SV_TARGET {
    float4 texColor = DiffuseTexture.Sample(Sampler, input.TexCoord);
    // alpha test: 丢弃半透明像素
    clip(texColor.a - 0.5);
    return texColor;
}

// 渐变色效果
float4 PSMainGradient(VSOutput input) : SV_TARGET {
    float3 colorA = float3(1.0, 0.3, 0.2); // 红
    float3 colorB = float3(0.2, 0.5, 1.0); // 蓝
    float t = input.TexCoord.y;
    float3 gradient = lerp(colorA, colorB, t);
    return float4(gradient, 1.0);
}

// 多色渐变
float4 PSMainMultiGradient(VSOutput input) : SV_TARGET {
    float t = input.TexCoord.y;
    float3 color;
    if (t < 0.33)
        color = lerp(float3(1,0,0), float3(0,1,0), t / 0.33);
    else if (t < 0.66)
        color = lerp(float3(0,1,0), float3(0,0,1), (t-0.33)/0.33);
    else
        color = lerp(float3(0,0,1), float3(1,0,1), (t-0.66)/0.34);
    return float4(color, 1.0);
}
```

纹理采样是像素着色器最核心的操作。clip 用于硬边缘透明裁剪，lerp 用于颜色插值。

## 常见误区

<Callout type="trap">
**现象 →** 用 clip 做半透明效果导致性能下降。
**原因 →** clip 会破坏 GPU 的早期深度测试优化。
**修法 →** clip 仅用于需要硬边缘的 alpha test（如树叶、铁丝网）。半透明效果应使用混合（Blend），不要用 clip 逐像素丢弃。
</Callout>

<Callout type="trap">
**现象 →** 在像素着色器中做过多纹理采样导致帧率下降。
**原因 →** 每次采样都消耗带宽，尤其依赖纹理读取会破坏缓存。
**修法 →** 合并纹理（图集/通道打包），减少采样次数。避免用前一次采样的结果作为下一次采样的坐标（依赖纹理读取），这会导致缓存失效。
</Callout>

<Answer>

<Answer>
clip(x) 在 x<0 时丢弃当前像素，常用于 alpha test 透明裁剪。注意事项：1)使用 clip 后该像素不写深度缓冲 2)过度使用 clip 会导致 GPU 过早剔除失效反而降低性能 3)仅在需要硬边缘透明时使用。
