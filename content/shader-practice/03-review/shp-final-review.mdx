### 完整工作流程
1)分析效果需求确定管线阶段 2)编写 HLSL 着色器代码 3)配置输入布局和常量缓冲 4)编译验证 5)在引擎中集成测试 6)性能优化 7)效果调参迭代

### 数据流
模型空间 → MVP → 裁剪空间 → 透视除法 → NDC → 视口变换 → 屏幕坐标 → 光栅化插值 → 像素着色器 → 颜色输出 → 后处理 → 帧缓冲 → 显示

### 优化链
定位瓶颈（Profiler） → 减少计算（低精度/去分支） → 减少采样（Mipmap/合并纹理） → 减少寄存器（简化/控制展开） → 验证效果

## 代码对照

```hlsl
// 综合示例：带光照的水面着色器核心结构

// 顶点着色器 — Gerstner 波位移
VSOutput VSMain(VSInput input) {
    VSOutput output;
    float3 pos = input.Position;
    // Gerstner 波位移
    float waveHeight = sin(pos.x * 2.0 + Time) * 0.1;
    pos.y += waveHeight;
    output.Position = mul(ViewProj, mul(World, float4(pos, 1.0)));
    output.Normal = normalize(float3(-cos(pos.x * 2.0 + Time) * 0.2, 1.0, 0));
    output.TexCoord = input.TexCoord + Time * 0.01; // 流动 UV
    output.WorldPos = mul(World, float4(pos, 1.0)).rgb;
    return output;
}

// 像素着色器 — Fresnel + 光照 + 噪声
float4 PSMain(VSOutput input) : SV_TARGET {
    float3 N = normalize(input.Normal);
    float3 V = normalize(ViewPos - input.WorldPos);
    float3 L = normalize(LightDir);
    // Fresnel
    float fresnel = pow(1.0 - max(dot(N, V), 0.0), 5.0);
    // Blinn-Phong 光照
    float3 H = normalize(L + V);
    float diff = max(dot(N, L), 0.0);
    float spec = pow(max(dot(N, H), 0.0), 64.0);
    // 混合反射/折射
    float3 refraction = deepColor * diff;
    float3 reflection = skyColor * spec;
    float3 color = lerp(refraction, reflection, fresnel);
    return float4(color, 1.0);
}
```

综合方案将顶点位移、Fresnel 混合、Blinn-Phong 光照、流动 UV 等技术组合，再叠加后处理 Bloom 和色调映射。

## 常见误区

<Callout type="trap">
**现象 →** 综合项目中各模块各自正确但整体效果不对。
**原因 →** 各模块之间数据传递不一致。
**修法 →** 确保顶点着色器输出的法线在世界空间且已归一化，像素着色器中再次归一化。UV 流动方向要与法线扰动一致。后处理的 HDR 值范围要与色调映射曲线匹配。
</Callout>

<Callout type="trap">
**现象 →** 最终效果性能很差无法实时运行。
**原因 →** 高级特效叠加后计算量过大。
**修法 →** 分级降质：SSR 降分辨率、体积雾减步进数、噪声预烘焙。先用低质量版本验证效果正确性，再逐步提升质量。Profiler 定位最贵的 Pass 优先优化。
</Callout>
