## 先预测，再核定系列身份

先预测：把ShaderX概括成“顶点、像素、光照、阴影”四个主题，会漏掉多少引擎、图像、体积、移动和GPGPU文章？答案是旧10页无法证明任何一册的完整性。官方与授权来源显示，ShaderX 2因稿件规模被编辑拆成<Term def="ShaderX 2的入门教程册与技巧集是两本独立物理书。">两册</Term>，因此系列是7个编号、8册物理卷。本文以<Term def="卷号、物理书名、篇名和来源URL共同构成不可混淆的身份。">篇章身份</Term>、<Term def="每篇官方文章只在一个主题拥有主归属。">唯一归属</Term>、<Term def="把旧API载体与算法保持的关系分开记录。">历史不变量</Term>和<Term def="同时验证正确性、兼容、性能与失败路径。">复现证书</Term>重建范围。

## 历史技术的现代化原则

```text
article identity -> historical hardware/API assumptions
assumptions -> mathematical and data-flow invariant
invariant -> CPU/offline reference + modern GPU path
modern path -> capture + diff + target-device metrics
```

旧式shader assembly、ps_1_x、DirectX 9 effect和早期OpenGL ES可以不再直接使用，但它们解决的带宽、采样、可见性、并行和状态管理问题仍需被准确复现。若现代硬件已有原生功能，页面要解释替代关系，而不是伪装成逐行移植。

```hlsl
float4 HistoricalInvariantProbe(float4 inputValue) : SV_Target {
    return EvaluateModernEquivalent(inputValue);
}
```

## 练习

<Exercises>
**问题1：为何系列编号是7，物理卷却是8？**
<Answer>ShaderX 2被编辑拆成Introductions and Tutorials与Shader Programming Tips and Tricks两册，因此编号2对应两本物理书。</Answer>

**问题2：怎样证明329篇没有重复归属？**
<Answer>为每篇使用卷ID和篇名组成唯一键，16个主题只允许一个主归属；清单总数、唯一键数和主题计数之和都必须等于329。</Answer>

**问题3：旧API不能运行时如何复现？**
<Answer>保留文章问题、数学或数据流不变量和边界，用CPU或离线参考建立基线，再实现现代GPU等价或受控近似并记录差异。</Answer>
</Exercises>
