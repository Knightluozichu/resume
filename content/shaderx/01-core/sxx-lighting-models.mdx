## 直觉引入

想象一束光照在桌面上。如果桌面光滑（镜子），光沿一个方向反射——这是镜面反射；如果桌面粗糙（木头），光向四面八方散射——这是漫反射。Phong 模型用简单的数学近似这两种效果，但真实世界的材质更复杂——金属和塑料的反射方式完全不同。<Term def="BRDF（双向反射分布函数）描述光线从入射方向到出射方向的反射比例">BRDF</Term> 就是描述这种反射行为的数学函数。

关键洞察：光照模型从「看起来对」到「物理正确」的演进，核心是 BRDF。Phong 是经验模型，Blinn-Phong 改进了高光，而 Cook-Torrance 基于微平面理论，用能量守恒和菲涅尔效应实现物理真实的金属/非金属反射。

## 概念讲解

### 光照模型演进

光照模型的发展路径：

- <Term def="Phong 模型用反射向量和视线向量的点积计算镜面高光">Phong 模型</Term>：specular = pow(max(R·V, 0), shininess)

- <Term def="Cook-Torrance 模型基于微平面理论的物理光照模型，包含菲涅尔、法线分布和几何遮蔽">Cook-Torrance</Term>：f = DFG / (4(N·L)(N·V))

## 交互Demo

<Stepper>
<Step title="第一步：理解 Phong 与 Blinn-Phong">Phong 用反射向量 R 计算高光，Blinn-Phong 用半角向量 H = normalize(L+V)。Blinn-Phong 的优势：高光更柔和自然，且避免了反射向量的计算（更快），是实时渲染的工业标准。</Step>
<Step title="第二步：微平面理论">
Cook-Torrance 的核心是微平面理论：表面由无数微小镜面组成。D 项描述微面法线分布（有多少微面对齐到半角向量），F 项是菲涅尔效应（掠射角反射增强），G 项是几何遮蔽（微面间的互相遮挡）。
<SxxLightingModelsDiagram />
</Step>
<Step title="第三步：金属与非金属">PBR 的关键区分：金属只有镜面反射（无漫反射），颜色来自反射率；非金属有漫反射（颜色来自反照率），镜面反射是无色的。用 metallic 参数在两者间插值，用 roughness 控制表面粗糙度。</Step>
</Stepper>

## 代码对照

```hlsl
// Cook-Torrance BRDF 实现
struct PSInput {
    float3 worldPos : POSITION;
    float3 normal   : NORMAL;
};

cbuffer LightCB : register(b0) {
    float3 lightDir;
    float3 lightColor;
    float3 viewPos;
};

// GGX 法线分布函数 (Trowbridge-Reitz)
float D_GGX(float3 N, float3 H, float roughness) {
    float a = roughness * roughness;
    float a2 = a * a;
    float NdotH = max(dot(N, H), 0.0);
    float NdotH2 = NdotH * NdotH;
    float denom = NdotH2 * (a2 - 1.0) + 1.0;
    return a2 / (3.14159265 * denom * denom);
}

// Schlick 菲涅尔近似
float3 F_Schlick(float cosTheta, float3 F0) {
    return F0 + (1.0 - F0) * pow(1.0 - cosTheta, 5.0);
}

// Smith 几何遮蔽
float G_Smith(float3 N, float3 V, float3 L, float roughness) {
    float k = (roughness + 1.0) * (roughness + 1.0) / 8.0;
    float NdotV = max(dot(N, V), 0.0);
    float NdotL = max(dot(N, L), 0.0);
    float gv = NdotV / (NdotV * (1.0 - k) + k);
    float gl = NdotL / (NdotL * (1.0 - k) + k);
    return gv * gl;
}

float3 CookTorranceBRDF(PSInput input, float3 albedo, float metallic, float roughness) {
    float3 N = normalize(input.normal);
    float3 V = normalize(viewPos - input.worldPos);
    float3 L = normalize(-lightDir);
    float3 H = normalize(L + V);
    
    float3 F0 = lerp(float3(0.04, 0.04, 0.04), albedo, metallic);
    
    float D = D_GGX(N, H, roughness);
    float3 F = F_Schlick(max(dot(H, V), 0.0), F0);
    float G = G_Smith(N, V, L, roughness);
    
    float3 specular = (D * F * G) / (4.0 * max(dot(N, V), 0.0) * max(dot(N, L), 0.0) + 0.001);
    float3 kD = (1.0 - F) * (1.0 - metallic);
    float3 diffuse = kD * albedo / 3.14159265;
    
    return (diffuse + specular) * lightColor * max(dot(N, L), 0.0);
}
```

## 常见误区

<Callout type="trap">
**误区：认为 Phong 和 Blinn-Phong 只是性能差异。**
两者的高光外观不同：Phong 的反射向量 R 在掠射角会产生「拉伸」的高光，看起来不自然；Blinn-Phong 的半角向量 H 产生更圆的高光，视觉上更接近真实。选择 Blinn-Phong 不只是因为快，更是因为效果更好。注意两者的 shininess 参数含义不同，Blinn-Phong 的 shininess 通常是 Phong 的 2-4 倍才能匹配类似效果。
</Callout>

<Callout type="trap">
**误区：PBR 中 metallic 和 roughness 可以随意取值。**
metallic 应该是 0 或 1（非金属或金属），中间值在物理上没有意义（没有「半金属」材质），只在艺术过渡时使用。roughness 的范围是 0-1，但 0 会产生无穷大的高光（除零问题），实际使用应限制最小值（如 0.05）。错误的参数组合会导致光照不自然，如金属材质出现彩色漫反射。
</Callout>

## 练习

<Exercises>
**问题 1**：对比 Phong 和 Blinn-Phong 模型的公式差异和视觉效果差异。

<Answer>
公式差异：Phong 的镜面项用反射向量 R = reflect(-L, N)，specular = pow(max(R·V, 0), shininess)；Blinn-Phong 用半角向量 H = normalize(L+V)，specular = pow(max(N·H, 0), shininess)。视觉效果差异：Phong 在掠射角产生拉长的椭圆形高光，不够自然；Blinn-Phong 的高光更圆、更柔和，更接近真实材质。性能上 Blinn-Phong 避免了 reflect 计算，略快。注意匹配相同视觉效果时，Blinn-Phong 的 shininess 约为 Phong 的 2-4 倍。工业实践中 Blinn-Phong 是主流选择。
</Answer>

**问题 2**：Cook-Torrance BRDF 中的 D、F、G 三项分别代表什么物理意义？

<Answer>
D（法线分布函数 Normal Distribution Function）：描述微平面的法线分布——有多少微面的法线对齐到半角向量 H。常用 GGX/Trowbridge-Reitz 模型，roughness 越大分布越广（高光越模糊）。F（菲涅尔项 Fresnel）：描述反射率随视角变化——掠射角（90度）时几乎所有光都被反射，正视角时反射率取决于材质（金属高、非金属低）。常用 Schlick 近似，F0 是正视角反射率。G（几何遮蔽/阴影项 Geometry）：描述微平面间的互相遮挡——入射光或反射光被相邻微面遮挡的比例。roughness 越大遮挡越严重。三项乘积 DFG 除以归一化因子 4(N·L)(N·V) 构成物理正确的镜面反射 BRDF。
</Answer>
</Exercises>

<GlossaryItem term="BRDF">双向反射分布函数，描述光线从入射方向到出射方向的反射比例，是物理光照模型的基础。</GlossaryItem>
<GlossaryItem term="微平面理论">假设粗糙表面由无数微小镜面组成，用统计分布函数描述整体反射行为的理论模型。</GlossaryItem>
<GlossaryItem term="菲涅尔效应">反射率随观察角度变化的物理现象——掠射角时反射率趋近100%，正视角时取决于材质。</GlossaryItem>
<GlossaryItem term="Cook-Torrance 模型">基于微平面理论的物理光照模型，包含法线分布(D)、菲涅尔(F)和几何遮蔽(G)三项。</GlossaryItem>
