## 直觉引入

想象你在暗室里用手电筒照一个杯子，杯子在桌上投下影子。阴影的本质是：光线被遮挡的区域。在 GPU 上实现阴影，最直觉的方法是「站在光源的位置看场景」——能看到的地方有光，看不到的地方就是阴影。这就是阴影映射的核心思想。

关键洞察：阴影映射是两趟渲染技术。第一趟从光源视角渲染深度图（Shadow Map），第二趟在相机视角渲染时比较像素深度与 Shadow Map 的深度——如果像素比 Shadow Map 更远，说明被遮挡，处于阴影中。

## 交互Demo

<Stepper>
<Step title="第一步：理解阴影映射两趟渲染">第一趟：从光源视角渲染场景，只记录深度到 Shadow Map（一张灰度图，存储最近距离）。第二趟：在相机视角渲染时，将每个像素变换到光源空间，比较其深度与 Shadow Map 中的深度。如果像素深度 > Shadow Map 深度，说明被遮挡，标记为阴影。</Step>
<Step title="第二步：PCF 软阴影">
硬阴影边缘锯齿明显。PCF 对 Shadow Map 做 N×N 次采样，每次独立比较深度，最后平均结果（如 3x3 = 9 次比较，0/9 到 9/9 形成渐变）。采样核越大阴影越柔和，但性能开销越高。
<SxxShadowTechniquesDiagram />
</Step>
<Step title="第三步：阴影偏移">深度比较存在精度问题，会产生「阴影痤疮」（表面出现条纹状自阴影）。解决方案是加偏移（bias）：比较时将像素深度减去一个小的 bias 值。bias 太小痤疮不消失，太大会产生「彼得潘宁」（阴影与物体脱离）。</Step>
</Stepper>

## 代码对照

```hlsl
// PCF 软阴影实现
Texture2D shadowMap : register(t0);
SamplerComparisonState shadowSampler : register(s0);

cbuffer ShadowCB : register(b1) {
    float4x4 lightViewProj;
    float3 lightDir;
    float shadowBias;
    float2 shadowMapSize;
};

float PCF_Shadow(float3 worldPos, float3 normal) {
    // 变换到光源裁剪空间
    float4 lightSpacePos = mul(lightViewProj, float4(worldPos, 1.0));
    float3 projCoords = lightSpacePos.xyz / lightSpacePos.w;
    projCoords.xy = projCoords.xy * 0.5 + 0.5; // NDC -> UV
    projCoords.y = 1.0 - projCoords.y; // 翻转Y
    
    // 斜率偏移：面与光线越平行偏移越大
    float slopeBias = shadowBias * (1.0 - max(dot(normal, lightDir), 0.0));
    float currentDepth = projCoords.z - slopeBias;
    
    // 3x3 PCF
    float shadow = 0.0;
    float2 texelSize = 1.0 / shadowMapSize;
    
    [unroll] for (int x = -1; x <= 1; x++) {
        [unroll] for (int y = -1; y <= 1; y++) {
            float2 offset = float2(x, y) * texelSize;
            shadow += shadowMap.SampleCmp(shadowSampler, projCoords.xy + offset, currentDepth);
        }
    }
    shadow /= 9.0;
    
    // 超出阴影图范围无阴影
    if (projCoords.z > 1.0) shadow = 1.0;
    
    return shadow;
}
```

## 常见误区

<Callout type="trap">
**误区：用固定偏移解决所有阴影痤疮。**
阴影痤疮的根本原因是深度精度不足，且表面与光线角度越平行越严重（斜率大时深度变化剧烈）。固定偏移在斜面处不够（痤疮残留），在正面处过大（彼得潘宁）。正确做法是使用斜率相关偏移（Slope-Scaled Bias）：bias = baseBias * (1 - N·L)，面与光线越平行偏移越大。配合正面剔除渲染 Shadow Map 可进一步减少痤疮。
</Callout>

<Callout type="trap">
**误区：PCF 采样核越大阴影越好。**
大采样核虽然阴影更柔和，但有两个问题：1) 性能——9x9 = 81 次采样远比 3x3 = 9 次昂贵；2) 渗光——大采样核会在物体边缘「泄漏」到本应完全阴影的区域，导致阴影变淡。实际中应先用 3x3 PCF 做基础，再通过 Poisson Disk 采样（旋转的随机核）在保持性能的同时提升柔和度，而非盲目增大采样核。
</Callout>

## 练习

<Exercises>
**问题 1**：阴影映射的两趟渲染分别做什么？为什么需要两趟？

<Answer>
第一趟（Shadow Map Pass）：从光源视角渲染整个场景，只记录每个像素到光源的最近深度，存入 Shadow Map（深度纹理）。第二趟（Lighting Pass）：从相机视角渲染场景，对每个像素计算其在光源空间中的深度，与 Shadow Map 中对应位置的深度比较。如果像素深度 > Shadow Map 深度，说明该像素被其他物体遮挡，光源照不到，标记为阴影。需要两趟是因为 GPU 无法在一次渲染中同时知道「光源视角的最近深度」和「相机视角的像素深度」——第一趟生成遮挡信息，第二趟消费它。
</Answer>

**问题 2**：CSM（级联阴影映射）解决什么问题？如何工作？

<Answer>
CSM 解决单张 Shadow Map 的分辨率不足问题：大场景中一张 Shadow Map 覆盖整个视锥，近处像素分辨率不够导致阴影锯齿严重。CSM 将相机视锥按距离分成多个级别（通常3-5级），每个级别用独立的高分辨率 Shadow Map 渲染。近处用小范围高精度 Shadow Map（阴影清晰），远处用大范围低精度 Shadow Map（阴影模糊但视觉影响小）。渲染时根据像素深度选择对应级别的 Shadow Map 采样，并在级联边界做平滑过渡避免硬切。CSM 是现代引擎的标准阴影方案。
</Answer>
