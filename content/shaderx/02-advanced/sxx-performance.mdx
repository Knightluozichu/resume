## 直觉引入

想象一个工厂流水线。GPU 是一个有数千个工人的超级工厂——每个工人（线程）同时做同样的工作。如果某些工人做 if 分支走了不同的路（分支发散），整条流水线要等最慢的工人完成。Shader 优化就是让每个工人的工作尽可能简单一致——减少步骤（ALU）、减少取料次数（带宽）、避免分岔（分支发散）。

关键洞察：GPU 性能优化的核心是**理解 SIMD 并行架构的约束**。GPU 以 warp（32线程）或 wavefront（64线程）为单位锁步执行——所有线程执行相同的指令。分支发散、寄存器压力、带宽瓶颈都会拖垮整组线程的性能。

## 概念讲解

### Shader 性能优化维度

<SxxPerformanceDiagram />

四个优化维度：

- <Term def="ALU 指令优化通过使用内建函数和减少运算次数来降低算术逻辑单元开销">ALU 优化</Term>：mad 代替 mul+add，rsqrt 代替 1/sqrt
- <Term def="带宽优化通过纹理压缩、Mipmap 和减少纹理采样来降低显存访问开销">带宽优化</Term>：BC/DXT 压缩，合并贴图
- <Term def="分支发散在 GPU SIMD 架构中，同一 warp 内不同线程走不同分支导致性能下降">分支发散</Term>：用 step/lerp 替代 if
- <Term def="寄存器压力 Shader 使用的临时寄存器数量影响 GPU 占用率">寄存器优化</Term>：减少临时变量，提高占用率

## 交互Demo

<Stepper>
<Step title="第一步：ALU 指令优化">GPU 有专用指令可以做复合运算：mad(a,b,c) = a*b+c 用一条指令代替 mul+add 两条。normalize 需要 sqrt，用 rsqrt（1/sqrt）+ 乘法比 1.0/sqrt + 乘法更快（GPU 有硬件 rsqrt）。避免 pow(x, 2.0)，用 x*x 代替——乘法比通用幂函数快得多。</Step>
<Step title="第二步：分支发散问题">
GPU 以 warp（32线程）为单位锁步执行。如果 if 条件使 warp 内一半线程走 true 一半走 false，GPU 两个分支都要执行——串行化。5 个线程走 false 的 if 分支让整个 warp 浪费 50% 性能。用无分支替代：c = lerp(a, b, step(threshold, x)) 代替 if(x > threshold) c = b; else c = a。
<SxxPerformanceDiagram />
</Step>
<Step title="第三步：寄存器与占用率">Shader 使用的临时变量占用 GPU 寄存器。寄存器用得越多，一个 SM（流多处理器）能同时容纳的 warp 越少，占用率越低。低占用率意味着无法用线程切换隐藏延迟。优化：复用中间变量、避免深层嵌套循环、用 [loop] 替代 [unroll] 控制展开策略。</Step>
</Stepper>

## 代码对照

```hlsl
// === ALU 优化示例 ===

// 差：mul + add 两条指令
float result = x * scale + offset;

// 好：mad 一条指令（编译器可能自动合并，但显式更保险）
float result = mad(x, scale, offset); 

// 差：1/sqrt 用通用除法 + sqrt
float invLen = 1.0 / sqrt(dot(v, v));

// 好：rsqrt 硬件指令
float invLen = rsqrt(dot(v, v));
float3 normalized = v * invLen; // 乘法比除法快

// 差：pow 通用幂函数
float falloff = pow(1.0 - cosTheta, 5.0);

// 好：手动乘法链（5 次乘法）
float t = 1.0 - cosTheta;
float falloff = t * t * t * t * t;

// === 分支优化示例 ===

// 差：动态分支，可能产生 warp 发散
float3 color;
if (useTexture) {
    color = tex.Sample(sam, uv).rgb;
} else {
    color = float3(1, 1, 1);
}

// 好：无分支替代（uniform 分支仍可用 if）
float3 texColor = tex.Sample(sam, uv).rgb;
float mask = useTexture ? 1.0 : 0.0; // uniform 分支编译期决定
float3 color = lerp(float3(1,1,1), texColor, mask);

// 差：逐像素条件判断
float light = 0;
if (NdotL > 0) {
    light = NdotL * intensity;
}

// 好：用 max 和 step 无分支替代
float light = max(NdotL, 0.0) * intensity;

// === 带宽优化：纹理合并 ===
// 差：3 张独立纹理，3 次采样
float3 albedo = albedoTex.Sample(sam, uv).rgb;
float roughness = roughTex.Sample(sam, uv).r;
float metallic = metalTex.Sample(sam, uv).r;

// 好：合并为一张 RGBA 纹理，1 次采样
float4 packed = materialTex.Sample(sam, uv);
float3 albedo = packed.rgb;
float roughness = packed.a; // alpha 通道存 roughness
// metallic 可用另一张纹理的 alpha 或用 BC 压缩的第二个通道
```

## 常见误区

<Callout type="trap">
**误区：所有 if 分支都有性能问题。**
GPU 分支分两种：uniform 分支（条件对所有线程相同，如 `if (useTexture)` 来自 constant buffer）在编译期或运行期由整个 warp 统一决策，没有发散开销。只有 dynamic 分支（条件逐像素不同，如 `if (NdotL > 0)`）才会产生 warp 发散。优化重点是 dynamic 分支，uniform 分支完全安全。过度消除所有 if 会使代码可读性下降且收益为零。
</Callout>

<Callout type="trap">
**误区：寄存器用得越少越好。**
寄存器使用量与占用率的关系不是线性的。GPU SM 有固定的寄存器总量，寄存器/线程 越少，能并行的 warp 越多（占用率高）。但占用率高不一定性能好——如果算法本身没有足够的延迟可隐藏（如纯 ALU 计算），低占用率也无所谓。关键是找到「够用的占用率」：通常 50% 以上即可，盲目减少寄存器（如用纹理查找代替中间变量）反而可能因为增加带宽而降低性能。用 Profiler 分析实际瓶颈再优化。
</Callout>

## 练习

<Exercises>
**问题 1**：什么是 warp 分支发散？它为什么降低 GPU 性能？

<Answer>
GPU 以 warp（NVIDIA 32线程 / AMD 64线程）为单位锁步执行——同一 warp 内所有线程在同一时钟周期执行相同指令。当 if 条件使 warp 内不同线程走不同分支（如某些线程 NdotL>0 走 true 分支，其他走 false 分支）时，GPU 无法同时执行两个分支，只能串行化：先执行 true 分支（走 false 的线程闲置等待），再执行 false 分支（走 true 的线程闲置等待）。这意味着 warp 内 50% 的线程始终在等待，有效吞吐量减半。如果三分之一的线程走另一分支，吞吐量降到约 66%。这就是为什么动态分支（条件逐像素不同）在 GPU 上性能昂贵。
</Answer>

**问题 2**：Shader 性能优化的四个维度是什么？各举一个优化技巧。

<Answer>
四个维度：1) ALU 指令优化——减少算术运算指令数。技巧：用 mad(a,b,c) 代替 mul+add 两条指令；用 rsqrt + 乘法代替 1/sqrt；用 x*x 代替 pow(x,2)。2) 带宽优化——减少显存访问。技巧：合并多张纹理为一张 RGBA 纹理减少采样次数；使用 BC/DXT 纹理压缩减少带宽；启用 Mipmap 减少远距采样的纹素读取。3) 分支优化——避免 warp 发散。技巧：用 lerp(a, b, step(threshold, x)) 代替 if-else；用 max(NdotL, 0) 代替 if(NdotL>0)。uniform 分支（编译期条件）安全，只优化 dynamic 分支。4) 寄存器优化——降低寄存器压力提高占用率。技巧：复用中间变量、控制循环展开策略（[loop] vs [unroll]）、避免过深嵌套。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="warp 发散">GPU SIMD 架构中同一 warp 内线程走不同分支导致串行执行，有效吞吐量下降的性能问题。</GlossaryItem>
<GlossaryItem term="占用率">GPU SM 上活跃 warp 数与最大支持 warp 数的比值，受寄存器使用量影响。</GlossaryItem>
<GlossaryItem term="ALU 优化">通过使用 mad、rsqrt 等内建函数和减少运算次数来降低算术逻辑单元开销。</GlossaryItem>
<GlossaryItem term="uniform 分支">条件对所有线程相同的分支（来自 constant buffer），无发散开销，可安全使用 if。</GlossaryItem>
</Glossary>
