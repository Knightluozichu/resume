## 直觉引入

想象你在画一幅石头墙的纹理。传统方法是拍照后在 Photoshop 中处理成贴图——但照片有接缝、分辨率有限、无法动态修改。程序化纹理则是用数学公式「算」出纹理——就像用噪声函数「生成」石头的裂纹、苔藓的分布、沙地的颗粒。零纹理内存，无限不重复，参数可调。

关键洞察：程序化纹理的核心是**用噪声函数驱动颜色和细节**。Perlin 噪声产生平滑连续的图案（云、地形），Worley 噪声产生蜂窝状的分块（石头、龟裂）。通过多层噪声叠加（分形布朗运动）和权重混合，可以生成几乎任何自然纹理。

## 交互Demo

<Stepper>
<Step title="第一步：Perlin 噪声原理">Perlin 噪声在整数格点放置随机梯度向量，对每个点用其所在格子的 4 个梯度做双线性插值（2D）或三线性插值（3D）。关键是使用平滑插值函数 fade(t) = 6t^5 - 15t^4 + 10t^3，它保证 C2 连续性（一阶和二阶导数连续），消除块状感。</Step>
<Step title="第二步：Worley 噪声">
Worley 噪声在每个网格单元随机放置一个特征点，对每个像素计算到最近特征点的距离 F1（产生蜂窝）。F2 是第二近的距离，F2-F1 产生边缘高亮效果。Worley 特别适合石头、龟裂、动物鳞片等 cellular 纹理。

</Step>
<Step title="第三步：多层混合">用 fBm 叠加多层 Perlin 噪声产生分形细节：每层频率翻倍、振幅减半。然后用高度图驱动多层权重混合：低海拔用草地噪声，中海拔用岩石噪声，高海拔用雪地噪声，用 smoothstep 平滑过渡。</Step>

## 代码对照

```hlsl
// Perlin 噪声实现 (2D)
float2 hash22(float2 p) {
    p = float2(dot(p, float2(127.1, 311.7)), dot(p, float2(269.5, 183.3)));
    return frac(sin(p) * 43758.5453) * 2.0 - 1.0; // [-1, 1]
}

float fade(float t) {
    return t * t * t * (t * (t * 6.0 - 15.0) + 10.0); // 6t^5 - 15t^4 + 10t^3
}

float perlinNoise2D(float2 p) {
    float2 i = floor(p);
    float2 f = frac(p);
    float2 u = fade(f);
    
    float2 g00 = hash22(i);
    float2 g10 = hash22(i + float2(1.0, 0.0));
    float2 g01 = hash22(i + float2(0.0, 1.0));
    float2 g11 = hash22(i + float2(1.0, 1.0));
    
    float n00 = dot(g00, f);
    float n10 = dot(g10, f - float2(1.0, 0.0));
    float n01 = dot(g01, f - float2(0.0, 1.0));
    float n11 = dot(g11, f - float2(1.0, 1.0));
    
    return lerp(lerp(n00, n10, u.x), lerp(n01, n11, u.x), u.y) * 0.5 + 0.5;
}

// 分形布朗运动
float fbm(float2 p, int octaves) {
    float value = 0.0;
    float amplitude = 0.5;
    float frequency = 1.0;
    for (int i = 0; i < octaves; i++) {
        value += amplitude * perlinNoise2D(p * frequency);
        amplitude *= 0.5;
        frequency *= 2.0;
    }
    return value;
}

// 多层地形纹理混合
float3 terrainTexture(float2 uv, float height) {
    float3 grass = float3(0.3, 0.5, 0.2) * fbm(uv * 10.0, 4);
    float3 rock  = float3(0.5, 0.4, 0.35) * fbm(uv * 15.0, 5);
    float3 snow  = float3(0.9, 0.9, 0.95);
    
    float w1 = smoothstep(0.3, 0.5, height);
    float w2 = smoothstep(0.6, 0.8, height);
    
    float3 color = lerp(grass, rock, w1);
    color = lerp(color, snow, w2);
    return color;
}
```

## 常见误区

<Callout type="trap">
**误区：用 value noise 代替 Perlin noise。**
Value noise 直接在格点放随机值再插值，虽然实现简单，但会产生明显的「块状感」——每个格子边界可见。Perlin noise 在格点放梯度向量而非随机值，通过点积和平滑插值产生连续过渡，视觉上远优于 value noise。如果需要更高质量的噪声，可考虑 Simplex noise（Perlin 的改进版，在 3D+ 维度上性能更好且无方向性伪影）。
</Callout>

<Callout type="trap">
**误区：程序化纹理不做 Tiling 处理直接用于大地形。**
Perlin/Worley 噪声的周期由坐标范围决定——在大地形上直接使用会产生明显的重复图案。解决方案：1) 使用 3D 噪声在球面或环面拓扑上采样（数学上保证周期性连续）；2) 用三角波折叠 UV（abs(frac(uv)-0.5)*2）做四面镜像消除接缝；3) 用 Wang Tile 方法用少量带边界约束的 tile 拼接无限大平面。不做 Tiling 处理的程序化纹理在 50 米外就能看出重复模式。
</Callout>

## 练习

<Exercises>
**问题 1**：Perlin 噪声为什么需要 fade 函数？它的数学性质是什么？

<Answer>
fade 函数 fade(t) = 6t^5 - 15t^4 + 10t^3 是 Perlin 噪声的关键组件。它的作用是将线性插值的参数 t 做非线性映射，使噪声在格点边界处平滑过渡。数学性质：1) fade(0)=0, fade(1)=1（端点不变）；2) 一阶导数在端点为 0（fade'(0)=0, fade'(1)=0），保证格点边界处导数连续（C1）；3) 二阶导数在端点也为 0（fade''(0)=0, fade''(1)=0），保证 C2 连续性。没有 fade 函数，直接用线性插值会在格点边界产生导数不连续（「折角」），视觉上表现为块状感。fade 函数消除了这种伪影，使 Perlin 噪声看起来连续平滑。
</Answer>

**问题 2**：fBm（分形布朗运动）如何用单层噪声生成分形细节？

<Answer>
fBm 的原理是叠加多层不同频率和振幅的噪声（称为 octaves）。每层的频率翻倍（freq *= 2.0），振幅减半（amp *= 0.5）。公式：value = sum(amp_i * noise(freq_i * p))。频率翻倍使每层添加更细的细节（高频小尺度），振幅减半保证细节的贡献随频率递减（细节越细影响越小）。这模拟了自然界的分形特征——海岸线从太空看和近处看都有曲折，但曲折的幅度随尺度递减。通常用 4-8 个 octaves：太少细节不足，太多性能浪费且高频噪声在像素级别不可见。fBm 是地形高度图、云层、大理石纹理等程序化内容的基础。
</Answer>
</Exercises>

<GlossaryItem term="Perlin 噪声">在梯度格点间用平滑插值生成的连续噪声函数，由 Ken Perlin 发明，广泛用于程序化纹理。</GlossaryItem>
