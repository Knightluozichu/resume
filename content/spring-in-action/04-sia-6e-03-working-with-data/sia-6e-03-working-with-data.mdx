## 为什么从“关系聚合与事务台”开始

第3章 使用关系数据不是starter、注解或API清单，而是一条从“service → transaction → repository → relational constraints”到业务结果的可执行合同。关系聚合与事务台把框架决策和领域结果放在同一时间线，先预测第一处变化，再运行、反证、恢复和复位。

第3章 使用关系数据的单变量实验固定提交、JDK、依赖、输入和外部服务，只改变持久化策略或事务结局；面板中的方向性数字用于比较条件，不冒充真实压测、生产SLA或安全证明。
