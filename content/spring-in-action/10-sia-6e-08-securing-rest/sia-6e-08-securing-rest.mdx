## 为什么从“OAuth2授权码与资源服务器台”开始

第8章 保护REST API不是starter、注解或API清单，而是一条从“client → authorization server → token → resource server”到业务结果的可执行合同。OAuth2授权码与资源服务器台把框架决策和领域结果放在同一时间线，先预测第一处变化，再运行、反证、恢复和复位。

第8章 保护REST API的单变量实验固定提交、JDK、依赖、输入和外部服务，只改变令牌状态或授权范围；面板中的方向性数字用于比较条件，不冒充真实压测、生产SLA或安全证明。
