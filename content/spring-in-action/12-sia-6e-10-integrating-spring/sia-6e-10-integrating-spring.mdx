## 为什么从“Integration通道拓扑台”开始

第10章 Spring Integration不是starter、注解或API清单，而是一条从“gateway → channel → filter/router/transformer → adapter”到业务结果的可执行合同。Integration通道拓扑台把框架决策和领域结果放在同一时间线，先预测第一处变化，再运行、反证、恢复和复位。

第10章 Spring Integration的单变量实验固定提交、JDK、依赖、输入和外部服务，只改变通道类型或端点行为；面板中的方向性数字用于比较条件，不冒充真实压测、生产SLA或安全证明。

```java
@Bean
IntegrationFlow orders() {
  return IntegrationFlow.from("orders.in")
      .filter(Order.class, Order::isValid)
      .transform(Order.class, OrderPlaced::from)
      .channel("orders.out").get();
}
```
