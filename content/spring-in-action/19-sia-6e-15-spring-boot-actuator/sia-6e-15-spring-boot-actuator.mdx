## 为什么从“Actuator端点与指标台”开始

第15章 Spring Boot Actuator不是starter、注解或API清单，而是一条从“application state → endpoint/metric → secured exposure”到业务结果的可执行合同。Actuator端点与指标台把框架决策和领域结果放在同一时间线，先预测第一处变化，再运行、反证、恢复和复位。

第15章 Spring Boot Actuator的单变量实验固定提交、JDK、依赖、输入和外部服务，只改变端点暴露或调用身份；面板中的方向性数字用于比较条件，不冒充真实压测、生产SLA或安全证明。
