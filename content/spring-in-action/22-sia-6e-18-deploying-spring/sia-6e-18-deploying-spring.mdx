## 为什么从“JAR、镜像与K8s探针台”开始

第18章 部署Spring不是starter、注解或API清单，而是一条从“build → image → startup/liveness/readiness → traffic”到业务结果的可执行合同。JAR、镜像与K8s探针台把框架决策和领域结果放在同一时间线，先预测第一处变化，再运行、反证、恢复和复位。

第18章 部署Spring的单变量实验固定提交、JDK、依赖、输入和外部服务，只改变制品形态或关闭阶段；面板中的方向性数字用于比较条件，不冒充真实压测、生产SLA或安全证明。

第18章 部署Spring依据Manning[第6版产品页](https://www.manning.com/books/spring-in-action-sixth-edition)核定作者、2022年、520页和ISBN 9781617297571，并用[官方liveBook完整目录](https://livebook.manning.com/book/spring-in-action-sixth-edition/contents)定位4个Part、18章、附录及255个正式节点。第18章 部署Spring未取得出版正文授权，目录只限定范围，中文解释、代码、图示、实验、故障与答案均为独立教学重写。

第18章 部署Spring保留原书Spring Framework 5·3 / Boot 2·4历史语境；迁移复核以[Spring Framework 7·0·8参考](https://docs.spring.io/spring-framework/reference/index.html)、[Spring Boot 4·1·0系统要求](https://docs.spring.io/spring-boot/system-requirements.html)、[Spring Security](https://docs.spring.io/spring-security/reference/index.html)、[Spring Data](https://docs.spring.io/spring-data/commons/reference/index.html)、[Spring Integration](https://docs.spring.io/spring-integration/reference/index.html)与[Reactor](https://projectreactor.io/docs/core/release/reference/index.html)官方资料为事实依据。当前注记不冒充原书内容，也不允许把新API机械回填到旧基线。
