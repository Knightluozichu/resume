## SQL函数分类与应用

<SqtFunctionsDiagram />

SQL函数在SELECT阶段的列计算中执行，用于对数据进行转换、格式化和处理。函数分为文本、数值、日期、转换四大类。

## 文本处理函数

```
-- 大小写转换
SELECT UPPER(prod_name) AS upper_name FROM products;
SELECT LOWER(prod_name) AS lower_name FROM products;

-- 字符串长度
SELECT prod_name, LENGTH(prod_name) AS name_len FROM products;
SELECT prod_name, CHAR_LENGTH(prod_name) AS char_len FROM products;  -- 字符数（多字节安全）

-- 截取子串（MySQL 位置从1开始）
SELECT SUBSTRING(prod_name, 1, 5) AS first5 FROM products;  -- 从第1位取5个字符
SELECT LEFT(prod_name, 3) AS prefix FROM products;
SELECT RIGHT(prod_name, 3) AS suffix FROM products;

-- 去空格
SELECT TRIM('  hello  ') AS trimmed;       -- 'hello'
SELECT LTRIM('  hello  ') AS ltrimmed;     -- 'hello  '
SELECT RTRIM('  hello  ') AS rtrimmed;     -- '  hello'

-- 拼接与替换
SELECT CONCAT(first_name, ' ', last_name) AS full_name FROM customers;
SELECT REPLACE('Hello World', 'World', 'SQL') AS result;  -- 'Hello SQL'

-- 查找与定位
SELECT LOCATE('o', 'Hello') AS pos;  -- 5（返回位置，找不到返回0）
```

## 数值处理函数

```
-- 四舍五入与截断
SELECT ROUND(3.14159, 2);    -- 3.14（四舍五入到2位小数）
SELECT ROUND(3.5);           -- 4（四舍五入到整数）
SELECT TRUNCATE(3.14159, 2); -- 3.14（截断，不四舍五入）

-- 取整
SELECT CEIL(3.1);            -- 4（向上取整）
SELECT FLOOR(3.9);           -- 3（向下取整）

-- 数学函数
SELECT ABS(-5);              -- 5（绝对值）
SELECT MOD(10, 3);           -- 1（取模/求余）
SELECT POWER(2, 10);         -- 1024（幂运算）
SELECT RAND();               -- 0~1随机数

-- 分页计算常用
SELECT CEIL(101 / 20);       -- 6（总101条，每页20条，共6页）
```

## 日期时间函数

```
-- 获取当前日期时间
SELECT NOW();        -- 2024-01-15 14:30:00
SELECT CURDATE();    -- 2024-01-15
SELECT CURTIME();    -- 14:30:00

-- 提取日期部分
SELECT YEAR(order_date) AS yr FROM orders;
SELECT MONTH(order_date) AS mon FROM orders;
SELECT DAY(order_date) AS dy FROM orders;
SELECT DAYNAME('2024-01-15');  -- 'Monday'
SELECT MONTHNAME('2024-01-15'); -- 'January'

-- 日期格式化
SELECT DATE_FORMAT(order_date, '%Y年%m月%d日') AS formatted FROM orders;

-- 日期差与加减
SELECT DATEDIFF('2024-01-15', '2024-01-01');  -- 14（天数差）
SELECT DATE_ADD('2024-01-15', INTERVAL 7 DAY);  -- 2024-01-22
SELECT DATE_SUB('2024-01-15', INTERVAL 1 MONTH); -- 2023-12-15

-- 按日期范围查询
SELECT * FROM orders WHERE order_date BETWEEN '2024-01-01' AND '2024-01-31';
SELECT * FROM orders WHERE YEAR(order_date) = 2024 AND MONTH(order_date) = 1;
```

<Callout type="info" title="日期查询的最佳实践">
对日期列使用函数（如 `YEAR(order_date) = 2024`）会导致索引失效。推荐使用范围查询：`WHERE order_date >= '2024-01-01' AND order_date < '2024-02-01'`，这样可以利用索引。
</Callout>

## 类型转换与NULL处理

```
-- 类型转换
SELECT CAST('123' AS SIGNED);              -- 字符串转整数
SELECT CAST(3.14 AS DECIMAL(10,1));        -- 3.1
SELECT CONVERT('2024-01-15', DATE);        -- 字符串转日期

-- NULL 处理
-- COALESCE：返回第一个非NULL值
SELECT COALESCE(cust_email, '无邮箱') AS email FROM customers;

-- IFNULL（MySQL专用）：第一个参数为NULL则返回第二个
SELECT IFNULL(cust_email, '无邮箱') AS email FROM customers;

-- NULLIF：两个值相等返回NULL
SELECT NULLIF(score, 0);  -- score为0时返回NULL（避免除零）

-- 条件表达式
SELECT IF(score >= 60, '及格', '不及格') AS result FROM students;

-- CASE WHEN（更通用的条件逻辑）
SELECT prod_name,
  CASE
    WHEN prod_price < 5  THEN '便宜'
    WHEN prod_price < 10 THEN '适中'
    WHEN prod_price >= 10 THEN '较贵'
    ELSE '未知'
  END AS price_level
FROM products;
```

<Callout type="success" title="CASE WHEN 是SQL中的if-else">
CASE WHEN是SQL中实现条件逻辑的标准方式，比IF函数更通用（IF是MySQL专有）。可以用在SELECT、WHERE（子查询中）、ORDER BY等位置。CASE WHEN支持多条件和ELSE默认值，是数据分类标注的利器。
</Callout>

<Glossary>

<GlossaryItem term="SQL函数">
在SELECT阶段对列数据进行转换和处理的内置函数，分为文本、数值、日期、转换四大类。注意SQL函数在不同数据库中语法可能不同（如字符串拼接：MySQL用CONCAT，SQL Server用+），编写可移植SQL时需注意。
</GlossaryItem>

<GlossaryItem term="COALESCE">
返回参数列表中第一个非NULL值的函数。`COALESCE(a, b, c)` 如果a非NULL返回a，否则如果b非NULL返回b，以此类推。常用于NULL值替换，是SQL标准函数，所有数据库都支持。
</GlossaryItem>

<GlossaryItem term="CASE WHEN">
SQL中实现条件逻辑的标准表达式，类似编程语言中的if-else。语法：`CASE WHEN 条件1 THEN 值1 WHEN 条件2 THEN 值2 ELSE 默认值 END`。支持多个条件和ELSE子句，可用在SELECT、ORDER BY等位置。
</GlossaryItem>

<GlossaryItem term="日期函数索引失效">
对日期列使用函数（如YEAR()、MONTH()）会导致该列的索引无法使用，因为函数改变了列值的比较方式。最佳实践是使用范围查询替代函数：用 `WHERE date >= '2024-01-01' AND date < '2024-02-01'` 替代 `WHERE YEAR(date) = 2024 AND MONTH(date) = 1`。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1**：为什么对日期列使用函数（如 `YEAR(order_date) = 2024`）会导致索引失效？应该怎么写？

<Answer>
对列使用函数后，数据库需要对每一行的该列值先执行函数计算，再与常量比较，无法直接利用索引中已排序的值进行快速查找，因此退化为全表扫描。正确写法是使用范围查询：`WHERE order_date >= '2024-01-01' AND order_date < '2024-02-01'`，这样数据库可以直接利用索引上已排序的日期值进行范围定位，效率大幅提高。这是SQL性能优化中最常见的原则之一——不要在WHERE条件中对列使用函数。
</Answer>

**问题 2**：COALESCE函数的作用是什么？给出一个实际使用场景。

<Answer>
COALESCE返回参数列表中第一个非NULL值。语法：`COALESCE(val1, val2, val3, ...)`，从左到右找第一个非NULL值返回，如果全是NULL则返回NULL。实际场景：①显示NULL的默认值——`SELECT COALESCE(cust_email, '未填写') FROM customers`，将NULL邮箱显示为"未填写"；②多列优先取值——`SELECT COALESCE(mobile_phone, home_phone, work_phone) AS contact_phone`，优先返回手机号，没有则返回座机；③避免NULL参与运算——`price * COALESCE(discount, 1)` 避免折扣为NULL时整个计算结果为NULL。
</Answer>

**问题 3**：CASE WHEN表达式的语法是什么？它在SQL中扮演什么角色？

<Answer>
语法：`CASE WHEN 条件1 THEN 值1 [WHEN 条件2 THEN 值2 ...] [ELSE 默认值] END`。它是SQL中实现条件逻辑的标准方式，类似编程语言的if-else/if-elif-else。角色：①数据分类标注——如将价格分为"便宜/适中/较贵"；②条件计算——根据不同条件返回不同计算结果；③条件排序——在ORDER BY中实现自定义排序顺序。CASE WHEN是SQL标准，所有数据库都支持，比MySQL专有的IF函数更具可移植性。可用于SELECT、ORDER BY等位置，但不能直接用在WHERE中（应直接写条件）。
</Answer>

**问题 4**：SQL函数在不同数据库中的可移植性如何？举例说明。

<Answer>
SQL函数的可移植性较差，不同数据库的函数名和语法经常不同。典型例子：①字符串拼接——MySQL用CONCAT()，SQL Server用+运算符，Oracle用||运算符；②日期提取——MySQL用YEAR(date)，SQL Server用DATEPART(year, date)；③空值处理——MySQL有IFNULL()，SQL Server/Oracle用ISNULL()，标准SQL用COALESCE()；④LIMIT——MySQL/PostgreSQL用LIMIT，SQL Server用TOP，Oracle用ROWNUM。编写可移植SQL应优先使用SQL标准函数（如COALESCE），或使用ORM框架抽象差异。本书以MySQL语法为主。
</Answer>
