## 感知机概述

感知机是二分类的线性分类模型，是神经网络和支持向量机的基础。它的输入为特征向量，输出为实例的类别（+1 或 -1）。感知机旨在学习一个分离超平面，将特征空间划分为两个区域，分别对应两个类别。

## 模型形式

感知机的模型为：

```text
f(x) = sign(w · x + b)
```

其中 `w` 是权值向量，`b` 是偏置，`sign` 是符号函数。`w · x + b = 0` 对应特征空间中的一个分离超平面，`w` 是超平面的法向量，`b` 是超平面的截距。

<Callout type="info">

**直觉**：感知机的目标是找到一个超平面，将正类和负类完全分开。超平面的方向由 `w` 决定，位置由 `b` 决定。一个样本 `xi` 被正确分类当且仅当 `yi(w · xi + b) > 0`。

</Callout>

## 损失函数

感知机采用**误分类点到超平面的总距离**作为损失函数：

```text
L(w, b) = -Σ yi(w · xi + b)
```

其中求和仅对误分类点进行。一个点是误分类的当且仅当 `yi(w · xi + b) ≤ 0`。

这个损失函数的直觉：误分类点离超平面越远，损失越大。梯度下降法可以优化这个损失函数。

## 学习算法：原始形式

感知机学习算法的原始形式是一种随机梯度下降法：

```text
1. 选取初始参数 w0, b0
2. 在训练集中选取数据 (xi, yi)
3. 如果 yi(w · xi + b) ≤ 0（误分类点）：
     w ← w + η yi xi
     b ← b + η yi
4. 转至 2，直至训练集中没有误分类点
```

其中 `η`（0 < η ≤ 1）是学习率。

<Callout type="tip">

**参数更新的直觉**：当一个点被误分类时，如果 `yi=+1` 则 `w` 往 `xi` 方向移动（使 `w · xi` 增大），如果 `yi=-1` 则 `w` 往 `xi` 反方向移动。这种更新使超平面向正确分类该点的方向移动。

</Callout>

## 学习算法：对偶形式

对偶形式将 `w` 和 `b` 表示为实例的线性组合：`w = Σ αi yi xi`，其中 `αi ≥ 0` 表示第 `i` 个实例在更新中的累计次数。

```text
1. 初始化 α = 0, b = 0
2. 在训练集中选取 (xi, yi)
3. 如果 yi(Σ αj yj xj · xi + b) ≤ 0：
     αi ← αi + η
     b ← b + η yi
4. 转至 2，直至没有误分类
```

对偶形式中实例仅以内积形式出现（`xj · xi`），可以预先计算 **Gram 矩阵** `G = [xi · xj]` 加速计算。对偶形式为后续 SVM 的核技巧奠定了基础。

## Novikoff 收敛定理

**定理**：设训练数据集是线性可分的，则感知机学习算法的误分类次数 `k` 满足上界：

```text
k ≤ (R / γ)²
```

其中 `R = max||xi||`（样本最大范数），`γ` 是分离超平面的间隔。

定理的意义：①对于线性可分数据集，感知机算法经过有限次迭代一定能找到分离超平面；②间隔越大收敛越快；③仅对线性可分数据成立，对线性不可分数据算法不收敛。

<Callout type="info">

**感知机 vs SVM**：感知机的解不唯一——不同的初始值和误分类点选取顺序可能导致不同的超平面。SVM 通过最大间隔保证解唯一。这是感知机与 SVM 的重要区别。

</Callout>

<GlossaryItem term="感知机">
二分类的线性分类模型，模型形式 f(x)=sign(w·x+b)。分离超平面 w·x+b=0 将特征空间分为两个区域。损失函数为误分类点到超平面的总距离。学习算法为随机梯度下降。是神经网络和 SVM 的基础。
</GlossaryItem>

<GlossaryItem term="分离超平面">
特征空间中将两类样本分开的超平面 w·x+b=0。w 是法向量决定方向，b 是截距决定位置。感知机学习的目标就是找到这个超平面。
</GlossaryItem>

<GlossaryItem term="对偶形式">
将 w 和 b 表示为实例的线性组合 w=Σαi yi xi 的学习算法形式。利用 Gram 矩阵加速计算，并为核技巧奠定基础。αi 表示第 i 个实例在更新中的累计次数。
</GlossaryItem>

<GlossaryItem term="Gram 矩阵">
训练样本内积矩阵 G=[xi·xj]，在对偶形式中预先计算以加速每次更新。计算和存储复杂度为 O(N²)，在样本数较大时开销显著。
</GlossaryItem>

<GlossaryItem term="Novikoff 定理">
感知机收敛定理。对于线性可分数据集，误分类次数有上界 k≤(R/γ)²，其中 R 是样本最大范数，γ 是间隔。定理保证感知机在线性可分数据上必收敛。
</GlossaryItem>

<GlossaryItem term="线性可分">
存在一个超平面能将训练数据集的正负实例点完全正确地分开。感知机收敛定理仅在线性可分条件下成立。线性不可分时感知机算法不收敛（会振荡）。
</GlossaryItem>

</Glossary>

### 问题 1

什么是感知机？它的模型形式和损失函数是什么？

<Answer>

感知机是二分类的线性分类模型，其输入为特征向量，输出为实例的类别（+1 或 -1）。模型形式：f(x) = sign(w·x + b)，其中 w 是权值向量，b 是偏置。w·x + b = 0 对应特征空间中的一个分离超平面。损失函数：感知机采用误分类点到超平面的总距离作为损失函数 L(w,b) = -Σ yi(w·xi + b)，其中求和仅对误分类点进行。一个点是误分类的当且仅当 yi(w·xi+b) ≤ 0。这个损失函数是 w 和 b 的连续可导函数，便于用梯度下降法优化。感知机是神经网络和支持向量机的基础。

</Answer>

### 问题 2

感知机学习算法的原始形式是怎样的？

<Answer>

感知机学习算法的原始形式是一种随机梯度下降法。算法步骤：①选取初始参数 w0, b0；②在训练集中选取数据 (xi, yi)；③如果 yi(w·xi + b) ≤ 0（即该点是误分类点），则更新参数：w ← w + η yi xi，b ← b + η yi，其中 η 是学习率；④转至②，直至训练集中没有误分类点。算法的直觉：当一个点被误分类时，如果 yi=+1 则 w 往 xi 方向移动使 w·xi 增大，如果 yi=-1 则 w 往 xi 反方向移动。这种更新使超平面向正确分类该点的方向移动。感知机学习算法由于采用不同的初始值或选取不同的误分类点顺序，最终得到的超平面可能不同。

</Answer>

### 问题 3

感知机学习算法的对偶形式是什么？与原始形式有何不同？

<Answer>

对偶形式将 w 和 b 表示为实例 xi 和标记 yi 的线性组合，通过求解其系数 αi 而求得 w 和 b。在对偶形式中，w = Σ αi yi xi，其中 αi ≥ 0 表示第 i 个实例在更新中的累计次数。算法步骤：①初始化 α = 0, b = 0；②在训练集中选取 (xi, yi)；③如果 yi(Σ αj yj xj·xi + b) ≤ 0，则更新 αi ← αi + η, b ← b + η yi；④转至②直至没有误分类。对偶形式与原始形式的区别：①对偶形式中实例仅以内积形式出现，可以预先计算 Gram 矩阵加速；②对偶形式为核技巧奠定了基础——将内积替换为核函数即可处理非线性；③两者在数学上等价，但计算效率在不同场景下有差异。

</Answer>

### 问题 4

什么是 Novikoff 定理？它对感知机有什么意义？

<Answer>

Novikoff 定理（感知机收敛定理）：设训练数据集是线性可分的，即存在一个超平面能将正负实例完全分开，则感知机学习算法的误分类次数 k 满足上界 k ≤ (R/γ)²，其中 R = max||xi||（样本最大范数），γ 是分离超平面的间隔。定理的意义：①保证收敛——对于线性可分数据集，感知机学习算法经过有限次迭代后一定能找到一个分离超平面，不会无限循环；②误分类次数有上界——间隔越大收敛越快；③局限性——定理仅对线性可分数据成立，对线性不可分数据算法不收敛（会振荡）；④感知机的解不唯一——不同的初始值和误分类点选取顺序可能导致不同的超平面，这是感知机与 SVM 的重要区别。

</Answer>
