## 朴素贝叶斯概述

朴素贝叶斯法是基于贝叶斯定理与特征条件独立假设的分类方法。它是一种生成式模型，通过建模联合概率分布 `P(X,Y) = P(Y)P(X|Y)` 来进行分类。尽管条件独立性假设在实际中很少严格成立，但朴素贝叶斯在文本分类等任务中表现优秀。

## 贝叶斯定理

贝叶斯定理是朴素贝叶斯法的理论基础：

```text
P(Y|X) = P(X|Y) P(Y) / P(X)
```

- `P(Y)`：先验概率（类别分布）
- `P(X|Y)`：似然（给定类别下特征的概率）
- `P(Y|X)`：后验概率（给定特征后的类别概率）

分类规则：取后验概率最大的类别 `y = argmax_yk P(yk) Π P(Xi|yk)`。

## 条件独立性假设

朴素贝叶斯的「朴素」来自一个强假设——特征条件独立：

```text
P(X1, X2, ..., Xn | Y) = Π P(Xi | Y)
```

即假设特征在给定类别下条件独立。这一假设大大简化了计算：将 n 维联合分布分解为 n 个一维条件概率的乘积。

<Callout type="info">

**为什么独立性假设不严格成立但效果仍然好**：①分类只需比较后验概率的相对大小（argmax），不需要精确的概率值；②独立性假设虽然引入了偏差，但也大大减少了需要估计的参数数量，降低了方差。偏差-方差权衡中，偏差的增加被方差的减少所补偿。

</Callout>

## 参数估计

### 极大似然估计

先验概率：`P(Y=yk) = Σ I(yi=yk) / N`

条件概率：`P(Xi=xij | Y=yk) = Σ I(xi=xij, yi=yk) / Σ I(yi=yk)`

### 贝叶斯估计（拉普拉斯平滑）

当某个特征值在训练集中从未与某类别同时出现时，条件概率为 0，导致整个乘积为 0。为避免此「零概率」问题，引入平滑参数 `λ ≥ 0`：

```text
Pλ(Xi=xij | Y=yk) = (Σ I(xi=xij, yi=yk) + λ) / (Σ I(yi=yk) + Sj λ)
```

其中 `Sj` 是第 j 个特征的可能取值数。`λ=1` 时为拉普拉斯平滑（加一平滑），`λ=0` 时退化为极大似然估计。

## 算法流程

```text
训练阶段：
  1. 计算先验概率 P(Y=yk)
  2. 计算条件概率 P(Xi=xij | Y=yk)

预测阶段（给定新样本 x）：
  3. 对每个类别 yk，计算后验概率 P(Y=yk) Π P(Xi=xi | Y=yk)
  4. 取后验概率最大的类别作为预测结果
```

<Callout type="tip">

**数值稳定性**：在计算中通常取对数避免下溢（多个小概率相乘导致数值下溢）：`log P(yk|x) ∝ log P(yk) + Σ log P(Xi=xi | Y=yk)`。朴素贝叶斯的训练时间复杂度为 `O(NK)`，预测时间复杂度为 `O(Kn)`，非常高效。

</Callout>

<GlossaryItem term="朴素贝叶斯法">
基于贝叶斯定理与特征条件独立假设的分类方法。通过建模联合概率 P(X,Y)=P(Y)P(X|Y) 进行分类。「朴素」来源于条件独立性假设。属于生成式模型。在文本分类等任务中表现优秀。
</GlossaryItem>

<GlossaryItem term="条件独立性假设">
朴素贝叶斯的核心假设：P(X1,...,Xn|Y) = Π P(Xi|Y)，即特征在给定类别下条件独立。这一假设简化了联合分布计算，虽然实际中很少严格成立，但由于分类只需 argmax，效果仍然好。
</GlossaryItem>

<GlossaryItem term="贝叶斯定理">
P(Y|X) = P(X|Y)P(Y)/P(X)。后验概率 = 似然 × 先验 / 证据。是朴素贝叶斯法的理论基础。
</GlossaryItem>

<GlossaryItem term="极大似然估计（MLE）">
用训练数据的频率作为概率估计。先验 P(Y=yk) = ΣI(yi=yk)/N，条件概率 P(Xi|yk) = ΣI(xi,yk)/ΣI(yk)。简单直观但可能出现零概率问题。
</GlossaryItem>

<GlossaryItem term="拉普拉斯平滑">
贝叶斯估计中 λ=1 的特例，也称加一平滑。通过在分子和分母分别加 λ 和 Sj·λ，保证所有概率为正值，避免零概率导致整个乘积为 0。
</GlossaryItem>

<GlossaryItem term="生成式模型">
建模联合概率分布 P(X,Y) = P(Y)P(X|Y) 的方法。朴素贝叶斯是生成式模型，通过贝叶斯定理从联合分布得到后验 P(Y|X)。与直接建模 P(Y|X) 的判别式模型相对。
</GlossaryItem>

</Glossary>

### 问题 1

什么是朴素贝叶斯法？它的核心假设是什么？

<Answer>

朴素贝叶斯法是基于贝叶斯定理与特征条件独立假设的分类方法。其基本思想是：对于给定的待分类项 x，计算在每个类别 yk 下 x 出现的后验概率 P(yk|x)，取后验概率最大的类别作为预测结果。核心假设是条件独立性假设：P(X1,X2,...,Xn | Y) = Π P(Xi | Y)，即假设特征在给定类别下条件独立。这一假设是「朴素」的来源——它简化了联合条件概率的计算，将 n 维联合分布分解为 n 个一维条件概率的乘积。朴素贝叶斯法属于生成式模型，它建模联合概率 P(X,Y) = P(Y)P(X|Y)。

</Answer>

### 问题 2

朴素贝叶斯法的参数如何估计？什么是拉普拉斯平滑？

<Answer>

朴素贝叶斯法需要估计先验概率 P(Y=yk) 和条件概率 P(Xi=xij|Y=yk)。极大似然估计：先验 P(Y=yk) = Σ I(yi=yk)/N，条件概率 P(Xi=xij|Y=yk) = Σ I(xi=xij,yi=yk)/Σ I(yi=yk)。贝叶斯估计（拉普拉斯平滑）：当某个特征值在训练集中从未与某类别同时出现时，条件概率为 0，导致整个乘积为 0。为避免此问题，引入平滑参数 λ：Pλ(Xi=xij|Y=yk) = (Σ I(xi=xij,yi=yk)+λ)/(Σ I(yi=yk)+Sj λ)。λ=1 时为拉普拉斯平滑（加一平滑），λ=0 时退化为极大似然估计。平滑保证了所有概率为正值。

</Answer>

### 问题 3

朴素贝叶斯法的算法流程是什么？

<Answer>

朴素贝叶斯算法流程分为训练和预测两个阶段。训练阶段：①计算先验概率 P(Y=yk) = Σ I(yi=yk)/N。②计算条件概率 P(Xi=xij|Y=yk)，对每个特征 i 和每个类别 k。预测阶段：③对每个类别 yk，计算后验概率 P(Y=yk) Π P(Xi=xi|Y=yk)。④取后验概率最大的类别作为预测结果。注意在计算中通常取对数避免下溢：log P(yk|x) ∝ log P(yk) + Σ log P(Xi=xi|Y=yk)。朴素贝叶斯的训练时间复杂度为 O(NK)，预测时间复杂度为 O(Kn)，非常高效。

</Answer>

### 问题 4

朴素贝叶斯法与贝叶斯估计有什么关系？为什么独立性假设虽不严格成立但效果仍然好？

<Answer>

朴素贝叶斯法的参数估计可以采用极大似然估计（频率派观点）或贝叶斯估计（贝叶斯派观点）。贝叶斯估计引入先验分布（通过平滑参数 λ 体现），使得估计更稳健。λ=0 时退化为极大似然估计，λ>0 时为贝叶斯估计，λ=1 为拉普拉斯平滑。独立性假设虽不严格成立但效果仍然好的原因：①分类只需比较后验概率的相对大小（argmax），不需要精确的概率值——即使条件概率估计有偏差，只要不影响 argmax 的结果，分类就是正确的。②独立性假设虽然引入了偏差，但也大大减少了需要估计的参数数量——从估计联合概率降至估计条件概率，降低了方差。偏差的增加被方差的减少所补偿。③在特征维度高、训练数据有限时，独立性假设的简化优势更加明显。

</Answer>
