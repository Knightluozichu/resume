## 逻辑斯谛回归与最大熵概述

逻辑斯谛回归和最大熵模型是两种密切相关的对数线性模型。逻辑斯谛回归从对数几率的线性模型出发，最大熵从最大熵原理出发，但两者在数学上等价。它们都是判别式模型，直接建模 `P(Y|X)`，并且都是凸优化问题，保证全局最优解。

## 逻辑斯谛回归模型

### 模型形式

二分类逻辑斯谛回归：

```text
P(Y=1|x) = exp(w·x + b) / (1 + exp(w·x + b))
P(Y=0|x) = 1 / (1 + exp(w·x + b))
```

等价地，**对数几率**（log odds）是 x 的线性函数：

```text
log(P / (1-P)) = w · x + b
```

这意味着逻辑斯谛回归假设对数几率是特征的线性组合。

### 多项逻辑斯谛回归（softmax）

多分类时使用 softmax：

```text
P(Y=yk | x) = exp(wk · x) / Σ exp(wj · x)
```

<Callout type="info">

**sigmoid 函数性质**：`σ(z) = 1/(1+exp(-z))` 的输出在 (0,1) 之间可解释为概率，单调递增，在 z=0 处值为 0.5。逻辑斯谛回归是最广为使用的分类模型之一，也是神经网络中 softmax 层的基础。

</Callout>

## 参数估计：极大似然

通过极大似然估计参数。对数似然函数：

```text
l(w) = Σ [yi(w·xi) - log(1 + exp(w·xi))]
```

这是 `w` 的凹函数，极大似然估计是凸优化问题，有全局最优解。可用梯度下降法或牛顿法求解。

## 最大熵原理

最大熵原理：在所有满足约束条件的概率模型中，**熵最大的模型是最好的**。直觉是：在满足已知约束的前提下，对未知部分不做任何额外假设，保持最大的不确定性。

### 最大熵模型

```text
Pw(y|x) = (1/Zw(x)) exp(Σ wi fi(x,y))
```

其中 `fi(x,y)` 是特征函数，`wi` 是权重，`Zw(x)` 是归一化因子。

约束条件：特征函数关于模型分布的期望等于关于经验分布的期望。

## 逻辑斯谛回归与最大熵的等价性

<Callout type="tip">

**关键结论**：二分类逻辑斯谛回归是最大熵模型的特例。当最大熵模型中特征函数取特定形式时，最大熵模型的解与逻辑斯谛回归形式完全一致。多项逻辑斯谛回归也可以看作多类最大熵模型的特例。两者的对数线性形式是统一的。

</Callout>

## 学习算法

| 算法 | 特点 |
|------|------|
| 改进的迭代尺度法（IIS） | 固定其他参数，逐个优化单个参数 |
| 梯度下降法 | 对所有参数同时沿负梯度更新 |
| 拟牛顿法（L-BFGS） | 利用二阶信息加速收敛，实践中最常用 |
| 牛顿法 | 精确计算 Hessian，收敛最快但开销大 |

</GlossaryItem>

<GlossaryItem term="对数几率（log odds）">
log(P/(1-P))，即正类概率与负类概率比值的对数。逻辑斯谛回归假设对数几率是特征的线性组合 log(P/(1-P))=w·x+b，这是逻辑斯谛回归模型的核心假设。
</GlossaryItem>

<GlossaryItem term="最大熵原理">
在所有满足约束条件的概率模型中，熵最大的模型是最好的。直觉是：在满足已知约束的前提下，对未知部分不做任何额外假设，保持最大的不确定性。
</GlossaryItem>

<GlossaryItem term="最大熵模型">
Pw(y|x) = (1/Zw(x)) exp(Σ wi fi(x,y))。特征函数 fi(x,y) 是二值函数，权重 wi 通过约束条件（模型期望=经验期望）确定。是指数族分布的一种，与逻辑斯谛回归等价。
</GlossaryItem>

<GlossaryItem term="改进的迭代尺度法（IIS）">
最大熵模型的学习算法之一。固定其他参数，逐个优化单个参数 wi。每次迭代中，对每个 wi 求解方程使其增量满足约束。优点是每次只需解一维优化问题，缺点是收敛较慢。
</GlossaryItem>

### 问题 1

什么是逻辑斯谛回归模型？它的模型形式是什么？

<Answer>

逻辑斯谛回归是一种分类模型，通过逻辑斯谛函数（sigmoid 函数）将线性模型的输出映射到 (0,1) 区间，表示为正类的概率。二分类逻辑斯谛回归模型：P(Y=1|x) = exp(w·x+b)/(1+exp(w·x+b))，P(Y=0|x) = 1/(1+exp(w·x+b))。等价地，对数几率 log(P/(1-P)) = w·x+b 是 x 的线性函数。这意味着逻辑斯谛回归模型假设对数几率是特征 x 的线性组合。多项逻辑斯谛回归（softmax 回归）用于多分类：P(Y=yk|x) = exp(wk·x)/Σ exp(wj·x)。逻辑斯谛回归是判别式模型，直接建模 P(Y|X)。它是最广为使用的分类模型之一，也是神经网络中 softmax 层的基础。

</Answer>

### 问题 2

逻辑斯谛回归的参数如何估计？

<Answer>

逻辑斯谛回归的参数通过极大似然估计来估计。似然函数为 L(w) = Π [π(xi)]^yi [1-π(xi)]^(1-yi)，其中 π(xi) = P(Y=1|xi)。对数似然函数为 l(w) = Σ [yi log π(xi) + (1-yi) log(1-π(xi))] = Σ [yi(w·xi) - log(1+exp(w·xi))]。极大似然估计就是求使 l(w) 最大的 w。由于 l(w) 是 w 的凹函数，极大似然估计是一个无约束的凸优化问题，可以用梯度下降法或牛顿法求解。梯度：∂l/∂w = Σ (yi - π(xi)) xi。梯度下降更新：w ← w + η Σ (yi - π(xi)) xi。逻辑斯谛回归的凸优化性质保证了解的全局最优性。

</Answer>

### 问题 3

什么是最大熵原理？最大熵模型的形式是什么？

<Answer>

最大熵原理是概率模型学习的一个准则。其基本思想是：在所有满足约束条件的概率模型中，熵最大的模型是最好的。直觉是：在满足已知约束的前提下，对未知部分不做任何额外假设，保持最大的不确定性。最大熵模型的形式：Pw(y|x) = (1/Zw(x)) exp(Σ wi fi(x,y))，其中 fi(x,y) 是特征函数（二值函数），wi 是特征函数的权重，Zw(x) = Σ_y exp(Σ wi fi(x,y)) 是归一化因子。约束条件：特征函数关于模型分布的期望等于关于经验分布的期望。最大熵模型的学习等价于在约束条件下最大化对数似然函数，可以通过拉格朗日乘子法求解。

</Answer>

### 问题 4

逻辑斯谛回归与最大熵模型的关系是什么？最大熵模型的学习算法有哪些？

<Answer>

二分类逻辑斯谛回归是最大熵模型的特例。当最大熵模型中特征函数取特定形式时（y=+1 时 f(x,y)=x，y=-1 时 f(x,y)=0），最大熵模型的解与逻辑斯谛回归形式完全一致。多项逻辑斯谛回归也可以看作多类最大熵模型的特例。两者的对数线性形式是统一的。因此逻辑斯谛回归和最大熵模型在数学上是等价的，只是出发点不同——逻辑斯谛回归从对数几率的线性模型出发，最大熵从最大熵原理出发。最大熵模型的学习算法：①改进的迭代尺度法（IIS）——固定其他参数，逐个优化单个参数 wi，每次只需解一维优化问题，缺点是收敛较慢。②梯度下降法——同时对所有参数沿负梯度方向更新。③拟牛顿法（如 L-BFGS）——利用二阶信息加速收敛，是目前实践中最常用的方法。④牛顿法——精确计算 Hessian 矩阵，收敛最快但计算和存储开销大。

</Answer>
