## 从“一套书为什么只有七个编号章节”开始

先预测：TAOCP不是把常见主题各写成一个短章，而是让一个编号章节占据一整卷甚至跨越多个物理卷。若只看到书架上的五本书，会误以为有五章；若只看Chapter 1至7，又会把Volume 4A和4B近一千六百页压成一个学习页面。正确地图必须同时保留“物理出版物”和“逻辑章节”两个坐标。


本课程以出版社当前Volumes 1–4B boxed set为。它包含五个：

- Volume 1 · *Fundamental Algorithms*, Third Edition：Chapter 1与Chapter 2。
- Volume 2 · *Seminumerical Algorithms*, Third Edition：Chapter 3与Chapter 4。
- Volume 3 · *Sorting and Searching*, Second Edition：Chapter 5与Chapter 6。
- Volume 4A · *Combinatorial Algorithms, Part 1*：Chapter 7前半。
- Volume 4B · *Combinatorial Algorithms, Part 2*：Chapter 7继续部分。

因此，课程使用8个正式教学单元：Chapter 1至6各一个，Chapter 7按4A和4B各一个。学习地图和总复习是导航页，不冒充原书章节。

## 正式出版边界与未来路线


Knuth官方页面会持续列出Volume 4后续分册、在写的Volume 5与更远计划。这些信息说明系列仍在生长，却不能反向改变当前完成定义。与出版状态必须分开记录：

$$
\text{current corpus}
=\{V1,V2,V3,V4A,V4B\},
\qquad
\text{logical chapters}=\{1,2,\ldots,7\}.
$$

若未来4C正式合订出版，课程应新增Chapter 7 Part 3单元，而不是悄悄把4C内容塞进4B页面。若Volume 5正式出版，则新增Chapter 9和10所对应的卷册；在那之前，它们只属于路线图。这样，100分始终代表一个可核验时间点，而不是对未完成作品做虚假承诺。


## 七章主脊：表示、算法与分析


TAOCP每个主题都反复执行同一工作法。先给对象和任务的精确定义，再选取机器或数据表示，随后陈述算法步骤与保持条件，最后用数学分析和实验比较成本。这里的可写为

$$
\mathcal C=(D,\ P,\ A,\ I,\ Q),
$$

其中$D$是输入域，$P$是前置条件，$A$是算法，$I$是循环或表示不变量，$Q$包含正确性与资源成本。只抄$A$会失去算法为何成立、何时适用、应与谁比较等核心信息。

### Chapter 1–2：共同语言与数据载体

Chapter 1建立算法描述、离散数学、算法分析、MIX机器模型与基本编程技术。它不是“数学附录”，而是后续各卷共同使用的语言。Chapter 2把记录组织成线性表、树、多链结构，并讨论垃圾回收和动态存储分配。表示选择改变操作成本：

$$
T_{\text{algorithm}}
=\sum_i c_i\,m_i,
$$

其中$m_i$是某类基本操作执行次数，$c_i$是在明确机器模型下的单位代价。抽象复杂度给增长趋势，机器级计数则解释常数和内存访问为何影响实际选择。

### Chapter 3–4：半数值算法

Chapter 3研究确定性状态如何生成随机数流，以及统计检验能证伪什么、不能证明什么；Chapter 4从位置记数制推进到浮点、多精度、有理数与多项式算术。两章共同提醒：数值结果必须附带表示约束。一个生成器即使周期很长，也可能在高维结构上失败；一个浮点公式即使实数恒等，也可能因舍入顺序不同而改变结果。

### Chapter 5–6：排序与搜索

Chapter 5把排列结构、内部排序、最优比较与外部存储统一到“建立次序”的问题；Chapter 6把顺序搜索、键比较、数字搜索、散列和次关键字检索统一到“利用结构定位记录”的问题。两章相互依赖：排序的预处理成本只有在后续查询足够多时才值得支付。

若一次排序成本为$S(n)$，未排序查询成本为$L(n)$，有序查询成本为$B(n)$，查询次数的盈亏点满足

$$
q\bigl(L(n)-B(n)\bigr)\ge S(n).
$$

这个不等式比“二分总比线性快”更完整，因为它同时计算建索引、数据更新与查询批量。

### Chapter 7：组合搜索为何分成4A和4B

Volume 4A从Boolean结构、位技巧和二元决策图进入元组、排列、组合、划分与树的系统生成。Volume 4B继续回溯编程，深入Dancing Links和Satisfiability。前者偏向不重不漏地枚举对象，后者偏向在巨大搜索空间中做选择、撤销、传播和学习。它们共享组合爆炸：

$$
|\{0,1\}^n|=2^n,
\qquad
|S_n|=n!,
$$

因此一个减少分支、避免重复或改善表示的想法，可能带来数量级而非百分比级的提升。

## 四层阅读证书


每个正式单元都要交付四种证据：

1. Specification：输入、输出、边界和失败语义明确。
2. Invariant：解释算法每一步保持什么，终止时为何得到正确结果。
3. Analysis：给出时间、空间、比较次数、内存访问或误差的可复查推导。
4. Experiment：实现参考算法，对小域穷举，对大域做确定种子的统计或性能实验。

尤其重要。链表图看起来连通不代表前驱后继互相一致；排序结果递增不代表记录多重集合没有丢失；SAT求解器返回一个赋值不代表每条子句都满足。每个视觉结论都必须落到可执行断言。

```ts
type Certificate<Input, Output> = {
  precondition: (input: Input) => boolean;
  run: (input: Input) => Output;
  postcondition: (input: Input, output: Output) => boolean;
  cost: (input: Input) => number;
};

function verify<I, O>(c: Certificate<I, O>, input: I) {
  if (!c.precondition(input)) throw new Error("outside domain");
  const output = c.run(input);
  if (!c.postcondition(input, output)) throw new Error("bad result");
  return { output, measuredCost: c.cost(input) };
}
```

## 小结

TAOCP当前验收语料是五个物理卷：Volume 1、2、3、4A、4B。逻辑上它们覆盖Chapter 1至7；教学上把跨卷的Chapter 7拆为4A与4B两个单元，因此共有8个原书单元。出版范围排除尚未合订的后续材料和未来卷，但保留它们作为路线信息。阅读每单元时，以分析契约串起说明、表示不变量、定量分析和实验，不把代码、复杂度或视觉图单独当成完成证据。
