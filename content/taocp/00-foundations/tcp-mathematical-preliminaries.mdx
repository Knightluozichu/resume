## 直觉引入

盖楼前要学好测量。算法分析的核心是「这个算法跑多快」，而回答这个问题需要数学工具——求和告诉你循环的总代价，递归告诉你分治算法的分裂模式，数论告诉你模运算的性质。

没有这些工具，你只能说「这个算法挺快的」；有了它们，你能精确地说「这个算法在最坏情况下是 $O(n \log n)$，平均是 $O(n)$」。

## 概念讲解

### 求和与增长趋势

<Term def="大 O 表示法描述函数渐近上界：f(n) = O(g(n)) 表示存在常数 C 和 n₀，使 n > n₀ 时 f(n) ≤ C·g(n)">大 O 表示法</Term>是算法分析的核心语言。它关心的是增长趋势而非精确值——$3n^2 + 5n + 100$ 和 $n^2$ 都是 $O(n^2)$，因为当 $n$ 足够大时，最高次项主导。

常见求和公式：

$$\sum_{k=1}^{n} k = \frac{n(n+1)}{2} = O(n^2)$$

这个式子在说：1 加到 n 等于 n(n+1)/2，增长趋势是平方级。

$$\sum_{k=0}^{n} 2^k = 2^{n+1} - 1 = O(2^n)$$

等比级数的和几乎是末项的两倍——这就是分治算法每层代价翻倍时的总代价。

### 递归关系

<Term def="递归关系是用函数在较小输入上的值来定义函数本身的等式，如 T(n) = 2T(n/2) + n">递归关系</Term>描述了分治算法的运行时间。求解递归关系是分析递归算法效率的关键步骤。

### 数论基础

<Term def="模运算是计算整数除法余数的运算，满足 (a+b) mod m = ((a mod m) + (b mod m)) mod m">模运算</Term>在密码学和随机数生成中至关重要。理解模运算的性质是后续学习 RSA 加密和线性同余随机数的基础。

<Stepper>
<Step title="第一步：写出递归式">
分治算法将大小为 $n$ 的问题分成 $a$ 个大小为 $n/b$ 的子问题，合并代价为 $f(n)$。递归式为 $T(n) = aT(n/b) + f(n)$。例如归并排序：$T(n) = 2T(n/2) + O(n)$。
</Step>
<Step title="第二步：展开递归">
将 $T(n/b)$ 继续展开，直到到达基准情形 $T(1)$。展开 $\log_b n$ 层后，每层的工作量形成几何级数。
</Step>
<Step title="第三步：求和验证">
把所有层的工作量加起来。如果每层工作量相同（如归并排序每层 $O(n)$，共 $\log n$ 层），总和为 $O(n \log n)$。用归纳法验证结果正确。
</Step>
</Stepper>

## 代码对照

```python
# 数学预备知识的代码验证
import math

# 1. 求和公式验证：sum(k) = n(n+1)/2
n = 100
assert sum(range(1, n+1)) == n * (n+1) // 2

# 2. 递归关系：归并排序 T(n) = 2T(n/2) + n
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])
    return merge(left, right)  # 合并代价 O(n)

# T(n) = 2T(n/2) + n => O(n log n)

# 3. 模运算性质验证
m = 7
a, b = 15, 23
assert (a + b) % m == ((a % m) + (b % m)) % m  # 5
assert (a * b) % m == ((a % m) * (b % m)) % m  # 1
```

## 常见误区

<Callout type="trap">
**误区：认为大 O 表示法给出的是算法的精确运行时间。**
大 O 只描述渐近上界（增长趋势），不含常数因子。$O(n)$ 的算法不一定比 $O(n^2)$ 快——当 $n$ 很小时，常数因子可能主导。大 O 回答的是「当 $n$ 趋向无穷时，谁更快」，而非「在任何输入下谁更快」。
</Callout>

<Callout type="trap">
**误区：递归关系的展开总是 straightforward 的。**
很多递归关系没有简单的闭式解。主定理只适用于特定形式（$T(n) = aT(n/b) + f(n)$），更复杂的递归需要生成函数或递归树方法。盲目套公式而不理解推导过程，遇到变体就会出错。
</Callout>

<Exercises>
**问题 1**：用数学归纳法证明 $\sum_{k=1}^{n} k = n(n+1)/2$。

<Answer>
归纳基础：$n=1$ 时，左边 = 1，右边 = 1×2/2 = 1，成立。归纳假设：假设 $n = m$ 时成立，即 $\sum_{k=1}^{m} k = m(m+1)/2$。归纳步骤：$n = m+1$ 时，$\sum_{k=1}^{m+1} k = m(m+1)/2 + (m+1) = (m+1)(m+2)/2$，即 $(m+1)((m+1)+1)/2$，成立。由归纳原理，对所有 $n \geq 1$ 成立。
</Answer>

**问题 2**：为什么大 O 表示法用上界而非精确值来描述算法效率？

<Answer>
因为算法的实际运行时间依赖于硬件、编译器、输入数据等众多因素，精确值难以跨平台比较。大 O 捕捉的是「增长趋势」这一本质特征，它消除了常数因子的干扰，让我们能公平地比较不同算法在规模足够大时的相对效率。此外，上界给出了最坏情况的保证，这对实时系统等场景至关重要。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="大 O 表示法">
描述函数渐近上界的数学记号。f(n) = O(g(n)) 表示存在常数 C 和 n₀，使 n > n₀ 时 f(n) ≤ C·g(n)。关注增长趋势而非精确值。
</GlossaryItem>
<GlossaryItem term="递归关系">
用函数在较小输入上的值来定义函数本身的等式，如 T(n) = 2T(n/2) + n。是分析递归算法效率的核心工具。
</GlossaryItem>
<GlossaryItem term="数学归纳法">
证明对所有自然数成立的命题的方法：先证基础情形（n=1），再假设 n=m 成立推导 n=m+1 也成立。
</GlossaryItem>
<GlossaryItem term="模运算">
计算整数除法余数的运算。满足 (a±b) mod m = ((a mod m) ± (b mod m)) mod m 和类似的乘法性质，是密码学的基础。
</GlossaryItem>
</Glossary>
