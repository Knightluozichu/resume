## 直觉引入

图书馆有两种藏书方式：一种按编号排列在书架上（线性表），一种按分类树层层展开（树结构），还有一种按主题交叉索引（多链结构）。选哪种取决于你怎么找书——按编号找用线性表，按类别浏览用树，按多个关键词交叉查找用多链结构。

信息结构就是数据的「藏书方式」。Knuth 之所以叫「信息结构」而非「数据结构」，是因为他强调的是信息的逻辑关系而非物理存储。

## 概念讲解

### 线性表

<Term def="线性表是元素排成一列的结构，每个元素有唯一前驱和后继（首尾除外）">线性表</Term>是最简单的信息结构。数组是其顺序存储实现，链表是其链式存储实现。

### 树结构

<Term def="树是层次化结构，有一个根节点，每个节点有零个或多个子节点，节点间通过边连接">树结构</Term>把线性的一对一关系扩展为一对多关系。二叉搜索树把查找从 $O(n)$ 降到 $O(\log n)$。

<Term def="多链结构是每个节点包含多个指针域的复杂信息结构，可表达多对多关系">多链结构</Term>是最通用的信息结构。正交表、稀疏矩阵、图都可用多链结构实现。

统计高频操作：如果主要是按下标访问，选数组 $O(1)$；如果频繁插入删除，选链表 $O(1)$；如果需要有序查找，选树 $O(\log n)$。
</Step>
<Step title="第二步：评估空间开销">
数组空间紧凑但需预分配或扩容；链表每个节点多一个指针（8 字节）；树需要左右两个指针。空间换时间还是时间换空间取决于场景。
</Step>
<Step title="第三步：考虑扩展性">
如果未来需要多维度查询（如按姓名和按年龄都能查找），多链结构或索引表比单一结构更灵活。静态数据用数组+排序，动态数据用平衡树。
</Step>
</Stepper>

## 代码对照

```python
# 三种信息结构的基本操作对比
from collections import deque
import bisect

# 1. 线性表（数组）—— 擅长随机访问
arr = [3, 1, 4, 1, 5, 9, 2, 6]
print(arr[3])  # O(1) 随机访问
bisect.insort(arr, 7)  # O(n) 有序插入

# 2. 树结构（二叉搜索树）—— 擅长有序查找
class TreeNode:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None

def bst_insert(root, val):
    if root is None:
        return TreeNode(val)
    if val < root.val:
        root.left = bst_insert(root.left, val)
    else:
        root.right = bst_insert(root.right, val)
    return root  # 平均 O(log n)

# 3. 多链结构（邻接表）—— 擅长关系查询
graph = {0: [1, 2], 1: [0, 3], 2: [0, 3], 3: [1, 2]}
```

## 常见误区

<Callout type="trap">
**误区：认为树结构总是比线性表好。**
树的优势是有序查找 $O(\log n)$，但代价是每个节点需要两个指针（更多内存）和更复杂的维护逻辑。如果数据量小或只需顺序遍历，数组更高效。树的指针跳转还会破坏 CPU 缓存局部性。
</Callout>

<Callout type="trap">
**误区：多链结构只用于图。**
多链结构不限于图。稀疏矩阵用十字链表（行链表+列链表）、数据库索引用 B+ 树（多路搜索树）、操作系统用多重链表管理空闲块。任何需要多维度访问的场景都适用。
</Callout>

<Exercises>
**问题 1**：什么场景下应该用链表而非数组？

<Answer>
频繁在头部或中间插入删除元素时用链表。链表插入删除 $O(1)$（已知位置），数组需要移动元素 $O(n)$。如果数据量未知且频繁增删，链表更优。但若需要随机访问或对缓存友好性要求高，数组更好。
</Answer>

**问题 2**：为什么 Knuth 用「信息结构」而非「数据结构」来描述这些概念？

<Answer>
Knuth 强调的是信息的逻辑组织关系——数据元素之间如何关联、如何被检索——而非具体的物理存储方式。同一个信息结构（如线性表）可以用不同物理方式实现（数组或链表）。「信息结构」更准确地反映了概念层面的抽象。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="线性表">
元素排成一列的结构，每个元素有唯一前驱和后继。数组和链表是其两种基本实现。
</GlossaryItem>
<GlossaryItem term="树结构">
层次化结构，有一个根节点，每个节点有零个或多个子节点。二叉搜索树支持 O(log n) 查找。
</GlossaryItem>
<GlossaryItem term="多链结构">
每个节点包含多个指针域的复杂信息结构，可表达多对多关系。适用于稀疏矩阵、图、正交表等场景。
</GlossaryItem>
<GlossaryItem term="信息结构">
Knuth 对数据结构的称呼，强调信息的逻辑组织关系而非物理存储方式。同一信息结构可有不同物理实现。
</GlossaryItem>
</Glossary>
