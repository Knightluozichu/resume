## 直觉引入

两个大整数相乘，本质上就是多项式乘法。$123 \times 456$ 可以看作 $(x^2 + 2x + 3) \times (4x^2 + 5x + 6)$ 在 $x = 10$ 处求值。如果多项式乘法能加速，大整数乘法也能加速——这就是 Knuth 讨论多项式运算的动机之一。

多项式有两种表示方式：系数表示（直观但乘法慢）和点值表示（乘法快但转换有成本）。快速傅里叶变换（FFT）让两者之间的转换从 $O(n^2)$ 降到 $O(n \log n)$。

## 概念讲解

### 系数表示与点值表示

<Term def="系数表示是用一组系数 (a₀, a₁, ..., aₙ₋₁) 描述多项式 A(x) = a₀ + a₁x + ... + aₙ₋₁xⁿ⁻¹">系数表示</Term>是最直觉的多项式表示。两个 $n$ 次多项式的系数表示相乘需要 $O(n^2)$ 次coef乘法。

<Term def="点值表示是用 n 个点 (x₀,y₀), (x₁,y₁), ..., (xₙ₋₁,yₙ₋₁) 描述多项式，其中 yᵢ = A(xᵢ)">点值表示</Term>的优势是乘法只需 $O(n)$——对应点的 $y$ 值相乘即可。

### FFT 加速

<Term def="快速傅里叶变换（FFT）利用单位根的对称性，在 O(n log n) 时间内完成多项式系数表示与点值表示的转换">FFT</Term>是多项式算法的里程碑。它选择 $n$ 次单位根 $\omega_n^k = e^{2\pi i k / n}$ 作为求值点，利用对称性将 $O(n^2)$ 的求值降到 $O(n \log n)$。

### 幂级数

<Term def="幂级数是形如 sum(aₙxⁿ) 的无穷级数，在算法分析中用于生成函数和递归关系的求解">幂级数</Term>在算法分析中扮演生成函数的角色。Fibonacci 数列的生成函数为：

$$F(x) = \frac{x}{1 - x - x^2}$$

展开后系数就是 Fibonacci 数。

<Step title="第一步：补零到 2n 项">
两个 $n$ 次多项式相乘结果是 $2n-1$ 次。将两个多项式补零到 $N = 2n$ 项（N 是 2 的幂），为 FFT 做准备。
</Step>
<Step title="第二步：FFT 转点值">
对两个多项式分别做 FFT，从系数表示转为点值表示。利用单位根的对称性，每层递归将问题规模减半，总复杂度 $O(N \log N)$。
</Step>
<Step title="第三步：点值相乘 + IFFT">
在点值表示下，乘法只需 $O(N)$（对应 $y$ 值相乘）。然后用逆 FFT（IFFT）转回系数表示，复杂度 $O(N \log N)$。总复杂度 $O(N \log N)$，远优于朴素 $O(n^2)$。
</Step>
</Stepper>

## 代码对照

```python
# 多项式乘法：朴素 vs FFT
import numpy as np

# 1. 朴素系数乘法 O(n²)
def poly_mul_naive(A, B):
    n, m = len(A), len(B)
    result = [0] * (n + m - 1)
    for i in range(n):
        for j in range(m):
            result[i + j] += A[i] * B[j]
    return result

print(poly_mul_naive([1, 2, 3], [4, 5, 6]))  # [4, 13, 28, 27, 18]

# 2. FFT 乘法 O(n log n)
def poly_mul_fft(A, B):
    n = len(A) + len(B) - 1
    N = 1 << (n - 1).bit_length()  # 补到 2 的幂
    # FFT 转点值
    fa = np.fft.fft(A, N)
    fb = np.fft.fft(B, N)
    # 点值相乘
    fc = fa * fb
    # IFFT 转回系数
    result = np.round(np.fft.ifft(fc).real).astype(int)
    return result[:len(A) + len(B) - 1].tolist()

print(poly_mul_fft([1, 2, 3], [4, 5, 6]))  # [4, 13, 28, 27, 18]

# 3. 大整数乘法 = 多项式乘法 + 进位
# 123 * 456 = poly_mul([3,2,1], [6,5,4]) 然后进位
```

## 常见误区

<Callout type="trap">
**误区：认为 FFT 总是比朴素乘法快。**
FFT 有常数因子较大的开销（复数运算、递归/迭代框架）。当多项式次数很小时（如 $n < 64$），朴素 $O(n^2)$ 乘法由于常数小反而更快。实际实现中常用阈值切换：小规模用朴素，大规模用 FFT。
</Callout>

<Callout type="trap">
**误区：认为点值表示的求值点可以任意选择。**
FFT 选择 $n$ 次单位根作为求值点，是因为它们的对称性（$\omega_n^{k+n/2} = -\omega_n^k$）使得递归可以减半。任意选择求值点虽然也可以做插值，但求值和插值都退化为 $O(n^2)$，失去 FFT 的加速效果。
</Callout>

<Exercises>
**问题 1**：为什么 FFT 将多项式乘法从 O(n²) 降到 O(n log n)？

<Answer>
FFT 的核心是选择 $n$ 次单位根作为求值点。单位根的对称性（$\omega_n^{k+n/2} = -\omega_n^k$）使得 DFT 可以分治：将 $n$ 点 DFT 分解为两个 $n/2$ 点 DFT，每层 $O(n)$，共 $\log n$ 层，总计 $O(n \log n)$。朴素方法对 $n$ 个点各求一次值，每次 $O(n)$，总计 $O(n^2)$。FFT 利用了单位根的特殊性质避免了重复计算。
</Answer>

**问题 2**：用系数乘法计算 (1+2x+3x²) × (4+5x+6x²) 的结果。

<Answer>
结果系数：$c_0 = 1×4 = 4$；$c_1 = 1×5+2×4 = 13$；$c_2 = 1×6+2×5+3×4 = 28$；$c_3 = 2×6+3×5 = 27$；$c_4 = 3×6 = 18$。结果为 $4 + 13x + 28x^2 + 27x^3 + 18x^4$。验证：$123 × 456 = 56088$，而 $4 + 130 + 2800 + 27000 + 18000 = 56088$ ✓。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="系数表示">
用一组系数 (a₀, a₁, ..., aₙ₋₁) 描述多项式的方式。直觉但乘法 O(n²)。
</GlossaryItem>
<GlossaryItem term="点值表示">
用 n 个点 (xᵢ, yᵢ) 描述多项式的方式。乘法只需 O(n)（对应 y 值相乘），但转换有成本。
</GlossaryItem>
<GlossaryItem term="FFT">
快速傅里叶变换，利用单位根对称性在 O(n log n) 内完成系数与点值表示的转换。
</GlossaryItem>
<GlossaryItem term="幂级数">
形如 sum(aₙxⁿ) 的无穷级数，在算法分析中用作生成函数，可用于求解递归关系。
</GlossaryItem>
