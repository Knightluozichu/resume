## 从“回头再试”为什么不足以成为算法开始

先预测：N皇后求解器找到一个合法棋盘，能否说明它枚举完整？一个 SAT 求解器返回`UNSAT`，没有冲突证据时能否相信？组合算法第二部分（combinatorial algorithms part 2）研究的不是模糊的“试错”，而是带契约的搜索：节点表示合法部分状态，分支覆盖所有尚未决定的可能，传播只推出逻辑后果，剪枝不会删除可行解，撤销精确恢复父状态。

Volume 4B 的路线是 mathematical preliminaries redux（数学预备再访）、backtrack programming（回溯编程）、dancing links（舞蹈链）、satisfiability（可满足性）和 clause-learning algorithms（子句学习算法）。它把 Volume 4A 的无条件生成改造成有约束搜索，再把失败分支提炼成可复用知识。


## 数学预备再访：对象空间、部分状态与见证

一个约束问题由变量、取值域和约束组成。完整赋值若满足全部约束就是解；部分赋值只决定部分变量，其意义在于描述仍可能扩展成解的一组完整对象。搜索树节点存部分赋值，边存一个选择，叶要么给出解见证，要么给出不能扩展的冲突见证。


若每层平均分支因子为 $b$、深度为 $d$，无剪枝完整树规模为：

$$
L=b^d,\qquad N=1+b+\cdots+b^d=\frac{b^{d+1}-1}{b-1}.
$$

指数项说明微小剪枝改进可以胜过局部常数优化，但也说明错误剪枝会系统性漏解。完备性论证通常归纳于深度：每个完整解在当前变量处恰好属于一个分支，该分支未被不可靠规则删除。

不应复制整个问题。占用列集合、剩余容量、未满足子句计数等增量摘要能让检查接近每次选择的局部成本，但撤销日志必须覆盖每个被修改字段。

## 回溯编程：选择、传播、递归、撤销

的标准骨架把状态修改包围在严格作用域内：

```python
def search(state):
    propagate(state)
    if state.conflict:
        return
    if state.complete:
        emit(state.witness())
        return
    choice = choose(state)
    for value in domain(choice):
        mark = state.mark()
        state.assign(choice, value)
        search(state)
        state.undo(mark)
```

`mark/undo`比“凭记忆反做一次”可靠，因为传播可能修改许多间接状态。持久化数据结构用新版本替代撤销日志，也能保持父状态，但会增加分配和垃圾回收成本。

### N皇后与增量冲突集合

N皇后每行放一个皇后，只需维护已占列、主对角线`row-column`和副对角线`row+column`。这三组标识构成部分状态不变量：已有皇后互不攻击。选择新列前即可拒绝冲突，不必等完整棋盘再检查。


合法棋盘是 SAT 见证式证据：逐行坐标可独立验证。若要计数全部解，还需证明每行分支覆盖所有列、冲突判断等价于攻击条件，并将结果与已知小规模计数交叉核对。

### 剪枝、界与优化目标

用于优化问题。最大化时上界必须大于等于该分支所有完成解；若低估上界，可能删掉真正最优解。分数背包松弛允许切分物品，因此给0/1背包提供可计算上界。


$$
UB(s)\ge \max_{x\text{ extends }s}f(x),\qquad UB(s)\le incumbent\Longrightarrow prune(s).
$$

可行性剪枝证明“没有任何扩展能满足约束”，界剪枝证明“扩展不可能改进目标”，两者证据不同。良好分支顺序尽早找到强 incumbent，会让同一个正确上界剪掉更多节点。

### 对称破除

若群作用把多个状态映射为等价解，只保留每个轨道的规范代表可减少搜索。互补位串可选择数值较小者，N皇后可利用镜像，但有自对称对象时不能简单把计数一律乘二。


对称约束必须保证每个等价类至少保留一个状态。优化问题还要保证目标函数在对称变换下不变；否则两个可行状态虽然结构相似，却不等价。

## 精确覆盖与 Algorithm X

可写成零一矩阵：列代表约束，行代表候选，目标是选行使每列和恰好为一。仅检查“每列至少一次”会把冲突行误判为解。


$$
\sum_{r:A_{rc}=1}x_r=1\quad\text{for every primary column }c,\qquad x_r\in\{0,1\}.
$$

Algorithm X 选择一个未覆盖列，对含一的每个候选行建立分支；选中行后覆盖它所含的全部列，并删除与这些列冲突的其他行。若没有列，当前行集是解；若某列没有候选行，当前分支冲突。

### Dancing Links 的可逆稀疏矩阵

（DLX）不是新的搜索逻辑，而是 Algorithm X 的状态表示。每个一节点同时属于行环和列环，列头记录当前候选数。cover 先摘列头，再逐行摘除冲突节点；uncover 必须严格逆序插回。


```text
cover(c):
  unlink column header c
  for each row r in c:
    for each node j in r except c:
      unlink j vertically; decrement j.column.size

uncover(c):
  visit rows and row nodes in reverse order
  relink each node; increment its column size
  relink column header c
```

选择候选数最少的列是 fail-first 启发式：它不改变解集合，只减少平均分支数。指针结构验收需在随机 cover/uncover 序列后逐列遍历，检查左右、上下互逆、列计数和矩阵内容完全恢复。

## 可满足性：从 CNF 求值到 DPLL

（CNF）把 SAT 写为“每个子句至少一个真文字”。完整赋值很容易验证；难点是从部分赋值高效判断已满足、未决定、单位或冲突子句。


### 单元传播与理由

若一个未满足子句除一个文字外都为假，剩余文字必须为真，这就是 unit propagation（单元传播）。传播得到的赋值要记录理由子句和决策层级，既用于冲突分析，也用于撤销到某个 trail 标记。


纯文字消除、子句包含和变量消去也可简化公式，但若需要输出模型或 UNSAT 证明，预处理步骤必须能重建见证。传播固定点意味着当前没有单位子句，不意味着公式已可满足。

### DPLL 的完备分支

把回溯骨架实例化为 SAT。若传播不冲突且所有子句满足，就得到模型；否则选择变量 $x$，递归搜索 $F|_{x=0}$ 与 $F|_{x=1}$。两个分支覆盖所有赋值，故搜索完备。


```ts
function dpll(formula: Formula, trail: Trail): Model | null {
  if (!propagate(formula, trail)) return null;
  if (formula.isSatisfied(trail)) return trail.model();
  const variable = chooseUnassigned(formula, trail);
  return branch(variable, false) ?? branch(variable, true);
}
```

变量与极性启发式影响速度但不影响正确性，前提是冲突后仍覆盖未探索分支。现代求解器使用活动度、相位保存和重启；重启清除决策 trail，却保留学到的子句。

## Watched literals：让传播只触碰相关子句

避免每次赋值重扫全部子句。若一个 watch 变假，优先找另一个不假的未监视文字；找不到时，另一 watch 为真则子句满足，为未赋值则成为单位，为假则冲突。


watch 的关键不变量不是“监视两个真文字”，而是只要子句尚非单位/冲突，就有足够的非假候选支持延迟访问。回溯把文字从假恢复为未赋值时通常无需移动 watch，这种单向更新正是效率来源。

## 蕴含图与冲突分析

传播文字是图节点，理由子句从使其成为单位的假文字连到该节点；决策文字没有理由。冲突可视为某变量两极同时被迫成立。节点携带决策层级，使求解器能区分当前分支原因与更早祖先条件。


resolution（消解）从含 $x$ 的子句和含 $\neg x$ 的子句消去 $x$：

$$
(A\lor x)\land(B\lor\neg x)\Longrightarrow(A\lor B).
$$

反复把冲突子句与当前层传播文字的理由消解，直到学到子句在当前层只含一个文字，得到 first UIP 子句。它在回跳到次高层后立即成为单位，阻止相同冲突区域再次出现。

### 子句学习与非时间顺序回跳

clause-learning algorithms（子句学习算法）把失败分支变成新约束。学到子句必须由原公式和已有学习子句逻辑蕴含，因此不会删除任何模型；它同时给出回跳层级，即除当前层文字外最高的决策层。


无限保留所有学习子句会拖慢传播，所以求解器按活动度、长度或 LBD 周期删除低价值子句，但通常保留锁定为当前理由的子句。UNSAT 证明可记录每个学习子句的消解依据，最终导出空子句。


## 检验矩阵与失败复现

回溯实现要测试空问题、立即冲突、唯一解、多解、深层冲突、撤销后重走兄弟分支和对称固定点。DLX 随机 cover 后逆序 uncover 必须逐指针恢复。SAT 对小变量公式穷举所有赋值作为 oracle，比较求解结果；再加入重复文字、重言式、空子句和长传播链。子句学习需逐条验证 resolvent，回跳后学到子句应成为单位。

## 小结

Volume 4B 把组合搜索组织为可验证状态机：部分赋值定义节点，传播推出必然后果，分支保证覆盖，剪枝给出证明，trail或Dancing Links保证可逆，模型或冲突子句提供见证。SAT进一步用watched literals降低传播成本，用蕴含图解释冲突，用子句学习和非时间回跳复用失败信息。可靠求解器的标准不是“很快找到答案”，而是每个删减与回退都不破坏解空间语义。
