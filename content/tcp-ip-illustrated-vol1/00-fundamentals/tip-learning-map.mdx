## TCP/IP 四层模型

### 四层模型与协议对应

| 层级 | 核心协议 | 职责 | 对应章节 |
|------|----------|------|---------|
| 应用层 | HTTP/DNS/SMTP/FTP | 业务数据格式 | ch8 |
| 传输层 | TCP/UDP | 端到端通信、可靠传输 | ch4-6 |
| 网络层 | IP/ICMP/IGMP | 路由、寻址、差错报告 | ch2-3,7 |
| 链路层 | 以太网/ARP | 物理寻址、帧传输 | ch1 |

### 封装与解封装

数据在发送方**逐层向下封装**（每层加头），在接收方**逐层向上解封装**（每层剥头）：

```text
发送方（封装）：
  应用层数据
  → 加 TCP/UDP 头（传输层段）
  → 加 IP 头（网络层包）
  → 加以太网帧头尾（链路层帧）
  → 物理比特流传输

接收方（解封装）：
  物理比特流
  → 剥帧头 → IP 包
  → 剥 IP 头 → TCP/UDP 段
  → 剥 TCP/UDP 头 → 应用数据
```

<Callout type="info" title="为什么从链路层开始学">

TCP/IP 协议栈是自底向上构建的——链路层解决「物理上怎么传」，网络层解决「怎么路由到目的」，传输层解决「怎么可靠传输」，应用层解决「业务数据格式」。理解下层机制（如 ARP 解析 MAC、IP 路由转发）是理解上层行为（如 TCP 连接、HTTP 请求）的前提。

</Callout>

## TCP/IP 与 OSI 模型对应

| TCP/IP 四层 | OSI 七层 | 说明 |
|------------|---------|------|
| 应用层 | 应用层+表示层+会话层（5-7） | 合并上三层 |
| 传输层 | 传输层（4） | 一一对应 |
| 网络层 | 网络层（3） | 一一对应 |
| 链路层 | 数据链路层+物理层（1-2） | 合并下两层 |

<Glossary>

<GlossaryItem term="TCP/IP 协议栈（TCP/IP Protocol Stack）">
TCP/IP 协议栈是互联网的基础通信架构，分为四层：链路层（以太网/ARP——物理寻址与帧传输）、网络层（IP/ICMP/IGMP——路由寻址与差错报告）、传输层（TCP/UDP——端到端通信）、应用层（HTTP/DNS/SMTP等——业务数据格式）。数据发送时逐层向下封装（每层加头部），接收时逐层向上解封装（每层剥头部）。每一层为上层提供服务，同时依赖下层的功能。TCP/IP 模型比 OSI 七层模型更简洁实用，是实际互联网运行的标准。
</GlossaryItem>

<GlossaryItem term="封装与解封装（Encapsulation / Decapsulation）">
封装是发送方将上层数据加上本层头部（及尾部）转为下层协议数据单元的过程：应用数据 → TCP/UDP段（加传输层头）→ IP包（加网络层头）→ 以太网帧（加链路层头尾）。解封装是接收方的逆过程：逐层剥离头部，将 Payload 交给上层。每层只处理本层头部，上层数据作为本层 Payload。封装使各层独立演进——IP 层不关心上层是 TCP 还是 UDP，链路层不关心上层是 IP 还是 ARP。
</GlossaryItem>

<GlossaryItem term="MTU（Maximum Transmission Unit）">
最大传输单元是链路层一次能承载的最大数据 payload 长度。以太网 MTU=1500 字节。当 IP 包总长度超过 MTU 时，路由器将包分片传输（除非 DF 标志禁止分片）。MTU 影响网络效率：MTU 太小则头部开销占比大，太大则分片概率高。Path MTU Discovery（PMTUD）通过设 DF=1 并利用 ICMP 差错报文发现路径上最小 MTU，使源端发送的包无需分片即可到达目的。
</GlossaryItem>

<GlossaryItem term="协议数据单元（PDU）">
协议数据单元是各层的数据封装单位：链路层 PDU = 帧（Frame，含以太网头+IP包+FCS）；网络层 PDU = 包/数据报（Packet/Datagram，含IP头+传输层段）；传输层 PDU = 段（TCP Segment）或数据报（UDP Datagram，含传输层头+应用数据）；应用层 PDU = 报文（Message）。每层 PDU 的头部包含本层控制信息（如地址、序号、校验），Payload 是上层的 PDU。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1：** TCP/IP 协议栈的四层模型分别是什么？每层的主要协议有哪些？

<Answer>

TCP/IP 四层模型：①链路层——以太网、ARP，负责物理寻址与帧传输 ②网络层——IP、ICMP、IGMP，负责路由与寻址 ③传输层——TCP、UDP，负责端到端通信 ④应用层——HTTP、DNS、SMTP、FTP，负责具体业务数据格式。数据发送时逐层向下封装（加头），接收时逐层向上解封装（剥头）。

</Answer>

**问题 2：** 数据在 TCP/IP 协议栈中是如何逐层封装和解封装的？

<Answer>

封装（发送方）：应用层数据 → 传输层加 TCP/UDP 头 → 网络层加 IP 头 → 链路层加以太网帧头尾，逐层向下传递。解封装（接收方）：链路层剥离帧头 → 网络层剥离 IP 头 → 传输层剥离 TCP/UDP 头 → 应用层拿到原始数据。每层只处理本层头部，上层数据作为下层 Payload。

</Answer>

</Exercises>
