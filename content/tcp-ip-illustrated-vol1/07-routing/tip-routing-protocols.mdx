## 路由协议分类

<TipRoutingProtocolsDiagram />

### 按自治系统范围分类

```text
路由协议
  ├── IGP（内部网关协议）——AS 内部
  │     ├── RIP（距离矢量）
  │     └── OSPF（链路状态）
  └── EGP（外部网关协议）——AS 之间
        └── BGP（路径矢量）
```

### 按算法分类

| 类型 | 代表 | 原理 | 特点 |
|------|------|------|------|
| 距离矢量 | RIP | 只知道距离+方向，周期发路由表 | 简单，收敛慢 |
| 链路状态 | OSPF | 全网拓扑，各自算最短路径 | 复杂，收敛快 |
| 路径矢量 | BGP | 记录 AS 路径，策略路由 | 可扩展，支持策略 |

## RIP（距离矢量）

### 工作原理

```text
度量：跳数（每经过一个路由器+1）
限制：最大 15 跳，16 跳=不可达
更新：每 30 秒广播完整路由表给邻居
算法：Bellman-Ford
```

### 计数到无穷问题

```text
网络 N 断开后：
  路由器 A：N 不可达（距离16）
  路由器 B：从 A 学到 N（距离17=不可达）
  但 B 可能先告诉 C：N 距离 2（旧的）
  C 告诉 A：N 距离 3
  A 告诉 B：N 距离 4
  ... 距离不断累加，直到 16 才收敛
```

### 缓解措施

| 措施 | 原理 |
|------|------|
| 水平分割 | 不将从某邻居学到的路由发回给该邻居 |
| 毒化逆转 | 发回时设为不可达（16跳），加速收敛 |
| 触发更新 | 拓扑变化时立即发送更新，不等周期 |
| 保持计时器 | 收到不可达信息后暂时不接收该路由更新 |

## OSPF（链路状态）

### 工作原理

```text
1. 发现邻居：发送 Hello 包建立邻接关系
2. 泛洪 LSA：将自身链路状态通告给整个区域
3. 构建 LSDB：所有路由器收到全部 LSA，形成相同的链路状态数据库
4. 计算路由：各自用 Dijkstra 算法计算最短路径树
5. 生成路由表：从最短路径树导出路由表
```

### 区域划分

```text
OSPF 分层架构：
  骨干区域（Area 0）——所有区域必须连接到骨干
  非骨干区域（Area 1, 2, ...）——内部拓扑变化不扩散到其他区域

区域边界路由器（ABR）：连接骨干与非骨干
自治系统边界路由器（ASBR）：连接外部 AS

优势：
  - 减少 LSA 泛洪范围
  - 缩小 LSDB 规模
  - 降低 Dijkstra 计算复杂度
```

### OSPF 关键参数

```text
度量：带宽代价 cost = 10^8 / 带宽(bps)
组播地址：224.0.0.5（所有 OSPF 路由器）
         224.0.0.6（DR/BDR）
协议号：89
```

## BGP（路径矢量）

### 工作原理

```text
用途：AS 间路由，互联网骨干的核心协议
传输：TCP 端口 179（可靠传输）
度量：路径属性（非单一数值）
算法：路径矢量

关键属性：
  AS_PATH：经过的 AS 列表（防环）
  LOCAL_PREF：本地优先级（选路策略）
  MED：多出口鉴别器（影响入站选路）
  NEXT_HOP：下一跳地址
```

### BGP 选路过程

```text
1. 收到邻居通告的路由（含 AS_PATH 等属性）
2. 按属性优先级选路：
   ① LOCAL_PREF 最高
   ② AS_PATH 最短
   ③ ORIGIN 最优
   ④ MED 最低
   ⑤ NEXT_HOP 最近
3. 将最优路由安装到路由表
```

## 路由协议对比

| 特性 | RIP | OSPF | BGP |
|------|-----|------|-----|
| 算法 | 距离矢量 | 链路状态 | 路径矢量 |
| 度量 | 跳数 | 带宽代价 | 路径属性 |
| 范围 | IGP（小型） | IGP（大型） | EGP（AS间） |
| 传输 | UDP 520 | IP 协议号 89 | TCP 179 |
| 收敛速度 | 慢 | 快 | 中 |
| 可扩展性 | 差 | 中 | 好 |

<Glossary>

<GlossaryItem term="RIP（Routing Information Protocol）">
RIP 路由信息协议是距离矢量路由协议。度量用跳数（max 15，16=不可达），每 30 秒广播完整路由表给邻居，用 Bellman-Ford 算法。问题：计数到无穷（网络断开时距离不断累加直到 16 才收敛）。缓解措施：水平分割（不将邻居路由发回）、毒化逆转（发回时设不可达）、触发更新（变化时立即发送）。版本：RIPv1（广播）、RIPv2（组播+VLSM+认证）。适合小型网络。
</GlossaryItem>

<GlossaryItem term="OSPF（Open Shortest Path First）">
OSPF 开放式最短路径优先是链路状态路由协议。每个路由器通过 LSA 泛洪了解全网拓扑，构建相同 LSDB，各自用 Dijkstra 算法计算最短路径树。度量用带宽代价（cost=10^8/bw）。支持区域划分：骨干区域（Area 0）+ 非骨干区域，减少 LSA 泛洪和计算量。组播地址 224.0.0.5/6，协议号 89。收敛快，适合大型网络。触发更新+周期性刷新（30分钟）。
</GlossaryItem>

<GlossaryItem term="BGP（Border Gateway Protocol）">
BGP 边界网关协议是 AS 间路由协议，是互联网骨干的核心。用 TCP 端口 179 可靠传输。是路径矢量协议，核心属性 AS_PATH 记录经过的 AS 列表（防环）。选路按 LOCAL_PREF→AS_PATH 长度→ORIGIN→MED→NEXT_HOP 等属性优先级决策，支持丰富的策略路由。BGP-4 支持 CIDR，是当前互联网使用的版本。适合超大规模网络，收敛速度中等。
</GlossaryItem>

<GlossaryItem term="距离矢量 vs 链路状态">
距离矢量协议（RIP）：路由器只知道到各目的的距离和下一跳方向，周期性将整个路由表发给邻居，用 Bellman-Ford 算法——「听说」路由。问题：计数到无穷、收敛慢。链路状态协议（OSPF）：路由器了解整个网络拓扑（通过 LSA 泛洪），各自独立用 Dijkstra 算法计算最短路径——「看见」全图。优势：收敛快、无计数到无穷、可扩展到大型网络，但开销更大。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1：** 距离矢量路由协议（RIP）和链路状态路由协议（OSPF）的核心区别是什么？

<Answer>

距离矢量（RIP）：每个路由器只知道自己到各目的网络的距离（跳数）和下一跳方向，周期性将整个路由表发给邻居，用 Bellman-Ford 算法——「听说」路由。问题：计数到无穷、收敛慢。链路状态（OSPF）：每个路由器了解整个网络拓扑（通过 LSA 泛洪），各自用 Dijkstra 算法独立计算最短路径——「看见」全图。OSPF 收敛快、可扩展到大型网络。

</Answer>

**问题 2：** BGP 协议的作用是什么？它与 IGP 有什么区别？

<Answer>

BGP 是 AS 间路由协议，负责在不同 AS 之间交换可达性信息，是互联网骨干的核心路由协议。与 IGP 的区别：①范围——IGP 在 AS 内部运行，BGP 在 AS 之间运行 ②度量——IGP 用跳数/带宽等单一度量，BGP 用路径属性做策略路由 ③传输——IGP 直接用 IP 封装，BGP 用 TCP 端口 179 ④规模——IGP 适合中小型网络，BGP 支撑全球互联网路由表。

</Answer>
