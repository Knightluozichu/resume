## 表里没有这一行时怎么办

记录了几个输入及其结果，不等于知道其他输入的结果。如果只会翻表，表里没有的一行就无从回答；如果给出一条可计算的规则，就能产生新答案，却也承担了规则选错的风险。

本页用一组原创的小数值例子，把“选哪种规则”“调哪些数”“拿什么检验”分开。它们不运行语言模型，也不推断当前 ChatGPT 的内部规格。

## What Is a Model? / 什么是模型？

这是本页唯一的正式目录坐标。作者2023年公开文章的这一节从记住观测与计算新输入的差别出发，强调任何模型都有某种结构和可调的数。本页保留这个问题，但不用原文的落体数据、图像或代码，另造可以逐项验算的例子。

### 先选结构，再谈调整

<Term def="允许哪些计算形式的一组规则；改变其结构就改变了可选择的规则范围。">
  模型族
</Term>
不是某一条已选好的曲线。例如，所有一次多项式组成一族，所有二次多项式又组成另一族。即使数据相同，允许的形式不同，最好的拟合也可能不同。

<Term def="固定模型结构后，可以调整的数；这里是多项式各项的系数。">参数</Term>
则是在族内选择具体规则的数。记输入为 $x$、阶数为 $d$、系数向量为
$\theta=(\theta_0,\ldots,\theta_d)^T$：

$$
f_\theta(x)=\sum_{j=0}^{d}\theta_j x^j.
$$

人话是：先决定最多用到几次幂，再决定每一项乘多少。$d=2$ 时有三个系数；把 $\theta$ 改掉不会增加一列，把 $d$ 从1改成2才会增加 $x^2$ 这一项。这里的三个参数只是玩具系数，不能与真实语言模型的参数量作比例换算。

模型的用途是按固定规则对输入计算输出。选一个简单族可以减少自由度，但简单本身不是正确性的保证；选复杂族增加了可表示的关系，也没有自动获得对新数据的保证。这两点将在第三个实验形成数值对照。

## 从幂基到设计矩阵

<Term def="把每个输入代入各个基函数后排成的表；每行一个样本，每列一种基函数。">
  设计矩阵
</Term>
把计算组织得更清楚。这里按样本排列行，按 $1,x,x^2$ 排列列；$x^0$
按多项式常数项定义为1，包括
$x=0$。矩阵是数学上的行列表示，不涉及某个库的内存存储顺序。

$$
\Phi_{ij}=x_i^j\quad(j=0,\ldots,d),\qquad
\Phi=\begin{bmatrix}1&-1&1\\1&0&0\\1&1&1\end{bmatrix},\quad
\theta=\begin{bmatrix}1\\1\\1\end{bmatrix},\quad
\hat y=\Phi\theta=\begin{bmatrix}1\\1\\3\end{bmatrix}.
$$

中间一行表示 $x=0$：只有常数项留下，所以输出是1。若把第一列误写为0，每个预测都少掉 $\theta_0$；此例变成 $[0,0,2]$。错误已经发生在输入表示阶段，不是之后的拟合算法“没学好”。

> 先预测，再操作：保持三个系数都是1，把输入改成 $[0,1,2]$，二次规则输出什么？切成一次后，哪一项消失？

这个实验只把给定系数乘进矩阵，没有根据答案寻找系数。换一组基函数会换表示；在本页固定幂基后，改变系数、改变阶数、破坏常数列是三种不同操作。

### 用标准库重算每一行

下面所有 `python` 块按出现顺序拼接，就是一个完整程序；不需要下载数据、安装库或调用模型接口。先用标准库 `Fraction` 保存精确分数，避免把浮点近似的零误认成数学上的零。

```python
from fractions import Fraction as F


def dot(a, b):
    assert len(a) == len(b)
    return sum((u * v for u, v in zip(a, b)), F(0))


def basis(xs, degree, broken=False):
    return [[F(0) if broken and j == 0 else x ** j
             for j in range(degree + 1)] for x in xs]


def predict(theta, x):
    return sum((c * x ** j for j, c in enumerate(theta)), F(0))


xs, theta = list(map(F, [-1, 0, 1])), list(map(F, [1, 1, 1]))
assert [dot(r, theta) for r in basis(xs, 2)] == [1, 1, 3]
assert [dot(r, theta) for r in basis(xs, 2, True)] == [0, 0, 2]
```

`basis` 的故障与界面一致：它真正修改第一列，不是只改一条警告。接下来换一个问题：如果系数还不知道，如何选择它？

## 把拟合看成离观测最近的投影

<Term def="选择参数，使预测与观测之差的平方和最小的准则。">最小二乘</Term>
是一种选择参数的办法，不是模型结构本身。用 $y$ 表示观测向量，$\hat y$
表示预测，残差 $r=y-\hat y$ 表示尚未解释的差：

$$
\operatorname{SSE}(\theta)=\lVert y-\hat y\rVert^2=\sum_i(y_i-\hat y_i)^2.
$$

平方把正负差都计入代价。此处是未加权平方和；不同观测的重要性相同，也没有额外惩罚项。把它最小化，仅表示在这个族、这些观测、这个准则下最接近。

### 两条观测构成一个二维空间

为了看到几何，不先做复杂曲线。设只有一个参数、两条观测，固定方向 $a=(a_1,a_2)^T\ne0$，允许的预测是 $\hat y=\theta a$。图中的横、纵轴分别是**观测1的数值、观测2的数值**，不是通常函数图上的 $x,y$。所有候选预测落在穿过原点的一条直线上。

展开平方和，再令导数为零：

$$
\operatorname{SSE}=y\cdot y-2\theta(a\cdot y)+\theta^2(a\cdot a),\qquad
\frac{d\operatorname{SSE}}{d\theta}=-2a\cdot y+2\theta(a\cdot a)=0
\quad\Rightarrow\quad\theta^*=\frac{a\cdot y}{a\cdot a}.
$$

因为 $a\cdot a>0$，这是唯一的最小值，而不是最大值。把它代回残差，得到 $a\cdot r=a\cdot y-\theta^*(a\cdot a)=0$：残差与模型直线垂直。正交是可检验的最优性条件；不意味着残差为零，更不意味着找到了现实原因。

例如 $a=(1,1)$、$y=(2,0)$ 时，$\theta^*=1$，预测为 $(1,1)$，残差为 $(1,-1)$，平方和为2。故意用 $\theta=2$，预测移到 $(2,2)$，平方和变成4，且 $a\cdot r=-2$，不再正交。下图第三步显示这条残差和参考解的直角标。

这里没有截距、没有多参数平面、没有梯度训练。完整的多项式最小二乘也有投影解释，但要投影到设计矩阵列张成的子空间；不能把这幅二维线图误当作任意网络的训练轨迹。

### 精确检查垂足与错误参数

下面直接执行刚才的式子。第二组输入会让垂足非常靠近观测点，距离小仍然不必等于零。

```python
def project(a, y, broken=False):
    optimum = dot(a, y) / dot(a, a)
    theta = optimum + int(broken)
    fitted = [theta * u for u in a]
    residual = [v - u for v, u in zip(y, fitted)]
    return theta, fitted, residual, dot(residual, residual)


a, y = list(map(F, [1, 1])), list(map(F, [2, 0]))
t, fitted, r, sse = project(a, y)
assert (t, fitted, r, sse) == (1, [1, 1], [1, -1], 2)
assert dot(a, r) == 0
assert project(a, y, True)[3] == 4

a, y = list(map(F, [1, 2])), list(map(F, [1, 3]))
t, fitted, r, sse = project(a, y)
assert t == F(7, 5) and sse == F(1, 5)
assert dot(a, r) == 0
assert project(a, y, True)[3] == F(26, 5)
assert dot(a, project(a, y, True)[2]) == -5
```

代码不搜索很多候选值，而是精确算出垂足并验证正交。界面的错误模式则沿模型直线偏移一个参数单位，改变的是实际几何与误差。

## 能拟合，不等于能走出样本范围

<Term def="把已选规则用于观测输入范围之外；这需要额外检验，不能由范围内拟合自动保证。">
  外推
</Term>
与范围内的新点检验不同。为把两者分开，本页指定一个完全已知的人工世界
$f(x)=1+x^2$：这让我们有条件计算新输入的真值，而真实任务通常没有这份答案表。

训练输入是 $[-1,-1/3,1/3,1]$，观测值为真值加交替噪声 $\varepsilon[-1,1,-1,1]$。留出输入是 $[-2/3,0,2/3]$，在训练范围内但不参与拟合；外推检验用 $[3/2,2]$。后两组都用无噪声真值评分。由于评分对象不同，不能把三种误差当作完全同分布的统计估计。

### 三次的零训练误差付出了什么

选择一次、二次或三次多项式，分别有2、3、4个参数。四个不同训练输入让三次曲线可以穿过四个带噪观测。对本页特定数据，可以手算出三次解：

$$
p_3(x)=1+x^2+\varepsilon\left(\frac92x^3-\frac72x\right),\qquad
p_3(2)=5+29\varepsilon.
$$

括号在四个训练输入上恰好交替为 $-1,1,-1,1$，所以也把噪声精确拟合了。取 $\varepsilon=0.2$，在 $x=2$ 输出10.8，而真值只有5。二次解则是 $p_2(x)=1+x^2+(3\varepsilon/5)x$，同一点输出5.24；它没有穿过全部观测，却在这个例子的外推点更准。这是指定数据下的算术结论，不是“阶数越小越好”的普遍定理。

误差统一按每点平均的平方差计算，$S$ 表示所选评分集合、$z_i$ 是该集合的评分目标：

$$
\operatorname{MSE}_S=\frac{1}{|S|}\sum_{i\in S}\bigl(p_d(x_i)-z_i\bigr)^2.
$$

训练集的 $z_i$ 是带噪观测，留出与外推的 $z_i$ 是人工真值。界面用实心圆画训练观测、空心菱形画留出点；第三步另画外推子图，明确标出不同的纵轴尺度，避免为容纳10.8而把范围内的细微差别压扁。

> 先预测：二次改三次后，训练误差降到多少？留出与外推误差是否同步下降？然后打开“把留出点混入拟合”，看看曲线与系数是否真的变化。

<TcgMain03ModelEvidenceGateLab />

故障模式把三个留出点加入拟合，样本数从4变7，再在这些点上报告误差。菱形填色表明角色已改变；即使数值更小，也不能再叫独立检验。关掉故障可回到同参数的参考曲线；“完整重置”另外恢复阶数、噪声、故障、游标和暂停状态。

### 小维求解器：透明优先，不是生产建议

为让前端与 Python 共用同一个数学问题，下面显式构造正规方程 $\Phi^T\Phi\theta=\Phi^Ty$，再用带主元选择的消元求解。此处输入互异、阶数不超过3，设计矩阵满列秩；`Fraction` 可精确验算。前端使用浮点。大型或病态问题不应照搬这个求解器，正规方程还会恶化条件数；本页不比较数值库性能。

```python
def fit(xs, ys, degree):
    rows = basis(xs, degree)
    m = degree + 1
    cols = list(map(list, zip(*rows)))
    aug = [[dot(cols[i], cols[j]) for j in range(m)]
           + [dot(cols[i], ys)] for i in range(m)]
    for k in range(m):
        pivot = max(range(k, m), key=lambda i: abs(aug[i][k]))
        aug[k], aug[pivot] = aug[pivot], aug[k]
        scale = aug[k][k]
        assert scale != 0, "columns must be independent"
        aug[k] = [v / scale for v in aug[k]]
        for i in range(m):
            if i != k:
                factor = aug[i][k]
                aug[i] = [v - factor * u
                          for v, u in zip(aug[i], aug[k])]
    return [row[-1] for row in aug]


def truth(x):
    return 1 + x * x


def mse(theta, xs, ys):
    return sum(((predict(theta, x) - y) ** 2
                for x, y in zip(xs, ys)), F(0)) / len(xs)
```

先固定分组，再求系数。`leaked` 明确给出故障的数学含义：不是隐去一条记录，而是让原本只负责评分的点参加求解。

```python
train_x = [F(-1), F(-1, 3), F(1, 3), F(1)]
hold_x = [F(-2, 3), F(0), F(2, 3)]
ext_x = [F(3, 2), F(2)]


def experiment(degree, eps, leaked=False):
    train_y = [truth(x) + eps * sign
               for x, sign in zip(train_x, [-1, 1, -1, 1])]
    fit_x = train_x + hold_x if leaked else train_x
    fit_y = train_y + list(map(truth, hold_x)) if leaked else train_y
    theta = fit(fit_x, fit_y, degree)
    scores = (mse(theta, train_x, train_y),
              mse(theta, hold_x, list(map(truth, hold_x))),
              mse(theta, ext_x, list(map(truth, ext_x))))
    return theta, scores
```

最后检查整条结论链。二次系数中一次项为 $3\varepsilon/5$，三次系数中一次项为 $-7\varepsilon/2$、三次项为 $9\varepsilon/2$。打印的三项依次对应训练、留出、外推；泄漏后的第二项须改称“泄漏点误差”。

```python
for eps in [F(1, 10), F(1, 5)]:
    q, q_scores = experiment(2, eps)
    c, c_scores = experiment(3, eps)
    assert q == [1, 3 * eps / 5, 1]
    assert c == [1, -7 * eps / 2, 1, 9 * eps / 2]
    assert c_scores[0] == 0 < q_scores[0]
    assert c_scores[1] > q_scores[1]
    assert c_scores[2] > q_scores[2]
    assert predict(c, F(2)) == 5 + 29 * eps
    assert predict(q, F(2)) == 5 + 6 * eps / 5
    leaked, _ = experiment(3, eps, leaked=True)
    assert leaked != c
    print("eps", eps, "quadratic", q_scores, "cubic", c_scores)
print("all model assertions passed")
```

这些断言只证明本页数据和计算一致。没有随机采样置信区间，没有真实 ChatGPT 的训练、推理或速度测量。即便一条曲线在三组点都表现好，也还不足以证明现实中的因果机制；那需要问题相关的额外假设和实验。

## 三个容易混在一起的判断

选择模型结构、找到准则下的最优参数、证明新输入可靠，是三个不同任务。下面的反例分别对应三个实验，不能只看最后一个误差数字。

### 误区一：增加系数就是换模型结构

**现象**：把 $\theta_2$ 调大，就说模型多了一项。**原因**：混淆已存在列的权重与列是否存在。**修法**：在实验一保持二次，换系数只改点积；改成一次才真正删掉 $x^2$ 列。常数列为零则是另一种表示故障。

### 误区二：残差正交就说明模型完全正确

**现象**：看到直角标便断言预测等于观测。**原因**：把最小距离误认为零距离。**修法**：在实验二用默认输入，正交但 SSE 为2；它只是在所选直线内最优，不代表无误差或揭示真实原因。

### 误区三：训练点全穿过，留出就不用了

**现象**：三次训练误差为零，便忽略外推；或把泄漏后的较小误差当新证据。**原因**：一边选系数、一边把同一答案当独立检验。**修法**：先分组，再比较曲线；泄漏点不能再算留出，范围内检验也不能替代范围外检验。

## 小结与练习

一页里从“可计算的规则”走到了“可检验的适用范围”，三条收获与开头目标对应：

- 幂基决定列，系数决定列的加权组合。
- 最小二乘垂足可有非零残差。
- 穿过训练点不保证留出或外推可靠。

**问题 2**：实验二用 $a=(1,2)$、$y=(1,3)$，从导数算出 $\theta^*$、残差与 SSE；为什么无需残差为零？若参数加1，SSE 增加多少？

</Answer>

</Answer>

## 名词解释

五个术语分别回答：允许什么形式、调哪些数、如何组织输入、按什么准则选数、范围之外如何使用。

<Glossary>
  <GlossaryItem term="模型族">
    允许使用的一组计算规则；例如所有二次多项式，而非某条已经选定的曲线。
  </GlossaryItem>
  <GlossaryItem term="参数">
    结构确定以后仍可调整的数；本页是每一列基函数前面的系数。
  </GlossaryItem>
  <GlossaryItem term="设计矩阵">
    把每个输入算成一行基函数值的表；列与系数一一对应。
  </GlossaryItem>
  <GlossaryItem term="最小二乘">
    让预测与观测的差的平方和最小；最小不一定为零。
  </GlossaryItem>
  <GlossaryItem term="外推">
    把规则用到已观测输入范围之外；范围内拟合好并不自动担保它。
  </GlossaryItem>
</Glossary>
