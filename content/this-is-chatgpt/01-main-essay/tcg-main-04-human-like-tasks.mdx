## 为什么看起来相似，还会认错

同一张小图，擦掉一笔、加深一角，我们可能仍觉得它没有变。但一个只按格子比较的程序，可能已经改了答案。这一节要追问：它在比较什么，又凭什么把答案叫作正确？

如果只看几张清楚的样例，我们很容易高估程序。把原图、改过的图和一组从未拿来选规则的图分开，才能发现：有时错的是读图顺序，有时是规则太脆弱，有时则是我们算错了错误的价值。

## Models for Human-Like Tasks / 面向类人任务的模型

本页对应原文这一个正式分节。作者在2023年的公开长文中，从数值拟合转向图像识别：人能认出变形的数字，仅靠逐像素比对却很脆弱。他暂把识别函数当作黑盒，接着问：一张逐渐模糊的图，还应不应该被判作原来的数字？这不是只凭来源就能裁定的问题，还涉及人类知觉和任务定义。

这里有两个层次。第一，程序能否给输入一个可复算的类别？第二，这个类别是否符合人对任务的判断？证明距离公式算对，只解决第一层；要回答第二层，需要明确标注规则、收集人的判断、使用独立测试，不能把一个数学函数正确执行当作它正确模仿人的证明。

### 本页做什么，不做什么

我们用本站手工设计的A、B两种3×3符号替代真实数字照片，依次研究表示、扰动、评估。符号名只是数据标签，不暗示它们是什么手写字母。它们不取自原文图像，不是MNIST，也没有神经网络或训练过程。后面“神经网络”一章才讨论可组合的计算结构；本页不会借用加权DAG、ReLU或XOR实验。

在真实监督学习中，样本标签提供希望模型学习的答案，训练集用于拟合参数；验证集用于选规则，测试集用于最后评估。三者的职责不同。本页只手工指定模板和分数，演示这些职责为什么必须分开，**没有实际训练集成绩或真实识别准确率**。看过评估结果再反复选阈值，也会使它逐渐变成验证集，最终仍需另一份未参与选择的测试数据。

## 把小图写成可以检查的距离

<Term def="把每个位置的明暗按固定顺序排成数值数组。">像素表示</Term>
不是图像本身的全部含义，而是让程序能够读入图像的一套约定。这里黑为1、浅为0，自上而下、每行从左到右，得到9维向量。若显示按行排列，计算却按列读取，同一串数就对应另一张图；归一化、裁切、尺寸和顺序都属于表示约定。

### 每一格怎样贡献误差

<Term def="逐个位置比较输入与参考图，合并差异后得到的数值。">模板距离</Term>
在这里选为平方差之和。符号表：$x_i$是输入第$i$格灰度，$A_i,B_i$是两个固定模板，$\alpha$是从A混向B的比例，$\beta$是亮度偏移，$d_A,d_B$是平方距离。$i$从0到8，数组行优先；这不是图形API的矩阵布局规则。

$$
x_i=\operatorname{clip}_{[0,1]}((1-\alpha)A_i+\alpha B_i+\beta),\qquad d_C(x)=\sum_{i=0}^{8}(x_i-C_i)^2.
$$

这个式子在说：先混合并裁切每格明暗，再把输入与模板C的每格差异平方后相加。平方使正负差异不抵消；它不自动提供平移、旋转或光照不变性。图中的误差场越深，表示该格贡献越大，不是“模型注意力”。程序选距离较小者，等距时固定选A，这是明确的实现约定，不是知觉定律。

先预测：输入就是A时，如果只把计算端改成按列读取，会不会变成B？运行后检查输入网格、两幅误差场和累计曲线，再恢复。之后将$\alpha$选为0.5，验证“等距按A”与“显著更像A”不是一回事。

### Python 1：表示与逐像素误差

将本页所有`python`块按顺序保存到同一个文件，用Python 3运行；只用标准库。先定义与图中一致的9格数据。所有后续例子复用这里的数组，而不是读取外部模型或图片。

```python
from math import isclose

A = (1, 0, 0, 1, 0, 0, 1, 1, 1)
B = (1, 1, 1, 0, 0, 1, 0, 0, 1)

def transpose(x):
    return tuple(x[(i % 3) * 3 + i // 3] for i in range(9))

def pixels(alpha=0.0, brightness=0.0, edits=None):
    x = [min(1, max(0, (1-alpha)*a + alpha*b + brightness))
         for a, b in zip(A, B)]
    for i, value in (edits or {}).items():
        x[i] = value
    return tuple(x)

def error_field(x, template):
    return tuple((v-t)**2 for v, t in zip(x, template))

def distances(x):
    return sum(error_field(x, A)), sum(error_field(x, B))

def predict(pair):
    return "A" if pair[0] <= pair[1] else "B"
```

下面先查数值，再查故障。A、B恰有6格不同，所以输入A时距离为$(0,6)$；一半混合时，6个差异格各贡献0.25，两边都是1.5。转置A恰好得到B，是为让表示故障可见而特意设计的数据，并非所有图像都会这样。

```python
assert distances(pixels()) == (0, 6)
assert distances(pixels(0.5)) == (1.5, 1.5)
assert predict(distances(pixels(0.5))) == "A"
assert transpose(A) == B
assert distances(transpose(pixels())) == (6, 0)
assert predict(distances(transpose(pixels()))) == "B"
assert distances(pixels()) == (0, 6)  # 撤销转置，恢复同一输入
assert distances(pixels(edits={1: 1})) == (1, 5)
print("pixel", distances(A), distances(pixels(0.5)))
```

## 用一张扰动地图寻找翻转位置

<Term def="在给定输入空间里，使分类规则从一种输出切换到另一种输出的位置集合。">
  决策边界
</Term>
把“动一点会怎样”变成可计算的问题。这里不是任意9维输入：我们只让顶部两格按$a$从A移向B，其余四个差异格按$b$移动，三个相同格保持不变。地图上每一点因此都对应一幅明确的小图，而不是任意画出来的语义坐标。

### 边界从距离差推出来

$a,b$都在0到1之间；$w$是其余四格的距离权重，顶部两格权重为1。因为各组内的差异都是从0变1或从1变0，同一组的平方贡献相同，可以先相加再比较：

$$
d_A=2a^2+4wb^2,\qquad d_B=2(1-a)^2+4w(1-b)^2.
$$

这个式子在说：顶部只有两格，而另一组有四格；即使$a=b$，两组总影响也未必相同。将两边相减，二次项消去，得到$d_A-d_B=4a+8wb-2-4w$。距离相等的条件是：

$$
2a+4wb=1+2w.
$$

这条直线一侧判A，另一侧判B，线上按A。$w=1$时就是$a+2b=1.5$；默认目标$(0.25,0.75)$落在B侧。沿原点到目标的路径$(ta,tb)$，第一次等距发生在$t=1.5/1.75=6/7$。动画只采七个位置，所以最后一步才看到跨域，**采样步数不是边界精度**。

先预测：漏算其余四格会把斜线变成哪条线？注入故障后，声明的$w$仍显示1，但实际贡献为0，边界变成$a=0.5$，默认目标被判A。再把权重切为2，观察正常边界旋转；权重是你指定的距离偏好，不是从人类判断中学来的可靠性。

### Python 2：检查解析边界与输入图一致

先按坐标生成图，再给每格加权计算距离，独立验证前面的简化公式。注意实验1使用所有格同权，实验2改变$w$才引入新的度量；它们不是同一个参数被偷偷改名。

```python
TOP, REST = (1, 2), (3, 5, 6, 7)

def perturb(a, b):
    return tuple(v + (a if i in TOP else b if i in REST else 0)
                 * (B[i]-v) for i, v in enumerate(A))

def region_distances(a, b, w=1):
    return 2*a*a + 4*w*b*b, 2*(1-a)**2 + 4*w*(1-b)**2

def weighted_distances(x, w):
    weights = [w if i in REST else 1 for i in range(9)]
    return tuple(sum(q*(v-c)**2 for q, v, c in zip(weights, x, t))
                 for t in (A, B))

for w in (0, 0.5, 1, 2):
    for ai in range(21):
        for bi in range(21):
            a, b = ai/20, bi/20
            exact = weighted_distances(perturb(a, b), w)
            closed = region_distances(a, b, w)
            assert all(isclose(x, y, abs_tol=1e-12)
                       for x, y in zip(exact, closed))
```

数值接近边界时不要把浮点舍入造成的极小差值当作发现新现象。下面用恰好可表示的点检查等距；默认目标的参考、漏算和恢复三次比较，其他条件完全相同。

```python
assert region_distances(0.5, 0.5) == (1.5, 1.5)
assert predict(region_distances(0.25, 0.75, 1)) == "B"
assert predict(region_distances(0.25, 0.75, 0)) == "A"
assert predict(region_distances(0.25, 0.75, 1)) == "B"
a, b = 0.25, 0.75
crossing = 1.5 / (a + 2*b)
assert isclose(crossing, 6/7)
assert predict(region_distances(a*0.8, b*0.8)) == "A"
assert predict(region_distances(a, b)) == "B"
print("boundary", crossing)
```

### 来源标签不是知觉标签

从A生成的所有扰动图，都可以保留“来自A”的来源记录，但不能因此宣称人一定还会把它看成A。接近B的图尤其如此。要评估模仿人的任务，须事先规定标签如何获取，必要时允许多人意见不一致、模糊样本或拒答。这里没有采集人的判断，地图只显示我们的规则输出，不能验证它是否符合人的知觉。

同样，在这张二维地图上稳定，不代表旋转、缩放、背景变化或其他七个方向也稳定。独立测试应包含目标使用环境的变化，而不是只把模板原样放回去。数学可以证明我们画出的边界；它无法替我们证明“任务已被解决”。这正是原文从图像识别引出的重要区分。

## 阈值把错误送进不同的格子

<Term def="按真实类别和预测类别交叉计数的表，区分命中、漏报、误报和正确排除。">
  混淆矩阵
</Term>
保留了准确率丢掉的方向信息。我们另造12条评估记录，5条真实阳性、7条真实阴性；这里的分数是手写排序数，不来自前两个实验，不是经过校准的概率。这样做是为了隔离评估机制，而不是暗示模板距离已经变成真实识别置信度。

### 先声明阳性，再声明阈值

本例把“需要拦下的目标”叫阳性，阴性是其他对象。分数$s$达到阈值$\tau$就预测阳性，包含相等情况。真阳性TP是拦对，漏报FN是该拦未拦；误报FP是不该拦却拦了，真阴性TN是正确放行。把阳性改成另一种业务事件，四格的含义也要随之更改，不能只照搬缩写。

<Term def="给不同类型错误指定同一单位的损失，再按发生次数相加。">误判代价</Term>
让阈值选择有了明确目标。$c_{FN},c_{FP}
$分别是一次漏报和一次误报的损失；这里只用假定的代价单位，不是实际医疗、金融或安全决策建议。

$$
\widehat y=\mathbf{1}[s\geq\tau],\qquad L=c_{FN}FN+c_{FP}FP,\qquad \mathrm{accuracy}=\frac{TP+TN}{N}.
$$

这个式子在说：阈值决定分数送往哪一侧，而代价还要看送错的方向值多少钱。固定分数和标签时，降低阈值不会增加FN，但可能增加FP。它不改变真实标签，也不会凭空提升分数质量。代价只有在两种错误可用同一单位比较时才可相加；实际选阈值还应考虑容量、公平性和评估不确定性。

先预测：漏报比误报贵4倍，阈值从0.5降到0.3，准确率和代价会朝同一方向变化吗？再注入“参考集冒充评估”，比较分母和分数带，不要只看100%的准确率。

### Python 3：分母和错分代价都要保留

下面的`evaluation`与`reference`是两个独立手工列表，没有从任何模型采集。参考列表仅有4个容易样本；故障用它替换评估列表，模拟挑容易数据汇报的错误。它不是训练所得结果，因此也不能用它计算真实泛化差距。

```python
scores = (0.9, 0.8, 0.6, 0.55, 0.5, 0.45,
          0.4, 0.35, 0.3, 0.2, 0.1, 0.05)
evaluation = tuple((s, i in (0, 1, 3, 5, 8))
                   for i, s in enumerate(scores))
reference = ((0.95, True), (0.85, True),
             (0.15, False), (0.05, False))

def confusion(records, threshold):
    counts = dict(TP=0, FN=0, FP=0, TN=0)
    for score, positive in records:
        predicted = score >= threshold
        key = ("TP" if predicted else "FN") if positive else (
               "FP" if predicted else "TN")
        counts[key] += 1
    assert sum(counts.values()) == len(records)
    return counts

def report(records, threshold, cfn=4, cfp=1):
    c = confusion(records, threshold)
    loss = cfn*c["FN"] + cfp*c["FP"]
    accuracy = (c["TP"] + c["TN"]) / len(records)
    return c, loss, accuracy
```

阈值0.5时，分数恰好0.5的阴性也被判阳性，所以FP包括它。调高阈值0.7会消除误报，却漏掉3个阳性；这说明“更严格”未必意味着总代价更小。调低到0.3时准确率仍为8/12，总代价却从10降到4，必须说清正在优化哪个目标。

```python
base, loss, acc = report(evaluation, 0.5)
assert base == dict(TP=3, FN=2, FP=2, TN=5)
assert (loss, acc) == (10, 8/12)
assert report(evaluation, 0.3) == (
    dict(TP=5, FN=0, FP=4, TN=3), 4, 8/12)
assert report(evaluation, 0.7) == (
    dict(TP=2, FN=3, FP=0, TN=7), 12, 9/12)
easy = report(reference, 0.5)
assert easy == (dict(TP=2, FN=0, FP=0, TN=2), 0, 1)
assert report(evaluation, 0.5) == (base, loss, acc)  # 恢复
print("evaluation", base, loss, acc, "reference", easy)
```

上面两处`8/12`相同：0.3与0.5的准确率**一样**，但错分结构和代价不同；0.7的准确率则更高，代价也更高。实际运行这些断言，可以纠正“降低阈值一定降低准确率”的过度概括。若只拿准确率选阈值，你在这里会偏爱0.7，而不是漏报代价4时更合适的0.3。

### 为什么必须检查样本构成

类不平衡会让总准确率掩盖少数类的失败。例如在另一个假定集合里，100个样本只有1个阳性，全部预测阴性也能有99%准确率，却漏掉唯一目标。这不是本实验实测值，而是一个可直接计数的反例。它解释了为什么要报告分母、阳性占比和四格计数，而不只报一位小数。

本页12条固定记录同样太少，也不是随机采样；它只能教你复算阈值、错分和代价，不能估计生产环境的错误率。在真实任务里，还应保留数据来源、标签定义、重复样本处理和未参与调参的测试集。降低代价的教学算例，不等于部署安全性已经验证。

## 三个常见误区

这三个错误分别发生在表示、标签定义和汇报环节。先确认错误在哪一层，再修复相应约定，不要把所有异常都归结为“模型不够聪明”。

### 误区一：换一下读图顺序不影响答案

<Callout type="trap" title="表示约定错位">

**现象→** 原图没改，A却被判B。**原因→** 显示按行，计算按列，实际比较的是转置图。**修法→** 在实验1核对计算输入和逐格误差，统一展平顺序，再用同一输入恢复距离$(0,6)$。

</Callout>

### 误区二：从A变来的图，正确答案永远是A

<Callout type="trap" title="混淆来源与知觉">

**现象→** 把所有扰动后的B判定都叫错误。**原因→** 来源标签不等于人类判断，尤其在模糊或混合处。**修法→** 实验2只称“规则跨域”；评价类人能力前另订标注规范并采集判断，保留分歧。

</Callout>

### 误区三：容易样本100%说明已经解决任务

<Callout type="trap" title="错分和分母被隐藏">

**现象→** 故障模式准确率变100%。**原因→** 换成4条容易参考数据，回避12条评估记录及漏报代价。**修法→** 恢复独立列表，报四格计数与分母；阈值只在验证数据上选择，再用新测试集评价。

</Callout>

## 小结与练习

现在把三个层次重新连起来：表示使图像可计算，边界说明规则何时翻转，独立评估决定你有资格对什么任务下结论。前者算对不保证后者成立；这就是类人任务不能只靠几张漂亮样例证明的原因。

- 像素顺序和模板距离必须逐格可复算。
- 决策边界属于指定度量，不替人决定标签。
- 同一准确率也可能隐藏不同错分和代价。

**问题 1**：完整重置实验1，手动将第2格从0改1。手算$d_A,d_B$；再把混合设为0.5，不清除该覆盖，结果是什么？为什么只改滑杆不能叫完整重置？

<Answer>

初次编辑只改一个原本A为0、B为1的格，距离为$(1,5)$。混合0.5时其他5个差异格各贡献0.25，被覆盖那格对A贡献1、对B贡献0，所以是$(2.25,1.25)$。编辑是独立状态，改变混合不取消覆盖；完整重置还必须清9格覆盖、亮度、故障、时间位置和播放。可在Python里加断言`distances(pixels(0.5, edits={1: 1})) == (2.25, 1.25)`。

</Answer>

**问题 2**：将实验2权重改为2，保持目标$(0.25,0.75)$。推导等距线及沿起点到目标的等距$t$，再改动$b$找到A侧目标。这个结果能否证明人看见的类别也改变了？

<Answer>

等距线是$2a+8b=5$，路径上$t=5/(2\times0.25+8\times0.75)=10/13$。在$a=0.25$处，$b\leq0.5625$判A，取$b=0.5$可验证。它只证明指定距离规则的输出，未采集人类标签，不能证明人的知觉变化；图上颜色也不是“真实类别”。改实验时同时核对目标图像，别只盯着色域。

</Answer>

**问题 3**：独立实现Python的阈值扫描，在0、0.05、…、1中枚举最低代价；默认$c_{FN}=4,c_{FP}=1$，并列时取较高阈值。再把误报代价改为8，在实验3验证最优阈值是否改变。能把这12条当最终测试集吗？

<Answer>

用`candidates = [(report(evaluation, i/20, 4, 1)[1], -i/20) for i in range(21)]`，再取`min(candidates)`得到最低代价4，按并列规则阈值0.3。误报代价8时枚举会得到阈值0.8，代价12（TP2、FN3、FP0、TN7）。因为你已经用这12条选择阈值，它们承担了验证集职责，不能再声称是未参与调参的最终测试集。分数是手写数，扫描也不是训练识别器。

</Answer>

## 名词解释

这五个词对应三个实验中实际可检查的对象；每个定义都不暗示模拟已经获得人的视觉能力。

<Glossary>
  <GlossaryItem term="像素表示">
    按固定位置顺序，把图像明暗排成数值数组；本页每格范围0到1，行优先。
  </GlossaryItem>
  <GlossaryItem term="模板距离">
    输入和固定参考图之间的差异总量；本页为逐像素平方差之和，不是语义距离。
  </GlossaryItem>
  <GlossaryItem term="决策边界">
    给定规则输出类别发生切换的位置；本页是二维扰动族内的等距线。
  </GlossaryItem>
  <GlossaryItem term="混淆矩阵">
    按真实与预测标签交叉计数的四格表，保留错分方向。
  </GlossaryItem>
  <GlossaryItem term="误判代价">
    对每类错误规定统一单位的损失，再按次数相加；取值必须由任务定义。
  </GlossaryItem>
</Glossary>
