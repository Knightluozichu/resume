## 从地图上的四个角开始

在一张正方形地图上，只给四个角涂色：左下与右上留白，另外两角涂深。一条直线能把深色与留白两组分开吗？试着画几次，就会发现问题不在画得不够准。

如果只能把已有直线挪动、旋转，重复很多次也无济于事。我们需要一种会“折一下”的计算，再把几次简单计算连起来。这一章解释折弯从哪里来，以及连起来以后究竟多了什么能力。

## Neural Nets / 神经网络

本页对应原作主长文的 **Neural Nets** 一节。它承接“能完成类似人类任务的模型”：不再把模型当成只见输入输出的盒子，而是展开盒子内部的数值连接。学习顺序是先算一个节点，再接成层，最后看整个输入平面怎样被划分。学习如何选择参数属于下一章，本章始终使用手写常数，不执行参数更新。

### 权重：连接不是等份投票

<Term def="连接上乘到输入数值的系数，正负决定贡献方向，绝对值决定缩放大小">
  权重
</Term>
把上游数值变成下游收到的贡献。设两个输入为 $x_1,x_2$，一条连接权重为
$w_1$，它贡献的是 $w_1x_1$，不是
$w_1+x_1$。正权不必然让最终输出增加：后面还可能遇到负权或被截断。负权也不等于连接不存在，它确实参与相加。

实验一用实线与虚线区分正负，用线宽编码绝对值。把 $w$ 从 2 改成 −1，边既变细又变成虚线；如果只改标签而不改连接语义，就无法解释节点的数值变化。

### 偏置：让转折不必经过原点

<Term def="加到带权输入总和上的独立常数，用来移动响应开始的位置">偏置</Term>
在输入都为零时仍能贡献数值。一个节点先计算

$$
z=w_1x_1+w_2x_2+b.
$$

这个式子在说：先把每条输入按各自系数缩放，再把贡献和常数相加。偏置不是另一个输入样本，也不从当前输入自动算出；它是这个节点自己的参数。实验一只调第一个隐节点的 $b_1$，第二个节点的常数保持为零，便能隔离两条路径。

### 激活函数：真正的折弯发生在这里

<Term def="作用于带权和的数值函数；非线性选择使层的组合不再只是一次直线变换">
  激活函数
</Term>
接在求和之后。本章固定使用 ReLU，记作
$R(z)=\max(0,z)$：负值归零，非负值原样保留。它在零处连续，但左右斜率从 0 变成
1。实验二把这个转折画成可移动的铰链，而不是把“非线性”当作一句口号。

有些网络还会选别的激活方式；ReLU 是这里便于手算的选择，不是“所有神经元都如此”或“当前 ChatGPT 一定如此”。实验一输出节点故意只做线性组合，所以输出可以为负，也不是概率。

### 隐藏层：输出之前的中间计算

<Term def="位于输入和输出之间、把上游数值重新组合为中间数值的一层节点">
  隐藏层
</Term>
的“隐藏”是位置名称，不表示运行时无法读取。前向计算按层推进：前一层所有结果算好后，后一层才使用它们。实验一的结构是
2→2→1，第一层矩阵有 2 行、2 列，每一行对应一个隐节点；两个偏置分别属于这两行。

这些中间数值可以看成新的坐标。但一个节点不必对应一个人类能命名的概念。原文用图像网络内部状态说明这种解释困难；本站没有运行其图像网络，也不把小网络里可读的坐标外推成真实语言模型的完整解释。

### 决策区域：输出数值怎样变成分类

<Term def="输入空间中被同一判定规则分到同一类别的点的集合">决策区域</Term>
需要同时指定网络与判定规则。数值输出大于或等于阈值判为 1，其他情况判为
0，会把连续平面划成区域；阈值也会移动边界，不能与网络内部折点混为一谈。

原文以最近点识别和分类分区说明这种几何视角；本页另造 XOR 四角任务，避免复制原图与原示例。实验三显示完整正方形上的中心采样着色，并叠加精确解析边界。四角全部正确只表示通过四个测试点，不表示正方形内所有位置都有“真实标签”，更不证明泛化或训练成功。

## 实验一：沿着带权连接前向计算

这次只沿箭头计算，不调整参数去拟合数据。图中的边宽、符号和节点大小都来自同一组公式；播放光标依次强调输入、带权求和、隐层激活和输出组合，进度条可以停在任一阶段。

### 先手算一个确定结果

固定 $x_2=1$，输入控件记作 $u=x_1$。两隐节点与输出定义为

$$
h_1=R(wu-1+b),\qquad h_2=R(u+1),\qquad y=h_1-\tfrac12h_2.
$$

这个式子在说：第一路有一条 −1 连接与可调偏置，第二路把两输入相加，最后让第二路以负半份贡献输出。默认 $u=1,w=2,b=0$，依次得到 $z_1=1,z_2=2,h_1=1,h_2=2,y=0$。网络有固定的 2→2→1 形状，调整这些数值并不改变节点数。

先预测：只把 −1 连接翻成 +1，第一个与参考不同的量是什么？它是否会连带改变 $h_2$？再开故障，核对是否得到 $z_1=3,h_1=3,y=2$，且 $h_2$ 仍是 2。完整重置应回到所有默认参数、关闭故障、暂停并回到第一步，不只是把圆画回原处。

## 实验二：两个铰链怎样合成新折线

一个 ReLU 只提供一个折点，多个带不同偏置的 ReLU 可以在不同位置改变斜率。这里横轴是一个输入，不是训练步数；播放只是沿横轴取样，不代表损失下降或学习过程。

### 从一条斜坡到向下折返

先构造两路 $R(x-t)$ 与 $R(x-t-1)$，再在输出处给第二路 −2 倍系数：

$$
f(x)=a\,[R(x-t)-2R(x-t-1)].
$$

这个式子在说：第一路在 $t$ 开始上坡，第二路在 $t+1$ 开始减去两倍斜坡。逐段代入可得：$x\leq t$ 时 $f=0$；$t<x\leq t+1$ 时 $f=a(x-t)$；$x>t+1$ 时 $f=a(2+t-x)$。三个区间的斜率分别是 0、$a$、$-a$，两处连接连续。

先预测：把 $t$ 从 0 改成 0.5，哪两个横坐标会一起移动？把 $a$ 加大，折点会不会移动？观察虚线第一路与实线组合，再开“漏掉第二铰链”：右侧斜率不再折成负值。请注意右端出现负值并不是 ReLU 输出为负，而是输出处的负系数造成的。

<TcgMain05NeuralNetsComputeTraceLab />

### 删除所有非线性为什么不同

漏掉一个支路与把所有激活改成恒等函数是两种不同故障。如果两层都只执行 $h=W_1x+b_1$、$y=W_2h+b_2$，把前式代入后可写成

$$
y=(W_2W_1)x+(W_2b_1+b_2).
$$

这个式子在说：多层的矩阵乘法和常数相加仍能合并成一层，堆叠本身没有产生折点。这里讨论的是纯线性加偏置的层；不能把结论套到含非线性、门控或其他运算的任意架构上。

## 实验三：隐藏层怎样划分 XOR 输入平面

XOR 在两个输入不同的时候目标为 1，相同的时候目标为 0。因此四个角的目标是 00→0、10→1、01→1、11→0。实验把横纵输入都限制在 0 到 1；角点之外的着色是网络的延伸预测，而非另有标注的数据集。

### 用总和坐标造出一条斜带

令 $s=x_1+x_2$，设隐节点为 $R(s)$ 和 $R(s-k)$，输出 score 是第一路减第二路的两倍，再用阈值 $\theta$ 判断。默认 $k=1,\theta=0.5$，因为正方形内 $s\geq0$，输出可拆成

$$
\operatorname{score}(s)=\begin{cases}s,&s\leq1,\\2-s,&s>1.\end{cases}
$$

这个式子在说：总和先上升，再在 1 处转为下降。判为 1 的范围是 $0.5\leq s\leq1.5$，正好是一条包含 10、01、排除 00、11 的斜带。虚线 $s=k$ 是隐层折点，实线是 score 等于阈值的地方；两者职责不同。

先预测：只提高阈值，斜带是变宽还是变窄？只把 $k$ 改成 0.5，11 的输出怎样变化？最后开启“隐层改成恒等函数”，同一组系数会得到 score=$s-2(s-k)=2k-s$。默认时 00 的输出从 0 变成 2，错误地落入类别 1，斜带退成单半平面。这个失败是结构限制，不靠再按几次播放解决。

<TcgMain05NeuralNetsEvidenceGateLab />

### 为什么任何单直线都无解

设单直线规则是 $q=Ax_1+Bx_2+c\geq0$ 判 1。为了让 00、11 为 0，必须有 $c<0$ 与 $A+B+c<0$；让 10、01 为 1，又要求 $A+c\geq0$ 与 $B+c\geq0$。后两式相加给出 $A+B+2c\geq0$，前两式相加却给出 $A+B+2c<0$，矛盾。边界上取等号也救不了这个规则。

隐藏层非线性允许两个边界一起出现，解决的是这四点的可表示性。它没有自动回答参数能否从数据学到、样本需要多少或新数据上是否可靠。这些问题留给下一章，不能从“存在一组能算对的手写参数”直接跳过去。

## 用标准库逐块复算三个实验

以下四块按出现顺序拼接成一个 Python 3 程序即可运行，不需要包、模型、SDK 或 GPU。它是手写玩具网络的前向计算与数值断言，**不是真模型训练**。可以把拼接结果保存为 `neural_nets.py` 后运行 `python3 neural_nets.py`；不从远端下载模型或访问服务。

### 第一步：保留求和前后的两个数值

节点同时返回 $z$ 和激活值，才能看清负值是在哪一步被归零。省略中间值会使“负权错误”和“激活错误”在最终输出里混在一起。

```python
from math import isclose


def relu(z):
    return max(0.0, z)


def node(inputs, weights, bias):
    assert len(inputs) == len(weights)
    z = sum(x * w for x, w in zip(inputs, weights)) + bias
    return z, relu(z)


assert node([1, 1], [2, -1], 0) == (1, 1)
assert node([0, 1], [2, -1], 0) == (-1, 0.0)
```

### 第二步：接起网络，故障只改一条边

两次运行使用相同输入与输出系数，只有第一个隐节点的第二条边不同。断言检查不仅末端变化，还检查第二个隐节点未受影响。

```python
def circuit(u=1, w=2, b=0, fault=False):
    z1, h1 = node([u, 1], [w, 1 if fault else -1], b)
    z2, h2 = node([u, 1], [1, 1], 0)
    return (z1, z2), (h1, h2), h1 - 0.5 * h2


reference = circuit()
broken = circuit(fault=True)
assert reference == ((1, 2), (1, 2), 0.0)
assert broken == ((3, 2), (3, 2), 2.0)
assert reference[1][1] == broken[1][1]
assert circuit(u=0)[2] == -0.5
```

### 第三步：按区间检查铰链组合

不只测试折点本身，还取左右多个点核对分段推导。修改 $t$ 后，函数与分段公式必须一起平移；把第二支路删去则会违反右侧斜率的预期。

```python
def hinges(x, t=0, a=1, fault=False):
    second = 0 if fault else 2 * relu(x - t - 1)
    return a * (relu(x - t) - second)


for t in [-0.5, 0, 0.5]:
    for a in [0.5, 1, 1.5]:
        for x in [-1, -0.25, 0.5, 1.25, 2]:
            expected = 0 if x <= t else a * (x - t)
            if x > t + 1:
                expected = a * (2 + t - x)
            assert isclose(hinges(x, t, a), expected)
assert hinges(2) == 0
assert hinges(2, fault=True) == 2
```

### 第四步：分别断言数值与区域标签

阈值测试与 score 测试分开写，避免把预测正确误当作内部数值正确。最后再扫一个稠密网格，核对默认斜带与公式一致；这只是解析结果的数值复核，不是泛化测量。

```python
def xor_score(x1, x2, k=1, fault=False):
    s = x1 + x2
    return 2 * k - s if fault else relu(s) - 2 * relu(s - k)


corners = [(0, 0), (1, 0), (0, 1), (1, 1)]
assert [xor_score(*p) for p in corners] == [0, 1, 1, 0]
assert [int(xor_score(*p) >= 0.5) for p in corners] == [0, 1, 1, 0]
assert [int(xor_score(*p, fault=True) >= 0.5)
        for p in corners] == [1, 1, 1, 0]
for i in range(21):
    for j in range(21):
        x, y = i / 20, j / 20
        assert (xor_score(x, y) >= 0.5) == (0.5 <= x + y <= 1.5)
assert circuit() == reference
print("PASS: circuit, hinge composition, XOR regions; no training")
```

## 常见误区：从图形定位原因

以下三个错误分别对应连边、输出组合和整体结构。不要看到最终分类不对就笼统归因于“网络太小”；先指出被改动的计算及其影响范围。

### 误区一：负权就是这条连接不工作

<Callout type="trap">

**现象 →** 删掉负边，却以为结果不变。

**原因 →** 负权参与减法；只有零权才使该边贡献恒为零。

**修法 →** 在实验一把 w 设为 −1，手算乘积；再对比 −1 边翻成 +1 的故障，辨认改变的节点。

</Callout>

### 误区二：用了 ReLU，整个网络就不能输出负数

<Callout type="trap">

**现象 →** 把实验二右端的负输出当作程序错误。

**原因 →** ReLU 的非负性只约束该节点的输出，后面的负系数仍能改变符号。

**修法 →** 取 t=−0.5、a=1、x=2，分别算两路 2.5 和 1.5，组合得到 −0.5。

</Callout>

### 误区三：多加线性层总能学出 XOR

<Callout type="trap">

**现象 →** 关闭全部非线性后，仍期待靠深度得到斜带。

**原因 →** 纯矩阵乘法与常数相加可合并为一个直线规则，与四角约束矛盾。

**修法 →** 开启实验三故障，看 00 错分；恢复两处 ReLU，再区分“可以表示”与“已经训练”。

</Callout>

## 小结与练习

回到开头的地图：需要的不是更用力地画同一条直线，而是让中间计算在不同区间采取不同规则。下面三点分别回收手算、修改折点和解释 XOR 的目标。

- 连边负责乘系数，节点依次求和、加偏置、激活。
- 两个错开的 ReLU 可组合成不同斜率的连续折线。
- XOR 可由隐层非线性表示，但不等于训练成功。

## 来源、历史与适用范围

## 名词解释

下面五项与正文首次高亮一一对应；权重、偏置决定节点收到什么，激活与隐藏层决定如何组合，最后由输出规则产生决策区域。

<Glossary>
  <GlossaryItem term="权重">
    乘在连接输入上的系数，符号决定贡献方向，绝对值决定缩放大小。
  </GlossaryItem>
  <GlossaryItem term="偏置">
    加到输入贡献总和上的独立常数，可以移动节点响应的起点。
  </GlossaryItem>
  <GlossaryItem term="激活函数">
    接在带权和之后的函数；本章 ReLU 把负数变零，让图形出现折点。
  </GlossaryItem>
  <GlossaryItem term="隐藏层">
    输入与最终输出之间的一层中间节点；它的数值可读取，不必有自然语言名称。
  </GlossaryItem>
  <GlossaryItem term="决策区域">
    在固定网络与阈值下，被判为同一类别的一组输入位置。
  </GlossaryItem>
</Glossary>
