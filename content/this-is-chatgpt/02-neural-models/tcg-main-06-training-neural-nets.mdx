## 为什么不仅要会算输出

上一节相当于在地图上按给定路线走一遍；本节要问：终点偏了，应该改哪一个路标、改多少？没有纠偏方法，每次试走就只能盲目碰运气。

## Machine Learning, and the Training of Neural Nets / 机器学习和神经网络训练

这个正式单元的核心区别是：运行模型时参数固定，训练时则用样本计算误差，再改变参数。沿用上一节的“模型是可计算函数”作为先修，本节不再画神经元加权连线，也不复讲激活函数、ReLU 或 XOR。我们只检查训练中三个相互独立的问题：误差对参数有多敏感、沿那个方向走多远、多个样本的方向怎样合在一起。

### 从样本到一个可比较的数

给定输入 x、目标 y 和预测 wx，<Term def="把预测与目标的差异变成一个要减小的数的规则">损失函数</Term>把好坏变成可计算的标量。这里 w 是唯一可调参数，x 与 y 是固定样本。使用一半平方误差是为了让求导简单；这不是语言模型训练目标的完整形式。

$$
a=wx,\qquad r=a-y,\qquad L=\tfrac12 r^2.
$$

这个式子说：先得到预测，再保留有符号的差，最后把差平方；平方后的 L 不再告诉我们该往左还是往右改 w。实验一会保留这三个中间值，用它们找回方向信息。

### 计算带：存值后反向回写

这里的<Term def="从一个标量输出向前面的运算倒序传回导数并累加贡献的方法">反向模式求导</Term>不反转模型，也不根据输出恢复输入。神经网络训练中常说的反向传播，就是在网络计算上应用这类链式求导。它先记录正向运算及求导所需的值，再以输出对自身的导数 1 为起点，倒着乘每一步的局部导数。记带横线的量为 L 对该量的导数，例如 r̄ 表示 ∂L/∂r。

$$
\bar L=1,\quad \bar r=\bar L\,r,\quad \bar a=\bar r\cdot1,\quad \bar w=\bar a\,x.
$$

这条链在说：每个中间量只负责把收到的敏感度乘上本地倍率，再传给它依赖的量；如果一个量被多处使用，应把多路贡献相加。本例只有一条依赖链，所以不需要画神经网络结构。

在 w=0.75、x=2、y=1 时，正向为 a=1.5、r=0.5、L=0.125；逆向依次写入 1、0.5、0.5、1。最后的 1 意味着 w 的微小增加会令损失约增加同样大小。丢掉最后的倍率 x，不会改变正向结果，却会把最终导数写成 0.5。

先预测：把输入 x 改为 3，哪些正向值和伴随线段会变长？播放到最后，再打开“把 x 错写成 1”，观察首个分岔是否只发生在 w̄。所有线段与数值都来自同一组计算。

### 二维方向：导数不等于更新

多个参数对应的偏导数组成<Term def="由各参数偏导数组成、指向局部增长最快方向的向量">梯度</Term>。在欧氏坐标中，沿它的反方向走一个足够小的步子，通常能在当前可微位置降低损失；“足够小”不能省略。反向模式负责算导数，更新规则负责使用它，两者不是一回事。

实验二故意选择可解析的二维碗面。u、v 是两个参数，不是样本坐标；椭圆上的点损失相同。横纵轴使用相同像素尺度，所以轨迹可以与等高线方向比较。

$$
L(u,v)=\tfrac12(u^2+4v^2),\qquad \nabla L=(u,4v).
$$

这个式子说：沿 v 方向的弯曲程度是 u 方向的四倍，同样的参数偏移会得到更大的 v 方向导数。

### 步长：朝下也可能跨过低谷

<Term def="把梯度转换成一次参数移动量的比例系数">学习率</Term>η
控制更新距离，不能把它解释成“学得越快就越好”。实验中使用最简单的负梯度更新，不含动量或自适应缩放。

$$
u_{k+1}=(1-\eta)u_k,\qquad v_{k+1}=(1-4\eta)v_k.
$$

这就是从旧参数减去 η 倍梯度后逐项整理的结果；两轴分别按不同倍率收缩或翻转。要对任意起点都收敛，两个倍率的绝对值都须小于 1，因此本例需 0＜η＜0.5。η=0.4 时 v 来回换号但幅度减小；η=0.55 时 v 换号且幅度增大。轨迹过冲和损失发散不是同义词。

先预测：保持起点不变，把 η 从 0.2 改为 0.4，再改为 0.55，逐步看点是接近还是远离中心。打开“减写成加”会在第一步使损失上升。虚线始终给出同参数的正确减法参考；越界会明确报警，不通过自动缩放把发散伪装为收敛。

<TcgMain06TrainingNeuralNetsComputeTraceLab />

作者原文以山谷说明局部与全局的区别，但这只是直觉：一般非凸目标上的离散更新不保证一定到达某个局部最小点，还可能遇到鞍点、震荡或不收敛。本实验的碗面只有一个最小点，不能凭它断言复杂网络也只有一个最优解。

### 批次：先合方向，再做一次更新

一个<Term def="一次更新使用的一小组训练样本">小批量</Term>（mini-batch）让多个样本共同决定一次更新。本页固定同一个参数 θ，为第 i 个样本指定目标点 tᵢ，令它的损失为到目标点的平方距离的一半。这是二维二次函数族，不是神经网络训练实录。

$$
L_B(\theta)=\frac1m\sum_{i=1}^{m}\frac{\|\theta-t_i\|^2}{2},\qquad g_B=\frac1m\sum_{i=1}^{m}(\theta-t_i).
$$

这个式子说：在同一个 θ 上先算每个样本的方向，再逐项相加并除以样本数 m；平均损失的导数就是平均梯度。逐样本连续更新会改变后续梯度的计算位置，不等于这里固定 θ 后平均一次。

实验三固定 θ=(0,0)，四个梯度依次是 (2,s)、(2,−s)、(−2,s)、(−2,−s)。虚线扇图保留各样本方向，细实线首尾相接给出求和路线，主色箭头表示平均梯度；实际下降方向还需取负号。m=2 时均值是 (2,0)，m=4 时恰好抵消为零，即使每个样本的梯度都非零。

先预测：增大 s 为什么会展开扇面，却不改变前两个样本的平均方向？将批次改成 4 并拖到最后，检查零向量。再改回 2，打开“只求和不除样本数”；错误箭头变成 (4,0)，同一学习率下更新长度翻倍。四样本的零可能把这一错误掩盖，不能只测一个输入。

### 训练拟合与范围外预测是两项验收

训练损失下降只说明给定样本与目标上的数值改善。原文强调：不同参数解可能都符合观察到的数据，却在样本之外产生不同预测。这个区别不需要大模型就能验证：只给 x=−1 和 x=1 两点、目标均为 1，函数 f(x)=1 与 h(x)=x² 在两点都零误差，但在 x=0 或 x=2 就不同。

下面的程序把未参与更新的点单独检查。它不是完整的泛化研究，也不通过观察这个留出点再调参数。对于真实任务，还需代表目标用途的数据、明确的数据划分和独立评估；本页不展开下一节的训练经验或配方。

## 用标准库把三个实验复算一遍

按出现顺序把以下 Python 代码块拼接为一个文件，再用 `python3 文件名.py` 执行。全部使用标准库，所有断言均实际执行；浮点数只在比较时给出容差，不把显示四舍五入后的数字拿来递推。它验证的是有限教学计算，不是训大模型或 GPU 测量。完整拼接副本和运行记录保存在本章离线证据目录，正文已包含完整程序。

### 先存标量，再回传导数

`chain` 明确区分正向的残差和反向的导数；故障只替换最后一个局部倍率。`math.isclose` 用于后面的独立检查。

```python
from math import isclose


def chain(w=0.75, x=2.0, y=1.0, fault=False):
    a = w * x
    r = a - y
    loss = r * r / 2
    bar_loss = 1.0
    bar_r = bar_loss * r
    bar_a = bar_r
    bar_w = bar_a * (1.0 if fault else x)
    return loss, (bar_loss, bar_r, bar_a, bar_w)


base_loss, bars = chain()
assert isclose(base_loss, 0.125)
assert bars == (1.0, 0.5, 0.5, 1.0)
```

对 w 两边各挪一小步，直接重新计算损失，就能用差分核对导数；这里的独立检查不复用反向计算结果。故障后的前三个伴随值仍一致，最终值才分岔。

```python
h = 1e-6
finite = (chain(0.75 + h)[0] - chain(0.75 - h)[0]) / (2*h)
assert isclose(finite, bars[-1], rel_tol=1e-8)
bad_loss, bad_bars = chain(fault=True)
assert bad_loss == base_loss
assert bad_bars[:3] == bars[:3]
assert bad_bars[-1] == 0.5
assert not isclose(finite, bad_bars[-1], rel_tol=1e-8)
assert chain() == (base_loss, bars)  # 撤销故障可重放
```

### 用同一个碗面检查收缩与过冲

下面的 `walk` 返回包含起点的九个位置。符号故障不改目标函数，只把负梯度变为正梯度，因此可把两条路径逐步比较。

```python
def bowl(p):
    u, v = p
    return (u*u + 4*v*v) / 2


def walk(rate, fault=False, start=(3.0, 1.5)):
    points = [start]
    for _ in range(8):
        u, v = points[-1]
        sign = 1 if fault else -1
        points.append((u + sign*rate*u, v + sign*rate*4*v))
    return points


stable = walk(0.2)
assert all(bowl(b) < bowl(a) for a, b in zip(stable, stable[1:]))
assert isclose(stable[1][0], 2.4)
assert isclose(stable[1][1], 0.3)
```

“翻到另一侧”不代表一定失败。先验证 η=0.4 的符号翻转和幅度收缩，再检查 η=0.55 走八步后的增长；后者不是声称每一条轴、每一步总损失都立即增加。

```python
oscillating = walk(0.4)
assert oscillating[1][1] < 0
assert abs(oscillating[1][1]) < abs(oscillating[0][1])
unstable = walk(0.55)
assert abs(unstable[-1][1]) > abs(unstable[0][1])
assert bowl(unstable[-1]) > bowl(unstable[0])
ascent = walk(0.2, fault=True)
assert ascent[0] == stable[0]
assert bowl(ascent[1]) > bowl(stable[0])
assert walk(0.2) == stable
```

### 把样本方向平均，而不是悄悄放大步长

为了与扇图对应，所有向量都在同一个 θ=0 上计算。这不是按样本依次更新参数的循环。函数的故障分支仅省略除法。

```python
def batch_gradient(m, s=1.0, fault=False):
    gradients = [(2, s), (2, -s), (-2, s), (-2, -s)][:m]
    total = tuple(sum(g[j] for g in gradients) for j in (0, 1))
    return total if fault else tuple(v / m for v in total)


assert batch_gradient(1) == (2, 1)
assert batch_gradient(2) == (2, 0)
assert batch_gradient(2, s=2) == (2, 0)
assert batch_gradient(4) == (0, 0)
assert batch_gradient(2, fault=True) == (4, 0)
assert batch_gradient(4, fault=True) == (0, 0)  # 会掩盖错误
assert batch_gradient(2) == (2, 0)  # 恢复平均
```

最后用两条函数检查“训练集一样好，范围外也一样好”的错误推论。这里没有用留出点来训练或选模型；它只是一个反例，展示训练样本不足以唯一确定范围外的函数。

```python
training = [(-1.0, 1.0), (1.0, 1.0)]
held_out = [(2.0, 1.0)]


def mse(function, samples):
    return sum((function(x) - y)**2 for x, y in samples) / len(samples)


constant = lambda x: 1.0
square = lambda x: x*x
assert mse(constant, training) == mse(square, training) == 0
assert mse(constant, held_out) == 0
assert mse(square, held_out) == 9
print("PASS: adjoints, contour path, batch mean, held-out counterexample")
```

## 常见误区

三个错误分别位于导数计算、更新距离和评估边界，不能都归咎于“网络没学好”。先确定错在哪个算式，再选择相应的修复方法。

### 误区一：损失对了，导数就一定对

<Callout type="trap">
  **现象 →** 实验一输出的 L 完全正常，却给出错误的 w̄。 **原因 →**
  正向值相同不代表反向局部倍率正确；省略 x 不会改变预测。 **修法 →**
  将输入改为非 1，逐行回写并用中心差分核对最终导数。
</Callout>

### 误区二：每一步方向正确就不会变差

<Callout type="trap">
  **现象 →** 实验二 η=0.55 时上下跳动且逐渐远离中心。 **原因 →**
  导数是局部信息，过大的有限步长越过了可降低损失的区域。 **修法 →**
  用两轴收缩倍率检查步长；不要把所有震荡都称为发散。
</Callout>

### 误区三：批次抵消就说明每个样本都拟合好了

<Callout type="trap">
  **现象 →** 四样本平均箭头为零，扇图却仍有四个非零方向。 **原因 →**
  平均梯度为零不等于每个样本损失为零，也不证明范围外预测正确。 **修法 →**
  检查逐样本结果与独立样本；再用两样本测试求和与平均是否混淆。
</Callout>

## 小结与练习

本节的三个实验不是三个训练阶段的万能模板，而是三种可单独检算的运算。能解释每个故障的首个分岔，才算把公式与画面对应起来。

- 计算带存值后倒序传导数，不能丢局部倍率。
- 等高线给出局部方向，步长决定是否过冲。
- 扇图平均可抵消，低训练误差不保证外推。

**问题 2**：修改实验二的学习率为 0.4 和 0.55，解释它们为何都能上下换边，却只有后者不收敛。再在 Python 中加入 η=0.5 的断言，预测 v 会怎样。

<Answer>

两者的 v 倍率分别为 −0.6 与 −1.2，因此都会换边，前者幅度缩小，后者扩大；u 倍率分别为 0.6 与 0.45，仍收缩。η=0.5 时 v 倍率为 −1，非零 v 的幅度保持不变，可断言 `abs(walk(0.5)[-1][1]) == 1.5`。它不会到中心；若起点 v=0 则是特殊情形，不能用它推出所有起点收敛。

</Answer>

</Answer>
