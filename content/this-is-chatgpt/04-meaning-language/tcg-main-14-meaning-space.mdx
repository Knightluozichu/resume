## 直觉：先想一张压扁的地图

两条公路在航拍图上交叉，不意味着车辆可以在那里换道：它们也许分处桥上和桥下。少画一个高度轴，会改变你对“附近”的判断。把词、句子画到二维平面也有相同的认识风险：图能提供线索，却不能替原始坐标或语义评估作证。

本节的直觉地图是：**表示成点 → 检查投影损失 → 加入上下文看分支 → 提出可被反例拒绝的规则**。三套实验都使用公开定义的微型数学对象，既不提取真实模型内部状态，也不测量当前ChatGPT的语义。我们要练习的是怎样检验解释，不是怎样把漂亮动画命名为定律。

## Meaning Space and Semantic Laws of Motion / 意义空间与语义运动定律

把语言对象画成点，只得到了一种表示，还没有得到支配这些点的定律。本节沿着作者的问题分三步核查：压到平面后邻居是否改变，同一用法在不同上下文中怎样分流，以及一条看似合理的规则能否经受次序反例。每一步都保留独立可算的对照，避免把图上的形状直接当成关于意义的结论。

### 作者在问什么，而非已经证明什么

Wolfram在2023年公开长文中，把文本的数值表示想象为语言特征空间中的点；续写则对应点序列。他进一步问：是否存在约束这些点移动、同时保持文本有意义的“语义运动定律”？这是研究问题，不是宣布已经发现了类似力学的方程。

这里的<Term def="用数值表示语言对象，并在所选坐标与距离下讨论关系的空间；不等于意义本身">意义空间</Term>是表示框架。作者展示的名词与词性布局提供了邻近结构的例子，但一个词并不只有一个意义或词性。他用crane可指鸟或机械的上下文例子，说明仅看孤立词标签可能把不同用法混在一起。我们下一实验用“苹果”的果园/维修情境作人工类比，不声称复现原图或模型。

作者还借类比关系询问空间是否有类似平行移动、局部平直的结构：图上有时能看到迹象，但并不普遍。看到几条近乎平行的关系线，不能跳到“所有关系都能用同一个向量相加”。即使轨迹中真有稳定规律，适合表达它的坐标、变量也未必是当前画出来的轴。

### 实验一：删掉一个轴，谁还是近邻？

<Term def="把高维坐标映到较低维坐标的操作；本节直接丢弃一个轴，因此可能丢失距离信息">
  投影
</Term>
先在一个完全已知的空间里检查。查询点为O=(0,0,0)，其余点为A=(1,0,3)、B=(2,0,0)、C=(0,3,0)。距离均用欧氏距离，近邻不包含查询点本身。符号k为取出的近邻数，N为相应集合，orig和proj分别表示原空间与投影。

$$
d(O,A)=\sqrt{10},\quad d(O,B)=2,\quad d(O,C)=3,\qquad
R_k=\frac{|N_k^{\mathrm{orig}}\cap N_k^{\mathrm{proj}}|}{k}.
$$

人话是：先分别取两份最近的k个点，再数有几个相同。这个召回R只核对几何邻居，不衡量文本是否有意义。

> 预测：xy平面上A只有距离1，它是原空间最近的点吗？把k从1改为2，召回会升到1还是只到一半？

<TcgMain14MeaningSpaceContextContractLab />

1. 默认xy、k=1，逐帧前进到“独立审计”：原排序B→C→A，投影排序A→B→C，集合无交集，R=0。
2. 改k=2，重新推进。原集合为B、C，投影集合为A、B，只有B相同，R=1/2。圈表示投影距离，下方连线显示排名变换，不是语义关联线。
3. 改xz、k=2，投影距离依次为C的0、B的2、A的√10；邻域集合恰好相同，R=1，但顺序仍不同。C与O重叠是丢失y轴造成的，不代表原点重复。
4. 回到xy、k=1，注入“用投影集合自验”。报告变1，独立值仍为0：拿同一份集合和自己比，检验对象已经偷换。撤销故障，再“完整重置”，应回到xy、k=1、首帧、暂停。

即便某个k、某个投影保留了邻域，也不能由这三个点推出所有邻域稳定，更不能推出“二维图反映真实词义”。要评价语言表示，还需任务、上下文和独立语义标注。

### 实验二：上下文改变的是整束候选，不只一条线

<Term def="在固定上下文和当前状态下，为下一状态规定的一组非负且和为1的概率">
  条件转移
</Term>
让我们把分支说清楚。定义五个状态：U为待解释用法，F为果实解释，D为设备解释，R、S为两类后续描述。它们只是人工标签。上下文c决定p：果园p=0.8，维修p=0.2。

第一轮U→F的概率为p，U→D为1−p。第二轮F→R及D→S为r，另两支为1−r；R、S是吸收态。用行向量表示质量，P每行对应“从该状态出发”，状态次序U、F、D、R、S，传播为μ下一轮=μ当前轮P。本例可以不写矩阵，直接算：

$$
\mu_0=(1,0,0,0,0),\quad \mu_1=(0,p,1-p,0,0),\quad
q=P(R)=pr+(1-p)(1-r),\quad \mu_2=(0,0,0,q,1-q).
$$

R有两条入路，因此要把两条路的质量相加。例如果园、r=0.75时，0.8×0.75=0.6来自F，0.2×0.25=0.05来自D，合计q=0.65；S为0.35。

> 预测：只把上下文换为维修，R会变成0.2吗？注意它不仅能从F到达，也能从D到达。

<TcgMain14MeaningSpaceComputeTraceLab />

1. 默认逐帧看U分流，再看第二轮汇流。上方边标签是**到达该边的无条件质量**，不是该边的行条件概率；活动线宽为1+18×质量，零质量边只保留淡虚线结构。三列质量带每列总和都为1。
2. 换维修：第一轮F=0.2、D=0.8；第二轮R=0.2×0.75+0.8×0.25=0.35。不是把首轮p直接抄到最终R。
3. 将r改为1，默认果园得到R=0.8、S=0.2。没有跨侧转移，却仍有两种可能终点，不能把“转移确定”混同“初始解释确定”。
4. 注入“抹去上下文”，首轮被覆盖为各0.5。两种上下文都被画成R=S=0.5，期望终点归零。撤销可恢复分流差异；完整重置恢复果园、r=0.75、无故障、首帧、暂停。

<Term def="按先后排列的状态位置序列；概率模型中的一次路径与各时刻的期望位置序列必须区分">
  轨迹
</Term>
不自动等于期望。为了画图，我们给F、R的纵坐标+1，D、S为−1，U为0；横坐标只是轮数。于是第一轮期望纵坐标为2p−1，末轮为2q−1。果园默认末轮为0.3，维修为−0.3。真实单条路径末点只能在+1或−1；图中虚线期望穿过0.3，并没有第三类语义状态，也不是词在物理空间飞行。

作者原文区分了零温情形下逐步选最大概率候选的轨迹，以及每步候选概率形成的“扇面”。我们的五态模型聚合有限路径的全部质量，**不是**复现其候选词、温度设置或高维内部状态。它只让“单条选择”和“整束分布”的差异可手算。多步扇面可能很复杂，二维中朝某方向展开也不等于受某个物理势场支配。

### 实验三：把“顺序无关”变成可以失败的命题

<Term def="明确指定输入、可观察结果和拒绝条件，使反例能够推翻的陈述">
  可证伪假说
</Term>
要比“看起来有规律”具体。下面不使用词向量；定义两个平面操作，检验它们在给定起点是否可交换。s为正整数强度，起点为(x₀,0)。

$$
A(x,y)=(x+1,y),\quad B_s(x,y)=(x,y+sx),\qquad
B_s(A(x_0,0))=(x_0+1,s(x_0+1)),\quad
A(B_s(x_0,0))=(x_0+1,sx_0).
$$

A只向右移动1；B的竖向改变量取决于**当时**的x。先A会改变随后B读取的x，因此两端点竖向差恰为s。界面AB指“先A后B”，即函数合成B(A(·))，不能反读。

> 预测：默认从(0,0)出发，先B会动吗？把x₀改为1，两条路径端点会重合，还是仍差1？

<TcgMain14MeaningSpaceEvidenceGateLab />

1. 默认x₀=0、s=1，实线路径(0,0)→(1,0)→(1,1)，虚线路径(0,0)→(0,0)→(1,0)。默认B的第一步为零位移，所以两步并非都能看到不同线段。
2. 改x₀=1，可见两种第一步都移动；最终AB=(2,2)、BA=(2,1)，差仍为1。改s=2，差变2，而非随着x₀变成4。
3. 注入“抄终点”：观测BA被抄成AB，报告差0，虚线错误终点与实线合并；独立重算的真实BA保留为空圈，标尺仍显示真实差。数据被覆盖，不是操作突然可交换。
4. 撤销故障并完整重置：恢复x₀=0、s=1、无故障、首帧、暂停。任一改参或故障也会暂停并回首帧，防止旧轨迹与新参数混看。

这拒绝的是“这两个指定操作在该起点顺序无关”。它不证明自然语言必有曲率，也不否认别的规律。作者关于平行移动、平直性乃至测地线的讨论启发我们寻找可检验结构，但本例的剪切操作不是语言实验，更不是对作者一般猜想的证明。

## 把三份账本写成可运行程序

以下Python块按顺序拼成一个文件即可运行，只用标准库，无网络、模型或硬件测量。浮点量用容差断言；不为匹配图示而舍入计算。界面只在SVG输出边界把坐标格式化，避免运行环境末位差影响渲染。

先固定点集与排序方法。原点不放入候选，集合相交只比较身份，不比较绘图位置。

```python
from math import dist, isclose, isfinite
import json

POINTS = {"A": (1, 0, 3), "B": (2, 0, 0), "C": (0, 3, 0)}
ORIGIN = (0, 0, 0)

def neighbors(plane, k):
    assert plane in ("xy", "xz") and k in (1, 2)
    axis = 1 if plane == "xy" else 2
    original = sorted(POINTS, key=lambda n: dist(ORIGIN, POINTS[n]))
    projected = sorted(POINTS, key=lambda n:
                       dist((0, 0), (POINTS[n][0], POINTS[n][axis])))
    shared = set(original[:k]) & set(projected[:k])
    return original, projected, len(shared) / k

assert neighbors("xy", 1) == (["B", "C", "A"], ["A", "B", "C"], 0)
assert neighbors("xy", 2)[2] == 0.5
assert neighbors("xz", 1)[2] == 0
assert neighbors("xz", 2)[2] == 1
```

再定义概率流。矩阵不是必要输入：两条到R的路径已经足够计算q，同时保存每轮状态质量供独立检查。

```python
def flow(context, r, fault=False):
    assert context in ("orchard", "repair") and r in (0.75, 1)
    p = 0.5 if fault else {"orchard": 0.8, "repair": 0.2}[context]
    q = p * r + (1 - p) * (1 - r)
    rows = ((1, 0, 0, 0, 0), (0, p, 1-p, 0, 0), (0, 0, 0, q, 1-q))
    return {"p": p, "q": q, "mean_y": 2*q-1, "rows": rows}

for context, expected in (("orchard", 0.65), ("repair", 0.35)):
    result = flow(context, 0.75)
    assert isclose(result["q"], expected, abs_tol=1e-12)
    for row in result["rows"]:
        assert all(isfinite(v) and 0 <= v <= 1 for v in row)
        assert isclose(sum(row), 1, abs_tol=1e-12)
assert isclose(flow("orchard", 0.75)["mean_y"], 0.3, abs_tol=1e-12)
assert isclose(flow("repair", 1)["q"], 0.2, abs_tol=1e-12)
```

第三份账本逐次调用操作，而不是直接填写期望终点。断言比较两次真实组合，不能用抄写后的观测替代它们。

```python
def A(point):
    x, y = point
    return x + 1, y

def B(point, s):
    x, y = point
    return x, y + s*x

def order(x0, s):
    assert x0 in (0, 1) and s in (1, 2)
    start = (x0, 0)
    ab, ba = B(A(start), s), A(B(start, s))
    return ab, ba, dist(ab, ba)

assert order(0, 1) == ((1, 1), (1, 0), 1)
assert order(1, 1) == ((2, 2), (2, 1), 1)
assert order(1, 2) == ((2, 4), (2, 2), 2)
```

最后把故障与真值并列。错误报告满足自己的检查，并不能让独立真值改变；这些断言正是三种故障必须暴露的差异。

```python
projection_true = neighbors("xy", 1)[2]
projection_bad = len({"A"} & {"A"}) / 1
assert projection_bad == 1 and projection_true == 0
normal = flow("orchard", 0.75)
erased = flow("orchard", 0.75, fault=True)
assert erased["q"] == 0.5 and erased["mean_y"] == 0
assert isclose(normal["q"] - erased["q"], 0.15, abs_tol=1e-12)
ab, ba, true_gap = order(0, 1)
observed_ba = ab
assert dist(ab, observed_ba) == 0 and true_gap == 1 and ba == (1, 0)

for x0 in (0, 1):
    for s in (1, 2):
        assert order(x0, s)[2] == s
for context in ("orchard", "repair"):
    for r in (0.75, 1):
        assert isclose(flow(context, r, True)["q"], 0.5, abs_tol=1e-12)
        for fault in (False, True):
            for row in flow(context, r, fault)["rows"]:
                assert all(isfinite(v) and 0 <= v <= 1 for v in row)
                assert isclose(sum(row), 1, abs_tol=1e-12)
print(json.dumps({"xy_k2": neighbors("xy", 2)[2],
                  "orchard_q": normal["q"], "erased_q": erased["q"],
                  "order_gap": true_gap}, sort_keys=True))
```

这一输出应包含xy_k2=0.5、orchard_q≈0.65、erased_q=0.5、order_gap=1。它证明程序满足本节有限定义，不证明训练出了意义，也没有访问ChatGPT。若要在真实模型检验类似假说，需要指定层、表示提取方法、投影算法、上下文样本与独立评价；不能把本节坐标换上模型名字就算实验。

## 三个常见误区

三套实验的错误都有一个共同入口：把需要验证的对象悄悄换掉。平面距离不能代替原空间距离，分布的期望不能代替一次可达路径，一个次序反例也不能代替对所有语言规律的判断。下面分别追查被替换的对象，再给出能抓住错误的独立检查。

<Callout type="trap" title="平面很近，所以意义很近？">
  现象：A在xy图上最近，便把它认作原空间近邻。原因：丢掉z后抹去了A的高度。修法：同一身份回查原空间排序，并改变投影和k；召回合格也只代表这份几何检查合格。
</Callout>

<Callout type="trap" title="虚线经过0.3，所以产生了中间意义？">
  现象：把期望连线当成一次实际路径。原因：将分布的平均位置误当状态集合新增的元素。修法：检查可达终点只有R、S，并同时保留各轮质量；平均可以不属于可达状态。
</Callout>

<Callout type="trap" title="一个反例，就能裁定所有语言规律？">
  现象：次序差不为零便宣布不存在语义规律。原因：把一个明确的可交换命题扩成所有可能规律。修法：写清操作、起点、差值及拒绝条件；拒绝后仍可研究别的操作或变量，不能以换坐标为由逃避检验。
</Callout>

## 小结

本节能交出的不是一条语义运动方程，而是三种检查解释的方法：保留投影前的邻居作对照，沿上下文条件传播完整概率质量，并用两种操作次序独立重算端点。它们让一个具体说法可以失败，却不把人工算例升级成语言的普适规律。

- 投影可丢失邻居；回查原空间才知损失。
- 上下文改变概率流，期望线不等于单条路径。
- 有限反例只拒绝所写命题，不能制造普适定律。

作者在该节结尾明确保留了未知：还不能从当时内部行为的经验观察中解码模型所发现的语言结构。“也许变量选错了”是后续研究方向，不是测地线或物理式规律已被证实的证据。接下来的语义语法章节讨论另一层结构，不能替这一未知补上未经验证的答案。

</Answer>

**问题 3：反例拒绝了什么？**

起点(1,0)、s=2时，计算两端点。若程序把BA覆盖为AB，应保存哪份独立结果，才能发现假通过？

<Answer>
  先A后B为(2,4)，先B后A为(2,2)，欧氏距离2。保留原始起点与两个操作，分别执行组合而非复制端点；覆盖后报告虽为0，独立差仍为2。只拒绝这两个操作在该起点可交换的命题，不证明任何语言模型必然遵循它们。
</Answer>

</Exercises>

## 人话词典

这里把五个关键词按实验中的用途收束起来：意义空间是表示框架，投影可能丢失邻居，条件转移规定分支概率，轨迹记录先后位置，可证伪假说则必须允许反例拒绝。回看图形时，要同时记住这些词各自没有承诺什么，尤其不能把表示或期望连线当成意义本身。

<Glossary>
  <GlossaryItem term="意义空间">
    把语言对象表示成点并讨论数值关系的空间；坐标不是意义本身。
  </GlossaryItem>
  <GlossaryItem term="投影">
    降低坐标维数的映射；看起来邻近可能是信息丢失的结果。
  </GlossaryItem>
  <GlossaryItem term="条件转移">
    固定上下文后，从当前状态到下一状态的一行概率。
  </GlossaryItem>
  <GlossaryItem term="轨迹">
    有先后顺序的位置序列；单次路径与期望位置序列不是一回事。
  </GlossaryItem>
  <GlossaryItem term="可证伪假说">
    指定结果与拒绝条件，允许反例推翻的陈述。
  </GlossaryItem>
</Glossary>
