## 实验一：同一次扰动，三种后续命运

先预测：第二步注入0.2，后面不再加新扰动。反馈增益分别为0.5、1、1.25时，第六步的差异会小于、等于还是大于0.2？不要把“以后没有新错误”误认为“旧差异已消失”。

<Term def="让两个过程共享起点与外部条件，仅改变一个因素，并逐步比较状态差异。">
  耦合比较
</Term>
把参考轨迹与受扰轨迹放在同一坐标系，避免把输入变化误归因于反馈。这里两者起点都是0.1，每步都加0.02；第二条轨迹只在指定步额外加一次数值。
<Term def="只在指定一步加入、其余步骤为零的外部扰动。">脉冲扰动</Term>
之后仍可能通过前一步状态继续传递，这正是要比较的对象。

符号约定：$t$是离散步；$r_t$是参考状态；$s_t$是受扰状态；$a$是反馈增益；$\varepsilon$是注入幅度；$k$是注入步；$\delta_t=s_t-r_t$。两条更新规则是 $r_t=a r_{t-1}+0.02$ 与 $s_t=a s_{t-1}+0.02+\varepsilon\mathbf{1}_{t=k}$。

$$
\delta_t=a\delta_{t-1}+\varepsilon\mathbf{1}_{t=k},\qquad
\delta_t=\begin{cases}0&t<k\\\varepsilon a^{t-k}&t\geq k.\end{cases}
$$

这个式子在说：共同输入抵消后，偏差由一次注入和后续重复相乘决定；它不是从真实ChatGPT测得的误差增长律。

<TcgOfficialFinalReviewContextContractLab />

操作顺序：保留默认 $a=1.25,\varepsilon=0.2,k=2$，逐帧走到第六步，得到差异约**0.48828125**。只把增益换成0.5，末差降为**0.0125**；换成1则保持**0.2**。横轴是步数，固定纵轴是状态值，实线与虚线之间的竖线标出同一步差异。改变注入步会移动竖向标记并缩短或延长传播长度。

打开故障后，每一步错误借用参考前值，而不是受扰轨迹自己的前值。第2步仍有0.2，第3步却立即归零；这不是稳定反馈的证据，而是把要测的反馈切断了。完整重置恢复1.25、0.2、第2步注入、故障关、第0帧、暂停与零进度。本实验没有抽样token，没有测量真实生成错误率，也没有模拟网络内部的反向求导。

## 实验二：什么变化会被归一化抵消

先预测：三项分数从 `[-1,0,1]` 变成 `[1,2,3]`，概率会不会变化？若改成 `[-2,0,2]` 呢？两个操作都改变数字，却改变了不同的关系。

<Term def="对规定的一类变换保持不变的量或关系；必须明确变换作用于哪些对象。">
  不变量
</Term>
不能脱离前提使用。对softmax，给**所有项共同加同一个数**会抵消，但共同乘尺度一般不会。

符号约定：$z_i$是第$i$项原分数；$s$是共同尺度；$c$是共同平移；$p_i$是归一化概率。实验使用 $z=(-1,0,1)$ 与 $p_i=e^{s z_i+c}/\sum_j e^{s z_j+c}$。

$$
\frac{e^{s z_i+c}}{\sum_j e^{s z_j+c}}
=\frac{e^{s z_i}}{\sum_j e^{s z_j}},\qquad
\frac{p_3}{p_2}=e^{s(z_3-z_2)}.
$$

这个式子在说：共同的指数因子约掉了；尺度却留在分数差里，所以会改变概率比。实现先减最大分数再指数运算，以稳定计算，而不是先四舍五入分数。

<TcgOfficialFinalReviewComputeTraceLab />

按帧看原分数、共同缩放、添加平移和比较概率。默认尺度1、平移2，末帧概率约为 **[0.090031, 0.244728, 0.665241]**，与平移前重合；上方分数点已经移动，下方概率点却仍在空心圈中央。尺度改成2后，概率约为 **[0.015876, 0.117310, 0.866813]**，重心向第三个顶点移动。三角形表示三项概率之和为1，不是把高维语义压到二维。

打开故障，只给第三项加2，分数成为 `[-1,0,3]`，概率约为 **[0.017148, 0.046613, 0.936240]**，点与圈分开，$p_3/p_2$从$e$变成$e^3$。这没有推翻共同平移不变量：故障已经破坏“共同”前提。平移设为0会掩盖故障，不能用此单例宣布修复。完整重置恢复尺度1、平移2、故障关、原分数帧、暂停和零进度；本实验没有温度抽样或目标梯度训练。

## 实验三：找出能区分两条规则的输入

先预测：规则A、B在输入 `0`、`1`、`11` 后都输出 `0`、`1`、`1`，可以直接互换吗？先不要增加更多同类型样本，试着让一个1后面跟几个0。

<Term def="两个规则在指定有限观测集上的输出相同，不意味着内部状态或所有输入上的行为相同。">
  观测等价
</Term>
描述的是相对于观测集的关系。目标A判断“是否曾经出现1”，一旦见1就永远输出1；B则把记忆设为$L$，每读一个0减1，降到0便输出0。两条规则事先写死，**没有拟合、训练或模型选择算法**。

<Term def="能让两个候选规则产生不同输出的合法输入。">区分输入</Term>
比重复查看同样的成功记录更有用。令$g$是1后面零的数量，B的剩余记忆是$\max(0,L-g)$；只要$g\geq
L$，A仍输出1，B已输出0。因此这两条规则的最短区分串是 `1` 后接 $L$ 个 `0`，长度
$L+1$。

<TcgOfficialFinalReviewEvidenceGateLab />

默认 $L=2,g=2$。第0帧显示三个已见样本；第1帧重置探测状态；第2帧读1，A到吸收态1、B到状态2；第3帧读0，B到1；第4帧再读0，B到0，A仍为1。继续到后两帧只表示没有更多输入，不会暗中追加字符。图中A的回环表示记忆保留，B的阶梯表示零使记忆递减，虚线表示1使记忆复位，底部已着色方格表示真正读过的字符。

故障根据三个样本相同就拿B替代目标A，输出连线从A切换到B，因此在默认第4帧给出错误的0。把$L$改成3、$g$仍为2，最终又相同；这只是探测串不够长。把$g$增至3才暴露差异。完整重置恢复记忆2、零数2、故障关、样本帧、暂停、零进度和未发布状态。本实验不是奇偶校验，也不是“所有模型永远无法识别”的证明；它只构造了有限观测不能唯一确定规则的一个反例。

## 用标准库复算三个关系

按顺序把以下三块保存到同一个Python文件执行。它们只用标准库与有限循环，断言对应图中的数值和边界；没有训练大模型、网络请求、真实API或GPU计时。小数比较使用容差，不把显示用的四位小数反馈进运算。

```python
from math import exp, isclose

def coupled(a=1.25, epsilon=0.2, k=2, fault=False):
    r, s = [0.1], [0.1]
    for t in range(1, 7):
        r.append(a * r[-1] + 0.02)
        prior = r[t - 1] if fault else s[-1]
        s.append(a * prior + 0.02 + (epsilon if t == k else 0))
    return [y - x for x, y in zip(r, s)]

for a, expected in ((0.5, 0.0125), (1, 0.2), (1.25, 0.48828125)):
    assert isclose(coupled(a)[6], expected, abs_tol=1e-12)
assert isclose(coupled(fault=True)[2], 0.2, abs_tol=1e-12)
assert coupled(fault=True)[3:] == [0.0] * 4
```

接着只改变分数变换，保留相同归一化函数。共同平移不变与错误的单项平移在同一组断言中比较。

```python
def softmax(values):
    maximum = max(values)
    weights = [exp(v - maximum) for v in values]
    return [w / sum(weights) for w in weights]

def distribution(scale=1, shift=2, fault=False):
    return softmax([scale * z + (shift if not fault or i == 2 else 0)
                    for i, z in enumerate((-1, 0, 1))])

base = softmax([-1, 0, 1])
for c in (-4, -2, 0, 2, 4):
    assert all(isclose(a, b, abs_tol=1e-12)
               for a, b in zip(base, distribution(1, c)))
assert isclose(distribution(2)[2], 0.8668133321973349)
p = distribution(fault=True)
assert isclose(p[2] / p[1], exp(3))
assert distribution(1, 0, True) == distribution(1, 0, False)
```

最后穷举短输入而不是拟合曲线。它验证“最短”仅针对这里预先给定的两条规则；未把它泛化到任意学习系统。

```python
from itertools import product

def machines(word, memory=2):
    a = b = 0
    for symbol in word:
        a = 1 if symbol == "1" else a
        b = memory if symbol == "1" else max(0, b - 1)
    return a, int(b > 0)

for memory in (1, 2, 3):
    assert [machines(w, memory) for w in ("0", "1", "11")] == [(0, 0), (1, 1), (1, 1)]
    for n in range(memory + 1):
        assert all(a == b for a, b in
                   (machines("".join(w), memory) for w in product("01", repeat=n)))
    assert machines("1" + "0" * memory, memory) == (1, 0)
assert machines("100", 3) == (1, 1)
assert machines("1000", 3) == (1, 0)
print("finite coupling/invariance/distinguishability assertions passed")
```

## 三个需要纠正的推断

三组比较的错处不在同一个地方：实验一错换了反馈来源，实验二错换了变换范围，实验三错把局部输出一致升级成规则可替换。先指出前提变化，再讨论数值，才能避免用末端成功掩盖机制错误。

<Callout type="trap" title="没有新扰动，就没有旧偏差？">
  **现象 →** 只在第2步改一次，之后应立即回到参考线。**原因 →**
  把外部扰动为零与内部状态差为零混淆；默认后续仍乘1.25。**修法 →**
  比较两条各自反馈的轨迹，逐步验证差异；若一步归零，检查是否像故障一样偷偷换回参考输入。
</Callout>

<Callout type="trap" title="任何分数改变都改变概率？">
  **现象 →** 上方三个分数点移动，概率点必须移动。**原因 →**
  忽略共同加常数被归一化抵消，也可能把只改一项误说成共同平移。**修法 →**
  先写出所有分数的变换，再计算概率比；用非零平移测试前提，不能只测平移0。
</Callout>

<Callout type="trap" title="样本全对，所以两个规则一样？">
  **现象 →** A、B对三个样本输出一样，可以随意替换。**原因 →**
  已见输入没让记忆耗尽，状态差尚未显露。**修法 →**
  根据候选规则构造区分串，并明确目标是A；若只报告二者不同而未声明任务，不能直接宣布谁正确。
</Callout>

## 小结与迁移边界

这次复习从三种关系收束论证：差异可能通过反馈延续；表示改变也可能保留分布；有限观测相同却可能隐藏不同规则。它们分别限制了“以后没有新错就恢复”“数字变了能力就变了”“旧题都对所以新题也对”三种直觉。迁移到真实系统时，还须重新定义状态、变换和测试输入，不能套用本页的数值。

- 生成循环与单次前向计算不同；标量反馈只是隔离机制的替身。
- 证明不变量必须保留变换前提；尺度、共同平移和单项平移不可混用。
- 新输入能否区分候选规则，比重复计算旧样本的通过率更有信息。

<Answer>

</Answer>

## 名词解释

五个词分别定位比较方法、扰动形式、变换性质以及有限观测能支持的结论。回看实验时，应能把每个定义对应到具体轨迹、概率点或输入串，而不是只背名称。

<Glossary>
  <GlossaryItem term="耦合比较">
    固定共同条件并对齐两条过程，逐步比较单一变化造成的状态差；实验一共享起点和每步常数输入。
  </GlossaryItem>
  <GlossaryItem term="脉冲扰动">
    只在指定一步注入的变化；后续是否继续存在，取决于反馈，而不取决于是否继续外部注入。
  </GlossaryItem>
  <GlossaryItem term="不变量">
    在明确规定的变换下保持的量；实验二概率对共同加常数不变，共同缩放通常会改变概率。
  </GlossaryItem>
  <GlossaryItem term="观测等价">
    相对于某个有限观测集输出相同；不宣称内部状态相同或所有输入行为相同。
  </GlossaryItem>
  <GlossaryItem term="区分输入">
    使两个候选规则输出不同的合法输入；实验三最短串为一个1后接L个0。
  </GlossaryItem>
</Glossary>
