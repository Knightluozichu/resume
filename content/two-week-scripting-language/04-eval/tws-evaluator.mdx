## 求值器的作用

求值器（Evaluator）是解释器的**后端核心**：通过访问者模式遍历 AST，执行计算，将程序逻辑转化为实际效果。

```text
AST 根节点  ──Evaluator 遍历──→  执行结果
  program       递归 eval        Integer / String / Object
```

## 环境（Environment）

环境是**变量绑定的容器**，存储变量名到值的映射。这是求值器的核心数据结构。

### 环境结构

```java
public class Environment {
    private Map<String, Object> values;  // 变量名 → 值
    private Environment outer;            // 外层环境引用
}
```

### 变量查找规则

```text
get("x") 查找过程:

  当前环境 E3: { z=10 }        ← 找不到 x
       ↓ outer
  函数环境 E2: { y=5, x=3 }    ← 找到 x=3，返回 3
       ↓ outer
  全局环境 E1: { even=0 }
```

| 操作 | 行为 |
|------|------|
| `get(name)` | 当前环境找 → outer 找 → ... → 全局环境 |
| `put(name, value)` | 直接写入当前环境 |

<Callout type="info">

这种链式查找机制实现了**词法作用域**——内层代码可以访问外层变量，但外层不能访问内层变量。

</Callout>

## 各 AST 节点的求值规则

| 节点类型 | 求值规则 | 返回值 |
|---------|---------|--------|
| NumberLiteral | `Integer.valueOf(text)` | 整数值 |
| StringLiteral | 字符串内容（去除引号） | String |
| Name | `env.get(name)` 查找绑定值 | 绑定的值 |
| BinaryExpr | 先求左右子树，再按运算符计算 | 运算结果 |
| IfStmnt | 求值条件，true 执行 then 块 | 块结果或 null |
| WhileStmnt | 循环求值条件+循环体直到 false | null |
| BlockStmnt | 依次求值每条子语句 | 最后一条的值 |

### BinaryExpr 求值示例

```text
表达式: x + y * 2  (x=3, y=4)

AST:  BinaryExpr(+)
       /          \
   Name(x)    BinaryExpr(*)
              /        \
          Name(y)   Number(2)

求值过程:
  1. 求 Name(x) → env.get("x") → 3
  2. 求 BinaryExpr(*):
     2a. 求 Name(y) → env.get("y") → 4
     2b. 求 NumberLiteral(2) → 2
     2c. 4 * 2 = 8
  3. 3 + 8 = 11

结果: 11
```

## IfStmnt 与 WhileStmnt

### IfStmnt 求值

```text
if (x > 0) { ... } else { ... }

求值流程:
  1. 求值条件表达式 x > 0
  2. 条件为 true → 求值 then 块，返回结果
  3. 条件为 false → 求值 else 块（如果存在）
```

### WhileStmnt 求值

```text
while (i < 10) { i = i + 1 }

求值流程:
  1. 求值条件 i < 10
  2. true → 求值循环体 i = i + 1
  3. 重复步骤 1-2，直到条件为 false
  4. 返回 null
```

<Callout type="warning">

Stone 中条件判断的「真值」规则：**非零整数为 true，零为 false**。字符串等非整数类型用于条件会抛出类型异常。

</Callout>

## 树遍历解释器总结

```text
树遍历解释器 = 递归 eval + 环境链查找

特点:
  ✓ 无中间字节码，直接在 AST 上执行
  ✓ 结构清晰，易于理解和实现
  ✓ 递归求值，自然反映 AST 的树形结构
  ✗ 性能较低（每次执行都要遍历 AST）
```

### 问题 1

求值器的作用是什么？它如何遍历 AST？

<Answer>

求值器的作用是遍历 AST 并执行计算，将程序逻辑转化为实际效果。它通过访问者模式遍历 AST：从根节点开始，对每个节点调用 accept(visitor)，visitor 为每种节点类型实现对应的 eval 方法。表达式节点 eval 返回计算值，语句节点 eval 执行副作用（如变量赋值）并返回 null。递归地对子节点求值，直到叶子节点。

</Answer>

### 问题 2

环境是什么？变量的 get 和 put 操作如何工作？

<Answer>

环境是变量绑定的容器，存储变量名到值的映射。每个 Environment 持有 values（Map）和 outer（外层环境引用）。get 操作：先在当前环境的 values 中查找变量名，找到则返回值；未找到则递归到 outer 环境查找，直到全局环境。put 操作：直接将变量名和值写入当前环境的 values 中。这种链式查找机制实现了词法作用域——内层代码可以访问外层变量，但外层不能访问内层变量。

</Answer>

### 问题 3

BinaryExpr 节点是如何求值的？以 `x + y * 2` 为例说明完整求值过程。

<Answer>

BinaryExpr 求值步骤：①先递归求值左子树得到左操作数值 ②递归求值右子树得到右操作数值 ③根据运算符 Token 执行对应运算，返回结果。以 `x + y * 2` 为例：AST 根为 BinaryExpr(+)，左子树 Name(x)，右子树 BinaryExpr(*)。求值时先求 Name(x) → env.get("x") 得到 3，再求 BinaryExpr(*)：求 Name(y) → 4，求 NumberLiteral(2) → 2，执行 4*2=8。最后执行 3+8=11，返回 11。

</Answer>

### 问题 4

IfStmnt 和 WhileStmnt 的求值逻辑分别是什么？

<Answer>

IfStmnt 求值：先递归求值条件表达式得到布尔值，如果为 true 则求值 then 分支的语句块并返回结果，否则求值 else 分支（如果存在）。WhileStmnt 求值：循环执行——先求值条件表达式，如果为 true 则求值循环体语句块，然后再次求值条件，如此循环直到条件为 false。循环体求值结果被丢弃，WhileStmnt 最终返回 null。两者都依赖条件表达式的求值结果来控制流程，条件非零整数视为 true，零视为 false。

</Answer>
