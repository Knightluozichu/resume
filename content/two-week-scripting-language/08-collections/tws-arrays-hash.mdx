## 数组与哈希表

Stone 支持两种集合类型：数组（Array）和哈希表（Hash）。

<TwsArraysHashDiagram />

### 数组

```text
a = [10, 20, 30]       // 创建数组
a[0]                   // → 10（索引访问）
a[1] = 99              // 修改元素
// 底层: Java ArrayList<Object>
```

### 哈希表

```text
h = {"name": "Stone", "ver": 1}   // 创建哈希表
h["name"]                          // → "Stone"（键访问）
h["x"] = 99                        // 新增键值对
// 底层: Java HashMap<Object, Object>
```

## 内部结构

### 数组内存结构

```text
索引:    [0]    [1]    [2]
值:      10     99     30
              ↑ 已修改
有序存储，O(1) 随机访问
```

### 哈希表内部结构

```text
键            值
"name"   →   "Stone"
"ver"    →   1
"x"      →   99

键经 hash 计算定位桶，O(1) 平均查找
```

## 索引表达式求值

数组 `a[i]` 和哈希 `h[key]` **共用同一种语法**，在 AST 中表示为 `IndexExpr` 节点：

```text
IndexExpr
  ├── 目标表达式 (a / h)
  └── 索引表达式 (i / "key")
```

### 求值流程

```text
求值 a[i]:

  1. 求值目标表达式 a → 得到集合对象
  2. 求值索引表达式 i → 得到索引值
  3. instanceof 判断集合类型:
     ArrayList → 用整数索引调用 get/put
     HashMap   → 用键对象调用 get/put
  4. 执行索引操作，返回结果
```

<Callout type="info">

Array 和 Hash 共用 `[]` 语法，通过**运行时类型分发**到不同操作。这是动态类型语言的典型特征——同一语法适配多种类型。

</Callout>

## 数组 vs 哈希表对比

| 对比维度 | 数组 Array | 哈希表 Hash |
|---------|-----------|------------|
| 索引类型 | 整数（从 0 开始） | 任意类型（通常 String） |
| 有序性 | 有序（按插入顺序） | 无序 |
| 底层实现 | `ArrayList<Object>` | `HashMap<Object, Object>` |
| 访问复杂度 | O(1) 随机访问 | O(1) 平均查找 |
| 语法 | `[1, 2, 3]` | `{"k": v}` |
| 访问 | `a[0]` | `h["k"]` |

<Callout type="warning">

用字符串索引数组（`a["x"]`）或用整数索引哈希表虽然语法合法，但语义不同。类型不匹配时抛出异常。

</Callout>

## 索引赋值

```text
a[1] = 99      // 数组赋值：替换索引 1 的元素
h["x"] = 99    // 哈希赋值：新增或更新键 "x" 的值
```

索引赋值也是 IndexExpr，求值器区分 get 和 put：作为赋值目标时执行 put，作为表达式时执行 get。

<Glossary>

<GlossaryItem term="数组（Array）">
Stone 的有序集合类型，用方括号 `[1, 2, 3]` 创建，用整数索引访问。底层用 Java ArrayList 实现，O(1) 随机访问。
</GlossaryItem>

<GlossaryItem term="哈希表（Hash）">
Stone 的键值映射类型，用花括号 `{"k": v}` 创建，用任意类型键访问。底层用 Java HashMap 实现，O(1) 平均查找。
</GlossaryItem>

<GlossaryItem term="IndexExpr（索引表达式）">
AST 中表示 `a[i]` 语法的节点，包含目标表达式和索引表达式两个子节点。求值器按目标类型分发到 ArrayList 或 HashMap 操作。
</GlossaryItem>

<GlossaryItem term="运行时类型分发">
同一语法根据操作数的运行时类型执行不同操作。`a[i]` 根据 a 是 ArrayList 还是 HashMap 分发到不同的 get/put 实现。
</GlossaryItem>

</Glossary>

<Exercises>

### 问题 1

Stone 中如何创建和访问数组？数组底层用什么实现？

<Answer>

创建数组用方括号语法：`a = [10, 20, 30]`。访问元素用整数索引：`a[0]` 返回 10。修改元素：`a[1] = 99`。数组底层用 Java 的 ArrayList 实现，有序、可变长度。数组元素可以是任意 Stone 值（Integer、String、Function、StoneObject 等），支持混合类型存储。索引从 0 开始，越界访问抛出运行时异常。

</Answer>

### 问题 2

Stone 中如何创建和访问哈希表？哈希表底层用什么实现？

<Answer>

创建哈希表用花括号语法：`h = {"name": "Stone", "ver": 1}`，键和值用冒号分隔。访问值用方括号加键：`h["name"]` 返回 "Stone"。新增键值对：`h["x"] = 99`。哈希表底层用 Java 的 HashMap 实现，键可以是任意类型（通常用 String），值也可以是任意类型。哈希表是无序的键值映射，平均查找复杂度 O(1)。

</Answer>

### 问题 3

索引表达式 `a[i]` 在 AST 中如何表示？求值器如何处理数组索引和哈希索引？

<Answer>

索引表达式在 AST 中表示为 IndexExpr 节点，包含两个子节点：目标表达式（a）和索引表达式（i）。求值器处理 IndexExpr 的流程：①递归求值目标表达式得到集合对象 ②递归求值索引表达式得到索引值 ③用 instanceof 判断集合对象类型：如果是 ArrayList 则用整数索引调用 get/put；如果是 HashMap 则用键对象调用 get/put ④类型不匹配抛出异常。Array 和 Hash 共用同一种语法 `a[i]`，通过运行时类型分发到不同操作。

</Answer>

### 问题 4

数组和哈希表在索引类型、有序性、底层实现上有什么区别？

<Answer>

三方面区别：①索引类型——数组用整数索引（从 0 开始），哈希表用任意类型键（通常 String）②有序性——数组有序（按插入顺序存储），哈希表无序（基于 hash 函数定位）③底层实现——数组用 ArrayList（基于动态数组，O(1) 随机访问），哈希表用 HashMap（基于哈希桶，O(1) 平均查找）。两者都用 `[]` 语法访问，但语义不同——数组是位置访问，哈希表是键查找。

</Answer>
