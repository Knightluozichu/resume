## 可复现实验

逐项对照保存的文章索引，为每个条目定位章节页、实验、交互图和复习题。先预测旧目录遗漏最多的领域，再检查 C#、数据表、模型动画、渲染、AI 与寻路是否恢复。

最小实现只暴露本章关键状态，不把因果藏进通用框架。

```csharp
const verifiedChapters = [1, 2, 3, 4, 5, 6, 7, 8, 10] as const;
const missingFromIndex = [9] as const;

function isVerified(chapter: number) {
  return verifiedChapters.includes(chapter as never);
}
```

统一证据契约把结构、版本和故障计划放在同一结果中。

```ts
type LeadProgramEvidence = {
  chapter: "u3ap-official-learning-map";
  runtimeVersion: string;
  sample: "baseline" | "boundary" | "failure";
  stages: readonly string[];
  firstDeviation: string | null;
  decision: "pass" | "rejected";
};

function canRelease(run: LeadProgramEvidence): boolean {
  return run.stages.length === 6 &&
    (run.sample !== "failure" || run.decision === "rejected");
}
```

证据日志至少保留下列字段，并与捕获文件使用同一运行编号。

```text
stage,name,sample,input,observation,result
1,确认连载身份,baseline,planned,observed,pass
2,核对文章索引,baseline,planned,observed,pass
3,映射九个章节,baseline,planned,observed,pass
4,标记缺失第9章,baseline,planned,observed,pass
5,建立实验题库,baseline,planned,observed,pass
6,全链验收,baseline,planned,observed,pass
```

## 两个必须主动制造的失败

<Callout type="trap" title="局部结论没有运行证据">
  把在线连载误写成正式出版书，并用架构、内存、热更新、CI/CD 十页自拟课程替换原作者的九章文章索引。必须保存故障版本和首个偏离节点，再用相同输入验证修复。
</Callout>

<Callout type="trap" title="指标改善但系统边界退化">
  故意让一个平均指标变好，同时删除版本、长尾、内存、协议、画质或交接证据。只要“9 个可验证编号章节全部有独立页面，48 个文章主题逐项命中，第9章缺号被明确标注且没有虚构内容。”不成立，即使演示成功也必须拒绝。
</Callout>
