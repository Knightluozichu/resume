## 可复现实验

建立角色配置和本地化文本两张小表，固定 schema 版本。先预测重复主键、缺失引用和缺失语言键的错误位置，再注入三种故障验证构建门。

最小实现只暴露本章关键状态，不把因果藏进通用框架。

```csharp
public sealed record HeroRow(int Id, string NameKey, int BaseHp);

static void Validate(HeroRow row, ISet<int> ids)
{
    if (!ids.Add(row.Id)) throw new InvalidOperationException("duplicate id");
    if (row.BaseHp <= 0) throw new InvalidOperationException("invalid hp");
}
```

统一证据契约把结构、版本和故障计划放在同一结果中。

```ts
type LeadProgramEvidence = {
  chapter: "u3ap-03-data-tables";
  runtimeVersion: string;
  sample: "baseline" | "boundary" | "failure";
  stages: readonly string[];
  firstDeviation: string | null;
  decision: "pass" | "rejected";
};

function canRelease(run: LeadProgramEvidence): boolean {
  return run.stages.length === 6 &&
    (run.sample !== "failure" || run.decision === "rejected");
}
```

证据日志至少保留下列字段，并与捕获文件使用同一运行编号。

```text
stage,name,sample,input,observation,result
1,分类数据,baseline,planned,observed,pass
2,声明 schema,baseline,planned,observed,pass
3,导出生成,baseline,planned,observed,pass
4,验证引用,baseline,planned,observed,pass
5,加载运行时,baseline,planned,observed,pass
6,切换语言复验,baseline,planned,observed,pass
```
