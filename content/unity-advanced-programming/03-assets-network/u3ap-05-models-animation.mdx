## 可复现实验

对同一批模型分别保持独立、静态合并和运行时合并，固定相机路径。先预测 Draw Call、剔除、内存和加载耗时，再销毁场景验证依赖是否归零。

最小实现只暴露本章关键状态，不把因果藏进通用框架。

```csharp
public sealed class AssetLease<T> : IDisposable where T : UnityEngine.Object
{
    public T Asset { get; }
    private readonly Action release;
    public AssetLease(T asset, Action release) { Asset = asset; this.release = release; }
    public void Dispose() => release();
}
```

统一证据契约把结构、版本和故障计划放在同一结果中。

```ts
type LeadProgramEvidence = {
  chapter: "u3ap-05-models-animation";
  runtimeVersion: string;
  sample: "baseline" | "boundary" | "failure";
  stages: readonly string[];
  firstDeviation: string | null;
  decision: "pass" | "rejected";
};

function canRelease(run: LeadProgramEvidence): boolean {
  return run.stages.length === 6 &&
    (run.sample !== "failure" || run.decision === "rejected");
}
```
