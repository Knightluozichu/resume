## 可复现实验

从干净工程运行一个配置驱动的联网角色场景，按章节依次注入重复主键、UI 残留订阅、资源泄漏、丢包乱序、Shader 变体膨胀、AI 中断和不可达地图。

最小实现只暴露本章关键状态，不把因果藏进通用框架。

```csharp
type LeadProgramGate = {
  chapter: 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 10;
  baseline: string;
  failureRejected: boolean;
  regressionPassed: boolean;
};
```

统一证据契约把结构、版本和故障计划放在同一结果中。

```ts
type LeadProgramEvidence = {
  chapter: "u3ap-official-final-review";
  runtimeVersion: string;
  sample: "baseline" | "boundary" | "failure";
  stages: readonly string[];
  firstDeviation: string | null;
  decision: "pass" | "rejected";
};

function canRelease(run: LeadProgramEvidence): boolean {
  return run.stages.length === 6 &&
    (run.sample !== "failure" || run.decision === "rejected");
}
```

证据日志至少保留下列字段，并与捕获文件使用同一运行编号。

```text
stage,name,sample,input,observation,result
1,载入配置资源,baseline,planned,observed,pass
2,建立页面角色,baseline,planned,observed,pass
3,连接协议状态,baseline,planned,observed,pass
4,运行 AI 寻路,baseline,planned,observed,pass
5,捕获渲染性能,baseline,planned,observed,pass
6,执行全链回归,baseline,planned,observed,pass
```
