## 从变化与时间到可交付动画

全书的共同模型是 property = f(time)。第一章建立帧、关键帧、动画类型和代码驱动；第二章把连续帧装入 Sprite 资产；第三章用 Animation 窗口和粒子处理场景级表现；第四章让门和按钮进入 Mecanim 图；第五章导入骨骼、Avatar、重定向和根运动；第六章用 Blend Tree 驱动可控角色；第七章补上顶点变形、末端约束和预渲染视频。每章都必须保留输入资产、时间规则、求值器、输出对象与失败信号。

## 关键对象与数据流

阅读顺序先建立动画本体与二维帧，再掌握 Unity 原生创作工具和非角色状态机，随后进入角色导入、重定向、根运动和 Blend Tree，最后比较 Blend Shape、IK 与视频纹理三种完全不同的输出路径。章节之间用同一观察框架连接：谁提供时间，谁拥有状态，谁写属性，谁把结果呈现给玩家，失败时最早能在哪个阶段看到偏差。

排查时从最早可控输入开始，逐段检查导入设置、中间状态和最终像素。最终画面正确但链路不符合预测，也不能立即签发，因为它可能依赖未记录的帧率、缓存、随机种子或编辑器状态。

## 七章怎样构成同一条动画证据链

全书不是七组互不相关的编辑器操作。第一章定义时间、采样和变化函数，第二章把离散图像变成可按时间求值的 Sprite Clip，第三章把关键帧扩展到场景对象和统计性粒子，第四章用参数与转换组织非角色状态，第五章建立骨骼、Avatar、重定向和根运动的身份契约，第六章把连续输入映射到 Blend Tree，终章再分别处理顶点形变、末端约束和视频像素。每一步都能写成输入资产、时间来源、求值器、输出属性和失败信号。

贯穿案例可以是一扇带守卫的媒体展厅：按钮触发门状态图，角色按 Blend Tree 走近，手部 IK 对准把手，面部 Blend Shape 表达反应，墙面 VideoPlayer 播放内容，背景粒子和相机曲线提供氛围。验收不只看最终画面，还要固定 Sprite 导入、Clip 时间、Animator 参数、Avatar 映射、根位移、混合权重、IK 权重和媒体准备状态。任一异常都应能沿链回溯，而不是重新拖动参数碰运气。

## 导读签发检查

- 7 个官方章节各有唯一承载页，Timeline 等现代主题只作为迁移补充。
- 每章都保留正常、边界和故意失败样本，并记录最早异常信号。
- 时间相关实验固定帧率或采样点，资产相关实验固定导入设置和 GUID。
- Unity 5 的旧面板和 API 与现代替代分栏，不倒写原书历史。
- 证据包含版本、场景、资产、参数、时间点、截图、日志和性能数据。

随机抽取“角色脚滑但 Blend Tree 权重正常”这一症状，读者应优先检查根运动、Avatar 比例、Clip 位移和角色控制器，而不是继续调整混合阈值。能从结果选择最早可观察状态，说明学习地图已经成为诊断路线；只能复述工具名称，则仍未建立跨章模型。

## 正常、边界与失败样本

每章至少保存一个正常样本、一个极端边界和一个故意破坏配置。正常样本证明主路径，边界样本说明适用范围，失败样本证明诊断方法真的能抓到错误。

## 从 Unity 5 到现代 Unity

原书写于 Unity 5 时期，使用 Mecanim 总称、Legacy Animation 示例、旧粒子属性名和 MovieTexture。现代复现应保留帧与曲线、Sprite 导入、AnimationClip、Animator 图、Avatar 重定向、根运动、Blend Tree、Blend Shape 与 IK 这些稳定概念；视频改用 VideoPlayer，媒体格式与平台解码需要重新验证。Timeline 可以作为现代补充，但不能替代任何原章。

迁移记录采用五列：原书载体、稳定不变量、现代实现、不可等价处、目标平台证据。允许替换工具和 API，不允许抹去原始问题或倒写历史。

## 验收证据

导读验收要求 7/7 正文章有唯一页面，9 页导航顺序正确，中文版与英文版身份可追溯，54 道题与 slug 对齐，现代主题没有占用原始名额。跨章样例还要记录固定帧率、资产 GUID、导入参数、状态快照、关键时间点画面与故意失败配置。

证据包同时记录场景路径、代码版本、资产 GUID、参数、复现步骤、预期和实际结果。交给另一位读者后不需要猜测隐藏状态即可重放，才算掌握而不只是看过。

## 小结

- 中文版对应 Alan Thorn 的 Unity Animation Essentials 第一版
- 原书有 7 个正文章，导读和总复习不占覆盖分母
- 学习链从变化与时间推进到精灵、场景、角色和高级表现
- 现代迁移替换过时载体，但不能重写原始目录和实验问题
