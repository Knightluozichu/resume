## 直觉引入

Animator 控制器像交通信号灯系统。State 是路口的每个方向（Idle/Run/Jump），Transition 是红绿灯切换规则（Speed>0 从 Idle 转 Run），Parameter 是传感器数据（速度/是否着地/跳跃按键）。代码修改变量（animator.SetFloat），控制器自动评估条件切换状态，播放对应动画。

## 代码对照

```csharp
// 修改参数驱动状态切换
void Update() {
    float speed = _rb.velocity.magnitude;
    _animator.SetFloat("Speed", speed);           // Float：驱动走/跑
    _animator.SetBool("IsGrounded", IsGrounded());  // Bool：着地状态

    if (Input.GetButtonDown("Jump"))
        _animator.SetTrigger("Jump");               // Trigger：一次性触发

    if (Input.GetButtonDown("Fire1"))
        _animator.SetTrigger("Attack");             // 触发上层攻击动画
}

// 获取当前状态信息
var stateInfo = _animator.GetCurrentAnimatorStateInfo(0);
if (stateInfo.IsName("Attack")) {
    // 在攻击状态中
}

// 动画完成后回调（用 Animation Event 或 normalizedTime）
if (stateInfo.normalizedTime >= 1f && stateInfo.IsName("Attack")) {
    _animator.SetTrigger("AttackDone");
}
```

## 常见误区

<Callout type="trap">
**误区：所有 Transition 都勾选 Has Exit Time，导致动作响应迟钝。**
Has Exit Time=true 会等当前动画播放到指定时间才切换。对于需要即时响应的动作（攻击/受击/跳跃），这会导致按了攻击键却要等当前动画播完才切换。应该：即时动作用 Has Exit Time=false（条件满足立即切换），自然过渡（走→跑）保留 Has Exit Time 或用短 Duration 平滑过渡。攻击动画的转出 Transition 设 Has Exit Time=true（等攻击播完才转回 Idle），转入设 false（立即开始攻击）。
</Callout>

<Callout type="trap">
**误区：用大量 Bool 参数管理状态切换，逻辑越来越复杂。**
Bool 参数需要手动管理开/关——SetBool("IsAttacking", true) 开始攻击，SetBool("IsAttacking", false) 结束攻击。如果忘记关闭，状态卡在攻击中。Trigger 是一次性触发——SetTrigger("Attack") 触发后自动重置，不需要手动关闭。原则：一次性动作用 Trigger（跳跃/攻击/受击），持续状态用 Bool（着地/死亡），连续值用 Float（速度/方向）。
</Callout>

<Exercises>
**问题 1**：Float、Bool、Trigger 三种参数分别适合什么场景？

<Answer>
Float：连续值参数，适合范围数据——Speed（0~1 驱动走/跑混合）、Horizontal/Vertical（移动方向）。Bool：布尔参数，适合持续状态标记——IsGrounded（着地/空中）、IsDead（存活/死亡），需要手动开/关。Trigger：一次性触发参数，适合即时动作——Jump/Attack/Hit，用一次自动重置，不需要手动关闭。选择原则：连续数据用 Float，持续状态用 Bool，一次性动作用 Trigger。
</Answer>

**问题 2**：如何实现上半身攻击和下半身移动同时播放？

<Answer>
用 Animator Layer + AvatarMask：1)创建 Base Layer（全身，播放 Idle/Run 移动动画）和 Upper Body Layer（上半身，播放 Attack 动画）；2)创建 AvatarMask 只勾选上半身骨骼（脊椎/手臂/头部）；3)Upper Body Layer 设置 Weight=1、Mask=Upper Body Mask；4)Base Layer 播放移动动画（下半身驱动），Upper Body Layer 播放攻击动画（上半身覆盖）；5)代码 animator.SetTrigger("Attack") 触发上层攻击，下层移动不受影响。效果：角色边跑边攻击。
</Answer>
</Exercises>
