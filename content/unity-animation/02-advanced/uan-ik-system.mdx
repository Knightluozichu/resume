## 直觉引入

拿杯子时，你不用想「肩膀转 30 度、肘弯 90 度、腕转 15 度」——你只想「手到杯子位置」，大脑自动算关节角度。这就是 IK（逆向运动学）——设定末端目标，自动反推关节。FK（正向运动学）是反过来——旋转关节，末端跟随。动画中 FK 做主体动作，IK 补细节（脚贴地/手抓物/头注视）。

## 概念讲解

### FK vs IK

<UanIkSystemDiagram />

<Term def="FK(正向运动学)是旋转父骨骼子骨骼跟随的传统动画方式，简单直观但无法直接控制末端位置">FK</Term>是传统方式。

<Term def="IK(逆向运动学)是设定末端目标位置自动反推关节角度的方法，可直接控制末端到达指定位置">IK</Term>是目标驱动。

<Term def="OnAnimatorIK是Animator的IK回调方法，在每帧动画更新后调用，用于设置IK目标和权重">OnAnimatorIK</Term>是 IK 入口。

<Term def="IK权重(Weight 0~1)控制IK影响程度——0用动画数据、1用IK目标、中间值混合，用于平滑过渡">IK 权重</Term>控制影响程度。

## 交互Demo

<Stepper>
<Step title="第一步：启用 IK Pass">在 Animator 的 Layer 设置中勾选 IK Pass，才会触发 OnAnimatorIK 回调。回调参数 layerIndex 表示当前层。每帧动画更新后调用，此时骨骼还在动画位置，IK 修改叠加在动画之上。</Step>
<Step title="第二步：脚部 IK">
void OnAnimatorIK(int layer) { 射线检测脚下地面 → SetIKPositionWeight(LeftFoot, 1f) → SetIKPosition(LeftFoot, hit.point) → SetIKRotation(LeftFoot, alignToNormal) }。每帧根据地面高度调整脚部位置，实现斜坡/台阶贴合。
<UanIkSystemDiagram />
</Step>
<Step title="第三步：权重平滑过渡">直接设 Weight=0/1 会导致脚部跳变。用 Mathf.SmoothDamp 逐渐改变——离地脚权重从 1 渐变到 0（不贴合），落地脚从 0 渐变到 1（恢复贴合）。头部注视用 SetLookAtPosition + SetLookAtWeight(0.5f)（半权重，微微注视）。</Step>
</Stepper>

## 代码对照

```csharp
[RequireComponent(typeof(Animator))]
public class FootIK : MonoBehaviour {
    [SerializeField] private float _raycastDistance = 1.2f;
    [SerializeField] private LayerMask _groundLayer;
    private Animator _animator;

    void Awake() => _animator = GetComponent<Animator>();

    void OnAnimatorIK(int layerIndex) {
        ProcessFootIK(AvatarIKGoal.LeftFoot);
        ProcessFootIK(AvatarIKGoal.RightFoot);

        // 头部注视
        _animator.SetLookAtPosition(_lookTarget.position);
        _animator.SetLookAtWeight(0.5f); // 半权重
    }

    void ProcessFootIK(AvatarIKGoal foot) {
        Vector3 footPos = _animator.GetIKPosition(foot);
        if (Physics.Raycast(footPos + Vector3.up * 0.5f, Vector3.down, out RaycastHit hit, _raycastDistance, _groundLayer)) {
            _animator.SetIKPosition(foot, hit.point);
            _animator.SetIKRotation(foot, Quaternion.FromToRotation(Vector3.up, hit.normal));
            _animator.SetIKPositionWeight(foot, 1f);
            _animator.SetIKRotationWeight(foot, 1f);
        }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：忘记在 Layer 中勾选 IK Pass，导致 OnAnimatorIK 不触发。**
IK Pass 是 Layer 级别的设置——不勾选，OnAnimatorIK 回调永远不会被调用。在 Animator 窗口→Layers→点击齿轮→勾选 IK Pass。每个 Layer 独立设置，只有需要 IK 的 Layer 勾选（避免不必要的计算）。这是 IK 不工作的最常见原因。
</Callout>

<Callout type="trap">
**误区：IK 权重直接设 0 或 1，导致脚部跳变。**
角色跳跃离地时，如果脚部 IK 权重从 1 突然变为 0，脚会从贴合位置跳回动画位置——视觉跳变。正确做法：用 Mathf.Lerp 或 SmoothDamp 逐渐改变权重——离地时 weight 从 1 渐变到 0（0.1 秒过渡），落地时从 0 渐变到 1。也可以根据动画曲线控制——走路动画中抬脚帧权重降低，落脚帧权重升高。
</Callout>

<Exercises>
**问题 1**：FK 和 IK 的区别是什么？分别适合什么场景？

<Answer>
FK（正向运动学）：旋转父骨骼子骨骼跟随，简单直观。适合主体动画（走路/攻击/跳跃）——美术用关键帧逐级旋转骨骼。IK（逆向运动学）：设定末端目标自动反推关节角度。适合细节补充——脚部贴合斜坡/台阶（设定脚目标到地面位置）、手部抓取物体（设定手目标到物体位置）、头部注视目标。FK 做主体，IK 补细节，两者叠加。
</Answer>

**问题 2**：如何用 IK 实现角色在斜坡上脚部贴合？

<Answer>
1)Animator Layer 勾选 IK Pass；2)OnAnimatorIK 中每帧射线检测：从脚部上方 0.5m 向下射线检测地面高度；3)SetIKPositionWeight(foot, 1f) 设置完全 IK 权重；4)SetIKPosition(foot, hit.point) 脚部移到射线命中点；5)SetIKRotation(foot, Quaternion.FromToRotation(Vector3.up, hit.normal)) 旋转脚贴合斜坡法线；6)权重用 SmoothDamp 平滑过渡——离地脚权重渐降，落地脚渐升。效果：角色在斜坡上行走时脚贴合斜面不穿地。
</Answer>
</Exercises>
