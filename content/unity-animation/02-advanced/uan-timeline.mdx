## 直觉引入

Timeline 像视频编辑软件的时间线——多轨道同步播放。动画轨道放角色动作，音频轨道放 BGM 和音效，激活轨道控制特效开关，信号轨道在关键时间点触发代码。适合做过场动画——角色A走到中央→角色B出现→对话→特效→镜头切换，全部按时间线精确编排。Animator 是状态机（交互），Timeline 是线性编排（导播）。

## 概念讲解

### Timeline 结构

<UanTimelineDiagram />

<Term def="Timeline是Unity的线性时间线编排系统，多轨道同步播放动画/音频/特效/信号，适合过场动画">Timeline</Term>是过场导演。

<Term def="Track(轨道)是Timeline中的水平轨道，每条轨道控制一类资源——Animation/Activation/Audio/Signal/Control">Track</Term>是资源轨道。

<Term def="Signal(信号)是Timeline在特定时间点发送的事件，触发Signal Receiver上的回调方法，用于时间线与代码交互">Signal</Term>是时间触发器。

<Term def="Animation Track是Timeline的动画轨道，可以播放角色动画、混合多个Clip、控制动画速度和循环">Animation Track</Term>是动画轨道。

## 交互Demo

<Stepper>
<Step title="第一步：创建 Timeline">Create → Timeline 创建 .playable 资产，绑定到 GameObject 的 PlayableDirector 组件。Timeline 窗口中添加 Track——Animation Track 绑定角色 Animator 播放动画，Audio Track 播放音频，Activation Track 控制物体激活。</Step>
<Step title="第二步：编辑 Clip">
在 Track 上放置 Clip（片段）——拖拽 AnimationClip 到 Animation Track，拖拽 AudioClip 到 Audio Track。Clip 可以拖动调整时间位置、缩放调整时长、裁剪首尾。多个 Clip 可以重叠或混合（Blend）实现平滑过渡。
<UanTimelineDiagram />
</Step>
<Step title="第三步：Signal 信号">在 Signal Track 的时间点添加 Signal Emitter，绑定 Signal Receiver 组件到目标 GameObject。播放到该时间点时触发 Receiver 的回调方法。如 5 秒 Signal 触发「显示对话框」、8 秒 Signal 触发「结束过场」。Signal 让 Timeline 与代码交互。</Step>
</Stepper>

## 代码对照

```csharp
// 播放 Timeline
var director = GetComponent<PlayableDirector>();
director.Play();

// 监听 Timeline 播放完成
director.stopped += (dir) => {
    Debug.Log("过场动画播放完毕");
    GameManager.Instance.ResumeGameplay();
};

// Signal Receiver 回调
public class CutsceneReceiver : MonoBehaviour {
    public void OnCharacterBAppear() {
        DialogueUI.Instance.Show("角色B出现了！");
    }
    public void OnExplosion() {
        ParticleSystem effect = Instantiate(_explosionPrefab, _pos, Quaternion.identity);
        effect.Play();
    }
    public void OnCutsceneEnd() {
        GameManager.Instance.SwitchToGameplay();
    }
}

// 代码控制 Timeline 播放速度
director.playableGraph.GetRootPlayable(0).SetSpeed(0.5f); // 慢放
```

## 常见误区

<Callout type="trap">
**误区：用 Timeline 做玩家控制的实时角色动画。**
Timeline 是线性时间线——按预编排的顺序播放，不能根据玩家输入实时切换。玩家控制的走/跑/跳/攻击应该用 Animator 状态机——参数驱动状态切换，响应玩家输入。Timeline 只用于非交互的过场动画/剧情序列/教学演示。在过场中需要切换到玩家控制时，用 Signal 触发 Timeline 停止+Animator 启用。
</Callout>

<Callout type="trap">
**误区：在 Timeline 过场中用 Animation Event 触发逻辑，发现触发时机不准确。**
Animation Event 绑定在 AnimationClip 的关键帧上——如果 Timeline 中对 Clip 做了裁剪/缩放/偏移，Event 的触发时间会偏移。过场动画应该用 Timeline 的 Signal 系统——Signal 在 Timeline 时间线上精确定位，不受 Clip 编辑影响。Signal Receiver 注册回调方法，播放到信号时间点时精确触发。
</Callout>

<Exercises>
**问题 1**：Timeline 和 Animator 的区别是什么？

<Answer>
Animator 是状态机——根据参数交互式切换动画（走/跑/跳），适合玩家控制的实时角色动画。Timeline 是线性时间线——按时间编排多轨道（动画/音频/特效/信号）同步播放，适合非交互的过场动画/剧情序列。Animator 是「玩家驱动」（参数变化触发状态切换），Timeline 是「导演驱动」（按预编排时间线播放）。过场中需要切换到玩家控制时，用 Signal 触发停止 Timeline + 启用 Animator。
</Answer>

**问题 2**：用 Timeline 设计一个过场动画的编排方案。

<Answer>
1)Animation Track A：角色A走到中央（0~3s）→待机（3~8s）；2)Activation Track：3s 激活角色B；3)Animation Track B：角色B动画（3~8s）；4)Audio Track：脚步声→对话→特效音效；5)Signal Track：3s Signal「B出现」触发对话UI，5s Signal「特效」触发粒子，8s Signal「结束」切回游戏控制；6)Cinemachine Track：镜头跟随→全景→特写。Signal Receiver 注册回调方法。多轨道同步编排，动画/音频/特效/镜头精确配合。
</Answer>
</Exercises>
