## 为什么从这个动画任务开始

角色基础页把骨骼、Avatar、剪辑和场景位移拆开；重定向复用运动语义，不等于自动解决接触与根轨迹。 “Chapter 5. Character Animation Fundamentals：骨骼、Avatar 与根运动”使用的贯穿任务是：把一段行走剪辑重定向到两个比例不同的人形角色，比较脚底、朝向、根轨迹和控制器位移。 操作前先预测哪个采样点或状态会先变化，播放后再补理由不算预测。

本页围绕“怎样证明同一人形剪辑在两个Avatar上保持语义，并让根运动与角色控制器不重复位移？”建立正常、故障与恢复路径。只有“Chapter 5. Character Animation Fundamentals：骨骼、Avatar 与根运动”保持“骨骼映射有效，Avatar姿势可核对，根位移只有一个权威来源，偏移修正有前后轨迹”并交付骨骼映射、Avatar验证、源目标姿势、剪辑设置、根曲线、Apply Root Motion、控制器轨迹和偏移修正。，编辑器预览或运行画面才构成动画证据。

## 本页回顾

掌握“Chapter 5. Character Animation Fundamentals：骨骼、Avatar 与根运动”不是记住编辑器点击顺序，而是能围绕“怎样证明同一人形剪辑在两个Avatar上保持语义，并让根运动与角色控制器不重复位移？”重建动画状态，并用“骨骼映射有效，Avatar姿势可核对，根位移只有一个权威来源，偏移修正有前后轨迹”拒绝“Animator应用Root Motion，角色控制脚本又积分速度，角色每帧发生双倍位移”。最终交付为骨骼映射、Avatar验证、源目标姿势、剪辑设置、根曲线、Apply Root Motion、控制器轨迹和偏移修正。
