## 直觉引入

游戏没有声音就像哑剧。Unity 音频系统由 AudioSource（播放器）、AudioListener（耳朵）、AudioClip（音频文件）三要素组成。3D 音效让声音有空间感——离得远声音小，左边发出的声音左耳先听到。

当多个音效同时播放（射击游戏枪声不断），如果每次都创建新 AudioSource 播放再销毁，GC 和实例化开销会导致卡顿。解决方案是音频对象池——预创建一批 AudioSource 循环复用。AudioMixer 则像调音台，分轨控制 BGM、音效、语音的音量。

## 概念讲解

<Term def="Unity 的音频播放组件，挂在 GameObject 上播放 AudioClip">AudioSource</Term>是声音的出口。

<Term def="Unity 的音频混音器，分轨控制音量、效果和分组">AudioMixer</Term>是调音台。

<Term def="声音随距离衰减、左右声道有方位感的播放模式">3D 音效</Term>让声音有空间感。

### 音频系统三要素
- **AudioSource**：播放器（喇叭）
- **AudioListener**：接收器（耳朵，通常在相机上）
- **AudioClip**：音频文件（mp3/wav/ogg）

### AudioMixer 分轨
- **Master**：总音量
- **BGM**：背景音乐
- **SFX**：音效
- **Voice**：语音

<Term def="预创建一批 AudioSource 循环复用的模式">音频对象池</Term>避免频繁创建销毁。

<Stepper>
<Step title="第一步：配音频组件">
在场景中创建 AudioManager（DontDestroyOnLoad），挂多个 AudioSource 作为对象池。主相机挂 AudioListener。导入音频文件设为 Streaming 或 Decompress On Load。
</Step>
<Step title="第二步：设 AudioMixer">
创建 AudioMixer，建 Master→BGM/SFX/Voice 三组。每个 AudioSource 的 Output 连到对应组。用暴露参数暴露音量滑块，在 UI 中控制。
</Step>
<Step title="第三步：实现对象池">
AudioManager 维护一个 AudioSource 列表。Play 时找空闲的 AudioSource 播放，没有则扩容。3D 音效设 spatialBlend=1，音源跟随物体移动。
</Step>
</Stepper>

## 代码对照

```csharp
// Unity C#: 音频对象池管理器
using System.Collections.Generic;
using UnityEngine;
using UnityEngine.Audio;

public class AudioManager : MonoBehaviour
{
    public static AudioManager Instance { get; private set; }

    public AudioMixer mixer;
    public int poolSize = 16;

    private List<AudioSource> pool = new List<AudioSource>();
    private int roundRobin = 0;

    void Awake()
    {
        Instance = this;
        DontDestroyOnLoad(gameObject);

        // 初始化对象池
        for (int i = 0; i < poolSize; i++)
        {
            var go = new GameObject("AudioSource_" + i);
            go.transform.SetParent(transform);
            var src = go.AddComponent<AudioSource>();
            src.playOnAwake = false;
            pool.Add(src);
        }
    }

    // 播放 2D 音效
    public void Play(AudioClip clip, float volume = 1f)
    {
        var src = GetAvailableSource();
        src.spatialBlend = 0f; // 2D
        src.clip = clip;
        src.volume = volume;
        src.outputAudioMixerGroup = mixer.FindMatchingGroups("SFX")[0];
        src.Play();
    }

    // 播放 3D 音效（在指定位置）
    public void PlayAtPoint(AudioClip clip, Vector3 pos, float volume = 1f)
    {
        var src = GetAvailableSource();
        src.spatialBlend = 1f; // 3D
        src.transform.position = pos;
        src.clip = clip;
        src.volume = volume;
        src.minDistance = 1f;
        src.maxDistance = 20f;
        src.outputAudioMixerGroup = mixer.FindMatchingGroups("SFX")[0];
        src.Play();
    }

    // 轮询获取可用 AudioSource
    AudioSource GetAvailableSource()
    {
        for (int i = 0; i < poolSize; i++)
        {
            int idx = (roundRobin + i) % pool.Count;
            if (!pool[idx].isPlaying)
            {
                roundRobin = (idx + 1) % pool.Count;
                return pool[idx];
            }
        }
        // 全忙，强制用下一个（打断旧音效）
        var src = pool[roundRobin];
        roundRobin = (roundRobin + 1) % pool.Count;
        return src;
    }

    // AudioMixer 音量控制（分贝）
    public void SetVolume(string group, float volume01)
    {
        // 0~1 映射到 -80~0 dB
        float db = volume01 > 0 ? Mathf.Log10(volume01) * 20 : -80f;
        mixer.SetFloat(group + "Volume", db);
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** 每次播放音效都 AudioSource.PlayOneShot 或 new GameObject，GC 飙升。
**原因 →** PlayOneShot 虽然不创建新对象但无法控制 3D 位置。new GameObject+Destroy 每次都分配内存触发 GC。
**修法 →** 用音频对象池：预创建 N 个 AudioSource，Play 时找空闲的播放。所有音效复用这 N 个 AudioSource，零 GC 分配。
</Callout>
<Callout type="trap">
**现象 →** 音效播放有延迟，不跟手。
**原因 →** 音频文件用了 Vorbis 编码但加载方式设为 Streaming，流式加载有延迟。或者 AudioListener 时间缩放导致。
**修法 →** 短音效（枪声/UI）设为 Decompress On Load，预解压无延迟。BGM 等长音频设为 Streaming 省内存。检查 AudioListener 的 velocityUpdateMode。
</Callout>

## 练习

<Exercises>
**问题**：为什么每次 Play 播放音效都 new AudioSource 会卡？

<Answer>
new GameObject + AddComponent 在托管堆和原生堆都分配内存，Destroy 时又回收，高频操作（如连发射击）导致 GC 频繁触发。对象池预创建一批 AudioSource 循环复用——Play 时找空闲的播放，不创建不销毁，GC 分配为零，性能稳定。
</Answer>

**问题**：AudioMixer 的分轨有什么用？怎么实现 BGM 淡入淡出？

<Answer>
分轨让你独立控制 BGM/音效/语音的音量，互不影响。比如玩家调低 BGM 不影响音效。实现淡入淡出：用 mixer.SetFloat 渐变暴露的音量参数。从 -80dB（静音）渐变到 0dB（满音量）用 Lerp 或 DOTween 做插值动画，实现平滑淡入淡出。
</Answer>
</Exercises>
