## 最小实现骨架

下面的代码不是原书代码复制，而是用于复现实验的最小骨架。它只表达本章关键所有权，生产实现还要加入错误分类、超时、指标和清理。

```csharp
public sealed record TrainingMission(Guid Id, long Generation, IReadOnlyList<int> Trainees);
bool TryStart(TrainingMission mission)
{
    if (!authorization.Exists(mission.Id, mission.Generation)) return false;
    if (activeGeneration >= mission.Generation) return false;
    activeGeneration = mission.Generation;
    return simulator.Start(mission);
}
```

状态轨迹必须与代码同时存在：

```text
trace_id,stage,input_version,state_version,owner,budget,decision
baseline-01,定义训练目标,1,1,primary,normal,accept
boundary-01,绑定分队与学员,1,2,primary,limit,accept
failure-01,收集结果并签发,0,2,primary,exceeded,reject
```

验收驱动器每次只改变一个变量，避免同时改变版本、负载和时序后无法定位因果：

```text
for sample in [baseline, boundary, failure]:
  reset_fixture(seed = 20260716)
  run_same_input(sample)
  assert_single_owner()
  assert_bounded_budget()
  export_first_divergence_and_recovery()
```

## 可复现实验

以同一批学员连续启动两代任务，先预测旧代迟到状态会污染哪个模块，再注入断线、重复授权和越序启动并核对任务时间线。 每次运行保存客户端版本、服务端版本、协议或资源摘要、随机种子、样本类型、首偏离节点、恢复动作和最终决策。平均值只能说明趋势，不能证明单次关键状态没有重复或丢失。

## 两个必须主动制造的失败

<Callout type="trap" title="所有权或顺序被绕过">
  任务配置只用可变名称关联学员，重命名或重复名称后把授权发给错误实体。
  用同一输入重放修复，保存首偏离状态和拒绝原因；只修到最终画面相同仍不算通过。
</Callout>

<Callout type="trap" title="正常样本掩盖边界错误">
  旧任务的迟到消息没有任务代际，重启训练后继续修改新任务状态。
  必须补充边界和失败样本，证明错误在跨越下一层之前已经停止并留下可恢复证据。
</Callout>

## 验收矩阵

| 样本 | 输入变化                     | 预期状态         | 通过条件                 |
| ---- | ---------------------------- | ---------------- | ------------------------ |
| 正常 | 合法版本、身份和容量         | 六阶段顺序完成   | 双端或资源摘要一致       |
| 边界 | 临界时序、容量、重复或切换   | 达到预算但不越界 | 无第二份事实，无无限队列 |
| 失败 | 畸形、旧代际、断线或依赖失效 | 在首偏离点停止   | 明确拒绝、补偿或回滚     |
| 恢复 | 修复后重放同一输入           | 收敛到正常轨迹   | 无幽灵状态和资源泄漏     |

<Ucn06SimulationArchitectureEvidenceLab />

本页签发不变量是：**任务、角色和终端身份唯一；授权先于启动；消息携带任务代际；结束后输入被拒绝且结果可追溯。**。它必须由轨迹、版本、序号和恢复复测共同证明，不能被一次演示、截图或平均指标替代。
