## 最小实现骨架

下面的代码不是原书代码复制，而是用于复现实验的最小骨架。它只表达本章关键所有权，生产实现还要加入错误分类、超时、指标和清理。

```csharp
async Task SwitchSceneAsync(SceneManifest next, CancellationToken ct)
{
    await barrier.StopOldWorldAsync(ct);
    await loader.LoadDependenciesAsync(next, ct);
    await SceneManager.LoadSceneAsync(next.SceneName);
    await weather.ApplyAsync(next.Weather, ct);
    barrier.PublishReady(next.Generation);
}
```

状态轨迹必须与代码同时存在：

```text
trace_id,stage,input_version,state_version,owner,budget,decision
baseline-01,建立场景清单,1,1,primary,normal,accept
boundary-01,集成水天气道路,1,2,primary,limit,accept
failure-01,切换卸载后签发,0,2,primary,exceeded,reject
```

验收驱动器每次只改变一个变量，避免同时改变版本、负载和时序后无法定位因果：

```text
for sample in [baseline, boundary, failure]:
  reset_fixture(seed = 20260716)
  run_same_input(sample)
  assert_single_owner()
  assert_bounded_budget()
  export_first_divergence_and_recovery()
```

## 验收矩阵

| 样本 | 输入变化                     | 预期状态         | 通过条件                 |
| ---- | ---------------------------- | ---------------- | ------------------------ |
| 正常 | 合法版本、身份和容量         | 六阶段顺序完成   | 双端或资源摘要一致       |
| 边界 | 临界时序、容量、重复或切换   | 达到预算但不越界 | 无第二份事实，无无限队列 |
| 失败 | 畸形、旧代际、断线或依赖失效 | 在首偏离点停止   | 明确拒绝、补偿或回滚     |
| 恢复 | 修复后重放同一输入           | 收敛到正常轨迹   | 无幽灵状态和资源泄漏     |

本页签发不变量是：**场景依赖显式；动态对象不进入静态事实；加载完成包含子系统就绪；卸载后没有旧场景回调和资源引用。**。它必须由轨迹、版本、序号和恢复复测共同证明，不能被一次演示、截图或平均指标替代。
