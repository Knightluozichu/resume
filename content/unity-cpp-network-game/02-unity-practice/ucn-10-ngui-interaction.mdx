## 最小实现骨架

下面的代码不是原书代码复制，而是用于复现实验的最小骨架。它只表达本章关键所有权，生产实现还要加入错误分类、超时、指标和清理。

```csharp
public sealed class LoginView : MonoBehaviour
{
    public void Bind(LoginViewModel vm)
    {
        userLabel.text = vm.UserName;
        loginButton.onClick.Clear();
        loginButton.onClick.Add(() => vm.SubmitLogin());
    }
    void OnDisable() => loginButton.onClick.Clear();
}
```

状态轨迹必须与代码同时存在：

```text
trace_id,stage,input_version,state_version,owner,budget,decision
baseline-01,导入NGUI并建图集,1,1,primary,normal,accept
boundary-01,完成分辨率自适应,1,2,primary,limit,accept
failure-01,VR可读性签发,0,2,primary,exceeded,reject
```

验收驱动器每次只改变一个变量，避免同时改变版本、负载和时序后无法定位因果：

```text
for sample in [baseline, boundary, failure]:
  reset_fixture(seed = 20260716)
  run_same_input(sample)
  assert_single_owner()
  assert_bounded_budget()
  export_first_divergence_and_recovery()
```

| 样本 | 输入变化                     | 预期状态         | 通过条件                 |
| ---- | ---------------------------- | ---------------- | ------------------------ |
| 正常 | 合法版本、身份和容量         | 六阶段顺序完成   | 双端或资源摘要一致       |
