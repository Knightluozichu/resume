## 最小实现骨架

下面的代码不是原书代码复制，而是用于复现实验的最小骨架。它只表达本章关键所有权，生产实现还要加入错误分类、超时、指标和清理。

```cpp
WSADATA data{};
if (WSAStartup(MAKEWORD(2, 2), &data) != 0) throw NetworkError{};
Socket socket{::socket(AF_INET, SOCK_STREAM, IPPROTO_TCP)};
sockaddr_in endpoint = make_endpoint("127.0.0.1", 9000);
socket.connect(endpoint);
send_all(socket, frame);
Frame reply = receive_frame(socket);
```

状态轨迹必须与代码同时存在：

```text
trace_id,stage,input_version,state_version,owner,budget,decision
baseline-01,初始化Winsock,1,1,primary,normal,accept
boundary-01,完成TCP连接收发,1,2,primary,limit,accept
failure-01,错误关闭后签发,0,2,primary,exceeded,reject
```

验收驱动器每次只改变一个变量，避免同时改变版本、负载和时序后无法定位因果：

```text
for sample in [baseline, boundary, failure]:
  reset_fixture(seed = 20260716)
  run_same_input(sample)
  assert_single_owner()
  assert_bounded_budget()
  export_first_divergence_and_recovery()
```

## 可复现实验

让TCP代理按随机边界拆分数据，并向UDP端口注入截断包和伪造来源。先预测哪种错误会被错误地当成正常关闭，再保存系统错误码。 每次运行保存客户端版本、服务端版本、协议或资源摘要、随机种子、样本类型、首偏离节点、恢复动作和最终决策。平均值只能说明趋势，不能证明单次关键状态没有重复或丢失。

## 两个必须主动制造的失败

<Callout type="trap" title="所有权或顺序被绕过">
  假设一次send或recv等于一条完整消息，TCP分片后协议立即错位。
  用同一输入重放修复，保存首偏离状态和拒绝原因；只修到最终画面相同仍不算通过。
</Callout>

<Callout type="trap" title="正常样本掩盖边界错误">
  UDP接收后不校验来源端点和报文长度，任意伪造数据报都能进入业务解析器。
  必须补充边界和失败样本，证明错误在跨越下一层之前已经停止并留下可恢复证据。
</Callout>

## 验收矩阵

| 样本 | 输入变化                     | 预期状态         | 通过条件                 |
| ---- | ---------------------------- | ---------------- | ------------------------ |
| 正常 | 合法版本、身份和容量         | 六阶段顺序完成   | 双端或资源摘要一致       |
| 边界 | 临界时序、容量、重复或切换   | 达到预算但不越界 | 无第二份事实，无无限队列 |
| 失败 | 畸形、旧代际、断线或依赖失效 | 在首偏离点停止   | 明确拒绝、补偿或回滚     |
| 恢复 | 修复后重放同一输入           | 收敛到正常轨迹   | 无幽灵状态和资源泄漏     |
