## 直觉引入

Unity 像一座城堡，C# 是城堡里的管家，所有事情（渲染、UI、物理）都在城堡里按顺序做。但网络通信是城堡外面的快递员——如果让管家自己跑出去收快递，城堡里的事情就停了。正确做法是雇佣一个外面的快递员（C++ 网络线程），他在外面收好快递，管家只需要定时在窗口问一句「有快递吗？」（net_poll），拿进来拆开处理。

## 为什么用 C++ Native Plugin

<Term def="Native Plugin 是 Unity 通过 P/Invoke 调用的 C/C++ 动态链接库（.dll/.so/.a），在非托管线程中运行，可直接调用系统 API，无 GC 开销。">Native Plugin</Term> 相比纯 C# 网络层的优势：

| 维度 | C# Socket | C++ Native Plugin |
|------|-----------|-------------------|
| GC 压力 | 每次 BeginReceive 产生 GC 分配 | 零 GC（C++ 自管内存） |
| 线程控制 | C# 线程受 Unity 管理 | C++ std::thread 独立运行 |
| I/O 性能 | 经过 .NET 运行时 | 直接 epoll/IOCP |
| 代码复用 | 客户端单独写 | 与服务器共享 Protobuf 代码 |
| 跨平台 | IL2CPP 行为有差异 | 各平台 Native 一致 |

## P/Invoke 桥接

```csharp
using System.Runtime.InteropServices;
using UnityEngine;

public class NetworkManager : MonoBehaviour
{
    // 声明 C++ 导出函数
    [DllImport("netlib")]
    private static extern int net_init(string host, int port);

    [DllImport("netlib")]
    private static extern int net_poll(byte[] buf, int maxSize);

    [DllImport("netlib")]
    private static extern int net_send(byte[] buf, int size);

    [DllImport("netlib")]
    private static extern void net_shutdown();

    private byte[] m_recvBuf = new byte[8192];

    void Start()
    {
        net_init("127.0.0.1", 8888);
    }

    void Update()
    {
        // 每帧轮询取消息
        int maxPerFrame = 50;  // 单帧最多处理 50 条，防卡帧
        int count = 0;
        while (count < maxPerFrame)
        {
            int n = net_poll(m_recvBuf, m_recvBuf.Length);
            if (n <= 0) break;  // 无消息

            // 解析消息号
            ushort msgId = BitConverter.ToUInt16(m_recvBuf, 0);
            // 分发到对应处理器
            MessageDispatcher.Dispatch(msgId, m_recvBuf, 2, n - 2);
            count++;
        }
    }

    void OnDestroy()
    {
        net_shutdown();
    }
}
```

## C++ 导出函数

```cpp
// netlib.cpp — 编译为各平台动态库
#include <thread>
#include <atomic>
#include <cstring>

extern "C" {
    // 网络线程
    static std::thread g_net_thread;
    static std::atomic<bool> g_running{false};
    static SpscQueue<Packet> g_msg_queue;  // 线程安全队列

    // 初始化连接
    int net_init(const char* host, int port) {
        if (connect_to_server(host, port) < 0) return -1;
        g_running = true;
        g_net_thread = std::thread(net_thread_loop);  // 启动网络线程
        return 0;
    }

    // Unity 主线程调用：取消息（拷贝到 C# 缓冲区）
    int net_poll(char* buf, int max_size) {
        Packet pkt;
        if (!g_msg_queue.pop(pkt)) return 0;  // 无消息

        int total = 2 + pkt.body_size;
        if (total > max_size) return -1;  // 缓冲区不够

        // 写入消息号 + 消息体
        uint16_t msg_id = htons(pkt.msg_id);
        memcpy(buf, &msg_id, 2);
        memcpy(buf + 2, pkt.body, pkt.body_size);
        return total;
    }

    // Unity 主线程调用：发送消息
    int net_send(const char* buf, int size) {
        return send_to_server(buf, size);
    }

    void net_shutdown() {
        g_running = false;
        if (g_net_thread.joinable()) g_net_thread.join();
        close_connection();
    }
}

// 网络线程：epoll 收包 → 写入队列
void net_thread_loop() {
    while (g_running) {
        int n = epoll_wait(g_epfd, g_events, MAX, 100);
        for (int i = 0; i < n; i++) {
            if (g_events[i].events & EPOLLIN) {
                recv_to_ringbuf(g_events[i].data.fd);
                while (auto pkt = g_ringbuf.try_pop()) {
                    g_msg_queue.push(*pkt);  // 推入队列，等主线程取
                }
            }
        }
    }
}
```

<Callout type="warning">
C++ 网络线程绝不能调用 Unity API（Transform/UI/Physics），这些只能在主线程调用。线程间唯一的交互点是无锁消息队列。
</Callout>

## 数据传递：Marshal vs unsafe

```csharp
// 方式 1：Marshal.Copy（安全，有一次拷贝）
[DllImport("netlib")]
private static extern int net_poll(IntPtr buf, int maxSize);

void Update() {
    IntPtr ptr = Marshal.AllocHGlobal(8192);
    int n = net_poll(ptr, 8192);
    if (n > 0) {
        Marshal.Copy(ptr, m_recvBuf, 0, n);  // native → managed 拷贝
    }
    Marshal.FreeHGlobal(ptr);
}

// 方式 2：unsafe 指针（零拷贝，需要 unsafe 编译选项）
void Update() {
    unsafe {
        fixed (byte* p = m_recvBuf) {
            int n = net_poll(p, m_recvBuf.Length);  // 直接写 managed 数组
        }
    }
}
```

<Callout type="info">
先用 Marshal.Copy 保证正确性，Profiler 发现瓶颈后再针对性切换 unsafe。每帧几十条消息时 Marshal.Copy 的拷贝开销可忽略。
</Callout>

<Glossary>
<GlossaryItem term="P/Invoke">Platform Invocation Services，C# 调用 C/C++ 非托管 DLL 的机制，通过 DllImport 特性声明 extern 函数。</GlossaryItem>
<GlossaryItem term="Marshal.Copy">在托管内存和非托管内存之间拷贝数据的 C# API，安全但有拷贝开销。</GlossaryItem>
<GlossaryItem term="IL2CPP">Unity 将 C# 编译为 C++ 再编译为原生代码的后端，减少 JIT 开销但增加编译时间。</GlossaryItem>
<GlossaryItem term="extern &quot;C&quot;">C++ 关键字，禁止名称修饰（name mangling），确保 C# 能通过函数名找到导出函数。</GlossaryItem>
</Glossary>

</Exercises>

<Answer>
1. C++ 无 GC 停顿、直接 epoll/IOCP、独立网络线程不占主线程、与服务器共享 Protobuf 代码。C# 的 Socket 在高频收发时 GC 压力大。
2. Marshal.Copy 安全但有一次 native→managed 拷贝，适合消息量中等的场景。unsafe 指针零拷贝性能最高但需要 unsafe 编译选项，适合高频大消息。先用 Marshal.Copy，发现瓶颈再切 unsafe。
3. Update() 调 net_poll → C++ 从队列取消息拷贝到 buf → 返回字节数 → C# 读 MsgId → 查路由表 → 反序列化 Protobuf → 触发回调 → 更新表现层。单帧限 50 条防卡帧。
4. C++ 侧用线程安全队列（无锁环形队列或互斥锁）——网络线程写，主线程读。C++ 不调用 Unity API。C# 侧 Update 在主线程轮询 net_poll，收到的数据全在主线程处理，不需要锁。
</Answer>
