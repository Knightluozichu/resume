## 直觉引入

3D 动作游戏（如鬼泣、黑神话）的核心是「打」——但打不是简单的播动画，而是连招：轻击一段→轻击二段→轻击三段，每段动画有取消窗口可以接下一段。这套系统由动画状态机驱动，动画之间的切换规则就是连招规则。

Unity 的 Animator Controller 是可视化的动画状态机。每个状态是一个动画，切换条件是参数（如 comboCount）。Cinemachine 则提供专业的摄像机跟随，能实现自动转向、镜头拉近、震屏等效果。

## 概念讲解

<Term def="Unity 的可视化动画状态机，用状态和切换条件控制动画播放">Animator Controller</Term>是动作游戏的核心。

<Term def="连续攻击的招式系统，每段攻击有取消窗口可接下一段">连招系统</Term>是动作游戏的灵魂。

<Term def="Unity 的专业摄像机系统，支持跟随、瞄准、震屏等">Cinemachine</Term>提供电影级镜头。

### 连招系统设计
- 每段攻击有「取消窗口」
- 窗口内输入→接下一段
- 窗口外输入→无效
- 三段后回到待机

<Term def="动画中可以输入指令取消当前动画的特定时间段">取消窗口</Term>决定连招流畅度。

## 代码对照

```csharp
// Unity C#: 3D 动作游戏连招系统
using UnityEngine;

[RequireComponent(typeof(Animator))]
public class ComboSystem : MonoBehaviour
{
    private Animator anim;
    public int maxCombo = 3;
    public float comboResetTime = 0.8f; // 连招超时

    private int comboCount = 0;
    private float lastAttackTime = 0f;
    private bool canCombo = false; // 取消窗口

    void Awake() => anim = GetComponent<Animator>();

    void Update()
    {
        // 超时重置连招
        if (Time.time - lastAttackTime > comboResetTime)
        {
            comboCount = 0;
            anim.SetInteger("ComboCount", 0);
        }

        // 攻击输入
        if (Input.GetMouseButtonDown(0))
        {
            if (canCombo || comboCount == 0)
            {
                comboCount = Mathf.Min(comboCount + 1, maxCombo);
                anim.SetInteger("ComboCount", comboCount);
                anim.SetTrigger("Attack");
                lastAttackTime = Time.time;
            }
        }
    }

    // 动画事件: 取消窗口开始
    public void OnComboWindowOpen()
    {
        canCombo = true;
    }

    // 动画事件: 取消窗口结束
    public void OnComboWindowClose()
    {
        canCombo = false;
    }

    // 动画事件: 攻击结束
    public void OnAttackEnd()
    {
        if (!canCombo)
        {
            comboCount = 0;
            anim.SetInteger("ComboCount", 0);
        }
    }

    // 动画事件: 命中判定（攻击动画中段）
    public void OnHitFrame()
    {
        // 检测前方敌人
        Collider[] hits = Physics.OverlapSphere(
            transform.position + transform.forward * 1f,
            1.5f, LayerMask.GetMask("Enemy"));
        foreach (var hit in hits)
        {
            hit.SendMessage("TakeDamage", 10, SendMessageOptions.DontRequireReceiver);
        }
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** 连招不流畅，按了攻击键没反应或总是从头开始。
**原因 →** 没有取消窗口机制，动画必须播完才能播下一个。comboCount 逻辑不对。
**修法 →** 在攻击动画中段加动画事件标记取消窗口。窗口内按攻击键 comboCount+1 播下一段。窗口外归零回 Idle。用 Animator 的 transition 和 comboCount 参数控制切换。
</Callout>
<Callout type="trap">
**现象 →** 摄像机跟不上角色，转弯时角色跑出画面。
**原因 →** 用了固定摄像机或跟随太死板，没有 Damping 平滑。
**修法 →** 用 Cinemachine Virtual Camera。设 Body 为 Framing Transposer，Damping 设 0.5-1.0 平滑跟随。Boss 战用 LookAt 锁定。受击用 Cinemachine Impulse 震屏。
</Callout>

## 练习

<Exercises>
**问题**：为什么动作游戏的动画状态机比代码逻辑更重要？

<Answer>
动作游戏的核心体验来自动画切换的流畅度——连招取消、受击硬直、闪避无缝衔接。这些时序由动画状态机控制：每个状态的进入/退出条件、动画事件的触发时机决定了手感。代码逻辑只是辅助（计 comboCount、检测命中），真正的游戏体验在 Animator 窗口里设计。优秀的动作游戏 80% 的时间在调动画状态机。
</Answer>

**问题**：连招系统的取消窗口是什么？怎么实现？

<Answer>
取消窗口是攻击动画中可以输入指令取消当前动画接下一段的时间段。实现：1）在动画中段添加动画事件 OnComboWindowOpen 和 OnComboWindowClose；2）窗口内按攻击键 comboCount+1 播下一段；3）窗口外按无效，动画播完 comboCount 归零。取消窗口让连招连贯无间断，是动作游戏爽快感的核心。
</Answer>
</Exercises>
