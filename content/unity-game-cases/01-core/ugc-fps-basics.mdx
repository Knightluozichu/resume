## 直觉引入

FPS 的核心是「看-瞄准-射击」。玩家通过第一人称视角操控角色，鼠标控制视角，左键射击。射击判定有两种方案：物理子弹（创建有速度的物体飞向目标）和 Raycast 射线（瞬间检测命中）。大多数 FPS 用 Raycast——因为子弹速度快到肉眼看不到，物理子弹的性能开销不值得。

敌人 AI 是 FPS 的另一个核心：敌人需要巡逻、发现玩家、追击、射击。这用 NavMeshAgent 寻路+状态机 AI 实现。

## 概念讲解

<Term def="Unity 的角色控制器组件，不依赖物理引擎，适合 FPS 移动">CharacterController</Term>是 FPS 移动的首选。

<Term def="用射线检测射击命中的方案，即时无弹道延迟">Raycast 射击</Term>是 FPS 射击的核心。

<Term def="用状态机控制敌人行为的 AI 系统（巡逻/追击/攻击）">敌人 AI</Term>让游戏有挑战。

### 射击方案对比
| | Raycast 射击 | 物理子弹 |
|---|---|---|
| 速度 | 即时 | 有弹道 |
| 性能 | 好 | 差 |
| 真实感 | 低 | 高 |
| 适用 | 即时射击 | 慢速弹 |

<Term def="用鼠标控制水平转身和垂直仰俯的视角系统">Mouse Look</Term>是 FPS 的操作基础。

## 代码对照

```csharp
// Unity C#: FPS 控制器与射击系统
using UnityEngine;

[RequireComponent(typeof(CharacterController))]
public class FPSController : MonoBehaviour
{
    public Camera playerCamera;
    public float moveSpeed = 5f;
    public float mouseSensitivity = 2f;
    public float gravity = -9.81f;
    public float jumpHeight = 1.5f;

    private CharacterController controller;
    private float verticalRotation = 0f;
    private Vector3 velocity;
    private bool isGrounded;

    // 射击参数
    public float fireRate = 0.1f;
    public float damage = 25f;
    public float range = 100f;
    private float nextFireTime = 0f;

    void Start()
    {
        controller = GetComponent<CharacterController>();
        Cursor.lockState = CursorLockMode.Locked;
    }

    void Update()
    {
        LookAround();
        Move();
        Shoot();
    }

    void LookAround()
    {
        float mouseX = Input.GetAxis("Mouse X") * mouseSensitivity;
        float mouseY = Input.GetAxis("Mouse Y") * mouseSensitivity;

        // 水平: 转身体
        transform.Rotate(Vector3.up * mouseX);

        // 垂直: 仰俯相机 (限制角度)
        verticalRotation -= mouseY;
        verticalRotation = Mathf.Clamp(verticalRotation, -90f, 90f);
        playerCamera.transform.localRotation =
            Quaternion.Euler(verticalRotation, 0, 0);
    }

    void Move()
    {
        isGrounded = controller.isGrounded;

        float h = Input.GetAxis("Horizontal");
        float v = Input.GetAxis("Vertical");

        Vector3 move = transform.right * h + transform.forward * v;
        controller.Move(move * moveSpeed * Time.deltaTime);

        // 重力
        if (isGrounded && velocity.y < 0)
            velocity.y = -2f;

        // 跳跃
        if (Input.GetButtonDown("Jump") && isGrounded)
            velocity.y = Mathf.Sqrt(jumpHeight * 2f * gravity * -1);

        velocity.y += gravity * Time.deltaTime;
        controller.Move(velocity * Time.deltaTime);
    }

    void Shoot()
    {
        if (Input.GetMouseButton(0) && Time.time >= nextFireTime)
        {
            nextFireTime = Time.time + fireRate;

            // Raycast 射击
            Ray ray = new Ray(
                playerCamera.transform.position,
                playerCamera.transform.forward);

            if (Physics.Raycast(ray, out RaycastHit hit, range))
            {
                // 命中判定
                hit.collider.SendMessage("TakeDamage", damage,
                    SendMessageOptions.DontRequireReceiver);

                // 弹孔特效
                Debug.Log("命中: " + hit.collider.name);
            }
        }
    }
}

// 敌人 AI
[RequireComponent(typeof(NavMeshAgent))]
public class EnemyAI : MonoBehaviour
{
    public Transform player;
    public float detectRange = 15f;
    public float attackRange = 8f;
    public float health = 100f;
    public float damage = 10f;
    public float fireRate = 1f;

    private NavMeshAgent agent;
    private float nextFireTime;
    private enum State { Patrol, Chase, Attack }
    private State state = State.Patrol;

    void Start() => agent = GetComponent<NavMeshAgent>();

    void Update()
    {
        float dist = Vector3.Distance(transform.position, player.position);
        bool canSee = CanSeePlayer();

        switch (state)
        {
            case State.Patrol:
                if (canSee) state = State.Chase;
                break;
            case State.Chase:
                agent.SetDestination(player.position);
                if (dist < attackRange && canSee) state = State.Attack;
                else if (dist > detectRange * 2) state = State.Patrol;
                break;
            case State.Attack:
                agent.SetDestination(transform.position);
                transform.LookAt(player);
                if (Time.time >= nextFireTime)
                {
                    ShootPlayer();
                    nextFireTime = Time.time + fireRate;
                }
                if (dist > attackRange) state = State.Chase;
                break;
        }
    }

    bool CanSeePlayer()
    {
        float dist = Vector3.Distance(transform.position, player.position);
        if (dist > detectRange) return false;

        Vector3 dir = (player.position - transform.position).normalized;
        if (Physics.Raycast(transform.position, dir, out var hit, detectRange))
            return hit.transform == player;
        return false;
    }

    void ShootPlayer()
    {
        // 敌人射击玩家
        player.SendMessage("TakeDamage", damage,
            SendMessageOptions.DontRequireReceiver);
    }

    void TakeDamage(float dmg)
    {
        health -= dmg;
        if (health <= 0) Destroy(gameObject);
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** FPS 射击有延迟，子弹飞过去才造成伤害。
**原因 →** 用了物理子弹（Instantiate 子弹物体+Rigidbody 速度），子弹飞行需要时间。
**修法 →** 改用 Raycast 射击：从相机中心发射射线，Physics.Raycast 检测命中，SendMessage TakeDamage 即时造成伤害。大多数 FPS（CS/使命召唤）都用 Raycast，子弹速度太快物理子弹无意义。
</Callout>
<Callout type="trap">
**现象 →** 敌人 AI 穿墙看到玩家，隔着墙追击。
**原因 →** CanSeePlayer 只检查距离没检查视线，没有 Raycast 视线检测。
**修法 →** CanSeePlayer 中加 Raycast：从敌人眼睛到玩家发射射线，如果射线被墙挡住则看不见。只有视线无阻才能进入 Chase 状态。
</Callout>

## 练习

<Exercises>
**问题**：为什么 FPS 用 Raycast 而非物理子弹？

<Answer>
步枪子弹速度约 900m/s，100 米距离飞行只需 0.1 秒，玩家根本看不到弹道。物理子弹的 Rigidbody 速度模拟在这个速度下没有意义，还浪费性能。Raycast 瞬间检测命中，性能好、判定准。只有慢速弹（火箭筒/弓箭）才用物理子弹，因为玩家需要看到弹道。
</Answer>

**问题**：FPS 的敌人 AI 怎么实现视线检测？

<Answer>
视线检测用 Raycast：1）先检查距离——超出 detectRange 直接看不见；2）从敌人眼睛位置到玩家发射 Raycast；3）如果射线命中玩家则看得见（hit.transform == player.transform）；4）如果射线命中墙则看不见。只有视线无阻才能进入 Chase/Attack 状态，防止穿墙追击。
</Answer>
</Exercises>
