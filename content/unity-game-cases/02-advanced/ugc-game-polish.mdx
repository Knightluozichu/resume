## 直觉引入

游戏做完核心玩法只是完成了 50%。剩下 50% 是打磨：性能优化让游戏不卡、UX 反馈让操作爽、多平台适配让游戏能发布。很多独立游戏死在打磨阶段——核心玩法好玩但 20fps 卡顿、操作反馈弱、包体太大商店拒绝。

性能优化的三大杀手：GC 卡顿（对象池解决）、DrawCall 过多（批处理解决）、内存泄漏（Profiler 定位）。UX 打磨的三个层次：视觉反馈（特效/震屏）、听觉反馈（音效/震动）、操作反馈（缓动/吸附）。

## 概念讲解

<Term def="Unity 的性能分析工具，CPU/GPU/Memory 模块定位瓶颈">Profiler</Term>是优化的眼睛。

<Term def="逐帧查看 DrawCall 的调试工具，分析为何没批处理">Frame Debugger</Term>是渲染优化的利器。

<Term def="操作后给玩家的视觉/听觉/触觉反馈">UX 反馈</Term>让游戏有手感。

### 性能优化三大杀手
- **GC 卡顿**：对象池解决
- **DrawCall 过多**：SRP Batcher+GPU Instancing
- **内存泄漏**：Memory Profiler 定位

### UX 打磨三层次
- **视觉**：特效、震屏、缓动
- **听觉**：音效、音乐、震动
- **操作**：吸附、容错、预输入

<Term def="用缓动函数让动画从线性变为有节奏的曲线">缓动</Term>是手感的秘密。

## 代码对照

```csharp
// Unity C#: 游戏打磨工具集
using UnityEngine;
using DG.Tweening; // DOTween 缓动库

// 1. 震屏效果
public class ScreenShake : MonoBehaviour
{
    public float shakeDuration = 0.3f;
    public float shakeMagnitude = 0.5f;

    private Vector3 originalPos;
    private bool isShaking = false;

    void Awake() => originalPos = transform.localPosition;

    public void Shake(float duration = 0, float magnitude = 0)
    {
        if (duration == 0) duration = shakeDuration;
        if (magnitude == 0) magnitude = shakeMagnitude;
        StartCoroutine(ShakeRoutine(duration, magnitude));
    }

    System.Collections.IEnumerator ShakeRoutine(float dur, float mag)
    {
        isShaking = true;
        float elapsed = 0f;
        while (elapsed < dur)
        {
            transform.localPosition = originalPos +
                Random.insideUnitSphere * mag;
            elapsed += Time.deltaTime;
            yield return null;
        }
        transform.localPosition = originalPos;
        isShaking = false;
    }
}

// 2. 缓动动画 (DOTween)
public class UIAnimations : MonoBehaviour
{
    public CanvasGroup panel;

    public void FadeIn()
    {
        // 缓入: 从透明渐变到不透明
        panel.alpha = 0;
        panel.DOFade(1, 0.3f).SetEase(Ease.OutCubic);
        panel.transform.DOScale(0.9f, 0.3f).From().SetEase(Ease.OutBack);
    }

    public void FadeOut()
    {
        panel.DOFade(0, 0.2f).SetEase(Ease.InCubic);
    }

    public void ButtonClickFeedback(Transform button)
    {
        // 按钮点击: 缩放弹跳
        button.DOScale(0.9f, 0.05f).OnComplete(() =>
        {
            button.DOScale(1f, 0.1f).SetEase(Ease.OutBack);
        });
    }
}

// 3. 受击反馈
public class HitFeedback : MonoBehaviour
{
    public SpriteRenderer spriteRenderer;
    public Color hitColor = Color.red;
    public float flashDuration = 0.1f;

    private Color originalColor;

    void Start() => originalColor = spriteRenderer.color;

    public void OnHit()
    {
        // 视觉: 闪红
        StartCoroutine(FlashRoutine());

        // 震屏
        Camera.main.GetComponent<ScreenShake>()?.Shake();

        // 音效
        AudioManager.Instance?.Play(SFXType.Hit);
    }

    System.Collections.IEnumerator FlashRoutine()
    {
        spriteRenderer.color = hitColor;
        yield return new WaitForSeconds(flashDuration);
        spriteRenderer.color = originalColor;
    }
}

// 4. 性能监控
public class PerformanceMonitor : MonoBehaviour
{
    public float updateInterval = 0.5f;
    private float fps;
    private float timer;

    void Update()
    {
        timer += Time.deltaTime;
        if (timer >= updateInterval)
        {
            fps = 1f / Time.deltaTime;
            Debug.Log("FPS: " + fps.ToString("F0"));
            timer = 0;
        }
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** 游戏 60fps 但玩家感觉卡顿，偶发掉帧。
**原因 →** 偶发的 GC.Collect 暂停主线程几十毫秒，或者某帧物理计算过重。
**修法 →** 用 Profiler CPU 模块找 GC Alloc 列——每帧有分配则用对象池消除。找帧率暴跌的那一帧，展开调用树定位是哪个函数耗时。常见：foreach、LINQ、字符串拼接。
</Callout>
<Callout type="trap">
**现象 →** 操作手感僵硬，点击按钮没反馈。
**原因 →** 没有视觉/听觉/触觉反馈，操作到结果之间没有中间状态。
**修法 →** 加三层反馈：视觉——按钮缩放弹跳（DOTween DOScale）、颜色变化；听觉——点击音效；触觉——手机振动（Handheld.Vibrate）。反馈让操作有重量感。
</Callout>

## 练习

<Exercises>
**问题**：为什么游戏打磨占整个项目时间的 50%？

<Answer>
核心玩法跑通只是验证了游戏好玩，但好玩不等于能发布。打磨要做三件事：1）性能优化——GC 卡顿、DrawCall 过多、内存泄漏，每项都要用 Profiler 逐帧排查；2）UX 手感——加视觉/听觉/操作反馈，让每个操作有重量感；3）多平台适配——不同平台分辨率、性能、输入方式不同。这三件事各占项目时间的 15-20%，加起来超过 50%。
</Answer>

**问题**：UX 反馈的三个层次是什么？举例说明。

<Answer>
1）视觉反馈——受击闪红、震屏、粒子特效、缓动动画。如击中敌人时屏幕震+敌人闪红+伤害数字弹出；2）听觉反馈——击中音效、环境音、BGM。如开枪有枪声、命中有金属声；3）操作反馈——吸附（自动吸附到边缘）、容错（Coyote Time）、预输入（Jump Buffer）。三层叠加让操作有重量感和爽快感。
</Answer>
</Exercises>
