## 直觉引入

赛车游戏的核心是「速度感」——引擎轰鸣、弯道漂移、碰撞飞出。Unity 的 WheelCollider 是专门为车辆物理设计的组件：模拟轮胎摩擦、悬挂系统、转向几何。用 AddForce 推一个方块也能动，但不会有真实的车辆手感。

赛道系统用触发器（Trigger）管理：起点线触发器记录圈数，检查点触发器确保不抄近路，终点触发器结束比赛。车辆 AI 则用 Waypoint 路径点+WheelCollider 转向实现自动驾驶。

## 概念讲解

<Term def="Unity 专门为车辆物理设计的碰撞体组件，模拟轮胎摩擦和悬挂">WheelCollider</Term>是赛车物理的核心。

<Term def="用触发器记录圈数和检查点的系统">赛道系统</Term>管理比赛流程。

<Term def="用路径点和转向控制实现 AI 车辆自动驾驶">车辆 AI</Term>让比赛有对手。

### WheelCollider 核心
- **悬挂**：Spring/Damper 模拟弹性
- **摩擦**：前轮转向/后轮驱动
- **力矩**：motorTorque 驱动/brakeTorque 刹车

<Term def="赛道上按顺序通过的路径点，用于 AI 导航和检查点">Waypoint</Term>是 AI 赛车的基础。

<Step title="第二步：做赛道系统">
赛道上放检查点触发器（Trigger），按顺序编号。起点线触发器记录圈数。必须按顺序通过所有检查点才能完成一圈。终点触发器结束比赛。
</Step>
<Step title="第三步：做车辆 AI">
赛道中放 Waypoint 路径点。AI 车辆找最近的下一个 Waypoint，用 WheelCollider 转向朝向它，motorTorque 加速。弯道前减速，直道加速。
</Step>
</Stepper>

## 代码对照

```csharp
// Unity C#: 赛车控制系统
using UnityEngine;
using System.Collections.Generic;

[RequireComponent(typeof(Rigidbody))]
public class CarController : MonoBehaviour
{
    public WheelCollider frontLeftWheel;
    public WheelCollider frontRightWheel;
    public WheelCollider rearLeftWheel;
    public WheelCollider rearRightWheel;

    public Transform[] wheelMeshes; // 轮子视觉模型

    public float motorTorque = 400f;
    public float brakeTorque = 300f;
    public float maxSteerAngle = 30f;
    public float downforce = 100f;

    private Rigidbody rb;

    void Start() => rb = GetComponent<Rigidbody>();

    void FixedUpdate()
    {
        float vertical = Input.GetAxis("Vertical");
        float horizontal = Input.GetAxis("Horizontal");

        // 驱动 (后轮)
        rearLeftWheel.motorTorque = vertical * motorTorque;
        rearRightWheel.motorTorque = vertical * motorTorque;

        // 刹车
        if (Input.GetKey(KeyCode.Space))
        {
            frontLeftWheel.brakeTorque = brakeTorque;
            frontRightWheel.brakeTorque = brakeTorque;
            rearLeftWheel.brakeTorque = brakeTorque;
            rearRightWheel.brakeTorque = brakeTorque;
        }
        else
        {
            frontLeftWheel.brakeTorque = 0;
            frontRightWheel.brakeTorque = 0;
            rearLeftWheel.brakeTorque = 0;
            rearRightWheel.brakeTorque = 0;
        }

        // 转向 (前轮)
        frontLeftWheel.steerAngle = horizontal * maxSteerAngle;
        frontRightWheel.steerAngle = horizontal * maxSteerAngle;

        // 下压力 (防止高速飞起)
        rb.AddForce(-transform.up * downforce * rb.velocity.magnitude);

        // 更新轮子视觉
        UpdateWheelMeshes();
    }

    void UpdateWheelMeshes()
    {
        Vector3 pos;
        Quaternion rot;

        frontLeftWheel.GetWorldPose(out pos, out rot);
        wheelMeshes[0].position = pos;
        wheelMeshes[0].rotation = rot;

        frontRightWheel.GetWorldPose(out pos, out rot);
        wheelMeshes[1].position = pos;
        wheelMeshes[1].rotation = rot;

        rearLeftWheel.GetWorldPose(out pos, out rot);
        wheelMeshes[2].position = pos;
        wheelMeshes[2].rotation = rot;

        rearRightWheel.GetWorldPose(out pos, out rot);
        wheelMeshes[3].position = pos;
        wheelMeshes[3].rotation = rot;
    }
}

// 赛道检查点系统
public class TrackManager : MonoBehaviour
{
    public Transform[] checkpoints;
    public int totalLaps = 3;

    private int currentCheckpoint = 0;
    private int currentLap = 0;
    private bool raceFinished = false;

    void OnTriggerEnter(Collider other)
    {
        if (raceFinished) return;
        if (!other.CompareTag("Checkpoint")) return;

        int checkpointIndex = System.Array.IndexOf(
            checkpoints, other.transform);

        if (checkpointIndex == currentCheckpoint)
        {
            currentCheckpoint++;
            if (currentCheckpoint >= checkpoints.Length)
            {
                currentCheckpoint = 0;
                currentLap++;
                Debug.Log("完成第 " + currentLap + " 圈");

                if (currentLap >= totalLaps)
                {
                    raceFinished = true;
                    Debug.Log("比赛结束！");
                }
            }
        }
    }
}

// 车辆 AI
public class CarAI : MonoBehaviour
{
    public Transform[] waypoints;
    public float motorTorque = 300f;
    public float maxSteerAngle = 25f;
    public float turnSpeed = 5f;

    private WheelCollider frontLeft;
    private WheelCollider frontRight;
    private WheelCollider rearLeft;
    private WheelCollider rearRight;
    private int currentWaypoint = 0;

    void Start()
    {
        var wheels = GetComponentsInChildren<WheelCollider>();
        frontLeft = wheels[0];
        frontRight = wheels[1];
        rearLeft = wheels[2];
        rearRight = wheels[3];
    }

    void FixedUpdate()
    {
        if (currentWaypoint >= waypoints.Length) return;

        // 朝向下一个 Waypoint
        Vector3 relativePos = transform.InverseTransformPoint(
            waypoints[currentWaypoint].position);
        float steer = (relativePos.x / relativePos.magnitude) * maxSteerAngle;

        frontLeft.steerAngle = Mathf.Lerp(
            frontLeft.steerAngle, steer, Time.fixedDeltaTime * turnSpeed);
        frontRight.steerAngle = frontLeft.steerAngle;

        // 加速
        rearLeft.motorTorque = motorTorque;
        rearRight.motorTorque = motorTorque;

        // 到达 Waypoint，切换下一个
        if (Vector3.Distance(transform.position,
            waypoints[currentWaypoint].position) < 5f)
        {
            currentWaypoint = (currentWaypoint + 1) % waypoints.Length;
        }
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** 车辆翻车或高速过弯飞出去。
**原因 →** 没有下压力（Downforce），高速时车身抬起失去抓地力。重心太高。
**修法 →** 在 FixedUpdate 中加 rb.AddForce(-transform.up * downforce * velocity) 模拟空气动力学下压力。降低 Rigidbody 的 Center of Mass（质心）到车身底部。调大 WheelCollider 的悬挂 Spring。
</Callout>
<Callout type="trap">
**现象 →** AI 车辆在弯道冲出赛道或原地打转。
**原因 →** AI 转向太急，没有根据弯道曲率减速。Waypoint 之间距离太远。
**修法 →** 弯道前减速：检测前方 Waypoint 与当前方向夹角大则减小 motorTorque。Waypoint 在弯道处加密。转向用 Lerp 平滑而非直接设值。加 Brake 当方向偏差太大。
</Callout>

## 练习

<Exercises>
**问题**：为什么赛车游戏用 WheelCollider 而非 Rigidbody AddForce？

<Answer>
WheelCollider 专门模拟车辆物理：轮胎摩擦（侧向/纵向）、悬挂弹簧、转向几何。这些是车辆手感的基础。用 AddForce 推方块虽然能动但没有轮胎抓地力、没有悬挂缓冲、没有转向滑动——感觉像推冰块不像开车。WheelCollider 的 motorTorque/brakeTorque/steerAngle 是真实车辆参数，调出的手感接近真实驾驶。
</Answer>

**问题**：赛道检查点系统怎么防止抄近路？

<Answer>
赛道上按顺序放检查点触发器，必须按 0→1→2→...→N 顺序通过。跳过检查点（如从 0 直接到 3）不计圈。只有通过最后一个检查点回到起点才算完成一圈。用 currentCheckpoint 记录当前要过的检查点编号，OnTriggerEnter 检查是否按顺序到达。
</Answer>
</Exercises>
