## 直觉引入

策略游戏（如星际争霸、文明）的核心是「指挥」——框选单位、右键移动、攻击敌人。这背后的技术是网格系统+A*寻路。网格把连续的地图离散化为格子，每个格子可以标记可走/不可走/有单位。A* 在网格上找最短路径。

RTS 的操作控制是另一个核心：左键框选多个单位，右键点击目的地移动。需要处理框选矩形、单位碰撞避免、队形移动等。

## 概念讲解

<Term def="把地图离散化为格子，每格标记可走/不可走的数据结构">网格系统</Term>是策略游戏的基础。

<Term def="即时战略游戏的操作方式：左键框选单位，右键移动">RTS 控制</Term>是策略游戏的交互核心。

<Term def="在网格上找最短路径的经典算法">A* 寻路</Term>让单位自动走到目标。

### 策略游戏技术栈
- **网格系统**：地图离散化
- **A* 寻路**：单位移动路径
- **框选系统**：鼠标矩形选单位
- **Fog of War**：战争迷雾

<Term def="在地图上遮挡未探索区域的系统">战争迷雾</Term>增加策略深度。

A* 算法：OpenList+CloseList+启发函数（曼哈顿距离）。从起点扩展邻居格子，计算 G+H 值，选最小 F 值的格子继续扩展，直到到达终点。
</Step>

## 代码对照

```csharp
// Unity C#: 策略游戏网格与单位控制
using UnityEngine;
using System.Collections.Generic;

public class GridManager : MonoBehaviour
{
    public int width = 50;
    public int height = 50;
    public float cellSize = 1f;
    private GridCell[,] grid;

    void Start()
    {
        grid = new GridCell[width, height];
        for (int x = 0; x < width; x++)
            for (int y = 0; y < height; y++)
                grid[x, y] = new GridCell { walkable = true };
    }

    // 世界坐标转网格坐标
    public Vector2Int WorldToGrid(Vector3 worldPos)
    {
        return new Vector2Int(
            Mathf.FloorToInt(worldPos.x / cellSize),
            Mathf.FloorToInt(worldPos.z / cellSize));
    }

    // 网格坐标转世界坐标
    public Vector3 GridToWorld(Vector2Int gridPos)
    {
        return new Vector3(
            gridPos.x * cellSize + cellSize / 2f,
            0,
            gridPos.y * cellSize + cellSize / 2f);
    }

    public bool IsWalkable(int x, int y)
    {
        if (x < 0 || x >= width || y < 0 || y >= height)
            return false;
        return grid[x, y].walkable;
    }

    // A* 寻路
    public List<Vector2Int> FindPath(Vector2Int start, Vector2Int end)
    {
        var openList = new List<PathNode>();
        var closedSet = new HashSet<Vector2Int>();
        var cameFrom = new Dictionary<Vector2Int, Vector2Int>();
        var gScore = new Dictionary<Vector2Int, float>();
        var fScore = new Dictionary<Vector2Int, float>();

        gScore[start] = 0;
        fScore[start] = Heuristic(start, end);
        openList.Add(new PathNode { pos = start, f = fScore[start] });

        while (openList.Count > 0)
        {
            // 取 F 值最小的
            openList.Sort((a, b) => a.f.CompareTo(b.f));
            var current = openList[0].pos;

            if (current == end)
                return ReconstructPath(cameFrom, current);

            openList.RemoveAt(0);
            closedSet.Add(current);

            // 检查 4 个邻居
            Vector2Int[] dirs = {
                new Vector2Int(1, 0), new Vector2Int(-1, 0),
                new Vector2Int(0, 1), new Vector2Int(0, -1) };

            foreach (var dir in dirs)
            {
                var neighbor = current + dir;
                if (!IsWalkable(neighbor.x, neighbor.y)) continue;
                if (closedSet.Contains(neighbor)) continue;

                float tentativeG = gScore[current] + 1;
                if (!gScore.ContainsKey(neighbor) || tentativeG < gScore[neighbor])
                {
                    cameFrom[neighbor] = current;
                    gScore[neighbor] = tentativeG;
                    fScore[neighbor] = tentativeG + Heuristic(neighbor, end);
                    if (!openList.Exists(n => n.pos == neighbor))
                        openList.Add(new PathNode { pos = neighbor, f = fScore[neighbor] });
                }
            }
        }
        return null; // 无路径
    }

    float Heuristic(Vector2Int a, Vector2Int b)
    {
        return Mathf.Abs(a.x - b.x) + Mathf.Abs(a.y - b.y);
    }

    List<Vector2Int> ReconstructPath(Dictionary<Vector2Int, Vector2Int> cameFrom, Vector2Int current)
    {
        var path = new List<Vector2Int> { current };
        while (cameFrom.ContainsKey(current))
        {
            current = cameFrom[current];
            path.Add(current);
        }
        path.Reverse();
        return path;
    }
}

public class GridCell { public bool walkable; }
public class PathNode { public Vector2Int pos; public float f; }

// 单位选择与控制
public class UnitController : MonoBehaviour
{
    public GridManager grid;
    private List<Unit> selectedUnits = new List<Unit>();
    private Vector3 dragStart;
    private bool isDragging;

    void Update()
    {
        // 左键框选
        if (Input.GetMouseButtonDown(0))
        {
            dragStart = Input.mousePosition;
            isDragging = true;
        }
        if (Input.GetMouseButtonUp(0) && isDragging)
        {
            SelectUnitsInRect(dragStart, Input.mousePosition);
            isDragging = false;
        }

        // 右键移动
        if (Input.GetMouseButtonDown(1) && selectedUnits.Count > 0)
        {
            Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
            if (Physics.Raycast(ray, out var hit))
            {
                var targetGrid = grid.WorldToGrid(hit.point);
                foreach (var unit in selectedUnits)
                    unit.MoveTo(targetGrid);
            }
        }
    }

    void SelectUnitsInRect(Vector3 start, Vector3 end)
    {
        selectedUnits.Clear();
        var units = FindObjectsOfType<Unit>();
        foreach (var unit in units)
        {
            var screenPos = Camera.main.WorldToScreenPoint(unit.transform.position);
            if (IsInRect(screenPos, start, end))
            {
                selectedUnits.Add(unit);
                unit.SetSelected(true);
            }
        }
    }

    bool IsInRect(Vector3 pos, Vector3 start, Vector3 end)
    {
        var min = Vector3.Min(start, end);
        var max = Vector3.Max(start, end);
        return pos.x >= min.x && pos.x <= max.x && pos.y >= min.y && pos.y <= max.y;
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** 多个单位走到同一格重叠在一起。
**原因 →** A* 寻路没考虑其他单位的占用，所有单位走同一条路径到同一个格子。
**修法 →** 在网格上标记已占用的格子，寻路时跳过。或给不同单位分配不同的目标格子（队形偏移）。加碰撞避让：到达附近时减速停下。
</Callout>
<Callout type="trap">
**现象 →** 框选时选到了屏幕外的单位或选不全。
**原因 →** 框选矩形用 GUI 坐标但单位位置用世界坐标，坐标系不匹配。
**修法 →** 统一用 ScreenPointToRay 和 WorldToScreenPoint 转换坐标。框选时遍历所有单位，把世界坐标转屏幕坐标判断是否在矩形内。注意 z 坐标为负时单位在相机背后。
</Callout>

## 练习

<Exercises>
**问题**：为什么策略游戏用网格而非自由坐标？

<Answer>
网格把连续地图离散化为格子，三个优势：1）A* 寻路在网格上效率高（节点数有限）；2）碰撞检测简单（格子是否被占）；3）建筑放置和单位定位精确到格。自由坐标需要复杂的碰撞检测和路径规划，计算量大。星际争霸、文明都用网格，只是渲染时隐藏了格子线。
</Answer>

**问题**：A* 寻路的启发函数为什么用曼哈顿距离？

<Answer>
网格移动只允许上下左右四个方向（不能斜走），曼哈顿距离（|dx|+|dy|）是这种移动方式的最短距离估计，是 admissible（不高估）的启发函数。如果允许斜走则用对角线距离。启发函数不高估才能保证 A* 找到最优路径。用欧几里得距离会低估实际距离，虽然也能找到路径但效率降低。
</Answer>
</Exercises>
