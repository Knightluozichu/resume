## 核心知识与现代 Unity 对照

### 资产职责与工具边界

声音不是背景附件，它传递事件、距离和材质感；二维图像承担纹理、图标和遮罩；三维数据包含顶点、法线、UV、骨骼与动画。选择 Blender、Maya、音频编辑器或图像工具时，应看输出契约和团队能力，而不是把所有内容都塞进 Unity 内修改。

### 拓扑、UV 与实时预算

SDS 适合塑造平滑高模，Retopology 把高模重建为可动画低模，UV 决定纹理如何覆盖表面。低多边形不是越少越好，而是在轮廓、关节变形、法线质量和目标设备预算之间取舍。导出前固定单位、轴向、原点和命名，才能避免导入后靠缩放补救。

### 从 Standard Shader 到现代材质

原书以 Standard Shader 和 PBS 解释材质；现代项目应映射到 Built-in Standard、URP Lit 或 HDRP Lit。金属度、粗糙度或平滑度、法线和遮蔽贴图必须按管线约定打包。Reflection Probe 提供局部环境反射，但不能替代正确的直接光和间接光。

### 角色、骨骼与环境验证

角色资产要同时检查 Avatar、骨骼映射、蒙皮权重和动作重定向。Mixamo 可提供快速动作来源，但授权、骨骼命名和根运动仍需核验。Skybox 与环境光决定材质基准；在资产检查场景中旋转灯光和相机，比只看一张漂亮截图更能暴露法线、接缝和反射问题。

在复刻时，最容易犯的错误是只追求最终画面或最终数值。正确的证据链必须同时保存环境、输入、首个状态变化、中间状态、失败原因和最终产物。版本差异可以改变按钮位置或 API 名称，却不能改变本单元要解决的对象关系和验收问题。
