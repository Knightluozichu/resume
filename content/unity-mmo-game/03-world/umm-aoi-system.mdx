## 直觉引入

想象你在一个万人演唱会上。如果每个人说话都通过大喇叭广播给全场，那噪音会让人崩溃。实际上你只关心身边的人在说什么——你有一个「兴趣区域」，区域外的人说话你听不到。MMO 的 AOI（Area of Interest）就是这个机制：服务器只把玩家视野范围内的实体信息推送给他，视野外的一概不传。万人同服的关键不是减少消息总量，而是只发给关心的客户端。

## AOI 的本质

<Term def="AOI（Area of Interest）是 MMO 服务器的空间索引技术，确保每个玩家只收到视野范围内实体的消息，把消息广播复杂度从 O(n^2) 降到 O(n*k)。">AOI</Term>解决的是「谁需要知道谁的存在」。万人同服时，如果每个玩家的移动都广播给所有人，服务器每秒要处理 10000 * 10000 = 1 亿次消息发送。AOI 确保每个玩家只收到视野范围内（如周围 50 米）实体的消息，把消息量降到 O(n*k)（k 为视野内平均实体数，通常 50-200）。

## 九宫格算法

九宫格是最常用的 AOI 算法。把世界划分为固定大小的方格，玩家所在格及周围 8 格内的实体即为可见实体：

```csharp
// 九宫格 AOI 实现
public class GridAOI {
    private float cellSize = 50f;  // 每格 50x50 米
    private Dictionary<Vector2Int, HashSet<Entity>> cells = new();

    // 实体进入/移动时更新所在格子
    public void OnEntityMove(Entity entity, Vector3 newPos) {
        Vector2Int newCell = WorldToCell(newPos);
        Vector2Int oldCell = entity.Cell;

        if (newCell == oldCell) return;  // 格子没变，不处理

        // 从旧格子移除
        if (cells.ContainsKey(oldCell))
            cells[oldCell].Remove(entity);

        // 加入新格子
        if (!cells.ContainsKey(newCell))
            cells[newCell] = new HashSet<Entity>();
        cells[newCell].Add(entity);
        entity.Cell = newCell;

        // 计算视野变化：新进入的实体和离开的实体
        var newVisible = GetNineGrids(newCell).SelectMany(c =>
            cells.GetValueOrDefault(c) ?? new HashSet<Entity>());
        var oldVisible = GetNineGrids(oldCell).SelectMany(c =>
            cells.GetValueOrDefault(c) ?? new HashSet<Entity>());

        var entered = newVisible.Except(oldVisible);  // 新进入视野
        var left = oldVisible.Except(newVisible);     // 离开视野

        // 通知客户端：entered 发 EntityEnter，left 发 EntityLeave
    }

    Vector2Int WorldToCell(Vector3 pos) =>
        new((int)(pos.x / cellSize), (int)(pos.z / cellSize));

    Vector2Int[] GetNineGrids(Vector2Int center) {
        var result = new Vector2Int[9];
        int i = 0;
        for (int dx = -1; dx <= 1; dx++)
            for (int dz = -1; dz <= 1; dz++)
                result[i++] = new(center.x + dx, center.y + dz);
        return result;
    }
}
```

## 十字链表算法

十字链表用两条排序链表管理实体，视野范围可动态变化：

```csharp
// 十字链表 AOI（简化版）
public class CrossListAOI {
    // 每个实体同时挂在 X 和 Y 排序链表上
    // 查询视野 = X 链表区间 ∩ Y 链表区间
    private LinkedList<Entity> xList = new();  // 按 x 坐标排序
    private LinkedList<Entity> yList = new();  // 按 y 坐标排序

    public List<Entity> QueryView(Entity center, float radius) {
        // X 区间：[center.x - radius, center.x + radius]
        var xSet = xList.Where(e =>
            Math.Abs(e.Position.x - center.Position.x) <= radius);
        // Y 区间：[center.y - radius, center.y + radius]
        var ySet = yList.Where(e =>
            Math.Abs(e.Position.z - center.Position.z) <= radius);
        // 交集即为视野内实体
        return xSet.Intersect(ySet).ToList();
    }

    // 实体移动时更新两条链表中的位置（插入排序）
    public void OnEntityMove(Entity entity, Vector3 newPos) {
        entity.Position = newPos;
        Reinsert(xList, entity, e => e.Position.x);
        Reinsert(yList, entity, e => e.Position.z);
    }
}
```

## 边界抖动

玩家在格子边界来回走动会导致频繁进出（抖动）。用迟滞区间解决：

```csharp
// 迟滞区间：加载用小阈值，卸载用大阈值
public class GridAOIWithHysteresis : GridAOI {
    private float loadRadius = 50f;    // 进入 50 米内加载
    private float unloadRadius = 80f;  // 超过 80 米才卸载

    public void OnEntityMove(Entity entity, Vector3 newPos) {
        // 检查新进入的实体（距离 < loadRadius 才加载）
        foreach (var other in GetAllEntities()) {
            float dist = Vector3.Distance(newPos, other.Position);
            if (!entity.Visible.Contains(other) && dist < loadRadius) {
                entity.Visible.Add(other);
                SendEntityEnter(entity, other);
            }
            // 只有距离 > unloadRadius 才卸载（留有余量）
            if (entity.Visible.Contains(other) && dist > unloadRadius) {
                entity.Visible.Remove(other);
                SendEntityLeave(entity, other);
            }
        }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：AOI 的目的就是减少消息数量。** AOI 的真正目的是「只发给关心的客户端」——消息总量并没有减少（该产生的还是会产生），只是收件人范围被精确控制了。如果一个区域有 200 人，一个人的移动消息还是要发 200 份，但不会发给区域外的 9800 人。AOI 是用「精确投递」代替「广播」，不是消除消息。
</Callout>

<Exercises>
**问题 1**：九宫格和十字链表各有什么优缺点？

<Answer>
九宫格：实现简单、查询快（O(1) 遍历 9 格），但格子大小固定、不能适应不同视野需求、边界抖动。十字链表：视野范围可动态变化，不依赖固定格子，但实体移动时要更新两条链表、维护开销大。MMO 通常用九宫格（简单可靠），需要灵活视野时用十字链表。
</Answer>

**问题 2**：边界抖动如何解决？

<Answer>
用迟滞区间：加载用较小阈值（如 50 米内加载），卸载用较大阈值（如 80 米外才卸载）。玩家在边界 ±5 米范围内来回走动时，不会触发反复加载/卸载。代价是多保留一些实体在内存中，用少量内存换稳定性。
</Answer>
</Exercises>
