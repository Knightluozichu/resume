## 直觉引入

深度纹理就像一张「距离地图」——每个像素存储着它离相机有多远。但这个距离是经过透视投影压缩的（远处变化很小），需要用数学公式还原成真实距离。有了这张地图，你就能做景深（远处模糊）、屏幕空间雾（远处变白）等基于深度的特效。

## 概念讲解

<Term def="存储每个像素裁剪空间 z 值的特殊纹理">深度纹理</Term><Term def="将非线性深度值转换为 0~1 线性深度的函数">Linear01Depth</Term><Term def="基于深度模拟相机焦外模糊的特效">景深 DOF</Term><Term def="在屏幕空间用深度驱动的雾效">屏幕空间雾</Term>

### 获取深度纹理
Camera.depthTextureMode = DepthTextureMode.Depth 生成深度纹理。Shader 中通过 _CameraDepthTexture 全局变量采样。DepthNormals 模式同时获取深度和法线。

### 深度值线性化
深度纹理存储裁剪空间 z 值（非线性），远处变化很小。用 Linear01Depth 转换为线性深度（0=近 1=远），LinearEyeDepth 转换为观察空间距离。

### 景深 DOF
采样深度获取像素深度，用焦点距离和范围计算模糊权重，对焦外区域做模糊，将模糊与原图按权重混合。

### 屏幕空间雾
用 LinearEyeDepth 转换为观察空间距离，用指数衰减计算雾密度，将雾色与场景色按密度混合。比顶点雾更精确。

## 代码对照

```csharp
// C# 开启深度纹理
void Start() {
    GetComponent<Camera>().depthTextureMode = DepthTextureMode.Depth;
    // 同时获取深度和法线
    // GetComponent<Camera>().depthTextureMode = DepthTextureMode.DepthNormals;
}
```

```hlsl
// 屏幕空间雾效 Shader
sampler2D _MainTex;
sampler2D _CameraDepthTexture;
float4 _FogColor;
float _FogDensity;
float _FogStart;
float _FogEnd;

fixed4 frag(v2f_img i) : SV_Target {
    fixed4 sceneColor = tex2D(_MainTex, i.uv);
    // 采样深度纹理
    float rawDepth = SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, i.uv);
    // 转换为观察空间距离
    float eyeDepth = LinearEyeDepth(rawDepth);
    // 指数衰减雾密度
    float fogFactor = exp(-eyeDepth * _FogDensity);
    fogFactor = saturate(1.0 - fogFactor);
    // 混合雾色和场景色
    return lerp(sceneColor, _FogColor, fogFactor);
}
```

```hlsl
// 景深效果核心
float depth = Linear01Depth(SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, i.uv));
float blurWeight = smoothstep(_FocusDistance, _FocusDistance + _FocusRange, abs(depth - _FocusDistance));
// blurWeight 越大越模糊
fixed4 blurred = tex2D(_BlurredTex, i.uv);
fixed4 original = tex2D(_MainTex, i.uv);
return lerp(original, blurred, blurWeight);
```

深度纹理用 SAMPLE_DEPTH_TEXTURE 采样，必须用 Linear01Depth/LinearEyeDepth 转换后才能正确使用。

## 常见误区

<Callout type="trap">
**现象 →** 深度纹理采样的值不对，雾效或景深效果异常。
**原因 →** 直接使用原始深度值没有线性化。
**修法 →** 深度纹理存储的是裁剪空间的非线性 z 值，远处变化很小。必须用 Linear01Depth（0~1）或 LinearEyeDepth（观察空间距离）转换后才能正确比较和计算。
</Callout>

<Callout type="trap">
**现象 →** 深度纹理全黑或全白，无法正常使用。
**原因 →** 相机没有开启深度纹理模式。
**修法 →** 在 C# 脚本中设置 Camera.depthTextureMode = DepthTextureMode.Depth。注意如果有多个相机，每个需要深度的相机都要开启。某些渲染路径（如 Forward）可能需要额外配置。
</Callout>

## 练习

<Exercises>
**问题**：Unity 中如何获取深度纹理？

<Answer>
在相机上设置 Camera.depthTextureMode = DepthTextureMode.Depth 生成深度纹理。在 Shader 中通过 _CameraDepthTexture 全局变量采样。也可用 DepthNormals 模式同时获取深度和法线。
</Answer>

**问题**：如何用深度纹理实现景深（DOF）效果？

<Answer>
1)采样深度纹理获取每个像素的深度 2)用焦点距离和范围计算模糊权重 3)对焦外区域做模糊 4)将模糊结果与原图按权重混合 5)近焦和远焦可分别处理 6)用降分辨率模糊提升性能。
</Answer>
</Exercises>
