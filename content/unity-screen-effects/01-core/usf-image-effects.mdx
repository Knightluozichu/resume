## 直觉引入

图像效果就像 Photoshop 的滤镜——模糊是把每个像素和周围像素混合，边缘检测是找出颜色变化剧烈的地方，扭曲是让像素从别的地方取色。每个效果都是对全屏每个像素做数学运算，用不同的采样方式和计算公式产生不同效果。

## 概念讲解

<Term def="用高斯/方框卷积核降低图像高频细节的效果">模糊</Term><Term def="用 Sobel/Roberts 算子检测图像亮度梯度的效果">边缘检测</Term><Term def="从中心向外放射状采样的模糊效果">径向模糊</Term><Term def="用噪声纹理偏移采样 UV 产生扭曲的效果">屏幕扭曲</Term>

### 常用效果
模糊（高斯/方框/径向/方向）、锐化（Unsharp Mask）、边缘检测（Sobel/Roberts）、色彩反转、灰度化、像素化、扭曲（波纹/鱼眼）。

### Sobel 边缘检测
采样 3x3 像素亮度，用 Sobel 算子（水平和垂直卷积核）计算梯度，梯度模长大于阈值为边缘。可叠加深度和法线纹理做更精确检测。

### 径向 vs 方向模糊
径向模糊以中心为原点径向步进采样，产生放射状效果。方向模糊沿固定方向步进采样。径向模糊常用于速度感，方向模糊用于运动模糊。

### 屏幕扭曲
用噪声纹理生成偏移量，修改采样 UV，用修改后的 UV 采样源纹理。噪声 UV 随时间流动产生动态扭曲。

## 代码对照

```hlsl
// Sobel 边缘检测
sampler2D _MainTex;
float _EdgeThreshold;

fixed4 frag(v2f_img i) : SV_Target {
    float2 uv = i.uv;
    float2 texel = float2(1.0 / _ScreenParams.x, 1.0 / _ScreenParams.y);

    // 采样 3x3 亮度
    float l[9];
    l[0] = Luminance(tex2D(_MainTex, uv + float2(-1,-1) * texel).rgb);
    l[1] = Luminance(tex2D(_MainTex, uv + float2( 0,-1) * texel).rgb);
    l[2] = Luminance(tex2D(_MainTex, uv + float2( 1,-1) * texel).rgb);
    l[3] = Luminance(tex2D(_MainTex, uv + float2(-1, 0) * texel).rgb);
    l[4] = Luminance(tex2D(_MainTex, uv).rgb);
    l[5] = Luminance(tex2D(_MainTex, uv + float2( 1, 0) * texel).rgb);
    l[6] = Luminance(tex2D(_MainTex, uv + float2(-1, 1) * texel).rgb);
    l[7] = Luminance(tex2D(_MainTex, uv + float2( 0, 1) * texel).rgb);
    l[8] = Luminance(tex2D(_MainTex, uv + float2( 1, 1) * texel).rgb);

    // Sobel 算子
    float gx = -l[0] - 2*l[3] - l[6] + l[2] + 2*l[5] + l[8];
    float gy = -l[0] - 2*l[1] - l[2] + l[6] + 2*l[7] + l[8];
    float edge = sqrt(gx*gx + gy*gy);

    fixed4 col = tex2D(_MainTex, uv);
    return edge > _EdgeThreshold ? fixed4(0,0,0,1) : col;
}
```

```hlsl
// 屏幕扭曲
sampler2D _MainTex;
sampler2D _NoiseTex;
float _DistortionStrength;
float _Time;

fixed4 frag(v2f_img i) : SV_Target {
    // 采样噪声纹理获取偏移
    float2 noiseUV = i.uv + float2(_Time * 0.05, _Time * 0.03);
    float2 offset = (tex2D(_NoiseTex, noiseUV).rg - 0.5) * _DistortionStrength;
    // 用偏移 UV 采样源纹理
    return tex2D(_MainTex, i.uv + offset);
}
```

Sobel 边缘检测用 3x3 卷积核计算梯度，屏幕扭曲用噪声纹理偏移 UV 采样。

## 常见误区

<Callout type="trap">
**现象 →** 边缘检测结果噪点很多。
**原因 →** 阈值太低或没有用深度/法线纹理辅助。
**修法 →** 提高边缘检测阈值过滤弱边缘。叠加深度纹理做深度边缘检测，叠加法线纹理做法线边缘检测。结合颜色+深度+法线三种边缘能得到更干净准确的结果。
</Callout>

<Callout type="trap">
**现象 →** 高斯模糊性能很差。
**原因 →** 用了一趟大核 2D 卷积。
**修法 →** 将高斯模糊分离为水平+垂直两趟 1D 卷积，采样次数从 N^2 降为 2N。进一步可用降采样-上采样方法减少采样次数。移动端考虑用方框模糊近似高斯。
</Callout>

## 练习

<Exercises>
**问题**：Sobel 边缘检测在屏幕特效中如何实现？

<Answer>
1)采样当前像素和周围 8 个像素的亮度值 2)用 Sobel 算子做水平和垂直卷积 3)计算梯度的模长 4)模长大于阈值为边缘 5)可叠加深度和法线纹理做更精确的边缘检测。
</Answer>

**问题**：如何实现屏幕扭曲效果（如传送门、热气扭曲）？

<Answer>
1)用噪声纹理生成扭曲偏移量 2)偏移量乘以强度系数 3)用偏移量修改屏幕 UV 4)用修改后的 UV 采样源纹理 5)噪声 UV 随时间流动产生动态扭曲 6)可用遮罩纹理控制扭曲区域。
</Answer>
</Exercises>
