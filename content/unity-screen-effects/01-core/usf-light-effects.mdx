## 直觉引入

光照特效就像给照片加上「光的感觉」——体积光是阳光穿过树林时的光柱，镜头光晕是镜头对着光源时产生的光斑，SSAO 是角落和缝隙里的阴影，镜头灰尘是镜头上的污渍散射光。这些效果让画面有「被相机拍到」的真实感，而不是 CG 感。

## 概念讲解

<Term def="在屏幕空间模拟光散射效果的特效">体积光 God Rays</Term><Term def="光源在镜头中产生光斑和星芒的特效">镜头光晕</Term><Term def="在屏幕空间近似计算环境遮蔽的特效">SSAO</Term><Term def="模拟镜头污渍散射光线的特效">镜头灰尘</Term>

### 体积光
以光源在屏幕上的投影位置为中心，从每个像素向光源方向径向步进采样，累加采样亮度作为光散射量，用衰减函数控制距离衰减。

### 镜头光晕
计算光源到屏幕中心的向量，沿反方向生成一系列光斑。每个光斑用不同大小、颜色和位置，Blend Add 叠加到画面。

### SSAO
采样每个像素周围的随机半球，用深度纹理重建位置，比较深度差。深度差小于半径的采样点贡献遮蔽，累加遮蔽值并平滑。

## 代码对照

```hlsl
// 体积光 (God Rays) — 径向采样
sampler2D _MainTex;
float2 _LightScreenPos; // 光源屏幕位置
float _SampleCount;
float _Density;
float _Weight;

fixed4 frag(v2f_img i) : SV_Target {
    float2 deltaUV = (i.uv - _LightScreenPos) / _SampleCount * _Density;
    float2 uv = i.uv;
    float illumination = 1.0;
    float3 color = float3(0, 0, 0);

    for (int j = 0; j < _SampleCount; j++) {
        uv -= deltaUV;
        fixed4 sampled = tex2D(_MainTex, uv);
        illumination *= _Weight;
        color += sampled.rgb * illumination;
    }
    color /= _SampleCount;

    fixed4 original = tex2D(_MainTex, i.uv);
    return original + fixed4(color, 1.0);
}
```

```hlsl
// SSAO 核心
sampler2D _CameraDepthTexture;
sampler2D _CameraDepthNormalsTexture;
float3 _Samples[64]; // 随机半球采样点

float frag(v2f_img i) : SV_Target {
    float depth = LinearEyeDepth(SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, i.uv));
    float3 normal = DecodeViewNormalStereo(tex2D(_CameraDepthNormalsTexture, i.uv));
    // 重建观察空间位置
    float3 pos = reconstructViewPos(i.uv, depth);
    // 采样半球
    float occlusion = 0;
    for (int s = 0; s < 64; s++) {
        float3 samplePos = pos + _Samples[s] * _Radius;
        float2 sampleUV = projectToScreen(samplePos);
        float sampleDepth = LinearEyeDepth(SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, sampleUV));
        occlusion += (sampleDepth <= samplePos.z ? 1.0 : 0.0);
    }
    occlusion = 1.0 - occlusion / 64.0;
    return occlusion;
}
```

体积光用径向步进累加亮度，SSAO 用随机半球采样深度比较计算遮蔽。两者都需要降分辨率优化。

## 常见误区

<Callout type="trap">
**现象 →** 体积光效果噪点严重。
**原因 →** 采样次数太少或没有平滑。
**修法 →** 增加采样次数（但注意性能），或降分辨率处理后上采样。用 jitter（随机偏移采样位置）加时间累加平滑。降分辨率本身也是一种天然的模糊。
</Callout>

<Callout type="trap">
**现象 →** SSAO 产生画面闪烁。
**原因 →** 采样噪声不随屏幕空间旋转，或分辨率太低。
**修法 →** 用 4x4 旋转向量噪声使采样模式随像素变化。降分辨率计算后做双边滤波上采样（保留边缘的模糊）。增加采样数减少方差。时域累加可进一步稳定画面。
</Callout>

## 练习

<Exercises>
**问题**：体积光（God Rays）的径向采样实现原理是什么？

<Answer>
1)以光源在屏幕上的投影位置为中心 2)从每个像素向光源方向做径向步进采样 3)累加采样亮度作为光散射量 4)用衰减函数控制距离衰减 5)将散射光叠加到场景颜色 6)可降分辨率处理提升性能。
</Answer>

**问题**：如何实现屏幕空间环境遮蔽（SSAO）？

<Answer>
1)在屏幕空间采样每个像素周围的随机半球 2)用深度纹理重建位置 3)比较采样点和当前点的深度差 4)深度差小于半径的采样点贡献遮蔽 5)累加遮蔽值并平滑 6)将遮蔽因子乘到环境光上。
</Answer>
</Exercises>
