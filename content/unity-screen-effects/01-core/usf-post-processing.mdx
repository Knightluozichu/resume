## 直觉引入

后处理栈就像一套滤镜管理系统——Layer 是相机上的滤镜架（控制执行），Volume 是滤镜的影响范围（进入区域才生效），Profile 是滤镜配方（配置具体参数）。走进不同区域自动切换滤镜，走出区域平滑恢复，全程自动过渡。

## 概念讲解

<Term def="挂载在相机上控制后处理渲染执行的组件">PostProcessLayer</Term><Term def="控制后处理效果影响范围和权重的组件">PostProcessVolume</Term><Term def="后处理效果配置资源，含各效果参数">PostProcessProfile</Term><Term def="多个 Volume 效果按权重平滑过渡的机制">Volume Blending</Term>

### 三层架构
- PostProcessLayer：挂在相机上，控制渲染执行和抗锯齿
- PostProcessVolume：场景中的影响范围，可全局或局部
- PostProcessProfile：效果配置资源，含 Bloom/ColorGrading/Vignette 等

### Volume Blending
多个 Volume 可设置影响范围和优先级。相机进入 Volume 范围时效果按权重平滑过渡。实现区域性的后处理变化（如进入洞穴画面变暗）。

### URP 差异
URP 后处理集成在渲染管线中，用 Volume + VolumeProfile 配置。自定义后处理用 ScriptableRendererFeature + ScriptableRenderPass。

## 代码对照

```csharp
// URP 自定义后处理
// 1. VolumeComponent 定义参数
[VolumeComponentMenu("Custom/MyEffect")]
public class MyEffectSettings : VolumeComponent {
    public FloatParameter intensity = new FloatParameter(1f);
    public ColorParameter tintColor = new ColorParameter(Color.white);
}

// 2. ScriptableRenderPass 执行渲染
public class MyEffectPass : ScriptableRenderPass {
    public override void Execute(ScriptableRenderContext ctx, ref RenderingData data) {
        var stack = VolumeManager.instance.stack;
        var settings = stack.GetComponent<MyEffectSettings>();
        if (!settings.IsActive()) return;

        // Blit 执行自定义 Shader
        Blit(source, destination, material);
    }
}

// 3. ScriptableRendererFeature 注册
public class MyEffectFeature : ScriptableRendererFeature {
    public override void AddRenderPasses(ScriptableRenderer renderer, ref RenderingData data) {
        renderer.EnqueuePass(myEffectPass);
    }
}
```

URP 自定义后处理三件套：VolumeComponent（参数）+ RenderPass（执行）+ RendererFeature（注册）。

## 常见误区

<Callout type="trap">
**现象 →** Post Processing Stack 在 URP 项目中不工作。
**原因 →** URP 不兼容内置管线的 Post Processing Stack v2。
**修法 →** URP 使用自带的 Volume 系统。移除 PostProcessing Stack v2 包，使用 URP 的 Volume + VolumeProfile。自定义效果用 ScriptableRendererFeature 而非 OnRenderImage。
</Callout>

<Callout type="trap">
**现象 →** Volume Blending 过渡太突兀。
**原因 →** 权重变化太快或 Volume 范围太小。
**修法 →** 增大 Volume 的 Box Collider 范围使过渡区域更长。调整 Weight 曲线使过渡更平滑。确保 Blend Distance 设置合理。全局 Volume 用 weight 属性手动控制过渡。
</Callout>

## 练习

<Exercises>
**问题**：PostProcessVolume 的 Blending 功能如何工作？

<Answer>
多个 Volume 可以在场景中设置影响范围和优先级。相机进入 Volume 范围时，效果按权重平滑过渡。可设置全局 Volume 和局部 Volume，实现区域性的后处理效果变化。
</Answer>

**问题**：如何在 URP 中自定义后处理效果？

<Answer>
1)创建 ScriptableRendererFeature 和 ScriptableRenderPass 2)在 Pass 中用 Blit 执行自定义 Shader 3)创建 VolumeComponent 定义可调参数 4)用 RenderTargetHandle 管理临时纹理 5)在 Render Feature 中注入到管线合适位置。
</Answer>
</Exercises>
