## 直觉引入

OnRenderImage 就像照片打印机的最后一道工序——相机拍好照片后（场景渲染完成），在打印出来之前（输出到屏幕），你有机会用滤镜处理这张照片。Graphics.Blit 就是「把照片送进滤镜机器」的操作：把源纹理送进材质的 Shader，处理完输出到目标。

## 概念讲解

<Term def="Unity 中相机渲染完成后处理屏幕图像的回调">OnRenderImage</Term><Term def="将源纹理经材质 Shader 处理后输出到目标的函数">Graphics.Blit</Term><Term def="离屏渲染目标纹理，存储中间处理结果">RenderTexture</Term><Term def="多个屏幕特效串联执行的处理方式">多效果链</Term>

### OnRenderImage
在相机渲染完成后自动调用。src 是当前帧场景渲染结果，dest 是输出目标（null 则输出到屏幕）。通过 Graphics.Blit(src, dest, material) 执行处理。

### Graphics.Blit
内部渲染一个全屏四边形，将 src 绑定到材质主纹理，用 Shader 处理每个像素后输出到 dest。顶点着色器只传递 UV，像素着色器做实际处理。

### 多效果链
多个效果串联执行：src → Blit(tmp, mat1) → Blit(tmp, mat2) → Blit(dest, mat3)。用 RenderTexture.GetTemporary / Release 管理临时纹理避免 GC。

## 代码对照

```csharp
// 多效果链式处理
public class MultiEffect : MonoBehaviour {
    public Material blurMaterial;
    public Material colorMaterial;
    private RenderTexture tempTexture;

    void OnRenderImage(RenderTexture src, RenderTexture dest) {
        // 获取临时 RenderTexture
        RenderTexture tmp = RenderTexture.GetTemporary(src.width, src.height);

        // 效果 1: 模糊
        Graphics.Blit(src, tmp, blurMaterial);
        // 效果 2: 调色
        Graphics.Blit(tmp, dest, colorMaterial);

        // 释放临时纹理
        RenderTexture.ReleaseTemporary(tmp);
    }
}
```

```hlsl
// 屏幕特效 Shader — 简单亮度调整
Shader "Hidden/BrightnessEffect" {
    Properties {
        _MainTex ("Texture", 2D) = "white" {}
        _Brightness ("Brightness", Float) = 1.0
    }
    SubShader {
        Pass {
            CGPROGRAM
            #pragma vertex vert_img
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            float _Brightness;

            fixed4 frag(v2f_img i) : SV_Target {
                fixed4 col = tex2D(_MainTex, i.uv);
                return col * _Brightness;
            }
            ENDCG
        }
    }
}
```

多效果链用临时 RenderTexture 串联 Blit。注意 GetTemporary/Release 配对使用避免内存泄漏。

## 常见误区

<Callout type="trap">
**现象 →** 屏幕特效不执行。
**原因 →** 脚本没挂载在相机上，或 OnRenderImage 签名不对。
**修法 →** 屏幕特效脚本必须挂载在有 Camera 组件的 GameObject 上。OnRenderImage 签名必须是 void OnRenderImage(RenderTexture src, RenderTexture dest)。确保相机已启用渲染。
</Callout>

<Callout type="trap">
**现象 →** 频繁创建 RenderTexture 导致 GC 和性能问题。
**原因 →** 每帧 new RenderTexture。
**修法 →** 使用 RenderTexture.GetTemporary / ReleaseTemporary 池化临时纹理。固定尺寸的中间纹理可在 OnEnable 创建、OnDisable 释放。避免每帧分配。
</Callout>

## 练习

<Exercises>
**问题**：OnRenderImage 回调的 src 和 dest 参数分别是什么？

<Answer>
src 是源 RenderTexture，包含当前帧已渲染的场景图像。dest 是目标 RenderTexture，处理后的图像输出到这里。如果 dest 为 null 则直接输出到屏幕。通过 Graphics.Blit(src, dest, material) 执行处理。
</Answer>

**问题**：如何构建一个可扩展的多特效屏幕特效系统？

<Answer>
1)创建 ScreenEffectBase 基类管理 OnRenderImage 2)每个效果继承基类实现自己的 Shader 3)用链式 Blit 串联多个效果 4)管理临时 RenderTexture 池避免 GC 5)支持效果开关和参数调节 6)移动端降分辨率处理。
</Answer>
</Exercises>
