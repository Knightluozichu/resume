## 直觉引入

Bloom 就像过曝照片中亮的东西向外「溢光」——太阳、灯泡、自发光物体的亮度超过阈值后，光芒向周围扩散。实现方法是：先把亮的区域提取出来，缩小几遍模糊（降采样），再放大回去累加（上采样），最后叠加到画面上。缩小再放大的过程让光晕自然扩散。

## 概念讲解

<Term def="亮度超过阈值的区域向周围扩散发光的特效">Bloom 辉光</Term><Term def="将纹理逐级缩小处理以减少采样次数的技术">降采样</Term><Term def="将缩小后的纹理逐级放大累加的技术">上采样</Term><Term def="模拟镜头污渍散射光线的 Bloom 增强效果">Lens Dirt</Term>

### Bloom 管线
1. 从 HDR 场景提取亮度超过阈值的区域
2. 对高亮纹理做降采样（Mip 链：1/2, 1/4, 1/8, 1/16）
3. 每级做高斯模糊
4. 从最小 Mip 逐级上采样累加
5. 将 Bloom 纹理叠加到场景颜色

### 降采样-上采样优势
小尺寸小核模糊等价于大尺寸大核模糊。采样次数大幅减少，小尺寸纹理缓存命中率更高。比直接大核模糊高效得多。

### Lens Dirt
将 Bloom 纹理与 Dirt 纹理相乘得到散射光，叠加到 Bloom 结果。Dirt 纹理让辉光产生不规则散射，增加真实感。

将 Bloom 纹理与 Dirt 贴图相乘得到散射光，乘以强度后叠加到 Bloom 结果。最终将 Bloom 叠加到场景颜色并做色调映射。
</Step>

## 代码对照

```hlsl
// 亮度提取
sampler2D _MainTex;
float _BloomThreshold;

fixed4 fragExtract(v2f_img i) : SV_Target {
    fixed4 col = tex2D(_MainTex, i.uv);
    float brightness = Luminance(col.rgb);
    float contribution = max(0, brightness - _BloomThreshold);
    return col * contribution / max(brightness, 0.00001);
}

// 降采样模糊（每级）
sampler2D _BloomTex;
float4 _TexelSize;

fixed4 fragDownsample(v2f_img i) : SV_Target {
    float2 uv = i.uv;
    float2 texel = _TexelSize.xy;
    // 5x5 高斯采样（简化为 13 次）
    fixed4 sum = tex2D(_BloomTex, uv) * 0.227;
    sum += tex2D(_BloomTex, uv + float2(1,0)*texel) * 0.194;
    sum += tex2D(_BloomTex, uv - float2(1,0)*texel) * 0.194;
    sum += tex2D(_BloomTex, uv + float2(0,1)*texel) * 0.121;
    sum += tex2D(_BloomTex, uv - float2(0,1)*texel) * 0.121;
    return sum;
}

// 上采样累加
sampler2D _BloomLow; // 低分辨率
sampler2D _BloomHigh; // 高分辨率
float _BloomIntensity;

fixed4 fragUpsample(v2f_img i) : SV_Target {
    fixed4 low = tex2D(_BloomLow, i.uv);
    fixed4 high = tex2D(_BloomHigh, i.uv);
    return lerp(high, low, _BloomIntensity);
}

// 最终叠加
fixed4 fragCombine(v2f_img i) : SV_Target {
    fixed4 scene = tex2D(_MainTex, i.uv);
    fixed4 bloom = tex2D(_BloomTex, i.uv);
    fixed4 dirt = tex2D(_DirtTex, i.uv);
    // Bloom × Dirt = 散射光
    float3 lensDirt = bloom.rgb * dirt.rgb * _DirtIntensity;
    return fixed4(scene.rgb + bloom.rgb + lensDirt, 1.0);
}
```

Bloom 管线：亮度提取 → 降采样模糊 → 上采样累加 → 叠加场景。Lens Dirt 与 Bloom 相乘后叠加增强真实感。

## 常见误区

<Callout type="trap">
**现象 →** Bloom 效果不够明显或太强烈。
**原因 →** 阈值或强度参数不对。
**修法 →** 阈值控制哪些区域产生辉光（通常 0.8-1.2），太低则全屏发光。强度控制辉光亮度叠加比例。需要 HDR 渲染才能让亮度超过 1.0 产生正确的 Bloom。先确保 HDR 开启。
</Callout>

<Callout type="trap">
**现象 →** Bloom 在移动物体边缘出现闪烁。
**原因 →** 降采样导致高频信息丢失产生不稳定。
**修法 →** 增加降采样层数减少每级缩放比。使用稳定的采样模式（避免随机）。可加时域累加稳定画面。确保降采样时使用正确的过滤模式（Bilinear）。
</Callout>

## 练习

<Exercises>
**问题**：Bloom 效果的标准管线步骤是什么？

<Answer>
1)从 HDR 场景中提取亮度超过阈值的区域 2)对高亮纹理做降采样（Mip 链）3)每级做高斯模糊 4)从最小 Mip 逐级上采样累加 5)将 Bloom 纹理叠加到场景颜色 6)最终色调映射输出。
</Answer>

**问题**：Bloom 的降采样-上采样方法为什么比直接大核模糊高效？

<Answer>
直接大核模糊需要 N*N 次采样。降采样将纹理缩小到小尺寸，在小尺寸上做小核模糊等价于大尺寸的大核模糊。上采样时累加各级结果。采样次数大幅减少，且小尺寸纹理缓存命中率更高。
</Answer>
</Exercises>
