## 直觉引入

总复习就像把所有滤镜串成一条完整的后期流水线——先拍好照片（场景渲染+深度纹理），依次过 SSAO（加暗角）、SSR（加反射）、Bloom（加辉光）、DOF（加景深）、Motion Blur（加运动模糊）、Color Grading（调色），最后输出。每个环节都是前面积累的技术，串联起来就是电影级后处理。

## 概念讲解

<Term def="从需求分析到 URP 迁移的完整屏幕特效开发流程">工作流程</Term><Term def="场景渲染→RenderTexture→Blit→Shader→链式→屏幕的完整数据传递">数据流</Term><Term def="降分辨率→合并Pass→RT池化→按需深度纹理的优化策略">优化链</Term><Term def="SSAO→SSR→Bloom→DOF→ColorGrading 的后处理组合">电影级管线</Term>

### 完整流程
1)分析效果需求确定技术方案 2)编写屏幕特效 Shader 3)创建 C# 脚本管理 OnRenderImage 4)配置 RenderTexture 和材质 5)串联多效果链 6)性能优化 7)URP 迁移到 RenderFeature

### 数据流
场景渲染→RenderTexture（颜色+深度）→OnRenderImage→Blit(src,dest,material)→Shader 全屏处理→多效果链式串联→最终输出到屏幕

### 优化链
降分辨率处理再上采样 → 合并多效果到一个 Pass → RenderTexture 池化 → 深度/法线纹理按需开启 → 移动端减少效果数量和精度 → Profiler 定位最贵 Pass

### 电影级管线
SSAO → SSR → Bloom（+Lens Dirt）→ DOF → Motion Blur → Color Grading（ACES+LUT）→ 风格化（色差/暗角/颗粒）→ 输出

## 代码对照

```csharp
// 电影级后处理管线 — 多效果串联
public class CinematicPostProcessing : MonoBehaviour {
    public Material ssaoMaterial;
    public Material bloomMaterial;
    public Material dofMaterial;
    public Material colorGradingMaterial;
    public Material stylizeMaterial;

    void OnRenderImage(RenderTexture src, RenderTexture dest) {
        // 获取两个临时 RT 交替使用
        RenderTexture rt1 = RenderTexture.GetTemporary(src.width, src.height, 0);
        RenderTexture rt2 = RenderTexture.GetTemporary(src.width, src.height, 0);

        // 1. SSAO
        Graphics.Blit(src, rt1, ssaoMaterial);
        // 2. Bloom (内部多 Pass 降采样-上采样)
        Graphics.Blit(rt1, rt2, bloomMaterial);
        // 3. DOF
        Graphics.Blit(rt2, rt1, dofMaterial);
        // 4. Color Grading (ACES + LUT)
        Graphics.Blit(rt1, rt2, colorGradingMaterial);
        // 5. 风格化 (色差/暗角/颗粒)
        Graphics.Blit(rt2, dest, stylizeMaterial);

        RenderTexture.ReleaseTemporary(rt1);
        RenderTexture.ReleaseTemporary(rt2);
    }
}
```

```hlsl
// ACES 色调映射 — 管线最终输出前
float3 ACESFilm(float3 x) {
    return saturate((x * (2.51 * x + 0.03)) / (x * (2.43 * x + 0.59) + 0.14));
}

fixed4 fragColorGrading(v2f_img i) : SV_Target {
    fixed4 col = tex2D(_MainTex, i.uv);
    col.rgb = ACESFilm(col.rgb);       // HDR → LDR
    col.rgb = applyLUT(col.rgb);       // LUT 风格化
    col.rgb = applyVignette(col.rgb, i.uv); // 暗角
    return col;
}
```

电影级管线按 SSAO→SSR→Bloom→DOF→MotionBlur→ColorGrading→风格化 顺序串联，每步用 Blit 传递中间结果。

## 常见误区

<Callout type="trap">
**现象 →** 后处理管线顺序不对导致效果互相干扰。
**原因 →** 效果之间的依赖关系没有考虑。
**修法 →** SSAO 应在 Bloom 之前（遮蔽影响光照）。Color Grading 在最后（色调映射需要 HDR 输入）。Bloom 在 DOF 之前（先辉光再虚化）。Motion Blur 在 Color Grading 之前。遵循光照→特效→调色的顺序。
</Callout>

<Callout type="trap">
**现象 →** 后处理管线性能太差无法实时运行。
**原因 →** 效果太多且全分辨率处理。
**修法 →** 降分辨率处理（SSAO/Bloom/DOF 可半分辨率）。合并简单效果到一个 Pass。RT 池化避免 GC。移动端减少效果数量。Profiler 定位最贵 Pass 优先优化。考虑 URP 的原生后处理优化。
</Callout>
