## 从输入到结果的数据链

本章主链是：采样输入 → FixedUpdate → 施力速度 → 碰撞射线 → 接地判定 → 平台结果。每个节点保存切片ID、帧号、对象ID和状态版本。表现系统只能呈现玩法事实，资源与数据系统必须通过租约或快照管理生命周期。

```csharp
void FixedUpdate()
{
    body.AddForce(moveIntent * acceleration, ForceMode.Acceleration);
    bool grounded = Physics2D.OverlapBox(feet.position, feetSize, 0f, groundMask);
    if (jumpQueued && grounded) body.AddForce(Vector2.up * jumpImpulse, ForceMode2D.Impulse);
}
```
