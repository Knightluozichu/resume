## 从输入到结果的数据链

本章主链是：游戏事件 → 音频路由 → 剪辑选择 → 空间参数 → 混合播放 → 结束回收。每个节点保存切片ID、帧号、对象ID和状态版本。表现系统只能呈现玩法事实，资源与数据系统必须通过租约或快照管理生命周期。

```csharp
public void PlaySfx(AudioCue cue, Vector3 position)
{
    if (!limiter.TryAcquire(cue.Id)) return;
    AudioSource source = pool.Get();
    cue.Configure(source, position, settings.SfxVolume);
    source.Play();
}
```

旧输入API、Text、AssetBundle或LitJSON可以迁移到Input System、TextMeshPro、Addressables或System.Text.Json，但迁移账本必须写明原书问题、替代实现、保留不变量和对照证据。
