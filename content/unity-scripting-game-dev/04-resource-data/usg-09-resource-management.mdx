## 从输入到结果的数据链

本章主链是：GUID引用 → 构建依赖 → 内容清单 → 网络下载 → 加载实例 → 引用释放。每个节点保存切片ID、帧号、对象ID和状态版本。表现系统只能呈现玩法事实，资源与数据系统必须通过租约或快照管理生命周期。

```csharp
async Task<AssetLease<T>> LoadAsync<T>(AssetKey key) where T : Object
{
    ManifestEntry entry = manifest.Require(key);
    await dependencies.AcquireAsync(entry.Dependencies);
    T asset = await bundles.LoadAsync<T>(entry.Bundle, entry.AssetName);
    return new AssetLease<T>(asset, () => Release(entry));
}
```

旧输入API、Text、AssetBundle或LitJSON可以迁移到Input System、TextMeshPro、Addressables或System.Text.Json，但迁移账本必须写明原书问题、替代实现、保留不变量和对照证据。
