## 核心模型与行为不变量

AI先从感知层生成快照，再由FSM选择巡逻、警戒、追击或攻击，导航代理执行路径。视野必须同时满足距离、方向和遮挡，导航障碍与链接则决定路径可达性。

## 从输入到结果的数据链

本章主链是：采样目标 → 视锥遮挡 → 状态转换 → 路径规划 → 动作执行 → 结果反馈。每个节点保存切片ID、帧号、对象ID和状态版本。表现系统只能呈现玩法事实，资源与数据系统必须通过租约或快照管理生命周期。

```csharp
bool CanSee(Target target)
{
    Vector3 delta = target.Eye - eye.position;
    if (delta.sqrMagnitude > viewRange * viewRange) return false;
    if (Vector3.Dot(eye.forward, delta.normalized) < viewCos) return false;
    return !Physics.Raycast(eye.position, delta.normalized, delta.magnitude, obstacleMask);
}
```
