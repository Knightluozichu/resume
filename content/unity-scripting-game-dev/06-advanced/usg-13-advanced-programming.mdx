## 从输入到结果的数据链

本章主链是：Profiler证据 → 池键租用 → 对象重置 → 迭代器挂起 → 事件发布 → 释放验收。每个节点保存切片ID、帧号、对象ID和状态版本。表现系统只能呈现玩法事实，资源与数据系统必须通过租约或快照管理生命周期。

```csharp
public PooledLease<T> Rent<T>(PoolKey key) where T : Component, IPoolable
{
    T item = pools[key].Take<T>();
    item.OnRent();
    return new PooledLease<T>(item, () => ReturnOnce(key, item));
}
```

旧输入API、Text、AssetBundle或LitJSON可以迁移到Input System、TextMeshPro、Addressables或System.Text.Json，但迁移账本必须写明原书问题、替代实现、保留不变量和对照证据。
