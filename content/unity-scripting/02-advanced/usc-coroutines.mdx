## 直觉引入

协程像在书里夹书签。你读到一半（yield），放下书做别的事，等条件满足后翻到书签页继续读。协程把一段逻辑拆成多帧执行——不用回调地狱，代码看起来是线性的。StartCoroutine 启动，yield return 暂停，条件满足后自动恢复。注意：协程仍在主线程，不是多线程。

## 概念讲解

### 协程机制

<UscCoroutinesDiagram />

<Term def="协程(Coroutine)是Unity的跨帧异步执行机制，用IEnumerator迭代器实现，yield指令控制暂停和恢复">协程</Term>是跨帧执行利器。

<Term def="yield return是协程的暂停指令，返回值决定何时恢复——null等一帧，WaitForSeconds等秒数，WaitForEndOfFrame等帧末">yield return</Term>控制恢复时机。

<Term def="StartCoroutine启动协程，返回Coroutine引用用于StopCoroutine；对象禁用时协程自动停止">StartCoroutine</Term>启动协程。

<Term def="WaitForSeconds延迟恢复的yield指令，受Time.timeScale影响；WaitForSecondsRealtime不受timeScale影响">WaitForSeconds</Term>是延迟指令。

## 代码对照

```csharp
// 基本协程
IEnumerator DelayedAction() {
    Debug.Log("开始");
    yield return new WaitForSeconds(2f); // 等2秒
    Debug.Log("2秒后执行");
}

void Start() {
    StartCoroutine(DelayedAction());
}

// 技能释放序列
IEnumerator CastSkill() {
    // 前摇
    _animator.SetTrigger("Cast");
    yield return new WaitForSeconds(1f);

    // 伤害判定
    var enemies = Physics.OverlapSphere(transform.position, 5f, _enemyLayer);
    foreach (var e in enemies) e.GetComponent<Health>()?.TakeDamage(50);

    // 后摇
    yield return new WaitForSeconds(0.5f);

    // 冷却
    _isCooling = true;
    yield return new WaitForSeconds(5f);
    _isCooling = false;
}

// 生命周期管理
void OnEnable() { StartCoroutine(MainRoutine()); }
void OnDisable() { StopAllCoroutines(); }

// 嵌套协程
IEnumerator ParentRoutine() {
    yield return StartCoroutine(ChildRoutine()); // 等子协程完成
    Debug.Log("子协程完成后继续");
}
```

## 常见误区

<Callout type="trap">
**误区：认为协程是多线程，在协程中做 CPU 密集计算。**
协程在主线程执行——yield 时挂起让出 CPU，恢复后继续执行。如果在协程中做大量计算（如路径搜索、大量物理检测），会卡住主线程导致掉帧。协程只是把逻辑分摊到多帧，不是并行计算。CPU 密集任务应该用 Unity Job System（多线程）或 C# Task.Run。协程适合 IO 等待（延迟、加载、动画序列）而非计算。
</Callout>

<Callout type="trap">
**误区：StopCoroutine 传入了不同的 IEnumerator 实例，导致无法停止协程。**
StartCoroutine(MyRoutine()) 启动的协程，用 StopCoroutine(MyRoutine()) 无法停止——因为两次 MyRoutine() 创建了不同的 IEnumerator 实例。正确做法：1)用返回值——Coroutine c = StartCoroutine(MyRoutine()); StopCoroutine(c);；2)用方法名——StopCoroutine("MyRoutine")（字符串方式，不推荐）；3)StopAllCoroutines() 停止所有。最佳实践：缓存 Coroutine 引用。
</Callout>

<Exercises>
**问题 1**：协程和多线程有什么区别？

<Answer>
协程在主线程执行，yield 时挂起让出 CPU，恢复后继续。同一时刻只有一个协程在执行，不涉及线程切换，无锁无竞态。但 CPU 密集计算仍阻塞主线程。多线程可以真正并行（利用多核），但需要处理线程安全（锁/原子操作/竞态条件）。协程适合 IO 等待（延迟、异步加载、动画序列），多线程适合 CPU 密集计算（路径搜索、大规模数据处理）。Unity 中协程用于轻量异步，Job System 用于多线程并行。
</Answer>

**问题 2**：用协程实现一个技能释放：前摇1秒→伤害→后摇0.5秒→冷却5秒。

<Answer>
IEnumerator CastSkill() { 1)前摇：播放动画，yield return new WaitForSeconds(1f)；2)伤害：OverlapSphere 检测范围敌人，调用 TakeDamage；3)后摇：yield return new WaitForSeconds(0.5f)；4)冷却：_isCooling=true，yield return new WaitForSeconds(5f)，_isCooling=false。释放入口 if(!_isCooling) StartCoroutine(CastSkill())。可打断：协程中检查 _interrupted 标志，yield break 退出。OnDisable 中 StopAllCoroutines 确保干净停止。协程让时序逻辑线性化，避免嵌套回调。
</Answer>
</Exercises>
