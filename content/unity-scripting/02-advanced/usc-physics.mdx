## 直觉引入

物理系统让游戏世界有「重量」和「碰撞」。Rigidbody 是物体的「体重和惯性」——受重力、被力推动。Collider 是物体的「形状」——决定碰撞范围。碰撞事件（OnCollision）像两车相撞——有物理阻挡。触发事件（OnTrigger）像走进感应门——无阻挡但被检测到。射线检测（Raycast）像激光扫描——从一点射出射线看碰到了什么。

### 物理系统组成

<Term def="Rigidbody是赋予GameObject物理属性的组件，提供质量、阻力、重力，接收AddForce等物理力">Rigidbody</Term>提供物理动力学。

## 交互Demo

<Stepper>
<Step title="第一步：Rigidbody 与 Collider">Rigidbody 提供物理动力学（质量/重力/力），Collider 提供碰撞范围（形状）。要产生物理碰撞，双方都需要 Collider，至少一方需要非 Kinematic 的 Rigidbody。isKinematic=true 的对象不受力但可被代码移动并推动其他对象。</Step>
<Step title="第二步：碰撞与触发">
碰撞（isTrigger=false）：物理阻挡 + OnCollisionEnter 回调，参数 Collision 含接触点和冲量。触发（isTrigger=true）：无阻挡（穿透）+ OnTriggerEnter 回调，参数是对方 Collider。选择：需要物理碰撞用 Collision，只需检测进入区域用 Trigger（如拾取物品、进入触发区）。

</Step>

## 代码对照

```csharp
// 物理移动（FixedUpdate 中）
void FixedUpdate() {
    _rb.MovePosition(transform.position + moveDir * speed * Time.fixedDeltaTime);
    // 或 _rb.AddForce(moveDir * force, ForceMode.Impulse);
}

// 碰撞事件（物理阻挡）
void OnCollisionEnter(Collision other) {
    if (other.gameObject.CompareTag("Enemy")) {
        ContactPoint contact = other.contacts[0];
        Debug.Log("碰撞点: " + contact.point);
    }
}

// 触发事件（无阻挡）
void OnTriggerEnter(Collider other) {
    if (other.CompareTag("Pickup")) {
        CollectItem(other.gameObject);
    }
}

// 射线检测
void Update() {
    Ray ray = Camera.main.ScreenPointToRay(Input.mousePosition);
    if (Physics.Raycast(ray, out RaycastHit hit, 100f, LayerMask.GetMask("Ground"))) {
        Debug.Log("点击地面: " + hit.point);
    }
}

// 范围检测（近战攻击）
Collider[] enemies = Physics.OverlapSphere(attackPos, radius, LayerMask.GetMask("Enemy"));
foreach (var enemy in enemies) {
    enemy.GetComponent<Health>()?.TakeDamage(damage);
}
```

## 常见误区

<Callout type="trap">
**误区：在 Update 中用 AddForce 或修改 Rigidbody.velocity 做物理移动。**
Update 帧率波动，在 Update 中施力会导致物理模拟不稳定——帧率高时力多帧低时力少，表现为角色抖动或穿透。物理操作必须放 FixedUpdate（固定时间步），用 Time.fixedDeltaTime 计算。移动用 Rigidbody.MovePosition（Kinematic）或 AddForce（动力学），不要直接修改 transform.position（绕过物理引擎，碰撞检测会失效）。
</Callout>

<Callout type="trap">
**误区：用 OnCollisionEnter 检测高速子弹的碰撞。**
物理引擎按固定时间步更新，如果子弹速度足够快，一帧内可能从一个位置「跳」到另一个位置，中间的碰撞体被穿透（Tunneling）。解决方案：1)用射线检测 Physics.Raycast（从上一帧位置到当前位置射一条线）；2)用 Rigidbody.Continuous Collision Detection（连续碰撞检测）；3)用 Physics.SphereCast（球形射线）。不要用默认的 Discrete 碰撞检测模式处理高速物体。
</Callout>

<Exercises>
**问题 1**：OnCollisionEnter 和 OnTriggerEnter 的触发条件有什么区别？

<Answer>
OnCollisionEnter：双方都有 Collider（isTrigger=false），至少一方有非 Kinematic 的 Rigidbody。产生物理阻挡，参数是 Collision（含接触点/冲量）。OnTriggerEnter：双方都有 Collider（至少一方 isTrigger=true），至少一方有 Rigidbody（可以是 Kinematic）。无物理阻挡（穿透），参数是对方 Collider 引用。选择：需要物理碰撞用 Collision（如角色撞墙），只需检测进入区域用 Trigger（如拾取物品、进入传送门）。
</Answer>

**问题 2**：为什么物理操作要放 FixedUpdate 而非 Update？

<Answer>
FixedUpdate 按固定时间步（默认 0.02s）调用，物理引擎在此间隔内更新，保证模拟稳定。Update 每帧调用，帧率波动时物理力不均匀——帧率高时力多次施加（角色加速），帧率低时力少次施加（角色减速），导致物理行为不一致甚至穿透。物理力（AddForce）和移动（MovePosition）放 FixedUpdate，用 Time.fixedDeltaTime 计算位移。Time.deltaTime 在 Update 中用（帧间插值），Time.fixedDeltaTime 在 FixedUpdate 中用（固定步长）。
</Answer>
</Exercises>
