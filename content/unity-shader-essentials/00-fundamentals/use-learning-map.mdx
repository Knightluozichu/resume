## 直觉引入

想象你要给一个3D模型「上色」。在Unity中，这件事由Shader完成——它是一段GPU程序，决定每个像素的最终颜色。Unity Shader 入门精要就是教你写Shader的教程，从最基础的渲染管线概念，到ShaderLab语法，再到光照模型、透明效果、后处理，最终到高级技术。

全书的核心线索是：先理解渲染管线怎么跑（基础），再学会用ShaderLab编写Shader（语法），然后掌握光照计算（核心），最后追求各种视觉效果（高级）。

## 代码对照

```hlsl
// Unity Shader 的核心：顶点+片元
Shader "Custom/Simple" {
    Properties { _Color ("Color", Color) = (1,1,1,1) }
    SubShader {
        Pass {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            
            float4 _Color;
            
            float4 vert(float4 v : POSITION) : SV_POSITION {
                return UnityObjectToClipPos(v);
            }
            
            float4 frag() : SV_Target {
                return _Color;
            }
            ENDCG
        }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：把Shader当CPU代码写。**
Shader运行在GPU上，没有调试器逐步执行，没有print输出。调试靠颜色输出（把变量值映射成颜色）和帧调试器（Frame Debugger）。思维方式也不同——Shader是并行的，每个顶点/像素独立计算，不能依赖其他顶点/像素的结果。
</Callout>

<Callout type="trap">
**误区：跳过数学基础直接写Shader。**
Shader核心是空间变换和光照计算，都依赖线性代数——矩阵乘法、点积叉积、坐标系转换。跳过数学基础，后面的MVP矩阵和光照模型公式都看不懂。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？它们之间是什么关系？

<Answer>
基础管线、ShaderLab语法、光照与效果、高级技术。呈递进关系：基础管线提供架构认知，ShaderLab语法是编写工具，光照与效果是核心内容，高级技术是进阶应用。每一层都建立在前一层之上——不懂管线无法理解Shader运行环境，不懂语法无法编写Shader，不懂光照无法实现真实效果。
</Answer>

**问题 2**：为什么说「Shader是并行程序」？这对编程思维有什么影响？

<Answer>
GPU同时处理数千个顶点/像素，每个顶点/像素的Shader代码独立执行。这意味着：1）不能依赖其他顶点/像素的中间结果（无全局通信）；2）分支(if/else)效率低——不同像素走不同分支时GPU需同时执行所有分支；3）数据局部性重要——相邻像素访问相同纹理时缓存友好。编程思维从CPU的串行思维转为GPU的数据并行思维——思考「对每个像素做什么」而非「按什么顺序处理」。
</Answer>
</Exercises>
