## 直觉引入

想象一条流水线。原材料（3D模型数据）从一头进入，经过一系列加工站（顶点处理、光栅化、片元处理），最终从另一头产出成品（屏幕上的像素）。每个加工站就是渲染管线的一个阶段，Shader是其中可编程的工位。

顶点着色器是第一个工位——把3D顶点变换到屏幕空间。光栅化是中间工位——把三角形「填」成像素。片元着色器是最后一个工位——决定每个像素的颜色。

## 概念讲解

### 渲染管线流程

<Term def="顶点着色器(Vertex Shader)对每个顶点执行，主要职责是空间变换（模型空间->裁剪空间）">顶点着色器</Term>是管线的第一个可编程阶段。

<Term def="MVP矩阵是Model-View-Projection三个变换矩阵的乘积，将顶点从模型空间变换到裁剪空间">MVP矩阵</Term>是顶点着色器的核心计算。

## 代码对照

```hlsl
// Unity 渲染管线核心流程
// 顶点着色器: MVP变换
v2f vert(appdata v) {
    v2f o;
    o.pos = UnityObjectToClipPos(v.vertex);  // MVP变换
    o.uv = v.uv;
    o.normal = UnityObjectToWorldNormal(v.normal);
    return o;
}

// 片元着色器: 计算颜色
fixed4 frag(v2f i) : SV_Target {
    fixed4 col = tex2D(_MainTex, i.uv);  // 采样纹理
    col.rgb *= _Color.rgb;               // 乘以颜色
    return col;
}
```

## 常见误区

<Callout type="trap">
**误区：混淆模型空间、世界空间、视图空间、裁剪空间。**
模型空间是顶点相对于模型原点的坐标。世界空间是相对于场景原点的坐标（经Model变换）。视图空间是相对于相机的坐标（经View变换）。裁剪空间是投影后的坐标（经Projection变换）。四个空间是递进变换关系，搞混会导致顶点出现在错误位置。
</Callout>

<Callout type="trap">
**误区：认为片元就是像素。**
片元是像素的候选者——一个像素可能有多个片元（如透明物体重叠），最终通过深度测试和混合决定哪个片元的颜色写入帧缓冲。片元比像素携带更多信息（深度、模板值等）。
</Callout>

<Exercises>
**问题 1**：MVP矩阵的三个变换分别是什么？各做什么？

<Answer>
光栅化将三角形图元转换为片元——决定屏幕上哪些像素被三角形覆盖。对每个被覆盖的像素生成一个片元。顶点属性（UV、法线、颜色等）通过插值传递到片元：三角形三个顶点的属性在三角形内部按重心坐标线性插值。例如三角形一个顶点UV是(0,0)，另一个是(1,1)，中间像素的UV就是插值结果(0.5,0.5)。透视投影下插值需要透视校正（perspective-correct interpolation）。
</Answer>

**问题 2**：为什么片元不等于像素？它们的关系是什么？

<Answer>
片元是像素的候选者。一个屏幕像素可能对应多个片元——当多个三角形重叠（如透明物体层叠）时，每个三角形在该像素位置生成一个片元。片元经过深度测试（只有最前面的通过）、模板测试、混合（Blending）后，才决定最终写入帧缓冲的颜色。所以片元是「待决定的像素」，经过管线后处理才变成最终的像素值。片元携带深度、模板等额外信息用于这些测试。
</Answer>
</Exercises>
