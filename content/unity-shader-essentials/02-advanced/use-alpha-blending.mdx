## 直觉引入

想象一扇玻璃窗。你能透过玻璃看到后面的东西——玻璃是透明的。在Shader中实现透明有两种方式：Alpha Test像剪纸——不透明的地方保留，透明的地方直接丢弃；Alpha Blending像调色——把当前颜色和背景颜色按比例混合。

Alpha Test简单高效但不支持半透明（要么有要么没有）。Alpha Blending支持半透明但需要排序（从后往前渲染才能正确混合）。

## 交互Demo

<Stepper>
<Step title="第一步：Alpha Test">clip(alpha - threshold)：alpha小于阈值时丢弃片元。适合树叶、铁丝网等全透全不透的物体。不需要排序，不影响深度缓冲。但边缘有锯齿（硬边）。</Step>
<Step title="第二步：Alpha Blending">
Blend SrcAlpha OneMinusSrcAlpha：当前颜色乘以alpha，背景颜色乘以(1-alpha)，相加得到混合结果。支持半透明但需关闭深度写入(避免遮挡后面的透明物体)且需从后往前渲染。
<UseAlphaBlendingDiagram />
</Step>
<Step title="第三步：混合模式">不同混合因子实现不同效果：正常透明(ScrAlpha,1-ScrAlpha)、加法发光(One,One)、乘法变暗(DstColor,Zero)。选择取决于视觉效果需求。</Step>
</Stepper>

## 代码对照

```hlsl
// Alpha Test: 硬边透明
fixed4 frag(v2f i) : SV_Target {
    fixed4 col = tex2D(_MainTex, i.uv);
    clip(col.a - _Cutoff);  // alpha < _Cutoff 的片元丢弃
    return col;
}

// Alpha Blending: 半透明混合
// ShaderLab中设置:
// Tags { "Queue"="Transparent" }
// Blend SrcAlpha OneMinusSrcAlpha
// ZWrite Off  // 关闭深度写入

fixed4 frag(v2f i) : SV_Target {
    fixed4 col = tex2D(_MainTex, i.uv);
    col.rgb *= _Color.rgb;
    col.a *= _Color.a;  // 控制透明度
    return col;
    // GPU自动混合: result = col.rgb*col.a + bg.rgb*(1-col.a)
}
```

## 常见误区

<Callout type="trap">
**误区：Alpha Blending时忘记关闭深度写入。**
半透明混合需要从后往前渲染——先画后面的透明物体，再画前面的叠加混合。如果不排序，前面物体先画写入颜色，后面物体再画时混合的是空背景而非前面物体，结果错误。
</Callout>

<Callout type="trap">
**误区：认为Alpha Blending不需要排序。**
Alpha Blending的混合公式 result = src*alpha + dst*(1-alpha) 依赖渲染顺序——后面的物体先画(dst正确），前面物体后画叠加(src混合到正确的dst）。不排序会导致混合结果错误。Alpha Test不需要排序因为它是丢弃而非混合，丢弃的片元不写入颜色和深度，不丢弃的片元正常写入深度。
</Callout>

<Exercises>
**问题 1**：Alpha Test和Alpha Blending的区别是什么？

<Answer>
Alpha Blending公式 result = src*alpha + dst*(1-alpha)，dst是帧缓冲当前值。如果先画前面的透明物体（src），dst是空背景。再画后面的透明物体时，它的dst是前面物体的颜色，混合结果错误（后面物体叠加到了前面物体上）。正确顺序是先画后面的(dst=背景），再画前面的(src混合到正确的dst=后面物体+背景）。所以需要按深度从后往前排序。
</Answer>

**问题 2**：为什么透明物体需要从后往前渲染？

<Answer>
Alpha Blending公式 result=src*alpha+dst*(1-alpha)，dst是帧缓冲当前值。必须先画后面的(dst=背景正确），再画前面的(src混合到正确dst）。如果先画前面，dst=空背景，再画后面时dst=前面颜色，混合错误。所以需要按深度从后往前排序。Alpha Test不需要排序因为丢弃的片元不参与混合。
</Answer>
</Exercises>

<GlossaryItem term='Alpha Blending'>用Blend命令混合当前颜色和帧缓冲颜色，支持半透明，需关闭深度写入和排序。</GlossaryItem>
