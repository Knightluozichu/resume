## 直觉引入

想象你给场景拍了一张「深度照片」——每个像素不存颜色，存「这个点离相机多远」。这就是深度纹理。再拍一张「法线照片」——每个像素存「这个面朝哪个方向」。这就是法线纹理。

这两个「特殊照片」是屏幕空间效果的数据基础。有了深度，你可以做雾、景深、轮廓描边；有了法线，你可以做屏幕空间反射、边缘检测、SSAO。它们把3D信息编码到2D图像中，让后处理Shader能访问场景几何信息。

## 概念讲解

### 深度与法线纹理

<UseDepthNormalDiagram />

<Term def="深度纹理(Depth Texture)存储每个像素的深度值(裁剪空间Z值)，用于后处理效果">深度纹理</Term>通过ReplaceShader或内置命令生成。

<Term def="法线纹理(Normal Texture)存储每个像素的法线方向(世界空间或观察空间)">法线纹理</Term>与深度纹理可合并为深度+法线纹理。

<Term def="深度重建世界位置通过深度值和逆VP矩阵，从屏幕坐标反推世界空间坐标">深度重建位置</Term>是许多屏幕空间效果的核心步骤。

<Term def="CameraDepthMode设置相机渲染深度纹理的模式(Depth/DepthNormals)">CameraDepthMode</Term>控制Unity生成哪种深度纹理。

## 代码对照

```hlsl
// 深度纹理采样与位置重建

// 1. 采样深度纹理
float depth = SAMPLE_DEPTH_TEXTURE(_CameraDepthTexture, i.uv);
// 线性化深度
float linearDepth = Linear01Depth(depth);

// 2. 重建世界空间位置
float4 clipPos = float4(i.uv * 2 - 1, depth, 1);  // NDC坐标
clipPos.y *= _ProjectionParams.x;  // 处理平台翻转
float4 worldPos = mul(unity_MatrixInvVP, clipPos);
worldPos /= worldPos.w;

// 3. 法线纹理采样
float3 normal = DecodeViewNormalStereo(
    tex2D(_CameraDepthNormalsTexture, i.uv)
);

// 4. 用途: 边缘检测
float depthDiff = abs(depth - depthRight);
float normalDiff = abs(dot(normal, normalRight));
if (depthDiff > threshold || normalDiff < threshold)
    return edgeColor;  // 边缘
```

## 常见误区

<Callout type="trap">
**误区：直接使用非线性深度值做计算。**
不同图形API(DirectX/OpenGL/Vulkan)的UV.y方向不同，DirectX翻转Y轴。重建位置时clipPos.y需要乘以_ProjectionParams.x处理翻转。
</Callout>

<Callout type="trap">
**误区：忘记处理平台差异(翻转Y轴)。**
不同图形API的UV.y方向不同——DirectX的纹理原点在左上(Y向下)，OpenGL在左下(Y向上)。重建位置时NDC坐标的Y需要乘以_ProjectionParams.x(+1或-1)处理平台翻转。忘记处理会导致在不同平台渲染结果不同。Unity通常通过UNITY_UV_STARTS_AT_TOP宏处理。
</Callout>

<Exercises>
**问题 1**：深度纹理存储的是什么数据？为什么需要线性化？

<Answer>
步骤：1)采样深度纹理得到depth(非线性)；2)构建NDC坐标clipPos=float4(uv*2-1, depth, 1)（注意Y轴平台翻转）；3)用逆VP矩阵变换mul(unity_MatrixInvVP, clipPos)得到齐次坐标；4)除以w分量得到世界空间位置worldPos。这个位置可以用于屏幕空间雾、SSR反射等效果——知道每个像素的3D位置就能做3D计算。
</Answer>

**问题 2**：如何用深度纹理重建世界空间位置？

<Answer>
重建步骤：1)采样深度纹理得depth；2)构建NDC坐标float4(uv*2-1, depth, 1)；3)Y轴翻转处理clipPos.y*=_ProjectionParams.x；4)用逆VP矩阵mul(unity_MatrixInvVP, clipPos)变换；5)除以w得worldPos。用途：屏幕空间雾、SSR、SSAO等需要像素3D位置的效果。
</Answer>
</Exercises>
