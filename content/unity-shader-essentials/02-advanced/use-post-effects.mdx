## 直觉引入

想象你在PS里修照片——调亮度、加滤镜、做模糊。Unity的后处理就是「GPU版的PS修图」——先把场景渲染到一张纹理，再用Shader对这张纹理做处理，输出到屏幕。

后处理的魅力在于它作用于整个画面——一个简单的Shader就能改变整个场景的氛围。亮度调整、色彩校正、模糊、泛光、描边……所有「整体画面效果」都是后处理实现的。

## 概念讲解

### 后处理原理与实现

<UsePostEffectsDiagram />

<Term def="后处理(Post-Processing)将场景渲染到纹理后用Shader处理，再输出到屏幕的技术">后处理</Term>是画面级效果的实现方式。

<Term def="OnRenderImage是MonoBehaviour的回调，在所有渲染完成后调用，用于实现后处理">OnRenderImage</Term>是C#后处理入口。

<Term def="Graphics.Blit将源纹理用材质(Shader)处理后复制到目标纹理">Graphics.Blit</Term>是后处理的核心API。

<Term def="CommandBuffer允许在不写C#脚本的情况下用命令缓冲区实现后处理">CommandBuffer</Term>是更灵活的后处理实现方式。

## 交互Demo

<Stepper>
<Step title="第一步：基本原理">后处理 = 渲染场景到RT(RenderTexture) -> 用Shader处理RT -> 输出到屏幕。C#端用OnRenderImage+Graphics.Blit，Shader端写片元着色器处理全屏四边形。</Step>
<Step title="第二步：简单效果">
亮度=rgb*brightness，对比度=(rgb-0.5)*contrast+0.5，饱和度=mix(gray,rgb,saturation)。这三个调整是最基础的后处理，一个Shader即可完成。
<UsePostEffectsDiagram />
</Step>
<Step title="第三步：复杂效果">泛光(Bloom)=亮度提取->高斯模糊->叠加。描边=深度/法线边缘检测。运动模糊=速度缓冲混合。复杂效果通常需要多Pass(多次Blit)和中间纹理。</Step>

## 代码对照

```csharp
// C# 后处理脚本
public class PostEffect : MonoBehaviour {
    public Material postMaterial;
    
    void OnRenderImage(RenderTexture src, RenderTexture dst) {
        Graphics.Blit(src, dst, postMaterial);
    }
}
```

```hlsl
// 亮度/对比度/饱和度后处理Shader
fixed4 frag(v2f i) : SV_Target {
    fixed4 col = tex2D(_MainTex, i.uv);
    
    // 亮度
    col.rgb *= _Brightness;
    
    // 对比度
    col.rgb = (col.rgb - 0.5) * _Contrast + 0.5;
    
    // 饱和度
    float gray = dot(col.rgb, float3(0.299, 0.587, 0.114));
    col.rgb = lerp(gray, col.rgb, _Saturation);
    
    return col;
}
```

## 常见误区

<Callout type="trap">
**误区：后处理中忘记处理平台UV翻转。**
高斯模糊是后处理中最重的操作之一——多Pass模糊每Pass都读+写全屏纹理。在移动端尤其昂贵。能用低分辨率模糊的降分辨率，能用分离模糊的不用全模糊。
</Callout>

<Callout type="trap">
**误区：后处理滥用高斯模糊。**
高斯模糊是多Pass操作——每个Pass读全屏纹理+写全屏纹理，开销与分辨率成正比。移动端1080p的一次模糊可能消耗2-3ms。优化：1)降分辨率模糊(先缩到1/4再模糊再放大)；2)用分离模糊(水平+垂直两次1D替代一次2D，O(n) vs O(n²))；3)用Kawase模糊等近似算法。
</Callout>

<Exercises>
**问题 1**：后处理的基本原理是什么？亮度、对比度、饱和度的调整公式是什么？

<Answer>
后处理 = 场景渲染到RenderTexture -> 用后处理Shader对RT做全屏处理 -> 输出到屏幕。C#端用OnRenderImage回调+Graphics.Blit(src,dst,material)。亮度：rgb *= brightness。对比度：(rgb-0.5)*contrast+0.5。饱和度：gray=dot(rgb,(0.299,0.587,0.114))，lerp(gray,rgb,saturation)。三个调整可叠加在一个Shader中完成。
</Answer>

**问题 2**：后处理的性能开销在哪里？如何优化？

<Answer>
开销在：1)全屏纹理读写——每个Pass读+写整个屏幕，开销与分辨率成正比；2)多Pass效果——Bloom需4-6次Blit，每次都是全屏操作；3)模糊操作——高斯模糊是计算密集型。优化：1)降分辨率——中间纹理用1/2或1/4分辨率；2)分离模糊——水平+垂直两次1D替代一次2D(O(n) vs O(n*n))；3)减少Pass——合并可在一个Shader中完成的效果；4)移动端用简化算法——Kawase模糊替代高斯。后处理在移动端通常占帧时间的20-40%。
</Answer>
</Exercises>
