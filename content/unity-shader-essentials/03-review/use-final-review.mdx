## 直觉引入

想象你要写一个有光照、有透明、有后处理的完整Shader。你需要：理解渲染管线（顶点怎么变到像素）-> 用ShaderLab搭建结构（Properties/SubShader/Pass）-> 写顶点片元着色器（MVP变换+光照计算）-> 加透明效果（Alpha Test/Blending）-> 用深度法线纹理做屏幕效果 -> 最后用后处理提升画面。

总复习就是把这个完整流程走一遍，把每一步对应的知识点串联起来。

## 代码对照

```hlsl
// 完整Shader: 光照+透明+纹理
Shader "Custom/Complete" {
    Properties {
        _Color ("Color", Color) = (1,1,1,1)
        _MainTex ("Albedo", 2D) = "white" {}
        _Gloss ("Gloss", Range(0,1)) = 0.5
        _Alpha ("Alpha", Range(0,1)) = 1.0
    }
    SubShader {
        Tags { "Queue"="Transparent" "RenderType"="Transparent" }
        Blend SrcAlpha OneMinusSrcAlpha
        ZWrite Off
        Pass {
            Tags { "LightMode"="ForwardBase" }
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"
            #include "Lighting.cginc"
            
            struct appdata { float4 vertex:POSITION; float2 uv:TEXCOORD0; float3 normal:NORMAL; };
            struct v2f { float4 pos:SV_POSITION; float2 uv:TEXCOORD0; float3 worldNormal:TEXCOORD1; float3 worldPos:TEXCOORD2; };
            
            sampler2D _MainTex; float4 _MainTex_ST;
            fixed4 _Color; float _Gloss; float _Alpha;
            
            v2f vert(appdata v) {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = TRANSFORM_TEX(v.uv, _MainTex);
                o.worldNormal = UnityObjectToWorldNormal(v.normal);
                o.worldPos = mul(unity_ObjectToWorld, v.vertex).xyz;
                return o;
            }
            
            fixed4 frag(v2f i) : SV_Target {
                fixed4 col = tex2D(_MainTex, i.uv) * _Color;
                float3 N = normalize(i.worldNormal);
                float3 L = normalize(_WorldSpaceLightPos0.xyz);
                float3 V = normalize(_WorldSpaceCameraPos - i.worldPos);
                float3 H = normalize(L + V);
                float3 ambient = UNITY_LIGHTMODEL_AMBIENT.rgb * col.rgb;
                float3 diffuse = _LightColor0.rgb * col.rgb * max(0,dot(N,L));
                float3 specular = _LightColor0.rgb * pow(max(0,dot(N,H)), _Gloss*100);
                col.rgb = ambient + diffuse + specular;
                col.a *= _Alpha;
                return col;
            }
            ENDCG
        }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：孤立学习各章不串联。**
Shader是实践性极强的技术——每个概念都需要在Unity中编写、编译、运行、观察效果。只看语法不写Shader，就像只看游泳教材不下水。
</Callout>

<Callout type="trap">
**误区：只学语法不练效果。**
Shader是实践性技术——每个概念都需在Unity中编写运行观察效果。建议每章学完后动手实现对应Shader：学完光照写一个Blinn-Phong，学完透明写一个半透明窗口，学完后处理写一个亮度调整。只看语法不写代码无法理解Shader的运行时行为。
</Callout>

<Exercises>
**问题 1**：用「一个Shader的编写流程」串联全书四大板块。

<Answer>
1)Shader编写：ShaderLab结构：Queue=Transparent+Blend SrcAlpha OneMinusSrcAlpha+ZWrite Off。顶点着色器：MVP变换+传递世界法线和世界位置。片元着色器：tex2D采样玻璃纹理，计算Blinn-Phong光照(环境+漫反射+镜面)，alpha控制透明度。2)边缘描边：后处理Shader采样深度纹理和法线纹理，计算深度差和法线差，超过阈值的像素描边色。3)Bloom泛光：后处理Shader提取亮度阈值以上的区域，高斯模糊降采样，叠加回原图。4)渲染顺序：先渲染不透明物体->渲染透明玻璃(Queue=Transparent)->后处理描边->后处理Bloom。5)性能：描边和Bloom可以合并到一个后处理Shader的多Pass中减少Blit次数。整体：ShaderLab管结构，CGPROGRAM管光照，后处理管描边+Bloom，Queue管渲染顺序。
</Answer>

**问题 2**：给定一个需要半透明玻璃+Blinn-Phong光照+边缘描边+Bloom泛光的效果需求，设计完整方案。

<Answer>
1)玻璃Shader: Queue=Transparent, Blend SrcAlpha OneMinusSrcAlpha, ZWrite Off。vert做MVP+传递世界法线/位置。frag做Blinn-Phong光照(ambient+diffuse+specular)+alpha控制透明。2)边缘描边: 后处理采样深度+法线纹理，计算相邻像素差，超阈值描边。3)Bloom: 后处理提取高亮区域->高斯模糊降采样->叠加回原图。4)渲染顺序: 不透明->透明玻璃->描边后处理->Bloom后处理。5)优化: 描边+Bloom合并到同一后处理多Pass减少Blit。整体方案覆盖全书四大板块：管线理解渲染流程，ShaderLab搭建结构，光照实现Blinn-Phong，高级技术做透明+描边+泛光。
</Answer>
</Exercises>
