### 核心对象

1. **版本迁移**：在引擎升级前后比较渲染默认值、宏、编译器和材质数据的过程。
2. **环境光变化**：天空盒、GI、反射和色彩空间默认值改变导致的整体亮度差异。
3. **编译严格性**：新编译器对类型、语义、未初始化值和平台规则执行更严格检查。
4. **非统一缩放**：模型各轴比例不同、需要正确位置与法线变换的缩放。
5. **固定管线退场**：旧式状态组合逐渐被可编程Shader替代的兼容性变化。

## 数据流与公式

任何Shader效果都先写清五项契约：输入属性来自哪里，当前值位于哪个坐标或色彩空间，可编程阶段输出什么，ShaderLab状态如何合并结果，以及目标平台和Unity版本是什么。

$$
\Delta C=C_{new}-C_{old}
$$

$$
n'=normalize((M^{-1})^Tn)
$$

$$
migration=compile+visual+performance
$$

$$
tolerance=\|I_{new}-I_{reference}\|
$$

迁移不能只看有没有编译错误。先固定相机、灯光、天空盒、色彩空间与曝光，对旧新版本截图和帧调试记录逐项对比。编译器报错应修复类型和语义根因，不用宽松强转掩盖；非统一缩放要显式验证法线矩阵，固定函数Shader则应重写为可编程路径。 公式不是孤立记忆项；每个向量都标注空间，每个颜色都标注线性或sRGB，每个深度都标注设备、NDC或观察距离，每个纹理通道都标注数据语义。

## 最小Shader实现

```hlsl
// 迁移时显式声明类型和空间
float3 worldNormal = UnityObjectToWorldNormal(v.normal);
float3 worldPos = mul(unity_ObjectToWorld, v.vertex).xyz;
return float4(normalize(worldNormal) * 0.5 + 0.5, 1);
```

实现顺序固定为常量颜色、输入可视化、核心公式、材质参数和优化。每新增一个步骤都保留开关，这样画面异常时可以二分定位。编译成功只证明语法和部分类型成立，不证明空间、状态或色彩处理正确。

## Unity侧设置与渲染状态

```csharp
var material = renderer.sharedMaterial;
material.SetFloat("_DebugMode", debugMode);
material.EnableKeyword(debugMode > 0 ? "DEBUG_VIEW" : "BASELINE_VIEW");
Debug.Assert(material.shader.isSupported);
```

材质、相机和光源属于实验输入，不能只保存Shader文件。用Frame Debugger检查实际选择的SubShader和Pass、关键字变体、渲染队列、RenderTarget、深度写入和混合；用Profiler或GPU捕获确认成本来自提交、顶点、片元还是带宽。

## 边界与平台差异

测试零向量、负缩放、非统一缩放、UV边界、透明物体交叉、近远裁剪面、HDR亮度、不同纹理导入设置和移动精度。原书以Unity 5时代内置管线为语境；迁移到当前Unity、URP或HDRP时，应把概念映射和API替换单独记录，不能把新管线行为倒写成原书内容。

```text
scene: fixed reference scene
unity: exact editor version
pipeline: built-in or named SRP
platform: graphics API and GPU
evidence: image diff + frame events + timings
```

## 验收证书

验收包至少包含Shader与脚本、材质参数、测试场景、参考图和候选图、Frame Debugger事件、编译关键字、目标平台、帧时间与反例。升级后场景更亮就整体压暗材质，没有核对环境光、色彩空间和反射探针默认值。 修复后必须重放同一输入，确认画面和性能变化都能由证据解释。

## 常见误区

<Callout type="trap" title="只看最终截图">升级后场景更亮就整体压暗材质，没有核对环境光、色彩空间和反射探针默认值。</Callout>

<Callout type="trap" title="忽略版本与状态">同一段HLSL在不同Unity版本、渲染管线、关键字和纹理导入设置下可能走不同Pass或解释不同数据。修复时把版本、平台、状态和资源设置纳入实验输入。</Callout>

## 本章回顾

本页覆盖版本迁移、环境光变化、编译严格性、非统一缩放、固定管线退场。掌握标准是能从视觉目标画出数据流，写出最小实现，逐阶段可视化中间值，再用渲染状态、边界样例和性能数据完成复现。
