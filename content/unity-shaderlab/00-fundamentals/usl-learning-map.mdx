## 直觉引入

Unity ShaderLab 就像一套精装修系统——ShaderLab 文件结构是户型图（框架），Properties 是可调节的家具面板，SubShader/Pass 是各房间的施工方案，表面着色器是全屋定制（自动处理光照），光照模型是装修风格（Lambert/PBR/卡通），GrabPass 和 Command Buffer 是高级定制工艺。先懂框架再学施工，最后做定制。

## 代码对照

```shaderlab
// ShaderLab 文件基本结构
Shader "Custom/SimpleShader" {
    Properties {
        _Color ("Main Color", Color) = (1,1,1,1)
        _MainTex ("Texture", 2D) = "white" {}
    }
    SubShader {
        Tags { "RenderType"="Opaque" "Queue"="Geometry" }
        LOD 200

        Pass {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            struct appdata {
                float4 vertex : POSITION;
                float2 uv : TEXCOORD0;
            };

            struct v2f {
                float4 pos : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            sampler2D _MainTex;
            float4 _Color;

            v2f vert(appdata v) {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.uv;
                return o;
            }

            fixed4 frag(v2f i) : SV_Target {
                return tex2D(_MainTex, i.uv) * _Color;
            }
            ENDCG
        }
    }
    Fallback "Diffuse"
}
```

从 ShaderLab 文件结构出发，逐步深入 Properties、Pass、表面着色器和光照模型。

## 常见误区

<Callout type="trap">
**现象 →** 直接写 CG 代码不理解 ShaderLab 框架。
**原因 →** 觉得 ShaderLab 只是壳，CG 才是核心。
**修法 →** ShaderLab 框架决定了 Unity 如何编译和执行 Shader。Properties、Tags、LOD、Fallback 都是 Unity 特有的机制。不理解框架就无法正确配置渲染状态和多平台适配。
</Callout>

<Callout type="trap">
**现象 →** 所有效果都用表面着色器实现。
**原因 →** 表面着色器简单方便。
**修法 →** 表面着色器编译生成的代码冗余多，无法精确控制 Pass 和渲染状态。后处理、屏幕特效、非标准光照应直接用顶点/片段着色器。根据需求选择合适的着色器类型。
</Callout>

## 练习

<Exercises>
**问题**：表面着色器和顶点/片段着色器在 Unity 中有什么关系？

<Answer>
表面着色器是 Unity 对顶点/片段着色器的封装，自动处理光照和阴影。它编译后会生成多个 Pass 的顶点/片段着色器。适合快速实现光照效果；需要更精细控制时应直接写顶点/片段着色器。
</Answer>

**问题**：如何系统学习 Unity ShaderLab 开发？

<Answer>
1)理解 ShaderLab 文件结构框架 2)掌握 Properties 声明与材质面板交互 3)学习 SubShader/Pass 的 LOD 和 Tags 4)用表面着色器快速实现光照 5)自定义光照模型深入理解 6)GrabPass 和 Command Buffer 做屏幕特效 7)综合实战整合所有知识。
</Answer>
</Exercises>
