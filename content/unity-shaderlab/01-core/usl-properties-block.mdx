## 直觉引入

Properties 就像遥控器的按钮——每个按钮（属性）有名字和标签，在材质面板上显示为滑块、颜色选择器或纹理槽。调按钮就是在调参数，参数传到 Shader 代码中影响渲染结果。C# 脚本可以像程序化按按钮一样动态修改这些值。

## 概念讲解

<Term def="材质面板中显示为输入框的浮点数属性">Float</Term><Term def="带滑块且限制范围的浮点数属性">Range</Term><Term def="可拖拽纹理资源的属性类型">纹理属性</Term><Term def="避免创建材质实例的属性修改方式">MaterialPropertyBlock</Term>

### 属性类型
- Float/Range：浮点数，Range 带滑块限制范围
- Color：RGBA 颜色，面板显示颜色选择器
- Vector：四维向量，面板显示四个输入框
- 2D/3D/Cube：纹理类型，面板显示纹理槽

### 声明格式
`_Name("Label", Type) = Default`。名称带下划线前缀，Label 显示在面板上，Type 决定面板控件类型，Default 是默认值。

### C# 交互
Material.SetFloat/SetColor/SetTexture 修改属性。MaterialPropertyBlock 修改属性不创建材质实例，保持合批。Shader.SetGlobalFloat 设置全局属性影响所有材质。

<Stepper>
<Step title="第一步：声明属性">
在 Properties 块中声明 _Color、_MainTex、_Gloss 等属性。每个属性有名称、面板标签、类型和默认值，在材质面板中自动生成对应控件。
</Step>
<Step title="第二步：面板交互">
在材质面板中调节属性值，Unity 将值传递到 Shader 代码中。颜色用 Color 选择器，浮点数用输入框或滑块，纹理用拖拽槽。
</Step>
<Step title="第三步：C# 动态修改">
用 Material.SetFloat/SetColor 修改属性。使用 MaterialPropertyBlock 避免创建材质实例（合批友好）。全局属性用 Shader.SetGlobalColor 影响所有材质。
</Step>
</Stepper>

## 代码对照

```shaderlab
Properties {
    _Color ("Main Color", Color) = (1,1,1,1)
    _MainTex ("Texture", 2D) = "white" {}
    _Gloss ("Gloss", Range(0,1)) = 0.5
    _Speed ("Speed", Float) = 1.0
    _Dir ("Direction", Vector) = (1,0,0,0)
}
```

```csharp
// C# 动态修改属性
Material mat = renderer.material;
mat.SetColor("_Color", Color.red);
mat.SetFloat("_Speed", 2.0f);

// MaterialPropertyBlock — 合批友好
MaterialPropertyBlock block = new MaterialPropertyBlock();
renderer.GetPropertyBlock(block);
block.SetColor("_Color", Color.red);
renderer.SetPropertyBlock(block);

// 全局属性 — 影响所有材质
Shader.SetGlobalFloat("_GlobalTime", Time.time);
```

MaterialPropertyBlock 修改属性不创建新材质实例，GPU 合批不受影响。直接修改 material 属性会创建实例破坏合批。

## 常见误区

<Callout type="trap">
**现象 →** 用 renderer.material 修改属性后物体不再合批。
**原因 →** renderer.material 会创建材质实例。
**修法 →** 使用 MaterialPropertyBlock 修改属性，它不会创建材质实例，保持合批。批量修改相同材质的不同物体时尤其重要。
</Callout>

<Callout type="trap">
**现象 →** Properties 声明了属性但面板上不显示。
**原因 →** 属性名或格式写错，或在 Shader 代码中未引用该属性。
**修法 →** 检查属性声明格式：_Name("Label", Type) = Default。确保名称有下划线前缀。如果属性在 Shader 代码中完全没使用，Unity 可能会优化掉它。
</Callout>

## 练习

<Exercises>
**问题**：Properties 中 Float 和 Range 类型的区别是什么？

<Answer>
Float 是普通浮点数，在面板上显示为输入框。Range(min, max) 是带滑块的浮点数，限制在 min 到 max 范围内。两者在 Shader 代码中都映射为 float 类型，但面板交互方式不同。
</Answer>

**问题**：如何在 C# 脚本中动态修改材质的 Properties？

<Answer>
1)用 Material.SetFloat/SetColor/SetTexture 修改 2)使用 MaterialPropertyBlock 避免创建材质实例（合批友好）3)属性名要加下划线前缀 4)用 Shader.SetGlobalFloat 设置全局属性影响所有材质。
</Answer>
</Exercises>
