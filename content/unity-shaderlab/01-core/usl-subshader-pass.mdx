## 直觉引入

Pass 就像刷漆的工序——一遍底漆一遍面漆。单 Pass 是一次刷完，多 Pass 是分多次刷。描边效果就是两遍工序：第一遍正常刷（渲染本体），第二遍往外扩一圈刷背面（描边轮廓）。每遍可以控制刷不刷背面（Cull）、要不要测深度（ZTest）、怎么混合颜色（Blend）。

## 概念讲解

<Term def="一次完整的绘制调用，一个 SubShader 可含多个">Pass</Term><Term def="控制面剔除的渲染状态（Back/Front/Off）">Cull</Term><Term def="控制是否写入深度缓冲的渲染状态">ZWrite</Term><Term def="控制颜色混合方式的渲染状态">Blend</Term>

### 多 Pass 渲染
一个 SubShader 可含多个 Pass，每个 Pass 是一次绘制调用。多 Pass 用于描边、多次光照、特殊效果等。Pass 之间通过渲染状态和 Blend 模式叠加。

### 渲染状态
- Cull：Back 剔除背面（默认）、Front 剔除正面、Off 不剔除
- ZWrite：On 写深度（默认）、Off 不写
- ZTest：LEqual（默认）、Less、Always 等
- Blend：SrcAlpha OneMinusSrcAlpha 标准透明混合

### UsePass
引用其他 Shader 的 Pass 避免重复代码。格式 UsePass "ShaderName/PASSNAME"。被引用的 Pass 必须有 Name 标签且全大写。

## 代码对照

```shaderlab
SubShader {
    Tags { "RenderType"="Opaque" "Queue"="Geometry" }

    // Pass 1: 正常渲染
    Pass {
        Name "MAIN"
        Cull Back
        ZWrite On

        CGPROGRAM
        #pragma vertex vert
        #pragma fragment frag
        // ... 正常渲染代码
        ENDCG
    }

    // Pass 2: 描边
    Pass {
        Name "OUTLINE"
        Cull Front    // 只显示背面
        ZWrite Off    // 不写深度

        CGPROGRAM
        #pragma vertex vert
        #pragma fragment frag

        float _OutlineWidth;

        v2f vert(appdata v) {
            v2f o;
            // 顶点沿法线外扩
            v.vertex.xyz += v.normal * _OutlineWidth;
            o.pos = UnityObjectToClipPos(v.vertex);
            return o;
        }

        fixed4 frag(v2f i) : SV_Target {
            return _OutlineColor; // 纯色描边
        }
        ENDCG
    }
}

// UsePass 复用
// UsePass "Custom/OutlineShader/OUTLINE"
```

描边用 Cull Front + 法线外扩实现，UsePass 可复用其他 Shader 的命名 Pass。

## 常见误区

<Callout type="trap">
**现象 →** 描边 Pass 渲染了整个物体而不是只显示边缘。
**原因 →** Cull 设置错误。
**修法 →** 描边 Pass 必须 Cull Front（剔除正面），只显示背面。背面的外扩部分正好露在本体边缘外面，形成描边轮廓。如果 Cull Back 则会和本体完全重叠看不到描边。
</Callout>

<Callout type="trap">
**现象 →** UsePass 引用其他 Shader 的 Pass 失败。
**原因 →** Pass 名称拼写或大小写不对。
**修法 →** UsePass 的 Pass 名称必须全大写。如被引用 Shader 中 Pass 名为 "Outline"，UsePass 中应写 "OUTLINE"。检查被引用的 Pass 是否有 Name 标签。
</Callout>

## 练习

<Exercises>
**问题**：Pass 中的 Cull、ZWrite、ZTest、Blend 分别控制什么？

<Answer>
Cull 控制面剔除（Back/Front/Off）、ZWrite 控制是否写深度缓冲、ZTest 控制深度测试函数（Less/LEqual/Always 等）、Blend 控制混合模式（SrcAlpha OneMinusSrcAlpha 为标准透明混合）。
</Answer>

**问题**：如何用多 Pass 实现物体描边效果？

<Answer>
1)Pass 1 正常渲染物体 2)Pass 2 将顶点沿法线方向外扩，Cull Front 剔除正面只显示背面，用纯色填充 3)外扩后的背面形成描边轮廓 4)设置 ZWrite Off 避免深度冲突。
</Answer>
</Exercises>
