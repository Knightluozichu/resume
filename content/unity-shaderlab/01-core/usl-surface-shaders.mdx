## 直觉引入

表面着色器就像全屋定制装修——你只管说「这个房间是木地板、那个房间是瓷砖」（填 SurfaceOutput 的 Albedo、Normal 等字段），Unity 自动帮你处理灯光、阴影、全局光照。而顶点/片段着色器就像自己动手装修，每个细节都要自己搞定，但可以做出非标准的效果。

## 概念讲解

<Term def="Unity 对顶点/片段着色器的封装，自动处理光照">表面着色器</Term><Term def="声明表面着色器的编译指令">#pragma surface</Term><Term def="表面着色器输出结构体，含 Albedo/Normal 等">SurfaceOutput</Term><Term def="表面着色器编译后自动生成的底层着色器">编译生成</Term>

### 优势
自动处理光照、阴影、光照探针和全局光照。开发者只需关注表面属性（Albedo、Normal、Emission 等）。代码简洁，适合快速实现光照效果。

### #pragma surface
`#pragma surface surf Lambert` 声明表面函数为 surf，光照模型为 Lambert。可加 vertex:vert 指定顶点函数、alpha 启用透明、finalcolor:fn 指定最终颜色修改函数。

### SurfaceOutput
Albedo（漫反射颜色）、Normal（法线）、Emission（自发光）、Specular（高光）、Gloss（高光强度）、Alpha（透明度）。Standard 模式额外含 Metallic、Smoothness、Occlusion。

## 代码对照

```shaderlab
Shader "Custom/SurfaceShader" {
    Properties {
        _MainTex ("Texture", 2D) = "white" {}
        _Color ("Color", Color) = (1,1,1,1)
        _Gloss ("Gloss", Range(0,1)) = 0.5
    }
    SubShader {
        Tags { "RenderType"="Opaque" }
        LOD 200

        CGPROGRAM
        // 表面着色器声明: surf 函数 + Standard 光照 + 顶点函数
        #pragma surface surf Standard fullforwardshadows vertex:vert
        #pragma target 3.0

        sampler2D _MainTex;
        fixed4 _Color;
        half _Gloss;

        struct Input {
            float2 uv_MainTex;
            float3 worldNormal;
        };

        // 顶点函数（可选）
        void vert(inout appdata_full v) {
            // 可在此修改顶点数据
        }

        // 表面函数
        void surf(Input IN, inout SurfaceOutputStandard o) {
            fixed4 c = tex2D(_MainTex, IN.uv_MainTex) * _Color;
            o.Albedo = c.rgb;
            o.Metallic = 0.0;
            o.Smoothness = _Gloss;
            o.Alpha = c.a;
        }
        ENDCG
    }
    Fallback "Diffuse"
}
```

表面着色器只需填写 SurfaceOutput 字段，Unity 自动处理光照阴影。编译后生成 ForwardBase/ForwardAdd/Shadow 等多个 Pass。

## 常见误区

<Callout type="trap">
**现象 →** 表面着色器编译后变体数量爆炸。
**原因 →** Unity 自动生成多个 Pass 和多种光照路径的变体。
**修法 →** 用 #pragma skip_variants 跳过不需要的变体。如果只需要前向渲染，用 exclude_path:deferred 排除延迟渲染路径。如果效果不需要标准光照，改用顶点/片段着色器减少编译量。
</Callout>

<Callout type="trap">
**现象 →** 表面着色器做后处理或屏幕特效无法工作。
**原因 →** 表面着色器需要光照和几何体，不适合全屏处理。
**修法 →** 后处理和屏幕特效必须用顶点/片段着色器。表面着色器仅用于有几何体的物体光照。全屏四边形没有法线和光照，表面着色器不适用。
</Callout>

## 练习

<Exercises>
**问题**：#pragma surface surf Lambert 中的各参数含义是什么？

<Answer>
surface 声明表面着色器，surf 是表面函数名，Lambert 是光照模型。还可加 vertex:vert 指定顶点函数、alpha 启用透明、finalcolor:fn 指定最终颜色修改函数等可选参数。
</Answer>

**问题**：何时应该用表面着色器，何时应该用顶点/片段着色器？

<Answer>
表面着色器适合：需要标准光照、需要与全局光照/阴影系统集成、快速原型开发。顶点/片段着色器适合：需要精确控制 Pass 和渲染状态、后处理/屏幕特效、非标准光照、自定义渲染管线、性能要求极高。
</Answer>
</Exercises>
