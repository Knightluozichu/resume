## 直觉引入

高级 ShaderLab 技巧就像厨师的拿手菜——变体管理是控制菜单大小（太多选项厨房做不过来），溶解效果是用模具切割食材（噪声阈值裁剪），能量护盾是多种调味的组合（Fresnel + 噪声 + 折射）。每个技巧都是基础技术的组合运用。

## 概念讲解

<Term def="按需编译 Shader 变体的编译指令">shader_feature</Term><Term def="编译所有组合的 Shader 变体编译指令">multi_compile</Term><Term def="用噪声纹理阈值裁剪像素实现溶解消失的效果">溶解效果</Term><Term def="用 Fresnel + 噪声 + GrabPass 组合实现的护盾特效">能量护盾</Term>

### 变体管理
- shader_feature：只编译使用到的变体，包体小但需手动管理
- multi_compile：编译所有组合变体，兼容性好但包体大
- skip_variants：跳过不需要的变体

### 溶解效果
用噪声纹理采样得到阈值，与 DissolveAmount 比较，低于阈值的像素 clip 丢弃。阈值边缘用 smoothstep 绘制燃烧色。

### 能量护盾
Fresnel 控制边缘发光 + 噪声纹理叠加能量流动 + GrabPass 做折射扭曲 + 受击脉冲扩散 + Blend Add 叠加发光。

## 代码对照

```shaderlab
// 溶解效果 Shader
Shader "Custom/Dissolve" {
    Properties {
        _MainTex ("Texture", 2D) = "white" {}
        _NoiseTex ("Noise", 2D) = "white" {}
        _DissolveAmount ("Dissolve", Range(0,1)) = 0
        _EdgeWidth ("Edge Width", Range(0,0.5)) = 0.1
        _EdgeColor ("Edge Color", Color) = (1,0.5,0,1)
    }
    SubShader {
        Tags { "RenderType"="Opaque" }
        Pass {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            sampler2D _NoiseTex;
            float _DissolveAmount;
            float _EdgeWidth;
            fixed4 _EdgeColor;

            struct v2f {
                float4 pos : SV_POSITION;
                float2 uv : TEXCOORD0;
            };

            v2f vert(appdata v) {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.texcoord;
                return o;
            }

            fixed4 frag(v2f i) : SV_Target {
                float noise = tex2D(_NoiseTex, i.uv).r;
                float threshold = _DissolveAmount;
                // 低于阈值丢弃
                clip(noise - threshold);
                // 燃烧边缘
                float edge = smoothstep(threshold, threshold + _EdgeWidth, noise);
                fixed3 albedo = tex2D(_MainTex, i.uv).rgb;
                fixed3 color = lerp(_EdgeColor.rgb, albedo, edge);
                return fixed4(color, 1.0);
            }
            ENDCG
        }
    }
}
```

溶解用噪声阈值 clip 丢弃像素，smoothstep 在边缘绘制燃烧色。shader_feature 控制可选功能减少变体。

## 常见误区

<Callout type="trap">
**现象 →** shader_feature 声明的变体在打包后丢失。
**原因 →** shader_feature 只编译使用到的变体，打包时未引用的变体不编译。
**修法 →** 使用 Shader Variant Collection 显式声明需要保留的变体。或在材质中设置对应关键词确保被引用。multi_compile 则会编译所有组合，不需要额外处理。
</Callout>

<Callout type="trap">
**现象 →** 溶解边缘燃烧色过渡太硬。
**原因 →** smoothstep 的范围太小或噪声纹理分辨率太低。
**修法 →** 增大 _EdgeWidth 使过渡区域更宽。使用高分辨率噪声纹理避免像素化。可叠加多层不同频率的噪声使边缘更自然。边缘色可用渐变纹理替代固定颜色。
</Callout>

## 练习

<Exercises>
**问题**：Unity ShaderLab 中 shader_feature 和 multi_compile 的区别？

<Answer>
shader_feature 只编译使用到的变体（编译时根据材质决定），适合不常用的开关。multi_compile 编译所有组合的变体，适合全局通用的功能。shader_feature 包体更小但需手动管理变体，multi_compile 包体大但兼容性好。
</Answer>

**问题**：如何在 ShaderLab 中实现溶解效果？

<Answer>
1)用噪声纹理采样得到阈值 2)与 DissolveAmount 参数比较 3)低于阈值的像素 clip 丢弃 4)在阈值边缘用 smoothstep 绘制燃烧边缘 5)边缘宽度用 smoothstep 控制 6)DissolveAmount 从 0 到 1 动画实现溶解过渡。
</Answer>
</Exercises>
