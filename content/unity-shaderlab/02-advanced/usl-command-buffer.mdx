## 直觉引入

Command Buffer 就像在工厂流水线上加装自定义工位——你可以在流水线的任何阶段（AfterGBuffer、AfterLighting 等）插入自己的工序（渲染特定对象、拷贝纹理、执行自定义 Pass）。比 GrabPass 灵活得多，可以精确控制渲染时机和对象。

## 概念讲解

<Term def="在渲染管线特定位置插入自定义渲染命令的机制">Command Buffer</Term><Term def="Command Buffer 挂载的渲染管线事件点">CameraEvent</Term><Term def="用替换着色器渲染指定对象到目标的命令">DrawRenderers</Term><Term def="URP 中替代 Command Buffer 的自定义渲染 Pass">Render Feature</Term>

### 挂载事件
可挂载到 CameraEvent（如 AfterGBuffer、AfterLighting、BeforeImageEffects）或 LightEvent 上，在管线的不同阶段插入命令。

### 可用命令
DrawRenderers（渲染指定对象）、Blit（拷贝纹理）、SetRenderTarget（设置渲染目标）、EnableShaderKeyword（控制关键词）等。

### 选择性描边
用 Replacement Shader 只渲染需要描边的对象到纯色纹理，做边缘检测后叠加回主画面。通过 Layer 过滤只描边指定对象。

## 代码对照

```csharp
// C# 脚本创建 Command Buffer 实现选择性描边
public class OutlineCommandBuffer : MonoBehaviour {
    public Material outlineMaterial;
    public LayerMask outlineLayer;
    private CommandBuffer cmdBuffer;

    void OnEnable() {
        Camera cam = GetComponent<Camera>();
        cmdBuffer = new CommandBuffer();
        cmdBuffer.name = "Outline Effect";

        // 创建 RenderTexture
        int rtID = Shader.PropertyToID("_OutlineTex");
        cmdBuffer.GetTemporaryRT(rtID, -1, -1);

        // 设置渲染目标
        cmdBuffer.SetRenderTarget(rtID);
        cmdBuffer.ClearRenderTarget(true, true, Color.black);

        // 只渲染指定 Layer 的对象（用替换着色器）
        Renderer[] renderers = FindObjectsOfType<Renderer>();
        foreach (var r in renderers) {
            if (((1 << r.gameObject.layer) & outlineLayer) != 0) {
                cmdBuffer.DrawRenderer(r, outlineMaterial);
            }
        }

        // Blit 回主画面（可加边缘检测 Pass）
        cmdBuffer.Blit(rtID, BuiltinRenderTextureType.CurrentActive, outlineMaterial, 1);

        // 挂载到 AfterGBuffer 事件
        cam.AddCommandBuffer(CameraEvent.AfterGBuffer, cmdBuffer);
    }

    void OnDisable() {
        GetComponent<Camera>().RemoveCommandBuffer(CameraEvent.AfterGBuffer, cmdBuffer);
        cmdBuffer.Release();
    }
}
```

Command Buffer 在 AfterGBuffer 阶段渲染指定对象到纹理，再 Blit 回主画面。通过 Layer 过滤只处理目标对象。

## 常见误区

<Callout type="trap">
**现象 →** Command Buffer 在 URP 项目中不生效。
**原因 →** URP 的渲染管线与内置管线不同，CameraEvent 不适用。
**修法 →** URP 中应使用 ScriptableRendererFeature 和 ScriptableRenderPass 替代 Command Buffer。创建 Render Feature 资产，在 RenderPass 中执行自定义渲染逻辑，与 URP 管线原生集成。
</Callout>

<Callout type="trap">
**现象 →** Command Buffer 渲染的对象深度不正确。
**原因 →** Command Buffer 的渲染目标和深度缓冲设置不对。
**修法 →** 确保在 SetRenderTarget 时同时设置深度缓冲。如果需要与场景深度测试，使用 BuiltinRenderTextureType.Depth 或绑定场景深度纹理。DrawRenderers 时设置正确的 RenderFlags。
</Callout>

## 练习

<Exercises>
**问题**：Command Buffer 可以挂载到哪些渲染事件上？

<Answer>
AfterEvent（如 AfterGBuffer、AfterLighting、BeforeImageEffects）、BeforeEvent、BetweenEvent 等。可挂在相机上（CameraEvent）或光源上（LightEvent），在管线的不同阶段插入自定义渲染命令。
</Answer>

**问题**：如何用 Command Buffer 实现选择性描边效果？

<Answer>
1)创建 RenderTexture 作为描边目标 2)Command Buffer 在 AfterGBuffer 阶段执行 3)用替换着色器只渲染需要描边的对象到纯色纹理 4)对纹理做边缘检测 5)将描边结果叠加回主画面 6)通过 Layer 过滤只描边指定对象。
</Answer>
</Exercises>
