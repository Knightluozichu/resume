## 直觉引入

GrabPass 就像在画画过程中拍一张当前画布的照片——你可以在上面继续画，也可以把照片变形后贴回去。玻璃折射就是：先拍下玻璃后面的内容（GrabPass），再用法线扰动采样位置，让透过玻璃看到的内容产生扭曲效果。

## 概念讲解

<Term def="捕获当前屏幕内容为纹理供后续 Pass 使用">GrabPass</Term><Term def="每帧每对象抓取一次屏幕的 GrabPass 写法">无名称 GrabPass</Term><Term def="只抓取一次所有对象共享的 GrabPass 写法">命名 GrabPass</Term><Term def="用法线偏移屏幕 UV 采样 GrabPass 纹理的效果">折射扭曲</Term>

### 两种写法
- `GrabPass {}`：每帧每个使用它的对象抓取一次，开销大
- `GrabPass { "TextureName" }`：只抓取一次，所有对象共享，性能更好

### 折射实现
1. GrabPass 抓取屏幕纹理
2. 采样法线贴图获取扰动方向
3. 用扰动方向偏移屏幕 UV
4. 用偏移 UV 采样 GrabPass 纹理
5. 叠加玻璃颜色和透明度

### 性能问题
GrabPass 需要将帧缓冲拷贝到纹理，开销大。替代方案：Command Buffer 手动控制、URP 的 Opaque Texture、降分辨率抓取。

## 代码对照

```shaderlab
Shader "Custom/GlassRefraction" {
    Properties {
        _MainTex ("Texture", 2D) = "white" {}
        _BumpMap ("Normal Map", 2D) = "bump" {}
        _RefractionAmount ("Refraction", Range(0,1)) = 0.5
        _Color ("Color", Color) = (1,1,1,1)
    }
    SubShader {
        Tags { "Queue"="Transparent" "RenderType"="Opaque" }

        // 抓取屏幕 — 带名称，只抓一次
        GrabPass { "_GrabTexture" }

        Pass {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            sampler2D _GrabTexture;
            sampler2D _MainTex;
            sampler2D _BumpMap;
            float _RefractionAmount;
            fixed4 _Color;

            struct v2f {
                float4 pos : SV_POSITION;
                float4 grabPos : TEXCOORD0;
                float2 uv : TEXCOORD1;
            };

            v2f vert(appdata_full v) {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.grabPos = ComputeGrabScreenPos(o.pos);
                o.uv = v.texcoord;
                return o;
            }

            fixed4 frag(v2f i) : SV_Target {
                // 采样法线贴图获取扰动方向
                float3 normal = UnpackNormal(tex2D(_BumpMap, i.uv));
                // 偏移屏幕 UV
                float2 offset = normal.xy * _RefractionAmount;
                i.grabPos.xy += offset * i.grabPos.z;
                // 采样抓取的屏幕纹理
                fixed3 refraction = tex2Dproj(_GrabTexture, i.grabPos).rgb;
                // 叠加玻璃颜色
                fixed3 albedo = tex2D(_MainTex, i.uv).rgb;
                return fixed4(lerp(refraction, albedo, _Color.a), 1.0);
            }
            ENDCG
        }
    }
}
```

GrabPass 抓取屏幕后用法线偏移 UV 采样实现折射。Queue=Transparent 确保在不透明物体之后抓取。

## 常见误区

<Callout type="trap">
**现象 →** GrabPass 抓取的画面不包含应该被折射的物体。
**原因 →** 渲染队列设置不对，GrabPass 在目标物体之前执行。
**修法 →** 使用 GrabPass 的 Shader 渲染队列必须设为 Transparent（或更高），确保不透明物体先渲染完毕再抓取。否则抓取的屏幕不包含背景物体。
</Callout>

<Callout type="trap">
**现象 →** 多个使用 GrabPass 的物体性能急剧下降。
**原因 →** 使用了无名称的 GrabPass {}，每个对象每帧都抓取一次。
**修法 →** 使用带名称的 GrabPass { "_GrabTexture" }，只抓取一次所有对象共享。移动端考虑用 Command Buffer 或 URP Opaque Texture 替代，避免每帧拷贝帧缓冲。
</Callout>

## 练习

<Exercises>
**问题**：GrabPass 有两种写法，区别是什么？

<Answer>
GrabPass {} 每帧为每个使用它的对象抓取一次屏幕，开销大。GrabPass { "TextureName" } 只抓取一次屏幕并存为命名纹理，所有对象共享，性能更好。推荐使用带名称的写法。
</Answer>

**问题**：GrabPass 有什么性能问题？如何替代？

<Answer>
GrabPass 需要将屏幕内容从帧缓冲拷贝到纹理，开销较大，尤其在移动端。替代方案：1)用 CommandBuffer 手动控制抓取时机和分辨率 2)URP/HDRP 中用 Opaque Texture 替代 3)降分辨率抓取再放大 4)仅在必要时使用。
</Answer>
</Exercises>
