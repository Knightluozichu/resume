## 直觉引入

总复习就像把装修技能串起来——从看户型图（ShaderLab 结构）到选家具面板（Properties），从施工方案（SubShader/Pass）到装修风格（光照模型），再到高级定制（GrabPass/Command Buffer），最后整合成一套完整的装修方案。拼完后你就能独立设计任何 Unity Shader。

## 概念讲解

<Term def="从需求分析到多平台适配的完整 Shader 开发流程">工作流程</Term><Term def="Properties→SubShader→Pass→光照→输出的完整数据传递">数据流</Term><Term def="减少 Pass→控制变体→LOD→合并纹理→half 精度的优化策略">优化链</Term><Term def="溶解+描边+护盾等基础技术组合的实战方案">特效组合</Term>

### 完整流程
1)分析效果需求选择着色器类型 2)编写 ShaderLab 文件结构和 Properties 3)实现 SubShader 和 Pass 逻辑 4)选择光照模型或自定义 5)材质面板调参 6)C# 脚本动态控制 7)多平台适配与性能优化

### 数据流
Properties 声明属性→材质面板设置值→C# 传递参数→SubShader 选择→Pass 执行渲染状态→CG/HLSL 代码处理顶点和像素→光照模型计算→混合输出到帧缓冲

### 优化链
减少 Pass 数量 → 控制变体用 shader_feature → LOD 多级 Shader → 减少纹理采样和合并纹理 → 移动端用 half 精度 → 合批减少 Draw Call

## 代码对照

```shaderlab
// 综合示例：带溶解和描边的技能特效 Shader
Shader "Custom/SkillEffect" {
    Properties {
        _MainTex ("Texture", 2D) = "white" {}
        _NoiseTex ("Noise", 2D) = "white" {}
        _DissolveAmount ("Dissolve", Range(0,1)) = 0
        _EdgeColor ("Edge Color", Color) = (1,0.5,0,1)
        _OutlineWidth ("Outline Width", Range(0,0.1)) = 0.02
        _OutlineColor ("Outline Color", Color) = (0,0,0,1)
    }
    SubShader {
        Tags { "RenderType"="Opaque" "Queue"="Geometry" }
        LOD 200

        // Pass 1: 正常渲染 + 溶解
        Pass {
            Name "MAIN"
            Cull Back
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #pragma shader_feature ENABLE_DISSOLVE
            #include "UnityCG.cginc"

            sampler2D _MainTex;
            sampler2D _NoiseTex;
            float _DissolveAmount;
            fixed4 _EdgeColor;

            fixed4 frag(v2f i) : SV_Target {
                #ifdef ENABLE_DISSOLVE
                float noise = tex2D(_NoiseTex, i.uv).r;
                clip(noise - _DissolveAmount);
                float edge = smoothstep(_DissolveAmount, _DissolveAmount + 0.1, noise);
                fixed3 albedo = tex2D(_MainTex, i.uv).rgb;
                return fixed4(lerp(_EdgeColor.rgb, albedo, edge), 1.0);
                #else
                return tex2D(_MainTex, i.uv);
                #endif
            }
            ENDCG
        }

        // Pass 2: 描边
        Pass {
            Name "OUTLINE"
            Cull Front
            ZWrite Off
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            float _OutlineWidth;
            fixed4 _OutlineColor;
            v2f vert(appdata v) {
                v2f o;
                v.vertex.xyz += v.normal * _OutlineWidth;
                o.pos = UnityObjectToClipPos(v.vertex);
                return o;
            }
            fixed4 frag(v2f i) : SV_Target { return _OutlineColor; }
            ENDCG
        }
    }
    Fallback "Diffuse"
}
```

综合方案将溶解（噪声+clip+smoothstep）、描边（多Pass+Cull Front）、变体管理（shader_feature）组合。C# 控制 DissolveAmount 动画。

## 常见误区

<Callout type="trap">
**现象 →** 综合效果在低端设备上无法运行。
**原因 →** 没有做多平台适配和性能优化。
**修法 →** 用多个 SubShader 按 LOD 分级，高 LOD 用完整效果，低 LOD 简化。用 #pragma target 控制 Shader Model 版本。shader_feature 控制可选功能。移动端用 half 精度和减少纹理采样。
</Callout>

<Callout type="trap">
**现象 →** 打包后 Shader 变体数量过多导致包体膨胀。
**原因 →** 过度使用 multi_compile 且没有裁剪变体。
**修法 →** 优先用 shader_feature 替代 multi_compile。用 #pragma skip_variants 跳过不需要的变体。分析 build 报告找出最大的 Shader。用 Shader Variant Collection 管理关键变体。考虑用 Addressables 按需加载。
</Callout>
