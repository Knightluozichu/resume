## 直觉引入

把 UGUI 想象成一层套一层的相框。最外层是 Canvas（画框），里面每个元素都是 RectTransform（子相框），子相框里放视觉内容（Image/Text）或交互控件（Button/Slider）。交互控件本质上就是视觉组件加上了「可选中」的能力——按下变色、悬停高亮。

### 组件层级

## 交互Demo

<Stepper>
<Step title="第一步：RectTransform 定位">每个 UI 元素都有 RectTransform。锚点决定元素相对父级的对齐方式——锚点在中心时元素居中，锚点四角拉开时元素随父级拉伸。轴心决定元素自身的旋转和缩放中心。</Step>
<Step title="第二步：视觉组件">
Image 和 Text 是最常用的视觉组件。Image 用 Sprite，支持九宫格拉伸（防止圆角变形）和图集合并（减少 Draw Call）。Text 用 Font 渲染文字，支持富文本标签。RawImage 用于动态纹理。
<UidUguiBasicsDiagram />
</Step>
<Step title="第三步：交互组件">Button/Toggle/Slider 都继承自 Selectable。Selectable 提供四种状态（正常/高亮/按下/禁用）的颜色和精灵切换。Button 在此基础上实现 IPointerClickHandler，点击时触发 onClick 事件。</Step>

## 代码对照

```csharp
// RectTransform 锚点设置（居中拉伸）
rectTransform.anchorMin = Vector2.zero;   // 左下角
rectTransform.anchorMax = Vector2.one;    // 右上角
rectTransform.pivot = new Vector2(0.5f, 0.5f); // 中心轴心

// Image 九宫格拉伸
image.sprite = mySprite;
image.type = Image.Type.Sliced; // 九宫格

// Button 事件注册
button.onClick.AddListener(() => {
    Debug.Log("按钮被点击");
});

// 自定义交互组件
public class MyToggle : Selectable, IPointerClickHandler {
    public UnityEvent onToggle;
    public void OnPointerClick(PointerEventData e) => onToggle?.Invoke();
}
```

## 常见误区

<Callout type="trap">
**误区：用 RawImage 代替 Image 来显示静态图片。**
RawImage 不支持九宫格拉伸和图集合并，每个 RawImage 都会打断合批产生独立 Draw Call。静态 UI 图片应该用 Image + Sprite + 图集。RawImage 仅用于动态加载的纹理（网络图片、RenderTexture），用完即销毁。
</Callout>

<Callout type="trap">
**误区：在 Update 中用 Input.GetMouseButtonDown 检测 UI 点击。**
UGUI 有完整的事件系统，应该用 IPointerClickHandler 等接口被动接收事件。在 Update 中轮询鼠标输入会绕过事件系统，无法区分 UI 点击和游戏世界点击，也无法支持手柄和触摸。正确做法是实现事件接口，让 EventSystem 派发事件。
</Callout>

<Exercises>
**问题 1**：Image 和 RawImage 有什么区别？什么时候该用哪个？

<Answer>
Image 使用 Sprite，支持九宫格拉伸（防止圆角变形）和图集合并（减少 Draw Call），是静态 UI 图片的首选。RawImage 使用 Texture2D，不支持九宫格和图集，每个 RawImage 会打断合批。RawImage 仅用于动态纹理——网络下载的图片、RenderTexture、摄像头画面等无法预打包到图集的场景。能用 Image 就不要用 RawImage。
</Answer>

**问题 2**：RectTransform 的锚点和轴心分别影响什么？

<Answer>
锚点定义元素相对于父级矩形的参考点。锚点是一个点时，元素位置相对该点偏移；锚点四角拉开成矩形时，元素随父级拉伸（padding 保持不变）。轴心定义元素自身的旋转和缩放中心——轴心在中心时旋转围绕中心，在左上角时旋转围绕左上角。简言之：锚点决定「相对父级怎么定位」，轴心决定「自身怎么变换」。
</Answer>
</Exercises>
