## 直觉引入

如果你做过网页开发，UI Toolkit 会让你感到亲切——UXML 就是 HTML（定义结构），USS 就是 CSS（控制样式），C# 就是 JavaScript（处理逻辑）。三层分离，各管各的。而 UGUI 更像 Unity 的传统方式——所有配置在 Inspector 里，结构与样式混在一起。

## 概念讲解

### 三层架构

<UidUitoolkitDiagram />

<Term def="UXML是UI Toolkit的结构描述文件，类似HTML，用XML语法定义VisualElement层级树">UXML</Term>定义结构。

<Term def="USS是UI Toolkit的样式表文件，类似CSS，用选择器+属性控制VisualElement的外观和布局">USS</Term>控制样式。

<Term def="VisualElement是UI Toolkit的基础元素类，轻量数据对象，不创建GameObject，构成元素树">VisualElement</Term>是 UI Toolkit 的基础。

<Term def="保留模式(Retained Mode)是UI Toolkit的渲染方式，只重绘变化部分，而非每帧全量重建，性能优于UGUI的即时模式">保留模式</Term>是性能优势的来源。

## 代码对照

```csharp
// UXML 结构
// <UXML>
//   <Label class="title" text="设置"/>
//   <Button name="confirmBtn" text="确定"/>
// </UXML>

// USS 样式
// .title { font-size: 24px; color: white; }
// #confirmBtn:hover { background-color: #4CAF50; }

// C# 逻辑
var root = uiDocument.rootVisualElement;
var btn = root.Q<Button>("confirmBtn");
var title = root.Q<Label>(className: "title");

btn.RegisterCallback<ClickEvent>(e => {
    title.text = "已确认";
});

// 数据绑定（Unity 2023+）
btn.SetBinding("text", new DataBinding \{ dataSource = myData, dataPath = "btnLabel" });
```

## 常见误区

<Callout type="trap">
**误区：认为 UI Toolkit 可以完全替代 UGUI。**
UI Toolkit 目前主要面向编辑器扩展和复杂数据面板，运行时游戏 UI 的支持仍在完善中。UGUI 在 3D 空间 UI、粒子特效集成、运行时动态创建等方面仍有优势。Unity 官方建议：编辑器工具用 UI Toolkit，运行时游戏 UI 视项目需求选择，两者并存互补。
</Callout>

<Callout type="trap">
**误区：在 Update 中每帧 Query 查找 VisualElement。**
root.Q 方法遍历 VisualElement 树，大量查询有性能开销。应该在初始化时缓存查询结果：`private Button _btn; void Start() { _btn = root.Q<Button>("myBtn"); }`，后续直接用 _btn 操作。和 UGUI 的 GameObject.Find 一样，不要在 Update 中调用。
</Callout>

<Exercises>
**问题 1**：UI Toolkit 和 UGUI 的核心区别是什么？

<Answer>
1)UI Toolkit 不创建 GameObject，VisualElement 是轻量数据对象，不进入场景树；UGUI 的每个元素都是 GameObject。2)UI Toolkit 用保留模式渲染（只重绘变化部分），UGUI 用即时模式（每帧重建网格）。3)UI Toolkit 支持 Flexbox 布局，UGUI 用 LayoutGroup。4)UI Toolkit 用 UXML/USS 分离结构和样式，UGUI 全在 Inspector 配置。UI Toolkit 适合编辑器和复杂面板，UGUI 适合运行时游戏 UI。
</Answer>

**问题 2**：如何在 C# 中查询 UXML 元素并注册点击事件？

<Answer>
通过 UIDocument 组件获取 rootVisualElement，然后用 Q 方法查询：var btn = root.Q&lt;Button&gt;("myBtn");（按 name 查询）或 root.Q&lt;Label&gt;(className: "title");（按 class 查询）。注册事件：btn.RegisterCallback&lt;ClickEvent&gt;(e =&gt; &#123; Debug.Log("点击"); &#125;);。注意 Q 方法遍历元素树，应在初始化时缓存查询结果，不要在 Update 中每帧查询。
</Answer>
</Exercises>
