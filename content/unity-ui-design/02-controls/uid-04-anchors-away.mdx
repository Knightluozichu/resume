## 为什么从这个UI任务开始

锚点页把响应式布局还原为父矩形中的归一坐标与偏移；缩放模式解决的是度量政策，不能替代正确锚定。 “Chapter 4. Anchors Away”使用的贯穿任务是：为HUD固定四角按钮、拉伸中央状态栏，并比较三种Canvas Scaler模式在手机与桌面的结果。 操作前先预测哪个矩形、射线目标或事件处理器会变化，运行后再补理由不算预测。

本页围绕“怎样从产品约束选择固定像素、按屏幕缩放或物理尺寸，而不是靠拖动到某一分辨率看起来合适？”建立正常、故障与恢复路径。只有“Chapter 4. Anchors Away”保持“锚点归一坐标、轴心、偏移、参考分辨率、Match和安全区均被记录并在边界视口复核”并交付Anchor Min/Max、Pivot、offset、参考分辨率、Match值、物理单位、宽高比矩阵、安全区截图和选择理由。，编辑器画面才构成UI证据。
