## 直觉引入

想象你在装修房子。先搭框架（URP 架构），再选墙纸和涂料（Shader Graph / Lit Unlit），然后装灯具（光照系统），拉窗帘（阴影），最后挂装饰画和调色（后处理），最后检查水电效率（性能优化）。URP 就是这栋房子——从管线骨架到视觉细节，再到工程优化。

全书的核心线索是：先理解「URP 怎么组织渲染」（架构），再学「怎么写 Shader」（Shader Graph / HLSL），然后学「怎么打光」（光照），接着学「怎么产生阴影」（阴影），再学「怎么加滤镜」（后处理），最后学「怎么跑得快」（优化）。

## 代码对照

```hlsl
// URP 一帧的渲染流程（简化）
// 1. SRP Core 调度：Render() 入口
// 2. Shadow Pass：渲染 Shadow Map
// 3. Opaque Pass：渲染不透明物体（Lit/Unlit）
// 4. Depth/Normal Pass：辅助纹理（如 SSAO）
// 5. Transparent Pass：渲染半透明物体
// 6. Post Processing Pass：Bloom/调色/ToneMap

// URP Shader 结构（ShaderLab）
Shader "Custom/URPLit" {
    Properties { ... }
    SubShader {
        Tags { "RenderPipeline" = "UniversalPipeline" }
        Pass {
            Name "ForwardLit"
            Tags { "LightMode" = "UniversalForward" }
            HLSLPROGRAM
            // URP 的 HLSL include
            #include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"
            #pragma vertex vert
            #pragma fragment frag
            ENDHLSL
        }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：把 URP 当内置管线用。**
URP 的设计哲学是可编程管线，它的 Pass 组织、Shader 结构、光照模型都与内置管线不同。直接搬内置管线的 ShaderLab 写法会导致功能不正常。URP 必须用 `"RenderPipeline" = "UniversalPipeline"` 标签和对应的 HLSL 库。
</Callout>

<Callout type="trap">
**误区：只学 Shader Graph 不学 HLSL。**
Shader Graph 适合快速原型和简单效果，但复杂着色逻辑、性能优化和自定义 Pass 仍需手写 HLSL。理解 Shader Graph 生成的 HLSL 代码，才能真正掌握 URP Shader 开发。
</Callout>

<Exercises>
**问题 1**：全书四大板块是什么？它们之间是什么关系？

<Answer>
基础架构（URP/Shader Graph）、材质与光照（Lit/Unlit/光照）、高级效果（阴影/后处理/自定义 Pass）、工程优化（性能调优）。呈递进关系：基础架构提供管线认知和着色器编辑能力，材质与光照实现视觉真实感，高级效果拓展渲染表现力，工程优化确保高效运行。
</Answer>

**问题 2**：为什么说「SRP 是骨架，Shader 是皮肤，光照是灵魂」？

<Answer>
SRP（Scriptable Render Pipeline）定义了渲染管线的组织方式——Pass 的顺序、渲染目标的分配、Feature 的注入，是整个渲染的骨架。Shader 定义了物体表面的视觉表现——颜色、纹理、透明度，是可见的皮肤。光照决定了物体的明暗、质感和空间关系——没有光照，PBR 材质只是一片纯色，是赋予场景生命力的灵魂。三者缺一不可：骨架支撑结构，皮肤展现外观，灵魂注入真实感。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="URP">Unity Universal Render Pipeline，Unity 的可编程渲染管线，兼顾跨平台兼容性与渲染可定制性。</GlossaryItem>
<GlossaryItem term="SRP Batch">URP 的合批机制，将相同 Shader 的绘制调用合并，减少 CPU 端的 SetPassCall 开销。</GlossaryItem>
<GlossaryItem term="Shader Graph">Unity 的可视化着色器编辑器，通过节点连线生成 HLSL 代码，降低 Shader 编写门槛。</GlossaryItem>
<GlossaryItem term="Render Pass">渲染管线中的一个执行单元，负责一组绘制命令和渲染目标配置，是 URP 管线的基本积木。</GlossaryItem>
</Glossary>
