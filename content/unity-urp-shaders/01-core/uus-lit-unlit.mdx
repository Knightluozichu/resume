## 直觉引入

想象两个房间。一个房间有窗户，阳光照进来，墙壁地板的明暗随光线变化——这是 Lit（受光）。另一个房间没有窗户，墙就是它本来的颜色，不受外界光线影响——这是 Unlit（无光照）。URP 的 Lit 和 Unlit 就是这两种「房间」。

## 概念讲解

### Lit 与 Unlit 对比

<UusLitUnlitDiagram />

<Term def="Lit Shader 是参与光照计算的着色器，基于 PBR（Physically Based Rendering）材质模型">Lit</Term> 是 URP 的主力材质：接收直接光、间接光、阴影，支持金属度、平滑度、法线贴图等 PBR 参数。

<Term def="Unlit Shader 是不参与光照计算的着色器，直接输出颜色或纹理采样结果">Unlit</Term> 跳过光照管线，颜色直通输出。性能极低，适合 UI、粒子特效、调试可视化。

Lit 的光照计算：Direct（Diffuse + Specular BRDF）+ Indirect（GI + Reflection Probe）。Unlit 的「计算」：Color = Texture.Sample(uv) 或固定颜色。

## 代码对照

```hlsl
// Lit Shader 核心光照（简化）
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"

half4 frag(Varyings IN) : SV_Target {
    // PBR 参数
    half3 albedo = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, IN.uv).rgb * _BaseColor.rgb;
    half metallic = _Metallic;
    half smoothness = _Smoothness;
    half3 normalTS = UnpackNormal(SAMPLE_TEXTURE2D(_BumpMap, sampler_BumpMap, IN.uv));

    // URP 光照计算（BRDF + GI + Shadow）
    InputData inputData = BuildInputData(IN, normalTS);
    SurfaceData surface = BuildSurfaceData(albedo, metallic, smoothness);
    half4 color = UniversalFragmentPBR(inputData, surface);
    return color;
}

// Unlit Shader 核心输出（简化）
half4 frag(Varyings IN) : SV_Target {
    half4 texColor = SAMPLE_TEXTURE2D(_BaseMap, sampler_BaseMap, IN.uv);
    return texColor * _BaseColor; // 直通输出，无光照计算
}
```

## 常见误区

<Callout type="trap">
**误区：所有物体都用 Lit。**
UI 元素、调试网格、简单粒子特效不需要光照——用 Lit 会白白增加光照计算开销。这些场景应使用 Unlit，开销降低数倍。判断标准：需要随光线变化明暗用 Lit，需要固定外观用 Unlit。
</Callout>

<Callout type="trap">
**误区：不理解 Metallic 的物理含义。**
Metallic 是 0 或 1 的二值参数（金属或非金属），中间值缺乏物理意义。金属（Metallic=1）的反射率高且无漫反射，非金属（Metallic=0）的反射率低且有漫反射。常见错误：用中间 Metallic 值做「半金属」效果，这不符合 PBR 原理。
</Callout>

<Exercises>
**问题 1**：Lit 和 Unlit 的核心区别是什么？

<Answer>
Lit 参与 URP 光照管线，基于 PBR 材质模型计算直接光（Diffuse + Specular BRDF）和间接光（GI + Reflection Probe），受光源和阴影影响。Unlit 不参与光照计算，颜色 = 纹理采样或固定色，直通输出。Lit 开销高（取决于光源数和 BRDF 复杂度），Unlit 开销极低。Lit 用于需要真实感的 3D 物体，Unlit 用于 UI、粒子、调试。
</Answer>

**问题 2**：为什么 UI 和粒子通常用 Unlit？

<Answer>
UI 元素（按钮、文本、图标）和粒子特效不需要受场景光照影响——它们的外观是设计固定的，不应随场景光源变化。使用 Unlit 的原因：1) 无光照计算开销，性能远优于 Lit；2) 颜色精确可控，不受光源颜色和强度干扰；3) 渲染顺序在 Transparent 队列，与 UI/粒子的半透明需求匹配；4) 避免不必要的 Shadow Caster/Receiver 计算。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="Lit">参与光照计算的 URP 着色器，基于 PBR 材质模型，支持金属度、平滑度、法线等参数。</GlossaryItem>
<GlossaryItem term="Unlit">不参与光照计算的着色器，直接输出颜色或纹理采样，开销极低。</GlossaryItem>
<GlossaryItem term="PBR">Physically Based Rendering，基于物理的渲染，使用真实物理参数（金属度、粗糙度）描述材质。</GlossaryItem>
<GlossaryItem term="Metallic">PBR 材质参数，0 表示非金属（有漫反射），1 表示金属（无漫反射，高反射率）。</GlossaryItem>
</Glossary>
