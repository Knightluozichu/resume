## 直觉引入

想象一个晴天。阳光直接照在你身上（直接光），同时地面和墙壁把阳光反射到你身上（间接光）。你的肤色、衣服材质决定光线如何被反射（BRDF）。URP 光照系统就是模拟这个过程：直接光 + 间接光，经 BRDF 计算，得出最终像素颜色。

## 概念讲解

### 光照组成

<UusUrpLightingDiagram />

URP 光照公式：`最终颜色 = Direct(Diffuse + Specular) + Indirect(Diffuse + Specular)`

- <Term def="主光源（Main Light）是 URP 中最亮的一个平行光，始终逐像素计算">主光源</Term>：平行光，逐像素计算
- <Term def="附加光（Additional Lights）是主光源之外的光源（点光/聚光），按上限分逐像素和逐顶点">附加光</Term>：点光/聚光，超出逐像素上限退化为逐顶点
- <Term def="BRDF（Bidirectional Reflectance Distribution Function）是双向反射分布函数，描述光线如何被表面反射">BRDF</Term>：Cook-Torrance 模型 = Diffuse(Lambert) + Specular(GGX NDF + Smith G + Schlick Fresnel)
- <Term def="GI（Global Illumination）是全局光照，提供间接光：球谐光照（SH）提供漫反射间接光，反射探针提供镜面间接光">GI</Term>：Spherical Harmonics + Reflection Probe

## 代码对照

```hlsl
// URP 光照核心（简化）
#include "Packages/com.unity.render-pipelines.universal/ShaderLibrary/Lighting.hlsl"

half4 frag(Varyings IN) : SV_Target {
    InputData inputData = BuildInputData(IN, normalTS);
    SurfaceData surface = BuildSurfaceData(albedo, metallic, smoothness);

    // UniversalFragmentPBR 内部执行：
    // 1. 主光源：GetMainLight() → Diffuse + Specular (BRDF)
    // 2. 附加光：loop GetAdditionalLight() → 逐像素/逐顶点
    // 3. 间接光：SH (GI Diffuse) + Reflection Probe (GI Specular)
    // 4. 阴影：MainLightShadow + AdditionalLightShadow
    half4 color = UniversalFragmentPBR(inputData, surface);
    return color;
}

// BRDF 核心公式（简化）
// Diffuse: Lambert = albedo / PI
// Specular: Cook-Torrance = (D * G * F) / (4 * (N·L) * (N·V))
//   D = GGX NDF（法线分布函数）
//   G = Smith Geometry（几何遮蔽）
//   F = Schlick Fresnel（菲涅尔反射）
```

## 常见误区

<Callout type="trap">
**误区：忽视逐像素与逐顶点光照的差异。**
URP 有逐像素光源上限（URP Asset 中配置），超出上限的光源退化为逐顶点计算。逐顶点光照在三角形内线性插值，高光区域会出现明显面片化。需要在 URP Asset 中根据平台平衡上限值。
</Callout>

<Callout type="trap">
**误区：混淆 Smoothness 和 Roughness。**
URP 用 Smoothness（0=粗糙 1=光滑），PBR 理论用 Roughness（0=光滑 1=粗糙），二者互为倒数（Roughness = 1 - Smoothness）。在 Shader 中转换时要注意，混用会导致材质外观反转。
</Callout>

<Exercises>
**问题 1**：URP 光照公式是什么？各部分如何计算？

<Answer>
最终颜色 = Direct(Diffuse + Specular) + Indirect(Diffuse + Specular)。Direct Diffuse 用 Lambert 模型（albedo/PI），Direct Specular 用 Cook-Torrance 模型（D*G*F / 4(N·L)(N·V)），其中 D=GGX NDF、G=Smith 几何函数、F=Schlick 菲涅尔。Indirect Diffuse 用球谐光照（SH），Indirect Specular 用 Reflection Probe 采样。主光源逐像素计算，附加光按上限分逐像素/逐顶点。
</Answer>

**问题 2**：为什么逐顶点光照会出现面片化？如何缓解？

<Answer>
逐顶点光照在顶点着色器中计算光照，光颜色在三角形内通过重心坐标线性插值到像素。高光集中在顶点附近，三角形中心的高光丢失，导致高光区域出现明显的三角形面片边界。缓解方法：1) 增加 URP Asset 的逐像素光源上限（Per Pixel Limit）；2) 增加模型顶点密度；3) 对需要高质量高光的物体使用 Reflection Probe 或预烘焙；4) 在移动端用 Lightmap 替代实时附加光。
</Answer>
</Exercises>

<GlossaryItem term="主光源">URP 中最亮的平行光，始终逐像素计算，是场景主要光照来源。</GlossaryItem>
