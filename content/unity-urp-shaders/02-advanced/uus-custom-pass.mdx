## 直觉引入

想象 URP 管线是一条流水线传送带，Render Pass 是传送带上的工位。内置工位（不透明渲染、阴影、后处理）已经排好顺序。自定义 Pass 就是你在传送带上「插队」——在指定位置放一个新工位，执行你的自定义渲染逻辑（描边、全屏特效、自定义深度等）。

## 概念讲解

### Feature 与 Pass 的关系

<UusCustomPassDiagram />

<Term def="ScriptableRendererFeature 是 URP 渲染特性的抽象，负责创建和注册 Render Pass">ScriptableRendererFeature</Term> 是入口：Create() 初始化 Pass，AddRenderPasses() 将 Pass 注入管线。

<Term def="ScriptableRenderPass 是 URP 渲染通道的抽象，在 Execute() 中执行实际绘制命令">ScriptableRenderPass</Term> 是执行体：
- `Create()`：Feature 初始化时调用，创建 Pass 实例
- `OnCameraSetup()`：每帧每相机调用，分配 RT、配置渲染目标
- `Execute()`：每帧每相机调用，执行 Blit / DrawMesh 等绘制命令
- `OnCameraCleanup()`：释放临时 RT

## 代码对照

```csharp
// 自定义描边 Renderer Feature（完整示例）
public class OutlineFeature : ScriptableRendererFeature {
    public RenderPassEvent renderPassEvent = RenderPassEvent.AfterRenderingOpaques;
    public Material outlineMaterial;
    OutlinePass m_OutlinePass;

    public override void Create() {
        m_OutlinePass = new OutlinePass(renderPassEvent, outlineMaterial);
    }

    public override void AddRenderPasses(ScriptableRenderer renderer, ref RenderingData data) {
        if (outlineMaterial != null)
            renderer.EnqueuePass(m_OutlinePass);
    }

    class OutlinePass : ScriptableRenderPass {
        Material m_Material;
        int m_TempRT = Shader.PropertyToID("_OutlineTemp");

        public OutlinePass(RenderPassEvent evt, Material mat) {
            renderPassEvent = evt;
            m_Material = mat;
        }

        public override void OnCameraSetup(CommandBuffer cmd, ref RenderingData data) {
            var desc = data.cameraData.cameraTargetDescriptor;
            desc.depthBufferBits = 0; // 只需颜色
            cmd.GetTemporaryRT(m_TempRT, desc);
        }

        public override void Execute(ScriptableRenderContext ctx, ref RenderingData data) {
            var cmd = CommandBufferPool.Get("Outline");
            // Blit：场景颜色 → 临时RT（经描边材质处理）→ 场景颜色
            Blit(cmd, data.cameraData.renderer.cameraColorTarget, m_TempRT, m_Material);
            Blit(cmd, m_TempRT, data.cameraData.renderer.cameraColorTarget);
            ctx.ExecuteCommandBuffer(cmd);
            CommandBufferPool.Release(cmd);
        }

        public override void OnCameraCleanup(CommandBuffer cmd) {
            cmd.ReleaseTemporaryRT(m_TempRT);
        }
    }
}
```

## 常见误区

<Callout type="trap">
**误区：在 Execute 中直接操作 cameraColorTarget 不分配临时 RT。**
直接 Blit 到 cameraColorTarget 是未定义行为——GPU 可能正在读取同一 RT 作为输入。必须分配临时 RT 作为中间缓冲：source → tempRT（材质处理）→ source。忘记释放临时 RT 会导致内存泄漏。
</Callout>

<Callout type="trap">
**误区：忽视注入点顺序导致效果异常。**
注入点决定 Pass 在管线中的执行时机。如描边在 AfterRenderingOpaques（不透明后）但 BeforeRenderingTransparents（半透明前），这样半透明物体不会被描边。选错注入点可能导致描边被后处理覆盖，或读取到错误的 RT 状态。
</Callout>

<Exercises>
**问题 1**：Renderer Feature 和 Render Pass 的关系是什么？各自的生命周期方法有哪些？

<Answer>
Renderer Feature（ScriptableRendererFeature）是入口，负责创建和注册 Pass。Create() 在 Feature 初始化时调用，创建 Pass 实例。AddRenderPasses() 每帧每相机调用，将 Pass 通过 EnqueuePass 注入管线。Render Pass（ScriptableRenderPass）是执行体，OnCameraSetup() 每帧分配 RT 和配置目标，Execute() 每帧执行 Blit/DrawMesh 绘制命令，OnCameraCleanup() 释放临时 RT。
</Answer>

**问题 2**：如何用自定义 Pass 实现描边效果？关键步骤是什么？

<Answer>
关键步骤：1) 编写描边材质（Fragment Shader 中采样邻域像素，根据亮度差或深度差生成描边颜色）；2) 创建 OutlineFeature 继承 ScriptableRendererFeature，在 Create() 中创建 OutlinePass；3) OutlinePass 在 OnCameraSetup() 分配临时 RT，在 Execute() 中执行两次 Blit：cameraColorTarget → tempRT（经描边材质处理）→ cameraColorTarget；4) 在 OnCameraCleanup() 释放临时 RT；5) 在 Renderer Data 添加 OutlineFeature，设置注入点为 AfterRenderingOpaques。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="ScriptableRendererFeature">URP 渲染特性抽象，负责创建 Pass 实例并通过 AddRenderPasses 注入管线。</GlossaryItem>
<GlossaryItem term="ScriptableRenderPass">URP 渲染通道抽象，在 Execute() 中执行 Blit/DrawMesh 等绘制命令。</GlossaryItem>
<GlossaryItem term="注入点">RenderPassEvent 枚举，决定 Pass 在管线中的执行时机（如 BeforeRendering/AfterRendering）。</GlossaryItem>
<GlossaryItem term="Blit">全屏像素拷贝操作，将一个 RT 的内容经材质处理后写入另一个 RT。</GlossaryItem>
</Glossary>
