### 五个核心符号

1. **MainLightShadow**：从主光阴影图与级联数据计算衰减的函数族。
2. **AdditionalLightShadow**：从附加光阴影图集读取点光或聚光阴影的函数族。
3. **ScreenSpaceOcclusionData**：保存直接和间接环境遮蔽因子的结构。
4. **SampleSceneDepth**：按URP声明与XR宏读取相机深度纹理的接口。
5. **Normal Reconstruction**：在没有法线纹理时从深度邻域重建世界或视空间法线。

## 生产者到消费者链

追踪世界点到阴影坐标、级联选择、采样与淡出，再读SSAO对Direct/Indirect的调制。深度与法线采样必须通过URP声明宏支持XR、动态分辨率和平台纹理类型。 阅读顺序固定为资源入口、ShaderLab Properties与Pass、HLSL输入结构、核心函数、共享库、运行时Renderer选择。每个箭头都写明文件、符号、参数、关键字和目标缓冲。

$$
shadow=sampleAtlas(shadowCoord,cascade)
$$

$$
attenuation=distanceAtten*shadowAtten
$$

$$
AO=(directAO,indirectAO)
$$

$$
normal=reconstruct(depthNeighborhood)
$$

公式中的位置、方向、深度、颜色和索引必须标注空间、范围与来源。源码中能找到函数不证明它在当前变体执行，必须继续核对pragma、关键字、LightMode和Renderer配置。

## 最小源码探针

```hlsl
float depth=SampleSceneDepth(uv);
```

探针顺序是常量输出、输入结构可视化、核心函数分项、固定状态和目标缓冲。先确认实际Shader变体和Pass，再解释颜色或性能差异。

## 运行时互证

```text
source: commit + package path + symbol
material: shader + keywords + UnityPerMaterial layout
renderer: renderer asset + rendering path + pass event
```

用Frame Debugger确认实际Pass和关键字，用GPU捕获确认RenderState、资源绑定、MRT与时序，用构建日志确认变体是否保留。修改包源码时还要记录嵌入包与上游提交的差异。
