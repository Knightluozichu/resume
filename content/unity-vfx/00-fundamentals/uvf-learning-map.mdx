## 直觉引入

游戏特效是玩家最直接感受到的「爽快」来源——火焰燃烧、刀光划过、爆炸冲击、技能释放。这些视觉效果背后是一套从粒子到 Shader、从动画驱动到战斗综合的技术体系。

这本书把 Unity 游戏特效拆成十章，从粒子系统基础开始，到 Shader 特效、后处理、动画/物理驱动，最后到 UI 特效与战斗综合。每章解决一个核心技术问题，章与章之间层层递进。

## 概念讲解

全书分四个阶段：**基础入门**（学习地图+粒子基础）、**核心技术**（粒子进阶+Shader+后处理）、**高级应用**（动画/物理/UI/战斗特效）、**综合复习**。

<Term def="Unity 中模拟离散视觉元素的核心系统">粒子系统</Term>是特效的素材来源。<Term def="控制物体表面渲染效果的程序">Shader</Term>赋予特效质感。<Term def="在渲染管线末端对全屏画面施加的处理">后处理</Term>统一画面氛围。<Term def="通过动画事件和物理碰撞触发特效">驱动系统</Term>控制特效时机。

### 阶段依赖
- 基础 → 核心：有了粒子素材，才能用 Shader 和后处理增强
- 核心 → 高级：有了质感和氛围，才能用动画/物理驱动
- 高级 → 复习：综合应用完成后，串联全书知识体系

### 学习节奏建议
- 第 1 章通读全图，建立全局观
- 第 2-4 章是核心技术，逐个掌握
- 第 5-8 章是高级应用，实战驱动
- 第 9-10 章串联全书，做综合项目

## 代码对照

```csharp
// Unity C#: 游戏特效核心技术路径概览
// 1. 粒子系统基础
var ps = GetComponent<ParticleSystem>();
ps.Play();

// 2. 粒子进阶：曲线驱动
var colorOverLifetime = ps.colorOverLifetime;
colorOverLifetime.enabled = true;

// 3. Shader 特效：溶解
material.SetFloat("_Threshold", dissolveAmount);

// 4. 后处理：Bloom（URP Volume）
var bloom = volume.profile.Get<Bloom>();
bloom.intensity.value = 2f;

// 5. 动画事件驱动特效
void OnSlash() {
    var vfx = ObjectPool.Get(slashPrefab);
    vfx.transform.position = transform.position;
}

// 6. 物理碰撞特效
void OnCollisionEnter(Collision col) {
    var cp = col.contacts[0];
    SpawnHitVfx(cp.point, cp.normal);
}

// 7. 战斗打击感：顿帧
Time.timeScale = 0f;
StartCoroutine(ResumeTime(0.08f));
```

## 常见误区

<Callout type="trap">
**现象 →** 学了一堆特效技术，但做出来的战斗「不够爽」。
**原因 →** 只关注单个特效的视觉效果，忽略了打击感四要素的配合。
**修法 →** 先建全局观：粒子→Shader→后处理→动画驱动→物理碰撞→UI反馈→战斗综合。做战斗特效时按打击感四要素逐项检查：顿帧有没有？震屏有没有？特效爆发够不够？音效同步了没？
</Callout>

**问题**：全书四个阶段分别解决什么问题？如果只能保留一个阶段来让游戏有特效，你保留哪个？

<Answer>
基础入门解决「特效素材从哪来」——粒子系统是地基。核心技术解决「素材如何有质感」——Shader和后处理让画面好看。高级应用解决「特效如何与游戏交互」——动画和物理驱动让特效有节奏。综合复习解决「如何系统化运用」。若只保留一个阶段，必须保留基础入门——没有粒子就没有任何视觉特效，其余都是增强。
</Answer>
</Exercises>

<GlossaryItem term="粒子系统">Unity 中模拟离散视觉元素（火焰、烟雾、爆炸）的核心系统，通过 ParticleSystem 组件控制生成、运动和渲染。</GlossaryItem>

<GlossaryItem term="后处理">在渲染管线末端对全屏画面施加的处理（Bloom、景深、色彩校正），统一画面氛围。</GlossaryItem>
<GlossaryItem term="打击感">战斗特效的综合体验，由顿帧、震屏、特效爆发、音效四要素构成。</GlossaryItem>
</Glossary>
