## 直觉引入

粒子系统是游戏特效的地基。火焰、烟雾、爆炸、魔法弹——所有离散的视觉元素都由粒子模拟。Unity 的 ParticleSystem 组件像一台「粒子工厂」：你告诉它从哪发射、发射多少、怎么运动、长什么样，它就持续产出粒子。

最常见的入门错误是「参数全默认」——默认的白色方块粒子看起来毫无质感。关键在于配置 Shape（发射形状）、Emission（发射速率）、Renderer（材质混合模式）三大模块。

## 概念讲解

<Term def="Unity 中模拟粒子系统的核心组件">ParticleSystem</Term>由多个模块组成。

### 四大基本模块

| 模块 | 作用 | 关键参数 |
|---|---|---|
| Main | 全局参数 | Duration、Looping、Start Lifetime、Start Speed |
| Emission | 发射控制 | Rate over Time、Bursts |
| Shape | 发射形状 | Sphere、Cone、Box、Mesh |
| Renderer | 渲染设置 | Render Mode、Material、Trail |

<Term def="每秒持续发射的粒子数量">Rate over Time</Term>适合持续型特效。<Term def="在特定时间点一次性发射一批粒子">Bursts</Term>适合爆发型特效。

## 交互Demo

> 猜一猜：火焰特效的材质混合模式应该用什么？（提示：Additive 让重叠区域更亮）

<UvfParticleBasicsDiagram />

<Stepper>
<Step title="第一步：创建粒子系统">
GameObject → Effects → Particle System。默认是一个向上喷射白色方块的粒子系统。先改 Main Module：Duration=5s、Looping=true、Start Lifetime=1-2s 随机、Start Speed=2-4 随机。
</Step>
<Step title="第二步：配形状和发射">
Shape 设为 Cone（锥形），角度15度模拟火焰扩散。Emission Rate=30/s 持续发射。Start Size=0.3-0.8 随机让粒子大小不一。
</Step>
<Step title="第三步：配材质和混合">
Renderer 的 Material 用 Additive 混合模式贴图（柔边圆点）。配合 Color over Lifetime 让粒子从橙黄渐变到暗红再到透明。这就是一个基础火焰。
</Step>
</Stepper>

## 代码对照

```csharp
using UnityEngine;

// 粒子特效播放器：对象池版本
public class VfxPlayer : MonoBehaviour
{
    public GameObject firePrefab;
    private GameObject fireInstance;
    private ParticleSystem ps;

    void Start()
    {
        // 预创建实例（对象池思想）
        fireInstance = Instantiate(firePrefab, transform);
        fireInstance.SetActive(false);
        ps = fireInstance.GetComponent<ParticleSystem>();
    }

    // 在指定位置播放特效
    public void PlayAt(Vector3 pos, Quaternion rot)
    {
        fireInstance.transform.SetPositionAndRotation(pos, rot);
        fireInstance.SetActive(true);
        ps.Play();
    }

    // 停止并回收
    public void Stop()
    {
        ps.Stop(true, ParticleSystemStopBehavior.StopEmitting);
        // 等粒子消散后隐藏
        Invoke(nameof(Hide), ps.main.duration);
    }

    void Hide() => fireInstance.SetActive(false);
}
```

## 常见误区

<Callout type="trap">
**现象 →** 粒子特效看起来像一堆白色方块，毫无质感。
**原因 →** Renderer 的 Material 用了默认的 Default-Particle，且混合模式不是 Additive。
**修法 →** 换成带柔边圆点贴图的材质，混合模式设为 Additive（叠加）。Additive 让重叠粒子区域更亮，火焰、光效都靠这个模式产生发光感。再配合 Color over Lifetime 渐变颜色。
</Callout>

## 练习

<Exercises>
**问题**：Rate over Time 和 Bursts 有什么区别？各举一个使用场景。

<Answer>
Rate over Time 是每秒持续发射固定数量的粒子，适合持续型特效——如火焰持续燃烧、喷泉持续喷水、烟雾持续冒出。Bursts 是在特定时间点一次性发射一批粒子，适合爆发型特效——如爆炸瞬间喷出碎片、撞击瞬间迸发火花、闪雷瞬间光爆。实际中常组合：火焰用 Rate over Time 持续发射，爆炸瞬间用 Bursts 一次性发射50个碎片粒子。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="Main Module">ParticleSystem 的主模块，控制全局参数如 Duration（持续时间）、Looping（循环）、Start Lifetime（初始生命）、Start Speed（初始速度）。</GlossaryItem>
<GlossaryItem term="Emission">发射模块，控制粒子生成速率。Rate over Time 持续发射，Bursts 突发发射。</GlossaryItem>
<GlossaryItem term="Shape">形状模块，定义粒子发射的几何形状（球体、锥体、盒子等），决定粒子的初始方向和分布。</GlossaryItem>
<GlossaryItem term="Additive 混合">加法混合模式，重叠像素亮度叠加，适合发光、火焰等特效。与 Alpha 混合（正常透明）相对。</GlossaryItem>
</Glossary>
