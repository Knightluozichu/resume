## 直觉引入

粒子系统给了特效「形状」，Shader 给特效「质感」。同样是火焰——贴一张贴图是平面的，用 Shader 加 Fresnel 边缘光就有了立体发光感；角色死亡时直接消失很突兀，用溶解 Shader 逐渐消散才有魔法感。

Shader 特效三大经典：溶解让物体从有到无渐变消失，扭曲让画面产生热浪/空间撕裂感，发光让物体边缘产生光晕扩散。三者组合可以实现传送、冰冻碎裂、能量护盾等复杂特效。

## 概念讲解

### 三大经典 Shader 特效

| 特效 | 原理 | 关键参数 |
|---|---|---|
| 溶解 | 噪声值 vs 阈值，clip 丢弃像素 | _Threshold、_BurnColor、_BurnWidth |
| 扭曲 | UV 偏移采样屏幕颜色 | _DistortStrength、噪声贴图 |
| 发光 | Fresnel 边缘光 + Emission | _Power、_GlowColor |

<Term def="用噪声贴图与阈值比较来丢弃像素的 Shader 技术">溶解</Term>让物体逐渐消失。<Term def="通过偏移 UV 采样屏幕画面产生折射效果">扭曲</Term>模拟热浪和空间扰动。<Term def="利用视角与法线夹角在物体边缘产生发光">Fresnel 发光</Term>让边缘有光晕。

<Stepper>
<Step title="第一步：溶解 Shader">
片元着色器中 `clip(noise.r - _Threshold)`，阈值随时间从0到1递增。边缘 Burn 光：在阈值附近用 `step` 函数叠加 `_BurnColor`，让消散边缘有燃烧光。
</Step>
<Step title="第二步：扭曲 Shader">
用 GrabPass（Built-in）或 RenderTexture（URP）抓取屏幕，在片元着色器中 `uv += noise.r * _DistortStrength` 偏移采样坐标，画面产生折射/热浪效果。
</Step>
<Step title="第三步：发光 Shader">
Fresnel 公式 `pow(1 - dot(N, V), _Power)`，N 是法线 V 是视线方向。结果乘以 `_GlowColor` 叠加到最终颜色。配合 Emission 输出到 HDR，经 Bloom 后处理产生光晕扩散。
</Step>
</Stepper>

## 代码对照

```hlsl
// ShaderLab: 溶解特效（Built-in 管线）
Shader "Custom/Dissolve"
{
    Properties
    {
        _MainTex ("Texture", 2D) = "white" {}
        _NoiseTex ("Noise", 2D) = "white" {}
        _Threshold ("Threshold", Range(0, 1)) = 0
        _BurnColor ("Burn Color", Color) = (1, 0.5, 0, 1)
        _BurnWidth ("Burn Width", Range(0, 0.5)) = 0.1
    }
    SubShader
    {
        Tags { "RenderType"="Transparent" "Queue"="Transparent" }
        Pass
        {
            CGPROGRAM
            #pragma vertex vert
            #pragma fragment frag
            #include "UnityCG.cginc"

            struct appdata { float4 vertex:POSITION; float2 uv:TEXCOORD0; };
            struct v2f { float4 pos:SV_POSITION; float2 uv:TEXCOORD0; };

            sampler2D _MainTex, _NoiseTex;
            float _Threshold, _BurnWidth;
            fixed4 _BurnColor;

            v2f vert(appdata v) {
                v2f o;
                o.pos = UnityObjectToClipPos(v.vertex);
                o.uv = v.uv;
                return o;
            }

            fixed4 frag(v2f i) : SV_Target {
                float noise = tex2D(_NoiseTex, i.uv).r;
                float diff = noise - _Threshold;
                clip(diff); // 丢弃低于阈值的像素

                fixed4 col = tex2D(_MainTex, i.uv);
                // 边缘 Burn 光
                float burn = 1 - smoothstep(0, _BurnWidth, diff);
                col.rgb += _BurnColor.rgb * burn;
                return col;
            }
            ENDCG
        }
    }
}
```

```csharp
// C# 控制溶解进度
public class DissolveController : MonoBehaviour
{
    public Material dissolveMaterial;
    public float duration = 1.5f;

    public void StartDissolve()
    {
        StartCoroutine(DissolveRoutine());
    }

    IEnumerator DissolveRoutine()
    {
        float t = 0;
        while (t < duration)
        {
            t += Time.deltaTime;
            dissolveMaterial.SetFloat("_Threshold", t / duration);
            yield return null;
        }
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** 溶解特效看起来像「直接消失」，没有渐变过程。
**原因 →** 阈值变化太快，或者噪声贴图对比度太低（接近纯灰），导致大部分像素同时被 clip 掉。
**修法 →** 1）用高对比度噪声贴图（如 Perlin Noise，黑白分明）；2）阈值变化持续时间至少1秒以上；3）加边缘 Burn 光让消散边界可见——用 `smoothstep` 在阈值附近一定宽度内叠加发光色。
</Callout>

## 练习

<Exercises>
**问题**：如何用 Fresnel 效果实现物体边缘发光？写出核心 Shader 代码并解释每个变量的含义。

<Answer>
核心代码：`float3 viewDir = normalize(_WorldSpaceCameraPos - worldPos); float fresnel = pow(1.0 - saturate(dot(normal, viewDir)), _Power); float3 glow = fresnel * _GlowColor.rgb; finalColor += glow;`。变量含义：viewDir 是从物体顶点指向相机的方向；normal 是表面法线；dot(N, V) 在面向相机的面接近1，在边缘接近0；1-dot(N,V) 在边缘接近1；pow() 让边缘光更集中在轮廓线；_Power 控制光晕宽度（值越大光晕越窄）；_GlowColor 控制发光颜色。最终叠加到物体颜色上，配合 Emission 输出到 HDR，经 Bloom 后处理产生光晕扩散。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="溶解（Dissolve）">用噪声贴图与阈值比较，clip() 丢弃低于阈值的像素，让物体逐渐消失的 Shader 技术。边缘可加 Burn 光。</GlossaryItem>
<GlossaryItem term="Fresnel">视角与法线夹角越大（边缘）反射越强的物理现象，在 Shader 中用 `pow(1-dot(N,V), power)` 模拟，常用于边缘发光。</GlossaryItem>
<GlossaryItem term="GrabPass">Built-in 管线中抓取当前屏幕到纹理的 Pass，用于扭曲、折射等屏幕空间特效。URP 中用 RenderTexture 替代。</GlossaryItem>
<GlossaryItem term="Emission">材质的自发光通道，输出到 HDR 缓冲，配合 Bloom 后处理产生光晕扩散效果。</GlossaryItem>
</Glossary>
