## 数据链与最小实现

触发事件 → 位置法线 → 头部拖尾 → 命中爆发 → UI排序 → 池化回收 构成本章的主链。每个节点都记录输入来源、状态所有者、更新时间、输出消费者与首个失败信号。视觉系统只消费玩法事实，不自行决定命中、治疗、升级或传送结果。

```csharp
void SpawnHit(ContactPoint contact, EffectPool pool)
{
    Quaternion rotation = Quaternion.LookRotation(contact.normal);
    pool.Play("Hit", contact.point, rotation,
        onParticlesStopped: pool.Release);
}
```

现代实现可以替换旧粒子属性名称、材质接口或资源导入器，但迁移账本必须逐项写明“旧实现、替代实现、保留不变量、验证证据”。这样既避免把旧API当成当前最佳实践，也避免用新工具掩盖原案例缺失。
