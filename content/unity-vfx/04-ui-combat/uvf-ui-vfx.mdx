## 直觉引入

UI 特效是玩家与游戏交互的「视觉反馈层」——按钮点击有弹跳、面板弹出有滑动、伤害数字有飘字、受击时屏幕闪红。这些反馈让 UI 从「静态界面」变成「活的体验」。

UI 特效三大技术：UGUI 动画（DOTween 驱动 Transform 动画）、Canvas 粒子（粒子在 UI 层渲染）、屏幕反馈（震屏+闪屏+飘字）。三者配合构成完整的交互反馈。

## 概念讲解

<Term def="Unity 的 UI 系统，通过 Canvas 渲染 2D 界面元素">UGUI</Term>配合 DOTween 做动画。

<Term def="在 Canvas 上渲染粒子特效">UI 粒子</Term>需要正确配置 Render Mode。

<Term def="全屏视觉冲击反馈">屏幕反馈</Term>包括震屏、闪屏、飘字。

### 三大 UI 特效技术

| 技术 | 用途 | 工具 |
|---|---|---|
| UGUI 动画 | 按钮弹跳、面板滑入、脉冲提示 | DOTween |
| Canvas 粒子 | 金币飞出、技能图标光效、开箱光芒 | ParticleSystem + Canvas |
| 屏幕反馈 | 震屏、闪红、伤害飘字 | Camera Shake + Image Alpha + TextMeshPro |

<Stepper>
<Step title="第一步：UGUI 动画">
用 DOTween 驱动 UI 元素：按钮点击 `transform.DOScale(0.9f, 0.1f).SetEase(Ease.OutBack)` 弹跳，面板滑入 `rectTransform.DOAnchorPos(Vector2.zero, 0.3f).SetEase(Ease.OutBack)`。
</Step>
<Step title="第二步：Canvas 粒子">
Canvas 用 Screen Space - Camera 模式（非 Overlay），粒子系统正常渲染即可被相机捕获。或用专门的 UI Particle 组件。金币飞出用 ParticleSystem + Render Mode=Canvas。
</Step>
<Step title="第三步：屏幕反馈">
震屏：`camera.DoShakePosition(0.5f, 0.3f)`。闪屏：全屏红色 Image 的 Alpha 从1渐变到0。飘字：TextMeshPro 文本+DOTween 向上飘+渐隐，用对象池管理。
</Step>
</Stepper>

## 代码对照

```csharp
using UnityEngine;
using DG.Tweening;
using TMPro;

// UI 特效管理器：飘字+震屏+闪屏
public class UiVfxManager : MonoBehaviour
{
    public static UiVfxManager Instance;

    [Header("飘字")]
    public TextMeshProUGUI damageTextPrefab;
    public Transform canvasTransform;
    public int poolSize = 20;

    [Header("震屏")]
    public Camera mainCamera;
    public float shakeDuration = 0.3f;
    public float shakeStrength = 0.5f;

    [Header("闪屏")]
    public UnityEngine.UI.Image flashImage;

    private Queue<TextMeshProUGUI> textPool = new();

    void Awake()
    {
        Instance = this;
        // 预创建飘字对象池
        for (int i = 0; i < poolSize; i++)
        {
            var text = Instantiate(damageTextPrefab, canvasTransform);
            text.gameObject.SetActive(false);
            textPool.Enqueue(text);
        }
    }

    // 显示伤害飘字
    public void ShowDamage(Vector3 worldPos, int damage, bool isCrit = false)
    {
        var text = textPool.Dequeue();
        text.text = damage.ToString();
        text.color = isCrit ? Color.red : Color.white;
        text.fontSize = isCrit ? 48 : 32;

        // 世界坐标转屏幕坐标
        Vector2 screenPos = mainCamera.WorldToScreenPoint(worldPos);
        text.transform.position = screenPos;
        text.gameObject.SetActive(true);

        // 向上飘 + 渐隐
        text.transform.DOMoveY(screenPos.y + 80f, 0.8f)
            .SetEase(Ease.OutQuad);
        text.DOFade(0f, 0.8f).OnComplete(() =>
        {
            text.gameObject.SetActive(false);
            text.alpha = 1f;
            textPool.Enqueue(text);
        });
    }

    // 屏幕震屏
    public void ScreenShake(float multiplier = 1f)
    {
        mainCamera.DOShakePosition(
            shakeDuration,
            shakeStrength * multiplier);
    }

    // 屏幕闪红
    public void FlashScreen(Color color, float duration = 0.3f)
    {
        flashImage.color = color;
        flashImage.gameObject.SetActive(true);
        flashImage.DOFade(0f, duration).OnComplete(() =>
        {
            flashImage.gameObject.SetActive(false);
        });
    }
}
```

## 常见误区

<Callout type="trap">
**现象 →** 粒子特效在 UI 上看不到，3D 场景里正常。
**原因 →** Canvas 用了 Screen Space - Overlay 模式，标准 ParticleSystem 不渲染在 Overlay Canvas 上。
**修法 →** 改用 Screen Space - Camera 模式（Canvas 关联一个相机），粒子正常渲染。或使用专门的 UI Particle 方案（如 Unity 官方的 UI Particle 或第三方插件），它们可以在 Overlay Canvas 上渲染粒子。另外注意 UI 粒子的 SortingOrder 要设置正确，确保在 UI 元素之上。
</Callout>

## 练习

<Exercises>
**问题**：如何实现伤害飘字效果？如何用对象池管理大量飘字避免 GC？

<Answer>
1）飘字预制体：TextMeshPro 文本 + DOTween 动画（向上飘80px + 渐隐，0.8秒）。2）对象池：预创建20个飘字放入 Queue。需要时 Dequeue 取出，设置位置（WorldToScreenPoint 转屏幕坐标）、文字、颜色（暴击红色大字号）。3）播放 DOTween 动画，OnComplete 回调中 SetActive(false) 并 Enqueue 回收。4）暴击用红色48字号+额外震荡动画，普通用白色32字号。关键：每秒可能产生几十个飘字，Instantiate/Destroy 每次产生 GC，对象池让实例复用，GC 压力归零。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="DOTween">Unity 常用的 Tween 动画插件，用链式 API 驱动 Transform、颜色、透明度等属性的缓动动画，支持 Ease 曲线。</GlossaryItem>
<GlossaryItem term="Screen Space - Camera">Canvas 渲染模式之一，UI 渲染到指定相机，粒子等3D对象可以与 UI 交互渲染。Overlay 模式下粒子不可见。</GlossaryItem>
<GlossaryItem term="TextMeshPro">Unity 的高级文本渲染组件，支持 SDF 字体、富文本、动态字号，比原生 Text 清晰且功能强大，常用于飘字。</GlossaryItem>
<GlossaryItem term="Screen Shake">屏幕震屏，通过 Camera 抖动或 UI 偏移模拟冲击感，DOTween 的 DoShakePosition 是常用实现。</GlossaryItem>
</Glossary>
