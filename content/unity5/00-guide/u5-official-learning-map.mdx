## 可执行实现骨架

脚本边界显式保存状态，避免展示层直接决定玩法结果：

```csharp
using UnityEngine;

public sealed class ChapterController : MonoBehaviour
{
    [SerializeField] GameObject target;
    bool completed;

    public void ExecuteOnce()
    {
        if (completed || target == null) return;
        completed = true;
        ApplyChapterResult(target);
    }
}
```

测试记录必须能回到具体对象与事件：

```json
{
  "chapter": "u5-official-learning-map",
  "bookPages": "1-586",
  "chain": ["TPS场景","角色战斗","UI架构","世界系统","多人网络","真实感与数据"],
  "unity": "5.x-pinned",
  "scene": "fixed-tps-checkpoint",
  "normal": true,
  "boundary": true,
  "failureReplay": true
}
```
