## 核心模型与不可变条件

用模型、纹理、材质、Standard Shader、光源和天空盒构成 TPS 场景的几何与视觉基线。 主链为：**3D模型 → 纹理导入 → 材质 → PBR通道 → 光照 → 天空盒**。每一节点只消费前一节点已经验证的对象、状态或事件，不能从最终表现反推中间过程一定正确。

本页不可变条件是：**场景外观必须由可追溯模型、材质参数、光源和天空配置共同决定，不能依赖丢失引用或编辑器临时状态。** 任何“看起来能跑”的结果都必须经过重复加载、异常输入和边界时序检验。

## 可执行实现骨架

脚本边界显式保存状态，避免展示层直接决定玩法结果：

```csharp
using UnityEngine;

public sealed class ChapterController : MonoBehaviour
{
    [SerializeField] GameObject target;
    bool completed;

    public void ExecuteOnce()
    {
        if (completed || target == null) return;
        completed = true;
        ApplyChapterResult(target);
    }
}
```

测试记录必须能回到具体对象与事件：

```json
{
  "chapter": "u5-03-game-scene",
  "bookPages": "49-76",
  "chain": ["3D模型","纹理导入","材质","PBR通道","光照","天空盒"],
  "unity": "5.x-pinned",
  "scene": "fixed-tps-checkpoint",
  "normal": true,
  "boundary": true,
  "failureReplay": true
}
```

```text

PASS invariant=场景外观必须由可追溯模型、材质参数、光源和天空配置共同决定，不能依赖丢失引用或编辑器临时状态。
```
