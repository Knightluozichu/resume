本页不可变条件是：**角色移动、相机、动画与阴影必须共享明确坐标和更新时序，在不同帧率下保持相同玩法结果。** 任何“看起来能跑”的结果都必须经过重复加载、异常输入和边界时序检验。

## 可执行实现骨架

脚本边界显式保存状态，避免展示层直接决定玩法结果：

```csharp
using UnityEngine;

public sealed class ChapterController : MonoBehaviour
{
    [SerializeField] GameObject target;
    bool completed;

    public void ExecuteOnce()
    {
        if (completed || target == null) return;
        completed = true;
        ApplyChapterResult(target);
    }
}
```

测试记录必须能回到具体对象与事件：

```json
{
  "chapter": "u5-04-player-character",
  "bookPages": "77-117",
  "chain": ["角色模型","组件缓存","输入向量","移动旋转","相机跟随","动画阴影"],
  "unity": "5.x-pinned",
  "scene": "fixed-tps-checkpoint",
  "normal": true,
  "boundary": true,
  "failureReplay": true
}
```

签发输出同时保留通过值与拒绝原因：

```text
PASS context=version+scene+prefab+input
PASS chain=角色模型 -> 组件缓存 -> 输入向量 -> 移动旋转 -> 相机跟随 -> 动画阴影
PASS invariant=角色移动、相机、动画与阴影必须共享明确坐标和更新时序，在不同帧率下保持相同玩法结果。
REJECT duplicate-event | stale-object | changed-scene | missing-cleanup
```
