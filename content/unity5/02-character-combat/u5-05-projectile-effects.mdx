## 可执行实现骨架

脚本边界显式保存状态，避免展示层直接决定玩法结果：

```csharp
using UnityEngine;

public sealed class ChapterController : MonoBehaviour
{
    [SerializeField] GameObject target;
    bool completed;

    public void ExecuteOnce()
    {
        if (completed || target == null) return;
        completed = true;
        ApplyChapterResult(target);
    }
}
```

测试记录必须能回到具体对象与事件：

```json
{
  "chapter": "u5-05-projectile-effects",
  "bookPages": "119-170",
  "chain": ["输入发射","子弹生成","刚体运动","碰撞感知","伤害结算","视听反馈"],
  "unity": "5.x-pinned",
  "scene": "fixed-tps-checkpoint",
  "normal": true,
  "boundary": true,
  "failureReplay": true
}
```

