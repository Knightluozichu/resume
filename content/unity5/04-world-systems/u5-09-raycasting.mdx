## 核心模型与不可变条件

用射线起点、方向、距离、LayerMask 和命中信息实现油桶爆炸与激光束交互。 主链为：**射线来源 → 方向距离 → LayerMask → 命中信息 → 玩法结算 → 激光表现**。每一节点只消费前一节点已经验证的对象、状态或事件，不能从最终表现反推中间过程一定正确。

本页不可变条件是：**射线查询必须限定空间、层和触发器策略，命中结果只能驱动一次合法玩法结算。** 任何“看起来能跑”的结果都必须经过重复加载、异常输入和边界时序检验。

## 可执行实现骨架

脚本边界显式保存状态，避免展示层直接决定玩法结果：

```csharp
using UnityEngine;

public sealed class ChapterController : MonoBehaviour
{
    [SerializeField] GameObject target;
    bool completed;

    public void ExecuteOnce()
    {
        if (completed || target == null) return;
        completed = true;
        ApplyChapterResult(target);
    }
}
```

测试记录必须能回到具体对象与事件：

```json
{
  "chapter": "u5-09-raycasting",
  "bookPages": "313-328",
  "chain": ["射线来源","方向距离","LayerMask","命中信息","玩法结算","激光表现"],
  "unity": "5.x-pinned",
  "scene": "fixed-tps-checkpoint",
  "normal": true,
  "boundary": true,
  "failureReplay": true
}
```

签发输出同时保留通过值与拒绝原因：

```text
PASS context=version+scene+prefab+input
PASS chain=射线来源 -> 方向距离 -> LayerMask -> 命中信息 -> 玩法结算 -> 激光表现
PASS invariant=射线查询必须限定空间、层和触发器策略，命中结果只能驱动一次合法玩法结算。
REJECT duplicate-event | stale-object | changed-scene | missing-cleanup
```
