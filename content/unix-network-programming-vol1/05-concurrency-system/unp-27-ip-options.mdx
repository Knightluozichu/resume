第27章 IP选项围绕IPv4选项、IPv4源路径选项、IPv6扩展首部、IPv6步跳选项和目的地选项、IPv6路由首部、IPv6粘附选项建立从套接字接口到分组、内核状态与清理结果的证据链。

本页核心不变量是：**首部长度、字节序、校验和与链路类型一致，捕获过滤边界明确，实验只使用最小网络权限。** 它同时约束正常、边界、故障和恢复样本。应用函数返回成功只是一条证据，还要检查地址长度、字节序、短计数、EINTR/EAGAIN、套接字状态、内核队列、分组顺序与异步清理。

实验台账至少包含内核/库版本、命名空间、接口与路由、地址端口、入口参数、描述符所有者、预期状态、实际返回与errno、首个分组分叉、内核队列和清理结果十一列。性能样本还固定并发度、连接复用、预热、输入规模、采样窗口和延迟分位；抓包必须记录过滤器、snaplen与时间基准。

## 常见误区

  只看应用最终文本，不检查短读写、errno、套接字状态、内核队列与线上分组是否一致。

</Callout>

## 四类样本与验收

| 样本 | 只改变什么                 | 必查证据              | 通过条件   |
| ---- | -------------------------- | --------------------- | ---------- |
| 基线 | 固定网络、地址与输入       | API、状态、队列与分组 | 与预测一致 |
| 边界 | 缓冲、MTU、并发或时序      | 首个阻塞、截断或拒绝  | 边界可解释 |
| 故障 | 丢包、复位、信号或路径故障 | errno、首包与责任层   | 故障可定位 |
| 恢复 | 关闭、回收、撤销网络设置   | 残留端点与同输入重放  | 回到基线   |
