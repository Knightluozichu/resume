## 为什么只记结论不足以掌握传感器融合

学习“传感器融合”时，第一步不是记住结论，而是冻结输入、上下文、版本和成功标准。只有这些条件明确，传感器融合的含义才不会随着样例变化。正文已有的概念说明要与结构图、运行轨迹和失败样本互相印证，不能只凭最终输出看似正确就宣布完成。

结构分析从前融合与后融合开始：列出参与者、职责、连接方向、生命周期和所有权，再沿正常路径追踪数据或控制流。每一条边都要说明为什么存在、谁创建、谁消费、谁负责清理；如果边界被跨越，必须能在证据中找到第一处异常。

机制验证要把卡尔曼滤波写成可以执行的条件。正常样本证明主路径，恰好边界样本验证等号和空值，单故障样本只破坏一个假设。三类样本使用同一份观察指标，避免因为测试口径变化而把偶然结果误认成规律。

成本分析同时记录时间、空间、延迟、耦合、可维护性和不可逆操作。数据关联与时空对齐不是一句“可能失败”，而是可复现输入、预期停点、实际轨迹、错误分类与清理步骤。任何自动重试都要有次数、预算和幂等边界。

方案比较不能只列优点。需要给出直接实现、当前方案和至少一个替代方案，逐项比较复杂度、扩展点、故障隔离和团队认知成本。当问题规模很小或变化轴稳定时，更简单的实现往往更好；模式与框架必须由真实变化压力证明。

实现阶段把大结论拆成可检查的中间产物：配置快照、结构清单、状态转移、输入输出样本、日志摘要和测试结果。每个产物带来源与生成命令，下一阶段只消费已通过门禁的版本，避免旧缓存或隐式默认值污染结论。

解释结果时必须区分相关性与因果性、接口承诺与实现细节、设计意图与运行事实。对“小结与练习”的判断要由独立证据支持，并明确适用范围；一旦输入分布、版本、硬件或组织边界改变，就重新运行最小实验。

复盘从首个分叉开始，而不是从最后一个报错倒推。先比较冻结输入，再比较第一份结构化中间产物，随后检查状态、约束和副作用。这样可以把复杂系统的排错范围收缩到一个阶段，避免在多个层次同时修改造成新的不确定性。

迁移到真实项目时，先选择一个最小但有代表性的切片，保存改造前基线，再逐步引入“传感器融合”中的机制。每一步只改变一个变量并保留回滚点；性能、正确性、安全性和可理解性至少各有一项可量化指标。

最终验收要求读者能脱离页面重新画出结构、口述关键链路、实现最小版本、构造一个反例并解释失败位置。若只能复述名词而不能预测中间状态，说明知识仍停留在识记层，需要回到图示和实验重新验证。

```ts
type Evidence = { stage: string; expected: string; actual: string };

function verify(sample: unknown, expected: readonly Evidence[]) {
  const trace = runFromCleanState(sample);
  return expected.find((item, index) => trace[index]?.actual !== item.expected);
```

## 术语表


## 传感器融合

多传感器各自有盲区，融合的目标是把它们的观测合并成一个比任何单一来源都更可信的整体估计。融合不是简单取平均，而是要解决「这些观测是不是同一个目标」「它们的时间和空间基准对不对齐」两个前置问题，再用滤波把带噪声的观测收敛到稳定估计。

## 前融合与后融合

在数据层合并：把摄像头像素、雷达点云、激光雷达点云在融合前就拼到一起，送入统一的感知模型。它的优势是信息保留完整——模型能看到所有原始细节，理论上限高。代价是对算力与时空对齐要求极高，且任一传感器故障会污染整体输入。

在目标层合并：每个传感器先各自跑出自己的检测/跟踪结果（目标的位置、速度、类别），再由融合模块把这些目标级结果按关联规则合并。它的优势是模块解耦、算力负担轻、单传感器故障影响可控。代价是原始信息在各自处理时已丢失，融合上限受限。

工程上常两者混合：关键目标用前融合保精度，外围目标用后融合省算力。

## 卡尔曼滤波

是融合的核心数学工具。它把状态估计分成两步循环。

预测步：根据运动模型（如匀速模型）用上一时刻状态推算当前状态，同时把不确定性（协方差）放大——因为预测引入了过程噪声。

更新步：拿到传感器观测后，计算预测与观测的差值，用卡尔曼增益决定「更信预测还是更信观测」——观测越准（观测噪声越小），增益越大、越偏向观测。更新后的状态既被预测约束（运动连续性）又被观测校正（测量真实性），不确定性收敛。

多传感器场景下，不同传感器的观测轮流进入更新步，状态估计在多个来源间不断修正，最终收敛到比任何单一传感器都准的估计。扩展卡尔曼滤波（EKF）处理非线性运动模型，无迹卡尔曼滤波（UKF）用采样点逼近非线性传播，是工程常用变体。

## 数据关联与时空对齐

融合正确性依赖两个前置工程。时空对齐：不同传感器的采样频率、时间戳、坐标系都不同，必须先把它们对齐到统一的时间基准与空间坐标系——时间上靠时间戳同步与插值，空间上靠外参标定把各传感器坐标变换到车体坐标系。：判断雷达看到的一个回波与摄像头看到的一个框是不是同一辆车，常用最近邻或匈牙利匹配。关联错了，滤波会把两个目标的状态混算，越滤越乱。


## 小结与练习

- 前融合在数据层合并、信息完整但算力与对齐要求高；后融合在目标层合并、解耦轻量但上限受限
- 卡尔曼滤波分预测步（运动模型推算、不确定性放大）与更新步（观测校正、增益定权重），循环收敛
- 时空对齐统一各传感器的时间戳与坐标系，数据关联判断观测是否同一目标
- 融合出问题先查对齐与关联，再调滤波参数；错误关联比缺观测危害更大
