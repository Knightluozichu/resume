## 为什么只记结论不足以掌握车辆控制

学习“车辆控制”时，第一步不是记住结论，而是冻结输入、上下文、版本和成功标准。只有这些条件明确，车辆控制的含义才不会随着样例变化。正文已有的概念说明要与结构图、运行轨迹和失败样本互相印证，不能只凭最终输出看似正确就宣布完成。

结构分析从纵向控制开始：列出参与者、职责、连接方向、生命周期和所有权，再沿正常路径追踪数据或控制流。每一条边都要说明为什么存在、谁创建、谁消费、谁负责清理；如果边界被跨越，必须能在证据中找到第一处异常。

机制验证要把横向控制写成可以执行的条件。正常样本证明主路径，恰好边界样本验证等号和空值，单故障样本只破坏一个假设。三类样本使用同一份观察指标，避免因为测试口径变化而把偶然结果误认成规律。

成本分析同时记录时间、空间、延迟、耦合、可维护性和不可逆操作。反馈回路不是一句“可能失败”，而是可复现输入、预期停点、实际轨迹、错误分类与清理步骤。任何自动重试都要有次数、预算和幂等边界。

方案比较不能只列优点。需要给出直接实现、当前方案和至少一个替代方案，逐项比较复杂度、扩展点、故障隔离和团队认知成本。当问题规模很小或变化轴稳定时，更简单的实现往往更好；模式与框架必须由真实变化压力证明。

实现阶段把大结论拆成可检查的中间产物：配置快照、结构清单、状态转移、输入输出样本、日志摘要和测试结果。每个产物带来源与生成命令，下一阶段只消费已通过门禁的版本，避免旧缓存或隐式默认值污染结论。

解释结果时必须区分相关性与因果性、接口承诺与实现细节、设计意图与运行事实。对“小结与练习”的判断要由独立证据支持，并明确适用范围；一旦输入分布、版本、硬件或组织边界改变，就重新运行最小实验。

复盘从首个分叉开始，而不是从最后一个报错倒推。先比较冻结输入，再比较第一份结构化中间产物，随后检查状态、约束和副作用。这样可以把复杂系统的排错范围收缩到一个阶段，避免在多个层次同时修改造成新的不确定性。

迁移到真实项目时，先选择一个最小但有代表性的切片，保存改造前基线，再逐步引入“车辆控制”中的机制。每一步只改变一个变量并保留回滚点；性能、正确性、安全性和可理解性至少各有一项可量化指标。

最终验收要求读者能脱离页面重新画出结构、口述关键链路、实现最小版本、构造一个反例并解释失败位置。若只能复述名词而不能预测中间状态，说明知识仍停留在识记层，需要回到图示和实验重新验证。

function verify(sample: unknown, expected: readonly Evidence[]) {
  const trace = runFromCleanState(sample);
  return expected.find((item, index) => trace[index]?.actual !== item.expected);

## 术语表


## 车辆控制

规划给出的是「该走哪条轨迹」，控制负责把轨迹变成方向盘转角与油门刹车踏板开度。控制分纵向与横向两个独立又耦合的子系统：纵向管速度（油门与刹车），横向管方向（方向盘）。

## 纵向控制

的目标是让实际车速跟踪规划给的目标速度。主流用 PID
控制：算出目标速度与实际速度的误差，按比例（P）、积分（I）、微分（D）三项加权求出油门或刹车开度。比例项快速消除当前误差，积分项消除稳态误差（如上坡时持续补油门），微分项抑制超调与震荡。

纵向控制的难点是执行器非线性：油门开度与加速度不是线性关系，低速蠕行与高速巡航的增益差异大，刹车与油门切换有间隙。工程上常用增益调度——不同车速区间用不同 PID 参数——或前馈补偿（用规划加速度直接预判油门）来改善。

## 横向控制

的目标是让车辆沿规划轨迹走，核心是消除横向偏移与航向误差。它依赖车辆动力学模型描述「给定转角与车速，车辆怎么动」。

是最常用的简化模型。它假设左右轮合并成中线上前后两个轮，忽略车身侧倾与载荷转移，用横摆角速度与质心侧偏角两个状态描述横向运动。这个简化在常规车速与转向角下足够准确，且计算量小，是横向控制的基础。高速大转向时模型失准，需用更复杂模型。

横向控制的算法分两类。几何法（如 Pure Pursuit 纯跟踪）靠几何关系算转角，简单但对曲率突变敏感、高速易震荡。模型预测控制（MPC）在当前时刻用动力学模型预测未来若干步的车辆轨迹，优化转角序列使预测轨迹贴合目标，只执行第一步再滚动优化。MPC 能显式处理约束（方向盘转角与转速上限）并预判曲率，平滑性远优于 PID 与几何法，是高阶自动驾驶横向控制的主流。

## 反馈回路

纵向与横向都是闭环反馈控制：传感器量出实际状态（车速、位置、航向），与目标求误差，控制器算执行量，执行器改变车辆状态，再量、再算——循环收敛到目标。反馈回路是控制稳定的根本：没有反馈就是开环，任何扰动（路面坡度、风、轮胎磨损）都会让车偏离；有反馈就能持续修正。


## 小结与练习

- 纵向控制用 PID 调油门刹车跟踪目标速度，难点是执行器非线性，用增益调度与前馈补偿
- 横向控制用自行车模型描述动力学，MPC 预测优化转角序列，优于几何法与 PID
- 自行车模型把四轮简化为两轮、用横摆与侧偏描述横向运动，常规工况够准且算量小
- 反馈回路是控制稳定根本：量状态、求误差、算执行量、改状态、循环收敛
