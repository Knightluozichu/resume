## 机制拆解

### 1. 建立机制边界

Reflect.get传入receiver可让访问器中的this继续指向代理；set时比较target与toRaw(receiver)，避免原型链上的一次赋值触发两次。has、ownKeys和deleteProperty分别对应in、遍历和删除依赖。

先预测：如果省略这一层，依赖、节点身份、任务顺序或请求状态会在哪里首次偏离？

### 2. 处理关键算法

数组索引新增会影响length，缩短length会使越界索引失效；includes等查找要在代理和原始数组上兼容，push等会读写length并可能自触发，需要暂停追踪。

先预测：如果省略这一层，依赖、节点身份、任务顺序或请求状态会在哪里首次偏离？

### 3. 签发失败与恢复

Map和Set方法依赖正确this，因此要返回包装函数。get追踪键，size和迭代追踪结构依赖，set区分新增与修改；写入前把代理值还原，避免原始集合被响应代理污染。

先预测：如果省略这一层，依赖、节点身份、任务顺序或请求状态会在哪里首次偏离？

## 最小可运行实验

```js
const reactiveMap = new WeakMap();
function reactive(target) {
  if (reactiveMap.has(target)) return reactiveMap.get(target);
  const proxy = new Proxy(target, mutableHandlers);
  reactiveMap.set(target, proxy);
  return proxy;
}
```

## 常见误区与故障注入

<Callout type="trap">
  **误区一：代理Object只拦截get和set，删除属性或for-in变化时视图不更新。**
  必须保存输入、执行轨迹和首偏离点，而不是只比较最终结果。
</Callout>

<Callout type="trap">

## 小结

- **Proxy**：拦截对象基本操作并把读取、写入、遍历等行为转交处理器的代理对象。
- **Reflect**：以函数形式执行对象内部操作并允许显式传入接收者的标准API。
- **深响应**：递归或按需把嵌套对象转换为响应式代理的策略。
- **只读**：允许读取但拒绝或警告写入的代理语义。
- **集合代理**：为Map、Set等集合方法建立正确this、追踪与触发语义的包装。
