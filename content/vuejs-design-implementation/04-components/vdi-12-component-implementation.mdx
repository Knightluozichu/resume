## 机制拆解

### 1. 建立机制边界

实例保存state、props、isMounted、subTree和mounted钩子。首次effect执行调用render并挂载子树，之后状态变化得到新subTree并patch旧树；currentInstance只在setup和生命周期注册期间有效。

### 2. 处理关键算法

父组件更新时比较新旧组件VNode，若props变化则复用实例并更新浅响应props，再调度子组件被动更新。attrs与props按声明拆分，props只读语义不能阻止父级提供新值。

### 3. 签发失败与恢复

setup接收浅只读props和emit、slots等上下文，返回函数可作为render，返回对象则暴露给渲染上下文。slots是返回VNode数组的函数，避免父级内容在错误组件上下文提前求值。

## 最小可运行实验

```js
const instance = {
  state: reactive(data()),
  props: shallowReactive(props),
  isMounted: false,
  subTree: null,
};
effect(() => {
  const subTree = render.call(renderContext);
  instance.isMounted
    ? patch(instance.subTree, subTree, container)
    : patch(null, subTree, container);
  instance.subTree = subTree;
  instance.isMounted = true;
});
```
