## 直觉引入

把一个 Vue 项目想象成一栋大楼。你先要打地基——数据怎么变就怎么响应、模板怎么描述界面（基础语法）；然后立柱子——界面怎么拆成可复用的组件、逻辑怎么抽成 Hooks（组件体系）；接着拉电线——跨组件的状态怎么共享、页面之间怎么跳转与鉴权（状态路由）；再装门窗——首屏怎么渲染更快、怎么打包部署上线（工程化）；最后做验收——把十章知识串成一张图谱（总复习）。本书回答的就是这些「从能渲染到能上线」的 Vue 工程问题。

## 四阶段递进

<Term def="Vue 应用是以响应式系统为数据驱动核心、用组件树组织界面、靠状态管理与路由连接多视图、经 SSR/构建部署交付到线上的分层体系。">Vue 工程体系</Term>的学习可以拆成四个递进阶段。**基础语法**包括响应式系统与模板语法——它们解决「数据变了视图怎么自动更新」和「界面怎么声明式描述」，是所有上层逻辑的基底。**组件体系**包括组件设计模式与 Composition API——它们决定「界面怎么拆」和「逻辑怎么复用」。**状态路由**包括 Vuex/Pinia 与 Vue Router——它们让应用「能共享状态」和「能多页导航」。**工程化**包括 SSR/SSG 与构建部署——它们连接「应用与世界」和「应用与生产环境」。

```javascript
// 一次「用户点击 → 数据更新 → 视图刷新 → 上线交付」的 Vue 运行时旅程
import { ref } from "vue";

const count = ref(0); // 1. 基础层：ref 创建响应式数据（第 2 章响应式系统）

// 2. 模板层：{{ count }} 编译成 render，数据变触发 patch（第 3 章模板语法）
//   <button @click="count++">{{ count }}</button>

// 3. 组件层：点击逻辑抽成 useCounter() 跨组件复用（第 4-5 章）
function useCounter(initial = 0) {
  const count = ref(initial);
  const increment = () => count.value++;
  return { count, increment };
}

// 4. 状态路由层：登录态存 Pinia，跳转前 beforeEach 鉴权（第 6-7 章）
// 5. 工程化层：详情页 SSR 直出，Vite 打包上 CDN（第 8-9 章）
```

## 常见误区

<Callout type="trap">
**误区：会写 Vue 组件就等于懂 Vue 工程化。** 组件只是表层——能搭模板、写 setup、调 API，照文档抄就会。真正的难点在工程化判断力：响应式为什么会失效（解构丢响应式、ref 忘 `.value`、reactive 整体替换）；组件边界怎么划才不致 props 爆炸；该用全局状态还是局部状态；路由守卫放鉴权还是组件内放；SSR 的 hydration 不一致怎么排查；分包策略对首屏的影响。这些是「项目跑起来后」才显现的问题，也是中高级面试与生产实战的真正考点。把组件当终点的人，做的应用能跑但难维护；把工程化当核心的人，才能做出可控、可扩展、可上线的 Vue 项目。
</Callout>

<Exercises>
**问题 1**：全书四阶段是什么？为什么是这个顺序？

<Answer>
基础语法（响应式/模板）→ 组件体系（组件设计/Composition API）→ 状态路由（Vuex·Pinia/路由）→ 工程化（SSR·SSG/构建部署）→ 总复习。顺序由依赖关系决定：没有响应式和模板就没有可运行的视图；没有视图就没有组件可拆；没有组件就没有通信与状态共享的需求；没有状态与路由就做不出多页面应用；没有工程化就无法交付上线。先「能渲染」，再「能拆分」，然后「能共享与导航」，接着「能服务端渲染」，最后「能上线」。
</Answer>

**问题 2（实现题）**：用「一次点击到上线交付」的旅程，说明全书十章各自扮演什么角色。

<Answer>
用户点击按钮：①响应式系统——`state.count++` 经 Proxy.set 拦截，trigger 派发 effect（第 2 章）；②模板语法——`{{ count }}` 经编译生成 render，新 VNode 经 patch 更新 DOM（第 3 章）；③组件设计——点击在 Child 内，`emit('add')` 冒泡到 Parent（第 4 章）；④Composition API——计数逻辑抽 `useCounter()` 复用（第 5 章）；⑤状态管理——用户信息存 Pinia 跨组件共享（第 6 章）；⑥路由守卫——跳转详情页前 beforeEach 鉴权（第 7 章）；⑦SSR——详情页首屏直出利于 SEO（第 8 章）；⑧构建部署——Vite 打包分包、产物上 CDN、CI/CD 发布（第 9 章）。学习地图（第 1 章）给方向，总复习（第 10 章）串闭环。
</Answer>
</Exercises>
