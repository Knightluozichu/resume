## 核心概念与所有权

<Term def="用双花括号把表达式结果转成文本节点并安全显示的绑定方式。">文本插值</Term>、<Term def="把表达式结果绑定到元素属性、组件prop、类名或样式的指令。">v-bind</Term>、<Term def="声明DOM或组件事件监听器，并可附加事件修饰符的指令。">v-on</Term>、<Term def="按控件或组件约定组合值输入与更新事件的双向绑定语法糖。">v-model</Term>、<Term def="在列表更新中标识节点身份、帮助复用和移动判断的稳定值。">key</Term>。
这些概念不是孤立名词：每一个都要回答“输入由谁创建、状态保存在哪里、哪个事件可以修改、失败如何传播、离开页面后由谁清理”。

## 机制拆解

### 1. 内容、属性与事件分工

文本插值默认转义HTML，v-html会写入原始内容并扩大注入风险；v-bind提供属性值，v-on把用户动作转成方法调用。模板表达式应保持轻量，复杂转换放在计算属性中，副作用放在方法或侦听器中。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 2. v-model是一组明确契约

在文本框上，v-model通常组合value与input；在自定义组件上，Vue 2默认组合value prop与input事件。lazy、number和trim改变提交时机或规范化方式，必须用空值、中文输入和非法数字验证。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 3. 结构指令与身份

v-if真正创建和销毁分支，v-show保留节点只切换显示；高频切换通常偏向v-show。v-for必须使用与业务实体一致的稳定key，数组索引无法在插入、排序后保持身份，可能让输入框或组件状态错位。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

## 最小可运行实验

下面的最小实现聚焦本页核心。先在独立页面运行，再加入空输入、快速重复操作和销毁重建；不要直接把演示代码当成完整生产方案。

```js
<div id="app">
  <input v-model.trim="query" @keyup.enter="search">
  <article v-for="item in results" :key="item.id">
    {{ item.title }}
  </article>
</div>
```

## 常见误区与故障注入

<Callout type="trap">
  **误区一：把不可信字符串直接交给v-html，既跳过文本转义又让内容边界失去审计。**
  最终截图可能仍正确，但状态轨迹、资源数量或下一次交互已经偏离；必须保存首次偏离前后的输入与事件。
</Callout>

<Callout type="trap">
  **误区二：在可重排列表中使用数组索引作key，导致DOM和组件内部状态绑定到错误实体。**
  用正常样本无法暴露这一问题，要增加边界、失败和恢复样本，并在销毁后检查残留任务。
</Callout>

## 验收矩阵

| 样本 | 输入与环境变化               | 预期状态       | 通过条件               |
| ---- | ---------------------------- | -------------- | ---------------------- |
| 正常 | 合法数据、稳定身份、固定版本 | 完成主链       | 输出与状态摘要一致     |
| 边界 | 空值、极限数量、快速重复事件 | 有界退化       | 不越界、不重复、不阻塞 |
| 失败 | 请求拒绝、旧缓存、资源缺失   | 首偏离点停止   | 错误显式传播或降级     |
| 恢复 | 清除故障后重放同一输入       | 收敛到正常轨迹 | 无陈旧任务和资源泄漏   |

## 小结

- **文本插值**：用双花括号把表达式结果转成文本节点并安全显示的绑定方式。
- **v-bind**：把表达式结果绑定到元素属性、组件prop、类名或样式的指令。
- **v-on**：声明DOM或组件事件监听器，并可附加事件修饰符的指令。
- **v-model**：按控件或组件约定组合值输入与更新事件的双向绑定语法糖。
- **key**：在列表更新中标识节点身份、帮助复用和移动判断的稳定值。
- 本页已经把官方目录、机制链、最小实现、故障注入和恢复证据放在同一条验收路径上。
- 原书Vue 2技术语境与现代迁移说明保持清晰边界。
