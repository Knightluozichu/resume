## 机制拆解

### 1. 数据、属性与方法的所有权

props由父组件拥有，子组件只能提出更新；data由当前实例拥有；methods表示命令。把prop复制进data会制造两个事实来源，除非明确建立一次性初始化或编辑草稿边界。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 2. computed和watch按问题选择

computed回答由哪些状态可以纯粹推导当前值，并利用缓存避免重复计算；watch回答状态变化后要执行什么副作用，例如请求、持久化或第三方同步。用watch回写另一个状态常常意味着派生关系应改为computed。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 3. 渲染与复用需要可追踪来源

el、template和render存在优先级，最终都生成虚拟节点。过滤器适合简单展示转换，自定义指令只处理DOM细节，组件承担可组合界面。混入合并规则隐蔽，使用时要记录冲突、钩子顺序和迁移出口。

## 最小可运行实验

下面的最小实现聚焦本页核心。先在独立页面运行，再加入空输入、快速重复操作和销毁重建；不要直接把演示代码当成完整生产方案。

```js
new Vue({
  props: { price: Number, quantity: Number },
  computed: {
    total() {
      return this.price * this.quantity;
    },
  },
  watch: {
    total(value) {
      analytics.record("total", value);
    },
  },
});
```
