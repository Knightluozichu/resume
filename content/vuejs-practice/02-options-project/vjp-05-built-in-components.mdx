## 核心概念与所有权

<Term def="通过is在多个组件类型之间切换当前渲染目标的内置能力。">动态组件</Term>、<Term def="由父级提供内容、由子级决定放置位置的内容分发契约。">插槽</Term>、<Term def="缓存非活动组件实例并触发激活与停用钩子的抽象组件。">keep-alive</Term>、<Term def="为单个元素或组件的进入、离开过程协调类名和钩子的抽象组件。">transition</Term>、<Term def="由组件类型和key共同确定、影响实例复用与状态保存的标识。">组件身份</Term>。
这些概念不是孤立名词：每一个都要回答“输入由谁创建、状态保存在哪里、哪个事件可以修改、失败如何传播、离开页面后由谁清理”。

|   # | 概念       | 工程含义                                                   |
| --: | ---------- | ---------------------------------------------------------- |
|   1 | 动态组件   | 通过is在多个组件类型之间切换当前渲染目标的内置能力。       |
|   2 | 插槽       | 由父级提供内容、由子级决定放置位置的内容分发契约。         |
|   3 | keep-alive | 缓存非活动组件实例并触发激活与停用钩子的抽象组件。         |
|   4 | transition | 为单个元素或组件的进入、离开过程协调类名和钩子的抽象组件。 |
|   5 | 组件身份   | 由组件类型和key共同确定、影响实例复用与状态保存的标识。    |

## 机制拆解

### 1. 动态选择不等于重建

component的is决定渲染类型，key进一步决定同类型实例是否复用。切换表单步骤时，错误的身份策略会保留不该保留的输入，或销毁本应缓存的状态。先定义业务实体身份，再决定key和缓存。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 2. 插槽分开内容与布局所有权

父组件拥有业务内容和数据，子组件拥有版式与插槽位置。具名插槽表达多个区域，作用域插槽把子组件计算出的局部上下文以受控参数交给父级渲染，避免直接读取子组件内部状态。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 3. 缓存与过渡都是生命周期

keep-alive中的组件不会普通销毁，而会activated和deactivated；订阅和轮询要考虑停用状态。transition等待CSS或JS过渡结束，多节点切换要有稳定key和明确mode，否则旧新节点可能同时占位。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

## 最小可运行实验

下面的最小实现聚焦本页核心。先在独立页面运行，再加入空输入、快速重复操作和销毁重建；不要直接把演示代码当成完整生产方案。

```js

  <component :is="currentView" :key="recordId">
    <template #toolbar>操作区</template>
  </component>
</keep-alive>
```

## 常见误区与故障注入

<Callout type="trap">
  **误区一：把keep-alive当成无上限页面缓存，既不设include也不处理deactivated中的后台任务。**
  最终截图可能仍正确，但状态轨迹、资源数量或下一次交互已经偏离；必须保存首次偏离前后的输入与事件。
</Callout>

<Callout type="trap">
  **误区二：多节点过渡没有稳定key，框架复用旧节点后进入和离开类名落在错误对象上。**
  用正常样本无法暴露这一问题，要增加边界、失败和恢复样本，并在销毁后检查残留任务。
</Callout>

## 验收矩阵

| 样本 | 输入与环境变化               | 预期状态       | 通过条件               |
| ---- | ---------------------------- | -------------- | ---------------------- |
| 正常 | 合法数据、稳定身份、固定版本 | 完成主链       | 输出与状态摘要一致     |
| 边界 | 空值、极限数量、快速重复事件 | 有界退化       | 不越界、不重复、不阻塞 |
| 失败 | 请求拒绝、旧缓存、资源缺失   | 首偏离点停止   | 错误显式传播或降级     |
| 恢复 | 清除故障后重放同一输入       | 收敛到正常轨迹 | 无陈旧任务和资源泄漏   |

## 小结

- **动态组件**：通过is在多个组件类型之间切换当前渲染目标的内置能力。
- **插槽**：由父级提供内容、由子级决定放置位置的内容分发契约。
- **keep-alive**：缓存非活动组件实例并触发激活与停用钩子的抽象组件。
- **transition**：为单个元素或组件的进入、离开过程协调类名和钩子的抽象组件。
- **组件身份**：由组件类型和key共同确定、影响实例复用与状态保存的标识。
