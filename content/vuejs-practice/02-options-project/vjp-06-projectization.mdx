## 机制拆解

### 1. 项目目录表达责任

入口负责挂载根实例，组件目录承载可复用界面，视图目录对应路由页面，store集中真正共享的状态，静态资源与构建配置保持独立。目录不是装饰；它应让新增功能的状态、路由和视图落点可预测。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 2. 路由把URL变成可恢复状态

history或hash变化后，路由器匹配记录、解析参数并渲染对应组件。参数、查询和导航守卫都应可序列化和重放；页面刷新、后退和未知路径必须有明确结果，而不是只验证点击链接。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

### 3. Vuex约束共享写入

state保存共享事实，getter派生读取，mutation同步提交状态，action协调异步流程。对象引用意味着直接修改嵌套对象同样会改变store；开发约束要让写入经过可追踪入口，并为失败请求定义回滚或错误状态。

先预测：若省略这一层，状态、组件身份、异步任务或构建产物会在哪里首次偏离？

## 最小可运行实验

下面的最小实现聚焦本页核心。先在独立页面运行，再加入空输入、快速重复操作和销毁重建；不要直接把演示代码当成完整生产方案。

```js
const store = new Vuex.Store({
  state: { cart: [] },
  mutations: {
    add(state, product) {
      state.cart.push(product);
    },
  },
  actions: {
    addToCart({ commit }, product) {
      commit("add", product);
    },
  },
});
```

证据记录必须同时保存目录坐标、运行时和状态摘要：

```yaml
book: Vue.js从入门到项目实战
page: vjp-06-projectization
sample: normal | boundary | failure | recovery
runtime: Vue 2.x + pinned toolchain
input_fixture: fixed
first_divergence: null
cleanup_complete: true
```

故障脚本保持一次只改变一个变量：

```text
baseline -> run_same_input
inject -> stale-state | duplicate-event | denied-resource | broken-build
observe -> stop_at_first_divergence
recover -> clear_fault_and_replay
assert -> one_state_owner && stable_output && no_stale_task && no_resource_leak
```

## 常见误区与故障注入

<Callout type="trap">
  **误区一：把所有组件局部状态都放进Vuex，增加全局耦合却没有获得跨边界共享价值。**
  最终截图可能仍正确，但状态轨迹、资源数量或下一次交互已经偏离；必须保存首次偏离前后的输入与事件。
</Callout>

<Callout type="trap">
  **误区二：路由只在点击导航时可用，刷新深层URL或浏览器后退时丢失状态和匹配结果。**
  用正常样本无法暴露这一问题，要增加边界、失败和恢复样本，并在销毁后检查残留任务。
</Callout>

## 验收矩阵

| 样本 | 输入与环境变化               | 预期状态       | 通过条件               |
| ---- | ---------------------------- | -------------- | ---------------------- |
| 正常 | 合法数据、稳定身份、固定版本 | 完成主链       | 输出与状态摘要一致     |
| 边界 | 空值、极限数量、快速重复事件 | 有界退化       | 不越界、不重复、不阻塞 |
| 失败 | 请求拒绝、旧缓存、资源缺失   | 首偏离点停止   | 错误显式传播或降级     |
| 恢复 | 清除故障后重放同一输入       | 收敛到正常轨迹 | 无陈旧任务和资源泄漏   |

本页签发不变量是：**项目目录能说明责任，任意有效URL可刷新恢复，共享状态只经可追踪入口修改，异步失败不会留下半提交状态。** 单次成功、平均耗时或最终截图不能代替运行时版本、事件轨迹、首偏离点和清理证据。
