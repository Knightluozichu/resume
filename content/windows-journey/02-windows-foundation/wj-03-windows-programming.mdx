  注入“遗漏 DefWindowProc、DispatchMessage 或 PostQuitMessage”后应停在第一个因果分叉；若MSG 序列、窗口句柄、分派顺序、CPU 空闲率和退出码无法解释并复位，当前实现失败。
</Callout>
