## 问题先于 API

直接持有 HDC 或删除仍被选入 DC 的对象会产生泄漏和未定义绘制状态。本章先保存问题、初态和输入，再讨论 API；通过条件是“每次取得的 DC 都按来源配对释放，每个 GDI 对象删除前已脱离 DC”，不是画面偶然出现一次。
