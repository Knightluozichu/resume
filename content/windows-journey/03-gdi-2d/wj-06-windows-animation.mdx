## 问题先于 API

每次循环移动固定距离会让动画速度随机器和窗口消息负载变化。本章先保存问题、初态和输入，再讨论 API；通过条件是“相同真实时长和输入产生相同模拟时间与动画帧序列”，不是画面偶然出现一次。
