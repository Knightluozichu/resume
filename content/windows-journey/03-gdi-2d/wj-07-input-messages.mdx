## 问题先于 API

把按键消息当成连续状态会丢失按住语义，把屏幕坐标当客户区坐标会错位。本章先保存问题、初态和输入，再讨论 API；通过条件是“同一输入记录与窗口尺寸产生相同动作序列”，不是画面偶然出现一次。

## 可重放实现或计算骨架

```text
freeze -> 接收消息 -> 换算坐标 -> 更新快照 -> 消费动作 -> 焦点复位
fault -> 窗口失焦后按键状态未清零导致角色持续移动
evidence -> 消息时间戳、动作快照、坐标换算和焦点转换
reset -> replay identical input
```

真实程序还要固定编译器、SDK、窗口尺寸、资源、随机种子、时间步和输入记录；否则历史实现与现代迁移不能公平比较。
