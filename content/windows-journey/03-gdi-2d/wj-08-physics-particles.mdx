## 问题先于 API

逐帧常量位移和随帧率取随机数会让粒子轨迹不可重放。本章先保存问题、初态和输入，再讨论 API；通过条件是“相同初态、种子、输入和步长产生相同粒子轨迹”，不是画面偶然出现一次。
