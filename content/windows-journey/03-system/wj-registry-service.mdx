## 直觉引入

注册表是 Windows 的「档案柜」——系统的所有配置都存在这里，从桌面壁纸到启动项，从硬件驱动到软件设置。而服务是 Windows 的「后勤人员」——那些不需要用户登录就在后台默默运行的程序（如 Windows Update、防火墙、数据库引擎）。它们的关系是：服务的配置就存在注册表的 `HKLM\SYSTEM\CurrentControlSet\Services` 下——注册表是服务的「人事档案」。

## 注册表结构与 API

<Term def="注册表（Registry）是 Windows 的层次化配置数据库，以树形结构存储系统和应用的配置信息。五大根键：HKCR（文件关联/COM）、HKCU（当前用户配置）、HKLM（系统全局配置）、HKUS（所有用户配置）、HKCC（当前硬件配置）。">注册表</Term>的基本操作遵循「打开→读写→关闭」模式：

```c
// 读取注册表配置
HKEY hKey;
// 1. 打开键
LONG result = RegOpenKeyExW(
    HKEY_CURRENT_USER,           // 根键
    L"Software\\MyApp",          // 子键路径
    0,                           // 保留参数
    KEY_READ,                    // 访问权限
    &hKey                        // 输出键句柄
);
if (result == ERROR_SUCCESS) {
    // 2. 读取值
    WCHAR value[256];
    DWORD valueSize = sizeof(value);
    DWORD valueType;
    RegQueryValueExW(hKey, L"Setting", NULL, &valueType,
                     (LPBYTE)value, &valueSize);

    // 也可以写入值
    DWORD data = 42;
    RegSetValueExW(hKey, L"Count", 0, REG_DWORD,
                   (const BYTE*)&data, sizeof(data));

    // 3. 关闭键
    RegCloseKey(hKey);
}

// 枚举子键
DWORD index = 0;
WCHAR subKeyName[256];
DWORD nameSize = 256;
while (RegEnumKeyExW(hKey, index, subKeyName, &nameSize,
                     NULL, NULL, NULL, NULL) == ERROR_SUCCESS) {
    // 处理子键...
    index++;
    nameSize = 256;
}
```

注册表值类型：`REG_SZ`（字符串）、`REG_DWORD`（32位整数）、`REG_BINARY`（二进制）、`REG_MULTI_SZ`（多字符串）、`REG_EXPAND_SZ`（可展开环境变量的字符串）。

## 服务体系与 SCM

<Term def="服务控制管理器（SCM，services.exe）是 Windows 的服务管理核心进程，在系统启动时运行。负责读取注册表中的服务配置、按启动类型启动服务、接受服务控制请求（停止/暂停/继续）、维护服务状态。">SCM</Term>统一管理所有 Windows 服务。服务的配置存储在注册表中，生命周期由 SCM 控制：

```c
// 服务程序的入口结构
void WINAPI ServiceMain(DWORD argc, LPWSTR* argv) {
    // 1. 注册控制处理器
    SERVICE_STATUS_HANDLE hStatus = RegisterServiceCtrlHandlerExW(
        L"MyService", CtrlHandler, NULL);

    // 2. 上报启动中状态
    SERVICE_STATUS status = {};
    status.dwServiceType = SERVICE_WIN32_OWN_PROCESS;
    status.dwCurrentState = SERVICE_START_PENDING;
    SetServiceStatus(hStatus, &status);

    // 3. 执行服务逻辑（后台循环）
    // ... 服务工作 ...

    // 4. 上报运行中状态
    status.dwCurrentState = SERVICE_RUNNING;
    status.dwControlsAccepted = SERVICE_ACCEPT_STOP;
    SetServiceStatus(hStatus, &status);

    // 5. 等待停止请求
    WaitForSingleObject(hStopEvent, INFINITE);

    // 6. 上报已停止
    status.dwCurrentState = SERVICE_STOPPED;
    SetServiceStatus(hStatus, &status);
}

// 从外部控制服务
void ManageService() {
    // 打开 SCM
    SC_HANDLE hSCM = OpenSCManagerW(NULL, NULL, SC_MANAGER_ALL_ACCESS);

    // 打开服务
    SC_HANDLE hService = OpenServiceW(hSCM, L"MyService",
                                       SERVICE_START | SERVICE_STOP);

    // 启动服务
    StartServiceW(hService, 0, NULL);

    // 停止服务
    SERVICE_CONTROL_STATUS_REASON_PARAMS reason = {};
    ControlServiceEx(hService, SERVICE_CONTROL_STOP, &reason, NULL);

    CloseServiceHandle(hService);
    CloseServiceHandle(hSCM);
}
```

<Callout type="trap">
**误区：注册表可以随便改，改错了重启就好。** 注册表是系统全局配置，错误修改可能导致系统无法启动、蓝屏或数据丢失。特别是 `HKLM\SYSTEM` 和 `HKLM\SAM` 下的键——前者影响驱动加载和启动配置，后者存储安全账户信息。修改前必须备份（`reg export` 或系统还原点）。运行时修改注册表后，大多数应用需要重启才能读取新值（除非程序监听了 `RegNotifyChangeKeyValue`）。服务相关的注册表修改后需要重启服务或重启系统才生效。
</Callout>

<Exercises>
**问题 1**：注册表的五大根键分别是什么？

<Answer>
①HKCR（HKEY_CLASSES_ROOT）——文件关联和 COM 组件注册信息；②HKCU（HKEY_CURRENT_USER）——当前用户个人配置（桌面/环境变量）；③HKLM（HKEY_LOCAL_MACHINE）——系统全局配置（硬件/软件/安全），所有用户共享；④HKU（HKEY_USERS）——所有用户配置文件集合，HKCU 是其别名；⑤HKCC（HKEY_CURRENT_CONFIG）——当前硬件配置文件。HKLM 和 HKCU 是最常操作的根键。
</Answer>

**问题 2**：服务的三种启动类型是什么？SCM 如何管理服务？

<Answer>
SCM 在系统启动时读取注册表 `HKLM\SYSTEM\CurrentControlSet\Services` 下的服务配置。三种启动类型：①SERVICE_AUTO_START（自动）——系统启动时自动启动；②SERVICE_DEMAND_START（手动）——由 StartService 按需启动；③SERVICE_DISABLED（禁用）——不可启动。服务生命周期：SCM 启动服务进程 → ServiceMain 执行 → RegisterServiceCtrlHandler 注册控制处理器 → SetServiceStatus 上报状态 → 收到 SERVICE_CONTROL_STOP 时清理退出。ControlService 发送控制码，QueryServiceStatus 查询状态。
</Answer>
</Exercises>

<Glossary>
<GlossaryItem term="注册表（Registry）">Windows 的层次化配置数据库，树形结构：根键 → 子键 → 值项。值项由名称+类型+数据组成。常见类型：REG_SZ（字符串）、REG_DWORD（32位整数）、REG_BINARY（二进制）、REG_MULTI_SZ（多字符串）。API：RegOpenKeyEx/RegQueryValueEx/RegSetValueEx/RegCloseKey。修改需谨慎，错误修改可导致系统故障。</GlossaryItem>
<GlossaryItem term="SCM（服务控制管理器）">services.exe 进程，系统启动时运行，统一管理所有 Windows 服务。负责读取注册表服务配置、按启动类型启动、接受控制请求（停止/暂停/继续）、维护服务状态。服务配置存在 HKLM\SYSTEM\CurrentControlSet\Services\<服务名> 下，包含 ImagePath（路径）、Start（启动类型）、Type（服务类型）等值。</GlossaryItem>
<GlossaryItem term="服务生命周期">SCM 读取配置 → StartService 启动 → ServiceMain 入口 → RegisterServiceCtrlHandler 注册 → SetServiceStatus(SERVICE_RUNNING) → 工作循环 → 收到 STOP → SetServiceStatus(SERVICE_STOPPED) → 退出。三种启动类型：自动（AUTO_START）、手动（DEMAND_START）、禁用（DISABLED）。</GlossaryItem>
</Glossary>
