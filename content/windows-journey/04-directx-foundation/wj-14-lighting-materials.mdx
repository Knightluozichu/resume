14.9 章节小憩 进入“计算漫反射”阶段时，先标出输入、状态拥有者和可见输出，再解释在同一空间计算环境光、漫反射和镜面项，再由材质决定反射比例。2013 年的 API 名称作为历史坐标保留；迁移到现代工具时只替换实现，不能改变本章问题与证据口径。

验证 14.9 章节小憩 时固定其余条件，记录点积、各光照分量、法线长度和最终颜色，随后注入“非均匀缩放后法线未正确变换或归一化”并执行复位。该节点由此同时具备出现、解释、专属实验和练习验证四级证据。

## 可重放实现或计算骨架

```text
initial = fixed_state + fixed_input + fixed_timestep
historical = run(initial, "D3D9 固定光照")
modern = run(initial, "着色器显式光照")
compare(historical, modern, "颜色误差")
pass = "光照结果能由法线、光向、视向和材质参数逐项复算"
```

真实程序还要固定编译器、SDK、窗口尺寸、资源、随机种子、时间步和输入记录；否则历史实现与现代迁移不能公平比较。

<Callout type="trap" title="把历史 API 当成当前默认方案">
  本章保留 D3D9 固定光照 的教学身份，但新项目必须核对平台支持并解释为何选择 着色器显式光照 或其他方案。
</Callout>

<Callout type="trap" title="只看最终画面">
  第14章 绘制出质感的世界—光照与材质必须说明准备法线、变换光向、计算漫反射、计算镜面、合成材质的先后关系；最终像素相同不代表消息、资源、矩阵或状态安全。
</Callout>

<Callout type="trap" title="失败后继续运行">
  注入“非均匀缩放后法线未正确变换或归一化”后应停在第一个因果分叉；若点积、各光照分量、法线长度和最终颜色无法解释并复位，当前实现失败。
</Callout>
