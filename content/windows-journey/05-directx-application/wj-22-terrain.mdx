## 可重放实现或计算骨架

```text
freeze -> 读取高度 -> 生成顶点 -> 建立索引 -> 计算法线 -> 查询碰撞
fault -> 世界坐标到高度图索引取整越界或查询使用另一条对角线
evidence -> 高度样本、顶点索引、三角重心、法线和查询误差
reset -> replay identical input
```

真实程序还要固定编译器、SDK、窗口尺寸、资源、随机种子、时间步和输入记录；否则历史实现与现代迁移不能公平比较。

<Callout type="trap" title="把历史 API 当成当前默认方案">
  本章保留 CPU 高度图地形 的教学身份，但新项目必须核对平台支持并解释为何选择 分块地形管线 或其他方案。
</Callout>

<Callout type="trap" title="只看最终画面">
  第22章 钟灵毓秀的世界——三维地形的构建必须说明读取高度、生成顶点、建立索引、计算法线、查询碰撞的先后关系；最终像素相同不代表消息、资源、矩阵或状态安全。
</Callout>

<Callout type="trap" title="失败后继续运行">

</Callout>
