## 可重放实现或计算骨架

```text
freeze -> 池中发射 -> 更新寿命 -> 积分位置 -> 相机排序 -> 批量回收
fault -> 透明粒子近到远绘制或死亡粒子仍留在活动列表
evidence -> 发射序号、寿命、位置、排序键、池容量和绘制批次
reset -> replay identical input
```

真实程序还要固定编译器、SDK、窗口尺寸、资源、随机种子、时间步和输入记录；否则历史实现与现代迁移不能公平比较。
