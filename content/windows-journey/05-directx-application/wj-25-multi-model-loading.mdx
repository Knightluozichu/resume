## 问题先于 API

逐实例重复加载会放大内存，而错误共享可变状态会让一个模型污染其他模型。本章先保存问题、初态和输入，再讨论 API；通过条件是“同一资产只加载一次，实例变化不修改共享资源或其他实例”，不是画面偶然出现一次。

## 可重放实现或计算骨架

```text
freeze -> 规范路径 -> 查询缓存 -> 加载资源 -> 创建实例 -> 引用释放
fault -> 缓存键未规范化造成重复资源，或实例直接改共享材质
evidence -> 缓存键、资源身份、引用计数、实例变换和内存占用
reset -> replay identical input
```

真实程序还要固定编译器、SDK、窗口尺寸、资源、随机种子、时间步和输入记录；否则历史实现与现代迁移不能公平比较。
