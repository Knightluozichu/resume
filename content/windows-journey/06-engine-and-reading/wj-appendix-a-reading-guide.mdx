## 可重放实现或计算骨架

```text
freeze -> 定位缺口 -> 核对版本 -> 选择资料 -> 制作产物 -> 复盘去留
fault -> 按知名度囤积资料却没有练习产物和停止条件
evidence -> 能力矩阵、版本信息、阅读产物和复盘记录
reset -> replay identical input
```

真实程序还要固定编译器、SDK、窗口尺寸、资源、随机种子、时间步和输入记录；否则历史实现与现代迁移不能公平比较。

<Callout type="trap" title="把历史 API 当成当前默认方案">
  本章保留 2013 进阶书单 的教学身份，但新项目必须核对平台支持并解释为何选择 持续更新路线 或其他方案。
</Callout>

<Callout type="trap" title="只看最终画面">
  附录A 进阶游戏编程书籍总结与推荐必须说明定位缺口、核对版本、选择资料、制作产物、复盘去留的先后关系；最终像素相同不代表消息、资源、矩阵或状态安全。
</Callout>

<Callout type="trap" title="失败后继续运行">
  注入“按知名度囤积资料却没有练习产物和停止条件”后应停在第一个因果分叉；若能力矩阵、版本信息、阅读产物和复盘记录无法解释并复位，当前实现失败。
</Callout>
