## 为什么从这个问题开始

第1章 Windows内部概览围绕“进程、线程、句柄、对象与虚拟内存怎样按目标build和进程上下文建立可调试关系？”建立贯穿任务。先冻结出版轨、目标build、驱动包和对象身份，再以小输入观察状态与调用链，最后用唯一故障和同输入恢复验收；只有守住“每个地址、ID、句柄和对象引用都绑定进程、build、架构与生命周期”并交付对象关系图、句柄/访问掩码、VA页状态与系统调用轨迹，目录术语、DDI名字或一次成功加载才可能升级为机制证据。
