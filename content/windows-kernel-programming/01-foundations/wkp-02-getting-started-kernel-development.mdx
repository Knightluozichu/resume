## 为什么从这个问题开始

第2章 开始内核开发围绕“Windows build、SDK、WDK、Visual Studio、架构、驱动模型、签名与部署怎样组成可恢复构建链？”建立贯穿任务。先冻结出版轨、目标build、驱动包和对象身份，再以小输入观察状态与调用链，最后用唯一故障和同输入恢复验收；只有守住“可重建驱动包只进入隔离测试目标且卸载、重启和快照恢复均可用”并交付环境清单、SYS/INF/CAT摘要、签名验证、部署日志与恢复快照，目录术语、DDI名字或一次成功加载才可能升级为机制证据。
