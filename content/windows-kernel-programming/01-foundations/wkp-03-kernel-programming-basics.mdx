## 为什么从这个问题开始

第3章 内核程序设计基础围绕“NTSTATUS、IRQL、字符串、池、链表、驱动对象和设备对象怎样形成失败安全的内核合同？”建立贯穿任务。先冻结出版轨、目标build、驱动包和对象身份，再以小输入观察状态与调用链，最后用唯一故障和同输入恢复验收；只有守住“每条成功与失败路径都满足IRQL、分页性、所有权、引用和反向清理”并交付DDI/IRQL矩阵、池标签与分配轨迹、对象/链表不变量和失败注入，目录术语、DDI名字或一次成功加载才可能升级为机制证据。
