## 为什么从这个问题开始

第4章 驱动程序：从头到尾围绕“DriverEntry、设备对象、访问控制、Create/Close、IOCTL与Unload怎样闭合一个驱动生命周期？”建立贯穿任务。先冻结出版轨、目标build、驱动包和对象身份，再以小输入观察状态与调用链，最后用唯一故障和同输入恢复验收；只有守住“停止新请求后所有句柄、IRP、引用、设备与命名对象按反向顺序归零”并交付生命周期状态机、SDDL/设备访问、IOCTL协议夹具、并发关闭与卸载轨迹，目录术语、DDI名字或一次成功加载才可能升级为机制证据。
