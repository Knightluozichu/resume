## 为什么从这个问题开始

第10章 文件系统小过滤驱动围绕“Minifilter的高度、注册、实例、pre/post、文件名、context、I/O、通信端口与卸载怎样闭环？”建立贯穿任务。先冻结出版轨、目标build、驱动包和对象身份，再以小输入观察状态与调用链，最后用唯一故障和同输入恢复验收；只有守住“过滤次序合法且callback data、名称、context、端口、实例和filter引用全部归零”并交付高度/加载组身份、操作回调轨迹、名称/context引用、端口消息与Filter Verifier结果，目录术语、DDI名字或一次成功加载才可能升级为机制证据。

第10章 文件系统小过滤驱动把Minifilter装卸、初始化、高度、I/O、删除保护、文件名、context、备份、通信与调试连接成可复核链：中文版目录给185正式坐标，作者一版页面暴露19项目录差异，18页样章限定局部授权，二版与MIT仓库只支持迁移，当前Microsoft文档和目标DDI限定实际合同。版本/IRQL合同、透明对象探针、唯一故障首错、反向卸载和同输入恢复共同决定能否上架。最终交付高度/加载组身份、操作回调轨迹、名称/context引用、端口消息与Filter Verifier结果并同时报告未测build、未开放正文和安全边界。
