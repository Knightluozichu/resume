## 数据包分析流程

一次完整的数据包分析经历以下阶段：

```text
启动抓包 → 捕获过滤 → 显示过滤 → 协议解码 → 流量分析 → 异常检测 → 报告整合
```

<Callout type="info" title="为什么从工具基础开始学">

数据包分析的前提是「能抓到包、能看懂界面」。Wireshark 的三大核心区域（包列表、包详情、原始字节）是所有后续分析的基础——过滤技术在包列表中应用，协议解码在包详情中展开，安全检测依赖前两者的组合。先掌握工具操作，后续的过滤和协议分析才有立足点。

</Callout>

## 推荐学习路径

```text
工具基础(界面/抓包) → 过滤技术(捕获/显示) → 协议分析(链路/传输/应用) → 安全检测 → 复习整合
       ↓                    ↓                      ↓                    ↓            ↓
    界面布局             BPF语法              以太网/IP            端口扫描        端到端流程
    抓包流程             显示表达式             TCP/UDP             DDoS检测        知识网络
                                              HTTP/DNS             入侵检测
```

<Glossary>

<GlossaryItem term="Wireshark">
Wireshark 是全球最流行的开源网络协议分析工具，支持 2000+ 协议的深度解码。它通过网卡抓取网络流量，逐层解析数据包，提供包列表、包详情树、原始字节三视图。核心能力：实时抓包与离线分析、BPF 捕获过滤与显示过滤、TCP 流跟踪、统计图表（Endpoints/Conversations/IO Graphs）、协议解密（TLS/Wireshark 密钥日志）。适用于网络故障排查、协议学习、安全审计和性能分析。
</GlossaryItem>

<GlossaryItem term="五大知识域">
Wireshark 数据包分析实战的内容按递进关系分为五大知识域：①工具基础（界面操作、抓包流程）②过滤技术（BPF 捕获过滤、显示表达式）③协议分析（以太网/IP/TCP/UDP/HTTP/DNS/DHCP 逐层解码）④安全检测（端口扫描、DDoS、入侵检测、恶意通信识别）⑤知识整合（端到端分析流程、知识网络）。每个域解决一个核心问题，域间有依赖关系：工具是地基，过滤是手段，协议是内容，安全是应用，整合是闭环。
</GlossaryItem>

<GlossaryItem term="数据包分析流程（Packet Analysis Workflow）">
完整的数据包分析流程：①启动抓包（选网卡、设捕获过滤）②捕获过滤（BPF 语法减少抓包量）③显示过滤（表达式筛选聚焦目标）④协议解码（逐层展开包详情）⑤流量分析（跟踪 TCP 流、统计会话）⑥异常检测（识别扫描/洪泛/入侵）⑦报告整合（导出数据、撰写报告）。核心思维：自底向上逐层解码 + 自顶向下需求驱动过滤 + 全局统计定位异常。
</GlossaryItem>

<GlossaryItem term="协议栈层级（Protocol Stack Layers）">
网络协议按 OSI 七层模型分层，Wireshark 逐层解码：链路层（Ethernet——MAC 地址、帧结构）→ 网络层（IP——IP 地址、路由、分片；ARP——地址解析）→ 传输层（TCP——面向连接可靠传输；UDP——无连接快速传输）→ 应用层（HTTP/DNS/DHCP 等业务协议）。每一层的数据封装在下一层的 Payload 中，Wireshark 在包详情区以树形结构逐层展开，点击展开即可查看各层字段。
</GlossaryItem>

</Glossary>

**问题 1：** Wireshark 数据包分析实战的五大知识域分别解决什么问题？它们之间有什么依赖关系？

<Answer>

五大知识域：①工具基础——解决「工具怎么用、界面怎么看」，是所有后续分析的地基 ②过滤技术——解决「怎么精准捕获和筛选」，依赖工具基础的操作能力 ③协议分析——解决「各层协议怎么拆解」，依赖过滤技术来定位目标包 ④安全检测——解决「怎么发现异常和攻击」，依赖协议分析来理解正常与异常的区别 ⑤知识整合——解决「知识怎么串联、端到端怎么分析」。依赖链：工具 → 过滤 → 协议 → 安全 → 整合，同时安全检测贯穿所有协议层。

</Answer>

**问题 2：** 描述一次完整的数据包分析流程，涉及本书哪些章节的知识？

<Answer>

完整流程：①启动抓包——选网卡、设置捕获过滤器（第 1-2 章工具基础和捕获过滤）②显示过滤——用表达式筛选聚焦目标（第 3 章显示过滤器）③协议解码——逐层展开：以太网→IP→TCP→HTTP/DNS（第 4-7 章协议分析）④流量分析——跟踪 TCP 流、统计会话（第 5-6 章传输层和应用层）⑤异常检测——识别扫描/DDoS/入侵（第 8 章安全检测）⑥报告整合——导出数据、撰写分析报告（第 9 章知识整合）。每一步都用过滤器驱动，逐层缩小分析范围。

</Answer>
