## Wireshark 界面布局

<WpaWiresharkBasicsDiagram />

Wireshark 界面由上至下分为五大区域，每个区域服务于分析的不同环节。

### 三大核心区域

| 区域 | 功能 | 关键信息 |
|------|------|---------|
| 包列表区（Packet List） | 每行一个数据包 | 序号/时间/源/目的/协议/长度/摘要 |
| 包详情区（Packet Details） | 树形协议解码 | 逐层展开：Frame → Ethernet → IP → TCP → HTTP |
| 原始字节区（Packet Bytes） | 十六进制+ASCII | 选中字段在此高亮对应字节 |

```text
包列表区操作：
  - 点击某行 → 包详情区和原始字节区同步更新
  - 右键某行 → Apply as Filter / Follow TCP Stream / Colorize
  - 双击某行 → 弹出独立详情窗口

包详情区操作：
  - 点击 ▸ → 展开该层协议字段
  - 右键字段 → Apply as Filter / Prepare as Filter / Copy
  - 选中字段 → 原始字节区高亮对应字节
```

## 抓包流程

### 基本操作

```text
1. 选择网卡：Capture → Options（或点击网卡列表）
2. 开始抓包：点击工具栏鲨鱼鳍按钮（蓝色）
3. 产生流量：在浏览器中访问网页、执行命令等
4. 停止抓包：点击工具栏红方块按钮
5. 分析数据：在包列表区过滤和查看
```

<Callout type="warning" title="网卡选择注意事项">

选择网卡时要注意：①选择实际有流量通过的网卡（有线选 eth0/en0，无线选 wlan0）②如果不确定哪个网卡有流量，先看网卡列表中的流量波形图 ③虚拟机环境选对应的桥接或 NAT 网卡 ④管理员/root 权限才能抓包（Linux 需 `sudo` 或配置 dumpcap 权限）。

</Callout>

### 混合模式与监听模式

| 模式 | 适用场景 | 原理 |
|------|---------|------|
| 混合模式（Promiscuous） | 有线网络 | 网卡接收局域网所有包（含发往其他设备的） |
| 监听模式（Monitor） | 无线网络 | 网卡接收空气中所有 Wi-Fi 802.11 帧 |

```text
混合模式局限：
  交换网络中，交换机只把包送到目标端口
  → 混合模式只能收到：广播帧 + 本端口流量
  → 要抓其他端口的流量需：端口镜像 / SPAN

监听模式优势：
  无线网卡以监听方式接收所有 802.11 帧
  → 可抓其他设备之间的 Wi-Fi 通信
  → 无需关联到特定 AP
```

## 文件管理

### 保存与打开

```text
保存：File → Save As → 选择路径和格式
打开：File → Open → 选择 .pcapng/.pcap 文件
      或直接拖拽文件到 Wireshark 窗口
```

### 文件格式对比

| 格式 | 全称 | 特点 |
|------|------|------|
| pcapng | PCAP Next Generation | 默认格式，支持多接口/注释/元数据 |
| pcap | libpcap | 旧格式，单接口，兼容性好 |
| 5vw | 5views | 商业抓包工具格式 |

<Callout type="info" title="pcapng 的优势">

pcapng 是现代抓包格式：①支持多接口数据（同一文件可含有线+无线）②支持自定义注释（可在包上添加备注）③支持更大的文件（超过 4GB）④向后兼容 pcap 格式。推荐始终使用 pcapng 格式保存。

</Callout>

## 着色规则

Wireshark 内置着色规则，不同协议和包类型用不同颜色高亮：

```text
常见着色规则（View → Coloring Rules）：
  HTTP 请求    → 绿色
  HTTP 响应    → 浅绿
  TCP RST      → 红色
  TCP SYN      → 浅蓝
  DNS          → 蓝色
  TLS          → 紫色
  错误/异常     → 深红
```

<Glossary>

<GlossaryItem term="混合模式（Promiscuous Mode）">
混合模式是有线网卡的抓包模式：网卡不再只接收发给自己的帧，而是接收网卡上所有的电信号帧。在共享式网络（Hub）中可抓到所有流量；在交换式网络中由于交换机隔离，只能收到广播帧和本端口的流量。要抓其他端口的流量需要配置端口镜像（SPAN/Port Mirroring）。Wireshark 默认开启混合模式。
</GlossaryItem>

<GlossaryItem term="监听模式（Monitor Mode）">
监听模式是无线网卡的抓包模式：网卡以「监听」方式接收空气中所有 Wi-Fi 802.11 帧，包括其他设备之间的通信，无需关联到特定 AP。这是无线网络分析的基础——不进入监听模式只能收到自己关联 AP 的通信帧。在 Wireshark 抓包选项中，无线网卡支持切换到监听模式。注意：监听模式下网卡不发送数据，只接收。
</GlossaryItem>

<GlossaryItem term="pcapng（PCAP Next Generation）">
pcapng 是 Wireshark 默认的抓包文件格式，取代旧的 pcap 格式。优势：①支持多接口——同一文件可包含多个网卡的数据（如同时抓有线和无线）②支持注释——可在任意包上添加文本备注 ③支持元数据——记录抓包接口、OS、应用等信息 ④支持大文件——超过 4GB 无问题 ⑤向后兼容 pcap。文件扩展名通常为 .pcapng。
</GlossaryItem>

<GlossaryItem term="着色规则（Coloring Rules）">
Wireshark 的着色规则自动给不同类型的包上色，帮助快速识别包的性质。内置规则如：HTTP 请求为绿色、TCP RST 为红色、DNS 为蓝色、TLS 为紫色等。用户可在 View → Coloring Rules 中自定义规则。着色基于显示过滤器表达式——每条规则是一个过滤器+一个颜色。右键包列表中的某行 → Colorize Conversation 可给特定会话着色，方便区分多个并行会话。
</GlossaryItem>

</Glossary>

<Exercises>

**问题 1：** Wireshark 界面的三大核心区域分别显示什么内容？它们之间如何联动？

<Answer>

三大核心区域：①包列表区——每行一个数据包，显示序号、时间、源/目的地址、协议、长度、摘要信息 ②包详情区——树形展开当前选中包的逐层协议解码，点击 ▸ 展开各字段 ③原始字节区——十六进制+ASCII 对照显示包的原始字节。联动方式：点击包列表区的某行 → 包详情区和原始字节区同步更新为该包的内容；在包详情区选中某个字段 → 原始字节区高亮该字段对应的字节。这种三视图联动让分析者能同时看到摘要、解码和原始数据。

</Answer>

**问题 2：** 混合模式和监听模式有什么区别？在交换式网络中混合模式有什么局限？

<Answer>

混合模式用于有线网卡，让网卡接收局域网中所有帧（不仅是发给自己的）；监听模式用于无线网卡，让网卡接收空气中所有 Wi-Fi 802.11 帧（包括其他设备之间的通信）。在交换式网络中混合模式的局限：交换机只会把帧送到目标端口，因此网卡即使开启混合模式也只能收到广播帧和发往本端口的帧，无法抓取其他端口的通信。要抓其他端口的流量需要配置端口镜像（SPAN/Port Mirroring），将其他端口的流量复制到抓包端口。

</Answer>

</Exercises>
