# SVG 配图布局铁律

> 所有 `src/components/mdx/**` 下的 SVG 配图**必须逐条遵守**。画图或改图前必须先读本文件；违反任意一条 = review 打回。

---

## 一、画布与边框

| 规则 | 要求 | 违例示例 |
|---|---|---|
| **R1** | 容器四周留白 ≥ 32px，文字距边界 ≥ 24px | `y={30}` 放标题在 520px 高的画布里——标题上边距仅 30px |
| **R2** | 底部最后一行文字距 `VIEW_H` 底部 ≥ 24px | `y={VIEW_H - 8}` 放文字在半像素贴底 |
| **R3** | viewBox 宽 ≥ 660px（不得小于这个值，否则移动端文字密集处必然挤压） | `viewBox="0 0 480 380"` |

---

## 二、字号系统

SVG 中 `fontSize` 无 em/rem 概念——px 直接对应 viewBox 逻辑像素。本站统一阶梯：

| 角色 | 最小字号 | 推荐 | 用途 |
|---|---|---|---|
| **主标题** | 15px | 16px | 图题（每张图一个） |
| **节标题** | 13px | 14px | 面板标题、分支名 |
| **正文/标签** | 11px | 12px | 数字、节点内文字、标注 |
| **辅助说明** | 10px | — | 仅用于图例脚注、来源标注 |

**R4**：正文文字最小 11px，禁止使用 8.5px / 9px / 9.5px。≤10px 仅允许在脚注/图例中出现且**每图不超过 2 处**。

---

## 三、元素间距

| 规则 | 要求 |
|---|---|
| **R5** | 同层相邻盒子/节点间间距 ≥ 8px（包括文本到边框、文本到相邻盒的距离） |
| **R6** | 上下两行文字行距 ≥ 行高 + 6px（即 12px 文字的行距 ≥ 18px） |
| **R7** | 箭头标签与节点边缘距离 ≥ 10px，箭头不能"戳进"盒子 |
| **R8** | 三段式面板布局：面板间间距 ≥ 20px |
| **R9** | 任一区域（面板/面板内子区域/底部总结栏）的**内部总高度 ≥ 该区域内元素数量 × 行高 + 标注高度 + 上下内边距各 12px**——计算值不够就加大面板高度。**禁止"压缩到刚好塞进去"。** |

---

## 四、视觉层次

| 规则 | 要求 |
|---|---|
| **R10** | 标题 → 主体图示 → 底部总结/复杂度：三段式垂直分层，层之间有分隔线或 ≥ 20px 留白 |
| **R11** | 同一张图中，同类型元素的尺寸统一（如所有数字盒子宽高一致、所有节点圆半径一致） |
| **R12** | 颜色语义固定：高亮/accent 用于当前操作元素，success 用于正确/完成，warning 用于警告/失衡，danger 用于错误/删除 |

---

## 五、SOP：画新配图前的布局检查单

每画或重修一张 SVG 前，先读本文件并在纸面/代码常量里预留画布、泳道、节点、文字和箭头空间。每画完一张 SVG，按以下清单自检后才可以提交：

- [ ] 整张图上下左右各有 ≥ 32px 无元素空白区（R1）
- [ ] 没有 fontSize < 10px 的文字（R4）
- [ ] 所有相邻元素间距离 ≥ 8px，用手量坐标差自证（R5）
- [ ] 文本与文本、文本与箭头/路径之间没有互压或穿插（R5/R7）
- [ ] 面板高度 = 内容总高 + 24px 上下内边距，不按刚好塞下算（R9）
- [ ] 三段层次（标题/主体/底部）之间有清晰分隔（R10）
- [ ] 同类元素宽高一致（R11）
- [ ] 选中/hover 态与普通态肉眼可区分（R12）
